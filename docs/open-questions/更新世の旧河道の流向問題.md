# 未解決問題：更新世の旧河道はどちら向きに流れていたのか

弦巻川・水窪川側の浅い谷と谷端川側の谷は、お茶の水女子大学付近を経て地形的につながっていた可能性がある。しかし、**谷筋がつながることと、水がどちら向きに流れたかは別問題**であり、流向は未決着である。

この問題はこれまで [横断テーマ](../横断テーマ.md) と [歴史地形・流路シミュレーション方針](../歴史地形・流路シミュレーション方針.md) に整理してきたが、他の中心課題と同様に独立文書として切り出す。

主要出典は各節に直接示す。共通の書誌情報は [出典一覧](../出典一覧.md) を参照。

## 問い

現在の中心的な問いは次の三つである。

1. 弦巻川・水窪川側の谷と谷端川側の谷は、更新世のある時期に一本の谷として連続していたのか。
2. 連続していたなら、水は弦巻川・水窪川側から谷端川へ流れたのか、その逆か、それとも途中に分水界があったのか。
3. 音羽谷を神田川へ南下する流れは、その時期にすでに存在していたのか（後述の小日向台「島状」仮説の前提条件）。

## 滝口（2019）の旧河道説

滝口志郎「武蔵野台地の地形に関する諸問題」（2019）は、弦巻川・水窪川上流の浅い谷と、護国寺以南の深い谷の**河床高度が不連続**であることに注目し、上流側の高い河床を更新世の旧河道と考える案を示している。さらに、弦巻川の流路がかつて谷端川側へつながっていた可能性を提示する。〔研究論文／仮説〕  
出典：滝口志郎「武蔵野台地の地形に関する諸問題」『深田地質研究所年報』第20号、2019年。[深田地質研究所](https://fukadaken.or.jp/?page_id=6569)、[国立国会図書館デジタルコレクション](https://dl.ndl.go.jp/pid/14529520)、[論文PDF（特に図5・図6、p.40–41）](https://fukadaken.or.jp/data_pdf/20_35.pdf) / [PAP-001](../sources/papers/PAP-001.md)(../出典一覧.md)

一例として、お茶の水女子大学付近を経て谷端川側へつながる流路が図示される（論文図6では弦巻川・水窪川が北側経由で谷端川へ注ぐ姿）。ただし論文の図は接続関係を概略的に示したもので、合流角や流向は厳密ではない。

## 考えられる流向の案

現時点では、次のどれか一つに固定しない。

- 弦巻川・水窪川側から谷端川へ流れた
- 谷端川側から護国寺方面へ流れた
- 途中に分水界があった
- 河川争奪や流路逆転が起きた
- 論文の図は接続関係を概略的に示しただけで、合流角や流向は厳密でない

### 産総研「都市域の地質地盤図 東京都区部」（2021年公開）

産業技術総合研究所は2021年5月21日、東京都区部の3次元地質地盤図を公開した。約5万地点のボーリング資料と独自調査を地層対比に利用し、任意の測線の地質断面図も表示できる。同発表は、武蔵野台地の一部に、約14万年前頃の氷期に形成され、約13万～12万年前の間氷期に海が侵入して軟らかい泥で埋められた谷があると説明する。〔確認：産総研の研究発表・公開図の仕様〕

ただし、約14万年前という年代は東京都区部で認められた古い埋没谷の**一般的な形成期**であり、三河川の下に同年代の谷が実際に連続することや、その流向を確認したものではない。本調査では護国寺・雑司が谷・小石川間の具体的な断面図の作成・判読はまだ行っていない。  
出典：産業技術総合研究所「[ついに完成！東京都心部の3次元地質地盤図](https://www.aist.go.jp/aist_j/press_release/pr2021/pr20210521/pr20210521.html)」（2021年5月21日）／「[都市域の地質地盤図](https://gbank.gsj.jp/urbangeol/)」

### 木村克己（2023）：小石川谷の埋没谷

木村克己「文京区本駒込周辺の地形を読み解く：本郷台の成り立ちと洪水・地震ハザード」（『深田地質研究所年報』第24号、2023年、pp.87–108）は、5m数値標高モデルとボーリング柱状図による地質断面から、小石川谷について上・中流では侵食が卓越するのに対し、下流は沖積層が埋めた埋没谷であると論じる。〔確認：論文の要旨・図表の説明〕

谷端川下流（小石川谷）と音羽谷の旧河道・更新世流向の検討において、現代の谷底標高だけでなく沖積層の厚さ・人工改変と古い侵食面を区別するための比較資料となる。ただし対象は本駒込周辺の指ヶ谷・小石川谷であり、**水窪川・弦巻川との更新世の接続や古流向を示したものではない**。  
出典：木村克己「[文京区本駒込周辺の地形を読み解く](https://fukadaken.or.jp/data_pdf/24_87.pdf)」（深田地質研究所年報24号、2023年）

### 小石川三丁目東遺跡：埋没谷の地層境界の具体例

谷端川下流の小石川谷に面する小石川三丁目26番3号の発掘調査では、北側の立川ローム・武蔵野礫層の台地と、南側のシルト・粘土・砂礫層を基盤とする低地との地層境界、谷の埋没過程で堆積した縄文時代以降の黒ボク土が記録されている。〔確認：発掘担当者の概要〕

## 派生問題：小日向台が「島状」だった可能性（未検証）

小日向台を、更新世のある時期に周囲の水系から切り離された**島状の台地**とみなせるかという問いがある。西側の音羽谷、南側の神田川、東側の茗荷谷・人参川などに加え、北側にお茶の水女子大学付近を通って谷端川へ至る旧河道が存在したと仮定すれば、周辺の谷が輪のようにつながる可能性を検討できる。〔地形的着想／未検証〕

ただし、**滝口（2019）の旧河道仮説が正しいことだけでは「島」を意味しない**。論文図6の例では弦巻川・水窪川が北側経由で谷端川へ注ぐ姿が示されているが、その同じ時期に現在の音羽谷を神田川へ南下する流れが存在したことは図示・立証されていない。東側の人参川の谷頭が北側の旧河道へ連続していたかも別途確認が要る。現代に残る複数の谷を、形成時期を無視して一つの時代へ重ねると、見かけの閉じた環を作ってしまう。また、谷がつながっていても、その全区間が同時期に流水を持っていたとは限らない。

検証点は、(1) 北側旧河道の位置と年代、(2) 音羽谷の南向き河道の成立年代、(3) 茗荷谷・人参川側の谷頭と北側旧河道との接続、(4) これらの水系が**同時代に連続していたか**、(5) もし囲まれるなら、小日向台のみか小石川台なども含むのか、である。現段階の評価は**条件付きの地形仮説であり、島だったという史実認定ではない**。

## 検証の方法論

流向の検証は [歴史地形・流路シミュレーション方針](../歴史地形・流路シミュレーション方針.md) に従う。要点は次の通り。

- 更新世については、現在の地表面ではなく、**ボーリング柱状図を観測値の中心とする埋没谷底面モデル**（同方針の Model C）を作る。産総研3D地質地盤図は広域補間・整合確認に使う。
- 既往論文が示す旧河道の流路は観測された河道位置そのものではなく、地形・地質から考察された旧河道像である。したがって**その流向をDEM・地質モデルへ最初から入力しない**（検証の循環を避ける）。
- 「更新世」を一枚の固定地形として扱わない。どの侵食面・どの谷埋め層の基底を旧河床面とみなすかを明示し、異なる時期の谷を混同しない。
- 凹地処理・流向計算は1通りに固定せず、不確実性を入力資料の段階からモデル化する。結果がほぼ一方向に集中すれば強い地形的支持となる。逆に、わずかな入力差で流向が頻繁に逆転するなら、結論は**「現在得られる史料精度では流向を決められない」**となり、それ自体を研究成果とする。

## 重要な注意

この問題では、次の三つを混同しない。

- **谷筋が地形的に連続しているか**
- **その谷を実際に水が流れていたか（いつの時代か）**
- **水がどちら向きに流れていたか**

また、「更新世の旧河道」と近世以降の河道・暗渠・下水道幹線は別の時代の対象であり、現在の谷底標高や現行の流路から更新世の流向を直接読み取らない。
