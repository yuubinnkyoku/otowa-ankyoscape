# 未解決問題

このリポジトリでは、既知の河川史を整理するだけでなく、**史料同士が食い違う点、まだ流路や年代を確定できない点を追うこと**を中心課題とする。

未解決問題は、川別の概要や横断テーマの中へ埋め込まず、原則としてここから独立文書へ分ける。

## 主要な未解決問題

### 水窪川と弦巻川は合流していたのか

- [水窪川と弦巻川の合流・接続問題](tsurumaki-mizukubo-confluence.md)

護国寺南西端以南で、弦巻川が水窪川へ合流した時期・地点があったのか、それとも音羽谷の東西を別々に南下していたのかを検討する。

### 音羽谷西側の弦巻川下流はいつ成立したのか

現時点では [横断テーマ](../cross-cutting-themes.md) と [弦巻川](../tsurumaki-gawa.md) に整理している。1681年前後の護国寺・音羽町造成時、水田開発・灌漑再編時、既存小水路の段階的拡張など複数案が残る。

### 更新世の旧河道はどちら向きに流れていたのか

深田地質研究所の2019年論文が示す弦巻川・水窪川側と谷端川側の谷の接続可能性について、谷筋の連続と流向を分けて検証する必要がある。現時点では [横断テーマ](../cross-cutting-themes.md) と [歴史地形・流向シミュレーション計画](../historical-terrain-and-flow-simulation-plan.md) に整理している。

### 千川上水から弦巻川・水窪川へ直接分水したのか

千川上水から谷端川への分水は確認できるが、弦巻川・水窪川への直接分水は未確認。取水口・樋・分水路・管理文書などの具体的証拠が必要である。

## 方針

未解決問題の文書では、できるだけ次を分けて記録する。

- **確認できる事実**
- **地図・写真からの観察**
- **候補となる説明**
- **各候補を弱める反証・留保**
- **決着に必要な一次史料や測量資料**

新しい資料によって一つの問題が解けた場合も、文書を消すのではなく、どの史料によってどの仮説が棄却・支持されたかを残す。
