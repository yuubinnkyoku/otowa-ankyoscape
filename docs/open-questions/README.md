# 未解決問題

このリポジトリでは、既知の河川史を整理するだけでなく、**史料同士が食い違う点、まだ流路や年代を確定できない点を追うこと**を中心課題とする。

未解決問題は、川別の概要や横断テーマの中へ埋め込まず、原則としてここから独立文書へ分ける。主要書誌は [出典一覧](../出典一覧.md) を参照。

## 主要な未解決問題

### 水窪川と弦巻川は合流していたのか

- [水窪川と弦巻川の合流・接続問題](水窪川と弦巻川の合流・接続問題.md)

護国寺南西端以南で、弦巻川が水窪川へ合流した時期・地点があったのか、それとも音羽谷の東西を別々に南下していたのかを検討する。

中心史料は、1682年・1687年の江戸図、1772年『武蔵国豊島郡雑司谷村絵図』、1851年近吾堂板、1941年『「郷土の観察」の指導体系』、1878年『東京府村誌』雑司ヶ谷村条の二次転記など。各資料のURLと証拠強度は専用文書に記載する。

### 音羽谷西側の弦巻川下流はいつ成立したのか

- [音羽谷西側の弦巻川下流の成立年代](音羽谷西側の弦巻川下流の成立年代.md)

1681年の護国寺創建時、1696～1697年の門前・寺域再編時、その後の水田開発・灌漑再編時など複数案を検討する。『御府内備考』、1697年からの『護国寺日記』、幕府の沿革図、1772年絵図、1851年切絵図、1878年『東京府村誌』などを年代順に追い、**西側河道を初めて連続して確認できる時点**を絞る。

### 更新世の旧河道はどちら向きに流れていたのか

滝口志郎「武蔵野台地の地形に関する諸問題」（2019）は、弦巻川の流路がかつて谷端川側へつながっていた可能性を提示する。ただし、谷筋の連続と具体的な流向は分けて検証する必要がある。  
出典：[深田地質研究所](https://fukadaken.or.jp/?page_id=6569) / [国立国会図書館](https://dl.ndl.go.jp/pid/14529520)

現時点では [横断テーマ](../横断テーマ.md) と [歴史地形・流路シミュレーション方針](../歴史地形・流路シミュレーション方針.md) に整理している。

### 千川上水から弦巻川・水窪川へ直接分水したのか

千川上水から谷端川への分水は確認できる。練馬わがまち資料館は「長崎村外三村分水」が粟島神社の池を水源とする谷端川へつながったことを説明する。  
出典：[練馬わがまち資料館「千川上水の分水を訪ねて（2）」](https://www.nerima-archives.jp/column/3572/)

一方、弦巻川・水窪川への直接分水は未確認で、取水口・樋・分水路・管理文書などの具体的証拠が必要である。一次資料候補として [練馬区「千川家文書」](https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/rekishibunkazai/bunkazai/b0904.html) がある。

## 方針

未解決問題の文書では、できるだけ次を分けて記録する。

- **確認できる事実**
- **地図・写真からの観察**
- **候補となる説明**
- **各候補を弱める反証・留保**
- **決着に必要な一次史料や測量資料**
- **使用した史料の書名・年代・公開元・URL**

新しい資料によって一つの問題が解けた場合も、文書を消すのではなく、どの史料によってどの仮説が棄却・支持されたかを残す。
