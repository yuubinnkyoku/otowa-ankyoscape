# 谷端川1956年暗渠工事の「区公報」原典確認

## 問題

豊島区の公式デジタル年表「昭和 としま」には、昭和31年3月（1956年3月）として次の工事完成が掲載されている。

- 谷端川支流：千早町2-1から長崎2-6まで、全長310m
- 要町1-5から1-15まで、約125m

年表上の出典表示は **「区公報」** である。

確認ページ：
https://adeac.jp/toshima-history/timeline/tm000008_1?key=%E6%98%AD%E5%92%8C31%EF%BD%9E40%E5%B9%B4

## 現在確認できていること

【確認】豊島区公式ADEACの年表本文には、1956年3月の「谷端川暗渠工事完成」と、上記2区間・延長が明記されている。

【確認】同じ行には根拠資料として「区公報」と表示される。

【保留】どの号・何月何日発行・何ページの区公報を参照したのかは、現在の年表画面だけでは特定できていない。

【保留】『豊島区史 年表編』（豊島区、1982年）という後年の年表資料の存在と刊行年は確認できるが、この1956年の工事項目が同書の該当ページに掲載されていることを原画像で直接確認していない。したがって、同書の1982年をこの工事項目の `source.year` として代入しない。

## 知識グラフ上の扱い

この工事に対応する4つの `flows_through` claim は、出来事の historical time として1956年を保持する。一方、Hakken型の discovery/evidence timeline には、**実際に確認した資料側の年代**が必要である。

現時点では `TOSHIMA_YABATA_TIMELINE` の `year` を推測で埋めない。そのため、次の4 base triplesは research queue の「source year 不明」へ残す。

```text
1956年千早町〜長崎区間 — flows_through → 千早町2-1
1956年千早町〜長崎区間 — flows_through → 長崎2-6
1956年要町区間       — flows_through → 要町1-5
1956年要町区間       — flows_through → 要町1-15
```

これは欠損ではあるが、未来情報漏洩を避けるための意図的な保留である。

## 次に探す原典

最優先は、1956年3月の工事完成を報じた**当時の豊島区の区公報**である。年表の表記から、少なくとも次を検索語・照会情報として使える。

```text
谷端川暗渠工事
谷端川支流
千早町2-1
長崎2-6
要町1-5
要町1-15
310メートル
125メートル
昭和31年3月
```

3月中の工事完成であるため、1956年3月号だけでなく、完成後の1956年4月前後の公報も確認対象にする。ただし発行号を推定で確定しない。

原典が見つかった場合は、

1. 公報の正式名称
2. 号数
3. 発行年月日
4. 該当ページ
5. 工事件名
6. 区間・延長の原文

を記録し、`TOSHIMA_YABATA_TIMELINE` から原典 source を分離する。原典を直接確認できた場合だけ `primary_source_checked=true` とする。

## 研究上の意味

この4辺は historical time がすでに1956年で揃っているため、原典確認によって史実の年代が増えるわけではない。しかし discovery/evidence timeline では、現在唯一残っている source-year blocked 群である。

したがって原典確認に成功すると、単に4件増えるだけでなく、**現在の research queue の source-year 欠損をゼロにできる可能性がある**。その後は source year の穴埋めより、同じ河川・地点を異なる年代の一次史料で再観測する作業へ重点を移せる。
