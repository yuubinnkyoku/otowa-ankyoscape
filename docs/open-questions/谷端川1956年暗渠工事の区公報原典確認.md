# 谷端川1956年暗渠工事の「区公報」原典確認

**状態：解決（2026-09-10）**

このファイルは探索経緯の監査記録として `open-questions` 配下に残す。

## 問題

豊島区の公式デジタル年表「昭和 としま」には、昭和31年3月（1956年3月）として次の工事完成が掲載されている。

- 谷端川支流：千早町2-1から長崎2-6まで、全長310m
- 要町1-5から1-15まで、約125m

年表上の出典表示は **「区公報」** だった。

年表：
https://adeac.jp/toshima-history/timeline/tm000008_1?key=%E6%98%AD%E5%92%8C31%EF%BD%9E40%E5%B9%B4

## 原典を確認

【一次史料確認】豊島区が公開している「広報としまライブラリー」には昭和31年度以前の旧公報PDFも収録されており、昭和31年4月15日発行の **『豊島区政公報』第78号** を確認した。

原典PDF：
https://toshima.rlibrary.jp/archive/19560415_0078/pdf/19560415_0078.pdf

第78号1頁の見出しは **「谷端川暗渠工事完成」**。写真付きの記事で、年表と同じ二つの工事区間を確認できる。

- 千早町2-1から長崎2-6に至る総延長310m
- 要町1-5から15番地に至る地域約125m

記事は3月に工事が完成したことを報じており、年表の「昭和31年3月」と整合する。したがって、年表が示す「区公報」の原資料に相当すると判断できる。

## 知識グラフ上の処理

原典を `S43` として分離した。

```text
S43
title: 豊島区『豊島区政公報』第78号「谷端川暗渠工事完成」
year: 1956
year_kind: issue
source_class: primary
primary_source_checked: true
```

既存の `TOSHIMA_YABATA_TIMELINE` claim を書き換えるのではなく、`S43` だけを根拠にする独立 claim を6件追加した。これにより、二次的な区史年表による確認と当時の一次史料による確認を別々の証拠として保持する。

対象は、

```text
1956年千早町〜長崎区間 — flows_through → 千早町2-1
1956年千早町〜長崎区間 — flows_through → 長崎2-6
1956年千早町〜長崎区間 — culverted → 1956年暗渠工事
1956年要町区間       — flows_through → 要町1-5
1956年要町区間       — flows_through → 要町1-15
1956年要町区間       — culverted → 1956年暗渠工事
```

である。

historical time と source/evidence time はどちらも1956年になるが、今回は「後世の資料が1956年を記述している」のではなく、**1956年4月15日発行の同時代公報を直接確認した結果**なので、discovery/evidence time に1956年を入れてよい。

## 探索で分かったこと

豊島区の「広報としまライブラリー」は、少なくとも昭和23年度以降の旧広報・区政公報を年度・号ごとにPDF公開している。昭和30年度末には、

```text
第75号  1956-01-01
第76号  1956-02-10
第77号  1956-03-20
```

があり、昭和31年度最初の

```text
第78号  1956-04-15
```

で谷端川暗渠工事完成が大きく掲載されていた。

「3月完成」という年表の日付だけを見て3月号に限定せず、完成後の4月号まで確認したことが原典発見につながった。

## 研究上の意味

この確認により、従来 source-year 不明だった1956年の `flows_through` 4 base triples は discovery/evidence timeline に入れられるようになった。

残る source-year blocked は、この4件ではなく、別件の **1895年谷端川水車設立願 (`S34`)** が中心になる。`S34` では1895年が年表の出来事年であって source 自体の年代ではないことが判明しているため、そこは引き続き原史料または年表自体の資料年代を探す。

次の優先課題は source year の穴埋めだけではなく、同じ河川・橋・地点を異なる年代の一次史料で再観測し、THiGER が評価可能な時系列密度を増やすことである。
