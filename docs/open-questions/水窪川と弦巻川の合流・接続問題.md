# 未解決問題：水窪川と弦巻川は合流していたのか

水窪川と弦巻川は、近代の実測図では音羽谷の東西を並ぶ二流として追うことができる。しかし、それ以前も常に二流だったのか、護国寺付近または音羽谷の途中で合流する時期があったのかは確定していない。

この問題は、単に「合流点を探す」だけでは済まない。**時代によって接続関係そのものが変化した可能性**があるためである。

主要出典は各節に直接示す。共通の書誌情報は [出典一覧](../出典一覧.md) を参照。

## 問い

現在の中心的な問いは次の三つである。

1. 雑司ヶ谷から来た弦巻川は、護国寺南西端より下流で水窪川へ合流していた時期があるのか。
2. 合流していたなら、その地点と時期はどこまで絞れるか。
3. 音羽谷の東西二流は、自然河道の分岐なのか、近世の造成・灌漑・排水による再編なのか。

## 現在考えられる三つの型

```mermaid
flowchart TB
    subgraph A[案A：東西二流のまま南下]
      A1[弦巻川] --> A3[神田川方面]
      A2[水窪川] --> A4[神田川方面]
    end

    subgraph B[案B：弦巻川が水窪川へ合流]
      B1[弦巻川] --> B3((合流点))
      B2[水窪川] --> B3
      B3 --> B4[下流]
    end

    subgraph C[案C：時代によって接続が変化]
      C1[近世初期] --> C2[一流または接続あり]
      C2 --> C3[造成・灌漑・河道整理]
      C3 --> C4[東西二流]
    end
```

案Cを考える一つの理由が、1941年の教育資料に現れる「一流→二流」説である。ただし、これは近世の工事記録ではない。

## 1941年資料：「一流を二流に分けた」説の出典

東京女子高等師範学校附属国民学校児童教育研究会 編『「郷土の観察」の指導体系』（1941年）には、音羽谷の川について、**もとは一流で、水田開発時に灌漑のため二流に分けられたのではないか**という趣旨の地理的推測がある。〔史料中の推測〕  
出典：『「郷土の観察」の指導体系』皇国青年教育協会、1941年、国民学校教育研究書 第3輯。[国立国会図書館デジタルコレクション PID 1275204](https://dl.ndl.go.jp/pid/1275204)、[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000002-I000000645614) / [BOOK-002](../sources/books/BOOK-002.md)(../出典一覧.md)

この資料が示すのは、**1941年時点でそのような地理的説明が提示されていたこと**であり、近世に実際に行われた工事の年代・地点・施工主体を直接証明するものではない。

## 1682年・1687年：水窪川は見えるが弦巻川は不明瞭

護国寺創建翌年の天和2年（1682）『増補江戸大絵図 絵入』と、貞享4年（1687）『ゑ入江戸大繪圖』では、本調査の観察として水窪川とみられる水路を確認できる一方、弦巻川は確認できない。〔観察〕

- 1682年『増補江戸大絵図 絵入』：[国立国会図書館デジタルコレクション](https://dl.ndl.go.jp/pid/1286182) / [MAP-001](../sources/maps/MAP-001.md)(../出典一覧.md)
- 1687年『ゑ入江戸大繪圖』：[国立国会図書館デジタルコレクション](https://dl.ndl.go.jp/pid/2542450) / [MAP-002](../sources/maps/MAP-002.md)(../出典一覧.md)

これは「当時は水窪川一流だった」案と整合するようにも見える。しかし、両図は江戸全体を描く広域図であり、小河川が省略される可能性がある。**弦巻川が描かれていないことだけでは不存在を証明できない。**

## 1772年：本流・護国寺裏門側支流・橋をオンライン複製で直接確認

明和9年（1772）『武蔵国豊島郡雑司谷村絵図』が現存し、豊島区立郷土資料館編『豊島区地域地図 第5集（近世・村絵図I編）』に複製・読みおこし参考図が収録されている。〔史料所在確認〕

- 豊島区公式：[「豊島区地域地図集（複製）」](https://www.city.toshima.lg.jp/129/bunka/bunka/shiryokan/kankobutu/005951.html)
- 国立国会図書館：[『豊島区地域地図 第5集』書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000009123633)
- 東京都建設局も同絵図の読みおこし参考図を資料に使用：[雑司ケ谷霊園関連資料](https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/000050293)
- 本調査で直接確認したオンライン複製：[画像掲載元](https://zoushigaya.seesaa.net/article/189594335.html)
- 出典整理：[MAP-003](../sources/maps/MAP-003.md)(../出典一覧.md)・[GOV-011](../sources/gov/GOV-011.md)(../出典一覧.md)

2026年9月、本調査でオンライン複製画像を直接確認した。少なくとも、**本浄寺南側付近で丸池方面から来る弦巻川本流とみられる水路に、護国寺裏門方向から来る別水路が接続する描写**、護国寺裏門側の水路が絵図内部で丸く膨らんだ上流端を持つこと、道路横断部に橋らしい梯子状記号があることを確認している。〔画像観察〕2026-10-26 の再確認では、その丸く膨らんだ上流端は「護国寺裏門」の記しの少し南に位置する。

護国寺裏門側の丸い終端は、同図の丸池の表現との類似から、小池・湧水・水源となる溜まりを示した可能性がある。ただし凡例で確定したわけではない。また接続後の水路の見かけの方位をそのまま実際の流向とはみなさない。村絵図は実測図ではないため、現在地への位置比定、方位、流向は原図・読みおこし参考図・後世地図で引き続き照合する。

## 1829年：『御府内備考』では東西二流を区別（原文確認済み）

文政12年（1829）成立の『御府内備考』巻之五十「護国寺領三ヶ町」には東青柳町・西青柳町が収録されることを東京都公文書館の目録で確認できる。〔史料所在確認〕

現在確認している二次転記では、**東青柳町の東寄りを北から南へ流れる細流**について、幅九尺、古来の川名は不明、水上は「巣鴨村雑司ヶ谷村之内田場際」、流末は「鼠ヶ谷下水」とされる。一方、**西青柳町側の細流は「里俗弦巻川」**とされ、こちらも流末では鼠ヶ谷下水と称したという。〔本文は二次転記〕

原文確認（NDL刊本・AI読取）：大日本地誌大系 第3巻（NDLJP:1214872、雄山閣・昭和6、巻之四十七〜七十四所収）の画像で、巻之五十の東青柳町川項目（コマ20）・西青柳町川項目（コマ21）を確認した。東青柳町は幅九尺・水上は巣鴨村雜司ケ谷村之內田場際・流末は鼠ケ谷下水、西青柳町は里俗弦卷川・水上は雜司ケ谷村之內丸池で同村田畑際より當町え入・流末は鼠ケ谷下水であり、二次転記の内容と一致する。原文の字形は「鼠ケ谷下水」「弦卷川」である。なお「東西鼠谷下水」は青柳町節ではなく、コマ25の榎木町節・埋樋項目に「東西鼠谷下水落口」として現れる。東京都公文書館写本（巻之四十八〜五十二）との異同は未確認。〔原文確認：AI〕出典：[GAZ-013](../sources/gazetteers/GAZ-013.md)

この転記が原文どおりなら、少なくとも江戸後期の同じ史料体系の中で、音羽門前の東西に別々の細流が認識され、西側には弦巻川という里俗名が明記されていたことになる。これは「江戸後期まで護国寺で必ず一流に合流していた」とする単純な復元を弱める材料になる一方、**両者が下流のどこかで接続した可能性まで否定するものではない**。

幅・水上・流末・「里俗弦巻川」の文言はNDL刊本画像で確認済み（AI読取。写本との異同は未確認）。  
出典：東京都公文書館 [『御府内備考 巻之四十八～五十二』](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_01&pkey=000101055) / 国立国会図書館 [『大日本地誌大系 第3巻 御府内備考』](https://ndlsearch.ndl.go.jp/books/R100000039-I1214872) / 本文二次転記：[「水窪川」](https://ameblo.jp/kazuaruki/entry-12940940845.html) / 原文確認（NDL刊本・AI読取）：[GAZ-013](../sources/gazetteers/GAZ-013.md)

## 1851年：護国寺南西端を越えて水路が続く

近吾堂板『音羽目白雑司ケ谷辺絵図』（嘉永4年・1851）は、東京都立図書館 TOKYOアーカイブで公開されている。〔一次史料〕  
原資料：[東京都立図書館 TOKYOアーカイブ](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000013-00042337)、[CiNii Books](https://ci.nii.ac.jp/ncid/BA59680420) / [MAP-005](../sources/maps/MAP-005.md)(../出典一覧.md)

本調査では、西側から来た弦巻川とみられる青線が護国寺南西端へ達し、道路との交差部を越えて寺域外へ短く続くように読み取っている。〔観察〕

この観察は、

> 弦巻川は護国寺境内で終わり、そこで水窪川へ合流していた

という単純な読みを弱める。

ただし、その短い線の先が

- 音羽谷西側をそのまま南下するのか
- 少し下流で東へ寄り水窪川へ合流するのか

までは、この切絵図だけでは決められない。

また、1857年改の尾張屋板では細い水路の表現が近吾堂板と異なる。版による描写差があるため、**地図に描かれないことと水路の不存在を同一視しない。**  
比較資料：[1857年『嘉永新鐫雑司ケ谷音羽絵図』](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000013-00042340) / [MAP-006](../sources/maps/MAP-006.md)(../出典一覧.md)

## 1878年：『東京府村誌』の「西青柳町ニ通ス」

地域史調査による1878年『東京府村誌』雑司ヶ谷村条の転記では、弦巻川について**「丸池ヨリ出テ一条ノ流と為リ、本村ノ中央ヲ東流シ西青柳町ニ通ス」**とされる。〔二次転記による確認〕  
転記：[「雑司ヶ谷村用水」](https://ameblo.jp/kazuaruki/entry-12940940738.html) / [GAZ-001](../sources/gazetteers/GAZ-001.md)(../出典一覧.md)

『皇国地誌稿本東京府誌』の復刻版は、東京都公文書館所蔵の「東京府村誌」全15冊を影印したものとされる。  
書誌：[CiNii Books「皇国地誌稿本東京府誌」](https://ci.nii.ac.jp/ncid/BB30888890)

西青柳町は現在の文京区音羽二丁目付近にあたる。この転記を根拠として採用すれば、少なくとも1878年には

```mermaid
flowchart LR
    A[丸池] --> B[弦巻川]
    B --> C[雑司ヶ谷]
    C --> D[護国寺南西側]
    D --> E[西青柳町]
```

という連続が当時の村誌で認識されていたことを示す強い史料になる。

その場合、**護国寺で直ちに水窪川へ合流した**という案はかなり弱くなる。ただし、「西青柳町へ通じる」ことと、「そこから神田川まで水窪川と一度も接続せず独立して流れた」ことは同義ではない。

> [!NOTE]
> 「西青柳町ニ通ス」は [GAZ-001](../sources/gazetteers/GAZ-001.md) の二次転記に基づく引用であり、『東京府村誌』原画像の該当箇所は未確認である。2026-10-26 の方針として、転記元を明示した孫引きを本文引用の根拠として採用する。原文との照合は将来の課題として残す。

## 1880–1886年：迅速測図原図では東西二流が分かれる

[MAP-025](../sources/maps/MAP-025.md)（第一軍管地方2万分1迅速測図原図、フランス式彩色図、1880–1886年測量）を東京時層地図で確認したところ、水窪川・弦巻川・谷端川はいずれも描かれ、人参川は描かれていない。〔2026-10-26 直接確認〕

水窪川と弦巻川は接続せず、二流に分かれて描かれている。したがって、少なくとも1880年代の測量時点では「東西二流のまま南下する」形が実測図の上で成立していた。

付随する観察：

- 丸池そのものの描出はないが、弦巻川の青線が途切れる位置は西池袋公園（丸池跡）にあたる。1878年村誌の「丸池ヨリ出テ」という記述と矛盾しない位置関係である。
- 弦巻川の下流の線は神田上水（神田川）まで届いているように見える（断定はしない）。
- 水窪川の青線の始点は 35.726176, 139.720294（現在の豊島区東池袋4丁目付近、東京時層地図上の読み取り）。

## 現時点の評価

| 仮説 | 現在の評価 | 主な根拠・留保 |
| --- | --- | --- |
| 近世を通じて東西二流だった | 可能性あり | 1851年近吾堂板以降と整合し、1880–1886年迅速測図原図でも二流に分かれて描かれる。ただし1682・1687年図では弦巻川を確認できない |
| 弦巻川は護国寺で水窪川へ合流していた | 単純な形では弱くなった | 1851年近吾堂板で護国寺南西端より先へ青線が続くという本調査の観察 |
| もう少し下流で合流していた時期がある | 未解決 | 1851年図の先を同時代史料で連続追跡できていない |
| 元は一流で、後に灌漑のため二流化した | 検討価値あり | 1941年資料 [BOOK-002](../sources/books/BOOK-002.md)(../出典一覧.md) に同趣旨の推測。ただし近世の工事記録ではない |
| 時代ごとに接続関係が変化した | 有力な検討枠組み | 造成・水田開発・河道整理を考えると固定的な二択では説明しきれない可能性 |

## 決着に必要な資料

1. **1772年『武蔵国豊島郡雑司谷村絵図』高精細画像**  
   弦巻川の護国寺方向の末端を直接確認する。（オンライン複製が高画質であり、2026-10-26 に複製レベルで確認済みとした。護国寺裏門側支流の上流端は「護国寺裏門」の記しの少し南。）
2. **1878年『東京府村誌』雑司ヶ谷村条の原画像**  
   「西青柳町ニ通ス」という二次転記を原文で確認する。（2026-10-26 に転記の孫引き採用を決めたため、決着の必須条件ではなく将来の照合課題に移した。）
3. **『御府内備考』の西青柳町・音羽町・雑司ヶ谷関係巻**  
   川、下水、悪水、橋、用水の記述を連続して読む。
4. **1851年前後の別系統の切絵図・村絵図**  
   護国寺南西端から西青柳町・音羽町下流までを追う。
5. **明治初期の実測図・地籍図**  
   東西二流が確実に成立した最古年代を、図名・図歴まで含めて固定する。
6. **近世・明治初期の水田開発、用水、悪水路工事記録**  
   「一流を二流に分けた」という1941年説を工事記録から検証する。

## 重要な注意

この問題では、次の三つを混同しない。

- **地図に描かれているか**
- **実際に水路が存在したか**
- **その水路を当時「弦巻川」「水窪川」と認識していたか**

また、「ある時点で合流していた」ことが確認できても、それが全時代に当てはまるとは限らない。

このため、最終的には一つの合流点を探すよりも、**年代ごとの水路接続図を作ること**がこの問題の解決に近い。
