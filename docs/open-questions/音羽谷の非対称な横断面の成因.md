# 未解決問題：音羽谷の非対称な横断面はなぜ生じたのか

作成：2026-10-19。**仮説整理であり、成因の確定ではない。**

## 問題の所在

利用者提示の音羽谷の模式的横断図では、西側（目白台側と想定）が幅広く緩やかに谷底へ降り、東側（小日向台側と想定）は短距離で急に降りる。**元図に標高・水平縮尺・測線座標・方位がないため、この左右の対応は仮置き**。小日向台が「削られなかった」とは限らず、谷壁が急ということは谷底付近で強く侵食・削剥された可能性もある。

文京区は音羽谷を武蔵野台地に刻まれた谷の一つと説明する。音羽地区について区は「目白台・関口台の台地から神田川沿い、そして音羽通りへと続くなだらかな傾斜地が大半」と説明し、小日向側の鼠坂は急な階段付き坂として紹介している。ただし、これらの説明自体は全測線の横断面解析ではない。

- [文京区「文京区の位置と地形」](https://www.city.bunkyo.lg.jp/b005/p005241.html)
- [文京区「音羽地域活動センター：音羽地区の地勢」](https://www.city.bunkyo.lg.jp/b011/p006660/index.html)
- [文京区「鼠坂」](https://www.city.bunkyo.lg.jp/b014/p004021.html)

## 主な説明候補（いずれも未検証）

1. **主流の東側への偏り・長期的な谷底移動**：合流期の主要な流れが小日向側の斜面脚部を浸食し、目白台側では旧谷底・斜面堆積物が残った可能性。ただし、現在の非対称性だけでは流路の偏りや向きを復元できない。蛇行部の外岸・内岸を、長い谷全体へ機械的に当てはめない。
2. **斜面崩壊・表面侵食・支谷・堆積の差**：目白台側では斜面が幅広く後退した、支谷からの土砂供給があった、谷底縁に堆積地形が残ったなどの可能性。緩斜面は「浸食が弱かった」証拠ではない。
3. **地質・地下水条件の差**：崩れやすい砂質層と関東ロームなどの層構成・地下水の湧出高さの差。東京都のボーリング柱状図と産総研の東京都区部地質地盤図で同一測線の東西を照合する必要。
4. **霜柱・気候条件による斜面後退**：関東の非対称谷で議論されてきた一般的な機構。玉川上水のほぼ東西走向の水路では日当たりに起因する非対称法面が実測研究されているが、**音羽谷は概ね南北方向であり、同じ日向・日陰の説明をそのまま適用できない**。
5. **宅地・道・寺社の切土・盛土**：近世・近代以降の改変は現断面を変えるが、武蔵野台地を刻む音羽谷全体の形成と同一視できない。

非対称谷の成因一般：[『最新 地学事典』「非対称谷」](https://kotobank.jp/word/%E9%9D%9E%E5%AF%BE%E7%A7%B0%E8%B0%B7-1399011)。
関東ロームと霜柱による斜面後退：[佐藤ほか（2003）「東京都玉川上水の水路法面崩落と樹木管理に関する研究」](https://www.jstage.jst.go.jp/article/ceispapers/ceis17/0/ceis17_0_13/_article/-char/ja/)；[関連研究資料](https://www.ai-shokubutsu.co.jp/files/pages/report_02/tamagawa.pdf)。

## 流路成立問題との区別

**音羽谷の開析・非対称な谷壁の形成**と、**護国寺創建（1681年前後）に音羽谷西縁の弦巻川下流が成立・整備されたか**は時間尺度の異なる別の問題。後者が真であっても、江戸時代の河道工事が前者の急崖を造ったとはいえない。創建期の川筋は引き続き未解決。関連：[音羽谷西側の弦巻川下流の成立年代](音羽谷西側の弦巻川下流の成立年代.md)。

## 検証手順

1. 横断図の**測線位置・方位・横縦の縮尺・現在標高**を固定。護国寺南、音羽中流、江戸川橋北など、数本の東西横断線を並べ、非対称が谷全体に持続するか確認する。
2. 1880年代実測図、1909年地形図、1920年代三千分一図と現代DEMを比較。**古地形に見える部分と造成で変わった部分を分ける。**
3. 緩斜面に段丘様の平坦面や堆積層があるか、目白台側から音羽谷へ入る支谷・谷頭がどう配置されるかを調べる。
4. 東西両岸のボーリングの層界標高（ローム、砂層、谷埋め層）および湧水層を対応付ける。
5. 形成史を弦巻川・水窪川の旧流路仮説と比較する。ただし**横断面の非対称性のみから、1681年の合流地点や河道の付け替えを立証しない。**

現時点の暫定評価は、**東側谷壁脚部の侵食と西側斜面の長期的な後退・堆積の組合せは考えられるが、測線・地質観測なしに優劣を決められない**、というもの。

## 2026-10-19 追調査：護国寺創建前から谷底・河道が小日向台側へ偏っていたか

### 結論と確実度

- **近世以前から音羽谷に谷地形・耕地が存在したこと**：強く示唆。護国寺の1681年造営だけで谷全体や東側急崖を形成したとは考えにくい。
- **護国寺創建前から小日向側へ下る斜面・坂道があったこと**：1672年刊『新板江戸外絵図』に、現在の鼠坂・八幡坂と対応するとされる坂道が見えるという既存の読図研究がある。**今回、原図の該当地点を直接トレースして検証してはいない**ため、坂の比定は二次資料の報告。
- **当時の自然谷底・主河道が現代と同様に小日向台側へ偏在していたこと**：未証明。1672年絵図に坂が描かれることは近世前の崖・段差の証拠となるが、川筋や東西標高断面の定量証拠ではない。
- **水窪川が主流で弦巻川がそこへ合流／逆に弦巻川が主流だったこと**：いずれも未判定。流量・集水面積・旧谷底の連続性の確認が必要。

### 1643年頃：『寛永江戸全図』

臼杵市歴史資料館の所蔵解説によれば、1642～1643年頃の屋敷地調査の内容を反映した絵図の写し（写本製作年と情報年代は別）。之潮の復刻版への編集関係者の談話を引用した2014年ブログでは、護国寺予定地は「御薬種畑」、音羽谷は神田川に下る水田地帯だったと解説。**水田と水流二分の叙述は、今回原図画像から直接検証したものではない。川筋が谷の東西どちらにあったかは不明。**

### 1672年：創建前の小日向・高田を含む絵図

対象原図『新板江戸外絵図 小日向、牛込、四ツ谷』（寛文12年=1672年。NDL目録の同名図群は1671–1674年刊）。都立図書館では1672年と明記。小日向側の鼠坂・八幡坂の古道がこの図に確認できると現地地誌研究が報告。**坂の存在は小日向側の谷壁が江戸中期の参道造成で初めてできたものではない可能性を強める**。ただし高低差や崖の勾配、河道偏在の証明にはならない。

### 発掘：護国寺境内に埋没谷の存在

文京区教育委員会等『東京都文京区 大塚坂下町遺跡』（2012年、B-125）の文化財要約では、護国寺境内の近世遺構・盛土に加え、「旧地形として、埋没谷が調査区北側を東西方向に走るように検出された」と記載される。**古地形が造成土の下に残る重要証拠**。ただし谷の埋積年代・標高・音羽谷本流への接続・流向はこの要約からは不明。なお「東西に走る埋没谷」＝「南北に延びる音羽谷本流の東側偏在」ではない。

- [CiNii 2012大塚坂下町遺跡](https://cir.nii.ac.jp/crid/2120307889445994368)
- [全国文化財総覧 DOI 10.24484/sitereports.47157](https://sitereports.nabunken.go.jp/47157)

また『東京都文京区 音羽二丁目遺跡』（警視庁大塚警察署改築、2012年、B-126）の要約は、江戸初めまで関口村耕地で、護国寺創建に伴う門前町化、19世紀前半～中頃の整地を記録する。**整地年代は1681年の河川移設とは別**。

- [CiNii 音羽二丁目遺跡](https://cir.nii.ac.jp/crid/2120589364412597760)

### 史料の立場が異なる点

本田創（2021）は、1681年護国寺造営に際し、水窪川・弦巻川を谷両端の崖下へ整備したと説明するが、近世の施工記録自体を提示したものではない。他方、山岡光治「地図豆」散歩資料は弦巻川を本流・水窪川を支流と表記し、切絵図から両流がかつて合流していたと復元する。**両者は後世の解釈で、今回の問い（1681年より前の主河道位置）を直接証明しない**。

- [本田創 2021](https://bunshun.jp/articles/-/50033?page=4)
- [地図豆 ぐるっと護国寺](https://www.ripro.co.jp/yamaoka/mapsuv200/meguri/14-1chizusanpo2.pdf)

### 決着への最短経路

1. 1672年『新板江戸外絵図』の**小日向・鼠坂・八幡坂・護国寺予定地**を同一図上で拡大読図。1660年代以前の道路、水田、水路、凹地表現を把握し、図式上の水路省略とも区別する。
2. 『寛永江戸全図』の「御薬種畑」付近を原図または之潮復刻版で読図し、**水田帯の東西幅、道路、水路**を確認する。図式が地形・流路の細部を保証するか検討。
3. 大塚坂下町遺跡の報告書本体から埋没谷の位置・幅・地層・標高・堆積時代を取得し、断面と照合。
4. 音羽上中下流の東西複数測線で、1909年以前の崖線・等高線および地質境界から**造成前の谷底の最深位置**を推定。現在の水窪川位置をそのまま自然旧河道として入力しない。

**暫定判断：非対称の大枠が1681年以前からあった可能性は高いが、谷底・川筋が小日向台の崖際を南下していたかは未証明。**
