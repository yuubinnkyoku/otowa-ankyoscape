## どの地図を見るべきか

リポジトリの地図一覧にある資料なら、特に次の3つが重要そう。

| 地図 | 確認したいこと |
|---|---|
| 1883年『五千分一東京図測量原図』 | 茗荷谷から金剛寺坂下までの細い水路 |
| 1909年『東京近傍1万分1地形図』 | 谷底に連続した河道があるか |
| 1912年『東京市及接続郡部地籍地図』 | 道路とは別に水路用地が存在するか |

これらについては、まだ人参川の推定流路と直接照合できていない。

現時点での判断はこう。

- **「人参川」という呼び名の存在：確実**
- **茗荷谷に水流で削られた谷があること：確実**
- **金剛寺坂下の人参川と茗荷谷上流の水路が同一だったこと：未確定**
- **歴史地図に人参川が描かれていること：未確認**

だから、さっきの「第四の川発見！」は少し早まった。

むしろ面白いのは、**名前は文章に残っているのに、川筋を示す地図上の証拠がまだ見つかっていない**こと。

今まで調べてきた水窪川・弦巻川・谷端川とは、ちょっと違う種類の問題かもしれない。

## 1. なぜ計算済みの座標を配信しないのか？

調べたところ、**そもそも計算結果をあらかじめ用意しているのではなく、利用者のブラウザで毎回計算している**らしい。

公式サイトには、表示範囲に応じた標高データを取得し、ブラウザ上で地形解析を実行すると明記されている。citeturn808669search2

考えられる理由は主に3つ。

- **計算範囲が変わる**：表示する地域によって計算対象が変化する。
- **計算条件が変わる**：標高データの解像度、窪地を埋める深さ、地形の平滑化などを変更できる。
- **配信量を抑えられる**：全国の詳細な流路を事前計算して保存するより、必要な場所だけ計算する設計にできる。

ただ、個人的には、**計算済みの流路をGeoJSONなどで出力できたら、暗渠調査にものすごく便利**だと思う。

### 実は、一部はダウンロードできる！

|---|---|

明治維新で武士が東京を離れると、大量の武家屋敷が空き地になった。東京府は1869年（明治2年）、その跡地に桑や茶を植えることを奨励する「桑茶政策」を始めた。

東京都公文書館によれば、これは荒廃した屋敷地の活用と産業振興を兼ねた政策だった。1880年代の地図にも、その痕跡が残っているという。<Cite refs={["turn333064search0","turn333064search6"]}/>

だから、この地図に並んでいる小さな「茶」「畑」は、**江戸時代の屋敷地が明治になって農地へ転用された痕跡**かもしれない。

しかも、さらに決定的な資料があった。

文京区が公表した景観に関する基礎調査では、小日向の街並みについて、**江戸時代末期の町割りを継承し、短冊状の街区や狭い道路が残っている**と説明している。<Cite ref="turn333064search47"/>

つまり、明治に一から設計したというより、江戸時代につくられた区画の骨格を引き継いでいた、と考える方が資料に合っている。

## 2. 地層の性質によっても変わる

筑附周辺で特に関係しそうなのが、関東ロームなどの台地を構成する地層。

防災科学技術研究所の解説によれば、自然に堆積した関東ロームは比較的強度がある一方、一度崩して練り返すと強度が大きく低下するという性質がある。<Cite ref="turn686338search1"/>

そのため、同じ地層でも、地下水の状態や風化の進み具合によって斜面の安定性が変わる。

| 条件 | できやすい地形 |
|---|---|
| 地層の強度が高い | 急斜面が維持されやすい |
| 風化や小規模崩壊が長く続く | 緩やかな斜面へ変化しやすい |
| 川が谷底を深く削る | 急な谷壁が生じやすい |
| 崩れた土砂が谷底に堆積する | 斜面下部が緩やかになりやすい |
| 地下水が斜面から湧き出す | 谷頭侵食や局所的な崩壊が進む場合がある |

東京都も、台地の崖下から湧き出す地下水が中小河川の水源になることを説明している。<Cite ref="turn686338search0"/>

## 3. 筑附の南側では、もう一つ別の事情がある

**「坂道」と「自然の斜面」は同じではない**んだよね。

人が坂道を造る場合、歩いたり車を通したりできるように、斜面を斜めに横切ったり、地面を削ったりする。

一方、宅地を平坦に造成すると、敷地の境界に急な擁壁ができる。

だから、もともとは一つの自然斜面だった場所が、人工的に「平地・崖・平地」という階段状の地形へ変わることもある。

さっきの筑附南側の写真にあった高い擁壁や細い階段は、この影響も疑う必要がある。

江戸の坂道や地誌を詳しく調べた「坂と歴史の町・小日向の坂道」では、次のように整理されている。<Cite ref="turn209671search0"/>

| 歴史的地名 | 小日向茗荷谷町 | 小日向清水谷町 |

## 4. 清水谷には本当に湧水があった

1735年（享保20年）の『続江戸砂子』には、清水谷でかつて清水が湧き出していたという記述がある。

特に具体的な例が、藤坂下の伝明寺にあった**観音水**。

東京都地質調査業協会の技術資料によると、伝明寺の観音水は地元で親しまれていたものの、春日通り沿いの工事で地下水の流路が変化し、1991年には完全に涸渇したとされる。<Cite ref="turn283366search4"/>

さらに、文京区の地域史関係資料には、清水谷周辺に昭和初期まで水の流れがあり、ホタルが飛んでいたという地域の証言も記録されている。<Cite ref="turn786492search11"/>

つまり清水谷は、単なる地名ではなく、実際に水が豊富だった谷だったと考えられる。

# 茗荷谷・人参川調査のまとめ
<text color="secondary" size="xs">2026年10月9日時点｜文献・古地図・現地観察</text>

## 1. 人参川という川の存在

人参川は、少なくとも大正時代には実際に使われていた呼び名だった。

永井荷風『<Entity category="book" value="日和下駄" disambig="1915年刊行の永井荷風の随筆"/>』（1915年）には、

> 小石川金剛寺坂下の下水を人参川と呼ぶ

と記されている。荷風はこれを「溝川」の一例として取り上げており、当時すでに排水路のような状態だったことがうかがえる。<Cite ref="turn180622search9"/>

一方、2016年の『日々の理科』第633号には、茗荷谷の地形を形成した神田川の支流として「古茗荷谷川」が登場する。

ただし、**人参川と古茗荷谷川が完全に同じ範囲を指したかは未確定**。また、上流側まで「人参川」と呼ばれていたかも分かっていない。

## 2. 茗荷谷と清水谷の地理的な関係

当初は春日通り付近が茗荷谷なのではないかと考えていたけれど、江戸時代の地誌を調べると、もっと南側の谷筋を指していたことが分かった。

| 地名 | 歴史的な位置の目安 |
|---|---|
| 茗荷谷 | 茗荷坂〜蛙坂・釈迦坂付近 |
| 清水谷 | 藤坂〜伝明寺付近 |

『御府内備考』には「茗荷谷」「清水谷」が別項目として記載されている。<Cite ref="turn932829search7"/>

江戸時代には区別されていたものの、坂道の説明では両名称が重なる例もあり、境界は厳密に決まっていなかった可能性がある。<Cite ref="turn932829search3"/>

そして人参川は、こうした谷筋の水を集めて、現在の丸ノ内線・小石川車両基地付近から神田川へ向かっていたと考えられている。<Cite ref="turn932829search1"/>

## 3. 人参川には二つの源頭があったらしい

2022年の暗渠調査「水の行方を追って」は、人参川の源頭を大きく二つに分けている。

これらのうち、特に重要だったのは次の三つ。

**明治初期の五千分一東京図測量原図**

1883〜1884年の測量原図は、等高線・建物・池などを詳細に記録している。<Cite ref="turn220495search0"/>

ここで人参川の西側源頭候補を追跡できた。ただし、地図上の細い線が水路記号なのかは再確認が必要。

**拓殖大学東門付近の湧水池**

明治初期の地図には、中央に小さな島のある池と、さらに南側の池が描かれていた。

地元の「茗荷谷界隈サイト」でも、このうち島のある池が現在の拓殖大学東門入口付近にあったと推定されている。<Cite ref="turn180622search3"/>

これは上流域の水環境を復元する有力な手掛かり。

**三方を崖や坂に囲まれた谷頭**

現地で確認した、周囲の高い土地から低地へ集まる地形は、源頭部の特徴とよく合っていた。地下から明瞭な流水音も聞こえた。

ただし、現在の水音は合流式下水道などに由来する可能性があり、昔の川そのものが残っている証拠ではない。

## 5. 小日向台の分水界について

色別標高図を25m、27m、29mの基準で見比べることで、筑附南方には複雑な高まりと浅い凹地が存在することが分かった。

現在考えているのは、**一つではなく、複数の分水界が存在する可能性**。

| 分水界の候補 | 現在の仮説 |
|---|---|
| 筑附から南へ延びる高まり | 水窪川側と人参川側の集水域を分ける可能性 |
| 小日向台内部の鞍部 | 北へ下る水は人参川側、南へ下る水は大日坂方面へ向かう可能性 |
| 久世山周辺 | 台地南斜面の水が神田川沿いの低地へ集まる可能性 |

とくに現地観察で、西東方向の地面が比較的高いのに対し、北にも南にも標高が下がる場所が存在したのは興味深い。

これは、**人参川と神田川へ直接向かう小さな集水域の境界**を考える手掛かりになりそう。

ただし、現在の造成された地形と、明治初期の自然地形は一致するとは限らない。

## 6. 還国寺の湧水と小日向台南斜面

南側にも重要な発見があった。

大日坂の下方にあたる還国寺付近には、明治初期の地図で複数の池が描かれている。

さらに、現在の還国寺にも湧水を引き込んだ池が存在するという紹介がある。

これについて考えられるのが、久世山などの台地上へ降った雨が地中へ浸透し、南側の斜面下で湧き出していたという仕組み。

もっとも、**還国寺の湧水が久世山のどの範囲から供給されているかは未確認**。地表の分水界と地下水の分水界が一致する保証もない。

産総研の三次元地質図や東京都のボーリング柱状図を利用して、砂礫層・粘土層・地下水位を調べることが次の課題になった。

## 7. 関連して分かった歴史的なこと

調査の途中、人参川の周辺史についても発見があった。

江戸時代の切支丹坂と現在の切支丹坂は位置が異なり、現在の庚申坂などもかつて切支丹坂と呼ばれていた。さらに切支丹屋敷へ向かう道には、水路を渡る「獄門橋」が存在したという記録がある。<Cite ref="turn180622search0"/>

また、小日向台町の格子状の町割りは、1850年代の尾張屋版の絵図にも描かれていた。明治初期の地図に見られる整然とした道路網は、江戸時代からの土地利用を引き継いでいたことが分かった。

そして鼠坂下付近の水窪川には、明治初期の地図で「江戸川橋」と読める橋名が描かれていた。現在の神田川に架かる江戸川橋との関係は、引き続き調べたい。

## 9. 今後、優先して確認したいこと

個人的には、次の三つが特に重要だと思う。

1. **動画主の水源候補と、明治初期の西側源頭候補の間を古地図で追う。** 道路の浅いくぼみが、自然の谷筋に由来するものか確かめたい。
2. **1883〜1884年の測量原図を現在の地形と重ねる。** 筑附南方の分水界候補、拓殖大学の細い路地、複数の池の位置を比較する。
3. **久世山から還国寺、人参川の源頭側まで地質断面を作る。** 湧水の高さと地層の境界が対応するか検証する。

今回の調査の成果は、**「人参川が存在したらしい」という話から、「どの谷を通って、どこに水が集まり、どこから湧いていたのか」を具体的な地点で検証できる段階に進んだこと**だと思う。
