# 2026-08-31 追加資料：水久保地名と明治初期の弦巻川

既存の `README.md`、`docs/chat-findings-2026-08-31.md`、`docs/source-review-addendum-2026-08-31.md` を確認したところ、最近の調査内容の大部分はすでに反映されていた。

一方、次の資料はまだ十分に組み込まれていない。特に **1878年『東京府村誌』の雑司ヶ谷村条** は、音羽通り西側の弦巻川がいつ成立したかを考えるうえで重要な可能性がある。

> [!IMPORTANT]
> 1878年『東京府村誌』の本文は、現時点では原画像を直接判読できておらず、地域史調査による転記を確認した段階である。以下では **二次転記による確認** と **原資料の所在確認** を分けて扱う。

---

## 1. 1878年『東京府村誌』雑司ヶ谷村条：弦巻川は「西青柳町ニ通ス」とされる

地域史調査「雑司ヶ谷村用水」は、明治11年（1878）の『東京府村誌』雑司ヶ谷村条から、丸池と弦巻川について次の内容を転記している。

- 丸池は雑司ヶ谷村の西にあり、弦巻川の源で、田の用水にもなる。
- 弦巻川は丸池から一条の流れとなり、村の中央を東流して **西青柳町へ通じる**。
- 雑司ヶ谷村の水田は5町3畝15歩、畑は70町余とされる。

二次転記：
https://ameblo.jp/kazuaruki/entry-12940940738.html

### この記述の意味

これは、原文確認が取れればかなり重要である。

既存文書では、1851・1857年の切絵図だけでは、護国寺南西側から先の弦巻川が

- 水窪川へ合流したのか
- 音羽谷西側を独立して南下したのか

を決められないとしている。

一方、1878年の村誌が本当に **「西青柳町ニ通ス」** と記しているなら、少なくともこの時点で、雑司ヶ谷村を流れてきた弦巻川が **護国寺南西側から現在の音羽二丁目西側に相当する西青柳町へ続いていた** ことになる。

ただし、これだけで

> 1878年には西青柳町から江戸川橋・神田川まで現在と同じ西側河道が全通していた

とまでは言えない。村誌が証明する可能性があるのは、まず **雑司ヶ谷村から西青柳町への接続** である。

```mermaid
flowchart LR
    A[丸池] --> B[弦巻川]
    B --> C[雑司ヶ谷村中央を東流]
    C --> D[西青柳町へ]
    D -.下流の正確な線形は要検証.-> E[音羽谷西側・神田川方面]
```

### 西青柳町の位置

『日本歴史地名大系』の「西青柳町」は、現在の **文京区音羽二丁目** にあたり、音羽町一丁目を挟んで東青柳町の西に位置する護国寺門前町とする。

確認用：
https://kotobank.jp/word/%E8%A5%BF%E9%9D%92%E6%9F%B3%E7%94%BA-3043789

歴史地名大系データセット：
https://geoshape.ex.nii.ac.jp/nrct/resource/13/130000201600.html

したがって「西青柳町ニ通ス」は、弦巻川下流の成立年代を考える際、**1878年を一つの重要な上限年代候補**にできる可能性がある。

### 原資料の所在

『皇国地誌稿本東京府誌』の復刻版は、東京都公文書館所蔵の「東京府誌」全46冊と「東京府村誌」全15冊を影印したものとされる。

CiNii Books：
https://ci.nii.ac.jp/ncid/BB30888890

国立国会図書館『東京府誌 : 皇国地誌稿本』各巻：
https://ndlsearch.ndl.go.jp/books/R100000002-I000010691825

**最優先課題：雑司ヶ谷村条の収録巻・頁を特定し、原画像で「西青柳町ニ通ス」、丸池、水田・畑面積を直接確認する。**

## 2. 1911年の5千分1番地界入地図：水久保・水久保新田の字界確認に使える

今昔マップでは、1896～1909年、1917～1924年、1927～1939年の地形図に「水久保」「水久保新田」が見える。一方、1880～1884年の迅速測図では同じ場所が主に畑として描かれ、字名は表示されない。

この空白を埋める資料として、東京逓信管理局による1911年の **『東京府北豊島郡高田村豊多摩郡戸塚村』** がある。

- 縮尺：1:5,000
- 刊行：1911年7月
- 番地界入り
- 著作権所有者：東京逓信管理局

CiNii Books：
https://ci.nii.ac.jp/ncid/BA55911066

国立国会図書館では、1911年原図の複製版も所蔵している：
https://ndlsearch.ndl.go.jp/books/R100000002-I000009377006

### 水久保・水久保新田との関係

この1911・1920年の番地界入地図をもとに小字を復元した二次資料では、旧雑司ヶ谷村側の小字として **「水久保」「水久保新田」** が並んでいる。

二次復元：
https://spidersweb-map.github.io/koaza-map/pages/%E5%8C%97%E8%B1%8A%E5%B3%B6%E9%83%A1.html

現時点では二次復元に依存しているため、**1911年原図上で字名・字界を直接確認する**のが次の作業になる。

この資料は、単に「水久保という地名があった」ことだけでなく、

- 水窪川旧流路
- 水久保と水久保新田の境界
- 番地界
- 旧道
- 雑司ヶ谷村域

を同じ縮尺で重ねられる点が強い。

## 3. 1918年『北豊島郡誌』：水久保を近代地誌側から確認する

北豊島郡農会編『北豊島郡誌』は1918年刊、631頁の郡誌で、国立国会図書館デジタルコレクションでインターネット公開されている。

国立国会図書館：
https://ndlsearch.ndl.go.jp/books/R100000002-I000000892967

デジタルコレクション PID：
https://dl.ndl.go.jp/pid/1879945

この郡誌は、雑司ヶ谷村の小名・土地利用・沿革を近代側から照合する資料として使える。とくに、江戸後期の『新編武蔵風土記稿』に現れる **「水久保」** と、1911年番地界図・1909年以後の地形図に現れる **「水久保」「水久保新田」** の連続性を検証する補助資料になる。

> [!NOTE]
> 「水久保新田」がいつ成立した小字かは、1918年郡誌だけで決めず、地租改正期の地引絵図・土地台帳まで戻って確認する。

## 4. 『御府内備考』護国寺三ヶ領・雑司ヶ谷：西側流路成立問題の優先資料

東京都公文書館には、東京市本の『府内備考』巻48～52をまとめた資料が公開扱いで所蔵されている。

対象巻には、

- 巻48・49：関口
- **巻50：護国寺領三ヶ町（東青柳町、西青柳町、音羽町一～九丁目など）**
- 巻51：高田
- **巻52：雑司ヶ谷**

が含まれる。

東京都公文書館 資料ID 000101055：
https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_01&pkey=000101055

### なぜ重要か

音羽通り西側の弦巻川成立問題を解くには、広域切絵図よりも、**西青柳町・音羽町・雑司ヶ谷を個別に記述する地誌**の方が有力な可能性がある。

確認したい語句は、

- 川・下水・悪水
- 弦巻／鶴巻
- 水久保／水窪
- 鼠ヶ谷下水
- 東青柳下水
- 橋
- 田・用水・堰

など。

特に、巻50の西青柳町・音羽町と巻52の雑司ヶ谷を連続して読めば、**雑司ヶ谷側の弦巻川がどの水路へ接続すると認識されていたか**を文章から追える可能性がある。

## 5. 現時点で更新できる年代幅

新資料候補を含めると、音羽谷西側の弦巻川については次のように整理できる。

| 年代 | 状況 | 評価 |
|---|---|---|
| 1682・1687 | 広域江戸図では水窪川側が見えるが、西側弦巻川は不明瞭 | 不存在の証明にはならない |
| 1772 | 雑司谷村絵図に弦巻川が描かれるとされる | 雑司ヶ谷村内の流路。下流は要高精細確認 |
| 1851 | 弦巻川らしい青線が護国寺南西端を越えて短く続く | 水窪川合流・西側独立流のどちらも未確定 |
| **1878** | 『東京府村誌』転記では「西青柳町ニ通ス」 | **原文確認できれば、西青柳町への接続を直接示す重要史料** |
| 1880年代以後 | 実測図で東西二流が明瞭 | 西側河道の存在は確実 |

したがって、現時点で最も優先すべき確認は、**1878年『東京府村誌』雑司ヶ谷村条の原文**である。

これが確認できれば、「音羽通り西側の弦巻川がいつできたか」という問題は、少なくとも

> **1878年までには雑司ヶ谷村から西青柳町へ弦巻川が通じていた**

というところまで一段強く絞れる。

ただし、西青柳町から神田川までの全区間が同じ時点で現在知られる線形だったかは、引き続き別史料で検証する。
