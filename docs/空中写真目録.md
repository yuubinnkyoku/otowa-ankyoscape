# 空中写真目録 — 池袋〜小石川の3河川流域（1936〜1966年撮影分）

国土地理院「地図・空中写真閲覧サービス」の検索APIを用い、水窪川・弦巻川・谷端川（・人参川候補谷）の流域を含む3つの範囲について、**1966年以前に撮影された空中写真136コマのメタデータ**（整理番号・コース・写真番号・撮影日・縮尺・画像中心座標）を一覧化したものである（2026年10月25日取得）。

> [!IMPORTANT]
> この目録は**写真の所在・撮影条件の索引**であり、**写真本体の読み取り・判読結果ではない**。各コマに旧河道・池・暗渠が実際に写っているかは、ビューアで画像を確認するまで未確定。中心座標は撮影範囲のおおよその中心で、周辺域の写り込み範囲（オーバーラップ）はコマごとに異なる。「日付不明」はデータベース上の登録日付が不明の意味で、撮影年代の特定を意味しない。

## 取得方法・対象範囲

- 検索先: 国土地理院 地図・空中写真閲覧サービス（https://service.gsi.go.jp/map-photos/app/map ）
- 同サービスの検索API（`/map-photos/app/api/photo`）に以下の3範囲を指定し、測量日が1966年以前のコマを抽出（範囲どうしの重複は整理番号ごとに除去）:
  1. 池袋・音羽・護国寺・雑司が谷・大塚（経度139.700–139.755、緯度35.705–35.740）
  2. 椎名町・南長崎・要町（谷端川上流。経度139.680–139.706、緯度35.715–35.740）
  3. 小石川下流・後楽・水道橋（谷端川下流。経度139.745–139.765、緯度35.698–35.720）
- 各コマのIDは「[ビューアで開く](https://service.gsi.go.jp/map-photos/app/map?search=photo&id={ID})」形式でリンク。簡易閲覧は無償・登録不要、高画質・最大画質は同サービスへの無料ユーザー登録が必要。
- 中心座標は「緯度, 経度」。**メタデータの市区名は画像中心点の所属**であり、撮影範囲全体の所属ではない。

1. **メタデータと画像の区別**: 本目録の撮影日・縮尺・中心座標はデータベース値。撮影範囲の四隅座標もAPI応答に含まれるため、対象地点が実際に写るかは四隅範囲とオーバーラップ率で確認する。
2. **「日付不明」コマ**: 陸軍 M23ロ・M23ハ・R9・R11 の一部は登録日付が不明（表中「日付不明」）。**撮影年代を仮定して使わない**。整理番号体系・隣接コマとの重複から年代を推定する必要がある。
3. **縮尺の意味**: 「約1/9,928」等はカメラ高度と焦点距離から算出された撮影縮尺で、印刷・納品縮尺とは限らない。
4. **判読の原則**: 池・水面・樹木・低地の読み取りは、本リポジトリの古地図読図（[地図一覧](地図一覧.md)）と同じく、**画像に見えること・見えないことの意味を限定して**記録する。写真の色調・コントラストで水面判定は誤り得るため、池の存否は形状・周囲地物との整合で確認する。
5. **著作権・出典**: 空中写真の複製・掲載には出典表記が必要であり、場合により手続を要する。本リポジトリでは当面**ビューアへのリンクと判読メモのみ**とし、画像本体の転載は行わない。
