# 水窪川・弦巻川・谷端川・人参川と詩歌

調査日：2026年10月23日

## 検索と採録の方針

詩歌を次の三種に分ける。題・本文で河川を特定できる「直接」、沿川の湧水・地形・谷の風景に関連する「流域」、地域名や寺の句碑を介して結び付くが川の描写とは限らない「周辺」。川の名と同じ「小石川」「音羽」が別地域にもある点に注意し、京都・山科の音羽山／音羽川などは除外する。

**句碑が存在する場所と、実際にその句が詠まれた場所は区別する。** 二次資料でのみ採録した作品の作者・原綴・初出は未確定として記録。

## 弦巻川

### 「みづまやの牛の腹ゆく蛍かな」〔直接〕

- 題：「弦巻川蛍」、場所指定：「法明寺前流」。
- 作者：鈷梁（2009年紹介記事の記載。読み・表記は一次史料で未確認）。
- 表記異同：「みづまやの牛の腹ゆくほたるかな」。
- 「みづまや」は牛の水飲み場と説明される。弦巻川沿いの蛍と牛の光景を示す。
- 資料：矢島勝昭「雑司が谷談義 第4話 弦巻川」『まちづくりニュース ぞうしがや』第45号（1997年3月）、『若葉抄』に言及。
  - https://zoshigaya.org/pdf/news/45.pdf
  - 「俳句や和歌に詠まれた雑司ヶ谷」（2009年3月26日）は「武蔵国雑司谷八境句」の「弦巻川蛍 法明寺前流」として収録。https://kimonokukai.blog37.fc2.com/blog-entry-7.html
- **研究上の用途：** 法明寺前に弦巻川が存在したという近世後期の地域認識を示す。ただし護国寺創建時（1681年）の流路や人工改修年代を証明するものではない。

### 「吹送るほしも岩ふれしみづかな」柳塘〔流域の湧水・暫定翻刻〕

- 題：「星跡清水 鬼子母神出現之所」。
- 星跡清水（清土鬼子母神）を対象とするらしい。表記・句の切れ方に読みにくい箇所があるため、**2009年紹介記事の文字列をそのまま採録**し、原典未照合とする。
- この清水と弦巻川の水理的接続は未検証。題に川名はない。
- 出典：https://kimonokukai.blog37.fc2.com/blog-entry-7.html

### 「雑司が谷繁き木立に降る雨の／降りつのりきて音の重しも」窪田空穂〔流域〕

- 文京区の小篠坂の説明板（文京区教育委員会・平成元年3月）に引用されている。小篠坂は護国寺北西〜本浄寺へ下る。
- あくまで雑司が谷の雨と木立の歌で、弦巻川自体への言及はない。
- 説明板の紹介：https://citywalk2020.hatenablog.com/entry/2025/02/19/141900
- 作者の居住と作品：https://www.city.bunkyo.lg.jp/b014/p003940.html

### 「目白台北の傾斜の雜司ケ谷細き路地ありその奧に住む」窪田空穂〔流域〕

- 目白台北斜面と雑司が谷の地形・路地を詠む歌。水路を詠んだわけではない。
- 作品紹介：https://tankanokoto.com/2023/06/utubo-2.html
- 文京区の作者紹介：https://www.city.bunkyo.lg.jp/b014/p003940.html

### 関連作品（川自体を詠んだわけではない）

- 「鬼子母尊現れしは青き谷戸のどこ」加倉井秋を：雑司が谷の谷戸の景観。
- 「雑司が谷雨の欅に鵙鳴けり」水原秋桜子：雑司が谷の風物。
- 両句の紹介：https://kimonokukai.blog37.fc2.com/blog-entry-7.html
- 「武蔵国雑司谷八境句」には「姿見橋鷺」の句もあるが、橋の位置と対象四河川のつながりを確かめるまでは**弦巻川の句とはみなさない**。

## 谷端川（下流の小石川・千川・礫川）

### 「一時雨礫や降って小石川」松尾芭蕉〔川名と重なる地名／周辺〕

- 1677年（延宝5年）の作として紹介される。句の異表記：「一しぐれ礫や降て小石川」「一しぐれ礫や降りて小石川」など。
- 時雨・礫（つぶて）・小石川という語を用いた句。
- 慈眼院（澤蔵司稲荷、文京区小石川3丁目）に句碑があり、文京区教育委員会の善光寺坂説明にも掲載。
- **注意：** 「小石川」は地名でもあり、この句が谷端川の水面を直接詠んだと断定できない。川と地域の歴史的呼称の一致を示す「関連詩歌」とする。
- 芭蕉句解説：https://www2.yamanashi-ken.ac.jp/~itoyo/basho/haikusyu/sigre.htm
- 善光寺坂説明板の採録：https://massneko.hatenablog.com/entry/2015/06/20/000000
- 谷端川＝小石川（下流部）の地名根拠：『日本歴史地名大系』小石川（平凡社）https://kotobank.jp/word/%E5%B0%8F%E7%9F%B3%E5%B7%9D-61267

### 「雑然と鷺は群れつつおのがじしあなやるせなきすがたなりけり」古泉千樫〔周辺・未確定〕

- 吹上坂下の播磨たんぼ（旧小石川の低地）の説明に付された短歌。
- **採録に留保：** 原歌集・詠まれた場所を確認できていないため、「播磨たんぼを直接詠んだ」証拠としては使用しない。
- 出典（二次記事）：https://chikyuza.net/%E3%80%8C%E6%96%87%E4%BA%AC%E5%8C%BA%E6%98%A5%E6%97%A5%E3%83%BB%E5%B0%8F%E7%9F%B3%E5%B7%9D%EF%BC%9D%E5%9D%82%E6%88%B8%E6%96%87%E5%AD%A6%E3%82%92%E3%82%81%E3%81%90%E3%81%A3%E3%81%A6%E3%80%8D%E3%81%AB/

## 水窪川

2026年10月23日現在、**水窪川を題または本文で直接示す、原典の確認できる短歌・俳句は未発見**。周辺の「音羽」「護国寺」の詩歌を、東側の水窪川と西側の弦巻川のどちらに結び付けられるか、地名だけで決めない。

- 永井荷風『葛飾土産』（1947年）に「音羽久世山崖下の細流」とあり、水窪川に対応する可能性が高いが、本文上は無名の細流。**これは散文であり詩歌ではない。**
- 原文：https://www.aozora.gr.jp/cards/001341/files/49636_39417.html

## 人参川

2026年10月23日現在、**人参川を直接詠んだ短歌・俳句は未発見**。

- 永井荷風『葛飾土産』に「竹島町の人参川」と明記される（同時代の地域記憶を後年に記述した散文）。『日和下駄』の「金剛寺坂下の人参川」と別の場所を指すのか、同じ水路の区間なのか検証が必要。
- 原文：https://www.aozora.gr.jp/cards/001341/files/49636_39417.html
- 既存調査：[人参川](人参川.md)

## 優先して確認したい一次史料

1. 金子直徳『若葉抄』（『若葉の梢』増補本）の「弦巻川蛍」と「武蔵国雑司谷八境句」：刊行・成立年代、作者「鈷梁」の字形、句の原綴、題「法明寺前流」の原記載。
2. 星跡清水の句の原綴と、旧地図における清水の位置・弦巻川との水系上の接続。
3. 芭蕉句の初出史料と「小石川」が河川名なのか地域名なのかの文脈。
4. 人参川の「金剛寺坂下」と「竹島町」の位置関係および詩歌作品の有無。
5. 検索語の追加：谷端川／千川／小石川／礫川、弦巻川／雑司谷蛍／法明寺前、水窪川／音羽久世山／音羽通り、人参川／金剛寺坂／竹島町／茗荷谷。京都・山科の音羽山／音羽川と混同しない。
