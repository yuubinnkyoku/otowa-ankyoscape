# 2026年11月10日・1912年地籍図553コマ（茗荷谷町）の水路・池の原図判読

## 目的

人参川候補の未解決事項（1912年地籍図に河道・水路敷が描かれるか／拓殖大東門付近の池と二源頭の旧水路・橋を原図で確定できるか）に対し、『東京市及接続郡部地籍地図』上巻（[MAP-008](../sources/maps/MAP-008.md)・NDL pid 966079）の**553コマ（茗荷谷町・拓殖大学付近）**をAIが原図判読する。利用者観察の「道路沿いの水路候補」「着色」を独立に検証することが狙い。

## 対象と方法

- **553コマ**＝茗荷谷町（図番号44・小石川）。NDL IIIF `R0000553` を 2400px で取得し、全体＋中心／官有地／東門部のクロップ（2〜3倍）を目視判読。画像は転載せずリンクと本メモのみ残す。
- **重要な限界：NDLデジタル再現はモノクロ（グレースケール）**。**彩度計測（AI）：538・540・552・553・566・567すべて R=G=B・彩度最大0＝無彩色**＝pid 966079 のデジタル再現は**巻全体が無彩色**（混在ではない）。したがって利用者の「着色」観察（552・553だけでなく566・567・538〜541を含む）は**本NDLデジタル再現由来ではなく、彩色の別再現（原本・彩色複製本・未同定のデジタルitem）に由来する**。彩色再現の所在同定が未解決課題。
- 地籍図の凡例（水路・池・崖・道路の記号定義）は未照合。線種・ハシュアからの性格推定は留保付きで記録する。

## 観察

- **拓殖大学の前身を確認**：図郭中央下の大区画に「**東洋協会学校**」「**官有地**」の注記。東洋協会学校は拓殖大学の前身にあたり、現キャンパス位置の戦前地籍上の対応が取れる。その東縁に**崖線（ハシュア）帯**が走り、茗荷谷の谷壁と整合する。
- **周囲町名**：清水谷町・竹早町・同心町・第六天町・水道端町二丁目・小日向台町一丁目・大塚町・三軒町。茗荷谷町が谷頭の台地と谷に挟まれる位置関係が読める。
- **地番・地目・所有者**：田・畑・宅・山林の地目と所有者名注記（杉浦・渡辺・田口・村上ら）を伴う地番区画が格子状に並ぶ。
- **縦走線状地物（性格未確定）**：地番1309（字注記「南大路」相当）の西縁に**灰色帯＋黒帯が並ぶ縦走線**がある。水路・崖・道路のいずれかは判別できない（モノクロ・凡例未照合）。
- **池・開渠**：**閉じた池形状（島状池＋南側別池を含む）や、連続する開渠の描線は本コマからは確認できない**。道路沿いの破線は道路敷・境界表現と読め、水路と確定しない。

## 小結

1. **553コマは拓殖大学前身（東洋協会学校）の官有地と谷壁崖線を確かな地籍証拠として示す**が、**人参川候補の開渠・池を確定しない**。
2. **利用者の「着色」観察はNDLモノクロ再現では検証不能**。着色による水路候補の判断は、彩色本・別再現の照合なしには確定できない。〔未解決〕
3. 地番1309西縁の灰色＋黒帯の縦走線は**水路候補として残すが性格未確定**。凡例照合と彩色再現、および五千分一東京図（[MAP-007](../sources/maps/MAP-007.md)）の池状表現との位置合わせが次の課題。
4. 明治期池状表現（拓殖大東門・島状池）は**五千分一東京図側の観察**であり、1912年地籍図553コマで池が確認できないことは、**池が1912年までに埋まった可能性**と**地籍図が池を描かない／モノクロで判別できない可能性**の両方を残す。不在を断定しない。
