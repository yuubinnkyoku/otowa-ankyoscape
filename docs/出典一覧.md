# 出典一覧

このファイルは、分割後の調査ノートから参照する**主要出典の共通一覧**です。

本文では、できるだけ「豊島区資料」「1941年資料」のような曖昧な書き方を避け、該当する出典番号へ直接リンクします。分割前READMEで使っていた `[Sxx]` / `[Bxx]` が判明しているものは、見出しにも旧番号を残しています。

> [!IMPORTANT]
> **出典が存在すること**と、**その出典が本文中の仮説を証明すること**は別です。とくに古地図については、資料の所在・年代の確認と、そこから流路を読み取った本調査の観察を分けて扱います。

## 水窪川

### S03 — 豊島区「水窪川をたどって」関連プレス資料

- 豊島区広報課、1999年10月9日付プレス資料。
- https://adeac.jp/viewitem/toshima-history/viewer/viewer/pressH111009/data/pressH111009.pdf
- 「水久保」の地名由来、「水久保川」「日の出川」、近世地誌『御府内備考』の「鼠ヶ谷下水」、川幅一間ほど、昭和初期から戦後にかけて下水化されたことなどを記す。

### S02 — 本田創「水窪川」現地解説

- 本田創「池袋に残る“消えた川”を追ってみると…神田川へ向かう『水窪川』の暗渠には何がある？」文春オンライン、2021年11月20日。
- https://bunshun.jp/articles/-/50033
- 音羽谷東端の水窪川、護国寺創建を契機とする音羽町造成と東西二流の整備についての解説に使用。
- **近世の工事記録そのものではない**ため、成立年の直接証拠としては扱わない。

### S33 — 「わが街ひすとりぃ 日出」現地ロケ

- 豊島区「としまひすとりぃ」オーラルヒストリー「わが街ひすとりぃ 日出」現地ロケ編。
- https://adeac.jp/toshima-history/texthtml/d000000/mp00500101/ht420120
- 辻広場の案内板「水窪川　小さな川が流れていた　後世に伝える」と1986年表示、辻広場整備についての住民証言を確認できる。

### S05-M — Natrium.jp「神田川周辺の水路敷群（水窪川）」

- https://natrium.jp/canal_lot/kanda/mizukubo/index.html
- 現地地形・水路敷・下水道台帳などを照合した現地調査記録。一次史料ではなく、現地観察・比較資料として使う。

## 出典の使い分け

- **一次史料・同時代史料**：古地図、村誌、行政文書など。流路・名称・年代を直接確認する際の優先資料。
- **公的な後世資料**：自治体史、施設解説、郷土資料館資料。一次史料の所在確認や地域史の整理に使う。
- **研究論文**：地形・地質などの学術的考察。仮説の根拠と限界を明記する。
- **現地調査・二次資料**：Natrium.jp、地域史ブログ、暗渠書籍など。観察点・資料候補の発見には有用だが、重要な年代や工事事実は可能な限り一次史料・公的資料で裏取りする。
