# 横断テーマ

水窪川・弦巻川・谷端川を別々に見るだけでは捉えにくい背景・共通テーマをまとめる。

**個々の未解決問題は [open-questions/](open-questions/README.md) に独立させる。** とくに水窪川と弦巻川の合流・接続については、[専用文書](open-questions/水窪川と弦巻川の合流・接続問題.md) を参照。

主要出典は各記述の直後に示し、一覧は [出典一覧](出典一覧.md) にまとめる。

## 千川上水との関係

千川上水は元禄9年（1696）に玉川上水から分水され、宝永4年（1707）には沿線20か村の農民が田へ水を引くことを許された。〔確認〕  
出典：練馬区公式 [「千川上水跡」](https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/rekishibunkazai/bunkazai/b047.html)、東京都建設局 [「千川上水」](https://www.kensetsu.metro.tokyo.lg.jp/jimusho/yonken/koji2/senkawa) / [S08](出典一覧.md)

谷端川については、要町3丁目付近から南東へ分かれる「長崎村外三村分水」が、粟島神社の池を水源とする谷端川へ接続していたことが確認できる。〔確認〕  
出典：練馬わがまち資料館 [「千川上水の分水を訪ねて（2）」](https://www.nerima-archives.jp/column/3572/) / [S11](出典一覧.md)

一方、弦巻川・水窪川へ直接補水したことを示す分水口・樋・水路は現時点で確認できていない。周辺河川への余水供給自体はあり得るが、**「あり得る」ことと「実際にあった」ことは分ける。**

今後の一次資料候補として、1696年の請負手形から1884年の絵図までを含む「千川家文書」がある。  
出典：練馬区公式 [「千川家文書」](https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/rekishibunkazai/bunkazai/b0904.html) / [S19](出典一覧.md)

## 更新世の旧河道

滝口志郎「武蔵野台地の地形に関する諸問題」（2019）は、弦巻川・水窪川上流の浅い谷と、護国寺以南の深い谷の河床高度が不連続であることに注目し、上流側の高い河床を更新世の旧河道と考える案を示している。さらに、弦巻川の流路がかつて谷端川側へつながっていた可能性を提示する。〔研究論文／仮説〕  
出典：滝口志郎「武蔵野台地の地形に関する諸問題」『深田地質研究所年報』第20号、2019年。[深田地質研究所](https://fukadaken.or.jp/?page_id=6569)、[国立国会図書館デジタルコレクション](https://dl.ndl.go.jp/pid/14529520) / [S01](出典一覧.md)

一例として、お茶の水女子大学付近を経て谷端川側へつながる流路が図示される。しかし、**谷筋がつながることと、水がどちら向きへ流れたかは別問題**である。

```mermaid
flowchart LR
    A[弦巻川・水窪川側の浅い谷] --- B[お茶の水女子大学付近]
    B --- C[谷端川側の谷]
```

考えられる案は、

- 弦巻川・水窪川側から谷端川へ流れた
- 谷端川側から護国寺方面へ流れた
- 途中に分水界があった
- 河川争奪や流路逆転が起きた
- 論文の図は接続関係を概略的に示しただけで、合流角や流向は厳密でない

などである。現時点ではどれか一つに固定しない。

## 音羽谷の東西二流はいつ成立したか

本田創の2021年の現地解説は、1681年の護国寺創建を契機に音羽町が造成され、その際に水窪川・弦巻川が町裏の東西崖下に沿う二流へ整備されたと説明する。〔後世の解説〕  
出典：本田創「池袋に残る“消えた川”を追ってみると…神田川へ向かう『水窪川』の暗渠には何がある？」[文春オンライン](https://bunshun.jp/articles/-/50033) / [S02](出典一覧.md)

ただし、これは**1681年の工事記録そのものではない**。整備前の正確な流路や完成年を直接示す一次史料は、現時点で未確認である。

### 1941年資料の「一流→二流」説

東京女子高等師範学校附属国民学校児童教育研究会 編『「郷土の観察」の指導体系』（1941年）には、音羽谷の川について、**もとは一流で、水田開発時に灌漑のため二流に分けられたのではないか**という趣旨の地理的推測がある。〔史料中の推測〕  
出典：『「郷土の観察」の指導体系』皇国青年教育協会、1941年、国民学校教育研究書 第3輯。[国立国会図書館デジタルコレクション PID 1275204](https://dl.ndl.go.jp/pid/1275204)、[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000002-I000000645614) / [B03](出典一覧.md)

**これは近世の工事当時の記録ではない。** したがって「実際に一流を二流へ分けた」と確定する根拠ではなく、後世の地理的推論として検証対象に置く。

現在の成立時期の候補は次の通り。

1. 1681年前後の護国寺・音羽町造成時に西側水路が成立した。
2. その後の水田拡張・灌漑再編時に成立した。
3. 既存の小水路が段階的に拡幅・接続され、後に弦巻川下流として認識された。

一次史料で工事時期を確定できるまでは未解決とする。

## なぜ水窪川は音羽谷の東端なのか

自然河川なら谷の中央を流れそうだが、水窪川は東側崖下に沿う。この配置については、

- 小日向台・豊島岡側の崖下湧水
- 近世の護国寺・音羽町造成
- 谷底を田畑・町として利用するための河道固定

が組み合わさった可能性を考えている。これは〔推定〕であり、現時点で単一の一次史料から証明された説明ではない。

## 今後の優先課題

- 1772年『武蔵国豊島郡雑司谷村絵図』の高精細画像を確認する。
- 1682年から明治初期までの間で、音羽谷西側の水路を明瞭に描く最古の一次資料を探す。
- 千川家文書などから、谷端川以外への分水記録がないか調べる。
- 谷端川水源地付近の発掘・古環境研究を入手し、更新世旧河道説と照合する。
- 自然河道、近世水路、暗渠管、現代下水道幹線を年代別に分けて比較する。
