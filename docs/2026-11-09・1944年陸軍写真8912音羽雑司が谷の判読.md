# 1944年陸軍写真8912-C1-148による戦時中段の音羽・雑司が谷判読

2026年11月9日。1936年（陸軍B7/B8）と1947年（米軍M372）の間に**戦時中段（1944年）**を追加するため、**1944/10/22 陸軍 8912-C1-148**（[MAP-145](sources/maps/MAP-145.md)、約1/17,000）を判読した。結論は**(a) 音羽・雑司が谷・東池袋は1944年に既に密集市街化、(b) 大規模な焼跡・空襲痕なし（本格空襲前）、(c) 河道・池の水面は未確認**。

## 方法とスキャン回転の補正

- 標準版（2685×3015）を取得。**フィルム題簽（写真番号・整理番号）が上下逆**であったため、スキャンが**180度回転**していると判断し、180度回転補正後にAPI四隅座標から8パラメータ homography で Web Mercator z16 へ逆 warp した。
- 中心 (35.7235,139.7235) にキャンバスを置き、現況標準地図タイルと並べて位置合わせを試みた。**ランドマーク単位の対応は暫定**（幾何誤差約100〜300m）。

## 観察（範囲全域の定性・回転補正の誤差に依存しない）

- **全域が密集市街地**（格子状街区・小住宅）。農地の格子は卓越しない。雑司が谷が1936→1947の間に市街化したという既往比較と整合し、**1944年には既に市街化が進んでいた**ことを補強する。
- **大規模な焼跡・空襲痕は確認できない**。1944/10/22は東京本格空襲（1945年）より前で、戦災前の市街地景観を写す。
- 樹林・格子状緑地パッチ（霊園・寺社境内に相当する候補）と大きな矩形の施設・校地ブロックが点在。
- **河道・開渠・池の平滑な水面は確認できない**（約1.1 m/px の検出限界）。

## 留保

- スキャン回転補正・内容範囲の推定を含む大まかな幾何対応のため、**個別ランドマーク（霊園・護国寺・池候補）の一点特定はしない**。位置合わせは暫定。
- 「密集市街地・焼跡なし」は範囲全域の定性観察であり、回転補正の誤差に依存しない主張として扱う。
- 戦時中段は「1936→1947の市街化進行」を補強するが、**池・水源の存否はこのコマでは判定できない**。

## 小結

- 音羽・雑司が谷の比較段に**1944年（戦時中・空襲前）**を追加：1936年農地混在 → **1944年密集市街・焼跡なし** → 1947年密集市街 → 1963年完全市街。
- 丸池・東青柳町池などの水面は本コマでも未確認。過去への遡及は引き続き絵図・地籍図・屋敷図を要する。
- 私有地・柵の先・崖下への立ち入りは提案しない。
