# 音羽二丁目遺跡と水窪川沿いの池状地物・旧流路仮説

2026年10月、地理院地図「文明開化期 東京主要部」の読図と、近傍の発掘調査報告書『音羽二丁目遺跡』の書誌・要約を照合するために作成した調査メモ。**発掘調査の成果と、利用者による古地図読図・旧流路仮説は分けて記す。**

## 1. 発掘調査で確認されたこと〔報告書の要約により確認〕

- **資料**：文京区教育委員会編『東京都文京区 音羽二丁目遺跡――警視庁大塚警察署改築工事に伴う埋蔵文化財発掘調査報告書』、警視庁・文京区教育委員会、2012年12月、文京区埋蔵文化財調査報告書 **B-126**。本文15ページ・図版1枚。
- 調査地点は**大塚警察署改築工事に伴う発掘調査区**。現在の大塚警察署は東京都文京区音羽2丁目12番26号に所在するが、**調査区の具体的な輪郭は報告書本文・位置図で要確認**。
- CiNii Researchに掲載された報告書の要約によれば、調査区は**江戸時代はじめまでは関口村の耕作地の一角**であり、護国寺創建に伴い**護国寺領の門前町屋**となった。遺構・遺物は少なく、**19世紀前葉から中葉頃に当該地で整地が行われた**ことが確認された。
- この「整地」の**範囲・厚さ・堆積物の性質・整地前の地形・年代判定の根拠**は、現在確認できる要約からは分からない。報告書本文は未読。

出典：[CiNii Research／要約・書誌](https://cir.nii.ac.jp/crid/2120589364412597760)（DOI: [10.24484/sitereports.86651](https://doi.org/10.24484/sitereports.86651)）／[国立国会図書館サーチ／書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I026235685)／[CiNii Books／所蔵館](https://ci.nii.ac.jp/ncid/BB1842879X)／[警視庁・大塚警察署所在地](https://www.keishicho.metro.tokyo.lg.jp/about_mpd/shokai/ichiran/kankatsu/otsuka/ps_info.html)。共通書誌は [出典一覧のS60](出典一覧.md) 参照。

## 2. 水窪川沿いの池状地物〔利用者の古地図読図／未確定〕

- **読図位置の目安**：北緯 **35.717529**、東経 **139.728814**。利用者が2026年10月に提示した、地理院地図「文明開化期 東京主要部」（**五千分一東京図測量原図系**）の画面上で、水窪川の**西側**に淡青色の**四角形に近い池状・水路状の表現**が見える。
- 本流に接しているように見える部分もあるが、線の重なりや図式が判読しきれず、**池、水槽、用排水路、庭園施設、旧河道の残存水域**のいずれかは判定できない。水窪川本流との接続も未確認。
- 利用者は、**この形の地物を他の比較地図ではまだ確認できていない**と報告している。ただし、どの地図の何年版・どの画質で比較したかは未記録であり、**他図で見えないことは地物が消滅した証拠ではない**。
- 利用者が提示した**赤線**は、本流より**西寄りの旧流路候補**を示す推測線。赤線上には測量原図の時点ですでに建物・区画が見えるため、もし実際の旧河道なら**当該図の測量以前に埋め立て・付け替え等が行われた**という追加仮説が必要になる。赤線自体を古地図に描かれた河道として扱わない。

地図の原資料所在：[国土地理院「五千分一東京図測量原図」](https://service.gsi.go.jp/kochizu/app/map/tokyo-sokuryozu)／[地図一覧](地図一覧.md)。

**注意**：別の調査メモにある「1909年図の現講談社付近の池・河道上施設」とは、**現段階で同一の地物と確定していない**。位置合わせが必要。

## 3. 整地と旧河道の関係〔仮説・未検証〕

19世紀前葉〜中葉の整地は、**近隣で地面が人為的に改変された実例**として重要。ただし次の推論は成立しない。

- **整地があった → 水窪川の旧流路を埋めた**：整地層の下に旧河床・水成堆積物・溝などを確認していないため言えない。
- **近隣で整地があった → 池状地物の場所も同時に整地された**：発掘調査区と池状地物の位置関係・標高差・地層の連続性が未確定。
- **19世紀の整地 → 1681年の護国寺創建時の河道整備**：年代が一致せず、同一事業の証拠にもならない。創建を契機とした二流の整備は本田創による**後世の解説**であり、近世の工事記録とは別扱い（[S02](出典一覧.md)）。

整地の目的は、宅地化・建築に伴う整備、水害対策、排水改善など複数考えられる。どれであったかは未確認。

## 4. 現物確認で優先する項目

1. **報告書の調査区位置図・平面図**を入手し、座標35.717529, 139.728814と同じ地図上で照合。以前挙げた「約80m」という近接距離は、位置図との照合前なので確定値として採用しない。
2. **土層断面・柱状図**から、整地層の厚さ、下位にある自然層（耕作土・河成砂礫・泥・有機質層等）、地下水の記録を確認する。砂や泥だけで旧河道と断定せず、堆積構造・地形との組み合わせで判断する。
3. **整地の年代根拠**（出土陶磁器・遺構の切り合い・古文書等）、整地以前の地表面標高、近代造成による撹乱を確認する。
4. **五千分一東京図の高精細原画像・凡例**で、池状表現の色・外形・本流への接続・建物との位置関係を再判読する。
5. **江戸期の絵図、明治初年の地券・沽券関係図、1880年代図、1909年1万分1地形図、1912年地籍図**で、同じ地点の地割と水面表現を年代順に照合する。図式・縮尺・画質の違いを記録する。
6. **屋敷池・農業用水・製紙用水・旧河道**の各説に対し、土地所有者・職業・取水や排水の記録を探す。当地で製紙業が営まれたことは未確認。

**当面の位置付け：**『音羽二丁目遺跡』の整地記録は〔要約から確認〕、水窪川西側の池状地物は〔利用者による図上観察〕、赤線の旧流路は〔仮説〕、その相互関係は〔未検証〕。
