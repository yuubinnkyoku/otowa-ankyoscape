# 暗渠・旧河川ブログ横断調査（2026年10月23日）

対象：水窪川（音羽川・水久保・東青柳下水）、弦巻川（鶴巻川）、谷端川（小石川・礫川・千川・西大下水・各支流）、人参川（茗荷谷周辺。古茗荷谷川との同一視は保留）。

## 調査方法と限界

既存の [出典一覧](出典一覧.md) と [水窪川](水窪川.md)・[弦巻川](弦巻川.md)・[谷端川](谷端川.md)・[人参川](人参川.md)、一部の調査ログを比較した。川名・異体字・下水名・支流名・著者名で公開記事を検索し、著者別の月別記事・目次・連載を遡った。下記の「未整理」は、少なくとも河川別本文と出典一覧で個々の記事が適切に索引化されていないという意味。大容量の旧ログなどに単発で URL が残っている可能性は否定しない。

網羅とは「検索・目次で見つかる主要な連載や価値の高い現地踏査を拾う」ことであり、非公開・検索対象外・移転前のブログまでの完全性は保証できない。記事の見出し・検索索引で内容を確認したものと、本文まで調べたものが混在する。明治以前の工事年代・水路接続・水源は、筆者の復元と一次史料を混同しない。2026-10-23現在。

## 最重要発見：護国寺創建と弦巻川付け替え説の先行例

**「水の行方を追って」2014年1月の弦巻川連載**には、護国寺建設以前の弦巻川が護国寺南側から水窪川に合流し、護国寺参道整備に伴い両側へ川筋が分けられたとする解説が明記される。

- [弦巻川の記事一覧（2014年1月21日・28日・30日の3回）](https://wanjin.blog.fc2.com/?cat=8&page=0&pc=)。1月21日の記事「弦巻川―増殖…」※冒頭回では、**1681年の護国寺建立時に西側・東側へ流路を工事で配置した**と述べる。1月28日 [「人間の手が加わっていない天然物の希少価値」](https://wanjin.blog.fc2.com/blog-entry-24.html) は、自然河道は不忍通り付近までで、その下流の音羽谷西側は人為的に設けたと主張。1月30日の記事「多数決の原理…」は、本来は護国寺門前を東へ進み、水窪川に合流したと明記。
- **評価**：既存の有力仮説に強く似た「先行する二次資料の復元説」。このブログだけでは1681年の工事・旧合流地点の一次証拠にはならない。ブログの参照元（文献、地域史、聞き書き、古図）を追跡する必要がある。後のブログで同様の説明が見つかっても、同一の伝聞・著書からの転載なら「独立した裏付け」は増えない。
- **注意**：同記事は「この川の流路は後世の人工水路」と強く断じる一方、地籍・同時代文書を出典として挙げない。既存の [音羽谷西側成立年代](open-questions/音羽谷西側の弦巻川下流の成立年代.md) の1696～97年説・別湧水路接続説を棄却する根拠にはならない。

## 今後の優先検証

1. **最優先**：2014年「水の行方を追って」の1681年付け替え説の出典特定。2014年記事より先に出た本田創の旧「東京の水」や『失われた川を歩く』旧版、区史、地元資料のどれを参照したか追跡する。同じ文章が後代に何件あっても一次証拠の代わりにはならない。
2. **原典追跡**：髙山英男が紹介する横山恵美「豊島区の湧き水をたずねて」（豊島区郷土資料館研究紀要第11号）の書誌、画像、付図を調べる。谷端川支流、弦巻川沿いの湧水について一次・準一次記録になる可能性。
3. **近代の線形照合**：高橋俊一「谷端川の跡を歩く」の1909〜1956年重ね合わせ資料を、国土地理院の原図・1912年地籍図で検証。特に小石川下流の1934年以前からの暗渠化と上流の暗渠化時期を分ける。
4. **別水路の留保**：D.2.C.の豊島岡墓地「蛇池」支流・丸池北西流出路、髙山の南長崎支流再検証、人参川に近い茗荷谷支流（仮）を本流同定なしに別候補として記録する。
5. **写真年代**：2010・2011・2018・2020・2024・2026年の写真が残る位置は、現存、消滅、私有地、未訪問に分ける。私邸や学内へ無許可で立ち入らない。

**総合判定**：既存の出典一覧は公文書・地図・主著作に強いが、暗渠系ブログの**連載単位、支流別の索引、後年の訂正追跡**に大きな欠落があった。今後は単一ブログの断定を新事実として丸写しせず、現地写真・二次推定・公的史料を分離して活用する。
