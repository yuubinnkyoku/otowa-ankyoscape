# 2026-11-25（第322回）・東京市史稿市街篇（第14・18・20・21冊）のlab全文掃引＝霊岸島「八町堀千川屋鋪」請取文言・白山前町千川屋鋪正徳4年両証文・享保7年差止事蹟章4引用元（柳營日次記・撰要永久錄・有德院殿御實紀・國朝舊章錄）・神田旅籠町堀井の安永9年5月9日／天明3卯年渡し文言の新規収録

## 概要

前回（第321回）に続き NDL次世代デジタルライブラリー（lab）の『東京市史稿』市街篇 series の fulltext 掃引を行った。第316回ノートに残っていた「市街篇14・18相当」の冊（3450788・3450793）と、新たに同定した「市街篇20・21」（3450797・3450801）を掃引し、4冊ぶんの未収録文言を確認したため GAZ-190〜GAZ-193 として登録した。また残候補だった江戸叢書巻4/5（1912998/1913009）を掃引し、いずれも既存の BOOK-202（十方庵遊歴雑記 二編）・BOOK-203（三編の複製版）として登録済みで新情報なしと確定した。

## 新規収録（GAZ-190 〜 GAZ-193）

1. **GAZ-190（市街篇 第十四・3450788）**: 霊岸島川口町の「八町堀千川屋鋪」条。御府内沿革書図據ニ拠る、柳澤出羽守殿上ケ屋敷4,612坪が元禄12己卯年（1699）2月3日に町屋代地として渡された**受領側の請取文言**（立合い:松前伊豆守組・保田越前守組の与力同心＝平塚伊右衞門・生田三郎左衞門・鈴木孫左衞門＋町年寄・布施半右衞門・奈良屋市右衞門）。柳澤出羽守・4,612坪・平塚伊右衞門等はいずれもrepo初出。「千川屋鋪」の語義は OCR 列崩壊のため断定せず（江戸川筋の立地であり千川上水系の直接座標ではないと観察）。**湯島の神田上水86間5尺埋樋文言は GAZ-122（町方書上〔69〕）の市街篇側採録＝対校点のみで新規情報なし。**
2. **GAZ-191（市街篇 第十八・3450793）**: 白山前町千川屋鋪の**正徳4年2月27日（名主六之丞預り）と3月22日（千川德兵衞・太兵衞渡し）の両証文言**。立合人「嶋田佐渡守内小倉半内」「小林久左衞門組鈴木」「高林又兵衞組村井」、**「外ニ下水坪十七坪五合」＝下水付帯用地の坪数がrepo初出**。GAZ-053 の宝永元年証文の「南伏屋賴母」に対し本冊は「南伏屋修理」と読める＝判読対立の新対校本。正徳4年＝甲午の干支対立（GAZ-049⑫の注記）に証文側2票。
3. **GAZ-192（市街篇 第二十・3450797）**: 「千川上水其他廢止」事蹟章（pp.501-504）。①柳營日次記「（享保7年8月）十七日庚午」条（差止側の柳營日次記引用は repo 初出、鑿通条〔GAZ-016〕と別条）、②石川近江守渡しの御書付（「**中興〓懸り**」と読め＝中奥/中興判読対立の第3テキスト）、③撰要永久錄の**水筋文言「武藏野保田新田〓板橋庚申塚・巢鴨・谷中・上野下谷・淺草筋に相掛り」**（水元〜末端給水区域を一つの触文言で結ぶ列挙・repo初出。撰要永久錄＝GOV-378 と同一資料の別の触）、④三正綜覽拠りの**9月3日（乙酉）千川・青山三田廃止令・9月5日（丁亥）本所上水廃止**の日次候補（8月触→10月実施の間に9月の令の層）、⑤**有德院殿御實紀「この十月より千川の上水を引ことをとゞめらる」「本所上水ハ…水もかゝらざるをもてとゞめらるゝとなり」＝実施文言 repo 初出**、⑥**國朝舊章錄の引用文言（火消組合仰付との併記条）＝引用元として repo 初出**（番町小川町駿河臺等火消組合＋千川上水青山三田等の上水停止）。
4. **GAZ-193（市街篇 第二十一・3450801）**: 神田旅籠町の昌平橋外堀井の渡預繪圖證文＋**後日注記「安永九庚子年五月九日 旅籠町之者共（より）請負人加東屋甚五郞に渡ス」「天明三卯年 千川上水請負人に引渡こ相成い。右錠鍵加東屋甚五郞に相渡、先預り之者不殘消印濟」**＝①安永9年5月9日の**日次が repo 初出**（GOV-441「安永9年5月」と月次整合）、②**天明3卯年 vs GOV-441「天明4辰年五月」の年次対立の新 witness**、③錠鍵・消印の運用細部。享保11年2月18日の証文側の立合人名（吉澤藤七郎・矢部伊右衞門・鈴木伊勢守内）も GAZ-130 未収録で初出。昌平橋外揚場の土屋小左衞門拝借文言（享保11年2月4日・浅草門跡旧地）も記録。神田仲町系の文言は GAZ-041 重複のため不採録（第317回判定を踏襲）。
