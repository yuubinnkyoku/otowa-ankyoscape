→ 都電沿い  
→ 写真の大塚6丁目17～18付近

結論は、**「ここは水窪川の上流部の川跡。ただし源流地点はさらに池袋側」**です。

### どんな景色だったか

明治から昭和初期ごろなら、次のような景色だったと考えられます。

- 窪地の中央に、あまり大きくない浅い池
- 池の周囲には湿った草地やぬかるみ
- 池から東側へ流れ出す細い水窪川
- 周辺は畑や寺、低い木造家屋
- 南側には根津山の雑木林や丘陵

郷土史系の記録には、**池のほとりに栗の木が生えていた小池**だったという話もあります。ただし、これは当時の聞き取りをもとにした記述で、池の正確な形や大きさまでは分かりません。citeturn256647search6

なお、「蟹ヶ窪」は池だけの名前ではなく、池袋駅東口から現在の東池袋方面に広がる**旧字名**でもありました。1927年の記録にも「西巣鴨町大字池袋字蟹ヶ窪」という住所が確認できます。citeturn389841view5

### 池そのものの写真は？

公開されている資料をかなり探しましたが、**水面や湿地が残っていた時代の蟹ヶ窪を地上から直接撮影した写真は確認できませんでした**。見つかるのは、すでに埋め立てられ、美久仁小路や商店ができた後の写真が中心です。

ただし、国土地理院では1945～1950年ごろの空中写真を閲覧できます。水面がはっきり残っている時代ではありませんが、周囲より低い土地や戦後直後の区画を確認する資料にはなります。citeturn604361search0turn604361search16
