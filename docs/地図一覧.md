# 水窪川・弦巻川・谷端川が描かれた地図一覧

水窪川・弦巻川・谷端川（小石川・千川などの別称を含む）の河道を確認できる、または確認候補となる地図を年代順に整理する。

このページは**書誌一覧ではなく読図索引**である。地図の所在・刊年だけでなく、「その地図上で各河川をどこまで確認できたか」を更新していく。詳しい書誌は [出典一覧](出典一覧.md)、各河川の解釈は [水窪川](水窪川.md)・[弦巻川](弦巻川.md)・[谷端川](谷端川.md) を参照。

> [!IMPORTANT]
> 古地図では小河川が省略されることがある。したがって、**図上で見えないことを、その年代に河川が存在しなかった証拠にはしない。**
>
> また、原図・デジタル画像・写真複製・印刷復刻では淡色の細線の見え方が大きく変わる。同じ地図でも、どの複製で確認したかを区別する。

## 判定記号

| 記号 | 意味 |
| --- | --- |
| **◎** | 河道を明瞭に確認済み |
| **○** | 河川とみられる水路を確認済み。名称同定や細部には留保あり |
| **△** | 候補線・二次読図などはあるが、原図上での同定が未確定 |
| **▲** | **掲載されているはず／別画像では線を確認できるが、現在参照している複製・画像では見えない、または判読困難** |
| **×** | 対象範囲を確認したが、図上では河道を確認できない |
| **?** | **未確認**。そもそも該当箇所を十分に読図していない |
| **—** | 地図の範囲外、または対象河川を扱わない図 |

**▲ と ? は別扱いにする。**  
▲ は「あると考える根拠はあるが、画質・複製・印刷などのため今見ている資料では読めない」、? は「まだ調べていない／判断材料が足りない」という意味。

## 河川別の時系列

### 水窪川

1682 ○ → 1687 ○ → 1772 ? → 1817 ? → 1851 ? → 1883–84 △ → **1909 ◎** → 1912 ○

江戸前期の1682・1687年図と、近代の1909年図の間がまだ薄い。とくに1817年『江戸府内実測図』で水窪川側を改めて確認する価値がある。

### 弦巻川

1682 × → 1687 × → 1772 ○ → **1817 ▲** → 1851 ○ → 1857 △ → 1883–84 △ → **1909 ◎**

1772年村絵図と1851年切絵図の間に1817年『江戸府内実測図』が入る。ここは、**デジタル画像では淡線が見えるのに復刻印刷では見えにくい**という複製差があるため、今後の重点確認対象とする。

### 谷端川

1682 ? → 1687 ? → 1801 △ → 1817 ? → 1883–84 ? → **1909 ◎** → 1912 ○ → 1916 △

近世の谷端川については、1801年巣鴨村図の原図確認と、それ以前の村絵図・江戸外縁図の探索が必要。

## 複製・画質に関する注意

### 1817年『江戸府内実測図』

2026年9月29日の確認では、ネット上の高解像度画像で雑司ヶ谷付近に見える淡い細線が、人文社の復刻印刷ではほとんど見えなかった。したがって、この地図については当面、

- **原図に線がない**
- **撮影段階で弱くなった**
- **製版・印刷段階で淡色線が飛んだ**
- **別写本で描写差がある**

を区別する。復刻版で見えないことだけを根拠に「河川が描かれていない」と判定しない。

### 『江戸復原図』

店頭確認では河川線を追う用途には向かなかった。町割・寺社・道路と現在位置を照合する補助資料としては使えるが、**3河川の河道索引の主資料にはしない。**

## 更新方針

新しい地図を確認したら、少なくとも次を記録する。

1. 地図名・年代・縮尺
2. 水窪川／弦巻川／谷端川の判定記号
3. どの区間を確認したか
4. 原図・デジタル画像・復刻版のどれを見たか
5. 公開URLまたは所蔵先
6. 「河川名が明記されている」のか、「位置から河川と同定した」のか
7. 見えない場合は **▲（掲載推定・判読困難）／×（図上で確認できず）／?（未確認）** のどれかを必ず分ける
