# 1912年地籍図読図・引継ぎメモ（2026年10月19日現在）

## 調査の核心
本プロジェクトの主眼は**護国寺創建（17世紀後半）前後に弦巻川の護国寺周辺流路が現在知られる西側の経路へ整備・変更されたのか**を解明すること。1912年の地籍図で確認した二流が近世初期から存在したかどうかは、別問題として区別する。江戸初期の地図・文献・地割・発掘史料の照合が必要。

調査対象：**水窪川・弦巻川・谷端川（西大下水・小石川）・人参川**、および**東大下水・旧神田上水・蟹川とその支流候補**。
主な資料：東京市区調査会『東京市及接続郡部地籍地図』上巻（1912年）、国立国会図書館デジタルコレクション [PID 966079](https://dl.ndl.go.jp/pid/966079)。コマ番号は冊子内の**画像コマ番号**であり、書籍の印刷ページ番号とは区別する。個別図：`https://dl.ndl.go.jp/pid/966079/1/<コマ番号>`。

## 1912年地籍図での主要観察
全コマの細かな観察事実・座標は [谷端川.mdのコマ別一覧](谷端川.md) を参照。以下は再開用の概略。

- **512〜535コマ**：谷端川を後楽園付近から小石川植物園周辺まで追跡。528〜533コマで谷端川本流と別の**東大下水系の可能性がある水路**を観察。533コマの指ヶ谷方面の上流端候補は 35.730152, 139.740712。535コマで谷端川の分岐・島状区画（35.721924, 139.739104）と直角屈曲（35.724377, 139.737553）を記録。
- **536〜541コマ**：水窪川の護国寺北・東側。538コマでは流路に着色がない例があり、539〜541コマでは**着色と河道線・地番境界の位置のずれ、二股に見える不正確な着色**がある。**色塗りだけで実際の河道・分岐を断定しない**。
- **542〜543コマ**：播磨坂東側・植物園南側の谷端川。543コマは 35.718856, 139.742543 付近で二度屈曲。**544〜548コマ**では河川を確認できず（図にないことは川が存在しない証明ではない）。
- **549・551コマ**：色だけ残り、黒い線描・文字等が欠落して見える不可解なページ。河川の有無は**判定不能**。**550コマ**は金剛寺付近で河川を確認できず。
- **552〜553コマ**：人参川下流域・拓殖大学周辺に着色／道路沿いの水路らしい描写。**1912年に開渠が存在したかは未確定**。1915年永井荷風『日和下駄』に金剛寺坂下の下水を「人参川」と呼ぶ同時代の記述がある。[人参川.md](人参川.md)。
- **556〜559コマ**：久世山・小日向水道町。556コマの 35.709928, 139.735237 付近に旧神田上水らしい着色、神田川は別に描写。558コマでは**弦巻川と旧神田上水候補の双方が近い位置で途切れる**ため、両者の接続を疑う。**実際の合流・伏樋・廃水路跡の区別は未決着**。557・559は明るい版のように見える。
- **560〜564コマ**：水道端町付近の南北の水路候補２か所（35.710075, 139.740012／35.708782, 139.742331）は1921年の1万分1地形図にも対応する筋が見えるとの比較報告。563コマで東側の筋が神田川に接続するように見える。564コマは蟹川の合流と、他の地形図には見えない支流らしい線。561には神田川、562は明るい版。
- **565〜571コマ**：**566〜569コマで護国寺南から音羽谷の水窪川と弦巻川の２河川を連続して確認**。1912年図と1921年の1万分1地形図で東西二流の配置が整合。569コマには**川なのに着色が不完全な部分**がある。565・570は明るい版。567コマ（音羽2・3丁目）には「附属横坂」付近の橋がまだ見えず、現講談社周辺に「佐藤某邸」と読める屋敷名があり、以前話題の池は確認できない（池の地点同定・消失時期は不明）。571コマには**今宮神社前の橋**と**弦巻川最下流の西向きの急屈曲**が描かれる。旧神田上水との接続かは未確定。
- **572〜573コマ**：大洗堰・江戸川橋西側の神田川南岸に枝流候補。573コマの 35.709719, 139.728268 付近の水路は**蟹川の支流か独立した川か未同定**。
- **574〜578コマ**：574・578は明るい版との観察、575は音羽5・6丁目西側目白台の**弦巻川**、576は椿山荘付近の神田川、577は音羽7・8丁目西側の目白台（河川の有無については未報告）。
- **579〜581コマ**：579・580は**目白台**との位置報告のみ（河川の有無は未判定）。**581コマ（旧東京盲学校・腰掛稲荷神社付近）は弦巻川が明瞭**。現在の護国寺西交差点付近の崖下には**弦巻稲荷神社**（マンション階段踊り場の小祠）がある。崖上の腰掛稲荷とは別の神社。**創建年代・社名が川名に由来するか・1912年当時の所在は未確認**。2019年[現地紹介](https://sanpo-nikki.com/shrine/tsurumakiinarijinja/)／[筑波大学附属視覚特別支援学校の公式沿革](https://www.nsfb.tsukuba.ac.jp/kisyukusya/sya_0_d.html)。

## 史料の読み方・注意
- **直接観察**（利用者が原図・現代地図を見た）と**仮説**（その線が特定河川、旧神田上水との合流、旧河道の開削年代など）を混ぜない。
- 地籍図では**黒い描線、道路、地番と着色の位置が一致しない例**が多数ある。色の欠落だけを水路の不存在とみなさない。逆に着色だけで開渠の存続としない。
- 明るい版（557, 559, 562, 565, 570, 574, 578など）が、同図郭の別版なのか撮影・印刷濃度の違いなのかは未確認。549・551の黒色欠落問題は別に扱う。
- 1901年以後も旧神田上水の一部（巻石白堀）が工業用水として維持された記録がある。だから**1912年に水路敷が描かれていても不思議ではない**が、弦巻川の当該合流点で通水していたかは未確認。[弦巻川.md](弦巻川.md)／[出典一覧.md](出典一覧.md)。
- **弦巻稲荷神社の存在は地名・谷筋の記憶の手掛かり**にすぎず、旧流路位置や護国寺創建当時の河道の証明にはならない。

## 次の作業
1. 1912年地籍図は**582コマ以降**を必要に応じ確認。581までの詳細は[コマ別一覧](谷端川.md)にある。
2. **581コマの弦巻川と弦巻稲荷の位置**を現代地形・筆界で重ね合わせる。575コマ（目白台）や566〜571コマ（音羽）の流路と接続するか検証。
3. **571コマ西向き屈曲・558コマ旧神田上水候補**を1883年五千分一東京図、1909年・1921年一万分一地形図と比較。神田川へ直接合流したか、旧神田上水へ注いだか、伏樋で交差したかを分ける。
4. 調査の核心である**護国寺創建前後**について、1682/1687年図、1772年雑司谷村絵図、1817年江戸府内実測図、1851/1857年切絵図等の描写と護国寺創建関連の工事・寺域記録をさらに精査。
5. 旧音羽谷の池（35.717529, 139.728814）、講談社付近の別池候補、旧「佐藤某邸」の**地番・位置を区別**し、同一地物を勝手に結びつけない。
