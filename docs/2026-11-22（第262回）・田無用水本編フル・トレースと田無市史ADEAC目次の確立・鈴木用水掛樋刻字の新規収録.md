# 2026-11-22（第262回）田無用水本編フル・トレースと田無市史ADEAC目次の確立・鈴木用水掛樋刻字の新規収録

第262回の定期調査記録。前回までの経緯は[第261回ノート](2026-11-22（第261回）・西東京水路跡散歩36本の掃引完結と小金井分水の案内板年次文言・田柄用水全流路の新規収録.md)（追加調査分を含む）参照。本回は第261回ノートの積み残し（musasinowalker田無用水本編の未取得・田無図書館パネル82番系の田無市史関連）を実行し、**田無用水（新堀用水）本編4本＋田無用水を扱う独立ブログ3系統＋『田無市史』（ADEAC）の目次構成確立**を行った。両者の接点は「田無市史の引用文言」であり、田無用水・田柄用水・田無新田用水（いずれも第260〜262回で新規に体系化した玉川上水系田無周辺用水群）の文献側原典が『田無市史』に集中しているという状況の把握が本回の構造的な成果である。

## 既存仮説との相互関係〔観察〕

- **明治3〜4年の田無周辺水利再編の像がさらに強まる**: 新堀用水の明治3年（1870）4月・8か所分水口統合（BLOG-282＝第3系統文言）に、1870年南部水路取水口の砂川用水統合（BLOG-275＝小金井分水）・1870年ごろ境村区間整備〔筆者推定〕（BLOG-277）・田柄用水1871年開削（BLOG-278・[GOV-098](sources/gov/GOV-098.md)明治4年）・千川用水直引取廻達（[GOV-100](sources/gov/GOV-100.md)明治4年）が並び、**田無・小金井一帯の明治3〜4年（1870〜71）水利再編が多系統の観察で共鳴する**（因果関係・全体像の統一的説明はまだ史料がないため、「再編期」という呼び方にとどめる）。
- **田無用水の起点文言の分布**: 「元禄9年（1696）喜平橋取水」（案内板文言・BLOG-281/282両方に現れる）は既存の小金井分水1696年系4系統と同年代で、**元禄9年＝1696年前後の玉川上水系分水の波**（山王窪築樋1696年・小金井分水1696年・田無用水元禄9年）として並べられる〔いずれも伝聞・案内板文言で原典確認は今後課題〕。
- **はけ口・流失点の位置の収束**: BLOG-283の南町調整池比定（昭和写真）＋BLOG-281の南水路末流（文化橋→トンネル→南町3丁目側）＋BLOG-282の南町3丁目石神井川合流点＝**三系統が石神井川旧河道（南町側）へ向かう流失点で緩く一致**する（昭和中期以前の正確な落下点は未確定のまま。御嶽菅笠1834年図が最早期の候補資料）。
- **田無市史という文献原典の位置づけ**: BLOG-284の文言群（樋口四寸四方・七か所水車場・体内ボリ等）がすべて『田無市史』経由であることが明示されたことで、田無用水系の観察記録の多くは**「田無市史→ブログ引用」の系譜**だと判明した。ADEACの本文画像照合（pagecodeあたり）で原典文言を直接確認することが、田無用水群の年代・規模の断定可能性を決める。
- **橋場（田無）の地名**: BLOG-285の「用水に街の手前で架けた橋」という由来説は、青梅街道橋場で田無用水が南北分流する位置（BLOG-281）と対照できる〔地名由来はいずれも「説」〕。
- **石神井川（田無市域）の流路変遷**: BLOG-281（文化橋・南町側接続の変遷）・BLOG-283（はけ口・津島神社の流路）・BLOG-284（石神井川の水車）が**石神井川の昭和後期改修を挟む前後像**（明治水車→昭和はけ口写真→現況）を供給した（repoの石神井川行には「流路変遷観察群」として追記）。
