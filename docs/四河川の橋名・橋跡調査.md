# 四河川の橋名・橋跡調査（2026-11-10現在）

対象は水窪川・弦巻川・谷端川・人参川。**史料上の固有橋名**、**無名の渡河施設**、**後年の橋跡・装飾橋・跨線橋**、**近隣の神田川・神田上水の橋**を混同しない。以下の数は「史上の全橋数」ではなく、**確認できた資料に現れる件数**。一次資料未見の引用には留保を付す。

## 水窪川

- **地震橋**：『御府内備考』巻之五十「護国寺領三ケ町」**東青柳町**の川項目に「地震橋、石橋、長九尺程・幅二間半、前出の川に懸る」趣旨の記述を確認済み。水窪川側と対応する根拠がある。リポジトリの[GAZ-013](sources/gazetteers/GAZ-013.md)（AIによる国立国会図書館刊本画像の読取）。[「水の行方を追って」](https://wanjin.blog.fc2.com/blog-entry-4.html)は不忍通り・富士見坂下で「芋洗橋（または地震橋）」と紹介するが、**芋洗橋という別称自体は現段階で二次資料**。
- **今宮橋**：今宮神社鳥居前、旧水窪川横断部。床版とされる石板を現地記事が記録。[本田創・文春オンライン（2021年）](https://bunshun.jp/articles/-/50033?page=5)、既存[水窪川ノート](水窪川.md)の1912年地籍図571コマの橋描写参照。床版・石材の施工年代は別途確認する。
- **「江戸川橋」読図候補**：鼠坂下付近、水窪川横断箇所の五千分一東京図原図系画像を利用者が判読。いったん「上江戸川橋」とした読みは撤回済み。**原字形再読・神田川に架かる同名橋との識別を要する**。[水窪川](水窪川.md)、[2026-10-09現地観察](2026-10-09・茗荷谷・人参川現地観察.md)。
- **周辺の追加調査候補**：同『御府内備考』巻之五十の音羽町各丁目・桜木町には「壱貫橋」「丸太橋」「駒止橋（旧称鼠ケ谷橋）」「九丁目橋」等の記載あり。[GAZ-013](sources/gazetteers/GAZ-013.md)。現在、東側水窪川・西側弦巻川・神田上水のどの渡河施設かを**未確定**とし、上の2件に加算しない。「九丁目橋」は神田上水に懸かるとされる。また「関口橋」「江戸川橋」「音羽花水橋」は周辺の神田川・旧神田上水の橋との区別が必要。[BLOG-021](sources/blogs/BLOG-021.md)。

## 弦巻川

- **1853年『雑司ヶ谷村ほか沿革起立書上』の二次転記**：上流から次の**12施設**を列挙する。
  1. 卒トハ橋（卒塔婆橋、小橋）
  2. 石橋（名不詳）
  3. 小土橋（名不詳）
  4. 土橋（名不詳）
  5. 鎌倉橋（石橋）
  6. 木村橋
  7. 南坂橋（小橋）
  8. 丸太投渡橋（固有名ではなく構造の説明か）
  9. 弦巻橋（板橋）
  10. 松屋橋（石橋）
  11. 境橋（石橋）
  12. 石橋（名不詳）

  **固有名称が読み取れるのは7名称**（卒塔婆・鎌倉・木村・南坂・弦巻・松屋・境）。列挙順・史料名は [kazuaruki「雑司ヶ谷村用水」](https://ameblo.jp/kazuaruki/entry-12940940738.html) による**二次転記**であり、柳下家文書の原史料画像は未照合。既存[弦巻川](弦巻川.md)、[江戸名所図会・護国寺図の検討](江戸名所図会・護国寺図の検討.md)には護国寺南西端の橋＝弦巻橋という**仮説**がある。
- **松屋橋の独立裏付け**：1829年『御府内備考』巻之五十の**西青柳町**に松屋橋（石橋、長九尺・幅一間ほど）の記載。[GAZ-013](sources/gazetteers/GAZ-013.md)。上の1853年橋名一覧の存在を独立に補強するが、両年の橋材・位置の継続性は未確定。
- **星谷橋**：『江戸名所図会』の「星谷の井」下流の橋。弦巻川本流上ではなく支流・小流路上の可能性を残す。1853年の12施設に機械的に加えない。[護国寺星谷の水系](護国寺星谷の水系.md)。
- **構造と場所の補助**：清立院前の「当所石橋施主木村氏」碑は木村橋比定の手掛かり。[「水の行方を追って」弦巻川](https://wanjin.blog.fc2.com/blog-entry-24.html)。1772年村絵図、1851年切絵図、地籍図との接合が課題。

## 谷端川

- **基本書誌**：豊島区立郷土資料館友の会『旧谷端川の橋の跡を探る』（**1999年12月、35頁**）。[CiNii書誌](https://ci.nii.ac.jp/ncid/BA46331735)。豊島区広報（**2000年1月21日**）が**源流から流末までの有名・無名67橋**を取り上げたと明記。[区公式PDF](https://adeac.jp/viewitem/toshima-history/viewer/viewer/pressH120121/data/pressH120121.pdf)、[GOV-007](sources/gov/GOV-007.md)。基礎となる連載は清水治男「谷端川橋名私考」（1989〜92年）と田崎不二夫の続編（1993〜96年）。**冊子・連載の現物未読**。

- **緑道区間以外の橋名例**：宮原橋、松浦橋、宮仲橋、猫貍橋（猫又橋・猫股橋等の異表記）、一木橋（旧称一本橋との伝承）、氷川橋、久竪橋、熊野窪橋、姿見橋など。資料と図上位置は[Natrium.jp（谷端川周辺水路）](https://natrium.jp/canal_lot/yabata/yabata08/index.html)、[同・小石川](https://natrium.jp/canal_lot/yabata/koishikawa/index.html)、[谷端川の跡を歩く](https://warpal.sakura.ne.jp/river-yabata/top-map.htm)、[既存の谷端川ノート](谷端川.md)を参照。同名の現役道路橋や跨線橋（とくに宮下橋・宮仲橋）を誤同定しない。
- **確認すべき核**：1999年原冊子の全67件を【原掲載名／異表記／出典／現代地番／座標／出典の性格／当初架橋年と調査年】で転記してから、2026年の32構造物との重複を照合する。恣意的に67＋32としない。

## 人参川

- 現状で原史料に裏付けられた**固有橋名は未収録**。[人参川](人参川.md)には茗荷谷・拓殖大学東門付近の池と二筋の流れ、橋らしい図像への言及があるが、地元ブログ[「昔の茗荷谷」](https://kai-wai.net/myogadani/2015/09/15/%E6%98%94%E3%81%AE%E8%8C%97%E8%8D%B7%E8%B0%B7/)に基づく二次読図である。橋の固有名・人参川本流との対応・元の位置を断定しない。

## 次の調査優先度

1. **最優先：1999年『旧谷端川の橋の跡を探る』現物を確認**（区立図書館・郷土資料館、学習院大学図書館の書誌情報）し、67橋の原一覧を台帳化する。
2. **『御府内備考』巻之五十の音羽町一〜九丁目・桜木町の橋項目**を原画像から逐字採録し、水窪・弦巻・神田上水を分ける。特に壱貫橋、駒止橋、鼠ケ谷橋。
3. **1853年「雑司ヶ谷村ほか沿革起立書上」原本・影印**を確保し、12施設の列挙順と橋の位置・材質を確定する。
4. **人参川**に関する明治五千分一図、地籍図の橋記号と番地・道を重ね、名称史料の探索対象を絞る。

### 注意

この文書は調査時点の**検証進度一覧**で、近世・近代に実在した橋梁の総数ではない。「現在の川跡に架かる道路」「橋の存在」「史料中の固有名」「旧名の継承」は別々に検証する。
