# 弦巻川中流の行き止まり路地と池袋上流三谷合流の読図・リサーチセッション（2026年11月21日）

2026年11月21日のチャット調査の記録。写真の原本はリポジトリに転載していない（踏査一覧の規則に従う）。

## 1. 弦巻川中流・雑司が谷付近の未舗装の行き止まり路地〔観察＝踏査一覧F17〕

2026年11月21日にチャットで4枚の写真が共有された（撮影・訪問日は未確定）。座標**35.720566,139.717773**付近（GPS誤差の余地あり）。観察の概要：

- 未舗装の行き止まり路地。片側に約2mのコンクリート擁壁、反対側に古い建物の壁。
- 白い円柱形の構造物（高さ約1m・径約20cm）。**下水道換気柱の有力候補**だが、刻印は写真では確認できない。
- 小さなコンクリート構造物、路地の草木、格子フェンス越しに煉瓦壁と石灯籠らしき白い柱。
- 路地の奥には**三角形の側面開口のある低いコンクリートの箱**（高さ約50〜70cm・幅約1m・内部は浅い空洞に土砂・蓋の跡なし・刻印なし）。廃止された排水ます（枡）か管渠の吐口跡の可能性。上面開口がなく浅いので防火水槽の可能性は低い。白い円柱（換気柱候補）と合わせて、水まわりの小設備が路地の奥にまとまって残る構図〔観察の候補、用途は未特定〕。

**位置の解釈〔候補〕**：弦巻通りの南1〜2ブロックは、暗渠化時の付け替え前の旧流路帯とする読図がある（[BLOG-002](sources/blogs/BLOG-002.md)）。当路地はその帯の中流域にあたる可能性がある。一方、[BLOG-002](sources/blogs/BLOG-002.md)が紹介する、1ブロックだけ文京区が弦巻通りの北側にはみ出している部分の**区境沿いの未舗装小道**（水路敷かどうかは筆者自身「わからない」とする）との異同は未確認。

**判断の留保**：換気柱と確認できれば雑司ヶ谷幹線（＝暗渠化された弦巻川）上かそれに近い位置の傍証になりうるが、刻印（「下水」「雑幹」等）の現地確認が前提。擁壁・行き止まり路地だけでは造成や現代下水でも説明可能で、旧水路敷の確定根拠にはならない。

## 2. 南池袋・上流合流域の読図〔仮説の記録〕

検討地点は座標**35.723666,139.710782**（池袋駅南・大ガード〜明治通りの間）。

- **確認された事実〔観察〕**：東京時層地図の当該地点では、川の描線は確認した全レイヤーで**北側の直線流路**に一致していた。
- **当事者の読み〔仮説A〕**：南側の曲がりくねった細い現道こそ本来の流れで、図上の北側線は本来の川とずれているのではないか。
- **分析〔留保〕**：
  1. 迅速測図→明治42→大正の各レイヤーは同じ原図系統の流用の可能性があり、独立証拠としては弱い。
  2. 「旧図の北側川＝付け替え前×南の現道＝付け替え後（暗渠化された川）」という時代差説（仮説B）でも図と現道の関係は両立する。
  3. [BLOG-002](sources/blogs/BLOG-002.md)の三谷合流の読図（2026年11月21日追記）によれば、この地点は**3つの谷筋の合流域の内部**にあたる。南北のずれの議論は、合流域での谷筋の再編として整理し直す余地がある。
- **未解決**：仮説A・Bいずれも確定していない。決め手は明治44年高田村全図（[MAP-035](sources/maps/MAP-035.md)）・大正15年明細図（[MAP-037](sources/maps/MAP-037.md)）の原図レベルの照合、1947年米軍写真（[MAP-126](sources/maps/MAP-126.md)〜[MAP-128](sources/maps/MAP-128.md)）の判読、現地の蓋の刻印確認。なお1912年地籍地図には池袋村シートがなく（[弦巻川.md](弦巻川.md)の2026年11月9日確認）、この経路での区画照合は不可。
