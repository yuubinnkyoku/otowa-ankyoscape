# 第334回（2026-11-26）: TOKYOアーカイブ横断掃引（「上水」67件）＝尾張屋板切絵図2点・玉川上水絵図2点の所在特定（MAP-225〜227新規・MAP-022追記）

姉妹川（水窪川・弦巻川・谷端川・千川）定期調査の第334回。本回はTOKYOアーカイブ（東京都立図書館デジタルアーカイブ）の横断掃引を主体に実施し、地図3件の新規収録（MAP-225〜227）とMAP-022の追記を行った（総数1850→1853・地図224→227）。確認・観察・推定・仮説の区別は本文中に明記する。

## 1. TOKYOアーカイブ横断掃引の経過と技術メモ

### 1.1 検索レシピ（再構築・確認済み）〔確認〕

- 一覧検索: `GET https://archive.library.metro.tokyo.lg.jp/da/result_s?q=<URLエンコード>` → 応答HTMLから `moveDetail('{tilcod}')` を抽出。
- ページ送り: `GET /da/result?q=<enc>&start=<N>&mode=result`。
- 詳細頁: `/da/detail?tilcod={id}` の `<th>`/`<td>` から書誌。
- 画像リスト: `POST /da/ajax/image`（body: page=0&start=0&tilcod={id}）。

### 1.2 川名キーワードの技術的制約〔観察・本回の重要メモ〕

- 千川・谷端川・弦巻・水窪などの**川名系キーワードはサーバ500/000エラー**（接続断）。一方で小石川・高田・池袋・上水・用水・鬼子母神・護国寺・六義園・雑司ケ谷などでは200が返る。以降の掃引では川名そのものを避け、アーカイブ側のキーワード設計（地域名・施設名・「上水」「用水」等）に合わせる必要がある。
- 「上水」で67件（第330回の走査と称する20件から増加。**検索範囲・ページ送りの設定差の可能性があり、両走査の同定は今回は行わず断定しない**〔観察〕）。

### 1.3 掃引結果の整理

- 67件を全走査し、四河川・千川に関係する可能性のある資料を書誌レベルで仕分けた。
- 皇居（明治宮殿）水道設備図面群20点・近代東京都水道局刊行物群・江戸川上水道誌群（墨田区系）は**スコープ外見送り**（repoの対象が千川上水・神田上水・玉川上水系の武蔵野〜東京西北部であるため。ただし明治宮殿群は城内水道の研究進展時の再検討候補としてノートにのみ記録）。
- 神田上水3点＝[MAP-205](../sources/maps/MAP-205.md)/[MAP-206](../sources/maps/MAP-206.md)/[MAP-207](../sources/maps/MAP-207.md)既収録。
