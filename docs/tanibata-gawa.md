# 谷端川

谷端川について、現在までに確認できた主要事項をまとめる。詳しい出典番号・調査経緯は [分割前README全文](research-notes-full.md) を参照。

## 水源と流路

谷端川は、要町の粟島神社境内にある弁天池の湧水を水源とし、椎名町方面へ南下したあとU字状に大きく向きを変え、板橋・大塚・小石川を経て神田川へ流れた河川である。

大塚以南では「小石川」「礫川」などの名が使われ、資料・地域によって「氷川」の呼称も見られる。

## 千川上水からの分水

谷端川は千川上水から実際に分水を受けていた。要町3丁目付近から南東へ分かれる「長崎村外三村分水」が、粟島神社の池を水源とする谷端川へ接続していたことが公的資料で確認できる。

したがって、

- 千川上水 → 谷端川：〔確認〕
- 千川上水 → 弦巻川：〔未確認〕
- 千川上水 → 水窪川：〔未確認〕

と区別する。

## 近代の利用と改修

1895年には、巣鴨新田の谷端川へ水車を新設する計画が東京府へ申請されたが、地元地主の反対で不許可となった記録がある。これは水車の実在記録ではなく、具体的な水力利用計画の記録である。

谷端川の改修・暗渠化は一度に完了したのではなく、下流部から段階的に進んだ。河川廃止後は暗渠上が児童遊園や緑道へ転用され、現在の谷端川南緑道・北緑道につながっている。

## 池袋モンパルナスとの関係

谷端川沿いには戦前のアトリエ群が形成され、現在も「谷端川アトリエ群跡」など、池袋モンパルナスと旧河川地形の関係を示す場所が残る。

旧河川沿いの低地と、アトリエ村・町工場・鉄道などの土地利用を重ねると、谷端川は単なる水路史だけでなく、池袋周辺の都市形成を読む軸にもなる。

## 現在の下水道幹線

谷端川の名を引き継ぐ下水道幹線は、現在の都市基盤・浸水対策の一部として利用されている。旧河道と現在管路の一致は、下水道台帳や旧版地図で区間ごとに確認する必要がある。
