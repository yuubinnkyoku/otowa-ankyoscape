# 第266回資料ノート（2026-11-22）: 廣瀨裕之研究群の書誌確定（教職研究センター紀要の正確な号年・田無碑論文のNDL所在・BOOK-283）・増補版目次の章記録

## 本回の方針と概要

第265回で所在確定した廣瀨裕之の田無・小金井金石文研究群（[PAP-103](sources/papers/PAP-103.md)石盥考・[PAP-104](sources/papers/PAP-104.md)桜樹接種碑考・[BOOK-281](sources/books/BOOK-281.md)/[BOOK-282](sources/books/BOOK-282.md)単著書）の残課題（紀要第3号の「養老田碑と賀陽玄順の書」の所在・所収書の実体）を、NDLサーチSRU API・武蔵野大学図書館の紀要目次頁・出版社（世界思想社）書籍ページの3系統で横断確認した。結果として**新規2件（[PAP-105](sources/papers/PAP-105.md)・[BOOK-283](sources/books/BOOK-283.md)）＋追記3件（PAP-104・BOOK-281・BOOK-282）**を反映した。
