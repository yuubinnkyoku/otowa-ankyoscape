# 2026年11月10日・1948年米軍写真M737-72：人参川候補谷筋南（神田川合流まで）の判読

## 目的

人参川候補（茗荷谷・古茗荷谷川）の**谷筋南側**——谷頭（35.715）から小石川・後楽北を経て**神田川合流部（≈35.709）**まで——を戦後写真で確認する。1947年 [M372-52](../sources/maps/MAP-153.md) は下縁が 35.7123 で谷筋南を覆わず、[M737-141](https://service.gsi.go.jp/map-photos/app/map?search=photo&id=11540) も谷頭止まり（下縁 35.7116）で南を覆わない。GSI空間検索（lon 139.727–139.741 / lat 35.704–35.714 / 1945–50）で**谷全体を覆う USA-M737-72（spec 189222）**を発見し、これを判読対象とした。

## 対象コマと方法

- **USA-M737-72**（[MAP-154](../sources/maps/MAP-154.md)）：1948/01/18、約1/9,980・**0.63 m/px**、K-17B、文京区。範囲 lat 35.6996–35.7206 / lon 139.7215–139.7472。
- 標準版（3937×3780・グレースケール・北方位）をダウンロードし、API四隅→内容ピクセル四隅のホモグラフィで位置合わせ。**全体オーバービュー（z16相当）＋谷頭東・谷筋・合流部の源解像度クロップ（2倍拡大）**を目視判読。画像は転載せず、ビューアリンクと本メモのみ残す。
- 幾何誤差は約100〜300m。小流・小水面・樹冠下は検出限界。**見えないことを不在の証明としない**。

## 観察

- **受水側の神田川は明瞭**：東西方向の**暗い開水面帯**が橋を伴って横断（≈35.709）。右（東）縁にも南北方向の水面帯（江戸川系）。**幅の広い神田川は0.63 m/pxで検出できる**。
- **谷頭東（拓殖大付近・35.715）**：明るい**大型の施設建物（キャンパス候補）**と周囲の**矩形区画（畑地／空地）**、**暗い不整形パッチ**（池・樹林・影の別は未確認）。明治期地図の池状表現（拓殖大東門付近）との対応は未照合。
- **谷筋（35.7115）**：**曲走する明るい道路**＋**矩形区画格子**＋散在建物。右下に暗いパッチ（性格未確認）。連続する開渠の描線はない。
- **合流部（35.7085・神田川南岸）**：**密集小住宅格子＋曲がる路地**。不明瞭な暗い曲線が走るが、路地か水路か判別できない。
- 全体として**密集市街地**で、1947年 [M372-52](../sources/maps/MAP-153.md) の谷頭「空地化／焼跡化」に対し、本コマの谷筋南は住宅が卓越（文京区の戦災が比較的軽かったことと整合）。

## 小結

1. **M737-72 は人参川候補の谷頭から神田川合流までを覆う初の戦後コマ**。M372-52（1947）・M737-141 が覆わなかった南側を補完する。
2. **受水側の神田川は開水面として検出できるが、支流の人参川候補は連続開渠を検出できない**。これは「幅の広い本流は見え、細い支流は見えない」という**検出限界の対比**であり、人参川候補が1948年に既に暗渠化・埋設されていた可能性と整合するが、不在を断定しない。
3. 谷頭の矩形区画・暗いパッチ、合流部の不明瞭な暗い曲線は、**池・樹林・影・路地のいずれかを判別できていない**。明治期池状表現・荷風「人参川」呼称（1915）との位置照合が次の課題。
4. 1936 [B7-C3-71](../sources/maps/MAP-152.md) → 1947 [M372-52](../sources/maps/MAP-153.md) → **1948 M737-72** の戦前・戦後三段で谷頭〜谷筋南の土地利用比較が揃った。ただし**いずれも人参川候補の開渠・池水面を確定していない**。
