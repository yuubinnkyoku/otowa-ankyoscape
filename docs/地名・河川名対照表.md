# 地名・河川名対照表

同じ場所・同じ川の別の呼び名を、関係の種類を区別してまとめた対照表。2026-10-26 作成、同日の追加監査（[2026-10-26・地名河川名対照表・追加監査](2026-10-26・地名河川名対照表・追加監査.md)）を反映して再構成した。**正規形は未決定**（利用者の決定で確定する）。出現数は 2026-10-26 時点のリポジトリ内 grep 件数（史料名・引用中の出現を含む。追加監査由来の名称は再集計していない）。

## 関係の種類

- **異表記**：同じ対象の表記の違い（弦巻川／鶴巻川、護国寺／護國寺など）
- **区間名**：対象の一部区間だけの名称（弦巻川上流の布引川、谷端川下流の小石川など）
- **伝承・限定名**：限られた史料・地域で伝えられる名称（鶴舞川、十町川など）。原本確認の有無を併記する
- **関連別対象**：別名ではなく、関係する別の対象（分水、支流、近くの水系など）
- **同一性未確定**：同じ対象を指すか未確定の対応（人参川／古茗荷谷川など）
- **範囲相違**：似た名前でも指す範囲が異なる地名（高田／下高田など）。別名として統合しない

## 統一方針（案）

- 本文で自ら言及するときの正規形は未決定。史料名・書名・引用文の中の表記は史料のまま変えない。
- 施設・霊園・駅などの正式名称はそのまま残す（例：現代町名は「雑司が谷」だが、霊園の正式名称は「雑司ケ谷霊園」）。
- 歴史的な別名は消さず、この表で結び付ける。初出で別名を併記してよい。
- **谷端川と谷田川は別水系**（谷田川は駒込・田端方面から不忍池へ向かう）。文字が似ていても統合しない。
