# 1956年米軍写真M316-70による谷端川上流の判読・開渠期高分解能コマの不存在確認（2026年11月9日）

## 目的と空間検索の方法

谷端川上流（椎名町・南長崎）の**開渠期（1951年改修〜1962年廃止）**を約1/10,000以下で写すコマは、既存の[空中写真目録](空中写真目録.md)（中心点ベース136コマ）には無い（開渠期は1/20,000以下のみ）。目録外のコースも含めて探すため、GSI検索APIの**空間検索パラメータ**をフロントエンドJSから特定して用いた。〔確認：map.js の getListParam 実装〕

- 点交差検索: `intersect_lat` / `intersect_lon`（指定点を撮影範囲が含むコマを返す）。
- 範囲検索: `lon_min` / `lon_max` / `lat_min` / `lat_max`（画像中心が範囲内に入るコマ）。
- 併用フィルタ: `search_date_from` / `search_date_to`（年）、`scale_from` / `scale_to`、`limit`。
- 従来の `bbox` / `lat` / `lon` / `north`… 等の推測名は**無効**（未フィルタの既定200件を返す）。

## 開渠期・高分解能コマの不存在（確認事項）

- 点交差検索（35.724,139.690／35.726,139.694／35.722,139.686 の3点、1950〜1963）で返るコマのうち**約1/10,000以下は1963年MKT636（廃止後）のみ**。開渠期（1951〜1962）は 1956 M316/M318/M324（約1/19,703〜1/20,000）・1957 M1010R1（約1/20,000）・1961 KT611YZ（約1/25,000）・1952 M10-21-2（約1/40,352）のみ。
- 範囲検索（経度139.678〜139.708・緯度35.714〜35.741、1949〜1962、limit500）でも**約1/12,000以下は0件**。
- したがって**谷端川上流の開渠期を約1/10,000以下で写すコマはGSIデータベースに存在しない**。開渠期の最高分解能は約1/20,000（約1.27 m/px）。〔確認：空間検索の結果〕

## 判読対象と方法

開渠期の最高分解能として **1956/03/08 USA-M316-70**（[MAP-147](sources/maps/MAP-147.md)、約1/20,000、中心35.72242,139.68084）を選択。四隅は経度139.655〜139.706・緯度35.7015〜35.7433 を覆い、谷筋核心（約139.688,35.724）を内側に含む。標準版400dpi（3780×3937px）を取得。**スキャンが180度回転**していたため回転補正後、API四隅→内容像素の8パラメータ homography で Web Mercator z16 に逆ワープし、谷筋核心のクロップ（約1.75×2.1km）と谷筋帯の3倍拡大クロップを判読した。〔確認：標準版画像の判読〕

## 観察

- **土地利用は混在（市街化途上）**：北・中心部に密集住宅ブロック、南・所に**矩形農地が残存**。1948年（[MAP-140](sources/maps/MAP-140.md)・[MAP-141](sources/maps/MAP-141.md)・農地卓越）と1961年（[MAP-143](sources/maps/MAP-143.md)・密集市街）の**中間段**。
- **谷筋**は樹林帯の低い谷（帯状暗部）と**細い線状地物**（河道・園路の候補）として読めるが、**連続する開渠の水面描線は確認できない**。約1.27 m/px では幅数mの開渠は検出限界。〔留保：検出限界／幾何誤差約100〜300m・スキャン回転補正後の位置合わせ暫定〕
- 大規模焼跡・広い空地は目立たない（戦後復興済みの市街縁）。

## 小結

- **市街化の開始を1948〜1956年に絞り込み**：1956年に既に密集住宅と農地の混在＝市街化は1956年までに進行中。完了は1961年（[MAP-143](sources/maps/MAP-143.md)）。主体は**1948〜1961年**のうち前半（1948〜1956）に着目すべき段階にある。
- **開渠の姿は依然未確認**：開渠期最高分解能でも約1/20,000（1.27 m/px）で検出限界。**約1/10,000以下の開渠期コマは存在しない**ため、開渠期の河道描線は空中写真からは確定できない。今後は地上写真・工事記録・河川台帳等の別史料、または1/20,000コマの線状地物の同定（河道か園路か）に委ねる。〔未解決〕
