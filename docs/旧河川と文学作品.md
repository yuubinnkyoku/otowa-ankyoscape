# 水窪川・弦巻川・谷端川・人参川と文学作品

調査日：2026年10月27日。四河川を扱う小説・随筆・詩歌・小唄・紙芝居・教育記録の横断調査。

関連：[詩歌の先行調査](旧河川と詩歌.md)／[地名・河川名対照表](地名・河川名対照表.md)。

## 判定基準・調査範囲

- **川名直接**：作品の題・本文に、対象河川の固有名・地域限定の別名が登場する（ただし同名異河川・地名との一致を照合する）。
- **河道描写・比定候補**：固有名はないが、地形・橋・街路・流向から該当する可能性が相当程度ある。確定例と混ぜない。
- **流域・周辺**：地域の坂・谷・風物の描写のみ。河川の存在・経路を示した作品とは扱わない。
- **未確認・二次報告**：出版・目次等は確認できても本文未閲覧の場合、描写の内容を断定しない。
- 文学作品を地理史料に転用する際は、**作品の成立・発表年、描かれた時代、作者の記憶の時期、再録時の改稿**を分離する。
- 検索時には水窪／水久保／日の出／音羽／東青柳下水、弦巻／鶴巻／布引／鶴舞、谷端／矢畑／小石川／礫川／氷川／西大下水／十町川、人参川／古茗荷谷川に加え、寺・橋・坂・旧町名で検索する。
- 同音異義語に注意：**谷端川と駒込方面の谷田川は別水系**、「音羽川」は京都等にもある、「小石川」は地名にもなる。「水窪川」は静岡県浜松市水窪の川の名称でもあり、東京と混同しない。
- **網羅性の限界**：公開された全文と書誌・既存調査を中心にした調査であり、未電子化雑誌・自費出版・同人詩誌・寄贈資料までを完全に探索したという意味ではない。

### 田村隆一の「谷端川」の読みの変遷

先行調査 [BLOG-014](sources/blogs/BLOG-014.md) は初出と再録を比較し、次の異同を報告する。

- 1981年『年金と住宅』21号「夜の帽子」・1982年23号「武州大塚のエピソード」：初出はルビなし。
- 1982年25号「田園交響楽」・1996年『ユリイカ』掲載「東京の田舎」：「たにはがわ」。
- 1988年『青春と読書』「あとはなんにもない」：「たにばがわ」。
- 1991年『新潮45』「退屈無想庵（五）緑の旧道」：「やばたがわ」の記載例。
- 1987年に巣鴨小学校訪問で「やばたがわ」の読みを教えられたとされるが、1988年刊『ぼくのピクニック』および後年再録の一部では「たにはがわ」の読みが残る。
- **これらは2020年の先行研究による原本対比の報告であり、今回すべての雑誌原本を確認したわけではない。** どの初出・再録の表記か必ず併記して利用する。

### 荷風が列挙した四つの谷

1947年『葛飾土産』[BOOK-030](sources/books/BOOK-030.md) で、荷風は小石川区の溝川を複数並列する。そこに「植物園門前の小石川」「竹島町の人参川」「音羽久世山崖下の細流」「音羽町西側…弦巻川」が並ぶ。このうち**久世山の細流だけが無名であり、水窪川との同定は後世の研究上の候補**。著者が現在の四河川を同名で列挙したと書かない。

1915年『日和下駄』[BOOK-003](sources/books/BOOK-003.md) は「人参川」の実名に加え、富坂下の「一筋の溝川」、小石川柳町の小流など、谷端川下流部との照合候補を描写する。場所が具体的な文芸資料として、経路・橋・町界の歴史地図と重ねる価値がある。作品内の細流を区間全体へ無条件に拡張しない。

## 優先して読む原本（未確認）

1. **森内俊雄「谷端川」**：『海』1978年8月号 [BOOK-033](sources/books/BOOK-033.md) と、単行本『微笑の町』[BOOK-034](sources/books/BOOK-034.md)。河川の具体的描写、地名・橋名、時代設定、再録改稿を確認。
2. **田村隆一の初出誌と1988年本**：『年金と住宅』21・23・25号（1981–82年）、『海』1983年6月号、『青春と読書』1988年11月、『新潮45』1991年6月、『ユリイカ』1996年1月、1988年『ぼくのピクニック』。原文引用と読みの字形を逐一照合。
3. **『若葉抄』／『若葉の梢』**：句「弦巻川蛍」の題・場所指定「法明寺前流」・作者「鈷梁」の原本確認 [BOOK-040](sources/books/BOOK-040.md)。
4. **紙芝居『弦巻川がきえちゃったよ』** [BOOK-037](sources/books/BOOK-037.md)：制作年、全文、伝説部分と歴史的叙述の区別を確認。
5. **小瀬松次郎『成蹊小学校之一年間』** [BOOK-029](sources/books/BOOK-029.md)：NDL個人送信・館内等で「十町川」水遊びの場面を確認。
6. **『日和下駄』の版間異同**：青空文庫の全文版と分章版でURL・旧仮名表記の差がある。特に富坂下の溝川の箇所は「路地」章を原本で確認する。
7. **『暗渠パラダイス！』の水窪川章** [BOOK-042](sources/books/BOOK-042.md)：現代の随筆・紀行として実際の記述を読む。古典文学に水窪川が登場する証拠にはならない。
8. **小石川柳町周辺の作家**：『こころ』の「石橋」、『日和下駄』の「溝川」を1883年五千分一・1912年地籍図・橋梁資料と照合し、どの水路・橋に対応するか検証する。

## 使用時の注意

- 「文学が描く場所」と「地図上の河道」は別証拠。表現は誇張・省略・時代混合があり得る。
- 「谷端川／谷田川」「水窪（東京）／水窪（静岡）」「音羽（東京）／京都」を検索で排除する。
- 地域資料に句碑があることは、その場所で詠んだ証明にならない。
- 書誌だけ確実な場合は、あらすじ・場面・川幅等を捏造しない。
- より狭い対象・短歌俳句の先行調査は[旧河川と詩歌](旧河川と詩歌.md)に残し、重複する長い原文の二重収録は避ける。
