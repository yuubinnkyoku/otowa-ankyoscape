- **[GOV-621](sources/gov/GOV-621.md)として新規採録**。都下水道局トピックス「下水道台帳情報システムがスマートフォンに対応しました」（2026-11-19・1119_6618）を検索スニペットで確認したのち、**SEMIS本体のWeb APIに機械到達**:
