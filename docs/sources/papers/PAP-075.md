# [PAP-075] 松山洋・成宮博之（2025）「東京の湧水の湧出量は長期減少傾向にあるのか？」〔repo初出〕

- **書誌〔確認: J-STAGE記事頁・2026-11-14〕**: 松山洋（立正大学）・**成宮博之**（東京学芸大学）「**東京の湧水の湧出量は長期減少傾向にあるのか？**」、『水文・水資源学会誌』**38巻2号 pp.141-152・2025年5月5日**、DOI [10.3178/jjshwr.38.1839](https://doi.org/10.3178/jjshwr.38.1839)。J-STAGEの[記事頁](https://www.jstage.jst.go.jp/article/jjshwr/38/2/38_38.1839/_article/-char/ja)で抄録を直接確認〔成宮博之は[PAP-019](PAP-019.md)（2006年・湧水の水温変化）の著者で、**松山洋との続柄（共著関係）が2006年から2025年まで継続する研究系列**〕。
- **抄録の内容〔確認・repo初出〕**: ①対象は**氷川神社（品川区）の湧水**で、冬季に枯渇した年（2017・2019・2021・2023年）の湧出挙動を**3段直列タンクモデル**で分析。②結論: 枯渇年は**「年々変動」で説明され、湧出量の長期減少傾向の証拠にはならない**。③**1973〜2023年の1〜3月の降水量・流出量に有意な長期変化はなく、2月の蒸発量のみ増加**〔**都内湧水の「長期減衰」仮説に対して、単一事例ではあるが否定的・限定的な知見**。手法は気象データ（気象庁）とタンクモデルの組み合わせ〕。
- **repoの湧水減衰仮説文献列への位置づけ〔観察〕**: [PAP-018](PAP-018.md)（新井正ら1987・台地部湧水の現状）→[PAP-019](PAP-019.md)（成宮ら2006・過去20年の水温変化）→[GOV-081](../gov/GOV-081.md)（都環境局・令和5年度調査で豊島区0地点）→[BLOG-130](../blogs/BLOG-130.md)（2026年10月・長雨後の湧き水の「復活」報道）という既存の系列に加え、**2025年時点の学術側が「減少傾向」の問い直しを出版している**ことを固定した〔水窪川・音羽谷の湧水（[GOV-124](../gov/GOV-124.md)の定量値・[GOV-147](../gov/GOV-147.md)の報告書シリーズ）の解釈において、「都心湧水は一律に減衰している」という単純化を避け、降水量依存の年々変動と都市化による枯渇（豊島区0地点）を区別する視座を与える〕。
- **制限・未解決**: ①本文PDFのテキスト抽出不能（CIDフォント・ToUnicodeなし・2026-11-14取得試行）。②対象は品川区氷川神社の湧水であり、**音羽谷・水窪川流域の湧水への適用は直接ではない**〔武蔵野台地東縁の湧水一般への外挿は本文確認後に判断〕。③枯渇年の特定メカニズム（2月蒸発量増加の寄与）の詳細は本文未見。
