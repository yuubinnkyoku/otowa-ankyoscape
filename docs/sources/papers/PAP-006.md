# [PAP-006] 『護国寺境内遺跡』

- 確認者について：2026-10-26、利用者は未見と申告。確認者は未判定のまま。

## 2026年10月31日の公開要旨照合

- **書誌の補足：** 松井和浩『護国寺境内遺跡』、東京都スポーツ文化事業団東京都埋蔵文化財センター、2010年12月28日、東京都埋蔵文化財センター調査報告第251集、8・59頁。重文護国寺月光殿（旧日光院客殿）保存修理事業に伴う発掘調査。DOI: [10.24484/sitereports.25235](https://doi.org/10.24484/sitereports.25235)。[国立国会図書館サーチの著者要旨](https://ndlsearch.ndl.go.jp/books/R000000025-I011440005048821)／[同書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000011077526)。
- **内容メモ（公開要旨）：** 月光殿のコンクリート布基礎の下まで掘り下げ、近世の遺構確認面で大型遺構、土坑、焼土跡、植栽痕、礎石、ピットを検出。出土遺物の主な年代は17世紀末～18世紀前葉と18世紀末～19世紀中葉の二群。後者の土坑には土製の縁起小判が多く、報告者は西国三十三所写との関連を考えている。創建期に近い遺構の存在も報告者の推定として記される。
- **確認の範囲：** この追記は国立国会図書館サーチに掲載された著者要旨と書誌を確認したもの。**報告書本文・遺構図面・地層断面は未閲覧**であり、検出遺構を旧水窪川・弦巻川の河道や水利施設と同定できない。基礎の亀裂に埋蔵文化財が影響したという記述も調査契機の仮説で、確定原因ではない。従来の確認者欄・確認状況は過去の由来を尊重して変更していない。
