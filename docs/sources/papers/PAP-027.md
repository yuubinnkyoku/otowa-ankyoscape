# [PAP-027] 深田伊佐夫「千川上水における流域環境の変化と宗教的構築物について」『中央学術研究所紀要』第42号（2013年）

- **書誌〔確認〕**：深田伊佐夫「千川上水における流域環境の変化と宗教的構築物について」、『中央学術研究所紀要』**第42号（2013年）、p.158-180**。echo-lab.ddo.jp掲載PDF。直アクセスは遮断されるが**Wayback Machineのid_付きURLで本文全文取得可（2026-11-12、第30回実行）**。
- **内容〔確認：本文全文〕**：
  - **沿革の9時期区分**（表1）：Ⅰ徳川家御成地の給水（1696-1722）／Ⅱ市中上水の供給（1696-1722）／Ⅲ灌漑用水の供給（1707-、宝永4年20ヶ村嘆願で許可、のち谷端川・石神井川への分水を開削）／Ⅳ市中上水供給廃止（1722-1781、室鳩巣の「地脈分断」建議・幕府財政難・離農者流入抑制説）／Ⅴ再開（1781-1786）／Ⅵ再度廃止（1786-1880）／Ⅶ工業用水の供給（1865-1972）／Ⅷ近代水道の供給（1880-1908、千川水道株式会社）／Ⅸ親水空間の創出（1989-）。**本文は「1971（昭和46）年に役割を終えた」、表1はⅦを「〜1972（昭和46）」と記し、論文内で年次表記に不整合がある**（断定せずそのまま記録）。
  - **流路・現況（2013年1-5月に計4回の現地踏査）**：開渠約6km（武蔵野市関前5丁目〜練馬区関町南3丁目）＋暗渠約17km。**西巣鴨2丁目の旧巣鴨浄水所（現・千川公園）に王子分水の石碑と高さ1m程の水栓バルブ2基が保存**。**北区滝野川6丁目〜板橋駅間に千川上水株式会社の社紋を刻んだマンホールが散見**（社紋マンホールの実在観察）。豊島区千早4丁目都立千早高校北東部に金属フェンス囲いの水路痕跡、板橋区大谷口1丁目・大山西町付近の都道420号内回りに延長200mほどの長挟物。
  - **文京区の千川通り（都道436号小石川西巣鴨線）の由来**：千川上水長崎分水から導水された「谷端川下流部分の小石川（礫川）を暗渠化したことに由来する」と明記。
  - **宗教的構築物19ヶ所の一覧**（表2-4、2013年2-5月現地調査）：内訳は庚申塔8・地蔵尊3・不動尊2・供養塔3・馬頭観音1・水神1・弁財天1。直接千川上水に関係する9ヶ所のうち**5ヶ所が慶応元年以降〜昭和46年の比較的新しい年代に集中し、建立目的は全て水難供養**という考察。
  - **個別構築物（repo初出のもの）**：
    - **石橋供養塔**（武蔵野市関前5-21先、1841年＝天保12年、井口橋の木→石架替記念＋悪霊侵入防止祈願。**井口橋の橋名はrepo初出**）。
    - **橋供養聖観音**（練馬区豊玉北5-8東神社境内、1774年＝安永3年、筋違橋の竣工祝賀・人馬安全祈願。**1953（昭和28）年、千川上水の暗渠化に伴い東神社境内へ移設**（東神社関係者の話）。**筋違橋の橋名・位置と「1953年暗渠化に伴う移設」はrepo初出**）。
    - **川施餓鬼供養塔**（練馬区中村南1-15南蔵院内、本文では「1883（明治15）年」、表3-5では「1892（明治15）年」建立表記で**論文内で年次が食い違う**（明治15=1882年のため「1883」「1892」「明治15」の3表記が併存。断定せず）。中新井分水＝江古田川への分水堰付近に建立、中新井村・中村・下練馬村の施主9名刻字、暗渠工事の際に南蔵院境内へ移設。
    - **日川地蔵尊**（南蔵院内、**1940（昭和15）年、千川上水で溺死した7人の子供の供養で建立＝repo初出**、暗渠工事で南蔵院へ移設。
    - **千川地蔵尊**（練馬区旭丘2-15能満寺境内、**1925（大正14）年の川ざらいで川底から発見**〔BLOG-032既出の千川地蔵の発見年次の初の一次的特定〕、能満寺関係者は「増水で川底に埋没した可能性」、1940年代の暗渠工事で能満寺境内へ移設。
    - **水神社**（板橋区大谷口1丁目、都道420号脇の暗渠部長挟物地内、1940年代建立推察＝昭和初期の宅地化で水難事故多発、1983年遷座、2007年改修。**大谷口水神社の存在はrepo初出候補**〔BLOG-079の簸川神社境内取水舎とは別〕）。
    - **九頭龍弁財天**（練馬区中村北4-12、現在地から100m上流の**九頭龍橋付近から移設、1974（昭和49）年に一連の小祠を再建**。渡邊龍神遺言による安芸宮島の市杵島大神分祀の由緒。**九頭龍橋の橋名はrepo初出**）。
    - **中村垢離取不動尊**（練馬区中村南3-1、相州大山系の雨乞い霊場、明治後半に中村北3丁目交差点付近の中村分水堰付近へ移設、**1956（昭和31）年、上水の暗渠化と道路拡張で再び現在地へ移転**）。
  - **水量記録**：1880（明治13）年千川水道㈱設立の際、従来130坪に150坪を増やし計280坪（石神井図書館郷土資料室1976経由）。
  - **人口動態**：旧北豊島郡1889年73,405名→1940年1,247,614名（豊島区1983・北豊島郡農会1918/1979復刻経由）。
  - **文献目録の頁特定**：『いたばしの河川』（BOOK-031）千川関係頁＝pp.80-85・107-115、北沢邦彦・肥留間博『千川上水路図解説』（MAP-061）＝p.31、『千川上水―昭和27年の写真を中心に―』（BOOK-058）＝p.45。**深田1991（PAP-029）の書誌＝紀要20号pp.84-100**。
- **謝辞・補足**：第72回日本宗教学会研究大会（國學院大學）で口頭発表済み。東神社・能満寺への聞き取り、練馬区役所総務部の行政資料レファレンス。
