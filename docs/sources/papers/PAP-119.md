# [PAP-119] 井坂綾・岩﨑茜「戦前戦中期の目白・南長崎の暮らし」（2020）— 弦巻川下流〜千川上水南側の生活史聴取〔repo初出・所在のみ〕

## repoとの関連〔観察〕

- **対象地域**: **目白**＝弦巻川（丸池→下落合方面）・水窪川（諏訪山系）の谷頭に接する地域、**南長崎**＝千川上水の南側（弦巻川下流・妙正寺川との谷間）にあたる。戦前戦中期（＝弦巻川の暗渠化・転換期を含む年代）の暮らしの聞き取りには、川・水路の記憶・井戸・洗い場等の日々の水利用が含まれる可能性があるが、**本文未見のため水系への言及の有無は一切断定しない**〔所在のみ〕。
- **聞き取り調査報告**: 文献・地誌とは異なる生活史系のルートで、弦巻川・千川上水周辺の水利用や暗渠以前の川の記憶に関する体験談が得られる可能性がある資料候補〔観察〕。
