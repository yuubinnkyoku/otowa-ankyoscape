# [PAP-054] 鄧君龍「近世飴屋川口屋の流れを汲む」（2024）〔repo初出〕

- **書誌〔確認: 豊島区立郷土資料館刊行物ページを2026-11-14に直接取得〕**: 鄧君龍「**近世飴屋川口屋の流れを汲む**」、豊島区立郷土資料館研究紀要『**生活と文化』第33号**（**2024年3月22日発行**、900円）収録。同号のほかの収録: 寺田農×原田光対談（豊島大博覧会）・青木哲夫「学童集団疎開の決定」・及川将基（徳川家祥の江戸北郊訪問）・永嶋里佳（鈴木信太郎）等。
- **位置づけ〔観察〕**: [BLOG-188](../blogs/BLOG-188.md)・[BLOG-190](../blogs/BLOG-190.md)（水窪川沿いの上川口屋・飴屋1781年創業の記事）を扱う**2024年の郷土資料館紀要論文**。飴屋川口屋を「近世」から通史で扱う学術系テキストとしてrepo初出で、水窪川沿い（雑司ヶ谷）の飴屋の由緒・屋号の変遷について史料に基づく記述が含まれる可能性がある。
- **制限・未解決**: 本文未確認（紀要本文は豊島区立郷土資料館での閲覧・購入）。
