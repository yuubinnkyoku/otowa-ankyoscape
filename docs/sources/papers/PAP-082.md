# [PAP-082] 雑司ヶ谷研究20：絵地図と国土地理院旧版地図より読み取る道路形成の歴史

- **書誌〔確認: JWUリポジトリrecord頁・本文・2026-11-15〕**: 杉浦美鈴・薬袋奈美子・大山祐加子・原わかな・古賀碧「**雑司ヶ谷研究20 絵地図と国土地理院旧版地図より読み取る道路形成の歴史**」、『**日本女子大学紀要 家政学系』第72号**（**2025年3月1日発行**）、**pp.55-65**。DOI [10.57483/0002000548](https://doi.org/10.57483/0002000548)。EISSN 2759730X、公開日2025年4月11日、open access。日本女子大学機関リポジトリ [record/2000548](https://jwu.repo.nii.ac.jp/records/2000548)。2026-11-15時点でリポジトリ本体（JAIRO Cloud）は停止中のため、[Waybackスナップショット（20260118232257）](http://web.archive.org/web/20260118232257/https://jwu.repo.nii.ac.jp/records/2000548)から本文PDF（11ページ）を取得し、**本文全文をPDFテキスト層からデコードして直接確認**した。雑司ヶ谷研究シリーズの第20報。
- **弦巻川への記載〔確認: 本文p.57〕**: 「昭和初期になり弦巻川の近くまで人が住むようになった。**1932年に弦巻川が暗渠化し弦巻通りとなり**，地図(15)から弦巻通りを確認できた」。地図(15)は昭和8（1933）『豊島区詳細図』〔README既収録の豊島区地域地図集第1集・1933年1月5日刊の図と同一視できる〕。**1932年という暗渠化の年と弦巻通りへの改変を、2025年発行の紀要論文が明記している**。
- **鶴巻川・鶴巻通りの表記〔確認: 本文p.58〕**: 図3の説明として「**鶴巻川の暗渠化に伴い形成された鶴巻通り**が昭和初期の図より確認できる」。README既収録の[かたりべ104](https://www.city.toshima.lg.jp/documents/2546/kataribe104.pdf)（2012年）の「鶴巻（弦巻）川」「鶴巻道路」に続く「鶴巻」表記の学術論文での実例。誤植か表記ゆれかは判断しない。
- **表1「雑司が谷の変遷調査に用いた地図」24種〔確認: 本文表1〕**: 江戸期 (1)正徳6(1716)武蔵国豊島郡高田村絵図・(2)明和9(1772)武蔵国豊島郡雑司谷村絵図・(3)嘉永4(1851)音羽・目白・雑司ヶ谷絵図・(4)嘉永6(1853)**嘉永新鐫雑司ヶ谷・音羽絵図**→[MAP-164](../maps/MAP-164.md)。明治 (5)「明治14(1872)」2万分1フランス式色彩地図〔注: 明治14=1881であり1872（明治5）との併記は不整合。論文の表記のまま記録〕・(6)明治43(1910)1万分1豊島区地域地形図。大正 (7)大正5(1916)〜(12)大正15(1926)、昭和初期 (13)昭和4(1929)〜(17)昭和20(1945)、昭和 (18)昭和34(1959)〜(20)昭和62(1987)、平成 (21)平成1(1989)〜(24)平成30(2018)5千分1国土地理院基礎地図。**表1に各図の所蔵先・出典の記載はなく**(1)(2)(3)はREADME既収録の各絵図（[MAP-012](../maps/MAP-012.md)下高田村絵図・1772年雑司谷村絵図・[MAP-005](../maps/MAP-005.md)）と年代・図名が一致するが、所蔵本レベルの同一性は未照合。
- **江戸期の道と等高線〔観察: 本文図2〕**: 江戸期地図(1)〜(4)から判読した道を国土地理院色別標高図に重ねると「**色の境目，つまり等高線沿いと道路がほぼ一致する**。自然地形に合わせて，人や獣が歩いた所が道になっていったのではないかと想像できる」。地形順応の道路形成の観察。
- **道路幅員規定の変遷〔確認: 本文3-1・表2〕**: 加藤ら(1986)による整理として、住宅地内の道路幅員は**長屋建築規則による地域毎の3尺(0.9m)以上**が始まり→**1919年市街地建築物法で9尺(2.7m)以上**→**1938年に4m**→**1950年建築基準法42条1項で原則幅員4m以上**、建築基準法制定以前から存在する4m未満の道は42条2項の「**2項道路**」「みなし道路」（3項2.7m以上・4項6m未満）。表2は明治期の防火のための各地方条例を6尺(1.8m)とも整理。雑司が谷一〜三丁目の道路**623本**（交差点間・直角屈曲までを1本とするカウント）のうち2項道路51.8%（公道35.2%＋私道16.7%）・通路18.5%・1項1号道路22.5%等の統計（豊島区道路台帳2018年7月閲覧に基づく）、「市街地建築物法で示された9尺の道の名残と推定されるものが多い」という昭和初期の細街路形成の推定。
- **三河川への言及**: 弦巻川（鶴巻川）のみ。**谷端川・水窪川への言及は本文にない**〔2026-11-15、全文デコードテキストのgrep確認〕。
- **参考文献の照合〔確認: 本文参考文献〕**: 3)雑司が谷研究9（=[PAP-015](PAP-015.md)・既収録・表1(1)〜(4)の一部の図版を同論文が掲載する旨の注2あり）・4)豊島区遺跡調査会調査報告22「雑司が谷Ⅲ」（=README既収録の雑司が谷遺跡発掘報告書・第1分冊2010/12/10）。注1)2018年10月26日雑司が谷一丁目住民9人ヒアリング、注3)2018年12月21日豊島区職員ヒアリング。1925年王子電気軌道（現・都電荒川線）開通による交通利便性の向上が宅地化を後押しした可能性、2008年副都心線雑司が谷駅開通等も本文に記す。
- **制限・未解決**: ①**1932年という暗渠化年の一次出典（行政文書か先行研究か）は本文に示されず**、本論文だけで1932年の工事年・竣工日を立証するものではない（既収録の高田町下水道事業・1932年9月写真帖との整合を確認する独立文献と位置づける）。②本文掲載の各図版（図1〜図5）は低解像度で、地図(15)の弦巻通りの表示の直接判読は行っていない（本文の記述による）。③「明治14(1872)」の年号・西暦の不整合（前述）。④嘉永新鐫版（[MAP-164](../maps/MAP-164.md)）の原図は未確認。
