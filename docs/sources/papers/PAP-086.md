# [PAP-086] 大野正彦ら「千川上水生物復元」シリーズ（都環境研年報ほか）〔repo初出〕

シリーズ全体の書誌を一括登録する（個別のCiNiiレコードは本文取得後に分割する可能性あり）。

- **①〔確認: CiNii・2026-11-19〕**: 大野正彦・菊地幹夫・古明地（氏名の第3著者の表記はCiNiiレコード単位で再確認要）「**玉川上水,野火止用水,千川上水の底生動物相**」、『**東京都環境科学研究所年報**』（**1992年**）〔千川上水を玉川上水・野火止用水と並べて底生動物相で比較した都環境研の初期研究〕。
- **②〔確認: CiNii・2026-11-19〕**: 大野正彦・古明地・若林明子「**千川上水における自然環境復元の試み(その1)**」、『**東京都環境科学研究所年報**』（**1994年**）。
- **③〔確認: CiNii・2026-11-19〕**: 「**千川上水における自然環境復元の試み(その2)**」、『**東京都環境科学研究所年報**』（**1995年**）〔著者表記の個別確認は本文取得時に要〕。
- **④〔確認: CiNii・2026-11-19〕**: 大野正彦・若林明子「**千川上水における自然環境復元の試み(その3)**」、『**東京都環境科学研究所年報**』（**1998年**）。CiNii crid [1050001335066855616](https://cir.nii.ac.jp/crid/1050001335066855616)（その3）ほか。
- **⑤〔確認: CiNii・2026-11-19〕**: 「**千川上水における生物を豊かにする試み**」、『**生活排水』第19巻第217号**、**pp.9-15**〔番号表記は要再確認〕。
- **位置づけ〔観察: シリーズ構成からの推定〕**: 千川上水の清流復活・生物復元はREADMEでも言及される事象だが、その**研究側の一次文献**（都環境研のプロジェクト研究として1992年から1998年まで継続）はrepo未登録だった。清流復活（README既収録の高度処理水導入などの施策）の**効果検証・工法の学術的記述を含む可能性**がある〔本文未取得のため断定しない〕。
- **制限・未解決**: ①全編とも本文は未取得（都環境研年報の都立図書館・NDL収蔵確認、都環境研ウェブでの個別報告書PDFの検索が次回課題）。②「(その2)」の著者名・③⑤の正確な巻号はレコード単位の再確認が必要。③谷端川・弦巻川・水窪川への言及の有無は未確認。
