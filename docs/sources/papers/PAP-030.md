# [PAP-030] 「東京都公文書館収蔵史料に見る板橋の水車 その用水争論をめぐって」『板橋区立郷土資料館紀要』第10号（1994年3月）

- **書誌〔確認：CiNii誌名書誌の記事目録〕**：「**東京都公文書館収蔵史料に見る板橋の水車 その用水争論をめぐって**」、『板橋区立郷土資料館紀要』**第10号、1994年3月刊**（板橋区教育委員会、ISSN 0289-8535、NCID AN10129259）。著者名はCiNii目録上では未表示。〔[CiNii誌名書誌](https://ci.nii.ac.jp/ncid/AN10129259)〕
- **対応〔推定〕**：板橋区内の水車と**用水争論**を都公文書館所蔵史料に基づき扱った論文。板橋区に存した水車は千川上水沿い（[BLOG-094](../blogs/BLOG-094.md)の文化4年溢水事故・水車不許可、[GOV-088](../gov/GOV-088.md)周辺）と石神井川沿いに大別されるため、**千川用水の水車・争論史料を含む可能性が高いが、本文未見であり扱う川の特定はできない**（石神井川・中丸川・出端川系の可能性も残る）。
- **調査経緯〔確認〕**：nabunken（板橋区立郷土資料館紀要の全国文化財総覧収録）がアクセス集中で遮断され続けてきた第24回以来の課題について、**CiNii誌名書誌の記事目録（創刊号〜第21号・全202件）で代替し、千川・谷端・水窪・弦巻・用水・上水の語で冠した記事は本論文1本のみ**であることを確認（第32回ノート参照）。第6号（1987年3月）に千川関連記事なし。
- **制限〔未解決〕**：本文・著者未見。板橋区立郷土資料館での現物確認、著者名と頁数の特定、千川上水系の水車（板橋宿周辺）を扱うか否かの確認が次の一手。

- **追記（2026-11-14 第67回・nabunken復旧で総覧巻別ページを直接確認）**: **著者＝小林保男、pp.1-18**（紀要10号の巻頭論文）。総覧の分類は時代＝近世（細分不明）・近代（細分不明）、遺跡種別＝**集落・田畑**、学問種別テーマ＝資料紹介。〔[総覧巻別ページ](https://sitereports.nabunken.go.jp/ja/127118)〕〔第24回以来の「著者名と頁数の特定」を解消〕。板橋区内の水車・用水争論を都公文書館史料から扱う点は変わらず、**本文の所蔵史料・対象河川の特定は依然未確認**（千川上水系か石神井川系か）。「田畑」分類は用水 context を示唆するが断定しない。本文は総覧に外部PDFリンクなし。
