# [PAP-014] 雑司が谷の乾板工場・井戸水と2021～2023年の発掘

- **書誌〔確認〕**：高橋俊之「[感光材料の産業史―『東洋乾板株式会社』と高橋慎二郎](https://www.jstage.jst.go.jp/article/photogrst/87/2/87_71/_article/-char/ja/)」『日本写真学会誌』**87巻2号、2024年、pp.71–78**、DOI [10.11454/photogrst.87.71](https://doi.org/10.11454/photogrst.87.71)。**発行2024年5月20日、J-STAGE公開6月10日**。公開された[論文全文PDF](https://www.takahashi.tokyo.jp/ayumi/shashingakkai2024.pdf)を2026年11月3日に文字で確認。
- **土地利用と水〔確認：論文pp.72–73の著者による叙述〕**：1914年（大正3年）の**高橋写真乾板研究所**を旧**雑司ヶ谷114番地（現・南池袋4丁目23番）**、1919年（大正8年）の**東洋乾板株式会社**を旧**雑司ヶ谷626番地（現・南池袋2丁目40番）**と記す。研究所設置時の雑司が谷は人家が少なく、**良質で豊富な井戸水**に恵まれていたと説明する。水質測定値・水位時系列は記されない。
- **発掘〔確認：論文p.77の本文と図13の説明〕**：**2021年夏～2023年春**の南池袋2丁目40番周辺の再開発発掘で、東洋乾板の研究所建物の**基礎部分**などを確認し、1927年の「新写真科学研究所」に関する資料にいう**暗室3室の基礎**も確認できたと述べる。**2023年2月4日の区教育委員会の遺跡見学会資料にある排水施設**とは、施設の名称・位置を別途照合する必要がある。
- **本文の年代表記〔観察：同一論文内の不一致〕**：**日本語要旨・本文は東洋乾板の設立を1919年（大正8年）**とする一方、PDF冒頭の**英語要旨には「1912」**とある。後者を設立年の確定根拠として使わない。
- **制約〔未解決〕**：論文は産業史研究であり、**旧弦巻川への工場排水口、井戸の水脈、河道との接続、井戸掘削深度**を直接測定した資料ではない。地下水の利用と旧河道・下水道の線形は区別する。
