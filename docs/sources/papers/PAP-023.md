# [PAP-023] 大橋欣治「江戸・東京の水利探訪（その4）」

- **書誌〔確認〕**：大橋欣治（鹿島建設(株)技術研究所）「江戸・東京の水利探訪（その4）水利遺産探訪―江戸・東京の上水の歩み―」、『水土の知＝農業農村工学会誌』第75巻第7号（2007年）pp.647以下。J-STAGEで本文（PDF）を直接取得〔repo初出の論文〕。
- **江戸六上水と享保の廃止〔確認〕**：江戸六上水（神田・玉川・本所（亀有）・青山・三田・千川）を整理し、享保7年（1722）に神田・玉川を除く四上水の利用停止について、**儒学者・室鳩巣（1658-1734）の献策説**（江戸の地下に水道が縦横に通じ水脈を分断し風を呼び土地を乾燥させるため大火が頻発する、との主張）を紹介〔[BOOK-065](../books/BOOK-065.md)（練馬区史補説）の「非科学的な意見の犠牲」叙述と同系の廃止理由説。室鳩巣献策説の名寄せはrepo初出〕。千川上水は一時復興後に再び廃止され、本所・三田・千川はそれぞれ流域の農業用水等に転用。
- **明治期の千川上水〔確認〕**：**1880年（明治13年）に岩崎弥太郎から千川上水の再興計画が提出され「千川水道(株)」が設立、翌明治14年に突貫工事で開設**〔①千川水道会社の設立（明治13年）と開設・通水（明治14年）の年次を区別した叙述＝repo初出。②[GOV-077](../gov/GOV-077.md)「明治40年まで存続（41年4月解散）」に対し、本論文は**「千川上水は1907年（明治40）に廃止」**と表記〔廃止年（明治40）と解散年（明治41）の区別として整合的に読めるが、断定せず並記〕。③同時期の麻布水道（明治15年開設・水量不足で2年後に玉川上水樋線へ編入）との対比で千川水道(株)の位置づけを説明〕。
- **上水の多目的利用〔確認〕**：上水は飲料水主体のほか農業用水・防火用水・江戸城の堀への補給水・大名屋敷の池・水車の動力源・水運としても使われ、沿いには桜が植えられた〔[GOV-056](../gov/GOV-056.md)「新小金井」・[BLOG-101](../blogs/BLOG-101.md)千川堤植桜楓碑と対応する概括〕。
- **三河川への使い方〔推定〕**：千川上水の上水→農業用水転用（享保以降）の流れを学会誌レベルの概括で確認。谷端川（長崎村分水）個別の記述はなく、灌漑分水の個別年次には踏み込まない。
