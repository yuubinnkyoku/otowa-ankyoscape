## 内容メモ〔いずれも本文記載事実の確認レベル。ファイル内規則により解釈は書かない〕

- **主史料〔本文冒頭記載〕**: 東京都公文書館・東京府文書に加え**三菱史料館所蔵史料**（尊経閣文庫「御達并進達物留」・「千川上水　各自引用樋線切絵図11葉」MA-01209 など）と『郵便報知新聞』。
- **再興の周知〔本文引用〕**: 『郵便報知新聞』**明治12年（1879）9月4日号**に「或ル華族（前田家）」ほか「有志者」による千川上水再興の呼びかけ記事。**同年9月30日**に守田治兵衛・平山省斎・小木曽冨蔵・増田寿平が出願（明治12年「千川水道御開設之義願」全文引用＝官設希望・「消却法書」・資金3万円）。
- **第四十四国立銀行宛証書〔本文引用〕**: 明治12年10月2日・7名。
- **前田家と岩崎家の接続〔本文引用〕**: 尊経閣文庫「御達并進達物留」明治12年11月12日＝前田家が**岩崎弥太郎**に井戸数50を申し込み（**岩崎が水量を決定する権限**を求める）。
- **発起人の交代〔本文記載〕**: **明治13年（1880）3月26日の発起人＝岩崎弥太郎・二橋元長・熊谷武五郎・寺西成器の4名**（前段の守田らは発起人から消える）。開設願は官設・消却方の文言を削除し**株券5万円（1株100円・500株、うち400株を発起人4名が引き受け）**の方式に。**同年3月29日**東京府土木課水道掛上申（会社形式反対・官設提案・神田上水拝借金の前例引用）→**4月10日**東京府「会社設立ノ方法ニ於テハ不都合無之」→**8月25日開設許可**（明治14年通水）。**10月起工・明治14年12月竣工予定**の東京府回答（工事はその都度の支払い）。
- **上野公園分岐〔本文記載〕**: 明治12年12月の上申で上野公園分岐・第二回内国勧業博覧会利用を構想＝[GOV-099](../gov/GOV-099.md)（帝國博物館の上野公園引用樋管）と接続する先駆構想。
- **定款・営業規則〔本文引用〕**: 定款第一条（**工事は東京府庁官鑿**）・第二条（取締は警視局）。営業規則で用水を「並井」「吹井」の2種に分け水賦金を徴収（第三条：引用請求は東京府庁へ具申し認許を受ける。第六条：会社は**元樋**の開設・修理のみで、引取枡・引取樋は引用主負担）。定款第17条（水賦金を営業費・修理費・維持積金・利益配当金の4類に分けて出納）・第18条（維持積金・修理費は「確実ナル銀行又ハ富豪」へ預け運用増殖）。1882年4月6日「当社維持目的」で水賦金収入7500円の内訳（経費1000円・修繕費1000円・樋の積立金2000円・株主配当3500円）。
- **巣鴨村の水溜池〔本文記載〕**: 明治13年12月1日東京府知事松田道之→内務卿松方正義、**北豊島郡巣鴨村 反別七反壱畝拾壱歩**の「新堀及水溜敷」としての地種変換伺（水道会社がすでに買入れ）→12月28日聞届け→1881年1月28日地券下げ渡し願（**所有地第二種之地券を岩崎彌太郎名義で**）→2月1日交付→**3月7日巣鴨村水溜池水番人として澤田陶三を雇入れた届出**。1880年10月巣鴨村在住榎本七五郎の水番人志願を東京府が「水番人之儀者千川水道会社之所属ニ候間」と却下＝**水番人の所管が明治13〜14年時点ですでに会社側にあった**。
- **工事精算〔本文引用〕**: 1882年8月18日二橋元長→東京府知事芳川顕正宛「仕様書並精算帳水路樋線高低測量図御下附之義ニ付願」＝**上保屋水門工事→水路修繕→巣鴨石堰→水溜池開鑿修繕→埋樋工事→巣鴨ヨリ本郷筋・切通シ筋・三組町線**の全仕様書・木材鉄物遣高・工数人足高の精算請求（水路は「上保屋千川水門口ヨリ巣鴨石堰来ル処水溜池迄」）。
- **吹井の増収〔本文引用〕**: 1881年9月6日「営業規則増補ニ付御認可願」＝吹井（吹き上げ井）希望者が多く**「庭園等粧飾ノ為メ」に昼夜多量引用**され水道維持に支障、増水分は元賦金8円を基礎に増収。
- **東京大学の引用〔本文引用〕**: 1881年5月26日水道会社が本郷・小石川両区役所へ（引用希望者は費用減免の達を出すよう）、**同年6月28日本郷区役所→文部省会計局達＝「駒込東片町ヨリ本郷森川町通リ湯島切通町迄」の工事に際し東京大学本郷御用地内「外国教授館」等での飲用水請求があれば費用を減ずる**旨＝[GOV-099](../gov/GOV-099.md)（帝大給水の明治14年起点）と接続。
- **三菱傘下化〔本文引用〕**: 1886年3月29日岩崎弥之助通達＝「第百十九国立銀行及千川水道会社ハ独立ノ会社ナリト雖モ其株式ハ我占有ナルヲ以テ業務上総テ本社ノ指図ヲ受ケシム」「役員ハ総テ本社々員ヲ以テ之ニ充ツ」。
- **水賦金の制度上の位置付け〔本文記載〕**: 明治13年5月27日布告第27号第2条で「水道費」が地方税費目に加え得ることに。東京府会（5月31日）で銀林綱男書記官が「水道費」は既存の水賦金（神田上水・玉川上水は「協議費」で支払い）とは別と説明。地方税規則（1878年11月）で水賦金は区部限りの利害＝協議費扱い。明治7年ファン・ドールン『東京改良意見書』→1876年12月水道改正委員→1877年9月『東京水道改設之概略』の流れ。
- **前田家・岩崎家の邸宅での利用〔本文記載・取得範囲内〕**: 前田家は本郷邸・根岸邸、岩崎家は4邸で引用。**根岸邸は本来農商務省博物局が上野公園内へ引用していた権利の一部譲渡**の形で引水（1893年千川水道会社作成水路図で「瀧吹井ニシテ百四十六個六分」＝**邸内の滝として利用**。1896年『古今秘伝・築山造庭法』下巻に「根岸加賀邸別荘庭園」の銅版画掲載＝中央に滝が池に落ちる構図）。**本郷邸は1879年11月時点で引用希望、1882年許可**（水路図で往来→井戸分岐→池）。駒込西片町の旧福山藩主阿部家でも邸内「泉水」修繕に千川水道会社の者が訪ねた記録。前田利嗣（前田慶寧逝去1874年・家督相続時10代）の後見人斉泰による行幸・有栖川宮威仁親王との婚姻など復権工作との文脈で饗応の場としての邸宅整備を論じる。**岩崎邸（富士前町邸ほか）の詳細は未取得頁**。
- **第1図の作図資料〔本文注記〕**: 「千川上水　各自引用樋線切絵図11葉」（三菱史料館所蔵，MA-01209）＋「第一軍管区地方2万分の1迅速測図原図」（フランス式彩色図）。
