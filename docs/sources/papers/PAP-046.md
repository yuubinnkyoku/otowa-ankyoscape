# [PAP-046] 横山恵美2002「明治期における北豊島郡の産業について」

- **書誌〔確認：全国文化財総覧（nabunken）の巻別ページ所収論文目録〕**：横山恵美「**明治期における北豊島郡の産業について 内国勧業博覧会の出品状況から**」『板橋区立郷土資料館紀要』**第14号 pp.31-55、2002年11月刊**（板橋区教育委員会、NCID AN10129259）。〔[総覧巻別ページ](https://sitereports.nabunken.go.jp/ja/127122)〕〔**repo初出の書誌**〕
- **著者〔確認〕**：横山恵美は[BOOK-064](../books/BOOK-064.md)（「豊島区の湧き水をたずねて」豊島区立郷土資料館研究紀要『生活と文化』第11号・2001）と同一研究者。
- **位置づけ〔推定〕**：内国勧業博覧会の出品状況から**明治期北豊島郡の産業**を扱う。北豊島郡（板橋・練馬・豊島一带）の産業には千川上水沿いの水車・製粉・染色、石神井川沿いの水車等が含まれ、**千川上水の用水利用（[PAP-022](PAP-022.md)の千川水道会社・[GOV-067](../gov/GOV-067.md)の水田利用）に言及する可能性がある**。本文未見で千川言及の有無は未確認。
- **制限・未解決**：総覧ページに外部PDFリンクなし。板橋区立郷土資料館での現物確認が次の一手。同号には渡辺嘉之「東京北郊地域における農家副業としての漬物製造 東京府北豊島郡下練馬村田中宇兵衛家の沢庵漬販売を事例として」（pp.56-73）もある（第67回ノート参照・田中家と[GOV-069](../gov/GOV-069.md)の斎藤水車=田中水車の関係は未確認）。
