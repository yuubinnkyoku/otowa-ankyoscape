# [PAP-036] 濯川でのカワセミ採餌行動の記録（武蔵高中紀要5・2021）

- **書誌〔確認〕**：「武蔵学園で一時的に保護されたカワセミの幼鳥，および濯川でのカワセミの採餌行動の記録」、『武蔵高等学校中学校紀要』**第5号（2021年6月発刊）**。武蔵大学機関リポジトリの紀要第5号目次（DSpace handle 11149/1869）に掲載題目を確認（2026-11-13、第60回実行）。学校公式ブログ（musashi.ed.jp/blog/20210630-305.html）で第5号発刊と「リポジトリに抄録と本論PDF掲載」が確認できる。**著者・頁数・本文は未確認**〔著者は白井亮久と推定されるが確認できておらず断定しない〕。紀要5号のPDFはbitstream形式（ko_chu_kiyo05_*）で公開されており、本論文の個別bitstream URLは未特定。
- **repoとの関連〔推定〕**：
  - 題目の「**濯川でのカワセミの採餌行動の記録**」は、**濯川（千川上水中新井分水の復元水路）でカワセミが採餌する観察記録が存在することを示す学術文献**。カワセミの採餌は小魚等の餌生物の成立を前提とするため、**1985年蘇生以降の濯川に餌生物を含む水生生態が一定程度成立していたことの一次記録候補**〔本文未確認のため、観察年・採餌内容・魚種は記録しない〕。
  - ORG-019・ORG-024（濯川の蘇生と循環）・ORG-030（濯川と自然観察）に続く、**濯川の生物相を扱う紀要シリーズの一環**。
- **注意**：本文PDFのbitstream URL特定と内容確認（採餌対象の魚種・観察年次）が次回課題。濯川の水が循環式（ORG-019）である点との関係で、魚類がどこから導入されたかの言及の有無も要確認。
