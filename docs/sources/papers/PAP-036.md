# [PAP-036] 濯川でのカワセミ採餌行動の記録（武蔵高中紀要7・2023）【第60回登録→第62回 直接確認へ格上げ・紀要号の訂正】

- **書誌〔確認〕**：白井亮久（生物科）・池原満（埼玉県新座市）・村松茂樹（千葉県市川市）「武蔵学園で一時的に保護されたカワセミの幼鳥，および濯川でのカワセミの採餌行動の記録」、『武蔵高等学校中学校紀要』**第7号（2023年3月31日）、pp.151-160**。武蔵大学機関リポジトリ DSpace **handle 11149/2518**、bitstream PDF（ko_chu_kiyo07_151_160_shirai_ikehara_muramatsu.pdf）。第60回登録時に「第5号（2021年）」と記載したが、**収録は第7号（2022年度・2023年3月）であったことを訂正**（handleページのAppears in Collectionsで確認）。
- **本文取得〔確認〕**：直アクセス・直bitstreamは遮断されるが、**Wayback Machine id_付きURL（2024スナップショット）で本文全取得**（2026-11-13、第62回実行）。
- **主要事実〔確認：本文〕**：
  - **2022年7月、武蔵学園大学三号館北側の駐輪場で左翼を傷ついたカワセミ幼鳥（全長16cm程度）が発見され一時保護**。学外から偶発的に入り込んだものと推定され、一次保護の後、東京都指定の動物病院に引き渡された。
  - **同年9月と10月に、濯川で別個体のカワセミによる小型のアメリカザリガニの採餌行動を観察**〔1985年蘇生以降の濯川に甲殻類を含む水生生態が成立していたことの一次観察記録。導入魚の言及は本文取得範囲になし〕。
  - 濯川は**「循環型河川」で巣を作るような環境ではなく、カワセミの定住に適さない**。数年に何回かみられる程度で、**練馬区の調査（2012）でも武蔵学園での記録はない**。
  - 都市河川のコンクリート壁面を利用した巣作り（川内2015引用）・近隣の石神井川での目撃という文脈で、武蔵学園のカワセミを都市鳥の水辺パッチ利用として位置づける。
- **repoとの関連〔確認〕**：ORG-019・ORG-024（濯川の蘇生と循環）・ORG-030（濯川と自然観察）に続く、**濯川の生物相を扱う紀要シリーズの一環**。PAP-033（1926年水生生物標本）から見た濯川（中新井分水）の水環境の現代的な継続観察資料。
- **注意**：第60回の「紀要5号・著者未確認」の記載は上記のとおり解消。学内で保護した傷病個体と採餌個体は別個体と本文は区別する。
