  1. **昭和36年の特別区移管〔確認〕**: **昭和36（1961）年4月1日付**で東京都管理の普通河川（地方自治法上の公共溝渠）が特別区へ移管された。移管の際に**手続き上の齟齬があり、移管保留を予定していた普通河川まで移管してしまったため、事後に（旧河川法の）準用河川認定することで都知事管理の河川に位置付け直した**経緯が建設局河川部発出文書から確認できたとする（まとめの文言）。
  2. **「移管保留河川」9河川〔確認・原文文言〕**: 貴船堀（貴船川）・旧呑川・北前堀・南前堀・六間堀（以上は大田区所在）、並びに谷沢川（大田区ほか）・江古田川（中野区）・神谷堀（北区）・**千川（上水）（練馬区ほか）の計9河川（運河）**。ただし当該移管保留を指示した文書に保留の特段の事由は明記されていなかった。**移管保留9河川の延長表〔確認・数値復元〕**: 延長計9河川29,421m・未改修計14,647m。内訳＝旧呑川1,434/1,359・貴船堀1,115/1,115・南前堀670/0・北前堀850/666・六間堀650/0・谷沢川5,830/2,017・**千川16,782/8,090**・江古田川1,640/1,400・神谷堀450/0（延長m/未改修延長m）〔**千川（上水）の管理延長16,782m・当時の未改修区間8,090mという数値の現われ**〕。
  3. **千川（上水）の法的地位の一貫性〔確認・repoの千川系仮説の一次裏付け〕**: 「法定河川以外の公有水面について…当時も東京都が管理していた**千川（上水）**を除き、特別区が管理していた公共溝渠としての公有水面は以下の二種類に大別できる」。現況表（「保留ほか河川における法定等廃止後の現況」）の千川（上水）〔練馬区ほか〕欄＝「**国有財産（法定外公共物）：地元区移管が保留／財産・機能面ともに東京都管理**」〔+S39・S40・現行いずれも「知事管理・公有水面」の表記29〕。移管保留河川のうち表中「存続」と記された江古田川・谷沢川・千川（上水）のうち、**千川（上水）は従前より法定外公共物として管理されてきた**（他の2河川は現在も一級河川として存続）〔[BLOG-129](../blogs/BLOG-129.md)（都議会・千川=法定外公共物回答）の制度的背景の本文裏付け〕。
