# [PAP-039] 亀岡2022「西貝家文書から見る中村の土地利用と土地所有者の変化」（武蔵高中紀要6・pp.3-24）

- **書誌〔確認〕**：亀岡岳志「西貝家文書から見る中村の土地利用と土地所有者の変化―中新井村土地区画整理事業資料の検討」、『武蔵高等学校中学校紀要』**第6号（2022年5月31日）、pp.3-24**。武蔵大学機関リポジトリ DSpace **handle 11149/2412**、bitstream PDF（ko_chu_kiyo06_003_024_kameoka.pdf・2MB）。直は遮断、**Wayback id_付きURLでhandleページ（書誌・要旨）を取得**（2026-11-13、第62回実行）。本文PDFのテキスト取得は今回未実施。
- **要旨〔確認〕**：練馬区中村及び豊玉地域で昭和戦前期に行われた土地区画整理事業に関する資料を多く含む**「西貝家文書」（石神井ふるさと文化館所蔵）**を検討。文書中の**「中村町第一土地区画整理組合」関連資料**を用いて、中村地域（現練馬区中村北・中村・中村南）西部で進行した区画整理による土地利用の変化の詳細を明らかにした。農村景観から郊外住宅地景観への急速な変貌は事業当初の立案計画に基づくもので、転入者の急増と生業構造の変化が平行して発生。
- **repoとの関連〔確認〕**：
  - **「西貝家文書」= 石神井ふるさと文化館所蔵の中新井村関連古文書群としてrepo初出のアーカイブ**。同館はGOV-092（千川上水記録フィルム写真39枚）で既にrepo参照済みで、千川上水・中新井分水流域の一次資料を更に含むことが判明。
  - PAP-038（第5号・続編前編）に続く亀岡の中新井村区画整理研究の（続編的位置づけ）。中新井分水流域の都市化過程の学術的裏付け。
