## repoとの関連〔観察〕

- **谷端川鎌倉橋と古道鎌倉街道**: repoでは谷端川の鎌倉橋を「古道＝鎌倉街道と通じるbridge名」候補として扱い（第54回ノートのmermaid図「鎌倉橋=古道鎌倉街道」ほか）、[GOV-128](../gov/GOV-128.md)（小池陸子インタビュー）でも谷端川調査参加者の矢島勝昭の関心が鎌倉街道に向かった経緯が語られる。本論文は「**鎌倉街道中道**」と**江戸氏・松原氏**（中世豊島郡の武士団）を主題とし、中道の豊島郡内経路を文献・考古の両面から検討する主題であり、谷端川沿いの古道（鎌倉橋）の文脈に関連し得る資料候補〔本文未見のため、谷端川跨過地点への言及の有無は断定しない〕。
- **主題の系譜**: 谷端川水源地の環境変遷（PAP-026）と同号収録で、谷端川流域の地形史と古道・中世系の両面が同一号で揃う〔観察〕。
