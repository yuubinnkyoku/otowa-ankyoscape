# [PAP-019] 東京都内の湧水の過去20年間の水温変化（2006年）

- **直接確認（2026-11-11、J-STAGE本文PDF、冒頭〜II章・表1周辺）**：東京都が1987～2001年に実施した都内**30地点の湧水調査**のデータと2005～2006年の渇水期・豊水期の実測（水温・pH・電気伝導度・SiO₂濃度）を合わせ、Kendall検定で水温変化傾向を解析。**解析対象23地点のうち渇水期13地点・豊水期11地点で有意水準5%の水温上昇**があった。SiO₂濃度と渇水期・豊水期の水温差に有意な負の相関を認め、涵養域・滞留時間との関係を論じる。
- **関連研究の系譜〔確認：本文の文献案内〕**：東京都環境局（旧環境保全局水質保全部）の湧水調査系列（1989～2002）、上田ほか（2000）、国分・土屋（2003）、谷口（1998）、**「台地部を対象としている新井ほか（1987）」［[PAP-018](../papers/PAP-018.md)］**を引用・位置づけている。国分寺崖線の真姿の池で**1987～1997年に平均0.8℃上昇**（小倉2000の引用）。
- **限界〔未解決〕**：取得部の本文に**豊島区・文京区・池袋・目白・雑司が谷・小石川・谷端川・弦巻川・水窪川の直接の言与は確認できなかった**（表1の諸元は画像化されており、今回の取得範囲では30地点の地名判読ができていない）。
- **repoでの位置づけ〔推定〕**：都内の残存湧水に都市化・温暖化の影響が実測で出ていることを示す論文で、枯渇した三河川の湧水・谷頭（粟島神社弁天池・音羽谷・目白崖下など）の**保存条件・減少傾向の比較基準点**に使える。「東京の名湧水57選」（平成15年1月、豊島区からの選定なし＝2026-10-25調査ノート記録済み）の時代的背景も与える。
