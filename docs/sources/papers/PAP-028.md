# [PAP-028] 大雨による台地湧水復活の水文学的実測（2004年事例）

- **資料〔確認：本文PDF全文〕**：国分邦紀（東京都土木技術研究所地象部）「大雨により復活した台地の湧水・地下水についての水文学的考察」、**東京都土木技術支援・人材育成センター年報（平成17年・ISSN 0387-2416）所収**（[tmpc.or.jp PDF](https://www.tmpc.or.jp/Portals/0/images/03_business/douro/dobokugijutsu/tech/nenpo/pdf/000026761.pdf)）。〔確認：本文〕
- **さいかち窪湧水〔確認〕**：小平霊園北東隅の馬蹄形窪地「さいかち窪」（約2.5ha・**黒目川の源流の谷頭**）で、**2004年10月下旬〜11月上旬に6年ぶりの湧水が観測**された。誘因は**2004年9月24日〜10月25日の累加降雨約823mm**（東京の年間平均降水量の半分超を1か月で）。観測井の地下水位は変動幅約6m（AP59.8〜65.5m）で2004年9-10月に急上昇。湧水期間の水収支から**湧出量は平均0.09m³/sec（湧出高換算552mm）**、池は約2か月継続し黒目川へ総流出約62.2万m³。
- **井の頭池の湧水復活〔確認〕**：神田川の源頭水源である井の頭池で**2004年10月下旬〜11月上旬に池底からの湧水**。西部公園緑地事務所によれば**池が清水状態になったのは過去20年間で1991年9月・1998年8-9月・2004年を含め3回ほど**。
- **地質メカニズム〔確認〕**：武蔵野礫層（主帯水層・透水係数1.2×10⁻²〜1.3×10⁻³cm/sec）上位の黒ボク土層が大雨時に水を貯留しやすい**宙水（gravel上部の被圧）構造**。谷状窪地ではローム層欠損・黒ボク土直下が帯水層。
- **意義〔解釈〕**：[PAP-018]（1985-86年の谷頭湧水残存）・[PAP-021]（透水面減少⇔地下水位低下）・[BLOG-130]（2026年36日連続降水で井の頭・深大寺の湧水復活）に対し、**「降水量の極大で枯渇湧水が数年ぶりに復活する」メカニズムを定量的水収支で示した都の一次技術資料**。三河川（水窪川・弦巻川・谷端川）の谷頭湧水も同種の台地宙水構造に依存したと推定される（推定）。
- **注意〔未解決〕**：本論文は黒目川・神田川源頭部の事例であり、三河川の湧点そのものを扱ったものではない。
