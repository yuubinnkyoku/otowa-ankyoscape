# [PAP-045] 海野修2001「加賀藩下屋敷関係基本史料（『加賀藩史料』）の出典索引ならびに論考等の一覧」

- **書誌〔確認：全国文化財総覧（nabunken）の巻別ページ所収論文目録〕**：海野修「**加賀藩下屋敷関係基本史料（『加賀藩史料』）の出典索引ならびに論考等の一覧**」『板橋区立郷土資料館紀要』**第13号 pp.56-65、2001年3月刊**（板橋区教育委員会、NCID AN10129259）。総覧のテーマ分類は「資料集成」。〔[総覧巻別ページ](https://sitereports.nabunken.go.jp/ja/127121)〕〔**repo初出の書誌**〕
- **位置づけ〔推定〕**：**『加賀藩史料』のうち加賀藩下屋敷（板橋平尾邸）関係の出典を索引化した資料集成**。[BLOG-146](../blogs/BLOG-146.md)が依拠する天明7年分水見積書・[GOV-093](../gov/GOV-093.md)の御下屋敷惣絵図・[BLOG-095](../blogs/BLOG-095.md)の加賀藩江戸下屋敷絵図（前田育徳会尊経閣文庫）など、平尾邸・千川上水用水関係史料の原出典を特定するための探索手段になりうる。本文未見で収録範囲は未確認。
- **制限・未解決**：総覧ページに外部PDFリンクなし。板橋区立郷土資料館での現物確認が次の一手。
