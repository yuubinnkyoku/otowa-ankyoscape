# [PAP-002] 『音羽二丁目遺跡』発掘調査報告書（2012年）

- 文京区教育委員会編『東京都文京区 音羽二丁目遺跡――警視庁大塚警察署改築工事に伴う埋蔵文化財発掘調査報告書』警視庁・文京区教育委員会、2012年12月。文京区埋蔵文化財調査報告書B-126。15ページ＋図版1枚。
- [CiNii Research（書誌・要約）](https://cir.nii.ac.jp/crid/2120589364412597760)／[国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/books/R100000002-I026235685)／[CiNii Books（所蔵館）](https://ci.nii.ac.jp/ncid/BB1842879X)／[全国文化財総覧（書誌リンク）](https://sitereports.nabunken.go.jp/86651)
- 要約によれば、調査区は江戸初期まで関口村の耕作地で、護国寺創建に伴い護国寺領門前町屋となり、**19世紀前葉～中葉頃に整地が行われた**。
- **報告書本文は未読。** 整地の地点・面積・層厚・地層、河川・池との関連を裏付ける記述は未確認。旧水窪川河道の埋立てが発掘で判明したという意味ではない。
- 調査上の論点は [音羽二丁目遺跡と水窪川沿いの旧流路仮説](../../音羽二丁目遺跡と水窪川沿いの旧流路仮説.md) に整理する。
