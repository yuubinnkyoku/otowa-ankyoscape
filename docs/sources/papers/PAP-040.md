# [PAP-040] 渡邉-東馬・白井・福田2022「Florula Musashinoensisの再検討」（武蔵高中紀要6・pp.65-114）

- **書誌〔確認〕**：渡邉-東馬加奈（九州大学総合研究博物館）・白井亮久（武蔵高等学校中学校）・福田泰二（武蔵学園記念室）「大正末期に出版された Florula Musashinoensis（武蔵野植物目録）の再検討 / Revision of "Florula Musashinoensis" Published in 1926」、『武蔵高等学校中学校紀要』**第6号（2022年5月31日）、pp.65-114**。武蔵大学機関リポジトリ DSpace **handle 11149/2417**、bitstream PDF（ko_chu_kiyo06_065_114_watanabe-toma_shirai_fukuda.pdf）。直は遮断、**Wayback id_付きURLで本文（冒頭部分・要旨・採集地分析の一部）を取得**（2026-11-13、第62回実行）。
- **主要事実〔確認：本文・要旨〕**：
  - Florula Musashinoensis（1926）は武蔵高等学校が1922〜1925年に東京西北の郊外で行った維管束植物相調査の目録。**調査・目録化の指揮は久内清孝に嘱託され、牧野富太郎からも多くの助言を受けている**〔PAP-033経由の「和田八重造（1922着任の博物学講師）の発案・10年計画」（大坪2003）と、本論文の「指揮は久内清孝」との関係は、発案と指揮の役割分担と解する余地があるが、断定せず並記〕。
  - 今回の再検討で**改訂リストは紅藻類1種＋維管束植物1,283分類群**（1,103種・26亜種・94変種・36品・24栽培品）となり、**証拠標本は87.3%の分類群で現存**。目録未掲載の16分類群の標本も発見。**23区の2020年レッドリスト該当は249分類群**〔1920年代の東京西北部植物相とその喪失の規模を標本ベースで定量化＝PAP-033のFauna/Florula系譜の植物側の本体研究〕。
  - 採集地分析〔確認〕：学校周辺の採集が多くを占め、石神井川・南蔵院・宿湿化味（現羽沢付近）・中村橋・旧上板橋村・志村・**椎名町**・旧長崎村・旧落合村・旧野方村・和田山（現哲学堂付近）などで目立つ〔椎名町・長崎村＝谷端川流域、上板橋・中村橋＝千川上水流域の採集地記録〕。採集地の比定には「今昔マップ on the web」（谷2017）を使用。
- **repoとの関連〔確認〕**：PAP-033が指摘した「Florula区域図14採集地にSENKAWA AQUEDUCT（千川上水）を含む」の背景となるFlorula本体の増補改訂研究。武蔵学園生物調査（1922→1941千川上水調査→現代標本整理）の系譜を植物側から補強する。
- **注意**：取得した本文部分では千川上水（SENKAWA）の固有名言及は確認できず（32KB打ち切り以降の言及は未確認）。採集地記述では石神井川側の採集が「比較的多かった」としており、千川上水沿いの採集の位置づけは本文全文確認後に判断する。
