# [PAP-003] 土木研究所資料第1026号・1972～74年の水文観測原簿（2026年10月25日本文PDF確認）

- 建設省土木研究所都市河川研究室（山口高志）『都内谷端川・桃園川排水区水文観測資料（昭和47年～昭和49年）』土木研究所資料第1026号、1975年3月1日、301頁。
- 刊行物データベース: https://thesis.pwri.go.jp/public_detail/103342
- 本文PDF: http://thesis.pwri.go.jp/files/doken_shiryou_1026_00.pdf
- 要旨は昭和44年（1969年）発足の都市河川研究室が東京都下水道局計画部と協力し、谷端川下水道幹線（5.42km²）・桃園川下水道幹線（4.58km²）で雨量・水位観測を行った成果の一部と説明。1982・1983年流出解析論文（既収録）の観測原簿にあたる。
- 本文1.1に「豊島区千早2丁目の稲荷FSA（谷端川水源地）を最上流端～文京区小石川の神田川合流点」「自然流路はすでに失われている」「流路延長3.4 km・平均地形勾配1/69」「昭和47年度末～48年度初頭に上流部で拡幅・延伸」、1.3表-1に谷端川側観測点3点（椎名町駅東南・要町駅東・大塚駅西北）を画像判読。
- **本文PDFは画像のみでテキスト層なし**。判読した数値・観測点番号（Y.B.R.1～3）は高精細画像での再確認要。
- 図-1（排水区概況図・PDF9頁）の300dpi判読（2026年10月25日）では、**観測点3か所が○印＋番号で図上に明示**され、Y.B.R.1＝図西側（椎名町方面）・Y.B.R.2＝中央やや西（要町方面）・Y.B.R.3＝東側（大塚方面）に配置。幹線と東武東上線・山手線等の鉄道交差の図示も確認。**細部の座標値・個別の町名注記は老朽スキャンのため判読限界**があり、位置の確定はビューアの高精細画像で要再確認。桃園川側の図・観測点は本図では未確認。
