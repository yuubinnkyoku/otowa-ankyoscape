# [PAP-031] 大谷口配水塔の設計の過程と技術的特徴（所在確認）

- **書誌〔確認: J-STAGE書誌・Wikipedia脚注経由〕**: 窪田陽一・関田匡延・松田奉康・清水厚雄「大谷口配水塔の設計の過程と技術的特徴」、**土木史研究論文集 第25巻（2006年）75-86頁・doi:10.11532/journalhs2004.25.75**（[J-STAGE](https://www.jstage.jst.go.jp/article/journalhs2004/25/0/25_0_75/_pdf)）。**本文PDFは本回2回の取得試行ともfetch不能**（ページ取得サービスの障害応答）のため、以下の内容は**Wikipedia「大谷口配水塔」「野方配水塔」両項（本論文を脚注に持つ二次資料）による概要**であり、本文確認後に直接確認へ格上げする。
- **〔二次確認〕 概要**: 大谷口配水塔は**荒玉水道**（大正14年〔1925〕設立の公営水道組合・現在の中野区・杉並区・板橋区・豊島区・北区周辺に給水）の**大谷口給水場（現大谷口給水所）**にあった配水塔。**昭和6年（1931）完成**・高さ約33mの鉄筋コンクリート造円筒に大小二つのドーム。完成当時は周辺が畑田圃で、近隣上板橋村各戸ではなく**王子・滝野川方面の製紙工場への給水が主**だった。**1972年7月31日まで使用**、老朽化と給水所再整備のため**2005年6月取り壊し**（板橋区の景観百選「大谷口水道タンク」）。**2011年3月に旧配水塔を模したデザインのポンプ棟が完成**。設計者は駒沢給水塔等と同じく中島鋭治とする説が長らく流布したが、没年から計算が合わず**中島洋吉の設計とする説が有力**（この点が本論文の主要な主張の一つ）。
- **〔二次確認〕 野方配水塔との関係**: 同じ荒玉水道の配水塔として中野区に**野方配水塔**（現存・災害用給水槽1,500m³・中野区平和史跡）があり、本論文は両塔の設計担当者を扱う〔荒玉水道の給水圏＝千川上水・谷端川流域の中野・杉並・板橋・豊島・北という重複は地名・水系の文脈で意味を持つ〕。
- **意義〔観察の集積〕**: [BLOG-145](../blogs/BLOG-145.md)の**水道端交番（板橋区大谷口・給水所前）**の「水道端」地名の近代的実体（大谷口給水所と配水塔）の学術論文。大谷口給水所周辺の「水道」地名の由来が荒玉水道の施設にあるとする理解を、土木史研究の水準で裏付ける文献である。千川上水（江戸期）と荒玉水道（近代）の二層の水インフラが大谷口で重なる地点として、地名・土地利用の検討資料。
