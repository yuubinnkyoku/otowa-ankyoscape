  1. **田柄川の全体像〔確認〕**: 「田柄川は東京都練馬区の北東部を東に流れ，**板橋区の都立城北中央公園の先で石神井川に合流する**全長５キロ弱の小河川」＝**全区間を「田柄川」の名で通し、石神井川合流点＝城北中央公園の先と記述**。この流路記述はrepoの**谷端川（上流＝田柄川の別称関係）と一致**し、[BLOG-118](../blogs/BLOG-118.md)（田柄川＝谷端川上流部別称説）・[BLOG-369](../blogs/BLOG-369.md)（橋名群）を強める学術文献側の一次記述。**1970年代に入ると下水道幹線に転用され暗渠化、上は「田柄川緑道」のグリーンベルト化**〔確認〕＝BLOG-367「1980年代前半全流路暗渠化」説との関係は年次の食い違いとして対校要。
  2. **「田枯」「田涸」語源説〔確認・本文§3〕**: 「おそらく田柄という地名は**「田枯」あるいは「田涸」に由来する**ものだろう。そして、その田柄地区を流れる川だから田柄川と名づけられた」と著者推定。＝[BLOG-366](../blogs/BLOG-366.md)（第377回・2017年二次引用）の語源説の**本文側確認**（引用の忠実性も確認）。
  3. **下田柄の池〔確認・本文§2〕**: 寛政4年（1792）筆写「下練馬村絵図」（練馬区役所文化財係編2007『絵図にみる練馬⑴』収録）の西側のため池。釈敬順『十方庵遊歴雑記』（文化11年=1814以降完成）に「**練馬下田柄村の池**」と見え、**大きさは１町（109メートル）四方**。田柄川北側・氷川神社（大松の氷川様・開基年代不明）付近で、現在は住宅で痕跡完全消滅〔本文記述〕＝BLOG-366（有楽町線あたり・北保健相談所の西）・GOV-630（下練馬村絵図「溜井」）の比定問題に本文側の大きさ・十方庵の出典を補強。
  4. **田柄用水の開削〔確認・本文§5〕**: 明治4年（1871）正月に『小島家文書』（練馬区教育委員会編1993・479〜482頁）により申請、**同年10月に村ごとの工事区間分担と工事費用が品川県御役所に報告**。田無用水（元禄9年=1696玉川上水分流）からの分水。嘆願は当初**田無・上保谷・関・上石神井・下石神井・田中・谷原・土支田・上練馬・下練馬の10村**、**途中で谷原村が抜けて「田無村ほか８カ村」**＝BLOG-371（10カ村灌漑）と整合。**新規開削の用水路は約17.2キロメートル・分担費用総額約1,342両**〔本文文言〕。流路＝田無駅北口を分水口→富士街道沿い→石神井→田中・土支田経由→田柄川接続＋田柄川北側並行の独立用水路→下練馬宿経由→再合流。名称変遷「田無村ほか8カ村組合用水」→「玉川上水新井筋分水」→「田柄田用水」→「田柄用水」〔確認〕。**完成時期は諸説**（明治4年10月＝区史歴史編/同年4〜5月＝平田2004・練馬区/初秋＝小史/明治6年「一応完成」＝小島家文書解説）〔本文が併置・断定せず〕。**平田（2004）説: 下練馬宿の飲料水供給目的・下練馬村が相当の資金提供**〔二次引用〕。**天保10年（1839）「土支田村下組絵図」に用水筋の既存小水路が「悪水」（排水路）として記載**〔確認〕＝repoの悪水主題（GOV-633等）に接続。吉成1978の命名理由③「田柄地区にもともと悪水堀があり自然流水による小河川が多かった」を著者は有力と評価〔確認〕。
  5. **千川家と下練馬宿〔確認・本文§6〕**: 千川の名字を与えられた**徳兵衛・太兵衛**、千川上水開削（寛政年間）の際に**帯刀を許され「千川水路取締」**。下練馬宿**中宿「千川屋」**が子孫の居住地（大木正治郎1925年生まれによる下練馬宿復元図〔図3〕・おそらく1930年前後の街並み）。**阿弥陀堂の千川家墓誌**: 3代源蔵〜11代仙司（平成21年=2009年没）までの没年記録（4代善蔵天保5年=1834・7代右〔祐〕保明治27年=1894等）。**9代千川善造は明治23年（1890）東京府土木課から「千川水路見廻役」に任命**。千川善造作成「千川善造家系略譜」（豊島区立郷土資料館編1995『千川上水関係史料集・Ⅰ』131〜138頁）と墓誌は**5代善蔵/仙輔・6代民蔵の有無で食い違い**〔本文が併置〕＝GOV-078・BLOG-380（千川家墓所2019年再観察）に学術文献側の系譜・職制記録を接続。
  6. **成増飛行場と流路変更〔確認・本文§10〕**: 昭和18年（1943）陸軍成増飛行場建設（独立飛行第47中隊・1943年春に500名の地権者集め）。**滑走路横断部で田柄用水は一部トンネル化**。**田柄川流路の戦時変更〔本文が練馬区（刊行年不明）の記述を引用〕**: 現・光が丘から現・田柄2丁目南交差点付近まではほぼ旧流路のうちの1本に沿って川が掘られ、**下流の北町5丁目にあった大堰までは旧流路とは異なるルートに新たに川が掘られた。旧流路は池端にあった池とともに新流路の土で埋め立てられた**。「工兵隊・囚人使役」伝承に対し、北町5丁目旧家の田中氏証言「**1メートル5円で町会が請負い、青年団の私たちが掘った**」〔聞き取り〕。飛行場敷地内には川と池が残ったという伝承。＝**田柄川（谷端川上流）の1943年流路変更の位置と労働実態を初めて本文レベルで具体化**（BLOG-367/372/374の旧流路議論・大堰〔BLOG-369〕の位置と接続）。
  7. **水田の時代〔確認〕**: 大木正治郎「水田が積極的にあったのは明治25年頃から大正末の30年間」分析（北沢1987引用）を妥当と評価＝田柄用水増水から昭和初頭までが水田の時代〔確認〕。
  8. **消滅寺院の記録〔確認・注⑶〕**: 大松の氷川神社隣の**松林寺**は『練馬の寺院』（練馬区教育委員会1971=2004）に記載がなく、1881年地形図に寺院記号あり→1909年地形図で消失。明治維新の際に金乗院（錦・文久元年開基か）に統合されたという〔本文〕。
