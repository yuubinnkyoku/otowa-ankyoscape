# [PAP-011] 藤村和正『散水型浸透計による浸透能実測値を用いた都市流域の洪水流出解析とその応用』

- **書誌〔確認〕**：藤村和正、東京都立大学、**1999年1月**、博士学位論文（工学）。東京都立大学機関リポジトリ「みやこ鳥」資料番号 **4537**、公開日 **2012年11月30日**、本文PDF **10357-001.pdf**。出典：[機関リポジトリ書誌](https://tokyo-metro-u.repo.nii.ac.jp/records/4537)／[原論文PDF](https://tokyo-metro-u.repo.nii.ac.jp/record/4537/files/10357-001.pdf)／[著者の業績一覧](https://kenkyu.hino.meisei-u.ac.jp/fujimura/%E7%A0%94%E7%A9%B6%E6%A5%AD%E7%B8%BE/)。
- **谷端川の観測図〔確認：本文p.38–39、図3-10・図3-11〕**：5.42 km²の解析対象を記し、図3-10の●で**6地点の転倒ます型自記雨量計**、▲で**水位観測地点**を示す。雨量・水位の記録間隔は**5分**。図3-11は流域を区画化した計算モデルを示す。観測点の住所・座標をこの調査では読み取っていない。
- **土地利用・浸透能〔確認：本文p.11–16、p.38〕**：対象排水区の面積構成は**道路・駐車場等21.1％、建物38.9％、民家・寺社の間地等37.6％、運動場・公園等2.4％**。本文は散水型浸透計による測定を記し、終期浸透能を散水開始約60分後の値として扱う。表・図は測定場所の住所を示すものではない。
- **計算プログラム〔確認：付録III・印刷pp.140–143、163頁以降〕**：谷端川流域の流出解析プログラムの掲載を確認。**ybt.f**（谷端川のKinematic wave流出解析）、**ysr.f**（浸透能を変えた計算、ヘッダーに1997年7月7日）、**ysd.f**（谷端川試験流域、ヘッダーに1992年7月28日）など、FORTRAN形式のコードと計算条件が印刷されている。本文・付録の文字抽出には誤読があり、コードの完全性・実行可能性・再現性は未検証。ヘッダーの日付はコードに記された日付で、観測日や河川工事日ではない。
- **注意**：1999年は論文作成年で、谷端川の開渠・暗渠化・排水施設整備の年代を示さない。1992年の共著論文と**研究系列が重なる**ため、別個の独立観測結果として二重計上しない。
