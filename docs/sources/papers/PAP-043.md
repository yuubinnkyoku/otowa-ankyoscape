# [PAP-043] 辻崎久哲1996「加賀藩江戸藩邸の変遷と板橋平尾邸」

- **書誌〔確認：全国文化財総覧（nabunken）の巻別ページ所収論文目録〕**：辻崎久哲「**加賀藩江戸藩邸の変遷と板橋平尾邸**」『板橋区立郷土資料館紀要』**第11号 pp.1-25、1996年3月刊**（板橋区教育委員会、NCID AN10129259）。〔[総覧巻別ページ](https://sitereports.nabunken.go.jp/ja/127119)〕〔**repo初出の書誌**〕
- **位置づけ〔推定〕**：加賀藩前田家の江戸藩邸群のなかで**板橋平尾邸（下屋敷）の変遷**を扱った論文。平尾邸は**天明7年（1787）の千川用水引き入れ見積書**（[BLOG-146](../blogs/BLOG-146.md)・延長168間・193両2朱）と**庭園内の大池**（[GOV-093](../gov/GOV-093.md)・御下屋敷惣絵図）で、repoの千川上水用水史と直接重なる対象。本文未見であり、分水・大池・千川上水への言及の有無は未確認。
- **制限・未解決**：総覧ページに外部PDFリンクなし。板橋区立郷土資料館での現物確認が次の一手。平尾邸関係の既存書誌（[GOV-095](../gov/GOV-095.md)・[PAP-044](PAP-044.md)・[PAP-045](PAP-045.md)）と合わせた該当箇所の突き合わせが調査の焦点。
