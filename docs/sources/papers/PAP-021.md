# [PAP-021] 久富ほか（2015）武蔵野台地の浅層地下水位の長期変動解析

- **書誌〔確認〕**：水文・水資源学会誌第28巻第3号（2015年5月）原著論文。J-STAGEのPDF全文を直接確認（首都大学東京・松山洋地理学教室）。
- **内容〔確認〕**：MODFLOWによる武蔵野台地の浅層地下水流動の再現（1976〜2012年、日単位）とGCM4種を用いた将来予測（2013〜2050年）。1977〜2012年の地下水位低下量と観測井戸の涵養域減少量に正の相関があり、要因は**水田・農地・森林などの透水面の減少と建物用地など不透水面の増加**。土地利用不変を仮定すると将来は適度な強度の降水量増加により地下水位上昇が示唆。
- **repoへの関連〔推定〕**：水窪川・弦巻川の湧水の長期的減衰仮説（[水窪川湧水の変化検討](../../水窪川湧水の変化検討・リサーチセッション.md)・[BLOG-052](../blogs/BLOG-052.md)）に対し、**都市化（不透水面化）→涵養減→浅層地下水位低下という定量的メカニズム**を武蔵野台地全体で実証した研究として、成宮2006（[PAP-019](PAP-019.md)）の湧水温長期記録と並ぶ背景文献。**本論文は三河川・千川上水を直接扱っていない**（謝辞に「東京の湧水・地下水の変遷と土地利用」近藤次郎グラント）。
