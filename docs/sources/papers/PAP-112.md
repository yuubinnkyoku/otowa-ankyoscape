## 要約本文の文言〔確認: 総覧レコード要約・2026-11-24取得〕

- **屋敷の変遷**: 当該地は江戸時代、**加賀藩前田家の下屋敷の一角**（周囲に藤堂家下屋敷・土井家等の大名屋敷）→**元禄8（1695）年に柳沢吉保が敷地45,862坪を拝領**〔下屋敷として活用〕→**元文4（1739）年に敷地南東側一帯が上地され田安宗武が拝領**→旗本屋敷地への区割り→当調査地点も**「御駕籠之者大繩地」へ**→幕末以降は**岩崎弥太郎が六義園を含む広大な土地を購入**。
- **同一意向確認面から廃絶時期の異なる遺構77基**: 南北に走る**54・55号遺構（堀溝）**は「一度掘削した溝を転圧して埋戻し、同主軸で内側を再掘削したのち、側面は土留めされた構造」。**遺構年代は18世紀前葉に比定され、前田家または柳沢家の所産と推定**される。
- **28号遺構（溝跡）**: 東西に走る溝で、**延享4年頃に柳沢家の南東側に置かれた御駕籠之者大繩地との区画溝と推定**される。
- **街区整備の観察**: 18世紀末葉から19世紀中葉の遺構からは街区を意識した様子が見られ、整然とした遺構配置が窺われる。
- **上水関連の文言はレコード要約に含まれず**（「上水」「水路」「用水」「湧水」いずれもレコード全文に0件・2026-11-24確認）＝**陰性**。

## repoとの関連〔観察〕

- **柳沢家屋敷史年代の考古学的対応**: 総覧要約が示す年代群（1695拝領45,862坪／1739南東側上地・田安宗武拝領／延享4年頃の御駕籠之者大繩地化／幕末以後の岩崎弥太郎購入）は、第4地点〔[PAP-109](PAP-109.md)〕・第3地点〔[PAP-113](PAP-113.md)〕の要約と相互に整合する屋敷変遷記述で、54・55号堀溝（18世紀前葉比定＝前田家/柳沢家所産推定）・28号区画溝（延享4年頃比定）がその年代構造を遺構レベルで裏付ける発掘側の提示〔本文未閲覧のため、比定の細部論拠は報告書確認待ち〕。
- **上水系遺構の陰性**: PAP-109第4地点が「上水跡5」を検出したのに対し、本地点（屋敷南東側の1739年上地後の区画内＝旧田安家拝領地→大繩地）の遺構欄・要約には給水系遺構の記述がない。第4地点＝給水末端（大泉水側）、第1地点＝上地後区画という屋敷内の性格違いとして並置できる〔観察・本文での確認は課題〕。
- **地下室4**: 遺構欄に地下室が4基記載される。要約末尾に「地下室、土坑、植栽列といった遺構性格」への言及がある。屋敷地内の地下室群の詳細（用途・年代）は本文未閲覧のため未確認。
