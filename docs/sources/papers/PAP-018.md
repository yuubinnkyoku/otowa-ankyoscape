# [PAP-018] 「東京の台地部における湧水の現状」（1987年）

- **直接確認（2026-11-11、J-STAGE本文PDF、取得部＝冒頭約2頁分）**：都市の生活空間の見直しの中で水辺空間の再生が課題となる文脈、下水道整備に伴う都市内小河川の水質改善（東京都内の小河川のBOD濃度が1971年には50～100ppm、1982年には大半の地域で30ppm以下：東京都環境保全局1984）を述べ、都市化で雨水浸透が制限され地下水・湧水が影響を受ける現状を論じる。〔確認：冒頭部の本文〕
- **限界〔未解決〕**：取得部に音羽・雑司が谷・谷端川・弦巻川・水窪川等、当repoの対象地名への言及は確認できなかった。**本文全体（湧水地点一覧・観測値の有無、対象地区に豊島区・文京区の台地崖線が含まれるか）は未確認**で、湧水現況の一次資料としては扱わない。
- **repoでの位置づけ〔推定〕**：1987年時点の東京台地部の湧水の現況を扱う地理学会誌論文で、粟島神社弁天池（[GOV-015](../gov/GOV-015.md)）・音羽谷の崖下湧水・占春園の池など、**当repoの湧水地点の1980年代の状況を探す候補**。著者新井正は東京の湧水・地下水研究の第一人者とされるが、本論文との研究系列の整理は未実施。
