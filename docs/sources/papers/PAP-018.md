# [PAP-018] 「東京の台地部における湧水の現状」（1987年）

- **直接確認（2026-11-11〔第8回〕、J-STAGE本文PDF・全文4頁分）**：都市の生活空間の見直しの中で水辺空間の再生が課題となる文脈、下水道整備に伴う都市内小河川の水質改善（東京都内の小河川のBOD濃度が1971年には50～100ppm、1982年には大半の地域で30ppm以下：東京都環境保全局1984）を述べ、都市化で雨水浸透が制限され地下水位が低下し湧水の枯渇が生じると論じる。**現地調査は1985年秋と1985～86年冬の2回**、各区市町へのアンケートと消防研究所（1968・1970）・都公害局（1980）等の既存資料を併用。
- **本文内容〔確認：全文〕**：石神井川・入間川・仙川上流や三宝寺池・妙正寺池・善福寺池・井の頭池など**武蔵野面上の湧水池・湧水の枯渇**が目立つ。黒目川・落合川上流（東久留米の上水道取水を含む都内有数の湧水地）、白子川、江古田川・妙正寺川（複断面改修の河床湧水・水量は極めて少ない）、善福寺川（上水道漏水混入か）、**神田川上流（湧水は少ない。被圧湧水がみられる地点があり、下流左岸の崖・谷頭にも「わずかではあるが比較的安定した湧水」が残る）**、野川、目黒川右岸・駒場、明治神宮・新宿御苑などが残存流域として挙げられる。**河川改修で掘り下げられた河床に湧水がみられる例が都内で多い**。1985年秋の湧出量は**9.0×10⁴ m³/day**、1985～86年冬は**2.5×10⁴ m³/day**（測定不能地点を除く下限値）。
- **repoでの位置づけ〔推定〕**：**神田川（＝谷端川・東大下水系の受け皿河川）下流左岸の崖・谷頭湧水が1985～86年時点でわずかながら残存していた**という記述は、関口・東大下水谷頭（[地名・河川名対照表](../../地名・河川名対照表.md)）や江戸川橋〜水道橋付近の崖下湧水の議論に1980年代半ばの実況データを与える。弁天池のポンプ揚水転換時期論（[GOV-015](../gov/GOV-015.md)・[GOV-063](../gov/GOV-063.md)）と比較する時代断面にもなる。ただし**豊島区・文京区の個別地名・三河川（水窪川・弦巻川・谷端川）への直接の言及は本文になく**、当時すでに暗渠の三河川は対象から除かれているとみられる。
- **研究系列〔確認〕**：[PAP-019](../papers/PAP-019.md)（成宮ほか2006）が本論文を「台地部を対象とした湧水調査」として引用しており、1985年調査→都環境局30地点調査（1987～2001）→2006年解析の系譜に位置づく。
