# [PAP-037] 原塚・白井「Fauna Musashinensisとその証拠標本の発見」（日本生態学会67回・2020）

- **書誌〔確認〕**：原塚洸生・白井亮久（武蔵高校・標本庫学）「戦前の東京の動物相を調べたFauna Musashinensisとその証拠標本の発見」、**日本生態学会第67回全国大会（2020年3月・名古屋）講演要旨・一般講演（ポスター発表）PH-08**。日本生態学会ウェブサイトで要旨本文を直接確認（2026-11-13、第60回実行）。
- **内容〔確認：要旨本文〕**：
  - 武蔵高等学校中学校には**液浸標本が900点以上**収蔵。両生類31点・爬虫類49点を整理・同定した結果、**1920年代の東京での採集標本**があり「現在ではほぼみることができなくなったような種類」が含まれる。
  - **Fauna Musashinensis No.1（1929年）の両生爬虫類項を執筆した動物学者・岡田弥一郎**（日本爬虫両棲類学会会長も務めた）らが「約90年前の本校周辺（**練馬、上板橋など**）に生息していた動物を記録し当時の情報を載せ、その一部の写真を図版として掲載した」ことを確認。
  - 整理標本の中から、**Fauna No.1掲載のモノクロ写真と一致する標本（顔と模様の似たシロマダラ、ポーズ・指の形の似たツチガエルなど数個）を発見**。FAUNA図版掲載標本以外の数十個にも類似の古いラベル・整理番号が残り、**約90年前に採集された可能性**を著者は推定する。
- **repoとの関連〔確認＋推定〕**：
  - **Fauna No.1（1929）の証拠標本（特に両生類のツチガエル）が現存する**ことが確認された。ツチガエルは水田・湿地依存種で、**採集地の「練馬・上板橋」はそれぞれ千川上水中流域・流末（板橋側）にあたり、1920年代の千川上水流域の水田・湿地環境の生物標本による傍証**〔採集地と千川上水の位置関係の解釈はrepo側。論文自身は千川上水に言及しない〕。
  - PAP-033の「千川上水産2種の種名特定はFauna No.1原本確認待ち」課題に対し、**Fauna No.1の図版がモノクロ写真であること・その一部が現存標本と対応づけられること**が判明し、原本確認の手段（学園記念室デジタル公開頁＋現存標本照合）の見通しが向上。
- **注意**：学会ポスター要旨（学生・高校生発表を含む）であり、査読論文ではない。標本の採集年・採集地の個別特定は本文レベルの確認が必要。
