## repoとの関連〔観察〕

- **高田地区＝弦巻川・水窪川の上流域**: 目白・高田下宿・高田の谷頭流域は弦巻川（丸池系）・水窪川（諏訪山系）の水源地帯（[GAZ-002](../gazetteers/GAZ-002.md)の丸池→弦巻川源流文言・高田村小字の堰下・水久保など水系小字を既収録）。本資料紹介が扱う「高田地区関連文書類」に用水・水田・反別系の文書が含まれる可能性はあるが、**本文未見のため文書の内容は一切断定しない**〔所在のみ〕。
- **同筆者の系譜**: 髙木謙一は第23号（2014）「「高田」地域の土地利用に関する一考察-「明治四十二年地租名寄帳」の分析を中心に-」の筆者（区目録で確認済み・repo未登録）。地租名寄帳分析＝地割・土地利用の手法を経て「関連文書類」の資料紹介に至る流れと読める〔観察〕。
- **第22号の『高田町写真帖』**: 横山恵美「【資料紹介】『高田町写真帖』について」（第22号2013）も区目録で確認済み〔repo未登録〕。高田地区の資料紹介の連続性〔観察〕。
