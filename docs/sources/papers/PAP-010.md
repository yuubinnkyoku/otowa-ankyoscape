# [PAP-010] 小石川後楽園大泉水護岸修復工事に伴う第二次確認調査（2021年）

- **原資料の所在〔確認：公的書誌〕**：池田悦夫ほか『東京都文京区 国指定特別史跡及び特別名勝小石川後楽園大泉水護岸修復工事に伴う第二次確認調査：文京区春日町（小石川後楽園）遺跡第13地点確認調査報告書』、**東京都東部公園緑地事務所、2021年3月15日刊、B-112**。国立国会図書館サーチ掲載の書誌・報告要旨を確認（**2026年11月1日**）。[国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/books/R000000025-I011440005202466)／[全国遺跡報告総覧・DOI](https://doi.org/10.24484/sitereports.115127)／[東京都立図書館の2021年8月新着行政資料一覧](https://www.library.metro.tokyo.lg.jp/search/research_guide/tokyo/monthly/202108/index.html)。
- **発掘・池岸変遷〔二次転記：NDL掲載の報告要旨〕**：小石川後楽園の**大泉水**について、第二次確認調査では**8か所のトレンチ（H23-T1～T8）**を設けた。要旨は、汀線の変遷を大きく**6段階**に整理できるが、池の全周に共通して確認できるのは**4段階**であり、汀線の形態は**7種類**を確認したと記す。**大型木樋の導水設備の構造**、**長橋の実長・平面形態・構造の一部**も明らかになったという。これらは**報告者の調査結果の要旨**であり、原報告書の断面図・遺構平面図・編年表は本調査では未閲覧。
- **地理的な位置づけ〔観察／推定〕**：庭園は現在の**文京区後楽1丁目**にあり、旧谷端川（小石川）の下流側に近い。近世の**人工的な池・導水施設・護岸改変**を考古学的に比較する資料となる。ただし**大泉水の木樋が旧谷端川から取水したこと、あるいは谷端川へ放流したことは未確認**。大泉水の汀線の変遷を谷端川の自然河道変化と同一視しない。
- **年代の留保〔未解決〕**：**2021年3月15日は刊行日**であり、各トレンチの掘削日、6段階の年代区分、木樋の築造・廃止年代を示すものではない。原報告書を閲覧し、木樋の位置・断面・水流方向、汀線各段階の年代、旧谷端川との距離と標高関係を確認する必要がある。
