# [PAP-078] 土屋喬雄（1933）「鹿島紡績工場並びに機械の圖解説」〔repo初出・PAP-077関連書誌の独立登録〕

- **書誌〔確認: J-STAGE・2026-11-15〕**: 土屋喬雄「**鹿島紡績工場並びに機械の圖解説**」、『**社会経済史学**』**3巻3号 pp.326-327、1933年6月1日**（社会経済史学会）・DOI [10.20624/sehs.3.3_326](https://doi.org/10.20624/sehs.3.3_326)。J-STAGEで本文PDF（RC4暗号化）を取得し、復号・本文テキスト抽出により内容を確認した〔**[PAP-077](PAP-077.md)の関連書誌節に「所在のみ」で挙がっていた本論文の独立登録と、書誌（著者・掲載誌・頁・年）の特定**。ndlsearchレコード [R100000136-I1390282680077784960](https://ndlsearch.ndl.go.jp/books/R100000136-I1390282680077784960) と同一〕。
- **内容〔確認: 本文テキスト抽出〕**: 『社会経済史学』3(3)の**口絵**に掲げた木板刷り鳥瞰図の解説。主な記述は以下の通り〔抽出テキストの判読。一部の固有名・数字は判読不確実なため記載を省く〕:
  - **口絵の図は「我が國における最初の民設機械紡績工場たる瀧野川村鹿島紡績工場の鳥瞰圖、その動力たる水車及び諸機械を示したもの」**〔確認〕。原圖は縦1尺1寸×横1尺7寸の**木板圖**で、鹿島家の関係者（鹿島萬挙〔万平〕の玄孫に當たる人物）から土屋自身に寄贈されたもの。木板圖の描かれた年代は本文に「明かでない」という〔確認。**口絵図版そのものは本抽出では未確認**〕。
  - **沿革〔確認〕**: 我が國の機械紡績工場は①慶應3年竣工の鹿兒島（鹿兒島藩）、②明治3年の泉州堺（鹿兒島藩系）が官設系で、**第三が江戸の木綿問屋・鹿島萬挙（＝万平）が殆んど獨力で建設した瀧野川村鹿島紡績所で民設紡績工場の嚆矢**。起因は**元治元年の物價騰貴に対し幕府が府下の諸問屋へ物價引下げを下問した際、木綿問屋の鹿島が洋式機械による糸製造・人力節減を建言**したこと。翌年幕府の内命を得て同志を募り、横濱のウォルス商會経由で**英國へ紡績機械一組を注文、明治元年横濱に到着**（維新のため一時商會に預け置き）。
  - **設立〔確認〕**: **明治3年、やうやく政府の保護を得て瀧野川に敷地を求め設立に着手、明治五年末に工場竣工・機械据付**。**動力は水車、直徑二十呎、二十五馬力**、職工數三十餘名、工場建物は東西十九間五尺×南北五間、綿倉・事務所・寄宿舍等が附屬する小工場。原料は内地綿のみ。**明治二十年に深川の東京紡績に合併**され、十五年年間の經營を終えた〔**「明治五年末竣工・水車直徑20呎・25馬力・明治20年東京紡績合併」の年次・規模の一次的記述は、[BLOG-229](../blogs/BLOG-229.md)（明治3年設立・5年操業）・[BLOG-228](../blogs/BLOG-228.md)（北区史の明治5年冬操業）と照合可能な本文確認〕。
- **位置づけ〔観察〕**: ①[末尾至行](PAP-076.md)（1967）・[土屋喬雄「創立経営事情」](PAP-077.md)（1933）と同じ著者・同年の鹿島紡績所研究の**図版解説系**で、1933年時点で鹿島家に木板鳥瞰図（水車・機械を含む）が現存していたことを記録する。②**鹿島万平（萬挙）の幕末の建言→明治3年設立→5年末竣工→20年合併の年次列を、経済史家・土屋喬雄が鹿島家資料に基づき1933年にまとめた**点で、明治期の王子分水・水車動力の転用史（[BLOG-228](../blogs/BLOG-228.md)・[BLOG-229](../blogs/BLOG-229.md)）の学術文献系譜（PAP-076/077）を補う。③**本2頁の解説本文には水車の水源（千川上水・王子分水・石神井川のいずれか）への言及はない**ため、立地・用水の解釈はBLOG-228/229の二次記述に依拠したまま〔未解決の維持〕。
