# [PAP-034] 白井亮久「東京都絶滅種ベッコウトンボの戦前に練馬で採集された標本の発見」

- **書誌〔確認〕**：白井亮久「東京都絶滅種ベッコウトンボの戦前に練馬で採集された標本の発見」、『武蔵高等学校中学校紀要』**第6号（2022年）、pp.49-56**。武蔵大学機関リポジトリ（DSpace handle 11149/2415）掲載PDF。直は遮断、**Wayback id_付きURLで本文取得可（2026-11-13、第55回）**。同リポジトリには続きの「武蔵高等学校中学校収蔵の戦前の東京産キバネツノトンボ標本とその生息地」（handle 11149/2416）も存在〔書誌確認のみ〕。
- **内容〔確認：本文〕**：
  - **1926年5月12日「練馬」採集（平山修次郎）のベッコウトンボ標本が武蔵高中標本庫で発見された＝repo初出**。ベッコウトンボは東京都レッドリスト2020で絶滅（EX）指定で、石神井川周辺（練馬駅北部）に生息していたことが分かる初の標本記録。
  - 採集地「練馬」はFauna／Florulaの生物調査区域図の代表採集地で、**現在の練馬駅（西武池袋線）北部・練馬2・4丁目・桜台4・5丁目付近。Florula地図では駅から北約680mまでの石神井川の南の範囲で、「石神井川に繋がる細い二つの谷戸地形とその周辺に僅かな水田がある」（亀岡2021も参照）＝1926年時点の練馬駅北部の谷戸・水田環境の地形学的記述〔石神井川・千川上水（練馬谷頭付近）の1920年代土地利用の独立記述としてrepo初出級。谷端川・千川の谷頭湧水環境論（甲田2015・PAP-024群）と並ぶ環境史料〕。
  - Fauna Musashinensis No.1（1929）にもベッコウトンボが「貫井」産・rare として掲載〔貫井＝千川上水・石神井川に挟まれた採集地の一つ。千川上水沿いの谷戸環境の1929年時点の傍証〕。
- **注意**：石神井川系で千川上水・谷端川・弦巻川・水窪川の直接記述はない。石神井川・貫井・練馬という千川上水と共通の流域の1920年代水環境証拠として背景文献に位置づける。
