# [PAP-020] 滝口志郎（2018）武蔵野台地の水環境と社会生活

- **書誌〔確認〕**：深田地質研究所年報第19号、[PAP-001](PAP-001.md)（同・年報20「弦巻川はかつて谷端川に合流」説）の前年論文。PDF全文を直接確認。
- **内容〔確認〕**：①石神井川源頭部の鈴木遺跡（旧石器）と下野谷遺跡（縄文）の水環境変化（多摩川河床低下→武蔵野扇状地への給水停止）、②国分寺崖線の湧水と武蔵国分寺の立地（武蔵野礫層中の地下水頭と立川面の高低関係で湧水の有無を説明）、③「シマッポ」（降雨後に窪地に水が現れる小川）と集落発達・谷戸地名。
- **repoへの関連〔推定〕**：**板橋粘土層**（氾濫原に堆積した粘土質堆積物、一部は下末吉ローム上半部、西ほど薄い）の分布が武蔵野台地東部の浅層地下水賦存（地下水堆・宙水）を左右するという議論を、『東京の地盤（GIS版）』のボーリング資料で小平・田無・**練馬**周辺の分布として検証している。水窪川・弦巻川・谷端川の谷頭・崖下湧水の地質的背景（台地東縁の下末吉面・氾濫原性粘土層による浅層地下水）を考える際の一般的枠組みを与える。**ただし本論文は三河川を直接には扱わない**。
- **文献案内〔確認〕**：吉村信吉（1940）「武蔵野台地の地下水…地下水堆と聚落発達との関係」（地理教育32）と貝塚爽平（1964）『東京の自然史』66-74の紹介がある。〔湧水・集落関係の古典文献への案内〕
