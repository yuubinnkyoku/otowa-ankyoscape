# [PAP-033] 白井亮久・高田陽・福田悠人「武蔵高等学校収蔵の戦前の昆虫標本の整理（予報）」

- **書誌〔確認〕**：白井亮久・高田陽・福田悠人「武蔵高等学校収蔵の戦前の昆虫標本の整理（予報）～収蔵標本から探る創立期の生物相調査とFauna Musashinensis との関連について～」、『武蔵高等学校中学校紀要』**第4号（2020年）、pp.29-73**。武蔵大学機関リポジトリ（repository.musashi.ac.jp、DSpace handle 11149/2058）掲載PDF。直アクセスは遮断されるが**Wayback Machineのid_付きURLで本文全文取得可（2026-11-13、第55回実行）**。
- **千川上水1938-41年調査の学内史的系譜の特定〔確認：本文全文〕**：
  - **『千川上水（1941）』巻頭言で第三代校長・山本良吉（哲学）が「本校創立の際、武蔵野動植物誌を作らうとして、その一部分は纏まつたが、全部には至らないまヽで中止の姿となって居て、甚だ遺憾に思つて居る」と述べた**ことが本文に引用される。武蔵野動植物誌とはFlorula Musashinoensis（1926・維管束植物1000種超）とFauna Musashinensis No.1（1929・昆虫綱ほか）／No.2（1938・淡水生物）を指し、**千川上水実地調査（1938-41）は出版が途絶えた武蔵野動植物誌事業の延長線上の生徒実地調査として位置づけられる＝repo初出の文脈裏付け**〔GOV-076・ORG-025のアルバム・『千川上水』刊行（BLOG-113）の背景理解が深化〕。
  - 創立時の「武蔵高等学校附近生物調査（武蔵野ファウナ・フローラ調査）」は**1922年創立時に着任した博物学講師・和田八重造の発案・10年計画・学校を中心とした半径2.5マイル（約4km）圏内**（大坪2003経由）。
  - オンライン博物館「濯川と自然観察」頁（100nenshi.musashi.jp/Museum/Index/f9a8d486-db15-4455-92e8-071a3c872252）は**濯川周辺が和田八重造の自然観察の拠点であったこと・Florula／Faunaの出版費用を根津嘉一郎理事長が援助したこと**を記す〔博物館看板系資料の追加細部。ORG-026と参照〕。
- **1920年代の流域水環境の生物学的傍証〔確認〕**：
  - **Florula（1926）「武蔵高等学校附近生物調査区域図」の代表的採集地14地点に「SENKAWA AQUEDUCT（千川上水）」が含まれ、Fauna No.1 Insecta (1)で千川上水産2種が記録される＝repo初出**。ほかの採集地は野方・中新井・辨天（弁天）・椎名・貫井・練馬・北新井・小竹・南蔵院・和田山・宿湿化味（湿化味〔要原本確認〕）・上板橋・石神井川。**椎名（椎名町）・弁天（弁天池周辺か）・上板橋など千川上水・谷端川・中新井川流域の地名が1926年時点の水辺性生物採集地として記録される**。
  - 1926年の平山修次郎採集標本から、**カワラハンミョウ（1926.7.11南蔵院＝江古田川（中新井川）源流部の砂地河原環境）・ゲンゴロウ／コガタノゲンゴロウ（和田山）・ゲンジボタル（1926.5.5北新井）・ヘイケボタル（1926.8.8弁天）・タガメ**など現東京では絶滅した水生・水辺性昆虫が確認される〔**千川上水・中新井分水流域の1926年時点での常時水流・池沼環境の実在を、生物標本という独立系の一次資料で裏付ける＝湧水減衰仮説・土地利用変化（BLOG-105・PAP-020/021）の背景資料**〕。
  - **亀岡（2017）を引用し「1930年代には学校周辺の中新井地区で大規模な土地区画整理が進み、水田はなくなり河川は護岸され、水辺環境は急速に失われた」**〔中新井地区の区画整理時期を近代側から補強する文献参照〕。
- **その他〔確認〕**：千川上水産2種の具体種名は本文の該当箇所で特定できず（Insecta (1)の産地別集計表中）、Fauna No.1原本（武蔵学園記念室・ORG-025の2026-09-03デジタル公開）での確認が次の一手。平山修次郎（標本商・平山博物館）と武蔵高等学校の関係（1925-30年頃・採集依頼・標本購入）の詳細も本論文の主題。
- **注意**：本論文は千川上水そのものを主題としない（学校史・昆虫標本論文）が、『千川上水』1941の刊行背景・当時の水環境の証拠標本という2点でrepo仮説を強める独立資料。カワラハンミョウの「南蔵院＝江古田川（中新井川）源流部」の地形解釈は著者による。
