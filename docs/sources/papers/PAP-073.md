# [PAP-073] 安斎史郎ほか「国道下の障害物を山岳トンネル方式で撤去 東京都下水道第二千川幹線」（トンネルと地下184号・1985-12）〔repo初出・第89回継続調査〕

- **書誌〔確認: NDLサーチ『トンネルと地下』16(12)(184)号書誌ページの目次（R100000002-I000000017483-d3234438）・2026-11-14〕**: 安斎史郎（東京都）・船橋信行（東京都）・熊井文孝（鉄建建設株式会社）「**国道下の障害物を山岳トンネル方式で撤去 東京都下水道第二千川幹線**」、『トンネルと地下 : 日本トンネル技術協会誌』（土木工学社）**16巻12号（通号184）pp.41〜47・1985年12月**。
- **意義〔観察〕**: ①**第二千川幹線の施工を山岳トンネル方式で報じた1985年時点の技術記事**で、[PAP-070](PAP-070.md)（2009年・その8工事・推進工事）に先行する**1980年代前半の第二千川幹線建設期の施工記録**〔確認: NDL目次の著者所属「東京都」と題名〕。②**「国道下の障害物を撤去」という題名は、幹線掘進が国道（一般国道17号・青梅街道等と推測されるが本文未確認のため断定しない）の下を通る際の既設障害物対策**を示し、千川上水旧流路の浅層地盤（旧河道礫層）に由来する施工条件をうかがわせる〔推定: 題名からの推測・本文未確認〕。③第二千川幹線が[PAP-070](PAP-070.md)の「その8」まで少なくとも8次分割とすれば、1985年時点の記事は初期工区の記録である可能性がある〔仮説: 工事番号と年代の対応は本文未確認〕。
- **制限・未解決**: ①本文は未確認（NDL目次レベルのみ・国立国会図書館の個人送信対象かは未確認）。②対象国道・障害物の正体（旧構造物・埋設管か）・工区番号・施工年度は本文未確認のため断定しない。③著者安斎史郎・船橋信行の都下水道局所属はNDL目次の「東京都」表記からの推定〔確認: NDL目次〕。
