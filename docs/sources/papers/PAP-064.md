# [PAP-064] 石原成幸・河村明・高崎忠勝・天口英雄「東京都における中小河川改修と都市計画の歴史的経緯」

- **書誌〔確認: 本文PDF直接取得〕**: 石原成幸・河村明・高崎忠勝・天口英雄「**東京都における中小河川改修と都市計画の歴史的経緯***」『**土木史研究 講演集 Vol.31**』（土木学会土木史研究委員会・2011年）**pp.15〜24**〔[首都大学東京 石原Web掲載PDF](https://akira.fpark.tmu.ac.jp/paperlist/lecpaper/166.pdf)・2026年11月14日取得・テキスト層から本文抽出〕。
- **内容〔確認: 本文・表-1年表〕**:
  - 都は**都市計画法の制定当時から、河川改修を都市計画に位置づけて実施してきた**こと、その背景として中央政府による首都東京の統治体制の影響を明らかにした研究で、現在の環状七号線地下調節池等も**河川法の河川整備計画変更と同時に都市計画法の施設計画変更**を行っていると整理する。
  - 表-1年表の**S5（1930）欄：「東京都市計画事業 決定 立会川・神田上水ほか」「神田上水 市郡界〜中野町地内 4,114間」**＝**1930年都市計画決定の神田上水区間の対象延長（4,114間≒約7.5km）としてrepo初出の数値**。S6（1931）欄には呑川・宇田川・江戸川ほかの決定を載せる。
  - S64・H1欄に「**野火止用水・玉川上水・千川上水 清流復活通水開始(H1.3)**」を記す（1989年3月の清流復活通水の年次整理〔既存知見と整合〕）。
  - S48（1973）以降の年表では都市河川環境整備事業・流域貯留浸透事業・地下調節池構想等、東京の総合治水の変遷を一覧化する。
- **位置づけ〔観察〕**: README既述（石原成幸『都土木技術支援・人材育成センター年報』2010の「昭和5〜6年に立会川・神田上水・**谷端川**・呑川・宇田川・谷田川・江戸川の改修計画告示」整理・[国立公文書館『東京都市計画河川改修及其ノ事業執行年割決定ノ件』](https://jpsearch.go.jp/item/najda-KQdR01910100_00400)）の**裏付け文献として、1930〜31年の都市計画決定の制度史的枠組みを講演集レベルで確認**できる。**神田上水区間（市郡界〜中野町）の改修区間長4,114間が新規の定量値**で、千川上水〜神田上水系の水路が都市計画河川として扱われた1930年前後の実務の具体性を増す。ただし「神田上水」区間の市郡界〜中野町が千川上水のどの区間と重なるかは本文に明記がなく**断定しない**。
- **表記〔確認〕**: 著者表記は「石原 成幸・河村 明・高崎 忠勝・天口 英雄」（首都大学東京都市環境科学研究科。石原の同主題の一連の研究は都土木技術支援センター年報2009・2010・2016・2024に分冊されている〔README既出〕）。
