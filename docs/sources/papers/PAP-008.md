# [PAP-008] 関根正人ほか「石神井川流域を対象とした豪雨時の内水氾濫と河川洪水流の一体予測計算」（2016年）

- 関根正人・近藤恭平・神山宙大・小林香野「石神井川流域を対象とした豪雨時の内水氾濫と河川洪水流の一体予測計算」『土木学会論文集B1（水工学）』**72巻4号、2016年、pp.I_337–I_342**。DOI: [10.2208/jscejhe.72.I_337](https://doi.org/10.2208/jscejhe.72.I_337)。[J-STAGE掲載頁](https://www.jstage.jst.go.jp/article/jscejhe/72/4/72_I_337/_article/-char/ja/)／[原文PDF](https://www.jstage.jst.go.jp/article/jscejhe/72/4/72_I_337/_pdf)。原文PDFの本文・図の説明を直接確認（2026年10月31日）。
- **第2章(1)・(3)**：石神井川流域を含む**110.2km²**の区域について、東京都下水道台帳の枝管までの下水管路、道路、雨水吐、ポンプ所等を用いた計算を行う。対象区域は新河岸・小台処理区の全部と落合処理区の一部を含む。
- **第2章(2)**：2005年9月の杉並豪雨（観測された総雨量**263mm**、最大時間雨量**112mm/h**）と同じ降雨が**対象区域全域に一様に降るという仮定**で予測計算。実際に谷端川幹線全域で同量の雨が降った記録ではない。
- **第3章(2)・図4(a)～(d)**：石神井川の雨水吐の地点**A・B**に接続する大断面下水道として、**田柄川幹線・谷端川幹線**をそれぞれ挙げる。両幹線の断面積を等価な円形に換算した直径は、それぞれ**約5m・3m超**と記す。図4は石神井川流量・水位および雨水吐の流出入流量の**計算結果**であり、吐口の実測流量の時系列ではない。
- **第3章(2)・図4(e)**：河川から下水道への逆流が計算された例は地点**C**として示される。地点Cを谷端川幹線の地点Bと取り違えない。谷端川幹線で実際に逆流が観測されたことを示す資料ではない。
- 本文の図4は雨水吐の縦断的な相対位置を示すが、**谷端川幹線の吐口の正確な座標、放流開始年、旧谷端川自然河道との接続変更時期**は本文からは確定できない。
