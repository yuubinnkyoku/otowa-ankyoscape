- **書誌〔確認: J-STAGE記事頁〕**: 石原成幸（東京都立大学・東京都公園協会）・天口英雄（東京都立大学）・高崎忠勝（東京都立大学・東京都建設局）「**神田川水系桃園川の法定河川廃止と下水道幹線化の経緯について**」『**水文・水資源学会誌**』**37巻（2024年）p.187〜**（オンライン公開2024年12月30日・**DOI 10.11520/jshwr.37.0_187**）〔[J-STAGE記事頁](https://www.jstage.jst.go.jp/article/jshwr/37/0/37_187/_article/-char/ja)〕。

- **内容〔確認: 本文§2〕**: 桃園川は**現在の杉並区立天沼弁天池・天沼もえぎ公園付近を源頭とし、同区内の阿佐ヶ谷・高円寺を経て、中野区東中野1丁目地先で神田川（神田上水）に合流**していた（図-1に準用解除時点の周辺流路図）。**昭和27（1952）年1月10日、旧河川法に基づき中央線鉄橋から神田上水合流点までの延長約4.4kmが準用河川に認定され、その上流が公共溝渠**となった。昭和30年代頃から流域のスプロール化・市街化で水質汚濁が進行したため、**36答申に基づく下水道幹線整備の完了目途が立った昭和40（1965）年に準用河川の認定解除等を行い、昭和42（1970）年に解除区間の暗渠化を完了**。
- **表-2（河川・下水道管理者による協議経緯）〔確認: 表-2断片〕**: **S25 建告740「東京特別都市計画下水道」＝源頭水源を有する一部準用河川を除く全ての在来河川・水路を合流式下水道管渠に改良** → **S27 都告22：旧河川法・準用河川に認定** → **S36 東京都市計画河川・下水道特別調査委員会答申（河川の下水道幹線化など）＝36答申** → **S37 桃園川の管理移譲願い（下水道局長→建設局長）**「下水道局において一切を管理し公共下水道の一環として処理したい」 → **S38 公共下水道となる準用河川は下水道局へ移譲する方針決定（建設局長→下水道局長）** → **事前指揮「河川法の準用解除・廃止は支障ない」（回答）（建設省→都）** → **都告279：準用河川認定の解除並びに河川区域の廃止・公共用財産の用途廃止、東京都知事から旧大蔵省（関東財務局長）へ・公有水面の公用廃止・国有普通財産となる** → **S41 東京都市計画河川廃止**。
- **表-1（河川・下水道計画の諸元）〔確認: 表-1断片〕**: 河川計画と下水道計画の5区間比較（幅員m・水深m・流量m³/s）。**神田川合流点〜宮下橋＝8.0/3.5/64.7（河川）・8.00/3.50/100.7（下水道）**、**宮下橋〜桃園橋＝6.0/3.5/49.8・6.00/3.50/65.2**、**桃園橋〜都道222号＝6.00/3.30/59.6・5.00/3.10/41.3**、**都道222号〜中央線交点＝5.0/3.1/31.4・5.00/3.10/41.3**、第5区間（中央線交点〜）は抽出断片で数値未完。まとめ欄に**幅員8000～5000mm・水深3500～3100mm・Q=64.7～31.4m³/s（神田川合流点～中央線交点）**。
- **構造と勾配〔確認: 本文§2〕**: 桃園川の下水道幹線化では**河川護岸上部に桁を渡す形で暗渠化し、河床部分はインバートを新設**、**公共溝渠区間はボックスカルバート構造**。計画諸元から流路勾配を逆算し、**開渠区間1/800～1/400・公共溝渠1/300、下水道の覆蓋区間1/800～1/600・Box1/400**と推定（算定手法による差異あり）。
- **二段階管理移管〔確認: 本文§3-4〕**: **下流端から旧中野区役所（桃園橋）附近までの下水道幹線整備完了の段階で当該区間の管理権限を河川管理者から下水道管理者へ移管し、その後、法定区間の下水道幹線整備の完了を以て残区間を移管する二段階の管理移管**を実施。これにより改修済（下水道管理）と未改修（河川管理）区間の錯綜した公物管理を避け、水系一貫主義の管理体制を維持したと結論。
- **36答申と覆蓋化〔確認: 本文§4〕**: 旧建設省は**昭和40年代に河川の覆蓋化や縦断占用を認めない方針を明確にしていたにも関わらず、本事案では表-2の事前指揮や36答申委員として旧建設省職員が関与した覆蓋化が行われた**と指摘し、昭和40年（前後）の河川行政の変革と東京都側の意識変革の遅れを論じる。参考文献4)＝**東京都建設局河川部「東京都告示第279号（昭和40年3月31日東京都公報登載）付属資料、1965」**。
- **論文内表記の揺れ〔観察: 抽出テキストの直接比較〕**: 本文§2は認定解除を「**昭和40(1965)年**」とする一方、§4は「**昭和40(1968)年前後**」、参考文献4)は「**昭和40(1968)年3月31日東京都公報登載…1965**」と表記し、**論文自体の西暦換算に内部矛盾がある**（昭和40年=1965年）。**都告279の公報登載日を「1968年3月31日」と断定しない**〔未解決: 東京都公報昭和40年3月31日号の原本確認で確定〕。
- **位置づけ〔観察・repoへの意義〕**:
  - **谷端川1962年（昭和37年）河川廃止〔既収録〕との制度史比較**が本格的に可能になった。桃園川の手続骨格＝**36答申（S36）→管理移譲願い（S37）→移譲方針決定（S38）→事前指揮→都告279による準用認定解除・公有水面公用廃止（S40）→都市計画河川廃止（S41）→暗渠化完了（S42）**という年次骨格は、**準用河川→下水道幹線化の標準手続の類推材料**を与える。ただし**桃園川＝旧河川法の準用河川、谷端川＝都市計画河川（法定河川）と法定地位が異なるため、手続の単純な同一視はしない**。
  - **源頭の天沼弁天池が[GOV-105](../gov/GOV-105.md)矢嶋又次記憶画「天沼弁天池」（1978・「千川上水の分流と共に、天沼、阿佐ヶ谷の田に利用され」）と同一地点**で、千川上水分流の受益田と桃園川源流が天沼の湧水を分け合った地理的接続を、学術論文の流路図記述（図-1）と区史料の記憶画説明で突き合わせられる〔観察〕。
  - 36答申本文・建告740（1950年＝S25）は千川・谷端川の下水道化史（README既述の第二千川幹線・谷端川雨水渠系統）の上位計画であり、都告22（S27）は準用河川認定の一般的手続例として千川の「準用河川」表記検証にも参照できる〔観察〕。
