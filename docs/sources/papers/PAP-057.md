# [PAP-057] 永岡義久「小石川の坂道 千川筋吹上坂下の谷底 徳永直『太陽のない街』」（2013）〔repo初出〕

- **書誌〔確認: NDL雑誌記事索引〕**: 永岡義久「**小石川の坂道 千川筋吹上坂下の谷底 徳永直『太陽のない街』**」、『**公評**』**50巻6号（2013年7月）**〔[NDL雑誌記事索引](https://ndlsearch.ndl.go.jp/books/R000000004-I024577213)〔誌名レコード](https://ndlsearch.ndl.go.jp/books/R100000002-I000000007966-i5038063)〕。
- **内容〔確認: 記事タイトルのみ／本文未見〕**: 記事タイトルが**旧千川下流（小石川）の谷底低地＝「千川筋吹上坂下」を徳永直のプロレタリア文学『太陽のない街』（1929年・小石川の印刷工場争議が題材）の舞台として読む文学散歩的論考**であることを示す〔「千川筋」という表記自体が旧千川（礫川）下流の通称としての用例〕。
- **位置づけ〔観察〕**: repo既収録の『氷川下町会史』関連記述（[BLOG-160](../blogs/BLOG-160.md)〔[GOV-094](../gov/GOV-094.md)〕）も『太陽のない街』の舞台地域に触れるが、**「千川筋」という呼称で谷底の土地利用と文学の関係を独立に扱う記事の所在が新出**。ただし**本文未見で、旧流路・暗渠の記述の有無は不明**。
