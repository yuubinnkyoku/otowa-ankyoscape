# [PAP-069] 望月野花「江戸近郊農村に暮らす人々の生活実態に関する基礎的研究」（史艸59・2018）〔repo初出・書誌のみ〕

- **書誌〔確認: NDLサーチ雑誌記事索引（R000000004-I029399422）・2026-11-14〕**: 望月野花「**江戸近郊農村に暮らす人々の生活実態に関する基礎的研究 : 雑師ヶ谷村と角筈村を事例として**」、『**史艸**』（日本女子大学史学研究会 編）**59号 pp.57-77・2018年11月**。
- **意義〔観察・要本文確認〕**: ①**雑師ヶ谷村（弦巻川源流部〜雑司が谷の村）を主題に含む2010年代の学術論文**で、江戸近郊農村の生活実態（生業・家・物資などと推測されるが本文未確認）を基礎的に整理したものと書誌から読める。②比較対象の**角筈村（新宿区西新宿付近）は、[PAP-056](PAP-056.md)系の由緒書研究や[GOV-110](../gov/GOV-110.md)星野家文書の文脈と同じ西郊の村**で、雑師ヶ谷と角筈という**同じ江戸西近郊の二村対照**の枠組みは、[README](../../../README.md)の雑師ヶ谷村（御鷹方御役屋敷〔[PAP-072](PAP-072.md)〕・鬼子母神門前〔既出諸資料〕）の理解に対し生活史・社会史の学術的枠組みを与える候補〔本文未確認のため、千川上水・弦巻川の水利に言及するかは断定しない〕。③日本女子大学は目白台（旧音羽領の隣接・弦巻川下流域）に所在し、同校の史学研究会誌での雑師ヶ谷村研究の存在自体が地域研究の系譜を示す。
- **制限・未解決**: ①本文は未確認（CiNii Research CRID 1520572357116881792・NDL雑誌記事索引レベルの書誌のみ）。②雑師ヶ谷村の水利・水系への言及の有無は不明。③『史艸』59号の他の記事（雑師ヶ谷・水系関連の有無）は未走査。
