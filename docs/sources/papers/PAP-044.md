# [PAP-044] 永山嘉之1986「平尾邸の夕餉 廻遊式庭園・アップルの栽培等」

- **書誌〔確認：全国文化財総覧（nabunken）の巻別ページ所収論文目録〕**：永山嘉之「**平尾邸の夕餉 廻遊式庭園・アップルの栽培等**」『板橋区立郷土資料館紀要』**第5号 pp.8-14、1986年3月刊**（板橋区教育委員会、NCID AN10129259）。〔[総覧巻別ページ](https://sitereports.nabunken.go.jp/ja/127113)〕〔**repo初出の書誌**〕
- **位置づけ〔推定〕**：タイトルに「**廻遊式庭園**」とあり、[GOV-093](../gov/GOV-093.md)（広報いたばし平成26年・「池泉回遊式庭園」「御下屋敷惣絵図の庭園内の大池」）に先行する、**平尾邸庭園とその大池を扱った（と推定される）郷土史料論文**。庭園の夕餉（宴席）・アップル（リンゴ）栽培への言及から、幕末〜明治の邸内土地利用を伝える可能性がある。千川上水からの注水経路（大池先端・東板橋体育館前〔[BLOG-146](../blogs/BLOG-146.md)〕）との関係は本文未見で未確認。
- **制限・未解決**：総覧ページに外部PDFリンクなし。板橋区立郷土資料館での現物確認が次の一手。
