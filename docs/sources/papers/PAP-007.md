# [PAP-007] 田中康義「古い時代の小石川植物園」（1973年）

- 田中康義（東京大学理学部附属植物園）「古い時代の小石川植物園」『東京大学理学部広報』**第5巻第5号、1973年7月10日、pp.4–5**。東京大学理学部が公開する[当時の誌面PDF](https://www.s.u-tokyo.ac.jp/en/story/newsletter/past/19730710_5_5.pdf)の印刷pp.4–5を直接確認（2026年10月31日）。
- 印刷p.5に、享保7年（1722年）に設けられた小石川養生所の説明とともに、**「植物園中央付近に、その当時使用した井戸が現在に残っている」**と記載する。**「現在」は1973年の記述時点**であり、2026年の現存確認ではない。
- 印刷p.4の第1図は、**1915年（大正4年）東京帝国大学発行「植物園一覧図及び沿革誌参考図類」**からの部分図と説明される。薬園の土地利用や管理区画を検討するための図であり、谷端川の旧河道が図示されていることは未確認。
- 同記事は、1684年の御薬園移転、1698年の白山御殿普請に伴う敷地縮小、1721年の御殿地を含む拡張などを、既刊の園史や明治期の書状に基づいて整理している。**近世の原史料そのものではなく1973年の研究・紹介記事**として扱う。
- 井戸の水源帯水層、現在の水位・水質、旧谷端川本流との水理的接続は記事からは分からない。
