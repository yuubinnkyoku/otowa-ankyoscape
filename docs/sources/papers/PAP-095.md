# [PAP-095] 今村明恒「東京大阪兩市街地ニ於ケル震度ノ分布」（震災予防調査会報告 第77号・1916）

- **書誌〔確認〕**: 今村明恒「**東京大阪兩市街地ニ於ケル震度ノ分布**」、『**震災予防調査会報告**』**第77号**（大正5年・震災予防調査会）。NDL次世代デジタルライブラリー [book/974335](https://lab.ndl.go.jp/dl/book/974335)（APIの書誌でvolume「第77号」・刊年1916を確認）。東京编は第1図（震度4級の着色図）と震度小・中・稍大・大の区域列挙で構成される。**引用文言はすべてOCR由来で要原文照合**。
- **震度大ノ區域の「神田淵ノ跡」〔確認・observed文言〕**: 「**震度大ノ區域 - 池ノ端、神田淵ノ跡(小石川大下水、江戶川尻ヨリ舊小川町(駿河臺ト飯田町田安臺地ノ中間一面)、丸ノ内大名小路西側(辰ノ口、日比谷櫻田一帶)、淺草下谷ノ北部(吉原ヨリ吾妻橋附近マデト金杉、三之輪、龍泉寺間一面)、本所深川ノ西部**」〔**神田淵の跡（江戸川尻から小石川大下水・旧小川町に至る、駿河台と飯田町段丘の中間の一面）を震度大区域＝軟弱地盤として土地構造から推定した1916年の学術論文本文の文言**。「小石川大下水」＝[地名対照表](../../地名・河川名対照表.md)の谷端川下流部の歴史的呼称〔[GAZ-083](../gazetteers/GAZ-083.md)参照〕で、**蟹川系（江戸川＝神田川本流）と谷端川下流（小石川大下水）に挟まれた旧河谷の低湿地帯がこの文言の対象域**に当たる〔範囲の比定は本文の第1図の確認を要し断定しない〕〕。
- **震度中ノ區域の文言〔確認〕**: 「**根(津)湯島ノ東・御徒町附近、神田明神下、白山下、江戶川筋、牛込堀端、赤坂溜池筋、**芝金杉…」が震度中区域として列挙される〔**江戸川筋・白山下（蟹川中流域）や牛込堀端・赤坂溜池筋（溜池跡地）が山の手側の軟弱地盤例として挙げられること**＝[BOOK-167](../books/BOOK-167.md)（東京市史稿変災編第1の関谷博士調査引用の「江戶川筋(小石川區牛込區)」「白山下」文言）と対応する区域列挙〕。
- **関谷博士の安政2年遺稿の要旨の保存〔確認〕**: 「**關谷博士ハ安政二年江戶大地震ノ遺稿ニ於テ震原ヲ東龜井戸村市川村近傍トシ且ツ東京ニ於ケル震度ヲ三級ニ分チ**其ノ緩ナルヲ本芝田町、高輪、品川、麻布、靑山、赤坂、四谷、麴町、番町、九段上、牛込駒込邊ノ高地トシ**激ナルヲ築地、鐵砲洲、御曲輪內特ニ大手前…小川町、小石川、下谷、根津ヨリ下谷(茅町?)ノ通リ、淺草、吉原、本所…**トシ中間ナルヲ京橋邊、日本橋邊、神田邊、兩國邊トセリ」〔**①関谷博士（關谷清助）の安政2年（1855）大震の遺稿が震源を東亀井戸村・市川村近傍に推定し、東京の震度を緩・激・中間の3級に分類したこと、②その激級に小川町・小石川・根津〜下谷が入ることの要旨が今村によって引用保存されている**〕。また安政大震の武家死者の総数2131人のうち「**前記江戶川筋神田淵跡ノ九百人**」が江戸川筋＝神田淵跡に集中したと記す〔[BOOK-167](../books/BOOK-167.md)の文言と同型で、本論文がその出所側（または同系出所）であることの対校資料〕。
- **方法と自己位置づけ〔確認〕**: 大森博士の山の手・下町区別（本会報告第41号）を踏まえつつ、「**所謂山ノ手ト稱スル地方ニ於テモ亦軟弱ナル土地アリ下町ト稱スル地方ニ於テモ稍〓(=やや)堅牢ナル地盤ガ特ニ贏弱(?)ナル場處ノ間ニ參差トシテ相錯綜**」し、震度分布が土地の構造と調和すると論じ、安政2年大震の被災状況（潰家数＝報告第46号乙・死者数＝東西南北の四域各町の記録 pp.574-579）との照合を図る〔潰家・死者の集計そのものは第46号乙の所在確認が必要で本号の本文ではない〕。**安政2年の震度分布推定図として「第一圖ハ安政大震ノ震度分布圖ト見ル方寧ロ適當ナル位ナリ」と述べる**。
- **赤坂溜池の成因叙述〔確認・副次的〕**: 諸町の沿革叙述の中に「**溜池トハ往古江戶市中ニ分布スル用水ヲ溜メタル大池ニテ 今ノ葵ケ岡ト星ケ岡トノ間ナル低地ハ其ノ池ノ跡ナルベシ**」〔**江戸市中に分布した用水の溜池としての赤坂溜池の位置・成因の1916年説明文**＝[GAZ-116](../gazetteers/GAZ-116.md)（御府内備考赤坂巻の溜池・赤坂川文言群）と対照可能な明治末〜大正初頭の概括の datapoint〕。
- **陰性記録〔確認〕**: 本号のFullTextで「水窪」0件・「谷端」0件・「弦巻」0件・「千川」0件・「蟹」0件・「音羽」0件・「雑司／雜司」0件。**対象四河川名そのものは陰性**（対象域は江戸川（神田川）下流〜小石川大下水・赤坂溜池等の縁辺）。
