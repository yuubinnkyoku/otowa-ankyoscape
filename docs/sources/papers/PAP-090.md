# [PAP-090] 山口高志（1976）「雨天時合流式下水道からの汚濁流出シミュレーション--都内谷端川排水区の場合」〔repo初出〕

- **書誌〔確認: CiNii・2026-11-19〕**: 山口高志「**雨天時合流式下水道からの汚濁流出シミュレーション--都内谷端川排水区の場合**」、『**土木技術資料』第18巻第2号**（**1976年・年次は巻号からの推定**）。CiNii crid [1523388080439170048](https://cir.nii.ac.jp/crid/1523388080439170048)。
- **位置づけ〔観察: 題名からの推定〕**: **「谷端川排水区」をモデル対象にした合流式下水道の雨天時汚濁流出シミュレーション**の技術記事。谷端川排水区を対象区名に冠した下水道技術文献としては、repo既収録の桃園川排水区系水文資料（[PAP-003](PAP-003.md)・[PAP-047](PAP-047.md)）と並ぶ、**谷端川流域の下水道整備研究の初期（1970年代）文献**〔repo初出。谷端川排水区という区分が1976年時点で技術文献の操作単位として使われていたこと自体が、谷端川流域の下水道整備の進行度の傍証になり得る〕。本文未取得のため、シミュレーションに使った管渠・分流先（谷端川のどの区間を対象にしたか）は未確認。
- **制限・未解決**: ①本文は未取得（『土木技術資料』=日本下水道協会系誌。NDL収蔵確認が次回課題）。②年次が巻号からの推定（前述）。③山口高志の所属（土木研究所・下水道局か）は未確認。
