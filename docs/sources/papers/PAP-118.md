## repoとの関連〔観察〕

- **遊歩記ジャンルと四河川**: 開港後の外国人遊歩記（オールコック系・幕使随行記など）は江戸近郊の水景・橋・茶屋の描写を含むことが多い。目白・雑司ヶ谷・王子方面への経路が弦巻川・水窪川（音羽・目白周辺）や千川上水沿いに重なる可能性はあるが、**本文未見のため経路も言及の有無も断定しない**〔所在のみ〕。
- **同筆者**: 及川将基は第33号「天保10年徳川家祥の江戸北郊訪問」〔[PAP-121](PAP-121.md)〕の筆者で、江戸北郊の紀行・訪問記が研究主題という系列〔観察〕。
