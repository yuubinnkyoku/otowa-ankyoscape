# [PAP-016] 雑司ヶ谷研究4：雑司ヶ谷の領域の変遷に関する研究

- **書誌〔所在確認〕**：『日本女子大学紀要 家政学部』第61号（2014年）。住居学科（古賀碧ほか）。[zoshigaya.orgの公開PDF](http://zoshigaya.org/pdf/zoshigaya-study/zoshigaya-study4.pdf)。**2026年11月10日時点でPDFへの直接アクセスはサイト側の自動アクセス遮断により不能**で、以下は検索エンジンの抄録・断片による二次転記。
- **内容〔二次転記：検索結果の抄録〕**：江戸期の絵図類に、**現在の池袋駅西側に位置する弦巻川の源泉であるとされる丸池にあたる池が描かれており、その周辺から西側に延びる谷**が確認できるとする。鉄道や街路の整備によって地域が細分化されたこと、都市インフラ整備の影響下の**1963年の住居表示変更で雑司ヶ谷の領域が狭まった**ことも確認したとする。
- **評価〔推定〕**：丸池と西へ延びる谷の絵図上の観察は、丸池を弦巻川の源泉とする複数の二次読図（[BLOG-028](../blogs/BLOG-028.md)等）とは独立の学術的な読図候補として、丸池の史的実在の裏付けに使える可能性がある。ただし**どの絵図を読んだか（雑司谷村絵図〔[MAP-003](../maps/MAP-003.md)〕等との対応）は抄録では特定できていない**。
