# [PAP-035] 高田陽・白井亮久「武蔵高中標本庫の鳥類剥製標本」（武蔵高中紀要1・2016）

- **書誌〔確認〕**：高田陽・白井亮久「武蔵高中標本庫の鳥類剥製標本：1920年代の採集標本に基づく鳥類のFauna Musashinensisの作成」、『武蔵高等学校中学校紀要』（The Musashi Bulletin）**第1号（2016年10月31日）、pp.45-76**。CiNii Research（crid 1050845762390363648）で書誌・要旨確認（2026-11-13、第60回実行）。武蔵大学機関リポジトリにDSpace handle 11149/1873で登録されているが、本実行環境ではhandle・bitstreamとも自動アクセス遮断で**本文PDFは未取得**。
- **要旨内容〔確認：CiNii要旨〕**：
  - 武蔵高等学校中学校（練馬区）標本庫の鳥類剥製標本を調査し**30種34点**を確認。うち**12点が旧制武蔵高等学校創立期の1924〜1926年に学校周辺で採集**されたもの。
  - Fauna Musashinensis（和田八重造・半径2.5マイル〔約4km〕圏内・10年計画の武蔵野動物相調査）には**これまで鳥類の報告がなく**、12点の標本は同調査に関係するものと考え、**約90年前の武蔵野の鳥類目録を「Fauna Musashinensis Aves (partial collection)」としてまとめた**。
  - 検討の結果、**鳥類のFauna Musashinensisは未刊あるいは作成中のまま途切れたと推測**される。採集に従事していた2名が中途退学したこと、カスミ網を操る技術を持つ人が調査に参加できなくなったことで引き継がれず中断した可能性を著者は挙げる。
  - 既刊Fauna No.1（1929）に鳥類の断片的記録（**2月の冬季観察に限定された目録**・カラス類・オナガ・カルガモなど当時から生息していたはずの留鳥を欠く）があることを指摘。
  - 標本から想起される1920年代の種として、**ムクドリ・ヒヨドリ・スズメ・ホオジロ・シジュウカラ・アトリ・ジョウビタキ・バン**などを挙げる〔水辺依存種のバン（水鳥）を含む〕。
- **repoとの関連〔推定〕**：
  - 学校周辺＝**千川上水・中新井分水（濯川）・江古田川（中新井川）流域**であり、**1920年代の鳥類相（特に水辺依存種バンの記録）が、PAP-033の水生昆虫標本群（カワラハンミョウ・ゲンジボタル・ヘイケボタル・タガメ等）と並ぶ、1920年代の常時水域・池沼環境の生物学的傍証の追加**となる〔種毎の採集地が本文未確認のため、流域内のどの水域由来かは断定しない〕。
  - **Fauna Musashinensisに鳥類調査が存在し未刊のまま中断した事実**は、PAP-033の「武蔵野動植物誌の出版途絶」の理解に鳥類部門という新たな具体例を加える。
