## 要旨の文言〔確認: 総覧レコード要約本文・2026-11-24取得〕

- **鉤手状の堀〔確認・repo初出〕**: 「柳沢家駒込屋敷の外周を廻る、**鉤の手状を呈する幅約7mの堀**が確認された」＝**六義園の調査で初めて確認された外郭を廻る区画遺構**（覆土に水成堆積物が認められる）。
- **上水跡〔確認・repo初出〕**: 「調査区を縦断し、**給水源が千川上水と考えられる上水跡**が確認された」「**上水跡は下部構造を伴い堀を掛け渡し、その様子が『六義園の図』に描かれたものと一致する**」。
- **時期区分〔確認〕**: 遺構確認面3面を詳細検討し**計7期の変遷**を提示。第1面（Ⅰa〜Ⅰc期）＝17世紀末葉〜18世紀後葉（**鉤手形に屈曲する塀と塀に掛け渡す上水跡**が構築）、第2面（Ⅱa〜Ⅱc期）＝19世紀前葉〜中葉（大規模切土による庭園削平・屋敷地東西方向と同軸の2基の道跡）、第3面（Ⅲ期）＝19世紀中葉（硬化面・轍状跡・植栽痕）。各期の遺構はⅠa期の堀・上水跡の軸を踏襲して同軸・同位置に構築。
- **大泉水水分石への同軸延伸〔確認・repo初出〕**: 「**Ⅰa期・Ⅲc期で上水跡が確認され、その遺構を同軸方向に延伸させると、現在の六義園の大泉水の要となる水分石に至ることが判明した。上水跡は千川上水を源とし、木樋を通して大泉水に給水された**」。
- **絵図の信頼性〔確認〕**: 覆土の分析と『宴遊日記』を交えて庭園内の植生・大泉水の水位変化を提示し、「調査結果によって**『六義園の図』に描かれた絵図の内容は、その当時の庭園の様子を正確に伝えている**ことが示された」。

## repoとの関連〔観察〕

- **千川上水→六義園給水の考古学的一次裏付け・repo初出**: 給水の存在と経路をこれまで文献・踏査レベル（[BLOG-043](../blogs/BLOG-043.md)の昭和43年停止説と「流路上」の空気弁蓋観察・[PAP-017](PAP-017.md)の明治10年代再興〔千川上水解散と六義園の関係の行政記録〕）で追ってきたが、**発掘遺構（上水跡5・下部構造・木樋給水）として裏付けた初めての一次記録**。しかも第4地点が屋敷外縁ではなく**屋敷内部の給水末端（大泉水・水分石への同軸延伸）**を押さえた点で、給水経路の具体性が一段上がった。
- **駒込屋敷の位置の具体化**: 給水遺構の実在地点が**本駒込6-16-10（240㎡）**に特定され、巣鴨側本流（分配堰〔[BLOG-043](../blogs/BLOG-043.md)・[BLOG-095](../blogs/BLOG-095.md)〕）〜屋敷内末端までの経路研究に中間点の座標が与えられた。屋敷外区間（千川上水本流から屋敷敷地まで）の遺構は本次調査では未確認＝接続部は今後の課題。
- **『六義園の図』評価の変化**: 絵図が「当時の庭園を正確に伝える」ことが発掘結果と突合で示された＝**六義園の図に描かれた水系要素を歴史資料として引用する際の信頼性根拠**が生じた〔観察〕。
