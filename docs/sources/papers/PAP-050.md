# [PAP-050] 横井時冬「上水渠鑿通ノ紀事──(神田上水○千川上水)」

- **意義〔観察〕**: ①横井時冬（1859-1923・『新編武蔵風土記稿』以来の江戸地誌研究者）による**明治23年時点の千川上水開鑿記事**であり、千川水道会社の給水期（1881-1908）・廃止（1870年上水廃止→灌漑転用）直後の時期に書かれた**近代初期の千川上水史記述**として、江戸期史料と現代研究の間を埋める時点資料になり得る。②題名が**神田上水と千川上水を並記**しており、谷端川の下流（西大下水・小石川）を含む神田川水系の上水史と千川上水を一体で扱う視点が明治期にすでにあったことの傍証候補〔いずれも本文未見のため推定にとどめる〕。
