- **主題の位置づけ〔観察・本文未見〕**: 題名が「**千川用水拡張工事を中心にして**」と明示し、幕末期の滝野川大炮製造所建設と周辺村落の関係を千川用水（千川上水）の拡張工事の枠で論じる論文〔**[PAP-079](PAP-079.md)（馬場永子「幕末の滝野川反射炉について」・2014）の21年先行の研究候補**で、同一の滝野川大炮製造所＝反射炉群を千川用水の水利史的文脈で扱った点が題名レベルで共通する。大炮製造所の用水供給が千川用水の下流側での拡張（新規分水・流量増）実務とどう結ばれるかの説明の有無・年代の特定は本文未見のため一切断定しない〕。
