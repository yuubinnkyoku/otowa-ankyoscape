# [PAP-015] 雑司ヶ谷研究9：明治期以降の宅地形成の歴史

- **書誌〔確認〕**：『日本女子大学紀要 家政学部』第67号（2020年）、pp.111–。住居学科（杉浦美鈴・大山祐加子・薬袋奈美子）・人間生活学研究科（原わかな）。[雑司が谷のまちづくり（zoshigaya.org）の公開PDF](https://zoshigaya.org/pdf/zoshigaya-study/zoshigaya-study9.pdf)を2026年11月10日に直接確認。雑司が谷研究シリーズの第9報。
- **内容〔確認：抄録・本文冒頭〕**：木造密集市街地である豊島区雑司が谷一〜三丁目の路地と宅地形成の変遷を、絵地図と国土地理院旧版地図・建物棟数の推移で追い、地域住民へのヒアリングと突き合わせて確認したとする。**鬼子母神堂・本浄寺の周辺のように古くから宅地だった場所と、弦巻川の暗渠化に伴って宅地化した場所が明確になった**と報告する。江戸・明治初期は近郊農業と鬼子母神堂を中心とした町で、建物棟数の急増は大正期以降。
- **住民証言〔確認：論文掲載のヒアリング〕**：「父親が弦巻川で大根を洗っていた」「雑司が谷と地名に谷という漢字が入っている通り谷となっていて田んぼの面積は少なく多くが畑だった」等の地域住民のコメントを掲載。**弦巻川で大根を洗ったという記憶は、[GOV-017](../gov/GOV-017.md)（かたりべ23号「弦巻川――その1・大根を洗う川」）と独立に一致する別の証言**であり、記憶の分布を増やす。
- **制限〔未解決〕**：今回確認したのは抄録と冒頭部で、**暗渠化に伴う宅地化と判定した区画の特定方法・座標・図版の再現は未精読**。1926年『高田町中部・北部住宅明細図』を参考文献に挙げるが図版の再現がない点は、[MAP-037](../maps/MAP-037.md)の2026年11月9日の確認と同じ。宅地化の判定をそのまま弦巻川の正確な旧流路の復原に使わない。
- **三河川への使い方〔推定〕**：弦巻川の1932年（高田町による暗渠化）以降の雑司が谷の土地利用再編を区画・路地単位で扱う学術的先行研究として、[弦巻川調査ノート](../../弦巻川.md)の土地利用記述との照合に使える。暗渠化→宅地化の順序は弦巻川の流路の位置そのものの証拠ではない。
