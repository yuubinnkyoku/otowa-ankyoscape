# [PAP-009] 東京大学埋蔵文化財調査室『東京大学構内遺跡調査研究年報6』小石川分館地点発掘調査（2008年）

- **原資料〔直接確認〕**：東京大学埋蔵文化財調査室『東京大学構内遺跡調査研究年報6』（**2008年刊、2006年度年報**）第2部「東京大学白山構内の遺跡 総合研究博物館小石川分館地点発掘調査報告」、**pp.151–186**。原文PDFの**pp.151、159–165、171–173**を確認（2026年11月1日）。[東京大学学術機関リポジトリ・原文PDF](https://repository.dl.itc.u-tokyo.ac.jp/record/54969/files/nenpou6.pdf)／[東京大学埋蔵文化財調査室の遺跡紹介](https://www.aru.u-tokyo.ac.jp/utokyo-sites.html)。
- **調査地点・時期〔確認〕**：**文京区白山3丁目7番1号**、東京大学総合研究博物館小石川分館（旧東京医学校本館）増築に伴う**30.3㎡**の発掘。現地調査は**2000年11月27日～12月4日**であり、**2008年は報告書刊行年**（原文p.151「例言」）。既収録の2023–2024年調査『原町西遺跡』（文京区白山4丁目10番8）とは**別の調査地点**。
- **地形・湧水〔確認：報告書の記述〕**：白山台地の台頂部は**標高約25m**、南側の小石川谷は**約10m**で、急崖下に多くの湧水地が認められるという（p.164）。これは調査時点の地形・湧水についての記述であり、特定の湧出口の位置・湧出量を測定した一覧ではない。
- **御殿堀候補SD1〔確認と報告者の推定を区別〕**：白山台地南斜面下の大形溝**SD1**は、調査区内で**幅9.20m以上・深さ2.70m以上**を確認。調査者は壁面勾配約37°から**幅11.2m以上**を推定する（pp.165、171）。**深さ約2.60mで地下水が湧出**し、底部の確認を断念した。下部には水分の多い堆積層があり、上部は人為的に埋め戻されたと推定する。SD1を**1698年（元禄11）の小石川御殿拡張時の外周堀**に比定し、**1713年（正徳3）の御殿廃止後に埋め戻された**とするのは、絵図・出土遺物・他地点との比較による**報告者の解釈**（pp.164–165、171–173）。
- **井戸候補SE2〔確認／推定〕**：SD1より古い層の**SE2**は長軸約110cm、短軸約80cm、深さ約185cmの遺構で、**調査時に底から絶えず水が滲出**したと記す。報告者は井戸の可能性を指摘するが、**廃絶年代は不明**（p.166）。2000年の発掘時の湧出を、江戸時代の恒常的な自然湧水の直接観測とみなさない。
- **比較上の価値と限界〔観察／未解決〕**：小石川谷の**南斜面に面する別地点**で、人工堀の規模・埋戻し・地下水の実地記録が得られる。既収録の2025年『原町西遺跡』における**千川上水系の取水路3本**と比較し、御殿堀の西端・北側・取水部の配置を検証できる。ただし**SD1・SE2は谷端川の自然河床ではなく、旧谷端川への放流先・御殿堀との水理接続も未確認**。現代の発掘時地下水位を1698年当時の水位にそのまま当てはめない。
