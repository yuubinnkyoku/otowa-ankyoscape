# [PAP-038] 亀岡2021「中新井村の土地区画事業のはじまり（１）」（武蔵高中紀要5・pp.77-92）

- **書誌〔確認〕**：亀岡岳志「中新井村の土地区画事業のはじまり～練馬区豊玉地域・中村地域の景観形成（１）～」、『武蔵高等学校中学校紀要』**第5号（2021年3月31日）、pp.77-92**。武蔵大学機関リポジトリ DSpace **handle 11149/2248**、bitstream PDF（ko_chu_kiyo05_077_092_kameoka.pdf・2.36MB）。直は遮断、**Wayback id_付きURLで本文（冒頭～図2解説付近）を取得**（2026-11-13、第62回実行）。英文副題 "Beginnings of the Land Readjustment Project in Naka-arai-mura"。
- **主要事実〔確認：本文冒頭・要旨〕**：
  - **明治末〜大正期の中新井村（現練馬区豊玉地域・中村地域）は「南部に谷戸を有する台地上の農村」**であった（明治44年地形図上の水田着色図で示す。水色が水田、青は川と用水路、赤は中新井村の範囲）。
  - 現在の地形図との対比で**「水田は全くなくなり、かつて水田があった谷戸の低地やその両岸の崖線は平坦な地形に変わっている。河川や用水路の多くは暗渠化され、開渠部分も流路が変更されている」**〔中新井川・千川上水分水群（濯川を含む）の近代的変遷を学術論文レベルで初めて明文化した記述＝GOV-005・BLOG-105・PAP-033（1930年代区画整理で水辺環境喪失）の引用元亀岡研究の本体〕。
  - 要旨〔確認〕：関東大震災を契機に東京郊外の宅地化が急進し、中新井村では昭和戦前期に全村で土地区画整理を実施。**村当局者が内務省系の都市計画理念に賛同して積極的に行動し、事後的に村内の同意を得るプロセス**だった。
- **repoとの関連〔確認〕**：武蔵学園所在地の豊玉地域＝旧中新井村＝**千川上水中新井分水（濯川・中新井川）の流域**。PAP-033が引用した「亀岡（2017）」の研究シリーズの続編で、中新井分水流域の水環境喪失（湧水減衰仮説の土地利用側メカニズム）を区画整理研究から直接裏付ける。
- **注意**：取得した本文部分（冒頭〜pp.78付近）では千川上水・濯川の固有名は確認できず、汎用的に「河川や用水路」と記す（PDF全文2.36MBの残り部分の言及は未確認、断定しない）。「（１）」とある通り続編あり→PAP-039（第6号・西貝家文書）。
