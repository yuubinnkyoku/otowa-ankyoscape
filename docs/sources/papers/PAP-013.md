# [PAP-013] 歴史的地下水環境の復原―史料と古地図から見た東京の井戸と人間活動

- **書誌〔確認〕**：谷口智雅・谷口真人、2007年度日本地理学会春季学術大会、発表番号 **P845**。『日本地理学会発表要旨集』2007年春季大会。**J-STAGE公開日：2007年4月29日**。DOI: [10.14866/ajg.2007s.0.195.0](https://doi.org/10.14866/ajg.2007s.0.195.0)。[学会公開の発表要旨](https://www.jstage.jst.go.jp/article/ajg/2007s/0/2007s_0_195/_article/-char/ja)を直接確認した（2026年11月3日）。
- **対象図・範囲〔確認：著者による要旨〕**：**1887年（明治20年）刊の「1/5000東京図測量原図」に記された井戸記号**から、近代東京の井戸分布を復原したと報告。対象は東を隅田川右岸、西を新宿・山手線内付近、北を上野・目白、南を隅田川河口・麻布とする東京中心部約8km四方。**1887年は要旨に記された地図の刊年であり、全井戸の掘削年や測量年ではない**。
- **地形・土地利用との関係〔確認：著者による分析結果の要旨〕**：井戸記号は住宅密集地・屋敷敷地内などに分布し、**低地・台地・旧河道という地形条件とは必ずしも一致しない**と報告。現代の文京区についても井戸の分布を把握し、住宅地の路地・寺社に井戸があるとする。要旨中の「この頃の東京の掘り井戸は約45,000とも言われ」は**既往の概数の紹介**であり、本研究が地図上で数えた確定数として扱わない。
- **三河川への使い方〔推定〕**：文京区内の**水窪川・弦巻川の音羽谷下流**、**谷端川（小石川）の下流**では、既登録の[MAP-007](../maps/MAP-007.md)（五千分一東京図測量原図）を、**水路・谷地形だけでなく井戸記号・宅地・寺社の分布**も含めて再読図する価値がある。井戸の存在は水利用の指標だが、**井戸の位置だけから湧出口・伏流水の方向・旧河道・三河川の接続を推定しない**。
- **未解決／制限**：公開ページで直接確認できたのは**学会発表要旨（図・地点別井戸一覧なし）**で、個々の井戸の座標・現存・井戸深・地下水位・水質・調査年は示されていない。対象範囲の端にある池袋西部・谷端川上流の網羅性も未確認。原地図の図葉別井戸記号と著者の集計図・文京区現地調査記録を別途照合する必要がある。**2007年は発表年で、河川改修・暗渠化・井戸築造の年ではない**。
