# [PAP-032] 角田清美「千川上水の歴史と水利用」

- **書誌〔確認: 東京都水道歴史館デジタルアーカイブ ro-da 書誌頁（2026-11-13 直接取得）〕**: 角田清美 著「千川上水の歴史と水利用」、**羽村市郷土博物館紀要 第37号（94p・21cm）**、羽村市郷土博物館 編・発行、**令和5年（2023）3月**。水道歴史館の所蔵は**開架書架B・逐次刊行物・館外貸出不可**。
- **同号の収録論文**: 同号には**岡崎学「〈資料紹介〉『治水要辨』と森田通定」**と本論文の2本を収録〔『治水要辨』は玉川上水系の治水技術書で、千川上水の上流側（羽村堰＝玉川上水取水口）からの水利用史文脈で読まれる資料〕。
- **repoへの意義**: 2023年刊行の千川上水史の**新規学術文献**であり、repoの千川上水文献群（BOOK-060〜077・PAP-022〜031）に欠けていた直近年次の紀要論文。水利用の観点（灌漑・水車・上水の用途別整理）が論題から推定されるが、**本文未確認のため内容の断定はしない**。
- **関連**: 羽村市郷土博物館は玉川上水の取水口（羽村堰）を担当地域とする博物館で、千川上水＝玉川上水の分水（千川分水）という上流側視点からの千川研究という特色をもつ〔[GOV-064](../gov/GOV-064.md)千川分水写真との関係で、分水口側の水利用記録という観点はrepoの下流側資料（板橋・練馬・豊島）を補う〕。
- **頁数〔確認: 羽村市公式サイト 紀要第37号目次頁（2026-11-14・Wayback 20241205130542 保存版で取得）〕**: 本論文は**pp.39〜85**（同号の岡崎学「〈資料紹介〉『治水要辨』と森田通定」はpp.37〜38）。PDFの所在（羽村市公式サイト掲載の有無）はこの目次頁では確認できず未確認。
- **制限・未解決**: 本文はネット非公開・館外不可。羽村市郷土博物館での現物確認、またはCiNii・羽村市図書館での所在確認が次の一手。『治水要辨』と千川の関係も本文確認後に追記。
