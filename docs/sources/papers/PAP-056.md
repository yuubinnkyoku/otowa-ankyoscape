# [PAP-056] 君塚仁彦「増上寺村々の『由緒』と巣鴨村」（1990）〔repo初出〕

- **書誌〔確認: 豊島区立郷土資料館刊行物ページを2026-11-14に直接取得〕**: 君塚仁彦「**増上寺村々の『由緒』と巣鴨村**」、豊島区立郷土資料館研究紀要『**生活と文化』第4号**（**1990年3月30日発行**、1,100円）収録。同号収録: 青木哲夫（集団学童疎開・序説）・長谷幸江・山辺昌彦（秋田雨雀）・海津一朗（美濃真壁氏）・福岡直子（民俗変容）等。
- **位置づけ〔観察・要注記〕**: **巣鴨村は谷端川・千川上水の下流域に位置する寺社領（増上寺領）の村**で、その「由緒」をめぐる村落史の論文。巣鴨村の由緒・領主関係が谷端川・千川の流路・水利と関わる記述を含む可能性があるが、**本文未確認のため四河川との関係の濃淡は不明**。断定しない。
- **制限・未解決**: 本文未確認（紀要本文は豊島区立郷土資料館での閲覧・購入）。増上寺領の由緒書の所在（『新編武蔵風土記稿』以外）も未調査。
