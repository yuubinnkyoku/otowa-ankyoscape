# [GOV-555] 武蔵野・三鷹「#平和まち歩き」・NTT武蔵野研究開発センタ頁〔東工場北辺の研究所化・1997年不発弾2発・地下道2001年解体の行政解説〕

- **書誌〔確認: 本文全文・2026-11-23取得〕**: 「武蔵野・三鷹 **#平和まち歩き**」サイトの個別スポット解説頁「**NTT武蔵野研究開発センタ（中島飛行機武蔵製作所「組立工場」跡地）**」 https://www.city.mitaka.lg.jp/peace-tourism/spots/musashino_01_10.html 〔Copyright© Musashino City / Mitaka City. の表記＝**武蔵野市・三鷹市の共同企画とみられる平和観光サイト**（URLは三鷹市ドメイン配下）。頁個別の公開・更新年次の明記なし〕。サイト内構成は「戦争とまちの歴史・散策コース・戦争遺跡・平和スポット・平和への取り組み」で、本頁は散策コース上のスポット解説の一つ。
- **東工場の研究所化の文言〔確認・repo初出〕**: 「中島飛行機武蔵製作所は、激しい空襲によって徹底的に破壊された。そのため、工場として継続されず、空襲でも残った鉄筋コンクリート造の建物の躯体は、改修工事を施されて、学校校舎や研究所の建物として利用された。**その最も早い事例が、昭和25年（1950年）、東工場の北辺に開設された電気通信省「電気通信研究所」、現在のNTT株式会社武蔵野研究開発センタである。**電気通信省はその後、逓信省を経て、日本電信電話公社（電電公社）となり、現在のNTT株式会社となった」＝**1950年・東工場北辺・電気通信省電気通信研究所の開設**（電気通信省→逓信省→電電公社→NTTの系譜）〔東工場の戦後転用の最早期事例という位置づけ文言ともにrepo初出〕＋「**その研究所の2、3号館は中島飛行機武蔵製作所の「組立工場」を改修したものだった**」＝**「組立工場」躯体の2・3号館への転用**〔「組立工場」の名称・2・3号館ともrepo初出〕。
- **地下道の文言〔確認・repo初出〕**: 「**地下には、中島飛行機武蔵製作所の特徴の一つである「地下道」も残っていたが、平成13年（2001年）、老朽化のため取り壊された**」＝**中島飛行機の特徴の一つとされる「地下道」の存在と2001年取り壊し**〔[BLOG-304](../blogs/BLOG-304.md)読売記事の「工場内を張り巡らされた地下道を通じて各職場に赴いていた」証言・[BLOG-305](../blogs/BLOG-305.md)武蔵野中央公園西口のコンクリート遺構（一説には工場地下通路の残骸）と対照できる行政側文言〕。
- **不発弾の文言〔確認・repo初出の数値群〕**: 「**同研究所構内からは、しばしば不発弾が発見されており、現在の本館棟（平成11年（1999年）竣工。地下2階地上12階）の建設工事中の平成9年（1997年）には、2000ポンド（1トン）爆弾の不発弾2発が相次いで発見された。周辺地域、半径500m以内は立ち入り禁止となり、自衛隊による不発弾処理が行われた**」＝**1997年・2000ポンド爆弾不発弾2発・半径500m立ち入り禁止・自衛隊処理**〔repo初出。本館棟1999年竣工・地下2階地上12階の建物諸元も初出〕＋「現在、構内への立ち入りは史料館見学時、関係エリアのみである」＝構内に**史料館**が存在する文言（見学の可否・案内の詳細は本文になし）。所在地＝**東京都武蔵野市緑町3-9-11**。
- **意義〔観察〕**: ①[BLOG-302](../blogs/BLOG-302.md)（住民団体2026年6月要望書「**全面的な不発弾調査の再実施**」）の文言が前提とする「過去の不発弾調査・処理」の実績を、**行政側解説（1997年・NTT構内・自衛隊処理）として初めて裏付ける記録**＝同要望文言の「再実施」の解釈が「かつて断片的な調査・処理が行われた」を指す公的根拠となる候補。②武蔵野中央公園＝西工場跡（[BLOG-302](../blogs/BLOG-302.md)・[GOV-549](GOV-549.md)）に対し、本頁は**東工場側（緑町・NTT構内）の戦後転用と不発弾実績**を担う＝中島飛行機跡地の東西分割を行政解説側で確認する一対。③時系列＝1944〜45年の空襲→戦後の富士産業・自衛隊処理（[GOV-556](GOV-556.md)）→1997年NTT不発弾→2001年地下道解体→2025年三鷹市掘削調査（[BLOG-304](../blogs/BLOG-304.md)）→2026年調節池工事の不発弾懸念（[BLOG-302](../blogs/BLOG-302.md)）という**不発弾レーンの連続記録の欠けた1997年点**が埋まる。
