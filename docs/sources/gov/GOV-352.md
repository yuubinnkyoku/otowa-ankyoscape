# [GOV-352] 書上帳 第40冊 — 昌平橋外の堀井戸の請負史と筋違橋外の千川上水助成地

- **書誌〔確認〕**: 『書上帳』第40冊（天明期〜寛政期の町奉行・御作事奉行関係の届書・御届書付・下げ札書面の綴）。NDL次世代デジタルライブラリー [book/2547574](https://lab.ndl.go.jp/dl/book/2547574)。同一シリーズの第122回登録冊（[GOV-276](GOV-276.md)系）に続く未登録冊。**引用文言はすべてOCR由来で要原文照合**。
- **昌平橋外明地際の堀井戸の水汲請負の変遷〔確認・天明期千川上水の通水開始の独立文言候補〕**: 井戸の請負替わりの伺書（「未七月」＝天明7未年7月の下げ札書面）に——「**昌平橋外明地ニ有之候堀井戸之儀 近辺武家丁共呑水二遣候に付 右井戸預け置候はゝ壱ヶ年金三拾両冥加金上納可仕旨 安永七戌年 深川永堀丁加東や甚五郎与申者申立候二付 吟味之上五ヶ年季之横りに而願之通被仰付候処 天明二寅年千(川)上水出来仕候間 水汲人無之候二付上納難仕候而請負御免被成下候様同三(卯)午年相願**」「**牧野大隅守町奉行勤役之節 右井戸千川上水陸負(＝請負候補・要照合)人共え無年限ニ而預ケ置 壱ケ年金三拾両ツヽ上納之積り吟味仕 同四辰年ゟ冥加金上納仕来候処 此度千川上水相止候二付 右井戸丁(＝町候補・要照合)奉行ゟ御普請方え引渡**」〔**①昌平橋外明地際の堀井戸（掘井戸）が安永7戌年（1778）に深川長堀町の加東屋甚五郎の5ヶ年季請負（冥加金30両/年）となっていたこと、②井戸の水は「**筋違橋御門外ゟ下谷辺迄之内**」の武家方町方の呑水に供され水銭を取立てていたこと、③**「天明二寅年（1782）千川上水出来仕候間 水汲人無之」＝千川上水の通水開始（出来）によって水汲人がいなくなり請負が成立しなくなったこと**、④牧野大隅守（町奉行）勤役中に井戸が千川上水請負人共へ無年限で預け置かれ天明4辰年（1784）まで冥加金が上納されたこと、⑤「此度千川上水相止候」（天明6年〔1786〕）で井戸が町奉行から御普請方へ引き渡されたこと**〕〔**③の「天明二寅年千川上水出来仕候間」は、安永9年10月27日の上水掛渡仰付（[GAZ-041](../gazetteers/GAZ-041.md)〜045）と天明6年の差止（[GOV-215](GOV-215.md)〜[GOV-218](GOV-218.md)）の間の**通水開始年代（天明2年＝1782）を伝える独立の文言候補**で、[GOV-353](GOV-353.md)（天明2〜3年の堀割御普請の御褒美）と年代が整合する。①井戸の水汲業が上水の給水で廃業し、差止後に請負が再開される構造は、同書上の「**右堀井近年千川上水相懸り水汲遣ひ候儀暫中絶仕先年汲方相定候共**」「**千川之水懸渡ニ付水汲候者諸負(＝請負候補)人手を離候段**」でも裏返しに記録される。⑤の後、請負人甚五郎の病死を受け神田多町壱丁目の中屋七兵衛が冥加金初年15両・2年目以降30両の10ヶ年季で再請負を願い出ている（水汲人一同「鎌」32文宛の取立の先例＝御勘定所書留参照の文言も）**。
- **筋違橋御門外の千川上水助成地の実務詳細〔確認・[GOV-215](GOV-215.md)（天明撰要類集[49]の「筋違橋外明地矢来際外弐ヶ所…信濃守ゟ達書付」）の同時代の届書群〕**: 同冊の天明6午年閏10月付けの御届書付群に——「**千川上水助成地 筋違橋御門外明地際三方高床地面請取候儀申上候書付御届**」「**先達而被仰渡候千川上水請負人共助成に被下置候筋違橋御門外明地三方商床地所 且又右明地際に有之候堀井共 山村信濃守方ゟ請取申候**」「**先達而被仰渡候千川上水請負人江相渡置候筋違橋御門外明地外廻り三方折廻シ商床番屋地所 山村信濃守ゟ請取申候**」〔**①筋違橋御門外明地の三方高床地面・三方商床地所・明地際の堀井・外廻り三方折廻しの商床番屋地所が千川上水請負人の助成地として下し置かれ、山村信濃守（御普請奉行・町奉行）方が請け取ったことの届書**＝**助成地が商床（商売床）・番屋付きの明地で構成されていた実務側の具体**（[GOV-215](GOV-215.md)の「矢来際外弐ヶ所」文言の構造の補充）。②「昌平橋外堀井戸」の文言と「筋違橋御門外明地際に有之候堀井」の文言が同一井戸か別井戸かは本冊では断定できない。③閏10月付け＝天明6年の上水差止（[GOV-215](GOV-215.md)〜[GOV-218](GOV-218.md)の閏10月差止）と同時期の引渡・請取の届書である可能性があるが、届書相互の前後関係は原文照合まで保留**〕。
- **位置づけ〔観察〕**: 千川上水の天明期再興の末端（神田川筋・昌平橋〜筋違橋外〜下谷方面）の呑水と水銭・助成地の実務を、町方の届書・伺書レベルで初めて連続して記録する冊。上水の通水が既存の堀井戸水汲業を置換し、差止によって旧来の水汲請負が復活する一連の変遷は、市中給水の経済構造の datapoint。
