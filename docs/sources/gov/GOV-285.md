# [GOV-285] 御普請方書上帳（文化13〜安政4）— 神田玉川両上水野方堀通と狭山池助水堀通の恒例の洲浚・葭茅刈取見廻りの記録群

- **書誌〔確認〕**: NDL次世代デジタルライブラリーの『（御普請方）書上帳』シリーズ（神田玉川上水関係の御普請方の書上の年代順綴）。本資料は**野方堀の語で横断検索してヒットした12冊**を1資料として登録する（各冊の書誌はNDLの [book/2587274](https://lab.ndl.go.jp/dl/book/2587274) 等に個別URLがある）。対象冊〔確認〕: 第49冊（文化13-14）[book/2587274](https://lab.ndl.go.jp/dl/book/2587274)・第51冊 [book/2587276](https://lab.ndl.go.jp/dl/book/2587276)（文政11年9月の記録を含む）・第52冊 [book/2587277](https://lab.ndl.go.jp/dl/book/2587277)（天保3年10月の記録を含む）・第54冊 [book/2587279](https://lab.ndl.go.jp/dl/book/2587279)・第55冊 [book/2587280](https://lab.ndl.go.jp/dl/book/2587280)・第57冊 [book/2587282](https://lab.ndl.go.jp/dl/book/2587282)・第59冊 [book/2587284](https://lab.ndl.go.jp/dl/book/2587284)・第60冊（弘化4-5）[book/2547577](https://lab.ndl.go.jp/dl/book/2547577)・第61冊（嘉永2-3）[book/2547578](https://lab.ndl.go.jp/dl/book/2547578)・第62冊（嘉永4-5）[book/2547579](https://lab.ndl.go.jp/dl/book/2547579)・第63冊（嘉永6-7）[book/2547580](https://lab.ndl.go.jp/dl/book/2547580)・第65冊（安政3-4）[book/2547582](https://lab.ndl.go.jp/dl/book/2547582)。**引用文言はすべてOCR由来で要原文照合。**
- **恒例業務の文言〔確認・repo初出の通時記録〕**: 各冊にほぼ同型の書上（御勘定所宛の御断・御扣の請取書付）が現れる——
  - 「**神田玉川両上水野方堀通葭茅雑木苅取見廻り為御用 差遣候 地割株(棟)梁弐人 宿代銀旅御扶持方請取候儀**」（文化13-14冊・文政11年・天保3年等）／「**神田玉川両上水野方堀通淵(渕)浚葭茅其外苅取見廻り為御用 差遣候 地割棟梁弐人**」（天保3年）＝**神田上水・玉川上水の両方の「野方堀通」について、葭茅・雑木の刈取と淵浚（浚渫）の見廻りのため地割棟梁2名を年次で派遣した**記録が文化13年（1816）〜安政4年（1857）の約40年にわたり綴に現れる（毎年の実施か・数年おきかの頻度の確定は各冊の年月日の通時配列の照合待ち）。
  - 支給の規模〔確認・文政11年の例〕:「**地割棟梁弐人 当子(文政11)八月十九日出立 同九月七日罷帰り 一ヶ月壱人銀半枚之積り 米三石七斗五合 代金三両壱分弐朱 銀七分四厘五毛**」＝**約1ヶ月の出立**・地割棟梁1人あたり銀半枚＋米（1日9升7合5勺余の割）＋飯米の規模。2587274（文化13冊）にも「**地割棟梁壱人 当子壬八月廿六日出立 同九月十九日罷帰り…一ヶ月限半数之積り**」等の同型の文言。
  - 派遣範囲の文言〔確認・repo初出〕: 2587274に「**右は神田上水水元井之頭池ゟ関口村迄 玉川上水水元福生村新堀…**」の文言が続き、**神田上水は井之頭池から関口村まで**を見廻ることが明記される（玉川上水側は福生村の水元から＝以下の文言の割付はOCR要照合）＝**「野方堀通」の見廻りの区間が水元から江戸側の終点（関口）まで指定される一次記録**（[GAZ-048](../gazetteers/GAZ-048.md)の関口大洗堰・[GOV-268](GOV-268.md)の関口水番人の系譜の補助）。
- **狭山池助水堀通の同時記録〔確認・重要な制度面の対校〕**: 文化13冊・天保3年冊・弘化4冊・嘉永6冊等に「**右は神田玉川両上水野方堀通 幷箱根ヶ崎村狹山池ゟ玉川上水江之助水堀通廿埋(?)出淵渡 葭茅其外苅取見廻り為御用 差遣候地割棟梁**」の文言＝**野方堀通の洲浚・刈取見廻りの業務が「箱根ヶ崎村狹山池から玉川上水への助水堀通」の見廻りを併せて行う**ことを示す記録（天保3年冊は「狹山池」2回・文化13冊も「狹山池」「狹山地」の文言を含む）＝[GOV-283](GOV-283.md)（見廻役の専任人事・文政〜慶応）と対校すると、**常設の見廻役（村方人員・年々金壱両）と幕府御普請方からの地割棟梁の年次派遣の二系統**が併存した制度構造の候補が読める（**両者の分担の断定は本資料群のみではできない・文言上は「幷」で一つの業務に纏められている**）。
- **行政上の枠〔確認〕**: 「御勘定所え御断御扣」・「御普請方下奉行」の宛・裁可文言（文政11年＝初鹿野河内守・大河内肥前守、天保3年＝勝志摩守・泉本正助、御普請方改役森川八兵衛・渡辺甚十郎等）＝上水の野方堀通の維持が御勘定所経理で実施された幕府直轄業務であることの帳簿面の裏付け。

## 制限・未解決

- ①すべてOCR由来で「洲浚／渕浚／淵浚」「株梁／棟梁」「廿埋(?)出淵渡」等の文言の原字形は照合必須。②各冊の同型書上の初出年・実施頻度（毎年か数年おきか）の通時配列の確定は未了（12冊の日付の全数抽出までは実施せず・文化13・文政11・天保3の3冊の全文確認と残り9冊のキーワード抽出のみ実施）。③「野方堀通」の指す範囲（神田上水区間＝井之頭池〜関口を含む点）は[GOV-268](GOV-268.md)の「野方堀通の語の使われ方の注意」と整合するが、玉川側の区間の下限（保谷・淀橋・四谷大木戸のいずれか）は本資料群の文言では確定しない。④狭山池助水堀通の見廻の業務の性質（専任見廻役との分担）は推定の域を出ない。
