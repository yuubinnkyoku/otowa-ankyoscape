# [GOV-095] 板橋区公文書館電子展示室52号「いたばしの『加賀』」

- **書誌〔確認〕**: 板橋区公式サイト「こうぶんしょ館電子展示室52号 いたばしの『加賃』」（ページ番号1009255・更新日2020年1月25日）。平成20年7月の金沢市との友好交流都市協定締結（2008年7月9日）記念の地下展示（電子展示室52号）に基づく頁。**直アクセスは本実行時点で「お探しのページを表示できません」のため、Wayback Machine（2024年スナップショット）で本文全文取得**〔[GOV-083](GOV-083.md)と同一の回避手段〕。
- **〔確認・repo初出〕 下屋敷御林大綱之絵図の図版と原本所蔵**: 頁内に**「下屋敷御林大綱之絵図（原本玉川図書館蔵）」の図版キャプション**。[BLOG-146](../blogs/BLOG-146.md)（第47回格上げ）が「板橋区公文書館電子展示室で閲覧可」と記録した当該絵図の**展示頁の特定と原本の所蔵図書館（玉川図書館）の明記＝第47回課題③の部分解消**。
- **〔確認〕 御成橋・大山・石神井川**: 「下屋敷『御成橋』の現在」「下屋敷『大山』の現在」「下屋敷内を流れた石神井川」の3点の本年（2020年）撮影写真を掲載〔**下屋敷内の橋・築山・石神井川の地点群の公式写真記録**〕。大山は「**大池や築山（大山）が配され**」とあり、[BLOG-080](../blogs/BLOG-080.md)記録の「大山」地名の由来検討に対し、下屋敷内の築山の呼称という屋敷側の文脈を提供する。
- **〔確認〕 拡張と転用の沿革**: 延宝7年（1679）前田綱紀が6万坪拝領→**最終的に21万坪余**（「江戸にあった大名屋敷地の中でも最大の広さ」）。**明治初年までは屋敷が続き、その後は石神井川の水力を利用できたことから陸軍関係の工場などに転用され、戦後には学校用地等となった**〔[GOV-093](GOV-093.md)の21万8千坪表記と整合。陸軍工場→学校用地の転用履歴の公文書館側記述〕。
- **〔確認〕 その他**: 2007年11月23日板橋区開催「加賀藩学講座」に定員40人に対し196人の応募。石神井川遊歩道の兼六園「徽軫灯籠」型オブジェ。添付PDF「我が町にあふれる『加賀』」「梅鉢紋と加賀中学校の校章」。
- **意義**: BLOG-146が言及した「下屋敷御林大綱之絵図」の電子展示の実体（52号）と原本所蔵（玉川図書館）が公式頁レベルで特定できた。平尾邸の大池への千川用水引き入れ（[BLOG-146](../blogs/BLOG-146.md)・[GOV-093](GOV-093.md)）の検討に必要な屋敷側の空間（御成橋・大山・石神井川の位置関係）の一次材料となる図版群。
