# [GOV-173] 1891年 談話筆記 — 千川上水の同時点一次数値

- **書誌〔確認〕**: 『水道及道路橋梁河川等ノ改良ニ関スル談話筆記』（1891年・東京府・市区改正・水道改良関係の談話筆記）。NDL次世代デジタルライブラリー [book/845862](https://lab.ndl.go.jp/dl/book/845862)。OCRテキストで千川上水関係を確認。**数値はOCR由来で要照合。**
- **千川上水の現況数値〔確認・repo初出の同時点数値〕**: 明治24年（1891）時点で千川上水は**保谷村で玉川上水を分派**し、水路は**巣鴨町溜池に至るまで五里六丁余**、うち**無葢溝（開渠）172間・樋管3,707間**、**本郷・下谷の一部・人口凡1.7万**に給水、**千川上水は千川水道会社の所有**。**「玉川神田両上水の如く取締の習慣なく五里余の水路に雨水汚水の流入するは二上水よりも甚し」**＝明治後期の民営千川水道の規模・水質評価の同時点一次記録。
- **位置づけ〔観察〕**: [GOV-172](GOV-172.md)（明治13年岩崎弥太郎等の再興許可）〜[BOOK-077](../books/BOOK-077.md)（明治40会社閉鎖）の間の**千川水道会社経営期の水路構成（開渠172間 vs 樋管3,707間）・給水規模**を初めて数値で固定。樋管が全延長の9割超を占める点は、江戸期から継承した埋樋構造（[GAZ-024](../gazetteers/GAZ-024.md)）が民営期も変わらず維持されたことを示す〔観察〕。

## 制限・未解決

- ①数値（172間・3,707間・1.7万人・五里六丁余）はOCR由来で原本照合を要する。②巣鴨町溜池の位置（巣鴨のどの溜池か）は本書では特定されない。③「溜池」が当時の水量調節施設として機能したかは本文で未確認。
