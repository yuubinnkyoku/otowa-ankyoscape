# [GOV-206] 東京市予算案管見 昭和2年度 — 千川筋一部改良費（1927）

- **書誌〔確認〕**: 東京市政調査会『東京市予算案管見』（昭和2年度・1927）。NDL次世代デジタルライブラリー [book/1280176](https://lab.ndl.go.jp/dl/book/1280176)。**引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **「千川筋一部改良費」の新規計上〔確認・repo初出〕**: 昭和2年度（1927年度）普通会計で「**緊急止ムヲ得スト認ムル**」新規事業として東京市が認めた一覧の道路築造費に「**千川筋一部改良費 八六、〇〇〇（円）**」＝**1927年度の東京市予算に「千川筋」の道路改良86,000円が新規事業として計上された**ことを記録する。同表の道路築造費は新宿御苑附近55,460円・芝区高輪町大崎間45,380円・千川筋一部改良費86,000円ほか、全体の新規事業合計1,224,853円。著者側は「其の『緊急止ムヲ得スト認ムル』新規事業ガ餘リニ見るべきものなきは遺憾の極み」と批判的に列挙。
- **位置づけ〔観察〕**: [GOV-180](GOV-180.md)（1925年決定の街路速成事業「**千川筋ノ街路**」・総事業費1,614.5万円・大正14年度〜昭和6年度の7箇年・執行は昭和6年度から7年度へ1箇年延期）と[GOV-187](GOV-187.md)（1938・一等大路第一類第十四号路線の路線確定）の間の**1927年の「千川筋」観測点**。街路速成事業の継続予算か独立の改良事業かは本文では区別できず断定しない〔いずれにせよ「千川筋」の道路改良が1927年度にも予算執行対象だったことを示す監視団体の記録〕。
- **性格〔注意〕**: 本書は東京市政調査会（民間の市政監視団体）による予算批判資料で、**東京市の予算書そのものではない**。計上額・事業名は市予算原表との照合を要する。

## 制限・未解決

- ①昭和2年度市予算原表での該当費目の確認は未了。②「一部改良」の区間・対象（街路か水路か）は本文に現れず断定しない〔「道路築造費」欄内の記載であるため道路と解せるが、改良対象区間は不明〕。③大正14年街路速成事業との予算上の関係は未確認。
