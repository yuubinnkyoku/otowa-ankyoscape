# [GOV-436] 嘉永撰要類集[25]高札之部上 — 天保4年の江戸川筋御留川高札と弘化3年の建替

- **書誌〔確認〕**: 『嘉永撰要類集』[25]（第五十八ノ下 高札之部上・写本）。NDL次世代デジタルライブラリー [book/2572947](https://lab.ndl.go.jp/dl/book/2572947)。**引用文言はすべてOCR由来で要原文照合**。
- **天保4年（1833）11月28日の江戸川筋の御留川高札〔確認・repo初出の文言群〕**: 弘化3午年（1846）10月28日の小日向水道町月行事・彦兵衛（五人組平八・名主三四郎等）の訴状・取調書付に——「**江戸川筋魚猟御留川相成去る天保四巳年十一月廿八日右川筋之内同町続除地内江新規御高札相建以来異変之節は可訴出段御役所におゐて被仰渡候**」＋建札文言＝「**江戸川筋洗関ゟ船河原橋迄之あいたにて魚を登り又は水をあひ長さ七尺九寸串木三寸角語輩あらは可為曲事もの也**」（文言はOCR崩れ大・「洗関」→「洗堰」（関口の大洗堰）・「水をあひ」→「簗をあひ」等の原字形候補あり）＋「**江戸川筋洗関ゟ船河原橋迄之間殺生いたす間敷御留川ニ付川筋町内持場除地内江戸川橋西際え…新規御高札御建**」＝**①天保4年（1833）11月28日、江戸川筋（神田上水の関口〜小日向区間）が魚猟の御留川（禁漁）とされ、高札が建てられたこと、②禁漁区間が「洗堰（候補）から船河原橋まで」＝大洗堰（関口）から飯田橋側の船河原橋までの神田上水開渠约1.2km区間であることの文言候補、③その高札の1か所が小日向水道町続除地の江戸川橋西際に建てられたこと**＝**神田上水区間の魚猟禁止（上水の水質・水利保護）の高札行政の一次記録（repo初出）**。
- **高札5か所建立の実務文言〔確認・文言候補〕**: 取調書付に「**右御高札之儀は去る天保四巳年十一月中榊原主計頭殿御勤役中江戸川筋洗関(?)ゟ船河原橋迄之間魚猟留川ニ相成候ニ付高札五ケ所え相建候様肥後守殿被仰渡候趣**」（榊原主計頭＝天保4年の北町奉行在職期・肥後守宛の仰渡）＝**御留川指定と同時に高札5か所が建立された**ことの施行文言候補（5か所のうちの1か所が江戸川橋西際・残り4か所の位置は本冊に見えず）。
- **弘化3年（1846）10月の風倒建替の実務〔確認・repo初出〕**: 「右御高札柱(串)折損倒候間取入置右御役所江御届申上候処御月番御番所え御訴へ可申上旨申渡候間依之此段御訴へ奉申上候」（10月27日夜9時頃の風による串の根際からの吹倒を10月28日に訴出）→見分（穂坂甚十郎・永谷兵蔵・10月29日）→「**御高札串共木品檜ニ而御座候…御文言聢(面染等有之候得共)と相分り申候…札串新規出来之積…一札竿壱本但木品檜三寸弐分角長(笠木下土際迄)七尺根入三尺大工手間建方一式銀拾七匁五分右之通瀬戸南町幸七店大工吉兵衛積書差出申候間同人江可被仰付哉…御入用払方之儀は前々之通六百両金之内に而仕払可仕候**」＝**高札の規格（檜3寸2分角・地上7尺・根入3尺）と建替入用（銀17匁5分・大工吉兵衛）・「六百両金之内」の払方に至る建替実務の全過程**＝江戸川橋際の高札の14年耐用の実測（天保4年〜弘化3年）。
- **江戸川橋の位置の裏付け〔観察〕**: 高札の場所が「**小日向水道町続除地内・江戸川橋西際**」と特定される＝**江戸川橋の小日向水道町側（西際）の位置の文言**。[GOV-213](GOV-213.md)の「西之方江戸川橋江壱町程」・[GOV-220](GOV-220.md)第205回追記の江戸向御入用橋リストの「関口水道町一江戸川橋」・[GOV-428](GOV-428.md)の辻番所文言（水道橋外・船河原橋以北＝江戸川通り）と並ぶ江戸川橋の位置定点。また「洗堰（候補）ゟ船河原橋迄」の区間文言は、[GOV-373](GOV-373.md)の「江戸川筋洗堰ゟ船河原橋迄之間」の区間表現（渡船請負証文の寛延3年〔1750〕宛・大潰〔大洗堰候補〕〜西河原橋）の**19世紀（1833・1846）の反復用例**として対校できる（同一区間の通時系列の管理単位の観察候補）。
- **位置づけ〔観察〕**: 神田上水（江戸川）の関口大洗堰〜船河原橋区間の禁漁は、上水の水質・水利保全（江戸川筋の魚猟が上水に与える影響の防止）の施行例と読めるが、**禁漁の目的の文言は本冊に明示されず断定しない**（「魚を登り又は水をあひ」の文言の解釈も原照合待ち）。[GOV-435](GOV-435.md)の関口水車（嘉永6年・神田上水余水利用）と同時代の江戸川筋の水利行政の層として、上水区間の利用（水車・揚場）と規制（禁漁）の並行を観察できる。

## 制限・未解決

- ①「洗関」「水をあひ」「魚を登り」等の建札文言はOCR崩れが激しく、原字形（洗堰／大洗堰・簗・梁等の候補）は原文照合まで特定しない。②御留川指定の行政的な理由（上水保全か・通行か）は本冊に文言なく断定しない。③高札5か所の残り4か所の位置は記載なし。④「六百両金」の性格（高札方の常備金か）は未確認。
