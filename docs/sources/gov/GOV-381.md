# [GOV-381] 記事条例 検使之部 — 白堀・御茶ノ水の検使規定と江戸川・神田川の性格区分〔第163回〕

- **書誌〔確認〕**: 『記事条例』78巻の検使之部3冊——上ノ一（[book/2548908](https://lab.ndl.go.jp/dl/book/2548908)）・下ノ一（[book/2548910](https://lab.ndl.go.jp/dl/book/2548910)）・下（[book/2548911](https://lab.ndl.go.jp/dl/book/2548911)）。死傷・変死の検使（現検）の行政規定の集録（2548910と2548911は並行本文）。**引用文言はすべてOCR由来で要原文照合。**
- **白堀通と御茶ノ水の樋の検使規定〔確認・repo初出〕**: 「**神田上水白堀通水死変死人等有之候節検使之儀に付御普請奉行申上書付**」＋「**神田上水白堀通并御茶之水致樋流死倒者等之節検使一件**」＋「**神田上水白堀通水死其外変死等有之節は水道町之町役**…」＝**白堀通と御茶ノ水の樋（渡樋・潜樋）で水死・変死者が出た場合の検使手続きが御普請奉行（上水管理者）の管轄で、水死は水道町の町役が扱う**という行政規定〔**白堀区間・御茶ノ水樋での水死・変死の管轄規定**＝白堀と御茶ノ水の樋管（[GAZ-043](../gazetteers/GAZ-043.md)系の御茶ノ水埋樋・[GAZ-049](../gazetteers/GAZ-049.md)⑥の樋構造）の実運用（人が落ちる・流される事故の系譜）を裏付ける行政記録。日付は「丑八月」（享和3癸亥の候補・要照合）〕。
- **江戸川と神田川の捨て物・溺死の性格区分〔確認・repo初出〕**: 寛政2戌年（1790）の規定——「**江戸川之儀は武家門前え懸り候分は其組合辻番ニ而取計町方江懸り候分ハ町方二而取扱**」＋「**神田川之方汐入之場所故捨物溺死等有之候而も差構不申**」＋「**例年七月盆棚崩候処江戸川内江取捨不申候様**（盆棚の江戸川への流入禁止）」＋「**右川通りえ塵芥幷盆棚取捨等之儀も以来致間敷**」＝**①江戸川は武家門前と町方で取扱を区分し塵芥・盆棚の投棄を禁止、②神田川（下流）は汐入場所であるため捨て物・溺死があっても差し支えない（構わない）**という2川の性格区分の行政文言〔**神田川の潮区間（汐入）の下流部と、淡水の江戸川上流部との水質・利用の区分が行政規定に現れた記録**。[GOV-373](GOV-373.md)の汐差引極限＝船河原橋辺の観測（寛延3年）と対校すると、船河原橋より下流の神田川が「汐入の場所」として扱われた制度の裏付けになる（潮汐上限より下流側の位置の対応は断定しない）〕。
- **寛政11年（1799）・聖堂西の神田川の「出来候水仕下水」と仮堰〔確認・repo初出〕**: 「**寛政十一未年六月廿九日…聖堂西之方神田川江今度出来候水仕下水先キ川内二溺死人有之候処此節埋ミ下水御普請中にて川中江幅九尺程長五六間斗板土俵ニ而堰出来**」＝**聖堂（湯島聖堂）西側の神田川で、新たに設けられた「水仕下水」（水汲み・水仕用の下水放流口）の先の川内に溺死者があり、当時は「埋み下水」の御普請中で川中に幅9尺・長5〜6間の板土俵の堰が作られていた**＝**駿河台・聖堂西の神田川の下水口普請と仮堰の一次記録**〔[GOV-375](GOV-375.md)の駿河台法面崩壊シリーズ（明和9・安永2の聖堂西之方）と同位置の下水口系の記録。「水仕下水」「埋ミ下水」の原字形は要照合。寛政11年の下水口新設が既存の白堀・下水研究（README §神田川）の駿河台側の展開資料になる〕。
- **寛政7卯年（1795）・大洗堰下の浮死骸〔確認・repo初出〕**: 「**関口水道町月行事半左衛門申上…今昼時同所神田御上水水上ゟ浮死骸流来大洗堰下江戸川内二流留候旨水番人為相知候に付罷越様子見候処日柄相立候死骸…組合名主立合見分…突流申度**」＝**神田上水の水上から浮死骸が流れ来て大洗堰下の江戸川に留まったのを水番人が発見・関口水道町の月行事が届出・組合名主立会で見分・突流（押し流し）とした**（寛政7年5月29日言上帳書抜）＝**大洗堰の下（江戸川）に上水側から流下した死骸が留まる事故の一次記録＋水番人の実務**（「江戸川内に有之浮死骸は突流候様申渡候事」の規定と対）〔[GOV-373](GOV-373.md)の大洗堰・水番人小屋の文言と対校できる水番人の実運用の記録〕。
