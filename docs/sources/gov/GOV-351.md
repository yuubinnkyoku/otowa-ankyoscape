# [GOV-351] 御府内沿革圖書 第一篇上（1940年活字版）— 解題・現存本所在と第20部coverage・駿河臺胸突坂

- **書誌〔確認〕**: 東京市役所編纂『御府内沿革圖書 第一篇上』（東京市史稿・住所篇・1940年〔昭和15年〕3月30日発行・NDL次世代デジタルライブラリー [book/3436302](https://lab.ndl.go.jp/dl/book/3436302)）。江戸の町・地所の沿革を延宝から幕末まで集成した『御府内沿革圖書』（御府内場末往還其外沿革圖書・[GAZ-080](../gazetteers/GAZ-080.md)等の原本シリーズ）の**昭和15年活字版・第一篇上（城内+神田橋御門外周辺が対象）**。**引用文言はOCR fulltextで検証済み（活字版でOCRの信頼性は比較的高いが、卷次・圖番等の細部は要原文照合）**。
- **編纂史の解題〔確認・repo初出の整理〕**: 解題に「**文化四年時ノ老中備前守牧野忠精、普請奉行和泉守小長谷政良加賀守岩瀨氏紀ニ命ジ**」着手→「**八年十二月政費節約ノ故ヲ以テ一旦之ヲ中止**」→「**天保元年十二月老中出羽守水野忠成命ジテ之ヲ再開セシム、安政五年全部二通ヲ完成シ、萬延元年八月二十一日內一通ヲ紅葉山文庫ニ納ル**」→「**文久中再ビ之ガ調繼有リ、是時調査ヲ本所深川ニモ及ボスト云フ**」＝**文化4年（1807）老中牧野忠精・普請奉行小長谷政良・岩瀬氏紀への命による着手、文化8年（1811）12月政費節約による中止、天保元年（1830）12月水野忠成による再開、安政5年（1858）二通完成、萬延元年（1860）紅葉山文庫納入、文久中の調継（本所深川への拡大）**の編纂史。〔[GAZ-012](../gazetteers/GAZ-012.md)のシリーズ同定記録に、編纂の開始・中止・再開・完成の各年代を補強する解題情報。〕
- **現存本の所在明細〔確認・repo初出の所在情報〕**: 「**二本ハ、今現ニ東京府ニ存シ、一ハ之ヲ府文庫ニ藏シ、一ハ寄托シテ帝國圖書館ニ在リ、前者ハ四十三册附圖四十二葉、第十三圖一葉ヲ缺ク、後者ハ卅二册附圖卅四葉**（府内6冊・場末4冊欠の注記）＋内閣文庫の部分本＋「**東京市役所市史編纂室亦一部四十四册附圖四十一葉ヲ有ス**」＝**昭和15年時点の現存3系統の所在・冊数・附図葉数の明細**。〔**[GAZ-012](../gazetteers/GAZ-012.md)/[GAZ-054](../gazetteers/GAZ-054.md)・[GOV-343](GOV-343.md)（延享期両村絵図面）等の原本の所在探索の基礎情報**。東京府文庫本43冊（附図42葉）はNDL次世代DLの原本系（2587242等）に対応する系統候補だが、対応関係の確定はしない。〕
- **22部coverage目録〔確認・文言候補〕**: 解題の部立目録に「**貳拾之部 小石川巢鴨音羽町關口村邊**」「拾九之部 四谷内藤宿高田大久保邊」「貳拾壹之部 下谷坂本村淺草龍泉寺村邊」「貳拾貳之部 下谷根津谷中新堀村田端村邊」等の22部の対象地名が現れる。〔**第20部（貮拾）が小石川・巣鴨・音羽町・関口村の周辺であることの活字版側の明記＝[GAZ-054](../gazetteers/GAZ-054.md)（貮拾利・嘉永7年調）・[GAZ-080](../gazetteers/GAZ-080.md)（拾九利・嘉永5年調）の部立ての理解を補強**。第19部が「四谷内藤宿高田大久保邊」とある点は、NDL原本の拾九利の表紙文言（牛込御門外側・早稲田村〜関口村一円）と部番号の対応に注意を要する（原本の部番号の付番は活字版編成と必ずしも一致せず、対応の確定は原画像照合待ち・断定しない）。〕
- **駿河臺小川町胸突坂邊の屋敷沿革と元禄6年の新道文言〔確認・文言候補〕**: 本冊所収の「**文化五辰年駿河臺小川町之內胸突坂邊屋敷々猿樂町東側邊屋敷々小川町裏猿樂町邊**」の条に、胸突坂上の水野九左衞門等の屋敷の延宝以前〜文久元酉年書継の沿革が集約され、その中に「**元祿六酉年六月前書棺坂上山口藤右衞門…崕地境之所被召上、袋町行留道〓續槌坂之方ニ新道出來**」＝**元禄6年（1693）6月、袋町行留道の続きの「槌坂」（「棺坂」は同文内のOCR変種候補・胸突坂方面の坂と読める）の方への新道の開通と、山口藤右衞門の崖地境の召上げ**の文言がある。〔**駿河台の胸突坂方面の元禄6年の新道記録＝[GAZ-081](../gazetteers/GAZ-081.md)（駿河台志・袋町の胸突坂）の江戸期側の対校資料**。坂名の表記揺れ（胸突坂・棺坂・槌坂）の同定はOCRでは確定できず、原画像照合を要する。関口側の胸突坂（[GAZ-076](../gazetteers/GAZ-076.md)・元禄10年新道）と同年代帯だが別地点（同名異坂）である点はGAZ-081と同じ注意。〕

## 制限・未解決

- ①活字版だが卷次・圖番・人名の細部は要原文照合。特に「棺坂」「槌坂」の坂名のOCR変種の判定は原画像ではできない（本冊が活字版であるため、OCR崩れではなく活字版自身の翻刻由来の可能性もあり、どの字形かの確認は原本PDFの閲覧待ち）。②現存本の所在明細は昭和15年時点のもので、その後の移動（帝國圖書館→国会図書館等）は本冊では確認できない。③第19部の原本（拾九利）と活字版の部立ての対応は確定していない（上記）。④現存本の冊数欠（第13圖一葉欠・府内6冊・場末4冊欠）と、NDL次世代DLで公開されている原本冊の対応関係の検証は未実施。

- **第155回追記〔確認・活字版続篇の所在〕**: 『御府内沿革圖書』活字版の後続篇がNDL次世代DLで公開されている——**第一篇下=3436304（番町文久調）・第二篇上=[3436306](https://lab.ndl.go.jp/dl/book/3436306)（吳服橋鍛冶橋御門外）・第二篇下=3436308（八丁堀）・第三篇下=3436311（小石川小日向之部=[GOV-359](GOV-359.md)として今回登録）**。第二篇上の凡例に彩色規定「**青=御堀・川、草色=土手**」〔観察：附図の彩色の凡例＝附図の読み取り（水路・土手の判別）のための規定情報〕。
