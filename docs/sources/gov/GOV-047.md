# [GOV-047] 豊島景観百選の谷端川緑道と水源説明

- **資料・年代〔確認〕**：豊島区「[豊島景観百選アンケート結果の発表](https://www.city.toshima.lg.jp/296/machizukuri/toshikekaku/kekan/1902251556.html)」と「[拡大図B](https://www.city.toshima.lg.jp/296/machizukuri/toshikekaku/kekan/1902271613.html)」。募集期間は**2018年7月1日～12月28日**、回答数は**103件**。両ページの表示更新日は**2025年7月10日**。2018年は景観募集の期間であり、写真の撮影年や暗渠化・緑道整備の年ではない。
- **掲載位置〔確認：区公式ページの文字情報〕**：拡大図Bの**番号21「谷端川緑道」**は所在地を**豊島区西池袋5丁目24付近**と明記し、緑道の写真と「緑が多く住宅街と調和している」という応募者コメントを掲載する。これは**応募景観の所在地**であって、谷端川全体の水源位置・旧河床の実測点ではない。地図画像と写真の細部は独立に判読していない。
- **水源・分水の表現〔確認：行政の説明文／観察：既存資料との表現差〕**：同じ項目は谷端川を「**千川分水の一つ**」と呼び、**粟島神社（要町2-14）の弁天池を源泉**と説明する。既収録の自然湧水と千川上水からの助水という二つの系統を、景観紹介用に簡略化した記述とみられるが、**谷端川全区間が人工の分水路だったと確定するものではない**。
- **照合上の注意〔未解決〕**：既登録の練馬区資料を紹介するREADMEには、粟島神社の位置が**「要町2-41」**と記されている。豊島区の本資料は**「要町2-14」**、[豊島区商店街連合会の案内](https://www.toshima-kushoren.gr.jp/course/course09.html)は**「要町2-14-4」**とする。表記の食い違いをそのまま残し、**地番・住所の取り違えか、参照先の違いか、旧地番との混同かは未検証**。どちらかを近世の湧水点・分水口の座標として扱わない。
