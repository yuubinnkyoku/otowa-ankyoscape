## 新規4件〔確認〕

- **①白堀通り各村分水口の涸水時「三分通差塞」定例の伺（明治16年〔1883〕12月28日起案）**: 「明治１６年１２月２８日 玉川上水水源涸水の為東京掛水量追々減じ水配上差支に付、**白堀通り各村分水口定例に倣い三分通差塞ぐ様各水番人へ達方取計申し度**、御苑海軍省兵器局印刷局等に関係有りに付通知及び水番人へ達の義併せて伺」（pkey [715330](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=715330)・綴込*082・往復録・第１類・水道・乙 〈土木課〉従６月至１２月・請求番号６１３．Ａ６．０８・[MF]府明Ⅱ明１６－０２６,[D]D287・16mmMFコマ０００６－０３１９・収録先簿冊資料ID 000123211）〔確認: 詳細頁表項目〕。
  - **玉川上水の水源涸水で東京への掛水量が漸減し水配に差支が出たため、「白堀通り各村分水口」を定例に倣って「三分通」に差し塞ぐ（差塞ぐ）よう各水番人へ達することを伺った**1883年の記録。①**「白堀通り各村分水口」に涸水時に通水を3分の1に絞る（「三分通」の解釈は本文未見のため流量3分の1説を含め断定しない）「定例」が存在したこと、②その運用を**各水番人**が担ったこと、③御苑（小石川の植物御苑）・海軍省兵器局・印刷局等の官衙が水配に関係したこと〔確認: 目録文言〕。
  - repo grep（三分通・涸水・白堀通り各村分水口）で既収録なし＝新規。**千川水道（白堀通り筋＝沈沙池から洗堰を経て千川へ通じる区間）の各村分水口の渇水時運用の一次文言候補**で、[GOV-588](GOV-588.md)・[GOV-615](GOV-615.md)（千川上水道書類並図面・601.A8.14系）の千川分水実務群と [GOV-623](GOV-623.md) の白堀筋丈量の村々通達（角筈村・高田村・上下落合村・中野村等）に**渇水時の水量制限運用の側を追加する**記録〔観察: 「白堀通り各村分水口」と千川側各村分水口の同一性は本文未見のため断定しない。玉川上水→江戸川（神田上水頭部）→白堀→千川の水系連鎖上の文言であることは目録文言から確認できる〕。
- **②白堀通り藻刈・堤草刈の10町地主負担の終了達（明治4年〔1871〕8月17日）**: 「明治４年８月１７日 **小日向水道町、小日向東古川町、小日向西古川町、小日向松ヶ枝町、関口水道町、小石川水道町、小石川表町、小石川仲町、小石川金富町、小日向台町の各町々地主共へ**従来神田上水関口洗堰より**小石川元水戸券邸堺迄白堀通り藻刈人足并堤草刈不浄物取捨水番人給等出金罷在の処自今其儀に及ばぬ**」（pkey [598155](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=598155)・綴込*006・庁中達 〈知事官房〉・請求番号６０５．Ｃ４．１０・[MF]府明Ⅱ明０４－０１４,[D]D195・16mmMFコマ０００６－００８２・収録先簿冊資料ID 000122240）〔確認: 詳細頁表項目。なお「券邸」は目録の表記のまま（元水戸邸の誤植候補・要原文照合）〕。
  - **神田上水廃止後の白堀（関口洗堰から小石川元水戸邸堺まで）の藻刈人足・堤草刈・不浄物取捨・水番人給などの出金を、小日向・関口・小石川の10か町の地主が従来負担してきたが、自今その必要がないとする庁中達**＝**白堀維持の地主負担（人足・草刈・不浄物・水番人給の4系統の出金）の具体的な負担者リストと、その終了（明治4年8月）の両方を1件で記録する達**〔確認: 目録文言〕。
  - repo grep（庁中達・小日向台町・この10町の組合）で既収録なし＝新規。[GOV-237](GOV-237.md)（明治2年・白堀藻刈3日間・入用金67両2分を水下町々の渡賃銭で支払）の**負担構造の明治4年の終焉側**を、[GOV-234](GOV-234.md)（三水道町の古来持場）・[GOV-384](GOV-384.md)（藻苅3ヶ所＝金杉・小日向・関口）から続く白堀維持労務の通時系列の終端側に接続する記録〔観察: 終了の理由（府費化・大下水化の進展か）は本文未見のため断定しない〕。

## 位置づけ〔観察〕

- 1871（白堀維持の10町地主負担の終了）→1875（関口水車の江戸川上掛樋大破と仮樋）→1877（水番人への上水車分水届）→1883（涸水時の白堀通り各村分水口の三分通差塞）＝**神田上水廃止（大下水化）後の江戸川・白堀・関口筋が、地主負担の終了・水車営業・渇水時運用のいずれの側でも明治10年代まで行政実務の対象であり続けた**ことの目録レベルの通時。千川上水（白堀通り筋から分水）の頭部側の上流文脈をなす記録群で、[GOV-615](GOV-615.md)・[GOV-623](GOV-623.md)・[GOV-638](GOV-638.md) と接続する。
