# [GOV-625] 水道歴史館「収蔵資料」頁＝神田上水石樋の公式解説

## 書誌・確認範囲

- 東京都水道歴史館公式サイトの収蔵資料頁（[https://www.suidorekishi.jp/collection/](https://www.suidorekishi.jp/collection/)・2026-11-27第368回にcurlで直接取得し本文全文確認）。石樋・木樋・共用栓等の収蔵資料解説ページ。

## 本文の確認内容〔確認: 公式頁本文〕

- **〔確認・repo初出〕神田上水の石樋の公式解説文言**: 「**昭和60年（1985）、水道橋から外堀通りをお茶の水へ上る道路の下から、石組みの水路が発見されました。その後の発掘調査によって、これは神田上水の石組みの地下水路、すなわち石樋であることがわかったのです。石樋は安山岩で構築され、幅は下部内法12㎝・上部内法150㎝、深さは120㎝～150㎝もあります。江戸上水では木樋が多く使われますが、水量の多い上流部分ではこのような石樋が使われていました**」＝**①発見年次＝昭和60年（1985）説、②材質＝安山岩、③断面寸法（下部内法12㎝の表記は[BLOG-356](../blogs/BLOG-356.md)碑文の下幅120cmと食い違う・公式頁の誤植の可能性があるが文言のまま記録）、④『上水記』の樋線図には「万年石樋」と記され、神田上水が掛樋で神田川を渡る直前の水路だったこと、⑤石樋は発掘調査ののち東京都水道歴史館裏手の本郷給水所公苑内に移築復元された（元々全体に蓋があり地下水路）**。
- **〔観察・年次対立〕石樋発見・発掘の年次対立の記録**: 本頁（水道歴史館公式）の「昭和60年（1985）発見」に対し、[BLOG-356](../blogs/BLOG-356.md)の移設復原碑文（東京都水道局）は「**昭和62年から平成元年にかけて発掘**」・「**昭和六二年、文京区本郷一丁目先の外堀通りで、神田川分水路の工事中発掘**」と記す＝**1985年（発見）と1987-89年（発掘調査）の別時点と読むこともできるが、文言上は対立として記録し断定しない**。
- **〔確認〕他の収蔵資料解説**: 千代田区丸の内三丁目遺跡出土の木樋（都教委所蔵・伏越し）・寛政3年（1791）幕府普請奉行上水方石野広通による公式記録『上水記』（天明8年起稿・3年がかりで3部作成・稼働していた神田上水・玉川上水の記録）等。『上水記』の書誌情報（石野広通・寛政3年・3部）は既存の[対照表 巻石白堀行]系記録の公式側裏付け。

## 制限・注意

- 収蔵資料頁は展示解説の転載であり、発掘調査報告書（文京区No.49遺跡）の書誌・本文は本頁からは確認できない。報告書の所在確認は今後課題（nabunken sitereportsは本回429）。
- 「下部内法12㎝」の寸法表記は碑文（下幅120cm）と桁が違い、公式頁の誤植の可能性があるが、原文表記のまま記録する。
