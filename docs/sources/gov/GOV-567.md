- **位置づけ〔観察〕**: [GOV-098](GOV-098.md)（練馬区史 歴史編）が宝永4年（1707）の灌漑許可の経緯を引用した「**千川文書写**（东京都公文書館蔵）」の参照先として、この東京市写本「千川文書」上・中・下3冊が有力候補になる〔**文言の直接照合は未実施・同一性は断定しない**。GOV-098の制限④「千川文書写の請求番号」の解消方向の記録〕。シリーズ名が「地誌／水道河川橋梁」で、千川家文書（[GOV-089](GOV-089.md)＝neribun297点・[GOV-004](GOV-004.md)）や練馬区史のいう西福寺所蔵三書（千川上水起立之義・千川上水古記録上申・千川上水路履暦）との異同は未照合。下巻の「取扱注意の絵図」が千川上水の絵図類（[MAP-119](../maps/MAP-119.md)・[MAP-120](../maps/MAP-120.md)等の系統か）に連なるかは本文未見のため推測にとどめる。
- **制限・未解決**: ①本文（マイクロフィルム江－地誌類067・068）は未見。②「上・中・下」の収録内容の分割・年代範囲は目録からは不明。③写本の作成主体（東京市）・作成年次は目録に記載なし。④GOV-098引用文言との照合、neribun297点（GOV-089）・西福寺所蔵三書との異同は次の課題。
