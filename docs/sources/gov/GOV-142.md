# [GOV-142] 小平市史別冊写真集「野火止用水と新堀用水の分水口」（1957年・飯山達雄撮影）〔repo初出〕

- **書誌〔確認: ADEAC小平目録頁・2026-11-14〕**: こだいらデジタルアーカイブ（小平市立図書館）「**小平市史別冊写真集**」資料グループ所収、「**野火止用水と新堀用水の分水口**」（目録ID [mp004010-100040](https://adeac.jp/kodaira-lib/catalog/mp004010-100040)）。**飯山達雄氏撮影・昭和32年（1957）**・所蔵機関**小平市立喜平図書館**・資料番号010・CC BY（表示）・IIIFマニフェスト欄あり。**小平市史別冊写真集グループのrepo初出**。
- **解題〔確認: 目録の解題欄〕**: 「玉川上水が左下から右上に流れている。**明治3 (1870) 年に小平市域北側の分水口は新堀用水に一本化され、ここに取水口が設けられた。手前の分水口が野火止用水。次が新堀用水。**」〔**1957年時点の野火止用水・新堀用水の両取水口が並ぶ地点の行政撮影写真**で、市史編纂時点の解題が明治3年の北側分水口一本化を明記する〕
- **意義〔観察〕**: [BLOG-224](../blogs/BLOG-224.md)（kasen.info・小平市教育委員会看板）・[BLOG-225](../blogs/BLOG-225.md)（守る会）の説明する新堀用水の取水状況（野火止用水堰に接して設けられた取水口）について、**1957年（昭和32年）時点の写真が残る**ことを固定した。写真の判読（両水口の位置関係・写真の向き・ kasen.info観察の「小平監視所敷地＝旧取水口」説との照合）は未実施〔IIIF画像は未判読〕。同じ「小平市史別冊写真集」グループ内の他写真（玉川上水・分水関連）の走査は次回候補。
