# [GOV-317] 警視類聚規則 坤（1879）— 甲57号布達の改正注記つき再録と心得・境村許可の再録

- **書誌〔確認〕**: 『**警視類聚規則**』**坤**（**1879**〔明治12年〕・警視本署。NDL次世代デジタルライブラリー [book/791012](https://lab.ndl.go.jp/dl/book/791012)）。警視本署の規則・達の類聚。**引用文言はOCR由来で原画像照合を要する**。

## ①甲第57号布達の再録（改正注記つき）〔確認文言〕

- 「**布達 十一年十月廿九日 甲第五十七號 神田玉川兩上水(源)取締禁例 左之通相定來ル十二月一日ヨリ施行候條此旨布達候事 第一條 魚鳥ヲ捕リ及ヒ游泳シ又ハ諸物品ヲ洗フヘ(カラス) 第二條 塵芥瓦礫其他汚穢物ヲ投棄スヘカラス 第三條 上水ニ沿フタル各地面ヨリ汚水混入セシム（第六號ヲ以テ改正 十二年二月廿六日甲） 第四條 堤上ノ竹木及ヒ下草等伐採スヘカラス（上同）**」
- **意味〔確認〕**: ①規則名が「神田玉川兩上水**源**取締禁例」（仮規則の「源」を保持する表記）で再録。②**第3条・第4条に「（第六號ヲ以テ改正 十二年二月廿六日甲）」「（上同）」の注記**＝[GOV-312](GOV-312.md)（甲第6号「第三條第四條左之通改正」）の**条文対応が第3・4条であることの類聚レベルの明示**。③再録の条文本文は仮規則原文と同じ文言で読めるため、**明治12年2月26日改正で第3・4条の実質文言がどう変わったか（語尾の整備かそれ以上の変更か）はこれらの再録群からは確定しない**（原布達の「左之通改正」本文〔GOV-312〕の割付照合が次の一手）。

## ②神田玉川兩上水路取締心得（明治12年2月26日番外）の再録〔確認文言〕

- 「**達 十二年二月廿六日(番外) 神田玉川(兩)上水路取締心得 左（ノ通相定候條此旨相達候事） 第三方面第四分署(之) 第一條 兩上水路敷地神奈川縣下ニ係ル塲所ニ於テ該取締禁例違犯者アルキハ該縣最寄警(察署ヘ送付スヘシ)**」
- **意味〔確認〕**: [GOV-315](GOV-315.md)③（警視庁令類纂第5版）で全文を取得した「**兩上水路取締心得**」の**1879年（達と同年）の類聚への収録**＝心得が明治12年2月26日（甲第6号の改名・改正と同日）の番外達として出されたことの同時代側の裏付け。

## ③境村外5か村新田の玉川上水際汲取場許可の再録〔確認文言・GOV-314の文言裏付け〕

- 「**（達）番外（第三方面第四分署之）…十一年十二月廿六日 別紙之通東京府ヨリ通知有…（別紙）東京府ヨリ通知…神奈川縣下武藏國多摩郡境村外關野新田梶野新田鈴木新田是政新田小川新田ノ六ケ村 昨十一月中爲飮用玉川上水際ニ於テ水汲取塲取設ケ之趣出願取調候處事情無餘儀次第ニ相聞ヘ候ニ付當分之內該水地敷地ニ傚ヒ小土手築立不潔無之樣…可致旨ヲ以テ聞屆候間 右ハ自然水路御取締ニモ相關候故其方面ヘ御達置相成度**」＋「**（達）…十二月廿一日（東京府ヨリ通知…）**」
- **意味〔確認・対校〕**: [GOV-314](GOV-314.md)②（番外第173号・境村外5か村の飲用水汲取場許可・12月26日達・府通知12月21日付）の**内容・日付ともに類聚側でも裏付けられた**。「鈴水新田」（GOV-314の表記候補）は本書のOCRでは「鈴木新田」と読める（判読対立として原画像照合まで併記）。

## 制限・未解決

- ①甲第6号改正後の第3・4条の確定文言（再録群はいずれも仮規則と同じ文言で、変更点が割付上見えない）。②「神田玉川兩上水源取締禁例」の「源」を含む規則名の表記揺れ（仮規則名由来）と、いつ「源」が落ちたか。③境村6か村の新田名の表記対立（鈴水／鈴木）。
