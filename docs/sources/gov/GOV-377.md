# [GOV-377] 東京水道改設之概略（1877）— 神田上水の多水源説と上水用語の行政定義〔第163回〕

- **書誌〔確認〕**: 東京府編『東京水道改設之概略』（明治10年・1877）。NDL次世代デジタルライブラリー [book/845990](https://lab.ndl.go.jp/dl/book/845990)。東京府の下水道改良（水道改設）の行政解説書。**引用文言はすべてOCR由来で要原文照合。**
- **神田上水の起源の並記〔確認・repo初出の文言候補〕**: 「**初メ寛永年間神田上水ノエヲ起シ承應ノ初年又玉川上水ヲ通ス**」＝**神田上水を寛永年間に起こし、承応の初年に玉川上水を通した**という寛永＋承応の並記説〔神田上水の開削年代論（慶長期神田川由来説・[GAZ-049](../gazetteers/GAZ-049.md)⑬の承応2年堀割説・[BOOK-147](../books/BOOK-147.md)の寛文元年改修説）に、1877年の府側の見解（寛永＝神田上水・承応＝玉川上水通水という役割分担の説明）を加える候補。OCRの「ノエヲ」の部分は原画像照合を要する〕。
- **神田上水の多水源合流説〔確認・repo初出の文言候補・核心〕**: 「**井ノ頭池下井草村善福寺池及ヒ上井草村妙正寺池ノ水ト玉川ノ派流ト相合シテ…大洗堰ニ至ル**」＝**井の頭池・善福寺池（下井草村）・妙正寺池（上井草村）の水と玉川の派流が相合して大洗堰に至る**＝神田上水の水源を**多水源の合流**として記す1877年の行政記録〔**神田上水＝井の頭単独源とみる系譜（[GAZ-069](../gazetteers/GAZ-069.md)「井頭ノ上水」）に対し、善福寺池・妙正寺池（妙正寺川・善福寺川水系）と玉川の派流（千川系か）を含む合流構造説**。repoの千川上水・神田上水の関係論（README §千川上水）の明治期の一次文言候補。「玉川ノ派流」の比定（千川上水か玉川上水の分水か）は本書からは断定しない。要原文照合〕。
- **大洗堰から左右に岐る構造と開削者名〔確認・文言候補〕**: 「大洗堰ヨリ左右岐リ」（左岐＝上水）の構造文言＋**寛永年中に「内田六次郎(?OCR要照合)」が開削した**という文言候補〔[GAZ-048](../gazetteers/GAZ-048.md)⑦の大洗堰＝神田上水と江戸川の分水口の構造と対校。開削者名のOCRは崩れが大きく原画像照合が前提〕。
- **明暦の火炎で記録を失う説明〔確認〕**: 「**明暦年間ノ火炎ニ罹リ其ノ詳ヲ得ス**」＝明暦の大火で詳記を失ったという記録喪失の説明〔神田上水の初期記録の欠損の行政側説明。[GAZ-049](../gazetteers/GAZ-049.md)⑬の年代説の対立の背景説明として利用〕。
- **上水用語の1877年の行政定義〔確認・repo初出の定義群〕**: 「**白堀**（素掘りの溝）・**桝**（埋桝・高桝・水見桝）・**潜樋**・**渡樋**・**懸樋**・**萬年樋（石製）**」の用語定義＝**上水施設の語彙の1877年の行政水準での定義集**〔[BOOK-147](../books/BOOK-147.md)（三田村鳶魚）の白堀・素樋の定義文言・[GAZ-035](../gazetteers/GAZ-035.md)/[GAZ-082](../gazetteers/GAZ-082.md)の万年樋・桝の用例・[GOV-382](GOV-382.md)の桝文言と対校できる、用語研究の府側の基準〕。
- **神田上水の延長〔確認〕**: 「**延長5里26町15間**」＝神田上水の全長の1877年時点の数値〔大洗堰〜江戸市内末端の距離の行政記録候補〕。
