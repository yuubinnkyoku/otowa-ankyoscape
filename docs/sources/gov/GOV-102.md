# [GOV-102] 『官報』第2782号・谷端川・神田上水改修受益者負担省令（1936年4月14日）

- **書誌〔確認: NDLサーチの同号目次〕**: 『官報』**1936（昭和11）年4月14日・第2782号**。同号目次の「省令」欄に「**内務省 / 第11号 / 東京都市計畫事業江戸川改修受益者負擔ニ關スル件 p413**」に続き「**内務省 / 第12号 / 東京都市計畫事業立會川、神田上水及谷端川改修受益者負擔ニ關スル件 p413**」を確認〔**repo初出**〕。
- **所在〔確認〕**: [NDLデジタルコレクション PID 2959262](https://dl.ndl.go.jp/pid/2959262)（DOI: 10.11501/2959262）。IIIFマニフェスト（`https://dl.ndl.go.jp/api/iiif/2959262/manifest.json`）の取得可否は本回未確認（GOV-101と同様の手法が次の一手）。
- **意義〔観察〕**: ①**谷端川改修が東京都市計画事業として内務省令で受益者負担（費用徴収）の枠組みが定められた**ことを示す法的記録で、1936年時点で改修事業がまだ執行（または費用徴収）段階にあったことを示唆する〔千川下流竣工1934（GOV-094）以降・全流域改修の継続を示す候補。本文未読のため断定しない〕。②同じ省令が**神田上水（谷端川下流の小石川・西大下水系）と立會川（石神井川下流）を一括**で扱っており、四河川の下流水系が都市計画事業の単位で一括整理されていたことの初出の傍証。③「受益者負担」は河川改修費用を沿線土地所有者に賦課する制度で、谷端川沿いの耕地整理（BLOG-122）や区画整理との関係も照合課題。
- **制限・未解決**: ①省令本文（負担金率・対象区域・徴収方法）は未読。②「立會川」は石神井川下流部の別名（板橋区志村方面）と解せるが、本資料単独では確定しない。③受益者負担の対象事業が1931年収用公告（GOV-101）の事業と同一かは未確認。
