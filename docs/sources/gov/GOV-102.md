# [GOV-102] 『官報』第2782号・谷端川・神田上水改修受益者負担省令（1936年4月14日）

- **書誌〔確認: NDLサーチの同号目次〕**: 『官報』**1936（昭和11）年4月14日・第2782号**。同号目次の「省令」欄に「**内務省 / 第11号 / 東京都市計畫事業江戸川改修受益者負擔ニ關スル件 p413**」に続き「**内務省 / 第12号 / 東京都市計畫事業立會川、神田上水及谷端川改修受益者負擔ニ關スル件 p413**」を確認〔**repo初出**〕。
- **所在〔確認〕**: [NDLデジタルコレクション PID 2959262](https://dl.ndl.go.jp/pid/2959262)（DOI: 10.11501/2959262）。IIIFマニフェスト（`https://dl.ndl.go.jp/api/iiif/2959262/manifest.json`）の取得可否は本回未確認（GOV-101と同様の手法が次の一手）。
- **意義〔観察〕**: ①**谷端川改修が東京都市計画事業として内務省令で受益者負担（費用徴収）の枠組みが定められた**ことを示す法的記録で、1936年時点で改修事業がまだ執行（または費用徴収）段階にあったことを示唆する〔千川下流竣工1934（GOV-094）以降・全流域改修の継続を示す候補〕。②同じ省令が**神田上水（谷端川下流の小石川・西大下水系）と立會川（石神井川下流）を一括**で扱っており、四河川の下流水系が都市計画事業の単位で一括整理されていたことの初出の傍証。③「受益者負担」は河川改修費用を沿線土地所有者に賦課する制度で、谷端川沿いの耕地整理（BLOG-122）や区画整理との関係も照合課題。
- **本文全文の確認〔確認・2026-11-16第128回追記・[GOV-296](GOV-296.md)〕**: 東京市『東京市例規類集』（1940・追錄第28號等）に「昭和一一年四月一四日內務省令第十二號」として**本省令の本文全文が収録されている**ことを確認（[GOV-296](GOV-296.md)に詳細）。要点＝**執行者＝東京府知事（府執行）**・受益者＝負担区劃内の土地の権利者群（所有者・質権者・地上権者・賃借人・使用借主・転借人・占用権者、一時的のものを除く）・**負担区劃は各河川毎に別個の図面で表示し、東京府庁・東京市役所に備置き縦覧に供す**・**負担総額＝事業費の4分の1**（坪当たり負担指数×坪数で按分・寄附算入・特殊工事費控除の規定つき）・**均等20分・年2回徴収**（予算額ベース算出・精算時に還付・追徴）・減免規定（重複負担・寄附・公用公共用地・境内地・私立学校用地・風致地区等）・告示事項＝負担区・指数・負担金額・期日・事業費予算額・精算額等。**同一日付の省令第11号（江戶川改修受益者負担）との対比＝江戸川は市執行・事業費14分の1・均等10分年1回**＝立会川・神田上水・谷端川と江戸川で負担率・徴収方法が明確に異なる（詳細は[GOV-296](GOV-296.md)）。
- **制限・未解決**: ①官報本文（p.413）と例規類集本文の対校は未了（官報のOCR判読は実行環境の制約で未実施）。②「立會川」は石神井川下流部の別名（板橋区志村方面）と解せるが、本資料単独では確定しない。③受益者負担の対象事業が1931年収用公告（GOV-101）の事業と同一かは未確認。④省令第12号の施行細則（府側告示）・負担区劃図の現物は所在未確認。
