# [GOV-294] 東京市豊島区勢要覧 昭和十一年版（1936）— 千川堤桜の1936年時点の来客記録

- **書誌〔確認〕**: 東京市豊島区（区役所）『東京市豊島区勢要覧』**昭和十一年版（第三回）**（1936）。巻頭の凡例に「昭和八年十月第一回、昨年三月第二回を發刊し爰に其の第三回を上梓」とあり、[GOV-199](GOV-199.md)（昭和10年版・第二回・[lab id 1281540](https://lab.ndl.go.jp/dl/book/1281540)）の翌年版にあたる。NDL次世代デジタルライブラリー [book/1281547](https://lab.ndl.go.jp/dl/book/1281547)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **千川堤桜の花見客記録〔確認・repo初出〕**: 長崎町（現・豊島区長崎）条に「又**千川堤の櫻花は最近大分都人士を招いて居る**」＝**1936年時点で千川堤の桜が「都人士」（都心側の見物客）を相当数集めていた**という区勢要覧レベルの記録＝千川堤桜が花見の名所として機能していたことの同時点の公的観察記録。
- **三川並記〔確認〕**: 「**西北部に谷端川、…西部に千川の細流あり**」＝谷端川・千川の並記は[GOV-199](GOV-199.md)（昭和10年版）「西南ニ鶴卷川、西北部ニ谷端川、西部ニ千川ノ細流アリ」と同型の翌年観察（本冊のOCRでは鶴巻川の該当部分が列崩れで切れている）。交通機関の欄に「武藏野鐵道が池袋驛より發して椎名町、東長崎の二驛を置き」等も。
- **内容メモ**: 千川堤桜の記述は長崎町条の町勢紹介の中にあり、植樹主体・品種（[BLOG-101](../blogs/BLOG-101.md)大正4年4村合同植樹説・[BOOK-122](../books/BOOK-122.md)「大正の初年」軍人會・靑年會説・[BOOK-125](../books/BOOK-125.md)1932年「大正年間」説）には触れず、**1936年時点の桜の実勢（来客）のみを記す**点が、植樹時期の3説対立とは独立した年代断面として使える。
