# [GOV-382] 東京市史稿 市街篇29・37 — 大洗堰の天明3・4年と天保2年の修復層〔第163回〕

- **書誌〔確認〕**: 『東京市史稿 市街篇』第二十九（東京市・1938・NDL [book/3450815](https://lab.ndl.go.jp/dl/book/3450815)）・第三十七（東京市・1941・NDL [book/3450831](https://lab.ndl.go.jp/dl/book/3450831)）。年次順の事蹟・附記体の活字版だが**OCRの列混線が激しく、引用文言はすべて原画像照合を要する**（本回は大洗堰関係の文言に限定して抽出）。
- **天明3年（1783）7月・大洗堰石垣の崩壊と神田上水断〔確認・repo初出・核心〕**: 市街篇29（天明3年ノ条）に「**（天明）三年より大雨降續、十七日…大雨、（小）日向大洗堰石垣崩れ、神田上水切る**」〔水災変災篇参照の注記つき〕＝**天明3年7月17日の大雨で小日向の大洗堰の石垣が崩れ、神田上水が断たれた**という記録〔**大洗堰の被害イベントのシリーズに天明3年7月を追加**＝[GOV-375](GOV-375.md)の天明6年7月石垣急破（出水前月）・[BOOK-130](../books/BOOK-130.md)/[BOOK-157](../books/BOOK-157.md)の天明6年7月出水と対で、**天明期に天明3年と天明6年の2度の大洗堰石垣の破損があった**という新たな層。OCRの「日向」は「小日向」の欠落候補・要照合〕。
- **天明4年（1784）7月・大洗堰石垣の修復と往来再開〔確認・repo初出〕**: 市街篇29（天明4年7月11日条）に「**神田上水大洗堰石垣御修復出来…（褒美の）申渡之…同所水番屋前通り（十二日）往來有之旨**」〔柳営日次記引用〕＝**天明4年7月11日に大洗堰石垣の修復が完成し、水番屋前の通りが12日に往来再開した**記録〔**天明3年7月崩壊→天明4年7月修復という約1年の復旧**の年代層。水番屋前通りの往来規制（修復中の閉鎖）と再開の文言は大洗堰脇の交通（[GOV-372](GOV-372.md)系の水番屋文言・[GOV-373](GOV-373.md)の馬駕籠相通と対校）〕。
- **天保2卯年（1831）7月・関口大洗堰普請と「銚子口」〔確認・repo初出の用語〕**: 市街篇37（天保2年7月28日の屋敷書抜の附記）に「**關口大洗堰普請…神田上水關口大洗堰疊石〓銚子口其外共御普請御用相勤いこ付被下之**（御普請方下奉行銀拾枚・菅沼給左衞門金七兩・近藤鎌吉…御普請方金五兩・庵原亮平）」＝**天保2年7月の関口大洗堰の普請（畳石の「銚子口」其外共）の御用を勤めた者への褒美**〔**「銚子口」という大洗堰の構造部品名の文言候補（repo初出・畳石〔疊石〕の銚子口＝堰の水口の構造か・原画像照合前提）**＝大洗堰修復年表（卯年〔[GOV-379](GOV-379.md)〕・安政3〜4年〔[GOV-380](GOV-380.md)〕）に天保2年7月を加える。褒美の金銭（銀10枚・金7両・金5両）の文言もOCR列混線があり要照合〕。
- **天保2年・小石川水道橋外の代地〔確認・文言候補〕**: 同附記に「**牧野遠江守上ヶ屋敷 小石川水道橋外七千八百三拾九坪餘 但、大名小路屋敷就御用差上爲代地**」＝**水道橋外の7,839坪余の武家屋敷が他の御用のため上地され代地が下された**記録〔水道橋外周の土地再編の天保2年の datapoint（[BOOK-129](../books/BOOK-129.md)系の水道橋周辺記録と対校）〕。
