# [GOV-597] 日本労働年鑑 第12輯 — 谷端川改修（立会川・神田上水と並記）の府都市計画新規事業費520万9千円の年度割と起債方法・巣鴨町下水の失業救済統計

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 大原社会問題研究所編『日本労働年鑑. 第12輯』（大原社会問題研究所・**1931**・[book/1448728](https://lab.ndl.go.jp/dl/book/1448728)）。昭和5年度の東京府の失業救済事業・議会審議を採録。**引用はOCR由来で、数値の一部（「八年度五三二九十三萬五千圓」等）にOCR崩れがあるため原本画像との照合を要する**。

## 文言〔確認・要照合〕

- 東京府議会の都市計画事業費（新規事業）条:
> 昭和五年度乃至八年度府都市計畫事業費繼續年期及支出方法(新規事業)**五百二十萬九千圓**、内譯 五年度**四十六萬五百圓**、六年度**百八十四萬五千三百圓**、七年度**百九十六萬八千二百圓**、八年度**九十三萬五千圓**（OCR「五三二九十三萬五千圓」＝要照合） **立會川、神田上水及谷端川改修** 起債の方法 利息の定率及償還の方法、目黑川改修費充當**十九萬三千圓**（利率）**四分八厘**、七年度迄据置 八年度より十四年度の七ヶ年間に償還 同上 品川海面埋立工事費充當**六萬九千圓**

- 同頁の郡部失業救済統計:
> （江戶川上水工事は…事業費百廿一萬一千四百九圓、內勞力費四十五萬四千二百四十八圓…）次に**巢鴨町下水工事**は事業費(OCR崩壊・引用しない)、內勞力費**十四萬七千六百六圓**、使用延人員**八萬六百四十五人**、一日平均使用人員**二百廿人**である。

## 読み取り〔観察・検算と対校は明記〕

- **①年度割絶対額の確定**: [GOV-159](GOV-159.md)（東京府岡田知事事項調書・trio改修の8.8/35.4/37.8/18%比率）に対し、本書は比率ではなく**年度割の絶対額（46万500・184万5300・196万8200・93万5000円）**を記し、**合計が520万9千円と一致する**（46.05+184.53+196.82+93.50=520.90万円・検算済み）。GOV-159の比率を金額に換算した背後の原数値系列と整合し、**昭和5年度予算として新規承認された年度当初額**として使える〔「事業費の使途内訳（三河川の配分）」は本条では示されない〕。
- **②起債方法の文言〔確認〕**: 「起債の方法・利息の定率及償還の方法」として**目黒川改修費充当19万3千円・品川海面埋立工事費充当6万9千円が利率（OCRで「利率」の字が落ち「四分八厘」のみ）4分8厘・7年度迄据置・8年度より14年度の7ヶ年間償還**と並記される＝trio改修520万9千円を含む起債群の償還条件の一次的な年鑑記録〔「四分八厘」は利率4分8厘（年4.8%）のOCR崩れと読むが、字面は要照合〕。
- **③巣鴨町下水工事の失業救済統計〔確認〕**: 昭和5年度の**郡部失業救済事業**として「巣鴨町下水工事」（事業費はOCR崩壊のため引用しない）の**労力費14万7606円・使用延人員8万645人・一日平均使用人員220人**を採録＝**谷端川流域の巣鴨町（1932年の東京市編入前）で下水工事が失業救済事業として実施された**ことの年鑑側統計。近接して「江戶川上水工事」（事業費121万1409円・労力費45万4248円・延人員23万3783人・日平均640人）も採録される〔同一の統計形式で並ぶ〕。下水と谷端川改修（trio改修3河川）が同じ昭和5年度の府事業として並行して走っていた時相の記録で、[BLOG-131](../blogs/BLOG-131.md)等の谷端川暗渠化工事の文脈（神田上水・谷端川の改修と下水整備の並行）の前段を成す。
- **④全体の文脈〔観察〕**: 当該頁は昭和5年度の東京府失業対策（府市協力・尾久町・亀戸町への事業誘致等）の記述の中に上記議会条を置く＝**世界恐慌下の失業救済政策と河道改修予算が直結していた**という経済的文脈を明示する資料〔trio改修が「失業救済」需要と結びついて先行した可能性を示す文脈史料として、断定はしない〕。

## 制限・未解決

- ①「八年度九十三萬五千圓」はOCRで「五三二九十三萬五千圓」と崩れている（前後の行融合か）＝原本要照合。②「四分八厘」の直前の「利率」の字がOCRで落ちている（目黒川・品川の充当額は全てtrio改修と同一の起債条件か、個別条かの構造も含め要照合）。③巣鴨町下水工事の「事業費」の数値はOCR崩壊で引用しない（労力費・人員のみ引用）。④昭和5年度は暦年度（1930年度）か会計年度表記かの注意（文中「昭和五年度」のまま引用）。
