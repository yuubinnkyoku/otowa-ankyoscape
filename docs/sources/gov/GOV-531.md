# [GOV-531] 都「神田川の新たな区間で河川事業に着手」〔寿橋〜富士見橋250m区間の着手表明・都公式発表〕

- **書誌〔確認: 本文・2026-11-23取得〕**: 東京都庁総合ホームページ報道発表「**神田川の新たな区間で河川事業に着手**」（2025年2月27日付）。 https://www.metro.tokyo.lg.jp/information/press/2025/02/2025022704 。別紙「案内図」（PDF）の添付あり〔所在のみ・今回未取得〕。
- **本文の文言〔確認: r.jina.ai経由本文・2026-11-23〕**: 「このたび、神田川の下記区間において、**都市計画事業の認可を取得しました**。これを受け、河川整備事業に着手しますのでお知らせします」「新たに事業着手する区間は、**中野区本町五丁目（寿橋下流）から杉並区和田一丁目（富士見橋上流）の約250メートル**です」「**令和7年2月27日から令和16年3月31日まで**の予定です」「今後は、下記区間の工事に向け、**設計等の準備を進めていきます**」。神田川の説明＝「**三鷹市の井の頭池に発し、善福寺川、妙正寺川を合流しながら東京都の中心部を流れ、下流部で日本橋川を分派したのち、隅田川に合流する一級河川**」「流域面積105平方キロメートル・河川延長24.6キロメートル」。
- **意義〔観察〕**: ①[GOV-530](GOV-530.md)（用地説明会ページ・「令和7年2月27日に事業認可が告示されました」）に対応する**都公式の着手表明文書**で、**認可年月日（2025-02-27）・区間（寿橋下流〜富士見橋上流・区丁目つき）・延長（約250m）・事業期間（〜令和16年3月31日）・着手段階（設計等の準備）**が一点に揃う〔区間の区丁目単位の特定と事業期限の明示は本資料で初〕。②**事業進行の方向＝改修が寿橋から富士見橋側へ進む**ことの2025年2月時点の一次記録で、[GOV-526](GOV-526.md)（その154・H31.3「下流から上流に向かって整備する計画」・新橋〜寿橋540m）→本資料という整備進行の行政側系列が揃う。
- **制限・未解決**: ①案内図PDFは今回未取得〔区間図の目視は次回課題〕。②**事業認可告示の原典（東京都公報の号）は未特定**：第18251号（R7.2.25）・第18253号（R7.2.27）・第18255号（R7.3.3頃）・第18262号（R7.3.12・道路事業変更認可告示のみ）の本文抽出を走査したが神田川文言は確認できず〔jina抽出ベース・画像PDFの目視未実施を含む〕。
