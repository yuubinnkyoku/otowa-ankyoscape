# [GOV-107] 星野家文書「千川養水路之件書類」（1794）〔repo初出の所在特定〕

## 書誌・公開状況（2026-11-14、ADEAC 杉並区立郷土博物館目録ページの直接確認・ai）

- 資料名(主)：千川養水路之件書類。資料名よみ：センカワヨウスイロノケンショルイ。
- 年月日：**1794年5月（寛政6寅年5月）**。時代：江戸。
- 差出人・作成者名：**星野兼五郎**（星野家＝江戸時代初期から上井草地域に居住の旧家）。
- 数量：1冊。形態：**竪帳**。材質：紙。
- 資料群名：星野家文書。指定登録種別：**杉並区指定有形文化財（古文書） 平成23年度**。
- 所在地：東京都杉並区大宮1-20-8 杉並区立郷土博物館。所蔵機関：杉並区 地域の学び推進課。
- 地域・場所：井草・今川・清水・桃井。
- 翻刻：**『星野家文書 千川用水関係史料（文化財シリーズ29）』（[BOOK-032](../books/BOOK-032.md)）1〜8頁**。
- 目録ページ：https://adeac.jp/suginami-city/catalog/mus-002476
- 公開解説（目録ページ記載）：星野家文書の多くは星野紋左衛門が戸長を務めた明治10・20年代に集中、文書群の概要は「平成23年度指定登録文化財調査報告」『平成23年度 杉並区文化財年報・研究紀要』（2013年）参照、の旨。

## 意義〔観察〕

- **「千川養水路之件書類」という史料名は [GOV-005](GOV-005.md)（練馬区「千川上水の分水を訪ねて(2)」本文）で寛政6年「千川養水路之件書類」に「江古田村田養水」という文言が引用されていたが、所在は記事に記載なしとされていた。本レコードで**杉並区立郷土博物館（星野家文書）に所蔵され、翻刻がBOOK-032の1〜8頁にあることが特定された**（GOV-005の未解決「所在は記事に記載なし」の解消）。
- GOV-005本文の記述から、本史料は**江古田村（現中野区）への「田養水」＝千川養水路の運用をめぐる文書**と推定されるが、目録レベルでは内容の詳細は確認できない（断定しない）。
- 星野家文書の千川関係は [GOV-016](GOV-016.md)（明治10年伏替願・mus-002479）に続く2点目の所在特定。
