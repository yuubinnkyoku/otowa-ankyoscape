# [GOV-395] 東京市史稿 市街篇第九 — 淀橋水車の寛文年中起立願文言・神田旅籠町の千川上水懸かり文言・求涼亭の音羽町由来説〔第166回〕

- **書誌〔確認〕**: 『東京市史稿』市街篇第九（東京市・1931年刊・都市政史料としての集成）。NDL次世代デジタルライブラリー [book/3450756](https://lab.ndl.go.jp/dl/book/3450756)。市街の起立・異動・事蹟の集成で、文政町方書上・寺社書上等の一次文書を大量に引用する。**引用文言はすべてOCR由来で要原文照合。市史稿の引用自体が一次文書の転記であるため、原文書（町方書上原本）との突合も理想だが現段階では市史稿掲載文言を記録する。**
- **淀橋水車の文政町方書上引用＝寛文年中起立願の回顧文言〔確認・核心・repo初出級〕**: 淀橋水車（附記三）の条に文政町方書上の引用として「**柏木淀橋町〔中略〕五百五拾坪家持久兵衞持右久兵衞儀、持地面住居仕、先祖彌兵衞と申者、年曆不知舊來〓當所百姓こる罷在候處、寛文年中神田御上水助水堀分水仕、水車取立申度段相願、右水車こる小麥粉井米麥等春立渡世仕候**」＝**①淀橋水車の家は柏木淀橋町内の家持久兵衛（550坪の家持久兵衛持）、②先祖彌兵衞（弥兵衛）が年暦不知の旧来の当地百姓であったところ、寛文年中（1661-73）に神田御上水の助水堀から分水して水車を立てたい旨を願い出て、③その水車で小麦粉や米麦などを舂いて（春立＝舂立のOCR候補）渡世した**という文政町方書上側の回顧〔**[GOV-390](GOV-390.md)（享保撰要類集・延享3亥年4月9日の家業譲渡裁定）の「享保四亥年（1719）水車仕立」文言より約60年先行する寛文年中起立願の年代情報＝両者の年代の食い違いは対校案件として記録し断定しない**〔享保4年説は奉行所裁定の一次文言、寛文年中説は文政期の町方書上側回顧（「寛文年中」に寛文年間の助水堀整備と水車願の記憶が融合している可能性も含む）。「神田御上水」の寛文年中の呼称・助水堀の実体（玉川上水助水か）も原文照合・裏付け待ち〕。**「先祖彌兵衞」の文言は[GOV-399](GOV-399.md)の弥兵衛系譜（寛文願→元文5年〔1735〕の弥兵衛印形→文久期の久兵衛）の系譜側補強**〕。
- **神田旅籠町壹丁目の文政町方書上引用＝安永9年（1780）の千川上水の町内懸かり・短期差止文言〔確認・核心・repo初出〕**: 神田旅籠町壹丁目の条に「**古上水跡之儀も、安永九子年中千川上水町内へ相懸り候得共、無程御差留ニ相成候處、右之形チ當時相見に不申候**」＝**①神田旅籠町1丁目に「古上水跡」があり、②安永9子年（1780）に千川上水が町内へ懸かった（通過した）が、ほどなく御差止めとなり、③その跡形は文政期（書上時点）には見えない**という町方書上側の回顧〔**千川上水の市中（神田側）への通水が安永9年（1780）に一時的に行われたことを町方書上側から記す文言候補（repo初出）**〔[GAZ-082](../gazetteers/GAZ-082.md)④の下谷側の安永8未年（1779）文言群（千川上水懸かり・差止）と1年差の対校案件として記録（安永8〜9年のどちらか・あるいは複数回かは両文言の照合まで断定しない）。旅籠町側の「古上水跡」の同定（千川上水跡か他の上水跡か）も文言上は保留〕。
- **求涼亭引用の音羽町・櫻木町の町名由来説（京清水寺模倣）〔確認・文言候補・repo初出〕**: 護國寺の条に「**求涼亭云く、當寺ハ京の〓水寺を摸さるゝ故に、前の町を音羽竹竹竹町櫻木町などなつけられ、又音羽町九丁あるも、京に一條より九條までの れあるにもとつくとそ**」（「〓水寺」＝清水寺のOCR崩れ候補・「音羽竹竹竹町」は「音羽町」等のOCR崩れ候補）＋同条に「**悉地院と號す。音羽町の北にあり**」の所在文言＝**①護國寺は京の清水寺（音羽山清水寺）を模したので、その前の町を音羽町・櫻木町などと名付け、②音羽町が九丁あるのは京の一条〜九条に因む**という求涼亭（『求涼亭筆記』か・人物の号か・要照合）による町名由来説〔**護国寺前の音羽町（明治期の小石川区音羽町＝現・文京区音羽）の町名由来を清水寺模倣に求める新系統の文言候補（repo初出）**〔**注意**: この由来説の「音羽町」は護國寺の「前の町」（同条の所在文言により護国寺の南側）を指すと読むのが自然で、[GAZ-076](../gazetteers/GAZ-076.md)・下記洞雲寺条の**牛込音羽町（現・新宿区側）とは別の音羽町**の可能性が高い。両音羽町への当てはめ・特に牛込音羽町の由来説として使うことは原文言の所在文言との突合まで行わない。「櫻木町」も牛込の桜木町（水窪川・弦巻川流域の町）とは限らない（京の清水寺参道の櫻に因むと読める文言）〕〕。
- **洞雲寺の文政寺社書上（牛込音羽町在・龍泉山）〔確認・参考〕**: 同巻に文政寺社書上の引用として「**洞雲寺ハ、豐嶋郡牛込音羽町ニ在、龍泉山と號す。境内除地三百六拾坪、年貢地四百五十坪、通計八百拾六坪、持添二ケ所九百八十三坪…本寺は黃檗山萬福寺にして、獅子林下なり。もとハ妙心寺派の禪にして、新坐郡野火留村平林寺ニ屬す。寛文年中黃檗派ニ轉す。中興ハ平石道樹和尙なり。隱元國師をして勸請開山とす。開基ハ醫家森養竹…來由を記さる書延享二年乙丑の火災こ亡て今詳な〔ら〕ず**」＋洞雲寺の文政寺社書上として「**寺起立年代相知レ不申候。往古ハ眞言之寺跡こるも候哉、野火泊平林寺こる濟家之處、寛文年中ニ黃檗等宗門こ相改候と申傳。其由諸書等ハ延享二丑年類燒仕、其節不殘燒失仕候と申傳**」＝**文政寺社書上による牛込音羽町の洞雲寺（龍泉山・黃檗宗・開基医家森養竹・延享2年類焼で由緒書焼失）の書上**〔**[GAZ-076](../gazetteers/GAZ-076.md)（関口寺社書上・文政10）の水神社・関口の鎮守八幡の別當と同寺**。同条には「**關口鎭守正八幡宮、束帶木座像、身丈七寸、春日之作と申傳有之候。本社九尺四方、拜殿貳間…**」「**關口水神社起立、別當洞雲寺御除地九百坪一、水神社一、神躰別ニ無之、本地佛妙見木座像…**」の関口側社記も同居（関口の水神社・八幡の実態の書上レベル対校資料）〕。
