# [GOV-505] 小金井市文化財センター通信 №3「小金井の湧水点 part 3」（2023-03-31発行）〔repo初出・四割堰の実影と梶家文書絵図による近世水利施設（大熊堰・掛樋群）の現在地推定・田用水／悪水の用途名論〕

- **書誌〔確認: 公式PDF取得・2026-11-22〕**: **小金井市文化財センター通信 №3「小金井の湧水点 part 3」**（**文／構成　多田 哲（学芸員）**・**令和5年3月31日発行**〔発行日はPDF末尾クレジットで確認・年のみ数字欠落でシリーズ一覧頁と整合〕・8頁）。[PDF](https://www.city.koganei.lg.jp/kankobunka/bunkazai/oshirase/bunkazaimagazine.files/bunkazaimagazine003.pdf)・[シリーズ一覧](https://www.city.koganei.lg.jp/kankobunka/bunkazai/oshirase/bunkazaimagazine.html)。本号は当repoの自作PDF抽出器で長らく文字化けていたが、**リテラル文字列のエスケープ処理（\\t等）の欠陥を修正した結果、ほぼ全文のテキスト化に成功**〔ただし一部の数字（年・地図の縮尺・号線番号・距離の桁）はテキスト化で欠落しており、該当箇所は「（数字欠落）」として扱う〕。主題は**野川・旧仙川流域（貫井たんぼ）の近世〜近代の水利施設史**＝part2（[GOV-504](GOV-504.md)）の「【以下、次号に続く】」の続き。
- **四割堰〔確認: 本文・水澤静男撮影写真の図版解説〕**: 「**中前橋の下流東にあった四割堰は小金井市域では最後まで残った堰**」で、竹と杭木で野川をせき止める伝統的な構造（「写真左側竹を杭木に編み込んで野川をせき止めているのが分かります。竹と杭木は堰の伝統的な用材」）＝**竹・杭木による伝統的堰工法の実影と構造文言**〔図版は水澤静男撮影・昭和（数字欠落）年の地図〔小金井町全図アトラス社〕に「割堰」記載あり。本文冒頭の「割堰 和30（1955）5月」表記と併せ、**昭和30年（1955）5月時点での存続**が確認できる。小金井町アトラス社図に弁天池は記載されていない点も本文の対比項目〕。
- **首塚胴塚と金井原古戦場〔確認・推定の区別は本文明示〕**: 「拓殖（大学）が首塚胴塚を取り壊し更地にして野菜畑にしたのち東京府が調査発掘をした」＝**首塚胴塚の取り壊しの経緯**。『小金井村郷土誌』（**昭和9年1月・小金井尋常高等小学校（現第一小学校）訓導教師らが編纂発行**）の光明院址の項目は過去形で書かれており、「**この２つの丸塚を首塚胴塚とすると、拓殖は昭和７年末には設立を決定しているので首塚胴塚の取り壊しは昭和８年頃と推定できます**」〔筆者推定〕。首塚胴塚と骨器（モリ農〔武蔵農場か〕の時代に出土・年代は「昭和10年頃」としか分からない）は「**金井原古戦場と結び付けられ熱狂的に取り沙汰されていました**」＝**新田勢が賊将足利尊氏に勝利した金井原古戦場（皇国史観の影響下で称揚）の指定（東京都史跡・昭和〔数字欠落〕年前後）を機に関心が盛り上がったとする戦前の受容史**〔松平実科女学校の造成や昭和4年の野川改修工事に伴う出土物の記録は存在しない、とする批判的整理が本文の主眼の一つ〕。
- **明治8年と昭和4年の地図の水文対比〔確認: 本文の読図〕**: 明治8年は地租改正（明治6年）により近代測量地図が作られた年の小金井における始まりの年（小金井村全図・貫井村全図＝難航の末明治8年に完成）。「**明治８年の小金井村全図・貫井村全図と昭和４年の地図を比較検討したところ３つの水系に根本的な変化がないことに気づきました。つまり野川と田用水・滄浪泉の池の湧水・玉川上水の分水は明治８年から昭和４年までほぼ変わっていないのです**」＝**野川（悪水／排水）・田用水（給水）・湧水系の3水系の明治8年～昭和4年の安定性の読図結論**〔弁天池を南西の隅とする水田地帯（貫井たんぼ）は小金井村と貫井村にまたがり、2つの村全図を合わせ見ることで明治8年の貫井たんぼが俯瞰できる〕。
- **梶家文書の絵図と近世水利施設の現在地推定〔確認: 本文・推定は地図照合による筆者推定として明示〕**: 江戸期にまで遡る**梶家文書の絵図**（享保5年・寛保4年のほか多数）に描かれた流路は「**今まで誰も指摘しなかったのが不思議なくらいに明治８年と昭和４年の地図に見る流路に相似**」であり、絵図のみにある堰や掛樋の現在地を明治8年・昭和4年・現代の地図に落とし込み計測した結果:
  - **大熊堰**: 西之台橋から東へ（数字欠落）mほどの地点・松平実科女学校の南西角地・くぢ宮付近・貫井村と小金井村の村境の東側（小金井村側）。享保5年絵図では「大熊堰を造って野川を一旦せき止めその上流の水位を上げる」（野川の水面が田んぼより低いため）。
  - **神明前掛樋**: 大熊堰のすぐ東側下流。「田用水の合流点に水を供給するためとしか思えない」（筆者の推測として明示）。
  - **横まくり掛樋**（別名: 横まくり筧・箱とい用水・横まくり箱樋筧）: **前原小学校北西の住宅地・前原小学校正門から（数字欠落）mほど西の駐車場付近・モリの池があった場所**。長さ五間（約9m・野川を斜めに横断するため川幅より長い）＝「**横まくり箱樋長五間 御公儀様御入用ニ御座候**」（**寛保3年**）＝**幕府（御入用普請）が維持費を賄っていた掛樋の用材記録**（松の板を組んだ樋＋松丸太2本の横張り木＋ヒノキ丸太8本の立柱、堰部分は葉竹・杭木）。
  - **大堀堰**: 野川はなみずき公の西端付近・村境の東側小金井村側。
  - 周辺の近世の字名: **神明前・横まくり・大堀・大上堀はいずれも検地帳に記載がある字名**＝「横まくりの語源はおそらく現在の前原小学校の西校舎付近で合流点に向かってほぼ直角に曲がっていた野川」（筆者の推論）。「**横まくり堰是ハ筧ニも仕候**」（**明和8年**）。
- **享保15年「用水新堀につき上小金井村惣百姓連印証文」と、呑用水の欠如〔確認: 一次文言の引用〕**: 「**享保十五年といえばしきりに上水からの分水を願い出ている時期であるが上小金井村の全員連名して新しい用水路建設を決定している。その事情は大熊堰が沼であるため水保ちがわるくて困るので坂下築樋の土をあげ神明山に新堀を掘り二本の水路とし一本は大熊堰付近をぬり樋にして通し一本は光明院境内から八右衛門畔を経て田用水に入れ太兵衛下まで通すこととする**」＝出典は**享保年〔15年＝1730〕作成の証文・『小金井市誌Ⅲ 資料編』**〔「ぬり樋」は正しく「**圦樋（ゐり樋）**」と読むと複数のくずし字読み下し専門家が結論した由を本文が記録＝神明前掛樋を指す話〕。さらに**明和8年**の文言「**当村ニハ呑用水前より無御座候 井戸御座候**」＝**分水路建設済みでも飲料水は井戸頼みだった事実**。**根岸茂夫（小金井市史編さん委員長）への取材**: 「**悪水は排水を意味する。田んぼより水位が低い野川は主に排水路として使われ、使用用途を悪水と書き込んでいるのであって固有名詞ではない。田用水は田んぼへの給水、悪水は田んぼからの排水と理解すべき**」＝**「悪水と呼ばれた仙川は使用用途が固有名詞に転化した事例」**〔[GOV-504](GOV-504.md) part2の呼称変遷の意味論的裏付け〕。
- **くぢ宮・押切場〔確認: くずし字判読の結果〕**: 小金井村絵図（宝永5年以降）の首塚胴塚辺りに鳥居のようなものと文字の記入があり、複数のくずし字読み下しの専門家の鑑定で「**くぢ宮**」（くび宮ではなく）と結論が一致、意味は不明だが前原神明宮とは**別の宮**が描かれている〔宝永5年以降の『小金井村絵図』KS569系〕。寛保4年絵図では大熊堰と神明前掛樋があった付近の「四角で囲った土地」を「**押切場**」と記入〔小金井市誌歴史編の対比図版も掲載〕。
- **意義〔観察〕**: ①**四割堰の実影と「小金井市域で最後まで残った堰」の文言**＝野川の近代以前の堰工法の実体資料で、[GOV-504](GOV-504.md)の山王窪の築樋（仙川側）と対になる野川側の水利施設記録。②**梶家文書絵図（享保5年・寛保4年）・明和8年・寛保3年・享保15年証文の水利施設群の現在地推定**＝小金井市域の玉川上水系「田用水」研究の座標群で、宝永『小金井村絵図』と明治8年・昭和4年・現代の地図の4層対照という方法論を通信自身が明示している。③**「悪水＝排水の用途名であって固有名詞ではない」（根岸茂夫談）**＝千川上水・玉川上水系の「悪水」呼称の語彙論として、[BOOK-235](../books/BOOK-235.md)の「大堀／堀」体系や[GOV-504](GOV-504.md)の武蔵川と接続する重要な定義文言。④**明和8年「呑用水前より無御座候」**＝近世の飲料水と用水の区別の一次文言。

## 制限・未解決

- ①梶家文書の絵図（享保5年・寛保4年）・用水新堀証文（享保15年）・明和8年文言の**原本は小金井市誌Ⅲ資料編・梶家文書そのものへの直接照合が未実施**（通信の引用文言に依拠）。②堰・掛樋の現在地（前原小学校駐車場付近等）は**明治8年・昭和4年・現代地図への落とし込みによる筆者の推定**で、発掘等の物理的確認はない。③PDFテキスト化で**年・路線番号・距離の数字が一部欠落**（例: 「昭和年」「現市道第号線」＝正確な桁は原画像の確認が必要）。④四割堰の取り壊し時期は本文に明記なし（昭和30年図に記載）。⑤「くぢ宮」の語義は本文も「意味は不明」としており、解釈を記録しない。⑥「坂下築樋」の「土置上げ」＝伏せ越し逆サイフォン説は筆述の解釈（本人が明示）。
