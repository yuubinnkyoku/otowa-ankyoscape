# [GOV-518] 豊島区「豊島区公園等再構築プラン」〔千川上水公園・谷端川系公園群の再整備の行政座標〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: 豊島区公式サイト（ページ更新日2026年4月6日・ページID 50829）。 https://www.city.toshima.lg.jp/454/2503031123.html 。meta description＝「**豊島区は、昨年度末に策定した基本計画の一環として「魅力ある公園づくり」を掲げ、地域の特徴を生かした公園づくりの計画（公園再構築プラン）を検討して**」＝**基本計画（昨年度末策定）の一環の地域別公園計画**。公開PDF＝本編・地域別編（2026年4月6日アップロード分：`/documents/50829/20260406173214.pdf`・`20260406173320.pdf`）ほか旧版数点。
- **モデル地域〔確認: 地域別編PDF本文〕**: 「**モデル地域は…「巣鴨・西巣鴨地域」「高田地域」「高松・要町・千川地域」**」〔選定基準＝①公園・児童遊園数が少ない②…③**親水施設**、（噴水等？）④…〕＝**3モデル地域のうち2つ（巣鴨・西巣鴨／高松・要町・千川）が千川上水・谷端川流域**。
- **巣鴨・西巣鴨地域の対象公園10園と機能分担〔確認: PDF本文・結果2-1表〕**: ①西巣鴨四丁目児童遊園②**千川上水公園**③西巣鴨二丁目公園④朝日公園⑤巣鴨五丁目児童遊園⑥〜⑧巣鴨四丁目児童遊園群⑨江戸橋公園⑩巣鴨一丁目児童遊園。**「地域全体…機能分担が必要」**という意見枠組みと、**公園の役割機能の割付表**＝**千川上水公園＝「のびのび遊べる」**・巣鴨五丁目児童遊園等も同機能・西巣鴨二丁目公園＝「自然にふれる」系。**意見表（公園の再構築への意見）で「千川上水公園（親水系）…再構築…するのが良い」「…設備を導入し機能更新」の文言**＝**千川上水公園＝都の旧千川上水浄水場跡地〔[GOV-106](GOV-106.md)沈澱池復元・[GOV-496](GOV-496.md)区制六十周年の親水空間〕の次期整備の行政座標**。
- **高松・要町・千川地域の対象公園13園〔確認: PDF本文・結果2-3表〕**: ①**千川彫刻公園**②要町一丁目児童遊園③高松一丁目児童遊園④高松二丁目児童遊園⑤高松三丁目児童遊園⑥千川二丁目第2児童遊園⑦千川二丁目中央児童遊園⑧千川二丁目児童遊園⑨要町一丁目広場⑩富士浅間神社境内仮児童遊園⑪**千川ひろば**⑫**高松一丁目公園予定地**⑬**高松三丁目公園予定地**（ほかに高松小学校・**千川中学校（改修中）**・千早公園・区民ひろば高松・豊島体育館の周辺施設記載）＝**千川上水旧流路（谷端川と並走区間）周辺の公園・児童遊園の現状一覧の行政記録**〔谷端川緑道（[GOV-106](GOV-106.md)）と千川上水公園の間の「公園の再構築」の体系座標〕。
- **意義〔観察〕**: ①**千川上水公園が「モデル地域の機能分担対象（のびのび遊べる）」として計上**され、親水空間としての再構築の候補文言が付いた＝[GOV-496](GOV-496.md)・[GOV-113](GOV-113.md)（千川上水公園系の公園行政記録）の**次の30年の行政側の計画文書**②高松・要町・千川地域の13公園群＝**千川上水跡地・千川二丁目系の公園の相対位置と規模（核・小核等）の一次記録**〔千川彫刻公園＝[GOV-117](GOV-117.md)・[GOV-129](GOV-129.md)の既存記録と接続〕③巣鴨・西巣鴨・高田と並ぶモデル地域選定（谷端川上流の染井・巣鴨地区＝[GOV-133](GOV-133.md)谷田川系）＝**谷端川・千川上水という水系遺産と公園網の対応関係の計画書側の視点**。

  - **モデル地域の方向性（第4章）**: 巣鴨・西巣鴨=「**親水施設」を千川上水公園、「インクルーシブ遊具」を巣鴨一丁目児童遊園へ設置する方向**」・巣鴨四丁目折戸児童遊園は**遊具を設置せず「憩い」をメイン機能へ特化**。高田=「親水施設」を高田中央三丁目公園、「インクルーシブ遊具」を高田第二公園へ・山吹の里公園「憩い」＋高齢者向け「健康遊具」。**高松・要町・千川=「親水施設」をふるさと千川ひろば、「インクルーシブ遊具」を高松一丁目公園予定地へ**・高松一丁目児童遊園=「憩い」特化・高松三丁目公園予定地=「広場」メイン＋「公園活用」「防災機能」サブ＝**第267回の地域別編の表に加えて、本編での文言が確定**〔千川上水公園・ふるさと千川ひろばへの親水施設設置方針・高松三丁目公園予定地の防災機能の2層〕。
