## 内容〔確認: 本文全文・2026-11-27取得〕

### ①「田柄用水の経路」（column/3632）

- **田柄川（自然河川・光が丘から田柄・北町・錦を経て板橋区で石神井川に合流）と、田柄から北町地内にもう一流、田柄川に沿う水路（＝田柄用水）があった**構造の明示:「その位置は**田柄四丁目の天祖神社前の東西の道路に当たり、ほぼこの道の北脇に沿って東流し、旧川越街道に達し、さらに街道の北あるいは南に接して流れ、北町一丁目地内で南に向かい、田柄川に合流**していました。今では完全に道路の下に埋められてしまいました」＝**用水の練馬区側流路の区界レベルの記述**。
- **「天祖神社前にある田柄用水に掛かっていた石橋（令和4年写真）」**＝天祖神社前の石橋の現存（2022年時点）の公的サイト記録〔写真文言〕＝[BLOG-360](../blogs/BLOG-360.md)（階段前の小さな橋＝用水流路跡〔観察〕）の公的側対応。
- 用水の上流追跡: 光が丘の西・土支田地内のコンクリートふたかけ部分や路地状で残る水路→富士街道南脇（現在歩道）→保谷→田無・青梅街道沿い→**田無橋場のバス停＝玉川上水の分水路が集束される重要な地点**。「当初は田無用水の延長として引かれた田柄用水でしたが、後にはここに集まる何本もの人工水路から水を受けることになりました」。
- 名称:「田柄田用水」などと呼ばれた人工河川。上水（飲料専用）と用水（灌漑ほか多目的）の名称区別への言及あり。

### ②「田柄用水の開発」（column/3656）

- 明治3年、玉川上水に船を通して淀橋まで物資輸送する計画（**輸送は明治5年5月で中止**）が起こり、玉川上水から直接水を引いていた各分水口は廃止、**上水に沿う「新堀用水」が現小平市中島町の西方（東京都水道局小平監視所）から引かれ、以後はこの分水から各村に水を分ける**ことになった＝[GOV-067](GOV-067.md)（千川上水側の通船計画分離文言）に対応する田柄用水側の同型文言。
- **「土支田の小島家に残る、明治4年正月の増水計画についての文書」には、水路延長で各村の水田面積が増えることは、すなわち、政府に差し出す税金が増えることになるとの趣旨が記してあり**＝**土支田小島家文書（明治4年正月）の内容の公的叙述＝repo初出**（[ORG-051](../org/ORG-051.md)今昔24の小島家文書〔練馬区教委1993編〕と同一文書群の候補・断定は原物確認まで保留）。
- 10か村（田無・上保谷・関・上石神井・下石神井・谷原・田中・下土支田・上練馬・下練馬〔後、谷原村が抜ける〕）の増水願い。**各村で見込まれた水田拡張面積: 田無村=25町歩（在来分を含む）・上保谷村=25町歩（同）・関村=1町歩・上石神井村=2町5反歩・下石神井村=7町歩・田中村=4町歩・下土支田村=9町歩・上練馬村=3町歩・下練馬村=4町歩**＝村別面積リスト。
- 「水路の延長工事は、明治4年5月（4月25日とも言われています）には、一応の完成を見た」「人件費そのほか、費用の合計は、**1,350両ほど**であったことが記録に見られます」＝完成期日2説と費用の文言。名称変遷: 玉川上水北側新井筋分水→田柄田用水→田柄用水。
- 明治10年、東京への飲料水不足で**玉川上水からの引水に50%の制限**が実施され、下土支田村は天水に頼り増水願いを繰り返し。明治15年には田中村から規定外の水を回してもらったり、下流の上練馬村・下練馬村との間に**水利用の協定**を結ぶ。
- 転機は**石神井川下流の板橋や王子に火薬製造所・王子製紙・大蔵省印刷局抄紙部などの大規模工場ができ、これらの工場用水に田柄用水の水が注目された**こと。「これらの工場は、初め、**千川上水や石神井川の水を利用していましたが、それだけでは足りず**、田柄用水系統の増水を願い、上流の小平市域各用水の流末を田柄用水に引き込む働きかけをしました」＝**千川上水系工場用水の不足が田柄用水増水の動機**という水系間連関の文言＝千川上水水利史（替水約定BOOK-220・分配堰碑BLOG-095・抄紙部給水GOV-058）の隣接系統側の裏付け。
- 「明治26年には大幅な増水計画が実り、田柄用水沿いの村をはじめ、**王子製紙などの工場、さらに王子村ほか22か村の間に、水利用の契約書が取り交わされています**」「これを記念して、**明治26年11月、田柄用水沿いに、水神を祀る記念碑が造られました（現在は、田柄四丁目の天祖神社に所在）**」＝**記念碑の建立月次（明治26年11月）・水神を祀る趣旨・現所在の3点セットの公的記録＝repo初出の精度**＝[BLOG-360](../blogs/BLOG-360.md)「上練馬村玉川上水分水紀念碑」碑名・明治26年増水実現説の公的側からの裏付け（同一碑と推定されるが断定は碑文採録まで保留）。

### ③「田柄用水 水田利用の形」（column/3688）

- 田無村がリーダーとなり9か村を誘ったことは**埼玉県行政文書（「保谷市史」所収）にも記されている**。灌漑用として見込まれた水田面積の合計は**約80町5反歩（約79.8ha）**。所在地は大きく2か所: **石神井川沿いに広がる水田（約60余町歩）と、練馬区域北東の田柄川沿い（16町歩）**。
- 石神井川流域7か村（田無・上保谷・関・上石神井・下石神井・田中・谷原）の水田は田柄用水そのものからの分水はほとんどなく、古くからの**田無用水**を通じて利用。**明治8年の「武蔵国郡村誌」には、保谷市域の石神井川に沿う水路と思われる「柳沢用水」の名が記されている**＝**柳沢用水の書誌的存在＝repo初出候補**（石神井川南流入・下流分水の役割と推定される）。[BLOG-281](../blogs/BLOG-281.md)柳沢遊水地系記述の用水側の対応候補。
- **安政6年（1859）の上練馬村絵図には、現在の田柄一丁目付近にわずかな水田が描かれ、下練馬村絵図（石神井公園ふるさと文化館所蔵・年代不詳）には、現在の北町地域と推定される川沿いに帯状の水田が見られる**＝江戸期水田の絵図レベルの記録。
- **「この下練馬村絵図には、上練馬村境（現北町八丁目の南西付近）にかなり大きな池が描かれ、『溜井』と記されています。これは、文化11年（1814）以降に刊行された地誌「遊歴雑記」に「練馬下田柄村の池」と紹介されているものに符合します。この池は、広さおよそ1町（約109m）四方で、元来は近郷の用水にするために掘り、設けられたとあります」**＝**①下練馬村絵図の「溜井」の所在（北町八丁目南西付近）・②遊歴雑記「練馬下田柄村の池」（1町四方・用水のため掘設）の2史料の符合という池の比定文言＝repo初出**＝[BLOG-073](../blogs/BLOG-073.md)/[BLOG-074](../blogs/BLOG-074.md)（遊歴雑記1814・高田雲雀1788池ヶ谷の豊島区側池群）に対する練馬区側の同書池記事で、遊歴雑記の池記述が多摩・豊島両域にまたがることが判る資料。
- 田柄川の谷はかなり発達し、**最も西の先端は土支田三丁目付近までさかのぼれる**。「土支田地域の水路は、田柄用水の一部とされていますが、それ以前にも自然の水路として存在していたことは、**明治2年と推定される土支田村の絵図**に描かれていることからも分かります」＝明治2年土支田村絵図の存在（[ORG-051](../org/ORG-051.md)今昔24の万延元年小島家文書記録と併せ、田柄川上流の江戸期資料群の所在が判る）。**明治44年発行の1万分の1地形図には、現光が丘西端に当たる地域まで水田地帯が広がっている**＝田柄用水の効果が図上に現れるという読図の指摘。

## 意義

- 田柄用水についての**区公式サイトレベルの一次的整理**（元・区報連載）で、①小島家文書（明治4年正月）の趣旨、②村別水田拡張面積と1,350両、③明治10年50%制限と明治15年協定、④工場用水（千川上水→田柄用水）の水系連関、⑤**明治26年11月の記念碑建立**、⑥天祖神社前石橋の現存、⑦下練馬村絵図「溜井」＝遊歴雑記「練馬下田柄村の池」の比定、⑧柳沢用水・安政6年/明治2年絵図・明治44年地形図の各所在、の8点がrepo初出。
