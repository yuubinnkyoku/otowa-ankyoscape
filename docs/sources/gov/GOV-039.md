# [GOV-039] 1993年『かたりべ』30号：河川の暗渠化と高田・雑司が谷の区境踏査

- **資料〔確認〕**：豊島区立郷土資料館『かたりべ』第30号、**1993年4月30日発行**。豊島区公式公開[PDF](https://www.city.toshima.lg.jp/documents/2549/kataribe30.pdf)（全8頁）。**印刷p.6**「郷土資料館なんでもQ&A／豊島区は起伏のある地域ですが、川が流れていないのはなぜですか？」（回答末尾署名「伊藤」）および**印刷p.1**「区境が見えた！」（末尾署名「石川」）を**原PDFのページ画像から直接判読**（2026年11月2日）。
- **1993年当時の区立資料館の説明〔確認〕**：p.6は、当時豊島区内で地表の川の流れとして見られるものを新宿区境の**神田川**とし、かつての**谷端川・弦巻川・水窪川・谷戸川**を「自然の川」、**千川上水**を「人工の川」と説明する。これらの多くが暗渠化され、その上を人や車が通ること、道路や公園に名残をとどめることも述べる。
- **谷端川の土地利用変化〔確認：同号p.6の後年の概説〕**：谷端川が**農業用水などとして流域の生活に密接に結びついていた**こと、都市化で**生活排水が流入**して川の性格が変化したことを述べる。**各時期の水質・流量・取水地点を測定した一次資料ではない**。
- **千川上水の状態〔確認：同号p.6の1993年時点の説明〕**：用途が江戸の町への給水から流域の農業用水、流末の産業用水へ変化したと説明し、戦後の暗渠化・一時的な通水停止・住民の清流復活運動を回顧する。**1993年時点では上流部に復活した流れが見える一方、豊島区内の区間は暗渠のまま**と述べる。具体的な停止年・復活年はこの頁にはない（別途、東京都建設局の1971年・1989年の記録と照合する）。
- **旧境界・神田川の改修前流路への言及〔確認：同号p.1〕**：「区境が見えた！」は**3月7・14・21・28日の地域史講座**で高田・雑司が谷および駒込・巣鴨の区境を歩いたと記し、旧**高田町と落合村の境**に当たる**豊島区目白3-4／新宿区下落合3-1**の細い通路を写真と地形図で示す。記事末尾では、区境の踏査が**護岸工事以前の神田川の流路**を意識する機会になったと述べる。**目白3-4の写真地点が旧神田川河床そのものだとは書かれていない**。
- **解釈上の留保〔観察／推定／未解決〕**：1993年の郷土資料館による概説・現地講座の回顧として価値があるが、**「自然の川」という総称は全区間の成立過程を立証しない**。とくに音羽谷の弦巻川下流の近世以降の造成・付け替えや、水窪川との合流の有無は別史料で検証する。区境の記述も、旧神田川の中心線や護岸工事の年・区間を確定する測量図ではない。**1993年の現況を2026年の現況と同一視しない**。
