# [GOV-138] 技術調査年報2015年版・目白・下落合雨水幹線シールド記事〔repo初出〕

- **書誌〔確認: Wayback保存版PDF全文取得〕**: 東京都下水道局『**技術調査年報-2015- Vol.39**』所収、**1-1-3**。貞本健志（**第一基幹施設再構築事務所 工事第二課 工事係**）「**大径礫・流速の速い地下水・急勾配におけるシールド施工について～豊島区目白三丁目、新宿区下落合二丁目付近再構築その３工事～**」（**要旨=印刷頁7・本文=印刷頁48〜51付近**。年報目次の頁表示「要旨7・本文48」で確認）。原本PDFは東京都オープンデータで公開されていた〔[オープンデータURL](https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2015all.pdf)・直接アクセスは403のため、[Wayback保存版 2024-07-08スナップショット](https://web.archive.org/web/20240708075528/https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2015all.pdf)（完全版23,476,466バイト・Range分割取得）で全文確認〕。処理区名＝**三河島処理区**、施策区分＝**浸水対策**、実施年度＝平成25〜27年度（要旨）。
- **工事の目的〔確認: 本文〕**: 「**ＪＲ目白駅付近は過去に浸水事故が発生しており、早急な対策が必要となっていた（写真2.1）**」とし、写真2.1のキャプションを「**過去の浸水被害状況（H24.8）**」と記す〔確認: 本文・写真キャプション文言。被害の規模・降雨・浸水機構の記述は本文に見当たらない〕。目的として**豊島区目白一・三丁目、高田三丁目、新宿区下落合二・三丁目付近の既設管きょの雨水排除能力の増強**を掲げ、**泥土圧シールド工法により新たな管きょ（内径2400mm）1,256mを敷設**したと記す〔確認: 本文〕。
- **工事区間〔確認: 本文〕**: **ＪＲ目白駅付近の発進立坑（「その2工事」で施工済み）から学習院大学の敷地（〼）側に新設する到達立坑まで**で、**到達立坑において既設幹線に接続**する〔確認: 本文・図2.1工事案内図の文言〕。構造物は一次覆工2400mm・194.40m＋一次覆工（二次覆工一体型）2400mm・1,061.55m（合計≒1,256m）等〔確認: 本文表〕。
- **地盤条件〔確認: 本文・要旨〕**: 通過地層は上層から**洪積の粘性土・礫・砂質土**。**礫層は50mm〜250mmに及ぶ大径礫**で構成され（当初ボーリングでは最大径70mmと想定していたが、追疎調査で最大径250mmと判明）、**層内には被圧された地下水が1.2cm/分程度（要旨文言）の速い流速で流れている**ことが**ボーリング孔を用いた熱量法による流向流速測定**で確認された〔確認: 本文〕。また**急勾配105.1‰**で礫層を掘進する区間があった〔確認: 本文・要旨〕。
- **位置づけ〔観察〕**: 対象地域（目白一・三丁目・高田三丁目・下落合二・三丁目）は**旧弦巻川下流域・神田川上流左岸の低地**で、repo既述の弦巻川・水窪川流域（音羽谷〜目白〜高田〜下落合）と重なる。**2012年（H24.8）にJR目白駅付近で浸水事故があったこと、その対策として φ2400mm・1,256m の雨水幹線が2013〜2015年度に新設されたこと**が都の技術資料で確認できる〔確認〕。ただし**本幹線の名称（弦巻川幹線か目白雨水幹線か等）・既設幹線の対応は本文に明記がなく、旧弦巻川の暗渠幹線との同一性は断定できない**〔未解決〕。「第一基幹施設再構築」「その3工事」の呼称から**同一事業のその1・その2（発進立坑側）工事の記録が年報他年版にある可能性**があり、追跡候補〔推定〕。
- **陰性記録〔確認: 全文走査〕**: 2015年版全ページ（記事多数）を走査し、**「谷端川」「千川」「弦巻川」「水窪川」「雑司ヶ谷」の文字は本1-1-3記事を含めて皆無**だった〔確認: 抽出テキストの全文検索〕。

## 制限・未解決

- ①浸水事故（H24.8）の規模・降雨量・浸水機構の記述は本文にない（写真キャプションのみ）。②新設幹線の名称・系統、既設幹線との関係は本文に明記なし。③工事案内図（図2.1）の線形は画像で未判読。④「その1」「その2」工事の記事所在（年報2013・2014年版は既にGOV-122/123で走査済みで該当記事は確認されていない。他年度版の所在は未確認）。⑤本文の数値文言の一部（地下水の流速は要旨「1.2cm/分」と本文「2cm/分程度」で表記が分かれる）は原本判読で要確定。
