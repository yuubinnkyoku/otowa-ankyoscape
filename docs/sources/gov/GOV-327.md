# [GOV-327] 東京市政概要 大正3年（1926）— 千川上水の本郷下谷給水の終焉と砲兵工廠給水の現勢〔repo初出・第139回〕

- **書誌〔確認〕**: 東京市編『東京市政概要 大正3年』（1926年刊）。NDL次世代デジタルライブラリー [book/951946](https://lab.ndl.go.jp/dl/book/951946) のOCR全文を確認。東京市の行政の全体像（水道・下水道・道路等）をまとめた**市編纂の行政資料**。**引用文言はOCR由来で要原文照合**。
- **千川上水の廃止文言〔確認・repo初出の明文化〕**: 「**又千川上水ハ近年迄本〓下谷ノ一部ニ給水セシモ明治四十年六月岩崎久彌ノ所有トナリ同時ニ之ヲ廢セリ**」＝**千川上水が近年まで「本〓（本郷候補）」・下谷の一部に給水していたが、明治40年（1907）6月に岩崎久彌の所有となり同時に廃止された**という市行政資料による廃止の明記＝[BOOK-140](../books/BOOK-140.md)（岩崎所有化）・[GOV-290](GOV-290.md)（1905年「本〓區內ニ遺殘」）の**後段の確定側の記述**で、廃止の主体（岩崎久彌の所有化）・時期（明治40年6月）を一文で結んだ行政側の整理。
- **「本〓」＝本郷区読みの強化〔確認・repo既仮説の強化〕**: 本書の「本〓下谷」は[GOV-290](GOV-290.md)（1905年「千川上水本〓區內ニ遺殘」）・[GOV-329](GOV-329.md)（1931年本郷区勢要覧・六義園の千川上水余水）と同じくOCR欠字「本〓」だが、**同一系統の沿革説（千川の給水区域＝本郷・下谷）を持つ[BOOK-173](../books/BOOK-173.md)（1907年「本〓下谷ノ一部ニ給水ス」）・[BOOK-174](../books/BOOK-174.md)（1926年「本〓、下谷ノ一部ニ給水」）・[GOV-329](GOV-329.md)（六義園＝本郷区）が「本〓」を本郷として扱う文脈と一致**するため、「本〓」＝本郷（区）の読みの蓋然性がさらに強まった（原字確認までの断定は既存方針どおり行わない）。
- **神田上水の水車業・砲兵工廠給水の現勢〔確認・repo初出の1926年断面〕**: 「**神田上水ハ新水道施設ノ結果明治三十四年六月其ノ飮用ヲ廃スト共ニ市內ノ給水ヲ絕チタルヲ以テ今ハ單ニ沿岸ノ水車業及東京砲兵工廠ニ供給スルノミナリ**」＝**神田上水が明治34年（1901）6月に飲用を廃止した後、1926年時点でも沿岸の水車業と東京砲兵工廠に供給している**という現勢記録＝[GOV-172](GOV-172.md)系の神田上水の戦前の残存利用の、**市行政資料による1926年の確認断面**（千川・神田の廃止後利用の非対称〔千川＝廃水、神田＝水車・工廠給水で存続〕という対比の明文化）。
- **下水管網の「千川線」〔確認・repo初出候補〕**: 下水道章に「**（原町ヨリ來ルモノハ丸山福山町、田町ヲ經テ富坂下ニ至リ）千川線ニ合シ更ニ南進シテ水道橋ニ至リ伏越ヲ以テ神田川ヲ横切リ神田猿樂町ヲ經テ錦町ニ至**」＝**下水管の幹線の一つに「千川線」の呼称があり、富坂下で合流・水道橋で神田川を伏越して神田猿楽町方面へ至る経路**（旧千川上水の流路に沿う下水幹線の呼称として、千川の名が下水管網に残る例。どの年の計画・実施かは章の前後で要精読）。
- **雨水吐の計画〔文言候補〕**: 下水道章に「**（汚水ハ）〓澄シテ之ヲ品川灣、隅田川及中川ニ放流スルコトトナリシ…近年降雨量著シク增加シタル事實ニ鑑ミ現設計ニ於テハ地勢ニ應シテ雨水ト汚水トヲ別種ノ管渠ニ導キテ排除スル所ノ分流法モ併用スルノ計畫トナリタリ**」・「**本計畫ニ於テハ全區ヲ通シテ到ル所管線ノ諸所ニ多數ノ雨水吐ヲ設置セリ**」＝雨水と汚水の分流併用の転換（大正期）と雨水吐の多数設置の計画文言（千川上流→滝野川堰堤上流横断→隅田川という第一雨水吐の経路の文言候補はOCRで確認できなかったため、位置の特定は保留とする）。

## 制限・未解決

- ①「本〓」の原字は原画像照合まで断定しない（本郷区読みは文脈的裏付けのみ）。②「千川線」下水管の計画年・路線の全容は章の精読待ち。③第一雨水吐の経路（千川上流→滝野川堰堤→隅田川）の文言は本書OCRでは確認できておらず、確認できた段階で追記する。
