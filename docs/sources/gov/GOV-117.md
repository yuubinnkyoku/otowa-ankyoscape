# [GOV-117] 豊島区公式「千川彫刻公園」施設案内頁〔repo初出（公式頁本文の直接確認）〕

- **書誌〔確認: 公式頁本文直接取得〕**: 豊島区公式ホームページ「**千川彫刻公園**」（公共施設案内・[URL](https://www.city.toshima.lg.jp/340/shisetsu/koen/062.html)）。
- **内容〔確認: 公式頁本文〕**:
  - **住所：千川1-24-2**。**最寄駅：東京メトロ有楽町線千川駅**。**面積：645.16平方メートル**。**開園：平成5年（1993）4月**。
  - 園内は**枯山水のある庭園風の小さなお山と子ども向き遊具の広場**で構成され、**この公園の元地主から寄贈されたものを含め4体のブロンズ像**がある。
- **位置づけ〔観察〕**: [GOV-113](GOV-113.md)②の1993年2月26日公園条例改正議案資料（千川彫刻公園を含む）の**約2か月後に開園**しており、議案→開園の時系列として整合する〔条例上の指定時期と開園年次が初めて裏付けで並んだ〕。所在地は**千川駅北西の千川1丁目**で、千川上水跡の千川親水公園（[GOV-080](GOV-080.md)・要町）とは別地点。「千川」を冠する公園（千川親水公園・千川上水公園〔[GOV-065](GOV-065.md)〕）に加わる第三の公園の所在地・整備年次が確定した。
- **彫刻の作者〔確認: 三次サイト（PARKFUL・2026-01公開記事）との併読〕**: 中野素昂「空を見上げる」・中生素昴「座像」・峯孝「春」・中野蒋「少女と仔やぎ」の4点〔[PARKFUL](https://parkful.net/2016/01/senkawa-chokoku-park/)・公式頁の4体の個別作者名は公式頁にないため二次記録として併記〕。
- **制限・未解決**: 元地主の氏名・寄贈経緯、千川上水旧流路と公園敷地の位置関係（旧千川沿いかどうか）は本文に記載がなく断定しない。公園名の「千川」が旧千川上水に由来するかも公式頁は説明しない。
