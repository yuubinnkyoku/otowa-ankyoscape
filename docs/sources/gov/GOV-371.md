# [GOV-371] 御府内場末往還其外沿革圖書 貮拾壱貞（安政3年10月調）— 上駒込〜西ヶ原〜滝野川〜王子〜堀之内〜上尾久の用水堀文言群〔第161回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の「**貮拾壱貞**」（**安政3年〔1856〕10月調**）。NDL次世代デジタルライブラリー [book/2587251](https://lab.ndl.go.jp/dl/book/2587251)。**上駒込村・西ヶ原村・滝野川村・王子村・梶原堀之内村・豊嶋村・上尾久村・船方村・下板橋宿の一円の地所書上を収める帳**〔[GAZ-012](../gazetteers/GAZ-012.md)の所在記録（第160回）を個別資料化したもの〕。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する。**
- **「御普請役用水堀」の文言〔確認・文言候補・核心〕**: 上駒込村松平左衛門尉抱屋鋪辺の地所の境界書上に「**北之方西ケ原村上駒込村之内御普請役用水堀并野道限**」＝**上駒込村と西ヶ原村の間に「御普請役」の用水堀（幕府御普請役に関係する用水堀）が安政3年時点で存在した境界文言**〔**「御普請役用水堀」の文言はrepo初出候補**。この用水堀の同定（千川上水〔旧野方堀〕の西ヶ原区間か・石神井川系の用水か・その他か）は本帳からは断定しない。西ヶ原〜上駒込の谷頭低地は千川上水の滝野川町内通過域（[BOOK-110](../books/BOOK-110.md)の字東大原/大原嵯峨の境＝旧千川上水路）に隣接する点で対照候補〕。
- **各村の「之内ニ用水堀有之」の定型文言群〔確認・文言候補〕**: ①西福寺辺（上駒込村西福寺の地所書上）「**同所之内ニ用水堀有之**」②昌林寺辺（西ヶ原村昌林寺・不動院・熊野権現社）「**同所之内に用水堀有之**」③金剛寺辺（滝野川村・王子村の金剛寺）④王子権現社地辺（尾野川村〔王子村〕）「**同所之内に石神井川筋其外用水堀等有之**」⑤梶原堀之内村・王子村「**内二用水堀等有之**」等＝**地所書上の境界文言として「之内ニ用水堀有之」の定型が安政3年の当該各村で繰り返し現れる**〔当該地域の用水（石神井川系用水・音無川・王子川筋の用水）の帳簿レベルの存在記録。各用水の同定はしない〕。
- **川名・方位語の文言群〔確認・文言候補〕**: ①「**王子村之内野道用水堀限南之方西ケ原村之内野道并滝野川村限北之方音無川端王子村**」＝**音無川端（音無川の畔）の方位起点語**。②「**西北之方者王子川ニ而南手ニ用水堀有之**」（梶原堀之内村豊嶋村）＝**王子川の南手の用水堀**。③「**東北之方戸田川端梶原堀之内村**」＝**戸田川端**。④「**同所之内ニ用水堀悪水抜堀敷等有之**」（上尾久村船方村の福性寺・白山権現社地辺）＝**「悪水抜堀」（悪水を排除する堀）の敷が帳簿に現れる記録**〔「悪水抜堀」の文言はrepo初出候補。上尾久・船方の悪水処理の実態記録〕。⑤「**下板橋宿松平加賀守下屋敷内江石神井川流レ入**」＝**松平加賀守下屋敷（現在の板橋本町の加賀屋敷跡）内に石神井川が流れ入る**という下板橋宿の地所書上〔下屋敷内の石神井川の流路記録〕。
- **位置づけ〔観察〕**: ①本帳の収録域（上駒込・西ヶ原・滝野川）は**千川上水の滝野川町内通過域に隣接**し、「御普請役用水堀」の上駒込/西ヶ原境界文言は同区間の用水史の対照資料候補（同定は保留）。②王子川・戸田川・音無川の川名と「悪水抜堀」の文言は、石神井川流域の用水・悪水システムの安政3年の帳簿レベルの観察として、[GOV-368](GOV-368.md)（駒込〜田端〜中里の用水堀文言群）と並ぶ周辺域の基礎資料〔本repoの四河川（水窪川・弦巻川・谷端川・千川上水）の直接の流路文言ではない点に注意〕。
