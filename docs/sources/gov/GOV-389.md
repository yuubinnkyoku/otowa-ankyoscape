# [GOV-389] 書上帳（天保5午〜6未）— 井之頭池水草刈御用の地割棟梁宿代銀決算〔第165回〕

- **書誌〔確認〕**: 『書上帳』（天保5午年〜天保6未年の勘定所への書上・請取の控帳。他に羽村大堰通走出等の御普請の文言も同居）。NDL次世代デジタルライブラリー [book/2587278](https://lab.ndl.go.jp/dl/book/2587278)。**引用文言はすべてOCR由来で要原文照合。**
- **天保5午年（1834）の井之頭池水草刈の決算〔確認・核心・repo初出〕**: 「**神田上水水元井之頭池水草刈取為御用差遣候地割杵梁宿代銀旅御扶持方代金請取候儀申上候書付御勘定所え御断御扣共**」＋「**但当午六月廿一日出立同七月七日罷帰候一ヶ月銀半枚之積り米壱石五斗六升代金弐両弐分銀弐匁四分三厘四毛但右同断一日壱人米九升七合五勺六升五合五割増之積日数十六日分御作事飯米三拾五石ニ付金五拾七両替之積右は神田上水水元井之頭池水草刈取為御用差遣候地割棟梁壱人宿代銀旅御扶持方代金御組合入用御取替金書面之通請取相渡申度奉存候此段申上候以上午七月**」＝**井之頭池の水草刈（水草の刈取り）の御用に差遣された地割棟梁1人分の宿代銀・旅御扶持方代金の請取書付（6月21日〜7月7日・実日数16日分・米1石5斗6升の代金2両2分ほか・日当は1日米9升7合5勺の5割増し）の勘定所書上**〔**井之頭池の水草刈が神田上水の水元管理の定常業務として幕府の勘定所経由で実施されていた**一次記録。**同種の文言が同年中に2件（6/21出立分と9月分か）見える**。地割棟梁の宿代・扶持の決算形式は[GOV-393](GOV-393.md)（文政10・水門并柵普請）・[GOV-394](GOV-394.md)（弘化2・土留普請）と同型＝**「水元の地割棟梁1人を御用で差遣する」経費形態の、水草刈（天保5・6）・水門柵修覆（文政10）・土留普請（弘化2）の3業種・4冊の書上帳横断で確認できる**＝井之頭池の管理業務の系譜の一次記録群（repo初出）〕。
- **天保6未年（1835）の同型文言〔確認〕**: 天保6未年の「**神田上水水元井之頭池…**」の書上（9月6日〜9月21日・16日分の地割棟梁宿代銀）が同冊に見える〔水草刈が複数年で反復実施された傍証。文言の全文切り出しは済んでいないので細部は次回再走査〕。
