- **2009年複製叢書への収録〔確認〕**: 近現代資料刊行会『近代都市の衛生環境. 東京編 39（清掃・廃棄物処理 1）』（2009.9・393p ; 22cm・NDL書誌 [000010603325 / R100000002-I000010603325](https://ndlsearch.ndl.go.jp/books/R100000002-I000010603325)）の収録目次に「**東京市下水道と芝浦汚水処分場 昭和9年10月（東京市）**」が複製収録されている〔書誌目次確認・複製本文は未見〕。NDL（EG213-J391）・東京都立中央図書館（498.0-5044-39）ほか蔵。
- **位置づけ〔観察・本文未見〕**: [GOV-473](GOV-473.md)（昭和4〜9年度の幹線改良統計・千川筋→芝浦文言）と同年・同月の解説パンフレット。付図「東京市下水道計画平面圖」は、[GOV-471](GOV-471.md)（1913・柳町〜富坂下千川筋道の実測図文言）以降の計画平面図系列（[GOV-172](GOV-172.md)〔1926・官報地図〕を経由）の**1934年時点の snapshots**である可能性があるが、**千川筋（小石川・本郷側）の描かれ方・処理区境界の表示は本文未見のため一切未確定**。
- **TOKYOアーカイブ蔵本の画像公開〔確認: アーカイブ詳細頁・画像リストAPI・2026-11-21第233回追記〕**: 同書の東京都立図書館蔵本（資料コード**5003127209**・請求記号**T/0・519/5127/G**）がTOKYOアーカイブ [detail?tilcod=0000000009-00006200](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00006200)で**画像の使用条件＝パブリックドメイン／全15コマ（12p本＋図2枚）の画像がインターネット公開**されていることを確認（第233回にアーカイブへの自動アクセスが確立〔手法は第233回ノート〕・zoom指定でフル解像度JPEGの取得可・第1コマの取得に成功済み）。**つまり本項の「本文未見」は原本而言の所在のみ状態から、閲覧・照合が可能な状態に格上げ**された〔文言の判読は当実行環境では不可（画像OCR不可）のため、本文12pの文言確認・図2枚の読図は次回以降の人手閲覧待ち。文言確定まで本項の内容記述は現状維持〕。
