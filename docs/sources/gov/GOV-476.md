# [GOV-476] 東京市下水道と芝浦汚水處分場（1934）— 所在のみ・複製収録確認

- **書誌〔確認〕**: 『東京市下水道と芝浦汚水處分場』（東京市・1934〔昭和9〕年10月・12p、図版2枚 ; 23cm ＋ 図2枚:「東京市下水道計画平面圖」「芝浦汚水處分場一般平面圖」・NDLサーチ [R100000001-I13111105443911](https://ndlsearch.ndl.go.jp/books/R100000001-I13111105443911)・東京都立中央図書館蔵・請求記号 0・519-5127-G・所蔵場所 B2書庫C）〔所在のみ・本文未見〕。
- **2009年複製叢書への収録〔確認〕**: 近現代資料刊行会『近代都市の衛生環境. 東京編 39（清掃・廃棄物処理 1）』（2009.9・393p ; 22cm・NDL書誌 [000010603325 / R100000002-I000010603325](https://ndlsearch.ndl.go.jp/books/R100000002-I000010603325)）の収録目次に「**東京市下水道と芝浦汚水処分場 昭和9年10月（東京市）**」が複製収録されている〔書誌目次確認・複製本文は未見〕。NDL（EG213-J391）・東京都立中央図書館（498.0-5044-39）ほか蔵。
- **位置づけ〔観察・本文未見〕**: [GOV-473](GOV-473.md)（昭和4〜9年度の幹線改良統計・千川筋→芝浦文言）と同年・同月の解説パンフレット。付図「東京市下水道計画平面圖」は、[GOV-471](GOV-471.md)（1913・柳町〜富坂下千川筋道の実測図文言）以降の計画平面図系列（[GOV-172](GOV-172.md)〔1926・官報地図〕を経由）の**1934年時点の snapshots**である可能性があるが、**千川筋（小石川・本郷側）の描かれ方・処理区境界の表示は本文未見のため一切未確定**。
- **処分区系列上の位置〔観察・本文未見〕**: [GOV-475](GOV-475.md)（1925・三分区と震害時の第一區残部未起工・三河島処分場文言）→ 本書（1934・芝浦処分場の一般向け説明）→ [GOV-477](GOV-477.md)（1949・郊外下水道計画）→ 現代の三河島処理区（第24回記録）という**千川筋処分区変遷の補助線**となりうる。断定はしない。

## 制限・未解決

- ①原本・複製とも本文は未見（所在のみ）。②「東京市下水道計画平面圖」に千川筋幹線・改良済み区間の表現があるかは複製本文確認後に確定する。③1934年10月以外の年度版の存在は未確認。
