# [GOV-460] 上練馬村現状調査 — 水田＝石神井川・田柄川・白子川沿岸の1931年定点

- **書誌〔確認〕**: 『上練馬村現状調査』（東京市臨時市域**擴張部**編・[book/1900508](https://lab.ndl.go.jp/dl/book/1900508)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**上練馬村（1932年板橋区→練馬区上練馬周辺）冊**＝**谷端川水系のさらに北隣＝石神井川上流域（田柄川・白子川源流域）の行政の定点**（対象四河川のすぐ外縁の水文系の参照点）。
- **水田＝三川沿岸の文言〔文言候補・本ファイルの核心〕**: 「**水田ハ石神井川・田柄川・白子川ノ沿岸**」＝**1931年時点で上練馬村の水田が石神井川・田柄川・白子川の沿岸に分布していた文言候補**〔**①田柄川（石神井川の南側支流（練馬区内を東流し石神井川に合流）が「灌漑としての水田の立地軸」として1931年行政調査に登載された一次文言候補（repo初出候補・repoの田柄川そのものへの言及として、[GOV-455](GOV-455.md)長崎町の千川用水灌漑との対比で、北多摩・北豊島の水田立地の軸の定点群、②石神井川の谷・白子川の谷＝谷端川・千川の谷と並ぶ武蔵野台地の谷頭系のうち最も北の系統の1931年の参画状況、③水田帯が1932年市域拡張直前まで残っていたことの定点**。正確な文・数値は要照合）〕。石神井川の「本村を東西に貫流」する文言候補も同章に見える。
- **谷戸・井戸〔文言候補〕**: 谷戸系の小地名群・井戸の記述（OCR崩壊大）＝上練馬の谷頭地形（貫井・上練馬の谷戸）の水利用の帳簿候補。
- **帳簿文言〔確認〕**: 人口・面積・財政・交通（武蔵野鉄道・村是）産業・教育・社会事業＝1932年市域拡張直前の上練馬村の帳簿。

## 制限・未解決

- ①「田柄川」の表記（田柄川/多加良川等の variant の別）はOCR崩壊のため要照合。②水田の面積・筆数の数字は読み取り不能。③上水道・下水道の章の本文（計画の有無）は本冊OCRからは判別できず次回の照合課題。④田柄川の流路・合流点の記述は本冊になし（流路特定には別資料を要する）。
