# [GOV-058] 東京都建設局第四建設事務所「千川上水」

- **直接確認（2026-11-11、open_url）**：千川上水は元禄9年（1696年）に本郷・下谷・浅草方面の飲料水および沿川への農業用水供給のため造られた約30kmの水路。**1971年（昭和46年）にその使命を終え水流が途絶え**、武蔵野市関町五丁目の玉川上水分水地点から練馬区関町一丁目の青梅街道までの5km区間を除きほとんどの区間が暗渠化された、と公式に説明。
- **清流復活〔確認〕**：昭和60年代の「清流復活事業」として開渠部の護岸工事・暗渠部の補修清掃が行われ、**平成元年3月に清流が復活**。現在は下水道局多摩川上流水再生センター処理の再生水が流れる。※[GOV-056](GOV-056.md)（ねりまの川）の「昭和63年春通水予定」と整合（予定→平成元年3月実現）。
- **管理区分〔確認〕**：当所管内15.9kmのうち開渠部2.1kmは**平成18年4月に練馬区（1.2km）・武蔵野市（0.9km）へ移管**。都は**練馬区関町南二丁目の伊勢橋下流から板橋区板橋一丁目までの暗渠区間13.8km**を補修・清掃等で維持管理。
- **三河川への使い方〔推定〕**：千川上水の通水終了年（1971）と、谷端川への長崎村分水の取水が終わる上限年代の裏付け（分水は水流途絶以前に利用中止とみられるが、本ページ単独では断定しない）。記事ID 017-001-20240710-002856。
