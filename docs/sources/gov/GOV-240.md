# [GOV-240] 駒込町方書上 [18]肆止 — 千駄木坂下町の谷戸川・合染橋の書上

- **書誌〔確認〕**: 町方書上の一本（[18] 駒込町方書上 肆止・[GOV-224](GOV-224.md)/[GOV-225](GOV-225.md)（[15]壱・[16]弐）と同シリーズ・文政10年（1827）丁亥の地誌御調書上の写し〔年判は要照合〕）。NDL次世代デジタルライブラリー [book/2571499](https://lab.ndl.go.jp/dl/book/2571499)。OCR全文精読。**引用文言はすべてOCR由来で要原文照合。**
- **千駄木坂下町の四至と谷戸川〔確認・repo初出の町特定〕**: 千駄木坂下町（千駄木町字団子坂下の町家に由来する町名・**元文2己年（1737）に寺社奉行井上河内守のもと町屋御免→延享2丑年（1745）12月に町奉行支配化**、それ以前は**湯嶋福祥院領百姓地**、町内惣家数93軒）の四至——「**東之方 谷戸川を谷中感並寺在前町法住寺境内…**」「**谷中感應寺古来町は当町之間を相流 駒込之堺ニ御座候**」＝**谷戸川が千駄木坂下町と谷中（感應寺・法住寺側）の間を流れ、当町のあたりが駒込の堺である**旨の書上〔谷戸川＝谷田川（藍染川系・石神井川水系）の千駄木〜谷中区間の流路位置の町方側の特定。**[GAZ-032](../gazetteers/GAZ-032.md)（風土記稿・御茶岡起源）と[GAZ-033](../gazetteers/GAZ-033.md)（御府内備考・御茶岡より出る堀）の流路記述の千駄木〜谷中間の通過町の裏付け**〕。
- **石橋「合染橋」〔確認・GAZ-033との対校〕**: 「**一石橋壱ヶ所 谷戸川二掛り申候 長サ弐間 巾八尺 名之義は合染橋と唱候者も有之由 尤織始メ年代等相知不申候**」＝**谷戸川に架かる石橋（長2間・巾8尺）、「合染橋」と唱える者もいるが架け始めの年代は不明**〔**[GAZ-033](../gazetteers/GAZ-033.md)（御府内備考巻32-40）の「石橋 長サ弐間幅八尺 右は谷戸川ニ掛り候 而合染橋と唱候者も有之由 尤掛始年代相知不申候」とほぼ同文**＝御府内備考の谷戸川条がこの町方書上（文政10年地誌御調）系の資料を元にしていることの対校。**「織始メ年代」（本書上）vs「掛始年代」（GAZ-033）の字形対立**（織＝掛のOCR誤読の可能性大・「合染橋」＝藍染橋（[GAZ-032](../gazetteers/GAZ-032.md)藍染川）の候補である点はGAZ-033と同じ）〕。
- **字谷戸川の渋江長伯様御預り地〔確認・GAZ-033の預り地の文言の元資料候補〕**: 「**増壱ヶ所中九尺程 字谷戸川之唱 渋江長伯様御預り 巣鴨御茶慶…出田端村新堀村下野辺村ゟ…**」＝**字「谷戸川」の土地（9尺程の増地）が渋江長伯（天文暦学者の渋江家か・要照合）の御預かり地である**旨の文言〔[GAZ-033](../gazetteers/GAZ-033.md)の制限⑥（渋江長伯預り地の背景未確認）に対し、**「字谷戸川」という小字名の実在を書上レベルで確認**。「巣鴨御茶慶」（御茶ノ岡か・OCR崩れ）と田端村・新堀村・下野辺村の並記は[GAZ-033](../gazetteers/GAZ-033.md)（御茶岡→田端→新堀→下駒込→谷中）の流路列挙と対応候補〕。
- **位置づけ〔観察〕**: [GAZ-033](../gazetteers/GAZ-033.md)（御府内備考の谷戸川条・repo既出）の**元資料側（文政10年の町方書上そのもの）を対校**できた点が主な価値。①谷戸川の流路の通過町（千駄木坂下町〜谷中感應寺境）の特定、②石橋「合染橋」の規模（長2間・巾8尺）の同文確認、③「字谷戸川」の小字の実在、という谷田川（藍染川）系統の江戸期の市中側記録を強める。谷戸川は四河川のいずれでもない隣接水系（石神井川系）であるが、谷端川北側の谷筋の対照資料として[GAZ-032](../gazetteers/GAZ-032.md)/[GAZ-033](../gazetteers/GAZ-033.md)/[GOV-133](GOV-133.md)の系譜に加わる。

## 制限・未解決

- ①「谷中感並寺」「織始メ」「巣鴨御茶慶」等のOCR崩れ語の原字形は要照合（感應寺・掛始め・御茶ノ岡と解したが断定しない）。②「合染橋」の字形（合／藍）は[GAZ-033](../gazetteers/GAZ-033.md)と同じく最優先の照合課題。③千駄木坂下町書上の当巻内の正確な頁割付・他町（駒込諸町）の書上との連続性は未確認（本精読は谷戸川関連の前後のみ）。④渋江長伯の同定（渋江春薩・長秀家か）は未実施。
