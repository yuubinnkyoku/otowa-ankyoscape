# [GOV-218] 南撰要類集[3]町奉行所之部 — 千川上水天明6閏十月差止の第三次資料と普請金流用の決着記録

- **書誌〔確認〕**: 『南撰要類集』[3]（第一下町奉行所之部・天明7〜8年〔1787-1788〕頃の記録集）。NDL次世代デジタルライブラリー [book/2550412](https://lab.ndl.go.jp/dl/book/2550412)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **「同年閏十月千川上水之儀も御差止被仰付候」〔確認・天明6閏十月差止の第三次独立資料・repo初出〕**: 養育所（田沼時代の福祉施設）手当地面の処分の文脈で——「**右三ヶ所地面売払貸附利金を以千川上水御入用之方え相遣可申哉之旨三年以前午三月田沼主殿頭え相伺候処同年五月養育所相止候ニ付右地面売払供積ニ而入札申付候得共望人無御座**同年閏十月千川上水之儀も御差止被仰付候**」〔**①養育所の廃止（天明6年5月）後、養育所手当の町屋敷売払金を千川上水の御入用に充てる案が田沼主殿頭（意次）に伺われたが、養育所廃止で売払いの目的が失われ入札しても望人がいなかったこと、②**同年（午年=天明6）閏十月に千川上水も差止が仰付けられたこと**＝**千川上水の天明6年再廃止の月が「閏十月」であることを裏付ける第三次独立資料**。従来の対立（府史「閏十月」vs 御府内上水在絶略記「十一月」〔[GOV-171](GOV-171.md)〕）について、本資料は府史側を支持する方向（「も」の字が養育所差止との並列を示し、差止の時期が同一年の閏10月であることを明記）。ただし「三年以前午三月」の「三年以前」と午年（天明6丙午）の整合はOCR上不可解で、文言の正確な対応は原文照合まで確定としない**〕〔天明6年（1786）に閏10月が実在したことは暦確認済み〕。
- **千川上水普請入用金の貸附金繰替流用と差止後の決着〔確認・千川上水再興の幕府財務の実態（repo初出）〕**: ①流用の実態——「**金弐千四百拾六両銀七匁三分五厘右千川上水普請入用之内御金波〔渡〕迄山村信濃守御役所貸附金上納之分繰替一金弐千七百五拾三両余〔弐朱〕相渡置候様**」（**千川上水の普請入用として、御金渡までの間、山村信濃守（町奉行）の役所の貸附金2,753両2朱を繰り替えて充当していた**）、②差止後の処理——「**右上水御差止二相成候故宝町三町目本町三町目瀬戸物町小船町壱町目取上屋敷御払にいたし漬〔旨〕可申段相伺候様〔処〕御払之儀は不被仰付右四ヶ所屋敷町奉行両御役所御預り二いた**」（**差止に伴い、宝町3丁目・本町3丁目・瀬戸物町・小船町1丁目の4ヶ所の屋敷を（養育所手当地面として）取上げ・払い下げる案が伺われたが、払下げは認められず4屋敷は町奉行両役所の預かりとなった**）、③地代金による皆済——「**是迄年々取立去午年迄之地代金…右金銀御金蔵え相納候様仕**」「**右流用金弐千七百五拾三両弐朱之内去未年弐千四百拾六両銀七匁三分五厘相納残り皆納一金三百三拾七両銀壱匁五厘**」（**天明7（未）に2,416両2分2朱+銀を、天明8（申）に残金337両2朱+銀を納めて皆済した**）、④残余の使途——「**向後取立候分は去ル申十一月以御書付被仰渡候通町方御救或ハ不時御入用等之永久為御手当両御番所え除置候様可仕候**」（**以後の地代金収入は、天明8申年11月の御書付の仰渡のとおり、町方御救または不時の御入用の永久の御手当として両御番所に置くことになった**）〔**千川上水の再興（安永9〜天明2の普請）の財源が、町奉行役所の貸附金（御救金・賃金貸付金等の基金か）の繰替流用で賄われていた実態、および差止後、（元々は千川上水のために繰り替えた金が）4ヶ所の町屋敷の地代金で元本化され、町方御救の基金に転化したという決着**＝**千川上水史の金銭的側面の初の実務記録**。日付の傍証＝「未五月廿一日根岸肥前守」「未三月廿六日伊豆守殿え」「申十一月十九日伊豆守殿え」「申十月小田切土佐守根岸肥前守」等の書付群（未=天明7・申=天明8）〕〔数値・人名はOCR由来で要照合。「御金波迄」は「御金御渡迄」の崩れか〕。
- **位置づけ〔観察〕**: ①千川上水の再興事業が田沼政権期の養育所（石川小エン…養育所の拡充）の政策群と資金的に連動していたこと、②差止（天明6閏10月）が田沼失脚（天明3〜4年）の**後**であることの再確認、③千川上水の失敗が単なる水路技術の問題でなく、資金繰り（貸附金流用の返済義務）と養育所廃止の波及を伴う行政過程だったこと——を示す。解釈の細部（養育所手当地面の特定＝壱町目銀5,000両・駿河町910両・宝町3,000両・本町2,000両・瀬戸物町1,350両・小船町2,500両の6ヶ所評価の文言は本書のOCRに現れる）は原文照合後に確定とする。
