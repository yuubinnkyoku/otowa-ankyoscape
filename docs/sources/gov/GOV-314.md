# [GOV-314] 東京警視本署達全書（明治11年坤・7〜12月）— 仮規則の運用細目と玉川上水際の民間取水許可

- **書誌〔確認〕**: 『**東京警視本署達全書**』（**明治十一年自七月至十二月**・坤。警視局藏版・1886年〔明治11年12月7日出板届〕）。NDL次世代デジタルライブラリー [book/791189](https://lab.ndl.go.jp/dl/book/791189)。表紙「明治十一年警視本署達全書 白七月至十二月」。**引用文言はOCR由来で原画像照合を要する**。本書と[GOV-313](GOV-313.md)（791198・同年分の布達全書）は同年の達を収める別書（収録範囲・番号体系の異同は要照合）。

## ①番外第125号（明治11年10月17日・文言候補）: 仮規則の運用細目〔確認文言・repo初出の運用面の記録〕

- 本文〔確認文言〕: 「**第三方面第四分署 神田玉川兩上水源取締假規則甲第五十七號ヲ以テ布達候ニ付テハ其署ニ於テ巡査交番ヲ定メ巡視可爲致 萬一水路中所物等ノ投棄アルヲ見認ル時ハ最寄水番人ヘ通達シ速ニ掃除方可取計 此旨相達候事 ○十月十七日第百二十五(番外)**」＝**甲第57号（仮規則〔[GOV-313](GOV-313.md)〕）の布達を受けて、第三方面第四分署において巡査交番を定めて巡視し、水路中の投棄を発見した場合は最寄の水番人に通達して速やかに掃除させる**という運用細目の達。
- **意義**: ①**施行（明治11年12月1日）に先立つ巡視体制の具体的な内容**（巡査交番の設置・「水番人」との連絡網）が確認できた。**水番人**（上水の番人）との連絡を命じた点は、[GOV-309](GOV-309.md)等の水番人関係の既存記録（石垣・水番の運用）と接続する。②「**第三方面第四分署**」が兩上水（神田上水側か）の取締を担当した署であることも分かる（分署の所轄範囲の特定は今後課題）。
- **日付の判読〔要照合・2026-11-16・第137回更新〕**: 「十月十七日」が正しいとすれば[GOV-313](GOV-313.md)の甲第57号布達日「十月二十九日」より先行し矛盾する。**第137回に[GOV-316](GOV-316.md)（東京警吏要覧・1879）・[GOV-317](GOV-317.md)（警視類聚規則坤・1879）・[GOV-315](GOV-315.md)（警視庁令類纂第5版・明治29年現行）の3系統の再録がいずれも同一内容の番外達を「（明治）十一年十月廿九日」付で収録していることを確認**＝**甲第57号布達と同日の10月29日付を支持する独立裏付け3点**。791189の「十月十七日」は「十月廿九日」の判読候補として原画像照合まで「文言候補」扱いを維持する（3点の再録が正しい可能性が強いが断定しない）。

## ②番外第173号（明治11年12月26日）: 玉川上水際の境村外5か村の飲用水汲取場〔確認文言・repo初出〕

- 本文〔確認文言〕: 「**第三方面第四分署 別紙之通東京府ヨリ通知有之候條爲心得此旨相達候事 (別紙) 十二月二十一日東京府ヨリ通知 神奈川縣下武藏國多摩郡境村外關野新田梶野新田鈴水新田是政新田小川新田ノ六ケ村リ昨十一月中爲飮用玉川上木際（＝玉川上水際・OCR）ニ於テ水汲取塲取設ケ之趣出願取調候處 情事情無餘儀次第ニ相間ヘ候ニ付 當分之內該水地敷地ニ傚ヒ小土手築立不潔無之樣蹈越支用可致旨ヲ以テ聞届候間 右ハ自然水路御取締ニモ相關候故其方面ヘ御達置相成度云々**」
- **構成**: ①武蔵国多摩郡の**境村・関野新田・梶野新田・鈴水新田・是政新田・小川新田の6か村**（現・武蔵境・府中方面）が②**飲用のため玉川上水際に水汲取場を設けたい**と前月（明治11年11月中）に出願し、③東京府が「当分の内・該水地敷地に小土手を築き立て・不潔なき様・蹈み越しの構えを用いる」ことを条件に聞き届け、④「**自然水路御取締にも相関候故**」として警視本署に達を求めた、という通知の転達。
- **意義**: **玉川上水の末端（多摩側下流末端域）での民間の飲用水取り入れの許可実例**（明治11年）で、①許可の条件に「小土手の築立」「不潔なき様」という**水質保全条件が付されている**こと、②**「自然水路御取緟」＝玉川上水の自然流路の警察取締**として警視本署の管轄事項になっていたことが確認できる。兩上水取締（神田・玉川）の「玉川」側の実際の運用実例として[GOV-312](GOV-312.md)・[GOV-313](GOV-313.md)と接続する。
- **判読上の注意〔要照合〕**: 「玉川上木際」は「玉川上水際」、「蹈越支用」は「蹈越之構」等の候補、「リ」は「ヨリ」の崩れ。文言候補として扱う。
