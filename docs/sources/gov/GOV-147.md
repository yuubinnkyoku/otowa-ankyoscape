# [GOV-147] 『東京の湧水 湧水調査報告書』シリーズのNDL書誌〔repo初出〕

- **書誌〔確認: NDLデジタルコレクション書誌・2026-11-14〜15〕**: 東京都環境保全局水質保全局（東京都環境局の前身組織）による湧水調査報告書シリーズ。**平成2年度調査報告書（[dl.ndl.go.jp pid/13417342](https://dl.ndl.go.jp/pid/13417342)）**・**平成5年度調査報告書（[pid/13417135](https://dl.ndl.go.jp/pid/13417135)）**の2点のNDLデジタルコレクション書誌を固定。いずれも**館内限定公開**（IIIF画像のインターネット提供なし）で本文は未確認〔取得可能なのは書誌レベルのみ〕。平成2年度〜平成9年度（1991〜1999年頃）のシリーズで、1998年・2000年版の存在も指摘されている（ILIS所蔵情報・未確認）。
- **GOV-124の※印湧水量の出典系列〔観察〕**: [GOV-124](GOV-124.md)（神田川流域河川整備計画・表2-4）の湧水表は「『東京の湧水』**H12年度調査報告書**・『東京の名湧水57選』H15・『湧水マップ』H25、※印の湧水量は**H3年度調査結果**」を出典に掲げる〔**H3年度（平成3年度＝1991年度）調査に対応する報告書が本シリーズ（平成2年度刊〜）の中にある**可能性が高い。音羽1丁目の湧水3件（今宮神社5.2m³/日等）・小日向の湧水の定量値の初出系列として、湧水減衰仮説（[PAP-075](../papers/PAP-075.md)参照）の時系列比較の基準点になる書誌群〕。ただし本シリーズの各年度版がどの年度の調査値を掲載するか（H3年度調査＝平成2年度版か平成4年度版か）は**本文未見のため特定できていない**。
- **意義〔観察〕**: 音羽谷（水窪川流域）・小日向谷の湧水量の数値が1990年代前半に都の環境部局によって調査・公刊されていたことの**書誌の所在固定**。館内限定のため次の一手はNDL館内での閲覧または東京都環境局への照会。
