# [GOV-236] 諸証文留帳 — 白堀通の見守喜兵衛・武兵衛の御請書

- **書誌〔確認〕**: 『諸証文留帳』（弘化2年〜安政元年〔1845-54〕・**旧幕引継書**＝明治政府への引継資料と読める由来書き付き）[book/2532712](https://lab.ndl.go.jp/dl/book/2532712)。OCR全文精読。**引用文言はすべてOCR由来で要原文照合。**
- **見守の御請書〔確認・repo初出の文言群〕**: 見守**喜兵衛・武兵衛**の御請書——「**古来より神田御上水白堀通渡る橋并箱下水見守相勤**」〔**①白堀通の「渡る橋」と「箱下水」の見守が「古来より」世襲的に勤められてきたこと、②「箱下水」＝箱樋の下水（神田上水の箱樋区間の呼称候補・[GAZ-049](../gazetteers/GAZ-049.md)⑦の「箱下水」文言と対校）の見守対象であること**〕。経緯として**天保14年（1843）に取払い→弘化3年（1846）に再拝借**（5ヶ年季・**地代金3両宛を七月と十二月の両度に割合前上納**）の文言。
- **巡視路の文言〔確認・repo初出〕**: 見守の巡視路——「**目白下大洗堰中堤東之方柵矢来際ゟ牛天神下水戸様御屋敷境迄御上水土手通繁々見廻り、同所金杉橋芥留**」＝**大洗堰の中堤（目白下）から牛天神下の水戸殿屋敷境まで、上水の土手通を頻繁に見廻り、金杉橋に芥留（ゴミ除け栅）を設ける**という業務範囲の記録〔**①見守の担当区間が大洗堰（関口の取水堰・[GAZ-048](../gazetteers/GAZ-048.md)関口の瀧・摺鉢の瀧）から水戸殿屋敷（小石川牛天神下）までの白堀全区間であること、②「中堤」の位置が「大洗堰」に付属するものであること（[GAZ-049](../gazetteers/GAZ-049.md)⑬の中堤3ヶ所・[GOV-234](GOV-234.md)検使例書の「関口中堤入口」と対校）、③金杉橋（白堀通の橋・[GOV-238](GOV-238.md)の定請負橋数書付にも見える）の存在と芥留の設置**〕。
- **地代金3両の年2回上納〔確認・GAZ-049との一致〕**: 冥加金/地代金3両を**七月・十二月の2回に分けて前納**する方式は、[GAZ-049](../gazetteers/GAZ-049.md)⑬⑦（番人喜兵衞・冥加金3両・年2回上納・見守番屋16坪2合5勺）と**完全に一致**＝GAZ-049の見守番屋の記述の解釈を旧幕引継書の証文で裏付ける。弘化3年（1846）の再拝借は[GOV-232](GOV-232.md)の白堀通大規模普請・[GOV-235](GOV-235.md)の見守番屋取調と同年。
- **位置づけ〔観察〕**: 白堀通の見守制度について、①業務内容（橋と箱下水の見守・土手通の巡視・金杉橋の芥留）、②負担区間（大洗堰〜水戸殿屋敷境）、③料金（地代金3両・年2回前納）、④沿革（天保14年取払→弘化3年再拝借）を**証文（当事者の御請書）レベルで初めて記録した資料**。[GAZ-049](../gazetteers/GAZ-049.md)（町方側の書上）と[GOV-235](GOV-235.md)（町奉行側の取調）の3点セットで白堀通の見守制度が確定できる。

## 制限・未解決

- ①「箱下水」の語の正確な表記（箱下水／函下水）と意味（箱樋の下水か）は要照合。②喜兵衛・武兵衛の同定（[GOV-235](GOV-235.md)の本郷元町平次郎店喜兵衛・関口水道町伝左衛門店武兵衛と同一人物か）は店先形式の一致で推定されるが原本文照合までは断定しない。③天保14年取払の理由（上水機能の縮小か・別件か）は本資料からは不明。④巡視路の「柵矢来際」「芥留」の表記はOCR由来で要照合。
