# [GOV-181] 都市計画東京地方委員会 議事速記録 第9号（1935年11月〜1936年）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第9号』・NDL次世代デジタルライブラリー [book/1207640](https://lab.ndl.go.jp/dl/book/1207640)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **議第160号「東京都市計画事業受益者負担金徴収計画決定ノ件」関係（三河川）〔確認・本文側補完〕**: 特別委員会の付託（昭和10年12月20日）から報告（昭和11年1月16日・同月20日の会議）を経て原案適当とされた経緯と、**東京府令第12号（受益者負担金徴収計画の公告・関係図面の縦覧）の条文**（第一条＝公告の方式・第三条＝「前条ノ規定ニ依リ公告シタル受益者負担金徴収計画及其實施ヲ伴フ図面ハ府庁及東京市役所ニ之ヲ備ヘ置クヘキモノトス」）が収録される。〔[GOV-102](GOV-102.md)（1936年1月25日付内務省告示第24号＝府県告示の目次側記録）に対して、**その前後で府令・委員会審議がどのように動いたかの本文側の補完資料**。受益者負担金制度そのもの＝東京府令第59号（1933年4月）の件は[GOV-104](GOV-104.md)参照〕〔文言はOCR要照合〕。

## 制限・未解決

- ①本号の受益者負担は**立会川・神田上水・谷端川の3河川で共通の制度枠**での運用だが、河川ごとの負担金額・負担区割の数値は本号OCRでは確認できていない（[GOV-184](GOV-184.md)の神田上水第一負担区のような個別区の告示は後続資料）。②第9号の正確な収録会議名・議第160号の正式題名・府令12号の公布年月日はOCRの頁割れがあり要照合。③受益者負担の**旧河川境界線から6間以内の土地への5%加算**規定は後の[GOV-183](GOV-183.md)（報告第12回・施行細則）に現れるもので、本号には未確認。
