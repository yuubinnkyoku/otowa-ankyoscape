# [GOV-231] 天保撰要類集 [308] — 室大下水の「万年樋」の修繕入用の用例

- **書誌〔確認〕**: 『**天保撰要類集**』[308]（第百九下・御入用之部）。NDL次世代デジタルライブラリー [book/2589136](https://lab.ndl.go.jp/dl/book/2589136)。天保期の町方の御入用（普請・修繕費）関係の帳簿類。**引用はOCR由来で文言は要原文照合。**
- **室大下水の「万年樋」の修繕入用〔確認・万年樋の語の汎用性の傍証〕**: 新材木町（新材木所）の上納地・地代の町入用の勘定書に——「**河岸冥加普請入用 室大下水万年樋辻損共 〆銀七拾五匁四分八厘五毛**」「**河岸冥加 大下水万年樋枡共入用 〆銀百四拾匁六分四厘八毛**」〔**①「室大下水」の「万年樋」の辻損（つじそこな・破損か・原字形要照合）の修繕と枡の入用が銀70-140匁規模で計上されていたこと、②「万年樋」が大下水側の樋の名称として帳簿で使われた用例**〕〔**[GAZ-035](../gazetteers/GAZ-035.md)の桜木町の埋樋2ヶ所「万年樋」が固有名として読める文脈に対し、①本件の「室大下水万年樋」（室大下水は小石川側の下水〕、②[GOV-226](GOV-226.md)の明治期水道行政書の「市内ノ配水ハ萬年樋及木極ヲ用ヒ」＝**「万年樋」は恒久的な通水樋を指す普通名詞（「お止まり樋」「失敗しない樋」の意か）としても使われた語**であることを示す。桜木町の「万年樋」が固有名か普通名詞的呼称かは、この2用例と合わせて判断資料とする（断定しない）**〕〔室大下水の位置・区間の特定は本資料の範囲外〕。
