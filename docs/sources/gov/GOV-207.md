# [GOV-207] 東京市水道事業年報（1938年）— 高田町・西巣鴨町下水道の排水区の数値

- **書誌〔確認〕**: 東京市『水道事業年報』（**昭和13年度・1938年**）。下水道章に「東京都市計畫**高田町下水道**」「同**雑司ヶ谷町**下水道（延長約1,070米）」「同**西巣鴨町**下水道」等を掲載。NDL次世代デジタルライブラリー [book/1073692](https://lab.ndl.go.jp/dl/book/1073692)。**すべての引用は同館OCRテキスト由来であり、表の列崩れがあるため数値・文言は原文画像との照合を要する。**
- **高田町下水道の4排水区〔確認・repo初出の重要文言〕**: 「地勢ニ依リ下水排除區域ヲ**音羽排水區、鶴卷川排水區、神田上水路排水區及谷端川排水區ノ4區ニ分劃ス**」。下水道延長約8,280米、合流法、隣接市町ノ一部ノ面積約39.00「ヘクタール」の流入を含む、排除方法は「**其ノ大部ハ…流シ一部ハ神田上水路及惡水路ニ排出ス**」。各区の区域は**鶴卷川排水區＝大字高田老松及小石川ノ各全部竝大字高田千登世・高田若葉・雑司ヶ谷旭出ノ各一部**、**音羽排水區＝大字雑司ヶ谷旭出ノ一部**ほか〔各区の面積・延長の行対応はOCR列崩れのため要照合〕＝**[GOV-166](GOV-166.md)（1937年下水道事業年報・高田町＝鶴巻川・神田上水路の2区扱いの記述）と[GOV-167](GOV-167.md)（1930高田町政概要・音羽・鶴巻川・旧神田上水・谷端川の流域区分）の食い違いに対し、1938年の年報が4排水区を明記する一次文言**＝**高田町計画の全容は4区であり、1937年報の記述は部分抜粋だった可能性が高いことを示す**〔1937年報の記述の性格（抜粋か計画変更か）の断定は原文照合まで保留〕。
- **西巣鴨町下水道の4排水区〔確認・要照合〕**: 「地勢ニ依リ下水排除區域ヲ**石神井川排水區、谷端川排水區、音羽排水區及谷田川排水區ノ4區ニ分割ス**」「**其ノ大部ハ谷端川及惡水路ニ排出シー部ハ東京市、巣鴨町及高田町下水道ニ合流ス**」。各区＝**谷端川排水區：區域大字巣鴨ノ大部竝大字池袋及堀之内ノ各一部 面積約138「ヘクタール」 下水道延長約30,770米／音羽排水區：區域大字巣鴨・池袋及堀之内ノ各一部 面積約100「ヘクタール」 下水道延長約19,970米／谷田川排水區：區域大字巣鴨ノ一部 面積約17「ヘクタール」 下水道延長約4,460米／石神井川排水區：面積約200「ヘクタール」 下水道延長約43,070米**〔OCR列崩れあり・行対応は要照合〕＝**rzeka「マンホール(170)」（2012年）が1932年『西巣鴨町誌』由来として二次転記した4排水区の面積・延長群（石神井川455ha／43,070m・谷端川138ha／37,070m・音羽100ha／19,970m・谷田川17ha／4,460m）と近似する一次資料側の文言**。**同転記の内部矛盾（面積合計710haが町面積約3.8km²を超える疑い）の解消は、この年報の原表（総面積455ha欄と石神井川区面積の行対応）の照合が有力手段**〔今回のOCRでは「總面積約455「ヘクタール」ノ區域」と石神井川区面積約200haの両方が読めるため、455haは西巣鴨町の総区域面積である可能性が高い。確定は原表照合まで保留〕。
- **位置づけ〔観察〕**: [GOV-200](GOV-200.md)（1932滝野川町下水道告示・4排水区＝谷端川・石神井川・谷田川・**田端**で音羽を含まない）と[GOV-166](GOV-166.md)（1937年報・滝野川町＝石神井川・谷端川・**音羽**・谷田川の4区）の**「音羽区」の有無の照合課題に対し、西巣鴨町（1938年報でも音羽排水区100haが存在）と滝野川町（1932告示は田端区）の町別差として整理する一次データを提供**。「音羽排水区」の水系帰属（旧水窪川・弦巻川下流域の排水区か）は従来どおり断定しない。
