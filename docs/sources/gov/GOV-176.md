# [GOV-176] 諸向掛合 — 千川上水樋枡伏渡と湯島・本郷の明地利用の連関

- **書誌〔確認〕**: 『諸向掛合』（町奉行所の諸役所掛合集）。NDL次世代デジタルライブラリー [book/2548672](https://lab.ndl.go.jp/dl/book/2548672)。OCRテキストで千川上水関係3条を確認。**文言はOCR由来で要照合。**
- **天明度樋枡伏渡の「助成」としての高床・床店免許〔確認・repo初出〕**: 「**既 天明度御先役方（町奉行）御取扱二而 千川上水樋枡伏渡ニ相成候砌 為助成 右明地且高床 御差免ニ相成候場所**」「**天明度千川上水請負人 為助成 同場所江床店御免被仰付 店主差障難渋仕候処 無間も右上水御差止二付 床店も取払二相成**」＝**天明度の千川上水樋枡伏渡工事に対する「助成」として湯島・本郷の明地に高床・床店の免許が出され、上水差止後取り払われた**旨の記録。さらに「**天明之度町奉行取扱二而千川上水樋郡伏渡候為助成 同六午年明地三方折廻し高床御取免二相成 其後千川上水御差止ニ相成候ニ付高床も取払候処 寛政十午年明地内面之方二而湯島壱丁目三丁目其外町屋代地二相成 文政十亥年同所北之方にて本郷五丁目六丁目町町屋代地に相成 当時下仕弐千百四拾弐坪余**」。
- **位置づけ〔観察〕**: [GOV-169](GOV-169.md)（天明3年11月素堀幷樋枡懸渡御普請）の工事が**町奉行取扱の「樋枡伏渡」**であり、その財政的助成として湯島・本郷の明地利用権（高床・床店）が請負人側に与えられたこと、差止（天明6年）で取払後、**寛政10年（1798）湯島1〜3丁目・文政10年（1827）本郷5〜6丁目の町屋代地化**に転換したことを、町奉行側の事務記録で示す。千川上水の市中樋管と湯島・本郷の明地（火除地）の土地利用史を結ぶ文書で、[GAZ-024](../gazetteers/GAZ-024.md)・[GAZ-025](../gazetteers/GAZ-025.md)の埋樋記録と対で読める。

## 制限・未解決

- ①対象明地の具体地番・高床の位置は本件では特定されていない（下仕2,142坪余は文政10年時点）。②「為助成」の制度的意味（上水工事の請負人への補償か）は本件文言からの推定は留保。③年号の読み（寛政十午年・文政十亥年）はOCR由来で要照合。
