# [GOV-278] 玉川上水留 安政3年 — 赤坂柳堤通の仮樋枡修復と赤坂の下水網の干渉

- **書誌〔確認〕**: 『玉川上水留』「玉川上水赤坂柳堤通仮樋枡御修復一件　安政三辰年三月より同年八月迄」（全1冊）[book/2587393](https://lab.ndl.go.jp/dl/book/2587393)。repo未登録（「薩摩小路」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔[GOV-272](GOV-272.md)天保4-5年普請・[GOV-275](GOV-275.md)弘化3年浅水取繕の柳堤通樋筋の、安政3年の修復。同じ年の[GOV-277](GOV-277.md)四谷御門外南之方修復とも連動〕
- **仮樋・息抜樋の仕様〔確認・repo初出の語〕**: 「**仮柳(樋?)大方(樋枡?)内法五尺五寸四方(深?)六尺 壱ヶ所 注文之外新規仕度候に付 松板拾弐枚 長六尺三寸幅壱尺厚三寸…**」＋「**息抜柳(樋?)内法三尺五寸四方(深?)三尺 壱ヶ所 注文之外左樋板二而仕付候ニ付 古貝折釘鉄目…**」＝**柳堤通の仮樋（本樋の修復中の迂回樋か・常設の仮樋かは要照合）内法5尺5寸四方・息抜樋（通気・減圧の樋か）内法3尺5寸四方が注文之外に新規に設けられた**（「仮樋」「息抜樋」の語義・「四方」の後の深さ寸法のOCR崩れは要照合。息抜樋＝[GOV-272](GOV-272.md)の帯附敷替等と並ぶ樋管の付属設備の語彙）。
- **溜池端通大下水・榎坂上埋下水の干渉〔確認・[GOV-274](GOV-274.md)嘉永2年の文言の反復〕**: 「**赤坂溜池端通大下水水上下水柵御修復有之候に付 水下も通後方被仰渡候処 榎坂上埋下水石垣孕押れ水行不宜 自然水上御普請所并溜池端明地え悪水溢出**」＝**赤坂溜池端通の「大下水」の水柵の修復に際し、榎坂上の「埋下水」の石垣の孕み押し出しで水行きが悪く、悪水（下水）が水上の御普請所と溜池端の明地に溢出した**＝[GOV-274](GOV-274.md)嘉永2年（1849）とほぼ同じ文言が安政3年（1856）にも反復＝**溜池端の大下水と榎坂上の埋下水（蓋をした暗渠下水）の不良状態が嘉永から安政にかけて継続していた（あるいは恒常的な問題として認識されていた）記録**＝赤坂・溜池周辺の下水網（大下水・埋下水）の実在と水理の実態の、時点を異にする2回の観察記録。
- **水留の宛名〔確認・周辺〕**: 水留の定型廻状「**明後三日一日限…水留…両御役宅幷御組屋敷江相掛不申候…水下も町々年番名主共えも…**」＋赤坂御屋敷（紀伊殿御城附?）・芝御屋敷への水留通知＝**水留の際、上水の樋筋に掛かる武家の御屋敷（赤坂・芝）に加え、水下の町々の年番名主にも触れる運用**＝上水の停止が給水先の武家屋敷・町屋の双方に影響する管理体制（人名・屋敷名のOCR崩れは要照合）。
- **組合年番〔確認・周辺〕**: 「**薩摩小路組合年番 鍋嶋加賀守殿 朽木近江守殿**」（正月〜七月の反復）＋「**築地鉄炮洲組合 久松五十之助殿 大道寺権次郎殿**」「**同所河岸通組合 松平遠江守殿 松平玄蕃頭殿**」＝**安政3年の薩摩小路組合年番は[GOV-277](GOV-277.md)四谷御門外南之方修復と同じ鍋嶋加賀守・朽木近江守**（同年の2件の修復の経理が同じ組合年番の下に行われた＝薩摩小路組合が柳堤通と四谷外堀端の双方の樋筋の維持に関与）＋築地・鉄炮洲・河岸通の組合の年番（玉川上水の給水が築地・湊方面にまで及ぶ組合の存在）。
