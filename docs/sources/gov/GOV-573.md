# [GOV-573] 雑司ヶ谷・字水窪新田の官民有地交換（1918）

- **調査方法〔確認〕**: 都公文書館クロス検索「水窪」40件のうち、水窪川（雑司ヶ谷〜音羽側）の流域に関係する唯一の記録として詳細頁を確認した（2026-11-24の継続調査）。残るヒットは大森区清水窪尋常小学校（荏原郡馬込町清水窪＝現・大田区）の増築・補助金群、南多摩郡八王子町萬町字水窪の廃道敷、荏原郡碑衾町大字衾字東水窪（現・世田谷区側）の国有地籍群等で**水窪川とは無関係**（大きな陰性。「水窪川」表記は引き続き0件）。なお [1080476](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=1080476) と [1080477](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=1080477) は**同一件名・同一請求番号・同一綴込番号の二重登録**〔目録上の重複の観察のみ記録〕。
- **記録の内容〔確認・repo初出の水窪新田の地番級一次記録〕**: 公開件名「**官民有地交換【図面４】〔北豊島郡高田村大字雑司ヶ谷字水窪新田１４８－１　４４５－３〕《安井惣太郎》**」・文書年度＝大正7年・起案＝**大正7年（1918）2月18日**・文書記号＝巳土甲・綴込9・収録先＝**官有地 冊の2（請求番号３０２．Ｂ５．１５）**・収録先簿冊資料ID 000126514・16mmMF**コマ0006-0566**・pkey [1080476](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=1080476)。＝**安井惣太郎名義の民地（字水窪新田148-1・445-3）と官有地との交換**の東京府の地籍実務記録で、**図面4枚**を伴う。
- **位置づけ〔観察・BOOK-116への一次補強〕**: 字水窪新田の実在と地番は [BOOK-116](../books/BOOK-116.md)（1922年『土地概評価 北豊島郡高田町』・OCR由来）の「字 水窪新田 一一二〜一八八番地」「字 水窪一八九〜二六〇番地」で既出だが、本件はその**4年前（1918）・府の地籍実務文書レベルの独立の裏付け**。**148-1は同書の水窪新田112〜188番地の範囲に相当**し、**445-3は同書のOCR記録に現れない番地**（改番・OCR欠落・水窪新田以外の字の混在のいずれによるかは未確認）。図面4枚は16mmMF（コマ0006-0566）で閲覧可能なため、水窪新田の筆の配置＝水窪川水源部（雑司ヶ谷の谷頭）の位置特定の対照材料候補〔図面内容は未見のため、水路・地形の描出の有無は判断しない〕。安井惣太郎の人物像・官地側の交換物件（位置・用途）は本文未見。
- **制限・未解決**: ①本文・図面4枚とも未見（16mmMFコマ0006-0566の館内閲覧・複写要否は要確認）。②445-3の位置・148-1との隣接関係は図面判読まで保留。③水窪川の旧河道・湧水地点との位置関係は本件目録からは特定できない。
