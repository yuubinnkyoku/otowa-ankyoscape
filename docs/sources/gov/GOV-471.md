# [GOV-471] 下水道沿革誌 初版（1913）— 元祿九年千川上水成るの評言と千川筋の実測図リスト

- **書誌〔確認〕**: 東京市下水改良事務所編『下水道沿革誌』初版（1913・NDL次世代デジタルライブラリー [book/950604](https://lab.ndl.go.jp/dl/book/950604)）。[GOV-164](GOV-164.md)（1914増補版・950605）の**初版**で、増補版に収録されない初版独自の文言（実測図リスト・千川線設計）を本登録の対象とする。**引用文言はすべてOCR由来で要原文照合**。
- **「元錄九年千川上水成ル」の沿革評言〔文言候補〕**: 藩政時代の重要事蹟の列挙の中に「**元錄九年千川上水成ル 元錄十年仙臺堀油堀ヲ疏鑿ス**」＝**元禄9年（1696）に千川上水が成ったことを沿革の基軸のひとつとして並記する評言**。〔**元禄9年創設説（風土記稿・由緒書系）を、1913年の下水道行政の沿革誌が「藩政時代の重要事蹟」として再確認した文言**。同書の前段に「元巣鴨村より出づる野水谷端川の末なりしも後千川上水の剰水を容れ…」系の谷端川認識（GOV-164既出）が続く構成**〕。
- **実測図リスト（千川・谷中・音羽系）〔文言候補・本登録の核心〕**: 測図・参考図のリストに——「**陸軍砲兵工廠内千川筋實測圖**」「**小石川區音羽町在來大下水實測圖**」「**小石川區柳町跡見女學校角ヨリ富坂下ニ至ル千川筋道平面圖**」「**下谷區谷中初音町ヨリ不忍池畔ニ至ル水路**」「**青山埋葬地附近水路平面圖**」等＝**①砲兵工廠（小石川区本村町側の陸軍施設）内の千川筋の実測、②音羽町の在来大下水、③柳町（跡見女学校角）〜富坂下の千川筋道、④谷中初音町〜不忍池畔の水路の実測・平面図の一群が1913年段階で存在（附図リスト上）していた記録**。〔**千川筋の市中残存区間（本村町→柳町→富坂→音羽・谷中初音町→不忍池系）が下水改良事業の測量対象になっていた実務の記録＝千川上水廃止後の残存水路の地理的範囲（藍染川・谷戸川系の下流側を含む）を確認するための図面の所在記録**。図面上の流路の実確認は別途原図照合が必要**〕。
- **千川線の設計文言〔文言候補・下水幹線史の新情報〕**: 「**砲兵工廠內ヲ隧道ヲ以テ富坂ニ出千川線ニ合スルモノトス 千川ハ郡部ニ廣大ナル流域ヲ有スルヲ以テ完全ニ之カ排水ヲ計ランニハ下流ニ於テ頗ル大ナル排水路ヲ作ラサル可カラス…板橋停車塲附近ヨリ瀧ノ川ニ至ル雨水吐ヲ新設シテ…**」＝**①砲兵工廠内を隧道として富坂へ出て千川線に合流させる路線、②千川（線）は郡部に広大な流域を有するため完全な排水には下流に大きな排水路が必要で、③板橋停車場附近から滝野川へ雨水吐を新設する構想**。〔**千川幹線（千川線）の集合下水路としての設計思想（1913）＝砲兵工廠隧道経由の路線と、板橋→滝野川の雨水吐（千川流域の水を神田川合流を経ず石神井川側へ放流する構想）の構想文言。現行の千川幹線のルートとの異同は原図照合課題**〕。
