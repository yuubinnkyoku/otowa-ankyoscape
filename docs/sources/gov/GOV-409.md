# [GOV-409] 東京府史蹟（1919）— 庚申橋=獄門橋の1919年明記と大洗堰改築進行の同時代記録

- **書誌〔確認・一部要照合〕**: 東京府編『東京府史蹟』、洪洋社、**1919年（大正8）**〔NDL書誌の publisher＝洪洋社。出版年の最終確認は原書誌照合〕。NDL次世代デジタルライブラリー [book/1181687](https://lab.ndl.go.jp/dl/book/1181687)。史蹟名勝天然記念物の府レベル調査報告（「東京府史蹟圖附錄 史的紀念物 天然紀念物 勝地保存心得及同調査票記入心得」等を附す。巻頭図版一覧に「切支丹屋敷趾」「井之頭池及舊關口洗堰」「玉川上水路(小金井)」等の写真を列挙）。**引用はOCR由来で文言は原画像との照合を要する。**
- **切支丹屋敷址条＝「庚申橋（古の獄門橋）を渡り」〔文言候補・repoの橋名調査への1919年府編witness〕**: 「**切支丹屋敷址は小石川區竹早町左邊の切支丹坂を下り、庚申橋(古の獄門橋)を渡り切支丹屋敷址**」＝**小石川区竹早町の切支丹坂を下り、「庚申橋（古の獄門橋）」を渡って切支丹屋敷址に至るという位置案内で、庚申橋＝獄門橋の同一橋説（古名の獄門橋が庚申橋の呼称に置き換わった、または併称された）を1919年の府編の調査書が明記**＝橋名調査の「庚申橋」項（小石川・切支丹屋敷前の神田川/江戸川支流の橋〔ネコマタ橋系の谷端川の橋か〕）の系譜（江戸期の獄門橋記録・庚申橋の諸用例）に対する明治末〜大正初頭の府レベルの認識の datapoint（どの橋（水系）を指すかは本条本文のみでは確定せず、切支丹屋敷（小石川区竹早町・現在の文京区の切支丹坂下）の前の橋（谷端川下流・神田川・白山御殿町方面の流路の橋）として原図版写真（巻頭図版の「切支丹屋敷趾」）との照合が次の課題。
- **井之頭池・旧関口洗堰条＝多水源説と天明6年造営の131年前表現〔文言候補・算術対立の記録〕**: 「**井之頭池は北多摩郡武藏野(?)三鷹二村の間にあり 其の面積一萬四千坪 地下水の湧出瀦溜して池となれるものにして…池の水は善福寺池と妙正寺池との流末を合せ、神田上水の源水となり 流下約五里 德川時代には市內に給水する必要上、水道の水位を高むる爲、天正年間小石川區關口に此の洗堰を設けたり 此の洗堰は今より百三十一年前天明六年に造られたるものなるが、明治四十三年來洗堰の水上屢〓洪水の災を蒙むれるにより、東京市は新に門扉によりて水位を調節し得る構造に改築しつゝあり**」＝**①井の頭池の面積（1万4千坪）・地下水湧出の成因、②善福寺池+妙正寺池の流末を合わせ神田上水の源水とする多水源説（[GOV-377](GOV-377.md)東京水道改設之概略の多水源合流説・[BOOK-209](../books/BOOK-209.md)江戸川条の複数水源記述と同じ系統）の1919年再述、③洗堰設置を「天正年間」とし、**④洗堰（現存石垣）を「今より百三十一年前＝天明6年（1786）に造られたるもの」とする年代文言、⑤明治43年（1910）以来の洗堰水上の度重なる洪水災害と、1919年時点で東京市が「門扉により水位を調節し得る構造」へ改築しつつある（進行形）**＝**天明6年石垣（[GOV-375](GOV-375.md)の天明6年説）の「造営」言及と大洗堰近代改築工事の進行の一次記録候補**〔**「今より百三十一年前」（1919−131＝1788＝天明8年）と「天明6年」（1786）の2年の算術上のずれが本文内に並存する（誤算か、天明8年説の混入かは断定せず・そのまま記録する）**。天正年間の洗堰設置説（新設の堰か改修か）も原画像照合前提。〕
