# [GOV-446] 豊多摩郡戸塚町現状調査 — 神田上水呼称による地勢規定と四村名主の帳簿

- **書誌〔確認〕**: 『豊多摩郡戸塚町現状調査』（東京市臨時市域**擴張部**編・NDL次世代デジタルライブラリー [book/1900473](https://lab.ndl.go.jp/dl/book/1900473)・縦割OCRで崩壊大）。**引用文言はすべてOCR由来で要原文照合**。[GOV-442](GOV-442.md)（落合町）・[GOV-331](GOV-331.md)（大泉村）と同一の現状調査シリーズで、**戸塚町（1932年淀橋区→1947年新宿区・高田馬場・西早稲田方面）冊**。第217回でGOV-442の陰性記録に触れたシリーズ棚卸し（第218回）の1冊。
- **地勢章の神田上水呼称による町域規定〔文言候補〕**: 「**戸塚町ハ牛込名ノ未端、神田上水ニ幅ム位置ニ在リテ東西二十三町南北八町ニ亘ル〓長ノ地〓ヲナス。東南部一帶ハ牛込名及戸山ケ原ノ立阜二連リテ高地ヲナセドモ西北部ニ至ルニ従ヒ地形次苐二低下シ神田上水沿岸ハ一般ニ卑湿ナル低地ヲナス**」＝**1931年の行政調査レベルで町の位置と地勢を「神田上水」の呼称で規定した文言**（「幅ム」は「挟マレ」等のOCR崩れ候補・要原文照合）。①「神田上水ニ挟マレ（?）た位置」＝戸塚町の町域を神田上水（＝神田川本流の呼称）に対して位置づける表現、②「神田上水沿岸ハ一般ニ卑湿ナル低地」＝**神田上水の沿岸（＝現在の神田川の高田馬場〜戸塚区間）の低湿地性を1931年時点の行政側の地勢記述として明記**〔[GOV-447](GOV-447.md)（淀橋町・神田上水ノ流域ハ一帶ノ低地）と同じシリーズ内の並行文言で、昭和初期の行政地形認識としてrepo初出級〕。
- **沿革章の「富塚村トモ書セリ」と四村名主〔文言候補・本ファイルの核心〕**: 「**戸塚ノ名称ハ古ク近村ノ総名ニシテ富塚村トモ書セリ。維新以前町内各大字ハ各々独立ノ村ヲナ三、下戶塚村戸塚村源兵衛村諏訪村ニハ各名主アリテ村勢ヲ取扱ヒ維新ノ際ニ及ベリ**」＝**①戸塚＝古くからの近村の総名で「富塚村」とも書いた（富塚表記の行政文書レベルの用例候補・「富塚村トモ書セリ」という言及自体が表記史の一次記録として価値を持つ）＝地名対照表の戸塚／富塚系の資料。②維新前に下戸塚村・戸塚村・源兵衛村・諏訪村の4村が各々独立の村で各名主を置いていた（＝現在の大字に相当する4村）＝**大字源兵衛・大字諏訪（[BOOK-149](../books/BOOK-149.md)戸塚町誌・[BOOK-190](../books/BOOK-190.md)土地概評価）の独立性の1931年行政側の追認文言**（維新の際まで4村制度が実在した記述）**。名主の実在を村勢単位で明記した文言として、源兵衛村の実在の系統に新たな系列（行政調査の沿革）を追加**。③明治2年2月「**呂川縣ノ置カルルニ及ビ本町ノ大部分八之レニ属ニタルモ後二牛込区ニ入リタル**」＋明治4年11月「呂川〓（縣）ノ廃止ト同時ニ本町ノ全區域ハ東京府ニ属」＝**戸塚町域が明治2〜4年に「呂川縣」（品川縣のOCR崩れ候補・東多摩郡域の品川県＝小菅県分轄の呼称問題は要照合）に属した後東京府に属した沿革の記述**〔当時の郡域所属の判定資料〕。
- **下水道の1931年未整備の文言〔陰性記録〕**: 「**(一)下水道事業ノ計画 本町ニ於テハ下水道事業ノ計画セラレタルモノアルモ未ダ何等具体化スル迄ニ至ラザル状態二アリ**」＝**1931年時点で戸塚町（高田馬場・西早稲田）に下水道の計画はあったが具体化していなかったことの行政側の明記**〔同文で給水側の文言「仝六年二月十三日專用栓給水ヲ開始ス」「昭和六年六月末現在…專用栓…給水鉄管二九三八六米」等の水道整備の文言と対照的に、下水道側だけが未具体化であった記録。千川・神田川系流域の下水道史の昭和初期座標として、[GOV-442](GOV-442.md)（落合町・施設ナシ）と並ぶ時系列的な定点〕。
- **帳簿文言〔確認〕**: 面積「**五四一、一七三坪 東京市ノ最小区タル四谷区ノ約六割**」＝戸塚町の面積と東京市区との比較等の統計群（数字はOCR崩れ・要照合）＝1932年市域拡張直前の戸塚町政の帳簿。

## 制限・未解決

- ①「神田上水ニ幅ム」の原字形（挟マレ等の推定の是非）・「牛込名ノ未端」の読みはOCR崩れのため要原文照合。②「富塚村トモ書セリ」の出典（どの文書の表記か）は本冊の沿革では明記されず、富塚表記の初出史料の特定は今後課題。③四村名主の時期・人名は本冊レベルでは未特定（[BOOK-149](../books/BOOK-149.md)戸塚町誌の名主系と対照が今後課題）。④「呂川縣」の原字形（品川縣か）は要原文照合、所属経緯の制度的解釈は本repoの範囲外（原文確認を前提とする）。⑤下水道の計画（いつ・どの区間）は本冊では言及なし（東京市合併後の敷設史は他資料）。
