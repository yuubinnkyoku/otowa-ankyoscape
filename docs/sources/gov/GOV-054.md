# [GOV-054] 東邦音楽大学文京キャンパス敷地の区による取得（報道発表）

- **書誌・所在〔確認〕**：文京区公式サイト「区政情報 > 広報・広聴 > 報道発表資料 > 令和7年の報道発表資料 > 報道発表資料（令和7年2月）」の「学校法人三室戸学園 東邦音楽大学文京キャンパス敷地の取得について」。2026年11月8日に本文を文字抽出で確認。
- **取得の経緯〔確認：報道発表の叙述〕**：東邦音楽大学文京キャンパスが**川越キャンパスに統合**することに伴い、同敷地を**区が取得（取得予定時期：令和7年度＝2025年度）**し、区立小・中学校の改築等に活用する。
- **敷地概要〔確認：報道発表の叙述〕**：土地所有者は学校法人三室戸学園。所在地（地番）は**文京区大塚4-46-9（大塚4-36-1外）**。**学校敷地面積：約6,400平方メートル**。東邦中学校・東邦高等学校の在校生（令和6年度入学）が卒業まで通学するため、**区の活用は令和8年度（2026年度）の在校生卒業以降**。
- **資料の限界〔未解決〕**：**池・森・樹林地・水辺への言及はない**。約6,400平方メートルは校舎敷地の面積であり、周辺樹林地の範囲・帰属は分からない。校地の歴史は [ORG-010](../org/ORG-010.md)（1939年現在地移転）を参照。
