# [GOV-023] 豊島区『みどりと広場の基本計画』（1993年3月）

## 書誌・所在

- 豊島区都市整備部都市計画課企画・編集、1993年3月初版第1刷発行。区長序文は1992年11月付。
- 原資料（豊島区デジタルアーカイブ公開PDF）：https://adeac.jp/viewitem/toshima-history/viewer/viewer/13_H050611_05/data/13_H050611_05.pdf
- 2026年10月31日、公開PDFの本文・該当表を確認。図面の細部の位置合わせは未実施。

## 内容メモ

- 印刷p.10–11「地形・地質」は、豊島区を標高約30mの武蔵野台地上に位置づけ、神田川・弦巻川・谷端川・谷田川による小規模な谷・崖・坂の形成を説明する。図2-1「豊島区の土地条件」の典拠を国土地理院の「土地条件図」とする。
- 同頁には図2-2「豊島区の現存植生」（典拠「東京都現存植生図」）を掲載する。1991年11月時点の区内緑被面積162.86ha、緑被率12.5％の数値も記載する（印刷p.12）。
- 印刷p.31「最終目標の具体化」は、1992年4月1日時点の公園・児童遊園等を144か所・154,324㎡とし、集計に「目白庭園」と「谷端川緑道」を含むと明記する。
- 同頁の表3-2「豊島区の公園配置の考え方」は、種別F「自由庭園など」の備考に「自由庭園、谷端川緑道」を記載する。これは当時の計画上の施設区分である。
- 144か所・154,324㎡は区内の公園等の合計であり、谷端川緑道単独の面積ではない。図2-1・図2-2は旧河道の実測図ではない。
