# [GOV-151] 紙の博物館「用水路修復助合金・堤舗修復助合金 請取帳」〔repo初出〕

- **書誌〔確認: 紙の博物館収蔵品データベース（jmapps）・2026-11-15〕**: 「**用水路修復助合金・堤舗修復助合金 請取帳**」（収蔵ID:951・[詳細レコード](https://jmapps.ne.jp/kamihaku/det.html?data_id=951)）。資料種類**文書**、作者（作成主体）**王子村外廿三ヶ村**、年代**明治8年〜明治23年（1875-1890）**、寸法228×155mm、**21点の画像がデータベース上で公開**。解説欄に「**抄紙会社御中**」の語〔「用水」のキーワード検索でヒット〕。
- **内容〔観察: 題名・解説からの推定〕**: 「**用水路修復助合金・堤舗修復助合金**」の**請取帳**（領収の記録）で、宛先が「**抄紙会社御中**」。**王子村外23ヶ村が、用水路・堤の修復に要した金を抄紙会社から助成（負担）してもらい、その請取を記録した帳簿**とみられる〔本文未判読のため、助成の法的性質（約定に基づく義務負担か・任意の寄付か）は断定しない〕。
- **意義〔観察〕**: ①[GOV-150](GOV-150.md)の明治7年9月3日約定（抄紙会社×王子村外23ヶ村）と同じ当事者同士（抄紙会社・王子村外23ヶ村）の**継続的な金銭関係（明治8〜23年の15年間）を示す帳簿**で、約定の実施態様を窺う補助資料〔約定証書の文言との照合が次回課題〕。②**千川用水系の水路の維持管理費を工場側（抄紙会社）が負担した**という明治期の実態を記録する点で、[BLOG-229](../blogs/BLOG-229.md)（社史の「会社の利用にまかされた水」）・[GOV-150](GOV-150.md)（水利権約定）に、**水路の維持費負担という金銭面の一次記録**を加える。③修復対象の「用水路」「堤」が千川用水（王子分水）のどの区間かは本文未判読〔要画像確認〕。
