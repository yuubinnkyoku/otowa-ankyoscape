# [GOV-183] 東京都市計画報告 第12回（1937年）

- **書誌〔確認〕**: 東京府『東京都市計画報告 第12回』（1937〔昭和12〕年）・NDL次世代デジタルライブラリー [book/1115002](https://lab.ndl.go.jp/dl/book/1115002)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **受益者負担施行細則〔確認・repo初出〕**: 東京都市計画事業受益者負担金徴収計画（立会川・神田上水・谷端川の3河川改修関係）の**施行細則**（昭和11年7月30日・東京府知事横山助成）。〔[GOV-102](GOV-102.md)（告示目次）→[GOV-181](GOV-181.md)（委員会・府令12号）に続く**実施段階の細則資料**〕〔文言はOCR要照合〕。
- **旧河川境界線から6間以内の土地への指数5%加算〔確認・repo初出〕**: 細則の規定として、**旧河川の境界線から6間（約10.9m）以内にある土地に対して受益者負担の指数を5%加算**する旨の規定が確認された。〔**旧河道（改修前の河川跡）沿いの土地が負担加重対象とされた**ことを示す規定で、旧河道の土地利用・区画整理との関係を考える上での制度的文脈。6間・5%の数値はOCR要照合〕。
- **「改修前ノ洪水時ニ於ケル浸水地域」文言〔確認・repo初出〕**: 「**立会川・神田上水及谷端川(板橋区地内)**」が改修前の洪水時の浸水地域として挙げられる文言が確認された。〔**改修前の谷端川が板橋区（旧西巣鴨町域）で浸水を起こしていた**ことを示す市側（府側）の記述。ただしこの後の資料（[GOV-184](GOV-184.md)・昭和11年11月14日細則改正）では「**谷端川(豊島区及滝野川区地内)**」という文言が現れ、区名の対応はOCR段階では確定しない。昭和10年の区名（板橋区・豊島区・滝野川区）はいずれも35区制で、旧西巣鴨町は大部分が板橋区に、谷端川下流は豊島区・滝野川区に属する。どの文言が正しいか・または区間の組み替えがあったかは要照合〕〔文言はOCR要照合〕。
- **補助線用地買収〔確認・参考〕**: 不動産取得第249号として**豊島区千川町2丁目・3坪5勺**の土地取得（補助線用地）が記録される。〔千川町の地名を持つ土地の取得は[GOV-184](GOV-184.md)の「千川」関係区間の文脈と並ぶ参考記録〕〔数値はOCR要照合〕。

  2. **第三条**＝「省令第五條第二項ノ規定ニ依ル受益者(轉借人ヲ除ク)ノ負擔金額ハ**同令第四條ノ規定ニ依リ算出シタル金額ノ百分ノ五十トス**但シ受益者ノ權利ノ態樣ニ依リ別ニ之ヲ定ムルコトアルヘシ」＝**賃借人・使用借主等（転借人を除く受益者）の負担金額は省令第4条算出額の50%**。
