# [GOV-276] 玉川上水留 嘉永5年 — 山下御門掛樋枡・井戸の修復（第121回課題①の直接史料）

- **書誌〔確認〕**: 『玉川上水留』「玉川上水山下御門掛樋枡御修復一件　嘉永五子年三月」（全1冊）[book/2587381](https://lab.ndl.go.jp/dl/book/2587381)。repo未登録（「山下御門」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔[GOV-270](GOV-270.md)（文久3年・薩摩小路組合樋筋の流末が山下御門）・第121回ノート課題①（御本城掛樋筋・薩摩小路組合樋筋流末山下御門の経路復元）に直結する、山下御門掛樋枡の修復の帳簿。〕
- **樋注文125間→実測123間3尺〔確認・repo初出の山下御門掛樋の定量記録〕**: 勘定帳「**樋長建百弐拾五間仕渡候注文之処 百弐拾三間三尺二而相済 長壱間三尺相減**」＝**山下御門に掛かる樋の注文書寸法125間に対し、実測では123間3尺で相済み、1間3尺減じた**＝樋管の設計寸法と実測のずれの記録（「建百弐拾五間仕渡候」のOCR解釈は要照合）。この樋が「掛樋」＝山下御門の門構・土手上に架かる樋管であることが題名と本文（「山下御門大番所掛樋枡井戸共御修復」）で確認できる。
- **埋枡3ヶ所・石縁枡・井戸の仕様〔確認・repo初出〕**: 仕様内訳——「**一 埋榊(枡?)大サ内法弐尺五寸四方深四尺 三ケ所**」「**一 地形一面石縁枡大サ内法前同断 弥(?)六尺 壱ケ所**」「**一 井戸大井(?)内法差渡弐尺七寸石嶋(積?)六尺四方 壱ケ所 右仕様化粧(?)ケ輪取除置 根ケ輪仕直候積**」＝**地上に露出する地形の石縁枡と、地下に埋める3ヶ所の埋枡（内法2尺5寸四方・深4尺）、6尺四方の石積の井戸**で構成＝山下御門掛樋枡の末端部（水の受け・吐きの設備）の構造記録（「埋枡」＝地下埋設の枡、「石縁枡」＝石縁の 枡 のOCR読みで原字形照合必須）。
- **天保9年修理から15年目の定期修復〔確認・repo初出の修繕サイクル〕**: 「**天保九戌年御修復之節は拾三ヶ年目ニ 此度は弐ヶ年相延**」＋「**天保九戌年御修復之節の仕様内訳見廻附切何書共写差出候 尤此度与先仕様と少々替り候場所は下ケ札いたし遣**」＝**山下御門掛樋枡は天保9(1838)年に修復された（その際も13年目の修復だった）もので、嘉永5(1852)年は15年目（2年延びた）の修復**＝**13〜15年周期の定期修復の管理が行われており、前回の仕様内訳を写して比較した実務（＝天保9年の山下御門掛樋枡修復の存在の傍証・遡れば文政期以前から山下御門掛樋が存在）**（「拾三ヶ年目」の起点〔いつの普請から数えて13年目か〕は本冊の文言のみでは確定できない）。
- **落札72両・公儀出銀僅少〔確認・repo初出の経理構造〕**: 「**金七拾弐両地割棟梁元積一金七拾五両入札直段差之金三両**」＋「**御組合入用高五百七拾弐(?)…公義御出銀凡金壱両壱分弐朱銀五匁三分四厘四毛 余(?)武家町出張凡金七拾両弐分銀弐匁壱分五厘五毛**」＝**落札72両（元積75両・3両の差引）のうち、公儀（幕府）の出銀は1両1分2朱+銀5匁3分4厘4毛程度と僅少で、残りほぼ全額が武家町（給水を受ける武家屋敷持ちの組合）の出銀**＝玉川上水の城内給水樋管の修復費が受益者負担（武家方）で賄われていた経理構造（[GOV-281](GOV-281.md)の慶応期の武家方水銀帳・出銀取集帳と直接対校可・「五百七拾弐」の単位〔両?〕と「出張」=「出銀」のOCRは要照合）。
- **昼水留＋夜は繋樋〔確認・repo初出の通水維持工法〕**: 「**一 樋御修復中昼之内水留いたし繋樋仕付 夜水は相掛可申候**」＝**修復中、昼間は水留（通水停止）とし、繋樋（仮設の迂回樋管）を仕付けて夜間は通水した**＝城内の重要給水管を完全に止められないための迂回給水の実務（[GOV-272](GOV-272.md)等の「一日限水留」と違い、山下御門掛樋の修復では昼のみ止め夜は迂回給水）。
- **日比谷御堀浚揚土で山下御門外〜数寄屋橋御門外の小土手に腹附〔確認・repo初出〕**: 「**一 樋伏方出来之上足土 日比谷御堀浚揚土 山下御門外ゟ数寄屋橋御門外迄小土手え腹附いたし有之候間 並能削取拾坪(?)持込 不陸無之様道造いたし砂利田(?)坪敷千均候積**」＝**樋の伏設完了後、日比谷御堀の浚渫揚土を山下御門外から数寄屋橋御門外までの小土手に腹附（土を継ぎ足し）した土を削り取って持込み、樋筋の不陸を直して砂利を敷いた**＝**山下御門外〜数寄屋橋御門外の間に、日比谷御堀（外堀）の浚渫土で築かれた小土手が存在し、その上を玉川上水の樋管が通る**という重要な地形記録＝外堀の浚渫副産物が上水樋管用土手の材料になった実態（「拾坪持込」「砂利田坪敷千均」のOCR崩れは要照合。この小土手は[GOV-282](GOV-282.md)書上帳（明和3・安永9）の「山下御門外〜虎御門間の外堀小土手の損所」と連続性が候補となる）。
- **山下御門大番所掛・御門内土手通の作業場〔確認・repo初出の山下御門内の立地〕**: 「**御修復中竹矢来箱番屋取建外に箱番家壱ヶ所差出**」「**同所御門内土手通江別紙絵図面朱引之通 諸色置場竹矢来取建箱番屋差置**」「**山下御門大番所掛樋枡井戸共御修復**」＝**樋枡・井戸の修復場所が山下御門の大番所に掛かる位置で、御門内（城内側）の土手通に諸色置場（資材置き場）・竹矢来・箱番屋（小屋）を設けた**＝山下御門が城内（外堀の内側）と城外を繋ぐ給水の結節点であることの明示（[GOV-270](GOV-270.md)の文久3年の薩摩小路組合樋筋流末の文言・[GOV-275](GOV-275.md)の御門々触出しリストの山下御門と対校可）。
- **山下丁・難波丁の町人の古物入札〔確認・repo初出の山下御門外の町〕**: 古物御拂（払い下げ）の入札に「**山下御門外山下丁家主長兵衛店湯屋勘助殿 油丁(?)二つ兵蔵 湯屋長助 難波丁家主長右衛門**」ほか山下御門外の山下丁・難波丁の町人が参加し、**湯屋（銭湯）が松7寸角の古彫樋34本・古樋板71枚・古弐重蓋8枚・古駒頭46の入札（落札高金4両2分銀5匁6分8厘・大黒屋・住吉屋長次郎・小川屋）で落札した**＝**嘉永5年時点の山下御門外に山下丁・難波丁の町（現在の西神田〜大手町方面か・[MAP-175](../maps/MAP-175.md)等の江戸図と対校要）が実在し、湯屋が湯水確保のために古樋管（燃材・資材）を落札した**（町名・人名・金額はすべてOCRで要照合。「山下丁」は山下御門外の町名と読めるが、「山下町」の表記かは原字形次第）。
- **実務の詳細〔確認・周辺〕**: ①樋材は「**四日市木置場ニ而下拵**」（四日市の木置場で下拵え）②「**取掛凡日積雨天休日相除凡三拾日**」＋樋枡・道造共15日③「**小前駄馬車差留…御門番え断 作事奉行 小普請奉行えも達**」（修復中の駄馬車の差留めと奉行への達）④「**煙立(?)…竹矢来之内江湯呑所…**」（竹矢来内に湯呑所）⑤「**四月廿一日出来形見分…鈴木治兵衛 斎藤金之丞 中嶋精蔵 荒井釜蔵 附切岩(?) 石川留五郎 高須謙蔵 吉孫(?)子丈助一同八時過相揃無滞見分相済候 古割御門番え引渡**」＝**出来形見分（検収）後、山下御門の御門番に樋枡を引き渡した**＝修復完了から御門番の日常管理への引渡しまでの実務の全体（人名はOCR要照合）。
