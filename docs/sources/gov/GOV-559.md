# [GOV-559] 武蔵野市「武蔵野市平和の日」ページ＋市冊子「中島飛行機武蔵製作所物語」所在〔平和の日制定の市側根拠と季刊むさしの再編集冊子の所在〕

## 1. 平和の日ページ（1007366）〔確認〕

- 市公式「**11月24日は「武蔵野市平和の日」です**」 https://www.city.musashino.lg.jp/heiwa_bunka_sports/heiwa/1007366.html （ページ番号1007366・**更新日 2026年11月24日**）。
- **制定の語り**: 「武蔵野市には、第二次世界大戦中、現在の**都立武蔵野中央公園辺り**に軍需工場である中島飛行機武蔵製作所があり、航空機エンジンを生産していたことから、たびたび米軍による攻撃目標となりました。**昭和19年11月24日の初空襲以降、終戦までに合計9回の空襲**を受け、工場の従業員や周辺住民など多くの方が犠牲となりました。市では…**平成23年に11月24日を「武蔵野市平和の日」として制定**しました」〔制定年の明示は[GOV-556](../gov/GOV-556.md)等で提起のままだった「平和の日」の制定年を市自身の文言で固定する一次情報〕。
- **リンク集**: 平和の日メッセージPDF（令和8年・R8peacemassage.pdf、74.3KB）／**武蔵野市平和の日（11月24日）条例**（ https://www.city.musashino.lg.jp/heiwa_bunka_sports/heiwa/1007367.html ）／平和施策について（1007368）。
- **まとめ欄の関連ページ（所在のみ・未確認）**: 武蔵野から伝える戦争体験記録集（1007369〜1007371・第4集1045812）・**特設サイト「武蔵野・三鷹 平和まち歩き」（1054065）**〔特設サイトは次回以降の調査対象候補〕。

## 2. 市冊子「中島飛行機武蔵製作所物語」ページ（1048509）〔確認〕

- 市公式「**中島飛行機武蔵製作所物語（季刊むさしの 昭和の武蔵野・番外編より）**」 https://www.city.musashino.lg.jp/heiwa_bunka_sports/heiwa/1048509.html （ページ番号1048509・**掲載日 2025年7月17日**）。
- **冊子の内容説明**: 「この冊子は**「武蔵野市平和の日」制定を記念し、平成13年から20年まで、季刊むさしのに掲載された「昭和の武蔵野・番外編 中島飛行機武蔵製作所物語」及び「武蔵野百年史こぼればなし」（共に長沼石根 氏著）より抜粋した記事を再編集し、発行するもの**です」〔**「平和の日制定を記念した市の冊子」という性格づけと、2連載の再編集であることの明文はrepo初出**。[GOV-558](../gov/GOV-558.md)の説明「番外編は№55〜62・2001年夏〜2003年春」との食い違いは、冊子が2連載分を含む期間によるものと推定されるが断定しない〕。
- **所在**: 資料は**市役所（西棟7階）市民活動推進課等で配布**。各図書館にて閲覧・貸出。ダウンロードは https://www.city.musashino.lg.jp/_res/projects/default_project/_page_/001/048/509/20250716.pdf （**PDF 21.2MB**）〔所在のみ。冊子本文は未確認〕。
- **共催の枠組み**: 市民・市民団体による非核都市宣言平和事業実行委員会との共催により各種平和事業を行っている旨の前置き。
