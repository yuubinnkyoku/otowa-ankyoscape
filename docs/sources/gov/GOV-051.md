# [GOV-051] 文京区公式「占春園」観光スポットページの歴史記述

- **書誌・所在〔確認〕**：文京区公式サイトの「文化・観光・スポーツ > 観光 > 観光スポット等 > 庭園 > 占春園（せんしゅんえん）」（担当：みどり公園課）。2026年11月8日に本文を文字抽出で確認。
- **歴史〔確認：公式ページの叙述〕**：水戸徳川家2代**光圀の弟・松平頼元**が**万治2年（1659）**にこの地に屋敷を構えた。その子**頼貞**は**陸奥国守山藩主として2万石**を領し、**大学頭**となった。**占春園はこの松平家の屋敷内の庭園の名残**であるとする。
- **資料の限界〔未解決〕**：池の名称・水源（湧水・用水・分水の別）・作庭の正確な年代・屋敷の範囲・現在の池との対応は、このページには書かれていない。地形・管理・池の現況は [GOV-052](GOV-052.md)、変遷の詳細は [BLOG-026](../blogs/BLOG-026.md)・[BLOG-027](../blogs/BLOG-027.md) を参照。
