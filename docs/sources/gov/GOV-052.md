# [GOV-052] 文京区公式「占春園」公園案内ページの地形・池・管理の記述

- **書誌・所在〔確認〕**：文京区公式サイトの「まちづくり・環境 > みどり・公園 > 公園等の案内 > 都立公園などの紹介 > 占春園」。2026年11月8日に本文を文字抽出で確認。
- **位置づけ・管理〔確認：公式ページの叙述〕**：占春園は**都市公園ではない**が、都市公園である**教育の森公園に隣接**し、合わせて都市計画公園**「文京中央公園」**に含まれる。**筑波大学附属小学校の自然観察の場**となっており、一般区民にも開放される。
- **地形・池〔確認：公式ページの叙述〕**：明るく広々とした教育の森公園とは異なり、**斜面と低地を利用した園内**は樹木がうっそうと生い茂り、ササに覆われた樹木の下に**細い階段状の園路が池に向かって下る**。**中島のある池**の回りには大木が生い茂る。**東側の低地にある広場にはカツラが3本**植わる。池の近くに**嘉納治五郎像**がある。教育の森公園から窪町東公園へと抜ける園路がある。
- **資料の限界〔未解決〕**：池の名称（落英池）・水源（湧水・用水・分水の別）・水深・流入出は、このページには明記されていない。「斜面と低地を利用した」という地形描写は確認できるが、**どの谷筋・旧水路に対応するかは書かれていない**。歴史は [GOV-051](GOV-051.md)、池名・かいぼりは [BLOG-026](../blogs/BLOG-026.md) を参照。
