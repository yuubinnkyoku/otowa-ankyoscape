# [GOV-222] 大赦調書[184] — 千川屋敷家主亀次郎（文政12年）

- **書誌〔確認〕**: 『大赦調書』[184]（文政12丑年〔1829〕の赦免関係の調書・小普請組御家人の酒乱・刃傷事件の赦免と内済の記録）。NDL次世代デジタルライブラリー [book/2572658](https://lab.ndl.go.jp/dl/book/2572658)。**引用はすべてOCR由来で、文言・人名は原文画像との照合を要する。**
- **「千川屋敷家主亀次郎」〔確認・repo初出〕**: 小普請組浅野隼人組の川崎平八郎の酒乱事件（文政12年8月21日・22日の嫡家留守への押し掛かり・投石）の調書——「**…所払小石川伊山前町〔白山前町のOCR崩れ〕千川屋敷家主亀次郎方に右居候**」・「**同所の田山前町〔同〕千川屋敷家主亀次郎其外承内済取扱候得共此者得心不致を憤り…**」〔**①文政12年（1829）時点で小石川白山前町の千川屋敷の家主が「亀次郎」であったこと、②赦免された当事者（川崎平八郎）が千川屋敷の家主方に居住していた（「所払」の身の居候）こと、③千川屋敷の家主亀次郎が事件の内済（示談）の取扱いを仲裁したこと**＝**千川屋敷（白山前町）の家主層の実名が文政期に確認できる一次記録（repo初出）**。「亀次郎」が千川家（請負人・元祖太兵衛→…→与惣兵衛→三左衛門〔[GOV-210](GOV-210.md)・[GOV-212](GOV-212.md)〕）の一族・縁者か、別の家主（地借・家守層）かは本資料からは確定できない（断定しない）。千川家の由緒（元祖太兵衛→太兵衛→…の男系）に「亀次郎」は現時点で未確認〕〔「伊山前町」「田山前町」は「白山前町」のOCR崩れ（前後の文脈で小石川白山前町の千川屋敷〔[GOV-208](GOV-208.md)〕に合致）〕。
- **位置づけ〔観察〕**: ①千川屋敷が「家主−居候（借家人）」の賃貸関係を持つ町屋敷として文政期に機能していたこと、②家主が内済の仲裁（近隣の顔役）として町方の紛争処理に参画していたこと——を示す。千川家（上水請負人）が江戸後期に上水差止（天明6）後も屋敷の家主として定住していた実態（README既存の千川家の「屋敷」の継続〔[GOV-211](GOV-211.md)・[GOV-212](GOV-212.md)〕）と併せ、**千川屋敷が千川上水廃止後も町方の賃貸・仲裁の拠点として存続していた**方向の傍証。ただし「亀次郎」と千川家の関係が不明のため、断定は避ける。

## 制限・未解決

- ①「亀次郎」の千川家の系譜上の位置（与惣兵衛〜三左衛門の時期の白山前町の家主）は未確定。②事件の詳細（川崎平八郎の身分・赦免の条件）は本資料のスコープ外のため深追いしない。③OCR崩れ（伊山・田山＝白山）の確定は原文照合による。
