# [GOV-201] 都市計画東京地方委員会 議事速記録 第6号 — 議第110号（1934）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第6号』（席次昭和9年3月30日現在・同日の委員会を収録）。NDL次世代デジタルライブラリー [book/1212972](https://lab.ndl.go.jp/dl/book/1212972)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **議第110号「東京都市計画河川改修及其ノ事業執行年度割中変更ノ件」〔確認・repo初出〕**: 1934〔昭和9〕年3月26日内務大臣山本達雄発議（被告示＝昭和5年8月13日内務省告示第155号）・第6号所収の委員会で原案通り決定。**同一告示の提案理由は東京府『東京都市計画報告』（昭和9年度第一期＝[GOV-205](GOV-205.md)・第三回＝[book/1448213](https://lab.ndl.go.jp/dl/book/1448213)）にも再録**。
- **谷端川の残工事〔確認・repo初出の重要文言〕**: 「**尙立會川ハ東海道線大井町驛附近ノ鐵道橋ノ改築竝其ノ附近、谷端川ニ付テハ暗渠敷ノ埋戾シ及廢川敷ノ整理工事ノ一部未了ニ屬スルヲ以テ事業ノ一部ヲ明年度（＝昭和10年度）ニ繰越シ執行セムトスルモノナリ**」＝**1934年3月時点の谷端川改修の未了部分が「暗渠敷の埋戻し」と「廃川敷の整理工事」であった**ことを特定する文言。〔[GOV-186](GOV-186.md)（1940「立会川及谷端川ハ既ニ昭和九年ニ完成」）・[GOV-205](GOV-205.md)（昭和9年度末に完成公表）と整合し、**本体暗渠化工事は昭和9年度完了、付帯の埋戻し・廃川敷整理は昭和10年度繰越し**という工程の内訳を与える〕〔文言はOCR要照合〕。
- **神田上水改修計画の変更〔確認・要照合〕**: 延長「約七、一六六米」→「**約六、九二九米**」（約237m短縮）。屈曲矯正6箇所（淀橋区内環状線高戸橋附近・小瀧橋附近・中央線東中野駅附近2箇所・淀橋〜桃園川合流点間の十二社東電変電所附近ほか・**内訳計数はOCRで崩れ要照合**）。護岸はT型鉄筋コンクリート造・高さ3.33〜4.67m、**玉川上水合流点より下流は沿岸工場の土揚敷不当占用の虞があるとして護岸中段を設け流水断面に余裕**を持たせる変更。起点中野区千代田町寿橋〜旧市郡界（淀橋区戸塚町一丁目）。
- **事業費・年度割〔確認・要照合〕**: 三河川（立会川・神田上水・谷端川）総経費**4,434,249円→5,630,722円40銭**（神田上水の計画変更に伴い工事費・用地補償費+1,262,335円、事務費▲62,335円、差引+120万円を追加、昭和7年度不用額3,526円60銭減）。執行年限を**昭和8年度完成予定から昭和10年度まで2箇年延長**（昭和5〜7年度約5割4分3厘・8年度約2割3分9厘・9年度約6分7厘・10年度約1割5分1厘）。**江戸川改修（東京市長執行）との調整・用地買収・建物移転の遅延**が延長理由。
- **位置づけ〔観察〕**: 三河川改修の予算・期間変遷の中期要素＝[GOV-159](GOV-159.md)（1930決定・520万9千円・4箇年）→[GOV-202](GOV-202.md)（1931・1932のデフレ減額で443万円台）→**本号（1934・計画変更で563万円台へ増額・2箇年延長）**→[GOV-161](GOV-161.md)（1935・昭和11年度まで延長）→[GOV-203](GOV-203.md)（1936・昭和12年度まで再延長）。「神田上水ハ昭和五年八月立會川及谷端川ト共ニ東京都市計画ニ決定セラレ」の文言は[GOV-159](GOV-159.md)・[GOV-180](GOV-180.md)と一致。
