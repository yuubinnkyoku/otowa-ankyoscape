# [GOV-193] 東京都市計画環状道路改修工事報告書（1933年）— 千川用水大堀割の空堀と塵芥充填

- **書誌〔確認〕**: 東京市『東京都市計画環状道路改修工事報告書』（昭和8年・1933）。NDL次世代デジタルライブラリー [book/1907000](https://lab.ndl.go.jp/dl/book/1907000)。**すべての引用は同館OCRテキスト由来であり、文言・数値は原文画像との照合を要する。**
- **「堀割」区間の実態〔確認・repo初出〕**: 豊島区内の新旧9号国道（中仙道）間の工事区間は「俗ニ**堀割**ト稱シ」、その成因＝「**千川用水ノ大堀割ノあつたのを該用水組合にて暗渠に改造せる結果、深さ約四米乃至五米、幅一〇米內外の空堀を生じ**」＝**用水組合による暗渠化（時期は本文では未特定）の結果、深さ4〜5m・幅10m内外の空堀が生じた**という第一次記録。空堀は「**忽ち舊瀧野川町の塵芥捨場に利用され**」道路改修前に「**全部塵芥を以て充塡し盡された**」と記す。〔文言・数値はOCR要照合〕。
- **工法〔確認〕**: 全除去は経費過大・塵芥の捨場難のため「**上部約二米を除去するに止め、良土を埋めて十分轉壓したる後、基礎コンクリートを打設**」＝**塵芥充填済み空堀の上に環状道路の基礎を敷設した工法記録**。爾来の状況についても言及がある（文言はOCR不良箇所あり・要照合）。〔文言はOCR要照合〕。
- **千川上水路に沿う旧道〔確認〕**: 中仙道〜飛鳥山前（旧岩槻街道）間には「**千川上水路に沿ふ鎌倉往還、飛鳥道、飛鳥山道等**」があった＝**千川堀割沿いの旧道群の道名記録**。〔文言はOCR要照合〕。
- **位置づけ〔観察〕**: 千川堀割の変遷を「**用水組合による暗渠化 → 空堀の塵芥捨場化 → 環状道路敷設**」という段階として一次記録で連結。[GOV-180](GOV-180.md)（千川筋街路）・[GOV-187](GOV-187.md)（千川筋＝一等大路第一類第十四号）の前提地形を数値化した報告書。「俗ニ堀割ト稱シ」という地元呼称の記録も加わる。
