# [GOV-126] 東京都建設局「神田川流域河川整備計画（変更原案）へのご意見等について（資料5-3）」

- **書誌〔確認: open_url本文取得〕**: 東京都建設局の会議資料「**神田川流域河川整備計画（変更原案）へのご意見等について（資料5-3）**」〔[kensetsu.metro.tokyo.lg.jp](https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/000060776)。本文約8,200字を取得（直curl不可・open_urlで取得）。整理番号1〜36の公募意見（要旨）と回答（案）の表。**発行日の本文記載なし。〔推定〕意見13が2018年整備の遅野井川親水施設・意見10が2021年11月14日の現地研修会に触れることから、[GOV-124](GOV-124.md)（令和5年3月計画・平成19年計画の変更）の原案手続に伴う意見として2022年頃と推定し、以降の確定情報が出るまで断定しない**〕。
- **千川上水の地中管〔確認: 意見13の市民一次観察〕**: 「**千川上水が地中管で公園内を通り、下池の池尻に流れ出ています。地中管を遅野井川親水施設の最上流部分に入れていただきたい**と願うものであり、そうすれば旧遅野井川筋(暗渠)を通った水は下池の池頭に出ます。下池の水質改善のためにも役立つものと考えます」〔都立善福寺公園（上池・下池）で湧水はほとんどなく数か所から地下水をポンプアップして池水を確保している状態、との観察とともに記載。回答（案）は「いただいたご意見は、関係機関と共有させていただきます」〕〔〔観察〕[GOV-124](GOV-124.md)図2-13の千川上水経由・善福寺川導水0.1m³/s（清流復活事業）の流末について、**千川上水が地中管で善福寺公園内を通過し下池の池尻に流出している**という現地観察レベルの位置情報を与える。[BLOG-090](../blogs/BLOG-090.md)/[BLOG-094](../blogs/BLOG-094.md)の「青梅街道交差点のすぐ先で善福寺川へ導水」（=善福寺公園付近）と整合するが、都の公式確認資料ではないため推定として扱う〕。
- **図2-13数値の読解補助〔確認: 意見20への回答〕**: 意見20「p.18 神田川平常水量については、赤数値は放流、導水量を含んでいる値ですか？」→回答「**放流、導水量を含んでいる値です**」〔[GOV-124](GOV-124.md)図2-13の青字＝放流量・導水量等、赤字＝河川流量という凡例の解釈を公式回答で確認〕。
- **遅野井川関連〔確認: 意見11・14〕**: 善福寺川上流域の遅野井川が再生され子どもたちの水辺になっていること、2018年に上池と下池をつなぐ水路「遅野井川親水施設」が**杉並区によって整備**されたこと、遅野井川の**下流側は未だ暗渠**であること、親しまれていた「よしきりはし」の復活提案〔回答: 整備の対象区間等は法定河川区間としており、意見は関係機関と共有〕。意見12: 上流部（夕やけ橋〜丸山橋）のミクリ・ナガエミクリ・カワヂシャ・カワモズク類など貴重な植物の保全希望。
- **表2-5の修正〔確認: 意見33〕**: 主な生物確認状況の魚類でモツゴが外来種リスト掲載種として赤字にされていたことへの誤り指摘→「黒字に修正しました」〔変更原案→決定の間の修正実例〕。意見16: オオカワヂシャ・オオブタクサの追加→「追加しました」。
- **弦巻川・水窪川・谷端川の言及〔確認: なし〕**: 本資料の意見・回答に三河川の言及なし（善福寺川・遅野井川・千川上水のみ）。
