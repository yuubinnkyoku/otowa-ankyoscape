# [GOV-600] 帝室博物館略史 — 上野動物園の使用水＝千川上水の1938年時点記録と水量の定量化

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 帝室博物館 編『帝室博物館略史』（**帝室博物館・1938**・[book/1839532](https://lab.ndl.go.jp/dl/book/1839532)）。帝室博物館（現・東京国立博物館。1938年の新館開館期）の沿革・附属動物園（上野動物園）・附属温室等の事業をまとめた博物館側の公式略史。**引用はOCR由来**。附表・水量記述の前後の列崩壊があるため原画像照合を要する。

## 文言〔確認・要照合〕

- **附属動物園章**（OCRコマ75枚目。印刷頁番号は未照合）:
> 動物園附屬動物園は博物館と相俟つて敎化ヲ裨補セントスルモノ… 園内地坪七千九百〇九坪七合二勺五才（既測量地）ノ外ニ未測量地百餘坪ヲ有ス。**園內ノ使用水ハ千川上水ヲ利用シテヰル。本園創立當時ハ水量十二時間ニ二千五百三十九立方尺ヲ算シテヰタガ、動物ノ增加ニ伴ヒ水量ノ不足ヲ來タシタノデ增量ノ計ヲ立テ、十二時間ニ四千六百二十七立方尺、卽チ石數ニシテ七百二十三石七斗餘トシテ引繼ギ今日マデ之レヲ使用シテヰル。**

## 読み取り〔観察・対校課題として登録〕

- **①上野動物園の使用水の水源名としての「千川上水」〔repo初出の文言群〕**: 1938年刊行の博物館側公式略史が附属動物園（明治15年〔1882〕創立）の使用水を**「千川上水ヲ利用」**と明記する。明治期の博物館用水の給水主体は[GOV-323](GOV-323.md)（第三回事務報告・帝国博物館用水＝**千川水道會社給水ノ分取**）・[BOOK-161](../books/BOOK-161.md)（明治23年頃の給水量＝博物館3,357立方尺/12h・動物園7,520余立方尺/12h・博覧会局が動物園用水から4,983立方尺を分取）で既知で、**明治13-14年の博覧会会場引水（[GOV-599](GOV-599.md)・1881）→明治23年（GOV-323/BOOK-161）→1938（本条）へ上野公園側の千川上水系給水の通時系列が揃った**〔1938年時点の給水手段（千川水道の後身の管路か・旧水路・井戸か）は本条では特定できない〕。
- **②水量の定量化〔repo初出の数値群〕**: ⅰ) 創立当時（明治15年）**2,539立方尺/12時間** ⅱ) 増量後**4,627立方尺/12時間＝723石7斗余**（「今日まで使用」）の2点。「増量の計」の実施時期は本条では特定できないが、博覧会局による分取（4,983立方尺・[BOOK-161](../books/BOOK-161.md)）を含む給水量増の背景候補となる。
- **③数値対校の課題〔断定しない〕**: [BOOK-161](../books/BOOK-161.md)の「動物園7,520余立方尺」と本条の「4,627立方尺（増量後）」は**同対象・別数値**として並立する。測定期間（12時間あたりか日あたりか）・測定時点・新田/旧田の石の換算差等、口径の違いが候補であり、本条単独では優劣をつけない〔原画像照合と兩資料の測定時点特定が今後必要〕。
- **④1938年文言の性格〔注意〕**: 「引継ギ今日マデ之レヲ使用シテヰル」は**1938年刊行時点の現勢記述として読める**が、略史の沿革章が明治期の記録（施設沿革・給水契約等）を引き継いでいる可能性もあり、**「昭和13年時点で現に千川上水（系統）の水を使用中」と断定するのは原画像・前後章の照合まで留保**する。
