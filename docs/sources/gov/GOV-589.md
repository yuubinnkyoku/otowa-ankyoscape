# [GOV-589] 「反射炉」8件全走査による新規5件+千川用水側に合同の2件（1869〜1878）

- **調査方法〔確認〕**: 都公文書館クロス検索のキーワード「反射炉」（8件・1頁・全14コレクション）を2026-11-25（第313回）に全走査した。8件のうち3件（687745〔鹿島てい説諭〕・687748〔元反射炉掛り水積割附改正草案〕・822394〔反射炉用水の半数の分水回答〕）は千川用水系の実務でもあるため[GOV-587](GOV-587.md)⑤に合同収録し、**残る5件の詳細頁（請求番号・MF・コマ）を本件で確認**した〔GOV-587と同じくPOSTレシピ不通後のGET復旧で取得〕。いずれも**本文は未見**。滝野川反射炉（元治元年〔1864〕着工・明治初頭まで運用。[BLOG-127](../blogs/BLOG-127.md)/[BLOG-226](../blogs/BLOG-226.md)・[PAP-122](../papers/PAP-122.md)系）の行政側（東京府文書）の記録群。
- **①明治2年（1869）・滝野川村反射炉の非常時の実務〔確認〕**: 「滝野川村反射炉**非常駆付人足并橋々修復水路取締之件**」（明治2年〔1869〕・第三課・**６０５．Ａ７．０６**〔諸伺留・第２号終〈第三課〉〕・収録先資料ID000120367・[MF]府明Ⅱ明02-006・コマ0648-1124・pkey [276340](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=276340)）＝**滝野川村の反射炉での非常事態（火事か水患かは未見）に対する人足の駆けつけ・橋の修復・水路の取締**を一括で扱った1869年の記録〔反射炉と橋・水路の立体的な管理（千川上水・石神井川の水利と橋梁群）が伺留に残る稀少な年次の一次文言〕。
- **②明治2年（1869）・軍務官反射炉の水車破損〔確認〕**: 「４月１７日 滝野邨の**軍務官反射炉建築場中水車破損に付水車の修覆方を示談しその返報を被下る様の旨達 軍務官判事→東京府御中**」（明治2年〔1869〕・兵部省御用留・**６０５．Ａ８．２１**・収録先資料ID000114483・[MF]府明Ⅱ明02-013・コマ0006-0199・pkey [1026317](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=1026317)）＝**1869年4月に軍務官（兵部省の前身）の反射炉建築場（滝野村）の水車が破損し、その修覆を東京府に指示した**記録〔反射炉の動力=水車（千川上水系からの引水）の破損・修覆の実務文言。「兵部省御用留」の簿冊である点も、軍務官→兵部省の移行期（1869年）の文書管理の実態を示す〕。
- **③明治3年（1870）・反射炉の兵部省御用皮革製造場への貸渡〔確認〕**: 「弾内記より**兵部省御用皮革製造場として王子瀧之川反射炉の内貸渡の義に付申上**」（明治3年〔1870〕・常務局・**６０４．Ａ２．０２**〔諸事留・２〕・収録先資料ID000119193・検索手段＝[MF]別置-001・pkey [546133](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=546133)）＝**1870年に王子瀧之川の反射炉（の一部）が兵部省御用の皮革製造場（軍需の皮革=鞣し場か）として貸し渡された**記録〔**反射炉施設の軍需転用（大砲鋳造から皮革製造への用途変更）**＝[BLOG-127](../blogs/BLOG-127.md)系の反射炉終焉期の観察（元治元年鋳造→慶応〜明治の転用）に行政側の実務を補強する一次文言。「弾内記」は人名（比定保留）〕。
- **④明治3年（1870）・招魂社造営の砂利運搬に反射炉からの船積み〔確認×2〕**: a) 「明治３年７月９日 **招魂社造営に付地形砂利滝ノ川反射炉より船積にて相運せ度願に付浅草橋場前見張所通船無差支様其筋へ御達有之度旨掛合**」（明治3年〔1870〕・兵部省御用留・**６０５．Ｂ３．０６**・収録先資料ID000114490・[MF]府明Ⅱ明03-003・コマ0006-0085・pkey [576016](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=576016)）・b) 「明治３年７月１０日 **滝之川反射炉より運船の儀承知に付目印雛形御廻し可申事**」（同上・pkey [576019](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=576019)）＝**1870年7月の招魂社（東京招魂社＝靖国神社の前身。1869年創立）の造営事業のために、砂利を滝野川反射炉の敷地・兵部省の船で運搬（船積み→神田川・浅草橋場経由か）した**記録群〔**反射炉の河岸（船着き場）機能の現存例**＝滝野川村の水利輸送（石神井川下流・千川接続不明）の一次文言。「目印雛形」＝運搬船の標識の雛形の回付〕。
- **⑤千川用水側に合同した2件（1875〜78）の所在再掲〔確認〕**: [GOV-587](GOV-587.md)⑤⑦に収録した a) 「**元反射炉掛り方積の義に付昨年中糸繭器械水車主鹿島ていへ説諭**」（明治11年〔1878〕・**６０９．Ａ７．０８**・pkey 687745）＝反射炉の旧水利権の民間転用の説諭、b) 「玉川上水分水より用水水路各村分水樋口改正并**元反射炉掛り水積割附**等の義に付紙幣局へ通知草案 明治１１年２月６日」（同上・pkey [687748](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=687748)）＝**反射炉の水積（用水割当）の樋口改正への織り込み**（同139号簿冊系の実務）、c) 「**紙幣寮抄紙局製造用水水積の儀は反射炉用水の半数王子村地内３７番屋敷地先にて分水相成候段回答 内務卿大久保利通より大蔵卿大隈重信へ 明治８年１０月１７日**」（第139号簿冊・**６０１．Ａ８．１４**・[MF]市明Ⅰ明18-001・pkey [822394](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=822394)）＝**1875年10月に紙幣寮抄紙局（王子）の製造用水は「反射炉用水の半数」を王子村地内37番屋敷地先で分水すると、内務卿大久保利通から大蔵卿大隈重信に回答した**記録〔**反射炉→紙幣寮への用水の引継ぎの比率（半数）と分水位置（王子村37番屋敷地先）を明記した中央官庁間の一次文言**＝千川用水史と反射炉史の接点の最重要候補。詳細頁の文書年度は第139号簿冊単位（明治10〜18年）〕。
- **位置づけ〔観察〕**: 1869（非常駆付・水車破損）→1870（皮革製造場への貸渡・招魂社の砂利運搬）→1875（紙幣寮＝反射炉用水の半数の引継ぎ）→1878（元反射炉掛り水積の民間水車への説諭・樋口改正）＝**滝野川反射炉の終焉期（1869〜70）から水利権の民間・官庁への移行（1875〜78）までの行政側の断面**が年次付きで並んだ。千川上水・用水の文言を持たない反射炉純粋の記録（①〜④）は反射炉史（[BLOG-127](../blogs/BLOG-127.md)）の補強資料で、⑤の3件が[GOV-587](GOV-587.md)の千川用水実務と本件を接続する。いずれも**本文未見**。
