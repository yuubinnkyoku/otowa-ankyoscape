# [GOV-056] ねりまの川「千川上水が暗きょに」

- **書誌〔確認〕**：練馬わがまち資料館コラム「ねりまの川」千川上水連載の最終回。2026年11月10日時点でサイトはメンテナンス中のため、[Wayback Machineの2025年1月21日スナップショット](https://web.archive.org/web/20250121150647/https://www.nerima-archives.jp/column/3599/)で本文を確認。記事末尾に「昭和62年5月21日」の記述があり、1987年発信の原記事を2024年6月1日にサイト掲載したとみられる（この点は推定）。原記事の初出媒体・執筆者は未確認。
- **灌漑分水の終期〔確認：記事の叙述〕**：明治13年以降の千川水道会社による飲料水供給と、水田灌漑・王子・板橋の工業用水利用が最盛期を迎えた後、**東京の市街化・近代水道の普及で明治41年に千川水道会社が解散**、**水田灌漑に利用された分水の多くは昭和10年代で利用が中止され、その後は主に板橋や王子の工場で利用**と説明。**「昭和10年代」は千川上水の灌漑分水全体の概括であり、谷端川への長崎村外三村分水の個別の終了年ではない**。
- **暗渠化の経緯〔確認〕**：昭和23年10月に区議会から東京都知事に出された意見書が**降雨時の氾濫・浸水被害、子どもの水死事故、衛生問題**を千川上水の弊害として挙げ、暗きょ化への善処を訴えた。水路管理権移管の問題（当時は板橋区長が管理）と工事費用（当時、暗きょ化に5,000万円必要）から、**練馬区内での実施は昭和27年3月以降**と説明。
- **その他〔確認〕**：大正4年、堤に大正天皇即位を記念して桜と楓が1,600本植えられ「新小金井」と呼ばれた（江古田浅間神社に石碑）。昭和10年には石神井川の水を豊島園（現・都立練馬城址公園）東側の中之橋下流わきから千川上水までポンプで揚げて利用した。昭和63年春に上流開きょ部へ通水予定（※平成元年春に清流復活）。
- **三河川への使い方〔推定〕**：谷端川への分水（長崎村外三村分水）の利用がいつまで続いたかという問題に対し、**「灌漑分水の多くは昭和10年代に利用中止」という概括が分水終期の上限を絞る手掛かり**になる。ただし練馬区視点の記述で、谷端川分水の樋・取水口の個別の廃止年代は示されない。**昭和27年3月は練馬区内の暗きょ化着手の時期で、豊島区内（谷端川・雑司ヶ谷幹線等）の暗渠化工事の年ではない**。
- **制限〔未解決〕**：本記事をもって谷端川分水の廃止年を断定しない。既登録の千川水道会社関係記述（[GOV-004](GOV-004.md)・[GOV-005](GOV-005.md)・練馬わがまち資料館[千川上水の歴史](https://www.nerima-archives.jp/column/3482/)）との整合照合と、千川家文書（[GOV-038](GOV-038.md)）・星野家文書（[BOOK-032](../books/BOOK-032.md)）側の廃止記録の確認が次の課題。
