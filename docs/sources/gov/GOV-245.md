# [GOV-245] 神田玉川上水留[1]（文久3年）— 白堀通組合橋七ヶ所・金杉橋掛直の全記録

- **書誌〔確認〕**: 『神田玉川上水留』[1] 「文久三亥年五月十月」冊。NDL次世代デジタルライブラリー [book/2587517](https://lab.ndl.go.jp/dl/book/2587517)。文久3年（1863）5-10月の神田上水・玉川上水の行政記録（慶応〜明治2年の同シリーズ[1]〜[33]の初冊）。**引用文言はすべてOCR由来で要原文照合。**
- **白堀通組合橋七ヶ所の橋数文言〔確認・repo初出の一次文言〕**: 「**神田上水白堀通掛渡有之候組合橋七ヶ所之内小石川金杉橋朽損…**」＝**文久3年（1863）時点で白堀通に「掛渡」の組合橋が七ヶ所あったことを明記する幕府側の一次文言**。＝[GOV-234](GOV-234.md)（明和撰要集・宝暦13年〜明和期の服部屋太兵衛の白堀通渡橋六ヶ所請負→新坂下橋を含め七ヶ所化）の「6→7ヶ所」問題に対し、**文久3年の時点で橋数七ヶ所と裏付けられる datapoint**（六ヶ所から七ヶ所への増加が宝暦〜文久の間に完了していたことの確認。橋の内訳・時期の特定は本冊のみでは不可）。
- **金杉橋掛直の全記録〔確認〕**: 「**小石川金杉橋朽損ニ付掛直…**」——①仕様「**橋渡三間三尺 巾二間**」＝**金杉橋（小石川・白堀通）の橋渡り長3間3尺・幅2間**②入札「**落札直金弐拾壱両壱分三朱 銀弐匁七分五厘**」＝落札直段21両1分3朱銀2匁7分5厘③財源として「**白堀通渡賃銭残金**」の充当文言＝**渡賃銭（渡橋の通行料）の残金が組合橋の掛直財源に回っていた実務**④「**玄蕃石居付**」（玄蕃石の居付・石積の局部か・語義は要照合）⑤「**箱番屋一ヶ所**」＝掛直に併せ箱番屋（見守番屋〔[GOV-235](GOV-235.md)・[GOV-236](GOV-236.md)の白堀通商番屋・箱下水見守と同系の施設か〕）1ヶ所の記録。
- **「往来繁殊馬車等通行多場所」〔確認〕**: 金杉橋の文言に「**往来繁殊馬車等通行多場所**」（往来が繁く馬車等の通行が多い場所）と読める語句＝**文久3年時点の金杉橋周辺の交通の実態語**（幕末期に白堀通筋で馬車通行があったことを示唆・OCRの読み「繁殊」は要照合）。
- **玉川上水野方堀留村々分水見廻〔確認・千川上水系の周辺文言〕**: 玉川上水の「**野方堀留村々分水見廻**」の代官実務記録（見廻りの割り当て・伺いと読める文言）＝**野方堀留（千川上水の水源地帯・野方堀の通村々）の分水の見廻りが玉川上水方の業務であったことの文久3年の記録**（[GOV-211](GOV-211.md)（千川家と千川上水）・[GOV-222](GOV-222.md)（野方堀留の文言）と対照できる千川上水源流部の行政実務）。
