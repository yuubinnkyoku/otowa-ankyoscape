# [GOV-273] 玉川上水留 天保9〜10年 — 赤坂紀伊国坂通の石樋枡の修復

- **書誌〔確認〕**: 『玉川上水留』「玉川上水赤坂紀伊国坂通石樋枡潰(?)水留方御修復御組合入用一件　天保九戌年十二月より同十亥年三月迄」（全1冊）[book/2587350](https://lab.ndl.go.jp/dl/book/2587350)。repo未登録の冊（「薩摩小路」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔赤坂の紀伊国坂（紀州藩紀伊国坂上屋敷方面）を通る玉川上水の石樋枡の修復帳簿。〕
- **石樋77間3尺・入子木樋の構造〔確認・repo初出の定量記録〕**: 出来形——「**玉川上水赤坂紀伊国坂通一石樋長七拾七間三尺 大サ内法(十八?)幅四尺(深?)之三尺 右仕様石樋有来之侭差置 極(樋?)裏両側幅弐尺通割栗石足石いたし目潰砂利入詰**」＋「**一入子木樋長同断 大サ内法幅三尺弐寸深弐尺六寸**」＝**紀伊国坂通の石樋（内法幅4尺・深3尺・延77間3尺）の内側に、同長の入子木樋（内法幅3尺2寸・深2尺6寸）を差し込む二重管構造**＝石樋の老朽化に対し石殻を残したまま木樋を挿入して通水を確保する工法（断面寸法の「十八」「之」等のOCR崩れは要照合。「入子樋」は[GOV-275](GOV-275.md)虎御門外通・[GOV-274](GOV-274.md)紀伊国坂下石垣樋と同じ語彙）。
- **紀伊殿辻番所前石枡〔確認・repo初出の特定施設〕**: 「**一 紀伊殿辻番所前石枡内一入子木枡 大サ内法七尺四寸(?)深三尺七寸 壱ケ所**」＝**紀伊国坂上の紀州藩屋敷前の辻番所の前に玉川上水の石枡があり、その内に入子木枡を設けた**＝現在の赤坂・紀伊国坂付近の上水施設の位置を具体的に示す記録（「内法七尺四寸」は幅のOCR誤読の可能性が高く、石枡の内法寸法の確定には原文照合必須）。
- **工費680両と工期〔確認・周辺〕**: 「**玉川上水赤坂紀伊国坂通石樋枡潰水留方御修復御組合入用一金六百八拾両 御修復日積晴天百八十日 去戌九月晦日ゟ取掛当亥正月三日迄二出来 惣日数百八拾壱日**」＝**御組合入用680両・晴天日積180日・天保9(戌)年9月晦日取掛〜天保10(亥)年正月3日出来（惣日数181日）**（「潰水留方」は石樋の崩潰と水留のOCR併記と読めるが原字形要照合）。
- **薩摩小路組合年番〔確認・周辺〕**: 「**薩摩小路組合年番 松平甲斐守殿 石川近江守殿**」＝**天保9-10年の薩摩小路組合の年番は松平甲斐守（=大名家老・甲斐守に封じられた松平姓の家臣か、譜代大名かは当帳簿のみでは特定不能）と石川近江守**（[GOV-272](GOV-272.md)天保4年=小笠原佐渡守・亀井能登守・北條相模守・[GOV-277](GOV-277.md)安政3年=鍋嶋加賀守・朽木近江守・[GOV-279](GOV-279.md)安政4-5年=小笠原佐渡守・亀井隠岐守・北條美濃守と対校＝**薩摩小路組合の年番交代の系列**がこれで天保から安政まで繋がる。石川近江守と朽木近江守の近江守の重複は偶然か系譜か断定しない）。
- **水留の通達宛名〔確認・周辺〕**: 水留は「**上水赤坂紀伊国坂通樋筋御修復ニ付来ル三日明六時ゟ暮六時迄一日限水留いたし候**」の定型廻状で、大久保駿河守・松平左兵衛佐・松平飛騨守（肝煎）・松平豊前守ほか武家屋敷方に宛てられ、梅小路（?）・「御勘定奉行中」への先例触の文言も残る（人名のOCR崩れ多く要照合）。
