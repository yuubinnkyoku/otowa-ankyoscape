# [GOV-268] 神田玉川上水留 文久3年 — 助水（玉川→神田）の運用と野方堀の見廻りの実務記録

- **書誌〔確認〕**: 『神田玉川上水留』文久三亥年五月より十月までの分冊——分冊ノ二 [book/2587518](https://lab.ndl.go.jp/dl/book/2587518)（御畳小屋掛井戸其外御修復仕様注文帳＋達書群）・分冊ノ三 [book/2587519](https://lab.ndl.go.jp/dl/book/2587519)（玉川上水清水御屋敷弐重塀内高掛其外御修復仕様注文帳＋達書群）。**引用文言はすべてOCR由来で要原文照合。**
- **神田上水への「助水」の差塞・半減・皆明け〔確認・repo初出の運用記録〕**: 玉川上水の水元（羽村）の出水・「水仕掛」の修理に伴う江戸掛（江戸への通水）減水の時期に、神田上水への**助水**（玉川上水から神田上水への補給水。野方堀＝千川上水跡の経路と読める）の分水口の操作が繰り返し記録される——
  - 「**玉川上水相減江戸掛御差支ニ相成候間 神田上水江之助水堀分水口 先達而皆留申渡置候処 申立之儀も有之間半減之差塞之儀 淀橋久兵衛え申渡候間**」（2587518・八月）＝**江戸掛減水のため神田上水への助水の分水口を一旦皆留め、申立により半減の明け方へ変更**という操作の文言。
  - 淀橋町（OCR変種：濱橋・溢橋）の**水車持久兵衛**の難渋歎願（文久3年8月12日の願）：「**当夏分ゟ引続濁水多ニ而渡世向舂挽等手後ニ相成…猶又減水仕休直し同様二相成 其上私共義は是迄堀井等一切無御座候上水而已呑水に相用居引取候御差留被為仰付居候而は実以難渋仕候**」＝**濁水と減水で水車の舂挽（精米）の渡世が立ち行かないこと・堀井（掘り井戸）がなく上水の水を呑水（飲料水）に使っていること**を理由とする願出。
  - 「**殊ニ可成水掛り方ニも相成御差支と申程ニも無之候間 旁以半減之明キ方去ル十二日申渡…四谷大木戸水番人半四郎立合**」（2587518）→九月四日「**此節元水相増候間是迄之通皆明之儀申渡候**」＝**8月12日半減開け→9月4日皆開け**の復旧の年月日。
  - 「**明日淀橋水車久兵衛引取上水堀え堰板仕付可申旨**」（2587519・九月十一日の達の取止めの記録）＝**久兵衛が自分の引取上水堀に堰板を仕付ける**操作の文言＝淀橋町水車持久兵衛の引取堀と助水の分水口の操作が連動して記録される（**久兵衛の水車の位置と引取堀の経路＝助水経路との関係は本冊のみでは確定できない・原文照合後に判断**）。
- **野方堀通村々分水口の見廻りの実務〔確認・repo初出の行程レベルの記録〕**: 「**玉川上水水元相減江戸掛差支候に付 野方堀通村々引取分水口為見廻り差遣置候様…御普請方同心山口清三郎 地割棟梁天野勝右衛門 今朝四谷大木戸水番屋え相揃出立仕候**」（九月八日出立）＝**玉川上水の減水時に、野方堀沿いの村々の引取分水口を確認するため、御普請方の同心と地割棟梁が四谷大木戸から出立して堀通を見廻る**という助水管理の実務の行程記録——
  - 触書の宛先は「**内藤新宿同口屋…高井戸村・境村・鈴木新田・山川村・砂川村・熊川村 右宿村々問屋名主**」＝**四谷〜羽村間の宿村の継送（人足・旅宿の用意）**のリスト（玉川上水沿いの宿駅の確認にも使える）。
  - 見廻りの復命に「**野方堀通分水口壱歩(処?)通差塞之儀は是迄之通居置**」（九月二十日）＝分水口の閉塞状態の確認文言。
  - [GOV-245](GOV-245.md)（文久3年の野方堀留村々分水見廻の文言）・[GOV-246](GOV-246.md)（慶応4年の野方堀通村々流水の経路文言）の**文久3年側の実務の詳細**として対校できる。
- **砂川村地内の「助水落口」と高札2ヶ所・「助水道」の制札文言〔確認・repo初出〕**: 「**玉川上水野方堀通砂川村地内狭山池(?)ゟ之助水落口并同村地先共高札弐ヶ所仕直仕様注文帳**」（2587519・亥十月）＝
  - **野方堀通の砂川村地内に「助水落口」があった**ことを示す帳簿名（**「狭山池」の部分はOCR高度崩れの候補・原字形照合必須**。砂川村は千川家（千川善蔵・千川平吉）の村で、[GOV-251](GOV-251.md)の「玉川十九分水増水口共堰科」の負担と関係する可能性があるが断定しない）。
  - 高札の仕直の仕様（檜板・蟻筏木・串柱・粟丸太等の寸法つき）と、**高札の文言「従此上水助水道におゐて水をあひ魚鳥を取ちり芥捨物あらふ輩あらは可為曲事」**＝**「助水道」という呼称で、助水の水路での魚鳥捕獲・芥捨て・洗い物を禁じる制札の文言**＝助水の水質保全の高札が野方堀沿い（砂川村地先）に建てられていた一次記録。
- **井之頭池の水草刈〔確認・周辺〕**: 「**神田上水水元井之頭池水草生立候ニ付乍行二相障候場所刈取其外為御用…今朝四谷大木戸水番屋え相揃出立仕候**」（2587519・九月十二日・池田孝市ほか）＝**神田上水の水元（井之頭池）の水草刈取りの実務記録**（[GOV-246](GOV-246.md)の「吉祥寺村井之頭弁天池湧出水ニ而野方堀通…」の経路文言の水元側の補強）。
- **関口水番人喜三〔確認・周辺〕**: 「**関口水番人喜三**」の宛名（2587519・九月十一日）＝[GOV-246](GOV-246.md)の水番人小兵衛・[GAZ-048](../gazetteers/GAZ-048.md)の大洗堰の水番人小屋と並ぶ**関口の水番人の実名の異なる例**（同一人物かは断定しない）。
