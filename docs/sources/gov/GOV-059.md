# [GOV-059] 千川元上水堀通見分絵図（都公文書館蔵）

- **所在確認（2026-11-11、閲覧停止資料一覧PDFを直接確認）**：東京都公文書館が「当館展示による原本閲覧停止資料一覧（令和8年5月22日）」で、**江戸明治期史料006362「江戸川、神田上水川、千川元上水堀通見分絵図」（請求番号 626.A2.26）を令和8年5月22日〜7月14日の期間、展示に供し原本閲覧を停止**していたことを確認。
- **意義〔観察〕**：「千川元上水」（＝千川上水の旧称とみられる）の堀通の見分絵図という**一次史料の実在が公文書館の公式文書で確認できた**。江戸川・神田上水と併記されており、水系全体の堀通を見分した絵図と推定される。内容（年代・描かれた区間・流路の描写）は未確認。
- **制限〔未解決〕**：絵図そのものの閲覧は未実施。**本資料で千川上水や谷端川分水の流路・年代を主張しない**。次回以降、公文書館情報検索システム（archives.metro.tokyo.lg.jp）で請求番号 626.A2.26 を引き、デジタル画像の有無・請求しての閲覧を確認する実見候補として登録。
