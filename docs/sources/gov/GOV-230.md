# [GOV-230] 諸問屋名前帳 [13] — 千川屋敷の舂米屋の屋号・人名

- **書誌〔確認〕**: 『**諸問屋名前帳 57巻**』の[13]（舂米屋 拾三番組・拾四番組）。NDL次世代デジタルライブラリー [book/2548734](https://lab.ndl.go.jp/dl/book/2548734)。幕末〜明治初頭期の舂米屋（精米業者）の名前帳。**引用はOCR由来で文言は要原文照合。年代は帳簿の性格から推定（要照合）。**
- **千川屋敷の舂米屋「越後屋庄次郎」〔確認・屋号・人名の初出〕**: 拾四番組のリストに——「**舂米屋 小石川白山前千川屋敷 越後屋庄次郎**」〔**小石川白山前町千川屋敷に舂米屋（越後屋庄次郎）が登録されていたこと＝千川屋敷内の業者の屋号・人名の一次記録**〕〔[GOV-223](GOV-223.md)（第109回・諸問屋名前帳[39]の千川屋敷の両替屋）と同じ帳簿シリーズの別巻で、千川屋敷の業態構成（舂米屋・両替屋）を補う。千川屋敷が賃貸・営業地として機能していた実態の追補資料〕〔周辺の舂米屋（小石川下富坂町・善仁寺門前・蓮花寺門前・白山大道通・駒込片町等）の並記も小石川白山周辺の精米業の分布の参考記録〕。
