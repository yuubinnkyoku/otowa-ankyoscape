# [GOV-239] 川浚 第2冊 — 三橋川の定渡請負と江戸川の川原管理区画

- **書誌〔確認〕**: 『川浚』第2冊 [book/2547756](https://lab.ndl.go.jp/dl/book/2547756)（[GOV-169](GOV-169.md)『川筋浚書留』と同系の幕府の川浚・橋関係留帳）。**「明和四亥年ゟ享和二戌年至 三橋川之定渡受負人并永代橋懸り名元近辺一件」**＝明和4年（1767）〜享和2年（1802）の記録で、**「明和四年永代橋・神田川新大橋・江戸川橋請負并後初敷手形帳写道役扣」**（永代橋・神田川の新大橋・江戸川橋の三橋の請負＝「三橋川」の語の由来か・要照合）を含む。OCR全文精読。**引用文言はすべてOCR由来で要原文照合。**
- **江戸川の川原管理区画〔確認・repo初出の文言〕**: 「**舟河原橋ゟ関口大洗堰迄拾五町 都合四拾九町之場所川崎之儀 柳橋ゟ牛込御門下迄は永代橋掛 舟河原橋ゟ大洗堰立江戸川筋は新橋掛り者共相願 橋渡銭永々被仰付 外引高助成地永代橋掛り江…**」（前後の文言は反復・OCR崩れあり）＝**①江戸川（神田川）の柳橋（下流端・浅草側）から関口大洗堰（上流端）までの49町の川原（「川崎」＝川原と読める・要照合）の管理が、柳橋〜牛込御門下の34町は「永代橋掛」（江戸川橋の永代請負人側）、舟河原橋〜大洗堰の15町は「新橋掛」（新規に橋を掛けた者側）に区分される**〔**②江戸川の上流区間（牛込御門〜大洗堰）の川原の帰属を、舟河原橋を境目として15町と定量的に記録する**＝[GAZ-049](../gazetteers/GAZ-049.md)⑬の江戸川の枝流考証（分派点関口水道町の西・大曲り→船河原橋）の「船河原橋」と本資料の「舟河原橋」の対応（同一橋の表記差か別地点か）が対校課題、**③橋渡銭が「永々被仰付」され、「外引高助成地」が永代橋掛に与えられた**＝江戸川の橋の維持の経済構造の記録〕。
- **神田川出水の土砂〔確認・参考〕**: 「去巳八月神田川出水に付 江戸川神田河筋土砂押出シ埋り候ニ付 柳橋合ゟ牛込御門下立三拾四町…」＝**巳年8月（宝暦4年1754か・明和6年1769か・年次特定は要照合）の神田川出水で江戸川・神田川筋に土砂が押し出されて埋まった**旨の文言〔江戸川（神田川）の上流部の出水・土砂記録として[BOOK-132](../books/BOOK-132.md)（明治期の出水記録群）以前の18世紀の例の候補。年次の割付は原文照合後に判断〕。
- **位置づけ〔観察〕**: 江戸川（神田川）の上流端である**関口大洗堰までの区間が、川原の管理単位として49町区画のうち15町（舟河原橋〜大洗堰）として定量的に把握されていた**ことの初出記録。大洗堰（[GAZ-048](../gazetteers/GAZ-048.md)関口の瀧・摺鉢の瀧・[GOV-236](GOV-236.md)巡視路の中堤）が江戸川の川政の上流端として機能していた傍証。橋渡銭・外引高助成地の文言は、[GOV-237](GOV-237.md)明治2年の渡賃銭による白堀の浚渫費と系譜的につながる料金負担構造の18世紀の記録候補。
