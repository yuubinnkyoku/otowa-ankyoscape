# [GOV-235] 市中取締類集 上水番等之部 — 神田上水の見守番屋と湯茶商の拝借

- **書誌〔確認〕**: 『市中取締類集』（町奉行関係の例集）[149]上水番等之部 [book/2572175](https://lab.ndl.go.jp/dl/book/2572175)。弘化3年（1846）の取調。OCR全文精読。**引用文言はすべてOCR由来で要原文照合。**
- **見守番屋取調〔確認・repo初出〕**: 神田上水の**見守番屋**の取調で、**赤坂御門外・榎坂水道橋・白堀通**の場所に商番屋5ヶ所があり「相洩れ」（5ヶ所が調べから漏れていた旨か・読み要照合）との文言＝**弘化3年時点の見守番屋・商番屋の所在が白堀通を含む3系統で記録される**〔白堀通の見守番屋の実在＝[GAZ-049](../gazetteers/GAZ-049.md)⑬の「見守番屋」（16坪2合5勺）・[GOV-236](GOV-236.md)の見守喜兵衛・武兵衛の御請書と対校する町奉行側の記録。「榎坂水道橋」は[GAZ-049](../gazetteers/GAZ-049.md)の榎坂（水道橋付近の坂）と対応候補〕。
- **喜兵衛・武兵衛の湯茶商拝借〔確認・repo初出〕**: ①**本郷元町平次郎店・喜兵衛**——小日向水道町の**水附除地**に商番屋と物置を構え**冥加金3両/年**を上納する湯茶商の拝借文言。②**関口水道町伝左衛門店・武兵衛**——**小石川諏訪町角**に商番屋を構え**1両2分/年**の文言〔**喜兵衛・武兵衛の2人の屋号（店先）と年額が[GOV-236](GOV-236.md)（諸証文留帳）の見守喜兵衛・武兵衛の御請書（地代金3両宛・年2回上納）と対応する**＝見守番屋の商番屋拝借の町奉行側・旧幕引継側の2系統の記録。「水附除地」＝上水に附した除地と読める（要照合）〕。
- **位置づけ〔観察〕**: [GAZ-049](../gazetteers/GAZ-049.md)⑬⑦（見守番屋16坪2合5勺・番人喜兵衞・冥加金3両・年2回上納）で初出になった**白堀通の見守番屋制度を、町奉行の取調記録（本資料）と旧幕引継の証文（[GOV-236](GOV-236.md)）の二系統から裏付ける**。弘化3年（1846）は[GOV-232](GOV-232.md)の白堀通大規模普請と同年で、**普請の実施年度に見守の拝借も組み直された**可能性がある（断定はしない）。
