# [GOV-203] 議事速記録 第10号 — 三河川年度割再延長・道路告示509号案（1936）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第10号』（議第188号議案〔道路受益者負担〕特別委員会第一回1936〔昭和11〕年11月4日開会ほかを収録）。NDL次世代デジタルライブラリー [book/1207652](https://lab.ndl.go.jp/dl/book/1207652)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **三河川年度割の再延長〔確認・repo初出・要照合〕**: 幹事高橋登一の説明「是ハ**神田上水、立會川、谷端川、三河川ノ改修事業ノ執行年限ヲ一箇年延長致シマシテ**…此ノ事業ハ**經費五百六十二萬圓**ヲ以チマシテ、**昭和五年度カラ昭和十一年度ニ至リマス、七箇年繼續事業**トシテ東京府知事ニ於テ執行中ノモノデアリマス**三河川中立會川ト谷端川ノ方ハ既ニ昭和九年度ニ完成致シマシテ**、神田上水ノ方ハ本年度ニ完成スル筈ニナツテ居リマシタ所ガ、**用地ノ買收、物件ノ移轉ナドニ非常ニ手間取リマシタノデ**、已ムヲ得ズ事業年度ヲ一箇年延長致シマシテ」→原案通り可決（動議山口久太郎41番・会長代理館哲二）。対照表は昭和5〜10年度＋11年度＋12年度（既定・変更後の各年額はOCR列崩れ・要照合）。＝**1936年11月時点で「立会川・谷端川は既に昭和9年度（1934年度）に完成」を幹事が委員会で公式に説明した記録**。
- **道路告示509号案の千川町〔確認・参考・要照合〕**: 同号収録の内務省告示第509号案「東京都市計画道路中左ノ路線ヲ都市計画事業トス」の路線一覧（幹線放射道路・幹線環状道路・補助線道路、執行年度割は昭和11〜18年度）の起終点に「**豐島區千川町二丁目**」が現れる〔どの路線番号かはOCR列崩れで特定不能・**現行道路（環六など）への対応は断定しない**〕。
- **位置づけ〔観察〕**: [GOV-161](GOV-161.md)（1935-12・昭和11年度まで延長・563万余円）の後の**再延長（→昭和12年度）**で、三河川改修の予算・期間変遷の最終段階に当たる。完成文言は[GOV-186](GOV-186.md)（1940・「既ニ昭和九年ニ完成」）・[GOV-205](GOV-205.md)（1935・昭和9年度末完成公表）に先行する1936年時点の確認。
