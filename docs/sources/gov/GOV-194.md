# [GOV-194] 醸造試験所要覧（1909年）— 「逆川」の1909年一次文言と千川用水の域内貫流

- **書誌〔確認〕**: 大蔵省印刷局から農商務省へ移管された醸造試験所の『醸造試験所要覧』（1909年・明治42年頃の内容を含む）。NDL次世代デジタルライブラリー [book/848109](https://lab.ndl.go.jp/dl/book/848109)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **所在地の地勢〔確認・repo初出の「逆川」文言〕**: 「**東ハ逆川ヲ隔テテ飛鳥山ニ接シ**、西北ハ瀧野川ノ〓流ニ臨ミテ王子權現ト相對シ、**南方一帶耕地ニ接シ千川用水南ヨリ來リテ域内ヲ貫流シ用水引用ノ便アリ**」＝**醸造試験所（旧幕府反射炉→大蔵省印刷局用地）敷地の東を「逆川」が流れ、千川用水が域内を南から貫流した**1909年の一次記述。「逆川」は王子川筋（石神井川）の分派・王子の字逆さ川（GOV-157系・BLOG-241系）との関係が想定されるが、本文のみでは確定しない（断定しない）。〔文言はOCR要照合〕。
- **千川用水の工業利用設備〔確認〕**: 「**敷地内ヲ流過スル千川用水ヲ利用シ工場用水ヲ補給スルノ目的**ヨリ」煉瓦造砂濾過池（砂濾過面積150平方尺・分水槽・溜水槽・水量調整装置つき・交代使用）を設置、濾過水を井水と混合し醸造試験機器（「アムモニヤ」冷縮機）に供給、「**使用後ハ直ニ水路ニ復歸スルコト**」＝**明治36年頃の千川用水の工業用水循環利用の設備記録**。〔文言・数値はOCR要照合〕。
- **沿革〔確認〕**: 元治年間に幕府が買上げた反射炉用地→明治初年廃止→大蔵省・陸軍省用地→明治11年9月に大蔵省印刷局が設置→**明治35年10月13日、土地4,929坪7合1勺・建物4棟を農商務省が授受**（明治36年11月に道路敷地74坪2合5勺も引き継ぎ）＝[GOV-157](GOV-157.md)（NDA明治期滝野川村官用地記録群・1902年転換・1903年醸造試験所用地編入）の**官庁側（授受側）沿革記述**。〔文言・数値はOCR要照合〕。
- **地質〔確認〕**: 「王子川沿岸廣袤數百間ハ礫ヲ挾雜セル砂層」で基礎工事中に地下水の湧出なし＝王子台地の地質記録。〔「若子川」は「王子川」のOCR判読推定・要照合〕。
