# [GOV-055] 豊島区プレスリリース「4月1日、池袋地名ゆかりの地に『元池袋史跡公園』オープン」（1998年3月31日）

- **書誌〔確認：原PDF1頁を視認〕**：平成10年3月31日付・豊島区プレスリリース、題「4月1日、池袋地名ゆかりの地に『元池袋史跡公園』オープン」。問い合わせ＝公園緑地課長。スキャンPDF（テキスト層なし・1頁）。
- **所在〔確認〕**：東京都豊島区「adeac」デジタルアーカイブ pressH100331。https://adeac.jp/viewitem/toshima-history/viewer/viewer/pressH100331/data/pressH100331.pdf
- **内容メモ〔確認：原PDFの直接判読〕**：
  - JR池袋駅西口近くにかつて「丸池」があり、「池袋」の地名由来と考えられる。**丸池があった場所「近くに」**1998年4月1日元池袋史跡公園がオープン（公園＝丸池そのものの位置ではない）。
  - 丸池のあった辺りはかつて「**池ケ谷**」と呼ばれ、「**池ケ谷の月**」と称された月の名所・蛍の群飛名所といわれる。
  - **明治45年（1912）この地に成蹊実務学校（現成蹊学園）創設**。**大正14年（1925）武蔵野市吉祥寺へ移転するまで丸池は湧水も枯れず「成蹊池」とも呼ばれ**、中で学生が泳いだ。
  - その後**学校跡地は鉄道教習所**となり、池は次第に縮小・周囲を石材で築き**コンクリート造りの池**となった。**戦後は元池袋公園の敷地となり、水も枯れ石積だけが残る**状態となった。
  - 公園の植え込み内に新しい池を作り、「**池袋地名ゆかりの池**」「**成蹊学園発祥之地**」の2碑を設置。広場に月の満ち欠けと星のデザイン・特殊照明。
  - 元池袋史跡公園：①所在＝**豊島区西池袋1丁目9番**（JR池袋駅西口徒歩3分）、②面積＝**167.98㎡**。
