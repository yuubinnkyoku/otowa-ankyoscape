# [GOV-096] 豊島区「わが街ひすとりぃ」基本情報・雑司が谷

- **資料〔確認〕**: 豊島区デジタル区史「わが街ひすとりぃ」基本情報「雑司が谷（一丁目～三丁目）」（**平成30年度**、基本データは平成30年1月現在と記す。adeac掲載PDFをopen_urlで直接取得）。出典：[原文PDF](https://adeac.jp/viewitem/toshima-history/viewer/viewer/content01_v8info/data/content01_v8info.pdf)。同シリーズの[GOV-034](GOV-034.md)（池袋）・[GOV-035](GOV-035.md)（池袋本町）と並ぶ雑司が谷版。地名対照表の雑司ヶ谷行を監査した[2026-10-26・追加監査ノート](../../2026-10-26・地名河川名対照表・追加監査.md)が「歴史表記」の出典URLとして参照済みだが、本ファイルが本文内容の初の資料化。
- **古文書初見〔確認：区資料の記述／原本未照合〕**: 雑司が谷の名が古文書・記録に見えるのは**永禄2（1559）年の『小田原衆所領役帳』が初めて**と明記。〔池袋村の永禄2年既存説（[BLOG-084](../blogs/BLOG-084.md)）と同一史料だが雑司が谷項目としての初見指摘はrepo初出〕
- **地名由来4説〔確認：区資料の列挙〕**: ①法明寺の雑司料、②小日向金剛寺の雑司料、③元弘・建武の頃、後醍醐天皇に仕えた北面の雑司・柳下若狭助・長島内匠助・戸張平次左衛門尉等が南朝衰退を嘆いて官を辞し土着、子孫が村民として残った、④身分のある人の子息の子を指す「曹司」から。〔[BLOG-188](../blogs/BLOG-188.md)（wanjin）の転記諸説の**区公式版による独立裏付け**。人名は「柳式若狭」ではなく**柳下若狭助**と記す（表記差は断定せず並記）〕
- **表記史〔確認〕**: 「曹司谷」（『江戸雀』『江戸名所記』）、「僧司ヶ谷」（『御江戸図説集覧』）、「雑司ヶ谷」（『遊歴雑記』）、「雑司谷」（『江戸名図会』）、「蔵主ヶ谷」「雑士ヶ谷」（『新編日本風土記稿』）と出典書名を添えて整理。〔対照表監査の雑司ヶ谷行（曹司谷・僧司ヶ谷・蔵主ヶ谷等）の**出典付き裏付け**]
- **吉宗の表記統一伝承〔伝聞：区資料も「伝えられる」と記す〕**: 徳川八代将軍吉宗が放鷹のために立ち寄った時「雑司ヶ谷村」と書くべしとしたと伝える。
- **住居表示〔確認〕**: **昭和41年の住居表示実施の際「雑司ヶ谷町」から現在の「雑司が谷」に変更**（町名変更年次＝repo初出）。
- **柳下家〔確認：区資料のスポット一覧〕**: エリア内の主なスポットとして「柳下家」を掲載〔由来説③の柳下氏の子孫と主張する家の現存を区資料が掲載する形。断定はしない〕。
- **弦巻川との関係〔観察〕**: 本資料自体は河川に言及しないが、雑司が谷は弦巻川・水窪川の谷筋に開けた土地であり（[BLOG-188](../blogs/BLOG-188.md)・[ORG-021](ORG-021.md)参照）、地名史は弦巻川流域の地区史資料として扱う。
- **制限〔未解決〕**: ①『小田原衆所領役帳』該当部の原文未照合。②由来説の当否について区資料自身も「定かではない」と記す。③柳下家の由来説③との関係は区資料の明記ではなく推測とする。
