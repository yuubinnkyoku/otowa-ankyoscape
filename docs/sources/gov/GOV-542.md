# [GOV-542] 官報 令和7年10月24日 関東地方整備局公示欄公告〔環七地下調節池第5号・第6号の施行期間等・repo初出の官報レベル文言群〕

- **書誌〔二次: kanpo-backup.com収蔵の官報令和7年10月24日号〕**: 関東地方整備局の公示欄公告。**OCRが多段組インターリーブしている**ため、以下に再構成した文言の**法条（建築基準法77条の21公示欄か都市計画法63条公告欄か）・告示番号の列帰属は未確定**＝官報原本（NDL・官報情報検索センター）での最終照合を要する（この制限は正直に維持する）。
- **公告本文の中核文言〔二次・OCR再構成〕**: 「建築基準法（昭和二十五年法律第二百一号）第七十七条の二十一第一項の規定に基づき、平成十三〔年…公示．…〕」＋表項目＝**「事業 第五号石神井川及び第六号神田川／事業施行期間 自平成二十八年四月一日 至令和十四年三月三十一日／都市計画事業の種類及び名称 平成二十八年関東地方整備局告示第百七十六号 東京都市計画河川／施行者の名称 東京都／事業地使用の部分変更なし 収用の部分変更なし**」＋署名＝**「令和七年十月二十四日 関東地方整備局長 橋本雅道**」。同じ頁に隣接して**「〇関東地方整備局告示第二百十三号の変更を認可したので、同条第二項の規定において準用する同法第六十二条第一項の規定に基づき、都市計画法（昭和四十三年法律第百号）第六十三条第一項の規定により、都市計画事業の事業計画〔…〕」**の文言と、「〇関東地方整備局告示第二百十四号 年関東地方整備局告示第二百五十号の一部を次のように改正する…」（収用事業の指定有効期間関係の文言）が混在して見える。
- **意義〔観察〕**: ①**都市計画事業「第五号石神井川及び第六号神田川」（＝環状七号線地下調節池の石神井川区間・神田川区間）の事業施行期間が「平成28年4月1日から令和14年3月31日まで」と官報レベルで公告されている**＝環七第5・6号の施行期間の上限（2024年時点の計画より2032年3月末まで延長された形）を示す文言としてrepo初出候補〔令和14年3月31日＝2032年3月31日。**従来repoに収録した施行期間文言との差分照合は次回課題**〕。②「都市計画事業の種類及び名称＝**平成28年関東地方整備局告示第176号 東京都市計画河川**」という名称文言が官報レベルで出ることも初出に近い（[GOV-538](../gov/GOV-538.md)の中野区資料の「告示第208号」等の告示群の上流側に当たる平成28年告示の体系を示す）。③**令和7年10月24日付の公告であること自体**が、[GOV-486](../gov/GOV-486.md)の令和7年10月〜11月の工事着手期（第242回のスケジュール文言）と同時期の事業側の行政動作の痕跡。
- **制限・未解決**: ①**法条と告示番号の対応**＝「第百七十六号」（事業の名称由来）、「第二百十三号」（変更認可対象）、「第二百十四号」（別件・道路区域）の3つの番号が同じ頁に混在するため、どの法条（建基法77条の21公示か都市計画法63条公告か）でどの告示が運用されているかは**官報原本のhuman目視で確定するまで断定しない**（第275回以降の課題）。②公告の冒頭「平成十三〔年…〕」の欠落部（建基法77条の21公示に基づく平成13年の?公示の参照文言と読めるが）は欠損ママ記録。③kanpo-backup.comは非公式ミラーで、正式引用には官報原本の頁番号確認が必要。④[GOV-541](../gov/GOV-541.md)と同じく、関東地方整備局告示第37号（R7.2.27・kanpo-backupの圏外）の取得は次回以降。
