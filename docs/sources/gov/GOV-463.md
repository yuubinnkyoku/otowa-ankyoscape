# [GOV-463] 正宝録続 七 — 安永9年樋掛渡の触と水銭28文の原文言

- **書誌〔確認〕**: 『正宝録続』[七]（江戸後期の幕府公用文書の編纂集・編者未詳・NDL次世代デジタルライブラリー [book/2547511](https://lab.ndl.go.jp/dl/book/2547511)・OCR丁起こしで崩れ大）。**引用文言はすべてOCR由来で要原文照合**。
- **安永9子年10月の千川上水樋掛渡の触〔文言候補・本登録の核心〕**: 「**子十月廿九日(?)…今日牧野大隅守様片番所に而千川上水樋を渡り候町々名主月行事幷請負人長十郎外三人之召出 此度千川上水先年之通町々樋を渡候義願人有之 右水筋町々一町井戸一ツ宛懸渡候ニ付道筋（以下OCR崩れ）**」＝**①安永9子年（1779-80）10月、牧野大隅守信彭の御番所（片番所）で千川上水の樋を掛け渡す町々の名主・月行事ならびに請負人長十郎外三人が召し出され、②「先年之通町々樋を渡す」旨の願人があった右水筋は町々ごとに井戸一つ宛を掛渡す、という触文言**。〔**GAZ-041〜045（御府内備考系・安永九子年十月廿七日牧野大隅守様御番所御掛にて上水掛渡之儀被仰付）の町方書上側文言と対校する、公用文書編纂集側の同じ一連の触**。日付の「廿九日」はOCR崩れ候補で「廿七日」との対立は併記・原字照合まで断定しない。請負人「長十郎」は天明撰要類集側の差止文書の「神田相生町喜兵衞地借長十郞」と同人候補〕。
- **一町井戸一ツ宛の原則文言〔文言候補・repo初出〕**: 「**右水筋町々一町井戸一ツ宛懸渡候ニ付**」＝**掛渡しは町ごとに井戸一つ宛（一町一井戸）を給水単位とする原則文言**。〔**千川上水再興の給水設計（樋ではなく井戸単位）を、町方書上（GAZ-041〜045の樋延長の町別リスト）と別角度から規定する文言候補。これまで御府内備考系・町方書上のいずれ側にも対応文言がなかった点で新規層〕。
- **水銭廿八文の取立文言〔文言候補・収入側の原規定〕**: 「**亥十一月町屋表通小間一間二付一ヶ月水銭として廿八文宛取立候間組合限取集右御番所え相納**」＝**①安永8亥年（1779）11月から安永8亥年（1779）11月からの文言の帰属は前後文でOCR要照合町屋表通の小間一間につき一ヶ月水銭28文宛を取立て、②組合限りで取り纏め、③右御番所（牧野大隅守番所）へ相納する**。〔**水銭28文/小間/月（GOV-224〔駒込側の水銭〕・GAZ-082〔上野山下の水錢月々四百四文〕・GOV-352〔神田旅籠町〕の既知文言群）の収入側の原規定文言。集金主体が「組合限」で、納付先が番所である実務構造を、記録側（町方書上）ではなく公用文書側から初めて明文化する**〕。

## 制限・未解決

- ①帳簿体裁のOCR崩れが大で、「子十月廿九日」の日の判読（廿七日说=GAZ-041〜045との対立）、「亥十一月」の条の帰属（安永8か安永9か）ともに原画像照合が前提。②「請負人長十郎」が千川家の請負人か、地主・店借側の請負人かは本文言単独では確定できない（GAZ-041の発願人宇田川長十郎との同名対校課題として残す）。③「一町井戸一ツ宛」が全町一律の原則か典型例の記載かは本資料では確定できない。
