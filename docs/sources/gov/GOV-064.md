# [GOV-064] 「【玉川上水】千川分水」ガラス乾板写真

- **資料〔確認：東京都水道歴史館デジタルアーカイブ目録、2026年11月11日閲覧〕**：同館デジタルアーカイブ「[【玉川上水】千川分水](https://www.ro-da.jp/suidorekishida/content/detail/REKI-039-015)」、**資料ID REKI-039-015**、ガラス乾板写真、寸法W16.5×H12.0cm、制作者**東京市水道局**、制作年月日**大正14年（1925）**。
- **地域・備考〔確認：目録表示〕**：地域・施設名は**「玉川上水／千川上水／千川分水／千川用水／西東京市」**。備考「『200』とあり。目録に原タイトル『千川分水』とあり」。公開日は2021年8月4日（撮影日ではない）。
- **repoでの位置づけ〔推定〕**：千川上水が玉川上水から分水する取水点（千川分水）を**1925年時点**に写したとされる写真史料で、水路図・絵図（[MAP-060](../maps/MAP-060.md)等）とは別種の視覚資料として、取水点周辺の地物・水量の検証候補。**写真画像そのものの判読は未実施**で、撮影地点の座標・図中の地物は未確認。1925年は目録の撮影年表示であり、分水口の開設年・改修年ではない。
