# [GOV-275] 玉川上水留 弘化3年 — 虎御門外通の入子樋枡普請と給水組合の触出し網

- **書誌〔確認〕**: 『玉川上水留』「玉川上水虎御門外通入子樋枡御普請一件　弘化三丙年三月より同年九月迄」（全1冊）[book/2587364](https://lab.ndl.go.jp/dl/book/2587364)。repo未登録（「薩摩小路」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔虎御門（現在の虎ノ門・西ノ門付近）外の玉川上水樋管の普請帳簿。〕
- **虎御門外通の入子樋枡普請と1日水留〔確認・周辺〕**: 「**玉川上水虎御門外通入子樋枡御普請ニ付御(?)十三日明ヶ六時ゟ暮六時迄一日限致水留候 尤御成雨天は日送り之積り**」＝**弘化3年閏5月13日に虎御門外通の入子樋枡の普請のため1日限の水留（明6時〜暮6時）**（「閏五月」のOCR崩れあり・[GOV-272](GOV-272.md)・[GOV-273](GOV-273.md)と同型の運用）。「虎御門外御普請方会所江返却」の文言＝普請会所が虎御門外に置かれた。
- **御門々への触出しの定型リスト〔確認・repo初出の給水樋筋が城内の御門群に掛かることの明示〕**: 「**御門々江相掛り不申候卯(?)桜田御門 馬場先御門 和田倉御門 呉服橋御門 鍛冶橋御門 日比谷御門 幸橋御門 数寄屋橋御門 山下御門 虎御門 右番頭中後以増上寺役人中**」＝**玉川上水の市中樋筋（虎御門外・日比谷方面）の水留の際、外桜田・馬場先・和田倉・呉服橋・鍛冶橋・日比谷・幸橋・数寄屋橋・山下・虎の各御門の番頭と増上寺役人に触れ出す定型文**＝**玉川上水の水が江戸城外堀の御門群（山下御門・数寄屋橋御門・虎御門等）に給水していることの帳簿側の明示**（[GOV-276](GOV-276.md)嘉永5・[GOV-277](GOV-277.md)安政3・[GOV-279](GOV-279.md)安政4-5・[GOV-280](GOV-280.md)安政4-5とほぼ同じ御門リストが反復される＝玉川上水の城内・城外給水の管理体制の定型）。
- **給水組合の年番リスト〔確認・repo初出の麹町・虎ノ門方面の給水網〕**: 「**浜掛組合年番 脇坂淡路守殿 稲葉富(?)太郎殿 愛宕下大通組合年番 松平陸奥守殿 一柳土(佐?)守殿 秋田小路組合年番 植村出羽守殿 佐久間小路組合年番 松平兵部(?)(?)殿 藪小路組合年番 木下左衛門佐殿 相良遠江守殿 薬師小路組合年番 井上隠之助殿 神保小路組合年番(?)…薩摩小路組合年番 鍋嶋紀伊守殿 松木近江守殿**」＝**弘化3年時点の虎御門・愛宕下・溜池方面の給水組合（浜掛・愛宕下大通・秋田小路・佐久間小路・藪小路・薬師小路・神保小路・薩摩小路）の年番の大名列**＝**現在の虎ノ門・西新橋・新橋・愛宕・芝方面に玉川上水の給水樋管の利用組合が存在した記録**（[GOV-270](GOV-270.md)文久3年・[GOV-272](GOV-272.md)天保4年と併せ、薩摩小路組合の年番交代の系列に弘化3年=鍋嶋紀伊守・松木近江守を挟むことができる）。
- **葵坂下〜虎御門外の樋筋の道直し〔確認・repo初出の工区の文言〕**: 「**葵坂下ゟ虎御門外迄樋筋足土持込道高下直いたし砂利敷平坂 右之通御普請致出来候**」＝**葵坂（現在の赤坂・溜池方面の坂）の下から虎御門外までの樋筋に沿って、土の持込み（足土）・道の高下の直し・砂利敷を行った**＝樋管普請に伴う樋筋沿道の整備の文言で、**葵坂〜虎御門外の樋管の経路（現在の赤坂〜虎ノ門間）の通過を示唆**（経路の完全な復元には[GOV-277](GOV-277.md)安政3年の経路文言・[GOV-279](GOV-279.md)の麹町大通系の文言との対校を要す）。
