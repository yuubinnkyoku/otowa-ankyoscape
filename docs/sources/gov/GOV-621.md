## SEMIS機械到達の手順（GETレシピ・2026-11-27時点）

1. `GET https://www.gesuijoho.metro.tokyo.lg.jp/semiswebsystem/LoginSkip.aspx?ReturnUrl=%2fsemiswebsystem%2f`（同意頁・cookie jar付）→ form1 の `__VIEWSTATE` `__VIEWSTATEGENERATOR` `__EVENTVALIDATION` を抽出。
2. `POST https://www.gesuijoho.metro.tokyo.lg.jp/semiswebsystem/TspAgreementWeb.aspx` に `__EVENTTARGET=LoginBtn` と上記隠しフィールドを送信 → **302 で `Skip.aspx`（地図ページ）へ**。cookies `ASP.NET_SessionId` `SEMIS_v500` `u_token` が発行される。
3. 以降、`https://www.gesuijoho.metro.tokyo.lg.jp/semiswebsystem/service/` 配下のASMXサービスが200で応答:
   - `TspSystemWebService.asmx/GetSystemInfo`（200・Layers: DB1「1/500DB」・Kei 9・BasePosX -80291887・BasePosY -9644545・DivTile 3×3・MinScale 250・MaxScale 100000）
   - `TspDispControlWebService.asmx/SetupInitDisp?clientKey=`（200・40,195 bytes・**DBListの全レイヤーツリー**）
   - `TspSystemWebService.asmx/IsSession`（`{"Status":0}`＝セッション有効）・`GetUserInfo`（`{"Code":1,...,"Status":0}`）
4. サービス定義は `https://www.gesuijoho.metro.tokyo.lg.jp/semiswebsystem/api/sp-5.2.0.1.js`（211,252 bytes）に集約。`sp.service.target="./service/"`。住所検索・テキスト検索（`TspAddressSearchWebService.asmx/GetAddressInfo` `TspTextSearchWebService.asmx/GetTextSearchInfo` `TspAddressMatchWebService.asmx/GetAddressCoord` 等）は存在するが、2026-11-27時点の呼び出しではいずれも `{"Status":-1}` で**実データ取得には未到達**〔確認: パラメータ不足時は「パラメーター: width が見つかりません」等の文言で必要引数が判明する〕。
