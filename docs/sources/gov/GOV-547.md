# [GOV-547] 都公報第18347号（R7.7.15）公告「都市計画河川事業の施行について」〔第五号石神井川の施行公告・認可告示原典の特定〕

- **書誌〔確認: 号PDF本文・r.jina.ai経由・2026-11-23取得〕**: 東京都公報 **第18347号（日刊・令和7年7月15日（火曜日）発行・2頁建て）** の号PDF https://www.tokyoto-koho.metro.tokyo.lg.jp/files/koho/y2025/18347.pdf （194,984バイト〔第279回取得時点〕）。目次の公告欄に「**○都市計画事業の施行…………（建設局河川部計画課）…一**」の掲載があり、本文公告欄に該当記事がある〔目次見出しは「都市計画事業の施行」・本見出しは「都市計画河川事業の施行について」で表記が異なる＝[GOV-534](GOV-534.md)（第18262号）と同じ形式〕。同号の告示（公）は駐車監視員資格者講習の実施（公安委員会告示第253号）1件のみで、**河川系公告は本1件のみ**。
- **公告本文の文言〔確認・r.jina.ai経由〕**: 「**都市計画河川事業の施行について 都市計画法（昭和四十三年法律第百号）第六十六条の規定により、次のとおり公告する。令和七年七月十五日 東京都知事 小池百合子**」「一 都市計画事業の種類及び名称 別表のとおり／二 **施行者の名称 東京都**／三 事務所の所在地 新宿区西新宿二丁目八番一号／四 事業地の所在 別表のとおり」〔[GOV-534](GOV-534.md)（第六号神田川・R7.3.12公告）と同一の文面形式〕。
- **別表〔確認・r.jina.ai経由の抽出断片・要目視〕**: 「**東京都市計画河川事業第五号石神井川**」／「**事業地の所在＝東京都練馬区関町北二丁目、関町北三丁目及び関町北四丁目地内**」／「**事業認可の告示＝令和七年六月三十日 関東地方整備局告示第百六十四号**」／「**所管事務所＝第四建設事務所**」。
- **意義〔観察〕**: ①[GOV-545](GOV-545.md)（着手プレス・第四建設事務所ページ）の未解決②「**第五号石神井川の事業認可告示の原典（関東地方整備局告示の番号・都公報の号）は未特定**」を解決＝**認可告示は東京都告示でなく国（関東地方整備局）の告示第164号〔令和7年6月30日〕として発出されたため、都公報の告示欄に現れない**〔第六号神田川＝[GOV-534](GOV-534.md)の告示第37号と完全に対称する構造の実証。プレス・ページに告示番号が既に出ていない第五号側でも対称予測どおりだった〕。②**認可（6.30）→施行公告（7.15）の間隔15日**は第六号（2.27認可→3.12公告=13日）と同程度で、両者の公告がほぼ同じ速度で発出される慣行の傍証。③**別表の事業地が「関町北四丁目」まで含む文言はrepo初出**〔[GOV-545](GOV-545.md)プレス・説明会資料の「関町北二丁目（本立寺橋上流）〜関町北三丁目（弁天橋下流）」に四丁目が加わる。別紙案内図（第279回取得・GOV-545追記）の付近町名ラベル「練馬区関町北四丁目」と整合するが、四丁目の含入が弁天橋下流端の位置拡大明示なのか丁目境界の事務的表記なのかは本公告からは判定できない〕。④**施行者＝東京都・所管＝第四建設事務所**が公文書レベルで確定（=GOV-545のページ記載と一致）。
- **走査記録〔確認・第279回〕**: 都公報の2025年7月分（第18337〜18358号・アーカイブ頁で存在を確認した全22号・うち18341号は休刊で404）を対象に、第18344〜18358号をr.jina.aiで本文抽出走査（18337〜18343号も18337/18338/18339/18340/18342/18343の6号を走査）＝**「都市計画河川」文言は第18347号の公告1件のみ**。第18345号（R7.7.11）の告示「令和七年度地籍調査事業計画」には豊島区千川二丁目・練馬区石神井台八丁目・田柄一〜四丁目等の調査対象文言がある〔千川二丁目=千川上水系の名の地の2025年度地籍調査対象は、現在進行形の地籍データの供給源として監視ノート参照〕。
