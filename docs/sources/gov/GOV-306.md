# [GOV-306] 『東京水道の沿革』（1896）— 1896年時点の千川上水現役給水と規模数値・表記変種

- **書誌〔確認・編者名は奥付OCR由来で要照合〕**: 鈴木信仁編『**東京水道の沿革**』（**愛善社・1896年〔明治29〕**）。NDL次世代デジタルライブラリー [book/845991](https://lab.ndl.go.jp/dl/book/845991)。東京市水道の沿革を叙述した明治中期の解説書。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①「現時給水する所の水道三條」＝千川上水の1896年時点現役給水〔確認文言〕**: 「**現時給水する所の水道三條あり一を神田上水とし二を玉川上水とし三を千川上水とす乃ち神田玉川の二水は共に德川幕府の遺物に屬し千川の一水は舊き言廢を再造しするもの**（OCRは「舊言⏎廃を再造し」に改行あり・読みは要照合）」＝**1896年時点で神田・玉川・千川の3上水が現役給水と明言する記述**。〔[GOV-290](GOV-290.md)（1905年時点の現役記録）の9年先行、[BOOK-140](../books/BOOK-140.md)（明治40年所有化）の11年前の基準点。千川上水が「幕府の遺物」ではなく「旧き廃を再造したもの」（＝明治13年千川水道會社による再興系）と位置づける表現も記録する〕。
- **②千川上水の流路・規模〔確認文言・数値はOCR由来〕**: 「**千川上水は其源玉川上水より分派し武藏新坐郡保谷村より起り五里二十餘町にして巢鴨溜池となる而して市內に入りて本〓（本郷）及ひ下谷の一部に給水す樋管の延長は凡三千七百七間井數凡千百二十九なり**」＝**①武蔵新座郡保谷村起点・五里二十余町で巣鴨溜池、②市内で本郷・下谷の一部に給水、③樋管延長凡3,707間・井数凡1,129**という規模記録。〔樋管・井の数値の体系は本書固有の情報で、[GOV-263](GOV-263.md)系（千川上水再興の幕府側記録）と数値の対校が課題。「新坐郡」は新座郡のOCR・要照合〕。
- **③起源譚の表記変種「多摩郡仙石村農徳兵衛、太兵衛」〔確認文言・表記変種〕**: 「**此上水は河村瑞賢の計畫する所にして多摩郡仙石村農徳兵衛、太兵衛二人工事に當り今を距る〓と二百年前元祿九年其功を竣ふ因て玉川庄右衛門等の例により二人に千川氏を賜ふ享保七年上水を廢し單に用水となし安永九年再興すと雖も給水十分ならす天明六年又廢す明治十三年岩崎彌太郞等千川水道會社を興し舊渠を修整して大に給水の便を與へたり**」＝**①河村瑞賢計画・「仙石村」の農徳兵衛・太兵衛の2人が工事に当たり元禄9年竣工、②千川氏の賜姓、③享保7年廃止→用水→安永9年再興→天明6年又廃→明治13年千川水道會社の経緯**。〔**「仙石村」表記は既存の「仙川村」系文言（[GAZ-049](../gazetteers/GAZ-049.md)④・[GOV-307](GOV-307.md)）と対立する表記変種**。原字形照合まで「仙石村／仙川村」の正否は断定しない。千川姓の賜姓相手が元禄9年竣工の2人（徳兵衛・太兵衛）である点は[GOV-208](GOV-208.md)系（元禄9年太兵衞徳兵衞）と整合〕。
- **④神田上水の1896年時点流路〔確認文言・repo初出級の現勢記録〕**: 「**小石川區關口より至り大洗堰に瀦て目白臺下に灌き園溝を傳いりて砲兵工廠內に入り露流して又暗渠に入り樋管を以て神田川を橫絕し神田日本橋兩區を通流するもの**（「園溝」「露流」はOCR崩れの候補・要照合）…**其延長凡三万八千餘間井數凡三千六百六拾餘**」＝**1896年時点の神田上水が関口の大洗堰に瀦め、目白台下に灌き、砲兵工廠内を経て、樋管で神田川を横断して神田・日本橋両区へ通流していたという流路の現勢記録**。〔1896年＝[GOV-307](GOV-307.md)のいう神田上水飲用廃止（明治34年6月）の5年前で、この時点では市内給水が残っていたことを示す傍証の一つ。砲兵工廠内への流入は既存の[BOOK-130](../books/BOOK-130.md)系の砲兵工廠供給記録と対校できる。「露流して又暗渠に入り」の解読は要照合〕。

## 制限・未解決

- ①「三千七百七間」は3,707間の読み（「三千七百七」の位取りの原字形は要照合）。②「舊言⏎廃を再造し」はOCRの改行・判読候補で、文意の確定は原文照合後。③「仙石村」vs「仙川村」の表記対立は原字形照合まで解決しない（[GOV-307](GOV-307.md)では「仙川村ノ農民德兵衞太兵衞」）。④本書の千川上水以外の章（改良水道の創始・水源など）の精読は今回は未実施。
