# [GOV-136] 東京都建設局 2026年の河川整備基本方針・河川整備計画変更ラッシュ

- **書誌〔確認: 報道発表・建設局ページ本文をopen_urlで取得・2026-11-14〕**: 東京都は2026年（令和8年）、都管理河川の河川整備基本方針・河川整備計画を体系的に変更している。直接確認した文書: ①都庁総合HP報道発表「[河川整備計画（変更原案）について意見募集](https://www.metro.tokyo.lg.jp/information/press/2026/04/2026042811)」（**2026-04-28**・記事ID 000-001-20260428-058477）②同「[河川整備計画（変更原案）についてご意見を募集します](https://www.metro.tokyo.lg.jp/information/press/2026/06/2026062614)」（**2026-06-26**）③建設局「[渋谷川・古川流域](https://www.kensetsu.metro.tokyo.lg.jp/river/seibi/shibuya)」（記事ID 017-001-20240710-001804・全文取得）④建設局「[河川整備計画について](https://www.kensetsu.metro.tokyo.lg.jp/river/jigyo/kasenseibikeikaku)」（2026-08-01インデックス・全パブコメ終了表示を検索インデックスで確認）⑤第20回（2026-06-30・[2026063031](https://www.metro.tokyo.lg.jp/information/press/2026/06/2026063031)）・第21回（2026-09-02・[2026090201](https://www.metro.tokyo.lg.jp/information/press/2026/09/2026090201)）河川整備計画策定専門家委員会の開催告知。
- **パブリックコメントの2波〔確認: 報道発表本文〕**: ①**2026-05-15〜06-15**: 神田川流域・石神井川・目黒川流域の計画（変更原案）。②**2026-07-01〜07-31**: **新河岸川及び白子川**・柳瀬川流域・**渋谷川・古川**及び呑川流域の計画（変更原案）。いずれも「将来の気候変動への対応」を変更の目的とし、「2050東京戦略」戦略21（頻発化・激甚化する風水害への対策強化）の取組とされる。2026-08-01時点の建設局計画ページは「パブリックコメントは終了…考え方や反映状況については、計画の公表時に建設局ホームページに掲載する予定」とし、**2026-11-14時点では決定版の公表はまだ確認できていない**〔要継続監視〕。
- **渋谷川・古川河川整備基本方針（令和8年3月）〔スニペット確認・PDF本文未取得〕**: 建設局は2026年2〜3月に**目黒川流域・呑川流域・渋谷川・古川**の3本の河川整備基本方針を変更した（建設局トップの告知、および計画ページの新基本方針PDF〔2026-02-27-201326-147・2026-03-06-174919-521・**2026-03-25-111731-042（渋谷川・古川・981KB）**〕）。令和8年3月版渋谷川・古川基本方針の本文（検索エンジンインデックスのスニペットによる）は、**「渋谷川の上流部分や河骨川、宇田川、笄川などの支流は暗渠化され、下水道幹線となっていた」**、**「渋谷川の上流部や支川は暗渠化され下水道幹線となっており、平常時の流量は極めて少ない」**と明記する。また**「気候変動を踏まえた年超過確率1/50〜1/100規模の降雨への対応を目指す（計画降雨量は降雨量の増加を適切に評価し、今後設定していく）」**との新目標、および**「渋谷川・古川河川再生計画（平成12年12月・建設省河川局長認定）**に基づく整備」に言及する。**弦巻川・水窪川の合流先（旧宇田川水系）を含む渋谷川水系の暗渠化・下水道幹線化を、現行の基本方針が明文で確認できる**。ただし弦巻川・水窪川の川名は同基本方針では確認できていない。
- **渋谷川・古川の計画変更の経過〔確認・一部スニペット〕**: 平成20年5月基本方針（000007315）→ 令和6年1月変更原案（000066496）→ **令和6年9月計画**（000007317・2024-10-10「『渋谷川・古川』の河川整備計画を変更」〔[2024101001](https://www.metro.tokyo.lg.jp/information/press/2024/10/2024101001)・堤防耐震対策目的〕）→ 令和8年3月基本方針変更 → **令和8年変更素案**（000066599・第20回専門家委員会資料6-2「渋谷川・古川 河川整備計画≪変更素案≫」）→ 2026年7月変更原案パブコメ → 第21回専門家委員会（2026-09-02・新河岸川及び白子川・柳瀬川流域・渋谷川・古川の変更原案を審議）。新渋谷橋を上流端とし稲荷橋から開水路・天現寺橋を境に上流2.4kmが渋谷川・下流4.4kmが古川・流域面積22.8km²という現行の体系記述は変更原案でも維持される〔スニペット確認〕。
- **渋谷川・古川流域ページの整備状況〔確認: open_url全文〕**: 令和6年度末時点の**河川の安全度達成率は渋谷川79%・古川68%、護岸整備率は渋谷川100%・古川32%**。**古川地下調節池（容量約135,000m³・平成29年度完成・取水口は養老橋下流右岸）**に加え、**新並木橋〜渋谷橋付近に容量約220,000m³の新たな調節池の整備を計画**。洪水対策目標は年超過確率1/20（1時間あたり75mm）。渋谷川・古川の水害表（昭和33年狩野川台風〜平成26年6月29日集中豪雨・駒場観測所）も掲載。
- **「隠田川（千駄ヶ谷幹線）」の図中対応〔スニペット確認・repo初出の公式図中対応〕**: 建設局の渋谷川・古川説明資料（kensetsu文書000053687・流域図）は、渋谷川最上流の旧川を**「隠田川（千駄ヶ谷幹線）」**と図中ラベルで記す〔検索エンジンインデックスのタイトル・スニペットによる。PDF本文未取得〕。**隠田川（穏田川）＝千駄ヶ谷幹線**という対応を都の公式資料図面が示す点で、[GOV-122](GOV-122.md)（技術調査年報2013・千駄ヶ谷幹線＝旧渋谷川遊歩道＝キャットストリート）の幹線特定を補強する。
- **四河川の親水系との対応〔観察〕**: ①**弦巻川・水窪川**（旧宇田川水系→渋谷川）: 渋谷川・古川の基本方針・計画変更の対象流域。②**谷端川**（新河岸川水系）: 新河岸川及び白子川計画変更（[BLOG-222](../blogs/BLOG-222.md)・計画降雨量75mm→85mm）の対象流域。③**千川上水**: 神田川流域計画（[GOV-124](GOV-124.md)・清流復活事業の善福寺川導水0.1m³/s）の変更過程。**四河川のいずれもが、親水系の基本方針・計画の2026年変更過程に含まれる**。変更原案本文での四河川の川名言及の有無は未確認〔要原案PDF入手〕。
