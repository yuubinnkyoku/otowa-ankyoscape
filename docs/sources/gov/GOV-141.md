# [GOV-141] こだいらデジタルアーカイブ「玉川上水の写真」コレクションの水衛所写真3点

- **所在〔確認: NDL OpenSearch（any=水衛所）→ NDLサーチ各書誌頁（R100000094-I1457496/I1457525/I1457480）のcurl+UA直接取得・IIIFマニフェスト・ADEAC目録頁・2026-11-14〕**: 小平市立図書館「こだいらデジタルアーカイブ」の資料グループ「**玉川上水の写真**」に、玉川上水の**水衛所**（分水樋・水質の監視施設）を写した写真が3点、**いずれもCC BY 4.0・インターネット公開**で登録されている。
- **写真3点の書誌〔確認: NDLサーチ書誌情報・IIIFマニフェスト〕**:
  - **「小平水衛所」**〔[mp000960-200050/dgt00804](https://adeac.jp/kodaira-lib/viewer/mp000960-200050/dgt00804)〕。撮影年: **1975〜1984年**。資料分類「玉川上水の写真－建物」。座標 35.7305495817641,139.42271053791（小平市・玉川上水沿い）。〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I1457496)〕
  - **「旧小川水衛所正面」**〔[mp001250-200050/dgt01519](https://adeac.jp/kodaira-lib/viewer/mp001250-200050/dgt01519)〕。撮影年: **1984年**。資料分類「玉川上水の写真－風景」。座標 35.718132,139.473127（小平市小川地区）。〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I1457525)・[ADEAC目録](https://adeac.jp/kodaira-lib/catalog/mp001250-200050)〕〔**1984年時点で「旧」小川水衛所の建物が現存・撮影されていた**ことを記録する行政写真。「旧」表記は機能停止後の建物であることを示すと読めるが、撮影時点の用途・解体時期は未確認〕
  - **「旧熊川水衛所」**〔[mp000800-200050/dgt00726](https://adeac.jp/kodaira-lib/viewer/mp000800-200050/dgt00726)〕。撮影年: **1975〜1984年**。資料分類「玉川上水の写真－建物」。座標 35.723366,139.342806（福生市熊川側の上流部。同じ「玉川上水の写真」グループに所蔵）。〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I1457480)〕
- **意義〔観察・repoへの関連〕**: ①[BLOG-220](../blogs/BLOG-220.md)の「境水衛所＝玉川上水32か所の水衛所の一つ」（千川上水の現分水口）の文言に対し、**小平・小川・熊川という3つの水衛所の名称が写真資料レベルで確認できた**。玉川上水の水衛所群のうち最低4か所（境・小平・小川・熊川）の個別名が判明したことになる（「32か所」の全数は本コレクションからは確認できない）。②「**旧小川水衛所正面**」は、千川上水請負人としての小川家（[GOV-100](GOV-100.md)）の本拠・小川村の分水地点に置かれた水衛所の建物を1984年に撮影した記録で、[GOV-100](GOV-100.md)第87回追記の砂川水衛所あて文書3件（明治41〜大正8年）とあわせ、**小川分水地点の水衛所の建物面・文書面の両方からの記録が揃った**。ただし「小川水衛所」と文書中の「砂川水衛所」は別の水衛所（砂川は上流側）であり、本写真＝砂川水衛所ではない〔注意〕。③水衛所は玉川上水・分水系統の明治期以降の管理施設で、千川上水の分水・水量管理史（境水衛所〔[BLOG-220](../blogs/BLOG-220.md)〕・千川分水の昭和40年調査写真〔[GOV-064](GOV-064.md)〕）と並ぶ管理史の物的資料。
