# [GOV-335] 神田上水留 分冊ノ二（明治3年7月）— 井の頭池の藻草刈取・茶苅船の入札と周辺6村名主連署〔第144回〕

- **書誌〔確認〕**: 『神田上水留』分冊ノ二（表紙文言候補「**明治二己年ヨリ神田上水留分冊ノ二**」内の明治3年条）。NDL次世代デジタルライブラリー [book/2587515](https://lab.ndl.go.jp/dl/book/2587515)。[GOV-334](GOV-334.md)（分冊ノ一）に続く兄弟冊。**OCR崩れが激しく、文言・数値は原画像照合を要する。**
- **入札公告の文言候補〔確認〕**: 「**明治三午年 神田上水源井之頭池 藻草刈取并茶苅船 土留柵 仕様注文 写取 入札可致候 御入用正路に積立 来る九日四時辰之口 土木司おゐて開札有之 間刻限無遅滞入札 下口宛印料いたし持参可致候 落札之上 書損算違等申立 引請御免相願候共 不取上間 精々入念入札可致候**」＝**①明治3年（1870）7月、井の頭池の藻草刈取りと茶苅船（藻草・水草を刈り運ぶ舟か。「茶苅」の原字は要照合）・土留柵の仕様注文書を写し取って入札させた、②土木司（明治政府〔民部省〕の土木司）が9日4時に開札した、③書損・算違を申し立てる引受人は取り上げない（入札規則）**＝**井の頭池の維持管理（藻草刈取り）が入札制の行政として実施された明治3年の一次記録**。「**茶苅日数八日限 皆出来之積相心得 取掛日限追而申渡候間 諸色益而用意致置…**」＝工期8日限の出来高請（「自然泥水二相成難見極候 再度苅取入念取揚見分請可申もの」の文言候補もあり、水辺の作業条件の記述）。〔神田上水の頭部（井の頭池）の管理が明治政府の土木司・入札制に移った過程の資料＝[GOV-334](GOV-334.md)（明治2年・上水方の修復）から[GOV-249](GOV-249.md)（明治2年9月・民部省上水屋敷改の触）へ続く明治初年の管理移行の通時系列の中間点〕
- **周辺6村の名主・百姓代連署〔文言候補〕**: 「**吉祥寺村… 久我山村名主太次衛門 野川村名主作右衛門 西窪村名主… 北野村百姓代… 下連村名主菊松… 名主見習**」＝**井の頭に接する吉祥寺村・久我山村・野川村・西窪村・北野村・下連村の名主・百姓代（名主見習を含む）が触書を受け取って連署する構成**＝**明治3年時点の井の頭周辺の村組織（井の頭池を囲む6村）と、上水行政の末端受け（村方）の一次記録**。〔井の頭池の共有・水利関係の村構成（吉祥寺村＋西窪村が池の両岸、久我山村・野川村・北野村・下連村が周辺）を役職名・人名付きで記す点が、井の頭の村際関係の基礎資料になる（人名の読み・村名の範囲は原画像照合を要する）〕
