# [GOV-376] 三橋以下橋々書類 55・66冊 — 新大橋証文の全文と船河原橋〜大洗堰15町〔第163回〕

- **書誌〔確認〕**: 『三橋以下橋々書類』の55冊（NDL [book/2540769](https://lab.ndl.go.jp/dl/book/2540769)）と66冊（NDL [book/2532835](https://lab.ndl.go.jp/dl/book/2532835)）。橋の請負・証文・類焼・相続等の行政文書集。**引用文言はすべてOCR由来で要原文照合。**
- **寛延3年（1750）5月19日の新大橋証文の全文〔確認・repo初出〕**: 「**柳橋〜牛込御門下34町＝永代橋掛り・船河原橋〜大洗堰15町＝新大橋掛り・渡銭は永々**」＝**神田川の渡船の運賃・組合の範囲が永代橋側（柳橋〜牛込御門下の34町）と新大橋側（船河原橋〜大洗堰の15町）に二分され、新大橋（渡船組合の橋）の渡銭が永々（永代）とされた**証文〔**船河原橋〜大洗堰間の15町が渡船組合の単位**＝[GOV-373](GOV-373.md)の船河原橋・大洗堰区間の川浚普請と独立に整合する、江戸川上流部の町連合の範囲の一次記録。助成地＝相生町3丁目＋芝口1丁目西側2ヶ所＋相生町4丁目300坪。渡銭・助成地の文言は要照合〕。
- **宝暦10年（1760）新大橋の類焼→仮橋→明和3年（1766）の本橋再建〔確認〕**: 新大橋の類焼と仮橋・明和3戌年11月の新規本橋の文言＝神田川の渡し新橋（新大橋）の再建史〔[BOOK-129](../books/BOOK-129.md)系の新大橋記録と対校〕。
- **柳原土手の柵修復の残金報告〔確認〕**: **柳原土手の柵1,042間余の新規修復の残金58両2分の報告**（66冊）＝[GOV-373](GOV-373.md)⑤の矢来柵1,042間余の新規修復（寛延3年11月〜寛延4年2月）と**同一の数値（1,042間余）による独立の裏付け**（六番町火消屋敷の道造160間・枯柳の植替の文言も整合）〔寛延3〜4年の柳原土手の矢来柵修復の実務の完結記録〕。
- **請負人の実務〔確認〕**: 橋請負人の病死・断絶・養子相続の実務文言群＝江戸期の橋維持の請負の相続構造〔[GOV-375](GOV-375.md)の請負人交代リストと対校〕。
