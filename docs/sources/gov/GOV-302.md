# [GOV-302] 東京府統計表（明治10年度分）— 「仙川用水」の統計行

- **書誌〔確認〕**: 東京府編『**東京府統計表 明治10年度分**』（1882年〔明治15年〕刊）。NDL次世代デジタルライブラリー [book/806593](https://lab.ndl.go.jp/dl/book/806593)。河川・用水の一覧表（名前・長サ・幅・鑿年・備考の列構造と見られる）を収める。**引用はすべて同館OCRテキスト由来で、表は列崩れ・行混在が著しく、文言候補として原画像照合を要する。**
- **「仙川用水」の統計行〔文言候補・repo初出級〕**: 一覧表中の「**仙川用水**」の行の備考列（と見られる箇所）に「**竹下新田ヨリ分流シ 上落合村ニテ神田上水ニ合ス**」という文言が読める〔列崩れのため「埼玉縣下新座郡小樽村…上下赤塚村ヲ經テ荒川ニ入ル」等の隣接行の文言との混在があり、帰属の確定は原画像照合を要する〕。**明治10年（1877）度時点で「仙川用水」が東京府統計の河川・用水表に独立項目として掲載されていた**ことの記録〔**長サ・幅・鑿年などの数値は列崩れで読めない**〕。
- **明治13年度分の対校（未登録冊）〔文言候補〕**: 同じく明治13年度分（[book/806596](https://lab.ndl.go.jp/dl/book/806596)・1882刊・未登録）にも「**仙川用水**」の行があり、備考列と見られる箇所に「**竹下新田ヨリ分流し…**」の文言候補が続く〔**明治13年度版では「上落合村ニテ神田上水ニ合ス」に対応する文言の読み替わり（「豊島村ト堀の内村ノ間二至リ荒川ニ入ル」という崩れた文言が近接する）があり、隣接行との混在の可能性がある。原画像照合まで備考欄の確定文言は保留**〕。
- **位置づけ〔観察・内容メモ〕**: ①「竹下新田ヨリ分流」＝[GAZ-057](../gazetteers/GAZ-057.md)（風土記稿・多磨郡の下祖師ヶ谷村条「新座郡上保谷村より入り同郡竹下新田を経て此のほとりに至りては仙川用水と云」）の経路文言（上保谷→竹下新田）と一致する明治期の府統計側の記録。②「上落合村ニテ神田上水ニ合ス」＝上落合村（現・杉並区上落合）を経て神田上水（＝千川上水の流末が接続する神田上水系か・千川上水残存流路が神田上水に合流したという統計認識か）は原画像照合まで比定保留。③江戸期の官撰地誌（風土記稿・豊島郡側と多磨郡側）→明治10年代の府統計→1916年豊多摩郡誌（[GAZ-051](../gazetteers/GAZ-051.md)千川用水・井草川）という「仙川用水／千川用水」呼称の通時系列のリンク。④千川上水の明治13年三たび興復（[BOOK-138](../books/BOOK-138.md)武蔵野歴史地理）の時期と重なる府統計での用例。

## 制限・未解決

- ①表OCRの列崩れが激しく、「仙川用水」行の長サ・幅・鑿年・備考欄の確定文言は読めない。②「上落合村ニテ神田上水ニ合ス」の神田上水の意味（千川上水の残存区間の呼称か・善福寺川系の神田上水か）は未確定。③明治13年度分（806596）は本ファイルの対校として記録した（独立登録せず・本文確認のみ）。どちらの年度版も原画像照合が必須。
