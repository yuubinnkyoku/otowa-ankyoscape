# [GOV-408] 内務省土木局第二十七回統計年報（1927）— 水道統計表の王子水道・神田川上流鑿井・淀橋町水道等の文言候補群

- **書誌〔確認〕**: 內務省土木局『統計年報』第二十七回（東京市京橋區北槇町・内務省土木局、印刷昭和2年〔1927〕3月）。NDL次世代デジタルライブラリー [book/1077166](https://lab.ndl.go.jp/dl/book/1077166)。凡例＝「道路橋梁員數＝大正十年末現在／軌道＝大正十二年末／**衞生工事＝大正十四年末**／土地收用＝大正十年乃至十四年」＋目次に「**大正十三年度水道給水其一**」「大正十三年度末現在水道栓數」「**水道〓要其二（大正十四年十二月三十一日）**」等の水道諸表＝**水道統計は大正13年度（1924年度）給水・大正14年末（1925年末）現在の事実を掲載**。**本repoでは衛生工事群（水道）のうち東京近郊の私営町村水道の行のみを記録対象とする（道路・軌道・土地収用の各表は素通り）。**
- **神奈川水道部管轄表の東京・神奈川側私営水道の一覧〔確認・文言候補・多桁表で行対応崩壊〕**: 大正14年末現在の水道概要表（神奈川水道部管轄欄）のOCR連結文字列から、次の水道名と文言候補が読める（**表の列＝水道名／着手・完成・給水開始年月日／水源／給水区域／設計費等の対応がOCRで全面崩壊しており、どの数値・年月日がどの水道に行くかの割り当ては一切確定できない。以下は文字列の出現順に基づく列挙のみ**）:
  - 「**東京市水道 玉川水道 多摩川 荏原郡調布村大字沼部**」＝玉川水道（多摩川水源・取水地調布村沼部）の大正14年末統計表レコード候補。
  - 「**王子水道 … 瀧野川鑿井 … 北豐島郡瀧野川町、王子村、板橋町、巢鴨町、西巢鴨町地内**」＝**王子水道の水源＝瀧野川鑿井（深井戸）・給水区域＝北豊島郡滝野川町・王子村・板橋町・巣鴨町・西巣鴨町地内と読める行候補**＋「**北豐島郡瀧野川町字馬場**」＝**鑿井位置が滝野川町字馬場である候補の文字列**〔着手・完成・給水開始の年月日候補（「同六·二二二八」「同七·〇〇·〇〇」「同八·一二·〇九」等）は王子水道行に対応するか不明〕。**王子水道（滝野川・王子・板橋・巣鴨側の明治末〜大正の私営水道）の給水区域・水源の文言候補としてrepo初出（repo既存の滝野川区間の水道端〔BLOG-092〕等と対校）**。
  - 「**神田川上流鑿井 … 豐多摩郡落合村字南〔OCR・以下不明〕 八九〇、〇〇〇**」＝**「神田川上流」を水源名とする鑿井（落合村字南?の深井戸候補）の行候補**＝**神田川上流（豊多摩郡落合村＝現・新宿区・中野区側の水源）の鑿井の存在を示す文言候補（repo初出候補。一日給水量候補「八九〇、〇〇〇」）**〔行対応崩壊のため明治〜大正の「神田川上水の水源」関係との接続の検討は原画像照合まで行わない〕。
  - 「**新宿水道 … 澁谷町水道 …**」＋給水区域候補「**同郡高田村及豐多摩郡戶塚村、落合町、大久保町、内藤新宿町、淀橋町中野町地内及目黑町ノ一部**」＝新宿水道（内藤新宿）・澁谷町水道の行候補。
  - 「**澁谷町水道 … 元湧水 … 伏流(多摩川流域) … 澁谷町水道分水 … 東京市水道分水**」＝澁谷町水道の水源（湧水→多摩川流域伏流→東京市水道分水への転換が読める候補）。
  - 「**淀橋町水道 … 東京市水道區分水 淀橋町大字角筈**」＝**淀橋町水道＝東京市水道の区分水（分水）による給水（受け入れ地点＝淀橋町大字角筈候補）の行候補**＝**大正期の淀橋側上水が東京市水道の分水に転換していた統計表レベルの文言候補〔repoの淀橋水車区間の水系史に接続する対校点（浅間水七ッ釜橋関連の千川上水系との関係は断定しない）〕**。
  - 「**荒玉水道 … 多摩川 北多摩郡砧村大字喜高見〔OCR・喜多見崩れ候補〕／…大字鎌田**」＝荒玉水道（多摩川水源・砧村）の行候補＋「千駄ヶ谷町水道」「八王子水道」「目黑町水道」「江戶川水道」「大島野增村水道〔OCR崩れ候補〕」等の私営水道名の列挙。
  - 北関東〜九州の水道一覧表（水戶市水道・宇都宮市水道・本更津水道・王子水道・新潟水道・澁谷町水道・江戶川水道・淀橋町水道・荒玉水道・八王子水道・日黑町水道・千駄ヶ谷町水道等＋設計費・人口等の数値群）。
- **位置づけ〔観察・大幅限定〕**: ①**滝野川・王子・板橋・巣鴨側（谷端川・石神井川下流側）の大正期の水道史（王子水道）と、神田川上流側の鑿井（落合村）・淀橋町水道（東京市分水）の統計年報レベルの存在記録**として、repoの近代水道史資料群（金杉水道町・滝野川の水道端〔BLOG-092〕・明治10年度府統計〔GOV-302〕等）に対する大正末の行政統計側の追加候補。②ただし**本表は多桁統計表のOCRで行・列の対応が全面崩壊しており（数字・年月日・地名の連結文字列の羅列）、上記のすべての対応関係は「文字列出現順に基づく候補」でしかない。原画像（ndlightbox）の照合なしに列挙以上の構造判断・数値信用は行わない。**
