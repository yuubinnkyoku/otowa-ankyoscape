# [GOV-582] 「環状七号線地下河川（仮称）基本検討委託」公告（2026-11-24）— 環七地下河川の基本検討段階への移行

## 記事・公告の概要〔確認: 建設通信新聞Digital 2026-11-25掲載（4面）記事本文〕

- 建設通信新聞Digital「**東京都/環七地下河川整備へ基本検討/希望申請11月27日まで/治水関係10件公告**」（**2026-11-25掲載・4面**・[kensetsunews 1313470](https://www.kensetsunews.com/archives/1313470)）。都財務局が**2026-11-24**に「**環状七号線地下河川（仮称）基本検討委託**」を含む**治水関係の希望制指名競争入札10件を公告**。希望申請は**11月27日まで**、**開札は12月16日**〔いずれも2026年〕。
- 環七地下河川では、**神田川、白子川、石神井川、目黒川、呑川の各流域**を対象に、**施設の配置や基本構造の検討、施工計画などを検討する**。**履行期間は2027年12月10日まで**。参加資格は「**土木・水系関係調査業務** A等級」など〔5流域文言は[GOV-291](GOV-291.md)②（第2回委員会報道・2026-08-05）で既出だが、**調達公告レベルではrepo初出**〕。
- **関連業務のうち、治水対策検討をパシフィックコンサルタンツ、基礎調査をエイト日本技術開発に委託した**〔確認: 記事本文。エイト日本＝基礎調査は[GOV-291](GOV-291.md)②の実施体制文言と一致〕。

## repo初出・対校文言

- **「基本検討委託」という調達公告自体がrepo初出**＝[GOV-291](GOV-291.md)（環七地下河川計画検討委員会・第1回2026-03-04・第2回2026-07-14）の「計画検討」段階に続く**次段階業務の調達**を伝える業界紙報道。第2回委員会報道（自然流下圧力管方式・最下流区間の内径12.5m想定・日本工営＝水理模型実験・エイト日本＝基礎調査の実施体制）に続き、基本検討段階に移行した時系列の定点。
- **「治水対策検討＝パシフィックコンサルタンツ」受注文言はrepo初出**〔grep確認: repo内「治水対策検討」は[GOV-554](GOV-554.md)（白子川中流部・フジヤマ担当）のみで、環七系の文言は既存なし〕。パシフィックの都下治水系受注は、**[GOV-546](GOV-546.md)（神田川中流部基礎調査）・[GOV-554](GOV-554.md)（新河岸川及び白子川の気候変動を踏まえた河川整備計画調査）**に続く3件目で、**環七系としては初**。
- 第2回委員会の実務体制（日本工営＝水理模型実験・エイト日本技術開発＝基礎調査・[GOV-291](GOV-291.md)②）と、本公告の「治水対策検討＝パシフィック・基礎調査＝エイト日本」を並べると、**環七系の先行2業務（治水対策検討・基礎調査）の受注者が初めて双方確認できた**〔「治水対策検討」が第2回委員会資料のどの部分に対応するかは本文未見のため断定しない〕。
