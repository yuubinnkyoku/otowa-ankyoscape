# [GOV-462] 板橋町現状調査 — 池袋村の一部の板橋町合流の沿革文言と低地埋立の定点

- **書誌〔確認〕**: 『板橋町現状調査』（東京市臨時市域**擴張部**編・[book/1900500](https://lab.ndl.go.jp/dl/book/1900500)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**板橋町（1932年板橋区）冊**＝**谷端川上流（長崎・中新井）の北隣＝石神井川下流・池袋台地の北斜面の行政定点**。石神井川・谷端川の直接文言は本冊fulltext走査限りで陰性（陰性記録として掲げる）。
- **沿革の池袋村文言〔文言候補・本ファイルの核心〕**: 「**明治二十二年…下板橋宿（ト）金井窪村滝野川ノ部（ヲ以テ）下板橋町（トナリ）…（後）中丸村及池袋村ノ一部ヲ加へ（テ）板橋町トナル**」＝**①明治22年（1889）に下板橋宿＋金井窪村滝野川ノ部で下板橋町が成立、②中丸村および池袋村の一部を加えて（現在の）板橋町となった沿革**〔**①池袋村の一部が板橋町に合流していた一次文言候補＝池袋地名が西巣鴨町〔[GOV-450](GOV-450.md)＝郡役所の字池袋642番地〕・板橋町の両側で大字・合体対象になっていたことを示す沿革文言候補（1932年の区割りで池袋の主要部は豊島区へと分かれるが、本文言はその前段の明治期の町村合流を記す）、②金井窪村の「滝野川ノ部」＝金井窪の滝野川側（谷端川・音川系の奥）の飛地的部域の合流の文言候補**。年次・地名の正確な表記はOCR要照合〕。
- **海抜定点〔文言候補・数値群〕**: 「**川越街道附近（=最高地?）百五尺五寸七分…板橋警察署附近九十六尺八寸五分…最低地…七十四尺二寸五分（大字滝野川?、OCR候補）**」＝**①川越街道附近105尺5寸7分・②板橋警察署附近96尺8寸5分・③最低地74尺2寸5分**＝**尺貫法の海抜の定点群**（（板橋＝石神井川低地に面した台地末端の 高さの定点＝[GOV-458](GOV-458.md)王子町のメートル法表記との対照）（OCR数字崩壊・候補値）。
- **塵芥の低地埋立〔文言候補〕**: 塵芥（ゴミ）の低地埋立（の実施・計画）の文言候補＝**1931年時点で清掃事業としての低地（石神井川沿い湿地等?)の埋立が行われていた記録候補**（低地＝水田・湿地の宅地化の前段の定式＝谷端川・千川系低地の土地利用変化の定点候補。対象地の特定は要照合）。
- **板橋地名沿革〔文言候補〕**: 板橋の地名について吉田東吾氏の説（豊島・広岡郷〔=板橋の古名候補〕）・「**板橋氏は上板橋村地内(説)**」等の OCR 文字列候補＝**板橋宿・板橋の地名沿革（中世の豊島氏・板橋氏の関係）の地方側の収集例**（[GAZ-012](../gazetteers/GAZ-012.md)絵図分冊の板橋宿・[GOV-450](GOV-450.md)北豊島郡役所の系統と地名側で対照・OCR大崩壊のため書名・説の内容は原画像照合必須）。
- **帳簿文言〔確認〕**: 人口・面積・財政・交通（省線山手線池袋駅・武蔵野線の交叉の文言候補・大宮電気鉄道等）・学校・社会事業＝1932年市域拡張直前の板橋町の帳簿。
