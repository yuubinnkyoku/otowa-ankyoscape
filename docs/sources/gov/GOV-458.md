# [GOV-458] 王子町現状調査 — 谷端川下流低地の海抜定点（1.8米）と王子台地（24.3米）

- **書誌〔確認〕**: 『王子町現状調査』（東京市臨時市域**擴張部**編・[book/1900498](https://lab.ndl.go.jp/dl/book/1900498)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**王子町（1932年王子区→北区）冊**＝**谷端川（下流の音川・秋川系統）の南東隣＝石神井川下流・堀ノ内・梶原の低地（谷端川が音川ないかで合流する地域の北隣）の基準点**。
- **最高地・最低地の海抜文言〔文言候補・本ファイルの核心〕**: 「**其ノ最髙(変?)地ハ大字王子岸ノ上（ニ）海抜二四米三、最低地ハ大字堀ノ内梶原ニ（ミテ）海拔一米八ナリ**」＝**①最高地＝大字王子岸ノ上24.3米、②最低地＝大字堀ノ内梶原1.8米**〔**①堀ノ内・梶原（石神井川・谷端川下流系の低湿低地（音川低地西部）＝王子の南の荒川沿いの低地）の海抜1.8米＝石神井川・谷端川系の下流低地の海抜定点（repo初出の数値）で、低地幹線（谷端川下流部の1934年一部暗渠化・1964年全面暗渠化）の敷設高の背景の地形基準値候補、②「海抜○米」＝メートル法表記＝[GOV-457](GOV-457.md)日暮里町の「海抜78尺程度」（尺貫法）との同シリーズ内での単位差＝編年側（メートル法移行期）の定点**。数値のOCRは比較的安定しているが要照合〕。
- **石神井川・荒川文言〔文言候補〕**: 「**石神井川ハ町ノ南端ヲ走リ荒川ニ(注ク)**」＝**石神井川が町の南端を流れ荒川に注ぐ**＝石神井川の王子町域での位置（南端＝王子-滝野川境界方面）の文言候補（[GAZ-022](../gazetteers/GAZ-022.md)風土記稿の石神井川系統と対照。音川との関係は本冊では不明）。「本町ハ北豊島郡東北部二位(?)置キ、東ハ荒川ヲ隔ラテ南足立郡江北村ニ対シ」等の方位文言もOCRで見える。
- **一等通路13号線〔文言候補〕**: 「一等通路十三号線（ハ）三河島(ヨリ)尾久…滝野川(一部)…王子中央…池袋(ヲ連結ス?)」＝**三河島＝尾久＝滝野川（一部）＝王子中央＝池袋を結ぶ一等通路13号線（大東京道路計画の幹線）の文言候補**〔**この路線は谷端川系の谷（音川低地）と石神井川系の谷を横断して池袋（＝板橋・豊島方面の高地）に至る＝後の明治通り・尾久の台地経由の幹線の原型候補**＝1931年時点で池袋が区画計画の基準点になっていた傍証（[GOV-454](GOV-454.md)武蔵野線池袋駅・[GOV-462](GOV-462.md)板橋町池袋村の沿革と対照）〕。
- **沿革〔文言候補〕**: 「住吉岸村ト称セラレ飛鳥山ノ名（ガ）寝灯際(?)(ナリシ)時ヨリ幾百星〓(年?)王子タルノ名称ハ何レノ時ニ改称セラレタルヤハ文献ノ徴ス可（ナルモノナシ?）」＝**王子の旧称と飛鳥山から王子への改称年代が文献に徴しがたいことを沿革章が自認する文言候補**（OCR大崩壊・候補値。「住吉岸村」等の固有名表記は原画像照合まで確定しない。飛鳥山・王子権現の地名関係は本冊文言のみでは谷端川（音川）系の水源問題に接続させない）。
- **帳簿文言〔確認〕**: 面積（1,756,674坪・南北は滝野川町・江北村等の隣接文言候補）・人口・財政・交通（省線京浜東北線王子駅・王子電車軌道他の文言候補）・学校・社会事業＝1932年市域拡張直前の王子町の帳簿。
