# [GOV-188] 特別都市計画委員会議事速記録 第11号（1930年）— 千川＝下水道負担の答弁

- **書誌〔確認〕**: 特別都市計画委員会『議事速記録 第11号』（昭和5年）。NDL次世代デジタルライブラリー [book/1225207](https://lab.ndl.go.jp/dl/book/1225207)。**すべての引用は同館OCRテキスト由来であり、文言・議案番号・人名は原文画像との照合を要する。**
- **議第九十八号＝氷川下〜巣鴨間路線の変更〔確認・repo初出〕**: 氷川下から巣鴨町字宮下の電車終点に至る路線について、「**小石川區內千川筋ノ下水道事業ノ執行ニ便スル爲ニ、路線ノ一部ヲ千川筋ニ變更シ**」「**千川敷ヲ利用シテ之ヲ十間ニ變更セン**トス」（幅員8間→10間）と説明＝**千川筋街路の幅員拡張が「千川筋の下水道事業」（千川暗渠化＝[GOV-094](GOV-094.md)氷川下暗渠化昭和5年11月着工・昭和9年7月竣工）に便するものとする1930年の委員会文言**。〔文言はOCR要照合〕。
- **千川の法的位置づけの答弁〔確認・repo初出の一次文言〕**: 朝倉委員「小石川ノ植物園ノ下ノ千川、**アレハ東京市デ御取リニナルノデアリマスカ**」→広瀬（東京市助役）「**アレハ下水道負擔デ**」「**河川デアリマセヌ**」＝**1930年時点で小石川植物園下の千川（開渠）が法定河川ではなく東京市下水道事業の負担対象であったことを、委員会答弁の形で確認できる一次文言**。〔議員・答弁者の氏名・役職はOCR要照合〕。
- **位置づけ〔観察〕**: [GOV-163](GOV-163.md)（1924・千川流域247.6万坪の下水計画）→[GOV-094](GOV-094.md)（昭和5年着工の氷川下暗渠化）→[GOV-159](GOV-159.md)（1930・谷端川改修と板橋放水路完成）という下水道側文書群の途中年の、**道路計画（都市計画）と下水道事業の連携**（千川敷を道路幅員に転用）を示す記録。「千川敷」という呼称も初出。
