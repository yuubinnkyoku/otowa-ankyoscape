# [GOV-631] 練馬わがまち資料館「ねりまの地名今むかし 現町名12＜田柄 たがら＞」

## 書誌・確認範囲〔確認〕

- 練馬区公式[練馬わがまち資料館](https://www.nerima-archives.jp/)の地名コラム「ねりまの地名今むかし」([現町名12＜田柄 たがら＞](https://www.nerima-archives.jp/column/1163/)・2021.11.1公開）。**郷土史研究家の桑島新一氏に執筆いただいた「練馬の地名今むかし」（昭和59年6月〜昭和60年8月区報連載）等を再構成したもの**で、当該頁の元掲載は**ねりま区報 昭和60年3月11日**。直アクセスはサイト全体のメンテナンス状態のため**Waybackスナップショット（2026-05-17）**で本文全文を確認した（repo grep 0件＝repo初出）。
- 桑島新一氏は**「田柄川今昔」（著作）**の所蔵写真を出典として本コラムに使用しており、同著作の存在も記録される。

## 内容〔確認: 本文全文・2026-11-27取得〕

- **「江戸時代の田柄は、現在の田柄の約2倍の広さがあった。東は北町の自衛隊付近（当時の下田柄）から、西は光が丘（当時の上田柄）まで、上練馬村・下練馬村にまたがっていた。寛永16年(1639)の検地帳に見られる古い地名だが、その由来は定かでない」**＝**①田柄の東西範囲（下田柄=現北町自衛隊付近〜上田柄=現光が丘）＝[ORG-051](../org/ORG-051.md)今昔1の旧バス停名「上田柄」との対応、②寛永16年（1639）検地帳による初出年代、③由来不詳の明記**。
- **『四神地名録』の田柄条応用**: 「この辺のことを江戸の地誌『四神地名録(ししんちめいろく)』は「**畑在所にて田方一分(いちぶ)ばかり、風土すぐれず広きといふのみ**」といっている」＝[GAZ-084](../gazetteers/GAZ-084.md)/[GAZ-085](../gazetteers/GAZ-085.md)（四神地名録既収録）における**田柄条の引用応用**として、水利不在（水の涸れた空の田んぼ）と年貢率の低さの文脈で使用。
- 明治4年、干ばつに悩む村人たちが資金を出し合い、近隣の村々と協力して**玉川上水の分水を引くことに成功**。「今も**天祖神社（田柄4－27）に、その時の記念碑(「田柄用水記念碑」　区史跡)がある**」＝**「田柄用水記念碑」の正式呼称と区史跡指定の区公式表記**＝[BLOG-360](../blogs/BLOG-360.md)（上練馬村玉川上水分水紀念碑）・[GOV-630](GOV-630.md)（明治26年11月建立・水神宮）の同一碑の区側呼称記録（碑名表記の差はそのまま記す）。
- **「昭和7年、旧上練馬村の田柄地区が板橋区練馬田柄町となった」**＝町村制以降の行政名の年次。**「30年代からの宅地化で、田柄川は生活用排水が流され、大雨ごとにあふれ出す「やっかい堀」になってしまった。47年ごろから工事が始まり、今は暗きょ化され、見事な緑道に変身」**＝**「やっかい堀」語の区公式コラムでの使用例（汚水・氾濫由来＝BLOG-118系）＋暗渠化工事の「47年ごろ」開始**＝[GOV-075](GOV-075.md)（47年度大々的着工）・[ORG-051](../org/ORG-051.md)今昔25（46年9月起工・区域別完成）と整合する第3系統（年次表記のずれは対立として断定せず）。
- **「練馬大根を川の流れで洗ったのを懐かしんで、その名も「練馬だいこんコース」。**（緑道のジョギングコース名）＝**田柄川緑道の愛称の由来＝repo初出**。**「昭和42年、住居表示で現町名となった」**。

## 意義

- 地名対照表の田柄条（上田柄・下田柄・練馬田柄町）の典拠として、区公式地名コラムの全文を確保した。田柄用水記念碑の「区史跡」指定表記、寛永16年検地帳、四神地名録田柄条の応用、「やっかい堀」の区公式用例、「練馬だいこんコース」の各点がrepo初出または既存仮説の公的側裏付け。

## 制限・未解決

- 寛永16年検地帳・桑島新一「田柄川今昔」の現物所在は未確認。暗渠化着手の年次表記（47年ごろ）は他資料（46年9月・47年度）と併記し断定しない。直アクセス不能のためWayback取得と明記。
