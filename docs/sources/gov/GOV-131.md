# [GOV-131] 豊島区「わが街ひすとりぃ 第16回 長崎 現地ロケ編」

- **書誌〔確認: ADEAC目録・全文テキスト取得〕**: 豊島区デジタル区史「としまひすとりぃ」広報番組。**収録日 令和元年7月10日、制作 令和元年11月、収録時間15分32秒**。出演: **熊澤雄一・古賀久恵**（ほか清水良浩・榑松正利・榑松次郎の各氏）。[ADEAC目録ページ](https://adeac.jp/toshima-history/catalog/mp00001610)、[現地ロケ編全文テキスト（ht420160）](https://adeac.jp/toshima-history/texthtml/d000000/mp00001610/ht420160)。
- **長崎1丁目の千川（上水）の流路位置と流水記憶〔確認: 全文テキストの直接引用〕**: カフェレストラン「ストーク」（清水良浩氏が**52年前（昭和43年頃）に開店**、椎名町駅周辺・長崎1丁目側）の前で、熊澤氏が「**ここのところはね、川が流れていたんです。向こう側**」、清水氏が「**千川っていうのがね。**」と応じ、熊澤氏が「**それはね、暗渠化（地下に埋設された導水路）した、暗渠ってねえ…**」と説明したうえで、清水氏が「**向こう側の歩道のところですね。向こう側の歩道のサミットのちょうど前あたりですね。あそこでずーっと流れてまして、**」と**現在の歩道・スーパーマーケット「サミット」前を基準にした流路の位置指示**を行う〔**長崎1丁目（椎名町駅南側）の千川上水開渠跡の位置を、現存ランドマークとの相対位置で示す古老証言**。「千川」が千川上水本流か谷端川上流（千川上水長崎村分水）かは証言だけでは確定しない〕。
- **学生運動期（1960年代後半）の光景〔確認: 全文テキストの直接引用〕**: 同じ清水氏の証言は「**学生運動の時には芸闘員ってのが芸術学部でできましてね。闘っていたんですけど、ここへ全部機動隊の車が停まって、ここから村へ行くような感じでした。**」と続き、**学生運動期に機動隊車両が千川沿いに停車していた光景**を伝える〔「あそこでずーっと流れてまして」との前段から、**1960年代後半時点で同所に開渠の残存ないし流水の記憶があった**可能性を示唆するが、暗渠化（埋設）の時期・流水の有無の正確な年代は本文中で特定されない〕。
- **アトリエ村〔確認: 全文テキスト〕**: 榑松正利氏（洋画家）のアトリエでの回想として、戦後数年～昭和30年代の「**さくらが丘**」アトリエ村（絵描き・彫刻家が多数居住、パルテノン看板、金子病院を目指して夜道を歩いた等）を語る〔[GOV-129](GOV-129.md)（第10回千川・長谷川義起・名井萬亀アトリエ）と同じ長崎・椎名町一帯のアトリエ村記憶の追加。川との位置関係の言及はない〕。

## 制限・未解決

- ①「サミットのちょうど前あたり」という位置指示は証言時点（2019年）のランドマーク基準であり、現在の道路・歩道の拡幅履歴を反映していない可能性がある。**1912年地籍図・空中写真との照合で流路の同定が未実施**。②学生運動期の「流れてまして」が恒常流水・残存開渠・雨天時流水のいずれかは未確認。③「千川」の区間特定（千川上水本流／長崎村分水＝谷端川上流）は未解決。④ストークの開店「52年前」は2019年収録時の概数（昭和43年頃と換算）。
