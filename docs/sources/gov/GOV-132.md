# [GOV-132] 豊島区「わが街ひすとりぃ 第11回 駒込 現地ロケ編」

- **書誌〔確認: ADEAC目録・全文テキスト取得〕**: 豊島区デジタル区史「としまひすとりぃ」広報番組。**収録日 平成31（2019）年4月16日、制作 令和元年6月、収録時間17分08秒**。出演: **中川福次・萩原寿夫・桂川和子**（ほか小川・池上・八木・関根・鏑木・稲垣の各氏）。[ADEAC目録ページ](https://adeac.jp/toshima-history/catalog/mp00001110)、[現地ロケ編全文テキスト（ht420110）](https://adeac.jp/toshima-history/texthtml/d000000/mp00001110/ht420110)。
- **旧藤堂家下屋敷の池を源とする川筋と現代の水脈観察〔確認: 全文テキストの直接引用〕**: 地域の共同菜園「わたしの庭・みんなの庭」で池上氏が「**（井戸を指しながら）そこのところに昔の地図を見ると、川が流れているんですけど、藤堂さんのお屋敷の池からね。水脈が近いからすぐ井戸が出るんですね。7メートルの浅い井戸で、そこからポンプでくみ上げて川を作って、最後に田んぼがあります。**」と語る〔**旧藤堂家下屋敷（現在の六義園周辺・染井）の池を源流とする川筋（谷田川系）に沿う低地で、現在も7m程度の浅井戸が出るという生活レベルの水脈観察**。参照した「昔の地図」の書誌は不明〕。
- **染井通りの成立〔確認: 全文テキスト〕**: 萩原氏が染井通りを「**明暦の大火っていうのがあってですね。その時にできた都市計画道路、まちづくりの道路でもあります。左側に藤堂家の下屋敷があって、右側にそこのお庭の手入れをする植木屋さんたちが住むようになって、こちらが一大植木屋さんの町になった**」と説明する〔染井＝ソメイヨシノ発祥の植木屋町の成立条件として、屋敷（池）→植木屋→川筋という立地関係の地域説明。明暦の大火後の道路整備説は証言者の地域史説明であり、道路の起工史料とは扱わない〕。

## 制限・未解決

- ①本資料の川筋は**谷田川（谷戸川・藍染川）系**であって、本repoの四河川（水窪川・弦巻川・谷端川・千川上水）ではない。ただし**駒込台地東縁の池→湧水→川という水環境の構造**は、音羽谷・目白（椿山荘・弦巻川・丸池）と同じ台地周縁部の水理を比較する文脈で記録する。②「7メートルの浅井戸」は菜園での掘削経験に基づく概数で、帯水層・湧水量・現在の稼働は未確認。③「藤堂さんのお屋敷の池から」流れる川の旧河道位置・「昔の地図」の書誌は未特定。
