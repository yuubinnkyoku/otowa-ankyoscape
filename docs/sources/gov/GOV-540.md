# [GOV-540] 都議会令和6年度予算特別委員会速記録第四号（五十嵐えり質疑）〔repo初出・神田川系B/C算定の都側一次文言〕

- **書誌〔確認: 本文取得〕**: 東京都議会 予算特別委員会速記録第四号（令和6年度・総括質疑第3日・[gikai.metro.tokyo.lg.jp/record/budget/2024/4-09.html](https://www.gikai.metro.tokyo.lg.jp/record/budget/2024/4-09.html)）。五十嵐えり委員（当時都議会議員）の総括質疑と**中島東京都技監**の答弁。開催日は本文に表記なし＝**令和6年2月下旬〜3月**〔五十嵐質疑の「本年の二月二十六日から準備工事が始まって」・「今年の説明会（二月二十二日・二十三日）」言及から2024年2月末以降直後の会期〕。
- **石神井川上流地下調節池の諸元〔確認: 技監答弁文言〕**: 西東京市の南町調節池から武蔵野市の都立武蔵野中央公園に至る**トンネル式地下調節池・延長約1.9km・貯留量約30万m³・青梅街道等の道路下**。**令和4年3月都市計画決定・同年10月都市計画事業認可・2024年2月26日準備工事開始・本体工事は令和7年度から**。
- **事業費の4変遷〔確認: 五十嵐質疑文言〕**: ①2023年1月18日・22日の住民説明会（武蔵野市千川小学校）で建設局が**600億円**と説明（技監は「計画検討段階の概算・過去の調節池シールド工事を参考にした算定」と回答）→②**877億円**（令和5年11月27日作成のB/C資料・国庫補助申請用）→③**989億円**（令和5年1月末公表）→④**1,073億円**（令和6年1月26日公表の令和6年度予算概要・技監「主要資材価格上昇のため」）＝**説明会で住民が金額飛躍に驚いた経緯の一次記録**。
- **B/C=1.31の算定構造〔確認: 質疑＋答弁の突き合わせ〕**: ①B/C資料（令和5.11.27・国庫補助採択申請のため河川整備計画策定専門家委員会に諮ったもの）で**便益1,154億円・年平均被害軽減期待額85.4億円・B/C=1.31**。②計算は**超過確率1/2（無害流量・時間40mm相当＝石神井川が溢れない水準）と1/10（時間65mm・目標75mmのうち流域対策分10mmを除く）の2ケースのみ**で、国交省「治水経済調査マニュアル（案）」（令和2年4月・同書27頁の6ケース設定「区間確率が滑らかに減少するよう配慮」）に反するとの批判。③五十嵐試算＝1/10規模の被害軽減427億円の年平均は42.7億円となるはずで、**2ケースの直線平均213.6億円×区間確率0.4=85.4億円とすることが過大**、42.7億円で再計算すれば**B/C=0.66**〔質問者側試算文言〕。④技監は「二分の一と十分の一の比較でその二つで十分」・「213.6掛ける0.4で85.4。42.7割る10ではない」と反論。
- **神田川・環状七号線地下調節池のB/C算定の明示〔確認: 技監答弁・本資料の核心〕**: 五十嵐「神田川・環状七号線地下調節池も**二十分の一と二分の一の二ケース**で想定計算をしていますけれども、これの理由を教えてください」に対し、技監＝「神田川では、河川整備計画の策定時に、整備期間全体における費用対効果…**調節池に加えまして流域対策あるいは護岸、これらの全てが完成した場合の効果を算定している**ということで**二十分の一、これ区部ですと七十五ミリに相当**…一方で、石神井川上流地下調節池では調節池のみの効果を評価するということで、**河川分が受け持つ六十五ミリ、十分の一**…に相当した確率を用いている」＝**神田川・環七のB/Cが「全整備完成後の1/20（75mm）と1/2の2ケース」で算出されていることの都側一次文言〔repo初出〕**。
- **その他の要点〔確認〕**: ①住民説明会＝2024年2月22日・23日**武蔵野市立千川小学校**（[BLOG-220](../blogs/BLOG-220.md)の千川上水沿い「武蔵野市立千川小学校（レンガ造りの外観）」と同校。2023年1月18日・22日も同会場）＝**千川小学校が石神井川上流調節池住民説明会の会場として使用された一次記録**（石神井川水系と千川の名の場の接続は事実の記載にとどめ、解釈はしない）。②氾濫想定＝1/10降雨で調節池なし1,044億円被害・あり616億円（差427億円）。③五十嵐「石神井川の有堤溢水の記録は近年では平成17年9月4日（時間最大雨量109mm・練馬区床上床下浸水32棟）だけ」（[GOV-538](../gov/GOV-538.md)の中野区妙正寺川と同日の被災日文言・石神井川側の被害棟数はrepo初出）。④技監「**平成28年度以降、事業評価委員会の対象となった建設局の事業で費用対効果が1を下回ったものはない**」。⑤五十嵐の開示請求で都の氾濫図が出されたが、練馬区・西東京市のハザードマップ（最大雨量153mm想定）より都の氾濫図（65mm計算）の浸水域が広いという不一致の指摘（技監は目的の違い〔評価用 vs 避難行動用〕で回答）。
- **意義〔観察〕**: ①**神田川・環七調節池のB/C算定ケース（1/2と1/20・全整備完成前提）が都の技監レベルで明示された**ことで、[GOV-485](../gov/GOV-485.md)のB/C=1.41・[GOV-149](../gov/GOV-149.md)森川氏の二重計上疑い・[GOV-539](../gov/GOV-539.md)答弁「単体B/C未確認」の3点が**同一の算定構造問題として接続**した。②石神井川上流調節池のB/C=1.31→[BLOG-296](../blogs/BLOG-296.md)の再提示（1.11・1,310億円）への経路の出発点に当たる議事記録。③2ケース算定と6ケース設定のマニュアル解釈の対立軸そのものの一次記録（他県は複数ケースという指摘含む）。
- **制限・未解決**: ①速記録につき発言の逐語性は議事録作成手続に依存する（都議会の速記録は_ucfirst原則として発言どおりだが、読み上げ資料の数字は答弁資料との照合が望ましい）。②中島技監の「六十五ミリ＝十分の一相当」は石神井川上流地下調節池の評価上の文脈であり、神田川流域計画における河道10mm＋調節池15mmの按分文言（[GOV-539](../gov/GOV-539.md)）とは別の場の表現・両者の換算関係の整理は次回以降。③配布資料「令和5年11月27日B/C資料」本体の取得は未了。
