# [GOV-091] 水道歴史館『上水記』展（2026年10月24日〜11月3日）

- **直接確認（2026-11-12、My TOKYO記事本文全文）**：東京都水道局の告知（2026-10-15付）。東京文化財ウィーク2026にあわせ、水道歴史館（文京区本郷2-7-1）で**2026年10月24日〜11月3日**に実施。
- **『上水記』の書誌〔確認〕**：**寛政3年（1791）完成の江戸上水の記録。石野広通による3部作・全10巻が揃って現存するのは水道歴史館所蔵本のみで、東京都指定有形文化財（古文書）**。**毎年1回の期間限定実物公開**を続けている。第2巻「玉川上水水元絵図并諸枠図」は**縦135.5cm×横514cm**の大紙面（羽村取水堰の江戸期の姿）。今回のテーマは歴代将軍と江戸上水（家康・秀忠・家光のまちづくり、11代家斉と『上水記』成立）。
- **千川上水研究との関係〔観察〕**：『上水記』は千川上水創設・分水史の基本史料群の一つとして、repoでは[GAZ-017](../gazetteers/GAZ-017.md)等で目次・引用レベルで利用している。**実物（全10巻）の限定公開は原本確認の機会**であり、千川上水関係巻の該当丁・図の確認を次回以降の課題とする。国立公文書館デジタルアーカイブにも「上水記 巻2 玉川上水水元絵図並諸枠図」（183-0786-0002）があり、別伝本の異同も未整理。
- **水道歴史展（同時開催）〔確認〕**：「記録写真で振り返る創設期の金町浄水場－給水開始100年－」。**金町浄水場は大正15年（1926）に当時の南葛飾郡・南足立郡・北豊島郡の3郡12町を給水区域とする「江戸川上水町村組合」の施設**として誕生。**北豊島郡**（＝千川上水・谷端川・水窪川・弦巻川の流域にあたる旧郡域）の近代水道化はこの組合経由であり、四河川流域の水道史の広域文脈になる。
- **パネル展示の継続〔確認〕**：水道歴史展は**2026年12月1日〜12月25日（水道歴史館1Fラウンジ）、2027年3月2日〜3月28日（水の科学館1Fアクア・ショーケース）**にパネル展示を継続。
- **制限**：『上水記』全10巻のうち千川上水記事を含む巻の今回は展示されたか、本告知では特定できない（第2巻が主眼）。展示図録・解説資料の入手が次の一手。
