- **千川小学校跡地の特養整備経緯（平成22〜26年）〔直接確認: ht01000930・ht01001020・ht01001120・第253回追記・repo初出〕**: ①平成22年第1回（2010-02）：「**これまで千川小学校跡地活用については、飛び地部分に高松第一保育園を移転改築し、小学校跡地には運動機能に配慮した近隣公園を整備することとしてまいりました。しかし、区内に特別養護老人ホームを整備する必要性が高く、改めて区内用地を検討いたしますと、千川小学校跡地は有力な候補として浮上してきました。**」＝当初の公園整備方針からの転換文言。②平成24年第2回（2012-06）：「**千川小学校跡地と中央図書館跡地の2か所における特養整備に向け、事業者を選定する段階に至りました。6月7日に実施した事業者公募説明会には、千川小跡地に49事業者が、中央図書館跡地に41事業者が参加してまいりました**」＝49事業者参加の公募説明会。③平成26年第4回（2014-12?）：「**特別養護老人ホーム「千川の杜」は平成27年4月1日の開設に向け、大詰めの作業が進んでおります**」＝特養名「千川の杜」の告知文言〔**①「千川の杜」という施設名が区議会レベルで平成26年に出現する文言、②千川小跡地の学校→保育園+公園→特養という転用史の回路が1990年代〜2010年代のスピーチ群で追える**。区史側の対応文言＝[BOOK-243](../books/BOOK-243.md)（せんかわみんなの家・要町3-54-16・216名分増床）〕
- **平成29年（2017）弦巻川水源「丸池」デザインモチーフ文言〔直接確認: ht01001230・平成29年第3回・2017年9月・第253回追記・repo初出〕**: 池袋西口公園整備の項で「**提案内容には、かつてあった弦巻川の水源、「丸池」をデザインモチーフとしたリング状の屋根、裏表のない円形デザイン、また、多様なイベントが可能な2つのステージ、日常の憩いの空間などが描かれ、まさに国際アート・カルチャー都市にふさわしい、他に類を見ない斬新なデザインであります。**」＋「**事業者は、「三菱地所設計」と、南池袋公園を設計した「ランドスケープ・プラス」の共同企業体であります。**」＝**弦巻川の水源丸池を公園デザインのモチーフとする旨の区長スピーチ文言（2017年9月・第3回定例会）＝[BOOK-242](../books/BOOK-242.md)（平成ひすとりぃ本文）と対になる議会側の文言つき二重記録**〔区史本文に先行（同時期）する議会での表明で、丸池モチーフ採用が区の意思決定レベルで発言されていた証拠〕
- **令和7年（2025）公園再構築モデル地区〔直接確認: ht01008190・令和7年第四回・2025-11-12・第253回追記〕**: 「**機能を有する公園が少ない地域である「高田地域」「巣鴨・西巣鴨地域」「高松・要町・千川地域」の3地域を選定しました。令和7年3月から開催してまいりました町会・公園利用者・関係団体へのヒアリングやワークショップでは、「ボール遊びや親水施設が少ない」「遊具が同じものばかりで魅力的でない」…といった意見**」＝**①豊島区の公園再構築モデル地区3地域に「高松・要町・千川」地域が選定されていること、②「ボール遊びや親水施設が少ない」という住民側ヒアリング文言（千川上水旧沿いの親水性の現状認識の資料候補）、③対象選定は令和7年・ヒアリングは2025年3月開始の新しい施策**〔千川の親水施設アメニティに関する議論は谷端川・千川上水系水景の歴史的系譜の現在側の観測点として注記〕

## 制限・未解決

- ①レコード群の範囲は昭和62年〜令和7年第四回（2025-11-12）の157会期。**Index全走査＋該当頁本文取得で照合済みの文言は本ファイルに記録の通りだが、157会期の全本文を逐一保存したわけではない**（千川・谷端川・弦巻川・水窪川の語で走査し該当頁とその前後頁を取得）。②「十カン計画」の表記は「十カ年計画」と表記ゆれ（原典は各頁で「十カ年計画」表記も混在・両方をそのまま記録）。③「千川児童遊園」「千川上水公園」の位置・沈澱池の位置は本文に特定文言なし。④平成26年第4回の会期日の特定（生テキストに日付表記がなかった場合の目録ハッシュ日付の確認）は未了（目録Indexでは日付なし表示）。⑤令和期の走査陰性（谷端川・水窪川文言なし）は「2019-2025の区議会あいざつ本文を対象に千川・谷端川・水窪川・弦巻川の文字列で走査した結果」として記録（会期ごとの本文検索の漏れがないとは言い切れない・順次走査済み頁の範囲）。
