# [GOV-496] 豊島区「区議会定例会招集あいさつ・所信表明」ADEAC公開群〔repo初出・谷端川緑道計画期間の年代文言候補〕

- **書誌〔確認: ADEAC横断catalog検索・2026-11-22取得〕**: 豊島区「**区議会定例会招集あいさつ・所信表明**」（ADEAC「としまひすとりぃ」・作成者＝豊島区・**レコード群の範囲＝昭和62年〜令和5年**・**テキスト一覧の公開あり**＝ADEAC本文検索インデクス対象）。[親目録 mp01000000](https://adeac.jp/toshima-history/catalog/mp01000000)（表題「昭和62年〜」）。各会期が個別目録ID（mp01000040＝昭和62年第4回〔1987-11-17〕・mp01000110＝平成元年第3回〔1989-09-28〕・mp01000150＝平成2年第3回〔1990-09-26〕ほか）で全テキスト公開されるとみられる〔本文検索ヒットと目録の対応個別確認は未了〕。
- **昭和62年（1987）の「谷端川緑道整備」事業化〔本文検索スニペット確認・文言候補〕**: 「昭和62年第1回区議会定例会招集あいさつ・所信表明(昭和62年2月13日)」で「**緑化対策につきましては、引き続き「谷端川緑道整備」を事業化するとともに、「植樹帯の新設」、…**」＝**1987年時点で「谷端川緑道整備」が区の施策として事業化の文言で現れる**〔[GOV-106](GOV-106.md)の「谷端川緑道整備工事」mp10001890（1990.10.5・工事レコード）・「谷端川緑道全線開通」gp1991040100（1991.4.1）に先行する**施策表明レベルの1987年の文言候補**〕
- **平成元年（1989）の十カン計画文言〔本文検索スニペット確認・repo初出候補〕**: 「平成元年第1回区議会定例会招集あいさつ・所信表明(平成元年2月23日)」で「**また、暗渠になっている谷端川の緑道化につきましては、昭和五十八年度より十カン計画で、「みどり豊かなみち…**」＋「平成元年第3回区議会定例会招集あいさつ(平成元年9月28日)」の「**谷端川緑道整備計画期間**」＝**①谷端川の緑道化が「昭和58年度（1983年度）より十カ年計画」として開始された、②「暗渠になっている谷端川の緑道化」という表明文言（1989年2月時点）**〔A. 昭和58年度開始・十カ年＝昭和58〜63年度目安とも読める期間設定の文言候補。B. 「みどり豊かなみち空間づくり」という計画名。1991年4月全線開通（[GOV-106](GOV-106.md)元年表・[README](../../../README.md)第118回）の前史の計画期間文言として**整備史の年代枠を前進させる**。C. 平成2年第1回（1990-02-22）の「みどり豊かなみち空間づくり」として進めてまいりました谷端川緑道化計画」〔本文検索スニペット確認・文言候補〕の使用例も併せて同系の文言候補とする〕
- **意義〔観察〕**: ①谷端川緑道の整備史はこれまで 1990年10月5日「谷端川緑道整備工事」レコード（[GOV-106](GOV-106.md)〔所在のみ〕）→1991年4月1日「全線開通」（元表）→1993年公園計画への算入（第118回・[README](../../../README.md)）が下限で、**1987年（事業化表明）・1983年度（計画開始・十カ年）という上限側の年代文言が加わった**（緑道整備の計画史の年代絞り込みに寄与）。②「暗渠になっている谷端川」という表現の行政側使用の定点（1989・平成元年）になる（[BOOK-124](../books/BOOK-124.md)の1937年「下水道工事によって暗渠」の註記から52年後の水平側の文言）。
