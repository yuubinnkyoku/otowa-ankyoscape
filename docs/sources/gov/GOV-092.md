# [GOV-092] 石神井公園ふるさと文化館「所蔵資料リスト」の千川上水記録フィルム写真39枚キャプション群

- **書誌〔確認〕**: 練馬区立石神井公園ふるさと文化館「所蔵資料リスト」（PDF・文書類／絵図類／写真・フィルム類／くらしの道具等の全収蔵品目録）。https://www.city.nerima.tokyo.jp/kankomoyoshi/bunka/nerimi.files/hurubunrisuto.pdf 。2026-11-12本文（テキスト）取得・直接確認。同リスト自体は[MAP-119](../maps/MAP-119.md)・[MAP-120](../maps/MAP-120.md)・[MAP-155](../maps/MAP-155.md)・[MAP-156](../maps/MAP-156.md)・[GOV-038](GOV-038.md)の所在確認に既利用だが、**「写真・フィルム」欄の千川上水記録フィルム39枚のキャプション群は本ファイルで初めて資料化**。
- **記録フィルムの概要〔確認〕**: 「千川上水記録フィルム」は**暗渠化が練馬区内で本格化する直前の昭和27（1952）年頃に撮影**され、**玉川上水から取水する付近から巣鴨付近まで**の千川上水沿いの風景を記録（[GOV-070](GOV-070.md)のカラーリバーサル60コマと同系の影像史料。コマ数・媒体の対応関係は未確認）。リストには39枚のカラー写真のキャプションを掲載。
- **〔確認〕 GHQ関東軍政部の千川上水取水（repo初出）**: 写真37（板橋区板橋1丁目・現在の板橋区立板橋一丁目児童遊園）のキャプション: 「第二次世界大戦前・戦中は東京第二陸軍造兵廠板橋製造所、**戦後はGHQ関東軍政部がここで千川上水から取水していた**」。造兵廠板橋製造所による千川取水は知られるが、**戦後のGHQ関東軍政部取水の地点・事実はrepo初出**。板橋一丁目児童遊園地点（千川下流部）での取水であり、1971年途絶までの戦後の千川上水利用の担い手を補う記録〔確認: 目録キャプション〕。
- **〔確認〕 田中水車の稼働終了年の第3データ**: 写真9（上石神井1丁目）: 「**昭和40年（1965）頃まで、千川上水の水で稼働していた田中水車**」。sirakigiの「昭和44年2月まで」（[BLOG-094](../blogs/BLOG-094.md)・『練馬の産業I』経由）に対し、**文化館目録は「昭和40年頃まで」と表記**。観察系証言（昭和40年頃まで）と一致する第3のデータポイントであり、表記差は断定せず並記。
- **〔確認〕 九頭竜橋の位置の具体化**: 写真13（中野区上鷺宮4丁目）: 「千川上水にかかっていた九頭竜橋。**橋は富士見台駅入口付近交差点にかつてあった**」。[PAP-027](../papers/PAP-027.md)の九頭龍橋・九頭龍弁財天（1974再建）と橋名が一致し、**1952年時点の橋の所在が交差点単位で特定される**（橋名表記「九頭竜／九頭龍」のゆれはそのまま記録）。
- **〔確認〕 中新井（上新街）分水の流末**: 写真19（中村北1丁目）: 「千川上水の**中新井（上新街）分水の取水口。この分水は中新井川に合流していた**」。[GOV-005](GOV-005.md)（中新井の池=中新井川原流）・[ORG-019](../org/ORG-019.md)（濯川=中新井村分水）を、1952年当時の写真キャプションとして裏付ける文言。
- **〔確認〕 1952年時点の暗渠化進捗の地点別記録**: 写真27（栄町・武蔵大学付近）「千川上水の暗渠化が進められている様子」・写真30〜31（旭丘1丁目）「暗渠工事がかなり進み、水の流れがすでに見られない」「**暗渠化された直後の様子。子どもが歩いている所に上水が流れていた**」・写真34（要町3丁目・千川児童遊園）「すでに暗渠化されている」・写真36（大谷口）「石橋の手前では開渠、下流ではすでに暗渠化」([GOV-071](GOV-071.md)同旨)・写真38（滝野川6丁目）「**第二次世界大戦前にすでに暗渠化**。ここで王子方面に分水」。**1952年撮影時点で旭丘（武蔵学園付近）は「暗渠化された直後」**であり、[BLOG-113](../blogs/BLOG-113.md)（1953年・武蔵学園前暗渠）と[ORG-019](../org/ORG-019.md)（1959〜60年・学校付近暗渠）の年次差問題に対して、**1952年末〜1953年説を支持する方向の傍証**（撮影時期「昭和27年頃」の幅を含め断定はしない）。
- **〔確認〕 移設・現所在の公式文言**: 写真20〜21（豊玉北6丁目）日川地蔵・施餓鬼供養塔「**現在、南蔵院墓地（練馬区中村）に移されている**」（[PAP-027](../papers/PAP-027.md)と整合）／写真28（旭丘1丁目）千川上水堤植桜楓碑「**千川通りと江古田銀座の分岐点にあった。碑は、現在、付近の浅間神社に移設されている**」（[BLOG-101](../blogs/BLOG-101.md)の移転〔伝聞〕の公式目録レベルでの確認）／写真32（南長崎6丁目）千川地蔵「現在、能満寺（練馬区旭丘）に移されている」（[PAP-027](../papers/PAP-027.md)の1940年代移設説と整合）。
- **〔確認〕 そのほかの新規細部**: 写真10（南田中）「千川上水の向かって右側の校舎は、この地にかつてあった**育英工業高等専門学校**か」（1952年時点の学校名の記録。repo初出候補）／写真39（西巣鴨2丁目）「千川上水は、かつて**取水口からこの付近まで素掘りの水路**となっていた」（素掘り区間の下流端が西巣鴨付近とする文言）。
