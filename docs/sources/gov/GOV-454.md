# [GOV-454] 高田町現状調査 — 下水道の石神井既設＋三河島新設の二系統と執行者=高田町長

- **書誌〔確認＋表記差異の記録〕**: NDL次世代デジタルライブラリー書誌は『北豊島郡高田町現状調査』（東京市臨時市域**擴張部**編・[book/1900501](https://lab.ndl.go.jp/dl/book/1900501)・縦割OCR）。**ただし本冊の対象は雑司ヶ谷・目白方面の高田町＝豊多摩郡高田町（1926年町制・現新宿区高田馬場・豊島区高田周辺）と考えるのが自然で、書誌の「北豊島郡」表記は原簿側の表記差異（誤記または旧郡呼称の混用）の可能性がある**〔本ファイルでは両表記を併記し断定しない。槪要章本文も「北豊島郡ノ南部」と自称するOCR文字列が見え、原簿側の表記である可能性が残る＝要原画像照合〕。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**高田町冊**＝弦巻川・妙正寺川系の下流側（面影橋・雑司ヶ谷側）の町の1冊。
- **下水道の既設＋新設の二系統構造〔文言候補・本ファイルの核心〕**: 「**本町ニ於ケル下水道事業ハ〓和四年十二月二十九日髙田町下水道調査費四千九百余円ヲ臨時質(費?)トシテ計上シ昭和五年一同(月?)ヨリ諸(般?)ノ準備ヲ整ヘ同月十八日ヨリ実地ニ就キ下木道(水道?)中心線ノ選定ニ着手シタリテ町内ノ一部ナレドモ今後設ケラルヽモノハ新設三河島系統ニ依り管渠延長一九、〇三四…(19,034m候補)ニシテ總工費一五〇八…(150万8千円候補)円ナリ…一日モ速ク其ノ完備ヲ期スベク努メ居レリ尚本事業ノ執行者ハ髙田町長ト指定セラレタリ。既設ノモノハ石神井系統ニシ(テ?)**」＝**①昭和4年（1929）12月29日に高田町下水道調査費4,900円余を臨時費として計上、②昭和5年（1930）1月から準備・同月18日から実地の下水道中心線選定に着手、③町内の一部には既に石神井系統（石神井側処分区の既設管渠）が存在し、今後新設されるものは三河島系統（計画管渠延長19,034m候補・総工費150万8千円候補）、④執行者＝高田町長**〔**①1931年時点で高田町域が石神井系統（既設）と三河島系統（新設計画）の二系統に跨っていた一次文言候補、②下水道実施調査着手の年月日（昭和4.12.29計上→昭和5.1.18選定着手）の行政側の定点、③数値はOCR数字崩壊のためすべて候補値**〕。**弦巻川／妙正寺川への直接言及は本冊fulltext走査限りで陰性**（陰性記録として掲げる）。
- **荒玉水道負担金〔文言候補・数値〕**: 荒玉水道（荒玉水道町村組合）の負担金12,439円の文言候補（OCR数字要照合）＝高田町の上水道側の費用負担の定点（[GOV-450](GOV-450.md)瀧野川町の荒玉水道第四水圧（西ヶ原484番地）と同組合への加入側の帳簿例）。
