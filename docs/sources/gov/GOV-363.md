# [GOV-363] 旧町名主家記・弘化2年の橋の列挙 — 掃部橋・菊桟橋・服部坂橋〔第158回〕

- **書誌〔確認〕**: 『旧町名主家記』の8巻本の[5]冊（写本・町名主の家の記録類の綴り）。NDL次世代デジタルライブラリー [book/2547486](https://lab.ndl.go.jp/dl/book/2547486)。**くずし字写本でOCR崩壊が大きく、引用文言はすべて原画像照合を要する**。
- **弘化2年4月8日付文言の橋の列挙〔確認・文言候補〕**: 弘化2年（1845）4月8日付の文言（青物町名主小左衛門の申渡・名主役の金銭関係の文脈と思われる）の中に、橋を渡る字（あざ）の列挙として「**渡ル字菊桟橋**」「**渡ル字掃部橋 十(小?)日向水道町より同所へ渡ル字服部坂橋**」と読める文言群。〔**①掃部橋が「（小）日向水道町より同所（＝西古川町側か・前後の文言から当該橋の対岸）へ渡る」橋として、渡り（通行）の文脈で列挙される文言候補**＝[GOV-221](GOV-221.md)（文化13〜文政6年・「水道町より西古川町え渡ル字掃部橋は惣水落と申名目無之」の先例言及）と**位置（水道町↔西古川町）が整合する弘化期の追記的 datapoint**。**②菊桟橋が同じ列挙の中で掃部橋と併記される文言候補**＝[GOV-220](GOV-220.md)（嘉永銘書・「里俗掃部橋」「里俗菊桟橋」の併記）に**先行する（約8年前の）菊桟橋の文言候補**＝掃部橋・菊桟橋の2橋名の併存が銘書以前の町方文書でも見える方向の候補。**③服部坂橋＝repo初出の橋名候補**（服部坂〔現在の小日向水道町〜西片町側の坂か・比定は未確定〕に架かる橋か、坂名由来の橋名かは本文言からは特定できない・要照合）。橋の列挙の文脈（通行・拝領地の四至か名主役の何かの理由か）と「同所」の指示対象は原画像照合まで保留する。〕
