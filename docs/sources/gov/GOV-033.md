# [GOV-033] 豊島区「橋梁の点検」：宮下橋・江戸橋の公的所在地

- **資料〔確認〕**：豊島区公式「[橋梁の点検](https://www.city.toshima.lg.jp/436/machizukuri/toshikekaku/kyoryo/019544.html)」（ページID **3092**、**2026年7月13日更新**）。同ページは、**令和6年度（2024年度）**に区管理14橋のうち13橋を点検したと記し、橋名・箇所・診断区分を表で公表する。
- **宮下橋〔確認〕**：表のNo.1は「**宮下橋**」、箇所は「**自巣鴨三丁目25番先 至巣鴨一丁目36番先**」、診断区分は「**Ⅱ**」。同ページではⅡを「予防保全段階」と定義する。
- **江戸橋〔確認〕**：表のNo.2は「**江戸橋**」、箇所は「**自巣鴨三丁目1番先 至南大塚一丁目32番先**」、診断区分は「**Ⅰ**」。**巣鴨三丁目1番先は宮下橋ではなく江戸橋の欄**に現れる。
- **付属図〔確認：目録・図中の橋名〕**：リンク先「[点検橋梁案内図](https://www.city.toshima.lg.jp/documents/3092/tenkenkyoryoannaizu.pdf)」は①宮下橋・②江戸橋を別項目として記載する。座標や旧河道の描線はこの資料では確定していない。
- **対象時期の区別**：2026年7月13日は**ウェブページ更新日**、2024年度は**点検年度**であり、橋の架設・改築年を表さない。
- **出典**：豊島区「[橋梁の点検](https://www.city.toshima.lg.jp/436/machizukuri/toshikekaku/kyoryo/019544.html)」（ページID3092、2026年7月13日更新、令和6年度点検結果）／同「[点検橋梁案内図](https://www.city.toshima.lg.jp/documents/3092/tenkenkyoryoannaizu.pdf)」。
