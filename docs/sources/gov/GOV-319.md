# [GOV-319] 衛生法規 沿革類纂（1880）— 明治10年丙第5号「飮用水營業人心得」の全文

- **書誌〔確認〕**: 『**衛生法規 : 沿革類纂**』（**1880**〔明治13年〕。NDL次世代デジタルライブラリー [book/797019](https://lab.ndl.go.jp/dl/book/797019)）。飮食物関係の警察規則を沿革順に類纂。**引用文言はOCR由来で原画像照合を要する**。同一規則の文言は『本朝民鑑』附録庚巻（1880・[book/788099](https://lab.ndl.go.jp/dl/book/788099)）にも再録されており、対校可（本ノートでは797019を採用）。

## ①明治10年9月19日東京警視本署丙第5号「飮用水營業人心得」全文〔確認文言・repo初出の規則〕

- 「**明治十年九月十九日 東京警視本署丙第五號達 神田玉川兩上水及ヒ利根川ヨリ汲取候販賣ノ飮水運送船 川々ニ於テ風波ノ爲メ潮水等混入候儀有之候テハ不相成候間右營業人心得方自今左ノ通假リニ相定候條此旨可相達事 第一條 神田玉川兩上水及ヒ利根川ヲ除クノ外他ノ川々ニ於テ飮水汲取ベカラス 第二條 汲取タル飮水ニ潮水及ヒ汚穢物混入セサル様運搬船ハ板蓋ヲ用ユベシ 第三條 (第一章) 該船ハ日々(〓潔=清潔?)ニ掃除ヲナスベシ 上水樋口ヨリ汲取候節ハ微塵鐵網或ハ麻布張枠等ノ水漉(器具ヲ用ユベシ) 第五條 飮水販賣ノ節水桶ハ必ス蓋ヲ用ユベシ**」（第4条は割付崩れで文頭が欠け文言候補）。
- **意味〔確認・repo初出〕**: ①**神田玉川兩上水（＋利根川）が飲料水の汲取許可水源として抽出され、他川からの汲取を禁止**した明治10年（1877）の規則＝**兩上水取締仮規則（明治11年10月甲57号〔[GOV-313](GOV-313.md)〕）の2年前の段階で、両上水は水船（運送船）による汲売りの水源だった**ことの規則レベルの記録。②**「上水樋口ヨリ汲取候節ハ微塵鐵網或ハ麻布張枠等ノ水漉器具」**＝**上水の樋口（樋管の取水口）で水商人が直接汲取していた**運用の一次文言〔repo初出〕＝給水網末端の「上水井」・樋管経由の利用形態（[GOV-252](GOV-252.md)系の吐棄水汲売り・水船販賣の系譜）の明治10年時点の取締側の記述。③「潮水等混入」＝運送中の水質管理（板蓋・桶蓋・清掃）の心得＝東京の水売り業の実務資料。

## ②明治11年5月9日乙第18号「飮料水注意法」〔確認文言・GOV-315の同文対校〕

- 不潔の水の飲用注意・井戸側の新調補理・下水の設置等の注意法全文（[GOV-315](GOV-315.md)の令類纂版と同文言）＝飮用水行政の注意喚起側の規則として甲57号（水源保全）とセットで運用された。

## 位置づけ〔観察〕

- 兩上水取締行政の通時系列の前端が拡張: **明治10年9月19日丙5号（飮用水營業人心得・水船の汲取水源の指定）→明治11年5月9日乙18号（飮料水注意法）→明治11年10月29日甲57号（兩上水源取締假規則〔[GOV-313](GOV-313.md)〕＋番外〔[GOV-314](GOV-314.md)〕）→明治12年2月26日甲6号（禁例化〔[GOV-312](GOV-312.md)〕＋心得〔[GOV-315](GOV-315.md)③〕）**。丙5号は仮規則が水源・敷地の保全を定めたのに対し、**水商人（営業人）側の汲取・運搬の心得**を定めた点で補完関係にある〔観察〕。利根川が並列の水源とされた点は、当時の江戸川・利根川筋の水売りの実態を示す副次資料。

## 制限・未解決

- ①第4条の文頭の欠落部分（割付照合）。②「〓潔」は「清潔」の判読候補。③丙5号の原布達（明治10年）の直接確認（本書は1880年の沿革類纂・二次 compilation である点に注意）。④「上水樋口」の具体的位置（どこで水商人が汲取ったか）は本規則からは特定できない。
