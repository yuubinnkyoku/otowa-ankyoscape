# [GOV-099] 東京大学文書館デジタル・アーカイブの千川関係記録群

- **所在〔確認: 東京大学文書館デジタル・アーカイブのキーワード検索「千川」（curl+UA・`https://uta.u-tokyo.ac.jp/uta/s/da/docarchive?search=千川`）で17件がヒットし、タイトル・参照コード・年代域を目録レベルで確認〕**。すべて「特定歴史公文書等」（一部はIIIF画像公開・CC0/PDM）。〔**repo初出の一次記録群**。既収録の森島2021論文（三菱史料館「樋線切絵図11葉」）が復元した明治期配水経路（[README §千川](../../../README.md)）の**受給者側（帝国大学・帝國博物館）の行政文書による裏付け**になる〕。
- **帝国大学・千川水道会社関係（S0001/S0004系）〔確認: 目録〕**:
  - **「千川水道新設ニ付外国教授館ヘ引樋ノ件」S0001/Mo040/0027・S0001/Mo045/0027（明治14〔1881〕年6月）**＝千川水道（會社）給水開始直後の大学側引樋記録〔明治14年6月という年次は[GOV-077](GOV-077.md)（明治13年設立・14年開設）と整合〕。
  - 「千川水道會社へ本學給水工事粗落成ニ付上水掛渡方申入ノ件」S0004/51/0026（明治22〔1889〕年6月3日）・「給水工事落成ニ付従来配水ノ口樋差塞方申入ノ件」S0004/51/0027（6月22日）。
  - 「會計課ヨリ千川上水本学構内煉瓦造水溜迄ノ支線増設ノ分仮引渡」S0001/Mo110/0098（**明治29年**・上位資料「文部省往復 明治二十九年」）＝**本郷構内の煉瓦造水溜（レンガ造貯水槽）までの千川上水支線増設**。IIIFマニフェスト（画像3枚）を確認〔画像本文の判読は未実施〕。
  - 「千川水道株式會社へ本学内給水用用水支線増設方ニ付照會并ニ右ニ関スル契約書下付方ノ件」S0004/54/0028（〔明治〕29年9月19日）・「本学構内千川上水引用期限契約満期後継續年限等ニ關シ千川水道株式會社トノ往復」S0004/54/0029（〔明治〕30年12月27日）。
  - **「千川水道株式會社へ本学引用ノ水量減少ノ義ニ付照會」S0004/55/0061（明治31〔1898〕年12月10日）**＝千川上水の水量減少を明治31年時点の行政文書で指摘〔[PAP-028](../papers/PAP-028.md)（透水面減少⇔地下水位低下）・[PAP-018](../papers/PAP-018.md)（湧水減衰）の仮説に対し、世紀転換期の水量低下を文書レベルで裏付ける候補。断定はしない〕。
  - 「構内給水ノ義水道部ヨリ送水ニ付従来引用ノ千川上水ノ内吹井五十箇分送水停止ノ義照会」S0004/56/0025（〔明治〕33年2月1日）・「五十箇ノ水賦金一箇九円ニ請求」S0004/56/0026（〔明治〕33年3月12日）＝**水賦金一箇九円という給水単価の数値**。
  - **「千川水道会社取締役へ該上水引用觧約ノ通知」S0004/57/0010（明治35〔1902〕年10月13日）**・「該上水引用觧約ニ付右断水ニ要スル費用請求」S0004/57/0025（明治36〔1903〕年1月12日）＝**東京帝大の千川上水引用解約・断水の年次**〔森島2021の「1908年6月25日千川水道会社解散」との前後関係＝大口需要者であった帝大が解散6年前に離脱した過程として記録。断定はしない〕。
- **帝國博物館・上野公園への千川上水樋線（S0003系）〔確認: 目録＝repo初出の個別文書〕**:
  - 「帝國博物館ヨリ千川上水樋管修繕ノ件ニ渉リ問合」S0003/07/0221（明治22年12月28日）・「上野公園ニ引用ノ千川上水樋管修繕ニ付該費金支出方照會等ノ件」S0003/10/0021（明治23年4月17日）。
  - **「千川上水樋線ノ内谷中上三嵜北町ヨリ上野公園地迠ノ土管伏替工事落成ニ付本学負担ニ属スル工事費囬送方照會」S0003/16/0085（明治29年5月8日）**＝**谷中上三崎北町から上野公園までの千川上水樋線（土管）の伏替工事**で、明治20年代後半まで同樋線が維持運用されていたことの行政文書による裏付け〔森島2021（白山坂上→肴町→千駄木林町→谷中三崎町→上野公園支線）の実在を維持記録側から補強〕。
- **竹内松次郎関係資料「千川上水ノ由来並千川堤桜ノ事」F0264/S02/0519〔確認: 目録・詳細メタデータ〕**: 収蔵は**柏（東京大学柏図書館）**・資料区分「歴史資料等」・**2点の冊子**・作成者**竹内松次郎**（旧制第一高等学校校長）・資料入手先**柳下洋子**・備考「同一表題だが内容は異なる。本文に写真がある方は**1932（昭和7）年頃**と推測。本文に写真がない方は**1937（昭和12）年以降**と推測」・利用条件**要審査**。〔**千川上水の由来と千川堤の桜を主題とする昭和期の冊子の実在**＝[BLOG-101](../blogs/BLOG-101.md)（千川堤植桜楓碑1915建碑・碑文）・[BLOG-155](../blogs/BLOG-155.md)（千川駅説明板・昭和2年桜伐採）・[ORG-027](../org/ORG-027.md)（武蔵写真館・千川通りの桜1957年）と連なる**千川堤桜研究の一次史料候補**。内容は未見・要審査で、竹内が誰に向けて記したか（一高・東大の敷地と千川の関係を含む）は本文確認待ち〕。
- **意義〔観察〕**: ①明治14年（給水開始）→明治22年（本学給水工事）→明治29年（煉瓦造水溜支線増設）→明治31年（水量減少照會）→明治33年（50箇吹井停止）→明治35年（解約）→明治36年（断水費用）という**東京帝大側の千川引用の通史が一次文書の年次で初めて一括して確認できた**。②上野公園への樋線維持記録は森島2021復元の支線を実務文書で裏付ける。③「煉瓦造水溜」＝本郷構内のレンガ造貯水槽の存在はrepo初出の施設情報。
- **制限・未解決**: ①各文書の本文（IIIF画像はS0001/Mo110/0098のみ確認・それ以外の画像有無は未確認）。②F0264の内容・要審査資料の閲覧手続き。③明治33年「水道部ヨリ送水」は（市営）水道への切り替えと解せるが断定しない。④竹内松次郎の冊子と柳下家（[GOV-096](GOV-096.md)の雑司が谷柳下家）の関係は未確認。
