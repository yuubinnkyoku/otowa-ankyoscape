# [GOV-254] 市中取締書留 [127]（安政）— 水車稼61人惣代と上保谷新田名主伊左衛門

- **書誌〔確認〕**: 『市中取締書留』第127冊（安政期・写）。NDL次世代デジタルライブラリー [book/2572362](https://lab.ndl.go.jp/dl/book/2572362)。**引用文言はOCR由来で要原文照合。**
- **水車稼61人惣代と上保谷新田名主伊左衛門の連印〔確認・repo初出〕**: 「**右水車稼六拾壱人惣代 右上所沢村四月十三日 安政三辰年七月十二日 平蔵印 下祖師（ヶ谷?）村仲吉印 上保谷新田名主伊左衛門印 野中新（田?）内年寄三反右衛門印 御奉行所様**」＝**安政3年（1856）7月12日付の「水車稼61人惣代」の願・書面の連印者に上所沢村・下祖師ヶ谷村・上保谷新田（名主伊左衛門）・野中新田が並ぶ記録**＝水車を稼ぐ者61人の惣代が多摩郡の複数村の名主層で構成され、その中に上保谷新田名主伊左衛門がいたことの一次記録。
- **粉屋再興願の却下と「文化以来之仕法」〔確認〕**: 御奉行所（町奉行）側の文言——「**粉之儀は取調候所…難役沙汰旨申渡候品ニ付 商法致定等可取極筋二は無之候間 御見込之通願書下ケ被遣候**」「**粉屋共再興願之儀者取調候処 文化以来之仕法ニ付 難役沙汰旨申渡候品ニ付…御見込之通願書下ケ被遣候**」＋「播磨守御書面」「井戸対馬守え御掛合之趣」＝**①粉（製粉）をめぐる願いが取調の上「難役沙汰」（沙汰止み）として処理されたこと、②「文化以来之仕法」＝文化年間（1804-18）以来の処理方法に従って却下されたこと、③播磨守（町奉行池田家か）・井戸対馬守（井戸覚弘か）の役所経由**＝**水車による粉屋稼の再興が文化期以来の仕法で制限されていた**ことの安政3年の実務記録。
- **位置づけ〔観察・断定はしない〕**: ①[GOV-250](GOV-250.md)（慶応3年・玉川上水留）に「三田千川両用水路江御用水車御取建」により年中定水化という水車関連の文言があり、[GOV-098](GOV-098.md)（練馬区史）に千川上水での天明以降の水車新設不許可の方針があるが、本記録は**玉川上水沿いの保谷新田・上保谷新田側の水車・粉屋稼の安政期の状況**を伝える。②千川への直接言及はなく、本記録の水車が玉川上水・千川用水のどちらに係る水車かは本冊のみでは特定できない。③伊左衛門は[GOV-250](GOV-250.md)（慶応3年）・[GOV-251](GOV-251.md)（慶応4年・四分水壱分呑水料）と同名の上保谷新田名主で、名主の継続とみるのが自然だが断定はしない。

## 制限・未解決
