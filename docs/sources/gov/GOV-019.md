# [GOV-019] 文京区公式「礫川公園」

## 書誌・公開状況

- 文京区土木部みどり公園課、公式施設案内「礫川公園」（ページID 4709、2023年4月14日更新、2026年10月29日閲覧）。
- 所在地は文京区春日1-15。後楽園駅北側、小石川台地の東端に位置すると説明される。

## 内容メモ

- この一帯はかつて軍用地で、戦後、都営住宅・中央大学・戦没者慰霊堂・公園用地に分割されたと記す。
- 昭和39年（1964年）に東京都が公園を造成し、翌昭和40年（1965年）に文京区へ移管したと記す。
- 公園は高低差を利用した3段構造で、下段は広場、中段は池と花壇、上段は遊具のある広場と説明される。中段・上段の間には高さ約10mのカスケードがある。
- このページは園内の池・カスケードの水源、造成前の池の存否、旧谷端川（小石川）との水理的な接続を示していない。
