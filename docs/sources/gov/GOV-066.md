# [GOV-066] 「【淀橋浄水場】千川線ポンプ所」紙焼写真

- **資料〔確認：東京都水道歴史館デジタルアーカイブ目録、2026年11月11日閲覧〕**：同館デジタルアーカイブ「[【淀橋浄水場】千川線ポンプ所](https://www.ro-da.jp/suidorekishida/content/detail/P0242_014_02)」、**資料ID P0242_014_02**、紙焼写真、寸法W16.2×H10.7cm、シリーズ「淀橋浄水場水質試験室・淀橋浄水場史写真」巻次57、制作者**東京都水道局**、制作年月日**昭和中期～後期**、地域・施設名「淀橋浄水場／新宿区」。
- **備考〔確認：目録表示〕**：「裏面に『千川線ポンプ所／正門側／40』、**『志村』丸印あり**」。公開日は2023年3月31日。
- **repoでの位置づけ〔推定〕**：昭和中期〜後期の近代水道導配水系統に**「千川線」という線名**が存在し、淀橋浄水場から**志村（板橋区）方面**への配水に関係したと読める目録記録で、**「千川」の名称が近代水道施設に継承された例**の候補。**「千川線」の経路・竣工年・千川上水旧路との位置関係は一切未確認**で、旧水路の流路復元には使えない。写真画像の判読も未実施。
