# [GOV-626] 千代田区文化財サイト「神田上水懸樋跡」— 標柱・説明板本文の公式公開

## 書誌・確認範囲

- 千代田区公式文化財サイト（edo-chiyoda.jp）の「文化財サイン（標柱・説明板）＞区内の史跡＞か行＞神田上水懸樋跡」頁（[https://www.edo-chiyoda.jp/knainobunkazai/bunkazaisign_hyochu_setsumeiban/2/2/131.html](https://www.edo-chiyoda.jp/knainobunkazai/bunkazaisign_hyochu_setsumeiban/2/2/131.html)・更新日2024年4月12日・場所：神田駿河台二丁目11先・2026-11-27第369回に閲覧ツールで本文全文取得）。repo grep（牛込門外・京橋川給水・俗に万年樋・神田駿河台二丁目11）で既収録なし＝新規。

## 内容メモ（本文全文確認）

- **〔確認・repo初出の公式文言〕万年樋呼称の由来**: 「江戸時代、この辺りには神田上水が神田川を越えるために設けた懸樋（かけひ）がありました。**1658年～1661年（万治年間）に架け替えられ、俗に万年樋と呼ばれました**」＝「万年」が「万治」に由来する（あるいは万治年間架替と俗呼称を並記する）区説明板レベルの文言（[BLOG-262](../blogs/BLOG-262.md)・[MAP-052](../maps/MAP-052.md)の万治年間文言に加わる公式頁）。
- **〔確認〕整備着手年代の公式側表記**: 「神田上水は、江戸で最も早く整備された上水といわれ、**1596年～1615年（慶長年間）に整備に着手したといいます**」＝慶長年間着手「説」として「といいます」留保付きで記載。
- **〔確認〕流路の概略**: 井の頭池・善福寺池・妙正寺池を水源とし、現在の文京区関口あたりに堰が設けられ、**小日向台から小石川後楽園を通り水道橋の下流**に達した。懸樋で神田川を越えた上水は「この辺りから暗渠（あんきょ、埋樋）」となった。
- **〔確認・repo初出〕給水範囲の公式文言**: 「**南は京橋川、東は永代橋より大川（現在の隅田川）以西、北は神田川、西は大手町から一橋門外まで供給されました**」＝給水範囲の四至を京橋川・永代橋・神田川・大手町〜一橋門外で示した区レベルの記載。
- **〔確認・repo初出〕江戸川/神田川呼称区分の明文**: 「なお、関口で神田上水から分水した余水は河川となります。**牛込門外（現在の飯田橋）までは「江戸川」、牛込門外から下流は「神田川」と呼ばれました**」＝江戸川→神田川の名称変更点を牛込門外（飯田橋）とする明文（Wikipedia江戸川橋以東を神田川とする系の記述とも整合）。

## 四河川への使い方
