# [GOV-491] 東京都下水道局「杉並区荻窪地区下水道床上浸水対策計画」〔repo初出・荻窪（高野ヶ谷戸・西田町）の内水対策の諸元〕

- **書誌〔確認: 東京都下水道局の「床上浸水対策計画」様式資料（様式１・様式２・参考図面の5頁構成）・2026-11-21取得〕**: 都下水道局サイトの直URL（`03yokaue_suginamiku`）はアクセス時にJSチャレンジのため、**Wayback Machineのid_スナップ（2025-04-21）**で本文PDF（473,541B）を取得・抽出。**様式（年度計画表にH31〜H36年度欄・工期H31単年計上）から平成30年度（2018）前後の作成と推定**〔文書自体の作成年月の明記なし・断定しない〕。
- **選定理由＝平成25年8月豪雨の被害文言〔確認・repo初出の一次文言候補〕**: 「杉並区荻窪地区は，窪地があるため豪雨の際にたびたび被害の発生する浸水常襲地域であり，**平成25年8月には集中豪雨により床上浸水21件、床下浸水10件及び道路冠水が発生した**」。なお内水浸水シミュレーションにより**10年間に延べ床上浸水被害家屋数107戸・床下浸水を含む延べ浸水被害家屋数240戸**が想定〔2013年8月（平成25年8月）の荻窪地区の浸水被害の行政側数値文言。善福寺川流域の[GOV-486](GOV-486.md)が令和5年台風2号の「西田端〜松見付近（荻窪地区）の溢水」とする下流側事例の、平成25年豪雨側の対応記録として位置づけ〕。
- **整備目標〔確認・「50ミリ対策地区」「床上浸水対策計画」＝repo初出の制度語〕**: 対象降雨**50mm/hr**（昭和61年7月「東京都における総合的な治水対策のあり方について（61答申）」の計画目標＝時間50mmに基づく）＋**「東京都豪雨対策基本方針(改定)（H26年6月）に基づき、杉並区荻窪地区を50ミリ対策地区として定め」**〔[GOV-125](GOV-125.md)（平成30年3月・神田川流域豪雨対策計画〔改定〕）の上位文書「基本方針(改定)」（H26.6）に基づく地区指定の本文実例。README既出の75ミリ対策地区（同基本方針系）と同族の50ミリ側の指定文言〕。
- **事業内容〔確認・諸元〕**: ①**雨水貯留管: 形態=管・集水面積35ha・内法○2,600/○800mm・延長650m・貯留量2,200m³・概算事業費1,430百万円・工期H31**、②**雨水管渠: ○800～2,600mm×650m（1,430百万円・H31・取水人孔4箇所・管理人孔2箇所）**〔年度計画表では雨水貯留管のみがH31年度=平成31年度に1,430百万円計上（H32〜H36は空欄）＝**単年度計上の小規模貯留管**〕。③**整備効果: 被害額296百万円削減・B/C=4.3・経済的内部収益率9.6%**。④**管渠の名称＝雨水管渠・排水区の名称＝新河岸**〔様式２管渠調書の排水区名称。荻窪地区（善福寺川左岸の窪地）の雨水が**新河岸川排水区**の管渠で処理される現行の排水構造の記録として、桃園川幹線（神田川流域）・善福寺川（一級河川）と排水区の帰属を区別する基礎資料。ただし本資料に関係河川は「無し」と明記〕。
- **制度背景〔確認〕**: 「東京都豪雨対策検討委員会」＝**平成18年5月23日設置（下水道局・都市整備局・建設局の3局構成、構成メンバー10名の実名リスト）**→平成19年8月「東京都豪雨対策基本方針」→**平成26年6月「東京都豪雨対策基本方針(改定)」**。内水ハザードマップは**平成18年3月策定済み**（[GOV-485](GOV-485.md)参照の杉並区洪水ハザードマップ・ソフト対策欄の杉並区行）。
- **意義〔観察〕**: ①荻窪地区＝**[BLOG-249](../blogs/BLOG-249.md)のあげ堀・西田たんぼ・[BLOG-250](../blogs/BLOG-250.md)の西田町（田端田圃）から転換した荻窪団地一帯と、[GOV-490](GOV-490.md)の高野ヶ谷戸の天水田圃**という窪地群の、現在の内水浸水対策の枠組みが数値で初めて入る**「窪地があるため」浸水常襲という選定理由文言自体が旧谷地形の現代の行政認識＝旧水田地帯の地形的遺続の傍証資料**、②「関係河川なし」＝この地区の浸水が河川氾濫（外水）でなく内水処理であるという資料上の区別、③令和の善福寺川地下調節池（[GOV-485](GOV-485.md)〜[GOV-489](GOV-489.md)・外水・河川系）と平成末期の荻窪貯留管（内水・下水道系）という**荻窪周辺の治水インフラの2系統分離（外水・河川系／内水・下水道系）**が行政資料側で確認できる。
- **制限・未解決**: ①文書の作成年の明記なし（H31単年計上・年度計画表の構成から平成30年度前後と推定・断定しない）。②貯留管の設置場所（地図は参考図面として画像化されており抽出不能・丁目不明）。③H31年度事業の実施完了の有無は未確認。④「浸水常襲地域」文言の同じ荻窪地区定義の他文書での整合は未照合。
