# [GOV-615] 「養水」「樋口」「白山御殿」掃引の千川系新規8件（1874〜1902）

- **調査方法〔確認〕**: 都公文書館クロス検索（GETレシピ＝第337回ノート§1・chkCls個別パラメータ繰り返し・1リクエスト毎sleep 5〜12秒）で「**養水**」（98件・1頁完結）・「**樋口**」（全16頁・約1,543件・頁送り完結）・「**白山御殿**」（170件・2頁）の3語を掃引し、四河川関連項目の詳細頁（請求番号・MF・コマ）を確認した〔第337〜343回から順送りだった掃引の実施〕。いずれも**本文は未見**（複製物＝マイクロフィルム閲覧可）。多くは荏原郡・南葛飾郡・北多摩郡など四河川水系外（三田養水・六郷領養水・玉川上水系田養水等）で、千川系は以下の8件（＋同一簿冊内の既収録対）。
- **①上保谷新田の千川田用水分水樋口朽損・附替（1874）〔確認・repo初出〕**: 「明治７年７月１９日 上保谷新田地先**千川田用水分水樋口朽損**に付、**附替并に元樋口跡塞方**出来に付検査の義願 **熊谷県管下**南第二大区七小区新庄郡上保谷新田戸長」（明治7年〔1874〕・土木・綴込*004・**６０６．Ｂ５．０６**〔管民願伺届・第４部〈土木（営繕取扱）〉〕・収録先資料ID000123050・[MF]府明Ⅱ明07-067・コマ0006-0766・pkey [819071](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=819071)）＝**千川上水の最上流側分水樋口の朽損・付替え（元樋口跡の閉塞検査）の1874年記録**〔「熊谷県管下」「新庄郡」表記＝上保谷新田（現埼玉県新座市側）が熊谷県→埼玉県に移管された時期の行政文書で、千川用水の上流端（取水口に近い分水樋口）の実務が府県境界変更期に処理されていた一次文言。BLOG-113樋口寸法変遷（1732/1737/1773）・GOV-587⑦の明治10〜11年樋口改正群より前段の樋口物理更新の記録〕。
- **②下板橋宿養水組合の引入示談（1877）〔確認・repo初出〕**: 「**下板橋宿養水組合村々引入方示談相整**の件」（明治10年〔1877〕・租税課・綴込037・**６０８．Ｂ４．０２**〔既決簿・郷村地理・第２号〈租税課〉〕・収録先資料ID000119326・[MF]府明Ⅱ明10-044・コマ0006-0794・pkey [330166](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=330166)）＝**下板橋宿に「養水組合」が存在し、村々の引水の示談が整った**1877年の記録〔下板橋＝千川下流・谷端川放水路域。板橋宿側の千川末端の養水組織の実在が行政記録で確認された点が新規。示談相手の村々・水量は本文未見〕。
- **③中村他16村の千川増水願（1878）〔確認・repo初出〕**: 「第八大区七小区**中村他１６村より千川田養水不足に付増水願** 明治１１年４月１７日」（明治11年〔1878〕・土木課・綴込*178・**６０９．Ｂ７．０７**〔回議録・願伺届・共９ノ４〈土木課〉明治11年従4月至6月〕・収録先資料ID000123137・[MF]府明Ⅱ明11-053・コマ0006-0854・pkey [689285](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=689285)）＝**中村を含む17村が千川田養水の不足を理由に増水を願出た**1878年の記録〔「中村」＝中村分水（[GOV-068](GOV-068.md)・関村分水と並ぶ千川分水の一つ）の本村とみられるが、16村の内訳は本文未見のため比定は保留。GOV-587⑦の明治11年4月2日の樋口改正伏替済（686329）と同年次・同月の実務で、樋口改正と増水願が並行していた可能性を示す（直接の因果は本文未見）〕。
- **④千川宿葛ヶ谷村の養水引入樋口修繕願（1879）〔確認・repo初出〕**: 「明治１２年７月８日 **千川宿葛ヶ谷村田養水引入樋口修繕願**出の義に付伺 南豊島郡葛ヶ谷村総代**名倉甚右衛門**」（明治12年〔1879〕・土木課・綴込*024・**６１０．Ｃ４．０７**〔回議録・願伺〈土木課〉明治12年7〜8月〕・収録先資料ID000123156・[MF]府明Ⅱ明12-054・コマ0006-0670・pkey [699054](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=699054)）＝**葛ヶ谷村（南豊島郡・現豊島区目白・雑司が谷周辺）が千川系の田養水の引入樋口の修繕を願出た**1879年の記録〔「千川宿」呼称を含む文言はrepo初出。「千川宿」＝千川村側の宿・字名か（比定は本文未見のため保留）。[GOV-005](GOV-005.md)（長崎村外三村分水・練馬区資料の葛ケ谷村分水=南長崎6-9千川北曲折点〔第33回〕）の実在分水の樋口修繕の行政側記録として裏付け〕。
- **⑤渡坂清吉引用の分水樋口付替群（1883・4件＋取付通知1件）〔確認×5・渡坂清吉はrepo初出人名〕**: 「渡坂清吉分引の分水樋口付替願の件に付博物局へ支障有無照会候処回答有之に付会社へ示達、博物局へ通知等指令案伺 千川水道会社取締役代理吾孫子義之 土木課 明治１６年６月８日」（明治16年〔1883〕・土木課・綴込(002)063・**６１３．Ｂ５．０６**〔回議録・第１類・乙号・水道・1月ヨリ7月マテ〈土木課〉〕・収録先資料ID000123217・[MF]府明Ⅱ明16-058・コマ0006-0582・pkey [714019](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=714019)）＝**引用主渡坂清吉の分水樋口の付替えについて、千川水道会社・府・博物局（上野公園地管理）の三者で支障有無を照会・示達した**1883年の実務群〔同内容の隣接レコード714020（同日・打合の上着手の申出の通知案）・714021（6月7日・同社社員召喚示達）・714022（6月1日・実地検査済・**上野公園地掛り樋線より分水**・会社より所轄博物局へ照会の上指令）を含む〕。あわせて「明治１６年７月２６日 **博物局より同局并に上野公園地に引用の千川上水樋口取付の義通知**に付、主務員出張立会の処不都合の義も無きに付上申書一覧」（明治16年〔1883〕・土木課・綴込*030・**６１３．Ａ６．０８**〔往復録・第１類・水道・乙〈土木課〉従6月至12月〕・収録先資料ID000123211・[MF]府明Ⅱ明16-026・コマ0006-0319・pkey [715278](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=715278)）＝**博物局（上野公園地）が千川上水を引用する樋口取付を通知し、府の主務員が立会検査した**記録〔[GOV-588](GOV-588.md)④の上野公園地引用願群（1882〜83）の実施側の断面。二橋元長・吾孫子義光（714019は「義之」表記）の千川水道会社取締役側の対応が並ぶ。同じ「樋口」掃引で検出した715262（上野公園地掛り千川上水樋線鉄道会社譲受分樋口測定願）は第313回ノート（GOV-588 dedupe監査）で既知のため本件には含めない〕。
- **⑥紙幣局用水分水の王子村37番屋敷地先文言（1875）〔確認・アイテム単位はrepo初出〕**: 「紙幣局用水分水の儀は田方養水の内**王子村地内３７番屋敷地先にて分水致し候段回答**旁申進 東京府より紙幣寮へ 明治８年１０月１０日」（文書年度明治10〜18年・**６０１．Ａ８．１４**〔第２種 水道＊千川上水道書類並図面・第１３９号〕・収録先資料ID000112301・[MF]市明Ⅰ明18-001・コマ0006-0500・pkey [822393](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=822393)）＝**紙幣局（紙幣寮）への用水分水が「田方養水の内王子村地内37番屋敷地先」で行われていると府が紙幣寮に回答した**1875年の記録〔同一簿冊（第139号・601.A8.14）内の[GOV-587](GOV-587.md)①⑥（822408梗概・822391上申等）と接続する、紙幣局引水の地点文言（37番屋敷地先）を含むレコード。[GOV-587](GOV-587.md)⑥の1875年抄紙局水車群（822391/995856/995935）と同年の回答側〕。
- **⑦分水樋口応急修理費支払方督促（1902）〔確認・アイテム単位はrepo初出〕**: 「分水樋口応急修理費支払方督促の件」（明治35年〔1902〕・水道部・綴込014・**６２５．Ｃ４．２６**〔第１種（水道部）神田千川上水ニ関スル書類〔明治３５年・第１種・神田川上水ニ関スル書類・水道部〕〈水道部〉〕・収録先資料ID000113451・[MF]市明Ⅰ明35-010・コマ0295-0561・pkey [305978](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=305978)）＝**神田千川上水（千川上水の水道部管理期）の分水樋口の応急修理費の支払督促の1902年記録**〔[GOV-588](GOV-588.md)の神田千川上水簿冊（625.C4系）内の実務アイテム。明治35年＝[GOV-587](GOV-587.md)⑩cの郡部諮問第3号（1902年・千川用水組合負担橋梁の府費移管）と同年で、水道部側の樋口維持と組合側の橋梁問題が並行していた時期の記録（直接の関連は本文未見）〕。
- **陰性・見送り〔確認・観察〕**: ①「白山御殿」170件は白山御殿町（小石川区）の市有地売却・墓地許可・道路敷・下水修繕等の地価・不動産系がほとんどで、**白山御殿を水源とする水路・分水系の文言は目録レベルでは確認できず陰性**（[GOV-056](GOV-056.md)千川呼称の白山御殿別説への追加材料はなし。1889年市町村制施行取調の「石神井川養水以南」（金杉村・西ヶ原村551822/551826/551835）は石神井川側の土地描写で四河川水系外）。②「樋口」掃引の380247（千川水道樋口伏換願書却下願・本橋勝右衛門・村沢藤七）は[GOV-588](GOV-588.md)③既収録。③1044186「板橋宿根村水堰取調の義伺」（1885・農商課・荏原郡田用水ニ関スル書類）は添付文書が古市場村・瀬田村・和泉村（玉川上水系田用水）で**千川系は付随文言のみの可能性が高く見送り**〔推定・本文未見〕。④三田養水（三田用水組合）・六郷領養水・石神井川養水群は四河川水系外のため本sourceには含めない（千川上水との関係史料が別途見つかった場合に再検討）。
- **位置づけ〔観察〕**: ①1874（上保谷新田・熊谷県管下）→1875（王子村37番屋敷地先の紙幣局分水）→1877（下板橋宿養水組合）→1878（中村他16村増水願・樋口改正と並行）→1879（葛ヶ谷村樋口修繕）→1883（上野公園地掛り樋線・渡坂清吉付替）→1902（水道部の樋口応急修理）＝**千川上水の分水樋口の維持・付替・増水の実務が上流端から下流・配水末端まで約30年分、行政側目録レベルで並んだ**。②「千川宿」（699054）・「元樋口跡塞方」（819071）の文言はいずれもrepo初出で、樋口の物理的管理（付替え・旧樋口閉塞）の語彙が特定できた。③いずれも**本文未見**のため、樋口位置の比定・村々の内訳・「千川宿」の意味は断定しない。
