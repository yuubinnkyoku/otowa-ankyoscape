# [GOV-445] 神田上水留[12] — 神田橋外明地の掛樋枡修復と真菰堀の文言

- **書誌〔確認〕**: 『神田上水留』[12]（[book/2587467](https://lab.ndl.go.jp/dl/book/2587467)・表紙「**弘化三年五月 神田上水留**」＋「**神田上水 神田橋外弐番三番四番明地掛樋枡御修復一件 …五月 御普請方**」）＝**神田橋御門外の明地（旅籠町明地系統・[GOV-441](GOV-441.md)の天保15年書上の区域）の掛樋枡・真菰堀の修復の一件冊**。**引用文言はすべてOCR由来で要原文照合。**
- **落札と差引検査〔確認・repo初出の会計文言〕**: 「**村田阿波守書面 金五拾八両ヲ以御修復被遊候 …(落札)一金五拾八両 一金六拾壱両三分 差引金三両三分 弐番札元積之方安シ**」＋「**右は…御組合入用之儀相伺候書付 村田阿波守書面 …嘉(伺?)之通一…之儀相伺候書面…四(丑?)四月十一日 落札**」＝**①弘化3（午）年4月11日の落札（58両・2番札・村田阿波守の書面）、②御用済（元積）61両3分との差引3両3分の検査文言**＝**神田橋外明地の修復が「御組合入用」（町方負担）として運営されたことを明示する文言〔神田上水の市中末端区間の維持の負担主体（御組合＝[GOV-384](GOV-384.md)・[GOV-378](GOV-378.md)の寛延2年移行以降の継続）の弘化3年の座標。村田阿波守は同一冊内に別願書文言でも現れる役方候補〕。
- **掛樋枡の内法寸法の変化〔文言候補・本ファイルの核心〕**: 由緒書の文言——「**当春猶又差向候儀ニ付種々手当仕御間ニ合置候間 …取調候処 有来明地懸元極者 内法六寸四方有之 御舂屋懸出揚極之方は内法四寸四方 … 掛替二相成候**（前後に玉川上水の代官町土手上の「仕水」文言・前例として「文政五午年神田上水神田橋外明地懸樋枡御供復之儀」の参照文言）」＝**①明地の掛樋の元極（水元側）の内法が6寸四方だったのに対し、御舂屋（水車の搗米所か・判読は要照合）の懸出揚の極は4寸四方で、②掛替（樋の掛替え）が行われたことの文言候補**〔**神田橋外明地の掛樋の内法寸法（6寸→4寸）の変化の文言候補**＝[GOV-233](GOV-233.md)第163回追記の引取樋の内法寸法群（1寸四方・2寸四方等の白堀区間の私取水樋）と対照する明地側の樋の寸法系列。差し渡し6寸→4寸への狭小化の意味（水量の制限か）は本冊では断定しない〕。
- **真菰堀の文言〔文言候補・repo初出の「真菰堀」語〕**: 「**右は神田上水神田橋外明地 真菰堀懸幷同所御塀 掛樋筋折損 潰水強 去巳年冬 右真菰埋出掛ニ付 鳥飼付方差支候間 水仕掛之儀奥向ゟ申出**」＋「**弐番明地内樋吐口下一 真菰堀 長八間 幅七尺 埋平均 …**」（他に「**真菰堀ゟ吸込之処 倒板八寸四方切抜 古柳側板之内相用 長壱尺五寸 幅壱人 深壱尺五寸之泥留仕付候積**」）＝**①神田橋外明地に「真菰堀」（真菰を植え込んだ浸透・浄化の堀か・機能の断定は保留）が存在して修復対象となったこと、②弐番明地内の樋の吐き口の下の真菰堀（長8間・幅7尺）の埋立、③真菰堀の吸込口の泥留（泥止め）の板仕様の文言**〔**「真菰堀」の語はrepo内で初出候補**（[GOV-233](GOV-233.md)の「真菰堀」OCR注意語の先行例・同系列の文言）＝**上水末端の明地の水路（真菰を用いた水の堀）の構造を記す帳簿候補**。「鳥飼付方差支」の判読要照合〕。
- **枡の修復群と柳の根取込〔文言候補〕**: 「**今度御舂屋掛樋枡場所替二相成 …古樋掘揚候 内木…相撰共役之頭共持込潰方致し相用 蓋付釘〆直 捻皮修復いたし 継手水焼之所切縮指皮入念打堅 銘鉄目壱挺弐拾五匁付壱ケ所江六挺ツゝ懸堅 粕へな土塗伏渡 丈夫二埋立候積**」「**戸田長門守屋敷脇 大サ内法弐尺五寸四方 深四尺 壱ヶ所 埋(枡?)料 右仕様朽損候ニ付伏直候積り**」「**長谷川又三郎屋敷前 壱地形一面 石縁枡 大サ内法弐尺五寸四方 深六尺 壱ヶ所 右仕様朽損候ニ付伏直候積**」「**弐番三番明地 真菰堀内 壱地形一面 枡 大サ内法弐尺五寸四分 深四尺五寸 壱ヶ所 深四尺 壱ヶ所 …同所西之方并四番明地内一同 大サ内法同断 深四尺 弐ヶ所 右仕様朽損候ニ付伏直候積**」「**四番明地内 壱地形一面枡ゟ真菰堀迄 長七間四尺之場所 柳之根取込候に付 書付…之頭差口共惣躰入念ちやん塗之積**」＝**①戸田長門守屋敷脇（内法2尺5寸四方・深4尺）・長谷川又三郎屋敷前（石縁枡・同内法・深6尺）・弐番三番明地真菰堀内（深4尺5寸・4尺の2ヶ所）・四番明地内（深4尺2ヶ所）の枡の朽損・伏直（埋戻し修復）の文言群、②四番明地の枡から真菰堀まで（長7間4尺）の区間に柳の根が食い込んでいたことの文言**〔**神田橋外明地（旅籠町明地系統）の枡（伏樋の竪枡か持出し枡か・構造の断定は保留）の配置と寸法の帳簿**＝[GOV-352](GOV-352.md)（昌平橋外堀井戸の伺書）・[GOV-441](GOV-441.md)（明地の井戸チェーン）の系統の弘化3年の修復実務側の記録。「柳の根取込」は明地の柳の根系が水路に侵入した維持実務の文言候補（[GOV-441](GOV-441.md)の水道町・明地の柳の用例と対照）〕。
- **垣・矢来と通行文言〔文言候補〕**: 「**御掛并弐番三番四番明地真菰堀掛共 一垣 長延百八拾間**（判読保留・要照合）」＝明地周囲の垣・矢来の総延長文言に続き、触文言「**右修復出来寄候に付 明廿日ゟ馬駕籠相通申候 此段御目付江被仰渡可被下候 尤右之段御側衆江も御断返差出申候以上 五月十九日 山城守殿**」＝**修復の完成に伴い明廿日から馬駕籠の通行を再開（相通）することを御目付・御側衆へ断った文言**＝工事中の通行止め（馬駕籠の通行制限）と再開の行政実務の記録候補。
- **前例文言〔確認参考〕**: 「**天保十三寅年 玉川上水 虎御門外(虎ノ門外のOCR候補) 御勘定奉行御役屋敷 岡(?)樋柳 新規御普請之節 …場所見廻り附切共書面之通申渡伺之通被仰渡候**」＋文政5午年神田橋外明地懸樋枡の前例文言（差越す御普請方・御勘定所の文言）＝修復仕様の前例（天保13年・文政5年）の参照文言群で、**神田橋外明地の樋枡修復が文政5（1822）→弘化3（1846）の複数回にわたる系列であること**を示す（文政5年分の本体冊の所在は未確認・今後課題）。
