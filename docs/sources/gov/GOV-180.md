# [GOV-180] 都市計画東京地方委員会 議事速記録 第3号（1931-03-30〜1932-02-08）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第3号』（第4回委員会 1931〔昭和6〕年3月30日開会・第5回 同年8月1日・第6回 同年11月18日・第7回 1932〔昭和7〕年2月8日開会を収録）・NDL次世代デジタルライブラリー [book/1212908](https://lab.ndl.go.jp/dl/book/1212908)。**すべての引用は同館OCRテキスト由来であり、数値・橋名等は原文画像との照合を要する。**
- **議第32号「東京都市計画河川改修及其ノ事業執行年割中変更ノ件（神田上水関係）」〔確認・repo初出・第5回 1931-08-01〕**: 内務大臣安達謙蔵（昭和6年7月27日付）。被告示は**昭和5年8月13日内務省告示第155号「東京都市計画河川改修及其ノ事業執行年割」**であり、その第一項第二号「神田上水ノ延長『約七、四八〇米』」を「**約七、一六六米**」に改める案。説明文言＝「東京府知事ノ執行スル神田上水改修計画中**水流ノ円滑ヲ期セム爲 落合町久保前橋下ヨリ戸塚町中ノ橋下ニ至ル区間ニ於ケル屈曲ヲ緩和シ以テ延長約三一四米ヲ短縮**セムトスルモノナリ」。委員会側の説明では「**谷端川ト共ニ既ニ改修計画ガ樹チマシテ目下東京府知事ニ於キマシテ事業ノ執行中**」の神田上水改修について「**水路ノ位置ヲ三箇所バカリ変更**」すると説明された。〔repo初出: ①告示155号の番号・日付（[GOV-159](GOV-159.md)の1930-07-28審議→08-08決定に続く告示段階）、②神田上水改修の延長7,480→7,166m（約314m短縮）という設計変更、③「久保前橋」「中ノ橋」という神田川（神田上水改修区間）の橋名候補、④屈曲緩和＝水路位置3箇所変更〕〔橋名・数値・文言はOCR要照合〕。
- **議第44号「東京都市計画西巣鴨町下水道及其ノ事業執行年割決定ノ件」（庶発第19号）〔確認・repo初出・第7回 1932-02-08〕**: 内務大臣中橋德五郎（昭和7年1月30日付）。①**経費総額291万円**を**昭和6年度から16年度に至る11箇年継続事業**とし、**執行者＝西巣鴨町長**（西巣鴨町費）とする。②説明＝「全町ニ亘ル下水道布設ノ計画ヲ樹テ之ヲ都市計画事業トシ…**谷端川ノ一部ノ改修ヲ遂行スル**コトニナツテ居リマス」。③排水＝「**谷端川及悪水路ニ排出シ、一部ハ東京市、巣鴨町及高田町下水道ニ合流ス**」。④管渠の構造＝「**総テ暗渠式**トシ排水量ノ多寡ニ応ジテ**陶管、鉄筋コンクリート管竝鉄筋コンクリート馬蹄形及矩形渠**ヲ使用ス」。⑤排水区＝**石神井川・谷端川・音羽・谷田川の4区**に区分し、**谷端川排水区＝大字巣鴨ノ大部竝大字池袋・堀之内ノ各一部・区域面積約138ha・下水道延長約30,770m**、**音羽排水区＝大字巣鴨・池袋・堀之内ノ各一部・約100ha・約19,970m**。⑥委員の質疑で横手千代之助（**上流で集めた下水を下流に流す下流住民の被害**）の質問に対し幹事飯沼一省（後に内務次官）が「**下水管渠ノ工事ハ全部暗渠**…其ノ排出イタシマシタ末ノ方ハ**将来ノ計画ト致シマシテ全部処分場ニ送リマシテ処分ヲシタ上デ排出スル**」（東京郊外ニ於ケル下水計画ノ完成ヲ俟ツ）と答弁。〔[GOV-162](GOV-162.md)（1930年・特別都市計画委員会第12号の計画段階「谷田川・谷端川・白山の3排水区」）に対して**決定段階の数値**を与える記録。経費291万円・11箇年（昭和6年度〜16年度＝1931〜1941年度）はREADME既述のrzeka「[マンホール(170)：東京府北豊島郡西巣鴨町の蓋](https://rzeka.blog88.fc2.com/blog-entry-277.html)」（2012-12-31）の町誌転記（1931〜1941年度の11か年計画・1932年3月内務省認可・同年5月18日着工）と年次枠で一致する。ただし**谷端川排水区の下水道延長は本速記録OCRが2箇所で「約三〇、七七〇米」（30,770m）とするのに対し、同記事の町誌転記は「37,070m」**であり、いずれが正しいかは原文照合まで確定しない。石神井川排水区の面積も本OCR「約二〇〇ヘクタール」前後に対し同記事は「455ha」と食い違う。**面積・延長を確定値として使わないこと**〕〔数値・文言はOCR要照合〕。
- **街路速成事業の「千川筋ノ街路」〔確認・repo初出・第4回 1931-03-30〕**: 幹事武部六蔵の説明で、**大正14年（1925）に決定された東京市長執行の「街路速成事業」**は「**千川筋ノ街路外十二線合計十三線**ニ就キマシテ事業費**千六百十四万五千円**ヲ以テ**大正十四年度ヨリ昭和六年度マデ七箇年ノ継続事業**ト致シマシテ目下執行中」と説明され、そのうえで6路線（郊外補助線第101号・市内第5・8・14号等の一部、二等大路第二類第8号・第14号）を追加して**合計19路線・総事業費1,658万2千余円**とし、**一部は失業救済事業として実施**、執行年限を**東京市財政の都合で昭和6年度から7年度へ1箇年延期**する案が付議された（議案番号は千住町下水道変更＝議第25号の直前だがOCRでは番号未確認）。〔**「千川筋」を冠する街路が1925年決定の街路速成事業の対象路線だった**ことを示す第一次記録。現在の千川通り（[BLOG-077](../blogs/BLOG-077.md)・[GOV-094](GOV-094.md)の千川下流改修1930-34を起源とする道路）とこの「千川筋ノ街路」の同一性・区間は本文では確認できず断定しない〕〔文言はOCR要照合〕。
- **同号のその他の河川関連議案〔確認・参考〕**: 議第33号「東京都市計画江戸川改修決定ノ件」（第5回付託・特別委員会9月25日・10月1日の2回会議で原案適当と報告）も収録。江戸川（江東地区）は本repoの直接対象外だが、告示155号の三河川（立会川・神田上水・谷端川）と並ぶ同時期の河川改修決定の背景資料。

## 制限・未解決

- ①告示155号の本文（計画要綱・年割の全容）は未読で、番号・日付は第3号OCRと[GOV-182](GOV-182.md)（東京都市計画報告第4回）の2系統のOCR由来。②「久保前橋」「中ノ橋」の位置・橋種は未特定（[GOV-159](GOV-159.md)の神田上水起点「寿橋」との位置関係も未整理）。③西巣鴨町下水道の谷端川排水区延長（30,770m vs 37,070m）・石神井川排水区面積（約200ha vs 455ha）は町誌系転記と対立したまま。④「谷端川ノ一部ノ改修」の区間・[GOV-160](GOV-160.md)（1934年谷端川変更要綱）との事業区分の関係は未確認。⑤千川筋街路の路線番号・区間・現行道路への対応は未解決。
