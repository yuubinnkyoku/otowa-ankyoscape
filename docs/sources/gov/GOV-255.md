# [GOV-255] 特別都市計画委員会議事速記録 第7號（1930）— 字北谷端の地番つき計画道路路線

- **書誌〔確認〕**: 復興局編『特別都市計画委員会議事速記録 第7號』（昭和5年＝1930）。NDL次世代デジタルライブラリー [book/1225165](https://lab.ndl.go.jp/dl/book/1225165)。**引用文言はOCR由来で要原文照合。**
- **計画道路路線19・20の地番記録〔確認・字北谷端の1930年地番〕**: 「**十九 板橋町大字下板橋字平尾裏八百八十八番地地先ヨリ大字金井窪字東前百七十番地地先ニ至ルノ路線 二十 板橋町大字瀧野川字北谷端二千三百七十九番地地先ヨリ同二千五百五十九番地ノ三地先ヲ右折シ 大字金井窪字東前百二十六番地地先、同百二十三番地地先ヲ經テ同百十四番地地先ニ至ルノ路線**」＝**①字平尾裏888番地→金井窪字東前170番地の路線19、②字北谷端2379番地→2559番地ノ3（右折）→金井窪字東前126・123・114番地の路線20**という計画道路の起点・経過・終点の地番つき記録。**字北谷端の1930年時点の地番（2379・2559ノ3）と、北谷端（滝野川側）から金井窪字東前（板橋町側）へ谷端川低地を横断する道路計画の位置関係**が特定できる。
- **町名表記の注意〔要照合〕**: 路線20の「**板橋町大字瀧野川**」は、滝野川町（当時は独立町）を板橋町の大字とする表記で、**OCR崩れか原文の区域表記の誤りかは要照合**（特別都市計画上の区域区分の表記の可能性もある）。路線18〜21は西巣鴨町大字池袋・巣鴨町大字巣鴨・板橋町・滝野川町にまたがる市域拡張関係の計画道路群の文脈で現れる。
- **位置づけ〔観察〕**: 谷端川中流域の谷端（北谷端）の1930年時点の地番・道路計画の基礎資料。1911年の板橋町字名一覧（[GAZ-052](../gazetteers/GAZ-052.md)）・1931年の板橋町現状調査（[GOV-253](GOV-253.md)）と併せて、明治末〜昭和初頭の谷端・金井窪地区の行政地名・地番の対照資料として管理する。

## 制限・未解決

- ①「板橋町大字瀧野川」の表記の原形は要照合。②地番の読み（二千三百七十九・二千五百五十九番地ノ三等）はOCRを含み要照合。③当該路線が現在地図上のどの道路として実現したか（未実施か）は本冊のみでは判断できない。
