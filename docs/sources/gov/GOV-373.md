# [GOV-373] 享保撰要類集 十九ノ下（堀川浚之部）— 寛延2年出水後の江戸川・神田川49町川浚普請〔第163回〕

- **書誌〔確認〕**: 『享保撰要類集』十九ノ下（堀川浚之部）。NDL次世代デジタルライブラリー [book/2572820](https://lab.ndl.go.jp/dl/book/2572820)。寛延2年（1749）8月出水後の**江戸川・神田川49町川浚普請**（寛延2年10月〜寛延4年）の行政文書群（出来届・証文・伺・御褒美等）。**[BOOK-129](../books/BOOK-129.md)（東京市史稿の抄出）が既にrepoに引用する同書の原本側**＝抄出漏れ文言の抽出が本ファイルの価値（49町範囲・船河原橋下洗堰吟味等の既知内容はBOOK-129/GOV-239の再録としない）。**引用文言はすべてOCR由来で要原文照合。**
- **船河原橋際の市ヶ谷大下水吐口の枡形石垣〔確認・repo初出〕**: 寛延3年（1750）8月9日・8月28日の出来届に「**市谷大下水仕口枡形有来石垣悉損…新規足石…桝形之廻り江木矢来**」＝**市ヶ谷大下水の吐口（船河原橋際）の枡形（桝形）石垣が悉く損傷し、新規に足石・桝形廻りの木矢来を構築した**という修理記録〔市ヶ谷大下水＝神田川に合流する牛込側の大下水。[BOOK-131](../books/BOOK-131.md)（橋梁篇）の船河原橋・市ヶ谷大下水関連文言と併せ、吐口構造（枡形＋石垣＋矢来）の江戸期の一次記録〕。
- **吐口際の新規高札（芥禁じ）〔確認・repo初出〕**: 寛延3年12月13日付けで**船河原橋際の市ヶ谷大下水吐口際に新規の高札**が立てられた（芥捨て禁止の趣旨・文言は要照合）＝**下水吐口への塵芥投棄規制の施設側の対応**〔大下水吐口の水質・芥問題の行政記録。寛延期に既に下水吐口の芥規制が高札レベルで運用されていたことの候補〕。
- **芥捨請負16人の流域町名リスト＝市ヶ谷大下水の集水域〔確認・repo初出〕**: 寛延3年9月7日/17日の証文に、**牛込揚場町・蜊河岸の船持16人が市ヶ谷大下水吐口への芥捨ての請負**（ゴミ対策の請負契約）とともに**流域の町名リスト**——牛込揚場町・神楽坂下・船河原町・市谷田町八丁目・長円寺谷牛小屋・四ツ谷御堀端・竹町・七軒町・糀町・塩町・尾州様御門前・本村町・津久戸前町・白銀町・肴町・横町・袋町・御箪笥町・元天龍寺前・御納戸町・御細工町・払方町・改代町・小日向水道町・音羽町筋——が列挙される＝**市ヶ谷大下水の集水域（牛込〜四ツ谷〜小日向方面）の一次記録**〔大下水の受益・負担範の特定資料。「長円寺谷牛小屋」等の施設名も含む〕。
- **潮上限観測「汐差引至極末ハ船河原橋辺」〔確認・repo初出・水理観測〕**: 寛延3年7月8日の文言に「**船河原橋辺江汐差引至極末**」＝**汐差引き（潮汐の遡上）の極限が船河原橋の辺**という観測文言〔**江戸川（神田川）の潮区間の上限が船河原橋**であることの幕府側の一次観測。江戸川水位と神田川汐位の差1尺6寸という文言と対で記される（要照合）。[GAZ-049](../gazetteers/GAZ-049.md)②の船河原橋（俗にどんと）＝御堀に落つ直前の位置観察・[GOV-381](GOV-381.md)（検使之部）の「神田川之方汐入之場所」と対校できる、神田川の潮汐上限の年代つきdatapoint〕。
- **水戸殿御屋敷前大下水吐口と水除石垣なまこ土手〔確認・repo初出〕**: 寛延3年11月晦日の文言に、**水戸殿御屋敷前の大下水吐口の水除石垣・なまこ土手**が川浚普請でも**残置**（撤去されず維持）された記録〔水戸屋敷沿いの江戸川の下水吐口と水除構造（なまこ壁状の土手）の一次記録。[GOV-372](GOV-372.md)系の水戸屋敷関連文言と対校〕。
- **その他の抄出漏れ文言群〔確認・文言候補〕**: ①関口水道町の川添屋敷（善兵衛・六左衛門）の地われ（寛延3年7月5日）、②小日向水道町仲町の地割孕出4ヶ所、③**神田川水道橋〜昌平橋の地山岩（岩盤）**と**駿河台方下水落口の上山岸崩入の石垣二段修復**＝神田川河床の岩盤（地山岩）の存在と駿河台側の下水落口・法面崩壊の修復記録、④牛込御門際〜小石川御門際〜水道橋際の堀端土手の高さ2尺規制、⑤**牛込御門際〜水道橋の矢来柵1,338間余（内石垣296間を除く1,042間余に新規柵・高3尺・1間5本杭9尺）と柳原土手の商床見世230間余の助成地化**（六番町火消屋敷廻りの道造160間・柳原土手の半分の道造・枯柳の植替つき・寛延3年11月〜寛延4年2月）、⑥越中嶋の捨土計画中止、⑦寛延3年11月16日の完成届「**江戸川通目白下大洗堰ゟ舟河原橋迄・神田川通牛込御門際ゟ大川口柳橋迄川渡不残出来**」、⑧御褒美の申渡。〔③は[GOV-375](GOV-375.md)の駿河台法面崩壊シリーズ（明和9・安永2・天明6）の江戸期先例としても位置づく。⑤の柳原土手の商床見世は[BOOK-129](../books/BOOK-129.md)系の江戸川堤の土地利用記録と対校〕。
- **位置づけ〔観察〕**: 寛延2年8月出水（[BOOK-130](../books/BOOK-130.md)・[GOV-375](GOV-375.md)参照）の復旧行政の全容を、①水理観測（汐差引・水位）、②護岸構造（枡形石垣・なまこ土手・岩盤河床）、③流域の自治（芥請負・集水域町名）、④空間規制（高札・土手高規制・矢来柵・商床の助成地化）の4層で記録した文書群。[BOOK-129](../books/BOOK-129.md)の抄出に依存せず原本側の文言を初めて確認した意義をもつ。
