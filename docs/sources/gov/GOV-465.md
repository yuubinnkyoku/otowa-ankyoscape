# [GOV-465] 天保撰要類集[352] — 千川宇兵衛の橋・人足負担の実名リストとその廃止

- **書誌〔確認〕**: 『天保撰要類集』[352]第百二十八 上（NDL次世代デジタルライブラリー [book/2589180](https://lab.ndl.go.jp/dl/book/2589180)・写本OCR）。**引用文言はすべてOCR由来で要原文照合**。
- **千川宇兵衛の負担の実名文言〔文言候補・本登録の核心〕**: 「**小網町壱町目宇兵衛儀 先代之節千川上水懸ケ渡候砌 自分金をも差加候訳を以地所拝領致し 右為冥加 上水吹所留人足并古之橋々 新規掛替修復共請負相勤申候**」＋「**上水吹所留人足賃弐両弐分余宛上納致し**」＝**①小網町壱町目の宇兵衛（千川宇兵衛）の先代が千川上水懸渡の砌に自分金を差加えた訳えで地所を拝領し、②その冥加として上水の吹所留（水番）の人足と根津側の古橋の新規掛替修復を請負い、③上水吹所留の人足賃2両2分余を上納してきた実名文言**。〔**[GOV-210](GOV-210.md)（嘉永3年請負替）・[GAZ-034](../gazetteers/GAZ-034.md)（千川金七由緒書の橋負担変遷）に先行する、宇兵衛代の橋・人足負担の具体的内容（賃金額つき）**〕。
- **根津4橋のリスト〔文言候補・橋名調査の新 datapoint〕**: 「**一根津宮永町ゟ同所惣門え渡る橋 一宮永町西裏通ゟ根津門前町渡ル橋 一根津門前町ゟ谷中通り渡る橋 一谷中通ゟ善光寺前町え渡ル橋 右四ヶ所懸替修復入用（後略）**」＝**①根津宮永町↔惣門、②宮永町西裏通↔根津門前町、③根津門前町↔谷中通り、④谷中通↔善光寺前町の4橋**。〔**[GOV-211](GOV-211.md)（嘉永3年根津側4橋）と対校する天保期の4橋リスト（表記のOCR混在は要照合）。GAZ-113（御府内備考・写本）の根津宮永町・社地門前・玉林寺門前の橋群と橋名・両岸・構造の面で重なる地名群に千川家負担の位置が確認できる**〕。
- **負担廃止の文言〔文言候補・時系列の中継点〕**: 「**千川宇兵衛町屋敷家作 此儀宇兵衛儀是迄相勤候 根津宮永町外三ヶ所橋普請并上水吹所留人足賃上納共御免ニ相成 橋之儀は御入用橋同様 町方御勘定方持ニ相改り 御入用ニ而御修復出来 上水留人足賃之儀は御蔵渡相成 拝領地之儀は受負地ニ申付 地代金御金蔵え相納（後略）**」＝**①根津宮永町外3ヶ所の橋普請と上水吹所留人足賃の上納が御免（廃止）となり、②橋は御入用橋同様の町方御勘定方持ちに改まり御入用にて修復、③上水留人足賃は御蔵渡となり、④拝領地は受負地に申付けられ地代金が御金蔵へ相納**。〔**天明再興〜廃止後も続いていた千川家の上水吹所留人足負担が幕末（天保期）の改革で廃止され、橋が町方御勘定方持ち（御入用橋と同様）に移行した時点の文言＝[GOV-210](GOV-210.md)（嘉永3年請負替）に先行する中継点**。年次の同定は本文中の「卯七月 阿部遠江守殿 御勘定吟味役衆 鳥居甲斐守」の併記から暦比定を要する「天保14癸卯（1843）候補」で要照合**〕。
- **増水口の練馬村への分水料文言〔文言候補・repo初出〕**: 「**千川上水増水口 武州練馬村江方水料之儀は 是迄之通御役所え為相納候様被仰渡候間**」＝**千川上水の増水口から武州練馬村への方水料（分水料）は従来通り御役所が為に相納するよう仰渡された旨**。〔**増水口の分水料の徴収主体（御役所＝勘定奉行所系）と納入先が上水廃止後の帳簿でも「是迄之通」維持された文言＝千川用水の増水口（増水口溝・角川上水元の分水施設）の水料の行先がrepoで初めて明文化**。方水料/分水料の判読対立は要照合〕。
- **小石川下富坂町四郎兵衛〔文言候補・同伴の当人〕**: 「**一同所下富坂町四郎兵衛家作 此儀四郎兵衛儀…**」＝宇兵衛と同型の家作・拝領地の語形で四郎兵衛の条も並ぶ（OCR崩れ大・全容は原文照合課題）。

- ①「卯七月」の年の同定（天保14癸卯〔1843〕候補）は暦比定と人名（阿部遠江守・鳥居甲斐守の在職）の突き合わせによるもので断定しない。②「御蔵渡」「受負地」の処遇の正確な法的意味（賦課の減免か形態変更か）は本資料では不完全。③根津4橋の橋名・両岸表記のOCR混在は [GOV-211](GOV-211.md)・[GAZ-113](../gazetteers/GAZ-113.md) との原字対校が前提。
