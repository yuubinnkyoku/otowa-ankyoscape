# [GOV-053] 文京区公式「教育の森公園」ページの池・水源・占春園との関係

- **書誌・所在〔確認〕**：文京区公式サイトの「まちづくり・環境 > みどり・公園 > 公園等の案内 > 区立公園一覧 > 教育の森公園」。所在地は**文京区大塚3-29**。2026年11月8日に本文を文字抽出で確認。
- **開園・前身〔確認：公式ページの叙述〕**：**旧東京教育大学（現在の筑波大学）の跡地**に**昭和61年（1986）**に開園。「水と緑の防災公園」として、中央部の自由広場・文京スポーツセンターが避難・救援活動に使われる。
- **池・水資源設備〔確認：公式ページの叙述〕**：**消防用に池や地下貯水槽などの水資源設備を充実**させているとする。自由広場のまわりに夏季の**じゃぶじゃぶ池**・**二つの半月池**・林間広場・石張りの正門広場などがある。**これらの池は防災・消防用の人工水景施設として説明される**。
- **占春園との関係〔確認：公式ページの叙述〕**：隣接して**「元の守山藩の上屋敷跡であった、斜面地を利用した自然豊かな占春園」**があると明記。筑波大学附属小学校の自然観察の場で、**文京区が維持管理を行い一般に開放**する。
- **資料の限界〔未解決〕**：教育の森公園の池（半月池・じゃぶじゃぶ池）が消防用水資源設備であることは確認できるが、**占春園の池（落英池）の水源は別であり、このページでは分からない**。設置・開園年月日は [GOV-020](GOV-020.md) の区立公園一覧（教育の森公園は1986年10月13日）とも照合できる。
