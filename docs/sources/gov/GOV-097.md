# [GOV-097] 文京区「バリアフリー整備」（巻石通り＝区道第889号）

- **資料〔確認: 文京区公式ページ本文をcurl+UAで直接取得〕**: 文京区「道路に関する事業 > バリアフリー整備」（ページID 4617、**更新日2025年4月1日**）。出典: [文京区ページ](https://www.city.bunkyo.lg.jp/b035/p004792.html)。旧神田上水（巻石白堀）上の道路である**巻石通り＝区道第889号**の整備計画・工事日程を区が公式に示す資料。〔[GOV-010](GOV-010.md)（巻石白堀の工業用水利用）・[BLOG-001](../blogs/BLOG-001.md)（水窪川出口＝旧神田上水注ぎ込み）の対象区間の**現行の都市計画上の位置づけ**としてrepo初出の行政情報〕
- **整備日程〔確認〕**: ①**平成28年度に「巻石通りバリアフリー計画」を作成**（概要版PDF 1,195KBを区ページで公開。PDFはCID符号化フォントでテキスト層が機械抽出不能、本文は未確認）。②**平成29年度より無電柱化整備に先行着手**。③**令和8年度より音羽通りから江戸川橋体育館までバリアフリー整備を実施予定**〔2026年の着工を区公式に裏付ける記述。菅谷幸子区議の2026年X投稿（着工開始・「暗渠由来の高低差や傾斜」との文言）と整合するが、X投稿自体は本ファイルでは出典としない〕。
- **区間の意味〔観察〕**: 「音羽通り〜江戸川橋体育館まで」の区間は、**旧神田上水の巻石白堀（現・巻石通り）の水道〜音羽〜江戸川橋周辺の下流部**にあたり、[GOV-010](GOV-010.md)（1935年頃まで砲兵工廠への工業用水）・[BLOG-021](../blogs/BLOG-021.md)（水道町→大日坂の橋＝現・巻石通り大日坂下交差点付近との解釈）と同一の水路上の道路整備である。暗渠由来の高低差がバリアフリー整備の対象になるという**現在も旧水路由来の地形が残存していることの行政側の間接的認識**と解せる〔推定〕。
