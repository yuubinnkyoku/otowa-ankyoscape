# [GOV-345] 市中取締類集[51][52] — 雑司谷町名主平次左衛門の名主詰と支配構造〔第151回〕

- **書誌〔確認〕**: 『市中取締類集 [51]』・『[52]』（NDL次世代デジタルライブラリー [book/2572077](https://lab.ndl.go.jp/dl/book/2572077)・[book/2572078](https://lab.ndl.go.jp/dl/book/2572078)）。名主組合の世話掛り・名主詰の人事と身元調査の記録（天保〜嘉永期の記録を含む）。**引用文言はすべてOCR由来で要原文照合**。
- **雑司谷町名主平次左衛門の身元調査〔確認・文言候補・repo初出の支配構造文言〕**: 名主組合20番組の名主詰（兼帯）の身元調査の記録——「**弐拾番組十弐人之内 雑司谷町名主（伊賀？見習？）平次左衛門四十歳位 柏木成子町（紋右衛門）… 右平次左衛門儀 先年は遊女通ひ等致 又其囲妾有之候処…十四年以前寅年十月 肝煎見間（見習の崩れ候補）被仰付候ゟ 身持相改 実体ニ相成 家事取締等致し候由…**」＋「**支配は雑司谷町之外二 門前地弐ヶ所 村方も御座候処 何れも気受能相聞申候 町方ハ誠之場末二而御用少二付不事馴候間 弁方之程ハ不相知 組合突合抔も稀之儀二付 善悪之沙汰無之**」＝**①雑司谷町名主平次左衛門（40歳位・嘉永期）が先年遊女通ひなどの身持ちの問題があったが14年前の寅年10月に肝煎（名主見習）を仰付けられて以後身持ちを改めた実体となっている旨の身元調査、②その支配が雑司谷町のほかに門前地2ヶ所と村方に及ぶこと、③町方が「誠之場末」（まことの場末）で御用が少ないこと、の文言候補**。〔**①[GAZ-075](../gazetteers/GAZ-075.md)（高田雑司ヶ谷町方書上写・文政9年丙戌書上の名主平次左衛門）・[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考巻52・雑司ケ谷町条の名主幌→戸張平次左衛門の先祖譚）と同一人物（またはその後継）の天保〜嘉永期の町奉行側の記録として、文政書上の名主層が幕末まで実在したことの追認**（同一性は年齢・文脈から候補とし断定しない）。②**雑司ヶ谷町の支配が「門前地2ヶ所＋村方」を含む構造であることの行政文書側の文言候補**＝鬼子母神門前・本浄寺門前（等）の門前地と雑司ヶ谷村の村方への名主支配の広がりの記録（門前地2ヶ所の個別比定は原画像照合が前提）。③「場末二而御用少」＝[GOV-343](GOV-343.md)の延享3年の限定的町方化（商業兼業層のみ）と整合する雑司ヶ谷町の性格づけの文言候補。〕
- **20番組の世話掛り名簿〔確認・文言候補〕**: 『[52]』の名主組合世話掛りの申合書に「**弐拾番組 雑司谷町名主平次左衛門 同相（柏）木成子町紋右衛門**」の連署（30人の名主のリスト中）＋「**右之者共 去卯年十二月より当辰十一月迄 組合世話掛り被仰付…来巳十二月迄勤越被仰付被下置候様仕度奉存候**」＝**雑司谷町名主平次左衛門が20番組（柏木成子町との2町の組）の組合世話掛り名主詰を勤めていた記録**（卯・辰・巳年の干支の比定〔天保14卯年〜弘化3丙午年か・嘉永6卯年〜嘉永7寅年か〕は原画像照合が前提）。〔雑司ヶ谷町が江戸の名主組合（20番組）に組み込まれ、世話掛りを輩出していたことの人事記録＝[GAZ-075]の町方書上（組合名主の文言）と対校できる実務側の記録候補。〕
