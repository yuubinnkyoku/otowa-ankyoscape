# [GOV-283] 玉川上水留・狭山池助水堀通見廻役起立代替申渡一件 — 狭山池助水堀と野方堀通見廻役の制度の一次記録

- **書誌〔確認〕**: 『玉川上水留』の1冊（NDL次世代デジタルライブラリー [book/2587334](https://lab.ndl.go.jp/dl/book/2587334)）。表紙書名「**箱根ケ崎村狭山池助水堀通見廻役起立代替申渡一件**」・「**文化五辰年四月ヨリ慶応元丑年八月迄**」（1808〜1865）・棚札「十七ノ百五十二弟五棚」。御普請方御役所差上申の御請書・達書・代官掛合書面の綴。**引用文言はすべてOCR由来で要原文照合。**
- **「狭山池」の原字形の有力候補〔確認・repo初出の頻度論拠〕**: 本冊のfulltextで池名は38回「狭山池」・4回「狹山池」で最頻（「狹山地」4回・「横山池」2回・「牧山池」2回・「穂山池」2回は同位置のOCR崩れ候補）＝**「箱根ヶ崎村狭山池幷玉川上水江之助水堀通」の書名・文言が一貫して現れる**。同一シリーズの書上帳（[GOV-285](GOV-285.md)）でも「箱根崎村狹山池ゟ玉川上水江之助水堀通」が安政期まで反復される。→ [GOV-268](GOV-268.md)の砂川村地内「助水落口」の「狭山池(?)」の読みの蓋然性を上げる傍証（**ただし池名の実体（狭山丘陵の狭山池か）・砂川村地内の落口との位置関係は本冊群のみでは確定しない・照合要**）。
- **狭山池助水堀通見廻役の制度〔確認・repo初出〕**: 狭山池から玉川上水（羽村）への**助水堀通**と**池内**の見廻り役の御請書・代替申渡の全記録——
  - 文化5辰年（1808）に見廻役が起立（本冊はその起立からの代替の記録）。手当は「**金壱両**」が「**年々七月被下置候**」（嘉永2年の八十八の御請書）＝年次手当の金額と支給月。
  - 見廻りの職務文言:「**持場見廻り無懈怠相勤 池内堀通共藤(樋?)流掛有之候はゝ持場村々え相達 為取揚水行**」（嘉永2年御請書）＝**池内と堀通の漏流の監視・持場村々への通報**。
  - 人事の系譜〔確認・OCR文言〕: ①箱根ヶ崎村名主**次郎右衛門**（文政元年時点で在役、同年「入牢」により文政6年差免）→ ②**羽村**名主**半平**（「**箱根ヶ崎村内ニ見廻り役可相勤もの無之 最寄羽村に相応之もの有之**」の申立により交代・嘉永2年病死）→ ③半平の子**安次郎**→④その子**八十八**（嘉永2年10月、11歳で見廻役相続・同村名主与市・水番人茂十郎・米蔵の附添。**「乍子年ゟ凶気ニ罹リ 当春狭山池浚」**＝子年（元治元年=1864）から凶気に罹り丑年（慶応元年）の春に**狭山池の浚渫**があり以後見廻に出られず差免）→ ⑤**為一郎**（池浚を引請・慶応元年8月23日病気で差免）＝**文化5年から慶応元年まで約57年分の見廻役の人事史**。「凶気」の実体（元治〜慶応のコレラ流行の候補）は断定しない。
  - 行政系統〔確認〕: 「御勘定奉行衆御普請奉行」宛・「御普請方御役所」差出の体裁で、支配御代官は**中村八太夫**→嘉永期以降は**江川太郎左衛門**（韮山代官）と記録される＝助水堀見廻役が代官支配を通じて幕府御普請方に直結する制度だったことの一次記録。
- **「玉川口上水野方堀通見廻役」の御請書〔確認・repo初出＝野方堀の常設見廻制度の一次記録〕**: 文政元寅年（1818）11月・**武州多摩郡砂川村名主源五右衛門**の御請書（見出し「**玉川口上水野方堀通見廻役**」）——
  - 「**玉川御上木(水?)野方堀通り見廻役被仰付壱ヶ年限 又板宛年々被下置候旨被仰渡**」＝**壱ヶ年期限・年次更新・年々手当**の常設の見廻役。諸書付絵図面は「不残跡役同村源五左衛門江直々引渡」＝引継ぎ制度。
  - 職務文言:「**常々入念無懈怠見廻 変(?)秋分水引取候節は弥正に用ひ繁々相廻 御上水御差支無御座候様相達**」（**秋分水引取の時期に重点的な見廻り**）、「**御上水堀江相渡有之候橋々掛直し修復**」（**堀に掛かる橋の修復責任**）、「**持場野方御上水元廻候節堀内え水死人…届出は代田村水番人方江村庄屋を以差出**」（**堀内の水死人の届出先＝代田村の水番人**）。
  - 同月の別の御請書で「**玉川御上水野方堀通見廻り仮之儀 是迄砂川村助左衛門相勤来候所 此度助左衛門病気付見廻役御免被遊 跡役同村加主(?)源六左衛門江被仰渡**」＝**文政元年まで砂川村助左衛門が野方堀通見廻役を兼勤**し、病気で交代したこと。巻末の達書の書抜（嘉永〜慶応）に「**玉川上水野方堀通見廻役 砂川村助左衛門持場ニ為心得見廻兼勤申渡 御組合入用ヲ以年々金壱両ツゝ御手当被下置為相勤候處 文政元寅年中病気ニ付差免 跡役箱根ヶ崎村名主次郎右衛門江申渡**」＝**野方堀通見廻役の手当も年々金壱両（御組合入用から）**で、**狭山池助水堀通見廻役と野方堀通見廻役が同一の人事（箱根ヶ崎村次郎右衛門）で運行された**ことを示す文言。

## 制限・未解決

- ①すべてOCR由来で、村名（「石川村」「武州多府中郡」等の助左衛門の村名割付）・人名（源五左衛門/従五郎・加主/名主・四郎兵衛等）・「藤流」（樋流の候補）・「凶気」の語の原字形は照合必須。②砂川村の助左衛門・源五右衛門・源六左衛門と千川家（千川善蔵・千川平吉）・[GOV-262](GOV-262.md)の「砂川村源右衛門」の異同は未確定。③「狭山池」の実体（狭山丘陵の溜池か）と羽村への助水経路の比定は本冊では行わない（文言は「箱根ヶ崎村狭山池幷玉川上水え之助水堀通」のみ）。④文化5年の起立時の文言（高札等）の初出部分は本冊の前半の精読で確認済みだが、高札文言そのものは本冊に含まれない。
