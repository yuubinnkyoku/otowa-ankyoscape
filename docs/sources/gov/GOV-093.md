# [GOV-093] 板橋区公式「加賀藩江戸下屋敷平尾邸の拝領と前田綱紀」

- **書誌〔確認: 本文全文〕**: 板橋区公式サイト「時代を紡ぐ」頁（ページ番号1004884・更新日2020年1月25日・**平成26年8月23日発行「広報いたばし」掲載・教育委員会事務局生涯学習課学芸員吉田政博執筆**）。区の学芸員による公式解説として[BLOG-144](../blogs/BLOG-144.md)（板橋区教委H29「千川上水跡」案内板の平尾邸大池水源説）の背景にある屋敷側の公的記述のうち、**当該頁自体はrepo初出**。
- **〔確認〕 拡領の規模**: 延宝7年（1679年）に五代藩主前田綱紀が板橋宿平尾の地に**6万坪を拝領**、その後拡張し最終的に**約21万8千坪**（「江戸と周辺に所在する全ての大名屋敷の中でも最大の面積」）。敷地範囲は**現在の加賀一・二丁目と板橋四丁目の全域、板橋一・三丁目の一部**〔豊島区・板橋区境に近い千川上水下流域部での屋敷規模の公式数値〕。
- **〔確認〕 御下屋敷惣絵図の庭園内の大池**: 頁頭に「**【御下屋敷惣絵図】庭園内の大池**」の図版を掲げ、金沢城の兼六園と同じく**池泉回遊式大名庭園**として設計・整備されたと解説〔**「御下屋敷惣絵図」という絵図名と庭園内の大池の存在が区公式頁で確認できた点＝repo初出**。大池の水源（千川上水・石神井川・湧水のいずれか）には触れず]。
- **〔確認〕 屋敷の機能**: 狩猟・散策・保養、**タンチョウヅルや唐鳥の飼育・希少植物の栽培**（藩の博物学・植物学・洋学の実証の場）、参勤交代時の旅装からの着替え・江戸屋敷の家族との対面、**幕末期には軍隊の調練や大砲製造**〔幕末の大砲製造は[BLOG-127](../blogs/BLOG-127.md)（慶応元年の大砲製造所・平尾水車）の背景事実として区公式に確認〕。
- **意義〔観察の集積〕**: ①[BLOG-146](../blogs/BLOG-146.md)（天明7年・千川家から加賀藩への分水見積書）と合わせ、**平尾邸と千川上水の関係**が屋敷側（区公式）・上水側（区史経由）の双方から裏付けられた。②大池の位置する池泉回遊式庭園の設計思想は、[GOV-068](GOV-068.md)（分水は湧水池・自然河川源頭に接続する設計）の文脈で大池水源説（[BLOG-144](../blogs/BLOG-144.md)）の背景資料になる。③幕末大砲製造・明治期の板橋火薬製造所（[BLOG-113](../blogs/BLOG-113.md)明治6年）への連続性の公式記述。
- **制限・未解決**: 「御下屋敷惣絵図」の所蔵先（板橋区・金沢市立玉川図書館等）・ полного画像は未確認。屋敷坪数について「約21万8千坪」（区・三井住友トラスト頁等）と「約2万8千坪」（金沢ぶらり散歩日記2016）の表記差があり、**断定せず差を記録するのみ**。大池の現況（加賀公園の築山以外に池跡があるか）は現地確認課題。
