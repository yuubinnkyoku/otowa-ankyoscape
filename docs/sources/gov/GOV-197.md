# [GOV-197] 東京市下水道事業概要（1927年）— 千川の下水道計画の中間年度文言

- **書誌〔確認〕**: 東京市『下水道事業概要』（昭和2年・1927）。NDL次世代デジタルライブラリー [book/1191302](https://lab.ndl.go.jp/dl/book/1191302)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **計画変更要領〔確認・repo初出〕**: 「**千川上流ノ放水路ハ板橋停車場附近ヨリ山手鐵道線路ニ沿ヒ石神井川ニ通セシメ、下流氷川下町初音町間ノ改修暗渠ハ都市計畫路線ニ沿ヒテ敷設ス**」＝**1927年時点の千川系の下水道計画文言**。上流（谷端川系）の放水路を板橋停車場付近から山手鉄道線路（東北本線）沿いに石神井川へ通し、下流の氷川下町〜初音町間の改修暗渠（＝[GOV-094](GOV-094.md)氷川下暗渠化）は都市計画路線に沿って敷設、とする。〔文言はOCR要照合〕。
- **上流流域下水の収容〔確認〕**: 「**藍染川、千川、音羽、江戶川、早稻田、古川等本市ノ上流ニ位スル各流域一部ノ下水ハ之ヲ收容スルモ支障ナキ計畫トス**」＝**藍染川・千川流域の下水を市内下水道で収容する計画**の文言。〔文言はOCR要照合〕。
- **沿革記述〔確認〕**: 「舊江戶ニ於テハ…小石川水道ヲ有シ次デ玉川上水ヲ通ジ、**更ニ千川上水ヲ營ミ**…」＝**千川上水を江戸の上水系譜（小石川水道→玉川上水）に連ねて記す**1927年市概要の文言。〔文言はOCR要照合〕。
- **位置づけ〔観察〕**: [GOV-163](GOV-163.md)（1924・谷端川から石神井川へ達する放水路新設の既定計画文言）と[GOV-159](GOV-159.md)（1930・「既ニ完成セル所謂板橋放水路」）の**中間年度の市側文言**として、板橋放水路の計画→完成の途上と氷川下暗渠化（昭和5年着工）の前提を押さえる。

## 制限・未解決

- ①1927年時点で板橋放水路が計画段階か着工済みかは本文の文言のみでは区別できない（「通セシメ」のテンスは要照合）。②千川流域の下水収容の具体区画は本文になし。③氷川下〜初音町間改修暗渠の延長・構造は未確認。
