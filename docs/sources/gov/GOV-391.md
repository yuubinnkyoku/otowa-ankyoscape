# [GOV-391] 類集撰要 巻之三十二「神事」— 千川屋敷の祭礼編入と小石川・高田の祭礼休止〔第165回〕

- **書誌〔確認〕**: 『類集撰要』巻之三十二「神事」冊。NDL次世代デジタルライブラリー [book/2571679](https://lab.ndl.go.jp/dl/book/2571679)。寛政6辰年9月調・**寛政9巳年祭礼町々御調之節書上之写（原本中野氏蔵）**の祭礼一覧（番組別の祭礼町の列挙＋祭礼の日取り・日数・休止の注記）を中心に収録。**引用文言はすべてOCR由来で要原文照合。**
- **小石川祭礼町列挙の「白山前町千川屋敷」〔確認・文言候補〕**: 小石川の祭礼番組の町列挙に「**小石川戸崎町本郷壱丁目…同下冨坂町西側同伝通院前表町…同白山前町千川屋敷**」等が連なる＝**千川屋敷が白山前町の内の祭礼（町方の祭礼組織）の単位として御調に列挙されている**〔**千川屋敷（[GAZ-036](../gazetteers/GAZ-036.md)・[GOV-208](GOV-208.md)等で位置特定済みの小石川の屋敷）が寛政期の祭礼の御調では町方の付帯単位として数えられていた**ことの一次記録候補。千川屋敷自体は既出なので、祭礼編入の文言としての新規性は限定的〕。
- **小石川「一水川明神」〔OCR候補〕の祭礼の相休〔確認・文言候補〕**: 「**同白山前町小石川一水川明神但祭礼九月十日隔年明和六丑年祭礼差出其後相休罷在**」＝**小石川の「一水川明神」（OCR崩れ・「水」を含む社名の候補。水神明神等の崩れの可能性。要原画像照合）の祭礼は9月10日隔年で、明和6丑年（1769）の祭礼差出の後、相休（以後休止）していた**ことの書上〔**明和6年＝神田上水の上水行政の明和6丑年再編（[GOV-234](GOV-234.md)・[GOV-384](GOV-384.md)の明和6年11月文言）と同一年の祭礼休止**が小石川で起きていた記録候補（両者の関連は本文言だけでは立証できず対校案件として登録）。社名の比定が前提で、祭礼と水系の関係は断定しない〕。
- **雑司ヶ谷鬼子母神の祭礼の体裁〔確認〕**: 「**雑司ヶ谷一鬼子母神毎年正月十六日祭礼但日数二日之内近辺町々幟挑灯等差出申候**」＝**鬼子母神の祭礼が毎年正月16日で、日数は2日之内、近辺町々が幟・挑灯を差し出す**体制の御調書上〔[GAZ-075](../gazetteers/GAZ-075.md)（雑司ヶ谷六町の地誌御調）と並ぶ雑司ヶ谷側の町方行政記録。正月16日の日取りの一次記録候補〕。
- **高田一定八幡の相休〔確認・文言候補〕**: 「**高田一定八幡酉年八月十五日祭礼但明和四亥年八月十五日祭礼被差出其已来相休申候**」＝高田の「一定八幡」〔OCR崩れ候補・社名要照合〕の祭礼は明和4亥年（1767）の差出以降相休〔小石川の明和6年相休と並ぶ18世紀後半の祭礼休止の事例。高田・雑司ヶ谷側（水窪川・弦巻川・神田上水上流域の町村）の祭礼の実態の対照資料。休止理由は本文言では不明〕。
- **四谷淀橋町の鎧明神・牛込築土明神・成子天神等の祭礼の体裁〔確認・参考〕**: 「四谷淀橋町一鎧明神毎年九月十五日祭礼但日数三日之間町内限幟挑灯差出申候」「牛込一築土明神毎年九月十五日祭礼…」等＝四谷淀橋町・牛込・小石川の祭礼の一定の体裁のリスト〔[GAZ-089](../gazetteers/GAZ-089.md)（四谷周辺の町方書上）と並ぶ寛政期の祭礼地図。水系との直接の関連は断定しない〕。
