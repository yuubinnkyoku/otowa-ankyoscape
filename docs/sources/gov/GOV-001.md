# [GOV-001] 豊島区「水窪川をたどって」関連プレス資料

- 豊島区広報課、1999年10月9日付プレス資料。
- https://adeac.jp/viewitem/toshima-history/viewer/viewer/pressH111009/data/pressH111009.pdf
- 「水久保」の地名由来、「水久保川」「日の出川」、近世地誌『御府内備考』の「鼠ヶ谷下水」、川幅一間ほど、昭和初期から戦後にかけて下水化されたことなどを記す。
- **1999年10月9日の踏査記録（原文1頁再照合）**：当日13時30分開始、参加者25名、約3時間。美久仁小路→旧巣鴨監獄脇→文京区大塚→音羽→江戸川橋。**造幣局脇の細道で排水溝跡と大谷石の塀並み**が見られたと記す。〔**確認：区広報の観察記述**〕 **大谷石を護岸とするのは広報中の推量**であり、施工年・正確な位置・現存状況は未確認。〔**未解決**〕
- **過去の講座の存在（原文1頁再照合）**：同テーマで**1989年度に弦巻川・谷端川を取り上げた**と明記。1989年度の踏査日・資料・参加者・両河川の施工年は未確認。〔**確認：1999年広報による回顧／未解決：1989年度の一次資料**〕
