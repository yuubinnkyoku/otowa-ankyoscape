# [GOV-148] 東京都財務局「調節池の広域的な整備に向けた検討委託（その２）」公告〔repo初出〕

- **書誌〔確認: 建設通信新聞の公告報道記事・2026-11-15取得〕**: 「[11月13日まで2件受付/調節池広域整備検討など/東京都財務局](https://www.kensetsunews.com/archives/1307376)」（建設通信新聞・**2026年11月11日掲載・4面**）。東京都財務局が**2026年11月10日**に「調節池の広域的な整備に向けた検討委託（その２）」と「境川中流部における調節池基礎調査委託」の希望制指名競争入札2件を公告したと報じる〔公告の一次テキスト（都財務局の入札公告ページ）は今回未特定・記事経由の二次〕。
- **対象流域と数値〔確認: 記事本文の記載〕**: 広域整備検討その２の対象流域は**神田川流域（河川延長約52.3km・流域面積約105km²）**・**石神井川流域（河川延長約25.2km・流域面積約73.1km²）**・**野川流域（河川延長約42.9km・流域面積約69.6km²）**の3流域〔**神田川流域の「河川延長約52.3km」は本川延長（一般に約24.6kmとされる）とは明らかに異なる数値で、流域内の管理河川の総延長等と推測されるが、公告原文での定義は未確認のため断定しない。流域面積約105km²は神田川水系の慣用値と整合する。石神井川・野川の流域数値もrepo初出〕〕。
- **業務内容と時期〔確認: 記事本文〕**: **2023年12月策定「気候変動を踏まえた河川施設のあり方」を踏まえ**、調節池の広域的な整備に向けた施設配置や治水効果等を検討する。業務内容は気候変動の影響等を考慮した降雨・流出解析、施設緒元やルート・施設の基本構造の概略、治水効果、事業効果、概略運用の検討等。**履行期間は2027年12月10日まで**。希望申請は11月13日まで、**開札は12月2日**。参加資格は土木・水系関係調査業務A等級＋「河川・水理調査」登録＋調節池（ダム・調整池除く）の洪水調節に関する治水検討業務の完了実績等。**前回の「調節池の広域的な整備に向けた検討委託」はパシフィックコンサルタンツが担当**。
- **意義〔観察〕**: 神田川（弦巻川・水窪川・谷端川の受け皿河川）流域の調節池広域整備検討が**2026年11月時点でその２期として発注継続中**であることの報道記録。令和5年3月現行の[GOV-124](GOV-124.md)（神田川流域河川整備計画）以降の計画状況（決定版は2026-11-15時点で未公表）と、[GOV-149](GOV-149.md)「気候変動を踏まえた河川施設のあり方」を結ぶ施策動向の時系列の一部となる。治水施設（調節池・地下河川）の新規計画は谷端川・弦巻川・水窪川の暗渠・下水道幹線（雑司ヶ谷幹線・神田川幹線等）の将来像にも関わりうるが、**対象施設の位置・規模は本文に具体がなく、四河川への直接の影響は現時点で特定できない**〔推定に留める〕。
