# [GOV-071] 千川上水記録フィルムの個別コマ（板橋区大谷口付近・推定）

- **資料〔確認〕**: 練馬区立石神井公園ふるさと文化館・分室「所蔵品アーカイブ」の個別ページ（[detail.cgi?id=10057](https://www.neribun.or.jp/archive/detail.cgi?id=10057)）、所蔵番号**5000-0057-040**、名称「千川上水記録フィルム　板橋区大谷口付近（推定場所）」。2026-11-11直接確認。カラー写真。
- **〔確認〕** アーカイブ解説：**暗渠化が練馬区内で本格化する直前の昭和27（1952）年頃に撮影**。**千川上水は、石橋の手前では開渠であるが、石橋の下流ではすでに暗渠化されている**。〔[GOV-070](GOV-070.md)（記録フィルム60コマ・区公式ページ）に続く、**同一フィルムの個別コマの所蔵番号つき公開**。大谷口付近（推定）という撮影地推定はGOV-070の7タイトルにはない地点の候補〕。
- **〔確認〕** 「玉川上水から取水する付近から巣鴨付近までの、練馬を中心とした千川上水沿いの風景の記録」という総合解説はGOV-070の記載と同内容。
- **〔推定・要照合〕** 解説の「石橋」が板橋区大谷口のどの橋を指すかは本ページでは特定できない〔大谷口の石橋の同定は次の一手〕。1952年時点で大谷口付近に開渠/暗渠の境があったことの傍証資料〔観察〕。
- **〔未解決〕** 画像の判読（アーカイブ上で画像クリック・拡大表示が可能と明記されるが本確認では実施せず）、同アーカイブ内の他コマ（前後の所蔵番号5000-0057-039/041等）の確認、フィルムの視聴手段（GOV-070の未解決課題と共通）。
