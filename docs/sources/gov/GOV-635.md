# [GOV-635] 「水路敷を道路敷」掃引で特定した水路消滅実務の公文書群（1917・1941）〔repo初出・第385回〕

## 書誌・確認範囲

第384回課題③（都公文書館403解除待ち掃引続き）に沿い、東京都公文書館クロス検索（GETレシピ・第337回形式・全chkCls 14コレクション・2026-11-28取得）で「水路敷を道路敷」（26件）「換地確定図」（15件）を掃引し、詳細頁の表項目を直接取得した。四河川流域に関係する新規は下記のとおり。

### ①「地種目組替 冊の18」の水路敷・用悪水路敷の道路充用群（大正6年=1917・文書記号 己土甲）

収録先簿冊の資料ID 000126790・収録先請求番号 302.D4.27・16mmMFコマ番号 0332-0665・電磁的記録媒体 D875-RAM・複写可（原本電子コピー不可・撮影可）。

- **pkey 1196116〔repo初出〕**: 「地種組換の件 図有り（用悪水路敷を道路敷に充用）〔豊多摩郡井萩村大字上井草字中通南〕《豊多摩郡》」・綴込10・起案1917年10月6日。**千川上水の六ヶ村分水（井草分水）流域（現在の井草・上井草）の「用悪水路敷」の道路転用実務**。BLOG-392（井草川上流は千川上水と井草分水の双方から導水〔伝聞〕）・GOV-689（葛ケ谷村分水）と同じ流域の用悪水路の消滅記録で、井草川流域の水路史の実務側補完。
- **pkey 1196147〜1196149（同一件の3レコード）**: 「水路敷を道路敷に充用の件 図有り〔北豊島郡志村大字小豆沢字東耕地1686番地先（内容注記: 天神前89番地先）〕《宇都宮金之烝》」・綴込30・起案1917年9月5日。**志村小豆沢（現在の板橋区志村・小豆沢）の水路の道路転用実務**。千川上水流域下流部（板橋区側）の小水路の消滅記録。
- **pkey 1196157・1196158（同一件の2レコード）**: 「水路敷を道路敷に充当の件 図有り〔北豊島郡滝ノ川町大字滝ノ川字東大原303～300番の1号（内容注記: 東大原197番の1号）〕《鈴木常吉》」・綴込35・起案1917年10月2日。**滝野川東大原（現在の北区滝野川・田端方周辺）の水路の道路転用実務**。谷端川・千川上水の滝野川区間の小水路の消滅記録。

### ② 千川上水沿いの中新井町第二土地区画整理の換地確定図（昭和16年=1941）

### ③ 陰性（掃引結果の記録）

- 「水路敷を道路敷」26件のうち上記以外は南葛飾郡（亀戸・柳島・大島・寺島）・南足立郡（千住）・荏原郡・豊多摩郡中野町・大久保町等の四河川スコープ外（岩渚町袋稗村137番地先〔pkey 1196146・1917年9月14日起案〕も荒川沿いのためスコープ外）。
- 「換地確定図」15件掃引で「戦災復興土地区画整理換地確定図」シリーズは**目録上6組合のみ**＝新井組合地区①〜⑦（000458210・中野区沼袋1-2丁目・松が丘1-2丁目・新井1-5丁目・昭和35年3月24日換地処分・地図14枚・60×84cm・縮尺1/600・請求番号「戦災復興－新井組合地区」・配架250M201-01・マイラー原図の複写物）／新宿第一（000458211）／西大久保（000458212）／**谷端（000458213＝GOV-633①）**／恵比寿（000458214）／麻布第一（000458215）。**弦巻・水窪・音羽・巣鴨の組合地区の同種図は目録上存在しない**＝谷端組合地区図が四河川流域で唯一の戦災復興換地確定図。新井組合地区（中野区・妙正寺川/神田川水系上流）・他5組合は四河川スコープ外。
- 「悪水吐」42件全件掃引（第384回課題の単語掃引）の結果、四河川関連は既収録の3件（pkey 490251＝GOV-633②〔下板橋宿石神井川悪水吐堰変換願1886〕・822458＝GOV-633⑥〔滝野川村西三軒家〜北谷端悪水吐水路府買上取調書1881〕・704789＝GOV-591〔千川水路滝野川村地内漏水の所并悪水吐捨兼用水路新設検査出張1881〕）のみで**新規なし**。ほか39件は月島・本所・浅草・南葛飾・荏原・南足立等のスコープ外。
- 「千川排水区枝線」（28件）「音羽排水区枝線」（6件）「千川排水区」（30件）「音羽排水区」（9件）の全件掃引で、**枝線第1号（千川・音羽とも）・第6号（同）・千川側第2号の簿冊レコードは目録上不在**＝GOV-628/634の「枝線第1・2・6号の所在未解決」が本掃引でも確認された（検出は第2〔音羽〕・3・4・5・7号のみ・すべてGOV-628/634既収録）。

## 四河川への使い方

- 大正6年（1917）の「地種目組替」群は、**千川上水流域（上井草・志村小豆沢・滝野川東大原）の小水路・用悪水路が道路敷に転用されていった消滅実務の同年次の一次記録**。本文・図面は未見だが、上井草の「用悪水路敷」文言は井草分水流域の排水系（用悪水路）の実在を示し、井草川・鎌田川流域の水路史（BLOG-392・GOV-689）の実務側補完になる。
- 中新井町第二土地区画整理組合の第二工区換地確定図（1941）は、千川上水沿いの「中新井」地名の区画整理実務の一次記録。中新井分水（GOV-005・BLOG-385/393の中新井川・弁天分水）流域の都市化過程の地籍側資料候補。
