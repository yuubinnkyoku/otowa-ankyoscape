# [GOV-347] 御府内往還其外沿革図書 十一（天保元年調）— 雑司ヶ谷村百姓平次郎への火除明地貸与と川田ヶ窪

- **書誌〔確認〕**: 『御府内往還其外沿革図書 十一 外四谷市谷牛込小日向辺一円之絵図』（写・天保元寅年調・NDL次世代デジタルライブラリー [book/2571702](https://lab.ndl.go.jp/dl/book/2571702)）。巻頭に「**天保元寅年調**御府内其還沿革図書外四谷市谷牛込小日向辺一円之絵図二 文二五八ノ六 御府内往還其外沿革図書十一…御普請奉行」＝**天保元年（1830）に御普請奉行が調製した市中（四谷・市谷・牛込・小日向周辺）の火除明地・大縄地の沿革帳**（repo既登録の御府内往還其外沿革図書シリーズ〔[GAZ-050](../gazetteers/GAZ-050.md)の十二之二・[GAZ-054](../gazetteers/GAZ-054.md)の貮拾利等〕の別巻十一・未登録巻の今回の登録）。**引用文言はすべてOCR由来で要原文照合**。
- **雑司ヶ谷村百姓平次郎の菜園場拝借〔確認・文言候補・repo初出の構造〕**: 市中各所の火除明地の沿革の条に、①「**明和四亥年十二月北之方明地一円雑司ヶ谷村百姓平次郎菜園場拝借也御勘定方え被成同五子年八月右平次郎拝借地引渡被召上**」（四谷の明地）、②「**明和四亥年十二月前書明地三ケ所共雑司谷村百姓平次郎菜園場拝借地御勘定方に成同五子年八月右平次郎拝借地被召上**」（法光寺構など三ヶ所の明地）、③「**明和四亥年十二月東西共明地之分一円雑司ヶ谷村百姓平次郎菜園場拝借地御勘定方え引渡二成同五子年八月右平次郎拝借地被召上**」（市谷の東西両明地）＝**明和4年（1767）12月に、四谷・市谷などの市中の火除明地が複数箇所まとめて雑司ヶ谷村百姓平次郎の菜園場（拝借地・御勘定方経由）として貸与され、明和5年（1768）8月に一斉に召上げられた**ことを、帳内の複数の条が同型文言で記す。〔**郊外の菜園農家（雑司ヶ谷村の百姓）が市中の火除明地を菜園場として一斉に借受けた実務記録＝repo初出の構造の記録候補**。①火除明地は防火の空間として維持されつつ、遊休期間は菜園として貸与される（寛延2年の紺屋物干場・元文元年の護持院隠居屋敷等の他の拝借例と同じ構造）。②貸与先が「雑司ヶ谷村百姓平次郎」1名に複数箇所集中している点が特徴（単一農家による市中菜園の展開か・同姓同名の別人かは本文だけでは判別できない）。③**平次郎と雑司ヶ谷町名主平次左衛門（[GAZ-075](../gazetteers/GAZ-075.md)・[GOV-345](GOV-345.md)・嘉永期の行政文書に現れる名主）との同定は本文だけでは不可**（名前の近似のみで断定しない）。〕
- **市谷柳町の「川田ヶ窪」〔確認・文言候補〕**: 市谷側の明地・屋敷の境界列挙に「西之方**市谷柳町川田ヶ窪**辺之部」＋屋敷の四至に「西之方**川田ヶ窪**辺迄」＝市谷柳町の「川田ヶ窪」の地名文言〔**窪系地名（窪地に由来する地名候補）の対照表登録候補**。谷端川・水窪川等の「窪」と同じ語素の市中側の用例だが、当該窪の成因（谷・湿地か）は本文に記載がなく断定しない〕。
- **水系文言の陰性〔確認〕**: 本冊のOCR全文で「弦巻」0件・「水窪」0件・「谷端」0件・「千川」0件＝火除明地・大縄地の沿革帳であり水系・流路の記録は含まれない（雑司ヶ谷村の記録は百姓平次郎の借受人側としてのみ現れる）。
