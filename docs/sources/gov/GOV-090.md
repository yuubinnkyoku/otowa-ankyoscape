# [GOV-090] 練馬区「サポーター体験記 246 千川上水と千川通りの秘密に迫る」

- **書誌〔確認：本文を直接取得〕**：練馬区高齢社会対策課いきがい係「サポーター体験記 246」。PDF、更新日**令和3年7月12日**（取材日令和3年6月17日）。[本文PDF](https://www.city.nerima.tokyo.jp/hokenfukushi/koreisha/ikigai/supporter.files/210712_246.pdf)。
- **内容〔確認：本文〕**：シニアナビサポーター2名（豆柴・ヒロちゃん）による、練馬区文化・生涯学習課伝統文化係長・学芸員**渡邉嘉之**（ふるさと文化館）へのインタビュー記事。
- **千川家に関する新情報〔確認：本文〕**：
  - 千川家と称する家は**4軒（播磨屋・和泉屋・加藤屋・中嶋屋）**あり、開削請負文書に名がある。**播磨屋・和泉屋は上方の地名の屋号で、播磨屋は開削当時「姫路出身」と名乗っていた**（本人表現は「史料を残した千川家の播磨屋は現に開削した頃は姫路出身、と名乗っています」）。
  - 千川家の由緒書（仙川村百姓説）について「元となるものは千川家が自分の家の歴史を書いたもの」「上方出身というよそ者より地元出身・農村出身と名乗った方が周囲のウケも良かったのでは無いか、なんて推測するんです」と**区学芸員による批評的解釈**を提示。 BOOK-065（練馬区史・千川家文書は仙川村百姓説にふれない）と方向が一致する補強資料。
  - **「千川」の名称について、引水地点周辺はかつて「千川郷」と呼ばれていたらしいとし、上保谷新田は開削後に誕生した地名だから「千川郷」が名称の由来ではないか、という渡邉説**〔推定〕。請負文書冒頭は「千河より本郷迄の御上水御普請を請け負う」。
  - 播磨屋は江戸（本郷）在住から、農業用水化ののち下練馬村（今の北町あたり）に移住〔GOV-078の千川家墓=北町2丁目と整合〕。明治以降も東京府から用水管理を任じられ、「その子孫にあたる方も水道を管理する職に携われた」〔聴取〕。
- **暗渠化に関する新情報〔確認：本文〕**：
  - **「この暗渠化は戦前から始まっております」「およそ25年かかっているのですが、実はこれは工事の都合ではなく、予算の関係」**。宅地化が早いところは暗渠化も早い。**管理区分が板橋区になったり東京都になったりと目まぐるしく入れ替わり、戦後は都が一括**（[GOV-053](../blogs/BLOG-053.md)・BLOG-129の法定外公共物・都管理の叙述と整合）。
  - 昭和15年頃と昭和27年頃の写真で今と比較可能（武蔵高校の「熱心な先生」が児童を引き連れて撮影＝[GOV-076](GOV-076.md)調査アルバム系の言及）。**部分的に暗渠化が始まっている様子が確認できる。一番わかりやすいのが筋違橋のあたり**〔PAP-027の筋違橋1953年暗渠化・親柱移設と接続〕。橋を模したモニュメント（親柱復元）が現存〔観察記述〕。
  - 上石神井1丁目2・3番の車道が低く歩道が高いのは、**車道が自然の谷底の地形で、歩道が上水のために谷を埋めた盛り土。絵図には1mm以下の「土手」の印が描かれる**〔読図〕。
- **分水・利用〔確認：本文〕**：畑にはほとんど使われず分水で低い田んぼへ。分水は「何分開き」などのルールがあり組合で統治・管理したのが千川家〔GOV-068の設計思想と整合〕。濯川=**中新井村分水路**で武蔵大学構内に分流跡が残る〔ORG-018〜020・GOV-005の補強〕。練馬区内では水車小屋が少なく農業優先だった〔推定含む〕。
- **注意**：千川郷説・播磨屋姫路出自等の個別考証は渡邉氏の状況証拠に基づく解釈として提示されており、原史料（千川家文書・請負文書）の直接確認までは本項では断定しない。
