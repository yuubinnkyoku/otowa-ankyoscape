# [GOV-331] 北豊島郡大泉村現状調査（1931）— 大泉村成立の6月文言と白子川源流=井頭溜池

- **書誌〔確認〕**: 東京市臨時市域擴張部『北豊島郡大泉村現状調査』（昭和6年＝1931。市域擴張調査資料・市域拡張に伴う郡部町村の現状調査シリーズ）。NDL次世代デジタルライブラリー [book/1900793](https://lab.ndl.go.jp/dl/book/1900793) のOCR全文を確認。**引用文言はOCR由来で原文画像との照合を要する**（本書はOCR崩れが多く、年号・村名に欠落・誤読を含む）。
- **沿革＝大泉村成立の明治24年6月〔確認・repo初出の行政調査書側文言〕**: 「**本村ハ三大字ヨリ成リ自治制發布前ニ於テ上下土支田ヲ一村トシ大字小樾及橋戸ハ之亦共ニ一村ヲ形成セリ…(明治二十)四年六月前記三大字ヲ合併シテ現在ノ大泉村ヲ創設**」＝**①自治制発布前は上下土支田（上土支田・下土支田）が一村、小榑（OCR「小樾」＝小榑の誤読候補）・橋戸が別の一村を形成していたこと、②明治24年6月に三大字（上土支田・下土支田・小榑・橋戸の諸村域＝OCR文脈上「三大字」とされる）を合併して大泉村を創設したこと**。「(明治二十)」の部分はOCRで欠落しており年号は文脈復元（**明治24年＝1891年と読む・原文照合を要する**）。**「六月」の月文言は大泉村成立期日論（6月/9月の対立）の6月側の行政調査書（1931）のdatapoint**＝[GOV-333](GOV-333.md)（埼玉県統計書・移管元側の「二十四年六月」）・[GAZ-063](../gazetteers/GAZ-063.md)（北足立郡誌1924「(六月樽橋村を東京府に移す)」）と同側。
- **白子川の源流＝井頭溜池〔確認・repo初出〕**: 「**白子川ハ其ノ源ヲ本村井頭溜池ニ(発)シ土支田小樾ヲ経テ東流**」＝**白子川の源流を大泉村の井頭溜池とする1931年公式文言**。「(発)」はOCR欠落部の文脈復元（原文照合を要する）。**「井頭溜池」＝[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌・1918）の大泉村名由来の「井頭と稱する小池」に対応する溜池で、repoで白子川の源流を井頭溜池と明言する初の文言**＝[GAZ-002](../gazetteers/GAZ-002.md)の田柄川・白子川の大泉村発源の記録（README既出）に対し、**源流位置を井頭溜池に具体化する観察文言**（井頭溜池と現在の井ノ頭公園（三鷹・吉祥寺）の井の頭池とは別水域で、武蔵野台地東縁の大泉町内の溜池が対象）。
- **四至〔確認・OCR誤読含む〕**: 「**東、上練馬村 南石神井村 西北多摩郡保谷村 北北足立郡白子村新倉村膝折村先山村**」＝大泉村の四隣。**「膝折村」＝現朝霞市の実在村名（新座郡膝折村→朝霞町）で、大泉村の北隣に正しく現れる。「先山村」はOCR誤読で「片山村」（現・和光市。新座郡片山村）の誤認候補**（原文照合を要する＝[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌）の四至「白子新倉片山の各村」が正側の候補）。
- **統計・社会事業〔確認〕**: 面積3,232,830坪・人口（大正9年国勢調査4,033→昭和5年5,052＝10年間に1,260人増）・武蔵野鉄道東大泉駅・「学園都市」（箱根土地株式会社経営の宅地開発）＝**市域拡張期（1931）の大泉村の人口動態・開発状況の行政統計**（大泉学園の前史の開発主体名の記録。数値はOCR要照合）。

## 制限・未解決

- ①沿革文言の「(明治二十)」欠落部・「小樾」＝小榑の原字・「(発)」欠落部はOCR由来で原文画像との照合を要する。②「三大字」の内部構成（上土支田・下土支田・小榑・橋戸の4名称と「三大字」表記の折り合い＝上土支田・下土支田が連続する区画か）は本書の判読からは確定しない（[GAZ-002](../gazetteers/GAZ-002.md)の「大字上土支田」「小樽及橋戸」の構成と対校しつつ断定しない）。③「先山村」＝片山村誤読説の原画像確認。④井頭溜池の正確な位置（現・大泉町のどこか・現存か）は本書からは特定できない。⑤明治24年6月の移管の法的根拠（官報告示・勅令等）は依然未発見。

## 2026-11-17 追記（第143回）：井頭溜池の現在位置の特定（観察）

- **井頭溜池＝現・練馬区立大泉井頭公園〔観察・現在位置の特定〕**: 本文言の「井頭溜池」の現在位置について、**練馬区公式HPの大泉井頭公園の紹介「大泉井頭公園は白子川の源流部にある公園」**（[練馬区・大泉井頭公園](https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/fukei/nerima_park/kunai/omonakoen/ooizumiigashira.html)）と、**白子川源流・水辺の会「白子川の源流は、練馬区立大泉井頭公園(東大泉7丁目・南大泉4丁目の境)にあります。…最初に井頭橋をくぐります」**（[白子川源流・水辺の会](https://shirakogawa.tokyo/nature/93/)）により、**大泉村の井頭溜池（井頭池）は現在の練馬区立大泉井頭公園（東大泉7丁目・南大泉4丁目の境＝旧大泉村域）に比定できる**〔観察：区公式HPの「白子川の源流部」文言と本書の「白子川ハ其ノ源ヲ本村井頭溜池ニ(発)シ」の対応による比定。旧溜池の池体が現在も同位置に残るか（埋立・公園化の経緯）は未確認〕。**「井頭」の地名は公園名（大泉井頭公園）・橋名（井頭橋＝白子川源流部の最初の橋）として現存**し、読みは「いがしら」（[GAZ-065](../gazetteers/GAZ-065.md)（大日本地名辞書・1907）の白子川条「井頭池より出て」と併せ、井頭池＝白子川源流の記録が1907・1918〔[GAZ-002](../gazetteers/GAZ-002.md)〕・1931（本書）と3時点で揃った）。制限④（井頭溜池の正確な位置）はこの比定をもって前進とする（池の現存形態・公園整備の沿革は課題に残す）。
