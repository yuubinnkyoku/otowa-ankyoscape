# [GOV-577] 都議会環境・建設委員会速記録第十三号（2014-11-13）— 千川上水問答の一次原文確認と環七×白子川連結の初期スペック

## 調査方法〔確認〕

- [gikai.metro.tokyo.lg.jp](https://www.gikai.metro.tokyo.lg.jp/record/environmental-construction/2014-13.html) の平成26年環境・建設委員会速記録第十三号（**2014年11月13日（木）・第九委員会室・午後一時開議・出席委員十四名**）。直接curlはWAF 403で遮断されるため、**r.jina.ai経由で全文（86,954字）を取得**（2026-11-24）。委員名簿「河野ゆうき君」の記載も原文で確認。
- 第301回で[BLOG-312](../blogs/BLOG-312.md)（kotakemol04・2015-08-23）が引用していた当該問答について、**引用文言と速記録原文の全文一致を検証**（主要文言5点すべて一致）＝引用の正確性を一次資料で裏付けた。

## ①千川上水問答の一次文言〔確認＝BLOG-312の一次確認〕

- **中島河川部長**: 「千川上水は、河川法の適用のない**法定外公共物**であり、**練馬区の伊勢橋から下流の暗渠区間、約十五キロメートル**につきましては、地元区への移管が整うまでの間、都が使用許可、維持管理などを実施しております」〔[GOV-058](GOV-058.md)の都管理暗渠13.8kmと僅差の数値並記〕
- **中島河川部長**: 「**平成十七年度から老朽化等の調査を行いました**ところ、**損傷や土砂の堆積が判明した**ため、補修工事等を行ってきており、**これに伴い、平成二十二年に通水を停止しております**」＝**通水停止年次（2010年）の一次文言**（[BLOG-129](../blogs/BLOG-129.md)の令和2年「現在停止」に繋がる）
- **中島河川部長**: 「千川上水の**武蔵野市から練馬区までの開渠区間、約五キロメートル**につきましては、**地方分権一括法の施行に伴い、平成十八年に地元区市に財産を譲与**しておりまして、暗渠区間の移管につきましても、地元区と協議を継続しております」〔[GOV-084](GOV-084.md)武蔵野市区間3.8km移譲（2006）の上位文言〕
- **中島河川部長**: 「暗渠区間の大部分は、千川通りなど幹線道路の下に位置しておりまして、切り開いて水路として復活、復元することは困難な状況ではございますが、地元区が空間的に余裕のある場所などで**清流復活に取り組む場合には、都として支援してまいります**。また、**通水の可能性につきまして、堆積物の除去や補修などにあわせて、引き続き調査検討してまいります**」
- **河野（ゆう）委員（板橋区選出・元板橋区議）**: 板橋区大山の千川上水は「**今はもうヒューム管が下に埋設されている、暗渠化された**」「これは**昭和三年、四年のころに暗渠化されて**、七、八十年たつわけなんですけど」〔委員個人の記憶に基づく発言なので**観察（発言）**として記録・断定しない〕

## ②BLOG-312未収録の千川系文言〔今回の速記録掃引で新たに確認〕

- **「千川上水」銘マンホールの存在観察〔repo初出文言候補・観察（発言）〕**: 河野委員「**マンホールなんかも、千川上水というふうに書いてあるマンホールも、実はまだある**ぐらい、よく見てみると、そういうふうな歴史的な遺産が残っております」＝**板橋区大山周辺で「千川上水」と銘記されたマンホールが2014年時点で存在したという証言**。[PAP-027](../papers/PAP-027.md)（北区滝野川6丁目〜板橋駅間の千川上水株式会社社紋マンホール観察・2013）と地域を異にする観察文言で相互に裏付け合う可能性がある〔位置・撮影時期は本文特定されないため断定しない〕。
- **大山駅周辺まちづくりマスタープランへの言及の一次確認**: 河野委員「板橋区内の東武東上線大山駅周辺においても、現在まちづくりが進められておりますけど、**このまちづくりマスタープランの中にも、千川上水のことが、可能性としてですが、少し触れられております**」＝当該マスタープラン（板橋区・2012年3月22日提言）の実在とかかわる都議会レベルの言及。**マスタープラン本文PDF（添付4点）はWaybackスナップショット（20260219145325）で所在を特定したが画像ベースPDFのため千川文言の頁特定はhuman目視待ち**（[第302回ノート](../../2026-11-24（第302回）・都議会速記録13号の一次確認・環七白子川連結初期スペックの確定・大山マスタープラン頁の特定とWaybackレジューム技.md)参照）。
- 河野委員による千川上水の概説（「千六百何年ぐらいにできた…玉川上水から分水をして江戸のまちの方に入ってくる」）は委員の理解の伝達にとどまる〔起立年代の文言ではない〕。

## ③補助第二二九号線×千川上水緑道の一体文言〔確認＝repo初出文言候補〕

- **高橋委員**: 「現道の千川通りは、**千川上水緑道と並行した幅員五・五メートルの歩道もない狭隘な道路**であり」「**昨年十月には、南側に千川上水緑道と一体になった緑豊かな歩道が整備され**」＝**2013年10月に千川上水緑道と一体の歩道が整備された**という年次・性状文言。
- **相場道路建設部長**: 「補助第二二九号線は、**立野橋交差点から青梅街道までの四百三十メートルの区間**で事業中であり、**既に約九七％の用地を取得**し、南側の歩道の開放に続き、車道の切りかえ工事を実施いたしました。今年度からは、**北側の電線共同溝設置工事**に着手する予定」「北側についても、新たに歩道を整備し、**植樹帯で歩行者と自転車を分離した、人に優しい道路空間を創出**してまいります」＝**千川通り（都道補助229号線）の拡幅整備が千川上水緑道の緑道空間と一体で計画・実施されている**という道路整備×水路空間の連関文言。

## ④環七×白子川広域調節池連結の2014年時点スペック〔repo初出文言群〕

- 「**環七地下調節池と白子川地下調節池とを、内径十二・五メートル、延長約五・五キロメートル、貯留量約六十八万立方メートルのトンネル式の新たな調節池で連結する**ものでございます」＝**広域調節池連結整備（環境七その2）の2014年時点の初期スペック**（[GOV-560](GOV-560.md)の「連結68万（貯留量約68万m³）」と一致する一次文言＝spec は遅くとも2014年に確定していた）。
- 「**神田川、石神井川、白子川の三流域間で調節池の容量の相互融通が可能**となり、**局地的かつ短時間の時間百ミリの豪雨にも効果を発揮**してまいります」＝3流域融通設計の一次文言。
- なお2014年時点で環七地下調節池の規模は「**五十四万トン**」と委員側から言及されている。

## ⑤境川河川整備計画原案の76万立米〔GOV-554の前史〕

- 委員質疑: 平成26年9月公表の境川河川整備計画（変更）原案に「東京都管理区間において**合計約七十六万立米の調節池を新たに整備**すると記載されております」「境川中流調節池は、その**第一弾**であり」＝**境川の都管理区間76万m³調節池整備の2014年原案文言**。のちの変更原案49.8万m³（[GOV-554](GOV-554.md)）に先行する初期計画値としての対校点〔76万→49.8万の変遷の意味づけは両文言の前後関係のみでは断定しない〕。
- 2014年9月の「時間百ミリを超える豪雨」（町田市の都管理区間の境川溢水）が原案議論の契機と委員から言及されている。

## ⑥白子川地下調節池の事業経過〔確認〕

- 「白子川地下調節池につきましては、**平成二十一年度より事業を再開**いたしまして、**二十二年度から着手した延長三・二キロメートルのシールドトンネル工事が本年一月に完了**いたしました」「**平成二十六年度末の暫定取水**と**二十八年度末の完成**を期待しておきます」＝事業再開（2009年度）→シールドトンネル完了（2014年1月）→暫定取水（2016年3月＝26年度末）→完成（2017年3月＝28年度末）という工程一次文言。
