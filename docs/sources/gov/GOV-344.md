# [GOV-344] 諸宗作事図帳[61]（新義真言宗）— 護国寺境内・門前の帳簿レベルの坪数と支配文言〔第151回〕

- **書誌〔確認〕**: 『諸宗作事図帳 [61] 百五十二（新義真言宗）』（写本・NDL次世代デジタルライブラリー [book/2573039](https://lab.ndl.go.jp/dl/book/2573039)）。寺社奉行系の作事（普請・建築）の図帳・書出の類集で、本冊は護国寺・護持院（筑波山護持院）関係の記録を多く含む。**OCRの崩れが非常に大きく（出火記録・日付の混交）、引用文言はすべて候補として原画像照合を要する**。
- **延宝9酉年2月11日・雑司ヶ谷御薬園地の護国寺屋敷拝領の文言候補〔確認・文言候補・repo初出候補〕**: 「**延宝九酉年二月十一日 雑司ヶ谷御薬蘭（御薬園のOCR崩れ候補）之地幷建家 御薬種八州へ虫喰… 大聖護国寺屋鋪拝領ニ付渡… 一土蔵 壱万八千壱坪（候補）**」＝**延宝9年（1681）2月11日に雑司ヶ谷の御薬園の地と建家が護国寺の屋敷として拝領された旨の文言候補**。〔**[GAZ-072](../gazetteers/GAZ-072.md)の芥川文書引用「牛込藥園ハ今ノ音羽護國寺境內」・同書の高田殿址条「延寶八年庚申德川氏護國寺ヲ建テ之ヲ廢ス」＝北薬園廃止（延宝8年）の翌年2月の拝領文言候補として、牛込（北）御薬園→護国寺境内説（正徳3年白山移転説と併せ）の帳簿側の対校資料**（年次・坪数・「御薬種」の文言は原画像照合が前提・断定しない）。延宝8年建立（GAZ-072）と延宝9年屋敷拝領の年次差は、寺の建立と薬園地の移管の2段階として整理できるが本冊からは断定しない。〕
- **護国寺境内の拝領坪数の通時文言候補〔確認・文言候補・repo初出候補〕**: 「**元禄三庚午年 西之方にて 護国寺境内西○壱万五千坪 拝領之由 地所不詳 趣書出**」＋「**同四辛未年 同境内東之方…拝領之由書出**」＋「**同十五年五月 元自性院領之内三千六百坪 拝領之由書出**」＋「**惣坪数四万七千坪余 護国寺惣坪数四万七千坪余ハ 正徳五乙未年十二月 御普請奉行大久下野守殿有之節之坪数ニ候**」＝**①元禄3年（1690）の境内西側15,000坪拝領、②元禄4年（1691）の境内東側の拝領、③元禄15年（1702）の自性院領内3,600坪の拝領、④惣坪数4万7千坪余（正徳5年〔1715〕12月の御普請奉行・大久下野守の調査時点の坪数）、という境内の拡大過程の坪数の書出の文言候補**。〔**護国寺の境内坪数が元禄3年〜15年の3段階の拝領で形成され、正徳5年に4.7万坪余と確定したとする帳簿の書出**＝[GAZ-073](../gazetteers/GAZ-073.md)（圓融寺自證院書上の元禄10年「護国寺御建立之切」収用）・[GAZ-072]の元禄年中護国寺建立（芥川文書）・[GAZ-013]（御府内備考・元禄5申年観音堂御建立）と対照できる**境内形成の年次・坪数のdatapoint群**（文言はすべて候補・年次の整合の最終判断は原画像照合待ち）。「自性院」の表記は自証院の変種か別寺院か要照合。〕
- **表通りの石垣延長・塔頭7ヶ寺・門前町家の町方支配の文言候補〔確認・文言候補・repo初出候補〕**: 「**拝領地 両寺惣境内四万七千坪余 新義真言宗 外ニ大塚村之内三千坪 護国寺隠居屋敷拝領 但屋式（屋敷？）別々拝領**」＋「**護国寺表通り 東西え惣石（石垣）拾弐百弐拾間壱尺三寸 霊（量？）行凡弐百拾八間余 塔頭合七ヶ寺 門前町家等 惣而町方支配二御座候**」＝**①護持院と護国寺の惣境内4.7万坪余＋大塚村内3,000坪の護国寺隠居屋敷、②護国寺の表通り（音羽町の通り）の東西の石垣1,220間1尺3寸・奥行218間余、③塔頭7ヶ寺、④門前町家はすべて町方支配、という作事図帳レベルの記録候補**。〔**①護国寺門前の音羽町（門前町家）が帳簿上「惣而町方支配」と明記される初の文言候補**＝[GAZ-013]（御府内備考・護国寺領三ケ町）・[GOV-342](GOV-342.md)（市中取締類集・護国寺領音羽町9ヶ町の名主源次郎）と接続する支配構造の帳簿側の裏付け。②表通りの石垣延長（1,220間1尺3寸・約2.4km候補）は門前町の通り幅・規模の検討資料（数字は原画像照合が前提）。③筑波山護持院と護国寺の「両寺」としての一体管理の文言（[GAZ-072]の筑波山護持院条〔音羽町の北・寺領千五百石〕と対照）。〕

- ①本冊のOCRは崩れが非常に大きく（帳簿・書出・日記の混交）、すべての文言・坪数・年次・人名（大久下野守・自性院/自証院）は原画像照合を要する（特に「壱万八千壱坪」「拾弐百弐拾間壱尺三寸」「四万七千坪余」の数字群）。②「雑司ヶ谷御薬園之地」の文言の文脈（牛込御薬園の当地移管か、別の薬園か）と延宝9年2月11日の拝領の確定は原画像照合まで留保（[GAZ-072]の延宝8年北薬園廃止説との整合は観察として記録）。③元禄3・4・15年の拝領の地形（境内の西・東・自性院領内の位置）は本冊の文言のみでは確定できない（作事図本体の図面の判読が前提）。④「正徳五乙未年十二月…大久下野守殿」の普請奉行調査の一件の比定（大久保氏の任官時期の確認）は未実施。⑤「塔頭合七ヶ寺」の塔頭の個別名は本冊の当該箇所のOCRからは読み取れない。
