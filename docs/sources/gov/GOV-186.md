# [GOV-186] 常務委員会議事速記録 第10号（1940年3月13日開会分）

- **書誌〔確認〕**: 都市計画東京地方委員会『常務委員会議事速記録 第10号』（昭和15年3月13日開会分を収録）・NDL次世代デジタルライブラリー [book/1184236](https://lab.ndl.go.jp/dl/book/1184236)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **「立会川及谷端川ハ既ニ完成」文言の委員会側記録〔確認・repo初出の年次情報〕**: 常委議第140号（昭和15年3月9日付・内務大臣兒玉秀雄）について幹事高橋登一が説明した文言＝「**立会川及谷端川ノ方ハ既ニ昭和九年ニ工事ガ完成シテ居リマス、処ガ神田上水ノ方ハ若干ノ浚渫工事ガ残テ居リ…18万2,380円ヲ追加**」〔「昭和九年ニ」の前後にOCRの頁番号混入（23/24）があり、この部分の連続判読は要照合〕。〔[GOV-135](GOV-135.md)（NDA文書・昭和15年3月23日付の起案で「立会川及谷端川ハ既ニ完成」と記す）と**同一案件の委員会側記録**であり、しかも「**昭和九年（1934年）ニ完成**」という**年次を与える**点でNDA文言を具体化する。谷端川改修（告示155号1930-08-13決定）の完成年次について、これまで[GOV-160](GOV-160.md)（1934年・都市計画報告第2回の変更要綱＝1934年時点で計画数値が確定）や[GOV-101](GOV-101.md)（1931年・収用公告）等の間接材料しかなかったところに、**「1934年完成」とする第一次記録**が加わった〕〔文言はOCR要照合〕。
- **三河川改修の総経費〔確認・参考〕**: 同説明で三河川（立会川・神田上水・谷端川）の改修事業費**562万余円**・**昭和5年度から14年度に至る10箇年度**の継続事業という枠組みが言及される。神田上水の残務（浚渫）に18万2,380円を追加する案が付議された。〔総経費・追加額・年度区分はOCR要照合〕。


- **〔2026-11-19 第193回追記・第十八回常務委員会（昭和15年12月9日開会）の読み落とし分〕**: 同号（第10号）には第十七回（昭和15年3月13日）のほか**第十八回常務委員会（昭和15年12月9日・內務省第二會議室）**も収録されており、第193回に再取得して以下を確認〔OCR由来で要原文照合〕。
  - **幹線環状道路第七号路線（環状線）の杉並区内「神田上水附近」区間変更〔repo初出の文言〕**: 常委議第147号（昭和2年内務省告示第409号の道路中変更・1940-11-30安井英二）＝「幹線環狀道路第七號路線中**杉並區內神田上水附近ヨリ補助線道路第三十五號路線トノ交會箇所附近ニ至ル區間**ニ於テ**在來道路ヲ利用シテ**工費ノ節減ヲ計ル」＋幹事高橋登一説明（工費**約四萬四千圓ノ節約**）＝**環状道路第七号（現・環七通り）の計画線が杉並区内で神田上水（水路）沿いの在来道路に付け替えられた1940年の委員会決定の文言**〔環七×神田上水（千川上水と同じ玉川系の給水路）の水路空間と道路網の交点の制度側記録。神田上水「附近」の在来道路の具体区間（天沼〜本天沼方面候補）は本文図面未確認で断定しない〕
  - **神田川上流改修に伴う飯田町の復興土地区画整理街路の位置変更〔参考〕**: 常委議第146号（大正13年内務省告示第171号の街路中変更）＝「神田川上流改修工事ニ伴ヒ…飯田橋附近ノ區間ガ河川敷トナル」ため街路位置を中央線寄りに移す＝**神田川（江戸川）上流改修と飯田橋周辺の土地区画整理街路の の位置関係の1940年記録**〔神田川はrepo四河川の直接対象外だが千川の流末関連の水系整備の同時代的記録として参考に残す〕
