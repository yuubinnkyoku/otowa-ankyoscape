# [GOV-360] 御府内場末往還其外沿革圖書 貮拾貮上（安政5年調）— 天保13年の雑司ヶ谷感応寺上地と猿若町芝居移転の替地行政・御鷹部屋同心の人物記録〔第158回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の[42]冊「貮拾貮上」（**安政5年〔1858〕調**の、場末の往還・土地の沿革を書き上げた帳簿群の1冊）。NDL次世代デジタルライブラリー [book/2587252](https://lab.ndl.go.jp/dl/book/2587252)。同系統の既登録冊: [GOV-168](GOV-168.md)（天保5年一件）・[GAZ-080](../gazetteers/GAZ-080.md)（拾九利・嘉永5年調）・[GOV-213](GOV-213.md)（拾九・天保8年調）等。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する**。
- **天保13寅年の感応寺上地と猿若町芝居移転の土地再編〔確認・文言候補・時代の中の雑司ヶ谷上地の流れ〕**: 「**天保十三寅年正月…小出伊勢守下屋鋪上ケ地 天保十三寅年中雑司ヶ谷感応寺上ヶ地之内にて代地ニ被下 右は沼革弐拾之部ニ出ルに成 同年二月中右上ケ地之内堺町葺屋町両芝居其外引移被仰出 為替地新道仕付…右地町名猿若町…**」＝**①天保13年（1842）正月に小出伊勢守の下屋敷が上地（収公）され、②同年中に雑司ヶ谷の感応寺上地の内で代地が下され（その詳細は「沼革弐拾之部」〔沼革二十之部の帳〕に出ると注明）、③同年2月中に小出伊勢守下屋敷の上地の内に堺町・葺屋町両芝居そのほかが引き移されるよう仰せ出され、替地・新道が仕付けられ、その地の町名が猿若町となった**、と読める文言群。〔**①天保13年の江戸市中の土地再編（芝居小屋の浅草猿若町への移転＝天保の改革期の市中政策）と雑司ヶ谷の感応寺上地の代地処理が同じ帳の中で一連の記録として現れる、②「雑司ヶ谷感応寺上ヶ地」＝天保13年時点で雑司ヶ谷に感応寺の上地（寺地の収公地）が存在し、その一部が代地処分に使われたことを示す文言候補**。[GOV-168](GOV-168.md)（天保5年〔1834〕の安藤対馬守屋敷が感応寺へ下された一件）と**時系列に整合する感応寺関連の土地記録**＝天保5年の拝領→天保13年の上地・代地処分という流れの候補。**ただし①感応寺の比定（谷中感応寺〔日蓮宗・天保4年の取潰しで知られる〕系か、別の感応寺か）と「雑司ヶ谷」の帰属の実字②「沼革弐拾之部」の帳の所在（本文言の全容はそちらにある）③代地の方向（誰がどこに代地を受けたか）はOCR崩壊のため未確定で、原画像照合まで断定しない**。〕
- **雑司ヶ谷御鷹部屋同心の人物記録〔確認・文言候補・repo初出の「御鷹部屋同心」語〕**: 「**塚本喜兵衛 文化元子年中 先代惣兵衛 雑司ヶ谷御鷹部屋同心被仰付**」＝**文化元年（1804・子年）に先代塚本惣兵衛が雑司ヶ谷御鷹部屋の同心に仰せ付けられた（任命された）という文言候補**。〔**「御鷹部屋同心」の語はrepo初出**＝[GAZ-073](../gazetteers/GAZ-073.md)（享保4年〔1719〕正月の御鷹部屋御用屋敷取立の代地収用記録）・[GAZ-048](../gazetteers/GAZ-048.md)（風土記稿・享保4年起立の御鷹部屋9,088坪余）と接続し、**享保4年起立の雑司ヶ谷御鷹部屋が文化元年時点でも同心（定員の役人）を伴って運用されていた方向の人物レベルの記録候補**（御鷹部屋=鷹狩用の鳥狩り部署の屋敷・同心はその構成員）。塚本家の先代・当代の実名や役割はOCR崩壊のため要照合。〕
