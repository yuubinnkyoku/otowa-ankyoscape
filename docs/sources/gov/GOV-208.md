# [GOV-208] 東京市町名沿革史（1938年）— 小石川流路の町列・千川屋敷の位置・戸崎町の由来

- **書誌〔確認〕**: 東京市編『**東京市町名沿革史**』（昭和13年・1938年）。東京市内の全町名の沿革を町別に記す。NDL次世代デジタルライブラリー [book/1231150](https://lab.ndl.go.jp/dl/book/1231150)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **小石川区章の小石川流路〔確認・repo初出の1938年時点の町列記録〕**: 「本區を貫流する小石川は**源を豐島區長崎町に發し細流を合せ同區巢鴨町に入り、谷端川と稱し、小石川に至り始めて此名あり。久堅町、戶崎町、八千代町、柳町、初音町、餌差町、下富坂町を經て小石川に至て大下水と稱し、仙臺橋を過ぎて神田川に注ぐ、長さ凡そ二里三十二町五十間なり**」＝**1938年時点の官撰側の流路記録で、①源を豊島区長崎町とする起点特定（＝谷端川源流説と整合）、②「巣鴨町で谷端川と称し、小石川区で小石川の名」＝区境での呼称切替、③久堅町→戸崎町→八千代町→柳町→初音町→餌差町→下富坂町の町列（氷川下町〜下富坂町間）、④「大下水」呼称区間、⑤仙台橋経由の神田川合流、⑥長さ凡そ二里三十二町五十間（約9.3km）**を一つの文で固定する〔町列の順序・「小石川に至り/を經て」の重複表現はOCR要照合〕。〔[BOOK-009](../books/BOOK-009.md)（1910・礫川要覧）の「氷川下町、久堅町の低地を貫き、戶崎町、柳町、初音町等を過ぎ砲兵工廠內を通過して神田川に注ぐ」と同じ流路系統の28年後の記録。両者の差（1910年は砲兵工廠内通過を明記、1938年は仙台橋を明記）は補い合う〕。続けて「**新編武藏風土記言ふ、往古は頗る大川なりしに後漸く道敷等埋立て今は廣さ凡そ一間一尺許深さ三、四尺乃至八、九尺に過ぎず**、江戶名勝誌は言ふ、古ノ吾妻川とて名所の一なりと」＝**風土記稿「往古は頗る大川」引用＋1938年時点の規模（幅一間一尺許・深さ三四尺乃至八九尺）**〔古ノ吾妻川の異名説は江戸名勝志由来として記録〕。
- **千川屋敷＝白山前町の内・元禄9年太兵衞・徳兵衞の宅地拝領〔確認・第102回課題（GOV-175「西千川」位置特定）への前進〕**: ①指ヶ谷町条「**明治二年五月白山前町の內千川屋敷及圓乘寺蓮華寺淨雲寺正福院の門前**（古ハ皆小石川村の民地にして概して傳通院領たり）**を併せて今の稱に改め**」＝**千川屋敷が白山前町の内にあり、明治2年5月に指ヶ谷町へ併合されたことを明記**〔現在の小石川指ヶ谷町内＝白山通りと染谷通り（旧・指ヶ谷一・二丁目）界隈〕。②（OCRの頁境界で親町名が欠落する箇所にあるが）「**千川屋敷は元祿九年多摩郡仙川村の民太兵衞、德兵衞命を受けて千川上水を通じ、村名を姓とし、宅地を給せられしもの是なり。蓮華寺の北に在る坂を蓮華寺坂と曰ひ、南に在る坂を伊賀坂と言ふ**(東京案内、御府內備考)」＝**千川上水開削の元禄9年請負人仙川村の太兵衞・徳兵衞が、上水通しの功で宅地を拝領し「千川」姓を名乗った屋敷が千川屋敷**であること、**その位置が蓮華寺坂（北）と伊賀坂（南）の間**であることを記す〔千川上水元禄9年開削説（[GAZ-002](../gazetteers/GAZ-002.md)・[BOOK-122](../books/BOOK-122.md)ほか）の請負人側の宅地位置を固定する記録。①②で千川屋敷の位置（白山前町の内→明治2年5月指ヶ谷町、蓮華寺坂〜伊賀坂間）が特定された＝**[GOV-175](GOV-175.md)「西千川」・千川屋敷の位置の第102回課題への回答候補**〔OCR頁境界欠落のため②の親町名の確認は原文照合で要確認〕。
- **戸崎町の名の由来〔確認・repo初出文言〕**: 戸崎町条「附近の大崎袖ヶ崎三崎等の例より考へ、**指ヶ谷、千川谷間の突端を戶崎と名付けたるものならん歟**」＝**「指ヶ谷・千川の谷間の突端」説**〔「千川谷間」＝小石川（千川）の谷という地形認識。伝・舳先町転訛説への対置として東京市自身が提示した説。推量形（ならん歟）であり断定ではない〕。
- **音羽町各丁の弦巻川現勢〔確認・1938年時点〕**: 音羽町三丁目「**弦卷川西を流れ下流音羽瀧となる**」、五丁目「弦卷川西に在り」、七丁目「弦卷川西に在り」、八丁目「西に弦卷川あり」、九丁目「**西に弦卷川あり。本町の西にも弦卷川あり**」、櫻木町「**町の西にも弦卷川あり**」＝**1938年時点でも弦巻川が音羽町・櫻木町の西側に開渠で残っていたことを示す町別記録**〔[GAZ-028](../gazetteers/GAZ-028.md)（1907・東京案内）の31年後。1932年弦巻通り開設後も残存していた川の実在記録として、弦巻川暗渠化・埋設時期（1932年説との関係）の検討資料〕〔OCR欄外混入あり・丁目対応は要照合〕。音羽町「六丁目七丁目の間に上る坂を鼠坂と言ふ」も〔[GAZ-030](../gazetteers/GAZ-030.md)（江戸名勝志）の鼠坂条と同じ坂の1938年表記〕。

## 制限・未解決

- ①すべての引用はOCR由来で、小石川流路の町列・「二里三十二町五十間」の数値・千川屋敷条の文言は原文画像照合を要する。②千川屋敷条（元禄9年太兵衞・徳兵衞）はOCRの頁境界で親町名が欠落しており、白山前町条・指ヶ谷町条のいずれに属するかは原文で確認する必要がある（明治2年5月指ヶ谷町併合の文言から白山前町→指ヶ谷町の流れは明らか）。③「小石川に至り始めて此名あり…小石川に至て大下水と稱し」の「小石川」（地名）と「小石川」（区名・川名）の使い分けは原文照合課題。④古ノ吾妻川説の出典（江戸名勝志の該当条）は[GAZ-030](../gazetteers/GAZ-030.md)本文では未確認。⑤弦巻川の音羽町西側現勢は1938年時点の記述だが、暗渠化（埋設）の時期・区間をこの資料だけでは特定できない。
