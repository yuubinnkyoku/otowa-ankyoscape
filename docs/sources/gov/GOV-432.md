# [GOV-432] 天明撰要類集 十五 — 千川上水御普請の小屋場＝筋違橋外・牧野大隅守一人懸りの文言

- **書誌〔確認〕**: 『天明撰要類集』全十五（御成・御通船関係の行政事例綴を含む冊・[GOV-215](GOV-215.md)・[GOV-353](GOV-353.md)・[GOV-354](GOV-354.md)と同シリーズの未登録冊）。NDL次世代デジタルライブラリー [book/2572887](https://lab.ndl.go.jp/dl/book/2572887)。**引用文言はすべてOCR由来で要原文照合**。
- **文言〔確認・repo初出〕**: 大川通（隅田川）御成の御通船の際に三小屋場へ御詰があったかどうかの再調の文書の中に——「**日本橋川筋ゟ大川通御成御通船之節三小屋場え御詰被遊候儀再調候処是迄御手限御普請所有之儀無御座 先達て千川上水御普請之節筋違橋外に小屋場有之牧野大隅守殿御壱人懸りに御座候処 上野御城之節北屋場江御徒入有之大隅守殿二は御詰不被成候 日本橋江戸橋御普請之節右川筋御成之節御普請小屋御徒江引渡橋奉行は引払申候**」＝**①大川通御成の御通船の際の小屋場の御詰の慣例の再調の中で、②「先達て（天明2〜3年）千川上水御普請の際には筋違橋外に小屋場があり、牧野大隅守が一人懸りだった」ことが想起されている、③上野御城の際の北屋場・日本橋江戸橋御普請の小屋の例と並べて、小屋場の管理（御徒への引渡・橋奉行の引払）の先例として引かれている**。
- **意味〔確認・GOV-354の未解決への回答候補〕**: [GOV-354](GOV-354.md)（天明6年・牢屋敷・千川上水小屋場の駈付人足帳簿）は「千川上水小屋場」の語の用例を登録したが、**小屋場の位置は本冊では特定できず「未解決②」**として残していた。本冊の文言は**その小屋場（堀割御普請＝[GOV-353](GOV-353.md)（天明2〜3年・牧野大隅守組・曲淵甲斐守組の与力同心の実務）の拠点）が「筋違橋外」＝神田川（江戸川）の筋違橋の外（千川上水の流末・[GOV-215](GOV-215.md)の天明期の流末舟揚げ区域と同じ神田側の河岸域）にあった**とする回想文言で、①小屋場の位置の一次情報、②「牧野大隅守殿御壱人懸り」＝普請の指揮が牧野大隅守（南町奉行・[GOV-353](GOV-353.md)・[GOV-215](GOV-215.md)の与力2組の申渡・番所上納の宛先と一貫）の単独懸かりであったことの裏付け（曲淵甲斐守組は与力同心の実務に含まれるが、屋場運営の指揮は牧野大隅守にあった可能性の指摘）、③千川上水の天明期再興の実務拠点が神田側の流末に置かれた＝**上水の流末（神田川合流点）側の河岸が普請管理局としても使われた**という立地情報（江戸城へ通勤する町奉行の管轄下の水利拠点として筋違橋外が選ばれた理由の考察は原画像照合まで保留）。
- **注意〔確認〕**: 本文言は天明2〜3年の普請時の一次文書ではなく、後年の再調文書中の回想（慣例確認のための先例の想起）である。小屋場の存在・位置・指揮系統の記録としては「行政文書中の想起文言」として位置づけ、普請当時の帳簿（[GOV-353](GOV-353.md)）と突き合わせの上で採用する。

## 制限・未解決

- ①「三小屋場」のうち筋違橋外の小屋場が千川上水御普請専用か（江戸橋・北屋場との併記との対応）は文脈照合要。②「御壱人懸り」の意味（牧野大隅守個人の指揮下か、牧野大隅守組の意味か）は原字形照合まで断定しない。③小屋場の規模・存続期間（天明6年の[GOV-354](GOV-354.md)の小屋場との同一性）は確定できない（同一と読むのが自然だが断定留保）。
