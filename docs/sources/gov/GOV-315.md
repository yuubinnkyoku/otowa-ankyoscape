# [GOV-315] 警視庁令類纂 第5版（明治29年現行）— 兩上水禁例の最終形・兩上水取締心得・三上水巡視訓令

- **書誌〔確認〕**: 『**警視庁令類纂**』**第5版**（**明治29年4月末日現行**・1898発行。NDL次世代デジタルライブラリー [book/791005](https://lab.ndl.go.jp/dl/book/791005)）。警視庁の現行規令を部門別に編纂した類纂。第九章衛生・第四款飮料水及氷雪（頁913〜919付近）に両上水・千川関係の規令を収録。**引用文言はOCR由来で原画像照合を要する**（ただし本書のOCRは布達全書系〔[GOV-311](GOV-311.md)等〕より列崩れが少なく条文が連続して読める）。

## ①神田玉川兩上水取締禁例の最終形全文〔確認文言・repo初出〕

- 「**布達 明治十一年十月二十九日甲第五十七號 神田玉川兩上水取締禁例 左ノ通相定來ル十二月一日ヨリ施行候條此旨布達候事 第一條 魚鳥ヲ捕リ及ヒ游泳シ又ハ諸物品ヲ洗フヘカラス 第二條 塵芥瓦礫其他汚穢物ヲ投棄スヘカラス 第三條 上水ニ沿フタル各地面ヨリ汚水混入セシムヘカラス 第四條 堤上ノ竹木及ヒ下草等伐採スヘカラス 第五條 此規則ニ違背シタル者ハ違警罪ヲ以テ罰セラルヘシ**」
- **意味〔確認・第136回課題①の解決〕**: 明治11年10月29日甲第57号の仮規則〔全文は[GOV-313](GOV-313.md)〕→明治12年2月26日甲第6号の改名・第3・4条改正・第5条（堤防破損告知条）刪除〔[GOV-312](GOV-312.md)〕を経た**禁例の最終形が5か条構成**で、**第5条は罰則条（違警罪）に置き換わっている**ことが初めて確認できた。旧第5条（破損箇所の巡查・分署への告知）は刪除され、罰則が新たな第5条として末尾に置かれた構成。**いつ罰則条が追加されたかは本書では確認できず**（[GOV-312](GOV-312.md)の違式罪目第76条〔明治12年2月26日追加→同年11月10日刪除〕の代置か、後年の罰則布達〔法規分類大全の「兩上水取締禁例罰則 甲第58号」候補〕によるかは未確認・文言候補として次回課題）。
- **現行性〔確認〕**: 本版の「明治29年（1896）4月末日現行」編纂＝**神田上水廃止（明治34年6月・[GOV-307](GOV-307.md)）の5年前まで両上水禁例が現行規令だった**ことの類纂レベルの裏付け。

## ②千川水道取締禁例の6か条全文〔確認文言・GOV-311制限①④の解決〕

- 「**布達 甲第二十五號連署 明治十四年五月十一日 千川水道取締禁例 左ノ通相定候條此旨布達候事 第一條 魚鳥ヲ捕リ及ヒ游泳シ又ハ諸物品ヲ洗フヘカラス 第二條 塵芥瓦礫其他汚穢物ヲ投棄スヘカラス 第三條 上水ニ沿フタル各地面ヨリ汚水混入セシムヘカラス 第四條 堤上ノ竹木及ヒ下草等伐採スヘカラス 第五條 水道敷地內ヘ諸車挽キ入レ又ハ牛馬ヲ牽キ入ルヘカラス但道路ニ係ル分ハ此限ニ在ラス 第六條 此規則ニ違背シタル者ハ違警罪ヲ以テ罰セラルヘシ**」
- **意味〔確認・対校〕**: [GOV-311](GOV-311.md)（布達全書明治14年分）でOCR崩れのため未復元だった**千川禁例の条構成が6か条と確定**した。①第4条＝堤上竹木下草伐採禁止（独立条）・②第5条＝水道敷地内への車・牛馬牽入禁止（道路分除外）・③**第6条＝違警罪罰則条が禁例自体に内蔵**（兩上水禁例と違い、千川禁例は当初から罰則条つきで布達された）。**[GOV-312](GOV-312.md)の違式罪目第76条罰則化→刪除（明治12年）の運用を経て、千川側（明治14年）はルール内罰則という形式を取った**ことが条文構造から読める〔観察〕。791005と[GOV-320](GOV-320.md)（現行日本衛生類典・1894）の2系統で同文言。

## ③「神田玉川兩上水取締心得」明治12年2月26日番外（第三方面第四分署）の全文〔確認文言・repo初出文書〕

- 「**達 明治十二年二月二十六日 番外 第三方面第四分署 神田玉川兩上水取締心得 左ノ通相定候條此旨相達候事 第一條 兩上水路敷地神奈川縣下ニ係ル場所ニ於テ該取締禁例違犯者アル時ハ該縣最寄警察署ヘ送付スヘシ但通常註違罪ハ問フヘキ限ニアラス 第二條 前條敷地內ニ變死人アル時ハ速ニ最寄警察署ヘ通知スヘシ 第三條 上水ニ沿フタル各地面ニ從來設置アル下水溝渠等流溢シテ禁例第三條ニ觸ル、場所ハ當分不問ニ付スヘシ**」
- **意味〔確認〕**: ①**兩上水路敷地の神奈川県下区画（玉川上水上流部）の違犯者は神奈川県側警察署へ送付**＝上水路敷地が当時府県境をまたいだことの警察運用レベルの記録。②変死人の取扱い。③**沿面の従来からの下水溝渠で上水への汚水流入（禁例第3条抵触）箇所は「當分不問」**＝明治12年時点で沿面に上水へ流入する既存の下水溝渠が複数実在し、一律禁止（第3条）と既存施設の矛盾を運用細則で揉み消した一次記録。**神田上水の汚染史（下水流入の実態）の証拠群（[GOV-292](GOV-292.md)系）を補強する運用側文書**〔観察〕。
- 目次表記は「神田玉川兩上水**路**取締心得」（兩上水**路**取締心得）で本文見出しと微妙に異なる（OCR崩れか表記揺れかは要照合）。

## ④訓令明治26年12月13日甲第62号「神田玉川千川三上水水路取締狀況申報方」〔確認文言・repo初出〕

- 「**訓令 明治二十六年十二月十三日 甲第六十二號 神田玉川千川三上水水路所在地警察署 神田玉川千川三上水水路取締ハ自今每月二回以上署員ヲ派シテ之ヲ爲サシメ其都度狀况ヲ申報スヘシ**」
- **意味〔確認〕**: ①「**神田玉川千川三上水**」という3上水の統称の公式文言〔repo初出〕（1891年の[GOV-173](GOV-173.md)「玉川神田千川ノ三上水」とも整合）。②**三上水の水路巡視を每月2回以上・署員派遣で実施し都度報告させる制度化**（明治26年＝千川上水の樋管3,707間期・神田上水廃止の8年前）＝**両禁例＋心得の運用が1893年に定常巡視体制として再編された**ことの訓令〔観察〕。③宛先が「水路所在地警察署」＝上水行政が特定分署（第三方面第四分署）から沿線の警察署の定常業務へ移行した後の体制。

## ⑤番外（明治11年10月29日）巡査交番達の再録〔確認文言・GOV-314への独立裏付け〕

- 「**達 明治十一年十月廿九日 番外 第三方面第四分署 神田玉川(内)上水源取締禁例第五十七號ヲ以テ布達候ニ付テハ其署ニ於テ巡査交番ヲ定メ巡視可爲致萬一水路中汚物等ノ投棄アルヲ見認ムル時ハ最寄水番人ヘ通達シ速ニ掃除方可取計此旨相達候事**」
- **意味〔確認〕**: 巡査交番設定・水番人連絡の番外達（[GOV-314](GOV-314.md)の番外第125号）が**明治11年10月29日付（＝甲第57号布達と同日）**として再録されている。791189（布達全書明治11年坤）の「十月十七日」（文言候補）との対立に対し、[GOV-316](GOV-316.md)（東京警吏要覧・1879）・[GOV-317](GOV-317.md)（警視類聚規則・1879）と本書の計3系統の再録がいずれも10月29日＝**甲57号と同日付を支持**（791189の10月17日は判読候補として維持しつつ、10月29日説が有力になった。原画像照合まで断定しない）。
