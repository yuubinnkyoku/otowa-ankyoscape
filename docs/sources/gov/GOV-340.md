# [GOV-340] 東京市水道事業年報（1936）— 境水衞所の建物の1936年定点〔第147回〕

- **書誌〔確認〕**: 東京市（水道局）編『東京市水道事業年報』（**東京市・1936年**。請求記号14.5-555・書誌ID000000726234。NDL次世代デジタルライブラリー [book/1073685](https://lab.ndl.go.jp/dl/book/1073685)）。水道局の事業・資産・建物を記録した年報で、**建物台帳（構造・坪数・価格の表）に「境水衞所」の行が存在する**。
- **境水衞所の建物台帳〔確認・文言候補・列崩れ〕**: 建物台帳の行——「**境水衞所 木造平板葺平家 水衞所外3棟竝附屬設備 35.000 1,338.300**」＝**境水衞所として「木造平板葺平家（水衞所の本屋）外3棟と附屬設備」・計35坪・1,338円300銭（価格値は候補）が1936年時点で実在した**記録（前後の行は「木造鐵板茸平家 事務所外6棟…143.250 9,370.750」「木造鐵鋼混凝土造二階家 事務所外1棟…329.960 44,096.000」等の水道局建物群。表は列崩れがあり坪数・価格の桁対応は要照合）。〔**①境水衞所が1936年（昭和11年）時点でも水道局の建物資産として実在し、「水衞所外3棟」という規模だった定点記録**＝[GOV-338](GOV-338.md)（1913例規・明治31年水衞心得の境水衞所）から23年後の実在確認で、境水衞所が明治から昭和期まで体制として継続したことの裏付け。**②位置の帰属（旧保谷村の境＝玉川上水沿いか、千川上水沿いの境橋付近か）は本表からは確定できず保留**（1936年時点で千川水道の分水樋鍵保管が継続していたかも本書からは未確認）。**③「境水衞所」の名称の実物の建物（35坪・木造平家4棟）の規模は、水衞所の実態（定員・詰所）を考える上での初めての具体的数値**（文言候補として扱い断定しない）。〕
- **〔2026-11-17・第148回追記〕境浄水所と境水衞所の別施設としての並存〔確認・文言候補〕**: ①建物台帳には境水衞所の行とは別に「**境淨水所 木造瓦葺平家 門衞（門番所の崩れ候補）外26棟及附屬設備 440.676（坪）94,476.160（円）**」の行があり、**境浄水所（440.676坪・9.4万円余・26棟）と境水衞所（35坪・1,338.300円・水衞所外3棟）が規模の全く異なる別施設として並記される**（表は列崩れで数値対応は要照合）。②水衞所群の建物行を見ると、境水衞所の前後に「和田堀…木造平板葺平家 水衞所外3棟竝附屬設備 24.210（坪候補）」・「幡ヶ谷…水衞所外1棟竝附屬設備 18.500（坪候補）」等の**玉川系水衞所群（和田堀・境・幡ヶ谷等）の同型の小規模水衞所行が並び、境水衞所はその中の一行**である。③本年報の所掌規程に「**境淨水所 1.境淨水場,井荻淨水場の維持管理運用に關する事項 1.玉川上水路,羽村村山線,境和田堀線の維持管理に關する事項**」＝**境浄水所の所掌が境浄水場・井荻浄水場の維持管理と玉川上水路・羽村村山線・境和田堀線の維持管理**である文言候補。〔**①境浄水所（浄水場管理拠点）と境水衞所（水路警備の詰所）が別施設であることが1936年時点の建物台帳・所掌規程の両方で確認でき、境水衞所の「境」が境浄水所と同じ境地区（玉川上水沿い）を指す観察を補強する**（比定の確定ではなく文言候補の積み上げ。第146回課題②の位置比定は継続課題）。**「境和田堀線」＝境〜和田堀間の玉川上水路区間の路線名の1936年水道局組織内用例（repo初出候補・文言候補）**で、[GOV-338](GOV-338.md)の境水衞所の受持区域（境〜和田堀内水衞所間等）と対照できる。〕
