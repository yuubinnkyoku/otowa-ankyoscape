# [GOV-017] 『かたりべ』23号「弦巻川――その1・大根を洗う川」

## 書誌・公開状況（2026-10-27、AI が PDF を目視読取で直接確認）

- 豊島区立郷土資料館だより『かたりべ』No.23、1991年9月25日発行、全4ページ。豊島区公式サイトでスキャン画像 PDF（文字情報なし）が公開されている。
- 発行者表記：豊島区立郷土資料館（豊島区西池袋2-37-4）。4ページ目末尾の編集後記欄に「かたりべ No.23」「1991年9月25日 発行」の記載がある。

## 内容メモ

- 2ページ目に連載「古記録にみる豊島のウォーターフロント」の第1回「弦巻川――その1・大根を洗う川」（君塚仁彦）が掲載される。
- 同記事は、『江戸名所図会』（斎藤月岑ら、1834〜1836年刊）の図が現在の弦巻川付近にあたるとし、現在の位置を宝城寺・清立院前の道の交差点付近とする。図では弦巻川が西から東へ流れ、画面中央に下る坂が御嶽坂であること、御嶽坂の下の平坦地に大根の洗い場があり、穫れた大根を洗う二人の農民の姿が描かれること、その大根は江戸府内へ運ばれて売られ雑司が谷村の農民の生活を支えたこと、川の南岸には水田が広がり弦巻川は用水としても利用されていたことを述べる。
- 弦巻川の水源は現在の元池袋公園にある丸池であったと古文献に記されている、とも述べる。
- 1932年（昭和7年）に当時の高田町の事業として進められた暗渠化工事が完成し、弦巻川は地上から姿を消した、と記す。
