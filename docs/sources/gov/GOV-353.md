# [GOV-353] 天明撰要類集 [22] 御褒美之部 — 千川上水堀割御普請の御褒美の帳簿

- **書誌〔確認〕**: 『天明撰要類集』[22] 十上 御褒美之部（天明期の行政事例の分類綴・[GOV-215](GOV-215.md)（同[49]明地之部）と同シリーズの未登録冊）。NDL次世代デジタルライブラリー [book/2572871](https://lab.ndl.go.jp/dl/book/2572871)。**引用文言はすべてOCR由来で要原文照合**。
- **千川上水堀割御普請の御褒美〔確認・repo初出の堀割普請の実施記録〕**: 目録に「**千川上水堀割御普請御用相勤候組与力同心え御褒美被下候旨御書付**」の項目があり、本文（p.112〜120相当）に——「**天明二寅年十二月十五日記写**」「**天明三寅年(＝干支はOCR崩れ・天明3卯年候補・要照合)十一月廿日 水野出羽守殿 順何(＝名字依候補)を以御渡 町奉行え 一金拾両宛 牧野大隅守組与力 山本茂一郎・生田祐九郎 金弐両宛 同安藤源助・下村弥助(源助) 曲淵甲斐守組与力 都筑長右衛門(兵右衛門)・磯貝友兵衛 牧野大隅守組同心内男八人 曲淵甲斐守組同心内男四人 千川上水堀割御普請御用相勤候ニ付被下之**」「**右は水野出羽守殿依御差図申渡候間難有可奉存候 卯十月申渡**」「**卯十一月…千川上水堀割御普請御用相勤候ニ付金弐両宛被下之**」〔**①千川上水の「堀割御普請」（開渠の堀割の本体普請）を町奉行2組（牧野大隅守組・曲淵甲斐守組）の与力6名・同心12名が担当し、金・銀の御褒美が下されたこと、②申渡は天明2寅年12月（記写）と天明3卯年10月・11月、③「水野出羽守殿（老中・水野忠友候補）依御差図」＝上水再興の幕閣側の差図役であること**〕〔**①「堀割御普請」の実施年代（天明2〜3年）は[GOV-352](GOV-352.md)の「天明二寅年千川上水出来仕候間」（通水開始＝天明2年）と整合する初の帳簿側記録で、[GAZ-041](../gazetteers/GAZ-041.md)〜045の安永9年10月27日掛渡仰付から天明6年差止までの間の普請実施期の特定資料。②与力の氏名（山本茂一郎・生田祐九郎・安藤源助・下村弥助・都筑長右衛門・磯貝友兵衛）はrepo初出。③「堀割」＝神田川筋の埋樋（掛渡）と区別される開渠区間の普請と読めるが、区間の所在は本文にない（[GOV-217](GOV-217.md)の駒込側板樋掛渡と対照して解釈は原画像照合まで保留）**。
- **位置づけ〔観察〕**: 千川上水の天明期再興が町奉行組の与力・同心の実務で遂行されたこと、再興の指図が老中（水野出羽守候補）に由来することを、御褒美の授与実務の帳簿で確認できる。牧野大隅守（神田側の掛渡仰付・駒込側の御見分・堀井戸の預置に一貫して関与）と曲淵甲斐守の2町奉行組体制である点も初の datapoint。
