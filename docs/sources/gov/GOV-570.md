- **書誌〔確認: 詳細頁目録・2026-11-24〕**: 資料種別＝**庁内刊行物**・資料ID [000525364](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_07&pkey=000525364)・文書・資料群ID＝その他・**請求番号＝環境Ｂ８６４**・配架340A・書名「**清流の復活 －野火止用水・玉川上水・千川上水－ （パンフレット）**」・**発行年月日＝昭和59年2月～平成5年3月（1984年2月～1993年3月）**・形態＝パンフレット／**4部**・作成組織＝東京都・作成者＝**環境保全局自然保護部**・公開・利用条件＝原本・複写可・検索手段＝[MF],[D]。
- **位置づけ〔観察〕**: ①**発行年の下限が1984年2月**＝[GOV-139](GOV-139.md)の清流復活事業開始年（昭和59年）と同年で、**事業開始と同時期の都の広報資料**である可能性が高い（初版の発行年次の確定は本文未見のため断定しない）。②題名が**野火止用水・玉川上水・千川上水の三用水を併記**＝[GOV-569](GOV-569.md)⑧の1990〜91年送水条件群と同じ三用水体の枠組みで、**清流復活を野火止用水への送水（1973年開始）と一体の施策としていた時期の資料**である可能性。③「4部」＝**複数の年次版・改訂版が同一請求番号に束ねられている**可能性がある（目録では区別されておらず断定しない）。
- **GOV-482との関係〔観察〕**: [GOV-482](GOV-482.md)『千川上水清流の復活』（**1989年3月・8p・30cm・都立中央図書館蔵**）は書名・形態の異なる**別書誌**で、本パンフレット群（1984.2〜1993.3）のどの版に対応するか（あるいは双方が並行して発行されたか）は本文未見のため判断しない。
