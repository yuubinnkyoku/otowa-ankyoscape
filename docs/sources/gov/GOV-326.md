# [GOV-326] 陸軍歴史 巻七（1889）— 幕末反射炉×千川用水の千川堀割900間余・呑水名義引水40余箇所の文言〔repo初出・第139回〕

- **書誌〔確認〕**: 参謀本部編『陸軍歴史 巻七』（明治22年＝1889刊）。NDL次世代デジタルライブラリー [book/988905](https://lab.ndl.go.jp/dl/book/988905) のOCR全文を確認。幕末の軍制・兵制の文書を編纂した参謀本部刊行の編纂史で、幕末期の反射炉・大砲製造関係の文書を引用する。**引用文言はOCR由来（くずし文の活字化）で要原文照合**。
- **反射爐錐臺取建の上申の採録〔確認・repo初出〕**: 目次と本文に「**瀧野川村地内反射爐錐臺取建ノ上申**」・「**瀧野川村地内反射爐御建築之事（反射爐其外速ニ御治定之儀申上候書付・入用增減取調申上候樣可仕候…）**」の項が見える＝**幕末の滝野川村地内への反射炉・錐臺建設の上申文書を『陸軍歴史』が採録**。年代の表記（「子七月」等の干支）はOCRで読み取りにくく、**元治〜慶応期のいずれかは原画像照合まで特定しない**。
- **滝野川村地内決定の経緯と千川堀割900間余〔確認・repo初出の文言〕**: 「**（御膝元近之御塲所（ニ）テ瀧野川村地內之外相應之塲所無之候間）いつをニも同所ニ御決定被下引續千川堀割長九百間餘之處（早〓御普請之積相心得）…**」＝**①反射炉の建設地として滝野川村地内が「御膝元近くで他に適当な場所がない」ことを理由に決定された経緯、②「千川堀割長900間余」という幕末時点の千川用水の堀割（開渠）の延長の文言**（900間余＝約1.6km。どこからどこまでの区間かは本文精読待ちだが、滝野川村地内の反射炉敷地に隣接する堀割の延長と読むのが自然な文脈。文言は要原文照合）。
- **千川水上の呑水名義引水40余箇所の指摘〔確認・repo初出の文言〕**: 「**千川水上ニ至リ而エ百姓持用水呑水等之名義ヲ以テ上水引入候分四拾餘箇所モ有之趣、右者全ク用水呑水之備（〓）ヨモ無之數丈之瀑布（フ）ト取設或ヲ泉水等玩弄いたし候類其外無用ニ屬し候上水引入置候義不少相聞**」＝**千川水上（上流部）で百姓持の用水・呑水などの名義で上水を引入れている分が40余箇所あり、その多くが瀑布の設置や泉水への玩弄など「無用」な引水であるという指摘**＝**幕末期の千川用水の取水実態（名義取水の乱れ・無用引水の蔓延）を内部から批判した文言**で、[GOV-189](GOV-189.md)（幕末の水車争論・「呑水丈ヶ差暮明願済」）・[GOV-144](GOV-144.md)（慶応2年千川用水稼水車書付）の文脈に、**上水側から見た幕末の水利用の乱れの記述**を加える。文言はOCR崩れが多く要原文照合。
- **湯島鑄立塲・關口錐入塲の言及〔確認・repo初出候補〕**: 「**湯島鑄立塲關口錐入塲等御取建以來規則不相立…**」・「**湯島大小砲鑄造塲關口錐入塲之義ニ付見込申上候樣以御書取被仰渡候趣…**」＝**湯島の鋳立場（大小砲鋳造場）と関口の錐入場（砲身に錐を通す工場）が並記される**幕末の官営工場配置の記述（錐入場の立地が関口＝神田上水筋にあることの兵制史料側の言及。[GOV-144](GOV-144.md)の明治3年「関口製造所並ニ滝ノ川反射爐ヲ造兵司ノ管轄トス」と接続する、湯島・関口の機能分担の記録候補。両場の前後関係・移転の有無は本文精読まで断定しない）。
- **「子七月」の年次＝元治元年（1864）の候補が強化〔確認・第140回追記〕**: 本次調査で「子七月」書付の周辺文書群の年次記載を精読した結果、①同巻に「**元治元年甲子三月**」の書付（聖諭による銅鉄器物の砲器鋳換）・「**文久三年癸亥四月發業 元治元年甲子八月成功**」（石堡塔建築委員）の記載があり、②「子七月」書付の禄利勘定系文言にも「**當子年**」・「**去亥七月**」「**文久二戌年**」等の干支が連続して現れる＝**「子」＝甲子＝元治元年（1864年7月候補）が文書群の年次体系として強く支持された**（原画像照合までの確定は留保）。[BLOG-127](../blogs/BLOG-127.md)（慶応元年の滝野川反射炉開削）の前段の計画・上申段階の時系列整理に使用できる。
