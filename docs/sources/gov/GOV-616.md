# [GOV-616] 東京市役所『大塚公園案内』（[192-]）— 大塚公園の谷地形公園化の公式案内

- **書誌〔確認・2026-11-26・TOA詳細頁〕**: [大塚公園案内]（東京市役所／編・[東京]・東京市・[192-]・**1枚**・24cm・件名「公園∥文京区」・資料コード**5002151818**・請求記号**T/32・629/5005/X**・東京都立図書館・パブリックドメイン・**全2コマ**〔詳細頁画像欄確認〕・[TOA詳細頁](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00006131)）＝第346回「大塚」掃引で文言未確認のまま見送っていた冊子の詳細頁書誌を本回取得・source化。
- **位置づけ〔観察・所在のみ〕**: 大塚公園（文京区大塚4-49・**1928年3月31日開園**・15,377m2）は、1926年に東京市が「公債償還基金経済所属地」として取得した**「利用しにくい崖地と窪地」**（4,028坪）を、欧米視察帰りの**井下清・東京市公園課長**が欧米風設計施工で公園化したもの（〔二次確認〕Wikipedia「大塚公園 (文京区)」・井下清「新しい都市公園　大塚公園の設計施工」『庭園と風景』10巻4号1928経由）＝**谷頭・谷壁地形を公園施設で直接的に記録した1920年代の行政側出版物**で、谷端川・水窪川系の谷地形（崖線・窪地）の土地利用史の対照資料候補。地形種別（どの谷の崖線・窪地か）は**図版判読まで断定しない**〔次回: 図上の公園配置と水路の関係確認〕。
- **repo初出文言〔確認・二次〕**: 「公債償還基金経済所属地」・「利用しにくい崖地と窪地」・井下清設計の3点（repo grep 0件＝初出。ただしWikipedia経由の二次文言で、原本『庭園と風景』1928・本案内図の文言は未確認）。

## 制限・未解決
