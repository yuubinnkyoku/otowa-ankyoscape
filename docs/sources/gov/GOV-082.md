# [GOV-082] 文京区議会 視察報告書「千川増強幹線事業」（令和4年度）

- **資料〔確認〕**：文京区議会災害対策調査特別委員会 視察報告書（令和4年7月19日視察・同年11月提出分。区PDF）。視察先は**千川増強幹線の到達立坑がある文京区立窪町東公園（文京区大塚3-32）の工事現場**。説明者は東京都下水道局第一基幹施設再構築事務所（工事第二課長・設計課長）。
- **千川増強幹線の工種〔確認：報告書本文〕**：[GOV-036](GOV-036.md)（2024年豊島区資料）では触れられなかった**工種・規模の詳細**を記す。
  - **平成25年（2013年）8月21日の1時間50ミリ超の集中豪雨で文京区千石・豊島区南大塚などが床上浸水等の甚大な被害**を受け、同年12月の都「豪雨対策下水道緊急プラン」で、特に被害の大きかった**都内4地区が「75ミリ対策地区」に選定**され、その1地区が**文京区千石から豊島区南大塚の千川幹線流域**〔確認〕。※2013年8月の氷川下・千石周辺の浸水はGOV-031・谷端川.mdで既知だが、**被害地域の公式な列挙（千石・南大塚）と「75ミリ対策地区」選定の経緯はrepo初出**。
  - **平成29年着工。発進立坑＝豊島区立上池袋東公園（上池袋1-30）、泥水式シールド（内径3.75m）で北大塚・南大塚等を経由し、約2.5kmを推進し文京区立窪町東公園へ**。**管路工事は令和4年5月に完了**〔確認〕。
  - **既設幹線との接続部は3か所：豊島区立宮仲公園（上池袋1-30）・北大塚・窪町東公園**〔確認。GOV-036の接続情報と整合〕。
  - **事業費は視察時点で累積約50億円**（国庫補助約1/2）〔確認〕。
  - **堀進中に支障物（礫）が発現し除去作業が発生、想定地盤と土質が異なっていたため施工方法を見直し、約3年の工期遅延**〔確認。**千川＝「礫川」の旧称と、礫質地盤であることの呼応は観察として記録する**（因果を主張しない）〕。
  - **貯水容量は「25mプール約85杯分」**、晴天時に揚水ポンプで既設管へ排水〔確認：質疑応答〕。
- **意義〔観察〕**：千川増強幹線＝旧小石川（谷端川下流）流域の現代的浸水対策の全体像を、行政（都下水道局）説明の記録レベルで確認できた。**現代の下水幹線を旧谷端川の自然河道と同一視しない**（GOV-036と同様の注意）。
- **未解決**：貯水容量の実数値（m³）、令和4年5月以降の接続・運転の完了年月（GOV-036の北大塚接続2025年8月予定との整合）、氷川下町会感謝状の提出日。
