# [GOV-234] 明和撰要集 上水之部 — 18世紀の白堀通の流水・渡橋・検使の記録群

- **書誌〔確認〕**: 『明和撰要集』（幕政例集）上水之部の[65]三十一上 [book/2549801](https://lab.ndl.go.jp/dl/book/2549801)・[66]三十一下 [book/2549802](https://lab.ndl.go.jp/dl/book/2549802)。両冊のOCR全文を精読。**引用文言はすべてOCR由来で要原文照合。**
- **明和6年の流死倒者検使一件〔確認・repo初出〕**: **明和6年（1769）の「白堀通并御茶ノ水懸樋」での流死倒者の検使一件**——久松筑前守・大岡主水正・牧野大隅守の名が見える〔**千川上水の明和6年再興願（[GOV-224](GOV-224.md)明和六丑年二月の御訴訟）と同年・同役人（牧野大隅守）で、神田上水側の検使事件**。白堀通と御茶ノ水の懸樋（神田上水の御茶ノ水横断樋）に流水があり流死者が出たことの検使＝**明和6年に白堀通・御茶ノ水樋に実水が流れていた**ことの傍証。**2026-11-18第164回追記**: [GOV-384](GOV-384.md)（類集撰要巻之十八「上水一件」）に**明和6丑年11月9日の同時期の上水行政文言**——「**大川(玉川?OCR)神田両両上水普請修復等之儀伺之上万事御普請方役所に而取計**」＋「**武門上水役并請負人大鋸町石主蔵兵衛弥左衛門…神田上の見廻り役永富町源六諏訪町作兵衛此度役筋請負共相ト一候事**」——が確認された＝明和6年の検使一件（本冊）と同年・同年月（11月）の両上水一元化・請負停止の行政再編が、別冊の町方例集レベルで裏付けられた（年月日・人名の細部は[GOV-378](GOV-378.md)の明和6年11月8日文言と対校して要照合）〕。
- **三水道町の「古来持場」文言〔確認・repo初出〕**: **金杉水道町・小日向水道町・関口水道町**が**白堀通を「古来持場」とする**文言＝三水道町が白堀通（神田上水堀）の維持・持場を古来担ってきた旨の記録〔[GAZ-049](../gazetteers/GAZ-049.md)⑬の「浚の儀は小石川金杉町持…小日向水道町持」の負担区分と対応する組織の由來文言候補〕。
- **検使例書〔確認・repo初出〕**: 正徳5年（**松平対馬守屋敷前白堀内の水死**）・享保4年（**小日向日輪寺前**の水死・「**関口中堤入口矢来際長光寺脇白堀内**」の水死・水道橋脇）等の検使例の列挙＝**正徳〜明和の18世紀を通じて白堀内に流水があり水死が繰り返された**ことの記録群〔白堀通が乾堀ではなかったことの傍証。「中堤」「水道橋」の地名も[GAZ-049](../gazetteers/GAZ-049.md)⑬の中堤3ヶ所・水道橋と対校可能〕。
- **服部屋太兵衛の白堀通渡橋六ヶ所請負→七ヶ所化〔確認・repo初出・橋名調査の最重要資料〕**: **服部屋太兵衛が白堀通の渡橋六ヶ所を請負い、新坂下橋を含めて七ヶ所に及んだ**旨の文言＝**白堀通に渡橋6〜7ヶ所が存在し、その1つが「新坂下橋」であった**ことの幕府記録〔①[GOV-232](GOV-232.md)弘化普請の「新坂下高札」と同じ地点の橋、②千川家の橋請負（根津惣門前橋→享保の谷中通り3橋増の6橋化→明和5年2橋減・[GAZ-049](../gazetteers/GAZ-049.md)⑫3）と対比できる**白堀側の橋請負**の存在。**服部屋太兵衛と[GOV-238](GOV-238.md)（享保撰要類集・諸所橋々之部）の延享2年落札者「佐久川町服部屋清右衛門」との関係（同族か別人か）は未確認・断定しない**〕。
- **渡橋渡下水新規組合の石高附リスト〔確認・repo初出〕**: 白堀通の渡橋・渡下水の**新規組合**の**石高附リスト**（安永元年〔1772〕と読める文言）——**久世出雲守・安藤対馬守・大久保長門守**ら武家屋敷の石高割のリスト＝**白堀通の橋と下水（渡下水）の維持を沿川の武家屋敷の石高割で賄う組織**が安永元年に新規に組み直された記録〔[GOV-237](GOV-237.md)明治2年の「水下町々の渡賃銭」による支払いと系譜的につながる負担組織の18世紀の記録候補〕。
- **位置づけ〔観察〕**: 白堀通について、①流水の実在（流死・検使）、②維持の持場（三水道町・武家屋敷の石高割）、③渡橋6〜7ヶ所と新坂下橋、という**18世紀の運用面の全体像を幕府例集で初めて裏付けた**。神田上水の堀割（承応2年説・[GAZ-049](../gazetteers/GAZ-049.md)⑬）から明治2年の大下水化（[GOV-237](GOV-237.md)）までの通史のうち、**明和〜安永期の補強資料**。
