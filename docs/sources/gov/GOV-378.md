# [GOV-378] 撰要永久録（町年寄触書集）— 白堀の行政・受益構造の触書群〔第163回〕

- **書誌〔確認〕**: 『撰要永久録』（司法省法律調査会蔵・日本学術振興会刊）の2冊（NDL [book/1365476](https://lab.ndl.go.jp/dl/book/1365476)・[book/1365477](https://lab.ndl.go.jp/dl/book/1365477)）。**町年寄の触書集**＝幕府から町方への通達の一次記録。**OCRは「〓」等の欠損が多く文言はすべて原画像照合を要する。**
- **享保13年（1728）9月2日の大風雨触書〔確認・一次文言〕**: 「**神田川出水・両国橋新大橋の足代古橋柱流失・山手土山崩れ・「目白山邊崩れ白堀埋り」**」＝享保13年9月2日の大風雨（出水）の被害を列挙する一次触書〔**[BOOK-131](../books/BOOK-131.md)（武江年表経由・第138回登録）の「目白山邊崩れ白堀埋り」文言の一次独立裏付け**＝武江年表が触書を正しく抄録していたことの確認。目白山下の白堀区間への土砂流入の享保13年の一次記録として、[GOV-233](GOV-233.md)の白堀の土砂問題・安政2年地震文言と並ぶ白堀の土砂被害の系譜〕。
- **霊岸島町の白堀浚の受益構造〔確認・repo初出〕**: 「50年余り前に**神田上水から玉川上水へ切替えた見返りに白堀浚を請負った**」由緒の記録＋**享保14年（1729）3月の白堀浚免除の交渉**（白堀御普請金＝小間1間に付1匁1分5厘5毛・武家方を除き町方のみ）＋**享保14年9月29日の白堀浚請負の交代**（六左衛門取上→大鋸町茂兵衛・賃銀五厘引・南方小間1間に付2分5厘）＝**霊岸島町が神田上水→玉川上水の切替の見返りとして白堀浚（=神田上水の白堀区間の維持）を請負っていた**受益構造の一次記録〔**白堀の維持負担の特例（霊岸島＝下流受益町の負担）**＝[GAZ-049](../gazetteers/GAZ-049.md)⑥の白堀の浚の町方負担区分（金杉町持・小日向水道町持）と並ぶ、白堀浚の負担構造の多層記録。霊岸島の切替の時期（50年余り前＝元禄頃の候補）は要照合〕。
- **寛延2巳年の通達＝白堀区間の石垣木樋の組合普請への移行〔確認・repo初出・核心〕**: 「**神田上水大洗堰〜三河町一丁目河岸の石垣木樋が從古來公儀御入用から御組合普請に移行**」（小間2間に付高100石積割合）＝**大洗堰〜三河町一丁目河岸区間（=江戸川沿いの上水樋管・石垣）の維持が、それまでの公儀（幕府）負担から町方組合の石高積に移行した**という寛延2年（1749）の転換点〔**白堀区間維持制度の転換**＝享保14年の霊岸島特例・[GAZ-049](../gazetteers/GAZ-049.md)⑥の浚負担区分・[GOV-234](GOV-234.md)の明和6年組合化とつらなる制度史の一次記録。寛延2年8月出水（[BOOK-130](../books/BOOK-130.md)）と同年の制度変更であることに注意（因果は断定しない）。**2026-11-18第164回追記**: [GOV-384](GOV-384.md)（類集撰要巻之十八「上水一件」）に**同一内容の月日・申渡人つき文言**——「**神田上水大院□より三河町壱丁目川岸迄石垣幷木樋等従古来公儀御入用を以御修復有之候得共当七月晦日已来惣門之通御組合普請被成候間…町方は小百弐間に付高百石之積り割合出銀有之**」（**寛延2巳11月5日**・能勢肥前守様申渡・庄三郎殿経由）——が確認され、**本録の文言の独立裏付けが成立**した。負担割合（小間2間に付高100石積）は両本で一致（字形は要照合）。「大院□」は大洗堰のOCR候補で、起点の読みは本録の「大洗堰〜三河町一丁目河岸」と対校して要照合〕。
- **明和6年（1769）11月8日の上水行政再編〔確認〕**: 「**玉川上水水役請負大鋸町茂兵衛・神田上水水見廻役永富町源六・諏訪町作兵衛の請負停止、両上水修復の御普請方役所一元管理**」＝両上水の水役の請負を停止し御普請方役所に一元化した文言〔[GOV-234](GOV-234.md)の明和6年組合化（第112回）の背景側＝上水行政の再編の触書レベルの裏付け。明和5年9月16日の上水方道方の御普請奉行懸の文言も同冊〕。

## 制限・未解決

- ①OCRの「〓」欠損が多く、特に数値（1匁1分5厘5毛・2分5厘・高100石積）と人名・年次の対は原画像照合が必須。②霊岸島の白堀浚請負の起源（「50年余り前」の切替の年次＝元禄期の候補）は本録からは確定できない。③寛延2年通達の「三河町一丁目」の位置（江戸川沿いの上水区間の下流端の候補）は要照合（第164回のGOV-384対校で「大院□〔大洗堰のOCR候補〕より三河町壱丁目川岸迄」の同区間文言が独立に確認され、「当七月晦日已来」の移行時点の文言も加わった）。④1365477冊の残りの触書の網羅的精読は未了。⑤明和6年11月8日の文言はGOV-384（類集撰要巻之十八）の明和6丑11月9日文言（「大川神田両両上水普請修復等之儀伺之上万事御普請方役所に而取計」・大鋸町石主蔵兵衛弥左衛門・永富町源六・諏訪町作兵衛の請負相止）と実質同内容で、年月日（8日/9日）・人名の細部は両本照合を要する。
