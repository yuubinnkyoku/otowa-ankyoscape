# [GOV-150] 紙の博物館「水利権関係書類」— 千川用水をめぐる明治期の約定証書群〔repo初出・第91回次回課題③の達成〕

- **書誌〔確認: 紙の博物館収蔵品データベース（jmapps）・2026-11-15〕**: 「**水利権関係書類**」（収蔵ID:945・[詳細レコード](https://jmapps.ne.jp/kamihaku/det.html?data_id=945)）。資料種類**文書**、作者**抄紙会社・製紙会社**、年代**明治7〜26年（1874-1893）**、寸法285×205mm、**124点の画像がデータベース上で公開**（「ビューアでみる」「PDFで表示」機能つき・文化庁Innovate MUSEUM事業によるデジタルアーカイブ）〔「千川」のキーワード検索で当レコードが単独ヒットした〕。
- **内容〔確認: 収蔵DBの解説欄〕**: 外題「水利権関係書類」。内題「**第五一号 王子 用水路ニ関スル書類**」。解説に挙げられた構成は:
  - **明治7年（1874）9月3日付 約定証書（抄紙会社・王子村外23ヶ村）**〔確認: 解説〕
  - **明治8年（1875）3月10日付「千川用水之儀ニ付 糸器械所鹿嶋萬平ト抄紙会社支配人谷敬三ト取結ヒタル約定証書」**〔確認: 解説〕
  - **明治23年（1890） 石神井川水利組合条例・石神井川用水図面**、ほか〔確認: 解説〕
- **第1の意義〔観察〕**: **鹿島万平（鹿嶋萬平）の「糸器械所」（＝鹿島紡績所）と抄紙会社の間で、千川用水をめぐる約定証書が明治8年3月10日に取り交わされた**ことを示す一次文書が紙の博物館に現存する〔**[BLOG-229](../blogs/BLOG-229.md)の「鹿島紡績所の動力＝王子分水の水車」（二次記述）について、当事者間の約定証書という一次文書の所在が固定された**。明治7年9月3日の抄紙会社×村々約定から約半年後の証書で、**鹿島紡績所（滝野川）と抄紙会社（王子）が同じ千川用水系の水を分け合う関係にあった**ことを文書レベルで裏付ける。取水量・取水地点の具体は画像判読まで確認できない〕。
- **第2の意義〔観察〕**: 明治7年9月3日の**抄紙会社×王子村外23ヶ村の約定証書**は、[BLOG-229](../blogs/BLOG-229.md)が引用する『王子製紙社史』（[BOOK-105](../books/BOOK-105.md)）の「会社の利用にまかされた水は…千川上水を巣鴨から分流して来たもの」の記述の**実務的基盤（会社と沿川村々の水利権調整）を示す一次文書**。村側の主体「王子村外23ヶ村」は、千川用水の流末・王子分水沿いの村々の利害共同体を示唆する〔村名の特定は画像判読まで行わない〕。
- **第3の意義〔観察〕**: 明治23年の**石神井川水利組合条例・石神井川用水図面**を同一文書群が含む〔千川用水（王子分水）と石神井川の水利が同一の権利関係の中で管理されていた痕跡。[BLOG-228](../blogs/BLOG-228.md)の北区史引用「分水された千川上水の一部は石神井川に流下」・[BLOG-230](../blogs/BLOG-230.md)の掛桶渡しとの対応が想定されるが、条例・図面の内容は未確認〕。
- **位置づけ〔観察〕**: [BLOG-230](../blogs/BLOG-230.md)の「**水路利用の証書・嘆願書は紙の博物館に保存**」（2021年パネル記述）の**具体的な現物の所在確認**。幕末の反射炉用水（[GOV-144](GOV-144.md)・1864-1870）→明治7-8年の紡績・製紙の工業用水への権利設定（本資料）という水利継承の一次文書列が、同じ北区飛鳥山の博物館群でたどれる。
