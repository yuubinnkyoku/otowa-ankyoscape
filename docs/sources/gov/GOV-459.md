# [GOV-459] 練馬町現状調査 — 上下水道計画ナシの1931年の対照的定点と谷戸地名群

- **書誌〔確認〕**: 『練馬町現状調査』（東京市臨時市域**擴張部**編・[book/1900503](https://lab.ndl.go.jp/dl/book/1900503)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**練馬町（1932年板橋区→練馬区）冊**＝**旧千川上水の北隣（中新井村との境界の相手側・[GOV-456](GOV-456.md)）の中枢町**。
- **上下水道計画ナシの文言〔文言候補・本ファイルの核心〕**: 「**地下水ハ一般飲料ニ好適(ニシテ)…目(下)上水道事業ノ計画ナシ、下水道(ニ)モ(計画ナシ?)**」＝**①地下水が一般の飲料に好適である、②目下（1931年時点）上水道事業の計画がなく、下水道も（計画が）ない**〔**①谷頭・湧水地帯（石神井池・谷戸地形の氾濫原側）の地下水依存の水文化の定点＝上水道の未整備がむしろ自然条件で代替されていた側の記録、②高田町（[GOV-454](GOV-454.md)＝下水道着手）・長崎町（[GOV-455](GOV-455.md)＝石神井系統）・日暮里町（[GOV-457](GOV-457.md)＝府計画の三河島系統）など本シリーズ内で進捗度が明確に分かれていた中で、計画そのものが存在しない側の対照点＝1931年の北多摩・北豊島郊外のインフラ格差の階層の最下層定点**〕。谷端川・千川の直接文言は本冊fulltext走査限りで陰性（陰性記録として掲げる）。
- **谷戸地名群〔文言候補〕**: 小名・字名として**宮ケ谷戸・羽根沢谷戸**等の谷戸系地名の文言候補（OCR崩壊・要照合）＝**武蔵野台地の谷頭（谷戸）地形の小字群の1931年の行政記録例**（谷端川・千川系の谷頭地形の谷戸の命名系統〔谷戸川・谷端川の語彙系＝[GAZ-032](../gazetteers/GAZ-032.md)等〕の地形学側の背景定点）。
- **石神井池・交通〔文言候補〕**: 石神井池（OCR文字列のみ視認・文脈は要照合）・武蔵野鉄道（貫通）・西武鉄道系（OCRで一部視認）の文言候補＝石神井川水系の要の1931年定点（石神井池の文言の確定は要原画像照合）。
- **帳簿文言〔確認〕**: 人口・面積・財政・産業（蔬菜（野菜）栽培関係の文言候補・OCR崩壊大）・教育・社会事業＝1932年市域拡張直前の練馬町の帳簿。
