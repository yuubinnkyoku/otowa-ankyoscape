# [GOV-304] 東京市新市域不良住宅地区調査（1936）— 谷田川の水害・千川工事の地区調書文言候補

- **書誌〔確認〕**: 東京市社会局（市社會事業協會）編『**東京市新市域不良住宅地区調査**』（1936年刊）。NDL次世代デジタルライブラリー [book/1463256](https://lab.ndl.go.jp/dl/book/1463256)。旧東京市域に編入された区域（昭和7年編入5郡82町村）の不良住宅地区の実態調査書。**引用はすべて同館OCRテキスト由来で、地区調書は表組み・分権形式がOCRで高度に崩れており、文言・行対応は原画像照合を要する。**
- **「大正九年頃迄谷田川ノ水害多カリキ」〔文言候補・repo初出級〕**: 地区調書の特記事項と見られる欄に「**大正九年頃迄谷田川ノ水害多カリキ**」という文言が読める＝**大正9年（1920）頃まで谷田川（＝千川の下水道・行政側呼称）の水害が多かった**という地区側の記録候補〔谷田川=千川の水害史（[GOV-297](GOV-297.md)の大正14年豪雨「千川附近」被害指定・[BOOK-147](../books/BOOK-147.md)の谷頭川叙述と対校できる）年次つき文言候補〕。
- **「昭和七年ノ千川ノ工事前ハ洪水ニ床下ニノアリシ地」〔文言候補・repo初出級〕**: 同欄に「**昭和七年ノ千川ノ工事前ハ洪水ニ床下ニノアリシ地ナリシガ**」（前後崩れ「昭和六年ニ傷マサレタル地ナリ」等も読める）＝**昭和7年の「千川の工事」（＝千川改修・放水路工事）の前は洪水で床下浸水があった地**という記録候補＝**「千川の工事」が地区住民・調査側の認識で昭和7年に実施された**ことを示す文言候補〔[GOV-185](GOV-185.md)の改修決定年表（昭和6年8月＝谷田川改修決定）と対校すると決定（昭和6年）→工事（昭和7年）の順で整合。地区側から見た千川工事の呼称が「千川ノ工事」であることも用例として記録に値する〕。
- **位置づけ〔観察・内容メモ〕**: ①この地区の比定（淀橋區・中野區のどの不良住宅地区か）はOCR列崩れのため本冊のみでは未確定（周辺行に「上高田一丁目二〇三」等の地番が読めるが行対応は保留）。②千川・谷田川の水害の地区側（住宅・生活レベル）の記録は、改修事業（[GOV-296](GOV-296.md)〜[GOV-184](GOV-184.md)の行政側記録）の対側の実態資料として希少。③不良住宅地区調査としての趣旨上、水害文言は「不良化の要因」の欄に置かれたと見られる。

## 制限・未解決

- ①地区調書の表形式がOCRで高度に崩壊しており、「谷田川ノ水害」「千川ノ工事」の文言がどの地区（地区番号・区名・町名）の行に帰属するかは原画像照合まで確定しない。②「昭和七年ノ千川ノ工事」の工事の具体的内容（千川放水路・旧川の埋め立て・暗渠化のどれか）は本冊のみでは不明。③「大正九年頃迄」の年次は文言候補。
