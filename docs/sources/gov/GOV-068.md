# [GOV-068] ねりまの川「千川上水の分水を訪ねて（１）」

- **書誌〔確認〕**：[GOV-005](GOV-005.md)（同連載の分水を訪ねて（2））の前回分。2026-11-11時点で当該サイトはopen_url不可のため、[Wayback Machineの2024年11月12日スナップショット](https://web.archive.org/web/20241112125157/https://www.nerima-archives.jp/column/3542/)で本文全文を確認。原記事は昭和62年3月21日号区報（北沢邦彦）。
- **分水の設計思想〔確認〕**：分水の多くは**自然河川の源頭部や湧水池、そこから流れ出た小川につながれ、自然の条件を巧みに利用**していたと説明。〔谷端川への長崎村外三村分水が粟島神社の湧水池（弁天池）につながれた構造（[GOV-005](GOV-005.md)）が系全体の設計思想として裏付けられた〕
- **関村分水〔確認〕**：関町南4-26・保谷市（現西東京市）境を北の**富士見池**方面へ引いた水田用水で、灌漑用水としては最上流。最も古い分水の一つと推定され、**寛政6年（1794年）の文書に「関村田養水」**、**天明4年（1784年）の「関村絵図」**に描写。明治には関村が利用組合から外れ水路も廃滅、現状では痕跡なし。〔天明4年「関村絵図」の存在確認＝repo未収録の絵図情報〕
- **上下石神井村分水〔確認〕**：上石神井1-32、青梅街道を千川上水本流がくぐる位置から北へ分水。江戸時代の**「千川用水堀絵図」に「上下石神井村分水」と表記**（[GOV-038](GOV-038.md)の千川家文書系絵図と同名史料の可能性あり、別物かどうかは未確認）、年次不明の上石神井村絵図に形状が描かれる。明治に両村が利用組合から抜け廃止、現地は宅地化。
- **多摩郡六か村用水〔確認〕**：関町南2-6付近・青梅街道南脇から杉並区域へ、上井草・下井草・上鷺宮・天沼・阿佐ヶ谷・下荻窪の6か村（江戸時代の文書には中村が併記）への分水。先端は**阿佐ヶ谷駅付近**に達し、妙正寺・桃園・善福寺の各川流域の水田を潤した。
- **中村分水〔確認〕**：中村北3-9脇の道路下、区画整理で水路変更後に暗渠、現在は一部が路地状。**寛政6年（1794年）の文書に「中村田養水」**、明治17年頃の「千川上水路図」に「中村用水」。南蔵院南側の水田に利用。
- **写真資料〔確認〕**：昭和27年撮影の「千川上水 関町南2-6付近」（石神井公園ふるさと文化館所蔵）が記事に掲載。
- **制限〔未解決〕**：関村絵図・上石神井村絵図の所在は記事に記載なし。「千川用水堀絵図」と東京都公文書館「千川元上水堀通見分絵図」（[GOV-061](GOV-061.md)）の異同は未確認。
