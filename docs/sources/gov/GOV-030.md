# [GOV-030] 1997年「池袋の森」開園時の豊島区報道写真

- **写真史料の所在〔確認〕**：豊島区デジタル区史「平成ぐらふぃっくす（平成報道写真）」の目録に、**「区内2か所の樹林地を区民の森として整備（池袋の森）」**という写真項目が**1997年4月29日**付で登録されている。同日の「目白の森」は別項目。〔確認：区公式写真目録の標題・日付・資料種別〕
- **整備年代の照合〔確認〕**：同区の公式年表は**1997年4月29日**を「池袋の森」「目白の森」の開園日とし、**1997年4月25日付広報発表**を典拠に挙げる。したがって目録の日付は**開園日と一致**する。ただし、写真の厳密な撮影日が同日かどうかは個別原票を確認する必要がある。
- **比較可能性〔推定〕**：既収録の[GOV-028](GOV-028.md)は現在の園内池を**「井戸水をくみ上げた池」**と説明する。1997年の公的写真は、公園整備直後の**池の有無・池岸・植栽・井戸設備**が写っていれば、現在の池と比較できる候補になる。**実際に池や井戸が写っているかは未確認**。
- **限界〔未解決〕**：写真画像・撮影方向・被写体・公園整備図面は未照合。**開園時の写真があることは、1907～1928年の島田牧場時代に同位置の池があったことや、谷端川支流が存在したことを証明しない**。また1997年は公園開園年であり、井戸の掘削年・池の造成年ではない。
- **利用条件**：目録の「平成報道写真」は**二次利用不可**。画像を複製せず原サイトを案内する。
- **出典**：豊島区デジタル区史「[平成ぐらふぃっくす（平成報道写真）](https://adeac.jp/toshima-history/catalog-list/list0007-03)」（「区内2か所の樹林地を区民の森として整備（池袋の森）」、**1997年4月29日**）／豊島区「[平成9年の区年表](https://adeac.jp/toshima-history/timeline/tm000001_1?key=%E5%B9%B3%E6%88%909%E5%B9%B4)」（**1997年4月25日付発表・同月29日開園**）／[GOV-028](GOV-028.md)。
