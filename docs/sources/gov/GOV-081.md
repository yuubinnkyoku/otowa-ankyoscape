# [GOV-081] 東京都環境局「湧水の保全について」「区別の湧水地点数」

- **資料〔確認〕**：東京都環境局ウェブサイト「湧水の保全について」（記事ID 021-001-20231206-008711）および「東京の湧水の現状 区別の湧水地点数」（記事ID 021-001-20231206-009395）。**都公式ページは直接取得が遮断されたため、Wayback Machine の 2025年スナップショットで本文を確認**した（「区別の湧水地点数」：https://web.archive.org/web/2025id_/https://www.kankyo.metro.tokyo.lg.jp/water/conservation/spring_water/current/district/ 、トップ頁：https://web.archive.org/web/2025id_/https://www.kankyo.metro.tokyo.lg.jp/water/conservation/spring_water/spring_water/ ）。
- **令和5年度調査〔確認〕**：**都内591地点（区部199地点・市町村392地点）の湧水が確認**されている。この数値はPAP-018（1985-86年調査・都内湧出量9.0×10⁴m³/day）以降の湧水現況を示す最新の公的統計として、**湧水減衰仮説の現時点での到達点を与える**。
- **区別の地点数〔確認：表の数値〕**（列は左から 令和5年度／増減／R4／R3／R2／R1／H30／H29／H28 と判読）：
  - **豊島区：0／0／0／0／0／2／2／3／2** — **令和2年度以降、区内の湧水地点数が0と把握されている**。平成28年度には2〜3地点が確認されていたことを踏まえると、**2010年代後半に行政把握上の湧水が消失した**ことを示す。弦巻川・水窪川流域の湧水観察（BLOG-052・BLOG-067・BLOG-100等）はこの統計と並べて読む必要がある〔**統計上0地点＝湧水の不存在の証明ではない**（崖面のしみ出し等は地点として計上されない可能性がある。断定しない）〕。
  - **板橋区：30／0／30／27／32／35／37／37／34**、**北区：13／-1／14／12／13／13／15／14／14**、**文京区：2／0／2／8／8／8／7／7／7**（文京区は令和2年度に8→2地点へ減少）。
  - **練馬区：19／-4／23／42／60／53／63／38／33** — 令和2年度（60）から令和5年度（19）への大幅減。千川上水流域の湧水動向として記録する。
- **湧水マップ〔所在確認〕**：令和5年度調査に基づく「湧水マップ」（全体版PDF 9,821KB）および分割版（「02 区市町村別湧水地点数一覧（PDF：642KB）」「03 湧水の湧出模式図」等）が同頁で公開されている。**各区の個別地点名の確認にはPDF本文（未取得）が必要**。
- **未解決**：豊島区の「0地点」の評価基準（計上対象から除外される湧出形態の有無）、区市町村別地点数一覧PDFの本文、令和5年度調査の調査方法（区市町村アンケートと思われるが原典未確認）。
- **注意**：湧水地点数は「区市町村の協力のもとに実施した調査の結果」であり「調査時期や調査時の天候などで、地点数が変化することがある」（都ページの注記）。**地点数の増減を直ちに湧水の消長と断定しない**。
