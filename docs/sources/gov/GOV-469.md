# [GOV-469] 御書附留帳 19・20 — 戸樋枡切組小屋場の用地引渡の原帳簿

- **戸樋枡切組小屋場の用地文言〔文言候補・本登録の核心〕**: 第20冊（天明2-3）: 「**千川上水戸樋枡切組小屋場地面 御断返之儀申上候書付 御普請奉行 御材木石奉行江御断 牧野大隅守 筋違橋御門外明地 柳原土手下御石置場 但和泉橋東之方二而長六拾間 右は千川上水戸樋枡切組小屋場地面 先達而請取申候処 右戸樋枡段々出来（後略）**」＋「**寅七月朔日 主殿頭殿 寅七月朔日 青山但馬守承之**」＝**①千川上水の戸樋・枡を切り組む小屋場の地面として、筋違橋御門外明地・柳原土手下御石置場のうち和泉橋東寄り長60間を先達て請取っていたものが、②戸樋枡が段々出来した（進捗した）ことに伴い御普請奉行・御材木石奉行へ御断（返納）した書付、③天明2寅年7月1日・青山但馬守承之**。〔**上流から江戸市中へ樋管を搬入した再興期の作業用地の実務文言。GOV-282（書上帳3冊）の小屋場の筋違橋御門外→柳原土手下→佐久間町裏通への引直しの系列の、安永〜天明再興期の原段階にあたる記録**〕。
- **子年の条の樋掛渡文言〔文言候補〕**: 第19冊（安永9子年）に「**千川上水町々樋掛ケ渡候（後略OCR崩れ）**」の文言あり（前後欠・詳細は原文照合課題）。
