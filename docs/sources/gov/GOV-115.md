# [GOV-115] 豊島区「イラスト地図 千川 : わが街・としまひすとりぃ」〔repo初出〕

- **書誌〔確認: NDLサーチ書誌〕**: 「**イラスト地図 千川 : わが街・としまひすとりぃ**」・責任表示**豊島区**・**2023年3月1日**〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I349807)〕。
- **内容〔確認: NDL書誌のタイトル・日付のみ／本文未見〕**: 豊島区の「わが街・としまひすとりぃ」シリーズ（町名史の基本情報・[GOV-096](GOV-096.md)・[GOV-035](GOV-035.md)・[GAZ-015](../gazetteers/GAZ-015.md)と同系列）の**千川地区（旧千川村・千川町域）版のイラスト地図**。**千川地区単独でのイラスト地図資料の存在がrepo初出**。
- **位置づけ〔観察〕**: 千川上水の名称由来（千川村〔[GOV-090](GOV-090.md)・[BLOG-170](../blogs/BLOG-170.md)参照〕）と旧流路・土地利用を町名史・区資料レベルで扱っている可能性がある。ただし**千川上水の流路・暗渠の記述を含むかは本文未確認で断定しない**。
- **制限・未解決**: 本文・図版未確認（豊島区デジタルアーカイブ〔ADEAC〕のビューア経由とみられる）。千川地区版と既収録の雑司が谷・池袋本町版（[GOV-096](GOV-096.md)・[GOV-035](GOV-035.md)）との内容の重複・差分は未調査。
- **第238回追記・親書誌mp101100の同定〔確認: ADEAC目録＋NDL書誌〔[I349807と書誌検索で同一化〕〕**: 本資料の親書誌＝資料群は、ADEAC豊島区デジタルアーカイブの**「わが街・としまひすとりぃ」（雑司が谷・池袋本町・千川など地区まちむら史シリーズのグラビ資料群mp101100・「平成ぐらふぃっくす（写真）」資料群・**豊島区政策経営部広報課区史編さん担当／監修・発行・令和5年3月・89ページ**・所蔵豊島区・ADEACでCC BY）と同定した〔**目録ページ・作成者・発行年月・ページ数の直接確認**〕。この同定の過程で、**gp081050「谷端川緑道　タイルアート」**（同mp101100の子レコード・**写真・令和3年7月**〔NDL [R100000094-I350002](https://ndlsearch.ndl.go.jp/books/R100000094-I350002)・ADEAC目録 [mp101100-gp081050](https://adeac.jp/toshima-history/catalog/mp101100-gp081050)・資料の分類「――わが街・としまひすとりぃ巻頭グラビア（生き物）」・viewer [mp101100-gp081050](https://adeac.jp/toshima-history/viewer/mp101100-gp081050/mp101100-gp081050)・CC BY 4.0〕）を、第237回で取得不能だったこの1点についてADEAC目録・NDL書誌の双方で実測確認した〔**「タイルアート」の文言はrepo全体で初出**〕。**ただし実画像（721×1080px）は取得できたものの、意匠の内容・設置区間（谷端川緑道のどこにどのようなタイルアートがあるか）・設置主体・設置年度は本レコードの書誌ではまったく特定できていない**〔観察: 書誌のみで未確認〕。「谷端川緑道」のグラビとして2021年7月時点の区側の記録であることを位置づけに留め、**画像内容の判読は今後の課題**とする。
