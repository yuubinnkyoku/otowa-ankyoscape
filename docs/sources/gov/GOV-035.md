# [GOV-035] 豊島区「わが街ひすとりぃ」池袋本町：井戸の所在地

- **資料〔確認〕**：豊島区デジタル区史「わが街ひすとりぃ」基本情報「池袋本町（一丁目～四丁目）」（**平成30年〔2018年〕1月現在**と記す資料、**p.2**）。資料自体の厳密な公開日は未確認。出典：[原文PDF](https://adeac.jp/viewitem/toshima-history/viewer/viewer/content01_v9info/data/content01_v9info.pdf)。
- **井戸〔確認：区資料の施設一覧〕**：一覧に**「池袋本町小学校井戸（旧文成小学校）」**を掲載し、所在地を**池袋本町四丁目36番1号**と記す。同じ一覧には**「旧豊島区立文成小学校」**も同番地で載る。
- **比較地点〔確認：同じ一覧〕**：**「谷端川北緑道」**は**池袋本町三丁目33番7号**と記載される。これらは**別の所在地**であり、井戸が旧谷端川の河道上にあることを示すものではない。
- **解釈上の留保〔未解決〕**：この資料から井戸の**掘削年、深さ、取水層、湧水との関係、2018年以降の現役性**は分からない。旧文成小学校の井戸を自然湧水、谷端川の水源、古い水路の取水口と同一視しない。旧河道・谷底低地との位置関係は地籍図・標高図との照合が必要。
