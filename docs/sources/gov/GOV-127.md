# [GOV-127] 豊島区広報課「花のお江戸は池袋に候 地元ブランド清酒『やばた川』発売」（1998年9月11日）

- **書誌〔確認: PDF本文抽出〕**: 豊島区広報課の〈街の話題〉プレスリリース。**1998（平成10）年9月11日**付。ADEAC「としまひすとりぃ」の豊島区公式記録（目録ID **mp404739**）。原文PDF（[pressH100911](https://adeac.jp/viewitem/toshima-history/viewer/viewer/pressH100911/data/pressH100911.pdf)）、[ADEAC目録ページ](https://adeac.jp/toshima-history/catalog/mp404739)。第83回（2026年11月14日）にPDFからの本文抽出で主要文言を直接確認した。**本資料は第130回（2026年8月30日）に旧READMEの出典[S247]として記録済みだったが、2026年秋のREADME本文分割時に現行README・docs/sourcesいずれにも反映されず脱落していたことを第83回に検出し、本ファイル（GOV-127）として復元した**。
- **谷端川の公式記述〔確認: 本文抽出〕**: 「谷端川は、**要町粟島神社の自然湧水池を水源とし、かつての長崎村、滝野川村、巣鴨村を経て小石川村へと**、現在の豊島区から文京区を流れ**神田川に合流していた延長11kmに及ぶ河川**であり、**豊島区内を最も長く流れて**（いた）」。また「現在は暗渠化され、その上に公園緑地遊歩道が作られている」。〔第130回の旧記録〔S247〕では、この川名紹介の後に「**江戸時代には千川上水から分水を受け、大正時代まで流域の生活用水・灌漑用水として利用された**」の一文も確認されている。第83回の抽出では途中に行の欠落があり、この一文の再抽出には至っていないため、旧記録に依拠して記す〕。
- **「やばた川」の商品名化〔確認: 本文抽出〕**: 暗渠化され公園緑地遊歩道となった谷端川の名を**「やばた川」**として、豊島区酒販連合会が池袋のプライベートブランド清酒の名に採用。**1998年9月12日発売**。ラベルには**池袋御嶽神社氏子16町会の御輿を担ぐ際の祭半纏のマーク**が配され、「やばた川」の書は**同神社宮司の筆**。醸造は新潟県新発田市産「五百万石」を原料米として**妙高酒造に委託**（前年冬仕込の大寒仕込本醸造酒、一升瓶約1万本、1.8リットル1895円・消費税別）。
- **解釈〔観察〕**: ①「延長11km」は、寅さん歩説明板の「全長約11km」や2024年「としまの記憶」映像の総延長11km説明と整合する**1998年公文書レベルの独立の延長データ**。②粟島神社自然湧水池水源説の1998年時点での公式記述であり、由緒板・景観百選・地域資料の系譜に区広報資料として加わる。③「豊島区内を最も長く流れて（いた）」は、谷端川＝区内最長の旧河川という区自身の整理を示す文言（〔抽出欠落のため末尾数文字は補って読んだ。断定表現に用いない〕）。④「やばた川」は、**川が物理的に消えた後も旧河川名が地域共同体の記憶・表象として再利用された具体的時点**を示す、緑道化・橋名表示とは異なる種類の「暗渠化後の記憶」の証拠。
- **注意〔要約の再伝達である点〕**: 本資料の河川史部分は『豊島区史』を要約した二次的整理であり、個々の取水・洗い場・灌漑施設が大正期の何年まで存続したかを示す一次的な水利記録ではない。「谷端川流域の全地点で大正末まで生活用水・灌漑利用が継続した」とは断定しない。弥生時代の集落形成に触れる一文もあるが、考古学的な年代・遺跡範囲は本資料だけで検証できないため採用しない。
