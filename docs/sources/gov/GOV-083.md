# [GOV-083] 板橋区公文書館 電子展示室81号「石神井川の水害と整備」

- **直接確認（2026-11-12、Wayback Machine id_ 付きURLで全文取得。区公式ページの直アクセスは404応答）**。ページ番号1032211・更新日2022年3月30日。こうぶんしょ館電子展示室81号。
- **狩野川台風（昭和33年＝1958年9月・台風22号）の水害**: 板橋区内の浸水家屋**12,800戸**、浸水面積**5平方キロメートル**（区面積約32km²の**約6分の1**）。区道橋11橋流失・6橋損傷。橋梁被害表（『区勢概要 昭和33年度版』1959年3月に一部加筆と注記）: 区道橋＝氷川橋（氷川21→氷川町）・新西原橋・久保田橋・宿橋（→南常盤台1-7・弥生町56）・山崎橋（上板橋町3-6089→東山町4・大谷口北町49）・境橋（長後1-4→不明）が木橋流失、根村橋大破ほか。都道橋＝西堰橋（栄町10）・向屋敷橋・学校橋・山中橋・堰の上橋・台橋など、下頭橋は合成桁で橋脚流失。〔石神井川沿いの橋の被害状況・当時地名と現地名の対応表。山崎橋＝[BLOG-124](../blogs/BLOG-124.md) の1977年洪水写真の橋〕
- **氾濫の継続**: 昭和51年（1976）9月台風17号、昭和53年（1978）4月、昭和54年（1979）5月の集中豪雨でも氾濫。〔[BLOG-124](../blogs/BLOG-124.md) と整合〕
- **整備の年次**: 狩野川台風の翌年の昭和34年（1959）に本格的な護岸工事が開始。板橋区流域では**昭和58年（1983）に1時間50ミリ降雨対応の改修工事が終了**。今後は**1時間75ミリ降雨対応**を目指し、河道拡幅・河床掘削に加え**調整池の設置**を進める。〔谷端川放水路（石神井川放流）・千川増強幹線（[GOV-082](GOV-082.md) の75ミリ対策）と同じ75ミリ目標の石神井川側の受け皿整備として記録〕
- **城北中央公園の石神井川調整池〔repo初出の施設情報〕**: 都立城北中央公園（板橋区桜川一丁目・小茂根五丁目、練馬区氷川台一丁目・羽沢三丁目）の石神井川沿いに設置が決定し、**第一期工事が進行中（2022年3月時点）**。長さ約163メートル・幅約33メートル・深さ約35メートルで、完成後の貯留量は**約9万立方メートル（25メートルプール約300杯分）**。整備テーマは「かつての石神井川と川沿い風景をしのばせる大規模公園」。〔谷端川の放流先である石神井川の洪水調節施設。現在の工区進捗は未確認〕
- 関連: 電子展示室19号「石神井川のはんらん」・25号・46号「石神井川のいま・むかし」など同シリーズの所在（[一覧](https://www.city.itabashi.tokyo.jp/kusei/shiryo/koubunsho/ichiran/1009277.html)）。未取得。
