# [GOV-020] 文京区公式「区立公園一覧」

## 書誌・公開状況

- 文京区土木部みどり公園課、公式「区立公園一覧」（ページID 4696、2026年9月8日更新、2026年10月29日閲覧）。
- 一覧表は所在地・面積・設置年月日・区開園年月日・特色を列挙する。

## 内容メモ

- 礫川公園（春日1-15）：設置1964年8月1日、区開園1965年4月1日。特色欄に噴水・カスケードなど。
- 窪町東公園（大塚3-30）：設置・区開園1953年9月1日。特色欄に「流れ、滝、水車」など。
- 教育の森公園（大塚3-29）：設置・区開園1986年10月13日。特色欄に「半月池、じゃぶじゃぶ池」など。
- 一覧にある池・滝・流れは公園施設として記載されたものであり、その水源、施設の個別施工年、旧河川・旧池・自然湧水との関係はこの表では分からない。
