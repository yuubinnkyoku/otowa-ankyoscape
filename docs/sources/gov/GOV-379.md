# [GOV-379] 触留 第12冊（卯年）— 大洗堰袖石垣と水道橋の修復の触書〔第163回〕

- **書誌〔確認〕**: 『触留』第12冊（NDL [book/2588755](https://lab.ndl.go.jp/dl/book/2588755)）。**書誌は年次不記載の写本**。本文の干支は**卯年**（7月〜12月の触）。**同冊の水道橋の橋台石垣築直・橋御修復（7月着手・9月往来再開・10月相済）は[BOOK-129](../books/BOOK-129.md)（東京市史稿）の「延享4年（1747）水道橋修理（御入用金69両・渡り14間半・橋幅4間・袖間7尺8寸）」と内容・時期が対応するため、卯年＝**延享4丁卯（1747）の候補**とする（紀年文言は本冊になく、年次は断定しない・要照合）。増上寺文昭院様御霊屋の修復の触（同時進行）を含む。**引用文言はすべてOCR由来で要原文照合。**
- **大洗堰道之類袖石垣の修復出来〔確認・repo初出〕**: 卯年8月2日の触に「**神田上水大洗堰道之類袖石垣御修復出来に付猶三日ゟ馬駕籠相通候段**」＝**大洗堰の道之類（そで）の石垣の修復が完成し、馬駕籠（荷駄運搬）の通行が3日後に再開された**という触書〔**大洗堰の袖石垣の修復イベント**の実務側記録。「道之類」の原字形（道の類・舟之類の可能性）は要照合。[GOV-380](GOV-380.md)の安政3〜4年の大洗堰左右袖石垣修復と同じ「袖石垣」の部位名で、18世紀中葉から幕末まで袖石垣が修復の焦点であることを示唆〕。
- **水道橋の橋台石垣築直と橋御修復〔確認・repo初出の実務側文言〕**: 7月14日の触「**水道橋橋台石垣築直幷橋御修復に付同所え湯小屋取建・煙立**」＋9月2日「**水道橋御修復出来ニ付今日ゟ往来有之**」＋10月「御用相済小屋場取払」＝**水道橋の橋台石垣の築直と橋本体の修復の全工程（湯小屋建設→往来止→往来再開→小屋場取払）**の触書〔[BOOK-129](../books/BOOK-129.md)の延享4年水道橋修理（69両・渡り14間半）の**実務側（往来規制・湯小屋の運用）の対応候補**〕。
- **水冠樋の新堀普請〔確認・repo初出候補〕**: 9月12日の触「**神田上水水冠樋新堀御普請ニ付神田様御門下江仮遊懸渡候間以後十四日ゟ屋船差留**」＝**水冠樋の新堀普請に伴い「神田様御門下」へ仮の遊懸渡（仮橋・遊んだ渡し）を掛け、屋船（屋形船）を留めた**記録〔「水冠樋」の名称（OCR候補・原字形要照合）と神田上水の樋の新堀の実務。「神田様御門下」の位置も要照合〕。
- **四谷側の上水施設の文言群〔確認・文言候補〕**: ①8月27日の触「**四谷大木戸水番屋構内堀通石垣其外御普請に付大木戸際ゟ29日ゟ5日間往来差留**」＝四谷大木戸の水番屋構内の堀通石垣の普請と往来規制、②11月の触「**尾張町ゟ出雲町迄上水樋押修復に付尾張町四丁目境…**」＝**四谷の尾張町〜出�町間の上水樋の修復**＝玉川上水の四谷区間（尾張町・出雲町は四谷の町名）の樋修復の触〔[GOV-380](GOV-380.md)の四谷万年樋文言・[GAZ-082](../gazetteers/GAZ-082.md)系の四谷上水文言と対校できる玉川上水側の記録〕。

## 制限・未解決

- ①**年次は推定**（卯年＝延享4丁卯候補）。書誌に年次がなく、BOOK-129の延享4年水道橋修理との対応による推定であることを断定しない（享保20乙卯等の可能性も残す）。②「道之類」「水冠樋」「仮遊懸渡」の原字形は要照合。③大洗堰袖石垣修復と水道橋修理が同一事業か独立かは本冊からは断定できない。
