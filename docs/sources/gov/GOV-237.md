# [GOV-237] 神田玉川上水留（明治2年）— 神田上水廃止（大下水化）直前の白堀通の実態

- **書誌〔確認〕**: 『神田玉川上水留』（明治2年〔1869〕・東京府系の上水留帳）の**分冊ノ二** [book/2587540](https://lab.ndl.go.jp/dl/book/2587540)・**分冊ノ四** [book/2587348](https://lab.ndl.go.jp/dl/book/2587348)。両冊のOCR全文を精読（4月と9月の記録）。**引用文言はすべてOCR由来で要原文照合。**
- **明治2年4月の記録〔確認・repo初出〕**: ①**小石川諏訪町の下水吐の押埋**②**金杉橋脇の浚詰**＝白堀通の下流側（小石川側）の下水吐と金杉橋（[GOV-236](GOV-236.md)の巡視路の終点近くの橋）の維持記録。
- **追記（第119回）・一橋御門外開成所表門脇の神田上水掛樋の出払い〔確認・repo初出〕**: 分冊ノ二の明治2年4月15日付の文言——「**玉川上水築地二之橋脇川内潟樋御普請幷神田上水一橋御門外開成所表門脇同所掛出払樋共…（明）後十七日ゟ取掛申候依之二之橋川筋通船差留候間…**」——＝**玉川上水築地二之橋脇の川内潟樋の普請と併せて、神田上水の一橋御門外・開成所表門脇に掛かる（出払＝取り払いの）樋を、4月17日から取り掛かった**（取掛）記録で、同じく二之橋川筋で通船を差し止めた。〔**一橋御門外＝神田上水（白堀）が江戸城外濠を越えて江戸城内へ給水する掛樋地点**。[GOV-265](GOV-265.md)の帳簿名「四谷御門外掛樋高柳見守番人」・[GOV-264](GOV-264.md)の「切支丹組屋敷前の一橋」と同じ一橋外の上水施設の一環で、**明治2年4月にその掛樋の出払い（撤去）が始まった**と読める文言候補。ただし①「掛出払樋」の区切り（「掛・出払樋」＝掛樋の出払いか、「掛出・払樋」か）・②出払いと新規掛替のどちらか・③「開成所」＝一橋御門外の開成所（旧蕃書調所系・現一橋付近）の比定、はOCR崩れ（「吹所之場所御渡復御後十七日」等）のため要原文照合。**神田上水の江戸城内給水の終末期の工程表として、[BOOK-123](../books/BOOK-123.md)（明治2年10月の大下水設計変更）に先行する実務記録**。〕
- **追記（第119回）・桜田太左衛門町外三ヶ町の竹樋8ヶ所の願〔確認・repo初出〕**: 分冊ノ二の明治2年4月20日付の願——連名「**桜田太左衛門町月行事源右衛門 同所久保町清七 同所善右衛門 同平七 幸橋御門外本郷六丁目代地又兵衛**」が「**中浜掛樋枡御代替相成候二付右御樋ゟ私共少々江引取候枝抱出折三ケ所并家主とも銘々井戸江引取候竹樋五ヶ所都合八ケ所之水口先規有形之通別紙以絵図**」と願出、東京府上水屋敷改が「**先規有形之義二付差支無之候間其御場所江も猶申立候様申渡候**」と処理した（4月20日願・同月書類相添申入の返書）。〔**上水末端の町屋給水の具体像**：①「中浜」（OCR「井浜」もあり・地の比定要照合）の掛樋が御代替（付け替え）になることに伴い、②枝3か所＋家主ごとの井戸へ引取る竹樋5か所＝計8か所の水口を「先規有形の通り」願出、③東京府が差支なしと認めた。桜田御門外・幸橋御門外本郷六丁目代地は**玉川上水末端（熊谷樋・幸橋口）方面の町**で、掛樋→枝樋→竹樋→井戸という末端給水の構造が数字つきで現れる点が本資料の価値。ただし①「中浜」の語はOCR崩れ大・②対象が玉川上水か神田上水か（願の宛先が両上水所管の上水屋敷改のため）は本文言では確定できず要照合。〕
- **明治2年9月の記録〔確認・repo初出〕**: 「**金剛寺橋上之方神田上水白堀通堤急破**」に対する**御普請取掛・車差留・制札**の文言＝**金剛寺橋の上方（上流側）で白堀通の堤が急に破損し、幕府→明治政権側が普請を取り掛け、車馬の通行を差し止め、制札を立てた**記録〔**「金剛寺橋」という橋名が白堀通の橋として明治2年の府の記録に現れる**＝[GOV-232](GOV-232.md)弘化普請の「金剛寺坂下石垣」・[GAZ-050](../gazetteers/GAZ-050.md)の「白堀端通金剛寺坂」と同じ金剛寺坂系の地点。「金剛寺」の寺名・橋の位置の確定は要照合〕。
- **白堀埋増による流末差支〔確認・repo初出〕**: **白堀の埋増（埋め上がり）による流末への差支え**→**藻刈并埋浚3日間**・**入用金67両2分**を**水下の町々の渡賃銭で支払う**文言＝**明治2年時点で白堀の浚渫・草刈の費用が下流町々の「渡賃銭」（橋の通行料と読める・要照合）で賄われた**記録〔[GOV-234](GOV-234.md)安永元年の石高割組合と系譜的につながる白堀の維持費負担の明治初頭の姿。**上水としての給水終末期に、通水確保ではなく流末（下水吐）の維持に費用が投じられていた**点が白堀の実態を示す〕。
- **上水屋敷改〔確認・repo初出〕**: **上水屋敷改**が**東京府・民部省土木司**の下で実施された文言＝**神田上水の管理組織が幕府の上水方から東京府・民部省土木司へ移行する組織移行期の記録**。
- **位置づけ〔観察〕**: [BOOK-123](../books/BOOK-123.md)（明治2年10月の大下水設計変更の陳情）と同年の**神田上水廃止（大下水化）直前の白堀の実態を府の一次記録で裏付ける**：①堤の破損と車差留・制札（上水路としての施設の劣化）、②流末維持の渡賃銭負担（下水路化への移行）、③東京府・民部省への管理移行。**白堀通の「上水」から「大下水」への転換の現場の記録**として[GOV-232](GOV-232.md)（弘化）→[GOV-233](GOV-233.md)（文久）→本資料（明治2年）の3点で幕末〜明治初頭の通史がつながる。
