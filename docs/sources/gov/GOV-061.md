# [GOV-061] ねりまの文化財 第60号（千川上水特集号）

- **書誌〔確認〕**：練馬区教育委員会の文化財愛護啓発誌『ねりまの文化財』**第60号（千川上水特集号）、平成16年（2004）3月**。2026-11-11の第3回調査時点では区サイトでリンク切れ・Wayback未収録と確認していたが、**同日中の再試行で公式PDF（dai60.pdf）に直接アクセスでき、冒頭部（約31KB分）を直接確認した**（以降の頁は今回の抽出では未確認）。
- **内容〔確認：冒頭「千川上水現況調査報告」〕**：特集は**平成15年7月〜10月に実施した文化財講座「千川上水・田柄用水の現況を調べてみよう」に参加した区民ボランティアの現況調査報告**を収録する。上流編（新旧取水口〜西武新宿線交差）によれば、
  - **現取水口**：五日市街道と境調布線が交差する境橋交差点の玉川上水右岸、「東京都北多摩南部建設事務所武蔵野工区」（武蔵野市境4-11）敷地内。取水堰は鉄筋コンクリート製で玉川上水に直角に開口。創設当時の取水口の位置は不明。
  - **第一の旧取水口跡（明治4年〜昭和41年まで使用）**：境橋から約500m上流、曙橋から少し遡った小金井堤の左岸。玉川上水に**先端切石積の分水堤**が突き出し、突堤の根元付近に赤錆たゲートの巻揚器が残る。
  - **第二の旧取水口（明治13年・千川水道株式会社が増設、明治40年まで使用）**：第一の旧取水口から徒歩90歩ほど上流の左岸、シュロの茂みの中に遺構が残置。分水堤は埋まりかけ、背後に小さな沈砂池状のものがある。※以上は縦書きOCR混在のため読みにくく、数値・年紀の再照合を要する（「高さ1m30?」「八一九六六」等の読みは確定していない）。
  - 参照基本資料として**『千川上水路図解説』（千川の会編・クオリ発行）**を挙げる（既収録[MAP-061](../maps/MAP-061.md)）、**明治13年取水口は「このほかにもう一つ存在する」との指摘**を同書が行う旨も記す。
- **意義〔観察〕**：**千川上水の3代の取水口（現・第一旧・第二旧）の位置と使用期間（明治4年〜昭和41年・明治13年〜明治40年）を、区教委の公式刊行物が現況写真つきで整理している**点が今回確認できた新情報。旧取水口の使用終了年（昭和41年＝1966）は、[GOV-058](GOV-058.md)の水流途絶（昭和46年）の前史として位置づく。
- **三河川への使い方〔推定〕**：取水口の変遷は上流部の話で、**谷端川への長崎村分水の位置・廃止年代を直接には示さない**。本誌の後半（下流編）に分水関係の記述があるかは今回の抽出範囲では未確認で、確認を次回の課題とする。
- **制限〔未解決〕**：PDFの全体（31KB以降）の内容・図版は未確認。OCRの誤読可能性を含み、**旧取水口の座標・遺構の現況を本記事だけで確定しない**。
