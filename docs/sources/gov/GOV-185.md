# [GOV-185] 東京都市計画概要（1937年）

- **書誌〔確認〕**: 東京府『東京都市計画概要』（1937〔昭和12〕年）・NDL次世代デジタルライブラリー [book/1463269](https://lab.ndl.go.jp/dl/book/1463269)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **河川改修決定年表〔確認・repo初出の市側照合資料〕**: 河川改修の決定年表として**昭和5年8月＝立会川・谷端川・神田上水／昭和6年8月＝呑川・宇田川・谷田川／昭和7年＝蛇崩川・妙正寺川**という並びが確認された。〔[GOV-159](GOV-159.md)（昭和5年7月28日審議→8月8日決定・告示155号）・[GOV-180](GOV-180.md)（告示155号の番号・日付）・[GOV-185]の三河川決定（昭和5年8月）を、**「東京府」側の年表資料で照合**するもの。[GOV-135](GOV-135.md)・[GOV-139](GOV-139.md)等で扱った東京都土木年報（戦後の都側資料）に対して、戦前の府側資料での決定年次の確認になる〕〔文言はOCR要照合〕。
- **「弦巻」の陰性記録〔確認〕**: 本書の全文検索で「弦巻」は**14回ヒットしたが、すべて「弦巻町」の町名としての言及で、「弦巻川」としての言及は1件もなかった**。〔**1937年時点の公式都市計画資料に「弦巻川」という河川名は（少なくとも本書のOCR全文では）現れない**という陰性記録。弦巻川の実在性・命名時期（[BLOG-008](../blogs/BLOG-008.md)・[GOV-021](GOV-021.md)等の河川名の諸説）を検討する上での一次資料側の陰性データとして記録する。ただし陰性の確定には目次・図版の目視確認が必要で、OCR上の陰性は「確認」ではなく「OCR上の陰性」扱いとする〕。
