# [GOV-406] 東京府文献叢書[31] — 書目中の「井頭上水役由緒書」の所在記録〔第167回〕

- **書誌〔確認〕**: 『東京府文献叢書』[31]（写・NDL次世代デジタルライブラリー [book/2577122](https://lab.ndl.go.jp/dl/book/2577122)）。東京府が収集した江戸関連文献の叢書の写しで、本冊は主として叢書の書目（目録）を収める（第六十四冊〜第八十二冊分の書名・著者の一覧）。**引用文言はすべてOCR由来で要原文照合。**
- **書目中の「井頭上水役由緒書」〔確認・核心・repo初出〕**: 「**第七十三冊井頭上水役由緒書牢屋舗年歴永代寺門前書小金井桜植添申上上武州一宮社記觀源為朝遺異紀事本末新見正路内田某石出某無名小林某行智杉田勘助…**」＝**第七十三冊に「井頭上水役由緒書」が含まれる旨の書目記録**〔**①「井頭上水役由緒書」という書名の存在を記録する書目（repo初出）、②第164回で静嘉堂文庫の『井頭上水由緒』（[GOV-384](GOV-384.md)の1877年東京水道改設の由緒系・請求記号特定は未了）を確認したが、本書目の「井頭上水役由緒書」が同一書か別書かは書名・冊構成の差から断定できない、③「井頭上水役」（井頭上水の役所）の由緒書という呼称は、井頭（神田）上水を「役」が管理した体制を示す名称として由緒書系文献の系譜に加える手がかり**。隣接の「牢屋舗年歴」「永代寺門前書」「小金井桜植添申上」等も江戸の施設・植栽の実務文書の書名群〕。
- **位置づけ〔観察〕**: 『東京府文献叢書』は甲集（[GAZ-083](../gazetteers/GAZ-083.md)＝甲集17小石川志料・[GAZ-090](../gazetteers/GAZ-090.md)＝甲集第四冊江戸往古図説）等の体系で知られるが、本冊[31]の書目は叢書全体の目録的性格を持ち、第七十三冊の内容の一次確認には第七十三冊そのものの所在確認（静嘉堂・内閣庫・都立図書館等）が必要。
- **第168回追記〔帝国図書館目録の記録・[GOV-407](GOV-407.md)〕**: 帝国図書館和漢書件名目録 第2編（NDL次世代DL 991349）に「**井頭上水役由緒 內田茂重著 献叢書甲集第七三册**」＝**「井頭上水役由緒」の著者を内田茂重とし、叢書甲集第七三冊への献上系とする目録記録**、帝国図書館和漢図書書名目録 第3編（991348）にも「井頭上水役由緒錄」の書名目録記録があることを確認した〔**①書目文言の直接確認（本冊fulltextの「第七十三冊井頭上水役由緒書牢屋舗年歴永代寺門前書小金井桜植添申上上武州一宮社記觀源為朝遺異紀事本末新見正路内田某石出某無名小林某行智杉田勘助…」＝第六十八〜七十四冊配列の中の位置も確認）、②著者内田茂重（総目の「内田某」に対応候補）・献上系の目録記録＝第七十三冊本体の所在探索の手がかり（帝国図書館系の所蔵履歴）**。詳しくは[GOV-407](GOV-407.md)〕。

## 制限・未解決

- ①「井頭上水役由緒書」と静嘉堂『井頭上水由緒』の異同は未確認（書名の「役」の有無は別書説の一因になりうるが断定しない）。②第七十三冊本体の所在は未特定だが、帝国図書館系の目録記録（[GOV-407](GOV-407.md)・內田茂重著・献上系）が第168回で確認できた（所蔵の実在確認は次回以降）。③書目のOCR崩れ（「觀源為朝遺異紀事本末」等の書名の区切り）は要照合。
