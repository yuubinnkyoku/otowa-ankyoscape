# [GOV-375] 安永撰要類集 六ノ上＋天明撰要類集 第六ノ上 — 天明6年7月の水道橋・大洗堰の修復と駿河台崩壊の先例書〔第163回〕

- **書誌〔確認〕**: ①『安永撰要類集』六ノ上（NDL [book/2549814](https://lab.ndl.go.jp/dl/book/2549814)）、②『天明撰要類集』第六ノ上（NDL [book/2572863](https://lab.ndl.go.jp/dl/book/2572863)）。**両書は同じ部門編成の並行テキストで、天明6年（1786）7月の文言が対校できる**（OCRの崩れの相互補正に有用）。**引用文言はすべてOCR由来で要原文照合。**
- **天明6年7月・水道橋外掛樋南之方の樋請石垣崩れ〔確認・repo初出〕**: 「**水道橋外掛樋南之方樋請石垣崩れ→足代懸ケ修復**」＝**水道橋の外掛樋の南側の樋請（樋受け）石垣が崩れ、足代（足場）を掛けて修復した**（通船への差支なし）という天明6年7月の記録〔水道橋の外掛樋（水道橋で神田川を跨ぐ上水の掛樋）の支持構造「樋請石垣」の修復文言。[GOV-373](GOV-373.md)⑦の水道橋〜昌平橋の文言群・[BOOK-129](../books/BOOK-129.md)の水道橋修理記録に、樋の支持構造のレイヤーを加える〕。
- **天明6年7月・大洗堰石垣の急破〔確認・repo初出〕**: 「**目白下大洗堰石垣急破→御修復中の桟橋懸置・人足入込**」＝**天明6年7月（出水の当月）に大洗堰の石垣が急破し、修復中の桟橋懸置・人足の出入りがあった**記録〔**大洗堰の石垣破損イベントのシリーズ（既存は文政12年〔[BOOK-139](../books/BOOK-139.md)系〕等）に天明6年7月を追加**。天明6年7月出水（[BOOK-130](../books/BOOK-130.md)・[BOOK-157](../books/BOOK-157.md)既出）と同月の大洗堰石垣急破の実務側記録として、出水被害の局所記録を補う。あわせて[GOV-382](GOV-382.md)（市史稿・天明3年7月大洗堰石垣崩れ＋天明4年7月修復・天保2年銚子口普請）とで大洗堰修復年表の中世～近世後期の層が揃いつつある〕。
- **駿河台土手崩落の先例書〔確認・repo初出〕**: 神田川右岸（駿河台側）の法面崩壊の**先例書**＝明和9年（1772）8月22日・安永2年（1773）5月3日の**聖堂西之方**・天明6年7月（**水道橋下之方1ヶ所＋駿河台6ヶ所＋立木20本余**）＝**駿河台の聖堂西〜水道橋下の神田川右岸法面の崩壊が明和9〜天明6の間に繰り返された**という行政側の系列認識〔[GOV-373](GOV-373.md)③の「駿河台方下水落口の上山岸崩入」（寛延3年）を含めれば寛延3〜天明6の約40年で4度以上の右岸崩壊・修復の記録群。駿河台崖線の安定性問題（README §神田川の河岸の検討資料）〕。
- **神田川常浚＋永代橋の請負人の交代リスト〔確認〕**: 宝暦4年（1754）〜天明8年（1788）の**神田川常浚と永代橋の請負人の交代の全リスト**（氏名・町名・病死・断絶・養子相続）＝常浚請負の実務の系譜〔[GOV-374](GOV-374.md)の定尺と対校できる常浚制度の継続記録〕。
- **千駄木・雑司ヶ谷の御鷹餌鳥請負人の一手請負化〔確認・repo初出〕**: 天明7年（1787）4月27日の文言に、**千駄木・雑司ヶ谷の御鷹餌鳥（鷹の餌鳥）の請負人（佐兵衛・又七・伊兵衛等・神田餌鳥屋敷家主伝兵衛）の実名と一手請負化**＝**雑司ヶ谷の御鷹部屋（[BOOK-152](../books/BOOK-152.md)の御鷹部屋文言・[GAZ-049](../gazetteers/GAZ-049.md)系の雑司ヶ谷御鷹部屋記録）の餌鳥調達の実務**の一次記録〔雑司ヶ谷の御鷹部屋の運営実態（江戸郊外の雑司ヶ谷・千駄木で鷹餌を捕獲させた構造）の裏付け〕。
