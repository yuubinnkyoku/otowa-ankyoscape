# [GOV-025] 東京都下水道局『雑司ヶ谷幹線再構築工事事故調査報告書』（2008年9月1日）

## 書誌・確認範囲

- 東京都下水道局・雑司ヶ谷幹線再構築工事事故調査委員会、**2008年9月1日**。
- 国土交通省公開の原報告書PDF：https://www.mlit.go.jp/common/000024056.pdf
- 2026年10月31日、原報告書の工事概要（印刷p.1）、図1～5（印刷pp.2–3）、事故・降雨状況（pp.4–8）を確認。**図面は画像でも確認**した。
- 同年9月12日の東京都議会公営企業委員会で、下水道局がこの報告書を説明：https://www.gikai.metro.tokyo.lg.jp/record/public-enterprise/2008-08.html

## 河川・下水道史に使える内容

- **〔確認：工事概要、印刷p.1〕** 施工場所は**豊島区雑司が谷1・2丁目、文京区目白台2丁目**。工期は**2007年12月3日～2009年1月15日（契約上の工期）**。老朽化した既設雑司ヶ谷幹線の内面を更生する計画で、矩形渠**幅2,000mm×高さ1,460mm、延長598.75m**、既設人孔改造8か所、汚水ます83か所、取付管径150～200mm・延長195.85mを記す。**工期は計画値であり、全工事が当初日程どおり竣工したことの証明ではない**。
- **〔確認：図1～5、印刷pp.2–3〕** 施工区間・管路位置、No.20～No.22人孔間の平面・縦断・断面図が掲載される。No.20～22間の延長は**82.55m**、管底勾配は図上**3.3‰・4.5‰**の区間表示、土被りは図示位置で**1.67m・1.28m**。これらは**2008年の当該工事区間の寸法・位置**であり、1930年代の旧弦巻川の自然河道幅や河床勾配ではない。
- **〔確認：工事の安全管理に用いた計算、印刷p.8〕** 工事区間の最下流側が受け持つ雨水・汚水の面積は**約48ha**とされ、施工計画書の想定では**無降雨時水深約10cm**、**50mm/h降雨時の等流水深約60～90cm**。これは**工事時の計画・計算上の値**で、事故時の実測水深や過去の弦巻川の流域面積を示すものではない。
- **〔確認：2008年8月5日の観測、印刷p.4〕** 工事地点約150mの下水道局豊島出張所雨量計は**11:53からの1時間最大57.5mm、11:50～18:35の総雨量134mm**を記録。東京アメッシュでは作業現場周辺に短時間で**80mm/h超の降雨強度**が現れたと報告する。異なる観測手法・時間幅の数値を混同しない。
- **〔確認：事故報告、印刷pp.4–6〕** **2008年8月5日、雑司が谷2丁目22番地先の再構築工事中に急激な増水事故が発生し、作業員5人が死亡**した。調査報告書は原因と再発防止策を検討している。記録は犠牲者を伴う事故の公的報告として慎重に扱う。

## 解釈上の限界と次の照合

- **〔観察〕** 旧弦巻川の流域に位置する**現代の雑司ヶ谷幹線の具体的な工事区間・断面・縦断勾配・集水条件**を、2008年時点の一次資料で追える。
- **〔推定〕** 1931～1932年頃の弦巻川暗渠化記録と図1～5を位置合わせし、旧河道から下水道への線形変更を検証するための基準資料になる。
- **〔未解決〕** 既設管の当初築造年・全区間の線形変更時期、2008年の更生工事の竣工状態、上流の丸池・弦巻川旧流路との厳密な対応。**2008年の管路を1932年の原暗渠や旧自然河道と同一視しない**。
