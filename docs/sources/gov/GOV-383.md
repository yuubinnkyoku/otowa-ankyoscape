# [GOV-383] 東京府文獻叢書 甲集第一冊（編修地誌備用典籍解題）— 江戸上水書類十巻の解題目録〔第163回〕

- **書誌〔確認〕**: 『東京府文獻叢書 甲集 第一冊 地理』（明治11年〔1878〕1月輯）＝**『編修地誌備用典籍解題』上（松平定常原撰・旧府学問所補）**。NDL次世代デジタルライブラリー [book/2577092](https://lab.ndl.go.jp/dl/book/2577092)。武蔵国の地誌・典籍の解題集。**引用文言はすべてOCR由来で要原文照合。**
- **江戸上水書類十巻の解題目録〔確認・所在情報〕**: 巻次の解題に「**（屋ヨリ江戸内上水掛リ絵図）第六巻 神田上水水元井ノ頭ヨリ目白下附近迄絵図／第七巻 神田上水目白附洲ヨリ江戸内水懸ル絵図／第八巻 玉川庄右衛門清右エ門書付・神田元水役茂十郎書付・青山上水三田上水千川上水魚有上水伝説大概／第九巻 玉川神田上水高札ノ写並流水車改書付／第十巻 上水掛り代々記並両上水御普請箇所同出銀石高取集方並水銀取集ノ儀・白堀浚賃銭取集附・白堀通渡下水橋ノ儀・水番人給金等・水番人廻リ方同心・白堀見廻リノ儀・水料米ノ事・水掛リノ分量・見廻リ払引事…都合十巻**」＝**神田・玉川両上水の行政文書10巻コレクション（絵図・書付・高札・代々記・白堀浚賃銭・白堀通渡下水橋・水番人給金・白堀見廻リ・水料米）の巻別目録**〔**上水行政文書のコレクションの存在と内容を記す書誌情報**＝[GOV-233](GOV-233.md)・[GOV-267](GOV-267.md)等の神田上水留・[GOV-234](GOV-234.md)の白堀見廻り文言が属する文書世界の全体像の一次記録。「白堀通渡下水橋」「白堀浚賃銭取集」等の項目名は白堀研究の未入手文書の手がかり（所在の特定は未了）。六〜十巻の「屋ヨリ江戸内上水掛リ絵図」等の前半巻名はOCR崩れ・要照合〕。
- **江戸上水の定義文言〔確認・文言候補〕**: 「**江戸上水トイエルハ玉川神田ノ二水アリ 水元玉川ヲセキ入ルハ玉川上水ナリ 井ノ頭ノ池水ヲ引クハ神田上水ナリ 先年青山上水…三田上水 千川上水 皆玉川ノ分水ナリ**」＝**江戸上水＝玉川・神田の二水、玉川の堰に入れるのが玉川上水、井の頭の池水を引くのが神田上水、（先年の）青山上水・三田上水・千川上水は皆玉川の分水**という解題側の定義〔**千川上水を玉川の分水とする1878年の府側認識**＝[GAZ-069](../gazetteers/GAZ-069.md)（井頭上水）・[GOV-377](GOV-377.md)（多水源合流説・「玉川ノ派流」）と対校できる、神田上水の水源と千川上水の系統の明治期の書誌家レベルの認識。「魚有上水」は「有馬上水」等のOCR候補・要照合〕。
- **道中記の巻構成の文言〔文言候補〕**: 第十五巻の解題に「**小日向金杦上水端・関口・目白・大洗堰・雑司谷ヲシルシ 小日向江戸川ニ起リ維司谷本立寺ニ終ル**」（金杦＝金杉のOCR候補）＝小日向・関口・目白・大洗堰・雑司ヶ谷を経る道中記の巻の存在〔[GAZ-083](../gazetteers/GAZ-083.md)⑩の江戸安見圖言及と対校しうる坊巡り・道中記系資料の手がかり（書名はOCR崩れ・要照合）〕。
