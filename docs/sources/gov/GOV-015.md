# [GOV-015] 板橋区櫻井徳太郎賞受賞作「人々の暮らしとお多福弁天～谷端川への祈りの変化～」

- 板橋区公式「令和4年度『第21回櫻井徳太郎賞』受賞結果」ページ（応募総数557編、ページ番号1043820、更新日2023年8月15日）で、小・中学生の部 最優秀賞として掲載される作品。作者は板橋区立板橋第四小学校6年 矢﨑瑛。添付ファイル名は「第21回櫻井徳太郎賞受賞作文（小中学生の部）（PDF 2.4MB）」。

- 内容メモ（以下はすべて本作品の記述であり、本調査による検証結果ではない）：
  - 谷端川は、豊島区要町の粟島神社付近の湧水を水源とする神田川の支流の一つである、と記す。
  - 鎌倉・室町時代には、粟島神社の弁天池の自然湧水をかんがい用水として使っていたため、流域にわずかな水田があった、と記す。
  - 江戸時代に入り、玉川上水より分水された千川上水が谷端川に分水されると水量が急激に増え、谷端川付近の長崎、池袋、板橋の中丸、金井久保、巣鴨などの村では、一七〇〇年に水料を納めることでかんがい用水として使えるようになった、と記す。典拠として板橋区教育委員会（1986）『いたばしの河川：その変遷と人々のくらし』を挙げる。
  - 安政の大地震のときに洪水があり、中丸町の一部の農家は高台に移ったことや、その後もしばしば洪水に見舞われた記録が残っている、と記す（典拠は同上）。
  - 谷端川は、一九六四年までに全区間が暗渠化された、と記す。
  - 谷端川と千川上水の位置を示す図1は、菅原健二（2007）『川の地図辞典 江戸・東京／二三区編 三訂版』による。図2〜図5は日本地図センター「東京時層地図」による土地利用の変化である。
  - 聞き取り（年月日・場所を作品末尾に明記）：2022年8月13日 宗仙寺・子易神社、2022年8月15日 粟島神社、2022年8月22日・25日 タカセ板橋店。
  - 宗仙寺での聞き取りとして、下板橋駅の辺りは田んぼで、谷端川が暗渠になる前はよくはんらんして浸水していた、と記す。
  - タカセ板橋店での聞き取りとして、一九五八年九月の狩野川台風のとき、下板橋駅付近にあったたたみ屋さんなどが浸水した、と記す。
  - 粟島神社での聞き取りとして、境内にある弁天池の水は、以前は湧水であったがいまは枯れていてポンプでくみ上げている、と記す。弁天社では、水がよく流れながらも、流れ過ぎてはんらんすることがないように祈っていた、と記す。
  - 下板橋駅付近のお多福弁天のプレート（由来板）として、四百年以上前にここに古い沼があり「お多福弁天沼」と呼ばれた、と記す。
  - 参考文献として挙げるもの：板橋区教育委員会（1986）『いたばしの河川：その変遷と人々のくらし』文化財シリーズ第五二集、板橋区河川調査報告書／佐藤建一郎・田村善次郎（2013）『祈りの民俗誌』／菅原健二（2007）『川の地図辞典 江戸・東京／二三区編 三訂版』／高野進芳（1967）「農耕と弁才天信仰との関係」。
