# [GOV-182] 東京都市計画報告 第4回（1935年）

- **書誌〔確認〕**: 東京府『東京都市計画報告 第4回』（1935〔昭和10〕年）・NDL次世代デジタルライブラリー [book/1448216](https://lab.ndl.go.jp/dl/book/1448216)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **「立会川外二河川改修」の文言の第二ソース〔確認〕**: 本報告は**昭和5年8月13日内務省告示第155号「東京都市計画河川改修及其ノ事業執行年割」**の対象を「立会川外二河川」として記述する。〔[GOV-159](GOV-159.md)（1930年・議事速記録第1号）に続く第二の独立ソースで、[GOV-180](GOV-180.md)（議事速記録第3号）のOCRと一致〕〔文言はOCR要照合〕。
- **延長数値〔確認・要照合〕**: 谷端川**2,953m**（[GOV-160](GOV-160.md)の2,952.671m〔1934年・都市計画報告第2回〕と整合する丸め）、立会川**3,571m**（[GOV-159](GOV-159.md)の3,564mと**微差**。同一資料系内の差として記録のみ行い、どちらが正かは確定しない）。
- **区間文言〔確認・repo初出〕**: 神田上水＝「**自中野橋至旧東京市郡界**」、谷端川＝「**至池袋鉄道山手線下**」。〔**山手線（池袋）下流端の文言は、谷端川改修区間の下流終点が山手線付近であったことを示す記述**として[GOV-160](GOV-160.md)の区間記述と突き合わせる価値がある。ただし「**中野橋**」は[GOV-180](GOV-180.md)・[GOV-159](GOV-159.md)の「**寿橋**」〔神田上水起点橋名〕と**OCRの読みが食い違う**可能性があり、確定は原文照合まで保留する〕〔文言はOCR要照合〕。
