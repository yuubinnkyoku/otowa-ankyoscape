# [GOV-050] 東洋乾板の井戸・鑿泉と雑司が谷の地下水利用

- **書誌・所在〔確認〕**：豊島区立郷土資料館『町工場の履歴書』（**1994年度特別展図録**）所収「良質な水をもとめて―東洋乾板から富士写真フイルムへ」、**印刷pp.55–57**（関連記事はpp.58–59にも続く）。[図録該当頁の公開複製PDF](https://takahashi.tokyo.jp/toshima/1994kyoudo.pdf)を2026年11月3日に確認。豊島区[公式刊行物案内](https://www.city.toshima.lg.jp/129/bunka/bunka/shiryokan/zuroku/1994zuroku.html)によれば特別展「町工場の履歴書」の開催期間は**1994年9月9日～11月20日**。**PDFの公開先は区公式サイトではなく高橋家関係者のサイト**であり、今回は文字抽出で本文を照合したが、原誌面の全画像・細かな数字の再判読は未実施。
- **工業用水・土地選択〔確認：図録の叙述／家族証言は図録による伝聞〕**：高橋慎二郎の長女・和田垣知恵の談話として、各地の井戸水を取り寄せて比較した結果、雑司が谷の水質が最良だったため製造地に選んだと紹介する。乾板製造には良質な水が重要で、**1919年（大正8年）設立の東洋乾板**の工場を**現在の南池袋2丁目40番付近**とする。水質の数値・分析表は掲載されていない。
- **井戸の設備〔確認：図録p.57の文字抽出／数字の原画像再確認が必要〕**：**1927年（昭和2年）の工場増設**に関連して、水不足を防ぐため**深さ26尺（約8m）の給水井戸**と**250尺（約76m）の鑿泉**を掘ったと説明する。**浅井戸と深い掘削を区別**する具体的な設備記録だが、両者の正確な座標・口径・取水層・揚水量・掘削竣工日・残存は未確認。尺数は公開複製の文字抽出によるため、原誌面での再判読を要する。
- **井戸写真〔確認：図録p.57の写真説明〕**：**1994年6月撮影**の「今も残る井戸」の写真を掲載し、研究所時代の乾板製造に使用した井戸を**南池袋2丁目41番3号**と記す。**南池袋2丁目40番の工場とは別の住所**であり、現在の残存・現役性や、1914年創設の研究所（別住所）との施設上の関係は未確定。
- **都市化〔確認：図録筆者の歴史的説明〕**：雑司が谷の宅地化が進むにつれて**井戸の水量が減った**と記す。これは1994年の回顧的記述であり、観測井の水位系列や低下開始年・原因を実測で示したものではない。
- **資料の限界〔未解決〕**：井戸・鑿泉・工場排水施設の配置図、取排水管の接続、弦巻川の旧河道との位置関係は未確認。井戸水の利用は**弦巻川からの直接取水**や**河川への排水**を意味しない。**1927年は増設・掘削に関する叙述の年、1994年は図録・写真の年**で、弦巻川暗渠化年ではない。
