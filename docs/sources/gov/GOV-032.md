# [GOV-032] 旧谷端川の宮下橋跡と、現役の鉄道跨線橋「宮下橋」を混同しない

- **資料〔確認〕**：豊島区『**豊島区公共施設等総合管理計画**』（**2016年3月**）の**p.5「図表9 橋梁（平成27年4月現在）」**は、区管理橋梁の**No.1「宮下橋」**を、交差物件**「鉄道」**、種類**「車道橋」**、橋長**28.70m**、面積**346.43m²**と記載する。**2015年4月時点の管理台帳値**であって、旧河川に架かっていた橋の寸法ではない。
- **名称・位置の区別〔確認／観察〕**：別の2026年現地踏査「ぶらっと遡上探索」Scene-1046（**2026年10月3日**）は、旧谷端川の**西池袋4丁目付近・緑道起点約3.4km**に**「#32宮下橋跡」**を記録し、親柱・欄干を撮影する。一方、当初参照した民間地図では現役の同名橋を**豊島区巣鴨3丁目1番付近**と表示していたが、後に確認した豊島区の2024年度橋梁点検結果では**宮下橋の所在地は巣鴨三丁目25番先～巣鴨一丁目36番先**、**巣鴨三丁目1番先は江戸橋**である。公式所在地の出典は別資料[GOV-033](GOV-033.md)を参照。**河川跡の橋名・現存する鉄道跨線橋の名称を同じ橋の改築履歴とみなしてはならない**。〔旧橋跡の位置・残存物は現地踏査者の記録／民間地図と公式点検結果の位置表示を区別〕
- **1989年の工事史料〔確認：公的目録〕**：豊島区デジタル区史の**1989年6月21日**の年表は、同年6月21日～7月14日の区議会定例会の主な案件に**「宮下橋改築工事等の請負契約」**を挙げ、典拠を『豊島区議会年報（平成元年）』とする。資料検索にも**「宮下橋改築工事（H010712企画総務委員会資料）」**（**1989年7月12日**）の目録がある。**1989年の工事が2015年の鉄道跨線橋に対応するかは契約図面未確認**であり、まして旧谷端川の宮下橋跡の改築工事とは断定できない。
- **研究上の位置づけ〔観察／推定〕**：旧谷端川緑道の橋名を、区管理の道路橋一覧や工事契約一覧で機械的に照合すると、**同名異橋による架橋・改築年代の誤同定**が起こり得る。旧橋跡については**1991年7月15日『広報としま』820号の緑道案内図**と1999年の橋跡調査、現地の銘板・親柱を照合する必要がある。
- **未解決**：現役跨線橋「宮下橋」の架設年・1989年工事との対応、旧谷端川宮下橋跡の架設年・原橋材の残存範囲。**橋長28.70mは旧谷端川の川幅を示さない**。
