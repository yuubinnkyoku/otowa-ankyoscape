# [GOV-426] 明和撰要集第二十七下 — 町年寄の職務語「上水御普請御用」（寛延3〜安永7年）

- **書誌〔確認〕**: 『明和撰要集』第二十七下。NDL次世代デジタルライブラリー [book/2549794](https://lab.ndl.go.jp/dl/book/2549794)。旧幕引継書系の内容（町奉行関係の願書・伺の綴）。fulltext（NDL lab API・ページtxt群）の全頁走査（2026-11-19第201回）。**引用文言はすべてOCR由来で要原文照合。**

## 寛延3年（1746）・安永7年（1778）: 町年寄の職務語「上水御普請御用」〔確認・repo初出〕

- **樽屋家（安永7戌年7月晦日の小札）**: 「町奉行先樽屋藤左衛門儀病身に罷在役儀難相勤御座候間退役仕忰吉五郎事当藤左衛門其節拾歳に罷成幼年に付成長仕候迄之内先藤左衛門弟与左衛衛門沙汰致見仕**町年寄役幷上水御普請御用共に相勤候様**仕度旨寛延三午年八月兄藤左衛門相願候に付其段堀田相模守殿え能勢肥後守山田伊豆守相伺候処伺之通可申付旨被仰渡候」＝**樽屋藤左衛門の病身退役に伴い、忰吉五郎（10歳）の成長まで弟与左衛門が「町年寄役并（幷）上水御普請御用」を共に勤める後見態勢を、寛延3年8月に奉行（堀田相模守・能勢肥後守・山田伊豆守）の伺で申付**けた履歴の文言〔確認〕。
- **喜多村家（安永7戌年8月朔日・橋本喜八郎江達）**: 「勘定町年寄喜戸村彦兵衛病死仕忰内蔵之助其節〔拾二歳候補〕に罷成…田中与頭右衛門儀当午二拾五歳に罷成此もの後見に仕吉五郎成長仕候迄之内役儀為相勤申度旨相願申候吟味仕候処与左衛門儀役儀可相勤者ニ御座候間**町年寄役并上水御普請御用共に相勤候様可申付候哉**奉仕候則願書之写奉入御覧」＝**喜多村彦兵衛（OCR「喜戸村」＝町年寄三家の一つ喜多村家の候補・要照合）病死に伴う忰内蔵之助への相続でも、後見人が「町年寄役并上水御普請御用」を共に勤める体制の申付文言**〔確認〕。
- **意味〔観察・断定しない〕**: 「上水御普請御用」が**町年寄の正規の職務連語として、寛延3年・安永7年の両家の家督文書に一貫して現れる**＝[GOV-423](GOV-423.md)（寛保元年4月17日・上水樋枡世話の町年寄移管）→[GOV-378](GOV-378.md)/[GOV-384](GOV-384.md)/[GOV-425](GOV-425.md)（寛延2年御組合普請化）という神田上水・白堀の町方管理体制の系譜が、**30年以上後の明和・安永期も書式文言として定着していた**ことを示す管理史の座標〔観察：ただしこの文言が出るのは町年寄の職務総覧の一部としてで、神田上水（白堀）個別区間の実務文言ではない。玉川・神田の別、また本冊が「上水」をどの上水に限定した語として使うかは本条だけからは断定しない〕。

## 陰性〔確認〕

- 「千川」「弦巻」「谷端」「水窪」「野方」は本冊fulltextで0件。町年寄三家（樽屋・喜多村・樽屋橋本家候補のOCR表記を含む）以外の上水関係文言なし。

## 制限・未解決

- ①「喜戸村彦兵衛」は喜多村家のOCR崩れ候補（樽屋家対応文言が「町奉行先樽屋」、達し役の「橋本喜八郎」も町年寄三家の樽屋橋本家かは要照合）。②与左衛門の実名（樽屋藤左衛門弟「与左衛衛門」「与左衛門」の表記揺れ）・内蔵之助の年齢（「当午拾二歳候補」の行割れ）は要照合。③「厚」（幷/并）の原字、役職呼称の正確な原表記（「上水御普請御用」の区切り）は原画像照合待ち。④寛延3年6月19日願書（「私父藤左衛門三年以前病死仕跡式相続仕不相替町年寄役被為仰付相勤」）と8月伺の前後関係は要再読み取り。
