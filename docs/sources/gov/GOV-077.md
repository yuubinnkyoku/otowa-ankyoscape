# [GOV-077] 練馬わがまち資料館「千川上水の歴史」

- **書誌〔制限の記録〕**：練馬わがまち資料館コラム「千川上水の歴史」初回（nerima-archives column/3482）。2026-11-11時点で当該サイトは再びメンテナンス中（第19回に本文未取得のままGOV化見送り、第20回にサイト復旧を確認したが、本回は直接open不可）のため、**検索スニペットで確認できた文言のみ**を記録する。
- **流路の現況説明〔確認：スニペット〕**：千川上水は関町南四丁目の南側の武蔵野市内を通って立野町の北側から練馬区内に入り、青梅街道までは**かれ川として残存**、**昭和63年春に玉川上水の水を通す工事**が行われた。以降は暗渠化され、千川上水緑道を経て上石神井1丁目の南へ、上井草駅西側で西武新宿線を北に越え、**補助229号線の拡幅に利用され**富士見台駅から江古田駅まで西武池袋線の南側を通る（通称千川通り・桜並木）〔[GOV-072](GOV-072.md)・[BLOG-090](../blogs/BLOG-090.md)と整合〕。巣鴨までを開渠（素掘り）とし、**それから先を木樋（木管・土中埋設）で江戸までつないだ**という流路構造の説明〔巣鴨以東の伏樋構造の文言の重複確認は本文取得後必要〕。
- **開削の経緯〔確認：スニペット〕**：「設計は水利の第一人者河村瑞賢が行ったともいわれ、施工請負は一般に多摩郡仙川村（現調布市仙川町）出身といわれる徳兵衛（**一説に常陸の出身で、千川家に入夫**）、太兵衛の両名で、**道奉行伊勢平八郎の監督の下**に工事に当たりました。このとき、当初予定されていた幕府費用だけでは間に合わず、**480両余を自前で出資した**と伝えています。こうした功により、後に両名には千川の姓が与えられ、名字帯刀が許されることとなり、また併せて**千川水路取締役を拝命**して、上水の管理を任され、**水使用料徴収の権利を得ました**」〔①道奉行伊勢平八郎・入夫説・取締役拝命・徴収権はrepo初出。②480両余の自前出資は[GOV-004](GOV-004.md)（2026-11-11直接確認）の「総費用1,340両余・幕府支出860両余」の差額480両と一致〔仮説として記録。出典系譜の照合は本文確認後〕。③[BOOK-065](../books/BOOK-065.md)の練馬区史補説は千川家由緒書が仙川村説に触れないと指摘しており、「一般に仙川村出身といわれる」の留保と対応する〕。
- **給水・分水の沿革〔確認：スニペット〕**：将軍お成りの小石川白山御殿・湯島聖堂・上野寛永寺および浅草寺への給水が主目的で、周辺の武家屋敷や町家の飲料水にも利用。**宝永4年（1707）には多摩郡6か村、豊島郡14か村に分水が引かれた**。享保7年（1722）と天明6年（1786）に二度の廃止をみて、水田灌漑に大きな役割を果たしながら幕末を迎え、練馬区域では石神井川や中新井川沿いの水田に恩恵〔「6か村＋14か村」の表記は[GOV-067](GOV-067.md)の20か村・[BLOG-113](../blogs/BLOG-113.md)の宝永4年7か所分水と数の枠が異なる。分水口の数と利用村数の違いと考えられるが、本文取得後に整理する〕。
