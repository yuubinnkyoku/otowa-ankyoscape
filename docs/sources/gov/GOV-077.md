# [GOV-077] 練馬わがまち資料館「千川上水の歴史」

- **書誌〔確認：2026-11-12更新〕**：練馬わがまち資料館コラム「ねりまの川」千川上水連載の初回。2026-11-12時点で当該サイトは引き続きメンテナンス中のため、[Wayback Machineの2024年6月13日スナップショット](https://web.archive.org/web/20240613132740/https://www.nerima-archives.jp/column/3482/)で本文全文を取得・直接確認（第21回までのスニペット確認から格上げ）。記事末尾の「昭和62年1月21日号区報」の記載と、シリーズ末尾の説明（**練馬区専門調査員・北沢邦彦が「ねりま区報」昭和61年4月21日号〜63年7月21日号に執筆した連載＋『みどりと水の練馬』〔平成元年3月・土木部公園緑地課発行〕第3章の加筆**を元にする）から、**原記事＝昭和62年（1987）1月21日号「ねりま区報」・執筆北沢邦彦**と特定〔第21回時点の「原記事の初出媒体・執筆者は未確認」を解消〕。
- **流路の現況説明〔確認：本文〕**：関町南四丁目の南側の武蔵野市内を通って立野町の北側から練馬区内に入り、青梅街道まではかれ川として残存（昭和63年春に玉川上水の水を通す工事・平成元年3月清流復活）。以降は暗渠化され、千川上水緑道を経て上石神井1丁目の南へ、上井草駅西側で西武新宿線を北に越え、補助229号線の拡幅に利用され富士見台駅から江古田駅まで西武池袋線の南側を通る〔[GOV-072](GOV-072.md)・[BLOG-090](../blogs/BLOG-090.md)と整合〕。**巣鴨までを開渠（素掘り）とし、それから先を木樋（木管・土中埋設）で江戸までつないだ**という流路構造の文言を本文で確認〔旧未解決①の重複確認が完了。伏樋構造の記述として[GOV-061](GOV-061)等と整合〕。
- **開発の経緯〔確認：本文〕**：千川上水は元禄9年（1696）に玉川上水を現在の保谷・武蔵野両市境で分水。「設計は水利の第一人者河村瑞賢が行ったともいわれ、施工請負は一般に多摩郡仙川村（現調布市仙川町）出身といわれる徳兵衛（一説に常陸の出身で、千川家に入夫）、太兵衛の両名で、道奉行伊勢平八郎の監督の下」に工事。幕府費用だけで間に合わず**480両余を自前で出資**、両名に千川の姓・名字帯刀・**千川水路取締役拝命・水使用料徴収の権利**〔480両余＝[GOV-004](GOV-004.md)の「総費用1,340両余・幕府支出860両余」の差額と一致（仮説として継続記録）。[BOOK-065](../books/BOOK-065.md)の仙川村説批評とも対応〕。
- **給水・分水の沿革〔確認：本文〕**：小石川白山御殿・湯島聖堂・上野寛永寺・浅草寺への給水が主目的で、周辺の武家屋敷・町家の飲料水にも利用。**宝永4年（1707）に多摩郡6か村・豊島郡14か村に分水が引かれた**。享保7年（1722）と**天明6年（1786）に二度の廃止**をみて、以降は水田灌漑に大きな役割。幕末〜明治には滝野川の反射炉（慶応元年着工・中断）・王子の抄紙会社（明治6年設立＝後の王子製紙）・板橋の火薬製造所（同6年・旧金沢藩敷地内）など工業用水として利用開始〔反射炉・抄紙・火薬製造所の3用途の文言は[BLOG-113](../blogs/BLOG-113.md)（武蔵学園写真展略年表）と一致〕。明治13年に岩崎弥太郎の立案で千川水道会社設立、明治40年（東京市近代水道）まで存続（**同41年4月解散**）。**昭和43年の都営地下鉄工事で六義園への水路が中断**、45年に都水道局が取水を中止、46年に大蔵省が工業用水道に切替〔[BLOG-113](../blogs/BLOG-113.md)（昭和45/46年取水停止）と整合〕。
- **千川家の墓〔確認：本文・図版説明〕**：図版説明として「**写真上：千川家代々の墓（昭和20年代　北町二丁目阿弥陀堂墓地内）**」「写真下：千川上水の流れ（昭和31年　上井草駅付近）」〔①**千川家代々の墓が練馬区北町二丁目の阿弥陀堂墓地内にあることの記録はrepo初出**（[GOV-038](GOV-038)千川家文書・[BOOK-065](../books/BOOK-065.md)千川家由緒書と対応する実在拠点）。②昭和31年上井草駅付近の開渠写真の存在もrepo初出〕。
- **旧未解決の整理〔確認〕**：①巣鴨以東の木樋文言→本文確認済み。②「6か村＋14か村」の表記→本文確認済み（分水村数の表記として[GOV-067](GOV-067.md)の20か村＝6+14と整合する可能性が高いが、分水口の数（7か所）との対応は引き続き断定しない）。③480両の系譜→GOV-004との差額一致のみ記録し、原典（千川家文書等）の直接照合は継続課題。
