# [GOV-073] 所蔵品アーカイブ「千川上水記録フィルム 西東京市新町６丁目付近」

- **書誌〔確認〕**：練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ詳細頁（アーカイブID=10022）。**番号5000-0057-004**、名称「千川上水記録フィルム　西東京市新町６丁目付近」、備考「カラー写真」。2026-11-11に直接確認。
- **内容〔確認：備考文言〕**：千川上水の風景を記録した写真。**「暗渠化が練馬区内で本格化する直前の昭和27(1952)年頃に撮影された」**。玉川上水から取水する付近から巣鴨付近までの、練馬を中心とした千川上水沿いの風景の記録。本コマは「玉川上水から取水する千川上水。向かって左側の流れが千川上水、右側の流れが玉川上水」と説明される**取水点直下流のコマ**。
- **[GOV-070](GOV-070.md)との関係〔確認・推定〕**：同頁（練馬区公式b1604）が説明する「千川上水の記録フィルム」（練馬区教育委員会・1952、60コマ）の個別コマが、ふるさと文化館分室の所蔵品アーカイブに通し番号で公開されていることが確認された。[GOV-071](GOV-071.md)（5000-0057-040・板橋区大谷口付近〔推定〕）と同じ5000-0057シリーズ。**シリーズ全体の目録調査（隣接番号の確認）が次の一手**。
- **暗渠化着手年代問題への含意〔推定〕**：「本格化する直前の昭和27(1952)年頃」という文言は、[GOV-070](GOV-070.md)の「工事の初期段階」・[GOV-072](GOV-072.md)の「昭和25年頃から」・[GOV-056](GOV-056.md)の「昭和27年3月以降」と整合し、**1952年当時は着手後まもない初期段階で、本格化はその後**という像を補強する。個別の着手年断定には使わない。
- **制限〔未解決〕**：画像本体は本頁では確認できず文言依存。所蔵番号の体系（0057シリーズの全コマ数・撮影地点の対応）は未確認。
