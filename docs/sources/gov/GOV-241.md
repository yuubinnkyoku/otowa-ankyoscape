# [GOV-241] 享保撰要類集[60] 十七ノ下（諸所橋々之部）— 寛延2年出水の江戸川筋橋群の流失と寛延3年の指谷町下水橋

- **書誌〔確認〕**: 『享保撰要類集』[60] 十七ノ下 諸所橋々之部（条目五十四〜八十一・延享4年〜宝暦2年）。NDL次世代デジタルライブラリー [book/2572815](https://lab.ndl.go.jp/dl/book/2572815)。[GOV-238](GOV-238.md)（[59] 十七ノ中）の次冊。**引用文言はすべてOCR由来で要原文照合。**
- **寛延2年（1749）8月13日出水による江戸川筋の橋群の流失〔確認・repo初出の個別記録〕**: 同じ出水（[BOOK-126](../books/BOOK-126.md)『江戸洪水記』抄出・[BOOK-129](../books/BOOK-129.md)惇信院殿御實紀の「神田上水掛樋流れ」と同じ出水）で被災した橋の個別の伺・修復・入札記録。
  - **関口橋**: 「当八月十三日出水二而流損候関口橋御修復奉伺候書付」（寛延2年10月29日）＋「当八月十三日出水二付関候(?)橋流橋杭共二川下江四五間流懸り有之候**右橋元之在所江到直し御修復**之搾り材木一式入札申付」（11月29日）＝**関口橋が流失し、橋杭とも川下へ四五間流れ、橋元の在所に架け直して修復**した記録。修復入札関係額と読める「**一金四拾八両弐分**」（行対応は要照合）＋石材木は品渡し・運送土砂利は代金払いの吟味書付・「**関口橋懸(岡?)直御入用材木代金も可被下置**」の伺。
  - **小日向古川橋**: 「当八月十三日出水二而流失仕候**小日向古川橋新規懸直之積入札**申付御入用所々吟味仕候処橋定請負人共方左之通二而下直二御座候 **一金六拾九両**」＝**古川橋が流失し、新規に架け直した入札69両**（[GAZ-049](../gazetteers/GAZ-049.md)⑬の小日向の古川橋〔江戸川＝神田川の橋〕の18世紀の流失・再架記録）。
  - **江戸川大橋**: 「**江戸川大橋流失ニ付町人共願之儀奉伺候書付**」（寛延2年10月晦日）＋「**牛込水道町ゟ十日向水道町江渡江戸川大橋 右橋当八月十三日出水二而流失仕其砌は船渡申付候処其後船渡相止候二付此度牛込水道町町人とも相願候者 右町内之儀は橋向武士方江商等二而渡世仕候処橋無之家業不罷成其上出火等之節は武士方とも大勢難儀に御座候間右橋出来迄**橋台より東之方江六間程寄 幅三尺長六間…之板を懸**」＝**江戸川大橋（牛込水道町⇔小日向水道町＝[GAZ-049](../gazetteers/GAZ-049.md)⑬「江戶川大橋と相唱、又里俗石切」の橋）が寛延2年出水で流失→船渡→船渡停止→牛込水道町の願で仮板橋（幅3尺・長6間・橋台より東へ6間寄り）を架けた記録**。江戸川大橋の流失と両岸町々の復旧運動の一次記録（repo初出）。
  - **牛込馬場下石橋**: 「牛込馬場下石橋御修復奉伺候書付」（寛延2年11月3日）＝「当八月十三日出水二而牛込馬場下石橋地形洗流石垣所々孕抜崩下り其上橋台四方石垣袖短り保不宜候ニ付此度別紙絵図…之通築立御修復之搾入札申付…**落札一金拾七両壱分**…**連雀町服部屋清右衛門**・永嶋町白子屋勘七・東湊町菱木屋喜兵衛・橋町壱丁目駿河屋嘉右衛門」＋「右橋**享保十三申年九月出水二損** 土岐丹後守殿寺社奉行之節御代官懸り二而御修復有之候」＝**牛込馬場下石橋の寛延2年被災・落札17両1分・落札者に連雀町服部屋清右衛門**（[GOV-234](GOV-234.md)服部屋太兵衛・[GOV-238](GOV-238.md)服部屋清右衛門と同姓の橋請負人の落札の実績文言）＋**享保13年（1728）出水の先行被災例**。
  - （周辺）渋谷宮昼(立?)橋の流失（20両2分）・両国橋芥留杭の抜け・定請負制度の文言（享保19寅年白子屋勘七・菱木屋喜兵衛の願い＝出火焼失・出水流失の際は御材木一式の代金を下し、その他は請負人負担とする極まり）。
- **延享4年（1747）の「神田上水白堀ニ相懸り候金剛寺橋」の人留〔確認・[BOOK-129](../books/BOOK-129.md)橋梁篇の抄出元の一次記録〕**: 「五十五 延享四卯年四月廿日堀田相模守殿え上ル 神田上水白泥ニ相懸り候金剛寺橋人留之儀申上候書付…**神田上水白堀ニ相懸り候金剛寺橋 右橋破損仕候二付修復申付候依之明廿一日より往来人留仕候**此段御目付江被仰渡可被下候以上 四月廿日 能勢肥後守」＝**金剛寺橋が「神田上水白堀に相懸かる」と表現され、延享4年4月に破損・修復・往来人留（4月21日より）が行われた一次記録**。同一頁内で件名側は「**白泥**」・本文側は「**白堀**」と出る（OCRの揺れ・原字形要照合）。[BOOK-129](../books/BOOK-129.md)（東京市史稿橋梁篇第二）の「金剛寺橋修理ス。延享四卯年四月」の引用元にあたる。
- **延享4年の水道橋修理の一次記録〔確認・[BOOK-129](../books/BOOK-129.md)の対校〕**: 「**水道橋御入用一地水油(?)金六拾九両一(?)…御橋幅四間渡り拾四間半…袖之間七尺八寸…鉄物不足仕足し**」＋材木之覚（136本・早赤松・廻し檜）・請負人白子屋勘七・菱木屋喜兵衛・「延享四卯年水道橋御修復御作事方より積り上り候処町方二而御入用積申付候様二…**町方下直二付御修復申付候**」＝**水道橋（神田上水の水道橋）の延享4年修理が町方下直（町方負担）で行われた過程**の一次記録（69両・幅4間・渡り14間半・袖7尺8寸の数値は[BOOK-129](../books/BOOK-129.md)の抄出と一致方向・行対応要照合）。
- **小石川指谷町の下水橋〔確認・repo初出〕**: 「七十三 寛延三午年十一月五日本多伯耆守殿え上ル **小石川指谷町橋人留之儀申上候書付**…**小石川指谷町壱町目ゟ弐町目え渡ル下水橋 右橋朽損町内より修復仕候ニ付明六日ゟ人留仕候尤仮橋懸置往来仕候得共馬車は難相通御座候**」＝**小石川指谷町（白山前町・千川屋敷の西隣の町・[GAZ-034](../gazetteers/GAZ-034.md)追記の指谷町）の1丁目⇔2丁目を結ぶ下水橋が寛延3年（1750）に朽損し、町内負担で修復・人留・仮橋を架けた記録**。[GAZ-034](../gazetteers/GAZ-034.md)の白山前町条の下水堀（指谷町通り・下水上橋の指谷町条への相互参照）と対校できる18世紀の橋の実在記録（同一橋かは断定しない）。
- **芝金杉橋（区別の記録）〔確認・陰性区別〕**: 「**芝金杉橋**」の折損・人留・〆切船渡（延享5年2月26日・宝暦2年10月10日）＝**芝（港区芝金杉）の金杉橋であって、白堀通の金杉橋（[GOV-232](GOV-232.md)・[GOV-236](GOV-236.md)・[GAZ-049](../gazetteers/GAZ-049.md)の小日向金杉橋）とは別橋**。諸所橋々之部に見える「金杉橋」は芝側のみで、小日向金杉橋の修理記録は本冊にはない（陰性の区別記録）。
