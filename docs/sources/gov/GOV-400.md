# [GOV-400] 書上帳第48冊 — 文化11年（1814）野方堀通葭茅刈取見廻りの玉川上水側下限の文言〔第166回〕

- **書誌〔確認〕**: 『書上帳』第48冊（文化10〜12年頃の勘定所への書上・請取の控帳・NDL次世代デジタルライブラリー [book/2587273](https://lab.ndl.go.jp/dl/book/2587273)）。**引用文言はすべてOCR由来で要原文照合。**
- **文化11戌年（1814）9月の野方堀通葭茅刈取見廻りの地割棟梁2名派遣〔確認・核心〕**: 「**神田玉川両上水野方堀通葭茅雑木苅取見廻り為御用差遣候地割棟梁弐人宿代銀旅御扶持方請取候儀申上候書付御勘定所え御断御扣共弐通柳沢佐渡守荒尾但馬守**」＋「**但神田上水野方堀通葭茅雑木苅取見廻為御用差遣候地割棟梁壱人当戌九月五日出立同月十八日罷帰り候一ヶ月銀半枚之積り…日数十四日分**」＋「**但辺玉川上水野方堀通り葭茅雑木苅取見廻り為御用差遣候地割棟梁壱人当戌九月五日出立同月十八日罷帰り候…日数一十四日分**」＝**神田上水側・玉川上水側の「野方堀通」の葭茅・雑木の刈取見廻りのため地割棟梁各1名（計2名）を9月5日出立〜9月18日罷帰（各14日分）で差遣した宿代銀・旅御扶持方の請取書上**〔[GOV-285](GOV-285.md)（第49冊以降・文化13〔1816〕〜安政4の同型書上群）の2年先行の同型記録＝恒例業務の初出級の遡行〕。
- **見廻り区間の文言＝玉川上水側の下限が四谷内藤宿裏〔確認・核心・repo初出〕**: 「**右は神田上水水元井之頭池ゟ関口村迄、玉川上水水元福生村新堀口ゟ四谷内藤宿裏通内藤大和守下屋敷境迄、堀通葭茅雑木苅取見廻り為御用差遣候地割棟梁弐人宿代銀旅御持持方代金御組合入用御取替金書面之通請取相渡申度奉存候**」＝**①神田上水は水元井之頭池から関口村まで、②玉川上水は水元福生村新堀口から四谷内藤宿裏通の内藤大和守下屋敷境まで**を見廻り区間とする文言〔**玉川上水側の見廻り区間の下限が「四谷内藤宿裏通内藤大和守下屋敷境」として一次文言に現れた（repo初出）＝[GOV-285](GOV-285.md)の制限③「玉川側の区間の下限（保谷・淀橋・四谷大木戸のいずれか）は本資料群の文言では確定しない」の解消方向の文言**〔内藤宿裏＝内藤新宿の裏通・内藤大和守（内藤家当主の受領名・比定は要照合）の下屋敷境＝四谷大木戸の江戸側でほぼ市中の境界に当たる。**ただし「下屋敷境」の位置の正確な同定（大木戸の内外いずれか）と、文化13年冊〔2587274〕の「福生村新堀…」の後続文言との一致の確認は原文照合まで保留**。「旅御持持方」は「旅御扶持方」のOCR崩れ候補〕。宛・裁可: 御普請方下奉行矢嶋藤蔵・増田源三郎・柳沢佐渡守・荒尾但馬守（戌10月）。
- **同冊の他の書上〔参考〕**: 上地請取直の御届（本所南割下水・柳嶋の先手・徒組屋敷大縄関係）・御普請方雇棟梁79人の作料（戊十月朔日〜同晦日・一日一人に付銀1匁5分・米1升5合宛）等が同居。
