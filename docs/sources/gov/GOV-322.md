# [GOV-322] 警視庁令類纂 第6版（明治31年12月）— 兩上水・千川規令群の明治31年時点での現行維持の確認

- **書誌〔確認〕**: 『**警視庁令類纂**』**第6版**（**明治31年12月25日発行**。上巻＝NDL次世代デジタルライブラリー [book/791006](https://lab.ndl.go.jp/dl/book/791006)・下巻＝[book/791007](https://lab.ndl.go.jp/dl/book/791007)）。警視庁の現行規令を部門別に編纂した類纂の第6版。**引用文言はOCR由来で原画像照合を要する**。
- **第5版（[GOV-315](GOV-315.md)）収録の兩上水・千川規令群の全再録＝明治31年12月時点でも現行〔確認・第137回課題⑤の部分的解決〕**: 下巻（頁280〜282付近）に①**兩上水取締禁例**（明治11年甲第57号・第5条違警罪罰則条つきの最終形5か条）・②**兩上水取締心得**（明治12年2月26日番外・第三方面第四分署）・③**巡査交番達**（明治11年10月29日番外）・④**千川水道取締禁例**（6か条）・⑤**訓令甲第62号**（神田玉川千川三上水の月2回以上巡視）が**全て再録されている**〔**第5版（明治29年4月現行）から第6版（明治31年12月現行）までの約3年間、兩上水禁例・心得・交番達・千川禁例・訓令とも削除されず現行のまま**＝神田上水廃止（明治34年6月）前に至る兩上水行政の通時系列の定点。**神田上水は廃止時点まで警察取締の対象だった**ことの傍証（観察）〕。
- **番號索引の「甲五七」の文言〔文言候補〕**: 下巻の番號索引に「**甲五七 10/29 頁276**」〔甲第57号の項目立てと日付列「10/29」・頁276の割付＝甲第57号と10月29日（巡査交番達の日付〔[GOV-314](GOV-314.md)〕）の対応の候補。年次の割付は原画像照合まで断定しない〕。
- **陰性記録〔確認・課題の記録〕**: NDL次世代デジタルライブラリーの『警視庁令類纂』所蔵は**第6版まで**で、明治32年以降の版のデジタル化はない＝**「兩上水禁例が類纂のどの版で削除されるか」（神田上水廃止〔明治34年6月〕後の収録の終了点）の追跡はデジタル資料の範囲では不可能**（第137回課題⑤の残りは実物・マイクロ資料での確認になる）。
