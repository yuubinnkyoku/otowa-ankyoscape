# [GOV-160] 都市計画東京地方委員会 常務委員会議事速記録 第5号（1934年・谷端川変更要綱）

- **書誌〔確認〕**: 都市計画東京地方委員会『常務委員会議事速記録 第5号』・NDL次世代デジタルライブラリー [book/1264616](https://lab.ndl.go.jp/dl/book/1264616)。常委議第50号。**すべての引用はOCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **谷端川变更要綱〔確認・repo初出〕**: 1934年（昭和9年）8月6日内務大臣後藤文夫の申請、同年8月21日内閣認可（[NDA簿冊 纂02116100-01300（GOV-135）](GOV-135.md)・[東京都市計画報告第4回（GOV）の告示422号](GOV-135.md)と対応）。変更点＝①**延長3,001.8m→2,952.671m（約49.1m減・実測結果）**、②構造を**3区分**に整理＝上流は**開渠（省線板橋駅鉄道橋下で石神井放水路に接続）**・中間は**円管**・下流は**矩形渠（大塚駅山手線下で旧巣鴨町施行の下水道幹線に接続）**、③深度＝暗渠区間0.30〜2.60m・開渠区間3.60m、④護岸をT型鉄筋コンクリート高4.67mから**半重力式RC高3.95〜5mに変更**（補償物件・土圧の実測による経済的理由）、⑤勾配＝開渠1/500・1/600、**赤羽線鉄道橋下は1/250〜1/18.6で石神井放水路に取付**、暗渠は1/500〜1/30、⑥橋梁＝改築11橋のうち**木橋5橋を廃止しRC6橋とする**〔文言はOCR・「五橋ハ之ヲ廃シ六橋ノ鉄筋混凝土橋トス」の判読〕、⑦年度割を昭和5〜9年度の支出額に調整、**不用額101,042円77は神田上水に流用見込**。このうち「大塚駅山手線下で旧巣鴨町施行の下水道幹線に接続」は、[GOV-159](GOV-159.md)（1930年・巣鴨町下水道谷端川下水幹線接続点）と[GOV-161](GOV-161.md)・[GOV-162](GOV-162.md)の巣鴨町下水道計画を接続させる文言。
- **円管区間の内訳〔確認・要照合〕**: 円管は径0.30mから1.20mまでの**7種の寸法**に分かれ、矩形渠は3種（幅員・深度微減）。幅員3区分の数値は区間表として列挙される〔数値はOCR・要照合〕。
- **立会川变更要綱〔確認・参考〕**: 同時に審議。延長3,563.7m→3,570.775m、上流稲荷橋〜四丁目橋間を開渠から**暗渠に変更**（新鶴貨物線〜四丁目橋間は幅6.67→9.09mに拡大）、浜川橋〜河口は10.91→11m、深度2.88〜3.48m→2.90〜3.60m。立会川は谷端川と一括事業とされた一方で、谷端川だけが「円管＋矩形渠」の全暗渠構造となったことが対比される〔文言はOCR〕。
- **位置づけ〔観察〕**: 1930年計画（[GOV-159](GOV-159.md)）から4年後の設計変更の全容。**木橋5橋の廃止→RC橋化**は、READMEの谷端川橋梁リスト（木橋→RC橋の更新過程）に1934年の制度変更として裏付けを与える。護岸型式の変更（T型→半重力式）は谷端川の深い開渠（西前橋〜板橋駅間）の設計見直しを示す。
