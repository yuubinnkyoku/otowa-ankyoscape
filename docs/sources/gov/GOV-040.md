# [GOV-040] 1996年『かたりべ』44号：谷端川沿いの旧字袋ヶ谷と千川上水の水車・調節バルブ

- **資料〔確認〕**：豊島区立郷土資料館『かたりべ』第44号、**1996年11月30日発行**。豊島区公式[原PDF](https://www.city.toshima.lg.jp/documents/2548/kataribe44.pdf)、全4頁。**印刷p.4**「資料紹介／袋ヶ谷自由学園の昼食」、**印刷p.3**「千川上水三百年の流れ」のQ&Aと写真キャプション、**印刷p.4**編集後記をページ画像で直接確認（2026年11月2日）。縦組み本文の固有名詞・旧地番は旧地籍図との再照合を要する。
- **谷端川沿いの土地利用〔確認：1996年の資料館による回顧〕**：p.4は、**1926年（大正15年）に屋根板工場を改造して設立された保育施設「袋ヶ谷自由学園」**の所在地を**西巣鴨町大字池袋字袋ヶ谷2081番地（現・池袋本町四丁目）**と説明する。周辺を**赤羽線（現・埼京線）・東武鉄道（現・東武東上線）・谷端川に囲まれた三角形の低地帯**と位置づけ、町工場の集積を記す。掲載写真は**1935年（昭和10年）前後の昼食光景**で、**河川や敷地境界を直接撮影したものではない**。同頁は1937年頃の新校舎と在園児約200人にも触れるが、これらは1996年記事の回顧記述であり、1926年の地籍・営業原簿を直接確認したわけではない。
- **千川上水の水車〔確認：1996年の資料館による史料紹介〕**：p.3は明治前期の『千川上水路図』に**水車と思われる表示が8か所**、**1905年（明治38年）の水車取調書には稼働する水車9か所**と説明する。**「昭和初期の岩崎水車」（田島五郎氏提供）**の写真も掲載する。8と9は別の年代・資料に基づく系列全体の数字であり、**谷端川沿いに9基あったこと、同じ地点で1基増えたことを示さない**。1905年の取調書原本は未閲覧。
- **千川上水公園の施設写真〔確認：1996年館報の掲載写真〕**：p.3には**「千川上水公園に残る調節バルブ」**と題する写真がある。1996年刊行時点の施設遺構を確認する手掛かりだが、**撮影年月日・バルブの製造／設置年代・位置・現存は不明**で、谷端川の分水口と同一視できない。
- **史料探索の手掛かり〔確認〕**：p.4編集後記は、**1996年11月24日から「千川上水三百年の流れ」展を開始**し、**練馬区・板橋区との共同調査で新資料が見つかった**と記す。ただし、発見資料の題名・所在はこの記事だけでは分からない。
