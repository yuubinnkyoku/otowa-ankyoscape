# [GOV-248] 神田玉川上水留（明治2年）— 達書・仕様注文帳群の白堀通損所リストと大日坂橋見守

- **書誌〔確認〕**: 『神田玉川上水留』明治2年冊群のうち達書・仕様注文帳: [9] [book/2587525](https://lab.ndl.go.jp/dl/book/2587525)（明治二巳年正月 分冊ノ二・達書）・[13] [book/2587529](https://lab.ndl.go.jp/dl/book/2587529)（明治二巳年正月 分冊ノ六）・[14] [book/2587534](https://lab.ndl.go.jp/dl/book/2587534)（明治二巳年正月より七月 分冊ノ一・仕様注文帳）・[25] [book/2587541](https://lab.ndl.go.jp/dl/book/2587541)（明治二巳年正月 分冊ノ三）。**引用文言はすべてOCR由来で要原文照合。**
- **白堀通損所修復の箇所別縦断リスト〔確認・repo初出・白堀通経路復元の新基礎資料〕**: 仕様注文帳（[9][14]）の白堀通損所の修復記録が**上流→下流の順に並ぶ箇所別リスト**として読める——「**駒塚橋上之方**」→「**桜木橋土之方**」→「**桜木町上之方**」→「**大日坂下**」→「**水道町裏通り**」→「**中堤**」＝**①駒塚橋（repo初出の橋名候補・位置要照合）②桜木橋（白堀通の桜木町付近の橋・[GOV-232](GOV-232.md)桜木町大下の渡石樋付近か）③桜木町上之方④大日坂下（[GAZ-049](../gazetteers/GAZ-049.md)八幡坂=大日坂・坂下の鼠ヶ谷下水の谷頭部）⑤水道町裏通り（小日向水道町）⑥中堤（[GOV-234](GOV-234.md)関口中堤入口と同系の地名）**——明治2年時点の白堀通（小日向〜小石川区間）の**地点名の並びとして経路復元の基礎になる一次リスト**（順序の機械的な解釈は避けるが、桜木橋→桜木町→大日坂→水道町→中堤という並びは音羽側から水道町・関口側への流路と整合）。
- **金剛寺橋掛直の年月日〔確認・[GOV-242](GOV-242.md)への補強〕**: [25]（2587541）の金剛寺橋掛直の記録に「**金剛寺坂橋**」「**令剛寺坂橋**」（OCR変種）の表記と年月日——**明治2年6月20日往来差留→6月22日取掛→6月29日相通（完工通行）**＝[GOV-242](GOV-242.md)（[11][17][29]の仕様・工費・9月の堤急破）に対し**6月の掛直の工程の日付を補強**（6月の掛直と9月の堤急破〔[GOV-237](GOV-237.md)〕の前後関係が確定。9月急破の後に再度の修理か、6月掛直の橋が9月の急破で被害を受けたかは本冊のみでは断定できない）。
- **大日坂橋見守勘助の在職〔確認・repo初出〕**: [13]（2587529）に「**大日坂橋 見守勘助**」と読める文言（明治2年11月13日の在職記録と読める文言）＋「**白堀通見守武兵衛**」の在職＝**①「大日坂橋」という橋名が明治2年に存在したことを示唆する文言（[GAZ-049](../gazetteers/GAZ-049.md)の八幡坂=大日坂の坂下=白堀通の鼠ヶ谷下水の谷頭部に橋があった傍証）②白堀通に大日坂橋の専属の見守（勘助）がいたという制度の文言（repo初出）**。大日坂橋が白堀（神田上水）の橋か鼠ヶ谷下水の橋かは本冊のみでは断定できない（位置・構造は原文照合と対校待ち）。
- **神田上水高札建場所〔確認〕**: 高札（制札）の建場所として「**井之頭池上水口北之方**」「**堀通関口村大洗堰迄**」の文言＝**①井之頭池の上水口（取水口）の北側②堀通の関口村の大洗堰まで**という高札の設置場所の明記（[GOV-237](GOV-237.md)の制札・[GOV-234](GOV-234.md)の大洗堰関連文言と対照できる上水全体の公示の実務）。
- **小日向江戸川端の水車御取立〔確認・周辺〕**: 「**小日向江戸川端え水車御取立**」（明治2年10月3日と読める文言・龍閑橋〜船河原橋間の東側の通行と読める語句）＝**小日向の江戸川（神田川）端への水車の取立（設置許可か設置記録か）の明治2年の文言**（[GOV-246](GOV-246.md)の関口水道町の水車持ちと対照できる江戸川筋の水車の新記録・語義は要照合）。
- **小石川金富町の石工佐吉〔確認・周辺〕**: 「**小石川金富町 石工佐吉**」の文言＝**白堀の石垣の修復に関係する石工（金富町=白堀沿いの町・[GAZ-049](../gazetteers/GAZ-049.md)向堀の小石川金杉町〜音羽町・桜木町・還國寺前〜小日向水道町の浚負担区間と対照）の実名の記録**（人名・業務の割付は要照合）。
