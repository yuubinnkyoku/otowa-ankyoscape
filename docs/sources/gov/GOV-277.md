- **書誌〔確認〕**: 『玉川上水留』「玉川上水四谷御門外南之方御堀端通石垣樋御修復一件　安政三辰年四月より同年十二月迄」（全1冊）[book/2587389](https://lab.ndl.go.jp/dl/book/2587389)。repo未登録（「山下御門」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔四谷御門外南之方＝現在の新宿区四谷〜外苑前・青山方面の外堀端で、[GOV-282](GOV-282.md)書上帳（安永10-天明2）の「四ツ谷御門外南之方溜枡吐口」の区域と重なる可能性がある。〕
- **安政2年10月の地震で崩落〔確認・repo初出の災害記録〕**: 「**去卯十月中地震之節崩落仮養方取斗置候場所之内 天徳寺門前代地前ゟ松平佐渡守屋敷辻番所前迄之処は皆潰ニ付仮養難取計候間…赤坂柳堤通御普請所二而相用候古仮樋を以手当仕急速水仕掛出来仕可成流末迄行渡居候**」＝**安政2(卯)年10月中の地震（＝安政江戸地震・1855年11月11日＝安政2年10月2日と暦の上で整合）で、天徳寺門前の代地前から松平佐渡守屋敷の辻番所前までの四谷御門外南之方の石垣樋が崩落し、仮養（応急処置）の後、赤坂柳堤通の御普請所の古仮樋で急速に水仕掛をして流末まで通水を維持した**＝**安政江戸地震が玉川上水の城内導水路（四谷御門外南之方の石垣樋）を破壊し、仮樋による迂回給水で応急対応した記録**（「卯十月中」の月日の表記はOCR要照合として、安政2年10月2日の地震と特定するのは暦の整合による推定と明記する）。
- **落札412両・元積681両〔確認・周辺〕**: 「**金四百拾弐両入札落直段(?) 金六百八拾壱両地割棟梁元積 差引金弐百六拾九両落札之方安(?)**」＝**入札落札412両に対し元積681両・差引269両（元積より安値）**＝安政の修復は元積を2/3程度に圧縮した入札（金額のOCR対立は要照合。石垣樋の大規模修復の市場価格の資料）。
