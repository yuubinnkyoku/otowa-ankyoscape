# [GOV-545] 都「石神井川の新たな区間で河川事業に着手」プレス＋第四建設事務所・石神井川（本立寺橋上流～弁天橋下流）事業説明会〔第五号石神井川の着手表明と説明会資料群〕

- **書誌〔確認: 都プレス本文・2026-11-23取得〕**: 東京都庁総合ホームページ報道発表「**石神井川の新たな区間で河川事業に着手します 水害から都民の命と暮らしを守り、安全なまちの実現に向けて**」（**2025年6月30日**付・建設局） https://www.metro.tokyo.lg.jp/information/press/2025/06/2025063003 〔記事ID 000-001-20250630-042374〕。別紙「案内図」PDF（664KB） https://www.metro.tokyo.lg.jp/documents/d/tosei/20250630_03_01 の添付あり〔第279回（2026-11-23）に本文取得成功。第278回時点では直curlがbot避けHTMLを返し未取得だった〕。
- **プレス本文の文言〔確認: r.jina.ai経由本文・2026-11-23〕**: 「このたび、石神井川の下記区間において、**都市計画事業の認可を取得しました**。これを受け、河川整備事業に着手します」「新たに事業着手する区間は、**練馬区関町北二丁目（本立寺橋上流）から関町北三丁目（弁天橋下流）の約390メートル**です」「**令和7年6月30日から令和16年3月31日まで**の予定です」「今後は、下記区間の工事に向け、**設計等の準備を進めていきます**」。石神井川の説明＝「**小平市内にその源を発し、東京都北部をほぼ一直線に東へ流れ、北区内で隅田川に合流する一級河川**」「**流域面積は73.1平方キロメートル、延長は25.2キロメートル**」。事業の概要＝「**1時間あたり50ミリメートルの降雨**による洪水を安全に流すことができるように、**川幅を広げるなどの河道整備**を行い、浸水被害の軽減を図ります」。問い合わせ＝建設局河川部計画課 03-5320-5414。
- **第四建設事務所ページ〔確認: ページ本文・2026-11-23取得〕**: 「石神井川（本立寺橋上流～弁天橋下流）事業説明会」 https://www.kensetsu.metro.tokyo.lg.jp/jimusho/yonken/daiyon0034 〔更新日2026-07-27・r.jina.ai本文取得〕。「東京都では、**東京都市計画河川事業第五号石神井川**のうち、**練馬区関町北二丁目（本立寺橋上流）から関町北三丁目（弁天橋下流）までの延長約390ｍの区間について、令和７年６月30日に国土交通省より事業認可を取得しました**」〔**「第五号石神井川」の号数文言が第四建設事務所ページで確認できる**＝[GOV-531](GOV-531.md)（第六号神田川・2025年2月27日認可）の対になる第五号の着手記録〕。添付3点＝「説明会のお知らせ」〔4,643KB〕 https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/shakujii-honryuji-notice ・「説明会資料」〔5,997KB・16頁〕 https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/shakujii-honryuji-document ・「説明会における主な質問回答及び意見」〔4,774KB・3頁〕 https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/shakujii-honryuji-Q$A 〔3PDFの本文をr.jina.ai経由で抽出済み〕。
- **説明会資料（16頁）の文言〔確認: r.jina.ai経由本文抽出・2026-11-23〕**: ①**石神井川の護岸整備率「76％※（※令和６年度末時点）」**〔[GOV-512](GOV-512.md)に先行する令和6年度末時点の石神井川の護岸整備率文言。事業中約1.4㎞（H21～）・約0.3㎞（H25～）の内訳も記載〕。②**平成17年9月の集中豪雨**＝「９月４日夕方から５日未明にかけて各所で時間最大100mm以上の激しい雨が降り、**石神井川や妙正寺川など８河川で溢水**」「石神井川では**浸水家屋921棟**の被害が発生」〔都心想定＝24時間雨量137.0mm・時間最大雨量114.0mm/hr・溝田橋付近〕。③**平成22年7月の集中豪雨**＝「北区の石神井川**溝田橋付近で溢水**」「浸水家屋**660棟**の被害が発生」〔板橋区観測所で時間最大100mm以上〕。④溢水被害の規模比較図（28.2ha・392棟／4.4ha・85棟）と「今回事業化する区間 約390m（本立寺橋 上流～弁天橋 下流）」の平面図＝**都市計画線の概略位置表示を含む**。
- **Q&A資料（3頁）の文言〔確認: r.jina.ai経由本文抽出・2026-11-23〕**: 質問①回答＝「現在の川幅は**約7m**ですが、整備後は**約12m**となり、**断面積としてはおおよそ2倍程度に拡大**される予定です」。質問②回答＝「**右岸側には幅5ｍ、左岸側には幅3ｍの管理用通路**を整備する計画」（右岸は現在の車道と同等の幅・左岸は歩道機能と桜並木の整備予定）。質問④＝河床を深く掘る断面拡大は流下勾配の観点から不可。質問⑪＝「**本区間は昭和51年に大規模な浸水被害**がありましたが、最近は溢水がありません。河道整備は本当に必要なのですか」。回答⑫＝「**本区間の都市計画は昭和37年に決定しており**、長年にわたり下流から河道の整備を進めています。**時間50mmの河道整備の方針は現在も変わってなく、この都市計画に基づいて整備が必要なため、都市計画の変更は予定していません**」〔**昭和37年の都市計画決定年次と昭和51年の大規模浸水の年次をともに明記する公式回答**＝[GOV-534](GOV-534.md)（第六号・都公報公告）・[GOV-538](GOV-538.md)（平成16年整備局告示第208号）と対になる第五号側の事業側記録〕。質問⑧・⑨＝**西武新宿線の連続立体交差事業・武蔵関駅前広場との調整文言**（高架下流下は河川断面縮小のため望ましくない）。質問⑩＝下流整備との順序（用地取得等の準備を考慮した事業認可）。
- **意義〔観察〕**: ①[GOV-531](GOV-531.md)（神田川第六号・2025年2月27日認可の着手プレス）と**完全に対になる第五号石神井川の着手表明文書**で、**認可年月日（2025-06-30・国土交通省）・区間（関町北二〜三丁目・橋名つき）・延長（約390m）・事業期間（〜令和16年3月31日）・着手段階（設計等の準備）**が一点に揃う。②**「東京都市計画河川事業第五号石神井川」の号数と「国土交通省より事業認可」の認可主体**が第四建設事務所ページで確定〔[GOV-542](GOV-542.md)（官報・「平成28年関東地方整備局告示第176号 東京都市計画河川第五号石神井川及び第六号神田川」の事業変更公告）・[GOV-535](GOV-535.md)（中野区・環七調節池の第5号石神井川＋第6号神田川）と接続＝**第五号の対象区間が従来の環七調節池（練馬区高松〜中野区野方）とは別に石神井川本川の河道整備区間でも運用されている**ことを確認できる〕。③説明会資料群は**神田川流域外の石神井川単独の治水史資料**だが、[GOV-124](GOV-124.md)（神田川流域河川整備計画）の環状七号線地下広域調節池が「神田川、善福寺川、妙正寺川、**石神井川**、白子川から取水を行う」と記す構造で**石神井川は間接的に神田川流域計画と接続**しており、第五号の都心側事業の現況資料として収録〔水窪川・弦巻川・谷端川の直接資料ではないため対照表等への反映は行わない〕。
- **別紙「案内図」本文〔確認: r.jina.ai経由本文抽出・2026-11-23（第279回追記）〕**: 「**既定認可区間 約1,400m（扇橋～本立寺橋）**」「**今回認可区間 約390m（本立寺橋～弁天橋）**」の図示文言＝**既定区間の起点橋「扇橋」はrepo初出の橋名**〔対象区間周辺の橋名として弁天橋・長者橋・本立寺橋・豊城橋・西豊城橋・庚申橋・扇橋の7橋の図示あり。「**図-１ 石神井川案内図**」「**図-２ 新規事業認可区間の位置図**」の2図構成。**既定認可区間1,400m（扇橋〜本立寺橋）＋今回認可区間390m（本立寺橋〜弁天橋）の2区間が本立寺橋で接続する構成**を図で確認できる＝土地条件文言として「新青梅街道」「練馬区関町北二〜四丁目・関町東二丁目・上石神井四丁目・石神井台四丁目・石神井台七丁目」の図示もある〕。図には**武蔵関公園（富士見池調節池）**の位置表示もあり〔[GOV-416](GOV-416.md)（『練馬区史 現勢資料編』の水質測定駅名「富士見池」）・[BOOK-089](../books/BOOK-089.md)（中西慶爾『青梅街道』「千川上水と富士見池」）と接続＝石神井川上流部の池・水系（千川上水系の富士見池）の資料との接続点。石神井川河道事業の案内図に調節池として池が表示される点は、[GOV-257](GOV-257.md)（1931年石神井村現状調査の石神井川・千川水道列挙）と同じ上流部の水系の重層記録〕。
- **文言食い違い〔併置・断定せず〕**: 第四建設事務所ページ本文は「**令和７年９月30日及び10月１日の両日**……説明会を開催しました」と記すが、添付3点（お知らせ・説明会資料・Q&A）はいずれも「**令和７年８月３０日（土）会場）都立石神井高等学校／令和７年９月１日（月）会場）練馬区関区民センター**」と記す〔ページ本文と添付で開催日の文言が食い違う。どちらが正しいかは本資料群からは判定不能で断定しない。開催日は前置き文言（お知らせ）と一致する8月30日・9月1日の可能性が高いが、ページ本文の更新日（2026-07-27）が説明会後に再編集された可能性も排除しない〕。
