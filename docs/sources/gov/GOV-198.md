# [GOV-198] 北豊島郡総覧 昭和5年度版（1931年）— 「千川筋土揚敷地」と板橋宿埋立ての年月日

- **書誌〔確認〕**: 東京府北豊島郡『北豊島郡総覧（昭和5年度版）』（1931年）。NDL次世代デジタルライブラリー [book/1049150](https://lab.ndl.go.jp/dl/book/1049150)。**すべての引用は同館OCRテキスト由来であり、文言・年月日・地番は原文画像との照合を要する。**
- **江古田新田の「千川筋土揚敷地」〔確認・repo初出〕**: 江古田新田（旧江古田村）の消防組記述＝「**江古田新田二〇七一、千川筋土揚敷地四坪五合ヲ消防器具置場並ニ火ノ見梯子建設地トシテ無償使用ノ認可**」（明治45年東京府知事認可）＝**「千川筋」が江古田新田の小字・土揚げ（築堤の残土置き場）敷地の地番として残存していた**記録。〔地番・面積・文言はOCR要照合〕。
- **板橋宿の千川用水埋立て道路化〔確認・repo初出の年月日〕**: 板橋町の記述＝「町內ヲ貫流スル千川用水路**五兵衞橋下流埋築町村道新設**ノ起工ヲナシ**同四年三月十四日開通**シ、又**五兵衞橋上流ヨリ大山橋マデ埋築道路新設ニ決シ同四年十二月九日起工シ同五年六月竣工**セリ」（前段の起工は昭和3年12月6日）＝**板橋宿内の千川用水の暗渠化・道路化が昭和3年（1928）〜昭和5年（1930）に2区間で実施された具体的年月日**。〔年月日はOCR要照合〕。
- **花井源兵衛〔確認〕**: 板橋町長（東京府会議長等を歴任・嘉永元年板橋宿生まれ）の記述＝「**千川用水路ノ暗渠計畫悉ク氏在職中ノ產績ナリ**」＝**千川用水暗渠計画が花井源兵衛町長の在職中の産績**とする人物記録。〔文言はOCR要照合〕。
- **流路記述〔確認〕**: 千川用水＝多摩川上水の分流で保谷から石神井村〜旧竹下新田〜上下石神井・田中・谷原・上練馬・下練馬・上板橋・長崎・板橋・瀧の川を経て王子町で石神井川に合う・延長5里24町余・幅約1間余（瀧の川町で3〜4間）＝1931年時点の全流路記述。江古田町＝「千川用水ハ〓戶道ニ併行シテ村ノ北端ヲ流レ上板橋江古田ニ入ル、唯一ノ灌漑及防火水」「**千川用水畔ニハ櫻樹多ク名所タリ**」等の記述も。〔文言・OCR判読不能箇所（〓）は要照合〕。

- **大泉村章の沿革＝榑橋村命名・5ヶ村連合戸長役場〔確認・repo初出〕**: 大泉村章の沿革に「大小區制廢されて、**小樾、橋戶、下保谷、上保谷、上保谷新田の五ヶ村聯合の戶長役場**を置く、同二十二年町村制施行に際し**橋戶小樾兩村を合して榑橋村と稱し**、同二十四年東京府管轄に移る」＝**①大小区制廃止後、小榑（OCR「小樾」＝小榑の誤読候補・原字照合要）・橋戸・下保谷・上保谷・上保谷新田の5か村の連合戸長役場が置かれていたこと、②明治22年町村制施行の際に橋戸村・小榑村を合して「榑橋村」と命名したこと（「榑橋」の命名行為の文言としてrepo初出）、③明治24年に東京府管轄へ移ったこと**＝1889年の榑橋村成立（小榑村＋橋戸村）の命名過程と、保谷側3か村（下保谷・上保谷・上保谷新田＝のちの保谷村）との連合戸長役場関係を含む沿革記録〔[GAZ-063](../gazetteers/GAZ-063.md)（北足立郡誌）・[GAZ-064](../gazetteers/GAZ-064.md)（風土記稿新座郡巻）の榑橋村記録への1931年の郡総覧側の追記〕。
- **小榑村旧記の県庁変遷〔確認・repo初出〕**: 「**小樛村の舊記に明治三年十月品川縣廳、明治六年六月入間縣廳同八年十二月熊谷縣廳なぞ記せり**」（「小樛」＝小榑のOCR崩れ候補）＝**小榑村の旧記（村方文書）が明治3年10月品川県庁・明治6年6月入間県庁・明治8年12月熊谷県庁の変遷を記す**＝維新期の県庁変遷（品川県〔1868-71〕→入間県〔1871-73〕→熊谷県〔1873-76〕→埼玉県〔1876-〕）を村方の旧記レベルで記録していた事実（大区小区制・連合戸長役場期の行政史の背景。OCR崩れがあり原字照合を要する）。
- **維新前の村役人・村高〔確認〕**: 維新前の村役人として**橋戸村莊惟美**ほかの名、村高として**橋戸村280石余・小榑（樛）村1,463石余・土支田村800石余**＝1889年以前の旧村の高の1931年時点の採録（維新前の村高の個別数値としてrepo初出。風土記稿由来の数値かは未確認・OCR要照合）。
- **初代村長鈴木政和＝9月文言〔確認・repo初出〕**: 「本村は**明治二十四年九月村の組織を定めらるゝと共に第一次の村長として鈴木政和氏**」＝**大泉村の組織確定・初代村長（鈴木政和）の選任が明治24年9月とする文言**＝大泉村成立期日の「月の対立」（6月派＝[GOV-333](GOV-333.md)（埼玉県統計書）・[GAZ-063](../gazetteers/GAZ-063.md)（北足立郡誌）・[GOV-331](GOV-331.md)（大泉村現状調査）／9月派＝本文言・[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌「明治二十四年九月…東京府の管轄に移り」））の9月側の代表文言。**「移管・合併（6月）と村組織確定・村長選任（9月）の2段階」が最も整合するが、官報の確認までは断定しない**。
- **千川用水の1931年現状＝板橋町山中より下流の暗渠化・道路併用〔確認・repo初出の文言〕**: 「二〇村の用水にて水田に漑ぎ水車を動かしたるも、**現在は上板橋以東水田無く、板橋町山中より下流を悉く暗渠し河身を道路に併用せり**」＝**①千川用水が20か村の用水として水田灌漑・水車動力に使われていたこと、②1931年時点で上板橋以東に水田がなく、板橋町山中より下流は全て暗渠化され河身を道路に併用していたこと**＝既記録の板橋宿埋立て（五兵衞橋下流・上流〜大山橋の2区間・昭和3〜5年）に加え、**暗渠化の範囲を「板橋町山中より下流」と明示する文言**（「山中」＝板橋町の小字か地名で、正確な位置は要確認）。
- **岩崎邸鴨池への引水＝千川用水の一支流〔確認・repo初出〕**: 「**瀧野川堀割にて(瀧野川三軒家と西巢鴨庚中塚境界地點)暗渠とし上駒込岩崎邸鴨池に引く清冽の水も亦千川用水の一支流たり**」＝**①瀧野川堀割（滝野川三軒家と西巣鴨庚中塚の境界地点）で暗渠とし、上駒込の岩崎邸（＝六義園）の鴨池に引かれる「清冽の水」も千川用水の一支流であること、②1931年時点で引水が現役であること**＝[GOV-329](GOV-329.md)（本郷区勢要覧・1931）の「六義園の大池に千川上水の余水を注ぐ現勢」の**独立出典（北豊島郡側・同年刊）による裏付け**＋[PAP-048](../papers/PAP-048.md)（森島2023・1894年六義園支線新設）・[BOOK-140](../books/BOOK-140.md)（明治40年岩崎所有化）の後の1931年の現勢観察。**鴨池＝六義園の大池の別名（池中島の鴨場に由来する呼称か）で、正確な池名の原字は要照合**。
- **谷端川＝板橋駅傍の石神井川分落隧道の実施済み〔確認・repo初出〕**: 「近年水田無く沿川住宅地と化したるを以て、降雨甚しき時は忽ち各所に氾濫し…**東京市は曩に板橋驛傍より隧道を石神井川に貫き、堰を以て之に分落せしめ。東京府は之れが治水策として改修を斷行しつゝあり**」＝**①谷端川の沿川の水田消失・住宅地化・氾濫頻発の1931年時点の観察、②東京市が既に（「曩に」）板橋駅傍から隧道で石神井川に貫き堰で分落させていたこと＝分落隧道の実施済み、③東京府の改修（1930年決定の谷端川改修〔[GOV-159](GOV-159.md)〕）が進行中であること**＝[BOOK-126](BOOK-126.md)（明治41年下水道設計の「千川上流ノ放水路ハ板橋停車場附近ヨリ…石神井川ニ通ゼシメ」＝設計文言）の**実施側の確認**＝谷端川の放水路（板橋駅傍→石神井川）が明治41年設計（1908）〜昭和初期の間に実施されたことを示す観察文言（実施年月は特定できない）。
- **水利総説＝江戸水利の源泉列挙〔確認・repo初出〕**: 「德川氏の江府を開くや亦水利攻究に全力を盡し、**玉川に、井頭池に、遲野井池に、千川に、石神井川に**其の利用の途を講じたる跡歷然たり」＝江戸の水利の源泉として玉川（玉川上水）・井頭池・遲野井池（OCR崩れ・**井ノ頭池の候補**・原字照合要）・千川・石神井川を挙げる文言＝**「井頭池」を武蔵野側の水利の源泉として挙げる1931年の文言**（[GOV-331](GOV-331.md)の白子川源流=井頭溜池・[GAZ-002](../gazetteers/GAZ-002.md)の大泉村名由来の井頭池と併せ、大泉村の井頭池が地域水利史で語られる資料）。
- **郡内最高所〔確認・対校〕**: 「大泉村小樾小作一七〇、九四尺 同村橋戶北原一五五、一〇尺」＝北豊島郡の最高所の数値＝[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌・1918）の「大泉村大字小榑百七十尺九寸四分」と同一数値（小字「小作」「北原」の付き方の差はOCR・原字照合要）＝**北豊島郡の最高地点（大泉村大字小榑＝約170尺）の2書一致**。
