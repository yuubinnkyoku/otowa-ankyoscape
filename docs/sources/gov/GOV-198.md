- **【正受院】条の「功曾久」＝場所判読を強める3系統の対校〔確認〕**: 本条（1931「大和字陀郡龍門の奥、功曾久に居た學仙房」）に、①[BOOK-122](../../books/BOOK-122.md)（武蔵野歴史地理1930「大和字陀郡龍門の奧功曾久といふ處に住せし學仙房」）、②[GAZ-097](../gazetteers/GAZ-097.md)第175回追記（江戸志〔内題「新編江戸志巻之三」〕[3]龍不動条「大和国宇多郡滝川の魚功曽人と云処に一宇有て学知坊と云僧住す」）が加わり、**「功曾久」を人名ではなく「處」（場所名）として読む本文が1930・1931・江戸期系地誌の3系統で確認**＝第173回追記で「人名判読OCR崩れ候補」とした部分は**場所名である可能性が強い**（「字陀郡（宇陀郡）龍門の奥」の地名扱い。ただし各書ともOCR由来で原画像照合までは「確定」としない）。
- **【金剛寺】条の観瀬『秋遊記』の所在特定〔確認・第173回ノート課題④の解決〕**: 本条④「觀瀾著の秋遊記には此邊を瀧野川道灌山と稱し、朝賴と道灌の遺跡だと書いてある」の秋遊記の所在が特定された＝[BOOK-201](../../books/BOOK-201.md)（『觀瀾集』[3]・三宅緝明〔観瀾〕著・写・NDL [2590573](https://lab.ndl.go.jp/dl/book/2590573)）所収「十四 秋遊記」＝宝永3年（1706・丙戌）の漢文遊記で「臨所謂瀧野川道灌山者。川乃源頼朝。稱兵進以置陣之所」等の本文をOCRで直接確認＝**1931年記事の元本文の実在確認**（秋遊記には松橋・板橋の橋名はなく、頼朝陣所を「川」として記す＝中立witness。詳細はBOOK-201）。
- **「遊歴雜誌」＝遊歴雜記（釋敬順）の表記ゆれ候補〔観察〕**: 本条【正受院】の「當院の本堂客殿等殆んど湯治場のやうであつたと**遊歴雜誌**にある」について、[BOOK-122](../../books/BOOK-122.md)第175回追記（同書は十方庵主釋敬順の旅行記を一貫して「**遊歷雜記**」と表記）と対照すると**「遊歴雜誌」は「遊歴雑記」（釋敬順）のOCR由来・表記ゆれの候補が強い**＝本repo内の遊歴雑記（敬順）系引用の表記は「遊歴雑記（釋敬順）」に統一して表記ゆれとして注記する形が妥当〔「誌/記」の切断は原画像照合まで確定扱いしない〕。
