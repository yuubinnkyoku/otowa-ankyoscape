# [GOV-444] 神田上水留[40]〜[42] — 水道橋外掛樋普請と河岸惣場・駒塚橋の文言

- **書誌〔確認〕**: 『神田上水留』の元治2丑年（1865・**四月十八日慶応改元**）四月取掛の関係3冊——分冊ノ一[40]（[book/2587495](https://lab.ndl.go.jp/dl/book/2587495)・「**神田上水水道橋外掛樋并埋樋枡其外共御普請一件 四月取掛**」の表紙）・分冊ノ二[41]（[book/2587496](https://lab.ndl.go.jp/dl/book/2587496)）・分冊ノ三[42]（[book/2587497](https://lab.ndl.go.jp/dl/book/2587497)・仕様注文帳の古物御払・附切の請取で内容が異なる）。**引用文言はすべてOCR由来（本群は崩壊が特に激しい）で要原文照合。**
- **[40]の申渡文言〔文言候補〕**: 「**雉子橋御門内小右衛門御普請方ゟ北屋場林田小右衛門江 神田上水水道橋外掛樋御普請之儀に付申渡儀有之間 明後三日四時 佐子(雉子?)橋御門内御堀浚小屋場え印形持参可罷出候**」＋「**是は神田上水水道橋外掛樋并四拾軒(?)御普請ニ付申渡候間左之通相心得**」＝**①水道橋外の掛樋普請の申渡が雉子橋御門内の御普請方（小右衛門）から北屋場の林田小右衛門宛に行われたこと、②「明後三日四時」に小屋場へ印形持参で罷出するよう命じた日程文言**（「四拾軒」の判読は要照合・掛樋と埋樋枡の普請の規模文言か）。
- **[41]河岸惣場の文言〔文言候補・崩壊大につき全て文言候補扱い〕**: 分冊ノ二の絵図面・覚書に——「**見守番屋 三間×三間**（文言は「三間三日三三間」と崩れて要照合）」「**松平讃岐守 物揚場 拾四間**」「**石川伊予守 物揚場 拾八間**(「物易易相撲十八間一日」と崩れて候補・要照合)」「**諸色物揚場 竹矢来**」「**小留場 竹矢来**」「**葭張 茶屋**」（八月葭張・茶屋の文言）「**高張挑灯**(文言候補)」「**神田上水道橋外…同所西之方神田川河岸え小屋場竹矢来 諸主(惣?)揚場…共取建 川内え足代桟橋掛置 最寄え諸主小相(屋?)番屋等差置**」「**且又同所東之方掛極見守番屋前通道内え竹矢来取建置候間 御成之節通御之御障に…**」＝**①水道橋外の神田川河岸（東西両川岸）に掛樋普請用の小屋場・竹矢来・物揚場・桟橋が設置されたこと、②物揚場が大名（松平讃岐守＝高松藩候補・石川伊予守＝伊予松山藩候補）の持ち分として長14間・18間で建てられたこと候補、③葭張・茶屋・高張挑灯等の河岸の仮設・茶屋の景観文言、④「御成之節通御之御障」＝普請中の御成（将軍御成か参府かは不特定）の通行への配慮文言**〔**幕末（1865年）の水道橋外神田川河岸の土地利用・仮設の一次記録候補**。大名の物揚場（荷揚場）は水道橋外の河岸が慶応期にも大名側の物流・揚場として使われていた傍証候補（[BOOK-152](../books/BOOK-152.md)巻頭の江戸期絵図の揚場や[GOV-288](GOV-288.md)の「神田川揚場竹矢来木戸門」と対照候補）。全て文言候補扱い〕。
- **[42]関口村駒塚橋の柵修復の附切手当〔文言候補・橋名調査対象〕**: 附切（普請現場の管理手当）の請取書に——「**金七両弐分三朱 銀壱匁弐分五厘 (丑)四月御普請方下奉行 神谷祐蔵**」＋その内訳文言「**是は神田上水関口村 駒塚橋上シ下モ柵御修復之方二而御手当請取候間 当御場所之方相除申候 金三両三分 支配勘定格 御普請方改役勤方(同断) 東原(粟原?)善八 御普請方上野権太郎 同夜役井上治左衛門 五日分一日壱人銀三匁宛 但当丑十月八日ゟ同十一月二日迄 日数合二十五日**」（重複文言では「**是天神田上水関口村駒塚橋上ミナモ柵御修復之方二而御手当請取候間**」）＝**①水道橋外の掛樋普請の支配附切方が、②別件として関口村の駒塚橋の上・下の柵の修復を担当して手当（金3両3分・丑10月8日〜11月2日25日分・1人1日銀3匁宛）を受け取ったため、③「当御場所」（水道橋外現場）の分は相除（除外）したという会計処理の文言**〔**駒塚橋（関口村・神田上水筋）の幕末の柵修復の行政文例**＝橋本体の修復ではなく柵（欄干・防護柵）の修復の記録で、[GAZ-048](../gazetteers/GAZ-048.md)・[GOV-248](GOV-248.md)・[BOOK-152](../books/BOOK-152.md)等の駒塚橋記録群への慶応元年の新たな一点。手当の会計構造（水道橋外普請の附切と駒塚橋柵の兼務）の文言として幕府普請方の実務の記録候補〕。
- **[42]の古物御払〔文言候補〕**: 仕様注文帳の表題「**神田上水水道橋外弐拾(?)其外御普請所 召抱御払仕様注文帳 神谷祐蔵 粟原善八 上野玄太郎 井上治左衛門**」＋「**行桁壱本 長四間壱尺四寸角 同代銀三百四拾弐匁九分**」「**壱ヶ村(?)長弐間三尺 同断 代銀百八拾六匁九分**」等＝水道橋外普請後の古材（桁等）の御払（払い下げ）の代銀文言群（行桁長4間の角材が342匁9分等・要照合）＝**普請材の再利用・払下の実務の帳簿候補**。
