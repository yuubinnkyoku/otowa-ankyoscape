# [GOV-045] 小石川区大塚仲町の配水本管敷設工事写真

- **資料〔確認：東京都水道歴史館の公開目録、2026年11月3日閲覧〕**：同館デジタルアーカイブ「[【工事写真】小石川区大塚仲町配水本管敷設工事](https://www.ro-da.jp/suidorekishida/content/detail/REKI-020-009)」、**資料ID REKI-020-009**、**ガラス乾板写真**、寸法**16.5×12.0cm**、地域・施設名「文京区」。
- **年代・制作主体〔確認：目録の表示〕**：制作年月日は**「大正時代～昭和前期」**という幅のある推定表示、制作者は**「東京市（水道局か）」**と留保される。**2025年12月16日**はデジタルアーカイブの**公開日**であり、写真撮影日・工事日ではない。
- **原題・記載〔確認：目録の備考〕**：「目録に原タイトル『小石川区大塚仲町配水本管敷設工事』とあり」。キーワード欄は**「線路」**。
- **確認の限界〔未解決〕**：目録の書誌・原題・公開日を直接確認した。**写真画像そのものの細部は未判読**。既知の同地区の電車軌道下鉄管敷設写真（P0120_012_02、REKI-039-003_02）と**同一工事・同一撮影地点・同一画像かは未照合**。旧町界、線路位置、鉄管の径・用途、施工日も未確定。
