# [GOV-598] 日本都市大観（昭和11年版・15年版）— 河川改修予算の府政年鑑記述と谷端川777万8千円

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 大阪毎日新聞社編『日本都市大観』（**大阪毎日新聞社**）。**昭和11年版**（**1936**・[book/1207937](https://lab.ndl.go.jp/dl/book/1207937)）と**昭和15年版**（**1941**・[book/1207969](https://lab.ndl.go.jp/dl/book/1207969)）の両方の東京府章の「都市計画事業」節を確認。**新聞社の年鑑（府政の一般解説書）であり、かつ引用はOCR由来のため、数値の信憑性・字面ともに要原文照合**（引用にあたっての注意文言）。数値を断定材料として単独で使わないことが本登録の前提。

- **昭和11年版**（東京府章・都市計画事業節）:
> 道路延長は國道十三万二千〓…に達してゐる…（第三期線は昭和七年から同十四年までの豫定で）豫算總額一億七千九百廿七万余円で目下實施してをり、**さらに河川ハ立合川、神田上水、谷端川、呑川、宇田川、谷田川、蛇崩川、妙正寺川、澁谷川上流の各河川に對し豫算一億九千七十五万円で改修を行つてゐる**

## 読み取り〔観察・乖離の対校課題として登録・断定しない〕

- **①谷端川777万8千円の新聞社年鑑数値〔repo初出の数値〕**: 昭和15年版の河川別予算列挙で**谷端川七百七十七万八千円**と単独表記される。これに対し既出の公文書系数値は ⅰ)[GOV-159](GOV-159.md): trio（立会川＋神田上水＋谷端川）総額**520万9千円**（1930年決定）ⅱ)[GOV-161](GOV-161.md): 谷端川分**工費約49万円**・延長2,953m（1935年末〜36年の委員会審議時点・trio総経費563万余円）であり、**約16倍の乖離**がある。考え方の候補は (a) 用地費・受益者負担・物価上昇込みの後年の総事業費への積み直し、(b) 年鑑側の誤栽・別河川（例：中川関係や呑川系）の数値との混同、(c) trio改修完成後の追加改修区間の取り込み等であるが、**本資料（新聞社年鑑・OCR）単独では判断できない**〔対校課題として登録。都立交差点の公文書（内務省・東京府の決算統計類）での確認が今後必要〕。
- **②同一の列挙内の整合性〔観察〕**: 15年版リスト内の**神田上水413万620円・立会川146万円**はtrio公文書系の大枠（神田上水388万円[GOV-161]・立会川128万円[GOV-161]）と比べて388→413万・128→146万と**各1.06〜1.14倍程度の増額**で整合的に見えるのに対し、**谷端川だけが49万→777.8万と桁違いに離れる**＝trioの内訳では本来一番小さい谷端川がリスト内で2番目の規模になる**同列挙内部での不自然さ**が、誤栽・混同説を弱めない程度には示唆する〔あくまで観察。777.8万円が「谷端川」の実総事業費である可能性も捨てない〕。
- **③1936年時点の群列挙〔確認〕**: 11年版は「**河川ハ立合川、神田上水、谷端川、呑川宇田川、谷田川、蛇崩川、妙正寺川、澁谷川上流の各河川に對し豫算一億九千七十五万円で改修を行つてゐる**」＝**1936年時点で谷端川がtrio改修（[GOV-159]）と並ぶ府の河川改修群里に含まれている**ことの年鑑側確認で、trio＋呑川・宇田川・谷田川・蛇崩川・妙正寺川・渋谷川上流という**昭和11年時点の府の河川改修の全面**を列挙する〔OCRで「呑川宇田川」が連結して読める箇所は区切り要照合〕。
- **④スコープ乖離の注意〔観察〕**: 11年版の「1億9,075万円」は上記8河川群が総額で、15年版のリスト（谷端川777.8万円を含む**13項目・合計約5,372万円**＝単純加算・検算済み）とスコープが異なる（15年版は環状放射線改修の「豫算總額二億三千二百万円」と河川予算を別個に載せる）。**同一書名の版間で集計範囲が変わる**ため、数値の相互引用時にはどちらの集計かを必ず明記して使う〔15年版リスト内の「都市計畫事業大阪府道路網」というOCR字面（東京府章における明らかなOCR崩れ）も、本版のOCR全体の品質が低いことの傍証として記録〕。
