# [GOV-289] 玉川上水留・天保10〜11年 — 四谷御門外の町方引取樋枡の新規伏渡（末端給水の管理）

- **書誌〔確認〕**: 『玉川上水留』の1冊（NDL次世代デジタルライブラリー [book/2587351](https://lab.ndl.go.jp/dl/book/2587351)・玉川上水留[17]）。表紙「**天保十亥年ヨリ至(同)十一子年 玉川上水四谷御門外町方引取樋枡新規伏渡一件 同十一子年御普請方**」。**引用文言はすべてOCR由来で要原文照合。**
- **麹町11丁目の埋樋の新規入替〔確認・repo初出の個別事例〕**: 「**麹町拾壱丁目家主徳兵衛…玉川御上水御組合分水…内法壱尺八寸四方 深サ六尺之埋樋壱ヶ所 私店前に有来候処 年来ニ相成朽損候ニ付 此度水口共(?)有形之通新規入替申度奉存候間 別紙絵(図面)…(修復)中日数十五日限**」＝**麹町11丁目の家主が玉川上水の組合分水（私店前の埋樋＝伏樋・内法1尺8寸四方・深6尺）の朽損を受け、新規入替えを願い出た**記録（天保10亥年6月24日の願・五人組・名主与兵衛の連署、工期15日限）＝**上水末端の町方の引取樋の新規伏替（「伏渡」）の願〜伺の実務の全文**（[GOV-289](GOV-289.md)と[GOV-284](GOV-284.md)の代田村分水口と並ぶ末端水利の個別史料）。
- **四谷伝馬町の万年樋筋の分水の取調〔確認・「万年樋」の玉川上水側の用例〕**: 「**四谷伝馬町壱丁目家主七郎兵衛…右御上水万年樋筋ゟ分水請候起立願人名前に年来相立 先年類焼之砌其物等焼失仕段与相分兼…就済井戸数ヶ所当時名書 別紙絵図面幷下ケ札を以奉申上**」＋「**玉川御上水御組合分水井戸浅水有之哉之旨御尋御座候 此段同所新道通御組合分水請候井戸取調候処 別紙絵図之通相違無御座候 尤浅水等一切無御座候**」＝**四谷伝馬町・新道通の「万年樋筋」から分水を請け負う町方の井戸（就済井戸）の起立願人名簿が先年の類焼で焼失し、改めて絵図面で取調べた**記録。**「万年樋」の語が玉川上水側の町方引取でも使われる**用例＝[GOV-232](GOV-232.md)（桜木町の万年樋＝町方書上・神田上水側）との語彙の対校資料（神田・玉川で共通する樋の類型語か）。
- **無願井戸の取潰し＝末端の需要管理〔確認・repo初出級〕**: 「**(無?)願井戸も見付候儀二御座候間 取潰之儀一通り申立候 且願済井戸之分も畢竟銘々引取板数多過分之水懸り故 右躰之始末ニも相成候二付 新道通り組合樋(?)ゟ両側共樋一筋(?)…**」＝**願を出さずに設けられた無願の分水井戸が見つかったため取潰しを申し立て、願済みの井戸についても銘々が引取り板を多くしすぎて水懸り（水の欠乏）になるので、始末（整理）とする**趣旨の文言＝**上水末端で町方が過剰に引取る需要側の管理（井戸の取潰し・引取板の制限）の一次記録**。上水側の給水能力と町方の需要の緊張を幕末期の帳簿レベルで示すdatapoint（浅水・吹水の無き旨の申渡と一体の運用）。
- **町別の出銀・請高のリスト〔確認・対校資料〕**: 「**出銀高一銀百七拾三匁七分五厘三(人?)…(間)数百六拾九間半 此石八千四百(個?)**」「**忍町此内銀七拾壱匁七分五厘…(間)敷七拾間請高 同所伝馬町壱丁目 同(断?)…**」＝塩町・忍町・伝馬町ら四谷御門外の町方の**出銀高と請高（請負延長）の町別リスト**（百六拾九間半・八千四百個の石などの中川通りの文言もあるか・OCR要照合）＝[GOV-270](GOV-270.md)（木挽町九組分水組合樋）・[GOV-284](GOV-284.md)（市中・武家方の給水樋寸法リスト）の系列の天保期の断面。
