- **「貫井＝温井」説の源流と実測の文言群〔確認: 本文直接引用〕**:
  - ①**前田武四郎の寄稿が温井説の情報源**: 「**「貫井」の地名の由来については、湧水が夏は冷たく冬は「温（ぬくい）」からであるとする説が知られています。この説は大正時代に三楽荘を造成した前田武四郎（1867～1931）が、武蔵野会の会報『武蔵野』に大正11年12月に寄稿した一文「貫井は昔し温井と書いた理由」が情報源のようです**」。
  - ②**大正10年の水温実測**: 「この貫井＝温井説の発端は、**大正10年11月28日、前田武四郎がとあるイギリス人を…自分の所有地の杉林にあった「おおせど」の湧水に案内したとき**に始まります。イギリス人は湧水に手を浸して普通の湧水とは違い温かいと言い出し…**12月4日には、今度はイギリス人の方から前田武四郎を誘って、おおせど・貫井神社・新次郎池を回って水温を計り、いずれも摂氏15～16度との結果**」＋「**これら湧水の水温の比較対象として、付近の玉川上水の分水2箇所の水温も測ったところ摂氏9度と9.5度でした。開渠で常に日光に晒されている分水に比べて、湧水は「温い」と二人は結論付けた**わけです」＝**湧水（15～16℃）と玉川上水分水（9℃・9.5℃）の冬季実測による「温い」の根拠**。
  - ③**竹越与三郎の「温井」書物**: 「**竹越与三郎（1865～1950）の訪問によって、前田武四郎は貫井＝温井説を確信するに至ります。竹越与三郎は民友社出身の歴史学者・著述家で、国木田独歩の先輩に当たる人物ですが、貫井についてある書物を読んだところ、「温井」と書かれていたと前田武四郎に教えています。書物のタイトルは書かれていません**」＝**「温井」表記を載せる書物の存在証言（書名不詳＝本資料でも特定されず）**。
  - ④**表記ゆらぎ**: 「**小金井と貫井にも異なる書き表し方があります。小金井…黄金井・金井／貫井…温井・抜井**」＋「**漢字の字面だけで地名の起源を類推するのは、本末転倒に陥る危険性を免れ得ないでしょう**」＋「**ただひとつ言える確かなことは、小金井と貫井は共に水、特に湧水と関連付けてその地名の由来が語られてきたことです**」＝**小金井の異表記群「黄金井・金井」と貫井の異表記群「温井・抜井」の明示＋地名由来論の方法への留意書き**。
  - ⑤**湧水点リストの方針**: 「**現在も水が湧いている場所（★）に限らず、水が枯れてはしまったが過去には湧いていた場所（☆）をも含めて、小金井市域の湧水点を西から東へリストアップしたもの**」＝★①新次郎池・★②貫井神社・☆③おおせど・★④滄浪泉園。
- **湧水点①〜④の文言群〔確認: 本文直接引用〕**:
  - **★①新次郎池（国分寺市南町1-7・東京経済大学構内・[東京の名湧水57選](GOV-488.md) No.36）**: 「**「諏訪の出」と呼ばれ**、小さな沢蟹が沢山いて子どもたちの遊び場でした」＋野川に流れ込む湧水＋「**「新次郎池」は戦後に命名されたもので、東京経済大学学長北沢進次郎（1887～1980）に由来**」＝**57選No.36の正式呼称が戦後命名とする一次説明**。
  - **★②貫井神社（貫井南町3-8・貫井遺跡・57選No.29）**: 「**本殿の西横から水が湧き、社務所手前には小規模な滝があります。ここは改修工事前の野川が、野川全流域のなかで最も国分寺崖線と接近していた場所。現在「湧水の道」と名付けられている遊歩道は、実際は旧野川の流路です**」＝**旧野川最接近点＝湧水の道＝旧野川流路の同定文言**。加えて**『甲武鉄道もより名所案内』（明治23年＝1890）の貫井弁天（貫井神社）案内**: 「**貫井の弁天　国分寺停車場より東十丁貫井村にあり、境内樹木繁茂り至て閑静なる地なり。その祠は丘の半腹にありて、此処より遠く富士、箱根等の山々を見はらし、景色甚だよし。又池あり常に清水湧き出で、流れて瀑布となる。此地四時ともに遊ぶによけれども、就中春は小金井観花の序に来りて桜を賞し、夏は瀑布を浴びて暑を避くるに妙なり**」＝**貫井神社を小金井桜（観花）の「序」（ついで）として設置する観光動線の明治23年一次文言（[対照表](../../地名・河川名対照表.md)「温井橋」行の桜堤観賞定点の明治期継続の傍証）**。続けて「**貫井神社と玉川上水堤の小金井桜は、小金井村観光振興の二大拠点であった**ので、沿線名所案内にはよくセットで載っています。**しかも小金井桜の中心地であった小金井橋の南岸には「貫井遊園地」と書かれた看板が立って**おり、貫井神社一帯を「貫井遊園地」と名付け、小金井桜と共に観光誘致を図っていた」＋昭和5年国分寺駅ホーム名所案内に「**貫井弁財天・国分寺旧址・大国魂神社・小金井の桜**」の4名所が掲示（最寄りは貫井弁財天八丁）＋**貫井プール**: 「大正12年には、**貫井の青年会が小金井最初のプール「貫井プール」を自力で建造**…**昭和48年6月に閉鎖**されています。**湧水を引き込んだプール**で…**その排水路はプール建造以前からあった田圃の用水路を流用**したもので、**この用水路には「おおせど」の湧水も流れ込んでいました**」＝**湧水利用プール（大正12年設置・昭和48年閉鎖）と排水路の展開（旧田圃用水路）の文言**（写真キャプションに「左端は弁天橋」もあり）。
  - **☆③おおせど（貫井南町3-7・貫井遺跡）**: 「**昭和53年に刊行された『小金井市誌Ⅴ　地名編』では「前田邸下」の泉と表現していますが、地元貫井では「おおせど」と呼ばれ、あえて漢字で書けば「大瀬戸」でしょう**。地図上では道の南側（500番）が水源地のように見えますが、**実際には道の北側（501番）が水源地**で道路を横断していました」＋郷土史家**星野進一「大正時代の貫井風景」（昭和57年7月11日小金井新聞）**: 「**前田別荘の南側、低いガケ下を東西に通じる道があり、雑木に囲まれた道の南側には音を立てて落ちるおよそ十尺（三㍍）の滝があった**」＝**地名「おおせど」の一次記録と3m級の滝の景観記録（2026-11-22時点で枯水的な☆評価）**。
  - **★④滄浪泉園（貫井南町3-2-28・はけうえ遺跡・57選No.30）**: 「**嘉永4年（1851）に鈴木家が設置した水車を回していました。この水車は鈴木家の当主弁次郎の名をとって弁車と呼ばれたと、郷土史家芳須緑は書き残しています。鈴木家が水車で賃搗きをしていた地所（527番）は、大正元年に波多野承五郎が買い取っていますが**、大正11年12月に前田武四郎が著した「貫井は昔し温井と書いた理由」には、**「波多野氏は之（湧水）で水車を廻はし米を搗かして居る。」とあります**。ということは**波多野承五郎が鈴木家から取得のちも水車は残っていて、波多野家がそのまま使用していた**のでしょう。**水車があった場所は滄浪泉園の入り口から薬師通りに下る弁車の坂の西側**」＝**嘉永4年（1851）設置の賃搗き水車「弁車」＝玉川上水以北・はけ（国分寺崖線）下湧水系の嘉永期水車の一次文言**（波多野承五郎＝福沢諭吉の弟子で実業家1858～1929・**武蔵野会会員**として前田武四郎と同会）＋**主の変遷**: 昭和12年山田三次郎（大久保利通の甥・旭硝子会長）→昭和14年川島三郎（三井鉱山会長・川島別荘）＝**貫井の豪邸群の主交代系列**。さらに本文中に**『貫井村全図 坂下』（明治8年＝1875・小金井市文化財センター所蔵）の地番記載**: 「**池は539番、水車があった鈴木家は527番**」＋貫井六道の辻付近の田圃文言・**「現在の貫井トンネル東側の国分寺崖線上にまで田圃（黄色）があった**ことが分かります」＝**明治8年地図の池539番・水車（鈴木家）527番・元湧水501番・滝500番の地番と地目配置の一次データ**。
- **三楽荘・日向家の湧水群〔確認〕**: 前田武四郎は**日本電気（NEC）の設立発起人**で、新次郎池は三楽荘系湧水線上にある=三楽の森公共緑地は**三楽荘の跡地**。「貫井は昔し温井と書いた理由」に「**日向氏地内**」の湧水があり「**日向氏は其の水で山わさび葵を作って居る**」＝**湧水の実利用（山ワサビ・葵の栽培）の大正文言**。通信は日向氏を実業家**日向利兵衛（1874～1939）**と推理（前田同様の武蔵野会会員・貫井神社西側にも土地）。日向利兵衛の長女の婿は**田村剛**（本多静六の弟子・国立公園の父）＝**武蔵野会系の貫井地主ネットワーク（前田・日向・波多野＝いずれも武蔵野会会員）の指摘**。
- **間欠加水の記録〔確認〕**: **富永次郎『失われた季節―日本人の記録』（角川新書・昭和31年）**: 「**五、六年に一度の割で、なが雨のあと水が出る。出はじめると、ながい時は四十日ぐらい、数ヵ所から、きれいな清水がコンコンと湧き出す**」＝**国分寺崖線上のムジナ坂西横の自宅（中町1-13-1）の出水記録**〔大岡昇平が『武蔵野夫人』の構想を練った富永邸（昭和23年）〕。

## 意義〔観察〕

- ①**「温井」表記（対照表「温井橋」行・[BOOK-234](../books/BOOK-234.md)の林述斎「温井橋（貫井橋）」〔第254回〕）の由来源流が、**大正11年12月の前田武四郎寄稿「貫井は昔し温井と書いた理由」に特定されるとする通信の説明**＝温井橋の江戸期一次文言（文化3＝1806）が大正期温井説（大正11＝1922寄稿）に**先行する116年分の時間差を伴う同系表記**という対校の材料（江戸期紀行文の「温井橋」と前田説の「温井」表記の直接の系譜関係は本稿では判定せず）。
- ②**嘉永4年（1851）鈴木家の水車「弁車」＝千川上水系水車史（[BLOG-096](../blogs/BLOG-096.md)上保谷新田文政元年1818設置願い・[GOV-501](GOV-501.md)関野分水の19世紀前半水車裁判）と同時代の武蔵野野水車 data pointで、しかもはけ崖線湧水系（玉川上水分水ではなく湧水利用）**＝野川方（はけ線）の水車の系譜区分に寄与。
- ③**『貫井村全図 坂下』（明治8年・小金井市文化財センター所蔵）の地番（池539・水車527・元湧水501・滝500）と貫井トンネル東側までの田圃**＝**明治国初期のはけ線湧水・水車・田圃景観の地図データの所在が明示されたこと**。
