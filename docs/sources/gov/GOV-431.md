# [GOV-431] 天明撰要類集 十三 — 薩摩小路武家組合樋の公儀御組合樋化の経緯（宝暦13〜安永3年）

- **書誌〔確認〕**: 『天明撰要類集』全十三（上水之部を含む行政事例綴・[GOV-215](GOV-215.md)（[49]明地之部）・[GOV-353](GOV-353.md)（[22]御褒美之部）・[GOV-354](GOV-354.md)（[51]火之部）と同シリーズの未登録冊）。NDL次世代デジタルライブラリー [book/2572882](https://lab.ndl.go.jp/dl/book/2572882)。**引用文言はすべてOCR由来で要原文照合**。
- **薩摩小路武家組合樋の記録群〔確認・repo初出〕**: 目録に「**薩摩小路上水樋之儀に付先年組合え達候趣上水方ゟ問合来返書付**」等の上水之部の項目——「**玉川上水薩摩小路樋筋之儀依田豊前守其御役所勤役之節武家方之分堀井追々出来上水不引之由断有之明和元申年迄ニ不残上水引取相止候處右樋筋より幸橋御門山下御門江上水相掛り候ニ付武家方ニ而は不用之樋ニ候得共右樋通り絵図面桃色紙附候水末樋筋は其侭差置**以来**公儀御組合樋ニ相成**」”（安永3年5月29日状・町奉行衆久松筑前守・青山但馬守・山田十太夫・佐々木伝次郎）＋「**公儀御組合ニ相成候儀者宝暦十三未年右組合之内松平大膳太夫殿堀井有之上水不用之由に而上水引取被相止度旨御断有之右に付障有無等之儀依田豊前守殿御尋に付公儀御割合出銀被差出候得者水口被相止候儀例も有之…則水口被差塞候其後右組合内松平信濃守殿松平美濃守様亀井能登守殿隅島(?)伊三郎殿小笠佐渡守殿追々右同様之御断有之**」（宝暦13年から順次の武家方の引取停止と公儀御割合出銀による水口差塞の経緯）＋「**先達而ゟ追々水口相止又は右武家方水口に相止候得は不残水口相止候故薩摩小路武家組合上水樋退転可仕候右組合樋筋ニは幸橋御門番所廻り上水御入用樋仕付有之并山下御門番所向に有之候右組合桝之上水は山下御門番所に而相用有之候**」（水口の全面停止の懸念＝組合樋の退転の危機と、**幸橋御門番所廻り・山下御門番所の上水御入用**が組合樋存続の根拠）＋町年寄（喜多村彦右衛門・奈良屋市右衛門・樽屋藤左衛門）差出の書付（安永3年6月25日）・左曲淵甲斐守の達（6月28日）＝**宝暦13年（1763）の松平大膳太夫家の堀井の水引取停止断を起点に、明和元年までに武家方の私的な水引取がすべて止まり、その間に武家方の組合樋筋が「公儀御組合樋」化した経緯と、その後の水口管理制度（公儀御割合出銀による停止・幸橋御門・山下御門番所の水利用の保障）を、安永3年の伺・町年寄書付・奉行達の三点セットで記録する一件**。
