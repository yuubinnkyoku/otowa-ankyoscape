# [GOV-470] 七十冊物類集 [32]・[52] — 元千川上水屋鋪の帳簿リスト化と立負人貸附の棄捐決着

- **書誌〔確認〕**: 『七十冊物類集 71巻』[32]三十一 火之元之儀被仰出并御組火之元守方之部（NDL [book/2548592](https://lab.ndl.go.jp/dl/book/2548592)）・[52]五十一 町年寄地割并鈴木藤吉郎之部（NDL [book/2548612](https://lab.ndl.go.jp/dl/book/2548612)）・写本OCR。**引用文言はすべてOCR由来で要原文照合**。
- **寛政2年御組屋敷廻ケ所伺書抜の「元千川上水屋鋪」〔文言候補・本登録の核心1〕**: 「**寛政二年御組屋敷廻ケ所伺書抜 一南茅場町添地 但御坊主拝領地町屋一同所 元千川上水屋鋪 一山王旅所門前 一坂本町 一神田紺屋町代地（以下略）**」（[32]と同文の引用が[52]にも重出）＝**寛政2年（1790）の御組屋敷廻ケ所の伺書抜きの中で、南茅場町添地の屋敷群のひとつとして「元千川上水屋鋪」がリスト化された文言**。〔**南茅場町の千川屋敷 ([GOV-215](GOV-215.md)・[GAZ-082](../gazetteers/GAZ-082.md)「里俗呼名千川屋鋪」・[GOV-230](GOV-230.md)千川屋敷家主亀次郎は小石川側)が、なお「元千川上水屋鋪」の屋敷名で帳簿上は屋敷の1戸として扱われている1790年時点の座標**。天明7年（1787）の上水廃止の3年後に書かれた屋敷側の実務帳簿として、廃止後に確認される数少ない「千川上水」呼称の実名用例**〕。
- **千川上水立負人への貸附の棄捐と決着〔文言候補・本登録の核心2〕**: 「**亥十二月 天明二寅年ゟ年々御合戦候内相成…千川上水立負人共 小舟町次兵衛 御蔵前札差共 右三口御貸附返役銭金 棄捐相成候分…屋敷御取上相成候ニ付右返納銭人而之分上り地面ヲ以文政三辰年…**」＋「**壱万三千五百八十兩…千川上水三ヶ村人并小船丁次兵衛 御蔵前に差共…返納残金…文致三辰年(=文政三辰年)ニ而皆納相成申候**」＝**①天明2寅年から年々の幕府の貸附（御貸附返役銭金）として千川上水の立負人（小舟町次兵衛・御蔵前札差・三ヶ村人等）が借受け、②棄捐（棄捐令による免除・帳簿整理）と屋敷取上を経て、③差上げた地面（地所返納）で弁済し文政3辰年（1820）に皆納した一件**。〔**千川上水再興の立負人（出資人）が、天明2年の通水開始直後から幕府の貸附金の返済に当たっていた財務の実態と、天明の棄捐令（金銀融通の絡み）→文政3年の決着までの帳簿側の初出**。金額（2万3878両2分・1万3780両・1097両2分等の並記群）は列崩れで要照合**〕。
