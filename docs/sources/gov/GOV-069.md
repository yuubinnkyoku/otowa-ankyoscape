# [GOV-069] 古老が語るねりまのむかし「千川上水沿いの水車」

- **書誌〔確認〕**：聞き手・練馬区史編さん専門委員北沢邦彦、原記事平成元年10月21日号区報、サイト再録2020年12月28日。2026-11-11時点で当該サイトはopen_url不可のため、[Wayback Machineの2026年4月7日スナップショット](https://web.archive.org/web/20260407214013/https://www.nerima-archives.jp/column/1623/)で本文全文を確認。証者は斉藤泰治さん（明治42年、現・南田中生まれ）。
- **斎藤水車の経営〔確認：証言〕**：南田中1丁目の水車は元は鴨下氏が経営。大正12年8月1日に従兄・斉藤倉之助が引き継ぎ、その死後、昭和5〜6年頃（証者22歳時）に泰治氏が引き継いだ。〔[GOV-067](GOV-067.md)の「斎藤水車（南田中1-22）」の経営系譜〕
- **取水構造〔確認：証言〕**：千川上水は家の南側の通りのほぼ中央を流れ、**堀幅は1間半（約2.7m）**。そこから**幅6尺（約1.8m）の水路**を分けて水車へ。**取入口は環八通りとの交わり付近**。水車は直径7mで下穴に沈める形式、使用水は千川上水に返した。**土揚敷（土手）使用料を東京府に支払い、取入口1箇所＋排水口2箇所の計3箇所に課税**。
- **稼働と終焉〔確認：証言〕**：精米・製粉が主（挽臼4・搗臼2・杵12、大正末に精米機導入）。昭和15年、玉川上水の水を村山貯水池へ溜める干害で半年断水し電気を導入（電柱22〜23本の費用を負担）。昭和19年7月2日の応召による3か月の操業停止で水車が使えなくなり、以後は電気のみ。周辺田んぼの消失で**昭和30年頃に廃業**。
- **暗渠化の時期〔確認：証言〕**：「その頃には、ずいぶんお世話になった千川上水も暗きょになっていました」。**南田中付近の千川上水は証者の認識上、昭和30年頃までに暗渠化済み**。〔千川上水練馬区間の暗渠化着手「昭和27年3月以降」（[GOV-056](GOV-056.md)）と整合する時期絞り込みの根拠。1971年の大蔵省印刷局への給水停止（第1回調査ノート参照）まで水が流れていた区間とは別の場所的・時間的問題であり、混同しない〕
- **写真資料〔確認〕**：「八成橋脇の水車（年不詳）」の写真が記事に掲載。
- **制限〔未解決〕**：廃業「昭和30年頃」および暗渠化認識は個人的記憶であり、区間・工事年次の文書による裏付けではない。八成橋の位置特定は未実施。
