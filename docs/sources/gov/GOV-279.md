# [GOV-279] 玉川上水留 安政4〜5年 — 四谷大通万年石垣樋枡の修復と御本丸・吹上の給水

- **書誌〔確認〕**: 『玉川上水留』「玉川上水四谷大通万年石垣樋枡御修復御組合入用一件　安政四巳年正月より同五午年三月迄」（全1冊）[book/2587400](https://lab.ndl.go.jp/dl/book/2587400)。repo未登録（「御本城」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔[GOV-277](GOV-277.md)安政3年の四谷御門外南之方修復の続編にあたる四谷方面の修復帳簿。〕
- **四谷塩町三丁目〜御堀端の万年石垣樋枡の地震損修復〔確認・repo初出の文言〕**: 「**四谷塩町三丁目ゟ御堀端迄万年石垣樋枡御修復**」＋「**玉川上水四谷大木戸際塩町三丁目ゟ御堀端辺万年石垣樋筋地震損御修復ニ付 向々御掛合済之上過日水留いたし候処 然る處此以後水移替之度々水留仕事為致候儀二有之**」＝**四谷大木戸際の塩町三丁目から外堀端までの「万年石垣樋枡」が地震損（[GOV-277](GOV-277.md)の安政2年10月の地震=安政江戸地震の被害と連続すると推定されるが、本冊の文言単独では地震の特定年は書かれおらず断定しない）を受け、安政4-5年に修復された**＝現在の新宿区四谷塩町（四谷大木戸の内側）から外堀端（外苑前・青山方面）までの樋管の被災修復記録。
- **御本丸掛・吹上掛樋筋の文言〔確認・repo初出級〕**: 「**前々御本丸掛吹上掛樋筋御普請御修復ニ而水留刻限明六時ゟ暮六時迄之御掛合済…可成丈手繰為致 八時過ゟは少々宛水仕掛取掛**」＋「**御本丸懸吹上懸共代官町土手上柳(?)…定寸ニ相掛申候**」＝**四谷大通万年石垣樋枡の修復に際し、御本丸掛・吹上掛の樋筋（江戸城本丸・吹上御殿への給水管）の水留の刻限が問題となり、修復後は御本丸掛・吹上掛とも代官町土手上（麹町代官町の土手上）を経由して定寸（通常の水位・流量）に戻した**＝**御本丸・吹上への給水樋筋が麹町代官町の土手上を通ることの安政期の文言**＝[GOV-271](GOV-271.md)（明治2年・御本城掛樋筋が代官町土手上を経由）・[GOV-280](GOV-280.md)（安政4-5年・「代官町土手上ゟ御本丸掛矢来桝弐之枡」）と3点対応で、**御本城（丸）掛樋筋の経路（麹町代官町土手上経由）が幕末を通じて不変だったことの傍証**（「柳」の字はOCR崩れの可能性が高く原文照合必須）。
- **城内御門群13か所への触出し〔確認・repo初出の最長の御門リスト〕**: 「**御門々上水相懸不申候旨(?) 外桜田御門 馬場先御門 和田倉御門 呉服橋御門 鍛冶橋御門 日比谷御門 幸橋御門 数寄屋橋御門 山下御門 触出し 虎御門 右番頭中 竹橋御門 半蔵御門 西番所 触出し 右番頭中**」＝**玉川上水が城内の御門群（外桜田・馬場先・和田倉・呉服橋・鍛冶橋・日比谷・幸橋・数寄屋橋・山下・虎・竹橋・半蔵・西番所）に給水していることの明示と、水留の際の触出しの定型**＝[GOV-275](GOV-275.md)（弘化3年）・[GOV-277](GOV-277.md)（安政3年）の御門リストに竹橋・半蔵・西番所が加わった最長のリスト＝城内全域への給水網の規模の指標。
