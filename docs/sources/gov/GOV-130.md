# [GOV-130] 豊島区「わが街ひすとりぃ 第14回 要町 現地ロケ編」

- **書誌〔確認: ADEAC目録・全文テキスト取得〕**: 豊島区デジタル区史「としまひすとりぃ」広報番組。**収録日 令和元年6月6日、制作 令和元年9月、収録時間14分37秒**。出演: **稲富文子・山田和夫**（ほか本橋勇・本橋香里・見米初枝の各氏）。[ADEAC目録ページ](https://adeac.jp/toshima-history/catalog/mp00001410)、[現地ロケ編全文テキスト（ht420140）](https://adeac.jp/toshima-history/texthtml/d000000/mp00001410/ht420140)。
- **要小学校前の「泥水の川」と長靴通学〔確認: 全文テキストの直接引用（伝聞）〕**: 稲富氏は要小学校（**昭和29年創立**）の初代校長について「**初代校長さんはもっとその前ですけど、学校の前に泥水の川があって。だからもう、学校に行くのに毎日、長靴履いて行ったよって。すごくご苦労されたっていうのは聞きましたね。**」と語る〔**谷端川水源地に近い要町の低地（要小学校周辺）に、開渠ないし泥溝状の水路の記憶が伝わる初の公的聞き取り記録**。ただし二重の伝聞（初代校長の回想の伝聞）であり、川の正体（谷端川本流・分水・用水の残置・道路側溝）・年代・正確な位置は本文中で特定されない〕。同じ場面で本橋勇氏が要小学校を「**長崎第二尋常小学校だった**」と補足する〔確認: 全文テキスト〕。
- **粟島神社=弁天様呼称の地域確認〔確認: 全文テキスト〕**: 粟島神社（要町2丁目・谷端川水源の弁天池で知られる）の前で山田氏が「**ここが粟島神社です。まあ、我々は弁天って言ってるかな。**」、稲富氏が「**弁天さんって言ってますけど。**」と応じる〔要町の古老が粟島神社を日常的に「弁天」と呼ぶことの確認。第15回千早（[GOV-128](GOV-128.md)関連のREADME千早bullet）の「弁天様の湧き水」証言を読む際の呼称の裏付け資料。ただし千早証言の「弁天様」を本文だけで粟島神社と断定する扱いは不変〕。
- **すずめが丘アトリエ村〔確認: 全文テキスト〕**: 山田氏が要町あさやけ子ども食堂周辺で、藝大生向けにアトリエが相次いで建てられた「**すずめが丘アトリエ村**」（道しるべあり）を案内する〔長崎・千川方面のアトリエ村群（さくらが丘・すずめが丘）の既知記録に対応。川との位置関係の言及はない〕。

## 制限・未解決

- ①「泥水の川」の一次叙述は初代校長自身のものではなく**伝聞の伝聞**であり、校長の通学年代（学校は昭和29年創立で、叙述は校長の幼少期＝戦前の可能性を含む）・川の位置・川種は未確認。②「弁天様の湧き水」（第15回千早）と粟島神社弁天池の同定は、本資料の呼称確認で可能性が上がるのみで断定しない。③すずめが丘アトリエ村の成立年代・範囲は本文中に特定情報がない。
