# [GOV-411] 練馬区「公道、私道の区別について」〔repo初出・公共溝渠の制度的定義の現行文言〕

- **書誌〔確認: 練馬区公式HP本文取得・2026-06-18更新〕**: 練馬区公式HP「**公道、私道の区別について**」、**ページ番号948-477-170**、**更新日2026年6月18日**（2026-11-19に本文を直接取得）。URL: [chosa.html](https://www.city.nerima.tokyo.jp/kurashi/sumai/doro/chosa.html)。
- **核心文言〔確認: 本文〕**: 区は道路を「**区道等**」として管理し、区道等には「**道路法に基づく区道**」と「**練馬区有通路条例に基づく区有通路**」がある。加えて「**道路ではありませんが、公共溝渠と呼ばれる水路がある**」＝**「公共溝渠」＝道路法にも区有通路条例にも当たらない、区が管理する水路としての第三分類**という現行制度の定義文言（repo初出の公式定義）。**区道・区有通路・公共溝渠のすべてに路線番号が付番されている**ことも本文で確認。
- **GIS閲覧可能性〔確認: 本文〕**: 「**地図情報ねりまっぷ**」のテーマ「**区道等の現況（参考公開）**」で**区道等のGIS閲覧が可能**＝**練馬区内の公共溝渠（区管理水路）の路線の位置的データをGISで参照できる公式手段**として重要〔ねりまっぷの当該テーマが公共溝渠の水路ポリゴン／ラインまで含むかどうかはIIIF・Webアプリ側の確認が未了のため断定しない＝「区道等」に公共溝渠が含まれる文言上の含意（路線番号付番対象）は確認済み〕。
- **位置づけ〔観察〕**: ①[PAP-065](../papers/PAP-065.md)（桃園川＝昭和27年準用河川認定・上流は公共溝渠）・[PAP-083](../papers/PAP-083.md)註10（**練馬区では昭和28（1953）年に「練馬区公共溝渠管理条例」が公布**）と接続する現行制度側の資料＝**練馬区の「公共溝渠」制度が2026年時点でも路線番号管理・使用許可（[GOV-412](GOV-412.md)）として運用され続けている**ことの公式裏付け。②千川上水系（中新井分水・濯川等）や谷端川源流（田柄川系）・弦巻川系の練馬区内における都市計画決定河川以外の水路網は、この公共溝渠管理の対象として現在も路線データが存在している可能性を示す（個々の水路の該当性はねりまっぷでの確認待ち）。
- **制限・未解決**: ①ねりまっぷ「区道等の現況（参考公開）」テーマの実際のデータ内容（公共溝渠ラインの有無・属性）は未確認。②公共溝渠の総延長・路線数の公式統計は未確認。③本ページと練馬区公共溝渠管理条例（g-reiki・403遮断中）の条文レベル接続は原文取得待ち。
