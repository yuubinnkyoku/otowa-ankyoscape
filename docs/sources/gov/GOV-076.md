# [GOV-076] 千川上水調査アルバム（練馬区登録文化財）

- **書誌〔確認〕**：練馬区公式サイト「指定・登録文化財」頁（ページ番号595-302-741、更新日2026年2月2日）。2026-11-11にopen_urlで本文直接確認。
- **内容〔確認〕**：武蔵高等学校交友会文化学部が**昭和13〜16年（1938〜1941年）に調査した千川上水の写真などの記録**。**4冊のアルバムに、武蔵野市境橋付近の玉川上水分水口から豊島区の千川上水公園までの本流や落合分水流域など200カットあまりの白黒写真**を収録。成果は『千川上水』（**石山乾二**、昭和16年武蔵高等学校報国団文化部民族文化部門）として刊行。
- **文化財〔確認〕**：**平成17年度練馬区登録文化財**。所在地は**武蔵学園記念室（豊玉上1丁目26番）**（江古田駅徒歩6分）。問い合わせ先は地域文化部文化・生涯学習課伝統文化係・武蔵学園記念室（電話03-5984-3748）。
- **意義〔確認の集積〕**：①[BLOG-112](../blogs/BLOG-112.md)（武蔵高校生徒の昭和15年調査・庚申橋下流の釣堀と谷端川分水）・第12回ノートのsirakigi写真展で問題にしていた**『千川上水』原本（写真アルバム）の所在と管理体制が、区登録文化財として公式に判明**〔第20回ノートの次回課題「武蔵高『千川上水』（昭和16年刊）原本の所在確認」を解消〕。②1938〜1941年の開渠時代の全流域写真200カット超が現存し閲覧先が明示されていることは、**流路・樋・水車・橋の1938〜41年時点の状況を画像で確認できる資料群**である（庚申橋・長崎村分水・谷端川分水口が写っているかは実物確認待ち）。③調査主体の表記は区ページ「交友会文化学部」に対し刊本書誌は「報国団文化部民族文化部門」。武蔵学園百年史関係サイトの「1941年1月、校友会は報国団と改められる」との記述で説明できる可能性があるが断定しない。④アルバム枚数は[BLOG-113](../blogs/BLOG-113.md)（武蔵学園記念室の写真展解説）では「約160枚」と表記が異なる。区ページ（200カットあまり）と記念室側（約160枚所収）のどちらが正確かは実物確認まで保留。
- **sirakigi senkawa11 頁（スニペット確認・2026-11-12）**：[BLOG-113](../blogs/BLOG-113.md)で問題にしていたsirakigi「千川上水展」頁（wwr3.ucom.ne.jp/sirakigi/senkawa11.html、直接open・Waybackとも不可）の検索スニペットを取得。「**昭和１６年発行の写真アルバムから当時の写真約１００枚（モノクロ）と解説を収録し、平成８年に武蔵大学の学芸員課程の３名の学生と共に調査し、千川上水開削３００...**」〔**平成8年（1996年・開削300年）に武蔵大学学芸員課程の学生3名と共に再調査が行われたこと、同頁掲載写真が約100枚であることの記録としてrepo初出**。アルバム総数の表記差（区ページ「200カットあまり」・[BLOG-113](../blogs/BLOG-113.md)「約160枚」・同頁「約100枚」）に第3の数値が加わった。展示時にどの範囲を抜粋したかの違いと考えられるが断定しない〕。
- **注意〔制限〕**：アルバムは文化財登録名であって一般に全コマが公開されているわけではない。閲覧は武蔵学園記念室の展示・窓口経由が前提。
