# [GOV-242] 神田玉川上水留（明治2年）— 金剛寺橋掛直御普請の仕様・工費の帳簿群

- **書誌〔確認〕**: 『神田玉川上水留』（東京府・明治2年（1869）の神田上水・玉川上水の行政記録。NDL次世代デジタルライブラリーで[1]〜[33]が公開）。金剛寺橋掛直御普請の関係冊として[11] [book/2587527](https://lab.ndl.go.jp/dl/book/2587527)（明治二巳年正月より 分冊ノ四）・[12] [book/2587528](https://lab.ndl.go.jp/dl/book/2587528)（同 分冊ノ五）・[13] [book/2587529](https://lab.ndl.go.jp/dl/book/2587529)（同 分冊ノ六）・[17] [book/2587533](https://lab.ndl.go.jp/dl/book/2587533)（明治二巳年正月より七月 分冊ノ四）・[18] [book/2587534](https://lab.ndl.go.jp/dl/book/2587534)（明治二巳年七月より十二月 分冊ノ一）・[29] [book/2587542](https://lab.ndl.go.jp/dl/book/2587542)（明治二巳年六月より十二月 分冊ノ三）がhit（本文の精読は[11][17][29]）。[GOV-237](GOV-237.md)（[24][26]分冊）と同じ明治2年の神田上水の記録群。**引用文言はすべてOCR由来で要原文照合。**
- **金剛寺橋掛直の仕様〔確認・repo初出の構造数値〕**: 「**神田上水白堀通金剛寺橋掛直御普請仕様注文**」——「**一橋渡長三間四尺 巾犬走り共九尺 高高サ弐尺五寸**」（[17]・2587533）／「**一橋渡長三間四尺 幅丈走共五尺 高浜(サ?)弐尺五寸**」（[29]・2587542の業形仕上内訳）＋「**小日向金剛寺橋渡り三間四尺内九貫目高高弐尺五寸**」（[17]）＝**金剛寺橋（小日向・白堀通の橋）の架け替え（掛直）の仕様: 橋渡り長3間4尺・高2尺5寸、幅は「犬走り共9尺」と「丈走共5尺」の2系のOCR文言（幅5尺+犬走りで9尺か・要照合）**。柱・桁・栗木等の材木の内訳つき（栗木1尺角長2間・代金3両1分1朱等）。
- **金剛寺橋の位置の文言〔確認〕**: 「**小日向金剛寺橋**」（[17]）＝**金剛寺橋が小日向側（小日向〜小石川の白堀区間）の橋**であることを明治2年の府の帳簿が明記（[GOV-232](GOV-232.md)弘化の「金剛寺坂下石垣」・[GOV-238](GOV-238.md)「金剛寺坂下橋」・[GOV-241](GOV-241.md)延享4年「神田上水白堀ニ相懸り候金剛寺橋」・[GOV-237](GOV-237.md)明治2年「金剛寺橋上之方堤急破」と対校できる橋名の継続記録）。
- **工費〔確認〕**: ①「**神田上水白堀通金剛寺橋掛直御普請御入用高 金六拾弐両壱分水(永?)四拾九文六分 内金四拾九両三分 永八拾九文六分八厘**」（[11]・巳八月出来月の記録と読める文言・要照合）②「**神田上水白堀通金剛寺橋掛直御普請諸職手間御請負帳**」（[17]・請負吉田屋正蔵）＝「**諸職手間一式…合金弐拾五両三分ト永弐百拾弐文九分七**」（大工木挽台伐共・人足運送等の合計）③「**神田上水白堀通金剛寺橋掛直御普請御入用出来所仕上内訳帳**」（清水元一郎・[29]）＝**掛直の総入用（62両1分余）と諸職手間（25両3分余）の帳簿レベルの記録**。
- **堤急破との関係〔確認・[GOV-237](GOV-237.md)の対校〕**: 「**九月三日…神田上水白堀通金剛寺橋上之方堤急破道内洗流候に付右場所差向車差留申度**」（[11]）＋「**神田上水白堀通金剛寺橋上之方浅水九月** 黒澤土木大令史 明治二巳年」（[18]）＝**明治2年9月3日の金剛寺橋上之方の堤急破（[GOV-237](GOV-237.md)の御普請取掛・車差留・制札と同一事件）に続いて、金剛寺橋自体の掛直（架け替え）が行われた過程**。
- **龍閑橋際石垣通の余垂板普請〔確認・周辺〕**: 「**神田上水龍閑橋際石垣通依余垂板其外御普請御入用高 金三拾八両 永百五拾五文五分 内金三拾両 永五百弐拾四文四分**」（[11]・金剛寺橋掛直と同頁の入用高リスト）＝**龍閑橋（神田川の龍閑橋・御茶ノ水付近）際の石垣通の余垂板普請38両の記録**＝「余垂板」（[GOV-232](GOV-232.md)弘化3〜4年の白堀通の主要構造材）が明治2年時点でも神田上水の別区間（龍閑橋際）で使われている記録（白堀通から下流への構造の継続の傍証・龍閑橋の帰属区間は要照合）。
- **掛直の年月日〔確認・2026-11-15第115回追記〕**: [25] [book/2587541](https://lab.ndl.go.jp/dl/book/2587541)（明治二巳年正月 分冊ノ三）の記録に**明治2年6月20日往来差留→6月22日取掛→6月29日相通（完工通行）**の工程の日付と「金剛寺坂橋」「令剛寺坂橋」（OCR変種）の表記＝**本ファイルの仕様・工費（[11][17][29]）に対し掛直の工程の年月日を補強**（[GOV-248](GOV-248.md)に詳しい。6月の掛直完工と9月の金剛寺橋上之方堤急破〔[GOV-237](GOV-237.md)〕の前後関係が確定したことになるが、両事件の因果は断定しない）。

## 制限・未解決

- ①すべてOCR由来で、仕様の幅（「犬走り共九尺」／「丈走共五尺」の対立）・「高浜」・入用高の通貨単位（「水」は「永」の誤読か）・「巳八月出来月二七」等の年月日の割付は原文照合を要する。②[12][13][18]の全内容の精読は未実施（同一事件の伺・届出の段階差と推定）。③金剛寺橋掛直の設計前提（堤急破で橋台が失われたための掛直か、老朽化による計画的架替か）は本冊群のみでは確定できない。④龍閑橋際の石垣通が白堀区間（小日向〜小石川）の延長上にあるかは位置関係の照合後に判断。
