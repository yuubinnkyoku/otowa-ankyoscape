# [GOV-519] 豊島区「大塚台公園の基本計画案について」〔repo初出・谷端川流域の区立公園の親水施設「未復旧」の行政一次文言〕

- **書誌・所在〔確認: ページ本文・2026-11-23取得〕**: 豊島区公式サイト「まちづくり・環境・産業 > 公園・緑化 > 公園 > 取り組み > 大塚台公園の基本計画案について」。**ページID 56313・更新日2026年9月4日**。 https://www.city.toshima.lg.jp/610/ootukadai/2604210807.html 〔同ページ親族の後続ページ＝リニューアル工事〔[GOV-520](GOV-520.md)・[GOV-521](GOV-521.md)〕と**同一ディレクトリ `/610/ootukadai/` のシリーズ**〕。
- **公園の概要〔確認: 本文〕**: 「**大塚台公園（面積：3546.9平方メートル　住所：南大塚3-27-1）は、昭和48年に開園し、山手線大塚駅から徒歩5分の立地である**ことや、遊具が多く区内に数少ない球技場があることから、多くの区民の方々が利用しています」＝**昭和48年（1973年）開園・3546.9㎡・南大塚3-27-1・山手線大塚駅徒歩5分**〔池袋タイムズの報道では「1973年（昭和48年）2月開園」〔[BLOG-290](../blogs/BLOG-290.md)〕・区本文の開園年は「昭和48年」のみ〕。
- **親水施設の「未復旧」文言〔確認: 本文・repo初出・本資料の核心〕**: 「一方で、**開園から52年が経過しており、公園施設や遊具、展示蒸気機関車の老朽化が激しいことや、昔あった親水施設が保育園仮園舎の建設により未復旧となっています**」＝**①かつて親水施設が存在したこと②保育園仮園舎の建設により失われたこと③以後未復旧であること、の3点が区自身の文言で記録されている**〔いつから親水施設があり、仮園舎の建設が何年か、撤去が何年かは本文に記載なし＝年代は特定できない〕。
- **基本計画案の施設構成〔確認: 本文〕**: 「多様な年齢層が楽しめる総合的な機能を持つ公園」として①**親水施設**②球技場③既存トイレのリフォーム④だれもが遊べる遊具広場（インクルーシブ、幼児、小中学生向け）⑤多目的広場⑥**都電側入り口新設**⑦バラの植栽。親水施設のイメージは「**夏は親水施設として、冬は複合遊具として遊べる施設**」〔夏のみの水遊び施設ではなく通年遊具という設計思想の区側一次文言〕。「注）基本計画案のため、詳細検討により変わることがあります」・「注）高木植栽の中に、サクラも含まれています」。
- **スケジュール・意見募集〔確認: 本文〕**: 「今後のスケジュール（**令和7年9月時点**）: 令和8年10月 工事着手／令和10年3月 しゅん工」＝**のちにリニューアル工事ページ（[GOV-520](GOV-520.md)・令和8年10月時点）で「令和8年11月18日着工・令和10年3月末完成」へ精緻化**。基本計画案への意見募集は**令和7年9月16日〜10月15日・総意見数236件**（「皆様からいただきましたご意見は出来る限り設計業務へ反映してまいります」）。目安となる近隣の言及＝「町会や近隣小中学校等のご意見を踏まえ」を作成経緯と明記。
- **意義〔観察〕**: ①**南大塚3丁目（谷端川上流流域・高橋俊一「谷端川の跡を歩く 南大塚編」系の関心区域）の区立公園に、かつて親水施設が存在し仮園舎建設で失われたという行政側の一次記録**＝谷端川流域の親水施設史（[GOV-106](GOV-106.md)千川上水公園・[GOV-496](GOV-496.md)沈澱池復元・[GOV-113](GOV-113.md)千川親水公園）に公園単位の新例を加える。②**「夏は親水・冬は複合遊具」の通年設計**と令和7〜8年区政の親水系方針（[GOV-518](GOV-518.md)公園等再構築プランの親水施設配分方針）が同じ時期に並走する＝区全体の水遊び施設の再配置の一環として読める〔計画間の因果は本文になく断定しない〕。③展示蒸気機関車（[BLOG-291](../blogs/BLOG-291.md)＝C58 407号機の二次報道）の老朽化文言が区自身にもある。
- **制限・未解決**: 元々の親水施設の設置年次・仮園舎の建設年次・仮園舎の現在状況（本園舎完成で仮園舎解体済みか・親水施設の旧位置）は本文から特定不能。テキスト取得ベースで、図-1平面図・図-2パース図の画像内容は未判読〔完成パースは[GOV-520](GOV-520.md)〕。
