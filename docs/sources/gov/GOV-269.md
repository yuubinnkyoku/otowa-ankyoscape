# [GOV-269] 神田玉川上水留 明治2年十二月 — 小石川水戸屋敷内の神田上水掛樋の普請

- **書誌〔確認〕**: 『神田玉川上水留』明治二己年六月より十二月マデ分冊ノ五止 [book/2587544](https://lab.ndl.go.jp/dl/book/2587544)（麻布方面の道造・桝等の記録が主体の分冊に神田上水側の記録を含む）。**引用文言はすべてOCR由来で要原文照合。**
- **小石川水戸屋敷内の神田上水掛樋の普請出来形内訳帳〔確認・repo初出の構造数値〕**: 「**関口大令史 服部少令史 小石川水戸(屋?)屋敷内神田上水掛樋御普請出来形内訳帳**」——「**一樋長拾七間四尺 弐間樋ニシテ八本…幅五尺 葉(深?)四尺**」「**此入用 側板敷板二遣ス檜壱尺三寸角六拾弐本…内柱梁…流板…護木二遣…樋跡先押柱…笠木押柱**」＝
  - **小石川の水戸屋敷内を神田上水（白堀）が「掛樋」（架樋＝地上に架けた水路橋・木樋）で通過していた**ことを示す明治2年の府の帳簿＝[GAZ-049](../gazetteers/GAZ-049.md)⑬「白堀上水…水戶殿屋敷に入る」・[GOV-262](GOV-262.md)「水源之儀水戸殿御屋敷内より流出し…上水ゟ車越仕掛」・[GOV-236](GOV-236.md)巡視路「牛天神下水戸様御屋敷境」と対校できる**白堀の水戸屋敷区間の通水構造の定量記録**（樋長17間4尺＝2間樋8本継ぎ・幅5尺・深4尺）。
  - 「**樋跡先押柱…立入一本**」等の部材の呼称・本数の内訳つき＝掛樋の構造（側板・敷板・内柱梁・流板・護木・押柱・笠木）の部材レベルの記録。
  - **水戸屋敷内区間が開渠（堀）ではなく掛樋だった**と読める点は、[GOV-262](GOV-262.md)の「庭中水車取建…神田掛差支」の水留一件（屋敷内の水路の操作が水車一件の帰結を左右した）と整合するが、全期間を通じて掛樋だったか（本普請が新規か修繕か）は本冊のみでは断定できない。
- **神田橋御門外の白川神祇大副拝借地の掛樋筋の修復〔確認・周辺〕**: 「**神田上水神田橋御門外白川神祇大副拝借(地?)掛樋筋御修復御入用仕上帳…竹樋長五拾六間四尺 注文内(差引?)男五拾五間三ヶ人**」（巳十一月）＝神田橋御門外の白川家（神祇大副＝白川伯王家）の拝借地を掛かる竹樋（長56間4尺）の修復記録＝上水末端の町屋給水の竹樋の実例（[GOV-237](GOV-237.md)の桜田太左衛門町の竹樋8ヶ所と同系の上水末端構造）。
- **掛樋の前後両側の石垣の築造〔確認・第121回追記・repo初出の構造数値〕**: 「**掛樋前後両側一石垣長建拾三間半高五尺此面坪拾壱坪弐合五勺**」＋「**土台…栗押五寸角拾四本…面杭ニ遣栗丸太拾四本長壱丈…石垣ニ遣間地石百九拾三本…成シ割粟石七坪五合…砂利三坪…**」（亥十一月）＝**水戸屋敷内の掛樋の前後両側に長13間半・高5尺の石垣（面坪11坪2合5勺）を築いた**入用記録＝**掛樋の前後（樋の両端の擁壁）の石構造の定量記録**（土台の栗押・面杭の栗丸太・間地石193本・粟石の投入の部材内訳つき）＝[GOV-267](GOV-267.md)の白堀通の下水石垣（高2尺5寸）・[GOV-242](GOV-242.md)の龍閑橋石垣樋脇と並ぶ上水施設の石垣の規格群。「前後両側」＝樋軸に沿う両側か樋の両端かの割付は要照合。
- **「関口」の人名用例の注意〔確認・陰性〕**: 本冊の「**関口大令史**」「**関口大木大金史**」は**維新期の府の技師（土木大令史）の人名**で、関口村とは無関係＝『神田玉川上水留』内の「関口」hitには人名のfalse positiveがあることの記録（[GOV-243](GOV-243.md)の神田音羽町と同様の注意書き）。同帳簿の宛名「**関口大令史 服部少令史**」＝明治2年の府の土木担当の令史の連署の実例。
