# [GOV-004] 千川上水の開削・農業用水利用

- 練馬区「千川上水跡」。
- https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/rekishibunkazai/bunkazai/b047.html
- 東京都建設局「千川上水」: https://www.kensetsu.metro.tokyo.lg.jp/jimusho/yonken/koji2/senkawa
- 1696年に玉川上水から分水、1707年に沿線20か村が田へ引水することを許されたことを記す。
- **〔2026-11-11 追記・本文直接確認（ページ番号463-161-182、更新日2026年1月9日）〕**：
  - **設計は河村瑞軒（1617～1699年）と伝えられ**、仙川村出身と伝えられる徳兵衛・太兵衛が工事を請負った。
  - 分水口から巣鴨までの費用は**1千340両余りを要し、幕府が支出したのは860両余り**。2人は**私費を投じて工事を成し遂げた**〔[GOV-077](GOV-077.md)（練馬わがまち資料館）の「480両余を自前で出資」は1340−860=480両と数字として整合する〔仮説として記録。両資料の出典系譜の照合は本文確認後〕〕。
  - 2人は功により**千川の姓と帯刀を許され、子孫は代々千川上水の取締役を務めた**。
  - 明治以降は**印刷局や王子製紙などで工場用水として大量に使われ**、**現在でも消火用水などに使われているが、大部分が暗きょとなり、素掘りのまま残されているのはこの付近だけ**〔消火用水の現在利用と、開渠残存区間が区登録範囲（関町南2〜4丁目ほか）に限られるという現況説明〕。
  - **昭和63年度 区登録文化財**。所在地は関町南2～4丁目ほか。
  - 〔宝永4年「20か村」の内訳（多摩郡6か村＋豊島郡14か村）は[GOV-077](GOV-077.md)を参照〕
