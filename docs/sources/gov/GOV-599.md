# [GOV-599] 第二回内国勧業博覧会事務報告 — 上野会場への千川上水引水の公式記録（明治13年决定→明治14年無税・無代価通水）

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 『第二回(明治十四年)内国勧業博覧会事務報告』（**農商務省・1883**・[book/801873](https://lab.ndl.go.jp/dl/book/801873)）。第二回内国勧業博覧会（明治14年〔1881〕3月1日開塲・上野公園）の事務報告で、巻頭に**事務日録（明治13年10月〜明治14年9月の逐次記事）**を載せる。**引用はOCR由来で、事務日録の「〇」区切り・日付の月归属は原画像照合を要する**。

## 文言〔確認・要照合〕

- **事務日録・明治13年11月17日条**:
> 〇十一月十七日 會塲內ハ千川上水ヲ引用スル〓ヲ决定ス 〇十三年三月二十六日二品能久親王ヲ總裁ト定メラル（※OCR連続・「引用スル〓ヲ」の〓は「コト」等の候補〔要照合〕）

- **事務日録・明治14年6月30日頃の条**（閉塲後の事務処理記事の並び）:
> 〇三十日 諸書類其他一切 農商務省ヘ引繼ク 〇同日 會塲内ヘ引用ノ千川上水 無代價通水

## 読み取り〔観察・一部は既存仮説の強化〕

- **①上野・第二回博覧会への千川上水引水の公式記録〔repo既出の「1881候補・断定保留」を強める確定文言〕**: [BOOK-218](../books/BOOK-218.md)（菅園『傳衢暗記』1882）の回想群には「上野の『第二回…』会場への千川筋引水と噴水（第二回内国勧業博覧会1881候補・断定保留）」という**仮説留保があった**。本事務報告の事務日録は ⅰ) 明治13年11月17日に**會塲内への千川上水引用を决定** ⅱ) 明治14年2月26日に**「該會社」の願出による無税通水を許可** ⅲ) 閉塲後の6月末に**無代価通水済みの事実を記録** する＝博覧会本体の公式報告書レベルで引水の計画→許可→実施が裏付けられ、**断定保留を外して「第二回博覧会（1881・上野）の会場用水として千川上水が引用された」と扱える一次記録**〔文言の月日対応・「無代價／無稅」の前身関係の解釈は原画像照合後に確定〕。
- **②千川水道（明治13年開業の民営水道）との接続の候補〔観察・断定はしない〕**: 2月26日条の願出主体は「**該會社**」としか記されない。ただしⅰ) 千川水道株式会社は**明治13年（1880）に岩崎弥太郎発起で設立**（[GOV-056](GOV-056.md)系・[GOV-588](GOV-588.md)岩崎弥太郎発起人総代の開設許可指令1880-9-30）、ⅱ) 都公文書館所蔵の千川水道側文書に**「博覧会場迄落成」の回答（1881）**（[GOV-588](GOV-588.md)）、ⅲ) 本報告書の褒賞記事に**「水道會社發起人岩崎彌太郥ヘ銀牌」**があり、時期・人物とも一致することから、「該會社＝千川水道会社（千川上水を水源とする給水会社）」が**有力対校候補**となる〔會社名の明記がないため断定はしない。褒賞文言の授与日（褒賞授与式は6月10日）・「水道會社」の同定も原画像照合課題〕。
- **③上野方面千川給水系列の起点としての位置づけ〔観察〕**: [GOV-323](GOV-323.md)（第三回事務報告・1891）の「帝国博物館用水＝**千川水道會社給水の分取**」・[BOOK-161](../books/BOOK-161.md)系の明治23年給水量（博物館3,357立方尺/12h・博覧会局が動物園用水から4,983立方尺を分取）との series: 明治14年（本条・博覧会）→明治23年（GOV-323・博物館・第三回博覧会）→昭和13年（[GOV-600](GOV-600.md)帝室博物館略史の動物園）という**上野公園側の千川上水系給水の通時系列**が23年分前倒しで確認された〔給水経路（千川水道の管路か開渠か）は本条では特定できない〕。

## 制限・未解決

- ①事務日録のOCRは「〇」区切り記事の連続・乱れがあり、各文言の月帰属（11月17日の年＝明治13年、2月26日・6月30日の月）は原画像照合まで確定扱いとしない。②「無稅通水」と「無代價通水」の関係（前者=通行税・使用料の免除願、後者=給水対価の免除か）は本条のみでは特定できない。③「該會社」の同定（千川水道会社か）は推定の域を出ない。④第二回博覧会の噴水（回想記録の「噴水」との対応）への言及の有無は本掃引では未確認。
