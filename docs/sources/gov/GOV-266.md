# [GOV-266] 神田玉川上水留 明治2年分冊ノ三 — 玉川上水の宿方助郷の免除願と仙川村・砂川村の名主層

- **書誌〔確認〕**: 『神田玉川上水留』明治二年巳年正月ヨリ（新田川〔神田川のOCR〕）上水留分冊ノ三 [book/2587526](https://lab.ndl.go.jp/dl/book/2587526)。明治2年（1869）の記録（土木司・営繕司の人事・高札・宿方関係が中心）。**引用文言はすべてOCR由来で要原文照合。**
- **玉川上水の宿方（助郷）の免除願の連名〔確認・repo初出〕**: 「**玉川御上水乍元 明治二巳年十月 昨村代兼外拾壱ケ村一昼夜 箱根ヶ崎村名主為一郎印 砂川村源右衛門印 片村与一右衛門印**」「**右箱根崎村為一郎 仙川村源五右衛門 八郎右衛門 明治二巳年十月 片村…与一右衛門 並山県御役所**」＝**玉川上水沿いの宿方（助郷＝上水の人足・夫役負担）12ヶ村が、明治2年10月に人足賃上げ（夏は農業・養蚕、晩秋〜早春は寒気の中の地中働きで1日15-20匁の増銭手当が必要・昨年中1万人余の御遣払）を理由に「宿方附屋御除」（宿方役の免除）を民部省土木司・並山県（神奈川県のOCRか）に願出た**記録——
  - **連名に「砂川村源右衛門」「仙川村源五右衛門・八郎右衛門」〔確認・repo初出〕**: **千川家文書の千川善蔵・千川平吉（砂川村）・千川姓由来の仙川村と同じ2村の名主・組頭層の明治2年の実名の記録**＝[GOV-246](GOV-246.md)（慶応4の砂川村千川善蔵・千川平吉の水料堰料上納）・[BOOK-126](../books/BOOK-126.md)/[GOV-211](GOV-211.md)（練馬村千川善藏）・[GAZ-049](../gazetteers/GAZ-049.md)（仙川村太兵衞・德兵衞の開発）と対照できる**千川家関係村の明治2年時点の村里的役員の一次記録**（源右衛門・源五右衛門・八郎右衛門と千川家〔善蔵・平吉家〕の関係は本冊のみでは確定できない・断定しない）。
  - **宿方の負担実態の文言**: 「**年中壱万人余之御遣払 当巳年之儀も右二准し候儀故 宿方助郷等被仰付候而者斗続難相成候**」＝玉川上水の人足に年1万人余の人夫賃がかかり、助郷負担では継続不可能という村側の主張の文言（玉川上水の維持労務の規模の一次記録）。
- **砂川村地内の玉川上水高札〔確認・周辺〕**: [GOV-264](GOV-264.md)の高札建場所リストに「**並山県支配所 砂川村地内 一殿ヶ谷村落口西之方 砂川村地内同橋毛道橋際西之方 砂川村地内…木村青梅道石橋際西之方 一木村五日市道石橋際 一石畑村山道通橋際西之方**」＝**砂川村地内に玉川上水の高札3ヶ所＋殿ヶ谷村・木村・石畑村の計7ヶ所（大宮県・品川県等の管轄区分つき）**。千川家の村（砂川村）の玉川上水沿いの高札の配置記録（[GOV-248](GOV-248.md)の井之頭池〜大洗堰の神田上水側の高札と対照）。
- **虎御門外本多肥前守居屋敷表門前通の上水樋枡〔確認・周辺〕**: 「**虎御門外肥前守居屋敷表門前通 上水樋枡新規御出来相成候 右は前々ゟ居屋敷古樋之方ゟ上水引取置候間 此度…樋口御朋ヶ被成下 屋敷内掛江水引取申度**」（本多肥前守家来・四月七日）＝虎ノ門外の本多肥前守（大多喜藩・本多正納か・要照合）屋敷表門前通りの**上水樋枡の新規御出来（新設）と屋敷内への引取の願**＝神田上水の樋枡（配水枡）の新設記録（[GOV-248](GOV-248.md)の猿楽町前田対馬守屋敷前万年石樋・[GAZ-035](../gazetteers/GAZ-035.md)万年樋と並ぶ上水末端の樋枡の動向の記録）。
