- **東京都市計画河川改修の年度割変更簿冊群（1934〜1940）〔所在のみ・repo初出〕**: 谷端川キーワードで次の5簿冊がヒット（いずれもNDAメタデータ確認・未デジタル化）。**1934-04-05（纂02112100-01300）・1934-08-21（纂02116100-01300）・1935-12-28（纂02179100-00100）・1936-04-02（纂02227100-01300）・1940-03-23（纂02580100-00400）**の「東京都市計画河川改修／年度割変更」関係簿冊。**1930年決定以降、遅くとも1940年まで谷端川の改修年度割が継続的に調整されていた行政記録列**であることを目録レベルで示す。各簿冊での谷端川言及の箇所（件名・細目か本文か）は未確認。
- **1930年（昭和5年）1月25日 東京都市計画巣鴨町下水道及其ノ事業執行年割決定ノ件〔所在のみ・repo初出〕**: 纂01907100-00600。谷端川キーワードでヒット（＝件名・細目に谷端川言及の可能性）。README既収録の**西巣鴨町下水道（1932年内務省認可→1932年5月着工）**より2年4か月前の**都市計画決定段階**の記録であり、「1930.1.25決定→1932.3認可→1932.5.18着工」という制度過程の前提資料候補。谷端川と下水道計画の関係（谷端川を幹線として利用する計画か）は本文未見のため断定しない。
- **1917年（大正6年）3月15日 谷端川橋梁橋桁変更届出の件〔所在のみ・repo初出〕**: 逓信省鉄道局、参照コード**平12運輸02078100-05400**、aipId 509497。旧形式のURLは2026-11-14時点で404。谷端川を跨ぐ**鉄道橋の橋桁変更届出**の存在を示す。対象路線（西武池袋線・東上線・山手線ほか谷端川沿いの路線）は本文確認まで特定しない。READMEの橋梁リストに谷端川の鉄道橋に関する一次記録として加えるべき候補。
- **1942年（昭和17年）3月30日 東京都市計画道路決定…板橋区道路追加・練馬町道路…〔所在のみ〕**: 纂02811100-00300、aipId 2468434。「千川上水」キーワードの唯一のヒット。件名のみで**千川上水沿いの道路化（千川通り）の都市計画決定であるかは断定できない**が、千川上水が都市計画道路起案の文脈で言及される行政記録の存在を固定する。
- **位置づけ〔観察〕**: ①谷端川に関する一次行政記録が公文書館に残り、1930年決定の附図が現存すること、②改修年度割が1930〜1940年代に継続調整されていたこと、③下水道（巣鴨町1930）・鉄道橋（1917）・道路（1942・千川上水）の各制度と谷端川・千川上水が結びつくこと——の3点が、repoの谷端川1930年代暗渠化過程（README既述）の**制度史的背景をなす記録群の所在**として記録価値を持つ。本文未見のため、放水路の着工年次・工区・流路図への直接の裏付けには使えない。
