# [GOV-541] 官報 令和8年3月17日 気象庁公示「水防活動用洪水予報及び警報の開始について」〔善福寺川の水防警報開始文言・repo初出〕

- **書誌〔二次: kanpo-backup.com収蔵の官報令和8年3月17日号〕**: 気象庁公示（官庁事項）。**kanpo-backup.comは2025年3月10日以降の官報のみを収蔵する非公式全文ミラーで、OCRが多段組インターリーブしている**ため文言の列帰属は慎重に扱う（以下の表記はOCRテキストから再構成した読みで、官報原本（NDL・官報情報検索センター）での最終照合を要する）。
- **公示の文言〔二次・OCR再構成〕**: 「東京都知事と水防法（昭和二十四年法律第百九十三号）第十一条第二項の規定による協議が整ったので、気象業務法（昭和二十七年法律第百六十五号）第十四条の二第三項の規定により、洪水について**の水防活動の利用に適合する予報及び警報を次のとおり実施します**」＋表項目＝**水系名: 荒川水系／河川名: 善福寺川／上流端: 杉並区善福寺二丁目〔松見橋〕／下流端: 神田川合流点〔白山前橋〕／区間（基準地点）: 松見橋〜白山前橋**／**担当官署及び共同実施機関: 気象庁大気海洋局・東京都建設局河川部・東京都**／**開始期日: 令和八年三月十七日十三時**＋署名＝**令和八年三月十七日 気象庁長官 野村竜一**〔表の各欄と値の対応はOCR列混在の可能性があり、〔〕内は文脈補い。官報原本での確定を要する〕。
- **意義〔観察〕**: ①**善福寺川で水防活動用洪水予報・警報が始まる（開始期日R8.3.17）という気象庁公示文言はrepo初出**で、[GOV-489](../gov/GOV-489.md)杉並区河川ライブカメラの「都水防チャンネル」・映像監視局群（松見橋・白山前橋両局を含む）と対応する水防体制の法定側の文言。②**松見橋・白山前橋が基準地点区間を構成する橋名として官報レベルで登場**した点が橋名資料としての新規性（両橋名自体は[GOV-489](../gov/GOV-489.md)・[BLOG-261](../blogs/BLOG-261.md)等で既出だが、水防基準地点としての文言化は初出）。③「松見橋〜白山前橋＝上流端から下流端」という配置は[GOV-489](../gov/GOV-489.md)の善福寺川13局の番地並び（松見橋=荻窪2丁目側、白山前橋=成田東2丁目側）と整合し、善福寺川下流側（白山前橋=成田東〜和田堀〜善福寺川緑地方面）の位置関係の補強。
- **重要な陰性観察〔二次・kanpo-backupサイト内検索「2025-03-10以降の官報全文」ベース〕**: 同ミラーのサイト内検索で**谷端川・水窪川・弦巻川・千川・雑司ヶ谷・妙正寺川・江古田川・環状七号線地下調節池は全て0件ヒット**（2026-11-23時点）＝対象四河川のうち法定河川に位置づけられていない川々（[PAP-099](../papers/PAP-099.md)の千川の法定河川非化と整合）が**官報レベルでも告知対象になっていない**陰性の裏付け（善福寺川・神田川系のみがヒットする対比）。
- **制限・未解決**: ①kanpo-backup.comの収蔵は**2025-03-10以降のみ**なので、それ以前の官報（例: 関東地方整備局告示第37号〔R7.2.27〕）は本ルートでは取得不可＝次回以降NDL官報（本環境ではDNS解決不能の実績あり）・関東地方整備局の告示目録ルートで継続。②公示の官報頁番号・号（令和8年3月17日官報第号）はOCRで欠落しており原本確認待ち。③「基準地点＝松見橋と白山前橋の区間」の正確な表の欄構成（「区間」「基準地点」欄の別）は官報原本で要確定。
