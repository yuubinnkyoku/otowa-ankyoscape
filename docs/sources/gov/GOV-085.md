# [GOV-085] 雨水出水浸水想定区域図の公表（令和8年3月）と豊島区の対応

- **内容〔スニペット確認〕**：豊島区「豊島区洪水・内水ハザードマップ」ページ（及び宅地建物取引業者向けページ）の記述として「**令和8年3月に東京都下水道局から水防法に基づく雨水出水浸水想定区域図の公表がありました。これにより豊島区では、水防法に基づくハザードマップは既に作成済であった『洪水（外水）』に加えて『雨水出水（内水）』も作成済となりました**」〔**水防法に基づく雨水出水浸水想定区域図（内水氾濫の法定図示）の2026年3月公表と、区への反映を示す行政記録としてrepo初出**。2026年8月22日の集中大雨（[BLOG-115](../blogs/BLOG-115.md)・[BLOG-117](../blogs/BLOG-117.md)）以降の流域リスク評価の新しい公的土台〕。
- **都のQA資料の所在〔スニペット確認〕**：東京都下水道局計画調整部「雨水出水浸水想定区域図 ―Ｑ＆Ａ― 2026（令和8）年3月」（ https://www.kensetsu.metro.tokyo.lg.jp/documents/d/gesui/usuisyussuiQA ）〔指定対象となる排水施設の説明を含む。**谷端川幹線・千川幹線・雑司ヶ谷幹線が指定対象に含まれるかは本文未確認**〕。
- **意義〔解釈〕**：旧河川暗渠の下水道幹線（谷端川幹線・千川幹線・第2雑司ヶ谷幹線）が内水対策の中核である豊島区で、内水氾濫の法定想定区域図が2026年3月に整備された。旧流路と雨水出水想定区域の重なりは、暗渠転用の現代的意義を評価する基礎資料になる。
