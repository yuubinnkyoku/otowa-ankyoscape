# [GOV-258] 東京府史 府會篇 第8巻（1933）— 谷端川・神田上水改修の府會過程（大正14年建議→昭和2年諮問→昭和3年7箇年継続）

- **書誌〔確認〕**: 東京府『東京府史』**第8巻（府會篇）**（1933年・次世代デジタルライブラリー [book/1176196](https://lab.ndl.go.jp/dl/book/1176196)）。巻頭凡例「第五章府會の行動其の二は、明治三十二年七月改正府縣制施行以來昭和三年十二月末日に至る迄の、府會市部會郡部會に於ける議事の梗〓を年次によつて節に分ち」＝明治32年〜昭和3年12月までの府会議事を収める巻。引用文言はOCR由来で要原文照合。
- **大正14年の府會・建議案〔確認・repo初出〕**: 「**石神井川·谷端川府費支辨編入調査ニ關スル建議案**」が可決（大正14年・府會篇45頁付近の配列）＝**石神井川・谷端川の改修の府費支辨（編入）調査を求める建議案の可決**〔発議者の氏名（大久保源之丞ほかと読める文言が同章にあるが、建議案への対応はOCR列崩れのため原配列の照合が必要）〕＝谷端川改修の**議会側の起点**。[GOV-159](GOV-159.md)（1930年7月28日・都市計画東京地方委員会での3川改修決定）に先行する府會過程の記録。
- **昭和2年の府會・府諮問第二號〔確認・repo初出〕**: 「**立會川、神田上水、谷端川及荒川上流改修竝ニ篠崎運河開鑿ノ件答申議決**」＝**昭和2年（1927）の府諮問第二号として、立会川・神田上水・谷端川・荒川上流の改修と篠崎運河開削が付議され答申議決**＝都市計画事業（別紙）として決定されたことを示す文言（「都市計畫事業トシテ別紙ノ通」）。〔[GOV-159](GOV-159.md)の1930年委員会決定に先行する1927年の府會過程で、**谷端川改修は1927年府會諮問→1930年都市計画委員会決定→1932年度着工という行政手続の流れ**が府史レベルで確認できた。〕
- **谷端川改修計畫說明書〔確認・repo初出の文言群〕**（昭和2年の府會の説明書・OCR列崩れ部分あり）:
  1. **水源文言**: 「**本川ハ北豊島郡長崎町舊千川上水ヨリ分流シ**同郡長崎、板橋、瀧野川、西巢鴨及巢鴨町ヲ經テ東京市ニ入ル排水路ニシテ」＝**谷端川の水源を「旧千川上水からの分流」とする府側公文書レベルの文言**（[GOV-165](GOV-165.md)長崎町現状調査・[BOOK-139](../books/BOOK-139.md)小石川区会史の「谷端川水源＝千川用水分水口」と同じ系統の府側記述）。
  2. **現況**: 板橋より上流部は耕地整理施行箇所を除くほか屈曲部が各所に散在・幅員は一般に狭小・**勾配は1/400**。
  3. **防火堰の撤去決定**: 「**防火ノ爲メ五六箇所ニ堰ノ設備アルモ水道施設ノ今日ニ於テハ其ノ要ヲ見ス故ニ之ヲ撤去シテ流水ノ快疏ヲ圖ラムトス**」＝**防火用の堰5〜6ヶ所が存在し、改修で撤去が決定したことの文言（repo初出）**〔谷端川の防火堰（防火水槽的機能）の実在と撤去の初出記録。撤去時期（改修着工の1932年以降か）と位置は本文書では不明。〕
  4. **関係町**: 「**其ノ關係町ハ巢鴨町、西巢鴨町、瀧野川町及板橋町ノ四箇町トス**」。
  5. **改修区間**: 「**東京市界ヨリ板橋驛ヲ經テ田樂橋ニ至ル延長千九百八十三間**」＝**改修延長1,983間**〔[GOV-159](GOV-159.md)（1930年委員会）の改修延長3,001.8m（約1,667間）と対立する数値。1,983間≒3,605mで乖離が大きく、区間の定義（市界起点・田樂橋終点か）かOCR誤読の問題か、原文照合が必須。断定せず併記。〕
  6. **現況幅員・改修幅員**: 板橋停車場下流は幅19〜20尺・深9〜12尺、上流は幅12尺・深5尺→改修後は上流18尺餘・下流26尺（数値はOCR要照合）。
  7. **工費**: 「**貳百六拾五萬七千圓**」・5箇年・年次「**五三一、四〇〇円**」（53万1,400円）＝**総工費265万7,000円・5箇年計画**（土地物件買收費・補償費等の内訳欄は列崩れ。買收費「拾五萬圓」等の文言は別項（篠崎運河か）と混在の可能性があり要照合）。
- **神田上水改修計畫說明書〔確認〕**: 「市郡境」から中野町壽橋に至る**延長4,431間**・関係町＝高田町・戸塚町・落合町・淀橋町・中野町・年々の被害平均48万円・年額29万2,000円等（数値・町名はOCR要照合）＝神田上水（江戸川上流）改修の並行計画の説明書。
- **昭和3年の府會〔確認〕**: 「**四百八拾九萬五千圓ノ內本年度支出額四萬圓ヲ計上**」＝立会川・神田上水・谷端川等の改修群の総額489万5,000円・**昭和4年度から7箇年継続**（年度割4万→昭和4年度20万→昭和5年度40万…の文言候補）＝**昭和2年諮問→昭和3年府會で7箇年継続事業として予算化**された過程（列崩れのため年度割の正確な対応は要照合）。
- **帝都復興史との対校〔確認・2026-11-16第128回追記・[GOV-297](GOV-297.md)〕**: 復興調査協會『帝都復興史』第貳卷（1930）の第七編河川運河に同一主题の記述があり、以下の対立・整合が確認できた:
  1. **谷端川の工費の対立**: 帝都復興史は「**改修工費豫算ハ百三十萬圓**」＝本書（府史・谷端川說明書）の「貳百六拾五萬七千圓」と**対立**。帝都復興史の神田上水路改修費は「**二百六十五萬七千圓**」と、本書の谷端川工費と一致する数字＝**本書の265.7万が（OCR列崩れ等で）神田上水の数値の混入である可能性が強まった**〔断定は両書の原画像対校まで保留。ただし両書の成立経緯（1927府諮問の同一說明書に由来するか）の検討も必要〕。
  2. **改修区間の終点橋の対立**: 帝都復興史「市郡境界ヨリ**板橋町**ヲ經テ**田端橋**ニ至ル延長**一千九百八十三間**」＝本書「東京市界ヨリ**板橋驛**ヲ經テ**田樂橋**ニ至ル延長千九百八十三間」と、**延長1,983間は一致、終点橋が「田端橋」/「田樂橋」で対立**＝OCR変種・原字形の照合課題（[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)第128回追補）。
  3. **幅員の独立確認**: 帝都復興史「現在本川ノ幅員**十二尺乃至二十尺**ヲ改メ**十八尺乃至二十六尺**トス」＝本書の「上流は幅12尺→18尺餘・下流は幅19〜20尺→26尺」と**範囲として整合**（数値の文言は要照合）。
  4. **神田上水の被害見積の算術整合**: 帝都復興史「**大正十年カラ大正十五年ニ亘ル五ヶ年間ニ約二百四十二萬圓ノ被害額**…**優ニ一ケ年五十萬圓以上**」＝本書の「年々の被害平均48万円」と**算術的に整合**（242万÷5≒48.4万/年）＝両書が同じ被害見積に基づく可能性が強い。
  5. **神田上水の河幅・深さの追記**: 帝都復興史「現在河幅…下流市郡境界附近ハ**八間**、上流壽橋附近ハ**四間**ナルモ之ヲ整理シテ**下流幅員八間、上流ハ六間**トス。又水路ノ深サモ不規則ニシテ**十二尺乃至六尺五寸**ナルヲ改修後ニ於テハ護岸天端迄**下流十三尺、上流八尺**トナス」＝白堀（旧神田上水路）の改修前後の河幅・深さの数値〔repo初出・[GOV-297](GOV-297.md)〕。

## 制限・未解決

- ①改修延長1,983間と[GOV-159](GOV-159.md)の3,001.8mの対立は原文照合まで保留（区間定義の違いの可能性も含む）。②防火堰「五六箇所」の位置・撤去の実施状況は本書では確認できず、改修工事写真や[GOV-260](GOV-260.md)（1935年進捗表）との照合が課題（[GOV-298](GOV-298.md)〔消防年鑑1927〕の「谷端川、矢田川ニ各一箇所ノ堰止施設ヲ構築シ貯水池代用トシタ」＝1926年度の消防組側の堰止利用の対側記録・2026-11-16第128回追記）。③建議案の発議者氏名の原配列・大正14年府會での審議経過の詳細は要照合。④工費内訳（土地物件買收費188万8,202円と読める数値の行先）は列崩れで要照合。⑤谷端川工費265.7万（本書）と130万（[GOV-297](GOV-297.md)帝都復興史）の対立の解消は両書の原画像対校が必須（神田上水265.7万の混入説が有力候補）。⑥終点橋「田樂橋」（本書）/「田端橋」（同）の原字形は要照合。
