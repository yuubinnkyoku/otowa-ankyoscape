# [GOV-346] 享保撰要類集[51] 十四下ノ下 神社仏閣之部 — 雑司ヶ谷3門前の市中門前町屋リスト

- **書誌〔確認〕**: 『享保撰要類集[51] 十四下ノ下 神社仏閣之部』（写本・編纂年代の記載なし。NDL次世代デジタルライブラリー [book/2572806](https://lab.ndl.go.jp/dl/book/2572806)）。享保期（1716-1736）の事例を集めた幕政撰要類集の神社仏閣之部冊（「四ツ谷町雑司ヶ谷法妙寺門前鬼子母神門前放生寺門前」の文言が市中門前町屋の扱いを定めた条のリスト内に現れる）。[GOV-343](GOV-343.md)（南撰要類集・雑司ヶ谷村絵図面）と同系列の撰要類集資料。
- **文言〔確認・文言候補・要原文照合〕**: 市中門前町屋のリストに「**四ツ谷町雑司ヶ谷法妙寺門前鬼子母神門前放生寺門前**」（OCR）＝**享保期の帳簿に、雑司ヶ谷の法明寺（法妙寺）・鬼子母神（安養寺産泰寺）・放生寺の3門前が並記される**（OCRの「四ツ谷町」は四谷と雑司ヶ谷を結ぶ「四ツ谷町」の街道名〔現在の明治通り・雑司ヶ谷方面〕と、法妙寺門前・鬼子母神門前・放生寺門前の切れ目の読み方の両方があり得るため、原画像での区切り確認を要する）。
- **位置づけ〔観察〕**: ①[GAZ-077](../gazetteers/GAZ-077.md)（寛政一巡寺社門前帳・延享度に遡る門前町屋19軒の記録）の**前身級の帳簿記録**。享保期に雑司ヶ谷3門前が市中門前町屋として幕府の把握対象になっていたことの記録であり、門前町家の発生期（GAZ-076の目白不動門前1629年起り〔要照合〕・1731年焼失・再建）と享保期の間の行政文書側の存在証明。②雑司ヶ谷3門前（法明寺・鬼子母神・放生寺）の並記は、[BOOK-090](../books/BOOK-090.md)（新板江戸大絵図の雑司ヶ谷3門前集中）・[GAZ-077](../gazetteers/GAZ-077.md)と同じ構図の行政帳簿版。③「四ツ谷町」の街道名が享保期に帳簿に現れること自体、雑司ヶ谷と四谷を結ぶ街道（現在の明治通りの原形）の享保期用例となる〔観察・文言候補〕。
- **水系文言の陰性〔確認〕**: 本冊のOCR全文で「弦巻」0件・「水窪」0件・「千川」0件・「谷端」0件。神社仏閣之部の門前町屋リストであり、水系・流路の記録は含まれない。
