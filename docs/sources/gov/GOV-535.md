# [GOV-535] 中野区「都市計画河川」〔区一次資料の都市計画河川一覧・環七第6号神田川の計画区域座標〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: 中野区公式ホームページ「まちづくり・都市計画」内「都市計画河川」ページ。 https://www.city.tokyo-nakano.lg.jp/kusei/kousou/seido/toshikeikaku/toshikeikakukasen.html ページID 895960263・**更新日2025年3月5日**〔令和7年2月27日の神田川事業認可（[GOV-534](GOV-534.md)）の6日後の更新で、認可を受けた更新の可能性はあるが更新理由の断定は不可〕。担当＝区政情報・中野区都市基盤部都市計画課。
- **中野区内の都市計画河川一覧表〔確認: 本文表〕**:
    - **神田川**＝起点「台東区柳橋一丁目（隅田川合流点）」〜終点「杉並区久我山三丁目（三鷹市境界）」・**決定年月日＝昭和22年11月26日・告示番号＝戦復院第122号**、**（変更）平成2年1月26日・都第86号**・**幅員44〜16メートル**・**延長22,800メートル（中野区流域3,400メートル）**〔神田川の都市計画決定の告示番号と計画幅員・延長の数値がrepo初出〕。
    - **妙正寺川**＝新宿区下落合二丁目（神田川合流点）〜杉並区清水三丁目（井草川合流点）・昭和22年11月26日戦復院第122号・（変更）昭和45年12月22日都第1349号・幅員19〜15m・延長9,700m（中野区流域5,898m）。
    - **善福寺川**＝杉並区和田一丁目〜杉並区善福寺二丁目・昭和22年11月26日戦復院第122号・（変更）昭和45年12月22日都第1349号・幅員20〜11m・延長10,860m（中野区流域410m）。
    - **神田川・環状七号線地下調整池**＝昭和61年12月22日・**都告示第1354号**・4,500m。
    - **第五号石神井川及び第六号神田川**（環状七号線地下調節池の計画）＝**練馬区高松二丁目〜中野区野方六丁目**・**平成27年12月17日・都告示第1809号**・表記幅員14.2m・延長欄「ー」・**（面積：150,800平方メートル）**〔**環七地下調節池の第5号石神井川＋第6号神田川の計画区域の両端座標（練馬区高松2〜中野区野方6）と都告示番号・面積がrepo初出**＝[GOV-513](GOV-513.md)系の環七調節池監視（開札2026-12-02・[GOV-148](GOV-148.md)その2広域整備検討）に使える計画的座標〕。

- **問い合わせ先の記載〔確認〕**: 計画決定＝東京都建設局河川部計画課中小河川担当・**事業決定/既存＝東京都第三建設事務所工事第2課**〔[GOV-534](GOV-534.md)の所管事務所=第三建設事務所と整合〕。
- **意義〔観察〕**: ①神田川の都市計画の枠（戦復院第122号〔昭和22〕＋都第86号〔平成2〕）・**計画幅員44〜16m・全区間延長22,800m**の一覧を区一次資料で確認〔個別区間の整備記録（[GOV-514](GOV-514.md)の護岸整備率等）を受ける計画上位の座標〕。②環七地下調節池の計画的な裏付け（第5号・第6号の計画区域座標・告示番号）が**監視系の通知文言の照合基準**になる。③中野区の地形説明（台地5つ・谷5つ）は弦巻川・水窪川の地形議論（武蔵野台地の小台地構造）を中野区側から確認できる一文。
