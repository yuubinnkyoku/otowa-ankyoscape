# [GOV-539] 衆議院質問主意書 質問第202号＋答弁第202号（善福寺川上流地下調節池の費用便益比）〔repo初出・国会レベルの初の一次公文書群〕

- **書誌〔確認: 本文HTML全文取得〕**: 衆議院 第219回国会 **質問第202号「善福寺川上流地下調節池整備事業の費用便益比に関する質問主意書」**（[質問](https://www.shugiin.go.jp/internet/itdb_shitsumon.nsf/html/shitsumon/a219202.htm)／[答弁本文](https://www.shugiin.go.jp/internet/itdb_shitsumon.nsf/html/shitsumon/b219202.htm)）。提出＝**五十嵐えり衆議院議員・令和7年12月12日**、答弁＝**内閣（内閣総理大臣高市早苗署名）・令和7年12月23日受領**（官報令和7年12月15日号〔質問主意書掲載〕・12月23日号〔答弁書掲載〕）。五十嵐えり氏はnov 2024年都議会選後に衆議院議員へ転出した人物で、[GOV-540](../gov/GOV-540.md)の都議会速記録（令和6年度予算特別委員会）での石神井川上流地下調節池B/C質疑の継続系譜上にある。
- **質問本文の要点〔確認〕**: ①**国土交通省は令和7年度当初予算で2億円を社会資本整備総合交付金として配分、今後は事業費の1/2＝約700億円以上の国費投入を予定**〔国側の財源計画の国会文書レベル初出〕。②東京都公表の事業費1,557億円（[GOV-485](../gov/GOV-485.md)/[GOV-486](../gov/GOV-486.md)に整合）に加え、**B/C算定資料上の事業費1,406億円（工事費以外の設計・管理費等を除く試算値）の2つの数値が併存**。③神田川流域の河川整備計画の**全体事業費総額約4,844億円のうち29%を善福寺川上流地下調節池が占め、総便益6,814億円のうち貯水容量では全地下調節池の18.6%・河道整備＝時間降雨10mm対応＋全地下調節池＝同一15mm対応から按分便益は総便益の11.2%＝推計B/C約0.5**〔repo初出の計算構造。ただしこれは質問者の試算文言である点に注意〕。④都が令和7年1月29日に国へ申請した社会資本総合整備計画の**「荒川水系神田川調節池整備事業（調節池群）」B/C=1.4は複数事業込みの数値**で、社会資本整備総合交付金要綱（令和7年3月31日最終改正）の「水系・一連区間単位等で算出した費用便益比を記載可」条項に依拠するとの指摘。
- **答弁書の要点〔確認〕**: 質問一（当該事業単体でB/Cが1.0を上回ることの確認）に対し**「お尋ねの『善福寺川上流地下調節池整備事業』のみを対象として『費用便益比が一.〇を上回ること』は確認していない」**＝**政府レベルで単体B/C未確認を明示した文書文言〔repo初出〕**。質問二（要綱の単体B/C記載義務化）に対し河川砂防技術基準・「治水経済調査マニュアル（案）」（令和7年7月30日付国水計第49号・[GOV-485](../gov/GOV-485.md)FAQの言及と同一年度版）を根拠に**水系・一連区間単位の算出を正当化し、要綱改正は不要**と回答。
- **repo内の位置づけ〔観察〕**: ①[GOV-485](../gov/GOV-485.md)のB/C=1.41（流域全体評価・令和6年度時点）・[GOV-149](../gov/GOV-149.md)森川明夫技術士の二重計上疑い・[GOV-540](../gov/GOV-540.md)都議会質疑（神田川・環七は1/2と1/20の2ケース）と並ぶ**善福寺川上流地下調節池B/C問題の政府側一次文言**で、争点（＝事業単体のB/C非公表）が内閣答弁書で初めて明示された点が決定的に新しい。②B/C算定資料上の事業費1,406億円・全体事業費4,844億円・総便益6,814億円・按分便益11.2%の各数値は**国交省・財務省提出資料レベルの数値を質問者が引用した文言**で、都公表値（1,557億円）との差異の存在自体が記録対象。③「第219回国会・12月12日」という**提出日そのものも、[BLOG-296](../blogs/BLOG-296.md)（五十嵐えりnoteの続報待ち系譜）と突合可能な時点情報**。
- **制限・未解決**: ①質問本文の「推計B/C約0.5」は五十嵐議員側の試算文言であり、**政府が算定した単体B/Cの公式値ではない**（答弁書は算定値の提示自体を回避）。②B/C算定資料（都が国に提出した社会資本総合整備計画の添付）の本文は未取得で、4,844億円・6,814億円の直接確認は資料本体の開示・公表待ち。③官報本文（令和7年12月15日・12月23日発行）の頁・号は本環境では未確認（衆議院のHTMLで本文確認のみ）。
