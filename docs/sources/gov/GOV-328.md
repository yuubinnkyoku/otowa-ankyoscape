# [GOV-328] 豊島区政読本（1936）— 谷端川暗渠化の住民陳情と千川沿岸緑地計画の区政記録〔repo初出・第139回〕

- **書誌〔確認〕**: 豊島区編『豊島区政読本』（昭和11年＝1936刊）。NDL次世代デジタルライブラリー [book/1266912](https://lab.ndl.go.jp/dl/book/1266912) のOCR全文を確認。区政の各方面（教育・土木・下水道等）と区の委員会一覧を載せた**区編纂の行政資料**。**引用文言はOCR由来（委員会一覧は列崩れが激しい）で要原文照合**。
- **谷端川暗渠工事陳情委員（7名）〔確認・repo初出〕**: 区の委員会一覧に「**谷端川暗渠工事陳情委員（七名）**」の掲載があり、本文に「**（改良下水工事ニ伴ヒ幅員擴張トナリ其ノ）暗渠式又ハ覆蓋式トシテ其ノ上ヲ道路ニ供セシムベク府市當局ニ向ツテ情ヲ訴ヘテ運動ヲ促シタル處着〓此ノ目的ハ進捗シツ〓アル**」＝**①改良下水工事に伴う幅員拡張を契機に、谷端川を暗渠式または覆蓋式としてその上を道路に供するよう府市当局に陳情した区の委員会（7名）が存在した、②その目的が1936年時点で「着々進捗しつつある」**＝**谷端川の暗渠化を住民・区政側から運動した記録**で、[GOV-303](GOV-303.md)・[GOV-297](GOV-297.md)系の谷端川改修の行政側決定過程に**住民側の陳情の層を加える datapoint**（委員の設置年は一覧の割付から読み取れず・陳情の開始時期は要原表照合）。
- **千川沿岸の緑地計画の要請〔確認・repo初出〕**: 「**千川沿岸ハ區內ノ景勝地トシテ綠地計畫ヲ樹テラレンコトヲ要請シ當局ニ向ツテ具申スル等實現ニ努力シツ〓アリ**」＝**千川沿岸を区内の景勝地として緑地計画の樹立を当局に具申する区政の動き**（文言はOCR崩れ「要聖」「具情」等の原字照合を要する）。委員会一覧には「促進委員」の行と昭和10年存続の日付が並ぶ（**「千川沿岸緑地計画促進委員」相当の委員会が昭和10年に存続**と読めるが、一覧の列崩れのため委員会名と日付の対応は原表照合待ち）＝[GOV-303](GOV-303.md)（千川沿岸の緑地計画関係）に先行する1930年代前半の区政側の運動記録。
- **庚申橋（千川町）の造修予定〔確認・repo初出の橋梁帳簿〕**: 道路・橋梁章に「**昭和十一年度造修豫定橋ハ（庚申橋）千川町地内**」＝**昭和11年度の造修予定橋として千川町地内の庚申橋が挙げられている**＝**千川（旧千川上水・現在水路）沿いの豊島区千川町の橋として「庚申橋」の名が1936年の区政資料の橋梁帳簿に現れる**（橋の本体〔石橋・木橋等の分類欄〕・川幅等の割付はOCR列崩れのため原表照合を要する。橋名調査に追補）。
- **地形の記述〔確認・対校〕**: 「**谷端川、西部ニ千川ガ流レ、目白臺豐島ケ丘ニ連ル臺地ヲナシ海拔ハ一七・五米カラ三六・三米ニ及ンデヰル**」（要旨）＝谷端川と千川を並記する区の地形記述（区政読本レベルの概説だが、1936年時点で両水路の並存を区が把握していた文言）。
