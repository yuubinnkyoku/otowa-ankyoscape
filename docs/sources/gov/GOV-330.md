# [GOV-330] 府県及北海道境域沿革一覧 第2,3編（1910）— 保谷村移管の法律本体（明治40年法律第8号）＝千川上水の水元の府県所属の確定〔repo初出・第140回〕

- **書誌〔確認〕**: 内閣統計局編『府県及北海道境域沿革一覧』第2,3編（東京統計協会・明治43年＝1910刊）。NDL次世代デジタルライブラリー [book/762899](https://lab.ndl.go.jp/dl/book/762899) のOCR全文を確認。府県境の変遷を詔勅・法律の条文ごとに採録した官庁の統計編纂資料（第3編に法律・勅令の条文が収録される）。**引用文言はOCR由来で要原文照合**。
- **保谷村の東京府移管の法律本体〔確認・repo初出＝第139回ノート課題④の解決〕**: 「**第八號 三月十六日 朕帝國議會ノ協賛ヲ經タル東京府北多摩郡埼玉縣北足立郡境界變更法律ヲ裁可シ茲ニ之ヲ公布セシム**」「**埼玉縣北足立郡保谷村ヲ東京府北多摩郡ニ編入ス**」「**附則 本法ハ明治四十年四月一日ヨリ之ヲ施行ス**」（內閣總理大臣候爵西園寺公望・內務大臣原敬）＝**①千川用水の水元の村（保谷村）の埼玉県→東京府移管が「東京府北多摩郡埼玉縣北足立郡境界變更法律」（明治40年3月16日・法律第8号）によるものであること、②施行が明治40年4月1日であること、が法律条文レベルで確定**。同書の東京府条・埼玉県条の双方にも「**四十年三月十六日法律第八號ヲ以テ埼玉縣管下北足立郡保谷村ヲ東京府管下北多摩郡ニ編入シ同年四月一日ヨリ之ヲ實施ス**」の沿革記事がある＝[BOOK-174](../books/BOOK-174.md)（1926）の「**明治年間該村ハ北多摩郡ニ變換セラル**」の注記の年次（明治40年4月1日）と法的根拠（法律第8号）が行政記録で確定し、同資料ファイルの制限②が解消。外側の年表（西東京市資料など）の1907年4月1日説と整合する法律本体側の文言。
- **保谷村の郡変換の全chain〔確認・通時系列の固定〕**: 同書に採録された条文群で、千川上水の水元（保谷新田・保谷村地先〔[GOV-250](GOV-250.md)・[GOV-284](GOV-284.md)〕）の近代の所属が**①明治29年3月29日法律第40号**（「埼玉縣管下武藏國**北足立、新座、入間、高麗、比企、橫見、兒玉、賀美、那珂、大里、幡維、榛澤、男衾ノ十三郡ヲ廢シ其區域ヲ以テ更ニ北足立、入間、比企、兒玉、大里ノ五郡ヲ置キ**同年四月一日ヨリ之ヲ實施ス」）＝**新座郡廃止・北足立郡への統合（保谷村は埼玉県新座郡→同県北足立郡へ）**、**②明治40年3月16日法律第8号**（前項）＝**東京府北多摩郡への編入**、の2段階であることが確定。1889年町村制で上保谷・下保谷・上保谷新田の3か村の合併による保谷村成立（埼玉県新座郡）は外側書誌による補助知識（本書では未確認）。
- **三多摩移管（明治26年法律第12号）の条文の採録〔確認・対校〕**: 「**第十二號 明治二十六年三月四日 朕帝國議會ノ協賛ヲ經タル東京府及神奈川縣境域變更ニ關スル法律ヲ裁可シ茲ニ之ヲ公布セシム**」「**神奈川縣下武藏國西多摩郡北多摩郡南多摩郡ヲ東京府ニ移ス**」「**此ノ法律ハ明治二十六年四月一日ヨリ施行ス**」＝[法令全書明治26年](https://lab.ndl.go.jp/dl/book/787990)（中巻・本次調査で別途確認）と同一文言の採録＝**北多摩郡（田無町・小川村など千川用水の中流の村々を含む）の神奈川県→東京府移管が1893年4月1日**であることの統計編纂資料側の裏付け。同書に**明治28年3月27日法律第24号「東京府埼玉縣千葉縣茨城縣境界變更法」**の併載もある（江戸川下流域等の別件で千川上水への直接関係は確認できず）。
- **千川用水の流路の府県跨ぎの時期構造〔観察〕**: 上記の条文群と町村レベルの所属（田無町は神奈川県北多摩郡〔1878年以降〕→1893年東京府、保谷村は埼玉県→1907年東京府、巣鴨村は東京府北豊島郡）を組み合わせると、**千川用水の流路が複数の府県にまたがっていた時期が**①〜1893年＝水元の保谷村（埼玉県）・中流の北多摩郡域（神奈川県）・下流の北豊島郡巣鴨（東京府）の**3府県跨ぎ**、②1893〜1907年＝水元の保谷村（埼玉県）とそれ以外（東京府）の**2府県跨ぎ（14年間）**、③1907年4月1日以降＝全線東京府、という3段階に整理できる＝[GOV-252](GOV-252.md)（1892年・伴直之助の「保谷新田に於て玉川より分派」＝3府県跨ぎ期の記述）・[GOV-100](GOV-100.md)（小川家文書＝旧北多摩郡側の水利文書）の文脈の行政的背景。**境橋（分水点の橋〔BOOK-137〕）の「境」が村境・府県境に由来するかは本書からは確認できず断定しない**（「相岐るゝさかい所」とする[BOOK-137](../books/BOOK-137.md)の説明が本筋のまま）。
- **田無町の所属の確認〔観察・外側資料による〕**: 田無町が神奈川県北多摩郡所属（1878年北多摩郡編入・1879年町制、1893年移管）は西東京市公式資料・Wikipedia等の外側資料による（本書は郡単位の記載のため田無町の文言なし）。**第139回ノートの「田無村と同時の埼玉県→東京府移管」という想定は誤りで、埼玉県から東京府へ移ったのは保谷村のみ**＝本条の重要な修正点。
