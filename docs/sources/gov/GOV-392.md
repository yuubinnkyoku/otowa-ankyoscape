# [GOV-392] 類集撰要 巻之四十九「名主」— 領主別名主一覧の雑司ヶ谷・三水道町の人名〔第165回〕

- **書誌〔確認〕**: 『類集撰要』巻之四十九「名主」冊（安永3〜寛政4年中心の名主関連例集・安永7戌年の年番申合等の文言を含む）。NDL次世代デジタルライブラリー [book/2571696](https://lab.ndl.go.jp/dl/book/2571696)。**引用文言はすべてOCR由来で要原文照合。**
- **江戸中の領主別名主一覧〔確認・核心〕**: 「**江戸中名主共年来実静に相勤候者又は不動成者…惣名主其番組ゟ弐拾三番組幷番外とも都合弐百六拾人程**」の取調に基づく領主（寺社・旗本）別の名主一覧に、①「**伝通院領小石川原町外弐拾二ケ所名主安右衛門**」・「**自澄院領雑司ヶ谷町卯二ヶ所名主平次左衛門**」〔**「自澄院」は「自証院」〔自証院＝市ヶ谷圓融寺自證院・雑司ヶ谷村の朱印地領主〕のOCR候補・要照合〕・「**蘇祥院領柏木淀橋町外四ケ所名主紋右衛門**」〔蘇祥院〔OCR崩れ候補〕・柏木淀橋町＝四谷側の淀橋町の領主側記録候補〕、②水道町筋では「**金杉水道町外四ケ所名主市郎右衛門**」「**小日向若屋町外十六ケ所石主三四郎**〔「若屋町」は「水道町」のOCR崩れ候補〕」「**関口水道町外四ケ所名主佐一郎**」＝**雑司ヶ谷町名主平次左衛門が自証院領の名主として冊に登場**し、**金杉水道町（市郎右衛門）・小日向水道町（三四郎）・関口水道町（佐一郎）の三水道町の名主人名が一覧レベルで残る**一次記録〔**[GOV-345](GOV-345.md)・[GAZ-075](../gazetteers/GAZ-075.md)の雑司ヶ谷町名主平次左衛門の年代遡行の資料**（一覧自体の明示年代はないが冊の中心年代は安永3〜寛政4年＝文政9年の地誌御調〔GAZ-075〕に先行）。**三水道町（白堀の藻苅3ヶ所・古来持場〔[GOV-234](GOV-234.md)〕）の名主の人名はrepo初出の系譜資料**＝白堀維持の担い手の組織の人物像の充実。名主肝煎制度の文言（「名主肝煎と唱其組合之上席に申付」）も同冊に見える〕。
- **名主の勤怠の取調文言〔確認・参考〕**: 「**名主之内不行届者も有之候ハゝ再三致教諭其上不相用者も候ハヽ可申出**」等の名主統制の文言＝寛政期の名主組織の再編の文脈〔一覧の作成背景〕。
