# [GOV-067] ねりまの川「千川上水が水田、工業利用に」

- **書誌〔確認〕**：練馬わがまち資料館コラム「ねりまの川」千川上水連載の1編。2026-11-11時点で当該サイトはopen_urlによる直接取得が不可のため、[Wayback Machineの2024年12月1日スナップショット](https://web.archive.org/web/20241201213224/https://www.nerima-archives.jp/column/3518/)で本文全文を確認。末尾のシリーズ解説により、練馬区専門調査員・北沢邦彦が「ねりま区報」（昭和61年4月21日号〜63年7月21日号）に執筆した連載「ねりまの川－その水系と人々の生活－」と『みどりと水の練馬』（平成元年3月、練馬区土木部公園緑地課）第3章「練馬の水系」を元にした再録と判明。本記事は昭和62年2月21日号区報が原記事。
- **水使用料の取り決め〔確認〕**：宝永4年（1707年）の灌漑利用開始時に村々は利用組合を作り、**田1反（約10a）につき米3升（約5.4L）ずつを千川家に支払う**取り決め。分水口の大きさは利用度に応じて厳重に取り決められ村別に割り当て。
- **利用村の構成〔確認〕**：上水の水を利用した村は**多摩郡系統6か村＋豊島郡系統14か村の計20か村**（幕末頃には関村が一時水路を放棄）。江戸時代に石神井川へ合流した水は、明治半ば以後には王子製紙などに引かれた水の流末を王子方面の村々でも利用。
- **元治元年（1864年）の村別水田利用面積〔確認〕**：練馬区域の豊島郡6か村について、中村7町7畝（約7.0ha）・中新井村17町5反2畝15歩（約17.5ha）・下練馬村3町9反（約3.9ha）・関村3町3反（約3.3ha）・上石神井村4町5反（約4.5ha）・下石神井村4町9反20歩（約4.9ha）。**千川上水系灌漑の規模を村別・数値で示す初出資料**（repo内照合用の定量的基準）。
- **明治11年の変化〔確認＋記事筆者の推定〕**：明治11年当時の全村データでは関・上石神井・下石神井の3か村が消えており、記事は明治4年の田柄用水新設（田無村など9か村の組合）への移籍のためと推定。
- **明治3年玉川上水通船計画〔確認〕**：明治3年に玉川上水へ荷船を通す計画が起こり、小平市中島町の先から玉川上水北脇に新水路が築かれた際、千川上水は本流から切り離され新水路につながれて著しく水量が減り、各村の農民が分水口復旧を嘆願。通船は水の汚れなどで間もなく中止され、千川上水は本流につなぎ直された。〔千川上水の流路変更イベントの年代を明治3年に特定する情報〕
- **水車〔確認〕**：千川上水は飲料水として引かれた性格から水車許可はほぼ下りず、**江戸時代は練馬区域で水車は設置されなかった**（幕末に1、2所在が推定される程度）。明治になり王子方面で工業用水利用が始まったのをきっかけに上流部にも設置。明治17年頃と推定される「千川上水路図」には8か所の水車が記され（「千川上水路図解説」肥留間・北沢著）、練馬区内で確認されている水車は**田中水車（上石神井1-8）・斎藤水車（南田中1-22）・鴨下水車（富士見台1-4）・矢島水車（豊玉上2-27）**の4か所。
- **制限〔未解決〕**：谷端川への長崎村外三村分水（[GOV-005](GOV-005.md)）の灌漑面積・水田面積は本記事では示されず、豊島郡14か村の内訳も未確認。水車8か所の個別位置は「千川上水路図」（[MAP-060](../maps/MAP-060.md)・[MAP-061](../maps/MAP-061.md)・[BOOK-014](../books/BOOK-014.md)・[GOV-040](GOV-040.md)・[GOV-061](GOV-061.md)参照）本文での確認が次の課題。
