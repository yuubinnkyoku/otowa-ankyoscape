# [GOV-172] 東京府史 行政篇 第4巻 — 谷端川改修・千川上水の府史記述

- **書誌〔確認〕**: 東京府『東京府史 行政篇』第4巻（1936年刊）・NDL次世代デジタルライブラリー [book/1207680](https://lab.ndl.go.jp/dl/book/1207680)。OCRテキストで土木篇「谷端川の改修」節・上水道章「千川上水」条を確認。**数値・文言はOCR由来で要照合。**
- **「谷端川の改修」節〔確認・GOV-159の独立傍証〕**: 谷端川は「北豊島郡長崎町境窪地先**旧千川上水より分水**」し、省線**板橋駅附近で赤羽線下を経**、「**東京市下水道速成事業の一として既に完成**」した**板橋放水路**で石神井川に放流、残余は西巣鴨・滝野川町界→巣鴨町貫流→大塚駅東で山手線下→小石川区で「**千川**」→**水道橋際で神田川に合流**。延長約8,000m・**流域面積約866ヘクタール（260万坪）**・幅員3.6〜6m・深1.5〜3m・平均勾配1/400・護岸なし。改修区間＝**西巣鴨町池袋西前橋下流約100mより巣鴨町下水道谷端川下水幹線接続点（山手線下）まで延長約3,001m**・矩形開渠（幅6m・深2.42/2.58m・RC護岸高4.67m）＋下流全暗渠（円形渠径30〜120cm・矩形渠幅2.43〜3.5m・深1.82〜2.63m）＝[GOV-159](GOV-159.md)（1930年委員会決定）とほぼ同一数値を1936年時点の府史が再録し、**決定→執行の連続性を独立に傍証**する。
- **上水道章「千川上水」条〔確認・repo初出の文言多数〕**: 御府内上水在絶略記を引用し「**上保谷分水口より瀧野川に至る五里二十四町許、濶壹間許、瀧野川堰口より巢鴨村に至る二町五十二間、陰樋延長凡壹里拾五町四十七間とす**」＝**開渠5里24町＋陰樋1里15町47間**の内訳寸法。按語で「**元祿九年丙子 北多摩郡仙川村の民 太兵衞・德兵衞なる者に命じ之を開鑿し、小石川別殿・湯島・聖堂・上野・淺草等に通ぜしめ、千川上水と稱す。享保七年壬寅八月、令して之を壅廢す。安永九庚子に至り再び開の議あり。…天明元年辛丑二月より府下を疏鑿し十二月を以て成る。同六年丙午十一月又命じて、瀧野川以下を塞き、是を王子村に注ぎ、專ら灌漑の用に供す。明治十二年己卯、瀧野川以下を開き、水路を改鑿して今の狀となす**」。さらに「享保七年十月**青山・三田・本所の諸上水と共に一旦廃止**となり、その後**安永八年十一月に再興**されたが、**天明六年閏十月に至つて又もや廢止**…**明治十三年八月に至り、岩崎彌太郞等の請を許し、千川水道を再興**して本郷・下谷・小石川・神田の諸區の飮料に充てさせた。**明治三十一年神田・玉川等の諸上水と共に廢絕した**」。
- **新情報のポイント〔観察〕**: ①**陰樋延長1里15町47間**という江戸市中埋樋区間の総延長寸法（[GAZ-024](../gazetteers/GAZ-024.md)の町別埋樋長と照合可能）。②**天明6年は閏十月**（[GOV-171](GOV-171.md)は十一月と記す——月名の食い違いはOCRも含め要照合）。③**明治12年（1879）滝野川以下の開削・改鑿**という明治期工事件。④**明治13年8月の岩崎弥太郎等による千川水道再興許可**（給水区域＝本郷・下谷・小石川・神田）。⑤**明治31年廃絶**（[BOOK-077](../books/BOOK-077.md)の「明治40会社閉鎖」とは給水停止と会社消滅の別事象と解釈可能だが本書では整理されず併記に留める）。
- **上水道章総説〔確認〕**: 江戸の上水を「神田・玉川・千川」を**三百年存続の「江戸の三上水」**と総説し、六上水（神田・玉川・青山・亀有・三田・千川）の枠組みで千川上水を位置づける。

## 制限・未解決

- ①陰樋延長・堰口間数・年月（閏十月/十一月）はOCR由来で原本照合を要する。②「御府内上水在絶略記」引用部と府史自身の叙述の境界はOCR上明瞭でない箇所がある。③明治12年改鑿の対象区間・明治13年岩崎弥太郎「等」の具体的当事者は本書では特定されない。④保谷分水口が「上保谷」である点は[GOV-100](GOV-100.md)系の保谷新田関係文書と要照合。
