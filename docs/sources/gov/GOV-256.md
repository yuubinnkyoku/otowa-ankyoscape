# [GOV-256] 東京府史 府會篇 第四巻（1931）— 千川用水組合負担橋梁の府費支辨移管（明治34年）

- **書誌〔確認〕**: 東京府『東京府史』**第4巻（府會篇）**（1931年・次世代デジタルライブラリー [book/1176124](https://lab.ndl.go.jp/dl/book/1176124)）。巻頭凡例「第五章府會の行動其の二は、明治三十二年七月本府に改正府縣制施行以來昭和三年十二月末日に至る迄の、府會·市部會·郡部會議事の梗〓を年次によつて節に分ち…先づ、編纂の成つた明治三十二年より同三十九年に至る八箇年分を、第四卷として發行したのでゐる」＝**明治32〜39年の府會・市部会・郡部会の議事の梗概を収める巻**。引用文言はOCR由来で要原文照合。
- **諮問第三「千川用水組合負擔ノ橋梁ヲ府費支辨ニ移スノ件」答申議決〔確認・repo初出〕**: 「明治三十四年の府會」の章に「**千川用水組合負擔ノ橋梁ヲ府費支辨ニ移スノ件·····答申議決**」＝**千川用水の橋梁の維持負担を用水組合から府費へ移す件が諮問として付議され答申議決された明治34年（1901）の府會記録**。〔千川用水の橋の維持管理主体の変遷（千川家→用水組合→府費）の最初の行政側記録として、[GOV-258](GOV-258.md)（昭和2年・谷端川改修の府諮問）・[BOOK-139](../books/BOOK-139.md)（明治41年・千川大下水改修の区会陳情）より約30年先行。当該諮問が通常府會か臨時会か・月次は章内の配列から原文照合で確認要。〕
- **理由書〔確認・文言はOCR要照合〕**: 「**右ハ道ニ架設シアル橋梁ナルモ千川用水路ニ當レルニ依リ從來該組合費用ヲ負擔シ來リシ處近來交通頻繁ヲ加ヘ從テ完全ナル施設ヲ爲サ(?)…交通上障害不尠ト認ム…爾今府費ヲ以テ之ヲ支辨セントス**」（前後割注は列崩れ・要照合）＝**①道路橋であるが千川用水路に当たるため従来は組合が費用を負担してきたこと、②交通頻繁の増大により府費での完全な施設への移行が図られたこと**の理由説明。
- **別表橋梁リスト〔確認・表はOCR列崩れ大・行対応は要照合〕**: 諮問添付の別表（OCR上、明治33年度郡部決算書・明治35年の府會と同頁面に混在）に橋名・線名・郡名・町村名・橋質（木・石）・長幅の欄が並び、読み取れる範囲で——
  - **線名**: 「**板橋間道**」「**青梅街道**」「**川越街道**」（＋大字/字欄）
  - **橋名**: 「**江古田橋**」「**郡役所裏字下五兵衞橋**」「**筋違橋**」「**伊勢橋**」「**石橋**」「**大山橋**」
  - **郡名・町村名**: 北豊島郡「**板橋町**」「**石神井村**」「板橋町」、字/關所欄「下板橋」「上板橋」「下板橋」「大字竹(?)」
  - **橋質**: 「**木**」「**石橋**」等
  ＝**千川用水（現千川上水・千川児童公園筋）が板橋町〜石神井村域で街道・間道と交差する8橋程度の実在リスト**（江古田橋＝中板橋・庚申通り付近の旧江古田橋〔[橋名調査](../../四河川の橋名・橋跡調査.md)参照〕と同名候補・大山橋＝大山街道と千川用水の交差点〔現在の氷川橋付近か〕等、比定は原文照合後に検討）。長幅の数値欄（「〇〇〇三三」「九尺〇〇〇〇」等）は列崩れで行対応不能。
- **位置づけ〔観察〕**: 千川用水の橋梁のうち街道級の橋（江古田橋・青梅街道橋・川越街道橋・大山橋等）が**明治34年時点で「用水組合負担」だった**ことの直接的な府側記録＝享保〜明和期の千川家負担の根津側4橋（[GOV-210](GOV-210.md)〜[GOV-212](GOV-212.md)）とは別系統の、**中流〜上流側（北豊島郡内）の橋の維持負担の実態**を示す最初の定量リスト。用水組合の橋梁維持義務（宝永4年水料米文言〔[GAZ-016](../gazetteers/GAZ-016.md)・幸治願書〕と担当区分が連続するか）は今後の照合課題。
