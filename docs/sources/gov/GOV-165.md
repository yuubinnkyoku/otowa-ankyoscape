# [GOV-165] 東京市臨時市域拡張部 北豊島郡長崎町現状調査（1931年）

- **書誌〔確認〕**: 東京市臨時市域拡張部による北豊島郡長崎町の現状調査報告（1931年・昭和6年）・NDL次世代デジタルライブラリー [book/1900502](https://lab.ndl.go.jp/dl/book/1900502)。**引用はOCR由来・要原文照合。**
- **長崎町の水路記述〔確認・repo初出の文言〕**: 「**千川用水ハ町ノ西北ヲ桜井街道（正確な街道名はOCR判読）ニ沿ヒテ流レ、谷端川ハ町ノ中央ヲ貫通シ**」〔OCR・要照合〕。長崎村が豊多摩郡下落合の一部を併合して町制を施行した経緯・人口密度等の統計を含む市域拡張時（1932年東京市編入直前）の行政調査。
- **位置づけ〔観察〕**: ①[GOV-159](GOV-159.md)（1930年）が谷端川の分水点を「北豊島郡長崎町**字境窪**」と記した直後の同町に関する市側調査で、**千川用水（本流）が町の西北を・谷端川（分水）が町の中央を貫流する**という平面配置の行政記録。境窪分水（[GOV-129](GOV-129.md)・[BOOK-077](../books/BOOK-077.md)）の地理文脈に1931年の断面を加える。②1932年市域拡張前夜の長崎町の現況記録として、豊島区化直前の谷端川上流域の土地利用研究の基礎資料候補。
