# [GOV-262] 神田玉川上水留 明治2年分冊ノ一 — 小石川御門外の西洋風水輪車願一件と船河原橋際の水車願却下

- **書誌〔確認〕**: 『神田玉川上水留』明治二己年神田玉川上水留分冊ノ一 [book/2587522](https://lab.ndl.go.jp/dl/book/2587522)。冊頭に「**同十七ノ二百四十三 第八棚彫治二己年□□上木方留帳 水車頭 書類写 屋鋪改**」とあり、**「水車頭」の書類写**（上水方の水車担当の記録綴り）であることを明記。明治2年（1869）の記録。**引用文言はすべてOCR由来で要原文照合。**
- **小石川御門外御堀端の「西洋風水輪車」新規取建願の全過程〔確認・repo初出〕**: 願人の牛込中里村町家持**隆之助**（五人組七之助）が、**小石川御門外広場之内明地幷元竹内清兵衛様上り屋敷跡明地**（川岸付之場所凡五拾間奥行・川中寄）に**新規水車（水輪車）の取建**と地所拝借を願い出た一件の全過程——
  - **慶応4（1868）年12月22-23日**: 最初の願（屋敷跡大地は別段願・水車は只今相願の旨の仰渡→翌23日に河岸付場所約50間奥行・川中寄を拝借し水車取建願を御訴訟）。
  - **明治2年2月20日**: 場所御見分。**2月・3月の伺**: 「**普通の水車は落水を車口受け伝廻為致候処、隆之助工風は流水え車を仕掛押廻し候器械ニ有之**」＝**普通の水車（落水を受けて回す）に対し、隆之助の方式は流水に車を仕掛けて押し回す器械**という機構説明の文言（**「西洋風水輪車」の表記もあり**）。
  - **水源の文言〔確認・白堀（神田上水）の位置記録〕**: 「**右流は徳川（ママ）民部大輔屋敷内ゟ出候神田上水之分水ニ付上水ゟ車越仕掛候趣**」「**水源之儀水戸殿御屋敷内より流出し**」＝**水源は水戸家（徳川家）屋敷内を通って流出する神田上水の分水（余水吐）で、上水に車を架け越して仕掛ける**＝白堀が水戸家屋敷を貫通し下流側（小石川御門外御堀端）に流出する構造の明治2年の一次文言（[GAZ-049](../gazetteers/GAZ-049.md)⑬「白堀上水…水戶殿屋敷に入る」・[GOV-236](GOV-236.md)巡視路「牛天神下水戸様御屋敷境」と対校）。
  - **3月24日**: 御屋敷（水戸家）側の回答取りまとめ——水戸家側の公務人鹿嶋又四郎・奥御平服之頭取鈴木三蔵・監察方中村弥平・坊主組頭安藤安右衛門の4名の名を挙げて「於御屋敷万端一差障之筋決而無御座候旨」。
  - **4月4日**: 徳川少将内（家中）から「**全く之餘水に候間差障無之**」段申聞＝**当該水流が「餘水」（余水）であることの当事者（水戸家）側の確認文言**。
  - **5月3日**: 「**東京府上水屋敷改**」あて「**小石川御門外徳川少将内餘水仕筋 同所御堀端ニ而…水車取建之儀願出御取調之上願之通御申付被成候**」＝**許可**。地所は「**長五拾間幅五間**」。
  - **拝借証文の文言〔確認・repo初出の水車営業条件〕**: 「**当巳年ゟ来ル戌年迄 五ケ年季 壱ケ年冥加金五拾両 七月十二月両度に上納可仕**」「**構通道造吐筋柵石垣共破損有之候ハヽ取繕可仕**」「**上水減水出水之節々家業相休可申候 若御上水御差障にも相成候上は年限中(中略)とも御取敢可被仰付**」＝**5年季・年冥加金50両（7月・12月の2回納）・白堀の柵・石垣の破損は一手に修繕・上水の減水・出水時は家業休止・上水に差支が生じた場合は期間中でも取り上げる**という水車営業の条件の証文言。用途は「**舂米渡世**」（米搗き）で「時相場ゟ五ゟ安に売捌」。
  - **許可後の曲折〔確認・文言はOCR由来〕**: 5月に徳川家側から「**先頃同家中水筋見分之処 多分之泥水有之 其上巾壱間程之水引取口有之 庭中水車取建…神田掛差支ニ付 右編水ヶ所留方**」との申立が会計官（営繕司）に伝えられ、「**神田上水掛差支ニ付廃水留方営繕司ゟ御掛合申入置候処**」の後、**6月に「民部官上水掛取扱に而徳川中将屋敷内仕水留方同家え申達仕水留切相成候段申聞」＝屋敷内での水留（通水止め）が実施され、水車一件は「六月分見合」**（見合わせ）となった経過。水車が実際に稼働したかは本冊では確認できない（断定しない）。
- **江戸川筋船河原橋際の新規水車願の却下文言〔確認・repo初出・船河原橋の新datapoint〕**: 「**江戸川筋弘(船?)河原橋際ニ而新規水車取建方願之義勘弁いたし候処…右場所者 出水之度々諸方より落水多分にて水吐至而悪敷場所 且者水車取建水上(カ)候而は猶更水嵩最寄一円難渋之次第**」＝**江戸川（神田川）筋の船河原橋際の新規水車願が「出水のたびに諸方からの落水が多く水吐きが悪い場所であり、水車を建てれば水位が上がり一円難渋する」という理由で却下された文言**。①「船河原橋際」が江戸川筋（牛込側）にあることの明治2年の一次文言（[GOV-239](GOV-239.md)「舟河原橋ゟ関口大洗堰迄拾五町」・[GAZ-049](../gazetteers/GAZ-049.md)⑬「船河原橋」との表記対立の新datapoint。「弘河原橋」はOCRと断定しない）②江戸川の船河原橋付近が「水吐きの悪い低湿地」であったことの行政側の評価文言（[GOV-263](GOV-263.md)の川上村々の難儀申立と対校）。
- **玉川上水沿いの表井の取払い〔確認・周辺〕**: 「**往還間狭に付取払被仰付**」として、横町往還の「**玉川御上水請候表井一ケ所**」の取払い・埋立と引取樋（「元松平肥後守様御手持」）の処分、場所見立の新規井戸願の記録（明治2年6月・衆目町家主二右衛門ら）＝玉川上水に繋がれた給水井（表井）の明治2年の行政記録（神田上水側の[GOV-237](GOV-237.md)諏訪町下水吐押埋と同時期の上水施設の整理）。

## 制限・未解決

- ①すべてOCR由来。特に「徳川札民部大輔屋敷内」の「札」・「水湛車」「神田掛差支」「編水ヶ所」「水上(カ)」「弘河原橋」「明治二丑年五月」（丑は巳の誤読か）等の原字形・当て字は原文照合必須。②「水車頭」という役・部署の実態（江戸期の水車方の明治2年への継承か）は本冊のみでは確定できない。③隆之助の水車が実際に稼働開始したか・水留切は一時的か恒久かは本冊の範囲では確認できない。④民部大輔・徳川少将・徳川中将の同一人物の特定（水戸徳川家当主の官途名の可能性が強いが断定しない）と屋敷の位置（水戸殿屋敷＝白堀の小石川区間の既知の水戸様御屋敷か）は対校要。⑤牛込中里村町の比定（中里村＝牛込側か）は要照合。
