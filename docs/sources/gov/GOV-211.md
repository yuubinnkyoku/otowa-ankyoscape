# [GOV-211] 年番取拝十一 [11]（嘉永3）— 千川屋敷上納地請負人代り調

- **書誌〔確認〕**: 町奉行所の年番取締の記録類（嘉永3戌年・十一冊之内の第11冊）。NDL次世代デジタルライブラリー [book/2571991](https://lab.ndl.go.jp/dl/book/2571991)。目録に「**五 小石川白山前町千川屋敷上納地請負人代り調**」の項目がある。**嘉永3年5月の千川屋敷上納地請負替（宇兵衛→三左衛門）の一件を、町奉行遠山左衛門尉の書付・宇兵衛願・（関連）御勘定奉行衆への伺い等の形で収める。[GOV-210](GOV-210.md)（市中取締類集201・河岸地調之部）と同一事件の年番取扱側の写し**で、文言の一部がより完全な形で読める。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **享保年中の橋の増減の経緯〔確認・[GAZ-034](../gazetteers/GAZ-034.md)の由緒書との数値対立の並記〕**: 宇兵衛願——「**根津惣門前 御入用を以 御掛直しに相成り候 橋四ヶ所 新規掛替修復共 手限入用を以 御用相勤度奉願上候処 其節之道御奉行 高林又兵衛様に奉願候処 願之通被仰付 相勤来候処 享保年中 右四ヶ所之内 御成橋壱ヶ所 橋巾減少 被仰付 右代りに 谷中辺に而 橋弐ケ所相増 都合六ケ所 新規修復共相勤来候処 明和五子年中 御普請方御役所御掛にて 右六ヶ所之内弐ヶ所 減少被仰付**」〔**①正徳4年拝領後に根津惣門前の橋4ヶ所の新規掛替修復負担を願い出て道奉行高林又兵衛のもとで相勤い、②享保年中に「御成橋」1ヶ所の橋巾減少、代わりに谷中辺で橋2ヶ所増えて都合6ヶ所、③明和5年に2ヶ所減免（代りに銭17貫文/年〔[GOV-210](GOV-210.md)〕）**＝**千川家の橋負担の変遷の宇兵衛側（嘉永3年願書）の文言**。**当初橋数（本願書=4ヶ所・[GAZ-034](../gazetteers/GAZ-034.md)由緒書=3ヶ所〔OCR〕）と谷中側増橋数（本願書=2ヶ所・由緒書=3ヶ所〔OCR〕）が対立する**——合計6ヶ所と明和5年の減免2ヶ所・残4ヶ所は一致するため表記・伝承の異同と考えられるが、**断定せず並記し原文照合課題とする**〕。
- **根津側4橋の位置列挙（明和5年減免後の残り4橋）〔確認・千川家負担橋の位置の確定資料〕**: 遠山書付——「**一本橋之儀之（＝は） 根津宮永町に而 同所惣門え 渡橋 宮永町西裏通ゟ 根津門前町え 堀端 同所ゟ 谷中通り 渡橋 同所より 善光寺前町 渡候橋 都合四橋に有之候 右減切弐ヶ所之…（中略）**」〔**明和5年減免後の残り4橋＝①根津宮永町→根津惣門の渡橋、②宮永町西裏通→根津門前町の堀端の橋、③同所→谷中通りの渡橋、④同所→善光寺前町へ渡る橋**＝**千川家が修復負担した橋が根津惣門まわり・谷中側（千川上水の下流部）にあったことを橋の両岸の町名で特定する文言（repo初出の位置列挙）**。①根津宮永町（現・文京区根津の御殿坂・根津神社惣門周辺）、④善光寺前町（現・台東区谷中の善光寺〔浄土宗不动院隣の「善光寺」〕門前）で、千川上水（再興期の流路）の根津・谷中方面への流路を示す基礎資料〕。
- **天保14卯年（1843）の免除・取上げの文言〔確認・[GOV-210](GOV-210.md)と同一内容の年番側写し〕**: 「**天保十四卯年七月廿九日 御普請方御役所におゐて 橋普請并びに迄納銭共 差免 拝領地之儀之取上ニ相成候段被仰渡 同年八月九日 当御番所様ゟ右町之地位 見合相応之地代相納候様被仰渡 是迄金拾壱両ヲ両度へ金五両弐分ツヽ上納仕 御受負被仰付…**」〔天保14年7月29日の橋普請・上納銭の免除と拝領地取上げ、同年8月9日の地代（11両・2回各5両2分）上納の申し渡し＝[GOV-210](GOV-210.md)と同一の文言が年番取扱側にも残ることを確認（文言の対校用資料）〕。
- **三左衛門の身分と請負の承認〔確認〕**: 「**同人儀 近年病身に相成候に付 右御地所内に罷在候 三左衛門儀は 私甥に而 当戌三拾七才に相成候 身元慥成者に付…御受貢壱ケ年金拾壱両…両度に割合 七月十二月十日限 金五両弐分ツヽ無滞先上納可仕候**」＋遠山書付の結部「**是迄之通 証人相立 受負金拾壱両ツヽ上納可致旨 申立候 差支も無之候はゝ 申上之上 願之通可承届に存候**」〔三左衛門=宇兵衛の甥・嘉永3年時点37才・千川屋敷内居住・証人（神田明神下御台所町治兵衛地借茂七）立ての上での承認の記録〕。
