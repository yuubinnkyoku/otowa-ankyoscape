# [GOV-455] 長崎町現状調査 — 谷端川の字水原文言と千川用水の1931年灌漑利用の文言候補

- **書誌〔確認〕**: 『長崎町現状調査』（東京市臨時市域**擴張部**編・[book/1900502](https://lab.ndl.go.jp/dl/book/1900502)・縦割OCR大崩壊）。**引用文言はすべてOCR由来で要原文照合（本冊はOCR品質が特に悪く、書き下しは列復元による候補値）**。現状調査シリーズの**長崎町（1932年板橋区→練馬区長崎周辺）冊**＝**谷端川（小石川）上流水系・千川上水旧水路の中枢に位置する町の1冊**＝本シリーズ中で千川・谷端に最も近い核心冊。
- **地勢章の谷端川＋字水原文言〔文言候補・本ファイルの核心①〕**: 「**谷端川ハ町ノ北字水原(沿ヒテ流レ候補)**」＝**谷端川が町の北の「字水原」に（沿って流れる）とする1931年行政調査の文言候補**〔**①「字水原」＝谷端川上流域の小字名候補＝谷端水源地（谷頭・湧水地）に対応する字名の一次語候補（repo初出候補。水窪〔みずくぼ〕・水元系の水系語彙と接続しうる）、②本文言はOCR大崩壊のため、括弧内の補読を含めすべて原画像照合前提**〕。対照表「谷端川」行へ追記。
- **千川用水の灌漑利用文言〔文言候補・本ファイルの核心②〕**: 「**他ニ千川用水(町ノ西北…道二沿ヒテ流レ)…灌漑其ノ他ニ便スル**」＝**①町の北西を千川用水が（道に沿って）流れ、②灌漑その他に便するとする1931年の行政調査文言候補**〔**①千川上水の廃止後も「千川用水」として1931年時点で水路が現役の灌漑用水として機能していた（＝行政調査レベルで「用水」と明記された）一次文言候補（repo初出級）、②「道二沿ヒテ流レ」＝旧千川上水温並び（ケヤキ並木道＝石神井通り系統）の記憶を残す流路文言候補（[MAP-203](../maps/MAP-203.md)千川付・[GOV-098](GOV-098.md)1881千川上水堀との通時対校）、③主語の水路名が「千川用水」と「千川」のどちらの表記かはOCR崩壊のため要照合**〕。対照表「千川上水/千川用水」行へ追記。
- **地勢章の丘陵文言〔文言候補〕**: 中新井方面からの丘陵が二波に分れ、上板橋南方〜高田町・落合町一帯の高地に至るという地勢叙述＋西巣鴨町境方面に「**谷精川(谷端川候補)**」という川名のOCR文字列が見える＝**「谷端川」のOCR崩壊 variant「谷精川」の記録（原画像で谷端川か別の川かを要照合・断定せず）**＝武蔵野台地の谷頭地形（谷端川・千川両水系の分水嶺～谷頭）の1931年の地形叙述。
- **下水道〔文言候補〕**: 「**下水道(事業?)ハ石神井系統(ニ)（属ス）…処分場ハ江北村**」＝**①下水道が石神井系統に属す、②処分場が江北村にあるという文言候補**〔**「処分場＝江北村」＝石神井川下流の江北村（岩淵町隣接・現北区足立区境側）への排水計画の1931年時点の一次文言候補（[GOV-450](GOV-450.md)瀧野川町の「江北処分場」・[GOV-445](GOV-445.md)第217回落合町とは別冊での同系統の裏付け）**。管渠延長・工費の数字はOCR崩壊で読み取り不能〕。
- **交通〔文言候補〕**: 武蔵野鉄道（現西武池袋線系統）が町を貫通・池袋駅方面への連絡の文言候補＝谷端川上流域の鉄道開発の1931年定点。沿革＝旧長崎村＋下落合（一部?）等の大正15年町制との合流のOCR文字列（要照合）。
- **帳簿文言〔確認〕**: 人口・面積（昭和5年10月1日国勢調査値の文字列候補）・財政（昭和6年度予算＝歳入臨時部96,388円等・OCR数字崩壊）＝1932年市域拡張直前の長崎町の帳簿。

## 制限・未解決

- ①**本冊はOCR大崩壊（列復元でも約半分が欠落）のため、「字水原」「千川用水（灌漑）」の2文言はいずれも原画像照合が完了するまで候補値とする（repo最優先の照合課題の一つ）**。②「字水原」の水路との位置関係（字名が谷端川の水源側か単に沿川の字か）は本文言からは特定できず断定しない。③「谷精川」はOCR崩壊 variant の可能性が高いが別川の可能性も排除できない。④下水道の管渠延長・工費の数字は読み取り不能。⑤武蔵野鉄道の駅名は本冊レベルでは特定できず。
