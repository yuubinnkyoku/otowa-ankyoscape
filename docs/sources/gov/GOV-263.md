# [GOV-263] 神田玉川上水留 明治2年分冊ノ二 — 江戸川端の水車と川上村々の難儀・赤坂紀伊国坂下の白堀水車願

- **書誌〔確認〕**: 『神田玉川上水留』明治二己年神田玉川上水留分冊ノ二 [book/2587523](https://lab.ndl.go.jp/dl/book/2587523)。明治2年（1869）4月〜7月の記録。**引用文言はすべてOCR由来で要原文照合。**
- **「両上水…余水を以為御益水車取建方」の行政方針文言〔確認・repo初出〕**: 冊頭に「**此役官ゟ懸り…神田玉川（両）上水御普請御用途多に付 右両上水…余水を以為御益 水車取建方 土木司おゐて取調候処**」と読める文言＝**神田・玉川両上水の余水を「御益」（収益）として水車を建てる方針を民部官土木司が調査した**ことを示す明治2年の行政文言（維新直後の上水の活用方針の一次記録）。
- **江戸川端の水車と田安中納言物揚場〔確認・repo初出の構造数値〕**: 「**神田余水江戸川へ船も難出来場所に付 別紙絵図朱引之通御用地に相成候間 田安中納言物揚場（外）場所替御取計**」＝江戸川（神田川）の余水を落とす場所が船の難所であるため御用地化し、田安徳川家の物揚場を場所替えする経過に加え、
  - 「**田安中納言物揚場…水車場地所 長六拾間余 巾平均拾五間**」＝**田安家物揚場の水車場地所（長60間余・幅平均15間）**。
  - 「**樋長八拾七間四尺 巾九尺**」（同所の樋〔水路〕の規格）＝**樋87間4尺・幅9尺**という江戸川端の水車の給水樋の定量記録（OCR数字は要照合）。
  - 「**江戸川端に而新規水車取建に付ては 江戸川筋之流水増候節は水上武家町其外共難渋いたし居候間**」＝**増水時の武家町の難渋を理由に、水車の仕法（吐方）の確約を取る交渉の文言**。願人側は武州豊嶋郡穏田村（渋谷の穏田）側の人物（組頭吉兵衛・年寄親類兼佐太郎・名主清兵衛ら）で、「**神田上水余水を以江戸川端水車所来之儀**」の文言がある。
- **牛込船河原橋際の民部省水車取立と川上村々の難儀申立〔確認・repo初出〕**: 「**当…関口町外弐ヶ村水下も 牛込船河原橋際え 民部省におひて小平(水車?)取立相成候 以上之処 右様相成候而は 川上大町村々 水行不宜難儀之段申立候**」＝**①関口町外2ヶ村の「水下」にあたる牛込の船河原橋際に民部省が水車の取立を認めた②それに対して川上の村々（大町村々）が「水行不宜・難儀」と申立てた**という一件の記録——[GOV-262](GOV-262.md)の船河原橋際の水車願の却下文言・[GOV-239](GOV-239.md)の「舟河原橋ゟ関口大洗堰迄拾五町」の川政区画と対校できる**船河原橋際の水車をめぐる上流下流対立の一次記録**。「小平」は「水車」のOCR崩れ候補（原字形照合まで断定しない）。「関口町外弐ヶ村」の2村の同定（関口村・水道町外か）は要照合。
- **赤坂紀伊国坂下「御上水白堀」の新規水車願〔確認・repo初出・白堀呼称の別系統の用例〕**: 「**赤坂紀伊国坂下 御上水白堀江 新規水車取建之儀**」の願（明治2年4月24日・**品川県**支配所経由＝当時の赤坂が品川県管轄）——願人は「**武州豊嶋郡穏田村組頭吉兵衛**」（[GOV-262](GOV-262.md)・上欄の江戸川端の願人と同一人物群かは要照合）、内訳は「**問寄地所に而凡三四百坪**」「**御堀凡三四間位者埋立方仕候而**」「**坂落しに相流れ候水勢空敷(カ)白堀迄**」＝**問寄地所300-400坪・堀幅3-4間ほどを埋め立てて水車を建てる・坂落ちの水勢が良い白堀である**という計画文言——
  - **「白堀」という呼称が赤坂側の上水（青山上水系＝玉川上水の支流）でも使われていることを示す明治2年の一次文言**＝[GOV-245](GOV-245.md)・[GOV-246](GOV-246.md)の赤坂「弁慶堀端白堀通」（2587529）に続き、**「白堀」呼称が神田上水固有ではないことの第3の用例**。地名対照表の「白堀」行の注意書きを補強する。
  - 玉川上水系（青山上水）の水車・樋の管理が品川県（旧幕府代官所→品川県）から民部官土木司・東京府へ移る時期の行政の動きを示す同時期の記録でもある。
- **小石川御門外御堀端の物揚場の御用召上げ〔確認・周辺〕**: 「**小石川御門外御堀端物揚場 此度御用に付被召上候 尤代地之儀は外場(外?)可而見立可**」＝白堀沿い（小石川御門外御堀端）の物揚場が御用に召し上げられ代地見立となった文言（[GOV-262](GOV-262.md)の隆之助の水車一件と同じ町域の同時期の土地利用記録）。
