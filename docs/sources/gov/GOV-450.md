# [GOV-450] 北豊島郡瀧野川町現状調査 — 三排水系統と1931年の下水道着手・荒玉水道の座標

- **書誌〔確認〕**: 『北豊島郡瀧野川町現状調査』（東京市臨時市域**擴張部**編・[book/1900492](https://lab.ndl.go.jp/dl/book/1900492)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**瀧野川町（1932年滝野川区→北区）冊**＝谷端川流域（下流側）の町の1冊。
- **下水道の三排水系統区分〔文言候補・本ファイルの核心〕**: 「**九、下水道事業 下水道事業（計画?）ハ地勢上大体三排水系統ニ区分シ、一ハ羽田（及?）三河島処分場（東京市計画ノモノ）ニ、一ハ江北処分場（（荒?）玉水道町村組合（関係?）…本町ニ於ケル下水道系統之レカ（=この系統?）…）ニ属スルモノナルガ全町ニ於ケル下水道施設ハ完備セス、本年度ヨリ之レカ（其ノ?）実施調査ニ着手シ目下其ノ認可申請凖備中（ナリ）**」＝**①1931年時点の瀧野川町の下水道計画が「地勢上大体三排水系統」に区分されること、②その処分場が羽田・三河島（東京市計画）と江北処分場（町村組合側）であること、③「本年度（昭和6年度=1931）から実施調査に着手し、目下その認可申請準備中」であること**〔**①「江北処分場」＝江北地区の下水処分場（岩淵方面）への接続を1931年時点で瀧野川町側が計画していた一次文言候補（repo初出候補）、②1931年= 瀧野川町の下水道実施調査着手の年次の行政側の定点、③谷端川流域（音羽・西ヶ原側）と石神井川流域の排水の系統分離の枠組みの途上の記録（「三系統」の内訳の地形との対応（谷端川側がどの系統に属するか）は本文言からは特定できず断定しない）**。「(荒)玉水道町村組合」の文言はOCR崩れ大・江北処分場の管理主体（北豊島郡下水道組合か他組合か）は要原文照合〕。
- **荒玉水道第四水圧〔文言候補・数値群〕**: 「**本町大字西ヶ原四百八十四番地ニ荒王（荒玉）苐四水圧（第四水圧?）…苐五（?）…工費総額ハ千八百六拾万円 起工八大正十四年四月 竣工ハ昭和四年九月トス 給水区域ハ本町外十二ヶ町**」＋組合費分担金の年次表（昭和某年度〜・OCR数字崩壊）＝**①荒玉水道（豊島町村組合水道＝'荒玉水道町村組合'）の第四水圧（配水池等の施設候補）が大字西ヶ原484番地にあったこと、②起工大正14年4月・竣工昭和4年9月・工費総額1,860万円、③給水区域＝瀧野川町外12ヶ町**＝**荒玉水道の瀧野川町域の设施の位置（西ヶ原484番地）と建設時期（1925〜1929）の行政調査レベルの帳簿文言**（水道の整備が先行し下水道が未完備という1931年の北郊のインフラ格差の定点として[GOV-446](GOV-446.md)〜[GOV-449](GOV-449.md)（豊多摩郡側の現状調査の同様の構図）と対照できる）。
- **北豊島郡役所の字池袋移轉〔文言候補〕**: 「**（北豊島）郡役所ハ板橋町（ニ）北豊島郡役所内ニ設置シ昭和三年五月仝郡西巣鴨町字池袋六百四十二番地ヘ新築移轉シ現在ニ及ベリ**」＝**北豊島郡役所が昭和3年5月に西巣鴨町字池袋642番地へ新築移轉したことの文言**〔「西巣鴨町字池袋」＝池袋が西巣鴨町（現豊島区池袋）の大字であったことを示す行政文書レベルの実例（第116回の西巣鴨町現状調査（GOV-337等）の陰性記録と対照する、郡役所所在地としての字池袋の登載例。字池袋642番地の現地比定は本冊レベルではなしえない）〕。
- **帳簿文言〔確認〕**: 人口・面積・交通（省線山手線の巣鴨・駒込両駅・大宮電鉄計画・板橋乗合自動車の庚申塚分岐等）・学校・社会事業等の帳簿（OCR崩壊大）＝1932年市域拡張直前の瀧野川町の帳簿。
