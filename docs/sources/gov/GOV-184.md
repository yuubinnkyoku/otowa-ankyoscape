- **神田上水第一受益者負担区の告示〔確認・repo初出〕**: 昭和11年11月28日付の**神田上水第一負担区**の告示で、**中野区本町通3-16-2先壽橋からあやめ橋**に至る地番つき区間が負担区として指定される。〔[GOV-183](GOV-183.md)の施行細則に続く**個別負担区の確定例**。「壽橋」が起点橋名として現れることは[GOV-182](GOV-182.md)の「中野橋」誤読説（[GOV-159](GOV-159.md)・[GOV-180](GOV-180.md)の「寿橋」が正しい可能性）を補強する方向の材料。あやめ橋（中野区）の位置は未調査〕〔文言はOCR要照合〕。
- **施行済区間一覧の文言〔確認・repo初出・要行照合〕**: 神田上水の施行済区間一覧に「**至東京市下水道藍染川放水路起**」・「**自巣鴨町下水道谷田川幹線終点**」という文言が現れる。〔**「藍染川」が谷田川（千川下流）の下水道放水路化の名称として使われた**可能性を示唆する文言候補。千川＝藍染川＝谷田川の関係（[GOV-107](GOV-107.md)・[GOV-135](GOV-135.md)等で扱った同流の別称問題）に新しい資料側の材料を与える。ただし**この文言がどの区間の始点・終点に対応するかはOCRの行崩れで確定できず、行対応の照合を要する**〕〔文言はOCR要照合〕。
- **細則改正〔確認・repo初出〕**: 昭和11年11月14日の細則改正で、谷端川関係の文言に「**豊島区及滝野川区地内**」が現れる。〔[GOV-183](GOV-183.md)（報告第12回）の「谷端川(板橋区地内)」との対応関係（区名の訂正か、区間の組み替えか）は未解決〕〔文言はOCR要照合〕。
- **負担指数単価〔確認・参考〕**: 指数一箇当り**拾錢八厘一**（10銭8厘1）の文言が確認される。〔受益者負担の実勢単価の例。ただし適用対象（どの負担区か）の行対応は要照合〕〔数値はOCR要照合〕。
