# [GOV-544] 東京都水防災総合情報システムの善福寺川観測所系列〔repo初出・[GOV-541](GOV-541.md)の基準地点＝松見橋・白山前橋の観測所実在の裏付け〕

- **repo初出・既出の区別〔観察〕**: ①観測所名としての**善福池・和田堀公園調節池・朝日橋はrepo初出**（[GOV-489](GOV-489.md)区ライブカメラ一覧には和田堀公園分・朝日橋分の文言はなく、都水防災システム側の観測所名としては新規の文言）。②原寺分橋・原橋・荻窪橋・西田端橋・相生橋・宮下橋・善福寺取水は[GOV-489](GOV-489.md)等で既出だが、**都側システムでの「観測所番号（tgid 224001〜等）・水位/静止画の別・10進座標**」は本ページで初めて一括取得。③**松見橋・白山前橋が「水位」観測所（稼働中の水位計あり）であること**は、[GOV-541](GOV-541.md)（官報公示の基準地点）の2橋が水位観測所に一致する＝**公示の「基準地点＝松見橋・白山前橋」欄読みの強い傍証**。④**善福寺取水の座標35.68540,139.65484**は、[GOV-489](GOV-489.md)の堀ノ内2丁目1番（善福寺川取水施設）＝[BLOG-297](../blogs/BLOG-297.md)環七インフラツアーの善福寺川取水拝見ポイント・[GOV-486](GOV-486.md)環七東端取水施設の所在の10進座標として初出（環七調節池の善福寺川取水口の位置特定の補助資料）。
- **意義〔観察〕**: ①**善福寺川の水防観測網が「原寺分橋（最上流・湧水域付近）→朝日橋（最下流）」まで12点で張り巡らされ、水位計は①原寺分橋・③荻窪橋・④松見橋・⑤西田端橋・⑦相生橋（善）・⑧白山前橋・⑨宮下橋の7点に設置、静止画（カメラ）は②原橋・③⑤⑦⑧⑨・⑥善福池・⑩和田堀公園調節池・⑪善福寺取水・⑫朝日橋にある構成が一次ページから確認できた**。②この観測網は[GOV-541](GOV-541.md)（水防警報開始・2026年3月）が公示された実務側の観測体制と対応し、観測所整備→公示の前後関係の考察資料〔前後の因果は断定しない〕。③「善福池」という観測所名は善福寺池（[GOV-487](GOV-487.md)善福寺公園の上の池・下の池）の池畔観測点と読めるが、観測対象・設置位置の詳細は未確認〔推定〕。④和田堀公園調節池・善福寺取水が観測所群に含まれる＝**環七調節池の取水施設・関連調節池が都の水防観測網のノードになっている**ことを示す観測上の初出一級文言。
- **制限・未解決**: ①観測所系列の「上流→下流」の並びはページ表示順（善福寺川上流→下流の巡り）と読めるが、⑩〜⑫（和田堀公園調節池・善福寺取水・朝日橋）の正確な並び順・河道上の位置関係は座標から要検証（座標値は⑩㉑⑫が明らかに河道本流から分岐した位置にあり、表示順がそのまま河道順とは限らない）。②宮下橋の位置（35.68349,139.64136）は白山前橋下流で善福寺川本流に戻る形と読める〔推定〕。③各観測値（現在水位）は変動するため本資料の扱いは「観測所網の構造」と「座標」に限る（水位値の記録は対象外）。④スマートフォン版・軽量版のページ体系（/s/・/im/i/）の内容差は未確認。
