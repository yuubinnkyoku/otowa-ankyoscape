# [GOV-227] 東京市水道小誌（1899）— 千川上水の沿革条と玉川上水からの現役分水の文言

- **書誌〔確認〕**: 『**東京市水道小誌 : 図入**』（明治32年・1899年）。NDL次世代デジタルライブラリー [book/845987](https://lab.ndl.go.jp/dl/book/845987)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **千川上水条＝千川姓・府中邸地文言を含む1899年版の沿革条〔確認〕**: 「**千川上水ハ埼玉縣新座郡保谷村ニ於テ玉川上水ヲ分派シ之ヲ巢鴨溜池ニ致ス沿渠各村ニ供給シテ市內ニ入リ本〓下谷ノ一部ニ給水ス其開鑿ノ起リハ元祿年間ニシテ彼ノ河村瑞賢ノ計〓ニ係リ多摩郡仙川村ノ農民德兵衛、太兵衛ノ兩人此工事ニ從ヒ元祿九年中其工峻ル依テ彼ノ村名ヲ以テ名トシ文字ヲバ千川ト改メ事ヲ奉セシ村民二人ノ姓ニ賜リ且ツ江戸府中ニ邸地ヲ賜ヒシト云フ然ルニ享保七年上水ヲ廢シ單ニ用水ト爲ス後安永九年再ヒ之ヲ興シ本〓湯島、下谷、淺草等ニ給水セシモ爾後興廢一ナラス今ノ千川上水ハ明治十三年岩崎彌太郞等千川水道會社ヲ起シ舊渠ヲ修理開通セシモノナリ**」〔**①元禄年間起こり・河村瑞賢の計画・仙川村の徳兵衛・太兵衛の工事・元禄9年竣功、②「**彼ノ村名ヲ以テ名トシ文字ヲバ千川ト改メ事ヲ奉セシ村民二人ノ姓ニ賜リ且ツ江戸府中ニ邸地ヲ賜ヒシト云フ**」＝**村名（仙川）を千川と改めた文字を姓として賜り、江戸府中に邸地を賜った**＝千川姓・江戸府中の邸地（＝千川屋敷）の拝領を明治期の水道行政書が沿革として記述、③享保7年廃止→用水化→安永9年再興→明治13年千川水道会社——の1899年版の整理**〔[GOV-226](GOV-226.md)（1893）と同一系統の沿革記述で、②の千川姓・邸地文言は[GOV-210](GOV-210.md)〜[GOV-212](GOV-212.md)（千川家由緒書・上納地文書）と[GOV-229](GOV-229.md)（1934）・[GOV-208](GOV-208.md)（1938）の間を埋める明治期官書側の記述〕〕。
- **玉川上水からの現役分水の文言〔確認・1899年時点の神田・千川両上水の水源〕**: 玉川上水条に——「**方今玉川上水ノ水量ハ羽村引入口ニ於テ每秒時ニ四百四十立方尺以上ニシテ沿渠各村ノ用水ニ供給シ又其幾分ヲ千川、神田兩上水ニ分割シ以テ四ツ谷大木戶ニ達シ夫レヨリ市內ニ給水ス**」〔**1899年（明治32）時点で、玉川上水が「其幾分を千川・神田両上水に分割」して四ツ谷大木戸に達し市内に給水していた＝千川上水・神田上水が玉川上水の分水で現役だったことを明記する文言**。①[GOV-226](GOV-226.md)（1893・「一分派」）と併せ、明治20〜30年代の千川上水の稼働実態（千川水道会社による旧渠の修鑿給水）を裏付ける。②「四ツ谷大木戶」が玉川上水の終点で、そこから千川・神田両上水の配水系が分かれていた点の明記（千川上水の実際の分水口は保谷だが、本書は玉川本水の流末管理の視点で四谷大木戸を挙げる——両者の関係は文言のまま記録し断定しない）〕〔文言はOCR・要照合〕。
