# [GOV-498] 豊島区「わが街ひすとりぃ 第20回 北大塚 現地ロケ編」全文テキスト〔repo初出・谷端川民話『うなぎの道あんない』の口述・谷端川を舞台とする説話の一次聴取記録〕

- **書誌〔確認: ADEAC目録詳細頁・2026-11-22取得〕**: 「**わが街ひすとりぃ 第20回 北大巣 現地ロケ編**」〔目録表記は「**北大塚**」〕（**目録ID mp00002010**・作成者＝小林和子出演・北本建夫出演〔**目録の作成者欄は「北本建夫」・解題欄は「北村建夫」と表記対立**〕〔ゲスト＝矢嶋邦興・美與子（『うなぎの道あんない』矢嶋家）・柳川昌子（親子読書会）・保坂德右衛門（子安天満宮）〕・**製作者＝豊島区・製作年令和2年3月・収録日：令和元年12月12日・収録時間14分10秒**・映像資料）。**権利関係：「映像は二次利用不可 全文テキストのみ CC BY(表示)とする」**。[目録](https://adeac.jp/toshima-history/catalog/mp00002010)・[全文テキスト](https://adeac.jp/toshima-history/texthtml/d000000/mp00500101/ht420200)〔確認: 全文テキスト取得〕
- **谷端川の民話『うなぎの道あんない』〔聴取・repo初出・本資料の目玉〕**: 空蝉橋下交差点の項。柳川昌子「**ここの信号が「空蝉橋下」という信号なんですけど、この辺りが多分、このお話（民話『うなぎの道あんない』）の舞台だと思うんですね。**」→「**（三叉路を指しながら）向こうの方から落ち武者が逃げてきて、この大きな谷端川にぶつかって、「もう逃げられない、もうこれまでか」と覚悟をしたら、うなぎに案内されるように向こう岸に渡れて……。**」→矢嶋邦興「**柳川さんの方でいろいろまとめていただいて、紙芝居が出来ました。先ほどの侍がですね、諦めかけたところでうなぎが出てきて渡れたという。そこで渡ったところで蕎麦がきをいただいて――。**」→柳川「**それで命拾いをしたっていうことで、まあその、恩あるうなぎを食べないってことで、今でもそれを守ってるって。**」→矢嶋「**うなぎを食べないとか、お正月に焼き物をしないとか。**」→柳川「**500年以上前にこのお話が出来た。**」→矢嶋「**室町時くらい。太田道灌（おおたどうかん）ですから、1400年代ですね。**」→柳川「**それからずっと続いていて、そのしきたりを守ってるから。**」→矢嶋美與子「**いやいや……。**」＝**①谷端川（空蝉橋下交差点付近）を舞台とする落ち武者とうなぎの民話『うなぎの道あんない』の口述、②うなぎの恩によりうなぎを食べないというしきたり（正月に焼き物をしない）を矢嶋家が現在も守るという語り（美與子さんの「いやいや……」という反応は本文上意図が読めず、断定して扱わない）、③柳川昌子による内容整理と紙芝居化の存在、④成立を太田道灌時代（500年以上前・1400年代〈室町〉）とする伝承的年代の語り**〔A. **谷端川を主題とする民話の全体像が、区のオーラルヒストリーで口述記録化されている**＝repo初出の系統（これまで谷端川の口承は bridge名・水難等の断片に限られた）。B. 落ち武者・矢嶋家の系譜と蕎麦がきのくだりは民話固有の語りであり、歴史的事実としての確定は当然しない（道灌時代の成立も伝承の年代観にすぎない）。C. 柳川は前段で「**そのうなぎの道案内は、特に絵本にしたいなってずっと思ってたんですね**」「**当主が矢島（矢嶋）家の方がいらしたんですよね。矢島（矢嶋）さんのお家の話だというのが後で分かりまして**」と語り、絵本化への希望と民話が矢嶋家の家の話である認識を示す＝**紙芝居は実在・絵本は希望段階**として区別して記録〕
- **空蝉橋の明治36年切り通し架橋と「空蝉の松」〔聴取・発話者＝小林和子〕**: 同ロケの「■空蝉橋と出世稲荷神社」の項で小林和子「**この空蝉橋は、ここの下に、明治36年に電車が通った時、池袋―田端間が通った時に出来たんですね。切り通しにして橋を架けた。**」→「**その前から、どこでしょうね、この辺に出世稲荷っていうお稲荷さんがあって。そこに立派な赤松の大木があって、なんと明治天皇が行幸された時にその赤松にセミの抜け殻――いわゆる空蝉ですね、いっぱい付いていたので、この松を「空蝉の松」と名付けよとおっしゃったかどうか……そういうことで空蝉という言葉が出てきて、そしてここで橋が出来た時に大変優雅な空蝉橋っていう名前が付いたんですね。結局その松は枯れてしまったそうですね。そして出世稲荷自体は、こちらのもうちょっと奥行った辺りに引っ越したということですね。**」＝**①空蝉橋が明治36年（1903）の池袋―田端間電車開通時の切り通しに架けられた橋であるという説話、②出世稲荷の赤松＝「空蝉の松」の明治天皇行幸譚（「名付けよとおっしゃったかどうか……」と発話者自身が留保を付ける）、③松の枯死・出世稲荷の移転**〔空蝉橋・橋名由来の口承の一次記録。明治36年＝山手線の池袋―田端間開通に伴う切り通し架橋という説明は、本文献上の口述として記録し、史料による裏付けまで事実とは断定しない〕
- **意義〔観察〕**: ①**四河川の民話・伝承レベルで、谷端川を「この大きな谷端川」と大きさとともに呼ぶ語りの全文が、区の聴取記録として残る**（谷端川の通水時代の川相の記憶〔多くの証言では細流〕に対し、民話では「大きな」川として語られる点は語りの性格差として記録に値する・実測と断定はしない）。②『うなぎの道あんない』の紙芝居化・巣鴨図書館（昭和43年開館の記述あり）での親子読書会での継承は、**谷端川系の記憶の現代的実践（民話の紙芝居・絵本・かるた・すごろく文化への接続）**の例として [GOV-496](GOV-496.md)（谷端川緑道施策）と対照できる。③民話の矢嶋家と、[GOV-128](GOV-128.md)（谷端川橋名連載に関与した矢島勝昭・巣鴨のむかしを語り合う会）の矢島家とが同系かどうかは本資料からは確認できないが、**谷端川まわりの口承・執筆遺産に「矢島（矢嶋）」家が2系統登場する**ことは対照記録として保持する（断定しない）。③子安天満宮の保坂德右衛門の項には「**このお社が建ってから500年は経ってるだろうと思います。だから西暦の1500年頃にはもう建ってます。**」という社殿の年代口碑もあり、北大塚周辺の年代観の対照資料となる。
