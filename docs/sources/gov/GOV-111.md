# [GOV-111] 文化遺産オンライン「星野家文書」詳細ページ〔repo初出の指定データ〕

## 記録内容（2026-11-14、文化庁「文化遺産オンライン」詳細ページの直接確認・ai）

- 名称（よみ）: ほしのけもんじょ（星野家文書）。員数: 冊子及び一紙文書、版木、印章。
- 時代区分: 江戸時代～昭和初期／**1630年（寛永7年）～1948年（昭和23年）**。
- 所在地: 東京都杉並区大宮一丁目20番8号（杉並区立郷土博物館内）。所有者: 杉並区教育委員会。指定種別: 有形文化財(美術工芸品)。**指定年月日: 2012年2月23日**。
- 解説本文の要点:
  - 最初の調査時には**270点の文書群**として『文化財シリーズ5 杉並の古文書目録』（**昭和48年＝1973年**）に収録され、その後、千川用水に関わる史料を翻刻した『文化財シリーズ29 星野家文書-千川用水関係史料』（**昭和58年＝1983年**）として刊行された〔[BOOK-032](../books/BOOK-032.md)と一致〕。その後も文化財保護審議会委員による調査が重ねられ、**平成23年度に追加資料を含めて区に寄贈**、整理し直した結果、**総点数664点の文書群として指定に至った**。
  - **664点のうちモノ資料26点を除いた時代別内訳: 近世期13点・明治期598点・大正・昭和期24点・年未詳3点**（明治期が約90%）〔GOV-110のmus-000820（664点・江戸期13点・寛永7年「武州井草村御地詰帳」）に点数の内訳レベルの詳細を追加するデータ〕。
  - 星野家は江戸初期から上井草地域に居住の旧家。明治に入ってからは当主の**紋左衛門**が村政に活躍し、**明治11年（1878）から22年（1889）までは上下井草村連合戸長、明治22年から井荻村村会議員、同26年（1893）6月から36年（1903）9月まで井荻村村長**などを歴任。星野家文書の多くは紋左衛門が戸長として10年間にわたり作成・授受した戸長役場史料〔[GOV-110](GOV-110.md)の明治10〜20年代千川用水経営文書群の作成背景の行政経歴レベルの裏付け〕。
  - 戸長役場史料の形態・様式の検討上重要な**版木・印章**が現存。版木は「東京府 多摩郡」の罫紙・戸長役場の領収証を刷るためのもので、「東京府東多摩郡」の罫紙の版木は**明治29年の豊多摩郡成立の際に「東」を削ったのではないか**との解説。印章は「東多摩郡上下井草村戸長役場」「学費」「地租割地方税」「戸数割地方税」など**23点**。
