# [GOV-403] 屋敷渡預絵図証文第176冊 — 鶏声窪の屋敷渡証文と船河原橋際の揚場（1750）〔第167回〕

- **書誌〔確認〕**: 『屋敷渡預絵図証文』第176冊（写・NDL次世代デジタルライブラリー [book/2547886](https://lab.ndl.go.jp/dl/book/2547886)）。寛延3庚午（1750）8月の屋敷・揚場の御渡に付く絵図証文の写し綴。**引用文言はすべてOCR由来で要原文照合。**
- **駒込鶏声窪の屋敷渡証文〔確認・核心・repo初出〕**: 「**駒込鶏声窪加藤三之丞上り地之内今度願之通森重治郎屋鋪拝領仕御渡之被成四方間数坪数右御絵図之面御定規之通相違無御座請取申候為後日御如件**」＋日付「**寛延三庚午年八月廿五日**」＝**駒込鶏声窪の加藤三之丞上り地の内の森重治郎屋鋪の拝領（屋敷渡）の証文**〔**鶏声窪の江戸期実務文書（屋敷渡証文）用例（1750年）＝鶏声窪が住居地址の実務記録に現れる一次文書例**。水系とは直接しないが谷頭地名の実務側の定点として、[GAZ-083](../gazetteers/GAZ-083.md)（小石川志料・土井大炊頭屋敷文言）・[GAZ-090](../gazetteers/GAZ-090.md)（東京府文献叢書[4]・皇角原旧名説）・[BOOK-197](../books/BOOK-197.md)（鶏声窪由来譚）と対照表で対校できる**。「森重治郎」は「夜重治郎」等のOCR変種もあり原照合要。加藤三之丞の上り地（買い上げ地）の中の屋敷という土地保有構造の記録〕。
- **船河原橋際の神田川河岸の揚場の御渡証文〔確認・核心・repo初出〕**: 「**船河原橋近所神田川通り河岸に而今度願之通一阿倍百助揚ケ場御渡之被成右御絵図之面御定境之通相違無御座請取申候為後日仍如件御徒頭阿倍百助内寛延三庚午年八月廿三日**」（同型文言が2回・「御定境／御定税」等のOCR変種あり）＝**船河原橋近くの神田川通りの河岸に、願出により阿倍百助（御徒頭・人名は「阿信百助」「阿詰百助」等のOCR変種があり要照合）に揚場（揚ケ場）が御渡された旨の1750年8月23日の証文**〔**①船河原橋際の神田川（江戸川）河岸に揚場（荷揚げ場）が実在した1750年定点（江戸川水運の河岸の実務文書例・repo初出候補）、②「神田川通り」の表記が船河原橋周辺の川に対して1750年に使われている用例（「神田川」呼称の18世紀中葉の一次文書側の用例として、神田川=江戸川下流部の呼称の通時系列に加える候補）、③船河原橋の位置（神田川に架かる橋として揚場の方位の基準になっている）の間接裏付け**。絵図（御絵図之面）は本冊では確認できず、揚場の規模・取り扱い荷は不明〕。
- **同冊の他の証文〔参考〕**: 白山境内・根津五拾間町の屋敷拝領・道拾四間壱尺九寸の渡等、関口・白山周辺の屋敷渡証文が多数同居（鶏声窪・白山・根津の地理的近接の実務文書群）。

## 制限・未解決

- ①「森重治郎／夜重治郎」「阿倍百助／阿信百助／阿詰百助」等の人名のOCR変種の原字形照合は必須。②「上り地」の法的意味（買い上げ地・請地等）は断定しない。③揚場の位置（船河原橋の上流側か下流側か）・規模・用途は本証文では特定できない（絵図面の所在確認が課題）。④「神田川通り河岸」の「神田川」が江戸川の下流部（現・神田川）を指すかは文脈上自然だが、原画像の絵図面での確認が理想。
