# [GOV-175] 市中取締類集 上水番等之部 — 千川宇兵衛関係の町奉行側記録

- **書誌〔確認〕**: 『市中取締類集 舊草引繼書上 上水番等之部』（町奉行所の上水番・見守番・床店関係例集）。NDL次世代デジタルライブラリー [book/2572173](https://lab.ndl.go.jp/dl/book/2572173)（同一シリーズ [book/2572172](https://lab.ndl.go.jp/dl/book/2572172)）。OCRテキストで千川宇兵衛関係を確認。**文言・人名はOCR由来で要照合。**
- **千川宇兵衛の屋敷と「西千川」〔確認・repo初出〕**: 上水差止に伴う床店・地面取上の達しに「**小石川向山前 千川宇兵衛町不敷家作**」「**西千川 宇兵衛屋敷** 是迄之上納銭幷 十 **請負橋四ケ所 普請修復共 差免 地面取上ケ申渡候**」＝**千川上水請負人千川宇兵衛の屋敷が小石川向山前にあり、「西千川」の地名で呼ばれた**旨の町奉行側記録。千川家が**請負橋4ヶ所の普請修復**を負担していたことが差免・地面取上の対象として列挙される。
- **小網町宇兵衛の先代の私財投入と渡橋4ヶ所〔確認・文言OCR〕**: 「右之内**小網町壱町目宇兵衛儀 先代之節 千川上水懸ケ渡候御自分金をも差出候訳を以地面拝領**」＝千川家（小網町1町目宇兵衛）の先代が**私財を投じて千川上水を懸け渡し**たことを理由に地面を拝領していたことが、上水差止後の取上の文脈で記録される〔先代の誰か・何年かは本件では特定されない〕。
- **神田上水側の見守番記録〔確認〕**: 神田上水の白堀通・水道橋外掛樋の見守番人・床店の冥加金・地代金上納の例集多数（明和5年〜天明5年の年次を含む）＝[GOV-176](GOV-176.md)と併せ、江戸上水の市中管理実務の例集。
- **位置づけ〔観察〕**: 千川家（千川姓を給った[GOV-171](GOV-171.md)の徳兵衛・太兵衛系）の後裔請負人**千川宇兵衛**の市中側屋敷（小石川向山前＝小石川植物園後・向山の前）と**「西千川」の地名**が町奉行文書レベルで確認される初出資料。差止後の「**請負橋四ケ所普請修復共差免**」は千川家の維持負担範囲が橋梁に及んでいたことを示す〔橋の位置は本件では未特定〕。
