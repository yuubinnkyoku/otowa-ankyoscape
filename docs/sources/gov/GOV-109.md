# [GOV-109] 矢嶋又次記憶画2枚（青梅街道の追分・清水の湧水地）〔repo初出〕

ADEAC杉並区コレクションの矢嶋又次記憶画（[GOV-105](GOV-105.md)②「天沼弁天池」と同じ資料群・同一作者）の「千川」キーワード横断で、さらに2枚の所在と公開解説（矢嶋自身の解説文）を確認した〔2026-11-14、目録ページをcurl+UAで直接取得・ai〕。

## ①「青梅街道の追分」mus-003860・1976年（昭和51年）・水彩1枚〔確認: 目録・公開解説〕

- 公開解説（矢嶋執筆の原文をそのまま掲載、との注記付き）: **「青梅街道の追分といって天沼田んぼ、阿佐ヶ谷田んぼへの用水の分岐点。現在川は暗きょにして下水道、川の上は商店会の仮自転車置場になっている。左の畑が協和銀行、右の畑が公生堂書店の場所。左上方に見えるのが天沼キリスト教会。此の川は多摩川羽村の堰より取り入れた千川上水の分流である。杉並方面は此の水の恩恵を受けた。」**
- 矢嶋又次（明治38年〜昭和63年・荻窪の矢嶋足袋店生まれ）が70歳の昭和51年（1985）より記憶をもとに描いた記憶画シリーズ。
- 目録：https://adeac.jp/suginami-city/catalog/mus-003860

## ②「清水の湧水地」mus-003878・1978年（昭和53年）・水彩1枚〔確認: 目録・公開解説〕

- 公開解説（同・原文）: **「昔より此の地に清水の湧水池があり、青梅街道（清水郵便局際）より分水した千川用水と共に沓掛田圃用水と共に合流して、多くの稲作に利用された。今は湧水も少なく、余水は下水道に流している。場所は清水一丁目井口彰夫氏所有であり、山本氏宅地内にある。清水の町名も此の遊水池に依るものと思ふ。」**
- キーワード：青梅街道／清水。地域・場所：井草・今川・清水・桃井。
- 目録：https://adeac.jp/suginami-city/catalog/mus-003878

## 意義〔観察〕

- ①**青梅街道の追分が「天沼田んぼ・阿佐ヶ谷田んぼへの用水の分岐点」で、現在は暗渠（下水道）・川の上は商店会の仮設自転車置場**という現況説明＝**天沼・阿佐ヶ谷方面への千川上水分流（分水）の分岐点位置が記憶画の解説文で具体化**された（「多摩川羽村の堰より取り入れた千川上水の分流」という水系認識の文言も矢嶋自身の表現として確認）。
- ②**清水（杉並区清水一丁目）の湧水池が千川用水（青梅街道の分水）・沓掛田圃用水と合流して稲作に利用された**という湧水・用水の重層利用の記述＝**杉並区側の湧水地点の一次的記憶記録**。「清水の町名も此の遊水池に依るものと思ふ」は矢嶋自身の私説（断定しない）。
- 「沓掛田圃用水」の呼称はrepo初出候補（他史料での用例確認は未実施）。
