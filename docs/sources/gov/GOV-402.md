# [GOV-402] 触留第20冊 — 中野筋御成の道筋（小瀧橋御渡・小淀山御立場脇・神田上水御伝橋文言候補・鶴/鶉御用）〔第167回〕

- **書誌〔確認〕**: 『触留』第20冊（幕府の触書の写し綴・NDL次世代デジタルライブラリー [book/2549597](https://lab.ndl.go.jp/dl/book/2549597)）。巳九月の触が基調で、江川太郎左衛門の船打稽古・「墨利加使節出府」に伴う通行規制の触等が同居する（幕末期の冊。**巳年の確定は文言にないが、墨利加（アメリカ）使節の江戸出府の触が同居することから安政4丁巳〔1857・ハリス使節の江戸下宿〕候補が挙げられる。断定は保留**）。**引用文言はすべてOCR由来で要原文照合。**
- **中野筋御成の道筋全文〔確認・核心・repo初出〕**: 冊内に同一道筋が2系統（御小人目付宛・御普請方筋宛）で採録される。第1（巳九月三日ごろ）: 「**御道筋矢来御門ゟ田安御門外森精蔵屋敷前脇火消屋敷脇通り高木兵部少輔屋敷牛込御門外神楽坂通肴店町酒井若狭守屋敷前榎町済松寺前早稲田町馬場下町ゟ高田越来屋共庭御通抜諏訪谷台通鶴御用上戸塚村居村道ゟ小瀧橋御渡上落合村往還野道通り題御用新井村薬師境内御通抜同村中野村野道通同所往還ゟ御膳所中野村宝仙寺還御中野村野道通り小淀山御立場脇ゟ神田上水御伝橋御渡柏木村野道通鶉御用相済成子町内藤新宿通り大木戸四ッ谷往還通り左え荒木横町ゟ松平摂津守屋敷前通尾張殿屋敷前通八幡前右之市ヶ谷御門左分三番町通**」。第2（九月十日）: 「**…椹町済松寺前早稲目町馬場下町より高内植木屋共庭御通拵諏訪公台通鶉御用上戸塚村居村道ゟ小滝橋御渡上落合村往還野々道通鶉御用新井村薬師境内御通掠…小笠山御立場脇神内上水御伝橋御渡…**」＝**矢来御門→田安御門外→牛込御門外神楽坂通（肴店町・酒井若狭守屋敷前）→榎町済松寺前→早稲田町馬場下町→高田越→諏訪谷台通（鶴御用〔第2系統は鶉御用〕）→上戸塚村居村道→小瀧橋御渡→上落合村往還野道（鶉御用〔第1系統は「題御用」＝崩れ〕）→新井村薬師境内御通抜→中野村野道→御膳所中野村宝仙寺（還御）→中野村野道→小淀山御立場脇（第2系統「小笠山」＝崩れ候補）→神田上水御伝橋御渡→柏木村野道通（鶉御用相済）→成子町→内藤新宿→大木戸→四ッ谷→荒木横町→市ヶ谷御門**という御成の道筋〔**①小瀧橋を御成の渡河点として実利用した記録（[BOOK-148](../books/BOOK-148.md)の1933年時点の字小瀧橋・[GOV-366](GOV-366.md)〔方位起点の小瀧橋〕と対校される幕期の実利用文言・repo初出）、②「御伝橋」＝神田上水に架かる橋の名として2系統ともに現れる文言候補（位置は宝仙寺〔中野村〕から柏木村への間の神田上水＝淀橋付近の渡しと読むのが自然だが、「御伝橋」が「御淀橋／淀橋」のOCR崩れか、独立の橋名かは原画像照合まで断定しない・repo初出の橋名文言候補）、③諏訪谷台通の鶴御用（第2系統は鶉御用）と上落合村野道・柏木村野道の鶉御用の狩猟地点文言（中野町誌等の鶉狩り跡の記録系統に先立つ実務記録候補）、④御膳所が中野村宝仙寺であったこと（小金井筋御成〔[GOV-398](GOV-398.md)・[GOV-401](GOV-401.md)〕の吉祥寺村名主宅との対照）、⑤小淀山御立場脇の通過（小金井筋御成の小淀山御立場と同じ中野村内の御用向地の系列）**〕。

## 制限・未解決

- ①巳年の確定は不可（墨利加使節出府の触の内容〔ハリス使節の1857年出府か〕の原確認まで保留）。②「御伝橋」の原字形は最重要の照合案件（「淀橋」崩れ説と独立橋名説の両方を保持）。③「高田越来屋共庭御通抜」の「来屋共庭」（茶屋庭か）・「上戸塚村居村道」の読み・「小笠山」（小淀山崩れ）・「神内上水」（神田上水崩れ）・「題御用」（鶉御用崩れ）等の崩れ文言は原画像照合必須。④諏訪谷台の「鶴御用／鶉御用」の両読みのどちらが正しいかは2系統の対校では決まらない。⑤御成の主体の比定は不可。
