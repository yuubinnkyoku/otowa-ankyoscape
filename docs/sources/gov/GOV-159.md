# [GOV-159] 都市計画東京地方委員会 議事速記録 第2号（1930年7月28日・三河川改修決定）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第2号』（帝国議会に提出する議案関係）・NDL次世代デジタルライブラリー [book/1212897](https://lab.ndl.go.jp/dl/book/1212897)。1930年（昭和5年）7月28日の第2回本会議（委員長清浦奎吾）速記録。**すべての引用は同館OCRテキスト由来であり、数値・橋名等は原文画像との照合を要する。**
- **議第七号「東京都市計画河川改修及其ノ事業執行年割決定ノ件」〔確認・repo初出の本文〕**: 1930年（昭和5年）7月28日内務大臣安達謙藏発議。**立会川・神田上水・谷端川の3河川を一括して都市計画河川改修に決定**、総経費**520万9千円**（国庫補助対象・事業費）、執行期間**昭和5年度〜昭和8年度の4箇年継続**、執行者東京府知事。年度割は昭和5年度約8.8%・6年度約35.4%・7年度約37.8%・8年度約18%〔最末年度の厘位はOCR判読不能〕。原案可決。これが[NDA簿冊 附Ｂ09002100（谷端川附図・GOV-135）](GOV-135.md)や[PAP-064](../papers/PAP-064.md)の引用する1930年8月8日決定の委員会側審議記録である。
- **谷端川の現況説明（1930年時点）〔確認・repo初出の公式文言〕**: 「谷端川ハ北豊島郡長崎町**字境窪**ニ於テ**旧千川上水ヨリ分水シ**、板橋町及西巣鴨町ノ境界ヲ流レ、板橋駅附近ニ於テ鉄道**赤羽線下**ヲ経テ**流水ノ殆ド全部ヲ**……**既ニ完成セル所謂板橋放水路ニヨリ石神井川ニ放流シ**、其ノ残余ハ両岸及付近ノ下水ヲ合セテ西巣鴨町ト滝野川町ノ境界ヲ経テ巣鴨町ヲ貫キ、大塚駅ノ東ニ於テ山手線ヲ貫キ、**其ノ下流ハ市内ニ入リ千川トナリ**、小石川区ヲ経テ**水道橋際ニ於テ神田川ニ合流ス**」。起点より市郡界（山手線下）に至る延長**約8,000m**、流域面積**約866ha（260万坪）**。1930年時点で谷端川名義の流水は板橋放水路（下水道速成事業として完成済）で石神井川側に排除され、下流は「千川」呼称で神田川に接続していたことの**制度文書による明文**。境窪（さいくぼ）分水点（[GOV-129](GOV-129.md)の境窪証言）・板橋放水路完成年代（READMEの1924/25年次問題）・下流千川呼称（[GOV-023](GOV-023.md)ほか）を一枚の公文書文言で裏付ける。
- **水害・現況の欠陥〔確認〕**: 屈曲甚だしく、幅3.6〜6m・深1.5〜3m・平均勾配1/400、護岸工なく、板橋放水路下流では汚物塵芥の堆積・悪水停滞があり、豪雨の度に両岸に氾濫、被害の著しいのは板橋放水路より上流で下流部は局部的浸水のみ〔文言はOCR・要照合〕。
- **谷端川改修計画要綱（1930年決定時）〔確認・repo初出の設計一次数値〕**: 改修区間＝**西巣鴨町大字池袋の西前橋下流約百米（55間）から巣鴨町下水道谷端川下水幹線接続点（山手線下）まで、延長約3,001m（1,651間）**。それより上流部の改修は将来に待つ。上流からの流水は全部板橋放水路で石神井川に放流済みのため、改修区間は流域内の雨水・汚水のみを対象とする。在来河川の利用・屈曲の矯正・勾配平均化。構造＝**上流（板橋放水路上流）は矩形開渠（幅6m・深2.42m／2.57m・鉄筋コンクリート護岸高4.67m）**、**下流は全部暗渠（円形渠径0.3〜1.2m・矩形渠幅2.43〜3.5m・深1.82〜2.63m）**。橋梁＝**改築11橋＋橋台根固1橋**、鋼桁・鉄筋コンクリート桁・**木桁**の別を区間表に列挙。区間表に**谷端橋・鎌倉橋・蛇○橋**の橋名が現れる〔橋名はOCR判読・要照合〕。開渠勾配1/600・1/400、暗渠勾配1/100〜1/500等の区間別数値あり〔要照合〕。
- **三河川一覧表〔確認・数値はOCR要照合〕**: 立会川3,564m（荏原郡荏原町品川用水交叉点〜海）・神田上水7,480m（豊多摩郡中野町寿橋〜東京市郡界）・**谷端川3,002m（西巣鴨町字池袋〜巣鴨町山手線下）**。谷端川のみが「旧千川上水の分水を源とする開渠水路」であり、他の2河川とは起源が異なることが対比される。
- **位置づけ〔観察〕**: READMEの谷端川1930年代改修（1930.7決定→[1934年変更（GOV-160）](GOV-160.md)→[1935年度割延長・受益者負担（GOV-161）](GOV-161.md)→1940年完成）の**設計一次記録の出発点**。西前橋（[BLOG-233](../blogs/BLOG-233.md)・[BOOK-109](../books/BOOK-109.md)）が改修区間上流端の基準点であることを初めて公文書レベルで確認。
