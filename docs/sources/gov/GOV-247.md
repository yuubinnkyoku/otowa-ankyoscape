# [GOV-247] 神田玉川上水留[8]（明治2年正月）— 明治新政府への帳簿引継ぎと千川家の上水料上納

- **書誌〔確認〕**: 『神田玉川上水留』[8] 「明治二巳年正月」冊。NDL次世代デジタルライブラリー [book/2587524](https://lab.ndl.go.jp/dl/book/2587524)。明治2年（1869）正月の神田上水・玉川上水の行政記録。**引用文言はすべてOCR由来で要原文照合。**
- **会計官営繕司への帳簿引継ぎ〔確認・上水行政の明治新政府移管の一次記録〕**: 明治2年2月11日と読める日付の帳簿引継ぎ目録——「**神田木白堀渡賃銭取集帳**」（「神田木」は「神田上」のOCR誤読か・要照合）「**武家町出銀取集帳四冊**」「**水銀取集帳四冊**」「**両上水御門々持場絵図**」等＝**①白堀渡賃銭取集帳②武家町出銀取集帳（[GOV-243](GOV-243.md)慶応3年武家方水銀取集帳の系統）③水銀取集帳④両上水（神田・玉川）の御門々持場絵図**が、会計官営繕司（明治新政府）に引継ぎされたことの目録。＝[GOV-243](GOV-243.md)（慶応3年の幕府側取集帳）→本冊（明治2年の引継ぎ）→[GOV-249](GOV-249.md)（明治2年9月の民部省上水屋敷改への上納）という**上水帳簿の幕府→明治政府移管の連続が目録レベルで確認できる記録**。「持場絵図」は[GOV-234](GOV-234.md)の三水道町の「古来持場」と同系の用語（絵図の実物は未確認）。
- **千川善蔵・千川平吉の玉川上水料代金〔確認・repo初出の金額〕**: 「**玉川上水料代金 四両壱分**」（玄辰年分＝慶応4年分と読める文言）を「**砂川村 千川善蔵**」「**千川平吉**」が東京府上水屋敷改役所に上納した記録＝**[GOV-246](GOV-246.md)（慶応4年水料堰料上納帳）に続き、明治2年正月時点でも千川善蔵・千川平吉（砂川村）が玉川上水の水料の上納人であることを裏付ける記録**（金額4両1分・上納先「東京府上水屋敷改役所」＝明治新政府の上水行政機関の実名）。
- **保谷村名主伊左衛門の呑水料〔確認〕**: 「**保谷村名主伊左衛門**」の呑水料（水呑料）の文言＝[GOV-246](GOV-246.md)の上保谷村伊左衛門と同人物と読める上納記録（保谷村は千川上水の通村・[GOV-211](GOV-211.md)千川上水五代記の保谷村分水と対照）。
- **白堀通余垂板の引継文言〔確認〕**: 「**白堀通余垂板其のし共無渡しらす**」と読める文言（「其外共無渡しらす」か・原字形要照合）＝**余垂板（[GOV-232](GOV-232.md)弘化普請の白堀通の主要構造材・801間）が明治2年正月時点でも帳簿引継ぎの対象として存在したことの文言**（「無渡」の語義＝渡賃銭の未納か材料の未納かは要照合）。

## 制限・未解決

- ①すべてOCR由来で、特に「神田木白堀渡賃銭取集帳」の「木」（「上」の誤読か）・「玄辰年」の割付（慶応4辰年か）・「其のし共無渡しらす」の原文言は要照合。②引継ぎ目録の帳簿の現存先（東京府への移管後の所在）は未確認（[BOOK-136](../books/BOOK-136.md)東京府史行政篇の『神田上水留』28冊との関係が対校候補）。③千川善蔵・千川平吉と練馬村千川家（[BOOK-126](../books/BOOK-126.md)）の関係は[GOV-246](GOV-246.md)と同様に未確定。④「東京府上水屋敷改役所」の組織の沿革（民部省土木司〔[GOV-237](GOV-237.md)〕との前後関係）は要整理。
