# [GOV-214] 玉川上水留（慶応3年）— 茅場町千川屋敷の玉川上水普請金出銀の記録

- **書誌〔確認〕**: 『玉川上水留』（慶応3卯年4月・「玉川上水御組合普請金町方出銀取集帳」と思われる勘定帳・番組別に町方の出銀を集計）。NDL次世代デジタルライブラリー [book/2587447](https://lab.ndl.go.jp/dl/book/2587447)。**引用はOCR由来で、文言・数値は原文照合を要する。**
- **南茅場町千川屋敷の出銀〔確認・茅場町千川屋敷の負担の実態（repo初出）〕**: 六番組の枠で——「**六番組南茅場町弐番之地一合銀四匁弐分四厘五毛…六番組南茅場町千川屋敷一合銀弐拾九匁三分八厘五毛一合銀拾七匁六分〔三厘壱毛〕…竹島町之内八番組水谷町へ合併致候分…**」〔**①南茅場町の「千川屋敷」が慶応3年（1867）の玉川上水御組合普請金に「一合銀29匁3分8厘5毛」を出銀していたこと、②その直後に続く「一合銀17匁6分3厘1毛」の別枠出銀（同じ千川屋敷分か隣接項目かはOCRの行対応からは確定できない・要照合）**＝**八丁堀・茅場町側の「千川屋敷」（[BOOK-131](../books/BOOK-131.md)元禄12年入堀半埋立・[BOOK-133](../books/BOOK-133.md)万延元年出火・[GOV-219](GOV-219.md)類集撰要の「茅場町千川屋敷地主」）が、江戸期末期（1867）まで町方の上水関連賦課の負担主体として存続していた実務記録**。千川上水の請負人たる小石川白山前町の千川屋敷（[GOV-208](GOV-208.md)）とは別主体である点は[BOOK-131](../books/BOOK-131.md)の注意を維持する〕〔29匁3分8厘5毛という額は同一帳面の中で他の町の数値と比較して突出しているが、面割・間割の計算単位は帳面の体裁からは確定できない〕。
- **位置づけ〔観察〕**: 玉川上水の組合普請金（上水の維持費を受益町方が割り当てる仕組み）に千川屋敷が番組（六番組）の中の一項目として計上されていることは、①南茅場町千川屋敷が町方組織（名主・月行事の支配下）に組み込まれていたこと、②水道関係の賦課の単位として「屋敷」単位の計上があったこと、を示す。**小石川白山前町の千川屋敷が千川上水由来の拝領屋敷であるのに対し、茅場町の千川屋敷がなぜ玉川上水の組合に出銀していたのか（両「千川屋敷」の起源関係）は未確認（断定しない）。**
