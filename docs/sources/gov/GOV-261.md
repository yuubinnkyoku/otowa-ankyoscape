# [GOV-261] 東京府郡部集団的不良住宅地区図集（1928）— 高田町水窪169番地の不良住宅地区記録と谷端川・千川上水沿線の地区リスト

- **書誌〔確認〕**: 東京府学務部社会課『**東京府郡部(隣接五郡)集団的不良住宅地区図集**』（1928年1月・大正15年〔1926〕6月〜8月調査と読める）。NDL次世代デジタルライブラリー [book/1280202](https://lab.ndl.go.jp/dl/book/1280202)。隣接五郡（北豊島郡等）の集団的不良住宅地区（貧民街・バラック集住地区）を地番単位でリストし写真図版を付した府調査。OCRは図版キャプション・目次の崩れが多く、文言は要原文照合。
- **「高田町水窪一六九番地附近」〔確認・repo初出の水窪の1920年代土地利用記録〕**: 地所リストに「**高田町水窪一六九番地附近**」＝**大正15年（1926）調査時点で、高田町大字水窪（水窪川源流域の旧水久保・水窪一帯）169番地附近が集団的不良住宅地区として府調査の対象になっていたことの地番レベルの記録**。〔**水窪川源流域（現在の豊島区西池袋〜南池袋側の水窪谷）の1920年代の土地利用（不良住宅地区化）を示す府の公式調査記録**。水窪谷の水田・畑地の都市化と下層住宅地化の過程のdatapoint。地区の規模・世帯数・写真図版の有無は本文判読・原図照合の課題。〕
- **千川上水・谷端川沿線の地区リスト〔確認・repo初出〕**: 同リストに次の地区が並ぶ——「**西巢鴨町向原三、三七一番地附近**」「**西巢鴨町向原二、九九七番地附近**」「**高田町雜司ケ谷飛地一、一七九番地**」「**巢鴨町宮下一、六〇二番地附近**」「**巢鴨町三丁目二〇番地附近**」「**西巢鴨町庚申塚六一六番地附近**」「**西巢鴨町集鴨五二一番地附近**」〔**向原・宮下・庚申塚＝谷端川中流域の沿線地区、雑司ヶ谷飛地＝弦巻川中流域側の地区が、いずれも1926年調査で集団的不良住宅地区として把握されていたことの地番レベルの記録**。千川上水暗渠化（大正期）以後・谷端川改修（昭和期）以前の沿線低地の住宅状況の府側の切り口として、[GOV-258](GOV-258.md)（1927年谷端川改修計畫說明書）・[GOV-165](GOV-165.md)（1931年長崎町）の文脈に前置きできる土地利用記録。〕
- **庚申塚616番地の写真図版〔確認・図版キャプション〕**: 図版キャプションに「**西菓鴨町庚申塚六一六番地 不良住宅地區外景ノ一部**」「**不良住宅地區通路**」（庚申塚616番地付近と読める）＝**庚申塚地区の不良住宅の外景・通路の写真図版が本書に収録されていること**。〔写真そのものの判読（地物・地形・水路の有無）は未実施。原図確認により谷端川沿いの都市環境の1920年代の視覚資料になり得る。〕
