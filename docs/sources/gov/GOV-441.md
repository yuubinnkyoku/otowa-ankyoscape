# [GOV-441] 御府内往還其外沿革図書 十四 — 旅籠町明地の井戸の通時チェーンと神田側の平次郎拝借地文言

- **書誌〔確認〕**: 『御府内往還其外沿革図書』**十四**（**天保十五辰年三月調**・「外神田湯嶋天神下下谷辺一円之絵図一枚」・表紙に「東京府」の文字を含む）。NDL次世代デジタルライブラリー [book/2571704](https://lab.ndl.go.jp/dl/book/2571704)。目録に昌平橋外明地辺〜神田川通和泉橋の広道（神田佐久間町・同松永町・同相生町・同花房町代地・同仲町・**同旅籠町**・同須田町代地辺之部）を筆頭に置く冊。**引用文言はすべてOCR由来で要原文照合**。
- **神田旅籠町明地の井戸の通時チェーン〔確認・[GOV-352](GOV-352.md)（昌平橋外明地の堀井戸の伺書）の独立対校〕**: 旅籠町弐丁目の明地（元柳原町・馬喰町四丁目地続の堀代地で当時町名神田旅籠町弐丁目）の沿革書上に——「**享保八卯年九月 明地之内北之方に有之候井戸壱ヶ所 神田旅籠町弐丁目拝借**」「**同十一午年二月 神田旅籠町壱丁目弐丁目御預 安永九子年五月 深川永堀町 加藤屋甚五郎 冥加金上納 年季清負井戸に成 天明四辰年五月 千川上水請負人引請井戸に成候節 町方持被成二成**」〔**①明地内の井戸が享保8卯年（1723）9月に旅籠町二丁目の拝借として現れ、享保11午年（1726）2月には旅籠町壱丁目・弐丁目の「御預」に変わる前史、②安永9子年（1780）5月に深川永堀町の加藤屋甚五郎が冥加金上納の年季清負井戸とする請負、③天明4辰年（1784）5月に千川上水請負人が引き受けた節に「町方持」へ変わったこと、の一連の記述**。同文言は本冊内に2回現れる〕。〔**対校**: [GOV-352](GOV-352.md)（書上帳第40冊の伺書）は昌平橋外明地際の堀井戸について「**安永七戌年** 深川永堀丁 加東や甚五郎与申者」の5ヶ年季請負（冥加金30両/年）→天明2寅年千川上水出来で水汲人無之→牧野大隅守勤役中に千川上水請負人共へ無年限預置・天明4辰年ゟ上納、と記録する。**本冊は①請負開始の年次対立（安永7戌年 vs 安永九子年〔1780〕5月）、②請負人名の表記対立（加東や甚五郎 vs 加藤屋甚五郎・いずれも深川永堀〔長堀〕町）、③天明4年5月の月次と「町方持」の運用細部、を独立に与える**。同一井戸（昌平橋外＝神田旅籠町側の明地際）かについては両史料の文言の重なりから有力だが、明地内の北之方・南之方のどちらの井戸に当たるか（本冊は北之方・南之方の2井戸の記述を含む）は原文照合まで保留する**〕。〔時系列上の位置づけ: 安永9年10月の掛渡仰付（[GAZ-041](../gazetteers/GAZ-041.md)〜045）→天明2年通水開始文言（GOV-352）→**天明4年5月の請負井戸化＝千川上水の末端給水と市中の既存井戸の接続のdatapoint（repo初出の月次）**→天明6年水銭404文＋204文（[GAZ-082](../gazetteers/GAZ-082.md)・[GAZ-114](../gazetteers/GAZ-114.md)）→天明7年4月差止（[GOV-215](GOV-215.md)〜[GOV-218](GOV-218.md)）〕。
- **神田側の雑司ヶ谷村百姓平次郎拝借地の文言〔確認・[GOV-347](GOV-347.md)（四谷市谷側菜園場）・[GOV-358](GOV-358.md)（浅草側菜園場）に続く神田側の同型文言候補〕**: 神田佐久間町四丁目河岸地（元柳原町替地・当時町名神田冨松町）の地所の沿革書上に——「**明和四亥年五月 明地外国出来 百姓平次郎拝借地に成**」「**都合五ケ所之明地内壱ケ所明地は前に出る 雑司ヶ谷村百姓平次郎拝借地 拝借地北之方 町方薪置場に成二成 同五子年五月 右拝借地之内東之方弐ヶ所被召上 板倉佐渡守当時中屋敷に被下**」〔**①明和4亥年（1767）5月に神田川岸の新明地が「外国出来」（明地が発生的に生じた旨の文言候補）し、雑司ヶ谷村の百姓平次郎の拝借地となったこと、②その拝借地の北之方が「町方薪置場」化したこと、③明和5子年（1768）5月に東之方2ヶ所が召し上げられ板倉佐渡守の当時中屋敷に下されたこと**。平次郎の名はGOV-347・GOV-358の文言と同名で、**雑司ヶ谷村百姓平次郎の拝借地の文言の神田側用例（同一人物かは本冊では確認できない）**。「町方薪置場」は平次郎文言群でrepo初出の細部〕。
- **断片文言（地震）〔文言候補・崩壊著しく要照合〕**: 同じ佐久間町四丁目河岸地の書上に「**同町拝領町屋共 地震出来 右町屋強(?) 明地を隔…**」の崩壊文言があり、**拝領町屋の被害を「地震出来」と記す文言候補**が現れる〔地震の年次・対象地震の比定は本文の前後関係の照合まで保留する〕。
