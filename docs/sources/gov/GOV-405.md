# [GOV-405] 大東京新区町名地番表 — 戸塚町3丁目の字馬尿川の1932年公式地番表記〔第167回〕

- **書誌〔確認〕**: 東京市編『大東京新区町名地番表』（1932〔昭和7〕・NDL次世代デジタルライブラリー [book/1212497](https://lab.ndl.go.jp/dl/book/1212497)）。東京市が1932年の区編入（大東京）に際して編纂した区町名・字名・地番の公式一覧表。**引用文言はすべてOCR由来で要原文照合（本書は活字印刷だがOCRの列崩れ・算用数字の誤読が多い）。**
- **戸塚町3丁目の字名表中の「馬尿川」〔確認・核心〕**: 「**戸塚町三丁目淀橋區（豐多摩郡戶塚町）**」の字名・地番表の中に「**…一、〇六九ノ二一、〇六九ノ五馬尿川一、〇七〇ノ二一、〇七〇ノ三〓水川一…**」＝**旧豊多摩郡戸塚町（淀橋区）の字名の列に「馬尿川」が登載され、その地番が一〇六九ノ二一・一〇六九ノ五等として列挙されている**〔**①[BOOK-190](../books/BOOK-190.md)（土地概評価・1922）の「字、馬尿川一〇七〇-一〇七六番地」・[BOOK-149](../books/BOOK-149.md)（戸塚町誌・1931）の小字名「馬尿川自一〇七〇番至一〇七六番」と同じ字名が、1932年の東京市編入時点の公式地番表でも「〇六九ノ二一・〇六九ノ五」の地番つきで登載された＝**第3時点の確認**（番地の読み〔一〇七〇ノ一〜〇七〇ノ六等の崩れ〕は原照合要）、②同じ字名列に「**〓水川**」（「秣川」のOCR崩れ候補）・「**源兵衞向芝原**」・「**戶塚馬場崎**」等の隣接字名が並ぶ＝馬尿川・秣川の字が戸塚町3丁目の字群として隣接登載される構造の裏付け候補**〕。
- **位置づけ〔観察〕**: 馬尿川の字名記録は1922（BOOK-190）→1931（BOOK-149）→1932（本書・東京市の公式表）と3時点で連続し、区編入後も字名として存続したことが市の公式資料で裏付けられた（区編入時に町名・地番が再編される中での字名の残存の記録）。馬尿川＝秣川の流れに沿う窪地の字名という理解（BOOK-149由来説）は変わらず、独立の川の現勢とは断定しない。

## 制限・未解決

- ①地番のOCRの誤読（〇六九ノ二一・〇六九ノ五等）は原文照合必須（BOOK-190/BOOK-149の一〇七〇番系との対応の確認が前提）。②「〓水川」が秣川の崩れであるかは原画像で要確認（馬尿川の直後に置かれている字名）。③本表は「旧町名／旧字名」の対照列を含むため、編入後の新町名体系との対応の精読は次回以降の課題。
