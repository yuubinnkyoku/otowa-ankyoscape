# [GOV-457] 日暮里町現状調査 — 府計画の三河島系統下水道組合の1931年定点

- **書誌〔確認〕**: 『日暮里町現状調査』（東京市臨時市域**擴張部**編・[book/1900491](https://lab.ndl.go.jp/dl/book/1900491)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**日暮里町（1932年荒川区→荒川區周辺）冊**＝**本シリーズの南東端＝神田川（江戸川）下流左岸・三河島系統の排水区に属する側の基準点として、高田町（[GOV-454](GOV-454.md)）等の「新設＝三河島系統」文言の受け皿側の対照冊**。谷端川・千川の直接文言は本冊fulltext走査限りで陰性（陰性記録として掲げる）。
- **下水道＝三河島系統・府計画・組合事業〔文言候補・本ファイルの核心〕**: 「**下水道(事業)ハ三河島系統(ニシテ)…東京府土木部(ノ)計画(ニ依リ)…昭和五年三月…調査(シ)…組合事業トシテ(認可申請中?)**」＝**①下水道が三河島系統であること、②東京府土木部の計画に基づくこと、③昭和5年（1930）3月調査、④（日暮里町＋周辺町村の）組合事業として認可申請中であること**〔**①三河島系統＝谷端川下流側（明治の神田下水・三河島汚水処理場系統）への接続が府（東京府土木部）主導の計画で進んでいたことの行政側定点、②「組合事業」という形式＝単独町事業ではなく広域組合（三河島汚水処理場の受け側）への参加方式の記録候補、③[GOV-454](GOV-454.md)高田町の「新設三河島系統」と[GOV-455](GOV-455.md)長崎町の「石神井系統・処分場＝江北村」の系統地図の一角**〕。事業費191,876円（昭和5〜10年度・候補値）・計画管渠延長13,141.96間（候補値）＝**「間」単位の管渠延長＝江戸期以来の尺貫法単位の下水道計画の実務例（メートル法移行期の単位併存の定点候補**・[GOV-454](GOV-454.md)のメートル表記と対照。OCR数字要照合）。
- **地勢〔文言候補〕**: 「**東部(ハ)低地(ニシテ)…西部(ハ)台地(ナリ)…海抜78尺程度**」＝**谷端川・神田川下流側の低地（荒川・隅田川氾濫原）と日暮里・谷中台地の境の地形の定点**（谷中＝谷端川源流側の台地の東縁・[GAZ-113](../gazetteers/GAZ-113.md)谷中総説の蛍澤・藍染川系統の地域と接する。海抜78尺程度＝尺貫法の高度表記の例。要照合）。
- **帳簿文言〔確認〕**: 人口・面積・財政・交通（日暮里駅・京成電鉄等の文言候補・OCR崩壊大）・学校・社会事業＝1932年市域拡張直前の日暮里町の帳簿。
