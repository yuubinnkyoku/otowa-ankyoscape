# [GOV-361] 市中取締類集・名主取締之部 — 天保期の名主支配場としての雑司ヶ谷鬼子母神門前〔第158回〕

- **書誌〔確認〕**: 『市中取締類集』の[66]冊「名主取締之部」（町奉行所の市中取締関係の法令・一件を類集した帳簿の1冊・所収文書は天保期〔yearは文書紀年の代表値として1837〕）。NDL次世代デジタルライブラリー [book/2572092](https://lab.ndl.go.jp/dl/book/2572092)。**本冊はOCRの崩壊が非常に大きく、引用文言はすべて原画像照合を要する**。
- **名主の支配場10ヶ所列挙の「雑司ヶ谷鬼子母神門前」〔確認・文言候補〕**: 牛込原町系の名主の支配場の列挙（都合10ヶ所）の中に「**雑司ヶ谷鬼子母神門前**」が現れる文言候補＝**天保期に鬼子母神門前（門前町）が牛込原町系の名主の支配場（町奉行支配の町方単位）の一つであったことの実務レベルの記録候補**。〔[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考巻52・文政丙戌書上の雑司ヶ谷町・鬼子母神門前の条）・[GOV-343](GOV-343.md)（南撰要類集・延享3年の町方御支配化・門前文言〔第152回〕）より後の、**文政町方書上以降の天保期の門前町支配の継続を示す datapoint 候補**。支配場列挙の全体（他の9ヶ所の町村名・当該名主の実名）はOCR崩壊のため要照合。〕
- **門前の家主仙右衛門外三人の借用金・支配の一件〔確認・文言候補〕**: 「**巳年…雑司ヶ谷鬼子母神門前 家主仙右衛門外三人…金百五拾両…借用…**」と読める文言群＝**鬼子母神門前の家主仙右衛門外3人が金150両を借用した一件と、その支配（名主支配の実務）をめぐる記録の候補**。〔門前町の家主の実名（仙右衛門）と金銭一件の記録候補＝門前町の経済活動の実務レベルの datapoint（文言細部の文脈〔借用の相手・年貢か借用金か・支配替えの願の文脈〕はOCR崩壊のため要照合・本登録では内容の確定を保留）。**「巳年」の比定（天保8年〔1837〕丁酉か）も含め原画像照合後に断定する。**〕

## 制限・未解決

- ①本冊はこの回で精査した資料の中でもOCR崩壊が特に大きい（片仮名交じりの帳簿）。本登録は文言の所在記録にとどめ、文言の細部（支配場の他の町村名・名主の実名・借用金一件の全容・紀年）はすべて原画像照合を要する。②「雑司ヶ谷鬼子母神門前」の支配が名主の支配場として継続した期間（文政書上〜天保期の間の変化）は本冊だけでは確定できない（[GOV-362](GOV-362.md)の安政3年の名主平左衛門と併せて流れの候補とする）。
- ③牛込原町系名主の支配の系統（原町＝牛込の町方書上の系列〔[GAZ-013](../gazetteers/GAZ-013.md)の原町丁・雑司ヶ谷町の関係〕）と本冊の名主の比定は未実施。
