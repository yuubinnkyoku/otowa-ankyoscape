# [GOV-464] 憲教類典 58 — 享保7年8月の千川上水差止触と「中奥」給水文言

- **書誌〔確認〕**: 『憲教類典』[58]（近藤守重〔近藤重教〕編・江戸後期の公用文書編纂集・NDL次世代デジタルライブラリー [book/2553789](https://lab.ndl.go.jp/dl/book/2553789)）。本冊は川堤・上水関係の条文集で、**享保7壬寅年（1722）の上水系の一斉差止の触文言群**を収める。**引用文言はすべてOCR由来で要原文照合**。
- **享保7年8月18日・19日の千川上水差止触〔文言候補・本登録の核心〕**: 「**享保七壬寅年八月十八日 千川上水之儀 中奥ゟかゝり候事に候故 自今相止候間 其段向々江可被申達候 来ル十月ゟ上水取不申筈候間 可被得其意候 寅八月**」＋「**享保七壬寅年八月十九日 石川近江守殿御渡 御目付え 千川上水之儀 中奥よりかゝり候事ニ候故 自今相止候間 其段向々江可被申達候 来ル十月より上水取不申筈に候間 可被得其意候)**」＝**①享保7年8月18日・19日、千川上水は「中奥に掛かり候事」を理由に「自今相止（停止）」と仰付られ、②「来ル10月より上水を取不申（給水を取りやめる）」旨が御目付を通じて触れ出された**。〔**「中奥に掛かり候事」＝千川上水が幕府奥向き（中奥）に給水していたことを理由に挙げた文言はrepo初出**。既知の給水先（小石川御殿・湯島聖堂・東叡山・浅草御殿等）に「中奥」を加える検討材料だが、中奥＝江戸城御殿の中奥区画への直結給水か、御殿系給水の婉曲表記かは本資料単独では断定しない。8月18日（無署名文言）と19日（石川近江守殿御渡）の2件の同内容文言が並ぶ〕。
- **同時期の上水群の停止文言〔文言候補・周辺比較〕**: 「**享保七壬寅年九月三日（四日） 青山三田両所上水之儀 中奥よりかゝり候事に候故（中興より掛り候事故） 自今は相止候間…来ル十月より上水取不申筈**」＋「**享保七寅年九月五日 本所上水之儀 中興よりかゝり候儀に候得共 殊さし水も不参候故 自今は彌相止候**」＝**享保7年8〜9月に千川・青山三田両上水・本所上水が同じ「中奥・中興掛かり」を理由に相次いで差止められた公文書群**。〔**千川上水の享保7年廃止（風土記稿の享保七年廃セラレテ…用水ニ賜フ系の通説）が、青山三田両上水・本所上水の停止と同じ年月の行政的一斉措置として実施された実務の一次文言**。千川の文言のみ「中奥」・青山三田は「中奥より」/「中興より」の判読対立あり。本所上水の「殊さし水も不参候故」＝水量不足の文言差は断定材料として併記〕。
- **周辺文言〔文言候補〕**: 同冊に市ヶ谷御門〜牛込御門間の御堀での濫りな魚釣りの取締触（享保13戊申5月22日・大森半七郎被相触）など御堀管理文言も収まる（周辺情報としての記録に留める）。
