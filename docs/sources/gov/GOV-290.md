# [GOV-290] 東京市改良水道ノ衛生学的観察（1905）— 千川上水の1905年の残存給水と水質定量

- **書誌〔確認〕**: 遠山椿吉著『東京市改良水道ノ衛生学的観察』（掬精書屋・明治38年＝1905）。NDL次世代デジタルライブラリー [book/845983](https://lab.ndl.go.jp/dl/book/845983)。**引用文言はすべてOCR由来で要原文照合**（[GOV-252](GOV-252.md)（1892年・伴直之助『東京市水道改良意見』）と対になる明治後期の水道論・衛生学的観察）。
- **六派上水の定義と龜有上水〔確認・BOOK-140の裏付け〕**: 「**六派トハ即チ玉川上水神田上水、千川上水、三田上水、靑山上水及龜有上水之ナリ 就中其三田靑山龜有ノ三派ハ中頃ニ廢レテ、新水道設置以前マデ存續シタルハ玉川神田及千川ノ三派ノミナリシ**」＋「**龜有上水ハ元祿年間ニ起リ本所方面ニ給水シタルカ、享保ニ至リテ廢セラル、(考ノ十四二十)**」＝**江戸の六派上水（玉川・神田・千川・三田・青山・亀有）の定義の1905年の書き分けと、亀有上水（元禄年間起立・本所方面給水・享保廃止）の文言**＝[BOOK-140](../books/BOOK-140.md)（「亀有」の上水の記述）の1905年側の裏付け（「考ノ十四二十」は同書が引用する原典の略号か・要照合）。
- **明治36年6月廃止後も現役の千川上水〔確認・repo初出級の観察〕**: 「**而シテ此三派中ノ二派ハ昨三十六年六月ニ廢セラレタ(レトモ?)…千川上水本〓區內ニ遺殘シテ、現ニ同區民一部ノ用水ニ供セラル**」＝**神田・玉川両上水が明治36年（1903）6月に廃止された後も、千川上水が「本〓区」内に遺残し1905年時点で現に同区民一部の用水に供されていた**ことの明記＝**千川上水の廃止年代論（[BOOK-140](../books/BOOK-140.md)の明治40年岩崎所有化・[GOV-077](GOV-077.md)の明治13年会社設立→40-41年解散）の中間点として、1903年以降・1907年以前の実在給水の断面**。区名「本〓」はOCR欠字（同書の旧水道井戸の区名列挙「小石川區・本〓區・下谷區・淺草・本所・深川」で本所区と別個に並ぶことから**本郷区と推定できるが断定せず原画像照合待ち**＝[GOV-252](GOV-252.md)の「本〓（本所か本郷か）」問題と同じ扱い）。
- **千川上水の井戸76個〔確認・repo初出の実数〕**: 「**本〓區ニ千川上水ノ井戶七十六個アリ**」＝「本〓区」の千川上水の井戸76個という1905年の実数の観察（[GOV-252](GOV-252.md)（1892年）の「千川三上水井六千六百六十七」の三上水合計の井数と対照的な、千川単独の区別井数のdatapoint・行割付は要照合）。
- **千川上水の細菌数の定量〔確認・repo初出の水質データ〕**: 「**千川上水ノ細菌數ハ三種中最モ多ク、而シテ其各個試驗中最多六一六〇〇 最少一六〇〇**」＝**千川上水の1立方センチメートル中の細菌数が最多6,160・最少1,600で、玉川・神田（三派中の他の二派）に比べて最も多かった**という1905年の定量記録（「一水中含有ノ細菌數ハ一立方仙迷中ヲ意味ス」の注記つき）＝[GOV-252](GOV-252.md)（1892年の「五里餘の水路に雨水汚水の流入するは二上水よりも甚し」という定性批判）の**定量版・1905年時点の水質の実測値**。
- **沿革説の採録〔確認・対校資料〕**: 「**千川上水ハ元祿年間河村瑞賢ノ計〓ニ係リ、爾後享保以後興廢一ナラス、遂ニ今ノ千川上水ニ至リ、明治十三年岩崎彌太郞等千川水道會社ヲ起シ、舊渠ヲ修理開通シタルモノナリ**」＝**元禄年間の河村瑞賢の計画に係るという説（千川上水の起請者を巡る通説の一つ）の1905年の採録**と、明治13年（1880）の千川水道会社（岩崎弥太郎等）による旧渠の修理開通という整理＝[GOV-077](GOV-077.md)（会社設立）・[BOOK-077](../books/BOOK-077.md)（『千川上水』の沿革説）の対校。
- **神田上水の構造説〔確認・対校資料〕**: 「**恐クハ往時ノ所謂小石川水道ニシテ、天正年間大久保主水ノ創〓ニ係ルノ說稍信スヘシト云フ、源ヲ北多摩郡三鷹村井ノ頭池ニ發シ、豊多摩郡井〓村善福寺池妙正寺池ノ流末ト淀橋ニ於テ分岐セル玉川上(水…)**」＝神田上水を「小石川水道」・大久保主水（主水正）の創立説「稍信スヘシ」とし、**水源を井の頭池とし、善福寺池・妙正寺池の流末を合わせ、淀橋で玉川上水の助水(?)を分岐して関口へ送る**構造の記述＝[GOV-252](GOV-252.md)の神田上水記述（井の頭〜小石川関口）と対になる1905年の整理（妙正寺川・善福寺川の流末が上水に組み込まれたとする観察として千川上水と同じ台地水系の文脈でも参照に値する・文言は要照合）。

- **狹山助水（狹山池助水堀）の章〔確認・repo初出級・2026-11-16第125回精読〕**: 同書第二章（新水道ノ起原及源水）中に**狹山助水の項**（明治35年10月・明治36年3月の水質試験の説明として「**狹山助水ノ成立、經過及附近村落ノ關係ヲ記スルノ要アリ**」と前置き）があり、**狹山池助水堀の1905年時点の同時代的な記述**が残る——
  - 所在・規模: 「**狹山ケ池ハ羽村ノ北方約一里二十餘丁、箱根ヶ崎村ノ畑中ニ在リ、約千坪餘ノ沼池ナリ**」＋「**狭山ヶ池往昔ハ周圍數里ニ亘ル大湖沼ナリシカ、今ヤ其痕跡ヲ止ムルニ過キス**」＝**狹山池＝羽村の北方約1里20余丁・箱根ヶ崎村の畑中・約千坪余の沼池（往昔は周囲数里の大湖沼）**＝[GOV-283](GOV-283.md)（見廻役一件の「箱根ヶ崎村狭山池」）の池の位置・規模の1905年の同時代的記述（Wikipedia「玉川上水」脚注の狹山池＝瑞穂町所在〔西多摩郡瑞穂町＝箱根ヶ崎村の後身〕とも整合）。
  - 経路と「残堀川」の別称: 「**池水ハ之ヨリ石畑殿ケ谷、岸、三ツ木等ノ諸村落ヲ經テ砂川村ニ至リ玉川上水ノ右側ニ開口ス、河長約二里强**」＋「**三ツ木村即チ殘堀川ナリ、此川ハ三ツ木村ニ至リテ大ニ水量ヲ增シ、中藤砂川等ノ諸村ヲ經テ**」＝**①助水堀の経路（狹山池→石畑・殿ケ谷・岸・三ツ木→砂川村で玉川上水の右側に開口・延長約2里強）②三ツ木村から下流は「残堀川」の別称**の1905年の明記＝**助水堀の下流＝残堀川という別称関係の同時代的な一次記録・repo初出**（[GOV-283](GOV-283.md)の第123回課題④〔経路比定〕の1905年側の裏付け・経路の断定は原文照合まで保留）。
  - 助水の称の由来: 「**往古ハ〓流漾々タル泉流ニシテ羽村引入口ニ故障アルニ際シ一時此水ヲ以テ補充シタルモノナリシ、故ニ助水ノ稱アリシモ今ハ却テ村落汚水ノ排泄路ニシテ新水道源水ノ一大汚染源ヲナスニ至ル**」（「〓」はOCR欠字）＝**羽村の引入口（取水口）の故障の際に一時的に補充した水源だから「助水」と呼ばれる**という助水の称の由来説と、1905年時点では「村落汚水の排泄路＝新水道源水の一大汚染源」への転落の指摘。
  - 水質試験（明治35年10月・36年3月・採水計画は西多摩郡羽村引入口から北多摩郡小平村字野…の区間）: 「**狹山助水(七ヶ所ノ平均)細菌數三、〇八二**」＝多摩川（九ヶ所平均）**1,010**・玉川上水（四ヶ所平均）**2,700**・新水路（六ヶ所平均）**1,531**に対して**狹山助水（七ヶ所平均）3,082が最多**で、「**狹山池(池ノ北側及流出口)ニ於テハ三百八十乃至五百**」（多摩川上流〔宮津川流入口の上流〕=440と同水準）＝**狹山池自体の水は細菌数380〜500と飲料許容水準だが、助水堀を流れる間に沿岸村落の汚染で3,082まで増える**という1905年の定量の指摘＝千川上水の最多6,160（上記）と並ぶ、当書の源水汚染の実測例。
  - 汚染実況: 「**該地方ノ農民ハ此助水路ニ於テ糞桶ヲ洗ヒ又…種々ノ不潔物ヲ投入スルノ風アリ大雨ノ後玉川本流ノ赤褐色汚濁ヲ呈スル**」＋「**岸村殿ケ谷村石畑村セル屎尿亦之ニ混入ス、其他不潔ノ細流三四條**」＝**農民の糞桶洗い・不潔物投入・沿岸3村（岸・殿ケ谷・石畑）の屎尿混入・大雨後の赤褐色汚濁**という汚染の実況記録＝Wikipedia「玉川上水」脚注（[GOV-283](GOV-283.md)・三次資料）の「明治期の水質悪化」の**1905年の同時代的な裏付け**（脚注の出典の一次確認は継続課題だが、内容面から脚注記述の実質的な裏付けとなる）。
- **「本〓區」＝本郷區の同定の強化〔確認・OCR由来の推定・第125回追記〕**: 同書の細菌数表の区名の配列が「**麴町・神田・日本橋・京橋・芝・赤坂・麻布・四谷・牛込・小石川・本〓・下谷・淺草・本所・深川**」＝東京15区の標準的な配列で「**本〓」は小石川區と下谷區の間**に位置することから、**「本〓區」＝本郷區**の推定が強化された（旧水道井戸の区名列挙で本所區と別個に並ぶ従来の観察と一致。OCR欠字のため原画像照合まで断定はしない）。

## 制限・未解決

- ①「本〓區」の区名（本郷区か本所区か）はOCR欠字で、同書の表の区名の並び（本所区と別個に現れる・第125回に細菌数表の区名配列で小石川區と下谷區の間であることも確認）から本郷区の可能性が高いが原画像照合まで断定しない。②細菌数6,160／1,600の行割付（どの試験日・どの井戸のデータか）と井戸76個の帰属区は表組みのOCR崩れがあり要照合。③狹山助水の章の文言（池の位置・経路・村名・細菌数）もOCR由来で要原文照合（「河長約二里强」の「强」の表記・採水10ヶ所の内訳の数字も含む）。④「昨三十六年六月ニ廃セラレタ(レトモ)」の「昨」の表記から1905年（明治38年）の出版に対して1903年6月を「昨年」とする文言の整合（1904年説の可能性の吟味）は要照合（明治36年＝1903年の読みが通説的前提）。⑤河村瑞賢計画説・大久保主水創立説は同書の採録した説であり、本資料だけで説の優劣は判断しない（[BOOK-077](../books/BOOK-077.md)等の沿革記述との対校課題）。
