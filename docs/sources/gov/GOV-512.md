# [GOV-512] 東京都建設局「令和7年7月10日豪雨における調節池の効果について」〔神田川水系の現行治水施設の定量実績資料・repo初出〕

## 内容〔確認: 公式ページ本文・2026-11-22取得〕

- **書誌〔確認: ページ本文・記事ID〕**: 東京都建設局「中小河川整備のストック効果」内のページ「[令和7年7月10日豪雨における調節池の効果について](https://www.kensetsu.metro.tokyo.lg.jp/river/chusho_seibi/stock/250710_effects)」（**記事ID 017-001-20250910-011133**＝記事IDの日付要素から**2025年9月10日頃の公開と推定**〔推定〕。問い合わせ先は東京都河川部計画課中小河川担当）。**直curlは403（WAF遮断）**だがブラウザ経由の取得ルートでは本文全文が確認できた〔2026-11-22〕。
- **令和7年7月10日豪雨の規模〔確認: 本文・気象庁解析と実測の区別を本文自体が明記〕**:
  - 「**令和7年7月10日に局地的に大雨が降り、気象庁から記録的短時間大雨情報（気象庁の解析雨量で杉並区：120㎜/h、中野区：110㎜/h）が発表されました**」＋解析雨量表＝**杉並区120㎜/h・中野区110㎜/h・練馬区110㎜/h・目黒区100㎜/h・世田谷区100㎜/h・渋谷区100㎜/h**。
  - 実測値＝「**杉並区の下井草観測所で時間最大93㎜/h、総雨量109㎜**」「**世田谷区の北沢観測所で時間最大96㎜/h**」。
  - 「**妙正寺川では、鷺盛橋観測所において、1時間で河川水位がピークに達して**います。上高田上観測所においては、たった30分で河川水位がピークに達しています」＝**妙正寺川流域（神田川の支川）の水位到達時間の実測文言**。
- **調節池取水実績〔確認: 本文の取水実績表＝本資料の核心〕**: 「**都内で12箇所の調節池に洪水を取水して、合計約41万㎥貯留しました**」（8河川12調節池・貯留率合計15%）。**神田川水系側の数値**:
  1. **神田川・環状七号線地下調節池（[GOV-291](GOV-291.md)系の既設区間）: 取水量129,000㎥・貯留率24%**〔**神田川（弦巻川・水窪川・谷端川の受け皿）の地下調節池の単一降雨での公式取水実績数値＝repo初出〕**。
  2. **神田川: 下高井戸調節池 5,000㎥・17%**〔repo初出の調節池名・個別数値〕。
  3. **妙正寺川: 鷺宮調節池 35,000㎥・100%**（本文＝「**鷺宮調節池では調節池容量35,000㎥の全てを取水して、調節池の効果を発揮しました**」＝満杯取水）・上高田調節池 69,000㎥・44%・妙正寺川第二調節池 15,000㎥・16%・落合調節池 4,600㎥・9%〔いずれも個別数値はrepo初出〕。
  4. **石神井川: 城北中央公園調節池 500㎥・貯留率1%**〔一期施設の初期取水実績＝[GOV-087](GOV-087.md)（産経報道）・[ORG-023](../org/ORG-023.md)の後追いにあたる公式数値側の文言。**都営一期施設が令和7年7月10日時点で取水稼働していたことの一次確認**〕。
  5. その他流域＝白子川地下調節池 62,000㎥・29%、江古田川北江古田調節池 13,000㎥・81%、目黒川荏原調節池 46,000㎥・23%・船入場調節池 5,000㎥・9%、渋谷川・古川の古川地下調節池 23,000㎥・18%。
- **効果のシミュレーション文言〔確認: 本文・「都のシミュレーション結果」注記つき〕**: 「**鷺宮調節池で取水したことにより、調節池下流（環状七号線付近）の水位を約1.0m水位上昇を抑え**、河川からの溢水を防ぐことができました」＋「**５つの調節池で取水したことにより、調節池下流（環状六号線付近）の水位を約0.7m水位上昇を抑え**」＝**妙正寺川上流部・下流部での水位抑制効果（約1.0m・約0.7m）の公式推計文言**。

## repoとの関連〔観察〕

- 神田川の支川（弦巻川＝妙正寺川下流系・水窪川＝江古田川上流系の隣接）と受け皿としての神田川湧水系の治水は、repoの「四河川の暗渠・下水道幹線の現在進行形の治水」系の枠組みの最重要側面。**単一豪雨での神田川・環七地下調節池の取水129,000㎥（貯留率24%）という定量実績**は、[GOV-149](GOV-149.md)「気候変動を踏まえた河川施設のあり方」→[GOV-291](GOV-291.md)環七地下河川計画検討委員会（延伸構想）という計画系資料群に対する**実績系の一次アンカー**になる（今後の雨水流出の議論で実績値として引用可能）。
- **下井草観測所の93㎜/h・杉並区の解析120㎜/h**という実測・解析の数値は、松庵川・あげ堀・六ヶ村分水系（善福寺川・神田川上流域：対照表の善福寺川系の行群）の氾濫史の現代側データ点。
- 城北中央公園調節池500㎥（1%）の一次数値は、[GOV-087](GOV-087.md)の報道文言（1号ケーソン完成・2026年稼働）と同じ施工系統の**都の公式実績側**を補う（[BLOG-288](../blogs/BLOG-288.md)〔ゆる歴史散歩会〕の「一期施設は2025年6月に取水を開始し、同年7月10日の豪雨では約500立方メートルを取水」の文言の出典が本資料〔都建設局「令和7年7月10日豪雨における調節池の効果」とblog内参考資料欄に明記〕と特定できた〔blog側の参考資料欄の記載＝二次ソース側の出典示唆の確認〕）。

## 意義〔観察〕

- 都管理の中小河川調節池全体系の単一降雨実績を8河川12池の内訳つきで公示した公式資料で、**神田川水系の治水現状の定量の一次出典**。repoが扱う四河川（神田川湧水系の旧河川群）の近未来の水路像（調節池・地下河川への接続）を論じる際の実績ベースライン。
