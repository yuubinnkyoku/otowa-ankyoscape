# [GOV-215] 天明撰要類集[49]明地之部 — 千川上水請負人の神田川筋（昌平橋〜筋違橋外）での揚場銭・出浅の記録

- **書誌〔確認〕**: 『天明撰要類集』[49]（十九上明地之部・天明6年〜7年頃の町奉行所明地関係記録集）。NDL次世代デジタルライブラリー [book/2572898](https://lab.ndl.go.jp/dl/book/2572898)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **筋違橋御門外明地の千川上水請負人助成地〔確認・repo初出〕**: 「**筋違橋外明地矢来際外弐ヶ所千川上水請負人助成地に相渡候積伺相済旨信濃守ゟ達書付**」〔**①筋違橋御門外（現在のJR秋葉原・神田明神間の神田川筋）の明地2ヶ所（矢来際の外）が千川上水請負人の助成地として渡されていたこと、②山村信濃守（町奉行）の達書付で相済んだこと**＝**千川上水の再興期（安永9〜天明6）に、請負人の収入源として神田側（下流域）の明地が充当されていた実態の初出記録**。千川上水の末端が神田川（神田上水の姫ヶ瀬川以遠）に接続する系統（[GOV-218](GOV-218.md)の差止・[GOV-217](GOV-217.md)の駒込掛渡と対になる下流域の記録）〕。
- **揚場銭取立の紛争〔確認〕**: ①湯島・神田旅籠町組の米屋8ヶ所の願——「**筋違橋御門外昌平橋迄之間二而商売物河岸揚仕来候処右河岸ゟ水揚致し候荷物不依何揚場銭可取立旨千川上水請負人申聞致迷惑候旨願出右之外武士米も揚場銭可請取旨申候趣相聞候**」、②これに対する御書面（午8月付け）——「**千川上水請負人方江筋違橋御門外河岸に而揚場致取立候儀は不申付候**」〔**①昌平橋〜筋違橋外の神田川河岸で揚げた荷物に揚場銭を取立てようとした千川上水請負人と米屋の対立、②奉行所が請負人側の揚場銭取立を認めなかった（「不申付」）こと**＝千川上水請負人の収入確保の試みの限界を示す一次記録〕。
- **「天明6年8月19日初而出浅取立」〔確認・repo初出〕**: 「**六月天明六午年八月十九日初而千川上水出浅取立候に付願乍恐以書付御訴訟奉申上候一米商売脇店八ケ所並神田旅籠町組米屋行事共願出**」〔**①天明6年（1786）8月19日に初めて千川上水の「出浅」（浅瀬の通行？運搬？）に対する銭の取立が始まったこと、②それに対する米商売脇店8ヶ所と神田旅籠町組米屋行事の訴訟**＝千川上水再興末期の収入手段の実態。「出浅」の語義（出し場・浅所の通行料か）はOCRのみからは確定できない（断定しない・要照合）〕。
- **差止後の請負人リスト〔確認・請負人構成の初出〕**: 「**天明六午年閏十月廿二日書上写一千川上水請負人神田相生町喜兵衛地借長十郎同所清兵衛店宇助同所平永町家持長右衛門佐久間町弐町目喜兵衛店幸右衛門同所三町目勘左衛門庄吉三勝武州多摩郡小川村名主弥次郎申上候**」〔**①千川上水の請負人が差止直後（天明6閏10月22日）に連名で書上を提出したこと、②請負人の構成＝神田相生町・平永町・佐久間町の町方数名＋**武州多摩郡小川村名主弥次郎**であること**＝**千川上水の請負人に水源付近（保谷・小川村方面＝千川上水取水元の田無・保ヶ谷領）の村方が参加していた実態の初出記録**。小川村名主の参画は、千川家（元禄期の元請負人・[GOV-210](GOV-210.md)）の系譜と再興期請負人の関係を考える上での重要な傍観資料（関係の実態は未確認・断定しない）〕〔「勘左衛門庄吉」「三勝」等のOCR崩れあり、人名の正確な分節は要原文照合〕。
- **差止後の請負地・拝借金の訴訟〔確認〕**: 「**千川上水懸渡御差止ニ相成ニ付請負地幷拝借金等之儀向方にて申渡候趣請負人共訴書付**」〔**差止に伴う請負地・拠出金（拝借金）の処分をめぐる請負人側の訴訟**＝[GOV-218](GOV-218.md)（南撰要類集・差止後の金銭決着）と同一事件群の町奉行所側の記録。両者で対校可能〕。
