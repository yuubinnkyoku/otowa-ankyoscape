# [GOV-428] 享保撰要類集 二十一ノ下 — 辻番所請負と江戸川通り・目白下御上水外通の文言

- **書誌〔確認〕**: 『享保撰要類集』二十一ノ下。辻番所の請負・運用関係の行政事例綴（町奉行関係・[GOV-390](GOV-390.md)（享保撰要類集二十一・延享3年）系の同シリーズ冊で、二十五ノ下ノ下＝[GOV-429](GOV-429.md)・二十六ノ上＝[GOV-430](GOV-430.md)と隣接冊）。NDL次世代デジタルライブラリー [book/2572826](https://lab.ndl.go.jp/dl/book/2572826)。**引用文言はすべてOCR由来で要原文照合**。
- **辻番所惣請負人の申渡〔確認〕**: 「**一享保八年卯二月十三日辻番所惣請負人江一二被仰渡之覚 未十一月辻番請負相止候ニ付此書付不相(知?)**」＝享保8年（1723）2月13日の辻番所惣請負人への申渡の覚と、「未十一月」の辻番請負停止の記録（「未」の年次は干支との対応がOCRから確定できない・要照合）。同冊に**牛込水道町の地借八左衛門の失敗例**「**牛込水道町八左衛門儀辻番人に悪敷者差置此度御仕置ニ罷成候依之…請負場所御取上ケ被成返料拾貫文上納被仰付**」もある＝辻番請負の行政実例（牛込水道町＝[GAZ-049](../gazetteers/GAZ-049.md)系の水道町）。
- **請負場所の地理文言〔確認・repo初出の文言群〕**: 請負人の請負場所範囲の列挙の中に——「**一一昌平橋ゟ西は御堀端通り水道橋外船河原橋ゟ北は江戸川通り目白下御上水外通高田村追分辺迄牛込水道町松右衛門地借り五拾一ヶ所八左衛門印九月十日**」＝牛込水道町の地借（印は八左衛門）の請負51ヶ所は「水道橋外・船河原橋ゟ北」の「江戸川通り」が「目白下御上水外通」を経て「高田村追分」に至る通り筋、＋「**船河原橋ゟ南は御堀通り牛込御門迄 牛込御門ゟ西は神楽坂通り牛込寺町通横町通り早稲田通り穴八幡前高田馬場先迄巣鴨原町壱丁目家主弐拾弐ヶ所善兵衛印**」＝船河原橋以南の御堀通り〜牛込御門〜神楽坂・寺町・早稲田・穴八幡前・高田馬場先〜巣鴨原町の範囲、＝**辻番の配置範囲の表現を通じて、江戸川（神田川）左岸の縦断路（水道橋・船河原橋〜牛込御門〜高田馬場方面）と江戸川沿いに高田村追分へ達する通りが享保期の行政文書で列挙された記録**。
- **意味〔確認・地名情報〕**: ①「**目白下御上水外通**」＝江戸川通り（神田川沿いの通り）のうち目白下（[GAZ-049](../gazetteers/GAZ-049.md)巻45総説の「白堀上水關口の方より流れ來り」系の目白下〜小石川区間）で「御上水の外側の通り」という呼称で記録された用例（repo初出の文言候補・白堀端通〔[GAZ-050](../gazetteers/GAZ-050.md)〕の上水側／外側の道の対応関係の比定は原文照合まで断定しない）、②「**高田村追分**」＝高田村（千川上水が通過した村の一つ・[BOOK-161](../books/BOOK-161.md)系）への追分として、江戸川通りから千川上水沿い方面へ分岐する地点の呼称、③水道橋・船河原橋は[橋名調査](../../四河川の橋名・橋跡調査.md)の江戸川（神田川）の橋群として既登録だが、**辻番・番所の配置から見た橋周辺の通り構造の一次記録**として両橋の通時系列に享保期の層を追加する資料。

## 制限・未解決

- ①「未十一月」の年次・「不相(知?)」の原字は要照合。②請負範囲列挙の各行がどの辻番所に対応するか（行割れが激しく、牛込水道町の51ヶ所の範囲の起終点の解釈は原画像で確認要）。③「御上水外通」の原表記（外通り・外通）と意味（上水の外側の通りか）は文脈照合まで保留。④OCRの文字化け・区切り（「ゟ」の方向指示や行の継ぎ目の判別）は引用の正確な区切り方に影響するため、碑文的採用は原画像照合が前提。
