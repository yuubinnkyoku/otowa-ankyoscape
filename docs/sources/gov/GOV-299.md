# [GOV-299] 失業対策資料 第1輯（1934）— 谷端川流域の下水道整備の初期（1929-31）が失業救済事業として実施された記録

- **①巣鴨町下水道築造工事の昭和4年度計画と五年度繰越〔確認・本文文言〕**: 「**管下近接町村の失業救濟事業として江戶川上水町村組合計畫に係る事業費五十三萬四千六百四十圓、勞力費十八萬七千三十一圓の上水道擴張工事及び巢鴨町の事業費二十三萬五千七十一圓、勞力費五萬二千四百二圓の下水道築造工事が施行される豫定であつたが、是等は事業並に起債の認可手續等に日時を要した爲其の殆んど全部を五年度へ繰越すの止むなきに至つたのである**」＝**巣鴨町下水道築造工事（事業費235,071円・労力費52,402円）が昭和4年度の失業救済事業として計画され、認可手続の遅れでほぼ全部を昭和5年度へ繰越した**本文文言。一覧表A（昭和4年度・郡部）にも「**巢鴨町下水道築造工事 二三五、〇七一**」の行が見える〔数値列はOCR列崩れのため原表照合まで保留〕。
- **②昭和5年度の巣鴨町改良下水道工事〔文言候補〕**: 昭和5年度から6年度への繰越一覧表に「**巢鴨町 起債事業 改良下水道工事 二〇〇、〇〇〇（円）／二九、七〇〇（円）**」の行＝**昭和5年度の巣鴨町改良下水道工事（事業費20万円・労力費2万9700円）**〔列崩れのため文言候補・原表照合要〕。[GOV-162](GOV-162.md)（1930年巣鴨町下水道計画）の計画が失業救済事業の枠組みで施行された記録として接続する。
- **③昭和6年度既定失業救済事業の下水道群〔文言候補〕**: 昭和6年度既定の町村別事業として「**高田町 起債事業 改良下水道工事 四〇三、三八〇／一〇〇、九六三**」「**東部下水道町村組 起債事業 下水道改良工事 八八九、〇〇〇**」「**巢鴨町 起債事業 下水道工事（六年度認可）**」「**西巢鴨町 同（起債事業）下水道敷設工事（六年度認可）**」等が並ぶ〔数値はOCR列崩れのため原表照合まで保留〕＝**巣鴨町・西巣鴨町（＝谷端川流域の旧町）の下水道敷設が昭和6年度（1931）の失業救済事業（起債）として既定だった記録**。
- **④東京府施行の河川改修種目の「立會川改修・神田上水改修・谷端川改修」文言候補〔repo初出級・要照合〕**: 昭和4年度〜5年度の府施行失業救済事業の表で「**目黑川改修埋立工事／…明川／立會川改修／…改修工／修…神田上水改／事／谷端川改修／縣道改良工事／道路公債法ニ依ル府／（工事警視廳施行）警察署及消防署建築／濟事業／臨時冬季應急失業救…計**」というOCR崩れの種目並びが見える＝**「立會川改修」「神田上水改修」「谷端川改修」が東京府施行の失業救済事業（または臨時冬季応急失業救済事業）の種目として並記された表**の候補〔**表OCRは全面崩壊しており、どの年度・どの事業枠（昭和4年度・5年度・6年度・臨時冬季）に対応するか、事業費・労力費の数値は一切読めない。文言候補として所在を記録し、原画像照合を要する**〕。また昭和6年度既定に「**淀橋町 神田上水支流改修並排水路新設**」の行も見える〔文言候補〕。
- **⑤繰越表の備考「道路工事ハ一部施行中河川工事ハ大體完」〔文言候補〕**: 昭和6年度繰越の備考欄と見られる箇所に「**道路工事ハ一部施行中 河川工事ハ大體完**」の文言候補＝河川改修工事（立會川・神田上水・谷端川等）が昭和6年度末（1931）時点で「大体完了」に近かった可能性のある記録候補〔OCR崩れ・原画像照合必須。[GOV-135](GOV-135.md)NDA記録群の1940年完成文言（纂02580100-00400）との中間点、[GOV-300](GOV-300.md)（1933年時点の谷端川改修工の施行状況）との対照資料〕。
