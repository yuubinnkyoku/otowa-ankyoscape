# [GOV-274] 玉川上水留 天保14〜15年・嘉永2年 — 赤坂紀伊国坂下の石垣樋の崩落修復と入子樋枡修復

- **書誌〔確認〕**: 『玉川上水留』「玉川上水赤坂紀伊国坂下石垣樋崩所人除矢来其外共御修復御組合入用一件　天保十四巳年三月より同十五午年三月迄」（全1冊）[book/2587357](https://lab.ndl.go.jp/dl/book/2587357)＋「玉川上水赤坂紀伊国坂石垣樋内入子樋枡其外御修復附切御手当帳　嘉永二酉年正月より同閏四月迄」（全1冊）[book/2587373](https://lab.ndl.go.jp/dl/book/2587373)。いずれもrepo未登録（「薩摩小路」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔紀伊国坂下の石垣樋＝[GOV-273](GOV-273.md)の紀伊国坂通石樋の下流側とみられる区間の災害修復と、6年後の入子樋枡修復の一対。〕
- **石垣樋の上水堀への崩落〔確認・repo初出の災害記録〕**: 「**…上水堀江落入有之候間取揚…一日水留二而築立…**」＋仕様「**石垣崩所上一土手崩所長六間巾壱間高六尺**」＝**紀伊国坂下の石垣樋の石垣・土手（長6間・巾1間・高6尺）が上水堀（開渠）に崩れ落ち、取り揚げて1日限りの水留で築き直した**＝石垣樋（石造樋管）と開渠（堀）が隣接・交差する紀伊国坂下の立地を裏付ける災害記録（天保14-15年3月の出来事かは帳簿の年月区分に基づく推定で、崩落の発生日は本冊では確認できない）。
- **落札94両3分〔確認・周辺〕**: 「**金八拾両三分銀弐匁…金九拾四両三分入札落直段…地割棟梁元積差高金拾三両三分弐朱銀五匁**」＝**入札の結果94両3分（帳簿の他箇所に「元積」との差引13両3分2朱・銀5匁の文言）**（OCRで「80両3分+銀2匁」と「94両3分」が併記され金額体系が崩れているため、元積・入札・落札の各額の確定には原文照合必須）。
- **嘉永2年の入子樋枡修復と御手当帳〔確認・repo初出の附切手当の実務〕**: 「**玉川上水赤坂紀伊国坂石垣樋内入子樋枡其外御修復中附切相勤候支配向…御褒美…御普請方下奉行橋本恵次郎…当酉正月廿日ゟ同閏四月朔日迄日数合百日分**」＝**嘉永2(酉)年正月20日〜閏4月朔日（日数合100日分）に紀伊国坂石垣樋内の入子樋枡の修復が行われ、附切（樋の継ぎ目・木寄せ）を勤めた支配向の者に褒美・手当が出された記録**（「附切御手当帳」＝樋管の附切作業の人足賃の帳簿で、玉川上水末端の修復が小規模作業の積み重ねとして運営された実態）。
- **溜池端通大下水・榎坂上埋下水との干渉〔確認・repo初出の文言〕**: 嘉永2年冊に「**赤坂溜池端通大下水水上下水柵御修復…榎坂上埋下水石垣孕押れ水行不宜…自然水上御普請所并溜池端明地え悪水溢出**」＝**赤坂溜池端通の「大下水」（下水の幹線）の水柵の修復に際し、榎坂上の「埋下水」（暗渠化された下水）の石垣が孕み押し出されて水行きが悪く、悪水が水上の御普請所と溜池端の明地に溢出した**という文言＝**榎坂（赤坂・溜池間の坂＝現在の赤坂溜池方面か）に「埋下水」と呼ばれる暗渠下水が存在し、上水樋筋と下水（大下水）の水柵・悪水の干渉があった**記録（「埋下水」＝埋設・蓋をした下水と読めるが、玉川上水系文書の用語としての確定は原字形照合を要す。同じ文言は[GOV-278](GOV-278.md)安政3年の柳堤通仮樋枡修復冊にも反復される＝後年の赤坂の下水網の状態の継続性の傍証）。
- **薩摩小路組合年番〔確認・周辺〕**: 天保14-15年冊＝「**薩摩小路組合年番 松平甲斐守殿 石川近江守殿**」（[GOV-273](GOV-273.md)天保9-10年と同じ顔触れ＝甲斐守・近江守が天保期の薩摩小路組合の年番として続いた可能性）、嘉永2年冊＝「**薩摩小路組合年番 松平甲斐守殿(?) 石川近江守殿**」のOCR崩れ（嘉永2年時点で同じ両名かどうかは断定できず要照合）。
