# [GOV-238] 享保撰要類集 十七ノ中（諸所橋々之部）— 音羽町九丁目橋の定請負と延享期の音羽の坂渡り小橋

- **書誌〔確認〕**: 『享保撰要類集』（幕政例集・[GOV-170](GOV-170.md)（二十一 上水之部）と同シリーズ）の[59]十七ノ中 [book/2572814](https://lab.ndl.go.jp/dl/book/2572814)＝**諸所橋々之部**。OCR全文精読。**引用文言はすべてOCR由来で要原文照合。**
- **石河土佐守の定請負橋数書付〔確認・repo初出〕**: 石河土佐守が請負う**定請負橋数の書付**（戌年四月廿九日付と読める文言・年次の確定は要照合）に、江戸・本所・深川の橋のリストが列挙され、**「音羽町九丁目橋」「江戸川橋」「金杉橋」「金剛寺坂下橋」「関口橋」が含まれる**（ほかに日本橋・江戸橋・霊岸橋・亀嶋橋・京橋・今戸橋・築地橋・市谷浄瑠璃坂下石橋・白金台町橋・新鳥越橋等・全橋名の確定は原文照合課題）。請負は**文金千両の公役金**による定請負制（「翌巳年より金弐百両相増」との文言もあり・読み要照合）〔**①「音羽町九丁目橋」が江戸市中の橋の定請負の対象として幕府例集に現れる**＝[BOOK-129](../books/BOOK-129.md)宝暦10年修理・[GAZ-035](../gazetteers/GAZ-035.md)九丁目橋（小日向水道町持ち・神田御上水に架かる）・[GAZ-050](../gazetteers/GAZ-050.md)「白堀端通音羽町九町目橋」に先行する延享〜寛延期の橋名の一次記録、**②「金剛寺坂下橋」「金杉橋」も白堀通沿いの橋として同時に定請負の対象**＝[GOV-236](GOV-236.md)の金杉橋芥留・[GOV-232](GOV-232.md)金剛寺坂下石垣・[GOV-237](GOV-237.md)金剛寺橋と橋名系がつながる、**③石河土佐守は[GOV-170](GOV-170.md)の元文4年分水三十二ヶ所伺の御附紙の石河土佐守と同一人物候補**＝千川用水の分水管理と江戸市中の橋の定請負を兼ねた幕臣（同一人物かは役職の原文照合後に判断）〕。
- **延享元年〜2年の音羽町九丁目の小橋修復〔確認・repo初出〕**: ①「**大塚護国寺門前音羽町九丁目ゟ目四坂駒井町え渡る小橋**」の破損・御修復の申上（延享元子年〔1744〕の文言）②「**音羽町九丁目ゟ目田坂福井町え渡小橋**」——**長3間1尺・幅2間1尺**、破損につき音羽町九丁目町人ともの相願（松平主計頭申上）、見分の上入札で**落札34両1分**（落札者: 木場永嶋町白子屋勘七・東湊町菱木屋喜兵衛、二番札・三番札に**佐久川町服部屋清右衛門**等）・**仕様帳1冊の差上**（延享二丑年〔1745〕十月の文言）〔**音羽町九丁目から目白坂方面（「目四坂」駒井町・「目田坂」福井町）へ渡る小橋2基の修復記録**。「目四坂」「目田坂」はOCR由来で原字形（目白坂か・別の坂か）は要照合、駒井町・福井町は目白台下の町（現・豊島区駒込/文京区関口方面）で、**音羽谷と目白台の間の谷（白堀・神田上水の堀）を渡る橋の候補**（橋が渡す川・堀の特定は原文照合後に判断）〕。④同冊には新大橋古杭御払の入札（延享元年）・江戸橋人留（延享2年）等の橋の行政記録も続く。
- **位置づけ〔観察〕**: [四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)の「音羽町九丁目橋」（宝暦10年修理が初出）に対し、**約15年先行する延享〜寛延期の定請負・修復記録を幕府例集で裏付け、金剛寺坂下橋・金杉橋・関口橋という白堀通・江戸川沿いの橋名群も同時に初出**させる。音羽九丁目の坂渡り小橋2基（目四坂・目田坂え渡る）は、**音羽谷の南縁（目白坂下）の小橋群の初出記録**で、[GOV-234](GOV-234.md)の服部屋太兵衛の白堀通渡橋6〜7ヶ所（新坂下橋を含む）と合わせ、**18世紀中頃の音羽〜小日向間の谷横断の橋の密度が確認できる**。
