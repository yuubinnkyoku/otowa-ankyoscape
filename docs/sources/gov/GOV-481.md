# [GOV-481] 千川上水試験通水に伴う水質調査等委託報告書（1989）〔repo初出〕

- **書誌〔確認: NDL Search SRU・2026-11-21〕**: 東京都環境保全局（編）『**千川上水試験通水に伴う水質調査等委託報告書**』（**1989年3月**・**22,21p・30cm**・東京都立中央図書館蔵〔書誌「所蔵場所：B2書庫C」〕・NDL Search [R100000001-I13111100597001](https://ndlsearch.ndl.go.jp/bibliography/R100000001-I13111100597001)）＋同局『**千川上水試験通水に伴う水質調査等委託報告書 : 資料収集整理結果**』（**1989年3月・129p・30cm**・同所蔵・[R100000001-I13111100597002](https://ndlsearch.ndl.go.jp/bibliography/R100000001-I13111100597002)）。**同一委託の本体報告書と資料編（129p）の2冊**として発行されていることを確認。**本文は未見**。
- **主題の位置づけ〔観察・本文未見〕**: **千川上水の清流復活事業系の1989年時点の「試験通水」について、水質調査等を委託した行政報告書**〔千川上水の清流復活系の行政側・環境保全局系の資料で、下水道整備・都建設局側の文書群（[GOV-119](GOV-119.md)・[GOV-124](GOV-124.md)ほか・README §千川上水）に対して、**1989年試験通水と水質データの側の欠けていた裏付け**の候補。「資料収集整理結果」129p分には千川上水の歴史・土地利用・水質データの文献集が含まれる可能性があるが、内容は未見のため断定しない〕。
