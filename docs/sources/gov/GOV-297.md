# [GOV-297] 帝都復興史 第2巻（1930）— 谷端川・江戸川・神田上水路の改修計画と大正14年豪雨の被害地理

- **書誌〔確認〕**: 復興調査協會編『帝都復興史』第貳卷（興文堂書院・1930年〔奥付「昭和五年四月二十八日印刷・昭和五年五月一日發行」〕）。次世代デジタルライブラリー [book/1259299](https://lab.ndl.go.jp/dl/book/1259299)。第七編河川運河ほかを収録。**すべての引用は同館OCRテキスト由来であり、文言・数値は原文画像との照合を要する。**
- **谷端川改修計畫〔確認・repo初出の文言群〕**: 第七編・東京市施行の河川改修並びに計畫に「(二)谷端川改修計畫」として:
  1. **水源・流路**: 「本川ハ北豊島郡長崎町**舊千川上水より分岐**シ長崎、瀧ノ川町、巢鴨町ヲ經テ東京市ニ入ル排水路ニシテ、洪水ノ氾濫ニ從來每年少ナカラザル被害ヲ蒙リツ〓アルノミナラズ、沿岸ハ板橋ヨリ下流市街地ニ於テ**荒廢甚ダシク**之ヲ改修スルモノ」＝[GOV-258](GOV-258.md)（府史）と同じ「旧千川上水より分岐」系統の記述＋**「沿岸は板橋より下流の市街地で荒廃甚だし」**という改修前の谷端川沿岸の都市的状況の文言〔repo初出〕。
  2. **工費予算＝130万圓〔確認・GOV-258との対立〕**: 「改修工費豫算ハ**百三十萬圓**」＝[GOV-258](GOV-258.md)（府史・谷端川說明書）の「貳百六拾五萬七千圓」との**対立**。同一書の神田上水路改修費が「**二百六十五萬七千圓**」と一致することから、**府史の265.7万は神田上水の数値の混入（列崩れ・混同）の可能性が強まった**（断定は原画像対校まで保留・[GOV-258](GOV-258.md)追記参照）。
  3. **改修区間**: 「改修區間ハ市郡境界ヨリ**板橋町ヲ經テ田端橋ニ至ル**延長**一千九百八十三間**トス」＝延長1,983間は[GOV-258](GOV-258.md)と一致（同数字の独立確認）。**終点橋の表記が府史「田樂橋」に対し本書「田端橋」**＝OCR変種・原字形の対立候補（[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)第128回追補参照）。
  4. **幅員**: 「現在本川ノ幅員**十二尺乃至二十尺**ヲ改メ**十八尺乃至二十六尺**トス」＝[GOV-258](GOV-258.md)の「上流は幅12尺→18尺餘・下流は幅19〜20尺→26尺」と**範囲として整合する独立確認**（数値の文言は要照合）。
- **江戶川改修計畫（市施行）〔確認・repo初出の文言群〕**: 「(二)江戶川改修計畫」＝「江戶川ノ改修ハ大正八年七月之ガ施行ヲ了シタルモ、上流部ノ急速ナル發展ニ伴ヒ在來ノ原野、溜池等ハ宅地トナリ雨水ノ流下速カトナリタル爲メ…**東京府ニ於テ上流部舊神田上水路改修計畫アリ、此ノ計畫竣功ノ上ハ一層雨水ノ流下ヲ速カナラシメテ到底排水シ得ズ**…府ノ計畫ト相俟ツテ改修スルコトヲ計畫シタ」＝**江戸川改修が「府の旧神田上水路改修との連動」を理由として計画された**ことの文言。要点:
  1. **工費・期間**: 「**工費豫算ハ五百八十五萬圓**ニシテ**五ヶ年繼續事業**」。
  2. **区間**: 「改修延長ハ**船河原橋下流川口**ヨリ**駒塚橋上流郡市境界**ニ至ル**一千四百九十三間**トス」＝**起点＝船河原橋下流の川口（神田川合流点側）・終点＝駒塚橋上流の郡市境界**という区間両端の橋名の特定〔江戸川改修区間の両端の橋名としてrepo初出の明記〕。
  3. **幅員・護岸**: 現在最大13間・最小8間→**13間乃至9間**。護岸は両岸全部石垣（上部練積・下部混凝土基礎・護岸高19〜26尺）。
  4. **浚渫深〔確認・repo初出の数値群〕**: 「浚渫深ハ在來河底ヨリ**川口ニ於テ七尺七寸、白鳥橋及江戶川橋附近ニ於テ七尺六寸、大洗堰下流ニ於テ七尺三寸、同所上流ヨリ郡市境界迄ハ八尺**ニシテ此ノ平均深ハ約七尺七寸トス」＝**川口・白鳥橋・江戶川橋・大洗堰・郡市境界の5地点別の浚渫深**。**大洗堰が1930年の改修計画の水準点（堰の上下で浚渫深が変わる境）として機能していた**ことの記録。
  5. **舟運**: 「本川ハ現在舟運ノ便ナキモノナルモ**改修ニ依リ江戶川附近〔ママ・沿岸?〕マデ舟筏ノ便ヲ開カシム**」＝**船河原橋＝当時の舟運末端（下流端）という配位の傍証**〔第122回課題③（船河原橋＝江戸川の下流端の橋）の前進〕。
- **神田上水路改修計畫（府施行）〔確認〕**: 「(五)神田上水路改修計畫」＝
  1. **被害見積**: 「**大正十年カラ大正十五年ニ亘ル五ヶ年間ニ約二百四十二萬圓ノ被害額**ヲ見積ラレ尙交通上ノ損害、家屋ニ關スル損害等ヲ加算スルトキハ**優ニ一ケ年五十萬圓以上ニ上ル**」＝**5ヶ年間の被害見積242万圓（年平均約48.4万圓）**＝[GOV-258](GOV-258.md)（府史）の「年々の被害平均48万円」と**算術的に整合**（両書が同じ見積に基づく可能性が強い・要照合）。
  2. **工費**: 「改修費ハ**二百六十五萬七千圓**」＝[GOV-258](GOV-258.md)の神田上水4,431間・265万7千円と一致。
  3. **区間・関係地域**: 「市郡境界ヨリ中野町地內**壽橋**ニ至ル延長**四千四百三十一間**」・「**關係地域ハ四ケ町村**ニ及ブ」。
  4. **河幅・深さ〔確認・repo初出の数値〕**: 「現在河幅ハ極メテ不規則ニシテ…**下流市郡境界附近ハ八間、上流壽橋附近ハ四間**ナルモ之ヲ整理シテ**下流幅員八間、上流ハ六間**トス。又水路ノ深サモ不規則ニシテ**十二尺乃至六尺五寸**ナルヲ改修後ニ於テハ護岸天端迄**下流十三尺、上流八尺**トナス」＝**白堀（旧神田上水路）の改修前後の河幅（下流8間→8間・上流4間→6間）と深さ（12尺〜6尺5寸→下流13尺・上流8尺）**。
- **大正14年豪雨の被害箇所〔確認・千川・藍染川の氾濫指定はrepo初出〕**: 「最近ニ於ケル市內水害ノ最モ甚ダシカッタノハ**大正十四年八月二十六日、九月三十日及十月一日ノ豪雨**ニシテ、八月二十五、六日兩日ニ亙ル總降雨量ハ**一千七百二十五粍**、繼續一時間ノ最大降雨量ハ**四十八粍五**ニシテ明治十九年以後東京市ニ於ケル記錄ニヨレバ**第五番目ノ大雨**…其ノ被害範圍ハ市內十五區及隣接十一ケ町村…**河川氾濫區域ハ約百三十五萬坪、下水氾濫區域約三百七十八萬坪合計五百十三萬坪**」＋「**氾濫ニ依ル被害ノ主ナル箇所ハ江戶川沿岸、千川附近、溜池附近、藍染川及三河島、山谷、日暮里並ニ江東一帶**ニシテ、浸水家屋ハ市內江西ニテハ**二萬三千六十戶**、江東ニ於テハ**一萬六百五十九戶**ニ及ンダ…（十月）被害ハ更ニ甚ダシク浸水家屋ハ**江西三萬二百四十八戶、江東一萬二千九百七十九戶**」＝**大正14年（1925）8・9・10月豪雨の被害主箇所として「千川附近」「溜池附近」「藍染川」が列挙された一次統計**。千川（旧千川上水の流末）・藍染川（上流谷戸川・堺川〔[GAZ-055](../gazetteers/GAZ-055.md)〕）の具体的氾濫指定はrepo初出。〔「江戶川治岸」はOCR由来の誤読（沿岸）の疑いがあり要照合〕
- **明治43年洪水〔確認・BOOK-126との対立併記〕**: 「**江戶川及舊神田上水ノ洪水**ハ市內ニ於テハ其ノ被害ノ程度荒川ニ次ギ**明治四十三年大洪水ノ際ハ郡部ハ勿論市內ニ於テモ小石川、牛込兩區ニ於テ浸水家屋五千二百九十六戶ニ達シ**タル」＋「其後ニ於テモ氾濫屢々ニシテ被害亦少ナカラズ**古川及千川ノ出水モ亦是等諸川ニ次イデ相當ノ被害**ガアッタ」＝**明治43年（1910）8月洪水で江戸川・旧神田上水の被害により小石川・牛込両区で浸水家屋5,296戸**（[BOOK-126](../books/BOOK-126.md)の小石川区内9,369棟という数値との対立は併記して要照合）＋**古川・千川の出水も「相当の被害」があった**と続く文言。
- **千川の位置づけ〔確認・repo初出の観察文言〕**: 同編の河川総説に「此ノ外**市ノ西北部ニ於テ千川ガアルガ、之ハ舟運ノ便ナク單ニ一大下水トシテ存在スルニ過ギナイ**」＝**1930年時点の千川（旧千川上水の残余）を「舟運なし・単なる一大下水」とする同時代的観察**。同総説に「**神田上流舊神田上水ハ北豊多摩郡三鷹村井ノ頭池ニ源ヲ發シ**…市內ニ入ツテ**江戶川ト稱セラレ**小石川及牛込兩區ノ間ヲ流レ**飯田橋附近ニ於テ神田川ニ合**シ」＝旧神田上水＝江戸川の水源（井の頭池）・神田川合流点（飯田橋附近）の流路確認。
