# [GOV-526] 都建設局三建「神田川整備工事（その154）議事要旨等」〔柳橋〜本郷橋の構台延伸と用地交渉の説明会資料〕

- **所在地・書誌〔確認: ページ本文・2026-11-23取得〕**: 東京都建設局第三建設事務所「審議会・各種会議の情報 > 工事説明会（神田川整備工事）」内の個別ページ。**表題「神田川整備工事（その154）議事要旨等」・更新日2023年6月27日・記事ID 017-001-20240820-006353**。 https://www.kensetsu.metro.tokyo.lg.jp/jimusho/sanken/kakusyukaigi/kouji/kandagaw_154 。添付4種＝議事要旨【PDF：133KB】（000044410）・説明会次第【PDF：95KB】（000044411=**説明会当日(?)の本文取得はエラー頁応答**）・工事概要書【PDF：811KB】（000044412）・説明資料【PDF：9,066KB】（**本文未取得**）。
- **議事要旨（000044410・2頁）〔確認: 本文・2026-11-23〕**: 「神田川整備工事（その154）工事説明会〔議事要旨〕」＝**日時 平成31年3月7日（木）午後7時00分〜午後8時30分・場所 中野区立第二中学校 体育館**。主なQ&A:
  - **護岸の構造**: 今回整備される護岸は**右岸側は鋼管杭で、左岸側が支持杭**。都「将来計画では両岸共に鋼管杭を施工する。**鋼管杭を施工するためには、用地の確保が必要であり、現在、地先の方々と用地取得の交渉を行っている。したがって、左岸側は現在の河川区域内で支持杭を施工**する」「**支持杭は仮設である**」「**地先の方々との用地交渉の協議が整い次第、鋼管杭を施工する**」〔護岸の主体構造の完成と用地取得の前後関係の一次文言〕。
  - **搬出入口**: 「[GOV-525](GOV-525.md)（その153）から引き続き、今回の工事においても**柳橋上流右岸側**を工事車両の搬出入口として使用」。
  - **今後の整備**（重要文言の引用）: 「**新橋から寿橋までの 540 ｍの区間について、国からの事業認可を受けている。これまでどおり下流から上流に向かって整備する計画**」「用地取得が完了していない区間があるため、地先の方々との協議が整い次第、順次進めていく。**現段階で整備が完了する時期は、未定である**」〔H31.3時点の事業認可区間の一次文言。「新橋」がどの橋（新設予定の本郷橋か橋名か）を指すかは本文から断定不能〕。
  - **家屋調査**: 柳橋の下流側は工事完了済みで**事後調査を2019年6月以降に予定**・対象＝「**神田川整備工事（その152）及び神田川整備工事（その153）において、家屋調査の対象となっている範囲以外の方**」で本工事では**「ビオス中野」と「本郷橋フラット」が対象**〔沿岸建物名の行政記録〕・賃貸マンションも対象・平日夜・休日の調査も可能。
- **工事概要書（000044412）〔確認: 本文・2026-11-23〕**: 「本工事は、**柳橋から本郷橋の間において、護岸の整備**を行うものです」＝**中野区本町五丁目地内から弥生町二丁目地内まで・平成31年4月上旬から平成31年6月中旬まで（予定）**（土日祝作業なし）・**柳橋から本郷橋の区間において、両岸の護岸整備に向け、鋼管杭等を施工し、現在設置している作業構台を本郷橋側に約18ｍ延伸（施工延長：左岸22.5ｍ 右岸24.9ｍ、一部完成済区間を含む）**・**本工事施工に伴う、道路・橋の通行止めはありません**。断面図＝鋼管杭φ1000 **L=17.0m**・**支持杭 L=12.0m（H-300）**・位置図＝本郷橋・柳橋・千代田橋・寿橋・**地図承認番号 平29情使、第1515号（国土地理院基盤地図情報）**。施工者＝**大豊建設株式会社**（単独・現場代理人兼監理技術者 田中）。
- **意義〔観察〕**: ①**「540m区間の国の事業認可」文言（H31.3）と[GOV-530](GOV-530.md)の令和7年2月27日事業認可告示（寿橋下流〜富士見橋上流）との関係**＝同一の認可か追加の認可かは本文から判定不能〔両文言を並記・接続の検討は川別文書で〕が、**神田川中野区側の区間整備が「下流から上流へ」進むことの行政側繰り返し文言**として時系列の骨格を与える。②支持杭=仮設・用地交渉後に鋼管杭という**川幅拡幅の用地制約の一次文言**＝[GOV-525](GOV-525.md)（80cm高架け替え・家屋階段）→本資料（用地交渉）→[GOV-527](GOV-527.md)（家屋損害賠償作業）の交渉史の流れの途中点。③ビオス中野・本郷橋フラットという**中野新橋駅周辺の建物名の行政記録**＝子書の特定と照合可能。
- **制限・未解決**: ①説明会次第（000044411）はdocument取得でエラー頁応答・説明資料（9,066KB）は本文未取得〔次回課題〕。②説明会の日時は本ページで平成31年3月7日と確認〔第268回の[GOV-523](GOV-523.md)では一覧側に表示なし＝一覧未掲載の個別ページ〕。③「新橋」の同定は断定しない。
