# [GOV-583] 種子屋街道シンポジウムのプレスリリース（2026-11-20配信）— 地名・交通史・土地利用系のリード

## 開催概要〔確認: PR TIMES配信本文〕

- 豊島区が**一般財団法人榎本種苗歴史文化財団**と共に、**令和8年11月28日（土）**、「**種子屋(たねや)街道の歴史を今に伝える 種子屋街道に芽吹く地域の未来**」を開催（配信: **2026年11月20日11時21分**）。「今回で**3回目**となる本シンポジウム」（榎本種苗歴史文化財団理事・加藤祐子氏のコメント）。
- **会場**: 大正大学8号館4階礼拝ホール（**豊島区西巣鴨3-20-1**）＋**区指定文化財「榎本家店舗兼住宅および新座敷」（豊島区西巣鴨3-19-2）**。
- **第1部（13:00〜15:00）報告4題**: ①**豊島区立郷土資料館 学芸員・横山恵美「江戸・東京の特産物と種子屋－榎本留吉商店と種子屋街道－」** ②大竹道茂（江戸東京・伝統野菜研究会 代表）「江戸東京野菜には物語がある」 ③古田尚也（大正大学 教授）「巣鴨オールキャンパス構想と種子屋街道」 ④政金裕太（信州大学農学部 研究員）「種子屋の歴史を受け継ぐ緑地づくり」※報告後ディスカッション。
- **第2部（15:10〜16:30）＝「榎本家店舗兼住宅および新座敷」の文化財保存修理事業見学会**（協同組合伝統技法研究会・角野茂勝氏）。
- 主催＝一般財団法人榎本種苗歴史文化財団・**共催＝大正大学・豊島区・協同組合伝統技法研究会**・後援＝巣鴨信用金庫・株式会社日本農林社・日本種苗協会・種苗会館・住友林業・**東京種苗株式会社**など。定員150名（当日直接会場へ）・無料。
- 「榎本家店舗兼住宅および新座敷」＝「**江戸時代から続く種子屋街道の歴史を伝える、戦災を免れた区内最古の木造住宅**で、**令和5年4月に豊島区の有形文化財に指定**」〔確認: プレス本文〕。

## repo初出・リード意義

- **「種子屋街道」はrepo初出の街道名**〔grep確認: README本文・docs/に「種子屋街道」「種苗屋街道」の文言なし。「種屋街道」はREADME「谷端川沿いの水車」条の出典欄にtakitan頁名として1回登場のみ〕。**旧中山道と千川上水に挟まれた巣鴨〜西巣鴨〜滝野川三軒家〜板橋清水町の種苗商家集積地の通称**で、[BLOG-313](../blogs/BLOG-313.md)（滝野川探検隊「種屋街道」頁・榎本氏2004年地図の転載）の導入文「**中山道と千川上水に囲まれた土地は種苗屋問屋を営む家も多く在り**…有名な種苗屋街道でした」の**行政側対応**＝千川上水×中山道という交通・水系の空間構造が種苗集積地の立地条件として行政発信で裏付けられた〔ただしプレス本文に千川上水等の水系文言なし〕。
- **西巣鴨3-19-2（榎本家店舗）**＝[BLOG-313](../blogs/BLOG-313.md)の⑯「東京種苗（西巣鴨3-19-2・創業弘化元年〔1844〕・榎本家）」と同番地＝**千川上水調節池・西巣鴨沿線（種苗家・榎本家）の店舗兼住宅が区指定文化財かつ保存修理中**であることの行政側確認。千川上水の関村〜西巣鴨区間の沿線土地利用史（種苗業）の現行レベルの定点〔保存修理事業の内容・修理範囲は配布資料未見〕。
- **横山恵美＝[BOOK-064](../books/BOOK-064.md)（『生活と文化』第11号・「＜調査ノート＞豊島区の湧き水をたずねて」・2001年12月発行）の著者**＝豊島区の水系・特産物研究の tracker的人物（豊島区立郷土資料館）が種子屋主題で継続活動中という**人的リード**〔報告①の本文・資料は未取得で、千川上水・谷端川への言及の有無は未確認〕。
- 後援に東京種苗株式会社（西巣鴨の榎本家系種苗会社＝[BLOG-313](../blogs/BLOG-313.md)⑯）が名を連ねる点も、種苗商家集積の現代的継承（東京種苗・日本農林社〔滝野川6-6-5・BLOG-313⑬〕等）の系譜に対応。
