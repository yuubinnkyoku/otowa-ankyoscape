# [GOV-026] 東京都『平成20年8月5日豪雨に伴う被害状況等について（第4報）』

- 東京都総務局総合防災部、**2008年8月5日20時30分現在**の速報。
- 原資料：https://www.bousai.metro.tokyo.lg.jp/mobile/taisaku/saigai/1000036/1000041/1000500.html
- **〔確認：行政の当日速報〕** 文京区の**床上浸水6件**の内訳は**音羽1丁目4件、水道1丁目・2丁目計2件**。**床下浸水1件**は水道1丁目。豊島区では目白2丁目の床下浸水1件を記す。
- **〔確認〕** 同速報は豊島区雑司ヶ谷2丁目22番の**雑司ヶ谷幹線再構築工事現場の増水事故**も記載する。ただし当日20時30分時点の人的被害の暫定値であり、最終的な死者数の典拠には**2008年9月1日の事故調査報告書 [GOV-025](GOV-025.md)**を用いる。
- **〔観察〕** 旧水窪川・弦巻川に近い音羽地区と、旧谷端川下流域にも近い水道地区で、2008年の同一豪雨時に町丁目単位の浸水報告が存在する。
- **〔未解決／注意〕** 浸水箇所の番地・浸水原因・水路との接続・下水管の溢水地点はこの速報では特定できない。**「音羽1丁目の4件は水窪川または弦巻川の旧河道で起きた」「水道1・2丁目の浸水は谷端川が原因」とは断定しない**。件数は同日20時30分時点の暫定集計で、最終被害統計とは限らない。
