# [GOV-212] 七十冊物類集 廿一 [22]（嘉永4〜万延元年）— 千川屋敷上納地の三左衛門→平吉への譲渡

- **書誌〔確認〕**: 町方の物類集（嘉永四亥年〜万延元申年〔1851-1860〕・廿一冊物の内の上納地御手当地助成地請負関係の記録集）。NDL次世代デジタルライブラリー [book/2548582](https://lab.ndl.go.jp/dl/book/2548582)。目録に「**安政二卯年…石川千川屋敷上納地請負人代り合**」等の項目がある。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **三左衛門の病身による平吉への譲渡〔確認・千川家の請負の嘉永6年頃の再継承（repo初出）〕**: 町奉行への書付（嘉永6丑年〔1853〕3月頃・「可丑三月」のOCR・要照合。井戸対馬守（井戸覚弘か）・池田播磨守（池田長発か）の役職名が見える）——「**…同人儀（三左衛門）近年病身…（の趣） 平吉え 跡（請）負之儀 此度 播磨守御役所え願出候に付 相糺候処 上納金高其外 都而是迄仕来之通に而 受負可仕旨 申聞 差支之儀も相聞不申候に付 願之通 受負 申候 此段申上置候**」〔**①嘉永3年に千川屋敷上納地を受負った三左衛門が自らも病身となり、②「平吉」に跡を請負わせる件が池田播磨守（町奉行）の役所に願出られ、③上納金高その他はそれまでの通りで差し支えなく承認された**＝**千川屋敷上納地の請負が宇兵衛→三左衛門（嘉永3〔[GOV-210](GOV-210.md)・[GOV-211](GOV-211.md)〕）→平吉（嘉永6頃）と再び継承された記録（repo初出）**〕〔「平吉」が「霊岸橋際受負地与惣兵衛地借譲受人平吉」として連判に現れる（嘉永5子年12月の文言）ため、同一人物と推定されるが、霊岸橋際の受負地（別件の上納地）との関係の詳細はOCRの行対応からは確定できない・要照合〕。
- **元祖太兵衛の由緒の並行テキスト〔確認・[GOV-210](GOV-210.md)・[GOV-211](GOV-211.md)との対校用〕**: 三左衛門願（由緒の再申告）——「**私元祖太兵衛義は 元禄九子年中 小石川御殿え 御上水御普請御用 被仰付 御入用金 被下置候而上 保谷新田ゟ玉川御上水ヲ分け 字千川上水と唱 新規開発仕 上水無滞 掛渡 御普請出来仕候 右上保谷新田ゟ東鴨村迄（OCR・[GOV-210](GOV-210.md)の「巣鴨村」の誤読の可能性大）素堀之場所 凡五里弐拾四町余之処 堀筋見立…御金高にしては 素堀御普請出来兼…自分入用金四百八拾両余 差出…夫より御用之御場所に（埋樋二而）無滞 上水掛渡…千川上水元役 被仰付…表間口拾五間五尺 裏行北之方拾壱間壱尺余 南之方拾九間三尺 裏幅拾四間弐尺余之御屋敷壱ヶ所 拝領…正徳四午年（干支はOCR・要照合）御殿御上水御不用に相成候間 右屋敷拝領仕**」〔**千川上水の素堀区間（保谷新田〜巣鴨村・5里24町余）・私費482両余・埋樋での掛渡・千川屋敷の寸法・千川上水元役・正徳4年屋敷拝領の由緒文言の並行テキスト**（[GOV-210](GOV-210.md)・[GOV-211](GOV-211.md)と同一事件の由緒申告が嘉永6年頃の願書にも再録されていることを確認＝文言の対校・数値の確定に使える）〕。
- **証人の交替と嘉永5年12月の連判〔確認〕**: 「**証人 小網町壱町目当時栄吉地借勘助方同居平兵衛儀は 近年病身に付 証人御免被成下置候 跡証人之儀は 神田明神下御台所町治兵衛地借茂七…**」／「**…（願の）尤 諸人（証人か・OCR）神田明神下御台所町治兵衛地借も（茂七か）七儀は近年病身に付 証人御免被成…跡詰人之儀は 谷中天王寺左（御）門前の家主久四郎と申者 身元慥成者に御座候間 証人相立申度奉存候**」＋連判「**小石川白山前町千川屋敷与（三?）兵衛地借 嘉永五子年十二月 三左衛門印 与兵衛印 五人組弥七印 霊岸橋際受負地与惣兵衛地借譲受人平吉印…谷中天王寺御門前町（の家主）証人久四郎印 神田明神下御台所町…茂七（印）**」〔**①証人が小網町の平兵衛→神田明神下御台所町の治兵衛地借茂七→谷中天王寺門前の家主久四郎へと代替わりした経緯、②嘉永5子年（1852）12月付の三左衛門・与兵衛・平吉・久四郎・茂七らの連判**＝請負実務（証人制度）の変遷の記録。**谷中天王寺門前の家主が千川屋敷の証人になっていること**は、千川家の人的つながりが根津・谷中方面（千川上水下流域＝[GOV-211](GOV-211.md)の橋の位置）にも及んでいたことを示す傍証（事実の列挙にとどめ、解釈は断定しない）〕〔人名・連判の対応はOCR崩れのため要照合〕。
- **陰性〔確認・注意記録〕**: 本書には千川屋敷関連の上記のほか、上納地の免除願・時之鐘屋敷等の項目があるが、四河川（水窪川・弦巻川・谷端川）の直接記述はない。**なお『類集撰要 地面』（天保期か・[book/2571647](https://lab.ndl.go.jp/dl/book/2571647)）には「千川屋敷藤兵衛」「茅場町千川屋敷地主」の文言が現れる**——**これは八丁堀・茅場町側の「千川屋敷」（[BOOK-131](../books/BOOK-131.md)の元禄12年入堀半埋立・[BOOK-133](../books/BOOK-133.md)の万延元年出火）系の屋敷の可能性があり、小石川白山前町の千川屋敷（千川上水請負人）とは別の「千川屋敷」が江戸に存在したことの注意情報として記録する（両者の関係は未確認・断定しない）。個別資料化は次回以降に判断。**
