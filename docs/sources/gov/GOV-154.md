# [GOV-154] 東京都「豪雨対策基本方針（改定）」第1章・第2章〔repo初出・本文確認〕

- **書誌〔確認: PDF本文・Waybackスナップショット〕**: 東京都「**豪雨対策基本方針（改定）**」。都の都市整備関連サーバー（toshiseibi.metro.tokyo.lg.jp）で章別PDFとして公開: **s01＝第1章「『東京都豪雨対策基本方針』の考え方」（6頁・[Waybackスナップショット 20250513220450](https://web.archive.org/web/20250513220450id_/https://www.toshiseibi.metro.tokyo.lg.jp/documents/d/toshiseibi/pdf_kiban_gouu_houshin_pdf_kaitei_s01)・4,348,107bytes）**・**s02＝第2章「豪雨対策の現状と課題」（26頁・[Waybackスナップショット 20251114210931](https://web.archive.org/web/20251114210931id_/https://www.toshiseibi.metro.tokyo.lg.jp/documents/d/toshiseibi/pdf_kiban_gouu_houshin_pdf_kaitei_s02)・9,120,316bytes）**。s03（26頁）・s04もスナップショット取得（20251114213858・20251114203409）したが**画像ベースPDFでテキスト層がなく、本文未判読**。直URLは2026-11-15時点で403（WAF）で、Wayback経由でのみ取得可能。**内容（2007年8月初策定・2014年6月改定の経緯、2022年度末時点データ、2040年代の将来像、5施策）は[GOV-149](GOV-149.md)が「東京都豪雨対策基本方針(改定)(令和5(2023)年12月)」として引用する文書と整合する**〔確認: 文言の内容照合。ただしスナップショットは2025年取得時点のものであり、2023年12月の初出公表時から同一ファイルであることの直接確認はない・注意〕。
- **第1章（s01）の要点〔確認: 本文抽出〕**: 「東京都豪雨対策基本方針」は**自助・共助・公助を踏まえた豪雨対策の基本方針**で、**5つの施策（河川整備・下水道整備・流域対策・家づくり・まちづくり対策・避難方策）**の方向性を示す。**2040年代の将来像＝「気候変動により激甚化・頻発化する豪雨に対して安心・安全なまち」**、**降雨量の増加（変化倍率1.1倍）を踏まえ豪雨対策の目標降雨を10ミリ引き上げ**〔GOV-149の「CC 1/20」定義（2℃上昇時の変化倍率1.1倍）と同じ前提を方針本文側でも確認〕。
- **対策強化流域＝10流域の構成〔確認・repo初出〕**: 第2章の定義＝**「対策強化流域」とは、2014（平成26）年に「東京都豪雨対策基本方針（改定）」等で選定した年超過確率1/20規模の降雨に対応する流域（現在、神田川や野川などの10流域）**。表2-5「流域別計画一覧」は①**流域別豪雨対策計画＝神田川、渋谷川・古川、石神井川、目黒川、呑川、野川、白子川、谷沢川・丸子川の8流域**（都と区市町村による東京都総合治水対策協議会が策定）・②**流域整備計画＝新河岸川、中川・綾瀬川、残堀川、境川の4流域**（総合治水対策特定河川）・③流域水害対策計画＝鶴見川流域、を列挙。本文は**「対策強化流域（流域別豪雨対策計画を検討中の柳瀬川流域を除く9流域）における目標対策量は約654万㎥」**と記し、**表2-6「流域対策の現況（2021年度末）」は神田川（目標約216万㎥・実績約122万㎥・57%）・目黒川（87%）・石神井川（71%）・野川（60%）・渋谷川・古川（56%）・呑川（59%）・谷沢川・丸子川（66%）・境川（116%）・白子川（62%）の9河川で合計約654万㎥（実績約432万㎥・66%）とする〔**9流域合計654万㎥の一致により、対策強化流域10流域＝表2-6の9河川＋柳瀬川と特定できる**（確認: 表の合計文言）。これにより[GOV-149](GOV-149.md)概要版の「10流域（神田川、石神井川、白子川、野川、境川等）」の「等」の部分＝**渋谷川・古川、目黒川、呑川、谷沢川・丸子川、柳瀬川**と確定。境川は流域別豪雨対策計画ではなく流域整備計画の対象（実績43万㎥で目標37万㎥の116%＝超過達成）〕。
- **河川整備の現況〔確認: 第2章2.4.1・表2-3〕**: 隅田川以西の中小河川のうち市街化区域内で改修を必要とする**46河川・324km**を対象に、2022（令和4）年度末までに**護岸整備220.9km（整備率68%）**・**調節池12河川27箇所・総貯留量約264万m³**・**分水路5河川8箇所・総延長約12km**を整備。**河川の安全度達成率は対策強化流域63%・一般の流域81%**〔第93回で確認した2025年11月時点の「12河川29箇所・約268万m³」（[GOV-149](GOV-149.md)追記）の1年前の基準時点値として、整備の進行（27→29箇所・264→268万m³）を数量化〕。
- **下水道整備の現況〔確認: 第2章2.4.2〕**: 「下水道浸水対策計画2022」（2022年3月）で**目標整備水準を時間75ミリへ引き上げ、重点地区を57地区から67地区へ**（新規10地区選定）。2022年度末時点で**28地区完了（進捗率約42%）**・雨水貯留施設58か所（約60万m³）・雨水ポンプ施設70か所（約14万m³/分）。多摩部では**流域下水道雨水幹線5幹線整備済**。
- **浸水重点地区67地区一覧〔確認・repo初出〕**: 第2章の重点地区一覧（番号・地区名・完了/事業中）に、**No.28「北区滝野川」（事業中）**・**No.52「目黒区上目黒、世田谷区弦巻」（事業中）**・No.42「板橋区熊野町、中丸町」（事業中）・No.55「文京区千石、豊島区南大塚」等を列挙〔**No.42・No.65（池袋本町）はREADME既収録（経営レポート2024/2026）だが、No.28（北区滝野川＝谷端川下流側の低地）とNo.52（世田谷区弦巻＝弦巻川の名の地）はrepo初出**。地区番号は経営レポートと共通の体系。ただし**各地区の対象地区と旧河道・幹線の位置の対応は本表では示されない**〕。
- **雨水貯留管20幹線一覧〔確認〕**: 第2章の雨水貯留管一覧に**谷端川1号幹線（貯留量32,000m³）**・堀船1号幹線（2,100m³）・王子西1号幹線（12,200m³）・渋谷駅西口貯留管（4,000m³）・和田弥生幹線（150,000m³）・第二十二社幹線（13,700m³+9,000m³）・江東幹線（31,000m³）等20幹線を掲載〔**谷端川1号幹線の32,000m³という公称値が、下水道局の経営レポート2020（README既収録）・国土交通省図とは別系統の2023年12月方針文書でも再掲される**第三の独立公表源。2003年完成仕様32,400m³との差の未解決問題（README既述）は本資料でも解消しない〕。
- **流域対策の指導基準〔確認〕**: 対策強化流域では**対象行為＝敷地面積500㎡以上の開発行為・建築行為等、対策量＝神田川流域等7流域600㎥/ha・その他流域500㎥/ha**で、区市町村の要綱・条例に基づき貯留浸透施設の設置を指導〔神田川流域の重点地区での現行指導量の確認〕。
