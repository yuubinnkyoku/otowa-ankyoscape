# [GOV-292] 決算検査報告 昭和40年度（1966）— 豊島区谷端川下水道幹線新設の会計検査記録

- **書誌〔確認〕**: 会計検査院『決算検査報告』昭和40年度（1966年刊）。NDL次世代デジタルライブラリー [book/1350400](https://lab.ndl.go.jp/dl/book/1350400)。**すべての引用は同館OCRテキスト由来であり、文言・数値は原文画像との照合を要する。**
- **「豊島区谷端川下水」の検査記録〔確認・repo初出〕**: 施行検査の対象事案として「**東京都道幹線新設 豊島区谷端川下水 東京都**」が掲載される。「**コンクリート暗きょ延長435メートルの新設にあたり、路面復旧の舗装1,809平米は下層路盤を砂利厚さ20センチメートル361立米、上層路盤を砕石厚さ15センチメートル271立米、表層をアスファルト乳剤厚さ3センチメートル計38センチメートルで施行したこととしているが、実際はうち1,746平米は上層路盤5センチメートル…（以下施行不良の指摘）**」＝**東京都道幹線新設「豊島区谷端川下水」＝コンクリート暗きょ延長435mの下水道幹線新設工事**として、路面復旧舗装の施行不良（上層路盤厚不足等）が会計検査で指摘された記録。別箇所の経過表に「**豊島区谷端川下水道幹線新設**」「**施行不良**」「**手直工事完了**」（昭和41.8.29等の年月日表記）も見える〔行対応はOCR列崩れのため原表照合まで保留〕。
- **内容メモ**: 同書は全国の公共工事の施行検査結果を列挙する会計検査院の年次報告で、本事案は道路（都道幹線）+下水の復旧・手直工事費の減額・国庫負担金の処理の文脈で掲載される。谷端川関係としては、①**「谷端川下水」という下水道幹線名称**が1960年代の国の検査文書に現れること、②**豊島区下流部（都道幹線沿い）でのコンクリート暗きょ435m新設**＝谷端川の下水幹線整備の一工区が昭和40年度決算レベルで施行されていたこと、③施行不良→手直し（昭和41〜42年頃）の工程が会計検査記録として残ること、が内容メモとして残る。工事の具体的位置・暗きょ種別（雨水・汚水の別）・「谷端川下水」幹線の全体計画との関係は本文では特定できない。
- **位置づけ〔観察〕**: [GOV-159](GOV-159.md)（1930年谷端川改修・全暗渠計画）→[GOV-163](GOV-163.md)（1924年）→戦後の谷端川流域下水幹線（千川増強幹線〔README既出の2020年代記録〕の前身級）の系譜の間の、**1960年代の谷端川下水道幹線（コンクリート暗きょ）の整備年代の傍証資料**。
