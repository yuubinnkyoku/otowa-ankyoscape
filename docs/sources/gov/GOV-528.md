# [GOV-528] 都建設局三建「神田川整備工事（その157）のお知らせ」〔柳橋〜本郷橋区間の仕上げ・本郷橋新設の募知情文書〕

- **所在地・書誌〔確認: PDF本文・2026-11-23取得〕**: 都建設局サイト配下の添付文書 `https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/000062212` （**「神田川整備工事（その157）のお知らせ」**）。[GOV-523](GOV-523.md)一覧ページには対応する行がなく・個別説明会ページとしても一覧に出ない＝**単発ドキュメント**〔リンク元ページは今回未特定〕。HTTPヘッダーの公開日表示=2024年7月8日〔PDFのアップロード系日付・文書自体の作成日ではない点に注意〕。
- **本文要旨〔確認: PDF本文・2026-11-23〕**: 「神田川では**1時間50㎜の降雨に対応する川の整備**を進めております。本工事は、**柳橋上流から本郷橋上流の区間において、両岸の護岸整備の仕上げ、本郷橋の新設および河川沿い通路の整備**を行うものです。**本工事で柳橋から本郷橋までの整備が完了し、通行可能となります**。」
  - 工事場所＝**中野区本町五丁目地内から同区弥生町二丁目地内まで**・**工事期間 令和5年2月下旬〜令和6年10月上旬（予定）**（土日祝作業なし）・作業時間8〜18時。
  - 工事内容＝**柳橋から本郷橋の区間において、川沿いに舗装や柵を設置し歩行者用の通路を整備。また本郷橋の新設、柳橋上流に広場を整備。これに伴い、現在設置している作業構台を撤去（施工延長：左岸 107.9ｍ 右岸 110.2ｍ）**。
  - **本郷橋通行止め＝令和5年2月下旬〜令和6年3月下旬（予定）**（歩行者用通路も閉鎖）・本郷橋の両側の道路も一時使用。
  - 完了断面図＝**本郷橋部（1-1断面）＝橋梁新設・鋼管杭φ1000・管理用通路「※歩行者等が通行できます」**・本郷橋下流部（2-2断面）＝護岸工（鋼管杭の前面を装飾）・河床工・位置図＝本郷橋・柳橋・千代田橋・寿橋・工事工程表（令和4〜6年表示＝**工程表に令和4年の起点表示がありR4時点以前の作成を示唆**〔作成年の観察・断定はしない〕）・地図承認番号 R2JHs1148。
  - 施工者＝**大豊建設株式会社**（田中・03-6382-6201）・発注者＝東京都 第三建設事務所 工事第二課 妙正寺川事業センター 須賀・榮・工事担当 上野・篠田。
