# [GOV-595] 公文雑纂 昭和九年 第四十四巻 都市計画七「東京都市計画河川改修中変更ノ件」

## 書誌〔確認〕

- 国立公文書館 デジタルアーカイブ 『**公文雑纂 昭和九年 第四十四巻 都市計画七**』所収「**東京都市計画河川改修中変更ノ件**」（ref＝**纂02116100-01300**・**1934年（昭和9年）8月21日**・作成＝内閣・公開・紙・**CC0**）＝[DAG資料情報](https://www.digital.archives.go.jp/item/2440846)。
- 〔取得経緯: 第316回に記録したjpsearch増分（谷端川44→45）の+1差分の実体。理由書の本文テキスト（索引データ経由）を取得して確認済み〕〔技術メモ: digital.archives.go.jpは**www付きでないと解決しない**（apexドメインにはAレコードがない）〕

## 文言〔確認・要原本照合〕

- 理由書: 「**立会川、神田上水、谷端川の３河川改修事業は既定計画に基き工事施行中の処立会川及谷端川の両河川に付ては其の後工事実施の都合上其の延長、幅員、深度に於て些少の変更の必要を生するに至りたるを以て本案の如く変更せむとするものなり**」

## 読み取り〔観察〕

1. **1934年8月時点で谷端川改修事業が「既定計画に基き工事施行中」であることを内閣側の公文雑纂レベルで記す一次記録**。〔事業決定1930.8.8（[GOV-159](GOV-159.md)・PAP-064）→変更1931.8.4（[GOV-228](GOV-228.md)の都市年鑑側 datapoint）→1934.2の改修計画説明書群（[GOV-568](GOV-568.md)）を経て、竣工昭和9年（[BLOG-077](../blogs/BLOG-077.md)記念碑・着手昭和5年）に至る年幅の**中央省庁文書側の中間点**。着手から竣工の市側記録（[BLOG-077]・[GOV-581](GOV-581.md)受益者負担）と初めて連結する内閣府側の独立系統〕
2. **変更の属性が「延長・幅員・深度」の3要素であることの内閣側理由書レベルの文言**＝[GOV-228]（1934-08・常務委員会速記録の変更要綱〔延長・構造区分・橋梁〕）・1934-08-21付の府告示系変更（[GOV-160](GOV-160.md)）の**背後の内閣提出文書の存在が確定**。〔変更の数値（延長・幅員・深度の変更前後値）は理由書索引テキストでは未確認＝府市側文書群との対照課題〕
3. **立会川・神田上水・谷端川の3河川が一組の「都市計画河川改修」案件として内閣に提出されている**＝東京市の都市計画河川事業の中央手続レベルでのグルーピングの傍証。**神田上水（江戸川）は変更対象に含まれない**＝谷端川と神田上水の改修ステージの差（神田上水側はこの時点で書き換え不要）を示す候補〔神田上水の事業年度・完了時期との対応は本件では特定しない〕。

## 制限・未解決

- ①原本画像（理由書・添付の変更対照表・図面）の照合は未実施。②3河川改修の「既定計画」の originally 決定年月・変更後の数値は本索引テキストでは確認できず、[GOV-228]・[GOV-568]・[GOV-160]との数値対照が今後の課題。③公文雑纂の同巻の他の都市計画七収録文書（神田上水関連の有無）は未精査。
