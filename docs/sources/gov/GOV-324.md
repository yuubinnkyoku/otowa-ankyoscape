# [GOV-324] 東京市区改正委員会議事録 第2巻（1900）— 千川水道への分水13立方尺の1882年定量〔repo初出・第139回〕

- **書誌〔確認〕**: 『東京市区改正委員会議事録 第2巻』（東京市区改正委員会・明治33年＝1900刊）。NDL次世代デジタルライブラリー [book/784702](https://lab.ndl.go.jp/dl/book/784702) のOCR全文を確認（fulltextは複数回の取得試行で入手）。市区改正事業の審議過程を収めた官庁記録。**引用文言はOCR由来で要原文照合**。
- **明治15年11月調査の玉川上水水量配分〔確認・repo初出の定量〕**: 「**明治十五年十一月ノ調査ニ依レハ現在四ツ谷大木戶ニ達スル水量ハ三十八立方尺ニ過キスト雖モ水渠ヨリ千川水道ニ分水スルモノ十三立方尺、神田上水ニ分水スルモノ三十二立方尺、戶田分水〇、九立方尺ヲ合スルトキハ一秒時間八十三、九立方尺ノ水量ヲ得ヘシ**」＝**①四ツ谷大木戸（配水の基準点）への到達水量38立方尺/秒、②千川水道への分水量13立方尺/秒、③神田上水32立方尺/秒、④戸田分水0.9立方尺/秒、合計83.9立方尺/秒**という明治15年（1882）11月調査の玉川上水系の水量配分の定量。
- **千川分水量の通時系列への追加〔確認・時系列 datapoint〕**: 千川用水・千川水道への分水量の既存観測点（[GOV-170](GOV-170.md)の元文4年樋口寸法・[GOV-189](GOV-189.md)の幕末「千川口当節四歩明」・[BLOG-095](../blogs/BLOG-095.md)の分配堰碑の樋口寸積116坪8合）が寸法・面積ベースなのに対し、**1882年時点の分水量を立方尺/秒で直接に示す行政側数値**として新しい型の観測点。千川分水（13立方尺）が神田上水分水（32立方尺）の約4割で戸田分水（0.9立方尺）を大きく上回るという**玉川上水配分内での千川の位置づけの1882年断面**。測定の場所（水渠のどこで「分水スル」か＝四ツ谷大木戸より上流の分岐点群か）は本文の前後を要精読。
- **明治15年11月文言の帰属の確定〔確認・第140回追記＝制限③②の大幅解消〕**: 本次調査（2026-11-17）で前後文を精読した結果、この文言は**明治21年12月「東京市區上水設計第一報告」（東京市区改正委員会・調査主任バルトン）の水源論**の中の文言と確定。①帰属の直接文言＝「**明治二十一年十二月東京市區上水設計第一報告別冊之通具申候也（參考ノ爲メ上水設計第一報告書ヲ左ニ揭ク）**」・委員長芳川顯正宛・「**「バルトン」氏ヲ取調主任ト爲シ數回審議ヲ經テ玆ニ此第一報告ヲ呈ス**」。②文脈＝「**玉川ハ大都府ノ給水ニ適當ナル水源ト云フヘシ水量モ亦充分ニシテ…其空費澄泄ヲ防クトキ需要ノ量…ニ對シ尙餘アルヘシ**（明治十五年十一月ノ調査ニ依レハ…八十三、九立方尺ノ水量ヲ得ヘシ）」＝**水量の十分性（需要に対する余剰）を論じる水源論の根拠として1882年調査が引用されている**＝市区改正に伴う水道改良（改良水道の水源選定）の前提調査という目的が確定（制限③解消）。③**測定の性格**＝四ツ谷大木戸到達量（38立方尺）に水渠からの各分水（千川13・神田32・戸田0.9）を合計して83.9立方尺/秒を得るという**水渠の分岐点群での配水構造の把握**であり、「千川水道ニ分水スル」の測定地点は**玉川水渠の千川分水口（保谷地先の分岐）における分水量**と読める（大木戸付近ではない）。測定地点の特定（元樋口か境橋分水口か）は原文照合まで留保。
- **狭山池の1888年実地観察と改良案〔確認・repo初出の文言・第140回追記〕**: 同第一報告の羽村水門と東京間の水渠の水質論に**狹山池の実地観察**がある。①観察文言＝「**羽村ノ近傍ニ狭山ノ池ナルモノアリテ其水ヲ上水渠ニ排出ス…瀦水ヲ水渠ニ排出スルノ小溝ハ近傍人家ノ下水ヲ受ク**（羽村ノ近傍水渠ノ北岸ニ於テ小屋ノ櫛比スルモノアリテ不潔ナル下水ヲ排出スルコト固ヨリ疑フヘカラス…其家ノ下水ハ泉水ノ流出ト混合シテ共ニ水渠ニ流下スルヲ見タリ）**是汚水侵入ノ一例ナリ**」＝**狭山池の排水小溝が近傍人家の下水を受け、玉川上水渠へ排出されていたという1888年時点の実地検分の記録**。②改良案文言＝「**水源ニ就キ目下改良ヲ爲スヘキモノハ…（第二）前記ノ狭山池ハ水渠ヲ越ヘテ玉川ノ下流ヘ放流セシムルカ又ハ此池ヲ埋立テ平地ト爲スコト**」＝**狹山池を玉川上水系から外す2案（玉川下流への放流化か埋立）が公式報告に提示された記録**＝[GOV-283](GOV-283.md)（狹山池助水堀通見廻役・1808-65）・[GOV-290](GOV-290.md)（1905年時点の池の現況）・[BOOK-142](../books/BOOK-142.md)（1924年「纔に水溜り」）の通時系列に**助水堀系の水質問題を指摘した1888年の行政側検分のdatapoint**を加える（池の廃止・放流が実施されたかは本報告では確認できず断定しない）。
- **四ツ谷大木戸樋口の採水表の所在〔確認・第140回追記〕**: 同報告に「**四ツ谷大木戶〓口ニ於テ採酌シタルモノハ**」に始まる**玉川上水分析表**（明治17年4月〜明治18年5月の採水時列・固形物・鹽素・硫酸・硬度・過滿俺酸加里・アムモニヤ・亞硝酸の欄）がある＝**1884-85年の玉川上水の水質の定量分析表の所在記録**（列崩れが激しく数値の採録は原表照合まで見送り）。千川上水の分析（[GOV-308](GOV-308.md)・1888年衛生試驗彙報の明治17-18年分析表）と同一の採水時期を共有する可能性（対応関係は要照合）。
- **観察〔観察〕**: ①市区改正委員会（後の東京市区改正審査会）が水道水源の実測値を審議資料として用いたという行政過程の記録で、[GOV-252](GOV-252.md)（1892年水道改良意見）・[GOV-290](GOV-290.md)（1905年衛生学的観察）の水量・水質論の前段にあたる。②明治15年11月という時期は千川水道會社の再興（明治13年8月）の2年後にあたり、**再興直後の千川分水の実量**として千川水道會社の給水規模を推定する根拠候補。③「戸田分水」は[GOV-151](GOV-151.md)系の戸田（渡田）用水関連か（比定は断定しない・要精読）。
