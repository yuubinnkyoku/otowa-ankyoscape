# [GOV-169] 川筋浚書留 — 天明3年11月千川上水普請の一次記録

- **書誌〔確認〕**: 『川筋浚書留』（幕府御普請方の川筋浚・普請・褒美記録帳）の第3冊 [book/2547630](https://lab.ndl.go.jp/dl/book/2547630)・第7冊 [book/2547634](https://lab.ndl.go.jp/dl/book/2547634)・第17冊 [book/2571800](https://lab.ndl.go.jp/dl/book/2571800)。いずれもNDL次世代デジタルライブラリーOCRテキストで千川上水条を確認（同内容の控が複数冊に重複）。**引用文言はOCR由来で要照合。**
- **天明3年11月の千川上水普請〔確認・repo初出の一次記録〕**: 第17冊に「**天明三卯年十一月一 千川上水素堀幷樋枡岡渡（懸渡）御普請 御用相勤候 御褒美金弐枚時服弐 牧野大隅守 但御入用高幷御普請日数留記無御座候**」＝**天明3年（1783）11月に「素堀」と「樋枡懸渡」の御普請が実施された**旨の御普請方記録。牧野大隅守（奉行的役）への御褒美（金2枚・時服2）が下付された。
- **与力・同心の褒美〔確認・文言OCR〕**: 第7冊に「**天明三卯年 千川上水素堀并樋枡懸渡之節 掛候与力壱人え拾両宛別段銀五枚宛 同五人え金弐両宛別段弐枚ツヽ被下置候**」＝当該普請に掛かった与力1人（10両＋別段銀5枚）・同心5人（各2両＋別段2枚）への褒美下付記録。
- **位置づけ〔観察〕**: [BOOK-077](../books/BOOK-077.md)（1941）の沿革「天明3（1783）竣成」に対し、**江戸幕府御普請方側の同時代記録**で工事の内容（素堀＋樋枡懸渡）・実施月（11月）・関与者（牧野大隅守・与力1・同心5）を初めて裏付ける。天明元年（辛丑）の疏鑿完成（[GOV-172](GOV-172.md)所引の沿革文言）に続く**追加・補修の御普請時点**として、安永9年再興→天明6年廃止の間の工程を埋める一次資料。褒美記録は経過・結果（入用高・日数）を「留記無之」として省略する帳簿形式である点に注意。

## 制限・未解決

- ①OCR由来の文言（「岡渡/懸渡」「素壁/素堀」等の判読ゆれ）は原本照合を要する。②「素堀」「樋枡懸渡」の施工区間（保谷分水口〜滝野川か、市中樋管か）は本記録からは特定できない。③牧野大隅守の役職名（普請奉行か否か）は未確認。
