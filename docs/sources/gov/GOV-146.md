# [GOV-146] すぎなみ学倶楽部「天保の水普請 新堀用水」〔repo初出〕

- **書誌〔確認: 2026-11-15・本文全文取得〕**: 杉並区公式情報サイト「すぎなみ学倶楽部」歴史カテゴリ「記録に残したい歴史」の[「智慧と技術の結集！天保の水普請　新堀用水」](https://www.suginamigaku.org/2014/10/h-niibori.html)。ページ上の表示日は**2007年12月7日**（URLパスは2014年10月で、移設・再掲の可能性あり・成立年の断定はしない）。杉並区の地域学習サイトとしての公式性はあるが、『杉並風土記』（森泰樹著）からの引用形式を含む**区の二次解説**であり、一次文書の直接確認ではない。
- **千川上水との接点〔確認・repo初出〕**: 解説の冒頭で、三ヶ村（中野村・高円寺村・馬橋村）の水田灌漑は「**主として天沼弁天池の湧水と千川上水からの分水を合わせた桃園川の流水**を利用していた」と明記〔**千川上水の分水が桃園川経由で中野方面の灌漑に使われていた**という構図を杉並区側の解説で確認。千川上水の灌漑範囲の南限理解（[BLOG-053](../blogs/BLOG-053.md)・README §千川上水）に接続する〕。
- **天保11年（1840）の第一次開削〔確認〕**: 天保4〜7年の凶作を契機に、尾根筋の向側の善福寺川から桃園川流域へトンネルで導水する計画。取水口は当初**権現堰（熊野神社裏手・矢倉橋付近）**、高低差不足のため**掛樋**で**成宗弁天池（成田東5-29）**に落とし、青梅街道の尾根筋を**トンネル**で潜り**元長生湯付近**で桃園川流域へ流出。幕府領代官**中村八太夫**の実地検査で**270両の補助金**、請負人は**馬橋村名主の大谷助次郎**、設計・施工・監督は**水盛大工の川嶋銀蔵**。天保11年2月地鎮祭・5月中旬完成。
- **天保12年（1841）の路線変更〔確認〕**: 完成直後、**川獺の巣による漏水と大雨による土手崩壊**で一部路線を変更し再度工事、**取水口を上流の広場堰（大谷戸橋上流・荻窪団地西北側駐車場付近）に変更**して天保12年に完成〔**二段階開削・二つのルート**の存在を区の解説レベルで確認〕。
- **三ヶ村用水記念碑〔確認〕**: **明治13年（1880）建之**・杉並高校隣の**成宗五色弁財天社境内**（成田東5-29・須賀神社と並ぶ）・**平成17年度杉並区登録有形文化財（歴史資料）**・公式名「中野村・高円寺村馬橋村三ヶ村用水記念碑」。碑文の採録あり: 「馬橋村之地平原乏水屡罹凶旱三村之民相謀上請開新渠引池水以灌漑時県令中村氏給費**天保十二辛丑正月工竣**」・発起・主名として**堀江卯右衛門・大谷徳左衛門・村田仁三郎・大谷助次郎**・水盛大工**川崎銀藏**〔碑面の表記ゆれ（川嶋銀蔵／川崎銀藏）に注意〕。弁天池付近の埋立工事で一時行方不明となり再建された経緯も記す。新堀用水は**22町7反の水田**を潤し、恩恵は**大正時代まで**続いた。
- **大谷家文書との対応〔観察〕**: [MAP-162](../maps/MAP-162.md)（「中野村高円寺村馬橋村三ヶ村用水路図」＝**大谷家文書**・杉並区指定有形文化財）と本解説の**大谷助次郎＝馬橋村名主で開削請負人**という記述が、大谷家（代々馬橋村の世襲名主・地方文書を約300年分保有）という文書群の性格と整合する〔絵図の一次性格を裏付ける文脈。ただし本解説は絵図を直接引用しておらず、対応は文書群の出自レベルに留める〕。
- **ADEAC解説との照合〔観察・未整理〕**: [MAP-162](../maps/MAP-162.md)のADEAC公開解説は「1度目の開削ルートは西田端橋から善福寺川沿いに南へ迂回して須賀神社のある弁天池へ、2度目は西田端橋から東へ弁天池へ直線」と述べ、本解説は「1度目＝権現堰から掛樋で弁天池へ、2度目＝取水口を上流の広場堰へ変更」と述べる〔**2つの解説で第一次ルートの形（迂回掘割か掛樋か）と取水口の対応（権現堰・広場堰・西田端橋の相互関係）が完全には揃わない**。西田端橋・権現堰・広場堰の位置関係の実地照合と、原本（大谷家文書・『杉並風土記』）の確認を要するため、ここでは両説を併記して断定しない〕。

## 制限・未解決

- ①区の二次解説であり、天保11/12年の工期・工費・人名の最終確認には『杉並風土記』（森泰樹）・大谷家文書原本が必要。②権現堰・広場堰・西田端橋・掛樋の位置関係の図的照合は未実施。③ページ日付（2007年12月7日）とURLパス（2014/10）の食い違いの理由は未確認。
