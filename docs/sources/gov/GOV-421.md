# [GOV-421] 享保撰要類集[62] 十八上ノ下（出水之部）— 寛保2年出水の御救実務側の冊

- **書誌〔確認〕**: 『享保撰要類集』[62] 十八上ノ下 出水之部。NDL次世代デジタルライブラリー [book/2572817](https://lab.ndl.go.jp/dl/book/2572817)。[GOV-420](GOV-420.md)（[61] 十八上ノ上）の次冊で、主に**寛保2年（1742）8月出水後の本所・深川筋の御救実務**を所収（2026-11-19第198回・fulltext全頁走査）。**引用文言はすべてOCR由来で要原文照合。**

## 内容メモ

- **本所筋の飢人小屋・粥の施行〔確認〕**: 本所・深川の浸水世帯への粥飯の施行・飢人小屋の設置・片付の伺書付群（松平左近将監殿え上ルの書付群として約80丁にわたって続く）。
- **渡船・賃銭の実務〔確認〕**: 両国橋・新大橋の船渡の賃銭・役船の配船・人留の文言群（新大橋の渡船賃銭50銭系の文言候補を含む・数値の行対応は要照合）。
- **寛保2年出水の江戸側の対応は[GOV-420](GOV-420.md)（大川筋日次・小日向筋書付）と本冊（御救実務）で対になっている**＝1742年出水（[PAP-094](../papers/PAP-094.md)・Sippel 2014の主題）の幕府側の一次記録が「報告→見分→御救→普請」の链条で復元できる所収構成。
