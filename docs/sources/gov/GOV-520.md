# [GOV-520] 豊島区「大塚台公園のリニューアル工事について」〔全面閉鎖・着工日の時系列確定と完成パースの行政一次記録〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: 豊島区公式サイト「まちづくり・環境・産業 > 公園・緑化 > 公園 > 取り組み > 大塚台公園のリニューアル工事について」。**ページID 57516・更新日2026年11月11日**。 https://www.city.toshima.lg.jp/610/ootukadaikouen/2608050806.html 〔基本計画案（[GOV-519](GOV-519.md)）の実施段階ページ〕。
- **工事の性格・全面閉鎖〔確認: 本文〕**: 「開園から53年が経過し、全体的に施設や遊具の老朽化が進行」「**今回の工事では既存施設のトイレ以外は全て解体し、一体の機能をもつ公園として生まれ変わります**」「**改修工事にあたり、2026年11月18日(水曜日)より公園は全面閉鎖となりご利用できません**」＝**既存トイレ以外全解体・2026年11月18日全面閉鎖**〔リニューアル後の完成パースが完成・公開（画像＝全体パース＋部分パース（都電側入り口・多目的広場・遊具エリア・ウォーターパーク遊具））〕。
- **スケジュール〔確認: 本文〕**: 「スケジュール（**令和8年10月時点**）: **令和8年11月18日 リニューアル工事着工／令和10年3月末 完成、リニューアルオープン**」＝基本計画案ページの「令和7年9月時点: 令和8年10月着工・令和10年3月竣工」（[GOV-519](GOV-519.md)）が**1か月強後ろへ精緻化された**〔池袋タイムズ報道〔[BLOG-290](../blogs/BLOG-290.md)〕の「2026年11月着工予定・2028年3月末完成」と整合〕。
- **施設詳細①〜⑦〔確認: 本文〕**: ①**二面球技場**「高さ6～10mのフェンスに囲まれており、全面がゴムチップ舗装のため快適にバスケットやキャッチボールが出来ます。2面」②**ウォーターパーク遊具**「**夏には水が噴き出し、子どもたちが全身びしょ濡れになって遊べる蒸気機関車をモチーフにした親水遊具です。夏以外の季節は、複合遊具として一年を通じて楽しめます**」③**遊具広場**（ミスト付きの日陰・砂場・3連ブランコ（**ハーネス型、バケット型含む**）・ロッキング遊具・**回転ジャングルジム**・**オムニスピナー**・幼児用滑り台）④**だんだん花壇**「都電沿線のバラと一体となるように、都電側の花壇はバラを植栽」⑤**多目的広場**（ロングベンチ・桜植栽）⑥**大型複合遊具**「**小学生に遊びたい要素のアンケートを取り、人気の機能を詰め合わせた**複合遊具」（登り・クライミング・バランス）⑦**都電側入り口**「都電側に新たに公園の顔となる入口とテラスを新設します。テラスに座り大塚駅側に広がる都電とバラをご覧いただけます」。
- **意義〔観察〕**: ①**親水施設の復元が着工段階に入った**＝[GOV-519](GOV-519.md)の「昔あった親水施設が保育園仮園舎の建設により未復旧」から、ウォーターパーク遊具（蒸気機関車モチーフ＝前身の展示蒸気機関車の意匠継承）としての実現プロセスが行政側ページで追跡可能。②**「蒸気機関車をモチーフにした親水遊具」**＝撤去される展示蒸気機関車（[BLOG-291](../blogs/BLOG-291.md)の撤去・解体報道）の記憶を遊具で接続する設計〔動機の公認は本文になく断定しない〕。③都電荒川線沿いの公園という立地面（都電側入り口・バラ）が整備主軸に明示された。
- **制限・未解決**: 施工者・工費（[GOV-521](GOV-521.md)の「全体工事費約6.8億円」のみ）・仮園舎の状態・親水遊具の正確な位置は本文に未記載。着工後の進捗（実着工日・着工式の有無）とウォーターパーク遊具の寄付募集結果はウォッチリスト。
