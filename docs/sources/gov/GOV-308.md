# [GOV-308] 『衛生試驗彙報』第3號（1888）— 千川上水の給水経路の文言と明治17-18年の分析表

- **書誌〔確認・第3號の年は要照合〕**: 内務省衛生局『**衛生試驗彙報**』**第3號**（**内務省衛生局・1888年〔明治21頃〕**。誌號と年の対応は奥付・表紙の原画像照合を要する）。NDL次世代デジタルライブラリー [book/1084069](https://lab.ndl.go.jp/dl/book/1084069)。東京府下の上水試験成績（明治17年4月〜明治18年3月の毎月分析）を収める。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①千川上水の給水経路の一次文言〔確認文言・repo初出級〕**: 「**千川上水ハ近年ノ創設ニ係リ亦木樋（OCR「木麺」・要照合）ヲ用ヒテ小石川區巢鴨ヨリ本〓（本郷）下谷ノ兩區ニ派流スト雖其供用尙（未ダ）タタラス**」＝**①千川上水を「近年の創設」（＝明治13年千川水道會社による再興系）と位置づけ、②木樋を用いて小石川区巣鴨から本郷・下谷の両区へ派流する給水経路、③その供用（給水の実態）がなお広くない、という1888年時点の観察文言**。〔明治13年再興〜明治40年廃止の間の1888年時点の千川上水の実態（給水範囲・設備の材質・供用状況）を伝える衛生行政側の文言。「巣鴨→本郷・下谷」の経路は[GOV-306](GOV-306.md)（1896・本郷及び下谷の一部に給水）・[GOV-307](GOV-307.md)（1911）と通時的に整合する。木樋の使用は既存の幕府期の樋管記録と対校できる〕。
- **②明治17-18年の千川上水の水質分析〔確認・表は列崩れ〕**: 「**千川上水ハ前ニ言ヘルカ如ク其供用未タ廣カラサルヲ以テ僅ニ極口其他二ケ所ニ於テ二回ノ分析ヲ為シタルノミ**」＝**千川上水は供用が広くないため「極口」のほか2ヶ所で計2回の分析のみが行われた**旨の記録＋「**第三號千川上水分析表**」の立項。〔①「極口」は採水地名として表に現れる（千川上水の取水・給水の樋の極口と推測されるが、本書だけでは設備の同定は断定しない）、②明治17年4月〜18年3月の分析期間中に千川上水の水質試験が実施されていた事実、③神田上水・玉川上水は「第一號」「第二號」分析表として毎月の採水で対照的に実施されていたこと。**分析表の数値部分はOCRの列崩れが著しく、本資料では数値の採録はしない（原画像の表起こしが必要）**〕。
- **③神田上水の流路文言の対校値〔確認文言〕**: 「**神田上水ハ東京ヲ距ル〓四里許井ノ頭ヨリ源ヲ發シ中途全福寺妙正寺ノ二助水ト合シテ小川トナリ田間ヲ匯流シテ關口ニ至リ小石川區ヲ經テ神田區ニ入リ分派シテ日本橋區ノ市街ニ普及シ遂ニ兩國橋蠣殻町本材木町等ノ諸地ニ至リテ河中ニ入ル**」＝1888年時点の神田上水の流路・給水範囲（井の頭→関口→小石川区→神田区→日本橋区→両国橋・蠣殻町・本材木町）の衛生行政側の記録。〔[GOV-306](GOV-306.md)④（1896年流路）の8年前の対校〕。

## 制限・未解決

- ①「木麺」は「木樋」のOCR崩れの候補（原字形照合を要する）。②「極口」の採水地点の設備上の同定（巣鴨の樋の極口か給水桝か）は本書だけでは断定しない。③分析表の数値は列崩れのため未採録。原画像での表起こし・数値の採録は今後課題。④第3號の刊行年（1888）は書誌API由来で、誌號と分析期間（明治17-18年）の関係の原画像確認を要する。
