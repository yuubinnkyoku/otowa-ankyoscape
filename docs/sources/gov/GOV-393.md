- **書誌〔確認〕**: 『書上帳』（文政10亥年〔1827〕中心の勘定所への書上・請取の控帳。亥正月の御徒組屋敷大縄関係・先手組屋敷関係の書上も同居）。NDL次世代デジタルライブラリー [book/2587275](https://lab.ndl.go.jp/dl/book/2587275)。**引用文言はすべてOCR由来で要原文照合。**
- **文政10亥年の井之頭池水門・柵御普請の決算〔確認・核心・repo初出〕**: 「**神田上水元井之頭池水門并畑其外共御普請為御用差遣候地割棟梁壱人宿代銀旅御扶持方代金請取候儀申上候書付御勘定所え御断御扣共三月十日**」＋本文「**但神田上水水元井之頭池水門并柵其外共御普請為御用差遣候地割棟梁壱人去戌十一月四日出立同十二月八日罷帰候一ヶ月銀半枚之積り米三石四斗壱升弐合五勺代金弐両弐朱銀四匁壱分弐厘五毛但右同断一日壱人米九升七合五勺六升五合五割増之積日数三十五日分御作料飯米三拾五石ニ付金弐拾弐両弐分替之積**」＋「**御普請方下奉行増田源三郎菅沼給左衛門右之通下奉行共申聞候間御勘定所え被仰渡可被下候**」＝**井之頭池の水門・柵（前年文政9戌11月4日〜12月8日の35日間）の御普請に差遣された地割棟梁1人分の宿代銀・旅御扶持方代金の請取書上**〔**井之頭池の水門・柵の修理工事が幕府の御普請方経由・勘定所決済で実施されていた**一次記録〔repo初出。〔[GOV-389](GOV-389.md)（天保5・6の水草刈）・[GOV-394](GOV-394.md)（弘化2の土留普請）と合わせて、**井之頭池の管理業務（水草刈・水門柵修覆・土留普請）が文政10〜弘化2年（1827〜1845）の書上帳群で地割棟梁宿代銀の共通形式で記録されている**＝水元の直轄管理の定常実務の帳簿列。時系列は文政10（水門・柵）→天保5・6（水草刈）→弘化2（土留）〕。「水門并畑」の「畑」は「柵」等のOCR崩れ候補・要照合（同冊に「水門并柵」も見える）〕。
- **同型の書上の反復〔確認・参考〕**: 同一の文言型（「神田上水元井之頭池水門并…御普請為御用差遣候地割棟梁壱人宿代銀…」）が同冊に複数回現れる〔棟梁の差遣が単発でなく反復した形。全数の切り出しは次回再走査〕。
