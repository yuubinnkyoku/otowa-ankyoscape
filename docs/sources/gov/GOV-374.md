# [GOV-374] 享保撰要類集 十九ノ上（堀川浚之部）— 六ヶ所御堀浚の定尺と水道橋の銅葺〔第163回〕

- **書誌〔確認〕**: 『享保撰要類集』十九ノ上（堀川浚之部）。NDL次世代デジタルライブラリー [book/2572819](https://lab.ndl.go.jp/dl/book/2572819)。元文3年（1738）3月付けの**六ヶ所御堀浚請負の定尺**等を収める。**引用文言はすべてOCR由来で要原文照合。**
- **六ヶ所御堀浚の定尺〔確認・repo初出〕**: ①「**江戸川筋 小日向大橋ゟ船河原橋迄 水欠より弐尺**」＝**江戸川の小日向大橋〜船河原橋区間の浚渫定尺が「水欠より2尺」**（年2回渡・92坪/年・請負20両）、②「**牛込御門〜水道橋 干汐ニ水尾通弐尺五寸**」＝**牛込御門〜水道橋区間は干潮時の水尾（水末）で2尺5寸**（920坪・請負200両）、③「**水道橋〜大川口 干汐三尺**」＝水道橋〜大川口（柳橋方面）区間は干汐3尺、④四ツ谷御門〜牛込御門の溜（20両）〔**江戸川・神田川の区間別の浚渫定尺・浚渫量（坪数）・請負額**の一次記録。①の「小日向大橋」は区間の起点橋としての用例（[GAZ-049](../gazetteers/GAZ-049.md)⑤の江戸川大橋＝石切橋と対校）。「干汐ニ水尾通弐尺五寸」＝**潮汐に応じて浚渫深の基準が変わる**運用の文言〕。
- **水道橋の神田上水戸極の銅葺〔確認・repo初出候補〕**: 「**水道橋神田上水戸極屋根共ニ銅ニ而葺建**」＝**水道橋の神田上水の水戸極（上水の末端樋管・水門の極）とその屋根が銅葺きで建てられた**記録（請負人・石川次郎左衛門（霊岸島）・六ヶ所合計800両/年）〔水道橋の神田上水通水構造の「水戸極」の名称と銅葺という材質の記録。[GOV-378](GOV-378.md)の水道行政・[BOOK-129](../books/BOOK-129.md)の水道橋修理記録と対校〕。
- **通船差支の文言〔確認〕**: 神田川が市ヶ谷・牛込・小石川・番町辺で**通船の差支**になるという文言（元文元年）＝神田川上流部の舟運限界の実務認識〔[GAZ-088](../gazetteers/GAZ-088.md)⑤の立慶橋下通舟上限文言と対校〕。
