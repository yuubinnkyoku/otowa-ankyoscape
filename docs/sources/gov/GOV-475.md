# [GOV-475] 東京市下水道震害調査報告（1925）— 三分区・三河島処分場・「至千川」幹線の震害

- **書誌〔確認〕**: 東京市下水課『東京市下水道震害調査報告』（1925・NDL次世代デジタルライブラリー [book/1876361](https://lab.ndl.go.jp/dl/book/1876361)・NDL書誌ID 000000972415・請求記号 519.2-To457t2）。章立て（OCR第4・7コマ）: 第一節「東京市下水改良計畫の大要竝大震當時ノ現存諸工營物」・第二節「下水管渠の被害」・第三節「三河島汚水處分場の被害」ほか「淺草喞筒場の被害」「處分場諸構造物…震害」等の節。**引用文言はすべてOCR由来・要原画像照合。統計表（「東京市下水旣成管渠震害統計表」）はOCR列崩れが甚大なため、文言・数値・線名の対応は原画像照合まで候補扱い**（本項では翻刻を原文表記どおりに示し、OCR崩壊部は〔〕や（=候補）で注記）。
- **三分区文言〔文言候補・第7コマ〕**: 「**東京市下水改良計畫の大綱は、明治四十一年當時の東京市區改正委員會の議定に係るものにして、地勢の關係により全市を三大別し、隅田川以西の大部分卽ち芝、麻布、麴町、赤坂、四谷、牛込、小石〔=小石川・OCR崩壊候補〕、本〓（=本郷候補）、京橋、日本橋の十區、神田區の大部分及下谷區の一部を加へて之を第一區とし、上野臺、本〓臺（=本郷臺候補）より以東神田川以北の低濕なる地區卽ち下谷區淺草區の大部竝神田區の一部を第二區とし、殘餘の江東方面即ち本所深川二區を第三區とし、各區各別に汚水、雨水の排除竝に汚水の處分を講ぜんとするものなり**」。〔明治41年（1908）市区改正委員会議定の下水三分区の出所文言。**千川・谷端川流域の小石川・本郷側、水窪川・弦巻川流域の牛込側は第一區**＝[GOV-163](GOV-163.md)（1924）の流域区分の上位の行政区分文言〕。
- **大震当時の進捗文言〔文言候補・第7〜8コマ〕**: 「**以上の計畫中東京市に於て第一に工を起せるは第二區に屬する地域にしてこれを第一期工事とし明治四十四年起工大正十一年略ぼその工を竣れり。次に第二期工事として第一區中、本市の中樞區域卽ち京橋、日本橋兩區竝麴町區の內丸ノ内及芝區の一部に對し大正十年工を起し目下施工中に屬す**」＋「**殘餘の地區に對しては實施調査を完了せしと雖未だ起工するに至らずして這般の大震に際會せるものなり**」＋「**大震當時迄に竣工せるは全市の約二割に止まり他は未着手なり**」＋「**上記第一表に見る如く大震當時の現存下水管渠はその延長、十萬間餘に及び**」（第8コマ）。〔**大正12年9月の時点で小石川側（千川筋＝第一區残部）の改良下水道は実施調査完了も未起工だった**＝[GOV-473](GOV-473.md)（昭和4〜9年度の千川筋下水道改良工事）による1929年着手と整合する進捗文言。竣工「諸工營物」表（第8コマ）に「三河島汚水處分場／淺草田町喞筒場／神田和泉町喞筒場／速成雨水吐幹線(九線)／第一區汚水幹線ノ一部／第一區汚水壓送管ノ一部／第〔二?〕區枝線ノ一部」等が列挙〕。
- **速成雨水吐工事〔文言候補・第7コマ〕**: 「**尙是より先、第一區中其の地形溪谷の態をなし排水狀態甚しく不良なる部分(例へば市ケ谷谷町、或は古川流域の如き)に對し局部的に雨水吐管渠工事を施せるもの九ケ所を數ふ。之を速成雨水吐工事とし大正五年度より大正九年度に亘り其の工を竣れり**」。〔大正5〜9年度（1916-20）の第一區溪谷部9線の先行雨水吐実務。第10〜11コマの統計表はこの系統＝指ヶ谷線・藍染川線等を含む幹線群の震害統計〕。
- **指ヶ谷線＝「柳町至千川」幹線〔文言候補・本登録の核心・第10〜11コマ〕**: 統計表の行群（OCR）に——線名欄「**指ケ谷線**」判読・自至欄「**自指ヶ谷〔至〕白山下經**」・規模「**6.5×5.0乃至…520**（=延長520間候補）」・「**柳町至千川 9.0×5.0 但柳町附近ハ土覆少ナシ**」＝内法6.5尺×5.0尺（一部9.0×5.0か・表崩れ）の幹線が「**千川**」へ達する行、地勢欄「**地勢千川流域低地カ本〓（=本郷）臺小石川臺ニヨリテ將ニ狹マレントス 方向略南微東 川口ニ位ス**」・縦断欄「堀鑿深9.5〜13.0・土覆3.0〜6.0・勾配1/500」・被害欄「**被害ハ大部分下流柳町方面ニ集マル**」「**之ノ附近ハ特ニ地盤惡シ而シテ柳町附近ノ被害密度ハ13.0ニ及ブ**」。〔①**「千川」＝旧千川（谷端川下流＝神田川合流系の小石川低地）が1925年の下水実務で吐口名・流域名として使われた行政用例**（[GOV-471](GOV-471.md)〔1913〕の「千川線」構想・「柳町〜富坂下千川筋道平面圖」の後継実体にあたる行＝repo初出）、②指ヶ谷→白山下→柳町（千川吐口）の第一區雨水吐幹線の1923年震害実測＋柳町附近被害密度13.0という数値記録、③「柳町」＝文京区千石の柳町（旧小石川区柳町）と突き合わせると指ヶ谷（音羽・護国寺側谷）→白山下→千石台地間→千川低地の流路が特定できる候補。ただし表崩れのため線名と数値列の正確な対応は原画像照合まで候補〕。
- **藍染川の流路規定文言〔文言候補・第11コマ〕**: 同表の別行群に——「**駒込臺彌生町臺ト上野臺〔間ヲ北ヨリ南ニ流ルル〕藍染川ノ流域ノ中流部ニ位ス**（自至欄: 千駄木町・6.0×6.2）」・「**藍染川ノ下流不忍池西岸ニ沿フ 方向略南北 下流ニ東西ノ部アリ**（池ノ端七軒町・7.0×6.2等）」・「**方向開渠部南東其他北東**」＋線名欄「**藍染線**」判読（「藍染線開葢形渠」）。〔**藍染川の中流＝千駄木町（駒込台-弥生町台-上野台間）・下流＝不忍池西岸という1925年下水実務での流路規定**＝谷端川小石川区間の藍染川呼称（[GAZ-093](../gazetteers/GAZ-093.md)等の桜川系史料群と対照）の行政用例・開渠部の残存も文言候補。地誌・町方書上系とは独立の系統の一次文言〕。
- **「藍染排水路」文言〔文言候補・第22コマ〕**: 第二節末の火災損害額内譯表に「**藍染排水路**」の施設名列読（金額対応は訳列崩れのため不定）＝**藍染川に並走する「藍染排水路」という下水施設名の実務用例（repo初出候補）**。
- **三河島汚水処分場の文言〔文言候補・第15〜16コマ・本登録の核心〕**: 「**三河島汚水處分場は府下三河島町荒川岸に位し、東京市下水道設計第二區卽ち淺草、下谷兩區の大部並に外神田を包含する地域、面積約二百一萬八千坪の下水を〔簡〕淨處分する施設にして、大正十一年三月作業を開始せるものなり。其敷地面積約五萬六千坪**」＋「**處分能力は、最大乾天時一日約二百四十萬立方尺、降雨時に於ては一秒時約百六十五立方尺の下水を取扱ふものとす、尙必要に應じ將來擴張の余地を存す**」＋設備仕様（沈砂池2個・喞筒室〔建坪349坪73勺〕・沈澱池6個〔內1個予備・長280尺×幅70尺・水深5尺〜5尺8寸5分〕・點滴濾過式濾過床17類〔床總面積30萬8千平方尺〕・撒水機14組・最後沈澱井2個・滓渣喞筒室・滓渣槽2個等）。〔**三河島処分場の運転開始（大正11＝1922年3月）・第二區（浅草・下谷・外神田）201万8千坪の処分区範囲の行政側一次文言**＝千川筋処分区変遷（第一區→芝浦〔1934・GOV-473〕→現代の三河島処理区〔第24回記録〕）の系列の初期定点〕。
- **三味線堀改修文言〔文言候補・対照系・第9〜10コマ〕**: 「**本マ線（=本町線?判読候補）ハ舊三味線堀ヲソノマ〔改修セルモノニシテ渠底部舊〕溝底 土覆ハ1.0內外ナリ**」＝旧堀を転用した既設幹線の実務例（第二區の下谷・浅草側で、第10コマの近藤線・束堀新草線・南線棚燒熱等の第二區幹線行群とともに「味線堀」のOCR断片も現れる）。「三味線堀」の実務用例はrepo初出候補（線名の判読は原画像照合前提）。
