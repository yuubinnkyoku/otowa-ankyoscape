# [GOV-350] 神田玉川上水留 分冊ノ二（明治2年）— 関口水道町の鉄砲製造所一件帳の書名と狹山助水堀の高札

- **書誌〔確認〕**: 『神田玉川上水留』（写・明治2年〔1869〕正月より・分冊ノ二・NDL次世代デジタルライブラリー [book/2587525](https://lab.ndl.go.jp/dl/book/2587525)）。明治2年の神田・玉川上水関係の一件帳合集（[GOV-248](GOV-248.md)系の未登録分冊・今回の登録）。**引用文言はすべてOCR由来で要原文照合**。
- **「関口水道町御鉄炮製造所増御用地御構外道造其外一件帳」の書名記録〔確認・文言候補・repo初出〕**: 明治2年5月19日の東京府屋敷役山田六郎持参の覚に載る11冊の目録の中に「**関口水道町御鉄炮製造所増御用地御構外道造其外一件帳**」の書名が現れる。〔**幕末〜明治初頭の関口水道町の鉄砲製造所（現在の目白通り沿い・関口水道町の陸軍造兵廠の前身期）の増用地・構外道造（構外の道路造成）の一件帳の存在記録＝repo初出の書名情報**。repoのREADME・gov資料群にこれまで鉄砲製造所の記述がないことは確認済み。①書名は目録経由の情報で、一件帳本体の所在は本冊では確認できない。②「増御用地」「構外道造」から、製造所の用地拡張に伴う境界・道路の再編が明治2年時点で文書化されていたことが読めるが、増用地の範囲・時期（幕末の炮兵工廠系か・明治以降か）は本冊では確認できない。③関口大洗堰・神田上水堀筋（[GAZ-080](../gazetteers/GAZ-080.md)の水番屋構等）と水道町の土地利用の変化を結ぶ資料候補。〕
- **狹山池助水堀の高札建場所6ヶ所リスト〔確認・文言候補〕**: 「**箱根ヶ崎村狭山池ゟ玉川上水江之一町水堀通高札建場所**」として、①「**殿ヶ谷村落口西之方**」②「**石畑村村山道通橋際西之方**」③「**三ツ木村五日市道石橋際東之方**」④「**三ツ木村青梅道石橋際西之方**」⑤「**中藤村稲毛道橋際西之方****」⑥「**箱根ヶ崎村日光近辺橋際東之方****」の建場所が列挙される（殿ヶ谷村地内の1ヶ所目の有無はOCRで両様・要照合）。〔**狹山池から玉川上水への助水堀（一町水堀）沿いの高札建場所の明治2年の実務リスト＝[GOV-283](GOV-283.md)/[GOV-285](GOV-285.md)/[GOV-288](GOV-288.md)/[GOV-290](GOV-290.md)の狹山助水の経路比定の明治2年補強資料**。高札の内容（助水堀の保護規定か）は本冊では確認できない。玉川上水系でありrepo対象4河川の外縁の資料だが、[GOV-264](GOV-264.md)の玉川上水高札と対になる助水堀側の記録として登録。〕
