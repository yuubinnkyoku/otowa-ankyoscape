# [GOV-396] 東京市史稿 市街編44 — 嘉永7年（1854）淀橋水車の焔硝製法と爆発事故の一次記録群・「不姿見橋」の巷説・安政大地震の玉川上水樋文言〔第166回〕

- **書誌〔確認〕**: 『東京市史稿』市街編44（東京都・1957年刊）。NDL次世代デジタルライブラリー [book/9640906](https://lab.ndl.go.jp/dl/book/9640906)。嘉永〜安政期の市街の事蹟の集成で、町奉行所・代官所等の一次文書を大量に引用する。**引用文言はすべてOCR由来で要原文照合。**
- **嘉永7寅年（1854）6月11日の柏木淀橋町訴状＝淀橋水車の御用焔硝製法の仰付と町内の嘆願〔確認・核心・repo初出〕**: 「**右淀橋水車え御用焔硝製法之義被仰付候處、兼而水車こ而製法の不調法は、瀧野川村水車、細川の小山村水車、其外こハ酒井の牛込矢來屋敷の製法、深川六間堀の小細川の雷火共、都合四ヶ度の過失こて、手ごり致し**」＋「**役人より名主紋右衞門相進め候樣申付候ニ付、家主供々相進め候こ付、水車久兵衞御請致候由、右こ付門口棒杭こ、西洋砲御貯御用合藥製場御用鐵炮藥製法所玉藥方右之通棒杭を建て、每日々々製法致候ニ付、近邊之者ハひやひや致し相止度存し**」＋「**又本人久兵衞ハ右御用こて每日々々八兩宛こ相成候故、是も欲情こて御免を不願**」＋「**町內之者共二度迄御免願ひ出候得共、御免無之…御勘辨之上御取計有之候樣存候**」（嘉永七寅年五月十七日答下ケ札・湯島麟祥院領武州柏木淀橋町）＝**①淀橋水車への御用焔硝（火薬）製法の仰付があり、②先に水車での製法の不調法（失敗）が瀧野川村水車・細川の小山村水車・酒井の牛込矢来屋敷の製法・深川六間堀の小細川の雷火の都合4回あり（手ごり）、③町内の嘆願にもかかわらず水車久兵衛が御請し、門口に棒杭を立て「西洋砲御貯御用合藥製場・御用鐵炮藥製法所・玉藥方」の立て札を掲げて毎日製法を行い、④久兵衛は日当毎日8両を受け取り御免を願い出なかった**という嘉永7年5月17日時点の訴状〔**水車火薬製造の先行4事故のリスト（repo初出）と、淀橋水車が嘉永6丑年（1853）7月中に焔硝製法を仰付られた旨の文言（「去丑…の七月中被仰付候得共」・OCR崩れ大）も同居**。酒井の牛込矢来屋敷の「製法」は彦根藩井伊屋敷とも読めるが断定しない〕。
- **嘉永7寅年6月12日朝6時過ぎの水車合藥製場出火・爆発事故〔確認・核心・repo初出〕**: ①御届（柏木淀橋町）: 「**柏木淀橋町水車合藥製場より出火致し、御品燒失仕候**」、②小遣人足利吉右之者の焼死御届: 「**柏木淀橋町水車製藥場會所小遣爲相勤、一昨十日泊りこ御座候處、昨曉六時過、右製藥場より出火仕、會所向押倒し候節、立追候間合も無之相見へ候內、直こ火移り燒死仕候**」（八丁堀三丁目家持八三郎引受）＝**6月12日朝6時過ぎに水車合薬製場から出火・会所が押倒（爆風）となり、小遣人足利吉右之者が焼死**、③柏木淀橋町訴状（月行事常次郎・五人組岩次郎連署）: 「**玉久兵衞方人足之內壹人卽死致し候由風聞致候へ共、虛實未タ突留兼申候。柏木淀橋町過半押潰、同處成子町武州豐島郡角筈村柏木村多摩郡中野村本〓村町家共損家有之候**」＋「**久兵衞住居過半飛散し、見世表間口六間奧行三間程傾き損し**」＋「**久兵衞方土藏二ケ所散亂致し、右跡十間四方程深さ八九尺程地上掘返し…**」＝**淀橋町過半押潰し・成子町・角筈村・柏木村・中野村の損家・久兵衛住居の過半飛散・土蔵2ヶ所散乱と直径十間四方・深さ八九尺の掘返し（爆発痕）**、④「**右廿五駄ヘ火移り候者新宿いづミ新田御焔硝藏へ四箱附廿五駄相納メ候よし、是こて逃候者ハ怪我致さず**」＝**和泉新田の御焔硝藏へ四箱附廿五駄を相納める直前の荷に火移りとの噂（類焼直前の輸送の文言候補・要照合）**、⑤角筈村御代官所御届: 「**武州豐島郡角筈村之儀は、町方支配柏木淀橋町え隣り居、右淀橋町家持久兵衞義受負所持之水車ニテ、御鐵炮玉藥方井下曾根金三郎掛り合藥製法致罷在候處…曉六時頃、右合藥場より火氣相發、町家等燒失致し、右響ニ而前書角筈村淀橋町百姓家之内潰家二軒損家五軒出來、人馬怪我者無之**」＝**角筈村側の被害（潰家2軒・損家5軒）と「御鐵炮玉藥方井下曾根金三郎」の掛かり**、⑥最寄支配所の書上: 「**甲州道中之方ぇ寄、代々木村、角筈村、幡ケ谷村、右三ケ村最寄村方御座候**」、⑦見舞金の実務: 「**潰家壹軒こ付金三步ツ破損家壹軒こ付金壹步ツヽ、十兵衞又左衞門より見舞として差送候段屆出**」（角筈村百姓又三郎外八人・麴町平川町の鈴木十兵衞・越前屋又左衞門が成子町に家屋敷所持）＝**嘉永7年6月12日の淀橋水車合薬製場爆発の被害・届出・見舞の実務記録一式〔repo初出**〔**[GOV-399](GOV-399.md)（文久〜元治の相続願）の「安政元寅年右水車ニ而炮薬舂立及出火」の文言と年次整合（嘉永7年11月改元・安政元年＝1854）＝同一事故の後追い側の一次文言**。嘉永明治年間録（[book/772604](https://lab.ndl.go.jp/dl/book/772604)）の巷説は「**當二月十一日阿部播磨守下屋敷にて火藥製作の節多人數怪我有之一昨廿二日四谷淀橋水車にて製藥あ火移り…**」と**二月**の事故として記し月日の対立候補をなす（年間録は後代編纂の巷説集・一次記録側の六月を優先しつつ対立を併記。巷説の二月事故は訴状の「當春七年…板橋〓小山村之水車には火難有之」等の先行事故の記憶混淆の候補もあるが断定しない）〕。
- **「不姿見橋」の巷説〔確認・文言候補・repo初出〕**: 前記訴状の末尾に「**淀橋を昔ハ不姿見橋と申けれハ、地雷火で家を殘らず打崩し、人の姿も見ずの橋なり**」＝**淀橋（面影橋）は昔「不姿見橋」と呼ばれ、地雷火で家を残らず打ち崩し「人の姿も見ない橋」という巷説**〔**面影橋＝淀橋の異名群（[GAZ-030](../gazetteers/GAZ-030.md)の安見橋・[BOOK-194](../books/BOOK-194.md)の姿見数の橋・姿か橋）に新系統を追加する文言候補**〔訴状本文に付された巷説で、嘉永7年の爆発事故の直後の世相で語られた由来譚（地雷火＝火薬の爆発）と読むことも可能だが、巷説の成立年代・「不姿見」の初出は本文言では確定しない。**「姿見数の橋」（BOOK-194）と「不姿見橋」の語形の類似は対校案件**〕。
- **安政大地震の玉川上水樋文言〔確認・参考・repo初出〕**: 同巻の四ツ谷邊の地震被災記録に「**四ツ谷御門外〓新宿迄之間左程こ無之、半潰土藏震ひ位也。新宿〓四ツ谷御門外迄玉川上水樋震ひ潰し水吹出し、往來難儀こ付、水元を止ル。右こ付、又々水切こ而難儀致し候よし**」＝**安政大地震（安政2卯年11月・1855）で四谷御門外〜新宿間の玉川上水の樋が震い潰れて水が吹き出し、通行の難儀により水元（取水元）を止め、そのため再び水切（通水停止）の難儀が出た**という被災記録〔**玉川上水の内藤新宿〜四谷区間の樋の被災と水元停止・水切の実務の文言候補（repo初出）**〔出典は安政錄・嘉永明治年間録・藤岡屋日記等の集成（巻末の出典列による）。四谷御門外〜新宿間の「樋」の位置（上水の開渠・樋管のどの区間か）は文言上保留〕。
