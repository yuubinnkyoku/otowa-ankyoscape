# [GOV-329] 本郷区勢要覧 昭和5年（1931）— 六義園大池の千川上水余水の現勢〔repo初出・第139回〕

- **書誌〔確認〕**: 本郷区編『本郷区勢要覧 昭和5年』（1931年刊）。NDL次世代デジタルライブラリー [book/1280521](https://lab.ndl.go.jp/dl/book/1280521) のOCR全文を確認。本郷区（現文京区本郷域）の区勢・史跡をまとめた**区編纂の行政資料**。**引用文言はOCR由来で要原文照合**。
- **六義園大池への千川上水余水〔確認・repo初出の現勢〕**: 六義園址の条に「**園內ノ大池ニハ千川上水ノ餘水ヲ注イデヰルガ、此上水ハ舊時「玉川ヨリ煉馬ヲ歷テ巢鴨ニワタリ、駒込富士前ヨリ本江（本郷のOCR誤候補）湯島ニ至リ、上野山谷中下谷柳原淺草邊ヘカ〓ル。享保七八ノ比絕」ト續江戸砂子ニ記シタモノガコレデアル**」＝**1931年時点で六義園の大池に千川上水の余水が注がれていたという現勢記録**＝[GOV-327](GOV-327.md)（千川上水の明治40年6月廃止）・[BOOK-140](../books/BOOK-140.md)（岩崎所有化）の後も、**岩崎家所有となった千川水の余水が本郷区の六義園（旧岩崎邸域）の大池に使われていた**という上水廃止後の水的利用の実態の区政資料側の観察（余水の給水源・経路〔巣鴨の濾過池からの陰樋か〕は本書では特定できない）。**千川水と六義園・柳澤氏（旧郡山藩）・岩崎家の接続の1931年断面**として重要な datapoint。
- **続江戸砂子引用の千川流路説〔確認・repo既出説の1931年再録〕**: 引用文言「**玉川ヨリ煉馬ヲ歷テ巢鴨ニワタリ、駒込富士前ヨリ本郷湯島ニ至リ、上野山谷中下谷柳原淺草邊ヘカ〓ル**」＝千川の市中流路（駒込富士前→本郷湯島→上野→下谷→柳原浅草）の江戸期の説を『続江戸砂子』から引用（流路説の原典採録の系譜に加わる。**「続江戸砂子」の書名確認・引用の正確さは原典との対照を要する**）。享保7・8年の断絶→「**再興ハ明治十三年八月デ千川水道會社ノ手ニ依ツテ翌年工事完成**」＝再興の沿革の整理（明治13年8月起業→14年工事完成という時系列の区政資料側の記述で、[BOOK-174](../books/BOOK-174.md)・[GOV-327](GOV-327.md)の沿革説と一致）。
- **「本〓」問題への含意〔観察〕**: 本書は本郷区の編纂資料で、区内地名・史跡（六義園）の文脈で千川上水を扱う。**千川の市中側の給水区域を「本郷」域と把握する立場から書かれた区勢要覧**である点で、[GOV-290](GOV-290.md)・[GOV-327](GOV-327.md)の「本〓（本郷候補）」読みを傍証する文脈資料となる（原字「本江」はOCR誤候補で断定しない）。
