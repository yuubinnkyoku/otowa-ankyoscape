# [GOV-448] 豊多摩郡中野町現状調査 — 旧神田上水呼称・吾福寺支流表記・暗渠1,174mの帳簿

- **書誌〔確認〕**: 『豊多摩郡中野町現状調査』（東京市臨時市域**擴張部**編・[book/1900480](https://lab.ndl.go.jp/dl/book/1900480)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**中野町（1932年中野区）冊**。第218回の現状調査シリーズ棚卸しの中で最も収穫のあった1冊。
- **位置章の「旧神田上水ヲ隔テ淀橋町」〔文言候補〕**: 「**豊多摩郡ノ中央、旧神田上水ヲ隔テ淀橋町・代々幡町（ト境シ）東（ハ）東南部（ハ）北落合町、野方町…**」＝**1931年の行政調査の位置章で、中野町と淀橋町の境界を「旧神田上水」で隔てると規定した文言**＝**「旧神田上水」呼称による現行境界の規定の用例（repo初出の文脈候補）**〔対照表「旧神田上水」行（上水廃止後の旧上水路）の具体的な1931年の行政文書レベルの使用例＝神田上水廃止（明治30年代）後も、境界の基準線・地勢の基準線として「旧神田上水」の呼称が昭和初期の行政文書で生きていたことの定点〕。地勢章でも「**青梅街道ヲ挾ンデ神田上水（本町南部ノ北端ヲ）、吾福寺支流（北部ノ南端ヲ）夫々東西ニ奬（礫?）流ス**」＝**青梅街道を挟んで南の北端に神田上水（＝神田川）、北の南端に「吾福寺支流」（＝善福寺川のOCR表記候補）が東西に並走する地勢規定**〔①「吾福寺支流」＝善福寺川の「善福寺」のOCR崩れ候補（善福寺＝善福寺川の由来寺・中野区内に現存）で、repo内でこの表記は初出候補（要原画像照合）、②神田川と善福寺川が青梅街道を挟んで東西に並走する中野台地の谷構造を、1931年の行政調査文体で南北の端として規定した文言〕。
- **海拔数値の地勢文言〔確認・数値は要照合〕**: 「**此ノ流域一帶ノ地形稱（最?）低ク神田上水下流大字本御地内ニ於テ海拔八十八尺四寸四分ヲ示セリ之ニ及シテ町ノ西北野方町ニ接スル中野駅附立（附近）八髙地形ヲ有シ海拔百三十三尺三寸二分ヲ示ス又西南部和田堀内ニ連ナル大字雜色モ地形稍髙ク最高百二十九尺七寸ニ達ス**」＝**①中野町内の最低点＝「神田上水下流」の大字本町（？「本御」のOCR崩れ候補）地内で海拔88尺4寸4分＝神田川流域が町内最低の谷であることの数値規定、②中野駅附近133尺3寸2分、③雑色（大字雑色）最高129尺7分（…寸）＝**1931年時点の行政調査レベルで町内の最低点が「神田上水下流」の地内であることを具体的高度で確認した文言**（尺貫法の高度表記＝地籍図・空中写真の地形判読の対照基準になり得る）。
- **暗渠1,174mの下水道文言〔文言候補・本ファイルの核心〕**: 「**四九、下水道事業 下水道事業規定ニヨル施設ナキモ町内ニ（二?）ヶ所ニ總延長一、一七四米ナル暗渠ノ〓（敷?設?）設アリ 会（左?）工事八大正十四年 戸（府?）算額二四、四九一円ヲ以テ施設計画ヲ立テ 会年十一月起エシ（大正十四年十一月?）昭和五年十一月ソノ全部ヲ完了セリ**」＝**①「下水道事業規定ニヨル施設ナキモ」（正式の下水道事業による施設はないが）、②町内に総延長1,174mの暗渠の施設があり、③大正14年（1925）に算額24,491円で計画を立て同年11月起工、④昭和5年（1930）11月にその全部を完了した**＝**中野町の下水道史の在一次座標群**〔**大正14年に中野町が自費で計画・起工し昭和5年に完成させた1,174mの暗渠の文言候補。中野町域（旧千川上水・神田川流域・青梅街道沿い）の大正期の暗渠の1,174mについて、その水路の正体（雨水・污水別・千川上水旧水路の転用か新設か）は本文言からは特定できず、千川上水系の暗渠化（既存の知見：千川上水跡の暗渠・下水道幹線への転用）との同一視は断定しない（要原画像照合・所在の「二ヶ所」の比定は今後課題）**。対応する既存系として[GOV-166](GOV-166.md)（東京市下水道年報・千川系幹線）の計画～実施の流れと、[GOV-442](GOV-442.md)（落合町・施設ナシ）の陰性記録があり、中野町側だけが独自に暗渠を整備していた時間差の定点候補〕。
- **帳簿文言〔確認〕**: 沿革＝中野・本郷（本〓?）・雑色の三村併合・「中野ヲ以テ冠称」・明治2年2月に品川縣（〓川縣）から神奈川縣に替わり第四十六区・明治5年8月東多摩郡（等）の文言、鉄道＝中央線（中野・東中野）・西武電車（宝泉寺前・鍋屋横町・天神前・淀橋の各駅）・東京乗合（青バス）の路線記述等＝1932年市域拡張直前の中野町の帳簿。
