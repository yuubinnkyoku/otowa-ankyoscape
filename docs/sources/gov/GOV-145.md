# [GOV-145] 国立公文書館の滝野川町谷端の土地区画整理・下水道一次記録（NDA「滝野川」検索・1942〜1954）〔repo初出〕

- **調査方法〔確認〕**: NDA検索APIで「滝野川」（79件ヒット）を走査し、repoの四河川（水窪川・弦巻川・谷端川・千川上水）に関係する3件を抽出（2026-11-14〜15）。いずれも**未デジタル化**（`/img/` ビューアなし・`/file/` 詳細ページで目録のみ到達可）で、国立公文書館（東京本館）等での閲覧対象。
- **1951年（昭和26年）1月24日 東京特別都市計画復興土地区画整理事業組合施行（滝野川谷端）設計変更認可申請〔所在のみ〕**: 建設省都市局、請求記号**昭５６建設22000080-00600**、[file/1878974](https://www.digital.archives.go.jp/file/1878974)〔**滝野川町谷端（現在の北区滝野川の谷端地区）の復興土地区画整理が組合施行で行われ、1951年時点で設計変更の認可申請段階にあった**ことを示す行政記録〕。
- **1954年（昭和29年）6月10日 東京特別都市計画滝野川町谷端復興土地区画整理設計変更認可〔所在のみ〕**: 建設省計画局都市復興課、請求記号**昭５６建設22200050-00300**、[file/1879170](https://www.digital.archives.go.jp/file/1879170)〔1951年申請の設計変更が**1954年に認可**された記録。両記録で「復興土地区画整理」と呼ばれる事業が戦後10年近く継続していたことが分かる〕。
- **1942年（昭和17年）3月23日 大久保町・滝野川町・郊外下水道事業の執行年度割中変更（昭和17年内務省告示第230号）〔所在のみ〕**: 内務省国土局計画課、請求記号**昭５３建設56000040-00300**、[file/1868703](https://www.digital.archives.go.jp/file/1868703)〔**東京都市計画下水道事業として大久保町・滝野川町・郊外の3事業が告示レベルで存在し、1942年に執行年度割の変更が行われた**ことを示す。滝野川町下水道は現在の北区滝野川地区の下水整備の前史〕。
- **位置づけ〔観察・要注意〕**: 「滝野川谷端」は**滝野川町の字・小字地名（現在の北区側）であって、豊島区の谷端川そのものの記録ではない**可能性が高い〔地名の同名現象。谷端川（豊島区・粟島神社弁天池水源）と「谷端」という谷戸の縁を意味する普通名詞由来の地名が北区滝野川にもある点は、[GAZ-015](../gazetteers/GAZ-015.md)（池袋村の地名由来・谷端川流域説）等の地名研究の比較材料になりうるが、両者の関係は本文未見のため断定しない〕。一方、**滝野川町下水道事業（1942）は千川上水・王子分水の滝野川地域（[GOV-144](GOV-144.md)の反射炉・大砲御製造所の地）の下水道史の前段階**として、また復興土地区画整理（1951/1954）は**滝野川の戦後の街区・水路痕跡の形成圧力**として、READMEの千川上水・滝野川区間（[BLOG-043](../blogs/BLOG-043.md)の滝野川区間暗渠化）の文脈に接続する所在記録である〔いずれも本文未見で、事業区域が谷端川・千川上水旧流路と重なるかは確認できていない〕。
