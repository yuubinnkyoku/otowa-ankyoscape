# [GOV-041] 1989年度「失われた水辺を探る」の実施期間を館報から確認

- **資料〔確認〕**：豊島区立郷土資料館『かたりべ』第18号、**1990年5月15日発行**、[豊島区公式PDF](https://www.city.toshima.lg.jp/documents/2550/kataribe18.pdf)、全4頁。**印刷p.4「1989年度の郷土資料館事業について」**をページ画像から直接判読（2026年11月2日）。
- **講座の期間〔確認：1990年の事業報告〕**：同頁は地域史講座「中世・鎌倉街道を調べる」と「失われた水辺を探る」を挙げ、**前者を1989年6月4日～6月25日、後者を同年10月8日～11月5日**に実施したと記す。これは**後年の1999年広報による回顧より約9年前の事業報告**であり、講座の実施期間を日付まで絞れる。
- **対象河川との関係〔確認：別資料との照合／推定〕**：1999年10月9日の豊島区広報資料 [GOV-001](GOV-001.md) は、1989年度の同系統の講座で**弦巻川・谷端川**を取り上げたと回顧する。また、豊島区の1991年度展示紹介では1989年度の「豊島区の川を歩く～谷端川・弦巻川～」を挙げる。**「失われた水辺を探る」と「豊島区の川を歩く」が同一企画の正式名・副題の関係にあるかは未照合**。従って**1989年10月8日・11月5日を各河川の個別踏査日と断定しない**。
- **史料探索上の意義〔推定〕**：1989年**10～11月**の講座案内・配布地図・写真・参加者記録・報告を優先して探索する根拠になる。**講座の開催期間は河川の暗渠化・橋の撤去・道路工事の年代ではない**。各回の日付、経路、配布物、撮影地点は未確認。
