# [GOV-089] ふるさと文化館所蔵品アーカイブ「千川家文書」

## 書誌・所在（2026-11-12、直接確認・ai）

- 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（文書類）の総括レコード。 https://www.neribun.or.jp/archive/detail.cgi?id=10003
- 番号: **2000-1-0002**。名称: 千川家文書（せんかわけもんじょ）。年代: **元禄9年（1696）〜明治17年（1884）**。
- 内容等〔確認: レコード本文〕: 「千川上水の歴史を広く知ることができる千川上水絵図など江戸期、明治期の文書・記録・絵図類**297点（江戸期168点、明治期62点、不詳67点）**」。

## 内容メモ

- [MAP-155](../maps/MAP-155.md)（千川用水堀絵図・2000-1-0002-284）、[MAP-156](../maps/MAP-156.md)（江戸上水配水図・2000-1-0002-279）等、repo既収録の千川家文書系個別資料の**上位コレクションの総括レコード**として、コレクション全体の規模（297点）と年代幅（元禄9年〜明治17年）を初めて一次レベルで確認した。
- 年代幅の下限「明治17年（1884）」は、[GOV-068](GOV-068.md)・[GOV-005](GOV-005.md)が引用する「明治17年11月『千川上水絵図』」「明治17年頃『千川上水路図』」の作成年と一致し、これらの絵図が千川家文書（または同時期の関連文書群）に含まれる可能性を示唆する〔推定、断定はしない〕。

## 制限・未解決

- 297点の個別点目録（明細）はこのレコードからは取得できない。アーカイブの個別レコード番号の通し調査（2000-1-0002-xxx系列）が次の一手。既知の個別レコード: 10016（江戸上水配水図）。
- 千川家文書のうち区登録文化財「千川家文書」（昭和63年度登録、[GOV-004](GOV-004.md)）との収蔵・登載関係は本レコードからは確認できない。
