# [GOV-204] 議事速記録 第7号 — 谷端川附近の工場地域指定の陳情（1935）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第7号』（第十七回委員会1935〔昭和10〕年3月26日開会ほかを収録）。NDL次世代デジタルライブラリー [book/1207608](https://lab.ndl.go.jp/dl/book/1207608)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **谷端川附近の工場集積の陳情〔確認・repo初出・要照合〕**: 地域指定関連議案（議第130号周辺）の審議で浅香銀治郎（28番）が「現在瀧野川區ノ工場地帶ト致シマシテハ…其ノ外ノ**豐島區ニ接近シタ方ノ谷端川ニ接近シタアノ方面一帶ガ從來カラ非常ニ工場ガ發展シテ居ル**ノデアリマシテ、アノ方面ニ付テノ御指定ガナイトイフコトハ**工場經營者達モ非常ニ不安ヲ感ジマス**所デ、此ノ點ニ付キマシテハ屢々當局ニ向ツテ指定方ヲ陳情シテ居ルト聞イテ居リマスガ、是非當局ニ於キマシテモ充分御調査ノ上工場地帶トシテ御指定セラレムコトヲ御願ヒスル次第デアリマス」と陳情。番外の当局側要約でも「**二十八番ノ淺香サンカラハ瀧野川區ノ谷端川ノ附近ヲ工業地域ニ變更シテ貰ヒタイト云フ御希望ガアリ**」と整理し、「現在デハ變更提案トイフ所迄立チ至ツテ居リマセヌ」と回答（再検討・協議会で話題には上っている旨の説明）。
- **位置づけ〔観察〕**: **1935年時点で谷端川の滝野川区側（豊島区境界接近地帯）に工場が集積し、工業地域（工場地帯）指定を求める運動が繰り返されていた**ことを示す委員会一次記録。谷端川下流部の市街化・工業化圧力の土地利用記録として、[GOV-200](GOV-200.md)（1932・瀧野川町下水道）・[GOV-180](GOV-180.md)の西巣鴨町下水道と並ぶ1930年代の谷端川両岸開発記録。指定が実現したか否かは本号では確認できず断定しない。
- **注意**: 本議論に現れるのは谷端川の**滝野川区側**で、豊島区内の谷端川（千川下流）そのものの土地利用ではない〔豊島区側の指定状況は本号では未確認〕。
