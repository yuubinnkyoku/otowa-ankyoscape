# [GOV-343] 南撰要類集[147] — 延享3年の雑司ヶ谷村・千駄ヶ谷村の町方支配化の実務記録〔第151回〕

- **書誌〔確認〕**: 『南撰要類集 [147]』（拝借地之部、町屋敷之部・NDL次世代デジタルライブラリー [book/2550556](https://lab.ndl.go.jp/dl/book/2550556)）。享保撰要類集・類柑子撰要系に連なる幕府の行政記録類集で、本冊には**享和2戌年（1802）に町方（町奉行所）で再調整された延享3寅年（1746）の伺書写帳の書留**が収録される。**引用文言はすべてOCR由来で要原文照合**。
- **延享3年・雑司ヶ谷村の町方御支配化の伺文言〔確認・repo初出の実務レベル記録〕**: 「**延享三寅年 雑司を谷村 千駄ヶ谷村之町方御支配ニ罷成候節之絵図宜之儀 書留相調申上候書付**」（享和2戌年八月・奈良屋市右衛門ら）＋伺書写帳の文言——「**延享三寅年八月 自証院順（領） 雑司に谷村之儀 商売売相兼 但百姓町家ハ以来町方御支配二罷成 耕作一通之百姓之分ハ町方御支配ニハ不相成候旨 寺社御奉行方ニ而被仰渡候段 右雑司谷村名主ゟ私共方え届出**」＝**①延享3年（1746）に自証院領雑司ヶ谷村について、商売を兼業する百姓町屋（町家）は以後町方（町奉行）支配となり、耕作一通の百姓は町方支配に移らない旨が寺社奉行方から仰渡され、雑司谷村名主から届け出があった、という伺書写帳の文言**。〔**「雑式谷村」への町奉行支配化＝[GAZ-075](../gazetteers/GAZ-075.md)（高田雑司ヶ谷町方書上写の「延享三寅年中…町御奉行能勢肥後守様…右雑司谷村之内往還附百姓町屋之分 町方御支配被御付候」）・[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考巻52・延享3年町奉行化）の背後の、寺社奉行→町奉行の管轄移管の実務文言（文言候補）**。町方化の対象が「往還附百姓町屋」（GAZ-075）＝「商売相兼候百姓町屋」（本冊）で一致し、**町方化が全村ではなく商業兼業の町屋層に限定的であったことの実務記録**。仰渡の奉行が能勢肥後守（能勢頼寛＝町奉行）である点もGAZ-075と対応（OCR崩れのため原画像照合が前提）。〕
- **千駄ヶ谷村（吉祥寺領・西福寺領・霊山寺領）の同時の町方化〔確認・repo初出〕**: 「**同年同月 千駄ヶ谷村 吉祥寺領 西福寺領 霊山寺領 右三段（領）豊世（世）ニ而商仕候百姓町屋 葭簀張（葭簗張）仕 茶水商仕候百姓町屋 耕作一通之分共ニ以来町方御支配二罷成候旨 寺社御（歩）行方ニ而被仰渡候段**」＝**千駄ヶ谷村の吉祥寺領・西福寺領・霊山寺領の3領についても同月（延享3年8月）に、商いをする百姓町屋・葭簀張（葭簀張りの茶屋か）・茶水商の百姓町屋が町方支配に移る旨の仰渡があった記録**。〔**雑司ヶ谷村の町方化が千駄ヶ谷村の3寺領の町屋と同時・同形式の施策であったことの記録**＝雑司ヶ谷鬼子母神門前の門前町化（[GAZ-013]鬼子母神門前条の天正6年門前百姓→宝永7年家作願→延享2年町御支配）と千駄ヶ谷の茶屋・水茶屋の町屋の府内町並化が一連の延享期の寺社領町屋政策であった観察資料。「葭簀張」の語は仮小屋の茶屋の実態を示す文言候補。〕
- **伺書写帳の経緯（延享3年11月の差出と絵図面の所在）〔確認・文言候補〕**: 「**私共方ゟ差上申候伺書写帳壱冊 右写之内 寺社御奉行方え附札致し来候文言二 絵図宜之儀有之候処 右絵図写 御役所ニ無御座候間 写仕差上可申旨被仰渡**」＋「**延享三寅年十一月 能勢肥後守殿 町方御勤役之節 右同書差上申候得共 寺社御番行方ゟ来り候絵図面ハ写留無御座 相知不申候**」＝**延享3年11月に能勢肥後守（町奉行）の勤役時に伺書写帳が差し出された一方、寺社奉行方から回ってきたはずの絵図面の写が享和2年時点で所在不明であることの記録**。〔**延享3年の町方化の際の雑司ヶ谷村・千駄ヶ谷村の絵図面（町並の絵図）の存在と紛失の記録**＝[GAZ-012](../gazetteers/GAZ-012.md)系の嘉永期の沿革図書の絵図の先駆けにあたる延享期の村絵図の存在示唆（所在は不明・原画像照合が前提）。行政文書の引継ぎの実務（附札・絵図の写の有無）の記録としても類例が少ない。〕
