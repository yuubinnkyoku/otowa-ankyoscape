# [GOV-447] 豊多摩郡淀橋町現状調査 — 神田上水流域低地規定と町域の成立文言

- **書誌〔確認〕**: 『豊多摩郡淀橋町現状調査』（東京市臨時市域**擴張部**編・[book/1900476](https://lab.ndl.go.jp/dl/book/1900476)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**淀橋町（1932年淀橋区→新宿区・西新宿〜東京都庁方面）冊**。
- **地勢章の神田上水流域の規定〔文言候補〕**: 「**（地勢概要）淀橋町ハ〓シ（概シ）平坦ナル台地ニシテ一ノ髙阜ナシト雖モ、殊（ニ坪?）ニ神田上水ノ流域ハ一帶ノ低地ナルヲ以テ成子坂角筈ノ両村ヲ併合シタルモノニシテ**」＋「**附近ヲ古クヨリ淀〓（橋?）町ト唱ヘテ柏木村ノ小名トナリ居タリ**」＝**①淀橋町＝成子坂村・角筈村の併合で成立した既存知見を1931年行政調査の沿革章で確認、②淀橋の地名が古くから柏木村の小名であったことの文言候補、③地形は平坦な台地だが**神田上水の流域だけが一帯の低地**であることの地勢規定**〔**神田上水（＝神田川の角筈・西新宿区間）の低地性を行政調査文体で明記した文言としてrepo初出級**・[GOV-446](GOV-446.md)（戸塚町・沿岸卑湿）と同じシリーズ内の並行文言で、神田上水の流路の谷性の1931年側の定点〕。
- **下水道の取扱い〔陰性記録・目次レベル〕**: 本冊の項目見出しに「**下水道事業**」の目次語が現れるが、概要本文中に下水道の具体的な施設・計画の文言は走査限りで見えない（検証済み: 「下水道」の出現は目次・見出し群と「都市的施設ノ未ダ残サレタルモノ尠シトセズ下水道事業ノ來（来?）ニ於テモ現在以上ノ増加ハ豫想スル能ハズ」＝人口飽和・下水道未整備ゆえの増加抑制という文脈の言及のみ）＝**1931年時点で淀橋町の下水道事業が具体化していなかった（ことを示唆する否定的な言及を含む）記録**〔[GOV-446](GOV-446.md)（戸塚町・未具体化）と同系列の定点。「拳グベキモノナシ」の文言は済生会東京府淀橋診療所の文言であって下水道の文言ではない（第218回の掃引で見分けた）注意書き〕。
- **人口飽和の文言〔確認〕**: 「**本町ノ人口ハ大正九年ノ國〓調查ヨリ昭和五年ノ國〓調查（ニ）大久保町ト共ニ既ニ飽和狀態ニ達シ十ヶ年间ニ四割ノ増加**」＝淀橋町（新宿駅周辺）の人口が大正9〜昭和5年に飽和状態に達した人口統計文言（数字はOCR崩れ・要照合）。および方面委員・社会事業・上水道事業の現況等の帳簿文言（「大正十三年上水道事業」の起業文言等）もあり＝1932年市域拡張直前の淀橋町政の帳簿。
