# [GOV-410] 御府内場末往還其外沿革圖書 拾七下（嘉永元1848調）— 笄橋川筋と新堀川の文言群

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』**拾七（三冊のうち「下」）**、冊子頭文言「**五八ノ十六 嘉永元申年六月調 御府内場末往還其外沿革圖書 拾七三冊之内下 麻布土中下渋谷村青山上下豊沢村一円之絵圖壱枚三枚之内下**」＝**嘉永元年（1848）6月調の麻布・下渋谷村・青山・上豊沢村一円の屋敷替地・地所の沿革調書**（同シリーズの[GOV-364](GOV-364.md)貮拾貞・[GOV-371](GOV-371.md)貮拾壱貞・[GOV-372](GOV-372.md)貮拾壱元下等と同じ帳簿形式。目録文言に「渋谷御掃除町 麻布桜田町 笄橋西手小屋敷辺之部」「渋谷広尾町 下渋谷村 牧野備前守下屋敷…」等の条名）。NDL次世代デジタルライブラリー [book/2587239](https://lab.ndl.go.jp/dl/book/2587239)。**引用はすべてOCR由来で文言は原文画像との照合を要する。**
- **「笄橋川筋」の境界文言＝1848年の川筋・橋名witness〔文言候補・笄川の調書レベル初出〕**: ①「**西之方笄橋川筋限 南之方麻布桜田町脇 笄橋通道敷限 北之方阿部城一郎(誠一郎?)下屋敷…**」（麻布之内東之方・麻布桜田町〜龍土材木町・松平石見守屋敷前の条）②「**上渋谷村之内上豊沢村 東之方伊達遠江守屋敷并青山原宿村間之道敷 笄橋川筋限 西之方青山大膳亮下屋敷内限 南之方青山原宿村之内限 北之方青山大膳亮下屋敷脇…**」（青山上渋谷村上豊沢の条）③「**東南之方笄橋川筋 百人組大縄地後ゟ 青山護之助屋敷 内藤紀伊守抱屋敷 松平左京大夫屋敷…**」ほか計4箇所以上で「**笄橋川筋**」が地所の四至（境界）に用いられる＝**嘉永元年（1848）時点で「笄橋」と「笄橋川筋」が、麻布桜田町（麻布側）と青山原宿村・上渋谷村上豊沢（渋谷川低地側）の境界基準として幕府の調書に実用されている**＝**笄川＝龍川系（[BOOK-209](../books/BOOK-209.md)紫の一本笄橋条・[GOV-136](GOV-136.md)現代の笄川＝下水道幹線化文言）における、1848年の幕府調書レベルの川筋・橋名の一次記録候補（repo初出）**。目録文言の「笄橋西手小屋敷辺之部」＝笄橋の西手の小屋敷という条名レベルの用例も併せて初出（川筋の流路復元（桜田町〜原宿村・上豊沢村を結ぶ線上）と「笄橋通道敷」の道の比定は地図対校を要し、本文言では断定しない。OCRの「城一郎/誠一郎」の原字確認も必要）。
- **渋谷川下流の「川筋惣体川幅堀廣」＝元禄十二卯年頃と新堀川・橋四ヶ所〔文言候補・repo初出の開削記録〕**: 「**同十二卯年頃 西南之方川筋惣体川幅堀廣 西之方当時渋谷川 南之方同新堀川 小成(?) 其頃ゟ南之方新堀端に下渋谷村百姓地弐ヶ所有之 当時右川筋ニ橋四ケ所 四ヶ所之内大板橋・庚申橋之外弐ヶ所は当時作場同様二有之有之候得共 川幅堀廣之節ゟ懸渡有之候哉年月其外不詳**」＝**①元禄12卯年（1699）頃に「川筋惣体」を「川幅堀廣」（堀下げ・川幅拡幅）した、②西側が当時の渋谷川・南側が「新堀川」、③当時の川筋に橋4ヶ所（大板橋・庚申橋の他2ヶ所は作場のまま）、④堀広の節に懸け渡したか否か・年月不詳**＝**渋谷川下流（下渋谷村一帯）の江戸期の川幅拡幅・新堀（新堀川）の開削の実務記録候補**＝笄川=新堀系説（[BLOG-185](../blogs/BLOG-185.md)笄川=龍川の人工新堀説・[GOV-136](GOV-136.md)笄川の暗渠下水道化）と、宇田川・渋谷川下流の灘烙の対校に供する一次 datapoint（「新堀川」が笄橋川筋と同一水路かその分流かは本文言では断定しない。「小成」の判読・「作場」の語義（材木置場か）も要照合）。
- **下渋谷村・麻布村の百姓池〔文言候補〕**: 「**下渋谷村麻布村入会百姓地并南手下渋谷村百姓池三ヶ所共地続 同所渋谷川端 下渋谷村百姓地…**」「**…麻布村百姓地下濱谷村百姓池四ヶ所共地続 南手渋谷川端…**」＝下渋谷村・麻布村入会の百姓池3ヶ所・4ヶ所の存在と渋谷川端への地続き＝**下渋谷の池の嘉永期の一次記録候補**（池の比定は未実施。往還・屋敷替地の年代層〔延宝年中→天和3→元禄12→享保4等の書上定型〕は[GOV-364](GOV-364.md)系と同型）。
- **陰性〔確認〕**: 本冊fulltextで「谷端」0件・「千川」0件・「水窪」0件・「弦巻」0件・「上水」0件＝対象4河川の川名は本冊に見えない。本冊の価値は笄橋川筋・新堀川・百姓池の文言に集約される（渋谷川下流・笄川系の対校資料）。
