# [GOV-399] 市中取締書留[196]文久 — 淀橋水車の文久〜元治期の家業相続願と井之頭池水門下二百間の文言〔第166回〕

- **書誌〔確認〕**: 『市中取締書留』[196]（文久期の書留冊・NDL次世代デジタルライブラリー [book/2572431](https://lab.ndl.go.jp/dl/book/2572431)。「子十月」「子十一月」の干支つき文言を含み文久4＝元治元年甲子（1864）の記録が最深と読める（改元前後の書留・年次の最終確定は要照合））。**引用文言はすべてOCR由来で要原文照合。**
- **文久〜元治期の淀橋水車家業相続願〔確認・核心・repo初出〕**: 「**柏木淀橋町家持久兵衛水車様相談之儀取調申上候書付**」で「**右は神田上水西水堀筋ゟ分水引受、往来淀橋町二而水車稼渡世仕来候處、近来病身二相成家業向出来兼候之間、従弟吉太郎江相談為仕前同様渡世仕度旨預出候**」＋「**水車是迄之通為水料米毎年四斗俵弐拾俵水に御張紙直段を以上納幷水元井之頭池罷成下弐百間之場所自分入用を以埋仮其外共顔之通可申渡旨存候**」＝**①柏木淀橋町家持久兵衛は神田上水の〔西/成〕水堀筋からの分水引受（OCRで「西水堀」「成水堀」の2変種・原字形は要照合）で従来淀橋町で水車稼の渡世をしてきたが、近来病身となり家業ができないため従弟吉太郎に相続させ前同様の渡世をしたい旨の願い、②水料は米毎年四斗（二十俵）・御張紙直段の上納、③水元井之頭池の水門下二百間の場所を自分入用で埋め渡す等の条件**という家業相続の掛合・取調〔**①[GOV-390](GOV-390.md)（享保撰要類集・延享3裁定）の享保4年（1719）家業セット「井之頭池水門底板幷橋一ケ所・同野方白堀之内長弐百間・玉川通堰料米弐拾俵宛」の幕末（文久〜元治）までの継続を示す文言候補、②とりわけ「水元井之頭池水門下弐百間之場所自分入用を以埋渡」はGOV-390の「野方白堀之内長弐百間」と同じ二百間の負担区間を井之頭池水門の下に置く文言＝**「野方白堀弐百間≒井之頭池水門下二百間」の同定を強める対校案件**（GOV-390の制限①の前進・ただし両文言の「弐百間」の同じ区間への当てはめの確定は原文照合まで断定しない）、③水料米二十俵はGOV-390の「玉川通堰料米弐拾俵宛」と同値で通時的に整合**〔相続人の吉太郎は中野村百姓甚右衛門（甚左衛門のOCR変種併存）の子で九歳・実父甚右衛門が後見人（「吉太郎儀未タ幼年二付実父中野村百姓甚右衛門後見相勤候」）。伺人・奉行: 松平石見守・池田播磨守・御作事奉行経由の町奉行衆との往復〕。
- **安政元寅年（1854）炮薬舂立出火後の米穀以外舂立禁止の一札〔確認・核心・repo初出〕**: 「**然知右久兵衛義安政元寅年右水車ニ而炮薬舂立及出火、其砌向後米穀之外三百立致間敷旨町役人共江一札取置候間、此度久兵衛跡吉太郎江相談…被仰付候ハゝ是迄之通米穀之外舂立致間敷旨一札書改吉太郎甚右衛門ゟ町役人共方江取置候積**」＝**久兵衛は安政元寅年（1854）に水車で炮薬を舂いて出火を起こし、その後米穀以外は舂き立てない旨の一札を町役人衆に取置かれており、今回の吉太郎への相続でも同内容の一札を吉太郎・甚右衛門宛に書き改めて取き置く**という文言〔**[GOV-396](GOV-396.md)（市街編44・嘉永7年6月12日の爆発事故）の後日談の一次文言＝同一事故（嘉永7＝安政元年）の奉行所実務側の記録**〔「三百立」は「舂立」のOCR崩れ候補〕。
- **久兵衛の資産の書上〔確認・参考〕**: 「**右久兵衛儀町内間口拾壱間裏行弐拾五間御着金三百両之山家屋敷壱ヶ所大地境柏木村之内弐拾石之同地所持仕家内之儀は其身并召仕男女弐拾人相応相暮**」＝**間口11間・裏行25間の家屋敷（御着金300両）・柏木村之内20石の地所・身内と召使い男女20人**という資産書上〔淀橋水車家の幕末の規模の定量的記録（「御着金三百両之山」のOCR崩れは要照合）〕。
- **（補足併記）元文5年（1735）の両国橋東広小路の拝借地証文の「淀橋水車弥兵衛印付」〔確認・文言候補・別冊〕**: 『諸証文言上帳』（享保〜宝暦4の証文集・NDL次世代デジタルライブラリー [book/2542025](https://lab.ndl.go.jp/dl/book/2542025)）に、元文5申7月8日・本所回向院〔田向院＝回向院のOCR候補〕境内の信州善光寺開帳に伴う両国橋東広小路脇の御茶弘め所（茶店）の御拝借地所の証文に「**仍而如件元文五年申七月八日淀橋水車弥兵衛印付ケれ右預地所間数相改候処条引之通に御座候右之通相渡申候**」＝**拝借地所の間数相改・相渡の証文に淀橋水車弥兵衛の印形が付されていた**文言〔**弥兵衛（[GOV-395](GOV-395.md)の文政町方書上の「先祖彌兵衞」）の1735年の実務定点**＝弥兵衛系譜（寛文年中願の回顧→元文5印形→文久期の久兵衛家）の通時系列の接続資料。広小路の茶店営業と水車家の関係（出店・保証人か）は文言上断定しない〕。

## 制限・未解決

- ①「西水堀／成水堀」の原字形（「惣水堀」等の候補も含む）は要照合。②「水元井之頭池罷成下弐百間」の「罷成下」は「水門下」のOCR崩れ候補で原画像照合必須（GOV-390の「野方白堀之内長弐百間」との同定の可否はそこにかかる）。③子十月〜子一月の年（文久4＝元治元年甲子〔1864〕候補）の確定・「300立→舂立」の確定は要照合。④久兵衛と吉太郎の続柄（従弟・中野村百姓甚右衛門の子）の実数の血縁関係は文言上の「従弟」に依る。⑤254025の証文の「弥兵衛印付ケれ」の読み（印付＝印形を付した者・宛先か）は要照合。
