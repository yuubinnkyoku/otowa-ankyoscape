# [GOV-229] 大東京町名沿革 巻2（1934）— 千川屋敷・音羽町の町名沿革の府編系統の文言

- **書誌〔確認〕**: 東京府編『**大東京町名沿革**』巻2（昭和9年・1934年）。NDL次世代デジタルライブラリー [book/1212511](https://lab.ndl.go.jp/dl/book/1212511)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **千川屋敷条＝元禄9年太兵衞・德兵衞文言の1934年府編系統〔確認〕**: 小石川区の町名沿革の箇所に——「**明治五年白山前町ノ內千川屋敷及圓乘寺門前、蓮華寺門前、淨雲寺門前、正福院門前ヲ併セテ今ノ稱ニ改メ、五年八月又仲町廣小路、白山御殿大通、小十人町ノ士地ヲ加フ。千川屋敷ハ元祿九年多摩郡仙川村ノ民太兵衞、德兵衞命ヲ受ケテ千川上水ヲ通ジ村名ヲ姓トシ宅地ヲ給セラレシモノナリ**」〔**①白山前町の内の千川屋敷が（圓乘寺・蓮華寺・淨雲寺・正福院の門前と共に）併せて「今の称に改め」られたこと（**明治五年**と記す）、②**千川屋敷＝元禄9年、多摩郡仙川村の民太兵衞・徳兵衞が命を受けて千川上水を通じ、村名を姓とし宅地を給せられたもの**との由緒文言**＝[GOV-208](GOV-208.md)（東京市町名沿革史・1938）の「明治2年5月…指ヶ谷町へ併合」「千川屋敷は元禄九年…」文言の**4年先行の東京府編系統のテキスト**（同一由緒の再録と見られるが、**併合年が「明治五年」vs「明治2年5月」で対立**＝OCRの頁・項目境界の問題も含み、原文照合で確認するまで確定しない。両書の併合年表現は明治2年町名改正と明治5年大区小区制の両段階を指す可能性がある）〕〔太兵衞・徳兵衞の由緒文言は[GOV-210](GOV-210.md)〜[GOV-212](GOV-212.md)の千川家文書・[GOV-227](GOV-227.md)（1899）と同一事件の官撰側の記述〕。
- **音羽町条＝「以前鼠ヶ谷ト稱セシト傳フ」〔確認・鼠ヶ谷の所在に向けた1934年の文言〕**: 音羽町一丁目条——「**音羽町九ケ町ハ昔時雜司ケ谷、小日向、關口、小石川諸村ノ內ニ係ル。元祿十年護國寺領ト爲リ此時市肆ヲ開キ後之ヲ德川氏ノ女官音羽ニ給ス。因テ此ノ稱アリ。以前鼠ヶ谷ト稱セシト傳フ**」〔**音羽町（九ヶ町）の地が「以前 鼠ヶ谷と称せしと伝ふ」＝鼠ヶ谷の地名の所在を音羽町側に置く1934年府編の文言**〕〔**[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考巻50・音羽町「以前鼠ケ谷と申字に而御座候由申伝候」）・[GAZ-035](../gazetteers/GAZ-035.md)（町方書上[149]の鼠ヶ谷稲荷・鼠ヶ谷下水）と同じ伝承の20世紀官撰側での採録。**[GOV-208](GOV-208.md)（1938）が千川屋敷（白山側）の旧称として鼠ヶ谷を扱っているかどうかの再照合課題と合わせ、鼠ヶ谷の本来の所在（音羽町側）が1934年府編でも音羽町条に置かれていることは、地名の位置論の重要な傍証**（鼠ヶ谷・千川屋敷・鼠谷村〔手代不知堂町条・小日向側〕の3者の関係の吟味資料）〕〔OCRの項目境界で音羽町条と千川屋敷条の親項目の割付は要照合〕。
