# [GOV-192] 常務委員会議事速記録 第8号（1938年）— 千川堤桜保存のための補助線道路第47号路線変更

- **書誌〔確認〕**: 都市計画東京地方委員会『常務委員会議事速記録 第8号』（昭和13年）。NDL次世代デジタルライブラリー [book/1207598](https://lab.ndl.go.jp/dl/book/1207598)。**すべての引用は同館OCRテキスト由来であり、文言・数値は原文画像との照合を要する。**
- **補助線道路第47号路線〔確認・repo初出〕**: 中野区江古田1丁目を起点とし板橋区板橋4丁目に至る幅員11mの補助線道路。豊島区千川2丁目→千川3丁目の約900m区間は「**千川用水ノ西側ニ沿ツテ居ル在來ノ道路ヲ利用スル計畫デアリマシタ**」が、「**千川堤ノ櫻並木ニ非常ニ接近シテ居リマス**」ため路線を西側（堤から離れる方向）へ移動する変更（昭和12年9月14日内務大臣決定）。延長約2,816m→約2,818m。〔文言・数値はOCR要照合〕。
- **理由書文言〔確認・repo初出〕**: 「本路線ハ**千川堤ノ櫻樹ヲ保存スルト共ニ屈曲ヲ緩和シ交通ノ圓滑ヲ圖ラム**カ爲其ノ位置ヲ本案ノ如ク變更セムトスルモノナリ」＝**千川堤の桜並木の保存が都市計画道路の位置決定の明示的な理由になった第一次記録**。質疑で山口久太郎委員「櫻ノ保護デスカ」等のやりとりあり。〔文言・人名はOCR要照合〕。
- **位置づけ〔観察〕**: 千川桜の1938年時点の所在区間＝豊島区千川2〜3丁目（要町〜板橋宿側）の西側堤と特定できる計画資料。[BLOG-101](../blogs/BLOG-101.md)（大正4年千川堤植桜楓碑）・[GOV-178](GOV-178.md)（1941年「櫻並木」文言）と連続する桜史の途中年の公文書。
