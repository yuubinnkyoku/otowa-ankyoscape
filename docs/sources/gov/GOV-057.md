# [GOV-057] かたりべ141号「90年前の高田町の三大事業」

- **書誌〔確認：公式目次ページ〕**：『かたりべ』141号、**2022年1月28日発行**。[公式サイトの号別目次](https://www.city.toshima.lg.jp/129/bunka/bunka/shiryokan/kankobutu/kataribe/kataribe140.html)で目次を確認（2026年11月10日）。所収記事「豊島をさぐる〈25〉90年前の高田町の三大事業／ビフォー＆アフター」。
- **記事の存在のみ確認**：**90年前＝2022年から数えて1932年**で、弦巻川の高田町による暗渠化工事（1932年）や区制施行（豊島区発足）と同じ年の高田町の「三大事業」を扱う可能性があるが、**本文は未閲覧**で三大事業の内容・弦巻川言及の有無は不明。
- **制限〔未解決〕**：PDF本文への直接アクセスは2026年11月10日時点で文字抽出不能（サイトの翻訳ガード）。高田町の昭和初期の土木・都市整備の事業史として、**弦巻川暗渠化の事業的背景を検証する最短の実見候補**。本文閲覧後に内容を判定するまで、三大事業と弦巻川暗渠化の関係を断定しない。
