# [GOV-298] 消防年鑑 昭和2年版（1927）— 谷端川の堰止の消防水利利用と大正15年雑司ヶ谷大火

- **書誌〔確認〕**: 『消防年鑑 昭和二年版』（三生社・1927）。次世代デジタルライブラリー [book/1465501](https://lab.ndl.go.jp/dl/book/1465501)。大正15年（1926）の火災・消防行政の年鑑。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **谷端川・矢田川の堰止施設〔確認・repo初出〕**: 府下消防組の設備拡充の列挙中に「**巢鴨町消防組 谷端川、矢田川ニ各一箇所ノ堰止施設ヲ構築シ貯水池代用トシタ**」＝**巣鴨町消防組が大正15年度に谷端川と矢田川（谷田川）に各1ヶ所の堰止施設を築き、貯水池の代用とした**という記録〔記事区分（設備拡充・記念事業のいずれの見出しか）はOCR列崩れのため要照合〕。要点:
  1. **谷端川の堰止の実在の裏付け**: [GOV-258](GOV-258.md)（府史・昭和2年說明書）の「防火ノ爲メ五六箇所ニ堰ノ設備アルモ…之ヲ撤去シテ流水ノ快疏ヲ圖ラムトス」（防火堰5〜6ヶ所・改修で撤去決定）という1927年府側記録に対し、**同年刊行の消防年鑑が消防組側の視点で「堰止施設を構築し貯水池代用」と記す**＝防火堰の撤去直前（1926年度）の時点で堰止が消防水利として積極利用されていたことの対側の一次記録。**堰の数（府史5〜6ヶ所・消防組側谷端川1ヶ所新設）と、既存堰か新設堰かの関係は本書のみでは確定できない**（断定しない）。
  2. **矢田川（谷田川）との併記**: 谷田川（駒込・田端方面から不忍池へ向かう別水系〔対照表の統一方針参照〕）にも1ヶ所＝北豊島郡域の小河川の堰止貯水池化が府下消防組の共通施策だったことの傍証。
- **大正15年3月19日雑司ヶ谷大火〔確認・repo初出の一次記録〕**: 「十五年ノ大火記」章に「**三月十九日午前二時二十分 東京府下北豐島郡西巢鴨町字向原三〇六九 鍍金職工川口孫七方ヨリ發火シ、折柄北西九米突ノ疾風ニ煽ラレ同向原ノ一部ヲ燒キ、更ニ高田町ニ延ビ同町字雜司ヶ谷旭出ノ大部、同水久保、水原ノ一部七百七戶ヲ全燒シ十三戶ノ半燒ヲ出シ七千六百十一坪、百九十二萬六千七百二十圓ヲ灰燼トナシ同五十五分鎮火ス、同火災ニテ防禦中ノ消防組員一名負傷シ罹災者二千二百二十八人ニ達ス、同地帶ハ通路狹隘且ツ消防水利皆無ノ狀態デ僅カニ遠隔ノ地ヨリ送水シ得タルニ過ギズ、爲メニ防禦作業ニ頗ル困難ヲ感ジ遂ニ大火ノ因ヲナシタノデアル**」＝
  1. **大火の概要**: 発火＝西巣鴨町字向原3069（鍍金職工川口孫七方）・午前2時20分・北西9mの疾風→高田町字雑司ヶ谷旭出の大部・**水久保**・**水原**の一部・**707戸全焼・13戸半焼・7,611坪・1,926,720円**・鎮火2時55分・罹災者2,228人。
  2. **水窪（水久保）方面の1926年時点の実況**: 「**通路狹隘且ツ消防水利皆無**」＝**大正15年時点の雑司ヶ谷北部（旭出・水久保・水原）が通路が狭く消防水利が皆無だった**ことの消防行政側の一次記録＝水窪川流域の市街地化（宅地化）が水利整備に先行して進んだ状態の記録。発火地の字「向原」は雑司ヶ谷村の19小名（[BOOK-144](../books/BOOK-144.md)）の一つで、雑司ヶ谷村の字地割が西巣鴨町・高田町の行政界をまたいで残っていたことの傍証〔字名の対応の断定は保留〕。
  3. **「水原」の字名**: 高田町字水久保と並ぶ「**水原**」の表記が見える＝「水窪」のOCR誤読・異表記・別字名のいずれかは原画像照合まで断定できない（[地名・河川名対照表](../../地名・河川名対照表.md)に対照行を追加）。
- **その他の水窪・弦巻関連の吟味〔確認・陰性〕**: 本書の「弦卷」「水窪」の他のhitは人名（消防組員の氏名）・静岡県の地名等のfalse positiveで、四河川に関する追加情報はない。
