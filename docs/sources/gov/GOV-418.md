# [GOV-418] 「千川上水記録フィルム」の通し目録（所蔵品アーカイブ・公開39コマ）

## 書誌・経緯

- 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブのフィルムカテゴリ（[index.cgi?c=3](https://www.neribun.or.jp/archive/index.cgi?c=3)）に公開される「**千川上水記録フィルム**」の全39コマを第195回（2026-11-19）に走査し、**所蔵番号（5000-0057-XXX）・各詳細頁のID・撮影地点の名称・画像公開の対応を確定**した〔第18回（GOV-073）で残していた「シリーズ全体の目録調査（隣接番号の確認）」の実施・解決〕。
- 全39コマで備考「カラー写真」、内容等に共通文言「暗渠化が練馬区内で本格化する直前の**昭和27(1952)年頃に撮影**された。玉川上水から取水する付近から**巣鴨付近**までの、練馬を中心とした千川上水沿いの風景の記録。」〔 [GOV-070](GOV-070.md)（練馬区公式・60コマ）との関係では、アーカイブ側はそのうち**39コマを公開**（欠番を含む対象は下表のとおり。未公開コマの存在可否は本走査では判断できない）〕。各コマの詳細頁（`detail.cgi?id=NNNNN`）にはこのほか個別の情景説明文言があり、画像も直接閲覧可能（`https://www.neribun.or.jp/archive/img/5000-0057-XXX_01.jpg` 形式）。

## 意義（観察）

1. **撮影地点の連鎖が千川上水の1952年地上流路と一致する**: 桜堤（武蔵野市）→新町（西東京市）→柳沢（西東京市）→関町南→上石神井→南田中→上鷺宮（中野区）→中村北→豊玉北→練馬→桜台→栄町→旭丘→南長崎（豊島区）→要町（豊島区）→大谷口（板橋区）→板橋→滝野川（北区）→西巣鴨（豊島区）＝**取水点から巣鴨付近までの現在町名で特定された連続定点群**として、repoの千川上水流路復元（[GOV-070](GOV-070.md)・暗渠化年次論）に対して1952年時点の水路の実存と位置を画像つきで裏付ける基礎資料になる〔個々のコマの情景から流路位置を割り出すには画像判読が前提。番号順と流下順は必ずしも一致しない（022が中村北1・021が中村北2等の逆転がある）〕。
2. **谷端川源流部（要町）・千川上水末端（西巣鴨）の1952年写真の存在**: 要町3丁目2コマは谷端川緑道の源流域（千川上水と谷端川の並走区間）の直近、西巣鴨2丁目は千川上水の流末（巣鴨付近）の写真で、**谷端川上流の1952年時点の観察材料**をアーカイブ側から特定できた〔千川上水からの分水と谷端川源流の関係の画像照合は未了〕。
3. **[GOV-071](GOV-071.md)（大谷口）のID特定**: 板橋区大谷口付近〔推定〕=5000-0057-040=詳細頁id=10057が確定し、第16回の当該コマの登録文言と一致した。
