# [GOV-249] 神田玉川上水留[32][33]（明治2年9月）— 白堀浚賃銀（渡賃銭）明治2年分取集上納帳の全貌

- **書誌〔確認〕**: 『神田玉川上水留』[32] [book/2587545](https://lab.ndl.go.jp/dl/book/2587545)・[33] [book/2587546](https://lab.ndl.go.jp/dl/book/2587546)（ともに明治二巳年九月冊）。NDL次世代デジタルライブラリー。明治2年（1869）9月の白堀浚賃銀（渡賃銭）の取集・上納の帳簿群（シリーズ[1]〜[33]の末尾の冊）。**引用文言はすべてOCR由来で要原文照合。**
- **上納触書〔確認〕**: 「**白堀浚賃銀**（渡賃銭）明治2年分の取集を触れる書付——明治2年9月4日付と読める文言・上納先「**民部省上水屋敷改**」」＝**白堀の渡賃銭（渡橋の通行料）を「白堀浚賃銀」として取集し、民部省の上水屋敷改（[GOV-237](GOV-237.md)の上水屋敷改と同系の明治政府の上水監督機関）に上納する制度の明治2年9月の一次文言**＝[GOV-237](GOV-237.md)（明治2年4月・9月の白堀埋増への浚費67両2分を水下町々の渡賃銭で支払）の**渡賃銭の収入側（取集・上納）の帳簿**として対応する記録（支出と収入の両面が揃った）。
- **番組別・町別・家主別の全リスト〔確認・repo初出の定量的記録〕**: 取集帳の本体が「**元壱番組**」〜「**三拾七番組**」の番組別・町別（**堀江町・伊勢町・堀留町・紺屋町・佐久間町**等）・家主別の銀銭高のリストとして読める＝**白堀の渡賃銭の負担者が神田・日本橋側の市中の町方（水下町々）の番組単位で組織され、家主ごとに銀銭を取集されていた実務の全リスト**（[GOV-237](GOV-237.md)の「水下町々の渡賃銭」の具体的な負担者側の構造）。「番組」は江戸期の町方行政の五人組替わり組合（神田・日本橋の町方の番組）で、**上流の白堀の浚渫費を下流の市中の番組が負担するという神田上水の費用負担構造の最後期（廃止直前・明治2年）の帳簿レベルの全貌**。
- **市中御改正と番組再編の伺い〔確認・制度の終末期の記録〕**: 「**市中御改正**」（町村合併・番組改正）に伴って白堀浚賃銀の番組の割付を再編する伺いの文言＝**明治2年の市中改正（東京の町村合併・番組の再編）が上水の渡賃銭制度の負担組織に直接影響し、帳簿の番組割付の変更を必要としたことの記録**（同年10月の神田上水廃止（大下水化・[BOOK-123](../books/BOOK-123.md)）の直前の制度運用の終末期の様子）。
