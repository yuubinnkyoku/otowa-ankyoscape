# [GOV-521] 豊島区「大塚台公園リニューアル工事における寄付募集について」〔ウォーターパーク遊具の調達構造（GCF）の行政一次記録〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: 豊島区公式サイト「取り組み > 大塚台公園リニューアル工事における寄付募集について」。**ページID 57442・更新日2026年11月11日**。 https://www.city.toshima.lg.jp/610/2607271842.html 。
- **GCFの仕組み〔確認: 本文〕**: 「大塚台公園（面積：3546.9平方メートル　住所：南大塚3-27-1）のリニューアル工事において、**寄付型クラウドファンディング（以後、GCF）を活用**いたします。GCFとは、自治体が抱える課題や事業の解決のため、**ふるさと納税の仕組みを活用して課題や事業に直接寄付できる仕組み**です」「**本寄附は区民の方も寄付金の控除と、公園へのお名前記銘などの特典の受け取りが可能**です」＝区民も対象の寄付方式。税制優遇＝個人（原則2,000円控除額差引・確定申告）・法人（寄附金額の全額損金算入）。納付書・スマホ払いの双方の窓口案内あり。
- **プロジェクト本文〔確認: 本文・文言〕**: 「**こどもたちの夏を変える！大塚台公園に"びしょ濡れで遊べる遊具"をつくりたい！**」「大塚台公園に新たなシンボルとして**「蒸気機関車をモチーフにしたウォーターパーク遊具」を整備します**」「**こちらの遊具は上にある大きなバケツが回転して大量の水が降ってくるほか、シャワートンネルや遊具のさまざまな所から水が噴き出し、子どもたちが思い切り水遊びを楽しめる、全身びしょ濡れになる遊具です**」「**水深は20cm程度と浅く、床面は滑りにくいゴムチップ舗装**」「**夏以外の季節は、複合遊具として一年を通じて楽しめます**」「単なる遊具ではなく、この公園ならではの新しいランドマークとなる施設です」。特徴3点＝真夏の暑さでも遊べる・一年を通じて遊べる・だれでも安心して遊べる（「最近の猛暑により、公園の遊具は熱くて遊べないという利用者の声が届いています」「**遊具の機能を最大限発揮できるとともに限られた公園の面積を有効に活用**」＝面積制約下の親水+遊具の複合設計思想）。
- **寄附金の取扱〔確認: 本文〕**: 「**皆様からご支援いただいた寄附は、大塚台公園リニューアル工事におけるウォーターパーク遊具の整備に活用**」「【目標金額に達しなかった場合】目標金額に達しなかった場合にも、ウォーターパーク遊具の整備費の一部として活用」「**目標金額以上の寄附を頂いた場合、本プロジェクト（全体工事費約6.8億円）へ活用**」＝**全体工事費およそ6.8億円の一次数値〔repo初出〕**〔目標金額の数値自体は本頁本文中に記載なし＝外部ポータル側確認待ち〕。
- **意義〔観察〕**: ①**親水遊具をGCF（ふるさと納税）で調達する構造**＝区政の公園親水施設の資金調達方式の新例（千川上水公園系＝[GOV-496](GOV-496.md)区制六十周年の整備と調達構造が異なる）。②「水深20cm・ゴムチップ・回転バケツ・シャワートンネル」という**安全・機能仕様の一次文言**＝設計実態の裏付けデータ。③猛暑で遊具が遊べないという利用実態の行政側認識が背景文言に明示されている。
- **制限・未解決**: 目標金額・募集期間・寄付実績は本頁に未記載（リンク先ポータル・開始予定は[GOV-520](GOV-520.md)系ではなく池袋タイムズが「2026年9月9日から」と報道〔[BLOG-290](../blogs/BLOG-290.md)〕・ポータル側の一次確認が次課題）。「寄附金受領証明書」等の実務文言は参考。
