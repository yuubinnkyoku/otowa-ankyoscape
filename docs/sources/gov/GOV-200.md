# [GOV-200] 都市計画東京地方委員会 議事速記録 第4号 — 瀧野川町下水道決定（1932）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第4号』（第八回委員会1932〔昭和7〕年3月31日開会・第九回委員会同年9月20日開会・第十回委員会同年12月21日開会を収録・820頁）。NDL次世代デジタルライブラリー [book/1212950](https://lab.ndl.go.jp/dl/book/1212950)。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **議第76号「東京都市計画瀧野川町下水道決定ノ件」（内務省東都第71号）〔確認・repo初出〕**: 1932〔昭和7〕年9月16日内務大臣山本達雄発議・**第九回委員会（1932-09-20）で原案通り決定**（会長潮恵之輔・説明事務官西村輝一）→同年9月29日内閣認可→**10月4日内務省告示第242号**。**決定段階の告示全文を速記録内に収める**。
- **決定内容〔確認・要照合〕**: ①下水排除区域＝瀧野川町内の鉄道その他官庁用地の大部を除く**総面積約450.76ヘクタール**（全町502ha・昭和5年国勢調査人口約10万）。②下水排除方法＝**合流法**・自然流下で「**其ノ大部ハ谷端川、谷田川竝王子町、尾久町及日暮里町下水道ニ合流シ一部ハ石神井川ニ放流ス**」。③下水排除量＝計画人口約11万6千人・1人当たり1日平均167リットル・1時間最大降雨量50ミリで算出。④「**下水管渠ノ構造ハ總テ暗渠トシ**」排水量の多寡に応じ陶管・鉄筋コンクリート管。⑤4排水区＝**石神井川排水区**（大字瀧野川・上中里の大部及大字西ケ原の一部・約201.52ha・延長約41,196m）／**谷田川排水区**（大字中里・田端の大部及大字西ケ原の一部・約132.90ha・約21,575m）／**田端排水区**（昭和町1〜3丁目・田端新町1〜3丁目の全部及大字田端・上中里・中里の一部・約96.44ha・約22,845m）／**谷端川排水区（大字瀧野川ノ一部・約19.90ha・延長約4,291m）**。⑥下水道総延長約89,907m・経費約300万円。⑦**昭和7年度から16年度までの十箇年継続事業**とし、本来の執行者は瀧野川町長だが、**市域拡張（1932年10月の東京市併合）実現後は東京市長の執行**に切り替える旨の説明。
- **理由書〔確認・要照合〕**: 瀧野川町の人口は大正9年〜昭和5年の10年間に**2.47倍**に増加、既存の下水溝は「其ノ構造〓ネ露渠ニシテ幅員、水深、勾配等総テ適當ナラズ」「汚水、汚泥ハ忽チ氾濫シテ周圍ノ道路、住宅地ヲ汚瀆スルヲ常トス**其ノ氾濫區域面積約三十萬坪**」＝**1932年時点の瀧野川町（谷端川北岸・谷田川流域）が露渠下水の氾濫地域であった**ことの理由書。
- **位置づけ〔観察〕**: [BOOK-112](../books/BOOK-112.md)（1933・滝野川町誌の計画紹介）・[GOV-166](GOV-166.md)（1937・年報）の前身に当たる**都市計画決定段階の一次記録**。[GOV-180](GOV-180.md)の西巣鴨町下水道決定（1932年1月）と同年で、**谷端川を受容水域とする郊外下水道計画が谷端川の両側（西巣鴨＝南岸・瀧野川＝北岸）で同年に告示された**ことを示す。谷端川排水区が「大字瀧野川ノ一部」19.90haを含む＝**1932年時点の公式区割りで谷端川流域が滝野川町地内にも及んだ**ことを示す〔該当地域の特定は図面表示のみで本文では不可・要図面照合〕。
- **注意〔GOV-166との食い違い〕**: [GOV-166](GOV-166.md)（1937・下水道事業年報）の滝野川町の4排水区表記は「石神井川・谷端川・**音羽**・谷田川」だが、本告示の4区は「石神井川・谷田川・**田端**・谷端川」で**音羽を含まず田端を含む**。年報側の混同（西巣鴨町の4区＝[GOV-180](GOV-180.md)と同一構成）か計画変更かは本段階では確定しない〔要照合〕。
