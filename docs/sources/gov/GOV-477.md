# [GOV-477] 東京市郊外下水道計画（白翁1949・水道協会雑誌＋2008年口語訳版）— 所在のみ

- **書誌①〔確認〕**: 白翁（「古稀中白翁」名義）「**東京市郊外下水道計画**」『水道協会雑誌』179号（日本水道協会・1949・p.34〜35・NDLサーチ [R000000004-I5165370](https://ndlsearch.ndl.go.jp/books/R000000004-I5165370)・国立国会図書館蔵）〔所在のみ・本文未見〕。**書誌検索上は図書ではなく雑誌記事**（2頁）。なお東京都立中央図書館にも同定題名の明治期雑誌目録系record（R100000146・「東京市郊外下水道計画、東京市下水道基本計画 179」1949）が見えるが、同一物かどうかは書誌IDが異なるため要確認〔確認＝record存在のみ〕。
- **書誌②〔確認〕**: 『東京市郊外下水道計画』（東京都下水道サービス株式会社・2008年7月・206p ; 31cm・NDL書誌 [000009629864 / R100000002-I000009629864](https://ndlsearch.ndl.go.jp/books/R100000002-I000009629864)・別書誌 [BA87421227 / R100000136-I1970586434915310770](https://ndlsearch.ndl.go.jp/books/R100000136-I1970586434915310770)）〔所在のみ・本文未見〕。内容注記: 「**郊外下水道決定ニ至ル迄ノ経過」の口語訳版**」「原本の口語訳に加えて、**各町村誌の下水道計画を収集**し、かつ新旧比較できるよう**現行の設計基準をも合わせて掲載**したもの」「**折り込図（地図）2枚**」〔書誌注記確認〕。
- **原本の存在〔書誌注記由来・観察〕**: 上記内容注記により、**東京市刊の「郊外下水道決定ニ至ル迄ノ経過」という原本（冊子）の存在**が裏付けられる。刊年不詳・所在は未確認（2008年口語訳版の本文で原本の刊年・形態が明らかになる可能性がある）。
- **位置づけ〔観察・本文未見〕**: 郊外下水道＝**市域外（後の東京市に編入される各町村）も含む下水道計画**の系列で、[GOV-145](GOV-145.md)（1942・滝野川町郊外下水道計画年度割文言）の研究・計画上の前後関係に位置する系統の資料。**滝野川・西巣鴨・豊島・渋谷・代々幡など旧町村（＝谷端川・水窪川・弦巻川・千川上水の流域町村）ごとの下水道計画（町村誌収録）が含まれる可能性**が内容注記から推定されるが、**収録町村の範囲・千川・谷端川流域の文言の有無は本文未見のため一切未確定**。
- **折り込み図〔書誌確認・本文未見〕**: 地図2枚の内容不詳。「郊外下水道」の処分区域・管網図である可能性があるが断定しない。
