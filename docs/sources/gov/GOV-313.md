# [GOV-313] 東京警視本署布達全書（明治11年分）— 神田玉川両上水源取締仮規則の全文5か条

- **書誌〔確認〕**: 『**東京警視本署布達全書**』（**明治11年分**。NDL次世代デジタルライブラリー [book/791198](https://lab.ndl.go.jp/dl/book/791198)）。明治11年（1878）の警視本署布達を編年収録。**引用文言はOCR由来で原画像照合を要する**。

## ①甲第57号（明治11年10月29日）: 取締假規則の全文〔確認文言・repo初出の全文〕

- 本文〔確認文言〕: 「**十月二十九日甲第五拾七號 神田玉川兩上水源取締假規則 左之通相定來ル 十二月一日ヨリ施行候條此旨布達候事
第一條 魚鳥ヲ捕リ及ヒ游泳シ又ハ諸物品ヲ洗フベカララズ
第二條 塵芥瓦礫其他汚穢物ヲ投棄スベカラズ
第三條 上水ニ沿フタル各地面ヨリ汚水混入セサル樣注意スベシ
第四條 堤上ノ竹木及ヒ下草等猥ニ伐採スベカラズ
第五條 前條ノ塲合ハ勿論其他上水ニ屬スル堤防等破損ノ塲所アラハ巡行ノ巡查又ハ最寄警視分署ヘ告知ル樣**」
- **構成**: 5か条＝**①魚鳥の捕獲・游泳・諸物品の洗浄禁止②塵芥・瓦礫・汚穢物の投棄禁止③上水沿面の各地面からの汚水混入への注意（義務規定）④堤上の竹木・下草の濫伐採禁止⑤堤防等破損箇所の巡行巡查・最寄分署への告知**。
- **意義**: ①**神田上水・玉川上水の水源・水質保全の最初期の警察規則の全文**が確認できた（石垣・水番人等の既存の施設運用〔[GOV-309](GOV-309.md)等〕に対する、一般行為への禁止規定の整備）。②施行日は**明治11年12月1日**。③第3条は「注意スベシ」（注意義務）で、後の禁例化（明治12年2月26日・[GOV-312](GOV-312.md)）の際に第3条・第4条が改正され第5条が刪除された＝仮規則から禁例への条文変化の基準テキスト。④[GOV-311](GOV-311.md)（明治14年・千川水道取締禁例）の5か条（魚鳥・游泳・洗浄／投棄／汗水混入／伐採／車・牛馬牽入）と**①〜④の文言がほぼ対応**し、千川禁例の前史的意義がある（千川禁例第5条の車・牛馬牽入禁止は本規則にはなく、千川水道の施設事情に応じた拡張）。
- **日付の対立〔要照合〕**: [GOV-314](GOV-314.md)（明治11年坤・警視局藏版）の番外第125号が「**十月十七日**」で甲第57号に基づく運用細目を達している。本条の布達日「十月二十九日」との前後関係は、①いずれかのOCR判読差、②布達日と転達日の差の可能性があり、原画像照合まで確定しない。
