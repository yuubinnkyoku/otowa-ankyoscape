# [GOV-124] 東京都建設局『荒川水系神田川流域河川整備計画』（令和5年3月）

- **書誌〔確認: 杉並区サイトのPDFミラーを直接取得・本文抽出〕**: 東京都建設局『**荒川水系神田川流域河川整備計画**』（**令和5年3月**、本文59頁）。[杉並区ミラー](https://www.city.suginami.tokyo.jp/documents/1578/kandagawakasenseibikeikaku.pdf)で全文PDFを取得し、テキスト抽出で確認〔repo初出。都建設局本来の掲載場所は今回未特定〕。
- **千川上水経由の善福寺川導水〔確認: 図2-13「神田川の平常時の水量」〕**: 清流復活事業により、多摩川上水再生センターの高度処理水を**玉川上水を通じて神田川に 0.13m³/s、千川上水を通じて善福寺川に 0.1m³/s** 導水していると明記。出典注記「玉川・千川上水導水量：H2～H7の多摩川上水再生センターからの日平均送水量を計画配分により分配」〔〔観察〕[BLOG-090](../blogs/BLOG-090.md)（本田創2011）「1日1万トンのうち7000トンは青梅街道交差点のすぐ先で善福寺川へ導水」・[BLOG-094](../blogs/BLOG-094.md)（sirakigi）「善福寺池へ1日7000トン（千川流水の約3分の2）」の 0.081m³/s 相当の個人観察と、都建設局計画数値 0.1m³/s が同水準で整合。両者の対応関係は明示されないため推定として扱う〕。
- **神田川流域の湧水表〔確認: 表2-4〕**: 表2-4に流域の湧水を集約（出典: 『東京の湧水』H12年度調査報告書・『東京の名湧水57選』H15・『湧水マップ』H25、いずれも東京都環境局。※印の湧水量はH3年度調査結果）。
  - **文京区音羽1丁目の湧水3件の定量値**〔確認〕: **今宮神社（音羽1丁目4番）5.2m³/日※・民家（音羽1丁目）5.8m³/日※・民家（音羽1丁目）1.1m³/日※**〔水窪川流域・音羽谷の湧水量の数値を都の河川整備計画レベルで確認したのはrepo初出。河川名欄は「神田川」〕。
  - **小日向の湧水**〔確認〕: 民家（小日向2丁目）0.2m³/日※・養徳学舎（小日向4丁目3番3号）1.0m³/日※〔小日向谷の湧水定量値〕。藤寺伝明寺（小日向4丁目3番11号）は名称のみ掲載。
  - **「H25調査時は確認されていない」湧水**〔確認〕: **江戸川公園（関口2丁目1番）・豊島区民家（高田1丁目）・区立高南小学校（高田2丁目12番7号）**〔〔観察〕高田1・2丁目は弦巻川・水窪川系の谷頭〜谷筋にあたり、H25（2013）時点で湧水が確認されなかった枯渇記録として読める。計画書の欄上では「神田川」扱い〕。関口芭蕉庵（関口2丁目11番）・新江戸川公園（目白台1丁目1番22号、「現在『肥後細川庭園』に名称変更」の注記付き）も掲載。
- **「桃園川合流点」の現存〔確認: 図3-1計画流量配分図〕**: 神田川の橋名・流量の節点リスト中に**「桃園川合流点」が淀橋の上流側に現存**〔〔観察〕[PAP-065](../papers/PAP-065.md)が示す桃園川の法定河川廃止（昭和42年暗渠化完了）後も、流量配分図の節点名称として合流点表記が残る。計画流量の接続関係は図の画像判読を行っていないため数値は採らない〕。
- **神田上水の旧呼称区分〔確認: 「歴史・文化」節〕**: 江戸時代、「上流より神田上水の取水堰であった**関口大洗堰までを神田上水、関口大洗堰から船河原橋までを江戸川、それより下流を神田川**と呼んでいた」と明記〔神田川・江戸川・神田上水の旧称区分を現行の都計画書が再述〕。
- **分水路諸元〔確認: 表2-3〕**: 高田馬場分水路1,460m（□6.65×6.60m×2＋□6.00×6.80m×1）・江戸川橋分水路1,644m（□7.50×7.15m×2＋□7.50×7.20m×1）・水道橋分水路1,640m・お茶の水分水路1,300m（φ8.80m×1区間を含む）。
- **主要水害記録〔確認: 表2-1〕**: S33.9.26狩野川台風（床下19,962棟・床上18,394棟・合計38,356棟・東京76.0mm/h・浸水面積1,194.0ha）・**S38.8.1集中豪雨（合計9,456棟・豊島43.0mm/h）**など、1,000棟以上浸水の記録を掲載。S56.7.22集中豪雨（188.7ha）・H17.9.4集中豪雨（3,591棟・下井草112.0mm/h）。
- **弦巻川・水窪川の欠如〔観察〕**: 本文で神田川の支川は善福寺川・妙正寺川・江古田川のみ、派川は日本橋川・亀島川のみ。**弦巻川・水窪川（いずれも暗渠化済み）への言及なし**〔神田川直系の旧小支川が現行の一級河川計画から消えていることの確認。谷端川系（千川上水・桃園川）は桃園川合流点・千川上水導水の形で残る〕。

## 制限・未解決

- ①図2-13・図3-1は画像のため、流量数値の全体像は未判読（本文テキストに現れた数値のみ採録）。②音羽1丁目の湧水2件の民家の地番なし（特定不可）。③「計画配分」の根拠資料（H2～H7の送水契約・配分手続）の所在不明。④都建設局本来の掲載URLの特定と、現行の「変更」手続の有無（[GOV-126](GOV-126.md)参照）。
