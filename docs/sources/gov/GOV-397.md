# [GOV-397] 市中取締類集[208] 在町家作之部 — 淀橋水車久兵衛家の御成御門・御用挑灯の仕来と御小休所の継続〔第166回〕

- **書誌〔確認〕**: 『市中取締類集』[208]在町家作之部（天保14卯年7月の事案を含む冊・NDL次世代デジタルライブラリー [book/2572234](https://lab.ndl.go.jp/dl/book/2572234)）。百姓町人の家作の起立・規制の取締例集。**引用文言はすべてOCR由来で要原文照合。**
- **天保14卯年（1843）7月の柏木淀橋町水車久兵衛家の家作の起立御尋〔確認・核心・repo初出〕**: 「**天保十四卯年七月柏木淀橋町水車久兵衛家に之儀二付其筋掛合其外申渡調**」の件で「**此度百姓町人共家作之儀尊家ニ紛敷分ハ取払候様御触に御座候処、私家作之儀起立御尋ニ付左ニ申上候**」＝家作取締の御触（贅沢・僭上の家作の取払）に対する起立御尋への書上で、**①「前々ゟ中野筋江應有徳院様御代々様御成之節者御小休所ニ相成候一御座所壱ケ所、右家作衆建候儀は古来は自分入用を以先々取建候儀二御座候」**＝**中野筋への御成（「應有徳院様」＝有徳院〔徳川吉宗の院号〕・「御代々様」＝歴代の御成とOCR崩れ候補）の際に淀橋水車久兵衛家が御小休所となった御座所一ヶ所**があり、家作は古来自分入用（自己負担）で建てた、**②「一御成御門壱ケ所、右は左来水車江之通用口に御座候処、御成度々有之御通行御座候ニ付、年限不知新夕ニ自分入用を以取建、尤平常〆切置自用に通路不仕、右御門は前同様同御役所ニ而当時は御修復二相成申候」**＝**御成御門一ヶ所は元来水車への通用口であったが、度々の御成の御通行のために（年限不知の新規に）自分入用で建て直し、平常は閉め切って自用の通路とせず、御門は前同様小普請方御役所で当時も修復されている**、**③「右二付御用と申高張御挑灯弐張幷御成御門と申御掛札御渡二相成居申候」**＝**御用高張挑灯2張と「御成御門」の掛札を相渡されている**という書上〔**淀橋水車の施設が御成の通過動線に組み込まれた実態（通用口の御成御門化）の一次文言（repo初出）**〔水車の通用口を御成御通行に転用した年限不知の取立文言は、[GOV-390](GOV-390.md)の享保4年（1719）の家業セット成立・「享保年中に御小休となる」（[BOOK-194](../books/BOOK-194.md)）と時期整合の可能性があるが「年限不知」のため断定しない〕。
- **御用挑灯の享保年中相渡の仕来と文政8年の引替請取〔確認・核心・repo初出〕**: 「**御用挑灯之儀は享保年中御小納戸頭取松平伊賀守善図にて相渡、文政八酉年十月小普請方ニ而引替請取御改、此度御留上二相成候**」＋「**御用挑灯之儀は御成御門等有之非常之節為用意…享保年中口小納戸頭取差図を以相渡置候儀相違無之候**」＝**①御用挑灯（高張挑灯2張）は享保年中に御小納戸頭取〔松平伊賀守〕の差図で相渡され、②文政8酉年（1825）10月に小普請方が引替請取・御改を行い、③天保14の家作御触の際に留め置きが確定した**という仕来の文言〔**享保年中の挑灯・掛札の相渡＝享保4年の水車家業裁定と同時期の可能性があり（[GOV-390](GOV-390.md)の享保期家業セットの構成要素の候補）、文政8年の引替請取と天保14年の留の3点の通時系列が付いた一次文言（repo初出）**。「善図」は「差図」のOCR候補。松平伊賀守＝[GOV-390](GOV-390.md)の「松平伊賀守相願」と同一人物の候補（比定は要照合）〕。
- **享保度より当時迄の御小休の継続と鷹野の不定式性〔確認・参考〕**: 「**右久兵衛方古享保度より当時迄御成之節御小休等に相成候儀は相違無之**」＋「**中弐歩御減之節は右久兵衛前御議定場ニ多分相減候ニ付…此後迚も中野筋御成之節は御小休所にも可相成候得共、御鷹野御成之儀は其節々之御模様次第之儀にて定式御小休所と申儀二は無之**」＝**享保度から天保14当時まで御成の節の御小休所であったことに相違なく、今後も中野筋御成の際は御小休所となるが、鷹野の御成は時々の御模様次第で定式の御小休所ではない**という吟味書上〔**淀橋水車久兵衛家の御小休所の享保〜天保の継続の一次文言**〔[GOV-349](GOV-349.md)（御成の淀橋水車への御立寄）・[GOV-398](GOV-398.md)（触留の小金井筋御成の御小休所・淀橋御渡）と対校する中核資料。「應有徳院様御代々様」の読み（吉宗以降の代々の御成か）は要照合〕。天保14卯7月朔日の宛先・印形: 「五人組名主久兵衛印伝吉印紋右衛門印御番所様」・小普請奉行鳥居甲斐守・御鳥見組頭中の関係書面の往復。
