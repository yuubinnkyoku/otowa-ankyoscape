# [GOV-424] 享保撰要類集[68] 二十下ノ上（上水之部）— 寛保2年出水の上水行政側報告と武家屋敷内樋の維持構造

- **書誌〔確認〕**: 『享保撰要類集』[68] 二十下ノ上 上水之部。NDL次世代デジタルライブラリー [book/2572823](https://lab.ndl.go.jp/dl/book/2572823)。項目番号は**七十二〜九十七**（寛保2年6月〜10月前後）。[67]（[GOV-423](GOV-423.md)）の次の冊で、第200回でrepo初登録。fulltext（NDL lab API・ページtxt群）の全頁走査（2026-11-19第200回）。**引用文言はすべてOCR由来で要原文照合。**OCRの題署は「全二十丁ノ上」「上水之部下」。

## 寛保2年8月8日風雨の上水行政側報告〔確認・repo初出〕

- **七十七（8月9日）**: 「昨夜之風雨に而**神田上水通目白山**…**江戸川大水二而水道橋渡り樋江も水附**候旨相聞申候依之**年寄共早々見分差遣**申候吟味仕追而可申上候」（石河土佐守）＝8月8日夜の風雨で目白山側の神田上水が止まるのではないかという不穏な状況・江戸川（神田川）の大水で**水道橋の渡り樋にも水が付いた**という通報に対し、町年寄らがすぐ見分を派遣した初動報告。
- **七十八（8月10日）**: 「一昨八日之風雨ニ而〔目白山関打并〕**水役茂左衛門両人負場所之内遂ケ樋流落候ニ付白堀増幷仮樋申付候依之水切申候間申上候**」＝水役茂左衛門（両人負場所）の遂ケ樋が流落したため**白堀を増し掘るとともに仮樋を申し付け、水を切った**＝**「白堀増幷仮樋」という寛保2年8月の応急工法の一次文言〔repo初出〕**。
- **対で読める既存記録〔観察〕**: [GOV-420](GOV-420.md)（[61] 出水之部）の寛保2年8月9日「小日向筋出水之儀申上候書付」（石河土佐守提出＝[BOOK-130](../books/BOOK-130.md)第196回追記の水見分書付の一次原典）が**被害側の見分報告**、本冊の七十七〜七十八が**上水行政側の対応・応急実務の報告**で、同一事件の両面が上司（本多伊豫守）宛書付群として対になる〔確認：同一事件の書付が別部（出水之部・上水之部）に跨る初の対校例。文言の全対応（大洗堰・音羽町の箇所名が本冊側には出ない）は原画像照合まで断定しない〕。
- **四谷御門外北之方上水戸樋の破損〔確認・repo初出〕**: 同時期の条に「四谷御門外北之方上水戸樋昨夜之風雨に而**土手崩れ土屋落樋三拾間程吹破り**候由**渋谷御門番**小堀西近ゟ申来候」＝**四谷御門外北の上水戸樋が土手崩れで約30間吹き破れた（渋谷御門番からの通報）**＝寛保2年8月出水の玉川上水側（吹上給水系）の被害の箇所別報告。樋が掛からず上水が不通になった文言つき〔条の entry 番号はOCR行割れで要照合〕。

## 八十二（寛保2年9月3日）: 水戸殿屋敷内の神田上水樋の流失と100両拝借〔確認・repo初出〕

- 「先月八日小日向筋出水に付神田上水通所に破損仕**神田水元役内田茂左衛門**受負罷在候**水戸殿屋敷内に有之候〔長拾壱〕間半之内樋**…**石垣長拾壱間余流失**…材木を以組入土台取付ケ…雨天之無差別相働仕本樋二取組候而**同月十四日迄ニ出来同日ゟ水相懸り申候**」＋「当夏金七拾両程相懸ケ…此度押流新規二仕立候**入用金百両余**相掛候間…**金百両拝借**被仰付候様仕度奉存候…**来年より拾年賦上納**之積り」＝**水戸徳川家屋敷内を通る神田上水の樋（11間半余）が8月8日出水で流失・石垣11間余も流失し、水元役内田茂左衛門の負担で雨天突貫の復旧（8月14日通水）・費用100両の10年賦拝借**の一次記録〔確認〕。「〔長拾壱〕」の単位（間半/合半）はOCRで要照合。
- **意味〔観察〕**: [GOV-269](GOV-269.md)（明治2年の水戸屋敷内掛樋普請）・[GAZ-049](../gazetteers/GAZ-049.md)⑬（白堀上水「水戶殿屋敷に入る」）の**武家屋敷内区間の維持が水元役の負担で行われていた江戸期の構造**が寛保期の帳簿で確認できた。内田茂左衛門＝[GOV-384](GOV-384.md)第164回の内田家（水元役・元文期の内田六次郎系）と同家系の人物（同族と断定はしないが職名の継承と名字から対応候補として記録価値あり）。

## 御本丸掛り四谷樋掛普請の実務（八十三〜八十四）〔確認・repo初出〕

- 寛保2年9月22日・10月: 「御本丸掛り上れ御普請ニ付水留之儀」＝四ッ谷御門内から御門外高獄下までの通り直し普請に伴う水留・**往来人馬留**（9月25-26日の両日・雨天順延）＋「御本丸掛り上れ通〔り〕四谷御箪笥〔町〕同町長州より同所御門外高料下迄**長延る弐百五間樋掛**御普請…麹町拾一町内角より高村下迄之樋枡伏替…日数三日人へか留」＝**四谷御門外〜御本丸方面の205間の樋掛給水網の普請時の断水・通行止の実務文言**。〔[GOV-288](GOV-288.md)の天保期の御本丸掛樋高枡サイクルの約90年前の先行例として樋掛網の起点側座標。町名・間数はOCR要照合〕
- **井之頭池水の玉川上水への「仕懸」構想文言候補〔確認・repo初出候補・断定しない〕**: 八十四（10月）に、玉川上水の濁り（水澄対策の難航: 前堰の澄し・脇の堰留の失敗）に対し「**神田上水と水元井之頭池水玉川上水江仕懸申候積り**奈良屋市左衛門見分に差遣候処…御入用多候而も水かさ透御用立不申」という行がある〔確認・文言は前後の行割れが激しく要原文照合〕＝**神田上水の水元・井之頭池の水を玉川上水へ「仕懸ける」（掛ける）構想が寛保2年10月に検討された**という従来知られた文脈（[GOV-390](GOV-390.md)の享保4年の淀橋水車による玉川→神田助水〔逆方向〕と対になる逆ベクトルの検討文言候補）。実施の有無は本冊では確認できず〔未解決〕。
