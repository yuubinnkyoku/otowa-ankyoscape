# [GOV-500] 豊島区「わが街ひすとりぃ 第8回 雑司が谷」現地ロケ編全文テキスト〔repo初出・弦巻川上流域（雑司が谷）の地主柳下家の戦後生活史の口述〕

- **書誌〔確認: 全文テキスト取得・2026-11-22〕**: 豊島区デジタル区史「としまひすとりぃ」オーラルヒストリー**「わが街ひすとりぃ 第8回 雑司が谷」現地ロケ編全文テキスト**（[テキスト頁 ht420080](https://adeac.jp/toshima-history/text-list/d000000/ht420080)・[texthtml URL](https://adeac.jp/toshima-history/texthtml/d000000/mp00500101/ht420080)）。**「オーラルヒストリー 全文テキスト」corpus（ADEAC目録ID mp00500101・ウェブコンテンツ・平成30年7月〜令和4年5月31日製作・CC BY）**に属する。同じcorpus内の小池陸子インタビュー（ht430020）は[GOV-128](GOV-128.md)として既収録、現地ロケ編の千早（第15回）・北大塚（第20回）・東池袋（第12回）は[GOV-497](GOV-497.md)〜[GOV-499](GOV-499.md)として既収録＝**未収録だった雑司が谷回の全文テキストを本ファイルで採録**〔話者＝柳下さん（柳下家）・清田さん・髙野さん。収録地＝柳下家の墓地・自宅、雑司が谷弦巻通り商友会、旧高田小学校跡、雑司が谷駅周辺〕。
- **柳下家の一次口述〔確認: 本文の直接引用〕**: ①墓地＝「**わが家の墓地、みんな見てほら。ほら見て、いかに古いかね**」＋「**こっちは柳下宗家…こちらが一番の元の柳下さんのお墓だな**」〔清田さん〕、②自宅＝「**真ん中に小さい土俵があって、本当の相撲部屋。土間が広くて、あそこでお稽古したのかなって思う。小さな土俵があって、本当に相撲部屋って感じ**」、③「**私が嫁に来た頃はプールもあったんですよ。その頃は今よりも豊かでしたので、プールがあって、当時…終戦後、私の主人の話だと学校が焼けてプールがなかった学校がたくさんあったんですってね。その時、学校に貸したって記憶ありますね**」、④「**ここに1軒もうちなかったから。早く嫁に来たので、夜中にね、主人と2人で水着を着て泳いだことあります。６０何年前ですけど。本当に家一軒なかったの。全部林。この辺の柳下家は何軒かありますよね。だから、それぞれの名前つけて呼んだんで、うちのことは「森の柳下」って**」＝**雑司が谷の柳下家（墓地の「柳下宗家」・複数の柳下家の分家群「森の柳下」・戦後接収前の屋敷内相撲部屋とプール・周囲が全部林だった戦後直後の立地）の生活史の一次口述**〔[BOOK-233](../books/BOOK-233.md)（豊島区史資料編四）が所在を記録した「雑司が谷柳下家日記」M29-32・柳下家大福帳・柳下家領収の柳下家と家名を同じくするが、**家系の同一性は本資料では確認できない（断定しない）**。[GAZ-048](../gazetteers/GAZ-048.md)・[GAZ-072](../gazetteers/GAZ-072.md)の雑司ヶ谷の柳下若狹（谷頭集落の名主）の家の系統との関係も同様に保留〕。
- **弦巻通り商友会の口述〔確認: 本文の直接引用〕**: 「**ちょうど我が弦巻通りの商店街にでてきました**」＋「**前はね、ここまでお店があったんですよ。ところが火事でこっち側だけ焼けちゃって。もとはね、全部お店が入ってる**」＝**弦巻通り（弦巻川暗渠上の通り）の商店街（雑司が谷弦巻通り商友会）の戦後の店舗の連なりと火事による片側焼失の記憶**〔弦巻通りが弦巻川に由来する通りの呼称であること自体は既知の前提で、本資料は商店街の実態側の口述として記録する〕。
- **水系文言の陰性〔観察・正直な記録〕**: 本文中に「川」「弦巻川」「水」「暗渠」「湧水」に直接対応する水系の記述は確認できなかった（「プール」「池袋」等の語はある）＝**本資料は水系資料というより弦巻川上流域の集落（雑司が谷）の家・通りの生活史資料**。採録の価値は①柳下家文書（BOOK-233）の「文書を出した家」の戦後像の口述側補助、②弦巻通りの商店街の一次記憶、の2点にある。
- **留意〔注意〕**: 聞き取り・現地ロケの実施年月日は本文に明記されていない（話者が「６０何年前」と語る時代基準の確定はできないため西暦換算をしない）。話者の氏名の全体（柳下さん・清田さん・髙野さん）も本文表記ままで、フルネームは確認できていない個所があるため、人名の断定はしない。新型コロナの言及（小池インタビュー〔GOV-128〕と同時期）から2020年頃の収録と推定されるが、収録日の確定は目録照合まで保留する。
