# [GOV-034] 豊島区「わが街ひすとりぃ」池袋：地名の二説

- **資料〔確認〕**：豊島区デジタル区史「わが街ひすとりぃ」基本情報「池袋（一丁目～四丁目）」（**平成30年〔2018年〕1月現在**と記す資料、**p.1**）。資料自体の厳密な公開日は未確認。出典：[原文PDF](https://adeac.jp/viewitem/toshima-history/viewer/viewer/content01_v3info/data/content01_v3info.pdf)。
- **池の由来説〔確認：区資料の記述／原典未照合〕**：区資料は『遊歴雑記』を**1814年（文化11年）に書かれたもの**と説明し、昔の池の多さに「池袋」の名が由来するとの記述を紹介する。ここでの1814年は**区資料による著作年代の表記**であり、池・川の形成や地名成立の年代ではない。既収録の1997年『ぞうしがや』45号は『遊歴雑記』を1829年と記しており、**原典の巻次・成立時期を未照合のまま、どちらか一方に統一しない**。
- **谷端川に囲まれた地形説〔確認：区資料に「ある説」として記載／仮説〕**：区資料は、**現在の池袋本町の周囲を巡る旧谷端川に囲まれた土地の形状**から「池袋」と呼ばれたという別説も挙げる。**地名成立を示す近世の一次史料や河道の包囲形状を復元した図を示しているわけではない**。
- **比較の意味〔観察〕**：丸池・湧水の説明と、谷端川沿いの谷地形による説明は、対象とする池・谷・流路が異なる可能性がある。池袋本町付近の地形・旧字界と池袋駅西側の丸池を同一地点にまとめない。〔**未解決：『遊歴雑記』原典の巻次・成立年代、旧谷端川と池袋本町の包囲関係、地名初出との照合**〕
