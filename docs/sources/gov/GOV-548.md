# [GOV-548] 武蔵野市「石神井川上流地下調節池について」〔市側公式ポータル・名称決定と説明会年表・リンク集〕

- **書誌〔確認: ページ本文・r.jina.ai経由・2026-11-23取得〕**: 武蔵野市公式サイト「暮らし・手続き > 上下水道 > **石神井川上流地下調節池について**」。**ページ番号1039135・更新日2026年11月9日** https://www.city.musashino.lg.jp/kurashi_tetsuzuki/jogesuido/1039135.html 〔市区側公式ページとして [GOV-539](GOV-539.md)/[GOV-540](GOV-540.md)（都議会・開示系）の補完初出〕。
- **事業内容の文言〔確認〕**: 「東京都では**石神井川河川整備計画（平成28年3月策定）**等に基づき、近年激甚化する豪雨に対して中小河川の目標整備水準を引き上げ、浸水対策事業の一環として調節池等の検討・整備を進めています」「本事業は、市内（一部地域）の雨水を排出している石神井川において、**1時間あたり75ミリの降雨に対応**するため、**青梅街道や伏見通りの道路区域、河川区域、学校や公園の公共施設等の地下に、河川の水を貯留するトンネル構造の調節池の整備を計画**しています。施工にあたっては、**都立武蔵野中央公園の一部を発進立坑として使用し、シールド工法による掘削**を行う予定です」〔伏見通りを含むroute文言・発進立坑の公園名が市側文言で確認できる。[GOV-540](GOV-540.md)の技監答弁（延長約1.9km・貯留量約30万m³・青梅街道等の道路下）と整合〕。
- **説明会の年表〔確認・repo初出の年表一式〕**: 令和4年7月13日 本工事に対する要望書（石神井川上流第一調節池〔仮称〕工事について・PDF 57.1KB添付あり）／令和5年1月18日・22日 設計段階の説明会／**令和5年6月28日 名称決定（石神井川上流第一調節池〔仮称〕→「石神井川上流地下調節池」・読み仮名「しゃくじいがわ じょうりゅう ちか ちょうせつち」＝名称決定年月日の一次記録はrepo初出**）／令和5年9月8日・9日 設計段階の説明会（**西東京市**）／令和6年2月22日・23日 準備工事の説明会／令和6年12月19日・21日 準備工事の説明会（西東京市）／令和7年3月2日・5日 準備工事の説明会／**令和8年3月11日・15日 本体工事の説明会＝令和8年3月の時点で本体工事の住民説明段階に入ったことを市側ページが記録**〔添付外部リンク＝都建設局「石神井川上流地下調節池工事に関する工事説明会 武蔵野中央公園（武蔵野市）～南町調節池（西東京市）における工事について」 https://www.kensetsu.metro.tokyo.lg.jp/jimusho/kitanan/setumeikaisiryou/kitatamananbu0097_00008 〕。
