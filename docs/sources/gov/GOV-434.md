# [GOV-434] 天明撰要類集 二十九上 — 白堀通・御茶之水掛樋の変死検使の先格伺（天明元年）

- **書誌〔確認〕**: 『天明撰要類集』全二十九上（町奉行関係の行政事例綴・[GOV-215](GOV-215.md)・[GOV-353](GOV-353.md)・[GOV-354](GOV-354.md)と同シリーズの未登録冊。谷中玉林寺門前・青柳町の欠落名主の件なども含む）。NDL次世代デジタルライブラリー [book/2572921](https://lab.ndl.go.jp/dl/book/2572921)。**引用文言はすべてOCR由来で要原文照合**。
- **検使一件の先格伺〔確認・repo初出の実例文言〕**: 「**八月廿四日 牧野大隅守取之 奉新庄織部 神田上水白堀通幷御茶之水掛樋 流死例者等之節検使一件之儀に付奉伺候書付 書面伺之通相心得可申旨被仰渡奉畏候 丑八月廿六日 久松筑前守 大岡主水正**」＋伺の本文「**神田上水白堀通水死其外変死等有之節は水道町之町役人ゟ町奉行所江訴出候得者直二町奉行ゟ検使差遣落着申渡候先格御座候 且又御茶之水掛ケ樋其外右近辺上水方持場之内変死等御座候者御目付方ゟ検使差遣シ落着申渡候先格御座候 先年御番方ニ而上水方相勤候砌 町奉行 御目付ゟ検使差遣候例書 両様共別紙奉入御覧候 右先格之通 白堀通り変死等有之節は以来町奉行所江水道町持場ゟ訴出次第直ニ検使差遣 御茶之水懸ケ樋近辺変死等有之節は御普請奉行ゟ御目付江断次第検使**」（天明元年〔1781・丑年〕8月3日御直・8月26日申渡）＝**①神田上水の白堀通で水死・変死者が出た場合は水道町の町役人の訴出→町奉行の直接の検使、②御茶之水の掛樋（懸樋）・その近辺の上水方持場で変死者が出た場合は御目付方の検使、という管轄区分の先例を再確認した仰渡**。
- **意味〔確認・[GOV-381](GOV-381.md)の規定の適用実例〕**: [GOV-381](GOV-381.md)（幕府『記事条例』78巻 検使之部）は「**神田上水白堀通并御茶之水 樋 流死・変死者の検使規定**（御普請奉行管轄・水道町之町役）」を登録済みだが、同規定の適用と先格の存在が**天明元年（1781）の実例の伺・仰渡で運用されていた**ことを本冊が示す＝①白堀・御茶之水樋区間で水死・変死者が出るという事象自体が天明元年以前から先例として扱われていた、②「先年御番方ニ而上水方相勤候砌」の文言＝検使例が制定以前（上水方への検使制度の初期運用）に遡ることを示唆する文言候補、③御茶之水の樋＝[GAZ-043](../gazetteers/GAZ-043.md)系の御茶ノ水樋管・[GOV-241](GOV-241.md)等の神田上水掛樋の再校資料として、**白堀開渠区間（町奉行検使）と掛樋区間（御目付検使）の管轄区分＝水路構造の違いと役所の対応の違いの一次記録**。
