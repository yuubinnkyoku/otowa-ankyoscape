# [GOV-282] 書上帳 明和3・安永9・安永10-天明2 — 山下御門外の堀端・小土手と四谷御門外南之方の溜枡吐口（18世紀の外堀・上水末端の維持記録）

- **書誌〔確認〕**: 『書上帳』（江戸城外堀・上水・下水の損所・修復の書上）3冊——①「明和三年丙戌二月より同年十二月迄」[book/2547565](https://lab.ndl.go.jp/dl/book/2547565)、②「安永九子年正月より同十月迄」[book/2547572](https://lab.ndl.go.jp/dl/book/2547572)、③「安永十丑年正月より天明二年寅年十二月迄」[book/2547573](https://lab.ndl.go.jp/dl/book/2547573)。いずれもrepo未登録（「山下御門」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔江戸城外堀・玉川上水末端・下水の維持の、幕末帳簿群（GOV-270〜281）に先行する18世紀の記録。〕
- **山下御門外東之方町屋前の堀端石垣崩と数寄屋橋御門外の「洗関掛ケ板」〔確認・repo初出〕**: 明和3（1766）年——「**山下御門外東之方町屋前御堀端石垣崩 長四間高五尺 三月五日崩**」＋「**…為見分…数寄屋橋御門外洗関(?)掛ケ板を取除ケ…二三日間御堀水減し…見分**」＝**山下御門外東之方の町屋前の堀端の石垣（長4間・高5尺）が明和3年3月5日に崩れ、見分のため数寄屋橋御門外の「洗関掛ケ板」（堀の水位を調節する堰板と読める）を取り除いて2-3日間堀の水を減らして検分した**＝**①山下御門外に町屋があった（「東之方」の方位の明示）②数寄屋橋御門外に外堀の水位調節の堰板（掛ケ板）が存在した**という2点の18世紀の記録（「洗関」の字はOCR崩れの可能性が高く、「洗堰」「せき」等の原字形照合必須。外堀の水が数寄屋橋側の堰で制御され、山下御門外の見分のために減水できた＝外堀の水理運用の実態）。
- **山下御門外南之方〜虎御門間の小土手の損所〔確認・repo初出〕**: 安永9（1780）年——「**山下御門外南之方町屋前ゟ虎御門内(前?)迄 御堀端小土手所〻損有之**」＋「**四ツ谷喰違土橋外南之方道之頬土手裏崩 同北之方…長六間程巾四間程 并同所向大土手下水際石垣共崩**」ほか「**常盤橋御門ゟ呉服橋…鍛冶橋…数寄屋橋御門外西之方迄之内 高石垣所〻孕有之**」＝**安永9年に、山下御門外南之方の町屋前から虎御門前までの外堀端の小土手に損所が生じた**＝**山下御門〜虎御門間の外堀沿いに小土手が存在し、その維持修繕が18世紀から行われていた**記録＝[GOV-276](GOV-276.md)嘉永5年（1852）の「日比谷御堀浚揚土…山下御門外ゟ数寄屋橋御門外迄小土手え腹附」と対校すると、**山下御門外の外堀沿いの小土手が18世紀（安永9=1780）から幕末（嘉永5=1852）まで存在し続けた**ことが2点の独立した記録で裏付けられた（「小土手」が玉川上水樋管用の土手であるとは両帳簿のみでは断定できないが、[GOV-276](GOV-276.md)の文言〔樋の足土のために小土手の土を削り取る〕と整合的）。
- **四ツ谷御門外南之方の溜枡吐口〔確認・repo初出〕**: 安永10〜天明2（1781-82）——「**四ツ谷御門外南之方 溜枡吐口出例有之 同所大土手内 沈穴少々宛所〻有之**」＝**四谷御門外南之方の「溜枡」（水を溜める枡）の吐口から例外的な出水があり、同所の大土手内に小さな沈穴（陥没穴）が点在した**＝**18世紀後半に四谷御門外南之方に上水の溜枡と吐口・大土手が存在した**記録＝[GOV-277](GOV-277.md)安政3年（1856）の「四谷御門外南之方御堀端通石垣樋御修復」の区域の**約75年分の先行記録**で、この地点（四谷外堀端南側）の上水設備（溜枡・吐口）の長期の連続性の傍証（沈穴=大土手内の空洞化で、石垣樋・埋樋の老朽化に伴う陥没の可能性があるが断定はしない）。
- **赤坂溜池端柳堤通上水樋修復の小屋場と御茶水の下水吐箱樋〔確認・周辺〕**: ①明和3年冊「**赤坂溜池端柳堤通上水樋御修復…西紺屋町御堀端…小屋場…戌十二月…引渡**」＝**明和3年にも赤坂溜池端の柳堤通の上水樋の修復が行われ、西紺屋町の堀端に小屋場が置かれた**＝柳堤通樋筋（[GOV-272](GOV-272.md)天保4-5年より66年先行）の18世紀の修復記録。②安永10-天明2冊「**御茶水火消御役屋敷脇大土手崩…下水吐箱樋新規場所…樋長減…なめ床掘割樋白(?)記(?)…強(?)伏せ渡**」＝**御茶水の火消役屋敷脇の大土手の崩れと、下水の吐口の箱樋の新規の場所（樋長の減・なめ床・掘割樋の伏せ渡し）**＝御茶水（神田川上流部）の下水吐きの樋管の記録（御茶水の上下水の実態は文言の切り出しが不完全で、帳簿全体の再精読を要す）。
- **千川上水の樋掛渡小屋場の引直〔確認・repo初出の千川上水の資材拠点〕**: ①安永9冊「**千川上水町々樋掛渡…筋違橋御門外明地…柳原土手下御石置場…樋掛切組小屋場…町奉行江相渡…安永九子十一月十二日…**」＝**千川上水の町々への樋掛（樋管の架設）の資材の石置場・切組（樋の組み立て）小屋場が筋違橋御門外の明地・柳原土手下に置かれた**。②安永10-天明2冊「**千川上水樋枡切組小屋場…柳原土手下…和泉橋東之方長六拾間(60間)…浅草筋樋枡伏方取懸り候ニ付 佐久間町裏通明地江小屋場引直**」＝**浅草筋への樋枡の伏設に伴い、柳原土手下（和泉橋東・長60間）の小屋場を佐久間町裏通の明地に引き直した**＝千川上水の江戸市中への給水（浅草筋方面）の実務と、柳原土手下（神田川沿い）の資材置場の実在＝**千川上水（千川の上水。新宿区〜小石川方面から江戸市中へ）の市中樋管の展開の18世紀の記録**（「千川上水」は小石川の千川上水（千川給水）で、玉川上水とは別系統と読めるが、帳簿の同冊に収録される事務の関連〔江戸城の水路全般の書上〕は注記に値する。千川上水の語の表記は要照合）。
- **御城廻りの高石垣のリストと壱番町御堀浚〔確認・周辺〕**: 明和3年冊に「**高石垣草抜…呉服橋…鍛冶橋…数寄屋橋…幸橋…山下御門…清水御門…田安御門…半蔵御門…外桜田…馬場先…和田倉…神田橋…常盤橋…一ツ橋…雉子橋…竹橋…虎御門溜池落口**」の御城廻りリスト＋「**壱番町御堀浚…金三百拾八両…京都書林竹本越前守の内借…**」＝江戸城外堀の高石垣の草抜き（補修点検）が御門群の一巡で行われ、「虎御門溜池落口」（虎御門内の溜池の落口=虎ノ門の溜池〔現在の溜池方面か、城内の溜池かは要検討〕）まで含まれた記録＋壱番町の堀浚（318両・京都の書林からの内借〔借財〕）の経理（「虎御門溜池落口」の文言は虎御門内の上水関連の溜池と読めるが、位置の比定は原字形照合と地図資料を要す）。

## 制限・未解決

- ①すべてOCR由来。「洗関掛ケ板」「沈穴」「吐箱樋」「なめ床掘割樋白記強伏せ渡」等の語・日付（三月五日崩等）・金額は原文照合必須。②「山下御門外東之方」の町屋の位置（山下御門の外の東側＝現在の千代田区大手町〜丸の内方面か）は、江戸図・地図資料との対校で比定する必要がある。③「四ツ谷御門外南之方の溜枡吐口」と[GOV-277](GOV-277.md)安政3年の石垣樋の位置の同一性は、区間名（南之方）の一致から強く推定されるが、文言の対校（吐口・石垣樋の設備の連続性）で確認する。④「虎御門溜池落口」の溜池は虎御門内の城内溜池と読めるが、赤坂の溜池（溜池方面）との混同の可能性を排除できない。⑤千川上水の文言は玉川上水の系統とは別系統と読んだが、帳簿の編纂単位（江戸城の水路全般の書上帳か）の確認を要す。
