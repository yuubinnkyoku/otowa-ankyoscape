# [GOV-177] 中新井村現状調査（1931）— 旧千川上水の境界機能

- **書誌〔確認〕**: 『（東京市）北豊島郡中新井村現状調査』（1931年・市側の郡部現状調査）。NDL次世代デジタルライブラリー [book/1900505](https://lab.ndl.go.jp/dl/book/1900505)。OCRテキストで確認。**文言はOCR由来で要照合。**
- **旧千川上水の境界文言〔確認・repo初出〕**: 「本村北部より府道に沿ひ 練馬町との境界に**旧千川上水**」＝**1931年時点で旧千川上水が中新井村と練馬町の境界をなす**旨の市側現状調査記録。
- **位置づけ〔観察〕**: [GOV-165](GOV-165.md)（長崎町現状調査・1931）の兄弟調査で、千川上水跡の**行政境界としての残存**（中新井村＝現練馬区中部・千川上水の分水群地帯 [GOV-156](GOV-156.md)の豊玉地区に隣接）を1931年時点の行政文書で確認。

## 制限・未解決

- ①「旧千川上水」区間の起点・終点（村境のどの範囲か）は本調査では特定できない。②当時の水路の有無（通水・溝化）は文言上不明。
