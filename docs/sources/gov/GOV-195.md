# [GOV-195] 印刷局沿革録（1903年）— 明治8年の千川用水水積増加の官庁側記録

- **書誌〔確認〕**: 大蔵省印刷局『印刷局沿革録』（明治36年・1903）。NDL次世代デジタルライブラリー [book/784387](https://lab.ndl.go.jp/dl/book/784387)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **明治8年の用水増水〔確認・repo初出の官庁側文言〕**: 明治8年（1875）10月31日の条＝「工場建築地トシテ**王子村水車場ヲ購入**シ次テ工事ニ著手ス、**又水車ニ要スル千川用水ノ水積ヲ增加ス**」＝**印刷局（紙幣抄紙）が王子村の水車場を購入し、水車運転のため千川用水の水嵩を増加させた**沿革録の記述。〔文言はOCR要照合〕。
- **位置づけ〔観察〕**: 明治8年3月10日の千川用水賃借約定（鹿嶋萬平×抄紙会社・[GOV-150](GOV-150.md)）と同年の水車場購入・用水増水が並行する＝**反射炉跡地の抄紙事業（鹿島紡績→抄紙会社→印刷局抄紙部）の水力利用（PAP-076/077系・BLOG-229/230系）について、民間側の約定証書（GOV-150）に加えて官庁側（需要者側）の沿革記録が揃った**。明治8年という千川用水史の転換点（旧水車系統の再編）の両面からの第一次記録。約定と沿革録の時系列（3月約定→10月水車場購入）から、増水が約定後の事業拡大に対応したものと推定される（推定）。

## 制限・未解決

- ①「水積ヲ增加ス」の手段（元樋口の拡幅か、新たな分水か）は本文では特定できない。②購入した水車場の規模・位置の詳細は本文になし（[GOV-194](GOV-194.md)・[GOV-157](GOV-157.md)の用地記録と照合が必要）。③増水が千川用水下流の灌漑に与えた影響は本文では言及なし。
