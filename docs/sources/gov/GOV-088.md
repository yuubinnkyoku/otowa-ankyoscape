# [GOV-088] 北区観光公式頁の千川上水分配堰碑解説

- **資料〔確認：公式頁本文〕**：北区観光ホームページ「[千川上水分配堰碑](https://kanko.city.kita.lg.jp/spot/433-2/)」（王子・滝野川エリア、所在地**滝野川6-9-1**、問い合わせ先は飛鳥山博物館事業係と明記）。〔確認：区公式観光頁〕
- **解説内容〔確認〕**：①千川上水は元禄9年（1696）玉川上水分水の上水で今は暗渠。②**江戸幕府が大砲工場を建設する際、この堰から西巣鴨交差点の方向に分水路が通された**。③明治になると分水路は**北区・荒川区・台東区内の23か村の灌漑用水、王子近辺の紡績工場・抄紙会社・大蔵省紙幣寮抄紙局（今の印刷局滝野川工場）の工業用水**として利用された。④**碑は明治15年（1882）に水利権を明確にするため設置**された。⑤「北区が近代工業の発祥の地となったのも石神井川、千川上水の豊かな水があったから」。
- **既存資料との関係〔解釈〕**：[BLOG-095]の碑文全面採録（樋口寸積・明治15年建立・明治42年裏面追刻）と**設置年・趣旨が整合**する公式側解説。〔確認：整合〕〕幕末の反射炉への分水は[BLOG-053]（1865年王子分水が「堀割」の由来）・[BLOG-127]（慶応元年の開削工事）と同じ出来事を指すが、**「西巣鴨交差点の方向」という流向の公式表現**はrepo初出の具体化。[GOV-056]の23か村数値・[BLOG-101]の沿革年表とも整合。
- **未確認〔注意〕**：「大砲工場」＝滝野川反射炉を指すかは頁に明記されない（文脈上その解釈が自然だが断定資料ではない）。
