# [GOV-338] 東京市例規類集（1913）— 水衞心得の境水衞所と千川水道・千川用水の分水樋鍵保管

- **書誌〔確認〕**: 東京市内記課編『東京市例規類集』（明治46年＝1913。東京市の現行の条例・規則・告示・訓令・通牒等の「例規」を類別に蒐録した市編纂の法規集成。凡例「本書ハ東京市現行ノ條例規則其他告示訓令通牒等ニシテ例規ト爲ルヘキモノ…ヲ蒐錄ス」）。NDL次世代デジタルライブラリー [book/1337642](https://lab.ndl.go.jp/dl/book/1337642) のOCR全文を確認。**引用文言はOCR由来で原文画像との照合を要する**（段組の崩れ・頁横断の混在が多い）。
- **水衞心得と境水衞所の千川系分水樋鍵保管〔確認・repo初出・文言候補〕**: 第十二類水道の「水衞心得」（設定年月日欄「明治三十一年二月二十一日設定」）——「**水衞ハ專ラ芥揚ニ從事シ兼テ水路ノ取締ヲ爲スヘシ**」「**水衞ノ受持區域ハ左ノ如シ（四谷大木戸水衞所間・和田堀内水衞所間・久我山水衞所間・境水衞所間・小川水衞所間・砂川水衞所間・熊川水衞所間・水道課羽村派出所…）**」（受持区域は表組のOCR崩れあり・要照合）、および分水樋鍵保管の表——「**品川用水.千川水道、千川用水分水樋鍵境水衞所詰水衞保管**」（一連の表として「齋藤櫻門、原宿、神田上水分水樋鍵（大木戶水衞所）」「三田用水、幡ヶ谷分水樋（和出堀水衞所）」「高井戶、北澤、鳥山、牟禮分水樋鍵（久我山水衞所）」「小川、野火止分水樋鍵（小川水衞所）」「砂川分水樋鍵（砂川水衞所）」「殿々谷、拜島、熊川、福生分水樋鍵（熊川水衞所）」等）＝**①玉川上水沿いの諸分水の樋の鍵を各水衞所の水衞が保管した制度の文言のうち、千川系＝「品川用水・千川水道・千川用水」の分水樋の鍵を境水衞所の水衞が保管したとする記録、②「千川水道」と「千川用水」が並記され、それぞれ分水樋を持つとされた観察、③境水衞所（玉川上水の境＝旧保谷村境橋付近と推定されるが比定は保留）の管轄が千川系の分水管理を含んだこと**の3点〔**「水衞」語のrepo初出**。「境水衞所」は[BOOK-121](../books/BOOK-121.md)等の境新田・境橋分水の記録群（README §千川上水の保谷村境橋分岐）と対校する地点で、明治31年（1898）時点の東京市側の分水管理の一次制度記録。文言はOCR由来で要照合〕。
- **市區改正附改良下水の千川線・雑司ヶ谷線〔確認・文言候補・BOOK-126との対校案件〕**: 第十三類「市區改正附改良下水」の説明文——「**汚水及百分ノ一吋雨水ヲ以テ雑司ケ谷線ヲ合シ沿路ノ活水ヲ集メテ水道町ヲ東ニ牛天神社前ニ至リ砲兵工廠內ヲ隧道ヲ以テ富坂ニ出テ千川線ニ合ス千川ハ郡部ニ廣大ナル流域ヲ有スルヲ以テ瀧ノ川堰堤上流ヨリ雨水ヲ疏通スルニ足ル可キ新水路ヲ設ケ隅田川ニ放流セシメ千川線ハ單ニ鐵道線以南ノ郡部流域及沿路ノ雨水ト汚水トヲ合セ現在ノ開渠ヲ混凝土下水溝ニ改修シ富坂ニ來リ水道端線ヲ合シ…**」（「隧」の原字はOCR「燧」候補・「百分ノ一吋雨水」＝「百分ノ一吋」は汚水量の慣用表現候補・全体に段組崩れがあり**文言候補・要原画像照合**）＝**市區改正附改良下水（明治期の東京市下水改良計画）の幹線名としての千川線・雑司ヶ谷線の記述で、千川線が「現在ノ開渠」（＝千川の開渠を下水幹線に転用する前提）を混凝土下水溝に改修し、千川の雨水を「瀧ノ川堰堤上流」から新水路で隅田川に放流させる計画文言**。〔[BOOK-126](../books/BOOK-126.md)（小石川区史・1935の明治41年市下水道設計の千川線・雑司谷線記述）と文言が一部異同する（「瀧ノ川堰堤」の判読・「隅田川ニ放流」の有無等）＝同じ計画の記録系統の対校案件。本書（1913蒐録）と区史（1935記述）のどちらが告示原文に近いかは原画像照合まで断定しない。〕
- **「千川下流」の下水管規模文言〔確認・文言候補〕**: 下水説明文中——「**最大ナル下水管ハ千川下流ニ於ケル底幅十三尺深サ六尺ノ開渠芝公園前ヨリ芝園橋ニ至ル底幅十二尺ノ半圓形管及芝園橋ヨリ芝浦ニ至ル幅十尺深サ六尺七寸ノ馬蹄形管等ニシテ**」＝「千川下流」の底幅13尺・深さ6尺の開渠が「最大ナル下水管」とされた文言（前後の文脈が芝区側の下水説明に接続しており、段組崩れで千川線説明との文脈の帰属が不確実・**要原画像照合**）。〔「千川下流」の用例としては[BOOK-126](../books/BOOK-126.md)の千川（下水幹線名）の用例群と対校する。開渠の規模数値は文言候補として扱う。〕
- **明治41年の電話信号ベル網〔確認・文言候補〕**: 「電話信号ベル押方ヲ定ム」（年月日欄「明治四十一年七月二十(九)日(市參事會議決)」・日の判読は要照合）の対象一覧に「**水道課羽村派出所・淀橋浄水工場・機關室餘水吐・熊川水衞所・小川水衞所・境水衞所・久我山水衞所・和田堀内水衞所**」＝**羽村から淀橋・境・和田堀内までの水道施設・水衞所を結ぶ電話・信号ベル網の明治41年（1908）時点の記録**。〔境水衞所が1908年時点で電話網の結節点であったことの制度的傍証（通信網の文言であって位置の特定ではない）。〕

## 制限・未解決

- ①水衞心得の受持区域・分水樋鍵保管の表は段組のOCR崩れが大きく、行対応の正確な復元は原画像照合を要する（「境水衞所＝千川水道・千川用水の鍵保管」という対応自体はOCRでも一つの行として読めるが、確定は原画像待ち）。②境水衞所の位置（旧保谷村境橋＝現・保谷境橋付近か）は本書からは特定できず比定保留。③「千川水道」と「千川用水」の並記の意味（民営水道と灌漑用水の区別か）は本書の文言のみからは断定しない（[GOV-173](GOV-173.md)の1891年「千川上水ハ千川水道會社ノ所有タリ」と対校しつつ次回課題）。④市區改正附改良下水の千川線文言と[BOOK-126](../books/BOOK-126.md)（明治41年告示系）の異同の原画像対校は未実施。⑤「最大ナル下水管」文言の文脈帰属（千川線か芝区側か）は要照合。
