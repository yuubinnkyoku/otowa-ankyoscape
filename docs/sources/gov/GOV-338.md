# [GOV-338] 東京市例規類集（1913）— 水衞心得の境水衞所と千川水道・千川用水の分水樋鍵保管

- **書誌〔確認〕**: 東京市内記課編『東京市例規類集』（明治46年＝1913。東京市の現行の条例・規則・告示・訓令・通牒等の「例規」を類別に蒐録した市編纂の法規集成。凡例「本書ハ東京市現行ノ條例規則其他告示訓令通牒等ニシテ例規ト爲ルヘキモノ…ヲ蒐錄ス」）。NDL次世代デジタルライブラリー [book/1337642](https://lab.ndl.go.jp/dl/book/1337642) のOCR全文を確認。**引用文言はOCR由来で原文画像との照合を要する**（段組の崩れ・頁横断の混在が多い）。**〔2026-11-17・第147回追記〕**: 同書の**1922年版**（東京市・大正11年・[book/913872](https://lab.ndl.go.jp/dl/book/913872)・請求記号特108-428・書誌ID000000536213）に**同一の水衞心得（明治31年2月21日設定の再録）が収録されていることをfulltextで確認**——「**品川用水、千川水道、千川用水分水樋鍵 境水衞所詰水衞保管**」の文言が1922年版でもそのまま再録され、**境水衞所による千川水道・千川用水の分水樋鍵保管制度が1913年版から1922年版まで（制度設定は明治31年から）例規集に継続収録されていた**ことを裏付ける。受持区域（「境…小川水衞所間」＝境水衞所の担任区域が境〜小川水衞所間〔玉川上水沿い〕の文言候補）も1922年版で再確認（表組のOCR崩れは1913版と同様・文言候補のまま確定は原画像照合待ち）。市區改正附改良下水の千川線・雑司ヶ谷線文言も1922年版に同型で再録される（1913版文言との対校は本項の②で扱い、1922年版を独立登録しない）。
- **水衞心得と境水衞所の千川系分水樋鍵保管〔確認・repo初出・文言候補〕**: 第十二類水道の「水衞心得」（設定年月日欄「明治三十一年二月二十一日設定」）——「**水衞ハ專ラ芥揚ニ從事シ兼テ水路ノ取締ヲ爲スヘシ**」「**水衞ノ受持區域ハ左ノ如シ（四谷大木戸水衞所間・和田堀内水衞所間・久我山水衞所間・境水衞所間・小川水衞所間・砂川水衞所間・熊川水衞所間・水道課羽村派出所…）**」（受持区域は表組のOCR崩れあり・要照合）、および分水樋鍵保管の表——「**品川用水.千川水道、千川用水分水樋鍵境水衞所詰水衞保管**」（一連の表として「齋藤櫻門、原宿、神田上水分水樋鍵（大木戶水衞所）」「三田用水、幡ヶ谷分水樋（和出堀水衞所）」「高井戶、北澤、鳥山、牟禮分水樋鍵（久我山水衞所）」「小川、野火止分水樋鍵（小川水衞所）」「砂川分水樋鍵（砂川水衞所）」「殿々谷、拜島、熊川、福生分水樋鍵（熊川水衞所）」等）＝**①玉川上水沿いの諸分水の樋の鍵を各水衞所の水衞が保管した制度の文言のうち、千川系＝「品川用水・千川水道・千川用水」の分水樋の鍵を境水衞所の水衞が保管したとする記録、②「千川水道」と「千川用水」が並記され、それぞれ分水樋を持つとされた観察、③境水衞所（玉川上水の境＝旧保谷村境橋付近と推定されるが比定は保留）の管轄が千川系の分水管理を含んだこと**の3点〔**「水衞」語のrepo初出**。「境水衞所」は[BOOK-121](../books/BOOK-121.md)等の境新田・境橋分水の記録群（README §千川上水の保谷村境橋分岐）と対校する地点で、明治31年（1898）時点の東京市側の分水管理の一次制度記録。文言はOCR由来で要照合〕。
- **市區改正附改良下水の千川線・雑司ヶ谷線〔確認・文言候補・BOOK-126との対校案件〕**: 第十三類「市區改正附改良下水」の説明文——「**汚水及百分ノ一吋雨水ヲ以テ雑司ケ谷線ヲ合シ沿路ノ活水ヲ集メテ水道町ヲ東ニ牛天神社前ニ至リ砲兵工廠內ヲ隧道ヲ以テ富坂ニ出テ千川線ニ合ス千川ハ郡部ニ廣大ナル流域ヲ有スルヲ以テ瀧ノ川堰堤上流ヨリ雨水ヲ疏通スルニ足ル可キ新水路ヲ設ケ隅田川ニ放流セシメ千川線ハ單ニ鐵道線以南ノ郡部流域及沿路ノ雨水ト汚水トヲ合セ現在ノ開渠ヲ混凝土下水溝ニ改修シ富坂ニ來リ水道端線ヲ合シ…**」（「隧」の原字はOCR「燧」候補・「百分ノ一吋雨水」＝「百分ノ一吋」は汚水量の慣用表現候補・全体に段組崩れがあり**文言候補・要原画像照合**）＝**市區改正附改良下水（明治期の東京市下水改良計画）の幹線名としての千川線・雑司ヶ谷線の記述で、千川線が「現在ノ開渠」（＝千川の開渠を下水幹線に転用する前提）を混凝土下水溝に改修し、千川の雨水を「瀧ノ川堰堤上流」から新水路で隅田川に放流させる計画文言**。〔[BOOK-126](../books/BOOK-126.md)（小石川区史・1935の明治41年市下水道設計の千川線・雑司谷線記述）と文言が一部異同する（「瀧ノ川堰堤」の判読・「隅田川ニ放流」の有無等）＝同じ計画の記録系統の対校案件。本書（1913蒐録）と区史（1935記述）のどちらが告示原文に近いかは原画像照合まで断定しない。〕
- **〔2026-11-17・第148回追記〕千川線文言の帰属特定＝「東京市下水道設計」（明治41年4月11日市告示第28号）の収録本文〔確認・文言候補〕**: 当該文言の直前に「**東京市下水道設計　明治四十一年四月十一日市告示第二十八號　東京市區改正事業ノ內下水道設計左ノ通リ定メラル　但圖面ハ本市役所ニ備置ク　右明治二十一年勅令第六十二號東京市區改正條例第二條ニ據リ告示ス**」の見出し文言があり、千川線・雑司ヶ谷線・芝線等の説明は**明治41年（1908）4月11日の市告示第28号（区改正条例第2条に基づく「東京市下水道設計」）の収録本文**であることが帰属特定できた。その冒頭——「**下水ノ排除ハ合流法ニ依リ雨水及汚水ヲ同一ノ管渠ニ導キ雨水ハ適所ニ雨水吐ヲ設ケ河川濠池等ニ放出シ汚水ハ〓澄シテ之ヲ品川灣、隅田川及中川ニ放流ス　但地勢ニ應シ分流法ヲ併用スルコトアルヘシ（大正二年五月十五日市告示第六十七號ヲ以テ本項中但書追加）**」＝合流法主体・分流法併用の但書は大正2年告示67号の追加。および「**汚水量ハ全市ノ人口ヲ三百万ト假定シ一人一日平均六立方尺ヲ八時間內ニ排泄スルモノトシ雨水量ハ一時間ノ最大降雨量ヲ二吋トセリ　但一時間百分ノ一吋雨水ハ汚水ト同一ニ之ヲ處分ス（大正二年五月十五日市告示第六十七號ヲ以テ本項中改正）**」＝**①汚水量の設計基準（全市人口300万・1人1日6立方尺・8時間内排泄）、②雨水量の設計基準＝1時間の最大降雨量2吋（約50.8mm/h）**の文言候補。〔**本書の千川線文言は告示28号の本体側テキスト（大正2年告示67号の但書追加・改正込みの1913年現行形）で、BOOK-126（小石川区史）の引用元告示の本体側にあたる**。区史の文言差（「都市計畫路線ニ沿ヒ、初音町ヲ經テ」等の有無）は区史が別版・後年改訂版を引く可能性があり断定せず対校記録にとどめる。**「雨水量1時間2吋（≈50mm/h）」の文言は[BLOG-115](../blogs/BLOG-115.md)「下水道50mm/h設計基準」の源流候補**（観察・断定しない）。なお第三區（下谷側）の説明にも「汚水量ハ本區畫ノ人口ヲ將來六十万ト假定シ…雨水量ハ一時間ノ最大降雨量ヲ二吋トセリ」と同基準の区域版文言がある。〕
- **雑司ヶ谷線・大塚線の起点＝在来開渠の改修文言〔確認・文言候補・第148回追記〕**: 同告示本文（中段區域）——「**小石川雜司ケ谷ヨリ起ルモノハ在來ノ開渠ヲ改修シテ江戶川橋ニ出テ雨水ヲ江戶川ニ放流シ汚水及百分ノ一吋雨水ヲ以テ大塚ヨリ來ル下水管ニ合ス**」「**大塚ヨリ起ルモノハ在來ノ開渠ヲ改修シテ郡部ノ雨水ト沿路ノ汚水及雨水ヲ集メ江戶川橋ニ來リ雨水ヲ江戶川ニ棄テ汚水及百分ノ一吋雨水ヲ以テ雜司ケ谷線ヲ合シ沿路ノ活水ヲ集メテ水道町ヲ東ニ牛天神社前ニ至リ砲兵工廠內ヲ燧道（隧道のOCR崩れ候補）ヲ以テ富坂ニ出テ千川線ニ合ス**」＝**①雑司ヶ谷線の起点が「小石川雑司ヶ谷の在来開渠（＝弦巻川系の開渠）の改修」、②大塚線の起点が「大塚の在来開渠（＝谷端川系の開渠）の改修」で、それぞれ江戸川橋（神田川）へ雨水を放流しつつ汚水を雑司ヶ谷線→砲兵工廠内隧道→富坂→千川線に集める経路**の全体文言（文言候補・要原画像照合）。〔**弦巻川・谷端川の在来開渠を下水管に改修して転用する計画の明治41年告示レベルの文言で、両川の下水道転用計画の年代的上限を画する記録**（BOOK-126区史の同系記述の告示本体側）。「在來ノ開渠」が両川のどの区間を指すか（江戸川橋への雨水放流の位置関係を含む）は告示図面（「圖面ハ本市役所ニ備置ク」）の確認を要するので特定しない。〕

## 制限・未解決

- ①水衞心得の受持区域・分水樋鍵保管の表は段組のOCR崩れが大きく、行対応の正確な復元は原画像照合を要する（「境水衞所＝千川水道・千川用水の鍵保管」という対応自体はOCRでも一つの行として読めるが、確定は原画像待ち。1913版と1922版の両方で同一文言候補が確認できる点は文言の安定性の傍証）。②境水衞所の位置（旧保谷村境橋＝現・保谷境橋付近か、武蔵野市境の玉川上水沿いか）は本書からは特定できず比定保留（1922年版の受持区域文言候補「境〜小川水衞所間」は玉川上水沿い説を補強する方向の datapoint だが、表崩れのため断定しない。**1936年水道事業年報の建物台帳に境水衞所の実在記録あり＝[GOV-340](GOV-340.md)**）。③「千川水道」と「千川用水」の並記の意味（民営水道と灌漑用水の区別か）は本書の文言のみからは断定しない（[GOV-173](GOV-173.md)の1891年「千川上水ハ千川水道會社ノ所有タリ」と対校しつつ次回課題）。④市區改正附改良下水の千川線文言と[BOOK-126](../books/BOOK-126.md)（明治41年告示系）の異同の原画像対校は未実施（**ただし第148回に、文言が「東京市下水道設計」〔明治41年4月11日市告示第28号〕の収録本文と帰属特定できた。区史の文言差の説明〔区史が別版・後年改訂版を引くか〕は原画像対校まで断定しない**）。⑤「最大ナル下水管」文言の文脈帰属（千川線か芝区側か）は要照合。⑥第148回追記分（告示見出し・汚水量・雨水量2吋・雑司ヶ谷線/大塚線の起点文言）もOCR由来の文言候補で、原画像照合までは断定しない（特に「燧道」＝隧道の判読と「江戶川橋」の橋名）。
