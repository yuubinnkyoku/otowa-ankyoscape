# [GOV-024] 豊島区『豊島区景観計画』（2022年6月改定）第5章「池袋西地域」

## 書誌・所在

- 豊島区、2022年（令和4年）6月改定。豊島区公式「豊島区景観計画」（ページID 22568、2025年7月10日更新）で改定年月と第5章「池袋西地域」のPDFへのリンクを確認。
- 原資料（印刷pp.77–81を含む）：https://www.city.toshima.lg.jp/documents/22568/kaitei_keikankeikaku_5-06.pdf
- 版の説明：https://www.city.toshima.lg.jp/296/machizukuri/toshikekaku/kekan/1805301638.html
- 2026年10月31日、公開PDFの抽出本文・図題・凡例・図中文字を確認。図形の精密な線形・座標の直接判読や位置合わせは未実施。

## 内容メモ

- **〔確認：図題・図中文字〕** 印刷p.78の図表5-49「池袋西地域の等高線」には「水窪川」「弦巻川」「谷端川」の表記があり、標高0・20・40mの目盛りがある。典拠は国土地理院「基盤地図情報数値標高モデル」と明記される。地形の比較図であり、各河川が現在開渠で流れていることや過去の河道中心線を示す実測図ではない。
- **〔確認：図題・凡例・図中文字〕** 印刷p.81の「明治42（1909）年の市街地の様子」と記された編集図には、3河川のほか「千川上水本流」「千川上水・長崎分水」の文字があり、凡例に「河川」「水田」「畑・雑木林」「集落」「街道等」「鉄道」が示される。出典表示は「豊島区地域地図第四集 2011、豊島区史跡めぐり」。**1909年当時の原測量図そのものではなく、後年の資料を基にした再構成図**である。
- **〔確認：計画本文〕** 印刷p.78は谷端川南緑道を旧河川に由来する緑地として位置づけ、p.79は「かつての水の流れを生かして」連続する緑の景観形成を進める方針を記す。これは2022年の景観政策であり、1909年の緑道の存在を意味しない。
- **〔観察・意義〕** 既収録の2015年版『豊島区景観計画』p.72の水窪川付近の編集図について残していた「弦巻川・谷端川まで図郭が及ぶか未確認」という課題に対し、**2022年改定版の池袋西地域の図では三河川を同一図郭で比較できる**ことを確認した。ただし2015年版の当該図そのものの図郭や改訂差分は未照合。
- **〔未解決〕** p.81の描線と各河川の旧流路・水田の境界・長崎分水の分岐点との精密な対応、図の編集・一般化の程度、1909年当時の原図との異同。図中の近接・交差表現だけから水窪川と弦巻川の合流や千川上水からの直接分水を確定しない。
