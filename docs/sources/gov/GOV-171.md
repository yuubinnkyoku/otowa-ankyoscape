# [GOV-171] 御府内上水在絶略記（多摩官渠図本）— 千川上水条の全文

- **書誌〔確認〕**: 『多摩官渠圖』（根岸信輔氏寄贈・多摩川上水之図・野火留分水之図等とともに**『御府内上水在絶略記』四（冑山文庫・浜野代筆）**を収録）・NDL次世代デジタルライブラリー [book/2541386](https://lab.ndl.go.jp/dl/book/2541386)。OCRテキストで千川上水条を確認。**文言はOCR由来で要照合。**
- **千川上水条〔確認・repo初出の本文〕**: 「千川上水 **元禄九子年** 初て**小石川御殿・湯嶋・同聖堂・東叡山・浅草御殿**への上水也。**多摩郡保谷村より玉川上水を引 巣鴨村まて五里弐拾四町堀割**、**巣鴨庚申塚通り本郷湯嶋浅草へ懸る**。**御村徳兵衛・太兵衛 両人開発被仰付、他の字をあらめ千川となし両人の性（姓）に給**。去る**宝永四亥年 白山御殿へ懸る**。**享保七寅年十月 ことやみ（事止み）**、江府へは不懸、**村々田用水に成**。また**安永九子年より江府へ懸る、本郷湯島下谷浅草の辺一圓懸渡**。**天明六午年十一月**また…みて**田場（畑）用水のみに成**」＝元禄9年開通時の**供給先一覧（小石川御殿・湯島・聖堂＝湯島聖堂・東叡山・浅草御殿）**・**宝永4年（1707）白山御殿への延伸**・**開発者徳兵衛・太兵衛への「千川」姓下賜**を含む沿革の江戸期写本記述。
- **享保7年廃止の理由伝承〔確認・文言OCR〕**: 同書に「享保七寅年やみたり 同**青山三田千川の水道御差止**に相成候は…（宝？）新助へ火災二付水道之儀御尋ねありしと記申上候書面の内に **江戸中地下に機を織ことく水道あるか故に地脈絶地気わかれ集不申 風は大地の息にて地は水気を含潤し…水道へ抜候故風枯乾仕うわつき火を誘ひ候よし 井水出来候所之水道をやめ度と申上候由**是等ゟ御差止に成候哉」＝**江戸市中に張り巡らされた樋管が地脈を断ち地気を分け、乾燥・火災を招くとする上申（井水がある場所の水道廃止論）が差止の理由として後世に記録された伝承**〔人名はOCR判読不能・要照合〕。
- **千川分水口の記載〔OCR不鮮〕**: 末尾の分水口・書付写し群に「千川分水口 同断 半兵衛 山王勘三郎書付写」の語が現れる〔文脈はOCR不鮮・内容未詳〕。
- **位置づけ〔観察〕**: [GOV-172](GOV-172.md)（東京府史行政篇）が「御府内上水在絶略記」引用として載せる沿革文言（保谷分水口より瀧野川に至る五里二十四町…）の**引用元本文に相当**。元禄9年の供給先・宝永4年白山御殿延伸・千川姓下賜は[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌）の記述と相互に独立する江戸期側の傍証。享保7年差止の理由伝承は他の出典で未確認の新情報〔伝承として記録〕。
