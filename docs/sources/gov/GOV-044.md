# [GOV-044] 2015年『豊島区都市づくりビジョン』の目白地域資源図

- **書誌・年代〔確認〕**：豊島区『豊島区都市づくりビジョン』、**2015年（平成27年）3月策定**、第6章「地域別まちづくり方針」9「目白地域」、**印刷p.213「図表269 地域資源図（目白地域）」**。[区公開の該当章PDF](https://www.city.toshima.lg.jp/295/machizukuri/toshikekaku/toshikekaku/documents/6syou_9.pdf)（2026年11月3日確認）。策定年月は[豊島区公式「区政のあゆみ年表」](https://www.city.toshima.lg.jp/012/kuse/gaiyo/nenpyo/017934.html)の2015年3月欄でも確認できる。
- **掲載事項〔確認：公式PDFから抽出された図表の文字情報〕**：**図表269には「谷端川」と「弦巻川」がそれぞれ明記**され、図の凡例に**「河川」「河川（暗渠）」**がある。周辺の地名・施設名として**西池袋2丁目、目白3～5丁目、目白庭園、上り屋敷公園、西武池袋線**などが記載されている。**印刷p.210**には同地域の変遷、**p.211**には2011年度土地利用現況調査に基づく土地利用図もある。
- **判読上の制約〔未解決〕**：図表の**文字情報・凡例は確認**したが、**地図画像の線分・座標・図上の相互位置は独立に判読できていない**。したがって両河川の描線の正確な位置、分水界、交差・合流、現存管渠の配置、2015年当時の流路中心線はこの確認から確定できない。**2015年は計画策定年**で、両河川の開削・暗渠化・工事年ではない。2015年の都市計画上の表現と、近世・近代の河道復元を区別する。
