# [GOV-342] 市中取締類集[47]＋市中取締続類集[4] — 音羽町9ヶ町の名主行政（岡場所廃止後の音羽町の衰退の実務記録）〔第151回〕

- **書誌〔確認〕**: 『市中取締類集 [47]』（名主之部・嘉永6丑年〔1849〕の記録を含む・NDL次世代デジタルライブラリー [book/2572073](https://lab.ndl.go.jp/dl/book/2572073)）＋『市中取締続類集 [4]』（名主之部ノ四・嘉永七寅年七月〔1854〕・[book/2588531](https://lab.ndl.go.jp/dl/book/2588531)）。**同一の音羽町一件の嘉永6年分と嘉永7年分の追伸を含む姉妹冊のため同一ファイルに登録**。江戸町奉行所の名主行政の記録集（名主の任免・身元調査・支配替の伺・書付）。**引用文言はすべてOCR由来で要原文照合（草子系で崩れ大）**。
- **天保13寅年11月・名主源次郎の御取放＝音羽岡場所廃止に連動する行政実務記録〔確認・repo初出〕**: 嘉永6年丑四月の支配替願の伺書——「**護国寺領音羽町弐町目三町目四町目 右は音羽町弐町目ゟ九町目桜木町迄都合九ヶ町 元名主源次郎支配ニ御座候處 去ル天保十三寅年十一月中 名主役御取放相成 跡組合名主持ニ被仰付置候**」（2572073）＋身元調査書——「**去ル天保十三寅年十一月中 隠商女一件ニ付 源次郎義 名主役御取放二相成**」（2572073・同文の追伸は2588531で「**隠売女一件ニ而役儀御取放相成**」の表記）＝**①音羽町2〜9丁目桜木町の9ヶ町を支配した名主源次郎が、天保13年（1842）11月に「隠商女（隠売女）一件」で名主役を御取放（免職）となり、以後組合名主が持ち回りで町用を扱った、という行政実務の一次記録**。〔**音羽岡場所（飯盛女・岡女郎の集住地）の天保13年8月の引移し（廃止）＝[GAZ-070](../gazetteers/GAZ-070.md)（江都近郊名勝一覧の天保13年8月岡場所引移り記事）から3か月後の同年11月の名主免職として、岡場所廃止の町奉行側の行政処分の実務記録が初めて確認できた**（両者の直接の因果は本冊では明記されないため断定しないが、同年の月次の連動は観察として記録値がある）。岡場所廃止が音羽町支配体制の交代（名主の交代・組合支配への移行）を伴ったことの帳簿レベルの裏付け。〕
- **嘉永6年・音羽2〜4丁目の大塚上町名主への当分支配附＝岡場所廃止後の町の貧窮の実態〔確認・repo初出〕**: 同一件の願・伺——「**右九ヶ町之内弐町目三町目四町目 右三ヶ町之儀は 家主共困窮之者共ニ而 其日稼之者多分有之 内外差支候間 今般右三ヶ町ニ談之上 隣町小石川大塚上町名主常次郎え 当分之内支配ニ相附申度段 家主共并組合名主一同相願之地頭添朝差出申候**」（2572073）＋常次郎の身元（「**先代三十郎実忰ニ而 天保九戌年十二月ゟ名代勤仕罷在**」・丑32歳）＋「**右三ヶ町之儀は夫々貧窮二而 其日稼之者共多く**」（2588531の引照）＝**嘉永6年（1849）に音羽町2〜4丁目の家主たちが「困窮」「其日稼之者（日雇い労働者）が多い」ことを理由に、隣町の小石川大塚上町名主常次郎への「当分之内支配附」を願い出て認可された記録**。〔**岡場所廃止（1842）から7年後の嘉永6年時点で音羽町下側3ヶ町の家主層の貧窮と日雇い化が行政文書に明記されている＝岡場所廃止が音羽町の経済基盤に与えた影響の実務レベルの記録候補**（因果の断定はしない）。音羽町9ヶ町のうち2〜4丁目（下側＝水窪川沿いの低地側）のみが支配替の対象となった点は、町内の格差の観察資料。〕
- **嘉永7年・音羽5丁目外5ヶ町の見立名主願〔確認・文言候補〕**: 2588531（嘉永7寅年七月）——「**音羽町弐町目外八ヶ町 元名主源次郎義 去る天保十三寅年十一月中名主役御取放ニ相成 支配町々組合名主持之内 同所弐町目三町目四町目之儀は去丑四月中組合小石川大塚上町名主（常）次郎江当分支配附被仰付候跡 同五町（目外）五ケ町 此度町人共見立 同町六町目家持貞吉ト申当寅十八歳罷成候者…名主役被仰付被下置候様 町人共一同相願之申候**」＋貞吉の身元（「**小石川御箪笥町（善蔵）実子ニ而是迄蒙御咎候儀無御座**」・家屋敷「表問合間四間半長行問合間半有之家屋鋪壱ヶ所所持」候補）＝**嘉永7年（1854）に音羽町5丁目外5ヶ町の町人が6丁目の家持貞吉（18歳）を名主に見立て願出た記録**（願の認可の有無は本冊の伺・取調の範囲では最終文言未確認・要照合）。〔源次郎免職（1842）→2〜4丁目の大塚上町支配付（1849）→5丁目外5ヶ町の見立名主願（1854）という**音羽町9ヶ町の支配体制の再編の10年超の通時記録**。貞吉の実父が小石川箪笥町の名主層である点は音羽町の名主人材の近隣依存の観察資料。〕
- **月輪院・日輪院の「当院兼帯所護国寺領」の文言候補〔確認・文言候補〕**: 2572073の一件の連署に「**月輪院 飯市右衛門 喜多村彦右衛門 樽（樽？）藤左衛門 様 上 拾四番組名主共以書付申上候**」の近傍に「**月輪院・日輪院…当院兼帯所護国寺領**」の文言候補（OCR崩れ大・前後関係の復元は原画像照合が前提）。〔音羽町の組合（14番組）の名主詰に月輪院・日輪院（護国寺の兼帯所の院家候補）の文言が現れる可能性の存在記録（断定しない・原画像照合まで保留）。〕
