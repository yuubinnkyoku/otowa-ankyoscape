# [GOV-226] 東京市水道要覧（1893）— 千川上水の沿革条と改良水道（水源の多摩川統合）の根拠文言

- **書誌〔確認〕**: 東京市水道局編『**東京市水道要覧**』（明治26年・1893年・図入）。NDL次世代デジタルライブラリー [book/845988](https://lab.ndl.go.jp/dl/book/845988)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **千川上水条＝瑞賢計画説の官撰文言〔確認〕**: 「**千川上水。埼玉縣新坐郡保谷村ニ於テ玉川上水ヲ分派シ之ヲ巢鴨溜池ニ致ス沿渠各村ニ供給シテ市內ニ入リ本〓下谷ノ一部ニ給水ス開鑿ノ起リハ元祿年間ニシテ彼ノ河村瑞賢ノ計〓ニ係リ多摩郡仙川村ノ農民德兵衛太兵衛ノ兩人此工事ニ從ヒ元祿九年中其工竣ル然ルニ享保七年上水ヲ廢シ單ニ用水ト爲ス安永九年再ヒ之ヲ興シ本〓湯嶋下谷淺草等ニ給セシモ自後興廢一ナラス今ノ千川上水ハ明治十三年岩崎彌太郞等千川水道會社ヲ起シ舊渠ヲ修鑿セシモノナリ保谷新田分水口ヨリ巢鴨沈澄池ニ至ル其間水路五里餘露溝長百七十間樋管長三千七百間餘ニ達セリ**」〔**①開削の起りを元禄年間とし「**彼ノ河村瑞賢ノ計画**ニ係リ」＝河村瑞賢計画説を明治期の市の水道行政刊行物が採録（[BOOK-118](../books/BOOK-118.md)（1912・堀切彦四郎「河村瑞賢計画説」）に先行する1893年の公的書での瑞賢説文言）、②工事を多摩郡仙川村の徳兵衛・太兵衛の両人が従事し元禄9年に竣功、③享保7年に上水を廃して単に用水とし、④安永9年に再興し本郷・湯島・下谷・淺草等に給水、⑤明治13年に岩崎弥太郎等が千川水道会社を起し旧渠を修鑿、⑥保谷新田分水口〜巣鴨沈澄池の水路五里余・**露溝（無葢溝）170間・樋管3,700間余**の数値**＝千川上水の沿革・数値の1893年時点での公式整理〔数値は[GOV-173](GOV-173.md)（1891）と同系統で[GOV-228](GOV-228.md)（1894）の172間・3,707間と近似〕〕。
- **改良水道（多摩川水源統合）の根拠文言〔確認・repo初出の公式文言〕**: ①水源の項——「**現在ノ三上水中神田上水ノ如キハ汚水ノ混入ヲ免レス…其千川上水ノ如キハ固ヨリ玉川上水ノ一分派タリ是レ水源ヲ求ムルニ於テ多摩川ヲ取ル所以ナ**」＝**千川上水が「固より玉川上水の一分派」であることを、改良水道で水源を多摩川に統合する理由の第一として挙げた1893年時点の公式文言**。②効果の項——「**現在上水ハ外侵ノ汚物混入ヲ免レス神田千川兩上水ニ於テ殊ニ之ヲ見ル**」＝神田・千川両上水に特に汚物混入が見られたこと（＝両上水の水質問題が水源統合のもう一つの根拠）〔明治41年（1908）の神田・千川両上水の廃止・改良水道への統合に至る議論の、起点側の1893年公式文書での根拠表現として記録〕。
- **市中配水の「萬年樋」〔確認・語の汎用性の傍証〕**: 「**市內ノ配水ハ萬年樋及木極ヲ用ヒ井戶側モ固ヨリ木造ナルカ故ニ外水滲入ノ憂ナシトセス**」＝1893年時点で市内配水に「萬年樋」（＝通水樋の普通名詞用法）と木樋（OCR「木極」）が使われていた文言〔[GAZ-035](../gazetteers/GAZ-035.md)の桜木町「万年樋」（固有名として読める文脈）と[GOV-231](GOV-231.md)の室大下水「万年樋」に加え、**明治期の水道行政文書でも萬年樋が普通名詞として使われる用例**＝万年樋の語の性格を吟味する資料〕。
