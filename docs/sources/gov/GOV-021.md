# [GOV-021] 東京都文化財めぐり「小石川・雑司が谷を歩いてみませんか」

## 書誌・所在

- 東京都の文化財散策案内。公開・更新年月日はページ上で確認できず、2026年10月31日に本文を確認。
- 該当箇所：「鬼子母神大門ケヤキ並木」（都指定天然記念物、1940年4月18日指定）。
- 原ページ：https://www.syougai.metro.tokyo.lg.jp/bunkazai/week/koishikawa/

## 内容メモ

- 都電荒川線鬼子母神前駅から鬼子母神堂に向かう約100mの参道について、昭和10年代には大径木が19本あったと記す。
- 下水本管の敷設と道路整備に伴いケヤキが伐採され、ページの説明時点で古木は参道西側3本・東側1本になったと記す。伐採箇所への植え替えにも言及する。
- 下水本管の工事年・路線名・埋設位置・伐採本数の内訳は示していない。
