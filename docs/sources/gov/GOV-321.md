# [GOV-321] 警視庁史稿 下巻（1894）— 第三方面第四分署の所轄と新宿警察署への改組

- **書誌〔確認〕**: 『**警視庁史稿**』**下巻（巻之2〜巻之15）**（**1894**。NDL次世代デジタルライブラリー [book/785267](https://lab.ndl.go.jp/dl/book/785267)）。警視庁の沿革・各警察署の系統（位置・管轄・定員・交番所・署長）を記述した官庁史稿。**引用文言はOCR由来で原画像照合を要する（系統条の地字と役職名の列が交錯する箇所がある）**。

## ①新宿警察署系統条の第三方面第四分署記述〔確認文言・文言候補〕

- 「**位置…前ニ同 警視第三方面第四分署 前ニ同 ◎十一年十一月二日大小區畫ヲ廢シ區郡名稱區域ニ改ム 牛込區ノ内若松町外五ケ町 小石川區ノ内關口町 四ツ谷區ノ内永住町(側西?) 東多摩郡ノ内上高井戶村外三十一ヶ村**」＋「**十四年一月十四日再ヒ警視廳ヲ置キ方面區畫ヲ改定シ五方面ニ分チ警察署(並)巡査屯所及ヒ分屯所ヲ設ケ其二十九日配置ヲ定ム**」
- **意味〔確認・文言候補〕**: ①「兩上水取締」の達が宛てられた**第三方面第四分署（[GOV-314](GOV-314.md)・[GOV-315](GOV-315.md)③・[GOV-317](GOV-317.md)）は、後の新宿警察署の前身**で、明治11年11月2日の区域改め後の所轄は**牛込区若松町外5か町・小石川区関口町・四谷区（永住町付近か）・東多摩郡上高井戸村外31か村**と読める（文言候補・割付要照合）。②**小石川区関口町＝神田上水の取水地（関口の大洗堰・江戸川分派〔[GOV-297](GOV-297.md)・GAZ-048の関口の瀧等〕）**を所轄に含み、③**東多摩郡村々＝玉川上水の沿線郡部（境村等の取水許可〔[GOV-314](GOV-314.md)②〕）**を管轄した＝**兩上水（神田・玉川）の水源・幹線の治安を一手に握る分署だったことが、取締達の宛先としての行政的背景**〔観察〕。④**明治14年1月14日の警視庁再置で方面分署制は終了**し、警察署制（新宿警察署等）に改組＝**両上水の心得・番外が明治11〜13年の分署期の文書である**ことの制度史の位置づけ。
- **注意〔文言候補〕**: 所轄区域の列挙は系統条の割付崩れの恐れがあり、また近接する「南豐島郡ノ内内藤新宿三丁外六ケ町 角筈村外二十一ケ村 北豐島郡ノ内中里村外十一ケ村 荏原郡ノ内上北澤村外二十五ヶ村 合十七ヶ町九十二ヶ村」のブロックは**明治14年改組後の新宿警察署の管轄**に帰属する可能性が高い（どちらのブロックが分署期・警察署期の所轄かは原表照合まで確定しない）。

## ②人事記録の断片〔文言候補〕

- 「**十一年三月十六日第三方面第四分署長ニ轉ス**」（牛込系統条・諏訪(?)の転任）、「**第三方面第四分署長二等少警部山崎重應**」等の人事が散見＝**明治11年3月時点で同分署に分署長が在任**していたことの記録（氏名・前後の帰属は割付崩れで文言候補）。

## 制限・未解決

- ①所轄区域リストの2ブロックの帰属（分署期vs明治14年警察署期）。②「四ツ谷區ノ内永住町側西」の判読。③第三方面第四分署の署所位置の町名（「位置前ニ同」で省略されており原典では別途記載のはず・要照合）。④明治10年2月の警視本署化以前（警視廳期）の同分署の系統。
