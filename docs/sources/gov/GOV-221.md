# [GOV-221] 諸事留帳43巻[7] — 掃部橋の「惣水落名目無之」の先例言及

- **書誌〔確認〕**: 『諸事留帳』43巻[7]（文化13〔1816〕〜文政6〔1823〕年頃・御先例方（町奉行所の先例照査部門）の書留と思われる）。NDL次世代デジタルライブラリー [book/2548965](https://lab.ndl.go.jp/dl/book/2548965)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **掃部橋＝「惣水落と申名目無之」の先例言及〔確認・repo初出〕**: 橋の取扱（拙者共方＝御先例方かの管轄か）をめぐる協議の文脈で——「**水道町より西古川町え渡ル字掃部橋は惣水落ゟ申名目無之候間其御役所江訴出候儀二も可有之哉**」〔**①小日向水道町〜西古川町の掃部橋には「惣水落」という名目（＝惣下水・都市下水としての扱い）が無いこと、②それゆえ「其御役所」への訴え出の筋（下水扱いの投げ込みか）もあり得るかという協議であること**＝**掃部橋が「惣水落（下水）」ではなく神田上水（江戸川）に架かる「川橋」として扱われていたことの先例言及**。続く文脈に「**往還横切下水は町方持にても…**」「**上水悪水落候而小日向水道町ゟ同所西古川町江掛渡有之候橋右は前々ゟ拙者共方〔所管か〕**」があり、**掃部橋が上水（神田上水）の「悪水落」（上水から溢れる余水の落口）を伴う掛渡橋として、下水とは別系統で処理されていた**実務区分が読み取れる（文言の区切りはOCR崩れを含み、正確な管轄の帰属は要照合・断定しない）〕〔寛政3卯年（1791）の「御先役方江御懸合済」の先例参照文言あり＝この取扱論は寛政3年先例に基づく〕。
- **千駄ヶ谷町の「坂下川」〔観察・周辺情報（四河川スコープ外・ノート記録）〕**: 同協議の対比例として——「**千万ヶ谷町御配被成候処右は悪水落に有之候得共坂下川と唱金下水にも無之由町方之者申立候段被仰聞…**」「**千軒谷町橋之儀は悪水落橋には有之候得共坂下川え唱全み下水にも無之…**」〔**千駄ヶ谷町に「坂下川」と呼ばれる水路があり、千駄ヶ谷町の橋は「悪水落橋ではあるが坂下川と呼ばれ、（金看板の）下水でもない」という町方の申立て**＝**「坂下川」が千駄ヶ谷の水路名として文化〜文政期の行政文書に現れる記録（repo未収録語・渋谷川水系の支流名候補）**。四河川（水窪川・弦巻川・谷端川・千川）のスコープ外（渋谷川系）のため、本資料では掃部橋文言の対比例として記録し、坂下川の本格的な調査（渋谷川上流の宇田川・川研究会の系譜との関係）は次回以降の課題とする〕〔「千万ヶ谷」「千軒谷」は千駄ヶ谷のOCR崩れ〕。
