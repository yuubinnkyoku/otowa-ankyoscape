# [GOV-008] 谷端川南緑道

- 豊島区公式「谷端川南緑道」。
- https://www.city.toshima.lg.jp/340/shisetsu/koen/033.html
- 1962年の河川廃止、1966年以後の児童遊園・遊歩道化、1990年までの緑道整備を説明。
- **追記（2026-11-11 第20回・open_url直接確認。ページID 7285、更新日2015年2月25日）**：覆蓋上部の利用承認・開放は**昭和41年に谷端川第1から第3児童遊園、昭和42年に第4児童遊園、昭和55年に遊歩道**（いずれも都下水道局より承認）。**昭和58年から始まる施設改修整備は平成2年に終了**し、西武池袋線から川越街道に至る区間が現在の谷端川南緑道に。**緑道は幅4〜5メートル、面積8,885.72平方メートル、開園は平成3年4月**（住所: 西池袋4-5-5、最寄り: 椎名町駅・要町駅）。道路との交差点の欄干がかつての谷端川の橋を想起させるとの記述〔橋の記憶の公式叙述〕。
