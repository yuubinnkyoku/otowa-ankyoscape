# [GOV-048] 雑司が谷駅建設時の中世道路・薬研堀と弦巻川への坂（2012年館報）

- **資料〔確認〕**：豊島区立郷土資料館『かたりべ』第107号（**2012年10月16日発行**）、印刷**p.4**「鎌倉街道を歩いてみよう②『鎌倉街道を掘る』」（「豊島の遺跡」第11回）。[豊島区公式PDF](https://www.city.toshima.lg.jp/documents/2546/kataribe107.pdf)の**4頁目のページ画像を直接閲覧（2026年11月3日）**。本文に**A・B・Cの位置記号を付した「鎌倉街道推定ルートと高田宿」図**、発掘道路の上層堆積状態の写真・説明図がある。
- **中世道路〔確認：2012年館報が紹介する発掘調査の記述／発掘原報告書の図面・実測値は未照合〕**：東京地下鉄副都心線**雑司が谷駅建設に先立つ発掘**で、建設用地を横切り**南北に直線的に延びる約50mの中世道路（図中B）**が見つかったとする。最大幅は**約5.5m**。初期の路面は**幅3m弱で両側に側溝**があり、側溝が埋まるにつれて道幅が広がったと解説する。**13～15世紀の常滑・瀬戸などの陶器や中国産磁器の破片**の出土を記す。これらは**2012年時点の資料館記事による発掘成果の紹介**であり、道路の使用期間を遺物の年代だけから厳密に始終年まで決めない。
- **弦巻川へ下る坂と薬研堀〔確認：館報記事の発掘成果紹介／観察：図中Cの位置関係〕**：記事は、上記の道から北方へ進む想定線上、**弦巻川に下る坂道に沿って幅約4m・深さ約2mのV字断面の「薬研堀」（図中C）**が発掘されたと述べる。筆者は鎌倉・南北朝期にも用いられた溝形式を手掛かりに、鎌倉街道がこの堀に沿って北上し、**弦巻川を越えた可能性**を論じている。
- **重要な留保〔推定・仮説・未解決〕**：**薬研堀は道路脇の人工溝の遺構として紹介されており、弦巻川本流の河床・支流・暗渠管と同一視できない**。中世道路Bから薬研堀Cへ連続する道筋、さらに**弦巻川を渡った地点は記事筆者の推定**で、橋の橋台・橋名・渡河施設の発掘確認を示したものではない。**中世の道路・溝の存在は、1930年代の弦巻川暗渠化の工事年代を直接決めない**。発掘原報告書の調査区平面図・断面・遺構番号・層位・年代判定と、旧河道図・地籍図を照合する必要がある。
- **関連する地点〔確認・推定を区別〕**：記事は**宿坂（高田側から清戸道＝現目白通りへ上る道）**と鬼子母神堂西側の道、雑司が谷駅工事用地を位置づける。宿坂に沿う**道の両側の湧水を流す水路**に言及するが、これを中世の弦巻川本流と認定してはいない。宿坂・駅工区・薬研堀の位置関係は掲載概略図のA・B・Cで追えるものの、座標・標高は未取得。
