# [GOV-413] 『練馬区史 現勢資料編』年表（honcho1）〔repo初出・2026-11-19本文取得〕

- **書誌〔確認〕**: 『練馬区史 現勢資料編』（昭和55年3月刊）年表部分＝練馬区デジタルアーカイブ（www2.i-repository.net・[genseishiryohen_honcho1.xhtml](https://www2.i-repository.net/contents/myc/text_4genseishiryohen/genseishiryohen_honcho1.xhtml)）。第193回（2026-11-19）に本文xhtml直接取得。**年表は本文テキスト化済みで静止画表ではない。区史編さんによる二次資料（年表）レベルの記録として扱い、各項目の原典（区議会議事録・都広報等）との対照は未実施。**
- **千川上水・公共溝渠関係の年表項目〔確認・repo初出の年次確定群〕**:
  - **昭和18年（1943）9月1日**: 「**千川上水管理者に板橋区長指定**」〔千川上水の管理者が板橋区長に指定された（第二次大戦中の区制移行期）の記録。管理主体変遷の出発点〕
  - **昭和23年（1948）**: 「区議会，『**千川上水管理権移管に関する意見書・請願書**』を可決。東京都知事・東京都議会議長に提出」〔[GOV-075](GOV-075.md)①（上程10月11日）の年表側記録〕
  - **昭和25年（1950）**: 「区議会，『**千川暗渠工事に関する請願書**』を可決。東京都議会議長に提出」〔[GOV-075](GOV-075.md)②（昭和25年5月地元請願→7月28日都へ請願）の年表側記録〕
  - **昭和26年（1951）11月1日**: 「**千川上水の上水管理権を都建設局第４建設事務所に移管**」〔1948年意見書から3年後の管理権移管実現・移管先の都建設局第4建設事務所（練馬区を所管する建設事務所）の年次確定〕
  - **昭和27年（1952）3月26日**: 「**千川暗渠化工事，区内着手**」〔練馬区内の千川暗渠化着手の年月日（年表側）。[GOV-075](GOV-075.md)②意見書の「本年4月初旬着工」とのずれは併記管理〕
  - **昭和27年10月29日**: 「区議会，『**公共溝渠築造に関する意見書・請願書**』および『**千川上水暗渠工事に伴う排水溝設置についての意見書・請願書**』を可決。東京都知事，東京都議会議長に提出」〔[GOV-075](GOV-075.md)②④の年表側記録〕
  - **昭和28年（1953）**: 「**練馬区公共溝渠管理条例公布**」（同年「練馬区『特別区道』道路占用料等徴収条例公布」の別項あり）〔条例公布の年表側記録＝[GOV-412](GOV-412.md)の昭和28年7月23日条例第9号と整合〕
  - **昭和31年（1956）9月11日**: 「**千川の水，善福寺公園に引水（都，公園緑地部承認）**」〔千川上水の水が善福寺公園（杉並区・善福寺川沿いの都立公園）に引かれた1956年9月11日の記録＝千川の水の公園利用の年次確定〕
  - **昭和42年（1967）**: 「区内に初めて**下水道が入り使用開始**」〔練馬区の下水道の始まり（千川暗渠の排水溝併設要求〔GOV-075②〕から15年）〕
  - **昭和44年（1969）4月**: 「**千川管理事務が都北多摩建設事務所に移管**」〔管理主体が都建設局第4建設事務所（1951）から北多摩建設事務所に変遷〕
  - **昭和45年（1970）4月**: 「**都水道局，千川上水から取水中止**」〔都水道局の千川上水取水中止の年月〔1943年板橋区長指定→1951年都建設局→1969年北多摩→1970年取水中止という千川上水の管理・利用の終焉過程の年表〕
  - **昭和51年（1976）**: 「**千川の共同清掃実施**」〔武蔵野・保谷・練馬住民による共同清掃（[BLOG-113](../blogs/BLOG-113.md)の共同清掃年表の区史側記録）〕
- **グラントハイツ関連（honcho5の開発計画文書〔目撃確認〕）**: honcho5所収のグラントハイツ跡地開発計画に「石神井川の**田柄川下流河川改修が概成するまでの間（昭和57年度末まで）**放流する許容量を超える雨水に対しては，**暫定的に必要な調節池を設ける**」＝田柄川下流改修（石神井川）と暫定調節池の計画文言〔隣接河川だが千川上水系の戦後整備と同時期の区政資料〕。
- **honcho4所収の「第137表 河川水質調査結果（田柄川・緑地橋）」〔所在のみ〕**: 田柄川の水質調査の橋名として「**緑地橋**」が現れる〔田柄川（石神井川系）の橋名の所在記録のみ。四河川の橋名調査の対象外だが隣接水系で初見〕。
