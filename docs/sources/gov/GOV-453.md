# [GOV-453] 豊多摩郡千駄ヶ谷町現状調査 — 渋谷川放流の下水暗渠（昭和3年起工）の流路文言

- **書誌〔確認〕**: 『豊多摩郡千駄ヶ谷町現状調査』（東京市臨時市域**擴張部**編・[book/1900479](https://lab.ndl.go.jp/dl/book/1900479)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**千駄ヶ谷町（1932年渋谷区・代々幡区）冊**＝渋谷川上流（宇田川・千川系候補の流域）の町。
- **渋谷川放流の下水暗渠文言〔文言候補・本ファイルの核心〕**: 下水道事業概要章——「**本町ニ於テ目下工事中ノ下水道暗渠工事ハ代々幡町境界ニ端ヲ発シ明治神宮ノ（裏参道?）側ニ沿ヒ神宮裏参道下ヲ潜リ大字原宿及千駄ヶ谷境下ヲ通リ渋谷川ニ落ス**」＋「**（下水道）八（ノ?）工事ハ昭和三年起（工?）エシ、（昭和）年度完成ノ豫定ニシテ工費ハ起債ニヨラズ町費ヨリ支出セラレツヽアリ。既成延長一二三七間本年度完成五七三間ニシテ（昭和某年度?）**」＝**①1931年時点で千駄ヶ谷町の下水道暗渠が工事中、②その流路＝代々幡町境界起点→明治神宮側に沿い→神宮裏参道の下を潜り→大字原宿と千駄ヶ谷の境界の下を通→渋谷川へ放流、③昭和3年（1928）起工・町費支出（起債によらない）・既成延長1,237間＋本年度完成予定573間**〔**渋谷川（＝渋谷川上流＝宇田川・宮下川方面）への下水道の放流口の位置・時期の行政側一次文言候補。明治神宮裏参道下を潜り原宿・千駄ヶ谷境を通る暗渠のルート復元の基礎資料候補**（現代の神宮外苑〜原宿一帯の下水道幹線の前史）。渋谷川のどの位置に落ちたか（宇田川合流点との前後）は本文言からは特定できず断定しない（原画像照合・文字列は崩れ含み）。**弦巻川・水窪川の合流先の渋谷川水系の下水道史（[GOV-442](GOV-442.md)（落合町・施設ナシ）・[GOV-449](GOV-449.md)（野方町・将来展望文言）と並ぶ）の下流側の1931年の定点**。間（けん）単位の延長（1,237間≒2,247m）と[GOV-448](GOV-448.md)（中野町・メートル単位）との単位の違いも注記〕。
- **町勢図の「千川」ラベル〔文言候補・地図由来〕**: 巻頭の「東京市千駄ヶ谷町畧圖」中のラベル群に「**千川**」の文字列（「四谷區…千川德内町邸千駄（…）」のOCR連なり）＝**千駄ヶ谷町略図（1931年・縮尺1:25,000候補）に「千川」のラベルが存在することの文言候補**〔**千駄ヶ谷の地名由来の「千川村」説（千駄ヶ谷＝千川（ちのかわ）村に由来する説）との関係のほか、図上のどこに書かれたか（隣接地の表示・水路の表示か）の判別が OCRでは不能・原画像照合を要する。**仮に水路表示であれば千川（上水）の流路図資料になり得るが断定は一切しない（地図OCRの崩壊が甚だしい）**。対照表「千川上水」行・千駄ヶ谷地名関係の追加照合資料として記録**〕。
- **帳簿文言〔確認・OCR崩壊大〕**: 人口「**四〇、九〇〇人**」（昭和5年国勢調査）・面積「**七四一、七三〇坪**」・人口密度・財政・鉄道（中央線・山手線・代々木・原宿両駅）・学校等の帳簿＝1932年市域拡張直前の千駄ヶ谷町政の帳簿。
- **渋谷川の文言〔確認〕**: 上記のほか「**渋谷川ニ落ス**」の流路文言のみで「渋谷川」への他の言及は本冊fulltext走査限りで4件（同一の下水道文言群と他1件）。地理的・地勢的な渋谷川の叙述は本冊では見えず＝陰性。
