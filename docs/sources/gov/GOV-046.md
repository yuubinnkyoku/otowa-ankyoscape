# [GOV-046] 船河原橋付近の配水本管伏越替工事写真

- **資料〔確認：東京都水道歴史館の公開目録、2026年11月3日閲覧〕**：同館デジタルアーカイブ「[【工事写真】配水本管1800ミリ伏越替工事小石川区船河原橋](https://www.ro-da.jp/suidorekishida/content/detail/REKI-019-040)」、**資料ID REKI-019-040**、**ガラス乾板写真**、寸法**16.5×12.0cm**、地域・施設名「文京区」。
- **原目録の記載〔確認〕**：備考欄に**「六七二」**の文字と、原タイトル**「配水本管1800ミリ伏越替工事小石川区船河原橋 昭和9年（1934）7月10日」**が記載される。**1934年7月10日は原目録の題名に付された日付**であり、現段階で撮影日・着工日・竣工日のどれかは確定しない。
- **年代・制作主体〔確認：目録の表示〕**：別の制作年月日欄は**「大正時代～昭和前期」**と広く、制作者は**「東京市（水道局か）」**と留保される。公開日は**2025年12月16日**。原題の日付と制作年月日欄の粒度が異なることを保持する。
- **確認の限界〔未解決〕**：写真画像の細部は未判読。既知の**1933年6月30日「船河原橋際伏越工事」写真（P0114_027_03）**と同一工区・同一管・連続工程かは未確認。**配水本管は上水道の管路であり、谷端川・水窪川・弦巻川の暗渠や下水道幹線を撮影した証拠ではない**。
