# [GOV-210] 市中取締類集 [201] 河岸地調之部（嘉永3）— 千川屋敷上納地の請負替と太兵衛の由緒

- **書誌〔確認〕**: 『**市中取締類集**』の内、嘉永3戌年（1850）の**河岸地調之部**（目録番号[201]）。NDL次世代デジタルライブラリー [book/2572227](https://lab.ndl.go.jp/dl/book/2572227)。千川家（千川屋敷）関係では[GOV-175](GOV-175.md)（上水番等之部）の兄弟巻に当たる。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **嘉永3年（1850）5月の千川屋敷上納地の請負替願〔確認・千川家の後期の一次記録〕**: 「**嘉永三年五月 小石川白山前町 千川屋敷上納地請負人 小網町壱町目家主宇兵衛 請負御免願 跡請負之儀に付調（戌五月十日 従兵衛を以御渡し）**」——宇兵衛願「**私元祖太兵衛儀は 元禄九子年中 小石川御殿え 御上水御普請御用を被仰付…上保谷新田ゟ玉川御上水を分け 字千川上水と唱 新規開発仕 上水無滞 掛渡 御普請出来仕候**…（中略）**然る処近年病身に罷り候に付 右御地所内に罷り在候 三左衛門儀は 私甥に而当戌三拾七才に罷り候 身元慥成者に付 右御地所跡 御受負被仰付被下置候様奉願上候**」＋連判（嘉永3戌年4月29日・請負人宇兵衛・**小石川白山前町千川屋敷与兵衛地借・譲受人三左衛門**・家主与兵衛・証人神田明神下御台所町治兵衛地借茂七ら）〔**①千川屋敷上納地の請負人・小網町1丁目家主宇兵衛が病身で請負御免を願い、②同じ屋敷内に住む甥の三左衛門（嘉永3年時点37才）が跡を受負った一件、③証人は神田明神下御台所町の治兵衛地借茂七**＝千川家の請負の嘉永3年の継承記録〕〔白山前町側の家主「与兵衛」と地借「三左衛門」の関係、「千川屋敷与兵衛地借」「千兵衛地借」等の表記の揺れ（OCR）は原文照合課題〕。
- **御受貢の条件〔確認〕**: 「**御受貢壱ヶ年金拾壱両 伯父宇兵衛上納仕来候通り 両度に割合 七月・十二月十日限 金五両弐分ツヽ 無滞先上納可仕候**」〔**上納地の年貢（御受貢）は年11両、7月と12月の2回に分けて各5両2分を上納**＝千川屋敷が拝領地から上納地（御受貢地）へ転換された後の負担額の一次文言〕。
- **元祖太兵衛の由緒申告（素堀区間の両端の文言を含む）〔確認・千川上水の開削方式の最詳級の文言〕**: 宇兵衛願——「**右上保谷新田ゟ巣鴨村 素堀之場所 凡五里弐拾四町余之処 堀筋見立 御普請取掛申候処 被下置候御金高にしては 素堀御普請出来兼申候に付 此段奉願上候処 急御用に有之間 如何様にも取計 普請成就仕候様被仰付候に付 自分入用金四百八拾両余 差出 素堀（野方素堀・OCRの原字形要照合）出来仕 夫より御用之御場所江 埋樋に而 無滞 上水掛渡仕 普請皆出来成就仕候 依て右勤功に 千川上水元役を被仰付 并びに其節住居之場所に而 千川屋敷と唱候場所 表間口（田舎間）拾五間五尺 裏行北之方拾壱間壱尺余 南之方拾九間三尺 裏幅拾四間弐尺余之町屋敷壱ヶ所 拝領被仰付…正徳四午年（OCRの干支は要照合） 御殿御不用に相成候間 右屋敷拝領仕**」〔**①千川上水の素堀（開渠）区間が「保谷新田〜巣鴨村」で凡そ5里24町余（約22km）、②幕府から下された御金高では素堀普請が出来かねたため太兵衛が私費482両余を投じて完成、③素堀区間から先は「埋樋」で上水を掛け渡した、④功により千川上水の元役に任じられ千川屋敷（表間口15間5尺・裏行北11間1尺余・南19間3尺・裏幅14間2尺余）を拝領、⑤正徳4年（1714）御殿が不用になり屋敷拝領**＝**開渠（素堀）と伏樋（埋樋）の区区分け・区間長（5里24町余）・千川屋敷の寸法の最詳級の文言（素堀区間の両端〔保谷新田〜巣鴨村〕の特定はrepo初出の情報）**。「野方素堀」の「野方」は「おおかた（概ね）」等の読みの可能性もあり原字形照合まで解釈保留。482両余と[GAZ-034](../gazetteers/GAZ-034.md)由緒書の482両1分の対立は並記〕。
- **天保14卯年（1843）の橋普請・上納の免除と拝領地取上げ〔確認・千川家負担の終焉の文言〕**: 遠山左衛門尉（町奉行・遠山景元か・OCR「遠山菅尉」「遠左衛門尉」等）の書付／宇兵衛願——「**明和五子年（OCRの干支は要照合） 右橋 御普請方持に相成 六ヶ所之内弐ヶ所減切に成（其代りとして年々銭拾七貫文宛 上水吹所人足為賃銭 上納仕来候処）天保十四卯年七月廿九日 御普請方御役所におゐて 橋普請并びに上納銭共 差免 拝領地之儀は取上に相成候段 被仰渡候 同年八月九日 当御番所様より 右町之地代 見合相応之地代を相納候様被仰渡 是迄金拾壱両ヲ両度に金五両弐分宛上納仕 御受負被仰付**」＋「**去る卯年三月（天保14年3月） 御普請方持 水道番其外 町人共身分之儀は 私共進退に相改候様 水野越前守殿（＝水野忠邦）被仰渡**」〔**①明和5年（1768）に橋6ヶ所の内2ヶ所減免・代りに銭17貫文/年上納（[GAZ-034](../gazetteers/GAZ-034.md)と整合）、②天保14卯年7月29日に御普請方役所で橋普請と上納銭の双方が免除され、拝領地（千川屋敷）が取上げの上、地代（年11両・2回各5両2分）を納める上納地になったこと、その同年8月9日の番所からの申し渡し、③天保14年3月の水野越前守（水野忠邦）による水道番・町人身分の改革の申し渡しが契機だったこと**＝**千川家の元禄9年からの負担（橋普請・水料金・上納銭）が天保14年の上知令の一環として終わり、千川屋敷が上納地に転換された過程の一次文言（repo初出）**〕。
- **根津側の橋の文言〔確認・千川家の橋の位置資料〕**: 遠山書付——「**一本橋之儀は 根津宮永町ゟ同所惣門え渡候橋 宮永町西裏通ゟ根津門前町え渡橋（堀端）同所ゟ（谷中通り渡橋）同所より（善光寺前町渡候橋）…都合四橋に有之候**」〔**明和5年減免後の残り4橋の位置が①根津宮永町→同所惣門、②宮永町西裏通→根津門前町（堀端）、③同所→谷中通り、④同所→善光寺前町であること**＝**千川家が修復負担した橋がすべて根津・谷中側（千川上水の下流部・根津惣門周辺）にあったことを конкретно示す文言**（[GOV-171](GOV-171.md)・[GAZ-034](../gazetteers/GAZ-034.md)の千川上水の下流域＝本郷・根津・谷中方面の流路と整合）。橋名はこの書付にはない〕〔本書と同一事件の年番取扱側の写し＝[GOV-211](GOV-211.md)に同内容の文言がある〕。
- **位置づけ〔観察〕**: ①元禄9年（[GAZ-034](../gazetteers/GAZ-034.md)・[GOV-208](GOV-208.md)）→正徳4年→享保年中→明和5年→天保14年→嘉永3年の千川家の負担・屋敷の変遷の全体像が、[GAZ-034](../gazetteers/GAZ-034.md)（文政9年・金七側）と本書（嘉永3年・宇兵衛側）・[GOV-211](GOV-211.md)・[GOV-212](GOV-212.md)の4資料でほぼつながる。②天保14年3月の水野忠邦による身分改正が、上水請負人の特権（冥加負担と引き換えの拝領地無役）を解消した契機であることは、天保の改革研究の文脈でも位置づけられる（ここでは記録の列挙にとどめる）。
