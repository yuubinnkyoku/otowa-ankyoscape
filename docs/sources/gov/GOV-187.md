# [GOV-187] 常務委員会議事速記録 第7号（1938年）— 「等大路第一類第十四號路線、即チ千川筋ノ道路」

- **書誌〔確認〕**: 都市計画東京地方委員会『常務委員会議事速記録 第7号』（昭和13年）。NDL次世代デジタルライブラリー [book/1207593](https://lab.ndl.go.jp/dl/book/1207593)。**すべての引用は同館OCRテキスト由来であり、文言・町名・数値は原文画像との照合を要する。**
- **千川筋街路の路線番号特定〔確認・repo初出〕**: 幹事説明の文言＝「**等大路第一類第十四號路線、即チ千川筋ノ道路**」「**竹早町ノ電車通ヲ起點ト致シマシテ、久堅町、白山御殿町、（帝大ノ植物園ノアリマス下ノ方）指ケ谷町、本〓區ノ駒込蓬萊町ヲ經過致シマシテ、駒込千駄木町ノ根津神社ノアリマス附近ノ電車通マデ參リマスル幅員八間ノ環狀系ノ路線**」＝**千川筋の街路が都市計画道路の一等大路第一類第十四号路線であることの路線番号特定**。執行者＝東京市長。〔[GOV-180](GOV-180.md)（「千川筋ノ街路」速成事業）・[GOV-178](GOV-178.md)（千川上水線緑道）の路線の計画上の位置づけを初めて番号レベルで固定する文言〕〔文言はOCR要照合〕。
- **路線変更（江戸川橋方）の理由〔確認〕**: 久堅町地内の共同印刷株式会社の工場2棟（主要建物＝鉄筋コンクリート造）が道路敷に掛かるため、主要建物を避けて経費節約＋在来道路利用に変更。「**僅カノ變更ニ依リ一萬坪餘リノ土地買收ト家屋移轉トヲ免レマシタ**」＝経費約9万7千円節約の理由説明。小石川植物園内の「**ミヅキ**」の保存（「**帝大ノ農學部カラ平等ニ大事ニスベシト云フコトニナツテ居マス**」＝明治32年以来の吸水試験継続・外国専門家来訪時も重要視）のため路線が植物園側に掛からない配置。千川筋の道路に「**循環式ノ交通整理ニ適シマスヤウナ廣場**」を設置する変更理由。〔数値・樹種名・文言はOCR要照合〕。
- **位置づけ〔観察〕**: 千川筋＝音羽〜小石川谷頭の低地（水窪川・弦巻川に隣接する谷筋）を環状街路として計画していた1938年時点の委員会記録。[ORG-001](../orgs/ORG-001.md)（共同印刷小石川工場）と小石川植物園が千川筋街路の位置決定要因になった第一次記録。第47号補助線（[GOV-192](GOV-192.md)）と番号体系を異にする。

## 制限・未解決

- ①OCRで町名・人名の判読混乱（「久堅町地内ノ二久堅町」等）があり、経由町名の正確な列挙は要照合。②「千川筋ノ道路」の全延長のうち千川（旧千川上水・弦巻川谷筋）に沿う区間の特定は地図参照文言のみで未確定。③「みづき」の樹種表記はOCRカナ（ミズキ＝水木の可能性）で要照合。④循環式交通広場の設置位置は本文では特定できない。
