# [GOV-005] 長崎村外三村分水 → 谷端川

- 練馬わがまち資料館「千川上水の分水を訪ねて（2）」。
- https://www.nerima-archives.jp/column/3572/
- 要町3丁目付近から南東へ分かれ、粟島神社の池を水源とする谷端川へつながった「長崎村外三村分水」を説明。明治10年文書の「長崎村、中丸村、池袋村、金井窪村四ケ村用水」も紹介する。

## 本文全文確認（2026-11-12、Wayback Machine 2024-12-01スナップショットで取得・ai）

- **書誌〔確認〕**: [GOV-068](GOV-068.md)（分水を訪ねて（1））の続き。ねりま区報（昭和61年4月21日号〜63年7月21日号連載「ねりまの川」、北沢邦彦）の再録で、当該回の区報発行日は本文からは特定できず〔未解決〕。2026-11-12時点で当該サイトは直アクセス不可のため、[Wayback Machine 2024-12-01スナップショット](https://web.archive.org/web/20241201193511/https://www.nerima-archives.jp/column/3572/)で全文確認。
- **中新井村分水〔確認〕**: 宝永4年（1707）から分水があったが、江戸期の位置は「謎のまま」と記す。**明治10年7月「千川用水組合村樋口伏替願」**に、字上新街（中村と豊玉の境に取入口）・字下新街（**豊玉上2-20**に取入口）・字北新井（**豊玉上1-26・武蔵大学内**に取入口）の3か所が記載。明治17年11月の「千川上水絵図」にいずれも「中新井村用水」と描かれる。
  - **上新街分水は現学田公園一帯の池（中新井の池）に導かれ、この池は中新井川の原流**。明和8年（1771）の「江古田村鑑帳」にすでに「旱損」とあり、これを補うため千川上水から引いたと伝えられる〔千川分水=自然河川源頭への補水という設計思想（[GOV-068](GOV-068.md)）を中新井川でも裏付ける〕。
  - 下新街分水は豊玉北2-17の市杵島神社境内の湧水池から流れ出す水路に接続。
  - **北新井分水は武蔵大学内を通り、その水路跡を同学が泉水として復元したものが「濯川」**〔[ORG-018](../org/ORG-018.md)・[ORG-019](../org/ORG-019.md)・[ORG-020](../org/ORG-020.md)の濯川=中新井分水説の初出の書き言葉資料〕。
  - このほか豊玉地域に、現練馬消防署北側の水車の流末と思われる水路が南へ流れ、三の橋庚申（豊玉中3-16）東側付近で、現練馬郵便局南側の池から流れ出た小川と合流するなど、**文献に見られない水路（現在はすべて暗渠）**があったと記す〔役割は調査の必要ありと明記〕。
- **下練馬村分水〔確認〕**: 栄町15付近（環状七号線脇）から北へ羽沢-桜台境を石神井川へ向かった分水。宝永4年からあったが当時と同位置かは不明。明治17年頃「千川上水路図」に「下練馬村用水」。羽沢二丁目から下流は自然の谷を利用。
- **江古田村分水〔確認〕**: 旭丘1-18付近から南西へ、妙正寺川沿いの江古田村（現中野区）の水田へ。**寛政6年（1794）「千川養水路之件書類」に「江古田村田養水」**。明治17年絵図に「江古田村用水」、現在も一部路地状。
- **葛ケ谷村分水〔確認〕**: **豊島区南長崎6-9、千川上水が北に曲折する位置**から南東へ分水し、妙正寺川沿いの葛ケ谷村（現新宿区）の水田へ。寛政6年文書にもある古い水路で、明治17年絵図に「葛ケ谷村用水」。目白通り付近から南に自然の谷があり、現在も一部緑道。〔南長崎6-9=千川上水北曲折点の位置具体化。BLOG-064の南長崎支流・エンガ堀（[BLOG-103](../blogs/BLOG-103.md)）付近の水系復元の史料〕
- **長崎村外三村分水=谷端川〔確認〕**: 要町3-45付近から南東へ分水、要町2-41の粟島神社境内池を水源とする谷端川に接続。明治10年7月樋口伏替願に「長崎村、中丸村、池袋村、金井窪村四ケ村用水」。谷端川は現在、道路下暗渠やコンクリート蓋掛けとなり遊び場・遊歩道に利用。
- **そのほか〔確認〕**: 明治17年絵図には「滝ノ川村用水」「巣鴨村用水」も描かれるが、現状はいずれも不明。
- **写真資料〔確認〕**: 昭和38年・中新井村分水（右）と中村分水（左）の合流点（現学田公園西側）須藤亮作氏提供写真を掲載。
- **備考〔確認〕**: 中新井川は現在、中野区境の下徳殿橋まで暗渠・緑道。橋の名前は「徳殿橋」だが交差点名・地図表記は「徳田橋」。
