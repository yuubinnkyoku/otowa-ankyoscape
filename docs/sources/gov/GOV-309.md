# [GOV-309] 『町会所一件書留』寛政六年上（写）— 湯島側町方の帳簿に見える「千川上水出銀」

- **書誌〔確認〕**: 『**町会所一件書留**』[9]（**八 寛政六寅年（1794）弐冊ノ内上・写本**）。NDL次世代デジタルライブラリー [book/2587073](https://lab.ndl.go.jp/dl/book/2587073)。寛政6年の町会所一件書留（江戸の町会所・町奉行所あての町方の願・風聞書留の写）で、本冊には湯島三組町（湯島拝領町屋敷＝御小人・御駕籠之者の拝領町屋敷の三組町）の町入用・積金関係の書留が含まれる。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①「千川上水出銀」＝湯島側町方の負担の帳簿記録〔確認文言・repo初出級の受益側実務記録〕**: 「**町內役人共心得違二而千川上水出銀組入書出候ニ付此銀積金之上納被仰付…然る処御仁恵之思召を以千川上水出銀之儀は相除候様被仰渡候**」＝**①町内役人共が（町入用の書出の際に）千川上水の出銀を組入れて書き出したため、この銀の積金の上納が仰付けられ、町役人共が度々免除を願い出たところ、御仁恵により千川上水出銀の儀は相除くよう仰渡された、という経緯**。湯島三組町（湯島の拝領町屋敷の町）の町入用・七分積金の書出の中に「千川上水出銀」が実在の負担項目として現れる。〔**千川上水の請負・水銭制度の受益側（湯島の町方）の実務帳簿記録として、[GAZ-049](../gazetteers/GAZ-049.md)⑩-⑪（湯島区間の埋中樋の町別延長・桝）・[GOV-224](GOV-224.md)〜[GOV-218](GOV-218.md)（中流の町方書上）と対になる下流側の町方の一次記録**。天明6年（1786）差止・天明7年4月取潰し（[GAZ-049](../gazetteers/GAZ-049.md)①⑪）から数年後の寛政期に「千川上水出銀」が町の帳簿に残る点の解釈（水銭の残務整理か負担名目の残存か）は本書留だけでは断定しない〕。
- **②「千川上水水銀之分」の引除の年月〔確認文言・年月の特定〕**: 「**減金之内…九兩拾匁餘千川上水水銀（＝水銭のOCR崩れ候補）之分去々子年二月中相願同三月願之通引除被仰付候由**」＝**町入用減高中の九両拾匁余が「千川上水水銭之分」で、去々子年（寛政4年・1792）2月に相願し同年3月に願の通り引除が仰付けられた由**。〔千川上水の水銭負担分が年額九両十匁余という金額の規模と、寛政4年3月の引除という年月の記録。「水銀」は「水錢」のOCR崩れと読む（原字形照合を要する）。「去々子年」は寛政6年から遡って寛政4年壬子（1792）〕。
- **③同書留の前後の文脈〔確認・内容メモ〕**: 本冊の湯島三組町関係の書留は、度々の類焼で地主（小給の者）が貸家を補理できず明地が多いこと、町方御改正で七分積金（地主7分・家守3分の積金）の書出が命じられたこと、その書出の中での減金・引除の交渉などを記す。千川上水出銀はこの町の財務の書類の中の項目として現れる。

## 制限・未解決

- ①「千川上水水銀之分」の「水銀」は「水錢（水銭）」のOCR崩れの候補で、原字形照合まで確定しない。②「去々子年」＝寛政4年（1792）の読み（寛政6年寅年から2年前の子年）。③天明期差止後の寛政期の「千川上水出銀」の性格（水銭の残務整理か名目の残存か安永〜天明期の滞納の処理か）は本書留だけでは特定できない。④本冊は写本で、原本の所在・町会所文書群の中の位置づけは未確認。⑤湯島三組町の3町の具体的な町名の割り当ては原画像照合を要する。
