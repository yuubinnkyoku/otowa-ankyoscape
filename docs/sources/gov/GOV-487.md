# [GOV-487] 東京都建設局『善福寺公園マネジメントプラン』〔repo初出・善福寺川源流の都立公園本体の管理計画書〕

- **書誌〔確認: PDF本文・2026-11-21取得〕**: 東京都建設局『善福寺公園マネジメントプラン』（**令和8年〔2026〕3月**・16頁）。URL末尾 `080326kbetsumpzenpukuji` で第242回がCDXで発掘した別版候補2点のうちの一つ。正式ホスト（kensetsu.metro.tokyo.lg.jp）はJSチャレンジで本文不達のため、Wayback `id_` URL（2026-10-29スナップ・3,823,714B）で取得。**善福寺川上流地下調節池の文書ではなく、都立善福寺公園（杉並区善福寺二・三丁目・善福寺池＝善福寺川源流）自体の公園別マネジメントプラン**。
- **都市計画・開園の数値〔確認: Ⅰ.1〜2〕**: **東京都市計画公園第7・5・13号善福寺公園**（位置＝杉並区善福寺二・三丁目各地内・面積10.89ha・種別＝特殊公園・風致）・**決定告示＝昭和32年12月21日建設省告示第1689号**・**開園＝昭和36年6月16日**（当初は上の池の周囲4.8ha）・**開園面積80,264.47㎡（令和7年11月1日現在）**。主な公園施設＝管理事務所・子供広場・ボート場・ゲートボール場・**上の池・下の池**。
- **善福寺池＝武蔵野三大湧水池〔確認: Ⅰ.4・Ⅰ.6・repo初出の文言群〕**: ①「かつて**武蔵野三大湧水池の一つ**であった善福寺池を中心にした池と樹林地の公園」②「昭和5年10月に『**善福寺風致地区**』に指定」③「上の池は、武蔵野三大湧水池の一つに数えられ、その**水量が豊富で江戸時代の神田用水の補助水源として利用されたと言われており**、下流の善福寺川の源流であった」④「**現在は湧水が枯渇してしまい、井戸水の汲み上げにより池の補給水としている**」⑤「**池の地盤は周辺の地盤から低く、大雨の後には法尻から湧水があることがある**」＝都（管理側）が「恒常湧水は枯渇・大雨後のみ法尻から湧出」と公式文言化〔③の「神田用水の補助水源」は千川上水・神田上水史、⑤は〔BLOG-130〕2026年長雨の湧き水復活報道と接続する都側メカニズム文言〕。
- **「遅の井」〔確認: Ⅰ.6.3・repo初出〕**: 善福寺池の湧水のひとつ。言い伝えとして**文治5年（1189年）、源頼朝が奥州征伐の途中この地で飲料水を求めて掘った・弓の「はず」で7度目に湧出・「今や遅し」と待ったことから「遅の井」と命名**。**「現在では泉が涸れてしまっているため井戸を掘り、ポンプで汲み上げ、遅の井の滝として復元している」**＝遅の井の滝が人為的な井戸水循環である公式文言。
- **沿革〔確認: Ⅳ・年月と項目・文言対応は抽出上ずれあり＝human目視で要突き合わせ〕**: 昭和5年10月風致地区指定→昭和32年12月告示第1689号で都市計画決定→昭和36年6月上の池周囲4.8ha開園（ボート場を善福寺風致協会へ管理許可）→昭和39年8月上の池水面部分と下の池大部分1.9ha追加→昭和50年6月下の池南端0.4ha追加→昭和54年6月頃上の池北端運動広場・下の池河川沿い0.6ha追加→以後694㎡・963㎡単位の追加→平成18年4月・平成30年4月の項目あり。
- **整備計画〔確認: Ⅰ.7〕**: 「都市計画公園・緑地の整備方針（令和2年7月改定）」の**優先整備区域「事業促進区域」800㎡（杉並区善福寺二丁目）を令和11年度までに事業化**。計画区域に未供用区域が残る。
- **自然環境〔確認: Ⅰ.5・Ⅰ.6〕**: 善福寺池にゴイサギ・カモ・カイツブリ・カワセミ、下の池にアシの群生、この地域は**杉並区内で最もコケ類が多く生育**（大気汚染に弱いとされるコケ類）・風致地区内の第1種低層住居専用地域・東京女子大学・杉並工業高校が近隣・公園上の池地区と下の池地区の中央を貫く道路（青梅街道から南善福寺方面）が分断要素・**公園東側に外環道路が通る予定**。
- **意義〔観察〕**: ①repo初出の「**遅の井**」名称・源頼朝伝承・滝の人工復元文言、②「神田用水の補助水源」文言〔[GOV-486](GOV-486.md)が引用した善福寺川=神田川合流の系統より上流側の接続〕、③**大雨後の法尻湧水**という条件付き湧水機構の都側文言は[BLOG-130](../blogs/BLOG-130.md)（2026年長雨の湧き水復活・井の頭公園の武蔵野台地湧水機構言及）と裏面関係、④都立善福寺川緑地（調節池発進立坑〔[GOV-485](GOV-485.md)〕）と都立善福寺公園（善福寺池）が**別公園**であることの確認＝善福寺川の水源管理と治水施設の位置関係整理に寄与。
- **制限・未解決**: ①抽出はかな・一部漢字欠落を含む＝沿革表の年月と項目の対応はずれの可能性がありhuman目視で要照合。②「武蔵野三大湧水池」の他の2か所（井の頭池・池尻?）の同時文言は本文になし。③「神田用水の補助水源」の出典・時期は本文に説明なし（江戸時代と「言われており」の伝聞文言）。
