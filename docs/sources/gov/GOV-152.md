# [GOV-152] 紙の博物館「製品関係書類」— 明治33～43年期「石神井川下用水ニ関スル契約書」を含む文書群〔repo初出〕

- **書誌〔確認: 紙の博物館収蔵品データベース（jmapps）・2026-11-15〕**: 「**製品関係書類**」（収蔵ID:953・[詳細レコード](https://jmapps.ne.jp/kamihaku/det.html?data_id=953)）。資料種類**文書**、作者**製紙会社**、年代欄**明治11～15年（1878-1882）**、寸法30×22mm、**139点の画像がデータベース上で公開**（data_id=3535からの個別画像・キャプションなし・「ビューアでみる」「PDFで表示」機能つき）。キーワード検索「石神井川」（AND条件）で [GOV-150](GOV-150.md)（収蔵ID:945）とともにヒットした2件のうちの1件。
- **内容〔確認: 収蔵DBの解説欄〕**: 解説の列挙は「有恒社往復文書、1870年万国製紙場統計表、明治12年三田製紙所往復文書、製品相場表印刷用紙、包装用紙、大阪製紙所製品見本直段書、明治11年12月筆記用印刷用洋紙、横浜港取引相場表、**明治33～43年期石神井川下用水ニ関スル契約書**、連合製紙会社ト柏原洋紙店ト契約スル要領、その他売買領収証」。**多様な製紙会社文書の寄せ集め（外題「製品関係書類」）で、その中に「石神井川下用水ニ関スル契約書」が含まれる**。
- **意義〔観察〕**: ①「**石神井川下用水**」は、千川用水（王子分水）の流末が石神井川へ落とされた系統（[BLOG-228](../blogs/BLOG-228.md)の北区史引用「分水された千川上水の一部は石神井川に流下」・[BLOG-230](../blogs/BLOG-230.md)の掛桶渡し・[GOV-150](GOV-150.md)の明治23年石神井川水利組合条例）を指す語として、**明治33～43年期（1900-1910）の契約書という一次文書の形で現れる**。明治7-8年の水利権設定（GOV-150）から四半世紀以上後の**20世紀初頭まで用水の契約関係が更新され続けていた**ことを示す所在記録。②当契約書の**当事者・条件・対象区間は画像判読まで確認できない**が、[MAP-163](../maps/MAP-163.md)（明治38年・千川上水使用権利詳細平面図＝1905年）が明治33～43年期の中央（1905年）に位置することから、**同時期の権利関係図面（MAP-163）と契約書（本資料）の照合**が次回の判読課題になる。
- **注意〔観察〕**: レコードの年代欄「明治11～15年」は一群の文書の代表年代であり、解説に挙げられる明治33～43年期の契約書・「1870年万国製紙場統計表」など**個別文書の作成年とは食い違う**。契約書の正確な年・当事者は画像判読・目録原本の確認まで確定しない。
