# [GOV-133] 豊島区「わが街ひすとりぃ 第13回 巣鴨 現地ロケ編」

- **書誌〔確認: ADEAC目録・全文テキスト取得〕**: 豊島区デジタル区史「としまひすとりぃ」広報番組。**収録日 令和元年5月29日、制作 令和元年8月、収録時間14分40秒**。出演: **尾崎和子・秋山信行**。[ADEAC目録ページ](https://adeac.jp/toshima-history/catalog/mp00001310)、[現地ロケ編全文テキスト（ht420130）](https://adeac.jp/toshima-history/texthtml/d000000/mp00001310/ht420130)。
- **谷戸川→谷田川→藍染川の流路証言〔確認: 全文テキストの直接引用〕**: 秋山氏が染井霊園の周囲で「**ここで通りがこう下がって行って、一番低くなっているところに川が流れていたんです。それが谷戸川。それが谷田川に。谷田橋がありますから。そこらへんは谷田川だし。その先は藍染川っていう名前です。**」と、**同一水路の区間別呼称（谷戸川→谷田川→藍染川）**を実地の地形（通りが下る最低部）とともに説明する。続けて「**谷田川っていうのが湧き水としてあったわけですので、やっぱり高台だったわけですよね。豊島区も高台の街だから、川筋に沿って発展しているのではなくて、尾根筋の街道に沿って発展していった街**」と集落立地の説明を行う〔湧水源の川としての谷田川理解。出演者の秋山信行氏は[BLOG-092](../blogs/BLOG-092.md)（滝野川探検隊「千川上水とは」寄稿者）と同名だが、同一人物であることの確認は本文になく推定として扱う〕。
- **「長池」湧水池〔確認: 全文テキストの直接引用〕**: 同じ秋山氏の証言に「**今、自転車が来ているあたりに長池っていう湧き水の池があって、明治時代の地図ですと湿地になってる。円になってるんですね。**」がある〔**染井霊園周辺（慈眼寺・芥川龍之介墓・谷崎潤一郎墓付近）の湧水池「長池」の存在と、明治期地図での湿地（円形図形）としての描写**。参照された明治期地図の書誌は特定されていない〕。また霊園内の大きな桜について「**この……谷田川の川沿いなんです。その土手の桜です。**」と補足する〔確認〕。
- **朝日ほのぼのランドのホタル〔確認: 全文テキスト〕**: 朝日ほのぼのランド（巣鴨）の池で管理人が「**これからですね、夜になるとホタルが出るんですよ。**」と案内し、秋山氏が「**カワニナがいるという。**」「井戸水でホタルの幼虫を育てて、夜になるとホタルが、今は出てくるわけですね。」と説明、尾崎氏と秋山氏が5～6年前（2010年代前半）に夜間観察した旨を語る〔**巣鴨の市街地に現在もあるホタル生息施設の一次記録。井戸水・カワニナ・稲作体験（バケツ稲）を含む水環境の現況。ただしホタルは放流・飼育個体であり、自然湧水への依存は説明されていない〕。

## 制限・未解決

- ①本資料の川筋は**谷田川（谷戸川・藍染川）系**であって、本repoの四河川ではない。ただし**巣鴨の谷端川と谷田川に挟まれた枝状谷**（[ORG-009](../org/ORG-009.md)）の一方の水系について、区公式映像レベルで流路認識・湧水構造が記録される意義はある。②「長池」の位置は「自転車が来ているあたり」という現場指示で、座標・現況（埋立て・残存）は未確認。明治期地図の書誌未特定。③谷戸川→谷田川→藍染川の区間境界・呼称の年代変化は本証言では確定しない。④秋山信行氏の人物同定（BLOG-092寄稿者と同一か）は未確認。
