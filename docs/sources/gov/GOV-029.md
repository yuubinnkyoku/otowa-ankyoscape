# [GOV-029] 文京区「吹上稲荷神社」（2025年7月15日更新）

- 文京区公式の[施設・歴史案内](https://www.city.bunkyo.lg.jp/b014/p003827.html)を確認。現在の所在地は**文京区大塚5-21-11**。
- 区の沿革説明によれば、江戸城内に祀られたことを起源（**1622年**）とし、その後複数の移転を経て、**1751年に善仁寺（現小石川4丁目）へ移され、さらに護国寺・薬師寺などを経て1912年（明治45年）に現在地へ移った**。〔確認：区公式が記す由緒・移転年〕
- **現在の神社の位置は1912年以前の同社の所在地ではない**。近世絵図における神社の位置と現在の水窪川谷筋を結びつける際には、遷座の前後を区別する必要がある。〔観察：年代を伴う位置照合上の注意〕
- この資料は**神社の所在地・由緒を示すもので、水窪川の河床位置・水量・湧水・暗渠化年を記録したものではない**。歴史的な移転の細部は区の現代の説明であり、移転時の公文書や境内図は未照合。〔未解決〕
