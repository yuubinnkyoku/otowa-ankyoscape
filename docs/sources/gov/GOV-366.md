# [GOV-366] 御府内場末往還其外沿革圖書 拾九貞（嘉永5年9月調）— 神田上水中流の「堀筋」境界文言群と「助水堀筋」〔第160回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の[19]冊「拾九貞」（**嘉永五子年〔1852〕九月調**）。NDL次世代デジタルライブラリー [book/2587243](https://lab.ndl.go.jp/dl/book/2587243)。表紙文言に「**嘉永五子年九月調 御府内場末往還其外沿革図書拾九（四）冊之内貞 四谷内藤宿 東西大久保村 狛木村〔柏木村のOCR崩れ候補〕 中野村 高田村 源兵衛村 諏訪谷村 上戸塚村 上下落合村 一円之絵図壱枚**」とあり、**神田上水中流（淀橋〜落合〜戸塚）の両岸の村々を収める帳**。第19部の分冊で[GAZ-080](../gazetteers/GAZ-080.md)（拾九利）と同部（第19部拾九は元亨利貞に細分）に当たる。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する。**
- **「神田上水堀筋」の地所境界文言群〔確認・文言候補〕**: 各村の地所書上の四隣記述に「神田上水堀筋」が境界として反復される。①**柏木村**（成子町・淀橋町）＝「**西北之方 淀橋ゟ神田上水堀筋**」「**西北之方は神田上水堀筋二而**」（常圓寺・天満宮社地・岡田将監抱屋鋪・円照寺境内の地所）・「**西之方 神田上水堀筋**」（麟祥院無年貢抱屋敷・三上豊前守抱屋鋪）。②**中野村**＝「**東之方 神田上水堀筋限**」（宝仙寺脇通・宝仙寺境内東手）・「**東南之方 神田上水堀筋限**」（氷川明神社地・慈眼寺持東手）・「**北之方 神田上水堀筋**」（土屋勝右衛門屋敷・脇屋庄左衛門抱屋敷の諏訪谷村・上戸塚村境）。③**上戸塚村**＝「**西北之方 折廻し神田上水堀筋**」（観音寺境内・北村季元抱屋敷・田嶋橋通）・「**西南之方 神田上水堀筋**」（松平兵部大輔抱屋敷・高田四家町の高田村境）。④**高田村・下落合村**＝高田村松平兵部大輔抱屋鋪辺・下落合村酒井求次郎屋敷辺・大草畑吉屋鋪辺の「**西南之方 神田上水堀筋**」等。＝**嘉永5年（1852）時点の神田上水（淀橋〜戸塚〜落合）が村方の地所境界の堀筋として帳簿レベルで記録される文言群**〔「小瀧橋」「面影橋」「田嶋橋」等の橋名も四隣の方位起点として現れる〕。
- **「神田上水助水堀筋」の文言候補〔確認・文言候補・repo初出〕**: ①**上落合村泰雲寺辺之部**＝「**東南之方 神田上水堀筋限…東北之方 神田上水助水堀筋限 西南之方 小瀧橋ゟ中野村上落合村之内野道限**」。②**下落合村薬王院辺之部**＝「**西南之方 神田上水堀筋并助水堀筋限**」＋「**西南之方 神田上水掘筋并助水堀筋**」（薬王院・諏訪明神社地・妙楽寺退転跡の地所）。＝**神田上水本流の「堀筋」とは別の「助水堀筋」が、上落合・下落合の地所の四隣で並行して境界をなす文言候補**〔**「助水堀」の語がrepo初出**。「神田上水に助水を注ぐ堀」の意に読めるが、この助水堀が何に当たるか（千川上水〔淀橋分水〕か、妙正寺川側の水路か、その他か）は**本帳からは断定しない**。上落合の文言で本流の堀筋（東南）と助水堀筋（東北）が同一地所の異なる方位に現れる点は、両堀が並行関係にあることを示唆する観察材料〕。
- **位置づけ〔観察〕**: ①神田上水の中流（柏木＝西早稲田〜戸塚・落合）について、嘉永5年の村方地所書上の四隣表現に「堀筋」が反復される＝[GAZ-080](../gazetteers/GAZ-080.md)（拾九利・嘉永5年の牛込関口・早稲田・小日向・高田・下戸塚側の「神田上水堀筋并同所大洗樋下川筋」）と対になる**上流側（淀橋〜柏木〜中野）の地所境界文言**。②「助水堀筋」の上落合・下落合での分布は、上水の並行助水路の存在（あるいは記憶）を嘉永期の帳簿レベルで示す候補であり、千川上水の落合付近での流路対応（[README](../../README.md) §千川上水）の検討材料になる。ただし本帳の文言だけでは助水堀の水流の実体・方向・水源は確定できない。

## 制限・未解決

- ①本帳はくずし字でOCR崩壊が大きい。引用文言（神田上水堀筋・助水堀筋・小瀧橋・各村名）はすべて原画像照合を要する。②「助水堀筋」の実体（千川上水〔淀橋分水〕か他の水路か）は本帳からは断定しない。絵図部分（一円之絵図壱枚）の読図で助水堀の描かれ方を確認する必要がある。③「狛木村」＝柏木村のOCR崩れ候補の原字確認。④出火記録の年月（文政・嘉永の出火覚え）のOCR崩壊が大きく、沿革年代層の利用は要照合。⑤同冊の源兵衛村・諏訪谷村・東西大久保村の地所書上の他の水路文言（「用水堀」等）の網羅的抽出は今後課題。
