# [GOV-337] 北豊島郡高田町現状調査（1931）— 高田町下水道の1930-31年着手と4河川記述の陰性

- **書誌〔確認〕**: 東京市臨時市域擴張部『北豊島郡高田町現状調査』（昭和6年＝1931・市域拡張調査資料シリーズ。表紙「市域拡張調査資料 北豊島郡高田町現状調査 東京市臨時市域擴張部」・資料ラベル「D167 H33」・本文中「(昭和六年十一月現在)」）。NDL次世代デジタルライブラリー [book/1900501](https://lab.ndl.go.jp/dl/book/1900501) のOCR全文を確認。**引用文言はOCR由来で原文画像との照合を要する**（本書はOCR崩れが多く、数字・年月日に欠落・誤読を含む）。同シリーズの[GOV-331](GOV-331.md)（大泉村・1900793）・[GOV-257](GOV-257.md)（石神井村）・第143回陰性記録（上練馬村・1900508）の高田町版。
- **下水道事業の1930-31年着手〔確認・文言候補・repo初出〕**: 「**本町ニ於ケル下水道事業ハ昭和四年十二月二十九日高田町下水道調査費四千九百余円ヲ臨時費トシテ計上シ昭和五年一月ヨリ諸般ノ準備ヲ整ヘ同月十八日ヨリ実地ニ就キ下水道中心線ノ選定ニ着手シタリ既設ノモノハ石神井系統ニシテ町内ノ一部ナレドモ今後設ケラルヽモノハ新設三河島系統ニ依リ管渠延長一九、〇三四米ニシテ總工費一五二万八千円ナリ大東京二包含セラルヽ本町トシテ一日モ速ク其ノ完備ヲ期スベク努メ居レリ尚本事業ノ執行者ハ高田町々長ト指定セラレタリ**」（一部はOCR崩れの文脈復元。「昭和四年十二**円**二十九日」＝十二月の誤読候補・「一同ヨリ」＝一月候補・「諸檄」＝諸般候補・「石神井条統」＝石神井系統候補・「三河島糸統」＝三河島系統候補・「一九、〇三四〓九一」＝一九、〇三四米候補・「一五ニ八ヽ円」＝一五二万八千円候補。**数値・年月日は原画像照合を要する**）＝**高田町域＝旧水窪川・弦巻川・千川下流・谷端川下流域（現在の豊島区高田・目白・雑司が谷〜新宿区早稲田〜文京区大塚・西片側）の下水道の、昭和4年度調査費計上（4,900余円）→昭和5年1月18日実地着手（中心線選定）という1930-31年の起点側記録**。既設管渠が石神井系統（落合方面）に属し、新設は三河島系統（下水を東放流）である点も本文言。〔[GOV-207](GOV-207.md)（1938年水道事業年報・高田町4排水区＝音羽・鶴巻川・神田上水路・谷端川の区域・面積・延長）の7年前の着手側記録で、高田町下水道の1930年代の事業過程の起点にあたる。〕
- **上水道＝荒玉水道町村組合〔確認〕**: 「**本町ノ上水道ハ荒玉水道町村組合ニ加入セルヲ以テ（事業ノ）沿革及事業ハ荒玉水道ノ項ヲ参照スベシ…昭和六年度荒玉水道町村組合費負担金トシテ一二、四三九円ヲ計上シタリ**」（OCR崩れの文脈復元含む・数値は要照合）＝高田町の上水道が荒玉水道町村組合（多摩川原水の荒玉水道）経由である1931年時点の記録。〔町村単位の上水道供給組織のdatapoint。千川上水・神田上水とは別系統の近代上水道経由であることも、旧上水系水路の水道用途がこの時点で荒玉系に置換された観察として記録する。〕
- **沿革＝高田村成立・町制施行〔確認・OCR崩れ大〕**: 「**明治二十二年町村制ノ施行ニ際シ雑司ケ谷村、高田村（・小石川村・巣鴨村・落合村）ノ谷飛地ヲ併合シテ高田村トナシ、大正九年四月三日町制ヲ施行シ以テ今日ニ至ル**」（間に「高田千登世町」「高田若葉町」「雑司ケ谷旭出町」等のOCR語群が介在し、併合対象村名の列挙は正確な復元ができない・**要原画像照合**）＝**①明治22年（1889）の町村制施行で雑司ヶ谷村等が併合されて高田村が成立したこと、②大正9年（1920）4月3日の町制施行の年月日**の行政調査書側の文言。〔水窪川・弦巻川流域（雑司ヶ谷村・高田村域）の明治22年市制町村制以降の行政単位の成立記録。]
- **1931年の交通・停留場現勢〔確認〕**: 「**本町内所在ノ停車場ハ省線山手線ニ属スル目白駅、王子電車ニ属スル面影橋ノ学習院下ノ鬼子母神前ノ雑司ヶ谷水久保等アリテ交通頗ル便ナリ**」（OCR崩れの文脈復元）＝**王子電車（後の都電）の面影橋・学習院下・鬼子母神前・雑司ヶ谷・水久保の各停留場が1931年時点で存在した記録**。〔水久保停留場（現・豊島区雑司が谷の水久保通り付近）は1931年現勢としてrepo初出の停留場。面影橋（神田川・旧江戸川）・学習院下・鬼子母神前の地名と併せ、音羽谷〜雑司ヶ谷側の都市化の定点。〕
- **字名「高田雑司ヶ谷西谷戸」〔確認〕**: 郵便の項の配達地名表に「**高田雑司ヶ谷西谷戸**」＝**「西谷戸」の字名が1931年公式町勢調査の郵便配達地名として現れる用例**。〔[GOV-062](GOV-062.md)系の雑司ヶ谷の谷戸地形の字名記録を補強する1931年行政文書側の用例。谷戸名が大正期以降も字名として存続した観察。〕
- **4河川の直接記述なし〔確認・陰性〕**: OCR全文に対して「弦巻」「弦卷」「水窪」「千川」「谷端」「神田川」が**いずれも0件**〔確認〕＝**1931年の公式町勢調査（東京市臨時市域擴張部による高田町調査）の地勢・河川・水利の記述から、弦巻川・水窪川・千川（用水）・谷端川が消えている観察**。〔4河川がこの時点で同町の「現状」を記述する行政文書の河水項目に載らなかったことの陰性記録。地勢項には「早稲田ノ台地ニ隣レル所ハ一帯ニ連丘起伏ス」等の谷地形の言及はある。ただしOCR崩れにより河川名が誤読されて現れない可能性は排除できず、原画像での掃除が必要（断定しない）。〕

## 制限・未解決

- ①下水道文言の年月日・数値（十二月二十九日・一月十八日・4,900余円・19,034米・152万8千円）はOCR崩れを含むため原画像照合を要する（文言候補として扱う）。②沿革の併合村名の列挙はOCRの段組崩れで正確に復元できていない（雑司ヶ谷村・高田村・小石川村・巣鴨村・落合村の谷飛地の構成は要照合）。③「石神井系統」の既設管渠の実際の経路（落合方面＝石神井川沿いか）は本書からは特定できない。④水久保停留場の開業年（王子電車の開業は大正初期だが本書では現勢のみ）は本書からは得られない。⑤4河川の陰性はOCR品質の限界を含む（原画像の目視確認まで確定としない）。
