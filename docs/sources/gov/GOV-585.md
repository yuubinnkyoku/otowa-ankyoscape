# [GOV-585] 豊島区文化財ニュース第16号・榎本家店舗兼住宅および新座敷の指定告知

## 本文記載事項〔確認: 区公式文化財ニュース・ページID 44399・更新日2023年6月8日〕

- 「旧中山道沿いに残る**東京種苗株式会社**の建物」が「**榎本家店舗兼住宅および新座敷**」として**豊島区有形文化財に指定**されたことの告知（文化財ニュース【第16号】）〔所有者が東京種苗株式会社である旨の行政側記載。指定は令和5年4月〔[GOV-583](GOV-583.md)・[GOV-584](GOV-584.md)と一致〕〕。
- **初代榎本留吉の開業経緯〔確認〕**: 「江戸時代から**中山道沿いの滝野川村（現北区）**には、**種苗業を営む家が3家**あり、**3家のうちの1軒から弘化元（1844）年に分家して、巣鴨庚申塚で種苗業を開業したのが榎本留吉**で、この建物を所有する榎本家の初代」〔＝[BLOG-316](../blogs/BLOG-316.md)「元祖三家＝枡屋（榎本）孫八・越部半右衛門・榎本重左衛門＝三軒家地名由来説」の行政側対応文言。**「滝野川村の種苗業3家」の存在と「その1軒の分家」が1844年という区側記録**〔BLOG-316は滝野川の元祖三家を掲げるが、区側は対象家を特定しない〕。
- **建築詳細〔確認〕**: 店舗部分＝**木造つし二階建て切妻造り、切落桟瓦葺き**。北側の住居部分＝**木造平屋建て寄棟造り**。新座敷＝廊下で店舗兼住宅に接合、**木造二階建て入母屋造りの引掛桟瓦葺きで洋館が付属**。
- **年代の確定根拠〔確認〕**: 新座敷＝**四代留吉の結婚を機に建てられた**もので、**棟札の記載から昭和11（1936）年に竣工**したと考えられる。店舗兼住宅＝**榎本家の伝承や残された建築的特徴から、建築年代は明治40（1907）年頃と推定**〔棟札と伝承の使い分けという指定時の年代判断の記録〕。
- **空襲20年4月13日**: 「昭和20（1945）年**4月13日**に激しい空襲を受けた場所にあって**奇跡的に焼失を免れた**、豊島区内では数少ない戦前期の建築物」〔4月13日の日付までの区側記載〕。
- 「西巣鴨地域の歴史を象徴する「**種子屋通り**」を偲ばせる建物である点からも、豊島区にとって重要な文化財建造物」（**「種子屋通り」文言**＝[ORG-047](../org/ORG-047.md)の種子地蔵「参拝のしおり」文言・[GOV-583](GOV-583.md)第3回区詳細頁の報告3題名「種子屋通り」と同じ通称系文言の区文化財行政側での使用）。

## repo初出・リード意義

- **初代の開業年（1844・分家）・開業地（巣鴨庚申塚）・出自（滝野川村の種苗業3家の1軒の分家）が区の文化財行政側の記載で確定**した点が本資料の主眼。[BLOG-313](../blogs/BLOG-313.md)⑯「東京種苗（西巣鴨3-19-2・創業弘化元年〔1844〕・榎本家）」の1844年を区側も裏付け（BLOG-313の原本のひとつと推定されるが同定はしない）。
- **昭和11（1936）年の棟札・明治40（1907）年頃の推定**＝建物2棟の年代の公式見解で、[BLOG-315](../blogs/BLOG-315.md)（屋根保存修理の観察＝街道面の古瓦）の観察記録と対照可能な年代基準。
- 種苗商家集積地（千川上水×旧中山道の沿線）の商業建築の現存例としての建築記録（構造・屋根形式・洋館付属）で、地区の土地利用史の建築側資料。
