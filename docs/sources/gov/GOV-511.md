# [GOV-511] わきみず第125号（上祖師谷地区ミニコミ・2025-12-15）〔repo初出・仙川下流部（世田谷区上祖師谷〜鎌田）の住民側記録〕

## 内容〔確認: PDF本文テキスト抽出・2026-11-22〕

- **書誌〔確認〕**: 「**わきみず**」第125号＝上祖師谷地区ミニコミ編集委員会発行・年2回発行・事務局は上祖師谷まちづくりセンター。世田谷区公式サイト（city.setagaya.lg.jp）掲載のPDF。2025（令和7）年12月15日発行。地元ミニコミだが区サイト経由で一般公開されており、本repoでは「公的サイト掲載資料」として扱う。※見開きレイアウトのためテキスト抽出の読み順が一部前後する可能性に留意。
- **仙川のなりたち〔確認: 本文直接引用〕**:
  - 「**仙川は、上流端（起点）が小金井市の新小金井街道の下にあり、武蔵野市、三鷹市、調布市を通って世田谷区に入り、鎌田で野川と合流するまでの20.9㎞の一級河川です**」＝**仙川の全体像（起点・経路・末川合流・幹線流路20.9km・一級河川）〔多摩川→世田谷区間の水系定義〕**。
  - 「**仙川の名称は、三鷹市の新川丸池公園の湧水池が水量豊富で、「千釜（せんがま）」と呼ばれていたことが由来とされています。**川は「せんかわ」、町名や駅は「せんがわ」と読み方が異なりますが、連濁（れんだく）という音の変化により「か」が「が」と濁り地名として定着したものです**」＝**仙川の名称由来＝新川丸池の湧水池「千釜」説＋川「せんかわ」／地名「せんがわ」の連濁による読み分けの説明〔[BLOG-272](../blogs/BLOG-272.md)の「当時の源流＝三鷹市新川5丁目の丸池」と同じ水系・同名池の別系統の記録〕**。
  - 「**仙川の上流部分はコンクリートの細い水路で、水は流れておらず、一部暗渠化されていますが、三鷹市に入ると湧水の再放流（野川橋周辺）や、三鷹市東部下水処理場からの高度処理水の放流（新川地区）によって水量が増え、私たちが知る仙川の姿になります**」＝**上流部の無水・中流部の水再生（湧水再放流＋高度処理水放流）という現在の水量構造〔[GOV-510](GOV-510.md)の「渇水期にたびたび涸渇」・[BLOG-264](../blogs/BLOG-264.md)（No.2）の「大雨でない限り水が流れない」と整合する下流側視点〕**。
  - 「**下流部分は、成城大学のグランド横を通った後流れが早くなり、鎌田で一旦野川と合流した後に、多摩川に合流します**」＝下流部の流向。
- **流域の生活史〔確認: 本文直接引用〕**:
  - 「**昭和30年代に開発が進むまでは護岸壁がない川幅の狭い小川で、周囲では縄文土器も出土**」＝**縄文土器出土という考古学的な傍観記録（周囲に遺跡の存在）**。
  - 「**今年で開園50年を迎えた祖師谷公園の中を流れる仙川の両岸には多くの桜の木があり、都内の桜の名所の一つ**」＝**祖師谷公園開園50年（2025年時点＝1975年開園という逆算）**。
- **氾濫史〔確認: 本文直接引用〕**:
  - 「**1966（昭和41）年の台風4号（通称ビートルズ台風）の際は、流域全体で床上浸水6千戸弱、床下浸水3万戸弱の大きな被害が出ました。ある有名俳優が水浸しになった地域を自宅に置いていたボートでまわり、周辺住民の避難を手伝ったとの逸話が残っています**」＝****1966年台風4号＝「ビートルズ台風」・床上浸水6千戸弱・床下浸水3万戸弱・俳優のボート避難支援の逸話〔[GOV-508](GOV-508.md)の「昭和41年（1966）台風4号氾濫・激甚災害指定」と対校する被害規模の数値が初めてrepo入り〕**。
  - 「**また、2005（平成17）年の台風14号でも鎌田周辺で浸水がありました**」＝**2005年台風14号の鎌田周辺浸水という第2の氾濫記録〔2005年氾濫はrepo初出〕**。
  - 「**最近は下水道の整備が進み大きな被害は発生していません**」「**仙川の水は、生活排水や工場排水などで大変汚れていた時期がありましたが、下水道の整備が進んだことにより現在は大変きれいになりました**」＝**下水道整備による水質・治水の双方への効用という近年史**。
- **佐藤治雄証言（昭和20〜30年代の仙川）〔確認: 本文直接引用〕**:
  - 「**昔の仙川は川幅が狭く、農作業用の丸太の橋もかかっており、大雨で丸太が流されると下流まで丸太を探しに行って橋をかけなおしていました**」＝**農作業用の丸太橋と流失・再設の実態**。
  - 「**川の周辺は水はけが悪くて雨が降ると泥だらけになるので、通勤・通学の人は長靴で千歳烏山駅まで歩いて駅前の靴屋さんで靴に履き替え、長靴は靴屋さんに預けて電車に乗っていました**」＝**長靴文化（千歳烏山駅前の靴屋での履き替え・預かり）という流域の生活実態記録**。
  - 「**竹（孟宗竹）の節を取って穴をあけて川に沈めておくと翌日にはウナギやナマズ、ゲバチ（ギバチ）が獲れました**」＝**孟宗竹の節を用いた漁労技術（ウナギ・ナマズ・ゲバチ〔ギバチ＝ナマズ目の淡水魚〕）**。
  - 「**宮下橋の近くには農家用の洗い場があり、収穫した野菜などを洗っていました**」＝**宮下橋付近の農家用洗い場**。
  - 「**昭和30年代後半の東京オリンピックの建設ラッシュで、周辺の水田が大量の残土処理場所となったことをきっかけに、その後駒大グランド・寮の建設や宅地化などの開発が進み、風景が変わっていきました**」＝**1964年オリンピック建設ラッシュ→残土処理→宅地化・駒大グランド建設という土地利用変遷の実像〔[BLOG-272](../blogs/BLOG-272.md)の仙川拡幅・開発史と対照する下流側の記録〕**。
- **新しい橋〔確認: 本文直接引用〕**: 「**仙川には多くの橋がありますが、新しくできる道路（上祖師谷神明社横から駒大グランドに繋がる都道54号、宮下橋下流）に新設する橋の名称を選考中です**」＝**都道54号（上祖師谷神明社横〜駒大グランド）の宮下橋下流への新設橋・命名選考中〔2025年12月時点の進行中プロジェクト＝命名結果の再監視対象〕**。

## repoとの関連〔観察〕

- 仙川の名称由来（千釜）・20.9kmの全体像・無水上流域と放流による中流部などの**下流側（世田谷区）からの仙川像**は、repoが主に小金井側（上流端・山王窪・武蔵川〔[GOV-504](GOV-504.md)〕）から集めてきた仙川史料群の**下流側の接続点**として機能する。1966年ビートルズ台風の被害規模数値（床上6千戸弱・床下3万戸弱）は [GOV-508](GOV-508.md)（激甚災害指定）の数値的裏付け、2005年台風14号浸水は [BLOG-265](../blogs/BLOG-265.md)（1963年氾濫・市報1973年）と対照する治水史に2つ目の現代氾濫事例として加わる。

## 意義〔観察〕

- 住民証言（丸太橋・洗い場・長靴文化・孟宗竹漁・残土処理）は**仙川流域の土地利用・生活の変遷の一次的な口碑史料**。ミニコミだが区サイトで公開されており、 住民側の記録層として対照表・READMEの仙川治水史・生活史の水系側の座標を埋める。
