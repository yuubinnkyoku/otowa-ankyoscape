# [GOV-311] 東京警視本署布達全書（明治14年分）— 千川水道取締禁例の全文

- **書誌〔確認〕**: 『**東京警視本署布達全書**』（**明治14年分**・1886年発行。NDL次世代デジタルライブラリー [book/791201](https://lab.ndl.go.jp/dl/book/791201)）。警視本署の布達を編年で収録。明治14年5月11日付の布達群（甲第24号・25号・26号…）を収める。**引用文言はOCR由来で、条の区切りに崩れがあるため原画像照合必須**。

## ①「千川水道取締禁例」明治14年5月11日甲第25号〔確認文言・repo初出の全文〕

- 目次〔確認文言〕: 「**五月十一日 甲第貳拾五號 京府知事連署 千川水道取締禁例**」＝警視本署と東京府知事の連署布達。
- 本文〔確認文言・OCR崩れあり〕: 「千川水道取締禁例 **第一條 魚鳥ヲ捕リ及ヒ游泳シ又ハ諸物品ヲ洗フベ**[カラズ] **第二條** [汚?]**ラ塵芥瓦**[礫?]**種其他汚穢物ヲ投棄ス**[ベカラズ] **第三條** **上水ニ沿フタル各地面ヨリ汗水混入セシ**[ベカラズ] **第四條** [?]**第五條 堤上ノ竹木及ヒ下草等伐採スラズ 水道敷地內ヘ諸車挽キ入レ又ハ牛馬ヲ牽キ入ルラズ 但道路ニ係ル分ハ此限ニ在ラズ**」＝**千川水道（千川上水の明治13年千川水道会社給水系）の水質保全・施設保護の警察条例の本文**。第2条・第4条の周辺はOCRで条名と本文の区切りが崩れており、文言の割付は原画像照合まで「文言候補」として扱う。**構成は6か条＝①魚鳥捕獲・游泳・物品洗浄の禁止②塵芥・瓦礫・汚穢物投棄の禁止③沿面各地面からの汚水混入の禁止④堤上の竹木・下草の伐採禁止⑤水道敷地内への車・牛馬の牽入禁止（道路分は除外）⑥違警罪罰則条**（第4・第6条の復元は[GOV-315](GOV-315.md)・[GOV-320](GOV-320.md)の再録〔2026-11-16・第137回〕）。
- **意義**: ①[BOOK-161](../books/BOOK-161.md)（1941年・武蔵高等学校冊子）の「**明治14年千川水道取締禁令が定められ、上水を汚すことが禁ぜられた**」という沿革叙述と「**「本上水は飮料水につき汚損すべからず」との警視廳の標木**」の沿岸現存（1941）観察の**法的根拠の布達本文がここで初めて全文確認できた**。②明治14年は千川水道会社設立（明治13年）の翌年で、**民間水道会社の給水開始直後の警察取締の整備**という時系列が分かる。③千川水道が「飯料水」して法的に保護されていたことの行政文書レベルの裏付け（千川上水の飲料水終期論〔[GOV-290](../gov/GOV-290.md)1905年現役給水〕の法制面の支柱）。

## ②神田・玉川両上水取締禁例の言及〔確認文言・2026-11-16・第136回追記で系列確定〕

- 別箇所に「**神田玉川兩上水取締禁例**」の達（明治12年1月・甲第17号候補:目次の「十七號達 神田玉川兩上水取締禁例」）の存在が目次に見える＝**神田・玉川両上水には千川より先（明治12年）に同等の取締禁例があった**ことの書誌記録。
- **〔2026-11-16・第136回追記〕両上水取締の通時系列の確定**: [GOV-313](GOV-313.md)（明治11年10月29日・取締**假規則**全文5か条・12月1日施行）→ [GOV-314](GOV-314.md)（明治11年坤・施行前の巡査交番の運用細目）→ [GOV-312](GOV-312.md)（明治12年2月26日・**禁例への改名**と第3・4条改正・第5条刪除＋同日**違式罪目第76条で罰則化**、ただし**同年11月10日に罰則刪除**）→ 本資料の千川水道取締禁例（明治14年5月11日）＝**神田玉川両上水の仮規則（明治11年）・禁例化（明治12年）と、千川水道の禁例（明治14年）の系譜が布達本文レベルで初めて通時につながった**。明治14年の千川禁例は、両上水の禁例化（明治12年）と同じ東京府知事連署形式を踏襲する。
- **条文対応〔確認・対校〕**: 假規則（[GOV-313](GOV-313.md)）の第1条（魚鳥・游泳・洗浄）〜第4条（堤上竹木下草）と千川禁例の第1〜4条は文言がほぼ対応。千川禁例の第5条（水道敷地内への車・牛馬牽入禁止・但道路分除外）は兩上水の仮規則・禁例には見えない**千川水道固有の追加条項**（給水施設の敷地管理の事情を反映したか・断定はしない）。

- **〔2026-11-16・第137回追記〕千川禁例の条構成が6か条と確定**: [GOV-315](GOV-315.md)（警視庁令類纂第5版・明治29年現行）・[GOV-320](GOV-320.md)（現行日本衛生類典・1894）の2系統の再録で、**第4条＝堤上ノ竹木及ヒ下草等伐採スヘカラス（独立条として復元）・第5条＝水道敷地内への車・牛馬牽入禁止（但道路分除外）・第6条＝此規則ニ違背シタル者ハ違警罪ヲ以テ罰セラルヘシ（罰則条）**の6か条構成がほぼ同文言で確認された。**千川禁例は兩上水禁例（罰則は当初外部の違式罪目経由〔GOV-312〕→後に第5条として内蔵〔GOV-315〕）と違い、明治14年の布達当初から罰則条を条例内に持つ**構造〔観察〕。

## 制限・未解決

- ①布達本文の条割付はOCR崩れのため原画像照合まで確定しない（**ただし第4条の本文と第6条の罰則条はGOV-315/GOV-320の再録で復元済み・2026-11-16更新**。第2条の冒頭文言のみなお要照合）。②「神田玉川兩上水取締禁例」の本文は[GOV-312](GOV-312.md)（明治12年分）で改正・刪除の文言が確認できたが、改名後の禁例の**全文**（第1・2条の原文）はなお原布達レベルでは未確認。③禁例の施行範囲（千川上水の全区間か市中給水区間か）は布達本文からは判然としない。④違反者への罰則規定（違警罪処分）の適用関係は**別布達ではなく禁例自体の第6条として内蔵されていたことがGOV-315/GOV-320で確認された（2026-11-16・第137回更新）**。違式罪目・違警罪法体系との重複適用関係の細部はなお要確認。
