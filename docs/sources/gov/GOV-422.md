# [GOV-422] 享保撰要類集[63] 十八ノ下（出水之部）— 寛延2年出水の被災報告と延享元年の船繋留規則

## 延享元年（1744）の神田川筋の船筏繋留規則〔確認・repo初出〕

- 「**神田川筋繋置候船筏等大水之節は別而入念繋置両国橋江一切流懸り不申様二可致候 若令油断流懸候はゝ船幷筏諸荷物共に取上之 其船主荷主まて越度に可申付候** 右之通両国橋上大川通り并神田川筋町人共え町触可申付候依之町触書案壱通奉入御覧候…（船荷物筏等は諸国ゟ乗込大川通り神田川筋二懸り罷在候間荷主又は船頭共え右町触之趣其所之名主町人共ゟ申聞候様二年番名主共江可申渡候以上）**延享元子年七月廿日…左近将監殿え上**」＝**①延享元年時点で神田川（江戸川）筋に諸国からの荷物船・筏が「懸り罷在」していたこと、②大水の際に入念に繋置き、両国橋へ流れ懸からないようにするよう町触を出したこと、③油断して流れ懸かった場合は船・筏・諸荷物を取上げ、船主・荷主まで「越度」（過料）に処すこと、④両国橋上の大川通り並びに神田川筋の町人への町触書案の運用（年番名主経由）**＝**延享4年（1747）の「神田上水白堀ニ相懸り候金剛寺橋」の水防波浪（[GOV-241](GOV-241.md)）に先行する神田川筋の船舶管理の触の全文（repo初出）**。

## 寛延2年（1749）8月出水の被災報告群

- **8月11日書付〔確認・[BOOK-130](../books/BOOK-130.md)第196回追記の8月15日集計の前段候補〕**: 松ヶ枝町・西古川町の流家7軒、音羽5〜9丁目・桜木町の崖崩れと土蔵2ヶ所潰れ、市谷船河原町の御堀4間崩、元鮫ヶ橋南町の安藤監物下屋敷の山崩9尺、麻布永坂・南日ヶ窪町裏通りの京極織部屋敷の崖崩2間×20間半等（BOOK-130の8月15日書付の文言と対校関係・日付と箇所の対応は要照合）。
- **8月14日の神田上水の掛樋流失の報告〔確認・[BOOK-130](../books/BOOK-130.md)8月14日書付と同一文書群〕**: 「**風雨ニ而神田川出水仕 水道橋際（の）神田上水掛樋流失仕 上水相懸り不申い。假樋仕**」系の文言（白堀通り小日向金剛寺坂邊の崩込・小日向櫻木丁内の上水之假樋破損等が続く）＝**寛延2年8月14日の神田上水（白堀）の不通と仮樋の運用の一次報告（[GOV-241](GOV-241.md)・[BOOK-129](../books/BOOK-129.md)・[GOV-373](GOV-373.md)との対応はBOOK-130第196回追記の通り）**。
- **8月15日の橋梁報告〔確認・repo初出の個別文言〕**: 「（前略）**舟河原橋・龍慶橋不残流、中之橋・石切町之橋・東古川町⇔水道町古川橋落、江戸川橋（は）川上之方杭抜ヶ両橋台地形押流、小日向関口橋流**、渋谷宮益橋…」系の文言群（OCRの列順は要照合）＝**寛延2年出水で江戸川（神田川）筋の舟河原橋・龍慶橋（隆慶橋）・中之橋・石切町之橋・古川橋・江戸川橋・関口橋と渋谷川の宮益橋が同時に破壊された橋梁集計**＝個別の修復記録（[GOV-241](GOV-241.md)の関口橋・古川橋・江戸川大橋・牛込馬場下石橋）の被災側の対応点。
- **8月15日の流家・水死集計と小石川氷川明神門前⇔大塚の渡土橋流失〔確認・repo初出〕**: 「**（小石川）明神門前建家八軒土蔵五ケ所流失**」の文言に続き、「**明神門前ゟ大塚之方江渡土橋流落 往来無之処 去ル十七日三十歳計之中間躰之男 衣類陸二差置瀬踏仕候躰二而罷越 水死仕候哉 今以死骸相見不申候由申候 依之申上候以上 八月 能勢肥後守（馬場）讃岐守（本多）伯耆守殿江上ル 大岡出雲守殿江も上ル**」＝**①小石川の氷川明神（OCR「水川」候補）門前の建家8軒・土蔵5ヶ所の流失、②氷川明神門前から大塚方面へ渡す渡土橋の流失と、8月17日にその川を渡ろうとした30歳頃の中間（使用人）が水死した（死骸は発見されず）という文言＝小石川〜大塚間の谷（谷端川上流域の谷頭から氷川下方面）を渡る土橋の1749年の流失の一次記録（repo初出）**。ほかに**本銀町四丁目の町医・石春調が小石川御門外で流死**という新文言。集計の総数（町々の流家潰家67ヶ所）はBOOK-130第196回追記の数値と同値（対校点）。
- **8月29日の両国橋組与力の御褒美願〔確認〕**: 「**当月十三日神田川出水仕 同十五日両国橋大川出水仕**」＝神田川筋の出水（8月13日）と大川の出水（8月15日）を分けて記載する時系列的文言。
- **仮橋の取払・修復の追随〔確認・[GOV-241](GOV-241.md)との重複関係〕**: 柳橋・昌平橋の仮橋の10月26日取払、江戸川大橋の修復の12月27日出来・歩之板取払等の修復系列＝[GOV-241](GOV-241.md)（十七ノ下・寛延2年の橋梁修復冊）と文書の対応が疑われる同一事件の写し候補（両冊の重複の全確定は原照合課題として残す）。

## 位置づけ〔観察・断定しない〕

- **寛延2年8月出水を「8月11日（崖崩れ・流家の訴出）→8月14日（上水不通）→8月15日（橋梁集計・流家集計・水死）→8月29日（水防褒美）→秋〜12月（仮橋・修復）」の日次で追える一次書付群**が、[BOOK-130](../books/BOOK-130.md)（変災編第2の抄出）・[GOV-241](GOV-241.md)（橋々之部の修復側）との3点対校で成立した。
- **「小石川氷川明神門前⇔大塚之方」の渡土橋**は、谷端川上流域の小石川側の谷頭（水源側の谷）から大塚方面へ渡る生活道の土橋の1749年の実在・流失を示す。この渡土橋が谷端川本流か藍染川系かの比定は本文言からは確定できない（原照合・地形照合を次回課題とする）。
