# [GOV-468] 御普請書留14 — 天明3卯11月堀割普請褒賞の御普請奉行側記録

- **書誌〔確認〕**: 『御普請書留』14（写本・NDL次世代デジタルライブラリー [book/2571957](https://lab.ndl.go.jp/dl/book/2571957)・[book/2588170](https://lab.ndl.go.jp/dl/book/2588170) の2伝本を対校・いずれも写本OCR）。**引用文言はすべてOCR由来で要原文照合**。
- **天明3卯11月堀割普請の褒賞〔文言候補・本登録の核心〕**: 「**右は天明三卯年十一月千川上水堀割御普請御用相勤候ニ付被下候 但右御用骨折出精相勤候ニ付別段銀子被下候**」「**千川上水堀割御普請之儀有之候…金弐両宛…牧野大隅守組与力都筑兵右衛門 磯貝藤兵衛（ほか曲淵甲斐守組与力 安藤源助・下村弥助(・生田祐九郎)、同心列臣 金弐両宛/別段銀弐枚宛 内男八人・同人四人等）**」＝**天明3卯年（1783）11月の千川上水堀割御普請の御用を勤めた与力・同心に対し、骨折出精の別段銀子が下された文言（牧野大隅守組の与力都筑兵右衛門・磯貝藤兵衛のほか曲淵甲斐守組の与力・同心群）**。〔**[GOV-353](GOV-353.md)（天明撰要類集[22]御褒美之部・天明2年12月記写・卯10/11月申渡）に記録されたのと同じ堀割普請褒賞の、御普請奉行側帳簿（御普請書留）による独立確認**。東京都公文書館『東京市史稿 上水篇』目次の「**千川上水堀割竣成 1783-11-20**（柳営日次記・撰要集）」と、褒賞文言の「天明三卯年十一月…堀割御普請」の年月が一致し、**堀割普請の実施期（天明3年11月）の働き手側の実名を裏付ける**〕。
- **御用掛の勤務形態〔文言候補〕**: 「**右千川上水御用掛之儀は与力同心共向々役掛乍相勤 日々罷出相勤候儀二御座候**」＝**千川上水御用掛の与力同心はそれぞれの役掛けを兼ねたままで日々出勤して勤務した旨**。〔**普請人夫ではなく与力・同心の日常勤務で運用されたと読める文言候補（要照合）**〕。

## 制限・未解決

- ①2伝本の文言はほぼ同一だが、人名・銀子の枚数の判読差（生田祐九郎の有無・別段銀の枚数）が残る（原字照合前提）。②褒賞の申渡の時期（普請中か竣工後か）は本資料では文面から確定できない。
