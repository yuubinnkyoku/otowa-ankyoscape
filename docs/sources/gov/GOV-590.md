- **意義〔観察〕**: ①取入口3点（1968年2点＋昭和30〜50年代1点）は玉川上水から千川上水が分岐する取入口の**通水終了（昭和46年=1971年〔GOV-058〕）直前**の状況を伝える写真群で、[BOOK-234](../books/BOOK-234.md)（小川村〜取入口間の桜堤60町）・取水口関係の各記録の「1970年時点の実景」として対校できる。②本流スライド8点（1970年）は練馬区立石神井公園ふるさと文化館の千川上水記録フィルム（昭和27年頃・〔既収録〕）から通水終了までの間の景観資料で、**撮影年が明記された1970年の千川上水写真群としてrepoの写真資料年代列を補強**する。③「流水なき千川上水路」（備考=昭和50年前半＝1975〜76年頃）は**通水終了（1971）後・練馬区側流水復活（1975）前後に相当する年代の、水を失った水路の実景を直接1点で示す記録**で、暗渠化・断流後の水路の状態を伝えるrepo初出の写真記録候補〔備考の年代日付は目録文言どおり〕。④「柳橋辺り」（96651011）は千川上水沿いの地点名を資料名に含むが、どこの柳橋か（本repoに既出の複数の柳橋との対応）は画像内容確認まで特定しない。
- **制限・未解決**: ①12点とも**画像の内容（撮影地点・写っている区间・向き）は本調査では未確認**（収蔵品目録のメタデータ取得まで）。②「柳橋」の比定は未実施。③ToMuCoの画像公開状況（サムネイル・高解像度の有無）の確認は次回以降。④ステレオ写真の実体（1枚＝ステレオペア1組か）は目録に「員数1枚」とあるのみで原画像確認待ち。
