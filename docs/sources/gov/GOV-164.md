# [GOV-164] 東京市 下水道沿革誌（1914年）

- **書誌〔確認〕**: 東京市『下水道沿革誌』（大正3年・1914）・NDL次世代デジタルライブラリー [book/950605](https://lab.ndl.go.jp/dl/book/950605)。**引用はOCR由来・要原文照合。**
- **小石川の項〔確認・repo初出〕**: 「小石川ハ古ヨリ細流ニシテ末ハ神田川ニ入レリ」…「**元巣鴨村ヨリ出ツル野水谷端川ノ末ナリシカ後千川上水ノ剰水ヲ容レ**駿河臺ノ西ニ於テ小川（昔ノ江戸川）ニ會流セシモ**現今ハ直チニ神田川ニ注ク**」〔OCR・要照合〕。小石川の末池に関する考察も併記。**1914年時点の市公式下水道史が、小石川（谷端川の下流部での呼称）を「元は谷端川の末、後（1779年以降の千川再興以降）は千川上水の剰水を受け、現今は直接神田川に注ぐ」と記述**したことになる。
- **位置づけ〔観察〕**: 谷端川〜千川〜小石川〜神田川の水系接続の明治期形態を、[GOV-023](GOV-023.md)（千川の下流呼称）・[GOV-163](GOV-163.md)（1924年・「谷端川ノ下流ハ千川ニシテ」）・[BOOK-077](../books/BOOK-077.md)（1941年・後楽園横を経て神田川合流）に並ぶ年代断面として固定する。1914→1924→1930→1941と「下流千川呼称」の公文書列が連続する。
