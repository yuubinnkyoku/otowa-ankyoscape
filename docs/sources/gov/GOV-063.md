# [GOV-063] 豊島区の環境に関する現状調査（資料第2-2号）

- **直接確認（2026-11-11、区公式PDF、冒頭部）**：地球環境・自然環境・人文歴史環境を文献・統計で整理した調査資料。「地下水・湧水」の現状として、**揚水機出力300Wを超える全ての井戸の揚水量が年間約59万㎥、井戸本数73本**と記す。〔確認：冒頭部の本文／表紙・刊年表示は取得部に含まれず刊年は未確認〕
- **典拠整理〔確認〕**：同資料の地下水・湧水項は「都内の地下水揚水の実態（東京都）」を主要文献として挙げる。地形は「豊島区都市づくりビジョン」に依拠する。
- **repoでの位置づけ〔推定〕**：現代の豊島区の地下水揚水の規模を示す区公式の統計で、**粟島神社弁天池のポンプ揚水への転換（[GOV-015](../gov/GOV-015.md)）や谷頭湧水の減少を地下水面上昇・低下や揚水と関連づけて検討する際の背景資料**。揚水量が湧水の枯渇の直接原因であるとは本統計からは断定しない。〔未解決：刊年・「都内の地下水揚水の実態」の該当年度版の特定〕
