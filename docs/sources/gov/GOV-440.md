# [GOV-440] 南撰要類集[8]上納地之部 — 江戸川神田川常浚御手当金の文政期の実務運用

- **書誌〔確認〕**: 『南撰要類集』[8]（第三中 上納地之部・文政9戌年〔1826〕の記録集）。NDL次世代デジタルライブラリー [book/2550417](https://lab.ndl.go.jp/dl/book/2550417)。**引用はすべてOCR由来で文言は要原文照合。**
- **浅草本所御蔵入堀の常浚御手当屋敷地代の不足分処理（文政9戌2月）〔確認・repo初出の制度文言〕**: 本所相生町五〔八・OCR崩れ候補〕丁目の地所**126坪余**の内半分が文政8年（1825）9月に御用部屋坊主長勝へ拝領地として渡され、地代が**月1両×4ヶ月=4両**不足→「**江戸川神田川常浚御手当金〔屋敷地代取立置候内〕**」を以補填、以後は**年2回（二季）6両宛・計12両/年を浅草御蔵へ振向納入**という運用の確定〔**①「江戸川神田川常浚御手当」＝江戸川（神田川）の常時浚渫（常浚）の恒常財源の制度名が文政9年（1826）の町奉行所の実務文書レベルで現れること（repo初出候補）、②本所相生町の屋敷がその財源の原資（御手当屋敷）であること＝寛延3年（1750）の渡助成地（本所相生町2ヶ所・[GOV-373](GOV-373.md)）と同じ町の地所であることの直結関係、③拝領渡に伴う地代収入の減少を常浚御手当金から補填し、以後の年12両分の振替納入を確定するという財政実務の一次記録**〕。④「御蔵入堀」＝[GOV-439](GOV-439.md)の浅草御蔵入堀系の上納地（常浚御手当屋敷の収入対象の堀端屋敷群）と同じ体系。
- **江戸橋広小路上納増金一件（文政9戌7月〜9月）〔確認・文言候補群〕**: ①広小路の由来——「**明暦三酉年中大火後…火除明地二而本材木町・元四日市町江御預**」（明暦3年〔1655〕大火後の火除明地として本材木町・元四日市町へ御預）＝**江戸橋広小路（火除明地の貸地）の由来源于文言**、②上納金の推移——**明和7寅年（1764）から上納金100両→寛政年中の御肴御役所建設により97両3分→文政9年に増金して年220〔222〕両を蓮池御金蔵へ上納**、③制度上の位置づけ——「**右江戸橋広小路地右之儀は江戸川神田川常浚御手当屋敷之内ニ而上納金之儀者年々蓮池御金蔵え上納仕候**」＝**江戸橋広小路の地は「江戸川神田川常浚御手当屋敷」の内であることの明文**、④町年寄の覚書——「**江戸川神田川御手当屋敷 江戸場〔江戸方・OCR崩れ候補〕壱ヶ年上納高凡廣小路外四ヶ所地代金是迄金七百拾六両弐分銀弐分壱厘…右納高之内拾弐両宛浅草本所御蔵入堀…御手当之方江引取**」〔**①常浚御手当屋敷の年間地代収入の規模＝広小路外4ヶ所（「江戸方」の地所群）で凡716両2分+銀2分1厘という一次数値（OCR崩れ注意），②その納高の内12両が浅草本所御蔵入堀の御手当方へ引き取られる運用＝上項の年12両の振替納入の財政側の裏付け、③江戸橋広小路上納金の恒例（年220〔222〕両・蓮池御金蔵）とその御手当屋敷内の位置づけ**＝**「江戸川神田川常浚御手当」の文政期の年間規模（約716両）と内訳（広小路上納金220〔222〕両を含む4〜5か所の地代金構成）の一次文言群**〕。
- **位置づけ〔観察〕: 神田川（江戸川）の渡・浚財政の通時系列の中間の確定**: 本資料により——**①寛延3年（1750）: 渡助成地の設定（[GOV-373](GOV-373.md)・本所相生町2ヶ所＋二葉町1ヶ所・永代橋/新大橋の渡銭の助成地）→②享和元年（1801）頃: 「江戸川神田川筋渡助成地地代金」の余剰分貸付・利息850両2分の金蔵納入・御入用橋（京橋）への流用（[GOV-439](GOV-439.md)）→③文政9年（1826）: 「江戸川神田川常浚御手当」として年約716両の屋敷地代収入（江戸橋広小路220〔222〕両を含む）・12両の浅草御蔵振替（本冊）**という**制度名（渡助成地→常浚御手当屋敷）・規模・運用の変遷の3点が一次資料でつながった**。①神田川系の浚渫費用の財源（橋渡銭・助成地地代）が江戸川橋の渡銭停止（[GOV-438](GOV-438.md)・1790）以後も「常浚御手当」として恒常化していたこと、②本所相生町の地所が1750年と1826年の両時点で財源の原資であること、を示す。なお神田上水（白堀）側の浚賃銭（[GOV-245](GOV-245.md)〜[GOV-249](GOV-249.md)・白堀浚賃銭/渡賃銭）とは別系統の（江戸川=神田川の堀川の）財源であることに注意。

## 制限・未解決

- ①本所相生町の丁目（五/八のOCR対立）・拝領地の面積・月1両の計算基数は要照合。②広小路上納金の「220/222」両の原字・「江戸場」の読み（江戸方候補）・716両2分の内訳4ヶ所の特定はOCR崩れあり要照合。③明和7年からの上納開始の経緯（御肴御役所建設前の負担先）と蓮池御金蔵の制度上の性格は本冊では未確認。④「江戸方壱ヶ年上納高凡716両」が常浚御手当屋敷の全体収入か江戸方分のみかの確定は要照合。
