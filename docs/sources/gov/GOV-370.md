# [GOV-370] 復興建築叢書第拾貳號（1920・復興局建築部）— 建築線路線一覧の水窪川・千川流域文言〔第161回〕

- **書誌〔確認〕**: 復興局建築部『復興建築叢書第拾貳號』（**大正9年〔1920〕**）。NDL次世代デジタルライブラリー [book/1906921](https://lab.ndl.go.jp/dl/book/1906921)。市街地建築物法（大正8年公布）に基づく**建築線（道路に面する建築物の敷地の線）指定・建築物敷地の地域指定**の関係書類で、東京市内・郡部（豊多摩郡・北豊島郡）の**指定路線の起終点・経由地・番地を列挙**した一覧を含む〔第158回・第160回ノートでGOV登録候補として言及・本回で資料化〕。**引用文言・路線番号・番地はすべてOCR由来で原画像照合を要する。**
- **字蟹ヶ窪経由の計画路線〔確認・文言候補・核心〕**: ①「**豐多摩郡內ロ第二十號路線終點ヨリ高田町大字高田千登世町及西巢鴨町大字池袋字蟹ケ窪ヲ經テ大字瀧野川町字飛鳥山前六十八番地ノ二地先ニ至ルノ路線**」＝**高田千登世町→西巣鴨町大字池袋字蟹ヶ窪→滝野川町字飛鳥山前68-2番地**を結ぶ建築線路線。②「**西巢鴨町大字池袋字西山五百七十六番地ノ一地先ヨリ同字蟹ヶ窪六百二十九番地ノ一地先ヲ經テ同七百五十五番地ノ一地先ニ至ルノ路線**」＝**字西山576-1→字蟹ヶ窪629-1→755-1**の区間路線〔**字蟹ヶ窪（水窪川の源流窪地と比定される字名）を経由する都市計画路線が1920年に番地つきで指定されていた記録**。当路線の現道路への対応（目白通り・要町方面か）は本書からは断定しない〕。
- **高田橋・長崎村字五郞窪経由の路線〔確認・文言候補〕**: 「**東京市內ロ第五十二號路線終點ヨリ高田町大字高田字千登世町、高田橋、豐多摩郡落合町及北豐島郡長崎村字五郞窪ヲ經テ上板橋村境界ニ至ルノ路線**」＝**千登世町→高田橋→落合町→長崎村字五郞窪→上板橋村境**を結ぶ路線〔**高田橋（神田上水筋の高田橋と比定候補・要照合）と長崎村字五郞窪（千川上水通過域の窪字名候補）の1920年の建築線文言**。五郞窪＝五郎窪の表記も〕。
- **小石川・音羽・関口周辺の市内路線〔確認・文言候補〕**: ①路線40「**牛込區天神町…山吹町、小石川區關口水道町及江川橋ヲ經テ音羽町一丁目…大塚仲町ヲ經テ氷川下町…**」＝**江川橋（江戸川橋のOCR変種候補・要照合）経由の山手〜小石川縦断路線**。②路線51〜55＝「**東古川町…關口水道町ヲ經テ關口町…**」「**音羽町五丁目…關口町及高田老松町ヲ經テ高田豐川町…**」「**大塚辻町…**」「**音羽町一丁目…西靑柳町ヲ經テ高田豐川町…**」「**大塚坂下町…**」＝**関口〜音羽〜高田豊川（弦巻川・神田上水流域）の市郡境界に至る建築線群**。③路線61「**…小石川區初音町…戶崎町及白山御殿町…水川下町〔氷川下町〕…**」＝**初音町→戸崎町→白山御殿町→氷川下町を結ぶ路線**〔戸崎町〜氷川下＝千川（小石川下流）低地縦断路線の候補。番地・番号はOCR・要照合〕。
- **位置づけ〔観察〕**: ①本書は1920年（関東大震災前・市街地建築物法施行直後）の**復興局建築部による建築線指定の一次記録**で、水窪川源流（字蟹ヶ窪）・神田上水筋（高田橋・江戸川橋）・千川低地（戸崎町〜氷川下）・千川上水通過域（五郞窪）を**経由地名・番地つきで**記す点で、当該各地点の都市計画史の基礎資料となる〔大正期の都市計画路線網と現行道路（目白通り・千川通り等）の対応の確定は地図照合が前提で本書からは断定しない〕。②[GOV-159](GOV-159.md)・[GOV-166](GOV-166.md)等の1920〜30年代の都市計画・下水道資料群と並ぶ1920年時点の座標的文献。

## 制限・未解決

- ①本書はOCR列崩れがあり、路線番号（「一一」「ロ」等の崩れ）・番地・文言はすべて原画像照合を要する。②「江川橋」＝江戸川橋、「水川下町」＝氷川下町の読み替えは候補扱い。③各路線の現道路への対応（蟹ヶ窪路線＝目白通りか、五郞窪路線＝千川通り筋か等）は本書からは断定しない（地図照合の課題）。④「高田橋」が神田上水（現・神田川）筋の高田橋か他の橋かは要照合。
