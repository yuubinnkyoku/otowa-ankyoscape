# [GOV-065] 「【その他】千川上水公園」ガラス乾板写真と沈殿池の解説

- **資料〔確認：東京都水道歴史館デジタルアーカイブ目録、2026年11月11日閲覧〕**：同館デジタルアーカイブ「[【その他】千川上水公園](https://www.ro-da.jp/suidorekishida/content/detail/REKI-003-007_02)」、**資料ID REKI-003-007_02**、ガラス乾板写真、寸法W16.5×H12.0cm、制作者**東京市水道局**、制作年月日**昭和前期**、地域・施設名**「豊島区」**。
- **解説〔確認：目録の解説欄〕**：「これは千川上水公園の千川上水沈殿池を写した写真と考えられる。**かつてはこの沈澱池で水量調節をして給水をしていたとされる**」。備考「目録に原タイトル『千川上水公園」とあり」。公開日は2022年9月30日。
- **repoでの位置づけ〔推定〕**：千川上水公園（豊島区西巣鴨、[GOV-040](../gov/GOV-040.md)・[GOV-061](../gov/GOV-061.md)参照）に**沈殿池（沈澱池）**があり水量調節・給水に使われたとする**水道局側の目録解説**で、六義園への給水（昭和43年停止説は[BLOG-043](../blogs/BLOG-043.md)）の上流側施設の実在を裏付ける。豊島区教委の現地説明板の二次転記（[BLOG-053](../blogs/BLOG-053.md)）とも整合する。**写真画像の判読は未実施**で、池の形状・位置の同定はこれだけでは確定しない。「昭和前期」は幅のある目録推定表示。
