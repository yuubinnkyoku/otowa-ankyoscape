# [GOV-027] 『官報』第1201号・内務省告示第250号

- **資料名・日付〔確認：国立国会図書館サーチに掲載された『官報』の書誌・目次〕**：『官報』**1930年（昭和5年）12月29日、第1201号**。同号の目次に、**内務省告示第250号「東京都市計畫高田町下水道及其事業執行年割」**が**印刷p.748**の項目として登録されている。
- **所在〔確認〕**：[国立国会図書館サーチ・同号](https://ndlsearch.ndl.go.jp/books/R100000039-I2957668)／[国立国会図書館デジタルコレクション・PID 2957668](https://dl.ndl.go.jp/pid/2957668)（DOI: 10.11501/2957668、請求記号 YC-1）。書誌上の公開範囲はインターネット公開。
- **確認の限界〔未解決〕**：**目次と書誌のみを直接確認し、告示本文・別紙・図面の原画像は未読**。この目次だけから、内閣認可日、告示本文の正確な文言、工事起終点・管路・工費・年度別執行額・告示の効力発生日は確定できない。**官報の掲載日を工事着工日・竣工日と混同しない**。
- **次の確認対象〔調査課題〕**：印刷p.748の告示原文を読み、既収録の豊島区立郷土資料館リーフレットが記す**1930年12月24日の内閣認可**と、1932年9月付の高田町下水道築造記念碑の二次転記にある認可・事業年割を、別々の行政手続として照合する。
