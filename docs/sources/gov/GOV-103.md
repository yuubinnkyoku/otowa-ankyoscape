# [GOV-103] 豊島区の谷端川関連行政記録2件（NDLサーチ書誌）

NDLサーチのOpenSearch APIで「谷端川」を検索したところ、**豊島区立図書館の区政資料（R100000094）の個別レコード**として、repo未収録の行政記録2件の所在を確認した〔いずれもrepo初出〕。

- **①公園条例・児童遊園条例・公衆便所条例改正議案資料「谷端川南・北緑道、池袋平和通り・千早緑地公園」〔確認: NDLサーチ書誌〕**: **1991（平成3）年2月20日**・「**H030220区民建設委員会資料**」〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I182695)〕。**谷端川南・北緑道の公園条例・児童遊園条例上の位置づけを定める条例改正の議案資料**〔谷端川緑道の公園としての整備（GOV-008/009）が条例レベルで扱われた時点の区議会資料。BLOG-153の「平成2年谷端川南緑道命名」の翌年の議案で、命名→条例整備の順序として並べられる候補。議案本文は未確認〕。
- **②「谷端川一号幹線の一部完了について」〔確認: NDLサーチ書誌〕**: **2001（平成13）年7月31日**・「**H130731副都心開発調査特別委員会資料**」〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I184169)〕。**谷端川一号幹線（下水道幹線）の一部完了**を区議会委員会に報告した資料〔**「谷端川一号幹線」という幹線名がrepo初出**で、Wikipedia谷端川脚注の「谷端川上幹線（新河岸処理区）／谷端川幹線（小台処理区）」（第24回ノート記録・下水道台帳未確認）に続く第三の幹線名表記。一号幹線がどの区間・処理区を指すか・既述幹線との対応は未確認〕。
- **共通の留意〔観察〕**: いずれもNDLサーチ書誌のみで本文未確認。**本資料に基づいて緑道整備年次や下水道幹線区分を本文で主張しない**。豊島区立図書館での現物確認・区議会会議録検索が次の一手。
