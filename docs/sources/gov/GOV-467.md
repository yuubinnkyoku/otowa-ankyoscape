# [GOV-467] 町会所一件書留（寛政5丑年）— 千川上水負担の町入用帳簿上の決着一件

- **書誌〔確認〕**: 『町会所一件書留』[7]六 寛政五丑年 三冊ノ内中（NDL [book/2587071](https://lab.ndl.go.jp/dl/book/2587071)）・[8]七 寛政五丑年 三冊ノ内下（NDL [book/2587072](https://lab.ndl.go.jp/dl/book/2587072)）・写本OCR。**引用文言はすべてOCR由来で要原文照合**。帳簿の数字は列崩れが激しく、金額の採用は原画像照合が前提。
- **千川上水普請入用の町別分担金リスト〔文言候補・本登録の核心〕**: 「**千川上水普請入用之分金 壱両壱分六匁七分四厘 巣鴨御駕籠町 同弐両壱分六分弐厘九毛 駒込片町之内上組 同弐両弐分壱匁九分七厘 同断中組…（下谷当町弐町目・同壱町目・湯嶋天神門前町・同坂上町・上野新黒門町・本郷壱町目〜同所六町目・春木町壱丁目・同所三町目・妻恋町・下谷茅町・湯嶋三組町等）**」＋「**右口之千川上水普請ニ入用幷水銀等五ケ年平均一ケ年分書面之金高引除度旨申立**」＝**①千川上水の普請入用の分担金を巣鴨御駕籠町・駒込片町（上組・中組）・下谷各町・湯島天神門前町・坂上町・上野新黒門町・本郷各町・春木町・妻恋町等の町別に賦課した帳簿、②その金高を町入用の書面から引除く旨の申立（吟味の上で引除き了済）**。〔**再興期の千川上水普請費が上流（巣鴨・駒込）から下流（本郷・湯島・上野・下谷）までの給水町に分担されていた実務の帳簿初出。町入用帳との突合作業として記録**〕。
- **「千川水銀（水料）」の引除文言〔文言候補・水銭の帳簿上の名称〕**: 「**千川水銀五ヶ年平均一ヶ年分金九両拾匁六分引除度旨申立 吟味之上除遣候**」＝**千川水銀（＝千川上水の水料。「水銀」＝「水賃/水料」の略記は [GOV-281](GOV-281.md)（武家方水銀帳）の用例と同じ）の5ヶ年平均一ヶ年分＝金9両10匁6分を町入用から引除く旨の吟味一件**。〔**千川上水の水料負担の実額が初めて金遣で出た文言候補（要照合）。寛政5（1793）＝天明7年差止の6年後の帳簿で過去5ヶ年分の決着を行っている**〕。
- **番人仮小屋普請入用金・寄積金〔文言候補〕**: 「**右同断番人仮小屋普請入用金四両弐分余 右五口〆一金弐拾壱両壱分余**」「**千川上水銀共金弐百五両弐分余**（寄積金のリスト内）」＝**千川上水の番人（水番）の仮小屋の普請入用金の分担と、町会所の寄積金リストの中の「千川上水銀共金205両余」の並記**。〔**上水付帯施設（水番小屋）の維持費の町別分担の初出候補**〕。

## 制限・未解決

- ①本一件の「千川上水普請」が天明2〜3の堀割普請の精算か、別の保全工事かは、寛政5の帳簿で過去5ヶ年（寛政元年〜4年?）の平均を問題にしている点から単純な天明期精算とは言い切れず断定しない（原史料の広文面での帰属確認が必要）。②金額は列崩れが激しく全数値の採用は要照合。③「水銀」＝水料の読み替えはGOV-281の用例による支持つき候補だが、原字照合まで断定しない。
