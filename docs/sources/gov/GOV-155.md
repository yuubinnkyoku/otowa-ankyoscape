# [GOV-155] 東京都第三建設事務所「河川の整備」〔repo初出・第97回〕

- **環状七号線地下広域調節池の諸元〔確認: 本文・施設概要表〕**: **環七と目白通りの地下に建設**と明記。**連結区間**＝白子川地下調節池（豊島区）と神田川・環七地下調節池を結ぶトンネルで、**内径12.5m・延長約5.4km・貯留量約68万m³**。施設概要表の数値: 白子川地下調節池 内径10.0m・延長3.2km・貯留量21.2万m³／連結区間 内径12.5m・延長5.4km・貯留量68万m³／神田川・環七地下調節池 内径12.5m・延長4.5km・貯留量54万m³＝**計 延長約13.1km・貯留量約143万m³**〔本文中に「総延長約13.2km・貯留容量約143.2万m³」という表記もあり、**同一頁内で13.1km/143万m³ と 13.2km/143.2万m³ の表記ゆれがある**〕。
- **工事経過〔確認: 本文〕**: 平成28年度末 発注・契約 → 平成29年 立坑工事着手・シールドマシン製作 → 平成30年9月 シールドマシン完成 → 令和元年10月 中間立坑完成 → 現在 **本体トンネル構築中**。令和7年12月時点の進捗説明資料（PDF）への言及あり。
- **意義〔観察〕**: ①**神田川流域の広域治水施設の最新の諸元（2026年7月更新）を都の一次資料で固定**した。産経新聞報道（README既出・「約13km・143万m³」）を、都公式頁の施設概要表・工事経過で裏付け・具体化した〔報道の数値の一次確認〕。②**目白通りは弦巻川下流域（高田馬場〜江戸川橋方面の谷）を通る幹線道路**で、同頁の「環七と目白通りの地下」という記載は、**弦巻川の1932年暗渠化（README既出・PAP-082）とは別系統の、地下深部の大規模雨水貯留施設が同区域の地下に構築中**であることを示す〔連結トンネルの詳細な線形（目白通りのどの区間を通るか）は当頁本文では確認できず、断定しない〕。③白子川（板橋区）〜神田川（中野区方面）を結ぶ5.4kmの地下導水は、**水窪川・弦巻川・谷端川の現在の受け皿である神田川水系の治水構造**に関わる情報〔江戸川＝神田川上流部の現在の整備状況の記録として、河川史の現代側の接点になる〕。
- **制限・未解決**: ①連結トンネルの起終点・線形の地図上の確認は当頁本文では不可能（立坑位置等は令和7年12月進捗PDF等の別資料。次回課題）。②表記ゆれ（13.1km/13.2km）のどちらが正確な現行値かは当頁からは確定できない〔両方の数値を記録〕。③第三建設事務所管内の他河川（神田川本川の整備状況等）の記述も本文に含まれるが、今回の要点は環状七号線地下広域調節池とした。
