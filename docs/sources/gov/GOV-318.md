# [GOV-318] 現行規則万民法典（1887）— 両禁例の明治20年頃の現行性の記録

- **書誌〔確認〕**: 『**現行規則万民法典**』（**1887**〔明治20年頃〕。NDL次世代デジタルライブラリー [book/787333](https://lab.ndl.go.jp/dl/book/787333)）。現行の警察規則を列挙した法令輯覧。**引用文言はOCR由来で原画像照合を要する（番号・日付の割付が列崩れしている）**。

## ①警視廳の諸規則リスト中の両禁例〔確認文言・文言候補〕

- リスト中に「**○千川水道取締禁例 十四年五月十一日甲第二十五號東京府連署布達 ○神田玉川(両)上水取締禁例 十一年十月廿九日甲(第廿七號?)警視廳布達**」＝**明治20年頃の現行規則リストに両禁例が並んで収録**されている（リストは馬車取締・人力車取締・湯屋取締・寄席取締など市中営業規則と混在）。
- ②番号表記の注意〔文言候補〕: 兩上水禁例の布達番号が「**甲第廿七號**」と読める箇所があるが、これは割付崩れの可能性が高く（「甲第五十七號」の「五」の脱落候補）、**甲57号（明治11年10月29日）が原布達**とする[GOV-315](GOV-315.md)（明治29年類纂の「甲第五十七號」）・[GOV-317](GOV-317.md)と合わせて判断すると五十七号が正しい可能性が強い。原画像照合まで確定しない（[GOV-311](GOV-311.md)の目次数値「甲第17号」候補とも併記管理）。
- ③「**以上諸規則ニ違背シタル者ハ何レモ違警罪ヲ以テ罰セラルヘシ**」の文言がリスト末尾に付く（近接する「明治十七年五月廿六日第三十九號警視廳達」等との割付関係は要照合）＝**両禁例への違警罪適用が明治20年頃には（違式罪目第76条の刪除〔明治12年11月・GOV-312〕後の新たな体系で）再び担保されていた**ことの書誌記録。

## 位置づけ〔観察〕

- 通時系列の埋め込み: 明治12年11月の罰則刪除（[GOV-312](GOV-312.md)③）→（違警罪法体系の整備期）→**本書（明治20年頃・違警罪適用の現行リスト）**→[GOV-320](GOV-320.md)（1894衛生類典）→[GOV-315](GOV-315.md)（1896令類纂・禁例本文に罰則条）＝**兩上水禁例の罰則が明治12年の刪除後、遅くとも明治20年頃までに違警罪体系で運用に復帰していた**観察の支柱となる。罰則条（第5条）の追加布達の番号・年次の特定が次の一手（法規分類大全の「兩上水取締禁例罰則 甲第58号」候補〔[GOV-312](GOV-312.md)追記参照〕と対校）。
