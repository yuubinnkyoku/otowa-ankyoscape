# [GOV-022] 豊島区「鬼子母神大門ケヤキ並木」

## 書誌・所在

- 豊島区公式ホームページ、ページID 41981、2022年10月25日更新。2026年10月31日に本文を確認。
- 原ページ：https://www.city.toshima.lg.jp/349/bunka/bunka/bunkazai/naturalmonument/2209260935.html

## 内容メモ

- 1937年（昭和12年）時点に大径のケヤキが18本あったと記す。
- 保存会の活動と1940年（昭和15年）の東京都天然記念物指定に言及する。
- ページの説明時点では大径木が4本となり、若いケヤキへ植え替えられてきたとする。
- 伐採時期や下水道工事との因果関係について、このページ単独では具体的に記していない。
