# [GOV-022] 豊島区「鬼子母神大門ケヤキ並木」

## 書誌・所在

- 豊島区公式ホームページ、ページID 41981、2022年10月25日更新。2026年10月31日に本文を確認。
- 原ページ：https://www.city.toshima.lg.jp/349/bunka/bunka/bunkazai/naturalmonument/2209260935.html

## 内容メモ

- 1937年（昭和12年）時点に大径のケヤキが18本あったと記す。
- 保存会の活動と1940年（昭和15年）の東京都天然記念物指定に言及する。
- ページの説明時点では大径木が4本となり、若いケヤキへ植え替えられてきたとする。
- 伐採時期や下水道工事との因果関係について、このページ単独では具体的に記していない。

## 追記（2026-11-17、第149回・江戸期の由来伝承の文言候補・[GAZ-013](../gazetteers/GAZ-013.md)経由）

- 『御府内備考』巻之五十二「雜司ケ谷町」条（丙戌書上＝文政9年・1826・大系版第3巻NDLJP:1214872のOCR全文）の大門の項に、**ケヤキ並木の由来伝承の文言候補**がある——「**此所往還町屋前にけや木並有之是は天正之頃當時之住人長島內匠と申者鬼子母神え奉納に植付候よし右內匠子孫當時村方年寄に而文左衛門と申者**」＝**大門前のケヤキ並木は天正の頃に当時の住人・長島內匠が鬼子母神への奉納として植え付けたもので、内匠の子孫は文政9年時点の村方年寄・文左衛門である、という町方書上レベルの由来伝承**（文言はOCR由来で原文画像照合を要する）。
- 本ページ（区の天然記念物解説・1937年18本・1940年指定）に対し、**約110年前の江戸期の書上由来譚**としての位置づけ。植付年代「天正之頃」・人物・子孫の氏名は伝承文言であり、現存並木の植栽年代・本数の根拠としては採用しない。長島內匠は同条の町名起立伝承（南朝流浪の禁中雑式の人物）と同一人物と書上は扱っており、[GAZ-013](../gazetteers/GAZ-013.md)第149回追記・対照表の雑司ヶ谷行と併せて参照。出典（書上本文の採録先）: [GAZ-013](../gazetteers/GAZ-013.md)（第149回追記）。
