# [GOV-086] 高田1・2丁目の土砂災害警戒区域新規指定（令和8年6月24日）

- **内容〔スニペット確認〕**：豊島区「豊島区土砂災害ハザードマップ」ページの記述として「**令和8年6月24日付の東京都告示により、高田1・2丁目が土砂災害警戒区域の新規指定**、駒込1丁目の土砂災害（特別）警戒区域が一部解除となりました」〔**高田1・2丁目（弦巻川が流れた谷頭・目白崖線下の傾斜地）の土砂災害警戒区域指定を示す行政記録としてrepo初出**〕。
- **意義〔解釈〕**：弦巻川の谷頭・崖線（雑司が谷〜高田の谷地形）が、2026年時点の防災行政上は急傾斜地の土砂災害リスク区域として指定されたことを示す。旧川の谷地形と現行の防災区域指定の対応を記録するもので、河川史・地形の直接史料ではない。
- **関連**：東京都建設局「土砂災害（特別）警戒区域の区市町村別指定状況」（ https://www.kensetsu.metro.tokyo.lg.jp/river/dosha_saigai/kasenbu0105/kasenbu0102 、令和8年8月26日現在）。
