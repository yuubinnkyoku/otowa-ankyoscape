# [GOV-010] 神田上水廃止後の巻石白堀の工業用水利用

- 東京都水道歴史館「小石川区砲兵工廠（上水樋線之図）」：https://www.ro-da.jp/suidorekishida/content/detail/K0224
- 同館「明治四十四年十二月 神田玉川上水水料徴収原簿」（1911年）：https://www.ro-da.jp/suidorekishida/content/detail/K0334
- 神田上水は1901年に東京市内への飲料水供給を廃止したが、小石川の巻石白堀は砲兵工廠への工業用水路として1935年頃まで維持されたとする公式資料解説。1912年地籍図556～559コマの旧水路表現を読むうえで重要。ただし弦巻川の合流や当該地点の通水を直接証明しない。
