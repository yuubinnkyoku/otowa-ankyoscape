# [GOV-253] 北豊島郡板橋町現状調査（1931）— 板橋町の形成と金井窪の行政統計

- **書誌〔確認〕**: 東京市臨時市域擴張部『北豊島郡板橋町現状調査』（昭和6年＝1931。市域拡張に伴う郡部町村の現状調査シリーズ）。NDL次世代デジタルライブラリー [book/1900500](https://lab.ndl.go.jp/dl/book/1900500)。**引用文言はOCR由来で要原文照合。**谷端川・千川上水の直接記述は本冊のOCR範囲では確認できなかった（水路言及なし）。
- **板橋町の形成沿革〔確認・明治22年境界問題の行政側文言〕**: 「**其後明治廿一年町村制ノ制定サレシヨリ 最初下板橋宿ハ金井窪村滝野川ノ部ヲ合シテ下板橋町ヲ構成スルヲ當然トセシモ 其後中丸村及池袋村ノ一部ヲモ加ヘテ板橋町ヲ形成シテ以耒現在ニ及ヘリ**」＝**①明治21年町村制定の際、当初の構成案は下板橋宿＋金井窪村滝野川ノ部（＝金井窪村のうち滝野川側の地域）で下板橋町を構成する予定だったこと、②その後中丸村と池袋村の一部も加えて板橋町となったこと**＝町村制施行期（明治22年）の板橋町の範囲確定の経緯の行政側記録。〔[BLOG-050](../blogs/BLOG-050.md)・[BOOK-115](../books/BOOK-115.md)（明治22年の板橋町境界・金井窪の帰属）の文脈に対し、市域拡張期（1931）の公式調査書の側からの裏付け文言。〕
- **金井窪・下板橋の行政統計〔確認〕**: 金井窪・下板橋・中丸の町会議員・有権者数・職業別統計（金井窪673?・下板橋994等の数値・OCR要照合）等、金井窪地区の1930-31年時点の行政単位としての統計資料。谷端川沿いの金井窪低地の人口・町政の基礎数値としての利用価値。
- **シリーズ内の位置づけ〔観察〕**: [GOV-165](GOV-165.md)（長崎町現状調査・同シリーズ）と同一シリーズの未登録分。隣接冊の西巣鴨町現状調査 [book/1900499](https://lab.ndl.go.jp/dl/book/1900499) はOCR範囲に水路言及なし（見送り・第116回ノート参照）。
