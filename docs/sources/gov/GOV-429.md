# [GOV-429] 享保撰要類集 二十五ノ下ノ下 — 「神田上水白堀」の享保17・18年の見廻名簿文言

- **書誌〔確認〕**: 『享保撰要類集』二十五ノ下ノ下。町奉行関係の行政事例綴（[GOV-428](GOV-428.md)（二十一ノ下）・[GOV-430](GOV-430.md)（二十六ノ上）と同シリーズ）。NDL次世代デジタルライブラリー [book/2572836](https://lab.ndl.go.jp/dl/book/2572836)。**引用文言はすべてOCR由来で要原文照合**。
- **名簿の構造〔確認〕**: 本冊には享保7年〜19年にわたる年次別の役人名の一覧（「一享保七寅年大岡越前守但馬守樋口次郎左衛門…」「一享保十二未年岡野伝左衛門諏訪美濃守組同心…」「一享保十五戌年両田作左衛門大岡越前守組…」等）が続き、その列の中に**「**神田上水白堀**」の見出し語の直後に享保17（子）・18（丑）年の行**が置かれる。「**神田上水白堀一享保十七子年平塚伊左衛門大岡越前守但馬守生田覚左衛門稲生下野守組見高木伊助大岡越前守祖恩(?)十河儀左衛門稲生下野守御馬方一享保十八丑年平塚伊五左衛門大岡越前守学力(?)生田覚左衛門稲生下野守但ゆつ(?)高木伊助大岡越前守御見損(?)川武左衛門稲生下野守様与力**」。
- **読み取り〔文言候補・掲げるのみ〕**: ①見出し語「神田上水白堀」が享保17・18年（1732〜33）の行の直前に置かれ、白堀に関わる年次名簿であることを示す、②人名（与力候補: 平塚伊左衛門/伊五左衛門・生田覚左衛門・稲生下野守（稲生家＝神田上水の樋方与力の名家との対応は要照合）・高木伊助・十河儀左衛門・川武左衛門）と「組見」「御見」「様与力」等の職務語候補が並ぶ、③「大岡越前守」＝南町奉行・大岡忠相の在職期（享保年間）と整合し、白堀の点検・見廻が町奉行組の与力・同心の実務であった体裁、④前後の年次行（享保16亥年「平塚伊右衛門但七月より家作改而止…与力御普請役生田覚左衛門」・享保19亥年「平塚伊左衛門大岡越前守組与力御駕五郎太夫稲生下野守御見…」）の職務との膝付き関係（家作改・御普請役の名簿の延長か、白堀固有の名簿か）は原画像の見開き構造の確認が前提。
- **意味〔観察〕**: [GOV-423](GOV-423.md)第48〜49条（寛保元年4月・上水樋枡世話の町年寄移管と「両組与力白堀懸り仮止」＝白堀の町方移管）の起点、すなわち**「白堀懸り」の与力行政が寛保以前のどの程度遡るか**が白堀管理史の未解決事項だったが、本冊の文言候補は**享保17〜18年に白堀の見廻・点検の当番名簿が既に存在した（可能性の指摘にとどめる）**ことを示す。[対照表](../../地名・河川名対照表.md)白堀行の通時系列の1728年（享保13年被災・浚渫）と1732〜33年（本冊の名簿文言）の層の間を埋める位置づけ候補。
