# [GOV-009] 谷端川北緑道

- 豊島区公式「谷端川北緑道」。
- https://www.city.toshima.lg.jp/340/shisetsu/koen/042.html
- 1962年の河川廃止、1971年の児童遊園・遊歩道化、1990年の施設改修を説明。
- **追記（2026-11-11 第20回・[Wayback Machine 2025年4月18日スナップショット](https://web.archive.org/web/20250418162545/https://www.city.toshima.lg.jp/340/shisetsu/koen/042.html)で本文直接確認。現行ページはJScookieで本文取得不能）**：覆蓋上部を**昭和46年に谷端川第5児童遊園及び遊歩道として都下水道局より承認を受け開放**。**平成2年の施設改修整備で西前橋から東武東上線下板橋駅前の自転車置場に至る区間**が谷端川北緑道に。**面積2,765.73平方メートル、開園は平成3年4月**（最寄り: 下板橋駅）。川の流れをイメージした舗装の広場・モニュメント・遊具の記述〔"川の流れ"を模したタイル・バラのアーチなど緑道の意匠の公式叙述〕。
