# [GOV-199] 東京市豊島区勢要覧 昭和10年版（1935年）— 豊島区の地勢の三川並記

- **書誌〔確認〕**: 東京市『東京市豊島区勢要覧（昭和10年版）』（1935年）。NDL次世代デジタルライブラリー [book/1281540](https://lab.ndl.go.jp/dl/book/1281540)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **地勢記述〔確認・repo初出の1935年三川並記〕**: 「地形ハ大體東西ニ長クシテ南北ニ短ク、**西南ニ鶴卷川、西北部ニ谷端川、西部ニ千川ノ細流アリ**、延々秩父ノ連峰ヲ望ミ地勢〓シテ臺地ヲ爲ス」＝**1935年時点で鶴巻川（弦巻川）・谷端川・千川が区勢要覧に現存河川（細流）として並記**されていた記録。高度は高所32m・低所21m。〔文言はOCR要照合〕。
- **位置づけ〔観察〕**: **鶴巻川が区の「西南」に位置するとの1935年の公式記述**＝弦巻川（鶴巻川）の存在を区勢要覧レベルの公的資料で確認（弦巻町の地名由来（GOV-185系の「弦巻町」記録）と対応する谷筋として、池袋〜雑司が谷〜目白方面の低地を指すと解される（推定））。千川を「細流」とする表現は、千川上水廃絶後の用水残流の呼称と整合する。三河川の位置関係（千川＝西部・谷端川＝西北部・鶴巻川＝西南）が一枚の文言で押さえられた点が価値。

## 制限・未解決

- ①鶴巻川のこの時点での流態（開渠・暗渠の別）は本文では特定できない。②「細流」の実態（通水か、雨水路化か）は未確認。③区勢要覧の他の記述（街区・上下水道）の千川・谷端川関連文言の精査は未実施。
