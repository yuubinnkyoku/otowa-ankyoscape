# [GOV-002] 豊島区「元池袋史跡公園」

- 豊島区公式「元池袋史跡公園」。
- https://www.city.toshima.lg.jp/340/shisetsu/koen/030.html
- 丸池について「弦巻川の源流として清らかな水が湧き出していました」と明記。現在の史跡公園は丸池そのものの現存位置ではなく、土地交換後に隣接地へ開園したもの。
