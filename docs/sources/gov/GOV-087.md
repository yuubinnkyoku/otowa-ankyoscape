# [GOV-087] 城北中央公園調節池1号ケーソンの完成と2026年夏の大雨での稼働

- **資料〔確認：報道本文〕**：産経新聞（宇都木渉記者）「[東京・石神井川沿いに現れた『地下神殿』豪雨災害対策の巨大な箱、調節池を見に行った](https://www.sankei.com/article/20251216-5UE53GD3XJLEFJD76EDX7LJA4E/)」（**2025年12月16日**）。東京都建設局が報道陣に公開した**城北中央公園調節池**の現地取材記事。〔確認：報道二次資料だが現地公開の内容を直接確認〕
- **1号ケーソンの完成〔確認〕**：**平成30年（2018）度から2026年6月までの約7年弱**をかけ、**幅33.4m・延長80.3m・高さ35.3m**（25mプール約300杯分）の「1号ケーソン」が完成。隣の地下では「2号ケーソン」の工事が同時進行で、完成すれば全体で**約25万m³の貯水能力**になるという。2つのケーソンを同時に沈下させる工事としては日本最大級の規模。
- **2026年夏の大雨で稼働〔確認（都担当者の説明として）〕**：1号ケーソンは**2026年7月の都内大雨でさっそく活躍し、地域を浸水被害から救った**と説明された。時系列は[GOV-083]の2022年時点の計画（163m×33m×深35m・9万m³・2021年度着工見込み）から進捗したもので、**約9万m³（1期）→全体約25万m³（2期併せて）**という[GOV-083]記載の数値計画を裏付ける報道。
- **意義〔解釈〕**：石神井川の75mm/h対応整備（[GOV-082]の千川増強幹線と同じ2013年8月豪雨が契機）の一翼。**谷端川放水路（1924/25年次問題）が石神井川への放流を担った歴史経緈（[BOOK-031]・[BLOG-090]）に対し、石神井川治水は現在も継続拡張中**という現在進行形の文脈資料。
- **未確認〔注意〕**：2号ケーソンの竣工時期・全体事業完了年は記事に示されず未確認。
