# [GOV-439] 南撰要類集[84] — 江戸川神田川筋渡助成地地代金の貸付利息と小日向境2橋の1804年掛直

- **書誌〔確認〕**: 『南撰要類集』[84]（享和〜文化初頭〔1801-1804〕頃の橋関係の書付群・部名・巻次の特定はOCR上未確定で要照合）。NDL次世代デジタルライブラリー [book/2550493](https://lab.ndl.go.jp/dl/book/2550493)。**引用はすべてOCR由来で文言は要原文照合。**
- **京橋掛替普請の財源としての江戸川神田川筋渡助成地地代金の貸付利息〔確認・repo初出の制度文言〕**: 亥8月の伺書——「**去之酉年以来門三郎申上伺之通郡代役所ニ而貸附被仰付候江戸川神田川筋渡助成地地代金等有余之分貸付利番…八百五十両弐分御金蔵え当時飯納仕置…京橋掛直し御入用に遣ひ払候様可仕哉**」＋書付末尾「**享和壱亥年十一月**」（小田切土佐守組与力松浦安右衛門・根岸肥前守組与力安藤小左衛門）〔**①「江戸川神田川筋渡助成地地代金」（=寛延3年〔1750〕設定の渡助成地〔[GOV-373](GOV-373.md)の本所相生町2ヶ所・二葉町1ヶ所・永代橋/新大橋の渡銭の助成地〕の地代金）に余剰分があり、郡代役所で貸付に回されていたこと、②その貸付利息（「利番」は利子のOCR候補）が金850両2分として御金蔵に納入済みであること、③その利息を京橋の掛替普請の御入用に払い下げる伺であること**＝**渡助成地の地代金が50年後に「江戸川神田川筋」の常設財源として運用され、御入用橋（[GOV-238](GOV-238.md)・[GOV-239](GOV-239.md)の千両橋システム＝定請負橋の公役金）の修復財源に回るという神田川（江戸川）の渡・浚財政システムの中間層（1750→1801）〔repo初出〕**。④「去之酉年」＝享和元亥（1801）から前の酉年（寛政9〔1789〕候補）で貸付の開始時期はOCRの干支対応も含め要照合。
- **文化元年（1804）9月の水道町⇔西古川町の江戸川渡り橋（長6間・幅1間）の町入用掛直〔確認・repo初出の一次記録〕**: 「**私とも町内ニ在戸川〔江戸川〕を渡候長六間二幅壱間之橋壱ケ所…前之町内角〔費〕を以掛来候所打損…此度町入用を以**」（子9月29日願・水道町月行事十右衛門・西古川町武兵衛）〔**①長6間×幅1間の町方持（町入用）橋が江戸川（神田上水開渠）を渡っていたこと、②寸法が天保6年（1835）の掃部橋（橋長6間＋橋台7間2尺・幅1間＝[GOV-213](GOV-213.md)）と近似すること＝掃部橋の1835年の35年前の姿の候補だが、下項の両町境の橋との関係（別橋か・同橋の別書付か）は原照合まで断定しない**〕。
- **文化元年10月の両町境の江戸川渡り橋（長2間・幅1間）の掛直〔確認・repo初出〕**: 「**私とも両町境二有之候江戸川を渡候長二間巾壱間之橋壱ケ所前々町内入用を以掛ケ来候所打損候ニ付此度も町入用を以先規之通掛ケ直申度**」（文化元10月・8月29日願→晦日見分→御伺→御成→普請→出来・10月18日見分）＋「**古川橋迄之間三十間程有之候ニ付往来差障り義無御坐候**」〔**①小日向水道町⇔西古川町の両町境に江戸川を渡る長2間×幅1間の町入用橋があり1804年に先規どおり掛直されたこと、②当橋から古川橋（東古川町側・[GOV-213](GOV-213.md)の麁朶橋）まで約30間の距離文言＝[GOV-213](GOV-213.md)の掃部橋から見た「古川橋江三拾間程・江戸川橋江壱町程」の距離体系と「水道町より西古川町え渡ル字掃部橋」（[GOV-221](GOV-221.md)・[GAZ-035](../gazetteers/GAZ-035.md)）の位置記述との対校文言候補＝両町境の橋が掃部橋（またはその前身・近接別橋）の候補になること、③願→見分→伺→普請→出来見分の約1.5ヶ月の小修復実務スケジュール（十両以下の町入用橋の無伺格の運用＝[GOV-239](GOV-239.md)・[GOV-438](GOV-438.md)の閾値制度の運用例）**。④30間の距離文言は上項の長6間の橋と本橋のいずれから測ったものか（OCR上は本橋の書付に接続）も原照合課題。
- **位置づけ〔観察〕**: ①本資料の「江戸川神田川筋渡助成地地代金」の運用は、**寛延3年（1750）の渡助成地・渡銭制度（[GOV-373](GOV-373.md)）→享和元年（1801）の貸付利息の御入用橋流用（本冊）→文政9年（1826）の「江戸川神田川常浚御手当」の恒常システム（[GOV-440](GOV-440.md)）**という神田川（江戸川）の渡・浚財政の通時系列の中間点に位置する。②1804年の2橋の町入用掛直は、**1845年銘書の小日向3橋（大道町⇔水道町・西古川⇔水道町・水道町⇔服部坂・里俗菊桟橋・掃部橋・唱無之〔[GOV-220](GOV-220.md)〕）の41年前の実務記録**で、水道町⇔西古川町間の江戸川渡りの小橋群（[GOV-213](GOV-213.md)天保6掃部橋流失再建を挟む）の19世紀初頭の定点になる。
