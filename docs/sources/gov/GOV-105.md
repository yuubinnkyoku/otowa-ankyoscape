# [GOV-105] 杉並区立郷土博物館ADEAC・千川関係資料3件〔いずれもrepo初出〕

ADEAC「杉並区立郷土博物館」コレクションで千川関係を目録探索したところ、3件を確認した〔目録頁をcurl+UAで取得〕。**杉並区のコレクションからの千川家側・千川上水記録はrepo初出**。

- **①須田家文書「覚（分水口水門差蓋笠木ほか伏替のため立合に付）」mus-013863（整理番号12-113-2）・7月6日・江戸〔確認: 目録〕**: 差出＝**千川善蔵・千川金七**／受取＝**遅野井村・天沼村・荻久保村・阿左ヶ谷村・鷺宮村・井草村・中村（7か村）**。キーワード＝千川用水/千川上水/上井草村/下井草村/阿佐ヶ谷村/上鷺宮村。〔**「千川」姓の差出人が千川上水の分水口水門の修理（差蓋笠木の伏替）に7か村の立会いを求めた文書**。①千川家文書の所在として[GOV-089](GOV-089.md)（neribun 297点・練馬）・小川家文書（[GOV-100](GOV-100.md)・小平）に続く**第三の系統が杉並区（須田家＝下荻窪村村役人の旧家・杉並区指定有形文化財）で確認できた**こと、②**分水口水門の修理に沿線受益村の立会いを求めた運営実務**がうかがえること、が新規。年は「江戸」表記のみで特定なし〕〔[目録](https://adeac.jp/suginami-city/catalog/mus-013863)〕
- **②矢嶋又次記憶画「天沼弁天池」mus-003877・1978年・水彩〔確認: 目録・公開解説〕**: 杉並区地域の学び推進課蔵（区民の描いた記憶画・昭和50年代）。公開解説に**「千川上水の分流と共に、天沼、阿佐ヶ谷の田に利用され」**、弁財天は池の中央の島（神仏分離で天沼八幡神社の所領になり弁天堂は路傍）という記述。〔[BLOG-162](../blogs/BLOG-162.md)（荻窪の矢嶋又次記憶画・白山通りの湧水小川）の**具体的な一枚の所在特定**。「千川上水の分流が天沼・阿佐ヶ谷の田に利用された」という文言もrepo初出〕〔[目録](https://adeac.jp/suginami-city/catalog/mus-003877)〕
- **③杉並区広報課写真「井草五丁目の千川上水街道」koho-photo-264・**昭和23年（1948）**撮影〔確認: 目録・CC BY-NC-ND〕**: 〔**「千川上水街道」という呼称が1948年の区広報写真のキャプションで使われていた**記録＝千川上水沿道を「街道」と呼ぶ用例の年代特定資料候補（本文・画像の内容確認は画像判読まで・断定はしない）〕〔[目録](https://adeac.jp/suginami-city/catalog/koho-photo-264)〕
- **④杉並区広報課写真「千川上水通り（井草五丁目）」koho-photo-084・昭和23年（1948）撮影〔確認: 目録・2026-11-14追記〕**: ③と同年代・同地域（井草・今川・清水・桃井地域）の別写真で、ADEAC「千川」横断検索（[GOV-110](GOV-110.md)）で確認。主題＝道路・陸橋。〔③「千川上水街道」と④「千川上水通り」の**1948年時点の呼称の並用が区広報写真キャプションで確認できる**。画像本文は未確認〕〔[目録](https://adeac.jp/suginami-city/catalog/koho-photo-084)〕
- **意義〔観察〕**: ①千川家文書の所在が3系統（neribun・小川家文書・須田家文書）になった。②杉並区側（六ヶ村分水エリア）の千川上水の運営・記憶の資料が一次文書・記憶画・写真の3層で確認できた。③adeac suginami-cityコレクションの千川関係の通し調査は今回が初回で、追加挖掘の余地が残る。→**2026-11-14追記: 通し調査（GOV-110）で「千川」48目録レコード・星野家文書664点・記憶画2枚（GOV-109）・樋伏替人足出願（GOV-108）を追加確認した。**
