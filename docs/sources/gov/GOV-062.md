# [GOV-062] 豊島区教育委員会 見学会記録「豊島区の歴史をたずねて（雑司が谷編）」

- **直接確認（2026-11-11、open_url・PDF本文）**：東京文化財ウィーク2005企画として2005年10月28日に開催された区教委主催見学会の記録PDF（豊島区デジタル区史・adeac）。案内人は横山恵美学芸員。コースは弦巻川沿い（丸池を水源とする神田川への川と説明）。
- **石橋記念供養塔〔区教委記述〕**：1733（享保18）年に木村氏が弦巻川に石橋を架けた記念に建立され、亡き両親の供養塔を兼ねていた。かつてここで村人の葬礼・野辺送りが行われたとする。※現在地は清立院・御嶽坂下周辺との対応が地図豆（BLOG-049）で示されるが、本PDFでは番地未記載。
- **高田町鶴巻川暗渠記念碑〔区教委記述〕**：大鳥神社の項に「1932（昭和7）年の高田町鶴巻川暗渠記念碑」と記す。※地図豆（BLOG-049）は同社の碑を「昭和6年（1931）の下水道施設記念碑」とする。碑名・建立年の両説を本ファイルに併記する。※現地確認は未実施。
- **表記〔区教委注記〕**：予定稿では「鶴巻川」だったが、「鶴」「弦」の両説があり両方が使用されているため、本稿ではより一般的な「弦巻川」に改めたと注記する。
- **その他の内容メモ**：弦巻川を「夏は蛍、秋は月の聖なる川」と流域の人々の生活を支えた川と紹介する。丸池（「池袋」の地名由来とも言う）を水源とし神田川に注ぐと説明する。清立院（雨乞いの請雨松・かさもり薬王菩薩）、雑司ケ谷霊園の御鷹部屋、清土鬼子母神の三角井（星の井）なども見学先に挙げる。
- **制限〔未解決〕**：石橋記念供養塔・暗渠記念碑の現地確認、野辺送りの一次史料（過去帳等）は未確認。
