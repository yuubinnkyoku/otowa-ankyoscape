- **河川水質調査表の測定駅名〔確認・表本体は画像化で数値未確認〕**: honcho4所収の**第135表〜第140表の河川水質調査結果**のうち、**第135表＝白子川・東埼橋**から**第140表＝富士見池**までの測定駅名を確認〔表の本体は静止画化されていて測定値・年次の本文読み取りは不能。**白子川の東埼橋**という測定地点名の記録、**富士見池**の水質調査実施の記録＝区内の池・河川の水質行政の一次資料。測定駅名・対象水域の一覧の全体確定は表画像の照合待ち〕。
- **「きれいな石神井川の確保についての要望書」〔確認・上程昭和49年8月23日〕**: 提出者＝区議会議長**田口阿久理**〔本文印字〕。石神井川の水質確保の要望で、**昭和47年9月26日の3区3市合同調査**・**BODが悪臭限界10PPM超**・**分流方式**への切り替え・**三次処理用水流入**の各文言〔石神井川の戦後水質行政の要望書の一次文言。石神井川は石神井川水系（田柄川の本流側）で、repoの石神井川水系の水質史として記録〕。
