# [GOV-449] 豊多摩郡野方町現状調査 — 妙正寺川流域の水田残存の1931年定点

- **書誌〔確認〕**: 『豊多摩郡野方町現状調査』（東京市臨時市域**擴張部**編・[book/1900481](https://lab.ndl.go.jp/dl/book/1900481)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**野方町（1932年中野区野方）冊**。
- **妙正寺川流域の水田残存〔文言候補・本ファイルの核心〕**: 「**本町ノ西南部ハ住宅客集（密集?）シ旣ニ都市的形態ヲ充分ニ満（具?）ヘタル地域ナレドモ中央部ヲ東西ニ貫流スル妙正寺川ノ流域ハ尚一〓ノ水田ヲナシ、東北部一帶ハ土地平担（平坦?）ナル畑地ニミテ新住宅其ノ间（間?）ニ介在三（在リ?）現在ニテモ練馬大根ノ名産地タル面影ヲ〓（ニ?）残セリ**」＝**①1931年時点で野方町の中央部（＝妙正寺川（＝弦巻川の現在呼称）の流域）に水田が残存していたことの行政側の明記、②東北部の平坦な畑地（練馬大根の名産地の「面影」＝名残り）**〔**妙正寺川（弦巻川）流域の土地利用の1931年の定点＝水田残存と畑地（青果産業）の帯の記録。弦巻川流域の都市化の進行度（下流の落合・戸塚側の市街化に対する上流側の農地残存）を行政調査レベルで確認できる文言**（[GOV-442](GOV-442.md)（落合町・同一水系の下流側）の「卑濕平坦ナル低地」＝市街地化との対照、[GOV-098](GOV-098.md)「練馬区史経由の弦巻川水田記述」等の水田系記述と同系列をなす）**。「水田ヲナシ」の意味（全面的な水田帯ではなく「一畦歩（?）の水田」程度の断片残存の可能性）は原画像照合まで断定しない**。
- **荒玉水道町村組合〔文言確認〕**: 「**(H)荒玉水道町村組合組合會議員三名**」＝野方町から荒玉水道町村組合（大正期の中野・杉並・豊多摩郡域の上水道組合）へ組合会議員3名を出していたことの記録（[GOV-450](GOV-450.md)瀧野川町・[BLOG系]荒玉水道と対照する豊多摩郡側の組合加盟の文言・給水区域の系譜への追記）。給水側の文言「**旣ニ荒王水道ノ敷設全町ニ及ベルモノアリテ将耒下水道ノ完備卜相俟チテ隣接、中野杉並ノ両町卜共ニ両郊ニ於ケル好〓ノ住宅地域タルベキコト疑ヒヲ入レズ**」＝**「荒玉水道の敷設が全町に及び、将来の下水道の完備と相まって 中野・杉並とともに良（好?）住宅地域となる」という将来展望の文言＝下水道未完備（水道整備が先行）の1931年時点の野方のインフラ状況の記録**〔下水道の計画文言そのものではなく展望文言なので、水田・畑地の土地利用と下水道整備の関係を示唆する材料として記録〕。
- **帳簿文言〔確認〕**: 人口・伝染病・区会議員・学務委員・IH荒玉・豊多摩病院組合等の帳簿（OCR数字崩壊大）＝1932年市域拡張直前の野方町の帳簿。

## 制限・未解決

- ①「尚一〓ノ水田ヲナシ」の「一〓」の原字（「一画」等の判読不能・範囲の大小は原画像照合まで確定しない）。②荒玉水道の文言中の「將耒下水道ノ完備」の読みは崩れ含み。③地理的「西南部住宅密集」・「中央部水田」・「東北部畑地」の字範囲の比定（大字単位）は本冊ではなされず今後課題。④荒玉水道町村組合の野方町加入（年次）の確定は他資料（組合史）に依る。
