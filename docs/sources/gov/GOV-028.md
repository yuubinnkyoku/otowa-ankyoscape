# [GOV-028] 豊島区「池袋の森」（公園施設案内）

- **資料・年代〔確認〕**：豊島区公式「池袋の森」（ページID 7316、**2015年2月25日更新**）。施設所在地は**池袋1-7-10**、面積**1,501.27m²**、開園は**1997年（平成9年）4月**。園内は林学博士の旧住宅の樹木を引き継ぐと説明する。
- **池の水源〔確認：公的施設案内の記述〕**：園内には**「井戸水をくみ上げた池」**があり、トンボやアサザが見られると記す。**現在の池が自然湧水の露頭である、あるいは旧谷端川支流の水源が残存している、と直接示す記述ではない**。
- **周辺の土地利用〔確認：2023年の地域団体による現地案内板の紹介／原案内板未照合〕**：NPO「いけぶくろねっと」の**2023年10月13日**の記事は、2021年設置の現地案内板を引用し、**島田牧場が1907年に創業し1928年まで営業**したこと、園内の池は牧場で使用していた井戸の水と説明されることを紹介する。これは**現地案内板の二次転記**であり、牧場の営業期間・井戸の継続利用を一次資料で確認したものではない。
- **比較・注意〔観察〕**：個人の暗渠踏査サイト D.2.C. の記事一覧は、同公園を**「トンボ池（湧水）／谷端川 島田牧場支流・島田屋敷支流」**と呼ぶ。しかし区の公園案内は**井戸水の揚水**と記している。**現代の池の存在や呼称だけから、自然湧水の持続、近代以前の池・旧水路、谷端川との水理的接続を確定しない**。揚水する井戸の掘削年・深度・帯水層・揚水方式・現在の水量・旧牧場時代との施設同一性は未確認。
- **調査課題〔未解決〕**：1907～1928年の地籍図・土地利用図・井戸記録と、島田牧場支流・島田屋敷支流と呼ばれる線形を比較する。井戸・池と旧谷端川の支流候補は**別々の証拠で同定**する。
- **出典**：豊島区「[池袋の森](https://www.city.toshima.lg.jp/340/shisetsu/koen/064.html)」（2015年2月25日更新）／NPOいけぶくろねっと「[『池袋の森』は牧場だった](https://w3.ikebukuro-net.jp/archives/info/bokujyo202310)」（2023年10月13日、2021年案内板の二次紹介）／D.2.C.「[COLUMN 2015年7月](https://d-2-c.jp/column_back84.html)」（「島田牧場支流」等の調査上の呼称）。
