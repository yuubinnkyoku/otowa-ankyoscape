# [GOV-364] 御府内場末往還其外沿革圖書 貮拾貞（嘉永7年10月調）— 感応寺上ヶ地の全容・中丸橋と用水堀・「千川分水」文言候補〔第159回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の[28]冊「貮拾貞」（**嘉永七寅年〔1854〕十月調**）。NDL次世代デジタルライブラリー [book/2587247](https://lab.ndl.go.jp/dl/book/2587247)。[GAZ-012](../gazetteers/GAZ-012.md)が確認した第20部の巻構成（元=[21][22][23]・亨=[24][25]・利=[26][27]・**貞=[28][29][30]**）では**「貞」の第1分冊**に当たり、表紙文言に「**嘉永七寅年十月調御府内場末往還沿革図書弐拾貞 雑司ヶ谷村高田村下落合村払巣鴨村代地雑司ヶ谷村小石川村代地下板橋宿池袋村前野村新田堀之内村巣鴨村瀧野川村金井窪村…中丸村長崎村上板橋村一円之絵図弐枚**」とあり、**谷端川上流域（雑司ヶ谷・高田・下落合・長崎・中丸・金井窪・下板橋）と千川上水沿線（池袋・長崎・中丸・金井窪）の村々を一冊に収める帳**（一部にOCR欠落文字あり）。メタデータの図版タグはgraphic_map 15件（多時点の絵図を含む）。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する**。
- **GOV-360制限③（「沼革弐拾之部」の帳の所在）の解消〔確認〕**: 本冊の御役所掟の目録に「**雑司ヶ谷村感応寺上ケ地小出信濃守下屋鋪神職修験拝領地其外下落合村高田村辺之部**」の条が立ち、本文に感応寺上ヶ地の全容が載る＝[GOV-360](GOV-360.md)（貮拾貮上・安政5年調）の天保13年文言の注明「右は沼革弐拾之部ニ出ルに成」が指す**「（沼革）弐拾之部」の帳の実体は第20部（弐拾）の本冊（貮拾貞）**と特定できる（部20の帳簿群のうち感応寺上ヶ地の条を立てる分冊）。
- **感応寺上ヶ地の全容年代層〔確認・文言候補・時系列〕**: 本文（押田近江守抱屋鋪辺之部に続く雑司ヶ谷村感応寺上ケ地条）の記述を通時的に並べると次の通り。①**延宝年中**＝「右一圓之地所**延宝年中は南手下落合村高田村百姓地ニ而其外当所ゟ東西え続一円安藤但馬守下屋鋪**」（当時は下落合・高田の百姓地と安藤但馬守下屋敷）。②**天和3年（癸亥・1683）**＝「当所ゟ東手地続は**天和三亥年中上ケ地ニ成**」（安藤下屋敷の東手が上地化。別所に「天和三庚年中」という表記もあり**「庚」は天和3年=癸亥と干支が合わないためOCR変種候補**・原字照合待ち）。③**天保5年（1834）5月**＝「**天保五午年五月安藤對馬守元右下屋鋪一圓御用に付被召上本所押上吉川四方之進屋鋪之内被召上為代地被下感応寺境内に成**」＝安藤対馬守の元下屋敷が召上げられ（安藤家の代地は本所押上の吉川四方之進屋鋪の内）、**当所は感応寺境内となった**＝[GOV-168](GOV-168.md)②の国立公文書館一次記録「雑司谷安藤対馬守屋敷感応寺江被下一件」（天保5年5月）と**年月・内容が完全に整合**。④**天保12年（1841）10月**＝「**同十二丑年十月思召有之感応寺廃寺被仰付上ケ地二成**」＝**感応寺が廃寺と仰せ付けられ上地となった年月の文言候補**（[GOV-360](GOV-360.md)の比定問題への新たな年代制約。谷中感応寺〔天保期の取潰しで知られる系統〕との異同等の比定は本帳からは確定できない）。⑤**天保13年（1842）正月〜2月**＝「**同十三寅年正月小出伊勢守当時浅草山之宿町下屋鋪御用に付被召上右感応寺上ケ地之内え新規道敷出来**」＋同年2月の替地文言＝[GOV-360](GOV-360.md)（貮拾貮上）の天保13年文言・猿若町芝居移転の替地行政と**同一事件の雑司ヶ谷側の記録として整合**。⑥**天保14年（1843）4月〜天保15年（1844）4月**＝割残地の処分と、「**同人願之通高田村芳心院領之内切縮道巾廣く成右寺領代地は同人下屋鋪前道敷行留之処ニ而振替**」＝**高田村芳心院領の寺領と下屋敷前の道幅の振替**（風土記稿〔[GAZ-048](../gazetteers/GAZ-048.md)〕の雑司ヶ谷村領属変遷の元禄14年芳心院領に続く、嘉永期の芳心院領の実務記録候補）。⑦**弘化2年（1845）11月**＝「牛込御細工町末大久保出雲守屋鋪家作とも小出信濃守拝領之節当所同人下屋鋪之内後之方上ヶ地二成」。⑧**弘化3年（1846）11月**＝「**右上ケ地之内西之方遠山安藝守下屋鋪に被下同所東之方割残地に成右割残池幷同所北濱ニ有之**（以下OCR崩壊「…刻残地…小出信濃守…当分御領地二成」）」＝**上ケ地の割残地に「池」と「北濱」が存在した文言候補**（水地形・崖地形の記録。位置の比定は未実施）。⑨**弘化3年7月（前後）**＝「右弐ヶ所之内西之方割残地之内**上州満徳寺境内町屋鋪とに成**」＋「**当山修験羽黒十老并羽黒十老湯殿行人触頭白川家神職羽黒修験え夫々被下地二成**」＝上州満徳寺境内・羽黒修験・白川家神職らへの拝領地処分（感応寺の構成員らしき修験・神職の集団への土地処分として読めるが、断定しない）。⑩**嘉永元年（1848）7月**＝「**感応寺上ケ地割残之内え新田新道敷出来同所之内本多日向守当時下屋敷ニ被下**」。⑪**嘉永5年（1852）3月**＝「**平岡丹波守下屋鋪ニ被下同月相対替ニ而瀧川大蔵ニ至出来同人え当分御預ニ成**」。⑫本条には**延宝年中→天和三→天保五午→天保十三寅・十四卯→天保十五辰→嘉永元申→当時（嘉永7）の多時点の形（絵図）の列挙**があり、感応寺上ヶ地の地形変遷を時系列図で追える体裁になっている。
- **白山御殿取建と雑司ヶ谷村地境の文言候補〔文言候補・OCR崩壊〕**: 「**雑司ヶ谷村地境不詳に候処天和三庚年中白山御殿御取建之節巣鴨村之内被召上**…**巣鴨村代地**…**小石川村代地并雑司ヶ谷村等入会有之候得共代地被下候節之割合不詳**」＝**天和3年頃の白山御殿の取建に際して巣鴨村の内が召上げられ、雑司ヶ谷村に巣鴨村代地・小石川村代地が入会として下された（割合は不詳）という地境変遷の記録候補**（白山御殿の内容・比定は本帳からは確認できない。「庚」の表記は上記の通り要照合。雑司ヶ谷村北辺〔巣鴨との境〕の土地利用史の候補）。
- **中丸橋と村境の用水堀〔文言候補・中丸橋の江戸期先行例〕**: 池袋村・中丸村境の地所書上（重林寺境内続きの持添地の条）に「**稲荷社也中丸橋近藤石見守抱屋鋪前弐ヶ村境ニ用水堀有之**」＝**中丸橋の橋名が嘉永7年（1854）時点の帳簿に現れ、その前の二ヶ村境に用水堀があった文言候補**。〔[BOOK-115](../books/BOOK-115.md)（1922年の中丸橋通りの道路名・「東には中丸橋通」）・[BOOK-109](../books/BOOK-109.md)（1922年・宮の下の橋名）・[BLOG-114](../blogs/BLOG-114.md)（2026年観察の中丸橋跡）の中丸橋の**江戸期の先行例候補**。**橋が架かる川の名は本帳に記されず**、村境の「用水堀」が谷端川（または其支流）・千川上水開渠のいずれに当たるかは本帳からは特定できない（千川上水の池袋〜中丸〜金井窪沿いの村境と符合するが断定しない）。〕
- **用水堀の文言群と延宝絵図の参照〔確認・文言候補〕**: 各村の地所書上に定型文「**延宝年中用水堀等地形不明之ケ所は同年中之絵図書入相除当時之絵図え出之**」（延宝年中の絵図に用水堀として載るが当時の形が不明な箇所は今回の絵図から除く旨）が反復され、**用水堀が延宝年中絵図の地形分類の標準項目であることと、嘉永7年調査が延宝年中絵図を参照して編纂された事実**が確認できる。村境・地所内の用水堀の実文言（川名は不記載）は巣鴨村（十羅刹境内の東北方・氷川〔OCR「水川」〕明神社地の村并び西南方）・巣鴨村滝野川村池袋村辺（東北方）・池袋村中丸村金井窪村辺・長崎村（岡部亮九郎抱屋鋪辺）・下板橋宿（館伊蔵抱屋鋪辺・金井窪村辺）など多数。
- **「千川分水」の図面文言候補〔文言候補・OCR高度崩壊〕**: 池袋村・雑司ヶ谷村辺の図面の文言らしい箇所に「**…勧進田沢同用水溜田…千川分水…**」と読める列がある。**「千川」の語が本帳の図面に現れる候補**だが、周辺のOCRが高度に崩壊しているため原画像照合まで文言として扱わない（「用水溜田」の語も含めて要照合）。
- **鼠山の部〔確認〕**: 目録に「**下落合村長崎村鼠山辺之部**」の条が立ち、延宝年中之形の図面文言に「鼡山鼠山」と見える＝**長崎村・下落合村境の「鼠山」の地名記録**（[GAZ-039](../gazetteers/GAZ-039.md)の2545221〔改正新編江戸志巻之九〕の目次にも「坂落合鼠山」と並ぶ）。**小日向・音羽町の「鼠ヶ谷下水」とは別の地名で、混同しない**。

## 制限・未解決

- ①本帳はくずし字でOCR崩壊が大きい。引用文言（感応寺・芳心院・中丸橋・用水堀・千川分水・白山御殿・鼠山）はすべて原画像照合を要する。②感応寺の比定（天保12年10月廃寺の文言候補は比定の新制約になるが、谷中感応寺系か別寺かは本帳からは確定できない）。③「天和三庚年／天和三亥年」の表記対立（天和3年=癸亥ゆえ「庚」はOCR変種候補・原字照合待ち）。④「中丸橋」の架かる川の特定、および村境の「用水堀」と千川上水・谷端川の対応は本帳からはできない。⑤「割残池」「北濱」の位置比定は未実施（高田村・下落合村境の下屋鋪群の中の位置で、原図照合を要する）。⑥「白山御殿」の内容・比定、⑦「千川分水」の原字はいずれも本帳文言からは確認できない。⑧同冊の絵図（一圓之絵図弐枚・多時点の形）の読図は未実施（画像人手確認待ち）。
