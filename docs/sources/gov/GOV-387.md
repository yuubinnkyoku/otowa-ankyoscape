# [GOV-387] 天保度御改正諸事留 二 — 押切帳に書かれない上水負担の別集扱い〔第165回〕

- **書誌〔確認〕**: 『天保度御改正諸事留』二（天保10寅年正月〜4月の町方行政の諸事留。触・申渡の日付つき列記）。NDL次世代デジタルライブラリー [book/2547389](https://lab.ndl.go.jp/dl/book/2547389)。**引用文言はすべてOCR由来で要原文照合。**
- **天保13寅年（1842）4月20日の町会所触〔確認・核心〕**: 「**天保十三寅年四月廿日山王神田氷川祭礼其外神事ニ付入用掛り高去ル子年迄町入用押切帳之内右掛り出銀差出候町々も有之中には五勺年之内祭礼入用出銀高諸不載無之町々も相見右は町入用押切帳江不差加別集ゟ相見候間押帳え不取出町々は石掛り高内訳相認早々差出可申候**…**一御年貢一公役一自身番火之番屋木戸等之類一持合橋并道造之類一神田玉川上水普請入用一同水銀一鐘役銭拾五軒一白堀浚賃銭一町年寄毎日銭一御年頭銀壱枚右之分にも都而押切帳え不書加号集に仕来候分**」＋「**此段御組合限月行事持場所共不洩様御通達可被成候四月廿日町会所年番折前火**」＝**①祭礼入用は町入用押切帳（町内経費の一本化帳簿）に差し加えず「別集」で処理する慣行、②**神田玉川上水普請入用・同水銀・白堀浚賃銭・鐘役銭（15軒に付き1か）等の公役性の負担も祭礼入用同様「押切帳え不書加・別集に仕来」の別扱い**であることを、子年（天保12以前）までの帳簿実態の洗い出し・差出命令とともに町会所（年番・折前火）が触れた記録〔**白堀浚賃・上水水銀が天保13年時点で町方の帳簿体系では「押切帳外の別集項目」として扱われていた**ことの実務一次記録＝**repo初出**の帳簿制度的文言。寛政期の[GOV-385](GOV-385.md)（定式入用リスト計上）と対照すると、18世紀末には町の年中入用の内訳に数えられた白堀浚賃が、天保の押切帳制度では帳外別扱いと整理された（あるいは元来帳外だったことが明文化された）帳簿上の位置の変化・不変の対校案件。「号集」は「別集」のOCR崩れ候補〕。
- **押切帳制度の文脈〔確認・参考〕**: 祭礼の幟・挑灯の出銀高の記載の有無が町々で不揃いなため「石掛り高内訳」の早々の差出を命じる文言＝天保の「御改正」が町内経費の洗い出し・帳簿の一元化（押切帳）を進める中で、上水負担群は帳外と線引きされた文脈。

## 制限・未解決
