# [GOV-252] 東京市水道改良意見（1892）— 千川上水の樋管延長3,879間と明治期水道論

- **書誌〔確認〕**: 伴直之助著『東京市水道改良意見』（経済新聞社・明治25年＝1892）。NDL次世代デジタルライブラリー [book/845984](https://lab.ndl.go.jp/dl/book/845984)。**引用文言はOCR由来で要原文照合。**
- **千川上水の樋管延長3,879間〔確認・repo初出の数値〕**: 「**千川上水は武州保谷新田に於て玉川より分派し、五里六丁餘にして巢鴨に至り、巢鴨より溝樋總長三千八百七十九間を以て本〓（＝本所か本郷か・OCR欠字）下谷の一部分一萬七千餘の住民に給水す**」＝**①保谷新田での分派・巣鴨まで5里6丁余の開渠、②巣鴨以後の樋管総長3,879間、③樋管先端で1万7千余の住民に給水**という1892年時点の数値記録。〔**樋管延長3,879間は[GOV-226](GOV-226.md)・[GOV-228](GOV-228.md)系の3,707間と対立する表記**。開渠延長「5里6丁余」も[GOV-212](GOV-212.md)（5里24町余）・[MAP-175](../maps/MAP-175.md)（野方堀5里21町余）等と数値が揺れる。いずれも測量・区間定義の差か誤記かは断定せず併記して管理する。〕
- **三上水の構造比較〔確認〕**: 同書に玉川上水（羽村〜四谷大木戸10里31丁・大木戸から溝樋総長5万909間・7区の一部17万6千余に給水）・神田上水（井の頭〜小石川関口5里26丁・関口から溝樋4万90間・3区の一部22万余に給水）の並行記録があり、「**以上三上水の木樋總長は九萬四千八百七十九間 即ち四拾里參拾參丁拾九間を以て人口四十一萬餘に給水するものにして、此の外三萬六千七百個の堀井あり**」＝**三上水の木樋総長9万4,879間・給水人口41万余・堀井3万6,700個という1892年の全体数値**。
- **千川上水の水質批判〔確認〕**: 「**千川上水は玉川神田兩水路の如く取締の習慣なく、五里餘の水路に雨水汚水の流入するは二上水よりも甚し**」＝**千川上水の開渠区間（5里余）に雨水・汚水が流入し、玉川・神田両上水よりも状況が悪いという1892年の評価**＝廃止後の千川上水跡の水質・維持管理状況の同時点観察（水質改善論の文脈）。
- **千川水道会社の実務数値〔確認・repo初出候補〕**: 水道改良後の諸費節減見込の項に「**市內上水使用者より千川水道會社ヘ仕拂ふべき分 千川上水井數並に吹井百十六ケ所 呼樋延長一ケ所に付平均四十五間…此新設浚渫費**」＋「千川三上水井六千六百六十七」等＝**①市内上水の使用者が千川水道会社へ支払う分の見込額（水料8,060円・浚渫修繕費1,819円の表記も）、②千川上水の井数（6,667の表記）・吹井116か所・呼樋1か所平均45間という施設数値**＝[GOV-077](GOV-077.md)の明治13年千川水道会社設立・明治40-41年解散の系譜に対する1892年時点の中間の実務数値。〔数値の行割付はOCR列崩れがあり要照合。〕

## 2026-11-16 追加内容メモ（第127回）：3,879間と3,707間の対立の集計差説の候補

- [GOV-173](GOV-173.md)（1891年談話筆記）の千川上水の内訳は**無葢溝172間＋樋管3,707間**であり、**172＋3,707＝3,879間**で本書（1892）の「**溝樋總長三千八百七十九間**」と**算術的に完全一致**する。この一致から、**3,879間系（本書）は無葢溝（開渠）を含む総延長、3,707間系（GOV-226/228）は樋管のみの集計、という集計範囲の差である可能性が強い**〔観察。両書は隣接年（1891・1892）の同時点数値で、計数の一致が偶然である可能性は排除できないが、「測量差か誤記か」という制限②の選択肢に「集計範囲の差」という第3の説明を加えるものとして記録する。断定は原典対校（両書の表の直接照合）まで保留〕。
