# [GOV-636] 「谷端」「溜井」「揚堀」「水窪」「弦巻」「逆サ川」語掃引の成果（第386回）

## 書誌・確認範囲

第385回ノート課題③（都公文書館次の掃引語）に沿い、東京都公文書館クロス検索（GETレシピ・第337回形式・全chkCls 14コレクション・2026-11-28取得）で「谷端」（75件）「溜井」（94件）「揚堀」（1件）「水窪」（40件）「弦巻」（216件・3頁走査）「逆サ川」（16件）を掃引し、詳細頁の表項目を直接取得した。既収録pkey（705787・822458・1084577・1188643・1211264・1238786・1279615・1281260・1283403・1300668・1300708・1322692・1374807・1892615・000365537・714686・1080476/1080477等＝GOV-568/571/586/628/629/633/634・第294/313/321回ノート既出）を除外した結果、四河川流域に関係する新規は下記2群。**本掃引で谷端川・千川上水系の目録レベル掃引語の大半が既収録であったことが確認された**。

### ① 明治21〜22年「市町村制施行順序取調書」の滝野川村字平尾北谷端・字谷津の分界調書（pkey 557855〔repo初出〕）

- 公開件名「北豊島郡下板橋宿の内・滝野川村の内字平尾北谷端の内・同村の内字谷津の分界段別地価戸数人口の表・図面」・文書年度 明治21年〜明治22年（1888〜89年）・作成主題課 市町村制施行順序取調所・収録先「市町村制施行順序取調書・荏原郡、北豊島郡、東多摩郡、南豊島郡・町村区域分割并飛地調書」（資料ID 000117963・請求番号 604.B4.05・16mmMF 0477-0707・D385-RAM・複写可）。
- 姉妹記録の557852（池袋村字大原・丸山・中原・上／滝野川村字東三軒家・西三軒家・平尾・鴻ノ台・北谷端・南谷端・御代ノ台の調書＝第321回ノート既出）と同じ簿冊で、**明治22年町村制施行に先立つ谷端（北谷端）・谷津の字境・飛地の確定作業の調書・図面**。**画像がデジタル・アーカイブシステムで公開されている**（画像リンク: https://dasasp03.i-repository.net/il/meta_pub/G0000002tokyoarchv03_0001179630001・2026-11-28時点で閲覧可・図面の判読は未了）。BLOG-069（明治22年町村制時の境界川）・GOV-633（谷端組合地区換地確定図）と接続する谷端の字界確定過程の一次史料。

### ② 滝野川町「逆サ川前耕地」の字名と地籍実務群（16件・1912〜1932〔repo grep「逆サ川」字名として0件＝repo初出〕）

「逆サ川」単語掃引16件はすべて北豊島郡滝野川村/町大字滝野川字逆サ川前耕地（一部「逆サ川耕地」）の地籍実務で、大正2年（1913・王子電気軌道の土地寄附）〜昭和7年（1932・東京税務監督局の雑種財産引受）に分布する。詳細頁を4件直接確認した:

- **pkey 1080635〔詳細確認・repo初出〕**: 「官有道路敷公用廃止無代下付【図面34】〔北豊島郡滝野川町大字滝野川字逆サ川前耕地自121-2～至122〕《滝野川町》」・大正8年（1919）2月12日起案・内容注記の住所地は「同字北谷端2288」＝**逆サ川前耕地が北谷端にあることを示す目録側の位置情報**・収録先「官有地 冊の2」（資料ID 000127446・請求303.C5.28・MF 0006-0690・図面34枚付き）。
- **pkey 1080458**: 不用道路敷無代下付（大正7年1918年1月12日起案・官有地 冊の1）。
- **pkey 1088079**: 王子電気軌道（株）の土地寄附（大正2年1913年1月10日起案・雑件 冊の8）＝**王子電車（現在の都電荒川線）敷地と逆サ川前耕地の接続を示す実務**。
- **pkey 1205532**: 「利用不能の残地売収の件伺〔滝野川町滝野川字逆サ川耕地97の3〕《鈴木清八》」・大正15年（1926）8月24日起案・収録先「土地収用 1.3第13号西巣鴨町～滝ノ川町 1.3第14号王子町 冊の197」＝**西巣鴨〜滝野川〜王子間の府道（1.3第13号線）建設に伴う残地処理**。
- ほか大正期〜昭和期の同一字内の土地登記・民有地境界・雑種財産引受等（1080478・1080629〜1080634〔同一件の複数レコード〕・1082145・1083547・1084521〔大字田端字西居村〕・1084695等・詳細頁未取得）。

## 四河川への使い方

- 「逆サ川前耕地」は**谷端川下流の滝野川低地（西巣鴨〜王子電車沿い・北谷端）の水路由来とみられる字名の公文書側実在が目録で初めて確認された**。「逆さ川」の語源（逆流・付け替え・蛇行等）は本文・図面未見のため断定しないが、対照表の「逆川」（出井川の通称〔板橋区〕・石神井川〔藍染川〕）とは別系統の字名資料として、滝野川地区の小水路・旧流路研究の地名側一次手がかりになる。谷端川・千川上水の滝野川区間（GOV-572・822458の西三軒家〜北谷端悪水吐水路等）の周辺字名として位置づけられる。
- 557855は谷端の字界・飛地の明治22年時点の確定図面で、**画像公開のため図面判読が外部から可能**＝谷端川を境界川とする町村制施行の地価・戸数データの読み取りが次の一手（human判読系課題）。

- 「逆サ川」掃引16件のうち詳細頁取得は4件。残12件の内容注記・起案日の確認は次回以降。
- 陰性記録: 「揚堀」は1件のみ（南足立郡千住の「土揚堀敷」1883＝スコープ外）で田柄用水の揚げ堀（BLOG-367/370）に対応する公文書は目録上不在。「溜井」94件は千束溜井（大森）・小溜井（花畑・綾瀬）等が大半で四河川関連は既収録の714686（中新井村溜井并砂利取場見分1884＝GOV-586）のみ。「水窪」40件は大森区清水窪・八王子字水窪・雑司ヶ谷字水窪新田（1080476/1080477＝第294回ノート既出）等で水窪川流域の新規なし。「弦巻」216件は荏原郡弦巻村（現世田谷区弦巻＝同名異村）が大半で弦巻川（豊島区・文京区）の新規目録は検出されなかった。
