# [GOV-451] 北豊島郡巣鴨町現状調査 — 巣鴨地名由来の「洲処面」説の文言候補

- **書誌〔確認〕**: 『北豊島郡巣鴨町現状調査』（東京市臨時市域**擴張部**編・[book/1900494](https://lab.ndl.go.jp/dl/book/1900494)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**巣鴨町（1932年巣鴨区→豊島区・庚申塚・松ヶ崎方面）冊**＝石神井川沿い（谷端川流域の南隣）の町。
- **巣鴨地名由来の「洲処面」説〔文言候補・本ファイルの核心〕**: 沿革章——「**（巣鴨北?）條役帳ニ（ハ）〓面巢鴨ハ古記ニ州鴨須賀茂、須賀母、等 アリシガ、古説ニ現在ノ巢鴨ト名附ケシハ…（中略）…庚申塚ニ役場ヲ置クノ字アリ 此地石神井川ニ臨ミテ洲処面ノ名アリ、因テ転ゼシ十(?)ラント云フ**」＝**①巣鴨＝古くは「州鴨」「須賀茂」「須賀母」等と書いた（北條役帳の表記を引く）、②巣鴨（スガモ）の発音が「洲処面（スどこも?）」「砂洲の洲処＝スガモ」に因んで転じたとする地名由来説の記載**〔**「洲処面」＝石神井川に臨む洲（砂洲・中洲）の「洲処」を語源とする巣鴨地名由来説の1931年の行政文書レベルの記録（repo初出候補）。石神井川の地形（洲）に由来する地名説明として、神田上水系の「洲」由来説（[BOOK-148](../books/BOOK-148.md)中野町誌・[GOV-390](GOV-390.md)の洲湯水・洲潟等の面影橋・淀橋系の「洲」由来語群）と同型の「洲」地名論の一次例**。「因リテ転ゼシ十(?)ラント云フ」の判読（「因テ転ゼシモノラント云フ」等の崩れ）と「洲処面」の原字（「洲処面」4字の確認も含む）は要原画像照合、採用は文言候補のまま（**地名由来説としての真偽の判定は本repoの範囲外**）〕。
- **庚申塚＝役場所在の地名文言〔確認〕**: 「**庚申塚ニ役場ヲ置クノ字（地名）アリ**」＋交通章の「**巢〓（鴨?）…庚申塚ヲ分岐トシ大塚ニ至ル板橋乗合自動車**」＝巣鴨町の役場所在地が（大字）庚申塚であったことの1931年の行政文言（現在の庚申塚交差点附近）。
- **谷端川関連の陰性〔陰性記録〕**: 本冊fulltextの走査限りで「谷端川」の直接言及なし＝石神井川沿いの町（谷端川流域の南隣・地内に「巣鴨川」＝石神井川下流の呼称候補の川が流れる）であるが本冊では谷端川に触れない・「小石川」の文言は区名・駅名・小石川町の文脈で18件（河川の小石川＝石神井川下流呼称としては判読不能）。1931年時点の巣鴨町の下水道文言も走査限りで見えず＝陰性とした。
- **帳簿文言〔確認〕**: 人口増加・人口密度・小学校増築計画・商工業発達・金融機関等の帳簿（OCR数字崩壊大）＝1932年市域拡張直前の巣鴨町政の帳簿。
