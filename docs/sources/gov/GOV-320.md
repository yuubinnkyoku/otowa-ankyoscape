# [GOV-320] 現行日本衛生類典（1894）— 沿革目次と両禁例の現行性の第三定点

- **書誌〔確認〕**: 『**現行日本衛生類典**』（**1894**〔明治27年〕。NDL次世代デジタルライブラリー [book/797094](https://lab.ndl.go.jp/dl/book/797094)）。衛生関係の現行法規類纂。第五章水道及飮料水に両禁例等を収録。**引用文言はOCR由来で原画像照合を要する（特に目次頁と兩上水禁例本文は列崩れが激しい）**。

## ①沿革目次（第五章水道及飮料水）〔確認文言〕

- 「飮料ノ淨水ヲ汚穢スル罪…刑法摘錄」「飮料水營業取締規則（明治二十一年 警察令第九號達）」「**神田玉川兩上水取締禁例**（明治十一年十月 警視廳甲第(五十)七號達）」「**千川水道取締禁例（明治十四年五月 警視廳甲第二十五號布達・警察令第九號?）**」「上水使用規則」「飮料水注意法（明治十一年五月警視廳乙第十八號達）」「東京市上水水料賦課規則」等の項目立て（割付崩れあり・文言候補）。
- **意味〔確認・観察〕**: 明治27年（1894）時点で**兩上水・千川の両禁例が衛生法規の現行体系に揃って収録**され、かつ目次が**明治10年（丙5号の系統の營業人取締）→明治11年→明治14年→明治21年（飮料水營業取締規則）の沿革順**で項目を並べている＝[GOV-319](GOV-319.md)の沿革類纂（1880）と同じ編纂思想の1894年版。兩上水禁例の項目書誌が「**明治十一年十月 警視廳甲第五十(七)號**」＝**甲57号の原布達日付を規則の出自として提示**（[GOV-315](GOV-315.md)・[GOV-318](GOV-318.md)と整合）。

## ②千川水道取締禁例の6か条再録〔確認文言・対校〕

- 第1条〜第6条（第4条堤上竹木下草伐採禁止・第5条水道敷地内車馬牽入禁止・第6条違警罪罰則）まで[GOV-315](GOV-315.md)②（警視庁令類纂第5版）とほぼ同文言で再録＝**千川禁例6か条構成の第2の独立系統**（両系統ともOCRだが独立した底本での一致）。兩上水禁例側の本文は割付崩れで第1条までしか連続読みできない（欠損・要照合）。

## 位置づけ〔観察〕

- 現行性の定系列: [GOV-318](GOV-318.md)（1887・現行リスト）→**本書（1894・現行衛生類典）**→[GOV-315](GOV-315.md)（1896・令類纂第5版現行）＝**兩上水禁例は神田上水廃止（明治34年6月）まで、千川禁例は千川上水廃止（明治40年6月）まで、ともに現行規令として編纂書に収録され続けた**ことの定点観測の第2点。

## 制限・未解決
