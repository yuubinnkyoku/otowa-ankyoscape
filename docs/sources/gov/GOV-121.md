- **意義〔観察・repoへの関連〕**: ①「**千川用水六ヶ村（組合）が編者・差出人となる文書**」が、東京・神奈川の区市立図書館ではなく**農林水産省系研究情報センター（＝NDL支部図書館）に現存する**という新所在の特定（第80回「所在のみ」から所蔵館・請求記号・配置場所まで具体的な請求情報が付いた）。千川用水沿線の村方文書は千川家文書（[GOV-089](GOV-089.md)・[GOV-004](GOV-004.md)）・小川家文書（[GOV-100](GOV-100.md)）・星野家文書（[GOV-110](GOV-110.md)）・當麻家文書（[GOV-120](GOV-120.md)）と多様な系統で分散所蔵されるが、**行政・研究系図書館にも一部が入っていた**ことが確定した。②作成年の目録記載「**[1875]＝明治8年**」は、[GOV-100](GOV-100.md)の明治13年（1880）増水運動シリーズ（6月起願→8月却下）や明治4年（1871）民部省の直引取差免廻達（SZ104683）の**間に当たる年代**で、明治前期の六ヶ村組合の活動をうかがわせる。ただし伺書の内容（何の伺いか・差出先）は本文未確認のため、明治13年運動との関係は断定しない。③「六ヶ村」という組合単位は、[GOV-110](GOV-110.md)の「拾七ヶ村組合」「南六ヶ村組合」（千川養水・杉並側）や[GOV-100](GOV-100.md)の「北側新井筋弐拾七ヶ村組合」と規模が異なり、千川用水の受益村組合の編成単位を比較する際の参照点（**どの6か村かは本レコードからは特定できず、断定しない**）。
