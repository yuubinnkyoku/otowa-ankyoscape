# [GOV-246] 神田玉川上水留[4]（慶応4〜明治元年）— 維新期の上水方引継ぎと千川家の水料上納

- **書誌〔確認〕**: 『神田玉川上水留』[4] 「慶応四辰年五月ヨリ明治元年十二月マテ」冊。NDL次世代デジタルライブラリー [book/2587520](https://lab.ndl.go.jp/dl/book/2587520)。慶応4年（1868）5月〜明治元年（1868）12月の神田上水・玉川上水の行政記録。戊辰戦争期の江戸引き渡しから明治政府への移管の過渡期の冊。**引用文言はすべてOCR由来で要原文照合。**
- **神田上水全体の記述〔確認・repo初出の全体文言〕**: 慶応4年5月・市政南裁判所あての上水方引継ぎ書上に「**江戸ゟ五里西之方吉祥寺村井之頭弁天池湧出水ニ而野方堀通村々流水目白下関口村迄堀通并同所ゟ牛天神下迄ハ左右石垣白堀ニ有之**」＝**①水源＝井之頭弁天池の湧出水②「野方堀」（千川上水区間・野方堀通村々への分水区間）を経て目白下関口村まで堀通③関口から牛天神下までは左右石垣の白堀**——神田上水（江戸川）の全体経路を水源から流末まで一枚の書上に記した慶応4年の一次文言。②③の区間の接続（野方堀→関口→白堀）は[GOV-247](GOV-247.md)の引継帳面・[BOOK-123](../books/BOOK-123.md)明治2年の上水絵図と対校できる**経路記述の新基礎資料**。「五里」は[GOV-222](GOV-222.md)「五里24町余」・[GAZ-049](../gazetteers/GAZ-049.md)⑫の「五里」系文言と対照（本冊は距離の細部なし）。
- **引継帳面目録〔確認〕**: 同書上の帳面目録に「**白堀浚賃銭取集帳**」「**渡橋箱下水組合帳**」「**上水記絵図**」等が読める＝**白堀浚賃銭（渡賃銭）・渡橋箱下水（白堀通の橋と箱下水の組合）・上水絵図が、慶応4年時点で一つの行政ファイル（帳簿群）として新政府に引き継がれたことの目録証拠**（[GOV-249](GOV-249.md)の明治2年白堀浚賃銀取集帳の前史・帳簿の系統の裏付け）。
- **千川善蔵・千川平吉の玉川上水水料上納〔確認・repo初出〕**: 「**玉川上水堀通村々水料堰料上納帳**」に「**砂川村 千川善蔵**」「**千川平吉**」の名＝**砂川村（千川上水の通村・千川家の本拠）の千川善蔵・千川平吉が、玉川上水堀通村々の水料・堰料を上納していた慶応4年の実務記録**。＝練馬村の千川善藏（[BOOK-126](../books/BOOK-126.md)・[GOV-211](GOV-211.md)の千川上水五代記・千川家）と同名の人物の別村（砂川村）での出現。**両者の関係（同一人物か別人か・分家か）は本冊のみでは確定できない**（要照合・断定しない）。同帳に「上保谷村 伊左衛門」もあり。
- **見守武兵衛の在職〔確認〕**: 「**見守武兵衛**」の在職・業務の記録（白堀通の渡橋并箱下水の見守〔[GOV-236](GOV-236.md)の見守喜兵衛・武兵衛の御請書〕の慶応4年の継続）＋「**金杉橋際拝借地**」の文言（見守の拝借地が金杉橋際と読める・帰属は要照合）＋「**関口水道町 水車持半兵衛長兵衛**」＝**関口水道町の水車持ち（半兵衛・長兵衛）の慶応4年の記録**（[GOV-248](GOV-248.md)の小日向江戸川端の水車取立と対照できる水車系の文言）。
