# [GOV-401] 御用向諸事日記24巻[15] — 天保15辰年2月の小金井筋御成の道筋（触留30冊と同一御成の独立記録）〔第167回〕

- **書誌〔確認〕**: 『御用向諸事日記』24巻[15]（写・NDL次世代デジタルライブラリー [book/2577238](https://lab.ndl.go.jp/dl/book/2577238)）。御用向の実務日記の写しで、天保15辰年（1844）2月の条が含まれる。**引用文言はすべてOCR由来で要原文照合。**
- **天保15辰年2月の小金井筋御成の道筋〔確認・核心・repo初出〕**: 「**天保十五辰年二月**」の日付を持つ扶持方の条に続いて「**明後廿五日小金井筋右大将様御成弥被仰出候尤御組定は去ル十八日相済候一御場所小金井筋一御供揃一御膳所一杭所六時前吉祥寺村くると十郎左衛門淀橋一小鷹一宿所内藤新宿御道書矢来御門ゟ半蔵御門四谷御門内藤新宿往還通成子町ゟ井ノ休所従橋水車久兵衛右相済淀橋御渡中野村小淀山御立場二而雉子御用相済野道より松梅往還通高円寺村成宗村上田村戸村大宮前新田吉祥寺村往還通上保谷村新田境新田ゟ玉川上水端通鈴木新田小金井橋辺迄同所ゟ御立戻又上水端通上蓮雀村吉祥寺村御林通無礼村井ノ頭弁天境内御通福師道**」＝**御膳所＝吉祥寺村（十郎左衛門〔「くると十郎左衛門」は名主十郎左衛門のOCR崩れ候補〕）・小鷹・宿所＝内藤新宿・井ノ休所＝淀橋水車久兵衛（「従橋水車」は淀橋水車の崩れ候補）・淀橋御渡・中野村小淀山御立場二而雉子御用相済（小淀山で雉子〔キジ〕狩が行われた文言候補）・野道→青梅往還（「松梅往還」は崩れ候補）→高円寺村・成宗村・上高井戸村〔「上田村戸村」は崩れ候補〕・大宮前新田・吉祥寺村→上保谷新田・境新田→玉川上水端通（鈴木新田）→小金井橋辺→復路: 上水端通→上蓮雀村・吉祥寺村御林・〔無礼村＝崩れ〕→井ノ頭弁天境内御通→福師道**という道筋〔**①[GOV-398](GOV-398.md)（触留第30冊・辰二月廿四日の触）と同一の小金井筋御成を、触ではなく実務日記の側から記録した独立系統の記録であること（御膳所=吉祥寺村十郎左衛門・淀橋御渡・小淀山御立場・玉川上水端通・井ノ頭弁天境内御通の要素が一致）、②**GOV-398の「辰年」について、本日記の直前の条が「天保十五辰年二月」の日付を持つことから天保15辰（1844）2月25日説が有力候補**に浮上（冊の棚札から想定していた天保3壬辰〔1832〕説を更新・ただし日記の条の切れ目と日付の対応は原画像照合まで断定は保留）、③「雉子御用相済」＝小淀山の御立場で雉子狩が行われた旨の文言候補（[GOV-398](GOV-398.md)の「難御用相済」の崩れの補強読み）**〕。
- **同日記の卯年十月十日の御成の復路〔参考・文言候補〕**: 「**卯十月十日吉祥寺村御勝所くる十郎八衛門還御同所大宮前新田上高井戸村成宗村高円寺村ゟ美極往還通浜橋御渡成子町内藤新宿仕置通四谷**」＝吉祥寺村の御勝所（御膳所の異表記候補）から還御し、大宮前新田・上高井戸村・成宗村・高円寺村を経て青梅往還（「美極往還」は崩れ候補）に戻り「**浜橋御渡**」を渡り成子町・内藤新宿仕置通から四谷へ向かう道筋〔「浜橋御渡」は「淀橋御渡」のOCR崩れ候補（同じ神田上水の渡しの別表記か崩れかは原照合まで断定しない）＝小金井筋御成の還路の渡河点の異表記の対校案件〕。
