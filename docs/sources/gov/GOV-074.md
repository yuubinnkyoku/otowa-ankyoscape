# [GOV-074] 板橋区「浸水履歴」

## 書誌・所在（2026-11-11、板橋区公式ページを直接確認・ai）

- 板橋区土木部土木計画・交通安全課調整係の「浸水履歴」ページ（ページ番号1005716、更新日2026年10月26日）。 https://www.city.itabashi.tokyo.jp/bousai/bousai/shinsu/1005716.html
- 掲載範囲〔確認: ページ本文〕：**昭和43年4月30日以降の浸水被害を地域別に掲載**。平成9年以前は区全体の被害件数のみ、平成10年以降は床上・床下浸水別に「番」まで、平成12年9月12日以降の道路冠水は日付別、**令和7年3月からは地域別浸水履歴に道路冠水箇所も統合表記**。
- 添付ファイルは五十音別PDF12本と「道路冠水箇所一覧表」（PDF 345.5KB）。浸水記録がない地域として大谷口一丁目等が挙げられる。

## 内容メモ

- **〔所在のみ〕** 本ページは目次であり、**各地域の浸水記録の実データはPDF本文で未確認**。谷端川流域（板橋区側: 中丸・幸町・大山西町・大谷口・氷川町・弥生町等）の昭和43年以降の浸水・冠水記録の公的アーカイブの所在として記録する。
- **〔注意〕** 掲載が昭和43年4月30日以降のため、**大正14年洪水（[BLOG-077](../blogs/BLOG-077.md)）や谷端川放水路1924/25年次問題（『いたばしの河川』〔[BOOK-031](../books/BOOK-031.md)〕）の直接史料にはならない**。谷端川河川廃止（1962年〔[GOV-008](GOV-008.md)〕）以降の下水道幹線時代の浸水記録の確認に用いる。
