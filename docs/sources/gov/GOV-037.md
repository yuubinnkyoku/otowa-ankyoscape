# [GOV-037] 『太政類典』「両上水修繕費金貸与」（1875年5月9日）

- **資料〔確認：国立公文書館の公的目録とJACARの内容テキスト〕**：太政官『太政類典』第二編（明治4～10年）、第175巻「運漕一・治水道路一」、件名「両上水修繕費金貸与」、**明治8年5月9日（1875年5月9日）**。国立公文書館請求番号 **太00397100**、件名番号 **062**、JACARレファレンスコード **A24011123900**、規模 **18**。出典：[JACARの件名・内容テキスト](https://www.jacar.archives.go.jp/das/meta/A24011123900)／[国立公文書館デジタルアーカイブの原件目録](https://www.digital.archives.go.jp/item/1392992)／[ジャパンサーチ書誌](https://jpsearch.go.jp/item/najda-vEkk00397100_06200)。
- **神田上水の区間〔確認：JACAR公開の公文書内容テキスト〕**：本文の「内務省伺」に、玉川上水の対象を「四谷大木戸ヨリ代々木村ニ至ル」、神田上水の対象を「**音羽花水橋ヨリ造兵司邸地ニ至ル**」とする記載がある。**「音羽花水橋」の表記が公的な史料内容テキストに存在することは、地域史ブログから独立して確認できた**。
- **修繕理由・内容〔確認：同内容テキスト〕**：両流について「**家屋接近ニシテ不潔尤甚シキ場所**」とし、「**土手築立等取計申度**」とする計画・申請上の説明がある。費用に関して「**一金二万円 五ケ年賦貸下**」との記載がある。**工事の実施・完了、実際の貸付額・支出、具体的な土手の施工箇所を示す完成記録ではない**。
- **確認範囲と留保**：今回は**JACARの公的な内容テキストと国立公文書館の原件目録を直接確認**した。**原公文書画像の字形・付属図・全頁は未照合**。橋の正確な位置・構造、1829年『御府内備考』の大日坂下の橋との同一性、現在の神田川「華水橋」との関係は、この史料だけでは確定しない。**神田上水の工事を水窪川・弦巻川の改修と同一視しない**。
