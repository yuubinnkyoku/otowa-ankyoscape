# [GOV-369] 御府内場末往還其外沿革圖書 貮拾元下（嘉永7年10月調）— 小日向上水端屋鋪と白山御殿跡の代地再編〔第160回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の「貮拾元下」（**嘉永七寅年〔1854〕十月調**・第20部「元」の分冊）。NDL次世代デジタルライブラリー [book/2587266](https://lab.ndl.go.jp/dl/book/2587266)。目録文言に「**小石川白山裏門前通 同所指谷町 同所正福院 妙伝寺 本念寺境内其外小屋鋪**」「**小石川白山御殿跡大通ゟ元矢場并同所大道通町屋**」「**小石川白山御殿跡大通ゟ芥川山野寺〔小野寺のOCR崩れ候補〕御預御築園 岡田利左衛門御役屋鋪 施薬院**」「**小石川白山御殿跡 芥川小野寺御預御薬園 塔川相模守 高井石見守屋鋪 水川明神社地**」等とあり、**小石川白山裏門前通・指ヶ谷町・白山御殿跡一円の町方・屋鋪の書上を収める帳**。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する。**
- **「小日向上水端」屋鋪と白山御殿跡の代地再編〔確認・文言候補・核心〕**: 白山御殿跡の地所書上に「**正徳三己年頃 前書御殿御取払に成候由に有之 同四午年 右御殿跡地之内并同所前通二有之広道之内も御殿跡地え籠 同所之内え新規道敷出来 同年二月 右地所之内 酒井修理大夫小日向上水端屋鋪差上候代地**」＝**①白山御殿が正徳3年（1713）頃に取払われた、②正徳4年（1714）に御殿跡地の再編（前通の広道の取り込み・新規道敷の設定）が行われ、③その年2月に酒井修理大夫（酒井河内守と同族候補・要照合）の「小日向上水端屋鋪」が差上げられ、白山御殿跡の代地が下された**という一連の行政記録〔**「小日向上水端」＝小日向（現・文京区小日向）の神田上水（江戸川）の水岸（上水端）にあった屋鋪**を指す語で、「上水端」という立地語が屋鋪の固有表示として帳簿に現れる文言候補＝**神田上水沿いの土地の呼称の嘉永期の帳簿レベルの用例**。〔「水番屋構并水当人持地」（[GAZ-080](../gazetteers/GAZ-080.md)・嘉永5年の関口村側）と並ぶ、上水施設沿いの土地・立地の書上語彙〕〕。
- **享保2年の御薬園添地〔確認・文言候補〕**: 「**正徳四午年九月 酒井修理大夫下屋鋪之内 松平式部少輔江切坪相対替に而二屋鋪二成 享保二同年中 松平式部少輔右屋鋪之内東南之方被召上 同所に有之道敷共 御薬閣〔御薬園のOCR候補〕添地に成**」＋「**同六五年中 同人右差上候残地幷前書酒井修理大夫切坪銭地共上ケ地に成**」＋（別所の地所）「**嘉永七寅年八月 松平駿河守下高輪下屋鋪御用に付被召上候為代地 前書御薬園同人下屋鋪次之部江に被下**」＝**酒井修理大夫屋鋪→松平式部少輔の相対替（正徳4年9月）→享保2年（1717）に東南方が上ケられ道敷とも御薬園の添地化→享保6年（1721）に残地・切坪銭地も上ケ地**という白山御殿跡内の土地再編と御薬園の拡大の年代層〔白山御殿跡の御薬園（岡田利左衛門御預・芥川小野寺御預）は目録文言で「御薬園」と現れるため、本文の「御薬閣」は「御薬園」のOCR変種候補。要原画像照合〕。
- **位置づけ〔観察〕**: ①本冊の白山御殿跡の地所書上は、[GOV-364](GOV-364.md)（貮拾貞）の「白山御殿取建と雑司ヶ谷村地境」文言（天和3年取建）と対になる**取払い後（正徳3年以降）の白山御殿跡の土地利用の記録**。②「小日向上水端屋鋪」は、神田上水の小日向〜関口区間の水岸の屋敷が代地行政の対象になった例で、上水沿いの土地の帯状利用（水番屋・水車・屋鋪）の資料（[GAZ-080](../gazetteers/GAZ-080.md)の関口側書上と対校）。③指ヶ谷町・白山裏門前通の町方書上は、[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考・小石川側）の巻石白堀・指ヶ谷周辺の調査に対する嘉永期の帳簿側の対応資料になる（白堀文言の有無は本回では確認できず、再精査課題）。
