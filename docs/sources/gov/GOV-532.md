# [GOV-532] 豊島区「区民の声」谷端川南緑道回答〔路灯のLED化と全面改修時の反映文言〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: 豊島区公式ホームページ「**区民の声（暮らし・地域）**」（ページID52958・**更新日2026年5月21日**）。 https://www.city.toshima.lg.jp/016/2506181022.html 〔区へのご意見と回答を項目別に載せるページ〕。
- **該当項の文言〔確認: 本文・文言〕**: 項目名「**谷端川南緑道のウォーカブルエリア化**」。ご意見＝「最近、夜にランニングをしています。**谷端川南緑道は車通りがなく走りやすいのですが、暗さや植え込みのため夜は避けています**。夜も明るく、木々や花が脇に整備されたウォーカブルな通路になることを望んでいます。また、**山手通りと並走する谷端川南緑道**がきれいになれば、豊島区の魅力向上にもつながると考えています」。回答（**令和7年4月**）＝「**谷端川南緑道の街路灯は照度は確保されておりますが、木々が繁り暗くなっている場所がありますので、剪定や古い水銀灯のLED化を進めます**。**今後、緑道を全面改修する際には、地域の方のご意見や、今回の提案も取り入れ、ウォーカブルな緑道整備を目指してまいります**」。
- **意義〔観察〕**: ①[GOV-008](GOV-008.md)（谷端川南緑道・区公式ページ）系の**現行維持施策（樹木剪定・水銀灯のLED化）の一次文言**で、谷端川南緑道の暗さ・植え込みの問題が区民の声として記録され、区がLED化を回答した点が新規。②「**今後、緑道を全面改修する際には**」の文言＝全面改修の可能性を前提した文言だが、**改修の時期・計画の有無は本文に明示なし**〔断定しない〕。③「山手通りと並走する」＝緑道の並走路の位置付けの一次記録。
- **制限・未解決**: ①回答は令和7年4月付・ページ更新日は2026年5月21日〔LED化工事の実施状況・完成時期は本文に文言なし＝今後の区資料・現地観察での追跡対象〕。②同一ページには中池袋公園のトレーディング対応（令和7年2月）・駐輪場の精算方法（令和7年3月）・南池袋スポーツ公園のじゃぶじゃぶ池（令和7年8月）等の他項目も並ぶ〔水系関連は谷端川南緑道の1項目のみ〕。
