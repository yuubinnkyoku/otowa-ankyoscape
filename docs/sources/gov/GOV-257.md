# [GOV-257] 北豊島郡石神井村現状調査（1931）— 千川水道の石神井村側の記述と石神井川水源

- **書誌〔確認〕**: 東京市臨時市域拡張部『市域擴張調査資料 北豊島郡石神井村現状調査』（昭和6年11月・1931年）。NDL次世代デジタルライブラリー [book/1900794](https://lab.ndl.go.jp/dl/book/1900794)。**巻頭に「昭和六年十一月 市域擴張調査資料 北豊島郡石神井村現狀調査 東京市臨時市域擴張部」の刊記**（OCR）。引用文言はOCR由来で要原文照合。
- **「五 河川」条〔確認・repo初出級〕**: 「**五 河川トシテハ石神井川多摩川分水、千川水道アリ**」＝**1931年（市域拡張時点）に千川水道（千川上水）が石神井村の河川として石神井川・多摩川分水（多摩川特定用水）と並んで列挙されている**行政側記録。〔石神井村域を千川上水が通過することの1931年公式調査レベルの確認。[GOV-165](GOV-165.md)（長崎町）・[GOV-253](GOV-253.md)（板橋町）と同じシリーズで、千川用水を「河川」枠で挙げた点が石神井村版の特徴。「千川水道」の表記は郡誌系の「千川用水」と並ぶ呼称の用例。〕
- **石神井川の水源と支流〔確認〕**: 「**石神井川ハ水源三全寺池ヨリ発シ（ママ・三寶寺池のOCR崩れか）支流開ノ溜井ヨリ発スルモノト田中下ニテ合シ練馬ヲ横切リ東流シテ王子ニ至リ荒川ニ注ク**」（前後割注あり・要照合）＝**①石神井川の水源＝三宝寺池、②支流＝「開ノ溜井」発の水流が田中(の下?)で合流**という1931年時点の行政側水源記述。〔「開ノ溜井」は石神井川支流の水源溜井の固有名候補（原字照合前提）。〕
- **三宝寺池の記述〔確認〕**: 「**石神井城趾ノ古濠ニシテ池中ニ蓴菜ヲ生ス池ノ周〓四町余池水清冷大旱ト(モ)枯渇セス周囲ニハ松杉桧欝蒼トシテ繁茂シ**」＝三宝寺池＝石神井城趾の古濠・蓴菜の自生・周囲四町余・池水清冷で大旱でも枯渇しないという1931年時点の実況記録。〔[BOOK-140](../books/BOOK-140.md)（1918・台地脊梁の地形記述）と並ぶ石神井川水源側の観察資料。〕
- **シリーズ内の位置づけ〔観察〕**: [GOV-165](GOV-165.md)（長崎町現状調査・千川用水と谷端川の記述あり）と同一シリーズ（市域擴張調査資料）の石神井村版。板橋町版（[GOV-253](GOV-253.md)）では水路言及なし・西巣鴨町版（1900499）も水路言及なしに対し、**石神井村版は千川水道を明記する**＝千川上水の流路上の町村での記録の有無の差がシリーズ内で対照できる。

## 制限・未解決

- ①「三全寺池」は三寶寺池のOCR崩れの可能性が高いが原字要照合。②「開ノ溜井」の原字・所在（石神井川支流の溜井の固有名か）は要照合。「田中下ニテ合シ」の「田中下」の区切りも列崩れの可能性あり。③千川水道条は列挙のみで、村域内の通過位置（字・地番）の記述の有無は図版・付表（OCR範囲外）で未確認。
