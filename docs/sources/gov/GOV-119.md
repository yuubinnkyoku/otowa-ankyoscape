# [GOV-119] 東京都下水道局『技術調査年報2008』「第二・十二社幹線水理模型実験について」〔repo初出〕

- **書誌〔確認: Wayback保存版PDF全文取得〕**: 東京都下水道局『**技術調査年報 -2008-**』（**平成20年（2008）11月**発行）所収「**第二・十二社幹線水理模型実験について**」**pp.55〜64**（次項目「浅川水再生センター…」がp.65開始）。原本PDFは東京都オープンデータで公開されていた〔[オープンデータURL](https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2008all.pdf)・2026年11月時点の直接アクセスは403で、[Wayback保存版 2024-05-31](https://web.archive.org/web/20240531063908/https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2008all.pdf)（約6.9MB・本体8,169,500バイト相当を取得）で全文取得〕。
- **内容〔確認: 本文（テキスト抽出）〕**:
  - 実験対象の**第二・十二社幹線は、内径1,500mm〜3,500mm・延長約4.9kmの浸水対策用の合流幹線**で、**既設十二社幹線を補完する幹線として昭和63年（1988）から整備を進めており**、実験時点では**神田川への放流渠吐口及び既設十二社幹線からの切替工事を除き工事は完了、暫定貯留管として供用**している。
  - 下流部**約2km区間は2箇所の伏せ越しや急勾配といった構造**をもち、最下流部放流渠吐口に至る延長約2km区間（No.3〜吐口）の模型を作成して水理特性を把握した。
  - 実験の背景として、**平成9年度「多摩川・荒川等流域別下水道整備総合計画」（流総計画）による単位汚水量（十二社処理分区・第6小分区）の増加や流域の見直しによる流入量の増加**で、当初設計に比べ全体流入量が増加したこと、現場の既設埋設物の状況により**人孔形状が変わり幹線への取付方法が変更**となったことをあげる。
  - **「横越流分水方式」と「直接分水方式」の2タイプで水理模型実験を行い、各水理公式の適用範囲を定め**、水理模型実験で流した分水量と水理公式で求めた分水量の対応を整理した（分水施設の設計手法の検討）。
- **位置づけ〔観察〕**: [PAP-062](../papers/PAP-062.md)（第二十二社幹線・第二雑司ヶ谷幹線の流下施設の検討及び水理模型実験〔下水道新技術研究所年報p.125〜130〕）と同じく**第二十二社幹線（第二・十二社幹線）の水理模型実験を記録する技術資料**で、都下水道局自身の実験として先立つ（2008年時点の暫定貯留管運用と分水施設計画）。十二社幹線・第二十二社幹線は**神田川水系の下水幹線**で、弦巻川・水窪川が合流する神田川の流水・下水道運用（[BLOG-188](../blogs/BLOG-188.md)の水量多時の神田川直接放水）の下流側条件を理解する文脈資料。ただし**十二社流域自体は四河川流域外**であり、接続は神田川の受け皿としての関連にとどまる。
- **表記〔観察〕**: 同一論文内で「第二・十二社幹線」と「第二十二社幹線」の両表記が混在する（NDLの[PAP-062](../papers/PAP-062.md)レコードの読みは「ダイニジュウニシャ カンセン」）。**両表記が同一幹線を指すかは本文上明示されないため断定しない**。
- **補足〔確認: 目次〕**: 同年報には「流出解析モデルを活用した管きょ再構築の整備手法に関する調査」p.43 も所収。技術調査年報シリーズは2000〜2014年度分がオープンデータで公開されていた（直アクセスは403・Wayback保存版で取得可）。
- **制限・未解決**: 十二社幹線の神田川放流地点の位置、第二十二社幹線の四河川流域（特に雑司ヶ谷・弦巻川低地）との直接的な水理接続の有無、本文図面（模型写真・断面図）の判読。2008年報の当該論文著者名（テキスト抽出で個人名欄が未抽出）。
