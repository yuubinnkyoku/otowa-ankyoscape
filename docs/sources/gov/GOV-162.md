# [GOV-162] 特別都市計画委員会 議事速記録 第12号（1930年・巣鴨町下水道計画）

- **書誌〔確認〕**: 特別都市計画委員会『議事速記録 第12号』・NDL次世代デジタルライブラリー [book/1225223](https://lab.ndl.go.jp/dl/book/1225223)。**引用はOCRテキスト由来・要原文照合。**
- **巣鴨町下水道計画〔確認・repo初出の本文〕**: 対象面積**566,810坪**・計画人口**約7万**（既存3万4千・自然増加等を加算）。計画汚水量＝1人1日平均6立方尺の半量を8時間に排泄するものとし、雨水量＝1時間最大降雨量**50mm**、合流法。下水は**谷田川・谷端川及悪水路に排出**。排水区は**谷田川・谷端川・白山の3区**に区分。下水道延長**約4万米**、総経費**143万5千円**、執行期間**昭和4年度〜8年度の5箇年**。これが[NDA簿冊 纂01907100-00600（1930-01-25「東京都市計画巣鴨町下水道及其ノ事業執行年割決定ノ件」・GOV-135）](GOV-135.md)の委員会側審議記録の本文に相当すると考えられる〔簿冊との同一案件対応は目録文言レベルで推定〕。
- **谷端川排水区の区域〔確認・要照合〕**: 大字上駒込・駒込妙義坂下・巣鴨三丁目の全部、巣鴨二丁目・四丁目・込染井（染井）の各一部〔地名はOCR判読〕。谷端川（＝千川下流）が巣鴨町の主要な排水受容先として都市計画上明示された記録。
- **位置づけ〔観察〕**: ①[GOV-159](GOV-159.md)（1930年7月・谷端川改修）が「巣鴨町下水道谷端川下水幹線接続点」を下流端に定めたのと同年に、巣鴨町側の下水道計画が**谷端川排水区を3排水区の一つ**に定めており、河川改修と下水道計画が接続点を共有していたことが裏付けられる。②README既述の西巣鴨町下水道（1932年内務省認可）に先行する**巣鴨町の1930年決定**で、[GOV-166](GOV-166.md)（1937年下水道事業年報）の「谷田川・谷端川・悪水路へ排出」と同構造の水系区分が7年前から固定していたことになる。
