# [GOV-435] 嘉永撰要類集[15]橋之部下・渡船之部冒頭 — 嘉永6年の関口水道町の水車の掛樋掛替一件

- **書誌〔確認〕**: 『嘉永撰要類集』[15]（第五十三ノ下 橋之部・渡船之部・写本）。NDL次世代デジタルライブラリー [book/2572937](https://lab.ndl.go.jp/dl/book/2572937)。**引用文言はすべてOCR由来で要原文照合**。本冊の橋之部は関口水道町の水車の一件で始まる（渡船之部は永代橋外弐橋の橋番人夜番の件から）。
- **嘉永6年（1853）の関口水道町の水車の掛樋新規掛替〔確認・repo初出の実務記録〕**: 同町**家持「きち」（後見 佐右衛門／作右衛門・OCRゆれ）が所持の水車**について——「**関口水道町家持きち後見作右衛門所持之水車掛樋(槌)朽損(打損)候ニ付此度有形之通掛樋幷樋受(清・受て)之杭共新規掛替申度旨右に付…江戸川内江足代相掛ヶ度段訴出候**」（嘉永6丑年4月26日・御殿直達・立田岩太郎／井戸対馬守）→「**願之通り申渡候右に付江戸川内え足代相掛ヶ今日より普請取掛候**」（5月5日）→「**普請出来足代取払申候**」（5月28日）＝**①神田上水（江戸川）に掛樋で接続する関口水道町の町人所有の水車（受樋と杭を新規掛替）、②修復中は江戸川内に足代（仮足場）を設け、完工後に取払う運用、③普請の伺→申渡→取掛→出来→足代取払の全過程**が記録される＝**御普請方の水道橋の掛樋（[GOV-423](GOV-423.md)・[GOV-425](GOV-425.md)）と同じ構造・手続きの民間側適用例**。
- **水車の性格＝神田上水余水の受水〔確認・文言候補〕**: 例取調書付（町年寄 館〔馆〕市右衛門）に「**右之もの神田上水余水を受水車家業仕候処右水車江之掛樋朽損候ニ付…日数三十日之内江戸川内江足代相掛申度旨別紙絵図面相添願書并右町名主ゟ差出候例書**」＝**関口水道町の水車が神田上水の余水を受けて水車家業を営む町人経営の施設であり、嘉永6年時点でも掛樋で江戸川（神田上水開渠）から取水していた**ことの一次文言候補。（**余水を受**＝上水本流の余水利用形式。[GOV-195](GOV-195.md)の印刷局王子水車場・[GAZ-048](../gazetteers/GAZ-048.md)の関口の大滝の水車群の系譜と並ぶ19世紀中葉の定点。余水の具体的水量・取水位置の解釈は断定しない）。
- **前例2件＝文化4年（1807）8月と文政12年（1829）8月の出水破損〔確認・repo初出〕**: 同書付の例書に——「**例書文化し(四)未年八月右掛替相調候処私共江御下ヶ無之哉書留相見え不申候乍去例書永田備後守殿御番所え奉願御勘定御吟味役岸彦十郎殿江御達し相廻り右御同所江願出取掛被申渡候**」（文化4年〔1807〕の先例＝永田備後守番所経由）＋「**文政十二丑年八月右町善左衛門半兵衛水車江戸川筋出水仕掛組幷樋受之杭共破損仕同月八日掛直江戸川内足代相掛申度段筒井伊賀守殿御番所え奉願同廿九日猶又伺書差上候処同九月二日年寄同心中見分之上翌日願之通被仰付同月廿三日比田出来足代取払**」（文政12年〔1829〕8月の例＝**江戸川筋の出水で水車の掛組と樋受の杭が破損し、8月8日に掛直・同月29日伺・9月2日願之通・9月23日出来・足代取払**）＝**①文政12年8月の江戸川筋出水の一次側（例書引用）の記録で、[BOOK-126](../books/BOOK-126.md)の「文政12年の掃部橋・麁朶（粗朶）橋流失」（変災編第2経由）と同時期の江戸川筋出水の裏付け候補（同一出水かは断定しないが、掃部橋はこの水車の直近下流・上流の橋〔GOV-213〕で両岸被害の対応関係の対校案件）、②関口水車の前回流損例**。**文政12年8月の江戸川筋出水は repo初出の出水 datapoint**（掃部橋流失史〔享保13→天明6→文政12→天保6〕の文政12年の実際の被災内容を江戸川筋の出水として裏付ける方向の文言候補）。
- **冥加金の年限〔確認・文言候補〕**: 「**水車之義古来ゟ御普請方え年限相立冥加金上納仕候由今般願之次第も御普請方江者先日願済相成候旨名主佐一郎申之候**」＝**水車は古来から御普請方に年限を定めて冥加金を上納しており、嘉永6年の今回の願いも御普請方で願済み**＝関口水車の上水利用が幕府（御普請方）の年限契約・冥加金で管理されていた制度文言候補（金額・年限の実数値は本冊に見えず・要原照合）。
- **位置づけ〔観察〕**: [GOV-349](GOV-349.md)の「関口町水車え御立寄」（安永期・御成の立寄）・[GAZ-048](../gazetteers/GAZ-048.md)（関口の大滝・水車群）・[GOV-326](GOV-326.md)の「關口水車塲」（元治元年〔1864〕・官営の錐入場）に、**嘉永6年（1853）時点の町人所有・神田上水余水利用の水車の経営実務**を加える。嘉永6年の民間水車と元治元年の官営水車塲の関係（同一施設の官営化か別施設か）は本冊からは特定できず断定しない。江戸川内への足代の設置・取払は[GOV-423](GOV-423.md)の白堀増幷仮樋（寛保2年）・[GOV-241](GOV-241.md)の橋修復の足代と同じ水路内仮設の行政手続き体系的に並ぶ記録。
