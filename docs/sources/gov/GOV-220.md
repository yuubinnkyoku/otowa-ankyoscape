# [GOV-220] 嘉永撰要類集[13]橋之部 — 掃部橋の橋帳（銘書）登録の確認

- **書誌〔確認〕**: 『嘉永撰要類集』[13]（第五十三ノ上橋之部・嘉永4〜6年〔1851-1853〕頃の町奉行所の橋の銘書（御入用橋・町入用橋の登録帳）関係の記録集）。NDL次世代デジタルライブラリー [book/2572935](https://lab.ndl.go.jp/dl/book/2572935)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **銘書リスト（都合四拾五橋）における「里俗掃部橋」〔確認・repo初出〕**: 銘書の列挙——「**小日向大道町え渡〔橋〕同所水道町え一十日向西古川同所水道町え渡度橋十日向水道町ゟ同所服部坂取渡橋都合四拾五橋里俗菊桟橋里俗掃部橋里俗之唱無之本所御入用橋并町入用稲銘書**」〔**①嘉永期の町奉行所の橋の銘書（登録帳）に「里俗掃部橋」として掃部橋が登録されていたこと、②「都合四拾五橋」の銘書群の中の列挙であること、③同じ箇所に「里俗菊桟橋」（菊橋か・OCR崩れの可能性）が並ぶこと、④続けて「里俗之唱無之」（里俗の呼び名のない橋）も並記され、**御入用橋（幕府持）と町入用橋（町方持）を銘書に分けて登録する体系**であること**＝**掃部橋が嘉永期に公式の橋帳レベルで「里俗」名つきで登録されていたことの確認（repo初出）。掃部橋の行政上の位置づけ（御入用橋か町入用橋かの区画）は、この文言では「里俗」列に置かれているが、対応する本文（掃部橋が町方持であることは[GOV-213](GOV-213.md)天保6年願の「町内入用ヲ以懸来候」・[GOV-221](GOV-221.md)の取扱議論で既出）と併せて解釈する（文言の正確な区画は要原文照合）**〕〔「十日向」「稲銘書」等はOCR崩れが濃厚で、橋名・町名の対応は要照合〕。
- **「服部坂」の文言〔観察〕**: 「十日向水道町ゟ同所服部坂取渡橋」の文言に「**服部坂**」が現れる〔**小石川の水道町側の坂の名（服部坂＝現在の「はね坂」・掃部ヶ坂方面の旧称候補）が嘉永期の橋帳の文脈で現れる可能性**。OCR崩れの可能性が高く（「取渡橋」の区切りも不確定）、坂名の特定は原文照合まで保留。服部氏と小石川の縁（服部嘉太夫＝天保6年掃部橋の見分人〔[GOV-213](GOV-213.md)〕）との関係の検討は断定を避ける〕。

## 制限・未解決
