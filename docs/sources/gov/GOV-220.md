# [GOV-220] 嘉永撰要類集[13]橋之部 — 弘化2年の橋銘札触書と掃部橋・神田上水系4橋の銘書登録

- **書誌〔確認〕**: 『嘉永撰要類集』[13]（第五十三ノ上橋之部・写本）。**冒頭の文書群は弘化2巳年（1845）正月〜4月の「御府内橋々往来之もの通弁のための橋銘札打付」一件の記録集**（第205回に全冊走査で特定・前回の「嘉永4〜6年頃」の年代推定を訂正。写本の成立自体は嘉永期で冊名の「嘉永撰要」は維持）。NDL次世代デジタルライブラリー [book/2572935](https://lab.ndl.go.jp/dl/book/2572935)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **銘書リスト（都合四拾五橋）における「里俗掃部橋」〔確認・repo初出〕**: 銘書の列挙——「**小日向大道町え渡〔橋〕同所水道町え一十日向西古川同所水道町え渡度橋十日向水道町ゟ同所服部坂取渡橋都合四拾五橋里俗菊桟橋里俗掃部橋里俗之唱無之本所御入用橋并町入用稲銘書**」〔**①嘉永期の町奉行所の橋の銘書（登録帳）に「里俗掃部橋」として掃部橋が登録されていたこと、②「都合四拾五橋」の銘書群の中の列挙であること、③同じ箇所に「里俗菊桟橋」（菊橋か・OCR崩れの可能性）が並ぶこと、④続けて「里俗之唱無之」（里俗の呼び名のない橋）も並記され、**御入用橋（幕府持）と町入用橋（町方持）を銘書に分けて登録する体系**であること**＝**掃部橋が嘉永期に公式の橋帳レベルで「里俗」名つきで登録されていたことの確認（repo初出）。掃部橋の行政上の位置づけ（御入用橋か町入用橋かの区画）は、この文言では「里俗」列に置かれているが、対応する本文（掃部橋が町方持であることは[GOV-213](GOV-213.md)天保6年願の「町内入用ヲ以懸来候」・[GOV-221](GOV-221.md)の取扱議論で既出）と併せて解釈する（文言の正確な区画は要原文照合）**〕〔「十日向」「稲銘書」等はOCR崩れが濃厚で、橋名・町名の対応は要照合〕。
- **「服部坂」の文言〔観察〕**: 「十日向水道町ゟ同所服部坂取渡橋」の文言に「**服部坂**」が現れる〔**小石川の水道町側の坂の名（服部坂＝現在の「はね坂」・掃部ヶ坂方面の旧称候補）が嘉永期の橋帳の文脈で現れる可能性**。OCR崩れの可能性が高く（「取渡橋」の区切りも不確定）、坂名の特定は原文照合まで保留。服部氏と小石川の縁（服部嘉太夫＝天保6年掃部橋の見分人〔[GOV-213](GOV-213.md)〕）との関係の検討は断定を避ける〕。

## 第205回追記（2026-11-20・全冊走査）

- **弘化2巳年（1845）4月8日の南北小口年番名主宛の橋銘札触書〔確認・repo初出〕**: 冒頭文書群の頂点として——「**南北小口年番名主　御府内橋々往来之もの通弁之ため御入用橋并町方持受橋之分以来最寄町々二而引受前後男柱袖柱之内え橋銘札打付置可申尤高探等無之石橋小橋之類且他向懸り御入用橋又者武家寺院其外支違持請ノ分は銘札打付候に不及候…但日本橋京橋江戸橋は銘札打付候に不及候**」弘化二巳年四月八日（市中取締掛・本所方定橋掛経由の評議・伺を経ての御触）＝**①往来人の通弁のため御府内の橋に橋銘札を打付ける触書が弘化2年に出されたこと、②銘札は「本銘無之里俗之唱有之分」は「何町ゟ何町江渡ル字何橋」と認め、「本銘里俗之通称無之分」は「何町ゟ何町江渡ル橋」と認める方式（里俗名が銘札に併記される）、③日本橋・京橋・江戸橋（＋両国橋・永代橋・新大橋・大川橋伺書）は銘札不要の識語、④武家・寺院持受の橋は対象外**＝**「里俗橋名」が1845年に銘札レベルで行政登録された触書**で、本資料の「里俗掃部橋」「里俗菊桟橋」の銘書群はこの触書の施行事務（銘書の書上げ・評議）の産物と読める（前回の銘書リストの年代を「嘉永4〜6年頃」と推定したのは誤りで、弘化2年〔1845〕に訂正）。
- **江戸向御入用橋（幕府持）28橋リストの神田上水系3橋＋里俗九町目橋〔確認・repo初出〕**: 触書末尾の「江戸向御入用橋并町入用」銘書のうち**江戸向御入用橋（都合弐拾八橋）**のリストに——「**小日向水道町一古川橋　関口水道町一江戸川橋　同町一関口橋**」＋「**小日向水道町ゟ二百羽町九町目え渡橋　里俗九町目橋**」＝**①1845年時点で古川橋（小日向水道町）・江戸川橋（関口水道町）・関口橋（同町）の神田上水系3橋が御入用橋（幕府持）に分類されていたこと、②九町目橋（小日向水道町ゟ「二百羽町」九町目え渡橋）も御入用橋側で「里俗九町目橋」と里俗名併記、③「里俗九町目橋」は音羽の九丁目橋（音羽九丁目交差点付近・江戸川橋の下流側）の有力候補**（「二百羽町」はOCR崩れが濃厚で何町かは要原照合・候補として関口方面か目白方面かの特定は保留）。**江戸川橋・関口橋が1845年に幕府持＝神田上水（江戸川）の開渠区間の橋の維持責任が幕府側にあったことの一次文言**（[GOV-213](GOV-213.md)の掃部橋＝町方持と対照）。古川橋・関口橋・九町目橋の銘札認方（何町ゟ何町江渡ル字何橋）も同リスト内に見える。
- **掃部橋の分類の裏付け〔観察〕**: 上記の触書に付随する銘書の分類で**掃部橋は御入用橋28橋側ではなく、町方持の「都合四拾五橋」銘書の「里俗菊桟橋　里俗掃部橋　里俗之唱無之」列**（前回既出の文言＝江戸向町入用橋の銘書）に置かれる＝**掃部橋の町方持（町入用＝町方の入用での維持）が1845年の銘書レベルでも裏付けられ、[GOV-213](GOV-213.md)（天保6年・「町内入用ヲ以懸来候」）・[GOV-221](GOV-221.md)と整合**。また本資料の銘書の施行（弘化2年4月8日触書）は、**寛政度の水溜桶町銘札の先例を引く評議文言**（「寛政度坂部能登守殿町方御勤役中町々家前水溜桶江町銘札記可差出旨被仰渡候弁利書留有之」）も含む＝町銘札行政の系譜の観察記録。
