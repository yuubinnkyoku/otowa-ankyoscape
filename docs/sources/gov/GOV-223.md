- **千川屋敷の両替屋の層歴〔確認・repo初出〕**: 「**小石川白山前町千川屋敷小石川拾ヶ谷町〔与七?〕地借庄左衛門地境一両替屋嘉永五子年九月廿七日頃名家主代届出す同日所替承届安政五午年八月十五日印形改承置慶応三卯年十月廿二日印形〔いる〕届出し文久三亥年三月廿三日千川屋敷ゟ一〔雑〕橋谷町家主与兵衛方同居相成段…申出承届**」〔**①小石川白山前町の千川屋敷内（雑司ヶ谷側の地借との地境）に両替屋が存在したこと、②嘉永5年（1852）9月27日頃に家主代を届け出て同日所替（場所替）が承認されたこと、③安政5年（1858）8月15日に印形改（印鑑の更新登録）、④慶応3年（1867）10月22日に印形の替え届け、⑤文久3年（1863）3月23日に千川屋敷から雑司ヶ谷の家主与兵衛方への同居替えを届け出たこと**＝**千川屋敷が幕末期に両替商の営業地（間口・店舎の賃貸）として使われていた実務記録（repo初出）**。千川上水の廃止（天明6）から半世紀以上後の嘉永〜慶応期に、屋敷が上水の機能とは無関係な商業地として賃貸されていた実態が確認できる〕〔「小石川拾ヶ谷町与七地借庄左衛門地境」の分節はOCR崩れを含み、正確な隣接関係（雑司ヶ谷与七の飛地と千川屋敷の地境か）は要原文照合。「一橋谷町」「橋ヶ谷町」は「雑司ヶ谷町」のOCR崩れの可能性大〕。
- **位置づけ〔観察〕**: ①千川屋敷の商業利用（両替屋＝金融業の営業登録）は、[GOV-222](GOV-222.md)（文政12年の家主・居候の賃貸関係）と併せ、**千川上水廃止後に千川屋敷が不動産（賃貸・営業地）として運用されていた**経過を連続的に示す。②文久3年に雑司ヶ谷の家主与兵衛方への同居替えが届けられたことは、この両替商が雑司ヶ谷方面（千川上水の上流側の給水地域）とも人的・地縁的なつながりを持っていた可能性を示す（文言の対応は要照合・解釈は断定しない）。③「与七」・「与兵衛」の雑司ヶ谷側の人名が千川屋敷の地割の隣接文言に現れる点は、千川屋敷の北側（雑司ヶ谷村飛地方面）との地境の特定の手がかりになる可能性がある（1912年地籍図との突合せは未実施）。
