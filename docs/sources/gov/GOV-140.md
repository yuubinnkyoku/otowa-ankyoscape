# [GOV-140] 豊島区「橋梁の長寿命化修繕計画（平成28年度改定）」〔repo初出〕

- **書誌〔確認: ADEAC目録詳細頁・本文PDF取得・OCRテキスト層抽出〕**: 豊島区『**豊島区橋梁の長寿命化修繕計画（平成28年度改定）**』（**平成29年3月**・[ADEAC目録ID mp15002800](https://adeac.jp/toshima-history/catalog/mp15002800)・[本文PDF（14_02_H290300）](https://adeac.jp/viewitem/toshima-history/viewer/viewer/14_02_H290300/data/14_02_H290300.pdf)・110頁・約6.2MB）。区が管理する橋梁14橋（道路橋・立体横断施設）の諸元・点検結果（H26・H27年度）・長寿命化の修繕計画（H29〜H38年度の10か年）をまとめた計画書。PDFは画像スキャンにOCRテキスト層が付く形式で、テキスト層から主要な文言・数値を読み取った〔確認: OCRテキスト層の抽出〕。表組みの列対応は抽出文の並びからの復元であり、幅員内訳など列の帰属が曖昧な数値は〔推定: 列対応の判読〕と明示する。
- **宮下橋（跨線橋）の台帳諸元〔確認: 表1-1・表2-1・表9-3・巻末調書〕**: 箇所＝**巣鴨3-25〜巣鴨1-36**、交差物＝**JR山手線（複線）・JR湘南新宿ライン（複線）**、**鋼単純鋼床版鈑桁橋・耐候性鋼材**、**橋長28.70m・総幅員11.00m・面積287.00m²**、**架設年次＝平成3年3月（1991年3月）**、路線名＝区道32-760、径間数1、適用示方書＝S55年道路橋示方書、活荷重＝TL-20一等橋、床版厚12.0cm。〔確認: 複数表の一致〕 箇所（巣鴨3-25〜巣鴨1-36）は2024年度点検表の「自巣鴨三丁目25番先 至巣鴨一丁目36番先」と地番で一致する。
- **宮下橋の点検・修繕計画〔確認: 第2章・第9章〕**: 平成27年度点検で**落橋防止装置に進行した腐食**、横桁・床版に軽微な腐食、沓座モルタル・橋台にひびわれを確認し、対策区分**C1**（予防保全管理の実施段階）。今後の補修＝塗替塗装工・ひびわれ注入工・橋面防水工・舗装打換工、耐震補強（桁長25m以上の落橋防止装置等）をH29年度以降の10か年計画に位置づける。LCC試算では事後保全型管理約15.0億円・予防保全型管理約2.86億円。残寿命80年（長寿命化前提）。
- **repoの未解決問題への意義〔観察〕**: GOV-137（平成元年7月12日議案説明資料・施工箇所＝自巣鴨三丁目25番先〜巣鴨一丁目36番先・H元年次JR東日本施工〔区委託〕→H2年次区施工）に対し、本計画書の**架設年次「平成3年3月」**は改築工事の完了時期（H2年度＝1990年度末〜1991年3月）と整合し、BLOG-062（warpal）の三代目1991年6月竣工説とも同年。**1989〜1991年改築の対象橋＝現役の跨線橋宮下橋という同定〔推定〕が、区自身の橋梁台帳（架設年次・箇所・仕様）でさらに強化された**。工事図面の原本照合までは実施しておらず、同定を「確認」に格上げするのは原本確認後とする〔注意〕。旧谷端川の西池袋4丁目「#32宮下橋跡」とは同名異橋であり、本書の宮下橋を旧河川橋の架設年代資料として使わない〔注意〕。なお同書の**江戸橋**（架設年次平成13年3月・箇所＝巣鴨3-1〜南大塚1-32・鋼単純鋼床版鈑桁橋20.70m）も、2024年度点検表で「巣鴨三丁目1番先」にあった江戸橋の前身（架設年次）を与える〔確認〕。
- **源水橋・高塚橋＝区管理14橋中で交差物が「河川（神田川）」の唯一の2橋〔確認: 表2-1・表2-2・巻末調書・repo初出の定量値〕**: **源水橋**＝箇所**高田3-22〜高田3-3**、交差物＝**河川（神田川）**、PCプレテンション単純中空床版橋、**橋長17.86m・総幅員9.80m・面積175.02m²**、**架設年次＝平成11年3月（1999年）**、適用示方書＝H6年道示、活荷重＝A活荷重25t、H27年度点検で区分（A）・現況OK。**高塚橋**＝箇所**高田3-9〜高田3-11**、交差物＝**河川（神田川）**、PCプレテンション単純中空床版橋、**橋長19.80m・総幅員10.80m・面積213.84m²**、**架設年次＝平成13年5月（2001年）**、H6年道示、A活荷重25t、区分（A）。〔確認: 表2-1・巻末調書の一致〕 豊島区が区道で河川を跨ぐ橋は神田川のこの2橋のみで、**区管理橋の枠で旧谷端川・千川上水・弦巻川・水窪川を跨ぐ橋は存在しない**（谷端川緑道の旧橋親柱等は本書の管理対象外）。〔観察〕
- **1996年道路橋位置図（README既述）の「高塚橋」「源水橋」との関係〔注意・未解決〕**: README既述の1996年2月26日『道路橋等の施設概要及び耐震対策』（PDF p.8 位置図）にも「高塚橋」「源水橋」の図中記載があったが、交差物は不明のままだった。本書（H29.3）の現行台帳で両橋の交差物＝**神田川**・箇所＝**高田3丁目**と確認された。ただし現行橋の架設はH11・H13（1999・2001年）で**1996年図の同名橋より後**であり、1996年図の記載が前身橋・計画中の橋・図上の別対象のいずれかは本書からは確定できない〔未解決: 1996年図の同名橋の実体〕。
- **弦巻川・神田川上流域の文脈〔観察〕**: 高田3丁目は旧弦巻川下流域（弦巻川が神田川に合流した低地）にあたり、GOV-138（H24.8目白駅付近浸水→目白・高田三丁目・下落合のφ2400mm雨水幹線新設）と同じ町丁目を含む。神田川の現行河道を跨ぐ区管理橋2橋（H11・H13架設・計画当時の供用年数17年・15年）の存在は、**旧弦巻川合流後の神田川区間の河川幅（橋長17.86m・19.80m）と現代の橋梁整備年代**の公的定量値を与える。〔観察: 2橋と弦巻川合流点との上下流関係は本書の位置図判読までは実施していない〕 「源水橋」の橋名と湧水・源流との関係について本書に記載はなく、橋名由来は推定しない〔注意〕。
