# [GOV-367] 御府内場末往還其外沿革圖書 貮拾亨（嘉永7年10月調）— 巣鴨村内の用水堀と雑司ヶ谷村代地〔第160回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の[24]冊「貮拾亨」（**嘉永七寅年〔1854〕十月調**）。NDL次世代デジタルライブラリー [book/2587245](https://lab.ndl.go.jp/dl/book/2587245)。表紙文言に「**嘉永七寅年十月調 御府内場末往還江革図書弐拾亨 外小石川村 小石川新田一円之絵図壱枚 巣鴨村**」（OCR崩れあり）とあり、**外小石川村・小石川新田・巣鴨村の一円を収める帳**＝[GAZ-012](../gazetteers/GAZ-012.md)が「地所書上の水路文言の精査は未実施」とした巻の一つで、本回の精査により用水堀・代地の文言を確認した（課題の部分的解消）。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する。**
- **巣鴨村内の用水堀の位置つき文言候補〔確認・文言候補〕**: ①**松平播磨守下屋鋪辺之部**＝四隣「**西南之方 巣鴨村之内用水堀限**」＋所内「**同所西南之方ニ用水堀有之**」（子安天満宮社地・真性寺持稲荷社地・東福寺境内を含む地所）＝**下屋鋪の西南方に用水堀が存在した**。②**窪田治部右衛門抱屋鋪辺之部**＝四隣「**東北之方 巣鴨村之内用水堀限**」＋「**同所東北之方に用水堀有之**」＝**抱屋鋪の東北方に用水堀**。③定型文「**用水堀等往古地形不明之ケ所は古絵図書入相除当時之絵図え出之**」（延宝年中絵図との対比文言）も反復。＝**嘉永7年時点の巣鴨村内（小石川との境から御殿山・染井方面まで）の下屋敷群の外縁に用水堀があったことを位置つきで示す書上記録候補**〔個々の用水の同定（千川系か谷端川系か巣鴨村の内用水か）は本帳からは行わない〕。
- **元禄10年護国寺建立収用と雑司ヶ谷村代地巣鴨村〔確認・文言候補〕**: 小石川側の地所（鉄砲角場・割銭地の沿革）の書上に「**元禄十丑年中 護国寺御建立之節 雑司ヶ谷村自澄院領之内御用地に被召上 本文当所屋鋪上ケ地二而百姓地二相成候地所 代地に成候由 当時村名 雑司ヶ谷村代地 巣鴨村**」＝**元禄10年（1697）の護国寺御建立の際に雑司ヶ谷村の自澄院〔自証院のOCR候補〕領の内が御用地に召上げられ、当所がその代地となって「雑司ヶ谷村代地」として巣鴨村の内に編成された（当時の村名表示）という沿革文言候補**〔[GAZ-073](../gazetteers/GAZ-073.md)①の圓融寺自證院条「元禄十丑年五月 護国寺御建立之切…御用地ニ被上」（寺領側の収用記録）・[GAZ-048](../gazetteers/GAZ-048.md)（風土記稿の元禄10年伝通院領〔領属側〕）・[GOV-364](GOV-364.md)の白山御殿代地文言（天和3年・巣鴨村代地・小石川村代地・雑司ヶ谷村の入会）と対照できる、雑司ヶ谷村の土地収用と代地の巣鴨村内への置換えの記録群の一部。「自澄院」＝自証院のOCR変種候補・要原画像照合〕。
- **位置づけ〔観察〕**: ①本冊は[GAZ-012](../gazetteers/GAZ-012.md)（第20部の巻構成）の「亨」の分冊で、第20部の元亨利貞のうち外小石川・巣鴨側を担当する。用水堀文言は「貮拾貞」〔[GOV-364](GOV-364.md)〕の谷端川上流域（29箇所）の南隣の区間に当たり、嘉永期の巣鴨村内の水路密度の検討材料になる。②「雑司ヶ谷村代地巣鴨村」の村名表示は、元禄期の雑司ヶ谷村の収用代地が巣鴨村内に飛地的に存在した嘉永期の行政単位としての実務表示である。
