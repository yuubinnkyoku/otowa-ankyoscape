# [GOV-070] 千川上水の記録フィルム

- **資料〔確認〕**：練馬区公式「練馬の歴史と文化財＞指定・登録文化財＞千川上水の記録フィルム」（ページ番号477-805-894、更新日2026年3月19日）を2026-11-11に直接確認。**千川上水を流れに沿い、取水口から六義園までをカラーリバーサルフィルム60コマで構成する記録フィルム**。タイトル画面に「千川上水　製作練馬区教育委員会　1952」とあることから**昭和27年（1952）に練馬区教育委員会が製作**したものと特定される。
- **製作意図〔確認：公式ページの解説〕**：当時、練馬区内でも場所により暗渠化工事が進められていた中、**工事の初期段階において時機を失することなく撮影**され、**カラーフィルムを使用している**など、「暗渠となる前により良い記録を後世に残そうという意図が明らか」という。〔**千川上水の暗渠化が1952年当時進行中だったこと、暗渠化前のカラー影像記録の実在、いずれもrepo初出の情報**。1952年=昭和27年は[BOOK-058](../books/BOOK-058.md)（水道歴史館『千川上水 昭和27年の写真を中心に』）と同年であり、両者は昭和27年前後の千川上水の記録群を構成する〕
- **タイトル7本の撮影地点〔確認：公式ページの記載〕**：
  1. 関町南2丁目7番（青梅街道と交わる千川上水）
  2. 上石神井1丁目8番（**田中水車**）
  3. 中村北4丁目2番（中村橋駅の少し手前）
  4. 豊玉北6丁目13番（**石神井川からの揚水流入口**）
  5. 栄町9番（武蔵大学前の暗渠工事）
  6. 旭丘1丁目1番（暗渠工事が進く／暗渠化されて間もない頃）の2本
  7. 豊島区南長崎6丁目34番（千川上水と西武池袋線）
- **repoへの関連〔確認・推定〕**：①**田中水車の所在地=上石神井1丁目8番**が特定される。[GOV-067](GOV-067.md)の練馬区4水車のうちの一つと比定されるが、同ファイルの水車所在記述との突き合わせで断定しない〔要照合〕。②**豊玉北6丁目13番の「石神井川からの揚水流入口」**は、石神井川から千川上水への揚水運転の実在を伝える映像記録の所在として重要〔揚水の運転年代は未確認〕。③武蔵大学前・旭丘の暗渠工事の撮影は**1952年当時の暗渠化工事の現場影像**。④南長崎6-34（西武池袋線との交点）は[GOV-069](GOV-069.md)（斉藤泰治証言）の南田中暗渠化証言と同じ練馬区南東部に位置する。
- **制限〔未解決〕**：フィルム本体の視聴・デジタル公開の可否、上映会・収蔵部署、60コマ各場面の画像は本ページでは確認できず、タイトル文言の転記に依存する。文化財指定・登録の区別もページ上で明記なし。
