# [GOV-638] 神田上水系の水車実務＝白堀水口差塞・渡辺一敏・水料（1881〜1899）

- **調査方法〔確認〕**: [GOV-637](GOV-637.md)と同じ第387回「水車」掃引（2,798件）のうち神田上水系の4件（＋人名簿1件）を本件に分離収録した（**本文は未見**・詳細頁の表項目は直接取得）。
- **①神田上水「白堀」通水車の水口差塞通知2件（明治14年〔1881〕・往復録・乙号・上水〈土木課〉明治１４従１年月至６月・６１１．Ｃ５．０６・[MF]府明Ⅱ明１４－０１９）〔確認×2〕**: a) 「砲兵工廠へ神田上水白堀通水車水口差塞の義通知（綴込005）」（pkey [370592](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=370592)）・b) 「植物御苑へ神田上水白堀通水車水口差塞の義通知（綴込006）」（pkey [370593](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=370593)）＝**神田上水の白堀（関口大洗堰から江戸川橋・柳町方面へ通じていた開渠区間〔[PAP-124](../papers/PAP-124.md)の断面復元対象）の「通水車」の水口を塞ぐ（差塞）ことを、東京府が砲兵工廠（小石川）と植物御苑（小石川御殿跡の官設植物園）に通知した**1881年の往復記録〔**白堀沿いに民間水車（通水車）が存在し、その取水口が1881年に塞がれた**ことの一次文言で、[PAP-124](../papers/PAP-124.md)の白堀水理・箱下水・大下水潜り樋の復元と、[BLOG-356](../blogs/BLOG-356.md)〜[359](../blogs/BLOG-359.md)・[BLOG-375](../blogs/BLOG-375.md)の江戸川公園・大洗堰研究に行政実務側の対照資料を追加する。差塞の理由・水車の所有者は本文未見〕。
- **②水道改良事務所取扱水車営業人名簿の渡辺一敏（明治元年〜21年〔1868〜88〕台帳・００５・６１７．Ｂ６．１２・[MF]府明Ⅱ明２１－０８１）〔確認〕**: 「水車営業 南豊島郡戸塚村 南豊島郡角筈村 渡辺一敏」（pkey [738807](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=738807)）＝**東京府水道改良事務所が明治元〜21年に管轄した水車営業の台帳（人名簿）に渡辺一敏（戸塚村・角筈村＝神田上水沿いの村）が登載**〔簿冊注記に「本書は台帳に綴込ありしも水道改良事務所へ引継後要用無之に付取り除き参考の為め壱冊に綴置くものなり」とある。**[GOV-618](GOV-618.md)第360回追記③の渡辺姓系列（水車要録の郡平→一敏→政方→孝/万助→範重・1894年）の所属村落が「戸塚村・角筈村」と初めて特定**＝同系列の水車は神田上水・余水系（角筈・戸塚＝現在の新宿区側）の営業で、[BLOG-094](../blogs/BLOG-094.md)の渡辺水車（鴨下・富士見台1＝千川上水沿い）との比定は**別系統の候補が強まった**（同一人物説は本文未見のため断定せず〔推定〕）〕。
- **③渡辺一敏の水車回し堀破損と神田上水助水引入口閉鎖願（明治30年〔1897〕10月・０４７・第２種 水道＊市水道・玉川上水分水並に水量調査書類〔明治27年4月〜同31年12月〕・６０１．Ｄ３．１３・[MF]市明Ⅰ明３１－０１１）〔確認〕**: 「渡辺一敏より水車回し堀破損に付神田上水助水引入口伊地知閉鎖願の件」（pkey [212886](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=212886)）＝**渡辺一敏が自身の水車の回し堀（導水路）の破損を理由に、神田上水の「助水引入口」（伊地知〔人名か〕）の閉鎖を願い出た**1897年の記録〔**神田上水の「助水」引入口が水車営業と結合した実務**で、[PAP-093](../papers/PAP-093.md)・[BLOG-386](../blogs/BLOG-386.md)（神田上水助水堀の2023年現況・淀橋さくら公園排水口）の助水研究に行政側の対照を追加。回し堀・引入口の位置は本文未見〕。
- **④神田上水路水車水料（明治32年〔1899〕・０１７・第２種 水道＊水道上水水料（水道）・６０１．Ｄ５．２１・[MF]市明Ⅰ明３２－００９）〔確認〕**: 「神田上水路水車水料」（pkey [565992](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=565992)）＝**神田上水の水車に対する「水料」（用水使用料）の簿冊**〔[GOV-618](GOV-618.md)①iの千川系の水料金上納（1882・鹿島てい）と対になる神田上水側の水料記録の所在。対象水車の一覧は本文未見〕。
- **位置づけ〔観察〕**: 1881（白堀通水車の水口差塞）→1868〜88台帳（渡辺一敏の営業登載）→1897（回し堀破損と助水引入口閉鎖願）→1899（水車水料の簿冊）＝**神田上水の白堀・助水系の水車が明治30年代まで営業実務の対象になっていた**ことの目録レベルの通時。水窪川・弦巻川（旧神田上水の谷頭・余水系〔[BLOG-001](../blogs/BLOG-001.md)/[002](../blogs/BLOG-002.md)〕）の水系史の上流域側の裏付け資料。
