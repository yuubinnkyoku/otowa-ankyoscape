- **安政3年の名主役願の連署の「雑司ヶ谷町 平左衛門印」〔確認・文言候補・名主の系譜の datapoint〕**: 「**牛込馬場下町 安政三辰年十一月十九日 名主福次郎印 同所早稲田町同大佐三郎印 同所無量寺門前十一(?)作次郎印 雑司ヶ谷町 十一月 平左衛門印 極木成子町同紋右衛門 四谷太宗寺門前一(?)田田之助印…**」と読める文言候補＝**安政3年（1856）11月19日付の名主役願（名主役に関する願書）の連署に、牛込馬場下町・早稲田町・無量寺門前・極木成子町・四谷太宗寺門前等の周辺の名主と並んで「雑司ヶ谷町 平左衛門」の印が連なる記録**。〔**①安政3年時点の雑司ヶ谷町の名主が平左衛門であったことの印形レベルの記録候補、②連署の顔ぶれ（早稲田町・無量寺門前・成子町・太宗寺門前）＝雑司ヶ谷町が高田・牛込・四谷の周辺町々と同じ名主役の連署圏にあったことの候補**＝[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考巻52・文政丙戌書上の雑司ヶ谷町条の名主平次左衛門〔幌→戸張〕）・[GAZ-073](../gazetteers/GAZ-073.md)（延享3年時点の雑司ヶ谷村名主平次左衛門）・[GAZ-072](../gazetteers/GAZ-072.md)（文政町方書上の戸張平次左衞門）の**平次左衛門家の後代（子孫か後任か）の記録候補**。**表記（平左衛門／平次左衛門）の差・同一人物か子孫かは本冊からは確定できず断定しない**（原画像照合・他の帳簿との対照で名字・代数の特定を要する）。他の名主の名（福次郎・大佐三郎・作次郎・紋右衛門・田之助等）はOCR崩れを含む。〕

## 制限・未解決

- ①OCR崩壊があるため、連署の町名・名主人名・日付の実字は原画像照合を要する（特に「無量寺門前十一作次郎」の部分の原字）。②名主役願の内容（何の願か）は本断片では未確認で、同冊内の前後の文書から文脈を確認する必要がある。③平左衛門と文政期の平次左衛門家の関係（同一人物・子孫・別家）は断定しない。④連署圏（牛込〜四谷の名主の組）の制度的意味（名主役の掛合いの範囲）は本冊だけでは確定できない。
