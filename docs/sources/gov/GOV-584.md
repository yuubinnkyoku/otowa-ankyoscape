# [GOV-584] 豊島区報道発表・第2回種子屋街道シンポジウム告知（2025-11-13発信）

## 本文記載事項〔確認: 区公式報道発表ページ・ページID 54722・更新日2025年11月13日〕

- 豊島区の**令和7年11月13日**付報道発表。**令和7年11月29日（土曜）13時00分から16時30分**、大正大学（豊島区西巣鴨3-20-1）にて「**種子屋街道の歴史を今に伝える 地域に根差した種子屋の役割～これまでとこれから～**」を開催〔＝[BLOG-317](../blogs/BLOG-317.md)（いけぶくろねっと告知・2026-11-04投稿）が引用していた r0711/2511131356 の原本。**第2回シンポジウムのR7.11.29説（第310回の整理）を区側一次資料で確定**〕。
- **第1部（13:00〜14:40）＝シンポジウム（報告1～3、討議、発表）**・**第2部（14:40〜16:30）＝文化財保存修理事業見学会（協同組合伝統技法研究会 角野茂勝氏）**会場＝区指定文化財「榎本家店舗兼住宅および新座敷」（西巣鴨3-19-2）〔区広報本文では報告の題名・報告者名は未記載。BLOG-317の報告者3名（横山恵美・近藤友宏・吉田尚也）との直接の対照は不可〕。
- **主催＝一般財団法人榎本種苗歴史文化財団**・**共催＝豊島区、大正大学、協同組合伝統技法研究会**・**後援＝巣鴨信用金庫、株式会社日本農林社、一般社団法人日本種苗協会、住友林業株式会社**（4団体）。**第3回（[GOV-583](GOV-583.md)・R8.11.28）の後援にあった株式会社種苗会館・東京種苗株式会社は第2回後援には不在**〔第2回と第3回の後援の差の一次確認〕。定員150名（当日直接会場へ）・参加費無料。問い合わせ＝文化事業課 管理・文化財グループ（03-3981-1190）。
- 主催者の榎本種苗歴史文化財団理事**加藤祐子**氏のコメント:「区、学校、企業と力をあわせて『榎本家店舗兼住宅および新座敷』の魅力を最大限引き出し、特色のある地域づくりに貢献しながら、区民の方々と一緒になって盛り上げていきたい。**本シンポジウムで、その種を蒔きたい**」〔区側は「**祐子**」表記＝[BLOG-315](../blogs/BLOG-315.md)「加藤**佑子**」との表記対立（第2回挨拶者・五代目榎本泰吉の娘）。「その種を蒔きたい」はrepo初出文言〕。

## repo初出の文言・位置づけ

- **「種子屋街道」の行政側定義注記〔確認・repo初出〕**: 本ページは本文中の「本イベントで紹介する種子屋街道※」に対し、注記「※ **江戸時代から戦前までの期間、豊島区巣鴨から北区滝野川にかけての旧中山道沿いにあった多くの種子屋が軒を連ねた地域**」を付す〔豊島区が「種子屋街道」を定義する文言の一次記録。[GOV-583](GOV-583.md)（第3回プレス・PR TIMES配信）にも種子屋街道の空間的定義文言はなく、[BLOG-313](../blogs/BLOG-313.md)（滝野川探検隊「中山道と千川上水に囲まれた土地…有名な種苗屋街道でした」）の地域記録側文言に対する行政側の対応文言〕。千川上水への言及は本定義注記にはない。
- 「榎本家店舗兼住宅および新座敷」の紹介文言:「江戸時代から営まれてきた種子屋の歴史を今に伝える、**戦災を免れた区内では数少ない戦前期の建築物であり、区内最古の木造住宅**です（**令和5年4月 豊島区区有形文化財指定**）」〔「区内最古の木造住宅」文言は第3回プレス〔GOV-583〕と同一。「区有形文化財」の表記揺れ〕。
- 第2部見学会の実施（14:40〜16:30）＝[BLOG-315](../blogs/BLOG-315.md)（R6.11.30の第1回参加記）にあった種子地蔵前の見学会待機とは別回の、区側告知に基づく保存修理事業見学会の連続性の確認point〔第1回（R6.11.30）と第3回（R8.11.28）の間の中間年の実施記録〕。
