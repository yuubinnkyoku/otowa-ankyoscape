- **事業概要図（000028147・1頁）〔確認: 本文・2026-11-23〕**: 表題「**神田川（番屋橋下流～神泉橋下流）整備事業 平成28年7月 東京都第三建設事務所工事第二課**」＝**平成28年7月**の発行文言〔作成日確定〕。事業概要＝「**東京都では、水害に対する安全性を高めるため、１時間あたり50㎜の降雨を安全に流下させることができる河道の整備をすすめています。また、神田川や石神井川など区部の台地を流れる河川は、近年の50㎜を超える降雨に対応するため、調節池などを組み合わせることにより、75㎜の降雨に対応できるよう河川整備を進めています**」〔**50mm河道＋調節池で75mm**という整備方針文言＝[GOV-514](GOV-514.md)（時間50mm+調節池15mm+流域対策10mm=75mm）の内訳文言の前身にあたる平成28年時点の文言〕。標準横断図・**整備事業区間図（番屋橋〜宮前橋〜栄泉橋〜神泉橋の区間・護岸鋼管杭の図例）**・**各橋りょうの通行止期間（予定）＝番屋橋・宮前橋（平成30年頃）・栄泉橋（人道橋）・平成28年〜平成33年1月のチャート**〔[GOV-524](GOV-524.md)（その210・説明資料37頁）の橋梁通行止スケジュールと同じ形式文言〕・**「※栄泉橋について、破線期間（宮前橋通行止期間）の通学時間帯は、通行出来るよう検討いたします」**〔人道橋=通学路の文言〕・問い合わせ＝第三建設事務所 工事第二課 設計総括担当 03-3387-5367。
