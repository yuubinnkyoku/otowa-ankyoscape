# [GOV-259] 東京市域拡張史（1934）— 編入町村の水利引継ぎ要望と千川上水の敷設年代説

- **書誌〔確認〕**: 東京市臨時市域拡張部『東京市域拡張史』（1934年・次世代デジタルライブラリー [book/1259341](https://lab.ndl.go.jp/dl/book/1259341)）。1932年（昭和7年）10月の隣接五郡82町村の東京市への編入（市域6倍・人口約590万）の経過・要望・引継ぎ事務をまとめた記録書。巻頭に永田秀次郎市長の編入上奏文（「陛下睿聖ノ資ヲ以テ…四方ヨリ帝德ヲ慕ヒ」の文言）。引用文言はOCR由来で要原文照合。**千歳村・砧村編入の別冊（1937）は[1231039](https://lab.ndl.go.jp/dl/book/1231039)として既知（repo既出の要望記録と同形式）。**
- **長崎町の水利要望〔確認・repo初出〕**: 編入時の町村要望の列挙に——「**一、當町用惡水路ノ幹線タル谷端川ノ改修ヲ速カニ施行シ、併せて道路側溝ノ完備ヲ圖られたし(長崎)**」＋「**一、當町地域ノ用惡水路樋管橋梁其ノ他土木ニ關スル一切ノ事項ハ、市費ヲ以テ處置せられたし(長崎)**」＝**①長崎町が自町の用悪水路の幹線＝谷端川の改修の早期施行を求めたこと、②用悪水路の樋管・橋梁など土木一切の市費処置を求めたこと**＝1932年編入時の水利引継ぎ要望の町側一次記録。〔[GOV-258](GOV-258.md)（昭和2年府諮問・関係町に長崎を含む）→[GOV-159](GOV-159.md)（1930年決定）→1932年編入時の町要望→[GOV-260](GOV-260.md)（1935年進捗）という谷端川改修の行政過程の町側の補完。用悪水路の樋管（暗渠・伏越）の維持が町費だった実態の傍証。〕
- **瀧野川町の要望〔確認〕**: 「**一、從來町に於て經營せる街路撒水等の保健衞生施設は、市に於て繼續せられたし(瀧野川)**」＝**街路撒水（道路の水撒き）等の保健衞生施設の市への続行要求**〔撒水用水の水源（千川上水・谷端川系か）は本文では特定できないが、瀧野川町の水利用の実務が編入時に市へ引き継がれたことを示す要望の例証。〕
- **千川上水の敷設年代説〔確認・対校用〕**: 総説で「**四代家綱の世に神田・玉川の兩上水が竣工しつゞいて五代綱吉の時千川上水が敷設せられ、所謂江戶の三上水が完成**」＝**千川上水を五代綱吉（在職1680〜1709）の世の敷設とし、江戸三上水（神田・玉川・千川）の完成と位置づける1934年の公式記述**〔元禄9年（1696）起立の一次文言群（[GAZ-016](../gazetteers/GAZ-016.md)・柳營日次記「紀是年千川上水ヲ鑿通ス」等）とは幅のある年代の書き方（綱吉の世＝元禄期を指すと思われる）で、「江戸の三上水」の語の用例としてもrepo初出候補。〕
- **位置づけ〔観察〕**: [1231039](https://lab.ndl.go.jp/dl/book/1231039)（千歳村・砧村編入・repo既知）と同形式の**編入時の町村要望の一次記録が、谷端川流域の2町（長崎・瀧野川）について確認できた**ことが本冊の価値。千歳村・砧村の水利記述（用悪水路の市費処置要求）と同型の文言が北豊島側でも並ぶ＝**編入時の水利引継ぎ問題が全市域で共通の争点だったことの裏付け**。
