# [GOV-592] 橋・堰・用水・地名・水害の補遺群（1880〜1974）

- **調査方法〔確認〕**: 「千川水路」（[GOV-591](GOV-591.md)）の全走査に合わせ、千川・谷端系の橋・堰・用水・地名・水害の補遺を目的にキーワード「仁王橋」「高田村」「田柄川」「谷頭」「三軒家」等をクロス検索で掃引し、下記6群の詳細頁（請求番号・MF・コマ）を確認した〔第311回POSTレシピの復旧使用・技術の詳細は第315回ノート〕。いずれも**本文は未見**。
- **①仁王橋修補の1880年府側記録〔確認・「堀割小路」がrepo全grep新出〕**: 「明治１３年２月１８日 印刷局より北豊島郡滝野川村**堀割小路字御代之台に架設の仁王橋修補の義村民共より願出に付当局費用を以て該橋梁修補の義申進**」（明治13.2.18・**６１０．Ａ６．０１**〔往復録・甲号〈土木課〉明治13年度1月〜6月〕・[MF]府明Ⅱ明13-021・コマ0442-0950・pkey [697907](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=697907)）＝**仁王橋が滝野川村の堀割小路字御代之台に架設され、村民の願い出に対して「当局費用」（＝印刷局。仁王橋は千川用水に架かる＝東京府志料）で修補された**1880年の府側一次記録の目録情報〔[BLOG-321](../blogs/BLOG-321.md)の東京府志料滝野川村条「仁王橋＝千川用水ニ架ス・長8間3尺・幅1間・木造・仁王塚説」に対し、(a)所在字（堀割小路字御代之台）、(b)修補主体（村民の願い出に対し**当局（＝印刷局）費用で修補する体制**＝[GOV-591](GOV-591.md)⑤の1888〜89年護岸橋梁修繕費往復群に先行する**印刷局の維持費負担体制**）の新情報。志料の仁王橋との同一性は本文未見のため断定しない〔谷端川.mdの千川上水からの分水節に相互参照として追記済み〕〕。
- **②高田村の分水堰・用水（1883・1885）〔確認〕**: a) 「明治１６年１０月５日 **分水堰欠崩修繕願出** 北豊島郡高田村、**大沢民五郎**」（明治16.10.5・**６１３．Ｂ５．０７**〔回議録・第１類・乙号・水道〈土木課〉従9月至12月〕・[MF]府明Ⅱ明16-058・コマ0585-1056・pkey [715959](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=715959)）、b) 「北豊島郡高田村**用水変換**之義同村**醍醐惣左衛門等**より出願之件」（明治18〔1885〕・**６１４．Ａ５．０５**〔回議録（（雑願雑件）・南豊島郡）〈地理課〕〕・[MF]府明Ⅱ明18-059・コマ0006-0502・pkey [463074](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=463074)）＝**高田村（弦巻川・水窪川上流域の千川上水分水地帯）の分水堰の欠崩修繕と用水の変換（取替）の出願**の2件〔大沢民五郎・醍醐惣左衛門はいずれもrepo全grep新出人名。b)は簿冊名が「南豊島郡」だが件名は北豊島郡高田村で、高田村の郡帰属をめぐる既存の議論に注意して本ファイルでは件名どおりに記す〕。
- **③明治21〜22年・市町村制施行順序取調書の字名調書（1888〜89）〔確認・谷端・御代ノ台字名の一次列挙〕**: 「**高田村に属する部分池袋村の内字大原・丸山・中原・上の４字**合計反別戸数人口の調書、**下板橋町に属する分滝野川村の内字東三軒家・西三軒家・平尾・鴻ノ台・北谷端・南谷端・御代ノ台の７字**合計戸数人口反別地価の調書」（明治21〜22〔1888〜89〕・**６０４．Ｂ４．０５**〔市町村制施行順序取調書・荏原郡、北豊島郡、東多摩郡、南豊島郡・町村区域分割并飛地調書〈市町村制施行順序取調所〕従明治21年至22年〕・[MF]別置-018・コマ0477-0707・pkey [557852](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_04&pkey=557852)）＝**市町村制施行（1889）前後の村境確定作業で、池袋村の飛地的な4字と滝野川村の7字（北谷端・南谷端・御代ノ台を含む）が反別・戸数・人口・地価つきで調書化されていた**記録〔**北谷端・南谷端・御代ノ台の字名の一次調書**（＝下板橋町へ編入される滝野川村側の字。地名対照表系資料と対照可能）。件名の「高田村に属する部分池袋村の内4字」は池袋村のうち高田村側へ帰属する飛地群を意味する〔詳細な帰属の方向は本文未見のため、ここでは件名の文言のみ記す〕。**画像公開あり**（デジタルアーカイブ i-repository〔dasasp03・G0000002tokyoarchv03_0001179630001〕）＝次回の判読対象〕。
