- **水管の構造と規模〔確認・repo初出の定量〕**: 「**（其工事ヲ起スノ初ニ當テ竹樋ヲ以テ其用ヲ辨セントセシカ水勢强大ニシテ或ハ破損センコトヲ慮リ）檜材及杉材小樋トナシ樋長八百二十間吹井四所並井四所ヲ設ケリ**」＝**樋長820間（約1.49km）・吹井4所・並井4所**という千川水道會社施工の上野方面送水樋管の規模（当初竹樋を案じたが水勢が強いため檜材・杉材の小樋としたという経緯の文言。樋管の材質・長さの1880年代の実数で、[GOV-172](GOV-172.md)（明治24年上水道章程の「陰樋延長凡壹里拾五町四十七間」）の市中側陰樋総延長とは別の、上野公園方面への枝線の実数としてreferable）。
