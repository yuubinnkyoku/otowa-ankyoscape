# [GOV-312] 東京警視本署布達全書（明治12年分）— 兩上水取締禁例への改名・罰則化・同年内の罰則刪除

- **書誌〔確認〕**: 『**東京警視本署布達全書**』（**明治12年分**。NDL次世代デジタルライブラリー [book/791199](https://lab.ndl.go.jp/dl/book/791199)）。明治12年（1879）の警視本署布達を甲・乙・丙の部に分けて編年収録。**引用文言はOCR由来で原画像照合を要する（特に規則名の判読）**。

## ①甲第6号（明治12年2月26日・東京府知事連署）: 仮規則→禁例への改名と条文改正〔確認文言〕

- 本文〔確認文言・OCR崩れ箇所あり〕: 「**明治十一年甲第五拾七號布達 神田玉川兩上水源取締月假規則ヲ兩上水取締禁例トナシ及ヒ第三條第四條左之通改正シ第五條ヲ刪除候條此旨布達候事 第三條 上水ニ沿フタル各地面ヨリ汚水混八（混入セシム候補・判読要）セシム 第四條 堤上ノ竹木及ヒ下草等伐採スベカラス**」＝**明治11年10月甲第57号の「神田玉川兩上水源取締假規則」〔全文は [GOV-313](GOV-313.md)〕を「兩上水取締禁例」に改名し、第3条（沿面各地面からの汚水混入）・第4条（堤上の竹木・下草の伐採禁止）を改正し、第5条（堤防破損の巡查・分署への告知）を刪除した**。
- **判読上の注意〔要照合〕**: OCRでは規則名が「**月假規則**」と現れるが、改名対象は[GOV-313](GOV-313.md)の「神田玉川兩上水源取締**假**規則」であり、「月」は「同」等の判読候補（「同假規則」）として原画像照合まで確定しない。第3条の「汚水混八セシム」も「混入セシムベカラズ」等の判読候補がある。
- **東京府知事連署〔確認文言〕**: 「**事連署東京府知[事]**」＝[GOV-311](GOV-311.md)（明治14年・千川水道取締禁例・東京府知事連署）と同じ連署形式。目次にも「神田玉川兩上水源取締規則改正剛除等ノ事」（「剛除」は刪除のOCR崩れ）。
- **前後の布達〔確認文言〕**: 直前の2月12日甲第5号「**拙者儀歐洲ヘ渡航中本署事務ハ中警視安藤則命代理致シ候條此旨布達候事**」＝大警視・川路利良の欧州渡航中に中警視・安藤則命が本署事務を代理した期間の布達であることが分かる（目次「安藤則命代理ノ事」「大警視川路利良歐洲ヘ渡航中本署事務ノ事」）。**甲第6号・第7号はこの代理期に出されている**。

## ②甲第7号（明治12年2月26日）: 違式罪目への罰則追加〔確認文言〕

- 本文〔確認文言〕: 「**違式罪目左之通追加候條此旨布達候事 第七十六條 神田玉川兩上水取締禁例ニ違背スル者**」＝**違式罪目（違反罰則の目録）の第76条として「神田玉川兩上水取締禁例ニ違背スル者」を追加**＝仮規則の段階では布達本文に罰則規定がなかったものが、禁例化と同日に違式罪目経由で罰則化された。
- **意義**: 禁例（改正規則）と罰則（違式罪目）が同日2本の布達でセット運用された警察行政の実態が確認できる。

## ③甲第38号（明治12年11月10日）: 罰則の同年内刪除〔確認文言〕

- 本文〔確認文言〕: 「**十一月十日甲第三拾八號 違式罪目第六十九條第七十六條刪除候條此旨布達候事**」＝**違式罪目第76条（兩上水取締禁例違背）と第69条が同年11月10日に刪除**された。目次にも「違式罪目第六十七條第七十六條剛除ノ事」（「剛除」は刪除のOCR崩れ・第69条は「六十九」のOCR崩れ候補）。
- **意義**: **兩上水取締禁例の罰則は明治12年2月26日の追加から9か月足らずで刪除**された。以後の両上水の取締がどの罰則体系で運用されたか（禁例本文のみか・別の罪目へ移行したか）は本書では未確認。第69条の内容（何の罪目だったか）も本条では不明。

## 制限・未解決

- ①「月假規則」「汚水混八セシム」等のOCR崩れ箇所は原画像照合まで文言候補扱い。②違式罪目第69条の内容は未確認（第76条と同時刪除の理由関係も不明）。③罰則刪除（明治12年11月）後の取締の実効性の担保方法は未確認。④改正後の禁例の全文（第1・2条は仮規則から変わっていないか）は本書では省略されており、原布達・[GOV-314](GOV-314.md)（坤）等との突合せで確認する。
