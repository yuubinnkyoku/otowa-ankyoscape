# [GOV-094] 文京区「氷川下町会」頁・千川下流暗渠化の月次と氷川たんぼの沿革

- **書誌〔確認〕**: 文京区公式サイト「町会・自治会のご案内 > 大原エリア > 氷川下町会」（ページID 1264、更新日2024年4月25日）。**直アクセスは翻訳プロキシ遮断のため、Wayback Machine（2026-10-25スナップショット）で本文全文取得**〔[GOV-082](GOV-082.md)と同一の回避手段〕。本文は**文京区町会連合会創立60周年記念誌「六十年のあゆみ」（2014年11月発行）掲載内容の引用**と明記〔出典資料名の特定＝repo初出〕。
- **〔確認・repo初出〕 千川下流改修の月次**: 「**下水道の不備で千川は毎回何回かの出水にみまわれた。そこで、昭和5年11月根本的な治水改修工事が開始され、水流をコンクリートの暗渠にし、昭和9年7月に工事は竣工した。それが現在の千川通りの礎である**」〔**着手=昭和5（1930）年11月・竣工=昭和9（1934）年7月の月次までの記述＝repo初出**。[BLOG-077](../blogs/BLOG-077.md)の千川改修記念碑（昭和5年着手→総延長3,272m→昭和9年竣工）の年次と一致する独立の文献裏付け〕。
- **〔確認〕 氷川たんぼ・播麿たんぼの沿革**: 江戸期の新田開墾として「**享保年中（1726～1736）に千川沿いを中心に開墾して『氷川たんぼ』と称した**」〔[BLOG-078](../blogs/BLOG-078.md)の「氷川田んぼ」の享保年中開墾年次と一致〕。「明治24年、簸川神社のある台地の下の低地にあったので、その場所を氷川下町と名づけられた」。低地を流れる千川沿いに「氷川たんぼ」と「播麿たんぼ」があり、**明治末期頃までは花々が咲き清流には魚影も多く見受けられた**。**氷川たんぼは明治30年代に埋め立てられ人家・工場が立地**（[BLOG-119](../blogs/BLOG-119.md)の小石川區史引用と整合する沿革）。**明治29年に共同印刷の前身・博進社印刷工場が千川沿いの播麿たんぼの真中に進出**〔[ORG-001](../org/ORG-001.md)の1896年説と整合（明治29=1896）。同社沿革の1898年小石川移転との2年差はORG-001の併記のまま〕。
- **〔確認〕 中世の所領**: 「永禄年間（1558～1580）北条氏の家臣島津孫四郎の土地及び法林院領であった」〔小石川村の中世所領記述。[BLOG-119](../blogs/BLOG-119.md)の中世小石川文献群に加える候補〕。**昭和42年1月の住居表示で氷川下町会の名称は廃止**（千石2・3丁目、大塚3・4丁目の一部へ）〔町名廃止の年月の具体化〕。
- **意義**: 千川下流暗渠化の着工月（昭和5年11月）・竣工月（昭和9年7月）が町会連合会記念誌レベルで確認でき、[BLOG-077](../blogs/BLOG-077.md)（碑）・[BLOG-089](../blogs/BLOG-089.md)と合わせて1928議決→1930.11着工→1934.7竣工の工程が文献2系統で裏付けられた。氷川たんぼ・播麿たんぼの開墾（享保）→命名（明治24）→埋立（明治30年代）→暗渠（昭和5～9）→住居表示廃止（昭和42.1）の年次チェーンが一枚の文献内で揃った。
