# [GOV-316] 東京警吏要覧 2版（1879）— 禁例の改正注記つき再録と番外達の日付

- **書誌〔確認〕**: 『**東京警吏要覧**』**2版**（**1879**〔明治12年〕。**第二方面第四分署 編**・警視局。NDL次世代デジタルライブラリー [book/791206](https://lab.ndl.go.jp/dl/book/791206)）。警吏向けの布達・達の実務編纂書。**引用文言はOCR由来で原画像照合を要する（罫線と条文の割付が崩れている箇所がある）**。

## ①兩上水取締禁例の改正注記つき現行再録〔確認文言・文言候補〕

- 「**神田玉川兩上水取締禁例（十二月廿六日改正）左ノ通相定來ル（十二月一日）施行候條此旨布達候事（明治十一年十月廿九）日甲第五十七號 第一條 魚鳥ヲ捕リ及ヒ游泳シ又ハ諸物品ヲ洗フヘカラス 第二條 塵芥瓦礫其他汚穢物ヲ投棄スヘカラス 第三條 上水ニ沿フタル各地面ヨリ汚水混入セシムヘカラス（十二月廿六日改正）第四條 堤上ノ竹木及ヒ下草等伐採スヘカラス（十二月廿六日改正）第五條 前條ノ塲合ハ勿論其他上水ニ屬スル堤防等破損ノ塲所アラハ巡行ノ巡査又ハ最寄警視分署ヘ告知スヘシ**」（カッコ内は割付崩れから読み取った注記部分・文言候補）。
- **意味〔確認・文言候補〕**: ①規則名が「**兩上水取締禁例**」（改正後の名称）で再録され、第3条・第4条に**「（十二月廿六日改正）」＝明治12年2月26日の甲第6号改正の注記**が付く＝[GOV-312](GOV-312.md)の改名・改正の条文対応（第3・4条）の独立裏付け。②**一方で第5条として仮規則の旧第5条（堤防等破損の告知条）の本文がそのまま並ぶ**＝[GOV-312](GOV-312.md)の「第5条刪除」と[GOV-315](GOV-315.md)（明治29年現行の第5条＝罰則条）の間の再録形態の差。**編纂時に刪除前の原文が残ったか・罫線処理（抹消）がOCRで読めないか・第5条刪除が実際には別の運用だったかは原画像照合まで断定しない**（いずれにしても明治12年時点の分署編纂書が禁例を現行規則として収録した事実の記録）。

## ②巡査交番番外達の「十月廿九日」付〔確認文言・GOV-314との対照〕

- 「**神田玉川兩上水取締禁例甲第五十七號前件見合ヲ以テ布達候ニ付テハ其署ニ於テ巡査交番ヲ定メ巡視可爲致萬一水路中汚物等ノ投棄アルヲ見認ル時ハ最寄水番人ヘ通達シ速ニ掃除方可取計此旨相達候 十一年十月廿九日 番外 第三方面第四分署ヘ**」
- **意味〔確認〕**: [GOV-314](GOV-314.md)（布達全書明治11年坤）の番外第125号「十月十七日」（文言候補）と同一内容の達が**「十一年十月廿九日」付**で再録されている＝[GOV-315](GOV-315.md)（明治29年類纂）・[GOV-317](GOV-317.md)（警視類聚規則）と合わせ、**10月29日（甲第57号布達と同日）説の独立裏付け3点目**。791189の「十七日」は「廿九日」の判読候補として原画像照合を要する。

## ③違式罪目第76条の再録〔確認文言〕

- 「**十二年二月廿六日 甲第七號 第七十六條 神田玉川兩上水取締禁例ニ違背スル者**」＝[GOV-312](GOV-312.md)②の罰則化布達（違式罪目第76条追加）の本文レベルの独立再録。本書（明治12年編纂）は**罰則刪除（明治12年11月10日甲第38号）の同年編纂**のため、刪除前後の収録状態の原画像確認が残る課題。

## 位置づけ〔観察〕

- 本書の編者が「**第二方面第四分署**」（当時の方面分署制の実務部隊）であること自体が、明治11〜12年の上水取締達が「**第三方面第四分署**」宛て（[GOV-314](GOV-314.md)・[GOV-315](GOV-315.md)③）に出された分署組織の実像（方面内の分署が横断的に規令を共有していた）を示す副次資料になる〔観察〕。

## 制限・未解決

- ①第5条の再録構造（旧文残存の解釈）は原画像照合まで保留。②「十二月廿六日改正」の注記の正確な位置（第3条直後・第4条直後のいずれに付くか）は割付崩れのため文言候補。③本書の収録が罰則刪除（明治12年11月）の前後いずれの状態を写したかは未確認。
