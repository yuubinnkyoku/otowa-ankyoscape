# [GOV-209] 神田上水留 [13]/[14]（弘化3〜4年）— 鼠ヶ谷大下の渡石樋と白堀通の引取樋の修復

- **書誌〔確認〕**: 幕府水道方の上水修理関係の記録類（御普請一件）。**分冊一**＝NDL次世代デジタルライブラリー [book/2587468](https://lab.ndl.go.jp/dl/book/2587468)（弘化3午年8月14日付・西丸御持筒頭松平作左衛門組・封川良右衛門の文言を含む）、**分冊二**＝[book/2587469](https://lab.ndl.go.jp/dl/book/2587469)（弘化3午年6月〜弘化4未年2月・「神田上水留分冊ノ二」）。**いずれもOCR由来で文言は原文照合を要する。**
- **鼠ヶ谷大下家上の渡石樋の修復仕様〔確認・神田上水×鼠ヶ谷下水の交差構造の一次記録〕**: 分冊二の「御修復仕様注文」——「**鼠ヶ谷大下 水上(家上?)渡石道内 一渡石樋 内挟長七間（OCRで「嘉」の字が混入・原字形要照合）五尺七寸 右仕様 土台其侭差置 上廻朽損候に付 仕直し候積**」＋坪柱・帯指貫・上梁・上桁・梁桁等の木材寸法の仕様の列挙〔**①「鼠ヶ谷大下家上」の渡石樋（石造の掛け渡し樋）の内挟長7間(?)5尺7寸、②土台はそのまま据え置き、上廻りが朽損したため仕直すという弘化3年（1846）の修復仕様**＝**神田上水（白堀＝開渠区間）が鼠ヶ谷（弦巻川・水窪川系の谷）を渡る石樋構造の、幕府水道方による修復の一次記録（repo初出の修復仕様）**。「鼠ヶ谷大下」は鼠ヶ谷下水の下流域（音羽・桜木町界隈〔[GAZ-035](../gazetteers/GAZ-035.md)〕）とみられるが、渡石樋の正確な位置（桜木町の万年樋〔[GAZ-035](GAZ-035.md)〕と同構造か・別地点か）はこの文言からは特定できない（断定しない）〕。
- **矢来30間×2（鼠ヶ谷大下家上・桜木町大下）〔確認・repo初出〕**: 分冊一——「**鼠ヶ谷大下家上 渡石樋廻り 一 矢来 長延三拾間。桜木町大下 永上 同断 一同 長延三拾間。右仕様 惣体折損候に付 仕直候積**」＋矢来の仕様（栗丸太・杉中貫・木戸門等の詳細寸法）〔**①渡石樋廻りに矢来（柵）30間（鼠ヶ谷大下家上）、②桜木町大下の「永上」（OCR・原字形要照合）にも同断30間、③惣体折損につき仕直し**＝**神田上水の鼠ヶ谷大下・桜木町大下区間に矢来30間ずつが設けられていた記録（repo初出）**。桜木町大下・鼠ヶ谷大下という区間名で神田上水の流路管理が行われていたことを示す〕。同分冊には牛天神下水・戸殿(?)屋敷後口の矢来8間5尺・「金岡寺坂下橋台脇」の石垣（長4間・高6尺）の文言もある〔「金岡寺坂」は金剛寺坂（関口）のOCR誤読の可能性・要照合〕。
- **白堀通の引取樋5ヶ所の取調〔確認・白堀からの私的取水の構造の一次記録〕**: 分冊二——弘化3年6月23日・小日向水道町名主三四郎の書上「**今般 白堀通御普請に付 引取樋場所并びに樋内法 木樋・竹樋之訳 修復年限等 御調に付 別紙絵図面を以 樋場所之者 朱引仕奉申上候 引取樋五ヶ所 一 小日向川添屋敷に壱ヶ所 木樋 口内法壱寸半四方（OCR崩れ）にして去る辰年（＝天保15辰年か）四月廿五日 御願（通り）仕候 一 同所大日坂下に壱ヶ所 木樋 口内法弐寸四方と申伝のみに而修復年限等相分り不申候 一 同所服部坂下三ヶ所 …西之方に壱ヶ所 木垣口 内法壱寸四方に申伝のみ…中に而壱ヶ所 木樋 口内法弐寸四方に而当午（弘化3）五月十日 御願済 修復仕候**」〔**①神田上水白堀（開渠）通りの御普請に際し、沿道の屋敷等の引取樋（取水樋）5ヶ所（小日向川添屋敷1ヶ所・大日坂下1ヶ所・服部坂下3ヶ所）の樋の内法寸法（1寸半四方・2寸四方・1寸四方等）と御願・修復の年次（天保15辰年〔1836?〕・弘化3年5月10日等）を水道町名主が取り調べて提出した記録、②伏替（樋の取替え）の年次（天保15辰年・天保4己年〔OCR〕等）の列挙**＝**白堀（神田上水の開渠区間）から小日向側の屋敷が引取樋で取水していた実態とその管理（御願制）の一次文言（repo初出）**。大日坂・服部坂という坂名と小石川・小日向側の位置関係の資料。内法寸法・年次はOCR崩れが多く要照合〕〔小日向川添屋敷の町（[GAZ-034](../gazetteers/GAZ-034.md)の川添屋敷町）と、坂下の引取樋の対応は位置課題〕。
- **高札の文言〔確認・参考〕**: 分冊二に「神田上水 白堀通 高札 御普請仕様注文（新坂下）」の文言があり、白堀通りの高札（2ヶ所）の普請仕様も含まれる〔高札の内容（上水の掟等）の文言は本書からは未確認〕。
