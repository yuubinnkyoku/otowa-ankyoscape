# [GOV-490] すぎなみ学倶楽部「杉並の暗渠散歩」〔repo初出・区公式情報サイトの現地案内記録〕

- **書誌〔確認: 本文全文・2026-11-21取得〕**: 杉並区産業振興センター「すぎなみ学倶楽部」の記事「杉並の暗渠散歩」。**掲載日2019年12月16日・情報更新日2022年07月04日**。暗渠研究家**吉村生氏（ブログ「暗渠さんぽ」）・髙山英男氏（ブログ「毎日暗活！暗渠ハンター」）の案内**による荻窪駅北（桃園川本流・天沼）〜南（善福寺川水系・高野ヶ谷戸）の約1時間半の案内記録〔区の二次解説だが現地観察・住人証言を含む。出典・参考文献として『杉並の通称地名』（杉並区教育委員会）・**『杉並の川と橋』（杉並区立郷土博物館）〔repo書誌未収録〕**・『星野家文書－千川用水関係資料－』・**『杉並新聞 第1413号』〔repo未収録〕**・『杉並風土記 上巻』（森泰樹・杉並郷土史会）を明記〕。
- **桃園川の近現代文言〔確認・repo初出候補〕**: 「**1965（昭和40）年前後には暗渠化され、下水道「桃園川幹線」に整備され現在に至る**」＋**『1966（昭和41）年 杉並新聞第1413号』の「桃園川暗渠化工事の様子」の写真を掲載**〔[PAP-065](../papers/PAP-065.md)のS40認定解除→S42暗渠化完了の工程の中間点に相当する昭和41年の民間紙写真の存在記録。すぎなみ学による杉並新聞活用例〕。
- **弁天池周辺・弁天荘〔確認・repo初出〕**: 桃園川の水源の1つ・天沼弁天池（区立天沼弁天池公園）は**現在の人工池ではなく南側広場の位置にあった**「古地図にはほかにもあちこち池があった」〔[GOV-105](../gov/GOV-105.md)矢嶋又次記憶画の池群と対応する文言〕。池の1つ瓢箪池のほとりでは**割烹旅館「弁天荘」が1952（昭和27）年頃まで営業**、**天沼八幡神社の狛犬台座の裏に「株式会社 天沼弁天荘」の刻字が現存**〔弁天池の水利用（料理・旅館）の実態とその事業体の実名。弥生町…でなく天沼の戦後の水辺利用の一次観察記録〕。
- **（仮称）天沼1丁目支流〔確認・repo初出〕**: **桃園川本流の支流**であった横道（天沼2丁目→1丁目）。本流側はレンガ敷き、支流側は**横長コンクリート蓋が連なる蓋暗渠**・コケ・**橋跡**が残る。住宅に阻まれた先は**住宅が水路を避けて建てられている**のが地図で読め、**居合わせた住人から「かつて敷地内を水路が通っていた」証言**を得て、回り込んだ家と家の間に蓋暗渠を確認〔桃園川支流の位置・現況の現地観察記録。「（仮称）」は案内記事の便宜的呼称〕。
- **善福寺川高野ヶ谷戸支流〔確認・repo初出の整理〕**: 青梅街道南側・区立荻窪体育館正面口左に青梅街道方面から来る細い水路＝**区立大田黒公園付近を流れていた3本の水路のうちの1つ**で、**荻窪3・4丁目一帯の天水田圃と呼ばれた水田地帯の灌漑用水路**。辺り一帯の旧地名**田端村字高野ヶ谷戸**の名をとり**善福寺川高野ヶ谷戸支流**と呼ぶ。**『杉並風土記 上巻』に「杉並では谷戸を「がいど」と読んでいたので、高野ヶ谷戸は"こやがいど"と読む」という記述**がある（吉村氏談）〔高野ヶ谷戸の読みの典拠文言。3本の水路（体育館脇=点線2・東側=点線3・西側=点線1）の2016年当時の歩行流路。**1947（昭和22）年米軍撮影の写真（国土地理院）に加筆した「空中写真図」**を図版として使用＝高野ヶ谷戸支流の流路復元の図的根拠〕。
- **天水田圃〔確認・repo初出〕**: 青梅街道南側の荻窪3・4丁目辺りは**昭和30年代の宅地化が進むまで天水田圃と呼ばれる水田地帯**で用水路が何本も張り巡らされていた。**※1 天水田圃（てんすいたんぼ）: 天水とは湧水、雨水など天然の水のみを指す（『杉並の通称地名』より）。この付近には雨水をためた池と湧水池が混在していたといわれる**〔天水田圃の定義文言と出典。桃園川・高野ヶ谷戸系の灌漑構造の基礎資料〕。
- **六ヶ村分水（半兵衛・相澤堀）〔確認・「相澤堀」repo初出文言〕**: 青梅街道沿いに流れていた**六ヶ村分水（別名「半兵衛・相澤堀」）**という灌漑用水。**６カ所あった取水口のうち４カ所は四面道交差点付近**〔[BLOG-162](../blogs/BLOG-162.md)の四面道口（井口昭英の仮称）・観音川復元と対応する位置文言。「半兵衛」単独は既収録、**「相澤堀」の別名表記はrepo初出**〕。「区には暗渠が多く存在する」列挙として**妙正寺川・善福寺川・神田川から引いていた用水路のほか、玉川上水や、廃止された井草川・桃園川・小沢川**と整理〔廃川の列挙文言〕。
- **意義〔観察〕**: ①**（仮称)天沼1丁目支流・弁天荘・天水田圃・高野ヶ谷戸支流の命名・読み・現況**はいずれもrepo初出の観察群で、桃園川上流（天沼）と善福寺川左岸（田端村）の灌漑水路の復元に直接使える、②区民参加型サイトとはいえ**吉村生・髙山英男という専門家の現地案内に基づく区公式サイトの記録**として引用可能性が高い、③『杉並の川と橋』というrepo未収録書誌（[BLOG-249](../blogs/BLOG-249.md)・[BLOG-250](../blogs/BLOG-250.md)で本文引用が確認された郷土博物館刊行物）の内容への最短の入口、④杉並新聞1413号の昭和41年桃園川暗渠化工事写真は[GOV-492](GOV-492.md)のkoho-photo-307（昭和41年「桃園川下水幹線工事」広報課写真）と同時期の民間側写真として対になり得る〔断定はしない〕。
- **制限・未解決**: ①杉並新聞1413号・『杉並の川と橋』・『杉並の通称地名』の現物確認は未実施（孫引きで文言を確認したものとして扱う）。②「空中写真図」は加筆図版であり1947年写真そのものの判読とは別。③弁天荘の営業期間（1952年頃まで＝開始年不明）・屋号の企業情報は未確認。④天沼1丁目支流・高野ヶ谷戸支流の呼称は（仮称）を含み、歴史的正式名ではない。
