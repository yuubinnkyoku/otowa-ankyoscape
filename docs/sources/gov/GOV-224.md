# [GOV-224] 駒込町方書上 [15]壱 — 駒込区間の千川上水（古上水跡）の水元・掛渡・水銭の全経緯

- **書誌〔確認〕**: 御府内備考編纂の基礎資料となる**町方書上**の一本（[15] 駒込町方書上 壱）。NDL次世代デジタルライブラリー [book/2571496](https://lab.ndl.go.jp/dl/book/2571496)。末尾に「丁亥書上」の判があり、文政10年（1827）丁亥の地誌御調書上の写し〔年判はOCR・要照合〕。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **駒込区間の「古上水跡」条＝水元・年表の最詳文言〔確認・repo初出の文言を含む〕**: 駒込追分町と見える町の書上に——「**一 古上水跡 右は町内往還上通 千川上水と唱 武蔵野原保田新田と申所水元二而 浅草田原町三町目小兵衛店忠兵衛 同町壱丁目嘉右衛門店孫兵衛 高砂町三郎兵衛店幸左衛門 右三人之者とも願人二而 明和六丑年二月 御普請方御役所江御訴訟申上 其後安永八亥年十一月廿八日初而 巣鴨広小塚ゟ駒込辺其外町之御見分有之候後 板株渡出来 天明二定年八月中ゟ 水銭小内に付弐拾八人宛差出 牧野大隅守様御番所え上納致 其後天明六午年五月十日半減被仰付 同年八月中迄相調 九月中ゟ御止メニ相成 其後埋立被仰付候 尤千川上水と相唱候儀相分兼申候**」〔**①「古上水跡」が町内往還の上を通っていたこと、②千川上水と唱え、**水元（水源）を「武蔵野原保田新田と申所」と明記**（＝[GOV-212](GOV-212.md)由緒書の「保谷新田ゟ玉川御上水ヲ分け」と同じ分水口を町方側から呼んだ文言・repo初出の「武蔵野原」修飾付き）、③明和6年2月の願人3人（忠兵衛・孫兵衛・**幸左衛門**〔[GOV-217](GOV-217.md)のOCR「幸島」・[GOV-225](GOV-225.md)の「幸右衛門」と字形対立・要照合〕）、④**安永8亥年（1779）11月28日に初めて巣鴨広小路（OCR「広小塚」）から駒込辺ほかの御見分があり、その後板樋（OCR「板株渡」・要照合）の掛渡ができた**、⑤天明2寅年8月中から水銭（小間1間につき28文と読める・要照合）を**牧野大隅守様御番所へ上納**、⑥天明6午年**5月10日**に水銭半減、9月中に出（浅／桟）止め、その後埋立——の年表**〕〔**[GOV-217](GOV-217.md)（肴町・同文言）のOCR「安永一同十一年十一月廿八日」と対立する**安永8亥年**の干支つき読みで、[GOV-225](GOV-225.md)（[16]弐・安永八年）と2巻で一致。安永8年＝1779（亥）・天明2年＝1782（寅）で干支整合。⑤の「牧野大隅守様御番所え上納」＝**水銭の納付先が町奉行牧野大隅守の御番所である旨の初の文言**（神田側の掛渡仰付（安永9年10月27日・[GAZ-041](../gazetteers/GAZ-041.md)等）と同じ牧野大隅守が駒込側の検地・上納も掌った）〕。
- **「委細は馬込追分町に而申上候」〔確認・駒込十ヶ町の代表町構造〕**: 同巻の他町の書上に「**一 古上水跡 委細之義は馬込追分町に而申上候**」（馬込＝駒込のOCR）＝古上水跡の委細申上の代表町が駒込追分町であることを示す文言〔[GOV-225](GOV-225.md)（[16]弐）では浅嘉町が代表（吉町・吉祥寺門前・天台寺門前・石町が「委細は浅嘉町」と記す）＝**駒込十ヶ町の書上が代表町を追分町と浅嘉町の二系統で申告していた**ことの確認。両者の文言は同一事件の並行記録〕。
- **天明7年3月の施米と町内実態〔参考・千川上水と無関係の町方記録〕**: 同書上に天明7未年の飢饉で町内家数約300軒に玄米・白米を施し出した家持（日月町八人兵衛）が老中松平越中守から金200疋を賜った文言あり（千川上水差止（天明6-7）と同時期の駒込の飢饉対応の記録・流路情報なし）。

- **駒込三ッ家町条の「委細は駒込肴町ゟ申上候」と肴町条の文言変種〔文言候補・2026-11-21第225回追記・代表町の第三系統と判読対立の解消材料〕**: ①**駒込三ッ家町条（三ッ家町の書上・文政9戌年12月名主甚左衛門）**「**一 千川上水跡 右委細は駒込肴町ゟ申上候**」＝**「古上水跡／千川上水跡」の委細申上の代表町が「肴町」であると記す委任文言**＝既登録の追分町条（[15]壱）・浅嘉町条（[16]弐・[GOV-225](GOV-225.md)）に加え、**代表町の系統が「追分町」「浅嘉町」に次ぐ第三の「肴町」でも現れる**という観察（三ッ家町条は肴町へ委細を委任。文言は同一事件の並行記録で、代表町の申告が町ごと・冊ごとに分かれる実態の追加witness）、②**肴町条（本冊・[15]壱の肴町条）**「**一千川上水跡 但 明和六丑年二月中 浅草田原町小兵衛店忠兵衛 同町嘉右衛門店孫兵衛 高砂町三郎兵衛店幸右衛門 右三人千川上水掛渡し奉願 安永八〔=代・OCR崩れ候補〕亥年十一月廿八日御検地御改有之 掛渡出来仕 天明二寅年八月中ゟ水銭小間壱間に付廿八文も上納仕 其後同六午年五月中ゟ水銭半減被仰付 同九月中ゟ出銀相止 其後埋立被仰付候**」＝**追分町条（既登録・本資料の最詳文言）と同じ保田新田請願→安永8.11.28→天明2.8水銭→天明6.5半減→9月止→埋立の構造を持つ文言変種**で、**③願人第三の読みが「幸右衛門」**（追分町条「幸左衛門」・[GOV-217](GOV-217.md)「幸島」・[GOV-225](GOV-225.md)「幸右衛門」との判読対立群で浅嘉町条と一致するwitness）、**④安永8.11.28の文言が「御検地御改有之・掛渡出来仕」**と読める＝追分町条「御見分有之候後・板株渡出来」との**表記対立（御見分 vs 御検地御改・板株渡/板樋 vs 掛渡）**、⑤「**水銭小間壱間に付廿八文**」＝「小間1間につき28文」の明示文言（制限①の解読を支持・「上納先＝牧野大隅守様御番所」の文言は肴町条には見えない／追分町条のみ）。〔肴町条文言は文言候補・原画像照合前提。OCR「安永代亥年」の「代」は「八」の崩れ候補（安永8年=亥年で干支整合）〕。
