# [GOV-357] 申出書 [10] — 本郷桜馬場の元大砲吹立地の拝借願

- **書誌〔確認〕**: 『申出書』[10] 慶応3-4（町奉行所への申し出書の綴）。NDL次世代デジタルライブラリー [book/2587759](https://lab.ndl.go.jp/dl/book/2587759)。**引用文言はすべてOCR由来で要原文照合**。
- **元大砲吹立地・本郷桜馬場空地の3ヶ年拝借願〔確認・[GOV-356](GOV-356.md)の跡地再編の後続実務〕**: 「**湯嶋大小炮裂作場跡地ニ而去ル丑年中御鉄砲製造所附町屋ニ被仰付候に付 御作事奉行ゟ地所請取町割積致候処 神田川端往還学問所境二武家組合辻番所有之 新規道式に差除 地代上納方ニも差響候間 右辻番所外場所え引替之義先役共ゟ御目付え及掛合 同方二而外場所江引建直之儀当時調中二付 いまだ上納町屋参会人入札觸も不仕 其儘明地ニ而差置候儀二御座候**」（辰二月・町奉行への申上）＋「**元大砲吹立地本郷桜馬場空地三ヶ年之間拝借仕度**」（松平肥後守家来の願、辰正月）〔**①本郷桜馬場の「元大砲吹立地」＝湯島大小炮裂作場の関連地が、去る丑年（慶応元年＝1865）の御鉄砲製造所附町屋化の際に御作事奉行が地所請取・町割を行ったこと、②その町割が「神田川端往還学問所境」の武家組合辻番所と新規道の予定に差し支え、辻番所の引替・上納町屋の入札・参会人の触も未了で明地のままだったこと、③慶応4辰年（1868）正月に松平肥後守（前京都守護職・要照合）の家来が陣具等の吹立（鋳造）のために3ヶ年季の拝借を願い出たこと**＝**桜馬場の炮製作関連地が幕末維新期に明地化していた実態**（松平肥後守家来の願の本文に「同人領分産物素鉄繰出 大炮始鍋釜都而陣具等吹立申度」＝戊辰戦争期の武器生産の民間拝借の構造）。
- **「神田川端往還学問所境」の文言〔確認・神田川上流の土地構造のdatapoint〕**: 上記の町割文言に含まれる「**神田川端往還**」（学問所〔昌平黌〕の境の神田川沿いの往還）＝湯島〜本郷側の神田川端の往還呼称の慶応期の実務文書での用例（[GOV-356](GOV-356.md)の学問所火除囲込の土地再編区域と連続）。
- **位置づけ〔観察〕**: [GOV-356](GOV-356.md)（慶応元年の炮裂作場跡の町屋化・学問所囲込）の後、跡地の一部（桜馬場空地）の町割が頓挫して明地化し、維新期に大砲吹立のための拝借に回るまでの一連の実務を申出書レベルで追える。鉄砲製造所関連の土地の幕末〜維新の転用の完結性が高い事例。
