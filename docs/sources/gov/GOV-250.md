# [GOV-250] 玉川上水留 [116][117]（慶応3年）— 千川用水の取水実務の一次記録

- **書誌〔確認〕**: 『玉川上水留』第116冊 [book/2587452](https://lab.ndl.go.jp/dl/book/2587452)・第117冊 [book/2587453](https://lab.ndl.go.jp/dl/book/2587453)（慶応3卯年12月・写）。NDL次世代デジタルライブラリーOCRテキストで千川用水関係条を確認。**引用文言はすべてOCR由来で、文言・数値は原文画像との照合を要する。**同冊は武州多摩郡福生村名主十兵衛の玉川上水への「呼井」（取水井）新規願一件とその評価・見分の記録で、千川用水・三田用水の実務情報は上水側の利害評価の文脈で現れる。
- **千川用水組合17ヶ村と保谷新田地先元樋口〔確認・repo初出の一次文言〕**: 第117冊の評価文書——「**千川用水組合拾七ヶ村 右は田用に付年々秋ゟ翌春まて保谷新田地先元樋口にて津田留（＝皆留か・OCR要照合）之場所に候処 村之呑水差支皆留時節差立明（OCR・要照合） 天保二卯年願済以来 水料書面之通上納 本高之四分一…水銀百五拾七匁九分三厘七厘**」＝**①千川用水の組合が17ヶ村であること、②取水が保谷新田地先の「元樋口」で行われていること、③田用のため毎年秋〜翌春は皆留（用水側に止める）の場所であること、④天保2卯年（1831）の願済以来の水料上納であること**の幕府側評価文書での確認。〔水料の数値（本高四分一・水銀157匁9分3厘7厘等）はOCRの語順乱れが大きく、原文照合まで数値の採用は不可。〕
- **千川用水の樋寸法と三田用水との対比〔確認・数値は要照合〕**: 第116冊——「**千川用水夏分三郎新場所（OCR・要照合） 冬春皆留之場所 樋長三間大御内法竪壱人七寸（＝竪壱尺七寸か・OCR）…半坪百五拾六坪四合 三田用水同断極長三間大口内法竪弐人九寸（＝竪弐尺九寸か・OCR）**」＋「**千川三田両用水口田方用水時節計春秋彼岸之間差茎（？）三歩明 其余皆留之場所ニ有之候処…三田口定式三歩明 千川口当節四歩明**」＝**千川用水口の樋（長3間・内法竪1尺7寸か）と開口径（春秋彼岸の間3寸開き・其余皆留、当節4寸開き）の運用実務**。〔樋寸法（長3間・竪1尺7寸）は弘化2年の千川口用水樋（[MAP-175](../maps/MAP-175.md)「長三間 内法壱尺七寸」・OCR）と一致する読みが可能で、1845年と1867年の樋規模の継続性の対校資料。ただし両側ともOCRで、原文照合後の確定が前提。〕
- **三田用水の並行記録〔確認〕**: 同文書に「**右は三田用水前同断 皆留之場所に候処 北沢村地先元樋口ニ而八分通…嘉永五子年頑済（＝願済）年々水銀計上納有之通候事**」＝**三田用水の取水口が北沢村地先の元樋口で嘉永5子年（1852）願済**であることの対比情報（千川用水との制度上の対として記録）。〔嘉永5年願済は[MAP-175](../maps/MAP-175.md)・第116冊の分水願済書抜（「芝高輪松平薩摩守下屋敷江三田用水…嘉永文子年」）とも対応。〕
- **水車と元水減の背景文言〔確認・OCR崩れ大〕**: 「**近年合薬製（？）御用水車掛御水御用多 千川用水三田用水路前々ゟ多分之掛増に相成元水減等之砌は…江戸掛江響候程之儀之間**」「**瀧之川村雁入（？）水車掛水不足之趣 此上千川用水元樋口ニ而掛増之程も難計**」＝**嘉永〜慶応期に御用水車（製薬等）の掛かりで御水御用が増え、千川・三田両用水の掛増が元水減少に響くという上水側の利害論**。〔「瀧之川村雁入水車」の読み（滝野川村の水車か・別の施設か）はOCR崩れが大きく、原文照合まで特定しない。〕
- **保谷新田・上保谷新田の表記〔観察〕**: 見分・先触の文書に「上保谷新田」「保谷新田」の表記が繰り返し現れ（御普請方役人の宿泊予定地としても）、**幕末の玉川上水普請実務で「保谷新田」「上保谷新田」の表記が生で使われている**＝水元表記対立（保谷村／保田新田／保谷新田）の慣用を観察するデータポイント（断定はしない）。

## 制限・未解決

- ①数値群（水銀157匁9分3厘7厘・本高四分一・高18万2千375石余等）はOCRの語順乱れが激しく、原文照合まで引用値としては扱わない。②「津田留」「差茎三歩明」「壱人七寸」等の判読ゆれはすべて要照合。③「天保二卯年願済」の千川用水への帰属（書抜リストの行割付）は、天保2卯年と天保12丑年の両干支が並ぶ箇所のため要照合。④17ヶ村の村名リストは本冊では確認できず（別文書の課題）。
