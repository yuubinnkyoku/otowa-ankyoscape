# [GOV-078] 練馬区「千川家の墓（せんかわけのはか）」

- **書誌〔確認〕**：練馬区公式サイト「練馬の歴史と文化財 > 指定・登録文化財」内の千川家の墓案内頁（ページ番号452-013-675・更新日2010年2月1日）。2026-11-12時点でopen_urlによる直接取得では本文が取れない（JavaScript依存のページでナビゲーション部分のみ返る）ため、[Wayback Machineのスナップショット](https://web.archive.org/web/2024/https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/rekishibunkazai/bunkazai/b050.html)で本文全文を取得・直接確認〔[GOV-077](GOV-077.md)（ねりま区報記事・図版説明で千川家の墓に言及）に対応する、区公式の文化財案内頁の実在確認〕。
- **区登録〔確認：本文〕**：**千川家の墓は平成8年度に練馬区登録文化財として登録**〔①**千川家の墓そのものの登録文化財としての公式記録＝repo初出**。②[GOV-004](GOV-004.md)の千川家文書（昭和63年度区登録）とは別件の登録で、文書と墓所がそれぞれ登録文化財になっていることを確認〕。
- **歴代当主の没年〔確認：本文〕**：阿弥陀堂墓地内には**3代源蔵（明和4年〔1767〕没）・4代善蔵（天保5年〔1834〕没）・5代仙輔（天保8年〔1837〕没）・6代民蔵（天保11年〔1840〕没）・7代右保（明治27年〔1894〕没）などの墓石**が建つ〔**千川家歴代当主の没年の列記＝repo初出**。3代源蔵没年（明和4年）は千川家が下練馬村に移住して間もない時期に対応。4代善蔵〜6代民蔵の没年が3年刻みに近いのは偶然の可能性もあり、墓石の建立年・襲名順との対応は本文に記載がないため断定しない〕。
- **所在地〔確認：本文〕**：**阿弥陀堂墓地内（北町2丁目18番）**。東武東上線東武練馬駅南口下車徒歩5分〔GOV-077の「北町二丁目阿弥陀堂墓地内」を地番レベルで具体化。金乗院阿弥陀堂（[BLOG-118](../blogs/BLOG-118.md)）の所在地情報と一致〕。
- **千川上水の概説〔確認：本文〕**：元禄9年（1696）玉川上水から分水・河村瑞軒（1617〜1699）設計伝承・仙川村出身伝承の徳兵衛・太兵衛の請負・**分水口から巣鴨までの費用1,340両余りのうち幕府支出は860両余り**・私費投じた功により千川の姓と帯刀を許され子孫は代々千川上水の取締役・**3代源蔵の時に下練馬村（現北町2丁目）へ移住**〔[GOV-004](GOV-004.md)（b047）・[GOV-077](GOV-077.md)（ねりま区報）と文面がほぼ一致する区公式の定説叙述〕。

## 制限・未解決

- 墓石の現況・銘文の直接確認は未実施（GOV-077の未解決を継続）。
- 4代善蔵（天保5年没）と、[BLOG-113](../blogs/BLOG-113.md)にいう『東京市史稿』付録の千川上水絵図の「千川善蔵」（所蔵者名）の同名関係。没年から直接の同一人物とは限らず、**同人物可能性は仮説としてのみ記録**し断定しない。
- 頁の現在版（2010年以降の更新の有無）とWayback版の差分は未確認。

## 三河川への使い方

- 千川上水の施主家系の墓所（北町2-18）が、[GOV-061](GOV-061.md)（都公文書館の千川関係絵図）・[MAP-155](../maps/MAP-155.md)（千川家文書）と同じ千川家文書群の実在拠点として位置づけられる。千川上水の板橋区間・巣鴨以東の流路（[GOV-077](GOV-077.md)）の管理史を考える際の系譜の年代骨格（1767〜1894）を提供する。
