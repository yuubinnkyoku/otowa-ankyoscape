# [GOV-036] 豊島区「千川増強幹線事業について」（2024年10月2日）

- **資料〔確認〕**：豊島区都市整備部公園緑地課『千川増強幹線事業について』、**令和6年10月2日**、豊島区議会都市整備委員会資料、**2頁**。豊島区デジタル区史の目録ID **mp15003350**。出典：[原文PDF](https://adeac.jp/viewitem/toshima-history/viewer/viewer/mp15003350/data/mp15003350.pdf)／[豊島区公式目録](https://adeac.jp/toshima-history/catalog/mp15003350)。
- **第二千川幹線との接続〔確認：2024年10月2日時点の区報告〕**：東京都下水道局による**千川増強幹線の新設**と**第二千川幹線―千川増強幹線の地下接続工事**について、資料は「この工事が完了」し、**2024年8月末から取水開始できることになった**と記す。これは区が2024年10月に公表した工事・取水可能化の報告であり、**実際の通水開始日時、運転実績、全区間の供用開始を示す運転記録ではない**。
- **公園復旧〔確認：区報告〕**：工事に伴い利用制限のあった**宮仲公園は2024年7月、上池袋東公園は同年8月**に復旧工事が完了したと記す。資料には両公園の復旧後の写真・案内図が掲載されているが、**写真から地下接続管の位置や深さを読み取らない**。
- **残工事〔確認：2024年当時の予定〕**：**北大塚二丁目付近**での**既設千川幹線―千川増強幹線の接続工事**は、当時**2025年8月まで実施予定**とされていた。**2025年8月は予定終期であり竣工日ではない**。既収録の2025年4月15日付豊島区資料と2026年7月の工期延長報告があるため、2024年の予定を現時点の進捗に置き換えない。
- **比較上の意義〔観察〕**：2024年夏の「第二千川幹線との接続・取水可能化」と、なお残った「既設千川幹線との接続」を**別工区・別段階**として区別できる。2024年8月8日の議員視察にあった「8月末完成予定」を、後日の**区公式資料**で補強する。ただし現代の三幹線を**旧谷端川の自然河道と同一視しない**。
- **未解決**：各接続箇所の正確な座標・深度、取水開始の運転記録、北大塚二丁目接続の実際の竣工日、2025～2027年の変更工程。
