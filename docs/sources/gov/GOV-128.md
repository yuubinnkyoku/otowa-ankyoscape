# [GOV-128] 豊島区「ひと×街ひすとりぃ 第2回 小池陸子さん」インタビュー

- **書誌〔確認: 全文テキスト取得〕**: 豊島区デジタル区史「としまひすとりぃ」オーラルヒストリー。**2020（令和2）年3月4日13時～15時、「雑司が谷案内処」2階展示ギャラリーで収録**、**同年11月17日公開**。聞き手は吉田いち子氏・根岸豊氏。ADEAC目録ID **mp00500020**、全文テキスト（[ht430020](https://adeac.jp/toshima-history/text-list/d000000/ht430020)、約3.5万字）、[ADEAC目録ページ](https://adeac.jp/toshima-history/catalog/mp00500020)。**クリエイティブ・コモンズ表示4.0国際（CC BY 4.0）**ライセンスで公開されている〔確認: 目録ページのライセンス表示〕。小池氏は昭和42（1967）年から雑司が谷在住で、豊島区立郷土資料館の資料所在調査・郷土資料館友の会の活動に第1回から携わった当事者〔確認: 本文〕。
- **谷端川橋名連載の執筆体制〔確認: 本文の直接引用〕**: 「谷端川のことでは、すごく興味を持ってる方が、会報に写真を撮って載せてくださったり、**橋の名前の記事を3つぐらいずつ書いたりしてくださった**んですよ。（中略）**前半は清水さんで、後半が田崎さん。前半が終わった時に田崎さんが「もしよかったら、会報に書きたいんですけど」っておっしゃって、それで最後まで田崎さんが書いてくださった**んですね。それから**三田さんが橋の写真を全部撮った**んですよ」〔根岸氏の補足から田崎さん＝**田崎不二夫**、**「巣鴨のむかしを語り合う会」**のメンバーで同会で何度も冊子を出した地主の方とも確認〕。
- **〔観察: 既収録書誌との整合〕**: この証言は、2000年1月21日付区広報資料が示す**清水治男「谷端川橋名私考」（友の会だより第21～35号・1989年8月～1992年9月）→田崎不二夫「続（々）谷端川橋名私考」（第39～52号・1993年6月～1996年11月）**という連載系列〔[GOV-007](GOV-007.md)〕を当事者証言の側から裏付ける。とくに「**前半が終わった時に田崎さんが申し出た**」という経緯は、**第35号（1992年9月）と第39号（1993年6月）の間に号数の空白があること**（36～38号相当）と整合し、執筆交代が連載中断を挟んで行われたことを示唆する〔号数・発行月の照合は[GOV-007](GOV-007.md)の広報記述に依拠。36～38号の実在・橋名記事の有無は未確認〕。「3つぐらいずつ」は各回3橋程度ずつの執筆単位を示す表現として記録する〔1回の掲載橋数の確定値ではない〕。
- **矢島勝昭の関与〔確認: 本文の直接引用〕**: 「矢島さんも郷土資料館に入ってくださって。矢島さんは先生ではあるんですけれど、**「友の会」の会員**なんです。**谷端川の（調査）を一緒にしました**」。一方で「**矢島さんは、谷端川のお仕事にはあまり興味がなかった**んですよね」とも回想し、聞き手との応答で矢島氏の関心が**鎌倉街道**にあったことが確認される〔『昭和 思い出の日々』（画文集）を矢島氏が手がけたことの言及もある〕。**谷端川橋名連載の執筆者ではなく、矢島氏は調査参加・友の会会員としての位置にあった**という執筆体制の一次情報として記録する〔2000年講演「弦巻川の昔を語る」の矢島勝昭氏と同一人物と目されるが、本インタビューの「矢島さん」を鎌倉街道研究者の矢島勝昭と断定する文言は本資料になく、同一視は高確度の推定として扱う〕。
- **友の会結成の経緯〔確認: 本文〕**: 郷土資料館が高田・雑司が谷、巣鴨・駒込など**5地区に分けて毎年1回ずつ5年間続けた資料所在調査**（家庭を訪問して史料を聞き取る調査）の第1回目に、「このまま別れてしまうのはもったいないね」という流れで**友の会を結成**。当時はパソコンを打てる人が少なく**郷土資料館の学芸員が会報を打ち、会報はわら半紙に印刷**して作られた〔1980年代の友の会初期の運営実態の一次証言。BOOK-062の母体となった会報の物理的な制作条件を示す〕。
- **留意〔注意〕**: いずれも**当事者・同席者による約50年前の回想**であり、人名の表記（三田さんの氏名全体など）・号数・日付の細部は証言単独では確定しない。本インタビューの主要な谷端川橋名記事の内容（前半清水・後半田崎・三田さん写真）はREADMEの当該bulletに既に反映済みで、本ファイルはその出典の資料ファイル化と、矢島勝昭の関与・田崎不二夫の途中入会の経緯・友の会結成経緯の追加記録を目的とする。

## 制限・未解決
