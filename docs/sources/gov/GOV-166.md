# [GOV-166] 東京市 下水道事業年報 第15回・第16回（1937年・郡部下水道の排水区）

- **書誌〔確認〕**: 東京市『下水道事業年報』第15回（NDL次世代デジタルライブラリー [book/1114654](https://lab.ndl.go.jp/dl/book/1114654)）・第16回（[book/1114646](https://lab.ndl.go.jp/dl/book/1114646)）。[市政年報 昭和12年度（水道篇・book/1278329）](https://lab.ndl.go.jp/dl/book/1278329)（1939）にも同種記述。**引用はOCR由来・要原文照合。**
- **巣鴨町〔確認・要照合〕**: 汚水は**谷田川・谷端川及悪水路に排出**（[GOV-162](GOV-162.md)の1930年計画と同構造）。谷端川排水区の区域は大字上駒込・駒込妙義坂下・巣鴨三丁目の全部ほか〔地名はOCR判読〕。
- **高田町〔確認・要照合〕**: 大部分は東京市下水道に合流、一部は神田上水路及悪水路に排出。**鶴巻川排水区**（大字高田老松・小石川の全部ほか）・**神田上水路排水区**（大字高田豊川の全部ほか）。〔弦巻川・水窪川の名は現れないが、鶴巻川排水区は弦巻川水系の沼脇低地（[GOV-123](GOV-123.md)・[BLOG-233](../blogs/BLOG-233.md)文脈）に重なる候補。水系名の対応は断定しない〕
- **滝野川町〔確認・repo初出〕**: **石神井川・谷端川・音羽・谷田川の4排水区**。「**其ノ大部ハ谷端川及悪水路ニ排出シ**一部ハ東京市、巣鴨町及高田町下水道ニ合流」〔OCR・要照合〕。谷端川の北岸（西ヶ谷・田端方面）の下水を含むとみられるが、区域図は未確認。
- **位置づけ〔観察〕**: 1930年代半ばの郡部（1932年編入後は区部周縁）下水道計画が、改修中の谷端川を受容先の柱に据え続けた記録。滝野川町の「4排水区」表記は、谷端川（＝千川下流）が石神井川・音羽（神田川）・谷田川と並ぶ独立排水先として扱われたことの公式文書例。

## 制限・未解決

- ①OCR由来の区域名・文言は要照合。②各排水区の区域図は未確認。③鶴巻川と弦巻川の水系対応は本項では確定しない。④「悪水路」の流路位置は特定されない。
