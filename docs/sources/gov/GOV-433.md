# [GOV-433] 天明撰要類集 十八上ノ三 — 蓮光寺の関口村引寺・代地一件（元禄11年〜安永9年）

- **書誌〔確認〕**: 『天明撰要類集』全十八上ノ三（護国寺領音羽町の年貢・寺地関係の行政事例綴・上水直接の文言は本冊には無いが、[GAZ-054](../gazetteers/GAZ-054.md)（沿革図書・嘉永7年）の蓮光寺境内文言の一次側記録として見逃せない内容を含む）。NDL次世代デジタルライブラリー [book/2572896](https://lab.ndl.go.jp/dl/book/2572896)。**引用文言はすべてOCR由来で要原文照合**（本冊は崩れが特に大きい・「蓮光寺」が「運光寺」と崩れた行もある）。
- **蓮光寺の関口村引寺の記録〔確認・repo初出の一次文言群〕**: 「**安永九子年四月元禄十一年護国寺前新町屋ニ相成候節同所蓮光寺を武州関口村え引移被仰付候儀ニ付申上候書付**」＋「**元禄十一午(寅?)年護国寺前新町屋ニ相成候節同所蓮光寺ヲ武州関口村え引移被仰付候節之儀…護国寺領名主え相尋候処右蓮光寺其砌は当時護国寺領音羽町九町目之辺二有之候由之処…其節関口え引寺仕候様申伝及承申候得共年久敷儀ニ而書留等も無御座**」＋御勘定所（飯塚伊兵衛）による相糺「**武州豊嶋郡関口町地内二而蓮光寺え代地ニ被下候節様子相糺可申旨被仰渡…手代差遣為相糺候処蓮光寺儀元関口町地門当時護国寺領音羽町に罷在寺屋敷千坪御座候由 然処元禄十丑(丁?)年御用地に上り右為代地関口町地内音羽町六町目上ニ而元坪千坪ニ五百坪之増坪被下則拝領地千五百坪之内引移罷在候 尤増坪五百坪は御年貢地**」＋関口町名主孫太郎の申上「**右蓮光寺元屋敷は如何にし訳にて新町屋に相成候成之段御尋ニ御座候此儀は年久敷儀二而相知不申候**」＝**①元禄11年（1698・護国寺前新町屋＝[GAZ-016](../gazetteers/GAZ-016.md)の元禄10年8月町屋仰付けの翌年）に蓮光寺が（当時の音羽町九丁目辺の寺地＝千坪から）武州関口村（関口町）へ引寺され、②元地が「御用地に上り」（＝護国寺建立・新町屋立て分けに充てられ）、③代地として関口町地内（音羽町六丁目上側の位置表現）に元坪千坪＋増坪五百坪＝千五百坪が与えられ、増坪五百坪は御年貢地（＝年貢納付地・拝領地とは区別）として扱われた、④安永9年（1780）にこの年代久しい経緯が再相糺された（町奉行曲渕甲斐守の御尋・御勘定所・関口町名主・護国寺領名主の答書）**という一連の書付・申上・覚。
- **意味〔確認・対校〕**: [GAZ-054](../gazetteers/GAZ-054.md)の嘉永7年の書上は「**蓮光寺境内元目白坂下に有之候処元禄十丑年中護国寺御建立之節御用に付被召上候事 同十一寅年中当所に而代地被下**」＝蓮光寺の移転前の位置（元目白坂下）・元禄10年召上げ→同11年代地を登録していたが、「移転後の蓮光寺の位置（現在の小日向側か）の比定は本書のみでは行わない」と留保していた。本冊の文言は**①代地の所在を「関口町地内・音羽町六丁目上」の位置表現で記し、②引寺の先が「武州関口村」＝関口町（音羽谷ではなく関口側）、③元地が音羽町九丁目辺＝現在の音羽町の護国寺寄りの区域、④増坪の年貢地扱い・安永9年の再相糺の実務**を加える＝**蓮光寺の移転の位置比定に向けた一次側の年代・坪数・地名データ**（最終比定は原画像照合と現地比定まで留保）。音羽谷（水窪川下流の谷）の開発史（護国寺建立＝元禄10〜11年境界）の寺地レベルの再編の行政実例として[GAZ-016](../gazetteers/GAZ-016.md)（市街篇12の町屋仰付け）・[GAZ-012](../gazetteers/GAZ-012.md)（関口村の「東手關口村百姓地護国寺領ニ成」）・[GAZ-104](../gazetteers/GAZ-104.md)（善仁寺の代知・細井九左衛門御代官）と対校列を組む。

## 制限・未解決

- ①本冊OCRの崩れは非常に大きい（「蓮光寺／運光寺」「元禄十一午年／寅年」「元禄十丑年／丁丑年」等）＝年次干支・坪数・位置表現の原字形照合が必須。②安永9年の再相糺のきっかけ（何の件での御尋か・目次の周辺項目との関係）は本冊からは確定できず、次回の原画像確認課題。③「音羽町六丁目上」の空間解釈（音羽町六丁目の上側＝高台側か、関口町地内の音羽町寄りの区域か）は確定しない。④現在の蓮光寺（文京区小日向の蓮光寺）との同一性・比定は行わない。
