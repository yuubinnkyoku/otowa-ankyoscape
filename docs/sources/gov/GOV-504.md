# [GOV-504] 小金井市文化財センター通信 №2「小金井の湧水点 part 2・旧仙川２つの水源地」（2021-11-01発行）〔repo初出・旧仙川（悪水堀→武蔵川→仙川）の呼称変遷と水源地2箇所の小字・明治8年『貫井村全図 坂上』の橋の記入〕

- **書誌〔確認: 公式PDF取得・2026-11-22〕**: **小金井市文化財センター通信 №2「小金井の湧水点 part 2 ☆⑤ 旧仙川 ２つの水源地」**（**文／構成　多田 哲（学芸員）**・**令和3年11月1日発行**〔発行日はPDF末尾クレジットで直接確認〕・8頁）。[PDF](https://www.city.koganei.lg.jp/kankobunka/bunkazai/oshirase/bunkazaimagazine.files/bunkazaimagazine002.pdf)・[シリーズ一覧](https://www.city.koganei.lg.jp/kankobunka/bunkazai/oshirase/bunkazaimagazine.html)。自作抽出器で全文テキスト化（約2万字）。[GOV-502](GOV-502.md)（part1・貫井側湧水点群）に続き、本号は**仙川（旧仙川）の水源地と流路改変**を主題とする〔part1が「文／構成・発行日クレジット判定不能」だったのに対し本号以降はクレジット・発行日が確認できた〕。
- **仙川の呼称変遷〔確認: 本文直接引用〕**: 「**仙川は近世から「悪水」もしくは「悪水堀」と呼ぶのが一般的でしたが、戦後の小金井町報には「武蔵川」の名で記事が載っており、高度成長期を経てようやく仙川という名称が定着しています**」＝**悪水／悪水堀（近世）→武蔵川（戦後小金井町報）→仙川（高度成長期以降定着）という呼称変遷の整理**〔仙川＝多摩川水系で野川の支流。「仙川」呼称が新しいことは[GOV-505](GOV-505.md)（part3・「悪水」の意味論）と対で読むべき文言〕。
- **旧仙川の水源地2箇所と『貫井村誌』文言〔確認: 本文直接引用〕**: ①**東京サレジオ学園方面の水源地**（小平市上水南町4-7-1の東・小金井市域内の小字「**小長久保**」）＋②**貫井北四号水源**（東京都水道局管理・貫井北町3-23-13自転車保管所南側・小字「**枝久保**」・現在は孤立した井戸水源）＝**2水源地はいずれも貫井村（近世）の小字で、文献史料は『貫井村誌』（明治13年8月12日皇国地誌編纂のため政府に提出・**鈴木英男家文書98**）の「**悪水渠**」項にしかない**: 「**字小長久保ノ山林中ニ起リ**」「**字枝久保ノ山林中ニ起リ**」と2箇所が記録され、いずれも「**平時ハ水ナシ**」（普段は水が涸れている）とする〔**「久保」を含む小字＝旧仙川が形作った「窪」であるとする解釈は通信筆者の観察**〕。『小金井市誌Ⅴ 地名編』（昭和53年刊）は東京サレジオ学園方面の水源地を「東京サレジオ学園北方の"**お釜**"」と呼ぶ＝**湧水点の古語「かま」（[GOV-506](GOV-506.md) part4「かま坂」と同系）の文言**、貫井北四号水源については「**北方台地の崖面から夏場だけ湧出した泉**」と記す。
- **流路の復元〔確認・推定の区別は本文自明〕**: 2水源地から流れ出した流路は**本町住宅の給水塔があった付近で合流**（旧仙川の二又状態は昭和36年完成の本町住宅造成以前まで不変）、合流点で一本化した旧仙川は**山王窪の築樋（つきどい）で小金井分水の下を潜っていた**＝**仙川（自然河川）と玉川上水系小金井分水（人工水路）の立体交差（築樋＝伏せ越し）の位置の文言**。江戸期に玉川上水と小金井分水の分水網が敷設されると自然河川の仙川は「悪水あるいは悪水掘の名のもとに排水路」になった（本文）。仙川流域の遺跡は小金井市№22遺跡（山王稲穂神社周辺）のみの指定で、他流域にも包蔵地の可能性があるとする〔**包蔵地可能性は筆者の指摘=推定**〕。
- **『貫井村全図 坂上』の橋と貫井天王橋〔推定: 筆者推定として本文明示〕**: 明治8年測図『貫井村全図 坂上』（小金井市文化財センター所蔵・[GOV-502](GOV-502.md)の『貫井村全図 坂下』と対になる貫井村側の地図）で、貫井北四号水源から流れ出て合流点に向かい東流する水路を、幅2間の「**小金井村境界通**」（赤道）が渡る地点に**橋が記入**されている（本町住宅7-2号棟付近・現在は水路も道路もなし）。橋の南側の土地（885番）は**八雲神社**（現在の公務員住宅4・5号棟付近・祭神須佐之男命・神仏分離以前は牛頭天王で明治末期に貫井神社へ合祀。「小金井市域では唯一、牛頭天王を祀る祇園信仰が旧貫井村にあった」）＝**旧仙川と村社・祇園信仰の位置関係の地図記録**。さらに『東京府北多摩郡小金井村明治44年度歳入出予算表』（**島田良一家文書1013**）に「**貫井天王橋**」の橋名のみが記録され、**筆者（多田哲）は「八雲神社付近の橋と見て間違いないでしょ」と貫井天王橋＝明治8年図の橋と推定**〔具体的な地番は予算表に書かれておらず、**推定として記録**〕。
- **陸軍技術研究所による道路・水路改変〔確認: 本文・国土地理院空中写真の判読〕**: 昭和15年・17年の2度の強制買収で陸軍技術研究所（技研）が小金井と小平にまたがる地域に移転。**①技研用地内の道路（碁盤目状の直線道路・現在の市道第381号線他）は江戸期に遡る旧道を破壊分断**、**②町道第19号線（『貫井村全図 坂上』の「小金井村境界通」）と町道第20号線の分断・廃絶**、**③小金井分水の流路までも一中の西側の逆L字型水路として改変**＝**「水路も戦争遺跡」とする指摘**。**今年（取材時）発掘された上貫橋**は**昭和12年5月、技研改変以前の小金井分水を町道第19号線が渡る地点に架けられた橋**で、数年後には技研が小金井分水の流路を逆L字型に改変したため利用期間は短い（本文）。**武蔵農場**（シッカロールで有名な和光堂初代社長**大賀彊二**〔1875～1942〕設立の牛乳生産直売農場・昭和17年の2度目の用地買収の際に土地建物をすべて国に寄付）の存在も図版解説で確認。
- **戦後の流路改修〔確認: 本文〕**: 山王窪の築樋以西の流路は**本町住宅（昭和36年完成）造成に先立ち改修され、二又に分かれていた流路はこの時はじめて一本化**。貫井北四号水源の流路は埋め立てられ、東京サレジオ学園方面の流路は山王稲穂神社の台地を避けて急激に北上していたのを、より緩やかに山王窪の築樋まで東流する水路に付け替え〔＝**山王窪の築樋以西は「流路自体の抜本的な付け替え」を行っている類例のない区間で、安易に現代の仙川から古代の流路を類推してはならないとする注意**〕。また昭和19年陸軍撮影・昭和22年米軍撮影の空中写真では流路が小金井を超えて小平にまで延伸しているように見え、「**水源地が峡谷状の窪地を西へ移動しているように見える**」＝**技研造成前後で水源地の位置（小金井か小平か）すら曖昧になったとする筆者の観察**〔星野正行氏（学芸大北側の北大通り＝サレジオ通りを皮切りに技研の道路造成が始まったとする証言も記録〕。
- **意義〔観察〕**: ①**仙川の呼称変遷（悪水堀→武蔵川→仙川）と[BOOK-235](../books/BOOK-235.md)の「大堀／堀」体系・千川上水→千川用水の呼称遷移系と並ぶ、多摩地域の水路呼称の歴史的層の新規文言**。②**『貫井村誌』明治13年「悪水渠」項の「小長久保・枝久保」の2箇所水源地文言**＝仙川源流研究の一次文言で、[GOV-505](GOV-505.md)（part3・「悪水」は用途名という根岸茂夫への取材）と対になる源流側の記録。③**山王窪の築樋＝仙川が小金井分水を潜る伏せ越し**の位置、**貫井天王橋**（明治44予算表）の橋名はrepoの桥名史（温井橋・貫井橋系）に隣接する新座標。④**上貫橋（昭和12年5月）・技研による小金井分水の逆L字改変**は、玉川上水系水路の昭和期改変史の具体例として[GOV-502](GOV-502.md)の嘉永4年水車系譜（江戸期）と時代を接続する。
