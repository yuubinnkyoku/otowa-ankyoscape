# [GOV-228] 東京府史談（1894）— 三上水総説の中の千川上水の数値

- **書誌〔確認〕**: 『**東京府史談**』（明治27年・1894年）。東京府の通俗史談集（第三十六章「上水」ほか道灌山等の章を含む）。NDL次世代デジタルライブラリー [book/764175](https://lab.ndl.go.jp/dl/book/764175)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **三上水総説〔確認〕**: 第三十六章「上水」——「**東京市に於て、飲料に供する上水は、多摩、神田、千川の三流あり**」で始まり、多摩川上水（承応元年4月創設・羽村取入れ・延長十里三十一町余・四谷大木戸から樋に入り・萬年樋長千九百九十九間・無葢溝二百八間・樋管四萬八千七百二間で七区人口約17.6万に給水・吐捨水を深川・本所で飲用）、神田上水（寛永年間徳川家光の創設・井の頭池・善福寺池・妙正寺池の湧水＋玉川上水の助水・関口の大洗堰まで水路五里二十六町余・無葢溝七百五十三間余・萬年樋二千八十間余・樋管三萬七千二百五十七間余で小石川・神田・日本橋の三区人口約22万に給水）を経て千川条に至る〔三上水の規模・給水人口・吐捨水の再利用まで含む1894年時点の総説〕〔各数値はOCR・要照合〕。
- **千川上水条の数値〔確認・repo初出の「五里六町余・一万七千余」〕**: 「**千川上水は、元祿年間の創設にして、埼玉縣新座郡保谷村より、多摩川上水を分派し、巢鴨町溜池に至る、水路長五里六町餘、夫れより溝渠に引き入れ、無葢溝長百七十二間、樋管長三千七百七間を以て、本〓區、下谷區の一部人口凡そ一萬七千餘に給水せり**」〔**①元禄年間創設・埼玉県新座郡保谷村より分派・巣鴨町溜池に至る、②水路長五里六町余、③**無葢溝172間・樋管3,707間**、④本郷区・下谷区の一部の**人口凡そ17,000余に給水**——の数値**〕〔**[GOV-172](GOV-172.md)（東京府史引）・[GOV-173](GOV-173.md)（1891）・[GOV-226](GOV-226.md)（1893・170間/3,700間余）と対照すると、無葢溝170間vs172間・樋管3,700間余vs3,707間の差は同じ対象の丸め・筆写差の範囲。「五里六町余」は府史系統、「五里余」（水道要覧）と近似。**給水人口約1.7万は本条が初出の独立数値**（給水区域を本郷・下谷の一部とする点は安永9年再興時の「本郷湯島下谷淺草等」〔[GOV-226](GOV-226.md)〕に比べ狭い＝明治13年千川水道会社以降の実際の給水範囲を反映した可能性があるが断定しない）〕〕〔多摩川上水＝玉川上水の呼称に注意〕。
