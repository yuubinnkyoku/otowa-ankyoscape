# [GOV-225] 駒込町方書上 [16]弐 — 浅嘉町書上の千川上水跡条と駒込十ヶ町の代表申告

- **書誌〔確認〕**: 町方書上の一本（[16] 駒込町方書上 弐）。NDL次世代デジタルライブラリー [book/2571497](https://lab.ndl.go.jp/dl/book/2571497)。文政10年丁亥の地誌御調書上の写し〔年判は要照合〕。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **浅嘉町の「千川上水跡」条〔確認・[GOV-217](GOV-217.md)・[GOV-224](GOV-224.md)との対校用の第三の並行文言〕**: 青物市（当町と高林寺門前・天栄寺門前の三ヶ町の毎朝の千菜市）などで知られる駒込浅嘉町の書上に——「**一 千川上水跡 町内往還中程相通り申候 且明和六丑年二月中 浅草田原町小兵衛店忠兵衛 同町嘉右衛門店孫兵衛 高砂町三郎兵衛店幸右衛門 右三人千川上水掛渡奉願 安永八年十一月廿八日御検地御改有之 掛渡出来仕 天明二寅年八月中ゟ水銭小間壱間二付弐拾八文ツヽ上納仕 其後同六午年五月中ゟ水銭半減に被仰付 同九月中ゟ出桟相止 其後埋立被仰付候**」〔**①千川上水跡が浅嘉町の町内往還の中程を通っていたこと（＝駒込区間の流路の通過町の特定）、②明和6年2月の願人3人（忠兵衛・孫兵衛・幸右衛門）、③「**安永八年**十一月廿八日御検地・御改→掛渡出来」（干支なしの「安永八年」で[GOV-224](GOV-224.md)の「安永八亥年」と一致）、④「**天明二寅年**八月中から水銭（小間1間につき28文）」、⑤天明6午年5月中に水銭半減、⑥9月中に「**出桟**相止」→埋立の年表**〕〔**[GOV-217](GOV-217.md)のOCR「安永一同十一年十一月廿八日」「天明一寅年八月中」に対し、本書上と[GOV-224](GOV-224.md)は「安永八年（亥）」「天明二寅年」で一致＝安永8年（1779）11月28日御検地・天明2年（1782）8月水銭開始が2巻の独立したOCR読みで支持される（原画像照合まで断定しないが、干支整合は安永8説が優る）。人名も「幸島」（GOV-217）vs「幸右衛門」（本書）vs「幸左衛門」（GOV-224）の字形対立を記録**〕〔「出桟相止」の「桟」も[GOV-217](GOV-217.md)「出浅相止」・[GOV-215](GOV-215.md)「出浅取立」との字形対立（出浅＝通水開始か・出桟＝樋桟の取出しか・いずれも要照合）〕。
- **駒込十ヶ町側の「委細は浅嘉町」文言〔確認・千川上水跡を自町に持つ町の列挙〕**: 同巻の吉町・吉祥寺門前・天台寺門前・石町の各書上が「**千川上水跡 但 委細之義は駒込浅嘉町に而申上候**」等と記す〔**①千川上水跡が吉町・吉祥寺門前・天台寺門前・石町・浅嘉町（・[GOV-224](GOV-224.md)側の追分町ほか）の各町に跨って存在したこと、②浅嘉町がこの巻の代表申告町であること**＝駒込区間の通過町の一覧の一次記録（流路の字レベルの復元には絵図・地籍図との照合が残る）〕。

## 制限・未解決

- ①「出桟」「幸右衛門」等の原字形・「水銭小間壱間二付弐拾八文」の正確な区切りは原文照合を要する。②各町の「千川上水跡」の正確な通過位置（往還の東寄り・西寄り等）は本資料からは不明で、1912年地籍図との照合が課題。③浅嘉町条と追分町条（[GOV-224](GOV-224.md)）の文言差（水元記述の有無・「御検地御改」の語差）は書上が同じ事件を写した際の変異か、申告町ごとの認識差かは未確定。
