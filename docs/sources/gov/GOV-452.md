# [GOV-452] 豊多摩郡澁谷町現状調査 — 渋谷川の貫流と両岸丘岡の地勢規定

- **書誌〔確認〕**: 『豊多摩郡澁谷町現状調査』（東京市臨時市域**擴張部**編・[book/1900478](https://lab.ndl.go.jp/dl/book/1900478)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**澁谷町（1932年渋谷区）冊**＝渋谷川（＝宇田川・宮下川系の下流、弦巻川・水窪川の合流先）流域の中心冊。
- **地勢章の渋谷川貫流文言〔文言候補・本ファイルの核心〕**: 「**地（勢?）…全町概ネ髙燥ナル臺地ヲナス。渋谷川、町ノ中央ヲ貫流シソノ沿岸狹長ノ低地ヲ族（漬?）ミテ丘岡相對峙ス。東北方ノ高阜ハ手（千?）駄ヶ谷町ヨリ来レルモノニシテ麻布区ニ入リテ白金台トナリ延長シテ芝区ニ至リ髙輪、三田ノ臺地ヲナス。西南部ノ丘陵ハ代々幡町ヨリ逼リ耒リ曰黑町ヲ境シツヽ大崎町ニ至リテ終ル**」＝**①1931年時点の行政調査で渋谷川が澁谷町の中央を貫流し、沿岸に狹長な低地をなして両岸の丘岡が相対峙すると規定、②東北岸の高阜＝千駄ヶ谷由来→白金台→高輪・三田の台地、③西南岸の丘陵＝代々幡由来→自黒（?）→大崎に至る**〔**渋谷川の谷の両岸の台地連続性（東北側＝千駄ヶ谷〜白金〜高輪台地系／西南側＝代々幡〜自黒〜大崎系）を行政調査レベルで記した地勢文言＝渋谷川低地（宇田川・弦巻川・水窪川の合流点流域）の1931年の地形規定の一次記録候補（repo初出の地理範囲文言）**。「族ミテ」の原字（「漬ミテ」等の崩れ候補）・「曰黑町」（自黒町の崩れ候補）は要原画像照合〕。
- **町勢図の「宇田川」〔文言候補〕**: 表紙裏の町勢図（縮図）の地名群に「**宇田川**」の文字（「青宇田川宮竹美松涛下）…（街路と地図ラベル群）」＝**澁谷町の1931年時点の地名として「宇田川」（後の宇田川町・現在の宇田川町交差点〜センター街方面）が町勢図に登載されていることの文言**〔河川名の「宇田川」（渋谷川上流の古名）ではなく地名（町名）の登載と判読できるが、地名の「宇田川」が河川名由来である系譜（[対照表](../../ 地名・河川名対照表.md)の宇田川行）の1931年の定点として記録（原画像照合前提）〕。
- **沿革・帳簿文言〔確認・OCR崩壊大〕**: 「**〓谷ノ名ハ鎌倉時代ノ文献ニ〓見スルモ其ノ眞偽ハ〓トシテ德川家康入園（府?）ノ時御料地ニ編入卄レタリ**」＝渋谷地名の鎌倉時代文献説（真偽不明と付記）・家康入府時の御料地編入の沿革文言、面積「**一、八三三、五八〇坪**」・「**東京市（芝区?）ト略々同シ**」・明治2年「西川縣」（品川縣のOCR崩れ候補）の沿革等の帳簿＝1932年市域拡張直前の澁谷町政の帳簿。「西川縣」の原字は要照合。
