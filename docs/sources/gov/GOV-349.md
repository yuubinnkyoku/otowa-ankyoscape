# [GOV-349] 御成3（安永2年以降の御成御触書覚）— 雑司ヶ谷筋御成の道筋と橋の実利用

- **書誌〔確認〕**: 『御成』3（写・NDL次世代デジタルライブラリー [book/2548304](https://lab.ndl.go.jp/dl/book/2548304)）。巻頭に「十四ノ百四 第六棚 **安永二己年ゟ一吉八亥年至御成一件**」＝**安永2年（1773・癸巳）以降の御成（将軍家・大納言様の外出）の道筋の御触書・覚書集**（「安永二己年ゟ一吉八亥年至」の末尾の年次はOCR崩れで、収録期間の下限は要原画像照合。本文に「同安永三午年御成御触書」の文言あり＝安永3年〔1774〕の記録を含む）。**大納言様**の王子筋・雑司ヶ谷筋・駒場野・広尾筋等への御成の道筋（「町年寄三人覚」「御供揃ニ而」等の覚書形式）を収める。〔第118回は本冊を「道筋記録のみ・河川情報なし」として見送りとしたが、今回のOCR全文取得で**橋の御渡（実利用）・水車への御立寄の文言が確認されたため格上げ登録**する。「大納言様」の比定（将軍世子等）は本冊からは確定できず断定しない。〕
- **音羽町九丁目橋御渡〔確認・文言候補・橋の実利用記録〕**: 雑司ヶ谷筋御成の帰路の定型として「…**雑司ヶ谷居村通護国寺裏門ゟ表門口御通抜 音羽町九町目橋御渡 水道町 江戸川端左江 御堀端 小石川御門左江土手通 小川町…雉子橋御渡 右江清水御門 矢来御門**」の文言が**10数回**（十月・九月・二月・三月・八月等の各御成）繰り返される＝**安永2年（1773）以降、雑司ヶ谷筋（鬼子母神・法明寺・護国寺）御成の帰路は護国寺表門から音羽町九丁目橋を渡り水道町を経て江戸川端に出るルートが定番であった**ことの御触書レベルの記録候補。〔**音羽九丁目橋（[BOOK-158](../books/BOOK-158.md)の丁目体系〔護国寺門前が一丁目で神田上水に架かる橋が九丁目橋〕・[GOV-238](GOV-238.md)の宝暦10年以前の定請負橋・[BOOK-129](../books/BOOK-129.md)の宝暦10年修理）の1770年代の実利用・公儀の行列経路への採用の記録**＝橋名の「九町目」表記（丁/町のOCR対立・要照合）も含め橋名調査に追記。護国寺→水道町間の川（神田川＝江戸川）の渡河点として音羽九丁目橋が機能した構図は、[BOOK-158]の九丁目橋＝「目白のした神田上水へ懸りたるはし」の文言と整合する。〕
- **関口町水車への御立寄〔確認・文言候補・repo初出候補〕**: 王子筋等の往路の条に「**天神町 中里町 関口町水車え御立寄 夫 耕地土手通 下戸塚村通り 高田馬場え被為成**（乗馬上覧…）」の文言＝**御成の道筋が関口町の水車に立ち寄り、耕地土手を経て下戸塚村から高田馬場へ出る**記録候補（2月・3月の御成に2回）。〔**関口の水車（[GAZ-048](../gazetteers/GAZ-048.md)の関口の大滝・水車群・BOOK-151の関口堰の水車等の記録群）が将軍家の御成の立寄対象になった実利用記録の候補＝repo初出候補**。「関口町水車」がどの水車（大滝の源兵衛水車等）かは本冊からは特定できず断定しない（牛込門→神楽坂→天神町→中里町→関口町→下戸塚村の順路は目白台地の北縁を東から西に越えるルートとして地理的に整合）。〕
- **面影橋御渡〔確認・文言候補〕**: 雑司ヶ谷筋の別ルートの条に「**高田馬場…雑司ヶ谷道通面影橋御渡 四ッ谷町通 鬼子母神境内通…**」の文言（「面新橋」「向影橋」「西新橋」のOCR変種で現れる＝同一橋の崩れ候補）＝**高田馬場から雑司ヶ谷道に入り面影橋を渡る**往路の記録候補。〔**[GAZ-030](../gazetteers/GAZ-030.md)（江戸名勝志・安見橋＝「面影橋とも云」・高田馬場二町余・上水川に懸る）の面影橋の18世紀の実利用記録候補**。面影橋の架かる水路（上水川＝千川上水／神田上水系のいずれか）は既存の橋名調査の未確定問題のまま（本冊からは特定できず断定しない）。〕
- **田嶋橋御渡〔確認・文言候補〕**: 別ルートの条に「**高田馬場…落合往還通 田嶋橋御渡 耕地道 七面坂 鼠山 長崎村…池袋村 雑司ヶ谷…**」の文言（「田島橋」のOCR変種）＝**高田馬場から落合往還の田島橋を渡り長崎村・池袋村経由で雑司ヶ谷に入る**往路の記録候補。〔落合側の田島橋（千川上水の落合付近の橋候補）の18世紀の実利用記録候補。橋の所在・架かる水路は要精査（断定しない）。〕
- **水系関連の周辺文言〔確認・文言候補〕**: 「**水道橋**」（王子筋の「小川町通 水道橋」＝神田上水の水道橋の通過）・「**淀橋水車え御立寄**」「淀松町水車江御立寄」（中野筋の淀橋の水車＝神田上水の淀橋水車への立寄）・「江戸川橋」・「**赤羽橋際**」等の通過文言＝御成の道筋記録としての上水・川沿いの地名の18世紀の定点用例群。

## 制限・未解決

- ①写本でOCR崩れが大（特に固有名の漢字）で、「九町目橋」（九丁目橋）・「面影橋」（面新橋等の変種）・「田嶋橋」等の橋名の原字形は要原画像照合。②「安永二己年ゟ一吉八亥年至」の下限年次（「一文八亥年」等の崩れ）は未判読（要照合）。③「大納言様」の比定・各御成の年次と道筋の対応の全面整理は未実施（道筋文言の型の抽出を優先した）。④「関口町水車」「淀橋水車」の個別の水車の比定は断定しない。⑤本冊の道筋記録は「御成がどこを通ったか」の行政記録であり、河川・水路そのものの記述（流路・構造）は含まれない（実利用の間接資料として位置づける）。
