# [GOV-385] 類集撰要 巻之七（入用之部）— 霊岸嶋浜町の年中定式入用の白堀浚賃〔第165回〕

- **書誌〔確認〕**: 『類集撰要』（幕府の町方行政例集）の巻之七（入用之部）冊。NDL次世代デジタルライブラリー [book/2571653](https://lab.ndl.go.jp/dl/book/2571653)。町内の年中入用・定式入用の答申・通達を集録。**引用文言はすべてOCR由来で要原文照合。**
- **寛政2戌年（1790）正月15日の霊岸嶋浜町の年中定式入用答申〔確認・核心〕**: 「**一大役銀拾匁一時之鐘役銭一玉川上水水銀一同定請負金弐割合一神田上水白堀浚賃一御年頭献上物入目一晦日銭一名主役金…**」の定式入用リスト＋末尾「右御尋に付申上候以上**寛政二戌年正月十五日霊岸嶋浜町名主市兵衛印**」＝**霊岸嶋浜町（日本橋川沿いの下町）の町内の年中の定式入用の中に「神田上水白堀浚賃」と「玉川上水水銀（水料）」が鐘役銭・晦日銭・名主役金と並ぶ定番項目として計上されていた**町方側一次記録〔**[GOV-378](GOV-378.md)（撰要永久録）の霊岸島受益構造（水銀・白堀浚賃の両建）の、受益町側の帳簿レベルの裏付け**＝受益側でも「定式入用」として意識されていたことの初出級の証拠。玉川上水水銀に「同定請負金弐割合」の注記が付く点は[GOV-378](GOV-378.md)の請負構造の細部対校案件〕。
- **臨時入用と定式入用の区別の列挙〔確認〕**: 同答申は牢屋敷預け・橋普請・下水普請・上水普請・町内掛り井戸普請・火之見普請・出火時の人足弁当等を「臨時入用」として列挙し、上記の水銀・白堀浚賃等を「定式入用」に分類＝**白堀浚賃が臨時の上水普請ではなく定式的な年間経費として把握されていた**文脈〔負担の定期性の証拠〕。

## 制限・未解決

- ①文言はOCR由来で「水銀」の原字形（水料の意か銀納の意か）・「弐割合」の細部は原文照合を要する。②霊岸嶋浜町の白堀浚賃の金額はこの文脈には現れず（帳簿の別箇所か）、金額レベルの負担実態は未確認。③「同定請負金弐割合」の帰属（玉川上水水銀への注記か）は文脈上の推定で要照合。
