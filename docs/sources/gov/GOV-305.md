# [GOV-305] 東京市公園概観（1923）— 江戸川公園＝舊神田上水路關口洗堰の附屬地

- **書誌〔確認〕**: 東京市編『**東京市公園概観**』（1923年刊）。NDL次世代デジタルライブラリー [book/971974](https://lab.ndl.go.jp/dl/book/971974)。市内公園の現況解説書。引用はすべて同館OCRテキスト由来（本書の該当部はOCRの状態が比較的良好だが文言は原文画像との照合を要する）。
- **江戸川公園＝舊神田上水路關口洗堰の附屬地〔確認文言・repo初出級の公園側定義〕**: 「**江戸川公園（小石川區關口町） 舊神田上水路關口洗堰の附屬地で、北は小石川臺の斷崖にて、南は江戶川に沿ふた細長い地域である。開園は大正八年三月十五日。**」（開園日はOCR「三月一一十五日」で「三月十五日」の崩れ候補）＝**江戸川公園が「舊神田上水路」の關口洗堰の附屬地として開園したこと（大正8年＝1919年3月15日）の東京市側の公式解説**。南は江戶川（＝旧神田上水＝江戸川の開渠部）に沿う細長い地域、東方は江戶川橋際に正門・四阿・運動器具という立地記述。〔旧神田上水施設の公園への転用の一次記録。大洗堰・江戸川公園の開園年の公的記録候補〕
- **「洗堰は關口の大堰とて、納涼に、水泳に、古來有名な所」〔観察文言〕**: 「**洗堰は關口の大堰とて、納涼に、水泳に、古來有名な所である、此の公園の特色は、極めて自然味に富んだ散策地、納涼地である、崖上の眺望臺よりは牛込早稻田方面は一望の內にある。**」＝**1923年時点で關口洗堰（大洗堰）が納涼・水泳の場として日常利用されていた実況**の記録〔大洗堰の1923年時点の機能（堰としての運用に加えた行楽的利用）の観察文言。[GOV-297](GOV-297.md)（帝都復興史の浚渫深の基準点）・江戸川公園の現況（README既出の江戸川公園記述）と対校できる〕。
- **位置づけ〔観察・内容メモ〕**: ①「舊神田上水路」という呼称が1923年時点で市の公園行政の側で使われている用例（上水廃止後の流路の行政側呼称のひとつ）。②西方は「老樹叢林蓊鬱として、上水路並に崖を蔽ひ、恰も深山溪谷に在るの思ひあらしめる」＝**上水路（旧神田上水路の敷・崖）の樹林被覆の1923年時点の実況**＝現・江戸川公園の緑地が旧上水敷に由来することの観察記録。

## 制限・未解決

- ①開園日の「三月一一十五日」はOCR崩れで「三月十五日」と読んだ（要原文照合）。②「洗堰＝關口の大堰」の名称対応（洗堰／大洗堰／大堰）の使い分けは本書の表記ぶりによる。③本書の江戸川（現・神田川下流）そのものの流路記述は今回は未精読（關口・江戸川公園・洗堰周辺の確認のみ）。
