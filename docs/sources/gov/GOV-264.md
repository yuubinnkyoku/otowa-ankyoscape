# [GOV-264] 神田玉川上水留 明治2年分冊ノ五 — 高札建場所リストと白堀関口村区間の損所・普請仕様

- **書誌〔確認〕**: 『神田玉川上水留』明治2年分冊ノ五 [book/2587528](https://lab.ndl.go.jp/dl/book/2587528)。本冊は[GOV-242](GOV-242.md)の書誌で「[12] 分冊ノ五」としてhitのみ挙げられ精読未実施だった冊。本ファイルで高札・白堀損所関係を精読。対校として分冊ノ一（明治二巳年七月より十二月）[book/2587534](https://lab.ndl.go.jp/dl/book/2587534)（[GOV-248](GOV-248.md)の[14]）の柵石垣普請仕様を併読。**引用文言はすべてOCR由来で要原文照合。**
- **神田・玉川上水の高札建場所の全リスト〔確認・repo初出〕**: 明治2年の高札（制札）建場所の村別・管轄別のリスト——「**一箱根ヶ崎村 日光道通橋際東之方 一同村狭山地弁天南之方 〆七ケ所**（大宮県支配所）」「**神田上…場通高札前**（同断・大宮県支配所）」「**一関口村大洗堰上水神前 一同村大洗堰入口木戸門前 〆弐ヶ所**（東京府郡改支配所）」「**一小瀧橋際東之方…但戸塚村地内**」「**一井之頭池上ノ水口北之方**（民部官）」のほか、玉川上水沿いに「**砂川村地内**」「殿ヶ谷村落口」「呑川・千駄ヶ谷橋際（品川県）」「下落合村西橋際・淀橋際・本郷村字成願寺橋・和田村…・和泉村番屋坂下・上高井戸村宮築田橋際・下高井戸村定鎌倉橋際」等——
  - **「関口村大洗堰上水神前」**＝**大洗堰の上水神（水神）の前に高札**＝大洗堰に上水神（水神社）が祀られていたことを示唆する明治2年の文言（[GAZ-048](../gazetteers/GAZ-048.md)水神社（八幡合殿・本地妙見・関口洞雲寺持）と対校）。
  - **「大洗堰入口木戸門前」**＝大洗堰入口の木戸門の前にも1ヶ所＝[GOV-234](GOV-234.md)三水道町の「古来持場」・[GOV-236](GOV-236.md)巡視路の「大洗堰中堤東之方柵矢来際」と対照できる大洗堰の施設構成（入口木戸門・中堤・柵矢来）の補強。
  - [GOV-248](GOV-248.md)の「井之頭池上水口〜堀通関口村大洗堰迄」という高札の範囲文言を、**建場所単位のリストとして具体化**した記録。
- **白堀・関口村駒塚橋上流区間の損所取調書〔確認・repo初出の文言群〕**: 「**神田上水（白）堀近損所之箇所也取調書**」——「**関口村駒塚橋上之間北側 一道之…柵ニ長三間押出し板無之柱は尚之同断**」「**浜前…南側…土手上板柵長四間押出しに柵板折腐潰…壱ヶ所**」「**同断長五間押出シ前同断壱ヶ所**」「**一…基石長弐間弐尺崩落損所壱ヶ所 川添屋敷町屋前 但三ツ並**」「**一荒ケ谷土手石垣道之形長五間押出シ同断有之壱ヶ所**」「**切支丹組屋敷前 一橋左右地覆損シ形チ無之候**」「**金剛寺坂本一渡橋大破二相成居申候 同断一渡り下…**」＝
  - **「荒ヶ谷」の再出現〔確認〕**: [GOV-232](GOV-232.md)・[GOV-233](GOV-233.md)の「荒ヶ谷」「承ヶ谷」（鼠ヶ谷のOCR変種候補）に、明治2年冊の「**荒ケ谷土手石垣**」を加える＝白堀沿いの土手石垣の地名として鼠ヶ谷系の表記が神田上水留の別冊にも現れる（原字形照合まで変種と断定しない）。
  - **「切支丹組屋敷前」の橋〔確認・repo初出候補〕**: 白堀沿いに「**切支丹組屋敷前の一橋**」があり「**左右地覆損**」（左右の手すり覆いが損傷）と読める文言＝**小石川の切支丹屋敷（切支丹組屋敷）前に白堀の橋があったことを示唆する明治2年の文言**（切支丹屋敷の位置〔現・小石川2丁目付近〕と白堀の経路の対校が課題。橋名は不明）。
  - **「金剛寺坂本」の渡橋大破〔確認・repo初出〕**: 「**金剛寺坂本一渡橋大破二相成居申候**」＝**金剛寺坂下（金剛寺坂本）の渡橋が大破していた**という明治2年の損所取調文言＝[GOV-237](GOV-237.md)明治2年9月の金剛寺橋上之方堤急破・[GOV-242](GOV-242.md)金剛寺橋掛直（6月取掛）・[GOV-241](GOV-241.md)延享4年の金剛寺橋と対照できる**金剛寺坂の橋の新たな状態記録**（大破の年月・掛直との前後関係は本冊のみでは確定しない）。
  - **駒塚橋の位置の補強**: 「**神田上水関口村駒塚橋辺ゟりの下も白堀通**」「**関口村駒塚橋上之間北側**」＝**駒塚橋が関口村の白堀（神田上水）に架かり、その下流が白堀通である**ことを示す文言群（[GOV-248](GOV-248.md)の「駒塚橋上之方」・[GAZ-048](../gazetteers/GAZ-048.md)駒塚橋（長九間・駒繫橋→呼誤り伝承）と対校）。
- **柵石垣普請仕様の対校（2587534・分冊ノ一）〔確認・構造数値〕**: 「**神田上（水）関口村白堀通柵石垣参垂板損所御普請仕様注文**」——「**駒塚橋上之方北…一柵長七間高弐間 同所一柵長拾六間高七尺 杭木…丸太長三間… 杭木…四寸角…**」＝**駒塚橋上流側の柵（長7間×高2間・長16間×高7尺）・丸太杭の普請仕様**という定量文言（[GOV-248](GOV-248.md)の白堀通損所修復リストの「駒塚橋上之方」の具体の仕様として対校）。
- **赤坂溜池の「上水白堀」囲込地〔確認・周辺〕**: 「**赤坂溜池…明地堀際迄別紙絵図面朱引之中 今般道敷共…拝借地ニ被仰付候 就而は右囲込地所之内 上水白堀茂有之 時々見廻并御修復之節…入為立入候**」＝**赤坂溜池の明地拝借地内に「上水白堀」があり、見廻・修復の時に入立する**ことを条件とする文言＝[GOV-263](GOV-263.md)の赤坂紀伊国坂下の「御上水白堀」と並ぶ**赤坂側の白堀（青山上水系）の明治2年の用例**（神田上水の白堀とは別水路の同名呼称の注意書きを補強）。
- **清光院の白堀通石垣崩所修復申立〔確認・周辺〕**: 「**神田上水白堀通石垣崩所御修復相成候様 清光院周佐申立候 当方二而も一応見請候処相違無之 追々崩増之程も難計場所に付**」＝**清光院の周佐（住職か）が白堀通の石垣崩所の修復を申立てた**文言（清光院の所在・白堀のどの区間かは要照合）。
