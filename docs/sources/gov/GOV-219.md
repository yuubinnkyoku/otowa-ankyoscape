# [GOV-219] 類集撰要[1]地面 — 拝領屋敷調査の触に現れる両「千川屋敷」

- **書誌〔確認〕**: 『類集撰要』[1]（地面之部・拝領屋敷の調査関係の記録集・酉年4月の触を含む〔文政10戊辰か寛政10戊午か・成立年代の確定は目録照合が必要〕）。NDL次世代デジタルライブラリー [book/2571647](https://lab.ndl.go.jp/dl/book/2571647)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **「千川屋敷藤兵衛」の文言〔確認・repo初出〕**: 拝領屋敷の実態調査（屋敷者の御用相勤の有無・他支配の者の参入等の調査）の例示列——「**或は其後御用は相心候得共屋敷者其家引続拝領致罷在候分他支配之者相参之其荒増長崎屋原右衛門日和見次郎左衛門教政三拾三円堂寺永富町新次郎下冨坂四郎兵衛高場駒場寺国山千川屋敷藤兵衛高喰町元呉服師京都住宅左崎又右衛門三喜長左衛門元御絵師藤代町藤左衛衛門四郎左衛勘助浪人万次郎御取上岐々下谷大工屋敷**」〔**①拝領屋敷の調査文脈で「千川屋敷藤兵衛」という人名つきの例示があること（「寺国山千川屋敷藤兵衛」の分節はOCR崩れの可能性大・要照合）、②前後の文脈から「拝領屋敷に他支配の者が参入して荒増している」例の列挙であること**＝**千川屋敷（小石川白山前町か・茅場町かの判別はこの文言からは不可能）が拝領屋敷の管理問題の文脈で取り上げられた一次文言**。「藤兵衛」が白山前町の千川家（元祖太兵衛・与惣兵衛〔[GOV-210](GOV-210.md)〕）の一族の可能性（「藤兵衛」＝「与兵衛」の誤読か別人か）はOCRのみからは確定できない（断定しない・要照合）〕。
- **「茅場町千川屋敷地主」の文言〔確認・repo初出・八丁堀系千川屋敷の追認〕**: 同様の例示列に——「**茅場町千川屋敷地主（通弐町目八郎兵衛か・OCR要照合）**」の文言（第108回ノート記載の課題①の該当箇所）〔**①茅場町（南茅場町）に千川屋敷の「地主」がいたことが拝領屋敷調査の文脈で確認できること、②その人名（OCRでは「通弐町目八郎兵衛」等に読めるが不確定）**＝**八丁堀・茅場町側の「千川屋敷」（[BOOK-131](../books/BOOK-131.md)・[BOOK-133](../books/BOOK-133.md)・[GOV-214](GOV-214.md)）に地主（家主層）が存在したことの追認**。白山前町の千川屋敷（千川家の拝領・請負人）との関係は従来通り未確認（断定しない）〕。
- **位置づけ〔観察〕**: ①本書により、江戸に2系統（少なくとも表記上）の「千川屋敷」が**同一の行政文書（拝領屋敷の調査の触）の中で例示されている**ことが初めて確認された（同文書内で両者が並記されることで、両「千川屋敷」が江戸の行政上、別個の屋敷として認識されていた傍証になる方向の資料）。②「藤兵衛」の人名が千川家の系譜（太兵衛→…→与惣兵衛→三左衛門→平吉〔[GOV-212](GOV-212.md)〕）に接続するかは、くずし字の原文照合（「与兵衛」の誤読の可能性を含む）が必須。
