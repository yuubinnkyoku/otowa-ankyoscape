# [GOV-014] 文京区公式「3.関口大洗堰」

- 文京ふるさと歴史館の解説ページ「3.関口大洗堰」（ページID 7525、更新日 2024年5月5日）。
- https://www.city.bunkyo.lg.jp/rekishikan/p004330.html
- 神田上水は天正18年（1590）の少し後に開かれ、井の頭池などを水源として江戸・東京の生活水を供給した、との説明がある。
- 関口大洗堰の機能として、大滝橋近くで神田上水の水位を上げ、上水路を通して小石川の水戸藩上屋敷（現・東京ドーム一帯）の池（大泉水）を調整池とし、余った水は神田川に流した、との説明がある。
- 廃止について、明治34年に飲用水への利用を終えた後、工廠の移転により昭和8年（1933）に廃止された、との記述がある。西暦「1901年」の表記は同ページ本文にはなく、明治34年の換算である。
- 同ページ本文に「巻石白堀」の語は見当たらない（ページ内照合による）。
