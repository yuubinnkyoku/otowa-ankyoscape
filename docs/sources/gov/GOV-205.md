# [GOV-205] 東京都市計画報告 昭和9年度第一期・第四期 — 谷端川改修の完成公表（1934・1935）

- **書誌〔確認〕**: 東京府『東京都市計画報告』（昭和9年度第一期・[book/1448209](https://lab.ndl.go.jp/dl/book/1448209)／同年度第四期・[book/1448221](https://lab.ndl.go.jp/dl/book/1448221)）。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **谷端川・立会川の完成公表〔確認・repo初出の重要文言〕**: 第四期（昭和9年度末の進捗）「市域内ニ於テ工事中ノ河川關係都市計畫事業ノ**昭和九年第四期末ノ進捗狀況ヲ見ルニ完成シタル河川ハ東京府知事執行ノ谷端川、立會川ノ兩河川ニシテ**其ノ他ノ河川ハ次ノ通未完成ノモノデアル」＝**谷端川改修が昭和9年度（1934年度）末に完成したことを東京府が公式に公表した記録**。同書の河川工事進捗状況調は「昭和九年十二月末現在」。〔[GOV-203](GOV-203.md)（1936・「既ニ昭和九年度ニ完成」）・[GOV-186](GOV-186.md)（1940・「既ニ完成」）と整合する、完成直後の府側公表〕〔文言はOCR要照合〕。
- **第一期（1934）の河川進捗表〔確認・要照合〕**: 「都市計畫事業トシテノ河川改修工事狀況」表（昭和九年三月末日現在）に「**第三谷端川改修工事**（自…**至…鐵道山手線下**）」を収録〔「至鉄道山手線下」は[GOV-182](GOV-182.md)（報告第4回・「至池袋鉄道山手線下」）の区間文言と整合〕。
- **第一期・上水道章の総説〔確認・repo初出の1934年用例〕**: 「東京市の上水道の歴史は、遠く…**神田上水ニ始リ**、其ノ後…**玉川上水及此ノ外ニ千川上水、三田上水、青山上水、龜有上水等ガ作ラレタガ、三百年間ヲ通ジテ存在シタルモノハ玉川上水、神田上水、千川上水ノ三上水ノミトナツタ**」＝**千川上水を「江戸の三上水」の一つとする府/市側公式叙述の1934年用例**〔[GOV-172](GOV-172.md)（1936・東京府史）・[BOOK-065](../books/BOOK-065.md)（練馬区史）に先行〕〔文言はOCR要照合〕。
- **第一期・議第110号の再録〔確認〕**: [GOV-201](GOV-201.md)の提案理由（神田上水計画変更・執行年度昭和10年度まで延長・**事業費5,630,722円40銭**）を再録＝速記録第6号の第二ソース。第三回（[book/1448213](https://lab.ndl.go.jp/dl/book/1448213)）にも同一告示・対照表（計4,434,249円→5,630,722円・差引1,196,473円40）を再録。
