# [GOV-380] 触留 第19冊（安政4丁巳）＋玉川上水留[63] — 大洗堰左右袖石垣修復の着手から完成まで〔第163回〕

- **書誌〔確認〕**: ①『触留』第19冊（NDL [book/2549596](https://lab.ndl.go.jp/dl/book/2549596)）＝**安政4丁巳年（1857）確定**（本文中に「安政四丁巳年六月」「安政四巳年七月」の紀年文言が複数。講武所内御軍操練教授所の御開の触〔7月〕と整合）、②『玉川上水留』[63]（NDL [book/2587398](https://lab.ndl.go.jp/dl/book/2587398)）＝「安政四巳年正月より五月迄…玉川上水清水附屋形構内樋枡井戸共御修復一件 分冊ノ一」。**引用文言はすべてOCR由来で要原文照合。**
- **大洗堰左右袖石垣修復の年次チェーン〔確認・repo初出・核心〕**: ①玉川上水留[63]に「**但当辰年神田上水関口村大洗堰左右袖石垣其外御修復中書面之通附切伺之通被仰渡候 十一月**」＝**辰年（安政3丙辰・1856）11月に大洗堰の左右袖石垣其外の修復の人員配置（附切）が仰渡された**、②触留第19冊の7月13日の触「**神田上水関口村大洗堰其外共御普請ニ付同所え湯小屋主建煙立之儀申達置候処御用相済小屋取払申候**」＝**巳年（安政4・1857）7月13日に大洗堰其外共の御普請が相済み湯小屋を取払った**＝**安政3年11月着手→安政4年7月完成の大洗堰左右袖石垣修復の前後関係が2資料の独立の文言で確定**〔大洗堰修復年表（天明3年7月石垣崩れ→天明4年7月修復〔[GOV-382](GOV-382.md)〕・文政12年〔[BOOK-139](../books/BOOK-139.md)系〕・[GOV-379](GOV-379.md)の卯年袖石垣）に**安政3〜4年の修復**を加える。「左右袖石垣」の部位名は[GOV-379](GOV-379.md)の「道之類袖石垣」と同じく袖部が焦点であったことを示す〕。
- **玉川上水四谷万年樋の石垣樋落場修復〔確認・repo初出〕**: 安政4年6月22日の触「**玉川上水万年樋石垣樋江落場に付四ツ谷御門外御堀端小屋場内え湯小屋建候間煙立可申候**」＋6月末の触「**四谷浜町三丁目ゟ御堀端迄樋枡修復二付明後朔日ゟ場所送壱人立往来相通**」＝**玉川上水の四谷万年樋で石垣・樋の落場（破損落下）があり、四谷御門外御堀端（浜町三丁目〜御堀端）で樋枡の修復**が行われた（湯小屋・場所送＝人を立てての往来規制）＝**四谷万年樋の安政4年の修復記録**〔[GOV-379](GOV-379.md)の四谷尾張町〜出雲町の上水樋修復（卯年）・[GOV-381](GOV-381.md)（検使之部）の四谷大木戸文言と並ぶ玉川上水四谷区間の修復系譜。万年樋の固有名の用例（[GAZ-035](../gazetteers/GAZ-035.md)桜木町万年樋とは別系統の四谷万年樋）〕。
- **小日向水道町の橋の掛直普請〔確認・文言候補〕**: 安政4年6月の触に「**小日向水道町ゟ拾斗坂江渡り…右橋町内ゟ掛直普請出来仕候ニ付…廿五日ゟ仮橋取払本橋往来**」＝小日向水道町と「拾斗坂」（OCR候補・原字形要照合）を渡る橋の掛直普請と仮橋→本橋の切替〔**水道町の橋の幕末の修復記録**。架かる川（江戸川か白堀か）は本文言からは断定しない〕。
- **玉川上水清水屋形の樋枡井戸修復の請負構造〔確認〕**: 玉川上水留[63]本文＝清水屋形構内の樋枡（玄関前通・台所向・広敷前）・井戸の修復の**落札（108両2歩で落札・直段143両2歩・差引35両・地割棟梁元積）と公儀御出銀・武家町出銀の区分**＝玉川上水側の修復請負の実務（[GOV-267](GOV-267.md)系の神田上水の落札構造と対校できる玉川上水の記録）。

## 制限・未解決

- ①「辰年」＝安政3丙辰の同定は書面の紀年と玉川上水留[63]の表題（安政4巳年正月〜五月）の前年であることによる（「附切」の原字形も要照合）。②「拾斗坂」の原字形・位置は要照合。③万年樋の「樋江落場」の解釈（石垣と樋の落下か樋の落口か）は原画像照合後に判断。④[63]分冊ノ二以降（6月以降）は未確認。
