# [GOV-129] 豊島区「わが街ひすとりぃ 第10回 千川 現地ロケ編」

- **書誌〔確認: ADEAC目録・全文テキスト取得〕**: 豊島区デジタル区史「としまひすとりぃ」広報番組。**収録日 平成31（2019）年2月12日、制作 令和元年5月、収録時間14分05秒**。出演: **矢尾一枝・島功**（ほか長谷川熙・名井敏子・田島勝司・田島喜久雄・井上・和栗の各氏）。[ADEAC目録ページ](https://adeac.jp/toshima-history/catalog/mp00001010)、[現地ロケ編全文テキスト（ht420100）](https://adeac.jp/toshima-history/texthtml/d000000/mp00001010/ht420100)。目録のライセンス表示は**クリエイティブ・コモンズ表示4.0国際（CC BY 4.0）**〔確認: 目録ページ〕。同回の広報番組インタビュー編（[mp00001020](https://adeac.jp/toshima-history/catalog/mp00001020)、19分26秒、放送日 平成31年3月30日）には**全文テキストが存在しない**〔2026-11-14確認: ht420210は「対象のテキストは存在しないか、表示権限がありません」〕。
- **千川上水（暗渠）の蛇行と蛍・遊泳の伝聞〔確認: 全文テキストの直接引用〕**: 矢尾氏「**ここずっと流れてたんです。むこうに向かって。それでこう蛇行して…千川ってすごく蛇行してるんですよね。曲がりくねってね。昭和の初めとか、そんな時には蛍が飛んだりね。泳いでたなんて話をちょこっと聞きますけれども。**」〔蛇行は証言者の地形認識、**蛍・遊泳は「聞きます」という伝聞である点を区別する**。BLOG-079（千川たんぼのホタル・ドジョウ解説板）と整合する生活史の追加証言〕。同場面で矢尾氏・島氏は**板橋区境の四つ角の貝屋（山盛りの貝の剥き身）・中村屋・千川寿司・魚屋・時計屋**といった千川の商店街の記憶を語り、「**（昭和）50年代の初めくらいまでは…お店が続いてました**」と商店街の存続時期を補足する〔確認: 全文テキスト〕。
- **旧長崎村「境窪」の字名と畑作〔確認: 全文テキストの直接引用〕**: 榛名神社（千川1丁目）で総代の**田島勝司氏**が「**昔長崎村の境窪って場所だったんです、ここは。**」と提示した昔の地図を示して説明し、「**要町の通りがまだない**」「**この一帯がずっと全部畑なんですよね**」と土地利用を述べる。田島喜久雄氏が「**稲作じゃないから。**」「**麦とやっぱり大根ですよ。**」と畑作の内容を補足する〔**2026-10-11ノート（音羽暗渠調査・未反映分）に「豊島区のオーラルヒストリーにある証言」として記録され出典未特定だった境窪証言の、出典資料の特定と文言の確定**。ただし提示された地図の書誌・年代、境窪の範囲は本文中では特定されない〕。
- **千川彫刻公園=彫刻家中野素昂宅跡〔確認: 全文テキストの直接引用〕**: 千川彫刻公園（[GOV-117](GOV-117.md)）で近隣の井上氏が「**公園ができる前はここは中野さんの御宅でした、全部。**」と証言し、母屋・アトリエ・**木彫室**があったこと、**昭和13年に越入した当時は中野邸と2軒のみで「うちが来て4軒」**だったこと、中野素昂氏の制作生活のエピソード（モデル女性の覗き見、アトリエ中二階からの監督、夕食の同席、「芸術家っていうのは燃えてなきゃいけない」の語り）を回想する〔**GOV-117の「元地主寄贈4体ブロンズ」の元地主が中野素昂と接続する根拠となる古老証言**。ただし寄贈者名・宅跡範囲の公文書確認は未実施〕。
- **千川地区のアトリエ〔確認: 全文テキスト〕**: 彫刻家**長谷川義起（1891～1974）のアトリエ3棟**（現マンション「ドルフ長谷川」にご子息の長谷川熙氏が在住、越入当時「周辺はもう野っ原のようなところ」）、洋画家**名井萬亀（1896～1976）のアトリエ**（**昭和15～16年頃に石神井公園から当地へ移転建築**、名井敏子氏の回想）〔千川・長崎一帯のアトリエ村形成の個別実態として、すずめが丘・さくらが丘アトリエ村の既知記録に加える資料。千川上水・旧河道との位置関係には本文言及がない〕。

## 制限・未解決

- ①蛍・遊泳は「話を聞く」形の**伝聞**であり、昭和初期のどの区間か・水質・水量は未確認。②「境窪」の範囲・提示古地図の書誌は本文中に特定情報がない。③中野素昂宅跡と千川彫刻公園敷地の対応は古老証言ベースで、地籍図・公園設計図との照合は未実施。④インタビュー編（mp00001020）の本文（映像の直接視聴）は未確認。⑤いずれも**平成31年2月収録時点の約50～90年前の記憶の回想**であり、年代の概数を確定値として扱わない。
