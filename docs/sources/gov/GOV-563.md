# [GOV-563] 専門家委員会資料「東京都が管理する中小河川の特徴」〔都管理中小河川の氾濫形態類型と2ケース算定の方法論的正当化の都側スライド〕

## 書誌〔確認: PDF本文抽出・2026-11-23取得〕

- 「第18回河川整備計画策定専門家委員会」（2024年7月23日開催・[GOV-562](GOV-562.md)と同一会合）の配付資料 https://www.kensetsu.metro.tokyo.lg.jp/content/000070237.pdf 。狩野川台風（昭和33年9月27日）の浸水被害状況図を冒頭に掲げる資料〔スライド形式・約1,860行の抽出テキスト〕。

## 内容〔確認〕

- **堀込河道**: 「堀込」の語が4回。堀込河道（蓋かけ前の掘り込み河道）の説明として石神井川・神田川等を例示〔repoに「堀込」の用語での都側定義文言の初出か。既存の石神井川暗渠化工事 ([GOV-083](GOV-083.md) 等) の文脈での利用可能性〕。
- **中小河川の氾濫形態の3類型**: **流下型・拡散型・貯留型**。「**小規模河川の洪水浸水想定区域図作成の手引き（令和5年7月〔R5.7〕）**」由来の類型として提示〔手引きの文言が氾濫形態分類の出どころであることを明示する都側スライド〕。
- **市街地率**: 「市街地率が高い傾向⇒浸水被害は家屋等が主体【石神井川】【神田川】市街…」の文言〔都管理中小河川の被害構造説明〕。
- **都の2ケース算定（40mm/65mm）の方法論**: 「40mm」3回・「65mm」10回。根治水路・流量能力の枠組みとして**時間最大40mm（河川の整備目標）と65mm（想定外の降雨対応）の2ケース**の算定を行う構造の説明資料〔「手引き」準拠の想定図と都の費用便益2ケース ([GOV-562](GOV-562.md)・[GOV-540](GOV-540.md)) をつなぐ都側の方法論的正当化スライド。[GOV-149](GOV-149.md)（1/20目標整備水準）・[GOV-485](GOV-485.md)（善福寺川）でも同じ2ケース構造が使われているため、その原典的な所在として価値〕。
- 狩野川台風（S33.9.27）の浸水被害状況の図（手引きの被害想定の説明用事例）。
