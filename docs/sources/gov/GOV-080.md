# [GOV-080] 豊島区「千川親水公園」施設案内

- **書誌〔確認：スニペット〕**：豊島区公式サイトの公園施設案内頁。2026-11-12時点でopen_urlによる直接取得は不能（翻訳選択の応答のみで本文未取得）のため、複数の検索スニペット（PC版・モバイル版とも同一文言）で本文内容を確認。頁の更新日は未確認。
- **水流の復活〔確認：スニペット〕**：「ここはかつて千川上水の清流が眺められたところ。**水流はながらく途絶えていましたが、平成元年に復活し、暗渠管のなかを流れています**」〔①千川親水公園の水流が**暗渠管の中を流れている**という公式文言＝repo初出（公園の水路の実体が千川上水の暗渠管を利用しているか、独立の管路かは本文では区別できず断定しない）。②平成元年の復活時期は[GOV-077](GOV-077.md)の練馬区側の清流復活（平成元年3月・青梅街道までのかれ川）と同時期で、**千川上水の水を豊島区側でも平成元年に流した**可能性を示唆するが、本頁単独では水源・経路を断定できない〔仮説として記録〕〕。
- **敷地の由来〔確認：スニペット〕**：「**この敷地は東京都から借りており、以前は千川児童遊園の一…**（以下スニペット途切れ）」〔①公園敷地が**東京都からの借地**であること、②**旧千川児童遊園（の一部）を千川親水公園へ転用**した経緯の公式文言。BLOG-050・BLOG-069等の谷端川児童遊園（板橋区立）と同名異園の千川児童遊園（豊島区・千川沿い）の転用史として記録。転用年次は未確認〕。
- **制限〔未解決〕**：本文全文の直接取得、水流の水源・経路（千川上水暗渠管の流用か独立管路か）、平成元年の通水経緯（千川上水の清流復活事業〔[BLOG-090](../blogs/BLOG-090.md)・[GOV-077](GOV-077.md)〕と豊島区側事業の関係）、千川児童遊園から親水公園への転用年次。

## 三河川への使い方

- 千川親水公園（豊島区千川2丁目付近・庚申橋跡の下流側）は[BLOG-103](../blogs/BLOG-103.md)（Natrium・庚申橋の残存）・[BLOG-053](../blogs/BLOG-053.md)（調節池跡説明板）で観察対象になってきた公園。公式文言として「暗渠管のなかを流れる」水流の存在が裏付けられたことで、千川上水豊島区間の水の現在（清流復活水の到達範囲）を検討する際の区側資料。
