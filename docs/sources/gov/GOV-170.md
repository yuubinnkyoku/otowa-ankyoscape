# [GOV-170] 享保撰要類集 上水之部 — 享保7年千川上水差止の幕府一次記録

- **書誌〔確認〕**: 『享保撰要類集』二十七ノ上（内閣文库蔵・幕政例集）の上水之部。NDL次世代デジタルライブラリー [book/2572821](https://lab.ndl.go.jp/dl/book/2572821) OCRテキストで千川上水関係2条を確認。**文言はOCR由来で要照合。**
- **享保7年8月の千川上水差止御書付〔確認・repo初出の差止一次記録〕**: 「千川上水之儀 **中興より懸り候事に候故自今相止候間**其段向々江可被申達候 **来る十月より上水取不申筈**に候間可被得其意候 **享保七寅八月**」＝**享保7年（1722）8月に千川上水の「相止」が仰渡され、同年10月から取水停止**とする御書付（8月17日安藤対馬守御渡、中山出雲守方写し）。同一書式で「**青山三田両所上水之儀**中興より懸り候事…」の9月3日水野和泉守渡の書付も併せて写され、町触・町奉行への達の過程が記される。目次部に「千川上水 青山三田上水 本所上水 **相止候被仰渡之事**」の条目あり。
- **元文4年（1739）の千川用水樋口寸法〔確認・repo初出〕**: 玉川上水通り四谷大木戸までの**分水三拾二ヶ所**の伺書付（元文四未年十月三日付、石河土佐守御附紙）に「**千川用水樋口 壱尺に弐尺五寸** 同断 三田用水樋口 三尺四方」、その内12ヶ所は「**拾ヶ年以来新田用水幷領水に罷成候**」とある〔「拾ヶ年来」の内訳文言はOCR不鮮・要照合〕＝**廃止後も玉川上水の分水口台帳に千川用水樋口が寸法付きで残る1739年時点の一次記録**。
- **位置づけ〔観察〕**: [BOOK-077](../books/BOOK-077.md)・[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌）の年表「享保7年廃止」に対し、**差止の仰渡（8月）と取水停止（10月）の月単位の幕府側一次記録**を与える。「中興より懸り候」との文言は元禄9年開削が「中興」扱いであること、青山・三田・本所上水との同時差止であることも記録する。元文4年樋口寸法（1尺×2尺5寸）は[GOV-098](GOV-098.md)系の元樋寸法変遷（1732/1737/1773）に1739年の観測点を加える。

## 制限・未解決

- ①御書付の差出・宛先人名（安藤対馬守・水野和泉守・中山出雲守）・年月はOCR由来で原本照合を要する。②「中興」の語の内実（元禄9年開削を指すか）は解釈を留保。③元文4年伺書の「12ヶ所は10年来新田用水幷領水」の文言が千川用水樋口を含むかは文脈上明示されず断定しない。
