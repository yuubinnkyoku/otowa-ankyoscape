# [GOV-178] 都市計画東京地方委員会 第16号 — 千川上水線の戦時緑道計画

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第十六号』（第36回委員会＝**昭和16年（1941）12月24日開会**・第37回＝昭和17年3月17日を収録）。NDL次世代デジタルライブラリー [book/1172389](https://lab.ndl.go.jp/dl/book/1172389)。OCRテキストで議第二九〇号（東京都市計画綠地決定ノ件）関係を確認。**数値・文言はOCR由来で要照合。**
- **呑川・玉川上水・千川上水・石神井川の沿岸道路選定〔確認・repo初出〕**: 理由書が「市內河岸景勝地ノ內 先ヅ**呑川、玉川上水、千川上水、石神井川ヲ選ビテ沿岸道路ヲ新設又ハ擴幅シ、之ニ植樹ヲ施シ、以テ市民ノ體位向上ノ一助タラシムルト共ニ都市ノ防火ニ備ヘントス**」＝四河川（千川上水を含む）の**沿岸緑地道路（植樹付き）新設・拡幅の計画理由**。地域表示に「板橋區江古田町・北多摩郡武藏野町大字吉祥寺・板橋區練馬南町三丁目・中野區鷺宮六丁目・杉並區矢頭町」（水路敷を除く旨の注記）を列挙〔町名はOCR要照合〕。
- **「千川上水線」路線の数値〔確認〕**: 「第三號路線ノ**千川上水線**…**千川上水線ニ沿ツテ選ンダモノ**デアリマシテ、**起點ハ板橋區江古田町**デアリマシテ、**武藏野町大字吉祥寺ニ至ツテ**既定ノ武藏野都市計畫道路ニ接續スル計畫デアリマシテ、**其ノ延長約九粁、幅員ハ三十五「メートル」乃至五十「メートル**」デアリマシス。此ノ千川上水モ玉川上水ト同樣ニ**德川時代ノ遺蹟デアリマシテ**、起點附近ハ家屋ガ多イノデアリマシスガ、**沿線一帶ハ櫻並木ト雜木林ニ蔽ハレ景勝ノ地**デアリマシス」。
- **位置づけ〔観察〕**: 1941年（防空・防火の戦時下緑地計画）に**千川上水跡沿いの緑地道路化（江古田〜吉祥寺・約9km・幅員35〜50m）が都市計画線として決定審議された**記録。現在の千川上水緑道（武蔵野〜中野・杉並の「千川通り」沿い整備）の**戦時下の制度的直接前史**であり、[GOV-146](GOV-146.md)（天保新堀用水＝千川上水分水系の桃園川）・[GOV-156](GOV-156.md)（環七地下河川の豊玉地区）と地域が重なる。実際の整備・執行の有無は本記録では確認できない。

## 制限・未解決

- ①路線の区域表示（練馬南町・鷺宮・矢頭町等）はOCR由来で町名の判読照合を要する（「矢頭町」は判読留保）。②江古田〜吉祥寺間が千川上水のどの水路（旧上水か用水路か）に沿うかは、本委員会の路線呼称に依拠しており、水路の同定は古地図・地籍と要照合。③決定後の事業執行・戦後引継ぎは未確認。
