- **①掃除町21→20番地地先の「千川養水流末」への架渡橋の呼名の伺（1877）〔repo初出の府文書レベル文言〕**: 「小石川掃除町２１番地地先より同２０番地地先へ渡る**千川養水流末**へ架渡の橋の銘・呼名についての伺」＝**千川（谷端川下流域の千川呼称区間）の流末（掃除町地先）に架かる橋の名称を府が管民の願書に対して伺い立てた実務記録**。「千川**養水**流末」の表現＝**下流域の谷端川系水路が「千川養水」と呼ばれていた1877年の府側文言**で、[BLOG-078](../blogs/BLOG-078.md)/[BLOG-079](../blogs/BLOG-079.md)系の掃除町の千川の橋群・[BOOK-120](../../books/BOOK-120.md)（1880.10.4千川橋流失）に先行する1877年時点の橋の存在と行政上の命名実務を伝える〔観察: 対象橋が「千川橋」か別橋か・伺の結論（呼名の決定）は本文（MFコマ0006-0512）未確認で断定しない〕。
- **②明治34年（1901）の千川橋架換工事〔repoの千川橋年代列への1901年の加わり〕**: 賞与（手当）の件名＝**1901年に小石川区で千川橋の架換工事が行われ落成した**ことを人事記録（進退録）レベルで裏付ける〔確認: 目録文言〕。[BOOK-009](../../books/BOOK-009.md)（1910年時点で千川橋＝明治13〜14年架換の土橋）の後に**1901年の再架換の候補**となる行〔観察: 架換の場所・構造は本文未確認。1880流失→明治13-14架換→（1896・1897・1910の水害を経て）→1901架換→…という千川橋通時系列の整備史料〕。技手・崇島貞俊と技手補・狩野文平の人名はrepo初出〔確認: grep〕。
- **③猫俣橋の橋上に市電軌道（1933）〔千川下流域の猫俣橋（猫股橋）の昭和期の実在・位置記録〕**: 東京市電気局の**氷川下町〜大塚仲町間の軌道工事方法変更**の構造図群（線路平面図・縦断面図・**猫俣橋橋上軌道構造図**）＝**1933年時点で「猫俣橋」と呼ばれる橋が市電軌道の通る道路上に現存し、その橋上への軌道敷設（または構造の変更）が府の許可行政の対象になった**ことを伝える〔確認: 目録文言〕。位置（小石川区・氷川下町〜大塚仲町間）＝千川下流（氷川下町〜掃除町〜富坂の千川経由町名〔[GOV-593](GOV-593.md)の千川筋経由町名列〕と隣接する区域で、**[BLOG-210](../blogs/BLOG-210.md)の千川の猫股橋（根子股橋由来説）・[GAZ-048](../gazetteers/GAZ-048.md)の谷端川橋戸町の猫俣橋（石橋）の2系統の同名橋問題に対し、1933年の橋の存続と軌道上の位置を特定する図面資料**〔観察: 対象橋の川の同定（千川か谷端川か）は構造図本体（MFコマ0822-0934）で橋下の水路を確認するまで断定しない〕。千川改修（1930-34〔[GOV-094](GOV-094.md)〕）と同時期の軌道工事方法変更であることも時系列的に並ぶ〔観察〕。
