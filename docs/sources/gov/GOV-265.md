# [GOV-265] 神田玉川上水留 明治2年 — 両上水の帳簿引継ぎ目録と関口の水車持2名の一件帳

- **書誌〔確認〕**: 『神田玉川上水留』明治二巳年正月至十二月 神田玉川上水留分冊ノ一 [book/2587539](https://lab.ndl.go.jp/dl/book/2587539)。明治2年（1869）の記録。**引用文言はすべてOCR由来で要原文照合。**
- **両上水の帳簿・絵図の引継ぎ目録〔確認・repo初出の帳簿名群〕**: 上水方（神田・玉川両上水）の帳簿の目録として——「**神田玉川両上水御門之其外持場絵図**」「**諸御普請名書**」「**諸御普請所見出帳**」「**両上水石高増減帳**」「**両上水御組合普請幷水銀取集廻状請取案文留（三田用水は松平修理太夫…相記置）**」「**神田上水御組合普請合…出銀取…帳**」「**玉川上水御組合普請金…町方出銀取集帳**」「**神田上水町方水銀帳**」「**上水方其外伺済書抜**」「**（白）堀浚賃銭取集…弐冊**」「**関口水車持善左衛門一件**」「**関口村水番人代合其外共一件**」「**関口水車持半兵衛一件**」「**水車…附 三田用水分九口御修復**」「**一般水船一件・水船持上納高城幷鑑札引替**」「**四谷大木戸…番人代替…**」「**四谷御門外掛樋高柳見守番人…代替**」「**神田…上水年間帳**」「**明地之外拝借人願紙一件（慶応四辰年）**」等——
  - **「両上水御門之其外持場絵図」〔確認・repo初出〕**: 両上水の門・持場の絵図の帳簿名の記録＝[GOV-247](GOV-247.md)（明治2年正月・営繕司引継ぎ目録）の「両上水御門々持場絵図」と対応する**持場絵図の実在の追認**（絵図本体の所在は不明・現存確認が課題）。
  - **「関口水車持善左衛門一件」「関口水車持半兵衛一件」〔確認・repo初出〕**: **関口の水車持ち（水車所有者）の善左衛門・半兵衛の2名の一件帳が独立帳簿として存在した**ことの記録＝[GOV-246](GOV-246.md)の「関口水道町の水車持ち」・[GOV-262](GOV-262.md)（小石川御門外の新規水車願）・[GOV-263](GOV-263.md)（江戸川端の水車）と並ぶ**明治2年時点の上水沿い水車の所有者の実名の記録**（善左衛門・半兵衛の水車の位置〔江戸川端か白堀沿いか〕は本目録のみでは確定できない）。
  - **「関口村水番人一件」**: 関口村の水番人の一件帳＝[GOV-248](GOV-248.md)「白堀通見守武兵衛」・[GAZ-048](../gazetteers/GAZ-048.md)大洗堰の「水番人小屋」・[GOV-246](GOV-246.md)の水番人小兵衛と対照できる水番人の帳簿の存在記録。
  - **「白堀浚賃銭取集帳（弐冊）」**: [GOV-245](GOV-245.md)〜[GOV-249](GOV-249.md)の白堀渡賃銭・浚賃銀制度の帳簿が明治2年末時点で2冊存在したことの追認。
  - **「水船持上納高城幷鑑札引替」**: 上水の水船（水運船か・水番船か）の持ち主の上納高と鑑札（鑑札=免許札）の引替の帳簿名＝上水の水運・水船の鑑札制度の存在を示唆する記録（語義は要照合）。
  - **「四谷御門外掛樋高柳見守番人」**: 四谷御門外の掛樋の見守番人の代替の記録＝[GOV-254](GOV-254.md)（市中取締類集の榎坂水道橋見守等）と並ぶ上水掛樋の見守の実名（高柳）の記録。
