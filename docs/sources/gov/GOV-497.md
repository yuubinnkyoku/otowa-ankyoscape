- **千川上水の余り水と弁天様の湧き水〔聴取・ゲスト横山庸佼の発言・repo初出候補〕**: 旧平和小学校跡の項で「**（前方を指しながら）この先に千川上水っていうのがあって、あとで行くでしょうけれども。上水の余り水と弁天様の湧き水。今でも出てるって噂だけど。**」への武内千鶴子「**出てるらしいですよ。**」＝**千川上水の余り水・「弁天様」の湧き水が現在も出ているという口碑**〔A. 千早地域（豊島区西部・千川上水旧通水区域）における湧水の現存口碑＝[BLOG-067](../blogs/BLOG-067.md)（千早公園の残存湧水の2025年6月観察）と対照可能。B. 「弁天様」がどの弁天社を指すか（粟島神社〔弁天池で知られる〕か別の弁天か）は本テキストからは特定できない・「上水の余り水」の意味（放水路由来か伏流か）も断定しない〕
- **千早の十字路の沼地と3.11の地盤差〔聴取・観察・repo初出候補〕**: 同箇所で「**この辺、田んぼもあったのね。ここ（立っている十字路）なんか最後まで、家ができる頃まで、昭和28年ぐらいまではまだ沼地だったのね。3.11の地震ではこの通り、我が家も含めて他のとこはやられないのに、やっぱり沼地のところは地盤が弱いんだね。**」＝**①千早の十字路（付近）が家が建つ頃＝昭和28年（1953）ごろまで沼地だったという1950年代の地形記憶、②2011年3月11日地震で沼地だった場所のみ地盤が弱かったという被害の地点差の証言**〔低湿地記憶が宅地化期（1950年代中盤）まで遡る一次聴取・1936年空中写真判読（2026-11-08ノート群）の谷端川上流低地と対照可能〕
- **山手通り拡幅で消えた谷端川並行の一本道〔聴取・repo初出候補〕**: 「**山手通りが昔はもっと狭くて、道路の向こう側に家が立ち並んでいて…。谷端川との間にもう一本道があったんですよね。それを潰して全部家が向こう側に行っちゃったから。だからこの辺りっていうのは、子どもだったからよくは知らないけど、すんなり広げることができたと思うんですよね。空き地があったから。**」＝**山手通り拡幅時に谷端川との間にもう一本あった並行道路が潰され、家屋が道路の向こう側へ移ったという地形改変の証言**〔山手通り＝谷端川並行路の拡幅史（広幅員化）の民間側記憶。拡幅の時期（昭和40年代〈都市計画環六整理〉とみられるが本テキストに年代はない）の特定は外部資料待ちで断定しない〕
- **千早公園の地下防火水槽〔聴取・観察〕**: 「**ここ（公園）の地下が防火水槽になってるのね。７、８割。こっち側だけね。雪が降ると面白いですよ。防火水槽の上は…。**」→横山「**すぐ積もる。…向こう側は地面が冷えるまで積もらない。**」→千鶴子「**じゃあ、場所が特定できますね。**」→横山「**だから、ここからこっちが水槽だなってわかる。**」＋「**（以前は）廃棄物置場みたいになっていて評判が悪いところだった**」（千早公園の防火水槽・雪の積もり方の Observation）＝**千早公園（谷端川近傍）の地下防火水槽が敷地の7〜8割・片側のみを占め、雪の積もり方で水槽位置を特定できるという2019年時点の観察**〔防空・防火水槽の現代の残存利用の観察記録・谷端川流域の地下貯留系施設のdatapoint（水害施設ではなく防火水槽である点に注意）〕
- **意義〔観察〕**: ①**千川上水旧通水区域（千早）の湧水口碑・1950年代の沼地記憶・山手通りの拡幅断片・防火水槽の現状が、区のオーラルヒストリー事業の全文テキストとして一次記録化・公開されている**（聞き取り文言は「聴取」レベルで、文書確認ではなく口述の記憶である点を明示して扱う）。②「上水の余り水と弁天様の湧き水」は [GOV-496](GOV-496.md)（谷端川緑道整備・十カン計画）と同じ ADEAC「としまひすとりぃ」機関の映像系であり、**谷端川・千川上水の記憶の文字化資料の series**（わが街ひすとりぃ）の一レコードとして、[GOV-128](GOV-128.md)〜のオーラルヒストリー収録群に接続する。
