# [GOV-202] 常務委員会議事速記録 第2号・第3号 — 三河川改修の予算削減（1931・1932）

- **書誌〔確認〕**: 都市計画東京地方委員会『常務委員会議事速記録 第2号』（第三回常務委員会1931〔昭和6〕年7月28日開会を収録・[book/1264582](https://lab.ndl.go.jp/dl/book/1264582)）・『同 第3号』（第四回常務委員会1932〔昭和7〕年5月17日開会を収録・[book/1264593](https://lab.ndl.go.jp/dl/book/1264593)）。**すべての引用は同館OCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **第2号・第一次削減（1931-07-28）〔確認・repo初出・要照合〕**: 「立會川、神田上水、谷端川ノ改修事業ノ執行年割ヲ變更セムトスルモノ」＝三河川合計経費「**五百貳拾萬圓**（対照表の計5,209,000円）」を、昭和5年度に約6万9千円の不用額が生じたことと「**材料費等ノ物價下落**ニ伴ヒマシテ六年度ニ於テ貳拾貳萬四千圓計リヲ減額致シマシテ**總工費ヲ四百九拾壹萬五千圓ニ減額**」（対照表4,915,441円）。**昭和恐慌後のデフレ（物価下落）を理由とする河川改修予算の削減決定**。
- **第2号・質疑応答〔確認・要照合〕**: 中村梅吉（9番）「**金額ヲ減ジナイデ工事ヲソレダケ進メテ行クコトハ出來ナイノカ**」→事務官西村輝一「事業ヲ進メマスコトハ宜シイト思ヒマスガ**財政上ノ都合ガアリマシテ**…歲出ノ方モ落サナケレバナラナイト云フコト」＝**緊縮財政下で工事を前倒しできない事情を幹事が説明した応答**。
- **第3号・第二次削減（1932-05-17）〔確認・repo初出・要照合〕**: 「此ノ三河川改修總經費ハ四百九十一萬五千圓デアリマシテ」→昭和6年度に約19万円・昭和7年度の年割額で約29万円を節約し「**合セテ四十八萬圓ヲ減額致シマシテ總事業費ハ四百四十三萬圓バカリニ更メマシタ**」（対照表4,915,441→4,434,249円台）・「**事業ノ計畫等ニハ何等變更ハ無イノデアリマス**」＝計画不変のまま予算だけの削減。備考に昭和6年度減額714,694円49＝翌年度繰越513,742円18＋不用額200,952円31、昭和7年度増額232,502円18＝前年度繰越し＋予算節減額289,249円の差引、の内訳。
- **位置づけ〔観察〕**: [GOV-159](GOV-159.md)（1930決定・520万9千円・4箇年）→**本号2冊（1931-07・1932-05の2段階削減で443万円台）**→[GOV-201](GOV-201.md)（1934・計画変更で+120万円・563万円台）→[GOV-161](GOV-161.md)（1935・昭和11年度まで）→[GOV-203](GOV-203.md)（1936・昭和12年度まで）という**三河川改修予算変遷の欠けていた1931〜32年の減額段階を埋める記録**。[GOV-161](GOV-161.md)の「520万9千円から約42万円増額」という表現の間の推移が本号で確認できる（563万0722円−520万9000円≈42万1722円）。

## 制限・未解決

- ①対照表のOCR数値は列崩れがあり、各年の金額・歩合の正確な値は要照合（計額5,209,000円・4,915,441円・4,434,249円は[GOV-201](GOV-201.md)の4,434,249円と整合するが、細目は未確定）。②削減の告示番号・告示日は本2冊のOCRでは未確認。③議案番号（常委議第○号）は第3号で「次ニ常委議第二十七號」と続くことから26号前後と推定されるが未確定。
