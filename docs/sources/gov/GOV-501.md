- **講演要旨本文の文言群〔確認: 上記アーカイブ本文の直接引用〕**:
  - ①**田無・保谷の上水と江戸の区別**: 「今西東京市がある場所には、江戸時代には**田無村、上保谷村、下保谷村といくつかの新田集落**があり、農民が住んでいました。ここで重要なのが、**田無・保谷は、「江戸」の中には含まれていない**ということです」＋「田無は1700年ごろに分水が通り、1710年以降には田無・保谷を含む北多摩地域が「江戸向けの野菜を作る土地」として盛んに開発されるようになった」＋「**田無地域は田無分水、保谷地域は関野分水を利用**していました。人々は水門を設置して取水量を調整し、水道管にあたる木樋(もくひ)を作って、上手に水を村まで引いていきました」＝**田無分水と関野分水の 村割対応（田無＝田無分水・保谷＝関野分水）の明文化**〔READMEに「関野分水」の語は初出。関野新田（村名）は[GAZ-064](../gazetteers/GAZ-064.md)等で既出〕。
  - ②**「村あたり年1両」の水料金**: 「この水は本来、江戸の人々が使うためのものでしたから、タダでは使えませんでした。「水道料金」が発生したのです。**1年あたり1両で、これは村ごとに払う決まり**でした」＋「**使う水の量に関係なく1村あたり年1両**と決められていました」＋「江戸時代初期の1両は現在の価値にしておよそ10万円くらいに、中・後期の1両は4～6万円くらいになったと考えられています」＝**使用量無関係の定額制（村あたり年1両）の一次説明**。
  - ③**上保谷新田の水車裁判（関野分水）**: 「**上保谷新田は19世紀前半、水車を作るために関野分水の流れる道筋を勝手に変更し、下流にある関前新田と二度も裁判**になっています。川はつながっているため、上流の村が川に何かしら手を加えると、下流の村に大きな影響が及ぶのです。**この時の裁判では、いずれも関前新田に水が流れなくなったことが重く見られ、設置された水車は取り払われました**」＝**上流側の流路変更×下流への断水×敗訴（敗訴側の[上保谷新田]・下流側の[関前新田]）×水車取り払いという一連の「記事で読める実体」を伴う文言**〔解説本文に付された図版キャプション「田無村にあった水車の記録 安永9年（1780）／表紙」も確認〕。
  - ④**羽村→江戸の水量半減の幕府調査**: 「**1770年頃の幕府の調査によると、羽村で玉川上水に流れ込んだ水は、江戸に届くまでに半分以下の量**になっていました。玉川上水が運ぶ水の多くが、分水を利用する村々によって消費されていた」＝**1770年頃の幕府実測文言**。
  - ⑤**水門「三分明け」「二分明け」と下田半兵衛の願い書き**: 「この状況を見た幕府は、玉川上水の分水を利用する村々に対して**水門を「三分明け」にするように命じました。水門の開け具合を全開時の30%にする**こと」＋「**安政3年(1856)4月に玉川上水の水量が減ると、幕府は上水沿いの村々に水門の「二分明け」を命じました。三分明けであった水門をさらに閉じるように命じたのです**」＋「このとき、多くの人口を抱えていた田無村は水不足による生活の危機におちいりました。そこで**田無村の名主(名主とはその村の責任者、トップのこと。)である下田半兵衛は、水門を元の三分明けに戻すよう、幕府に願い書きを出しました**」＋「**西東京市中央図書館には、その願い書きの清書と、下書きの史料の紙焼きが保管**されており、村の責任者が願い書きを書くときにどのような部分の記述を重視していたのかがよくわかります」＋「**2か月後の6月には幕府よりいったん三分明けに戻すことが許可され、その2年後には三分明けの状態を当面の間維持することが許可**されています」＝**水門規制の運用（三分明け→安政3年の二分明け→6月に三分明け復帰→2年後に当面維持許可）と、田無村名主下田半兵衛の願い書き（清書・下書き紙焼き＝西東京市中央図書館所蔵）の存在の一次文言**〔ページに「名主・下田半兵衛の名前で出された水門三分明けの願い書き（清書）安政3年（1856）／冒頭」の図版キャプションあり〕。
- **意義〔観察〕**: ①**分水の村割対応（田無＝田無分水・保谷＝関野分水）と村あたり年1両の定額課金を、西東京市図書館が一般向けに明文化した公式資料**＝千川上水系水課金の比較基準（「千川上水は村高割」等の既存整理）に玉川上水分水側の並行事例を対校できる。②**関野分水の水争いの実体**＝上流の流路変更→下流断水→二度の裁判→水車取り払い、という流路の下流影響を伴う水車紛争の一般資料レベルの一次説明＝repoが多く集めてきた千川上水系水車（[BLOG-096](../blogs/BLOG-096.md)上保谷新田の水車・[GOV-100](GOV-100.md)薩摩芋水車・BOOK-238保谷の水車仲間側）と**同一市域（西東京市＝旧保谷村域）で同時代の水車紛争を扱う比較資料**。③**下田半兵衛の願い書きの現物（清書・下書き紙焼き）が西東京市中央図書館に保管されているという所在文言**＝アーカイブ探索の新たな一次資料所在。
