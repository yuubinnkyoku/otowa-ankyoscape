# [GOV-139] 技術調査年報2010年版・流域下水道オゾン処理設備調査〔repo初出〕

- **書誌〔確認: Wayback保存版PDF全文取得〕**: 東京都下水道局『**技術調査年報 -2010-**』（奥付「**平成23年2月 東京都下水道局**」）所収、**4-(1)-2**。濱本亜希・富田雅昭（**流域下水道本部 技術部 施設管理課**）「**流域下水道オゾン処理設備調査**」（要旨集＋本文「４．資源の有効利用（１）処理水再利用技術」内）。調査実施年度＝**平成21年度**・処理区名＝多摩川上流処理区・区分＝調査研究。原本PDFは〔[オープンデータURL](https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2010all.pdf)・直接403のため、[Wayback保存版 2024-07-08スナップショット](https://web.archive.org/web/20240708072731/https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2010all.pdf)（完全版21,639,018バイト・Range分割取得）で全文確認〕。
- **清流復活事業の処理水質史〔確認: 本文「1 はじめに」〕**: 「下水道局は環境局と協力し、**昭和59年から、水が枯渇した野火止用水、玉川上水、千川上水に多摩川上流水再生センターの下水処理水を順次送水**することで清流を復活させた（以下清流復活事業という）。**当初は二次処理水を砂ろ過した水を送っていたが、近隣住民から臭気、色等の改善を求められたことから、平成3年からは凝集剤（PAC）を添加し、砂ろ過後にオゾン処理を施した水を1日24,800m³送水している**。」〔確認: 本文文言の抽出〕。**清流復活事業の開始を「昭和59年（1984）から」と記し、野火止用水・玉川上水・千川上水の順次送水と明記する行政技術資料**として、README既述の「1989年3月千川上水通水（建設局）」「2012年都議会答弁（3水路合計約25,000m³/日）」に**事業起点と水質改善の経緯**を付け加える〔観察〕。
- **設備更新の背景〔確認: 本文〕**: 「当該オゾン処理設備は**稼働後19年を経過し更新時期**を迎えている」ことから、清流復活事業におけるオゾン処理の必要性と適正なオゾン注入率の確認を目的に調査を実施。**本調査は環境局の依頼により実施**したと明記〔確認〕。オゾン処理設備の稼働開始は**平成3年5月**（要旨）〔確認: 要旨文言〕。
- **水処理施設の概要〔確認: 本文「2 清流復活事業に係る水処理施設の概要」〕**: 二次処理水は**PAC添加（注入率3〜6mg/L）→砂ろ過→オゾン処理**されて玉川上水等に送水。**砂ろ過施設は処理能力900m³/日/槽の移床式上向流連続式ろ過槽48基**。**オゾン反応槽は直列2槽方式**で、発生オゾンを後段反応槽で曝気し排オゾンを前段に戻す循環により吸収効率を高め、**循環オゾン濃度1.3gO3/Nm³を目標に制御（オゾン注入率3mgO3/L相当）**〔確認: 本文・表1〕。表1にオゾン発生装置（発生方式＝無声放電・発生量18kgO3/h）、散気筒（気孔径100μm・筒数276本）、反応槽有効水深4.7m等の仕様〔確認: 表1の抽出値。一部数値の配置は要原本判読〕。二次処理水導水管（口径700mm・距離8.55km）の図中言及あり〔確認: 図1処理フロー〕。
- **水質調査の結果〔確認: 本文・要旨〕**: オゾン注入率1・3（現行）・5・6.5mgO3/Lの4条件（要旨は処理水量一定24,800m³/日・滞留時間28分、本文は調査時処理水量一定1,000m³/時・オゾン反応槽滞留時間約30分と記す〔文言差は要原本再確認〕）で実施。**臭気は砂ろ過（PAC添加）だけでは除去されず、オゾン処理により最大41%低減**、**色は砂ろ過で約50%除去、オゾン処理で最大89%除去**、**1,4-ジオキサンにもオゾン処理による除去効果を確認**〔確認: 本文・要旨〕。
- **位置づけ〔観察〕**: 千川上水の再生水（README既述：1971年通水停止→1989年3月清流復活→善福寺川導水0.1m³/s）について、**その水質処理の制度史（当初砂ろ過→住民要望→H3からPAC＋オゾン）と送水量24,800m³/日（3水路合計）・施設仕様**を、下水道局自身の技術資料が記録する。**「千川上水」は水が枯渇した対象水路として玉川上水・野火止用水と並んで明記される**〔確認〕。多摩川上流水再生センターから千川上水までの導水経路・千川上水内の流量配分は本文にない〔未解決〕。

## 制限・未解決

- ①本文PDFは2段組スキャン＋テキスト層で、表1の数値配置の一部は要原本判読。②要旨（24,800m³/日・HRT28分）と本文（1,000m³/時・HRT約30分）の処理水量文言の関係は未整理（送水量と調査流量の区別の可能性）。③千川上水への導水量単独の記載は本文になし。④オゾン設備更新の実際の竣工・更新方式（2010年以降）は本文になく、後続の年報等で追跡要。⑤年報全体のうち他記事に谷端川・千川上水・弦巻川・水窪川への言及は4-(1)-2以外に確認できなかった（陰性記録）。
