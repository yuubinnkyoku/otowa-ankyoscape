# [GOV-339] 東京都史蹟名勝天然紀念物（旧市域内・1943）— 「千川上水阯」条の都版公式概説〔第147回〕

- **書誌〔確認〕**: 東京都編『東京都史蹟名勝天然紀念物 : 旧市域内』（**東京都・1943年**。請求記号特277-63・書誌ID000000792073。NDL次世代デジタルライブラリー [book/1150320](https://lab.ndl.go.jp/dl/book/1150320)）。旧東京市域内の史蹟・名勝・天然紀念物を町名ごとに立項して解説する**都編纂の公式案内**。庚申塚・護国寺・鬼子母神等の条と並んで**「千川上水阯」の独立項目が存在する**（第117回で所在を確認した同条のfulltext確認・資料化）。
- **「千川上水阯」条＝沿革と流路の概説〔確認・文言候補・OCR高度崩れ〕**: 「**千川上水阯 …始め元祿九年、（小聖堂?＝湯島聖堂のOCR崩れ候補）…享保…明和六年再起したりしも 不便の爲 天明六年遂（廃止?）…一、ニ三丁目を北流して 朧野入（滝野川に入のOCR崩れ候補）に …一つは東流して谷端川となり、暗渠となりる**」＝**①千川上水の沿革を元禄9年起り→享保（停止）→明和6年再起→天明6年遂に（廃止）とする都版公式の概説、②流路の一つが（滝野川に）北流し、**一つは東流して谷端川となり、暗渠となった**とする分岐説の文言**。〔**①の沿革系列（元禄9年起り・享保停止・明和6年再起・天明6年廃止）は既存の通説系（[GOV-171](GOV-171.md)元禄9年説・[BOOK-157](../books/BOOK-157.md)武江年表の享保7年停止・[GAZ-049](../gazetteers/GAZ-049.md)御府内備考の明和〜天明系列）を1943年の都版公式案内がまとめて採用した記録。**②の「東流して谷端川となり」＝千川上水の一支流が谷端川に東流して注いだ（あるいは谷端川の水源となった）とする解釈の1943年公式文言候補**＝谷端川の水源論（千川上水分岐説）の都版側の datapoint（[GOV-337](GOV-337.md)高田町現状調査の谷端川系統・[GOV-207](GOV-207.md)水道事業年報の谷端川排水区と対照）。**該当条はOCRの高度崩れがあり、文言の正確な復元（「朧野入」「小聖堂」「天明六年遂」の直後語・条の範囲）は原画像照合を要する**。〕
- **立項の意義〔確認〕**: 千川上水跡が**1943年時点で旧市域内の「史蹟名勝天然紀念物」の案内対象として独立立項されていた**ことは、千川上水跡の公的な認知（遺構の保存・案内表示の有無は本書からは不明）の程度を示す背景記録。〔既存の千川上水の官方記録群（[GOV-171](GOV-171.md)〜[GOV-180](GOV-180.md)の沿革系・[BOOK-126](../books/BOOK-126.md)区史）に、都の史蹟名勝案内という行政広報側のジャンルでの言及を加える。立項と同時代の都の指定（史蹟名勝指定）の有無の照合は未了。〕
