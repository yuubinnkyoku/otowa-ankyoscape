# [GOV-270] 神田玉川上水留 文久3年 — 御三卿屋形と江戸城内・市中末端への玉川上水給水の実務

- **書誌〔確認〕**: 『神田玉川上水留』文久三亥年五月ヨリ十月マデ分冊ノ二 [book/2587518](https://lab.ndl.go.jp/dl/book/2587518)・分冊ノ三 [book/2587519](https://lab.ndl.go.jp/dl/book/2587519)＝[GOV-268](GOV-268.md)と同一の冊。**第120回の[GOV-268](GOV-268.md)登録時の制限⑤（その他の内容の未精読）を本ファイルで精読した分**。**引用文言はすべてOCR由来で要原文照合。**
- **田安屋形掛の玉川上水極枡の絵図面つき伏替修復〔確認・repo初出〕**: 「**田安屋形掛代官町土手上玉川上水極枡絵図面来引之通伏替修復いたし度候御差支も無之候はゝ明後十九日雨天日送致水留候間御支配向立合有之候様致度尤一日限相済候ニ付御断返御達有申候依之絵図面相添此段及御掛合候**」（八月十七日）→御作事奉行側の答「**拙者共方差支無之候尤同日支配向本留為立合差出可申候 被遣候絵図面留置**」＝
  - **江戸城代官町土手上の田安（徳川）屋形に給水する玉川上水の「極枡」（末端の枡）を絵図面を添えて伏替修復**し、文久3年8月19日に**一日限りの水留（断水）**をかけて実施した記録＝御三卿屋形への給水末端の維持の実務（御作事奉行衆の立合い・修復後は「御断返御達」＝通水再開の届出）。
  - 宛名の「**御作事奉行衆 坂井右近将監殿 松平対馬守殿 田沢対馬守**」＝幕末期の作事奉行の実名群（[GOV-268](GOV-268.md)の助水行政の宛名群と同じ冊内で対校できる・周辺）。
- **一橋屋形掛の玉川上水樋枡伏替〔確認・repo初出の城内給水樋の経路文言〕**: 「**一橋屋形掛玉川上水竹橋御門内大番所前芝間出掛并右御門御橋台下樋ゟ平川口前通屋形西切抜外埋榊迄樋枡伏替ニ付明後三日ゟ取掛候間右普請中御断返まて此段御達申候**」（十月朔日）＋「**玉川上水一橋屋形掛竹橋御門大番所前芝地掛ゟ同所御橋下潜樋屋形西門前迄但筋明三日ゟ修復取掛候ニ付御門番え御断有之候様存候**」（十月二日）＝
  - **一橋（徳川）屋形への玉川上水の給水樋（竹橋御門内大番所前芝間の出掛け〜御橋台下の潜樋〜平川口前通〜屋形西切抜〜外埋の榊まで）を伏替**し、10月3日から**3日間の御断返（断水）**・竹橋御門・一橋御門の門番への届出＝**江戸城竹橋御門内から平川口前を通って一橋屋形西門に至る給水樋の経路**の一次記録（「平川口前」は江戸城平川門付近と読めるが断定しない・「筋明」の割付は要照合）。
  - 普請中は「**御普請方同心壱人 地割棟梁壱人詰切候様いたし度候尤普請中石場所江箱番屋諸色等差置**」＝立会と資材置場の設置（樋枡伏替の修復現場の実務）。
