# [GOV-016] 『千川用水組合村々樋口伏替願』（1877年7月6日、杉並区指定有形文化財・星野家文書）

## 書誌・公開状況（2026-10-27、ADEAC 目録ページの直接確認・ai）

- 資料名：千川用水組合村々樋口伏替願。資料名よみ：センカワヨウスイクミアイムラムラヒグチフシカエネガイ。
- 年月日：1877年7月6日（明治10年7月6日）。時代：明治。
- 差出人・作成者名：15か村村々役人・惣代連名、水路見守人千川善蔵、第八大区七小区戸長岩佐満房。
- 受取人名：東京府知事 楠本正隆殿。
- 数量：1冊。形態：竪帳。材質：紙。
- 大分類：歴史。中分類：古文書。資料群名：星野家文書。分類番号：G3。
- 資料番号：mus-002479。指定登録種別：杉並区指定有形文化財（古文書） 平成23年度。
- 所在地：東京都杉並区大宮1-20-8 杉並区立郷土博物館。所蔵機関：杉並区 地域の学び推進課。
- ADEAC 目録ページ：https://adeac.jp/suginami-city/catalog/mus-002479?from=search
- NDLサーチの対応レコード：https://ndlsearch.ndl.go.jp/books/R100000094-I1542114 （1877年7月6日、杉並区デジタルアーカイブ（ADEAC）と連携する旨の表示あり。NDLサーチ上に原文画像の公開はない。）
- 公開解説（ADEAC 目録ページの記載）：星野家は江戸時代初期から上井草地域に居住していた旧家で、文書の多くは星野紋左衛門が戸長を務めた明治10・20年代に集中する旨、および文書群の概要は「平成23年度指定登録文化財調査報告」『平成23年度 杉並区文化財年報・研究紀要』（2013年）を参照されたい旨が記される。
- 翻刻の所在（ADEAC 目録ページの「翻刻」欄の記載）：『星野家文書 千川用水関係史料（文化財シリーズ29）』22〜25頁。史料名は「千川用水関係書類」と記載される。

- 長崎村地内項目の寸法・代表名（2026-10-27、ブラウザ目視読取・ai。cycle 15 補記）：寸法は「幅六寸五分、高六寸三分」と読めるとの報告に訂正された（従来の「幅三寸五分」は幅の初字の読みの訂正。幅の「六」は他の数字より確信度が一段低いため確定値としては扱わない）。同項目の末尾側の名列として「村代表相沢市左衛門」と読めるとの報告が確認された。
- 24頁下部の指令列（2026-10-27、ブラウザ目視読取・ai。cycle 15 補記。要約のみ）：合計・寸積の列と「東京府知事 楠本正隆殿」「第千九百五拾九号」「指令」などの列、および「水路守人 千川喜蔵」と読める列があるとの報告があった。25頁上部にも表が続くため最終結尾とは断定せず、目録の差出人欄の「水路見守人千川善蔵」との関係は未解決として同一視しない。22頁願文本文の中間列は大部分が判読できず、願文内での宛先・連署者名の区切りも判読できなかったため、宛先・差出人については目録情報の扱いのままとする。
