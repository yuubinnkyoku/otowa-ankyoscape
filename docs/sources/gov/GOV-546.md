# [GOV-546] 建通新聞・神田川中流部調節池の基礎調査報道〔高戸橋～駒塚橋・約30.9万m³の新調節池計画の業界紙2本〕

- **書誌①〔確認: 建通新聞電子版記事本文全文・2026-11-23取得〕**: 建通新聞電子版「**パシコンで基礎調査 神田川中流部の調節池新設**」（東京・**2025/12/15 13:54配信・【2025/12/16 東京版に掲載】**） https://digital.kentsu.co.jp/articles/artcl_rglr/01KC8PCR03PAXSBHJANRZVB1AH 〔本文全文を直接取得〕。
- **建通本文の文言〔確認〕**: 「東京都は**神田川中流部へ新たに設ける調節池の基礎調査業務をパシフィックコンサルタンツ（千代田区）に委託**した。**地下トンネル式で約30万９０００立方㍍の容量を確保する計画**の下、気候変動の影響などを踏まえた複数のルートを比較検討して事業全体の概略工程や概算事業費を考える。**２０２６年３月13日までに成果を得て**、事業化に向けた関係機関協議に生かす」「**23年３月の神田川流域河川整備計画**で**新宿区西早稲田３丁目（高戸橋）～文京区目白台１丁目（駒塚橋）の中流部区間に調節池を整備する**こととし、**23年度にパシフィックコンサルタンツで前段の基礎調査業務を実施**していた。また、同社は気候変動を踏まえて神田川流域の河川整備計画の調査と治水対策の検討を行う業務も受託している」「今回の基礎調査業務では、**過年度の委託で整理した候補ルートの一つ**について、気候変動の影響を踏まえて算出した流出解析結果を基にトンネルのルートと規模を**再整理**する他、**別途４ケースの候補ルートを追加検討**。また、これら**５ケース**のそれぞれで▽取排水施設▽換気施設▽監視制御施設▽資機材・車両などの出搬入施設▽電気・機械設備▽管理棟―といった**主要施設の構成や諸元を整理**するとともに、配置に関する概略検討を行う。その上で**事業全体の概略工程や期間、概算事業費を考えて関係機関との協議資料を作る**」。神田川の説明＝「三鷹市の井の頭池から善福寺川や妙正寺川を合流するなどして中央区と台東区の区界で隅田川に注ぐ**延長約24・６㌔、流域面積約１０５平方㌔の一級河川**」。
