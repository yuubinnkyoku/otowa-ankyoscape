# [GOV-233] 神田上水留（文久2年）— 白堀通の潰水・浅水と再修の入札記録

- **書誌〔確認〕**: 『神田上水留』（同題62冊・[GOV-232](GOV-232.md)書誌参照）。文久2年（1862）の白堀通再修の件は[33]〜[37]（[book/2587488](https://lab.ndl.go.jp/dl/book/2587488)〜[book/2587492](https://lab.ndl.go.jp/dl/book/2587492)）の5冊に収録（同一事件の関係冊）。本ファイルの内容は[33]（2587488）のOCR全文精読による。**引用文言はすべてOCR由来で要原文照合。**
- **区間の文言〔確認・repo初出〕**: 普請区間が「**音羽町九丁目橋上之方ゟ小石川牛天神下水戸殿屋敷際迄**」と記される＝**白堀通の上流端が「音羽町九丁目橋」の上方（上之方）に達する**ことの幕府側の明記〔[GAZ-050](../gazetteers/GAZ-050.md)（沿革図書十二之二）の大縄地目録「白堀端通音羽町九町目橋」・[BOOK-129](../books/BOOK-129.md)（橋梁篇）宝暦10年の音羽町九丁目橋修理・[GAZ-035](../gazetteers/GAZ-035.md)の九丁目橋（小日向水道町持ち・神田御上水に架かる）と整合する方向の文言〕。**白堀（神田上水堀）の上流端が音羽町九丁目橋まで及ぶか（金剛寺橋との関係）は原文照合後に判断**。
- **潰水・浅水の実態〔確認・repo初出〕**: 弘化の普請（[GOV-232](GOV-232.md)）後の**潰水・浅水**が問題とされた文言——堀内の水面が低地に対して我低く（「堀内水面比我低地」と読めるOCR文言・要照合）、土手内の土が洗い流される（「土手内土洗流し」と読める文言）等の**白堀通の通水不良・土手侵食の指摘**。**弘化3年（1846）の大規模修復から16年で再修が必要だった経緯**を記す。
- **入札〔確認〕**: 再修の入札で**落札直段545両**（と読める文言・要照合）。請負人名は本精読では未抽出。
- **「荒落谷下組合橋」〔OCR不明箇所〕**: 文中に「荒落谷下組合橋」と読める箇所あり（字形不明・「荒落谷」は近隣の谷名か組合名か特定できず原文照合課題）。
- **〔2026-11-15第114回追記〕[37]（2587492）の精読＝桜木町大下の渡石樋の再修・見守の引渡記録〔確認・repo初出〕**:
  - **入札文言の区間**: [33]（2587488）「此度神田上水白堀通**音羽九丁目桜木町ゟ牛天神下水戸殿屋敷際迄**土手内**余乗板**其外御普請入札申渡候間入念積り立来る五日四時入札持参可致候」＝**入札文言の区間の上流端が「音羽九丁目桜木町」**（区間文言の変種・「余乗板」の表記）。[33]の仕様注文に「音羽町九丁目町屋前通土手内一同長延三拾壱間・桜木町町屋前通并水道町町屋前通共両側共手内…」の区間内訳。
  - **桜木町大下の渡石樋の再修**: [33]「**桜木町大水上一渡石極(樋) 内棹(挾?)長七間宿(幅?)九尺五寸高五郎(尺)**…」＋[37]「**承ヶ谷大下水上一渡石樋 内秤長七間 酒(幅)九尺五寸高五尺七寸 右仕様土台之儘差置 其外仕様前(は?)内料に同断 同所廻り両側一参(矢)来長寿(拾?)三拾間 右仕様前矢来に同断 但弐ヶ所共両袖矢来下土台栗押五寸角ニ而仕付 水道町町屋後一石垣長拾五間…**」＝**文久2年の再修でも桜木町大下の渡石樋（長7間・幅9尺5寸・高5尺7寸のOCR文言）と両側の矢来30間ずつ・水道町側の石垣15間が修復対象**＝[GOV-232](GOV-232.md)第114回追記の弘化3〜4年の渡石樋修復と**同じ交差構造（桜木町大下×鼠ヶ谷大下）の16年後の再修**。「承ヶ谷」は鼠ヶ谷のOCR変種（[GOV-232](GOV-232.md)の「鼠ヶ谷」・同冊[33]の「荒ヶ谷大分(下?)水上渡石樋廻り一矢来長延三拾間」とあわせ**鼠ヶ谷のOCR表記の変種群**: 鼠ヶ谷／荒ヶ谷／承ヶ谷・原字形照合課題）。
  - **「荒落谷下組合橋」の解消〔観察・候補〕**: 制限に挙げた「荒落谷下組合橋」の「荒落谷」は、[33]の「荒ヶ谷大下」と同じ**鼠ヶ谷大下のOCR崩れである可能性が強い**（「荒ヶ谷大下組合橋」＝鼠ヶ谷大下の組合の橋か）。原字形照合まで断定しない。
  - **出来形の町屋別列挙**: [37]「壱羽町九丁目町屋朱引之通**余三万板(余乗板?)御普請出来**いたし…桜木町朱星之通**丸太矢来御普請出来**いたし候 町屋還国寺…」＋[33]「音羽町九丁目町屋…丸太矢来仕直候積…水道町町屋…同道…桜木町町屋朱引之通余乗板御普請之積候」＝**文久2年の出来形・積立が音羽9丁目・水道町・桜木町の町屋単位で列挙**される（余乗板普請と丸太矢来の出来形の分担の記録）。
  - **見守・水番人の引渡記録**: [37]「二月廿七日晴 一当御場所出来形心除(?)之儀無之旨…**覚 川除屋敷前并桜木町一矢来木戸川建弐ツ 水戸殿屋敷後牛天神下一同木戸門一ツ 水番人小兵衛 見守武兵衛 右之通小屋場ニおゐて預ケ置候**」＝**文久2年2月27日、桜木町の矢来・木戸2ヶ所と牛天神下の木戸門1ヶ所を、水番人小兵衛・見守武兵衛（[GOV-235](GOV-235.md)・[GOV-236](GOV-236.md)の見守武兵衛と同姓候補）に小屋場で引き渡した記録**＝白堀通の見守制度（巡視・芥留）の文久2年の実運用の裏付け。
- **位置づけ〔観察〕**: ①文久2年時点でも白堀通が通水路として修復対象であり、その上流端が音羽町九丁目橋の上方であること、②弘化→文久の16年周期の大規模修復の存在、を幕府の一次記録で裏付ける。文久2年（1862）は神田上水の廃止（明治2年の大下水化・[BOOK-123](../books/BOOK-123.md)・[GOV-237](GOV-237.md)）の7年前にあたり、**幕末の白堀通の機能縮小直前の整備記録**として[GOV-232](GOV-232.md)・[GOV-237](GOV-237.md)の間を埋める。**〔第114回追記〕③弘化・文久の両普請がともに桜木町大下×鼠ヶ谷大下の渡石樋と矢来を修復対象に含める**＝音羽谷底の交差構造が白堀通の維持の継続的な焦点だったことの一次記録側の裏付け（[GOV-232](GOV-232.md)第114回追記参照）。
