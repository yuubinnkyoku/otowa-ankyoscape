# [GOV-334] 神田上水留 分冊ノ一（明治2年）— 井の頭の刈所・土留柵修復と弁天社・聖天社廻りの石橋〔第144回〕

- **書誌〔確認〕**: 『神田上水留』分冊ノ一（表紙文言候補「**明治二己年ヨリ神田上水留分冊ノ一**」）。NDL次世代デジタルライブラリー [book/2587514](https://lab.ndl.go.jp/dl/book/2587514)。神田上水の帳簿群（[GOV-247](GOV-247.md)・[GOV-249](GOV-249.md)『神田玉川上水留』明治2年正月・9月の兄弟冊）に続く明治2〜3年系統の分冊。**OCR崩れが激しく、文言・数値はすべて原画像照合を要する。**
- **件名文言候補〔確認〕**: 「**神田上水源井之頭…刈所并土…柵御修復一件 土木…上水方**」＝**神田上水の水源（井の頭）の刈所（草刈所か）と土留柵の修復を「一件」として上水方の行政で処理した帳簿**＝**明治2年（1869）の時点でも神田上水の水源・頭部が管理・修復の対象だった**行政記録（神田上水の府内給水廃止〔明治33/34年説の対立は既存整理〕より前の明治初年の管理実態）。
- **井之頭池の弁天社・聖天社廻りの石橋群〔文言候補〕**: 「**井之頭池弁天社（仕）廻り東之方石橋…聖天石橋迄 同石橋…同所続石橋迄…弁天前石橋迄…聖天社廻り…一相詰長延七拾六間…**」＝**井の頭池の弁天社（池中島の弁天堂）・聖天社の廻りの石橋群（数本の石橋の継ぎ目・延長計76間超）の修復部材の明細**（松木140分宛3人・杉木3挺半・杭木・折釘等の部材名と歩・貫・斗の数量、桑畠の坪数が列挙される）。〔**井の頭池の弁天堂参道の石橋の存在と規模を部材レベルで記す明治初年の一次記録**＝池島の結線（現在の弁天橋系統）の明治期の実態の資料。「聖天社」の比定（井の頭周辺の聖天堂か）は周辺知識からの推定にとどめ、原典の図面・地名の照合を要する〕
- **品川県支配の文言〔文言候補・注記〕**: 「**品川県支配所 武州多摩郡…寺村地内 吉祥寺村六ヶ所**」＝**修復地が「品川県支配所 武州多摩郡吉祥寺村」地内と記される**＝**明治2年時点の井の頭（神田上水源）の行政所属が品川県（明治元年〜2年の武蔵国多摩郡の管轄県）であることの帳簿側の文言**（同年11月の品川県廃止・多摩郡の神奈川県移管〔知事県・岡田県等を経る多摩郡管轄変遷の整理〕より前の時点の帰属記録として、井の頭の明治初年の行政史の資料。県名・村名の正確な字面は要照合）。
