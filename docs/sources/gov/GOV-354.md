# [GOV-354] 天明撰要類集 [51] 火之部 — 千川上水の小屋場と駈付人足の帳簿

- **書誌〔確認〕**: 『天明撰要類集』[51] 二十上 火之部（天明期の出火・火消人足の行政事例綴・[GOV-215](GOV-215.md)（同[49]）・[GOV-353](GOV-353.md)（同[22]）と同シリーズの未登録冊）。NDL次世代デジタルライブラリー [book/2572900](https://lab.ndl.go.jp/dl/book/2572900)。**引用文言はすべてOCR由来で要原文照合**。
- **牢屋敷・千川上水の駈付人足相止〔確認・repo初出の小屋場文言〕**: 目録に「**牢屋敷千川上水幷御修復中橋々え駈付人足相止候義信濃守え諸之事**」の項目があり、本文（天明6午年の町火消人足の削減・駈付体制の伺書群）に——「**牢屋敷一千川上水一海賊橋松屋橋石出帯刀呼出達御向方取計…千川上水小屋場駈付人足之義は拙者方に内可申渡候 午三月 山村信濃守**」〔**①牢屋敷・千川上水・御修復中の橋々（海賊橋・松屋橋等）への駈付（出火時の人足駆付け）体制の見直しの項目群の中に千川上水の小屋場が含まれること、②千川上水小屋場の駈付人足の申渡が山村信濃守（御普請奉行・町奉行）の管轄であること**〕〔**「千川上水小屋場」＝千川上水の普請・維持の作業小屋場（[GOV-215](GOV-215.md)の請負人・[GOV-353](GOV-353.md)の堀割御普請の実務拠点候補）が天明6年3月時点で現存し、火消人足の駈付先として行政的に把握されていた記録＝**天明6年の上水差止（[GOV-215](GOV-215.md)〜[GOV-218](GOV-218.md)の8月出浅取立→閏10月差止）と同年の小屋場の存在の併記**（小屋場の位置・規模は本文にない）**。
- **「千川上水定小屋」の人足リスト〔確認・文言候補〕**: 同人足削減リストに「**千川上水定小屋〆五千六百八十九人…**」と見える行がある（前後は町火消の総数・減数の表で列崩れあり）〔**「千川上水定小屋」（定常の小屋）の語の用例**。数値の行対応はOCR列崩れのため数値自体の採用は不可。「〆」以下の構成は原画像照合が前提〕。周辺に「**吹上懸り上水御修復小屋場駈付人足**」「舟越橋松屋橋御修復小屋場」等の同型文言があり、御普請・御修復の小屋場への人足の駈付・削減が天明6年に一斉に整理されたことが分かる。
- **位置づけ〔観察〕**: 千川上水の天明期の施設（小屋場・定小屋）が、火消・人足行政の帳簿に「牢屋敷」等の公的施設と並んで扱われていた観察。上水の請負人（[GOV-215](GOV-215.md)）・堀割普請（[GOV-353](GOV-353.md)）に続き、普請実務の現場拠点の存在を裏付ける。
- **第220回追記〔確認・別本対校〕**: NDL次世代デジタルライブラリーに同型の編纂集として『安永撰要類集』[42] 二十ノ上 火之部（写・[book/2549844](https://lab.ndl.go.jp/dl/book/2549844)）・[43] 二十ノ中 火之部（写・[book/2549845](https://lab.ndl.go.jp/dl/book/2549845)）があり、[42]のOCRは本冊（天明撰要類集[51]）と同一構成の出火・火消人足行政の記事群を含む。その人数表で本冊の「**千川上水定小屋〆五千六百八十九人…**」に対応する行が「**千川上水定小屋〆五千六百八拾九人 七 四千三百八拾九人減 臨時駈附幷持退之分一弐百三拾九人増**」と判読できる＝**定小屋の人数表（〆5,689人・減4,389人・臨時駈附幷持退分239人増）の数値の判読更新候補**。同じ頁群に「**水道橋際上水樋右八百人減 一四百三拾八人 巳〔判読保留〕三百三拾八人減 四ッ谷御門外上水樋**」「**海賊橋松屋橋御修復小屋場 吹上懸り上水御修復小屋場 組附人足一三拾人**」＝**水道橋際・四ッ谷御門外の上水樋（江戸の給水樋）の駈附減数の並記と、海賊橋・松屋橋・吹上懸り上水の御修復小屋場の組附人足30人**も読める〔**①「水道橋際上水樋」800人減等は江戸の他上水の樋（水道橋=神田上水四ッ谷見附・御門外上水樋）で千川上水の文言と同表に並ぶ＝上水行政の枠組みで千川が扱われる観察の補強。②「海賊橋松屋橋」は本冊の目録文言（牢屋敷千川上水幷御修復中橋々）の「御修復中橋々」の中身の具体化候補。③[43]（二十ノ中）にも「**千川上水小屋場駈附人足之儀は拙者方に而可申渡候 午三月 山村信濃守**」があり、本冊既出文言とほぼ同一（OCRの細部差＝「取計」vs「取斗儀」等）**〕。**数値の採用・文言の確定はいずれも原画像照合まで保留する。**
