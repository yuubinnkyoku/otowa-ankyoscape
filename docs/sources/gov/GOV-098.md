- **資料〔確認: i-repositoryの本文XHTMLをcurl+UAで直接取得〕**: 『練馬区史 歴史編』の本文が `https://www2.i-repository.net/contents/myc/text_2rekishihen/rekishihen_honchoX.xhtml` の形式で**機械可読なXHTMLテキストとして公開されており、curl+UAで本文全文が直接取得できる**（honcho4＝第四部近世・約360KB本文、honcho5＝近代用水史・約440KB本文）。**刊年はページからは特定できず**（本文が昭和32年刊『練馬区史』を引用し、さらに昭和51年『練馬の水系』・昭和16年武蔵高校『千川上水』を参考文献に挙げるため昭和51年以降の区史本文とみられるが断定しない）。〔第20回以来「i-repository本文遮断」としていた**練馬区史系本文の新しい直接取得ルートの発見**。GOV-075（現勢資料編・スニペットのみ）とは別ボリュームで、本文全文が読める〕
- **千川家文書三書の所在〔確認: 本文の明記＝repo初出〕**: 千川上水の起立と変遷について「**千川上水起立之義」「千川上水古記録上申」「千川上水路履暦（ママ）**」の三書があるとし、**「いずれも豊島区西福寺所蔵千川家文書」**と明記。三書は内容に大差なく部分的な精粗があり、**明治13年まで記録のある「千川上水路履暦」を中心に**概略を記すとする。〔neribunアーカイブの千川家文書297点（[GOV-089](GOV-089.md)・元禄9年〜明治17年）と対応する文書群の**別の所在表記**。西福寺所蔵文言はrepo初出で、neribun所蔵分との異同（移管・写本の別）は未確認〕
- **「千川文書写」（東京都公文書館蔵）の引用〔確認＝repo初出の文言〕**: 宝永4年（1707）の灌漑許可の経緯を「千川文書写」所収の原文として引用: 「宝永四亥年、右千川上水堀通左右村々百姓申合、徳兵衛・太兵衛江相頼申候ハ右村方田場天水場ニ而年々難儀仕候ニ付、右御上水を用水ニ少々宛分水仕度奉存候間…御糺之上御上水吐水ヲ以村々田場用水ニ被下置候、依之田壱反歩ニ付為水料と米三升宛年々村方より右両人之者共江請取…御上水堀通ニ御入用ニ而相建候御高札拾六ヶ所御座候内八ヶ所新規修覆共請負人共より永々仕立差上可申段奉願上候処願之通被仰付候（下略）」。〔水料米3升/反は[GOV-067](GOV-067.md)と整合。**高札16か所（うち8か所新規修覆）の文言はrepo初出**。担当奉行4名（高林又兵衛・松下権兵衛・小宮山庄五郎・荒川八兵衛）の記載も初出〕
- **昭和6年の定量値〔確認＝repo初出の数値群〕**: 昭和6年「東京市第二水道拡張計画参考書」の値として、**最大取水量毎秒0.844 m³・灌漑面積88町4反歩・利用人員2,750人（うち飲用2,130人）・水車4台・庭園引水（六義園）1か所**。〔水車4台＝[GOV-067](GOV-067.md)「練馬区4水車」と整合。飲用2,130人が昭和6年時点で残存していたことの数値化〕
- **千川家系譜の記述〔確認〕**: 「千川家系譜」によると上水工事は始め**久右衛門が拝命したが直後死去**し、以後の記述が続く〔[GOV-077](GOV-077.md)（伊勢平八郎480両自前出資）・[GOV-004](GOV-004.md)と併せ、系譜側の記述として記録。真偽の判定はしない〕。
- **水車不許可の再確認〔確認〕**: 文化4年（1807）中荒井村名主伝内と上石神井村百姓勝五郎の水車願（早川八郎左衛門御代官所宛・千川善蔵・金七の名）が**千川上水では天明以降水車の新設を許可しない方針で却下**、文化6年にも中荒井村五郎作・上練馬村左内の願も実現せず、**「遂に明治に至るまで、この水系での水車稼は見ることが出来なかった」**と総括。〔[BLOG-094](../blogs/BLOG-094.md)（板橋区史通史編上経由の文化4/6年水車願い却下）の**練馬区史側からの独立裏付け**。ただし「明治に至るまで水車なし」と、[GOV-067](GOV-067.md)・昭和6年参考書の「水車4台」との関係は、明治以降の新設（[BLOG-094](../blogs/BLOG-094.md)の明治17年路図8水車・斉藤水車ら）で折り合わせると解せるが断定はしない〕
- **その他の本文内容〔確認〕**: ①中荒井村の水田は**すべて千川上水の恩恵**（『東京府志料』水田耕作面積と一致）。②上石神井村は水田15町2反のうち**約3割が千川上水依存**（安永2年千川茂兵衛・善蔵の水料米控）。③千川上水は**正徳4年（1714）市街地への大部分の給水を停め巣鴨村で打ち切り**、享保7年（1722）飲料水としての利用を停止〔[BLOG-101](../blogs/BLOG-101.md)（1696→1707→1722沿革）と整合する別の年次記述〕。④明和8年（1771）玉川上水渇水で千川上水差し塞ぎ、下練馬村の歎願。⑤**道奉行伊勢平八郎掛り・老中松平甲斐守・加藤越中守の命**で開発。⑥参考文献として東京市『東京市史稿上水編』・練馬区教委『練馬の水系』（昭和51年）・武蔵高等学校『千川上水』（昭和16年）・**都立板橋高校『千川上水沿線集落』（昭和31年）**を挙げる〔最後の1点は[BOOK-084](../books/BOOK-084.md)として新規登録〕。
- **honcho5（近代の部）〔確認〕**: ①「**中新井川には江戸期に千川の水を引水**」の文言〔[GOV-005](GOV-005.md)（中新井村分水・中新井の池）・[ORG-020](ORG-020.md)（濯川＝中新井分水）の区史本文側の裏付け〕。②**田柄用水**（明治4年秋完成・「玉川上水北側新井筋分水」・田無町外八か村組合用水・畑田成り対象村と水積1坪7合/町・明治8年規約）の詳述〔[BLOG-118](../blogs/BLOG-118.md)「千川上水から田柄川を引いた説」の年次・構造の背景資料。田柄用水は玉川上水起水で千川上水との直接関係は本文上明示されず、断定しない〕。
