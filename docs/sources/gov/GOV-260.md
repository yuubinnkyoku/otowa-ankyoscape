# [GOV-260] 東京都市計画報告 第7回（1935）— 立会川・神田上水・谷端川改修の進捗一覧

- **書誌〔確認〕**: 東京市『東京都市計画報告』**第7回（昭和10年第二期）**（1935年・次世代デジタルライブラリー [book/1448230](https://lab.ndl.go.jp/dl/book/1448230)）。巻頭序「東京市は昭和七年十月隣接五郡八十二箇町村を編入し、市域は一躍實に六倍の五五七·五九平方粁に達し」＝1932年編入後の都市計画事業報告。**表のOCR列崩れが激しく、文言・数値はすべて要原文照合**。
- **昭和10年3月末現在の事業一覧表〔確認・文言候補〕**: 河川改修欄に「**立會川、神田上水、谷端川改修**」の事業名が確認できる（「**三川ノ內市長執行分延長ニ、四〇〇米ヲ除ク**」と読める文言候補が付随＝**三川のうち市長執行分の延長から400mを除く**という区間調整の文言か。列崩れのため解釈は保留）。隣接欄に「**呑川、宇田川、谷田川改修**（昭和六、八、決定）」「**江戶川改修**」「**妙正寺川、蛇崩川改修**」の並行事業が並ぶ＝**1935年時点の東京市の河川改修事業の全体配置の中の谷端川改修の位置**。〔[GOV-159](GOV-159.md)（1930年決定）→[GOV-258](GOV-258.md)（1927年府諮問・昭和3年7箇年予算化）に続く1935年時点の進捗確認。〕
- **位置づけ〔観察〕**: 「市長執行分」という文言は、谷端川改修が**府（東京府）と市（東京市）の間で執行区分が存在した**こと（区間の分割執行）を示唆する候補（[GOV-259](GOV-259.md)の市費処置要望・[GOV-165](GOV-165.md)の市域問題の文脈）。ただし表の列崩れが激しく、**執行区分の正確な内容・区間は原文画像の照合が必須で、この段階では文言候補の記録に留める**。
- **注意〔観察・本対象外〕**: 同書の目黒区の記述に「**水窪尋常小学校**」（水窪尋常小）が現れるが、**これは目黒区の水窪（みずくぼ）の小学校で、本repoの水窪川（豊島区・弦巻川上流側）とは無関係**。誤同定に注意。
