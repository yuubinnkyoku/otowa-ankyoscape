# [GOV-368] 御府内場末往還其外沿革圖書 貮拾壱亨（安政3年10月調）— 駒込・田端・中里の用水堀文言群〔第160回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の[34]冊「貮拾壱亨」（**安政三辰年〔1856〕十月調**）。NDL次世代デジタルライブラリー [book/2587249](https://lab.ndl.go.jp/dl/book/2587249)。表紙文言に「**安政三辰年十月調 御府内場末往還其外沼革図書弐拾壱亨 外 上下駒込村 巣鴨村 新堀村 田端村 西ヶ原村 上中里村 中里村一円之絵図壱枚**」（OCR崩れあり）とあり、**上下駒込・巣鴨・新堀・田端・西ヶ原・中里の一円を収める帳**＝[GAZ-012](../gazetteers/GAZ-012.md)が「水路文言の精査は未実施」とした巻の一つで、本回の精査により用水堀文言を確認した（課題の部分的解消）。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する。**
- **用水堀の文言候補群〔確認・文言候補〕**: ①**駒込妙義坂下町脇・中里村境**＝「**中里村東北之方 妙義坂下町脇通用水堀より中里村并同村之内野道限**」＋「**西手前書駒込妙義坂下町脇ゟ東手中里村之内に用水堀有之**」（伝通院領町屋・上駒込村宝社地附の地所）＝**妙義坂下町脇の「用水堀」を起点に中里村方向へ延びる用水の堀の存在**。②**田端村・御鷹部屋**＝「**東北之方 田端村之内用水縁通野道**」（「用水縁」は「用水堀」のOCR変種候補）＋「**南手は御鷹部屋に而東北之方に用水堀有之**」＝**御鷹部屋の東北方（田端村方向）の用水堀**。③**下駒込村・田端村境**＝「**東北之方 下駒込村之内用水堀并田端村之内野道限**」＋「**東北之方に用水堀有之**」（下駒込村御鷹部屋辺之部・田端村百姓地の地所）。＝**安政3年（1856）時点の駒込〜田端〜中里の間（現在の西ヶ原〜田端〜中里）に用水堀網が存在したことを示す書上記録候補**〔個々の用水の同定（新堀用水・石神井川系の用水〔逆川・石神井用水等〕か谷端川系か）は本帳からは行わない〕。
- **新堀村巻としての意義〔観察〕**: 本帳は新堀村（谷端川上流の新堀）を収録対象に含む。「新堀」の地名自体が用水・堀の開発史（[README](../../README.md) §谷端川の新堀関連）と結びつくため、本帳の用水堀文言群（妙義坂下町脇・中里・田端）は**嘉永〜安政期の新堀村周辺の水利の記録候補**として位置づける。ただし本帳の「用水堀」が新堀用水に対応するかは断定できない。〔[GOV-364](GOV-364.md)（貮拾貞・嘉永7年）の用水堀29箇所の谷端川上流域に対し、本帳はその東隣（駒込・田端・中里）の区間に当たる。〕

## 制限・未解決

- ①本帳はくずし字でOCR崩壊が大きい。引用文言はすべて原画像照合を要する。②「用水縁」は「用水堀」のOCR変種候補。③用水堀の個別同定（新堀用水・石神井川系用水・谷端川系の別）は本帳からはできない（絵図部分「一円之絵図壱枚」の読図が前提）。④西ヶ原村・上中里村側の地所書上の用水文言の網羅的抽出は今後課題（本回は妙義坂下町・中里・田端・御鷹部屋周辺で抽出）。
