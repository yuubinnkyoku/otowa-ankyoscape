# [GOV-358] 御府内往還其外沿革図書 拾五・拾五之三 — 浅草側の平次郎菜園場文言

- **書誌〔確認〕**: 『御府内往還其外沿革図書』拾五・拾五之三（**弘化2年正月調**・神田下谷浅草辺）。NDL次世代デジタルライブラリー [book/2571705](https://lab.ndl.go.jp/dl/book/2571705)（拾五）・[book/2571706](https://lab.ndl.go.jp/dl/book/2571706)（拾五之三）。**引用文言はすべてOCR由来で要原文照合**。
- **雑司ヶ谷村平次郎菜園場（浅草側）〔確認・[GOV-347](GOV-347.md)（四谷市谷側）と同型文言の浅草側用例〕**: 2571706（拾五之三）p.17-18「**明和四亥年閏九月北之方新堀際明地之内江東西南え折曲り新道壱ケ所…新石川え…明和年中橋掛渡ニ成里俗稲荷橋…右明地雑司ヶ谷村百姓平次郎菜園場拝借地弐ヶ所二成同五子年八月拝借地被召上**」〔**①明和4年（1767）閏9月の新堀際の明地への新道開設、②明和年中の橋の架渡＝里俗稲荷橋の成立、③その明地が雑司ヶ谷村百姓平次郎の菜園場の拝借地2ヶ所であったこと、④明和5年（1768）8月の拝借地召上、の一連の記述**〕。平次郎の名は [GOV-347](GOV-347.md)（御府内沿革図書帳・四谷市谷之部）の市谷側の菜園場文言と同名で、**神田川（新堀川）沿いの複数区域で同名の拝借菜園が明和期に新道・新堀開削に伴って召し上げられた実務の浅草側用例**（千川上水の供給対象区域の旧・平次郎菜園場の記録としてrepo初出）。
- **稲荷橋〔確認・ただし新堀川系〕**: 上記文言の「**明和年中橋掛渡ニ成里俗稲荷橋**」＝新堀川（神田川下流部の掘割）への稲荷橋の成立年代の記録。**新堀川は本repoの対象四河川の外側だが**、神田川下流部（新堀）の橋の年代の datapoint として [橋名調査](../../四河川の橋名・橋跡調査.md) の神田川関連欄に併記した（本資料の主体は平次郎菜園場）。
- **目録の神田川下流町名群〔確認〕**: 同冊目録に新堀端・下平右衛門町等の神田川下流の町名が並ぶ（[GAZ-082](../gazetteers/GAZ-082.md)（御府内備考活字版）の上平右衛門町・下平右衛門町の河岸の千川上水井戸文言と同じ町域）。

## 制限・未解決

- ①「新石川」の読みと比定（新堀川の別称か石川の類か）は要照合。②平次郎（浅草側）と [GOV-347](GOV-347.md) の平次郎（市谷側）が同一人物かは本冊では確認できない（同型文言の並列にとどめる）。③稲荷橋の位置の特定は新堀川の流路確定が前提で、本repoでは断定しない。
