# [GOV-286] 玉川上水留・慶応元〜2年 — 赤坂弁慶堀際の下水掛樋の石樋化（大下水×上水堀の交差構造）

- **書誌〔確認〕**: 『玉川上水留』の1冊（NDL次世代デジタルライブラリー [book/2587442](https://lab.ndl.go.jp/dl/book/2587442)・玉川上水留[106]）。表紙に「**玉川上水赤坂弁慶堀際下水掛樋模様替并除地附板柵共御普請**」・伺書は丑年11月〜寅年3月（慶応元乙丑1865年11月〜慶応2丙寅1866年3月）。**引用文言はすべてOCR由来で要原文照合。**
- **大下水×上水堀の交差構造〔確認・repo初出級〕**: 伺書——「**赤坂弁慶堀際下水掛樋之儀は四谷鮫ヶ橋辺高臺ゟ流入候大下水(上?)木堀際ニ有之 強雨之節者水押開 悪水不浄物等流込 難差置候ニ付 安政五午年以前種々手当仕候得共 場広之儀ニ付防方工風(?)無御座候**」＝**四谷鮫ヶ橋の高台から流入する大下水が赤坂弁慶堀際で玉川上水堀（白堀）と交差し、大雨のたびに悪水・不浄物が上水堀に流れ込む構造上の問題が安政5年（1855）以前から続いていた**ことの慶応期の文言。「同年中上水堀上江下水掛樋桶理(?)弁慶場え大水之節吐捨ニ相成候間外損所等も少(?)」＝安政5年中の応急手当（上水堀上の下水掛樋を弁慶場(?)で大水時に吐き捨てる工法か・OCR要照合）。**下水が上水を跨ぐ／干渉する構造の事例として、[GOV-274](GOV-274.md)（溜池端通大下水・榎坂上埋下水の干渉文言）・[GOV-278](GOV-278.md)と並び、千川上水×谷端川・神田川系の交差構造（伏せ越し・掛樋）の対校資料になる。**
- **白堀上の木樋9間→石掛樋への模様替〔確認・repo初出の石樋化事例〕**: 仕様注文——「**白堀上一掛樋長九間 内法上八〇四尺(?) 深弐尺五寸 右仕様有来掛樋朽損 上水堀内江浅水強(?)難差置候ニ付 石掛極ニ模様替之積**」＝**白堀（玉川上水堀）の上に掛かる大下水の木樋（長9間・深2尺5寸・内法上の寸法はOCR崩れで要照合）が朽損し、石掛樋に模様替えする**趣旨。基礎は「下幅壱丈深壱尺を根切いたし 地杭松丸太長九尺壱丈末口三四寸三ツ切」・「袖八ヶ所幅三尺宛側石打廻し築立候積」＝**幕末の上水施設の石樋化（木樋→石樋）の現場仕様**（[GOV-273](GOV-273.md)紀伊国坂通の石樋（既存）に木の入子樋を差す工法と対照的に、既存木樋を石に置換する例）。
- **掛極上の渡橋の石橋化と四谷大木戸水番屋の古岩崎石の再利用〔確認・repo初出〕**: 「**掛極上通行一石橋長五尺幅四尺壱ヶ所 右仕様掛極上渡橋是迄木橋之処折損候に付右橋に(怪我?)替掛渡候積 岩岐石長五尺幅壱尺厚七八寸弐枚…取懐四谷大木戸水番屋内二有之候古岩岐石長五六尺幅壱尺四五寸厚七八寸弐枚持込柱上江掛渡**」＝**掛樋の上の通行用の渡橋（従来は木橋）の折損を受け、石橋（長5尺・幅4尺）1か所に掛け替え、その石材に四谷大木戸の水番屋内にあった古い岩崎石2枚を再利用して運び込んだ**＝上水施設の橋の石橋化と水番屋構内の石材の転用の実務（[GOV-248](GOV-248.md)の四谷大木戸水番屋の記録群と施設的につながる）。
- **応急修復の履歴〔確認・対校資料〕**: 「**安政五午年八月高金九両松古極板原五寸壱寸削落出来古釘打仕立**」「**万延二酉年九月高金四両三分弐朱 八間五尺之内長三間壱尺入子極杉板厚壱寸五分**」＝安政5年8月（9両）と万延2年（1861）9月（4両3分2朱・8間5尺のうち長3間1尺を入子極で杉板張り）の**下水掛樋の応急修復の2回の履歴**（「入子」の語彙は[GOV-273](GOV-273.md)・[GOV-274](GOV-274.md)の入子樋と同系）。
- **除地附板柵80間〔確認〕**: 「**(?)水除地附片側一板柵長八拾間 高三尺 右仕様杭木(塩?)角長九尺壱丈末口弐(?)三寸弐分切 間に送り五本打 松板幅八(五?)寸大板取交**」＝大下水の除地（水除地）の片側に杭に松板を打った板柵を長80間・高3尺で構築する仕様（雨天時に下水が上水堀へ押し開くのを防ぐ付帯設備）。
- **工費と負担割合〔確認・OCR一部要照合〕**: 「**御組合入用高金三百拾八両**」・「**公義御出銀凡金六両三分銀三匁五分四厘余 武家町出(銀?)凡金三百拾(壱?)両(?)**」＝総額318両のうち公儀出銀は約6両3分で残り約311両は武家町（御組合）出銀という**負担構造**（「拙取二も罷成候間御組合入用御取替金御内借」の文言もあり）。丑年12月の請取に「高金三百拾八両内一金三百両」の分割受領の記録。
- **神田上水神田橋御門外の例規参照〔確認・対校資料〕**: 「**但安政四巳年神田上水神田橋御門外御城内潜樋其外御普請之節書面之通被仰渡候**」「**安政四巳年神田(?)神田橋御門外御堀内潜極其外御普請 御組合入用高金三百八拾両**」＝**安政4年（1857）の神田上水・神田橋御門外の御城内潜樋（伏越樋）普請380両の例規を添えて体裁を整えた伺**＝神田・玉川両上水の普請の先例参照の実務（「潜樋」＝伏越の用語の神田上水側の使用例としても[GOV-089](GOV-089.md)系の交差構造資料の対校になる）。
