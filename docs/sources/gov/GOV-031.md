# [GOV-031] 千早二丁目・谷端川流域の地層剥ぎ取り標本を2017年の展示写真で確認

- **資料〔確認〕**：豊島区立郷土資料館『かたりべ』**126号（2017年12月8日）**、p.2「常設展示室 リニューアルオープン！ ～学芸員のオススメをご紹介～」第1節「大地の誕生」。谷端川流域の**千早二丁目**で採取された**高さ約4mの地層剥ぎ取り標本**を、2017年に改装された常設展示の中心に据えたと明記する。
- **標本・展示写真〔確認／観察〕**：同頁の展示写真には、室内の壁面に立てて設置された縦長の地層標本と説明展示が写る。**写真は2017年刊の展示状況を伝える**が、厳密な撮影日や現在も同じ展示形態かは未確認。標本の採取地点の番地・座標はこの記事単独では特定できない。
- **自然科学資料〔確認：館の解説〕**：館はこの地層に**AT（姶良Tn）テフラの火山ガラス**と、**水田の痕跡としての植物珪酸体（イネ科の植物に由来する微小なガラス質細胞）**が含まれると説明する。これは既収録の『かたりべ』**110号（2014年2月7日）**が記録した**千早二丁目39番・旧平和小学校校庭の2013年土層剥ぎ取り調査**と、所在地・地層の高さ・分析項目がよく一致する。〔**推定：同じ標本である可能性が高いが、標本番号・館の収蔵台帳による同定は未確認**〕
- **研究上の位置づけ〔観察／推定〕**：2013年調査を示す既存の発掘記録に加え、**2017年時点で標本が保存・展示され、写真記録が存在した**ことを別時点の公的資料から確認できた。土層の再観察や展示解説の原資料照合を依頼する際の手掛かりになる。
- **限界〔未解決〕**：展示写真だけでは各層の絶対年代・水田耕作の開始時期・自然湧出口・谷端川の旧河道中心線・流向は確定できない。**AT火山灰の堆積年代と水田耕作土の年代を同一視しない**。同じ標本であること、採取地点の正確な位置・標高、現在の展示状況は館の資料台帳と2014年記事・研究紀要で要照合。
- **出典**：豊島区立郷土資料館『[かたりべ No.126](https://www.city.toshima.lg.jp/documents/8036/kataribe126.pdf)』（**2017年12月8日**、p.2、展示写真・「大地の誕生」）／既収録『[かたりべ No.110](https://www.city.toshima.lg.jp/documents/2546/kataribe110.pdf)』（**2014年2月7日**、pp.2–3、2013年8月の調査）。
