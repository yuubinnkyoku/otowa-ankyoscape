# [GOV-049] 1801年の舗石建立塔を1996年に実見・紹介した郷土資料館報

- **資料〔確認〕**：豊島区立郷土資料館『[かたりべ43号](https://www.city.toshima.lg.jp/documents/2548/kataribe43.pdf)』（**1996年10月20日発行**）、印刷**p.7**、横山執筆「豊島をさぐる その3／区内の土木遺産―舗石建立塔―」。**2026年11月3日に区公式PDFの印刷p.7の誌面画像を直接閲覧**。石塔写真と寸法付き説明を掲載する。先に登録した[ORG-008](../org/ORG-008.md)の商店街連合会による二次紹介とは**別の、1996年時点の公的館報記事**である。
- **碑と所在地〔確認：1996年館報の本文・写真／銘文の直接実測ではない〕**：当時の所在地を**「千早一丁目二三」の地蔵堂内**とし、建立年を碑面の記載として**「寛政十三辛酉（一八〇一）年二月吉日」**と転記する。石塔写真のキャプションは**高さ149.5cm・幅32.8cm・奥行22.5cm**とする。碑の現物を今回再実測したわけではない。現住所の**千早1丁目23-3**は別資料[ORG-008](../org/ORG-008.md)の表記であり、1996年記事の番地表記と区別する。
- **旧道・湿地の記述〔確認：館報筆者による歴史地理の説明／観察：交通路と谷端川上流の湿地が関連づけられる〕**：長崎村・上板橋村方面の住民が池袋・雑司ヶ谷・音羽・江戸川橋を経て江戸の市場へ往来した**裏街道**と地蔵堂付近の道を関連づける。谷端川流域の洪水と通行の不便を背景に、**「谷端川の湿地帯（約百mの区間という）」に石を敷いた**と説明する。**約100mは館報が伝える概数・伝聞で、原工事記録による実測延長ではない**。
- **橋との関係〔推定：1996年記事筆者の解釈〕**：記事は橋の架設と周辺道路整備が村民の急務だったと推測するが、**1801年の橋の位置・橋名・架設事実を記した工事台帳や橋台遺構を提示していない**。敷石区間の起終点、旧谷端川の川幅・流路、築造工法、敷石調達方法も不明と明記する。**「橋が1801年に架けられた」「約100mの河床を石で覆った」と断定しない**。
- **史料価値〔推定〕**：商店街案内だけでは未確認だった**碑文の月表示（1801年2月吉日）・石塔の寸法・1996年の現地写真・約100mという伝聞延長・地蔵堂付近の通行路**を独立した公的館報で照合できる。1912年地籍図・近世絵図・地形断面と突き合わせ、敷石工区が**谷端川本流の横断路か、湿地を縦断する道か**を検証する候補になる。**1996年の刊行年、1801年の碑面建立年、推測された敷石工事時期は区別**する。
