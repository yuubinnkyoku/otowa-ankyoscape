# [GOV-601] 東京府水害統計・明治43年 — 1910年8月大水の府統計と出水河川列挙中の「千川上水」

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 東京府 編『東京府水害統計 明治43年』（**東京府・1911**・[book/798828](https://lab.ndl.go.jp/dl/book/798828)）。明治43年（1910）8月上旬の東京府管内大豪雨（1910年8月の大水。水窪川・弦巻川下流側の小石川指ヶ谷の出水絵葉書〔喜多川周之コレクション〕と同年）の被災統計。**巻頭概説の出水河川列挙・被災地記述のOCRは列崩壊が甚だしく、文言・配列とも原画像照合が必須**（本書は書誌・文言候補の保存を目的とする）。

## 文言〔OCR大崩壊・候補として記録〕

- **巻頭概説の出水河川列挙**（OCRコマ13枚目。「川」表記が連続する列崩壊で隣接欄と混線）:
> 明治四十三年八月上旬數日强雨ノ爲メ 東京府管內ノ諸川水位漸ク其ノ度ヲ高メ（九日、十日…浸水…）…江戶川 中川 目黑川 … **千川上水** …神田上水 …石神井川 …（＝出水・破堤等の重モナル河川の列挙表）

> 荏原、北豐島、南足立、南葛飾ノ四郡及東京市下谷、淺草…（浸水・道路ノ破壊・橋梁ノ破損若ハ流失…人畜ノ死傷…）

## 読み取り〔観察・文言候補〕

- **①府統計の出水河川列挙に「千川上水」〔repo初出の列挙文言候補〕**: 明治43年8月の大水を扱う府の公式統計書の河川列挙に「千川上水」（隣に神田上水・石神井川等）が含まれる見え方＝**1910年時点で千川用水（千川上水）が通水・機能中の水路として府の水害統計の対象に挙げられている用例候補**。千川上水の明治43年時点の現役性（[GOV-455](GOV-455.md)長崎町1931・[BOOK-325](../books/BOOK-325.md)印刷局王子1937等の同時期の現役記録系と接続する1910年定点）として使える〔表の正確な組（河川名×出水/破堤/流失等の欄）は原画像照合まで使用しない〕。
- **②年次の重さの確認〔観察〕**: 明治43年8月の大水は江戸東京博物館所蔵の喜多川周之コレクション『小石川指ケ谷町附近出水の実景』絵葉書（1910年・水窪川・弦巻川下流側の小石川指ヶ谷の出水）と同年で、**府統計レベルで当該水害の地理的スコープが四郡＋下谷・浅草等に及ぶことの確認**〔千川上水沿いの個別被害記録（浸水家屋数等）の有無は未掃引〕。
- **③命名の観察**: 1911年に「千川上水」の呼称が府統計で使われている＝大正〜昭和の「千川用水」呼称（[GOV-455](GOV-455.md)等）と、江戸〜明治前期の「千川上水」呼称の**混在期の通説 (#1600年代上水中止→寛政〜安永再興→天明再廃→用水化) の中で「上水」表記が統計書に残った用例**として対照表のtime seriesに使える候補。
