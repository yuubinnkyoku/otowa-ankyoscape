# [GOV-113] 豊島区の公園条例改正議案資料2件（NDLサーチ書誌）〔千川彫刻公園はrepo初出〕

NDLサーチのOpenSearch APIで「千川」を検索したところ、豊島区立図書館の区政資料（R100000094）の個別レコードとして、千川上水跡の公園2件を含む条例改正議案資料の所在を確認した。

- **①公園条例・児童遊園条例・公衆便所条例改正議案資料「上池袋中央・南池袋みどり・千川親水公園、千早町三丁目・上池袋一丁目児童遊園、東長崎駅前専用公衆便所」〔確認: NDLサーチ書誌〕**: **1989（平成元）年3月2日**・「H010302区民建設委員会資料」〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I182690)〕。**千川親水公園の公園条例上の取り扱いを定める条例改正の議案資料**〔[GOV-080](GOV-080.md)の水流復活（平成元年=1989年）と同年の区議会資料で、整備→条例整備の時系列整理の資料候補。議案本文は未確認〕。
- **②公園条例・児童遊園条例・公衆便所条例改正議案資料「上池袋さくら・山吹の里・千川彫刻公園ほか」〔確認: NDLサーチ書誌〕**: **1993（平成5）年2月26日**・「H050226区民建設委員会資料」〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I182700)〕。**「千川彫刻公園」という公園名がrepo初出**〔旧千川沿いの公園と推定されるが、所在地・整備年次は議案本文未確認で断定しない。「千川」を冠する公園（千川親水公園〔[GOV-080](GOV-080.md)〕・千川上水公園〔[GOV-065](GOV-065.md)〕）に加わる第三の公園名の候補〕。
- **共通の留意〔観察〕**: いずれもNDLサーチ書誌のみで議案本文未確認。条例改正の内容（指定・名称変更・区域変更の別）は書誌からは分からない。豊島区立図書館での現物確認・区議会会議録検索が次の一手。
