# [GOV-125] 東京都総合治水対策協議会『神田川流域豪雨対策計画（改定）』（平成30年3月）

- **書誌〔確認: Wayback保存版PDF全文取得〕**: 東京都総合治水対策協議会『**神田川流域豪雨対策計画（改定）**』（**平成30年（2018）3月**）。現行の [tokyo-sougou-chisui.jp 掲載URL](https://www.tokyo-sougou-chisui.jp/river/kanda_H30.pdf) は404で、[Wayback保存版 id_ 2024-05-14](https://web.archive.org/web/20240514045308id_/https://www.tokyo-sougou-chisui.jp/river/kanda_H30.pdf) で本文PDF（約10MB）を取得し全文抽出〔repo初出〕。
- **音羽地区の50ミリ対策完了〔確認: 表5-2〕**: 50ミリ施設整備の対策促進地区は全7地区のうち5地区で完了。**5番「文京区後楽、音羽（完了）」**〔〔観察〕音羽地区（水窪川・弦巻川の流末側にあたる文京区音羽・後楽一帯）の下水道50mm/hr対策完了の公式記録。どの幹線で完了したかの名称記載なし〕。7地区は新宿（第二戸山幹線）・中野（完了）・阿佐谷南（完了）・中村（完了）・後楽・音羽（完了）・北新宿（完了）・落合（第二妙正寺川幹線の吐口）。
- **千川幹線の増強施設〔確認: 表5-3〕**: 対策強化地区（全6地区）のうち、75ミリ施設整備の**市街地対策地区10番「文京区千石、豊島区南大塚　千川幹線の増強施設」**〔75mm/hr対応。〔観察〕[GOV-082](GOV-082.md)（文京区議会の千川増強幹線視察報告）・[BLOG-134](../blogs/BLOG-134.md)/[BLOG-194](../blogs/BLOG-194.md)（北大塚接続工事の年次記録）の上位計画にあたる記述。増強施設の計画流量・延長等の諸元は本計画になし〕。地下街対策地区は**新宿駅・池袋駅の両地区で完了**。
- **第二桃園川幹線〔確認: 表5-3〕**: 50ミリ拡充施設整備11番「**中野区東中野、杉並区阿佐谷　第二桃園川幹線**」・12番「杉並区荻窪　大宮前幹線の増強施設」・**13番「文京区大塚　主要枝線」**〔〔観察〕13番は北大塚地区の枝線整備（[BLOG-194](../blogs/BLOG-194.md)の北大塚接続工事文脈）に対応する候補だが、本計画に幹線名の記載なし、断定しない。第二桃園川幹線は旧桃園川流域の下水道幹線名として [PAP-065](../papers/PAP-065.md)（桃園川の下水道幹線化）の系譜を補強する名称〕。
- **支川記載の欠如〔観察〕**: 神田川の支川は善福寺川・妙正寺川・江古田川のみを記載。**弦巻川・水窪川の記載なし**〔[GOV-124](GOV-124.md)（令和5年3月整備計画）と同一の観察。両計画で旧小支川が体系から外れている〕。和田弥生幹線（H17年度完成・大規模貯留）の写真も掲載。
- **下水道整備の到達点〔確認〕**: 神田川流域は高田馬場から下流の大半が戦前に普及完了、上流は昭和39年落合処理場供用開始以降に本格化し昭和62年度にほぼ整備完了（注: 平成28年度末までの整備状況）。

- **第82回追記〔確認: 同PDFの本文抽出・2026-11-14〕**: ①本文の全文走査で**「谷端」「水窪」「弦巻」の3語とも0件**。弦巻川・水窪川に加え**谷端川も直接言及がない**ことを陰性データとして記録する（神田川の支川欄は善福寺川・妙正寺川・江古田川のみ。谷端川流域〔文京区千石・大塚など〕は千川幹線・主要枝線の対策地区として現れるが河川名では現れない）。②江古田川の諸元〔確認〕: **下徳田橋から中野区・練馬区の区界を流下し、江古田公園付近で妙正寺川に合流する河川延長1.6kmの一級河川**。③制度上の出典〔確認〕: 対策促進地区・地下街対策地区の位置づけは**平成19年度策定「東京都豪雨対策基本方針」**に由来し、本計画はその「基本方針（改定）」（平成26年6月・「東京都内の中小河川における今後の整備のあり方について」の提言を経て策定）に基づき平成21年計画を改定したもの〔制度の系譜を固定〕。

## 制限・未解決

- ①音羽地区対策完了の中身（幹線名・貯留容量・完了年）は本計画になし。②千川幹線増強施設の諸元・事業区間の特定は本計画になし。③「主要枝線」（文京区大塚）の枝線名の特定。④図5-5（対策地区配置図）は画像で未判読。
