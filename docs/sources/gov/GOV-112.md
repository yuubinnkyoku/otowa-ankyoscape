- **書誌〔確認: 目録詳細〕**: タイトル「**千川上水**」（センカワ ジョウスイ）。作成: **練馬区立関町図書館**。編集・発行: 練馬区立**石神井・大泉・関町・貫井・南田中**の5図書館。出版年: **令和3年度（2021年度）**。資料分類（大分類）: **調べ学習用地域資料カード**／中分類: 地形・土地。権利: **教育目的の利用可**。所蔵: 練馬区立貫井図書館。**監修: 葛城明彦**（日本地図センター・『地形図で楽しむ東京・凹凸ウォーク』等の著者で、[BOOK-047](../books/BOOK-047.md)・[PAP-004](../papers/PAP-004.md)等の谷頭・地形研究者と接続する監修者）。
