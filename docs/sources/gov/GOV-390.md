# [GOV-390] 享保撰要類集 第二十一 — 淀橋水車の享保4年起立と家業セット・「野方白堀」文言〔第165回〕

- **書誌〔確認〕**: 『享保撰要類集』第二十一冊（延享2丑・延享3亥年頃の御用書類・書付の列記）。NDL次世代デジタルライブラリー [book/2572824](https://lab.ndl.go.jp/dl/book/2572824)。同系列冊は[GOV-241](GOV-241.md)・[GOV-238](GOV-238.md)等でも登録済み。**引用文言はすべてOCR由来で要原文照合。**
- **延享3亥年（1746）4月9日の淀橋水車家業譲渡の一件〔確認・核心・repo初出級〕**: 「**延享三亥年四月九日板倉佐渡守殿え申上候淀橋水車家業譲渡之儀に付申上候書付願之通譲渡候様可申渡旨被仰渡奉畏候亥四月十九日同断伊勢肥後守**」の裁定文＋本文「**新肴町金之御座清兵衛方に当時罷出候弥兵衛元鮫ヶ橋南町家持久兵衛右弥兵衛儀従揚り罷在玉川上水通代々村樋口ゟ神田上水江之助水を以水平家業江此水平家業之儀親弥兵衛弐拾八年以前享保四亥年松平伊賀守相願候処同年十月大久保佐渡守殿え呼出し伊賀守并道奉行大濃部勘兵衛立合二而水車仕立候儀且又神田上水助水之樋口之儀願之通申渡候由弥被仰申候**」＝**①淀橋の水車（弥兵衛→久兵衛への家業譲渡）は享保4亥年（1719）に松平伊賀守の願いで立ち、大久保佐渡守の呼出し・道奉行（大濃部勘兵衛〔OCR崩れ候補〕）立合で水車を仕立てた、②水車の動力水は「玉川上水通代々村樋口から神田上水への助水」で「水平家業」を成立させ、神田上水への助水樋口も願い通り申渡された**〔**淀橋水車（多摩川の淀橋・面影橋際の水車）の享保4年起立と、代々村樋口から玉川上水を神田上水へ助水（逆送）する構造の幕府側一次文言＝repo初出級**。[BOOK-194](../books/BOOK-194.md)（天保7年の紀行「享保年中…其頃より初るか神田上水へ助水す」・溜池875坪3分）と対校する一次・紀行の2系統の対応関係。26年前＝享保4年の計算は延享3年から遡って整合〕。
- **家業セット＝井之頭池水門底板幷橋・野方白堀弐百間・玉川通堰料米20俵〔確認・核心・repo初出級〕**: 「**為御忠節神田上水井之頭池水門底板幷橋一ケ所同野方白堀之内長弐百間年之濱致其上玉川通堰料米弐拾俵宛言出来候処**…**久兵衛儀引受弥兵衛仕遂御忠節場相勤り堰料米も差出水車家業仕度旨双方相願申候**」＋裁定理由「**井之頭池水門并橋白堀通之渡等受負人無之候得は年々御修復御入用も相掛候儀に御座候間願之通久兵衛え譲渡候様可申付候**」＝**水車家の「御忠節」（幕府への役務負担）として①井之頭池の水門・底板・橋1か所の管理、②「**野方白堀之内長弐百間**」の区間管理、③玉川通への堰料米20俵の納付がセットで家業に付随し、受負人がいなければ年々の御修復に公費が掛かるので譲渡を認めた**〔**「野方白堀」＝野方堀（野方領を通る神田上水本流路・千川系との対校案件）を「白堀」と呼ぶ享保期の文言候補＝repo初出級**。神田上水の本堀が白堀と呼ばれる時代遡行の最古級候補（[GAZ-049](../gazetteers/GAZ-049.md)⑬の白堀呼称より先行する可能性）。「白堀之内長弐百間」が野方領内のどの区間か（井之頭池寄りか中游か）は本文言からは特定不能。**断定は避け「文言候補」として登録**。井之頭池の水門・底板・橋の管理が淀橋の水車家の役務だった点は[GOV-389](GOV-389.md)（天保5・6の水草刈）・[GOV-393](GOV-393.md)（文政10の水門柵普請）の幕府直轄経費と体制の前後対校案件〕。
- **「神田上水白垣通小日向金剛寺坂下新仕樋」の修復往来人留〔確認・文言候補〕**: 「**小日向入主印寺坂下上水新聞樋御修復十人留之儀…神田上水白垣通小日向金剛寺坂下新仕樋打損其外石垣土手樋上地形等御修復に付別紙随図面来引之通明後廿日より〆切往来人留仕候**」（七月十八日・能勢肥後守）＝**白堀通（「白垣通」＝白堀通の異表記候補・OCR崩れの可能性も残す）の小日向金剛寺坂下の新仕樋（「新聞樋」＝新聞樋/新樋のOCR候補）の打損・石垣土手の修復に付往来人留（通行止）を明後日から申し付けた御目付への文言**〔**小日向金剛寺坂下の上水樋・石垣・土手の修復と往来人留の一次文言**。[GOV-232](GOV-232.md)（金剛寺坂下石垣の弘化普請）・[GOV-341](GOV-341.md)系の金剛寺橋・金剛寺坂下文言群の先行例。「白垣」の字形は要原画像照合〕。
- **周辺文言〔確認・参考〕**: 延享2丑12月の「四谷御門外吹上近上水樋御修復ニ付水押之儀」の書付（「樋通潰レ御修復に付水押申候故日数二日程吹上御座候」＝上水樋修復時の水押（水留め）の文言候補）等が同冊に同居〔上水樋修復の実務の周辺用例〕。

## 制限・未解決

- ①「野方白堀」の「白堀」が野方堀（千川系）を指すか、神田上水本堀の野方領区間を指すかは本文言では確定できない（千川上水は享保期に再興〔千川上水明和6年再興願等の議論〕が、享保4年時点の千川系との対応は対校保留）。②「大濃部勘兵衛」・「白垣通」・「新聞樋」・「水平家業」等のOCR崩れは原画像照合を要する（「水平」は「以水平家業」＝水力で家業を立てる意か）。③淀橋水車の代々村樋口の位置・樋の規模は本冊に付かない（[BOOK-194](../books/BOOK-194.md)の樋寸法2尺5寸×3尺5寸との対校は時期が離れるため文言単位で行う）。④堰料米20俵の宛先（玉川上水の堰か）は要照合。
