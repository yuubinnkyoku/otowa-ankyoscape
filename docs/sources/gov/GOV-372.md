# [GOV-372] 御府内場末往還其外沿革圖書 貮拾壱元下（安政3年10月調）— 谷中・千駄木・新堀村の用水文言と宗林寺「昌平橋外」召上文言〔第161回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の「**貮拾壱元下**」（**安政3年〔1856〕10月調**）。NDL次世代デジタルライブラリー [book/2587264](https://lab.ndl.go.jp/dl/book/2587264)。**下駒込村・新堀村・谷中本村・金杉村・谷中三崎町・千駄木町等（谷中・千駄木一円）の地所書上を収める帳**〔[GAZ-012](../gazetteers/GAZ-012.md)の所在記録（第160回）を個別資料化したもの〕。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する。**
- **「新堀村前通用水路」の文言〔確認・文言候補・核心〕**: 下駒込村・新堀村（駒込千駄木坂下町・根津権現旧地一円）の地所書上に「**東之方駒込千駄木坂下町脇ゟ新堀村前通用水路限…西之方根津権現日地脇より下駒込村并同村之内野道新堀村限…**」＝**千駄木坂下町脇〜根津権現旧地の間に「新堀村前通用水路」があった**という安政3年の境界文言〔**「新堀村前通」の用水路＝新堀村の前を通る用水路**。新堀村（谷端川上流部の低地村・新堀用水〔千川上水の枝線〕の通過域）の水路の帳簿レベルの位置記録。当用水路と新堀用水（千川上水系）の同一性は本帳からは断定しないが、新堀用水研究（README §千川上水）の文脈で対照すべき文言〕。
- **谷中側の用水文言群〔確認・文言候補〕**: ①延命院辺（谷中本村・新堀村・松平三河守抱屋鋪の間）「**…新堀村之内野道并用水堀限…延命院脇ゟ青雲寺前通新堀村之内野道限…**」＝**延命院脇〜青雲寺前にも「新堀村之内」の野道と用水堀**。②谷中三崎町・天王寺古門前（下駒込村）「**下駒込村之内野道幷用水路限…天王寺古門前町屋前通道敷限…**」＝**天王寺古門前町屋の前にも下駒込村の野道と用水路**〔谷中側から見た新堀村・下駒込村の用水路の分布の記録。いずれもOCR崩れ・照合前提〕。
- **宗林寺元地「昌平橋外辺」の元禄14年召上文言〔確認・文言候補・核心〕**: 新堀村・宗林寺の地所書上に「**宗林寺境内之辺は下駒込村新堀村入会之地所に候処 元禄十四巳年中 宗林寺元地場所不知 昌平橋外辺之由不詳 御用ニ付被召上 当所東南之方百姓地之内代地に被下候由**」＝**①宗林寺の現在境内は元来 下駒込村・新堀村の入会地だった、②宗林寺の元地（場所は「昌平橋外辺」の由・詳細不詳）が元禄14年（1701）に御用のため召し上げられた、③その代地として当所（入会地の東南方の百姓地）が下された**という沿革〔**「昌平橋外」の宗林寺元地の収用記録**。昌平橋＝千川上水の昌平橋（千石・[GOV-297](GOV-297.md)の大洗堰附近の昌平橋）と比定される文脈だが、**本帳文言だけでは昌平橋の同定・御用の内容（千川上水樹筋・道路・その他）は断定しない**。千川上水沿い（昌平橋外）の土地の元禄期収用の候補記録として、新堀用水・千川上水の元禄期（享保以前の旧千川）の水路環境の議論に資料を追加する〕。
- **位置づけ〔観察〕**: ①新堀村・下駒込村（谷端川上流・千川上水系の枝水路域）の安政3年の用水路・用水堀の分布を、谷中側・千駄木側の両方向から記録した帳簿として、[GOV-365](GOV-365.md)（同時期・同系列の貮拾壱元上）・[GOV-368](GOV-368.md)（貮拾壱亨）と並ぶ新堀用水研究の基礎資料。②宗林寺元地の「昌平橋外辺」文言は、**千川上水の小石川側（昌平橋附近）の土地収用の元禄14年の年代層**を与える候補（御用の内容の特定・昌平橋の比定は原画像照合が前提）。
