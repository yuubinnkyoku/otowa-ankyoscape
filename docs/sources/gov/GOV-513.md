# [GOV-513] たまろくナビ「玉川上水の分水 (みどころ)」〔多摩北部6市の広域行政団体による分水群公式解説・repo初出〕

## 内容〔確認: 公式ページ本文・2026-11-22取得〕

- **書誌〔確認〕**: 「たまろくナビ」（[多摩北部都市広域行政圏協議会](https://www.tama6.jp/)＝小平・東村山・東大和・清瀬・東久留米・武蔵村山の6市による広域行政団体）の「みどころ」記事「[玉川上水の分水 (みどころ)](https://www.tama6.jp/meguri/spot/post_162.html)」（**更新日: 2026年03月03日**の明記あり）。**玉川上水系分水群（野火止・新堀・小川・鈴木・田無・千川）を一括解説する公式広域行政ページ**＝repo初出の公的統括資料。
- **新堀用水の掘削年と動機〔確認: 本文直接引用〕**:
  - 「**1870年に掘られた水路で、小平監視所から分岐しています。明治期に入り、玉川上水に通船が許されたことや水不足対策として、玉川上水北側の複数の分水口が新堀用水にまとめるために掘られたもの**で、今も流れを見ることができます**」＝**①1870年（明治3年）掘削、②玉川上水の通船許可、③水不足対策、④複数分水口の統合、という4要素を一篇で公式文言化**〔[BLOG-224](../blogs/BLOG-224.md)/[BLOG-225](../blogs/BLOG-225.md)（まろん通信・新堀用水）・[BLOG-282](../blogs/BLOG-282.md)（miwa3k・こだいら観光まちづくり協会案内板「明治3年4月・8か所の分水口を統合」）・[BLOG-275](../blogs/BLOG-275.md)（小金井分水の1870年統合）に続く**行政系の第4系統で、通船＋水不足の複合動機説を公式に明記した点が新規**〕。
  - 「**上流部は、胎内堀と呼ばれる素掘りのトンネル状の地下水路で、「堀を抜く」を意味する「ほっこぬき」ともいいます。現在もトンネルを掘るために利用した竪穴が残っています。**胎内掘坑口の復元**」＝**①胎内堀＝「ほっこぬき」の語源文言（「堀を抜く」）、②竪穴の現存、③坑口復元の存在＝いずれも公式文言**〔[BLOG-276](../blogs/BLOG-276.md)（ほっこ抜き＝人が立って進める高さ／新堀用水の胎内掘＝這って進む）の構造文言の公式側対応〕。
- **分水系譜〔確認: 本文〕**:
  - 新堀用水→小川橋付近で小川用水分水→青梅街道沿いで南北分水。
  - 「**新堀用水は、関東管区警察学校の南側付近で鈴木用水と田無用水に分水されます**」＝**鈴木用水・田無用水の分水位置（関東管区警察学校南側付近）の公式文言**〔[BLOG-281](../blogs/BLOG-281.md)・[BLOG-286](../blogs/BLOG-286.md)の観察と一致する行政側の位置特定〕。
  - 「**鈴木用水は、回田水門緑道でさらに大沼田用水を分水します。大沼田用水は、青梅街道付近で野中用水と分かれ、多摩湖自転車歩行者道沿いの小平ふるさと村の西のグリーンロード親水公園で、西武新宿線をくぐって北へ流れていきます**」＋「**野中用水は、青梅街道付近を東進します。現在の科学館通りから多摩六都科学館の西を通って、東久留米市南町の方までつながっていました**」＝**大沼田用水→野中用水の系譜と野中用水の末端（東久留米市南町まで）の公式文言**〔野中用水の東久留米市南町接続＝repo初出候補〕。
  - 「**鈴木用水は、鈴木街道の南北を東進し、一部は西東京市芝久保町の方までつながっていました。**鈴木用水大門橋緑道(小平市花小金井南町一丁目)**」＝**鈴木用水大門橋緑道の公式名と所在地の文言**〔[BLOG-286](../blogs/BLOG-286.md)(5)の大門橋緑道観察の行政側対応〕。
- **田無用水〔確認: 本文〕**:
  - 「**関東管区警察学校の南側付近で新堀用水から分水され、氷川通り沿いに流れていきます。小金井街道の手前で鈴木用水と交叉し、暗渠となって花南一丁目通り沿いに田無に向かいます**」＝流路（氷川通り→鈴木用水との交叉→花南一丁目通り）の公式文言。
  - 「**青梅街道の橋場付近で南北に分かれ、南側は「ふれあいのこみち」、北側が「やすらぎのこみち」となります。やすらぎのこみちは、総持寺や田無神社を通っていきます**」＝**橋場の南北分水と「ふれあいのこみち」「やすらぎのこみち」という現行遊歩道名の公式対応文言**〔[BLOG-281](../blogs/BLOG-281.md)〜[BLOG-285](../blogs/BLOG-285.md)の観察群・[BOOK-235](../books/BOOK-235.md)の「堀」呼称体系に対応する行政側の現況名公式化〕。
- **田柄川（田柄用水）〔確認: 本文〕**: 「**田無駅近くの、青梅街道の田無町交差点付近で田柄川(田柄用水)を分水します。田柄川は、現在は暗渠となっており、歩道として利用されています。保谷中学校付近の田柄川の暗渠**」＝**①田無町交差点付近の田柄川分水、②現在暗渠＝歩道、③保谷中学校付近の暗渠、の3文言が公式**〔[BLOG-278](../blogs/BLOG-278.md)（田柄用水8本・1871年開削説）の田無側分水点の行政側文言。**「田柄用水を田無用水から分水する」という位置の公式化で、BLOG-278系観察の分岐点比定を裏付ける**〕。
- **千川上水〔確認: 本文〕**:
  - 「**元禄9年(1696年)に造られた約30キロメートルの水路です。武蔵野市関前五丁目(西東京市新町四丁目)の境橋付近で玉川上水から分水されています**」＝**1696年開削・約30km・境橋付近の分水点・両市区表記の公式文言**。
  - 「**1971年に使命を終えて水流が途絶えましたが、東京都の「清流復活事業」により、1989年3月に清流が復活しました。現在は、多摩川上流水再生センターで処理された再生水が流れています**」＝**1971年断流→1989年3月清流復活→多摩川上流水再生センターの再生水、という千川上水近代史の3点を公式文言で直接確認**〔[GOV-106](GOV-106.md)/[GOV-113](GOV-113.md)系の千川上水の現況文言の広域行政側からの統合的対応〕。
