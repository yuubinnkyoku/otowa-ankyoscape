# [GOV-084] 武蔵野市「千川上水整備基本計画」（2010）

- **直接確認（2026-11-12、公式PDF全文〔テキスト取得範囲〕）**: 平成22年5月策定。計画対象は境橋〜吉祥寺橋の延長約3.8km（武蔵野市の北端、練馬区・西東京市に接する）。
- **管理移譲の年次〔repo初出〕**: 千川上水は昭和46年（1971）に通水が途絶え、平成元年（1989）の東京都「清流復活事業」で下水の高度処理水が通水され、**平成18年（2006）に境橋から吉祥寺橋までの約3.8kmの管理が東京都から武蔵野市へ移譲された**。本計画はこの管理移譲に伴い策定。〔[GOV-058](GOV-058.md) の都管理区分（13.8km暗渠）と併せた管理主体の変遣が具体化〕
- **清流復活後の現況の定量的記録〔確認〕**: 流路幅は**1.3〜2.5メートル**、水深は**15〜25センチ**。護岸は自然石積み・コンクリートブロック積み・コンクリート擁壁・擬木杭・丸太杭などで、断面構造は**概ね15タイプ**に大別。**橋は22箇所**（うちコンクリート構造17箇所・H鋼の簡易なもの5箇所）、石碑や供養塔などの歴史施設は**3基**、サイン施設19種61基、ベンチ35基。〔2008〜2010年調査時点の開渠の物理的実態の行政記録として [BLOG-090](../blogs/BLOG-090.md) の流量・開渠35m観察と併せて記録〕
- **土地利用〔確認〕**: 五日市街道交差部から関前橋までの区間は**都市公園に指定**。境橋から多摩湖自転車道交差点までの南側は**境公園（都市計画公園）予定地**。区間①（境橋〜五日市街道交差部＝武蔵野大学正門前）は両側を都道（五日市街道）が併走。
- 住民アンケート（無作為300名・回収128名）では約7割が千川上水を利用（散歩が最多）。生物調査・利用実態調査の詳細は「資料編」（本PDFとは別）にある旨。資料編の所在は未確認。
