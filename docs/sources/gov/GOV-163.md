# [GOV-163] 東京市 下水道改良実施調査報告書（1924年）

- **書誌〔確認〕**: 東京市『下水道改良実施調査報告書』（大正13年・1924）・NDL次世代デジタルライブラリー [book/1874952](https://lab.ndl.go.jp/dl/book/1874952)。**引用はOCR由来・要原文照合。**
- **谷端川（千川）流域の下水計画区分〔確認・repo初出〕**: 谷端川流域面積（郡部を含む）**約2,476,000坪（247.6万坪）**・人口123,800人（附表）。本文に「**谷端川ノ下流ハ千川ニシテ**」の明文。山手線（板橋赤羽線）以西約**172.8万坪**の雨水は「**既定計画ニ依リ谷端川ヨリ石神井川ニ達スル水路ヲ新設**シ以テ荒川ニ放流」、以東約**74.8万坪**の雨水・汚水は市内下水管の**千川幹線**に収容。**1924年時点で「谷端川→石神井川水路」が「既定計画」であったことの市の公式記録**で、板橋放水路の計画・建設時期（READMEの1924/25年次問題）に「1924年以前に計画決定済み」という上界を与える。
- **音羽流域〔確認・参考〕**: 面積約83.4万坪・雑司ヶ谷・高田町・巣鴨町の一部を含み、大半が山手線内。既定計画の雨水に加え**全流域の汚水も音羽幹線に収容**。水窪川・弦巻川の谷頭を含む「音羽流域」が下水計画上の独立区分として使われた記録〔水窪川・弦巻川の名は本件では現れない〕。
- **附表〔確認・要照合〕**: 流域名（藍染川・谷端川（千川）・音羽・神田上水等）ごとの面積・人口・雨水量・汚水量の一覧。藍染川（目黒川支流）と並列で谷端川（千川）だけが「下流の別名を持つ」流域として扱われる。
- **位置づけ〔観察〕**: ①千川幹線（音羽幹線とともに）の計画の初出に近い1924年公式区分。②[GOV-159](GOV-159.md)（1930年）の「板橋放水路ニヨリ石神井川ニ放流シ」に先行する**6年前の市側の既定計画文言**で、放水路が下水道速成事業として1930年以前に実現していたとする後年の説明（[GOV-159](GOV-159.md)）の前提を市文書で確認。
