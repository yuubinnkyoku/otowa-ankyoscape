# [GOV-493] すぎなみ学倶楽部「杉並区立桃園川緑道」〔repo初出・区公式情報サイトの公園史記録〕

- **書誌〔確認: 本文全文・2026-11-21取得〕**: 杉並区産業振興センター「すぎなみ学倶楽部」の特集「公園に行こう」記事「杉並区立桃園川緑道」。**掲載日2022年3月7日**。写真撮影日は2020年4月5日・2022年1月9日・2026年5月29日の3点が本文記載〔2026年5月の写真は掲載後に追記差し替えられた可能性があるが、追記履歴は本文に表示されず確認できず〕。
- **旧桃園川暗渠上の緑道〔確認・repo初出の公園史文言〕**: 桃園川緑道は「**旧桃園川の暗渠（※1）上に整備された、杉並区と中野区にわたって連なる緑道**」。JR中央線の南側に位置し、**杉並区側は阿佐ヶ谷〜高円寺駅間の高架脇から中野区との境まで東西約1,600m**。**1969（昭和44）年4月1日開園。当時の「杉並区広報」によると名称は「桃園川公園」**で、幼児・少年・成人の3つの機能別コーナー・遊具・ボール遊び場・階段式噴水等があった。遊戯施設の老朽化を理由に**平成元年度から改修に着手し、1994（平成6）年3月31日に「桃園川緑道」として生まれ変わった**〔**桃園川の緑道利用の起点（1969年。下水道「桃園川幹線」整備〔[GOV-490](../gov/GOV-490.md)のS40年前後暗渠化・S41桃園川幹線渠首工事写真〔[GOV-492](../gov/GOV-492.md)〕〕と同年代の公園化の公式記録**〕。
- **水道管を覆うモザイク構造物〔確認・repo初出〕**: 西側の出入口ゲート近くの総モザイク貼りの大きな構造物について、**杉並区都市整備部みどり公園課によれば「旧桃園川を横断する水道管を覆うもので、モザイクは水の流れを表現している」**〔**旧桃園川の川筋を横断する水道管の現存を暗示する区事務局回答**。カエル・カメ・カワウソ・カッパ・カモなど水にちなんだモニュメント群は「かつてここに川が流れていたことを思い起こしてもらうように」との意図と記す〕。広さは**8,948.97㎡**〔[GOV-491](../gov/GOV-491.md)の荻窪地区雨水貯留管とは別位置。川跡の空間利用の面積の一次数値〕。
- **意義〔観察〕**: ①[GOV-490](../gov/GOV-490.md)（すぎなみ学の暗渠散歩記事）・[GOV-146](../gov/GOV-146.md)（天保の水普請）に続く**すぎなみ学倶楽部の桃園川系3記事目**で、区民向け現地案内サイトの中で唯一、**桃園川の暗渠跡空間の公園化の時系列（1969年「桃園川公園」→1994年「桃園川緑道」）を公式に記述する資料**。②暗渠化（S40年代〔[PAP-065](../papers/PAP-065.md)・[GOV-492](../gov/GOV-492.md)〕）→開園（S44）→改修完了（H6）の順序が、[GOV-492](../gov/GOV-492.md)の昭和41年桃園川幹線渠首工事写真と並べて桃園川の宅地内空間転用史として整理できる〔公園化時の暗渠処理の方式（蓋・埋立）は本記事にはなく断定しない〕。③「旧桃園川を横断する水道管」の文言は、川跡上の上下水道インフラの立体的な交差の一次観察候補〔どの水道管（導水管の系統）かは未特定〕。

## 制限・未解決

- ①「杉並区広報」（1969年）の当該記事そのものは未確認（本記事の孫引き）。②水道管の系統（千川上水系の導水管か、配水管か）は未特定。③桃園川緑道の中野区側（中野区桃園川緑道）の整備史は本記事では杉並区側のみの記述で未確認。④2026年5月29日撮影写真の掲載経緯（記事追記）は未確認。
