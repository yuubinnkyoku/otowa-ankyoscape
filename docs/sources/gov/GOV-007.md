# [GOV-007] 谷端川の水源・全長・橋

- 豊島区広報課、2000年1月21日付プレス資料「かつて区内を流れていた川筋を辿って 冊子『旧谷端川の橋の跡を探る』」。
- https://adeac.jp/viewitem/toshima-history/viewer/viewer/pressH120121/data/pressH120121.pdf
- 谷端川を要町・粟島神社の自然湧水池「弁天池」を水源とし、神田川へ合流する延長約11kmの河川と説明。江戸時代の千川上水からの分水にも言及。
- 冊子書誌: https://ci.nii.ac.jp/ncid/BA46331735
- **原稿の来歴（2000年1月21日広報原文1頁で確認）**：『豊島区立郷土資料館友の会だより』第21～35号（1989年8月～1992年9月）の清水治男「谷端川橋名私考」、同第39～52号（1993年6月～1996年11月）の田崎不二夫「続谷端川橋名私考」「続々谷端川橋名私考」を元に加筆し、流路図・現況写真を追加。冊子はB5判35頁・1,000部発行。〔**確認：豊島区広報資料の記述**〕
- **注意**：原連載・冊子現物は未閲覧。連載の掲載年月は橋の架設・撤去年月でも写真の撮影年月でもない。各橋名の一次根拠、元連載と冊子の異同は未確認。〔**未解決**〕
