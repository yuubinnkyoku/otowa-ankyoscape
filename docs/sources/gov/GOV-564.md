- **書誌〔確認: 2026-11-24にEdge系User-Agent+`Accept: application/pdf,*/*`付きリクエストで現行サイトから直接取得（279,218B・PDF1.4・3頁）〕**: 東京都建設局のPDF `https://www.kensetsu.metro.tokyo.lg.jp/content/000070426.pdf` ＝「**第１８回河川整備計画策定専門家委員会における意見等について**」。第18回委員会（[GOV-563](GOV-563.md)は同年7月23日開催と記録・[BLOG-309](../blogs/BLOG-309.md)系列のnote執筆者は7月22日と記述＝開催日の表記は出典間で1日差、本PDF自体には開催日文言なし）で出た委員意見への都側回答を「【石神井川上流地下調節池整備事業について（事業の投資効果）】」「【同（費用便益比の算定）】」「【その他】」の3区分・整理番号付きでまとめた一次資料。**Wayback Machineには本PDFは未収蔵**（隣接番号000070425.pdfのみ20240815045846収蔵をCDXで確認。第288回ノートが「snapshot 20250325125021id経由で取得」と記録した経緯があるが、当該snapshotはCDX上に存在せず、実際は第289回の直接取得が初の本文確認〕。本文抽出はPDFテキスト層から3頁分（整理番号1〜11）を取得。
- **①B/Cの算定条件〔確認: 整理番号1・3・4・8・10・11本文〕**: ①**目標整備水準と計画規模の関係**＝「河川整備計画では、**年超過確率1/20（区部では時間75mm）を目標整備水準**としているが、これには**流域対策分10mmが含まれている**。石神井川上流地下調節池の**整備期間は13年間**を見込んでおり、流域対策を13年間で完成させることは困難である。よって、**流域対策分10mm分を除いた時間65mmに対応する年超過確率1/10としてB/Cの算出**を行っている」〔BLOG-309の②ケース算定批判（[GOV-562](GOV-562.md)）に対する都側の計算根拠の一次文言。時間75mm＝1/20・65mm＝1/10という確率対応は原文文言どおり記録し、数値体系の整合評価はしない〕。②**減価償却**＝「減価償却は見込んでいる。**整備が完了してから50年間として計算**を行っている」。③**便益の物価上昇**＝「便益の物価上昇については**前回と同様に見込んでいない**」（事業費側はデフレーター〔最新値は令和4年度、令和5年度は1.0〕で実数化）。④**社会的割引率**＝「今回の費用便益分析では、**社会的割引率を4％とし計算**を行っている。一方、国では、1％、2％で計算を行うことも始めている」への補足＝「**社会的割引率が2％の場合、B/Cは1.70、1％の場合、B/Cは2.14**となる」〔割引率4%主計算に対する2%・1%参考値の数値〈repo初出〉。[BLOG-309](../blogs/BLOG-309.md)のB1154億円/C877億円/B/C1.31（R5.11.27提示）系列と、割引率を変えた場合の感度の行政側数値の対照点。なお4%主計算そのもののB/C数値は本PDF本文に記載なし〕。⑤**評価の時点**＝都の回答「**事業実施の際のB/C**です」。⑥**計算ケース数の考え方**＝「B/Cの算定については前回と同様に**無害流量と計画規模で計算**している。治水経済調査マニュアル（案）では**大河川を念頭に作成されており、確率規模は1/100〜1/200の目標整備水準**としている。東京都の中小河川では、**目標整備水準が1/10や1/20であり、時間50mmは1/3と小さい**。マニュアルの但し書きでは、『**無害流量規模によってはこの限りではない**』と記載があることから、無害流量規模と計画規模で計算を行っている」〔BLOG-309論点③（無害流量=超過確率1/3・時間50mmへの修正提案）に対応する、都側の計算方法の根拠説明の一次文言〕。⑦**感度分析**＝「個々の変動リスクについては、それぞれで感度分析するやり方があるが、マニュアル（案）では扱いきれていない…不確実性をどう表現するかが今後の課題」「今後検討を進めていきたい」。⑧**メッシュデータ**＝「計算に使用した**メッシュデータには農漁家数が含まれている**。一方、水田面積や畑面積については、1haに満たないことから0haと表記されている」（畑0haでも農漁家数1以上となっていた計算表への説明）。
- **②降雨類型別の対策の使い分け〔確認: 【費用便益比の算定】整理番号1本文・repo初出の体系的文言〕**: 「**ゲリラ豪雨のような降雨継続時間の短い集中豪雨については調節池のような貯留施設で対応**することを考えている。一方、**台風性の豪雨のような総降雨量が大きい豪雨については、河道整備が重要**であると考えている。このことから、東京都では、**時間50mmまでの降雨については河道整備とし、それを超える降雨については調節池等で対応**することとしている。また、**線状降水帯など長時間にわたって降り続く降雨については、昨年公表した「気候変動を踏まえた河川施設のあり方」で示した地下河川といった流下型の施設を整備して対応**していきたいと考えている」〔降雨の継続時間・総量の類型（ゲリラ豪雨／台風性豪雨／線状降水帯）と施設類型（貯留型／河道／流下型地下河川）の対応を都が明示した一次文言。環七地下調節池系の「台風性=河道50mm」構成（[GOV-560](GOV-560.md)⑩⑪）と石神井川上流の調節池整備を同一の降雨類型の枠組みで位置づける横断資料〕
- **③内水・外水と3局連携〔確認: 【費用便益比の算定】整理番号2本文・BLOG-309論点⑥の一次裏付け〕**: 委員意見「**東京都の治水事業は内水被害と外水被害を分けて考えているが、住民から見ると浸水被害は一緒である。今後は、2020年に国交省が公表した流域治水の考え方に沿って進めていかないといけない。建設局は下水道局との調整をどのように行っているのか。**」への都側回答＝「**昭和60年代から河川（建設局）と下水道（下水道局）は総合治水対策として、流域対策を所管する都市整備局と連携し、3局で豪雨対策を行っている。定期的に協議会等を行い、3局連携を図っている**。こうした取り組みについて、今後も継続していく。**また、建設局と下水道局の2局間でも定期的に協議会等で連携を図っている**」〔**①内水・外水の区分への委員側からの異論（「住民から見ると浸水被害は一緒」）を収録した委員会一次資料であること、②建設局×下水道局×都市整備局の3局連携が「昭和60年代から」存在するという都側回答の年代文言（repo初出）、③2局間・3局間の定期的協議会の体制文言**。[BLOG-309](../blogs/BLOG-309.md)§4-(2)がNote10経由で引いた「第18回専門家委員会議事概要の文言」と対になる回答側の全文＝論点⑥（内水6割以上・建設局×下水道局調整の必要性）の行政側一次裏付け〕。
- **④気候変動と整備計画変更〔確認: 【その他】整理番号1本文〕**: 委員意見「今後の気候変動を踏まえ、整備水準の見直しでは、より強い計画降雨での浸水被害が拡大していく。また、その降雨の発生頻度も起こりやすくなると考えられている」への回答＝「**現在、対策強化流域で気候変動を踏まえた整備計画の変更について検討を開始している**。今後こうした意見を踏まえ検討を行っていく」〔対策強化流域（石神井川は該当〔[GOV-549](GOV-549.md)・[GOV-552](GOV-552.md)系で「石神井川の雨量観測所が対象」との記録あり、本PDF自体には流域名の列挙なし〕）での整備計画変更検討の「開始」を令和6年時点で明示した文言〕。
- **意義〔観察〕**: ①石神井川上流地下調節池整備事業のB/C算定の前提（65mm=1/10・整備13年・償却50年・便益物価上昇なし・割引率4%で2%なら1.70・1%なら2.14）を、批判側のnote（BLOG-309）と開示系（[GOV-543](GOV-543.md)）に依存せず行政側一文書で確認できた初の資料。②降雨類型別対策（調節池／河道50mm／地下河川）の体系的文言は、神田川流域の75mm方針（河道50mm+調節池構成〔[GOV-560](GOV-560.md)〕）と石神井川の計画を同じ枠組みに位置づける横断資料として、repo内の調節池レーン全体に接続する。③「3局連携は昭和60年代から」の年代文言は、総合治水対策史（[GOV-124](GOV-124.md)系）の制度側の起点理解を問い直す候補資料〔当時の総合治水対策の設置経緯との整合は別資料で要確認〕。
