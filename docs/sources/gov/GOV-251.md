# [GOV-251] 水料堰料諸上納金銭取立押切帳（慶応4年）— 千川家の堰科・上保谷新田の呑水料

- **書誌〔確認〕**: 『水料堰料諸上納金銭取立押切帳 慶應四辰年七月ヨリ改』（写）。NDL次世代デジタルライブラリー [book/2532725](https://lab.ndl.go.jp/dl/book/2532725)。玉川上水関係の水料・堰料の年次上納帳簿。**引用文言はすべてOCR由来で要原文照合。**
- **千川平吉・千川善蔵の「玉川十九分水増水口共堰科」〔確認・repo初出〕**: 「**十一月十七日 一金四両壱分 同断 千川平吉 同の川善蔵 是は玉川十九分水増水口共堰科 当辰年分 十二月十二日**」＝**千川平吉・千川善蔵が「玉川十九分水増水口」の共堰科として金4両1分を当辰年分（慶応4年＝1868）に上納した記録**。〔①千川家（千川上水の元役家）が**玉川上水の十九分水口の増水口の堰の維持費用（共堰科）を分担していた**ことの帳簿側の実務記録＝千川上水の玉川上水側施設の維持負担の裏付け。②「玉川十九分水」という分水口の呼称の用例。③千川善蔵は[GOV-098](GOV-098.md)（練馬区史・安永2年水料米控・文化4年水車願の千川善蔵）と同名、千川平吉は[GOV-212](GOV-212.md)（嘉永6年頃の千川屋敷請負継承の平吉）と同名だが、同一人物かは本帳簿のみでは断定しない。〕
- **上保谷新田伊左衛門の「四分水壱分呑水料」〔確認〕**: 「**上保谷新田 本文は弘化二白（＝弘化二巳年か・OCR）御入々相越立申候 □□□伊左衛門 四分水壱分呑水料 当辰年分上納 正月八日**」＝**上保谷新田の伊左衛門が「四分水壱分呑水料」を慶応4年分（正月8日）に上納した記録**。〔伊左衛門は[GOV-250](GOV-250.md)（慶応3年・上保谷新田の表記群）・[GOV-254](GOV-254.md)（安政3年・上保谷新田名主伊左衛門）と同名。同一人物（名主の継続）とみるのが自然だが、断定はしない。「四分水壱分」の水利の単位（4分水口の1分か）は要照合。〕
- **他の上納者の並び〔観察〕**: 同頁に下字井戸村・上津村・定橋町・南宮吉村・春分寺村等の水料・分水呑料の上納記録が並び、**玉川上水系の水料徴収の村別・金額別の一覧**として千川・保谷系の記録が位置づくられる。
