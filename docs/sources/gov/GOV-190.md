- **千川上水請負人の氏名・住所〔確認・repo初出〕**: 浅草天王町の床見世一件（葭菱張りの小商）の処分記録＝「**千川上水請負人下谷金杉上町家持長十郎助成地ニ相渡候**」＝**天明6年（1786）の市中給水再廃後も「千川上水請負人」の称号と実務が存続し、その請負人（長十郎・下谷金杉上町家持）が浅草天王町に助成地を持っていた**ことを示す寛政5年（1793）の記録。〔文言はOCR要照合〕。
- **位置づけ〔観察〕**: 千川上水請負人の市中側の実務者について、氏名（長十郎）・住所（下谷金杉上町）が残る作例。[GOV-175](GOV-175.md)（千川宇兵衛・小石川向山前の西千川）と併せ、灌漑用水への転換後も請負体制が幕末まで連続した（[GOV-189](GOV-189.md)慶応3年樋口運用）ことを示す系譜の途上の一点。請負人と千川家（千川太郎兵衛・徳兵衛）の関係は本文では特定できない。
