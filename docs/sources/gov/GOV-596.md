# [GOV-596] 徳川時代警察沿革誌 下巻 — 千川上水8ヶ所・神田上水11ヶ所禁制高札（正徳3年8月）と享保7年取水差止の並行文言

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 警察協会編『徳川時代警察沿革誌』下巻（警察協会・**1927**・[book/1443710](https://lab.ndl.go.jp/dl/book/1443710)）。江戸時代の高札・触・掟を主題別に採録した編纂書で、**第二十四欵 道路**（p.37・p.41相当）に上水道関係の高札文言が載る。**引用はOCR由来で、原本画像との照合を要する**（編纂書であるため、原本採録時の字面自体も一次史料の現物とは別系統）。

## 文言①〔確認・要照合: 高札採録〕

> 千川上水 小石川御殿掛り溜堀 巢鴨溜堀 同咄水門 同築土手 瀧川一里塚 金井久保橋際 板橋御林橋除 長崎築土手 **以上八ケ處** ／ 神田上水道 金杉橋際 金剛寺坂下 大六天前 小日向村 服部坂下 音羽町橋際 關口村大洗關 同所會我周防守屋敷前 高田橋際 下落合村橋際 戶塚村橋際 **以上十一ケ所** 定 此上水道におゐて魚鳥をとり水をあびちりあくたを捨る輩あらは曲事たるへき者也 **正德三年八月**

## 文言②〔確認・要照合: 享保7年差止〕

> 折上町奉行え 千川上水之儀**申興より掛り候事故**自今相止候間其段向々え可被申達候 來十月より上水取不申筈に候間可得其意候 右御書付**寅八月十七日安藤對馬守殿御渡**被成候由にて右寫中山出雲守方より差〓候（同頁に「享保七年寅八月」の年記）

## 読み取り〔観察・判読対立は明記〕

- **①年月の確定寄与**: [GAZ-117](../gazetteers/GAZ-117.md)（古事類苑が享保集成絲綸錄から引載する同一の高札文言）では「**（月日朱書）**」で年月不明だった箇所に、本書は高札本文直後に「**正德三年八月**」の年月を採録する＝**正徳3年（1713）8月の高札という別系統の年代観の並行資料**。ただし絲綸錄（享保年間編纂）と警察沿革誌（1927編纂）で年代採録が食い違うため、①同一文言の高札が正徳3年に出て享保期に再掲された、②いずれかの採録側の誤栽、のいずれかは**本資料では確定できない**〔断定しない。「正徳〜享保初期に千川上水・神田上水の禁制が運用されていた」までが安全な読み〕。
- **②判読対立の量化**: 同一の高札文言（[GAZ-117]の絲綸錄引載文言とほぼ同一の連続文字列）について、本書の採録は ⅰ)**「（同）咄水門」**（古事類苑版「吐水門」と対立）ⅱ)**「掛り」**（古事類苑版「懸り」〔原文は「かヽり」表記〕・撰要類集「懸り」と対立）ⅲ)**神田上水「以上十一ケ所」**（古事類苑版「以上十ヶ所」と対立）ⅳ)**「板橋御林橋除」**（古事類苑版「板橋御林橋際」と対立）。**千川上水側の8ヶ所（小石川御殿掛り溜堀・巢鴨溜堀・同咄〔吐〕水門・同築土手・瀧川一里塚・金井久保橋際・板橋御林橋○・長崎築土手）は箇所数が両系統で一致**し、神田上水側も所在地の列挙順が一致する〔編纂書どうしの字面対立であり原字確定には至らないが、対校資料として登録する〕。
- **③「水門」の位置文脈**: 千川上水8ヶ所の第3位に「同咄（吐）水門」＝「同」の付く系列（小石川御殿溜堀→巣鴨溜堀→その水門→築土手）として並ぶ＝**巣鴨の溜堀に付属する水門という列内位置**は両系統文言の共通解釈として確保される〔「何の水門か」の特定は既存の留保を維持〕。
- **④享保7年差止文言の並行出典＋第4の判読変種**: 「千川上水之儀**申興より掛り候事故**、自今相止候間…**寅八月十七日安藤對馬守殿御渡**」は [GOV-170](GOV-170.md)（撰要類集「中興より懸り候事」）・[GAZ-117]（絲綸錄「中興よりかヽり候事」）・[GOV-464](GOV-464.md)（憲教類典58「中奥ゟかゝり候事」）に続く**同一御書付の第4のテキスト**で、本書は**「申興」**の字面を採録する〔「中興（再興）」のOCR崩れか異本かは保留。「寅八月十七日・安藤対馬守御渡」の渡日は撰要類集と一致〕。同頁には大岡越前守書付（寅四月十七日）・青山三田上水差止（寅九月三日水野和泉守御渡）・本所上水文言（寅九月五日大久保佐渡守御渡）も併載され、**享保7年の上水差止一連の文書群が編纂されている**＝[GOV-170]の事件構成（青山・三田・本所の同時差止）の対応文言のほぼ全容と一致する。

## 制限・未解決

- ①「咄水門」vs「吐水門」「掛り」vs「懸り」「八ケ處/十一ケ所」の判読対立は本書採録によっては解消されない（編纂書の字面採録であるため、別系統の対校資料として保持）。②「正德三年八月」が札の建立年か採録年かは本文では明示がない。③p.37の「本所上水土手…同年問月」以下の玉川上水・本所上水の高札文言（代々木村より 井戶…）も千川とは別系統の上水禁制の並行資料だが、字面が崩れている箇所は引かない。④「瀧川」「金井久保橋」等の字面は要照合。
