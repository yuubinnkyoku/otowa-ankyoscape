- **位置づけ〔観察〕**: 本冊の橋之部は**天明6年（1786）7月出水の被災橋の査定・修復負担・復旧事業の帳簿群**で、①大塚坂下⇔東青柳町橋（過半流失・本普請）、②渋谷宮益橋・駒井町橋（小損・自己負担）の**被害の大小に応じた復旧負担の区別**が同じ書付群の中で観察される。比較基準橋として**福島橋（天明6正月・深川冨吉町⇔北川町）・今戸橋・新鳥越橋（浅草・天明6出水流失）**が同意項に挙げられる＝天明6出水の被災橋の査定の座標としての利用。大塚坂下町⇔東青柳町橋の帰属川（[GAZ-013](../gazetteers/GAZ-013.md)の東青柳町の地震橋・松屋橋と同じ谷の橋か）は、寸法・管理制度（橋定請負人＝御入用橋 vs 町方御掛かり）の対校課題として[GOV-438](GOV-438.md)に継承する。
