# [GOV-437] 南撰要類集[78]橋之部 — 天明6年出水の橋被害群と古川橋の掛替史・水除杭

- **大塚坂下町⇔東青柳町橋の天明6年（1786）7月出水流失と寛政2年本普請〔確認・repo初出〕**: 「**右橋四年前午年七月出水之節橋台石垣崩落橋過半流失仕候二付其面取繮申付往来仕来候**」〔**①被災年が「四年前午年七月出水」＝寛政2戌年（1790）の書付から遡って天明6丙午（1786）7月出水に整合すること（干支計算による推定・「天明6年の神田川筋の掃部橋・麁朶橋流失等の洪水」〔[BOOK-130](../books/BOOK-130.md)〕と同一年月の出水）、②橋台石垣の崩落と橋の過半流失、③「其面取繮」＝流れ残った部分を応急につないて往来を続けたこと、④橋定請負人（御入用）橋としての寛政2戌年（1790）の本普請であること**〕。入札系文言——材木代**金33両3分**（**白子屋甚七**の落札・内2分引き）＋**南橋台石垣築直27両**（「**地震損一金弐十七両**」のOCR文言候補・「地震損」の一字目は崩れ注意）＋「**流レ残所え役修復往来為仕候依之其後足之御材木弁石垣御入用奉願**」＝**流れ残りを活用した修復から本普請への移行**〔白子屋は[GOV-239](GOV-239.md)の寛延2年牛込馬場下石橋の白子屋勘七と同屋号の請負人群かは断定しない〕。
- **寸法の対立する2書付〔文言候補・OCR照合前提〕**: 寛政2年2月の見合書付は「**渡り四間に横弐間・8坪・材木33両1分**」、同じ冊の入札書付は「**伝渡長弐間横四間**」＝**渡り4間×幅2間 と 長2間×幅4間 の寸法の対立（OCR崩れの可能性が高く、両者の関係（誤記・別橋・別時点の書付）は原文照合まで保留・併記しておく）**。
- **天明6年出水の渋谷宮益橋・目白坂下駒井町橋の小損と自己負担修復〔確認・repo初出〕**: 「**既ニ右午年一水之砌渋谷宮益橋目白坂下駒井町橋損所有之候得共是少々之義二御座候二付自分入用を以修復仕候**」（戌2月・白子屋甚七・菅木屋刻比兵衛らかの書付）＝**①1786年7月出水で渋谷川系の宮益橋と目白坂下の駒井町橋に損所があったが軽微だったため橋定請負人が自己負担（自分入用）で修復したこと、②「一水之砌」の表現＝天明6出水の被害査定・修復負担の実務の文言群**＝**宮益橋の被災が[GOV-422](GOV-422.md)寛延2年（1749）出水（[BOOK-130](../books/BOOK-130.md)・[GOV-241](GOV-241.md)の被害橋列挙に「渋谷宮益橋」）に続き1786年でも被害を受けた2時点体制であることの追加層**。駒井町橋と音羽側の駒止橋（[GAZ-035](../gazetteers/GAZ-035.md)・目白坂上り口の横丁）との関係（音韻の近似だけでなく位置・構造の対照）は本文言からは判定できず対校課題として保留。
- **小日向古川橋（東古川町⇔水道町・江戸川渡り）の掛替史と本普請願〔確認・repo初出〕**: 寛政元年（1789）6月の本普請願（水道町源七・東古川町吉兵衛）——「**去る十一ヶ年以前安永八亥年八月中江戸川満水之節流失**…度々飯橋…老人子供仮橋二而は混雑」＋**御掛直履歴「寛延三午年御掛直・宝暦十二午年御掛直・明和四亥年御掛直」**〔**①安永8己亥（1779）8月の江戸川満水で古川橋が流失（「十一ヶ年以前」は願の干支元年からの数え方のずれが残る・文言候補）、②寛延3庚午（1750）・宝暦12壬午（1762）・明和4丁亥（1767）の3度の御掛直の履歴＝1749寛延2出水→1750懸直（[GOV-241](GOV-241.md)の小日向古川橋新規懸直69両・[GOV-422](GOV-422.md)の8月23日仮橋往来と整合）以降の35年間の古川橋の掛替史、③仮橋の往来混雑を理由とする本普請愿**〕。寸法——**渡り6間×幅2間1尺・13坪・材木代金60両1分＋銀10匁、石垣損所10坪・金45両3分＋銀3匁**（同書付に**霊岸島高橋の安永7年焼失石垣51両3分**との坪割比較文言も見える＝石垣坪単価の対校材料）。
- **古川橋の水除杭（江戸川内）の新規打設〔確認・repo初出の施設文言群〕**: 「**右橋是迄度々流失いたし保兼候間此上為水防江戸川内江水除杭打置候はゝ橋之保に可相成**」（酉10月・西鹿野河内守宛の願）＋御普請奉行の下ケ札「**絵図両朱星之杭木打候**」＋入札「**金六両三分銀壱匁五分**」（**小日向西古川町長八**・寛政元酉年11月4日・「**木口幷手間手伝とも一式**」）＝**①度重なる流失を受けて江戸川内（神田上水開渠＝江戸川区間）に橋を守る杭（水除杭）を打設する提案・設計（絵図の朱星＝打設位置指定）・入札までの実務の一群、②入札者が西古川町の町人であること（[GOV-213](GOV-213.md)・[GOV-220](GOV-220.md)の西古川町の橋の維持負担の系譜との対照）**＝**江戸川（神田川）の開渠内の杭の新規設置の一次記録（repo初出候補）**。「水除杭」の構造（護岸杭か水制か）は本文言からは特定できない。
- **宝暦11巳年（1761）の芝金杉橋普請の先行層〔文言候補〕**: 見合書付内の引用——「**渡り拾壱間二横四間・四十四坪・御材木代金弐百九十八両三分銀六匁・五月伺之上御普請申付（当八月）**」〔**「度暦十一巳年」／「宝暦十己年」とも読めるOCR崩れがあり、1761年（宝暦11）候補＝干支（巳）は宝暦11に整合し、[GOV-438](GOV-438.md)の安永7戌年（1778）掛替・寛政3亥年（1791）本橋掛替の「十四ケ年以前」の遡及文言ととして3時点の起点になりうる。年次の確定は原照合まで保留**〕。
- **位置づけ〔観察〕**: 本冊の橋之部は**天明6年（1786）7月出水の被災橋の査定・修復負担・復旧事業の帳簿群**で、①大塚坂下⇔東青柳町橋（過半流失・本普請）、②渋谷宮益橋・駒井町橋（小損・自己負担）の**被害の大小に応じた復旧負担の区別**が同じ書付群の中で観察される。比較基準橋として**福島橋（天明6正月・深川冨吉町⇔北川町）・今戸橋・新鳥越橋（浅草・天明6出水流失）**が同意項に挙げられる＝天明6出水の被災橋の査定の座標としての利用。大塚坂下町⇔東青柳町橋の帰属川（[GAZ-013](../gazetteers/GAZ-013.md)の東青柳町の地震橋・松屋橋と同じ谷の橋か）は、寸法・管理制度（橋定請負人＝御入用橋 vs 町方御掛かり）の対校課題として[GOV-438](GOV-438.md)に継承する。
