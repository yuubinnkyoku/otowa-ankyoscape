# [GOV-217] 駒込町方書上（文政9年地誌御調）— 千川上水跡の駒込での民間掛渡のmicro-history

- **書誌〔確認〕**: 『駒込町方書上』[参]（文政9年〔1826〕12月・地誌御調に伴う駒込の町方の書上。市場・拝領町・橋・川堀等の項目立てで各町が回答）。NDL次世代デジタルライブラリー [book/2571498](https://lab.ndl.go.jp/dl/book/2571498)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **駒込肴町の「千川上水跡」の年表〔確認・千川上水再興期の駒込での民間掛渡の全経緯（repo初出）〕**: 書上の「一川堀下水坂」等の項に——「**一千川上水跡但明和六丑年二月中浅草田原町小兵衛店忠兵衛同町嘉右衛門店孫兵衛高砂町三郎兵衛店幸島右三人千川上水掛渡奉願安永一同十一年十一月廿八日御検地御改有之掛渡出来仕天明一寅年八月中ゟ水銭小間壱間に付銭廿八文宛上納仕其後同六午年五月中ゟ水銭半減に被仰付同九月中ゟ出浅相止其後埋立被仰付候**」〔**①駒込肴町に「千川上水跡」（水路跡地）があったこと、②明和6年（1769）2月に浅草田原町の小兵衛店忠兵衛・同町嘉右衛門店孫兵衛・高砂町三郎兵衛店幸島の3人が千川上水の「掛渡」（水路の再通）を願出たこと、③安永11年（=天明2寅年・1782）11月28日に御検地・御改があり掛渡が完成したこと、④天明元年（=天明改元前の安永11か・OCRの「天明一寅」の読み注意）8月中から水銭として小間1間につき銭28文を上納していたこと、⑤天明6年（1786）5月中に水銭が半減に仰付けられ、同9月中に出浅（通水）が止められ、その後**埋立が仰付けられた**こと**＝**千川上水の享保廃止後〜天明再興〜天明6再廃止の駒込（中流域）での民間請負の実態を、年月日つきの一次情報として追える唯一級の記録（repo初出）。⑤の「出浅相止→埋立」は[GOV-218](GOV-218.md)の天明6閏10月差止・[GOV-215](GOV-215.md)の8月19日出浅取立と時期が接続し、差止の過程（9月出浅止→閏10月差止→埋立）の年表を精緻化する**〕〔「安永一同十一年」のOCR崩れ・「天明一寅年」の年次（安永11年=天明2寅の改元問題）は要原文照合。水銭の納付先（請負人か奉行所か）はOCRからは不明〕。
- **富士前町ほかの「千川上水跡」記載〔確認〕**: ①駒込富士前町の書上にも「**一千川上水跡右委細之義は駒足肴町ゟ申上候**」（委細は肴町から申上げる）とあり、②他町（肴町以外）では「**千川上水跡当町えは相掛り不申候**」・「**千川上水跡当町江は相掛り不申候**」等の記載が繰り返される〔**①千川上水跡が駒込肴町・富士前町にまたがって存在したこと、②地誌御調の際に「当町に掛かる/掛からない」を各町が回答したこと**＝千川上水跡の町割レベルでの範囲特定のための前提資料。水路跡がどの町割を通っていたかの復元は本書のOCR単独では不可能（絵図との照合が今後必要）〕。
- **位置づけ〔観察〕**: 駒込は千川上水の本流（小石川方面へ南下する旧千川）と駒込給水系統の両説が交錯する区域。本書上は「千川上水**跡**」と明記するため、**文政9年（1826）時点で駒込肴町・富士前町の水路は既に「跡」であった**（天明6の埋立以降・当時は通水していない）ことが確定できる。享保廃止（享保7〔[GOV-171](GOV-171.md)系〕）〜天明再興（安永9〜天明2）〜天明6再廃止という千川上水の通史（README既存）のうち、**駒込の中流域で再興が具体的に完成した（1782）・そして埋立で終わった**という局所のmicro-historyを本書が初めて一次情報で供給する（観察・文言の裏付け後に確定とできる）。
