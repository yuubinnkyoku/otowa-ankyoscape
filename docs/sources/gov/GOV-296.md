# [GOV-296] 東京市例規類集（1940）— 省令第12号（立會川・神田上水・谷端川改修受益者負担）の本文全文

- **書誌〔確認〕**: 東京市『東京市例規類集』（第一篇通規 第十一類財政 第二章市稅、手數料、負擔金 ほか・追錄第28號等に収録）。次世代デジタルライブラリー [book/1453131](https://lab.ndl.go.jp/dl/book/1453131)。**すべての引用は同館OCRテキスト由来であり、文言・数値は原文画像との照合を要する。**
- **省令第12号の本文〔確認・[GOV-102](GOV-102.md)の「本文未読」制限の解消〕**: 「**東京都市計畫事業立會川、神田上水及谷端川改修受益者負擔ニ關スル件 昭和一一年四月一四日內務省令第ニ號〔十二號〕**」として本文全文が収録されている（「左ノ通定ム」）。要点:
  1. **執行者〔確認〕**: 「第一條 **東京府知事**ハ都市計畫事業トシテ其ノ執行スベキ立會川神田上水及谷端川ノ改修ニ要スル費用ヲ本令ノ定ムル所ニ依リ受益者ヲシテ負擔セシムベシ」＝**府執行**（同一省令の対の江戶川=第11号は「東京市長」＝市執行）。
  2. **受益者の定義〔確認〕**: 「第二條 本令ニ於テ受益者ト稱スルハ大正九年内務省令第二十八號ニ拘ラズ第三條ノ負擔區劃內ニ在ル土地ニ付左ニ揭グル者ヲ謂フ但シ一時的ノモノヲ除ク 一有租地ノ所有者、質權者、地上權者、賃借人、使用借主及轉借人二無租地ニ付…」＝受益者＝負担区劃内の土地の権利者群（所有者・質権者・地上権者・賃借人・使用借主・転借人・占用権者）。
  3. **負担区劃と縦覧〔確認・repo初出の文言〕**: 「第三條 負擔區劃ハ**各河川每ニ別ニ圖面ヲ以テ表示シタル地城〔地域〕トス**知事ハ土地ノ狀況ニ依リ負擔區劃ヲ細分シテ負擔區ヲ定ムルコトヲ得」＋「第三條第一項ノ圖面ハ**東京府廳及東京市役所ニ備ヘ置キ縱覽ニ供ス**」＝**立会川・神田上水・谷端川のそれぞれ別個の負担区劃図が府庁・市役所で縦覧に供された**ことの文言。
  4. **負担率＝事業費の4分の1〔確認・repo初出〕**: 「第四條 各土地ノ受益者ノ負擔金額ハ左ノ各號ニ依リ之ヲ定ム 一負擔區劃內ニ在ル土地(受益者ナキ土地ヲ含ム)ニ付利益ヲ受タル厚薄ニ依リ一坪當負擔指數ヲ定メ之ニ各土地ノ坪數ヲ乘ジテ得タル數ヲ當該土地ノ負擔指數トス **二事業費ノ四分ノ一ヲ前號ノ各土地ノ負擔指數ノ總和ニテ除シテ得タル金額ヲ指數一箇當負擔金額トス** 三指數一箇當金額ニ各土地ノ負擔指數ヲ乗ジテ得タル金額ヲ當該土地ノ受益者ノ負擔金額トス」＝**受益者負担総額＝事業費の4分の1**。坪当たりの「負担指数」（受益の厚薄）×坪数で按分する方式。寄附（土地・物件・勞力・工法施工）は評価のうえ事業費に算入、橋梁等の特殊工事費は全部または一部を事業費から控除しうる。
  5. **徴収方法＝均等20分・年2回〔確認・repo初出〕**: 「第六條 **負擔金ハ之ヲ均等ニ二十分シ每年二囘別ニ定ムル期日ニ於ケル現在ノ受益者ヨリ之ヲ納付セシム**但シ受益者ノ申請ニ依リ負擔金ノ全部又ハ一部ヲ繰上納付セシムルコトヲ得 負擔金ハ事業費豫算額ニ依リ之ヲ算出ス 前項ノ負擔金額ガ事業費精算額ニ依リ算出シタル各受益者ノ負擔金額ニ比シ超過スルトキハ之ヲ還付シ不足スルトキハ之ヲ迫徴ス」＝**10年間・年2回（計20回）の分割徴収**。予算額ベースで算出し精算時に還付・追徴。
  6. **減免規定〔確認〕**: 第七條＝①同一土地で他の受益者負担金と同一年度内に重複負担となる場合、②費用補足のための寄附者がある場合、③公用・公共用地（国・府県・市町村ほか公共団体）、神社寺院祠宇佛堂の境内地、私立學校用地、風致地區内の土地、都市計畫法第十六條第一項の土地、道路境域内の土地等（受益者の申請により必要と認めたもの）＝減免事由の列挙。
  7. **告示事項〔確認〕**: 第八條＝負担区・坪当負担指数・指数一箇当負担金額・負担金額と分擔割合・期日・事業費予算額と精算額・減免土地は知事が告示。第九條＝施行細則は知事が定む（**第12号の施行細則は府側告示＝本書（市例規類集）には未収録・所在調査が課題**）。
- **対の省令第11号（江戶川改修受益者負担）〔確認・repo初出の対比〕**: 「東京都市計畫事業江戶川改修受益者負擔ニ關スル件 昭和十一年內務省令第十一號」（同一日付）が隣接して全文収録。**江戸川＝事業費の14分の1**（第四條「受益者ノ負擔金額ハ**事業費ノ十四分ノ一**トス」）・「**均等ニ十分シ每年一囘**」（10年間・年1回）・執行者＝東京市長。**同一日に公布された同種省令で、立会川・神田上水・谷端川（府執行）が1/4・20分等分年2回、江戸川（市執行）が1/14・10分等分年1回と、負担率と徴収方法が明確に異なる**＝[GOV-102](GOV-102.md)の疑問（谷端川と江戸川の負担枠組みの関係）に対する初出の定量回答。
- **江戸川改修受益者負担規程施行細則〔確認・repo初出の指数の具体値〕**: 「告示第三八六號 昭和一一年七月九日」＝「省令第五條第一號ノ一坪當負擔指數ハ省令第三條ノ圖面ニ表示スル所ニ依リ之ヲ左ノ如ク定ム **黃色ノ地域二箇〔2〕 綠色ノ地域三箇〔3〕 白色ノ地域六箇〔6〕 紫色ノ地域十二箇〔12〕**」＝**江戸川の負担区劃図が色分け（黄・緑・白・紫）されていて、地域ごとに坪当負担指数2・3・6・12が定められていた**ことの記録。分擔割合（質権者・地上権者92/100、所有者13/100〔13はOCR列崩れの疑い〕、地上権者・賃借人等55/100等）も列挙〔**数値はOCR列崩れのため原表照合まで保留**〕。
- **位置づけ〔観察〕**: ①[GOV-102](GOV-102.md)（官報目次で所在のみ確認していた省令）の本文を、市側の編纂物経由で確認したもの。官報本文（p.413）と例規類集本文の対校が原文照合の第一歩。②1936年時点で立会川・神田上水・谷端川の改修費用徴収が法的に枠付けられ、しかも**負担区劃図が府庁・市役所で縦覧に供されていた**＝区劃図の現存確認（都公文書館・国立公文書館）が、改修区間の確定（[GOV-258](GOV-258.md)1,983間/[GOV-297](GOV-297.md)の対立を含む）のための次の一手になりうる。③負担率1/4は府史・復興史の工費（谷端川130万〔GOV-297〕ないし265.7万〔GOV-258〕・神田上水265.7万〔両書〕）に対し最大約33万〜66万円の受益者負担総額を意味する〔比計算であり、実際の徴収額の記録は未確認〕。
