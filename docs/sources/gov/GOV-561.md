## 2. お知らせPDF（jyouhoku2osirase）の一次文言〔確認〕

- **工事件名**: 城北中央公園調節池（二期）工事。**工事場所: 板橋区小茂根五丁目地内から練馬区羽沢三丁目地内まで**。**工事期間: 令和7年6月下旬〜令和12年9月中旬**。作業時間 8:00〜18:00（**ニューマチックケーソン工は20:00まで**。原則日曜日作業なし・大型車のヤード最終退場17:00）。
- **工事内容: ニューマチックケーソン工・ケーソン内部構築工（3号及び5号ケーソン）**〔都の工事説明会資料として**本体ケーソン番号を特定する一次文言**でrepo初出（[BLOG-288](../blogs/BLOG-288.md)の「3号・5号ケーソン」知識の出どころ側）。[GOV-087](GOV-087.md)（産経・報道公開）の1号・2号ケーソン＝一期既設に対し、二期は3号〜5号のうち**3号・5号を本工事で設置**と図示（「本工事で設置するケーソン」表現。4号の扱いの文言は今回の抽出では確認できず断定しない）〕。
- **受注者: 戸田・西松建設共同企業体**（現場代理人 鈴木・監理技術者 伊藤・電話03-5926-5202）。**発注者: 東京都第四建設事務所 工事第二課**。
- 説明会は**令和7年5月30日（金）・31日（土）**、会場＝城北中央公園調節池施工ヤード内（所在地＝練馬区羽沢三丁目地内・都立大山高校そば・練馬区側ゲートからの案内図）。託児保育（生後6か月〜未就学児・専門業者委託）と手話通訳（タブレット端末）あり。見学は地下10mまで階段で往復・各回30名上限〔**一期工事の完了文言**: 「城北中央公園調節池（一期）工事その2」が6月末で完了し引き続いて二期に着手の案内〕。
- **事業目的の文言**: 「石神井川では、近年1時間あたり50ミリを超える降雨が増加していることから、**目標整備水準を50ミリから75ミリに引き上げて整備を進めています。その整備にあたっては1時間あたり50ミリまでを河川で対応し、これを超える降雨については、調節池などにより対応します**」〔**75ミリ引き上げの都側説明文言**。[GOV-149](GOV-149.md)（気候変動を踏まえた河川施設のあり方・目標整備水準1/20）から石神井川での75ミリ運用への接続を説明する一次資料〕。
- **計画数値〔確認、図面文言〕**:一期工事＝**貯留量約90,000㎥・面積約7,000㎡**（1号・2号ケーソン）／二期工事＝**貯留量約160,000㎥・面積約13,000㎡**（3号・5号ケーソン表示と併記）＝計約25万㎥規模〔[GOV-083](GOV-083.md)（計画163m×33m×深35m・9万m³）・[BLOG-288](../blogs/BLOG-288.md)（全体約25万㎥・一期約9万㎥）の数値を都発行資料側で裏付け〕。**越流堤L＝約120m**（調節池への流入イメージは「妙正寺川第二調節池」と表記・石神井川からの取水口構造の例示）。ニューマチックケーソン工法の解説（作業室・圧縮空気・天井走行ショベル・タワークレーン等）。
- **「一期土木工事は令和7年6月30日に完了予定で、直ちに取水を開始し下流域の水害の軽減に努めます。また、さらに計画の容量を確保するため、二期工事に着手します。全体事業は令和18年度の完成を目指しています」**〔完成目標年度の一次文言〕。
