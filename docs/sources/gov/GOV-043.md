# [GOV-043] 1716年高田村絵図の「大橋」と神田川の渡河点を紹介する2012年館報

- **資料〔確認〕**：豊島区立郷土資料館『かたりべ』第106号、**2012年7月19日発行**、[豊島区公式PDF](https://www.city.toshima.lg.jp/documents/2546/kataribe106.pdf)、全6頁。**印刷p.3**「鎌倉街道を歩いてみよう―高田宿の発見」（「豊島の遺跡」第10回）の記事本文と掲載絵図をページ画像で直接閲覧（2026年11月2日）。
- **記事が紹介する近世絵図〔確認：2012年の公的館報による説明／原絵図は未確認〕**：記事は**正徳6年（1716年）の高田村絵図**に、**神田川に架かる橋が「大橋」と記される**と説明し、現在の**面影橋付近**の渡河点に言及する。印刷p.3には村絵図の部分図と現在地形図の比較図がある。
- **史料系統の留保〔未解決〕**：掲載部分図の正確な原図名・所蔵先・測図精度は原本と未照合。既登録の[MAP-012](../maps/MAP-012.md)『武蔵国豊島郡下高田村絵図』（1716年）と**同じ原図・同一の版かどうかは未確定**。記事中の位置比定を1716年の橋位置の測量成果と扱わず、**「大橋」の架橋年・現橋との連続性・弦巻川の合流位置**を断定しない。
- **同号の別記事〔確認：2012年の館報印刷p.2を直接閲覧、2026年11月3日〕**：「道筋・川筋の残り方、高低差にこだわる！ 地域史講座『ブラトシマ』第1回の実施報告」は、**2012年6月2日（土）**の雑司が谷村絵図を使った講座を記録する。**参加者17名**が古絵図と現代地図に歩行経路を記入し、清土鬼子母神・水稲荷神社・宿坂・鬼子母神堂などを歩いた。記事は弦巻川を**当時すでに暗渠で、江戸時代の絵図と村人の生活を照合する対象**として説明する。〔**確認：講座の日付・方法・地点・参加人数／推定：2012年の配布地図・写真・歩行記録を探す手掛かり**〕 **講座の経路は近世の川筋の実測線ではなく、2012年の現地踏査経路**。講座で言及された川の暗渠化時期も工事原簿の独立確認ではない。
