# [GOV-556] 武蔵野市・空襲証言集「第一部 武蔵野の空襲とその記憶」〔富士産業の不発弾処理・グリーンパーク球場造成・11月24日の被害数値・散華乙女の碑の証言群〕

- **書誌〔確認: 本文全文・2026-11-23取得〕**: 武蔵野市サイト内のPDF「**第一部 武蔵野の空襲とその記憶**」 https://www.city.musashino.lg.jp/_res/projects/default_project/_page_/001/007/369/14416-5.pdf 〔市の平和施策系ページから配布される証言集の第一部（個別証言篇）とみられる〕。冒頭に「**廃墟となった中島飛行機武蔵製作所時計台**（昭和26年 中村正英氏撮影）」「**中島飛行機武蔵製作所を爆撃するＢ29**（米国公文書館所蔵）」の写真文言付き。各編末尾は「**※ご本人からの聞き取りにより作成しました。**」＝**聞き取り編纂物**。岡本氏の聞き取り時写真に「**体験を語る岡本氏（平成21年12月21日撮影）**」表記＝**聞き取り実施は平成21年（2009年）12月時点以降が下限**。PDF単体では題号・編者・発行年の表記なし〔市HTML頁（平和施策系）は403で書誌確定不能〕。
- **岡本勇（八幡町）「武蔵野の戦後の不発弾処理とグリーンパーク球場の造成」〔確認・repo初出の文言群〕**: ①終戦後、中島飛行機の残務整理を行う傘下の会社「**富士産業**」で「**爆弾であいた穴埋めの仕事**」を開始〔**富士産業の社名と残務整理会社という性格づけはrepo初出**〕。②浄化槽の中から**250キロの爆弾**を発見、工兵隊経験から**爆弾の雷管を抜く**処理。③**一トン爆弾**の処理＝「爆弾は深さ十メートルの穴にもぐっていて、落ちたときの爆弾の慣性で、さらに、落ちた穴から横へ三メートル、四メートルとずれている」＝**落下点と弾体の位置ずれ（横3〜4m）の工兵側観察**。④「**昭和二十五年ごろ、工場の跡がきれいになったので、野球場を作る話**が持ち上がり…私が野球場を作る指揮を執ることになり」〔球場造成の開始年代〕。⑤「**以前、逓信大臣だった松前重義さん**が…松前さんを社長にすれば、**線路が一番早く敷けるのでは**ないかという話になり」「**戦争中には工場への引込み線路がありました。今はグリーンパーク遊歩道になっています**が…**引込み線跡に、野球場への線路を敷くことができました**」＝**引込線跡の再利用による球場アクセス線**〔[BLOG-305](../blogs/BLOG-305.md)（引込線→昭和25年5月廃線→武蔵野競技場線昭和26年4月開業）の証言側対〕。⑥「**昭和二十六年五月五日こどもの日に開園**することに決まり」開園日は花火・子供を外野に一万人から入場、金田選手（国鉄スワローズ）「**とにかくグリーンパークじゃない、ほこりパークだ**」→年間十試合程度→六大学野球のグラウンド→**現在の公団に買っていただきました**＝**グリーンパーク球場の開園日・経営史の骨子**。⑦「**昭和三十二年ごろ、当時の市長に「今度は工場の外の爆弾処理を自衛隊と行うのだが、入札でやるのでお前も会社を作り、やらないか」**と声をかけられ」**岡本組**設立＝**工場外の不発弾処理（市×自衛隊×入札）の時期と体制**。⑧自衛隊20人・ユンボ・ブルドーザー・金属探知機（当時は一メートルくらいしか効果なし）で3日間掘って発見できず、岡本組側が突っつき棒（三メートルの棒）で探して**落下地点から七メートルずれた位置**で発見＝**1957年当時の自衛隊の探査能力の限界の証言**。⑨中町三丁目（現・都民銀行のところ）の建物予定地で欅5本に爆弾の破片が刺さっているのを確認・破裂済みと判定、後に都の道路拡幅で切る話になり「**三鷹の天文台の門のわきへ移植**」された＝**爆弾破片の刺さった欅の保存譚**。
- **内藤昭雄（三鷹市）「勤労動員・初めての空襲」〔確認・repo初出の数値〕**: 旧淀橋区内の国民学校高等科2年生として**東伏見駅**経由で中島飛行機武蔵製作所へ勤労動員、北口正門に銃を持った兵士・**東工場三階の発動機の組立現場**に配属（女子学生・熊谷の陸軍少年飛行学校生徒・太刀洗の特別幹部候補生の混成）。昭和19年11月1日にB29一機の偵察飛行を目撃。**11月24日の昼休み**（地下食堂）に爆撃＝「（記）**後の記録によれば、この日の被害は、死傷者百三十二名。内死者五十七名、負傷者七十五名でした**」＝**1944年11月24日の武蔵製作所被害の死傷者132名（死57・傷75）という数値が本文中の「後の記録」引用として初出**〔典拠元の一次公文は本文に特定なし＝確認課題〕。
- **肥田實次（吉祥寺本町）「武蔵野での空襲体験」〔確認・repo初出の文言〕**: 中島飛行機の**荻窪工場**に旋盤工として就労後、**田無の豊和重工業（中島飛行機の下請け工場）**へ〔**武蔵野市域の外側の中島下請け網**〕。**武蔵境の関東中学（今の聖徳学園中学校）に首都防衛連隊**があり「**一ヶ月のうち二十日間は工場で働き、十日間だけ、兵隊としてその連隊へ行っていました**」＝**在郷兵の月割勤務体制**。**井の頭の池の周りの杉の木を何百本と伐採＝中島の工場で亡くなった方のための棺桶用の板**〔井の頭公園=棺木 sourced 材の伐採地という土地利用文言〕。昭和19年11月24日最初の空襲時に距離二十メートルほどの落下・艦載機の機銃掃射（艦載機のほうが怖い）・**田無駅前に不発弾2カ所（小金井と武蔵境の兵隊が処理）**・爆弾穴の大きさ3〜4m/深さ5〜6m・戦争末期に中島飛行機は**高尾山の地下壕の工場**へ移転（湿気で機械がダメに）。
- **岡村千鶴子（吉祥寺北町）「私の戦争体験」〔確認・repo初出の文言〕**: 昭和19年11月24日の初空襲後、翌日、西へ探検に向かうと「**家から四本目の青葉小路に一トン爆弾が落ちて、直径十メートルくらいの大穴が掘られて家は吹っ飛んでいました**」＝**吉祥寺の市街地側の直撃被害事例（青葉小路・1トン爆弾・直径10m**）〔[BOOK-284](../books/BOOK-284.md)（青木邦弘回想「直径10メートルほどのすり鉢状の穴」）・[BLOG-304](../blogs/BLOG-304.md)（三鷹の爆弾穴20×15×1.5m）と対照できる国民的証言側の数値〕。
- **工藤ハナエ（桜堤）「戦争当時の追憶」〔確認・repo初出の文言〕**: 「地名は**東京都北多摩郡武蔵野町境千八百二十三番地**、家屋は木造平屋建ての二軒長屋で**二百余世帯ありました。旧中島飛行機製作所の社宅**でしたが、終戦のあと各自の所有となりました」＝**境の旧中島社宅長屋（一帯で200余世帯・一世帯30〜40坪）の規模**〔[BLOG-280](../blogs/BLOG-280.md)（戦中の中島飛行場関係者向け柳沢住宅）に続く中島飛行機の住宅系観察の第2点で、武蔵野市域・境側の社宅として初出〕。
- **沢辺松美（緑町）「十四歳の学徒動員」〔確認・repo初出の文言〕**: **武蔵野女子学院**（現・武蔵野大学の前身校系）高等女学校2年生の1944年11月に**給与課**へ動員（算盤で社員の給料計算・課長への叱責）。「**十二月三日の空襲で母校のテニスコートにあった防空壕に直撃弾が落ちて、そこに避難していた五年生の四人の方が亡くなりました**」＝**1944年12月3日の武蔵野女子学院防空壕直撃・4人死亡（17歳）**＋亡くなった先輩の同期生が「**散華乙女の碑**」という思い出集を作成・2007年6月の喜寿記念クラス会で碑前に献花＝**「散華乙女の碑」の存在と4人という人数**〔碑の建立年・所在地（候補=武蔵野大学構内〔[BLOG-305](../blogs/BLOG-305.md)の記念樹碑文言〕）は本文に明記なし〕。空襲激化後に**浅川の分室や小金井の工業高校の工場に分散**。
- **服部賢昌（吉祥寺東町）〔確認・repo初出の文言〕**: 旧制中学3年当時、**吉祥寺から中島飛行機の空襲を遠望**した証言（「**爆弾より高射砲の破片のほうが、被害が多かったくらい**」・3月10日の空襲で東が真赤でも「焼けていたのは阿佐ヶ谷まで」）＋**井の頭公園のお茶の水の近くに木工所**＝中島飛行機の空襲で亡くなった方のお棺をつくるために公園の杉を材料として製品化〔[GOV-556](GOV-556.md)肥田証言（井の頭池の杉伐採=棺桶用）と同一主題の隣接証言〕＋戦後の吉祥寺駅前（ハモニカ横丁）のやみ市・松根油（井の頭公園で採取=飛行機のガソリン代わり）・B29が久我山の高射砲に撃ち落とされた現場の見物譚。
- **意義〔観察〕**: ①**戦後の不発弾処理史（富士産業の穴埋め→岡本組の自衛隊×入札（昭和32年ごろ）→（[GOV-555](GOV-555.md)1997年NTT）→（[BLOG-304](../blogs/BLOG-304.md)2025年掘削調査）→（[BLOG-302](../blogs/BLOG-302.md)2026年要望））の時系列の欠けた中間部**を公的証言集で埋める記録で、武蔵野市域の不発弾レーンの背骨となる。②**グリーンパーク球場→武蔵野競技場線（[BLOG-305](../blogs/BLOG-305.md)）**の史実の連続性（引込線→球場線→公団売却→現グリーンパーク遊歩道／天文台外科）が民間blog・行政証言集の別系列でそれぞれ確認できた。③**11月24日の死傷者132名（死57・傷75）**・12月3日の防空壕直撃4人死亡・青葉小路の1トン爆弾直径10mなど、**被害の数値・日付側の新データ点**が複数出た（いずれも聞き取り由来で、一次公文との照合は未実施）。④境の旧中島社宅（200余世帯）・荻窪工場・田無の豊和重工業・井の頭公園の杉伐採など、**工場の周辺立地網（下請け・社宅・資材）の観察**が複数重なる。
