# [GOV-271] 神田玉川上水留 明治2年下半期 — 神田上水浜町元組合樋筋の全線修復と麹町樋筋→御本城への新規繋樋

- **書誌〔確認〕**: 『神田玉川上水留』明治二己年七月ヨリ十二月マデ分冊ノ四 [book/2587537](https://lab.ndl.go.jp/dl/book/2587537)（判事森左太夫・清水元一郎・鈴木包助宛の御普請仕様注文帳等）・分冊ノ四 [book/2587543](https://lab.ndl.go.jp/dl/book/2587543)（出来形仕上帳）・分冊ノ五止 [book/2587544](https://lab.ndl.go.jp/dl/book/2587544)＝[GOV-267](GOV-267.md)（白堀通修復の3段階帳簿）・[GOV-269](GOV-269.md)（水戸屋敷内掛樋）と同じ明治2年下半期冊の**玉川上水側・神田上水末端側の未精読部分**（[GOV-267](GOV-267.md)制限④・[GOV-269](GOV-269.md)制限③の一部に対応）。**引用文言はすべてOCR由来で要原文照合。**
- **神田上水浜町元組合樋筋の全線修復〔確認・repo初出の上水末端樋管網の定量記録〕**: 「**神田上水濱町元組会持樋筋御用懸り**」（冊頭）——「**神田上水浜町元組合持通筋御普請仕様注文 壱番埋枡ゟ六番堤枡迄一樋長延八拾七間壱尺大サ内法五寸(?)四二分木原(厚?)八寸 七番弐坪(?)ゟ拾六番出払(?)迄一円長延弐百七拾八間三尺大サ内法石同断 惣日(延?)合三百六拾五間四(尺?)…弐間樋六拾八本御在合相用差引弐間樋一日拾五本新組 右仕様折損難捨置候ニ付御普請之積**」＝
  - **神田上水の浜町の元組合持の樋筋（1番埋枡〜6番堤枡・7番〜16番の番号つき樋管群）の惣延365間余・2間樋68本の修復**＝**上水の末端の樋管網（番号つきの樋・枡の連続）の規模の定量記録**（repo初出）。「内法五寸」は明らかな誤読候補で寸法の数字はすべて要照合。「浜町」の帰属（神田側の浜町＝現中央区日本橋浜町方面か・神田橋寄りの浜町か）は要検討。
  - 「**右仕様樋枡伏渡出来後道長百八拾六間幅高(?)間三尺…公足之義は昌平橋御門内土手裾削り取持込保置候**」＝**樋枡の伏替後に江戸城昌平橋御門内の土手裾の削り取り・土の持込**の文言＝浜町樋筋の近傍が江戸城昌平橋御門内（江戸城北東・現皇居前の昌平橋）に及ぶことの傍証（「道長186間・幅3尺」の道路修繕の帰属の割付は要照合）。
- **麹町大通元組合樋筋→御本城掛樋筋への新規繋樋〔確認・repo初出＝維新後の皇城給水の実務〕**: 「**麹町大通元組合持通筋ゟ御本城掛樋筋え新規収原(?)樋掛仕付方并四谷御門外元組合樋筋之内樋押取壊方共御入用仕上帳**」（明治2年12月）＋「**麹町大通元組合樋筋ゟ御本城掛樋筋え新規繋樋掛仕付方并四谷御門外元組合樋筋之内樋掛取(押?)場方御入用仕上注文**」——「**樋長五間十一(?)…樋長寄て壱丈三尺五寸大大サ内法同長壱丈 麹町五丁目長壱人五寸(?) 四谷御門内竪壱人弐寸横壱尺四寸木厚三寸長壱丈六尺五寸…是は松元様長屋前に五間仕付候注文之処壱丈三尺五寸にて相済 外堀方壱丈は堀明口上**」＝
  - **玉川上水の麹町大通沿いの元組合樋筋から江戸城（皇城）本城への給水樋筋に「新規繋樋」（樋長5間・実際の仕上り1丈3尺5寸）を掛けた**明治2年12月の記録＝**維新後も御本城（皇城）への上水給水が現役で、麹町五丁目・四谷御門内で新規の樋掛が行われた**実務の一次記録（「松元様長屋前」「外堀方堀明口」の場所文言つき・人名「松元様」は要照合）。
  - 「**四谷御門外元組合樋筋之内樋押取壊方**」＝四谷御門外の旧元組合樋筋の一部を**取り壊した**記録＝麹町樋筋の再編（不要区間の撤去）と併せて読めるが、新旧の配置の全体は本冊のみでは確定できない。
- **四谷粟留町の御本城掛分レ掛の蓋修復〔確認・周辺〕**: 「**四谷粟留町御本城掛分レ掛差蓋約二(ヶ所?) 櫓胴縄拾尋壱寸弐分廻り金弐百疋…合金拾三両壱分**」（2587544・巳十二月）＝**四谷粟留町の「御本城掛」（御本城への給水樋筋）の「分レ掛」（分岐の樋）の蓋の修復**（櫓胴縄・廻り金の入用つき）＝[GOV-269](GOV-269.md)制限③の「四谷粟留町の分レ掛」の精読分（「粟留町」の表記・帰属はOCR要照合・同一帳簿内に「兵部省前土州焼失跡取繕」〔霞が関の兵部省〕の入用があることから麹町区方面の御用と読めるが断定しない）。
- **四ツ谷大木戸水番屋構内の投渡橋〔確認・周辺〕**: 「**四ツ谷大木戸水番屋構内上水堀投渡橋同所構吹抜丸太柵其外共御普請御入用仕上**」（2587543・巳九月）——「**役橋渡三間巾三尺壱ヶ所右入用投渡剃木板橋共ニ遣**」「**芥除杭長(?)団間右入用杭木ニ遣杉丸太三拾本長弐間**」＝**四谷大木戸の水番屋構内の上水堀の投渡橋（板橋・渡3間巾3尺）と芥除杭（杉丸太30本）**の明治2年の修復＝江戸入口の水番所の施設の実態（[GOV-270](GOV-270.md)の文久3年の大木戸上水吐水・[GOV-268](GOV-268.md)の見廻り出立点と並ぶ大木戸水番屋の構内の記録）。
- **玉川上水羽村出水の大堰通の急破修復〔確認・周辺〕**: 「**玉川上水元羽村出水二付大堰通其外急破御普請仕様注文**」（2587543・水番人久茂十郎宛）——「**当七月十三日出水大堰通流失…牛(杵)九組…右仕様出水に而大堰通牛杵前引籠裏…流失深堀之場所出来上水堰入方差支候ニ付流失跡江仮〆切仕付…牛杵取建候ニ付…蛇籠打方大小投抜木掛渡水仕掛**」＝**羽村大堰の明治2年（同年正月13日と7月13日の出水）の被害と修復**（牛杵〔杭の牛組み〕の流失・仮締切・蛇籠）＝[GOV-268](GOV-268.md)の文久3年羽村出水（助水行政の発端）と並ぶ水元側の急破修復の実務記録（「牛杵」「牛杭」のOCR変種は原字形照合必須）。
