# [GOV-271] 神田玉川上水留 明治2年下半期 — 神田上水浜町元組合樋筋の全線修復と麹町樋筋→御本城への新規繋樋

- **書誌〔確認〕**: 『神田玉川上水留』明治二己年七月ヨリ十二月マデ分冊ノ四 [book/2587537](https://lab.ndl.go.jp/dl/book/2587537)（判事森左太夫・清水元一郎・鈴木包助宛の御普請仕様注文帳等）・分冊ノ四 [book/2587543](https://lab.ndl.go.jp/dl/book/2587543)（出来形仕上帳）・分冊ノ五止 [book/2587544](https://lab.ndl.go.jp/dl/book/2587544)＝[GOV-267](GOV-267.md)（白堀通修復の3段階帳簿）・[GOV-269](GOV-269.md)（水戸屋敷内掛樋）と同じ明治2年下半期冊の**玉川上水側・神田上水末端側の未精読部分**（[GOV-267](GOV-267.md)制限④・[GOV-269](GOV-269.md)制限③の一部に対応）。**引用文言はすべてOCR由来で要原文照合。**
- **神田上水浜町元組合樋筋の全線修復〔確認・repo初出の上水末端樋管網の定量記録〕**: 「**神田上水濱町元組会持樋筋御用懸り**」（冊頭）——「**神田上水浜町元組合持通筋御普請仕様注文 壱番埋枡ゟ六番堤枡迄一樋長延八拾七間壱尺大サ内法五寸(?)四二分木原(厚?)八寸 七番弐坪(?)ゟ拾六番出払(?)迄一円長延弐百七拾八間三尺大サ内法石同断 惣日(延?)合三百六拾五間四(尺?)…弐間樋六拾八本御在合相用差引弐間樋一日拾五本新組 右仕様折損難捨置候ニ付御普請之積**」＝
  - **神田上水の浜町の元組合持の樋筋（1番埋枡〜6番堤枡・7番〜16番の番号つき樋管群）の惣延365間余・2間樋68本の修復**＝**上水の末端の樋管網（番号つきの樋・枡の連続）の規模の定量記録**（repo初出）。「内法五寸」は明らかな誤読候補で寸法の数字はすべて要照合。「浜町」の帰属（神田側の浜町＝現中央区日本橋浜町方面か・神田橋寄りの浜町か）は要検討。
  - 「**右仕様樋枡伏渡出来後道長百八拾六間幅高(?)間三尺…公足之義は昌平橋御門内土手裾削り取持込保置候**」＝**樋枡の伏替後に江戸城昌平橋御門内の土手裾の削り取り・土の持込**の文言＝浜町樋筋の近傍が江戸城昌平橋御門内（江戸城北東・現皇居前の昌平橋）に及ぶことの傍証（「道長186間・幅3尺」の道路修繕の帰属の割付は要照合）。
- **麹町大通元組合樋筋→御本城掛樋筋への新規繋樋〔確認・repo初出＝維新後の皇城給水の実務〕**: 「**麹町大通元組合持通筋ゟ御本城掛樋筋え新規収原(?)樋掛仕付方并四谷御門外元組合樋筋之内樋押取壊方共御入用仕上帳**」（明治2年12月）＋「**麹町大通元組合樋筋ゟ御本城掛樋筋え新規繋樋掛仕付方并四谷御門外元組合樋筋之内樋掛取(押?)場方御入用仕上注文**」——「**樋長五間十一(?)…樋長寄て壱丈三尺五寸大大サ内法同長壱丈 麹町五丁目長壱人五寸(?) 四谷御門内竪壱人弐寸横壱尺四寸木厚三寸長壱丈六尺五寸…是は松元様長屋前に五間仕付候注文之処壱丈三尺五寸にて相済 外堀方壱丈は堀明口上**」＝
  - **玉川上水の麹町大通沿いの元組合樋筋から江戸城（皇城）本城への給水樋筋に「新規繋樋」（樋長5間・実際の仕上り1丈3尺5寸）を掛けた**明治2年12月の記録＝**維新後も御本城（皇城）への上水給水が現役で、麹町五丁目・四谷御門内で新規の樋掛が行われた**実務の一次記録（「松元様長屋前」「外堀方堀明口」の場所文言つき・人名「松元様」は要照合）。
  - 「**四谷御門外元組合樋筋之内樋押取壊方**」＝四谷御門外の旧元組合樋筋の一部を**取り壊した**記録＝麹町樋筋の再編（不要区間の撤去）と併せて読めるが、新旧の配置の全体は本冊のみでは確定できない。
- **『玉川上水留』明治2年分冊ノ四（2587348）の御本城掛樋筋の文言〔確認・repo初出の「西城掛」・代官町土手上経由の追記〕**: [GOV-237](GOV-237.md)に書誌リンクのみあった『玉川上水留』明治二己年分冊ノ四 [book/2587348](https://lab.ndl.go.jp/dl/book/2587348)（民部省土木司宛の上水屋敷の伺・届の綴か）に、御本城掛樋筋の内容が含まれることを今回確認した——
  - 「**八月廿五日 東京府上水屋敷改 御事 民部大目土木民 玉川上水四谷御門外元組合持掛廻高(?)抔共朽損浅水多 難差置候ニ付御修復可取計之処 当節御入用御出方高之折柄 模様替取潰 同御門内二而御本城掛樋並ゟ新規帳平樋仕付 組合通江分水いたし流末掛方差支無之様為致**」＝**四谷御門外の元組合持の掛廻（掛樋）が朽損して浅水が多い（水漏れ・減水か）ため、模様替（配置替え）で取り潰し、四谷御門内で御本城掛樋と併せて新規の帳平樋（平たい樋か）を仕付け、組合通に分水して流末の掛方の差支えがないようにした**＝前項の2587537等（12月の繋樋）に先行する同年8月の配置替えの決定文言（「高井」「将監」らしき人名・「帳平樋」の語は原字形要照合）。
  - 「**御本(小?)城掛之方は四谷御門外峰行町元掛二而掛ヶ増(?)代官町二手上扣々掛板二而分普差格いたし候得共何レも差支無之**」＝**御本城掛は四谷御門外の峰行町(?)の元掛（元の架設点）に「掛ヶ増」（掛け増しか）をして、代官町の土手上に「扣々掛板」（継ぎ掛けの板か）で分普差格（分岐の普請か）した**＝**御本城掛樋筋が麹町代官町の土手上を経由することの明治2年の明示**＝[GOV-279](GOV-279.md)（安政4-5年・「御本丸懸吹上懸共代官町土手上…定寸ニ相掛申候」）・[GOV-280](GOV-280.md)（安政4-5年・「代官町土手上ゟ御本丸掛矢来桝弐之枡」）と3点対応で、**御本城（丸）掛樋筋の代官町土手上経由が幕末から維新直後まで不変**だったことの傍証（「峰行町」の町名はOCR崩れの可能性が高く、四谷御門外の町名の比定は要照合）。
  - 「**御本城掛樋筋ゟ麹町大通組合樋江新規没等(収京?収東?)樋御普請取掛候処 前後取付候に付 御城内掛西城掛共丈樋御出来る六日水留いたし候段 土木司ゟ申越候**」（十一月）＝**御本城掛樋筋から麹町大通の組合樋へ新規の樋を掛ける普請に際し、前後の取付のために「御城内掛・西城掛」の双方の樋に対して6日間の水留を行った**＝**「西城掛」（西城=西之丸への給水掛り）の文言がrepo初出級**＝御本城掛のほかに西城（西之丸）掛・御城内掛の系統があることの明示で、[GOV-279](GOV-279.md)の御本丸掛・吹上掛と併せると、**維新直後の皇城給水が御本城（本丸）・西城（西之丸）・吹上の複数系統で構成されていた**可能性が強まる（各系統の分担は本冊のみでは確定できない）。
  - 「**御本城掛り樋筋ゟ組合樋に収東(?)樋仕付方御普請ニ付 四谷御門大番所前堀明 往来差支候間 明五日ゟ壱人宛往来相通 馬駕籠車差留候段 土木司ゟ申越候**」（十一月四日）＝**四谷御門の大番所前の堀明（掘り割り）の工事で往来に支障が出るため、人払いと馬・駕籠・車の差留めを行った**＝四谷御門前（現・新宿区四谷の外堀端）での給水工事の交通規制の実務記録。
- **四谷粟留町の御本城掛分レ掛の蓋修復〔確認・周辺〕**: 「**四谷粟留町御本城掛分レ掛差蓋約二(ヶ所?) 櫓胴縄拾尋壱寸弐分廻り金弐百疋…合金拾三両壱分**」（2587544・巳十二月）＝**四谷粟留町の「御本城掛」（御本城への給水樋筋）の「分レ掛」（分岐の樋）の蓋の修復**（櫓胴縄・廻り金の入用つき）＝[GOV-269](GOV-269.md)制限③の「四谷粟留町の分レ掛」の精読分（「粟留町」の表記・帰属はOCR要照合・同一帳簿内に「兵部省前土州焼失跡取繕」〔霞が関の兵部省〕の入用があることから麹町区方面の御用と読めるが断定しない）。

## 制限・未解決

- ①すべてOCR由来で数字（惣延365間・2間樋68本・内法五寸・樋長5間・1丈3尺5寸等）・「浜町」「出払」「弐坪」「粟留町」「松元様」「収原」「峰行町」「帳平樋」「没等樋/収京樋/収東樋」等の割付・町名・人名・書名は原文照合必須。②「御本城掛樋筋」の経路は、本冊の2587348の文言（四谷御門外峰行町(?)元掛・代官町土手上・四谷御門内）と[GOV-279](GOV-279.md)/[GOV-280](GOV-280.md)の安政期の文言（代官町土手上・御本丸掛・吹上掛・清水御門山張番所脇）で経由地の輪郭（四谷御門外〜代官町土手上〜御城内）が裏付けられたが、全経路の確定には[MAP-175](../maps/MAP-175.md)の線路図・[GOV-270](GOV-270.md)の山下御門・幸橋御門内吐樋口の文言との対校が依然必要。「西城掛」の西城=西之丸の読みと、御本城・西城・吹上の各系統の分担は推定として原字形照合を要す。③「浜町元組合樋筋」の町名の帰属は要検討（神田上水の末端の浜町の位置の特定には江戸の町割図との照合が必要）。④2587543・2587544のその他の内容（白堀通の既載分・麻布の道造・春桃院門前の下水石垣等）は[GOV-267](GOV-267.md)・[GOV-269](GOV-269.md)の既載・周辺で新規datapointなし。⑤2587348の御本城関連以外の内容は[GOV-237](GOV-237.md)既載の竹樋関連と重なるが、同冊の全容の再点検（他の新規文言の有無）は次回に回す。
