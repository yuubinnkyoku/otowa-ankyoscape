# [GOV-407] 帝国図書館件名目録・書名目録の「井頭上水役由緒」記録 — 著者内田茂重・叢書甲集第七三冊献上系の目録記録〔第168回〕

- **書誌〔確認〕**: 『帝国図書館和漢書件名目録』第2編（NDL次世代デジタルライブラリー [book/991349](https://lab.ndl.go.jp/dl/book/991349)）・『帝国図書館和漢図書書名目録』第3編（[book/991348](https://lab.ndl.go.jp/dl/book/991348)）（いずれも明治期の帝国図書館の目録刊本）。**引用文言はすべてOCR由来で要原文照合。**
- **件名目録の記録〔確認・文言候補・repo初出〕**: 件名目録第2編の水道の項に「**井頭上水役由緒 內田茂重著 献叢書甲集第七三册**」＝**「井頭上水役由緒」という書（著者内田茂重）が叢書甲集第七三冊へ献上された旨の目録記録**〔**①[GOV-406](GOV-406.md)（東京府文献叢書[31]甲集総目の「第七十三冊井頭上水役由緒書…」）の書目記録に対応する帝国図書館側の目録記録、②著者の特定（內田茂重〔総目の「内田某」に対応候補〕）と献上系（「献叢書甲集第七三册」）の記録＝『井頭上水役由緒書』が東京府文献叢書甲集第七十三冊として収蔵・整理された経路の手がかり、③NDL次世代DLの全文横断検索では甲集第七十三冊本体（『井頭上水役由緒書』の本文）を含むデジタル化冊子は確認できず（陰性観察）、本文確認には第七十三冊の写しの現物（静嘉堂『井頭上水由緒』〔[GOV-384](GOV-384.md)〕との異同確認を含む）が必要**。件名目録の同項の隣接記載（牢屋舗年曆・永代寺門前書・小金井櫻植添申上等）は総目の第七十三冊書名群と一致〕。
- **書名目録の記録〔確認・文言候補〕**: 書名目録第3編に「**イノカ井頭上水役由緒錄イノカ井頭上水役由緒錄牢屋舗年曆、上小金井櫻植添申上、永代寺門前書…**」＝**「井頭上水役由緒錄」の書名見出し（「錄」の字のある別表記も見える）＋第七十三冊書名群の同居記録**〔件名目録と合わせ、書名表記が「井頭上水役由緒」／「井頭上水役由緒錄」で揺れる目録記録。「由緒書」〔GOV-406〕との表記差を含め、正書名の確定は原冊確認まで保留〕。
