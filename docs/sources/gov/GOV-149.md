# [GOV-149] 東京都「気候変動を踏まえた河川施設のあり方」（令和5年12月策定）〔repo初出〕

- **書誌〔確認: プレスリリース本文・2026-11-15取得〕**: 東京都建設局のプレスリリース「[『気候変動を踏まえた河川施設のあり方』の策定について](https://www.spt.metro.tokyo.lg.jp/tosei/hodohappyo/press/2023/12/18/11.html)」（**2023年12月18日**・建設局河川部計画課）。学識経験者等による「気候変動を踏まえた河川施設のあり方検討委員会」の検討に基づき策定されたもの。
- **中小河川の洪水対策〔確認: プレスリリース本文〕**: **「将来の気候変動により増加する降雨に対して河川からの溢水を防止する」ため、目標整備水準を「気候変動を踏まえた年超過確率20分の1の規模の降雨」に引き上げ**、調節池等を活用した効率的・効果的な対策を推進。加えて**トンネル式調節池を海等へ延伸し、線状降水帯のような数時間降り続く豪雨に対しても継続的に効果を発揮できる地下河川などの流下施設**、および**容量の相互融通を図り、局地的な時間100ミリを超える豪雨にも効果を発揮できる調節池のネットワーク化**など、多様な降雨を考慮した新たな整備手法の追加。
- **低地河川の高潮対策等〔確認: プレスリリース本文〕**: **0.6メートルの海面上昇と930ヘクトパスカルに強大化した伊勢湾台風級の台風**がもたらす高潮への対応へ引き上げ、防潮堤の嵩上げ・スーパー堤防の整備など各河川に応じた対策。
- **意義〔観察〕**: [GOV-148](GOV-148.md)（2026年11月の「調節池の広域的な整備に向けた検討委託（その２）」公告・対象に神田川流域を含む）が根拠と明示する政策文書であり、神田川水系（谷端川・弦巻川・水窪川の暗渠・下水道幹線の受け皿）の治水施設の方向性（1/20降雨の目標整備水準・調節池のネットワーク化・地下河川化）を初めてrepoに固定する。
- **第92回追記〔確認: 別添概要版PDFの本文抽出・2026-11-15取得〕**: 第91回にWAF遮断で未取得だった別添「気候変動を踏まえた河川施設のあり方（概要版）」を[11_01.pdf](https://www.spt.metro.tokyo.lg.jp/tosei/hodohappyo/press/2023/12/18/documents/11_01.pdf)（949,526bytes・PDF1.6・リファラ・ブラウザUA指定で取得成功）から全文抽出し、以下を確認した:
  - **10流域の一部列挙〔確認・repo初出〕**: 「東京都豪雨対策基本方針(改定)(令和5(2023)年12月)に基づき、**10流域（神田川、石神井川、白子川、野川、境川等）**において優先的に対策を実施」〔**神田川が10流域の筆頭に挙げられている**。谷端川・弦巻川・水窪川の受け皿河川として、この優先流域指定は四河川の治水文脈に直接響く。残る5流域名の確認は今後の「豪雨対策基本方針（改定）」本文確認課題〕。
  - **「CC 1/20」の定義〔確認・repo初出〕**: 気候変動を踏まえた年超過確率1/20の規模の降雨の略記。**降雨量は実績降雨データから確率雨量を算出した降雨量に対し、2℃上昇時における降雨量変化倍率（1.1倍）を乗じて設定**。観測所は**区部＝大手町・多摩＝八王子**を引き続き採用。「過去に浸水被害をもたらした降雨でも河川からの溢水が概ね解消」を整備目標の説明として明記〔神田川流域計画（[GOV-124](GOV-124.md)）の目標降雨改定の計算方式がわかる。大手町観測所採用は区部の中小河川一律〕。
  - **地下トンネル式調節池の新たな整備手法〔確認〕**: ①**流下施設の整備**＝「洪水を取水し続けることが可能な地下河川などの流下施設の整備」「下流の海等へ放流」、②**複数調節池の連結によるネットワーク化**＝「地下トンネルで複数の調節池を広域的に連結」「調節池容量を相互融通できる調節池のネットワーク化」。「地下トンネル式は、必要な事業用地が比較的小さく、複数の地点・流域から洪水を取水でき、施設規模やルートの柔軟な設定が可能」。
  - **低地河川の高潮対策の必要嵩上量〔確認〕**: 気候変動（2℃上昇）を考慮した伊勢湾台風級（930hPa）の高潮対応、海面水位の上昇量は2℃上昇の最大値相当の0.6mに設定。必要嵩上量と対策必要時期は**城南河川0.3〜0.5m（2040〜2060年代）・隅田川及びその支川0〜0.9m（2050〜2080年代）・中川・旧江戸川0〜0.6m（2050〜2080年代）**〔各河川の整備内容・時期は今後策定する「河川における高潮対策整備方針（仮称）」で整理〕。
  - **5つの視点〔確認〕**: ①激甚化する風水害から都民の命とくらしを守る②多様な降雨にも対応③既存ストックを最大限有効活用④まちづくりと一体⑤ソフト対策の強化。時間50mm以上の降雨発生率が増加傾向（昭和53年〜平成30年の経年変化グラフ）・東部低地帯の地盤高概念図（A.P.+2.1m）も掲載。
- **制限・未解決（第92回更新）**: ①概要版はスライド形式で、残る10流域のうち5流域名（「等」の部分）は未確認（「東京都豪雨対策基本方針（改定）」（令和5年12月）本文の入手が必要）。②神田川流域への具体的適用（調節池新設・地下河川延伸の候補ルート）は依然未特定。③10流域の優先順位・整備スケジュールは未確認。
- **第92回追記〔確認: 産経ニュース2026-10-21記事〕**: 産経新聞「[環七地下に直径12.5メートルの巨大トンネル 東京都最大級の地下防災インフラを歩く](https://www.sankei.com/article/20261021-CPWEAVLUN5NABPRS7XSJU3P7MI/)」（2026年10月21日・桑波田仰太）の都見学会取材記事で、①**都は2026年（令和8年）3月に有識者による検討委員会を設け、地下調節池の東京湾までの延伸（地下巨大河川構想）の基本構造などの検討を進めている**〔**「今年3月に検討委員会設置」という2026年の動きの報道はrepo初出**。都第三建設事務所の岡田理志課長の「ためるだけでは限界…地下空間を可能な限り活用」発言を引用〕、②**環七地下調節池と白子川地下調節池（練馬区）を結ぶ連結工事が平成29年に開始済みで、完成すれば総延長約13km・貯留量約143万m³（現在の約2倍）**〔**白子川連結の規模の具体（13km・143万m³・1時間100mm級対応）もrepo初出**。本資料の「調節池のネットワーク化」の実施例〕、③令和元年東日本台風で容量の約9割（約49万m³）を貯留し神田川の水位を最大約1.5m低下させた推計・2026年6月台風6号の取水痕跡〔環七地下調節池の実績値の報道確認〕。④見学会は都が民間事業者（見学会拡大パートナー）と連携して拡大しており、2026-11-02都建設局プレスで**2027年1月9日〜の「神田川・環状七号線地下調節池インフラツアー」**が告知されている（[都庁プレス](https://www.metro.tokyo.lg.jp/information/press/2026/11/2026110202)）〔撮影・見学会情報は参考〕。
