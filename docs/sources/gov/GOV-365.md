# [GOV-365] 御府内場末往還其外沿革圖書 貮拾壱元上（安政3年10月調）— 本浄寺引移宝永4年説の幕府帳簿系統の第3傍証〔第160回〕

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』の[31]冊「貮拾壱元上」（**安政三辰年〔1856〕十月調**）。NDL次世代デジタルライブラリー [book/2587248](https://lab.ndl.go.jp/dl/book/2587248)。表紙文言に「**安政三辰年十月調 御府内場末往還沿革図書弐拾壱元え□ 下谷谷中本村東叡山下駒込村根津新堀村谷中金杉村一円之絵図壱枚**」（OCR崩れあり）とあり、**谷中本村・下駒込・根津・新堀村・金杉村の一円を収める帳**（新堀村を含むため新堀用水研究の文脈でも参照される）。**くずし字帳簿でOCR崩壊が大きく、引用文言はすべて原画像照合を要する。**
- **水戸殿中屋鋪の地所書上と本浄寺境内の宝永4年上ケ文言〔確認・文言候補・核心〕**: 駒込水戸殿中屋鋪（池之端七軒町・根津宮永町辺之部）の地所書上に「**右一圓之地所延宝年中は西北間西丸御旗与力同心同御鎗同心大縄地 本浄寺境内 宝永四亥年頃上ケ也に成**」＋「**宝永四亥年頃 西北間本浄寺境内上ケ地 本浄寺代地は雑司ヶ谷目澄院領之内ニ而被下に成 其後右上け地何之地ニ相成候哉不詳**」＝**①当所（水戸殿中屋鋪一円）は延宝年中は西丸御旗与力・御鎗同心の大縄地と本浄寺境内だった、②本浄寺境内が宝永4年（1707）頃に上ケ地となり、③本浄寺の代地は雑司ヶ谷の「目澄院」領の内に下し置かれた、④以後の上ケ地の処分は不詳、という沿革記述**〔**「目澄院」は「自澄院」＝自証院（圓融寺。〔GAZ-073〕のOCRでも「自澄院」と崩れる）のOCR変種候補**。要原画像照合〕。
- **本浄寺引移宝永4年説の第3の独立傍証〔観察・時系列〕**: 本冊は幕府御普請方の帳簿（町方・寺社側でない官側の系統）であり、①[GAZ-073](../gazetteers/GAZ-073.md)（市谷寺社書上・圓融寺自證院条）の「**宝永四亥年八月中 根津権現在御造営に付駒込ニ有之候本浄寺当村引移候ニ付…下板橋村之内御林跡ニ而御代地被下置候**」（寺社側書上）、②[GAZ-075](../gazetteers/GAZ-075.md)（本浄寺側の記録）に続き、**官側帳簿の地所沿革として「本浄寺境内＝宝永四亥年頃上ケ」を記す第3の独立系統の傍証**となる。③[GAZ-072](../gazetteers/GAZ-072.md)（文政寺社書上の本浄寺条）の「寛永4年」引移説との対立では、**宝永4年（丁亥・根津権現宝永期御造営）側の根拠が系統の独立した3点で揃う**＝寛永4年説との対校関係は変わらず維持するが、宝永4年側が強化された（孰れが正しいかは原画像照合まで断定しない）。④特に本冊の文言は「本浄寺代地は雑司ヶ谷自証院〔OCR候補〕領の内に下された」という**収用された側（駒込の上ケ地の所有者・本浄寺）への代地の所在（雑司ヶ谷の自証院領の内）を官側帳簿が記す**点で、[GAZ-073](../gazetteers/GAZ-073.md)②の「下板橋村御林跡の代地」（雑司ヶ谷村高内の自証院朱印地が収上げられ、その代地が下板橋の御林跡とされた寺領側記録）と**方向が逆の同一事件の記録**（本浄寺の駒込屋敷地の収用→代地は雑司ヶ谷の自証院領の内）として整合する〔両書の「代地」の対象（本浄寺の駒込地か、自証院の雑司ヶ谷朱印地か）の対応関係はOCR文言の照合が前提で、細部の同定は断定しない〕。
- **享保5年以降の処分〔確認・文言候補〕**: 「**享保五子年正月 前書本浄寺上ケ地之内富永孫十郎当職屋鋪ニ被下 割残地小笠原喜三郎御養え御預に成**」＋同年九月の竹内甚右衛門屋鋪・寛保延享之頃の内崎治兵衛屋鋪など＝**本浄寺上ケ地（水戸殿中屋鋪に囲込）の享保5年（1720）以降の旗本屋鋪への処分の年代層**（水戸殿中屋鋪への小笠原信濃守抱屋鋪の天保6年相対替・囲込の文言と連なる）。

## 制限・未解決

- ①本帳はくずし字でOCR崩壊が大きい。引用文言（本浄寺・目澄院・富永孫十郎・水戸殿中屋鋪）はすべて原画像照合を要する。②「目澄院」＝自証院（圓融寺）の比定はOCR変種候補（「自澄院」との字形関係を含め原字照合が前提）。③本浄寺代地の「雑司ヶ谷目澄院領の内」が[GAZ-073](../gazetteers/GAZ-073.md)②の下板橋村御林跡代地と同一事件のどの部分に対応するかの細部同定は原画像照合まで保留。④宝永4年説と寛永4年説（〔GAZ-072〕）の対立の最終解決は本帳だけではできない。⑤新堀村巻としての新堀用水の文言の有無の精査は今後課題（本回は水戸殿中屋鋪・本浄寺関連で抜粋）。
