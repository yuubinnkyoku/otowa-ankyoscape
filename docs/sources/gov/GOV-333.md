# [GOV-333] 明治39年埼玉県統計書 第一卷（1907）— 榑橋村移管の6月文言（移管元の統計書）

- **書誌〔確認〕**: 埼玉県『明治39年埼玉県統計書 第一卷（土地、戶口及雜部）』（埼玉県・明治40年〔1907〕4月頃刊・明治39年事実）。NDL次世代デジタルライブラリー [book/806489](https://lab.ndl.go.jp/dl/book/806489) のOCR全文を確認。**引用文言はOCR由来で原文画像との照合を要する**。
- **管轄地沿革＝榑橋村移管の明治24年6月〔確認・repo初出＝月の対立の6月側の最有力datapoint〕**: 管轄地沿革の新座郡条に「**二十四年六月新座郡榑橋村ヲ東京府北豐島郡石神井村ノ內元上土支田村ト合併シ大泉村ト稱シ**」＝**①榑橋村（新座郡）の東京府北豊島郡への移管が明治24年6月であることを移管元の埼玉県の統計書が明記**、②**「榑橋村」の表記がOCRで正確に現れる**（[GAZ-063](../gazetteers/GAZ-063.md)（北足立郡誌・1924）の「樽橋村」が榑橋村のOCR誤読候補であることを補強する、誤読を介さない「榑橋村」表記の行政文書側の出現）、③**「石神井村ノ內元上土支田村ト合併シ」という表現**＝榑橋村が石神井村の大字上土支田（東京府側の既存村域）と合併して大泉村となった構造を「石神井村ノ內元上土支田村」の語で表現（[GOV-331](GOV-331.md)（大泉村現状調査・1931）の「(明治二十)四年六月前記三大字ヲ合併シテ現在ノ大泉村ヲ創設」・[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌・1918）の「石神井村に屬せし大字上土支田と合して一村となり、大泉村と稱せり」と対校可能な移管元側の文言）。
- **意義〔観察〕**: 大泉村成立期日の「月の対立」（6月派：本書・[GAZ-063](../gazetteers/GAZ-063.md)（北足立郡誌・1924）・[GOV-331](GOV-331.md)（大泉村現状調査・1931）・Wikipedia（6月15日）／9月派：[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌・1918）・[GOV-198](GOV-198.md)（北豊島郡総覧・1931「明治二十四年九月村の組織を定めらるゝ」））において、**移管元の県が自県の管轄喪失の年月として記録する「六月」は行政記録としての重みが大きい**。ただし9月側の文言（村の組織確定・村長選任）と内容が別事象（移管・合併＝6月／村組織・村長選任＝9月の2段階）である可能性も含め、**官報明治24年の告示の確認までは断定しない**（READMEの月の対立の整理を参照）。
- **本書の性質〔観察〕**: 明治39年（1906）の埼玉県の統計書で、榑橋村の移管（1891）は管轄地沿革の過去事実として採録される。**保谷村の北足立郡への所属（明治29年新座郡廃止以降・明治40年移管直前）の記録も管轄地沿革に含まれる**（保谷村の移管（明治40年4月1日・[GOV-330](GOV-330.md)）は本書の刊行（明治40年4月頃）とほぼ同時期で、採録の有無はOCR精読の範囲では未確認・断定しない）。

## 制限・未解決

- ①文言はOCR由来で原文照合を要する（特に「榑橋村」の字面・「六月」の数字）。②保谷村の明治40年移管の採録有無は未精読（本書刊行と移管の先後が近接するため、採録時点の措置が不明）。③官報明治24年（1891）の榑橋村移管の告示（太政官達・内務省達等）は未発見で、6月/9月の対立の最終的な解決は官報レベルの確認待ち。④「石神井村ノ內元上土支田村」の「元」の語の正確な範囲（元＝旧来の村域という意味か、旧村名か）は本書からは確定しない。
