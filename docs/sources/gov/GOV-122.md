# [GOV-122] 東京都下水道局『技術調査年報 -2013-』送泥管敷設事業・千駄ヶ谷幹線SPR施工の2記事〔repo初出〕

- **書誌〔確認: Wayback保存版PDF全文取得〕**: 東京都下水道局『**技術調査年報 -2013-**』（**平成25年（2013）12月発行**、平成24年度実施分、下水道局長 松浦將行）所収の2記事。原本PDFは東京都オープンデータで公開されていた〔[オープンデータURL](https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2013all.pdf)・2026年11月時点の直接アクセスは403で、[Wayback保存版 id_ 2024-05-18](https://web.archive.org/web/20240518150408id_/https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2013all.pdf)（本体9,348,371バイトを取得・本文抽出）で全文確認〕。**印刷頁とPDF頁はずれがあるため、頁数は本文頁フッタのノンブルで確認**。
- **記事1〔確認: 本文（テキスト抽出）〕**: 三瓶武史（第一基幹施設再構築事務所 設計課 設計第二係）「**落合水再生センター～みやぎ水再生センター間送泥管敷設事業**」**印刷頁43～49**（各頁フッタ-43-～-49-で確認・p.48相当頁のフッタは抽出時に欠落）。
  - 東京都区部では13ヶ所の水再生センターで発生した汚泥を5ヶ所の汚泥処理施設へ**総敷設延長約80kmの送泥管**で輸送。老朽化・耐震対策として今後の新設送泥管は**シールド専用管廊方式・予備管込み2条同時配管**とする方針の**最初の事業**。
  - 落合水再生センター（新宿区・中野区・杉並区等の下水を処理、**落合処理区流域面積3,506ha・計画人口約68万人**）の汚泥はみやぎ水再生センター経由で東部汚泥処理プラントへ。**既設送泥管約10kmは直接埋設が90%以上で昭和38年（1963）から約50年稼働**。破損時に**2日以内に復旧できなければ所定の放流水質を確保できず、放流先である神田川の流域人口約165万人に影響**と述べる。
  - 送泥管**φ400mm×2条**・管廊**内径2600mm**（維持管理スペース幅900mm×高さ2000mm）、**約3km毎に管理人孔/立坑**、シールド外径約3000mm・最小曲率半径15m。**ルートは3案から総延長約9.9kmの案を採用**。
  - 当初の**3工区案**では中間立坑用地**板谷公園**をシールド発進基地とする必要があり借用期間が長くなるため、**2工区案**（みやぎ側発進約6.7km＋落合側3.2km）に変更し、板谷公園は**通過立坑**（面板交換等メンテナンス）とした。板谷公園の作業ヤードも発進立坑計画の約1,400m²（公園全体の約1/4）から約1,000m²（約1/8）へ縮小、利用者の少ない公園中央部へ移設。
  - **図6（3工区案）・図7（2工区案）のルート図上に「谷端川親水公園」「王子六丁目公園」が地点名として描かれる**〔観察: 図面テキストの判読〕。本文の明文で役割を説明されるのは板谷公園のみで、両公園の採不採・立坑候補としての扱いは本文に明記されないため**断定しない**。
- **記事2〔確認: 本文（テキスト抽出）〕**: 比護一裕（第二基幹施設再構築事務所 工事第一課 工事第二係）「**大断面蓋掛け渠におけるＳＰＲ工法の施工 －千駄ヶ谷幹線再構築工事－**」**pp.67-68**。
  - **千駄ヶ谷幹線（渋谷区神宮前五・六丁目）は昭和38年（1963）施工の延長3,020m・最大断面5.75×3.70m級の大断面蓋掛け渠**。このうち**延長224.5mをSPR工法（更生断面5.75×2.93m～5.75×3.70m）で再構築**、工期**平成24年5月30日～平成25年10月25日（349日間）**、全期間深夜間（21～6時）施工。表-1のSPR施工実績（自由断面）は**渋谷川幹線5.75×3.85m（施工済）／千駄ヶ谷幹線5.10×3.32m（施工済）／千駄ヶ谷幹線5.75×3.70m（当工事）**で、**更生断面の幅が5.0mを超えるのはこの2路線3件のみ**とする（いずれも東京都下水道局発注）。
  - 施工環境として、千駄ヶ谷幹線上の通りは**「キャットストリート」と呼ばれ、東京オリンピックの開催をきっかけに渋谷川にそのまま蓋をして暗渠化したもので、正式名称は「旧渋谷川遊歩道」**と説明し、**暗渠沿いにはかつて架かっていた橋の親柱が現在もいくつか残されている**と記す〔確認: 本文の記述。親柱の特定橋名は本文に明記なし〕。
- **位置づけ〔観察〕**: 記事1は**谷端川上流域（豊島区池袋）の谷端川親水公園と王子六丁目公園が、都の送泥管ルート計画（平成24年度調査）の図面に立坑関連地点として現れる**記録で、親水公園の下水道施設用地としての側面の資料。神田川を放流先とする落合処理区（弦巻川・水窪川流域の下水を含む）と、谷端川幹線の流末であるみやぎ水再生センターを結ぶ汚泥輸送網の整備史でもある（[GOV-123](GOV-123.md)・README既述の2014年報池袋実施設計記事との接続）。記事2は**水窪川の合流先である渋谷川の下流（千駄ヶ谷～神宮前）の暗渠幹線**の構造史で、昭和38年施工・5.75m幅級の大断面蓋掛け渠という同時代（[GOV-105](GOV-105.md)千川の昭和9年暗渠化・[GOV-119](GOV-119.md)2008年報と連なる年代軸上の技術資料。渋谷川流域は四河川流域外のため、水窪川→渋谷川の下流側技術史の文脈で記録する。
- **同書既述記事**: 出野貴章「大規模な道路切回しを伴う既設幹線の改造について」（pp.59-62）はREADME §谷端川（補助173号線・谷端川上幹線）で既述・本レコードでは重複記載しない。
