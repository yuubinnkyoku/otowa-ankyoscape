# [GOV-189] 玉川上水留 慶応3卯年12月（分水口場所替伏下ヶ一件帳・分冊一）

- **書誌〔確認〕**: 『玉川上水留』（御作事方・慶応3卯年12月・分水口場所替伏下ヶ一件帳・分冊一）。NDL次世代デジタルライブラリー [book/2587452](https://lab.ndl.go.jp/dl/book/2587452)（分冊二＝[book/2587453](https://lab.ndl.go.jp/dl/book/2587453)）。**すべての引用は同館OCRテキスト由来であり、文言・寸法は原文画像との照合を要する。**主要な一件は福生村名主十兵衛による呼井（飲用水取入口）新規願の吟味・評議。
- **千川口の幕末開度〔確認・repo初出の1867年観測点〕**: 「**三田口定式三歩明 千川口当節四歩明**」「**千川用水夏分三郎（？）新場所 冬春皆留之場所 樋長三間大**」＝**千川用水元樋口の慶応3年（1867）時点の開度が定式（三田口三歩）より広い「四歩明」であった**旨の記録・樋長三間。〔元文4年の樋口寸法（「壱尺ニ弐尺五寸」）等の寸法変遷（GOV-170系）に1867年の観測点を追加。寸法単語の判読はOCR要照合〕。
- **瀧之川村水車の水不足〔確認〕**: 「**瀧之川村雁入水車掛水不足之趣 此上千川用水元樋口ニ而掛増之程モ難計**」＝滝野川村の水車の水不足と、千川用水元樋口での「掛増」（水嵩増し）の可否を巡る議論＝**幕末の水車争論に1867年の官文書を追加**（[GOV-144](GOV-144.md)慶応2年千川用水稼水車書付の翌年）。〔文言はOCR要照合〕。
- **分水願済先例一覧〔確認〕**: 安永4未年下高井戸村・天保2卯年・**天保12丑年「千川用水秋ゟ翌春迄皆留之場所村々呑水丈ヶ差暮明願済」**・弘化3午年角筈村松平摂津守下屋敷・嘉永文子年芝高輪松平薩摩守下屋敷（三田用水）等＝**千川用水の「冬春皆留」期の村々への飲用水分珠（呑水）先例が台帳に列挙**されている。〔文言はOCR要照合〕。

- **分冊二（[book/2587453](https://lab.ndl.go.jp/dl/book/2587453)）の千川関連記録〔確認・要照合〕**: ①「水料見合年々一金壱両宛 弥嶋村・砂川村・小川村…右村々引取分水**呑水田用水仕料金年之金三分**」＝**千川用水組合17ヶ村の水料台帳記録**（村々の引取分水・呑水田用水の仕料＝年金三分）。②「右は**田用に付年々秋ゟ翌春まて保谷新田地先元樋口にて津田留之場所**に候処…皆留時節…天保二卯年願済以来水料書面之通上納」＝**秋〜翌春の元樋口（保谷新田地先）での留め運用**の一次記録〔「津田留」は「皆留」のOCR誤読の可能性高。「天保二卯年」（1831）は分冊一の「天保12丑年」（1841）「秋ゟ翌春迄皆留之場所…願済」と年次が食い違い、いずれが正かは要照合〕。対になる三田用水条（北沢村地先元樋口・嘉永五子年願済）と併記される。③「**近来三田千川両用水路江御用水車御取建 右両樋口之儀者田方養時節斗味掛之場所ニ候處 御取建以来者年中定水掛り相成 御水御用多ニ候間**」＝**幕末に三田・千川両用水に御用水車が取建られ、両樋口の運用が「田方養時節のみ掛り」（季節運用）から「年中定水掛り」（通年定水）に変わった**記録＝分冊一の千川口開度（当節四歩明）・瀧之川村水車水不足と連続する、千川用水の幕末運用変化を示す一次文言〔いずれも文言はOCR要照合〕。

## 制限・未解決

- ①「四歩明」の「歩」の正確な寸法換算は未確認（元樋口寸法体系との対応は要検討）。②「掛増之程モ難計」の帰結（実施されたか否か）は分冊内では未確認。③分冊二（2587453）は千川関連の主要部分を精読・追記済み。ただし同冊の他の一件（福生村水車関係等）は未精読部分が残る。
