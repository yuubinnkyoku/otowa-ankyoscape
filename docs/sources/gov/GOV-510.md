# [GOV-510] 東京都建設局「野川第一・第二調節池地区 自然再生全体構想」1.2・1.3〔repo初出・野川の水系接続史（六郷用水系統化と戦後切り離し）・断面変遷・水量変遷・四割の堰・湧水64か所の都公式文言〕

- **書誌〔確認: 都建設局公式頁・2026-11-22取得〕**: **「野川第一・第二調節池地区 自然再生全体構想」**（平成18年9月・**野川第一・第二調節池地区自然再生協議会**・事務局＝東京都建設局）。都建設局公式頁「自然再生全体構想」の構想PDF群（`/documents/d/kensetsu/000006712`〔1.2節〕・`000006713`〔1.3節〕）＝**環境省サイトミラー（env.go.jp/content/900493739・900493741）で本文テキスト抽出に成功**（open_url経由・抽出元は「Microsoft Word - 全体構想 案 １章－１.doc」由来のテキスト層）。引用は抽出テキスト由来で**要原画像照合**。同頁には実施計画書（000006721=000006724）も掲載。
- **野川流域の概要〔確認: 1.2.1本文直接引用〕**: 「**野川は、多摩川の一次支川であり、国分寺東恋ヶ窪の㈱日立製作所中央研究所敷地内の大池に端を発し、国分寺崖線の湧水を集めながら崖線下をほぼ南東に流れ、小金井市、三鷹市、調布市、狛江市を経て、世田谷区二子玉川付近で多摩川へと合流する、流域面積69.6k㎡（仙川流域、入間川流域を含む）流路延長20.2kmの一級河川である**」＝**野川上流端＝日立中央研究所敷地内の大池・流域面積69.6㎢（仙川・入間川流域を含む）・流路延長20.2kmの現在値の都公式整理**。
- **玉川上水開通と野川水量の増大〔確認: 1.2.1本文直接引用〕**: 「**野川流域の土地利用と水文条件を大きく変えたものとして、江戸時代（承応3年・1654年）の玉川上水の開通があげられる。江戸市民の飲用水として開発された玉川上水は33ヶ所の分水口から武蔵野台地の各地に導水され、野川流域では分水路の一つである砂川分水、そこから分岐する国分寺分水、小金井分水により、飲用水及び灌漑用水として導水された。流末が野川や仙川に入ることで、水量は大きく増加した**」＝**玉川上水（1654開通）→砂川分水→国分寺分水・小金井分水→流末が野川や仙川に入ることで水量大きく増加、という野川・仙川の玉川上水系水収支の骨格の都公式文言**＝[BOOK-234](../books/BOOK-234.md)（分水機構）・[GOV-505](../gov/GOV-505.md)（田用水）体系のマクロ版。
- **明治前期〜昭和初期の野川河道断面と流量〔確認: 1.2.1本文直接引用〕**: 「**明治前期における野川の河道断面は幅２間（約3.6m）、土揚５尺（約1.5m）の素掘り水路であった。昭和初期は幅約4m、深さ約2mの柵渠もしくは木柵工の水路で、日量43,800㎥程度の流量があったと推定されている**」＝**野川の断面史（明治前期＝幅3.6m・深さ1.5m素掘り→昭和初期＝幅4m・深さ2m柵渠/木柵工・日量43,800㎥）の定量文言**＝[BOOK-247](../books/BOOK-247.md)（低湿地遺跡の「水利遺構〔7m×3m版築土留め＋杭列〕」）の古墳前期断面との時代対比に、近代断面の定点を付けた。
- **六郷用水系統化と戦後切り離し〔確認: 1.2.1本文直接引用〕**: 「**下流域では、江戸時代の初めに六郷用水が開削され、それまで多摩川に合流していた野川は六郷用水に流入するようになり、入間川、仙川も同様に六郷用水に併せられた。戦後に入り、東京への人口集中と市街地の拡大に対応する河川改修事業が実施され、下流域は六郷用水から切り離され、再び多摩川に合流するようになり、改修事業の進捗とともに現在の野川流域の姿ができあがった**」＝**江戸初期＝野川は多摩川合流→六郷用水開削で六郷用水流入へ（入間川・仙川も同様）→戦後の河川改修で六郷用水から切り離され再び多摩川合流、という野川・仙川・入間川3河川の下流端接続の系列の都公式文言〔repo初出〕**＝水系接続史の大筋を1節に持つ重要文献（六郷用水開削の時代「江戸時代の初め」の詳細年は本文では未特定）。
- **四割の堰〔確認: 1.2.1（2）本文直接引用・独立裏付け〕**: 「**昭和初期～中期の野川には、四割の堰があり、周囲に多くの用水路や溜池があった。川の周囲には水田が広がっていた**」＋「**昭和５年当時の地利水利図…はけの森の山の手側と野川周辺にいくつかの貯水池（ため池）があることがわかる。四割の堰付近には他よりもやや大きな貯水池（ため池）があることが記載されている**」＝**四割の堰の存在時期＝「昭和初期～中期」・周囲の用水路・溜池群・昭和5年地利水利図の「四割の堰付近には他よりもやや大きなため池」の文言＝[GOV-505](../gov/GOV-505.md)（四割堰＝中前橋下流東・小金井市域で最後まで残った堰）の都建設局側からの独立裏付け文言**（位置の同定〔中前橋下流東〕は GOV-505 側由来）。
- **水量減衰と水質史〔確認: 1.2.1（2）本文直接引用〕**: 「**国分寺、小金井付近より発する野水を集めた川の流れは湧水量で現在の2倍程度、野川の水量で10倍近くもあったとの報告（土屋十圀氏）もある**」＋「**人口の増加と高度成長期の産業発展などにより、野川の水質は1965年前後をピークとして急速に悪化し…1970年には周辺で最後の田んぼもなくなった。また、市街化による湧水の減少、1965年の玉川上水の通水停止、下水道の普及などにより野川の水量は著しく減少し、近年は渇水期にたびたび涸渇するようになった**」＝**土屋十圀報告（湧水2倍・野川水量10倍）・水質悪化ピーク1965年前後・最後の田んぼ消失1970年〔[GOV-508](../gov/GOV-508.md)の「最後の田植え＝昭和45年〔1970〕6月5日」の文言と同年で整合〕・玉川上水通水停止1965年の4点セット**。
- **湧水64か所と地区周辺の湧水点〔確認: 1.3.3（3）本文直接引用〕**: 「**東京都環境保全局（現環境局）の調査では野川流域で６４カ所の湧水がある**」＋「**対象地に近い湧水としては、貫井神社、蒼浪泉園、Ｔ邸、小金井市立はけの森美術館、野川第二調節池側溝（涸渇するときがある）、野川第一調節池北側の湧水、ICU 敷地内、湧き水広場、出山下湧水がある。湧水量は、貫井神社、わき水広場、出山下湧水が比較的多い**」＝**野川流域64か所の湧水（都環境保全局調査）と対象地区周辺9湧水点のリスト**＝[GOV-502](../gov/GOV-502.md)（貫井神社・滄浪泉園の湧水点群）の流域スケールの背景数値。
- **調節池の概要〔確認: 1.3.1〕**: 野川第一調節池＝貯留量21,000㎥・貯留水深1.8m・**完成年度昭和58年度**、野川第二調節池＝貯留量28,000㎥・貯留水深1.9m・**完成年度平成元年度**＝**両調節池の定量諸元の都公式値**（野川第二調節池の建設に伴う発掘＝野川中洲北遺跡〔[BOOK-255](../books/BOOK-255.md)〕・第一調節池整備と武蔵野公園低湿地遺跡〔[BOOK-254](../books/BOOK-254.md)〕の年代交差に使用可）。第二調節池湧水は第一調節池湧水より電気伝導度が高くDO・pHが低い＝「**両者の湧水が異なる水系であることが示唆された**」（平成14年度水質調査）。
- **流量と瀬切れ〔確認: 1.3.3〕**: 野川の流量は瀬切れにより測定不能箇所あり・「**大城掘橋下流30mから箭真舳橋下流100mまで水涸れ(2005/6/7)**」の実測記録（2005年）・旧流量の推定＝「**「玉川上水からの再分水量」と「野川公園付近までの湧水量」と推定される。しかし、砂川用水からの分水**」…＝1.3.3（2）に流量変遷図（土屋十圀・渡部一二データ由来か）の収録。
