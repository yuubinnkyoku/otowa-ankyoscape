# [GOV-359] 御府内沿革圖書 第三篇下（小石川小日向之部） — 神田上水白堀端通の切縮め

- **書誌〔確認〕**: 『御府内沿革圖書』第三篇下（**小石川小日向之部**・東京市史稿住所篇・東京市政府、1940）。NDL次世代デジタルライブラリー [book/3436311](https://lab.ndl.go.jp/dl/book/3436311)。OCRは中程度に崩壊しており引用文言は候補。『御府内沿革圖書』活字版の続篇（第一篇下=[GOV-351](GOV-351.md)追記の3436304、第二篇上=3436306、第二篇下=3436308に続く第三篇下）。
- **神田上水白堀端通の文言〔確認・文言候補〕**: p.123-124「**東之方竹島町石丸五左衞門屋鋪前より…西之方音羽町九丁目橋通限南之方江戶川限北之方神田上水白堀端通迄…延寳以前〓上水端道內に出張有之候處、元祿十丑年十月大塚町法華寺より出火之節、此邊類燒後、右…北之方切縮メ道內ニ成**」〔**①音羽町（江戸川と神田上水の間）の地所の北限が「神田上水白堀端通」であること、②延宝以前は上水端の道内に出張（建物の張出し）があったこと、③元禄10年（1697）10月の大塚町法華寺出火の類焼後に北側が切縮められ道内になったこと**＝**神田上水（白堀＝開渠区間）の端道の土地利用（出張→類焼後の切縮め）の17世紀末の実態**。[GAZ-012](../gazetteers/GAZ-012.md)（御府内沿革図書帳・貮拾利分冊の白堀端文言）の活字版側の記録として、白堀（開渠）区間の上水端の町屋の張出しと火災後の規制の datapoint がrepo初出]。
- **「御府內往還沿革圖書其外拾貳」目録〔確認〕**: 同書収録の「御府內往還沿革圖書其外拾貳」の目録に**白堀端通・茗荷谷・大塚・富坂・蓮華寺坂通の地所境界群**が並ぶ＝神田上水沿いの小石川側の往還・境界の一括記録（茗荷谷・大塚・富坂は神田上水（白堀）沿いの現在の地名に連なる）。
