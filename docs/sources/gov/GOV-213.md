# [GOV-213] 天保撰要類集（天保6年）— 掃部橋の天保6年7月1日出水流失と町内入用での再建の一次記録

- **書誌〔確認〕**: 『天保撰要類集 全中 第九十』（町奉行所の橋之部関係の記録集・天保5〜6年頃）。NDL次世代デジタルライブラリー [book/2589083](https://lab.ndl.go.jp/dl/book/2589083)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **天保6年7月1日の出水による掃部橋・堰板の流失〔確認・掃部橋流失史の4時点目（repo初出の一次記録）〕**: 小日向水道町・同所西古川町の両町月行事（半三郎・万次郎）の連名願（天保六未年閏七月廿四日付）——「**私とも町内二江戸川を渡候橋長六間左右江四尺宛橋台江懸に都合長七間弐尺幅壱間手摺高サ弐尺五寸之丸太長六間橋敷板左右江壱尺宛…桁三通貫弐通水道町之橋下堰板高壱丈四尺幅弐間半西古川町之方同壱丈弐尺幅三間有之前々ゟ町内入用ヲ以懸来候処当七月朔日出水之節右橋堰板共流失仕候間此度町内入用ヲ以先規有来通新規ニ掛替申度**」〔**①掃部橋が天保6年（1835）7月1日の出水で橋体と堰板の双方を流失したこと、②「前々より町内入用をもって懸け来り」（町方持）であったこと、③流失後も町内入用で「先規有来通り」新規に掛け替えるとする再建方針**＝掃部橋流失史（享保13〔[BOOK-126](../books/BOOK-126.md)の江戸洪水記〕・天明6〔[BOOK-126](../books/BOOK-126.md)小石川区史引用〕・文政12〔[BOOK-126](../books/BOOK-126.md)〕）に続く**4時点目の流失記録で、願書・見分・訴えの三段階が揃った一次記録（repo初出）**〕。
- **構造寸法の具体値〔確認・掃部橋の構造の初の数値記録〕**: ①橋体＝長6間＋橋台込み都合長7間2尺・幅1間・手摺高2尺5寸・橋杭2ヶ所4本・桁3通貫2通、②水道町側堰板＝高1丈4尺・幅2間半、③西古川町側堰板＝高1丈2尺・幅3間〔**掃部橋の橋体・堰板の寸法が初めて数値で確定できる記録。両岸に高さの異なる堰板（水道町側が2尺高い）があったことは、神田上水（江戸川）の水位対策として堰板の機能が両町側で非対称であったことを示す方向の観察（解釈は断定しない・文言は要原文照合）**〕。
- **見分・手続きの記録〔確認〕**: ①閏7月24日の見分（見分人＝**服部嘉太夫・人見脩助**）で「絵図之通相違無御座」、②閏7月26日大久保加賀守（老中）役所経由で往来人留が仰付けられ、③8月晦日の完成見分（見分人＝**中村元右衛門・永谷兵吉**）で「無相違危儀も無之丈夫二出来」、④9月朔日に往来再開〔**願→見分→往来留→普請→完成見分→訴え→往来再開という町奉行所の橋普請手続きの全過程が掃部橋一橋で追える記録（橋政史の実務例としてrepo初出）**〕。
- **掃部橋の相対位置の確定〔確認〕**: 「**尤東之方古川橋江三拾間程西之方江戸川橋江壱町程隔有之候間**」〔**掃部橋から東の古川橋（麁朶橋）まで約30間・西の江戸川橋（名残橋）まで約1町（約60間）という距離の一次記録（repo初出）。小石川の神田上水筋の橋の並び（江戸川橋−掃部橋−古川橋）の間隔を数値で固定でき、1912年地籍図・現行の街区と突き合わせる際の基準になる**〕〔30間・1町はOCR上明瞭だが、橋の対応（古川橋=麁朶橋、江戸川橋=名残橋）は[GAZ-039](../gazetteers/GAZ-039.md)・[GAZ-040](../gazetteers/GAZ-040.md)の橋名文言と整合・要照合〕。
