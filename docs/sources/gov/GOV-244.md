# [GOV-244] 神田上水留の残冊（天保5〜嘉永5年）— 白堀の水面実測・組合・浚・大洗堰の文言群

- **書誌〔確認〕**: 『神田上水留』のうち、[2] [book/2587457](https://lab.ndl.go.jp/dl/book/2587457)（天保5年7月・小川町御住居掛新規樋枡御普請 分冊ノ一）・[4] [book/2587459](https://lab.ndl.go.jp/dl/book/2587459)（天保9年正月・水道橋外石川伊豫守屋敷前石垣樋 分冊ノ一）・[10] [book/2587465](https://lab.ndl.go.jp/dl/book/2587465)（天保15年10月〜弘化2年7月・小川町錦小路石垣樋場所替 分冊ノ三）・[17] [book/2587472](https://lab.ndl.go.jp/dl/book/2587472)・[18] [book/2587473](https://lab.ndl.go.jp/dl/book/2587473)（嘉永2〜3年・水道橋脇掛樋 分冊ノ二・三）・[24] [book/2587479](https://lab.ndl.go.jp/dl/book/2587479)（嘉永5年・神田橋御門外通石垣樋 分冊ノ四）のOCR全文横断検索（キーワード: 白堀・目白下・大洗堰・白堀端通等）で抽出した文言群（[13]-[15][33]-[37]の白堀通普請件〔[GOV-232](GOV-232.md)・[GOV-233](GOV-233.md)〕の残冊側の背景記録）。**引用文言はすべてOCR由来で要原文照合。**
- **天保5年（1834）の牛天神下白堀水面の実測〔確認・repo初出の定量的記録〕**: [2]の水面測量の記録——「**神田上水牛天神下白堀水面ゟ松平讃岐守囲込地外組合留枡内水面壱丈壱尺六寸八分低し 右留枡水面ゟ御好水面七尺五寸六分高し 右御好水面ゟ白堀水面四尺壱寸弐分高し**」＋「猿楽町前田対馬守屋敷前**万年石樋**小西ゟ御住居御庭内御好心面迄水下り八寸三分 但三百四拾弐間四尺」「同所水面ゟ御住居御庭内御好分面迄水下り三寸 但三百六拾間」＝**牛天神下の白堀の水面が、松平讃岐守囲込地外の組合留枡内水面・「御好水面」との比高（1丈1尺6寸8分低・7尺5寸6分高・4尺1寸2分高の列）で実測されていた記録**（天保5年・小川町御住居〔江戸城内〕への新規樋枡普請に伴う測量）。**白堀に流水があり、その水面が管理されていた天保期の定量的傍証**（[GOV-233](GOV-233.md)文久2年の潰水・浅水の指摘の約30年前）。猿楽町前田対馬守屋敷前の「万年石樋」の用例（[GAZ-035](../gazetteers/GAZ-035.md)桜木町の万年樋・[GOV-231](GOV-231.md)万年樋の語の用例に加わる神田上水側の石樋の呼称・位置の照合課題）。
- **「白堀端通」「白堀橋通」の組合年番〔確認・repo初出の呼称〕**: ①[10]（天保15〜弘化2年）の水留の廻状の宛先リスト: 「新規組合年番竹本誉太郎殿 **水道端通組合年番**松平作左衛門殿組同心中 **白堀端通組合年番**勝田将監殿組同心中」②[18]（嘉永2〜3年）: 「**白堀橋通組合年番**鷲巣淡路守殿御組 �井与左衛門殿組同心中方中」＝**白堀沿いの武家方の組織が「白堀端通」「水道端通」と並ぶ「通」単位の組合（年番制）として水留・修復の廻状の宛先になっていた記録**。嘉永期の「**白堀橋通**」の表記は**「白堀橋」という橋の存在を示唆する**（[GAZ-050](../gazetteers/GAZ-050.md)の「白堀端」との表記差・OCR変種の可能性も含め原字形照合課題）。
- **「白堀浚に付水留」〔確認・repo初出〕**: [10]の錦小路修復中の水留の日程表: 「正月廿五日／二月十五日／三月廿五日／**四月十三日・十四日 是は白堀浚に付水留之節** 当御場所之方水留仕事いたし候事／四月廿九日／六月廿七日…右は御修復中水留仕事七度に有之候処 **白堀後之節水留兼用に付全く六度** 御達書廻状共差出候事」＝**天保15年〜弘化2年（1834-45）の神田上水の修復運用の中で、四月十三日・十四日に「白堀浚」（白堀の浚渫）のための水留（通水停止）が別途に行われた記録**＝白堀の定期的な浚渫（[GOV-237](GOV-237.md)明治2年4月の藻刈并埋浚3日間・同じ春季）の天保〜弘化期の先行例。
- **文政12年（1829）の関口村大洗堰の石垣急破御普請〔確認・repo初出〕**: [10]の御組合普請の実績リスト: 「**文政十二丑年 神田上水関口村大洗堰神石垣其外急破御普請 御組合入用伺済高金千百拾壱両弐分**…丑シ月廿日ゟ取掛り 寅四月十五日迄ニ出来 日数合弐百六拾二日」＋「文政十三寅年五月 神田上水関口村大洗堰**油不垣(石垣?)其外急破御普請中附切相勤候**支配向え左之通**御褒美被下置候 銀拾枚 人主七両**…」＝**大洗堰（関口村）の石垣が文政12年に急破し、御組合入用1111両2分・262日かけて修復され、奉行・同心らに御褒美が出た記録**＝大洗堰の修復史の定量的一次記録（[BOOK-121](../books/BOOK-121.md)正徳3年高札・[GAZ-048](../gazetteers/GAZ-048.md)大洗堰の構造数値・[BOOK-129](../books/BOOK-129.md)寛延2年浚に加わる19世紀の実績）。同リストに「天保六未年 神田上水小川町裏猿楽町通石垣樋御普請 御組合入用…金千弐拾弐両…日数三百九十六日」・「錦小路石垣場所替并表猿楽町通石垣樋共御修復…金千弐百弐両壱分弐朱…日数合弐百四十九日（辰十月廿四日ゟ巳七月六日）」も列挙。
- **「目白下大洗堰ゟ江戸川え水落」の廻状文言〔確認・繰返し用例〕**: [4][10][18][24]の水留の廻状（修復の通知）に「**目白下大洗堰ゟ江戸川え水落申候 右は御持場之儀二付申達候**」の定型文言（[4]の宛先「四口(?)五郎左衛門えは…」・[24]は「**目田下**大洗堰」とOCR化）＝**神田上水の水留（通水停止）の際に、大洗堰から江戸川（神田川）へ水を落とす（放流する）操作と、その「御持場」の担当者への通知が手順として繰り返されていた記録**＝**大洗堰の放水機能が上水の修復運用に組み込まれていた**ことの複数冊での用例（[BOOK-121](../books/BOOK-121.md)・[GAZ-048](../gazetteers/GAZ-048.md)の大洗堰の静的な記述に運用面の一次記録を加える）。[18]には「**関口洗櫣(洗堰?)水番人小兵衛**え右同文言」もあり、関口の水番人（小兵衛）の氏名の用例（[GOV-233](GOV-233.md)追記の文久2年の水番人小兵衛と同一人物候補・要照合）。
- **白堀通普請所の労災手当の例書〔確認・周辺〕**: [17]（嘉永2〜3年）の例書: 「**弘化三午年八月神田上水白堀通浅水留御普請所ニ而怪我いたし候節** 書面之通御手当被下置候」（小石川下富坂町の喜八への手当）＋「**白堀通洩水留御普請所ニ而怪我**…」＝**弘化3年8月の白堀通普請（[GOV-232](GOV-232.md)）の現場（「浅水留」「洩水留」の御普請所）での人足の怪我への手当の例**（白堀通普請の労務実態の傍証・「浅水留」の語は[GOV-233](GOV-233.md)の浅水の指摘と対照できる用例）。

## 制限・未解決

- ①すべてOCR由来で、「御好水面」「御好心面」「白堀後之節」等の語の原字形・水面比高の数値の向き（高／低の行対応）は原文照合を要する。②「白堀端通」「白堀橋通」の表記差が実在の通名の変化かOCR変種かは判断できない（「白堀橋」の実在は原字形照合まで保留）。③文政12年大洗堰急破の「油不垣」は「石垣」の誤読の可能性が高いが要照合。④白堀浚の年次（天保15年側か弘化2年側か）と実施主体（普請方か町方か）は本冊のみでは確定できない。⑤[2]の万年石樋（猿楽町前田対馬守屋敷前）の位置（御茶ノ水の万年樋か小石川区間の別の石樋か）は[GAZ-049](../gazetteers/GAZ-049.md)・[GAZ-035](../gazetteers/GAZ-035.md)の万年樋系の文言との対校課題。
