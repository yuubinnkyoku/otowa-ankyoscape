# [GOV-267] 神田玉川上水留 明治2年下半期 — 白堀通の余垂板・箱下水修復の注文→入用→出来形の3段階記録

- **書誌〔確認〕**: 『神田玉川上水留』明治二己年七月より十二月迄の関係冊——分冊ノ二 [book/2587535](https://lab.ndl.go.jp/dl/book/2587535)（**仕様注文帳**）・分冊ノ四 [book/2587537](https://lab.ndl.go.jp/dl/book/2587537)（**御入用帳**）・分冊ノ四（明治二己年六月より十二月マデ）[book/2587543](https://lab.ndl.go.jp/dl/book/2587543)（**出来形仕上帳**・松原土木大令史宛）。[GOV-248](GOV-248.md)（明治2年上半期の達書・仕様注文帳群）に続く明治2年下半期の白堀通（神田上水の小日向〜小石川区間）の修復記録。**同一の修復案件が仕様注文→御入用→出来形仕上の3段階の帳簿で揃った**初例。**引用文言はすべてOCR由来で要原文照合。**
- **白堀通余垂板損所取繕仕様注文帳〔確認・repo初出の構造文言〕**: 2587535冊頭「**七八月 黒沢土木大令史 神田上水白堀通余垂板損所其外取繕仕様注文帳**」——「**小石川金富町町屋前 一余垂板長四間高五尺 右仕様在来余乗板板損浅水強難差置候二付古杭板共惣躰堀取根伐いたし**」＝
  - **白堀（神田上水）の小石川金富町区間の町屋前に「余垂板」があった**ことを示す文言（**金富町の帰属・「小石川」の冠はOCR要照合**）。規格は長4間・高5尺＝[GOV-232](GOV-232.md)弘化の白堀通余垂板（高平均5尺・801間）と同じ高さの規格が明治2年時点でも使われていたことの datapoint。
  - **修復仕様**: 「**杭木栗丸太長九尺間二送り四斗 板松厚壱寸五分 小欠折釘八寸…鎮波巻打割地鎮波打堅**」「**是は一間二送り四斗打四間分**」「**余乗板間に弐枚半遣ひ杭木壱本ニ付〆永百拾弐文五分**」＝**杭1本あたり2枚半の「余乗板」を遣う**という板の使用枚数の定量文言（**同一帳簿内で「余垂板」と「余乗板」が混在**＝両表記のOCR異読の実例・原字形照合の最重要例）。
- **小日向白堀通渡箱下水仕直の3段階〔確認・repo初出の箱下水の仕様群〕**: 「**知事 判事 神田上水小日向白堀通渡箱下水仕直御普請仕様注文帳 森左太夫 清水元一郎 鈴木進生(近?) 御用掛**」（2587535）——
  - **金杉橋脇**: 「**一箱下水長六間大サ内法巾弐尺七寸木厚三寸深弐尺壱ケ所**」（2587535・仕様注文）→御入用帳（2587537）では「**金杉橋脇一御箱下水長六間大方内法巾成沢(?)七寸木石等**」・出来形（2587543）で「**神田上水小日向白堀通渡口相成下水仕直御普請出来形内訳 一箱下水長六間**」＝**金杉橋脇の箱下水（伏越樋）・長6間・内法巾2尺7寸**の3段階記録。
  - **下水請桝**: 「**同所一下水請升(桝)大方内法三尺四寸…壱ヶ所**」（2587537）＝白堀の渡りに付属する桝の内法3尺4寸（2587535の「下水柵」等と併せ、白堀の末端構造の構成要素）。
  - **服部坂下**: 「**服部坂下一(以?)箱下水長五間壱尺大方内法巾弐尺(原?)石(厚?)弐寸三分弐ヶ所**」（2587537）＝**服部坂下に箱下水が2ヶ所**＝[GAZ-049](../gazetteers/GAZ-049.md)⑬の「服部坂え渡る橋」（御府内備考貳）の坂下の水路構造の明治2年の実測級記録。
  - **金杉橋上之方**: 「**金杉橋上之方一箱下水長五間但濁(朽?)木御修復**」（2587537）＝金杉橋上流側の箱下水の修復。
  - **新坂手前の下水の埋まり**: 「**新坂手前下水幷金杉橋脇下水請払弐ヶ所埋り居候ニ付入念渡揚候積り**」（2587535）＝**新坂（新坂下高札・新坂下橋で知られる白堀沿いの坂）手前の下水と金杉橋脇の下水の2ヶ所が埋まっていた**という白堀の流末の閉塞状態の文言＝[GOV-237](GOV-237.md)明治2年の「白堀埋増による流末差支」と対校できる維新期の白堀の実態記録。
- **埋石下水・下水石垣の仕様〔確認・周辺〕**: 「**一埋石下水長壱間三尺大サ壱人四方右は宿(?)押埋り候ニ付惣躰堀揚根伐いたし…元形之通り栄(築?)立候積**」「**一下水石垣長壱間右同断高平均弐尺五寸 右仕様孕出し荒石渋下り水行差支候ニ付不損様取除元形之通築直候積**」（2587535）＝白堀沿いの下水の石構造（埋石下水・下水石垣高2尺5寸）の修復仕様＝[GOV-248](GOV-248.md)の「白堀通柵石垣」・[GOV-264](GOV-264.md)の「荒ケ谷土手石垣」と並ぶ白堀の石積構造の記録群。
- **「余垂板/余乗板」のOCR変種の統計〔確認・第120回の91冊横断集計〕**: 『神田上水留』61冊（[2587456〜2587516](https://lab.ndl.go.jp/dl/book/2587456)）＋『神田玉川上水留』30冊（2587517〜2587546）の全文での出現数は**余垂板428回（神田上水留394・玉川上水留34）・余乗板378回（318・60）・余置板94回（92・2）・参垂板20回・参乗板8回**（架垂板0回）＝**「余垂板」「余乗板」の2読みがほぼ拮抗して全期間を通じて出現し、同一帳簿内・同一箇所の文言でも混在する**＝どちらかが原字形と確定できる段階ではなく、原画像照合まで変種として併記する（本ファイルの表記「余垂板」は[GOV-232](GOV-232.md)初出時の読みに従った慣例）。

## 制限・未解決
