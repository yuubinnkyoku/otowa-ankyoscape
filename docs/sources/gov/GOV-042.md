# [GOV-042] 1909年一万分一地形図に関する2011年館報の読図と丸池の非表示

- **資料〔確認〕**：豊島区立郷土資料館『かたりべ』第102号、**2011年6月30日発行**、[豊島区公式PDF](https://www.city.toshima.lg.jp/documents/2546/kataribe102.pdf)、全4頁。**印刷p.2「一万分一地形図から、豊島区のまちの移り変わりを見てみよう！」**をページ画像で直接判読（2026年11月2日）。
- **地図系列〔確認：2011年の資料館の説明〕**：記事は豊島区立郷土資料館の『豊島区地域地図』第4集「東京近傍一万分一地形図（改訂版）」について、**1999年に刊行した第4集を2011年3月に改訂**したと説明する。原図の測図・修正年と**2011年の復刻・編集刊年は区別**する。
- **弦巻川源頭と村境〔観察：2011年の資料館による1909年図の読図〕**：記事は**1909年図の池袋駅西側**を例に、旧**長崎村（北）・高田村（南）の村境**を一点鎖線で示すと説明し、境界付近から南へ伸びる**谷と水田を弦巻川の源流域**と読んでいる。記事中に小さな地図抜粋があるが、**原測量図の凡例・図郭・境界線を別途照合する必要**がある。
- **丸池の非表示〔確認：2011年の解説文／未確認：1909年原図の独立判読〕**：同記事は、**当該図には湧水池が見えない**一方、谷の先端にかつて**丸池**があったと記す。**地図上で池が見えないことは、1909年に池や湧水が存在しなかった証拠ではない**。縮尺・記号・編集・地図の測量時点と、池の存在・水量の変化を分けて検証する。丸池の存続沿革は別途既登録の1998年豊島区広報等と照合する。
- **利用範囲〔推定／未解決〕**：旧村境、谷底・水田、丸池の候補位置を**1909年原図・1912年地籍図・近年の標高図**で重ね合わせる際の手掛かりとなる。この記事だけで源頭の正確な座標、池の形状、河道の流向や下流接続は確定できない。
