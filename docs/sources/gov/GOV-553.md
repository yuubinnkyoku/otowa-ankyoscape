# [GOV-553] 建通新聞・石神井川上流地下調節池の連絡管TN報道〔東伏見公園立坑・設計数値と工程の確定・GOV-549制限③の部分解消〕

- **書誌〔確認: r.jina.ai経由・本文全文・2026-11-23取得〕**: 建通新聞電子版「**石神井川地下調節池の連絡管ＴＮ 26年度から準備工**」（東京・**2026/02/09 15:22配信・【2026/02/10 東京版に掲載】**） https://digital.kentsu.co.jp/articles/artcl_rglr/01KH0D7KR3Q6GGEWAGRAECH5CX 〔建通新聞社の電子版（地方建設専門紙）。kensetsunews.com（建設通信新聞）とは別社〕。
- **連絡管トンネルの設計数値〔確認・repo初出の数値群〕**: 「東京都は石神井川上流地下調節池の連絡管トンネルを整備するため、**２０２６年度に準備工を始める**。**西東京市立東伏見公園に立坑を設け、シールド工法で内径５・８㍍、延長約０・２㌔の連絡管トンネルを構築して本管トンネルの途中につなげる**。**27年度までに準備工を終わらせ、28年度以降に立坑工やトンネル工を実施**。その後、石神井川付近に取水施設や管理施設を建設して工事を完了させる方針」「**連絡管トンネルは、26～27年度で西東京市立東伏見公園の樹木移設などを終えた上で、28年度以降に同公園内へニューマチックケーソン工法で立坑を設置。そこから本管トンネルの途中に向けシールドマシンを掘り進めて整備する。内径５・８㍍（外径約６・３㍍）、延長約０・２㌔の規模で、大部分が石神井川の地下約30㍍を通過する**」「**設計は建設技術研究所（中央区）が担当**」〔**内径5.8m・外径約6.3m・延長約0.2km・大部分が石神井川の地下約30m通過・設計者（建設技術研究所）・ニューマチックケーソン工法の連絡管側への適用**はいずれもrepo初出。[GOV-549](GOV-549.md)の制限③「東伏見公園中間立坑の直径・深度等の設計数値は本資料にない（連絡管の別途工事の設計文言待ち）」を業務文言レベルで部分解消する。立坑の直径・深度そのものは記事にはない〕。
- **本管トンネルの落札額〔確認・repo初出の数値〕**: 「**本管トンネルの工事は25年10月に大成・鹿島ＪＶが８８７億７５００万円で落札**。武蔵野中央公園内に発進立坑を、南町調節池内に到達立坑をそれぞれ設け、青梅街道や伏見通りなどの地下約30㍍に泥水式シールド工法で内径14・３㍍（外径約15・２㍍）、延長約１・９㌔の本管トンネルを構築する」〔**落札額887億7,500万円はrepo初出**（[GOV-549](GOV-549.md)は受注者＝大成・鹿島建設共同企業体「石神井川シールド作業所」まで）。発注時期「25年10月」＝[GOV-549](GOV-549.md)説明会（R8.3）の前年秋で時系列整合〕。
- **事業枠の文言〔確認〕**: 「石神井川上流地下調節池は、**西東京市南町１丁目の南町調節池から武蔵野市八幡町２丁目の武蔵野中央公園までの間**に整備する**貯留量約30万立方㍍のトンネル式調節池。22年３月に都市計画決定し、同年10月に事業認可を取得した。事業期間は35年度までで、総事業費を１３１０億円**と見積もっている」〔都市計画決定・事業認可の年次は[GOV-540](GOV-540.md)（技監答弁:令和4年3月都市計画決定・同年10月都市計画事業認可）と一致＝既知の一次裏付け。総事業費1,310億円は[BLOG-296](../blogs/BLOG-296.md)（五十嵐えりnote:1,073億→1,310億円・B/C 1.31→1.11）の業界紙側からの一致確認。「事業期間は35年度まで」はrepo初出候補（[GOV-540](GOV-540.md)・[GOV-548](GOV-548.md)に事業終期の文言は未確認）〕。
- **意義〔観察〕**: ①**GOV-549の「中間立坑（東伏見公園）・連絡管（別途工事 今後発注予定）」という構造について、連絡管側の規模・工法・工程・設計者が初めて数値レベルで確定**した＝本管（内径14.3m・1.9km・泥水式シールド）と連絡管（内径5.8m・0.2km・大部分が石神井川直下通過）の二段構造が明確になった。②「大部分が**石神井川の地下約30mを通過**する」＝連絡管が**石神井川河道の直下**に引き込まれる線形観察で、[BLOG-301](../blogs/BLOG-301.md)（mark60 Scene-353:蓮華橋上流左岸の護岸欠け＝増水時の南町調節池への流入口・西東京市調整池設置年次1980/1983）の流入口観察と、今後の取水施設位置の公表時に突合できる。③**取水施設や管理施設は連絡管トンネル整備の後に「石神井川付近に」建設される**工程文言＝[GOV-549](GOV-549.md)チラシ図の「取水位置」図上配置文言が実装工程として裏付けられた。④時系列（26年度準備工開始）は[GOV-548](GOV-548.md)（武蔵野市ポータル更新2026-11-09）・[GOV-549](GOV-549.md)（説明会2026年6月ページ）と同じ令和8年度の進行中観察と整合。
- **制限・未解決**: ①連絡管立坑（東伏見公園内）の直径・深度・位置の設計数値は本記事にない〔ニューマチックケーソン工法の採用まで。都側図面の公開待ち〕。②東伏見公園の樹木移設・準備工の発注形態（都発注か西東京市経由か）は本記事では特定不能。③887億7,500万円は記事文言によるもので、開札結果の都官方公告（都公報・電子調達）との照合は未実施〔開札系は[GOV-148](GOV-148.md)（環七調節池広域整備検討その2・開札2026-12-02）とは別の工事種〕。④配信日が2026-02-09である一方、26年度準備工の着手状況（着工済みか）は本記事では確定しない〔[GOV-548](GOV-548.md)/[GOV-549](GOV-549.md)（2026年11月時点）に東伏見公園側の着工文言は未確認〕。
