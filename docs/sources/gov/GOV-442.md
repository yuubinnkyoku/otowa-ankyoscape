# [GOV-442] 豊多摩郡落合町現状調査 — 妙法寺川の異表記候補と1931年の町政帳簿

- **書誌〔確認〕**: 『豊多摩郡落合町現状調査』（東京市臨時市域**擴張部**編・NDL次世代デジタルライブラリー [book/1900474](https://lab.ndl.go.jp/dl/book/1900474)・巻子本からOCR丁起こしの縦割テキストで崩壊大）。**引用文言はすべてOCR由来で要原文照合**。東京市臨時市域擴張部の現状調査シリーズは[GOV-331](GOV-331.md)（豊多摩郡大泉村現状調査・1931）と同一シリーズで、**落合町（1932年東京市編入→淀橋区落合町→中野区・新宿区）冊**。東京市への合佢前の豊多摩郡43町村の現状調査の1冊と推定（シリーズ全域の棚卸しは未了）。
- **妙正寺川×妙法寺川の同文内併存〔確認・異表記候補・本ファイルの核心〕**: 地勢章に——「**本町ノ地勢ハ本町ヲ東西ニ貫流スル妙正寺川ヲ以テ南北ニ二分サル、妙法寺川ノ流域ハ豊多摩郡中ニテモ地形最モ低キ地域ニシテ〓シテ卑濕平坦ナル低地ヲナス 妙正寺川ノ西南 大字上落合ノ地ハ中野町野方町ニ起レル岡脈連亘シテ一帯ノ髙名(地のOCR崩れ候補)ヲナシ 東北部下落合ノ地ハ目白台ニ連ル一帶ノ髙阜ニシテ小丘陵ノ起伏スルモノ多ク…最小適ノ住宅地タリ**」〔**同一の調査文体の中で「妙正寺川」と「妙法寺川」が併存する**（「妙正寺川」は本冊に他にも数回・文脈は同一川）＝**1931年時点の東京市の行政調査文書レベルで妙正寺川の異表記（または誤記）「妙法寺川」が流通していた一次文例**。誤記か意図的な記載かは本冊レベルでは確定できないが、**現在の「妙正寺川」の「妙法寺」由来説（下落合の妙法寺）を検討する際の1931年の行政文書側の文言候補**。（〔観察〕中野区側の妙正寺川流域の「妙法寺」は石神井川系の中村橋付近の寺で、落合の妙法寺（雑司ヶ谷・千川系を含む広域の寺）とは別寺。表記の由来の考察は断定しない）〕。
- **上落合・下落合の地勢文言〔確認〕**: 「**妙正寺川ノ西南 大字上落合ノ地ハ中野町野方町ニ起レル岡脈連亘シテ一帯ノ髙地ヲナシ 東北部下落合ノ地ハ目白台ニ連ル一帶ノ髙阜**」＝**上落合（西南岸）は中野町・野方町に起る岡脈の延長で高台、下落合（東北岸）は目白台に連なる高阜**＝妙正寺川の両岸の丘陵構造（中野台地側と目白台側）を東西二分して記載した1931年の行政側の地形記述〔[BOOK-189](../books/BOOK-189.md)（1922・落合村の地形）・[GOV-370](GOV-370.md)（1920・復興局建築線の高田〜下落合）と同じ区域の後時点の観察で、**妙正寺川の谷の両岸の地形構造を「中野・野方起りの岡脈×目白台系の高阜」と一对の丘陵名で記した文体**はrepo内で初出候補〕。
- **「下水道施設ナシ」〔確認・1931時点の陰性記録〕**: 「**下水道施設ナシ**（「町ノ東南二九下水道施設ナシ」のOCR崩れ文・前後は鉄道・軌道の章で「省線山手線電車ハ町ノ東部高田町トノ境界ニ並行シテ南北ニ走リ…」等の交通文言が続き、条の帰属は要原文照合）」＝**本現状調査の体例上、下水道の有無を立項して記載する箇所で「施設ナシ」と明記**〔観音開札前の落合町域（上落合・下落合・葛ヶ谷）に**1931年時点で下水道施設が無かったことの行政側の明記**＝[GOV-163](GOV-163.md)（1913・下水道設計告示28号）から[GOV-166](GOV-166.md)（東京市下水道事業年報）への千川・弦巻系幹線の計画～実施の中間座標として位置づけ可能（因果は断定しない）〕。
- **水道栓数と「〓玉水道町村組合」加入〔文言候補〕**: 「**町内ニ於ケル水道栓数…専用栓四四三三 計量栓… 私設共同栓四六(?) 公設共同栓…（昭和五年十二月末現在・数字はOCR崩れ大）**」「**本町ハ〓玉水道町村組合ニ加入シ給水區域…**」＝落合町の給水の組合加入の文言（**「〓玉」の判読は要原文照合**・豊多摩郡内の水道組合名〔荒玉／豊玉候補〕）。別ree所に「**豊多摩病院組合組合會議員 荒玉水道町村組合組合會議員**」の併記もある（いずれもOCR崩れで組合名の確定は要照合）＝**落合町の上水道史（組合給水→東京市営移行）の1931年の現状座標**。
- **その他の帳簿文言〔確認〕**: ①面積「**九七四、九五七坪 東京市ノ最大區タル芝區ノ約三割 最小區タル四谷區ノ約一·六倍**」＝落合町の面積と東京市15区との比較、②「**大正十三年四月…日 町制ヲ施行**」（落合村→落合町の町制施行・大正13年〔1924〕・日の判読は要照合）・沿革章の明治22年町村制・三村聯合戸長役場・「落合村ト改称」文言、③昭和5年9月発令の東京府方面委員設置規定に基く方面委員18名のリスト、④統計表群（歳入歳出・町有財産・町債・伝染病・出生死亡等の数字群・OCR縦割崩壊で数値の読みは要照合）＝**1932年市域拡張直前の落合町の全町政の帳簿記録**。
