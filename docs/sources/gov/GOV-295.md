# [GOV-295] 上下水道統計報告 昭和十四年度（1939）— 谷端川への下水放流の統計記録

- **書誌〔確認〕**: 厚生省調査『上下水道統計報告』**昭和十四年度**（社団法人 水道協会編・1939年刊）。例言に「本書は厚生省の報告例による昭和十四年度に於ける各府縣の上下水道統計報告を蒐輯編纂したものである」。NDL次世代デジタルライブラリー [book/1070216](https://lab.ndl.go.jp/dl/book/1070216)（同報告の同年度版冊 [book/1056670](https://lab.ndl.go.jp/dl/book/1056670) にも同一文言を確認）。**すべての引用は同館OCRテキスト由来であり、統計表のOCR列崩れが著しい。文言・行対応は原表照合を要する。**
- **旧滝野川町の排水〔確認・repo初出〕**: 「昭和十四年度末現在 第三下水道(其二)」の統計表中、旧東京市郊外の旧町村下水の排水方法欄に「**自然流下ニヨリ谷端川（及）谷田川並日暮里町下水道ニ放流ス、尚一部ハ石神井川ニ放流ス**」＝**旧滝野川町域の下水が自然流下で谷端川・谷田川・日暮里町下水道に放流され、一部は石神井川に放流されていた**1939年（昭和14年度末）時点の統計記録〔2冊のOCRで文列の崩れ方が異なり、「谷端川道」等の読みもあり得るため、文言の確定は原表照合まで保留。行（旧町村名）対応も保留〕。
- **旧西巣鴨町系の排水〔確認・repo初出候補〕**: 同表に「**自然流下ニヨリ谷端川及（一部ハ）惡水路ニ排出ス、（一部）ハ舊市内巢鴨町高田町ニ合流ス**」＝**旧西巣鴨町域（谷端川流域）の下水が谷端川と悪水路に排出され、一部は旧市内（巣鴨町・高田町）の下水に合流**していた記録〔OCR列崩れのため町名対応は保留だが、統計表中に「舊巢鴨町」「舊西巢鴨町」の行がある〕。
- **内容メモ**: 同報告は全国の都市・旧町村別の下水道（管渠延長・吐口位置・処分方法・排水方法）を統計表で一覧化する。東京市郊外（昭和7年市域拡張で編入された旧町村）の欄に、**谷端川が下水（悪水）の受け皿として1939年時点でも機能していた**ことを示す文言が残る。[BOOK-002](../books/BOOK-002.md)（1941「今日では下水として痕跡をとゞめてゐる」＝音羽谷側）・[GOV-188](GOV-188.md)（千川＝下水道負担）と並ぶ、下水道史側の昭和初期の観察記録。

## 制限・未解決

- ①OCR列崩れが著しく、放流先文言と旧町村名の行対応は原表（画像）照合まで保留・断定しない。②「谷端川道」の「道」の有無（「谷端川 道〔ニ〕」の分岐読みを含む）は原表照合課題。③旧滝野川町下水の量（排水總量等の数値）は列崩れのため採らない。④同じく旧高田町（弦巻川・水窪川流域）の放流先文言の有無の精査は未了。
