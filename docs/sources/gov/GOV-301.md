# [GOV-301] 日本都市年鑑 第3・昭和9年用（1933）— 立會川・神田上水・谷端川改修3線の事業決定変更の統計年鑑記録

- **書誌〔確認〕**: 国際文化振興会編『**日本都市年鑑 第3（昭和9年用）**』（1933年刊）。NDL次世代デジタルライブラリー [book/1464954](https://lab.ndl.go.jp/dl/book/1464954)。**引用はすべて同館OCRテキスト由来。都市計画の統計表は列崩れ・行混在が激しく、数値・年度対応は原文画像との照合を要する。**〔昭和8年用（[1465033](https://lab.ndl.go.jp/dl/book/1465033)）にも同種の表があるが、未取得（同一記録の可能性が高い）〕。
- **①都市計画河川表の文言候補〔repo初出の統計年鑑記録〕**: 東京府の都市計画河川の行に「**荒川…（中略）…澁谷川（全部事業決定）同6.8.4變更、立會川、神田上水、谷端川改修3線、埋立2線、新川、鐵砲洲川（全部事業決定）…7.3.31變更…**」という摘要欄の並びが読める＝**「立會川、神田上水、谷端川改修3線、埋立2線」が東京府（府知事執行）の都市計画河川事業として全部事業決定済みで、（昭和）7.3.31（＝1932年3月31日）に事業決定変更があった**ことの文言候補〔**OCRで年度・摘要欄の対応（事業決定の年月日と変更の年月日のどちらが7.3.31か）が崩れており、事業費列は列崩れで読めない。文言候補として記録し原画像照合を要する**〕。
- **②下水道表の巣鴨町下水道＝失業救済事業〔文言候補〕**: 東京市の下水道事業の表に「**東京都市計畫區域內巢鴨町下水道事業…處理事業／失業救濟事業（第一期）／失業救濟事業（第二期）／第三期下水道事業…昭和3乃至同17年度15箇年度…（面積）187.37（ヘクタール）…**」の行の候補＝**巣鴨町下水道事業が「失業救済事業（第一期・第二期）」の体裁で都市計画下水道事業に収載されている**記録候補〔数値は列崩れ〕。[GOV-299](GOV-299.md)（昭和4〜6年度の巣鴨町下水道の失業救済事業記録）と対応する統計年鑑側の記録。同じ表に西巢鴨町（455.00ヘクタール）・尾久町・高田町・王子町等の行も見える〔文言候補〕。
- **位置づけ〔観察・内容メモ〕**: ①[GOV-258](GOV-258.md)（1927府諮問・谷端川改修計画説明書）→[GOV-159](GOV-159.md)（1930委員会決定）→**本書（1932.3.31事業決定変更の文言候補）**→[GOV-300](GOV-300.md)（1933年時点の失業応急事業での施行）→[GOV-135](GOV-135.md)（1940完成）という谷端川改修の都市計画手続きの通時系列の中間のdatapoint。②「改修3線、埋立2線」の線数の表現は初出。③受益者負担の省令12号（1936・[GOV-296](GOV-296.md)）に先行する事業決定段階の記録。

- **trioの変更日は7.3.31ではなく6.8.4候補〔文言候補・対照材料〕**: 次巻の[GOV-473](GOV-473.md)（日本都市年鑑 第4・1934）で同じ表の第4版（昭和9年3月末現在）を**OCR行bboxの同一印刷行復元＋IIIF原画像密度照合**で読み直した結果、「立會川、神田上水、谷端川(全部事業決定)」の行は「**（昭和）5.8.8 同6.8.4變更、**」の書き出し（＝決定1930.8.8・変更1931.8.4）で、**「7.3.31變更」は「古川(全部事業決定)」行（大正14.12.8決定）に対応する**ことが確定方向で判別された。よって本書（第3表）の制限①「『7.3.31變更』がtrioの変更日か」の候補は、**第4表では否定方向**＝trioの変更日の候補は**（昭和）6.8.4（1931.8.4）**に置き換わる可能性が高い〔trio決定の5.8.8=1930.8.8は[GOV-159](GOV-159.md)・[PAP-064](../papers/PAP-064.md)の同年月日と整合〕。ただし**第3表自体の原画像照合は実施していない**ため、第3表の文言対応は本追記をもって確定とはせず、対照課題として残す（第3表の摘要欄も第4表と同じ「日付→河川名」の体裁であれば「同6.8.4變更、立會川、神田上水、谷端川」の行立ちになっているはずで、GOV-301本文の①に引用した平文OCRの並びとも矛盾しない）。
- **「改修3線、埋立2線」の内訳〔文言候補の儘〕**: 第4表ではtrioの次行に「（大正）10.5.13 改修3線、埋立2線、新川、鐵砲洲川(全部事業決定)」が独立の行として現れ、**「改修3線・埋立2線」は新川・鐵砲洲川群の行**であることが同行復元で分離される＝制限③（改修3線の内訳）について、**第3表の引用文言で「谷端川改修3線、埋立2線」と一続きに読めた箇所は、第4表では「谷端川(全部事業決定)」と「改修3線、埋立2線、新川、鐵砲洲川(全部事業決定)」の別行**である可能性が高い〔第3表の行立ちの原画像確認は引き続き残課題〕。
