  - **公開解説〔確認・repo初出の経緯文言〕**: 「この碑は、善福寺川から桃園川への田用水路開削の事跡を伝えるため明治13（1880）年に建立された記念碑である。碑には、発起人として中野村、高円寺村字小沢、高円寺村字原、馬橋村の名主を勤めた家の者の名が刻まれている。また、水盛大工の川嶋銀蔵は馬橋村の農業兼帯の大工である。用水路は（中略）代官（当時の代官は中村八大夫知剛）と調整を行いながら完成させた。**この碑が伝える用水は、天保の飢饉を契機として天保11（1840）年に計画され、善福寺川から水を引き、田端村・成宗村を通り、現在記念碑が立つ成宗弁財天にあった弁天池に一旦落とされ、青梅街道を暗渠（トンネル）で横断し、現区役所の東側を抜け、馬橋児童遊園沿いに通り、桃園川へ抜けていた。**計画では成宗村権現山堰（現在の矢倉橋脇）からの引水であったが、普請中に代官の指示により突如計画が変更された。結果、田端村広場堰（現在の西田端橋の上手）から引水して、田端神社の南を廻る用水路となった。この用水は途中を暗渠とすることで、高低差や他領の問題を解決しており（中略）**用水路は年内に完成したが、翌年には繰抜部分に獺の巣穴ができて、大雨で土手が崩れてしまい、利用できなくなっていた。そこで、再び計画をたて、田端村広場堰から直線で弁天池まで暗渠の用水路をつくることとした。三ヶ村は再度普請を行い、天保12（1841）年5月には完成している。この用水によって三か村合わせて22町7反1畝17歩が潤うこととなり、これは三ヶ村全体の田の約45％にあたっていた。****
