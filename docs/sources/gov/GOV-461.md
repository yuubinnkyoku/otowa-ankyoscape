# [GOV-461] 大久保町現状調査 — 淀橋浄水場の市外給水と下水道改良事業の定点

- **書誌〔確認〕**: 『大久保町現状調査』（東京市臨時市域**擴張部**編・[book/1900472](https://lab.ndl.go.jp/dl/book/1900472)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**大久保町（豊多摩郡・1932年淀橋区→新宿区大久保・百人町周辺）冊**＝**蟹川（戸山落＝神田川一支流候補）の中枢町＝現状調査シリーズ内では数少ない上下水道ともに「改良/新設」の実績を持つ側の定点**。**蟹川／戸山落への直接言及は本冊fulltext走査限りで陰性（陰性記録として掲げる＝地勢章の水路文言の有無は原画像照合課題）**。
- **上水道＝淀橋浄水場の市外給水〔文言候補・本ファイルの核心①〕**: 「**水源ハ東京市淀橋浄水場（ニシテ）（東京）市外給水（ノ）…昭和四年二月…認可（ヲ受ケ）着工…（昭和）五年度完成…給水面積四十六万坪…總工費二百八十七万五千円**」＝**①上水道の水源が東京市の淀橋浄水場（市外給水＝東京市から町への販売給水）であること、②昭和4年（1929）2月認可・着工、昭和5年度（1930）完成、③給水面積46万坪、④総工費287.5万円（候補値）**〔**①「市外給水」＝東京市が市域拡張前の周辺町村に水道を販売する形式が1931年時点で存在した一次文言候補（repo初出候補＝荒玉水道〔町村組合の自主水道＝GOV-450・GOV-454〕と東京市直営給水という**二つの上水道システムの併存**の1931年定点）、②淀橋浄水場（1924年着工・のち新宿区側）の市外側への供給実績の帳簿例**。数値・年次はOCR数字崩壊のためすべて候補値〕。
- **下水道改良事業〔文言候補・本ファイルの核心②〕**: 「**第一期下水道改良事業…五十二万八千七百三十九円（528,739円候補）…昭和二年…可决…（昭和）三年度ヨリ五年度（ニ至ル?）…**」＝**①下水道（の第一期）改良事業費528,739円、②昭和2年（1927）町会（?）可决、③昭和3〜5年度（1928〜30）実施**〔**「改良」事業＝大久保町の既存（＝明治期の）下水道の改良を意味する用語候補（対象四河川域外縁とはいえ、下水道の「新設」〔高田町＝GOV-454〕「計画」〔日暮里町＝GOV-457〕「計画ナシ」〔練馬町＝GOV-459〕に対する「改良（実績）」の第4類型として対照表化に値する）**。処分場・系統の文言はOCR崩壊で読み取り不能（次回の照合課題）〕。
