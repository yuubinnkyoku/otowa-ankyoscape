- **内容〔確認: 本文PDF抽出・第240回再抽出で数値欄復元〕**:
  - 谷端川水源地の**粟島神社（要町2-14-4〔第240回再抽出で復元〕）に、豊島区制70周年を記念してつくられた「**梟の樹を創る会**」（会長: 岩田甚一氏）による梟像コレクション「**ふくろうの路**」の**21号目が2009年8月10日に建立・除幕式が開催された**。開催日時は8月10日（月曜日）午前10時〜10時30分。
  - 同会は**世界中の若い美術家がデザインした梟像を48体建てることを目標**に掲げて活動を進めており（**現在21体**）、区内各地へ梟像を建てる活動を続け、**沿道景観や環境の保全、整備、観光振興など明るい文化都市豊島区のイメージアップ**を目的とする。**「ふるさと豊島を愛する心を育む」ため区内の子どもたちから「詩」を募集し、梟像の台座に彫り込む**。
  - 21号目は**「青少年を薬害から守るふくろう」**として建立。フランスの芸術家**ローレント・マイシン氏**のデザインで、「**人生をもっと楽しく**」という意味を込めて「**ウララ**」と名づけられた。
  - **梟像はフランスのテュールランディ村からの寄贈、台座は東京豊島ライオンズクラブからの寄贈**。**4月**にテュールランディ村で行われた受け渡し式で、会のほしかわよしお〔氏〕が「**地球のエネルギーが世界の人々の心を一つにし、ウララが知恵の神として青少年を見守る**」という現地の村長の言葉とともに受け取った。
  - 台座に刻まれた詩は**区立要小学校6年生・田中大河さんの詩「願いごと叶えてほしい ふくろうよ」**（**119の応募作品の中から選ばれた**）。**22号目は来年4月に建立予定**。
  - 除幕式には**豊島区長をはじめ21号目の誕生を待ちに待った地域の方々**が出席し、「ウ・ラ・ラ」の掛け声と共に白布を外した。**「池袋モンパルナスの画家がお参りに来ていた」**伝承に触れ、「**あるフランスから、東京のモンパルナスへ梟像が寄贈された**。これをきっかけに、若い芸術家がこの地に住んでいたということを世界にアピールしていきたい」（引用文言は出席者の発言として本文に記す）。
- **位置づけ〔観察〕**: 粟島神社＝谷端川水源・弁天池の所在地（[BLOG-195](../blogs/BLOG-195.md)由緒文言・[GOV-130](GOV-130.md)「弁天」呼称・[BLOG-217](../blogs/BLOG-217.md)湧水給水の観察・[PAP-026](../papers/PAP-026.md)水源地の学術論文）というrepoの水源地研究の文脈で、**同神社境内の現代的な土地の文化的利用（梟像コレクション「ふくろうの路」）の存在と、その21号建立（2009.8.10）を記録する区の公式記録**。水路・湧水の直接文言はなく、水源地という立地の神社の戦後～現代の境内の変遷・地域表象（「池袋モンパルナス」という地域イメージの系譜）の周辺史料として位置づける。梟像の現存・設置位置の特定は未実施。
