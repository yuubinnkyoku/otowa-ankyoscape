# [GOV-307] 『東京市水道小誌』（1911）— 神田・千川両上水の廃止年月の公式記録

- **書誌〔確認〕**: 東京市水道課編『**東京市水道小誌**』（**東京市水道課・1911年〔明治44〕**。出版年の末尾桁は奥付OCR由来で要照合）。NDL次世代デジタルライブラリー [book/845986](https://lab.ndl.go.jp/dl/book/845986)。東京市水道の沿革・設備を記した市の水道部門の小誌。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①六派の水道の総説〔確認文言〕**: 「**前後六派ノ水道アリシト云フ六派トハ即チ玉川上水、神田上水、千川上水、三田上水、靑山上水、龜有上水之ナリ爾後變遷興廢アリト雖モ就中三田靑山龜有ノ三派ハ中頃廢レテ今ニ尙ホ存續スルハ玉川神田及千川上水ノ三派ナリ**」＝江戸の六派（玉川・神田・千川・三田・青山・亀有）のうち三田・青山・亀有の3派が中期に廃れ、本書の時点まで続いたのが玉川・神田・千川の3派という整理。〔六派の構成の市側公式記録。千川上水を江戸六派水道の一つに数える整理の用例〕。
- **②神田上水の飲用廃止＝明治34年6月〔確認文言・年月日の確定記録〕**: 「**神田上水ハ新水道施設ノ結果明治三十四年六月其飮用ヲ廢スルト共ニ市内ノ給水ヲ斷チタルヲ以テ今ハ單ニ沿岸ノ水車業及東京砲兵工廠ニ供給スルノミナリ**」＝**①神田上水の飲用廃止と市内給水の切断が明治34年（1901年）6月、②以後は沿岸の水車業と東京砲兵工廠への供給のみ、という転用の内容と年月の明言**。〔沿革の部にも「**同年六月在來水道（玉川上水及神田上水）東京砲兵工廠及外市內一般ノ給水ヲ斷絕セリ其結果同九月…上水掛ヲ廢セリ**」（「東京砲兵工廠及外市內一般ノ」の部分はOCR崩れ・要照合）とあり、明治34年6月の給水断絶と同年9月の上水掛廃止という事務側の記録が対応する。神田上水の水車業・砲兵工廠への転用供給は既出の文言群と整合するが、「明治34年6月」という年月の市側一次文言は本書で確定する。〔[GOV-306](GOV-306.md)（1896年時点では市内給水が残る）と[BOOK-150](../books/BOOK-150.md)（1908年の観察）の間の基準点〕。
- **③千川上水の廃止＝明治40年6月・岩崎久彌の所有化と同時〔確認文言・年月日の確定記録〕**: 「**又千川上水ハ近年迄本〓（本郷）下谷ノ一部ニ給水セシモ明治四十年六月岩崎久彌ノ所有トナリ同時ニ之ヲ廃セリ**」＋千川上水の条「**然ルニ明治十三年更ニ岩崎彌太郞等千川水道會社ヲ起シ舊渠ヲ修理シテ本〓下谷ノ一部ニ給水シタリシカ明治四十年六月岩崎久彌ノ所有ニ歸シテヨリ市內ノ給水ヲ廃止セリ**」＝**千川上水が明治40年（1907年）6月に岩崎久彌の所有となり、同時に（市内の）給水を廃止したことの年月の明言**。〔[BOOK-140](../books/BOOK-140.md)（明治40年の岩崎所有化）・[GOV-290](GOV-290.md)（1905年現役）・[GOV-306](GOV-306.md)（1896年現役）の間を埋める決定的な年月日。「岩崎彌太郎（明治13年會社興起）→岩崎久彌（明治40年所有化・廃止）」の人物の引き継ぎの記述も本書に見える〕。
- **④千川上水の給水経路・起源譚〔確認文言〕**: 「**千川上水ハ北多摩郡保谷村ニ於テ玉川上水路ヨリ分岐シ沿渠各村ニ供給シテ巢鴨溜池ニ至リ夫レヨリ市內ニ入リ本〓下谷ノ一部ニ給水シタルモノナリ**」＋「**其開鑿ノ起因ハ元祿年間ニシテ彼ノ河村瑞賢ノ計畫ニ係リ多摩郡仙川村ノ農民德兵衞太兵衞ノ兩人此工事ニ從ヒ元祿九年中其工竣ル依テ彼ノ村名ヲ以テ名トシ又文字ヲ千川ト改メテ…兩人ノ姓ニ賜ハリ且ツ江戶府中ニ邸地ヲ賜ヒシト云フ**」＝**①保谷村分岐→沿渠各村→巣鴨溜池→市内（本郷・下谷の一部）の給水経路、②元禄年間・河村瑞賢の計画・仙川村の農民徳兵衞・太兵衞の2人が工事に従事・元禄9年竣工、③村名を名とし文字を千川と改めて2人に姓として賜り江戸府中に邸地を賜った由**。〔「彼ノ村名ヲ以テ名トシ」＝仙川村の村名由来説（文字を千川と改めた）の文言。江戸府中の邸地（千川屋敷＝[GAZ-049](../gazetteers/GAZ-049.md)④の白山前町千川屋敷条と対校）。安永9年再興後の給水範囲「本〓湯島、下谷、淺草等」の文言も本書にある（淺草はOCR崩れか・要照合）〕。

## 制限・未解決
