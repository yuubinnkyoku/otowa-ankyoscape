# [GOV-174] 1892年 東京市水道改良意見 — 千川上水の同時点数値

- **書誌〔確認〕**: 『東京市水道改良意見』（1892年）。NDL次世代デジタルライブラリー [book/845984](https://lab.ndl.go.jp/dl/book/845984)。OCRテキストで千川上水関係を確認。**数値はOCR由来で要照合。**
- **千川上水の数値〔確認・repo初出〕**: 明治25年（1892）時点の千川上水＝**保谷村に玉川上水を分派し、寸積百五十坪**を「旧来の千川用水路に引入」・**一旦田用水と合流**、**水路長五里六丁余・無葢溝172間・樋管3,879間**〔樋管は[GOV-173](GOV-173.md)（1891）の3,707間と差がある〕、**本郷・下谷の一部人口凡1.7万に給水・千川水道会社所有**。
- **位置づけ〔観察〕**: [GOV-173](GOV-173.md)と同時期の同種数値を別文書で記録し、**樋管延長の数値差（3,707間 vs 3,879間）**を観察として残す〔測定時点・区間差か誤植かは未確認〕。**「旧来の千川用水路に引入」「一旦田用水と合流」**＝1892年時点で旧千川用水路（江戸期の堀割）と田用水の合流構造が現用であった旨の文言は、[GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌）の「工業用水、田用水に用ひらる」との整合傍証。
