# [GOV-118] 武蔵野市「玉川上水・千川上水水質調査」頁〔repo初出〕

- **書誌〔確認: 公式頁本文（2025年9月3日Wayback保存版で全文取得・直接アクセスは403）〕**: 武蔵野市公式ホームページ「**玉川上水・千川上水水質調査**」、**掲載日2024年12月3日**、ページ番号1005005、担当は環境部環境政策課保全係〔[Wayback保存版](https://web.archive.org/web/20250903132634/https://www.city.musashino.lg.jp/gomi_kankyo/kogai_kankyobika/chosa/1005005.html)〕。
- **内容〔確認: 本文〕**:
  - **玉川上水・千川上水には清流復活事業として、下水処理場（東京都多摩川上流水再生センター）の2次処理水が放流されている**。市では流れる水の状態（汚れ具合）を把握するため、**主に生活環境項目の水質調査**を行う。
  - **平成28年度測定結果（PDF）**が公開されている〔PDF本文は武蔵野市WAFで未確認〕。
- **位置づけ〔観察〕**: [GOV-084](GOV-084.md)（武蔵野市「千川上水整備基本計画」2010・管理移譲3.8km）に続く武蔵野市区間の現況資料で、**管理移譲後の水質モニタリングが市の常設業務として公開されている**ことが新出。清流復活水の水源（多摩川上流水再生センター・2次処理水）を行政頁レベルで明記する点も、清流復活の水量構成（[BLOG-090](../blogs/BLOG-090.md)の1万トン中7000トン善福寺導水等の観察）と突き合わせられる行政側記録。
- **制限・未解決**: 平成28年度以降（令和期）の測定結果の有無、測定地点・回数は本文に見えず未確認。PDF本文の取得手段（武蔵市WAF回避）は次回課題。
