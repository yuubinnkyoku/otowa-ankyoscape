# [GOV-430] 享保撰要類集 二十六ノ上 — 町年寄由緒書の両水道支配・三ケ村代官・年百俵の文言

- **書誌〔確認〕**: 『享保撰要類集』二十六ノ上。町年寄三家（樽屋・喜多村・奈良屋）の由緒書・家職関係の行政事例綴（町人名字并刀御停止・熨斗目白帷子着用願・相続・退役願等の「縣宗恵町年寄」記録群）。NDL次世代デジタルライブラリー [book/2572837](https://lab.ndl.go.jp/dl/book/2572837)。**引用文言はすべてOCR由来で要原文照合**。
- **樽屋由緒書の天正18年の水道支配文言〔確認・repo初出〕**: 「**御入国以来天正十八年八月十五日於江戸町々支配役被仰付幷神田玉川両水道支配仕武州豊嶋郡之内関口小日向金杉三ケ村御代官相兼町年寄役相助代々刀帯熨斗目着用仕来候…其後神田玉川両水道は道佐奉行(?)支配に被仰付三ヶ村御代官所之儀も細井九左衛門支配に罷成候右之通先祖御奉公仕**」＝**①天正18年（1590・徳川家康の江戸入府の年）8月15日に江戸町々支配役が仰付けられ、「神田玉川両水道支配」を「武州豊嶋郡之内関口小日向金杉三ケ村御代官」と兼ねたという樽屋家の由緒の主張、②その後両水道の支配は「道佐奉行（OCR・原字形要照合）」の支配に移り、三ヶ村御代官所は「細井九左衛門」の支配になったという移管の文言**〔由緒書＝町年寄側の先祖の奉公の書上であり、水道史の史実としての採用は天正18年文言についてはあくまで「町年寄側の主張」として掲げる。ただしこの由緒が**天正18年 = 家康入府年の神田上水の起源とされる通説（樽屋藤右衛門の水道開削の伝承）の行政文書側の呼応候補**であること、また「関口・小日向・金杉三ケ村」＝[GAZ-049](../gazetteers/GAZ-049.md)/[GOV-384](GOV-384.md)の神田上水の三水道町（金杉・小日向・関口）の範囲と一致することの2点は指摘に値する〕。
- **寛延3年の樽屋家の上水御普請御用の記録〔確認・[GOV-426](GOV-426.md)の元文〕**: 「**寛延三午年八月十四日堀田相模守殿え御直ニ上ル町年寄樽屋藤左衛門病身ニ付退役願之儀…与左衛門後見仕町年寄役并上水御普請御用共に相勤候様可申付候哉**」（8月14日伺）＋「**寛延三午年十月十九日堀田相模守殿え上ル町年寄樽屋与左衛門御証文之儀申上候書付…藤左衛門取来候上水御用相勤候二付被下置候来百俵与左衛門名二而相渡候様御沙汰之文出候様仕度奉願候**」（10月19日の御証文名義変更願）＋「**寛延三午年十一月十七日御渡候御澄(証?)文覚来百俵樽屋吉五郎…町年寄役相勤玉川神田上水御普請世話仕候ニ付来如書面当午年被下候間任引付並之通以裏判手形向後藤左衛門時之通可被相渡候**」（11月17日御証文）＝**①樽屋藤左衛門の病身退役に伴い弟与左衛門が忰吉五郎の成長まで「町年寄役幷上水御普請御用」を後見する体制（寛延3年8月14日）＝[GOV-426](GOV-426.md)（明和撰要集・安永7年小札の再引用）の元となった寛延3年の直接記録、②**上水御用の職務に対して「来百俵」（年百俵）が下付されてきた由緒と、その名義を与左衛門に相渡す手続き、③御証文の本文に「玉川神田上水御普請世話仕候ニ付…被下候」とある＝上水御普請の世話の職務文言とそれへの年百俵の下付の一次文言群（repo初出）**。
- **並行文言〔確認・witness〕**: 別家（喜多村家側か・文脈要照合）の由緒書にほぼ同型の「**其後神田玉川両水道者道御奉行御先配被仰付三ヶ村御代官之儀も細井九左衛門支配と召越申候**」＝移管文言がもう一度現れる（「道佐奉行支配」「道御奉行御先配」の両方の原字形の照合作業へ）。
- **意味〔観察〕**: ①[GOV-423](GOV-423.md)（寛保元年4月・上水樋枡世話の町年寄移管）が町年寄の水道関与の管理史上の転換点として登録済みだが、**本冊の由緒書は両水道の支配を天正18年からの町年寄側の職務として主張し、その後奉行側支配へ移った経緯を書く＝寛保元年の「移管」が町年寄側の視座では先祖職の職分の復称に合わせた形になっている可能性の指摘**（因果の断定は原文照合まで保留）、②「細井九左衛門」＝[GAZ-104](../gazetteers/GAZ-104.md)（小日向寺社書上・元禄10年護国寺代知の「細井九左衛門御代官」）と同姓同名の代官候補で、時期（三ヶ村代官交代 ～ 元禄10年在職）の整合を指摘できる、③寛延3年8月14日・10月19日・11月17日の三段階の記録で[GOV-426](GOV-426.md)の再引用（「寛延三午年八月兄藤左衛門相願候に付…」）が元文と対応することを確認できた＝[GOV-426](GOV-426.md)側の引用文言の元文を確認できた。

## 制限・未解決

- ①「道佐奉行」「道御奉行御先配」の原字形はOCR崩れの可能性が高く、白堀・上水の移管先の官職名の確定は原画像照合が必須（候補: 作事奉行・小普請方・道中奉行等・断定しない）。②天正18年文言は由緒書（先祖の奉公の書上）であり、**神田上水の天正18年起源説の史料として直接採用するのではなく、町年寄側の主張の記録として区別して扱う**（家康入府期起源の通説との整合は示唆のみで因果は断定しない）。③与左衛門の表記（田中与左衛門／樽屋与左衛門・8月14日書付では「町人田中与左衛門」）の揺れとその理由（町人分家か表記崩れか）は要照合。④「御澄文覚」の原字（御証文覚か）・「来百俵」の「来」の読み（毎年来る百俵か）も照合要。
