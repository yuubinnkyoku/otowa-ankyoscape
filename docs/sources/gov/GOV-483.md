# [GOV-483] 豊島区プレスリリース「雑司ヶ谷霊園周回道路の古名表示案内板」（2002.1.30）〔repo初出〕

- **書誌〔確認: ADEAC豊島区デジタルアーカイブ目録詳細＋NDLサーチ書誌〕**: 「**緑のこみちに江戸の面影をしのぶ 雑司ヶ谷霊園周回道路の古名表示案内板を地域住民たちが設置**」。豊島区プレスリリース、**平成14年（2002）1月30日**。ADEAC目録 [mp405048](https://adeac.jp/toshima-history/catalog/mp405048)（本文PDF `mp405048/pressH140130_1.pdf`）・NDLサーチ [R100000094-I174283](https://ndlsearch.ndl.go.jp/books/R100000094-I174283)。本リポジトリの方法（ADEAC viewer頁のpdfjs経由取得＋ToUnicode CMapによる全文テキスト抽出）で**本文全文を直接確認**した〔確認: 本文〕。
- **内容①霊園外周の3古名案内板〔確認: 本文〕**: 都立雑司ヶ谷霊園（南池袋4-25）の外周に、江戸時代の古名と由来を紹介する**案内板3基**が2002年1月30日に設置された。古名の典拠は『**武蔵国豊島郡雑司谷村絵図（明和九年＝1772）**』で、3古名は**「鬼子母神道（きしもじんどう・霊園南）」「御鷹部屋道（おたかべやどう・霊園東）」「御鷹方御組屋敷道（おたかがたおくみやしきどう・霊園北）」**〔いずれも**repo初出の道名文言**。1772年雑司谷村絵図の存在と本リポジトリの画像観察記録（README「1772年『武蔵国豊島郡雑司谷村絵図』」の項）を、区自身の発行文体で裏側から補強する記録〕。プレス本文は、3道が「**音羽道・護国寺裏門から鬼子母神に通じる道**」として利用されていたこと、**徳川八代将軍吉宗の鷹狩り用の鷹の飼育所、鷹匠や同心たちの住む組屋敷**に由来すると説明し、案内板にもその説明が入ると記す〔確認: プレス本文の説明文。ただし吉宗期の比定・屋敷位置の対応は[GAZ-073](../gazetteers/GAZ-073.md)（享保4年正月「御鷹部屋御用屋敷御取立」・同年9月「御鷹部屋道敷」収用＝上戸塚村代地）・[PAP-072](../papers/PAP-072.md)（御鷹方御役屋敷の文献・絵図調査）との対校課題として断定しない〕。
- **内容②万年塀の生け垣化と「緑のこみちの会」〔確認: 本文〕**: 阪神・淡路大震災後の平成8年度の都の防災都市づくり重点地区指定→都の**霊園周囲万年塀改修計画**（当初は鉄板フェンス）→**平成10年度から3カ年・霊園周辺約1,000メートルの生け垣（一部緑化フェンス）整備**→**「緑のこみちの会」結成（平成11年3月・会員約70名）**という経緯が、案内板設置の背景として1枚のプレスにまとめて記録されている〔**「緑のこみち」・「緑のこみちの会」はrepo初出**。霊園周回道路が「緑のこみち」と呼ばれ、案内板がその生け垣の足元に建てられたことがわかる〕。設置主体は**雑司が谷地区まちづくり協議会・緑のこみちの会（両会長：伊藤博）**、案内板は日光から取り寄せたヒノキ・ケヤキを使った会員手作りで、**江戸時代の高札を模した形**、霊園外周3ヶ所に2002年1月30日午前10時から約2時間かけて設置〔確認〕。
- **位置づけ〔観察〕**: ①**1772年絵図上の道名（鬼子母神道・御鷹部屋道・御鷹方御組屋敷道）が、2002年時点で霊園外周の現地案内板という後世の表示に採用された記録**（絵図の道名の読み・比定の前提資料）、②音羽道・護国寺裏門→鬼子母神の道筋（READMEの弦巻川・護国寺回りの流路検討と接する交通史情報）、③霊園外周の生け垣という現況景観の成立年代（平成10〜12年度）の行政側記録、の3点で価値がある。ただし**プレスリリースは二次的な説明資料**であり、1772年絵図上の道名の判読そのもの、3案内板の現況（2026年時点の存置）、音羽道の経路実体は原図・現地で再照合を要する〔未解決〕。

## 制限・未解決

- ①案内板3基の**現況（存置・移設・撤去の有無）は未確認**（2002年設置時点の記録であり現存を意味しない）。②1772年絵図上の3道名の**原図での表記・位置の直接照合は未実施**（本repoの画像観察では道名レベルの判読に至っていない）。③「音羽道」の経路実体・「御鷹方御組屋敷道」と[GAZ-048](../gazetteers/GAZ-048.md)御鷹方組屋敷（14,530坪余）との位置対応は断定しない。④「歴史と文化の散歩道」ルートの該当区間の同定は未実施。
