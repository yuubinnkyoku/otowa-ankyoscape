# [GOV-072] 練馬区「千川上水・西武新宿線付近」

- **書誌〔確認〕**：練馬区公式サイト「ねりまの歴史を知る＞写真で見る練馬の今昔＞川・橋・公園＞千川上水・西武新宿線付近」。ページ番号641-579-203、更新日2024年4月11日。2026-11-11に直接確認。
- **開渠残存の位置〔確認：本文文言〕**：西武新宿線の上井草駅と上石神井駅の間、**下石神井四丁目29番**で線路の下を流れる千川上水。**線路下のわずか20メートル余りの区間だけは暗きょにならず、昔の流れが残っている**と説明〔現地観察・写真の有無は本頁上では3時点の写真（昭和38年撮影・資料番号24-0305、平成9年撮影・24-0522、平成29年9月撮影・24-0804）として掲載。これらの資料番号は練馬区の写真資料の所在特定に使える〕。
- **暗渠化の時期〔確認：本文文言〕**：**「千川上水は、区内では昭和25年頃から暗きょ化工事が行われ、この付近も昭和40年代に工事が終了しました」**。
- **暗渠化着手年代の3説の位置づけ〔推定〕**：着手年代について、①本頁「昭和25年頃から」（区公式・今昔シリーズ）、②[GOV-056](GOV-056.md)（練馬わがまち資料館）「練馬区内での実施は昭和27年3月以降」、③第17回ノートのWikipedia千川上水記事「練馬区内1952年（昭和27年）暗渠化着手」が並存する。**①は着手の時期をやや早く（昭和25年頃）に置く**。いずれも練馬区発の叙述で、着手の上限を昭和25年頃〜昭和27年3月の間に絞る材料になる。断定はしない。
- **他資料との整合〔確認・推定〕**：昭和40年代の完了時期は[GOV-069](GOV-069.md)（斉藤泰治証言・南田中付近の暗渠化）・Wikipedia系「昭和40年代前半完了」（第17回ノート）と整合する。20メートル余りの開渠残存区間は、[GOV-070](GOV-070.md)の記録フィルム（1952年）撮影地点一覧には含まれず、**現代まで水路形態が残る稀有な区間**として、清流復活区間（関町南〜）とは別に位置づけられる。
- **制限〔未解決〕**：資料番号24-0305・24-0522・24-0804の各写真の実画像・所蔵部署、昭和25年頃着手説の典拠となる行政文書（議会・事業記録）は未確認。
