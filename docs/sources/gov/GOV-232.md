# [GOV-232] 神田上水留（弘化3〜4年）— 白堀通の余垂板普請の幕府一次記録

- **書誌〔確認〕**: 『神田上水留』（幕府の神田上水関係留帳・NDL次世代デジタルライブラリーに同題62冊を確認）。白堀通普請一件は[13] [book/2587468](https://lab.ndl.go.jp/dl/book/2587468)・[14] [book/2587469](https://lab.ndl.go.jp/dl/book/2587469)・[15] [book/2587470](https://lab.ndl.go.jp/dl/book/2587470)の3冊に「**神田上水白堀通余垂板其外共御普請一件**」の件名で収録（同一事件の関係冊）。本ファイルの内容は[15]のOCR全文精読による。**引用文言はすべてOCR由来で要原文照合。**
- **白堀通の余垂板801間〔確認・repo初出の白堀普請の定量的記録〕**: 「**神田上水白堀通余垂板其外共御普請一件**」——白堀通の**余垂板（土手内に構える木板・表記はOCR「余垂板」で「余乗板」「余置板」等の字形対立の可能性あり要照合）**が**801間**（注文785間＋16間・高平均5尺と読める文言）に及ぶ御普請件。**区間は「小日向川添屋敷前通」から「小石川牛天神下」まで**＝白堀（神田上水の小日向〜小石川区間・[GAZ-049](../gazetteers/GAZ-049.md)⑬の「白堀上水關口の方より流れ來り、東流して小石川にかゝり、水戶殿屋敷に入る」区間）のほぼ全区間を対象とする大規模修復。年代は**弘化3〜4年（1846-47）**。
- **付帯工事の地点〔確認〕**: ①**金剛寺坂下の石垣**（長4間・高6尺と読める文言）②**小石川牛天神下水戸殿屋敷後口の矢来**（9間3尺と読める文言）③**茗荷谷坂下并新坂下の高札**——白堀沿いの坂（金剛寺坂・茗荷谷坂・新坂下）と施設（石垣・矢来・高札）の位置を幕府工事記録として列挙。**「新坂下」は[GOV-234](GOV-234.md)の新坂下橋（白堀通渡橋の七ヶ所化）と接する地点**。
- **工費〔確認〕**: 伺・入札を経て**千二百二十七両**→増減差引で**千二百四両1分2朱**（読みはOCR・要照合）。
- **鼠ヶ谷の言及〔確認・周辺〕**: [13][14]を含めて「鼠ヶ谷」のhitあり（音羽側の谷名・[地名・河川名対照表](../../地名・河川名対照表.md)の鼠ヶ谷系の文言候補・白堀普請との文脈上の関係は原文照合後に判断）。
- **〔2026-11-15第114回追記〕[13][14]の精読＝鼠ヶ谷大下×桜木町大下の渡石樋・矢来の修復仕様〔確認・repo初出の交差構造の一次記録〕**: [13]（2587468）・[14]（2587469）のOCR精読で、白堀通普請の仕様注文に**音羽谷底の交差構造の修復**が含まれていたことを確認。
  - **桜木町大下の渡石樋**: [13]「**桜木町大下水上一渡石樋 内長七間 幅九尺五寸 高五尺 右仕様惣体朽損候ニ付仕直候積**…石垣押二相成候ニ付石垣江馴染能仕付」＋[15]「**桜木町大下水上幅九尺五寸 一渡名樋(万樋?) 内柱長七間高五尺** 右仕様木品桧水形り土台入中角横土台…」＝**桜木町大下（東側）の「水上渡石樋」＝長7間・幅9尺5寸・高5尺の石樋が全面朽損し、土台を残して仕直された仕様**。「名樋」のOCRは[GAZ-035](../gazetteers/GAZ-035.md)桜木町の万年樋（万樋）系の呼称と対照課題。
  - **鼠ヶ谷大下の渡石樋の仕様注文**: [14]「**御修復仕様注文 鼠ヶ谷大下水上渡石道内一渡石樋 内挟長七間嘉(幅?)五尺七寸 右仕様土台其侭差置上廻朽損候ニ付仕直候積 坪柱木品積五寸角ニ長五尺上下帯指貫壱通…石垣江馴染能仕付**」＝**鼠ヶ谷大下（西側）の渡石道・石樋（内挟長7間・幅5尺7寸のOCR文言）の御修復仕様注文**（[13]の桜木町側の長7間・幅9尺5寸との対立は同一構造の別測りか別構造か要照合）。
  - **鼠ヶ谷大下・桜木町大下の矢来**: [13]「**鼠ヶ谷大下家(水?)上渡石樋廻り一矢来長延三拾間 桜木町大下永(水?)上同断一同長延三拾間 右仕様惣体折損候ニ付仕直候積**…**木戸門壱ケ所**」＝**渡石樋を囲む両側の矢来（鼠ヶ谷大下側30間＋桜木町大下側30間）と木戸門1ヶ所の折損仕直し**。
  - **工事内訳**: [15]（2587470）「**是は鼠之谷并桜木町共大下水上渡石樋 石六五(?)廻丸太矢来石垣取附之所…土台仕付…東押五寸角長弐間四本**…大工四人…賃銀拾七匁三分…手伝人足…」＝**「鼠之谷并桜木町共大下水上渡石樋」の丸太矢来・石垣取付の工事の出来形内訳（大工・人足の賃銀・土台材の明細）**。
  - **区間文言の完全形**: [13]「神田上水白堀通**架垂板**御普請仕様注文 **音羽町九町目町屋前通土手内一同長延三拾壱間** 桜木町町屋前通并水道町町屋前通共両側土手内 小日向服部坂下ゟ小石川小日向川添屋敷前通土手内一同長寄て三拾壱間 **牛天神下迄土手内一同長延六百七拾間** 一余垂板長延五拾三間高五尺…」＋同頁「**町屋後口一余垂板長六間高三尺右仕様洩水有之候ニ付新規余置板仕付候積**」＝**①区間の上流端に「音羽町九町目町屋前通」（31間）と桜木町・水道町の両側土手が明記される完全形、②本文表記が「架垂板」・「余垂板」・「余置板」の3種が混在**（[GOV-233](GOV-233.md)文久冊の「余乗板」とあわせ4変種・原字形照合課題）。
- **〔第114回追記・位置づけの補強〕**: 上記の鼠ヶ谷大下×桜木町大下の渡石樋・矢来の修復仕様は、**白堀（神田上水）と鼠ヶ谷下水（音羽谷）の交差部の工作物の構造数値（長7間・幅9尺5寸／5尺7寸・高5尺・矢来60間・木戸門）を、幕府の普請仕様注文レベルで記録した唯一の一次史料**。[GAZ-048](../gazetteers/GAZ-048.md)（風土記稿の「櫻木町にて神田上水の石樋を通して江戶川に入」＝東流の伏越）、[GAZ-035](../gazetteers/GAZ-035.md)（桜木町の万年樋・埋樋2ヶ所）の対校資料。**石樋が上水を渡す（水路橋）か下水を潜らせる（伏越）かは本記録のみでは断定できない**（「水上渡石樋」の解釈を含め原文照合後に判断）。
- **位置づけ〔観察〕**: [GAZ-049](../gazetteers/GAZ-049.md)の白堀（町方側の通称・承応2年堀割説）に対し、**幕府側の件名そのものが「白堀通」を用い、区間（小日向〜小石川）と規模（801間）と工費を記録する第一次の普請記録**。弘化期に白堀通の導水路としての機能が大規模に修復されていたこと＝**幕末直前も白堀通に流水を保つ構造が維持されていた**ことの傍証（[GOV-233](GOV-233.md)文久2年の潰水・浅水の指摘と対になる）。
