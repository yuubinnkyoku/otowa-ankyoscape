# [GOV-137] 豊島区議会「宮下橋改築工事」第63号議案説明資料〔repo初出〕

- **書誌〔確認: ADEAC目録詳細頁・本文PDF取得〕**: 豊島区議会 企画総務委員会「**第63号議案説明資料 宮下橋改築工事**」（**平成元年7月12日**・[ADEAC目録ID mp15000160](https://adeac.jp/toshima-history/catalog/mp15000160)・[本文PDF（14_02_H010712・CC BY）](https://adeac.jp/viewitem/toshima-history/viewer/viewer/14_02_H010712/data/14_02_H010712.pdf)・7頁）。PDFは画像スキャンにOCRテキスト層が付く形式で、テキスト層から主要な文言・数値を読み取った〔確認: OCRテキスト層の抽出〕。判読不能・誤変換の箇所は〔推定: OCR判読〕と明示し、原本画像の再判読までは確定扱いしない。
- **工事の基本仕様〔確認: OCRテキスト層（一部判読補正）〕**: 施工箇所＝**豊島区自巣鴨三丁目25番先 至巣鴨一丁目36番（先）**。構造形式＝**単純鋼床版桁橋**〔OCR文言「単純鋼床板鍍桁繕」からの判読補正・原本要確認〕、道路区分4種3級・設計荷重1等橋〔同〕、**橋長28.0m・支間27.0m・有効幅員10.0m**、交差角**68度10分（左）**、下部工＝**パイルベント式橋台2基**、基礎＝**杭基礎7本 L=22.5〜24.0m**〔OCR文言「抗基礎（現場打続）」→杭基礎（現場打杭）の判読補正〕。道路勾配は縦断8.0%・横断1.5%〔OCR判読〕。**仮橋**として**歩道橋（人・自転車・有効幅員2.0m・橋長28.0m）**を別箇所（自巣鴨三丁目側〜巣鴨一丁目37〔OCR判読・地番は要原本確認〕）に設けて代用した。
- **施工区分〔確認: OCRテキスト層〕**: **平成元年度**＝防護工（OCR文言「電車電河線防護工」・原本文言は要判読）・下部工・仮橋設置工・旧橋撤去工・仮設撤去等を**東日本旅客鉄道株式会社施工（区委託）**。**平成2年度**＝上部工製作・上部架設工・橋面仕上げ工・道路取付工・仮橋撤去工・撤去等を**豊島区施工**。**JR線にまたがる橋の工事を鉄道事業者（JR東日本）への委託と区直轄とに年次で分割した施工体制**が行政文書で確認できる。
- **repoの未解決問題への意義〔観察〕**: README・谷端川.md既述のとおり、豊島区「橋梁の点検」2024年度結果は現役の**宮下橋の所在地を「自巣鴨三丁目25番先 至巣鴨一丁目36番先」**と記し、2016年3月『豊島区公共施設等総合管理計画』は**鉄道を跨ぐ車道橋（橋長28.70m）**と記す。本議案資料の施工箇所は**点検表の所在地と地番で完全に一致**し、**橋長28.0mも台帳28.70mと概ね一致**（差0.7mは橋長の定義・計測差か後年の改良かは本文からは特定できない）、さらにJR東日本への工事委託・交差角68°10′から、**1989〜1991年の「宮下橋改築工事」の対象は現役の跨線橋宮下橋であることが強く示唆される**〔推定: 施工箇所・仕様・施工体制の一致による同定。工事図面の原本照合までは実施していない〕。この結果、旧谷端川の西池袋4丁目「#32宮下橋跡」（README既述）と同名異橋である点は変わらず、**旧河川橋の架設・改築年代への言及ではない**。谷端川.mdの「1989年の契約の対象が跨線橋かどうか未確定」（2026年11月1日追記）に対し、**対象橋＝跨線橋と確認できる一次行政文書**を提供する〔観察〕。
- **旧谷端川の橋名「宮下橋」（第41回・夢七雑録系の橋名由来「長崎神社下の橋」）との混同に注意**: 本資料の宮下橋は**道路がJR山手線を跨ぐ跨線橋**であり、旧谷端川の河川橋ではない。橋長28.0mを旧谷端川の川幅・旧河道幅に使わない〔注意〕。
