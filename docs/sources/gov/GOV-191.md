# [GOV-191] 諸事留帳 43巻[37]嘉永分冊一 — 「元千川上水屋敷」

- **書誌〔確認〕**: 『諸事留帳』43巻[37]嘉永分冊一（嘉永年間・幕政文書）。NDL次世代デジタルライブラリー [book/2548995](https://lab.ndl.go.jp/dl/book/2548995)。**すべての引用は同館OCRテキスト由来であり、文言・町名は原文画像との照合を要する。**
- **「元千川上水屋敷」の地名〔確認・repo初出〕**: 町方巡廻の書上（御組屋敷・御坊主拝領地等の巡廻記録）の列に、山王旅所門内・神田紺屋町代地・新保町代地・塗師町等の江戸の町名と並んで「**元千川上水屋敷**」の地名が登場＝**嘉永期（1848-54）に「千川上水屋敷」が「元（もと）」を冠する地名として江戸市中に残存していた**記録。〔文言はOCR要照合〕。
- **位置づけ〔観察・推定〕**: 天明6年（1786）の市中給水廃止から半世紀以上後の嘉永期に屋敷名が「元」付きで残存＝**上水関連施設の痕跡が地名として定着していた可能性**。「元」の冠が付くことは、嘉永期の巡廻時点ではもはや上水屋敷としての機能を失っていた（または名目化していた）ことの傍証候補。ただし町名として残っただけか、何らかの機能が残っていたかは本文では判別できない（断定しない）。屋敷の所在（小石川向山前の西千川〔[GOV-175](GOV-175.md)〕との関係等）も本文では特定できない。

## 制限・未解決

- ①屋敷の所在地の特定は不可（巡廻書上の配列からの推定も本文のみでは不能）。②「元」冠の名目化の時期は特定できない。③同分冊内の他の千川関連文言の有無は未精読。
