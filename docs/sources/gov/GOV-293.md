# [GOV-293] 東京市町名沿革史 続巻（1938）— 千川町の町名由来と西巣鴨の谷端川

- **書誌〔確認〕**: 東京市（東京市企画局都市計画課）編『東京市町名沿革史』（昭和13年・1938）。[GOV-208](GOV-208.md)（[lab id 1231150](https://lab.ndl.go.jp/dl/book/1231150)）の続巻にあたる冊（豊島区・滝野川区ほかを収録）。NDL次世代デジタルライブラリー [book/1231157](https://lab.ndl.go.jp/dl/book/1231157)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**〔両冊の巻次（上/下）の正式表記は目録照合を要する〕
- **千川町の町名由来〔確認・repo初出の文言〕**: 豊島区の町名沿革の記述で「**千川町一丁目 本町は字境窪の地なり。千川は域內を流るゝ舊千川上水に取る**」＝**千川町の町名が「域内を流るる旧千川上水」に由来すると明記**する官撰文言。続けて「千川町二丁目 本町は字北原の地なり」「千川町三丁目 本町は字水道向の地なり」＝**千川町一〜三丁目が長崎村の字境窪・北原・水道向に対応**する小字レベルの記録。〔「に取る」の判読（「に因る」等の可能性を含む）は原文照合を要するが、旧千川上水に由来する町名である旨の記述である点は明瞭〕
- **西巣鴨の谷端川〔確認〕**: 「西巣鴨三丁目…社線王子電車南北に走る、**二丁目との境に谷端川あり**」＝**1938年時点で谷端川が西巣鴨二〜三丁目の町境を流れていた**（開渠の存続を前提とする記述）〔谷端川の流態（開渠・暗渠の別）は本文言だけでは確定しない〕。
- **池袋村の用水〔確認・repo初出の引用形〕**: 池袋一丁目条で『新編武蔵風土記稿』を引用し「池袋村は地高して東北の方のみ水田あり…**用水は仙川用水を引注ぐ**」＝**池袋村の灌漑用水が「仙川用水」であることの風土記稿文言の再録**＝千川上水の「仙川」系名称（仙川村太兵衞・徳兵衞、仙→千の改字説〔GAZ-049〕）が用水の実務名として風土記稿に記録されていたことの町名沿革史レベルの確認。
- **内容メモ**: この冊の四河川関係は、千川町（町名・字名）・西巣鴨（谷端川の町境）・池袋（仙川用水）の3点が主。板橋区・滝野川区関係の町名（谷端関連字名）の記述も含まれるが、谷端川の直接的な流路記述は西巣鴨条の1点のみ。
