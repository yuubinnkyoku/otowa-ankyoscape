# [GOV-167] 高田町 町政概要（1930年・高田町独自の下水道調査）

- **書誌〔確認〕**: 高田町『町政概要』（昭和5年・1930）・NDL次世代デジタルライブラリー [book/1465831](https://lab.ndl.go.jp/dl/book/1465831)。**OCRが劣弱で引用の信頼度は本回確認分の中で最も低く、文言はすべて要原文照合。**
- **下水道の実施と調査〔確認・要照合〕**: 両側コンクリート下水・大谷石下水等の実施延長の記載、下水道延長1万3千余間（OCR判読）の内訳、**実測縦断面図の調製**（町の各機関の審議を経て下水道中心線の高低測量を実施）、**「東京府ヨリ交付セラレタル計画設計ト本町ノ調査ヲ対照」**との文言〔OCR〕。高田町が東京府の計画設計とは別に自町で実測を行い対照していた記録。
- **1万分の1図の流域区分〔確認・要照合〕**: 縮尺1万分の1の図面に**音羽流域・鶴巻川流域・旧神田上水流域・谷端川流域**の区分線と「至大塚町」「至学習院」「至早稲田」「至高田馬場」等の注記〔OCR・図面内容は未確認〕。弦巻川・水窪川の谷頭を含む高田町域の下水流域区分が1930年時点で図示されていたことの書誌記録。
- **位置づけ〔観察〕**: [GOV-163](GOV-163.md)（1924年・市側の音羽流域区分）と[GOV-166](GOV-166.md)（1937年・鶴巻川排水区）の間の町側の調査記録として、弦巻川・水窪川流域の下水道史（[GOV-123](GOV-123.md)の弦巻川暗渠化・沼脇低地文脈）に1930年の断面を与える。**実測縦断面図が現存すれば弦巻川・水窪川の谷頭地形の一次データになり得る**が、所在は本書誌情報からは確認できない。
