# [GOV-414] 練馬わがまち資料館「43 全村が区画整理された中新井村」〔repo初出・Wayback本文取得〕

- **書誌〔確認〕**: 練馬区「練馬わがまち資料館」（旧 URL https://www.nerima-archives.jp/column/2321/、現サイト移行済み・**Wayback Machineスナップショット2025年2月14日**で本文全文取得。「古老が語るねりまのむかし」シリーズ43）。語り手＝**金子定生（昭和2年生まれ・豊玉南在住）**、聞き手＝**亀井邦彦（練馬区史編さん専門委員）**。区報掲載の再録記事〔**平成4年（1992）8月21日号区報と同時代のシリーズ。掲載号の特定はスナップショット本文では確認できず断定しない**〕。
- **中新井川＝千川上水取水の分岐堰〔確認・repo初出の目撃文言〕**: 「田んぼは，**中新井川の水を利用したもの**でしたが，この川は，**豊玉と中村の境で千川上水の水を取り入れたもの**でした。今の**練馬自動車教習所（豊玉南3丁目）付近に堰（せき）があり，ここで川は2つに分かれ，1つは**富士稲荷神社（豊玉南3-11）の南側50ｍくらいのところを東に流れていました。**幅は1間（約1.8ｍ）くらい**でしたが，それからずっと南側が田んぼになっていて，その先に**中新井川の本流**が流れていました」〔**昭和6-7年頃（語り手が物心ついた頃）の中新井川の分水構造の目撃記録**＝千川上水→堰→2分岐→富士稲荷神社南側を東流する幅1間の支流と本流〕
- **南蔵院南の田んぼ〔確認〕**: 「南蔵院の南側にも田んぼがあり，これも**千川上水の水を中村地区内で引き入れて利用**したもの」〔南蔵院（中村）側の別系統の千川上水取水〕
- **清戸道＝千川通り〔確認〕**: 「村の中央から北側一帯はほとんど畑と屋敷森で，**清戸道（現在の千川通り）**沿いに何軒か店があり」〔清戸道＝現在の千川通り対応の語りの断定文言（現代の再録頁の注記の可能性もあり本文側層と断定しない）〕
- **中新井村の区画整理の年次〔確認〕**: 昭和7年10月板橋区編入を機に「村全域に区画整理」＝**昭和8年8月中新井町第一土地区画整理組合（現在の区役所一帯）→昭和9年11月第二組合（氷川神社〔豊玉南2-15-5〕辺り）→昭和10年3月第三組合（武蔵大学辺り）→昭和12年中村町第一組合（中村橋駅中心）→昭和13年中鷺土地区画整理組合**〔[PAP-039](../papers/PAP-039.md)（亀岡2022・中新井村土地区画整理事業資料）の組合史の古老側の通時確認〕
- **位置づけ〔観察〕**: ①「豊玉と中村の境で千川上水の水を取り入れた」中新井川の目撃記録（1931-32年頃）は、[PAP-083](../papers/PAP-083.md)（亀岡2017・千川上水中新井分水）の主題分水の**地表側の取水点・流路の目撃記録候補**（亀岡註4「中新井川＝江古田川（妙正寺川左岸支流）の呼称」説〔対照表104行〕との関係＝江古田川系本流への千川上水からの補給機構の実在を語ったものと読めるが、**目撃の「中新井川」が江古田川を指すのか千川分水路を指すのかは断定できない**・対照表中新井川行の第193回追記参照）。②練馬自動車教習所付近（豊玉南3）の堰位置は、[GOV-005](GOV-005.md)の学田公園（豊玉南3丁目）付近の「中新井の池」〔PAP-083註6〕との位置関係の照合課題。

## 制限・未解決
