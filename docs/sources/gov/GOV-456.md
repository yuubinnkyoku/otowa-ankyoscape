# [GOV-456] 中新井村現状調査 — 旧千川上水の境界・灌漑・排水文言候補

- **書誌〔確認〕**: 『中新井村現状調査』（東京市臨時市域**擴張部**編・[book/1900505](https://lab.ndl.go.jp/dl/book/1900505)・縦割OCR）。**引用文言はすべてOCR由来で要原文照合**。現状調査シリーズの**中新井村（1932年板橋区→練馬区・現中新井周辺）冊**＝**旧千川上水の北側堤防沿い（石神井通り〔旧千川上水北側堤防〕の北隣）に位置する村の1冊**。
- **地勢章の旧千川上水文言〔文言候補・本ファイルの核心〕**: 「**本村南部野方町ニ接スル附近ハ地〓(地勢?)〓マヽ低キモ概ネ平垣(平坦?)ニシテ…本村北部ヨリ府道ニ沿ヒ練馬町トノ境界ニ旧千川上水**」＋「**東流シ灌漑及排水ノ便アリ**」＝**①本村北部から府道に沿って練馬町との境界に「旧千川上水」があり、②東流して灌漑および排水に便がある（主語＝旧千川上水の水路／中新井村の地勢のいずれか＝要照合）とする1931年行政調査の文言候補**〔**①「旧千川上水」の呼称で1931年時点の現役水路（廃止された上水の旧水路＝千川用水系の路体を指すと推定される）を境界線として記録した行政文書レベルの用例、②灌漑・排水への利用機能の明記＝[GOV-455](GOV-455.md)長崎町の「灌漑其ノ他ニ便スル」と対になる裏付け文言候補（千川上水の廃止～昭和初期までの「灌漑用水としての存続」仮説を強める根拠）、③「東流シ」＝旧千川上水の中流部（中新井～練馬間）での流下方向の文言候補（千川上水全体が西→東流路であることと整合）**。主語の解釈（水路の機能か村の便益か）は原画像照合まで対校保留〕。対照表「旧千川上水」行へ追記。
- **沿革の井上正就拝領文言〔文言候補〕**: 徳川初期に当地が井上正就（江戸幕府老中・上野高崎藩主）に賜わりし地という沿革文言候補＝**中新井（新井の新規開拓地名）の地名由来と初期幕領の背景文脈**（井上家用例・OCR要照合）。
- **帳簿文言〔確認〕**: 人口・面積（一、〇九一、四二〇坪＝東京市の最大区たる芝区の約三割五分・最小区たる四谷区の約一割七分に当るという比較文言候補）産業・教育・社会事業・警備（上水道事業・下水道事業の目次項目が本シリーズの定番型として存在することもOCRで確認）＝1932年市域拡張直前の中新井村の帳簿。**面積が四谷区の約1.7倍＝旧千川上水沿いの「広い村」の規模感の定点**。

## 制限・未解決

- ①「東流シ灌漑及排水ノ便アリ」の主語は旧千川上水の水路機能／中新井村の便益のいずれとも読め、OCR列崩壊のため原画像照合まで断定しない。②「練馬町トノ境界ニ旧千川上水」＝旧千川上水の路体（堤敷）のうち中新井村側堤防が境界であったという1868〜1931年の土地行政の一次方法論の材料だが、位置の正確な対応（現石神井通り（旧千川上水の北側堤防）の北隣か）は地図対照を要する。③上水道・下水道事業の章の本文中身はOCR崩壊大（下水道＝石神井系統/千川系統の別は本冊からは読み取れず）。④井上正就文言の前後の文脈（賜年・村名との関係）は要照合。⑤数値群はすべて要照合。
