# [GOV-355] 市中取締書留 [222] 慶応 — 関口水道町の鉄砲製造所増用地の仰渡の実務記録

- **書誌〔確認〕**: 『市中取締書留』[222] 慶応（町奉行所の市中取締の達書・伺書綴の慶応期冊）。NDL次世代デジタルライブラリー [book/2572457](https://lab.ndl.go.jp/dl/book/2572457)。**引用文言はすべてOCR由来で要原文照合**。
- **慶応2年8月7日の鉄砲製造所増用地・構外往還道造の仰渡〔確認・[GOV-350](GOV-350.md)の一件帳書名の実務側対応〕**: 「**寅八月七日春名礼三を以被仰渡 右之助代藤兵衛え達し 町奉行衆大久保肥前守 関口水道町御鉄砲製造所増御用地御構外往還道造其外御普請に付 最寄町屋前え諸廻箱番屋等差置候間心得之儀御町役人江御申渡有之候様致し度存候**」〔**①慶応2寅年（1866）8月7日、町奉行衆大久保肥前守の番所から、関口水道町の御鉄砲製造所の増御用地・御構外往還道造（構外の往還の新設）其外の御普請に際し、最寄りの町屋の前に諸廻・箱番屋等を差し置く旨の心得が町役人へ申渡されたこと**＝**[GOV-350](GOV-350.md)（明治2年5月東京府持参覚の目録に見えた「関口水道町御鉄炮製造所増御用地御構外道造其外一件帳」）の書名と内容（増用地・構外道造）が完全に一致する幕末側の実務記録**（一件帳本体の所在は未確認のまま）。②「御構外往還道造」＝製造所の構外に往還（道路）を造る事業であることが実務文書でも確認できた**。
- **関口水道町の町人の製造所御用〔確認・周辺実務〕**: 同冊に「**関口水道町家主伊三郎・庄平 右之者御鉄炮製造所御用相届候ニ付時宜ニ寄夜中御用之儀も有之候ニ付勤中御用提灯貸渡申候**」（寅9月、町奉行衆・陸軍奉行並の達）〔**関口水道町の家主2名が御鉄砲製造所の御用に従事し、夜中の御用に備えて御用提灯の貸渡を受けた記録**＝製造所と町方の日常の結びつきの datapoint（[GOV-326](GOV-326.md)の関口水車塲の元治元年記録と明治期の造兵廠への過渡期の町方側記録）〕。
- **位置づけ〔観察〕**: [GOV-350](GOV-350.md)が書名（目録経由）だけで存在を推定していた一件帳の内容が、慶応2年の町奉行側の達書で年月日・奉行名付きで裏付けられた。関口水道町（神田上水堀筋・関口大洗堰沿いの町）の幕末の土地利用転換（鉄砲製造所の増用地・道路新設）の実務過程の記録。

## 制限・未解決
