# [GOV-123] 東京都下水道局『技術調査年報-2014- Vol.38』神田川流域雨水放流量緩和・段階方式2記事〔repo初出〕

- **書誌〔確認: Wayback保存版PDF全文取得〕**: 東京都下水道局『**技術調査年報-2014- Vol.38**』（**平成27年（2015）3月発行**、平成25年度実施分、下水道局長 松田芳和）所収の2記事。原本PDFは東京都オープンデータで公開されていた〔[オープンデータURL](https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2014all.pdf)・2026年11月時点の直接アクセスは403で、[Wayback保存版 id_ 2024-07-08](https://web.archive.org/web/20240708073130id_/https://www.opendata.metro.tokyo.lg.jp/gesui/R3/gijyututyousa/2014all.pdf)（本体15,069,642バイトを取得・本文抽出）で全文確認〕。頁数は本文頁フッタのノンブルで確認。
- **記事1〔確認: 本文（テキスト抽出）〕**: 鈴木淳也（建設部 設計調整課）「**区部河川における下水道からの雨水放流量の緩和について～神田川流域のケーススタディ～**」**pp.73-81**（要旨p.10・次記事がp.82開始で確認）。
  - 背景: **平成17年（2005）9月4日台風14号影響の集中豪雨で都内全域に約6,000棟の浸水被害**。整備途上の河川では下水道からの放流量規制があり吐口設置自体が困難な箇所もあった。
  - **平成20年（2008）3月31日、建設局と下水道局が「区部河川における下水道からの雨水放流量の調整、緩和に関する覚書」を締結**。河川ごとに確認書を取り交わす方式。手順は①流出解析モデル構築→②吐口複数選定と事業計画→③先行吐口選定→④実降雨でモデル再検証（必要に応じ確認書修正）→⑤残り吐口の緩和→⑥全吐口緩和後に再度再検証して完了。判断基準は**現況H.W.L.（既設護岸高から約1m差し引いた値）**。
  - **神田川流域では平成20年4月30日に「神田川流域における下水道雨水放流量の調整・緩和に関する確認書」を締結し、後楽ポンプ所・坂下幹線・第二十二社幹線・第二妙正寺川幹線の4箇所の吐口で放流量緩和を承認**。**平成21年5月に後楽ポンプ所、平成23年8月に坂下幹線の緩和を先行実施（平成23年度までに吐口工事完了）**、モデル更新・再検証（水位比較39箇所・平成23～24年の5降雨）を経て**平成25年（2013）3月29日に一部修正確認書を締結**。**隅田川・新河岸川流域では平成20年12月19日に確認書を締結し9箇所の吐口のうち5箇所の先行緩和を予定**、目黒川・白子川流域は検討中と記す。
  - モデル: **神田川流域約10,000ha**を**神田川・善福寺川・妙正寺川の河道と概ねφ800mm以上の下水道管網で構築**、降雨入力エリアごとに5雨量観測所を選定、水位比較39箇所で妥当性確認。
  - 坂下幹線の吐口断面協議事例: **計画放流量26.0m³/s（合理式）に対しシミュレーションによる当初緩和放流量19.5m³/s**。計画協議で断面縮小を指示され**袖壁を設けて高さ3.0m×巾2.15mに縮小**したところ袖壁損失で**緩和放流量18.6m³/s**となり、**平成24年に確認書を修正締結**。マニング式とシミュレーションの混用は断面確定を不能にする旨の課題指摘とともに、当面の暫定措置としてこれ以上の断面縮小検討は行わないとした。
  - **第二妙正寺川幹線は放流先の流況が複雑なため別途水理模型実験を実施**し、実験で安全性が確認された当初緩和放流量を踏襲、計画放流量は更新モデル上の最大値を記載したと記す。
- **記事2〔確認: 本文（テキスト抽出）〕**: 今井翔子（北部下水道事務所 再構築推進課）「**老朽化対策先行整備（段階方式）の拡大に向けた取組～実施設計における整備手法の比較・検証～**」**pp.45-50**（要旨p.6）。対象地域は豊島区池袋一・二丁目の実施設計（p.46表1の現況/将来系統はREADME既述のため重複記載しない）。
  - **p.50の注※2に「谷端川1号幹線の下流側は未整備となっている。（平成25年度現在）」と明記**〔確認: 注記の文言〕。対象地域の「老対（段階式）」は第1段階（能力確保GL-1.0m以下）を先行実施し、第2・第3段階で計画流下能力へ近づける整備手法で、**第2段階の実施時期が明確に設定できないため平成41年以降も浸水リスクを保有し続ける可能性**を指摘する。
- **位置づけ〔観察〕**: 記事1は**弦巻川・水窪川の合流先である神田川の、河川（建設局）と下水道（下水道局）の放流量協議の制度史（覚書→確認書→一部修正確認書）と、4吐口の名称・緩和実施年月を一次技術資料で固定する**。うち**第二十二社幹線は[GOV-119](GOV-119.md)（2008年報・水理模型実験時点で神田川放流渠吐口を残す工事中・暫定貯留管供用）と同一幹線で、2008年の実験・暫定運用から2013年の緩和承認に至る流れを接続する根拠になる**〔観察: 両記事の幹線名一致による接続。同一構造物である旨の相互明記はないため断定は保留〕。坂下幹線はREADME既述の「豪雨対策下水道緊急プラン」（計画排水量断片）に具体的な放流量値を与える。記事2の注※2は**README既述の「谷端川1号幹線整備完了（2013-14区資料）」対「谷端川一号幹線（一部）（2017区防災計画）」の表記差問題を、都下水道局自身が平成25年度時点で下流側未整備と記した技術資料として強める根拠**。
- **制限・未解決**: ①4吐口の位置（図4モデル概要図の原画像判読・後楽ポンプ所/坂下幹線の吐口地点は本文に住所なし）。②第二十二社幹線の神田川吐口位置と[GOV-119](GOV-119.md)記事の吐口の同一性。③新河岸川流域確認書の9吐口の個別名（本文に列挙なし・谷端川雨水渠関連吐口の有無は未確認）。④谷端川1号幹線「下流側」の区間定義（本文の注は一語のみで工区図なし）。⑤表1の緩和放流量・計画放流量の全吐口分の数値（p.79表1の画像判読未実施）。
