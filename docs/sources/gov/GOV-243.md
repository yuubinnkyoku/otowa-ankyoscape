# [GOV-243] 神田上水留[52]（慶応3年）— 神田上水の御組合普請金の武家方出銀取集帳

- **書誌〔確認〕**: 『神田上水留』[52] 「神田上水御組合普請金 武家方水銀取集帳 慶応三卯年四月 御金方」。NDL次世代デジタルライブラリー [book/2587507](https://lab.ndl.go.jp/dl/book/2587507)。慶応3年（1867）4月の神田上水の御組合普請金の武家方からの取集帳（[45][46][47][48][55][56]の水銀帳・[52]〜[58]の取集帳群のひとつ）。**引用文言はすべてOCR由来で要原文照合。**
- **御組合普請金の枠組み〔確認・repo初出の帳簿実態〕**: 「**水元江戸内共御普請金 御高拾万石 公儀御出銀**」＋地区別の賦課単位として「**神田橋内**」「神田橋御門内」「**昌平橋内銘々出銀取集**」「**猿楽町辺銘々出銀取集**」「稲荷小路」「元賀願寺前」「**小日向木道端銘々出張取集**」「**小石川御門之分**」「**小石川御門外組合**」「**牛天神下**」「**諏訪町**」等が並ぶ＝**神田上水の御組合普請金（共同修繕金）が、公儀（幕府）自身が10万石相当の出銀をする上位負担と、橋・町通りの単位（神田橋内・昌平橋内・猿楽町辺等）に分かれた武家方の石高割・名寄せによる賦課で構成されていた慶応3年の実態の帳簿**。
- **白堀通の独立の賦課単位〔確認・repo初出〕**: 「**白堀通銘々出銀取集組合高** 弐拾俵弐人扶持 一銀八分五厘壱毛 **久保応助 但五拾石之積 小石川御門之分 牛天神下**…」＝**白堀通が神田上水の御組合普請金の独立の賦課単位（組合）として帳簿に現れ、石高・扶持に応じた出銀（高20俵2人扶持につき銀8分5厘1毛等）を銘々から取集していた記録**＝[GOV-234](GOV-234.md)（明和撰要集・安永元年の渡橋渡下水の新規組合の石高附リスト・金杉・小日向・関口の三水道町の「古来持場」）以来の石高割負担組織が**幕末（1867）まで存続し、白堀通単位で運用されていた**ことの一次記録。
- **水戸殿の水元御普請金〔確認〕**: 「本元銘々高**三拾五万石** **水元御普請金 水戸殿一銀五貫九百五拾七匁壱** 高千七百七拾石御同人一銀三拾目壱分弐厘五毛 国込地分 小石川御門之分…」＝**水戸徳川家が35万石の高として「水元」の負担で約5貫957匁を出銀**した記録（水戸殿屋敷〔[GOV-232](GOV-232.md)・[GOV-233](GOV-233.md)の白堀通の下流端〕への給水の対価の負担か・名目は要照合）。
- **総決算〔確認〕**: 「江戸内石高合三百三拾三万四千六百九石壱斗九升七合 **武家方出銀金千弐百五拾壱両壱分壱朱**銀壱匁弐分七厘八毛 **町方出銀一金三百九拾六両弐分壱朱**銀壱匁六分六厘五毛 金千六百四拾七両三分弐朱銀弐匁九分四厘三毛」＝**神田上水の御組合普請金の武家方1251両余＋町方396両余＝計1647両余の総取集額**（慶応3年4月・神田上水廃止の2年前の大規模な共同修繕の規模）。
- **位置づけ〔観察〕**: [GOV-234](GOV-234.md)（安永元年の石高附リスト）→本帳（慶応3年の白堀通銘々出銀取集）→[GOV-237](GOV-237.md)（明治2年の水下町々の渡賃銭による浚渫費）という**神田上水の維持負担の組織（石高割の武家方組合）の19世紀を通じた連続性と、明治2年の渡賃銭への転換**を、帳簿レベルで確認できる記録。白堀通が「通り」単位の行政組織（組合年番＝[GOV-244](GOV-244.md)の天保〜嘉永の用例）として機能し続けたことの幕末の裏付け。
