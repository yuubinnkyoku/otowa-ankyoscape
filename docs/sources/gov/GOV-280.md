# [GOV-280] 玉川上水留 安政4〜5年 — 虎御門内外樋枡普請と御本丸掛矢来桝弐之枡

- **書誌〔確認〕**: 『玉川上水留』「玉川上水虎御門内外樋枡御普請御組合入用一件　安政四巳年三月より同五午年十二月迄」（全1冊）[book/2587409](https://lab.ndl.go.jp/dl/book/2587409)。repo未登録（「御本城」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔[GOV-279](GOV-279.md)と同年の安政4-5年の帳簿で、虎御門内外と代官町土手上〜御本丸掛の普請を扱う。〕
- **代官町土手上〜御本丸掛の矢来・桝弐之枡〔確認・repo初出の御本丸掛の設備〕**: 「**玉川上水代官町土手上ゟ御本丸掛矢来桝弐之枡其外樋筋御普請ニ付 清水御門山張番所脇小屋場木戸門白(?)壱ヶ所**」＝**麹町代官町の土手上から御本丸掛（江戸城本丸への給水管）に至る矢来・桝（弐之枡）その外の樋筋の普請に際し、清水御門の山張番所脇に小屋場の木戸門を設けた**＝**御本丸掛樋筋の起点側（清水御門・代官町土手上）に矢来（竹の囲い）・弐之枡（第二の枡）・小屋場が存在した設備記録**＝[GOV-279](GOV-279.md)（御本丸懸・吹上懸の水留と代官町土手上の定寸復帰）・[GOV-271](GOV-271.md)（明治2年・御本城掛樋筋の代官町土手上経由・「西城掛」）と対校して、**御本丸（城）掛樋筋が代官町土手上〜清水御門方面から城内に入る経路の幕末期の実態**が複数の冊で裏付けられた（「白」の字はOCR崩れ・「山張番所」は要照合。なお本冊の文言は「御本丸」、[GOV-271](GOV-271.md)明治2年は「御本城」で、表記の揺れは要原文照合）。
- **潰家・木戸門の設置場所群〔確認・repo初出〕**: 「**玉川上水…御普請所…潰家(?)…四谷御門外小屋場 四谷北伊賀町出小屋 牛込御門外揚場町屋前御堀端諸色揚場 芝口汐留橋西之方諸色揚場**」＝**四谷大通万年石垣樋枡・代官町土手上〜御本丸掛・虎御門外樋筋の普請に伴い、四谷御門外の小屋場・四谷北伊賀町の出小屋・牛込御門外揚場町の諸色揚場（資材揚場）・芝口汐留橋西の諸色揚場に仮設の小屋・揚場が設けられた**＝玉川上水の普請資材の搬入・揚げの拠点が、水路沿いに四谷〜牛込〜芝口（新橋）まで分散配置された実態（揚場町=牛込御門外＝現在の市谷〜牛込方面の船着場 related の揚場の地名記録としても値がある）。
- **城内御門群への触出し（山下御門を含む）〔確認・周辺〕**: 「**御門之上水相掛不申候旨認 外桜田御門 馬場先御門 和田倉御門 呉服橋御門 鍛冶橋御門 日比谷御門 幸橋御門 数寄屋橋御門 山下右番頭中…**」＝**安政4-5年の虎御門内外樋枡普請の水留でも、外桜田〜山下御門までの城内御門群に触れ出した**＝[GOV-275](GOV-275.md)・[GOV-277](GOV-277.md)・[GOV-279](GOV-279.md)と同型の定型文の反復＝**玉川上水の城内給水と御門管理体制の恒常性**（本冊のリストは虎御門・竹橋・半蔵等の後半が切れている可能性があり、全文の再確認を要す）。
- **水留の通達と講武所〔確認・周辺〕**: 「**玉川上水虎御門内外樋枡御普請所仮極江水移に付…一日限致水留**」（九月十一日等の反復）＋「**御築地講武所…浜御殿地…**」への通知＝虎御門内外の樋枡普請の水留の際、愛宕下の御築地講武所（現在の西新橋の講武所跡）と浜御殿地（浜離宮方面）にも触れた記録（[GOV-277](GOV-277.md)の経路文言の「浜御殿地掛り并愛宕下辺築地」と整合）。
- **薩摩小路組合年番〔確認・周辺〕**: 「**薩摩小路組合年番 松平阿波守殿 三浦志摩守殿**」ほか「**小組 浜掛 松平周防守殿 酒井下野守殿 愛宕下大通 井上伊豫守殿 数小路 松平丹波守殿 三名小路(大名小路?) 松平土佐守殿**」等＝**安政4-5年の虎御門内外樋枡普請の薩摩小路組合年番=松平阿波守・三浦志摩守**（[GOV-272](GOV-272.md)天保4年・[GOV-275](GOV-275.md)弘化3年・[GOV-277](GOV-277.md)/[GOV-278](GOV-278.md)安政3年・[GOV-279](GOV-279.md)安政4-5年と併せ、**薩摩小路組合の年番の交代系列が天保から安政までほぼ途切れず追える**ようになった。ただし同一人物の再任か別人かは官途名のみでは断定しない）。
