# [GOV-303] 東京都市計画報告 第14回（1937）— 改修工事進捗狀況表の改修区間・橋梁の文言

- **書誌〔確認〕**: 東京市都市計畫課編『**東京都市計畫報告 第十四回**』（1937年刊）。NDL次世代デジタルライブラリー [book/3462399](https://lab.ndl.go.jp/dl/book/3462399)。**引用はすべて同館OCRテキスト由来で、進捗狀況表は列崩れ（河川名列と區域列・数値列の混在）が著しく、文言・行対応は原画像照合を要する。**〔報告第12回＝[GOV-183](GOV-183.md)・第13回＝[GOV-184](GOV-184.md)に続く同報告シリーズの第14回〕
- **神田上水改修工事の區域文言〔文言候補・repo初出の区間表記〕**: 「河川改修工事進捗狀況」（昭和十二年三月末現在）表に「**神田上水改修工事**」の行があり、區域列と見られる箇所に「**自杉並區和田本町善福寺川合流點上流至中野區本〓通三丁目壽橋**」（本〓＝本町通のOCR崩れと見られる）が読める＝**神田上水改修の上流端＝杉並区和田本町の善福寺川合流点上流、下流端＝中野区本町通3丁目の壽橋**という区間の1937年3月末時点の公式記録候補〔[GOV-184](GOV-184.md)の告示768号（神田上水第一負担区＝壽橋→あやめ橋）の起点橋「壽橋」と整合し、[GOV-297](GOV-297.md)（帝都復興史）の改修計画の「上流壽橋」とも一致する。壽橋が改修区間の下流端の橋であることを進捗表レベルで裏付ける文言候補〕。
- **江戶川改修工事の區域文言〔文言候補・repo初出級〕**: 同表に「**江戶川改修工事**」の行があり、區域列と見られる箇所に「**自神田上水終點至神田川合流點**」が読める＝**江戶川改修＝「神田上水の終點」から「神田川合流點」までの区間**という公式の区間表記＝江戶川（旧神田上水の下流部）の改修区間の両端を神田上水終點・神田川合流點で表した1937年時点の記録候補〔[GOV-297](GOV-297.md)の江戶川改修計画（船河原橋下流川口〜駒塚橋上流郡市境界1,493間）とは別の区間表現で、改修の実施段階の江戶川の呼称と区間の対応を示す文言候補〕。
- **谷田川・立會川改修の區域文言候補〔文言候補・行対応保留〕**: 同表の周辺行に「**至東京市下水道藍染川放水路起點**」「**自巢鴨町下水道谷田川幹線終點至澁谷川**」「**自澁谷區松濤橋上流至神田上水合流點**」の文言が読める＝[GOV-184](GOV-184.md)（報告第13回）で確認した施行済区間文言「自巣鴨町下水道谷田川幹線終點」の後続部（〜至澁谷川）と、**立會川改修區域＝自澁谷區松濤橋上流至神田上水合流點**という区間表記の候補。列崩れのためどの文言が谷田川改修・立會川改修の行に帰属するかは原画像照合まで保留。
- **橋梁新設改修工事進捗表の「神田上水ニ架ス」橋梁〔文言候補・repo初出の地点〕**: 「橋梁新設改修工事進捗狀況」表に架設種別「**神田上水ニ架ス**」・位置「**中野區千代田町地内**」の橋梁の行が読める（ほかに「石神井川ニ架ス 板橋區上板橋三丁目地内」「江戶川ニ架ス」等が並ぶ）＝**昭和12年3月末時点で中野區千代田町地内（現・中野区弥生町・本町付近）の神田上水（＝神田川旧流路の改修区間）に橋梁の新設・架換工事の進捗表掲載件があった**記録候補〔橋名の列はOCR崩れで読めない〕。
- **位置づけ〔観察・内容メモ〕**: ①神田上水改修（[GOV-296](GOV-296.md)省令12号・[GOV-184](GOV-184.md)告示768号・[GOV-303]進捗表）で「壽橋」が改修区間の下流端・負担区の起点として一貫して現れることが確認できた（[GOV-182](GOV-182.md)の「中野橋」誤読説をさらに補強）。②江戶川改修の区間文言は「神田上水終點〜神田川合流點」と、**改修後の江戶川が神田上水の下流継承であることを区間名称のレベルで示す**。③進捗步合（%）の数値列は崩れており読み取り保留。

## 制限・未解決

- ①進捗狀況表は河川名列・區域列・延長・事業費・進捗步合列が横方向に崩れて混在しており、文言ごとの行帰属（谷田川改修・立會川改修・呑川改修・善福寺川改修等）は原画像照合まで保留。特に「自杉並區和田本町駒ヶ坂橋上流至和田本町神田上水改修始點」の文言は善福寺川改修の行か神田上水改修の別表記か未確定。②「本〓通」＝「本町通」の読みは文脈推定で原画像照合を要する。③數値（延長・事業費・進捗率）は本表では読み取り不能。
