# [GOV-388] 町会所一件書留（天保13寅中冊ノ二）— 堺町の小間減に伴う白堀浚賃銀の減額決算〔第165回〕

- **書誌〔確認〕**: 『町会所一件書留』天保13寅年中冊ノ二（町会所経由の一件書留・地所の引渡・上納・割賦の実務記録）。NDL次世代デジタルライブラリー [book/2587205](https://lab.ndl.go.jp/dl/book/2587205)。**引用文言はすべてOCR由来で要原文照合。**
- **堺町の地所上納と惣小間の減・白堀浚賃銀三口の減〔確認・核心〕**: 堺町（猿若町移転関連の地所処分）で「**元大坂町惣小間百弐拾六間弐尺壱寸之処此度五拾壱間弐尺弐寸相減候**」＝惣小間126間2尺1寸→51間2尺2寸への減。「**右ニ付御普請方御役所え上納仕候神田上水御普請金白堀浚賃銀同小銀三口共相減候段右御役所江御届申上御聞済相成町年寄江相納候公役銀御年御銀晦日銭共是又相減候**」＋「**其外町入用之儀も右小間相成候ニ付残小門ニ而割合候儀ニ相違無御座候**」＝**①堺町の地所の御普請方御役所への上納に伴い「神田上水御普請金・白堀浚賃銀・小銀」の三口がともに減額され、公役銀・御年御銀・晦日銭も減額された、②残りの小間で割合をやり直す**決算文言〔**白堀浚賃銀の負担が「神田上水御普請金」「小銀（水銀か）」と並ぶ独立の課目（三口）として小間（間口）割で賦課されていた**ことの天保13年（1842）の決算一次記録＝**repo初出**の負担・減免の実務文言。〔**[GOV-360](GOV-360.md)（猿若町移転に伴う上水負担の触）と時期・論点が整合する堺町側の帳簿**。猿若町（浅草）移転は天保12〜13年の一件で、堺町の地所減・負担減も同じ再編の中の処理。「小銀」は「水銀（水料）」のOCR候補・要照合〕。
- **決裁・立会の陣容〔確認・参考〕**: 引渡の立会に北御組与力・町年寄樽屋三郎左衛門・御普請方仮役清水三郎左衛門・改役鈴木治兵衛・下奉行出役牧原三蔵等が列する実務文言〔天保期の地所引渡・負担変更の役所間手続の参考〕。
