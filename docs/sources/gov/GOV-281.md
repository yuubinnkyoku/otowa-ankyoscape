# [GOV-281] 玉川上水留 慶応元〜3年 — 武家方水銀帳・出銀取集帳（給水料金の体系と薩摩小路組合の構成）

- **書誌〔確認〕**: 『玉川上水留』「玉川上水武家方水銀帳　慶応元乙丑年」（全1冊）[book/2587441](https://lab.ndl.go.jp/dl/book/2587441)・「同 慶応二丙寅年」（全1冊）[book/2587443](https://lab.ndl.go.jp/dl/book/2587443)・「同 慶応三丁卯年」（全1冊）[book/2587450](https://lab.ndl.go.jp/dl/book/2587450)・「玉川上水御組合普請金武家方出銀取集帳　慶応三丁卯年」（全1冊）[book/2587448](https://lab.ndl.go.jp/dl/book/2587448)。いずれもrepo未登録（「薩摩小路」横断検索で発見）。**引用文言はすべてOCR由来で要原文照合。**〔玉川上水の武家給水の料金（水銀=水料の銀）の割付帳と、組合普請金の出銀を取集めた帳簿。〕
- **水料の段階料率〔確認・repo初出の料金体系〕**: 「**一 高拾万石迄 百石ニ付銀弐分弐厘 一 高拾万石以上ゟ三拾万石迄 銀壱分五厘三毛 一 高三拾万石以上ゟ五拾万石迄 銀壱分弐厘 一 高五拾万石以上 銀八厘六毛(?)**」＝**武家方の水料は石高に応じた段階料率（10万石まで=100石につき銀2分2厘、10万〜30万石=1分5厘3毛、30万〜50万石=1分2厘、50万石以上=8厘6毛）**で、大禄の大名ほど100石あたりの料率が下がる累退構造＝玉川上水の武家給水の料金制度の体系的記録（「厘」「毛」の表記・最下段の料率の数字はOCR要照合）。
- **薩摩小路組合と佐賀藩〔確認・repo初出の組合の定量的実態〕**: 「**薩摩小路組合 一 高三拾五万七千三拾六石(35万7036石)**」＋「**松平肥前守 一 高拾七万八千五百拾八石余(17万8518石) 水銀四百弐拾八匁四分四厘三毛半(428匁4分4厘)**」＋「**虎御門外中屋敷分 水銀弐百拾四匁弐分弐厘壱毛(214匁2分2厘)**」＋「**幸橋御門内屋敷分 水銀弐百拾四匁弐分弐厘壱毛(214匁2分2厘)**」ほか「**松平甲斐守 一 高拾五万千弐百八拾八石余 水銀弐百三拾壱匁九分八厘…**」＝**薩摩小路組合の惣高35万7036石のうち、佐賀藩主松平肥前守（鍋島直大）が17万8518石で組合の過半を占め、その水銀（水料）は本藩分428匁4分4厘のほか、虎御門外の中屋敷分と幸橋御門内の屋敷分が各214匁2分2厘**＝**薩摩小路組合の最大の構成員が佐賀藩で、その屋敷が虎御門外中屋敷と幸橋御門内にあった**ことの帳簿側の定量的裏付け（**幸橋御門内屋敷分は[GOV-270](GOV-270.md)文久3年の「幸橋御門内 鍋島加賀守屋敷分」の帳簿側の対応〔慶応3年の鍋島=佐賀藩関係の屋敷か、別家の鍋島加賀守かは本帳の「松平肥前守」の屋敷名の文言と対校要〕**。松平甲斐守=久保田藩佐竹家分家か別家かは断定しない）。
- **紀伊殿・一橋殿・公儀・尾張殿〔確認・repo初出〕**: 水銀帳に「**紀伊殿 麹町屋敷分 一 高弐拾七万七千五百石 水銀…**」＋「**食違外(食違丁外?)屋敷分 高五万石**」「**芝屋敷分 高千六百石**」「**南伊賀町屋敷分…**」＝**紀州藩（紀伊殿）の麹町屋敷（高27万7500石の割付）・食違外の屋敷・芝屋敷・南伊賀町屋敷の水銀**＝紀州藩が麹町台の複数の屋敷で玉川上水を受けていた記録。出銀取集帳（2587448）に「**公儀 三拾万石 出銀五貫八百七拾七匁(5貫877匁)**」「**尾張殿 六拾壱万九千五百石 十二貫壱百三拾六匁五毛(12貫136匁5毛)**」「**一橋殿 拾万石 壱貫弐百拾壱匁(1貫211匁)**」「**一橋殿四谷屋敷分 六百九拾匁五分(690匁5分)**」「**亀之助殿 五万石 壱貫三百八拾壱匁(1貫381匁)****」＝**公儀（幕府）30万石・尾張藩61万9500石・一橋殿10万石+四谷屋敷分・亀之助殿（徳川慶頼か）5万石の水元（水元=水本の普請金）の出銀**＝**一橋家が四谷に屋敷を持ち（[GOV-270](GOV-270.md)の「一橋屋形」の帳簿側対応）、公儀・御三家・一橋家が玉川上水の水元の維持費を負担する体系**（「水元普請金」の語義・亀之助=徳川亀千代の改名時期との整合は要照合）。
- **与力・同心の水料〔確認・repo初出の町奉行与力・同心の給水〕**: 「**根岸肥前守組 与力弐拾五人 同人組(同心?)百人 右高合壱万六千石 一地米四斗 水銀三拾五匁弐分**」＝**町奉行根岸肥前守組の与力25人・同心100人の組が高合1万6000石（+毎年地米4斗）に相当の水銀35匁2分を納めた**＝与力・同心の組織も玉川上水の給水を受けて水料を負担した記録（根岸肥前守=南町奉行根岸鎮衛の一族かは時期（慶応）的に断定できず、別人の可能性が高い）。
- **麹町大通并永田町組合〔確認・周辺〕**: 出銀取集帳に「**麹町大通并永田町組合 四拾七万石…松平美濃守 四拾弐万六千五百石…出銀…**」ほか多数の大名列＝**慶応3年の麹町大通・永田町組合の惣高47万石**で、[GOV-279](GOV-279.md)安政4-5年の麹町太通・永田町役組合の年番（松平摂津守・丹羽左京太夫・大村丹後守等）と対応する組合の帳簿側の規模（構成大名の全容は帳簿の再精読と原文照合を要す）。

## 制限・未解決

- ①すべてOCR由来。料率・石高・匁目の数字はすべて原文照合必須（特に最下段の料率8厘6毛?・薩摩小路組合の惣高35万7036石・佐賀藩17万8518石）。②「水銀」は水料の銀（銀納の料金）と読めるが、帳簿の用語としての確定は要照合。③薩摩小路組合の全構成員のリストは3冊の再精読で補完が必要（本登録は代表的な文言のみ）。④「幸橋御門内屋敷分」が鍋島加賀守（[GOV-270](GOV-270.md)）と松平肥前守（佐賀藩）のどちらに対応するかは断定しない（両者の屋敷の位置関係の検討を次回に回す）。⑤2587441等に現れる「田安」の文言は人名「前田安之丞」のfalse positiveの可能性があり、田安家の水料と誤読しないこと。
