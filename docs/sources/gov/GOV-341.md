# [GOV-341] 東京府史 行政篇第5巻（1937）— 小金井桜の沿革と境水衞所の位置の府史レベル文言〔第151回〕

- **書誌〔確認〕**: 東京府編『東京府史 行政篇 第5巻』（1937年・NDL次世代デジタルライブラリー [book/1686821](https://lab.ndl.go.jp/dl/book/1686821)）。**該当頁はOCRの段組崩れ（複数段の文言の混交）が著しく、引用はすべて文言候補として原画像照合を要する**。
- **境水衞所と小金井桜並木の府史レベル文言〔確認・文言候補・repo初出〕**: 小金井の桜（史蹟名勝天然紀念物指定）の条——「**東京市水道局小川水衞所から下流同境水衞所に至る間の櫻並木**」（OCRでは「京市水道局小川水衞所から下流同境水衞所に至る間の櫻並木である」＝頭字の欠落候補）。〔**①小金井の桜堤が「東京市水道局の小川水衞所から下流の境水衞所に至る間」の玉川上水両岸にあることの、府史（官庁編纂・1937）レベルの文言＝境水衞所が桜堤の下流端（東端・武蔵境側）に位置することを示す行政文書側の記録候補**＝[GOV-338](GOV-338.md)（1913例規）・[GOV-340](GOV-340.md)（1936年報）と同じく境水衞所が東京市水道局（玉川上水路）の施設であることを前提とする記述。②「境水衞所＝千川上水の境橋分水点の施設」という解釈（[GOV-338]の制度文言からの想定）に対し、本文言は**境水衞所が玉川上水沿いにあって桜堤の下流端を成す**観察を直接的に示す初の府史級の文言候補（段組崩れのため確定は原画像照合まで留保）。〕
- **小金井桜の沿革（元文2年請負・翌3年6月竣工・川崎平右衞門定孝）〔確認・文言候補〕**: 同条の沿革叙述——「**武藏野新田世話役川崎平右衞門定孝が幕命によつて大和吉野·常陸櫻川から（種苗を取寄せ）…この上水路の小金井橋を中心として兩岸の堤塘一里餘に亘つて、元文二年工事を請負つて翌三年六月に至つて竣工した**」＋「**嘉永四年田無村の里正半衞と計つて櫻を數百本補植したといふ**」＋「**天保年中將軍家齊の賞覽があつてその名四方に擴がり**」。〔**①小金井桜の植栽を元文2年（1737）の請負工事（竣工・元文3年〔1738〕6月）とし、請負人を武蔵野新田世話役・川崎平右衞門定孝（大和吉野・常陸櫻川の種苗）とする府史の沿革文言候補**＝[BOOK-184](../books/BOOK-184.md)の旅行案内系（元文の頃・川崎平右衞門・幕府の許可）の元になったと考えられる官庁側の記述（依存関係は断定しない）。②**嘉永4年（1851）に田無村の里正・半衞が桜数百本を補植したという説**の採録（補植主体が田無村里正である点が旅行案内系にない詳細・文言候補）。③堤塘「一里餘」の規模文言。段組崩れのため語順・文脈の一部は復元を含む。〕
