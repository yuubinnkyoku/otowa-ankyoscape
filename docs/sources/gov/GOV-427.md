# [GOV-427] 明和撰要集第十二上 — 白山権現祭礼連署の「千川屋鋪」（安永3年）

- **書誌〔確認〕**: 『明和撰要集』第十二上。NDL次世代デジタルライブラリー [book/2549765](https://lab.ndl.go.jp/dl/book/2549765)。旧幕引継書系・町奉行関係の綴。fulltext（NDL lab API・ページtxt群）の全頁走査（2026-11-19第201回）。**引用文言はすべてOCR由来で要原文照合。**

## 安永3年（1774）9月19日: 白山権現祭礼差出町々の連署〔確認・repo初出〕

- **核心文言**: 「小石川白山権現江祭礼差出候町々月行事共一同御願申上候…右祭礼廻り場所之儀は場廣二御座候間是迄も度々喧嘩口論之上病人等も有之途中手間取候ニ付夜二入相廻り候場所も有之出し練物等差出候町々一統二甚難儀仕候依之右祭礼当日被下置候**定例御見分之外に御役人様方御出役被成下置候様**右祭礼差出候町之一同奉願上候…」＝**祭礼の宵宮（夜入相）廻りで喧嘩口論・病人・手間取りの難儀が続くため、定例の御見分に加えて役人の追加出役を求める文言**〔確認〕。
- **連署の冒頭**: 「安永三午年九月十九日 **小石川白山前町月行事佐平太印 同所千川屋鋪月行事茂八印 名主勘七印** 小石川戸崎町同所祥雲寺門前町同所法伝寺門前町同所喜運寺門前町月行事治兵衛印…本郷壱町目…同所六町目…小石川柳町同所下富坂町同所伝通院裏門前…**同所金杉水道町月行事茂左衛印 名主市御屋敷印** 駒込片町…駒込肴町…**同所追分町月行事長八印** 同所九軒屋敷…」〔確認〕。
- **意味〔観察・断定しない〕**: ①「**千川屋鋪**」（OCR・「千川屋敷」〔[GOV-208](GOV-208.md)/[GOV-210](GOV-210.md)/[GOV-211](GOV-211.md)・[BOOK-131](../books/BOOK-131.md)未解決④の千川家屋敷〕の誤認候補・要原字照合）が、**白山前町の直後に置かれた独自の月行事（茂八）を持つ連署単位として、本郷1〜6丁目・金杉水道町・駒込各町・小石川各町と並んで祭礼運用の町方単位を成している**＝安永3年時点で千川屋敷が（名主を持つ「町」ではないが）**月行事を置く区域運用単位として扱われた**一次文言候補〔確認・表記は原画像照合まで断定しない〕。②願の主体が月行事・名主層であること、③「同所」表記で白山前町に付属地名的に続くこと、から、千川屋鋪が白山前町の内分単位（町内の飛地・屋敷地割）である可能性が高いが、本願文言だけでは区域の実態（町屋化の程度・家数）までは断定できない〔観察〕。
- **位置づけ〔観察〕**: 千川屋敷は『新編武蔵風土記稿』で白山前町字形の説明に引かれる存在（[GAZ-104](../gazetteers/GAZ-104.md)他）で、repoでは地名・河川名対照表の「千川屋敷」行・[BOOK-131](../books/BOOK-131.md)未解決④に掲載中。**千川家の屋敷としての安永3年時点の行政運用上の位置**の一次資料として、時代を下る千川上水とは別に「千川」の家名・屋敷の区域的存在を示す補助資料〔観察：白山前町は白山御殿趾・白山神社の門前町で、千川屋敷の場所比定（現在の白山〜本駒込界隈説）を本条が動かすものではない〕。

## 同冊の周辺文言（参考）

- 同冊に「午六月曲甲斐守様牧大隅守」の白山権現祭礼伺の控え（「新規之場所に御座候間為御相談被仰聞候之趣…見廻り之同心共御差出被成可然」＝**四谷伝馬町天王稲荷の例も引き合いに出し、見廻り同心の差出を裁可する伺**、9月20日）もあり、安永3年の白山権現祭礼警戒の奉行所側記録として対応〔確認・補助〕。

## 陰性〔確認〕

- 「千川」は本連署の「千川屋鋪」1件のみ（単独の上水・用水名としては0件）。「弦巻」「谷端」「水窪」「野方」も本文0件。

## 制限・未解決

- ①「千川屋鋪」の「鋪」はOCR由来で、原字は「敷」の可能性が高いが原画像照合まで断定しない（風土記稿系の表記は「千川屋敷」）。②月行事「茂八」・名主「勘七」の実名・家は特定できていない（白山前町の町内文書との対校課題）。③連署は「千川屋鋪月行事」の後に「名主勘七印」が続くのが白山前町の名主か千川屋鋪の名主かはOCRの行割れからは確定できない。④祭礼差出の文言に千川上水（用水）関係の水利文言はない。
