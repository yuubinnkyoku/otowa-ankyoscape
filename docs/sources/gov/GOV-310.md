# [GOV-310] 玉川上水留〔26〕〔27〕 — 四谷代官町通「吹上御鷹部屋」の給水樋普請帳簿

- **書誌〔確認〕**: 『**玉川上水留〔26〕**』『**玉川上水留〔27〕**』（弘化2年〔1845〕）。NDL次世代デジタルライブラリー [book/2587360](https://lab.ndl.go.jp/dl/book/2587360)・[book/2587361](https://lab.ndl.go.jp/dl/book/2587361)。冊名（目次・ラベル）は「**玉川上水代官町通吹上御鷹部屋掛其外共樋枡御普請一件**」＝四谷代官町（現在の東京・四谷周辺・新宿区の区域で幕府代官が支配した町域）の**「吹上御鷹部屋」**に玉川上水を給水する樋・枡の普請（工事）の帳簿。
- **①「御鷹部屋」の別用例（四谷代官町）〔確認文言・repo初出の注意資料〕**: 幕府の鷹場運営の施設「御鷹部屋」への給水・水道の帳簿として、**弦巻川流域（雑司ヶ谷御鷹部屋〔[GAZ-048](../gazetteers/GAZ-048.md)⑭・御鷹部屋東の小溝〔[BOOK-152](../books/BOOK-152.md)〕）以外に、四谷代官町の「吹上御鷹部屋」という別の御鷹部屋が存在し、玉川上水から樋で給水されていた**ことを示す帳簿。
  - 〔**「御鷹部屋」は音羽・雑司ヶ谷の一帯に固有の施設名ではなく、幕府鷹場網の中で複数の場所に置かれた施設の一般名**であることの対照資料。弦巻川・水窪川の水源論で「御鷹部屋東の小溝」（金ヶ窪村〔[BOOK-152](../books/BOOK-152.md)〕）を引く際に、**雑司ヶ谷の御鷹部屋と四谷代官町の吹上御鷹部屋を混同しないための注意資料**として登録する（比較資料・陰性情報としての価値）。
- **②帳簿の内容〔確認文言〕**: 玉川上水から代官町の吹上御鷹部屋への**樋・枡（ひ・ます）の普請**（新設・修繕の工事）の記録で、**工費389両2分、弘化2年（1845）7月26日から11月11日までの104日間**の工事と記す〔fulltext確認済み・金額・日付の正確な文言は要原文照合〕。給水対象が鷹部屋（鷹の管理・鷹匠の詰所）である点で、鷹部屋の規模・常設性を示す間接資料。

## 制限・未解決

- ①本帳簿は四谷代官町の御鷹部屋の記録であり、**雑司ヶ谷御鷹部屋（弦巻川水源）の直接史料ではない**（あくまで対照・注意資料）。②「吹上」の語の意味（吹上御殿との関係か・地形の吹上か）は本帳簿からは特定できない。③工費389両2分の内訳（樋の延長・樋の材質等）の詳細はfulltextの走査が不完全で要再確認。④四谷代官町の位置の特定（四谷のどの町域か）は未確認。
