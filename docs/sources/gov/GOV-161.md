# [GOV-161] 都市計画東京地方委員会 議事速記録 第8号（1935年12月20日）

- **書誌〔確認〕**: 都市計画東京地方委員会『議事速記録 第8号』（第19回委員会・1935年（昭和10年）12月20日）・NDL次世代デジタルライブラリー [book/1207625](https://lab.ndl.go.jp/dl/book/1207625)。**引用はOCRテキスト由来・要原文照合。**
- **議第142号「東京都市計画河川改修年度割変更ノ件」〔確認・repo初出〕**: 立会川・神田上水・谷端川改修の年度割を1箇年延長（昭和5〜10年度の6箇年→**昭和11年度まで**）。総経費は変更後**563万余円**。1935年（昭和10年）9月4日内務大臣後藤文夫発議・同年12月委員会可決。これは[NDA簿冊 纂02179100-00100（1935-12-28・GOV-135）](GOV-135.md)の委員会側審議記録で、[GOV-159](GOV-159.md)の1930年決定（520万9千円・4箇年）から予算総額が約42万円増額・事業期間が2箇年延長したことを示す。
- **議第160号「東京都市計画事業 立会川、神田上水及谷端川改修受益者負担ニ関スル件」〔確認・repo初出〕**: 1935年12月16日内務大臣後藤文夫。**受益者負担区劇図つき**の令案で、区画は立会川（大井町方面）・神田上水・**谷端川（王子〜池袋方面）**の3地区〔文言・区画名はOCR・要照合〕。委員会で修正可決。これは[GOV-102](GOV-102.md)（1936年4月14日官報・内務省令受益者負担金額）に先行する**委員会決定段階の記録**で、受益者負担制度が1935年末に都市計画委員会で審議されていたことを示す。
- **大塚駅附近街路計画変更（一等大路第三類第十四号・補助線道路第57号路線）〔確認・重要〕**: 大塚駅周辺の街路を架道橋東方で直接連絡させ幅員を拡大する変更。「**曩ニ都市計画事業トシテ執行済ニ係ル谷端川暗渠敷ヲ可成利用シ**且学校其ノ他ノ移転ヲ避ケムカ為」の文言。この文言は[NDA簿冊 簿02227100-01300（1936-04-02・GOV-135）](GOV-135.md)に見えるものと同文で、**1935年12月時点で谷端川の大塚駅区間暗渠敷が「執行済」であったことを公文書文言の二重確認**とすることのできる時点情報源。ただし「暗渠敷の全線完成」ではなく当該区間の執行を意味するのみで、1940年3月[NDA簿冊「立会川及谷端川ハ既ニ完成」（GOV-135）](GOV-135.md)と併せて過程として読む。
- **位置づけ〔観察〕**: 1930年（[GOV-159](GOV-159.md)）→1934年（[GOV-160](GOV-160.md)）→1935年（本項）→1936年（施行細則・[GOV-102](GOV-102.md)）→1940年（完成）という谷端川改修の制度過程のうち、**予算の最終形と受益者負担制度の原案**を含む記録。大塚駅東側の街路（現・大塚駅前〜国道254号方面の路線網）が谷端川暗渠敷の転用を明示して計画された点は、[GOV-123](GOV-123.md)（大塚の谷端川痕跡）の地形解釈に制度側の裏付けを与える。
