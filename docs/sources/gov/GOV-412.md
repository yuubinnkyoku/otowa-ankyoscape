# [GOV-412] 練馬区「河川占用・公共溝渠の使用許可について」＋練馬区公共溝渠管理条例〔repo初出〕

- **書誌〔確認: 練馬区公式HP本文取得・2026-11-19〕**: 練馬区公式HP「**河川占用・公共溝渠の使用許可について**」、**ページ番号227-103-881**、**更新日2025年1月1日**。URL: [kasen_koukyo_kyoka.html](https://www.city.nerima.tokyo.jp/kurashi/sumai/kasen/kasen_koukyo_kyoka.html)。
- **核心文言〔確認: 本文〕**: ①「**公共溝渠（練馬区が管理する水路等）**において、工作物を設置する場合などは、練馬区の許可が必要」＝公共溝渠の語義の区公式文言（[GOV-411](GOV-411.md)の第三分類定義と一貫）。②「**なお、現在、新規の使用許可申請は工事用足場等の一時的な使用等に限定しています**」＝恒久的な占用を認めない現行運用の明記。③窓口は**土木部管理課道路占用係**。④様式＝公共溝渠使用許可申請【新規】【継続】【変更】の3種（Excel・LoGoフォーム対応）。⑤河川占用側では、練馬区内の一級河川は**「石神井川」および「白子川」の2河川のみ**と本文で明示（河川法第24条・26条の許可・東京都建設局の様式・**東京都第四建設事務所**管理課への事前相談）＝**練馬区内の一級河川の一覧が「石神井川」のみならず「白子川」と対で与えられる陰性情報**（千川上水・濯川・谷端川系は一級河川（準用を含む河川法上の河川）として現行では位置づかれないことを裏側から示唆。都の河川台帳系との正確な照合は別途課題）。
- **練馬区公共溝渠管理条例〔断片のみ・原文未取得〕**: [g-reiki.netの条例本文](https://www1.g-reiki.net/nerima/reiki_honbun/a100RG00000375.html)は当環境から**403遮断・Waybackスナップショットなし（2026-11-19）**。検索エンジンのsnippet経由で**附則に昭和58年・昭和61年の使用料改正の文言**が見えるのみ＝現行条文は「所在地未確認（原文未取得）」レベル。**公布年（昭和28=1953年）は[PAP-083](../papers/PAP-083.md)註10（亀岡岳志2017「練馬区公共溝渠管理条例が公布されている」）による二次情報**で、附則断片（58・61年改正）と併せて、条例が**半世紀を超えて運用される現行制度**であることのみ記録する。
- **位置づけ〔観察〕**: [PAP-083](../papers/PAP-083.md)註10の昭和28年公布説に、①附則断片（昭和58・61年使用料改正）、②2025年運用文言（新規許可は足場等一時使用に限定）、③第三分類としての制度的定義（[GOV-411](GOV-411.md)）が接続＝**公共溝渠＝1953年（亀岡註10の二次情報）以来現行まで70年近く運用される練馬区の水路管理制度**という制度史の軸（谷端川の準用河川廃止〔1962〕・桃園川の準用河川〜下水道移管〔PAP-065〕と並ぶ、都市水路の法的地位問題の現代側の補助線）。ただし条例本体の制定年・条文構成は原文取得まで確定しない。
- **制限・未解決**: ①条例全文の未取得（g-reiki遮断・区例規集・図書館蔵での確認が次の課題）。②「新規使用許可の一時使用限定」方針の開始時期は本文に 없（言及なし）。③公共溝渠の使用料額・許可件数等の統計は未確認。


- **〔2026-11-19 第193回追記・条例全文の所在解決〕**: 『練馬区史 現勢資料編』（[GOV-075](GOV-075.md)・honcho5・p.589以降）に「**練馬区公共溝渠管理条例（昭和二十八年七月二十三日条例第九号）**」の**全文（第1条〜第25条＋付則）**が収録されていることを本文直接取得で確認〔本ファイルの制限①「条例全文の未取得」（g-reiki遮断）は解消〕。要点＝①**公布年月日・条例番号の確定（昭和28年7月23日条例第9号）**：第192回時点の「昭和28年公布（亀岡註10の二次情報）」が区史資料編本文レベルで裏付けられ、伴って年表〔[GOV-413](GOV-413.md)〕の「昭和28年 練馬区公共溝渠管理条例公布」と整合。②**第2条（定義）**:「この条例において『公共溝渠』とは，**溝渠および堤塘，護岸，土揚敷その他これに附属して一体をなす施設**…であつて**一般公共の用に供せられているものの総称**をいう」〔第192回の符頭のスニペット文言と本文一致〕。③**第3条（行為の禁止）**＝土石・じんかい・汚物の放棄、有害廃液の直接排出、き損行為等の禁止。④**第4条（使用許可）・第5-7条（出願手続・願書・添付書類・利害関係者との協議）**＝区長の許可制（工作物の新築除却・竹木植栽・流水に影響する工事等）。⑤**第9条（使用料）**「使用面積により，一平方メートルにつき，**月額二十八円**」・第10条（電柱類・地下埋設物等の算定特例）・第11条（減免）・第12条（使用期間一年以内・特別の事由は三年以内）。⑥**第24条（過料）**「二千円以下の過料」。⑦**付則の改正3回（昭和50年3月17日条例第13号・昭和51年3月30日条例第16号・昭和54年3月14日条例第12号）**＝第192回のスニペットの附則改正（昭和58・61年等）より前の改正群で、使用料水準（月額28円）は昭和54年改正時点のもの〔honcho5の印刷は昭和55年刊なので、この条文は刊行時点の現行形。昭和58年以降の使用料改正文言（検索スニペット）と併せて改正史は連続する〕。⑧**目文言**＝「地方自治法の一部を改正する法律（昭和四十九年法律第七十一号）による改正前の地方自治法第二百八十一条第二項第九号の規定による公共溝渠の管理」＝旧地方自治法281条2項9号を根拠とする「**特別区が管理する公共溝渠**」の条例であることの条文上の確認〔[GOV-411](GOV-411.md)の第三分類定義（区道＋区有通路＋公共溝渠）の制度的関係の確認〕。〔いずれも区史資料編本文のテキスト由来で、区例規集原本との字句対照は今後課題。付則の日付・条文番号は区史印刷のまま記録〕
