# [GOV-386] 正宝事録 七十七 — 白堀浚賃銭の時相場請取願の返答指令〔第165回〕

- **書誌〔確認〕**: 『正宝事録』（幕府の御触書・例事の記録）の第七十七冊（収録は寛保4年〔1744〕〜宝暦5年〔1755〕頃の触書・御用の列記形式）。NDL次世代デジタルライブラリー [book/2571351](https://lab.ndl.go.jp/dl/book/2571351)。**引用文言はすべてOCR由来で要原文照合。**
- **白堀浚賃銭の時相場請取願〔確認・核心〕**: 七月廿日の条「**神田上水白堀浚賃銭時相場に而請取度願に付可致返答之事**」＝**神田上水の白堀浚賃銭を「時相場」で請け取りたいという願に対し返答するよう命じる触**〔**白堀浚賃が銭納で「時相場」（その時々の相場値段）での請取をめぐる交渉があった**ことの町奉行所側の一次文言候補。**浚賃負担の請負形態（定額ではなく相場建）を示す用例はrepo初出候補**。〔寛政期の[GOV-385](GOV-385.md)（定式入用計上）・天保期の[GOV-387](GOV-387.md)（押切帳別集）へと連なる負担制度史料列の18世紀中葉側の環。願主・返答の内容（容否・金額）は本冊では見えない〕。
- **同冊の関連する周辺文言〔確認・参考〕**: 水汲惣代筋願人（四月十三日）・橋普請幷人留の御番所願（六月九日・道御奉行仰渡）・日用無礼の役銭無滞（六月廿二日）等の町方行政の触の配列の中に上記文言が位置する〔上水負担の行政が町方の日常行政の枠で処理された文脈〕。

## 制限・未解決

- ①「七月廿日」の年は寛保4〜宝暦5年の収録期間内のいずれかで、本冊のOCR本文からは特定不能（干支・年号の付記は見当たらない）＝絶対年次は未確定のまま登録。②「請取度願」の願主（町方側か浚賃請負側か）は文言だけでは特定できない。③「時相場」の原字形（時相場/其時相場等）は要照合。
