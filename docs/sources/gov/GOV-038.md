# [GOV-038] 『千川家文書』（練馬区指定文化財、石神井公園ふるさと文化館所蔵）

## 書誌・所在（2026-10-30、練馬区公式ページと同館所蔵資料リストの直接確認・ai）

- 千川上水の開削・管理に関わった千川家に伝わった文書群。練馬区指定文化財（平成9年度区登録・平成10年度区指定）。
- 点数と年代：元禄9年（1696年）の千川上水請負手形から明治17年（1884年）の千川上水絵図まで、江戸期168点・明治期62点・年代不詳67点の計297点（練馬区公式「千川家文書」ページ、および石神井公園ふるさと文化館「所蔵資料リスト」文書類3番の記載で一致）。
- 構成の要点（練馬区公式ページ）：千川家から諸役所へ差し出した上申書などを書き写した御用留は、欠年が多少あるものの明和5年（1768年）から明治16年（1883年）まで20冊。絵図類は21点あり、配水の様子などを伝える。冒頭に掲出される代表資料は「千川用水一件（御用留）」「竹下新田付近の絵図」「御上水永々御請負定手形之事」。
- 所在地：石神井公園ふるさと文化館（練馬区石神井町5丁目12番16号）。同館では2026年9月12日から11月3日まで特別展「水を守る―千川家と千川上水の330年―」で千川家文書を展示（練馬区文化振興協会の催し案内で確認）。
- 練馬区公式ページ：https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/rekishibunkazai/bunkazai/b0904.html （更新日2026年3月19日）
- 所蔵資料リスト（練馬区公式PDF）：https://www.city.nerima.tokyo.jp/kankomoyoshi/bunka/nerimi.files/hurubunrisuto.pdf
