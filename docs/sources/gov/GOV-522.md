# [GOV-522] 豊島区「千川コミュニティガーデン」〔千川中学校プール跡地の土地利用の現況記録〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: 豊島区公式サイト「まちづくり・環境・産業 > 公園・緑化 > 公園 > 取り組み > みんなで育てる菜園！…」。**ページID 56315・更新日2026年6月22日**。 https://www.city.toshima.lg.jp/610/saien/2604210913.html 〔コンテンツ部分の表記ゆれ「千川コミュニテイガーデン」あり〕。
- **事業の構造〔確認: 本文・文言〕**: 「**豊島区が保有する未利用地（千川中学校のプール跡地）を有効活用し、民間企業がコミュニティガーデンとして整備・提供する新しい形の菜園**です。単なる「区画貸し」の菜園・農園とは異なり、**会員様同士で菜園全体をシェアして栽培を行います**。専門スタッフが栽培管理や利用者様同士のコミュニケーションをサポート」「※本事業は「**豊島区企業等による事業提案制度実施協定書**」に基づき、**DAIKEN株式会社が豊島区より補助を受けて実施**します」＝**区有未利用地×民間補助事業（DAIKEN）という新しい活用スキーム**。
- **所在地・諸元〔確認: 本文〕**: 名称＝**千川コミュニティガーデン**。**開園：2026年6月6日（土曜日）**。対象＝豊島区在住。**場所：豊島区高松1丁目12（千川中学校プール跡地）**。**アクセス＝東京メトロ要町駅から徒歩5分**。**利用料金＝1世帯ごとに月額3,000円（税込）（水道、用具、肥料・種代等込み）**。魅力＝「普段着」「手ぶら」で通える（立って作業ができるため体への負担が少ない）・地域とつながる。※利用者感想の引用は千葉市のコミュニティファーム利用者のもの（豊島区のものではない）と明記〔区本文自身が注記〕。
- **満員・追加募集〔確認: 本文・2026年6月22日時点〕**: 「このたび追加募集を行いました「千川コミュニティガーデン」は、**多くの皆さまからお申し込みをいただき、利用枠が満員となりました**」「今後につきましては、**空き状況が生じた際には随時情報を発信**してまいります」＝**開園約2.5か月で満員**〔会員数・区画数の数値は本文に未記載〕。
- **意義〔観察〕**: ①**千川中学校（[GOV-518](GOV-518.md)公園等再構築プランの高松・要町・千川モデル地域の周辺施設欄に「改修中」と記載）のプール跡地**という区内の土地履歴の2026年現況＝高松1丁目（千川上水旧流域・都が千川上水浄水場から区に払い下げた一帯の近隣〔[GOV-106](GOV-106.md)〕）の学校施設の未利用地が菜園に転用された一次記録。②プールの廃止年次・跡地の面積は本文記載なしだが、**「プール跡地」という呼称自体が、千川中学校のプールがすでに撤去・廃止されていることを区自身が示唆する文言**〔撤去年代の特定は本頁からはできず断定しない〕。③高松一丁目公園予定地（高松1丁目・[GOV-518](GOV-518.md)インクルーシブ遊具設置予定）と同じ高松1丁目内の土地再利用の並行例〔両者の位置関係は現地未確認〕。
- **制限・未解決**: 千川中学校のプールの廃止・撤去年次、跡地の面積・区画数・会員数、DAIKENとの協定の公募・採択年次・補助額は本文に未記載〔行政側一次資料（協定書・採択一覧）の確認と、千川中学校改修の進捗（GOV-518「改修中」文言のその後）が次課題〕。
