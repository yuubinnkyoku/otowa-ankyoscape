# [GOV-179] 特別都市計画委員会 第7号 — 小字「北谷端」の行政記録

- **書誌〔確認〕**: 特別都市計画委員会『議事速記錄』第7号（土地区画整理関係の路線決定・変更を収録）。NDL次世代デジタルライブラリー [book/1225165](https://lab.ndl.go.jp/dl/book/1225165)。OCRテキストで確認。**地番・文言はOCR由来で要照合。**
- 「字北谷端」の路線記録〔確認・repo初出〕: 区画整理路線の区域表示に「**板橋町大字瀧野川字北谷端 二千三百七十九番地地先ヨリ同二千五百五十九番地ノ三地先ヲ右折シ 大字金井窪字東前百二十六番地地先、同百二十三番地地先ヲ經テ同百十四番地地先ニ至ルノ路線**」（第20号路線）＝**滝野川に小字「北谷端」（地番2379〜2559付近）が存在した**旨の大正〜昭和初期の行政記録。前後の路線群（西巣鴨町大字池袋字西山・下板橋字平尾裏→金井窪字東前・巣鴨一丁目→駒込上富士前町→駒込染井）は谷端川流域の区画整理路線網をなす。
- **位置づけ〔観察〕**: 「谷端」が滝野川の小字として公的文書に現れる記録の追加（[BLOG-233](../blogs/BLOG-233.md)の谷端川橋列・[BOOK-112](../books/BOOK-112.md)滝野川町誌の「南北谷端」と対をなす「北谷端」）。谷端川の川名起源（谷端の窪地地名）を地番レベルで裏付ける一資料。
