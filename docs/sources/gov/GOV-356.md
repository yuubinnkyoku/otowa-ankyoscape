# [GOV-356] 検使一件 [2] — 湯島大小炮裂作場跡の御鉄砲製造所附町屋化の実務

- **書誌〔確認〕**: 『検使一件』[2]（慶応期の検使・地所請取の一件綴の第2冊）。NDL次世代デジタルライブラリー [book/2548277](https://lab.ndl.go.jp/dl/book/2548277)。**引用文言はすべてOCR由来で要原文照合**。
- **湯島大小炮裂作場跡の鉄砲製造所附町屋敷化の仰渡〔確認・repo初出の実務文言〕**: 「**御作事奉行衆池田播磨守 湯嶋大小炮裂作場跡也 此度御鉄炮製造所附町屋敷ニ被成置候旨 豊後守殿伊豆守殿被仰渡候間 地所請取渡日限等之儀は追而可及御打合候得共 右場所取調候に付而は坪改地先持場等之絵図御差越有之候様致度**」（丑閏五月＝慶応元閏5年）〔**①湯島の大小炮裂作場（大砲・小砲の鋳造所）の跡地が「御鉄砲製造所附町屋敷」とされたこと、②仰渡は豊後守殿・伊豆守殿（老中候補・要照合）、受けて地所の坪改・絵図の差越を取扱うのは御作事奉行衆池田播磨守であること**〕。同冊の後続文書に「**湯嶋大小炮裂川場(＝作場候補)跡 新開町屋御取建ニ付 異変并道造持場分之儀**」（辰五月）＝**跡地の新規町屋取建と道造の持場（負担区分）の実務**、「**右地蔵之内掛紙朱引六厘学問所火除囲込幷同所附新規色幅五間北通道幅も五間**」「**学問所囲込地之儀に付申上候書付 井上信濃守 湯島大小炮裂候場跡御鉄砲裂造所附町屋敷ニ可相成地面内此度学問所小除地ニ囲込之儀 林大学頭来両人申上候通 火除地ニ可仕尤陸軍奉行並町奉行可談旨被仰儀**」〔**跡地の町屋敷予定地の一部が学問所（昌平黌）の火除地として囲込まれたこと＝学問所（林大学頭）・陸軍奉行並・町奉行・御作事奉行の4者による跡地再編の実務**（昌平黌の火除地拡張＝湯島の神田川上流側の土地再編。囲込年代の下限＝慶応元〜4年）。
- **位置づけ〔観察〕**: [GOV-355](GOV-355.md)（関口水道町の増用地）と対になる湯島側の炮製作場跡地の記録。幕末の鉄砲製造所の設置（[GOV-326](GOV-326.md)の元治元年の関口水車塲の仕法替・湯島鑄立塲の文言）から、跡地の町屋化・学問所火除囲込・新規道造までの再編が、神田川上流の湯島〜本郷桜馬場周辺で一斉に進んだ実務の記録。「御鉄砲製造所附町屋敷」＝製造所に付属する町屋敷という土地区分の語もrepo初出候補。
- **関連する神田川端の文言〔確認〕**: [GOV-357](GOV-357.md)（桜馬場空地の拝借願）の前段として、同冊の文書群が「神田川端往還学問所境二武家組合辻番所有之新規道式ニ差除」構造（湯島の神田川端往還と学問所の境の再編）を含む。
