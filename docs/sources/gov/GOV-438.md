# [GOV-438] 南撰要類集[79]橋之部 — 寛政3年の本橋掛替群と江戸川橋の渡銭停止

- **書誌〔確認〕**: 『南撰要類集』[79]（第二十六ノ下 橋之部・寛政2〜3年〔1790-1791〕頃の橋の書付群）。NDL次世代デジタルライブラリー [book/2550488](https://lab.ndl.go.jp/dl/book/2550488)。**引用はすべてOCR由来で文言は要原文照合。**
- **大塚坂下⇔青柳町橋の本橋掛直の積書付（寛政3年3月10日・権同四五郎左衛門ら）〔確認・repo初出〕**: 「**大塚坂下青柳町橋長九尺但上下左右角柄共一金四十九両余本橋掛ケ直御入用**」＋「**五ケ年以前午年出水之節橋台石垣崩〔落〕橋巾半分程流失…流失残之分先請負人之節取締仕候処悉打損往来危…此度橋台石垣築直行桁塀敷板男柱地覆拾頭構ニ而不残新木を以掛直**」〔**①長九尺の小橋の本橋掛直（「上下左右角柄共」の構造語はOCR崩れ注意）、②天明6丙午（1786）出水（寛政3亥1791から「五ケ年以前午年」＝1786に整合）で橋台石垣崩落・橋巾半分流失→流れ残りを先請負人が応急接続→それも悉く打損で往来危険→橋台石垣・行桁・塀・敷板・男柱・地覆を新木で全面掛替、という被災から6年目の復旧の過程、③積書の内訳＝積金37両3分＋永50文・**先請負人落札高59両3分との差引21両3分余**・紙11両・鉄物代・鳶人足賃等＝入札高を下回る積書の構造**＝天明6出水の復旧事業の1791年側の決算的記録**。**長九尺**は[GAZ-013](../gazetteers/GAZ-013.md)の**地震橋（東青柳町・長9尺幅2間半・町方御掛かり）・松屋橋（長9尺）と一致するが、本橋は「橋定請負人（御入用）橋」で地震橋は町方御掛かり＝**両者の同一比定はせず対校課題として保留記録**（[GOV-437](GOV-437.md)の寛政2本普請（材木33両3分）との関係（同一橋の同一普請の過程か別橋か）も原照合まで保留）**。
- **九丁目橋（関口水道町⇔音羽九町目）の掛替史〔確認・repo初出の層群〕**: 寛政3年5月の本所深川の大破橋群の伺書内に——「**壱万羽町〔二百羽町OCR崩れ候補〕九丁目長四尺〔?崩れ候補〕横三間…関口水道町ゟ…音羽町九町目右横三間本橋掛替一金五十壱両三分永百拾七文余…十ケ年以前天明二当年（1782）掛替其後度々御修復…去戌年（寛政2）八月中取繮…殊に度々御成之節御渡紙〔御渡敷候補〕有之候場所**」〔**①九丁目橋が天明2壬寅（1782）に掛替があり（「十ケ年以前」は数え方のずれが残る文言候補）、寛政2年8月に取繕いを経て、寛政3年に横3間・51両3分+永117文余で本橋掛替されたこと、②「度々御成之節御渡敷有之候場所」＝殿様（将軍家か御三卿かは本文言では不詳）御成の折に渡河点（御渡敷＝経路指定・「渡紙」は渡敷のOCR候補）として繰り返し使われた場所であることを修復理由に挙げた文言候補**＝**九丁目橋の1782・1790・1791の3層＋御成の渡河点の指定の文言候補**。③御成の定型帰路の「音羽町九町目橋御渡」は[GOV-349](GOV-349.md)（安永2年以降10数回）で既出＝1791年の伺書は「度々御成之節御渡敷」の18世紀後半側の初の橋側文言候補。対校＝宝暦10年修理（[BOOK-129](../books/BOOK-129.md)）・町方書上の「小日向水道町持ち・幅2間長3間」（[GAZ-035](../gazetteers/GAZ-035.md)）・1845年御入用橋リストの「小日向水道町ゟ二百羽町九町目え渡橋 里俗九町目橋」([GOV-220](GOV-220.md))＝横3間の寸法は一貫する方向。「壱万羽町／二百羽町」の町名はOCR崩れで要照合〕。
- **江戸川橋の渡銭停止（寛政2戌年4月・池田筑後守・久世丹後守宛書付）〔確認・repo初出〕**: 「**江戸川橋之義八ケ年以前御年出水之節流失仕其節定請負人とも方にて仮橋仕立渡銭取立往来為仕候処此度定請負人御取敢に相成筑後守殿川掛取扱被仰付候ニ付渡銭は相止飯橋は其侭相用**」〔**①江戸川橋（関口水道町・[GOV-220](GOV-220.md)の1845年御入用橋・[BOOK-131](../books/BOOK-131.md)の名残橋）が「八ケ年以前」の出水（寛政2戌1790から遡って1782/83〔天明2-3〕出水候補）で流失したこと、②流失後は橋定請負人が仮橋を仕立て**渡銭を取って往来**を維持したこと（約8年間）、③寛政2年（1790）4月に定請負（=御取敢）に復帰したことに伴い**渡銭を停止し、仮橋（飯橋）はそのまま使用**したこと**＝**江戸川橋の流失→仮橋渡銭→定請負復帰・渡銭廃止という管理史の新層（江戸川橋の渡銭の一次文言はrepo初出）**。④同書付群に仮橋破損の折杭・桁・敷板の取繕書付と「**金拾両以上之分は積帳相添相伺拾両以下之分は…御届申上置**」の被災管理手続の整備文言（10両超は伺・以下は届）＝[GOV-439](GOV-439.md)の文化元年了橋の実務と通じる閾値運用の先行例。
- **芝金杉橋の本橋掛替（寛政3亥5月）〔確認〕**: 「**芝金杉橋長拾壱間半横四間六寸一金三百弐十弐両壱分永弐十九文余本橋掛替〔并前後桟橋入用共〕…十四ケ年以来安永七戌年（1778）掛替其後度々御修復…去戌年中両度取繕**」＋日数の覚「廿二日半照廿六日半雨廿五日〔?〕」〔**①長11間半×幅4間6寸・322両1分+永29文余（前後桟橋の入用を含む）の1791年本橋掛替、②「十四ケ年以前」＝安永7戊戌（1778）掛替（数え方のずれ1年は文言候補）、③寛政2年中に両度の取繕い**＝**[GOV-437](GOV-437.md)の宝暦11巳年（1761）普請候補→1778→1791の金杉橋の3時点＋天候日数の覚＝芝金杉橋（古川＝澤?の系の橋・[GOV-238](GOV-238.md)の定請負橋数書付の「金杉橋」と同列かは江戸市中の「金杉」町名の複数性に注意）の通時点系列**。日数文言の「照」は「晴」のOCR候補〕。
- **参考記録（対象外の橋の制度記事）〔観察〕**: 同冊に**柳原新シ橋の船渡の例書（享保15〜寛政元の例書に基づく運用）**と**米沢町難波橋の模様替（石垣の築出により橋長12間→5間2尺に短縮）**の書付が見える＝橋の代替手段（船渡）と河川改修に連動する橋の縮小の制度先例の参考。（本repo4河川の直接史料ではないが、江戸川橋の渡銭停止と船渡・仮橋の代替手段の制度文脈の対照材料として記録する。）

## 制限・未解決

- ①「壱万羽町」「長四尺横三間」の寸法はOCR崩れが濃厚（九丁目橋の形態の正確な寸法は要照合。「横三間」のみ一貫性がある）。②「御渡紙」は「御渡敷」の文言候補で、御成の主体・年次の特定は不可。③江戸川橋の「八ケ年以前御年出水」の出水の年（1782/83候補）と[BOOK-130](../books/BOOK-130.md)の天明期の出水の対応は断定しない。④大塚坂下⇔青柳町橋と[GOV-437](GOV-437.md)の大塚坂下⇔東青柳町橋の同一性・[GAZ-013](../gazetteers/GAZ-013.md)の地震橋・松屋橋との比定はすべて保留。⑤「渡銭」の金額・徴収方法の文言は本冊に見えない。⑥芝金杉橋の「金杉橋」の比定（芝金杉橋と宮益橋の間の川=古川〔澤〕渡りか）は原文照合まで確定しない。
