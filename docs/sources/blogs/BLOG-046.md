# [BLOG-046] らんまる「水窪川跡を歩く 2/2」

- **直接確認（2026-11-11、open_url・本文全文）**：2015年12月の水窪川下流側（豊島岡墓地〜江戸川橋）踏査記録。1/2も存在（本稿では下流側の記録のみ直接確認）。2026-10-23横断調査ノートではURLのみ把握で個別書誌化されていなかった。
- **製糸業の記述〔伝聞の二次叙述〕**：**「かつてこの付近の音羽谷と呼ばれる地域では、この水窪川と前日にあるいた弦巻川の水を利用した製糸業が盛んだった」**とする。※**「製糸」は repo 全体で初出の叙述**（search_code で0件を確認）。原典不明の伝聞で、音羽谷の産業史（紙漉き以外の水利用）の手掛かり候補として記録する。**本伝聞で製糸業の実在・規模・時期を主張しない**。文京区史等での裏付け確認を次回以降の課題とする。
- **今宮橋の川幅〔観察〕**：今宮神社参道手前の道路に埋まる石橋（今宮橋）について、**「この幅1.5mがそのまま水窪川の川幅であった」**とする（案内板等の出典は明記なし）。※既知の今宮橋の記録（[水窪川.md](../../水窪川.md)）に対する**川幅1.5mという数値の追加候補**。出典が不明のため要照合。
- **東青柳町崖下の湧水〔観察〕**：お茶の水女子大西門の先で**左岸が高い崖になり、壁面に「結構な湧水」が複数箇所で見られた**とする。※既知の2010〜2011年の同地点湧水記録（暗渠ハンター・2026-10-20ノート）と独立の別時点（2015年）の観察として、湧水の継続性の記録を増やす。
- **その他〔観察〕**：豊島岡墓地の高い塀、不忍通り富士見坂での流路寸断、護岸状の壁、八幡坂・鼠坂との高低差など。既知の地形記述の補強にとどまる。
