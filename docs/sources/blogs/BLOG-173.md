# [BLOG-173] 水徒然「水窪川に沿って街歩き。」

- **直接確認（2026-11-13、open_url・本文全文）**: [BLOG-065](BLOG-065.md)・[BLOG-066](BLOG-066.md)・[BLOG-159](BLOG-159.md)などの水徒然（onnbubatta）による2013年9月5日の水窪川踏査記〔筆者の水窪川カテゴリ記事でrepo未収録のもの〕。カテゴリに「水窪川」「神田川支流」を設定。
- **碑広場のタイル意匠〔repo初出候補・観察〕**: 水窪川の碑のある広場（富士山広場）で「**実際のタイルは紫陽花のように綺麗で、散策者の目を惹きます。水が流れ出るように敷かれたタイル**」〔碑周辺の舗装に水の流れを表した意匠があるという2013年観察＝[BLOG-171](BLOG-171.md)（2020年）の「川の流れのように設計」観察と並ぶ独立記録〕。
- **流域の井戸群の2013年現況〔観察〕**: 「**至る所に様々な井戸があり、水と親しむ暮らしが垣間見えます**」として、覆屋付き井戸・手洗い場・受け洗面器・柄杓付き・給湯器付き井戸・洗濯機の排水ホースが延びる井戸・路面より高い位置のアパートの水鉢などを記録〔[BLOG-052](BLOG-052.md)（2010年）に続ぐ水窪川沿い井戸密度の2013年時点の独立観察〕。「井戸数えたくなる」。
- **吹上稲荷の池〔repo初出候補・観察〕**: 「**『吹上稲荷』に小さいけれど池がありました。少々澱んでいます**」〔水窪川沿いの吹上稲荷の池の2013年現況観察〕。
- **鏡ヶ池会館〔repo初出候補・観察〕**: 「**『鏡ヶ池会館』と素敵な名称の看板を掲げた歴史ある建物**」〔水窪川流域の「鏡ヶ池」の名を含む施設名。水窪川沿いに鏡ヶ池という水面があった可能性を示唆する材料として**仮説の段階で記録**（本文は池の由来に言及せず）〕。
- **その他〔観察〕**: 大塚先儒墓所入口の敷石・「地境」の標・獅子2体・不忍通りに流れ下る前の井戸・新大塚駅そばの屋上広告（大塚3丁目交差点の「カメラ」広告の記憶）・今宮神社付近の湧き水が河口に近いクライマックスゾーンという表現〔[BLOG-052](BLOG-052.md)・[BLOG-128](BLOG-128.md)の今宮橋・湧水系記録と整合〕。
- **制限〔未解決〕**: 鏡ヶ池会館の所在地の特定と「鏡ヶ池」の水窪川との関係（現地確認・他史料）。吹上稲荷の池の現在の存否。同筆者の水窪川カテゴリ他記事（前後記事「練馬駅前の股間若衆ほか」「日光・日の…」）の未収録分。
