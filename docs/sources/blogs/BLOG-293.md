# [BLOG-293] 建通新聞「第２期エリアの工事、2026年度に本格スタート」〔弦巻川・谷端川流域の下水道枝線再構築の2026年度進行座標〕

- **書誌〔確認: 本文全文・2026-11-23取得〕**: 建通新聞電子版（kentsu digital）・東京。**公開2026年2月26日12:47・【2026/02/27 東京版に掲載】**。 https://digital.kentsu.co.jp/articles/artcl_rglr/01KHJR1ZHXTBZKBA1TH97X26EN 。図版＝「枝線再構築エリアと平均経過年数。**東京都下水道事業経営計画2026（案）より**」〔出典図の文言〕。
- **本文の文言〔確認: 本文・文言〕**: 「東京都下水道局は区部下水道の枝線再構築で、**2026年度に第2期エリアの工事を本格的にスタートさせる。30年度までの5年間に、第1期エリアの未実施分と合わせて面積ベースで3,400haの枝線を再構築する計画**」「区部下水道の枝線再構築は**整備年代から三つのエリアに分けて**実施する。道路交通や生活への影響を最小限に抑えるため、**道路を掘らずに管渠の内側からリニューアルする内面被覆工法**を活用している」。
- **第1期・第2期エリアの文言〔確認: 本文・文言〕**: 「現在、**整備年代が最も古い芝浦・三河島・砂町・小台の都心4処理区・約1万6,300ha（枝線延長約4,600km）を対象とした第1期エリア**で進めていて、**25年度までに面積ベースで約8割の工事を終えた。29年度の完了を目指している**」「これに続く**第2期エリアは、区部の西側に当たる新河岸・落合・森ケ崎の3処理区・約2万7,700ha（枝線延長約7,300km）が対象。北部、西部第一、西部第二、南部の4下水道事務所が所管**」。
- **北部下水道事務所（弦巻川流域）の文言〔確認: 本文・文言〕**: 「北部は所管区域の調査設計を2件委託。これらを踏まえ**『豊島区目白四丁目、西池袋三丁目付近』などの工事に向けて8件の実施設計を進めてきた**」〔**北部＝雑司ヶ谷幹線・第2雑司ヶ谷幹線（弦巻川系）の管内で、目白四丁目・西池袋三丁目は弦巻川流域の庁区内実施設計の座標**〕。比較対象として、西部第一＝「中野区若宮二、三丁目付近」など10件、西部第二＝「板橋区蓮沼町、清水町付近」など3件、南部＝「世田谷区下馬三、四丁目付近」など3件〔計24件+調査設計9件の実勢〕。
- **試行工事の文言〔確認: 本文・文言〕**: 「第1期エリアは枝線を敷設した道路の幅員が広く、沿道にはオフィスビルなどが立ち並んでいる。これに対し**第2期エリアは道路の幅員が比較的狭く、沿道の多くを住宅地が占めるなど施工条件が異なる。このため24年度に試行工事を2件発注した。具体的には三木田興業が『豊島区長崎五、六丁目付近再構築工事』（工期12月まで）、イチグミが『豊島区南長崎三、四丁目付近再構築工事』（工期27年1月まで）を担当**」〔**長崎・南長崎＝谷端川上流域（谷端川上幹線系）の枝線で、第2期エリアの最初の実働2件がともに豊島区＝弦巻川・谷端川流域で占められた**〕。
- **意義〔観察〕**: ①**弦巻川・谷端川流域の下水道枝線（谷端川上幹線・雑司ヶ谷幹線系）の更新が2026年度に本格化する**ことの、専門紙（土木・建設業界紙）経由の進行記録＝[BLOG-289](BLOG-289.md)（細川正博・千川増強幹線枝線）と同じ「内面被覆工法による枝線再構築」の系列だが、**第1期（三河島など）を経て第2期の管内が豊島区側に到達した**点が新規〔千川・弦巻川・谷端川の幹線と枝線の降雨時対応の土台の更新時期の座標〕。②**事業進行の方向＝第2期エリア本格化時に、まず谷端川上流域（長崎・南長崎）で試行し、次いで弦巻川流域（目白・西池袋）に進む**段取りが読める〔ただし本文は流域名（弦巻川・谷端川）に言及しておらず、幹線系との対応付けは本repoの見立て＝推定〕。
- **制限・未解決**: ①「枝線再構築エリアと平均経過年数」図＝**下水道事業経営計画2026（案）由来**〔本計画書そのものはrepo未収録で、目白四丁目・西池袋三丁目の枝線がどの幹線系か（雑司ヶ谷幹線・第2雑司ヶ谷幹線・弦巻川系幹線のどれに接続するか）は本文に文言なし〕。②試行2件の工期文言（「12月まで」「27年1月まで」）＝令和何年度の12月・1月かの明示が本文になし〔文脈上24年度発注なのでR6.12〜R7.1完と読めるが断定しない〕。③財源・事業費の文言なし。
