# [BLOG-221] 読んで♪観て♪歩く「秋の水窪川跡を歩く」2記事

- **資料〔確認〕**：kerakuten「[秋の水窪川跡を歩く](https://ameblo.jp/kak-dela/entry-12945958998.html)」（2025年11月15日公開）と「[秋の水窪川跡を歩く（つづき）](https://ameblo.jp/kak-dela/entry-12946876952.html)」（2025年11月18日付の月別記事一覧に掲載）。**2025年11月15日の「大塚物語る」ツアー参加者による現地記録**で、開催情報・順路は主催者の[ORG-033](../org/ORG-033.md)と照合できる。
- **暗渠上の街路〔観察〕**：筆者は、東池袋の水窪川跡に沿って、道路・緑道だけでなく住宅の隙間のような細い路地が連続し、曲折・高低差が残ると記す。暗渠の痕跡候補として**大谷石の護岸・マンホール**も挙げる。これは2025年参加者の現況観察であり、各構造物が水窪川の護岸・旧河道に由来するかは別途確認が必要。
- **辻広場・防災設備〔観察〕**：東池袋に**11か所**ある辻広場を、各40～100㎡程度の小規模広場と紹介し、貯水槽・消火栓が備わると記す。**富士山広場に「水窪川の碑」**、ポポー広場に災害用の手押し井戸があるという具体的な観察は、施設位置・現況を補う。辻広場11か所という数は[Natrium.jpの水窪川記事](https://natrium.jp/canal_lot/kanda/mizukubo/index.html)にも記載があり、本記事は別の参加者による再観察として扱う。
- **プラウドタワー東池袋敷地下の道筋〔仮説〕**：筆者は、現在のプラウドタワー東池袋による水路敷の途切れ・迂回が不自然として、**約40年前の地図**を参照し、現タワー敷地下に川跡らしい道が延びていたと読む。記事の地図画像は掲載されるが、**地図の正式名称・作成年・縮尺・所蔵元は記載されていない**。したがって、ここでは「1980年代半ば頃の地図を用いた筆者の読図仮説」として記録し、旧河道の確認・確定には使わない。原図の特定と、開発前の住宅地図・道路台帳・土地利用図との照合が必要。
- **区界との関係〔観察〕**：豊島区・文京区の区界と水窪川跡が重なる区間は、筆者の予想より少なかったという。区界と旧河道を同一視しないための現地観察として記録するが、境界線の全区間を測量比較した結果ではない。
- **暗渠化年の扱い〔未確認・注意〕**：筆者は新しいマンホール蓋にある「33」を**1933（昭和8）年の暗渠化年**と解釈する。しかし蓋の番号の意味・設置時期を示す銘板や工事記録は確認されていない。豊島区の1999年資料は水窪川が「昭和初期から戦後にかけて下水化」と幅をもたせて記す（[GOV-001](../gov/GOV-001.md)）。**「33」だけから1933年に全線または当該区間が暗渠化したと断定しない。**
- **戦災・区画整理との関係〔仮説・未検証〕**：筆者は周辺の空襲被害が比較的小さく、立退き・区画整理が進まなかったことが細街路の残存に関係したと説明する。参照した戦災焼失区域図の図名・図郭・範囲は本文から特定できず、因果関係も未検証。現段階では筆者の説明としてのみ記録する。
