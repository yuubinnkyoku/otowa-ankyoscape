# [BLOG-217] peepooblue「行け！いけ！探訪！！東京の池」— 粟島神社弁天池・谷端川親水公園（2009年観察）

- **取得状況〔確認〕**: 池を巡る写真ブログ「行け！いけ！探訪！！東京の池」（peepooblue、ココログ）の2009-10-27記事（粟島神社の弁天池）と2009-11-04記事（谷端川親水公園の池）。**第42回（[BLOG-155](BLOG-155.md)系調査）では「本文取得不可」としていたが、今回curl+UAで本文が直接取得できた**（サイト側の応答状況の変化）。
- **粟島神社の弁天池〔確認: 2009年10月の現地観察記事〕**: 所在地は豊島区要町2-14-4。有楽町線・副都心線の千川駅近く。**「地元の人々が湧水の池のほとりに水神を祀ったのが始まりらしく、雨乞いの神事も行われていた」**、**「現在は湧水も失われ、人工的に給水しているようです」**と、2009年時点で湧水が失われて人工給水になっていることを**観察として**記す。境内の池には石橋がかかり鯉・亀がいた。〔[GOV-034](../gov/GOV-034.md)・[BLOG-155](BLOG-155.md)系の粟島神社＝谷端川水源説の補強。**「2009年時点で人工給水」という湧水枯渇の時点観察はrepo初出**（枯渇年代の特定資料ではない）〕
- **谷端川の流路記述〔確認〕**: 上記記事は「**この池（弁天池）は神田川の支流・小石川の上流にあたる谷端川の水源のひとつ**」「**谷端川はその後、石神井川に接続するように流路が変更され、現在は完全に暗渠化**」と明記。親水公園記事（2009-11-04）では旧流路を具体的に記す: 弁天池を水源とする谷端川は南へ流れ、**西武池袋線の椎名町駅付近で線路の南側に達し東に折れ、山手通りの東側で北上に転じ、東武東上線の下板橋駅・埼京線の板橋駅を経て南東へ向きを変え、大塚駅・大塚三業通り・小石川を経て神田川に合流**、その後**板橋駅付近から北流して石神井川に接続する流路に変更**。川跡は大部分が道路化、**山手通りに並行する区間が緑道**。〔[BLOG-101](BLOG-101.md)・[MAP-160](../maps/MAP-160.md)系の「旧流路＝小石川経由で神田川へ／現流路＝石神井川接続」の2段階流路変更説の一般記事側からの裏付け。観察・知識の混在するブログ記事であり一次史料ではない〕
- **谷端川親水公園の池〔確認: 2009年11月の現地観察〕**: 所在地は豊島区池袋3-2-5。山手通りと要町通りの交差点の北東側。**「壁面から水が落ちる滝があるほか、スイレンや花菖蒲などが植えられた池があり、金魚も泳いでいます」**と2009年時点の親水公園の状況を記録〔[GOV-097](../gov/GOV-097.md)近傍の谷端川緑道（要町〜池袋）の2009年現況の観察記録。親水公園の整備時期・水源（ recycled水か湧水か）には触れず、特定しない〕
