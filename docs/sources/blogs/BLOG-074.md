# [BLOG-074] 続々・池袋地名の由来「丸池」（高田雲雀）

- **直接確認（2026-11-11、open_url・本文全文）**：豊島区史 資料編3巻収録の「高田雲雀」の記述をめぐる考察。引用画像（adeac・NDL）はopen_url不可のため、引用文は同noteの書き下ろし転記に依存する。
- **高田雲雀（天明8年／1788）〔二次転記：豊島区史 資料編3巻（[adeac mp120030/tosimas3/483](https://adeac.jp/toshima-history/viewer/mp120030/tosimas3/483)）経由〕**：「**琵琶島、検校島 蓮光院のうしろ北西の方也。これより先、四五町に池ヶ谷あり、今は池のかたちのミあり**」（大野屋某、大田南畝増補）〔**「池ヶ谷」「琵琶島」「検校島」「蓮光院」いずれもrepo初出の語**。1788年時点で「池の形のみ」＝池が埋まり形だけになっていたと読める記述。**池ヶ谷＝丸池と仮定すれば、丸池が一時凋落していた時期の傍証**になる（仮説）〕
- **検校島の比定〔推定（note作者の仮説）〕**：大正末期の地図で「**字中谷戸見行島**」という字名が確認でき、これを検校島の候補とする。見行島から丸池までの距離が「四五町」（約500m）と符合。「島」は弦巻川に削られた舌状地、「検校」は琵琶法師の官名（＝琵琶島の比定候補）。〔仮説段階。字名「中谷戸見行島」の所在図葉の要確認〕
- **延宝期の入会〔二次転記：『御府内場末往還其外沿革図書』（[NDLデジタルコレクション pid/2587247/1/48](https://dl.ndl.go.jp/pid/2587247/1/48)）経由〕**：丸池周辺は**延宝（1673〜1681）の頃「池袋村」と「雑司ヶ谷村」の入会**だったとする。〔[GAZ-012](../gazetteers/GAZ-012.md)（同書の所在のみ登録）に収録される池袋村記事の内容初出。**丸池帰属問題（→雑司ヶ谷村）を遡る前史**として重要〕
- **note作者の仮説〔仮説〕**：①高田雲雀の「池」＝丸池。②天明8年頃池は形だけになっていた→③雑司ヶ谷村が恩恵を受けていたため「池の整備」を行った→④1814年（遊歴雑記）には三百坪余まで回復した、という復元筋。丸池は放置と整備を繰り返していた可能性、弦巻川周辺には丸池以外の消えた池があった可能性も指摘。
- **制限〔未解決〕**：全ての引用がnote経由の転記で、adeac・NDLの原本確認は未実施。池ヶ谷＝丸池・琵琶島＝検校島とも仮説。
