# [BLOG-220] y-ok.com（雄' Photo Page）「千川上水-1〜4」— 開渠部と千川上水公園の観察記録〔repo初出〕

- **取得状況〔確認〕**: 同サイト（[BLOG-219](BLOG-219.md)と同じ雄' Photo Page）の千川上水4回シリーズ（musashino/tamagawajosui/senkawajosui-1〜4.html）。**現行URLはContent-Length 0の空応答を返すため、Wayback Machineのid_付きURL（senkawajosui-1=2020-09-19・2=2020-09-14・3=2020-09-03・4=2020-08-31スナップショット）で本文全文を取得した**〔Wayback収蔵の存在自体が今回の特定。取得方法は各スナップショットにid_を付けたURL〕。
- **境水衛所〔repo初出の文言〕**: 千川上水-1で「玉川上水境橋の直ぐ下流、**32ヶ所置かれたと言う水衛所の一つ「境水衛所」が、現在も歴史遺産として保全されている。同時にここは現在の千川上水の分水口でもある**」と記す〔「境水衛所」の名称と玉川上水の水衛所32か所の一つという位置づけの文言はrepo初出。境橋（取水口）の現況は[GOV-084](../gov/GOV-084.md)・[BLOG-143](BLOG-143.md)系で既出〕。
- **旧分水口〔確認・既出説の整合〕**: 「現在の千川上水は境水衛所で玉川上水から分水されているが、元々はその500m程上流、**曙橋の上流側に分水口が有った**。ただこの分水口も**1871（明治4）年設置**のもので何回か付け替えられてきているそうだ」〔[BLOG-113](BLOG-113.md)（武蔵学園記念室年表「明治4年境橋上流分水口変更」）と整合する一般記事側の二次記録。伝聞形式〕。
- **清流復活〔確認・既出〕**: 1971年（昭和46）取水停止→1989年（平成元年）から高度処理再生水日量2000㎥・開渠部約5km、伊勢橋（関町一丁目交差点）で全量汲み上げられ善福寺川へ放水〔[GOV-084](../gov/GOV-084.md)・[BLOG-142](BLOG-142.md)系と整合。上井草開渠35mの水量内訳（善福寺導水7000トン/上井草3000トン）は記載なし〕。
- **関前五丁目交差点〔観察〕**: 「チョットした緑地となっていて千川上水は一時暗渠となる」。境橋交差点で都道7号線が2本に分岐し挟まれた三角形の緑地も観察〔中流域の開渠・暗渠の継ぎ目の観察記録〕。
- **武蔵野大学前〜電通研究所前〔観察〕**: 石橋供養塔・庚申塔のそばから上水の縁に降り、**約440mの親水的遊歩道**が続く。葭窪橋（[BLOG-097](BLOG-097.md)と同地点）・武蔵野市立千川小学校（レンガ造りの外観）・電通研究所前交差点で一時暗渠〔観察。石橋供養塔の碑名・建立年は本文に記載なし、同定はしていない〕。
- **関町一丁目交差点=六ヶ村分水取水口跡〔確認・既出〕**: 伊勢橋地点が「かって、千川上水からの六ヶ村分水取水口で」あったことを記す〔六ヶ村分水（多摩郡六か村用水）は[GOV-068](../gov/GOV-068.md)で既出〕。伊勢橋から下流は千川通りとして暗渠が続き「千川上水緑地」として200mほど整備、**伊勢橋で汲み上げられた後の暗渠には水は流れていない**と観察。
- **上井草の開渠〔観察・無水時点記録〕**: 「西武新宿線上井草駅の西250メートル程、線路をくぐって両側に、僅かに開渠として姿を現す。**しかし流れている水は無い**」〔**2020年8〜9月（スナップショット撮影時点）に上井草開渠が無水だったことの観察記録**＝[BLOG-159](BLOG-159.md)（2023年2月〜6月の3回無水観察）の前史となる無水時点データ。年次はスナップショット日付に基づく推定で、原ページの執筆時点そのものではない点に注意〕。路傍の庚申塔・観音供養塔と千川上水案内板（「案内板に有った、当時の写真」）の存在も観察〔[BLOG-143](BLOG-143.md)のエンガ堀起点読図周辺〕。
- **千川上水公園（千川上水調節池跡）〔観察・既出史料の整合〕**: 豊島区西巣鴨2-39-5。区の説明（筆者による豊島区ホームページの要約）として、旧千川上水水路敷地を市民が旧東京市へ寄付した**明治13年**にさかのぼる区最古の公園・**昭和15年**に公園として開放・地下に分水堰と沈殿池が残る、と記す〔[GOV-053](../gov/GOV-053.md)（調節池跡説明板・1865年反射炉分水）・[GOV-065](../gov/GOV-065.md)（沈殿池で水量調節）と整合。**公園内に同じものが2基ある六義園方面への送水に使われたバルブ（巻揚機）の2020年時点での現存と撮影**は、[BLOG-095](BLOG-095.md)（バルブ現存・沈殿池1973年造替え）の後年側の観察記録〕。「都道305からの千川上水公園。写真左側、50メートル弱に掘割交差点が有る」も位置関係の観察〔掘割交差点=交差点名の堀割由来はREADME既出〕。
