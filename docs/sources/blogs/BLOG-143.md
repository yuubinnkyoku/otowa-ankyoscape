# [BLOG-143] miwa3k「千川上水を歩く その１」（境橋〜上鷺宮）

- **書誌〔確認〕**: はてなブログ「散歩の途中」（miwa3k）の千川上水歩きシリーズ前半。投稿年は本文抽出範囲では確認できず未詳（同ブログは2016年以降稼働・2026年時点で存続）。**同筆者の既収録記事（[BLOG-070](BLOG-070.md) 小石川から谷端川）と同じシリーズ性が確認でき、千川上水全線を扱う未収録2回のうち前半**。直接openで本文全取得。
- **〔確認・引用〕 分水口の元樋**: 境橋下流の現在の分水口について「建設当時は**「3尺5寸四方の水門をもって」分水**していたとのこと」〔[BLOG-113](BLOG-113.md)（武蔵学園記念室年表）の元樋寸法変遷（1732/1737/1773）と対応する引用文言。筆者は出所を明示せず〕。
- **〔観察・repo初出〕 品川用水の分水口**: 千川上水分水口の**玉川上水すぐ下流側には別の用水路・品川用水の分水口があった**〔「千川上水」文脈での品川用水言及はrepo初出。玉川上水沿いの既知情報との整合確認は今後〕。
- **〔確認・repo初出〕 文字庚申塔（西東京市指定文化財第20号）**: 武蔵野大学前交差点付近。解説板全文を採録：**天明4年（1784）建立・上保谷新田の入口・新田村全戸による造立（「願主新田中」）・他の庚申塔に例を見ない「五穀成就」の刻銘・十万に通じる道しるべ・昭和61年3月西東京市教委**。解説は**天明3年（浅間山噴火・飢饉）を背景に「村の入口から飢饉が侵入しないように」建てたとの解釈**を示す〔千川上水沿いの石塔群（[PAP-027](../papers/PAP-027.md)の19ヶ所一覧）の補遺候補。原位置は現在とほぼ同じで東向き〕。
- **〔確認・補強〕 井口橋の石橋供養塔**: 五日市街道と千川上水の交点（武蔵野市側）。武蔵野市教委平成14年10月の解説板全文を採録：**天保12年（1841）8月・関前村々民の総意＋近隣諸村の助成で木橋→石橋に架替・本市内で現存する唯一のこの種の供養塔**。隣接の庚申塔は天保11年2月で願主等詳細不明〔[PAP-027](../papers/PAP-027.md)（石橋供養塔・1841・井口橋）の内容と一致し、「市内唯一」の文言を追加する独立二次記録〕。
- **〔観察〕 更新橋の庚申塔**: 関町南4丁目・締町3丁目境界。祠内の庚申塔（青面金剛像・鬼・三猿）を「更新橋の庚申塔」と解説。「**庚申橋」表記のはずが「更新橋」に変化したのではないか**という筆者推定〔[BLOG-094](BLOG-094.md)（更新橋）と [BLOG-103](BLOG-103.md)（千川親水公園手前の庚申橋残存・同名異橋候補）の間の表記問題に新たな視点。推定として記録〕。
- **〔確認・裏付け〕 上石神井千川児童遊園の水車解説板**: 「**最盛期にはこの流域だけで10基以上の水車**」「**この児童遊園のそばには昭和40年頃まで水車が回っており、区内でも一番最後まで上水を利用し粉が碾かれていた**」〔田中水車（観音山水車）廃業年次について [GOV-092](../gov/GOV-092.md)「昭和40年頃まで」と同文言の**出所（児童遊園解説板）が明示された独立記録**。「昭和40年頃」系の第3〜4データポイント]。
