# [BLOG-270] まち歩きで趣味探しと図書館めぐりを自転車で「玉川上水からの小金井分水と元禄年間に築かれた山王窪の築樋」〔repo初出・玉川上水〜築樋〜陸軍跡地を自転車で現地踏査した記事〕

## 内容〔確認: 本文全文・2026-11-22取得〕

- **書誌〔確認〕**: ココログ（cocolog-nifty）のブログ「まち歩きで趣味探しと図書館めぐりを自転車で」（tosyokan-bicycle）。2022-01-16記事。カテゴリ「土木」「08北多摩南部」。
- **玉川上水から小金井分水への流れ〔確認: 本文直接引用〕**:
  - 「**江戸時代の承応３年（１６５４）には玉川上水ができると、各村から分水の要望が出たといいます**」
  - 「**元禄年間（１６８８～１７０４）に幕府から許可され小金井分水が開通しました。八尺四方（２４センチ）の樋口で玉川上水から水を取り入れていたといいます**」＝**元禄年間の幕府許可という全体の時代規定＋八尺四方（24cm）の樋口**。
  - 「**明治３年（１８７０）から５年までの間に玉川上水は通船できるようにしたことがあるため、その支障となることから水の分水はここにある砂川用水からとなりました**」＝**明治3〜5年の通船→砂川用水への切替**（[BLOG-264](BLOG-264.md)No.24・No.26・[GOV-504](../gov/GOV-504.md)の「明治以後の切替」と同内容の独立記述）。
  - 「**因みに角には囲まれた水道施設らしきものがありますが、都水道局の貫井北五号水源です**」「**しばらく進むと道沿いに貫井北六号水源もありました。この辺りは水がないから用水を引いてきたのに、地下水が豊富があるというのも不思議な話です。深く井戸を掘る技術が進化したから**」＝**貫井北五号・六号水源の位置（小金井分水起点沿い）と、地下水技術で用水が不要になったという近代水利史の観察**。
- **山王窪築樋〔確認: 本文直接引用〕**:
  - 「**低い土地に土を盛り突き固めて土手を築き、その上に水路を通す土木工法である築樋となっており、ここは「山王窪の築樋」といいます**」
  - 「**当時、築樋は全長五十六間（１０２メートル）で一丈八尺（５．４メートル）あったと記録されています**」＝**山王窪築樋の規模＝全長56間（102m）・高さ1丈8尺（5.4m）「と記録されています」という出典付きの規模文言**。
  - 「**この山王窪の築樋は元禄９年（１６９６）に造られたものですから、江戸時代からの土木技術は素晴らしいものです**」＝**元禄9年（1696）造営説〔「造られたもの」との直記〕**。
  - 「**西側を見ると、下には仙川が流れています**」「**東側も住宅地の間を仙川が流れています。仙川はコンクリートで護岸工事されています**」＝仙川の現況観察。
- **陸軍技術研究所の石杭〔確認: 本文直接引用〕**:
  - 「**武蔵小金井駅に向かおうと道を南下して行くと、「陸軍技術研究所境界石杭」がありました。山王窪やその西の広い地域が公社住宅や公務員住宅、さらに新小金井街道の西は東京学芸大学と国有地や公有地になっています。広大な土地があったということですが、何かの跡地かと不思議に思っていたのですが、この研究所跡地だったと知りました**」＝**「陸軍技術研究所境界石杭」の現地実物確認〔観察〕＋広大な国有地化の経緯＝研究所跡地という説明**。

## repoとの関連〔観察〕

- ①**山王窪築樋1696年説＋56間・1丈8尺規模＝[BLOG-264](BLOG-264.md)（まろん通信1696年説）・[BLOG-269](BLOG-269.md)（tama-meguri・同一規模文言）と筆者系統の独立した複数一致**。「と記録されています」という言い方は一次史料（村誌等）の存在を示唆する。②**承応3年（1654）玉川上水→各村の分水要望→元禄年間幕府許可→小金井分水開通→八尺四方の樋口→明治3〜5年通船→砂川用水切替**という全体年表＝[GOV-510](../gov/GOV-510.md)の「承応3年掘削・各村分水」文言・[GOV-504](../gov/GOV-504.md)（貫井村誌：享保〜延享の分水文言群）と時系列で突き合わさる戦略的座標。③陸軍技術研究所の境界石杭＝[BLOG-264](BLOG-264.md)No.3「陸軍と記された石標」・No.1「昭和17年陸軍技術研究所で水路の向きが変えられた」と相互補強する**石造物の現地実存観察**。

## 意義〔観察〕

- 玉川上水→小金井分水→築樋→仙川→陸軍跡地という**水系と土地の歴史を1本の観察線でつないだ希少な現地記録**。特に「八尺四方（24cm）」の樋口という取水構造寸法と「56間・1丈8尺」の築樋規模は、[GOV-505](../gov/GOV-505.md)（梶家文書絵図の堰・掛樋）の寸法体系と対照できる数値資料。
