# [BLOG-136] 池袋ジャーナル「【池袋の地名の由来について】」

- **書誌〔確認：本文を直接取得〕**：ikebukuro-journal.com、2025年3月26日投稿。[本文](https://ikebukuro-journal.com/place-namei-old-map-ikebukuro/)。池袋西口の地域情報メディア。
- **史料所在情報〔確認：本文〕**：**立教大学公式サイトの古地図デジタルライブラリで『大東京最新明細地圖：隣接町村合併記念』（東亰日日新聞編纂、1932年12月）が公開されている**。谷端川・水窪川流域の字名の確認に使える〔repoでは未登録のデジタル公開情報。原図の水路描写の読図は未実施〕。
- **字名の解釈〔確認：本文〕**：
  - **蟹ヶ窪**：池袋東口の一帯から現在のサンシャインシティあたりまでの旧地名で、**美久仁小路も含まれる**。窪地が続いていた。美久仁小路から東池袋方面へ水窪川が流れていた〔BLOG-128・LOST-005の蟹ヶ窪解釈と整合。repoの蟹ヶ窪範囲解釈に「美久仁小路含む」を加える二次情報〕。
  - **水久保**：サンシャインシティ南側辺りの旧地名。**都電荒川線沿いの日出優良商店街も昔は「水久保商店街」と呼ばれていた**〔BLOG-128の古老聴取（水久保商店街通称）の別角度からの裏付け。「日出優良商店街の旧称」はrepo初出候補〕。
- **注意〔照合結果〕**：地名由来（池=梟の樹公園の池・ふくろう等）は諸説の紹介にとどまる二次記事。蟹ヶ窪・水久保の範囲は本記事の解釈であり、原図（立教大デジタルライブラリ）での直接確認までは「確認」とはしない。
