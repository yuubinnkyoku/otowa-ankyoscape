- **「昭和10年頃に暗渠化された」文言〔二次叙述＝repo初出の年次データポイント〕**: 水窪川を「**昭和10年頃に暗渠化された**川です」と記す。出典は明示されないが、同稿がガイドブックとして参照した**本田創『地形を楽しむ東京「暗渠」散歩』（洋泉社2012年12月・[BOOK-083](../books/BOOK-083.md)）**に由来するとみられる〔推定〕。水窪川暗渠化年次について既存の「昭和7年（1932）高田町工事開始説」（[BLOG-001](BLOG-001.md)・[BLOG-163](BLOG-163.md)）・「昭和8（1933）年頃」説（[BLOG-089](BLOG-089.md)・[BLOG-120](BLOG-120.md)）に次ぐ**「昭和10年（1935）頃」説のデータポイント**。どれも二次記録で、断定せず並記。
- **造幣局東京支局石垣下の排水溝石組み〔2015年観察＝repo初出の時点記録〕**: 巣鴨拘置所（スガモプリズン）跡の造幣局石垣について「**その下方には、監獄から水窪川に排水をしていた排水溝の石組みが見えていました**」〔2015-12-27時点で石組みが視認できたという観察記録〕。[BLOG-036](BLOG-036.md)（サンポー2019年・石組み露出目撃）・第2回ノート記録の「造幣局排水溝石組の2016年消滅」との時系列関係（2015年時点視認→2016年消滅→2019年露出報告の食い違い）は**原観察の精査が必要で断定しない**。
- **水源の湿地の位置〔読図・既知の補強〕**: 池袋東口のビル街の谷間辺りに「あったらしい**湿原**」が水源〔筆者の表現。美久仁小路水源説（[LOST-005](../lost-web/LOST-005.md)等）と調和する読図〕。
- **その他〔観察〕**: 都電荒川線を水窪川が「跨ぐ流路」だった個所の迂回（[BLOG-215](BLOG-215.md)の渡河窪み観察の前段階）、消火用水エリア、ガイドブック記載のミョウガ畑民家の荒廃（2015年時点・[BLOG-037](BLOG-037.md)ミョウガ畑の別時点記録）、ラムネ工場跡（[BLOG-099](BLOG-099.md)の位置特定の傍証）、護岸らしき壁・S字カーブ路など。いずれも既知の流路観察の2015年時点追認。
