- **護岸壁の名残の民家〔観察〕**: 坂下通りから新大塚駅へ抜ける道の途中で「**古い民家が一段高い所に建っています。護岸壁の名残りのようです**」〔水窪川の護岸壁を宅地に転用した家屋の観察〕。三叉路（右上=尾根上の新大塚駅・左=坂下通り・川跡は真ん中）から蛇行する細い川跡の読図。
- **ポポー広場の井戸の汲水〔観察〕**: 「**ポポー広場**という小さな公園」「**ここにもポンプ式の井戸が。ちゃんと水が汲めました**」〔[BLOG-108](BLOG-108.md)・[BLOG-171](BLOG-171.md)のポポー広場井戸の、汲水可能な状態にあった時点の独立観察として記録〕。
- **ラムネ工場跡の位置〔repo初出・位置具体化〕**: 「坂下通りを渡った所、マンションの建設現場沿いに川跡が続いています。**右手の駐車場には、かつてラムネ工場があったそうです**」〔[BLOG-099](BLOG-099.md)の旧ラムネ工場（1990年すぎ頃取り壊し）について、**坂下通り交差地点の右手の駐車場**という位置情報＝repo初出の具体化。聞取情報〕。
- **その他〔観察〕**: 大塚坂下町公園入口をかすめて丘沿いに細く続く流路・開運坂前の交番裏に出て坂下通りと合流しそうになって一旦離れる流路の変化。「大塚坂下町の谷」のタイトルどおり谷地形の観察記録。
