# [BLOG-005] 「谷端川の跡を歩く」小石川下流部

- 「谷端川の跡を歩く」『文京区千石編1』。
- https://warpal.sakura.ne.jp/river-yabata/b-koishi4/koishi4.htm
- 小石川下流で谷端川を「小石川大下水」「西大下水」とし、東大下水との合流後に後楽園内へ進む関係を紹介する現地調査資料。
- 一次史料ではないため、名称・合流位置は古地図や行政史料でも照合する。
