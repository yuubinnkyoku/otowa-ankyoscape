# [BLOG-128] ameblo・ねこたま「池袋にあった川、水窪川の跡を歩く①②」

- **書誌〔確認〕**：ameblo「ある日突然、世界から音が半分消えた 〜突発性難聴治療記〜 と猫とグルメと釣りのブログ」（筆者名ねこたま）の2017-08-09①「水源〜都電まで」・2017-08-10②「日の出町商店街〜坂下通り」。①②とも本文直接取得〔repo初出〕。③「坂下通りの東側へ」(entry-12293179010) は今回未取得。
- **水窪川の碑の年次銘〔観察〕**：②で富士山広場の「水窪川の碑」を掲示し、「昔ここに小さな川が流れていた 後世にこれを伝える **1986年**」と紹介〔[BLOG-110](BLOG-110.md)が2015年観察で碑文言を記録していたが年次は未記録。**1986年銘の観察記録としてrepo初出**。辻広場整備（昭和61〜平成10年・[BLOG-106](BLOG-106.md)）の初期年次と整合する。転写であるため正式な採録は現地確認待ち〕。
- **文明開化期地図の読図〔確認: 記事の叙述〕**：①で東京時層地図収録の文明開化期（明治9〜19年）地図について「水窪川の最上流は焼き鳥屋の前あたり」「根津山の北側から東へと水窪川が流れていた」と読図〔明治前期図で上流部が途中までしか描かれない点の個人観察。描図範囲の解釈は断定しない〕。
- **根津山の切崩し〔確認: 記事の叙述〕**：南池袋公園周辺について「戦後間もなくまで根津山という山と森林があった。戦後に土地の所有者だった根津嘉一郎が売却後、丘は切り崩されて平地となった」〔[BLOG-099](BLOG-099.md)の「蟹窪の池を根津山切り崩しで埋め立て（巣鴨プリズン米兵フットボール場造成）」と視点の異なる叙述。切崩し時期・用途の詳細は断定しない〕。
- **巣鴨プリズン排水溝跡の2017年現況〔観察〕**：東池袋の石垣下に「草で埋もれてしまっている」掲示板・排水溝の跡を確認〔[BLOG-025](BLOG-025.md)（2017年石積み移設保存）と同年の別観察として、当該掲示板の状態記録〕。造幣局跡地は「ちょっと前に移転しており、現在は更地・敷地3.2ha」（2017年時点）〔イケ・サンパーク整備前の状態記録〕。
- **都電荒川線の2017年工事聞取〔観察・伝聞〕**：大塚駅〜春日通り区間と同様の「線路を真ん中に持ってきて両脇に道路を通す」計画を、踏切警備員から聞いたと記録〔伝聞であり、その後の都電拡幅工事（[BLOG-108](BLOG-108.md)）の前段の聞取記録として〕。
- **水久保の地名・呼称聴取〔確認: 記事の叙述〕**：②で日の出町商店街について「大正時代は水久保新田（さらに西側は水久保）という地名だったため、地元のご老人からは水久保商店街とも呼ばれている」との聴取を記録〔**「水久保商店街」通称の聴取としてrepo初出候補**。水窪川の川名が水久保の字名由来説（[LOST-005](../lost-web/LOST-005.md)）に接続する聞取り資料〕。
- **谷地形の観察〔観察〕**：②で「水窪川と坂下通りは、春日通り側の丘と豊島ヶ岡御陵へ続く丘の間の谷間を通っている」坂道・崖沿いの高さの観察〔水窪川中流部の谷構造の現地観察記録〕。富士山広場の「富士山の形のネット」・「タイルの小川」の観察〔碑の川の流れ表現（[BLOG-110](BLOG-110.md)）と同一工作物かは断定しない〕。
