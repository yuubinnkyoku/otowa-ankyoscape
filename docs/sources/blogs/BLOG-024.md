# [BLOG-024] 「神田川橋巡り２」中の「音羽町紙抄場」図紹介

- **記事〔確認〕**：ベーム「[神田川橋巡り２：江戸川橋から小石川橋、プラス紅葉の小石川後楽園。](https://4travel.jp/travelogue/11794487)」、**2022年11月27日**。
- **図版〔記事の二次説明〕**：今宮神社の説明の直後、山本松谷の「**音羽町紙抄場**」という図を『明治東京名所図会』由来として紹介し、**漉いた紙をすのこで干す場面**と説明する。「明治40年頃」という説明もあるが、**原画・初出・制作年・原掲載頁は未照合**。
