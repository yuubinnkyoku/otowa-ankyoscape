# [BLOG-027] 占春園の池泉回遊式庭園としての性格と由緒（訪問記）

- **資料〔確認〕**：庭園情報メディア「おにわさん」の「[占春園 ― 東京都文京区・茗荷谷の庭園。](https://oniwa.garden/senshunen-garden-%E5%8D%A0%E6%98%A5%E5%9C%92/)」（**2019年6月10日**、2019年4月・6月訪問）。2026年11月8日に本文を文字抽出で確認。日本庭園メディアの訪問記であり、一次史料ではない。
- **性格・所在〔確認：記事の叙述〕**：占春園は**筑波大学東京キャンパスの敷地内にある池泉回遊式庭園**。近隣に教育の森公園・旧磯野家住宅（国重要文化財）・小石川植物園（国名勝）。**東京メトロ丸ノ内線茗荷谷駅より徒歩6分**、住所は**東京都文京区大塚3丁目29**。
- **由緒〔確認：記事の叙述／碑文の伝聞〕**：江戸時代初期、水戸光圀の弟で**常陸額田藩主だった松平頼元**がこの地に屋敷を構え、その当時作庭されたという。キャンパス内に残る江戸時代中期の**「旧守山藩邸碑」**の碑文によると、江戸時代には**占春園・青山の池田邸・溜池の黒田邸が「江戸三名園」**と称されたという。頼元の子**松平頼貞**の代に常陸国から**陸奥国守山藩**に移され、頼貞が守山藩初代藩主となって以降は明治維新まで松平家が守山藩主を務めた。
- **変遷・管理〔確認：記事の叙述〕**：近代以降は**東京教育大学、筑波大学**の所有と引き継がれ、現在は**筑波大学と文京区の共同管理**の下、筑波大附属小学校が自然観察の場として使用。**茗渓会「占春園復活プロジェクト」**により、冬〜春に日本庭園にふさわしくない樹木の伐採と**かいぼり（池の水の入れ替え）**が実施された。
- **資料の限界〔未解決〕**：**池の水源（湧水・用水・分水の別）は明記されていない**。「江戸三名園」は碑文に基づく伝聞であり、碑文の原拓・判読は未確認。池の名称は [BLOG-026](BLOG-026.md)（落英池）を参照。
