# [BLOG-321] sirakigi「千川上水 歴史・写真・探訪（6）」要町通り〜巣鴨

- **書誌〔確認〕**: sirakigi内の千川上水の歴史・写真・探訪シリーズ第6弾（要町通り〜巣鴨・千川上水公園）。「最新更新：2005.10.01」。**長らく取得できなかったsenkawa61頁を2026-11-25に本環境から直接取得（HTTP 200・Shift_JIS）して本文全文を確認**〔第312回〕。昭和14・15年の写真と現在の今昔写真を併載。
- **大正3年の暗渠化請願〔確認・二次・repo初出〕**: 板橋駅から上流の下板橋まで、**大正3年3月に「千川上水路を暗渠化し中山道の副道とする請願」が出されている**（板橋区史 資料編4の全文引用＝「中仙道ノ警察署ヨリ板橋駅停車場ニ至ル方面道路幅員狭クシテ一朝降雨アランカ泥濘臑ヲ没シ人車馬ノ交通上困難ナルハ…常ニ本町ノ名物語トシテ他ヨリ嘲笑セラレ…然ル処此道路ヲ距ル僅カ拾数間ノ南裏ニ千川水路アリ本町ニ於テハ殆ンド得ル処ナキノミナラズ**断崖十数尺ニシテ水深ク**沿岸ヲ通行スル老幼者及ビ泥酔者墜落シテ生命ヲ失フモノ往々アリ恰モ本町ニ大ナル穽ヲ存スルガ如ク危険甚ダシク…若シ此ノ千川水路ヲ掩ヒ此ヲ道路ニ供用シ中仙道ノ副道ニ充ツル事ヲ得バ之レ誠ニ一挙両得ノ策ニシテ…」〔**大正3年3月請願の年次・文言＝repo初出。千川の戦前暗渠化論の起点資料（道路幅員・嘲笑・墜落危険を理由とする副道化請願）**〕。
- **昭和4年12月の暗渠化許可〔確認・二次・repo初出〕**: **「昭和４年１２月に川越街道の下流域の暗渠化の申請に対して許可が出されている（板橋区史 近・現代 資料編４）」**。申請の理由内容＝①千川上水は往時の灌漑用水より工業用水として大半を占めること②沿岸は近時異常に発展し市街地を形成し交通が頻繁となり護岸が欠壊し維持修繕の経費が困難であること③塵芥汚物等の投入が多く衛生上実害があること④年々数名出る溺死者を看過できないこと⑤よって改修の上一般交通機関の整備に利用せしむる〔**昭和4年12月許可と申請理由の年次文言＝repo初出。板橋区側（大山〜巣鴨）の戦前暗渠化の年代層を確定する第一次の引用文言**〕。
- **昭和16年刊の観察〔確認・二次〕**: 文献1（昭和16年刊）によると大山西町付近は**昭和15年7月時点で暗渠工事中**、**大山の商店街をぬけた辺りからの千川はすでに戦前に「暗渠化サレ跡ヲ留メズ」**〔[GOV-076](../gov/GOV-076.md)の調査アルバム期（昭和13〜16年）に板橋〜巣鴨の写真が少ないことの説明として整合。昭和15年の暗渠化工事中の写真（堰止め・臨時小水路・コンクリート管敷設）を併載〕。
- **田留水車・喜内古屋水車〔確認・二次・repo初出〕**: 大山西町付近（明治24年地図の水車記号）に**田留水車（所有者：田中留吉）**〔**「田留水車」の名称と所有者の文言＝repo初出**〕。旧中山道の仲宿付近（板橋郵便局（板橋2丁目42）脇の道から旧道に入った所）に**喜内古屋水車**があった〔**同初出の文言。明治の前期までは千川の川筋は今より旧中山道寄りであったとの観察つき**。[GOV-067](../gov/GOV-067.md)の練馬区側4水車に対する板橋区側の水車記録〕。
- **東京府志料 滝野川村条の引用〔確認・二次・repo初出文言群〕**: ①**千川用水**＝「千川上水ノ遺址ナリ、玉川上水ノ分派埼玉県新座郡上保谷新田ヨリ来リ本府管内豊島郡関村ニ入り竹下新田上下石神井田中谷原諸村多摩郡上下鷺之宮村ヲ東流シ又豊島郡上下練馬中新井上下板橋長崎中丸金井窪数村ヲ経テ本村ノ東西南三面ヲ繞リ王子村ニ至リ石神井川ニ合ス、其間分派多シ、**本村ニ係ル所長サ二十七町二十五間広サ一間深サ一尺、田五町余ニ沃ク**」〔**東京府志料の千川用水・滝野川村内文言の字句＝repo初出候補（[GOV-098](../gov/GOV-098.md)が引用する東京府志料の水田面積の元文言）**〕。②**仁王橋**＝「千川用水ニ架ス、本村ヨリ巣鴨村ニ渡ル**長サ八間三尺広サ一間木造**、**往事此辺ニ仁王塚ト云フ一小塚アリシニ由リ名アリ**」〔**仁王橋の橋梁諸元・名称由来の文言＝repo初出**。現在地の比定は未実施〕。
- **千川の怪物〔確認・二次・repo初出〕**: **津田順敬『本朝諸国風土記』の記録＝「寛政十三年辛酉六月十三日、板橋宿のうら通千川の堀にて、怪物をとらへたり。先その形黒く長さ頭より尾まで三尺四五寸もあるべし、背中は黒き内にブツブツと一際黒く、頭は鯰に似て平く…目は長くして至て細し。口の大さ壱尺ばかり、前の両足は指四本、後ろの両足は指五本なり、腹は白く薄赤くしてまだらに…山椒魚の千歳を経し也ともいひ、又はやもりの幾許を経しなりとも、或は岩石竜といふもの也ともいへり」**〔**千川の堀の怪物捕獲譚（寛政13年＝1801年6月13日）＝repo初出の江戸後期随筆記録。千川の口承・生物相史の慰み資料として収録（実在確認・撰者津田順敬の書誌は未確認）**〕。
- **洗堰と600メートルの悪水路〔確認・二次・repo初出〕**: **板橋税務署付近で千川から石神井川の「堰の上・橋の下」へ向かう約600メートルの水路がある。周囲の地形は北方向へ低くなる。以前悪水（水の浄化のため）を逃がすためのものといわれ、年未詳の千川上水絵図には「洗堰」と記されていて水量調節の施設があったとみられる。明治期にはこの水路にも水車が設置されたという（板橋区史 通史編 上巻）**〔**「洗堰」文言・悪水路の位置・明治期水車設置＝repo初出**。石神井川〜千川の水路連結の第3の記録として、[BOOK-161](../books/BOOK-161.md)（練馬宿揚水・1941実測）・[BOOK-152](../books/BOOK-152.md)（下板橋揚水説）と対校（流向・比高の整理が必要で同一水路かは断定しない）〕。
- **造兵廠への分水口〔確認・repo初出候補〕**: **板橋一丁目の児童遊園**＝**「板橋火薬製造所のちの造兵廠への分水口があったあたり」**〔造兵廠の千川取水の取水口位置の具体化候補（第38回ノートのGHQ関東軍政部取水（板橋1丁目）・造兵廠→GHQ→印刷局の利用者像、第106回の板橋火薬製造所（石神井川の分疏）の記録と対照）。分水口の構造・年次は本頁からは特定できない〕。
- **現在の千川の終点〔確認〕**: 北区滝野川7丁目2。**千川上水文字が中心に図案化された鉄製マンホール2つ＝南側にある谷端川（暗渠排水管）へ行くものと、埼京線に沿って約600メートル北流し石神井川へ通じるもの。「ここまで千川を流れてきた日量3千トンの水は、ここで石神井川に落されてしまう。現在のところ、ここが千川の流れの終点である」**〔**現代の千川の流水終点（滝野川7-2）と流量・末端構造の文言＝repo初出候補（[GOV-070](../gov/GOV-070.md)の下流暗渠・社紋入マンホールの記録や[BLOG-090](BLOG-090.md)・[BLOG-094](BLOG-094.md)の流量数値との対校対象）**〕。
- **滝野川村辺乃部の図〔確認・二次・repo初出〕**: **「（御府内場末往還其外沿革図書 幕府普請方編・文化五〜文久年間〔1808〜63〕の滝野川村辺乃部の図には、延宝年中の形をもとにして、現在の谷端川が千川分水と記されている）」**〔**沿革図書の滝野川村辺の図が延宝年中（1673〜81年）の形を元に現在の谷端川を「千川分水」と記すとの文言＝repo初出。谷端川の起源系資料（[GAZ-048](../gazetteers/GAZ-048.md)風土記稿の江戸川神田上水分流説・[GOV-047](../gov/GOV-047.md)千川分水の一つ説）に加わる官記録系の傍証候補**。既収録の沿革図書分冊群（[GAZ-054](../gazetteers/GAZ-054.md)・[GAZ-080](../gazetteers/GAZ-080.md)・[GOV-360](../gov/GOV-360.md)〜[GOV-367](../gov/GOV-367.md)）にない滝野川村辺分冊の存在を示唆。原図の所在・該当分冊の特定は未実施（「文化五〜文久年間〔1808〜63〕」の西暦併記は文久＝1864年までのため上限に1年のずれがあるが原文表記のまま記録）〕。あわせて**滝野川村辺では南側に谷端川（暗渠）が千川にほぼ並行して流れる**尾根筋の地形観察＝「人工の川は一番高いところを通す」実例〔千川の開削技術系の観察記録〕。
- **王子分水・反射炉・錐台水車〔確認・二次・対校〕**: 明治通りの谷端川小学校の先（豊島区側の左角）に**千川上水分水堰（明治15年7月）＝「王子分水」ともいう**。**元治元年（1864）に幕府が黒船来航に驚き国防のため大砲製造の必要から石神井川の沿岸（後の大蔵省醸造試験場の一部）に反射炉（耐火煉瓦の溶鉱炉）を築き、大砲の咆孔を穿鑿する動力源として水車（錐台水車）が必要であったため千川から水を引くことになり、慶応元年9月中旬から約2ヶ月半を要して大砲製造所建設予定地まで開削。千川を拡張工事し（この影響は全流域に及んだ）分水を引いた。大砲製造所自体の完成・操業は不明**〔[BLOG-053](../blogs/BLOG-053.md)（慶応元年王子分水＝「堀割」由来自家説の区説明板）・BLOG-228（飛鳥山博物館展「反射炉完成は慶応2年10月頃」説）・[GOV-144](../gov/GOV-144.md)（慶応2年10月書付）との対校系列。「**錐台水車**」の用語と「完成・操業は不明」とする留保＝repo初出文言。「千川上水分水堰（明治15年7月）」の年月表記は[GOV-040](../gov/GOV-040.md)（千川上水分配堰石標の昭和40年調査写真・裏書「551」）との対校候補〕。
- **近代工業の系譜〔確認・二次・既収録系の再述〕**: ①鹿島万平の紡績工場＝**明治3年に許可**（のち本所の東京紡績に合併・移転）〔[PAP-078](../papers/PAP-078.md)の明治3年設立着手・明治5年末竣工・明治20年合併年次と対校〕②渋沢栄一の抄紙会社（王子製紙の基）が千川や石神井川の水車を動力に使用（明治8年頃から製紙・英国製機械・お雇い外国人）〔BLOG-228・BLOG-229既収録の系〕③大蔵省抄紙局（明治8年・紙幣製造・石神井川や千川の水で水車を駆動・明治10年王子製紙隣に工場）〔[GOV-088](../gov/GOV-088.md)等の既収録と同系列〕。**周辺整備が明治以降のこの地に近代産業を導入する大きな役割を果した**との総括。
- **千川上水公園と1993年復活計画〔確認・二次・repo初出〕**: 明治通りを隔てた南側（豊島区）が区立千川上水公園。地下は**六義園への沈殿貯水槽**で入水と出水の**調節バルブ**が残る（[GOV-040](../gov/GOV-040.md)参照）。**「実は1993年に豊島区により、この沈殿池を掘り直す復活計画があったが、先の要町3丁目の復活計画とともに中止になってしまった」**〔**1993年の豊島区復活計画中止の文言＝repo初出**。[BLOG-113](../blogs/BLOG-113.md)年表の1996年時点「一部地域の復元計画も中止されたまま」と整合し、中止をめぐる年代・主体を具体化。江戸時代は木樋でここから白山御殿（現東大植物園）へ向かい江戸の下町の水道になった、との再述（[GAZ-072](../gazetteers/GAZ-072.md)系の白山御殿関係と対照）〕。
- **千川2丁目〜大山西町の今昔〔確認・二次〕**: 豊島区千川2丁目（耕地の真中＝住宅地内に入る所・昭和15年7月時点で暗渠になる予定だった区間・信号機の元の庚申塔（**安永丙申〔1776〕の刻文**））・大山西町民家の境界石2個（コンクリート塀に頭だけ出ている）・**もと千川上水出張所の跡地（児童遊園）の弁天祠・あくたどめ**・ハッピーロード商店街（旧川越街道）・大山橋。板橋区大谷口1丁目と豊島区千川2丁目の区境。**文献5（千川上水探訪マップ1996）によれば「昭和28年から暗渠工事が始まった」らしく、かつて千川地蔵があった境の辺りは「34年」と記されている**〔豊島区〜板橋区境の暗渠化年次の観察記録。どの地点かは明確でない（本文の留保どおり）〕。板橋・滝野川のマンホール5種（3点は「千川上水」と刻印）〔[GOV-070](../gov/GOV-070.md)の社紋入マンホール（板橋駅〜滝野川6丁目）と対照〕。
- **滝野川6丁目62の馬頭観音〔確認・二次〕**: 江戸中期の刻文。千川筋ではない（旧中山道の道中安全祈願と推定）〔25年前の観察との対比の現況記録〕。**滝野川村の四至（東西20余町・南北12町・戸数180・東は西ヶ原村・西は下板橋村・南は巣鴨村・北は王子村）の引用は[GAZ-093](../gazetteers/GAZ-093.md)既収録の風土記稿滝野川村条と同文＝重複確認**。
- **〔未解決〕**: 板橋区史資料編4・通史編上巻の原典確認と書誌登録。東京府志料・御府内場末往還沿革図書（滝野川村辺乃部分冊）・『本朝諸国風土記』（津田順敬）の原本所在と該当箇所の直接確認。「洗堰」の位置と石神井川〜千川連絡系の方向整理（BOOK-161/BOOK-152との对校）。造兵廠分水口の構造・年次の一次史料。仁王橋の比定。
