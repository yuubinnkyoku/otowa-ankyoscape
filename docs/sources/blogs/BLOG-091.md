# [BLOG-091] 板橋区栄町の小水路跡と千川上水境界石の観察

- **書誌**: 水徒然（onnbubatta）、**2011年9月28日**公開。[原記事](https://yatolove.exblog.jp/14641979/)。2026-11-11全文取得確認。既収録 [BLOG-065](BLOG-065.md)・[BLOG-066](BLOG-066.md) と同筆者の別記事で、**本記事はrepo未収録だった**。
- **〔観察〕** **千川上水の境界石2基の現地観察**（板橋区栄町・大山付近、駐車場の路傍など）。1基は傾き・磨耗・剥落が進み、もう1基は「埋没しかかっている」と記す。**千川上水用地の境界を示す石（物理的遺構）の存在が、2011年時点の現地写真付きで確認できる**〔確認：筆者写真と説明／未確認：石の銘文・建立時期・何の境界（上水用地か私有地か）を明示する一次史料〕。境界石の所在は筆者の写真で区界特定はできず、repoの千川上水路線照合では「存在の記録」に留める。
- **〔観察〕** 同記事の前半は都立健康長寿医療センター（旧養育院）裏手から石神井川へ北向きに流れる**細い水路跡（板橋競馬場跡地内）**の遡行観察。東京時層地図明治終わり期で板橋競馬場内に位置し、筆者は競馬場の排水関連を推測**〔推定：競馬場排水路説／未解決：水路の起源〕**。
- **〔参考〕** 板橋競馬場は明治40年造成・明治43年廃止、跡地の一部に**大正2年（1913）巣鴨から愛光舎牧場が移転**と記す〔確認：筆者記述。「愛光舎」の牛乳屋が近隣に現存する観察も併記〕。
- **〔参考〕** 筆者はこの水路を lotus62（暗渠ハンター）のサイトで「石神井川 板橋競馬場支流」として紹介されていると記す。三河川・千川上水との直接的接続は本記事では主張されない。
- **〔未解決〕** 千川上水境界石の銘文・建立年・配置区間。競馬場支流と千川上水分水（栄町＝大山の東京都健康長寿医療センター前面道路を千川上水が流れていたとする [BLOG-092](BLOG-092.md)〔のJIAまち歩き〕との位置関係。
