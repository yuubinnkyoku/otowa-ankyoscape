# [BLOG-126] エンガ堀横・旭丘支流のカルデサック蓋暗渠

- **直接確認（2026-11-12、open_url・本文全文）**：毎日暗活！暗渠ハンター（旧『東京Peeling！』、髙山英男）。豊島区郷土資料館研究紀要第11号（[BOOK-064](../books/BOOK-064.md)）に掲載されていたエンガ堀周辺の湧水池2か所の現地探索記録。
- **エンガ堀の概説〔筆者見解・伝承含む〕**：エンガ堀は**江川堀が訛った呼称**とされ、板橋区小茂根あたりで**石神井川に合流する短い水路**。メインストリームは向丘あたりに鋭い谷を刻み、小竹向原あたりで2流が合流する。ひとつは**東長崎近辺の千川上水を水源**とし、もうひとつは**江古田駅の北側を水源**とする。〔大半が地形頼りの筆者推定。「あたり」が多いと本人も明記〕
- **長崎6-4の湧水〔観察〕**：紀要11号に基づき**豊島区長崎6-4周辺**（区境で隣は練馬区旭丘2-1、**西武池袋線がすぐ横を通る**）の湧水を探訪。湧水地点と、写真直後の**井戸の跡**を記録。この流れについて、リバーサイド（ブログ）記事では**西武池袋線を越えた南の千川上水から取水した水の流れ**とされていた〔二次〕。〔[BLOG-102](BLOG-102.md)（Natrium・エンガ堀起点＝東長崎3号踏切北）と呼応する千川上水由来説の観察側補強〕
- **旭丘支流（仮）の蓋暗渠〔観察：2012年4月〕**：長崎6丁目5あたりから旭丘2丁目に入る蓋暗渠。**継ぎ目孔を塞ぐ加工**がされたU字溝蓋暗渠が上流・下流に続き、私有地間に**橋**（蓋暗渠上に架設）を残す。末端は**扉と鍵で塞がれた袋小路（カルデサック）**で行き止まり、**エンガ堀本流より約1m低い位置**で本流に合流する。〔旭丘支流の実景・微地形がrepo初出〕
- **repoへの関連**：エンガ堀（江川堀）の石神井川合流水路として、[BLOG-103](BLOG-103.md)（Natrium千川上水ページのエンガ堀記述）と合わせ、千川上水→石神井川水系の副次的水理接続（[GOV-068](../gov/GOV-068.md)の設計思想と同型）を示す材料。
- **制限〔未解決〕**：江古田駅北側水源説は未検証。蓋暗渠・橋の現況は2012年時点の観察で、現況確認が必要。
