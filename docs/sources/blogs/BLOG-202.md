- **呼称体系〔確認：本文の整理〕**：豊島区・板橋区・北区では「谷端川」、文京区では「小石川」または「礫川（れきせん）」、また指ヶ谷や本郷からの流れ（東大下水）に対して「西大下水」とも呼んだ、と整理する〔既存の呼称記録と整合。新情報ではない〕。
- **暗渠化年次〔確認：本文主張〕**：汚染によるドブ川化を経て「暗渠化が完成したのは**1964年（昭和39年）の東京オリンピック開催を契機**としている」と記す〔筆者の通説的整理で出典を本文に示さない。[BLOG-132](BLOG-132.md)（地図子・1964年までに暗渠化の読図）・[GOV-015](../gov/GOV-015.md) 系の年次表現と一致する独立二次記録。1967年説（BLOG-150）・1962年河川廃止（BLOG-153）と対立するため断定せず並記〕。
- **暗渠の下水道幹線〔確認：本文主張〕**：現在、谷端川の暗渠は「**三つの下水道幹線**」として活用され、暗渠化の前後に板橋駅近辺と東武東上線下板橋近辺から石神井川へ向かう**二本の放水路**が設けられた、と記す〔三幹線区分（谷端川上幹線・谷端川幹線・千川幹線）・二放水路は既収録の整理と整合。本文は根拠を示さない〕。
- **流路特性〔確認〕**：南から北へ約3km流れる関東で珍しい北向き流れ、と記す〔既出の地形記録と整合〕。
