# [BLOG-162] 暗渠さんぽ「1-6 さんぽ：千川分水」

- **直接確認（2026-11-13、Wayback 20240419115805 スナップショット・本文全文）**：kaeru.moe 直は Access Denied（[BLOG-139](BLOG-139.md)と同じ回避手段）。「六ヶ村分水（当ブログでは千川分水）」のうち杉並区荻窪方面の流路を、**「観音川」**の名で復元する記事。
- **「観音川」命名文献の書誌〔repo初出〕**：**田中士郎「観音川と松庵川」『杉並郷土史会会報』第127号（平成6年）**。「松庵川」の命名記事と同一記事で、**順序としては観音川が先に紹介されていた**という。荻窪の光明院を指す「観音」による命名〔伝聞〕。千川上水の分水史（六ヶ村分水）の文献としてrepo初出の書誌。
- **観音川＝六ヶ村分水のひとつ〔推定〕**：四面道口（井口昭英の仮称）から南下し善福寺川へ向かう流れ＝「四面道口からの田用水」（既出）と重なる、とする。光明院は現在は高台にあり**かつては別位置だった説**（田中の推測〔伝聞〕：現在の光明院と荻窪白山神社の間の低地）。自然河川（荻の窪の湧水集水）に用水路を接続した可能性の指摘。
- **白山通りの湧水記録〔伝聞〕**：白山通り（ハクサンタウンズ）は大正初期「昼でも薄暗い切り通し」で**「崖下に湧水があった」**。**矢嶋又次の記憶画（杉並区郷土博物館分館）ではこの通り左端付近に湧水の小川が描かれる**〔伝聞〕。観音川に注ぐ支流の可能性。白山神社南側一帯は沼地で草が群生していたとも。
- **下流部の復元〔推定〕**：桃井二小の北東側・南東側を「ドブ川」が囲り、忍川橋のところで落ちている＝観音川の河口部と推測。環八に中流部をほとんど飲み込まれ痕跡がない。
- **清水口支流（仮）〔repo初出の整理〕**：同頁末尾に、六ヶ村分水の残る取水口「清水口」から分水する流れ（リバーサイド説の「四面道支流」とは別）を**「清水口支流（仮）」**として切り分ける整理。千川上水の水を引き入れ、途中で湧水を合わせ、妙正寺川に注ぐ。始点＝四面道交差点北側の排水場。
- **参考文献群〔書誌〕**：井口昭英『井草のむかし』、『おぎくぼいまむかし』（杉並区桃井第二小学校創立50周年記念）、「荻窪の古老矢嶋又次が遺した記憶画」（杉並区郷土博物館分館）、杉並区史跡散歩地図など。杉並側の千川上水分水史の一次・郷土資料の手掛かり。
- **制限〔未解決〕**：田中論文の本文・観音川取水口の位置は文献によりずれがあり未確定。『杉並郷土史会会報』第127号の現物確認が次の一手。
