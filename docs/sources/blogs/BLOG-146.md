# [BLOG-146] kawawalk「加賀藩下屋敷分水」（直接確認・Wayback）

- **書誌〔確認：Wayback Machine保存版本文全文〕**：gooブログ「神田川　「まる歩き」　しちゃいます！！」の千川用水６カテゴリ、**2015年10月6日投稿**〔第40回は検索スニペットのみだったが、Wayback保存版で本文全文取得に成功し直接確認へ格上げ。スニペットで確認済みの文言は本文と一致〕。
- **〔確認: 本文引用文言〕 天明7年（1787）の平尾邸への千川用水引き入れ見積書**: 「板橋区史 / 通史編上」による。**分水路の延長168間（≒306m）、費用総額193両2朱、千川家に納められる使用料・管理料毎年25両**〔見積書の定量内容＝repo初出。上水再廃止（天明6年・[GOV-077](../gov/GOV-077.md)系）の翌年に引込構想が持ち上がった時序も初出〕。
- **〔確認: 本文〕 分水の実施推定＝repo初出**: 「**この分水路のその後について、文献的には定かではありません。ただ、「下板橋宿絵図」で、観明寺門前に架かる石橋が、この分水路にかかわるものと目されます。同図の製作年代は未詳ですが、同様の石橋が文化3年（1806年）の「中山道分間延絵図」にもあることから、この計画が実際に施工、運用されたのでしょう**」〔**文化3年中山道分間延絵図の石橋描写を根拠とする実施・運用推定**。筆者推定であり原図未確認だが、天明7年分水の実施可否問題への初の具体的根拠提示〕。**分水口は平尾橋手前と推測**とも〔筆者推定〕。
- **〔確認: 本文〕 加賀藩下屋敷絵図群の所在＝repo初出**: ①**加賀藩江戸下屋敷絵図（前田育徳会尊経閣文庫所蔵）**を板橋区教委の解説プレートから引用。②**「下屋敷御林大綱之絵図」（文政7年・1824）を板橋区「公文書館電子展示室」で閲覧可能**〔第40回の「御下屋敷惣絵図（[GOV-093](../gov/GOV-093.md)）の所蔵先」課題への候補提示。当該電子展示室頁の直接確認が次の一手〕。
- **〔確認: 本文〕 大池先端への水路注入口**: 東板橋体育館前が「上掲絵図で、**大池の先端に水路が注いでいるあたり**」〔大池（[BLOG-144](BLOG-144.md)平尾邸大池水源説・[GOV-093](../gov/GOV-093.md)）への注水地点の具体化候補〕。
- **〔確認: 本文〕 観明寺の下屋敷遺構**: 石橋は門前の右手、境内に移築稲荷社、赤門は元下屋敷通用門伝承〔スニペットで既出・本文確認〕。明治44年「郵便図」には観明寺東縁沿い→北園高校方面の水路描写〔既出〕。
- **〔確認: 本文〕 王子新道の開通年＝repo初出**: 「**王子新道」の石碑。板橋から王子へ通う通勤路として、旧中山道仲宿交差点を起点に**明治21年（1889年）開通**〔板橋〜王子間の交通史の年次。千川上水・堀割周辺の都市化文脈〕。
