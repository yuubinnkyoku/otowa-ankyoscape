# [BLOG-023] 落合道人「江戸期からの紙漉きがつづいた落合地域。」

- **公開日〔確認〕**：**2026年10月6日**。[記事本文](https://tsune-atelier.seesaa.net/article/521591207.html)／[日別ページ](https://tsune-atelier.seesaa.net/archives/20261006-1.html)。
- **二次転記内容〔確認：記事本文〕**：関義城『江戸東京紙漉史考』から東京府産紙同業組合の沿革を紹介し、**1920年12月27日認可、北豊島・豊多摩・荏原・南足立の4郡と小石川区を対象、115名**とする。製品として江戸川巻紙・封筒・辞令用紙を挙げる。**1922年116工房、昭和期48工房、1929年解散**も記す。いずれも小石川区の個別工房の数字ではない。
