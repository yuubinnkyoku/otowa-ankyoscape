# [BLOG-154] 寅さん歩 その25 谷端川の流れを歩くー3（平野武宏）

- **直接確認（2026-11-13、Wayback id_付きURLで本文全文取得に格上げ）**：[Wayback保存版 2024-06-10](https://web.archive.org/web/20240610053137/http://www.shonan-fujisawa.jp/watanabe/wpage5144.pdf)。第43回は前半のみだった本文の後半（川越街道〜下板橋駅〜板橋駅〜明治通り）を取得。
- **橋名の由来の出典が特定〔確認〕**：**「橋名の由来については豊島区立郷土資料館友の会『旧谷端川の橋の跡を探る』から引用しています」**。この資料は筆者が豊島区主催の史跡めぐり講習会で受け取ったもの〔第43回の未解決（由来の出典）を解消。由来文言の一次出典はBOOK-062（友の会1999）〕。
- **前半部分の橋名由来・地番〔確認〕**：日ノ出橋（日の出が見えた）、北荒井橋（池袋3-10/3-11間・字「荒井」の北）、東橋（池袋3-13・諸説）、高松橋（池袋3-14/3-15間・地名）、上ノ橋（池袋3-32/板橋区南町9間・字「上」）、中上橋（池袋3-34/南町3間・地名と字の合成）、御嶽橋（池袋3-40/南町1間・豊島区側に御嶽神社）〔いずれも第43回記録どおり〕。
- **後半部分の橋名・由來（南緑道末尾〜児童遊園〜北緑道。由來文言はrepo初出）**：
  - **前田上の橋（池袋本町1-6と板橋区熊野町10の間）**：川越街道から振り返って見た橋。**「前」は熊野神社の前、前田橋の上にあるのが由来**。
  - **前田橋（池袋本町2丁目と熊野町10の間）**：**前田とは熊野神社前の田圃の意味**〔田圃由来の文言〕。
  - **北浦橋（池袋本町2-23と熊野町6の間）**：**北の平地（浦）なので北浦**。
  - **中丸橋（池袋本町2-33と熊野町5の間）**：地名由来。
  - **西前橋（池袋本町3-17と板橋区大山金井町5の間）**：**字名が由来**。この橋から板橋区管理の谷端川児童遊園は終わり、豊島区管理の**谷端川北緑道**となる。
  - **豊橋（池袋本町と大山金井町の間）**：**地名ではなく人間の願望を盛り込んだ橋名**〔「豊」の願望橋名説〕。
- **熊野神社（板橋区熊野町11-2）〔確認：社伝〕**：**創建は応永年間（1394〜1428）に豊島郡中丸村に移住してきた宇多天皇の子孫・庭田氏兼（後に岩田と改姓）が一族の氏神として熊野権現を勧請、天正15年（1587）に氏兼五代目の子孫が現在の地に遷座**〔応永勧請・天正15年遷座の年代文言はrepo初出候補。BLOG-150の中丸熊野神社応永勧請・天正15年遷座と完全整合＝独立裏付け〕。中丸村周辺の鎮守。
- **下板橋駅〜板橋駅の橋〔確認〕**：下板橋駅前の踏切を渡り、JR板橋駅へ向かって順に**三の橋・二の橋・一の橋（板橋区1-2と1-10の間）**が再現〔BLOG-121の下板橋児童遊園プレート観察と整合〕。
- **区間橋数〔確認：友の会資料〕**：**要町駅付近から明治通りまでは28の橋が確認**〔区間別橋数=repo初出。BLOG-155の水源〜椎名町6橋・椎名町〜長崎橋10橋、BLOG-152の明治通り〜不忍通り14橋、BLOG-156の文京区間15橋とあわせ区間別の橋数データが揃った〕。
- **流路〔観察〕**：板橋駅のガードを出ると北区滝野川7丁目と豊島区上池袋4丁目の区境を流れ、明治通りとの交差点に到達〔区境の具体番地〕。
- **制限〔未解決〕**：各橋の由来の最終出典は友の会1999冊子の現物確認待ち（筆者を介した二次引用）。
