# [BLOG-239] わんじん「東大下水：菊坂支流（仮）」（2014-03-11）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文）**: wanjin東大下水カテゴリの菊坂支流記事。西片支流（[BLOG-238](BLOG-238.md)）の次の支流。
- **前田家上屋敷→懐徳館の沿革〔ページ記載〕**: 東京大学本郷キャンパスは江戸期の**加賀前田藩上屋敷**。明治になり敷地の大半は東大キャンパスとなったが、南西隅に前田家の屋敷が残り、和館（**1905年・明治38年竣工**）・西洋館（**1907年・明治40年竣工**）を構えた。**1910年（明治43年）明治天皇の御行幸**に合わせて日本庭園が整備され懐徳館庭園（懐徳園）となり、のち「懐徳館」と命名されて迎賓館に使用（名は論語「君子懐徳」由来）。**1945年（昭和20年）東京大空襲で懐徳館焼失**（本郷キャンパスの他建物は被害を免れた）〔沿革数値の一次典拠は本文に示されず。現存する懐徳館（1950年・吉田五十八設計）とは別の旧館の話である点に注意〕。
- **懐徳館の池の余水＝菊坂支流の源〔wanjin推定〕**: 「**この懐徳館にある池の余水が菊坂支流の始まりと思われます**」。ただし現在の池は「無料開放の際に確認した池にはほとんど水がない状態」だったとする〔推定と明記。懐徳館の池→菊坂支流の接続はwanjinの現地観察に基づく仮説〕。
- **本郷通り「別れの橋」・見送り坂・見返り坂〔ページ記載・repo初出の橋名情報〕**: 懐徳館の池からの余水は本郷通りを抜け、「**本郷通りには『別れの橋』という名前の橋が菊坂支流上に架かっておりました**」。見送る側は菊坂支流に架かる別れの橋の手前の**「見送り坂」**から、江戸を離れる側は別れの橋の奥の**「見返り坂」**から双方を確認しあった、という情景を描く。江戸市中の北限はかねやす（本郷）までという文脈の言及もある〔別れの橋・見送り坂・見返り坂の命名の典拠は本文に示されず。橋名・坂名の史実性の照合は今後の課題だが、菊坂支流上の橋名の候補として記録〕。
- **ホテル磯山館裏の滝〔伝聞〕**: 「**ホテル磯山館の裏では滝を形成して流れていたそうです**」〔伝聞と明示。年代・現状は不明〕。
- **菊坂の由来〔ページ記載〕**: 「菊坂」の由来は**昔このあたりが菊畑だったことに由来**するとし、もともと「菊坂」という坂道の呼称は**現在の菊坂通りより東に折れたところにある「胸突坂」を指す呼称**だったとも記す〔由来・呼称移動説は典拠示されず〕。
