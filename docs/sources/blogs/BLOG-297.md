# [BLOG-297] クラブツーリズム「環状七号線地下調節池 幻想的な光の回廊」プレス〔repo初出・環七インフラツアー民間展開の初期一次プレス〕

- **書誌〔確認: prtimes本文全文取得〕**: ＫＮＴ－ＣＴホールディングス配信のPR TIMES公開プレスリリース（**2023年12月7日 15時02分**）。クラブツーリズム（江東区・酒井博社長）が東京都建設局・（公財）東京都公園協会と連携して**『期間限定の通り抜け！約600ｍの大冒険！環状七号線地下調節池 幻想的な光の回廊』ツアーを開催**、岩崎電気（伊藤義剛社長）との共同で**地下調節池本管のライトアップ＝光の回廊を演出**。
- **環状七号線地下調節池の説明文言〔確認: プレス本文〕**: 「環状七号線地下調節池とは、水害が多発した神田川中流域の水害に対する安全度を早期に向上させるために環状七号線の道路下に建設された、**長さ4.5km、内径12.5ｍの巨大トンネル**です。**神田川、善福寺川、および妙正寺川の洪水約54万立方メートルを貯留する施設**」＝**「神田川中流域」という位置づけ文言・54万m³の内訳を神田川・善福寺川・妙正寺川の3川とする文言**〔数値系は既知だが「中流域」の表現は一次プレス文言〕。
- **ツアーの行程文言〔確認〕**: **2024年2月4日（9:45集合12:00解散予定）と2月4日・25日（12:40集合15:00解散予定）の2コース（コース番号N4542-988・N4543-988）・旅行代金6,990円・東京メトロ丸の内線方南町駅改札前集合→環状七号線地下調節池へ→善福寺川取水施設から神田川取水施設まで約600ｍを通り抜けウォーキング→現地解散**＝**本管内を善福寺川取水施設から神田川取水施設まで約600m通り抜けた**という内部空間利用の初期一次文言〔repo初出〕。あわせて「新春ヨガ」の特別見学コース・見学ツアーコース一覧（tour.club-t.com）の案内あり。
- **意義〔観察〕**: ①[GOV-291](../gov/GOV-291.md)第1回委員会の「完成後の利用はインフラツアーなど多目的な活用」（R8.3.4）・都プレス2026-11-02の第2期告知（[GOV-149](../gov/GOV-149.md)第92回追記・2027-01-09〜02-28）の**前史として、2023年12月時点ですでに本管内ウォーキング＋ライトアップの民間ツアーが商品化されていた**＝環七インフラツアーの系列を2023年末起点に遡れる。②**「善福寺川取水施設から神田川取水施設まで約600m」**という2取水施設間の本管距離の一次文言は、[GOV-489](../gov/GOV-489.md)の善福寺川取水施設（堀ノ内2-1）・神田川取水施設（和泉4）両監視局の位置対比の補強資料。③国交省推進「インフラツーリズム」でクラブツーリズムが2011年から実施という業歴文言も含む。
- **制限・未解決**: ①実際の開催実績（2/4・2/25の実施有無・参加者数）は本プレスでは未確認。②「光の回廊」の写真・アーカイブの所在は未確認。③[GOV-149](../gov/GOV-149.md)第92回追記の都プレス（2026-11-02）と本プレス（2023-12-07）の間の2024〜2025年のツアー展開の全容（都プレス2025-11-13〔第1期告知〕等の増補）は次回以降に整理可能。
