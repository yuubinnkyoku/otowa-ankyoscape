# [BLOG-086] Natrium.jp 中丸川

- **直接確認（2026-11-11、open_url・本文全文・2026年7月6日追記分を含む）**：「板橋の地名」（板橋区教育委員会発行、1995年）の**幸町に発し谷端川まで東西に流れていた川を地元で中丸川と呼んでいた**という記述に基づき、本流と2支流の水路敷を地籍図（MapExpert地籍マップβ版含む）と現地で照合した記録。**2017年撮影＋2025年2月21日再訪＋2026年7月6日追記**。
- **本流の流路〔確認：地籍図＋観察〕**：西前橋（谷端川合流点）→ 山手通り → 大山金井町・熊野町境の裏路地 → 中丸町交差点付近の谷底 → 「さいわい通り」沿いの東西一直線 → 千川上水に到達。**川越街道中丸町交差点付近が微妙な谷底**であること、さいわい通り東端の蓋暗渠の残存（2017年時点）を記録する。
- **支流（南西方向）〔確認：地籍図＋観察〕**：中丸町の区画を斜めに横切る水路敷（空中写真で南西へ斜めに進む空間を発見して再訪）、**民家の境界線が点線状に斜め**になる路地、マンション脇の壁沿い水路敷を上流端とする流路を記録。
- **支流（北方向）〔確認：地籍図＋観察〕**：板橋二中付近のクネクレ道 → 小学校北側の溝 → マンション敷地の北側道路 → **千川上水にたどり着く**。**板橋二中の北側の溝の東側にも千川上水までつながる小道**があったと記す。
- **本流上流端＝千川上水〔確認：地籍図＋観察〕**：千川上水到達地点の脇に**青面金剛庚申塔**が置かれ、**五叉路のすぐ脇に中丸川から千川上水に向かう細い路地**がある。庚申塔の隣には片足だけの台座が残る。**水路敷が谷頭に達した地形**として、**大谷口給水塔裏あたりが谷頭のよう**で、**この近辺にかつて湧き水があったのだろうか**と筆者は問いかける。〔推定：谷頭・湧水〕
- **2026年7月6日追記〔確認：地籍図＋観察〕**：千川上水を渡った北側（**東側下板橋村・西側上板橋村の境になっていた路地**）に地籍図で水路敷が描かれ、現地に未舗装・砂利舗装の空間が残る。**かつては中丸川の最上流部だった可能性**があるという。村界は三叉路で東にそれるが、地形図では**やや西寄りの大谷口給水塔裏あたりが谷頭のよう**とする。
- **千川上水の水神様〔確認：観察〕**：本流上流端の千川上水脇に**千川上水の水神様が祀られていた**（現在は柱の陰の庚申塔の隣）と記し、千川上水について元禄9年（1696年）開通・昭和45年（1970年）までに大半が暗渠化の説明を付す。〔説明はnatriumによる二次整理〕
- **repoへの関連〔重要〕**：[BLOG-059](BLOG-059.md)の住民聴取「上流は千川上水につながっていた」と[GOV-068](../gov/GOV-068.md)の分水設計思想（分水は湧水池・自然河川源頭に接続）を、**地籍図・現地観察という第三の方法で独立に裏付ける**。中丸川の上流端が千川上水（おそらく分水・漏水系）に接続するという仮説が**千川上水→谷端川水系の副次的接続**として強化された。**中丸川＝出端川混同問題（[BLOG-059](BLOG-059.md)・[BLOG-080](BLOG-080.md)）についても中丸川の実在を流路単位で支持**する。〔観察の総合／接続の水理・時期は依然未解決〕
- **制限〔未解決〕**：中丸川が千川上水から実際に取水していたか（分水口・樋の有無）、千川上水北側の水路敷が中丸川最上流部か、の直接史料は確認されていない。
