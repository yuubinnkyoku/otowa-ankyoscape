- **都電荒川線の渡河地点〔観察＝repo初出〕**: **「都営荒川線。水窪川を渡る個所が窪んでいます」**〔日之出町〜東池袋間の都電荒川線と水窪川旧流路の交点が窪地として視認できるという2019年観察。都電側の渡河記述としてrepo初出〕。
- **造幣局＝巣鴨プリズン跡地〔伝聞＝repo初出の明文化〕**: 川跡が壁にぶつかる区間で「壁の上はかつて**巣鴨プリズンの敷地**。サンシャインシティの敷地がそうであったことは有名ですが、**造幣局までそうだった**のですね」〔[BLOG-099](BLOG-099.md)・[BLOG-175](BLOG-175.md)の造幣局・プリズン文脈を、住民向け二次叙述として補強〕。壁下に**排水口**〔観察〕。
- **東池袋の再開発と川跡の窪み〔観察〕**: 大勝軒総本山跡（現・首都高ガード下に移転）をかすめ、再開発地「あうるスポット」に**窪みと並ぶマンホール**〔旧流路位置の傍証候補〕。**日之出町公園**に「かつての川の存在を偲ぶためか、**短い流れ**が設置」〔[BLOG-171](BLOG-171.md)の日出町公園川モチーフの独立観察〕。
- **水源への到達〔観察・推定〕**: 豊島岡女子学園裏手の谷筋は**美久仁小路**に至り、横丁中程の**クランク状の花壇**（現在空地）を「ここが水源なのでしょうか？」と推定〔筆者の推定。花壇=旧水源の同一性は未確認〕。横丁の先の谷筋は飲食店・ラブホのビル群で塞がれ、地図上で突き抜けると**池袋駅東口前の五叉路**に至るという読図〔観察・推定〕。
- **制限〔未解決〕**: 花壇=水源説は観察に基づく仮説。五叉路から上流（西）側の流路の読図は本文になし。
