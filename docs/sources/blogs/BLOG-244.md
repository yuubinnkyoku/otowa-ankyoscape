# [BLOG-244] 髙山英男「暗渠ハンター　六義園の水のゆくえ」

- **直接確認（2026-11-15、本文全文。コメント欄は未取得）**: 暗渠ハンター（髙山英男）の六義園排水検証記事。2014年5月26日・6月24日の追記を含む。wanjin「東大下水：六義園支流（仮）」訂正記事（[BLOG-240](BLOG-240.md)）が訂正の契機として明記する相互リンク先記事で、本記事のコメント欄での北条光年とのやりとりが訂正流路の根拠の一つになったとされる〔BLOG-240の記載〕。ただしコメント欄の内容自体は本ファイルでは未取得（[BLOG-240](BLOG-240.md)は「lotus62コメント欄の情報自体は未取得（wanjinの要約による）」とする）。
- **六義園の池の取水〔ページ記載〕**: 六義園の池は、千川上水から「掘割」で取水し、ほぼ巣鴨地蔵通り商店街を通って巣鴨駅あたりから六義園の池に通水されていたとする。
- **問いと仮説〔著者の仮説〕**: 六義園が完成した1702年（元禄15年）当時は池の水を見える形で排水していたはずだとして、地形図で南側の鶏声ヶ窪に谷頭が現れることに着目し、「六義園の池の排水は、鶏声ヶ窪の川の最上流に繋がっている」という仮説を提示する。鶏声ヶ窪の下流の川跡は「東洋大学辺りから白山を通って、指ヶ谷という谷を流れ、やがて小石川に合流する」と説明する。
- **現地観察〔著者の観察〕**: 六義園からの出口そのものは不明。不忍通りを越えた昭和小学校と東洋文庫ミュージアムの間の空地を、鶏声ヶ窪の谷頭から北へ延長した線上の地点として記録する。江岸寺の入口の橋跡（「決して決定的証拠とはいえない」と著者が明記）。本駒込2-18〜20では谷底が寺の敷地内となり観察できない。本駒込1-27・28あたりから谷底の道が現れ、池跡（長谷川百貨店）を記録。本駒込1-7あたりから谷底と道が一致し、道は東洋大学の正門付近に達する。東洋大学の敷地の向こう側からは「分かり易い暗渠道」が始まると記録する。
- **追記（2014年5月26日）〔転記〕**: 平成6年『文京区景観整備調査報告書』から転記した図に、六義園から南に下る水路が「消失水路」としてプロットされていることを紹介する。報告書そのものは未照合で、本リポジトリにも未登録。
- **追記（2014年6月24日）**: 北条光年氏が六義園の池の排水について独自に集めた情報と仮説をコメント欄に寄せた旨を案内する。
- **制限**: 個人ブログの現地観察と仮説。六義園の出口は未特定で、検証は地形・痕跡の整合まで。本記事が手がかりの一つとする昭和小学校・東洋文庫間の区間について、wanjinは訂正記事（[BLOG-240](BLOG-240.md)）で「存在しない可能性が高い」としている。
