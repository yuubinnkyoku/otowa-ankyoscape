# [BLOG-095] 千川上水分配堰碑の碑文全面採録と調節池の現地観察

- **書誌**: citywalk2020「[千川上水分配堰碑＆マンホール＆千川上水調節池跡](https://citywalk2020.hatenablog.com/entry/2022/08/22/093445)」2022年8月22日（発見日2022年8月4日・再訪8月18日）。2026-11-11、直接アクセスは遮断されたため**Wayback Machine保存版（2022-10-13取得）で全文取得**して資料化。URL自体は[tools/link-audit]の収集対象にあったが資料ファイル化は今回が初。
- **〔確認・碑文採録〕** 北区滝野川六丁目9-1（明治通り沿い）の**千川上水分配堰碑の碑文を面別に採録する**：
  - 正面：**「千川上水分配堰」**
  - 右側面上部：**「玉川上水 水路新座 郡上保谷 新田分派」**
  - 右側面下部：**「樋口寸積百拾六坪八合　内　八拾三坪四合　印刷局抄紙部　三拾三坪四合　王子村外廿二箇村　樋口寸積百五拾坪　千川水道会社」**
  - 左側面：**「明治十五年七月造之」**
  - 裏面：**明治42年（1909）3月として、樋口の大きさと利用者、堰幅の長さ、千川上水公園内にあった溜池の水面の高さが刻まれている**〔裏面の文言本体は筆者の要約であり未採録〕。**碑文の面別全面採録（樋口寸積・印刷局抄紙部・王子村外廿二箇村・千川水道会社の対置）はrepo初出**〔確認：筆者による碑面の読み取り文言／未確認：筆者の釈文の検証・裏面全文〕。
- **〔確認・説明板〕** 同所の説明板（北区設置とみられる）の文言として、碑は**水利権を明確化し互いの取水量を遵守するため明治15年（1882）7月に設置**、分水路は**慶応元年（1865）11月の幕府大砲製造所（飛鳥山西側・滝野川2-6付近）建設に伴う開鑿**、明治期の利用は**北区・荒川区・台東区内の23か村の灌漑用水と王子近辺の紡績工場・抄紙会社・大蔵省紙幣寮抄紙局の工業用水**、千川上水本流も東京市内への給水が再開されたと説明する〔堀割の1865年由来は[BLOG-053](BLOG-053.md)・[ORG-014](../org/ORG-014.md)と同内容の説明板系叙述〕。
- **〔確認・二次〕** 千川上水公園側の説明板（平成16年3月・豊島区教育委員会）文言として、**明治13年（1880）に岩崎弥太郎らが設立した千川水道株式会社によって本郷・小石川・下谷・神田方面への給水が再開されると王子分水の分配堰が設置された**、公園側に分配堰の落し口と沈殿槽からの水量調整、**六義園方面への送水に使用したバルブ（巻揚器）が現在も残る**、沈殿池は**1973年頃に現在の構造に造り替えられ東京都東部公園緑地事務所が管理**と記す〔公園の沿革・堀割・沈殿池の叙述は[BLOG-053](BLOG-053.md)（tokyotoshima）の説明板転記と重複。バルブ現存と1973年造替え・管理者文言は本記載が詳しい〕。
- **〔確認・観察〕** マンホール蓋の所在観察：**千川上水の紋章入りの大型蓋・角型蓋（板橋駅東口近くに2枚と伝える）・直径60cm程度の蓋（滝野川6丁目と7丁目の境に4枚と伝える）**。公園内の**導水門・排水門**の観察写真〔確認：2022年の筆者観察／未確認：蓋の現況〕。
- **〔未解決〕** 裏面（明治42年）の全文採録、樋口寸積の坪单位の換算と水利の内訳（印刷局抄紙部83坪4合・王子村外22か村33坪4合・千川水道会社150坪）の原典照合、バルブ（巻揚器）の現況と銘板。
