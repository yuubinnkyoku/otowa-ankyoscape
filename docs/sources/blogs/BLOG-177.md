# [BLOG-177] 夢七雑録「谷端川（千川上水長崎村分水）跡を歩く−２−」

- **書誌・取得〔確認〕**：gooブログ「夢七雑録」2018-05-27付。**part1（BLOG-033格上げ）・part3（BLOG-133）の中間にあたるpart2を、Wayback id_指定で本文全文初取得（2026-11-13、第50回）**。これで同シリーズ3回の本文が全部揃った。椎名町駅〜川越街道（熊野橋）までの谷端川南緑道区間を橋単位でたどる記録。
- **西光院の橋供養碑〔repo初出〕**：中上橋の近くの**西光院に橋供養碑があり、「中丸村の上下両橋を延享2年（1745）に石橋として造立した」**とある。両橋とは**中上橋と中丸橋**と考えられるという〔筆者の碑文読み・橋名比定は推定。**江戸中期の石橋造立の年次を伝える碑文情報としてrepo初出**。実物の採録・書誌確認が次の一手〕。
- **下田橋→霜田橋の改称〔repo初出〕**：立教通り（池袋村絵図にも描かれた江戸時代からの道）に架かる橋は**下田橋と呼ばれていたようだが、後に霜田橋と改称された**〔BLOG-153格上げの霜田橋=下田（ゲデン）検地用語由来説に、「旧称下田橋」という独立の叙述が対応〕。
- **橋の付帯年次の読図**：明治の地図では霜田橋から中上橋の間に橋がなく、この間の橋（谷端川第二親水公園前後）は大正時代以降の架橋と推定。長崎橋の通り（西口バス通り）は大正14年地図に橋とも記されていない。日之出橋・北荒井橋・東橋は**大正時代の終わりのショートカット分水路（BLOG-033）整備の際に架けられたと思われる**〔読図・推定〕。
- **親水公園と野菜洗い場〔観察・伝聞〕**：谷端川緑道には2か所の親水公園（谷端川第二親水公園・谷端川親水公園）。親水公園の辺りは**谷端川の水を引き込んで野菜の洗い場にしていたという**〔BLOG-138の「かつて野菜洗い場」伝聞の独立裏付け〕。
- **上の橋への合流流れ〔観察〕**：上の橋は**高松小付近を水源とし、わきみず通りと呼ぶ細い道を下り、庚申塔の祠の横を通ってきた流れが橋の近くで谷端川に合流していた**〔BLOG-058のわきみず通り・BLOG-176の上ノ橋池袋3-23と位置が対応。谷端川南緑道の水流観察群に追加〕。
- **境橋以降の橋名とアトリエ村**：境橋（ここから谷端川が板橋区と豊島区の区境）・西側板橋区側にひかりが丘・みどりが丘のアトリエ村〔BLOG-138整合〕・御嶽橋（みたけ通り＝道幅拡張後の呼称）・南橋（中丸村小字）・境井田橋（池袋村小字・BLOG-139/157の境井田支流と対応）・他領橋（飛地由来）・熊野橋（交差点角の神社＝熊野神社由来）〔いずれもBLOG-138/148/154/176の橋名群と照合可能な独立列挙〕。
- **意義**：谷端川南緑道の橋名・由来・付帯年次を独立の踏査記録として列挙した点でBLOG-138（11-1Studio）・BLOG-150（freedomwalk）と相互検証が可能。中でも**西光院橋供養碑（延享2年石橋造立）**は江戸中期の橋の実在を伝える碑文レベルの情報で、実物確認により橋名調査の年次を大きく前進させうる。
- **注意**：碑文の年次・文言は筆者転写。改称の初出資料・各橋の架設年は未特定。
