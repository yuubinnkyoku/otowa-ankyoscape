# [BLOG-388] Natrium.jp「エンガ掘と周辺の水路敷群（下流端〜要町通り）」

- **書誌〔確認：curl本文全文・2026-11-28取得〕**：Natrium.jp「水路敷を行く」エンガ掘シリーズ第1頁（canal_lot目次走査で検出＝repo初出URL）。全国Q地図の東京都3千分の1地図（1961〜62年）に水路を書き込んだ読図を基調とする。本文記載の限り写真は2017年4月29日撮影（一部2017年5月・2025年2月26日の追記観察を含む）。
- **別称と起点〔伝聞・repo初出〕**：エンガ掘は**「エガ掘、江川などと呼ばれていたとも言われる」**〔伝聞。「エンガ」の語源をめぐる初出の別称群。断定は本文も留保〕。本流は**千川上水の豊島南長崎六郵便局北側から分水**、途中で千早高校西側・江古田駅・環状7号線武蔵野病院前交差点あたりからの支流を合わせ、北向きに石神井川へ向かう〔観察・読図〕〔起点位置の丰島南長崎六郵便局北側説は、[BLOG-103](BLOG-103.md)（東長崎3号踏切北）・[GOV-072](../gov/GOV-072.md)（エンガ堀=東長崎3号踏切北の起点）と対校すべき別観察。断定せず〕。
- **下流端の現況〔観察・repo初出〕**：石神井川にかかる**耕整橋の南側に大きく口を開けている排水口＝エンガ掘の合流点**。「そこそこの水量がある現役の暗渠」。円形排水口は増水時用と推定〔推定〕。
- **エンガ掘緑道〔観察・repo初出〕**：下流域は**「エンガ掘緑道」として一部整備**、一方通行道路2本の中央の緑地帯・歩道付き。向原団地（現コーシャハイム向原）付近から小竹向原駅北方の要町通りまで、遊歩道と道路の交互区間の現況を記録〔観察〕。
- **向原トンネル付近の旧流路〔観察・推定〕**：エンガ掘は向原小学校校庭下を通る**向原トンネル**入り口付近を横切って北へ流れていた〔推定〕。トンネル掘削で水路跡は失われている。直角に曲がる地点の行き止まり両側は崖で、「古い地図では行き止まりの先までエンガ掘か別れた谷筋があったようにも描かれている」〔読図・推定〕。
- **武蔵野病院前支流〔観察・repo初出〕**：遊歩道から西へ分岐する水路敷＝武蔵野病院前交差点近辺から流れてくる支流。ドラッグストアと工場の間の段差に沿って水路敷らしい空間が残る〔観察〕。小竹向原駅北側では昭和22年（1947）米軍空中写真で田んぼの間の水路として細かく分かれていた、西側の江古田からの流れは向原ゴルフセンターあたりで千川上水からの流れに合流していたようにも見え、古くは区境に沿って北へ流れていたようにも見える〔読図・推定〕。
