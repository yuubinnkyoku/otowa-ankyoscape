# [BLOG-004] 「水の行方を追って」東大下水

- 「水の行方を追って」『東大下水（ひがしおおげすい）―誤解を招く現代用語との意味の違い―』、2014年2月4日。
- https://wanjin.blog.fc2.com/blog-entry-26.html
- 谷端川（小石川）を西大下水、その東側から東京ドーム・後楽園方面へ進む水路を東大下水と整理する二次資料。
- 東大下水を、巣鴨・千石方面、六義園方面、西片方面、菊坂方面などの流れを集める水系として説明する。
- 同サイトの流路図には、第三者への提供・共有を想定していない旨の注意書きがあるため、**図そのものは本リポジトリへ転載せず、掲載元リンクのみ記録する。**
