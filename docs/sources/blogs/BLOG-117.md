# [BLOG-117] 産経新聞2026年8月22日「東京・北区、板橋区、豊島区…大雨」

- **書誌〔確認〕**：産経ニュースの報道記事（2026年8月22日21時19分配信）。2026-11-12に本文全文を直接取得〔[BLOG-115](BLOG-115.md)・[BLOG-116](BLOG-116.md)と合わせて2026年8月22日の報道記録群〕。
- **池袋駅地下構内の冠水〔確認：記事〕**：**冠水したJR池袋駅地下構内。規制線が張られ、駅員が排水作業を行っていた（8月22日午後5時30分、豊島区、読者提供の写真）**〔①**池袋駅直下の地下空間の浸水の写真付き報道記録＝repo初出**。②池袋駅は谷端川旧流路（西側・要町〜池袋本町）と水窪川谷頭（東側・東口）に挟まれた位置にあり、地下構内への浸水は周辺の谷地形と地下空間の対応の観察材料になるが、本記事は旧川筋に言及せず、**浸水経路（谷頭の地表水・下水道の満管等）は推定も残さず未解決とする**。③時間帯（17:30＝記録的短時間大雨情報〔17:17板橋区120ミリ以上〕の直後）の記録〕。
- **北区西が丘の冠水〔確認：記事〕**：警視庁赤羽署によると、22日夕、**北区西が丘1丁目で「車が動かなくなった」と110番**があり、運転手は自力で脱出。**一時的に道路が冠水し、車が故障したとみられる**〔西が丘は谷端川の北区区間（旧滝野川側流末に近い台地縁）に近い。冠水箇所と旧谷端川筋の対応は記事にないため断定しない〔[GOV-074](../gov/GOV-074.md)浸水履歴の更新版での対応確認が課題〕〕。
- **周辺自治体〔確認：記事〕**：戸田市・和光市を中心に道路冠水や車の水没の110番が数十件、人的被害なし〔埼玉側（新河岸川上流域）の記録〕。
