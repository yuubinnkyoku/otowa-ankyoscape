# [BLOG-228] 滝野川反射炉の完成時期と北区史の近代工場立地論（wheatbaku「幕末の大砲製造所⑧」）〔repo初出〕

- **直接確認（2026-11-15、open_url・本文全文）**: 気ままに江戸（夢見る獏）の「[滝野川・王子の近代工場の礎は滝野川大砲製造所（幕末の大砲製造所⑧）](https://wheatbaku.exblog.jp/32703421/)」（**2022年8月10日**）。同シリーズ②（関口大砲製造所）は[BLOG-227](BLOG-227.md)、⑨⑩は[BLOG-229](BLOG-229.md)・[BLOG-230](BLOG-230.md)として今回登録。
- **反射炉の完成時期〔確認：飛鳥山博物館図録の二次引用〕**: 滝野川反射炉が現実に完成したかは長く不明だったが、北区飛鳥山博物館発行「**近代工業のルーツ 滝野川反射炉展**」によれば、**最近の研究の結果、慶応2年（1866）10月頃に滝野川反射炉が完成したと考えられるようになっている**という〔**完成時期の研究値「慶応2年10月頃」はrepo初出**。[GOV-144](../gov/GOV-144.md)の慶応2年10月「武州豊島郡瀧野川村大砲御製造所江引入候千川用水稼水車之儀ニ付申上候書付」と**同一の年月**であり、一次文書の申上時期＝完成前後の運転開始期という対応が強まる。ただし大砲が実際に製造されたかは同展でも明確でない〕。錐台も設置され、全体で「滝野川大砲製造所」と呼ばれた。
- **北区史「近代工場のあけぼの」の引用〔確認：長文の二次引用〕**: 『北区史 通史編 近現代』の記述として、①**1872年（明治5）の冬に操業を開始した鹿島紡績所・1875年12月開業式の抄紙会社・1876年2月竣工の官営紙幣寮抄紙局**が王子・滝野川の近代工場の代表例、②立地は**水力（当時の主要動力源）と製紙用の多量の水**、**千川上水・石神井川の流末に位置する王子・滝野川で工業用水が入手しやすい環境**、③前提として**元治元年（1864）の滝野川村内（現・醸造試験場周辺）への大砲製造所設立計画**、翌年の**豊島村・王子村周辺の石神井川の拡幅・浚渫（通船化）**と、**錐台動力のための水車設置を企図した千川上水の分水・村内への新規堀割の工事**（『通史編近世』第八章第二節参照）、④**分水された千川上水の一部は石神井川に流下**、**跡地は陸軍省用地**となった、という内容を引用する〔**明治5年冬の鹿島紡績所操業開始・1865年の石神井川通船化と千川上水堀割の年次対応・千川上水残余の石神井川への流下・跡地の陸軍省用地化の一連の記述はrepo初出**。BLOG-127（慶応元年9月中旬〜11月末の工期）・BLOG-053（堀割の由来）と内容が連続する〕。
- **制限〔未解決〕**: ①「近代工業のルーツ 滝野川反射炉展」図録の書誌（展覧会の年・発行年・該当頁）は未特定で、完成時期「慶応2年10月頃」の出典論文・一次史料の確認が必要。**→ 第92回（2026-11-15）書誌特定済み: [BOOK-104](../books/BOOK-104.md)（東京都北区教育委員会・2016年10月・北区飛鳥山博物館秋期企画展・日本・ベルギー友好150周年）。出典論文の候補として [PAP-079](../papers/PAP-079.md)（馬場永子2014・所在のみ）を登録**。②北区史の該当頁・「最近の研究」の具体的な先行文献は未確認。③「千川上水の一部は石神井川に流下」の流量・経路（現・音無川への合流点か）は本文に具体がなく未解決のまま。
