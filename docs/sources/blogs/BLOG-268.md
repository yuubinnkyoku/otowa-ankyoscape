# [BLOG-268] まろん通信「小金井の水路跡」先駆別記事2本＋No.31「湧水の道」〔2013-14年の先駆記事と旧野川蛇行跡の観察〕

- **書誌〔確認: 本文全文3本・2026-11-22取得〕**: まろん通信（クマさん）のうち「小金井の水路跡」シリーズ（2016年開始）に先立つ先駆記事2本＝**[Vol.9「前原遊歩道もまた古い水路跡」（2013-11-18・archives/374）](https://koganei-kanko.jp/maron/archives/374)**・**[Vol.45「桜堤遊歩道、コレもまた古水路跡」（2014-04-30・archives/820）](https://koganei-kanko.jp/maron/archives/820)**とシリーズ坂下篇の**[No.31「湧水の道 その1」（Vol.562・2017-10-13・archives/7251）](https://koganei-kanko.jp/maron/archives/7251)**（[BLOG-264](BLOG-264.md)のVol.562本文取得済み記事）。
- **Vol.9前原遊歩道〔確認: 本文全文〕**: 「**古地図（昭和12年発行）を見ると、小金井市には水路が沢山ありましたが**」＋**前原町二丁目→一丁目→（霊園通りで一旦切れて「昔の溝が現れる」）→四丁目→東八道路・新小金井街道・小金井街道を越えて前原町五丁目までの遊歩道群**（「前原町二丁目遊歩道」→「前原町一丁目遊歩道」→「前原町四丁目遊歩道」→「前原町遊歩道」の標識名の変化）＋「**古地図と対比すると府中方面に繋がる水路ですが、水がどちらに流れていたのかは不明です。通った感じでは府中から野川に流れていたもののように感じました**」〔流向は「不明」と明記した上での筆者推感覚〕＝**前原町1〜5丁目の遊歩道群＝昭和12年（1937）古地図の水路跡で府中方面へ接続する長大水路の候補**＝シリーズNo.36〜39（Vol.914〜920）「前原町の遊歩道」の2013年先行記事。
- **Vol.45桜堤遊歩道〔確認: 本文全文〕**: 「**遊歩道に入ってしばらく歩くと「桜堤遊歩道」との標識、でもそれは武蔵野市の標識でここが小金井市との境界のようです。…小金井市に属する部分は約100mです**」＋「**古地図で確認すると確かに砂川用水の続きが流れていました。この先では深大寺用水とか呼ばれているようなので、この用水の末端は深大寺付近まで伸びているのでしょう**」＋「**玉川上水の南側を流れる砂川分水が南に流れを変えた付近から東に延びた水路がこの遊歩道となったようです**」〔「〜でしょう」「〜ようです」の推定文言〕＝**桜堤遊歩道＝砂川用水（砂川分水）の続きの末流で「深大寺用水」に接続する水路跡（小金井市側約100m・武蔵野市標識）**＝[BLOG-267](BLOG-267.md)No.24（2017年）の境村分水＝梶野町三丁目遊歩道→武蔵野市「桜堤遊歩道」の系譜文言と構造的に一致＝**2014年観察と2017年系譜特定の接続が成立する水路跡**〔同一水路の確認は両記事の対照によるが、位置・方向の一致から「一致候補」に留める〕。
- **No.31湧水の道〔確認: 本文全文〕＝野川旧蛇行跡の観察**: 「**今は河川改良工事でその面影はありませんが、かって野川は蛇行した幅の狭い川だったようです。「大川」と呼ばれたとのことですがなぜそう呼ばれたのか不思議な気がします。…大雨でも降ると氾濫したこともあったようで、かっては水量が多かったのかもしれません**」＝**野川の旧称「大川」呼称の伝聞文言〔repo初出候補・「とのこと」の伝聞であることを明記〕**。あわせて「**かっての野川の川幅や蛇行の様子を残しているのが「湧水の道」です。河川改修工事でまっすぐにしたため、蛇行した野川の河川跡が残り、そこを埋め立てて遊歩道としたものです**」＝**湧水の道＝河川改修（直線化）で残った旧蛇行跡の遊歩道化**＋「**鞍尾根橋から約100ｍ下流の左岸に…「湧水の道」と彫られた黒御影（斑糲岩）の石碑が雑草の中にひっそろと置かれています**」〔石碑の所在定点〕＋「**途中から遊歩道脇に水路が現れますが、この水は貫井神社から地下を通して導かれた湧水です。休みの日などザリガニを捕る子ども達で賑わいます。…水が戻るとちゃんとザリガニは復活します**」＝**貫井神社の湧水を地下導水管で引いた現役流水路と生物相（ザリガニ）の2017年観察**＋「**この左側は駐車場ですが、かって貫井プールがあったところです**」〔[GOV-502](../gov/GOV-502.md)の貫井プール（大正12年青年会自力建造・湧水引込・昭和48年6月閉鎖）の跡地整合〕。

## repoとの関連〔観察〕

- ①**野川の直線化＝河川改修の既往と旧蛇行の保存形態**＝[GOV-508](../gov/GOV-508.md)（野川改修・拡幅・蛇行修正・調整池化＝閉田の因果連鎖）の、普段は対岸に位置する「公園らしさ」の観察側の該当参照点で、旧蛇行の地上形が湧水の道遊歩道として残るメカニズムの記録。②**野川「大川」呼称**＝[GAZ-092](../gazetteers/GAZ-092.md)の小石川「大川」用例や「大堀」＝玉川上水の旧呼称体系（[BOOK-235](../books/BOOK-235.md)）と並ぶ川名の面での「大川」=大小対命名の材料の追加候補（伝聞文言で断定しない）。③**Vol.45桜堤遊歩道＝深大寺用水の末端観察（2014）**＝[BLOG-267](BLOG-267.md)（深大寺分水への名称変化の2017文言）・[BLOG-225](BLOG-225.md)（砂川分水＝深大寺用水への11分水一体化）の3witness構成＝**武蔵野市域の「桜堤」の名が千川上水桜堤（[GOV-341](../gov/GOV-341.md)）・玉川上水小金井桜堤とは別の第三次利用例（遊歩道名）であることの観察**。④前原遊歩道の府中方面長大接続＝仙川・野川・玉川上水のいずれの水系に属するかは流向不明のため帰属を保留＝「深大寺用水系」候補と [BLOG-267](BLOG-267.md)の井口新田経路との地理的近接の指摘に留める。
