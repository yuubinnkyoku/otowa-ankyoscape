# [BLOG-317] いけぶくろねっとの第2回シンポジウム告知 — R7.11.29開催説の根拠書誌

## 書誌〔確認〕

- 池袋の地域情報サイト「NPO いけぶくろねっと」（[BLOG-294](BLOG-294.md)＝大塚駅南口再開発告知で既出のサイト）の告知記事。**投稿日＝2026年11月4日**（datePublished=2026-11-04T12:30:57+09:00・投稿者ynegishi・カテゴリー「イベント・博物館・大正大学・巣鴨・文化財」）。約4,000字。
- 内容＝西巣鴨の大正大学でのシンポジウム「**種子屋街道の歴史を今に伝える地域に根差した種子屋の役割〜これまでとこれから〜**」が**11月29日13:00〜16:30に開催される**という告知。第1部＝報告・討議、第2部＝「榎本家店舗兼住宅および新座敷」の見学（見どころ解説）。
