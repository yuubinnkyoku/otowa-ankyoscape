# [BLOG-144] miwa3k「千川上水を歩く その２」（上鷺宮〜西巣鴨千川上水公園）

- **書誌〔確認〕**: 同シリーズ後半。中村橋駅西側から千川上水公園（沈殿池跡）まで。直接openで本文全取得。
- **〔観察・repo初出〕 九頭竜弁財天の移設先**: 中村橋駅西側の並木間の祠（渡邊龍神・弘法大師・子庚申・馬頭観音・子育地蔵を合祀）。**「元は富士見台駅前交差点付近に架かっていた九頭竜橋のあたりにあったものを移してきた」**〔[GOV-092](../gov/GOV-092.md)（九頭竜橋＝富士見台駅入口交差点）に**移設先（中村橋駅西側）を付け加える独立観察**〕。
- **〔観察・裏付け〕 中新井分水の分水路跡路地**: 富士見台駅〜桜台駅間で「中新井分水上新街分」「中新井分水下新街分」の**分水路跡が路地として現存**する観察（南側の水田・湧水池への補水）〔[GOV-005](../gov/GOV-005.md)（中新井村分水3か所）・[GOV-092](../gov/GOV-092.md)（上新街分水＝中新井川合流）の流路レベルの裏付け〕。
- **〔確認・引用〕 石神井川からの揚水補水**: 筋違橋付近は「明治以降に下流の工場で使用される水量が増加し、**石神井川からポンプで揚水した水を合流させて千川上水に補っていた**場所」〔[GOV-070](../gov/GOV-070.md)（1952年記録フィルム・揚水流入口＝豊玉北6-13）の系統について、**練馬駅前交差点付近（筋違橋）を合流点とする独立二次記録**。位置の同定は今後〕。筋違橋跡碑（[PAP-027](../papers/PAP-027.md)整合）も観察。
- **〔確認・引用・着手年次の新データ〕 清戸道解説板（平成16年3月・練馬区教委）**: 全文を採録。宝永4年（1707）灌漑許可・**水料は1反につき米3升・恩恵田は計100町歩**（[GOV-067](../gov/GOV-067.md)の元治元年数値と同じ系統）・**「この辺りは、昭和二十年代の終わり頃から、暗渠工事が始まりました」**〔**暗渠化着手年次について「昭和25年頃から」（[GOV-072](../gov/GOV-072.md)）とほぼ同内容の区教委解説板文言が確認された**。「27年3月着手」（[BLOG-113](BLOG-113.md)）・1952年着手（Wikipedia系）とも矛盾しない。着手年次の行政側表記が複数揃った点で重要〕。
- **〔確認・repo初出〕 桜台の桜の記念碑（昭和63年3月・練馬区教委）**: 「**桜台という地名は、千川上水沿いに植えられた桜並木にちなんでつけられた駅の名前によったもの**。記念碑は地元有志が区に寄贈」〔桜台地名＝千川上水桜並木由来説の初出。駅名→町名の順も明示。対照表に追記〕。
- **〔確認・repo初出〕 加賀藩下屋敷平尾邸の大池水源説**: 板橋区教委**平成29年3月**「千川上水跡」案内板（川越街道手前・水神祠脇）の全文を採録。**「板橋宿内に所在する加賀藩下屋敷平尾邸内の池泉回遊式庭園にあった大池の水源ともなっていました」**〔**千川上水が板橋宿の加賀藩下屋敷（平尾邸）庭園大池の水源だったとする官方解説板文言＝repo初出**。[BLOG-094](BLOG-094.md)の板橋火薬製造所用水・明治期水車と並ぶ板橋宿内の千川上水利用記録の補遺。平尾邸の所在・池の現況は要確認〕。同案内板は明治13年千川水道会社・明治40年飲料水停止（[GOV-056](../gov/GOV-056.md)・[BLOG-101](BLOG-101.md)整合）も記載。
- **〔観察〕 板橋駅前の築堤名残と谷端川との並行**: 板橋駅前で「**道路上がふくらんで凸状になっている。ここに築堤があって千川上水が流れていた名残り**」、右側の下り坂の先の低地が谷端川の流路。「**上水は丘の際・土地の高いところを、川は低いところを**」流れていたという地形観察〔千川上水と谷端川の並行関係（[GOV-073](../gov/GOV-073.md)・[BLOG-129](BLOG-129.md)文脈）を微地形レベルで記録した数少ない観察〕。
- **〔観察〕 その他**: 意匠マンホール（「千川上水」の文字を意匠化・「千」の文字と三重円など）、板橋駅〜埼京線で水路跡が分断、加賀藩下屋敷庭園や火薬製造工場への分水口は「痕跡は見つけられなかった」という否定的観察の明記、六義園送水バルブ・導水門（[GOV-092](../gov/GOV-092.md)・[BLOG-095](BLOG-095.md)整合）、「**六義園への送水管は付近の地下鉄工事の時に分断**されており現在は送水できない」〔分断時期・区間の特定は今後〕。
