# [BLOG-097] 葭窪橋と坂上水車の現地観察・公文書の写真採録

- **書誌**: 装丁家・大貫伸樹の装丁挿絵探検隊「[千川上水・坂上水車取水口、鎮守前水車](https://shinju-oonuki.hatenadiary.org/entry/20181013)」2018年10月13日。2026-11-11全文取得確認。昭和16年・1941年・2018年の写真を掲載。滝島俊のコメント（Facebook）を多数引用。
- **〔確認・観察〕** **葭窪橋**（柳沢4丁目・千川上水と武蔵野市八幡町〔旧「葭窪」〕の境）。北岸一帯は旧「葭窪北台」。**ここが坂上水車の取水口**とみられる。昭和31年の地図では「保谷二小通り」が千川上水まで直通していた（武蔵野運動場建設で分断）〔確認：筆者の地図読み・現地観察／推定：取水口の位置〕。
- **〔確認・二次〕** **明治40年（1907）当時の保谷村には2か所の水車があった**：**保谷村大字上保谷新田字鎮守290番地**と**同字坂上57番地**。昭和12年の地図に水車記号と用水路（葭窪橋あたりまで）、昭和31年の地図に「坂上57番地」がある〔確認：筆者による地図・絵図読み／未確認：地図の版本〕。
- **〔確認・史料写真〕** **平井家が知事へ提出した「公有土地水面使用願」控（昭和19年〔1944〕）の写真**を掲げ、**「水車営業地五七番地」から道路北側へ水路が引かれている**ことを示す。水路跡は**道路と生け垣の間の1メートル幅の空間**として現地で残存し、**都有地**とみられる〔確認：文書写真・現地聴取（住民が水路跡と説明）／未確認：使用願の原本の所在〕。
- **〔確認・観察〕** **こいこい橋**（新柳沢団地・ひょうたん公園の南）の特定と、**坂上水車場跡の一角を路地で一周する観察**（水車場跡は10軒ほどの民家に細分化、水路跡・出口側の痕跡は不明）。**1941年撮影の坂上の水車場写真**・**明治39年測図に「工場、鉄工所」記号（柳橋交差点と阿波洲神社の間＝鎮守前の水車工場〔明治44年に北多摩郡内で一番の生産額と伝える〕の候補）**〔確認：筆者観察／推定：鎮守前水車の比定〕。
- **〔未解決〕** 「こいこい橋」の橋名の由来と表示、葭窪橋の現況、字鎮守290番地の現在位置の確定、明治39年地図の工場記号と鎮守前水車の同一性。
