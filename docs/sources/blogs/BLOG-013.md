# [BLOG-013] 「神田川茗荷谷支流（仮）の底力」（暗渠さんぽ、2015年）

- 「暗渠さんぽ」2015年5月5日、茗荷谷支流（仮）の再訪記事（2010年記事の続編）。
- [神田川茗荷谷支流（仮）の底力](https://kaeru.moe-nifty.com/ankyo/2015/05/post-6c3a.html)
- 筆者は仮称「神田川茗荷谷支流（仮）」を継続使用する。**人参川・古茗荷谷川の名称は本記事の取得テキストには現れない。** 2026年10月23日の横断調査文書の「荷風の人参川にも言及する」との記述とは一致しないため、引用の際は本ファイルの読取を優先する。
- 経路・内容メモ：茗荷谷駅そばから谷が始まる→伝明寺付近の湧水（清水谷）→拓殖大学敷地内の大きな池と隣の池（文明開化期の地図表示）→拓殖大学西側の谷戸（文明開化期の地図では水路の描画あり）→小石川車両基地に飲み込まれた本流筋→車両基地下流の蓋暗渠→神田上水の道を渡り→小桜橋下に大きめの合流口（筆者は「付け替えられたのかもしれない」と推測する）。
- 筆者の地図読取メモ：江戸期の絵図ではこの谷に「茗荷谷」と書いてある、と記す（谷名の記載であり、河川名の記載ではない）。明治期の地図では谷に水田と小川、池が複数あった、と記す。
- **本記事は谷の呼称・経路の記録であり、人参川・古茗荷谷川との同一性の証拠ではない。** 写真の転載はしない。
