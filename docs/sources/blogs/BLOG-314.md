- **七月の滝野川村報告と八月十五日の再任命〔#73〕**: 「七月に滝野川村（現・酒類総合研究所東京事務所）に千川上水を引き込んで水車を設置し、反射炉錐台等を築けば永久に使える場所と、と報告を出している」＋引用「滝野川村地内に反射炉錐台等を建設すれば、水利の便は当然よろしく…先ず御勘定方支配向きの役人を派遣して実地見分し、分間測量等をさせましたところ、**同村耕地の掘割に千川上水を引き入れ水車仕掛けにすれば適切な場所となるはず**…」。そのうえ「1864元治元年八月十五日、幕府から小栗忠順にあらためて『**大小砲鋳立て御用向き、すべて重立(おもだ)ち取り扱わるべく候事**』（『陸軍歴史』巻七）が命じられた」〔**五月八日任命→七月報告→八月十五日再任命という月単位の順序はrepo初出の記述**。「七月」はコラムの文脈上元治元年七月扱いだが、[GOV-144](../gov/GOV-144.md)の**慶応元年（1865）7月伺（多010688「滝ノ川村地内江反射炉并大砲錐入水車取建王子川筋通船路取開ニ付伺」＝「掘割に千川上水を引き入れ水車仕掛け」に酷似）**との対応候補を併記し、元治元年七月報告と慶応元年七月伺が別文書か同文書かは断定しない。GOV-326「子七月＝元治元年」候補（第140回追記）の文書位置とも整合〕。
- **「圦樋皆明け」要求と作事奉行の拒否回答〔#73〕**: 千川上水の水源が玉川上水からの保谷分水であるため「江戸城や丸ノ内の大名屋敷、日本橋をうるおす玉川上水が優先され、千川上水への水量は厳しく制限されてきた」ことを踏まえ、「**小栗は勘定奉行立田主水正を通じ玉川上水を管轄とする作事奉行へ、制限されている千川上水への取水口を全開とする『圦(いり)樋(どい)皆(みな)明(あけ)』を依頼したところ、『千川へ皆明けにしたら江戸城内や江戸の町内に支障が起こるから、新規のそういう事業はとても認められない』という返事があった**」〔**「圦樋皆明け」要求→玉川上水側（作事奉行）の江戸城内・町内支障を理由とする拒否という交渉の具体的な往復はrepo初出の記述**。「圦樋」語自体はrepo既出（121回・105回ノート）だが拒否回答文言は既存資料群にない。立田主水正の仲介役という人名もgrep確認でrepo初出〕。
