# [BLOG-241] わんじん「板橋区の逆川たち」シリーズ（2025-03-12〜04-09・全5本）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文・全5本）**: wanjinが2025年3〜4月に連載した「板橋区の逆川たち」シリーズ5本: entry-586（2025-03-12・蓮根川傍流）・entry-587（2025-03-19・蓮根川傍流つづき）・entry-588（2025-03-26・前谷津川）・entry-589（2025-04-02・梶谷津川）・entry-590（2025-04-09・前谷津川下流）。いずれもFC2の**カテゴリは「荒川水系」**（entry-586/590で各ページのCategory表示を直接確認）。
- **「逆川」の用法〔repo初出の用語整理〕**: 各記事の冒頭定型文「**『荒川』・『新河岸川』が造った低地に、南側から北上して流入する“逆川”たちの流れを堪能いただきたく、板橋区内の河川を複数紹介しています**」。wanjinの「逆川」は**荒川・新河岸川低地に南から北へ流入する北流河川の総称（形容表現）であり、特定河川の固有名ではない**〔5本すべてに同じ定型文。この用法の解明は、[GOV-157](../gov/GOV-157.md)が残した「wanjin『逆川』カテゴリ8本」の構成問題に直結する（下記）〕。
- **シリーズ対象河川〔ページ記載〕**: ①**蓮根川の傍流**（entry-586/587）: 単純な支流と思われた流れが「蓮根川緑道」と命名されている事実にぶつかり、「傍流の蓮根川」は概ね3つの流れで構成され、東坂下2丁目で本流の蓮根川に注ぐ。②**前谷津川**（entry-588/590）: 東武東上線下赤塚駅または地下鉄赤塚駅の西北側、板橋区赤塚新町2丁目等から始まり約5km弱を北へ流れ高島平で新河岸川（新河岸運河）に合流する灌漑用水路。**出井川等と一緒の1965年に一級河川となったが、1960年代から宅地開発で生活排水で汚濁し、昭和50年代に出井川・蓮根川ともども暗渠化、1984年に全区間暗渠化、全区間暗渠化に先立つ1977年に一級河川指定廃止**。かつての徳丸ヶ原（高島平）の水田灌漑に使用。梶谷津川との合流地点寸前に前谷津川緑道の銅像、合流点200m東に黄金湯。③**梶谷津川**（entry-589）: 前谷津川の最大支流。最上流部は二筋が併行し、長い方は川越街道の南側・練馬区北町8丁目から始まる〔いずれも四河川（水窪川・弦巻川・谷端川・千川上水）のスコープ外の出井川系。年次の一次典拠は本文に示されず〕。
- **FC2カテゴリ「逆川」（8本）の構成解明〔確認: 2026-11-15にカテゴリ頁を直接取得〕**: wanjinブログのカテゴリ「逆川」は8本で、**カテゴリ頁（blog-category-10.html）の現在の収録は①さいたま市北区の逆川（さかさがわ）シリーズ5本（entry-32〜36・2013年）＋②上尾市の『逆川』シリーズ3本（entry-320〜322）＝計8本**。**「板橋区の逆川たち」5本（entry-586〜590）はカテゴリ「逆川」ではなく「荒川水系」に収録されており、カテゴリ計数に含まれない**〔第98回の[GOV-157](../gov/GOV-157.md)が「wanjin『逆川』カテゴリ8本（未取得）」と記録した未解決の構成を、カテゴリ頁の直接取得で確定〕。すなわちwanjinブログの「逆川」は、①埼玉県（さいたま市北区・上尾市）の**固有名「逆川（さかさがわ）」のカテゴリ**と、②板橋区の**北流河川の総称用法**（本シリーズ）とに使い分けられており、**滝野川村小字「逆さ川」（GOV-157）や谷端川支流「逆川」（[BLOG-087](BLOG-087.md)）とはカテゴリ・用法いずれの次元でも直接対応しない**〔対応なしの確認＝陰性記録〕。
- **制限**: 出井川・蓮根川・前谷津川・梶谷津川はいずれも四河川のスコープ外（荒川水系の直接支流側）。登録の意義は「逆川」用語の解明・GOV-157未解決の解消に限る。河川年次（1965年一級河川・1977年指定廃止・1984年全線暗渠化等）は wanjin の二次記述で、出井川・蓮根川・前谷津川の公的資料（板橋区・東京都）での照合は今後の課題。entry-586〜590の個別記事の本文は保存済み・個別の資料化はスコープ外とする。
