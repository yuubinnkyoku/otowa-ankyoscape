# [BLOG-258] Natrium.jp「善福寺川周辺の水路敷群（高野ヶ谷戸・上荻と西荻北）」（2021）〔repo初出・[BLOG-249](BLOG-249.md)・[BLOG-250](BLOG-250.md)・[BLOG-254](BLOG-254.md)の高野ヶ谷戸支流群レーンの網羅掃引〕

- **書誌〔確認: 本文全文2頁・2026-11-22取得〕**: 同カテゴリ内「高野ヶ谷戸」（2020/12/26・2021/4/21・4/24・5/29撮影）と「上荻と西荻北の水路敷」（2021/5/3ほか撮影）〔BLOG-254目録の「善福寺川上流」のうち未収録だった2頁〕。
- **高野ヶ谷戸の地名構造〔確認〕**: 「高野ヶ谷戸（こやがいど）はこのあたりの旧字名で、**『ヶ谷戸』を『がいど』と読むのは杉並の方言**だという」「**大田黒公園あたりを中心とした谷戸地形に付けられた地名**らしい。近所の『大谷戸』は『おおやと』と読まれているようだが、**古地図では大ヶ谷戸とかかれているので、かつてはおなじように呼んでいたかもしれない**」〔[GOV-490](../gov/GOV-490.md)（風土記の「がいど」読み）と対照する観察。**荻窪駅北には対応する中谷戸・小谷戸の旧字名があるが、こちらは古地図でも『ヶ』が入っていない**＝谷戸地名群の表記対照〕。
- **上流3支流の流路〔確認・観察〕**: 「上流部は三つの流れに分かれており、**それぞれ西側から大田黒公園、天沼橋、杉並区中央公園の方へ伸びている**」〔BLOG-250が観察した西側・中央・東側の3支流（仮称）の上流端側。**杉並区立中央図書館のテラスから読書の森方向を見たところに水路敷の上流端**があり、「**かつてこのあたりに湧き水があったということで、現在は改めて公園に作られた人工の池**」＝**読書の森の湧水→人工池**の観察〕。**宝暦6年（1756年）造立の馬頭観音**（東寄り支流沿い）〔庚申系石塔の追加〕。大田黒公園＝音楽評論家大田黒元雄氏の屋敷跡の公園。
- **田端神社と地名変遷〔確認・repo初出候補の順序説〕**: 「**この神社は元は菅原道真を祀る北野神社だったという。その神社が田んぼの端にあったので田端天神となり、その田端が地名になったという順序**らしい。**東西に村が分かれていたことから東田町、西田町となり、間にあった成宗町と一緒になって成田東、成田西になる**という結構な変遷」〔**神社（北野神社）→田端天神→田端地名→東田町・西田町→成田東西**という変遷の順序文言。成宗・成田地名合成の系譜（成宗＋田端＝成田）の初出一級の説明〕。
- **四面道口分水との接続〔確認〕**: 天神橋公園を流れてくる新堀用水との合流点の右岸旧流路から遡行、**擁壁下を水路敷が進み崖上には田端神社（台地南端）**→3差路（左右の道はいずれも元の水路）→旧荻窪団地（現シャレール荻窪・シティテラス荻窪）の脇〔[BLOG-256](BLOG-256.md)（新堀用水の善福寺川分岐）・[BLOG-257](BLOG-257.md)（四面道口分水）と空間的に接続する実走〕。
- **上荻と西荻北の水路敷〔確認・観察〕**: 西荻窪駅北側の左右両岸の細かい水路敷群＝**神明橋西側**（封鎖された排水口・河川敷より水路敷が低い＝護岸工事前は開渠で川に流れ込んでいた可能性）・**鍛治橋東側**（蓋暗渠が青梅街道の延長線まで・「これが分水口だったのかどうかはわからない」）・**中田橋北側**（右岸から合流・途中で南へ直角に曲がる）など複数の小支流の蓋暗渠観察〔善福寺川上流左岸の水路群の掃引〕。
- **荻外荘の池・放水路〔確認・repo初出候補〕**: 高野ヶ谷戸支流から松渓橋に向かって**放水路**があった観察（「古地図などには描かれていないが」）・近衛文麿旧邸**荻外荘（てきがいそう）**の公園前の遊歩道「**かつてはここに池があったという**」・松見橋の支流に向かう排水口の上の蓋暗渠＝放水路・支流の善福寺川との分岐点は荻窪第二児童遊園・春日橋の南側で本流と分かれる支流〔荻外荘の池の存在文言は、水窪川・谷端川レーンで収集してきた著名屋敷の池の記録群と同型の記録対象〕。
