# [BLOG-131] としま案内人ガイドツアーの千川上水跡観察（南長崎〜千川駅）

- **資料〔確認：公開記事本文〕**：「読んで♪観て♪歩く」[千川上水跡まち歩き（その２）](https://ameblo.jp/kak-dela/entry-12847637624.html)（**2024年4月8日**）。豊島区ボランティアガイド団体「としま案内人長崎町」のツアー参加記。〔確認：本文／ガイド説明は伝聞の体裁〕
- **水番所跡〔観察（ガイド説明の二次記録）〕**：**南長崎6丁目交差点（千川上水が直角に曲がる地点）の現セブンイレブン付近に水番所があり水盗人を見張っていた**と説明。地主の辻（亀ヶ崎?）に「**橋本屋**」という屋号の店があった（筆者所有の1987年住宅地図では「雑貨店」表記）。水番所の記述は[BLOG-094]・[MAP-064]に既出だが、**現在地標識（セブンイレブン）への具体化**は本記事による観察記録。
- **千川通りの呼称差〔観察〕**：都道鮫洲大山線の道路標識が途中で切れるのが終点で、**地元では左折して板橋方面へ向かう道をこそ「千川通り」と呼ぶ**（この先の方が暗渠化が遅く水路が見えていた時代を知る人が多いため）という説明。筆者自身の認識（西武線沿い＝千川通り）との食い違いの記録。〔観察：呼称の世代差・地域差の聞き取り〕
- **築樋（つきどい）跡の観察〔観察〕**：**明豊中学校付近で歩道（上水の水路跡）が車道より高くなっており、一定勾配維持の調整**という説明。ミニストップ右側路地のきつい下り坂も水路跡。「水道端地域安全センター」の場所も取水口（[BLOG-092]の「スイドウバタ」地名の地域内別実例）。〔観察／解釈は筆者とガイド〕
- **その他〔伝聞・推定を含む〕**：**「千早」は千川の流れが早いことからの命名**という説明（ガイド伝聞・要裏付け）。千川親水公園で**橋の遺構が「せっかく残ってるのに放置」**されている観察（橋名未特定・[GOV-080]区域）。**昭和初期とされる千川上水現役期の写真に写る寄棟屋根二階建ての建物が現存**（旧池田書店・現さくら小学校脇）という案内人の指摘〔伝聞：元写真の所在・撮影年は未確認〕。
