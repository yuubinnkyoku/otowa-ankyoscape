# [BLOG-069] 逃避の散歩 39．谷端川緑道

- **直接確認（2026-11-11、open_url・本文全文）**：池袋駅西口から西武池袋線線路際の緑道入口（宮下橋）に入り、南緑道・北緑道を通って下板橋駅まで約45分で全走した観察記録。
- **橋跡の目印の連続〔観察〕**：橋跡を通るごとに欄干状の柵・車輪止め・石柱・橋名標など目印が置かれているとして、**宮下橋・並木橋・羽黒橋・八幡橋・霜田橋（立教通り）・丸山橋・長崎橋・日ノ出橋・北新井橋・東あづま橋・高松橋・境橋・上かみの橋・中上橋・御獄橋・南橋・境田橋・他領橋・熊野橋・前田上かみの橋（以上・南緑道）→ 前田橋・北浦上橋・北浦橋・中丸橋・金井窪橋・西前橋・豊橋（以上・北緑道）**の順で通過したことを記す。〔橋名・配置は [BOOK-062](../books/BOOK-062.md)『旧谷端川の橋の跡を探る』の集録と重なるが、2022年5月時点の橋跡目印の設置状況を伝える独立の観察記録〕
- **緑道の縦断差異〔観察〕**：**南緑道は赤系タイル・レンガ造り風の柵**、**境橋以降（豊島区／板橋区境沿い）は柵が鉄製**、**北緑道は白色系タイル**で「谷端川児童遊園」の看板を付けた鉄柱が門代わり、と素材・色調が区間で変わることを記す。〔南緑道整備（昭和41年・[GOV-008](../gov/GOV-008.md)）と北緑道整備（昭和46年・[GOV-009](../gov/GOV-009.md)）の時期差に対応する観察として記録価値がある。いつ・誰が目印を設置したかは記事にない〕
- **親水施設〔観察〕**：霜田橋（立教通り）付近と要町一丁目交差点を渡った先の2か所の親水公園で**「親水施設稼働中止」の張り紙**を確認（2022年5月時点）〔谷端川緑道の親水施設の現況観測。稼働中止の開始時期・理由は不明〕
- **その他〔観察〕**：金井窪橋先で下水道整備工事の看板。境橋以降は板橋区側街灯「庚申通り商店会」・豊島区側「池袋坂下通り」の街灯名称板が並ぶ。
