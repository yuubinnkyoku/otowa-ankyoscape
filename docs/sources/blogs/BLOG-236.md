# [BLOG-236] わんじん「東大下水：六義園支流（仮）」（2014-02-18）〔訂正前の初出記事〕

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文）**: wanjin東大下水カテゴリ7本のうちの六義園支流初出記事。冒頭に「**2014年7月16日、当該記事を訂正致しました。訂正した記事はこちらです**」とentry-49（[BLOG-240](BLOG-240.md)）へのリンクがあり、**本記事は訂正版で明示的に置き換えられた旧版**である〔両記事を対で記録する〕。
- **六義園の造営〔ページ記載〕**: 徳川綱吉の側用人・柳沢吉保が**1695年（元禄8年）に加賀藩の旧下屋敷跡地を綱吉から拝領**し、**約2万7千坪**の平坦な土地に土を盛って丘を築き、**千川上水を引いて池を掘り、7年の歳月**をかけて回遊式築山泉水庭園を造った〔標準的な沿革の記述〕。
- **六義園支流＝千川上水分水の余水で始まる唯一の支流〔wanjin観察・repo初出の整理〕**: 「**東大下水の他の支流は、支流の周辺にある農業用水や雨水などを集めて流れが始まっているのに対し、六義園の支流は、千川上水から引き込んだ分水の余水によって、流れが始まっています**」と整理〔wanjinの分類観察。明治40年（1907）に千川上水からの六義園への給水が行われていたことはBLOG-113略年表の「岩崎邸六義園、王子方面の用水は存続」等の既収録と接続〕。千川上水分水が中山道の脇近辺を流れていたとする推定も記す。
- **訂正前の流路〔のちに訂正〕**: 六義園からの余水は不忍通りを渡り、昭和小学校敷地の一部（「昔から放っぽられていて怪しい雰囲気」）をかすめ、東洋文庫と昭和小学校の間を東南へ流れる流路を提示〔**この流路はentry-49（BLOG-240）で「下屋敷内の屋敷地となり、存在しない可能性が高い」と訂正された**。訂正の経緯・根拠はBLOG-240参照〕。
- **柳沢吉保の伝記的整理〔ページ記載〕**: 宝永3年（1706）大老格、宝永6年（1709）綱吉薨去後に失脚して隠居、晩年は六義園で過ごした。赤穂事件の裁断への関与を指摘する叙述もあり〔伝記・忠臣蔵像はwanjinの読みによる二次整理〕。
