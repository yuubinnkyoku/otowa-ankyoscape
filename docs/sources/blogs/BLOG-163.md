# [BLOG-163] 地図子「弦巻川を歩く」

- **直接確認（2026-11-13、Wayback 20241213154433 スナップショット・本文全文）**：2021年3月の弦巻川全流路（江戸川橋→元池袋史跡公園）遡行記録。同一筆者の谷端川記事（[BLOG-132](BLOG-132.md)）と別記事で、弦巻川単独記事はrepo未収録だった。
- **1932年暗渠化工事開始〔二次叙述〕**：「弦巻川は1932年に暗渠化の工事が始まった」。[BLOG-001](BLOG-001.md)（Natrium・弦巻川1932年流路付け替え）と整合する別出典の二次記録（依拠は本田創『失われた川を歩く 東京「暗渠」散歩 改訂版』2021）。
- **江戸川橋排水口の同定〔観察〕**：神田川江戸川橋地点の排水口2つの同定（交差点西側＝水窪川、東側＝弦巻川、**両川は地下で交差**）。[BLOG-076](BLOG-076.md)の観察と整合。
- **雑司ヶ谷の井戸ポンプ・掘り抜き井戸〔観察・repo初出の現役使用記録〕**：支流沿いの此花亭・茶亭なか山に**昔ながらの井戸ポンプが置かれ、現在も墓参りの人が実際に使用**（2021年3月）。[BLOG-002](BLOG-002.md)（Natrium・此花亭周辺）の追加観察。さらに弦巻通りに入る前の小道で**掘り抜き井戸があり「雨が少なかったこの日も水がちょろちょろと流れている」＝湧水の2021年時点の現役観察**。弦巻川流域の湧水・井戸の分布（[BLOG-052](BLOG-052.md)弦巻川断章の自噴井戸等）に2021年3月の独立時点を追加。
- **弦巻通りは付け替え後の流路〔二次叙述〕**：弦巻通りは暗渠化の際に流路を付け替えられているため本流路ではない（最初の1本南の小道が本流）＝BLOG-001・BLOG-063と整合。
- **元池袋の池〔二次叙述〕**：元池袋史跡公園の池は雑司ヶ谷村にあった池と言われるため**池袋とは関係がない可能性が高い**＝[BLOG-063](BLOG-063.md)（文春・丸池跡でない説）と整合。
- **制限〔未解決〕**：支流（雑司ヶ谷霊園付近が始まり）の流路の同定は記事の範囲では未確定。
