# [BLOG-290] 池袋タイムズ「南大塚の「大塚台公園」がリニューアルへ。2026年11月に着工予定」〔大塚台公園リニューアルの第三次（時点別）報道記録〕

- **書誌〔確認: ブログ本文全文・2026-11-23取得〕**: 池袋タイムズ（大塚・池袋のローカル情報メディア）の記事。**公開日2026年9月5日〔datePublished=2026-09-05〕**・カテゴリ「池袋ネタ」。 https://ikebukuro-times.com/archives/otsukadai-park2026.html 。
- **開園とSL〔確認: 本文・文言〕**: 「大塚台公園が開園したのは、**1973年（昭和48年）2月**」「公園の中央にある蒸気機関車も印象的ですよね。**このSLは、身近な場所で見られるようにと、1974年（昭和49年）に北海道から運ばれてきたもの**だそうです」＝**開園月「2月」とSL搬入年「1974年・北海道から」**〔区公式ページ（[GOV-519](../gov/GOV-519.md)）には開園月とSL来歴の記載なし＝本報道が現時点での唯一の補完文言。背景にあるSLの形称号（C58 407号機）は[次項](BLOG-291.md)の鉄道系報道〕。
- **整備内容〔確認: 本文・区公式サイト引用写真〕**: 「**今回の工事では、既存のトイレを除く施設をすべて解体**」「主な施設＝2面の球技場／ウォーターパーク遊具／インクルーシブ遊具を備えた遊具広場／だんだん花壇／多目的広場／大型複合遊具／都電側の新しい入口とテラス」「**水遊びができる「ウォーターパーク遊具」は、蒸気機関車をモチーフにしたデザイン。夏には水が噴き出し、夏以外は複合遊具として一年を通して遊べる**」「球技場は2面設けられ、**高さ6～10mのフェンスで囲まれます**。地面には**ゴムチップ舗装**」「遊具広場には…砂場やブランコ、滑り台、**回転ジャングルジム**など」「**ミスト付きの日陰**も設置」「**2026年9月には、リニューアル後の完成イメージが公開**」「**工事スケジュールは、2026年11月に着工予定。完成・リニューアルオープンは、2028年3月末を予定**」＝**区の工事ページ（[GOV-520](../gov/GOV-520.md)・更新11月11日）とほぼ同期・着工月単位で一致**。
- **寄付（クラウドファンディング）〔確認: 本文〕**: 「**ウォーターパーク遊具については、2026年9月9日からクラウドファンディングによる寄付募集が始まる予定**」＝[GOV-521](../gov/GOV-521.md)（GCFページ）の開始予定時点の報道記録。
