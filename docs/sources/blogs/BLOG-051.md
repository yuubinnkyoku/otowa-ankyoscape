# [BLOG-051] toshima_lab「江戸時代から残る池袋の道（西の野道）」

- **直接確認（2026-11-11、open_url・本文全文）**：2023年6月14日投稿。『豊島区史 地図編（上）』池袋村図（P18）に描かれる最も西側の「野道」の道筋読図。
- **野道の経路〔二次転記＋読図〕**：中丸道（坂下通り〜常盤通り）から大明小（みらい館大明）への分岐点を経て、池袋三丁目公園辺り→ルーテル教会→洞雲寺・光文社の東を抜けて南下し、江戸川乱歩邸方面へ。地形としては谷端川との高低差がある部分で、歩きやすい道筋を辿った結果の可能性を筆者が挙げる。
- **明治〜大正地図の記号変化〔読図〕**：対象地点の西側に明治42年地形図で独立樹（針葉樹）記号、大正5年図で「堆土」記号、大正10年図と『西巣鴨町事情明細図』で「神社」記号が現れる。村絵図に「庚申」「地蔵」等の目印が描かれない点も指摘。
- **遊歴雑記の「加味の天神」〔言及〕**：B地点西側に「上」という字名が存在したこと、「加味の天神」が誤記・別地点か含め未確定の関心として挙げる。大正5年図のB地点南東の「神社」記号の正体も未確定とする。
- **制限〔未解決〕**：野道の復元は筆者による読図で、池袋村図原本の直接確認は別途必要。「加味の天神」「上」字名の対応は未検証。
