# [BLOG-155] 寅さん歩 その25 谷端川の流れを歩くー1（平野武宏）

- **直接確認（2026-11-13、Wayback id_付きURLでPDF本文全文取得）**：[Wayback保存版 2024-06-10](https://web.archive.org/web/20240610053135/http://shonan-fujisawa.jp/watanabe/wpage5142.pdf)。寅さん歩その25の第1回（千川駅〜千川長崎分水〜粟島神社〜椎名町駅）。第43回で-2〜-4を取得済みだったシリーズの残り1回を取得。谷端川を「千川上水の長崎分水を源」と紹介。
- **千川駅付近の「千川上水跡」説明板の全文〔確認〕**：豊島区千早町・千川駅地上出口から要町3丁目交差点手前の説明板。①元禄9年（1696）幕府の命により**河村端賢**が設計、**千川太兵衛・徳兵衛の請負**〔「河村端賢」表記はGOV-004「河村瑞軒」設計伝承の別表記。請負人を太兵衛・徳兵衛の2名とする文言〕。②**全長は7里6町39間（約28km）**、保谷村で玉川上水から分流、湯島聖堂・上野東叡山・小石川白山御殿・浅草寺御殿に給水。③宝永4年（1707）流域の村々の嘆願で農業用水利用が許可（区域では長崎・池袋・巣鴨の各村）。④享保7年（1722）江戸への給水中止、**「安政8年（1779年）に再開」**〔元号と年次の不整合（安政8年は1855年。安永8年1779の誤記と解される）を説明板の文言としてそのまま記録し、修正しない〕、天明6年（1786）上水として廃止。⑤灌漑利用は継続、明治期以降は工場の産業用水。⑥**上水の堤には千数百本の桜が植えられ、戦後の都市化の進行とともに区内では昭和2年にほとんどが伐採**〔「区内では昭和2年（1927）にほとんど伐採」はrepo初出の文言・年次〕。⑦平成元年（1989）上水跡に区立千川親水公園開設〔GOV-080と整合〕。
- **千川長崎分水〔確認：筆者の観察〕**：要町通りの要町3丁目交差点で分岐して右折・千川駅方面へ向かい、本流は交差点を直進〔BLOG-042「要町三丁目交差点=長崎分水分水点」と整合〕。千川駅出口3の脇右側の道から粟島神社へ。
- **粟島神社・弁天池〔確認〕**：豊島区要町2-14-4。谷端川のもとの源は「**粟島神社の分水池（弁天池）**」〔「分水池」呼称はrepo初出候補〕。**弁天池は湧水とのこと**〔BLOG-135こだまコメントの聴取情報を筆者が「資料」依拠で確認側に記述〕。弁天池では農作祈願の雨乞い、流域各所に野菜の洗い場や水車、夏は蛍、蜆・鮒・鯉・鰻・ドジョウ採り〔BLOG-152西巣鴨説明板と同系統の記述〕。元禄9年に千川上水とつなげられ、**奉行所に願いを出し水料を収めることを条件に千川上水から田用水を引き込んだ**もので、長崎村・池袋村の田畑を潤した〔水料条件の文言は既存整理を裏付ける〕。
- **つつじが丘アトリエ村跡（千早2-30）〔確認〕**：**昭和13年（1938）に10棟建てられ、道路沿いにつつじが植えられていたので「つつじが丘アトリエ村」と呼ばれた**〔BLOG-138でアトリエ村地点は既出だが、1938年・10棟・命名由来の細部はrepo初出〕。大正末〜終戦頃の池袋モンパルナスの芸術家拠点。
- **上流部の橋数〔確認：友の会資料の引用〕**：**古地図（明治44年）によると水源から椎名町駅付近までに6つ位の橋**があった。橋名はなく、川幅1〜2m弱で農家が田畑に往来する個人の橋〔区間別橋数データとしてrepo初出。BLOG-066の明治44年逓信局地図依存記述（BLOG-065）と整合する読み〕。
- **周辺記録〔確認〕**：長崎神社（長崎1-9-4。江戸中期は十羅刹女社、神仏分離で氷川神社を経て長崎神社に、本殿嘉永2年建立・長崎獅子舞は元禄年間始まりの伝承）、金剛院（長崎1-9-2。大永2年建立・長崎神社の別当寺、明治34年寺内に長崎村役場）〔谷端川流域の村社・寺院の由緒で、橋名由来（宮下橋=長崎神社下の橋）の文脈資料〕。
- **制限〔未解決〕**：説明板の設置主体・設置年の直接確認。昭和2年桜伐採の行政文書。明治44年古地図の原本照合。
