# [BLOG-226] ゆる歴史散歩会「滝野川反射炉とは？」（2025年）〔repo初出〕

- **書誌〔確認: 2026-11-15・本文全文取得〕**: ゆる歴史散歩会（東京の歴史散歩サークルの解説サイト）の[「滝野川反射炉とは？王子分水・小栗上野介・錐台をたどる北区歴史散歩」](https://yuru-rekishi-sanpo.com/250318-takinogawa)。ページの公開日時メタは**2025年2月18日**（URLスラッグは250318で食い違いあり・成立年の細部は断定しない）。同サイトは[元池袋から弦巻川を歩く](https://yuru-rekishi-sanpo.com/250314-tsurumaki-river)（[BLOG-047](BLOG-047.md)）・[護国寺・池袋](https://yuru-rekishi-sanpo.com/251117-gokokuji-ikebukuro/)（[BLOG-106](BLOG-106.md)）で既収録。
- **錐台の水車動力としての王子分水〔確認〕**: 幕末の反射炉計画で大量の水が必要だった主な理由は「**反射炉そのものを動かすためではなく、錐台を動かす水車の動力を確保するため**」と整理〔砲身の内腔を仕上げる加工機械＝錐台の水力駆動という**機能面**の説明。BLOG-053/127の説明板・北区史系の記述に対して、目的構造を明示した2025年の二次解説〕。
- **1864年上申と工事の進行〔確認〕**: 元治元年（1864）に小栗忠順（勘定奉行）が滝野川村の反射炉＋錐台つき大砲製造所を計画し、「**1864年の上申と、その後に水路や施設の工事が進められたことが史料・研究で確認されています**」と記す〔[GOV-144](../gov/GOV-144.md)（NDA一次記録群: 元治元年12月上知達→慶応元年7月伺→慶応2年10月書付）の年代構造と**整合する二次整理**であることが今回の判明で裏づけられた〕。また「**1864年の調査では、既存の千川上水を広げて深くする工事と、新たな分水路の開削が検討・実施**」「六義園付近を起点とする水路ではなく、**滝野川の分配地点から大砲製造所側へ水を導く計画**」と流路構造を要約。
- **千川上水分配堰碑〔確認〕**: 北区滝野川6-9-1・**明治15年（1882）に水利権を明確にするため建てられた石碑**で「幕末に分水路が設けられた場所の記憶を伝える」と説明〔[BLOG-095](BLOG-095.md)（碑文採録）・[BLOG-127](BLOG-127.md)（説明板・1882年7月設置）の独立裏付けとなる2025年時点の現地解説〕。
- **明治への工業用水の継承〔確認・repo初出候補〕**: 明治5年（1872）に**鹿島万平が水力を利用する紡績工場**を設け、1873年に渋沢栄一ら設立の抄紙会社が王子で操業（のち王子製紙）、1904年に大蔵省醸造試験所が滝野川に開設（旧第一工場は現存・重要文化財）という年表〔**鹿島万平の水力紡績（1872）はrepo初出候補**。王子分水→明治工業用水の系譜（[BLOG-053](BLOG-053.md)の説明板にいう明治の工業用水への利用）の並行路線。鹿島万平紡績工場の位置・千川上水・石神井川のいずれの水力かは本文に明記がなく断定しない〕。
- **制限・未解決**: ①歴史散歩サークルの一般向け二次解説で、出典は北区公式説明板・千川上水分配堰碑・Wikipedia等の複合（一次史料の直接引用はなし）。②「1864年の上申」の史料名は明記されず（GOV-144の元治元年12月達・慶応元年7月伺との直接対応は推定に留める）。③鹿島万平紡績の立地・用水は未特定。
