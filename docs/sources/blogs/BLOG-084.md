# [BLOG-084] Natrium.jp 谷端川北緑道

- **直接確認（2026-11-11、open_url・本文全文）**：板橋駅東口〜下板橋駅〜川越街道（前田上の橋）までの谷端川北緑道と南北支流の観察（2017年11月19日・23日・12月9日撮影）。
- **田楽橋の欄干〔確認：観察・銘の読取〕〔repo初出〕**：山手通りの近くにある**子易神社**（[GOV-015](../gov/GOV-015.md)の聞き取り先と同じ神社）の境内に、**下板橋駅前に架かっていた田楽橋の欄干がベンチとして残されている**。**明治43年（1910年）と銘が打たれている**ため100年以上前の遺構と記す。〔欄干銘はnatriumの読取。田楽橋という橋名自体がrepo初出〕 橋の架替・撤去・移設の経緯・時期は本文にない。〔未解決：原橋の位置・移設年〕
- **お多福弁天〔確認：観察〕**：下板橋駅北側ビル敷地内に祀られる。**もとはこの辺りの沼の名前だった**という。[GOV-015](../gov/GOV-015.md)の「お多福弁天沼」由来板（四百年以上前の古い沼）と整合する現地記録。
- **池袋氷川神社〔確認：社伝由来の転記〕**：崖上に鎮座。**創建を伝える記録がなく**、永禄2年（1559年）にはすでに池袋村があり、天保元年（1830年）の『新編武蔵風土記稿』には村の鎮守としての記録が残るという。〔社史は二次転記／池袋村の位置は崖上高台〕
- **緑道の名称の不統一〔観察〕**：板橋区側では「谷端川北緑道」ではなく**谷端川児童遊園**として整備されており、板橋区側に北緑道の表示がなく**両区で名称が統一されていない**。〔[BLOG-050](BLOG-050.md)の谷端川児童遊園＝板橋区立の記録と整合〕
- **板橋駅西側の川跡〔観察＋推定〕**：板橋駅東口ホテル脇の通路状空間がかつての谷端川の一部とみられる一方、**現在の下水道本管は板橋駅の地下通路付近を通っており、暗渠になる前はそちらが川筋だったかもしれない**とする。〔推定〕
- **一の橋から池袋駅方向への支流〔観察〕**：一の橋から南へ池袋駅方向へ向かう支流があり、**もともと並走する二本の水路だったらしい**。東上第6号踏切方面へ続く水路敷・西向きの水路敷の断片を記録する。〔観察・伝聞／二本水路説の典拠は本文にない〕
- **橋名由来の字名〔確認：「板橋の地名」等による説明の転記〕**：**西前橋＝豊島郡板橋町大字金井窪の字「西前」**、**北浦橋＝旧字名「北裏」**（「裏」ではイメージが悪かったからかもしれない、と筆者推測）、**金井窪橋＝大字金井窪**、中丸橋は字名と現在の町名の位置がずれている気がする、と記す。〔由来の多くは二次説明／筆者推測部分は推定〕
- **補助73号線・82号線の予定地〔確認：行政計画の紹介〕**：東上第8号踏切付近は補助73号線、池袋本町三丁目チビッ子児童公園付近は補助82号線（北池袋駅〜山手通り）の予定地で、**谷端川跡の水路敷景観がいずれ失われる可能性**を指摘する。崖下のチビッ子児童公園は「いかにも湧き水が出ていそうな雰囲気」だが証拠は見つからないと記す。〔観察／湧水説は断定しない〕
- **豊橋の旧川幅〔観察〕**：欄干のある位置より手前に水路敷と思われるスペースが残り、**このあたりではもともと川幅がかなり広かった**と読める。
- **出端川合流点の階段〔観察〕**：谷端川北緑道が川越街道へ南進する位置に**出端川が合流するポイントの階段**がある（[BLOG-085](BLOG-085.md)参照）。
