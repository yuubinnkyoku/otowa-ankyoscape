# [BLOG-094] 千川上水(2) 更新橋〜上井草駅：千川筋の水車史と沿川遺構の再記録

- **書誌**: sirakigi「[千川上水(2) 更新橋〜上井草駅](http://wwr3.ucom.ne.jp/sirakigi/senkawa21.html)」（濯川 −歴史と景観−。ページ自体の公開年は未特定。掲載写真は昭和15年・38年・平成8・13・14年）。2026-11-11、直接アクセスは遮断されたため**Wayback Machine保存版（2025-11-10取得）で全文取得**して資料化。
- **〔確認・二次〕** **千川筋の水車は江戸期を通じて許可されなかったとする記述**。①**文化4年（1807）に下板橋や川越街道周辺で千川の溢水事故があり、水見守役千川両家の調査で原因は保谷新田の新之丞の水車とする記録があるとする（板橋区史 通史編上の引用）**。②**文化4年に荒居村名主伝内・上石神井村百姓勝五郎から「千川用水堀ニおいて水車仕度目論見」の願い出、文化6年に上練馬村百姓左内の新規水車願い（近世練馬諸家文書抄・練馬区〔昭和36年〕の引用）があり、いずれも許されなかった**。理由は灌漑用水としての水量不安定回避と下流域の反対とする〔確認：筆者による典拠書名つきの叙述／未確認：各原典本文〕。
- **〔確認・二次〕** **明治17年の千川上水路図に8か所の水車が記される**。練馬区内の水車として**斉藤（八成、南田中1）・渡辺（鴨下、富士見台1）・矢島（豊玉上2）**の3水車を挙げる〔渡辺・矢島の所在地記載はrepo初出候補〕。水車は千川の流量と平坦な地形から**下掛け式**であったとする。明治24年の地図にも水車記号がある〔確認：筆者叙述／未確認：千川上水路図の現物〕。
- **〔確認・二次〕** **田中水車（通称・観音山〔小字名〕水車）は昭和44年（1969）2月まで水車が回っていた**。昭和15年頃からモーター併用、**杵数43本・常時半数稼働・フル稼働で一日約1.2トンの製粉能力**、カレー粉原料・染色の藍・センブリ・ゲンノショウコ等も粉砕したとする（『練馬の産業I』練馬区教育委員会・昭和59年の引用）。**田中水車の案内板が上石千川児童遊園に設置され、石臼2基がマンション前植え込みに現存する**〔確認：筆者の現地観察文言／未確認：案内板文言・石臼の現況〕。
- **〔確認・二次〕** 『練馬区史』（昭和32年版）の引用として、**練馬区内（境橋〜旭丘1丁目）の千川の延長は10.53キロメートル・橋数41**と記す。
- **〔確認〕** 青梅街道と千川の交点の橋は**伊勢殿橋・出店橋（出店＝小字名）と呼ばれ、現在は「伊勢橋」のプレート**。御嶽神社参詣用の「御獄菅笠」（天保5年刊）に**水道端（右岸に水番所・左岸に二八蕎麦屋）の図**があると記す〔確認：筆者叙述／未確認：御獄菅笠の図版〕。竹下新田は新編武蔵風土記稿引用で**天明4年（1784）竹下忠左衛門の新墾**とする。
- **〔確認・二次〕** **「竹下新田千川用水堀絵図」（千川家蔵）の引用**〔[GOV-068](../gov/GOV-068.md)言及の絵図と同定要〕。水道端の分水は**井草村分水（6か村〔5か村〕分水）**で、上井草・下井草・天沼・阿佐ヶ谷・下荻窪（現杉並区）と上鷺宮（現中野区）の**南6か村組合**が維持管理、**水田は明治10年で約52町歩・明治21年で約80町歩**。杉並区の千川用水史は『星野家文書−千川用水関係史料−』（杉並区教育委員会・昭和58）に詳しいとする〔確認：筆者叙述／未確認：同刊の内容〕。
- **〔確認・二次〕** 桂橋・東北裏橋間の左岸に**水難者供養の「千川上水施餓亡霊鬼供養塔」（明治41年3月建立）**があり、道しるべとして**「右は田無小金井道、北は関青梅街道、左は吉祥寺停車場、井之頭道」**と刻む〔碑文言はrepo初出候補。未確認：塔の現物〕。更新橋脇の庚申塔（安永4年〔1775〕青面金剛）には**「右府中道、左深大寺道」**の刻字がある。
- **〔確認・二次〕** 1990年代の水量について、**境橋から下流で漏水・浸透により減少、暗渠部は空堀状態の土砂堆積で水が流れにくい**とし、**善福寺池へ1日7000トン導水（千川流水の約3分の2）・本流に約3000トン（1分間約2.1トン）**と記す〔[BLOG-090](BLOG-090.md)（本田創2011）と独立の同数値叙述。善福寺池直落入水は再生水の富栄養化で回避しているとも〕。
- **〔参考・確認〕** 屋敷森（関町南）、上石神井車両基地付近の**築樋**跡とみられる地形（歩道が一段高い）、上井草駅西側踏切付近で川幅5メートル余りとの「文献1」引用、昭和15年・38年・平成8-14年の今昔写真の所在。
- **〔未解決〕** 千川上水路図（明治17年）・千川家蔵の竹下新田絵図・『練馬の産業I』・『練馬区史』昭和32年版・『近世練馬諸家文書抄』・『板橋区史通史編上』・御獄菅笠・星野家文書（杉並区教委昭和58）の各原典確認。施餓亡供養塔・伊勢橋プレート・石臼の現地確認。「文献1」の書名特定。
