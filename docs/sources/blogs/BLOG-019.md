# [BLOG-019] 2020年4月16日の水窪川踏査と大塚六丁目の石垣・階段

- **資料〔確認〕**：小林力「[水窪川の地形と戦前地図](https://tkobays.blogspot.com/2020/04/blog-post_18.html)」（**2020年4月18日公開**）。本文は**2020年4月16日**の池袋東口から護国寺付近までの歩行を、時刻と写真説明を添えて記録している。写真の撮影時刻は投稿者の表示に依拠し、撮影位置の座標・方位は独立に検証していない。
- **現地の具体的地点〔観察：筆者の現地記録〕**：**10時53分、文京区大塚6丁目18番付近**で川跡に沿う石垣を記録し、**10時55分**には川の洗い場に下りるように見える石段を、**10時56～58分、大塚6丁目10番付近**では長い階段とその踊り場を撮影・紹介する。川跡の周囲にある**井戸を10時51分・11時20分・11時29分**にも記録するが、使用中か、自然湧水を汲む井戸かは不明。**大塚6丁目の番地を伴う2020年の階段・擁壁の写真照合候補**が追加された。
- **明治天皇御野立所跡石柱〔観察：筆者の現地記録・2020年4月19日追記分〕**：同記事の池袋東口付近の記録（**10時22分、美久仁小路南東**）として、「**明治天皇御野立所跡**」の石柱があることを追記している（**明治8年12月27日**の近衛兵板橋演習視察に伴う野立とする説明を添える）〔水窪川源流部（美久仁小路）の近代記念物としてrepo初出。石柱の建立年・建立主体は本文では特定されておらず、野立の事実は一次史料（『明治天皇紀』等）での確認が今後の課題〕。
- **旧版地図の比較〔筆者による二次読図〕**：筆者は**1909年（明治42年）・1932年（昭和7年）・1957年（昭和32年）**の地図を比較し、1932年図には水窪川が見えるが1957年図には見えないと述べる。**各原図の図郭・凡例・改測年・線種をこちらで再確認しておらず、1957年図の非表示を暗渠化工事の竣工年月とはみなさない**。同じ筆者の後半の歩行記録は[BLOG-020](BLOG-020.md)。
- **限界〔注意・未解決〕**：石垣・階段が河川護岸・旧洗い場の現物だったという証拠はない。**現在の階段・擁壁は宅地造成や道路改修の結果でもあり得る**。旧河床の深さ・中心線や井戸の水源は確定できない。1912年地籍図と標高図、道路・擁壁台帳で位置を再照合する必要がある。御野立所石柱の文言全文・建立年の現地採録は未実施。
