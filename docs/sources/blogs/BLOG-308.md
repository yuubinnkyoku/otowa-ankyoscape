# [BLOG-308] 毎日新聞・小池知事所信表明報道〔神田川流域河川整備計画の2026年度改定への知事レベルの言及〕

- **書誌〔確認: 無料公開部分の本文・2026-11-23取得〕**: 毎日新聞「**小池知事が所信表明、風水害対策で調節池整備へ ポイ捨て対策も**」 https://mainichi.jp/articles/20260918/k00/00m/310/186000c 〔**2026年9月18日** 都議会第3回定例会・**最終更新 9月19日 15:15**・全文493文字中無料部分=約265文字を取得（残り228文字は有料・未読）・写真=都議会議事堂で所信表明する小池知事（同日午後1時20分・柳澤一男撮影）〕。
- **核心文言〔確認・repo初出の先行情報〕**: 「東京都議会第3回定例会が**18日開会**し、小池百合子知事は所信表明で国内で相次ぐ水害を受け、**今年度改定の「河川整備計画」に地下河川や神田川などで新たな調節池の整備を盛り込むことや、新たな分水路の事業化に向けた検討を進めることを明らかにした**。」＝**①河川整備計画の「今年度（2026年度）改定」への言及、②地下河川・神田川等での新たな調節池整備の盛込み、③新たな分水路の事業化検討**という3点の知事レベルの表明〔repoは[GOV-124](../gov/GOV-124.md)（2026年5-6月パブコメ・変更原案）・[GOV-546](../gov/GOV-546.md)（神田川中流部調節池・高戸橋〜駒塚橋・約30.9万m³）・[GOV-557](../gov/GOV-557.md)系で「決定版未公表」の状態を監視してきた**神田川流域河川整備計画（平成17年3月策定→令和5年3月〔[GOV-124](../gov/GOV-124.md)〕）の次期改定の動向**について、知事の所信表明という最上位の政治レベルでの先行情報〕。
- **日曜7日大雨への言及〔確認〕**: 「**小池氏は7日の大雨で大島町などにレベル5土砂災害特別警報が出された**ことを挙げ、「**風水害対策は喫緊の課題**」として対策強化するとした。」＝2026-09-07大雨（大島町レベル5）が所信表明の動機として明示されている〔気象災害側の背景記録〕。
- **意義〔観察〕**: ①**「今年度改定の河川整備計画」＝神田川流域の整備計画改定（都建設局）が2026年度中に実現する可能性が知事レベルで表明された**ことで、[GOV-136](../gov/GOV-136.md)等の2026年告示ラッシュ（第六号神田川都市計画事業認可〔[GOV-534](../gov/GOV-534.md)〕等）の上位計画側の最終段階の対校点になる。②**「新たな分水路の事業化」の文言**はrepoで初めて見えた方向性（対象河川は本文に特定なし＝神田川とは限らない点に注意）で、神田川・環七広域調節池（[GOV-148](../gov/GOV-148.md)・2026-12-02開札案件）と並ぶ新規治水構造物の追加系列の可能性として監視対象に加える。③都の公式所信表明ページ（`https://www.metro.tokyo.lg.jp/governor/shisehoshin/08_03`）は2026-11-23時点で「お探しのページ」応答で**所信表明本文の一次取得は未達**＝報道経由の文言である点を本文の限定として明示。
- **制限・未解決**: ①**「河川整備計画」「地下河川」「調節池」「分水路」の各文言の対象河川の確定**（神田川流域の整備計画改定か、他流域か、複数か）は本報道本文からは特定不能（「神田川など」と唯一の河川名）。②有料部分（残り228文字）未読。③**知事所信表明の原文（都公式ページ）の取得**（会議録・議事録からの確認を含む）は次回課題。④**改定決定版の公表監視**（都建設局「河川整備計画について」頁・2026-11-09時点で神田川流域はR5.3版のまま＝次回以降の定点チェック）。
