## 内容メモ

- **〔伝聞・repo初出〕神田上水「白堀」の遺構発掘の新聞報道**: 江戸川橋からスタートし「**解体中の中学を横目に…（ここで神田上水白堀の遺構が発掘されたと新聞で読んだ）**」〔伝聞・新聞名・中学名・期日ともに本文に示されず〕。水窪川河口（江戸川橋）至近での神田上水白堀系遺構の発掘情報〔要原報道の特定〕。
- **〔観察・repo grep新出〕桜木町の小町名**: 「**水窪川が神田川に注ぐ辺りのごく狭いエリアに『桜木町』という小さな町名が付いていた**」〔観察〕。水窪川合流点に隣接する文京区桜木町（[GAZ-080](../gazetteers/GAZ-080.md)嘉永5年絵図の「桜木町前ゟ関口台町迄目白坂通道敷」等、江戸期から関口・音羽側の町名として既記録）の位置を水窪川合流点との関係で明示。
- **〔観察〕湧水の20年ぶり再訪で水量減少**: 合流点近くの湧水（桶のある地点）が「**水量減った…20年ぶりくらいなので当たり前か**」〔1990年代前後と2012年の湧水量の対校観察〕。今宮神社南まで来ると水の流れがある〔観察〕。八幡坂南側斜面・洗い場（金魚を泳がせていた跡か）・ブロックで隔てられた構造の観察〔観察〕。
- **〔言及〕水道端図書館**: 水窪川沿いの「水道端」町名に立地する図書館（文京区立・かつて芸術・写真系の収集強化担当）への言及〔水道端地名の生活史記録〕。
- その他: 久世山（平和の象徴）・小日向の台地上の凹み道・屋外洗い場（ハニカム構造タイル）の観察〔水関連生活史の周辺記録〕。
