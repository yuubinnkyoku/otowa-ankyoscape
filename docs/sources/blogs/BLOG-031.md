# [BLOG-031] 谷端川緑道歩き（粟島神社御由緒の転記）

- 個人ブログ「ワインとdineと散歩」の谷端川緑道歩き記事（千川駅〜粟島神社〜椎名町〜下板橋〜大塚〜富坂下）。公開年月日は未確認。文字コードは Shift_JIS。
- http://winedineosanpo.chips.jp/3O021.html

## 内容メモ（すべて本文の記述・二次転記）

- 谷端川の流路を、**豊島区千早と要町の境界付近・粟島神社境内の弁天池を水源**とし、**千川上水の長崎村分水が現在の有楽町線千川駅付近から樋で落とされ、粟島神社の湧水先で谷端川に合わせて南流**していたと説明する。〔二次概説：流路・分水の接続／独立測量ではない〕
- **粟島神社（弁天様）御由緒**を逐文転記する：「往昔ここは清水の湧出する静謐の地であった。泉は溢れ川となってこの地を潤し、のちに谷端川の源泉ともなった。…口承によれば、**鎌倉の末期頃から罔象女（水の神）が祀られ**、いつか弁天様として地元民に親しまれるようになった。**江戸の頃から大正末期まで**旱天の折、**雨乞祈祷の聖地**となり…五穀豊饒の信仰…悪疫退散の信仰を生み出していった。**神佛判然令以後弁財天に因み粟島神社を称するに至った**が、なお弁天様として蓄財利殖・具足円満・愛敬を祈る神として地元民に親しまれている。」〔二次転記：神社由緒書の引用／由緒書原本・神社庁記録は未照合〕
- 境内に**瓢箪形の池**（弁天池）があり、片方に亀・もう片方に鯉、**排水口の先は神社に沿った道路**になっている、と記す。〔観察：筆者の現地描写〕
- 神社から南の流路は「痕跡は何も残っていません」「流路を完全に埋立てて道路にしてしまったようです」と記す。〔観察：現地印象／暗渠化年の確定ではない〕
- 大塚三業通り（ＪＲ大塚駅ガード下先）を「谷端川が暗渠化されなかった（バイパスされた）区間」とする。〔二次概説〕
