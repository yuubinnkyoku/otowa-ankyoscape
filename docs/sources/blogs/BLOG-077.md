# [BLOG-077] 文京区の石碑-11 千川改修記念碑と明治天皇行幸碑

- **直接確認（2026-11-11、Wayback Machine [2025-11-04 snapshot](https://web.archive.org/web/20251104014239id_/https://blog.goo.ne.jp/fuw6606/e/7f368edc70df5d67539e97f0734d495d)）**：gooブログのサービス終了に伴い直接アクセス不可。アーカイブ本文で確認した。板橋区在住の石仏・石碑巡りの記録（2019年3月10日投稿）。
- **千川改修記念碑〔確認：記事の記述〕**：簸川神社石段（50段）の上り口右側に立つ。神社前2〜30mを横切る千川通りの下は暗渠で千川が流れている。〔位置・現況は[BLOG-070](BLOG-070.md)（miwa3k）と一致〕
- **洪水の記憶〔二次情報：筆者の叙述〕**：神社前一帯は「氷川たんぼ」と呼ばれ、その中央を流れる千川は清流だったが**年に2回は洪水となり床上浸水の被害**を出した。**どこの家にも「吊寝床」があった**という。**特に大正14年（1925）の洪水は記録的で、人々は舟での避難を余儀なくされた**。筆者はこの悲惨な光景の記録写真を区の図書館で探したが見当たらなかったという**否定的探索の記録**もある。〔**大正14年＝1925年の洪水の伝承はrepo初出**。谷端川放水路の1924/1925年次問題（[BOOK-031](../books/BOOK-031.md)候補、[第7回ノート](../../2026-11-11（第7回）・谷端川放水路の典拠特定・湧水論文・鈴木理生事典の追加調査.md)）と同じ時期に下流部が洪水に苦しんでいた傍証になり得るが、両者の直接の関連は未確認〔仮説〕〕
- **工事の工程〔確認：記事の記述〕**：地元の熱烈な要望を受け、**東京市は昭和5年（1930）から千川の暗渠工事に取り掛かり、総延長3,272mの下水工事は4年後の昭和9年（1934）に竣工**。この碑はその大工事完成の記念碑で、**裏面に各地域の功労者名がびっしりと刻まれている**。〔**着手1930年という新情報はrepo初出**。1928年東京市会議決（既出）と併せ、**議決1928→着手1930→竣工1934**の工程が揃った。3,272m・幅員18mはWikipedia谷端川の記述（[第7回ノート](../../2026-11-11（第7回）・谷端川放水路の典拠特定・湧水論文・鈴木理生事典の追加調査.md)）と一致し、BLOG-070の「1934年暗渠化」の読みを独立裏付ける〕
- **その他〔確認〕**：同じ記事内に明治天皇行幸碑（土方久元邸跡・恩光閣記碑）の記録。千川とは直接関係しないが、同地の近世以降の土地利用の文脈に使える。
- **制限〔未解決〕**：碑文そのものの採録は依然未実施。着手1930年の典拠（東京市の工事文書）は本記事では示されていない。昭和初期の簸川神社前写真は区の図書館で確認できなかったとの記述のみで、所在は不明。
