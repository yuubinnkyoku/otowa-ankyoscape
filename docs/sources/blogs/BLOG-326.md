## 内容メモ

- **〔確認: 記事本文〕** onnbubatta「水徒然」の2013年記事（[BLOG-105](BLOG-105.md)系）に触発され、**約7年を経て中丸川の上流端付近を確認**した記事。著者の前身ブログ記事の地形図で「出端川でなく中丸川」のくぼみの最上端にあたる場所。
- **〔観察〕** **板橋二中の北側にいきなり開渠が現れる**。ブロックを回り込むと次ブロックは暗渠（草深くて開渠か暗渠か判別不能・猫がすぐ逃げた）・さらに都営アパートのフェンスの向こうに**蓋つきの側溝**があり、その先は痕跡なし〔2020年7月時点の現況観察〕。
- **〔観察〕** すぐそばの**水神社**を参拝: **平成19年にここにお祀りしなおした**とのことで、大変きれいに手入れされている〔境内の由緒表示に基づく記録。祀り直しの前の所在地は本文に明記なし〕。
