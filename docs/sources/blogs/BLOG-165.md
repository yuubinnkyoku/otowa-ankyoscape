# [BLOG-165] ありゃりゃサンポ「千川上水を往く（板橋から掘割）」

- **直接確認（2026-11-13、Wayback 20251103230819 スナップショット・本文全文）**：goo blog 終了に伴い現行は遮断（BLOG-114・BLOG-160と同じ回避手段）。第44回課題④・第45回「URL特定に至らず」の当該記事を特定・取得。
- **板橋駅前の千川上水と谷端川の最接近距離〔repo初出の数値・観察〕**：**板橋駅前の川筋は谷端川の暗渠から僅か120m**しか離れておらず、2川は近距離で並流、とする。明治通り西巣鴨交差点から「200m下ると谷端川暗渠」の記述も。千川上水と谷端川の位置関係の定量的な観察値として記録（筆者の地図読みに基づく値で、測量値ではない）。
- **「千・川・上・水」4文字デザインのマンホール〔観察〕**：板橋駅前ロータリーの欅の植え込み裏に千川上水のマンホール、「千・川・上・水」の4文字が蓋にデザインされている。千川水道㈱社紋マンホール（[PAP-027](../papers/PAP-027.md)）とは別の、板橋駅前の蓋の意匠記録。
- **石神井川への余水放流分岐点の位置〔推定〕**：板橋駅前のコンクリートマンホールの場所が「千川上水の余水を石神井川に落とす分岐点」で、地中管を通って石神井川に注ぐ、と推定。石神井川沿いには**「千川上水の放流について」という説明看板**が立つ（同行者の写真で確認）。谷端川放水路（板橋駅東側）と石神井川放流の二系統の関係整理に有用な観察記録。
- **尾根上を流れる上水の不思議〔観察・推論〕**：板橋駅前で川筋が左右より一段高く、「尾根の一番高いところに作られた上水」「目的の方向に川を導くために盛り土をして高度を稼いだ可能性」の推論。
- **掘割バス停・分配堰碑・千川上水公園〔確認〕**：西巣鴨交差点角の明治15年分配堰碑（[BLOG-095](BLOG-095.md)）・掘割バス停・千川上水公園（沈殿池＝[GOV-065](../gov/GOV-065.md)）・六義園給水バルブ（[BLOG-095](BLOG-095.md)）の再確認。
- **制限〔未解決〕**：120m・200mの数値と石神井川放流経路の確定は筆者の読図依存。「千川上水の放流について」看板の設置主体・本文の確認が次の課題。
