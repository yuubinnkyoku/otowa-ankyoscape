# [BLOG-129] kotakemol04「千川上水公園と現在の流水状況」

- **書誌・取得経緯〔確認〕**：FC2ブログ「越後屋たぬき（FC2版）」の2021-01-14記事。直接openはFC2の閲覧制限（「このページの表示は許可されていません」）だが、**Wayback Machine 2024-11-20スナップショットで全文取得成功**〔第8回以来の長期アクセス不能頁の初取得。本文はスナップショット経由の直接確認と位置づける〕。
- **都議会の回答文言〔確認: 記事の引用〕**：令和2年第1回定例会（第1号）の質問への回答として「**補助第26号線の事業区域及び大山町クロスポイント周辺地区の再開発施行地区においては、千川上水が東西に暗きょとして存在しています。千川上水は、河川法の適用のない法定外公共物であり、当該地区の暗きょ区間は、国から地元区への移管が整うまでの間、都が維持管理などを実施しています。なお、通水については現在停止しています**」と引用〔**大山町クロスポイント周辺再開発地区の千川上水暗きょの法的位置づけ（法定外公共物・都管理・通水停止）を都議会回答レベルで確認した記録としてrepo初出**。第22回ノートの雑司ヶ谷幹線と並ぶ千川通水停止の行政文書記録〕。
- **沈殿池への未通水〔観察〕**：「現在も千川上水公園（の地下沈殿池）へは清流復活の水は来ていない」「写真で石神井川に流れ出ている水は谷端川幹線からのもの」〔[GOV-080](../gov/GOV-080.md)（豊島区「水流は平成元年に復活し暗渠管のなかを流れている」）とは水量・対象区間の認識が食い違いうるが、どちらも断定材料がなく、別区間・別系統（親水公園区間への放流と沈殿池区間の停止）を指す可能性があるため**並記して断定しない**〕。
- **流末の看板〔観察〕**：「JR板橋駅東側で谷端川幹線（下水）と合流して石神井川へ放流される、事実上の終点の看板」が平成27年時と変わらない「通水を停止中」のまま〔板橋駅東側放流口（[BLOG-059](BLOG-059.md)流末）の2021年時点の状態記録〕。
- **下水道台帳の読取〔観察〕**：分水堰碑の手前に散見する旧流路上の「千川」刻印マンホールについて、下水道台帳を見る限り「マンホールを結ぶことで地下の管路で旧流路をなぞれるというわけでもなく、そもそも**明治通りを渡って千川上水公園に至る下水管は確認できない**」〔第24回ノートの三幹線対応問題（谷端川幹線・千川幹線）に関わる筆者の台帳読取観察。台帳そのものは未確認のため筆者観察として記録〕。
- **現地案内板〔観察〕**：千川上水公園の現地案内板に「現在は、東京都東部公園緑地事務所が管理しており、利用されていません」〔地下沈殿池の管理主体・不利用の案内板記録。[GOV-065](../gov/GOV-065.md)（沈殿池で水量調節給水の目録解説）の現代の対比資料〕。
- **関連**：同筆者の千川上水シリーズ（[BLOG-035](BLOG-035.md)以降の一次記事群）の後追い観察。2015-08-23「現在千川上水暗渠部に水は流れていません」記事（都議会での河川部長発言取り上げ）の後日譚。
