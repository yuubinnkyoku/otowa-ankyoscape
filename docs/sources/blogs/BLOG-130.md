# [BLOG-130] 朝日新聞 2026年10月1日付湧水復活記事

- **書誌〔確認〕**：朝日新聞2026年10月1日18時00分配信、平山亜理・多田晃子・山浦正敬署名の記事。本文直接取得。四河川（水窪川・弦巻川・谷端川・千川）の流域外（井の頭公園・深大寺・光が丘公園）の記事だが、**武蔵野台地の湧水・地下水位の2026年現況の一次報道**として記録する。
- **記録的長雨〔確認〕**：都心で2026年8月27日から10月1日まで**36日連続の降水観測で過去最長を更新**。この期間の都内降水量は700ミリ超。
- **井の頭公園の湧水〔確認〕**：9月9日に湧水が確認され、22日ごろから遊歩道やベンチ脇などあちこちで目立つように（都西部公園緑地事務所談）。井の頭池は「かつて1日1万トン超の湧水があった場所」で、現在は地下水をポンプでくみ上げて水位を保つ〔湧水減衰→揚水代替の現況〕。
- **武蔵野台地の湧水機構〔確認〕**：市民団体「井の頭自然の会」鈴木浩克代表の説明として「武蔵野台地に降った雨は地下を流れて井の頭公園や善福寺公園、石神井公園などで湧水となって地上に現れ、神田川や善福寺川などの源流をつくってきた」「湧水は戦後の宅地開発や地下水のくみ上げによって減っていったが、今回の長雨で地下水の水位が急上昇し、**普段は枯渇している場所からも水が噴き出した**と考えられる」〔**湧水減衰仮説（[PAP-018](../papers/PAP-018.md)・[PAP-021](../papers/PAP-021.md)）について、降水量回復が短期に湧水を復活させうることの2026年の実例報道。谷端川水源（弁天池）・千川沿いの湧水地点も同様の機構上にある〕。
- **深大寺の湧水〔確認〕**：2025年11月以降の少雨で2026年2月ごろから枯渇していた湧水が梅雨に復活し、9月には本堂の隙間・床下から湧き出る状態（張堂興昭住職談）。
- **意義〔解釈〕**：2025年〜2026年上半期の少雨による湧水枯渇と、2026年8〜9月の長雨による湧水復活の対が一次報道で記録された。四河川流域の湧水・自噴井戸（[BLOG-052](BLOG-052.md)弦巻川・[GOV-081](../gov/GOV-081.md)区別湧水地点数）の変動を考える際の2026年の広域水文条件として使用する。
