# [BLOG-206] 下板橋〜板橋駅間の読図と「矢畑川」ガードの2018年観察

- **直接確認（2026-11-13、第64回・FC2直fetch）**：長年本文未取得だったentry-241の全文取得。
- **放水路の分岐〔観察：2018年〕**：下板橋駅を過ぎた谷端川はカラー舗装の途切れた位置から右に折れて板橋駅へ向かうが、**氾濫防止のための「第二石神井川放水路」が直進方向**に延びる。板橋駅南側の**「矢畑川自由通路地下道ガード」**を通過して南へ向きを変える一方、**石神井川放水路がガード通過地点から北へ**延びる〔二本の放水路（BLOG-070・GOV-083系の記録）の分岐位置の独立観察。「第二石神井川放水路」の呼称はrepoの放水路年次議論と照合候補〕。
- **三の橋〜一の橋と支流〔観察〕**：自転車置き場の先に**上流より三の橋・二の橋・一の橋**が続く〔BLOG-121のプレート観察と整合〕。**三の橋と一の橋の袂に、池袋の六辻（国道254号×明治通り等）あたりから流れる二条の支流がそれぞれ合流していた**〔下り谷・雲雀が谷戸方面の支流（entry-251/252=BLOG-209）の合流位置の具体化。repo初出の位置記述〕。その後川跡らしく蛇行しながら板橋駅南側へ。
- **「矢畑川」表記〔観察〕**：「矢畑川」という標記が誤字か別表記かは本文でも不明とする〔板橋区公文書館電子展示室76号の「矢畑川自由通路地下道ガード／矢畑川自由通路地下道架道橋」（既収録・分割前README 78.1）の2018年民間観察による独立裏付け〕。
- **近藤勇供養塔〔伝聞：子母澤寛『新選組遺聞』引用〕**：板橋駅前の供養塔に胴体が埋葬される伝承・「板橋刑場」は後世の創作（実際は馬捨場で斬首）・娘婿の勇五郎が3日後に掘り起こして三鷹の龍源寺へ改葬した説・**昭和4年に板橋の墓石下から首のない遺骨が発見**された話・供養塔の諱「冝昌」は「昌冝（まさよし）」の誤り、と記す〔谷端川との直接関係は薄いが [BLOG-054](BLOG-054.md) 追記の近藤勇供養塔（千川上水跡尾根筋）の補足記録。史実性は本文も断定しない〕。
