# [BLOG-266] まろん通信「小金井の水路跡」No.1＋No.6〔シリーズ第1回の特定解決と遊歩道北2号の流路確定〕

- **書誌〔確認: 本文全文2本・2026-11-22取得〕**: まろん通信（koganei-kanko.jp/maron・小金井市観光まちおこし協会）のレポーター連載「**小金井の水路跡**」（クマさん執筆）の**第1回＝[No.1（Vol.275・2016-05-15・archives/3043）](https://koganei-kanko.jp/maron/archives/3043)**（[BLOG-264](BLOG-264.md)の制限①「No.1未特定」の解決・シリーズの枠組みの宣言記事）と**[No.6「遊歩道北2号」（Vol.291・2016-06-21・archives/3239）](https://koganei-kanko.jp/maron/archives/3239)**（[BLOG-264](BLOG-264.md)制限③のVol.291本文取得済み記事）。
- **No.1〔確認: 本文全文〕＝シリーズの方法論的枠組みと小金井分水上流の変遷**:
  - 「**小金井市は東西に延びる国分寺崖線（ハケ）で 台地(武蔵野段丘面）の坂上と低地(立川段丘面）の坂下に分けられますが、水路の型は坂上・坂下で大きく異なります。坂上は生活用水や原野の開墾のために玉川上水から分水した水路で、坂下はハケの湧水や野川の水を主に水田に供給するための水路でした**」＝**ハケ上（武蔵野段丘面）=玉川上水系の分水・ハケ下（立川段丘面）=湧水・野川系という二層の水路型の枠組み宣言**＝[GOV-505](../gov/GOV-505.md)（田用水＝給水・悪水＝排水の貫井たんぼの水利体系）・[GOV-508](../gov/GOV-508.md)（水田跡）の坂下側と[GOV-502](../gov/GOV-502.md)〜[GOV-504](../gov/GOV-504.md)の湧水・分水群を位置づける座標軸の観察文言。
  - 「**小金井分水は江戸時代は玉川上水から直に分水していましたが、明治に入り玉川上水で通船のために堰を取り外しので直に分水できず、砂川分水から分水しました**」＝**明治の玉川上水通船に伴う取水の砂川分水経由への切替**＝[GOV-284](../gov/GOV-284.md)（野方堀通分水口体系）・[BLOG-225](BLOG-225.md)（新堀用水の明治3年統合）と同時代同型の分水口再編の小金井分水側文言候補〔通船の年代は本文になし・[BLOG-267](BLOG-267.md)の梶野分水「明治3年」と対応〕。
  - 「**その分水路跡は水はもちろん流れていませんが、部分的に溝の形が今も残っています。貫井北町三丁目から小金井生活実習所西側を通り築樋までです**」＝**明治以後の分水路の流路跡＝貫井北町三丁目→小金井生活実習所西側→築樋**という地上座標。
  - 「**昭和17年にこの付近に陸軍の技術研究所が出来た為、水路の向きが変えられてしまいました**」＋「**この水路の向きは陸軍技術研究所のできる前の水路の向きのようです**」＝**昭和17年（1942）の陸軍技術研究所（技研）設置による水路の向き改変の第2witness**＝[GOV-504](../gov/GOV-504.md)の「陸軍技術研究所（技研）の昭和15・17年強制買収による道路・水路改変・**小金井分水の逆L字改変**」の系列の観察側記録〔年次の細部（昭和15年買収の先行等）は通信側に依拠して判断しない〕。
- **No.6「遊歩道北2号」〔確認: 本文全文〕＝分水路の流路と年代文言**:
  - 「**小金井分水は築樋に入る直前で左（東）側に分水され、仙川北側の高台を小金井街道方面に流れていて最終的には仙川に落ちていました。その水路跡が遊歩道北２号として残っています**」＝[BLOG-264](BLOG-264.md)（No.2）の「築樋の北の入口、50mぐらい先から左に遊歩道北2号が分かれています」＝**分岐の分岐位置・方面の2witness一致**。
  - 「**1600年代の中頃、仙川は恐らく水が流れていて両岸には人々が住んでいた、だから1654年には山王稲穂神社を江戸の日枝神社から勧請して村の鎮守としたとのことです。しかし仙川を流れる水は少ないので1696年の小金井分水開通とともに仙川北側の高台にそこから分水して北斜面の生活用水あるいは農業用水として利用したようです**」＝**①山王稲穂神社勧請＝1654年（承応3年・玉川上水開通と同年・「江戸の日枝神社から」勧請説）②「1696年の小金井分水開通」〔repo初出の独立文言〕＝[BLOG-264](BLOG-264.md)No.2の「築樋が築かれたのが1696年」と文言系を同じくし、シリーズ内で1696年＝元禄9年説の2witnessとなった**〔当事者表明のみで一次史料の出典は本文になし・『貫井村誌』(GOV-504)・小金井市史レベルの史料との照合が今後の課題〕。「とのことです」「ようです」の伝聞・推定表現であることを明記する。
  - 「**この水路は今の小金井街道を越えたあたりで南に曲がり、大松木下之稲荷大神社の東側を通って仙川に落ちていました。築樋から小金井街道までの水路跡が遊歩道北２号として現在活用されています**」＝**遊歩道北2号の全流路＝築樋前分岐→仙川北側高台→小金井街道越え→南折→大松木下之稲荷大神社東側→仙川**〔大松木下之稲荷大神社＝小金井街道に接する社（写真キャプション「小金井街道に接する大松木下之稻荷大神の社、この社と右隣のマンションとの間付近に昔は水路があったようです」）＝**流末の目印の地物**〕。
  - 「**昭和12年の古地図、分水や川、古い道路がよく分かります。北大通りはまだ出来ていせん**」＝**昭和12年（1937）古地図を引用基準とすることの明示**＝[BLOG-268](BLOG-268.md)（Vol.9・Vol.45）と同じ古地図参照体系。

## repoとの関連〔観察〕

- ①**1696年（元禄9年）＝小金井分水開通説の第2witness**＝[BLOG-264](BLOG-264.md)の山王窪築樋1696年築造説（No.2）と同シリーズのNo.6で文言系を共有＝**同一筆者の重複証言ではあるが、貫井村誌・小金井市史レベルの一次史料で裏付けを取るまで「候補」のまま**。②玉川上水承応3年（1654）開通＝[GOV-510](../gov/GOV-510.md)の「玉川上水開通（1654）」と、稲穂神社勧請の同年性（筆者の示唆）は[GAZ-093](../gazetteers/GAZ-093.md)系の仙川周辺開発史の対照点。③陸軍技研の水路改変は[GOV-504](../gov/GOV-504.md)（昭和15・17年強制買収・逆L字改変・上貫橋の短命化）の観察側の該当参照点で、本記事の「向きが変えられた」写真定点の同一性までは特定しない。④遊歩道北2号の流路（大松木下之稲荷大神社東側で仙川）＝仙川北側高台の分水系（現在の道路名・地物への定着）＝[GOV-510](../gov/GOV-510.md)の砂川用水〜小金井用水系の末端の地上観察層。
