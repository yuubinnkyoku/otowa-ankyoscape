# [BLOG-159] ゆるゆるな毎日「東京散歩・千川上水」2023年・上井草開渠20mの無水観察と6月の通水テスト

- **書誌〔確認〕**: アメブロ「ゆるゆるな毎日」の2023年6月25日公開記事（2023年2月・春先・6月の3回の現地観察を含む）。〔第44回ノートの次回評価対象だった同ブログ記事の資料化。文は一般の散歩記だが、上井草開渠部の年間の水量観察として価値がある〕。
- **〔観察・repo初出〕 上井草開渠の水量と通水テスト**: 千川上水橋梁周辺の開渠（上井草2号踏切の西側、**わずか20メートルほど**）を2023年2月・春先・6月の3回訪れ、**いずれも水が流れていない（2月はカラカラに乾燥）**と観察〔[BLOG-090](BLOG-090.md)・[BLOG-103](BLOG-103.md)の開渠部観察の2023年時点の追跡〕。さらに「**毎年6月に、この場所から環境に配慮した赤い染料を流して通水テストをしているそうです**」〔**通水テストの existence と時期＝repo初出の聴取情報（「そうです」伝聞。実施主体・目的は記載なし）**〕。
- **〔観察〕 千川上水橋梁周辺の現況**: 千川通り（都道439号）の暗渠上を通ること、開渠部に小さな鉄橋（千川上水橋梁）が架かること、線路の間は塞がれていないこと、井草通り側に丸い土管が見えること、杉並区との区境の位置〔既収録（[BLOG-090](BLOG-090.md)）と同一箇所の2023年観察で、大きな新事実はない〕。
- **〔確認・二次言及〕 暗渠化年次の表記**: 「練馬区内で暗渠化の工事が始まったのは昭和25年（1950）年頃から。この辺りは昭和40年（1965）年に工事が終了」〔[GOV-072](../gov/GOV-072.md)（区公式・昭和25年頃着手説）の内容と同一の二次言及。出典は明記なし。着手年次3説（25年頃/27年3月以降/1952）の整理に変化なし〕。
- **意義**: 清流復活以降の千川上水開渠部が**常時は流水していない**という2023年の観察記録と、**年1回・6月の染料による通水テスト**の聴取。善福寺川導水（[BLOG-090](BLOG-090.md)・1日7000トン）後の実態把握に資する。
