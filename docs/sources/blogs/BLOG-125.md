# [BLOG-125] 谷端川沿い湧水ものがたり　大塚からの瓢箪池支流

- **直接確認（2026-11-12、open_url・本文全文）**：毎日暗活！暗渠ハンター（旧『東京Peeling！』、髙山英男）。「谷端川沿い湧水ものがたり」シリーズの瓢箪池支流回。[BLOG-061](BLOG-061.md)が「次回記事の所在と本文確認が必要」としていた未解決を解消する記事。全編が豊島区郷土資料館研究紀要第11号・横山恵美「＜調査ノート＞豊島区の湧き水をたずねて」（[BOOK-064](../books/BOOK-064.md)）の湧水リストに依拠した現地探索記録。
- **瓢箪池支流（仮）の水源〔観察〕**：**上池袋1-3**（山手線の窪み＝金網脇）。現地で大正生まれの住民から**「ここは小川というかドブというか、水の流れがあった」**、さらに**「山手線ができるまではこの谷（水路）は山手線の内側から続いていた」**との聴取を得ている。〔個人聴取。山手線建設で谷が分断される以前は現在の山手線内側（池袋方面）まで谷・水路が連続していた可能性を示す証言〕
- **「滝」の洗い場〔確認：紀要11号由来の記述〕**：**上池袋1-27**に洗い場があり、流れが急なため**「滝」と呼ばれていた**と記す。〔紀要11号本文の直接確認は未了。本記事経由の二次確認〕
- **瓢箪池〔確認：紀要11号由来の記述〕**：谷端川との合流部付近（現在の団地敷地あたり）に**瓢箪型の池**があり、雉・鷺・兎などが近辺に巣を作っていたと記す。**瓢箪池という池名・所在（上池袋1-3〜合流部）がrepo初出**。〔丸池（池袋）・弁天池（要町）と並ぶ池所在記録として対照表候補〕
- **旭湯〔観察〕**：谷端川合流点の一隅に銭湯**旭湯**があったと記し、跡地と推定される**コインランドリー旭**の写真を残す。
- **repoへの関連**：[BLOG-061](BLOG-061.md)（下り谷支流）の予告どおりの瓢箪池支流本文で、湧水地点（上池袋1-3）・「滝」洗い場（上池袋1-27）・合流部の池（瓢箪池）を位置レベルで記録。谷端川上流部の湧水支流群（[BLOG-056](BLOG-056.md)〜[BLOG-058](BLOG-058.md)、[BLOG-061](BLOG-061.md)）の下流側の穴を埋める。
