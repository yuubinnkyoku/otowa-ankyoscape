# [BLOG-299] 「豊島区 冠水 どこが危険の？」（art-pi.com）

- **書誌〔確認: 記事本文全文取得・2026-11-23〕**: 不動産系サイト「おかあさんのおうち」の解説記事「**豊島区 冠水 どこが危険の？**」。**公開日2026年9月23日**（datePublished=2026-09-23T12:44:37+0900）。 https://art-pi.com/toshima-kansui-doko-kiken/ 〔[BLOG-115](BLOG-115.md)（同サイト「板橋区はなぜ冠水しやすいの？」2026-09-10）と対になる豊島区版で、同サイトの市区別冠水シリーズの一環〕。不動産会社運営ブログのため、行政・国の一次情報の二次解説として位置づける〔事実性の核は都・区・国の一次資料への案内で確認〕。
- **谷端川緑道下の住所の浸水履歴〔確認: 記事の叙述・数値は都の記録経由の二次引用〕**: 「区のページによると、**谷端川は昭和37年に河川としては廃止され、暗渠の下水道幹線**になり、上はいま**谷端川南緑道・北緑道で、住所は西池袋4丁目と池袋本町3丁目**。どちらも、都の記録で浸水の多い町です」〔谷端川=昭和37年廃止・暗渠下水道幹線はrepo既知の通りだが、**緑道の住所を「西池袋4丁目と池袋本町3丁目」と町名単位で浸水履歴と並記する叙述は二手解説としての取りまとめ**〕。その浸水事例として、**2011年8月26日＝1時間87ミリで100世帯**・**2000年9月12日＝1時間18ミリで38世帯**・**1999年以降の最多は1999年8月29日の169世帯**・**2008年7月29日＝22ミリで40世帯**「区の表では、どちらもほとんどが床上浸水です」〔西池袋4丁目・池袋本町3丁目の浸水世帯数の年代群=谷端川暗渠（谷端川一号幹線）低地帯の内水履歴の二次記録〕。
- **年代別の集計〔確認: 記事の叙述〕**: 「区の表の世帯数を年代ごとに足すと、**1981〜89年が3,424世帯、2010年代は225世帯**でした。最も多い**1987年7月31日は、30分間に60ミリの雨で1,232世帯**が浸かっています」〔1987年7月31日の浸水はrepo既知（「未反映分」メモで床上1,123件・床下109件の集計）だが、**本記事の「1,232世帯」は系統の異なる数値**＝「件」単位との集計差（床上/床下の件数計か、浸水世帯数か）の取りこぼしに注意する記録として併置。断定しない〕。
- **国交省「道路冠水注意箇所」〔確認: 記事の叙述〕**: 「国土交通省 関東地方整備局の「**道路冠水注意箇所**」は、東京都の地図版の一覧で**135か**所。**豊島区は1か所**。**隣の板橋区だけの箇所は7か所、練馬区だけの箇所は6か所**で、ほかに**両区にまたがる箇所が3つ**」・「A は**区道12-680号線のビックリガード（南池袋1丁目）**。池袋駅の南で、線路の下をくぐる道です。管理は豊島区で、説明表には目白警察署と豊島消防署が載っています」〔**国交省の道路冠水注意箇所の都区別集計と豊島区唯一の箇所=ビックリガード（区道12-680号線）の特定はrepo初出候補**。ビックリガードの名称は[BLOG-185](BLOG-185.md)等で既出だが、道路冠水注意箇所としてのアンダーパス冠水対象であることを示す国の一次データの存在が二次解説で確認できる。**弦巻川上流域の低地（南池袋）の構造物の冠水対象として記録**〕。
- **都「浸水実績箇所の住所検索」〔確認: 記事の叙述〕**: 「東京都は「**浸水実績箇所の住所検索**」で、建物が床下・床上まで浸かった記録を公開しています。**元のデータから豊島区を取り出すと182行、日付で数えて48回**。町ごとに記録のある日を数え、**8回以上の15町**を並べました」〔都水害リスク情報システム（浸水実績）の豊島区抽出＝**記録のある日8回以上の15町の一覧形式**＝谷端川・千川低地の浸水町名の絞り込み経路としての二手解説〕。
- **下水道の整備史〔確認: 記事の叙述・用語はrepo既知〕**: 「区の計画によると、都下水道局は浸水対策として、**第二雑司ヶ谷幹線・第二千川幹線・谷端川一号幹線（一部）**などの整備を進めてきました」「**池袋駅は1時間75ミリの雨に対応する施設が完成済み**で、**南大塚では同じ75ミリに耐える工事が進んでいます**。**池袋本町は、都の「下水道浸水対策計画2022」の新しい重点地区10地区の1つ**に選ばれました」〔第二雑司ヶ谷幹線・第二千川幹線・谷端川一号幹線の区計画上の表記はrepo既出（[GOV-154](../gov/GOV-154.md)重点地区・[GOV-082](../gov/GOV-082.md)千川増強幹線系）だが、**「池袋本町=下水道浸水対策計画2022の新しい重点地区10地区の1つ」の文言を豊島区計画経由で確認できる二次記録**〔谷端川一号幹線系（谷端川）・第二千川幹線（千川）の両系統と高架下両側の池袋低地の接続関係の観察補助〕。
- **洪水と内水の区別〔確認: 記事の叙述〕**: 「区のハザードマップは「洪水・内水ハザードマップ」（**令和7年1月発行**）です。区のQ&Aでは、**川の氾濫による浸水の表示は「高田1～3丁目の神田川浸水想定区域」だけ**」「区の計画には、神田川付近の一部で**3メートルを超える浸水**が予想されると書かれています」「東京都下水道局は**令和8年3月25日に雨水出水浸水想定区域を指定**し…」〔[GOV-085](../gov/GOV-085.md)（雨水出水浸水想定区域図・R8.3）・[BLOG-107](BLOG-107.md)（江戸川橋合流点・谷積み石垣）系と整合する豊島区側の表記〕。
- **意義〔観察〕**: ①[BLOG-115](BLOG-115.md)（板橋区版）と対になる**豊島区版で、谷端川暗渠低地（西池袋4丁目・池袋本町3丁目）の浸水世帯数の年代別の取りまとめがrepo初めて一覧化**〔1981〜89年の3,424世帯・1987.7.31の1,232世帯=下水道整備黎明期の深刻だった内水被害の規模感と、2010年代225世帯=第二千川幹線等の整備以降の減少傾向が同じ表で読める唯一の二手資料。**因果は記事も本文repoも断定しない**〕。②**国交省「道路冠水注意箇所」（関東地方整備局）の東京都135か所のうち豊島区=ビックリガード1か所という指摘**は、弦巻川上流域（南池袋=ビックリガード周辺）・千川・谷端川流域の低地の現在の冠水対象を国の資料の存在ごと指し示す。③SRC（市公式・ハザードマップ・都の浸水実績・国の一覧）の所在一式が記事末尾に列挙されている=谷端川・千川・弦巻川流域の浸水資料の探索入口として有用。
- **制限・未解決**: ①浸水世帯数・雨量の全数値は記事経由の二次引用（元は都水害リスク情報システム・区の資料）。1987年7月31日の「1,232世帯」とrepo既知の「1,123件（床上+床下109件）」の差異の解消（集計単位・出典の同定）は都・区の一次資料で確認する。②国交省「道路冠水注意箇所」の東京都一覧（135か所）・箇所表の直接取得は今回未実施〔次回候補。板橋区7・練馬区6・両区跨ぎ3の内訳箇所は谷端川・千川低地の冠水対象特定に使える〕。③15町の町名一覧は記事図中の表記で、本文末尾の列挙とチェック要。
