# [BLOG-231] 増田剛己「池袋から江戸川橋まで、弦巻川の痕跡を歩く」〔全5ページ・repo初出（3ページ目の大鳥神社碑文はREADME既収録）〕

- **書誌〔確認: Wayback Machine スナップショット（2026-05-13・2024-11-05・2024-11-15・2024-12-11）・2026-11-15取得〕**: 増田剛己「[池袋から江戸川橋まで、弦巻川の痕跡を歩く](https://allabout.co.jp/gm/gc/214953/)」（All About・**更新日2010年7月13日**・散歩ガイド記事・全5ページ）。**3ページ目（大鳥神社の高田町下水道築造記念碑の碑文）はREADME既収録**（「公衆衛生ノ根本的解決」・昭和7年9月海老澤了之介識）。**1・2・4・5ページ目は今回がrepo初出**。直サイトはAkamaiのアクセス遮断のためWayback経由で取得。
- **1ページ目（元池袋・丸池）〔確認〕**: ホテルメトロポリタン脇の元池袋史跠公園を「かつてこの場所に**丸池（あるいは袋池と呼ばれていた）**」と紹介し、「**水がコンコンと湧き出る池で弦巻川の源流となった**」と記す〔丸池＝弦巻川源流はREADME既出の理解と同じ。**「袋池」の別呼称の併記は2026年時点の区公式資料には見当たらない追加の呼称記録**〕。びっくりガード西側擁壁の「**雑司が谷いろはかるた**」について、**「そ」の札に橋が描かれた「かつての弦巻川が描かれている絵」があり、いちばん手前が「卒塔婆橋である」**と読む〔**2010年時点で壁画が存在し「そ」＝卒塔婆橋の構成が観察されていた**という、既収録の2024-2025年撮影記録（Natrium・citywalk2020）より**14年遡る第三の独立観察**。かるた原画＝矢島勝昭（2005年11月刊行）との関係の確認材料〕。元池袋史跡公園から要町通りへの小道（下水道マンホールの蓋がある暗渠道）の2010年時点の観察もある。
- **2ページ目（明治通りまで）〔確認〕**: びっくりガードから西武線高架下を経て南池袋へ。**明治通りとの交差部が「いちばん低くなっている谷底」**で、池袋・新宿方面とも上り坂になる旨、**大鳥神社参道が谷筋を進む**旨の観察〔弦巻川の谷地形の2010年時点の読図。区境・標高図との照合資料〕。
- **4ページ目（弦巻通り・木村橋）〔確認〕**: 都電荒川線踏切から先の道筋は「よくわからない」としつつ、**「弦巻通り」という道が「かつての川跡だといわれている」**が、**マンホールの配置から「暗渠となっているのは一本西側の道のようだ」**と観察〔**弦巻通り（旧川跡とされる道）と暗渠道（一本西）を区別する2010年の現地観察。既収録の弦巻通り商店街の聞き取り（「この道がそうですよ」＝弦巻通りを指差す店主証言）と併せ、旧流路と現道のずれの解釈資料〕。清立院一角の**木村橋の石碑**について「木の橋だったものを地元の木村氏によって石橋に付け替えられた」「その記念に建てられたもの」と記す〔既収録の1733年石橋供養塔（木村氏の架けた橋・亡き両親の供養）と整合する、石碑側からの説明の第三記録〕。
- **5ページ目（江戸川橋）〔確認・注意〕**: 日本女子大寮・**三角寛の旧宅（2010年時点で料亭として現存）**・**菊池寛の旧宅**（案内の説明文＝**昭和12年（1937）に越してきて昭和23年（1948）に亡くなるまで過ごした**）を経て、不忍通りから音羽通りへ。「**菊池寛が住みはじめた時期、すでに弦巻川は暗渠になっていた**」と記す〔**旧宅の説明板の転居年（1937）を手掛かりに、菊池寛旧宅付近区間の暗渠化が1937年以前と読む2010年の二次的読み**。既収録の1931年起工・1935年頃完成説（弦巻通り2）・1932年9月以前の道路化（写真帖）と矛盾しない。ただし**説明板の転居年を暗渠完成の根拠にした執筆者の読みであって、竣工原簿の確認ではない**〕。下流端については「かつての弦巻川は、**今の江戸川公園手前で水窪川という、同じく池袋方面から流れてきた川と合流し、神田川に流れ込んでいた**。**今はもう少し下流に暗渠化された下水道が神田川に流れ込むポイントを見ることができた**」と記す〔**水窪川との合流→神田川という流路理解と、2010年時点の「実際の放流口が旧合流位置より下流にある」観察**。放流口位置の年代変化の比較資料〕。
- **位置づけ〔観察〕**: 弦巻川の暗渠化（1930年代）から約75年後の2010年の踏査記事で、**①2010年時点のいろはかるた壁画、②弦巻通りと暗渠道の区別、③1937年以前の暗渠化の傍観、④2010年時点の神田川放流口、⑤三角寛旧宅の料亭化（2010年）**という5点の現地観察を一つの記事で残す。第3ページ（碑文）を含む記事全体の資料化。
