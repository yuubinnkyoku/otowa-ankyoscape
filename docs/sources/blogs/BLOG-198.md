# [BLOG-198] 音羽谷の坂道シリーズ：文京区教委坂名標識文言群と弦巻川・水窪川の流路観察

- **直接確認（2026-11-13、第61回）**: はてなブログ「散歩の途中」の坂道探訪シリーズ3回（[その1](https://miwa3k.hatenablog.jp/entry/saka_otowa_01)／[その2](https://miwa3k.hatenablog.jp/entry/saka_otowa_02)／[その3](https://miwa3k.hatenablog.jp/entry/saka_otowa_03)）。**投稿年は本文で特定できず（2018年頃と推定、断定しない）**。音羽谷（江戸川橋〜護国寺）両側台地の名付き坂10本の記録で、各坂の文京区教委標識文言を写真から転記している。
- **音羽谷の成因〔観察: 筆者〕**: 「音羽谷は弦巻川と音羽川（別名：水窪川、東青柳下水）、小さな２つの川がつくった谷戸。護国寺下である時は合流し、またある時はせずに２つの流れが関口の神田川まで続いていたり」〔両川の対関係・不定合流の叙述はBLOG-001等と整合。「音羽川」の呼称使用は筆者の好みと明記〕。
- **三丁目橋（権三橋）〔確認: 文京区教委三丁目坂標識（昭和53年3月）の文言引用・repo初出の「権三橋」表記〕**: 「坂下の高速道路５号線の下には、かつて弦巻川が流れていて、三丁目橋(権三橋)がかかっていた」〔弦巻川の橋。『文京のあゆみ』（BOOK-057）の「雑三橋（三丁目橋）」と同一橋の可能性。表記群として橋名調査に追補〕。
- **水見坂〔確認: 文京区教委鼠坂標識（平成17年3月）の文言引用・repo初出〕**: 鼠坂の別名。『御府内備考』「鼠坂は音羽五丁目より新屋敷へのぼるの坂なり…」引用に続き、「”水見(みずみ)坂”とも呼ばれていたという。この坂上からは、音羽谷を高速道路に沿って流れていた、弦巻川の水流が眺められたからである」〔弦巻川開渠景観の公的解説による記憶。暗渠化前の景観史料として重要〕。
- **付属横坂〔観察: 筆者〕**: 坂下の横断道が音羽川（水窪川）の川跡。明治〜戦前は日本陸軍兵器支廠（大塚弾薬庫）で道が存在せず、昭和22年地図初出〔読図〕。明治以前は安藤長門守下屋敷〔GAZ-023の安藤氏屋敷記述と対応〕。
- **鳥尾坂〔確認: 文京区教委標識（平成9年3月）の文言引用〕**: 「明治になって、旧関口町192番地に鳥尾小弥太（陸軍軍人、貴族院議員、子爵）が住んでいた。西側の鉄砲坂は急坂すぎたので、鳥尾家は私財を投じて坂道を開いた。地元の人々は…「鳥尾坂」と名づけ、坂下の左わきに坂名を刻んだ石柱を建てた」〔BLOG-161（らんまる2015）の鳥尾坂=repo初出観察に、鳥尾小弥太私財開削・石柱現存という独立裏付けと詳細。筆者は明治〜昭和初期地図に道が見当たらず昭和22年地図が初出かとする読図推定（明治38年没との時系列疑義）を付記〕。
- **鉄砲坂〔確認: 文京区教委標識（平成8年3月）の文言引用〕**: 「坂下の東京音楽大学学生寮のあたりは、江戸時代には崖を利用して鉄砲の射撃練習をした的場（角場・大筒角場ともいわれた）」。標識脇に**安政四年『音羽繪圖』**の一部が示され、桂林寺の下に的場・鉄炮サカの描写がある〔**図名「音羽繪圖」（1857）はrepo初出図名候補。所在・全図の書誌は未確認〕。
- **八幡坂〔確認: 文京区教委標識（平成5年3月）の文言引用〕**: 『東京名所図会』引用で八幡坂と田中八幡宮（現在の今宮神社の地、明治初めまで）と久世山（下総関宿藩主久世氏屋敷）を解説。
- **鷺坂〔確認: 文京区教委標識（平成18年3月）の文言引用〕**: 久世山会が昭和7年7月に建立した石碑（揮毫・堀口九万一、万葉集「山城の久世の鷺坂…」）。堀口大学・三好達治・佐藤春夫による「昭和の坂名」。
- **目白坂〔確認: 文京区教委標識（昭和63年3月）の文言引用〕**: 清戸道（江戸川橋北詰〜西方清戸）の説明。元和4年（1618）新長谷寺（目白不動尊、家光が「目白」号を授けたとある）、戦時空襲で廃寺、不動尊は豊島区金乗院へ移座〔BLOG-163系の金乗院・清立院と同地域。椿山荘=旧椿山の文脈はORG-015と対応〕。
- **目白新坂〔確認: 都設置とみられる標識の文言引用〕**: 明治20年代半ばに新設。『新撰東京名所図会』「椿坂という、近年開創する所、坂名には椿山の旧跡に因むなり、里俗又新坂ともいへり」〔椿坂の椿山（椿山荘地名）との関連叙述〕。
- **七丁目坂〔観察: 筆者〕**: 旧音羽町七丁目（現関口3丁目）由来の無標識坂。
- **限界〔未解決〕**: 投稿年特定。標識文言の現地での直接採録・標識の現存確認。『音羽繪圖』（安政4年）の所在と図内容。三丁目橋（権三橋）とGAZ-013駒止橋（鼠ケ谷橋）の位置関係の照合。
