# [BLOG-118] 北町旧跡研究会「阿弥陀堂」

- **書誌〔確認〕**：練馬区北町の地域史サイト「練馬区北町旧跡研究会」のお宝話の1編（投稿日未確認）。2026-11-12に本文全文を直接取得。阿弥陀堂の堂主・岡田さんからの資料2点の紹介を含む〔[GOV-078](../gov/GOV-078.md)（練馬区公式・千川家の墓）と内容がほぼ一致する地域側の説明記録〕。
- **千川家の墓の説明〔確認〕**：阿弥陀堂の一番奥の左手に千川家の墓がある。元禄9年の分水・幕府の財源不足に千川家が私財を投じて完成・設計者は河村瑞軒と伝えられる〔GOV-078と一致。加算しない〕。
- **田柄川への導水説〔確認：本文の叙述・伝聞〕**：「**北町には、田柄川が流れていたが、水量に乏しいため、千川上水から田柄川を引いた**。水を引いてくるということは、北町には、人も財力もあったということがいえる」〔**千川上水から田柄川への導水という地域史の説明＝repo初出候補**。田柄川（石神井川支流・練馬区南部を流下）は千川上水の南側を並行する水系で、千川上水からの越流導水の可能性を示す伝聞。**根拠資料（堂主資料の内容）は本文に引用がなく断定できない**〔[GAZ-002](../gazetteers/GAZ-002.md)『北豊島郡誌』の田柄川記述・[GOV-068](../gov/GOV-068.md)（分水は湧水池・自然河川源頭に接続する設計思想）と照合が今後の課題〕〕。
- **田柄川の暗渠化〔確認：本文の叙述・伝聞〕**：「戦争で成増に飛行場ができたりしたため、水が途絶え、時代とともに必要もなくなってきて、埋め立てられた」「生活用水が流れ込んだりしたため汚れ、雨の度に氾濫したため**『やっかい堀』と言われ、暗渠化**された」〔①田柄川の**「やっかい堀」呼称＝repo初出**。②成増飛行場（旧陸軍成増飛行場）造成による水源途絶説は因果の根拠が示されず、**伝聞として記録し断定しない**。③雨の度の氾濫と暗渠化は谷端川・千川の都市化による氾濫史（[BLOG-077](BLOG-077.md)大正14年洪水等）と同型の説明〕。
- **制限〔未解決〕**：堂主・岡田さん資料2点の内容（頁上はリンクのみで引用なし）。田柄川への導水の時期・取水位置。成増飛行場と田柄川水源の関係。

## 三河川への使い方

- 千川上水の水利用の外延（灌漑分水）が石神井川水系（田柄川）側にも及んだ可能性を伝える地域伝聞。千川上水分水網（[GOV-068](../gov/GOV-068.md)関村・中村分水、[ORG-020](../org/ORG-020.md)中新井分水）に「田柄川導水」を加えるべきかの検討材料（仮説段階）。
