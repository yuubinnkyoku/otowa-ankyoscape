# [BLOG-026] 占春園・落英池のかいぼり（2019年）と変遷の二次記事

- **資料〔確認〕**：JIBUN「[歴史ある占春園の池をきれいに／親子参加のかいぼりイベントで再生](https://jibunmedia.org/?p=3345)」（**2019年3月28日公開**、頁内に2019年3月7日の表記）。2026年11月8日に本文を文字抽出で確認。執筆者は「（敬）」表記の記者。
- **池名・所在〔確認：記事の叙述〕**：池の名称を**「落英池」**とし、所在を**文京区大塚3丁目**の占春園とする。教育の森公園を下ったところにあると説明。
- **かいぼり〔確認：記事の叙述〕**：**2019年1月13日に池の水を抜いて在来種救出、2月10日に泥上げ、3月3日に在来種放流**。外来種のコイ・ゲンゴロウブナ・アメリカザリガニなどを捕まえ、ギンブナなどの在来種を救出。在来種は約1カ月半、筑波大附属小学校のプールで保護された。**かいぼりは池の水を抜いて入れ替える手入れ作業**である。
- **変遷〔確認：記事の叙述／人名は表記揺れあり〕**：昔は水戸黄門の義理の弟の屋敷で、東京ドーム4.4個分の20万平方メートルあったという。**1746年に藩主が作らせた石碑に「我が公の庭は占春と名づく」**と書かれる。明治時代に**東京高等師範学校**の敷地内となり、その後**東京教育大学、筑波大学**へ引き継がれ、現在は**筑波大学の所有**で**筑波大学附属小学校と文京区が管理**。東京高等師範学校校長だった**嘉納治五郎**の銅像が立つ。
- **整備の主体〔確認：記事の叙述〕**：東京高等師範学校から筑波大学に至る卒業生の同窓会**「茗渓会」**が整備に乗り出し、プロジェクトリーダーは水戸市植物公園園長の**西川綾子**氏。NPO法人**「生態工房」**（井の頭池などのかいぼりを手がける）が協力。
- **表記の注意〔未解決〕**：記事は屋敷の主を**「松平定元」**と書くが、文京区公式 [GOV-051](../gov/GOV-051.md) は**「松平頼元」**とする。〔二次資料の表記揺れ。公式表記を採る〕
- **資料の限界〔未解決〕**：**池の水源（湧水・地下水・用水・水道水の別）は明記されていない**。かいぼり記事は水の入れ替え作業を扱うものであり、池への恒常的な給水源・排水先を示すものではない。
