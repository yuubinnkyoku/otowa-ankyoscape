# [BLOG-140] wanjin「中丸川」2018年・中丸川＝千川上水分水説の第4の裏付け

- **書誌〔確認〕**: 「水の行方を追って」（わんじん）「中丸川　　－捻くれ者の自分にちょっと自己嫌悪－」、2018年6月6日投稿。https://wanjin.blog.fc2.com/blog-entry-248.html 。FC2現行はAccess Deniedのため **Wayback（2026-10-25スナップショット）で全文取得**（2026-11-12確認）。[BLOG-122](BLOG-122.md)（同ブログ・池袋耕地整理）の姉妹記事で、2026-10-23横断調査ノートで「2018年6月支流連載・個別索引が必要」とされていた1本。
- **〔観察・確認〕** 谷端川の支流で名前のある中丸川を通し踏査。**西側の水源＝千川上水からの分水**（靴だけの像が置かれた場所〔観察〕。ここから豊島区・板橋区の区境を進む）→川越街道・中丸町交差点手前で左折→私有地状の水路敷（蓋暗渠）→区境を離れ北進→大山西町からの流れと合流。
- **〔観察・確認〕** **大山西町からの流れも千川上水からの分水**（ゴミ置き場付近が源流で、直行する道路に千川上水が流れていた。**すぐそばに千川上水の境界石が防護下に保管**）→住宅街を北東→**板橋区立板橋第二中学校**敷地内を通過と推定→合流。以降、都電車両が展示される公園（水路跡とみられる）まで辿る〔観察〕。
- **〔仮説を強める根拠〕** 中丸川の源流が千川上水分水とする内容は、①[BLOG-059](BLOG-059.md)（髙山2012・古老聴取「上流は千川上水につながっていてきれいな川・昭和50年代に暗渠」）②[BLOG-081](BLOG-081.md)（Natrium・地籍図＋現地観察）③[BLOG-105](BLOG-105.md)（水徒然2013・学校周年誌回顧絵図の「どぶ川」）に続く**第4の独立した観察記録**。流路の細部（区境沿い・大山西町起点・板橋第二中学校経由）が相互に整合する。
- **〔観察・聴取〕** コメント欄（2024-08-21・Shane_come_back）に地元出身者の証言: **西源流の像のある場所は昔「あさり屋」と呼ばれる小屋に人が住んでいた**。3枚目のバス通りへ出る小道・8枚目からの細い道が川跡だったことを「言われてみれば納得」と回想〔聴取・署名なしネットコメント。伝聞段階〕。
- **〔確認〕** 同ブログの谷端川定義（要町二丁目・粟島神社弁天池水源・延長約11km・神田川最長支流）は[BLOG-125](BLOG-125.md)周辺のrepo既知情報と整合。
- **注意**: 千川上水からの分水とする同定は筆者の踏査・読図に基づく。明治期の分水文書での「中丸川」呼称の直接確認には、[GOV-068](../gov/GOV-068.md)・千川家文書類の照合が必要。
