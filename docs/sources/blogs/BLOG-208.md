# [BLOG-208] 谷端川支流の2源流（やよい児童遊園＋子育て地蔵）と耕地整理バイパス支流

- **直接確認（2026-11-13、第64回・FC2直fetch）**：entry-244（2018-05-09）・245（2018-05-16）・246（2018-05-23）の3回分。URLは代表してentry-244を掲げる（245=https://wanjin.blog.fc2.com/blog-entry-245.html、246=https://wanjin.blog.fc2.com/blog-entry-246.html）。
- **南長崎支流の2源流説〔観察：2018年〕**：この支流は**新宿区中落合三丁目・やよい児童遊園付近**と**豊島区南長崎二丁目・子育て地蔵付近**の二源流を持つと観察する〔南長崎支流（[BLOG-064](BLOG-064.md) 高山の再検証・[BLOG-157](BLOG-157.md) 椎名町支流＝トキワ荘通り起点説）に対する独立読図。**やよい児童遊園を源流とする読みはrepo初出**〕。
- **やよい児童遊園〔観察〕**：同園は**強い降雨時に周辺の雨水を貯留して地下に浸透させる水害防止施設**が地下に併設されている。「もともと周辺の雨水や生活排水などを集めて始まったと思われる流れ」〔雨水浸透施設の存在と支流源流の機能的説明はrepo初出候補〕。流れは東進しクランク状に曲折、コンクリート蓋・風呂屋・クリーニング屋の暗渠痕跡（聖母坂越え）を経て目白通りへ。目白通りを渡り80mで子育て地蔵からの流れと合流。
- **子育て地蔵源流〔観察〕**：子育て地蔵の隣地駐車場脇あたり（**トキワ荘お休み処の北側**）から始まり、マンション敷地内をほぼ直線で東進（「たばこジュー」表示の位置で山手通りを越え）、やよい児童遊園流と合流。合流後は北東へ、**豊島区立目白第一保育園脇・豊島区心身障害者福祉センター（＝真和中学校跡）敷地内**を抜け、**真和中学校跡の脇で谷端川本流と合流**する〔本流合流点＝旧真和中学校前の具体化。entry-236（BLOG-204）の「旧真和中学校の敷地手前で南からの流れが合流」と整合〕。
- **耕地整理バイパス支流〔観察＋推定〕**（entry-245/246）：谷端川から分かれて谷端川に合流する**バイパス状の支流**（要町通り越え後のほぼ直線の流路）を紹介。本来は**谷端川の舌状台地東側の農地へ千川上水の灌漑用水を届けるための開削**で、耕地整理による道路・橋の整備で住環境価値が向上し、用水路が耕地整理によって役割を終えたと推定する〔灌漑支路→排水直線化の変遷の独立考察。池袋モンパルナス・寺田政明の言及は文化文脈〕。
