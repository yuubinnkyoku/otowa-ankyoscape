# [BLOG-219] y-ok.com（雄' Photo Page）「谷端川-1〜4」— 4回シリーズの観察記録〔repo初出〕

- **取得状況〔確認〕**: 「雄' Photo Page-カメラ担いで西東」（30年間の渋谷暮らしで武蔵野と水辺を撮影、2019年岐阜移住と自己紹介する写真サイト）の谷端川4回シリーズ（yabatagawa-1〜4.html）。**第28回以降アクセス不能が継続していた y-ok.com だが、2026-11-14にcurl+UAで谷端川4頁すべて本文取得に成功**。撮影は2018年（サイト内の写真フォルダ「2018-photo/180602-yabatagawa」等。投稿年はページ上に明記なし・未詳）。
- **全体の内容〔確認〕**: 源流（粟島神社）から神田川合流（外堀通り）までの全流路を4回に分けて歩いた観察記録。総延長11km・「神田川水系最長の川」・西武池袋線越えの180度Uターン北流・板橋駅越えの再Uターン南下という流路形態の説明は既知（[BLOG-150](BLOG-150.md)系と同内容）。
- **要町三丁目交差点=千川上水取水口〔確認: 筆者観察〕**: 「画面左右に通る都道402に沿って千川上水が流れていた」「かってここが千川上水からの取水口で、写真前方、千川駅の方向に流されていたらしい。しかし現在その痕跡は全く見当たらない」、千川駅方向の区間の「車道も広いが左右の歩道も不相応に広い」＝分水路跡〔[BLOG-042](BLOG-042.md)（川のプロムナード・長崎分水分水点）・[GOV-080](../gov/GOV-080.md)と整合する独立観察〕。
- **粟島神社〔確認: 観察〕**: 「現在はおそらく水道の水だと思われるが、かってここからの湧水が谷端川の源流となっていた。千川上水からの分水もここに合流していたという」〔2018年時点で人工給水と推定する観察＝[BLOG-217](BLOG-217.md)（2009年人工給水観察）の後年側の独立整合〕。
- **谷端川第二親水公園のポンプ施設〔観察〕**: 南緑道の第二親水公園で「ポンプ施設のようなものが公園敷地に有ったが、親水公園の水利に関係するものか？」と観察し、機能は特定していない〔親水公園の水利施設の存在の観察記録。用途の断定はなし〕。
- **南谷端公園「谷端復興区画整理竣工記念」の碑〔観察・位置の具体化〕**: 谷端川-3（板橋駅〜不忍通り）で「谷端川（暗渠）道の少し脇、南谷端公園に、こんな石碑が立っていたが、谷端川と関係あるのだろうか」と観察〔碑の存在自体はREADME・[BLOG-133](BLOG-133.md)記載だが、**南谷端公園（板橋駅〜不忍通りのコース途中）に現存するという位置の具体化はrepo初出**。区画整理と谷端川の関係は筆者も断定していない〕。
- **千石三丁目交差点=谷底〔観察・読図〕**: 都道436（都電通り）と不忍通り（都道437）の交差点が谷の底で、右70mほど上った所に猫又坂（左）と白鷺坂（右）が対になって坂を昇る、という地形観察。「千川谷」「千石谷」の呼称に触れる〔「千川谷」はREADME既出。「**白鷺坂**」の対坂としての位置特定はrepo初出〕。猫又坂の案内板・袖石碑の観察は[BLOG-164](BLOG-164.md)・[BLOG-079](BLOG-079.md)と整合（猫又橋袖石移転保存説の系列）。
- **千石小石川区間の流路読図〔推定・断定せず〕**: 谷端川-4で「都道コース」（谷底の都道436沿い）と「脇道コース」（436に並行して蛇行する道筋）の2つの流路説を対置し、「元々この辺を流れていた谷端川は、川筋が1本と言う訳ではなく、何本かの流路に分かれてこの谷を流れていたものが、後に1本に統一された経過が有るらしい」として**実際の流路は特定しないまま**、地形優先で都道コースをやや支持する個人の読図。〔人工水路が高い所を通れる（玉川上水＝峰筋の例）という一般論と併記。流路特定の素材としては複数流路説の側に立つ観察記録〕
- **簸川神社・千川改修の碑〔観察〕**: 「脇道コース」上の小石川植物園手前に簸川神社があり「千川改修の碑が有った」〔碑本体は[GOV-062](../gov/GOV-062.md)・[BLOG-077](BLOG-077.md)・[BLOG-164](BLOG-164.md)で既出。位置関係の観察として記録〕。
- **東京ドーム広場の水場〔観察〕**: 東京ドーム・ショッピングモールの広場の人工水場について「この水場は谷端川（千川・小石川）流路に沿って設えたものだそうだ」と記す〔谷端川下流末端部の現代の水辺デザインと流路の重なりについての観察記録。「そうだ」と伝聞形式。外堀通り（都道405）沿いでは「谷端川の排水口などの表示は無かった」との観察も併記〕。
