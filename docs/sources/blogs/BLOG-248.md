# [BLOG-248] 和田一彦「善福寺川湧水 原寺分橋下流」（note）〔repo初出・区側一次文言を含む住民観察記〕

- **書誌〔確認: note本文・2026-11-21取得〕**: note（投稿者: 和田一彦「善福寺川を里川にカエル会」）「善福寺川湧水 原寺分橋下流」**2026年4月26日10:19投稿**。repoで和田氏・「里川にカエル会」のnoteは初採録。
- **区側回答文言〔確認: 本文引用・repo初出の杉並区一次文言〕**: 2025年4月8日付（受信番号3127）「**荻窪地下道湧水清掃と善福寺川原寺分橋下流湧水の説明パネル交換**」の区長への手紙への回答（杉並区都市整備部土木計画課長 瓜生昌彦署名）: ①「当該パネルは、善福寺川流域の湧水や水環境について理解を深めていただくことを目的として、**平成15年度に設置したもの**です」（経年劣化で文字が判読しにくい状態と現地確認）②「**原寺分橋付近は、善福寺川の中でも特に湧水が豊富であることから**、区民の皆様に実際に湧水を感じていただきながら理解を深めていただく意味で、説明パネルの役割は重要」③「湧水の枯渇や湧水量の減少などの問題が生じており、区といたしましても、これらの貴重な湧水を保全するための取組が必要」④「当該パネルの更新について検討を進め、準備が整い次第対応」＝区側が明文化した原寺分橋湧水の位置づけ文言。
- **観察文言〔確認: 本文〕**: ①「杉並区西荻北４丁目40番地 岸壁から湧水」②「**井荻小学校内を善福寺川が流れています**」（校地内流下・藤棚の観察）③[ORG-037](../org/ORG-037.md)（2018年5月）のjagh動画と比べ「**2018年動画に比べると水量が減っているように思います**」＝2018→2026年の湧水量減少の体感観察。
- **意義〔観察〕**: ①「**特に湧水が豊富**」という区側文言は[GOV-485](../gov/GOV-485.md)FAQ（都＝アンケート湧水マップ記載・観測井戸設置）・[GOV-486](../gov/GOV-486.md)（地下水位3.5m）と民・区・都の三層で重なる原寺分橋湧水の行政認識を示す、②**井荻小学校の校地内流下**は[GOV-485](../gov/GOV-485.md)FAQの区立井荻公園（低地部のみ・調節池連絡管立坑の仮設活用）と同じ井荻地区の善福寺川流路の新情報、③「**荻窪地下道**湧水」の言及＝JR荻窪駅付近の地下道に湧水が存在するという観察の記録（清掃要望の文脈）＝荻窪の水システムの未採集情報〔要精査〕、④平成15年度パネル＝[GOV-487](../gov/GOV-487.md)の57選が平成15年1月発表とほぼ同時期の区政側の施策。
- **制限・未解決**: ①「荻窪地下道湧水」の位置・現況は本文に詳細なし。②井荻小学校の流下が常時（暗渠を含む）か否かは本文不明。③説明パネルの更新実施の有無は未確認。
