# [BLOG-096] 上保谷新田の水車稼ぎと平井家の工業化

- **書誌**: 滝島俊（郷土史研究家）「[千川上水と上保谷新田の水車](https://nishitokyo-web.com/468)」（西東京市INFORMATION WEB「西東京市歴史探訪⑧」。2024年）。2026-11-11全文取得確認。
- **〔確認〕** **上保谷新田の草分け百姓・平井伊左衛門（繁庸）が1818年（文政元年）に水車設置を願い出て受理**。**水車場は現在の柳橋交差点西角付近で、専用水路を千川上水の上流約400メートルから引き込み**、精白・製粉の「水車稼ぎ」で財を成した。**1835年（天保6）の上保谷新田の分村成立とともに名主となる**〔確認：筆者叙述／未確認：願い出・絵図の原本〕。
- **〔確認・二次〕** **明治2年上保谷新田絵図**に水車場の記載と名主伊左衛門家がある〔確認：筆者による絵図抜粋掲載／原本の所在は記事に明記なし〕。上保谷新田での流れは**宝永4年（1707）の農業用水利用許可以降確保され、水車は江戸市中の給水停止・復活の影響を受けず稼働を続けた**とする。
- **〔確認〕** **平井週作（明治2年の御門訴事件の中心人物）**が明治半ばに**水車を銅線工場の動力として利用**し、**千川上水下流に新たな水車場（坂上水車）を設けて事業を拡大**。実経営は三谷氏・奥住氏とみられる。**当初の水車場は伸銅工場として昭和末期まで、坂上水車は戦時中に中島飛行機の部品工場として操業した**〔確認：筆者叙述／未確認：工場の登記・営業記録〕。
- **〔参考・確認〕** 明治39年測図の地理院地図に千川上水沿いの2か所の水車場が見えるとする。武蔵野新田（享保7年〔1722〕以降）開発の概説もある。
- **〔未解決〕** 御門訴事件の経緯と水車経営の関係、平井家の「公有土地水面使用願」（[BLOG-097](BLOG-097.md)参照）との照合、水車2基の廃止年。
