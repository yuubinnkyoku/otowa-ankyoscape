- **書誌〔確認: ブログ本文全文・2026-11-23取得〕**: 鉄道系多人執筆ブログ「Freedom Train」の個人記事。**投稿日2026年11月7日10:00・著者「みね」**（新潟県出身の大学生の自称あり）。**取材日は2026年10月24日〔確認: 本文「取材日(10/24)」〕**・大塚駅から都電荒川線沿いに徒歩10分で大塚台公園へ。**本文末尾に「p.s.11/21現在、予定通り公園は閉鎖されたようです」の追記〔確認〕**。 https://freedomtrain.jp/mine0455/58046/ 。**車歴情報の引用元は「C58407 機関車データベース（形式C58）– デゴイチよく走る!」〔確認: 本文「引用」節に明記〕＝本文車歴も機関車表・データベース系の二次情報**。
- **車歴の文言〔確認: 本文文言・二次情報〕**: 「C58-407は**1946年末**に大阪にあった**汽車製造**（現在の川崎車両に吸収）で製造」「C58自体は民鉄や輸出用含め**431両の製造**」「**新製配置は苗穂機関区**、以後廃車まで道産子を貫く」「**苗穂機関区→函館機関区木古内支区→函館機関区→五稜郭機関区**と来て、**1973年に新製配置された苗穂機関区に帰還**、ここで廃車」「木古内支区では支区廃止に立ち会った数少ない機関車で、最終配置車6両（C11形1両・C58形5両）の内の1両」「**廃車は1974年3月20日付け**、生涯で**約932,800km**（地球約23.3周）走行」。**関東側での現役履歴を含まない北海道一貫の車歴**として[BLOG-291](BLOG-291.md)（「函館で新製配置…五稜郭配置時に廃車」）と同系統の独立二次資料で、**配置順（函館系を経て苗穂帰還後に廃車）と木古内支区の細目・総走行距離は本資料がrepo初出**〔いずれも機関車データベース由来の二次転記・国鉄一次文書との照合は未実施〕。
- **展示開始・無償貸与契約の文言〔確認: 本文文言・二次情報〕**: 「遠路はるばる東京へ輸送された後、**1974年5月5日展示開始、翌6日に当時池袋周辺を管轄してた東京北鉄道管理局長と豊島区長との間で無償貸与契約が締結**」「なおこの契約は(**たぶん**)JRが引き継いでおり、先例を考えると契約上この機関車はJR東日本の持ち物ということになります」〔**かっこ内「たぶん」は筆者の推測文言・貸与主体の現行承継は推定として区別**〕。廃車（1974年3月20日）→東京輸送→**展示開始1974年5月5日**という月単位の年代確定情報はrepo初出で、[BLOG-290](BLOG-290.md)（池袋タイムズ「1974年(昭和49年)に北海道から運ばれてきた」）との整合がとれた〔展示年の「1974年」が独立二次資料2系統で一致・月日の最終確認は行政側一次文書待ち〕。
- **現車細部の観察〔観察: 筆者撮影写真付きの現地観察・2026年10月24日〕**: ①**運転台に上がる部分に扉が付けられている**＝「北海道など、冬が厳しいエリアに配置された機関車の必須装備」（現役C57-180との対比写真付き）。②**炭水車後ろのナンバープレートが手書き**（「盗難にでもあってしまったのでしょうか…」は筆者の憶測文言・盗難の有無は本文では未確認）。③**非公式側に「49-5-16 OM」の書込み**＝筆者は「昭和49年5月16日付で大宮工場で検査を終えている」標記と判読し、「展示後の検査」となることを「どういうことなんでしょう？」と疑問視〔判読・解釈とも筆者観察で、標記の意味付けの確定はしていない〕。④副灯・ATS-S型のみの表記・タブレットキャリアらしきもの・動輪縁とロッド類の白塗り（展示後の修繕の可能性を筆者が推測）。⑤柵の説明板プレート（「歩んだ道」等）の内容が「筆者仕入れてきた情報とかなり違う」〔BLOG-291が説明板①②を転写済みで、文言差の検証材料〕。
