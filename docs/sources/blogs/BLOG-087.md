# [BLOG-087] Natrium.jp 谷端川支流（池袋近辺）

- **直接確認（2026-11-11、open_url・本文全文）**：板橋駅西側から池袋駅まで南へ遡る、東京ではいわゆる**逆川**（北へ向かう谷端川本流に対し南へ向かう支流）の西側流路を中心とした観察（2017年11月26日撮影）。
- **東西2本の並行流路〔確認：観察〕**：板橋駅西側〜池袋への谷の東西に**2本並行して流れていた**とし、西側の流路を下板橋駅近くの「電車の見える公園」から追跡。**東上線をまたいで東側へ抜けていた**地点、東京総合車両センター池袋派出所の東側の行き止まり道、上池袋公園の南側で水路敷が復活する箇所、**山手線掘割**へ向かう路地を記録する。〔観察／2本説の典拠は本文にない〕
- **上流端＝池袋六ツ又〔観察・推定〕**：西側の水路敷は**池袋六ツ又交差点**（国道254号・都道305号・435号・441号が交わる六叉路）に出て、**その脇に七番目の道路として水路敷が加わる形**になっていると記す。**上流端そのものは道路に巻き込まれて良くわからない**と留保する。〔推定〕
- **六ツ又の庚申塔〔確認：観察〕〔repo初出〕**：六ツ又の近くの**ビルの壁の中に「庚申様」の庚申塔**が鎮座し、ビルの名前も**庚申ビルディング**。看板には**豊島区重要文化財**と書かれているが、**豊島区ホームページの区指定文化財一覧にはリストアップされていない**という。〔観察／指定の実態は未確認〕
- **repoへの関連**：この支流は[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)でいう板橋駅西側〜池袋の支流（[BLOG-050](BLOG-050.md)の板橋駅西口区境・[BLOG-084](BLOG-084.md)の一の橋から池袋駅方向の支流と同系）の流路具体化資料。**池袋六ツ又を上流端とする説**は、池袋駅西口の谷頭群（丸池・西池袋公園説など）とは別の支流系として区別する手掛かりになる。〔推定／水路の地籍上の帰属は未照合〕
