# [BLOG-230] 洋紙発祥之地碑のパネルと千川上水の掛桶渡し（wheatbaku「幕末の大砲製造所⑩」）〔repo初出〕

- **直接確認（2026-11-15、open_url・本文全文）**: 気ままに江戸（夢見る獏）の「[『洋紙発祥之地』の石碑（幕末の大砲製造所⑩）](https://wheatbaku.exblog.jp/32713239/)」（**2022年8月21日**）。同シリーズ②⑧⑨は[BLOG-227](BLOG-227.md)・[BLOG-228](BLOG-228.md)・[BLOG-229](BLOG-229.md)。
- **石碑と説明板〔確認：本文の現地記録〕**: JR王子駅中央改札口北側に「**洋紙発祥之地**」石碑（**工場創立80周年を記念して昭和28年10月建立**・碑文は「此地ハ明治五年十一月渋沢栄一ノ発議ニ因リ創立シタル王子製紙株式会社ガ英国ヨリ機械ヲ輸入シ洋紙業ヲ起セシ発祥ノ地ナリ…」）と、日本製紙設置の説明板（明治6年抄紙会社設立・昭和20年戦災で歴史を閉じる・昭和24年苫小牧製紙・十條製紙・本州製紙の三社分割）がある。
- **2021年設置パネルの水系記述〔確認：パネル文言の採録〕**: 大河ドラマ「青天を衝け」（2021年）放映を機に石碑裏の壁面へ設置された「洋紙発祥の地」パネルに、**「豊富な水源石神井川、千川上水が製紙関連工場群を造り、近代化産業に導く」**、および**「抄紙会社工場内と国立印刷局内には石神井川上に掛桶(木桶)で渡して千川上水を工場に引いていました。かつては江戸幕府が滝野川村に反射炉と水車を設置時、石神井川の川幅広げ、川底を下げる堀継ぎ工事が行われていた地域。」**、**「製紙工場が水路利用するための証書や嘆願書等が多く交わされています。その貴重な資料は紙の博物館に保存されています」**という文言がある〔**「掛桶（木桶）で石神井川上を渡して千川上水を引く」という抄紙会社・印刷局（紙幣寮抄紙局→印刷局）の取水構造の記述はrepo初出**。千川上水（王子分水）が石神井川と立体交差して工場に導水された構造を、2021年時点の現地パネルが説明する資料。**証書・嘆願書が紙の博物館に保存されるという所在情報もrepo初出**で、千川上水の明治期水利の一次資料群の探索先になる〕。筆者は、反射炉建設・王子分水開削が小栗上野介の上申・働きかけによることをパネルが明記していない点を批判的に論じている〔パネル文言の史実性より筆者の論評部分は意見として扱い、文言自体のみ記録〕。
- **制限〔未解決〕**: ①パネルの設置主体（日本製紙か・北区か）・設置年月の正確な確認は未実施（本文からは2021年放映に伴う設置と読める）。②「掛桶」の位置（石神井川のどの区間・何か所）・撤去時期は不明で、空中写真・地籍図での検証課題。③紙の博物館所蔵の証書・嘆願書の所蔵番号・目録は未確認。**→ 第92回（2026-11-15）所在特定済み: 収蔵品データベース（jmapps）の「水利権関係書類」（[GOV-150](../gov/GOV-150.md)・収蔵ID:945・124点画像公開）として、明治7年9月3日の抄紙会社×王子村外23ヶ村の約定証書・明治8年3月10日の千川用水之儀鹿嶋萬平×抄紙会社の約定証書等が収蔵解説に掲載。加えて明治38年「千川上水使用権利詳細平面図」（[MAP-163](../maps/MAP-163.md)）も特設ページで紹介。「嘆願書」に該当する個別文書の特定は画像判読まで残る**。④碑文「明治五年十一月創立」と説明板「明治6年設立」の年次差は本文で整理されておらず断定しない。
