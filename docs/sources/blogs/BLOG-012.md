# [BLOG-012] 「ミョウガの谷を歩く」（暗渠さんぽ、2010年）

- 「暗渠さんぽ」2010年3月5日、茗荷谷駅裏から小桜橋下の神田川合流口までの谷歩き記事。
- [ミョウガの谷を歩く](http://kaeru.moe-nifty.com/ankyo/2010/03/post-8929.html)
- 筆者はこの谷を流れる川について「手持ちの古地図、書籍ではこの谷を流れる川らしき表記は見つかりません」と記し、仮称「茗荷谷支流（仮）」を用いる。**人参川・古茗荷谷川の名称は本記事の取得テキストには現れない。**
- 経路の内容メモ：茗荷谷駅裏の谷状の下り坂→拓殖大学横→丸ノ内線高架下→伝明寺（藤寺）脇の藤坂→小石川車両基地沿い→小桜商店街→小桜橋下で神田川と合流。旧茗荷谷町の説明板として「小石川台地と小日向台地の間の浅い谷を、茗荷谷と呼んでいる。江戸時代、茗荷畑が多かったからといわれている。」を引用。伝明寺付近の説明板として「清水谷は小日向の谷なり。むかしここに清水が湧き出した。」を引用。
- **本記事は谷の呼称・経路の記録であり、人参川・古茗荷谷川との同一性の証拠ではない。** 写真の転載はしない。
