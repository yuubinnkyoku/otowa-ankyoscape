# [BLOG-133] 夢七雑録「谷端川（千川上水長崎村分水）跡を歩く−３−」

- **書誌・取得〔確認〕**：gooブログ「夢七雑録」2018-06-02付。BLOG-033（−１−）・BLOG-042（−２−）の続編で、**第6回以降アクセス不能が続いたpart3を、今回Wayback Machine保存版（id_指定）で本文全文取得した（2026-11-12、第30回）**。直接アクセスはgooブログサービス終了により遮断。
- **内容〔確認：本文全文〕**：下板橋駅から神田川合流点（市兵衛河岸）までの谷端川下流（小石川区間）を橋単位にたどる記録。著者の参考資料：『旧谷端川の橋の跡を探る』（BOOK-062）『千川上水関係資料Ⅰ』『新編武蔵風土記稿』『御府内備考』『御府内場末往還其外沿革図書』『いたばしの河川』『江戸名所図会』『東京図測量原図』（明治16）『豊島区地域地図集』等。
  - **池袋村絵図の谷戸と水源の読図**：下板橋周辺の谷戸は下流域を**雲雀谷戸**、上流域を**下り谷**と呼んだ（BLOG-065/066と整合）。谷戸は線路を越えて**現・池袋六ツ又付近**に達し、江戸時代の池袋村絵図では水源は**六ツ又より南＝現・サンシャインシティ付近**、**雑司ヶ谷道沿いにも水源＝現・池袋の森の近く**。谷戸からの流れは本来谷端川本流に流れ込むはずだが、池袋村絵図では**西前橋で谷端川本流から分水された分水路**（本流の南側を東流、明治通りの手前で本流に合流）に流入。**昭和4年の地図ではこの分水路は消滅**し、谷戸からの流れは本流に直接流入。
  - **下流区間の橋名・史料〔repo初出のもの〕**（著者の読図・伝承を含む、断定しない）：谷端橋（地名由来）、**鎌倉橋**（旧鎌倉街道跡、江戸時代から存在）、上之橋（山手線近くの流れ＋**薬学者丹羽藤吉郎邸〔後に山口邸〕の瓢箪形の池**の合流点）、中之橋、宮仲橋、**葮山橋**（北大塚三の交差点南側）、**蛇子橋（真法橋・寂法橋）**（巣鴨新田からの道が越える）、姿見橋（大塚三業地入口、紅色欄干）、見返橋、熊野窪橋（熊野神社由来〔BLOG-114の応永伝承と交差〕）、東福寺橋、**砂利場橋**（『新編武蔵風土記稿』：**護国寺造営の砂利取り場として使用された谷端川沿いの土地を享保年間に願い出て開墾し新田とした**と記す。土橋）、**一木橋**（いちもく橋・上猫貍橋・一本橋。砂利場橋の土橋が壊れた後に丸太の一本橋が架けられたかも知れないという憶測）、氷川橋（明治、千川通り＝都道436号の開通時に架設）、祇園橋（『新編武蔵風土記稿』では氷川橋、『御府内備考』・『江戸名所会』では祇園橋。当初土橋→後に木橋）、**久堅橋**（『上水北小日向小石川辺絵図』の橋戸町・戸崎町の橋、明治16年東京図測量原図で久堅橋と記載。明治40年小石川区全図では祇園橋との間に橋なし、昭和6年小石川区地籍図では複数橋が新設）、無量院前の橋（**戸崎橋と呼ばれていたかも知れない**という憶測）、**掃除橋**（先手組組屋敷の橋が明治に掃除町へ編入され改名）、**千川橋**（柳町から掃除町へ渡る橋、東京図測量原図で千川橋と記載〔谷端川が千川分水とも呼ばれたためかも知れない〕）、**裏柳橋**（柳町に渡る橋）、**源覚寺橋／嫁入橋**（東都小石川絵図では源覚寺橋、明治の橋柱に「嫁入橋」があり東京図測量原図でも嫁入橋。名主家の嫁入りを祝って橋を新しくした伝承）、**丸太橋**（もともと丸太の一本橋、明治時代には石橋）、富坂橋（江戸時代の坂下は今より南で位置が異なる）、仙台橋（市兵衛河岸、谷端川最下流の橋）。
  - **嘉永7年『御府内場末往還其外沿革図書』の読図**：蛇子橋の近くで合流する流れのほか、**大正大学付近を源流とし旧中山道に沿って流れ、庚申塚の手前で旧中山道を横切って南流する小川が谷端川に合流**していた。
  - **享和元年巣鴨村絵図の読図**：鎌倉橋と藤橋（富士橋・乞食橋〔BLOG-093と交差〕）の間に**四カ所の橋**を記す。『新編武蔵風土記稿』の橋のうち**上橋＝上之橋、寂法橋＝蛇子橋に該当すると思われ**、残り2カ所のうち1つは中之橋か、あと1つは判然としない。
  - **藤橋から先の水量**：西側**天祖神社付近の湧水池**からの流れと東側**天満宮付近の湧水池**からの流れが合流しているため水量が増えたと推定。
  - **昭和4年巣鴨町西巣鴨町全図**：東福寺橋と宮原橋（区境）の間に幾つかの橋を記載（明治42年地図では橋なし）。
  - **祥雲寺**：小石川から**後に池袋に移転**し、移転先の坂の下にも谷端川が流れていた。無量院は明治に廃寺。
  - **千川改修記念碑**（簸川神社、昭和9年暗渠化記念〔BLOG-077/070と整合〕）・東都小石川絵図の「**小石川大下水**」表記・「千川谷」呼称（千川上水長崎村分水を略して千川分水とも呼ばれたためかも知れない）。
