# [BLOG-119] ma-maison「小石川 歴史散歩(3)」

- **資料〔確認〕**：ma-maison（小石川地区の個人歴史サイト）の「小石川の地名の由来を探る（3）」頁。**同サイトは既収録（MAP-051・BOOK-009・GAZ-003等）だが本頁は未資料化**（link-auditのURL一覧には存在）。
- **『小石川區史』（昭和10年・1935）の直接引用〔確認：サイトの引用文言〕**：「小石川は江戸川の支流で、通稱（称）を千川と云ふ。源を長崎町に發し上流を谷端川と呼び、西北から迂回して丸山町で本區に入り、千川となって林町白山御殿町臺（台）地と大塚臺地との間を南東に流れ、**柳町附近で本郷臺下より來る指ヶ谷の溝（どぶ）水を併せ**、南流して小石川町で神田川に注いでゐる」。※**指ヶ谷（東大下水）の合流位置が「柳町附近」（現・小石川1丁目）と明治期区史レベルで特定される引用はrepo初出**。谷端川/千川呼称の境界（丸山町＝現千石3丁目旧町名）も引用内で確認。
- **昭和15年（1940）地図の読図〔確認：サイト記述〕**：千川の埋立後、**千川通りの道路計画が二重の赤線で示され、川は植物園付近まで暗渠になり、氷川下町・丸山町・巣鴨町の区間はまだ開渠として残っていた**。※1934年暗渠竣工（BLOG-077）以降も上流側に開渠が残存した時期があったことを示す読図〔観察。原本地図の再確認を要する〕。
- **千川通り・千川幹線〔確認〕**：現在の千川通り＝千石3丁目交差点から富坂下交差点まで（旧河川名に由来）、**その下を千川幹線と呼ばれる基幹下水道が流れる**。
- **礫川の地名の継承〔確認〕**：**礫川小学校（小石川2丁目・明治6年開校）**、**礫川公園（春日1丁目・昭和40年造設）**。北斎『富嶽三十六景「礫川雪ノ旦」』、小日向絵図の「礫川」表記。
- **中世文献上の小石川初出〔確認：サイト記述〕**：道興『回國雜記』文明19年（1487）、**文安5年（1448）『熊野領豊島年貢目録』の「五百文小石河四人」**、応永27年（1420）『武蔵国江戸之書立』（小石河を指すと考えられる書立）。**中世豊島郡文書による小石川の初出史料系譜はrepo初出**。
- **注意**：上記の中世文書・『小石川區史』引用はサイト経由の二次確認。原本（『回國雜記』・年貢目録・区史）は未確認のため、**引用文言の一字一句の検証は原本確認まで留保**する。
- **未解決**：『小石川區史』（昭和10年）の所蔵・閲覧手段、昭和15年地図の図幅特定、『熊野領豊島年貢目録』の所在。
