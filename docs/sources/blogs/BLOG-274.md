# [BLOG-274] 西東京水路跡散歩「関前の水路（関野用水）」3本＋「砂川用水（深大寺用水）」2本〔repo初出・関野用水の全流観察と千川上水交点・島﨑水車の廻し堀構造〕

## 内容〔確認: 本文全文5本・2026-11-22取得〕

- **書誌〔確認〕**: アメーバブログ「西東京水路跡散歩」（musasinowalker・[BLOG-272](BLOG-272.md)と同一筆者）の水路シリーズのうち、①**関前の水路（関野用水）その1〜3**（[entry-12579184757](https://ameblo.jp/musasinowalker/entry-12579184757.html)〔2020-04-25〕・[entry-12580177528](https://ameblo.jp/musasinowalker/entry-12580177528.html)〔2020-04-26〕・[entry-12580348896](https://ameblo.jp/musasinowalker/entry-12580348896.html)〔2020-04-27〕）＝玉川上水北側〜千川上水南側に囲まれた武蔵野市関前の用水、②**砂川用水（深大寺用水）その1〜2**（[entry-12580474479](https://ameblo.jp/musasinowalker/entry-12580474479.html)〔2020-04-28〕・[entry-12580893712](https://ameblo.jp/musasinowalker/entry-12580893712.html)〔2020-04-29〕）＝西武多摩湖線以東の砂川用水＝ともに配水管完成前の多摩地域の小水路網を現地写真で追うシリーズ記事。
- **関野用水その1（樋口橋〜桜通り）〔確認: 本文直接引用〕**:
  - 「**玉川上水北側と、千川上水南側に囲まれた関前地域に、水路が作られているのに気がつきました。関前新田と呼ばれるこの一帯は、両上水に囲われた地域でありながら水に難儀した土地だったようで 1つの深井戸を20軒以上で使っていた時期もあったそうです**」＝**関前新田＝両上水に挟まれながら水難儀の土地・深井戸1口を20軒以上共有〔伝聞〕**。
  - 「**関野用水が作られた後、その流末を千川上水を越え関前新田に伸ばすことで水不足の解消を図りました**」＋「**資料では水路は（樋口橋付近で）千川上水に落ちていた**」＝**関野用水の流末は千川上水を渡（越）えて関前新田側へ延伸されたという流路構造**。
  - 「**樋とは家の屋根の水を地面や排水口へ通す水路です。ここでは千川上水を渡す水路の事を指していたのではないでしょうか、「樋の（出入）口がある橋」で樋口橋と名付けられたと思われます**」＝**樋口橋の語源説＝千川上水を渡す樋（水路橋・樋管）の出入口の橋**〔筆者の推定〕＝**千川上水と用水の立体交差点の地名証拠という読み〔repo初出〕**。
  - 「**時系列としては、1670年頃に関前新田が拓かれるも長く水不足に苦しむ、1732年関野用水掘削、以降ある時点で流末を千川上水を越えて関前新田へ伸ばす、1871年新堀用水掘削、関野用水は水車用水路（新堀用水）に接続されるという感じでしょうか**」＝**関前新田開拓1670年頃→関野用水掘削1732年（享保17年）→千川上水越え延伸→1871年新堀用水掘削で水車用水路（新堀用水）へ接続という時系列の整理〔「でしょうか」の推定形〕**。
  - 「**千川上水を越える関前への水路はいつまで使われていたかは不明です**」＝樋の存続年代は不明と明記。
  - 現況として、樋口橋への直線路（桜通り＝玉川上水側から緩やかな下り）、東への分水路の痕跡、樋口橋公園沿いの東流（本流扱い）→武蔵境通りの手前で南北に分岐という流末側の枝網。
- **関野用水その2（武蔵境通り付近〜境浄水場北側付近）〔確認〕**: 「**井ノ頭通りは水道道路の別名の通り、都心へ向かう送水路があった用地を道路に転用したもので、１９２０年代以降に完成した新しい道です**」＝**井ノ頭通り＝送水路用地の道路転用（1920年代以降）という道路史の整理**〔repo初出候補〕。仲通り（関前新田の主要道候補）沿いの水路構造は「重複している部分がある」・御嶽神社（周辺は戦後まで大きな林・門前橋の推定）・北へ延びる分水跡など中路地の現況。
- **関野用水その3（関前4丁目公園付近〜千川上水付近）〔確認: 本文直接引用〕**:
  - 仲通りから北への2水路（西側＝畑に沿い現存・東側＝遊歩道化）は関前3丁目で合流し五日市街道へ。「**資料では水路は五日市街道辺りで消滅しているが、実際に現地で見てみると道路を渡り北側に伸びていたような痕跡がある**」＝**資料上の水路終点の五日市街道を越えた北進痕跡という現地読み**。
  - 畑の境界標＝「**隣の民家に対して１ｍほど離れた場所に境界標が打たれている。標識には「武」という文字が見える、武蔵野市の事か？小規模水路である用水路敷は当然市町村の管理なので、この間が水路跡ではないか**」＝**武蔵野市の境界標（「武」字）による用水路敷の検出法〔現地観察〕**。
  - 「**写真奥の青い陸橋がある場所は、千川上水の武蔵野大学前の交差点**」＝北進推定流路の目標座標。五日市街道と大師通りの交差点に「**御門訴事件記念碑**」（明治初期の農民闘争の犠牲者の慰霊碑）を記録＝**関前新田の水争い史の石碑候補**〔碑面の碑文確認は本文になし・次回以降の確認課題〕。
  - 大師通り沿いの歩道が消える路地を「**歩道が水路跡の道路転用したものだとすれば、この路地が水路跡なのではないかと思われる**」＝千川上水方面への接続の推測で連載を終える＝**関野用水の流末＝千川上水方面（還流か合流かは未確定）という推定文言**。
- **砂川用水その1（桜橋付近〜小金井分水分岐点）〔確認: 本文直接引用〕**:
  - 「**砂川用水は小川用水と同時期の１６５７年に開削された、玉川上水の分水路でも初期につくられた水路です。当初は現在の立川市一番町辺りで玉川上水から分水し、名前の通り砂川村で使用する水を運んでいました**」＝**1657年（明暦3年）開削説・当初取水点＝立川市一番町辺り〔repo初出の年号候補〕**。
  - 「**初期の頃は総延長4キロ程度とされており、現在の砂川七番から八番くらいで流末となっていたようです**」＝**初期延長約4km・流末＝砂川七〜八番という原形**〔「されている」の伝聞〕。
  - 「**明治に入り、玉川上水北側に各用水路に水を分ける新堀用水が掘削された頃、南側の各用水路の取水も統合する必要ができました。さらに砂川用水に接続する梶野新田用水も延伸して、深大寺方面への送水を最終目的としたことから、砂川用水は深大寺用水とも呼ばれるようになったようです**」＝**深大寺用水の別名の由来（梶野新田用水経由の深大寺送水目的）**＝[BLOG-267](BLOG-267.md)・[GOV-510](../gov/GOV-510.md)の砂川用水系の名称体系の観察側の整理〔拡充〕。
  - 現況として、西武多摩湖線交点・小平市立上水中学校北側の遊歩道化区間・喜平橋（金網越しに大きな溝、「**溝からは水が落ちる音がする、そこそこ深い場所に落ちている感じだが、下水に落としているのだろうか？**」）・稲荷神社（多摩湖線東側）の「**取水口に向かって勢いよく水が流れ込んでいる**」＝**稲荷神社境内への取水口の現地観察〔流末の用途は未確認〕**。
- **砂川用水その2（小金井街道〜梶野橋付近）〔確認: 本文直接引用〕**:
  - 「**昭和初期までこの場所より１００ｍほど西の場所には、島﨑水車と呼ばれる水車があった。現在、競技場通りの砂川用水の橋の脇に、市の設置した案内板があります**」＝**島﨑水車の位置（小金井街道交点より西100m・競技場通り付近）と市の案内板の存在**＝[BLOG-273](BLOG-273.md)（まろん通信No.19の「小金井市教育委員会「水車跡」看板」）と**同箇所の独立系統の観察＝相互補強**。
  - 「**水車のある辺りでは水路は2つに別れ、下向きの三角形のような形を作り、直線側に水車を設置していたようです。現在の砂川用水は、直線側水路のみ残されており“廻し堀”と呼ばれる迂回水路は埋め立てられてしまいました。昭和20年代までは迂回水路が残っており、その後昭和40年代までに埋められたようです**」＝**島﨑水車の廻し堀構造（2水路分岐・ 直線側に水車）と、迂回水路の残存＝昭和20年代まで→埋立＝昭和40年代までという廃止年代帯〔repo初出の構造・年代帯文言〕**。
  - 「**緑中央通り付近では水路は南へ迂回してからまた玉川上水付近まで戻ります。このエリアでは、唯一素掘りの水路を見る事ができる場所がある、水が流れなくなって数十年がたっているのだろうが、溝もしっかり残っており通水も可能なように見えた**」＝**桜町1丁目・緑中央通り付近の素掘り水路区間＝砂川用水で現存する唯一の素掘り〔現地観察〕**＋「**新小金井街道沿いの田無用水と大きさや作りがよく似ており**」という田無用水との構造比較。
  - 「**壁面は底から10～15センチの所まで直線上に汚れていて、通水があったころはここまで水が流れていたのだろう …と思ったが状態があまりに綺麗すぎる気がする。ひょっとして、今でも雨水排水路として大雨の際水を流しているのだろうか？**」＝**桜町1丁目区間の雨水排水路としての現役使用の可能性という観察仮説**（= [BLOG-273](BLOG-273.md)No.20の「20年で1回だけ水が流れた」口碑と対照可能）。

- ①**樋口橋の語源説と千川上水越え（関野用水1・3）**: 千川上水がrepo主題（千川上水・周辺用水）である点で、**千川上水を渡す樋（用水の立体交差）の存在とその出入口地名の観察はrepo初出**で、[GOV-511](../gov/GOV-511.md)等の千川上水沿いの橋・樋観察に追加する。関野用水の流末=千川上水方面（還流か合流か未確定）は千川上水の「排水先・給水先」の体系に新規の系統を加える。②**関野用水の1732年掘削説**: 梶野分水の享保17年（1732）許可説（[BLOG-269](BLOG-269.md)・二次転記）と同年＝**享保17年の分水ラッシュ期という候補の観察**（両説の史料系統の同一性は未確認・同一人物の史料に由来するかは断定しない）。③**関前新田の水争いの系譜**: [GOV-501](../gov/GOV-501.md)（西東京『水』飲み噺）の「**上保谷新田は19世紀前半、水車を作るために関野分水の流れる道筋を勝手に変更し、下流にある関前新田と二度も裁判**」「**水車は取り払われました**」という関野分水争議の記録＝**当ブログの関野用水観察はこの訴訟対象水路の現地側の流路データ**という強い対照関係（御門訴事件記念碑〔関野用水3〕も水争い期の碑候補として隣接する）。④**島﨑水車の相互補強（砂川用水2）**: [BLOG-273](BLOG-273.md)（教委看板・石臼＝小金井神社薄塚奉納）と、本記事（廻し堀構造・迂回水路の埋立年代帯）は**同箇所の2系統の独立観察**。稼働終了は「昭和12･3年頃まで」（まろん・伝聞）／「昭和初期まで」（musasinowalker）＝実質整合だが文言別として記録。⑤**砂川用水の原形（砂川用水1）**: 1657年開削説・取水点の変遷（立川市一番町→〔明治の統合〕→[BLOG-273](BLOG-273.md)No.18の松中橋〔立川・昭島市境〕）・初期流末＝砂川七〜八番という**沿革の前半部分はrepoの砂川用水系記録（GOV-501・510・BLOG-266〜273）の系譜側の補完**。

## 意義〔観察〕

- 関野用水（関前の水路）はrepoで初めて系統的に収録する用水で、**玉川上水×千川上水の間に挟まれた関前新田の難水地史（深井戸共有→1732年掘削→千川上水越え→1871年新堀用水接続）と流末側の現地観察**を供給する。特に**樋口橋語源説（樋の出入口）は千川上水を渡す樋という水利構造が地名に残る例**で、千川上水沿いの小規模立体交差の観測点として独自。島﨑水車の廻し堀構造（2水路分岐の三角形）と迂回水路の埋立年代帯（昭和20年代〜40年代）も、砂川用水の水車史（[GOV-501](../gov/GOV-501.md)の水車訴訟史・まろん通信No.19の石臼奉納〔[BLOG-273](BLOG-273.md)〕）に対して**物理構造と物理的消滅時期の層を新規に供給**する。

## 制限・未解決

- ①**1670年頃開拓・1732年掘削・1871年新堀用水掘削**の時系列は筆者の時系列整理で、出典の明示なし＝**掘削年代は伝聞由来の「候補」に留める**（1871年新堀用水は[GOV-510](../gov/GOV-510.md)系の明治3〜5年〔1870〜72〕通船・統合文言と整合する）。②**樋口橋語源説は推定文言**で、樋の構造（樋管・開渠の別）・撤去年代は本文になし。③**関野用水の千川上水交点（樋口橋）の流末が「落ちていた」か「渡っていた」か**：資料では千川上水に落ちる・筆者は渡って延伸と読む＝**対立候補として並置**し、千川上水側史料（千川上水の樋・放口関係の千川小川家文書群〔README既収録〕）との対照を次回課題とする。④1657年開削説・立川市一番町取水・総延長4km・砂川七〜八番流末はいずれも伝聞で、元史料（砂川村関係の村誌・水利帳）は未特定。⑤御門訴事件記念碑の碑文・建立年の直接確認は未実施。⑥同ブログの小金井分水11本・梶野新田用水6本・境村分水5本・田柄用水・白子川など他シリーズの掃引は次回以降。
