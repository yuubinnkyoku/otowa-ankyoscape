# [BLOG-021] 音羽花水橋の1875年史料転記と1829年の大日坂下の橋

- **資料〔確認：公開記事〕**：「丹 沢・足 柄 古 道 探 索 団」「[矢櫃峠周辺の道 (18)](https://tannasi1212.blog.jp/archives/34760700.html)」（**2026年6月29日公開、7月25日追記・訂正**）。記事の後半に、音羽・小日向の旧神田上水と橋梁について古文書の転記と古地図の比較がある。**原公文書・地誌の原画像は未照合**。ただし1875年件名については、[GOV-037](../gov/GOV-037.md)で**国立公文書館の原件目録とJACAR公的内容テキスト**を独立に確認した。
- **明治8年の橋名〔二次転記〕**：筆者は国立公文書館所蔵『**太政類典**』**第二編・第175巻「運漕一・治水道路一」**所収とする**1875年（明治8年）5月9日「両上水修繕費金貸与」**から、神田上水の工事対象区間を「**音羽花水橋ヨリ造兵司邸地ニ至ル**」とする一節を紹介する。**JACARの公的内容テキストでも同じ橋名・区間表現を確認できた**。同テキストには家屋の接近・不潔な場所の土手築立案、二万円・五年賦の貸付記述もある。〔**確認：公的テキスト／未確認：原画像の字形・工事実施**〕 原公文書画像の該当丁は未照合。出典：[GOV-037](../gov/GOV-037.md)。
- **文政12年の橋〔二次転記／同定は筆者の推定〕**：『**御府内備考**』**巻之46「小日向之二」水道町条**から、**水道町から大日坂へ渡る橋**を「**長凡四間程、幅凡五尺程**」とする記載を引用する。筆者は**旧水道町と小日向の間、現在の巻石通り・大日坂下交差点付近**の旧神田上水横断橋と解釈し、後の「音羽花水橋」と同一橋だった可能性を示す。**1829年の記載に「音羽花水橋」という橋名があったことは確認されていない**。橋長約7.3m・幅約1.5mは**橋の寸法**であり、水窪川・弦巻川の川幅ではない。
- **同名異橋の注意〔観察・未解決〕**：記事は現在の神田川の「華水橋」との名称継承も推測するが、**旧神田上水の「音羽花水橋」、現在の神田川の「華水橋」、音羽谷の水窪川・弦巻川の横断橋は、原図で確認するまで別の施設として扱う**。記事にある**現華水橋の1926年架橋説**は、既収録の文京区『令和8年度 土木現況』（2026年4月1日現在）にある**1933年の当初架橋完成年**と一致しないため、同じ工事を指すかも未解決。**1875年を旧神田上水の暗渠化年・橋の架設年とはしない**。
- **今後の照合〔未解決〕**：『太政類典』第175巻の原画像・付属資料、『御府内備考』巻之46の原文、1852～1853年の小日向・音羽絵図と1881年測量の迅速測図を比較して、**橋名・位置・廃止時期**を検証する。神田上水は三河川とは別の人工水路であり、**水窪川・弦巻川の合流証拠には使わない**。
