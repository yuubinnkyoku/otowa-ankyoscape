# [BLOG-156] 寅さん歩 その25 谷端川の流れを歩くー5（最終回）（平野武宏）

- **直接確認（2026-11-13、Wayback id_付きURLでPDF本文全文取得）**：[Wayback保存版 2024-06-10](https://web.archive.org/web/20240610053138/http://www.shonan-fujisawa.jp/watanabe/wpage5146.pdf)。寅さん歩その25シリーズの最終回（不忍通り〜神田川合流点）。第43回で「その26（最終回）の所在」を未解決としていたが、**シリーズはその25の全5回構成（wpage5142〜5146）で完結しており「その26」は存在しない**ことが本頁の取得で確定〔第43回・BLOG-152の未解決事項を解消〕。
- **猫貍橋（ねこまたばし）〔確認：説明板の記載〕**：不忍通りと交差する所にあった橋。**猫又・猫股・根子股・根木股と様々に書く**〔異表記の列挙文言〕。渡った左側に親柱の袖石と説明板がある〔BLOG-070/BLOG-133の親柱・袖石観察と整合〕。説明板には「この辺りに狸がいて、夜な夜な赤手拭いをかぶって踊るという話があった。ある夕暮れ時に、大塚辺りの道心者（少年僧）がこの橋の近くに来ると、草の茂みの中を白い獣が追ってくるので、すわ狸かとあわてて逃げて**千川にはまった。それからこの橋は猫貍橋（猫又橋）と呼ばれるようになった**。猫貍とは妖怪の一種である」〔狸伝承の説明板文言全文はrepo初出〕。
- **千川通りの呼称変遷〔確認：筆者の叙述〕**：不忍通りを横切った流れは右折し千川通りに入る。**道名の由来は千川（谷端川）**。「千川通り」は**豊島区上池袋からは「宮仲通り」、大塚駅南口交差点からは「プラタナス通り」、文京区に入り「千川通り」と呼ばれる**〔区間別呼称の文言はrepo初出候補〕。**練馬区の暗渠化された千川上水の上を通る「千川通り」とは繋がっていない**〔都道439号（練馬）と都道436号（文京）の同名異道路の指摘。BLOG-065千川通り呼称差と整合〕。
- **氷川町下町会史地図〔確認：筆者の叙述〕**：千川通り沿いで**昔の氷川町下町会史地図には川の流れの脇に共同印刷の建物が書かれていた**〔「氷川町下町会史地図」の存在と言及はrepo初出。BLOG-079の共同印刷前ベンチ銘板（礫川・1934暗渠）の文脈資料。町会史地図の所在・年代は未特定〕。
- **流路（文京区間）〔観察〕**：窪町東公園の交差点を直進（右=湯立坂から茗荷谷駅方面、左=小石川植物園・簸川神社方面）、播磨坂桜並木・源覚寺（こんにゃく閻魔）沿い、春日通り（富坂下交差点）を横切り直進、文京シビックセンター脇・**東京ドーム脇を左折し東京ドームシティの東京ドームと遊園地の下を流れ**、外堀通りを横切る〔東京ドーム下を流れる下流部流路の具体化。敷地は旧水戸殿屋敷→旧陸軍砲兵工廠〕。
- **神田川合流点・仙台橋〔確認：資料の引用〕**：**水道橋と小石川橋の間に仙台橋があり、仙台橋（仙台藩が架けた橋）の下から合流**とされる。現在仙台橋はなく**市兵衛河岸防災船着き場**となっている〔「仙台藩が架けた橋」の由緒文言はrepo初出候補。BLOG-133・BLOG-070の市兵衛河岸最下流記述と整合〕。
- **橋数〔確認：友の会資料の引用〕**：当日歩いた文京区間（不忍通り〜神田川）には**15の橋**がかけられていたが、ほとんど橋跡のモニュメントは残されていない〔BLOG-152の明治通り〜不忍通り14橋とあわせ区間別橋数〕。**谷端川の記録に残る橋は椎名町駅から神田川まで合計67橋**〔友の会1999冊子（BOOK-062）の67橋と同一の独立言及。全网罗の確認資料として重要〕。
