# [BLOG-068] 地図豆 9-1 目白の坂と泉探し

- **書誌**: 山岡光治「地図豆」の地図を広げて街歩き 9-1「目白の坂を上り下りしながら泉を探す」（距離約10.0km）PDF。https://www.ripro.co.jp/yamaoka/mapsuv200/meguri/9-1chizusanpo2.pdf 。2026-11-11本文取得確認（発行年はPDFから特定できず〔未確認〕）。
- **〔確認〕** **湧水の3分類**（東京都環境局「東京の名水57」から引用）: ①崖線タイプ（浸食崖の砂礫層から湧く。かん養域は狭い）②谷頭タイプ（谷頭の凹地形の含水層露出から湧く。かん養域は広い）③凹地滲みだしタイプ（川床・凹地に伏流水が圧で滲む）〔repoの湧水類型化・谷頭湧水仮説の整理にそのまま使える分類〕。
- **〔確認: 読図〕** **明治42年測図1万分の1地形図「目白」**: 目白崖線（学習院キャンパス南西角〜音羽通り）の崖下に池が複数あり、崖線タイプの湧水の存在を予想させる。低地には水田。平成5年修正1万分の1「新宿」図・デジタル標高地形図・1948年・1963年空中写真の変遷読図も付く〔弦巻川谷（雑司ヶ谷）と目白崖線の関係資料〕。
- **〔確認〕** ルート上の湧水の観察: **おとめ山公園の東西の谷で湧水が確認できる**、甘泉園（湧水）、椿山荘「古香井」、芭蕉庵（湧水）、新江戸川公園（湧水?）、血洗いの池（学習院、湧水?）〔目白崖線沿い湧水点の一次観察リスト〕。
- **〔確認〕** **南蔵院の北を東西に流れていた灌漑用の用水路**（付近の溜池や神田川本流から取水）が**道路として形を残している**（明治42年図で確認）〔神田川左岸（目白側）の灌漑用水の残存例〕。
- **〔確認〕** その他: 面影橋（明治20年東京実測図から「面影橋」、それ以前は姿見橋）、宿坂の関所（鎌倉街道）、砂利場の地名（氷川神社の石標・明治10年の日付）。
- **〔照合課題〕** おとめ山公園東西の谷の湧水の現況（PDFは2000年代と思われる執筆）、谷頭湧水仮説（谷端川・弦巻川上流）と崖線タイプ湧水（目白崖線）の区別への適用。
