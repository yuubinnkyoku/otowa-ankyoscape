# [BLOG-141] wanjin「谷端川支流」2018年・池袋御嶽神社筋の支流観察

- **書誌〔確認〕**: 「水の行方を追って」（わんじん）「谷端川支流　　－子育て祈願とカニバリズムの儀礼に関する接点－」、2018年5月30日投稿。https://wanjin.blog.fc2.com/blog-entry-247.html 。FC2現行はAccess Deniedのため **Wayback（2026-10-25スナップショット）で全文取得**（2026-11-12確認）。[BLOG-140](BLOG-140.md)（中丸川・entry-248）の前後に投稿された谷端川支流連載の1本で、同連載の未索引分。
- **〔観察・確認〕 池袋二〜三丁目境の約500mの支流を下流方向に踏査**: ①池袋2丁目・3丁目の境目付近に「いかにもな水路敷」が谷端川本流へ続く（源泉部は二丁目側へ食い込む推定・マンション群で確認不能）②北北東に約200m進むと**右岸に池袋御嶽神社**（池袋駅西口の鎮守）③御嶽神社付近は周辺の土地が高くなっており、**後年の土盛りで修正されたものと推定**（池袋図書館・池袋第二公園側への坂をなだらかにしたものと筆者は読む）④戸建て住宅の隙間の水路敷を進み、**御嶽橋の南東部分で谷端川本流と合流**〔観察〕。
- **〔仮説を強める根拠〕** 池袋村絵図（[BLOG-139](BLOG-139.md)）に「御嶽神社と境内西の橋」が描かれること、明治初期古地図で池袋付近の水路描写が同支流に対応する可能性（[BLOG-139](BLOG-139.md)・境井田支流の読図）と、本観察の**御嶽橋の南東で本流に合流する谷頭側支流**が位置として整合する。御嶽橋の橋名は[BLOG-081](BLOG-081.md)等で既出だが、**御嶽神社右岸を通る約500mの支流水路敷の実観察記録はrepo初出候補**。
- **〔観察〕 御嶽神社の境内社に子育稲荷神社（保食神）**があり、橋名「御嶽」＝神社由来の系譜（[BLOG-138](BLOG-138.md)の羽黒橋=羽黒神社由来と同型の神社→橋名の対応例）。
- **注意**: 支流の江戸期の存在・流路の同定は筆者の観察・読図に基づく。古地図上の水路描写（境井田支流とするか本支流とするか）との対応は未決着で、断定しない。
