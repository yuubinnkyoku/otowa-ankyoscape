- 大洗堰取壊し年次について、第368回の「昭和8〜10年頃」に「昭和8年」の明示年次を与えるメディア側記録。**典拠が本文にないため傍証扱いとし断定しない**（都水道局・文京区の行政文書での原拠確認が第368回課題のまま）。
