# [BLOG-045] 東京江戸ぶら「音羽川（水窪川）の消失はいつ？①」

- **直接確認（2026-11-11、open_url・本文全文）**：文京区音羽の音羽川（水窪川の下流部呼称）について、年代別の地図で**暗渠化の時期を絞り込む**ことを主題にした2017年の散歩・考証記事（同ブログのシリーズ全3回のうち①。②③はURL特定できず未確認）。
- **地図による暗渠化時期の絞り込み〔観察＋筆者の推論〕**：明治12年・**明治16年・明治43年・大正13年の各図に音羽川の記載を確認**し、**「東京近郊地圖 昭和7年」では音羽町の下に流れが残るが、「東京全圖 昭和9年」では川らしきものが消えている**ことから、筆者は**昭和7〜8年（1932〜33年）に暗渠化されたのではないか**と推論する。※**repo既知の水窪川暗渠化は「昭和初期から戦後にかけて下水化」（豊島区資料）で全区間を1933年と一括しない**立場（2026-08-31ノート）に対し、**音羽谷区間を昭和7〜9年の間に絞る独立の読図推論**として評価する価値がある。ただし各地図の版・縮尺・出版元は記事本文では特定されておらず、**本推論をもって暗渠化年を確定しない**。
- **今宮神社の石橋〔観察：筆者の推定込み〕**：境内参道の道路に埋まった石橋を**明治6年の遷座時に架けられたものと推定**し、「明治6年時点でも音羽川は存在していた」とする。※既知の今宮橋（[水窪川.md](../../水窪川.md) の橋名一覧）と同一の石橋と思われるが、**「明治6年架橋」は筆者の推定で史料裏付けは記事中にない**。
- **音羽九丁目の岡場所〔伝聞の二次叙述〕**：江戸期から昭和40年代頃まで音羽1〜9丁目があり、**音羽九丁目辺りは幕府非公認の私娼窟（岡場所）で、川沿いに私娼が客を取った**とする（「〜とされる」「〜らしい」の伝聞表現）。※原典不明。**地域史の伝承としてのみ記録し、事実とは採らない**。水窪川下流域の土地利用史（遊興地）の補助線に留める。
- **紙漉き〔伝聞の二次叙述〕**：江戸時代は水質が良く紙漉きが盛んで**川沿いに業者70件ほど**、汚濁が進み大正末期にはほぼ存在しなくなった、とする。※既知の「70〜80軒」説（[BLOG-024](BLOG-024.md)・[BOOK-050](../books/BOOK-050.md) 等の出典未提示統計）と同系の伝聞で、独立統計とは扱わない。**「大正末期にほぼ消滅」という時期情報は既存書誌で未確認の追加候補**（要原典照合）。
- **制限〔未解決〕**：②③の本文、参照した各時代地図の原典、岡場所・紙漉きの出典は未確認。
