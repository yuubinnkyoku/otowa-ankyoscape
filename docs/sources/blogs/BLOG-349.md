# [BLOG-349] 水徒然「煉瓦が導く小石川砲兵工廠の谷戸」

## 内容メモ

- **〔観察・repo初出〕小石川トンネル射撃場（旧東京砲兵工廠射撃場・礫川公園内）**: 煉瓦造りのトンネル入り口アーチのみが現存（アーチ上部の穴・塗り込められた入口）。**文京区ライフル射撃協会員の個人サイト**（http://…詳細サイト）に依拠し、明治16〜18年ごろ完成推定・陸軍小銃・機関銃の試射場・戦中〜戦後はライフル射撃場・1999年国・区へ返還・戦時中はシイタケ栽培も〔二次転記・サイトの所在は要特定〕。**トンネルは中央大学方面へ続く**〔二次情報〕。
- **〔確認・repo初出〕射撃場北端付近の「窪地」の存在**: 帝都地形図（昭和5年補正・昭和22年補修）の当該地点に**謎の窪地が食い込んでいる**ことを判読。明治迅速地図では**この谷と西隣の谷がはっきり描かれている**〔判読〕。中央大学〜戦没者墓苑〜礫川公園にかけて谷戸が眠るとの推定〔推定〕。「射撃場設置にあたり窪地を利用＋西端を造成」「盛土をくり抜いたような構造」の諸説を紹介〔二次〕。**一部は中央大学校舎新築工事の際に埋められた**との言及（うさおさんのブログの新聞記事写真経由）〔伝聞〕。
- **〔観察〕牛天神・常泉院周辺の煉瓦と水**: 牛天神敷地の駐車場（コンクリート塗り込み下に煉瓦が見える）・**牛天神石段脇から南へ降りる側溝（水面が少し動き揺らいでいた）**・牛天神の台地を支える煉瓦塀・擁壁〔観察〕。壁際に水路があったかの推測は「はっきりとした痕跡は見当たらず」〔陰性〕。
- **〔言及〕後楽園〜ラクーア付近の水路**: goo地図の明治期古地図で**現在のラクーア敷地内に水路が走っている**（古地図内の池の右側付近）〔判読〕。昭和22年航空写真の後楽園駅周辺の不思議な円型配置（高射砲陣地？）〔推定〕。
- **〔言及〕龍門寺門前町**: 江戸〜明治期の古地図の「龍門寺」（廃仏毀釈で廃寺・牛天神の別当寺）・安藤坂にほぼ平行する通りが龍門寺門前町を形成（江幡潤『文京の散歩道』経由）〔二次〕。永井荷風『伝通院』の砲兵工廠赤い裏門の一節〔二次引用〕。
- 筆者自身は「カテゴリーも取り敢えず『谷端川』としたが『神田川支流』になるのかな？？」と比定を保留〔比定保留〕。

## 四河川への使い方

- **谷端川（小石川）下流域の後楽園台地（中央大学〜礫川公園）に明治迅速地図レベルで2本の谷があったこと**、そのうちの1つが射撃場の窪地として利用・改変された経緯の整理資料。谷端川本流の北側台地の谷構造の新データ〔比定は筆者も保留・神田川支流の可能性を併記〕。
- 牛天神石段脇の側溝の流水（2015年）は、当該谷の水分の現況観察の候補〔断定できない〕。
