# [BLOG-252] 時空散歩「善福寺川筋の窪地・水路跡散歩 Ⅰ・Ⅱ・Ⅳ」4本（2016）〔repo初出・[BLOG-250](BLOG-250.md)（Ⅲ①②）で未収録だったシリーズ残り4本分の流路・橋名・用水の観察〕

- **書誌〔確認: 本文全文・2026-11-21取得〕**: ブログ「時空散歩」（yoyochichi）のシリーズ「杉並 善福寺川筋の窪地・水路跡散歩」のうち、未収録だった4本: **Ⅰ（2016年3月19日: 堀之内の旧流路（揚堀）と松ノ木支流・成田東支流を辿る）**・**Ⅱ（3月20日: 成田東・成田西を流れた旧流路（揚堀）跡を辿る）**・**Ⅳ①（5月9日: 成田西の善福寺川南を進む旧流路・揚堀を辿り、上荻の暗渠跡、そして西荻北の窪地・水路跡を歩く①）**・**Ⅳ②（5月10日: 同②）**。Ⅲ①②（2016年4月15/16日）は[第244回](../2026-11-21（第244回）・ADEAC杉並桃園川掃引群・大谷家文書天保用水路図2点・時空散歩善福寺川散歩Ⅲ・tokyoriver高野ヶ谷戸・すぎなみ学暗渠散歩の新規収録.md)で[BLOG-250](BLOG-250.md)として収録済み。Ⅳ②末尾で「善福寺川筋の窪地と水路跡、そして旧流路散歩もこれで一応お終い」とシリーズ完結。
- **堀之内の旧流路・揚堀（Ⅰ）〔確認〕**: 済美山運動公園（旧富士銀行グランド）台地下の済美小学校北に鉄柵で塞がれた水路跡があり、『杉並の川と橋』（[BOOK-229](../books/BOOK-229.md)）の「**日本済美学校・敷地概念図**」に河川改修前の善福寺川の複数流れ（3つの流れ）が描かれることから、済美小学校の北の水路跡＝**旧流路を活用した揚堀跡**（推定）と辿る〔**済美小学校の校庭に水路は潜る**＝校地内伏せの現地観察。揚堀の下流排水口は環七を越えた先ではなく和田堀橋の西と推定〕。**『杉並の川と橋』による「定塚窪」**: 定塚橋南の一帯は**「定塚窪」と呼ばれ、環七ができるまでは環七の西にある和田南田圃とつながった水田**が広がっていた〔定塚窪＝和田南田圃の連続水田地帯という公刊書記録の孫引き〕。水路跡の途中には**方南橋**（1944-54今昔マップ。現在は残っていない）があったと推定。梯子でドアに入る民家・ガーデン堀ノ内住宅敷地境の鉄柵・堀ノ内子供園・**本村橋＝「堀之内本村」由来**の観察。**和田堀の地名史（本文整理）**: 明治の町村制施行に際し妙法寺の堀之内村に和田村の難色から「和田堀之内村」→**大正15年（1926）町制で「和田堀町」**。
- **松ノ木支流・成田東支流（Ⅰ）〔確認・repo初出候補の流路群〕**: **松ノ木支流**: 源流点（成田東3-1）→成田東1-46/41の境→五日市街道をクロス→世尊院別院の東→成田東1-14（水路跡の案内図）→**松ノ木遺跡**→善福寺川旧流路に合流〔流路の実走＋遺跡名の併記〕。**成田東支流**: 善福寺川旧流路との合流点（和田堀公園北）→松ノ木中学の一筋北の車道→**金太郎の車止め（成田1-9）**→水路跡が途切れる→遊歩道状の水路跡→源流点〔**松ノ木・成田東の2支流名と流路は『杉並の川と橋』由来の整理ではなく書き手の仮称・実走観察**（[GOV-490](../gov/GOV-490.md)の空中写真図版の高野ヶ谷戸支流の仮称とは別系統の整理）〕。
- **成田東・成田西の揚堀（Ⅱ）〔確認〕**: 旧流路・揚堀の流路実走: 民間信仰石塔→東田中学校に沿う細路→杉並税務署前→須賀神社前→**杉並高校の敷地に沿って水路は進む**→金太郎の車止め→崖下の水路跡→**矢倉台先端部で揚堀と天保新堀用水が合わさる**→揚堀と天保新堀用水の分岐点→天保新堀用水のルートに乗り換え→**天保新堀用水・善福寺川の取水口**〔[BLOG-249](BLOG-249.md)の「あげ堀の下を潜っていた」潜渠関係・[BLOG-250](BLOG-250.md)の1947年航空写真の揚堀合流と接続する実走観察〕。**成田下橋の旧称**: 「**成田下橋は明治の頃、吉六橋と呼ばれる丸太一本の橋からはじまった、とのこと。吉六は尾崎橋まで迂回するのが面倒と丸太を渡した人の名**」〔**吉六橋の橋名由来文言 = repo初出候補**（孫引き・出典は本文上で『杉並の川と橋』系の記述とみられるが明示なし）〕。成園橋（由来不詳・成田と和田堀公園の合成か）・成田上橋・白山神社沿い等も記録。
- **成田西の善福寺川南の旧流路・揚堀（Ⅳ①②）〔確認〕**: 和田堀公園→成園橋→尾崎橋→宝昌寺→天王橋→**屋倉橋**→善福寺川緑地公園→成田西いこい緑地→**成田西切通し公園**→神通橋で善福寺川と合わさる〔**善福寺川の南（矢倉台側）の崖線下を辿る揚堀系旧流路の実走**。「今昔マップ首都 1896-1909」の「旧本流」の南を流れる水路＝成田東・成田西を流れた揚堀とほぼ同じルートと比定〕。
- **『杉並の川と橋』の作場橋文言（Ⅳ②再掲部分）〔確認・repo初出文言〕**: 「**昭和39年に都市計画公園として事業化された両地域（善福寺川緑地・和田堀公園）には、作場橋（農工作用の橋）の他、古道に架けられていた橋を除いて、一般通路用として橋は架けられていなかった**」〔**「作場橋」＝農工作用橋の呼称と都市計画公園化（S39）以前の橋の不在の文言候補**（孫引き。原文照合待ち）。[BLOG-250](BLOG-250.md)のS43橋梁名称図と併せ、善福寺川緑地の橋の発生史の前段〕。
- **善福寺川上流の橋名群（Ⅳ②）〔確認・repo初出候補群〕**: 春日橋から上流に**忍川下橋→忍川橋→忍川上橋**→「**与謝野晶子 鉄幹 ゆかりの地散策路」の碑**→荻窪橋→荻窪上橋→界橋→荻野橋→**東吾橋**→本村橋→置田橋→神明橋〔**忍川3橋・荻野橋・東吾橋・荻窪上橋・神明橋等は[GOV-486](../gov/GOV-486.md)の図ラベル（河道図・流量配分図）・[GOV-489](../gov/GOV-489.md)のライブカメラ一覧とも補完関係にあり、実走記録側の橋名リストとしてrepo初出候補**〕。上荻の暗渠①②③（出山橋・**鍛冶橋**・**中田橋**＝右岸に排水口と細路・**城山橋**）・西荻北の窪地の谷頭までの実走も記録〔**出山橋・鍛冶橋・中田橋・城山橋はrepo初出候補の橋名**〕。
- **第一期/第二期天保新堀用水の判別仮説（Ⅳ②）〔確認・本文の推定文言〕**: 旧荻窪住宅（現在の**シャレール荻窪**）から真東に向かい旧本流に合わさる水路＝**「第二期の天保新堀用水」**、本流から分かれて天保新堀用水路と荻窪に向かう旧流路・揚堀分岐点へ真南に下る水路＝**「第一期の天保新堀用水を揚堀として活用した水路跡」ではないだろうか**〔[GOV-492](../gov/GOV-492.md)の三ヶ村碑系史料（天保11年権現山堰→広場堰変更・天保12年再普請）と、[BLOG-250](BLOG-250.md)の1947年写真の揚堀使用観察を橋渡しする水路判別の推定。断定はしない〕。**「川﨑銀蔵」の五百分の一勾配の胎内掘り文言を再掲**（[BLOG-250](BLOG-250.md)・[GOV-146](../gov/GOV-146.md)・[GOV-492](../gov/GOV-492.md)の「川嶋銀蔵」との表記揺れは両論併記のまま）。
- **意義〔観察〕**: ①揚堀系の流路（堀之内・松ノ木・成田東・成田西）の実走と『杉並の川と橋』の孫引き文言群（定塚窪・日本済美学校概念図・作場橋・吉六橋）が一次観察レベルで接続した、②[BOOK-229](../books/BOOK-229.md)の書誌確定により、これらの孫引き文言の一次確認（同書の学了図と概念図）が将来可能になった、③忍川3橋・出山橋等の橋名リストは[GOV-489](../gov/GOV-489.md)のライブカメラ23局の橋名と合わせて善福寺川の現代橋名の対照資料になる。

## 制限・未解決

- ①『杉並の川と橋』由来の文言（定塚窪・日本済美学校敷地概念図・作場橋・吉六橋）は本文の孫引きで頁数・表記の正確さは原文照合待ち（[BOOK-229](../books/BOOK-229.md)まだ本文未見）。②松ノ木支流・成田東支流等の支流名は書き手の便宜呼称。③第一期/第二期天保新堀用水の判別は「ではないだろうか」の推定文言で、航空写真対比まで実施されていない。④橋名群の読み（特に「忍川」の表記）は現地案内由来と思われるが、写真扁額の目視確認までは本文記述ベース。
