# [BLOG-201] 川俣晶の縁側：芝浦工大高校敷地＝丸池跡地の一次証言

- **直接確認（2026-11-13、open_url・本文全文・Wayback未収蔵）**：歴史系個人サイト「川俣晶の縁側→歴史と文化→下高井戸周辺史雑記」の2008年10月28日記事。東京鉄道教習所→芝浦工業大学高等学校（[ORG-011](../org/ORG-011.md)・[BLOG-029](BLOG-029.md)と同一施設）の卒業生（在学2年間）による**丸池跡地の生活史の一次証言**。
- **高校敷地＝丸池跡地〔確認：筆者の在学体験の記述〕**：「高校時代の2年間通った高校の敷地が、何と神田川支流の弦巻川の水源地だった」「ジメジメした土地だと思っていたら、そこはまさに水源地となる「丸池」の跡地だった」。**校庭がジメジメしてスカッとしない土地・木造2階建ての古い校舎**〔丸池跡地の湿潤性を在学生の体感として記録した一次証言。[GOV-055](../gov/GOV-055.md)の丸池枯渇史と整合。時期は筆者の高校時代＝昭和40年代〜50年代と推定されるが本文に在学期間の年次は明記なし〕。
- **池袋駅前の土地利用〔確認：一次描写〕**：駅地下道の入り口から30秒、正面は道路を挟んですぐ東武線路、**裏口から出ると養老の滝があり、すぐ裏手にソープランドもあった**〔1970〜80年代の池袋駅前（旧弦巻川下流域の谷筋）の土地利用の一次描写。のちに芝浦工大中学高等学校として板橋（都営三田線志村三丁目駅最寄り）へ移転〕。
- **板橋新校舎の地下の川〔伝聞〕**：板橋の新校舎は**敷地の地下に川があり、そのため2階の渡り廊下には屋根を付けることができなかった**という話を聞いた記憶とする〔**対象の川は記事で特定されず**（志村三丁目駅周辺であれば中丸川・出端川・千川上水系が候補になるが断定できないため候補列挙にとどめる）〕。
- **高田町史の引用〔二次転記〕**：「鉄道教習所の構内となり、石囲いの水溜となつて居るが、大正時代の初期までは付近の子供達が水泳して居た」（『高田町史』昭和8年）〔BLOG-073で既出の文言と同一。引用元として『神田川「まる歩き」しちゃいます!!』（＝kawawalk、[BLOG-146](BLOG-146.md)等で既収録）の丸池①〜③を明示〕。
- **制限〔未解決〕**：在学期間・卒業年の特定なし。「環境最高or最悪」は私感評価。板橋新校舎の地下川の伝聞の裏付けなし。
