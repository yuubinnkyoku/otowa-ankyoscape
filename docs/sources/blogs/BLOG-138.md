# [BLOG-138] 谷端川南緑道の橋名列挙とアトリエ村の土地利用記録

- **直接確認（2026-11-12、open_url・本文全文）**：境橋付近の制作スタジオ「11-1 Studio」による谷端川南緑道のガイドページ（掲載年は明記なし。西池マートの2019年4月復活に触れることから**2019年以降の記述**）。作成主体が地元（緑道沿い）である点に意味がある。**正確な公開年は未確認**。
- **南緑道の橋名列挙〔確認：ページ記載〕**：「南緑道では計18箇所の橋があり」として**熊野橋・他領橋・境井田橋・南橋・御嶽橋・中上橋・上ノ橋・境橋・高松橋・東橋・北荒井橋・日ノ出橋・長崎橋・丸山橋・霜田橋・羽黒橋・八幡橋・並木橋・宮下橋**（19名）を列挙。「18箇所」との数字と列挙数が一致しない点はそのまま記録する（欠番・重複の可能性）。[BLOG-069](BLOG-069.md)（2022年・27橋観察）・[BLOG-114](BLOG-114.md)（2026年）と**独立の橋名列挙**であり、名寄せの照合資料になる。
- **野菜洗い場の記憶〔伝聞：ページ記載〕**：**要町交差点北側の親水公園は「かつては野菜洗い場があったそうだ」**。谷端川沿いの生活水利（洗い場）の位置的記憶として、[BLOG-125](BLOG-125.md)の上池袋の「滝」洗い場等と並ぶ記録。証言者・年代は不明。
- **羽黒橋の由来〔ページ記載〕**：**近くの羽黒神社に由来**すると明記。橋名由来の独立ソースとして[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)の該当欄から照合可能。
- **池袋モンパルナスのアトリエ村地名〔確認：ページ記載〕**：①源流部・粟島神社〜椎名町間（緑道化されていない区間）に**「つつじが丘アトリエ村」**（記念碑が現存し芸術家が現住と記す）②椎名町サンロード西側＝**「さくらが丘パルテノン」**（最大規模）③**中上橋**裏手の**「ひかりが丘アトリエ村」「みどりが丘アトリエ村」**（**池袋モンパルナスでは唯一板橋区側に属し、記念碑も痕跡もない**と記す）。アトリエ村の小地名を地点単位で特定する数少ない記録であり、[BLOG-106](BLOG-106.md)の辻広場整備や池袋耕地整理（[BLOG-122](BLOG-122.md)）との位置照合が次の課題。
- **川沿いの生活施設〔確認〕**：羽黒橋たもとの銭湯「湯～ゆランドあずま」（**旧屋号「東湯」から60年近く**）、霜田橋たもと「西池マート」→**2019年4月にクラフトビール醸造所・アート拠点「NishiikeMart」として再生**、境橋の「佐藤プラスチック」など。
