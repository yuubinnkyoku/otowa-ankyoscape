# [BLOG-185] 弦巻川　－人間の手が加わっていない天然物の希少価値－

- **直接確認（2026-11-13、第54回。FC2直は403のためWayback 2026-10-25スナップショット（web.archive.org/web/20261025110950/）で本文全文取得）**: wanjin弦巻川カテゴリ（全3回）の中編（投稿2014-01-28）。池袋駅東口〜雑司が谷〜不忍通り手前までの弦巻川上中流を歩いた記事。同カテゴリのentry-23「懐旧の念やみがたき郷愁の故郷」（2014-01-21）・entry-25「多数決の原理は少数派の犠牲的貢献によって成立？」はWayback未収蔵で未取得（今回ノートに記録）。
- **四面塔尊の由緒と移転史〔repo初出〕**: 西武百貨店とパルコの間にあった**四面塔尊**について、①**享保6年（1721年）夏、一晩で17名の辻斬りの残骸があった**ことを憂いた**池袋村民有志64人**が法明寺第22世上人に供養を依頼し**同年9月に法華経の題目を刻んだ石塔を建立**、②正面に題目・**右側面「北方板橋道」・左側面「南方高田雑司ケ谷道」の道標**としても使われた、③明治の区画整理で強制移動し作業員が相次いで事故死したため祭を行ったが大戦で中断、④**昭和30年（1955年）の丸物デパート建設で再移転**・建設中の事故頻発で祟りが噂された、⑤平成12年9月吉日「池袋四面塔尊奉賛会」の案内文言——という一連の由緒・年次を記す〔**1721年建立・村民64人・道標文言・丸物デパート移転（1955年）＝repo初出**。第45回追記のBLOG-114「池袋四面塔稲荷大明神（江戸期鎮座）」との名称対応・同一物かどうかは記事が言及しないため断定しない〕。
- **丸池と池袋地名〔議論の記録〕**: 元池袋史跡公園一帯の**丸池が「池袋の地名ゆかりの池」と碑に刻まれていることに対し「非常に眉唾もの」と評価**、池袋本町の複数の池＋袋状の窪地説・「ブクブク湧き」説を支持〔[BLOG-050](BLOG-050.md)池袋本町＝地名由来候補・[BLOG-073/074](BLOG-073.md)丸池と同名異地問題と整合する独立二次記録〕。**池袋本町を「北池袋」に改名しようとした役所工作に住民が猛反対し「池袋本町」とさせた経緯**・「東池袋も水久保の地名を残せばよかった」との私見も記録〔北池袋非存在の由来説明はrepo初出候補〕。
- **雑司が谷いろはかるたの弦巻川句〔repo初出候補〕**: ビックリガード脇道の落書き防止カルタ絵札（上川口屋で販売）に**「そ：卒塔婆も鎌倉も木村も弦巻川の橋の名」**の句〔[BLOG-034](BLOG-034.md)の雑司が谷いろはかるた言及に対応する具体句の初出文言。卒塔婆（＝四面塔尊）・鎌倉橋・木村橋が弦巻川の橋名であることを歌った句〕。ビックリガードの語源（山手線通過時の轟音・ガード下の立ち往生）も記録。
- **弦巻川中流の流路と施設〔観察・2014年〕**: 丸池を源流とする流路がビックリガード→JR・西武線潜り→明治通り→**大鳥神社参道**→法明寺前（**かつて仁王門があり、そのそばを弦巻川が流れていた**）→東京音楽大学横・**古道鎌倉街道の鎌倉橋**→**都電ガード（貴重な鉄橋だったが閉鎖済み。谷底低地で弦巻川がどこで都電線路をくぐっていたかは不明瞭**）→御嶽坂・清立院（雑司が谷七福神毘沙門天）→**清立院そばの「当所石橋施主木村氏」碑＝木村橋**〔木村橋は[BLOG-049](BLOG-049.md)等で既出だが**施主木村氏の碑文言は初出候補**〕→弦巻通り（雑司が谷弦巻通り商友会・川跡の銭湯）〔鎌倉橋は[GOV-028](../gov/GOV-028.md)の旧鎌倉橋・[BLOG-138](BLOG-138.md)の南坂橋系の読図と照合要〕。
- **区境段丘と「金山」地名〔観察・地名メモ〕**: 弦巻通りを抜けた先で**左岸が段丘状になり、左岸段丘上＝豊島区・右岸＝文京区で弦巻川は区境**だった一画は**「金山」と呼ばれていた**〔「金山」の音地名は[GAZ-022](../gazetteers/GAZ-022.md)で既出。弦巻川区境（BLOG-176等で既出）との位置関係の文脈追加。鉄関連出土の可能性は筆者の推測〕。
- **お鶴ヶ淵と北大路魯山人の句〔repo初出〕**: 菊池寛旧宅跡より先の下り坂は**「お鶴ヶ淵（あるいはお鶴ヶ瀧）」と呼ばれる落差の激しい流れ**で、北大路魯山人が当地**潭弦亭（旗本長田右兵衛督の抱え屋敷で文化人が集った）**で**「流れ出る水上清き土なれやつるまき川の瀧の白糸」**と詠んだ〔**お鶴ヶ淵・潭弦亭・魯山人句＝いずれもrepo初出**。落差の激しい地形は現存せず、「いかにも暗渠道」の細い路地に流れを確認できるとの観察〕。その路地の**釜伏せの井戸は現在も水が湧き出している**〔2014年時点の現役湧水観察。[BLOG-163](BLOG-163.md)（2021年此花亭・なか山の井戸ポンプ）・[BLOG-052](BLOG-052.md)（2010年星の井戸等）と合わせ弦巻川沿い湧水の時系列データポイント〕。
- **自然流路の終点と人工流路化〔観察〕**: 路地を抜けた流れは首都高速5号線と都道音羽池袋線にぶつかる所までが**自然河川としての弦巻川**で、**この先は人工的に護国寺参道の西側に流れを設けた**〔1932年流路付け替え（[BLOG-001](BLOG-001.md)）の位置叙述。「松屋橋がこの近辺にあった模様だがどこだかわかりにくい」とも〔松屋橋の位置限定は今回の記事からは不能〕〕。高速道路下でも流路跡は「シブトク残っている」〔[BLOG-137](BLOG-137.md)の高速下クネクネ暗渠歩道観察と整合〕。
