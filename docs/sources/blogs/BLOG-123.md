# [BLOG-123] CBC「道との遭遇」水窪川暗渠道（髙山英男案内・2025）

- **直接確認（2026-11-12、記事版全文）**: ミキの昴生・亜生MCの道バラエティ。暗渠道マニアの髙山英男氏が池袋の水窪川暗渠道を案内（2025年4月15日放送）。
- **護国寺付近の私邸敷地内の流路の2025年実地観察〔repo初出の観察記録〕**: 髙山氏が以前から気になっていたという「護国寺近くの大きな屋敷」。家主が長期不在のため親族の許可を得て、ご近所の方の家から敷地内の池を観察した結果、**水窪川（の旧流路）は庭の池に流入せず、手前に流れて敷地の塀に沿い、この先のカルバートで川が続いて抜けている**ことを確認した、と記す。〔確認：番組の観察記録。docs/2026-10-20・東青柳町の水窪川と私邸の池.md の最大の未決事項「池が川の本流を取り込んだのか、河道脇の池か」に対する**「河道は池と繋がらず塀沿いに残る」という2025年の実地観察傍証**。番組は「護国寺近く」としか位置を特定しないため、東青柳町私邸との同一性は高精度の推定として断定しない〕
