# [BLOG-114] BE-PAL「東京GREEN WAY FILE.36 谷端川プラスGREEN WAY」

- **書誌〔確認〕**：アウトドア媒体BE-PALの連載「プロハイカー斉藤正史の東京GREEN WAY」FILE.36（2026年4月27日公開）。前回（FILE.35）に続き谷端川緑道を歩く後編。本文を直接取得〔repo初出。橋跡の2026年時点の観察記録として[BLOG-069](BLOG-069.md)（2022年観察）の追跡観察にあたる〕。
- **橋跡の現況〔確認：記事中の2026年観察〕**：要町駅すぐの**長崎橋（跡）**から北上し、谷端川親水公園、**日ノ出橋跡・北荒井橋跡・東橋跡・境橋跡・上ノ橋跡・中上橋跡・御嶽橋跡・境井田橋跡・他領橋跡・熊野橋跡**と続いて川越街道に達する。さらに**前田上の橋跡・前田橋跡・北浦上橋跡・北浦橋跡・中丸橋跡・金井窪橋跡・西前橋跡・豊橋跡**を過ぎ、東武東上線下板橋駅前の自転車置き場付近まで〔①橋名の綴りは[BOOK-062](../books/BOOK-062.md)・[BLOG-069](BLOG-069.md)・[BLOG-081](BLOG-081.md)と同一のものが多く、2026年時点でも銘板等の名残が確認できることの傍証。②「境井田橋」の表記はBLOG-081と同一〕。
- **緑道の管理区分〔確認〕**：緑道は「谷端川南緑道」（豊島区管理）と「谷端川北緑道」（板橋区管理）に分かれ、川越街道で物理的に分断され、迂回が必要〔[GOV-008](../gov/GOV-008.md)・[GOV-009](../gov/GOV-009.md)の整備記録と整合する現況観察〕。
- **周辺の地名・施設〔観察の記録〕**：川越街道の交差点そばの「熊野町交差点レトロ空間」（所有者は「池袋の不動産王」といわれた加藤正衛）、**熊野町熊野神社（応永年間1394-1428創建といわれる由緒）**〔熊野町熊野神社の創建年代表記はrepo初出の観察報告。由来はブログ記述のため伝承として記録〕。下板橋駅先に「池袋本町電車の見える公園」、上池袋図書館（2026年5月末まで休館工事中）・上池袋さくら公園・宮沢賢治「農民芸術概論綱要」碑のフクロウ石像。
- **〔2026-11-13 第45回追記・確認〕 池袋駅前公園の2神社**：記事末尾の池袋駅前公園周辺の記述で「**池袋水天宮**」と「**池袋四面塔稲荷大明神**」という2つの神社があり、池袋水天宮は**昭和初期から**、池袋四面塔稲荷大明神は**江戸時代から**当地に鎮座していると記す〔**「池袋水天宮」の名称・昭和初期鎮座・四面塔稲荷の江戸期鎮座＝repo初出**。池袋駅前公園は弦巻川の水源とされる丸池周辺に近いが、記事は川との関係には言及していないため、水神（水天宮）祭祀と弦巻川・旧池の関係は仮説としても記録しない〕。
- **注意〔制限〕**：橋跡の同定は記事の観察に基づく。橋名の比定（橋跡標示の実在）は現地確認資料（BOOK-062）と一致するが、個々の銘板の現況は本記事の写真で確認できない。
