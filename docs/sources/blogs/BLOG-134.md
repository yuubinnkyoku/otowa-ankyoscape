# [BLOG-134] 細川正博「ゲリラ豪雨対策」

## 書誌〔確認〕

- 豊島区議会議員・細川正博の政策ページ「ゲリラ豪雨対策」。2013年から2026年7月15日追記まで年次つきで更新が続く一次記録（区政活動・都下水道局資料の転載を含む）。 https://www.hosokawamasahiro.jp/seisaku/environment/environment01.php
- 同内容の区政連絡会報告（2024-09-12第12地区区政連絡会）: [ameblo 2024-09-13](https://ameblo.jp/hosokawamasahiro/entry-12867329723.html)

## 内容〔確認: ページ本文〕

- **2013.8.21豪雨の被害詳細**: 南大塚一丁目の被害報告**131件（床上浸水46件、床下浸水37件、その他48件）**で大塚三業通り等に集中〔[GOV-082](../gov/GOV-082.md)の浸水被害記録の具体値〕。
- **要望から認定まで**: 2013.10.1高野区長へ要望、10.11都下水道局長宛に大塚三業通り5町会長連名の要望書。2013.12.17都「豪雨対策下水道緊急プラン」で**文京区千石・豊島区南大塚が75ミリ対策地区に認定**（4地区の一つ）。
- **2015.11「千川幹線流域の浸水対策整備案」**: 時間75ミリ対応は「新宿や池袋など繁華街のみで、市街地での対応は初」（2015.3.8追記）。**総事業費700億円、南大塚分だけでも30億円**。既設千川幹線・第二千川幹線の能力を増強する貯留管=千川増強幹線。
- **増強幹線本体**: 平成29年着工〜令和4年完了。上池袋東公園（上池袋1-30）発進→北大塚・南大塚経由→文京区窪町東公園（大塚3-32）まで内径3750mm〔[GOV-082](../gov/GOV-082.md)と整合〕。
- **人孔設置工事（貯水管への接続部3か所）**: ①宮仲公園（上池袋1-36）②北大塚二丁目付近③窪町東公園。2023.7.29宮仲公園工事現場火災で工期延長。**①③は2024.8.21に完了し下水道能力増強の効果が一部発揮**（2024-09-12区政連絡会で都下水道局が完了報告）。②は入札不調で契約遅延。
- **大塚駅北口マンホール工の位置変更〔確認〕**: 当初北大塚1-16（巣鴨警察署入口交差点付近）→**埋設物の輻輳で施工困難と判断され北大塚2-23付近（都道内）に変更**。
- **北大塚接続=「豊島区北大塚二丁目付近枝線工事」（2025.6.23追記）**: 千川第二幹線と増強幹線の接続は終了済みだが**千川幹線と増強幹線の接続が未完**。**北大塚予定箇所の試掘で千川幹線の位置が想定と違っていた**ことが判明しスケジュールに狂い。工事箇所: 北大塚二丁目・都道宮仲公園通り（路上）＋上池袋東公園（公園）。工期令和7年6月〜9年2月（公園一部使用は7年10月〜8年7月）。接続工事中は増強幹線を一旦塞ぐ（雨期明けの秋以降に施工）。
- **2026.7.15追記**: 路上工事は令和9年5月まで、公園工事は令和9年3月までとさらに延長。

## repo上の意味づけ

- 千川幹線（旧千川=谷端川下流部の下水道幹線〔[GOV-082](../gov/GOV-082.md)〕）の**現位置が都の想定図と食い違っていた**という試掘時の記録は、暗渠化当時（1930年代・昭和40年代等）の流路付替え・構造改変を検討する上で独立の傍証になりうる〔推定〕。
- 北大塚1-16（巣鴨警察署入口交差点）は千川筋の高桝跡（滝野川6-9）周辺と、北大塚2-23は谷端川・千川境界域（丸山町付近〔[BLOG-119](BLOG-119.md)〕）のそれぞれ近傍にあたる〔位置関係は要照合、断定しない〕。
