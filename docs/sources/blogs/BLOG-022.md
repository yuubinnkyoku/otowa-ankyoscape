# [BLOG-022] 2007年2月24日の水窪川・弦巻川跡踏査と地域の聞き取り

- **資料〔確認〕**：まさぼう「[池袋東側の路地裏](https://masaboupiano.seesaa.net/article/2007-02-25.html)」（**2007年2月25日23:39公開**）。記事は「昨日の土曜日」の踏査とするため、**現地歩行は2007年2月24日**と読める。水窪川を東池袋側から下流へたどり、不忍通り付近から弦巻川を上流へ歩いた記録。記事には現地写真が複数添えられるが、各画像の撮影地点・方向・時刻は未特定。
- **水窪川〔確認：筆者による2007年の現地観察と匿名住民の伝聞〕**：東池袋で話しかけてきた地元の男性が、付近を「水窪」と呼んだこと、昔は「紙梳場」が多かったことを語ったと記す。筆者は、水窪川跡に**井戸が多数、木造家屋、曲がる細道、旧川を伝える碑**を見たと記録する。男性の氏名・居住歴・紙漉きの時代と場所・各井戸の番地は示されない。
- **弦巻川〔確認：筆者による2007年の現地観察〕**：弦巻川跡でも井戸が多かったと記し、弦巻通りの**「雑二ストアー」**を通り抜け、当時は八百屋のみ営業していたと述べる。店舗の住所、営業開始年、建物と旧河道・下水管との位置関係は記されない。
- **資料の限界〔確認範囲〕**：記事の現地描写は**2007年時点の見聞**であり、匿名男性の回想は過去の紙漉き場の存在を直接証明する原史料ではない。井戸の多さは筆者の定性的印象であり、井戸の水源・深度・河川との接続や、紙漉き場の操業年代は不明。写真と当時の住宅地図・旧河道図の照合は未実施。
