# [BLOG-200] 続・池袋地名の由来「丸池」（鉄道教習所時代）

- **直接確認（2026-11-13、open_url・本文全文）**：[BLOG-073](BLOG-073.md)（丸池第1回）・[BLOG-074](BLOG-074.md)（高田雲雀）と同一作者（toshima_lab）のシリーズ第2回。前回noteの「高田町史（昭和8年）200頁」の丸池の惨状文言を、**昭和12年（1937）火保図（火災保険特殊地図）**と**国土地理院「年代別の写真1936年〜1942年頃」の空中写真**で検証する内容。
- **火保図による鉄道教習所の位置確認〔観察：火保図読図〕**：鉄道教習所は昭和7年（1932）当時、**池袋二丁目（旧・西巣鴨町大字池袋字向原）と雑司ヶ谷七丁目の境界に跨って存在**したと読む〔**火保図の利用自体がrepo初出の図種**。[BLOG-029](BLOG-029.md)（教習所＝西池袋1-11-1）・[GOV-055](../gov/GOV-055.md)（丸池＝成蹊池→教習所→枯渇）の位置関係と整合。火保図の原本確認は未実施〕。
- **空中写真による丸池の判読〔観察：空撮読図〕**：**食堂と浴室の真横に「丸池」があった**と判読（寄宿舎各棟と食堂は渡り廊下で接続）〔**丸池の教習所敷地内での相対位置（食堂・浴室に隣接）が視覚的に特定された初の読図**。撮影年代が1936〜42年の幅を持つ点は筆者も「昭和11年頃」と幅付きで記す〕。
- **高田町史文言の再引用〔二次転記〕**：「今は其の池の水は、鉄道教習所埴土の残飯残肴の棄場となつて、濁水漲ぎり、弦巻川は、裏長屋の炊事洗濯の汚水と塵芥とで、悪臭鼻を撲ち、昔は月の名所、蛍の名所であつたが、今は蚊の名所、蠅の名所となり…」〔BLOG-073で既出の文言と同一のため新規文言とはしない。**丸池・弦巻川の1933年時点の水質悪化の継続確認**〕。
- **浴室排水の推論〔推定：筆者の推測〕**：丸池ではなく**弦巻川に直接（浴室の排水も）流していたのではないか**とする（本文で「〜かも知れませんが」と明示）〔根拠は空撮の位置関係のみ。推測として記録〕。
- **制限〔未解決〕**：火保図の筆者・刊行者（東京火災保険協会系か）・所蔵先は記事で特定されていない。空撮のコマ番号も未特定。いずれも原本確認が次回課題。
