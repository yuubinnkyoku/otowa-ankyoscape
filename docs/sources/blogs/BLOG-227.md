# [BLOG-227] 関口大砲製造所の水利（wheatbaku「幕末の大砲製造所②」）〔repo初出〕

- **直接確認（2026-11-15、open_url・本文全文）**: 気ままに江戸（夢見る獏）の「[関口大砲製造所（幕末の大砲製造所②）](https://wheatbaku.exblog.jp/32651712/)」（**2022年7月6日**）。同じ筆者の同シリーズ⑤⑦（王子分水）は[BLOG-127](BLOG-127.md)として既収録。
- **湯島大小砲鋳立場の移転候補地〔確認：海舟全集第6巻「陸軍歴史上」所収上申書の二次引用〕**: 「鋼製大砲鋳立方之義に付御内意奉伺候書付」によれば、移転先の候補は**小日向水道町（＝関口水道町）**で、**町人所持の水車場2か所の北側への建設なら水掛かり十分**と評価。一方、**牛込船河原橋際（大曲あたりから水盛りするが地勢平坦で勾配が少なく）関口水道町より劣る**と判断されたという〔**牛込船河原橋際が具体的な対抗候補として検討され、地形勾配を理由に不採用だったという記述はrepo初出**。水窪川流域の小日向と神田川沿いの関口を結ぶ水車立地の比較史料〕。
- **関口大砲製造所の水利〔確認：大松騏一著『関口大砲製造所』所収文書の二次引用〕**: **文久2年（1862）10月付**の江戸南町奉行・小栗豊後守あて文書によると、**神田上水の大洗堰から神田上水の北側に堀を開削し、神田上水を懸樋（かけひ）で渡して水利を確保**したという〔**大洗堰を起点とする北側の堀の開削と、神田上水を懸樋で越える立体交差の構造はrepo初出**。既収録の大洗堰（[GOV-144](../gov/GOV-144.md)・文京ふるさと歴史館・水道歴史館の各記録）に、幕末期の製造所用水の取水構造という具体を加える。元治元年・慶応期の滝野川反射炉系（千川用水）と並び、文久期の神田上水系の軍事用水の実例〕。
- **位置の比定〔確認：本文の現地説明〕**: 関口水道町は**現在の江戸川橋の南一帯**で、関口大砲製造所は**江戸川橋交差点北西側の「プラザ江戸川橋」付近**に設置されていたとする〔江戸川橋の南たもとに関口水道町の説明板あり。**江戸川橋上流約400メートルに大洗堰があった**という位置記述は、既収録の大洗堰諸記録と整合〕。文久元年12月には砲身に螺旋を切る工作機械のオランダ発注の上申（竹内下野守らの連名）があったという〔洋式工作機械の導入経緯。水系の直接記述ではないため参考〕。
- **制限〔未解決〕**: ①大松騏一『関口大砲製造所』の初出情報（刊年・掲載文書の一次所在）は未確認で、文久2年10月文書の一次確認が必要。**→ 第92回（2026-11-15）書誌特定済み: [BOOK-103](../books/BOOK-103.md)（東京文献センター・2005年2月・ISBN4-925187-46-5・145p）。文書の一次所在の確認は同書本文閲覧まで残る**。②「北側に堀を開削」した堀の流路・規模・存続期間（廃止時期）は本文に記載がなく、現地・地籍図での検証課題。③牛込船河原橋際候補の「水盛り」評価の一次史料は未確認。④関口大砲製造所と明治3年「関口製造所」（[GOV-144](../gov/GOV-144.md)・太政官「関口製造所並ニ滝ノ川反射炉ヲ造兵司ノ管轄トス」）の同一性・継続性は、本記事では直接扱われておらず断定しない。
