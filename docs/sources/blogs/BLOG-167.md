# [BLOG-167] Natrium「エンガ掘と周辺の水路敷群（江古田の支流）」

- **書誌〔確認：open_url・本文全文〕**：Natrium.jpの水路敷シリーズ。エンガ堀（千川上水の谷迂回区間の通称）周辺の支流を扱う頁で、本シリーズでは[AGE年表関連のGOV-072](../gov/GOV-072.md)（エンガ堀＝東長崎3号踏切北起点）・[BLOG-102](BLOG-102.md)（エンガ堀=千川上水シリーズ）に続く位置づけだが、**江古田駅方面へ向かう支流の詳細観察はrepo初出**。本文記載の限り2017年6月10日・19日撮影。
- **支流2本の並行流路〔観察〕**：OpenStreetMapの読図として、**向原ゴルフセンターの西側で本流と分かれて西へ向かう支流**と、**板橋向原郵政宿舎の北側で分かれて西へ向かう支流**の2本が並行して小竹向原駅〜江古田駅へ向かう、とする流路復元〔推定を含む読図〕。南側支流は板橋向原郵政宿舎で本流と分かれた後すぐ工場敷地に飲み込まれ途中が追跡不能、崖下で再び水路敷として出現する〔観察〕。
- **北側支流の谷頭〔観察・repo初出〕**：北側支流の上流端は**江古田斎場へ向かう坂道を登りきったクリーニング店のある交差点あたりが谷頭だったよう**、と観察。江古田斎場裏手からの流れと江古田駅方向からの流れが広場状の場所で分岐する地点も記録〔観察〕。
- **水路敷の微観察〔観察〕**：練馬区の水色の水路敷ペイント〔[GOV-072](../gov/GOV-072.md)の水路敷ペイント文脈〕・この辺りの車止めに特有の緑と黄色のゼブラ模様・インターロッキング舗装の僅かな残存・崖と家の間を抜ける南側水路敷の高低差・江古田駅北公園を回り込む水路敷（自転車駐輪場として利用）など、エンガ堀支流の現況記録。
- **江古田駅前浅間神社〔参考〕**：流路の終端は浅間神社敷地で行き止まり。境内奥には**国指定重要有形民俗文化財「江古田富士」**がある〔repoでは江古田富士の言及は未収録〕。
- **制限〔未解決〕**：江古田斎場方面からの流れが水源だったのかは本文も「よく分からない」とする〔未解決〕。2支流の江戸期〜昭和の水系としての実体（千川上水からの分水か独立谷頭湧水か）は本頁の範囲外。

## 制限・未解決

- 江古田富士（富士塚）と江古田の谷頭湧水・水源信仰の関係は未調査。
