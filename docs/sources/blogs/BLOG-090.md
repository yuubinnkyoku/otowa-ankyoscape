# [BLOG-090] 千川上水橋梁（上井草）と開渠区間・流量配分の観察

- **書誌**: 本田創（tokyoriver）、**2011年5月23日**公開。[原記事](https://tokyoriver.exblog.jp/16370558/)。2026-11-11全文取得確認。著者は [LOST-003](../lost-web/LOST-003.md)（東京の水2005）・[BLOG-052](BLOG-052.md)（弦巻川断章）と同じ。**千川上水橋梁の記事自体はrepo初出**。
- **〔観察〕** 西武新宿線**上井草駅西側の線路上に「千川上水橋梁」の鉄橋（全長10m未満）があり、1926年竣工と記す**〔確認：筆者記述。竣工銘板の実物・時期の行政原典は未確認〕**。**前後の暗渠区間の間でここだけ約35mが開渠のまま残る**。青梅街道（関町一丁目）交差点から約1.2km下流でヒューム管から水が顔を出し、鉄橋直下で再び地中に潜る。
- **〔観察〕** 水路は**西武新宿線建設時に鉄橋長を短くするため付替えられた**と記す**〔確認：筆者の聞き取り・記述。付替え時期・図面は未確認〕**。
- **〔確認（2011年時点の筆者記述）〕** 清流復活（1989年）により千川上水には**1日1万トンの高度処理水**が流され、**うち7000トンは青梅街道交差点のすぐ先で善福寺川へ導水され、残り約3000トンがこの開渠区間に残る**。以後は約13kmの暗渠を流れ、**JR埼京線板橋駅東側で谷端川放水路の暗渠（谷端川幹線）に接続し、石神井川に放水される**と記す**〔行政資料との照合前の個人記述〕**。
- **〔確認〕** 筆者は谷端川放水路の暗渠を**「1924年に谷端川の氾濫対策としてつくられた水路」**と記す。既知の1924/1925年次問題（[BOOK-031](../books/BOOK-031.md)原典候補・[谷端川.md](../../谷端川.md)）に対し、**Wikipedia系統と独立の二次傍証が1件増えた**〔仮説：1924年説への追加傍証。原典確認前なので年次確定扱いにしない〕。
- **〔参考〕** コメント欄に地元まちづくり協議会で千川上水復活を活動する「鰍工房（松浦）」（2011-11-24）の書き込みがあり、井草周辺で復活運動が2011年時点で存在した記録になる。
- **〔未解決〕** 鉄橋竣工1926年の根拠（銘板か資料か）、付替え前の旧流路位置、流量配分（7000トン/3000トン）の出典、1989年通水時からの配分の不変性。
