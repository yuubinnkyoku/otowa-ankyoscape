# [BLOG-044] 雨男「住宅地の中の自噴井戸～弦巻川」

- **直接確認（2026-11-11、open_url・本文全文）**：2021〜2022年の訪問に基づく弦巻川下流→源流の暗渠踏査記録（2025年8月投稿）。水窪川と護国寺丘陵を挟んで対をなす流路として弦巻川を扱う。参考資料は『東京23区凸凹地図』（昭文社）。
- **自噴井戸・湧水の現地観察〔観察：2021〜2022年時点〕**：神田川合流点から護国寺裏手（豊島岡墓地・権現山）方面の暗渠沿いで、**行き止まりの暗渠道に水音が聞こえ、井戸の上に大きな鉄鍋を伏せた蓋があり、パイプから水がこんこんと噴き出していた**。さらにその先で**崖からの湧水と思われる水で付近の道路が水浸し**だった。筆者は23区の暗渠道で**噴出する湧水を見たのは初めて**とする。※位置の地番・座標は記事本文からは特定できず未確認。既知の水窪川沿いの湧水群（[水窪川湧水の変化検討・リサーチセッション.md](../../水窪川湧水の変化検討・リサーチセッション.md)）に対する**弦巻川側の湧水継続の観察記録**として、湧水分布の対照に使える可能性がある。**本観察で弦巻川の湧水の存続を全域で主張しない**。
- **目白架道橋〔二次叙述〕**：都電荒川線の**かつての都電唯一の跨道橋「目白架道橋」があったが、現在は塞がれている**と述べる。川との関連性は筆者も「わからない」と明記。※橋と弦巻川の関係は未確定。橋の撤去・閉鎖の時期も未確認。
- **雑司が谷いろはかるた〔観察〕**：西武池袋線・山手線をアンダーパスする道路付近の壁面に「雑司が谷いろはかるた」が描かれ、**弦巻川が描かれていた**。※かるたの制作年・制作者・弦巻川の描かれ方は未確認。弦巻川が地域のイメージとして選ばれた例として記録する。
- **源流の別説〔二次叙述〕**：丸池を源流とする説明を紹介したうえで、**『大江戸今昔巡り』（書誌詳細未確認）では西池袋公園が谷頭になる**とする。※既知の丸池源流説・滝口説（[PAP-001](../papers/PAP-001.md)）に対する**源流位置の別説（二手法）の存在記録**。原典の記述・出版情報は未照合で、本説をもって丸池源流説を覆さない。
- **上り屋敷駅ホーム跡〔二次叙述〕**：西武池袋線**上り屋敷駅（1953年廃止）のホーム跡**がわずかに残る。※弦巻川流路と同駅の位置関係の言及はないが、源流付近の戦後土地利用の変遷の文脈として記録する。
- **制限〔未解決〕**：自噴井戸・湧水の正確な位置、『大江戸今昔巡り』の書誌、かるたの成立史、目白架道橋の閉鎖時期はいずれも未確認。
