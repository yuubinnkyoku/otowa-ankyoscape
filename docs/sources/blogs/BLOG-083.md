# [BLOG-083] Natrium.jp 谷端川（椎名駅〜南長崎花咲公園）

- **直接確認（2026-11-11、open_url・本文全文）**：2017年の訪問では水路の位置が不明だった区間を、**MapExpert地籍マップ（β版）の公開で水路敷の位置が明確になった**として2025年2月23日に再訪した記録。
- **椎名町駅〜東長崎駅間の線路北側水路敷〔確認：地籍マップ＋観察〕**：地籍マップでは椎名町1号踏切から**東長崎駅手前まで線路北側に細い水路敷が描かれ**、現地では鉄道敷内の細い側溝・鉄板蓋の側溝として追跡できる。**東長崎駅構内では西側の側線脇から始まっており、水路敷というより東長崎駅の保線区から出る排水路のように見える**と観察する。〔観察＋推定：保線区排水路起源説／駅の建設・保線区の設置年は未確認〕
- **椎名町駅南側の窪み〔観察〕**：線路南側にも**不自然な窪みが線路に沿って続く**が、地籍マップに描かれず同定不能とする。〔未解決〕
- **椎名町駅から南長崎花咲公園への水路敷〔確認：地籍マップ＋観察〕**：2017年に見逃していた**道路脇の路肩・マンホールのはみ出す細い水路敷**が、地籍マップの水路敷に対応して**目白二又通り〜南長崎花咲公園**までつながると特定した。〔観察／流路の実態・流向は地籍図と現地判読の照合による推定〕
- **repoへの関連**：本ページの水路敷は[BLOG-064](BLOG-064.md)（高山2014南長崎支流再検証・Weekend Outdoors証言の昭和40年前後まで開渠＋ヒューム管埋設）と同じ椎名町〜南長崎の谷筋を、**地籍マップ・2025年の現況観察**という別の方法で裏付ける。保線区排水路起源説は新規の解釈候補で、鉄道排水路説・農業用水説・谷頭湧水説の検討材料になる。〔仮説段階〕
