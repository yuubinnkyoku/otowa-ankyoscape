# [BLOG-183] 水窪川　－たゆとう時間の淀みと開発の波－

- **直接確認（2026-11-13、第53回。FC2直はAccess DeniedのためWayback 2026-10-25 id_付きURLで本文全文取得）**: wanjin「水の行方を追って」の水窪川連載（カテゴリ5本）のうち、第50〜52回で未収録だった2013年9月の2本を取得した1本目。投稿2013-09-28、2014-01-13一部修正。
- **「中西の森」→「根津山」の変遷〔伝聞・2013年記録〕〔repo初出文言〕**: 蟹ヶ窪一帯の雑木林は、古くは旗本三千石中西氏数代の拡領地として「**中西の森**」と呼ばれ、明治末頃に実業家・**根津嘉一郎**（東武鉄道・富国徴兵保険経営）が買収して「**根津山**」の呼名がついた、と記す〔根津嘉一郎・根津山の部分はBLOG-099等で既出だが「中西の森」の前呼名はrepo初出。旗本中西氏の系譜は原本確認要〕。
- **蟹ヶ窪埋立て伝承の2013年時点記録〔伝聞〕**: 豊島岡女子学園の現在地（昭和23年移転）にあった丘（一説に古墳説）を切り崩して蟹ヶ窪の湿地を埋め立てた、というBLOG-099（坂まち通信第1号経由）と同系統の叙述を、独立の二次資料として記録〔根津山切崩しの内容は既出。本記事は2013年時点の証言 circulation の記録〕。
- **巣鴨監獄誘致の年次細部〔repo初出候補〕**: **明治18年に巣鴨村が地域発展のため監獄誘致運動を開始、明治21年に政府が土地を買い上げ、明治28年に石川島から警視庁監獄巣鴨支庁が移転**、大正11年巣鴨刑務所、昭和12年東京拘置所、昭和46年小菅移転、という沿革の年次を整理〔移転以降の沿革は既出の通説どおり。誘致運動開始明治18年・買収明治21年の年次は本ブログで初めて収録。原典（板橋区史・豊島区史等）の確認が今後の課題〕。
- **造幣局東京支局の沿革**: 昭和14年に南側を大蔵省に譲り、昭和18年に麹町の造幣局東京出張所を併せて造幣局東京支局となった〔標準的な沿革の整理。監獄→造幣局と水窪川崖下の土地利用の連続性の文脈〕。
- **『池袋の夜』の美久仁小路〔repo初出の文化的引用〕**: 昭和の歌謡曲『池袋の夜』（作詞・吉川静夫）に「**美久仁小路の灯りのように 待つわ待つわ**」と歌われたことを引用〔美久仁小路=蟹ヶ窪水源を歌謡史料から裏付ける地域史記録として収録〕。
- **水久保=高田村と巣鴨村の村境にまたがる土地**という整理〔BLOG-099・LOST-005と整合する2013年時点の二次記録〕。造幣局一角の監獄時代の排水口跡の2013年観察〔BLOG-025/107・BLOG-099系の変遷時点データとして記録〕。
