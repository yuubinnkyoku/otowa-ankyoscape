## 内容メモ

- **〔観察〕水窪川源流部（東池袋4丁目〜日の出町）の2013年実況**: 造幣局南西角の向かい（東池袋4丁目）の「土台細めの井戸」から緩く下る未経験区間の観察。廃屋同然の家・外壁からいきなりの蛇口・石造りの蔵・「木製の枠」の住居・耕作地（茗荷の栽培に言及）など、日の出町の川跡景観の記録〔観察〕。
- **〔確認・repo grep新出〕日光広場の設置年次の文言**: 日の出の防災広場「日光広場」の看板熟読で「**観光地：日光に見立てて作られたスペースで、かつ地下に貯水槽を備える。1990年の設置**」〔看板文言の観察〕。[BLOG-106](BLOG-106.md)（辻広場整備昭和61〜平成10年・日光広場=東池袋4-15-5）・[BLOG-109](BLOG-109.md)/[BLOG-110](BLOG-110.md)（説明版・男体山フェンス・華厳の滝ポンプ）に**看板レベルの設置年次1990年を追加**。
- **〔観察〕補助81号線の道路計用地と一帯のフェンス・小公園**: 「**補助81号線という、都電荒川線の線路に沿って北東に向かい、古河庭園の方まで延伸する道路計画が一帯にある…計画決定されたのは戦後直後の昭和21年**」〔読図・二次知識〕。水窪川周辺の小公園が「過渡期の措置」かもしれないという推測〔仮説〕。〔[BLOG-066](BLOG-066.md)・[BLOG-184](BLOG-184.md)の補助81号線記録と整合〕。
- **〔観察〕巣鴨プリズンからの排水口跡の探索**: 本田創の暗渠本（『地形を楽しむ東京「暗渠」散歩』）に見た「巣鴨プリズンからの排水口跡」を探し歩き「見つけた！！」〔2013年時点での目撃観察・[BLOG-099](BLOG-099.md)蟹ヶ窪埋立ての米兵フットボール場造成・[BLOG-107](BLOG-107.md)イケ・サンパーク保存石と対照する2013年の現況定点〕。
- **〔言及〕日の出優良商店街**: 「ここが川跡だと思っていました」という商店街の川跡認識の訂正経緯・「昭和二十年東京地図」の「日出町一丁目〜東池袋五丁目。共盛会商店街」写真〔二次書誌：昭和二十年東京地図〕。旧町名日の出町とサンシャイン命名の推測〔仮説〕。
- **〔言及〕水窪川の支流**: 「水窪川の支流と言えば護国寺からの流れ、のみなのかな」〔疑問形・支流構造の整理課題〕。

## 四河川への使い方

- **水窪川最上流部（東池袋〜日の出町）の2013年の詳細な実況観察**として、[BLOG-110](BLOG-110.md)（2022年）・[BLOG-344](BLOG-344.md)周辺の観察群に9年遡る定点データ。日光広場の設置年1990年は辻広場整備史（BLOG-106公式年次）との突合材料。
