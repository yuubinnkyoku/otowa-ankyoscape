## 内容メモ

- **〔確認: 記事本文＋写真・repo初出〕寄進者の村名・石工名**: 台座に寄進者の村・名前・金額が刻まれ、**石神井村、武蔵野村吉祥寺、関村、竹下村、西久保村、土支田村、保谷村**などの地名が読め、**石工「寅吉」**の名がある〔筆者による台座写真の読み。逐字の正確性は写真の拡大確認が必要〕。寄進者の苗字には今もこの近在に子孫が住む人が多いとも記す。
- **〔確認: 記事本文・repo初出〕所在の住所表記のずれ**: 供養塔の住所はGoogle mapでは**武蔵野市吉祥寺北町3-15-8**、練馬区では**練馬区関町南4-2**と出る〔区と市の境界（上水中央）と住所表記の不一致の記録。行政の登録・登記上の所在は未確認〕。
- **〔確認: 記事本文〕建立の背景**: 「ねりまの文化財・第60号・千川上水特集号」（練馬区教委生涯学習課文化財係・平成16年3月＝repo既収録書誌）に、上水で水難死した人々の霊を供養するため明治41年3月に地元有志が寄進して建立とある〔二次引用。第3回ノート以降所在のみだった同書誌の本文側記述の一部が間接的に確認された〕。「昔は水量も多く、この辺りに堰もあって、落ちて死ぬ人もいた」という地元の伝聞も記す。
- **〔観察・repo初出〕吉祥寺橋〜東北裏橋間の2024年現況**: 開渠で水が流れ、畑の向こうに寄進者の子孫とされる**井口家の屋敷林**が残る。屋敷林と畑の境を千川上水が流れ、屋敷林右端の電柱付近に吉祥寺橋が架かる＝「一番昔の風景をとどめている場所」とする観察。
- **〔聴取〕1960年代の大雨時の溢水**: 筆者の子供時代（1960年代）、まだ千川上水が機能していた頃は大雨で水があふれて**西武新宿線がよく運転中止**になっていた記憶〔個人記憶。BLOG-094の文化4年溢水事故・BLOG-113の水難碑文脈と併せ、上流部の溢水史の近代側の伝聞記録〕。
- 台座の道しるべ文言「右ハ田無小金井道 北ハ関青梅街道々 左ハ吉祥寺停車場 井之頭道」・明治41年3月建立はBLOG-094と同一碑の記述で重複（本記事は「吉祥寺停車場」=鉄道駅名を含む点で読み取りがより具体的）。
