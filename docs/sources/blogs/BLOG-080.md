- **出端川の水源〔確認：『板橋の地名』（板橋区教育委員会）由来の叙述＋筆者の見立て〕**：水源は**板橋区大山町（植栽の奥）**。**『千川上水』の流れからも近い場所にあり、その漏水も源泉に影響していた**ことと思われる〔推定〕。〔千川用水の洩水が水源とも言われる点は[BLOG-060](BLOG-060.md)（暗渠ハンター）と一致し、**千川上水→出端川の漏水接続の説を第二の独立資料が支持**。これまでのAccess Deniedで本文未確認だった wanjin の出端川編を初めて確認〕
- **流路の観察〔観察〕**：東へ流れ東武東上線大山駅方向へ（駅地下の連絡通路部分が流路かという筆者の疑問を残す）→東上線を越え**大山東町交差点で右折→すぐクランク状に左折（暗渠道と丸分かりな小路）→踏切の手前を左折（未舗装の通路部分が流路か）→踏切の警報機のあたりで右折し再び東上線を越える→マンション敷地・都道317号（山手通り）を越えて谷端川に合流**。山手通りは相当な土盛りがあり、実際の流路部分は低い所を流れていたものと思われる〔推定〕。
- **大山の地名由来〔確認：『板橋の地名』由来の叙述〕**：出端川の始まる大山町の「大山」は、**相模国大山の大山阿夫利神社への参詣に用いられた大山道の分岐点（中山道・川越街道より）から発生した地名**。「大山に曲がる処」が「大山」と略された。大山道は八道あり（青山通り・府中通り・八王子通り・柏尾通り・田村通り・羽尾通り・六本松通り・蓑毛通り各大山道）、最盛期の宝暦年間には年間20万人が大山に参詣したという。〔**出端川水源地の地名「大山」の由来説明はrepo初出**。地名・河川名対照表の大山項目の根拠に〕
- **支流呼称の混同問題への関連〔確認〕**：[BLOG-059](BLOG-059.md)（中丸川）で指摘した「wiki谷端川の『出端川』（中丸町〜熊野町〜西前橋）は『いたばしの地名』では中丸川」という混同問題に対し、本記事は**『いたばしの地名』の記述に基づき、大山町から東上線沿いに下る別の川として出端川を辿っており**、両支流が別項として実在する理解（[対照表](../../地名・河川名対照表.md)）を支持する第三の独立歩行記録となる。
