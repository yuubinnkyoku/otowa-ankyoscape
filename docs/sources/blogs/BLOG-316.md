# [BLOG-316] 成島哲子「種子(たね)屋街道」— 三軒家の地名由来説と東京種子同業組合・榎本家資料整理の年次

## 書誌・dedupeの経緯〔確認〕

- 滝野川探検隊サイト（takitan.com）の固定頁「**種子(たね)屋街道**」（**2025.04.18**掲載・署名＝**成島 哲子**）。**雑誌「月虹」2025年6月号（終刊号）投稿稿の、筆者・関係者の厚意による転載**。同一サイトの〔[BLOG-313](BLOG-313.md)（2021-12-31「種屋街道（たねやかいどう）」頁＝榎本氏2004年地図の転載）とは別記事〕。内容＝**令和6年11月30日の第1回種子屋街道シンポジウム「種子屋街道の歴史を今に伝える〜榎本家店舗兼住宅の承継と未来への種まき〜」への参加記**＋街道史の概説。
- 読者の前提知識としては、移り住んで「十七年経った」・「種子屋街道」なる講義を受けた、という書き出し〔筆者の体験文言〕。

## repo初出・リード文言

- **江戸期の滝野川種子屋の元祖三家＝枡屋（榎本）孫八・越部半右衛門・榎本重左衛門の三家とされる。「三軒家」の地名が今も地図上に残る**〔確認: 本文文言（「とされる」表現を含む）〕＝**「三軒家」（北区滝野川6丁目・READMEの[BLOG-313](BLOG-313.md)/[GOV-583](../gov/GOV-583.md)で地名として既出）の由来を種子屋三家に結びつける説のrepo初出**〔観察: 地域随想の由来語りであり、「三軒家は種子屋三家に由来する」ことを一次史料で確認した文言ではない。由来説として今後の対校対象とする〕。農家の副業として自家採取種子を中山道筋で売って評判となり、**参勤交代で国元に帰る武士も買っていった**、近くに**加賀藩の下屋敷**だった土地（畑・山林・渓流）がある、の説明〔確認: 本文。加賀藩下屋敷の滝野川所在はREADME既収録の文脈と整合する立地記述〕。
- **大正五年、滝野川種子屋が中心となり東京種子同業組合を設立**。目的＝種子の仕切相場協定・優良原種の生産と供給で、**練馬大根・滝野川牛蒡・大長人参・夏大根の優良原種を「東京ブランド」として供給**し全国的知名度と信用を高めた。**戦時中の種苗の生産配給統制により昭和十八年に解散**〔確認: 本文〕＝**種苗業者組織の設立（1916）・解散（1943）の年次とブランド化戦略の文言がrepo初出**〔観察: 組合設立・解散の行政一次記録（東京府誌・公報等）は未確認。年次の一次確認は今後の課題〕。
- **榎本家資料の整理系譜**: 「平成三年、榎本家より種子蔵の解体で大量の資料の寄贈が豊島区立郷土資料館になされ、資料館友の会古文書サークル有志五名が三十年かけ令和三年三月に、**約六万四千点**の整理をほぼ終えた。それにより**令和四年十二月一日「一般財団法人 榎本種苗歴史文化財団」の設立**となった」〔確認: 本文〕＝寄贈（1991）→整理（有志5名・30年・64,000点→2021.3）→財団設立（2022.12.1）という**資料群の規模と整理の年次・人員のrepo初出文言**。「この資料から中山道種子屋通りの歴史と奥深い種子屋の世界が明らかになってきた」〔引用文言〕＝[GOV-583](../gov/GOV-583.md)（財団が第3回シンポの主催）の前提となる資料基盤の記述。
- **「種子屋街道（たねやかいどう）」の命名は大正大学の「よみがえれ『種子屋街道』」プロジェクト**〔確認: 「〜命名したのもこのプロジェクトと聞く」という聞きかじり表現の文言〕＝**街道名が現代の大学プロジェクト由来であることを示唆する観察文言**〔仮説級: 聞き書き依存で、命名の初出時点の一次確認（どの文書・看板・リリースが初出か）は未確認〕。
- 大正大学プロジェクトの内容列挙＝グリーンインフラとしての都市農業、すがもプロジェクト、種子屋街道案内板の設置と説明、歴史学科の授業、キャンパス屋上農園〔確認: 本文。[ORG-046](../org/ORG-046.md)の看板設置（2022年3月）と対応〕。「亀の子束子もあるし、映画テルマエロマエに登場する風呂屋、稲荷湯もある」〔確認: 本文〕。
