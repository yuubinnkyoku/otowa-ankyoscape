# [BLOG-062] 谷端川アーチ・カルバート（warpal）

- **直接確認（2026-11-11、open_url・本文全文）**：[docs/谷端川.md](../../谷端川.md)で本文引用済みだったが資料ファイルが未登録だったため、書誌として登録する。なお本頁のアーチ・カルバート・大塚79号架道橋の解釈は谷端川.mdに反映済みであり、ここでは**未整理の記述**を登録する。
- **「谷端川」の地図初出〔観察：筆者の地図コレクション〕**：手持ちの江戸切絵図に谷端川の名は見当たらず、明治前期の2万分の1地形図にも中小河川名は記載されない。**1909年（明治42年）に始まる1万分の1地形図で初めて「谷端川」の名が記載される**。〔個人の地図読み。国土地理院の図歴確認で検証可能〕
- **北谷端・南谷端〔観察〕**：1万分の1地形図に「北谷端」「南谷端」の地名が初記載されるのは**1921年（大正10年・第二回修正測図「王子」）**。ただし**1911年（明治44年）発行の『東京府北豊嶋郡瀧野川村全図』に字名として記載**されており、字名自体は明治44年時点で存在する。
- **地名由来〔仮説：筆者の考察〕**：①谷の端を川が流れる地、②谷の傾斜地に畑が広がる地、の2説を筆者が提示。いずれも谷端地区の地形に関係する。由来の定説はなく仮説として扱う。
- **山手線築堤〔観察〕**：山手線は大塚駅近辺で谷端川の河川敷を渡るため**駅を含め約600mの区間で築堤となり、最も高いところでは8m以上**。暗渠化前の谷端川はアーチ橋（カルバート）で山手線をくぐり、現在の暗渠は**大塚79号架道橋**の下を通る。暗渠化は**昭和8年または9年**と整理〔既存の暗渠化年次整理（東京江戸ぶら推論・豊島区資料）と整合する二次整理〕。
- **repoへの関連**：北谷端・南谷端・『瀧野川村全図』は[地名・河川名対照表](../../地名・河川名対照表.md)・その監査記録と一致。谷端川の地図初出1909年説は地名初出の検討材料として新規。
- **制限〔未解決〕**：1909年説・由来2説は筆者の個人所蔵地図に基づく観察で、図幅名・図歴の特定は未実施。
