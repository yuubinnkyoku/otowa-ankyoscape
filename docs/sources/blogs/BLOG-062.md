# [BLOG-062] 谷端川アーチ・カルバート（warpal）

- **直接確認（2026-11-11、open_url・本文全文）**：[docs/谷端川.md](../../谷端川.md)で本文引用済みだったが資料ファイルが未登録だったため、書誌として登録する。なお本頁のアーチ・カルバート・大塚79号架道橋の解釈は谷端川.mdに反映済みであり、ここでは**未整理の記述**を登録する。
- **「谷端川」の地図初出〔観察：筆者の地図コレクション〕**：手持ちの江戸切絵図に谷端川の名は見当たらず、明治前期の2万分の1地形図にも中小河川名は記載されない。**1909年（明治42年）に始まる1万分の1地形図で初めて「谷端川」の名が記載される**。〔個人の地図読み。国土地理院の図歴確認で検証可能〕
- **北谷端・南谷端〔観察〕**：1万分の1地形図に「北谷端」「南谷端」の地名が初記載されるのは**1921年（大正10年・第二回修正測図「王子」）**。ただし**1911年（明治44年）発行の『東京府北豊嶋郡瀧野川村全図』に字名として記載**されており、字名自体は明治44年時点で存在する。
- **地名由来〔仮説：筆者の考察〕**：①谷の端を川が流れる地、②谷の傾斜地に畑が広がる地、の2説を筆者が提示。いずれも谷端地区の地形に関係する。由来の定説はなく仮説として扱う。
- **山手線築堤〔観察〕**：山手線は大塚駅近辺で谷端川の河川敷を渡るため**駅を含め約600mの区間で築堤となり、最も高いところでは8m以上**。暗渠化前の谷端川はアーチ橋（カルバート）で山手線をくぐり、現在の暗渠は**大塚79号架道橋**の下を通る。暗渠化は**昭和8年または9年**と整理〔既存の暗渠化年次整理（東京江戸ぶら推論・豊島区資料）と整合する二次整理〕。
- **repoへの関連**：北谷端・南谷端・『瀧野川村全図』は[地名・河川名対照表](../../地名・河川名対照表.md)・その監査記録と一致。谷端川の地図初出1909年説は地名初出の検討材料として新規。
- **制限〔未解決〕**：1909年説・由来2説は筆者の個人所蔵地図に基づく観察で、図幅名・図歴の特定は未実施。

## 追記（2026-11-14 第86回）: 同サイト「7. 宮下橋」頁

- **同サイトの別頁「7. 宮下橋」（[miyashita/miya-brg.htm](http://warpal.sakura.ne.jp/yamanote/14ohtsuka/8miyashita/miya-brg.htm)）を取得・直接確認（Shift_JIS本文）した〔確認: 本文全文・2026-11-14〕**。本頁は山手線大塚〜巣鴨間の跨線橋群の1つとして、**現役の宮下橋（豊島区巣鴨一丁目〜巣鴨三丁目・山手線・湘南新宿ラインの4線を跨ぐ）のデータ**を掲載する〔確認: 本文のデータ表〕。
- **三代説〔観察: 筆者（高橋俊一）の整理〕**: **初代＝1903年（明治36年）田端線（山手線の前身）開通時**（木製か？未確認）。**二代目＝1924年（大正13年）複々線化時・古レールを利用した幅1.4m程度の人道橋**。**三代目（現在橋）＝1991年（平成3年）6月竣工・橋長28.70m・幅員11.00m**。「江戸橋に先駆けて1991年に架け替えられた」「現在の橋が三代目だとすると、二代目の寿命は67年間だったことになる」と記す〔確認: 本文文言。初代の構造・二代目の図面は筆者も未確認として断定を避ける〕。
- **名前の由来〔観察: 筆者の考察・文京区の旧町名案内板・文化財案内板の引用〕**: **近くの旧宮下町（もと文京区の地名・現在は千石）による**。宮下町は**氷川明神（現簸川神社・小石川植物園西隣）の下にあった町**で、**1652年（承応元年）に徳川綱吉の白山御殿用地として召し上げられ、その代地として巣鴨村に移った**という。巣鴨の大鳥神社は別の由来とする〔確認: 本文文言。区の案内板の文言の直接照合は未実施〕。同頁には**1947年（昭和22年）8月の国土地理院空中写真での橋の位置表示**（戦後の様子）もある〔確認: 頁内の図〕。
- **位置づけ〔観察〕**: **1991年6月竣工は[GOV-137](../gov/GOV-137.md)（区議会議案説明資料・平成元年度〜平成2年度施工）の工事完了時期と整合し、橋長28.70mは2016年区管理台帳と一致する**〔観察: 数値の一致による相互補強。民間サイトの数値であるため確定は原本・台帳で〕。二代目（1924年・幅1.4m人道橋）の情報は、**1917年（大正6年）谷端川橋梁橋桁変更届出（[GOV-135](../gov/GOV-135.md)・逓信省鉄道局）や第44回の鉄橋位置問題（十町川・谷端川）とも比較可能な、跨線橋側の橋梁史**として参考になる〔推定〕。ただし本頁は個人サイトの記録で、**初代・二代目の橋梁図面・竣工年の公的資料での確認は未実施**。
