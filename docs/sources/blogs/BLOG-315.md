# [BLOG-315] 大竹道茂の第1回種子屋街道シンポジウム参加記 — 保存修理の現場観察と榎本家・育種家の人的系譜

## 書誌〔確認〕

- 江戸東京・伝統野菜研究会代表・大竹道茂の個人ブログ「江戸東京野菜通信」の記事「**種子屋街道に面した大正大学で「種子屋街道の歴史を今に伝える」シンポジウムが開催された。**」（**2024年12月4日 00:00投稿**）。**令和6年11月30日（土）・大正大学での第1回種子屋街道シンポジウム「種子屋街道の歴史を今に伝える〜榎本家店舗兼住宅の承継と未来への種まき〜」**（＝[GOV-583](../gov/GOV-583.md)の「今回で3回目」シンポジウムの既往回）の参加記録。第2部＝文化財保存修理事業の見学会。
- **プログラム**〔確認: 本文〕: 第1部＝①榎本留吉商店とその資料について（豊島区立郷土資料館学芸員・**横山恵美**）②榎本家店舗兼住宅及び新座敷の文化財的価値について（豊島区文化財保護審議会委員・神奈川大学特任教授・**内田清藏**）③よみがえれ「種子屋街道」プロジェクトについて（大正大学教授・**古田尚也**: 1.グリーンインフラとしての都市農業〔13号館テラスの農園〕2.すがもプロジェクトへの参加と種子屋街道〔滝野川ゴボウの栽培〕3.様々な関係者との連携の広がり＋YouTube第一弾〜第三弾）。第2部＝見学会（協同組合伝統技法研究会）。

## repo初出・リード文言

- **五代目当主・榎本泰吉氏は2024年2月に96歳で死去**〔確認: 本文「（榎本泰吉翁は2024年2月に96歳で亡くなられた）」〕＝**種子屋街道の最後の種苗商世代の逝去年月の記録**。見学会冒頭に**娘の加藤佑子氏が挨拶**し「生まれ育った店舗兼屋敷が豊島区の有形文化財に指定され…後世に伝えられることへの喜び」を述べたとする〔確認: 本文。**一般財団法人榎本種苗史文化財団「2022年に設立」**の文言もあるが、財団名は[GOV-583](../gov/GOV-583.md)等の「**榎本種苗歴史文化財団**」と表記差がある〔観察: 転記の揺れの可能性。正式名称の確認は断定しない〕〕。
- **「カネト商報」パンフレットの品種名**〔確認: 会場で郷土資料館が拡大展示したものを見た記録〕: 練馬大根・滝野川牛蒡・滝野川人参・中生山茄子等を掲載。長い品種名として「**東京練馬中長丸尻大根**」（10文字）「**東京大長練馬長尻澤庵大根**」（12文字）＝**榎本留吉商店発行資料の実物ベースの品種名記録**（従来のREADMEの練馬大根・滝野川系伝統野菜の記述に、商家パンフレット側の品種名文言を加える）。
- **榎本家店舗屋根の保存修理の現場観察**〔観察: 参加者の見聞記録〕: 10人単位で作業用パネルの階段を上って瓦屋根の作業を見学。数年かけて修理する予定で、まず雨漏り防止のため屋根から着手。**街道に面した南側が建設当時の古い瓦、見えない北側は新しい瓦**にしており、割れた瓦は北側の古い瓦の中から補っていた。「**丸に沢潟の家紋と、カネト社章の瓦**」の写真言及。**東京種苗の右隣（現・駐車場）は、種の取引記録などがしまわれていた石蔵があった場所**＝榎本家店舗の敷地内施設の位置観察〔建設当時の瓦の新旧配置の解釈は参加者の観察文言であり、修理仕様書等の一次資料ではない〕。
- **渡邊正好（渡辺早生ゴボウの育種家）と榎本泰吉の係**〔確認: 本文〕: 同行した渡邊和嘉氏の尊父＝育種家・渡邊正好氏は「渡辺早生ゴボウ」を育成、その種子は榎本泰吉社長の**東京種苗（株）**が販売。渡邊氏の兄・徳好氏のメール「**榎本泰吉さんは、父のとても仲の良い友達でした。一度だけ運転して父と一緒に種子屋街道の店に行ったことがあります…母も泰ちゃんと呼んでいましたから、種子屋さんの中では一番信用できる人だったんだと思います**」（50年前の話とする）＝**滝野川ゴボウ系育種家と種苗商の人的つながりの一次証言（伝聞）**。
- **種子地蔵の前で見学会の順番待ち**、待機者に山本洋空氏が滝野川ゴボウの栽培地を案内・説明〔観察: 本文〕。種子地蔵（[ORG-047](../org/ORG-047.md)・2022年5月建立）が見学会の待機場所として機能していることの傍側記録。
- 会場で遭遇した人物: 阿部希望（『伝統野菜をつくった人々』著者・横山学芸員と榎本留吉商店の調査を行った）、日本農林社・近藤友宏社長、元滝野川種苗・田中克造氏、大正大学・下村明徳講師〔確認: 本文。**種子屋街道関係者の現時点の人的ネットワークの記録**〕。「種子屋街道説明案内板の設置2022年3月・大正大学松本洋幸教授」文言は[ORG-046](../org/ORG-046.md)（看板5枚設置の大学側プレス）と対応〔松本の称号はプレス＝「准教授」・本記事＝「教授」の表記差あり〕。
