# [BLOG-229] 鹿島紡績所と抄紙会社の立地・用水（wheatbaku「幕末の大砲製造所⑨」）〔repo初出〕

- **直接確認（2026-11-15、open_url・本文全文）**: 気ままに江戸（夢見る獏）の「[鹿島紡績所と抄紙会社（幕末の大砲製造所⑨）](https://wheatbaku.exblog.jp/32708328/)」（**2022年8月15日**）。同シリーズ②⑧⑩は[BLOG-227](BLOG-227.md)・[BLOG-228](BLOG-228.md)・[BLOG-230](BLOG-230.md)。
- **鹿島万平と鹿島紡績所〔確認：本文記載〕**: 鹿島万平は**深川の米屋の次男**で、嘉永2年（1849）から木綿・繰綿問屋を開業、横浜開港後は綿花貿易に従事。**明治3年（1870）に滝野川に民間初の鹿島紡績所を設立し、明治5年（1872）に操業開始**〔明治3年設立・5年操業の年次差を明記。**設立年の明治3年はrepo初出**（BLOG-226の「明治5年に水力紡績工場を設け」の表記と年次が異なるため併記に留める）〕。**当時の西洋式紡績機械の動力は水車で、鹿島紡績所が滝野川に設立されたのは水車の動力となる王子分水があったため**〔**BLOG-226の未解決だった「鹿島万平紡績の立地・用水＝王子分水」を、筆者が明記する形で解消する二次記述。ただし王子分水のどの区間から取水したかの具体はなし〕。明治21年に長男・鹿島萬兵衛の東京紡績株式会社と合併して滝野川の工場は廃止（萬兵衛は大正11年『江戸の夕栄』を著す）。**明治37年に跡地へ大蔵省醸造試験所が設置**（昭和34年国税庁所管・平成7年東広島市へ移転、跡地は醸造試験場跡地公園）〔**鹿島紡績所＝滝野川反射炉跡地・醸造試験所の前史という土地の連続性はrepo初出**。BLOG-127の実踏（旧醸造試験所第一工場＝反射炉跡）と対応〕。
- **抄紙会社の用地選定〔確認：北区史引用〕**: 明治6年（1873）に渋沢栄一らが抄紙会社（後の王子製紙）を創立。用地は「**一に水が清くて良く、而も水量が豊富でなくてはならぬ、（中略）その次には交通の便も良くなくてはならぬ」**の方針で、外国人技術者を交えて**小日向・関口のほか岩淵・王子・板橋、品川川崎など各地で調査**が行われ、王子に決定した〔**水窪川流域の小日向が製紙工場の候補地として実地調査されたという記述はrepo初出**。関口（BLOG-227の大砲製造所と同じ町）と並ぶ候補の存在は、目白崖線下の水車・水利の評価の比較資料になる。ただし小日向調査の詳細（対象水路は神田上水か千川系か）は本文にない〕。王子決定の理由は**水質の良い王子分水の利用可能性**・破布の入手（東京中心地に近い）・**「隅田川」に通じる「石神井川」の舟運**（原材料・製品の運搬）・鹿島万平の推薦と王子村大谷倉之助らの誘致。
- **『王子製紙社史』の直接引用〔確認：二次引用（昭和31年刊社史の引用文）〕**: 『王子製紙社史』（**昭和31年6月15日発行 第1巻**）から「**王子村に工場を建設するについて最も重大な問題になったのは用水であった。製紙事業にとって用水は死活に関する重要事だったからである。（中略）こうして会社の利用にまかされた水は徳川幕府が慶応元年に王子・滝野川に大砲鋳造の目的を以て、反射炉を築造するにあたって、それに要する用水を得るため、千川上水を巣鴨から分流して来たものである。（後略）**」を引用する〔**明治期の当会社自身の社史が、抄紙会社の工業用水を幕末の反射炉用水として開削された千川上水の分流（＝王子分水）に帰する履歴を明記する記述はrepo初出**。「千川上水を巣鴨から分流」という起点表現はBLOG-127の分配堰（滝野川6-9）・堀留等の流路記述と対応する。社史原本・該当頁は未確認で、引用はブログ経由の二次〕。
- **制限〔未解決〕**: ①『王子製紙社史』の原本確認（該当頁・前後の文脈）は必要。②鹿島紡績所の取水地点・水車の位置の具体はなし。③「小日向・関口」の候補地調査の一次史料（社史・北区史の出典）は未確認。④明治3年設立・明治5年操業の年次は資料により表記ゆれがある（kotobank等では「明治5年創設」表記もあり）ため断定しない。
