# [BLOG-304] 読売新聞・岩崎兼男証言と三鷹市爆弾穴掘削調査の報道〔中島飛行機レーンの2026年報道アンカー〕

- **書誌〔確認: 本文全文・2026-11-23取得〕**: 読売新聞オンライン（東京23区のニュース）「**工場爆撃九死に一生　武蔵野空襲　元社員・岩崎さん　２０メートル先に不発弾**」 https://www.yomiuri.co.jp/local/tokyo23/news/20260904-GYTNT00386/ 〔**2026/09/05 05:00配信**（URL番号は20260904）・署名＝**長谷部耕二**〕。
- **武蔵製作所の規模・被害の概要文言〔確認・repo初出の文言群〕**: 「終戦まで現在の武蔵野市で稼働した**中島飛行機武蔵製作所**は旧日本軍の**零（ゼロ）式艦上戦闘機（零戦）のエンジンなど**を生産していたため、**計９回、米軍から空襲を受けた**」＝計9回の空襲。「武蔵野市などによると、**同製作所では軍用機のエンジンの約３割を生産しており、従業員や勤労動員の学徒ら約５万人が働いていた**」＝**エンジン約3割・従業員・学徒約5万人**（[BLOG-305](BLOG-305.md)「国内エンジン生産シェア4分の1」・約5万人との対で、約3割という数値はrepo初出〔出典の一次根拠（武蔵野市の説明の先）は本文に特定なし〕）。「同製作所は米軍から計９回に及ぶ空襲を受け、**２００人以上が亡くなった**。被害は周辺にも及び、一般市民も犠牲になった」＝200人以上〔[BLOG-305](BLOG-305.md)碑文（工場だけでも220名）とほぼ同値の報道側文言〕。
- **岩崎兼男証言（1944-11-24の西工場）〔確認・repo初出〕**: 三鷹市の**岩崎兼男さん（９９）**＝**1943年に徴用**され、**現在の都立武蔵野中央公園の周辺に建てられていた鉄筋コンクリート造りの西工場**で旋盤工としてエンジン部品製造〔**西工場の位置を都立武蔵野中央公園周辺とする文言**＝[BLOG-302](BLOG-302.md)（武蔵野中央公園=中島飛行機製作所跡地）・[GOV-555](../gov/GOV-555.md)（東工場北辺=NTT）と合わせ、**東西工場の対応が報道側でも裏付いた**〕。月給100円近い好待遇（一般日給1円との対比）。**44年11月24日、サイパン島から出撃した米軍のＢ29が本土空襲**＝二十数機が武蔵野市上空に飛来、工場3階→同僚約40人と地下1階の食堂に避難、「約２０メートル離れた場所の上部にぽっかりと穴が開き、**重さ２５０キロの爆弾が床に横たわっていた**」＝**250kg不発弾が約20m先に落下不発の証言**。「爆弾の信管が不完全だったおかげで命拾いした。もし爆発していたら皆、即死だっただろう」＝**信管の不完全性による不発**というメカニズム証言〔[GOV-556](../gov/GOV-556.md)（岡本勇の雷管抜き・処理実務）と対になる被災側の一次記録〕。爆撃は軍事機密とされ、上司が「余計なことは言うな」とかん口令・翌日の新聞は「**損害は軽微**」＝**報道統制下の被害の矮小化文言**。工場は爆撃後に近くへ移転して操業持続。B29に対し旧日本軍は高射砲陣地から攻撃したが砲弾は届かず、上司に「B29を撃墜するための砲身を作る旋盤を設計中」と言われた証言＋45年3月東京大空襲後の浅草の川で黒焦げの母子の目撃譚。
- **三鷹市2025年7月の爆弾穴掘削調査〔確認・repo初出〕**: 「隣接する三鷹市内の雑木林には、**縦約２０メートル、横約１５メートル、深さ約１・５メートルの楕円形の大きな穴**がある。**同市が昨年７月、大小二つの穴を掘削調査したところ、爆発で地中の土が周囲に飛び散った状況から、米軍機が落とした爆弾によって形成されたと確認された。地中からは、爆弾の一部とみられる金属片も見つかった**」＝**2025年7月・三鷹市の掘削調査で爆弾穴（楕円形20×15×約1.5m・大小2穴）の形成が確認され金属片が出土**〔武蔵野市域（[GOV-556](../gov/GOV-556.md)）ではなく三鷹市側の調査という点もrepo初出〕。
- **航空写真判読・書誌引用〔確認・repo初出〕**: 郷土史を調べている**国際基督教大高校の高柳昌久教諭（５９）**は「米軍が撮影した航空写真を見比べると、**４５年４～５月にできたものではないか**」＝**米軍航空写真の判読による爆弾穴の形成時期の推定**（4〜5月）。**青木邦弘著「中島戦闘機設計者の回想」（光人社ＮＦ文庫）**の引用文言＝「**夜間空襲で爆弾が落ちた。直径１０メートルほどのすり鉢状の穴が巨人の足跡のように続き、大きな松の木がへし折られていた**」＝**BOOK-284の武蔵空襲の語りの引用（転記）**。高柳教諭「『爆弾穴』は貴重で、歴史的な戦跡。爆撃の恐怖を伝え…大切に保存・活用してほしい」＝**爆弾穴の保存・活用の提言文言**。
- **意義〔観察〕**: ①[BLOG-302](BLOG-302.md)（2026年の住民側）・[GOV-555](../gov/GOV-555.md)（行政解説・1997年処理）・[GOV-556](../gov/GOV-556.md)（証言集・戦後処理史）を**2026年の有力紙報道で束ねるアンカー**で、中島飛行機レーン（工場立地→空襲→不発弾→跡地利用）の全体像が報道・行政・証言で交叉確認された形になる。②**2025年7月の三鷹市掘削調査**は、[BLOG-302](BLOG-302.md)の「不発弾の心配」（2026年時点の調節池工事）と[GOV-555](../gov/GOV-555.md)（1997年処理）の間の2025年に近隣市が爆弾穴の調査・形成確認・金属片出土まで行った事例で、**不発弾を巡る近年の行政活動の新事実**〔調査報告書本文は未取得＝文言は報道依拠〕。③**高柳昌久の航空写真判読（45年4〜5月）**はrepoの1944年陸軍写真・1947年米軍写真M372等の判読レーン（README載図系）と同じ視座（写真判読による年代絞り込み）の中島飛行機周辺への適用例。④書誌レベルでは[BOOK-284](../books/BOOK-284.md)（青木邦弘）を新規に開いた（文言の典拠は読売記事経由の二次引用）。
