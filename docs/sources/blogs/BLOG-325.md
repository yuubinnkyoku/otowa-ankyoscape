## 内容メモ

- **〔確認: 記事本文＋コメント欄〕** [BLOG-057](BLOG-057.md)で「愛心幼稚園支流（仏）」として記録した谷端川支流（水源＝目白5丁目・山手通りのすぐ内側の窪地〔BLOG-057〕）について、コメント欄の指摘（猫またぎさん・Holiveさん）を受けて**山手通りを越えてさらに西へ上流が続く**ことを確認しに行った記事。
- **〔観察〕** 支流の上流端は「かねまつ」（金松？）の表札の駐車場の前の**素朴な公園**で尽きる。著者は「水源はここかと疑いたくなるような公園」とし、**「谷端川の支流沿いには『水源＝公園』という箇所もいくつかある」**と指摘〔谷端川支流群の土地利用の傾向指摘〕。
- **〔観察＋推定〕** 中落合3丁目2-16に**山手通りから西に延びる短い苔の暗渠道**（2ブロックほどで消滅）を発見。地形図から、この暗渠は山手通りを北上して愛心幼稚園支流に合流していたのでは、あるいは「宅地化に伴って水路が上流にどんどん延びていく」現象の仕業かもしれない〔推定〕。
- **〔観察〕** 愛心幼稚園前の崖から始まる暗渠路地の実景: ワッフル型車止め・夥しいマンホール・コインランドリー沿い・末端の金網の向こうの放置された区画〔2012年時点の観察記録〕。建設業・建材屋の社屋が多いことへの著者の違和感の記録〔観察・意味づけなし〕。
