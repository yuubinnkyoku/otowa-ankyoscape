# [BLOG-033] 夢七雑録「谷端川（千川上水長崎村分水）跡を歩く−１−」

- **書誌・取得〔確認〕**：gooブログ「夢七雑録」2018-05-24付。**第30回（BLOG-133）と同じWayback id_指定の手段でpart1の本文全文を初取得した（2026-11-13、第50回）**。直接アクセスはgooブログサービス終了により遮断。従来の「二次転記（抄録）」から**直接確認へ格上げ**。
- **内容〔確認：本文全文〕**：粟島神社〜椎名町駅までの谷端川上流部（長崎村分水区間）を古地図（嘉永7年・明治42年・大正14年・大正15年）と突き合わせながらたどる記録。
  - **分水第一橋の位置〔読図〕**：明治42年地図で分水地点から田圃の中を粟島神社へ向かう水路と、それを横切る一本の道が記されており、**長崎村分水の一番目の橋は千川駅前郵便局の近く**と推定〔筆者読図〕。
  - **弁天池の変遷〔読図〕**：嘉永7年地図には**丸い弁天池**が描かれ、池から流出する谷端川に長崎村分水が合流。明治42年地図では**粟島神社を横切る道が池を南側と北側に分断**。南側の池は形を変えて現存、**北側の池（神社裏手駐車場辺り）は消滅**＝repo初出の池変遷叙述〔いずれも筆者の地図読み〕。
  - **上流部の二股流路〔読図〕**：谷端川は長崎村分水と合流後、**東側と西側に分かれて流れていた**が、大正の耕地整理で水路整理が進み、**大正15年地図では一本の直線的水路にまとめられた**〔BLOG-135・BLOG-133の耕地整理関連記録と整合〕。
  - **要小南側のショートカット分水路〔読図・repo初出候補〕**：谷端川から分水して東へ流れる分水路（現・要小の南側の道に相当）が**上流部をショートカットするように造られ**、上流部と中流部以下への給水バランスが目的だった**かも知れない**〔筆者推測〕。嘉永7年地図では**大山道を水路が掘り下げて潜り、道に橋を架けて越えていた**と推定。大正時代の終わりに直線化され**日之出橋付近で本流に合流**するようになったが、今は姿を消している〔BLOG-154の日ノ出橋=字名由来と対応する橋の付帯年次情報〕。
  - **第六天の祠と池〔観察・repo初出〕**：江戸時代からの道（現・信号付近）を右に行った先に**第六天の祠があり池もあったが、今は駐車場となり何も残っていない**〔GAZ-018等の第六天関係既収録に「池の消滅」という現況観察を追加〕。
  - **不動湯と水路跡〔観察・repo初出〕**：西向不動の祠のそばにあった**公衆浴場「不動湯」は廃業**したが、**その横を流れていた水路の跡は今も確認できる**。付近に長崎アトリエ村の説明版（BLOG-054・BLOG-138のアトリエ村地名と整合）。
  - **椎名町駅手前の西側合流水路〔読図〕**：大正14年地図には踏切手前で谷端川を渡る新道（現サミット通り相当）と**西から合流する水路**が記されるが、この水路は後に消滅し**線路の側溝がその代わりとなった**〔読図〕。
  - **暗渠化以前の冠水記憶〔伝聞〕**：この辺りは暗渠化以前、**大雨のあと膝ぐらいまで冠水することもあった**〔筆者の記憶・伝聞段階〕。
  - **山手通りで分断された江戸期道〔読図〕**：大正14年地図の長崎神社から目白通りへ出る江戸時代からの道（線路南側で谷端川に架かる唯一の橋を持つ）は**山手通りにより分断され現存しない**。大正15年地図では多くの道と橋が新設。
- **意義**：谷端川上流部の流路変遷（二股→一本化）・弁天池の南北分断と北池消滅・ショートカット分水路という未知の水路群を、複数時点の古地図読みで時系列配置した点が新規。個々の年次・位置は筆者読みのため原図照合を要する。
- **注意**：本記事の古地図（嘉永7年・明治42年・大正14/15年）の出典明示はなく、図版は未確認。読図内容を事実としてでなく読図結果として扱う。
