# [BLOG-033] 谷端川（千川上水長崎村分水）跡を歩く

- **二次転記（2026-11-11、検索結果の抄録）**：本文未確認。抄録によれば**長崎村分水（四ケ村分水）は千川上水の分水のなかで最も距離が長く、谷端川に千川上水から助水すると共に新たな水路も設けて、長崎村・池袋村**（ほか中丸村・金井窪村）に供給したとする。
