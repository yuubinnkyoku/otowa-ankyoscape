# [BLOG-257] Natrium.jp「善福寺川周辺の水路敷群（四面道口分水）」（2021）〔repo初出・[BLOG-254](BLOG-254.md)が指摘した最重要頁。六ヶ村分水レーン（[GOV-490](../gov/GOV-490.md)四面道4か所説・[BLOG-251](BLOG-251.md)小沢川養水説）の中核欠落部分〕

- **書誌〔確認: 本文全文・2026-11-22取得〕**: Natrium.jp「水路敷を行く」の善福寺川系カテゴリ内頁「四面道口分水」、写真は2021/5/29撮影〔BLOG-254の目録で「六ヶ村分水・天保新堀用水の諸課題に直結する頁群」とされていたもの〕。
- **四面道口分水の定義文言〔確認・repo初出〕**: 「**四面道口分水は新青梅街道を流れていた六ヶ村分水から善福寺川方向で導水していたもので、善福寺川左岸のそれほど広くない低地を流れている**」＋「**位置取りから考えると、この水が高野ヶ谷（こやがいど）の水路や、新堀用水を通して桃園川にも供給されていたのかもしれない**」〔六ヶ村分水の**分水先の一つとして四面道口分水＝善福寺川左岸低地への導水路**が具体的流路つきで初めて記録された。高野ヶ谷戸水路・新堀用水経由の桃園川供給は「かもしれない」の**推定文言**であり断定しない〕。
- **流路の実走観察〔確認・観察〕**: 「**春日橋から北へ向かう直線道路が元の分水とされる**」→桃二小東交差点手前の矢印部分・民家脇から崖に向かう**蓋暗渠と藪**（「このあたりに湧き水があったということだろうか」）→荻窪高校北側にも崖へ向かう蓋暗渠（荻窪高校敷地に紛れ込み崖上に水路敷は見当たらない）→桃井第二小学校脇（水路は直進方向から流れてきていた）→東電荻窪支社前交差点（路地から流れてきていた）→中央線側道の擁壁（中央線嵩上げで水路敷は途切れる）→環八西側・中央線北側の窪地と車止め付き水路敷（荻窪駅方向）→北端まで。**「かつては環八に沿って直接善福寺川に流れていく水路もあったらしいが、環八工事で跡形もない」**〔春日橋〜四面道間の流路を道路・蓋暗渠・窪地の残存で遡る観察記録。前期（環八工事前）の直接放流路と後期の導水流路の二系統の示唆〕。
- **四面道交差点側の現況〔確認・観察〕**: 「**四面道交差点西側で六ヶ村分水から水を分けていたはずだが、その痕跡もよくわからなくなってしまっている**」〔[GOV-490](../gov/GOV-490.md)（すぎなみ学「取水口6か所のうち4か所＝四面道交差点付近説」）の現地側背景。痕跡喪失の程度が記録された〕。
- **光明院（荻寺）〔確認・荻窪地名由来の文言〕**: 中央線が環八を渡る陸橋脇の真言宗豊山派光明院（荻寺）。「**和銅元年（708年）開創という言い伝え**のある古刹で、**あたりに生えていた荻を使って仏像を祀るお堂を建てた**といい、**そこから荻窪の地名が起こったと言われている**」〔荻窪地名由来の言い伝えの記録（和銅元年は言い伝え文言）〕。
- **荻窪白山神社〔確認〕**: 水路敷の東側に参道が並走する荻窪白山神社。「**文明年間（1469〜1486年）創建と伝わる**。**萩の箸で食事をすると歯痛が治るという逸話があって、歯痛除けの神社として知られている**そうだ」〔BLOG-250・BLOG-249に出てくる西田町・荻窪系の寺社群の追加〕。

## 制限・未解決

- ①四面道口分水という呼称と流路の同定は本文（書き手）によるもので、『杉並の川と橋』等の文献上の確認は本文に明記されず（引用文言なし）、出典文献は本文に明記されていない。②高野ヶ谷戸水路・新堀用水への給水関係は「かもしれない」の推定文言。③環八工事で消えたという直接放流路の存在時期・環八の工区年代との対応は未確認。④荻窪高校北側の蓋暗渠と桃二小脇の水路敷がどこで接続していたかは、本文の観察上で見失い箇所あり。
