- **芝久保用水の成立〔確認:（1）本文〕**: 「**明治期に入り田無用水が拡張された際、同時期に作られた水路が芝久保用水です。現在の西東京市芝久保２丁目付近より分水して、芝久保町南部や南町の西側をながれていました。主に飲水としての利用の他、余った水は石神井川沿いに作られた田畑の農業用水としても利用されたそうです**」＋「**一部は比較的遅くまで開渠区間が残っており、１９７０年代の半ばでも水路が確認できる場所がありました**」＝**①明治期の田無用水拡張と同時期の作成、②芝久保2丁目付近分水・芝久保町南部・南町の西側を流下、③飲水＋石神井川沿田畑の農業用水、④1970年代半ばまで開渠残存、という4層の文言**〔repo初出の芝久保用水本編観察。BLOG-281（1）・BLOG-286（5）の言及を本編観察に格上げ〕。
- **みたけ分社通りの分水と水車〔確認：（1）本文・repo初出〕**:
  - 「**田無用水からの分水は、みたけ分社通り交差点より少し手前で行われ、民家の裏手を抜けて、この場所から通りに沿って南に流れていたとされています**」＝分水点＝みたけ分社通り交差点少し手前〔「とされています」〕。通りの向かいには「**水路と歩道が続いて再び田無用水方向に向かっている**」＝**田無用水へ戻る水路の現存観察**。
  - 「**明治３年に水車が作られたという資料があることから、水車の動力のため、許可を得て芝久保用水の割り当てより多い水を引き込んで、過剰分を再び田無用水に還流していたのではないかと推測します**」＝**明治3年に水車が作られたという資料＋割当超過引水→田無用水への還流構造という推測**〔筆者推測と明記。田無用水の樋口四寸四方（[BLOG-284](BLOG-284.md)）＝水量制限の別例。**明治3年またも登場＝明治初年（1868-71）の水系再編期の文脈と重なる**〕。
- **空中写真読図と開渠終末期〔確認：（1）本文・国土地理院空中写真の引用加工図つき〕**: 「**芝久保用水の本流は、西武新宿線の線路上と同じ幅の黒い線が南北に走っていて、この黒い部分が本流であるとわかります**」＋「**手持ちの資料を見比べると、１９６８年ごろまでは、線路を渡る水路が確認できるが、その後の写真では線路の水路跡が消えていることから、１９７０年代の初めに埋められたのだと思います**」＋「**芝久保用水は、分水も併せて４ヶ所で西武新宿線を超えますが、最後まで水路が残っていたのはこの場所で、写真の通り１９７９年までは存在が確認できます。他の場所は、１９７０年代の初めには埋め立てられるか、暗渠化されています。１９８０年代半ばに入るとこの場所でも確認ができなくなっているため、８０年代の初頭にこの場所も埋め立てられたのでしょう**」＝**国土地理院空中写真（1961年・1979年引用・加工）による水路読図＋①西武新宿線越え4か所（分水込み）、②大半は1970年代初めに埋立/暗渠化、③五軒家通り踏切の最後の開渠は1979年まで確認・80年代最初の埋立、という終末期の年代観察**〔repo初出の詳細年代層〕。
- **下流の3流末〔確認：（1）本文〕**: 「**水路はこの先で、今の支援学校の間を曲がり石神井川に落ちるルートと、さつき橋まで行き落とされたルート、そして石神井川沿いの田畑に水を供給する、田用水のルートがあったと言われています**」＝**流末3ルート（田無特別支援学校裏→石神井川／さつき橋／田用水）**〔「と言われています」〕。
- **南町の水田用水〔確認：（2）本文〕**:
  - 「**最近まで存在すら知りませんでしたが、石神井川沿いに拓かれた田畑の農業用水として、芝久保用水を利用していたそうです**」＋「**水路がわかる資料を調べていたら１枚の絵を見つけました。南町一帯の田畑の位置と水路が書かれた絵なのですが、縮尺がめちゃくちゃで経路の特定は難しい**」＋「**尚、水路の名称は不明のため、仮称として水田用水とする**」＝**「南町一帯の田畑の位置と水路が書かれた絵」の存在＝repo未収録の図資料候補**〔絵の典拠・所載は本文に特定なし＝探索課題〕。
  - 「**資料の石神井川沿いの田んぼは緩い棚田になっているという記述を見て、この辺りの芝久保用水自体が現在より少し高い位置を流れていたのかもしれません**」＝**石神井川沿いの棚田の記述と芝久保用水の高度の推測**〔「かもしれません」〕。
  - 「**５０年ほど前まで、石神井川は今より川床が浅く狭かったので、大雨でよく氾濫していたそうです**」＝**50年ほど前（1960年代後半〜1970年代前半）までの石神井川の川床浅・狭・氾濫頻発という口碑**＝石神井川の改修史（昭和後期改修＝[BLOG-281](BLOG-281.md)〔4〕の旧流路文言）の地元側の口碑層。
  - 「**田無駅の真南、旧道の武蔵境通りの近く…昔は棚田になっていて、この坂の途中辺りを石神井川に併走して東に水路は流れていた。水路図には記載していないが、田無用水の南水路から一本水路が引かれ、この辺りに接続していたようだ**」＋「**水田用水は写真の広場奥側の道路に沿って進み、右側で田無用水の南水路の残水と合流後、写真手前側に流れる石神井川に流れ落ちていたようです**」＝**南町側の水路群（田無用水南水路から引かれた枝水路込み）の推定流路**。
  - 結び＝「**次回は文化橋より東側を紹介します**」＝続編（南町の水田用水（2））の存在を示す文言〔目録上の所在は未確認＝次回掃引課題〕。

## 意義〔観察〕

- 芝久保用水は田無用水系の枝用水として repoに名称のみ出ていた（[BLOG-281](BLOG-281.md)・[GOV-513](../gov/GOV-513.md)）が、本編観察で**開設期（明治）・分水点・流路・終末期（1970年代〜80年代最初）・流末の3ルート**が記録層として成立した。特に**空中写真による線路越え水路の消失年代の特定（1968年まで◯→70年代初め埋立／最後の1か所1979年まで◯→80年代最初埋立）は、repoの「いつ暗渠化したか」目的に対する最も細かい年代層の一つ**。
