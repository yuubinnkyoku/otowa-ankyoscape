# [BLOG-306] 乗りものニュース「武蔵野競技場線の跡を歩く」〔競技場線・境浄水場引込線の年次群・遺構細部の独立裏付け〕

## 書誌〔確認: 全4ページ本文（/post/82600, /82600/2, /82600/3, /82600/4）・2026-11-23取得〕

- 乗りものニュース https://trafficnews.jp/post/82600 「**実働わずか8か月！ 東京に残る「薄幸」鉄路、武蔵野競技場線の跡を歩く（写真17枚）**」（**2019.01.20**・**栗原 景**（フォトライター・1971年東京生まれ）・写真は2018年12月のほか2006年6月・2010年2月の自身の撮影資料を併用）。国土地理院の1956年航空写真（東京グリーンパーク球場解体直前）の加工図も掲載。

## 競技場線の年次群〔確認〕

- 国鉄（現・JR東日本）中央本線の三鷹駅から分岐、北へわずかひと駅、**全長3.2km**。**開業は1951（昭和26）年4月14日**。終点・武蔵野競技場前駅の横には**東京グリーンパーク球場**（「武蔵野グリーンパーク野球場」「東京スタディアム」とも。**国鉄スワローズ（現・東京ヤクルトスワローズ）の主催試合も開催**）があり、球場アクセス鉄道として建設〔開業日の明示は[BLOG-305](../blogs/BLOG-305.md)「昭和26年4月開業」を日レベルで具体化する独立裏付け〕。
- 電車が走ったのは**わずか1年足らずで実働約8か月**。**翌1952（昭和27）年に休止**、**1959（昭和34）年11月に廃止**〔BLOG-305「34年11月1日廃線」と整合〕。試合開催日にはボールをデザインしたヘッドマークを付けた直通電車が東京駅から運行された。

## 境浄水場引込線と競技場線の重層史〔確認〕

- **境浄水場は1924（大正13）年完成**。同じころ、**水の濾過に使う砂利の運搬用に武蔵境駅からの引込線が建設**。太平洋戦争開始で運行休止、**1943（昭和18）年ごろ境浄水場の北東にあった中島飛行機武蔵製作所への専用線に造り変え**（工場空襲破壊で用途喪失）。戦後の中島跡地は進駐軍接収を経て東側用地が返還され、**5万人収容の東京グリーンパーク球場が建設**。当時神宮球場が接収されていたため都内の公式戦球場は後楽園のみという事情があった〔大正13年砂利運搬起点の文言は[GOV-554](../gov/GOV-554.md)（境浄水場・水道施設史）系の傍証。「境浄水場の北東にあった中島」という位置関係の表現はrepo初出〕。
- **1950（昭和25）年に中島飛行機の引込線が廃止**されたのち、その跡を活用して三鷹駅からの球場アクセス線（＝武蔵野競技場線）が建設された。**同じころ境浄水場の引込線も復活**し、**1971（昭和46）年ごろに地図から姿を消した**〔BLOG-305の中島引込線「昭和25年5月廃線」と整合する独立年次群〕。
- 球場は**初年度にプロ野球・東京六大学野球など65試合を開催しただけで事実上閉鎖**（1952年の神宮返還・川崎球場開場で需要消失。**砂ぼこりが多いなど評判が良くなかった**）。**1956（昭和31）年球場閉鎖後は跡地に団地**（1980年代に米軍住宅返還→公園化、武蔵野市役所も移転）。

## 遺構の細部〔確認・撮影年つき〕

- **堀合児童公園・堀合遊歩道（三鷹駅北口から西へ700m）**: 民家との境目付近に「**工」と書かれた石の杭**（「工」は**明治時代に鉄道を含む産業開発を担った工部省のマーク**で、**国鉄と民有地の敷地境界**を表す敷地境界票）が残る。かつては多数あったが**今はわずか数基**（2018年12月撮影）〔**「工」石杭＝工部省マークの敷地境界票の説明はrepo初出**〕。
- **昭和59年（1984年）の遊歩道・公園整備**でほとんどの遺構を失い、**玉川上水の橋台といくつかの敷地境界票だけ**が残った。
- **ぎんなん橋**: いちょう橋（玉川上水渡り・歩道つき）の隣の歩行者専用橋。架設は**2012（平成24）年**で、線路跡の上に架けられ鉄道時代を偲んでレールが埋め込まれているが**レールは当時のものではない**。橋の両側に鉄道時代の橋台が残る。**2011（平成23）年までは橋台がほぼ完全な形で残っていたが、新武蔵境通り建設の際に橋台の上に新しい歩道橋が架けられ、貴重な遺構はほとんど見えなくなった**（2010年2月撮影では南側橋台の一部が道路建設で削られる過程が記録されている）。北側に案内板「**中島飛行機 武蔵製作所 工場引込線 橋台跡**」〔BLOG-305「ぎんなん橋（平成24年建設=旧橋台上）」と整合・経過の細部は独自〕。
- **みどり橋**: 境浄水場引込線跡の玉川上水にあった歩道橋（遊歩道整備時に鉄道橋を再活用）。**筆者が1991（平成3）年に訪れた際は自由に渡れたが、当時すでに木製手すりの腐食が進んでいた**。**1997（平成9）年ごろ老朽化から立入禁止となり、2000年ごろまでに撤去**。現在は橋台跡のみ。**みどり橋の延長線上に境浄水場の南門があり、道路に対して斜めに架かっていたのが鉄道時代の名残**〔**みどり橋の撤去に至る過程・斜め架設の指摘はrepo初出**〕。
- **グリーンパーク遊歩道**: ぎんなん橋以北で武蔵野市に入り、武蔵野競技場前駅跡まで続く。「**グリーンパーク**」とは**中島飛行機武蔵製作所跡地を接収した米軍が付けた名称**。鉄道遺構は案内板以外ほとんど残らず、敷地境界票も25年で大きく減少。沿線には田畑と農作物の無人販売所が残る。
- **武蔵野競技場前駅跡**: 武蔵野中央公園（中島飛行機武蔵製作所跡地・**戦後は70年代まで米軍住宅**）手前で大きく右にカーブし道路に合流。道路の左側の分譲マンションが線路跡（**路線廃止後も土地は国鉄が所有し、90年代まではJRの社宅があった**）。**その先、武蔵野市立高齢者総合センターがある交差点が終点・武蔵野競技場前駅のあった場所で、戦前は中島飛行機武蔵製作所の正門があった場所**〔[GOV-558](../gov/GOV-558.md)（高齢者総合センター=武蔵製作所の正門）・[BLOG-305](../blogs/BLOG-305.md)と一致する独立確認〕。
