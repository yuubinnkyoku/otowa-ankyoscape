# [BLOG-098] 山手通りと千川上水暗渠の立体交差構造（「エア暗渠」）

- **書誌**: 乗りものニュース、植村祐介「[『エア暗渠』意外な構造 見えない川と交差する東京の環状道路](https://trafficnews.jp/post/614628/2)」（2ページ目）。2026-11-11、直接アクセスは遮断されたため**Wayback Machine保存版（2026-01-04取得）で全文取得**して資料化。
- **〔確認・観察〕** **板橋区大山〜板橋区役所付近で、暗渠の千川通り（都道439号）と山手通りが交差する地点（仲宿交差点付近）で、千川上水の暗渠が山手通りの上下から挟まれる構造**であると記す。**外回り（北行き）は地上を走り千川暗渠の上を横断**、**内回り（南行き）は仲宿交差点をアンダーパスし、そのアンパスが上空の構造物3つのうち2つ目として千川上水の暗渠をくぐる**。「エア暗渠」いいえ「暗渠サンドイッチ」と表現する〔確認：記事の構造説明／未確認：道路断面図との照合〕。
- **〔確認・観察〕** **JR板橋駅近くの旧中山道平尾宿から西巣鴨までの間は、暗渠の部分が周囲の道路より不自然に高く、注意して見れば分かる**。千川上水はこの交差部を残したが水道施設としての利用は終了している。
- **〔確認・二次〕** 千川上水の概説（元禄9年開削・関町付近から23区内はほぼ暗渠・豊島区内で北東へ転じ大山〜区役所付近で山手通り交差・西巣鴨）を含む〔いずれも既知の概説〕。
- **〔repoへの関連〕** 暗渠の観察軸として**蓋の意匠・水路敷形状に加え、他交通との立体交差（千川暗渠が道路の下を通り抜ける側と跨ぐ側の区別）**を与える〔観察〕。
- **〔未解決〕** アンダーパス築造年代と千川暗渠築造年代の前後関係、同種の立体交差が他区間にあるか。
