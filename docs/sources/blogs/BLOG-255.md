# [BLOG-255] miwa3k「善福寺川を歩く 神田川合流点から善福寺池」（2016-09-13）〔repo初出・[BLOG-143](BLOG-143.md)・[BLOG-144](BLOG-144.md)（千川上水1・2）の同一作者の善福寺川全流歩行〕

- **書誌〔確認: 本文全文・2026-11-21取得〕**: ブログ「散歩の途中」（miwa3k）の記事、**投稿日時2016年9月13日**。神田川合流点（中野富士見町駅・富士見橋）から善福寺池へ遡り、さらに千川上水を横目に上石神井へ抜けるルートの全流歩行記録〔[BLOG-070](BLOG-070.md)（谷端川）・[BLOG-143](BLOG-143.md)・[BLOG-144](BLOG-144.md)（千川上水その1・その2）と同一作者〕。
- **延長の文言〔確認・repo初出候補の数値文言〕**: 「**河川としての公式な延長は10.5kmであるが、源流の遅野井の滝まで含めると11.3kmとなる。神田川の合流点には源流まで11.3kmの案内板が杉並区の名前でつけられている**」〔**善福寺川の公式延長10.5km／遅野井の滝込み11.3kmの測定文言と、合流点の区名義11.3km案内板の存在**。[GOV-487](../gov/GOV-487.md)（遅の井＝善福寺池の井戸水ポンプ揚水の滝・源流扱い）と対応する距離表示の一次観察。「遅野井の滝」の表記は本文のまま〕。
- **下流部の観察〔確認〕**: 神田川と善福寺川の合流点（背伸しをしないと見えないコンクリート護岸）→朝日橋（合流点から約250m）→環七越え（大聖堂入口交差点）→**善福寺取水施設の建物と調整池の呑口**（「増水時にあふれる水を左側にある調整池へ流し込むための入口（呑口）」「直径12.5mというどでかい水路管のトンネルが環七の下を通っている。神田川・善福寺川・妙正寺川の水量を調整」）〔[GOV-485](../gov/GOV-485.md)〜[GOV-486](../gov/GOV-486.md)の善福寺取水施設（都立善福寺川緑地）の現地側定点観察〕。**済美公園の親水施設**: 「おそらく蛇行していた川の流れを直線化した改修工事のときに古い流れのあった部分を公園にし、遊歩道をつけて河原に降りられるようにしたのだと思われる」〔蛇行帯の旧流れの公園化の推測文言〕。荒玉水道道路を渡って和田堀公園へ・**宮木橋**付近から上流側〔宮木橋=[GOV-486](../gov/GOV-486.md)流量配分図の図ラベル（宮木橋）と対照する実走定点〕。**和田堀公園〜善福寺川緑地で蛇行沿いに約4kmの緑の豊かな場所が続く**構造。
- **意義〔観察〕**: ①[GOV-486](../gov/GOV-486.md)・[GOV-489](../gov/GOV-489.md)で図・設備側から把握していた善福寺取水施設（呑口・調整池）の2016年時点の実物写真・見え方の一次観察、②11.3/10.5km文言と区名義の距離標識は、[GOV-487](../gov/GOV-487.md)の「遅の井系の源流扱い」の距離（起点）側の対応資料、③[BLOG-252](BLOG-252.md)の堀之内・済美地区の揚堀観察と同一空間の散歩系観察として対照可能。

## 制限・未解決
