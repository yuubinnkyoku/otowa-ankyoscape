# [BLOG-065] 谷端川暗渠 北池袋～下板橋間の観察

- **書誌**: 水徒然（onnbubatta）、**2016年6月25日**。https://yatolove.exblog.jp/23248324/ （exblog）。2026-11-11全文取得確認。2026-10-23・暗渠ブログ横断調査で未索引だった「水徒然」の谷端川記事の一部を資料化。
- **〔観察〕** 下板橋駅脇で谷端川暗渠（緑道）と交差、上流へ遡る散策記。**「豊橋」付近は谷端川が劇的に曲がる箇所**で、橋跡に似た構造物（幅員減少用の弧状の縁石か）を観察。
- **〔観察〕** 豊橋右岸側の変電所の敷地内に**蓋暗渠に見える敷石（交差あり・鉄板で継ぐ箇所あり）**がある。筆者自身が「単なる敷石かも」「トラップかしら」と疑いを留めており、**断定していない**。この変電所の東側隣地との境界が水路跡であることには言及（変電所近くに暗渠があるケースとの一般論と併記）。
- **〔観察〕** 谷端川上流部は激しく蛇行し、豊橋付近でグッと折れ、埼京線を越えた後は南東へ直線的に落ちる。東武東上線も下板橋→北池袋で大きく弧を描く。
- **〔観察〕** **北池袋駅近くに井戸の密集地帯**（現役と思われる井戸・花壇転用・水道下に電動ポンプ格納型など数か所）を記録〔下流・下板橋駅南側に製餡所、駅西側に製氷所があったとする旧地図読みも付記＝川沿い土地利用の傍証〕。
- **〔参考〕** 次回記事扱いで「谷端川・三之橋の女神さま」の存在に言及（未取得）。
- **〔未解決〕** 変電所内の敷石は同定不能・筆者の推測の域を出ない。井戸密集は谷端川谷頭低地の地下水利用の傍証にすぎず、川との直接接続は不明。
