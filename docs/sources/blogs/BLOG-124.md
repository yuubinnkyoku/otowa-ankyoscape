# [BLOG-124] めぐるスイッチ タイム写シーン10（大谷口北町・山崎橋）

- **直接確認（2026-11-12、本文全文）**: 電力会社PR記事。板橋区公文書館所蔵の**昭和52年（1977年）大雨時の石神井川の洪水写真**を元に現地（東山町と大谷口北町の境・山崎橋たもと）を訪ねる。公文書館の記録に撮影地点が残されていたと記す。〔石神井川の洪水写真の所在記録。板橋区公文書館の写真資料群の所在確認として GOV-074 浸水履歴と併せて記録〕
- **山崎／山崎田んぼ〔地名記録候補・二次転記〕**: 「大谷口北町周辺はかつて山崎といわれ、周囲は山崎田んぼといわれていました。水を張った田んぼに月が映えたその光景が非常に情緒的であった」という「越後屋たぬき」ブログの記述を孫引きする。**現在の山崎橋（平成6年＝1994年架替）の三日月・星の帯状意匠は山崎田んぼに映る月の風景の記憶が伝わったもの**と筆者が推測する。〔山崎・山崎田んぼはrepo初出の地名。孫引きのため原本確認待ち〕
- 石神井川の氾濫は昭和51年（1976）9月台風17号・昭和53年（1978）4月・昭和54年（1979）5月にもあった旨（[GOV-083](../gov/GOV-083.md) の板橋区公文書館展示と整合）。下頭橋（旧川越街道・石神井川）の「下頭橋〜けちんぼ六さん」伝説も水害由来と紹介。〔観察＋二次転記〕
