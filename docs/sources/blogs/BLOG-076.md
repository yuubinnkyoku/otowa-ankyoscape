# [BLOG-076] 暗渠を駆ける その3 弦巻川暗渠

- **直接確認（2026-11-11、open_url・本文全文）**：ランニングコース紹介ブログ。弦巻川＝神田川水系の支流、**始点＝豊島区立元池袋史跡公園（池袋駅から約200m）→終点＝東京メトロ有楽町線江戸川橋駅1a出口付近（神田川合流）、約4.2km**の現行の通説的認識を示す。
- **神田川合流点の水流〔観察〕**：「完全暗渠化されている弦巻川は**神田川へ注ぐ終点でのみ、水流をみることができます**。つまり今も道路の下で弦巻川は息をしている、ということが終点で確認できます」〔**江戸川橋・神田川合流部で弦巻川（第2雑司ヶ谷幹線系）の排水が流下しているという現況観察**。[LOST-001](../lost-web/LOST-001.md)（桜井氏）の弦巻川合流点観察と対応する独立の観察〕
- **表記と由来〔確認：記事の説明〕**：「弦」の字は縁起をかついで「**鶴**」があてられ「鶴巻川」と書かれることもあった。〔弦巻川／鶴巻川表記揺れの又一例（[BLOG-073](BLOG-073.md)『高田町史』1933の「鶴巻川」と並ぶ）〕
- **コース上の観察〔観察〕**：都電踏切・東京音楽大学池袋キャンパス・雑司ヶ谷の旧住居群など。暗渠は全区間道路、標高25〜39m。
- **制限〔未解決〕**：投稿年不明。「昭和の初め（1930年代初め）に全区間が暗渠化」という記述の典拠は不明（弦巻川の暗渠化時期論（BLOG-063文春シリーズ等）とは別の雑駁な概括として扱う）。
