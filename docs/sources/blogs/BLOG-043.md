# [BLOG-043] 駅からマンホール「暗渠を辿る ～ 千川上水」

- **直接確認（2026-11-11、open_url・本文全文）**：マンホール蓋観察サイトによる2011年の千川上水暗渠踏査記録。板橋駅〜千川親水公園間を蓋・遺構に注目しながら遡上した記録で、以下の各点が repo 未収録の観察・叙述として重要。
- **千川上水の蓋群〔観察〕**：千川上水の紋章（桜・イチョウ・メダカ風の意匠）が入った蓋が**板橋第一中学校裏に2枚・板橋高校南側の道に2枚**、滝野川6丁目と7丁目の境に**直径60cm程度の4枚**（林丈二『マンホールのふた 日本篇』昭和59年刊に既掲載で当時から泥詰まり）で確認できる。
- **巣鴨駅前の「千川上水空気弁・都北部公園」蓋〔観察＋筆者の推定〕**：**千川上水の六義園への給水の流路上**にあり、水道局ではなく建設局（北部公園緑地事務所=平成9年度まで、翌年度に南部と合併し現在は東部公園緑地事務所）設置と筆者が推測する。**六義園への給水は昭和43年に停止されたため、この蓋はそれ以前の設置で現在は未使用、下水道台帳にも記載がない**とする。※六義園給水停止（昭和43年＝1968年）の年は本ページの二次叙述として要出典照合（都公園協会・文京区資料等）。**本ページ単独では給水停止年を断定しない**。
- **千川上水公園（調節池跡）のバルブ〔観察〕**：江戸期に溜池で砂・ごみを沈殿させた後に下谷・浅草方面へ供給した調節池跡に、**六義園への給水を制御していたバルブが現存**する。
- **千川上水分配堰碑〔観察〕**：千川上水公園の明治通り向かいに**明治15年（1882）設置の「千川上水分配堰碑」**が残る。水利権明確化のために設置されたとする。碑の横に千川上水紋章の蓋。※碑の実在・碑文の読みは本ページによる。設置年の裏付けは要現地・公文書照合。
- **滝野川区間の暗渠化〔二次叙述〕**：滝野川6・7丁目境の蓋の周辺は**「この辺りが暗渠化されたのは昭和3年」**とする。※千川上水の滝野川区間の暗渠化年（1928年）を示す独立叙述として、既知の年表（1971年途絶〔GOV-058〕等）との整合を照合する。**本叙述単独では採用しない**。
- **大蔵省印刷局抄紙部への給水〔二次叙述〕**：幕末に王子方面への産業用水分水が始まり、**昭和46年まで大蔵省印刷局抄紙部（現・国立印刷局滝野川工場）へ給水**されたとする。※既知の千川上水通水終了（1971年〔GOV-058〕）と整合するが、抄紙部給水の上限年代の独立裏付けとして記録する。
- **流末の位置〔観察〕**：**板橋駅東口近くに角蓋2つ並び、現在の千川上水跡を流れる水流の終点はここで、ここから谷端川放水路に合流して石神井川に放水されている**。※既知の谷端川放水路（谷端川幹線雨水管）の説明と整合する位置情報の補強。
- **水神様の祠〔観察〕**：大山駅近くのアーケード内に、**千川上水が開渠だった時期の水難事故供養の水神様の祠**がある。※開渠期の水難史料・祠の由緒は未確認。**本観察だけで事故や年代を主張しない**。
- **「伏越」蓋〔観察〕**：千川上水暗渠を挟むように「伏越」蓋2枚（逆サイフォン。下水管が千川上水暗渠の下を横断）が設置され、暗渠位置の路上の目印になる。
- **制限〔未解決〕**：蓋の現況（2011年以降の撤去・更新）、分配堰碑の碑文全文、六義園給水停止年・滝野川区間暗渠化年の一次出典は未確認。
