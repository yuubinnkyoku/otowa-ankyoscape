# [BLOG-205] 谷端川北緑道（板橋区管轄）の橋跡観察と下板橋駅・金井窪駅の移転史

- **直接確認（2026-11-13、第64回・FC2直fetch）**：長年本文未取得だったentry-240（Wayback未収蔵・スニペットのみだった頁）の全文取得。
- **橋跡と支流合流〔観察：2018年〕**：**前田上の橋**（国道254号越え・板橋区側）に板橋区役所の**地籍図根点**がある。**前田橋のすぐ上流の民家敷地脇に素掘りの水路跡が現存**（「かつては水が流れていたのであろう窪み」）。北浦上橋・北浦橋は耕地整理時の橋、**江戸・明治期からあったのは中丸橋**で、中丸橋までが耕地整理の対象地域、と観察〔32橋リスト（BLOG-150・[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)）の補強。素掘り水路跡の現存観察はrepo初出候補〕。
- **金井窪〔推定：筆者による語釈〕**：「**金井」は鉄錆を含んだ湧水を意味する**そうで、かつての金井窪村は**錆水の湧く窪地**だったのかもしれない、とする〔「かな」＝鉄錆水の語釈は民俗語源で、原典（風土記稿等）の裏付けを本文は示さない。仮説として記録〕。
- **中丸川・出端川の合流〔観察〕**：**金井窪橋のすぐ先の左岸に中丸川が合流**〔BLOG-146・BLOG-150と整合〕。西前橋を渡る道は**高田雑司ヶ谷道**と呼ばれた古道（北は中山道仲宿、南は池袋駅付近から雑司ヶ谷・高田方面）〔西前橋＝高田雑司ヶ谷道は既出の整理と整合〕。西前橋の北で左岸に出端川が合流、出端川の合流点を過ぎると谷端川は東に向きを変え、**豊橋**がある。豊橋の先300mで北緑道は終了しカラー舗装に切り替わる。
- **下板橋駅の移転史〔伝聞・推定〕**：下板橋駅は**東武東上線開業時の起点駅**で、南側引込線敷地内に**0キロポストと東上鉄道発祥の記念碑**が設置されている。もともと東上本線は**大塚辻町（現・丸ノ内線新大塚駅付近）を起点とする免許**だったが東京市に阻まれ当駅からの開業となった、**1930年代（おそらく昭和10年頃）に移転**したようだ、と記す〔移転原因は「金井窪駅との駅間距離400m弱」「大塚辻町間開業不可能の判断で池袋方向に軌道を曲げた必要」との筆者推測。大塚辻町起点計画はrepo既記録と整合する独立記述〕。
- **金井窪駅〔伝聞：鉄道史の整理〕**：**1931年（昭和6年）9月開業**、1945年（昭和20年）4月13日の空襲で沿線が焼失し東武堀之内駅とともに営業休止、**1951年（昭和26年）に復活しないまま廃止**。金井窪駅は高田雑司ヶ谷道の西側・山手通り方向にあった〔位置の読図は [BLOG-050](BLOG-050.md) 黒田涼の区境議論と接続可能〕。
