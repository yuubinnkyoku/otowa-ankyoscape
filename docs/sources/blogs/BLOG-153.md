# [BLOG-153] 寅さん歩 その25 谷端川の流れを歩くー2（平野武宏）

- **直接確認（2026-11-13、Wayback id_付きURLで本文全文取得に格上げ）**：[Wayback保存版 2024-06-10](https://web.archive.org/web/20240610053136/http://www.shonan-fujisawa.jp/watanabe/wpage5143.pdf)。第43回は前半のみだった本文の後半（南緑道内の橋〜要町駅）を取得。
- **河川廃止と緑道命名の年次〔確認：筆者の記述〕**：「谷端川は**昭和37年（1962年）に河川としては廃止、暗渠化され下水道幹線**となりました。豊島区は谷端川跡を児童公園・親水公園・散歩道への整備を始め、**整備が終了した平成2年（1990年）に西武池袋線から川越街道までを「谷端川南緑道」（豊島区管理）としました**」〔1962年河川廃止説はGOV-008/009・BLOG-059と整合。「整備終了後の平成2年命名」という**命名年次の文言はrepo初出候補**〕。
- **橋の由來・位置（南緑道の後半部分。由来の多くはrepo初出の文言）**：
  - **宮下橋（西池袋4-14と4-36の間）**：緑道の入り口。**長崎神社下の橋という意味**〔由来文言はrepo初出〕。
  - **羽黒橋**：道路端に石標。**羽黒神社（西池袋4-23-3）に由来**。羽黒神社は山形県の出羽三山(羽黒山・月山・湯殿山)の出羽三山神社より分霊、**明治2年の社寺取調書によると武蔵国豊島郡長崎村の一社**〔社寺取調書の文言はrepo初出候補。BLOG-150の#30羽黒橋=橋跡碑のみ、BLOG-138の羽黒橋=羽黒神社由来と整合〕。
  - **霜田橋（西池袋4-18と4-19の間・立教通り交差）**：**「霜田」は「下田（ゲデン）」から変わったもの。関東の検地では一反歩あたり玄米一石一斗を産出する田畑を「下田」と云った**〔検地用語由来の文言はrepo初出〕。緑道の右側は立教大学用地（西池袋3丁目）。
  - **丸山橋（西池袋5-22と5-27の間）**：地名に由来。
  - **長崎橋跡の石標**：長崎地区の橋。**椎名町駅から「長崎橋」までに10の橋が確認されている**〔友の会資料による区間橋数=repo初出。南緑道に入ってからの7つの橋の位置に橋名の銘板付きモニュメントが再現〕。
- **谷端川第二親水公園**〔確認〕：霜田橋の先。途中に子供の像など彫刻が点在〔BLOG-148・BLOG-069の緑道観察と整合〕。
- **周辺〔確認〕**：要町一丁目交差点手前で山手通りと交差、有楽町線/副都心線の要町駅入り口。祥雲寺（池袋3-1-6）：江戸城和田倉門内に永禄7年創建、**明治39年（1906年）小石川区戸崎台より移転**〔周辺記録〕。
- **流路の読図〔観察〕**：椎名町駅北口の踏切を渡り椎名町公園角を左折、**西武池袋線を二度渡って**山手通りに沿って北上〔BLOG-135の「椎名町駅300m間に西武線が二度渡るU字」読図と独立に整合〕。
- **制限〔未解決〕**：1962廃止・1990命名の出典は筆者の記述で行政文書未特定。
