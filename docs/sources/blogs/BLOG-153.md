# [BLOG-153] 寅さん歩 その25 谷端川の流れを歩くー2（平野武宏）

- **直接確認（2026-11-13、Wayback id_付きURL）**：[Wayback保存版 2024-06-08](https://web.archive.org/web/20240608073403/http://shonan-fujisawa.jp/watanabe/wpage5143.pdf)。寅さん歩その25の第2回（椎名町駅〜谷端川南緑道〜要町駅手前）。**取得できたのは本文前半（約3.2KB・宮下橋のモニュメント付近まで）**で、川越街道到達以降の後半は未取得。
- **河川廃止と緑道命名の年次〔確認：筆者の記述〕**：「谷端川は**昭和37年（1962年）に河川としては廃止、暗渠化され下水道幹線**となりました。豊島区は谷端川跡を児童公園・親水公園・散歩道への整備を始め、**整備が終了した平成2年（1990年）に西武池袋線から川越街道までを「谷端川南緑道」（豊島区管理）としました**」〔1962年河川廃止説はGOV-008/009・BLOG-059と整合。「整備終了後の平成2年命名」という**命名年次の文言はrepo初出候補**（GOV-008/009の整備年次細目との厳密な異同は原資料照合を要する）〕。
- **宮下橋〔確認〕**：谷端川南緑道の入り口に当時の「**宮下橋**」のモニュメントがある〔BLOG-150の32構造物#32と整合する地点の独立叙述〕。
- **流路の読図〔観察〕**：椎名町駅北口の踏切を渡り椎名町公園角を左折、**西武池袋線を二度渡って**山手通りに沿って北上〔BLOG-135（落合道人2005）の「椎名町駅300m間に西武線が二度渡るU字」読図と独立に整合〕。豊島区西部福祉事務所（仮施設）脇を直進。
- **制限〔未解決〕**：本文後半（南緑道内の橋・川越街道接続部）未取得。1962廃止・1990命名の出典は筆者の記述で行政文書未特定。
