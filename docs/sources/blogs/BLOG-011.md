# [BLOG-011] 護国寺の自噴式手洗水盤（Replan 出張・旅先にて）

- 三木奎吾「護国寺 手水舎」Replanブログ、2013年7月6日
- http://kochihen.replan.ne.jp/?p=9209
- 元禄10年（1697）頃鋳造の唐銅蓮葉形手洗水盤一対二基（江戸鋳物師・椎名伊豫良寛作、桂昌院寄進とされる）を紹介し、寺の縁起を引用して**境内の湧水を利用する自噴式の手洗水盤として元禄期から明治大正期に利用された**と記す。
- 湧水利用の終期（明治大正期）とされる時期の根拠は縁起書きで、水源（湧出地・水量）や停止時期の詳細は記事にない。**境内の池・水路系（本項）と手水舎の湧水系の接続関係は不明**。独立の給水系だった可能性も含め、原史料（縁起・寺誌）で確認する。
- 確認者について：2026-10-26、利用者は未見と申告。確認者は未判定のまま。
