## 内容メモ

- **〔観察: 2019年〕** 西武池袋線・東長崎3号踏切を渡って北へ向かう千川上水。**踏切の北側で西へ向かってエンガ堀が流れ出ていた**（ビル脇の下がった部分がその名残）〔エンガ堀の起点が千川上水であることの現地観察記録。repoのエンガ堀資料群に加える〕。
- **〔観察〕** 長崎六丁目バス停（豊島区の地域公共バス扱い・1日8便）周辺。**歩道脇に中途半端な舗装部分があり、元の千川上水の水路敷**。都道420号が直線なのに対し水路敷がやや東側にはみ出している。サミットストア前で都道に合流。
- **〔観察〕** 豊島区立明豊中学校の前で都道が谷間になっている。本来の分水嶺はサミットストア付近から明豊中の裏側（南側）に回り込むが、**千川上水はエンガ堀支流の谷を跨ぐようにかさ上げして通り抜けており、学校側の歩道だけ位置が高くなっている**〔千川上水の谷越え構造の読図。エンガ堀谷頭と千川上水の立体関係の観察記録〕。
- **〔観察〕** 都立千早高校の前で千川上水は都道と別れる。三又で別れた先の水路敷に**複数の庚申塔をまとめて安置する場所**。「千川上水の脇にはたくさんの庚申塔が建てられていた」と推定。
- **〔観察〕** 北向きに進路を変えた水路敷の**千川親水公園の手前に橋がそのまま残存**。**「この橋を庚申橋といい、かつてはこの場所に庚申塔があったともいう」**〔千川上水（豊島区長崎側）の橋名・橋の現存遺構としてrepo初出。[BOOK-057](../books/BOOK-057.md)・[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)の小石川・人参川系の庚申橋とは別地点（同名異橋候補）〕。千川親水公園では水の流れが保たれている（枯れていない）。
- **〔観察〕** 児童公園整備区間を経て要町通り（都道441号）の**要町三丁目交差点**に至る。手前には橋の欄干が残り、以降は駐輪場として利用〔要町三丁目交差点＝長崎村外三村分水の分水点とする[GOV-068](../gov/GOV-068.md)・川のプロムナードの読図と、現地の水路敷痕跡が同じ交差点に収束する観察記録〕。
