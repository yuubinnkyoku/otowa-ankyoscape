# [BLOG-082] Natrium.jp 谷端川（椎名町〜上流端）その1

- **直接確認（2026-11-11、open_url・本文全文）**：目白四丁目仮児童遊園から千早フラワー公園方面への谷端川本流・支流の水路敷観察（2017年9月3日・11月5日撮影）。
- **旧真和中学校西側の南から合流する支流〔観察〕**：椎名町駅北側の旧真和中学校西側で南から支流が合流するとし、**道路右側の不自然な歩道＝旧側溝**、丁字路先の行き止まり水路敷、**目白第一保育園脇で道路に合流**、その先の交差点が**二つの水路の合流点**という流路をたどる。西側の流路（誓願寺裏手〜目白通り）と南側の流路（福の湯入口〜山手通り西側〜通学路の路地）を区別して記録する。〔観察／水路の同定は地籍照合なしの現地判読〕
- **目白通り二又子育地蔵尊〔確認：現地案内由来の転記〕〔repo初出〕**：**宝永7年（1710年）造立の銘**があり、元は**南長崎交番のある二又**に置かれていた路傍の地蔵尊で、**目白通りの拡幅工事に伴い昭和13年（1938年）に移転**したという。〔銘文・移転年は現地説明由来で、原典照合は未実施〕 **この地蔵の移転史は、目白通り拡幅（1938年）が南長崎二又周辺の水路敷・地形に与えた改変の時期を知る補助資料**となる。ただし地蔵の移転先が水路敷の延長線上かどうかは本文も「わからない」と明記。〔推定：水路との位置関係／未解決〕
- **椎名町駅の側溝〔観察＋二次読図〕**：谷端川本流の車止め先は椎名町駅にぶつかるが、**昭和22年（1947年）の空中写真では線路脇を踏切方向から水路が流れてきていたよう**に見えるとする。〔natriumの空中写真読図／検出限界・原写真の直接判読は未実施〕
