# [BLOG-182] 水窪川が作った谷を巡る⑥　もしかしてこれがホントの流路？

- **直接確認（2026-11-13、open_url・blog.jp直で本文全文取得）**: 第50〜51回で遮断が続いていた⑥（7711787）を取得。**第50回ノートの未解決「⑥本文未取得のため断定せず」が解消**し、BLOG-179（③④⑦）・BLOG-180（⑧）の読み替えの根拠となった⑥の訂正文を直接確認した。
- **造幣局崖下の遺構群〔観察: 2010年1月〕〔repo初出〕**: 東池袋造幣局の外郭に沿う崖上の対面2車線の道から、水窪川側谷への**鋭い崖**。崖下の細い道で**「高い崖の壁の下に開いた半円の穴を塞いだ跡」**と、石垣の奥の**「水を流していた管」らしき遺構**（正面から見ると管口）を観察。筆者は崖からの流れの受け止めを推測しつつ「この流れを引き継ぐ崖下の流路は見当たらない」とし、崖上=造幣局（前身=巣鴨プリズン）の観察として記す〔管の実体は記事内では特定されず、断定しない〕。
- **流路の訂正と本田創流路説〔repo初出文言の直接確認〕**: 予約投稿の間に調べた結果、**「随分まえに暗渠の大先輩HONDAさんがすでにこんなふうに取り上げてらっしゃいました」**として、①②回で「日の出商店街が流路だった」と書いたのを訂正。**「本当の流路はそうじゃない、ここなのではないか」**＝造幣局崖下の流路とし、**「水窪川の碑の位置も合点がいく」「このあたりの蛇行具合も説明がつく」「銭湯・君の湯裏側の蛇行もすんなりわかる」**と整理。**Googleマップに「新・水窪川」として地図を掲載**した旨を記す〔BLOG-179「君の湯裏=水窪川本流水路の読み替え〔⑥訂正に基づく〕」・BLOG-180「本来の水窪川流路に面した駐車場」の依拠元となる訂正文の実体を初めて直接確認〕。
- **本田創本人コメント〔確認: 2010年1月27日付コメント欄〕**: HONDA@東京の水が**「ちょうど訳あってつい先日、水窪川と弦巻川を再訪してきたところ」**と投稿〔本田創が2010年1月末に両川を再訪していたことを示す本人発言。BLOG-099/100（2010年2月18/19日投稿の音羽川①②）の直前の再訪に対応する可能性があるが、断定しない〕。
