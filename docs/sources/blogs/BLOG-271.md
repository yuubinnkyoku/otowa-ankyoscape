# [BLOG-271] あきぼう写真帖「山王窪の上を小金井分水が」〔repo初出・築樋の近接観察と「江戸末期建設」観察〕

## 内容〔確認: 本文全文・2026-11-22取得〕

- **書誌〔確認〕**: アメーバブログ「あきぼう写真帖」（akif4914）。2016-01-18公開。タイトル「山王窪の上を小金井分水が」（サブタイトル「公務員住宅内 窪地に湧水池 夕日に向かって」）。
- **探索の入口〔確認: 本文直接引用〕**: 「**山王稲穂神社の横で築樋の説明を読んだことから小金井分水を辿るミニ旅になりました**」＝**山王稲穂神社横の築樋説明板が探索の起点**という事実〔説明板の現地存在の傍観記録〕。
- **分水門・築樋の現況〔確認: 本文直接引用〕**:
  - 「**かつての錆付いた分水門に時の移ろいを見ましたね。玉川上水からの取水樋の痕跡が見つけられるかと、茜屋橋を渡って玉川上水の向こう側に回りましたけれど、草木に覆われていて痕跡は認められませんでした**」＝**錆ついた分水門（現地実見）・玉川上水の取水樋痕跡は草木に覆われ未発見**という観察[[BLOG-270](BLOG-270.md)の取水口〜茜屋橋〜分水起点に同じ座標系〕。
  - 「**公務員住宅の敷地内です。築樋の堤が見えます。緑色のフェンスのところに分水路があります。これだけの高さの差がある窪地、山王窪です。堤が2段になっていますね**」＝**築樋の位置が公務員住宅敷地内であること・堤2段構造という現況観察**。
- **「江戸末期の建設」観察〔確認: 本文直接引用〕**:
  - 「**現在の斜面は、建設当時からすれば何度か手が加えられていると思われますが、少なくとも当初は江戸末期の建設ということなのですから土木技術の高さは誇っていいものでしょう**」＝**「少なくとも当初は江戸末期の建設」という受け止め**。※直前の文脈は山王稲穂神社の説明板を読んだ後の筆者の解釈と思われるが、説明板の文言そのものは本記事に引用されておらず**、説明板が「江戸末期建設」と書いていたのか、筆者の読み替えかは本文からは確定できない**。
- **山王窪の湧水池推測〔観察〕**: 「**公務員住宅の敷地内を流れる仙川です。この低い山王窪の中を流れているのですがおそらくその昔は窪地に湧水の池もあったのではないかと思われます**」＝**山王窪＝かつて湧水池の窪地だったのではないかという推測〔筆者の推測と明記〕**＝[BLOG-272](BLOG-272.md)の「山王窪＝旧仙川源流の谷」という地形観察と相互に響く推測。
- **仙川の現況・築樋周辺の石造物〔確認〕**: 「**今の仙川は三面コンクリート製の河床になっているので、自然の川ではなくなっています…ここまで固めた川は、死んだ川といってもよいでしょう**」＋「**左からやってきたのが仙川で2本の木の場所で築樋の下をトンネルでくぐって向こう側に抜けているのです**」＝仙川の三面コンクリート化・トンネル潜还行のための「死んだ川」表現〔[BLOG-264](BLOG-264.md)No.2「三面コンクリート・地下水流入遮断」と同一観察の独立記録〕。「**左の小さな屋根の祠は大日尊です。手前の色の変わった舗装の部分が遊歩道北2号線で築樋があって、小金井分水の水路があるところです**」＝**大日尊祠・遊歩道北2号線の位置対応**。

## repoとの関連〔観察〕

- ①本記事の「**少なくとも当初は江戸末期の建設**」という観察は、**[BLOG-264](BLOG-264.md)（まろん通信）・[BLOG-269](BLOG-269.md)（tama-meguri）・[BLOG-270](BLOG-270.md)（tosyokan）の3系統が一致する元禄9年（1696）説との対立候補**。ただし出典（説明板の文言）が引用されていないため、①説明板が江戸末期説を掲げている②筆者が元禄9年説を「江戸末期」と解釈した③別の説明板（分水全体や仙川のもの）を読んでいる、の3通りが残る＝**建立年代の確定は説明板の文言直接確認まで断定しない**。その上で「堤が2段」・「現在の斜面は建設当時から何度か手が加えられている」という観察は、1696年原始形と現在の形の間に改変があることを前提とした読み方として対照表に整理する価値がある。②窪地の湧水池推測は[BLOG-272](BLOG-272.md)の「山王窪北西方向＝本来の源流」観察と対照する座標。

## 意義〔観察〕

- 築樋へ公務員住宅敷地内から接近した数少ない観察記録で、「堤2段」「分水門の残存」など構造細部の観察言語を残す。山王稲穂神社の説明板を起点としたブログ記事群（本記事＋[BLOG-272](BLOG-272.md)）は**説明板の文言を経由した築樋情報の二次的な流布経路**として、説明板文言の一次確認（現地）への橋渡し資料。
