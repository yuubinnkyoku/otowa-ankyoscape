# [BLOG-391] Natrium.jp「エンガ掘と周辺の水路敷群（小茂根の支流）」

- **書誌〔確認：curl本文全文・2026-11-28取得〕**：Natrium.jp エンガ掘シリーズの支流頁（repo初出URL）。写真は2017年5月28日・6月24日撮影。エンガ掘本流から小竹向原駅北側で別れた流れを環状7号線方面へ遡る。
- **小茂根の地名由来〔確認・repo初出〕**：環七を挟んだ小茂根（こもね）の地名は**「昭和40年（1965年）の住居表示実施のときに小山町、茂呂町、根ノ上町の頭文字を合成して作られた」**。**北西側の茂呂には先石器時代の、南側の根ノ上には弥生時代の遺跡がある**〔本文による説明〕〔小茂根地名の合成由来・3旧町名はrepo grep初出〕。
- **根ノ上遺跡〔観察・repo初出〕**：台橋通りを登ったところに**根ノ上遺跡**があり、**弥生時代の環濠集落が発掘された跡を復元したもの**を見た〔観察〕。
- **イチョウ並木＝開渠跡〔観察・読図・repo初出〕**：水路敷跡には「見事な街路樹の並木」。並木はイチョウとアベリア。**昭和38年（1963）空中写真（国土地理院撮影）では、ちょうど道路中央にある並木部分が開渠になっていたらしい**〔読図〕。小茂根一丁目児童遊園北側では水路敷が微妙に谷間になっている〔観察〕。
- **流路と現況〔観察〕**：小竹向原駅北方でエンガ掘本流から分岐し西進、ビルで直角に曲がり、南へ枝分かれ（上流端で終わる）、台橋通りを越え並木道としてオーケー小茂根店裏まで続き、要町通りへ向かう。**要町通りはかさ上げされており、交差点で歩道側が階段になる**〔観察〕。環七武蔵野病院前交差点側から見た要町通り（都道441号）・放射36号線の延伸状況（用地未確保・放射35号線より工事が進んでいない）〔観察〕。
- **小竹換気所と谷頭〔観察・repo初出〕**：環七側の谷頭にあたる場所に**赤レンガの西武有楽町線小竹換気所**がある〔観察〕。**小竹みどり公園あたりが水源だったのかもしれない**〔推定〕。街区案内図には矢印のところに水色で水路があったことが示されている〔観察〕。
- **さぶろく四季の道〔観察・repo初出〕**：要町通り南側に並走する遊歩道は**「さぶろく四季の道」と名付けられ、地元の方々によって整備されているらしい**〔伝聞〕。「さぶろく」は要町通りの計画道路名称である放射36号線に因むのかもしれない〔推定〕。
