# [BLOG-263] Natrium.jp「神田川周辺の水路敷群（小沢川）」〔repo初出・[BLOG-251](BLOG-251.md)（時空散歩「小沢川跡散歩」）との対照資料。第245回課題⑧の解決〕

- **書誌〔確認: 本文全文・2026-11-22取得〕**: Natrium.jp「水路敷を行く」の神田川下流カテゴリ内頁「小沢川」。写真は2022/8/14・8/21・2025/3/28・4/19撮影。
- **小沢川の記録上の位置〔確認〕**: 「**小沢川は『杉並の川と橋』（杉並区郷土博物館編、2009）に記載のある神田川の支流で、途中にある複数の湧水から水を集めて流れていた**という」〔[BLOG-251](BLOG-251.md)（約2km・真盛寺の新鏡ヶ池源流説・富士見橋脇で神田川に合流・蛇窪・清水窪＝支流の窪地名）と引用元文献を同じくする独立実走〕。「**東京メトロ丸の内線方南町支線の中野富士見町駅脇にある富士見橋**から下流方向、**小沢川の合流口（矢印）は封鎖されている**」〔合流口の現況観察＝BLOG-251の合流口観察の裏付け〕。
- **区画整理による流路付け替え〔確認・repo初出候補〕**: 中野富士見町駅そばの「**区整碑**」は「**小沢川下流の旧和田堀町字砂利田（現在の杉並区和田一丁目）を中心に行われた和田堀町第一土地区画整理組合が昭和6年（1931年）から17年（1942年）に実施した土地区画整理の完成を記念したもので、小沢川もこのときに現在の流路に付け替えられたようだ**」（参考: 「**杉並風土記 下巻（杉並郷土史叢書6）」/森泰樹, 1989**〕〔**小沢川の下流付け替え＝和田堀第一区画整理（S6-17）と同一時期という文言**＝[BLOG-261](BLOG-261.md)（善福寺川側の同区画整理・区整碑の実物観察）と対になる小沢川側の記録。「ようだ」の推定文言〕。ほか「**途中で川筋が断ち切られて神田川に向かって直線的に南下しているのがとても気になる**」「**特別区協議会所蔵の『豊多摩郡和田堀町全図』（小林又七, 1929）を見ると現在の流路から途中で分かれ現在よりもかなり西寄りを南下している**」〔[BLOG-261](BLOG-261.md)と同じ1929全図による旧流路読図〕＋「**全国Q地図に収録されている1880-86年関東地方迅速測図を見ると現在の小沢川左岸側（東）に旧神田上水に合流する小沢川の流れが見えるが、地図上の位置が正確でないため具体的な流路は特定しにくい。30m等高線よりも南側、高砂橋の北側で合流していたのかもしれない**」〔迅速測図上の旧神田上水合流部の候補文言（かもしれない）〕。「全国Q地図で色別等高線を確認してみると、**概ね標高30mの等高線を境に北側が台地、南側が低地**になっており**古くは小沢川もしくは善福寺川支流がこのあたりを東に向かって流れていたのかもしれない**」＋「**西側からは善福寺川の旧本流が流れてきて、本郷通り北側、環状七号線東側から神田川へ向かっていたように見える**」〔杉並側からみた神田川合流低地の構造文言〕。
- **湧水源群〔確認・観察〕**: ①**和田中央公園**: 「ここには**かつて湧水があり、小沢川の水源の一つ**となっていたという。公園の東寄りには**湧水を模した親水公園**が造られている」〔BLOG-251の水源説の追加〕。②**蛇窪**: 「公園を巻くように上っていく坂道の右側に、**『杉並の川と橋』では蛇窪と呼ばれている谷**が見える」＝遊歩道整備（途中に「この先行き止まり」標識・中野警察署の放置車止め・草叢）・上流端は北側の行き止まり路地。③**清水窪**: 「小沢川の北側に、『杉並区の川と橋』で**清水窪と呼ばれている窪地**が広がっている。**かつてはこのあたりにも湧水があったらしい**」〔蛇窪・清水窪の現地位置の特定観察＝BLOG-251（支流の窪地名として言及のみ）の進展〕。④**蚕糸の森公園**: 「北にある**高南中学校の脇を抜けて蚕糸（さんし）の森公園から流れてくる支流があったのではとする説がある**」〔新たな支流説。桑畑（蚕糸試験場由来）との関連可能性は未確認〕。
- **十貫坂の石塔群〔確認〕**: 「**十貫坂**に突き当たる。右（東）に曲がると十貫坂を上って鍋屋横丁へ至る」＝十貫坂の地蔵堂には「**元禄5年（1692年）造立の庚申塔や地蔵塔など6基**が納められている」〔十貫坂トンカチ坂系の地名・石塔史料。「十貫」由来の文言は本文にはない〕。
- **杉並能楽堂〔確認〕**: 「**杉並能楽堂は関東大震災後の昭和4年（1929年）に本郷弓町（現在の文京区本郷二丁目）から移転してきた**といい、**狂言大蔵流山本東次郎家が代々拠点**としているのだそうだ」〔移転史・芸能史の関連記録。地籍図上では能楽堂前から東へ水路敷が描かれる〕。**真盛寺**: 「**小沢川は真盛寺（しんせいじ）の境内にあった池から流れ出していた**という」「**真盛寺は別名を三井寺ともいい、日本橋越後屋の三井高利以来の三井家の菩提寺**であるという。**境内には新鏡ヶ池があり、そのあたりが小沢川の水源であったとされる**」〔BLOG-251の新鏡ヶ池源流説と合致。三井家菩提寺という由緒文言の追加〕。上流には用水路もあり「**西側に位置する本仏寺と妙祝寺の境内には蓋暗渠も残っているという**が私有地」。**堀ノ内斎場**南側歩道が水路敷・2020年撤去の区内最東端の金太郎など車止めの変遷観察。
- **自己訂正の記録〔確認・2025/4/19追記〕**: 「**（2025/4/19追記）地籍図を確認した結果、清水窪東側の水路敷について修正（小沢川本流の流路修正、支流の水路敷追加）を行なった**」・「2025/3/28追記：地籍図では写真右にまっすぐ進む方も水路敷として描かれている」〔**地籍図照合で流路記載を自己訂正した形跡**=地籍図照合による自己訂正を行う観察系資料としての特徴の記録〕。
