# [BLOG-307] 日本テクノ「check 防災施設」Vol.2・神田川・環状七号線地下調節池見学レポート〔消防水利としての平常貯水と取水実績の新数値群〕

- **書誌〔確認: 本文全文・2026-11-23取得〕**: 環境情報提供メディア「econews」（運営=日本テクノ株式会社）のレポートシリーズ「**check 防災施設**」Vol.2「**神田川・環状七号線地下調節池**」 https://econews.jp/report/check_bousai/18529/ 〔**投稿日: 2026.09.24 / 更新日: 2026.9.25**〕＝オープンファシリティ（インフラツアー）見学を通じた一般向け解説で、**東京都第三建設事務所 工事第二課長 岡田理志氏への実名インタビュー**を含む〔[BLOG-300](BLOG-300.md)・[BLOG-232](BLOG-232.md)に続く同施設の見学レポート系の2026年追記〕。
- **①渇水期の消防水利としての平常貯水〔repo初出の数値・直接確認〕**: 「**訪れた日は渇水期（11月から5月）だったので、トンネル本管には消防水利（災害時に活用するための水源）として約6万㎥が貯水されており、そこにドジョウやザリガニなど、取水とともに流れ込んだ生き物がたくましく生息している**」＝**①渇水期（11月〜5月）にトンネル本管へ約6万㎥を消防水利として貯水する運用、②取水とともに流れ込んだドジョウ・ザリガニの生息**〔repo初出の文言。調節池内の魚類混入は[GOV-560](../gov/GOV-560.md)（H17: コイ・カメ混入・職員がバケツで川へ放帰）の先行例〕。
- **②浸水被害の比較数値〔repo初出の数値・直接確認・岡田理志課長の述べとして〕**: 「**建設前の1993年台風11号と2004年台風22号の総雨量はほぼ同じです。ですが浸水面積は85ヘクタールから4ヘクタールに減り、浸水家屋も3117戸から46戸と、被害の軽減に大きく役立っています**」（岡田さん）＝**1993年台風11号（浸水面積85ha・浸水家屋3,117戸） vs 2004年台風22号（4ha・46戸）の同一総雨量での比較**〔[GOV-149](../gov/GOV-149.md)系の効果検証に台風単位の被害軽減比較を加える新データ点〕。
- **③取水実績の系列〔直接確認〕**: 「**1997年の利用開始から現在までの約30年間で計47回取水が行われた**。**2019年10月の台風19号では約49万立方メートル、トンネル内に最大貯留量の約9割となる洪水を受け止めた**」＝**2026年9月時点で約30年間・計47回取水**〔2005年10月まで47回の[GOV-149](../gov/GOV-149.md)記載・[BLOG-300](BLOG-300.md)の47回（2005年時点）に対し、約20年を経ても47回のまま（直近20年間の大規模取水の凝縮）という系列のアンカー。49万㎥（台風19号）は[GOV-512](../gov/GOV-512.md)の2019年実績系列と対応〕。諸元＝**環状七号線の地下34〜43メートル・延長4.5キロメートル・内径12.5メートル・約54万立方メートル**〔既知（[GOV-149](../gov/GOV-149.md)等）と一致〕。
- **④管理体制・維持管理〔repo初出の文言・直接確認〕**: **3か所の取水施設（神田川・善福寺川・妙正寺川）を統括管理する善福寺川取水施設で3河川の増水状況を遠隔監視・普段は無人・杉並区にレベル2大雨注意報が発令されると職員が24時間体制で監視・取水ゲート開閉**＝[BLOG-300](BLOG-300.md)（善福寺川取水施設の見学）の体制側の補完文言。**年1回高圧洗浄機や汚泥吸引車でトンネル内を掃除・コンクリートのひび割れを定期点検補修**＝維持管理側の記録〔repo初出〕。
- **⑤誤植の注意〔確認・原文どおり記録〕**: 本文に「**導水連絡管の大きさは内径64ｍ**」との文言があるが、**同一本文に「内径7ｍのドロップシャフト」「長さ約150mの導水連絡管」「（本管は）さらに大きく内径12.5ｍ」とあり、64ｍは明らかに不当な数値**＝誤植（「6.4ｍ」や「7ｍ」相当の取り違え候補）の可能性が高く、引用時は誤植として併記すること。
- **⑥cross-check（ENAA文書）〔観察: 別ソースの存在と数値の一致〕**: 一般財団法人エンジニアリング振興協会（enaa.or.jp）配布の2頁PDF `https://www.enaa.or.jp/?fname=sk00-1.pdf` （**調査見学時期 平成30年2月21日・施設管理者 東京都・施設所在地 東京都杉並区**・2018年頃作成とみられる施盛建設技術研究資料の断面図入り二頁）に「**平常時でも神田川の河川水を6万m3貯留しています**」の文言があり、**消防水利としての6万㎥平常貯水のH30時点側からの独立witness**となる〔PDF本文はCIDフォントで全抽出できず、検索エンジンのスニペット+テキスト層の数値（4.5km・12.5m・54m3〔総貯留54万㎥〕・6m3〔平常貯留6万㎥〕・H30.2.21等）での確認＝観察扱い。**アンダーパス・アンダーチェック系の同PDFの表題・掲載頁の特定は次回課題**〕。
- **意義〔観察〕**: ①**渇水期の消防水利としての平常貯水（約6万㎥）と生息生物の存在**は、調節池の平常時の水理的・生態的状態に関する初めての数値化された文言で、[BLOG-300](BLOG-300.md)（平常時の無水状態の記述）と対になる。②**1993 vs 2004年の浸水比較の数値**は、台風単位の定量的効果検証として[GOV-149](../gov/GOV-149.md)（2019年台風19号実績値系列）に先行する建設前後の比較データで、環七調節池の立入実績語の攻め手型の裏付けになる。③**岡田理志課長の実名**は、[BLOG-293](BLOG-293.md)・[GOV-514](../gov/GOV-514.md)系の整備現場の行政側の現在の担当者像として記録に残る〔実在の人物に付随する評価はすべて元情報どおりで、追加の解釈はしない〕。
- **制限・未解決**: ①見学レポート由来のため、数値・事実の原典（都の運用基準・効果検証資料）は未確認。②「消防水利」の法的位置づけ（水利権・消防法上の指定水利の有無）は本記事には特定なし。③「約30年間で計47回」の原文文言は「1997年の利用開始から現在まで」＝2026.9時点とみられるが、**取水回数47回には「洪水時」のみを指すか平常放流込みかの区別が原文になし**〔[GOV-149](../gov/GOV-149.md)の2005年時点値との連続性の解釈は断定しない〕。④ENAA PDF（sk00-1.pdf）の表題・シリーズ名・正式な出版年は未特定（次回課題）。
