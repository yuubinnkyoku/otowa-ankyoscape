# [BLOG-203] 長崎村分水・引水路の現況観察と「樋口（とよぐち）」地名

- **直接確認（2026-11-13、第64回・FC2直fetch）**。谷端川シリーズの千川上水引水路回。
- **引水路の現況〔観察：2018年の実地観察〕**：長崎村分水は**要町三丁目交差点（都道420号×441号）付近**から千川駅に沿って南東へ約250m進み、都道441号を逸れて分岐、次のブロックで公道を逸れて**マンション敷地内**に入る。**白い砂利に覆われ幅が半間（約0.9m）もない空間がフェンスに覆われて存在**し、この敷地を抜けると粟島神社（弁天池）に至る。**「地下に木樋を通していた」ようで、私有地だったためこのマンション敷地内のみ流路が残存しているのではないか**、と推測する〔観察＋筆者推定。引水路の地上痕跡としてrepo初出の具体観察〕。
- **「樋口（とよぐち）」地名〔確認：二次引用〕**：要町三丁目交差点・千川駅周辺は『[いたばしの河川 その変遷と人びとのくらし](../books/BOOK-031.md)』（板橋区教育委員会編）によると「**樋口（とよぐち）**」と呼ばれていた場所で、ここから長崎村分水が**樋管**によって谷端川に伝わっていたことを示す地名、と記す〔「樋口」の読み「とよぐち」・地名由来のこの文言はrepo初出候補。[BLOG-042](BLOG-042.md) の要町三丁目交差点＝長崎分水分水点の読み・[GOV-068](../gov/GOV-068.md) 分水設計思想と整合。「樋口」は用水樋口の意味で杉並区の樋口伏替願（[GOV-016](../gov/GOV-016.md)）などとは別文脈〕。
- **灌漑と暗渠化の因果〔推定：筆者考察〕**：引水により谷端川全流域の水田開発が進む一方、流量増加が大雨時の溢水・暗渠化（放水路設置）の遠因になり得ると論じる〔仮説段階〕。
- **千川上水の給水先〔確認：通説的整理〕**：小石川御殿・湯島聖堂・寛永寺・浅草寺・六義園の池への引水〔既出の通説と整合〕。
