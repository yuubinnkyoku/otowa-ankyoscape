# [BLOG-358] TEIONE「神田川（4）巻石通り」＝文京区教委旧白堀跡説明板全文

## 書誌・確認範囲

- TEIONE BLOG（[BLOG-093](BLOG-093.md)と同一ブログ・平山貞一）の「神田川（４）江戸川橋～御茶ノ水03-巻石通り」（散歩日時の本文記述=2017.5.11・投稿年は2017〔推定〕）。2026-11-27第368回に閲覧ツール経由で本文全文取得（直curlはCloudFront 403・Wayback未収蔵）。https://teione.exblog.jp/24189076/
- 江戸川橋〜御茶ノ水間（巻石通り沿い）の散歩記録で、**文京区教育委員会設置の「神田上水旧白堀跡」説明板を全文転写**する。

## 内容メモ

- **〔確認・repo初出〕文京区教委説明板の遺跡名・遺構番号**: 「**文京区小日向1・2丁目南遺跡**神田上水旧白堀跡」＝[BLOG-355](BLOG-355.md)（山の風音）の説明板転写にあった「小日向1・2丁目遺跡」に対し**「南」を含む正式遺跡名の第2転写**。また「**本調査で初めて発見された新旧2筋の白堀跡は間知石の石積み護岸で、長さは60ｍ以上確認されその一部を現地で展示しています。展示範囲は旧白堀の石積み護岸（15ｂ号遺構）をそのまま利用した新白堀の護岸（15ａ号遺構）が後に石蓋（万年巻石蓋）で覆われて暗渠化された所**」＝**①遺構番号15a（新白堀）・15b（旧白堀）の対、②「万年巻石蓋」の複合語、③現地展示範囲の構造説明、の3点がrepo初出**。〔「間知石」は[BLOG-356](../blogs/BLOG-356.md)の都水道局説明板と一致、[BLOG-355](BLOG-355.md)の「伊豆石」との表記差は対校記録（石材名と積み方の別表記の可能性・断定しない）〕。
- **〔確認・repo初出〕神田上水の終焉過程の説明板文言**: 「**東京砲兵工廠（小石川後楽園）では、東京市内への上水の供給が終了した明治34（1901）年以降も神田上水を工業用水や園内の大泉水の水源として使用していました。大正初期、石蓋で覆われた水路は鉄管の水路へ置換し姿を消します。関口大洗堰の取壊しや庭園用の深井戸設置に伴い昭和8～10（1933～1935）年頃神田上水の役割は終焉を迎えます**」＝**①明治34年以降の砲兵工廠（小石川後楽園）での工業用水・大泉水水源としての使用継続、②大正初期の鉄管置換、③関口大洗堰取壊しと庭園用深井戸設置に伴う昭和8〜10年（1933-35）頃の終焉、という下限年代と原因の公式説明がrepo初出**。〔既存の「1935年頃まで工業用水路」（都水道歴史館解説）に対し、下限を1933〜35年に絞り、大洗堰取壊し・深井戸設置という原因付けを与える。大洗堰取壊しの年次の原拠は本説明板からは確認できない〕。
- **〔確認〕旧町名案内の説明群（文京区設置）**: 小日向水道町（承応年間から神田上水定浚を命じられたので水道町と命名・明治2年知願寺等門前を併合）・水道端1・2丁目（上水堀の南北に沿った町・明治5年編成）・旧第六天前町（神田上水堀の土手の上に第六天社が祀られ、その北側の前の町）・荒木坂の規模（御府内備考引用・高さ凡五丈程約15m・巾貳間貳尺程約4m）・金富小前の神田上水路説明板（明治34年6月飲用給水停止・明治の初め暗渠化）＝**水道系町名群と神田上水の堀の土手の第六天社の位置関係が説明板レベルで確認できた**〔既収録の町名史の補強・対校〕。
- 〔確認〕小日向神社の由緒（文京区神社誌引用・天慶3年940年平貞盛勧請・氏子区域=水道1・2丁目・小日向1〜4丁目・関口1丁目）・新渡戸稲造旧居等の沿道諸記録〔四河川直接関連は薄く背景記録〕。
