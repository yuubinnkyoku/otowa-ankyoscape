# [BLOG-180] 水窪川が作った谷を巡る⑧　坂下通りから新大塚

- **直接確認（2026-11-13、open_url・本文全文）**：毎日暗活！暗渠ハンター（旧『東京Peeling！』、髙山英男）。**シリーズ最終回**。シリーズID体系が今回確定: ①=7711781・②=7711782・③=7711784・④=7711785・⑤=7711786・⑥=7711787・⑦=7711788・⑧=7711790（7711783/7711789は新着記事頁）。⑤⑥はblog.jp直もWaybackも未収蔵・遮断で**本文未取得のまま**（次回課題）。
- **君の湯裏の井戸小屋〔観察：2010年1月〕**：君の湯裏の、**本来の水窪川流路に面した駐車場**に、**手押しポンプ付き井戸の上に屋根のついた「井戸小屋」**が取り残されるように現存し、**黄金色のポンプは現役**と観察。〔BLOG-179（⑥訂正）の「君の湯裏=水窪川本流水路の読み替え」を受けた本流沿いの井戸遺構記録。ポポー広場の井戸（BLOG-108/172）とは別地点の井戸群観察として追加〕
- **ポポー公園の井戸〔観察〕**：新大塚に向かう崖下エリアの暗渠沿いに、**井戸（青いポンプ）のある「ポポー公園」**があると記録する。ポポーの木を植えた公園がコンセプト。〔第50回までにrepo未登録だった井戸観察の**2010年時点の初出記録**。BLOG-108（令和のポポー広場井戸で水汲み可）との名称差（ポポー公園／ポポー広場）は呼称の変化・別地点の可能性があり断定しない〕
- **新大塚崖下の階段住宅群〔観察〕**：新大塚駅南側の**鋭い崖**の中腹に建つ住宅は多くが「階段を上って玄関にたどり着く」形式で、階段幅を圧縮した急勾配の屋外階段が連続する。崖下に防火水槽も残存。坂下通りから新大塚駅へ向かう道自体が「もしかして…」感たっぷりの蛇行を見せる。〔水窪川右支谷の崖線（音羽崖線）下の都市形態記録〕
- **蛇行と支谷の読み〔観察〕**：君の湯裏から水窪川は蛇行して坂下通りに出て、通りの向こうに延びる細い道（歩道ライン付き・車幅なし）を**水路跡かもしれない**と記す。〔BLOG-175（①）の三角踏切・BLOG-179（⑦）の大塚坂下町公園と接続する東池袋〜新大塚間の流路観察の補完〕
