# [BLOG-283] 大貫伸樹「よみがえれ石神井川▶田無用水のはけ口は今どこに？」〔はけ口写真の特定・津島神社による流路証明・御嶽菅笠の滝描写〕

## 内容〔確認: 本文・2026-11-22取得〕

- **書誌〔確認〕**: はてなダイアリー「装丁家・大貫伸樹の装丁挿絵探検隊」（[BLOG-284](BLOG-284.md)と同一筆者）の[はけ口記事](https://shinju-oonuki.hatenadiary.org/entry/20150308)〔2015-03-08〕。石神井川に田無用水を落としていた「はけ口」（流末）付近の特定と、田無神社〜石神井川区間の消失流路の現地トレース。**田無市史（[BOOK-258](../books/BOOK-258.md)）掲載の地図を手に行った観察**で、田無市史を流域観察の座標に使った実例。
- **はけ口写真の特定〔確認: 本文直接引用〕**: 「**田無用水が石神井川に落とされる場所「はけ口」を昭和中頃に撮影したと思われる写真❶を見つけた。…この写真がどこなのかわかる人は少ないだろう。田無用水が田無神社まで来ていることは知っているが、下流の最近のルートの記述は見たことがない。田無神社と石神井川の間を流れていた流路跡を探すことができれば、写真の場所は特定できるはず**」＋「**手前に石神井川があり、遠景の堤には西武新宿線が走っているので、南町の辺りであることは察しが付く。田無市史に掲載されていた地図（右下）を手に、石神井川の田無用水はけ口があったと思われる南町調整池辺り❷から、田無神社までの消えてしまった流水経路をさがしてみた**」＋「**❷、ここが❶と同じ場所だと思われるが、石神井川の護岸工事が行われ、かつての畑は調整池となり、田無用水もはけ口もなくなってしまった**」＝**昭和中頃のはけ口写真＝南町調整池辺りの特定（護岸工事で畑→調整池化）**〔確認・筆者比定〕。「**❶…土手の下に白く見えるのは水路のためのトンネルか？**」＝**はけ口写真に写るトンネル状構造の観察**。
- **西武新宿線下のトンネル〔確認: 本文直接引用〕**: 「**西武線新宿線の下をくぐるトンネル。地図の位置から判断すると、このトンネルを田無用水がくぐっていたものと思われる**」＝**西武新宿線の盛土下をくぐるトンネル＝田無用水の伏所（伏越）の現存遺構**〔筆者推定〕 = [BLOG-281](BLOG-281.md)（北水路のガード下通過・「トラ柄模様の部分」）・[BLOG-282](BLOG-282.md)（調節池部分を通って石神井川へ）と相互一致＝**田無用水北水路の西武新宿線横断方式は3観察系統で一致**。
- **津島神社による流路証明〔確認〕**: 「**路地の入り口辺りからは覗いても見えない小さな神社・津島神社。古い地図にあるこの神社が見つかり、この路地が田無用水の流路で間違いないことを証明してくれる**」＝**津島神社（路地裏の小社）をランドマークにした流路の再現方法**。＝流路復元に神社・小社の位置照合を使う手法の記録（谷端川・弦巻川研究の橋・寺社照合手法と同型）。「**丸石積みの石垣は田無用水のなごりか？**」〔筆者推定〕。
- **滝と「御嶽菅笠」〔確認: 本文直接引用〕**: 「**この先（下流）には、かつて、田無用水の滝があったようだがマンションになって、場所を確認することは出来なくなってしまった**」＝**路地裏下流側（津島神社界隈の下流）の滝跡がマンション化で位置確認不能という観察**。＋「**田無用水の滝が描かれている「御嶽菅笠」1834（天保5）年。○の右が青梅街道と所沢街道が分かれる所・田無追い分**」＝**御嶽菅笠（天保5年〔1834〕刊の御嶽神社参詣案内記）の図中に田無用水の滝が描かれているという文言・田無追い分（青梅街道と所沢街道の分岐点）との位置的関係の指摘**〔確認・repoの御獄菅笠登録（[BLOG-094](BLOG-094.md)千川上水の水道端の図）に続く**田無側の図版言及でrepo初出**〕。
  - **対照**: [BLOG-281](BLOG-281.md)（musasinowalker・田無神社先の高台部で「江戸時代頃は滝になっていた」伝聞）との関係（同一滝か・田無神社側と津島神社側の別滝か）は**位置関係が異なるため断定せず対照候補として並置**。
- **田無神社側の遺構〔確認〕**: 「**路地裏を田無神社に続く用水路**」「**田無神社境内にある石橋**」「**田無神社境内にある田無用水の立て札と、水神宮**」＝**田無神社境内の石橋・立て札・水神宮の存在**（石橋= [BLOG-281](BLOG-281.md)・[BLOG-282](BLOG-282.md)と一致。水神宮はrepo初出候補）。
- **引用史料〔確認: 本文中の引用表記〕**: 「**「青梅街道沿いの町並み図」部分（田無中央図書館編『田無の昔話その3』昭和54年より。この地図には、まだ西武新宿線やその奥にある民家はない**」＝**田無中央図書館編『田無の昔話 その3』（昭和54年〔1979〕）掲載の「青梅街道沿いの町並み図」＝西武新宿線開通前の田無の町並み地図の存在**〔引用書誌として記録＝[BOOK-259](../books/BOOK-259.md)〕。

## repoとの関連〔観察〕

- ①**田無市史を使った流路復元の一例**: 本記事は田無市史掲載の地図を野外での流路照合に使用しており、[BOOK-258](../books/BOOK-258.md)（田無市史・ADEAC）の実用性を示す観察記録。水車・ドンドン川に関する本格的な田無市史引用は[BLOG-284](BLOG-284.md)（2018）が担う。
- ②**滝の証拠の系統化**: 田無用水の滝について「江戸時代頃といわれる高台の滝（BLOG-281）」・「御嶽菅笠1834年の滝描写＋路地裏下流側の滝跡（本記事）」という観察・図画系の言及が揃った。江戸期の用水の滝を描いた絵画史料（御嶽菅笠）は千川上水側の水道端の図（[BLOG-094](BLOG-094.md)）と同じ史料の別地域描出で、同書の田無方面図版は原典確認課題。
- ③**南町調整池のはけ口特定**: 石神井川の護岸工事で「かつての畑は調整池」という変遷文言は、石神井川の改修史（[BLOG-281](BLOG-281.md)の「昭和後期に改修されるまでは石神井川はもっと北側」）と断面で整合する。流末区域の土地利用変化（畑→調整池）の記録。

## 意義〔観察〕

- 田無用水の流末（はけ口）の位置とその消滅過程（護岸工事・調整池化・マンション化）を昭和写真の比定という形で記録した初の資料。トンネル・津島神社・丸石積み石垣・水神宮という**遺構・ランドマーク群の実物観察**は、地図・絵図だけでは確認できない流路の末端側の位置情報を与える。
