# [BLOG-179] 暗渠ハンター「水窪川が作った谷を巡る③④⑦」

- **直接確認（2026-11-13、第50回）**：連載3回分の本文全文をblog.jp直で取得（③=7711784・④=7711785・⑦=7711788）。**第49回が「直・Waybackとも遮断」とした⑦を初取得し、cocolog版③（Access Denied）もblog.jp版で初取得**。
- **③水窪川の碑の2010年時点観察〔観察〕**：碑は**富士山モチーフの辻広場の奥、草に埋もれた小さな碑**。「1986」銘の直接確認〔BLOG-110・128・171の碑文言・1986年銘と一致。**BLOG-173（水徒然2013）がタイル流路意匠のrepo初出候補としていた観察の3年前の観察記録であることを確認**〕。碑を源に**広場内を巡るタイル流路模型が対角線の角まで続き、排水口もある**という構造記録〔雨時に実際の水流が生じうる施設構造の記録〕。碑の「ここ」と商店街流路推定との直線距離約20mの乖離の指摘。
- **④布暗渠〔観察・repo初出〕**：坂下通り沿いに**上に布が敷かれた「布暗渠」**が現れ、**途中で普通の被コンクリ暗渠に変わる**という遷移の観察〔水窪川支流路地群の材質記録として新規〕。付近で下水道のメンテナンス工事中に下水道パーツを積んだ軽トラに遭遇（2010年時点の下水道整備の現場記録）。**「トラバー点」測量標識**の観察〔水路と直接関係ないが、坂下通りの測量基準点の存在記録〕。
- **⑦星降る広場の施工詳細〔観察・repo初出〕**：星降る広場（BLOG-110既出）の**コンクリート地面に星座が描かれ、小屋の屋根付近に大型的スポットライトが備えられ、夜間は光る仕掛け**であることを観察〔辻広場のテーマ施工の具体構造として新規〕。広場横に**緩い下り坂の元水路らしき道**、付近に埋立跡らしい「モダンアートみたいな」区画。
- **⑦君の湯と水窪川本流水路〔観察〕**：坂下通り沿いの銭湯**「君の湯」の裏手（大塚坂下町公園との間）の怪しい道が、⑥で訂正したとおり「たぶん水窪川の水路」**〔②商店街非流路の訂正を受けて、水窪川本流の流路候補が坂下通り南側の銭湯裏に再配置されるという**流路読み替えの記録**。⑥本文（7711787）は本回遮断で未確認のため、訂正の全容は断定しない〕。
- **⑦大塚坂下町公園〔観察・repo初出候補〕**：水窪川際の急斜面に「公園テクスチャ」を貼り付けたような構造で、**出入口は崖下1か所・崖上2か所だが崖上の2か所は施錠された扉で出入り不能**という不可思議な公園の観察〔BLOG-107・172の大塚坂下町公園言及に構造の具体記録を追加〕。
- **意義**：2010年時点の水窪川下流部（東池袋5丁目〜大塚坂下町）の路地・辻広場・銭湯・公園の観察を、BLOG-110（2015 eno）・BLOG-173（2013 水徒然）より前の時点で記録したことで、**碑・タイル流路・辻広場群の観察時系列が2010→2013→2015→2022（BLOG-110系）と4時点揃った**。
- **注意**：⑤「階段暗渠の美しさ」（7711786）・⑥「もしかしてこれがホントの流路？」（7711787）は本回遮断（IDは特定済み）。⑧のIDは未特定。布暗渠の水路同定（本流か支流か）は筆者観察時点では未確定。
