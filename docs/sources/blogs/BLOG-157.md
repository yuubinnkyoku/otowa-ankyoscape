# [BLOG-157] 谷端川支流（わんじん「水の行方を追って」entry-243・2018-05-02）

- **直接確認（2026-11-13、Wayback id_付きURLで本文全文取得）**：[Wayback保存版 2026-10-25](https://web.archive.org/web/20261025000000/http://wanjin.blog.fc2.com/blog-entry-243.html)。第37〜38回で取得したentry-247〜250シリーズ（谷端川支流・中丸川・千川上水・出端川）の前段にあたる支流紹介回。2018-05-02投稿。entry-241/242/244/245/251/252はWayback未収蔵のまま。
- **谷端川の支流2本（いずれも仮称・筆者の観察）**：
  - **長崎支流（仮）**：**水源は豊島区立長崎公園**（もともと学習院大学の職員用住宅地であったところ〔公園の旧用途はrepo初出〕）。公園内から水路敷が始まり、2ブロック進んだところで左折して道路に移り、すぐ右に曲がり、再び水路敷に戻る変化に富んだ流れ。**谷端川との合流地点は四辻のすべての角にミラーが立っている交差点**〔合流位置の目印の具体化〕。
  - **椎名町支流（仮）**：**トキワ荘にちなんだ「トキワ荘通り」から始まる**。手塚治虫・赤塚不二夫らが住んだトキワ荘（豊島区南長崎）のアパートに由来する通称。始まりは人ひとりやっと通れる狭小な水路敷で、私道っぽい道を抜けて再び水路敷へ。**この水路敷の近くでかつての井戸を発見（「きっと昔は良質な湧水が期待できた場所」）**〔井戸跡の実見〕。100m足らずで左（北）に折れ、西武池袋線の踏切に至り、この近辺で東に進路を変え**現在の椎名町駅の方向に進み、椎名町駅の西側の踏切近辺で谷端川と合流**〔合流位置の具体化。源流部近くには南長崎花咲公園とトキワ荘の記念碑〕。
- **意義〔観察〕**：谷端川右岸支流のうち、長崎公園水源・トキワ荘通り起点の2本について独立の実地観察記録。BLOG-139（境井田支流〔仮〕）・BLOG-061/126（瓢箪池・エンガ堀支流）とあわせ、谷端川支流の水路敷観察群を充実させる。支流名はいずれも筆者の仮称であり、地元呼称・史料上の名称の確認が課題。
- **周辺記録**：つのだじろうのトキワ荘時代の逸話（巻紙の抗議文・極真会館逃亡）〔川直接関係なし、トキワ荘通り＝支流起点の文脈のみ記録〕。
- **制限〔未解決〕**：両支流の江戸期〜昭和期の実在と流路の地図照合。長崎公園の学習院大学職員住宅地の根拠。井戸跡の現況。
