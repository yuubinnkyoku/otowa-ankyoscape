# [BLOG-284] 大貫伸樹「しん散歩（11）…田無用水、立川街道芝久保3丁目」〔『田無市史』の田無用水・水車記述の引用文言群＝repoの田無用水研究の引用史料特定〕

## 内容〔確認: 本文・2026-11-22取得〕

- **書誌〔確認〕**: はてなダイアリー「装丁家・大貫伸樹の装丁挿絵探検隊」（[BLOG-283](BLOG-283.md)と同一筆者）の[しん散歩（11）](https://shinju-oonuki.hatenadiary.org/entry/20180921)〔2018-09-21〕。昭和43年（1968）撮影の田無用水（立川街道芝久保3丁目）写真と2018年9月15日の同地点の比較から始まり、**田無市史（第3巻通史編・第4巻民俗編）の本文を多数引用しつつ芝久保用水の分水口・水車・土盛（ドアゲ）を考証する記事**。地元研究者（滝島俊・松崎博）のFBコメントによる相互検証を含む本格的な田無水路研究の記録で、**『田無市史』が田無用水研究の引用元史料として機能していることを示す記事**＝[BOOK-258](../books/BOOK-258.md)（ADEAC掲載）に接続する。
- **田無用水の規模と起点〔確認: 本文（田無市史の内容を要約した本文文言）〕**: 「**田無用水は、東京都小平市と西東京市を流れていた全長約5.6kmの用水路で、江戸時代前期に田無村の飲み水として玉川上水から分水してつくられました**」＋「**田無用水開削の嘆願書が提出されて許可が下りたのは元禄９年（1696）のことでした。田無用水は当初、田無村一村のための吞用水として二里半ほどの用水路が開削されました。喜平橋下流で玉川上水から分水されましたが、その樋口は四寸四方と他の用水に比べて小さいものでした。（ちなみに野火止用水は六尺×２尺、小川用水は一尺四方。）**」＝**①全長約5.6km〔= [BLOG-282](BLOG-282.md)（miwa3k「約6km」）と概ね一致する数字〕・②元禄9年（1696）嘆願書→許可・③当初田無村一村の吞用水・二里半（約10km）の開削４喜平橋下流分水・⑤樋口四寸四方＋他用水との対比（野火止六尺×2尺・小川一尺四方）**〔確認〕。「**その後幕末から明治にかけて、吞用水だけではなく、廻田新田や田無村の田用水としても利用されることとなりました**」＝**幕末〜明治の田用水化**。
  - **対照**: 樋口寸法の対比（四寸四方〔約12cm〕＝小規模）は、[BOOK-234](../books/BOOK-234.md)（小川用水樋口一尺四方・1656年九郎兵衛）・まろん通信の八尺四方（[BLOG-270](BLOG-270.md)）・山王窪築樋の全長56間・高さ1丈8尺（第259回）というrepoの樋寸法系列に**「四寸四方」という最小値のデータ点を追加する**。[BLOG-281](BLOG-281.md)（musasinowalker）は樋口寸法に言及せず、開削当初の取水規模の小ささは本記事からの記録。
- **明治期の水車場〔確認: 本文直接引用（『田無市史第四巻民俗編』からの引用部）〕**: 「**明治期には田無に七カ所の水車場があったが、その中でもっとも規模の大きな水車場を持っていた本町（旧下宿）の下田富宅家の水車…。同家の水車場は明治末には六三個ものつき臼があり、挽き臼は一個でつくのを専門に行っていた。この他の水車場では芝久保の高橋徳太郎家のものが明治中頃の一時期に、四六個つきの臼を持つ規模を持ち、また屋号ヤマジョウ（下田太郎右衛門家）といわれた家は、つき臼一六個、挽き臼六個で、いずれも水車家業を営んでいた。…南芝久保の中村家の東側の角にも水車があった…ここの水車は用水の下流にあり、10軒内外の家がこの水車を使って麦や粟などの雑穀をついていた。夜中に雑穀を入れておくと朝にはつきあがっていた。用水はこの水車場から急斜面の坂道沿いに南下して、石神井川沿いの田（現在の養護学校辺り）に流れ込んだ。この用水の流れる音はドンドンと周辺に響き、周辺の人はこの用水を通称ドンドン川と呼んでいた。**」＝**①明治期の田無七か所の水車場と主要三家（下田富宅家=つき63個・高橋徳太郎家〔芝久保〕=46臼・ヤマジョウ=下田太郎右衛門家=つき16+挽6）・②南芝久保中村家の共同水車（10軒内外・雑穀づき）とそこから南へ下る枝用水（現養護学校辺りの石神井川沿いの田へ流れ込む）・③枝用水の通称「ドンドン川」**〔確認・引用文言〕。
- **穴水車と体内ボリ〔確認: 本文直接引用（同書民俗編からの引用部）〕**: 「**田無の水車は一カ所を除いて用水にかけられた水車であった。それらはいずれも何メートルか地下に掘り下げてその落差を利用して水車を回した。半地下式の穴水車といわれるもので、それから排された水は、暗渠を通って表水路に流れ込んだ。暗渠は体内ボリといわれ、何メートルかおきに地表に息抜きの縦穴を掘っていた。その深さは場所によってはほとの高さほどもあり、川さらいの時にはこの縦穴から入って石ころなどを拾った**」＝**①半地下式「穴水車」（落差利用のための掘り下げ）・②排水暗渠の民俗語彙「体内ボリ（ないぼり）」・③「息抜きの縦穴」（数メートルおき・深さは場所により成人身長ほど〔原文ママ・「ほとの高さ」は「人（ひと）の高さ」の誤植候補〕）＝川さらい（清掃）の出入口**〔確認・引用文言。「穴水車」「体内ボリ」「息抜きの縦穴」はいずれもrepo初出の語彙〕。「川さらい」は[BOOK-235](../books/BOOK-235.md)（小平市史・境水衛所の「沼ざらい」）の浚渫語彙群と対照可能な民俗語彙（ADEACの民俗編目次〔[BOOK-258](../books/BOOK-258.md)〕でも独立見出し）。
- **石神井川の水車〔確認: 本文〕**: 「**雨が降った時くらいしか流れない石神井川にも水車があったんですね…。この水車は、現在は向台公園になっているところに住んでいた小山平太郎家によって、明治36年に設置届が出され…、水車講を構成し、21株・33軒の家が利用していました。しかし、4年後には廃止届が出されたようです**」＝**石神井川本流の水車（小山平太郎家・明治36年〔1903〕設置届・水車講21株33軒・明治40年〔1907〕ごろ廃止届）**〔確認・石神井川の水車事例としてrepo初出候補〕。水量不安定が廃止理由かの筆者推察つき。
- **芝久保用水の分水口・クランク〔確認: 本文＋滝島俊FBコメント〕**: 昭和43年（1968）写真と昭和62年（1987）住宅地図・実地観察から、「**コの字に曲がっていたところ**」（芝久保3丁目・畑と50m歩道で同定）を特定。別の地図では「コの字」カーブなしで芝久保用水の分水口になっているという地図間の相違を記録。滝島俊のFBコメント＝「**分水口と思われる南側に歩道がある地点（A）の標高は66.1m…みたけ分社通りの交差点（B）の標高は65.5m。約75mで60cmを直線的に下ります。一方、芝久保用水の（C）地点は65.9m、（D）地点は65.8mです。つまり、立川街道とみたけ分社通りの交差点から南下する道は登坂なので、芝久保用水としては、その前に流路を作る必要があったわけです。…もしかしたら芝久保用水を作る時（明治4年：1871年）に、（D）地点から（B）地点に戻す水路を作ったかも知れませんね。（B）−（D）間のみたけ分社通りの東側にはそれらしき歩道が存在していますので。**」＝**①標高値（A=66.1m・B=65.5m・C=65.9m・D=65.8m）を使った分水口位置の水利地理学的考察・②芝久保用水の開削を明治4年＝1871年とする説〔滝島俊〕**〔確認・コメント文言〕= 芝久保用水=田無用水系の分水（[BLOG-281](BLOG-281.md)〔2〕の芝久保用水分水観察）と対照。**「コの字」迂回の理由（分水口南側の登坂回避）という標高ベースの説明は、musasinowalkerの「水車引き込み水路」説と並ぶ第2仮説**（両説の最終判定はしない）。
- **ドアゲ（土盛）写真の再特定〔確認: 本文＋滝島俊・FBコメント群〕**: 「**昭和35（1960）年頃の芝久保町を流れる田無用水。流れの両脇に盛り上げられた土は、滝島さんのおっしゃっていた「土揚げ；ドアゲ」による堤？ってこれですね**」。滝島俊の再検証＝「**この場所は小平市との市境で、用水の右側は現在花小金井小学校があるところです。すなわちこの大きな土手は、市史に書かれている道路より高い所を流すために土盛りした土手で、明治初期の地図にも記載されている所ですね。証拠になったのは、左側に写っている「ちば」という名前のお店とその隣の酒屋です**」＝**①『田無市史第3巻通史編』の写真説明「土を盛り上げた田無用水路（芝久保町 1960年代）」の具体位置＝小平市との市境・花小金井小学校前・「ちば」（中華）・「くるみや酒店」の看板照合・②土盛（ドアゲ）＝道路より高い所を流すための土手で明治初期の地図にも記載・③撮影は1965〜66年頃との推定**〔確認・コメント文言〕。** musasinowalker〔BLOG-281〕「昔は橋場手前の窪地も堤で越えて…」・「大沼田用水が堤を使って窪地を超えている」という堤越え観察と同一の構造で、写真・地図・標高の3方面から特定された事例**。
- **田無図書館所蔵パネル82番〔確認: 本文＋松崎博・滝島俊FBコメント〕**: 松崎博「**大貫さんが撮影された上の写真の鳥居と稲荷を線路の南側の踏み切りあたりから撮影したのがこの写真（田無図書館所蔵パネル８２番）のようです**」・滝島俊「**その通りですね。府中道の踏切から撮影されてます。芝久保用水もちゃんと写ってますね**」＝**田無図書館所蔵の古写真パネル（82番・昭和35年〔1960〕撮影・府中道と西武新宿線の踏切）の存在と、市民研究での活用実態**〔確認〕= **田無図書館のパネルコレクションという未登録の資料群の存在示唆〔探索課題〕**。
- **水車の位置〔確認: 本文〕**: 「**立川街道芝久保町2丁目の芝久保用水取水口には水車があったようです（地図④）。このクランクカーブは水車場だったんですね。芝久保用水下流にももう一台水車があったみたいです。2つめは、向南中央通りと市役所通りの交差点のあたりです**」〔「地図は『田無市史第3巻民俗編』より転載」※引用巻名は原文ママ。ADEACの目録では第3巻=通史編・第4巻=民俗編で、本引用の「第3巻民俗編」は巻名混同の可能性＝原典照合課題〕。

## repoとの関連〔観察〕

- ①**『田無市史』の特定が本回最大の成果**: 本記事が引用する「樋口四寸四方」「七か所の水車場」「穴水車・体内ボリ・息抜きの縦穴」「ドンドン川」等の文言の出典が『田無市史』（第3巻通史編・第4巻民俗編）で、そのADEAC掲載（[BOOK-258](../books/BOOK-258.md)）を確認したことで、**引用元を原典照合可能な状態に置けた**。民俗編第八章第四節「田無の用水と井戸」の見出し構成（井戸・井戸替え・カワダナ・川さらい・水車）もADEAC目次で直接確認済み。
- ②**語彙の寄与**: 「穴水車」「体内ボリ」「息抜きの縦穴」「ドアゲ（土揚げ）」「水車講」はrepoの水車・水路語彙群（[BOOK-235](../books/BOOK-235.md)沼ざらい・[BLOG-270](BLOG-270.md)八尺四方・山王窪築樋の樋寸法系列）への追加点。特に「体内ボリ」（水車排水の伏渠）は、暗渠研究（谷端川・弦巻川・千川の樋・伏越構造）に対応する**用水側の地下構造の民俗語彙**。
- ③**樋口寸法の系譜**: 四寸四方（田無用水）＜一尺四方（小川用水）＜六尺×2尺（野火止用水）＜八尺四方（まろん通信・樋口）という大小関係のデータ系列が成立。田無用水の「飲み水専用・小規模取水」→明治の拡張（[BLOG-281](BLOG-281.md)の最大10倍拡幅）という規模変遷の始点を取水側から裏付ける。
- ④**市民研究・SNS検証の記録**: 滝島俊・松崎博のFBコメントによる写真比定・標高考察の過程は、地元研究者の検証プラクティスの記録で、今後の田無系資料（田無図書館パネル・田無市史図版）の原典探査の重要な手がかり。

## 意義〔観察〕

- 田無用水研究の中核文献（田無市史）の引用文言を、水車・語彙・寸法・写真考証の多方面から記録した資料。本記事のおかげで、田無市域の水路・水車研究は「観察系ブログ」から「自治体史の原典に接続した研究」に進む足場ができた（ADEAC本文照合が次の一手）。

## 制限・未解決

- ①田無市史の引用文言はあくまでブログ経由の二次引用で、原文（巻・頁・表記）はADEAC画像での照合が必要。特に「田無市史第3巻民俗編」という引用巻名はADEAC目録（第3巻=通史編・第4巻=民俗編）と整合しないため要照合。②「ほとの高さほどもあり」は原文の誤植・ブログ転記ミスの可能性（「人の高さ」候補）。③標高値（66.1m等）は滝島俊の測定・出典はFBコメントで再現性は未確認。④ドンドン川の正確な流路（南芝久保中村家〜養護学校辺り）は本文地図（未取得）で、位置比定は概略のみ。⑤パネル82番の続く田無図書館パネルコレクションの全容は未調査。⑥oomukiの「昭和43年撮影写真」「昭和62年住宅地図」の原本は未確認。
