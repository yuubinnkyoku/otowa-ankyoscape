# [BLOG-122] わんじん 谷端川南緑道と池袋耕地整理（東橋〜前田上の橋）

- **直接確認（2026-11-12、Wayback Machine 2026-10-25スナップショットで本文全文取得）**: FC2の直アクセスは遮断されるが、本エントリはWaybackに収蔵されていた（entry-240/241は未収蔵のまま継続）。谷端川南緑道を東橋から高松橋・境橋・上ノ橋・中上橋・御嶽橋・南橋・境井田橋・他領橋・熊野橋・前田上の橋（国道254号）まで辿る記事。
- **池袋耕地整理の年次細分〔確認：本文記述〕**: 対象地区は「西巣鴨町大字池袋字本村、他領、上、丸山、各一部境井田、前田及び飛地他領、境向、中原と、板橋町大字中丸字川原、前及び飛地沼田、中原の各一部」**618反余り**。**1920年（大正9年）内に谷端川流域の工事が竣功し、事業全体は1923年（大正12年）に完了**。同年に耕地整理組合が設立された長崎村など近隣に比べ一足早く、周辺地域の耕地整理の先駆けだったと記す。〔本文は出典を明示しない二次記述。README既述の『豊島区史 資料編 四』由来「618反余（うち田128反余）」と面積が一致する独立ソースで、**1923年全体完了と対象字名の構成はrepo初出**〕
- **橋名の字名・由来の対応〔確認：本文記述〕**: 中上橋は「上は西巣鴨町の字名です」とあり中上＝西巣鴨町字名の対応候補（文言がやや曖昧なため断定しない）。南橋＝板橋町中丸の字名「南」、境井田橋・他領橋・前田上の橋＝西巣鴨町池袋の字名、御嶽橋＝池袋御嶽神社（池袋駅西口側の鎮守）由来、熊野橋＝板橋側中丸の熊野神社由来。〔橋名自体は [BLOG-069](BLOG-069.md)・[BLOG-081](BLOG-081.md)・[BLOG-084](BLOG-084.md) 等で既出。由来対応の独立二次ソースとして記録〕
- **支流2本の合流位置〔観察〕**: 境橋から再び北上して100m以内に、板橋区立高松小学校の方から流れてくる支流が合流（上ノ橋付近）。中上橋の先の右岸に、豊島区池袋二丁目と三丁目の境付近から流れる支流が合流。〔南緑道沿いの2支流の位置の具体化。谷端川ノートの支流候補記録との照合課題〕
- **耕地整理と橋・用水路〔観察〕**: 今回紹介した橋の多くは耕地整理時に竣工した橋。耕地整理で設けられた用水路がかなりの頻度で路地に変わっており、「細い路地を見るとどれも用水路跡に思えてしまう」と記す。〔1920年前後の支水路再編の痕跡観察として README の池袋耕地整理組合の記述と整合〕
