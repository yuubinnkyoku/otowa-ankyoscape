# [BLOG-038] 城所信英「光と風を失った谷端川」

- **直接確認（2026-11-11、open_url）**：大塚の地域史家（都立高校教諭・大塚地域史研究）による谷端川論。**明治22年（1889）の町村制施行時、長崎町・西巣鴨町・巣鴨町・高田町（現豊島区の母体4町）の境界線として谷端川が流れていた**ことが、町村制当時の地図で確認できるとする。
- **瀧不動〔確認：記事の叙述〕**：**大塚駅北口・都電線路に沿ったビルの片隅に「瀧不動」が今も祀られており、ここに谷端川が流れ、堰のような小さな滝もあったと推定される**という。水を大切にした名残の祠として紹介。瀧不動の所在はrepo未収録（search_code確認済み）。
- **藤橋〔観察：記事による位置の具体化〕**：**折戸通り（江戸期から「王子道」と呼ばれた道筋。煉瓦ガードで山手線をくぐり、巣鴨庚申塚で中山道と交わる）にかかる橋が「藤橋」だった**とし、現在は広い交差点になっていて橋があったことはほとんど知られていないと説明。※[MAP-016](../maps/MAP-016.md)の「谷端川と藤橋が描かれるとする二次読図（△・高精細原図で再確認待ち）」を**独立の二次叙述が位置（折戸通り・王子道の交差点）つきで�付ける**。ただし本記事も二次叙述であり、原図の再確認をもって確定としない。
- **暗渠化着手〔既知〕**：昭和7年・東京市豊島区誕生とともに市が暗渠化工事に着手、の叙述は[2026-10-25・新史料追加調査.md](../../2026-10-25・新史料追加調査.md)に「行政原史料の確認要」として既記載。重複加算しない。
- **その他〔観察〕**：豊島区の地形が谷端川・弦巻川・水窪川の3河川で造形された、豊島区四か町の成り立ちと3川の関係（長崎町・西巣鴨町・巣鴨町=谷端川、高田町=弦巻川が造った「雑司が谷」）の整理。谷端川が明治36年の大塚駅開業後、農業用水から工業用水へ役割を変えたという指摘。劇団ムジカフォンテ「あの川、そこの川」への言及も既知（2026-10-25ノート）。
