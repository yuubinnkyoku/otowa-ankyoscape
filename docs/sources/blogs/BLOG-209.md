# [BLOG-209] 下り谷・雲雀が谷戸支流の踏査と上池袋支流の源流読図

- **直接確認（2026-11-13、第64回・FC2直fetch）**：entry-251（2018-06-27）・252（2018-07-04）・253（2018-07-11）。URLは代表してentry-251を掲げる（252=https://wanjin.blog.fc2.com/blog-entry-252.html、253=https://wanjin.blog.fc2.com/blog-entry-253.html）。
- **下り谷・雲雀が谷戸支流〔観察：2018年〕**：**東池袋二丁目から始まる支流**（古い地名だと「下り谷（さがりだに）」）。**池袋の六つ又交差点あたり**から始まり、下流は「雲雀が谷戸」と呼ばれる地区を流れ、かつての**新田堀之内村**にあった複数の流れのうち代表的な二条を地図に記す〔BLOG-054/065/066の雲雀ヶ谷戸・下り谷の字界記録と照合する独立踏査。池袋運輸区の**留置線**に至る左右分岐ルートと、留置線を越えた先の谷端川合流までをたどる（entry-252）〕。
- **新田堀之内村の由来〔確認：本文主張〕**：新田堀之内村は**王子の梶原堀之内村より分郷**した土地。「堀之内」とは中世の武士・領主の館の範囲を示す語で、**足利時代末期に梶原政景氏が構えた屋敷**の場所に由来する「梶原堀之内」の分郷で、池袋村と巣鴨村に挟まれた狭い地域に支流を用水路として新田が開発されたものと思われる、と説明〔新田堀之内村＝梶原堀之内分郷説のrepo初出候補。BLOG-127の堀留地名由来の記録と接続。その後「堀之内」の字となり、現在は橋や踏切に名が残る〕。
- **上池袋支流〔観察：2018年〕**（entry-253）：**上池袋と北大塚の境目近辺**から始まる流れを「上池袋支流（仮）」と名付け、**源流部は山手線の際で西巣鴨橋のすぐ北側**。明治通り手前で右折して東へ、明治通りと並行し上池袋二丁目交差点付近で公道へ、右岸に**豊島区立上池袋中央公園**（園内に**井戸用の手押しポンプ**がある）、**西巣鴨一丁目で谷端川右岸に合流**〔既収録の上池袋支流（D.2.C・横山恵美紀要11号経由）の流路読図の補強。西巣鴨橋北側＝山手線際の源流域の具体観察はrepo初出候補〕。
