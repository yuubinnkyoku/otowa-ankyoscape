# [BLOG-078] 簸川坂（小石川）

- **直接確認（2026-11-11、Wayback Machine [2025-02-10 snapshot](https://web.archive.org/web/20250210041913/http://nakano3bono.cocolog-nifty.com/blog/2017/11/post-3a2b.html)）**：直接アクセスは不可（Access Denied）だったためアーカイブ本文で確認した。坂道探訪シリーズ（2017年11月20日投稿）。
- **簸川坂解説板の内容〔確認：文京区教育委員会「郷土愛をはぐくむ文化財」掲示物の読み下し〕**：坂下一帯は**明治末頃まで「氷川田んぼ」といわれ、千川（小石川）が流れていた。洪水が多く、昭和9年（1934）暗渠が完成し、「千川通り」となった。神社石段下には千川改修記念碑がある**。〔「氷川田んぼ」呼称はrepo初出（[BLOG-077](BLOG-077.md)の「氷川たんぼ」と同区域の俗称）。千川下流の1934年暗渠化を3つ目の独立資料で再裏付け〕
- **祇園橋〔確認：江戸切絵図の読み〕**：**江戸切絵図には湯立坂から下ると千川に祇園橋が架かっていて、それを渡ると簸川（氷川）神社の参道になる。境内には宗慶寺別当とある**。〔**小石川（千川）に架かる江戸期の橋名「祇園橋」はrepo初出**。[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)への追加候補〕
- **周辺の土地利用〔確認・推定混在〕**：簸川神社は元禄2年（1699）に白山御殿造営のため現在地へ移転（※[ovan](https://ovanrei.hatenablog.com/entry/2023/12/17/213000)等は元禄12年とする。解説板・記事で年次表記に差があり、移転年は史料確認待ち）。大正期以降、坂下は田んぼ埋め立て後の中小工場が集まる町となり、太田胃散本社が残る。坂上の林町小学校は林大学頭（林鳳谷）の下屋敷跡の地名「林町」の名残。〔小石川下流低地の土地利用変化（たんぼ→工場→住宅）の傍証〕
