# [BLOG-120] 地図子「水窪川を歩く」（2019年12月14日）

- **資料〔確認〕**：はてなブログ「ふと思い立って、プチ冒険」（地図子）。**2019年12月14日・本田創氏のNHK文化センター「暗渠さんぽ 失われた川を歩く」講座（水窪川）のフィールドワーク記録**。**当該頁は第15回以来アクセス不能と記録されていたが、Wayback Machine（2023年スナップショット）で本文取得に成功**した。既存のリサーチノート（水窪川湧水の変化検討）で参照していたバケツ湧水写真（2019年12月14日）の出典頁の正式な資料化でもある。
- **水窪川の性格付け〔確認〕**：「**1933年と戦前に埋め立てられた川**であるということ」「緑道が一つもない」。※**水窪川暗渠化「昭和8年（1933年）頃」説（BLOG-089・NEWSポストセブン2022）に一致する年次を、2019年時点の独立の散歩記録が既に記していた**〔二次記述。行政史料の照合前なので年次確定には用いない〕。
- **流路概要〔確認〕**：池袋駅の東側を水源とし、東池袋駅・新大塚駅方面を通り、護国寺から支流を受け、**音羽通りの東側に沿って**流れ、江戸川橋駅近くで神田川に合流〔観察記録。BLOG-001/002（Natrium）・LOST-005と整合〕。
- **沿線の観察〔観察〕**：美久仁小路（水源の池があったとされる路地・入口と出口のほかに第3の入口を発見）、日光広場・辻広場（BLOG-109/110参照）、護国寺と窪み、崖から湧き出る水を受け止めるバケツ、護国寺〜江戸川橋の「晴れても水浸しの駐車場」、鳩山家、合流点の入れ替わり等。※日光広場・辻広場の内容は既収録（BLOG-106/108/109/110）だが、**2019年12月時点の観察記録として時系列の補強**になる。
- **注意**：写真10枚ベースの散歩レポートであり、水路の位置確定や年代特定の一次史料ではない。バケツ湧水は2019年12月14日の観察として扱う。

- **追記（2026-11-13・第51回、Wayback 2024スナップショット再取得）〔確認〕**:
  - **江戸川橋合流点の東西逆転**: 水窪川は音羽通りの**東側**を流れているが、合流地点は普通に考えれば江戸川橋の東側の穴のはずが、実際は**西側の穴が水窪川の合流地点**。「下水を整備する中で、何らかの理由で逆に付けられたのではないか」（本田創の解説〔伝聞〕）。地図子自身が**文京区関口2丁目の下水道台帳（都下水道情報）を確認し、本当に逆になっている**と記す。〔第24回ノートの「下水道台帳直接確認」課題に接続する、合流点位置の具体化=repo初出の観察記録〕
  - **護国寺境内の蛇池**: 「昔境内にあった**蛇池**からの流れに架かっていた石橋が残されている」。〔「蛇池」の池名=repo初出候補。音羽富士前に移設されたとする護国寺石橋（BLOG-089/100・護国寺細流の橋移設説）と同一石橋かどうかは記事が特定しないため断定しない〕
  - **護国寺本堂裏の窪地**: 本堂の裏の墓地の奥に**今でも窪地が残り、運が良ければ水が溜まっている**。「窪地は豊島岡御陵の中に続いていて追うことはできない」。〔水窪川水源「護国寺と窪み」の位置具体化〕

- **未解決**：本田創氏講座で伝えられた水窪川の説の内容のうち本頁に記録されなかった部分。
