# [BLOG-032] sirakigi「千川上水（5）武蔵学園〜要町通り」：濯川・学田・二叉〜要町の全容

- **書誌〔確認・格上げ〕**: sirakigi内の千川上水の歴史・写真・探訪シリーズ第5弾（武蔵学園〜要町通り）。「最新更新：2012.12.29」。**当初は検索結果の抄録（二次転記）のみで本文未確認だった（旧status: 二次転記）が、2026-11-25に本環境から直接取得（HTTP 200・Shift_JIS）して本文全文を確認し、直接確認に格上げ**〔第312回。旧抄録の千川地蔵尊・五良久保橋・能満寺移設の内容は本文でも裏付けられた〕。昭和7年の武蔵高校航空写真・昭和15年・30年・38年と現在の今昔写真を併載。
- **濯川＝第3中新井分水〔確認・二次〕**: 昭和7年の武蔵高等学校（当時・板橋区中新井一丁目）全景写真で**キャンパス中央を分断して流れる濯川は、もと千川用水の第3番目の中新井分水（中新井分水は宝永4年〔1707〕開削された）**。水田が南方向へ扇状に広がる。**明治10年の文書で分水口は2寸四方**。明治42年測量・昭和12年修正の1万分の1地図にも記載。**高校東門付近から北新井公園を通ってほぼ南に向かい、目白通りを横切り、中野の当時の東京市療養所前で中新井川に合流**していた。**上流篇の第1・第2中新井分水ともに約11町歩の田圃を潤した**〔[GOV-005](../gov/GOV-005.md)の字北新井（豊玉上1-26・武蔵大学内）取入口・[ORG-019](../org/ORG-019.md)濯川七橋などの既収録に対応する流路・寸法の文言〕。
- **濯川の学校史〔確認・二次・補強〕**: **大正11年頃は幅約一尺ほどの小川だった（当時の武蔵高等学校教員の証言）**。この小川を拡幅して川にしようとの話が出て**根津嘉一郎（初代）理事長も乗り気で、教員・生徒が一体となって年々拡幅し周辺に木々を植えた。一時は相当の川幅となり「舟を浮かべた」時もあった**。**この川を漢学に精通した山本良吉校長が屈原「楚辞」漁父の詩から「濯川（すすきがわ）」と命名**〔[ORG-019](../org/ORG-019.md)の命名史（1928年発行校友会誌・山本良吉）と対応する同系列の叙述。**「舟を浮かべた」＝repo初出の文言候補**〕。**昭和27年秋頃の千川本流の暗渠化の結果、しばらくして千川からの水源が断たれ、長らく降雨時に川となる自然の状態で放置**〔ORG-019の「昭和49年放置」等と対校〕。昭和40年代初めには五位鷺が営巣しヒナを豊島園の動物園に預けた譚・近隣の子供のエビガニ採り・汚泥堆積の結末。
- **濯川の蘇生と遗構〔確認・repo初出候補〕**: **昭和60年に学園の記念事業として関係者・同窓生からの寄付で濯川の蘇生計画（循環式）が実施され流れが蘇えった。流水域わずか200メートル足らずの「東京で一番短い川」かもしれない**〔[ORG-018](../org/ORG-018.md)・[ORG-019](../org/ORG-019.md)（1985年4月20日第1期工事完了・通水式）と整合する昭和60年説の別表記〕。**かつての千川分水の名残をとどめる水門が今も残る（高等学校研究室棟北側）。堰を越えた水は手前で暗渠の放水口に落ち、大雨で溢れたときのみこの記念物的な水門を流れる。「今日、千川分水でこのような水門が残されていることは希である」**〔**分水名残の現存水門＝repo初出候補**〕。**昭和5年設置・海抜38.295メートルの「水準標メモリアル」（大学8号館前・東経139度40分3秒・北緯35度44分0秒。最近GPSで計測したところ数百メートルの誤差があったといわれる）**〔**水準標メモリアル＝repo初出候補**〕。蘇生後の生物観察（眞鴨・セキレイ・小鷺・川蝉）〔[GOV-124](../gov/GOV-124.md)音羽湧水との対照ではない・千川分水系の生物相記録〕。
- **中荒井村（→中新井）史〔確認・二次・repo初出文言群〕**（参考：練馬区史 歴史編 昭和57）: ①**小田原衆所領役帳（永禄2年〔1559〕）に「一、森新三郎 買得 拾四貫五百文 元吉原知行 江戸廻中新居 此度被改上 知行役可申付」**＝「**江戸廻中新居**」の記録から中世より村が作られていた〔**所領役帳の「中新居」文言＝repo初出候補。中新井の語源系資料として対校対象**〕。②天正18年家康入府以来**板倉勝重が豊島・新座2郡に約千石を賜り2〜3代にわたり中荒井村を知行**。③正保の**武蔵田園簿で板倉周防守（重宗）知行地・135石2斗6升余（田方79石・畑方55石）**。④板倉家は伊勢三重郡内へ転封、**元禄11年（1698）に幕府直轄地となり幕末に至った**。⑤村方文書は残されていないが、**千川家文書の水料から計算すると安永2年（1773）で10町1反・寛政4年（1792）で11町1反・元治元年（1864）で17町5反になる**〔**安永2年・寛政4年の中荒井村田面積＝repo初出（元治元年17町5反＝[GOV-067](../gov/GOV-067.md)の17町5反2畝15歩と整合し、3時点の時系列を構成）**〕。
- **環七と下練馬村分水〔確認・二次・repo初出候補〕**: **昭和16年刊（文献1）「武蔵高等学校の横の新道路は未だ工事半で、広大な地面が雑草に蔽はれたまま放置されてある」＝現在の環状七号線の昭和15年時点の状況文言**〔**repo初出**。戦中戦後は付近の人たちが畑を作っていた（記念室所蔵写真）〕。**環七桜台陸橋の脇から北へ羽沢〜桜台境を石神井川方向へ向かったのが下練馬村分水で、環七建設で跡形もないが明治24年の地図に記されている。「数年前、練馬郷土資料室で千川家から寄贈された千川資料を中心に千川上水展が開催された時、資料の中の千川絵図（製作年不詳）を渡辺学芸員と見ていたところ、あまり記録のなかったこの分水が絵図に記されており、歴史のある分水ということで驚いた」**〔**千川家寄贈「千川絵図（製作年不詳）」の存在と下練馬村分水の記載＝repo初出候補**〔[GOV-005](../gov/GOV-005.md)の下練馬村分水（栄町15・環七脇）と[MAP-060](../maps/MAP-060.md)等の千川上水路図とは別系統の絵図候補で、どの絵図かの同定は未実施〕。**南には十三間道路（今日の目白通り）が造られていて、戦時中はいざという時飛行機の滑走路としても考えられていたという。その故か電柱などはない（昭和15年頃）**〔**十三間道路の滑走路想定・電柱のなさの説明文言＝repo初出候補（[BOOK-077](../books/BOOK-077.md)・[BOOK-161](../books/BOOK-161.md)の十三間道路記録への補強）**〕。
- **江古田駅の移転史〔確認・二次・repo初出候補〕**: 武蔵高等学校が開校した大正11年、**武蔵野稲荷神社（栄町10）の裏に、生徒の通学のため朝夕2回だけ蒸気機関車が停車する武蔵野鉄道最初の「江古田駅」がつくられた（数メートルの木製プラットホーム）。学校が武蔵野鉄道に通学の便をはかってもらうということで別途お金を支払っていた記録が残る。現・えこだ駅はその後3回目の移動で現在の場所になった**〔**江古田駅の通学用停車場（大正11年）と3回の移動の記録＝repo初出候補**〕。
- **二叉（江古田三叉路）と千川堤植桜楓碑〔確認・二次・補強〕**: 滝島酒店（旭丘1-66）の正面店先に**大正4年建立の千川堤植桜楓碑**があったが、**「昭和27年に始まった暗渠化工事や千川通りの幅員拡張に伴って、今は江古田駅北口前の浅間神社（小竹町1-59）の入口の右手に移設」**。**大正天皇即位記念に下練馬村・中新井村・長崎村・上板橋村4村の篤志家が千数百株の桜や楓を植樹したと碑に記される。数年後には「武蔵野鉄道で千川上水の桜を見に行こう」と広告が出た**〔[BLOG-101](../blogs/BLOG-101.md)碑文（大野徳太郎撰・四村聯合・千数百株・一里二十余町）・[GOV-092](../gov/GOV-092.md)（浅間神社移設の公式目録）と整合する独立の裏付け＋**移設理由（暗渠化工事と幅員拡張）の具体化**〕。**「この付近が暗渠化されたのは昭和27年夏頃（練馬区史）」＝二叉付近の暗渠化年次**。江古田富士塚（天保10年・国重要民俗文化財）は同神社境内。
- **境界石・火の見櫓の半鐘〔確認・repo初出候補〕**: **旭丘1丁目の練馬区旭丘地域集会所の玄関先に、以前グリーンベルトにあった千川の境界石が保存**（平成8年にはオオムラサキの根元にもあった）。**その隣に「明治37年に千川上水の土堤に建てられ、昭和48年頃まで使われていた火の見櫓の半鐘」が保存されている**〔**明治37年火の見櫓半鐘＝repo初出候補。千川堤の施設の保存例**〕。
- **江古田村分水〔確認・二次・寸法補強〕**: **旭丘1丁目16番地と33番地の間から南へ（中野区江原町方向）。「明治10年で分水口は約2寸6分四方、田3町3反に通水」。南流して水田を潤し中新井川（江古田川）に合流していた**〔[GOV-005](../gov/GOV-005.md)の江古田村分水に明治10年の寸法・面積を補強〕。
- **練馬区側の暗渠化の年次と費用〔確認・repo初出〕**: **昭和25年5月に地元住民の願を区議会が取り上げ東京都へ請願。その結果26年中に具体的に予算化され、練馬区と豊島区の境から千川の暗渠化が上流の二又（745メートル）に向かって着手されたのは昭和27年3月26日で、二叉が同年8月30日に竣工。費用は約840万円。さらに都バス練馬営業所までが同年10月（885万円）と年々上流に向かった**〔**着手月日（3月26日）・竣工日（8月30日）・区間距離（745m）・費用（約840万円＋885万円）＝repo初出の具体値**。[BLOG-113](../blogs/BLOG-113.md)略年表（25年5月請願→26年度予算→27年3月着手）の詳細化として一致。[GOV-072](../gov/GOV-072.md)の「昭和25年頃から着手」説は請願・予算化の時期を指した可能性があるが資料間の前提差として整理し断定しない〕。
- **水番所と落合分水〔確認・二次・repo初出文言群〕**: 千川の90度北東転換点（豊島区に入る所）の交差点には**もと水番所（今はファミリーレストラン）があった**。**ここからほぼ南東に向かって分かれていたのが落合分水で「葛ヶ谷分水」とも呼ばれた。「明治10年、分水口約3寸1、2分四方。妙正寺川周辺の4町8反の田を潤していた」**。西落合1・2丁目を経て西武線を横切り5丁目で妙正寺川に流入・**全長2キロ。「2、3年前まで流れていたが、落合方面から練馬へ行く新十三間道路の工事の結果閉鎖された」**〔**分水口寸法・受益面積・全長・閉鎖の経緯＝repo初出文言群**（2012年更新時の振り返りのため閉鎖は2009〜10年頃）〔[GOV-005](../gov/GOV-005.md)の葛ケ谷村分水・[GOV-076](../gov/GOV-076.md)の調査アルバム「落合分水流域」との対照。取水位置が南長崎6-9の千川北曲折点とqみ合うかは対校課題〕。この付近の大正時代初期に**籾山牧場**がつくられた（地図に記載・現マンション角に乳業会社の説明版）〔[BLOG-145](BLOG-145.md)の籾山牧場・明治乳業記録と整合する位置側の観察〕。
- **千川地蔵尊の句碑〔確認・二次・repo初出〕**: 長崎の千川90度転回点に千川地蔵尊（現・能満寺）。**隣の石柱には「大正十四年十月廿一日千川浚の御時高木森作どの者□上り給ふ地蔵尊」と彫られている**〔**大正14年（1925）10月21日の川浚いの際に拾い上げられた地蔵＝千川地蔵発見の大正14年説の刻文記録＝repo初出候補（[PAP-027](../papers/PAP-027.md)の1925年発見説の刻文側の裏付け）**。川浚いのとき首がなかったので新たに作っておまつりした（お顔が新しい）〕。長崎の立て札**「本上水は飲料水に付き汚損すべからず、右違反した者は罰せられるべし」が写真で確認できるだけで4か所**〔飲料水文言の立て札の視覚記録〕。**大正3年（大正天皇即位記念）に一里二十余町（約6キロ）に植樹された桜並木は「昭和34年流れの大部分が暗渠となり千数百本の桜が伐採されてしまった」**〔**昭和34年・千数百本伐採＝repo初出文言（[ORG-022](../org/ORG-022.md)の昭和34年2月写真＝この年の実相の傍証）**〕〔千川の桜を惜しむ桑原さんの証言（平成8年3月聞き取り）〕。
- **立教大学運動場付近の立体交叉〔確認・二次〕**: **「この先立教大学運動場付近で、千川は石神井川に流入する一小流と立体的に交叉する。すなわちこの一小流は地下を潜り、遙か下で再び地上に現れる。千川開鑿当時この辺は技術上相当苦労した所かと思われる」**〔千川と石神井川支流の立体交叉の実例記録＝repo初出候補（どの流れかの比定は未実施）〕。**庚申塔（庚申橋＝千早町4丁目）の推移**: **江戸初期〜中期の6基（安永8年・明和4年・延宝4年等）が並んでいた。「昭和43年頃まで5基そろっていたが、ある日忽然と姿を消し、9年後の昭和52年10月に北大泉の山林に捨てられているのが発見された」（豊島区史にも記録・現在地に引取安置・千早町4丁目有志が管理・一番古い一基は行方不明）**〔**庚申塔群の消失（昭和43年）と発見（昭和52年10月）＝repo初出文言群。[BLOG-103](BLOG-103.md)の庚申橋記録と対照**。かつて水準点標石があったが失われた。
- **千川親水公園と復元計画〔確認〕**: 庚申橋跡から先が千川親水公園（要町3丁目の児童遊園・100メートル）。**「区民の消えた水辺の風景を取り戻したいという市民運動により、暗渠部分を掘り起こし川を作り、コイなどの魚を放す復元の計画で1994年の完成を目指すものであったが、その後の財政・経済状態の低迷により、今はさたやみになっている」**〔**要町3丁目復元計画の目標年（1994年完成）と中止の文言＝repo初出候補（[BLOG-321](BLOG-321.md)の「1993年・千川上水公園の豊島区復活計画中止」と対になる要町側の記録。[BLOG-113](../blogs/BLOG-113.md)「一部地域の復元計画も中止されたまま」と整合）**]。要町通りの元釣堀（豊島区要町3丁目）跡はマンションになったが**橋板の2つの大きな石が道路の端に保存**〔釣堀の昭和15年写真あり〕。
