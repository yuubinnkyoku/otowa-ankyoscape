# [BLOG-319] sirakigi「千川上水 歴史・写真・探訪（3）」上井草駅〜富士見台駅

- **書誌〔確認〕**: sirakigi内の千川上水の歴史・写真・探訪シリーズ第3弾（上井草駅〜富士見台駅）。「最新更新：2005.09.22」。**長らく直接・Waybackとも取得できなかったsenkawa31頁を2026-11-25に本環境から直接取得（HTTP 200・Shift_JIS）して本文全文を確認**〔第312回〕。昭和15年・38年と平成の今昔写真を併載。
- **上井草駅の鉄橋〔確認・二次・repo初出候補〕**: 上井草駅の手前で千川は開渠として橋梁をくぐる。**この橋梁はその銘板によると東京石川島造船所1926年製で、西武鉄道開通当初のものであるという（文献2＝千川の会編『千川上水』1982による）**〔**千川の現存橋梁の製造所・製造年の銘板記録＝repo初出候補**。銘板の現物確認は未実施〕。ここから千川はヒューム管に入り水量は**1日3,000トン（1時間125トン・1分約2.1トン）**、この下流は全域暗渠〔[BLOG-090](../blogs/BLOG-090.md)・[BLOG-094](../blogs/BLOG-094.md)と整合する流量数値〕。
- **同潤社製糸工場〔確認・二次・repo初出〕**: 上井草駅入口の北側・**練馬区下石神井4丁目9〜10番に明治13年に設置された「同潤社」という製糸工場があった。敷地は約千坪・工女120人。明治13年に千川用水利用願いを出し、翌14年に分水口5分四方が許可されている。明治19年廃業、21年に玉川製糸所と改名したという**。**明治10年代前半の東京府で最初の私営製糸工場2社の一つで、もう一つは石神井台1丁目15番、三宝寺と道場寺の間にあった「興就社」**。これらにより石泉地区の生糸生産が飛躍的に増加したといわれる〔**同潤社・興就社の立地・規模・許可年次＝repo初出。千川用水の民間工業利用の具体例（[GOV-067](../gov/GOV-067.md)の明治以降の水車・工業利用の系譜に加わる）**。参考文献『練馬の産業Ⅱ』（練馬区教育委員会・昭和61）＝repo未収録の書誌候補〕。
- **八成（斉藤）水車の仕様〔確認・二次〕**: 環八を越えた八成橋付近に八成（斉藤）水車。**斉藤氏は大正12年8月から水車経営にたずさわり、それ以前は鴨下由右衛門という人が経営していた**〔[GOV-069](../gov/GOV-069.md)（大正12年8月1日斉藤倉之助引継ぎ・元は鴨下氏経営）と整合し、**前身経営者の個人名「鴨下由右衛門」を具体化**〕。**約70メートル上流から水を引き、当時の水輪は直径2丈4尺。水輪部は6尺ほど掘り下げて水車を仕掛け、水はトンネルで千川に戻していた。挽臼（臼の回転）4台・搗杵（杵の上下）12本で主に精麦**〔**水輪直径2丈4尺・挽臼4台・搗杵12本＝八成水車の構造数値としてrepo初出**〕。昭和4年測量・12年修正の地図に記載。このあたりから街路樹はプラタナスになる（参考：伊藤好一『武蔵野と水車屋』クリオ・1984＝repo未収録の書誌候補）。
- **昭和4年頃の水車6か所〔確認・二次〕**: 「千川の流れを利用した水車小屋は、**昭和4年頃に於てすら6ヶ所を数えたが、現在は僅かにここを加えて3ヶ所しか残っていない**」〔**昭和4年頃6か所→現在（更新時）3か所＝時点別水車数の変遷の補助線**。明治17年頃8か所（[GOV-040](../gov/GOV-040.md)・[GOV-067](../gov/GOV-067.md)）と昭和16年刊時点6か所（[BLOG-320](BLOG-320.md)参照の昭和16年刊文言）との間の系列整理に使える観察値。数え方・区間が資料ごとに異なる可能性があり断定しない〕。
- **渡辺（鴨下）水車〔確認・二次〕**: 千川児童遊園（富士見台1-4）に以前**「渡辺（鴨下）水車」**があった〔[GOV-067](../gov/GOV-067.md)の鴨下水車（富士見台1-4）に「渡辺」表記を付す叙述。経営の前後関係は本頁からは確定できない〕。
- **三兵橋・長命寺道標〔確認・二次・repo初出候補〕**: 富士見台駅南西にもと「三兵橋」があった。**長命寺道（東高野山長命寺）の道標は現在も千川通りの歩道に残され（高さ105センチ・「右長命寺道」）、マンション建設に伴い平成17年5月に練馬区により案内板が設置・整備された**〔長命寺道標の現存と整備年次＝repo初出候補。頁内表記のまま記録。嘉陵紀行（村尾正靖の紀行文）言及には「寛文11年（1799）」の年次併記があるが、寛文11年＝1671年で1799年＝寛政11年とはずれる〔頁内の年次誤記の観察。東野孝保撰石碑（貫井5-17）の文言との関係は原典確認まで留保〕〕。
- **九頭龍橋・九頭龍弁天〔確認・二次〕**: 富士見台駅入口・**「練馬から石神井へ達する往還にある千川唯一ともいうべき堂々たる橋梁」**。この橋の下付近で千川の水深は最も深く**約2メートルに達した（昭和15年頃）**〔[PAP-027](../papers/PAP-027.md)の九頭龍橋（1974年再建）の戦前の規模記録。五差路にあった〕。**九頭龍（九頭竜）弁天はもと九頭龍橋のたもとにあったが、暗渠化により一時行方不明になり、昭和49年に現在地（中村橋駅西歩道橋手前の広くなったグリーンベルト）に祀られた**（昭和49年建立の石碑に由来記録・渡邊龍神・弘法大師・子庚申・馬頭観世音も同祀）〔**九頭竜弁天の消失・昭和49年再祀＝repo初出候補（[BLOG-033](BLOG-033.md)の夢七雑録系記録・[PAP-027](../papers/PAP-027.md)の1974年九頭龍橋再建との対照）**〕。
- **現況〔確認〕**: 元育英高専の移転と跡地の住宅建設計画（2005年時点）・滝沢花園（南田中1-13-9）の温室・富士見台五差路への流路付けかえ（昭和のはじめの地図で千川に沿った道が離れて直進していたが、後に千川に沿って改修されたとの読み）。
- **昭和15年・38年写真の内容〔確認・二次〕**: 踏切付近の農家の収穫作業・八成橋からの畑地一望（水深約2m・雑草熊笹の密生）・水車の取入れ口水門（左は水車へ、右は本流）・浅間神社の小祠・育英工芸学校付近の桜並木（「千川堤の桜並木は既に筋違橋の上流立野橋付近から始まる」）〔[GOV-076](../gov/GOV-076.md)の調査アルバムと対比できる解説群〕。
- **〔未解決〕**: 上井草駅鉄橋の銘板の現物確認。同潤社・興就社の原典（『練馬の産業Ⅱ』）確認と書誌登録。八成水車の水車小屋写真（昭和15年・[GOV-076](../gov/GOV-076.md)の調査アルバムとの对照）。九頭龍弁天の昭和49年石碑の由来看板の現地確認。長命寺道標の案内板文言。
