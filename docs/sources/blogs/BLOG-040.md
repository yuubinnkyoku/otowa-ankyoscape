# [BLOG-040] 豊島区散歩 そのⅠ（谷端川・千川・小石川を下る）

- **直接確認（2026-11-11、open_url・本文全文）**：2009年の谷端川源流→小石川後楽園までの散歩記録。重要なのは以下の3点。
- **弁天池の揚水〔観察：2009年時点の現況〕**：粟島神社（要町2-14）境内の弁天池の湧水が谷端川の源流だが、**「現在ではポンプアップで水をくみ上げている、よう」**という2009年時点の現況観察。昔も湧水だけでは灌漑用水量が不足し、千川用水からの分流（養水）を取り入れていたと説明。※ポンプ揚水の有無・開始時期は本記事では確認できない（伝聞表現）。既収録の2022年粟島神社聞き取り（[GOV-015](../gov/GOV-015.md)）と合わせ、**2009年時点でもポンプ汲み上げが観察されている**ことが揚水開始時期の上限を絞る手掛かりになる。
- **「千川」呼称の別説〔二次叙述の記録〕**：谷端川が下流で千川と呼ばれたのは千川用水分流による、が通説だが、**「千川用水自体が小石川白山御殿まで通っていたから」という別説**を紹介（「千川用水開削の目的はもともと小石川白山御殿・本郷湯島聖堂・上野寛永寺や浅草寺などの御成御殿への給水」）。※既収録の千川上水目的論（千川用水と文京区解説・リサーチセッション.md・白山御殿関係）と照合する価値がある。
- **書誌情報〔所在確認〕**：散歩の参照資料として **『千川上水探訪マップ』（豊島区郷土資料館・池袋駅近くの勤労福祉会館内資料コーナーで入手、repo未収録）**、**『江戸の川あるき』栗田彰（青蛙房）**（谷端川を紹介）、『歩く・聞く・映す』（要町あたりを源流点とする谷端川川筋図を収録）を挙げる。**『千川上水探訪マップ』と栗田彰『江戸の川あるき』は repo 未収録の書誌**。
- **地名〔二次叙述〕**：要町の由来（扇の要・旧長崎村の中心地）、長崎の由来（舌状台地説と長崎氏由来説の併記）、椎名の由来は不明、など。推測を含み事実とは採らない。
- **制限〔未解決〕**：探訪マップ・『歩く・聞く・映す』の刊年・版の特定、白山御殿説の出典は未確認。
