# [BLOG-265] まろん通信Vol.2673「市報で50年前の小金井を見る事が出来ます」〔repo初出・市報1973年1月20日号由来の仙川洪水対策（宅地盛土資金融資・年利5.5%）・昭和38年氾濫を起点とする都の仙川河川改修の因果文言〕

- **書誌〔確認: 本文全文・2026-11-22取得〕**: まろん通信（koganei-kanko.jp/maron・小金井市観光まちおこし協会）Vol.2673「市報で５０年前の小金井を見る事が出来ます」（2023年1月9日公開・**レキGさん**〔まろんレポーター欄で1,160post・小金井育ち〕執筆・[archives/51929](https://koganei-kanko.jp/maron/archives/51929)）。**1973年（昭和48年）1月1日号・1月20日号の市報を振り返る記事**で、同市報の紙面写真（市提供・転載禁止）を根拠に解説する形式。
- **仙川洪水対策の融資制度〔確認: 本文直接引用〕**: 「**１月２０日号には仙川両岸に洪水対策として、盛り土資金貸し付けの説明があります。利率は年５．５％です。当時銀行の短期プライムレートは４．２５％から７．２５％昭和４９年にはさらに９．２５％まで上昇しています。長期プライムレートも７．７％から８．６％でした。今見るとまるで消費者金融金利のようです**」＝**1973年1月20日号市報＝仙川両岸の住宅地に洪水対策の宅地盛土（敷地かさ上げ）資金を市が年利5.5%で貸し付ける制度の説明記事**＝**個宅地単位の洪水対策（盛上げ）の打ち始めを示す施策文言**〔第257回〔[GOV-508](../gov/GOV-508.md)〕で探索中の市報昭和48年7月20日号「仙川分水路工事」と同年の市報系記事で、仙川治水史の1973年時点の断面が市報本文由来で分かる〕。
- **昭和38年氾濫と都の仙川河川改修〔確認: 本文直接引用〕**: 「**昭和３８年ですが仙川氾濫の写真です。左側が仙川で水が引き始めてもこの様な状態です。この後対策として東京都も仙川河川改修を行い今の仙川の幅になっています**」＝**昭和38年（1963）仙川氾濫→東京都による仙川河川改修→現行の川幅に至るという因果系列〔repo初出の文面〕**。Wikipedia「仙川」の昭和41年（1966）台風4号氾濫文言（[GOV-508](../gov/GOV-508.md)本町2丁目洪水・激甚災害指定）と**2つの洪水事象（38年・41年）が並んで治水史の起点に据えられている**可能性＝39〜41年氾濫の連続性・改修着手の時期は都資料での確認課題。
- **給水車の運行〔確認〕**: 「**同じ昭和３８年の仙川洪水で給水車が出た写真**」＝**洪水時の断水・給水車の応急給水の実態写真（市報）**＝明治〜昭和の断水史（[GOV-506](../gov/GOV-506.md)参照）の昭和分岐に接続する観察記録。
- **「仙川は怖い」の口碑〔確認: 本文直接引用〕**: 「**当時は仙川流域の人はよく「仙川は怖い」といっていました**」＝**流域住民の集団記憶としての恐怖口碑〔repo初出〕**。
- **水量の回想〔確認: 要約文言〕**: 「**５０年前の１９７３年１月の市報から…記事からは水が涸れて今では信じられないような仙川の記事もありました**」＝「水が涸れて」の記述＝[GOV-510](../gov/GOV-510.md)の水量減衰・瀬切れ文言と整合する1973年時点の市報側の観察。

## repoとの関連〔観察〕

- ①**仙川治水史の1973年断面＝宅地盛土資金融資（年利5.5%）という微視的施策の記録**＝[GOV-508](../gov/GOV-508.md)（台風4号・激甚災害・仙川分水路昭和48年）に続く市報系の仙川治水レコードで、河道改修（都）と宅地対策（市・融資）の並行体系を示す。②**昭和38年氾濫→都の仙川河川改修（現行川幅）の因果文言＝repoの仙川行（武蔵川／呼称変遷〔対照表〕）の治水側の歴史に「改修の直接契機」を追記できる**（改修着手年は都資料確認まで特定しない）。③**「仙川は怖い」の口碑と仙川の縮退（水が涸れる）の並在＝治水で川幅だけ確保され、水は消失した一方通行の変遷像**＝[BLOG-264](../blogs/BLOG-264.md)（三面コンクリート化による地下水流入遮断）の観察と合わせた仙川の近代史の重層記録。④市報1973年1月20日号の紙面写真＝仙川分水路工事（7月20日号〔GOV-508の引用〕）までの半年前の治水施策記事で、市報原本の所在（こがねい電子図書館・市アーカイブ）の探索を進める手がかり。

## 意義〔観察〕

- 市報の紙面を正月回顧として読み直した記事で、**市報1973年（昭和48年）記事の二次紹介に留まるが、市報原本に容易にアクセスできない現状では実質の本文見本として機能する**。仙川治水史（宅地盛土融資・都改修・昭和38年氾濫・給水車・「怖い」口碑）の5点セットが1記事でそろう。

## 制限・未解決

- ①市報1973年1月20日号の本文（盛り土資金貸し付けの施策詳細・対象区域・枠・返済条件）は記事の紹介文言からのみで、市報原本の確認は未実施。②「東京都も仙川河川改修を行い今の仙川の幅になった」の改修着手年（昭和38〜48年のいつか）・設計断面の数値は未特定＝都建設局の歴史資料（[GOV-510](../gov/GOV-510.md)の同協議会文書・実施計画書（000006721=000006724）周辺）の確認課題。③写真は市提供で転載禁止のため本文の引用文言のみを記録（画像引用はしない）。④紙面写真の判読（盛り土資金の記事本文・氾濫写真の位置特定）は市報原本確認と併せて実施する。
