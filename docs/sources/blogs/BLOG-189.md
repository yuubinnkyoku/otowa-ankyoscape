- **文京区区間の流路〔観察・2014年〕**: 護国寺〜江戸川橋。講談社裏手から高速道路に沿い、高速下と同じ高さのアスファルト下に資材収納トンネルがある地点・一段低くなる空間・駐車場・マンション横を経て、**高速下公園に「フェイクの水の流れ」（水路跡だが水無し）と噴水（ほとんど水が出ていない）**が整備されている〔**フェイク水流・噴水＝repo初出の観察記録**。[BLOG-137](BLOG-137.md)の高速下クネクネ暗渠歩道・[BLOG-001](BLOG-001.md)の1932年流路付け替えの文脈補強〕。江戸川橋のたもと（江戸川公園）で神田川に合流。
- **雑司ヶ谷幹線の分水運用〔repo初出文言〕**: 「現在の下水道雑司が谷幹線は、**流れる水量が多い際には神田川に直接放水**するが、少ない（適量な）場合は処理場まで行く」〔第2雑司ヶ谷幹線（[BLOG-063](BLOG-063.md)）の運用記述として新情報。都下水道局の一次資料（放流設備・可動堰の有無）での裏付けが次の課題〕。
- **「西青柳下水」呼称の不在〔repo初出の指摘〕**: 水窪川＝東青柳下水（[BLOG-184](BLOG-184.md)ほか）に対し、**弦巻川＝西青柳下水と呼ぶ記録は見当たらない**と明記〔講談社裏手＝西青柳町の流路記述を伴う。鼠ヶ谷下水を含む呼称体系整理の材料〕。
- **江戸川公園〔観察〕**: **1984年（昭和59年）神田川拡幅工事に伴う改修**・神田上水取り入れ口**大洗堰の復原**・**神田川治水に貢献した大井玄洞翁の胸像**〔**大井玄洞＝repo初出**。大洗堰は[GAZ-021](../gazetteers/GAZ-021.md)既出の補完・文脈追加〕。
- **首都高5号池袋線の建設文脈〔解釈・仮説〕**: 1964年東京五輪に向けた突貫工事で、用地買収を避けるため**河川・廃河川の上に道路を造った**との筆者解釈〔[BLOG-001](BLOG-001.md)・[BLOG-185](BLOG-185.md)（自然流路の終点＝高速5号線）と整合するが行政史料の裏付けなし。断定しない〕。
- **制限〔未解決〕**: ①雑司ヶ谷幹線の神田川直接放水の一次資料（都下水道局台帳・設計図書）未確認。②泪橋＝音無川の橋（『あしたのジョー』）は作品と実在橋の対応で本四河川と無関係、記録のみ。
