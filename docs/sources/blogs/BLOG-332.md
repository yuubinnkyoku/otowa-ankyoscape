# [BLOG-332] 暗渠ハンター 板橋湧水跡めぐり ２（上板橋エリア）

## 書誌・確認範囲

## 内容メモ

- **〔確認: 二次引用（『いたばしの河川』）〕** 上板橋・**子育て地蔵付近を源とし、五本欅の西側を通り、田柄川に流れ込む「どぶ川」**（五本欅＝川越街道沿いの欅5本の通称）。地形は「まっさらで谷頭らしいものも見当たらない」が地図上はうっすら凹む〔観察＋引用〕。
- **〔確認: 二次引用（『いたばしの河川』）〕** 「**古老の記憶でもこの川は早くから下水として用いられていた**ようで、この川の水を何かに用いたという話は聞くことができなかった」＝当該どぶ川の利用史の否定文言。
- **〔観察＋推定〕** 茂呂山下（小茂根5丁目・大山高校あたり）: 石神井川右岸の**「揚げ堀」的な用水路**（石神井川の水を一旦揚げて周囲に回す）。台橋あたりが石神井川との合流点・車止めと「水路へ降りていくような階段」・**湿気味橋の下に大きな合流口**。茂呂山遺跡との位置関係。

## repoへの関連

- **田柄川に注ぐ上板橋側の無名どぶ川の引用文言**＝田柄川上流部（練馬区側＝千川上水中流域の南隣）への注ぎ込みの『いたばしの河川』側記録。[BOOK-031](../books/BOOK-031.md)の本文未確認の制約の下で、同書の水路記述の二次抄録として蓄積する。
- 「揚げ堀」観察は[BLOG-331](BLOG-331.md)（桜台安養院のあげ堀）と同じ形式の石神井川取水施設の別例で、石神井川下流域（千川末端・谷端川放水路域の対岸）の用水構造の観察材料。湿気味橋はrepo初出の橋名候補〔観察段階〕。
