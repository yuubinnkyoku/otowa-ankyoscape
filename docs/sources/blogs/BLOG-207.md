# [BLOG-207] 板橋駅〜大塚の区境区間の読図と滝不動1935年頃暗渠化工事説

- **直接確認（2026-11-13、第64回・FC2直fetch）**。
- **区境と「谷端」地名〔確認：本文主張〕**：板橋駅を過ぎると流路は**北区と豊島区の区境（かつての滝野川村と池袋村の村境）**を進み、**北豊島郡滝野川村の一画に「谷端」という地区（現在の北区滝野川7丁目あたり）があり、この地区が谷端川の名称の由来**と整理する〔谷端地名由来の独立二次記述。gauche既収録の由来説と照合用〕。左岸側が「谷端」と呼ばれた地区で、現在も小学校や公園に名が残る。
- **明治通り〜堀割交差点〔観察〕**：明治通りを越え、**この交差点から300m余り北東に進むと千川上水の終着地点である「堀割交差点」**、そのそばの千川上水公園は**千川上水の沈殿池があった場所**で、この先へ樋で各所に送水された〔既出の沈殿池記録（GOV-065・BLOG-129）と整合する位置読図〕。明治通りの先200mで**上池袋から流れてくる支流が右岸に合流**〔BLOG-125の上池袋支流と整合〕、合流地点のすぐ先に谷端川跡の案内板が立つ（植物に埋もれ気味、2018年観察）。北大塚三丁目交差点＝旧癌研通り。
- **滝不動の移転史〔伝聞：本文の叙述〕**：大塚駅北口の川沿いの滝不動について、**「1935年（昭和10年）頃の暗渠化工事に伴い移転**し、個人の敷地内に祀られていた際に戦火で台座部分を残して消失。残された台座に新たに坐像を据えて安置していたところ、敷地保有者のビル建設により現在地（川沿い）に祀られることになった」と記す〔BLOG-038（昭和10年頃消滅→平成11年復帰）と内容整合しつつ、**「1935年頃の暗渠化工事」が谷端川下流（大塚）区間の暗渠化年次の独立データポイント**になる。寅さん歩（BLOG-152）の「板橋駅より下流＝昭和10年前後暗渠」と整合。断定は既存の年次対立（1967年説等）があるため行わない〕。
- 大塚駅前の角萬（ビル屋上の金閣寺）等は水路と直接関係しないため省略。
