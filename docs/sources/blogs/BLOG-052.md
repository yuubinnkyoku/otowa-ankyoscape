# [BLOG-052] 東京の水2009 fragments「弦巻川断章」

- **直接確認（2026-11-11、open_url・本文全文）**：本田創（tokyoriver＝[LOST-002](../lost-web/LOST-002.md)・[LOST-003](../lost-web/LOST-003.md)の同一人物）による2010年3月8日の記事。イベントで時間切れとなった弦巻川の補足解説。
- **既引用部分〔確認〕**：**明治16年（1883年）五千分一東京図測量原図では弦巻川と水窪川が神田上水の暗渠（点線表示）を伏樋でくぐって神田川に合流**していたとする読図（[弦巻川の571コマ記録](../../弦巻川.md)で既に引用済み）。
- **現地観察〔観察：筆者の現地確認記録〕**：①**音羽谷西縁（首都高速の1本東側の直線道路）**に未舗装の荒地として残る暗渠。**高速道路は川を埋めて造られたのではなく目白台／関口台の斜面上に作られたため暗渠の空間が残った**と分析。大谷石の擁壁から排水管が突き出し、微妙に蛇行する。**暗渠沿いの側溝に湧水が湧き出して流れていた**（撮影時、澄んだ水）。②**護国寺の西側の区間**は「弦巻川跡の道路では唯一暗渠らしさが残る区間」で、**かつてホタルが飛び交っていた**という。1998年の写真を掲載。道端に**鍋を伏せて塞いである井戸**があり、管から水が自然に流れ出し、井戸というより湧水で水量も多い。③**清土鬼子母神の星の井戸**：三角形の井戸で蓋を開けると水を湛え、**1561年に畑の中から発見された鬼子母神像をこの井戸の水で洗った**という伝承を紹介。
- **コメント欄〔二次情報〕**：筆者自身の返答で「このあたりには他にも密かに湧水が残っていて、サワガニがひっそりと棲息している場所もある」「弦巻川の西側の台地の斜面にあるお寺や個人宅の敷地内に、あちこちひっそりと湧水が残っている」。
- **制限〔未解決〕**：①の未舗装暗渠の正確な位置（座標）は記事の地図画像の判読が必要。湧水・井戸の現在の状況・水量の定量的記録はない。星の井戸の伝承の原典（社伝等）は未確認。
