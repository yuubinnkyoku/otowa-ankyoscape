# [BLOG-356] 歴史探訪と温泉「神田上水遺構（本郷）」＝石樋碑文・白堀移設復元・春日町石展示の説明板全文

- 本郷給水所公苑（文京区本郷2-7-1・水道歴史館裏手）に移築復元された神田上水遺構2件と春日町交差点の石展示1件の、現地説明板・碑文を写真撮影・転写した記録。**[BLOG-355](BLOG-355.md)（旧白堀跡説明板・第367回）に続ぐ、白堀発掘遺構の移設復元側の初の全文言記録**。

## 内容メモ

- **〔確認・repo初出〕「神田上水石樋」碑文（東京都水道局）**: 「**この石樋（石垣樋）は、昭和62年から平成元年にかけて発掘された神田上水幹線水路の一部を移築復原したものである。石樋の内部寸法は、上幅150cm、下幅120cm、石垣の高さ120～150cmで、長さ約180cm、幅60cm、厚さ30cm前後の蓋石がのせられている**」＋「**神田上水石樋の由来**」碑文（天正18年家康入府に際し大久保藤五郎忠行が開削・井の頭池水源・後楽園のあたりから地下の石樋・掛樋で神田川を渡し神田日本橋へ給水・「**昭和六二年、文京区本郷一丁目先の外堀通りで、神田川分水路の工事中発掘された神田上水遺跡の一部です。四百年近く土中に埋もれていたにもかかわらず原型を損なわず…東京の水道発祥の記念として、永く後世に伝えるため移設復原されたものであります**」）＝**石樋の定量寸法（上幅150・下幅120・高120-150cm・蓋石180×60×30cm）と移設復原の経緯文言がrepo初出**。〔発掘年次は昭和62年〜平成元年（1987-89）で、[GOV-625](../gov/GOV-625.md)の水道歴史館公式頁「昭和60年（1985）発見」との表記差はそのまま記録〕。
- **〔確認・repo初出〕「神田上水（白堀部分）」移設復元説明板（平成27年3月・東京都水道局）全文**: 平成23年・旧文京区立第五中学校敷地内（現文京総合福祉センター）で**時代の異なる二筋の流路跡が発見**、**間知石（四角錐）**が使われ、**間知石の下に胴木（石積みの基礎にする木）が設置され、石積みは1段から3段**、**左側が古く江戸時代（19世紀前・中葉頃）に構築、右側は幕末から明治以降の構築**、**右側の新しい流路の間知石の上には明治9年に神田上水の清浄を保つために設置された石の蓋の基礎にしたと考えられる長方形の石が積まれている**、**石の蓋から流路沿いの道が巻石通りと呼ばれるようになった**、文京総合福祉センターに遺跡の一部が保存展示＝**①遺構の相対年代（新旧流路の構築時代区分）、②間知石+胴木の工法、③石蓋設置＝明治9年説、④巻石通り呼称由来の公式文言がいずれもrepo初出**。〔明治9年（1876）石蓋説は[BLOG-355](BLOG-355.md)の明治10年・[BOOK-147](../books/BOOK-147.md)の明治10年巻石蓋・旧町名案内の明治11年頃と並ぶ第4の年次で、対校課題として記録（断定しない）〕。
- **〔確認・repo初出〕春日町交差点（文京区春日1-16-27）「ポケットパーク テーマ水」の石展示**: 植栽内に**昭和62年（1987）に水道橋付近から発掘された神田上水で使われていた石樋の石が展示**。文京区説明掲示全文（「昭和六十二年外堀通りの工事中に現在の水道橋付近から発掘」「大洗堰（現在の文京区関口）を経て水戸屋敷（現在の小石川後楽園一帯）に入れ、そこから先は暗渠（地下の樋）で通し」「お茶の水坂からは掛樋で神田川の上を横断」）＝**水道橋発掘石の3箇所目の展示先（本郷給水所公苑・春日町交差点・[GOV-625](../gov/GOV-625.md)の水道歴史館収蔵）の存在がrepo初出**。
- 〔確認〕公苑内に江戸切絵図「小日向絵図」から神田上水部分（関口から水戸殿の屋敷まで）を抜粋した展示もある〔観察記録〕。
