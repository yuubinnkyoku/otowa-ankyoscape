# [BLOG-029] 保存車両・碑記録サイト「動輪の由来」（池袋メトロポリタンプラザの東京鉄道教習所跡碑）

- **書誌〔確認：ページ本文を直接判読・Shift_JIS〕**：個人運営の碑・保存車両記録サイト「動輪の由来」池袋頁。撮影日 2005年1月7日。種別＝跡地碑。
- **所在〔確認〕**：碑の所在地＝**豊島区西池袋1-11-1 メトロポリタンプラザ**（MapCode 820135*55）。池袋駅西口メトロポリタンプラザ入口。
- **内容メモ〔確認：碑文・背景の転記〕**：
  - 碑文：「ここはかって**東京鉄道教習所**があり、広大な敷地に校舎、大講堂、図書館、プール、寄宿舎など…」。当時の所在地＝「東京府北豊玉郡西巣鴨町字池袋」（碑の表記ママ）。**敷地約37,000㎡・校舎/大講堂/寄宿舎など約100棟**。**存在時期＝大正13（1924）〜昭和29（1954）**。
  - 碑文：財団法人鉄道育英会設立の**東京鐡道中学が東京鉄道教習所内に開校**、後に東京育英中学/中学校/高等学校/芝浦工業大学高等学校と改称、**昭和57（1982）まで存在**（存在時期1924〜1982）。
  - 碑文：「これらの施設は**昭和20年4月14日の東京大空襲で一旦焼失**」。「なお、この地は**成蹊学園発祥の地**」。
  - 背景：1909（明治42）麹町区山下町に鉄道院職員中央教習所開設。**1924年に池袋成蹊学園跡であるこの地に移転**。1952年三島鉄道教習所と合わせ中央鉄道教習所、1953年本部国分寺移転、**1954年この地閉鎖**。1958年中央鉄道学園改称、1987年国鉄分割民営化で閉鎖。
- **留保**：碑文の二次転記（個人サイト）。郡名「北豊玉郡」は「北豊島郡」の誤記の可能性。丸池そのものの位置・区画は碑文にない。関連：[GOV-055](../gov/GOV-055.md)（丸池＝成蹊池→鉄道教習所→枯渇）・[ORG-011](../org/ORG-011.md)（学校公式沿革）。
