# [BLOG-222] 池尻成二note「白子川～河川整備計画改定についてのメモ②」

- **資料〔確認〕**：池尻成二（「川の環境と景観を考える会」元事務局長・川の写真・エッセイ）のnote記事「[白子川～河川整備計画改定についてのメモ②](https://note.com/ikesans/n/nd9c45cad125d)」（**2026年7月24日**公開）。本文をopen_urlで取得して確認。前回メモ①と対になる、2026年7月1日〜7月31日のパブリックコメント対象となった「**新河岸川及び白子川 河川整備計画（変更原案）**」（変更原案資料39ページ）の内容紹介・筆者による分析。
- **計画降雨量の変更〔確認：変更原案の数値を筆者が転記〕**：変更原案は**計画降雨量を1時間あたり75mmから85mmに引き上げる**（都内の風水害対策の統一基準化）。**谷端川を含む新河岸川水系の親水系で、計画降雨が現在の75mmから85mmに変わる**ことを示す具体例として記録価値がある。ただし筆者の転記であり、変更原案本文での谷端川の直接言及の有無は筆者記事からは確認できない。
- **調節池の配置見直し〔確認：転記〕**：白子川の地下調節池について、**従来計画の「向下橋」付近から「芝屋橋」付近への位置変更**を記す。調節池の**総容量502,000m³は変更されない**。白子川調節池の位置決定過程（向下橋案の経緯をメモ①で扱ったとされる）が、2026年変更で芝屋橋案に変わった点を示す。
- **流量カット〔確認：転記〕**：計画高水のカット量が**208m³/sから345m³/s**へ変更。流域の雨水流出を調節池で吸収する方針は維持される。
- **専門家委員会・公表スケジュール〔確認：転記〕**：第21回河川整備計画策定専門家委員会（2026年9月2日）での変更原案審議の予定を記す（[GOV-136](../gov/GOV-136.md)の開催告知と一致）。決定版の公表時期は明記されない。
- **谷端川への含意〔観察〕**：本noteは谷端川を直接扱わない。しかし谷端川の属する新河岸川水系の整備計画の枠組み（計画降雨・調節池配置）が2026年に更新される過程を、当事務局側の元局員の視点から説明する資料として、[GOV-136](../gov/GOV-136.md)と対で記録する。谷端川の個別改修・暗渠管理にこの変更が直ちに反映されるかは、変更原案本文・決定版の確認を要する〔未確認〕。
