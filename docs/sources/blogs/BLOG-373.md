## 内容メモ

- **〔観察・repo初出候補〕「北町支流（仮）」**: 川越街道下練馬宿に向かう田柄用水には交差する田柄川の支流があり、「新興橋に向かう北からの流れが地図に記載」されているとして**北町支流（仮）**と命名〔[BLOG-369](BLOG-369.md)（entry-217）の北町六丁目からの支流・[BLOG-374](BLOG-374.md)（entry-231）の駐屯地西支流との対応は要整理〕。
- **〔観察〕下練馬宿の用水の街道併走と水路分岐群**: 東京聖徳病院脇の水路敷を抜け、下練馬宿の上宿あたりで川越街道の南側に移り、**北町観音堂**で北側に移動、北町浅間神社と下練馬の富士塚（江古田浅間神社の富士塚が重要有形民俗文化財であることへの言及を含む）を通過。北町浅間神社から500m東進の間に**田柄川へ向かう水路が数えるだけで5箇所**設けられていた〔宿場区間の用水の形態と分流群の数の観察としてrepo初出の詳細〕。
- **〔観察・repo初出〕宿場施設の位置と田柄用水**: 下練馬宿の中心部で、**UR都市機構東武練馬アパート（1F食品スーパー）の位置が木下家本陣跡（本陣は後に北町観音堂の西の大木家本陣に引き継がれた）**、その隣に**内田家脇本陣跡**、対岸に**島野家の馬継の問屋場跡（現在はエイトサイド新和）**、問屋場跡のところで用水は街道の南側に戻る。問屋場跡からクランク状に進む水路があり、環八通りのトンネルの上に大山道道標。内田家末裔の店舗の手前からも水路が分岐〔木下家・大木家・内田家・島野家の宿場施設の位置を用水の流路に紐付けて記録＝いずれもrepo grep 0件＝repo初出。川越街道の宿場研究（宿場の高官専用本陣の運営実態の解説を含む）の地域史側記録〕。
- **〔観察・repo初出〕下宿水車**: 下練馬宿から田柄川への合流に向かう用水沿い（整骨院の手前を右折した路地→駐車場と住宅の隙間）に「**（下練馬宿）下宿水車**」があった〔水車名「下宿水車」はrepo grep 0件。[ORG-051](../org/ORG-051.md)の用水沿い水車群（下田・桜井・島崎・速見・鴨下・金子・関口）に加わる新出の水車名候補。「下宿橋」は第195回追補で既出の橋名群（富士橋→旧富士橋→下宿橋）と関連する地名側の記録〕。
- **〔観察〕用水の流末（渡戸橋で合流）**: 啓志線軌道跡（足場の組まれたビル）の西側を南下、国道254号線を越え、東本村庚申塚のある「**渡戸橋**」で田柄川に合流〔[BLOG-369](BLOG-369.md)（entry-217）の渡戸橋＝用水合流点の橋名観察と独立一致＝用水流末の位置が橋名レベルで裏付けられた〕。

## 四河川への使い方

- **田柄用水の宿場区間（下練馬宿）の流路・分流・宿場施設の対応を初めて流路単位で記録した観察記事群**。[ORG-051](../org/ORG-051.md)「行政上の田柄川」北町一丁目で川越街道を横断する記述の、用水側からの対校材料。
- 下宿水車は田柄用水の水車群に加える。本陣・脇本陣・問屋場の位置は用水・街道の空間構造の復元資料。
- 渡戸橋合流点は[BLOG-369](BLOG-369.md)と独立一致しており、用水流末の確定度を上げる。

## 制限・未解決

- 本陣群の位置の一次資料（宿場明細帳等）との照合。
