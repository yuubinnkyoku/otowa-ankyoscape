# [BLOG-135] 落合道人「谷端川は夕暮れて。」

- **書誌〔確認：Wayback 2025-02-09スナップショットで本文取得。現行サイトは403遮断〕**：tsune-atelier.seesaa.net、2005年12月28日付。[Wayback保存版](https://web.archive.org/web/20250209101741/https://tsune-atelier.seesaa.net/article/2005-12-28-1.html)。落合道人（ChinchikoPapa）は落合・目白地域の詳細な地域史研究者（[BLOG-023](BLOG-023.md)・BOOK-044/049既出）。
- **暗渠化年次の一次証言〔確認：本文〕**：**1948年（昭和23）から川底の掘削とコンクリート護岸工事が始まったが、その工事によってかえって洪水が起きやすくなり、1956年（昭和31）に千早町2丁目から長崎2丁目にかけて暗渠工事が完成。その後も工事が続き「河川全域が暗渠」となった**。出典は『豊島区80年のあゆみ』（豊島区／1982）〔確認：本文中の言及〕。
  - BLOG-132（地図子の読図「1964年までに暗渠化」）・Wikipedia系の年代と矛盾しない上流部（千早〜長崎）の年次具体化〔観察〕。谷端川本体の暗渠化年次問題に新たなデータポイント。
- **読図〔確認：本文〕**：谷端川は千川上水から分岐した灌漑用支流で、南北に大きくS字蛇行。椎名町駅周辺では武蔵野鉄道（現西武池袋線）が**わずか300mほどの間に谷端川を二度わたる**（金剛院・旧氷川明神女体宮〔現・長崎神社〕のある半島状丘陵をU字に迂回）。**U字型の底・最南端は真和中学（旧第四国民学校）裏門の前の道**。現在の豊島区あたりの川筋が「谷端川」、文京区に入ったあたりから「小石川」と呼ばれた〔BLOG-119『小石川區史』引用と整合〕。
- **コメント欄の聴取証言〔確認：Wayback本文〕**：
  - こだま（目白・椎名町在住年代の読者とみられる）：**谷端川は要町の粟島神社の池を水源とする「天然自然の川」で、灌漑需要の増加に伴い千川上水を引き込み水量を確保したと聞いている**〔聴取〕。記事主は「もともと自然の流れが存在した」と受けとめ、粟島神社の写真を追掲〔観察〕。谷端川の「湧水系自然河川+千川上水補水」の二重構造仮説の一次聴取資料。
  - いのうえ：椎名町では「**ドブ川**」と呼ぶ人がほとんどで、小冊子「モンパルナスそぞろ歩き」の手書き地図にもドブ川と記されていた〔聴取〕。戦前からの急激な汚染を示唆〔推定〕。
- **写真資料の所在情報〔確認：本文〕**：西池袋の氾濫写真・大塚の護岸崩壊写真は『豊島区50年のあゆみ』（豊島区）収録で、より大版の元写真は豊島区広報課所蔵〔本文中のコメント応答〕。西池袋鉄橋跡の谷端川跡遊歩道・明治43年・昭和4年の谷端川流路図も掲載〔観察〕。
- **関連〔観察〕**：コメント欄に池袋第三小学校で谷端川今昔を教材化した話（ギャラリー上り屋敷の西池袋お散歩マップ）。トラックバックに「古墳だらけの谷端川・小石川流域」「落合分水はバッケを流れ落ちた」（落合道人、2014）。
