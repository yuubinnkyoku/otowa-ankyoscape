# [BLOG-224] kasen.info「東京の河川」玉川上水(新堀用水)頁 — 新堀用水＝北側新井筋併記・市教委看板の胎内掘記載〔repo初出〕

- **取得状況〔確認〕**: 個人運営の河川データベースサイト「東京の河川」kasen.infoの玉川上水(新堀用水)頁（ページ表記の最終更新2006/02/12）。**ページはEUC-JPエンコーディングのためcurl+iconv(EUC-JP→UTF-8)で本文全文を取得**（open_urlでは文字化けして読めない）。日本河川管理コード欄付きの河川情報ページで、訪問記写真付き。
- **新堀用水＝北側新井筋の同一名併記〔確認: 頁内の名称欄〕**: 名称欄は「玉川上水(新堀用水)(たまがわじょうすい(しんぼりようすい))」とし、HTMLコメント形式で**別名「玉川上水(北側新井筋)(たまがわじょうすい(きたがわあらいすじ))」を併記**する。いずれの名称欄にも「**明治３年(1870)から供用開始**」と付す。〔**「新堀用水」と「北側新井筋」を同一水路の別名として併記するweb側記述の確認はrepo初出**。千川上水沿線の文書群に現れる「北側新井筋」（[GOV-100](../gov/GOV-100.md)各追記）が新堀用水（README既述の1870年開削水路）を指す可能性を示す資料。個人サイトであるため、より公的な資料（[BLOG-225](BLOG-225.md)の守る会頁・下記市教委看板・[BOOK-093](../books/BOOK-093.md)）との照合資料として扱う〕
- **本文記載〔確認: 頁本文〕**: ①「**明治3年(1870)4月15日から玉川上水に通船が許可され**」、本用水は「分水口の整備の一環として、この時に玉川上水の北側に掘られたもので、**千川上水までの計7つの分水口が、本用水から分水するように付け替えられた**」。②「**南側も玉川上水(砂川村)が延長され、同様に11分水口が付け替えられている**」。③「その後、玉川上水(=飲用水)の水質汚染を理由に、**明治5年(1872)5月30日で通船は禁止された**」。④「本用水は、**野火止用水の取水口の下流隣接した箇所に取水口が設けられ、そこから胎内掘(地下トンネル)で、旧小川用水の開口部まで導水されていた**。現在では、胎内掘は一部を除いて埋められてしまっている」。
- **小平市教育委員会看板（平成16年3月）の引用〔確認: 頁内の看板全文〕**: 「小川村の新田開発が**明暦2年(1656)に許可**され、最初に行われたのが小川分水を掘る工事でした。**小川村地割図(延宝2年頃)に描かれているように、分水口は現在の東小川橋付近に設けられ**、その大きさは一尺四尺(30.3cm x 30.3cm)でした。**文化4年(1807)には小川橋上流のこの地に分水口が付け替えられ、明治3年(1870)には玉川上水の北側に新堀用水(北側新井筋)が掘られます。野火止用水の取水口に接して新しい分水口が開かれ、小川分水から千川上水までの7つの分水口が埋められて1つの水路に統合されます。新しい分水口からここまでの900メートルは地下水路で、胎内掘(たいないぼり)とよばれています。**」（平成16年(2004)3月・小平市教育委員会）〔**市教委看板自体も「新堀用水(北側新井筋)」の同一名記載を使い、明治3年の北側分水口一本化と胎内掘900m地下水路を明記する**。看板の設置位置は小川橋上流の旧分水口位置と読めるが、頁本文からは座標確認不能〕
- **注意〔要判読〕**: 看板引用中の「**一尺四尺(30.3cm x 30.3cm)**」は寸法表記として内部整合しない（四尺≈121cm≠30.3cm。「一尺四方」等の誤記・転写ミスの可能性）ため、**樋口寸法の数値としては採用せず原本看板・地割図で要確認**。また「7つの分水口」は[README既述](../../../README.md)の東京都水道局説明「**野火止用水から千川上水までの9分水の取水口をまとめる**」と**分水数が食い違う（7対9）**。数え方（分水口の単位・野火止用水自身の扱い・時点差）は両資料ともに本文で内訳を明記しないため、**どちらか一方を採用せず、差異の記録として扱う**。
- **観察記録〔観察: 頁の訪問記〕**: ①野火止用水取水口の下流隣接箇所（現・小平監視所敷地）に本用水の取水口が作られていたが「小平監視所が作成されたため、その跡形はすでにない」、現在も本用水は実際に利用され玉川上水の水が流されているらしい、と記す〔伝聞含む・「らしい」との推量表現〕。②取水口から下流530m付近に「こぶのような盛り上がった部分が規則的とも思えるような間隔で出現」する観察。③「**用水 地道**」（「水道用地」か）の埋設表示の観察〔いずれも筆者の現地観察で、導水管の推測を含む〕。
- **意義〔観察〕**: README §千川上水の「明治3年（1870年）の玉川上水通船に伴い千川上水の上流側取水系統が付け替えられた」記述に対し、①**千川上水までの分水口を含む一本化の全体像（北側7分水・南側11分水）**、②**新堀用水＝北側新井筋の同一名**、③**胎内掘900m地下水路の構造**（旧小川用水開口部まで導水）という水路構造の説明を、市教委看板（2004年）・個人河川DBの二つのweb資料で確認した。ADEAC小川家文書の「北側新井筋胎内浚方」（[GOV-100](../gov/GOV-100.md)第88回追記・SZ107624）・「小川新田字山家の胎内堀の土橋障害除去請求」（同SZ107952）・明治3年「惣分水口御改正御請書写」（同SZ107882/107883）の各一次文書と対応する説明資料となる。
