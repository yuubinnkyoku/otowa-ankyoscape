# [BLOG-288] ゆる歴史散歩会「城北中央公園の歴史」〔田柄川の下流呼称「桜川」の新記録と調節池の公式数値の二次確認〕

## 内容〔確認: 本文・2026-11-22取得〕

- **書誌〔確認〕**: 散歩サークル「ゆる歴史散歩会」の解説記事「[城北中央公園の歴史｜防空緑地・石神井川・田柄川と地下調節池](https://yuru-rekishi-sanpo.com/johoku-chuo-park-history-rivers-retention-basin/)」（2026-11-02・東京・街歩き・都市史カテゴリ）。
- **田柄川の下流呼称「桜川」〔確認: 本文・repo初出候補〕**: 「**かつて練馬区を流れていた田柄川は、板橋区側では桜川と呼ばれ、石神井川へ注いでいました。現在の桜川緑道はその川を暗渠にして整備した道です。地下に水路を通したため、地上には樹木のある歩行空間が残りました。板橋区の案内では、緑道の所在地は桜川一丁目と三丁目の境とされています**」＝**①田柄川（練馬区）＝桜川（板橋区側）の下流呼称、②桜川緑道＝田柄川（桜川）の暗渠化遊歩道、③所在地＝桜川一丁目・三丁目の境（板橋区案内由来）、の3文言**〔[BLOG-278](BLOG-278.md)（田柄用水8本・上流＝枯れ川）・[GOV-460](../gov/GOV-460.md)（1931年「水田ハ石神井川・田柄川・白子川ノ沿岸」）の下流側の接続点で、**「桜川」の別称文言はrepoのgrepで初出＝対照表の田柄川系に加える候補行**〕。
- **城北中央公園の沿革〔確認: 本文〕**: 「**公園の前身は1942年（昭和17年）に計画された防空緑地です。（中略）1957年4月1日に「上板橋緑地」として開園しました。1970年から「城北中央公園」の名称になりました**」＝**1942年防空緑地計画→1957年4月1日上板橋緑地開園→1970年城北中央公園改称という公園沿革の3点**〔repo初出。石神井川・田柄川沿いの土地の戦時都市計画→公園化の経緯〕＋栗原遺跡（1955〜56年発掘・旧石器〜平安）・茂呂遺跡の言及。
- **城北中央公園調節池の数値〔確認: 本文・都建設局由来の二次〕**: 「**全体計画の貯留量は約25万立方メートル。約9万立方メートルの一期施設は2025年6月に取水を開始し、同年7月10日の豪雨では約500立方メートルを取水しました。二期工事では2026年に3号・5号のケーソン構築が進められています**」＝**①全体計画約25万㎥、②一期約9万㎥が2025年6月取水開始、③2025年7月10日豪雨で約500㎥取水、④2026年は二期の3号・5号ケーソン構築**〔同記事の参考資料欄に東京都建設局「令和7年7月10日豪雨における調節池の効果」が明記されており、500㎥の文言は[GOV-512](../gov/GOV-512.md)に一致＝**二次側の対応確認**。1号ケーソン完成時期は[GOV-087](../gov/GOV-087.md)（産経・2025年12月公開）の取材文言と一期の取水開始2025年6月の間に編年上の整理課題が残る〕。

## 意義〔観察〕

- 桜川緑道＝田柄川の暗渠遊歩道という一次的形態は、谷端川緑道・桃園川緑道と同型の「旧河川跡地の緑道化」の事例であり、暗渠遊歩道の比較系列に加わる。城北中央公園の防空緑地起源（1942）という立地史は、石神井川低地の土地利用史の新層。

## 制限・未解決

- ①「桜川」の別称は板橋区側の呼称で、絵図・地誌（新編武蔵風土記稿の田柄村条など）での確認は未実施＝近代以降の呼称の可能性もある（本文は由来を明示しない）。②桜川一丁目・三丁目の境という所在地文言は板橋区の「桜川緑道」案内由来。③調節池の2025年6月取水開始・3号/5号ケーソン構築の文言はブログ記事で、都建設局の事業案内（[GOV-087](../gov/GOV-087.md)が引用した一次系列）での直接確認が必要＝断定しない。④栗原遺跡・茂呂遺跡の詳細は本記事の外部リンク（練馬区の文化財解説）で、repoの[BOOK-254](../books/BOOK-254.md)系（武蔵野公園低湿地遺跡）と直接の関係は未確認。
