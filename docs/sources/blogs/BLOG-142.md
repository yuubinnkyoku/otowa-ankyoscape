# [BLOG-142] wanjin「千川上水」2018年・豊島区通水断念経緯と板橋浄水場の年次

- **書誌〔確認〕**: 「水の行方を追って」（わんじん）「千川上水　　　　－水の持つ機能の不思議さ－」、2018年6月13日投稿。https://wanjin.blog.fc2.com/blog-entry-249.html 。FC2現行はAccess Deniedのため **Wayback（2026-10-25スナップショット）で全文取得**（2026-11-12確認）。谷端川支流連載の間に挟まれた千川上水の総説回。
- **〔確認・二次〕 板橋浄水場の年次（表記差の記録）**: 「**1969年（昭和44年）、東京都水道局板橋浄水場が千川上水からの取水を止め、浄水場自体も廃止**されている。1970年（昭和45年）頃には暗渠化がほぼ終了…1971年（昭和46年）には大蔵省印刷局抄紙部への給水が止み…」。[BLOG-113](BLOG-113.md)（武蔵学園記念室年表）の「板橋浄水場設置1946」・「板橋浄水場（1970）」に対し、**本記事は1969年取水停止・浄水場廃止と表記**し1年の差がある。原典（都水道局側史料）での決着まで断定せず並記する。
- **〔確認・二次〕 豊島区の通水断念経緯（2018年時点の独立した二次記録）**: 「豊島区では**1991年（平成3年）に豊島区の60周年記念事業として千川上水の復活事業を行うことを決定**したものの、**暗渠管の調査を実施したところ、管内20箇所の異状、土砂の堆積、逆勾配等が見つかり**、多額な整備復旧費が必要となり、しかも都費からの支出は困難との結論が出され、結局通水を断念」。第10回ノートがWikipedia（Weblio複製）経由で記録した内容（平成4年度暗渠管調査・20箇所異状・都費支出困難）と同一の経緯を**2018年時点の個別ブログでも独立に記述**しており、二次情報の広がりを裏付ける。原典（豊島区の調査報告書）の特定は引き続き課題。
- **〔確認・二次〕 そのほかの年次**: 1982年（昭和57年）都の「マイタウン東京」構想で野火止用水・玉川上水・千川上水の清流復活事業が計画→1989年（平成元年）**開渠部約5kmに下水処理水等を活用した清流が復活**（[GOV-056](../gov/GOV-056.md)等の既知情報と整合）。「約5km程度なため清流が再生されていない区もある」。
