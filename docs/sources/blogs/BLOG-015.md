# [BLOG-015] 大塚5丁目3番・5番境界の階段（No.310）

- 東京階段学会調査部、2025年8月11日公開、2020年11月7日撮影。[原記事](https://stairs23.blog.fc2.com/blog-entry-3777.html)。
- 文京区大塚5丁目3番と5番の間。「水窪川」暗渠に面した5丁目5番を囲む境界道の階段と記載。
- 「マンション小石川台」との間を北向きに上る階段No.310。筆者記載の高低差は**約2.8m**。近傍の5丁目4番・6番境界にNo.311があると記載。
- **直接確認したのは公開記事の本文・撮影日・筆者の概数。** 高低差の測定方法・測点・標高基準は不明。原河道との位置合わせは未実施。写真は転載しない。
