# [BLOG-067] 一朴洞日記「名残の湧水」

- **書誌**: 一朴洞（多岐祐介、1949年生・池袋在住の回想記）、はてなブログ、**2025年6月19日**。https://takiyusuke.hatenablog.com/entry/2025/06/19/145141 。2026-11-11全文取得確認（第1回でアクセス遮断が記録されていたブログの新規エントリ取得）。
- **〔観察: 2025年時点〕** **千早公園（豊島区千早）には自然の高低差を利用した流水と池があり、「水が湧いているのだ」（人手による汲みあげ流水ではない）**と記す〔粟島神社弁天池の約100m東側の公園湧水の2025年現況観察＝repo初出〕。粟島神社と千早公園の流水の間には中学校運動場と区役所分庁舎があり、気づきにくいが**約100mの距離**。
- **〔観察〕** 粟島神社境内の池（亀が甲羅干し・「亀や魚を捨てないでください」の立札）。「湧水口がどこでどうなっているのか、私は知らない。おそらく容易には観られないかたちにしてあるのだろう」— **湧水口の現況は未観察**。
- **〔記事の理解＝二次情報〕** 「ここ粟島神社が谷端川の水源とされる。**近くを通る千川上水の分流がこの地の湧水と合流し、ここから谷端川となる**」〔長崎分水→粟島神社弁天池という既存repo理解と同じ構造を、地元在住者が2025年に記述。千川上水の流路（江古田→大山→中山道板橋）・谷端川の別名千川・中村橋の由来にも触れる（いずれも既知と整合）〕。
- **〔観察・推定〕** 谷端川の流路の回想: 西武池袋線の線路下を通過したところで東へ、数百メートル先で北へ、「いろは坂のごとく極端に蛇行」。西池袋あたりでは遊歩道、自宅界隈ではメインストリートの商店街。**拙宅の敷地も河川敷の傾斜地に戦後盛土して宅地造成されたのだろう**（筆者の推定）。
- **〔参考〕** 旧「アトリエ村」（池袋モンパルナス）の回想: 農村の川の畔に安く住める場所があるということで大正〜昭和前期に美術家が住んだ（千家元麿・熊谷守一）。**川沿いの芸術家村成立の地形因についての回想的説明**。
- **〔制限〕** 回想・推定を多く含む。湧水・池の現況は2025年6月の筆者観察であり、湧出量・湧水点の位置の裏取りは別途必要。
