# [BLOG-017] 2020年の千川通りの路面と下水道工事に関する住民記録

- 筆者maruhotei、**2020年12月1日16:32公開**。[原記事](https://maruho.exblog.jp/28327306/)。
- 筆者は、**文京区のこんにゃく閻魔交差点・えんま通り商店街付近の千川通り**について、車道中央の盛り上がりと歩道の傾斜を記述し、写真に言及する。**現況は筆者の2020年の観察であり、実測断面・写真の個別測点は未確認**。
- 東京都第六建設事務所・東京都下水道局に問い合わせた結果として、筆者は当時、**豊島区側から窪町東公園に向けて地下約40mでバイパス工事が進み、当時の見込みではその工事に約6年、後に旧暗渠内の新管築造と路面平坦化を行い、全体で10年以上かかる**との説明を受けたと記す。**行政機関の公表・回答原本ではなく、筆者による伝聞**。
- 筆者は車道の隆起を旧暗渠両側の地盤沈下（地下水揚水によるもの）で説明しているが、**地盤調査・水準測量・工事図面に基づく実証は記事中で確認できない**。工事の名称、深度・区間・工期・実施状況は行政の一次資料で要照合。**2020年の将来見通しを2026年の現行計画とみなさない**。
