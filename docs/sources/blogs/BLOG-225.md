# [BLOG-225] 玉川上水事典「新堀用水」頁（小平市玉川上水を守る会編）— 胎内堀の構造と惣分水口御改正の説明〔repo初出〕

- **取得状況〔確認〕**: 「玉川上水事典」HP（moguratushin / tamagawajitenHP、庄司徳治コレクション由来の玉川上水解説サイト）の「新堀用水」頁。頁頭に「**小平市玉川上水を守る会編『新堀用水』**」とあり、同会の解説を転載・再構成したページと読める（成立年は頁上に記載なし・[第39回ノート](../../2026-11-12（第39回）・miwa3k千川上水全線・平尾邸大池水源説・水道端大谷口の追加調査.md)で同サイトの千川上水頁は「文字コード不一致で本文抽出不能」だったが、**今回Shift_JIS（cp932）デコードで新堀用水頁の本文全文取得に成功**した〔本文取得手法: curl→Python bytes.decode('shift_jis', errors='replace')〕）。
- **通船史〔確認: 本文〕**: 「玉川上水を利用して、物資を運ぶ通船事業は**元文、明和、慶応年間３回に亘って出願したが、いずれも幕府からは許可されず明治２年(1869)９月の出願が維新政府によって認可された。通船は明治３年(1870)４月から２年間ではあったが、荷船の運行に伴い橋の架替えや分水口の整備、船留の新設等の工事に着手する**ことになった。」〔明和年間の出願に対応する小川家文書「玉川御上水通船仕用目論見帳」（明和7年閏6月・[GOV-100](../gov/GOV-100.md)第88回追記・SZ109835）の存在と対応する説明〕
- **文化4年付け替えと胎内堀の構造〔確認: 本文〕**: 「**小川橋上流120（メートル）左岸に文化４年(1807)２度目の分水口を小川家文書『玉川御上水通村々惣分水口御改正御請書写』記載の通り、野火止用水堰の右隣りに付替え、新水路は胎内堀(シールド工法)といって残土排出口の穴を60ヵ所掘り、双方から掘り進み、900（メートル）先の小川用水路の開渠口に繋いだのである。この新堀割水路が「新堀用水」である。**」〔**守る会の説明が小川家文書『玉川御上水通村々惣分水口御改正御請書写』を典拠として挙げる**＝ADEAC小平の同名文書（[GOV-100](../gov/GOV-100.md)第88回追記・**SZ107882/SZ107883**・明治3午年4月・25か村／28か村連署）と題名が一致。ただし本頁の「文化4年(1807)付け替え」と明治3年の新堀用水開削の文脈が一つの文で連結されており、**どの工事がどの年の出来事かの解釈は本文表現が連続的で断定できない**（[BLOG-224](BLOG-224.md)の市教委看板は文化4年付け替えと明治3年開削を別個の事象として記す）〕
- **分岐堰・盗水防止説・一本化〔確認: 本文〕**: 「**小川橋北詰下には小川用水と新堀用水との分岐堰がある。**分水口整備理由の一つには、**盗水を防止することにあったとも云われている**。従って、**北側の７分水は新堀用水に、南側11分水は砂川分水(深大寺用水)にそれぞれ一本化された**。」〔北側7分水の新堀用水一本化は[BLOG-224](BLOG-224.md)（kasen.info・市教委看板）と一致。「盗水防止説」は「とも云われている」との伝聞表現〕
- **運用と区間定義〔確認: 本文〕**: 「なお、新堀用水は自然流下のため、**常時水位は底部から1.6（メートル）以上保たないと送水が出来ない**のである。**監視所内の送水口から桜橋までの5.5kmを新堀用水という。**」〔**新堀用水の区間定義（小平監視所内の送水口→桜橋・5.5km）の文言はrepo初出**。桜橋の位置・地先は本頁に記載がなく未確認。 kasen.info（[BLOG-224](BLOG-224.md)）の「現在も本用水は実際に利用されるため、玉川上水の水が流されているらしい」との観察と対応する運用記述〕
- **意義〔観察〕**: ①**胎内堀の構造**（残土排出口の穴60か所・双方から掘進・900m先の小川用水路開渠口へ接続）という具体的な工事方法の説明は、ADEAC小川家文書の「北側新井筋胎内浚方諸入費一時立替金受取」（明治8年・SZ107624）・「小川新田字山家の胎内堀の土橋障害除去請求」（明治36年・SZ107952）の一次文書と対応する説明資料〔本文未確認のため、文書の内容がこの工事のどの段階に当たるかは断定しない〕。②**「玉川御上水通村々惣分水口御改正御請書写」への言及**により、同文書（SZ107882/107883）が守る会の新堀用水説明の典拠であることが分かる。③南側11分水の「砂川分水(深大寺用水)」一本化の文言は、北側（新堀用水＝千川上水方面）と対の整理としてrepo初出。
- **注意**: 「シールド工法」という表現は明治3年当時の用語ではなく、**現代の読者向けの比喩表現**と読めるため、当時の工法名としては採用しない。「桜橋」の比定（小平市内のどの橋か）・文化4年分水口の位置と野火止用水堰の位置関係の確定は未確認。
