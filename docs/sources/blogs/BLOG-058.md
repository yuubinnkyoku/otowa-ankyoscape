# [BLOG-058] 谷端川沿い湧水ものがたり　わきみず通り

- **直接確認（2026-11-11、open_url・本文全文）**：シリーズ第3回。祥雲寺下の洗い場と「わきみず通り」支流を扱う。
- **祥雲寺下の洗い場〔観察〕**：北上する谷端川が有楽町線を北に渡ったあたり、祥雲寺の下に**湧水が溜まる洗い場**が現存し、昔の写真でもほぼ同形の洗い場が確認できるという。〔紀要11号の古写真との比較観察〕
- **わきみず通り支流〔観察〕**：谷端川への合流部から遡り、**板橋区南町を掠め、山手通りを越え、高松2-22付近で再び細い暗渠道**となる。「わきみず通り」の名が残る道で、高松小学校の横が湧水地点。
- **紀要第11号からの引用〔確認：引用文〕**：「**高松小学校の西側に湧水が出て、ほぼ東に流れて谷端川に注いでいた。小川には農家ごとの洗い場があり、野菜や農具を洗った。川幅は0.5～1mくらいで、戦前まで使われていたという。足のあるウナギの伝承（ウナギを獲ったり食べたりすると死ぬという）がある。現在は暗渠となり『わきみず通り』と呼ばれている**」。
- **repoへの関連**：わきみず通りの支流位置・川幅・戦前までの利用はrepo初出。[BLOG-055](BLOG-055.md)（露塚散・東京路地紀行111）が記録した池袋〜板橋区南町の支流暗渠（ときわ通り坂下〜南町手前で谷端川緑道に合流）との異同は**未解決**（合流部の位置が近いが、わきみず通り支流は南町を西へ抜けて高松方面へ向かう）。
