# [BLOG-053] 「千川上水調節池跡」豊島区教委説明板の転記

- **直接確認（2026-11-11、open_url・本文全文）**：2012年8月21日の記事で、**豊島区教育委員会の現地説明板「千川上水調節池跡」**（所在地＝**豊島区西巣鴨2-39-5（千川上水公園）**、**平成16年（2004）3月設置**と読める）の全文転記。説明板内容は以下二次転記。
- **説明板の内容〔二次転記：区教委説明板〕**：千川上水は**元禄9年（1696）**、小石川白山御殿・湯島聖堂・上野寛永寺・浅草寺御殿と下谷・浅草方面の飲料水確保のため玉川上水を分水。のち近隣農村の農業用水にも利用。**上水はここにつくられた溜池（沈殿池）で砂やごみを沈殿させた後、木樋や竹樋の暗渠となって江戸市中へ給水**された。この付近を「堀割」と呼ぶのは、**慶応元年（1865）に幕府が滝野川村に建設した反射炉の水車利用のため、王子方面への分水（王子分水）を開削する際に堀をつくったことに由来**する。**明治13年（1880）、岩崎弥太郎らが設立した千川水道株式会社**により本郷・小石川・下谷・神田方面への給水が再開されると**王子分水との分配堰が設けられた**。明治通りの向かい側（**北区滝野川6-9**）には水利関係が刻まれた**「千川上水分配堰」の碑（明治15年建立）**が残る。公園側には分配堰の落し口があり、**沈殿槽からの水量調整**を行っていた。**公園内には駒込六義園方面への送水に使用していたバルブ（巻揚器）が現在も残る**。
- **repoでの位置づけ〔推定〕**：沈殿池（[GOV-065](../gov/GOV-065.md)の水道局目録解説・[GOV-040](../gov/GOV-040.md)）・分配堰碑明治15年（[BLOG-043](../blogs/BLOG-043.md)）・千川水道株式会社・巻揚器（[GOV-061](../gov/GOV-061.md)）は既出だが、**「堀割」呼称の由来を1865年の反射炉用水・王子分水開削に求める説明**、**王子分水という分水系統**はrepo初出。〔二次転記／説明板の現地での直接採録は今後の課題〕
