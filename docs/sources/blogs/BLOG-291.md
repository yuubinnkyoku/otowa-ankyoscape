# [BLOG-291] PublicTransportDiary「間もなく消える保存蒸気機関車C58 407号機」〔大塚台公園の展示SLの同定と撤去報の二次報道〕

- **書誌〔確認: ブログ本文全文・2026-11-23取得〕**: 「PublicTransportDiary」（鉄道保存車両を対象とする個人ブログ・著者名表示「矢的カズヒデ」）。**投稿日2026年10月27日20:00・カテゴリ「国鉄」**。 https://publictransport1014-920.blog.jp/archives/15493807.html 。
- **本文の要旨〔確認: 本文・文言〕**: 「**1946年(昭和21年)に新製以来引退まで北海道で活躍し、廃車後は東京･豊島区の大塚台公園で静態保存展示されましたC58 407号機が、老朽化や保存場所のリニューアルにより2026年内に撤去され、解体処分されることになりました**」「**函館機関区にて新製配置され、五稜郭機関区配置時に廃車となり、現役時代は北海道で運用**されました」「**引退後に国鉄から東京･豊島区に無償貸与され、以来大塚台公園にて保存･展示**」「50年以上に渡って展示されましたが、近年手入れが施されておらず劣化も進んでおり、維持も困難となり解体撤去処分されることになりました」「**展示開始当初は屋根や柵が無かったそうですが、後年設置されました**」〔説明板①②の転写も添えられる〕。写真＝2026年10月撮影の本体・劣化した機関室（キャブ）・現在の上屋・金網フェンス。
- **形式・車歴の観察〔確認: 本文文言・二次情報〕**: **形称号「C58 407号機」・1946年（昭和21年）新製・北海道（函館→五稜郭）で現役・廃車後に国鉄から豊島区へ無償貸与**＝大塚台公園の展示蒸気機関車（区公式ページでは無称号の「展示蒸気機関車」〔[GOV-519](../gov/GOV-519.md)〕）の同定情報〔形称号・車歴は機関車表・資料集由来の二次転記の可能性があり、国鉄・区の一次文書との照合はしていない〕。「50年以上」の展示＝**池袋タイムズ「1974年（昭和49年）に北海道から運ばれてきた」〔[BLOG-290](BLOG-290.md)〕と整合的な幅**〔50年(=2024年超)・1974年設置の別文言・断定しない〕。
- **撤去・解体処分の文言〔確認: 本文・二次報道〕**: 「**2026年内に撤去され、解体処分される**」＝**リニューアル工事（2026-11-18全面閉鎖・トイレ以外全解体〔[GOV-520](../gov/GOV-520.md)〕）の時系列に合致した撤去報**〔区・国鉄側の公式撤去決定文書の所在は未確認・区ページに撤去文言の明示も現時点では未確認＝断定せず「撤去報の二次伝達」として記録〕。
- **意義〔観察〕**: ①**南大塚3丁目（谷端川流域・[GOV-519](../gov/GOV-519.md)）の公園内の鉄道保存車両が2026年内に消える**という土地付帯物の変化の記録（撤去済みかどうかの実況確認が今後の現地観察点）。②**新ウォーターパーク遊具（[GOV-521](../gov/GOV-521.md)）の「蒸気機関車をモチーフ」設計**と撤去機の意匠継承の構図を、保存時の原状（屋根・柵の後年設置）と併せて並べられる＝機関車の記憶の移転先の設計意図の議論の資料〔設計側が意匠継承を公言した文言はまだ確認していない〕。
- **制限・未解決**: ①C58 407号機の形称号・車歴（1946年新製・函館・五稜郭・無償貸与）は**鉄道側の二次情報**＝沖田祐作「機関車表」等の原典・区の寄託文書との照合が次課題。②「2026年内撤去・解体」は報道文言で、公式文書での裏付け・撤去実施日の追跡はウォッチリスト。③「展示開始当初は屋根や柵が無かった」は伝聞（「そうですが」）。
