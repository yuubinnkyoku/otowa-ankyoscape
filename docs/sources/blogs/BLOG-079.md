# [BLOG-079] 暗渠となった文京区・小石川の跡探索

- **直接確認（2026-11-11、open_url・本文全文）**：2022年6月25日投稿の街歩き記事。小石川植物園前の共同印刷本社（[ORG-001](../org/ORG-001.md)・[ORG-002](../org/ORG-002.md)参照）を起点に千川通り・簸川神社・猫又坂を歩く。
- **共同印刷本社前のベンチ銘板〔確認：現地設置物の転記〕**：「**本郷台と豊島台の間を流れる川は礫川とも書き、小石の多い川であったことが小石川の由来。小石川は昭和9年（1934）に埋め立てられ暗渠になった。埋め立てられた小石川の上を通っている道路が、現在の千川通り**」。〔「礫川」表記の現地設置物での実例。1934年暗渠化の再裏付け〕
- **猫又橋親柱の袖石の解説板〔確認：文京区教委設置物の全文転記〕**：**むかし木の根っ子の股で橋をかけたので「根子股橋」と呼ばれた**、江戸の古い橋で伝説的に有名、『続江戸砂子』の狸・猫貍説話。**大正7年（1918）3月、この橋は立派な石を用いたコンクリート造りとなった**。千川はたびたび増水して水害→**昭和9年（1934）千川は暗渠になり道路の下を通るようになった。石造りの猫又橋は撤去されたが、地元の故市川虎之助氏（改修工事相談役）はその親柱と袖石を東京市と交渉して自宅に移した。ここにあるのは袖石の内2基**、袖石に刻まれた歌「騒がしき蛙は土に埋もれぬ　人にしあれば　如何に恨まん」は同氏の作。〔**根子股橋（猫又橋の別名説）・大正7年改築・昭和9年撤去・市川虎之助による親柱・袖石の移転保存・袖石2基の現存・短歌はいずれもrepo初出**。[BLOG-070](BLOG-070.md)の猫又橋親柱の観察に橋の実体史を追加する〕
- **千川の田園風景の記憶〔確認：解説板〕**：昭和のはじめまではこの川でどじょうを取り、ホタルを追って**稲田（千川たんぼ）**に落ちたなど、古老がのどかな田園風景を語っている。〔「千川たんぼ」呼称の実例。BLOG-077・078の氷川たんぼ（氷川田んぼ）と同区域の俗称とみられるが断定しない〕
- **簸川神社境内の施設〔確認：境内案内の転記〕**：境内施設一覧に**「取水舎」「水神社」「白宝稲荷」**が含まれる。〔**簸川神社境内の「取水舎」はrepo初出**。氷川田んぼ・千川時代の神社境内での水利用（取水）の痕跡候補だが、由来は本記事では説明されておらず、設置年代・対象水域は未確認〔仮説〕〕
- **猫又坂解説板〔確認〕**：不忍通りは大正11年（1922）頃開通、昔の坂は東側の崖の縁を通り千川にかかる猫又橋につながっていた（[BLOG-070](BLOG-070.md)と同一の解説板。※記事内の「大正１１年（１９９２）」は誤植）。
- **制限〔未解決〕**：市川虎之助・根子股橋の記述は解説板の転記に依存し、行政文書での確認は未実施。取水舎の由来・年代は未確認。
