# [BLOG-259] Natrium.jp「桃園川の水路敷群」（桃園川本流・末広橋〜上流端・その1/その2・三味線橋〜高円寺橋・その1/その2・高円寺橋〜阿佐ヶ谷駅・阿佐ヶ谷駅〜上流端・その1/その2）〔repo初出・全6頁一括。BLOG-254目録では「本流7頁」と計上されていたが全取得の結果6頁（4題・うち2題は2分割）で、計上差はノートに記録〕

- **書誌〔確認: 本文全文6頁・2026-11-22取得〕**: ①「末広橋〜三味線橋」・②「三味線橋〜高円寺橋」その1・③その2・④「高円寺橋〜阿佐ヶ谷駅」・⑤「阿佐ヶ谷駅〜上流端」その1・⑥その2。写真は2020/8/2・8/10・8/15・8/23・8/30・11/7・12/6・12/12・12/26・2021/1/2・6/20追記・2025/3/26ほか〔[GOV-493](../gov/GOV-493.md)（桃園川緑道の公式公園史）の 散歩側全線観察〕。
- **神田川合流形態の変遷〔確認・観察文言〕**: 「現在は南から北に向かって流れる神田川に西から流れてきた桃園川がほぼ直角にぶつかっているのだが、**古くは西から来た桃園川と東から来た神田川がここで合流して北へ向かっていたらしい**」〔桃園川・神田川の合流点形態変遷の観察文言。水窪川・弦巻川の神田川合流構造と対照可能な桃園川側の記録〕。
- **橋梁の遺構観察群〔確認・観察〕**: ①**庚申橋遺構**: 旧流路上に「**扁額には「かう志んはし」とあり、旧桃園川に架かっていた庚申橋の遺構**」（桃花小学校脇・道路の片側だけに取り残された欄干）。②**桃園橋**: 「親柱の扁額に**昭和11年（1936年）完成**」の鋼鉄桁。**※2021/6/20追記: 中野通りの拡張工事に伴い桃園橋は2021/4から解体。橋桁ごと撤去され、下水道の「桃園川幹線」のためにボックスカルバートを埋設して完全に暗渠化。親柱や欄干はいったん都有地で保管されるが、保存されるかどうかは未決定**〔[GOV-493](../gov/GOV-493.md)の桃園川幹線と直接対応〕。③**田替橋**: 「**川の氾濫で田んぼの位置が替わったから**だとか」（欄干は緑道整備時に切り取られ・親柱は残存）。④**金剛橋**: 昭和32年（1957年）の親柱。「昔は近辺に青面金剛庚申塔があったのかもしれない」。⑤**宮園橋**: 「大久保通りを古くは**宮園通りと言っていた**ことによる」・**昭和7年（1932年）完成**。⑥**高円寺橋**: 「**東京オリンピックに合わせて昭和39年（1964年）環七が通るまでこの場所に橋はなかった**」＝比較的新しい橋。ほか末広橋・小淀橋・睦橋・戸井橋・立田橋・宮下橋・塔ノ下橋・東雲橋・宮前橋・宝仙橋・金渓橋・慈眼堂橋・仲園橋・北裏橋・三味線橋・上町橋・箱堰橋・御伊勢橋・上宮橋・北畠橋・橋場橋・公園橋・中山谷下橋・中山谷橋・中島橋・西山谷小橋・西山谷橋・西山谷上橋・氷川橋・氷川小橋・宝下橋・宝橋・八反目橋・八反目上橋・内手橋・西原橋・馬橋など、**橋名親柱・扁額・欄干の残存状況の実測観察27橋超** 〔桃園川橋梁の一次観察記録としてrepoの橋梁レーンの基礎資料〕。
- **地名・神社群の由来文言〔確認〕**: ①**桃園**: 「**八大将軍徳川吉宗が鷹狩りのおりにこのあたりに桃を植えさせよと言った**のだとか。その場所は元は五代将軍徳川綱吉の生類憐みの令で設けられた野犬の保護施設である『**お囲い御用屋敷**』があった場所」。中野通り西側（明治大学中野キャンパス）は「古くは徳川綱吉が**犬屋敷（お囲い御用屋敷）を建てたあたりで、旧町名を囲町**といった。**その後陸軍電信大隊**などが施設を構え、**戦後は警察大学校**などがあった」。②**塔ノ山**: 「中野坂上交差点近くの旧第十中学校あたり（**旧宝仙寺飛地**）に存在した**三重塔**が塔ノ山の由来。三重塔は**寛永13年（1636年）に建てられたが、昭和20年（1945年）の空襲で焼け落ちてしまった**。三重塔は現在、宝仙寺境内に再建」。③**中野氷川神社**: 「**長元3年（1030年）創建と伝わる**古い神社で、**旧中野村の総鎮守**」・宮下橋の名は「北側にある氷川神社の坂の下にあることを意味する」。④**高圓寺**: 「**弘治元年（1555年）創建**と伝わり、徳川家光が鷹狩の際に休憩所として利用」。⑤**気象神社**: 高円寺氷川神社境内にあり、「**現在は馬橋公学校と馬橋公園になっている場所にあった陸軍気象部に祀られていたものをここへ遷した**」。⑥**天沼八幡神社**: このあたりの旧字名を**中谷戸**といい、**天正年間（1573〜1591年）創建**と伝わる。
- **馬橋＝住居表示で消滅した大字〔確認・repo初出候補〕**: 「このあたりは古くは**馬橋村**であり、一つ前の**内手は合併した杉並村時代の小名（字）**だったそう（馬橋稲荷神社サイトより）。**昭和37年（1962年）の住居表示で消えた馬橋の領域は早稲田通りから五日市街道まで広がっており、現在の梅里、高円寺北、高円寺南、阿佐ヶ谷南のそれぞれ一部**となっている。**かつて中央線の中野・荻窪間に馬橋駅を置こうという運動もあった**」〔江戸〜昭和の馬橋村が住居表示で解体された範囲と現在町名への分配の一級文言。馬橋駅運動の記録も初出〕。
- **天沼水源と上流端〔確認〕**: 「**桃園川本来の主な水源は地図左上の天沼弁天公園近辺もしくはその西側にある天沼西公園にあったとされ、青梅街道を流れていた六ヶ村分水から導水するために最上流部が延長されている**」〔**六ヶ村分水分岐で最上流部を延長したという構造文言**＝自然水源（天沼弁天池or天沼西公園）と人工延長部（六ヶ村分水）の二層〕。**天沼弁天池公園**: 「西武ゴルフ研修所の跡地に作られ」「**もともと公園南側に弁財天を祀った池があり、桃園川の水源となっていたというが、宅地化により湧水は涸れてしまった。現在の池は人工的に作られたもの**。**天沼という地名の由来となったともいうが、天沼の由来には諸説ある**」。**天沼西公園**: 「**こちらの方が元々は桃園川の源流だったという説もある**」。最上流部は遊歩道が青梅街道まで続き「**青梅街道を流れる六ヶ村分水から分かれた桃園川のここが最上流**」〔[BLOG-249](BLOG-249.md)・[BLOG-250](BLOG-250.md)・[BLOG-257](BLOG-257.md)・[BLOG-260](BLOG-260.md)の六ヶ村分水系と桃園川の接続点の実走〕。**松山通り**は「かつて**鎌倉街道阿佐ヶ谷道**として永福町の大宮八幡宮と笹目橋近くの早瀬の渡しを結んでいた」〔古道系の追加文言〕。
- **旧流路の蛇行〔確認・観察〕**: 塔ノ下橋南側（中野坂上方向の谷筋）・公園橋南（大きく南に蛇行）・上町橋・金渓橋上流（崖にぶつかって北に逸れた）・中島橋（改修前はやや南）などで**改修前の旧流路の位置観察**。桃園橋〜杉山公園間の地籍図水路敷（中野通り西側歩道付近）の 2025/3/26 追記観察もある。
