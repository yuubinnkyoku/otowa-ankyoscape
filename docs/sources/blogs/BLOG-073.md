# [BLOG-073] 池袋地名の由来「丸池」

- **直接確認（2026-11-11、open_url・本文全文）**：[BLOG-051](BLOG-051.md) と同一作者（toshima_lab）。引用元の『かたりべ』45号PDF（豊島区立郷土資料館）はopen_url不可（2026-11-11）のため、引用文は同noteの書き下ろし転記に依存する。
- **『遊歴雑記』（文化11年／1814）〔二次転記：「かたりべ」45号経由〕**：「**当村を池袋と号けし事ハ、往古夥しき池ありしによってなり。中古より段々と埋まりしかど、今もなを三百余坪もあらんや**」〔**repo初出の江戸期原典**。丸池（と夥しい池）が池袋村の村名の由来とする江戸期の記述。1814年時点で「三百余坪」が残っていたと読める〕
- **『高田町史』（昭和8年／1933）200頁〔二次転記〕**：「**鶴巻川と水源の丸池**」—「雑司谷浅井原の**池谷戸**なる鶴巻川の水源である處を丸池と云ひ、池は清水で絶えず湧き出でて河に流れた。今は鉄道教習所の構内となり、石囲いの水溜となつて居るが、大正時代の初期までは付近の子供達が水泳して居た。昔は此の池から湧き出る水が滾々として流れ…源義家などが、此の川で戦ひ、**弓の弦を巻いた**事もあるので、弦巻川と稱呼が起こつた…」「昔は蛍の名所で（略）…今は其の池の水は、鉄道教習所埴土の残飯残肴の棄場となつて、濁水漲ぎり…悪臭鼻を撲ち」〔**『高田町史』（1933）はrepo初出の書誌**（[GAZ-014](../gazetteers/GAZ-014.md)『高田村誌』1919とは別書）。**「池谷戸」「浅井原」の地名呼称はrepo初出**。「弦巻川」を「鶴巻川」と書いた昭和初期の表記例、丸池の近代の水質悪化・縮小過程（蛍の名所→汚水）を生々しく記す。BLOG-063（文春シリーズ）の丸池・東武鉄道土地史と相互補強〕
- **大正期の丸池写真の所在〔確認：ADEACリンク〕**：成蹊実務学校時代（大正7年頃）の丸池写真が豊島区アーカイブ（[adeac viewer mp105000/toshima50th/11](https://adeac.jp/toshima-history/viewer/mp105000/toshima50th/11)）で閲覧可能と記す。〔viewerはopen_urlで本文取得不能。**丸池の大正期写真の所在特定**として次回の現物確認課題〕
- **丸池の村帰属〔二次転記：「かたりべ」45号経由〕**：「池袋村は土地が高くて池水を引くことができず、土地の低い雑司ヶ谷村に池の湧き水が弦巻川となって流れ出ていたため、**雑司ヶ谷村の用水として使われるようになり、池の掃除や泥さらいなどを同村がおこなうようになった**からだといいます」。2025-02-20追記で**豊島区史（資料編3巻）に該当記述を確認**（[adeac mp120030/tosimas3/569](https://adeac.jp/toshima-history/viewer/mp120030/tosimas3/569)）とする〔**丸池が雑司ヶ谷村帰属（1772年絵図、MAP-003）である理由づけの民俗説明**。移管の年代・文書は不明〕
- **池袋村絵図の上流流路〔観察：読図指摘〕**：「丸池のさらに上流に湧水地があったと思われる。**池袋村絵図では現在の立教通り辺りに橋と流れが描かれている**。これについて語られている資料を見た覚えがない」〔**丸池上流（弦巻川最上流部）の流路を描く読図指摘**は [BLOG-052](BLOG-052.md)（西池袋公園＝谷頭説）・[BLOG-075](BLOG-075.md)（時層地図読図）と調和する方向〕
- **その他〔二次転記：「かたりべ」3号経由〕**：「イケブクロという呼称は先に開発が進んでいた雑司ヶ谷地域の人々が**自分たちの生活用水の源地方を指して呼んだ**ものが地名化したのかもしれない」〔外部呼称説の紹介〕
- **制限〔未解決〕**：『遊歴雑記』『高田町史』豊島区史とも原本画像・原本未確認。「池谷戸」「浅井原」の位置特定も未実施。
