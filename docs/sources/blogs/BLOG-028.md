# [BLOG-028] nippon.com「池袋（JY13）：ホテルメトロポリタンあたりにあった農業用水の水源『丸池』が駅名の由来」

- **書誌〔確認：2026年11月9日に実際に閲覧〕**：nippon.com、2024年5月10日付の記事。https://www.nippon.com/ja/japan-topics/c13306/ 。『遊歴雑記』（文化年間）の池袋村記事を紹介する二次資料。
- **内容メモ（どこに何が書いてあるか）〔観察〕**：
  - 丸池について『遊歴雑記』をもとに、当時なお**300余坪**の池が残り、水が常に湧き出して雑司ヶ谷方面へ流れていたと紹介する。
  - 掲載図（東京都公文書館所蔵「池袋村図」の複製）のキャプションは「**丸池は現在のホテルメトロポリタンのあたり。弦巻川は現在は暗渠となっている。**」。丸池旧位置の二次的な座標アンカーになる。
  - この流れを農業用水として使う権利を持っていたのは**雑司ヶ谷村の村民**で池袋村側ではなかったとする（池袋村は高台で丸池の水を引けなかったため）。
  - 掲載の「池袋村図」は東京都公文書館目録では「池袋村図（帙書：江戸各郷村図 坤）」彩色原図・93×118cm・資料ID 000100349（[MAP-018](../maps/MAP-018.md) 関連）。**図には現代の道路名がなく、単独では現在地への精密な位置合わせはできない**。
- **留保〔留保〕**：『遊歴雑記』原本の該当頁は未確認のため水利関係の細部は二次引用として扱う。ホテルメトロポリタン比定は記事キャプションによる二次的な目安であり、丸池旧位置の確定ではない。
