# [BLOG-102] Natrium.jp 千川上水（関町〜井草）

## 書誌・確認範囲

- Natrium.jp「水路敷を行く」千川上水シリーズ第1頁。写真は2011年9月17日・2013年4月13日/4月20日・2018年1月3日撮影。2026-11-11に open_url で本文全文を取得確認。**Natrium.jpの千川上水シリーズ（canal_lot/josui/）は本頁がrepo初出**（既登録の谷端川系11頁 [BLOG-081](BLOG-081.md)〜[BLOG-088](BLOG-088.md)・[LOST-004](../lost-web/LOST-004.md) とは別シリーズ）。

## 内容メモ

- **〔確認: ページ冒頭の概説〕** 千川上水は境橋（武蔵野市・西東京市境）で玉川上水から分かれ、練馬区・板橋区・北区を抜けて豊島区巣鴨の千川上水公園まで。**元禄9年（1696）完成、享保7年（1722）に農業用水専用とされた**と概説。
- **〔観察: 2013年〕** 青梅街道沿いの千川上水西側に**「関のかんかん地蔵」（正徳元年1711年造立）**。石で叩いて願をかける信仰で台座がやせ細ったと説明〔repo初出の石造物〕。
- **〔観察〕** 水道端バス停の前に稲荷神社。下流方向の都道439号（千川通り）拡幅工事中の記録（2013年）。
- **〔観察〕** **青梅街道の南側が開渠となっている千川上水の末端部分**。「ここまでは江戸時代の千川上水の姿をとどめている」〔[GOV-072](../gov/GOV-072.md)（練馬区・開渠残存区間）の末端側観察と整合〕。青梅街道の歩道脇に**「伊勢橋」という扁額のある欄干が残存**〔橋の遺構観察。下石神井〜上石神井間の伊勢橋。名称対応は要整理〕。
- **〔観察: 2011年〕** 西武新宿線の下をくぐる**千川上水橋梁。線路下ここだけ上水が開渠**で「千川上水の流れが見られるのはここが最後」〔[BLOG-090](BLOG-090.md)（本田創・約35m開渠）・[GOV-072](../gov/GOV-072.md)（線路下20m余り開渠残存）と独立の観察で整合〕。
- **〔観察〕** 上石神井一丁目のマンション前に無造作に置かれた石臼（付近の水車の石臼ではないかという説として紹介）〔千川上水の水車（[BLOG-094](BLOG-094.md)の明治17年8水車等）の周辺資料候補。同定は未確認〕。
- **〔観察〕** 下石神井一丁目の**青面金剛庚申塔（元禄13年1700年）・馬頭観音（宝永3年1706年）**、向三谷（旧字名）の武蔵御嶽神社（下津宮向三谷講御社の扁額）など、千川通り沿いの石仏・祠の記録。上井草駅近くに馬頭観音文字塔。
