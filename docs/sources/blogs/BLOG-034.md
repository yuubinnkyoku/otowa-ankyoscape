# [BLOG-034] 雑司が谷と鬼子母神（磯昭三記）

- **二次転記（2026-11-11）**：ページ本文は文字化け（UTF-8/CP932混在）で読み取り不能だが、検索結果の抄録と断片から**八代将軍吉宗が放鷹でこの地に来た際「雑司が谷村と書くべし」といわれてからと伝えられる**こと、**「谷」とはこの地に池袋の丸池を水源とした弦巻川が流れ、北西から南東に開けた谷であったこと**、鬼子母神門前の職人（大工）の暮らしを豊島の大工磯昭三が記した記事であることが確認できる。
- **意義〔観察〕**：**弦巻川＝雑司が谷の「谷」の地形 naming の説明を、職人の手記という独立系の二次資料でも確認**できた。「吉宗の命名」は伝承であり確認資料ではない。
- **追記（2026-11-11 第20回・検索スニペット追加確認）**：新たな検索スニペットで**「この弦巻川は、雑司が谷八景の一つにうたわれた風光を誇り、夏は蛍、秋は月の聖なる川として流域の人々の生活を支えた。弦巻川も時代の波に押し流され、昭和４年に暗渠化…」**との叙述が確認できた〔二次: スニペット〕。
  - **「雑司が谷八景」への弦巻川詠込はrepo初出**〔蛍・月の風光の評〕。
  - **「昭和4年（1929年）暗渠化」**との文言が確認できた。昭和7年（1932年）高田町実施説（Wikipedia・[BLOG-063](BLOG-063.md)）とは**年次が食い違う**〔注意: 文字化け本文未確認のため、昭和4年=着手・前置きの時期という解釈も可能。本資料単独では決められない〕。
