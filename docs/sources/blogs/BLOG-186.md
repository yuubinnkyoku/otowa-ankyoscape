- **大正後半の美術学生・画家の小屋群〔repo初出の伝聞〕**: **「大正時代後半には、谷端川沿いに簡易な小屋が多く建設され、美術学生や若い画家が集っていたそうです」**〔谷端川上流部（西池袋〜椎名町側）の画家・美術学生の小屋集落の伝聞記述はrepo初出。要町〜長崎のアトリエ村（1938年10棟・[BLOG-155](BLOG-155.md)）より前の大正期という時期設定が新情報。谷頭・湧水環境と安価な借地が集落成立の背景にあった可能性は本記事では説明されないため仮説化せず〕。
- **2026年4月時点の橋跡現況〔観察・BLOG-069（2022年）・BLOG-114（2026年）と衔接〕**: 西武池袋線より北側で宮下橋（**欄干らしきものと「みやしたばし」銘板が残る。遺構か復元かは記事も断定せず**）→並木橋→羽黒橋（先に銭湯「湯〜ゆランドあずま」＝旧屋号「東屋」・60年以上前創業）→八幡橋→霜田橋（立教通り）→谷端川第二親水公園（**この日池の水が抜かれていた**）→丸山橋→長崎橋（要町駅）〔**並木橋・八幡橋・丸山橋の現況列挙・第二親水公園の水抜き観察＝2026年時点の新データ。宮下橋のモニュメント的現況は[BLOG-153](BLOG-153.md)の記録と整合〕。
