# [BLOG-071] 旧田中村・南田中の石仏と八成水車

- **直接確認（2026-11-11、open_url・本文全文）**：旧田中村・南田中の寺社・石仏・文化財を巡る記事（訪問2019-04-23、投稿2023-04-20）。典拠は明示されないが練馬区史・まちづくり情報誌「こもれび」等に依拠した叙述を含む個人サイト。
- **八成水車〔確認：記事記述〕**：千川通り（旧千川上水）が**笹目通り（環八）と交わる「八交叉差点」**のすぐ近くに**戦前までは「八成水車」があった**。千川上水は**1696（元禄9）年に田中村の南端に通じた**が用水は田中村を素通りし、本格的な利用は明治以降。**八成水車が最初に千川上水から水を組み上げて使った**もので、これ以降**10基ほどの水車**がこの上水に造られた。水車を挟んで工場2か所、**挽臼4台・搗臼2台・杵12本・精米機**などで精米・麦の挽き割り・製粉を行った。〔**「八成水車」の呼称はrepo初出**。設備構成が [GOV-069](../gov/GOV-069.md) の斎藤水車の証言（挽臼4・搗臼2・杵12・精米機）と完全に一致し、「八成水車」は斎藤水車の別称・同所の通称と推定できる（仮説）。第9回ノートの未解決課題「八成橋の位置特定」に対し、[GOV-069]の「八成橋脇の水車」の位置を八交叉差点（千川通り×笹目通り）付近に具体化する根拠〕
- **長命寺道道しるべ〔観察〕**：千川通りを井草方面に進み笹目通りの手前に**「右 長命寺道」と刻まれた道しるべが現存**（現在は道路の反対側に移設）。**昭和15年頃の写真には手前に千川上水が流れ、「三兵橋」が架かり、傍らに東向きの道標が立っている**。〔**三兵橋はrepo初出の千川上水橋名**。昭和15年頃の写真の所在（「こもれび」等）は要確認〕
- **薬師堂橋〔確認：記事記述〕**：高野台駅付近（日出薬師の旧地）に「駅の前にはその名残に薬師堂橋がある」。〔石神井川水系の橋か千川上水の橋か記事からは特定できず未検証〕
- **田中村の字名〔確認：記事記述〕**：小名として薬師堂・供養塚・塚越・上久保があった。〔南田中の字名はrepo初出の可能性（対照表候補。薬師堂=高野台駅付近、供養塚=十善戒寺付近で明治以降「本村」、塚越=その東、上久保=塚越の南）〕
- **制限〔未解決〕**：記事の典拠書名が特定できていない。「10基ほどの水車」は [GOV-067](../gov/GOV-067.md) の「上水路図に8か所」・「練馬区内で確認される水車4か所」と数字が食い違う（範囲・時期の違いか。典拠確認要）。元禄9年=千川上水開削期（元禄年間）と整合するが本記事単独では開削年次の根拠にならない。
