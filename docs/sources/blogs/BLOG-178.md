- **コメント欄の地元情報〔伝聞・repo初出候補〕**：地元投稿者（aquira）により**「ここいらは空襲を受けなかったので古い家が多く、空いたところから豊島区が買い上げている。自然倒壊もあり再開発したい。買い上げ空き地がささむので妙な広場にしている」**、一本北側に日光（栃木）モチーフの広場〔陽明門遊具〕がある、との聴取〔**辻広場群（BLOG-106・110）の成立背景＝戦災を免れた家屋群と区の土地買い上げという説明の一次聴取記録**〕。
