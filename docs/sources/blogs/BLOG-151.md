# [BLOG-151] 雑司が谷大鳥神社（神社と御朱印）・1940年弦巻川暗渠化文言

- **直接確認（2026-11-12、open_url・Waybackスナップショット2024-09-09で本文全文）**: 現行頁はブロック応答のため[Wayback](https://web.archive.org/web/20240909182235/https://jinja.tokyolovers.jp/tokyo/toshima/zoushigaya-otorijinja)で取得（2016年5月11日投稿・2017年7月8日更新の神社紹介頁）。
- **〔確認・repo初出〕 1940（昭和15）年・弦巻川の暗渠化に伴う社殿配置の変換**: 御由緒に「**1940（昭和15）年、社地北側を流れていた弦巻川の暗渠化に伴い、社殿配置の変換が行なわれた。また同年、境内に隣接していた宮司の私有地（120数坪）を寄進・境内に編入**」とある〔弦巻川暗渠化の年次に関する**第四のデータポイント**。既存のデータ（高田町下水道1929〜33年〔[BLOG-063](BLOG-063.md)〕・大鳥神社碑1931年説〔[BLOG-049](BLOG-049.md)〕・同1932年説〔[GOV-062](../gov/GOV-062.md)〕・雑司が谷八景の「昭和4年暗渠化」〔[BLOG-034](BLOG-034.md)〕）と食い違いうるが、**下水道管の埋設と河川覆蓋・社地整形の別工事と解する余地もあり、断定せず並列記録**。神社側由緒が1940年に「弦巻川の暗渠化」で社地北側の状況が変わったと認識してきた点が記録価値〕。
- **〔確認・repo初出〕 創祀と高田村の位置関係**: 「1712（正徳2）年、出雲藩主松平出羽守の嫡男・万千代が疱瘡にかかり、**千登世橋近くの高田村下屋敷で療養**していた。出雲国鷺浦・鷺大明神（現・伊奈西波岐神社）に祈願し平癒したため、鬼子母神境内に勧請、手水舎の傍らに奉斎」〔**千登世橋・高田村下屋敷**という弦巻川谷頭に隣接する高田地域の地名を含む由緒〕。神仏分離で分離・「大鳥神社」と改称し大門ケヤキ並木沿いの料亭・蝶屋敷地に遷座（跡地の五軒長屋が現存し雑司が谷案内処が入居）、**旧幕臣・矢嶋昌郁が社地二百坪を奉献、1887（明治20）年に現在地へ遷座**、1917（大正6）年社殿新築、1955（昭和30）年約150坪買取で拡張、1981（昭和56）年現社殿造替〔社地変遷の年次群は弦巻川流域の土地利用史資料〕。
- **〔確認・repo初出〕 三杉稲荷神社の1967年遷座**: 境内社の一つで「もとは日出町の都電通り沿いで個人が祀っていたが**1967（昭和42）年、首都高5号線の用地となったため、大鳥神社境内に遷座**」〔弦巻川・雑司が谷流域で首都高5号線建設による社・施設の移転例。[BLOG-137](BLOG-137.md)の青柳小学校移転聴取と同系列の遷座記録〕。西宮神社（2010年雑司が谷七福神創設で再勧請）も記載。
- **〔確認〕 補足**: 限定御朱印は通常の社号でなく「**鷺大明神**」と表記〔社名の二重性＝GOV-062の「鶴／弦両説」と同様の表記揺れ資料〕。大鳥・七社・大塚天祖神社（[BLOG-093](BLOG-093.md)）の三社「都電神社めぐり」企画も記載。
