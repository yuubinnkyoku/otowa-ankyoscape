# [BLOG-139] 谷端川境井田支流（仮）・池袋三業地裏 hand の観察

- **書誌〔確認〕**: 「暗渠さんぽ」（nama）「ふとみれば花街、谷端川境井田支流（仮）」、2012年3月5日。http://kaeru.moe-nifty.com/ankyo/2012/03/post-f26c.html 。現行はAccess Deniedのため **Wayback（2022年スナップショット・id_指定）で全文取得**（2026-11-12確認）。
- **〔観察〕** 池袋駅東側・池袋3丁目（旧池袋村）の谷端川河口付近に合流する無名支流を「境井田支流（仮）」として踏査。三業通りの裏手を通る非常に狭い暗渠路地で、右岸に大谷石護岸状の残欠、つっかえ棒（新旧）・蓋がけ痕跡、河口付近に橋状の構造物と窥き穴を観察。谷頭のような緩やかな窪みに池があったかのような風情〔観察・筆者推定〕。
- **〔確認・repo初出文言〕** **明治初期の古地図に水路として描かれるのはこの川でただ一度のみ**、と明記。また流末は**二股**で、片方が谷端川合流点の少し東でカギ状に曲がる流れに相当すると読む〔筆者の読図〕。
- **〔確認・repo初出文言〕** **江戸期の池袋村絵図（「豊島郡の村絵図」より・豊島区立郷土資料館刊「歴史をたずねて 豊島区の文化財」池袋村の図）に御嶽神社が描かれ、境内の西の道に橋が架かっている**。位置的に境井田支流（仮）のための橋と筆者は推定〔推定〕。
- **〔確認・repo初出〕** 字名: **流末が「境井田」、流路に対して左側が「大上」、右側が「下上」、そのあたりの字が「上」**（池袋村の字。上掲「歴史をたずねて」池袋村に書き込み）。地名対照表に追記済み。
- **〔確認・repo初出〕** 牧場: **鈴木牧場（合流点1ブロック手前の左岸）と和田牧場（ほぼ右手）の2軒が川沿いにあった**（「ミルク色の残像」による）。牧場が川の水を利用したと推定〔推定〕。付近に銭湯「栄湯」（現・木材置場）・御嶽神社・御嶽北公園。
- **〔確認〕** 三業地: 池袋駅東側の待合兼小料理屋数十軒は大正〜昭和初期に大塚三業地へ吸収されたが、残りは地元の反対で西側の現三業通りへ移転し二業地→三業地となった（「豊島区史」による）。現在の営業は2軒のみ（「東京花街・粋な街」による）〔二次文献引用。原本未確認〕。
- **〔確認〕** 猫またぎさんの同名記事（2011年・境井田支流（仮））・ふろっぐねすと掲載がコメント欄で確認できる。**猫またぎ元記事はrepo未収録**。
- **注意**: 「境井田支流（仮）」は調査上の便宜名。D.2.C.の目次にある「境井田（御嶽）支流」や対照表の同欄と同じ対象とみられるが、歴史的正式名称ではない。水源についての文献は見つかっていない（筆者も「文献がひとつも見当たらない」と明記）。
- **制限〔未解決〕**: 「歴史をたずねて 豊島区の文化財」池袋村・「豊島郡の村絵図」・「ミルク色の残像」・「東京花街・粋な街」の各原本未確認。猫またぎ元記事の所在。新設道路（再開発）による現状変化の最新確認。
