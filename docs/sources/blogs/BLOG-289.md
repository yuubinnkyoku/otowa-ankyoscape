# [BLOG-289] 細川正博「千川増強幹線の北大塚での接続工事の工期延長について」

- **書誌〔確認: ブログ本文・2026-11-23取得〕**: 豊島区議・細川正博のブログ記事（**2026年7月15日投稿〔datePublished=2026-07-15T09:00+09:00〕**）。 https://ameblo.jp/hosokawamasahiro/entry-12972702319.html 〔BLOG-134（初報）・[BLOG-194](BLOG-194.md)（令和7年5月22日続報）に続く第3報。細川HP「ゲリラ豪雨対策」頁（ https://www.hosokawamasahiro.jp/seisaku/environment/environment01.php ）の経過リスト最新項目「R8.7.15」に対応〕。
- **2度目の工期延長〔確認: 本文・repo初出〕**: 「平成25年8月21日に南大塚1丁目などで起きたゲリラ豪雨の被害への抜本的な対策として行ってきた千川増強幹線に関連する「**豊島区北大塚二丁目付近枝線工事**」の工期延長について報告を受けました。**昨年5月に続いて2度目の工期延長です**」（当初「7年に8月に接続工事が完了予定」）:
  - **(1) 路上工事（豊島区北大塚二丁目＝宮仲公園通り）: 7年6月から9年2月 ⇒ 9年5月まで延長**
  - **(2) 公園工事（豊島区立上池袋東公園）: 7年10月から8年7月 ⇒ 9年3月まで延長**（「9年3月まで大幅に延長となります」）
  - 作業時間8:00〜18:00（原則、土日祝は作業なし）・**路上パーキングの撤去期間も令和9年5月まで延長**〔BLOG-194の記録（令和9年2月まで）からの延長〕。
- **接続構造の現況〔確認: 本文（BLOG-194の再掲・維持）〕**: 「**下水道本線の千川第二幹線と千川増強幹線の接続工事は終了していますが、千川幹線と増強幹線の接続工事が完了していません**」＝**3接続のうち、まだ千川幹線側が未完**（2015年から10年以上の残工事がこの枝線1件）。
- **完成段階情報〔確認: 本文直接引用〕**: 「**10年以上に及ぶ一連の工事は、残すところ上記を残すのみです。工事の完了が待ち遠しいです。**」＝**BLOG-194（「今回の工事をもって完成」）の完成宣言から、2度の工期延長を経た「残すところ1件」への修正**〔2013年8月21日豪雨（平成25年＝[BLOG-134](BLOG-134.md)起点）から的事業の終息点が令和9年5月以降へ後ずれした記録〕。
- **意義〔観察〕**: ①**千川増強幹線の最終接続（千川幹線×増強幹線）が令和9年5月以降にずれた一次（当事者区議）記録**＝[GOV-036](../gov/GOV-036.md)（増強幹線事業2024）・[BLOG-194](BLOG-194.md)の終息見通しの修正データ②宮仲公園通り路上パーキング撤去期間の延長と上池袋東公園の占用延長＝**谷端川上流域（宮仲公園＝[BLOG-066](BLOG-066.md)巣鴨学園支流暗渠の隣接地）の占用情報の更新**。
- **制限・未解決**: 都下水道局の一次公告・完了検査日との照合。2度の延長の理由（本記事では理由の記載なし＝BLOG-194の「千川幹線の位置が想定と違っていた」〔試掘〕が継続原因かは本文からは断定できない）。
