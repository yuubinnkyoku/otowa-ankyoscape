# [BLOG-050] 黒田涼「ひたすら暗渠歩きの豊島区西北境」

- **直接確認（2026-11-11、open_url・本文全文）**：2025年4月8日投稿の区境歩行記録。谷端川の板橋駅〜椎名町駅付近の区境・川跡の現地観察。
- **板橋駅西口の区境と川跡〔観察〕**：谷端川は板橋駅の西口でも暗渠で、その上が**谷端川児童遊園（板橋区立の公園）**。区境はガード出口部分で谷端川から離れ、下板橋駅方向へほぼ一直線に伸びる。区境に忠実に歩くなら西口前はマンション敷地を避け、川跡の一つ南の道を下ることになる。
- **池袋本町と屈曲〔観察・推測〕**：下板橋駅付近にほぼ180度向きを変える屈曲があり、その南側の袋状になった台地部分が池袋本町で、「池袋」の地名発祥の地域と筆者が考える。
- **震災後の区画整理〔二次叙述〕**：川越街道〜椎名町駅間の区境は関東大震災後の区画整理や河川改修で整理され、ともえ通り・さいわい通り周辺は元は板橋区側の下板橋町だった土地を区境の屈曲をなくすために土地交換したとする。「上ノ橋」（池袋3-23表示の電柱付近）で区境が右に曲がるとも記す。
- **小石川上水〔二次叙述〕**：谷端川は文京区に入ると小石川と名を変え、神田上水ができる前の小石川上水の水源はこの川だったとする。※小石川上水の原典は未提示。
- **その他の内容メモ**：谷端川緑道の一部（川越街道手前）は板橋区管理部分がある。谷端川の江戸期水源は粟島神社湧水池としつつ、千川上水と接続されて水田が発達した経緯、旧長崎村と板橋村の江戸期境界道（都立板橋高校〜三区境付近）を歩く。
- **制限〔未解決〕**：土地交換・区画整理の原典（関連都市計画史料）は未確認。「池袋」地名説は諸説の一つとしての筆者見解。
