# [BLOG-037] 暗渠探索紀・水窪川

- **直接確認（2026-11-11、open_url・part.1）**：水窪川の暗渠を源流（美久仁小路・旧「蟹ヶ窪」）から辿る写真記録。**源流とみられる場所にコンクリートの遺構のようなものが残る**（川との関係は筆者も特定できない）、谷筋に側溝がある、など谷地形と川跡の観察記事。
- **巣鴨プリズン排水管〔確認：part.1の叙述〕**：**巣鴨プリズン建設の際に川が埋められ、プリズンから水窪川へ排水する排水管はイケ・サンパーク内に残され、石垣は取り壊されて排水管だけが移設保存された**と説明。※[BLOG-025](BLOG-025.md)（2021年の移設保存・案内板）と同一事象の独立の観察記録として重複加算しない。
- **part.2〔直接確認：2026-11-12追記、open_url〕**：https://ankyo.chikyu-kagaku.com/2023/03/27/mizukubo-2/ 。中流域〜護国寺方面の観察記録。既知事項（富士山広場の水窪川の碑＝BLOG-110、男体山フェンス=BLOG-110）のほか、以下を含む。
  - **ミョウガ畑の記憶〔伝聞：part.2の叙述〕**：富士山広場付近に「ミョウガ畑があった」が現在は荒れ果てていると記す。水窪川谷沿いの微高地利用の生活記憶。
  - **ポンプ式の現役防災井戸〔確認〕**：暗渠わきの広場に防災井戸に指定された現役のポンプ式井戸があると観察。BLOG-100（吹き上げ稲荷付近「防災協定井戸」プレート）と並ぶ水窪川沿い防災井戸の第二観察例。
  - **銭湯と暗渠の立地関係〔観察〕**：暗渠近くに銭湯があり、「水に関係する施設であるため川沿いに作られやすい」との筆者考察。急坂・古いコンクリート・暗渠の駐輪場利用などの景観観察を含む。
- **意義〔観察〕**：谷地形の読み方（浅い谷、わずかな高低差、床の高い建物、階段、苔の生えた路面）を水窪川に沿って記録した現地観察の補助資料。**流路の位置の新証拠は含まない**。part.2の「防災井戸・ミョウガ畑・銭湯」は生活水利用の記録として加算価値がある。
