# [BLOG-218] いたくら美千代区議「巻石通りレポート」（2024-07-15）

- **〔確認〕**: 文京区議会議員いたくら美千代（日本共産党）の2024-07-15レポート。巻石通り（文京区・水道）の無電柱化について、**音羽通りから江戸川橋体育館までの区間（400m）**のうち区が担う道路を掘削して電気・通信ケーブルを入れる管路工事が**2024年5月24日に終了**（当初より約2か月早まる）。以後は地上機器設置・入線・建物への引き込み・電柱撤去を経て**区がバリアフリー工事を行い、2028（R10）年3月完成予定**。車道側に白いガードレールを広げている部分まで歩道を広げる計画。
- **〔確認＝repo初出〕**: **安藤坂から金富小学校までの第2期工事について2024年度中に設計し、埋蔵文化財調査も行う**と明記。当初計画では巻石通り無電柱化の全工事終了に32年かかるとの予測が早まる可能性に言及。
- **〔留意〕**: 区議（与野党の別を問わず）の活動報告であり、計画数値は区の資料〔[GOV-097](../gov/GOV-097.md)（区バリアフリー整備頁・平成28年度計画・区道889号）〕に基づくが、政治活動ページである点は出典評価に含める。**第2期区間の埋蔵文化財調査は、音羽・水道周辺（旧谷端川・小石川低地縁）で地中の遺構確認の機会が生じる可能性**を示す情報として記録価値あり（調査結果は未公表情報なし・断定しない）。〔水道・音羽の谷端川暗渠化区間（旧谷端川＝弦巻川合流先）での掘削機会〕
