# [BLOG-242] わんじん「東大下水（ひがしおおげすい）　－誤解を招く現代用語との意味の違い－」（2014-02-04）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文＋コメント欄）**: wanjin東大下水カテゴリ7本のうちの**シリーズ第1回（定義記事）**。
- **東大下水の定義〔ページ記載〕**: 本郷台地の西側を流れる排水機能を持つ河川＝谷端川（小石川）＝俗に**西大下水（にしおおげすい）**と呼ばれ、その東側を流れて現在の東京ドーム付近に進む流路が**東大下水（ひがしおおげすい）**。「**本郷にある東京大学のそばに流路があるので、東大の下水と書くわけではなく、谷端川（＝西大下水）と対をなす存在として、東側にあるため東大下水**」。江戸期の「下水」は生活排水を主体としない農業用水・排水の清流。**東大下水は4方面の流れの総称**: ①巣鴨駅方面（巣鴨大鳥神社付近）からの流れ（最長＝現在の下水道**白山幹線**）②六義園からの流れ③西片方面からの流れ④菊坂の流れ。**西大下水（谷端川）も東大下水も、当時の水戸藩邸（後楽園）に流れ込む**「とにかく水の流れが集中するところ」〔wanjinによる用語・流路の整理。後続の各支流記事（BLOG-235〜240）の前提〕。地形観察として「本郷台地は尾根筋に本郷通り、沢筋に白山通りが通っていたため、そこかしこに坂道ができた」旨の言及〔千川＝本郷台地の飲料上水〕。
- **コメント欄の1950年代実見証言〔repo初出の証言・PAP系の石橋跡論文の独立傍証〕**: コメント投稿者・**北条光年**（**昭和26年生まれ・3歳から旧上富士前町で育ち・昭和小学校に通い、江岸寺で週一回習字を習っていた**）による2014-05-01の証言: ①「**江岸寺の入り口に石橋があった**ことを思い出し、子供心になんで橋があるのだろうと思ったことを覚えています」②「**吉祥寺の南側の道路で掘割に水が流れていた**のを見た記憶がありました。今現地に行ってもその痕跡はなく、私の記憶違いかとも思う年月が経ってしまいました」③「**「文京区ふるさと館」にある海老床の店主が描いたこの近辺の江戸末期の絵地図**を見ると、なんと**吉祥寺の少し本郷よりに、本郷通りを横断する水路と橋が書かれている**ではないですか。私の記憶にある吉祥寺の南側にあった掘割はやはり間違いないだろうという確信を持つようになりました」〔**1950年代（投稿者が3歳〜小学校期＝昭和29年頃以降の記憶と推定される年代）の吉祥寺南側の開渠・掘割の実見**、および**本駒込・吉祥寺付近の本郷通りを横断する水路を描く江戸末期絵地図の所在（文京区ふるさと館〔現・文京区ふるさと歴史館か〕所蔵・「海老床」店主筆）の情報**。 wanjinはこのコメントへの返答で「実際に開渠だった状況をご覧になったことがある方より情報をいただけると大変助かります」と応じ、当該情報が六義園支流の再調査（[BLOG-240](BLOG-240.md)訂正）の契機の一つになった〕。
- **repo上の意義〔観察〕**: ①鈴木ら「本郷台地の地形・地質と文学・歴史との融合」（深田地質研究所年報26・2025）が**2025年4月に江岸寺で聞き取りを行い、門前に残る石橋跡を「東大下水」の痕跡**とする（README既収録）のに対し、本コメントは**2014年時点で同じ石橋（入り口の石橋）を1950年代に実見した記憶として記録した独立の証言**であり、石橋が実用橋だった時期（少なくとも1950年代の開渠期）の年代を絞る手掛かり〔実見年代は推定。橋と掘割の同時実見かどうかは文言上「記憶」として区別される〕。②海老床店主の江戸末期絵地図は**六義園支流（吉祥寺付近）の水路を含む本郷通り横断部を描く絵図の候補**として、文京区ふるさと歴史館での確認が今後の課題〔絵地図の正式名称・蔵書誌は未確認。「海老床」は商家名か人名かも未確認〕。
