# [BLOG-210] 大塚三業地〜神田川合流の橋名群・柳町支流・東大下水との3度の合流と市兵衛河岸

- **直接確認（2026-11-13、第64回・FC2直fetch）**：entry-254（2018-07-18）・255（2018-07-25）・256（2018-08-01）。URLは代表してentry-254を掲げる（255=https://wanjin.blog.fc2.com/blog-entry-255.html、256=https://wanjin.blog.fc2.com/blog-entry-256.html）。谷端川シリーズ本流編の最終3回。
- **大塚三業地の橋名群〔観察：2018年＋伝聞〕**：大塚駅北口・都道436号（旧癌研通り）横断歩道付近に**姿見橋**、三業通り沿いに**見返り橋**（二つの橋があった場所）・**熊野窪橋**（都電車庫手前の熊野社に由来する「熊野窪」地名。熊野社は大塚駅南口の天祖神社に移転）・**東福寺橋**（流路直線化で川に直行する道が筋違いになった位置に斜めに架かっていた）〔大塚周辺の橋名・位置の独立観察記録〕。巣鴨小学校（1919年＝大正8年仰高西尋常小として開校、校門前に無名の橋）西側を抜け、南大塚一丁目児童遊園手前に無名橋、丸山ちよの碑そばに**松浦橋**、区境（豊島区巣鴨町／文京区小石川区）に**宮原橋**〔巣鴨〜小石川間の橋名群はrepo初出候補〕。
- **一木橋＝「一本橋」誤字定着説〔伝聞〕**：文京区に入って最初の橋**一木橋（いちもくばし）**は、かつて「一本橋」と呼ばれたが、どこかで誤字表記され「いちもくばし」として定着したと記す〔橋名の変遷に関する独立説話。既存の橋名リストに注記候補〕。同近辺は**砂利場坂**と呼ばれ、文京区内での「小石川」「礫川（れきせん）」呼称と良質の砂利採取地であった可能性を指摘〔礫川呼称（既収録）と砂利採取場の機能的説明〕。不忍通り（都道437）の**猫股坂**は**「根子股橋」が「猫股橋」になり坂名も猫股坂になった**とする説〔猫股橋親柱現存の記録（既収録GOV系）の由来说補強〕。
- **湯立坂の由来文言〔確認：『続江戸砂子』文言の引用〕**：茗荷谷駅へ至る湯立坂について「**里人の説に、往古はこの坂の下は大河の入江にて、氷川の明神へは河を隔てゝ渡る事を得ず。故に、此所の氏子とも此坂にて湯花を奉りしより坂の名となれり**」と引用〔『続江戸砂子』由来文言は谷端川＝「大河の入江」説の史料的一級データポイント。既収録の湯立坂言及と照合要〕。同付近に**渋沢栄一らが設立した東京帽子株式会社**があった〔谷端川沿いの近代産業史料の補足〕。
- **柳町支流（仮）〔観察：2018年〕**：念速寺先の小さなカーブ地点で**「東大下水」とつながる流れに分岐**する支流を「柳町支流（仮）」と名付け、千川通りを渡って再合流する流路を観察〔東大下水と谷端川の下流域における接続支流の独立観察。repo初出の呼称〕。
- **東大下水との3度の合流〔観察＋確認〕**：小石川一丁目・柳町こどもの森南あたりから白山通り（都道301）と並行し、**えんま通り商店街手前で指ヶ谷から流れる東大下水が1度目の合流**。以後、外堀通りまで両者は並行しつつ**源覚寺（こんにゃくえんま）前で2度目**、礫川公園先のクランクで**3度目の合流**を繰り返す〔谷端川と東大下水の複数回合流構造の具体的読図。既存の「西大下水＝谷端川」呼称（GOV・MAP系）の流路側補強〕。東京ドーム（水戸藩江戸上屋敷＝小石川後楽園）内から西大下水・東大下水に注ぐ流れがあったとする。
- **市兵衛河岸〔確認：本文記述〕**：「市兵衛河岸」と呼ばれた場所で東大下水と完全に合流し神田川へ注ぐ。水道橋〜船河原橋間の一帯が**岩瀬市兵衛の屋敷に由来する「市兵衛河岸」**で、**明治期から昭和8年まで後楽園一帯の砲兵工廠の荷揚場**として利用され、現在は防災船着場〔谷端川終点＝神田川合流点（市兵衛河岸）の具体記述。砲兵工廠荷揚場＝昭和8年までの利用年次はrepo初出候補。最終合流点の既存仮説と照合〕。
