# [BLOG-235] わんじん「東大下水：指ヶ谷支流（仮）」（2014-02-11）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文）**: wanjin東大下水カテゴリ7本のうち最古の1本。**東大下水（ひがしおおげすい）＝千川の下流・神田川に注ぐ暗渠化された排水路**の支流群のうち、**「最も長い支流（本流？）」として巣鴨駅そばの千石四丁目付近から始まる指ヶ谷（さしがや）支流**を、六義園支流と合流する白山神社近辺まで辿る。
- **指ヶ谷支流の起点〔wanjin観察〕**: **巣鴨の大鳥神社周辺にかつてあった農耕地の排水を集めて流れを形成**。東大下水は排水路で「明確な源流となる湧水地があるわけではない」。千石四丁目周辺で白山通りの西側並行の通りに直交する路地が「ことごとく暗渠道」でマンホールが連続する光景を記録〔現地観察〕。不忍通りを最も低い谷筋のコンビニ脇で越え、明化小学校・一行院の脇を抜け、龍泉寺・寂圓寺の辺りから白山通りを北東に横断、京華女子高等学校・東洋大学・京華学園の敷地を通過し、龍雲禅院前で白山通り歩道の拡大部に花壇（マンホール鎮座）、白山神社の南側（地下鉄白山駅そば）で六義園支流と合流する流路〔wanjin流路観察。goo古地図等との照合はentry-49で実施〕。
- **千石地名「千川＋小石川」説の引用と疑義〔ページ記載〕**: 「千石という地名は**千川の“千”と小石川の“石”をとって名付けられたといいます**」と引用した上で、「千川も小石川も西大下水である谷端川の別称ではないかと思うのですが、**どうも釈然としないものがあります**」と疑義を呈する〔千石説の出典は本文に示されず。疑義はwanjinの意見〕。
- **「指ヶ谷」の両読み〔ページ記載〕**: 「**指ヶ谷保育園は『さしがやほいくえん』、指ヶ谷小学校は『さすがやしょうがっこう』**」と、同名の読みが年長と小1の施設で異なるという地元情報を記録。wanjinは本ブログ内で「さしがや」に統一〔地元施設の読みの実在は要確認〕。
- **千石一丁目の東京市燈孔マンホール〔repo初出の遺構情報〕**: 高橋甚也『下水道』（アルス、**1937年**）を引用し、燈孔の用途を「**大管渠の彎曲箇所、又は特に距離長大なる部分の中間にして、人孔を必要とせざる程度の場合には燈孔を代用する**」と説明。「大管渠＝現代の下水道幹線」「彎曲箇所は元々河川だった管渠の蛇行箇所であるケースが多い」。燈孔はランプを吊るして管渠内の点検等に用い、**「現在では新設されることはなく、大正から昭和初期に設置されたものが僅かに残っているのみ」**と記す〔高橋甚也『下水道』1937の文言引用。千石一丁目の燈孔蓋の現存写真つき。元河川（谷端川・東大下水系）の蛇行部を示唆する遺構候補だが、当該管渠がどの旧流路にあたるかは本文では特定されない〕。
- **佳水会館・京華学園の池〔ページ記載〕**: 燈孔のそばの「佳水会館」のネーミングから「往時の清流ぶりが偲ばれる」。**京華学園（中学・高校）の敷地にはかつて池があり**、写真で言及〔池の年代・規模は本文に記載なし〕。
