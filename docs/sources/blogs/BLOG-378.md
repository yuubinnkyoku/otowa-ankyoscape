## 内容メモ

- **〔観察〕桜橋の田柄川合流排水口と板橋区側の桜川呼称区分**: 桜橋たもとの「大きな排水口」＝現役の田柄川合流点。「練馬区側は田柄川、板橋区側は桜川と呼ばれ遊歩道として整備。板橋区側では元の流れが大きく変更され、元々は桜橋ではなくもう少し下流の複数箇所で石神井川に注いでいたらしい」＝[BLOG-377](BLOG-377.md)の合流複数説と同時成立の観察。
- **〔観察・repo初出〕緑道の橋名看板群（板橋区〜練馬区の区界〜棚橋）**: 桜川緑道銘板（桜橋北側）・**上板みたけ橋**（御嶽神社は交差点南側公園内）・区界（アスファルト→砂利舗装の変わり目・植え込みの「終点」銘板＝光が丘公園東側の「起点」と対）・距離標・**金越橋・仲一橋・宮元橋・今神橋**（東西南北の方角を示す植え込み）・**今神=下練馬村の字名**・円明橋・**横寺橋**・渡戸橋・金乘橋・北町橋・高徳橋（川越街道越え・田中昭彫刻）・下宿橋（啓志線鉄橋痕跡なし）＝wanjin田柄川橋名群（[BLOG-369](BLOG-369.md)）と独立の橋名観察。北子橋は銘板判読不能。
- **〔観察・repo初出〕円明院（文亀5年1502板碑発掘・穴守弁財天）**: 真言宗豊山派・1500年前後創建推定。**円明橋の橋名は円明院由来**＝橋名由来資料。**渡戸橋たもとの「東本村庚申講」青面金剛庚申塔・貞享2年（1685年）造立**＝[BLOG-369](BLOG-369.md)の東本村庚申塔（wanjin観察）と**年次まで一致する第2の独立観察**（同じ塔か隣接かの判別は写真対照待ち）。東本村=下練馬村字名。
- **〔観察・repo初出〕金乘橋跡の幅広水路敷・湧水推定**: 金乘院由来の金乘橋。「金乘橋と北町橋の間、都営錦一丁目第2アパート東側に水路敷と思しき細道。改修前の田柄川は現在の遊歩道より一つ東側の道路あたりを流れていたが、そこに流れ込む小さな湧水があったかもしれない」＝[BLOG-377](BLOG-377.md)（wanjin都営錦一丁目第2アパート東側の谷間）と独立の湧水・旧流路観察。
