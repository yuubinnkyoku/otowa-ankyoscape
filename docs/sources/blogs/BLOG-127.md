# [BLOG-127] 王子分水の開削工事と流路推定（wheatbaku「幕末の大砲製造所」シリーズ⑤⑦）

- **直接確認（2026-11-12、open_url・本文全文）**：気ままに江戸（夢見る獏）のシリーズ記事2本。⑤[小栗上野介、王子分水開削](https://wheatbaku.exblog.jp/32668814/)（2022年7月）と⑦[王子分水跡〈推定〉を歩く](https://wheatbaku.exblog.jp/32677066/)（2022年8月3日）。「北区史」・北区教育委員会説明板・日本大百科全書（ニッポニカ）を引用しつつ実踏する構成。
- **開削工事の工期と区間〔確認：二次（「北区史」経由）〕**：慶応元年（1865）の工事は、**①石神井川の王子石堰から下流の川幅切り広げと川床低下（大砲製造所への物資船輸送用）、②千川上水の広尾水車前＝平尾水車前（現板橋区板橋1-16付近）から高桝跡（現滝野川6-9付近）までの従来水路の拡幅、③高桝跡から大砲製造所建設予定地までの新規開削**からなり、**9月中旬から11月末頃までの約2か月半**で行われたとする。〔**平尾水車の位置（板橋1-16）・高桝跡の位置と呼称（滝野川6-9）・工期（9月中旬〜11月末）はいずれもrepo初出**〕
- **王子分水の定義〔確認：説明板〕**：北区教委の文化財説明板に「この分水路は、**慶応元年(1865)11月**、飛鳥山の西側（滝野川2-6付近）にあった江戸幕府の大砲製造所の建設に伴い、**開鑿された**もの」とある。〔[BLOG-053](BLOG-053.md)（1865年反射炉王子分水＝「堀割」の由来）と整合〕
- **分配堰碑と説明板〔確認〕**：千川上水公園前の明治通りを挟んだ向かい（北区側）に「千川上水分配堰碑」と北区教委説明板が設置される〔碑の所在地の位置確認〕。説明板文言：正面「千川上水分配堰」、**明治15年(1882)7月設置**、右側面に水源地・樋口の大きさと利用者、左側面に設置年月日、**裏面に明治42年3月として樋口の大きさ・利用者・堰幅・溜池水面の高さ**が刻まれる。〔[BLOG-095](BLOG-095.md)（citywalk2020の碑文採録）とほぼ一致する独立裏付け。碑の北区側設置状況は本記事が初出〕
- **「堀留」の地名由来〔確認：本文の説明〕**：明治通りと旧中山道の交差点「堀留」は、**千川上水の開渠（堀）が終了していることによる地名**とする。〔**堀留由来の記述はrepo初出**。地名対照表候補〕
- **ニッポニカ千川上水項の引用〔二次引用〕**：延長約30km・河村瑞賢設計・仙川村の太兵衛・徳兵衛監督・**巣鴨の庚申塚溜池**に入れ地下樋で給水、1722年上水利用廃止。〔延長「約30km」はrepo既述の約22km説と食い違うため、百科事典レベルの数値として参考記録に留める〕
- **王子分水流路の実踏推定〔推定：筆者の現地歩行〕**：千川上水公園付近（分配堰）から明治通り沿いに北上→大正大学を過ぎたカーブ地点から真北の路地（北区滝野川と豊島区巣鴨の区境）→白山通りを越え→首都高中央環状線下で直角に東→**天理教麹町大教会**の角を直角に曲がり北上→**庚申塚**（滝野川一丁目交番近く）→桜丘中学校・高等学校付近の下り坂→旧醸造試験所第一工場（滝野川反射炉跡）前で終点。「北区史」掲載の江戸期古地図では**滝野川村と巣鴨村の村境→巣鴨村と西ヶ原村の村境**を流れた後に北上したとする。〔流路は筆者推定。村境沿いという流路形状の根拠（古地図）は「北区史」の二次〕
- **repoへの関連**：1865年王子分水（[BLOG-053](BLOG-053.md)）について、**開削の工期・起点（平尾水車）・経由点（高桝）・終点（反射炉）の具体化**が本記事の価値。明治15年分配堰碑（[BLOG-095](BLOG-095.md)）の独立裏付けにもなる。
- **制限〔未解決〕**：工期・区間は「北区史」経由の二次で、同書の該当頁・掲載古地図の書誌特定が必要。広尾水車と平尾水車の表記ゆれ（同一水車か別物か）は本文では未整理。王子分水流路は推定であり、地籍図・公図での検証待ち。
