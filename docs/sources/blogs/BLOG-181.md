# [BLOG-181] 水窪川が作った谷を巡る⑤　階段暗渠の美しさ

- **直接確認（2026-11-13、open_url・blog.jp直で本文全文取得）**: 毎日暗活！暗渠ハンター（旧『東京Peeling！』、髙山英男）。第50〜51回で遮断が続いていた⑤が**blog.jp直で取得可能になった**（遮断は間欠的）。シリーズID体系（第51回確定: ⑤=7711786）のとおり。
- **階段暗渠の位置特定〔観察: 2010年1月〕〔repo初出〕**: 日の出優良商店会西側の一帯で、**東池袋5丁目32-14あたり**に「溝を埋めた跡のある時間差成型階段」を観察。**数段上がると数メートル平らな踊り場になり、この踊り場に蓋暗渠**があり、階段とともに暗渠が続く。崖上まで登ると振り返って「**崖上から階段といっしょに下る水路**があり、それを暗渠にして階段と同じ段差をつけた」と読む。〔水窪川右支谷の崖線に沿う支流級水路の実在を位置付きで示す観察記録。谷を巡る④（布暗渠）と⑧（新大塚階段住宅群）の間の地形記録を補完〕
- **都電線路西側の水道附属物〔観察〕**: 都電の線路を越えて西へ移動した先で、**木製（手作り風）のメーターボックス**と、**小さな仕切り弁のハンドホールが4つ並ぶ**密集箇所を観察〔水窪川谷の低地部の水道インフラ密度の逸話的記録。用途は筆者も特定できず、断定しない〕。
- **シリーズ内の位置づけ**: ⑤は⑥（BLOG-182）の「日の出商店会は流路でない」訂正の前段階にあたり、日の出優良商店会西側一帯に「暗渠然とした細い道があちこち」あるという観察は、⑥で本田創流路説を採る背景となった。
