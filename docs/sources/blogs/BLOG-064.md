# [BLOG-064] 暗渠ハンター 谷端川 南長崎支流（仮）を再検証

- **書誌**: 髙山英男「暗渠ハンター 谷端川 南長崎支流（仮）を再検証｡」毎日暗活！暗渠ハンター、**2014年9月8日**。http://lotus62ankyo.blog.jp/archives/7712218.html
- 2026-11-11に本文・コメント欄（2014年9〜10月）まで取得確認。**第10回ノートの次回課題1（本文取得失敗記事の再試行）を解消**。
- **〔確認: 紀要11号P60の引用〕** 横山恵美「豊島区の湧き水をたずねて」（豊島区郷土資料館研究紀要「生活と文化」第11号、2001年12月）: 「南長崎3-30、37間に湧き出た水は、南長崎2-24付近で西武池袋線にでて線路沿いに流れ、椎名町駅前のストア付近で谷端川に注いでいた（佐藤鈴代氏提供）。**明治44（1911）年の武蔵野鉄道開通前の地図にこの小川が描かれている**。また足立慶孝氏（1916年生）によれば、**昭和10年代まで線路沿いに湿地（原っぱ）が続いていた**」〔BLOG-057と同じ引用元の全文〕。
- **〔確認: コメント証言〕** 「南 長崎」氏（支流水源の池の目の前で育った人物）の指摘: ①元記事が「水源」とした**公園の池は公園化時に人工的に作られたもの**（髙山が水源特定を取り消し）。②**南長崎3-42付近（西武池袋線沿い）は水はけの悪い低地**だった。③**南長崎花咲公園前のタバコ店脇から西武池袋線方角へ伸びる細い暗渠**があり、南長崎支流（仮）につながっていたのではないか（髙山が現地再調査で賛同）。
- **〔確認: 筆者の観察〕** この暗渠道は**清戸道（尾根伝いの古道）**から北へ流れて始まっており、あたかも古道が分水嶺のように見える区間がある。一方、数百m離れた**としま昭和病院横の湧水から始まる暗渠**（同じく紀要11号参考）は、清戸道が低くなっていて**古道を越えて反対側に流れる**。
- **〔確認: コメント欄のWeekend Outdoors氏証言〕** ①この細い暗渠筋はライオンズマンション手前を北上し、**昭和40年ころまで水路として存在**（同氏の子ども時代の遊び場）。②ドブ川と思われていたものは「れっきとした川」で**農業用水だった可能性**、子供には奈落底に見えた溝は**約60cmの段差**。③大雨でよくあふれた。④**昭和40年前半の大規模改修でヒューム管が埋設**され、マンホールがないため暗渠らしくない。⑤水路は旧街道をさらに南に越え**目白通りまでつながっていた可能性**〔谷端川支流の暗渠化時期（昭和40年前後）と構造（ヒューム管埋設）の具体化＝repo初出〕。⑥水路の水源について、髙山は旧街道（清戸道）の排水と推測、Weekend Outdoors氏の略図では旧街道の南まで延伸。
- **〔未解決〕** Weekend Outdoors氏の水路と、[BLOG-058](BLOG-058.md)の愛心幼稚園支流（U字底）との対応（lotus62も同一水路か記憶が結びかなかった旨をコメント）。同氏ブログの該当記事（weekendoutdoors.blog97.fc2.com/blog-entry-1386.html）はfc2で未取得。
- **〔照合課題〕** 「明治44年武蔵野鉄道開通前の地図に小川が描かれている」の該当地図（紀要11号の掲載図か）と、repo所蔵の明治44年系図の照合。としま昭和病院横の湧水暗渠は紀要11号の湧水リスト由来（[BLOG-056](BLOG-056.md)〜[BLOG-061](BLOG-061.md)の系列と相互参照）。
