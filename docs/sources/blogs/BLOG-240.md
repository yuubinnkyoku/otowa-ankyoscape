# [BLOG-240] わんじん「東大下水：六義園支流（仮）　－訂正するに吝かではない件－」（2014-07-16・追記7/24・10/8）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文）**: wanjin東大下水カテゴリの六義園支流**訂正記事**。[BLOG-236](BLOG-236.md)（2014-02-18）の流路を2点訂正する。訂正の契機は**相互リンク先・lotus62（暗渠ハンター／東京Peeling！）「六義園の水のゆくえ」のコメント欄の情報**と、コメント欄での北条光年とのやりとり〔wanjin自身が「いただいた貴重な情報によって見直した箇所が少なくない」と明記。訂正版である本記事がwanjinの見解の正とする〕。
- **訂正その1: 六義園の全体像〔ページ記載・訂正〕**: **現在六義園として公園化されている部分は築造当時の半分程度の規模**で、**築造時は現在公園の南東側に柳沢吉保の居住地や家臣用の屋敷棟が設けられていた**。下屋敷全体図（絵図面）を掲載。江戸期の地図で当地が「松平家」「丹羽家」「森川家」と表示され柳沢家の下屋敷と確証できなかった点について、**7/24追記: 「柳沢吉保は将軍より松平の姓を賜ったという情報をいただいた。そのため江戸期の地図の表記が松平家になっている可能性」**〔読者情報による説明。松平姓拝領と地図表記の関係は今後の文献照合課題〕。
- **明治2年（1869）東京全図の「柳沢カヒ」「江カンシ」表記〔ページ記載〕: **「柳沢カヒ（甲斐であろうと思います）」の表示と、隣接する寺社領を表す赤地に「江カンシ（江岸寺）」の記載**を確認〔柳沢家は甲府藩から大和郡山藩へ転封だが明治2年図では「カヒ」表記。江岸寺の「江カンシ」仮名表記はrepo初出の読み。地図の書誌（版元等）は本文に記載なし〕。
- **外周堀の埋立〔ページ記載・wanjin推定〕**: 下屋敷は外周をぐるりと堀で囲み、**後に堀は北側と西側の二面を残して埋められた**との情報を紹介し、「**これは池の排水を北側あるいは西側に流していたために堀の水を残すことができた、と考えていいと思います**」〔推定と明記〕。岩崎弥太郎による買い上げ・現在の赤煉瓦塀について、**7/24追記: 「岩崎が造った当時のものはほとんど残っていなくて、新たに造り変えられた」**〔追記情報〕。東洋文庫は三菱三代目・岩崎久彌が1924年に設立。現在は本郷通り側の染井門付近から下水道に余水を排出するという。
- **心泉亭付近の湧水と「玉藻の磯」への水路〔ページ記載〕**: **六義園内の「心泉亭」のある場所付近にはかつて湧水が見られた**。**心泉亭付近から「玉藻の磯」と呼ばれる池の端方向に向かう水路の存在が、最初の絵図面でも確認できる**〔wanjinによる絵図面判読。駒込界隈に植木職人が集まった理由の一つが豊富な地下水（染井＝ソメイヨシノ発祥の地との関連）という記述と接続〕。屋敷内の飲水は井戸で賄った可能性が高く、「わざわざ千川上水の分水を屋敷地側に引水する可能性は低い」として、旧流路（東洋文庫と昭和小学校の間）は「存在しない可能性が高い」と訂正。
- **訂正その2: 新流路〔ページ記載・goo古地図明治期と合致検証〕**: 旧版（BLOG-236）の流路に代わる訂正流路: **外周堀からの排水路→T字路上（道路右側の「無意味なスペース」）を流れる→マンション前を抜け南下→文京区本駒込1-27と1-28の境界あたりで「goo古地図（明治期）に記されている流れと合致」→道なりに右カーブから突然左折し、龍光寺の西側にあった池（沼）に注ぐ→池の南側を抜け東洋大学敷地に入り、敷地内でほぼ直角に左折→蓮久寺・最乗寺の東側を進む→都営三田線白山駅をかすめるように進み→白山下交差点の西側付近で指ヶ谷支流（仮）と合流**〔本駒込1-27/1-28境界付近で「右岸からの流れ・左岸からの流れと思われる暗渠」の2本を観察する写真つき。合流点がgoo古地図明治期と合致する検証方法を示した点が本シリーズで方法的に重要〕。**六義園の余水排出はある時期廃止されているが理由・廃止時期は定かでなく、東面・南面の堀を埋め立てた時期との先後も判明していない**と明記〔未解決事項の明示〕。
- **道路供出の実例（10/8追記）〔ページ記載〕**: T字路の「無意味なスペース」について、**現在の基準では4m以上が道路とされる条件に対し、該当路地は2.24mの幅員で、無意味と称したスペースが0.88m**。片側だけが道路として認められる余地を供出したもので、現状はポールと鎖による封鎖、という**道路供出（4m基準）の実例**の観察〔2項道路・4m規制（PAP-082の道路幅員規定の変遷と対応する現地実例）〕。
- **鶏声ヶ窪＝傾城表記と『江戸砂子』の故事〔ページ記載〕**: 鶏声ヶ窪（けいせいがくぼ）は**江戸期の地図では「傾城」という表記が多い**。『江戸砂子』によると**中山道沿いの古河藩下屋敷辺り（現在の東洋大学の西側）から夜ごと鶏の声が聞こえ、地面を掘ったところ金銀の鶏が現れた**という故事に基づく地名と紹介し、「後付けの胡散臭い説のような気がします」と評す〔『江戸砂子』の文言はwanjin経由の二次引用〕。また、武家屋敷から管轄の異なる寺社領を掘り進める水路は考えにくく、寺社領を抜けない流路設定が妥当とする推理は、訂正流路の根拠の一つ〔論理的推定〕。
- **駒込1-10から藍染川へ流れる支流の訂正〔ページ記載〕**: **lotus62ブログのコメント欄に投稿した「駒込1-10あたりから藍染川に流れる支流」は、六義園の余水排出には関与していないものと思われる**と訂正〔wanjin自身の旧説の撤回。六義園余水と藍染川系支流（BLOG-238の東大敷地内分水嶺推定とも接続）の分離〕。
