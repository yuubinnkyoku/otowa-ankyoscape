# [BLOG-169] Code for Nerima「地図にない川（千川上水編）」

- **書誌〔確認：open_url・本文全文〕**：地域テック団体Code for Nerimaのnote記事。2018年4月22日投稿。練馬区内の千川上水（下石神井〜立野町〜関町）を対象にした入門的解説。団体noteとしての流域記録はrepo未収録だった。
- **立野橋の案内版〔観察：repo初出〕**：**立野橋の交差点の角に「千川上水と庚申塔の案内版」がある**〔上石神井の庚申橋（[BLOG-102](BLOG-102.md)）とは別地点の案内版。千川通り沿いの行政案内版の分布記録として加える〕。
- **下石神井の暗渠出口〔観察〕**：**下石神井の西武新宿線・千川通り・井草通りが交わる踏切の脇に千川上水の暗渠の出口**が見える〔[GOV-072](../gov/GOV-072.md)の下石神井4-29開渠残存と同一箇所の2018年時点の観察記録〕。ピンク色のレトロな給水塔（西武新宿線の車窓から見える）にも言及〔[BLOG-143](BLOG-143.md)の水道施設文脈〕。
- **開渠・暗渠の往復と音の観察〔観察〕**：立野橋〜青梅街道の緑道整備区間（「最近整備が終わった」＝2018年時点）を抜けると開渠が現れ、吉祥寺通りを渡って再び緑道下の暗渠へ戻る、という開渠・暗渠の往復構造を記録。**「暗渠の入り口に立って耳をすますと、木漏れ日の下で心地よい小川のせせらぎと、暗渠の奥からゴーっという低音の水の叫び声を同時に聞くことができる」**〔開渠区間の音環境の観察記録〕。畑地（キャベツ畑・ネギ畑・ビニールハウス）と開渠の並存＝2018年時点の土地利用記録。
- **位置づけ〔解釈〕**：内容は入門的再構成が中心だが、**2018年時点の立野橋案内版・緑道整備直後の状態・開渠区間の音と土地利用の観察**はrepoの時系列記録に加える価値があると判断し資料化。
