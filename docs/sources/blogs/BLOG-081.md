# [BLOG-081] Natrium.jp 谷端川南緑道その1

- **直接確認（2026-11-11、open_url・本文全文）**：谷端川南緑道（川越街道〜要町通り＝旧前田上橋〜御嶽橋区間）の2017年9月16日現地観察記録。**BLOG-001（水窪川編）・BLOG-002（弦巻川編）と同じシリーズの谷端川編だが、repoでは本シリーズ（yabata01〜08）を全体として未資料化だった**（[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)がyabata08を参考リンクとして引くのみ）。
- **橋のモニュメント〔観察〕**：緑道では**暗渠化の際に欄干を模した車止めに橋名が書かれたモニュメント**が残されており、**熊野橋・他領橋・境井田橋・南橋・御嶽橋**などを確認したと記す。写真はすべて2017年時点の観察であり、現況の維持状態は未確認。
- **東西方向の支流水路敷〔観察〕**：旧前田上橋〜御嶽橋間の谷端川沿いには**櫛の歯状に東西へ伸びる水路敷**が複数あり、西向きは少なく東向きが多いと観察。**境井田橋南側の東向き水路敷**（東側道路まで通り抜け可能）、**他領橋南側の東向き水路敷**（行き詰まり）などを記録。
- **南橋で西から合流する支流〔推定：natriumの空中写真読図〕**：南橋から山手通り「山手通り中丸」交差点に向かい、**谷端川北緑道の中丸橋で西から合流する支流**が分かれていたとし、**土地の境界線が南橋まで斜めになっている**ことが空中写真で読めるとする。地上は住宅密集で水路跡は残らない。〔観察＋二次読図／流路は仮説段階〕
- **御嶽橋の東へ分岐する支流〔観察〕**：御嶽橋のたもと（サワガニの彫像地点）で東へ分岐する支流の水路敷が、**他と違って補助173号線の西に沿ってかなりの長さで伸びている**のを確認。蓋暗渠ではなく側溝状と観察。**補助173号線の整備工事が当時進行中**だったことも記録。
- **repoへの関連〔観察〕**：南緑道の橋名モニュメント・車止めの設計（欄干模擬＋橋名記載）は、[BLOG-069](BLOG-069.md)の橋跡目印27橋観察・[BLOG-070](BLOG-070.md)の一の橋二の橋「再現」との異同照合に使える2017年時点の一次観察。本ページ自体は橋名考証史料ではなく現地観察記録。
- **制限〔未解決〕**：各水路敷の地籍図上の帰属・流向・開渠期の実態は本文では検証されていない。
