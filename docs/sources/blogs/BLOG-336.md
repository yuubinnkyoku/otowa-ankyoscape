## 内容メモ

- **〔確認: 図書館資料の二次転記〕** 江古田周辺の用水路資料として「**江古田散歩**」（中野区ことぶき大学大学院）と「**懐かしい江古田村の生活と自然**」の2点を参照。**北へ流れる千川上水から江古田村には稲利用に5つの分水があった**＝「**中村分水**」「**中新井分水**」「**弁天分水**」「**濯川（すすぎがわ）分水**」「**江古田分水**」〔5分水の併記リスト＝repo grep新出の文言組。「江古田散歩」「懐かしい江古田村の生活と自然」の書誌はrepo未収録＝本文・刊年とも未特定〕。
- **〔二次転記〕** 「懐かしい江古田村の生活と自然」には大正初期の古地図が掲載され**江古田村分水とその支流まで描かれる**（支流の流路は現代との対比図がないため特定できず）〔本文未確認のまま引用〕。
- **〔観察〕** 分水地点＝千川通りの**旭丘1丁目**の交差点。千川通りの片側の歩道が幅広で「いかにもかつての水路」の形を残す〔BLOG-320（要町三丁目付近への収束）・BLOG-166（千川通りの上流端）の旭丘側の具体化〕。
- **〔観察〕** 哲学堂ちかくの**野方給水塔**（現在は災害用の水備蓄装置）＝**荒玉水道として砧・大谷口と繋がっていた**〔水道ネットワーク叙述。荒玉水道自体はrepo既出の文脈に整合する再叙述〕。
- **〔観察・repo初出〕** 江古田湯（四角い煙突）＝暗渠サインの銭湯。**目白通りの「こぐま公園」＝かつて池があり農家が大根を洗う洗い場だった**（資料による）〔こぐま公園の池＝大根洗い場の文言はrepo grep新出〕。
- **〔観察・repo初出〕** 目白通りを渡った歩道橋下に**橋の欄干跡**（用水の遺構候補）。
- **〔観察〕** 江原公園の桜並木に沿って用水が流れていた・団地敷地の延長線上に「ここからまた流れるよ」と教えるような歩道スペース・東橋で江古田川（この区間は開渠）に合流・合流口が観察できる〔BLOG-166（2020年・東橋下流側の排水口で現在も水が流れる）の2010年時点の先行観察に対応〕。
- **〔推定〕** 支流は団地北側の崖地帯の斜めの土地割りを通り、廃品回収会社の敷地を抜けて江古田川に合流するとの私見（古地図ではさらに西進するが、と明記）〔著者の推定〕。
