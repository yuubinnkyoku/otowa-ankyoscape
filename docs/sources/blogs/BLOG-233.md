# [BLOG-233] わんじん「谷端川　－名前に偽りあり、の状況に陥った駅の顛末－」（2018-04-11）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文）**: wanjin「水の行方を追って」西大下水（谷端川）カテゴリの2018年4月の記事。**国道254号（前田上の橋）から下板橋駅そばまでの「谷端川北緑道」区間**を辿る。谷端川の水源を豊島区要町二丁目・粟島神社境内の弁天池、延長約11kmの神田川最長支流とする定義は同シリーズ既出の文言どおり。
- **北緑道の橋列〔観察: 記事記載〕**: 国道254号を越えたところから東武東上線下板橋駅そばまでは**板橋区管轄の谷端川北緑道**で、豊島区管轄の南緑道と「造作が明らかに異なる」と観察。橋の順: **前田上の橋（国道254号付近）→前田橋→北浦上橋→北浦橋→中丸橋→金井窪橋→西前橋→豊橋**。うち**前田橋・北浦上橋・北浦橋は耕地整理時に設けられた橋で「江戸・明治期にはなかった橋」**、**中丸橋が江戸・明治期からあった橋で、中丸橋までが耕地整理の対象地域**と整理〔wanjinの現地観察と既往調査の引用。耕地整理の範囲の中丸橋境界説は他資料との照合が必要〕。
- **「金井」=鉄錆湧水語源説〔ページ記載・典拠不明〕**: 金井窪橋の「金井」は**鉄錆を含んだ湧水を意味する**とし、かつての金井窪村は錆水の湧く窪地だったかもしれない、と記す〔典拠は本文に示されず。金井窪の地名由来説の一つとして記録〕。
- **中丸川・出端川の左岸合流〔ページ記載〕**: **金井窪橋のすぐ先の左岸に千川上水から分水を受けた「中丸川」が合流**、**西前橋の北で左岸に「出端川」が合流**し、出端川合流点を過ぎると谷端川は東に向きを変える。両支流は「改めて紹介する機会を設けます」と予告されており、中丸川はentry-248（未登録）、出端川も同ブログで別途扱われている〔流路の位置特定はwanjin流路地図の参照による二次記述〕。
- **西前橋＝高田雑司ヶ谷道〔ページ記載〕**: 西前橋を通る道は**高田雑司ヶ谷道と呼ばれた古道**で、「北は中山道仲宿、南は現在の池袋駅付近から雑司ヶ谷、高田方面へと通じている道」。現在は国道254号や線路で南側の道筋が定かでないとする〔高田雑司ヶ谷道の経路の独立記述。古道の一次典拠は不明〕。
- **下板橋駅＝東上線開業時の起点説〔ページ記載〕**: 豊橋の北側（東武百貨店倉庫・配送センター敷地）にかつて下板橋駅があり、**東武東上線開業時の起点駅**。南側の引込線敷地内に0キロポストや東上鉄道発祥の記念碑が設置されているという。**もともと東上本線は大塚辻町（現在の丸ノ内線新大塚駅付近）を起点とする免許を取得していたが、当時の東京市に阻まれ当駅から開業せざるを得なかった**、移転は「どうも1930年代（おそらく昭和10年頃）」と記す〔免許・移転の年次は典拠示されず「定かではない」と明記。大塚辻町起点計画の独立傍証として、第5回ノートの「東上線大塚辻町起点計画」記述と接続〕。
- **金井窪駅の沿革〔ページ記載〕**: 高田雑司ヶ谷道の西側・山手通りの方向に**金井窪駅（1931年9月開業、大山駅とほぼ同時期）**があった。**1945年4月13日の城北地区空襲**で池袋駅・東武堀之内駅（現・北池袋駅）・中板橋駅が焼け、金井窪駅は駅舎が焼け残ったものの東武堀之内駅とともに営業休止。**1951年に東武堀之内駅は北池袋駅として復活したが、金井窪駅は復活せず廃止**。金井窪駅と下板橋駅の駅間距離は400m弱。wanjinは「下板橋〜大塚辻町間の開業が不可能と判断されたために池袋駅方向に軌道を曲げる必要が生じたことが移転の原因であろうか」と推測〔移転原因は推測と明記〕。旧駅所在地は板橋区・移設先の現在地は豊島区で「名前に偽りあり」。
- **地籍図根点の観察〔観察〕**: 前田上の橋歩道に板橋区役所の地籍図根点があり、GPS測量普及以前のアナログ測量標識としての言及〔現地観察の記録〕。
