# [BLOG-137] 弦巻川暗渠散歩⑦ 護国寺〜音羽児童遊園

- **直接確認（2026-11-12、open_url・本文全文）**：ねこたま「ある日突然、世界から音が半分消えた」の弦巻川暗渠散歩シリーズ第7回（**2020-06-11**）。第1回（[BLOG-075](BLOG-075.md)）は既収録だったが、**⑦はrepo未収録だった**。続編⑧（江戸川橋方面）の所在は未確認。
- **護国寺前の流路読図〔観察：記事の推論〕**：東京時層地図で、弦巻川は**首都高護国寺インター入り口付近**を流れていたと読む。**この頃の不忍通りは現在よりやや北側**を通っていたことも地図から読み取る。橋・流路の復元は地図の直接判読による推定であり、原図の再確認は今後の課題。
- **腰掛稲荷神社〔観察〕**：不忍通り脇・ビルの影に隠れた小祠「**腰掛稲荷神社**」を確認。弦巻川・水窪川流域の宗教的構築物一覧（[PAP-027](../papers/PAP-027.md)の19か所一覧等）に加えうる候補だが、当神社と川の关系的史料はない。**〔未解決〕**。
- **青柳小学校の移転〔観察・聴取〕**：時層地図上の小学校マーク（＝弦巻川沿い）の位置について、**地元の人から「青柳小学校があったときにここを通っていた」**と聞き、**首都高速道路の建設時に不忍通りの反対側（旧陸軍埋葬地側）へ移転した**と記す。2020年時点の一次聴取であり、移転年代・校舎位置の裏付けは史料確認待ち。〔高速建設＝1960年代。弦巻川旧河道に学校が立地していた例として、[BLOG-121](BLOG-121.md)の谷端川沿い学校と並ぶ記録〕
- **高速下の川跡歩道〔観察〕**：大塚警察署交差点から高速道路側へ戻った先に、**「いかにも暗渠な感じのクネクネ曲がりながら進む歩道」**があり、高速下には児童公園が続く。川の旧河道に沿った現況の空間構造の観察として記録する。**旧河道と歩道の一致は記事の推定**であり、平面・縦断での裏付けはなし。
- **制限**：本記事の流路復元は東京時層地図の読図に依存し、原図葉の直接判読・空中写真照合は未実施。⑧の続き（江戸川橋合流部）が実在すれば追加観察候補。
