## 内容メモ

- **〔確認〕** 2020年3月13日付日刊ゲンダイ『北上次郎のこれが面白極上本だ！』で『暗渠パラダイス！』（BOOK-042）の書評が掲載されたこと〔書評の存在記録〕。
- **〔確認・repo初出〕** 書評が触れたのは『暗渠パラダイス！』**[コラム3]「キャラが際立つ板橋三大暗渠（東京都板橋区）」**の部分＝**「板橋三大暗渠」というコラムの存在**が本記事で初めて書誌レベルで確認できた。
- **〔確認・repo初出〕** 『板橋マニア』（GOV-620）に掲載した「板橋三大暗渠」記述は、同書初稿を「**暗渠三兄弟**」という設定（長男・次男・末っ子として3つの暗渠を紹介）で書いたが、多数著者分担のトーンと合わずボツになり、「まじめに」書き直したもの＝**自著『暗渠パラダイス！』で初稿の着想（「ズッコケ三人組」に変えて）を披露した経緯**。
- **〔確認〕** 「全然個性の違う三つの暗渠が仲良く隣り合っている」のが面白さという捉え方は初稿から不変、との叙述〔**板橋三大暗渠＝性格の異なる3暗渠の隣接**という性質の文言〕。
