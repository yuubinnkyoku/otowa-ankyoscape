# [BLOG-277] 西東京水路跡散歩「境村分水」（1）〜（5）〔repo初出の境村地先取水表記と杵築大社池枝水路・仙川寿橋旧流路という新規観察〕

## 内容〔確認: 本文全文5本・2026-11-22取得〕

- **書誌〔確認〕**: アメーバブログ「西東京水路跡散歩」（musasinowalker・[BLOG-272](BLOG-272.md)〜[BLOG-276](BLOG-276.md)と同一筆者）の**境村分水（1）〜（5）**＝[entry-12589188337](https://ameblo.jp/musasinowalker/entry-12589188337.html)〔2020-05-17〕・[entry-12589609521](https://ameblo.jp/musasinowalker/entry-12589609521.html)〔2020-05-18〕・[entry-12589794130](https://ameblo.jp/musasinowalker/entry-12589794130.html)〔2020-05-19〕・[entry-12589903346](https://ameblo.jp/musasinowalker/entry-12589903346.html)〔2020-05-20〕・[entry-12590060904](https://ameblo.jp/musasinowalker/entry-12590060904.html)〔2020-05-21〕。玉川上水南側の境村（現武蔵野市境〜小金井市境南町）へ飲用水を供給した用水の、梶野橋南西の砂川用水終端分岐点から武蔵境駅東側・境橋方面の枝網までの現地トレース。
- **境村分水の設置史（1）〔確認: 本文直接引用・repo初出の「境村地先」表記〕**:
  - 「**境村分水は手持ち資料が殆ど無く詳しいことはわからないが、少なくとも1870年以前から存在している飲用水路で**」＝**1870年（明治3年）以前からの存在＝飲用水路**〔「手持ち資料」の本体は未特定〕。
  - 「**少ない資料の中の表記で、取水場所が品川用水と同じ「境村地先」からとなっている、恐らくくぬぎ橋～境橋の間辺りではなかろうか**」＝**取水場所の表記「境村地先」＝品川用水（[GOV-284](../gov/GOV-284.md)の品川用水九ヶ村組合「境村地内」分水口）と同じ表記系統という指摘＋取水口のくぬぎ橋〜境橋間推定**〔repo初出（grep確認で0件）。「境村地先」の元資料は未特定のため、出典を開く課題として記録〕。
  - 「**掘削年はわかりませんが、１７００年代中期～１８００年代初頭に整備されたのではないかと思います**」＋「**掘削後の初期は玉川上水から直に取水していたので、ここから境橋付近までの水路は、１８７０年ごろの砂川用水延伸に合わせて整備されたと考えています**」＝**整備年代（1700年代中期〜1800年代初頭）・当初の玉川上水直取水・1870年頃の砂川用水延伸に合わせた区間整備の推定文言**〔筆者推定・候補扱い。1870年=明治3年は[BLOG-275](BLOG-275.md)の案内板1870年統合文言・[GOV-510](../gov/GOV-510.md)の明治3〜5年再編と同年次〕。
  - 「**水路の1本は梶野新田用水のと接続されており、最終的には深大寺用水に還流されていたようだ**」＝**梶野新田用水との接続→深大寺用水への還流**＝[BLOG-267](BLOG-267.md)（連雀通りで合流し深大寺分水へ）系の名称体系の実流路側の対応。
- **桜堤遊歩道（1）〔確認〕**: 梶野通り東側の水路敷遊歩道に「**桜堤遊歩道という名前が付けられていた。～号線ではないのか、看板も金属製の立派なもので他より扱いが良い**」＝**小金井市内の境村分水の遊歩道名＝桜堤遊歩道（「～号線」命名ではない）**＝[BLOG-268](BLOG-268.md)（まろん通信Vol.45「桜堤遊歩道」＝武蔵野市の標識・小金井市側は約100m）の**小金井市側区間の独立観察で市境をまたぐ遊歩道名の連続が両系統で一致**。くぬぎ橋の手前で遊歩道は北折するが「**この北へ延びる遊歩道部分は後年に付け足された部分で、本来の水路は直進してくぬぎ橋通りを越えていた**」＝**近代の付け足し区間と本来流路の分離の読み**〔観察〕。
- **仙川の旧流路と寿橋（2）〔確認: 本文直接引用・仙川流路史への新データ〕**:
  - 「**実は仙川は１９５０年代頃まではもっと南側を流れていたようで、実際水路が仙川と繋がっていたのは寿橋の所だった。仙川の寿橋から、現在この水路跡が仙川にぶつかるまでの区間は、この加水用水路の流路が使われている**」＝**仙川＝1950年代頃まで南側を流路とし、境村分水の枝水路（加水用水路）は寿橋で接続、現在の仙川の寿橋〜枝水路合流点までの区間は枝水路の流路を流用という流路転換の観察**＝[BLOG-272](BLOG-272.md)（同ブログおまけ・1947〜50年代の新流路掘削説）に**接続点（寿橋）と流用区間の具体系を与える新規観察**〔「1950年代頃までは」の元資料は未特定〕。
  - **武蔵境駅周辺の仙川の暗渠化（4）**: 「**現在の仙川は武蔵境通りから先が暗渠化されており、武蔵境駅北東部の都道１２号線沿いまで行かなければ姿を現しません**」＝**武蔵境通り以東の仙川の暗渠化**。
  - 「**境村分水は途中で仙川を越える。梶野新田用水は仙川を越えるのに築樋を使ったが、ここはそれほど高低差が無いのでそのまま越えていたようだ**」＋都道側の枝水路「**この水路は東へ向かい、武蔵境通りを越えて仙川を樋で越えて対岸まで続いていたとの事**」＝**境村分水本流の仙川横断（高低差がなく開渠越え）と枝水路の仙川樋越えの混在**〔「との事」の伝聞〕 ＝[BLOG-275](BLOG-275.md)（仙川への加水用水路群）・[GOV-504](../gov/GOV-504.md)（仙川悪水）と並ぶ 仙川の流路・水利構造の観察点。
- **杵築大社の枝水路（3）〔確認: 本文直接引用・repo初出〕**: 「**武蔵境駅南側へ延びる水路はとくに長く、杵築大社の方まで伸びていました。ただ、水路の終点が杵築大社の池に繋がっていたかは不明です**」＋「**１６００年代中盤、地域の守り神として創建された杵築大社。大きな富士塚がある神社で、その脇には池がある**」＝**境村分水の枝水路の終点＝杵築大社（1600年代中盤創建）方面・富士塚と池の現況**〔repo初出（grep確認で0件）。池への接続は「不明」と明記〕。
- **武蔵境駅北側の水路網（4）（5）〔確認〕**: 境橋南東の分岐（武蔵高校グランド北側）から都道123号沿い・武蔵境駅を中心に、境二丁目第一交差点で二手に分岐（ロータリー歩道として現存の南下流と南東流）・境山野公園への枝（「**公園はここより低地にあるので、何かの用途で分水をそこまで引いていたのだろう**」）・武蔵境駅北口のすきっぷ通り周辺の斜め流路（「**5年ほど前まで丁度正面の古民家前のように狭い道**」）・日本医科大学付近の分岐・武蔵境通り以東の駐輪場脇水路敷・仙川交差部の再横断。「**古地図によれば、この水路は中央線を越え北側に出たあたりで消えていた。７０年ほど前は森になっているようで、何の用途で水を引く必要があったのかは不明**」＝**用途不明の流末の記録**〔観察〕。
- そのほか: 境橋（五日市街道・上水桜通り・都道123号を結ぶ玉川上水の大きな橋）・上水桜通り沿いを流れてきた境村分水の流向・桜野小学校北東の路地の水路敷（玉川上水沿いへ北上）＋南向きの引き込み（「**痕跡もなく用途も不明**」）・境5丁目交差点付近の枝（50mほど北東）・境南通り（南口）で東西に分かれ消える流末。

## repoとの関連〔観察〕

- ①**「境村地先」取水表記**: [GOV-284](../gov/GOV-284.md)（文久元年広書）の品川用水九ヶ村組合「境村地内」入樋と、本記事「境村分水＝境村地先から取水・品川用水と同じ表記」との**「境村」水利語彙の対応**＝境村の水利史（境村分水・品川用水・千川上水〔境橋分水口・[BLOG-113](../blogs/BLOG-113.md)〔明治4年境橋分水口新設〕〕）を横断する次の照合課題。**境村分水当時、境村は同一の地域水利の枠（境村地先）で水を得ていた**という観察候補（品川用水・境村分水・千川上水境橋分水口の三者の関係は断定しない）。②**仙川の寿橋接続・流路流用（2）**: [BLOG-272](BLOG-272.md)の「1947〜50年代新流路掘削説」に**具体的な旧流路区間（寿橋）と流用現象（用水路跡→河川流路）の実体**を与え、仙川流路形成史仮説（[対照表](../../地名・河川名対照表.md)第259回行）を補強する第2観察。③**杵築大社の池**: 境村の鎮守系池（1600年代中盤創建）と枝水路の関係は、亀久保田圃の池・市杵島神社の溜池（[BLOG-264](BLOG-264.md)）と同じく**新田村落の池用水構造の候補**で、梶野新田用水・境村分水の灌漑対象側の実体資料。④**武蔵境駅周辺の水路網の消滅**: 武蔵境という鉄道駅前都市の水路の消滅形（開発と区画整理・団地建替〔2000年代〕）を、宅地化以前の森の流末とセットで記録。

## 意義〔観察〕

- 境村分水は[対照表](../../地名・河川名対照表.md)第259回行（[BLOG-267](BLOG-267.md)・[BLOG-268](BLOG-268.md)由来）と[GOV-284](../gov/GOV-284.md)の境村関係文言で間接的にしか把握していなかった用水で、本ファイルは**初めての全流路の系統的観察**として「境村地先」取水表記・くぬぎ橋〜境橋間の旧取水推定・杵築大社池枝水路という3点の**新規の水利語彙・流路実体**を供給する。特に**仙川の寿橋旧流路と加水用水路の流路流用**は、仙川の近代流路改修が**既存の用水路を下敷きに行われた**ことを示す観察で、[BLOG-272](BLOG-272.md)の流路形成史仮説を具体的な場所で裏付ける初のデータである。

## 制限・未解決

- ①「**手持ち資料**」（「境村地先」表記・1870年以前の存在・1950年代頃の仙川南側流路の出典）は未特定＝**資料本体の確認が最大の課題**。②整備年代（1700年代中期〜1800年代初頭）・1870年砂川用水延伸に合わせた整備・くぬぎ橋〜境橋間取水はすべて**筆者推定**。③杵築大社の池への接続は「不明」と明記されたまま（池の現況写真の湧水流入は観察されるが由来は不明）。④境山野公園枝の用途・桜野小学校の南向き引き込み・武蔵境駅北側の中央線越え流末の用途はいずれも「不明」のまま記録。⑤品川用水「境村地内」と境村分水「境村地先」の表記差（地内/地先）の意味・千川上水境橋分水口（[BLOG-113](../blogs/BLOG-113.md)）との関係は断定しない。⑥当ブログの世間話10・15や白子川・黒目川シリーズはrepo関心水域の外縁のため本回は未取得。
