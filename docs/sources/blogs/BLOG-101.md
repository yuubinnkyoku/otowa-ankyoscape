# [BLOG-101] 「漢文石碑を読み歩く 千川堤植桜楓碑」（bon-emma・円満字二郎HP）

## 書誌・確認範囲

- 個人サイト「円満字二郎のHP」内の漢文石碑読解シリーズ。ページの公開年は未詳。直接の open_url は 403 Forbidden のため、[Wayback Machine の2025年5月13日スナップショット](https://web.archive.org/web/20250513110308/http://bon-emma.my.coocan.jp/sekihi/senkawadutsumi.html)で本文・碑文全文を確認。画像本文は未確認。
- 対象の石碑は**千川堤植桜楓碑〔所在地: 練馬区小竹町1-59-2 江古田浅間神社境内・建碑: 大正4（1915）年11月・撰幷書: 東京府北豊島郡長 正七位勲六等 大野徳太郎〕**。[GOV-056](../gov/GOV-056.md)が言及する「江古田浅間神社に石碑」（大正4年・堤の桜と楓=「新小金井」）の碑文全文採録としてrepo初出。

## 内容メモ（碑文の叙述〔確認〕＋サイト著者の訓読・解説）

- **碑文記載の千川上水沿革〔確認: 碑文の記述。行政原典との照合は別途必要〕**:
  - 千川上水之始は**元禄9年（1696）**、新座郡保谷から豊島郡巣鴨まで凡六里、湯島・上野・浅草に亘る。
  - **宝永4年（1707）**、上水の両岸に植樹し、且つ灌漑を許す。
  - **享保7年（1722）**、故ありて上水を止む（以後、沿革殆ど廃）。〔repo既知の享保7年上水（飲料水供給）廃止・用水格下げと整合〕
  - **慶応元年（1865）**、滝野川に反射炉を築き、此の水を用うことを命ず。〔[BLOG-053](BLOG-053.md)（豊島区教委説明板転記）の1865年王子分水=反射炉用と対応する反射炉関連記述の第二源泉〕
  - **明治3年（1870）**、又た廃す。
  - **大正3年（1914）**、下練馬村の篤志者が水行を修め荊棘を伐り桜楓を植える議を建て、今上（大正天皇）践祚の大礼記念とす。村長が郡長に稟け、**中新井・長崎・上板橋の諸村長に知照、各村村会決議を経て四村聯合**、府知事の允可を得る。有志が貲を捐て労を援き数月で功成り、**桜楓実に千数百株、村落を経て田圃を過ぐること蜿蜒一里二十余町（約6.2km）**に亘る。碑文に**武蔵野鉄道が流れに沿いて開通**とある（池袋〜飯能間通車は大正4年）。
- **銘文〔確認〕**: 「千川上水昔汪洋 北及忍岡南聖堂…擬凌玉川雄一方…合同民力祝大嘗 此挙此功弗可忘 春秋長作後人慶」。**「玉川上水を凌ぎ一方の雄となろう（玉川を凌しのぎ一方に雄たらんと擬す）」**と結び、地元の自負を記す。
- **碑の移転〔確認: サイト著者の記述。聞き取りの出どおりは未特定〕**: 元は江古田駅南側の千川通り沿いに建っていたものを**区画整理の際に移動**したという。現地に案内板はない。

## 三河川への使い方

- 千川上水の沿革（1696開削→1707植樹・灌漑許可→1722上水中止→1865反射炉→1870再廃→1914植樹事業→1915建碑）を**一次史料（碑文）レベルで年代順に裏付ける**資料。[GOV-056](../gov/GOV-056.md)の「大正4年・桜と楓1,600本」記述は本碑文の「千数百株」とほぼ整合するが株数表記に差異がある。
- **中新井・長崎・上板橋・下練馬の四村聯合**という実施体制は、谷端川への長崎村外三村分水（[GOV-005](../gov/GOV-005.md)）を巡る村連合の文脈と並べて読める材料になる〔推定: 制度史的関連付けは本稿の範囲を超えるため、仮説として記録〕。

## 制限・未解決

- 碑文採録はスナップショット依存で、現地での実物照合・石材・碑寸は未確認。「千数百株」vs「1,600本」（[GOV-056](../gov/GOV-056.md)）の差異の決め手なし。
- 碑文の年代記述は建碑時（1915）の認識であり、元禄9年開削・宝永4年灌漑許可等の各年代を行政原典（千川家文書等）と照合する必要がある。
- 移転の「区画整理」の時期・出典は未特定。
