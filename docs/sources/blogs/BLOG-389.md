# [BLOG-389] Natrium.jp「エンガ掘と周辺の水路敷群（大谷口の支流）」

- **書誌〔確認：curl本文全文・2026-11-28取得〕**：Natrium.jp エンガ掘シリーズ第2頁（repo初出URL）。写真は2017年4月29日・5月6日・5月20日撮影（一部2025年2月26日追記）。
- **大谷口の支流〔観察・読図・repo初出〕**：エンガ掘の東側に「結構大きな石神井川の支流」があるが名前は付いていないらしい〔本文による「大谷口の支流」の仮称〕。**現在の流路（山崎橋から東へ）はあとから付け替えられたもので、もともとは下流の上板橋付近で石神井川に合流していたらしい**〔推定〕。蓋暗渠の残存区間・車両通行止めの水路敷（資材置き場）などの現況を記録。
- **山崎田んぼと橋脚照明〔観察・repo初出〕**：山崎橋の中央部に**月を模した照明**がある。**「昔この辺りは山崎田んぼと呼ばれ、水を張った田んぼに映る月が美しかったという故事に倣って作られているらしい」**〔伝聞〕＝[BLOG-124](BLOG-124.md)（山崎橋平成6年架替の三日月・星の帯状意匠＝山崎田んぼの月の記憶の推測）の**独立傍証候補**（照明の存在レベル。断定せず）。
- **大谷口給水所の沿革〔確認・repo初出の年次列〕**：千川上水脇の大谷口給水所には**戦前の昭和6年（1931年）に完成し、昭和47年（1972年）まで現役だった給水塔**があった。老朽化により**平成17年（2005年）に取り壊され、平成23年（2011年）に改めてポンプ棟として建てられた**。**かつて多摩川の砧浄水場から荒玉水道を通って水が運ばれ、ここから王子方面へ給水していた**〔本文による沿革説明〕〔給水所存在自体は[BLOG-145](BLOG-145.md)水道端交番・対照表で既収録だが、1931完成→1972現役→2005取壊→2011ポンプ棟の年次列と砧浄水場〜荒玉水道〜王子方面の給水系統説明はrepo初出〕。
- **千川上水の漏水〔伝聞・repo初出〕**：大谷口給水所の谷（日大看護学校谷間）には**「千川上水の漏水が流れて行っていたそうな」**〔伝聞〕＝[BLOG-104](BLOG-104.md)系の千川上水漏水説（エンガ堀水源）の傍証候補・[BLOG-111](BLOG-111.md)の谷迂回文脈と対校。
- **日大板橋病院西側の谷〔観察・repo初出〕**：日大医学部グラウンド西側の逆Y字の谷（昭和22年・昭和38年空中写真の読図）。東側の谷間にはかつて**溜池があったともいう**〔伝聞〕。谷間の密集住宅の**平成14年（2002年）〜平成21年（2009年）の改良事業**〔確認〕。谷頭はV字谷で、大谷口給水所の坂上に達する。
- **大谷口氷川神社〔確認・repo初出〕**：大谷口の丘上の氷川神社。**創建年代は不明で、延宝2年（1674年）には記録に見え、16世紀まで遡る可能性もあるという**〔伝聞〕。西側は切り立った崖で「かつて大谷を流れる水が削っていったのだろう」〔推定〕〔池袋本町の氷川神社（[ORG-028](../org/ORG-028.md)・[ORG-029](../org/ORG-029.md)）とは別の神社〕。門前商店街「パステル宮の下」は石神井川から大谷口通り（旧大谷道）までつながる〔観察〕。
- **大谷口の地名考察〔推定〕**：「大谷口」は大きな谷の入口を指す地名とし、その谷の候補として日大板橋病院西側の谷を挙げる〔筆者の推定〕。
