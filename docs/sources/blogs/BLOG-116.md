# [BLOG-116] 東京新聞2026年8月22日「関東南部で激しい雷雨…高島平」

- **書誌〔確認〕**：東京新聞デジタルの報道記事（2026年8月22日20時27分配信、宇佐見昭彦記者）。2026-11-12に本文全文を直接取得〔[BLOG-115](BLOG-115.md)（不動産系ブログによる気象情報の二次解説）を報道一次記録で補強〕。
- **雨量の実測値〔確認：記事〕**：レーダー解析で板橋区120ミリ以上・北区・豊島区・戸田市約100ミリ。**雨量計による実測では練馬区66.5ミリ・都心（千代田区）60ミリ**（千葉県君津市75.5ミリ）〔①「記録的短時間大雨」の報道時点の実測値の記録。②**練馬区の66.5ミリ実測**は千川上水流域（上石神井〜江古田〜板橋）と弦巻川・水窪川源流域（池袋方面）を結ぶ地域の観測値として、千川・谷端川の下水道幹線への流入を考える際の参考値〕。
- **高島平団地の浸水〔確認：記事〕**：高島平団地（板橋区）の商店街で午後7時ごろ、店や通路に入った水をかき出す作業。店員の話として**1時間ほどで水かさが上がり午後5時半前後には低い所では大人の膝下まで**、**マンホールの隙間から水が噴き出しているのを見た**。店に入った水の深さは5センチほどで、**「浸水は一昨年7月以来」**〔①高島平（新河岸川低地・谷端川流域の外側）の浸水の詳細な聞き取り記録。②マンホール噴出は下水道の満管時の噴出現象の記事上の観察〔推定〕。③「一昨年7月（2024年）以来」の浸水歴の聞き取り。高島平は谷端川流域からは外れるが、板橋区全体の冠水記録（[GOV-074](../gov/GOV-074.md)浸水履歴の令和8年度更新版での2026年8月22日分の掲載待ち）の予備情報として記録〕。
- **レベル4氾濫危険警報〔確認：記事〕**：神田川（中野区・文京区等）と善福寺川にレベル4氾濫危険警報を発表〔**弦巻川・水窪川の合流先の神田川**へのレベル4発表の報道記録。弦巻川・水窪川の流域の雨を神田川本流が受け止めた事象として、[BLOG-107](BLOG-107.md)（江戸川橋合流点石垣）との関連で注記〕。
