# [BLOG-049] 山岡光治「地図豆」14-1 ぐるっと護国寺、弦巻川をたどる

- **直接確認（2026-11-11、open_url・PDF本文）**：個人街歩き資料PDF（地図散歩シリーズ）。池袋駅→丸池→ビックリガード→大鳥神社→清立院→清土鬼子母神→護国寺→江戸川橋の弦巻川・水窪川沿いコース。docs内でURL引用はあったが資料ファイル化は今回が初回。
- **石橋記念石塔〔本文記述〕**：御嶽坂下（清立院付近）に1733（享保18）年建立の「石橋記念石塔」があり、左側面に「當所石橋施主木村氏」と読める文字があるとする。さらに古文書に「寛保二年戌年木村某ト申スモノ当時ノ石橋掛替仕、其節ヨリ木村橋ト愛唱申候」とあると引用する。※引用元古文書の書誌はPDF本文に未記載。河道はここから南へ折れるとする。享保18年建立と寛保2年掛替の関係は本文内で未整理。
- **大鳥神社の下水道施設記念碑〔本文記述〕**：大鳥神社境内に昭和6年（1931）の下水道施設記念碑があり、「このころから弦巻川の暗渠化が始まった」とする。河道は弦巻通ではなく、やや北の都電高架下の道になると復元する（弦巻通とするには高低差の無理があるとする）。※碑の正式名称・現存確認は未実施。
- **字名〔本文記述〕**：丸池から先は池谷戸、西側から合流する谷筋を西谷戸、さらにその先（西武線横断部）を中谷戸と呼んだとする。
- **丸池の空中写真判読〔本文記述〕**：終戦直後（1943年・1946年）の空中写真に矩形の小さな池が存在し、1963年の写真では埋め立てられて住宅地になるとする。※当repoのM372-53・M372-55・M390-33・M737-142・8912-C1-149判読（水面未確認）と食い違う。判読対象コマの特定なし。
- **その他の内容メモ**：清土鬼子母神周辺の弦巻川跡の小路に「今は珍しい清水が流れる井戸」があるとする。『遊歴雑記』（十方庵敬順）文化11年（1814）の池袋の池（三百余坪・西果てで常に迸水湧出）の引用。弦巻通りは弦巻川の蛇行のまま発達したとする一方、河道は都電高架下の道とする復元。江戸切絵図では水窪川（音羽川）は護国寺の塀沿いに続き富士見坂を越えて弦巻川と合流し音羽通り沿いに南下したとする。
- **制限〔未解決〕**：掲載空中写真のコマ番号、引用古文書の書誌、石橋記念石塔・下水道施設記念碑の現地再確認、成立年はいずれも未確認。
