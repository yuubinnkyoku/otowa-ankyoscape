# [BLOG-166] Natrium「江古田川周辺の水路敷群 その1」

- **直接確認（2026-11-13、open_url・本文全文）**：2020年2月22日・29日撮影。Natriumの水路敷シリーズ（[BLOG-001](BLOG-001.md)・[BLOG-102〜104](BLOG-102.md)等）で、江古田川（中新井川）周辺の分水を扱う頁は今回までrepo未収録だった。
- **江古田分水の流路観察〔観察〕**：合流地点＝**東橋（あずまばし）下流側の排水口で、いまでも水は流れている**（2020年2月）。東橋→江原公園（水路は埋め立て）→江原観音堂→目白通り→区界で切れた幅広い道路→**千川通りの上流端**という流路踏査。千川通りからは練馬区側（旭丘）へ遡る。
- **弁天分水＝桜台分水の別名〔repo初出〕**：江古田の森公園西側の支流を「**下新街分または弁天分水（桜台分水とも）**」と表記。[GOV-005](../gov/GOV-005.md)（明治10年樋口伏替願の「字下新街」）の別名表記として記録。
- **濯川の命名〔二次叙述〕**：「濯川という名前がついているが実際には千川上水の分水であって、江戸時代からあった用水路を分水口に位置する武蔵高校が出来た後に命名したもの」＝[ORG-019](../org/ORG-019.md)（1925年命名）と整合する独立叙述。濯川は武蔵大学江古田キャンパス中央を流れるが、千川通り側に分水口の痕跡はない、とも。
- **江古田植物化石層〔参考〕**：東橋付近は最終氷河期（1.6〜1.1万年前）のカラマツ等針葉樹の化石が発見される「江古田植物化石層」。江古田川・千川上水周辺の地形史の文脈資料。
- **その他〔観察〕**：穴守稲荷神社（千川通り沿い・江原町）・東福寺（徳川吉宗鷹狩御膳所）・江古田氷川神社（寛正元年1460創建伝承）等の周辺記事は流域の郷土史の補強。
- **制限〔未解決〕**：千川通り北側の小祠（地蔵尊か）の同定、江古田分水の練馬区側（旭丘）上流部の流路は本頁の範囲外。「その2」以降の取得が次の課題。
