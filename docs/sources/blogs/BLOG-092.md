# [BLOG-092] 千川上水の開渠記憶と尾根筋用水の証言（秋山信行）

- **書誌**: 滝野川探検隊（takitan.com）にJIA城北地域会の秋山信行が寄稿した文章。**公開年月日不詳、2026年11月11日閲覧**。[原記事](http://takitan.com/article/000079.html)。既収録 [ORG-014](../org/ORG-014.md)（JIA関東城北地域会2017まち歩き）と同じ会の別テキストで、**本寄稿自体はrepo初出**。
- **〔観察（記憶）〕** 筆者は**昭和30年（1955）頃、小学生当時に千川上水の開渠を見た記憶**を記す。西武新宿線上石神井駅前から畑の中のバス通りと小川の橋を渡ったとし、その小川を地元で**「スイドウバタ」と呼んでいた**、今も「**水道端**バス停**が残ると記す〔確認：筆者記憶と現存バス停。呼称のその他の史料性は未確認〕。
- **〔観察（記憶）〕** 中村橋駅付近の千川通りの並木は**「千川上水：昭和30年代に暗渠にした堤の名残・並木」で、橋の名が中村橋だった**と記す〔確認：筆者記述。「昭和30年代暗渠化」は上石神井・中村橋区間の時期を絞る記憶証言として、既収録の関村〜西巣鴨系の暗渠化時期論（[GOV-069](../gov/GOV-069.md)の南田中証言など）と区別して扱う〕。
- **〔観察〕** 千川駅方面の歩きで**板橋区との区界の千川通りに「用水路の幅がわかる地面が残されていた」**と記す〔観察：位置は豊島区〜板橋区の区界付近の千川通り沿い。具体地点は本文で特定されない〕。
- **〔推定〕** 千川上水の経路と**練馬区役所・板橋区役所・北区役所の立地が一致すること、豊島区には「千川」の地名が残ること**を指摘し、**尾根筋の開削路（石神井川や谷端川の谷ではなく水道目的の尾根筋）として城北地域を繋いだ**と論じる〔推定：筆者の解釈。区役所立地は事実だが因果は主張にとどまる〕。
- **〔確認・二次〕** 王子への分水（反射炉計画・王子製紙・印刷局抄紙部）の終点は**王子駅前の三角形の広場で貯水池だった**、石神井川は**掛樋・水道橋で渡しており飛鳥山「紙の博物館」収蔵資料で確認できる**と記す〔確認：筆者記述／未確認：紙の博物館収蔵資料の該当番号。王子駅前三角広場=貯水池は既収録の到達点叙述に物理的具体性を与える候補〕。
- **〔未解決〕** 寄稿の公開年、水道端バス停の現況、区界の「幅のわかる地面」の位置、紙の博物館収蔵資料の同定。
