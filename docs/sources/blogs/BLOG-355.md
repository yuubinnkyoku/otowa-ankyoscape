# [BLOG-355] 山の風音「神田上水下部を歩く」＝旧白堀跡発掘調査の記録

## 書誌・確認範囲

- 山の風音（yamakazeoto.jugem.jp・筆者yamakaze）の2022年5月18日記事（EUC-JP頁・2026-11-27第367回にcurlで直接取得し本文全文確認）。https://yamakazeoto.jugem.jp/?eid=294
- 同記事は文京区総合福祉センター前の「神田上水旧白堀跡」説明板の文言を引用しつつ神田上水下部（関口大洗堰〜水道橋懸樋）を歩いた記録。**[BLOG-346](BLOG-346.md)（2012年水徒然・「解体中の中学で神田上水白堀の遺構が発掘されたと新聞で読んだ」伝聞）の課題である発掘の対象・時期・内容を特定する二次記録**。

## 内容メモ

- **〔確認・repo初出〕神田上水旧白堀跡の発掘調査（平成23〜24年・2011-12）の内容**: 説明板文言として「**発掘調査では、白堀と呼ばれる開渠の堀が初めて発見されました。発掘された白堀は新旧2筋あり、伊豆石の石積み護岸が長さ60メートルにわたって確認されました。新白堀は、明治10年（1877）頃に水質保全のために石蓋でアーチ状に覆って暗渠化されましたが、発掘時には石蓋は取り除かれていて、石積みの一部も壊れていました。神田上水廃止により埋め戻された大正期（1912〜26）頃の状態を示していたと考えられます**」を引用。**発掘は神田上水左岸（北岸）のみで対岸（巻石通り下）は未確認、『東京市史稿上水篇』から川幅約3メートル**。
- **〔確認・repo初出〕発掘地点＝文京区総合福祉センター（文京区立第5中学校跡地）**: センター建設の際に新旧二層の石積の白堀（開渠）護岸が発掘され、周辺に神田上水があったことが裏付けられたと説明板にある〔本文記述〕。なお別ブログ（yagopin.seesaa.net・2018年1月「日々のできごと・思うこと」＝直403・Wayback未収蔵のため検索スニペット確認〔二次転記〕）に「もともと永井荷風も通った黒田小学校があり、その後文京区立第五中学校が建っていたが、廃校になって校舎を壊した際にこの遺構が発掘された。現在は地面の一部がガラス張りで護岸の石の一部が見える」という記述＝**BLOG-346の「解体中の中学」＝文京区立第五中学校（旧黒田小学校跡）と特定する材料**。
- **〔確認・repo初出〕巻石通りの由来**: 「明治11年頃、水質を保つため、開渠に石蓋をかけた。その石蓋を"巻石蓋"と呼んだ」という由来説明〔説明板由来とみられる本文記述・明治10年（白堀暗渠化）と明治11年（巻石蓋）の表記差はそのまま記録〕。
- 現在も埋蔵文化財調査が行われている〔2022年時点〕。金富小学校前の説明板・江戸川橋公園起点の経路（小日向台の裾の巻石通り・大日坂・服部坂・安藤坂・本法寺・牛天神方面）も記録。

## 四河川への使い方

- **[BLOG-346](BLOG-346.md)白堀発掘伝聞の大幅な特定**: 対象施設（文京区立第五中学校跡＝文京区総合福祉センター）・時期（平成23〜24年）・内容（白堀開渠初発見・新旧2筋・伊豆石護岸60m・明治10年頃アーチ暗渠化・大正期埋戻し状態）・川幅約3m（東京市史稿上水篇）が説明板レベルで確認できた。**原新聞そのものは依然未特定**（一次の発掘調査報告書〔埋蔵文化財調査会〕の所在確認が次の一手）。
- 白堀の物理構造（開渠・石積護岸・幅3m・のち石蓋アーチ暗渠化）は、[GAZ-049](../gazetteers/GAZ-049.md)（白堀通・巾五間〔区間により不同〕・承応2年堀割）・[GAZ-169](../gazetteers/GAZ-169.md)（白堀東添湿地）・第200回桜木町白堀文言群の江戸期記録に対する**考古学的裏付けの初の具体記録**。幅3m（発掘+市史稿）と5間（御府内備考・水道町条・ただし不同）の対校材料。
