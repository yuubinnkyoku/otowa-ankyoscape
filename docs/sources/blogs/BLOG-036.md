# [BLOG-036] サンポー「水窪川の暗渠で新発見」

- **直接確認（2026-11-11、open_url）**：文京区音羽で、長く民家だった敷地が近年更地になった際、**壁の下に横長の穴が奥まで続く水路の石組みの上部が確認できるようになった**と、生まれも育ちも音羽在住の地元民（「ソトノミスト」のペンネームで散歩記を書く人物）が2019年3月時点で報告した記事。**水窪川はこの更地の奥の壁に沿って流れていたとみられる**という。
- **造幣局の石組の消滅〔確認：記事の叙述〕**：都電荒川線手前の造幣局跡地の壁面には**下水を水窪川に流す排水溝の石組が残っていたが、2016年の造幣局閉鎖・更地化で石組も消滅**したという。※[BLOG-025](BLOG-025.md)の「旧排水口石積みの2021年移設保存・案内板」との異同（同一遺構の別時点・別部分の描写か）は要照合。移設保存された部分と消滅した部分を本記事で区別して断定しない。
- **源流〔確認：記事内での言及〕**：本田創「東京『暗渠』散歩」に従い、美久仁小路近辺の**「蟹窪」と呼ばれる湿地が源流**と紹介。既収録の[GOV-001](../gov/GOV-001.md)等と整合。
- **意義〔観察〕**：水窪川の流路に沿う**未整形の石積みが2019年に一時的に露出観察された**という地元民の目撃記録。観察時点で更地だった敷地がその後建築された可能性があり、現況の可視性は不明。旧流路の位置の裏付けとしては、穴の延び方と壁との関係の記述に限られ、**本記事単独で流路を立証しない**。
- **制限〔未解決〕**：写真の撮影地の地番・方位・石組みの構造の詳細は記事本文から特定できず未確認。
