# [BLOG-320] sirakigi「千川上水 歴史・写真・探訪（4）」富士見台駅〜桜台駅

- **書誌〔確認〕**: sirakigi内の千川上水の歴史・写真・探訪シリーズ第4弾（富士見台駅〜桜台駅）。「最新更新：2005.09.22」。**長らく取得できなかったsenkawa41頁を2026-11-25に本環境から直接取得（HTTP 200・Shift_JIS）して本文全文を確認**〔第312回〕。昭和14・15年・38年の写真と解説・探訪ガイドを併載。
- **中村分水〔確認・二次〕**: 中村橋駅付近（グリーンベルト中に祀られた大山不動尊が目印）から南東へ。**明治10年の分水口は約4寸3分四方で、田9町4反**。明治24年の地図ではほぼ南東に下り、南蔵院の南から東に回り周辺の水田を潤しつつ学田（学田公園）に合流〔[GOV-005](../gov/GOV-005.md)の中村関係・[GOV-067](../gov/GOV-067.md)の元治元年中村7町7畝に加わる明治10年時点の寸法・面積の文言〕。昭和14年6月には未だ分水の穴が残っていた（昭和15年写真）。
- **学田と中荒井池〔確認・二次〕**: 第1の中新井分水は目白通りの手前から南へ流れた（現マツダパーキングとマンションの間の路地）。**明治9年に南蔵院境内に設置された公立小学校（現・豊玉小学校）が明治17年に現在地に移築された後、学校の運営資金を生み出すため村人たちが沼地だった当地を開墾し「学田」と称した**。当地は江戸時代は**中荒井池**と呼ばれ、当時ここが水源となって**中新井川**が東南に発していた。**明和8年（1771）の江古田村鑑帳に「此村用水ハ豊嶋郡中荒井村溜池より落水引申候得共旱損仕候」とあり、池は水が枯れたのでこの千川から通水していた。明治10年の分水口は4寸四方で、以下2つの分水と合わせて11町の田を潤していた**〔**江古田村鑑帳の年次・文言＝repo初出候補（中荒井池の旱損と千川通水の村方文書側記録）**〕。学田は昭和15年に公園となった〔頁内には明治16年12月の豊玉学校開設による池の埋立開墾申請の文言もあり、小学校移置（明治17年）との前後関係は要整理〕。中新井川は中野区に入ると江古田川と呼ばれ、松が丘2丁目の江古田公園付近で妙正寺川に合流。
- **川布施餓鬼供養塔〔確認・二次・補強〕**: 南蔵院墓地入口左手に**川布施餓鬼供養塔（明治15年・矢島弥平次の名も刻まれる）**・**笠付地蔵**・**日川地蔵**の3基が並んで移設されている。**「これは大正末期には現在の千川通りが目白通りと交差する手前にあった（練馬区史 現勢編）」**〔**移設前位置の文言＝repo初出**。[PAP-027](../papers/PAP-027.md)の川施餓鬼供養塔（論文内で「1883（明治15）年」と表「1892（明治15）年」の年次食い違いあり）に場所の変遷を加える補強。第30回の「江古田川分水堰付近」説との位置対照候補・断定しない〕。
- **日川地蔵〔確認・二次・補強〕**: 練馬の宿入口（新道＝現・目白通りを横断したところ）に**紀元二千六百年（昭和15年）にできたばかりの日川地蔵尊。「最近2、3年の間だけでも7人溺死した幼い子供達の供養のために建てられたもの」**。縁日には人出が多く露店が繁盛。川幅2米・深さ1米半あまり。**地蔵尊はマンション建設に伴い昭和61年に南蔵院（練馬区中村1丁目）境内に移設され、墓地入口の左手に2体安置**〔[PAP-027](../papers/PAP-027.md)の「1940年・溺死7人の子供供養・南蔵院移設」と整合する文言の源流候補。移設の直接動因（マンション建設）の具体化〕。
- **石神井川からの揚水〔確認・二次・裏付け〕**: **日川地蔵と筋違橋とのほぼ中間の地点で一清流が豊島園の方面から千川に流入する。「これは石神井川を揚水して千川に合流せしめる水路で、明治以来下流の工場の用水としての、千川の水量不足を補ふためのものである。従って当然千川はこの下流から水量が増加する」**〔[BOOK-161](../books/BOOK-161.md)（1941年実測「日川地藏と筋違橋との略〓中間」）と同一位置の独立叙述＝練馬宿揚水位置説の裏付け。揚水のポンプのコックのようなものがあり、後ろには千川の境界石がたくさん積まれていた（昭和15年写真・平成8年開催の千川展見学者の証言）〕。
- **筋違橋の親柱復元記念碑〔確認・repo初出〕**: 練馬駅前の繁華街（清水電器ビル（旧・清水電気、現ドラッグストア）の前で千川は北側の内田木材店へ転ずる）。**平成17年に練馬区によって歩道のガードレールの間に、オリジナルを復刻した千川上水の記念碑が建てられた。裏面には写真プリント板が付けられ「この石碑は、昭和３０年までこの地にあった千川上水の筋違橋（すじかいばし）の親柱を復元したものです。写真は昭和１５年頃の暗きょになる前の筋違橋（写真提供 武蔵学園）」と記される**〔**筋違橋親柱復元記念碑（平成17年・練馬区）の文言＝repo初出**。第30回の橋供養正観音（昭和28年東神社移設、[PAP-027](../papers/PAP-027.md)）とは別の石造物。「昭和30年までこの地にあった」ことと[GOV-092](../gov/GOV-092.md)の昭和38年写真（練馬駅付近・既に暗渠化）との時間差は対校課題〕。
- **矢島水車と明治18年水車調〔確認・二次・repo初出〕**: 練馬消防署の北側で明治の中頃に千川から水を引いていた（「豊玉水車分水」という人もいる）。**矢島水車（現・豊玉上2-27付近）と呼ばれるもので、明治14年測量のものや大正の地図にも水車記号が載り、脱穀製粉等を業とした**。**明治18年の「水車場箇所及び所有者人名調」（東京都公文書館）によると、中新井村二千三十番で、深野総左衛門、矢島弥平治とある**〔**明治18年人名調の書名・番地・人名＝repo初出の文言**。[GOV-586](../gov/GOV-586.md)の1874年水車稼家取設願写・1883年千川水道敷地修繕願（中新井村2030番地深野惣左衛門）と番地・氏名が完全に対応する補強。原典本文は未見〕。**後にこの下流にも北島という人が水車を作ったとの伝聞**〔[GOV-067](../gov/GOV-067.md)の練馬区4水車にない「北島水車」の伝聞記録〕（参考：矢島英雄『矢島寺と矢島氏』昭和52＝repo未収録の書誌候補）。
- **三枚橋と桜の碑〔確認・二次・repo初出候補〕**: 桜台駅の手前交差点（みずほ銀行前）に**もと「三枚橋」（三枚の石からできていたから）という橋があった**。グリーンベルトに**昭和62年に「千川通りに桜を植える会」によって「桜の碑」が建てられている**〔**三枚橋の名称由来・桜の碑の建立年と会名＝repo初出候補**〕。
- **第2中新井分水（桜台分水・弁天分水）〔確認・二次〕**: 青果店と珈琲館の間の細い路地（マンホールが連なる）。**明治10年で分水口は1寸5分四方・明治14年、前記同潤社への分水のため5分四方に減**〔[BLOG-319](BLOG-319.md)の同潤社分水（5分四方）と対応する減水側の文言〕。**「1番目、3番目の分水ともで、田は11町を潤していた」＝11町は3分水合計の面積**。現・豊玉第二小学校の下を通り中新井公園を越えて南流し中新井川周辺の田を潤した〔[GOV-005](../gov/GOV-005.md)の字下新街（豊玉上2-20）取入口と対応候補。市杵島神社（豊玉北2-17）の「弁天分水」の別称〕。
- **正久保橋・新井水車・奈羅実覚帳〔確認・二次・repo初出〕**: 三枚橋から踏切を越えると石神井川の**正久保橋**に達し、ここには以前**新井水車**があった。**ここの明治4年の「奈羅実覚帳（ならのみおぼえちょう）」には約1ヶ月にドングリ300余石を製粉していた記録があり、当時、ドングリを飢饉などの荒救食としていたことがうかがえる**〔**「奈羅実覚帳」の書名・年次（明治4年）・ドングリ製粉記録＝repo初出**。石神井川沿いの水車記録だが、千川・石神井川の水車史・救荒史の対校資料。原帳の所在・読み下しは未確認〕。
- **清戸道と黄金電車〔確認・二次・repo初出〕**: 環七桜台陸橋の手前・都営バス練馬車庫付近のグリーンベルトに**清戸道（明治以降の名称）の石碑と千川上水の説明板**（スズキ病院前にも練馬区教委による同種の石碑と説明板）が建つ。**清戸道＝江戸川橋北詰から清瀬市中清戸へ約5里の農業生産道路。難所は目白坂（高さ約18メートル・道のり約250メートルの急坂・有償で立ちんぼうが手伝った）。江戸中期から練馬の村々から江戸市中へ農作物を出荷し、戻りに下肥や糠を持ち帰った「おわい街道」**。**戦時下で燃料が使えなくなり東京湾投棄ができなくなったため、昭和19年から東京都の懇請で武蔵野鉄道・旧西武鉄道・食料増産会社の3社が屎尿の電車輸送を始め、昭和28年3月まで続いた（一名「黄金電車」・夜間輸送・清瀬にも蓄溜場があった）（練馬区史 歴史編）**〔**「黄金電車」の運行年次（昭和19年〜28年3月）・輸送3社・夜間輸送＝repo初出**。[ORG-042](../org/ORG-042.md)の清戸道ツアー記録・第69回ノートの道しるべ地蔵（千川堤沿いの清戸道）への近代史側の補強〕。**練馬〜豊島区境までは清戸道が千川上水に沿い、千川通りと重なる**〔清戸道と千川の併走の文言〕。
- **練馬車庫と暗渠化〔確認・二次〕**: **東京環状乗合（黄バス・昭和17年2月に東京市営バスに統合）の車庫が桜台駅と武蔵学園の中間にあり、現在の都バス練馬車庫（新宿西口発路線の終点）。「この付近が暗渠化されたのは昭和28年2月頃」**〔練馬区側暗渠化の区間別年次の補強（[GOV-056](../gov/GOV-056.md)・[BLOG-113](../blogs/BLOG-113.md)年表・[ORG-022](../org/ORG-022.md)の1959年写真と対校）〕。大正15年には**ダット乗合自動車**（合資会社・資本金10万円・椎名町1-6営業所・自動車9台・女車掌10人・目白駅〜江古田駅〜武蔵高校前〜三枚橋〜練馬駅〜豊島園）が通っていた〔バス路線史の補遺〕。
- **練馬大根・練馬の語源〔確認・二次・土地利用史の補強〕**: 練馬の語源4説（馬の調練〔風土記稿〕・赤土等のねりば〔日本地名学研究〕・古代宿駅〔続日本紀〕・根沼説）。大正7年豊島郡全域の大根作付け1,324町歩・生産高1,987万貫・**下練馬村36,000樽**の沢庵（四斗樽・16貫）。最盛期は大正初年〜昭和10年頃・中国・朝鮮・米国へも輸出。**昭和15年に愛染院（春日町4-17-1）門前に練馬大根碑が建立（礎石は沢庵漬の重し石）**〔千川沿いの練馬の農業史の概説。第287回のとしまの記憶動画アーカイブの口述証言群（桜並木・沢庵）と対照可能〕。
- **〔未解決〕**: 江古田村鑑帳・「水車場箇所及び所有者人名調」・「奈羅実覚帳」の各原典の所在確認（都公文書館等）。親柱復元記念碑・桜の碑・清戸道石碑の現地写真と文言の直接採録。昭和28年2月頃（練馬車庫付近）と昭和27年夏頃（二叉付近）の区間年次の整理。北島水車伝聞の追証。
