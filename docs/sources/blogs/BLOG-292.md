# [BLOG-292] 江戸町巡り「【小石川①057】音羽町」〔音羽町の町名起立説と水窪川流域音羽地区の製紙業沿革の、行政史書引用つきの要約〕

- **書誌〔確認: ブログ本文全文・2026-11-23取得〕**: 「江戸町巡り」（町丁別に江戸の町名の沿革をまとめる個人ブログ・town-tpo系列と同じ記事体）。**投稿日2017年12月9日**。 https://edo.amebaownd.com/posts/3363751/ 。項目＝町番号小石川①057・町名音羽町一〜九丁目・起立1697（元禄10）年・現町名＝文京区音羽一・二丁目・小日向三丁目・目白台三丁目。
- **町名起立・町方沿革の文言〔確認: 本文・文言〕**: 「**1697(元禄10)年に護国寺領となり、町屋起立が指示されるが、家作人がないため、桂昌院の信任が厚かった奥女中の『音羽』という人物にこの門前町を拝領したため『音羽町』と名付けられた**」〔桂昌院の奥女中「音羽」拝領説＝repo初出の町名由来文言〕。もとは雑司ヶ谷村・小日向村・関口村の地。1713（正徳3）年町奉行支配、**1723（享保8）年町屋は取り払われ寺社奉行地となったが、1730（享保15）年に再び町屋が許され、1745（延享2）年から再び町奉行支配となる（備考）**。化政期（1804〜1830年）の家数783軒（**町方書上**）。
- **岡場所・遊興地の沿革〔確認: 本文・文言〕**: 「護国寺門前の当町には、参拝客相手の茶店等ができ、**宝永年間（1704〜1711年）には江戸市中の岡場所の1つとして栄えるようになった**」「1723(享保8)年、町奉行大岡越前守等は、享保の改革の一端として売春施設一切の取り壊しを命じた。その後、**延享年間（1744〜1748年）に六〜九丁目にかけて歓楽街が復活し、天保の改革時まで江戸有数の岡場所**として賑わった」「当町には吉田屋、三河屋等の料理屋があり、三都の名物を挙げている『**富貴地座位**』には**音羽町のあみかさ餅**が記されている」〔富貴地座位・あみかさ餅の文言ともrepo初出〕。
- **明治初年の物産〔確認: 本文・文言〕**: 「1871(明治4)年7月、土地、新屋敷を合併。1872(明治5)年8月、小日向町の一部を合併。**同年の戸数632・人口2,324、物産に大高紙、地政紙、地漉紙、漉返紙、今戸焼鍋があった（府志料）**」〔大高紙・地漉紙・漉返紙・今戸焼鍋の品種名はrepo初出〕。
- **製紙業沿革の文言〔確認: 本文・文言〕**: 「**音羽地区の製紙業は、1833(天保4)年、信州伊那郡の久保田増平が紙漉の技術を持ち込んだことに始まった。1885(明治18)年頃の生産品には土佐子紙、地政紙、泉貨紙等があり、1890(明治23)年に紙漉業者も79軒となった。明治中期以降洋紙の本格化と市街地化に伴い、徐々に衰退していった（文京区史）**」〔久保田増平の氏名・1833年起点・1885年頃品種（土佐子紙・泉貨紙）・1890年79軒・衰退要因（洋紙本格化・市街地化）の一連の文言はすべてrepo初出＝**水窪川流域（音羽谷）の製紙業の起源人物・技術移入元（信州伊那郡）・ピーク時の業者数・品種・衰退過程が年代つきで初めて座標化された**〕。
- **地形・現況の文言〔確認: 本文・文言〕**: 「文京区の北部に位置し、南北に細長く、**最南端で神田川に接する**。閑静な住宅街、**音羽通りを挟む谷（音羽谷）の崖下と崖上に跨る街**を有する。出版社である講談社や光文社（俗に言う音羽グループ）、鳩山会館等が存在する」〔音羽谷の崖下・崖上構造の記述〕。住居表示＝1966（昭和41）年4月1日一部を小日向三丁目に、残余は1967（昭和42）年1月1日に丁目を整理して音羽一・二丁目とし残余を目白台三丁目に編入。
- **意義〔観察〕**: ①**水窪川（音羽川）の氾濫原・谷頭の音羽地区の産業史（紙漉）の沿革を、文京区史・府志料・町方書上という行政側史書の引用形で年代つきに要約した記事**＝[BLOG-099](BLOG-099.md)〜[BLOG-100](BLOG-100.md)（暗渠ハンター・水窪川の紙漉望月家の言及）や[BLOG-045](BLOG-045.md)（東京江戸ぶら・音羽川）といった流路・暗渠側の記録に対して、町史・産業通史側の補助線を与える〔ただし本記事自体は先行史書の二次転記であり、文京区史・府志料の該当頁の直接確認はしていない〕。②**1833年（天保4）起源説**は、江戸期からの連続か幕末の新規定住かの判別材料になる〔「持ち込んだことに始まった」＝起源を一人物にある時点とする記録で、幕末維新期の品目（府志料の幕末物産目録系）との整合が読める〕。③音羽町の岡場所沿革＝谷頭の水資源（崖下湧水・川）と門前・遊興地の立地関係を考える際の時系列材料〔ただし本ブログはこの水系との関連については明示していない〕。
- **制限・未解決**: ①引用元の**文京区史・府志料・町方書上の該当頁は未確認**＝数値（家数783軒・79軒・戸数632）と氏名（久保田増平）の原典照合が次回課題。②桂昌院の奥女中「音羽」拠領説は「〜と名付けられた」の伝承記録で、拝領文書等の一次史料は未確認〔町名由来の他説との比較もしていない〕。③写真は音羽一丁目の今宮神社付近等で、水窪川の地形写真資料としては直接使えない。
