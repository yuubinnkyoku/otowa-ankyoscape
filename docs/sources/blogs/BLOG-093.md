# [BLOG-093] 大塚天祖神社の享和元年絵図と江戸名所図会十羅刹女堂の検討

- **書誌**: TEIONE BLOG 平山貞一、**2020年1月30日**。[原記事](https://teione.exblog.jp/27958991/)。2026-11-11全文取得確認。[2026-10-23・暗渠ブログ横断調査](../../2026-10-23・暗渠ブログ横断調査.md)で「未索引」としていた記事の本文確認・資料化。
- **〔確認・新史料候補〕** **大塚天祖神社境内に享和元年（1801）の絵図が掲示されている**。筆者は絵図に十羅刹女堂（現天祖神社）・東福寺・**谷端川（青線）**・中山道（真性寺・庚申塚）を見出す**〔確認：筆者が境内掲示の絵図を撮影・読図／未確認：絵図の正式名称・原本の所在・筆者の読図の検証。**1801年の谷端川流路を描いた境内絵図の現物確認・採録は次の一手**〕**。なお既収録の1801年舗石建立塔（[GOV-049](../gov/GOV-049.md)・千早1-23-3）と同年で、大塚側の同時期絵図として照合価値がある。
- **〔確認・二次〕** 江戸名所図会「十羅刹女堂」の解説を豊島区郷土資料館かたりべ4経由で引用する。**乞食橋は矢端川（谷端川）に架かる橋で別名を藤（富士）橋と呼んだ**、石標「鎮守十羅刹女神」「左大塚道・右王子道」が東福寺十羅刹女堂左隣に現存、福蔵寺は明治7年の火災で焼失し東福寺に合併、など〔確認：筆者によるかたりべ4の転載。かたりべ4本文・石標の現物は未確認〕。**「藤（富士）橋」呼称は既収録の藤橋（折戸通り×王子道交差点）と橋名・位置の照合資料になる**〔推定〕。
- **〔確認・二次〕** 東福寺は元禄4年（1691）に小石川大塚から当地へ移転。十羅刹女神は神仏分離で福蔵寺所有となり、**昭和30年まで大塚天祖神社に隣接した場所に置かれ、以後東福寺境内に移った**と記す〔確認：筆者記述（寺由緒等による）／未確認：一次史料〕。
- **〔確認・二次〕** 大塚花街（三業地）は**大正11年（1922）4月に巣鴨町字平松（現・南大塚）で指定地許可を得た。当初は天祖神社付近を望んだが「谷端川北側に指定された」**と記す〔確認：Wikipedia「大塚 (花街)」等による二次叙述／未確認：警視庁許可原簿〕。**谷端川の南岸・北岸という地形が大正期の土地利用（花街立地）に影響したという観察資料**〔推定〕。現三業通り＝谷端川流路跡（南大塚・大塚花町入口の暗渠）の写真観察もある。
- **〔参考〕** 天祖神社の社殿は区画整理で境内が3分の1に縮小された等の由緒碑転記もある〔確認：碑文転記〕。
- **〔未解決〕** 享和元年絵図の原本・縮尺・採録、かたりべ4の本文、藤橋・乞食橋の橋名対照への取り込み、大塚花街指定地と谷端川の位置関係の図化。
