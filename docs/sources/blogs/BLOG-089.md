# [BLOG-089] NEWSポストセブン・本田創「水窪川を遡る暗渠さんぽ」

- **直接確認（2026-11-11、open_url・本文全文）**：NEWSポストセブン掲載の週刊ポスト2022年4月22日号記事（取材・文＝上田千春、撮影＝小倉雄一郎、解説＝本田創）。**第7回調査以降アクセス不能が続いたNEWSポストセブンの水窪川記事で、今回初めて本文の直接取得に成功した**。
- **暗渠化の時期〔確認：本田創の説明〕**：水窪川の**暗渠化は「昭和8（1933）年頃」**と明記する。既収録の東京江戸ぶらによる**昭和7〜9年に絞る地図読図推論**に対し、**本田創による独立の「昭和8年頃」説**が加わった。〔二次説明／行政の工事原史料の裏付けは依然未確認。断定は避ける〕
- **流路〔確認：記事の説明〕**：池袋駅東側・サンシャイン60通りに近い**美久仁小路付近の湿地を源流**とし、文京区の**江戸川橋で神田川に合流する約3kmの川**。〔既収録の源流理解と整合〕
- **護国寺の門前町整備伝承〔確認：本田創の説明〕**：**天和元（1681）年に護国寺が創建された際、門前町を築くため東側の崖下に水窪川、西側の崖下に弦巻川を水路として整備し、両川の間に参道（現・音羽通り）を造ったと言われる**。〔「言われています」レベルの伝承として記事は提示。護国寺門前町の水路整備説に新たな独立の出典（本田創）が加わった〕
- **護国寺の石橋〔確認：記事の説明〕**：境内には**かつて湧水池から水窪川に注ぐ支流が存在し、石橋が架かっていた**。池も支流もない現在、**石橋は境内の富士塚「音羽富士」の前に保存されている**。〔既収録の[護国寺境内の旧水系](../../護国寺境内の旧水系.md)の「湧水池→支流→水窪川」構図と整合する二次説明〕
- **湧水の現況〔観察：記事の説明〕**：暗渠の路地を北に進む途中には橋跡などが残り、**崖の擁壁から湧水が流れ出す箇所もある**と記す。〔2022年時点の概説／個別地点は未特定〕
- **制限〔未解決〕**：「昭和8年頃」の出典・「1681年両川整備」伝承の原典（寺誌・地誌）は記事では示されない。
