# [BLOG-199] 都電さんぽ特集・雑司が谷弦巻通り商友会（清田明会長の弦巻川証言）

- **書誌〔確認〕**：東京都電さんぽ（東京新聞系サイト）特集記事「のんきにお散歩を楽しめる 昭和の風情が残る商店街」（special-1378）。都電荒川線「雑司が谷」〜「鬼子母神前」間の雑司が谷弦巻通り商友会の紹介記事で、**清田明会長の証言**を含む。**直アクセスは遮断されるがWayback Machine（2024スナップショット・id_）で本文取得**（2026-11-13、第62回実行）。同商友会自体はBLOG-185/188（wanjin）で既出だが、本記事の清田会長証言はrepo未収録。
- **主要事実〔確認：本文〕**：
  - 「この**弦巻通りの由来は、昔存在した、弦巻川という川**でした」（清田会長）。
  - 「かつて池袋にあった**丸池というのが水源**で、**昭和7年に暗渠化**されて、今の通りができたんです」〔丸池を弦巻川の水源とする地元伝承＝BLOG-073/074（丸池＝谷端川/弦巻川水源論争）に加わる独立の民間伝承データポイント。昭和7年暗渠化はBLOG-161等の既存説と一致〕。
  - 「暗渠ですから、**今も地下で弦巻川は流れている**のだそうです」〔現地下水流の存続を示す地元の認識。観察ではなく伝聞として記録〕。
  - 商店街は**昭和20年代後半から形成**。**昭和50年頃には約70軒を超える店舗**で夕方に歩行者天国になる賑わい〔弦巻川跡地の商業利用の時期特定＝1932（昭和7）年暗渠化→戦後商店街形成→昭和50年最盛期の土地利用年次チェーン〕。
- **repoとの関連〔観察＋伝聞〕**：弦巻川跡＝弦巻通りの命名由来・暗渠上の商業集積を、当事者（商店街会長）が説明する独立資料。丸池水源説の新たな伝承例として、丸池の帰属（谷端川×弦巻川）の未解決問題（第12回・BLOG-073/074）に入れる。断定はせず伝聞として扱う。
- **注意**：清田証言の丸池水源説・昭和7年暗渠化・地下水流存続はいずれも地元伝承レベルで、行政史料ではない。
