# [BLOG-025] 水窪川沿いの石積み排水口候補の移設保存と現地案内板

- **資料〔確認〕**：戦跡紀行ネット「[巣鴨刑務所の排水口跡（移設保存）と池袋散策](https://senseki-kikou.net/?p=19228)」（**2021年11月28日公開**、2021年11月の現地写真と、**2017年撮影**と明記した移設前写真3枚）。別の踏査者「[戦争遺跡 スガモプリズン排水溝 in イケ・サンパーク](https://citywalk2020.hatenablog.com/entry/2021/11/19/185348)」（**2021年11月19日公開、2025年2月7日更新**）も、**2021年10月21日**の公園内観察として案内板を転記する。双方は現地の同一案内板を参照しており、**独立した史料が2件あるとは数えない**。
- **案内板の転記〔確認：複数の現地記事にある掲示文の一致／未確認：設置者の原本・工事竣工図〕**：現在の豊島区立としまみどりの防災公園（IKE・SUNPARK）の**アーチ状石積み**は、隣接する**都市計画道路補助第176号線・特別区道41-340**を支えていた石垣の一部を、周辺道路整備で撤去した際に**保存して公園内に復元**したものと説明される。公園の一部の石材も再利用と記される。**現在の設置場所は原位置ではない**。
- **水窪川との関係〔仮説〕**：掲示文自身が、この石積みは**巣鴨刑務所の排水口として周辺の水窪川へつながっていた「のではないか」**という推量形を用いる。**刑務所の排水管接続・排水方向・施工年代を証明する行政工事記録ではない**。記事の断定的な見出し・説明と、掲示文の慎重な文言を区別する。
- **原位置候補〔観察・推定〕**：2021年11月28日の記事は、移設前を**公園南西側の坂下通り終端の階段下付近**と説明し、**2017年撮影**とする写真を掲載する。別記事は**東池袋4丁目34番16号付近**との旧位置情報を述べる一方、公園での観察位置を**東池袋4丁目42番**と記す。**番地の違いは旧位置・現位置の区別または記事側の概略表示であり、地番・施設位置の確定には使わない**。
- **既存の1999年資料との関係〔未解決〕**：豊島区広報の**1999年10月9日**水窪川踏査（[GOV-001](../gov/GOV-001.md)）にある「造幣局脇の排水溝跡」「護岸用と思われる大谷石塀並み」と、今回の石積みが**同じ施設・石材・道路区間かどうかは未確認**。掲示文は「道路を支えた石垣」とし、1999年の「旧護岸候補」と用途解釈が異なるため、**両者を同定しない**。2017年写真・1999年踏査経路・道路台帳・公園整備図の位置合わせが必要。
- 写真は転載せず原記事へリンクする。2021年時点の掲示文と観察であり、**2026年の現況・石材の残存を再確認したものではない**。
