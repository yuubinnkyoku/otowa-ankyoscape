# [BLOG-075] 弦巻川暗渠散歩①本当の水源？

- **直接確認（2026-11-11、open_url・本文全文）**：谷端川・水窪川に続く3本目の暗渠歩きとして弦巻川を歩くシリーズ第1回（2020-05-31）。続編「②池袋南口大ガード〜明治通りまで」も存在。
- **元池袋史跡公園〔観察〕**：西口メトロポリタン前の広場＝元池袋史跡公園に「池袋地名ゆかりの池」の碑と解説（池は弦巻川の源流、雑司が谷を通り江戸川橋まで）を確認。
- **丸池跡の位置のずれ〔観察〕**：Googleマップの「丸池（弦巻川水源）跡」ポイントは碑の裏側のブロックにあり碑は何もない。筆者は「ポイントがずれているだけかも」「もしかしたら丸池はこのブロックに広がる大きな池だったのかもしれない」と留保。〔元池袋公園の土地交換・移転（[GOV-055](../gov/GOV-055.md)）と地図ポイントのずれの関係を示す現代の観察〕
- **水源の読図〔観察：記事の推論〕**：東京時層地図（MAP-103）の文明開化期（約140年前）図では**水源は碑の位置でなく、もう少し北西側から流れており、この地図には丸池も描かれていない**。筆者は水源と思しき場所をたどり**西池袋公園**に至り、地形的にも坂になっていることから「丸池よりさらに上流の山の斜面に最上流部となる小さな湧水があったのかもしれない」として、**当ブログの前提では西池袋公園を弦巻川の水源とする**。〔**西池袋公園＝谷頭説（[BLOG-052](BLOG-052.md)『大江戸今昔巡り』等）の独立の読図による支持**。文明開化期図葉の再判読・丸池の有無の確認が今後の課題〕
- **制限〔未解決〕**：時層地図の該当図の直接判読は未実施（筆者も含め）。2026年時点の碑・公園の状況再確認も未実施。
