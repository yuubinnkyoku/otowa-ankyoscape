# [BLOG-280] 西東京水路跡散歩「田無新田用水」（1）（2）（3）〔1770年ごろ関野用水分水・「古老に聞いた田無用水」聞き取り資料・流末の石神井川変更〕

## 内容〔確認: 本文全文3本・2026-11-22取得〕

- **書誌〔確認〕**: アメーバブログ「西東京水路跡散歩」（musasinowalker・[BLOG-272](BLOG-272.md)〜[BLOG-279](BLOG-279.md)と同一筆者）の**田無新田用水（1）（2）（3）**＝[entry-12519719346](https://ameblo.jp/musasinowalker/entry-12519719346.html)〔2019-09-03〕・[entry-12520282960](https://ameblo.jp/musasinowalker/entry-12520282960.html)〔2019-09-04 12:54〕・[entry-12520485187](https://ameblo.jp/musasinowalker/entry-12520485187.html)〔2019-09-04 19:40〕。田無新田（現西東京市向台町・南町一帯）の生活用水路の、関野用水分水点（推定）から石神井川合流部までの現地トレース。**[BLOG-279](BLOG-279.md)（世間話13・2022年宅地開発の水路敷出現）の舞台と同じ用水の本編シリーズ**で、第261回ノートの未解決事項④「田無新田用水の水路図・本編記事は未取得」を本ファイルで解消する。
- **田無新田用水の起点と年代（1）〔確認: 本文直接引用〕**:
  - 「**１７７０年ごろ、田無村でも特に飲み水に困窮していた地域のため、新たに関野用水から田無新田用水が分水されることとなりました**」＝**1770年ごろ・飲み水目的・関野用水（玉川上水系〔[BLOG-274](BLOG-274.md)〕）からの分水という起点文言**〔伝聞・資料名の明示なし〕。
  - 「**マイマップの水路図…は、田無市が４０年ほど前に調べた聞き取り資料、「古老に聞いた田無用水」を元にレイヤー化したもの**」＋「**聞き取りの詳しい内容はわかりませんが、水路図は聞き取り当時のご老人が昔見たもの、もっとも伝え聞いたものが入っていると思われ、年代としては８０～１５０年ほど前の水路状況と思われます**」＝**流路図の典拠＝田無市聞き取り資料「古老に聞いた田無用水」〔repo初出・資料名の所在・刊行形態は未確認・2019年時点から約40年前（1970年代）の調査と筆者が読む〕＝向台町・南町一帯に広範囲な水路網を記録**。
  - **分水点の同定手法（1）〔確認〕**: 「**一番古い時代の航空写真（１９４８年頃・国土地理院の地図・空中写真閲覧サービス）に、田無新田用水の水路が写っています**」＋鉄塔の並びを現在図に照合して小金井公園造成前の水路位置を推定＝**1948年頃空中写真＋遺存鉄塔の位置基準という流路復元手法の記録**。分水点は「**筆者が関野用水からの分水点と考える場所**」〔推定〕。
  - 「**鈴木街道に至るまで…水路跡はありませんが車道幅が拡幅されています、併走水路が車道化したので広がったものと思われます**」「**府中道側の交差点が広いのは、こちらも水路跡を利用したためと思われます**」＝**鈴木街道・府中道の道幅拡幅箇所＝水路の車道化〔推定〕**。
  - 「**水道道路である、現在の多摩湖自転車道が作られたのは明治の終わり、井戸や水道の普及が始まりだした時期とも重なり、入れ替わるように飲水を目的とした水路は消滅していったのでしょう**」＝**多摩湖自転車道＝明治末の水道道路という性格づけと、上水道普及による飲水用水消滅の一般化〔推定〕**。
- **枝水路の増加と水路網の複雑化・廃滅年代（2）〔確認: 本文直接引用〕**:
  - 「**元々田無新田用水は、特に水利の悪かった向台地区の生活水として利用する役割がありましたが、使用できる家は限られていた（開削当時の本家か？）ようです。しかし、地域が発展して分家が増えると、水路の近くに家を構えることが難しくなり、不便が生じるため許可を取って枝水路を引く家もあったとあります**」＝**開削当初は使用家が限定（本家か？）・分家の増加で許可による枝水路が増えたという水路網複雑化の説明〔聞き取り資料由来と筆者が読む・文言「とあります」〕**。
  - 「**いつ頃まで水が流れていたかですが、昭和２０年ごろから水質の悪化が顕著となり、昭和３０年代には埋め立てが始まったようです**」＝**昭和20年ごろから水質悪化・昭和30年代埋め立て開始〔「ようです」推定文言〕**。
  - **現況**: 向台中央通りと市役所通りの交差点東側のお堂脇の水路跡・旧石川島播磨重工工場跡地（大型病院・マンション・スーパー）を挟んだサミットストア向台店北側の途切れ途切れの水路跡・向台中央通りの分水点の広がり（橋場推定）・農家の溜池に接続した水路（「言われています」）・都営向台四丁目第2アパートまでの本流水路跡＝**田無地域は水路の廃滅が進んでおり、断片水路跡自体が貴重という地域性の観察**。
- **流末の変遷・桶渡し・柳沢住宅（3）〔確認: 本文直接引用〕**:
  - 「**当初は、都道１２号線付近で流末となり溜水となっていたようですが、石神井川流域の開発が進むと水田用水が必要となり、流末を石神井川へと変更することになりました。この辺りは野中用水や柳窪用水の経緯と同じです**」＝**当初の流末＝都道12号線付近の溜水→石神井川流域開発による水田用水需要で流末を石神井川へ変更〔「ようです」推定を含む〕・野中用水・柳窪用水と同じ経緯という筆者整理**。
  - 「**石神井川の合流点の近くでは、石神井川の北側から水田用水の分水を桶で南側へ渡す場所もありました。十分な水があれば、わざわざそのような事をする必要はなかったでしょう**」＝**合流点近くの石神井川北側→南側への桶渡し（水田用水の分水）の存在と、本用水の水量不足の傍証〔「桶で渡す場所もありました」＝聞き取り由来か〕**。
  - 「**元々、田無用水と違い水量も少ない関野用水からの分水では、石神井川まで安定して流れを維持できていたのかは不明です**」＝**水量から見た到達可能性そのものへの疑義の提示〔筆者推定〕**。
  - 「**戦中に作られた中島飛行場の関係者向けの柳沢住宅がこの綺麗な区画に建っていたようです。この斜めの道は、その境界に沿って通っていた小道である。田無新田用水は柳沢住宅の区画内を進んでいたようだが、造成と共に埋められてしまったのだろうか**」＝**南町二丁目エース通り四叉路の斜め小道は水路図とはずれていて柳沢住宅（戦中・中島飛行場関係者向け）の境界小道〔推定〕・区画内の水路は造成で埋没〔推定〕**。田無市の注意書き看板（「２０年ほど前の看板」＝1990年代ごろの設置推定）。
