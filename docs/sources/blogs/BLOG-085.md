# [BLOG-085] Natrium.jp 出端川

- **直接確認（2026-11-11、open_url・本文全文）**：出端川の地籍図・現地観察照合の記録（2017年11月19日・12月9日、2025年2月21日再訪）。
- **水源〔確認：「板橋の地名」の説明〕**：出端川は**東武東上線大山駅西側に水源があったとされ**、「板橋の地名」（板橋区教育委員会発行、1995年）によれば**ハッピーロード大山の突き当たり・現マンションあたりに水源があった**という。**すぐそばに千川上水もあり、その漏水も合わせていたと思われる**とする。〔推定：千川上水漏水説／[BLOG-080](BLOG-080.md)の「大山=大山道分岐点の地名由来」と別の角度から『いたばしの地名』系の記述を補強〕
- **流路の地籍図照合〔確認：地籍図＋観察〕**：谷端川との合流点から山手通りまで一直線の水路敷 → 東上第10号踏切手前で線路南側の水路敷をたどり**東上第11号踏切の少し手前で東上線をくぐり北側へ** → 大山東町交差点で西へ転進 → 大山駅北口（かつての東上第14号踏切）→ 駅前商店街ハッピーロード大山 → 突き当たりが水源。途中**大山東町児童遊園の若干上流側に北から合流する水路敷**（2025年再訪で発見、地籍図で北側の道路までは描かれず）、**大山駅南口改札前付近から北に合流する支流**（地籍図に描かれるが痕跡なし）を記録。〔地籍図の描線と現況の照合観察／水路の実態は未検証〕
- **合流位置の別説〔確認：地籍図〕**：出端川が谷端川に合流する位置は**一本北の豊橋のところだという説もあり、地籍図でもこちらに水路敷が描かれている**として、豊橋西側の水路敷・東上線第9号踏切への道沿いの水路敷・大山金井町児童遊園以北の水路敷を確認した。〔二つの合流経路が併存する理由（複数水路の混同・付け替え）は未解決〕
- **repoへの関連**：[BLOG-059](BLOG-059.md)・[BLOG-080](BLOG-080.md)の「中丸川＝出端川混同問題」（両川別項実在説を支持）について、**出端川の流路を地籍図・踏切番号単位で具体化した独立の観察**として扱える。千川上水の漏水を水源に加える説は[GOV-068](../gov/GOV-068.md)の分水設計思想の傍証候補。〔推定〕
