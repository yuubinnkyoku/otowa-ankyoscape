# [BLOG-294] いけぶくろねっと「大塚駅南口地区再開発 都市計画の決定」〔着工竣工日程の文言・地域メディア記録〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: NPOいけぶくろねっと（池袋の情報サイト）の告知記事「大塚駅南口地区 再開発 都市計画の決定 地上41階地 下2階 2029(令和11)年着工・2032年竣工予定」。 https://w3.ikebukuro-net.jp/archives/info/ootuka-kaihatu202611 投稿日2026年11月20日・最終更新日時2026年11月20日・投稿者ynegishi・カテゴリー＝まちづくり／商店街／大塚／駅。
- **本文の文言〔確認〕**: 「**JR大塚駅南口の再開発について、豊島区が11月3日に都市計画を決定したと発表した**。再開発地区は駅南口の都電線路前の飲食店など商店街」「計画案は**地上41階、地下2階、高さ160m**。用途は住宅、店舗、生活支援施設、駐車場など。建築面積 約2,490㎡（建ぺい率約56％）」「これまでの経過、2019年に地権者勉強会、2019年から2022年に地権者協議会実施。2022年に大塚駅南口地区再開発準備組合設立（**権利者56人、加入者52人**、事務局は東京建物）」「今後のスケジュールは、**2027(令和9)年度に事業計画・再開発組合設立、2028年権利変換、2029年に着工、2032年竣工**」。図＝「豊島区都市計画審議会資料より」の注記。
