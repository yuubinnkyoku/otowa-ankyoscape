## 内容メモ

- **〔観察・repo初出〕氷川台支流の合流点=仲町小学校**: 円明橋で田柄川に合流する支流（西側流れと南側流れの2系統）。「水路は小学校の校庭を抜けて南側へ曲がっていっていたらしい」。西側流れの水源地＝みどりばす氷川台ルートの仲町小学校バス停あたりの窪地。**2025/3/2追記: MapExpert地籍マップ（β版）には丁字路から先にも水路敷が描かれ、十字路が起点**＝地籍図上の支流起点の具体化。
- **〔観察・repo初出〕南側流れと東京少年鑑別所**: 校庭から南向きの支流は東京少年鑑別所敷地内を流れていた。「古い地形図では鑑別所が谷頭になっており、その西側にもう一つ谷があるように描かれている」＝[BLOG-374](BLOG-374.md)（wanjin練馬駐屯地東西支流）に加わる氷川台周辺の谷構造観察。アコレ駐車場入口脇の歩道=水路敷・上流端は坂道の手前。
- 昭和22年空中写真では既に団地化していて畦道ではないとの観察＝1947年時点で宅地化していた傍証。
