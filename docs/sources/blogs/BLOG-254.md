# [BLOG-254] Natrium.jp「善福寺川周辺の水路敷群（善福寺池周辺）」（2023）〔repo初出・[BLOG-001](BLOG-001.md)・[BLOG-081](BLOG-081.md)〜[BLOG-088](BLOG-088.md)・[BLOG-102](BLOG-102.md)〜[BLOG-104](BLOG-104.md)と同じNatrium.jpの水路敷観察群のうち善福寺川系で未収録だった部分〕

- **書誌〔確認: 本文全文・2026-11-21取得〕**: Natrium.jp「水路敷を行く」の「桃園川・善福寺川の水路敷群」カテゴリ内の**「善福寺川周辺の水路敷群（善福寺池周辺）」**。**本文の写真は2023年7月23日撮影**。井荻橋から善福寺池までの右岸（崖側）の水路敷観察〔[BLOG-001](BLOG-001.md)（水窪川）・[BLOG-002](BLOG-002.md)（弦巻川）・千川上水3本・谷端川8本とは別カテゴリの未収録部分で、本格的な掃引は次回以降〕。
- **排水口と扁額〔確認・repo初出候補〕**: **井荻橋の右岸側の下の大きな排水口の扁額に「下水管渠」と書かれており、合流式下水道で雨量が多い時に汚水がそのまま川に流されている**旨・**原橋のたもとに大きな排水口**〔[GOV-485](../gov/GOV-485.md)・[GOV-486](../gov/GOV-486.md)の図面ラベル（河道図・立坑付近の表示）の現況観察の接続〕。
- **原寺分橋下の湧水の現況〔確認・[ORG-037](../org/ORG-037.md)・[BLOG-248](../blogs/BLOG-248.md)の湧水レーンの現況追補〕**: 「**「原寺分橋下の湧水」があり、写真右下の丸い穴が湧水ポイントと思われるが、ほかにも湧き出している場所があるのかもしれない。以前はかなりの湧水量があったというが、写真では丸い穴からはほとんど水が湧いていないように見える**」＋**杉並区設置と思われる「湧水のしくみ」を解説した看板が「かなり痛みが激しい」**〔**[ORG-037](../org/ORG-037.md)（日本地下水学会・2018年撮影の看板）と看板を同一とみなせる観察＋水量減少の記録**（[BLOG-248](../blogs/BLOG-248.md)の2018年動画比・2016年比の減少観察に2023年の定点観察を上書き可能な記述）。同一看板かはhuman目視確認待ち〕。
- **井荻小学校〜善福寺池間の水路敷〔確認・repo初出候補〕**: **耕整橋**の北側・**井荻小学校が両岸に跨ぐ部分は緑のトンネル**。井荻小学校の西側に**崖下を通る古い水路ではないかと思われる道が善福寺池まで伸びる**〔[BLOG-248](../blogs/BLOG-248.md)（井荻小学校の校地内流下）の流路観察と接続〕。**新町橋**で左岸へ・北東向きに一区画の水路敷・北向きの幅広い道＝**崖上の井草八幡宮から流れてきていた水路の跡**と思われる・井草八幡宮へ向かう坂道は**車止めのある水路敷**・**八幡西橋**の下流側にインターロッキング舗装の水路敷〔**井草八幡宮＝善福寺川左岸の水路群の源に当たる観察**。八幡宮の表側は青梅街道と**六ヶ村用水**が通り、その向こうは井草川・妙正寺川水系＝分水嶺の明示〕。
- **善福寺池の湧水〔確認〕**: **下の池が北向きに曲がる所で西側から流れてくる湧水が合流**・本流は下の池から流出し左（北）側の排水口からも流れ〔[GOV-487](../gov/GOV-487.md)（上の池・下の池・湧水枯渇）の現況観察〕。**下の池北側の丘陵＝善福寺城伝承地の一つ**: 「史料で確認することができないそうで、実在も含めはっきりせず、伝承地に遺構もない」・「善福寺周辺は太田道灌が文明9年（1477年）に江古田・沼袋原の戦い（江古田原合戦）で布陣した伝承もあるが、行軍ルートも諸説ある」〔城郭伝承の非確定文言の明記〕。
- **シリーズ目録〔確認: 目次頁・本文未確認の頁あり〕**: 「桃園川・善福寺川の水路敷群」カテゴリの全構成: **桃園川本流**（末広橋〜三味線橋・三味線橋〜高円寺橋その1/その2・高円寺橋〜阿佐ヶ谷駅・阿佐ヶ谷駅〜上流端その1/その2＝7頁）・**桃園川の支流**（日大二高の支流・谷戸川（天神川）・小淀川・阿佐ヶ谷川＝4頁）・**新堀用水 トンネルの前と後**（その1・その2＝2頁）・**善福寺川下流**（神田川合流点〜済美公園・堀ノ内の支流・松ノ木の支流・成田東の支流・成田西の支流・和田堀公園〜善福寺川緑地＝6頁）・**善福寺川上流**（高野ヶ谷戸(こやがいど)・四面道口分水・上荻と西荻北の水路敷・善福寺池周辺＝4頁）・**松庵川**（下流・上流・大宮前大下水・分水と女窪の支流＝3頁）〔**「新堀用水 トンネルの前と後」「四面道口分水」「谷戸川（天神川）」等、repoの六ヶ村分水・天保新堀用水・桃園川支流の諸課題に直結する頁群が存在する = 大口の掃引対象。今回は目録把握のみ〕。ほかに「神田川下流2」カテゴリに**小沢川**の頁が存在〔[BLOG-251](../blogs/BLOG-251.md)の小沢川レーンと接続する確認候補〕。
