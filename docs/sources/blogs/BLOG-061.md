# [BLOG-061] 谷端川沿い湧水ものがたり　下り谷を流れる支流

- **直接確認（2026-11-11、open_url・本文全文）**：シリーズ第6回。
- **紀要第11号からの引用〔確認：引用文〕**：「**上池袋2-2付近から湧き出た清水は小川となり、北上してJRと東武東上線を抜け、谷端川の一の橋（板橋区板橋1-2）近くに流れ込んだ。明治44（1911）年の巣鴨村全図にこの小川が描かれている。このあたりには幾筋もの小川があって谷端川に注いでいた**」。
- **下り谷支流（仮）の観察〔観察〕**：首都高池袋線高架下のひときわ窪んだ場所（上池袋2-2付近）から北へ暗渠が始まる。流路沿いに銭湯**ゆラックス（旧鳩の湯）**。JR・埼京線・東上線越え後、並行する2本の流路候補（北池袋駅付近の道とその一本西）の間を、**悪水路との役割分担の名残とみられる横断路地・段差階段**がつなぐ。東上線を踏切で越え、谷端川の**一の橋**（板橋1-2、谷端川緑道）に到達。
- **瓢箪池支流（仮）〔確認：言及〕**：**上池袋1-3**で湧き、谷端川との合流部に**瓢箪池**という池を作っていた支流があったと予告（次回記事扱い）。
- **一の橋の位置〔確認〕**：橋名表（[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)）の一の橋について、**板橋区板橋1-2**という地番レベルの位置を紀要引用として記録できる。
- **コメント欄〔確認〕**：nama氏が「ここ、**雲雀ヶ谷**ともよばれているようです」と指摘（[BLOG-054](BLOG-054.md)の雲雀ヶ谷戸と呼称が一致）。
- **repoへの関連**：下り谷（池袋六又〜板橋1丁目の谷戸）の支流について、湧水地点（上池袋2-2）と合流点（一の橋・板橋1-2）を初めて位置レベルで記録。[BLOG-055](BLOG-055.md)（露塚散111）の支流同定の比較材料にもなる。
