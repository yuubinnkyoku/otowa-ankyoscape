# [BLOG-261] Natrium.jp「善福寺川周辺の水路敷群」（善福寺川下流6頁）〔repo初出・BLOG-254目録「下流6頁」の全掃引。[BLOG-252](BLOG-252.md)・[BLOG-253](BLOG-253.md)（時空散歩・中央線あるある）と対照するNatrium 側の実走群〕

- **書誌〔確認: 本文全文6頁・2026-11-22取得〕**: ①「神田川合流点〜済美公園」（2024/4/19・2025/10/8撮影）・②「堀ノ内の支流」（2021/4/29ほか）・③「松ノ木の支流」（2021/1/2・2020/9/27ほか）・④「成田東の支流」（2020/9/27ほか）・⑤「成田西の支流」（2021/6/5ほか）・⑥「和田堀公園〜善福寺川緑地」（2025/10/17・2020/9/27ほか）。
- **済美の地名〔確認・[BLOG-253](BLOG-253.md)系の由来文言と合致〕**: 「済美公園付近には済美小学校など『済美（せいび）』を冠する施設などがあるが、**もとは明治40年（1907年）に開校した日本済美学校に由来している**。**済美という名称は中国の古伝から取られたもの**という。**昭和25年（1950年）に学校の敷地、設備などが杉並区に寄贈**され、現在は杉並区立養護学校などになっている」（[BLOG-250](BLOG-250.md)の日本済美学校敷地概念図と接続）。
- **和田堀町の区画整理と流路付け替え〔確認・本項の中核文言〕**: 「現在の和田一丁目南部（和田堀町字堰山）で**昭和6年（1931年）から和田堀町第一土地区画整理事業**が始まる前は、**善福寺川支流の水路が…北から神田川に合流していた**」〔**特別区協議会所蔵『豊多摩郡和田堀町全図』（小林又七, 1929）参照の文言**〕。「**和田堀養魚場があった**（溜池）」「対岸の**中野区側には中野プールという遊泳場があり、昭和初期には繁盛していたらしい**」〔遊泳史上の記録〕。「**和田堀町第一土地区画整理事業（昭和6年着工、昭和17年竣工）に続いて昭和16年（1941年）に和田堀第二土地区画整理事業…が組織されたが、折しも第二次世界大戦に突入したことから計画は一時中断し、戦後に再開して昭和35年（1960年）の完成となった**」＋「**『杉並の川と橋』（杉並区立郷土資料館, 2009）P69や杉並区立中央図書館所蔵の『組合誌 和田堀第二土地区画整理組合』（同, 1960）に掲載されている地図によれば、このあたりの善福寺川流域には両岸に多数の水路が農地の間を縫って引かれており、これを大幅に整理して善福寺川は駒が坂橋で東側の新流路と接続する形としたとされる**」〔**善福寺川下流の流路改変＝区画整理による水路群の大整理という説明の根拠が『杉並の川と橋』P69＋組合誌1960の地図**＝[BLOG-250](BLOG-250.md)（河川改修年次系列）・[BLOG-255](BLOG-255.md)（蛇行帯と済美公園）と対照。『杉並風土記 下巻』（森泰樹, 1989）参照文言もある〕。**大正5年（1916年）旧1万地形図「中野」**（善福寺川支流の付け替え前の流路）・**昭和7年版・昭和12年（1937年）旧1万地形図**（養魚場の地図上の出現）・**昭和22年空中写真**の読図＝「大正期には養魚場がまだ地図に現れておらず、昭和初期に善福寺川支流の出口がここから下流側へ付け替えられたようだ」。**区整碑**: 中野富士見町駅そば・和田堀町字砂利田中心の和田堀町第一土地区画整理（S6-17）完成記念〔[BLOG-263](BLOG-263.md)（小沢川）の「和田堀町第一土地区画整理で小沢川も現在の流路に付け替え」と対照する碑面の実物観察〕。
- **大宮八幡園と善福寺川緑地〔確認〕**: 「和田堀公園は**昭和9年（1934年）に開設された大宮八幡園という京急系列の遊園施設**をもとに周辺に拡大していったという歴史がある一方、**善福寺川緑地は河川改修による河川敷を利用して作られている**ようだ」「企業としての大宮八幡園は**戦災で施設を失い、平和島に拠点を移して競艇場の運営などを行う京急開発株式会社として現存**している（参考: 京急開発株式会社沿革）」・「緑地の開園は東京都公園協会のページによれば**昭和39年（1964年）**」〔[BLOG-252](BLOG-252.md)（大宮八幡園）・[GOV-487](../gov/GOV-487.md)系と対照する開園年の正式出典文言〕。緑地内に**民家5軒**が取り込まれ公園内を通らないと出入りできない宅地の観察（「緑地が作られた方が後でこの一角には古くから民家があった」）。
- **道角橋と揚げ堀〔確認・[BLOG-253](BLOG-253.md)（尾崎熊野神社に保存の片側欄干）との相互確証〕**: 「**道角橋という橋がここで揚げ堀を渡っていたという。欄干は揚げ堀が埋め立てられてから行方不明になっていたが、その後緑地で発見された片側の欄干が尾崎熊野神社に保存されている**」＋「緑地の西縁を流れていた揚げ掘のあとをさかのぼって」いく流路観察（白山前橋=緑地の南端基準点・善福寺川緑地の西縁沿い）〔**道角橋欄干の尾崎熊野神社保存＝BLOG-253の記録と独立に合致するNatrium側の観察**＝二重の一次観察として確証度が上がった〕。**尾崎橋**付近では「善福寺川は尾関橋付近では東寄りに蛇行していたようで」等の旧蛇行の読図もある。
- **松ノ木遺跡〔確認〕**: 「和田堀公園北側の台地に、**昭和29年（1954年）に発見された古墳時代の竪穴式住居跡**があり、茅葺き屋根が復原されている。このあたりの**松ノ木遺跡は約20,000年前の先土器時代から人が住んでいた痕跡**があるそうだ」〔BLOG-252（松ノ木支流の実走）の地域史側の補助〕。和田堀池・「和田堀と堀ノ内という地名は、堀ノ内二丁目から三丁目のあたりに**鎌倉幕府の御家人であった和田義盛の居館があったという伝承**によるものらしい。蛇行する善福寺川に張り出した台地は、城を置けば善福寺川が堀の役割を果たすので、そのような地名が残ったのかもしれない」〔伝承文言・「かもしれない」の推定〕。堀ノ内は「中世の武家居館の屋敷地（鎌倉幕府の侍所別当だった和田義盛の領地と伝わる）が堀に囲まれていたことからと言われているが、どこに居館が合ったのかは諸説あってはっきりしない」。
- **下流の支流群の実走〔確認・観察〕**: ①済美地区（方南公園の崖手前を流れた最南支流・環七西側は区画整理されておらず水路跡が残る）・②堀ノ内の支流（武蔵野橋袂の大排水口・善福寺川からの分流と堀ノ内支流の合流・二枚橋）・③松ノ木の支流（和田堀公園調整池建設2021時点の変化・金太郎の車止め・わんぱく広場の別分流の蓋暗渠）・④成田東の支流（本流と並走する旧支流・竹垣・湿った水路敷）・⑤成田西の支流（揚げ堀遡上側）〔BLOG-252の実走とほぼ同空間の独立観察。2025/10/17（最近時点）の撮影を含むのが特徴〕。
