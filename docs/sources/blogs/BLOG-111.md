# [BLOG-111] 東京の水2009 fragments「エンガ堀向原支流（上流部）」

## 内容メモ

- **〔確認: 概説〕** エンガ堀は石神井川の支流で練馬区・板橋区の区境付近を流れ、**1960年代末〜70年代初頭に暗渠化**。台地を鹿の角のように枝分かれして刻んだ谷を流れ、**台地の上にはエンガ堀の谷を迂回するように千川上水が流れていた**〔千川上水が石神井川系の谷頭を迂回・かさ上げで越える構造の読図。[BLOG-103](BLOG-103.md)（Natrium・明豊中付近のかさ上げ観察）と対応〕。
- **〔観察・確認: 資料引用〕** 向原・大谷口境界に源を発する支流（仮称・向原支流）の谷頭は「**田頭（でんがしら）**」と呼ばれ、湧水を蓄えた**溜池**が谷の下流部水田の水源だった。溜池は**大谷口2-35付近**。「資料によれば**上板橋に3箇所あった溜池のうちの2つで面積390坪**ほど」〔引用資料名は本文に明示されず。『いたばしの河川』〔[BOOK-031](../books/BOOK-031.md)〕等の公刊資料と推定されるが断定しない〕。
- **〔観察〕** 窪地の片隅の崖下に「**鯉供養の碑**」と石造物〔釣堀の供養塔とみられる石造物の現存観察〕。
- **〔確認: 地域史〕** 向原では**干ばつの年に雨乞いが行われ、榛名神社の水を運びこの溜池に入れた**という（榛名講・100km以上離れた山への信仰）。谷頭から台地に上がった**千川通り沿いには今も雨乞地蔵が残る**という〔「最近マンションが建っており健在かは不明」との注記〕。
- **〔確認: 地域史〕** 溜池は**昭和初期には釣り堀になり、戦後もしばらく営業**（「大谷口の釣堀」）。地名は暗渠を境に大谷口と向原に分かれる。

## 三河川への使い方

- **大谷口・向原周辺の湧水溜池・雨乞い・釣堀という地域史がrepo初出**。千川上水が迂回構造で流れていた谷の具体像として、[GOV-071](../gov/GOV-071.md)（大谷口付近の石橋・開渠写真）・[BLOG-104](BLOG-104.md)（氷川町の水路分水口）の千川上水下流部資料に谷頭側の文脈を与える。
- 「田頭」は溜池を備えた谷頭の小字とみられる〔推定〕。地名対照表への収載候補（「田頭／でんがしら」）。
