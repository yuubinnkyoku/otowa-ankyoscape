# [BLOG-002] T — Natrium.jp「神田川周辺の水路敷群（弦巻川）」

- https://natrium.jp/canal_lot/kanda/tsurumaki/index.html
- 1932年の暗渠化時の流路付け替え、現存する水路敷などを地図・公図境界・現地写真から検討する現地調査記録。一次史料ではなく、現地観察・比較資料として使う。
- **本文の内容資料化〔確認：2026-11-11に本文全文を取得〕**（撮影2023-12-23〜2024-7-13）：
- **出口と旧神田上水〔確認：当頁の読図〕**：江戸川橋西側の排水口は音羽通り東側を流れる雨水配管**坂下幹線のもので「元の水窪川の出口とも言える」**。弦巻川の出口は音羽通りの下で交差して江戸川橋の東側（雑司ヶ谷幹線＝弦巻川の排水口。位置関係から弦巻川の方が上を通って出ている）。**大正期の地図には弦巻川が江戸川橋西側の旧神田上水（現在の神田川よりもやや北寄り）に流れ出ているように描かれているものがある**〔BLOG-001の旧神田上水注ぎ込み説と対になる読図〕。
- **昭和7年（1932）暗渠化時の流路付け替え〔確認：当頁の主張〕**：弦巻川の本流は現在の弦巻通りに概ね沿っていたが、**暗渠化の際に流路の付け替えが行われ、もともとは弦巻通りと異なる場所を流れていた部分がある**。弦巻通りの1ブロック南側にくねくねと曲がる細い路地が旧流路とみられる〔[GOV-017](../gov/GOV-017.md)・[BLOG-038](BLOG-038.md)の弦巻川昭和7年暗渠化の記録に、**付け替え（流路変更）の具体像**を加える〕。
- **上流端の地図依据〔確認：当頁の列挙〕**：大日本帝国陸地測量部地図（例：大正12年地図）では上流端は西武池袋線より東側だが、**「明治44年北豊島郡高田村・豊多摩郡戸塚村全図」（豊島区立中央図書館など所蔵）や特別区協議会Webサイトの「大正14年東京府下高田町戸塚町全図」ではさらに上流が描かれている**〔[MAP-035](../maps/MAP-035.md)の同図（年代未詳→明治44年説の補強）・[MAP-117](../maps/MAP-117.md)の特別区協議会図と対応〕。首都高速と都電荒川線の間は**おおよそ公図境界（一部は豊島区と文京区の区境）が川筋を示す**（ブルーマップ・住居表示新旧対照表で確認したと説明）。
- **自噴井戸の現地観察〔確認：観察記録〕**：弦巻通りの1ブロック南の旧流路細道の路肩に**自噴井戸が現存**（撮影時点）〔[BLOG-052](BLOG-052.md)（本田創2010の自噴井戸・側溝湧水）の2010年観察に対し、2023〜24年時点の別観察として蓄積〕。
- **地名・社寺〔確認：当頁の由緒記〕**：清土鬼子母神堂（**清土＝このあたりの旧地名。永禄4年1561年にこの地で鬼子母神像が出土**）。小篠坂＝弦巻川支谷を利用した坂で、**支谷の谷頭は雑司ヶ谷霊園南側の此花亭付近**。弦巻稲荷神社（護国寺西交差点西の崖下、由緒不明）と崖上の腰掛稲荷神社との関係を指摘する意見あり。蓮光寺（寛永6年1629牛込創建・元禄11年1698当地へ移転）。
- **江戸川公園〔確認〕**：首都高速5号池袋線下の江戸川公園下流端が弦巻川河口部にあたる。江戸川橋下流左岸に小石川区西江戸川町・小石川江戸川町の地名があった〔神田川下流部の旧称「江戸川」の地名残存例〕。

**2026年11月21日追記（open_urlで本文を再取得し、未資料化だった中流・上流部の内容メモを追加）**：

- **中流の旧流路帯と区境の観察〔確認：当頁の現地観察〕**：弦巻通り南側に菊池寛旧宅跡の看板。1ブロックだけ文京区が弦巻通りの北側にはみ出している部分には、民家と駐車場の間の区境に沿って**未舗装の小道**があるが、**水路敷かどうかは「わからない」**とする。**公図の境界は現在の区境よりもやや川筋っぽく曲がっている**と説明。南側に蛇行していた部分は民家化して痕跡なし、再びのはみ出し部分は駐車場で、奥の住宅は崖上にあり、この辺りを南北に蛇行していたと推定する。日本女子大学寮を過ぎたところから川跡は弦巻通りをなぞり、北へ曲がりながら商店街へ。**商店街の交差点右側のベーカリー付近から上流では、弦巻川は通りよりも東側を流れていた**とし、「ここに弦巻川ありき」と描かれた壁の写真（2024/2/24撮影）を紹介する。
- **明治通り西側から上流端の三叉路まで〔確認：当頁の現地観察〕**：明治通り西側の上流部分では左右に細い路地が並走し、**弦巻川は中央の道を流れていた**と思われるとする（2024/7/26撮影）。並走する南側の路地は一見水路敷のようだが、**弦巻川を挟んだ農地の畦道だったのかもしれない**とする（2024/2/10撮影）。大ガード西側を南へ向かう道路の擁壁には雑司ヶ谷いろはかるたの「そ」（「**卒塔婆も鎌倉も木村も弦巻川の橋の名**」）が描かれ、**丸池から護国寺に向かって弦巻川に架かっていた橋の名**が紹介される（2024/2/10撮影）。
- **池袋駅南側の三谷合流の読図〔確認：当頁の読図〕**：OpenStreetMapと陸地測量部地図の比較で、**上流端の三叉路付近で谷筋が3つの方向から合流していたように見える**。北から順に、(1)立教通り北側のリビエラ東京裏あたりからホテルメトロポリタン北側の元池袋史跡公園（**丸池跡とされる**）を通ってくる谷、(2)西武池袋線の池袋3号踏切（**旧上り屋敷駅前**）北側付近から来る谷、(3)目白通り北側の三井住友銀行裏駐車場の窪地から来る谷。**高田村全図（明治44年）のルートは(1)の谷をなぞっている**とする〔[MAP-035](../maps/MAP-035.md)・[GOV-002](../gov/GOV-002.md)の丸池＝源流説、[BLOG-039](BLOG-039.md)・[BLOG-075](BLOG-075.md)の上流読図と対応〕。
- **(3)目白通り側の谷の観察〔確認：現地写真〕**：合流点から左に向いたところに**細い水路敷に見える坂道**。道幅が広くなったり狭くなったりし、ゆるやかなカーブの水路敷（?）は若干窪んだ場所を流れる。**レンガの壁から出ているのは暗渠に落ちる排水管**として紹介（2024/2/10撮影）。下流側は山手線で行き止まり。目白駅北側では目白通りに出る手前で**道が大きく窪み、三井住友銀行ビル裏の駐車場が窪地の先端**（2024/7/22撮影）。
- **(2)西武池袋線側の谷の観察〔確認：現地写真〕**：(1)の谷と別れ西に向かう道路は**西武池袋線まで川跡らしく緩やかに蛇行**、左手に南池袋一丁目公園、突き当たり住宅の脇に**行き止まりの細道**（2024/2/10撮影）。西側ではJR・西武池袋線の西側に回り込んで窪みを探す：旧長崎道踏切の少し北側（ゴミ集積所付近）の**わずかな窪み**（2024/7/22撮影）、北側の道路から見た**線路手前のうっすら凹み**（2024/7/22撮影）、池袋3号踏切の**かつてファミリーマートがあった空き地あたりが地形として谷頭**（2024/7/22撮影）、付近は整地されてよくわからない（2024/7/26撮影）。
- **(1)丸池側の谷の上流の観察〔確認：現地写真〕**：元池袋史跡公園から西へ、劇場通りを渡って谷筋は**西池袋公園の脇**を抜ける（2024/7/16撮影）。立教通りまで出て西側を見ると、**リビエラ東京（昭和25年・1950年に料亭「白雲閣」として開業）の裏側あたりが谷頭**と思われるとする（2024/2/3撮影）。
