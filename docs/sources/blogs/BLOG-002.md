# [BLOG-002] T — Natrium.jp「神田川周辺の水路敷群（弦巻川）」

- https://natrium.jp/canal_lot/kanda/tsurumaki/index.html
- 1932年の暗渠化時の流路付け替え、現存する水路敷などを地図・公図境界・現地写真から検討する現地調査記録。一次史料ではなく、現地観察・比較資料として使う。
- **本文の内容資料化〔確認：2026-11-11に本文全文を取得〕**（撮影2023-12-23〜2024-7-13）：
- **出口と旧神田上水〔確認：当頁の読図〕**：江戸川橋西側の排水口は音羽通り東側を流れる雨水配管**坂下幹線のもので「元の水窪川の出口とも言える」**。弦巻川の出口は音羽通りの下で交差して江戸川橋の東側（雑司ヶ谷幹線＝弦巻川の排水口。位置関係から弦巻川の方が上を通って出ている）。**大正期の地図には弦巻川が江戸川橋西側の旧神田上水（現在の神田川よりもやや北寄り）に流れ出ているように描かれているものがある**〔BLOG-001の旧神田上水注ぎ込み説と対になる読図〕。
- **昭和7年（1932）暗渠化時の流路付け替え〔確認：当頁の主張〕**：弦巻川の本流は現在の弦巻通りに概ね沿っていたが、**暗渠化の際に流路の付け替えが行われ、もともとは弦巻通りと異なる場所を流れていた部分がある**。弦巻通りの1ブロック南側にくねくねと曲がる細い路地が旧流路とみられる〔[GOV-017](../gov/GOV-017.md)・[BLOG-038](BLOG-038.md)の弦巻川昭和7年暗渠化の記録に、**付け替え（流路変更）の具体像**を加える〕。
- **上流端の地図依据〔確認：当頁の列挙〕**：大日本帝国陸地測量部地図（例：大正12年地図）では上流端は西武池袋線より東側だが、**「明治44年北豊島郡高田村・豊多摩郡戸塚村全図」（豊島区立中央図書館など所蔵）や特別区協議会Webサイトの「大正14年東京府下高田町戸塚町全図」ではさらに上流が描かれている**〔[MAP-035](../maps/MAP-035.md)の同図（年代未詳→明治44年説の補強）・[MAP-117](../maps/MAP-117.md)の特別区協議会図と対応〕。首都高速と都電荒川線の間は**おおよそ公図境界（一部は豊島区と文京区の区境）が川筋を示す**（ブルーマップ・住居表示新旧対照表で確認したと説明）。
- **自噴井戸の現地観察〔確認：観察記録〕**：弦巻通りの1ブロック南の旧流路細道の路肩に**自噴井戸が現存**（撮影時点）〔[BLOG-052](BLOG-052.md)（本田創2010の自噴井戸・側溝湧水）の2010年観察に対し、2023〜24年時点の別観察として蓄積〕。
- **地名・社寺〔確認：当頁の由緒記〕**：清土鬼子母神堂（**清土＝このあたりの旧地名。永禄4年1561年にこの地で鬼子母神像が出土**）。小篠坂＝弦巻川支谷を利用した坂で、**支谷の谷頭は雑司ヶ谷霊園南側の此花亭付近**。弦巻稲荷神社（護国寺西交差点西の崖下、由緒不明）と崖上の腰掛稲荷神社との関係を指摘する意見あり。蓮光寺（寛永6年1629牛込創建・元禄11年1698当地へ移転）。
- **江戸川公園〔確認〕**：首都高速5号池袋線下の江戸川公園下流端が弦巻川河口部にあたる。江戸川橋下流左岸に小石川区西江戸川町・小石川江戸川町の地名があった〔神田川下流部の旧称「江戸川」の地名残存例〕。
