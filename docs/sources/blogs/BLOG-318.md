# [BLOG-318] sirakigi「千川上水 歴史・写真・探訪（1）」境橋〜三郡橋

- **書誌〔確認〕**: sirakigi内の千川上水歴史・写真・探訪シリーズ第1弾（境橋〜三郡橋）。頁内表記＝鈴木勝司編 ／ 武蔵学園記念室・「最新更新：2010.11.07」（META name=author=鈴木勝司・META name=date=2010-10-20）。**第11回〜第25回以来「直接アクセス遮断・Wayback本文取得不能」（[GOV-076](../gov/GOV-076.md)ではスニペット確認のみ）だったsenkawa11頁を、2026-11-25に本環境から直接取得（HTTP 200・Shift_JIS）して本文全文を確認**〔第312回。BLOG-113系に残っていた同頁の未取得課題を解消〕。シリーズは流路を6分割した第3版で、1境橋〜三郡橋・2更新橋〜上井草駅（[BLOG-094](BLOG-094.md)）・3上井草駅〜富士見台駅（[BLOG-319](BLOG-319.md)）・4富士見台駅〜桜台駅（[BLOG-320](BLOG-320.md)）・5武蔵学園〜要町通り（[BLOG-032](BLOG-032.md)）・6要町通り〜巣鴨（[BLOG-321](BLOG-321.md)）＋写真展頁（[BLOG-113](BLOG-113.md)）。旧版「千川上水 写真と探訪 上・下」を分割・増補したものと頁内で明記。
- **体裁と文献群〔確認・二次〕**: モノクロ写真と太字解説は昭和16年刊の**文献1＝武蔵高等学校報国団民族文化部門編刊『千川上水』（昭和16年・25p・図版14枚）**（[GOV-076](../gov/GOV-076.md)の練馬区登録文化財「千川上水調査アルバム」の刊本・[BLOG-112](BLOG-112.md)書誌と対応）からの引用。カラー写真・探訪ガイドは筆者による現代のもの。参考文献11点を掲載: 文献2＝千川の会編『千川上水』（クリオ・1982・69p・**文献1の復刻を含む**＝repo未収録の書誌候補）、文献3＝練馬古文書研究会編『千川上水の今と昔』（平成3・58,19p＝repo未収録候補）、文献4＝豊島区立郷土資料館『近代（千川上水路図）編』1993（豊島区地域地図第6集・[BOOK-014](../books/BOOK-014.md)関連）、文献5＝『千川上水探訪マップ』（豊島区郷土資料館・1996・20p）、文献6＝『練馬の水系』（練馬区教育委員会・昭和51・145p）、文献9＝『写真集 練馬区の昭和史』（千秋社・1990・194p、第2版で同書から昭和38年頃写真の使用許可を得たと明記）、文献10＝『ねりま50年の移り変わり』（練馬区・平成9・277p）、文献11＝東京学芸大学近世史研究会編『千川上水・用水と江戸・武蔵野 ー管理体制と流域社会ー』（名著出版・2006・532,71p）。
- **千川開発の叙述〔確認・二次〕**: 元禄9年（1696）徳川綱吉の時代、老中松平甲斐守・加藤越中守の名で**「道奉行伊奈平八郎掛り」により開発**、土木家**河村瑞軒**の手により新座郡上保谷新田地内より玉川上水を分水し豊嶋郡巣鴨村の堀溜まで**5里24丁30間**、**徳兵衛・太兵衛の協力**（両人は私財を投じて完成・名字帯刀を許され千川の姓を賜り千川上水路取締役を仰せけられた）。〔**「伊奈平八郎」表記＝[GOV-098](../gov/GOV-098.md)（練馬区史i-repository本文）の「道奉行伊勢平八郎掛り」との氏族表記の対立（伊奈氏／伊勢氏）として対校対象**。河村瑞軒関与説は[BLOG-113](BLOG-113.md)略年表と同系統の叙述〕。
- **千川の名称〔確認・二次・表記の観察つき〕**: 千川家の明和5年の書上＝多摩郡仙川村の名称から両人に与えられ上水の名称になった・その根拠は明確でない〔[GOV-089](../gov/GOV-089.md)系の千川家文書・仙川村説と同系統〕。**頁の西暦併記が「明和５年（１６７８）」となっており、明和5年＝1768年とする換算と食い違う（頁内の誤記の観察を記録）**。
- **分水口の変遷〔確認・二次〕**: 「**現在の分水口は明治5年に変更拡大されたもの**」〔[BLOG-113](BLOG-113.md)略年表の「明治4年境橋上流へ分水口変更」との**年次表記の対立（4年／5年）**として併記・断定しない〕。**旧分水門は境橋から5、6分上流の曙橋（武蔵境・玉川上水沿い）に現在も残されている**（最近確認した時には周囲に雑木が繁茂して所在に注意が要る状態、との現地観察文言）〔旧分水門の現存と所在＝[GOV-061](../gov/GOV-061.md)等の境橋関係記録との照合対象〕。
- **水量〔確認・二次〕**: 現在の分水堰から千川へ**1日1万トン**が入る〔[BLOG-090](BLOG-090.md)・[BLOG-094](BLOG-094.md)の「善福寺池へ7,000トン＋本流3,000トン」と整合する境橋側の全量数値〕。
- **江戸給水・宝永4年分水〔確認・二次〕**: 3尺5寸四方の水門で玉川上水より分水し小石川御殿・湯島聖堂・上野東叡山・浅草寺に引き、余水は神田上水以東の小石川・本郷・湯島・外神田・下谷・浅草までの大名・小名・旗本・寺々町家に飲料水として掛渡し、**江戸市街地の3分の1**を潤した。宝永4年（1707）嘆願により**関・井草・中村・中新井・長崎・滝野川・巣鴨村等7か所の分水**を設け、供給は20か村・田1反に玄米3升の水料・寛政2年（1790）水田おおよそ百町歩〔[GOV-067](../gov/GOV-067.md)の宝永4年米3升・20か村、[GOV-005](../gov/GOV-005.md)の宝永4年分水群と整合する同系列の叙述〕。
- **享保7年の廃止〔確認・二次〕**: 室鳩巣の地脈断説を取り入れ玉川・神田両上水のみを残し千川・青山・三田・本所の4上水を廃止、巣鴨村にて締め切り、**江戸市中の水樋（木製水管）修繕費の莫大さも一因と考察**〔既収録の享保7年説（[BLOG-101](../blogs/BLOG-101.md)碑文等）と整合。廃止後も一時的に上水として復活しつつ主として灌漑用水となった〕。
- **上流域の水車〔確認・二次・repo初出候補〕**: 文献4（豊島区地域地図第6集1993）によれば**柳橋手前の左岸に500メートルに及ぶ堀を設けた「平井水車」があり針金を製造し、後に伸銅工場となった**〔**平井水車の操業内容＝repo初出**〕。**関前橋と千川橋の中間の左岸（現・西東京市柳沢3丁目）に「坂上水車」があり、平井水車の経営で針金製造を行った。昭和12年測量の地図にも載る**〔[BLOG-097](BLOG-097.md)（坂上水車取水口の現地観察・公有土地水面使用願）の経営系譜側を補強する文言〕。
- **石造物〔確認・二次〕**: 北多摩郡上保谷新田（現・西東京市新町）・武蔵野女子学院付近の五日市街道沿いの**庚申塔＝天明4年（1784）建立、現在も武蔵野大学正門前に残存**〔関前の庚申塔の建立年・現在地＝repo初出候補。[GOV-578](../gov/GOV-578.md)（武蔵野市整備基本計画）：武蔵野大学正門前のゾーニングと対照候補〕。境橋付近に「史跡玉川上水の碑」・平成3年の清流復活時の千川案内板・小金井桜の案内板（境橋の上流側）。
- **水流復活の年次〔確認・二次〕**: 玉川上水は昭和61年9月から杉並区久我山まで水流が復活（昭島の多摩川上流処理場の二次処理水を利用）、**平成2年3月には18年ぶりに千川にも水流が戻った**〔千川の水流復活の平成2年3月説＝既収録資料（[BLOG-113](../blogs/BLOG-113.md)等）との対校対象として記録〕。
- **昭和15年7月の実測〔確認・二次〕**: 境橋下流（川幅約1m・深さ約1m）・樋口（夏木立の下・川幅2mほど・浅く岸は低く流れ急）・柳橋より上流（この辺は非常に広く約3m・水量多く流れ緩やか）等の昭和15年7月写真の実測解説・柳橋付近は底より道路面まで約2m近く〔[GOV-076](../gov/GOV-076.md)の1938〜41年調査アルバム系写真と対比できる再調査時の今昔解説〕。
- **〔未解決〕**: 文献1〜11のうちrepo未収録候補（千川の会編1982・練馬古文書研究会平成3・写真集練馬区の昭和史1990等）の書誌登録判断。伊奈平八郎／伊勢平八郎表記の原典確認。明治4年／5年の分水口変更年次の確定。曙橋の旧分水門・武蔵野大学正門前の庚申塔の現地確認。
