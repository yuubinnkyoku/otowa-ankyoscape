## 内容メモ

- **〔観察・repo初出〕** 音羽川（水窪川下流）両岸の崖の続く区間で、**崖のコンクリの隙間から水が流れ出している場所がいたるところにある**＝「プチ湧水地帯」。**茶色い流出物はコンクリの向こうの赤土が水と一緒に流れ出たもの**（著者が棒で突いて確認）〔**コンクリ護岸の裏に地層（赤土）が露出する構造の2010年観察**〕。
- **〔観察〕** 鳩山会館（崖地帯の上にある）付近だけ流路が一瞬わからなくなるが、会館を過ぎると再び露わになる。会館入口から音羽川までの**ものすごい高低差**を感じられる〔音羽川谷の地形〕。
- **〔観察〕** 下流方向へ進むと左岸に急な崖が続き、**崖から降りてくる細い流れ**があり、足元は結構きれいな水だった〔谷頭側斜面の小流出水の観察〕。
- **〔観察〕** 池と見えたものはフェイク（別の施設）と自己訂正〔参考〕。
