# [BLOG-059] 谷端川沿い湧水ものがたり　中丸川

- **直接確認（2026-11-11、open_url・本文全文）**：シリーズ第4回。2012年4月14日付訂正付き。
- **支流呼称の訂正〔確認〕**：Wikipedia「谷端川」で中丸町〜熊野町〜西前橋で合流する支流に充てられている「出端川」の名は、板橋区教育委員会『いたばしの地名』ではこの川を**「中丸川」**と呼ぶとしており、記事は『いたばしの地名』の呼称に改めた。**wiki「谷端川」の支流記述には、中丸川＝出端川の混同がある可能性**を示す資料。〔既存[対照表](../../地名・河川名対照表.md)・[LOST-004](../lost-web/LOST-004.md)の中丸川理解と要照合〕
- **中丸川の流路〔観察・聴取〕**：**西前橋付近**で谷端川に合流。遡行すると首都高速中央環状線の橋裏、猫またぎのコメントによる**金井窪**、川越街道までは地形頼りの復元になるが、**板橋区幸町21の横の道**について住民聴取で「まぎれもなく川だった」「**上流は千川上水につながっていた**」「きれいな川で土手に草花、子どもがナズナを採った」「洪水しょっちゅうで川端の家は階段を何段か上がった高さに建てた」「**昭和50年代に暗渠となった**」との証言。上流は千川上水までほぼ一直線で、末端部は板橋区・豊島区境の複雑な線上と推定。
- **repoへの関連**：中丸川の水源が千川上水に接続するという聴取は、千川上水→谷端川水系の副次的接続（[GOV-068](../gov/GOV-068.md)の分水設計思想）を支流側から補強する。昭和50年代という暗渠化時期は中丸川に限った証言で、谷端川本流の暗渠化年（昭和37年廃止・[GOV-008](../gov/GOV-008.md)）とは別物。
