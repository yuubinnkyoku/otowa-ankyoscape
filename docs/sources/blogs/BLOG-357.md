# [BLOG-357] ma-maison「神田上水の流れた道をゆく」＝白堀遺構展示と石樋移築の観察

## 書誌・確認範囲

- ma-maison（[BLOG-119](BLOG-119.md)と同一サイト・小石川歴史散歩シリーズ）の「神田上水の流れた道をゆく」（rekishi_sanpo）。2026-11-27第368回にcurlで直接取得し本文全文確認。頁上に投稿日の表記なし（本文に文京総合福祉センターの平成27年4月1日竣工言及があるため2015年以降の執筆〔推定・断定しない〕）。https://ma-maison.sakura.ne.jp/hill/rekishi_sanpo/sanpo_kandajosui.html
- 神田上水の流路（江戸前期小日向・牛込付近の地図＝江戸川橋〜御茶ノ水〜後楽園・本郷側）を歩き、白堀跡・石樋展示・旧町名を説明した記録。

## 内容メモ

- **〔確認・repo初出〕文京総合福祉センター（平成27年2015年4月1日竣工・文京区立第5中学校跡地・昭和21年1946まで黒田小学校）の敷地に一部を復原展示**: 「この遺構は保存され、文京総合福祉センターの敷地に一部を復原して展示しています」＝[BLOG-355](BLOG-355.md)（ガラス張り観察はyagopinスニペット）に続く**現地展示の第2の独立記録**〔観察〕。説明板文言（白堀初発見・新旧2筋・伊豆石60m・明治10年頃石蓋アーチ暗渠化・大正期埋戻し状態・左岸のみ・『東京市史稿上水篇』川幅約3m）は[BLOG-355](BLOG-355.md)と同一文言〔重複・対校確認〕。
- **〔確認・repo初出〕水道歴史館東側への石樋・白堀の移築復原の文言**: 「**水道歴史館に隣接する東側に、昭和62年から平成元年（1987～89）に水道橋付近の外堀通り、文京区No.49遺跡で発掘された神田上水幹線水路の石樋と、平成23年（2011）に発掘された小日向1・2丁目遺跡の神田上水白堀の一部が移築、復原されています**」＝**①文京区No.49遺跡の遺跡番号と外堀通りでの発掘経緯、②平成23年発掘の白堀の一部が水道歴史館側にも移築されていること、の2点がrepo初出**。〔本郷給水所公苑＝水道歴史館東側の同一施設（[BLOG-356](BLOG-356.md)・[GOV-625](../gov/GOV-625.md)参照）〕。
- **〔確認・repo初出〕春日町交差点の石樋の石**: 「壱岐坂下の北にある春日町交差点には、昭和62年（1987）に水道橋付近から発掘された石樋の石が展示されています」＝[BLOG-356](../blogs/BLOG-356.md)のポケットパーク「テーマ水」と同一展示の独立観察〔対校〕。
- **〔確認・repo初出候補〕小日向水道町の存続**: 「昭和31年（1966）までは、音羽通りから服部坂にかけての一帯は、山側を含めて小日向水道町と呼ばれていました。大洗堰から音羽通りまでは関口水道町、服部坂から金剛寺坂までは水道端、その先、安藤坂までは水道町」＝**水道系旧町名の範囲区分の文言**。〔「昭和31年（1966）」は西暦と昭和の組合せとして誤りの可能性がある（昭和31年=1956年）が原文のまま記録・町名整理（昭和39〜41年住居表示）との関係は断定しない〕。
- 〔確認〕音羽谷の記述（小日向台と目白台に挟まれた谷・護国寺に向かって西に弦巻川・東に音羽川（水窪川）が昭和初期まで流れ現在暗渠）＝既収録範囲の再構成〔重複〕。金富小前の「神田上水路」説明板（明治34年6月飲用給水停止・明治の初めに暗渠化）も記録。
