## 内容メモ（①羽沢支流の上流端と濯川・2012年9月19日）

- **〔観察＋推定〕** 石神井川・羽沢支流の起点とされていた地点の反対側（千川上水を挟んだ北側）に、**千川上水と羽沢支流を結ぶ水路だったのでは**（正確な資料がないのであくまで想像と著者自身が明記）という痕跡: 環7の千川通り・西武新宿線陸橋の東側で、西武新宿線をまたぎ千川通りにぶつかる短い谷頭〔観察＝千川上水と石神井川水系を結ぶ水路の候補記録〕。
- **〔観察〕** 濯川（武蔵高等学校中学校敷地内）の学内現況: 八角井戸の木製井戸枠（埋設）〔[ORG-018](../org/ORG-018.md)と対応〕・緑地公園風の開渠・下流は水門を経て暗渠化し、北大…北新井公園（公園全体が窪地）〔[GOV-005](../gov/GOV-005.md)の北新井分水と対応〕を抜けて目白通りを越え、**江古田川（中新井川）の北江古田橋で合流**、合流地点に雨水吐〔観察〕。
- **〔二次転記〕** 濯川はもともと千川上水からの分水として江古田川までの田畑を潤していた流れで、上流部が大正22年（本文表記。年数は確認要）開設の武蔵学園敷地内に取り込まれ、大正25年の大掛かりな改修で現在の形になり「濯川」と命名〔[ORG-019](../org/ORG-019.md)・[BLOG-113](BLOG-113.md)の1925年命名と対応〕。
- **〔二次転記: 『建築文化』496号（1988年2月号）「武蔵学園濯川蘇生計画」〜思想とデザイン（内田祥哉・東京大学名誉教授）〕** 1980年代の資料に「**図書館下からの湧水も水源とした**」との記述〔repo未収録書誌の新規特定＝[ORG-019](../org/ORG-019.md)の内田祥哉設計の記事本体〕。湧水の現況は不明。

## 内容メモ（②弁天分水と豊玉中川・2012年9月26日）

- **〔観察〕** 千川上水からの分水「**弁天分水**」（＝[BLOG-320](BLOG-320.md)の第2中新井分水〔弁天分水〕と同一）の流路踏査: 豊玉2小→中新井公園（**大雨対策の直径2m超の貯水管埋設工事を2012年時点で観察**。環7を挟んでS字に江古田川付近〔豊玉中1丁目交差点あたり〕まで）→環7陸橋→豊玉2中→目白通り→江古田川合流口。
- **〔観察〕** 市杵島神社（豊玉）: 昭和30年代以前の地図ではすべて「**弁天祠**」表記で、**祠を囲む池**が描かれている。湧水が枯れた後に千川上水からの補水で上流ができて弁天分水となった〔記事の整理〕。「弁天分水」の名の由来はここから。境内に**橋の遺構が残るという一説**〔伝聞・鳥居の脚の裏に親柱らしきものを著者が撮影するも同定できず〕。
- **〔観察＋推定〕** 「豊玉中川（仮）」（記事命名）: 用水を受けていない単独の川。豊中橋たもとで江古田川に合流。上流は2筋で、その水源は**環七とよきた緑地**（環7沿いの小公園）の湧水ではないか〔推定・著者の地図の「湧水あり」書き込みに基づく〕。「不自然な公園」＝湧水の痕跡という視点は谷端川支流の水源＝公園傾向（[BLOG-325](BLOG-325.md)）とも共通する観察。
