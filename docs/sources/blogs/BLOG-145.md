# [BLOG-145] kotakemol04「千川上水」2011年・南長崎〜明豊中の築樋と水道端

- **書誌〔確認〕**: FC2ブログ「越後屋たぬき（FC2版）」の千川上水探訪シリーズ（2011年）。**当該entryは2026-11-12時点で直接openが可能**（[BLOG-129](BLOG-129.md)・entry-2533はWayback経由だったが、本entryはFC2現行で全文取得）。コメント欄（筆者こたけ氏と地元読者の応答）まで含めて確認。
- **〔確認・repo初出〕 籾山牧場と明治乳業工場**: 南長崎交差点（千川通り＝都道439号起点・千川上水が90度折れる地点）に「**かつて籾山牧場という牧場があり、その牛乳を使ってチーズ工場があった**」。コメント欄で「牧場の跡地に明治乳業の工場を作った。**その工場も平成6年3月まで操業**」〔**南長崎交差点の土地利用史（牧場→チーズ工場→明治乳業→現況）＝repo初出**。[BLOG-124](BLOG-124.md)の山崎田んぼ（大谷口）と並ぶ千川上水沿いの牧場記録〕。コメントで大谷口北町グリーンベルトの**積田牧場・大谷口搾乳所**（表札が残る）・要町の旧牧場の聴取もある。
- **〔観察〕 大正5年地図の「旧千川上水」記載**: 交差点脇の看板に掲げられた大正5年地図に「旧千川上水」と記載され、90度の折れが描かれる〔大正期に「旧千川上水」呼称が使われていた地図の存在。原図の特定は今後〕。
- **〔観察・repo初出〕 水道端交番（板橋区大谷口側）**: 中野通り（都道420号）・大谷口給水所前の交番が「**水道端交番**」（現在は青い地域安全センター）。**交番内に筆書きの「水道端」の文字**が掲げられていたという観察。交番の警察官は川も池も無いのに何故水道端か疑問に思っていたところ、筆者が「水道（すいどう）ではなく（みずのみちの端）と訓読みすればそれは上水」と説明したという逸話〔**「水道端」地名が滝野川区間（[BLOG-092](BLOG-092.md)のスイドウバタ）とは別に板橋区大谷口側にも現存する記録＝repo初出**。「みずのみちの端」訓読み説は筆者談として記録。練馬区HPでこの脇に水車があったとの言及（原ページ未特定）〕。対照表に追記。
- **〔観察・裏付け〕 明豊中学校わきの築樋と立体交差**: 旧千早中学校（平成16〜18年統廃合で現明豊中）脇の歩道が対面（ミニストップ側）より**約1m高い**。「**モノの資料によると築樋（つきどい）になっており、別に石神井川に注ぐ水路と立体交差になっていた**」と記し、明豊中側から3m近い高低差を観察〔[BLOG-131](BLOG-131.md)（としま案内人の築樋）・[BLOG-104](BLOG-104.md)（Natrium明豊中の谷越えかさ上げ）の**独立裏付け**。さらに**「この流れは大谷口北町のエンガ掘に至る流れの一つ」**としている〔**築樋で越えた水路がエンガ堀に接続するという系統記述＝repo初出**。石神井川支流（[BLOG-119](BLOG-119.md)等の中丸川・出端川文脈）とエンガ堀（[BLOG-103](BLOG-103.md)・[BLOG-111](BLOG-111.md)）の接続関係の新たな候補〕。
- **〔観察・聴取〕 その他**: 西武池袋線南長崎〜江古田間の踏切（武蔵野鉄道大正4年開業当時からの千川上水踏切の可能性に言及）、コメントで**30数年前（1970年代後半）に牛込商業高校・千早中学校辺りまで散歩した読者の記憶と道幅の拡幅**の証言〔千川通りの道路拡幅の時期感の傍証。断定は避ける〕。
