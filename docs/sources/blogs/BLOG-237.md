# [BLOG-237] わんじん「東大下水　－後楽園－」（2014-02-25）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文）**: wanjin東大下水カテゴリの本流記事。指ヶ谷支流と六義園支流が合流した流れを後楽園まで辿る。
- **向丘（むこうがおか）支流（仮）の合流〔ページ記載・wanjin命名〕**: 合流流れは一部が開発で消失するが**白山交番の東側で「いびつなホームベース状の流れ**」となり、**誠之小学校の北で「向丘（むこうがおか）支流（仮）」が合流**する〔向丘支流は丸山福山町・指ヶ谷町との境界（かつての丸山福山町の境）をなして流れる支流で、wanjinの仮称〕。
- **白山通りでの2分岐〔ページ記載〕**: 流れは**白山通りの「無駄に広い歩道が突然狭くなる箇所」で東に右折し、「谷端川：西大下水と合流する流れ」と「白山通りを南下する流れ」の2つに分かれる**〔東大下水系と谷端川系の接続点の位置を示す wanjin 観察。右折点の特定根拠は歩道幅員の変化という地形観察〕。
- **西片支流・菊坂支流の合流〔ページ記載〕**: 白山通りを南下する流れには**西片交差点のやや南側で西片支流と菊坂支流が合流**してくる〔後続のentry-30/31（[BLOG-238](BLOG-238.md)/[BLOG-239](BLOG-239.md)）で各支流を辿る〕。
- **後楽園史の整理〔ページ記載〕**: **1629年（寛永6年）水戸徳川家初代藩主・徳川頼房が作庭家・徳大寺左兵衛に命じて築庭**、嫡子光圀が改修、**明の遺臣・朱舜水の選名で「後楽園」**と命名。明治以後は**東京砲兵工廠**（1871〜1935頃）となり、関東大震災で甚大な被害を受けたため**1931年（昭和6年）から小倉兵器製造所（小倉）への集約移転**が図られ、跡地は払い下げられて**後楽園球場（現・東京ドーム）**等となった。**「後楽園から神田川に注ぎ込む東西の大下水（＝千川）は、本郷台地の西側に谷を刻んだ」**〔沿革年次は本文に一次典拠なし。千川の谷地形の説明はrepo既出の地形記述と対応〕。
- **制限**: 個人散策ブログ。向丘支流の名称・流路はwanjinの仮称・観察。後楽園・砲兵工廠の沿革は通説の二次整理。白山通りでの2分岐構造は古地図・下水道図との照合が今後の課題。
