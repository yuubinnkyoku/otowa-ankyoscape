# [BLOG-267] まろん通信「小金井の水路跡」梶野分水・境村分水群（No.24・26・29・30）〔repo初出・梶野分水の全系譜と流末の「深大寺分水」化〕

- **書誌〔確認: 本文全文4本・2026-11-22取得〕**: まろん通信の「小金井の水路跡」シリーズ（クマさん執筆）のうち梶野分水・境村分水の4本＝**[No.24「境村分水」（Vol.524・2017-08-08・archives/6712）](https://koganei-kanko.jp/maron/archives/6712)**・**[No.26「梶野分水その1」（Vol.526・2017-08-13・archives/6734）](https://koganei-kanko.jp/maron/archives/6734)**・**[No.29「梶野分水その4」（Vol.529・2017-08-18・archives/6772）](https://koganei-kanko.jp/maron/archives/6772)**・**[No.30「梶野分水その5」（Vol.530・2017-08-19・archives/6785）](https://koganei-kanko.jp/maron/archives/6785)**（[BLOG-264](BLOG-264.md)制限③のVol.526/529本文取得済み記事）。
- **取水切替と接続地点〔確認: No.24・No.26〕**: 「**梶野分水は江戸時代にはこの付近で玉川上水から直に取水していましたが、明治3年の玉川上水通船のために堰が取り払われ、砂川分水が延長されて梶野分水と繋がります**」〔No.24〕＋「**梶野分水が出来た江戸時代享保の頃は玉川上水から直に取水していましたが、明治3年の玉川上水通船により堰が取り払われ、砂川用水から水が供給されるようになりました。その接続地点は恐らく梶野町二丁目12番付近と思われます**」〔No.26・「恐らく〜と思われます」の筆者推定〕＝**①梶野分水の開削年代＝享保の頃（1716-36）②明治3年（1870）の通船による玉川上水直取水の廃止と砂川用水（砂川分水）経由への切替＝[BLOG-266](BLOG-266.md)（小金井分水の切替文言）・[BLOG-224](BLOG-224.md)/[BLOG-225](BLOG-225.md)（新堀用水・北側新井筋の明治3年統合）と同年次の分水口再編群③砂川用水との接続地点＝梶野町二丁目12番付近〔筆者推定文言〕**。
- **梶野築樋と本流〔確認: No.26〕**: 「**分水は梶野通りと交差して仙川の低地約300mほどを築樋で越えて仙川右岸の台地を南に流れます。築樋を渡りきったところで一部が東に分水します**」＝**梶野築樋で仙川低地約300mを越える立体交差**＝[BLOG-264](BLOG-264.md)（山王窪築樋・小金井分水側）と対になる仙川越え構造物の第2例＋「**梶野分水のメインの流れから東方向へ分水した流れが…ここだけ道が広いです**…**梶野町二丁目分水と仮称します**」〔筆者の仮称命名〕・ケヤキ並木と歩道への転用観察。
- **境村分水〔確認: No.24・repo初出の独立分水名〕**: 「**向きを変えたその当たりから東方向に「境村分水」が分かれていて、その水路跡が現在遊歩道として残っています。「梶野町三丁目の遊歩道」です。この水路跡は武蔵野市に入ると「桜堤遊歩道」と名前が変わります。名前だけでなく、レンガが敷き詰められたかなり人工的な遊歩道となります**」＋「**玉川上水は武蔵野台地の多摩川と荒川の分水嶺、つまり標高の高いところを辿って造られています。その南側で玉川上水に接近して流れていた境村分水は、その南側の広い開墾地に自然流下で水を供給できたわけです**」＝**境村分水＝梶野分水から東分岐（梶野町三丁目遊歩道→武蔵野市「桜堤遊歩道」に名称変更）で、玉川上水分水嶺の尾根に沿って開墾地に自然流下する用水**〔「桜堤遊歩道」＝[BLOG-268](BLOG-268.md)Vol.45（2014）で既に観察された遊歩道の、境村分水としての系譜特定＝2014記事と2017記事の接続〕。
- **名主後裔の現住〔確認: No.24・家文書との接続文言〕**: 「**砂川用水はハナノキ公園への通路と交差する付近ではきちんと整備された姿で現れ、かっての梶野新田の名主だった梶藤右衛門さんのご子孫の方が住む当たりで南の方に向きを変えます。この付近からは梶野分水と呼ばれるようになります**」＝**かっての梶野新田名主・梶藤右衛門の子孫の現住宅付近で砂川用水が南に向きを変えて梶野分水となる**＝[GOV-505](../gov/GOV-505.md)（梶家文書絵図・享保5年・寛保4年の水利施設）・[GOV-509](../gov/GOV-509.md)（編纂資料シリーズ第56〜64編梶野新田梶野家文書8分冊）の**梶家文書系史料の土地側の接続点**〔現住宅と文書所蔵家の同一性は本文に明示なく断定しない〕。
- **本流の東西分岐と両流路〔確認: No.29・No.30〕**: 「**梶野分水の本流はかっての東小金井貨物駅（現在造成地として整備中）付近で東と西の二つの流れに分かれます**」〔No.29〕:
  - **東流〔No.29〕**: 「**東側の流れは現在の富士見通りに出て、西武多摩川線との踏切直前で南に折れて連雀通りまで直進します**」＋「**この富士見通り、地蔵通りの東側延長部分に相当してかっては繋がっていましたが、東小金井駅が設けられたとき分断されてしまいます**」＋「**南に折れた水路跡は現在遊歩道として利用されています。遊歩道南５号線と南１号線です。途中に幼稚園のグランドがあって中断されますが、恐らくこの部分は幼稚園に払い下げられたものと推測します**」〔南折後の遊歩道南5号・南1号。幼稚園への払い下げは筆者推測〕。
  - **西流〔No.30〕**: 「**日本歯科大グランドの東側の路地が水路跡です。そのまま南側の個人の住宅の庭に接して南に延び、小金井市立東小学校の西側に接する道路の歩道となっています。更にそのまま南に延びて西武多摩川線の新小金井駅前に達し、西武線が出来る前はそのまま南に流れて連雀通りに達していますが、現在は線路で遮られ、線路沿いに南西方向に少し曲がって連雀通りに達しています**」＝**流路＝日本歯科大グランド東路地→東小学校西歩道→新小金井駅前→（西武線で分断・線路沿いに連雀通り）**。
- **連雀通りの合流と「深大寺分水」への名称変化〔確認: No.29・No.30・repo初出の系譜文言〕**: 「**連雀通り　かってこの道路際を小金井分水や梶野分水の末端が合流して井口新田の方へ流れていました。その先は深大寺分水と名を変えます**」〔No.29〕＋「**古地図によれは〔原文ママ〕、連雀通りに達した流れは連雀通り沿いに西から流れてきた小金井分水と合流し、東側に流れて井口新田の達し〔原文の乱れ〕南に折れて深大寺の方へ流れていました。この辺りからは流れの名称が変わり深大寺分水となります。しかし連雀通り沿いにその痕跡を探すことは出来ません**」〔No.30〕＝**①梶野分水（西流・東流）＋小金井分水の末端が連雀通り沿いで合流＝用水系統の「束ね」地点②井口新田経由で南折し深大寺方面へ③そこから「深大寺分水」に名称変化＝[BLOG-225](BLOG-225.md)の「南側11分水は砂川分水(深大寺用水)にそれぞれ一本化」・[BLOG-268](BLOG-268.md)Vol.45の「この先では深大寺用水とか呼ばれている」＝**深大寺用水の末端系譜の観察文言の3witness構成**〔「深大寺分水」「深大寺用水」の別表記は本文ごとにそのまま使う〕。

## repoとの関連〔観察〕

- ①**梶野分水の開削（享保）→明治3年の砂川用水切替→境村分水→桜堤遊歩道→深大寺分水という玉川上水系末端の用水系譜**がウェブ記事としては最も具体的な水系変遷文言で、[BLOG-266](BLOG-266.md)（小金井分水の同型の切替）と合わせて小金井市域の玉川上水分水の明治以後の再編を追う基礎資料。②明治3年＝[BLOG-225](BLOG-225.md)の新堀用水（北側7分水一体化）と同時期の再編＝南側の砂川分水11分水一体化（同記事の文言）と表裏をなす小金井側の具体例。③**井口新田**＝[GOV-284](../gov/GOV-284.md)（文久元年分水口体系の「梶野新田七ヶ村組合〔梶野・染谷・南関野・**井口**・仙川新田〕」）の**井口村の所在地が用水末端の経由地として観察層に現れる初例**。④梶野築樋＝仙川低地300mの板橋＝[GOV-510](../gov/GOV-510.md)（仙川の水量史・六郷用水系統化）と、山王窪築樋（[BLOG-264](BLOG-264.md)）とで仙川を越える2築樋の並列。
