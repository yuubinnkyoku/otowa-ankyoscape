# [BLOG-113] sirakigi「千川上水−今と昔−」（武蔵学園記念室・平成8年3月写真展）

- **書誌〔確認〕**：sirakigi（武蔵学園記念室職員サイト）senkawa1.html。平成8年（1996年）3月、千川上水開削300年に合わせて武蔵学園記念室で開かれた写真展「千川上水−今と昔−（昭和14・15年頃の写真を中心として）」の解説頁。2026-11-11時点で直接アクセスは遮断されていたため、[Wayback Machineの2021年5月23日スナップショット](https://web.archive.org/web/20210523022624/http://wwr3.ucom.ne.jp/sirakigi/senkawa1.html)で本文を確認〔第16・17回のsirakigi再取得課題のうちsenkawa1を解消。第12回の丸池・谷端川頁とは別頁〕。
- **写真アルバムの所在〔確認〕**：「当記念室には、旧制七年制高等学校のころの民族文化部門の生徒達による調査研究報告『千川上水』（昭和16年刊行）の元になった写真アルバム4冊（約160枚所収）が保存されている」。平成8年に記念室職員と武蔵大学学芸員課程の学生3名による実地調査を加え約80点を展示。〔[GOV-076](../gov/GOV-076.md)の「200カットあまり」との枚数表記の差異を記録〕。
- **千川上水関係略年表〔確認：年表文言〕**：江戸上水全体の沿革に続き、千川上水の年次が以下のように整理されている（年表は展示解説由来とみられ、個別年次の原典明示はないため「確認」は年表文言レベル）。
  - 元禄9年（1696）創設。「**河村瑞軒の設計による**」。開削文言「元禄九年子年多摩郡保谷村より玉川上水を引き、巣鴨村迄５里５［２］拾４町掘割庚申塚通リ、本郷、湯島、浅草へ懸る。仙川村太兵衛、徳兵衛開発仰せつかり、仙の字を改め千川を両人の姓に給る」〔河村瑞軒設計説・「５里５拾４町」の距離文言はrepo初出〕。
  - 宝永4年（1707）潅漑許可。「関、井草、中村、中新井、長崎、滝野川、巣鴨村等７個所の分水」。水料は水田1反歩につき玄米3升〔玄米3升/反は[GOV-067](../gov/GOV-067.md)と一致〕。
  - 享保7年（1722）廃止（室鳩巣の地下水道説を紹介）。享保17年（1732）元樋を「竪３尺横３尺５寸」から「１尺４方１間暗渠」に縮小。元文2年（1737）「内法１尺５寸横２尺・長さ１間の埋樋」。安永2年（1773）「内法１尺七寸横２尺３寸・長さ３間の埋樋」を許可、以後運上金として年「**金４両１分**」の水税〔元樋寸法の変遷と水税額はrepo初出〕。
  - 安永9年（1780）上水として再使用。天明6年（1786）上水使用を廃する。
  - 元治元年（1864）利用組合は千川幹線の村々（関、上・下石神井、中新井、江古田、葛ヶ谷、長崎、池袋、中丸、金井窪、滝野川、巣鴨等）と青梅街道沿い分水の村（阿佐ヶ谷、天沼、下荻窪、上井草、上鷺宮、中村等）あわせ**18か村、全水田面積の6割にあたる111町歩**の水田に分水〔「18か村・111町歩」は[GOV-067](../gov/GOV-067.md)の「20か村」と数字が異なるため、両者の母体（名寄せ方）の照合が要る〕。慶応元年（1865）滝野川村に反射炉、水力応用の水車運転。
  - 明治3年（1870）玉川上水通船開設に伴い旧来の直分水を廃止し砂川村地内各合併口からの分水に変更。千川側は水量不足。**明治4年（1871）境橋上流の分水口に変更。明治6年（1873）板橋火薬製造所に分水。明治8年（1875）王子製紙会社、大蔵省抄紙部に分水**〔3点ともrepo初出の年次〕。
  - 明治13年（1880）千川水道の再興。岩崎弥太郎外3名が千川水道会社を設け、本郷・下谷・小石川・神田区の飲料に通水〔[BLOG-095](BLOG-095.md)分配堰碑の樋口寸積（印刷局抄紙部・王子村外22か村）と接続する年次〕。明治14年（1881）**千川水道取締禁令5カ条**（魚鳥捕獲・遊泳・洗浄の禁止、汚穢物投棄の禁止、汚水混入の禁止、堤上竹木下草の伐採禁止、水道敷地内への車・牛馬の牽入禁止）〔禁令の全文引用はrepo初出〕。
  - 明治40年（1907）改良水道の普及により飲料水給水廃止。「**岩崎邸六義園、王子方面の用水は存続**」〔六義園給水の存続文言は、六義園給水昭和43年停止説（第4回・駅からマンホール）の背景〕。明治41年（1908）千川水道会社解散、**千川水利組合結成**〔分配堰碑裏面明治42年3月追刻（[BLOG-095](BLOG-095.md)）と1年の差がある点は照合課題〕。
  - 昭和13年（1938）水利権者は「内閣印刷局の抄紙部、陸軍火工兵器廠、岩崎家（現六義園）、妙正寺川谷の水田、練馬の一部水田所有者」。
  - 昭和21年（1946）板橋浄水場設置。昭和23年（1948）10月11日付で練馬区議会議長から千川上水の管理権を千川上水利用組合から都の河川課へ移すよう求める意見書（氾濫・溺死・道路損傷の弊害除去）を都知事に提出〔[GOV-075](../gov/GOV-075.md)の意見書原文所在と日付が一致〕。昭和25年（1950）5月、地元住民が暗渠化工事促進の請願書を練馬区議会に提出、区が都へ請願し26年度に練馬区内第1期工事予算が計上。**昭和27年（1952）3月、練馬区の暗渠化工事着手**〔[GOV-056](../gov/GOV-056.md)「27年3月以降」と一致、Wikipedia「1952年着手」説（第17回ノート）の原典候補を強める〕。**昭和28年（1953）千川上水・武蔵学園前が暗渠となる**〔江古田校地周辺の暗渠化の具体年次としてrepo初出。濯川（[ORG-018](../org/ORG-018.md)・[ORG-019](../org/ORG-019.md)）の千川との連絡史の基準年〕。
  - 昭和29年（1954）保谷新田地先の玉川上水取水口を廃止し武蔵野市関前地先に新取水口。昭和45年（1970）都水道局（板橋浄水場）が取水を停止、**昭和46年（1971）大蔵省印刷局王子工場が取水を停止**〔1971年途絶（第1回調査）の日付細分としてrepo初出〕。
  - 昭和59年（1984）野火止新用水、昭和61年（1986）玉川上水の下水処理水による復活。平成元年〜（1989〜）千川上水の復活（開渠化）（**武蔵野市、練馬区、豊島区（計画）**）〔豊島区が「計画」として挙げられている点を記録〕。
- **1996年時点の状況〔確認〕**：「地中に深く埋設されてから５０年以上経った今日でも、多くの地域の人達の記憶のなかに千川上水は生きている」「上流域の武蔵野市から練馬区の一部までは清流が復活されているが、中下流域では依然として暗渠のままで、**一部地域の復元計画も中止されたまま**」〔「埋設から50年以上」は1996年の感想文レベルの表現であり、暗渠化着手年代の資料としては用いない。「復元計画中止」が豊島区側計画の停止を指すかは断定しない〕。
- **千川上水絵図の所在〔確認〕**：展示品(1)「千川上水絵図（複製・千川善蔵所蔵）**『東京市史稿』上水篇第1巻付録**」。解説の正徳末頃説を「御鷹部屋ヘ掛ルモノ」の文言と享保元年の鷹狩復興から**享保初め頃**と推定〔千川家文書（[MAP-155](../maps/MAP-155.md)・[MAP-156](../maps/MAP-156.md)・[GOV-038](../gov/GOV-038.md)）と『東京市史稿』の関係を結ぶ手掛かり。neribun通し目録調査の継続課題〕。展示品(4)「江戸時代上水図（千川上水絵図を元に作成）」も展示されたと記録。新編武蔵風土記稿の千川上水跡項も引用（「堀幅４・５尺、或ハ広キ所モ九尺ニ過ズ。（滝野川）」）。
- **注意〔制限〕**：年表の各年次の出典（区史・千川家文書等のどれに依拠したか）は頁上に示されず、他所の記述（[GOV-067](../gov/GOV-067.md)の村数・[BLOG-094](BLOG-094.md)の水利組合年次表記）と食い違う箇所は資料間差異として並記し、本年表単独では確定しない。
