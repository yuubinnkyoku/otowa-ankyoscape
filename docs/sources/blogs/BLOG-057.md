# [BLOG-057] 谷端川沿い湧水ものがたり　椎名町の北から南

- **直接確認（2026-11-11、open_url・本文全文）**：シリーズ第2回。南長崎支流・愛心幼稚園支流の2支流と第六天の祠を扱う。
- **第六天の祠〔観察〕**：**長崎2-15**にあった第六天の祠。かつて**10畳ほどの沼**があったとの証言。2012年取材時には現地で祠が見当たらず、Googleストリートビューの旧画像で同一駐車場に祠が写っていることを確認し、**直近に撤去された**と判断している。〔観察＋画像比較〕
- **南長崎支流（仮）〔推定を多く含む〕**：水源は**南長崎公園**（公園内に井戸が現存）と推定。井戸からの窪みを延長すると銭湯・広野湯の裏手に達し、保育園の崖下を経て**南長崎5-24付近で西武池袋線に並行**、**椎名町駅のすぐ横で谷端川に合流**と復元する。大部分が地形からの推論で、本文も「ほとんど地形だけを頼りに推論せざるをえない」と明記。**西武池袋線沿い一帯は昭和10年代まで湿地が続いていた**と記す〔紀要11号由来の叙述〕。
- **愛心幼稚園支流（仮）〔観察〕**：**目白5丁目・山手通りのすぐ内側に軽くえぐれた窪地**が水源。愛心幼稚園脇の暗渠から北へ、区立施設敷地を抜け、西池袋中の横の道となって谷端川「Uの字」の底に南から合流する。
- **重要な追記〔確認〕**：2014年9月8日付で「南長崎さま」のコメントを契機に**検証・修正記事（[再検証](http://lotus62ankyo.blog.jp/archives/7712218.html)）が書かれている**。本記事の南長崎支流の流路復元は仮説段階として扱い、再検証記事（本文未確認）と合わせ読むこと。
- **repoへの関連**：南長崎支流・愛心幼稚園支流の実景・水源位置はrepo初出。椎名町駅すぐ南の車止めの道（谷端川U字底）は[natrium.jp](https://natrium.jp/canal_lot/yabata/index.html)の本流記録と位置対応する。
