# [BLOG-285] やまぐちたくじ「街探シリーズ＜３＞水の苦労した田無の興隆」〔1964年暗渠化説・橋場の地名由来説〕

## 内容〔確認: 本文・2026-11-22取得〕

- **書誌〔確認〕**: note「やまぐちたくじ」（1470ty）の[街探シリーズ＜３＞水の苦労した田無の興隆](https://note.com/1470ty/n/nb2591736d9d2)〔2023-11-01 18:27〕。田無橋場行バスを切っ掛けにした田無の町歩き・考察エッセイで、田無用水・橋場・遊歩道化の年代についての叙述を含む。
- **橋場の地名由来〔確認: 本文直接引用〕**: 「**今回、三鷹から田無橋場行のバスが出ており、「田無橋場」ってなんだ？というのが、田無訪問の切っ掛けだった**」＋「**調べたら、小平市小川から玉川上水を分水して、田無用水を通していた。この用水に田無の街に入る手前で橋を架けたのが、橋場の地名の由来のようだ**」＝**橋場（田無）の地名由来＝田無用水に田無の街の手前で架けた橋**〔「のようだ」推定〕。また「**この田無用水が引かれたのが１６９６年のこと**」＝1696年引水文言〔確認・[BLOG-281](BLOG-281.md)・[BLOG-282](BLOG-282.md)と一致〕。
  - **対照**: 橋場という地名は浅草側の橋場（[GAZ-097](../gazetteers/GAZ-097.md)橋場条の「橋場本名石浜」など盛衰記経由の中世地名考証群・repoの松橋／板橋論）と**同名異地名**。田無の橋場は田無用水関連の近世以降の小地名で、名前の類似から統合しない。
- **田無の水利と宿場〔確認: 本文直接引用〕**: 「**田無には川がなく、井戸を掘っても水が出ないという条件の悪い土地だった。隣り合う小金井は「黄金の井戸から水がわく」のが地名の由来となったのとは大きな違い**」＋「**江戸時代初期に江戸の街づくりのため、青梅の石灰を運ぶ青梅街道（成木街道）が青梅―田無―新宿ルートで開かれた**」〔= [BLOG-284](BLOG-284.md)（大貫伸樹・田無市史要約の慶長11年青梅街道開設文言）と一致〕＋「**水のない田無宿にはあまり多くの旅人を泊めることができず、田無は発展できないでいた**」＝**水利条件と宿場発展の関係づけ**〔筆者考察〕。「**そういう意味では田無用水は畑作にも重要だったが、何よりも田無に住む人や旅行者の生活用水＝命に水だった**」。「**田無の街の活性化は羽村で多摩川から取水された水によってなされたのだ**」＝**田無用水の水を「羽村の多摩川取水」にまで遡って捉える視点の記録**〔確認〕。
- **1964年暗渠化説〔確認: 本文直接引用〕**: 「**しかし、田無に住む人の生活を支えた田無用水も、終戦後の経済成長とともに、水道が整備された結果、必要性が薄れ１９６４年、くしくも１回目の東京オリンピックの年に暗渠化され、今は橋場から北側「やすらぎのこみち」、南側が「ふれあいのこみち」と名付けられたレンガの遊歩になっている**」＝**田無用水（田無市街地区間）の暗渠化年代＝1964年（東京オリンピックの年）説**〔確認・筆者叙述。出典の明示なし〕。
  - **対照**: musasinowalker〔BLOG-281〕は暗渠化年代を特定せず（「35年ほど前〔1980年代〕まで田無市役所の先まで水路跡が転々」・氷川通りの歩道一体区間が「以前は暗渠」記憶）・miwa3k〔[BLOG-282](BLOG-282.md)〕は「今はほとんどが暗渠」のみ。**本記事の1964年説は田無用水の暗渠化に具体的年代を与える唯一の文言**で、repoの暗渠化年代系列（谷端川1960年代前半説など）の対照データになるが、**単一出典のため「説」扱いとする**。
- **遊歩道化の現況〔確認〕**: 「**南北の二つのこみちを、橋場から歩いてみたが、かなりの距離があり、ところどころに昔用水だったころの面影を感じる曲線が現れる**」＋「**北側の「やすらぎのこみち」を行くと、最後あたりが総持寺、田無神社になる。このこみちを歩いていると、角々に地蔵尊や道祖神、馬頭観音など、原初的な信仰のあとも見られる**」＝**遊歩道沿いの石仏・道祖神群の観察**〔確認〕（庚申塔・馬頭観音= [BLOG-282](BLOG-282.md)の観察と呼応）。

## repoとの関連〔観察〕

- ①**暗渠化年代の候補追加**: 1964年説（本記事）・昭和30年代埋め立て開始〔田無新田用水・[BLOG-280](BLOG-280.md)〕・昭和中期ごろトンネル流末〔[BLOG-281](BLOG-281.md)（4）〕という田無方面の水路終末期の年代観察が揃い、**都内各所の暗渠化年代系列（谷端川・弦巻川研究の「いつ暗渠化したか」目的）に新たな比較点を与える**。
- ②**橋場（田無）**: 地名対照表の新規行（浅草橋場との同名異地名の注意つき）。水に関連する小地名の語源説（用水の橋）として、repoの橋名・地名研究（庚申橋・千貫橋・樋口橋〔BLOG-274〕など）に加わる。
- ③**羽村への遡行視点**: 「田無の活性化は羽村で多摩川から取水された水による」という文言は、玉川上水系全域論（開渠の多摩川→羽村取水→田無）の市域エッセイでの一般流通を示す記録で、水系の連続性の認識例。

## 意義〔観察〕

- 一般読者向けエッセイとはいえ、**暗渠化の年代（1964年説）と橋場の語源説という、専門系ソースにはない年代・由来文言**を1記事で含む。出典不明の推定を含むため「説」扱いで対照表に整理し、年代の断定はしない。
