# [BLOG-088] Natrium.jp 谷端川（宮原橋〜板橋駅）

- **直接確認（2026-11-11、open_url・本文全文）**：豊島区立上池袋図書館所蔵の冊子『[旧谷端川の橋の跡を探る](../books/BOOK-062.md)』（1999）を参考に、文京区・豊島区境の宮原橋から大塚駅を通って板橋駅まで下流側区間を歩いた観察記録（主に2023年12月30日・2022年9月19日撮影）。**橋名も同冊子に拠る**と明記する。
- **見返り橋〔確認：冊子準拠の橋名＋観察〕〔repo初出〕**：大塚三業通り商店街の**割烹のあたりに見返り橋があった**。冊子側に橋名の由来記述があったかは本文では分からず、位置は「割烹のあたり」という観察記録として扱う。
- **空蝉橋〔確認：観察＋推定〕**：大塚駅北側線路脇・自転車駐車場西側に**鉄板で蓋をされた空間**があり、隙間からのぞくと**蓋暗渠**だった。**空蝉橋はもともと高台にあり、谷端川の支流というには不自然な位置**にあるが、**旧貨物駅の排水路とかそういうものだろうか**と推測する。〔推定〕 既存の[谷端川ノート](../../谷端川.md)が空蝉橋を支流・水路敷候補として挙げる箇所の、2022年時点の具体的な現地観察（蓋暗渠の存在）にあたる。
- **大塚天祖神社〔確認：社の説明の転記〕〔repo初出〕**：大塚駅南口。**旧巣鴨村の鎮守**として**元亨年間（1321〜1324年）に伊勢神宮を勧請**したとされ、**明治6年（1873年）までは神明社と称していた**という。〔社史は二次転記／旧巣鴨村と谷端川流域の地域史資料〕
- **巣鴨小学校前の川跡〔観察〕**：大塚三業通り沿いの川跡は**緩やかに左右に曲がりながら進む**。松浦橋から右岸の南大塚一丁目児童遊園向こうに**車止め**、一つ道路を挟んだ北側に**未舗装の砂利道**（支流の水路敷のように見えるが確認資料は見つかっていない）がある。
- **旧王子電鉄の鉄橋〔確認：観察〕**：藤橋跡の上流側で千川通りが都電荒川線（さくらトラム）を跨ぐ位置には**旧王子電鉄の鉄橋があった**。**警報機も遮断機もない**が、都電は線路上の信号機を見ており、道路側も信号で制御されていると観察。〔既存の谷端川鉄橋記述（『王子電気軌道三十年史』など）と位置照合の対象〕
- **山手線ガード北側の川跡〔観察〕**：千川通りは左折するが、川跡は**ビル脇を通っていたらしい**。その先が藤橋跡で、藤橋から大塚駅北口を望む写真を添える。
- **repoへの関連**：BOOK-062（現物未読）の橋名（見返り橋・空蝉橋・姿見橋・藤橋・熊野窪橋・宮原橋・松浦橋）を**橋跡の現在位置とともに観察記録化**した点が新しい。**見返り橋・大塚天祖神社はrepo初出**。『旧谷端川の橋の跡を探る』の内容の一部が、信頼できる二次観察を通じて初めて具体的に知られた。
- **制限〔未解決〕**：各橋名の原典（冊子内の掲載頁・由来記述）は未確認。見返り橋・空蝉橋の比定位置はnatriumの写真観察に基づく。
