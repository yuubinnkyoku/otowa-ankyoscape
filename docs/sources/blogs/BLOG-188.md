- **雑司が谷の地名由来諸説〔repo初出・ブログ転記段階〕**: 『新編武蔵風土記』の紹介として①**法明寺または小日向金剛寺の「雑司料」**（税・物資を納める支配地）説、②**南朝の衰えを嘆いて官を辞した柳式若狭・長島内匠・戸張次左衛門が当地に土着し、子孫が村民として残った**説、「雑士」「蔵主」「僧司」「曹子」の表記ゆれ、③**八代吉宗が紛らわしさから「雑司ヶ谷」への表記統一を命じた**説〔**追記（2026-11-13、第57回）**: ①②③とも豊島区「わが街ひすとりぃ」雑司が谷（[GOV-096](../gov/GOV-096.md)）が同内容を区公式資料として掲載し、独立裏付けがついた。人名表記は区資料では「柳下若狭助」等〕。
- **雑司が谷八景と弦巻川〔伝聞〕**: 「夏は蛍、秋は月」の風光をうたわれた川〔[BLOG-034](BLOG-034.md)の八景（夏蛍・秋月）と同一系列の独立記録〕。昭和7年暗渠化・流路跡の大部分が下水道雑司ヶ谷幹線に転用は既出説の再記録。
- **流路記述〔読図〕**: 丸池（**池袋デュープレックスタワー敷地内＝源流位置の具体化**）→ビックリガード→明治通りを**千歳橋**に向かい途中左折→東京音大前→大鳥神社前→雑司が谷弦巻通り商友会→音羽通り→水窪川と並行→江戸川橋で神田川〔**千歳橋＝repo初出の橋名候補**。他資料との名寄せ・位置特定が次の課題〕。
- **護国寺1681年参道両側配置〔伝聞〕**: 護国寺建立（1681・天和元年）に参道（現音羽通り）を造る際、弦巻川を参道西側・水窪川を東側に流す工事がなされた〔[BLOG-089](BLOG-089.md)の1681年両川整備伝承と同一系統の二次記録で、独立裏付けとは数えない。横断調査ノートの評価を維持〕。
- **源頼家の弓の弦由来伝承〔伝聞〕**: 筆者は「おそらく後世のでっちあげ」と評価〔[BLOG-073](BLOG-073.md)・[ORG-017](../org/ORG-017.md)既出の伝承に対する批判的コメントの記録〕。
- **上川口屋〔repo初出〕**: 鬼子母神境内の駄菓子屋、**1781年（天明元年）創業・日本で最も古い駄菓子屋**との記述〔[BLOG-185](BLOG-185.md)かるた販売元の補完。川と直接関係ない雑司が谷の生活史・地名資料として記録。**追記（2026-11-13、第57回）**: 創業年次は週刊ポスト取材記事（[BLOG-190](BLOG-190.md)・2022年5月）が独立して1781年・飴屋として創業と報じ、裏付けがついた〕。
