# [BLOG-147] xaymaca「東京暗歩」弦巻川前編（池袋〜護国寺西）2020年

- **直接確認（2026-11-12、open_url・本文全文）**: はてなブログ「Say SILLY Things!」の東京暗歩シリーズ。池袋西口〜護国寺西交差点まで弦巻川跡を下流方向に歩く2020年11月の観察記。水窪川編（第36回評価済み・取得不能が続いていた）と同じシリーズで、**弦巻川頁は本回初取得**。
- **〔観察・repo初出候補〕 大鳥神社の「弦巻川暗渠化祈念碑」**: 大鳥神社境内に「**弦巻川暗渠化祈念碑**」とのこと（「文字はよく読めませんでした」）と観察〔碑名の表記として[GOV-062](../gov/GOV-062.md)「鶴巻川暗渠記念碑」（1932年建立の年次記録）・[BLOG-049](BLOG-049.md)「下水道施設記念碑」（1931年）に次ぐ**第三の呼称での観察記録**。同一碑と推定されるが、3呼称の異同・碑面の正式名称は断定せず、現地採録が解決手段〕。
- **〔観察〕 源流部**: メトロポリタンホテル前＝元池袋史跡公園の池袋地名由来モニュメント（丸池説：[BLOG-063](BLOG-063.md)参照）を起点とする読図は既出系統。**びっくりガードの高架壁に雑司ヶ谷いろはかるた「ぬ」＝「弦巻」**の絵があることを弦巻川文脈で確認した観察は、[BLOG-004](BLOG-004.md)（雑司ヶ谷いろはかるた）の桥名的補足に相当。
- **〔観察・推定〕 清土鬼子母神方面の支流読図**: 弦巻通りから清土鬼子母神へ向かう脇路地の低い佇まいを「**昔は弦巻川に合流する支流だったんだろう**」と推定〔観察段階の仮説として記録。清立院の小山上の地形とも整合〕。弦巻通り自体が元流路で低く、両側に高台（脇路地がなだらかな坂）という谷構造の読図。
- **〔観察〕 2020年時点の現況変化**: 弦巻通り終点（首都高5号池袋線手前）の木造昭和建築・黒板塀の小料理屋『寛』が消滅〔弦巻川沿いの戦後建築の消滅記録として景観変化のデータポイント〕。三上寛旧宅跡・日本女子大学生寘・雑二ストアー等の景観記録。
- **意義**: 弦巻川の東京暗歩シリーズ後編（護国寺西〜江戸川橋）とあわせ、2020年時点の流路読図・碑の観察を提供。碑の第三呼称は「鶴巻川／弦巻川」表記問題（[弦巻川](../../弦巻川.md)）に新しい観察データを加える。
