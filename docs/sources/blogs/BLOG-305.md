# [BLOG-305] 戦跡紀行ネット・中島飛行機武蔵製作所戦跡散策〔引込線→競技場線の年次群と公園碑文の転写・現況遺構の観察記録〕

- **書誌〔確認: 本文全文・2026-11-23取得〕**: 戦跡紀行ネット「〜日本の近代と慰霊の地を巡る〜」（senseki-kikou.net）の記事「**中島飛行機武蔵製作所関連の戦跡散策**」 https://senseki-kikou.net/?p=1483 〔**2019/5/5投稿**・2022/11/26更新表記・**平成29年11月撮影**（武蔵野市・西東京市）。同サイトの[BLOG-025](BLOG-025.md)（水窪川旧排水口石積みの移設保存・2017年写真・2021年投稿）に続く**同サイトから2本目の収録**〕。
- **引込線三線構造と年次群〔確認・repo初出の数値群〕**: ①三鷹側から「**堀合遊歩道**」として整備＝**国鉄武蔵野競技場線跡**、武蔵境側から「**本村公園**」として整備＝**境浄水場引込線跡**、両者を跨ぐ＝**中島飛行機武蔵製作所引込線跡**（武蔵境駅から工場へ軍需物資を輸送）という**三線の空間構造**〔repo初出の対応構造文言〕。②「**昭和25年5月に中島飛行機武蔵野製作所の引込線が廃線。昭和26年4月に武蔵野競技場線開業、34年11月1日に廃線**」＝**中島引込線の廃線年月（昭和25年5月）・武蔵野競技場線の開業（昭和26年4月）・廃止日（昭和34年11月1日）**〔repo初出の年次群で、[GOV-556](../gov/GOV-556.md)岡本勇証言「引込線跡に野球場への線路を敷く」と対になる鉄道史側の数値〕。③**ぎんなん橋**＝「**平成24年(2012)に当時の橋台跡の上に現在の橋が建設**」「橋の両脇には当時の「橋台」の跡がかろうじて残されている」＋廃線跡を思わせる鉄路の復元〔個人blogの現況観察〕。④「**1942年の地図と1951年の地図。武蔵境駅から中島飛行機武蔵製作所工場に向かっていた線路は、戦後に付け替えされ武蔵境から浄水場へ、三鷹から野球場へと**」＝戦後の線路付け替えの観察。
- **関前高射砲陣地跡〔確認・repo初出〕**: グリーンパーク遊歩道途中の案内看板（本blogの写真）に「**関前高射砲陣地**」＝「**この場所には高射砲6門が半円状に展開されていた**」という**6門・半円状配置の文言**〔[BLOG-304](BLOG-304.md)（高射砲はB29に届かず）の陣地側の呼応。陣地の一次史料（陸軍史・防衛研）との照合は未実施〕。
- **武蔵野中央公園碑文の転写〔確認・repo初出の文言群〕**: 「**緑が美しいのどかな畑地であったこの地は、昭和13年、中島飛行機株式会社が、本公園の敷地を含む畑地66万平方メートルに大規模な工場を建設した**」＝**昭和13年・畑地66万㎡の買収建設文言**〔[BLOG-302](BLOG-302.md)公園面積約11.2万㎡と対なる取得敷地の規模〕＋「戦争の激化に伴い**昭和19年11月以来延べ9回にわたる空襲を受け、工場だけでも220名**このほか周辺町民多数の尊い生命が奪われ」＝**延べ9回・工場220名**（[BLOG-304](BLOG-304.md)の計9回・200人以上と対照）＋「**昭和27年、工場跡地に米軍宿舎を建設することが決定**…**昭和48年、ついに返還が実現**」＝米軍宿舎決定（昭和27）・返還（昭和48）＋「**昭和50年、東京都はこの地を都市計画公園として整備することを決定**」「**昭和53年には前提的に全面解放され**」「**平成元年、通称「はらっぱ公園」として親しまれる、現在の都立武蔵野中央公園が誕生**」＝都立公園化の年次群＋「平成11年4月武蔵野市」の碑建立年〔碑=武蔵野市・平成11年4月建立という帰属文言。repo初出の公園来歴の連番〕。
- **跡地内の遺構・施設の観察〔確認・repo初出の文言群〕**: ①**変電室跡**＝都営武蔵野アパート建設後に管理事務所として活用、しかし「**平成27年(2015)に解体**」「**建屋解体途中に「戦災の傷跡＝不発弾の痕跡」が見つかる**も、あとの祭り…」＝**変電室の2015年解体と解体中の不発弾痕跡発見**〔不発弾レーン（[GOV-556](../gov/GOV-556.md)・[GOV-555](../gov/GOV-555.md)・[BLOG-304](BLOG-304.md)）に2015年の点を追加〕。②**正門跡**＝「**敷地面積は約56万平方ｍ(東京ドーム約12個分)**…**約5万人が働いていた**」「一般従業員は別の入口から工場内を張り巡らされた地下道を通じて各職場に赴いていたという」［[BLOG-304](BLOG-304.md)約5万人と一致・「約56万㎡」と公園碑文の「66万㎡」の差は正直記録（工場敷地と買収地の範囲差の可能性が高いが断定しない）］。③**東門跡（推定）**＝武蔵野市役所・市民公園方面・**競技場・プール**（現・武蔵野総合体育館・市民プールのある場所=当時は従業員用運動施設、航空写真でグランド・プールの形が確認できる））。④**北裏バス停**「**中島飛行機武蔵製作所の北側の裏**の意もあるとか。（諸説あり）」＝**地名「北裏」の由来説**〔地名系の候補文言〕。⑤**北門跡・プロペラ試運転場**＝現在のNTT武蔵野研究開発センタ付近（「**このセンター建設時の調査では地下通路が張り巡らされていた跡などが確認されている**」）＝[GOV-555](../gov/GOV-555.md)（地下道2001年解体）の対。⑥**武蔵野中央公園西口側のコンクリート遺構**「東西に伸びるコンクリート片。**一説にはこのコンクリート遺構は工場地下通路の残骸ともされている**」〔一説止まり・現況観察〕。⑦**株式会社SUBARU武蔵野社宅**（北西部・関前橋交差点付近）＝中島飛行機のDNA（戦後富士重工業→SUBARU）の継承文言。⑧**武蔵野大学構内の散華乙女の記念樹碑**（雪頂講堂6号館と図書館の間）＝[GOV-556](../gov/GOV-556.md)沢辺松美証言（武蔵野女子学院4人死亡・「散華乙女の碑」）と対になる**碑の位置（武蔵野大学構内）の観察**。⑨**東伏見稲荷神社境内に中島飛行機株式会社武蔵製作所殉職者慰霊碑**＝[GOV-556](../gov/GOV-556.md)死傷者レーンの慰霊碑系。⑩**延命寺の250キロ爆弾の破片・平和観音菩薩**＋中島ゆかりの**木製プロペラ**（現在は武蔵野ふるさと歴史館に委託展示＝プロペラはエンジン地上試運転用、試運転工場は北門近くのNTT付近）。
- **ふるさと歴史館の展示観察〔確認・repo初出の文言群〕**: **開設記念盃**（中島飛行機の社章・「**中島飛行機株式会社武蔵野制作所昭和十三年五月二十一日**」の側面文言）＝**開設の年月日（昭和13年5月21日）**の金石文的候補〔公園碑文の「昭和13年・畑地66万㎡に建設」と整合〕。**1トン通常爆弾(2000ポンド)の復元**（全長235cm）・鉄兜（正面に中島飛行機の社章）・食事券・屋根や地下通路の破片等の展示。**市制施行70周年記念企画展「TARGET No.357～攻撃目標となった町、武蔵野～」**（平成29年12月時点で開催中）の記録。
- **工場・企業史の要約文言〔確認・repo初出の文言群〕**: 1917年（大正6年）群馬・飛行機研究所創業（中島知久平・元海軍機関大尉）→1938（昭和13年）**陸軍専用エンジン工場として武蔵野製作所（武蔵野市緑町）開設**→1941（昭和16年）武蔵野製作所の西側に**海軍専用の多摩製作所**開設→**昭和18年統合「中島飛行機武蔵製作所」成立**（**国内エンジン生産シェア4分の1**）→**昭和19年11月24日、マリアナ諸島発進のB29東京初爆撃の目標**＝「**高度8000メートル以上の高高度爆撃を行うも、この初空襲での命中率は高くなかった**」・計9回→**疎開30ヶ所以上**（八王子浅川地下壕・宇都宮大谷・福島信夫山→[GOV-556](../gov/GOV-556.md)肥田証言(高尾山の地下壕)・[GOV-556](../gov/GOV-556.md)沢辺証言（浅川分室・小金井分散）と対応→**昭和20年4月国営化「第一軍需工廠」・武蔵製作所=「第十一製造廠」**→戦後**東工場跡地=電気通信研究所やグリーンパーク野球場、都営公団集合住宅**／**西工場跡地=米軍接収→宿舎→返還→平成元年(1989)武蔵野中央公園**＝**東西工場の分割来歴の全対**〔[BLOG-302](BLOG-302.md)（武蔵野中央公園=跡地）・[BLOG-304](BLOG-304.md)（西工場=中央公園周辺）・[GOV-555](../gov/GOV-555.md)（東工場北辺=NTT）の3点を束ねる俯瞰文言〕。
- **意義〔観察〕**: ①**引込線三線構造と年次群（廃線・開業・廃止）**は流路の前後関係の具体化（武蔵境駅→工場→（昭和25年廃線）→競技場線（昭和26-34）→グリーンパーク遊歩道）で、[GOV-556](../gov/GOV-556.md)の岡本勇証言（引込線跡への球場線敷設）と鉄道史側の数値群が対になり、対照表の新設行（堀合遊歩道／武蔵野競技場線／中島飛行機武蔵製作所引込線）で流路・年次の具体化に直結する。②**公園碑文（平成11年4月・武蔵野市）の転写**＝repoで初めて一次金石文的文言として公園の来歴を年代つきで示す記録（66万㎡・延べ9回・220名・米軍宿舎→返還→都立公園化→開園）。③中島レーンの大部分の「地点・年次」を網羅するまとめページで、[BLOG-302](BLOG-302.md)（住民側2026）・[GOV-555](../gov/GOV-555.md)（行政解説）・[GOV-556](../gov/GOV-556.md)（証言集）・[BLOG-304](BLOG-304.md)（報道2026）の各断片が**空間配置（正門→東門→北門→西口→公園）と年次（1938→1944→1950→1989→2012/2015/2017）**の枠に対応づけられる。
- **制限・未解決**: ①**個人blogの観察記録**で、年次群（引込線廃線昭和25年5月・競技場線開業昭和26年4月・廃線昭和34年11月1日）の一次確認（国鉄・JR東日本の廃線資料・武蔵野市史）は未実施。②碑文の転写は写真から起こしたもので、碑文の原本照合は未実施〔数字文言（66万㎡・220名等）の原碑との照合は要human目視ないし追加文献〕。③変電室の「不発弾の痕跡」・コンクリート遺構の「地下通路残骸」説は現況観察由来の伝聞で、裏付けなし。④「北裏」の地名由来は「諸説あり」留め。⑤投稿2019年時点の現況で、変電室（2015年解体済み）以外の遺構の現況の再確認（2026年時点）は未実施。⑥TARGET No.357企画展の図録・パンフの書誌は未取得（画像の判断による部分文言）。
