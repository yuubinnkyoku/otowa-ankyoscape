# [BLOG-394] Natrium.jp「水路敷ペイントその2（田柄用水）」

- **書誌〔確認：curl本文全文・2026-11-28取得〕**：Natrium.jp「名物探し・水路敷ペイント」シリーズその2（suirojiki/suirojiki_02.html・repo初出URL。canal_lot上位目次頁の全リンク走査とrepo既収録URL照合の差分で検出）。田柄川・田柄用水水系の公図上の「水路敷」に描かれた水色ペイント（「水路敷」の文字入り）を平和台・田柄町内・土支田・谷原・三原台・石神井公園駅北側の6区画で網羅した定点記録。写真は2012/5/4・2012/5/12・2013/1/2・2018/2/10・2021/8/21・2022/5/5・2022/8/16撮影の通時観察で、同一地点の劣化・再舗装・復活を追跡している。著者は一部地点を「186番目・187番目の水路敷ペイントとして地図にプロットし直した」と記しており、番号付きの網羅体系である〔観察〕。
- **韮窪＝田柄川上流端の谷頭〔観察・BLOG-367と整合〕**：三原台一丁目17番地（目白通り南側・マンション裏）の水路敷について「**この辺りは韮窪という地名があり、田柄川の上流端と言われる谷頭にあたる**」〔観察〕。韮窪（三原台）起源説（[BLOG-367](BLOG-367.md)）の谷頭位置を丁目・番地レベルで示す観察側の裏付け。なお同頁21番地から先は「**石神井公園駅方向から開削された用水路の跡が残っている**」〔観察〕。
- **消滅事例の年代記録〔観察・repo初出群〕**：①三原台二丁目1番地（練馬清掃工場の向かい）のペイントは「**2016年に暗渠の撤去工事が行われたため再舗装で消えてしまった**」〔観察〕＝暗渠実体の撤去年次記録。②土支田二丁目14番地（都道443号南側・田柄用水の大きなS字カーブ入り口）は区画整理に伴う歩道化で消滅〔観察〕。③田柄二丁目2番地北側の水路敷は「**2015年に区画整理によって廃止されてしまったので現存しない**」〔観察〕＝公図水路敷の消滅実例（2013/1/2撮影の旧記録が残る）。
- **密集事例〔観察〕**：土支田一丁目18番地には**6つの水路敷ペイントが連続**（うち四つ目は「交差点ではなくマンションの入り口脇に塗られており、なかなか珍しい存在」）〔観察〕。谷原六丁目24〜25番地の間を通る水路敷には連続して4つのペイントがあり、「**練馬清掃工場の前のジグザグ水路敷**（道幅＝川幅が広いので文字が小さく見える）」に四つ目〔観察〕。
- **再舗装後の復活事例〔観察〕**：田柄三丁目22〜23番地の西向きペイントは再舗装で「水」の字の上半分だけになっていたが、「**真新しいペイントに塗り直されていた**」（2022/5/5撮影）〔観察〕。田柄三丁目21番地から22番地の方向も2021/8時点では再舗装直後で消えていたが、2022/5には東向き・西向きとも復活しており、186・187番目として再プロット〔観察〕＝ペイントが行政・地元の維持行為で更新されている実態記録。
- **田柄地区の方位限界〔観察〕**：田柄四丁目19番地西側（光が丘公園へ向かう支流）が「田柄では一番北」・田柄三丁目17番地（田柄通り沿い・北へ向かう水路敷）が「一番南」・田柄三丁目28〜29番地の間（北向き）が「一番西」〔観察〕。東田柄橋跡（[BLOG-383](BLOG-383.md)）のすぐ西側にも北向きの水路敷ペイント〔観察〕。
- **石神井公園駅北側＝水系最上流のペイント〔観察〕**：石神井町四丁目9〜10番地の間の水路敷（東側・西側）が「**田柄川水系ではここが最も上流に位置する水路敷ペイント**」〔観察〕＝[BLOG-383](BLOG-383.md)（関口水車〜石神井公園駅から用水開削）の観察と呼応する公図側の痕跡記録。2012/5/12撮影。
- **支流入り口の位置具体化〔観察〕**：田柄四丁目21番地南側＝「北側の光が丘公園へ向かう支流の入り口」、21番地西側＝「水路敷が直角に曲がった先」〔観察〕＝[ORG-051](../org/ORG-051.md)（田柄川幹線・光が丘公園流路）の現地側補完。
