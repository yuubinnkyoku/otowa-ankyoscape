# [BLOG-158] 暗渠ハンター「江古田川と千川上水の接点いろいろ。」2012年・豊玉水車分水と中村分水の流路復元

- **書誌〔確認〕**: 『暗渠マニアック!』著者・髙山のブログ「毎日暗活！暗渠ハンター（旧『東京Peeling!』）」2012年11月5日。cocologオリジナル（lotus62.cocolog-nifty.com）はAccess Deniedだが blog.jpミラー（[BLOG-099](BLOG-099.md)・[BLOG-100](BLOG-100.md)・[BLOG-125](BLOG-125.md)・[BLOG-126](BLOG-126.md)と同手段）で全文取得〔repo未収録回の資料化〕。
- **〔確認・repo初出〕 「豊玉水車分水」の流路**: 手元の「**千川上水と江古田を潤した分水　江古田分水の周辺**」という資料からの抜き書きメモ（**著者表記が見つからないと明記**）として、**①豊玉北5-17から始まる ②千川上水は道筋橋から道の北側に回り通りの南側を流れ、豊玉上2-27にあった水車を回す ③その後南に曲がり、豊玉中3丁目あたりで練馬郵便局南側にあった池からの流れと合わせ、中新井川に注ぐ**と記す〔**「豊玉水車分水」の名称と流路記述＝repo初出**。[GOV-005](../gov/GOV-005.md)の「練馬消防署北側の水車の流末＋練馬郵便局南側の池の小川が三の橋庚申東側で合流する文献に見られない水路」との異同が課題。水車の位置（豊玉上2-27 vs 消防署北側）と合流点（豊玉中3丁目 vs 三の橋庚申東側）が食い違うため断定せず〕。
- **〔観察〕 豊玉北4-10の水路敷**: 資料の流路に沿う場所に「ぽっかりと水路敷表示がある」箇所を豊玉北4-10に確認。環7から練馬駅へ北上行く大きな道の西側の暗渠らしい道を「**練馬郵便局南側にあった池からの流れ**」と同定〔前項の流路の現地裏付け観察〕。
- **〔観察・repo初出〕 中村分水と田中稲荷神社**: 中村北3丁目交差点付近から南下し、**中村垢離取（こりとり）不動尊**の前を斜めに横切り、江古田川に近づく中村分水〔[GOV-005](../gov/GOV-005.md)の下練馬村分水ではなく中村分水の記述。[PAP-027](../papers/PAP-027.md)にも垢離取不動尊あり〕。分水に南から合流する流れの奥に**田中稲荷神社**があり、その流れは東に曲がり中村中学校にぶつかってから北上して合流〔**田中稲荷神社と中村中学校付近の支流系統＝repo初出の観察**〕。中村南1-16周辺の暗渠風の道・江古田川への合流前に「田圃にあちこちと水を回していた」観察。
- **〔推定〕 中新井村分水（北新井分）＝「濯川の分水」とする解釈**: 「中新井村分水」と「中新井村分水（北新井分）」が複数の文献に同名で出ることを不思議がりつつ、「**自分の中ではこちら（北新井分）は『濯川の分水』ということにしてます**」〔GOV-005（北新井分水=武蔵大学内=濯川の初出の書き言葉資料）と一致する独立の解釈。著者の整理であり文献確定ではない〕。
- **〔確認〕 石神井川方面の分水の言及**: 同一の千川上水沿い近距離に「北に向かって**新桜台付近を通り石神井川に注ぐ分水**もある」〔[GOV-005](../gov/GOV-005.md)の下練馬村分水の流路（栄町15付近から羽沢・桜台境）との対応候補。断定せず〕。
- **意義**: [GOV-005](../gov/GOV-005.md)が「役割は調査の必要あり」とした豊玉地域の文献に見られない水路群について、「江古田分水の周辺」という資料名と流路記述を初めて記録。江古田川〜千川上水接続の分水復元資料。

## 制限・未解決

- 抜き書き元資料「千川上水と江古田を潤した分水　江古田分水の周辺」の著者・書誌（練馬区関係資料か）の特定。豊玉水車分水の水車位置・合流点がGOV-005記述と食い違う点の原典照合。田中稲荷神社の位置と境内由緒。
