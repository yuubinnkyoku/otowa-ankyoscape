# [BLOG-262] Natrium.jp「善福寺川周辺の水路敷群」（松庵川/大宮前大下水 上流・松庵川下流・松庵川分水と女窪の支流 の全3頁）〔repo初出・[BLOG-162](BLOG-162.md)・[BLOG-174](BLOG-174.md)・[BLOG-250](BLOG-250.md)（松庵川の大正後期開削・悪水系文言）系に対応するNatrium側の全流路実走〕

- **書誌〔確認: 本文全文3頁・2026-11-22取得〕**: ①「松庵川/大宮前大下水上流」（2017/10/9・2017/8/19ほか）・②「松庵川下流」（2020年ほか）・③「松庵川分水と女窪の支流」。BLOG-254目録の「松庵川3頁」の全掃引。
- **松庵川の起源文言〔確認・『杉並の川と橋』（[BOOK-229](../books/BOOK-229.md)）依拠〕**: 「松庵川は旧杉並村（現杉並区）の**大ヶ谷戸という字名があったあたりの谷で善福寺川に合流している支流**だが、『杉並の川と橋』（2009/3杉並区郷土博物館発行）によれば**西荻窪駅西側にある吉祥女子中学高校あたりから始まる自然の谷間に、甲武鉄道（現在の中央線）を建設した際の用土採取跡地にできた池や周辺の下水を流すために開削された人工的な河川**とされる」「**もともとは松庵川という名前は付いておらず、大宮前大下水などとも呼ばれる下水路だったらしい**」〔**甲武鉄道起源の人工河川説・旧名「大宮前大下水」＝下水路**という性格規定文言。[BLOG-250](BLOG-250.md)（大正後期開削・吉祥寺方面下水＋工事用土採掘後の湧水処理・中流域で上下分離）と引用元を同じくする独立文言で、**上流端＝吉祥女子中学高校あたり・湧水源＝用土採取跡地の池（女窪・男窪）**の位置が具体化〕。
- **窪地名群〔確認・repo初出候補〕**: 「上流端は現在の**吉祥女子中学高等学校あたりにあったとされ、その近辺には甲武鉄道（現在の中央線）敷設工事用度の採掘で出来た窪地（**女窪と男窪**）や、**紺屋窪**という窪地があり、松庵川（大宮前大下水）は**それらの湧水や下水を流すために作られた**という」〔女窪・男窪・紺屋窪の3窪地名の初出一級の記録。窪系地名（蛇窪・清水窪〔[BLOG-251](BLOG-251.md)〕・鶏声ヶ窪等）の対照レーンに追加〕。女窪支流は「かつて**女窪と呼ばれた西荻窪駅北側の窪地**から善福寺川に向かって流れていた水路」で、伏見通りの**伏見稲荷神社**は「女窪があったと思われるあたりを通る伏見通りの由来ともなった」〔伏見通りの由来と女窪位置の対応文言〕。
- **大宮前新田と寺社群〔確認〕**: 「松庵川こと大宮前大下水は、**神明通り（新田街道、北街道）南側の大宮前新田の短冊状の土地割りの中を流れていたらしい**」〔新田の条里割りとの関係〕。**慈宏寺**: 「**寛文13年（1673年）創建**というから、南隣の大宮前春日神社（**万治年間、1658〜60年創建**）とほど近い時期に建てられた寺院で、**いずれも近辺の大宮前新田を開墾した井口家によって建てられたらしい**」〔新田開発と寺社建立の関係文言〕。**大宮前春日神社**の地名: 「杉並区にはもう一つ大宮という地名と大宮八幡宮があるため、**こちらの地名は宮前と省略された**という。で、そもそも**大宮前というのが春日神社のことではなく大宮八幡宮の手前にあるからという説もあり**、微妙によくわからない地名ではある。**いずれにせよ、松庵川の旧名である大宮前大下水の名前の元になっているのは確かなようだ」〔「宮前」地名の由来二説（春日神社説・大宮八幡宮手前説）の併記と大下水の名の由来〕。**神明天祖神社**: 「**天正12年（1584年）の検地ではすでに祠があった**という古い神社」〔検地（天正12年＝豊臣検地系の可能性）に先立つ祠存在の文言〕。
- **松庵川分水〔確認・現況観察〕**: 「松庵川の北側に、善福寺川に向かって分水が落とされている」＝「**東吾橋の西側に大きく口を開けた現役の排水口が分水の合流点**。松庵川も上流部は甲武鉄道建設時に作られた窪地からの排水に使われていたというので、**途中からこちらへ水を分けて落としていたのだろう**」〔**現役の開渠排水口の存在観察**＝松庵川の污水を善福寺川へ落とす構造の痕跡。本村橋脇の細い水路敷の観察もある〕。
- **流路の実走〔確認・観察〕**: 環八神明通りの西側で水路は神明通りに沿い（歩道部分かどうかは「よくわからない」）→ファミリーマート裏手→南荻窪図書館南側で進路を南へ→宮前けやき緑地（西から流れて来た）→宮前中学校の南側→慈宏寺境内の西向き蓋暗渠→神明通りから南へ分岐。下流側の本文（松庵川下流頁）は善福寺川合流部までの水路敷観察〔旧流路の道路化・車止めの観察が主で、水窪川・谷端川系の資料性は上流起源文言・窪地名群・寺社年代が主〕。

## 制限・未解決

- ①甲武鉄道起源説・用土採取跡地説は『杉並の川と橋』（BOOK-229）の孫引きで、開削時期（大正後期〔BLOG-250〕との関係・甲武鉄道の敷設時期〔明治中期〕と用土採取の年代的整合）は未確認。②「工事用度の採掘」は本文側の表記ゆれ（用土）か未確認。③女窪・男窪・紺屋窪の位置の精确な比定は本文のざっくりした表現どおり（西荻窪駅北側）で、地籍図等との照合は次回以降。④宮前地名由来二説の裁定は不能。
