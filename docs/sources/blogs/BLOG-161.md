# [BLOG-161] らんまる「弦巻川散歩」

- **直接確認（2026-11-13、open_url・本文全文）**：2015年12月26日の弦巻川全流路踏査記録。同一筆者の水窪川記録（[BLOG-046](BLOG-046.md)）の前日にあたる記事で、BLOG-046が言及する「前日にあるいた弦巻川」の実体。第40回以来アクセス不能とされていたが今回直接取得に成功。
- **昭和7年暗渠化の二次記録〔観察・二次叙述〕**：冒頭で「昭和七年に暗渠化され」とする。既知の年次データポイント（高田町下水道1929-33・大鳥神社1940年社殿配置変換〔BLOG-151〕・雑司が谷八景「昭和4年暗渠化」〔BLOG-034〕）に並ぶ2015年時点の独立二次記録。**どの年次が正しいかは本記録では断定しない**。
- **大鳥神社参道＝流路跡の読図〔観察〕**：明治通りから歩道橋上に見る「大鳥神社参道」が「見事に蛇行」し、参道＝弦巻川流路跡と読む。境内の弦巻川暗渠化記念碑（既知）・雑司ヶ谷ナスの説明も確認。
- **首都高5号下の空き地＝流路跡〔観察〕**：講談社前〜大塚警察署前の首都高下で、住宅地裏に細長い空き地を発見。「水が浸みだしているせいか緑の敷物が出現、ところどころ下から水が浸みだしている」とし、右壁が護岸状になる行き止まりの空き地を流路跡と同定。弦巻川中流域の湧水・湿気の2025年以前（2015年）の観察時点として記録。
- **弦巻川→水窪川→神田川の旧流路読図〔読図〕**：「かつて川だった頃の弦巻川は東に進路を変え、目白通りの東にある水窪川に合流した後、神田川に合流していた」と読む（出典は明記なし）。弦巻川と水窪川の旧流路関係について独立の読図記録として追加。
- **八百招地蔵〔repo初出・観察〕**：迂回途中（ライオンズマンション隣）に**八百招地蔵（やおまねきじぞう）**。「地蔵信仰によって病気が平癒した事を受けて明治時代に建立」。弦巻川沿いの宗教的構築物の新規記録（水神・地蔵の分布把握用）。
- **鳥尾坂〔repo初出・観察〕**：流路追跡中に「鳥尾坂」という坂道を発見。弦巻川流域の坂名として対照表収録候補。
- **その他〔観察〕**：池袋西口・元池袋史跡公園の「池袋地名ゆかりの池」碑起点の読図、山手線高架のいろはかるた「弦巻」、吉祥天の幟、弦巻川支流らしき蛇行路地（未踏破）。補強にとどまる。
- **制限〔未解決〕**：昭和7年説・水窪川合流説の出典（推定・本田創系の出版物か）は本文に明記なし。
