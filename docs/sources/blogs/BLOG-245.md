# [BLOG-245] ぶろっぐねすと「指ヶ谷リベンジ（１）　鶏声ヶ窪の支流」（2011-07-22）

- **直接確認（2026-11-15、本文全文）**: 「ぶろっぐねすと」の川歩き記事（2011年7月22日）。指ヶ谷の再訪記録。
- **位置づけ〔ページ記載〕**: 指ヶ谷という谷があり、西大下水（小石川）に比して東大下水とも呼ばれている、その上流北側にあるのが鶏声ヶ窪、とする。
- **鶏声ヶ窪の支谷〔著者の観察〕**: 支谷が2本あるとする。①文京区本駒込1-20、目赤不動と医歯薬出版の間の水路敷。②文京区本駒込1-25、駐車場の敷地内に井戸があり、敷地の途切れるところから道が広くなっている地点。②は1ブロック先付近で本流に合流しているようで、延長は約100m。お地蔵様の所在も記録する。
- **支谷②の性格〔著者の観察〕**: 谷があることは分かるがとても浅く（最初の井戸の裏側で1mくらい）、南にも窪地が続いて怪しい地点もあるが傾斜が逆になってしまう、と同定の難しさを記す。
- **制限**: 個人ブログの現地観察。水路敷・井戸の由来や水路としての成立は未検証。
