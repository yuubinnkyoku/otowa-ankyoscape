# [BLOG-295] カフェ「道みち」「学習院大学の〈血洗いの池〉」〔学習院構内案内の全文言・大正創作説の明記・2001年整備の一次的記録候補〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: FC2ブログ「カフェ「道みち」」（作者＝作州浪人）の歴史探訪記事「**学習院大学の「血洗いの池」**」 http://uzo800.blog.fc2.com/blog-entry-674.html **2015年10月26日18:26投稿**。下落合の湧水を調べる中で学習院の湧水池＝血洗いの池を知り、訪問した記録。
- **学習院構内案内の全文言〔二次転記・ブログによる引用〕**: 「**＜「血洗いの池」と呼ばれる池がある。元は湧水でできた用水池で、江戸時代には灌漑に使われており、水門・水路があった。学習院の構内になった後、赤穂浪士の1人堀部武庸が「高田馬場の決闘」において叔父の仇を討った血刀をこの池で洗ったという伝説が語られるようになった。この伝説は大正時代の学習院高等科生徒による創作で全く根拠はなく、史実ではないが、いつしかこの池を「血洗いの池」と呼ぶようになった。「血洗いの池」は魚類やザリガニ・水生昆虫・水生植物等を保護するため自然のままに任せていたが、湧水の枯渇と雨水泥水流入等による水質汚濁や、護岸の崩れ等による周辺環境の悪化を改善するため、2001年に池の浚渫・護岸の整備・水質浄化装置の設置・植栽改善・電灯設置・木製八つ橋の架橋など整備工事が行われた。＞**」〔**池の起原＝湧水の用水池・江戸期灌漑利用・水門と水路の存在・名称由来伝説の創作性・2001年整備内容が一枚の案内に揃った全文言候補。堀部武庸伝説を学習院自身が「史実ではない」と明記した**案内文言としてrepoの水準の高い一次的記録候補（ただし実物の案内板の設置年代・現存の実物確認は未了）〕。
- **本文の叙述〔確認〕**: 名称の受け継ぎについて「参拝から後輩へ、物騒な名前のまま引き継がれて行った、なかなかロマンがあります」（本文では堀部安兵衛の表記、案内引用は堀部武庸＝安兵衛の諱で、両表記が同一人物を指す）＋2015年現地の観察＝「池には木橋が架かり、池畔をめぐる散策路にはかなり古い木製のベンチ」「静かで、まったく人影はありません、**水はさほどきれいではないですが、鯉が泳いでいました**」「**池の南東端付近の斜面からはちょろちょろと水が湧き出ているように見えました**」「おとめ山公園の池はまだ湧水が健在です。しかし水はそれほどきれいとは言えません」〔案内「湧水の枯渇」後も2015年時点で南東端斜面に湧き出しが観察された記録＋おとめ山公園の池（湧水健在）との対照観察〕。
- **意義〔観察〕**: ①[ORG-039](../org/ORG-039.md)（学習院広報G.LiFE・2025年2月）の血洗いの池説明板文言「**湧水でできた池。かつては灌漑に用いられた**」と接続する**2015年時点の構内案内の全文言**〔両者の照合＝案内の文言の簡略化・入れ替え等の変遷の監視座標〕。②「**元は湧水でできた用水池・江戸期灌漑・水門と水路があった**」文言＝[README](../../../README.md)の下高田村の溜池（血洗池との同定に異説があるという注意書き）の議論に対して、**学習院自身の案内が江戸期灌漑用水池説を採る**ことの明確な記録。③堀部武庸（安兵衛）伝説の「**大正時代の学習院高等科生徒による創作で全く根拠はなく、史実ではない**」という案内文言＝[README](../../../README.md)が「血洗いの池」の名称由来を堀部安兵衛伝説として紹介されたものと歴史的事実と区別する既存の方針に対し、**設置主体（学習院）側から同じ区別がなされた**文言の傍証。④2001年の浚渫・護岸整備・水質浄化装置・木製八つ橋架橋という整備内容の年次つき記録はrepo grep確認で初出〔学習院・豊島区等の公式資料での裏付けは未確認〕。⑤2015年の現地観察（南東端斜面の湧き出し・鯉の生息）は[BLOG-068](../blogs/BLOG-068.md)の血洗いの池（湧水?）観察と同じ地点の独立観察として重ねられる。
- **制限・未解決**: ①構内案内の文言はブログ経由の二次転記で、**案内板の実物確認・設置年度・執筆主体（学習院のどの部署か）は未確認**＝「二次転記」格で管理する。②「湧水の枯渇」の時期・原因の文言なし（2001年整備前に湧水が枯渇したと読める文脈だが、枯渇年代の特定に使える文言はない）。③案内文言と2015年観察（湧き出し）の対立（枯渇後も小規模湧出の残存か、枯渇記述の不正確か）は解決できないまま記録する。④下落合の湧水調査が記事のきっかけであること以上に、用水の流末・水路の去向等への言及はない。
