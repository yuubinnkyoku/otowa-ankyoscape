# [BLOG-187] 東京の階段ウォッチング「大塚 暗渠っぽい道探索編」

- **直接確認（2026-11-13、第55回。ameblo現行頁を直接取得）**: 大塚5丁目の春日通り〜坂下通り間のクネクネ道（水窪川暗渠）を歩いた2019年5月23日の記事。**大塚5丁目の水窪川暗渠（谷筋）について地元年配者への聴取を含む＝repo初出の古老証言**。
- **古老聴取〔伝聞・repo初出〕**: ①このクネクネ道は**昔川で、聴取者は子供の頃に川辺で遊んだ**。②**道になってからも地元ではこの道を「坂下通り」と呼んでいた**。③**巣鴨拘置所跡にサンシャインシティができてからは「サンシャイン通り」と「坂下通り」を呼び分けた**〔サンシャインシティ開業（1978年頃）を画期とする地元呼称の変遷聴取。暗渠の路地が坂下通りの本流と認識されていた時期があったことの生活史証言〕。
- **観察〔2019年時点〕**: クネクネ道分岐→ポポー広場入口→**井戸の残存（災害用とされる）**→開運坂下交差点付近へ出る。開運坂下交差点に「旧大塚坂下町」の由来説明板（護国寺・桂昌院に触れる）あり〔ポポー広場の井戸は[BLOG-108](BLOG-108.md)/[BLOG-172](BLOG-172.md)の観察群に2019年時点を追加。開運坂の説明板の存在は[BLOG-172](BLOG-172.md)（joshuanchin -4・開運坂前の交番）と参照〕。
- **制限〔未解決〕**: ①聴取者の年代（川遊びの時期）は記事に特定されず、**「川だった」記憶の時期を昭和前期と断定できない**（水窪川暗渠化＝1933年頃説〔BLOG-089](BLOG-089.md)・BLOG-120〕との前後関係は未確定。伝聞段階として記録）。②「旧大塚坂下町」説明板の設置主体・年次は未採録。
- **補足**: 大塚坂下町界隈の他の歩記録（東京些末観光2018・yorusannpo・とくとみぶろぐ・雨男note等）はいずれも地形・景観観察中心で新情報はなく、本記事の古老聴取が該当界隈で唯一の生活史一次証言として記録価値を持つ。
