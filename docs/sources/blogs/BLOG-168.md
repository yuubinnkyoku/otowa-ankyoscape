# [BLOG-168] 平井園「千川上水を辻る旅」

- **書誌〔確認：open_url・本文全文〕**：豊島区の園芸店「平井園」の散歩ブログ。2021年1月3日投稿。千川上水を境橋（玉川上水分水地点）から浅草まで自転車で辿る紀行。
- **明治生まれの祖父の通行記憶〔聴取：repo初出の生活史一次証言〕**：**祖父（明治生まれ）が野菜を積んだ大八車で「川沿いの道」を下り神田方面へ出荷していた**「生前に聞いた」証言。荷造りをして暗いうちに出発、土手沿いを突進し眠くて土手から落ちそうになった、と記す〔千川上水沿いの道が明治期の農産物流通路として使われた生活史の一次証言記録〕。
- **空堀の観察〔観察〕**：練馬区間は「ずーと暗渠ですが、ときおり、**空堀が顔を見せる**。ここは上石神井の踏切辺り」〔[ORG-024](../org/ORG-024.md)（濯川の空堀）・[GOV-072](../gov/GOV-072.md)と並ぶ千川上水の空堀の独立観察〕。
- **桜の根による土手強化〔筆者解釈〕**：千川沿いの土手に桜が多い理由を「桜の根が地中に根を張り、花見の人出で土手が踏み固められ増水に耐える堅固な土手ができた。機能美と景観美を兼ねた江戸の知恵」と説明〔[BLOG-101](BLOG-101.md)植桜楓碑・[BLOG-155](BLOG-155.md)昭和2年桜伐採の文脈に対する個人解釈。史実の裏付けなし〕。
- **要町の粟島神社〔観察・仮説〕**：**要町で粟島神社を偶然発見**。「この神社の近くには千川駅が示すとおり、千川上水が流れていた。これは**阿波州神社と共通する特徴**で、なにか千川上水の開削と関連があるのかもしれない」という筆者仮説を明示〔仮説段階〕。さらに浅草の花やしき門前の淡島堂（アワシマ）と並べて「**千川上水沿いの文化伝来として阿波州神社が浅草寺淡島堂のオマージュであるということは大いに考えられる話**」とする〔筆者の個人仮説として記録。粟島神社（長崎）・阿波州神社（千川駅）と谷端川・千川沿いのアワシマ系神社の分布はrepoの地名・信仰調査の仮説候補〕。
- **その他の観察〔観察・既出整合〕**：吉祥寺橋辺りの舗装されていない野道・キャベツ畑と屋敷林〔[GOV-084](../gov/GOV-084.md)の現況と整合〕、板橋高校辺りの桜並木と庚申塔、大山（ハッピーロード大山）で痕跡を見失う、分配堰碑（碑文は[BLOG-095](BLOG-095.md)と同一文言の再録）、六義園給水用沈殿池の調節バルブ〔[GOV-065](../gov/GOV-065.md)の現況〕、御獄神社（青梅街道手前）。
