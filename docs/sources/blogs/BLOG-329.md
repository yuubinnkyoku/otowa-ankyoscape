## 内容メモ

- **〔確認: 記事本文〕** **品川電線株式会社の工場**がエンガ堀「除」の支流（江古田駅北側〜小竹向原駅近くのゴルフ練習場あたりで他支流と合流）の合流地点近辺にあることの観察（1937〔昭和12〕年創業・東京時層地図の昭和戦前期（昭和3〜11年）地図には工場も水車も記載なし・戦後の高度成長期地図に初出）。
- **〔仮説（筆者考察・未確定）〕** 品川電線が水車を利用して創業した可能性について、藤倉電線（玉川用水・代々木川の水車で1888年に電線製造開始）との対照から2仮説を提示: 仮説1＝水車と無関係に立地、仮説2＝地図に載らない小規模水車があり、昭和12年創業とともに電化。**伸銅業界では大正〜昭和に水車動力から電気動力へシフトした時期であり、創業時は電気動力と考える方がよさそう〔『近代日本の伸銅業: 水車から生まれた金属加工』（産業新聞社）の斜め読みによる〕**。断定はしていない。
- **〔観察〕** エンガ堀「減」の支流の水源: 環七「武蔵野病院前」交差点の少し南・焼肉チェーン店（安楽亭）付近の窪み〔観察〕。環七の反対側から南（江古田駅方面）から入る微弱な谷があり、区画整理時の生活排水路説〔筆者推定〕。
- **〔観察〕** エンガ堀「除」の支流の水源: **江古田駅前・錦華学園東角で、学園南側自転車置場からの流れと学園北側・浅間神社裏からの流れが合流**。**浅間神社裏には湧水による池があり、これが水源だったよう**〔観察〕。池のさらに西の浅い谷（銭湯「浅間湯」）は区画整理に伴う後付け排水路と想定〔推定〕。
- **〔確認: 記事文言〕** 「乗」の支流＝「**千川通りの練馬区旭丘1-4と豊島区南長崎6-10の間から始まる**」・本田創の「石神井川水系の全体図」には西の**能満寺方面から合流する短い支流の支流**が描かれる。
- **〔観察＋二次〕** 2013年1月6日補記: 本田創からの情報で**能満寺前の道の南側にはしご式開渠が（写真に）写っていた**ことの確認。増刷時にエンガ堀地図へ追記すると明記。
