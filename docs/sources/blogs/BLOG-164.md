# [BLOG-164] 千石のそよ風「千石さかみち部～第1回 猫又坂 その①」

- **直接確認（2026-11-13、open_url・本文全文）**：文京区千石地域のコミュニティサイト「千石のそよ風」の坂道連載第1回（文・雨宮みずほ、2021年3月21日）。千川（氷川下）と猫又橋を扱う、これまでrepo未収録のサイト。
- **袖石の短歌全文〔repo初出〕**：猫又橋親柱の袖石に刻まれる市川虎之助（改修工事相談役）の歌として、**「水泳に魚掻いし千川も地下に流れて見るよしもがな」**の全文を掲載。[BLOG-079](BLOG-079.md)（袖石2基現存＋短歌）の短歌本文の初めての全文確認候補。
- **年代付き猫又橋写真の記録〔repo初出の図版情報〕**：①**大正7年、アーチ状の猫又橋造成**と完成お祝いの写真（職人と思われる半纏の男性）の存在、②**大正11年、石組みの橋の上を市電が通る**写真の存在。いずれも**『写真で綴る「文の京」』（文京区刊）**の図版。大正7年石造改築（BLOG-079）の橋上を市電が渡った1922年時点の写真記録は、千川下流部の交通・河川景観の新データポイント。
- **昭和9年暗渠化で撤去・袖石保存〔二次叙述〕**：千川の暗渠化（昭和9年＝1934年、[GOV-094](../gov/GOV-094.md)・[BLOG-077](BLOG-077.md)の1930.11〜1934.7竣工と整合）に伴い橋は撤去、袖石は坂下に保存。
- **『江戸の花名勝会』の猫又橋〔repo初出の江戸文献記録〕**：江戸の名勝を歌舞伎役者と組み合わせる『江戸の花名勝会』ね九番組に「**市の川市蔵／巣鴨氷川下猫又橋**」＝猫又橋の化け猫を南総里見八犬伝・庚申山の怪猫退治の犬村大角と市川市蔵の見立てで描く。『続江戸砂子』の赤手ぬぐいの猫又譚（既知）と並ぶ江戸期文献記録。
- **『江戸名所図会』猫狸橋の農村風景〔二次叙述〕**：百姓が鍬を担いで渡り、女性が野菜を洗う描写・三日月とススキ＝既知（[BOOK-009](../books/BOOK-009.md)系）の確認。
- **参考文献〔書誌〕**：『ぶんきょうの坂道』（文京ふるさと歴史館刊）・『写真で綴る「文の京」』（文京区刊）。千川下流域の郷土史料の所在情報。
- **第2回以降（「川崎邸のお花見と猫又橋際公衆トイレ」等）の所在**：シリーズ続編の取得が次の課題。
