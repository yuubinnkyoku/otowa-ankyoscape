## 1. 石神井川上流の調節池群の整備史と実績〔確認: Note2 (nb3dea7e174ea)・repo初出の数値群〕

- **整備の系譜と容量**: **1972（S47）年 富士見池調節池（当初）21,000㎥ → 1980（S55）年 南町調節池 12,000㎥ → 1981（S56）年 芝久保調節池 11,000㎥ → 1983（S58）年 向台調節池 81,000㎥ → 2008（H20）年 富士見池調節池改修 33,800㎥に拡張＝上流域の既設調節池計137,800㎥**〔[BLOG-301](BLOG-301.md)（mark60・2017観察）の「1980年S55=芝久保・南町、1983年S58=向台」に対し**芝久保の設置年が1年ずれる（1981=S56）**。設置年の一次確認はまだなので断定せず、両説の併置記録とする〕。
- **過去の最大貯留量（都資料由来と筆者注記）**: **平成18年9月11日**（芝久保観測所で**時間最大85ミリ**を記録）に、**芝久保調節池 5,900㎥（容量の53%）・向台調節池 16,400㎥（同20%）**がいずれも過去最大の貯留を記録（水位計設置以降のデータ: 芝久保H8.12〜・向台H15.2〜）〔計画雨量75ミリに対する既設調節池の余裕の論拠とする主張〕。
- **南町調節池は1980年の完成以降、一度も満水になったことはない**（西東京市内では1980年以降、調節池貯水量の不足を原因とする溢水被害が発生していない）。
- **西東京市内の溢水被害**: 1980年以降の石神井川上流域の溢水による浸水被害は**2005.9.4に石神井台七丁目で32棟（床下27棟・床上5棟）**（護岸未整備で湾曲した河川形状が溢水原因と筆者が推定）。練馬区から水位計データを受領した分析では、溢水水位を超えたのは2005.9.4台風時（富士見池・稲荷橋の記録）と**2014.7.24夕方の集中豪雨**の2例のみ（出典は建設局「区市町村別水害データ」と明記）〔2005年・2014年の被害・超過記録を観測単位でrepo初出〕。
- 筆者の主張: 4調節池の容量計13.7万㎥に対し、計画の30万㎥（南町調節池の25倍）は過大。**完成後は毎年約6.5億円の維持管理費が想定**される。

## 2. 流域の3区分と被害の分布〔確認: Note8 (n35fb6ff22255)・流域区分の定義がrepo初出〕

- **流域区分の定義（筆者注1）**: 練馬区**関町・石神井台・上石神井**までを「上流域」、**石神井町・下石神井〜高松**（環状七号線地下広域調節池の取水施設まで）を「中流域」、**取水施設より下流**を「下流域」〔石神井川の被害論でしばしば使われる上流/下流弁別の明示的な定義例〕。
- 1980年以降の「**外水による浸水被害は大多数が中流域から下流域**」。**過去20年間の溢水による浸水被害はほぼ全数が北区（河口付近）で発生**、上流域の外水被害の例外は2005.9.4の32棟のみ（河川形状が原因）。**流域の浸水被害の6割以上は「内水」**による〔Note7 (n5979f44bc654)・本文未取得、論点まとめとNote8経由の二次〕。河道整備済みエリアでは治水性能が大きく向上している（Note3 [n4e3bd175446e] 未取得・所在のみ）。
- **「伏見通りアンダーパス」の冠水リスク〔確認: Note12 (n2a3d14f7f425)〕**: 石神井川からの氾濫水が**「伏見通りアンダーパス（西東京東伏見トンネル）」に大量流入する事態は必ず避ける必要がある**。南町調節池から東伏見公園脇の取水施設までは距離があるため、ゲリラ豪雨・集中豪雨では河川水位が上昇して伏見通りに氾濫水が溢れるリスクがあり、都の100ミリ/時氾濫想定図（[石神井川洪水浸水想定区域図](https://www.kensetsu.metro.tokyo.lg.jp/content/000067054.pdf)）でも氾濫域に含まれる。**東伏見橋が道路勾配のピークに位置するため**、伏見通りに氾濫水が溢れると勾配を下ってアンダーパスに大量流入する〔国交省の[道路冠水注意箇所マップ](../gov/GOV-550.md)（[GOV-550](../gov/GOV-550.md)/[GOV-551](../gov/GOV-551.md)）に東伏見・下保谷トンネルが掲載されていることと正面から接続する指摘〕。
- **代替案の提案〔Note11 (nb3ba565efcf7) 本文未取得・所在のみ、Note12で概要確認〕**: 東伏見公園拡幅予定地（青梅街道北側・**都市計画決定済**・河川改修用の用地買収ほぼ完了・**約7万㎡**）の地下に深さ4.2m掘削で30万㎥を確保できる試算。利点: 掘削工法で建設費低減・武蔵野中央公園（中島飛行機武蔵野製作所近傍・**戦時中の不発弾の可能性**）でのシールド発進立坑回避・青梅街道の冠水防止（増強した道路脇排水管の調節池接続）・**東伏見公園中間立坑と連絡管トンネル（約200m・小型シールド）の省略**・南町と富士見池の中間位置・伏見通りの上流側配置（アンダーパス冠水防止）。出典図は[東伏見公園マネジメントプラン](https://www.kensetsu.metro.tokyo.lg.jp/content/000021406.pdf) P18と洪水浸水想定区域図に筆者加筆〔2024年2月に市民が同案を都に提案済みとする記述を含む〕。

## 3. B/C2ケース算定への批判［論点まとめ（ https://note.com/green_nature/n/n5a9e4700d029 ）・確認］

- **10論点のまとめ**: ①計画規模は過大（南町調節池の25倍。過去の降雨・貯水履歴からの現実的な規模検証を主張）②**事業評価のための氾濫図は洪水浸水想定区域図・自治体ハザードマップより大幅に大きく誤っているので修正すべき**（Note 4）③**河道整備と調節池整備の便益を分けて計算すべき**（無害流量=超過確率1/3・時間50ミリへの修正提案・Note 5）④**治水経済調査マニュアルで公表指定の「氾濫ブロック分割図」「流量能力図」が存在しない**（都は未作成と説明・Note 6）⑤溢水被害は北区にほぼ全数⑥内水が6割以上（建設局×下水道局の調整の必要性は第18回専門家委員会 [content/000070426.pdf](https://www.kensetsu.metro.tokyo.lg.jp/content/000070426.pdf) でも指摘）⑦地上調節池が安全・経済的⑧東伏見公園拡幅部活用⑨暫定的に越水防止柵⑩流域治水（2020年法制化）。
- **[GOV-540](../gov/GOV-540.md)（都議会速記録）・[GOV-543](../gov/GOV-543.md)（開示文書）の行政側記録に対する、同じ批判軸（B/C2ケースの妥当性・河道整備便益の二重計上議論）を持つ市民側の体系的な反対資料**。[GOV-562](../gov/GOV-562.md)（委員会投資効果資料）で都が再提示した計算も「河道整備効果と調節池整備効果が区分されていない」との批判が保たれている。

### 4.1 Note1・3（計画規模）〔確認・筆者文言〕

- **南町調節池の流入実績**: 過去の貯水履歴（都資料確認と筆者注記）で**河川の水が流入するのは年間に1.3回程度**。南町は水位が堤防の半分くらいで流入する構造。**2006年9月11日の時間雨量75ミリ（芝久保・田無観測所の平均）でも貯水量10,000㎥で「２割程度の容量が余っている」**。**44年間（南町設置から現在まで）超過確率1/10の降雨が降らない確率は単純計算で１％未満**。**貯留可能容量12,000㎥**〔南町=12,000㎥の数値自体は既出と整合〕。[BLOG-296](BLOG-296.md)の「年間の約１日を除き…」という水位運用記述を裏付ける原文文言は本ノート。
- **工事中のリスク指摘**: 地下調節池完成までの**13年間は事業効果が得られない**、**南町調節池が工事中のときには調節池の使用ができなくなり、この付近の治水レベルが低下する**〔[GOV-549](../gov/GOV-549.md)の「南町調節池は現況取水機能を維持したままの先行掘削」との食い違いは断定せず併置〕。代替として南町の路盤下透水方式・防水フェンス等の短期工期案を提示。
- **1-(3) 流域4エリア読図**: 100ミリ降雨時の洪水浸水想定区域図を、①南町調節池〜青梅街道（護岸整備予定・区画整理必要）②青梅街道〜東伏見通り（護岸整備中・用地買収済）③東伏見通り〜武蔵関公園（護岸整備済）④武蔵関公園〜武蔵関駅下流（近年中に護岸整備・西武新宿線立体交差と併走）に区分し、**護岸整備に長期間を要するエリアは南町調節池〜柳沢橋（青梅街道）に限定**。下流域の護岸が50ミリ対応済で堤防高く幅広である点・環七取水施設による上流側の流量のピークカット点から、上流地下調節池の下流域対策としての必要性を否定する論構成〔筆者の読図・推定を含む〕。

### 4.3 Note7・9・10（内水と溢水の実績・委員会文言）〔確認・筆者集計＋引用文言〕
