# [BLOG-253] 中央線あるあるPROJECT「ひとり古墳部スソアキコ×暗渠マニアックスと歩く善福寺川」（2021-03-12）〔repo初出・道角橋遺構と1974年の天保新堀用水トンネル発掘記録〕

- **書誌〔確認: 本文全文・2026-11-21取得〕**: ウェブメディア「なみじゃない、杉並！-中央線あるあるPROJECT」（[chuosen-rr.com](https://www.chuosen-rr.com/)）の「観る・歩く」記事、**2021年3月12日公開**。イラストレーターのスソアキコ氏（ひとり古墳部）と**暗渠マニアックスの高山英男氏・吉村生氏**（[GOV-490](../gov/GOV-490.md)のすぎなみ学案内記事と同一人物）による尾崎橋〜善福寺川緑地〜成宗弁財天社〜五日市街道のまち歩き記事〔中沢新一氏が善福寺川の湾曲を『アースダイバー』着想の一つとする旨の紹介で始まる〕。
- **道角橋の現存遺構〔確認・repo初出〕**: 尾崎熊野神社（尾崎神社遺跡。縄文・古墳時代の土器片出土、地名「尾崎」＝小さな崎＝舌状台地突端部由来・鎌倉時代末期に紀州熊野権現を勧請と案内板文言）の**参道脇に「道角橋」という近くにあった橋梁の一部**が置かれている。「**五日市街道付近にあったものが移設**されたようで、実際に橋が架かっていたあたりには後ほど訪問**」。記事末尾で「**同じく七曲りのひとつで、熊野神社の参道に一部保存されていた道角橋があった場所**」を訪れ、橋の架かり方を再現写真で示す〔**「道角橋」＝五日市街道「尾崎の七曲り」に架かっていた橋の遺構が神社参道に一部保存されるという現物の存在記録。橋名・橋種・保存主体は本文に詳細なし**〕。
- **昭和49年（1974）の天保新堀用水トンネル発掘〔確認・repo初出〕**: 田端神社（矢倉台南遺跡＝矢倉台の高台）のはす向かいのマンション入口で、**「ここは旧新日本製鐵（株）の社宅があった場所で、昭和49年、その工事中に用水トンネル跡が見つかった現場。資料の下にある写真が、現在は埋められてますが、その発掘されたトンネル」**（吉村氏の解説）〔**天保新堀用水の胎内堀（トンネル）が1974年の社宅建設工事で実物が発掘され写真に残された記載と、その後の埋め戻し**。[MAP-162](../maps/MAP-162.md)・[BLOG-250](BLOG-250.md)が推定した新堀通過位置（共立女子学園研修センター杉並寮付近・台地裏通過）付近の発掘証言と位置が対応する。発掘写真の史料・報告書の有無は未確認で断定しない〕。
- **田端の水車〔確認・repo初出〕**: 共立女子学園研修センター杉並寮の西側あたりに**水車が存在した**。「**水車は精米などに使われていた**…**水車はそばに小さな祠があったと記録されている**ので、ちょうど写真のこのあたりにあったのでは、と推測**できる」（吉村氏）。証拠品として**荻窪の風景を描き残した矢嶋又次氏による記憶画「田端の水車」（昭和53年=1978・『荻窪の古老 矢嶋又次が遺した「記憶画」』杉並区立郷土博物館発行の図版）**を紹介〔**[GOV-105](../gov/GOV-105.md)・[GOV-109](../gov/GOV-109.md)の矢嶋又次記憶画群（ADEAC）の参照書籍側の用例として『荻窪の古老…記憶画』刊行物の存在記録**。水車の位置は推測文言で断定しない〕。
- **成宗弁財天社の用水中継池〔確認・repo初出〕**: 成宗弁財天社へは「**用水の中継地として利用された池**があったので立ち寄る（**湧水池の名残の池は、一般の人は入れませんが、ここの隣のマンション内にあります**）」〔天保新堀用水の中継池の弁天池（[GOV-492](../gov/GOV-492.md)系の「弁天池」・破堤後の再普請の終点）に対応する現況の観察記録〕。
- **尾崎の七曲りと馬頭観音塔〔確認・repo初出候補〕**: 善福寺川の川と台地の高低差による五日市街道の旧難所「**尾崎の七曲り**」（矢嶋又次氏のスケッチあり）・そのひとつに**馬頭観音塔**（旧五日市街道沿い）〔古道の難所構造と石仏の立地記録〕。
- **記事内の関連リソース言及〔確認〕**: 桃園川暗渠については同プロジェクトの「ミュージシャン・原田郁子さんと歩く 桃園川暗渠と銭湯」・「すぎなみ道草のススメ・桃園川暗渠を歩く（高円寺編）」・すぎなみ学倶楽部の記事・吉村氏のブログ等への案内がある〔いずれもrepo未収録の別記事。桃園川のまち歩きレーンの継続課題〕。
