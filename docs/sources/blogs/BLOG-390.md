# [BLOG-390] Natrium.jp「エンガ掘と周辺の水路敷群（要町通り〜千川通り）その1・その2」

- **書誌〔確認：curl本文全文・2026-11-28取得〕**：Natrium.jp エンガ掘シリーズ第3頁とその2（index.html・index_02.html、いずれもrepo初出URL）。写真は2017年6月10日・6月19日・7月18日・2011年7月23日撮影、2024年6月1日・2025年2月26日の追記観察を含む。第3頁（その1）＝千川上水まで遡る本流側の水路敷観察、その2＝最上流部と千川上水の分水口。
- **本流の水路敷観察〔観察〕**：要町通り（向原トンネル）の南から千川通りまで、東西2本ずつ並行して流れてくる水路跡が複雑に絡み合って合流する構造〔読図〕。板橋向原郵政宿舎・向原ゴルフセンター・豊島十中跡地（現千早スポーツフィールド）周辺の現況を記録。
- **3区境の合流点〔観察・repo初出〕**：**豊島区千早四丁目・練馬区小竹町一丁目・板橋区向原一丁目の3区が交わる場所**で水路敷群が合流。写真右端の道路は西武池袋線江古田駅へ至り、写真の道も地籍図では水路敷〔観察〕。
- **庚申塔・地蔵尊群〔観察・repo初出〕**：西側水路敷のさらに西側の崖上に地蔵尊と庚申塔が並ぶ場所。**上板橋村のあちらこちらにあった江戸時代（寛文〜明和年間）の地蔵尊や庚申塔をまとめたものらしい**〔観察・伝聞〕。
- **さくら小学校〔確認・対校〕**：豊島区立さくら小学校は元大成小学校で、板橋高校南側の**千川小学校と合併して現在の名称になった**〔本文〕〔[BLOG-131](BLOG-131.md)の旧池田書店（現さくら小学校脇）観察と同じ学校の沿革側補強〕。昭和22年空中写真では東側水路敷は大成小学校開設時に失われた、西側は現存〔読図・推定〕。
- **千川上水との立体交差〔確認・repo初出〕**：東側の支流は千川通りの都立千早高校西側・豊島区立明豊中学校あたりから流れてくる。**「ねりまの文化財 第60号」（練馬区教育委員会・2004年発行）によれば、ここで千川上水と水路が立体交差していたという」**〔二次引用〕＝千川上水の谷迂回（[BLOG-111](BLOG-111.md)）とエンガ堀系支流の立体交差関係を示す初出文言〔60号自体は[BOOK-014系]でrepo既収録書誌だが、この箇所の引用は初出〕。千川通りは窪地で下り坂から上り坂に切り替わっている〔観察〕。明豊中学校から先の水路は失われて分からない〔観察〕。
- **長崎悪水吐〔確認・repo初出〕**：その2で、東長崎3号踏切北側の低い道が千川上水に階段で上っていくあたりについて、**「ここは千川上水とは立体交差（写真の水路が上水の下をくぐる）していた悪水吐（長崎悪水吐）だという」**〔伝聞〕。**千川通りの東側には悪水吐の上流部分が開渠で残っている**として2024年6月1日に改めて観察、**西武池袋線東長崎2号踏切跡から線路北側に沿って千川上水へ開渠が見える**〔観察・repo初出の2024年現況〕。
- **千川上水の分水口〔観察・対校〕**：水路敷は一気に南の千川上水へ直進し**分水口に到着**。「千川通りを東長崎方向に見て左の自転車がある場所が分水口」〔観察〕〔[BLOG-103](BLOG-103.md)（踏切北で西へ流れ出すエンガ堀）・[GOV-072](../gov/GOV-072.md)と対校。本頁は分水口を千川通り側から観察〕。
