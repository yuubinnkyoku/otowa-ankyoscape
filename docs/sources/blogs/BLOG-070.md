# [BLOG-070] 小石川から谷端川へ 水の見えない川歩き

- **直接確認（2026-11-11、open_url・本文全文）**：神田川合流点（市兵衛河岸）から小石川（千川）を遡り、大塚・板橋駅を経て粟島神社弁天池・千川駅分水口付近まで全流路を歩いた記録。投稿年は本文に明記なし（はてなブログPro、隣接記事の内容から2020年代半ばより前と推定されるが確証なし）。
- **千川改修記念碑〔確認：現地案内板の記録〕**：小石川植物園北西隣の簸川（氷川）神社の鳥居の右に**「千川改修記念碑」**が立つ。記事は「1934（昭和9）年暗渠化されて千川通りとなった記念」と要約する。〔**repo初出の記念碑**。千川＝小石川（谷端川下流部）の文京区小石川区間の暗渠化を昭和9年とする新たな主張。碑文そのものの採録は未実施で、年次は記事の読みに依存〕
- **猫又橋〔観察〕**：不忍通り（猫又坂・氷川下交差点）に**猫又橋の親柱が残されている**〔観察〕。**猫又坂解説板（文京区教育委員会、1999年3月）をほぼ全文転記**：不忍通りは大正11年（1922）頃開通、昔の坂は東側の崖の縁を通り千川（小石川）に架かる猫又橋につながっていた、『続江戸砂子』の狸・猫貍説話（猫貍が千川にはまり→狸橋→猫貍橋→猫又橋）も記す〔猫又橋・猫又坂・解説板ともrepo初出。小石川下流の旧流路（崖の縁経由）と大正期の道路付け替えを伝える〕
- **市兵衛河岸〔確認〕**：神田川合流点の解説板（文京区教育委員会、1989年3月）を全文転記（岩瀬市兵衛屋敷・砲兵工廠の荷揚場・町名は昭和39年住居表示で消滅）〔合流点の解説板全文はrepo初出〕
- **下流流路の分岐〔記事の判断〕**：えんま通り商店街の先で通りが西に折れる地点（念速寺手前）で「川は千川通りをそのまま行くと解説されているものもあるが、どちらが本当かわからない。水路は二筋、三筋に分かれていることもある」と記す〔小石川下流部の流路複数説（[BLOG-005](BLOG-005.md)等）を歩行者視点で再提示〕
- **板橋駅付近〔確認：記事の見解〕**：板橋駅ホーム下通路が川跡。「向こうから流れが手前に出てきて左へ谷端川本流、**右側へも一時期分水があって、石神井川まで続いていたらしい**」〔谷端川放水路→石神井川接続の通説の再述（放水路の年次問題（[BOOK-031](../books/BOOK-031.md)候補）には触れず）〕。駅西側の歩道（谷端川児童遊園）では道路との交差地点に「一の橋、二の橋などの橋跡が**再現**されている」と記す〔緑道の橋名標が復元・再現である可能性を示唆する観察〕
- **粟島神社〔確認〕**：由緒の「往昔 ここは清水の湧出するせい静謐の地であった。泉は溢れ川となってこの地を潤し、のちに**谷端川の源泉ともなった**」を引用し、現在の弁天池は**井戸水をくみ上げている**、昔も水量は多くなく千川上水の分水と併せて谷端川に流していた（用途は農業用水）と整理。〔BLOG-056（暗渠ハンター）の長崎分水観察と整合する水流史観〕
- **制限〔未解決〕**：暗渠化1934年（千川）は記念碑の記事要約由来で、碑文採録・該当区間の文書による工事年次確認は未実施。猫又橋親柱の現況は2026年時点で再確認されていない。
