# [BLOG-020] 2020年4月16日の音羽東縁・水窪川沿いの坂と階段の記録

- **資料〔確認〕**：小林力「[音羽の坂、鳩山邸、鼠、八幡、鷺坂など](https://tkobays.blogspot.com/2020/04/blog-post_29.html)」（**2020年4月19日公開**）。[BLOG-019](BLOG-019.md)に続く**2020年4月16日**の写真付き現地踏査で、護国寺前から神田川方向へ水窪川跡をたどる。撮影時刻・地点は記事筆者の記載に依拠する。
- **位置の具体化〔観察：筆者の現地記録〕**：**11時38分**にお茶の水女子大学西門付近、**11時40分**に**日商岩井音羽マンション**前で旧水窪川に沿う道と崖上へ向かう坂、**11時48分**に**音羽ハウスの私有地内の階段**、**11時50分**に**音羽ハウスと筑波大学附属高校の間を上がる坂**を記録している。筆者は最後の坂を**「付属坂（仮称）」**、マンション前の坂を**「日商岩井坂（仮称）」**と呼ぶ。**いずれも筆者による便宜的呼称で、正式な坂名ではない**。
- **造成年代の手掛かり〔二次読図・筆者の説明〕**：筆者は**かつて崖上が大塚兵器庫だった頃には「付属坂（仮称）」がなかった**と述べ、**1908年の東京陸軍兵器支廠の大塚移転**や1932年図にも言及する。ただし**原地図の該当道路表現・道路新設年月・兵器庫の敷地境界は今回独立に確認していない**。したがって、坂の開設時期や旧水窪川の流路変更をこの記述から断定しない。
- **比較価値と限界〔観察・推定・未解決〕**：**2020年4月時点の崖下道路、階段、坂道の接続**を、旧水窪川沿いの地形と後世の造成を区別する現地照合点として利用できる。筆者は鼠坂・八幡坂・鷺坂も踏査しているが、**坂の位置や写真だけで旧河床・護岸・暗渠管の実測線は確定できない**。旧版地図と地籍・道路台帳、学校敷地の変遷を照合する必要がある。
