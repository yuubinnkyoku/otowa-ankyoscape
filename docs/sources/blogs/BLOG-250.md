# [BLOG-250] 時空散歩「善福寺川筋の窪地・水路跡散歩 Ⅲ」①②〔repo初出・『杉並の川と橋』の引用記録を中心とする記事〕

- **書誌〔確認: live本文全文・2026-11-21取得〕**: ブログ「時空散歩」（yoyochichi）の前後篇2記事。①「**杉並　善福寺川筋の窪地・水路跡散歩 Ⅲ…荻窪の旧流路・揚堀と高野ヶ谷戸の水路跡を辿る①**」（**2016年4月15日 21:27**〔[①のURL](http://yoyochichi.sakura.ne.jp/yochiyochi/2016/04/post-322.html)〕）＝**松庵川全流路と本田東公園の下水ポンプ場**。②「…辿る**②**」（**2016年4月16日 18:09**〔[②のURL](http://yoyochichi.sakura.ne.jp/yochiyochi/2016/04/post-323.html)〕）＝**荻窪の善福寺川旧流路・揚堀と高野ヶ谷戸3支流**。いずれも**『杉並の川と橋』（杉並区立郷土博物館）の文章を大量に引用する構成**で、本ファイルは引用主体の観察記録として位置づける〔『杉並の川と橋』はrepo未収録書誌（[GOV-490](../gov/GOV-490.md)も入口として記録）＝本記事経由での『杉並の川と橋』文言の二次伝達〕。
- **①松庵川の性格〔確認・引用文言〕**: 『杉並の川と橋』の引用として「**松庵川はこの窪地・松庵窪に集まる吉祥寺方面からの下水・悪水と、甲武鉄道敷設工事にともなう工事用土採掘後の湧水を処理する水路**とのことである。**水路は大正後期に開削されたようだが、昭和初期には宅地開発の影響ですでに下水路となっていた**」〔**松庵川の開削時期（大正後期）と由来（悪水+工事用土採掘後の湧水処理）の文言**。中央線の北に**女窪**・南に**男窪**があったという鉄道敷設用土砂採取跡の記述も引用〕。高井戸第四小学校建設（昭和12年決定）時の「**大宮前下水**の汚水停滞、汚染甚だしく保健衛生上からも改修してほしい」旨の陳情文言を引用〔**松庵川＝大宮前下水の別称の文言**〕。
- **①本田東公園の下水ポンプ場〔確認・repo初出の系譜文言〕**: 「下水処理場は**昭和27年（1952）に建設が開始され、完成したのは昭和35年（1960）**。その後**昭和44年（1969）に下水処理網として善福寺幹線が完成**したため、**昭和45年（1970）には下水ポンプ場が休止**になり、その跡地は「下水ポンプ場公園」となった。**現在は合流式下水改善施設（大雨時に一時的に下水を貯める施設）を兼ねた本田東公園**」＋「この地に下水処理場を設け、**神田川に送水**していた」〔松庵川流域の神田川横断送水の下水ポンプ場の変遷。本田東の由来は小字「本田北」「本田南」〕。
- **①松庵川の上下分離〔確認・引用文言）**: 「松庵川の水路が神明通りから慈光寺方面へと南に下る辺りから、北に水路が延び、善福寺川と繋がっている。**これは洪水対策として上流部からの下水をこの中流域で分離し善福寺川に流した**とのこと。この時点で松庵川の上流部と下流部は分離され、下流部は柳窪からの水を流すのが主眼となった。**松庵川とは言いながら、全区間がつながっていたのは数十年程度**」〔松庵川の分流構造の変遷。善福寺川への合流点2箇所（松見橋の少し下流・西田端橋と神通橋の中間）と各排水口も観察〕。松庵窪の標高点は井之頭池・善福寺池・妙法寺池と同じ標高50m辺りという指摘〔「はるか昔には豊かな湧水が湧きし今に残る窪地を形成したのであろうか」との観察〕。
- **②善福寺川の河川改修年次系列〔確認・『杉並の川と橋』引用・repo初出の通史文言〕**: 「**昭和10年(1935)頃に善福寺川流出口から鉄道橋下まで、昭和13年（1938）頃に中野境から駒が坂橋下流500m付近まで、その後戦争で中断した後、昭和21年（1946）に工事再開し、堀之内本村橋下流まで、昭和25年（1950）には済美橋下まで、昭和26年（1951）には大松橋上流まで（現在の和田堀公園の東辺り）工事が行われ、昭和38年（1963）には松渓橋下まで、昭和39年（1964）から45年（1970）にかけて松渓橋上流の工事が行われ、河川が次第に一本化され、これによって田用水路などが暗渠化されていった**」〔**善福寺川の河川改修の全体的年次系列の文言**＝田端田圃（西田田圃）の旧流路・揚堀群の消滅過程の時代枠〕。
- **②荻窪団地＝旧西田町田端田圃の変遷〔確認・『杉並の川と橋』引用・repo初出の数値〕**: 「**西田町の田端田圃（当時は西田田圃とも言われていた）が住宅公団建設用地に姿を変えた。（昭和）三十三年には二十七棟の五階建て団地が建設され、三十四年には「荻窪団地」と名付けられた入居が始まった。（中略）団地ができる前の西田町の人口（昭和二十五年）は851人であったのが昭和三十七年には3099人になり。四十年には3336人となった**。これは荻窪団地だけの人口増ではなく、付近の雑木林や畑地に社宅や都営団地等が建設された結果である」〔**田端田圃＝西田田圃の双称・荻窪団地の建設年次（S33建設・S34入居）・西田町の人口851→3,099→3,336人の3点セット**。[BLOG-249](BLOG-249.md)の西田たんぼ（荻窪団地一帯の旧称）との対応が確定する文言〕。
- **②神通橋・田端神社〔確認・引用文言〕**: 「神通橋は、五日市街道の高井戸境から青梅街道へ抜ける通称「**砂川道**」に架かる橋である。この道は**鎌倉道とも言われる古道**で途中に田端神社が祀られている」＋田端神社は「**応永年間（1394年-1429年）、足利持氏と上杉禅秀が戦ったとき、品川右京の家臣・良影がこの地に定住し、北野天神を勧請したことにはじまる**。往時は北野神社とも、社の場所が「田の端」にあったため、田端天神とも呼ばれ、土地の産土神に。**田端という地名は神社の名前に由来する。境内は古墳であった**」〔神通橋の橋名由来（腰痛・足痛の霊験＝「神通」）・砂川道＝鎌倉道説・田端神社の勧請伝承と地名由来・境内古墳の各文言。品川右京・良影は何者か不詳と明記〕。
- **②善福寺川緑地の橋名群〔確認・『杉並の川と橋』引用〕**: 「善福寺川緑地公内の最西端に架けられている神通橋と最東端の大成橋との間には上流から、**なかよし橋、西園橋、西田橋、せきれい橋、児童橋、相生橋、成田上橋、成田下橋、成園橋がある**。昭和43年の「杉並区橋梁名称図」には相生橋以外その名が出てこない。相生橋は（中略）、**昭和14年の「陸測図」には橋名の表記はないが、橋記号は表示されている。これは、昭和7年、田端田圃の中に杉並高等小学校が開校された時、通学用の新道が尾崎の丘方面に開通したので、善福寺川に架橋されたものと思う**」〔**緑地内通路橋群の全一覧とS43橋梁名称図への非掲載・相生橋の通学架橋説**。作場橋（農工作用）も言及〕。
- **②1947年航空写真の天保新堀取水口と揚堀〔確認・repo初出の観察〕**: 「**実際、昭和22年（1947）の航空写真には、大谷戸橋下流（神通橋のふたつ上流に架かる）の取水口から現在の公園を南に下る水路が見える。また、揚堀もその水路に合流している。天保新堀用水として開削された水路は昭和の頃まで揚堀の一部として田畑を潤していたようである。しかし現在、その痕跡は何も、ない**」〔**破堤後の第一次水路が揚堀として昭和まで使われていたという観察**＝[GOV-492](../gov/GOV-492.md)（三ヶ村碑解説）の破堤→再普請叙述（[MAP-162](../maps/MAP-162.md)の二段階開削説）と接続する用後の水路の利用史。推量表現を保持〕。
- **②天保新堀用水メモの再掲〔確認〕**: 「天保11年（1840）9月に貫通した天保新堀用水であるが、その2カ月後には善福寺川に沿って迂回していた田端・矢倉台付近の土手が崩壊。**その原因は「カワウソ」であった、とか。実際は大雨による土手の決壊ではないだろうか**」「大谷戸橋付近から弁天池にほぼ直線に進む水路を計画。途中の矢倉台は、**550mを胎内堀りで抜く工事**を再開。天保12年（1841）のことである」「**胎内堀りは馬橋村の水盛大工である川崎銀蔵が五百分の一という極めて緩やかな勾配**を掘り進め」「この用水の完成により、馬橋・高円寺・中野の村は、**大正の頃までその地の田圃の半分ほどをこの用水で潤した**、という」〔**①天保11年9月貫通→2カ月後破堤という時系列文言、②矢倉台550m胎内掘り、③勾配1/500、④馬橋・高円寺・中野が大正まで田圃の半分を潤したという文言**。**「川崎銀蔵」表記**: 本記事の引用は「川崎銀蔵」だが、[GOV-146](../gov/GOV-146.md)（碑面）・[GOV-492](../gov/GOV-492.md)（ADEAC解説）は「**川嶋銀蔵**」＝**同人の表記の揺れ（川嶋／川崎）が両広く存する**〔碑面の正確な表記の判読は未実施で断定しない〕。善福寺高校北・須賀神社の弁天池（「関東平野迅速測図」にも大きな池）、青梅街道下4-5m・高さ1.3m・幅1.6mの地下トンネル、用水開削以前から「新堀用水」と呼ばれる自然の水路が桃園川に下る窪地に流れていた点も記録〕。
- **②高野ヶ谷戸3支流（仮称）の流路〔確認・観察〕**: 本記事が「**高野ヶ谷戸西側支流（仮称）・中央支線（仮称）・東側支線（仮称）**」の3水路として実走した流路: 西側支流＝コンクリート蓋暗渠が北進→消滅。中央支線＝大田黒公園北の民家間の細路（旧石垣）→**中央図書館脇の公園の池**の西→駐車場→「読書の森公園」沿い→**中央図書館北の車道から北上し窪地を離れる→青梅街道・天沼陸橋付近**〔この越境部について「桃園川を養水した千川上水の六ヶ村分水から水を取り入れたのかとも思えてきた」＝**窪地を離れた北方延伸部＝六ヶ村分水系の流路候補**の観察〕。東側支線＝大田黒公園北側の道→車止めの細路→源流点付近〔[BLOG-249](BLOG-249.md)（tokyoriver）の大径マンホール合流点・東縁支流と対照される高野ヶ谷戸の支流群の詳細な流路観察〕。
- **②その他の地名・地形〔確認・観察〕**: ①**柳窪**＝標高45mラインの袋状窪地（五日市街道柳窪交差点の東_・西田小学校の北・松渓公園を北端とし善福寺川に平行する）〔repo初出の地形記述〕。②**大ヶ谷戸**＝「今昔マップ首都1927-1939」の西田小学校北の窪地表記・「西田町大ヶ谷戸遺跡」（縄文中期住居跡3基・松渓公園=原名「松渓遺跡公園」）〔repo初出の小字〕。③**矢倉台**＝『新編武蔵風土記稿』の「伝云鎌倉時代より陣屋櫓のありしを…**或は云成宗が柵迹なりと**…此辺りに**鎌倉街道の迹ありと云う**、但し此処より**長新田道**というあり、西五日市檜原街道なり」（小田原北条氏の家臣大橋知行（成宗）の館跡とも言われる）。④**成宗・田端・東田・西田の地名構成**＝「成宗の東側の田端を東田、西側を西田とした」＋昭和44年（1969）新住居表示での成田東・成田西成立〔repo初出の説明文言〕。⑤**荻外荘**＝入沢達吉から近衛文麿への譲渡・有馬頼寧命名。⑥**関東平野迅速測図**に須賀神社辺りの弁天池の表示。⑦**矢倉台の天保新堀用水の胎内掘り出現口**＝成田西4丁目・共立女子学園研修センター杉並寮の辺り（痕跡は見当たらない）。
