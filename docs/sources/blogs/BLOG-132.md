# [BLOG-132] 谷端川上流〜板橋駅の暗渠年次に関する独立の読図主張

- **資料〔確認：Wayback保存版本文〕**：地図子（chizuchizuko）「谷端川・小石川を歩く －1 水源からJR板橋駅まで－」（**2022年11月27日公開**。直接open不可のため[Wayback 20221127スナップショット](https://web.archive.org/web/20221127120122/https://chizuchizuko.hatenablog.com/entry/yabatagawakoishikawa1)で本文確認）。著者は多摩川流域の川歩きを主要題材とする地理系ブログ主（[BLOG-120]と同一著者）。
- **暗渠化年次の読図主張〔推定：カシミール3D古地図依存の個人読図〕**：**「谷端川」と呼ばれる豊島区・板橋区ゾーンは「1964年までに暗渠化」**（カシミール3Dの1960年代地図に水色の線が残る）、**「小石川（または氷川）」と呼ばれる文京区ゾーンは「1934年頃に暗渠化」**（これにより現在は水色の線が消え難易度が高い）と主張。〔推定：筆者の地図読図。一次史料の裏付けなし〕
- **年次の位置づけ〔解釈〕**：文京区側「1934年頃」は[BLOG-077]の千川下流暗渠（昭和5年着手→昭和9年竣工・総延長3,272m）と近似し、[BLOG-119]の「昭和15年地図で氷川下町等に開渠残存」との関係は要検証。**豊島区・板橋区側「1964年まで」はrepoで谷端川本体の暗渠化終了年を明示する初めての個人読図主張**（区境の谷端川上幹線等の事業年次とは別の、地図上の消線時期観察）。断定資料ではなく、読図上の消線年代記録として位置づける。
- **水源の観察〔観察〕**：粟島神社の弁天池は「水源と呼ぶには少し頼りない大きさの池。今は宅地化でさらに小さくなっているが、もともとあまり水は多くなかったようで**千川用水から水をもらって流していた**」＝[GOV-005]（長崎村外三村分水→谷端川）と整合する一般向け記述。椎名町駅南側の小道・要町の高所ドア・谷端川緑道の暗渠遊具・JR板橋駅のトンネル（**川が駅の下をくぐる**）などの観察写真。
