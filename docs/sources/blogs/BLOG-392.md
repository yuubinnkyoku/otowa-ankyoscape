# [BLOG-392] Natrium.jp「妙正寺川・井草川の水路敷群（井草川上流とその支流）その1〜その3」

- **書誌〔確認：curl本文全文・2026-11-28取得〕**：Natrium.jp 井草川シリーズ第2群（igusa02のindex.html・index_02.html・index_03.htmlの3頁・repo初出URL群）。第380回で本文未確認だった残頁の確認完了。写真は2011年7月23日撮影ほか。
- **井草川上流の導水二重系〔伝聞・repo初出〕**：井草川の上流端は青梅街道近くの切通し公園とされるが、**現在の都立杉並工業高校あたりでは流路が複雑に分かれている上、「千川上水と、関町一丁目近くで別れた六ヶ村分水（井草分水）の双方から導水していた」**という〔伝聞〕。**いくつもの流路が確認できる**〔観察〕〔井草川が千川上水と六ヶ村分水の双方から導水していたとする文言はrepo grep初出。[GOV-067](../gov/GOV-067.md)（六か村用水）・[BLOG-254](BLOG-254.md)（八幡宮〜六ヶ村用水の分水嶺）と対校する井草川側の新観察〕。
- **千川上水からの分水支流〔観察〕**：車止めを挟んだ向こうに水路敷が伸びる交差点が**千川上水からの分水を引いていた支流との合流点**〔観察〕。その3では「千川上水の分水は合流点から幅広い道で北上したあと突き当たって終わってしまい、千川上水まではたどり着けなかった」〔観察〕。
- **分水口の現況〔観察〕**：**「千川上水まで行ってみた。西武新宿線の上石神井車両基地あたりに分水口があったはずだが、痕跡は残っていないようだ」**〔観察・repo初出の現況〕。
- **井草八幡宮前庚申塔〔観察・repo初出候補〕**：井草八幡宮前交差点の向かい側に**元文5年（1740年）庚申の年の銘がある青面金剛庚申塔**〔観察〕〔[BLOG-254](BLOG-254.md)の井草八幡宮＝善福寺川左岸水路群の源と対照し、千川上水側（上石神井）の庚申塔資料として追加〕。
