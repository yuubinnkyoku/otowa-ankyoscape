# [BLOG-184] 水窪川　－分身が本体を駆逐しつつある街－

- **直接確認（2026-11-13、第53回。Wayback 2026-10-25 id_付きURLで本文全文取得）**: wanjin水窪川連載2013年9月の2本目（投稿2013-09-30、2014-01-13一部修正）。東池袋四丁目〜文京区大塚・音羽谷〜神田川合流までの中下流を歩いた記事。
- **「双子の川」呼称〔repo初出文言〕**: 音羽谷付近で**「弦巻川を音羽谷の西側に流して、双子の川と呼んだり、両方で鼠ヶ谷下水（ねずみがやつげすい）と呼んだりされていました」**と記す〔弦巻川と水窪川を対にする「双子の川」の呼称はrepo初出。鼠ヶ谷下水＝両川の包括呼称はBLOG-002（Natrium）で既出だが、本記事は2013年時点の独立二次記録として裏付けを追加する。「下水」を農業用水の意に用いる説明もBLOG-002と整合〕。ここでの「下水」の語義説明（飲用はしないが洗濯・農作物洗浄に利用）は芋洗橋の橋名由来の文脈提示〔「東青柳下水」の別称記述もBLOG-002既出文言の一致〕。
- **護持院から池の余水を水窪川へ〔観察/推定・2013年記録〕**: 不忍通りと交差する付近には**芋洗橋（または地震橋）**が架かり、**「護国寺（正確には護持院）側から池の余水を水窪川に流していた」**そうで、おそらく不忍通りの北側で水窪川に流れ込んでいたものと推定、と記す〔BLOG-123（2025年髙山実地観察: 水窪川は池に流入せず塀沿いカルバートで抜ける）と食い違う記述。両者の観察年次・観察地点の差を考慮し、どちらか一方では断定しない。護国寺池→水窪川への余水流入経路の可否は要現地・文献確認〕。
- **芋洗橋の寸法〔二次記録〕**: 長さ九尺程度・幅二間半（『御府内備考』より）〔repoのGAZ-013で『御府内備考』巻之五十東青柳町の「地震橋」記述（石橋・長九尺程・幅二間半）を直接確認済み。本記事は同じ寸法に言及する2013年時点の独立二次資料として整合記録〕。
- **『大塚』地名由来〔repo初出文言〕**: 『改撰江戸志』に基づき、**小石川大塚坂下町の小普請神尾豊後守組・森川鉾太郎屋敷地内に高さ五尺ほどの塚（同じく五尺ほどの朽ちた榎があった）があり大塚の由来、塚脇に稲荷（「大塚稲荷」）が祀られていた**、と記す〔森川鉾太郎・大塚稲荷・塚の寸法はrepo初出。屋敷地は現在の茗荷谷駅西南方約150mとし、塚も稲荷も現存せず、古墳墳丘の可能性が高いという筆者推定を伴う。豊島区の北大塚・南大塚は明治36年山手線大塚駅（本来の文京区の大塚の「分身」）由来とする議論も記録〕。
- **今宮神社前の橋遺構〔観察: 2013年〕**: 音羽谷下流の今宮神社前に「橋の遺構と思われるもの」を観察〔BLOG-089の今宮橋川幅1.5m（らんまる観察）・第50回の今宮神社系記録の前史として、2013年時点での現況観察記録〕。その下流で**巻石通りで神田上水の伏越を越えて神田川へ**〔伏越の存在は既出。本記事は「巻石」の名が石組み水道管に由来するとする文言を含む（巻石通り名由来はrepo既出の可能性があるため要照合）〕。
- **ミョウガ畑の変遷〔観察: 2013年〕**: 富士山広場の水窪川の碑の斜め先の「自称茗荷畑」について、**表示看板が消失し荒れ放題になっていた**と記す〔BLOG-037（ミョウガ畑〔伝聞〕）の現況変化の2013〜14年時点データ。看板消失の時期特定は本文からは不能〕。
- **都電東池袋四丁目停留所の系譜**: かつて日出町二丁目電停、さらに昔は**王子電気軌道大塚線の水久保電停**〔BLOG-018・LOST-005の水久保停留場系譜と整合する整理〕。補助81号線（明治通りバイパス）計画による都電沿いのフェンス化と「水窪川関連物の喪失」への懸念も記録〔2013年時点の整備状況〕。
- **お茶の水女子大学崖下の湧水〔聴取・2013年時点〕**: 「ほんのちょっと前には崖から湧水が見られた」が現在は量がかなり減少、以前は湧水を集めて金魚やメダカを飼う家もあった〔音羽谷崖下湧水の減衰を示す2013年時点の聴取記録。湧水減衰仮説の時系列データポイント〕。
- **音羽谷＝人工流路説〔仮説〕**: 「音羽谷のあたりは、自然な流路ではなく、人工的に流れを形作ったものです」との筆者推定〔BLOG-089（1681年護国寺門前町両川整備伝承）と同方向の独立推定。仮説として記録し断定しない〕。
