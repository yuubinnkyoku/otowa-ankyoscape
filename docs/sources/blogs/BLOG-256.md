# [BLOG-256] Natrium.jp「桃園川の水路敷群（新堀用水）その1・その2」〔repo初出・[BLOG-254](BLOG-254.md)が次回掃引対象に指摘した最重要頁。天保新堀用水レーン（[GOV-146](../gov/GOV-146.md)・[BLOG-250](BLOG-250.md)・[BLOG-252](BLOG-252.md)・[BLOG-253](BLOG-253.md)）の民間側フル掃引〕

- **書誌〔確認: 本文全文2頁・2026-11-22取得〕**: Natrium.jp「水路敷を行く」の桃園川系カテゴリ内頁「桃園川の水路敷群（新堀用水）その1」・「その2」。其1の写真は2020/8/10・8/23・12/19、其2は2020/12/6・12/12・12/26・2021/4/21・5/16・5/22撮影、一部2025/3/26・4/27撮影の追記写真を含む〔[BLOG-001](BLOG-001.md)・[BLOG-166](BLOG-166.md)・[BLOG-254](BLOG-254.md)と同じNatrium.jpの観察群〕。
- **新堀用水の全体構造〔確認: 『杉並の川と橋』（[BOOK-229](../books/BOOK-229.md)）の孫引き文言〕**: 「**新堀用水は、善福寺川を現在の天神橋公園がある水路敷の北端（広場堰）で分け、善福寺川が大きく南に迂回している田端神社の南側を回って成宗須賀神社の西側、成宗五色弁財天にあった弁天池まで水を運び、そこでいったん溜めて青梅街道の北へ向かって流していた**」〔**広場堰＝善福寺川からの分岐点が大谷戸橋付近の水門だったという位置特定文言**（「善福寺川との分岐点にあったのは天神橋ではなく大谷戸橋。かつてはこの辺りに広場堰という水門があり、善福寺川の豊富な水を新堀用水に向かって分けていた」）＝[BLOG-250](BLOG-250.md)の1947年航空写真判読（大谷戸橋下流の取水口）と対照可能な位置観察〕。
- **石橋用水〔確認・repo初出候補〕**: 「**『杉並の川と橋』では今回たどる中央のルートを新堀用水ができる前からあった石橋用水を転用したものとしており**」「**青梅街道の向こう側にある湧水を水源とした用水路（石橋用水）が桃園川に向かって流れていた**という。だとってきた水路敷はそのまま新堀用水に転用されたらしい」＋「**天保時代に新たに作られた東側のルートは東橋のひとつ下流側にある八反目上橋から上流へ向かうが、水路敷は残っておらず通れる道路としても途切れ途切れ**」〔新堀用水に先行する既存用水としての石橋用水の名・中央ルート=石橋用水転用説・複数ルート（西側・中央・東側）の存在文言。BLOG-252の第一期/第二期水路判別仮説と対照する新たな系譜情報〕。
- **トンネルの変遷〔確認・repo初出の中核文言〕**: 「**当初は善福寺川緑地から成宗城址（現在の共立女子大学研修センター杉並寮）あたりまでと、弁天池東側から青梅街道の下をすずらん通りまで2箇所の胎内堀りでトンネルを通したが、南側はカワウソと長雨の被害があって水漏れするため、新たに広場堰から東へ直行する新しいトンネルを掘った**という」＋「天保新堀用水は胎内掘りと呼ばれる素掘り（手掘り）のトンネルでこのあたり（すずらん通り側）に出てきていたという。トンネルは埋め戻されてしまったため現在では確認することができないらしい」〔**当初2トンネル→新たな東へ直行トンネルという変遷の初出文言**。カワウソ（獺）被害＋長雨による水漏れという廃止理由の記録。BLOG-253（1974年発掘写真）・GOV-146系の碑文資料と対照〕。
- **年次の揺れ〔確認・両論併記必須〕**: 其1冒頭は「**天保11年（1840年）から天保12年（1841年）にかけて作られた**」・同じ頁末尾では「**これだけの大工事を天保10年（1839年）と天保11年（1840年）のわずか2年で完成させた**」〔同一頁内で年次表記が揺れる＝孫引き先の『杉並の川と橋』の段階で年次が確定していない可能性。[GOV-146](../gov/GOV-146.md)・[GOV-492](../gov/GOV-492.md)系の三ヶ村碑碑面「正月」説（天保12年正月完成）とも異なるため、完成年は**天保10〜12年の幅で両論併記**とする〕。
- **弁天池〔確認〕**: 成宗五色弁財天「**もともと湧き水があり、新堀用水を通す際に用水の中継地として勢いをつけるために拡張した池**が使われた。**掘り出した土で富士塚を作ったというが、現存していない**」〔[BLOG-253](BLOG-253.md)（成宗弁財天社の用水中継池・隣接マンション内に湧水池の名残）と同じ池の湧水・人工拡張・富士塚の細部。湧水＋人工拡張の重層構造の文言〕。
- **馬橋庚申堂と石塔群〔確認〕**: 馬橋庚申堂は「**一番古いもので享保元年（1716年）造立**」＝新堀用水より古い。庚申堂向かいに「**此地者約三百年前庚申奉祭之遺跡也**」と彫られた石碑（元はこちらに庚申塔が立っていた可能性の推測）。五日市街道旧道の石塔群＝元禄11年（1698年）地蔵尊・宝暦10年（1760年）馬頭観音・宝暦3年（1753年）地蔵尊〔新堀用水と善福寺川の間の「戻し水路」＝「青梅街道に向かうトンネルへ流れていた水路の水を善福寺川へ戻していたらしい水路敷」（杉並土木事務所南側・白幡児童遊園・東田中学校南脇・地籍図上の水路敷）の観察と併せ、用水系の末端構造の補助史料〕。
- **須賀神社・成宗城〔確認〕**: 成宗須賀神社は「言い伝えでは**天慶4年（941年）**、平将門の乱を鎮圧したときに創建」。成宗城址（共立女子大学研修センター杉並寮の丘）は「**いわゆる居館（やかた）で、城主は大橋氏とも中野氏とも言われていてはっきりしない**」〔不確定文言の明記。最初のトンネルはこのあたりで水路敷に合流していたらしい〕。
- **参考文献の明記〔確認・repo初出候補の書誌〕**: 頁末の参考資料として「**武蔵国多摩郡馬橋村史（武蔵国多摩郡馬橋村史編纂委員会、1969）**」が『杉並の川と橋』（[BOOK-229](../books/BOOK-229.md)）とともに挙げられている〔『馬橋村史』1969の書誌存在がrepoで初めて確認された。BOOK-229とともに天保新堀用水の一次確認候補〕。
