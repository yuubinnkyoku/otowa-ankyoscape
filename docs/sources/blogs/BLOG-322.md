## 内容メモ

- **〔観察〕** 沢蔵司稲荷（文京区小石川3丁目・善光寺坂上）の「おあな（御穴）」霊窟: 四方を囲まれた完璧なスリバチ状窪地で、**社の脇に枯れた池跡2か所**。窪地の淵を巡らされた水路があり、底に水が溜まる前に淵から外へ排水する構造〔著者の観察〕。季節によって水を湛えたかは本文では確認できず〔未解決〕。
- **〔観察〕 同稲荷の石碑の後ろに「ふじばし」と平仮名で刻まれた橋の親柱が現存**。著者はこれを**小石川（谷端川）の南大塚に架かっていた「藤橋」の遺構**とする〔記事の推定〕。**藤橋遺構の現存地点の記録はrepo初出**。
- **〔二次転記: 東京23区辞典「権太夫稲荷」項〕** 南大塚1丁目60番・大塚三業地方面へ行く道の山手線土手際に建つ稲荷。幕末の地図では駅北口側に藤橋という橋がありその際に小さな稲荷社があり、**線路敷設の盛土時に現在地へ移した**とする。
- **〔二次転記: 同稲荷住職ブログ〕** 藤橋親柱がこの地にある経緯は不明としつつ、大塚方面を担当した火消「六番組」に関係がありそうとする〔伝聞〕。著者は権太夫稲荷の合祀に伴い親柱も持ち込まれた可能性を推定〔仮説〕。
