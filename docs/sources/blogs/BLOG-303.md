- **8.22豪雨時の取水数値〔確認・repo初出・第四建設事務所取材による〕**: 「今回の豪雨で、**城北中央公園調節池には約20分という短時間で約6,000トンの水が流れ込んだ**」「**一期調節池の貯留量は約9万立方メートルで、今回流れ込んだ量はその約7％にあたる**」＝**2026年8月22日豪雨での取水＝約6,000トン（≒約6,000m³）を約20分で受け止めたという実績値〔トン表記のまま転記〕**。
- **取水回数・年次の裏付け〔確認・GOV-512/BLOG-288との整合〕**: 「**昨年7月10日の豪雨では約500立方メートルを取水。東京都建設局 第四建設事務所によると、昨年の取水はこの1回で、今回が今年初めての取水だった**とのこと」＝**①2025年（令和7年）7月10日豪雨時の取水＝約500m³・1回のみ＝[GOV-512](../gov/GOV-512.md)（都公式・城北中央公園調節池500㎥・貯留率1%）と完全一致、②2026年の取水は8月22日が初（2026年8月末時点）＝GOV-512（2025年9月公開）以降の実績系の続柄としてrepo初出の年次観察**〔「昨年の約500立方メートルに対して、今回は約6,000トン」という約12倍の年度間比較も本文〕。
- **整備状況〔確認・既知数値の再確認〕**: 「**一期調節池の本体工事が完成したのは2025年6月**」「なお、現在供用している一期調節池の貯留量は約9万立方メートルですが、さらに整備が進められていて、**全体が完成すると約25万立方メートル** の水を貯められる計画みたい」＝[BLOG-288](BLOG-288.md)（一期9万㎥・2025年6月取水開始・全体25万㎥）と整合〔本記事側でも2025年6月＝一期完成年と再確認〕。
