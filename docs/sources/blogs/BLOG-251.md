# [BLOG-251] 時空散歩「小沢川跡散歩」（2016-02-21）〔repo初出・小沢川の流路・水源・六ヶ村分水との接続の現地観察記録〕

- **書誌〔確認: 本文全文・2026-11-21取得〕**: ブログ「時空散歩」（yoyochichi）の記事、投稿日時**2016年2月21日 13:02**。作者が池袋行きの途中に和田1丁目の台地で出合った東西に走る水路跡を辿った記録で、**善福寺川筋の窪地・水路跡散歩Ⅰ〜Ⅳ（[BLOG-250](BLOG-250.md)・[BLOG-252](BLOG-252.md)）の直接の前段**（小沢川の発見がシリーズの発端と本文で述べる）。
- **小沢川の全流路〔確認・Web情報の引用として本文に明記〕**: 小沢川は「**蚕糸の森公園から環七を隔てた西にある真盛寺にある新鏡ヶ池を源流とし、青梅街道の通る台地と善福寺川の北にある和田の台地の間の沢を流れ、善福寺川が神田川に合流した富士見橋脇で神田川に注ぐ2キロほどの川**」〔**真盛寺の新鏡ヶ池＝水源説・約2kmの流路・神田川富士見橋脇の合流点の3点セットはrepo初出**。[GOV-490](../gov/GOV-490.md)の「廃止された井草川・桃園川・小沢川」列挙文言（『杉並の通称地名』経由）に対して流路を具体化する記録〕。和田2丁目交差点の北の下り・道の下り切ったところの東西の細路が流路跡として辿られている。
- **新鏡ヶ池と木遣塚〔確認・現地案内板文言の引用〕**: 真盛寺（杉並区和泉）境内右手の「**新鏡ヶ池**」について「**旧高円寺村字中小沢の地名の由来となった古池で、中島に弁財天を祀り放生池となっています**。**門前の木遣塚は元禄年間、江戸城普請のときうたい始めた木遣節を後世に伝えるために建てたもので、毎年五月三日に鳶職和泉会の有志によってうたい継がれています**」〔**小沢川の川名が地名（字中小沢）由来であることの案内板文言＋「小さな沢といった地形に由来するものではあろう」（本文の推察）**。「鳶職和泉会」の名は旧和泉村側の職能組織の継承の記録候補〕。
- **支流の窪地〔確認・repo初出候補〕**: 高南中学校正面口〜蚕糸の森公園間の草地に行き止まりの水路跡があり、「**この水路跡は蛇窪とも清水窪とも称された窪地から流れ、小沢川に注ぐ支流**のようであった」〔**蛇窪・清水窪＝小沢川支流の窪地名**。蚕糸の森公園の池（蚕糸試験所跡地の公園造成池の可能性。明治の関東平野迅速地図に池の記載なし＝本文観察）〕。
- **千川上水六ヶ村分水からの養水〔確認・repo初出の接続文言〕**: 「**千川上水・六ヶ村分水は、練馬区関町で本流から分かれ、青梅街道に沿って台地上を下り、上井草・下井草・下荻窪・天沼・阿佐ヶ谷の6つの村に水を送る用水路。乏しい水量の桃園川への養水の役割を担った。**」に続けて「**高円寺まで下り、小沢川の養水ともなっていたことは今回初めて知った。もっとも、杉並の区立郷土博物館で買い求めた『杉並の川と橋』（[BOOK-229](../books/BOOK-229.md)）には、小沢川への養水の記述はなかった**」〔**六ヶ村分水の給水先として桃園川（既知）に加え小沢川があったとする主張の一次観察記録**。『杉並の川と橋』に記述はなく、当該文言の出典（当該サイト・地元資料か）は本文上で特定できず孫引き元の確認は未実施・断定しない〕。
- **養水・分水箇所の位置〔確認・現地観察〕**: 「**残るは千川上水の六ヶ村分水からの養水・分水口のあった、青梅街道と五日市街道の分岐点辺り。ついでのことでもあるので、養水・分水口に足をのばすことにする」**…「**六ヶ村分水の小沢川への養水の分水箇所を確認**」〔**六ヶ村分水の小沢川分水口＝青梅街道・五日市街道分岐点付近の観察**。[GOV-490](../gov/GOV-490.md)の「取水口6か所のうち4か所は四面道交差点付近」説とは位置が異なるが、取水口（千川上水から六ヶ村分水への取水）と分水口（六ヶ村分水から各用水への分水）の区別を含む異なる概念の可能性もあり、両論併記とする〕。
- **中野坂上延伸説〔確認〕**: 「**関町で千川上水本流から分かれ青梅街道を下った六ヶ村分水は、この地から更に東へと中野坂上まで下ったとも言われる（前述の如く『杉並の川と橋』にはその記述はない）**」〔**六ヶ村分水の末端の中野坂上説**。『杉並の川と橋』非記載であることを書き手自身が明記〕。
- **地形観察〔確認〕**: 帰宅後にカシミール3Dの数値地図5mメッシュ（標高）で小沢川の川筋が「**窪地として表示**」され、**清水窪・蛇窪の窪地もはっきり判別**できたとの記録〔数値地形データ上の小沢川谷の確認観察〕。
