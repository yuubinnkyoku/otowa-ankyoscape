# [BLOG-232] ラジエイト「環状七号線地下広域調節池〈石神井川区間〉（2025年5月）」〔repo初出・第98回〕

- **書誌〔確認: open_urlで本文全文取得・2026-11-15〕**: 建設業界メディア「**ラジエイト**」の現場取材記事「[環状七号線地下広域調節池〈石神井川区間〉（2025年5月）](https://radiate.jp/20250523/kanzyou7_2025-05/)」（**2025年5月23日**公開）。**同サイトは「環状七号線地下広域調節池」の工事を2022年4月（[2022-04-22回](https://radiate.jp/20220422/kanzyou7_2022-04/)）から時系列で定期取材するシリーズ**を持ち、本記事は2025年5月22日の現場取材に基づく。位置図・掘削進捗図の出所を東京都第三建設事務所と明記する。
- **立坑の固有名称と位置〔確認: 本文〕**: ①**発進たて坑=「妙正寺川たて坑」（中野区野方五丁目）**——施工ヤードとして整備し、**妙正寺川の取水施設も併設**。②**到達たて坑=「石神井川たて坑」（練馬区高松三丁目）**。③**中間たて坑=練馬区豊玉中3丁目**（完成後のトンネル維持・管理用。シールドトンネルとの連結管は**開放型シールド工法**で整備）〔[GOV-156](../gov/GOV-156.md)（kanzyou7.com）の「発進立坑、中野区野方」「中間立坑、練馬区豊玉」と対応し、**立坑が取水する河川名（妙正寺川・石神井川）を固有名称として明記する**数少ない記述〕。
- **機能の説明〔確認: 本文〕**: 環七地下には神田川・環七七号線地下調節池、目白通り地下には白子川地下調節池が既に稼働。石神井川区間で接続し**全長13.1km・貯留容量143万m³**の国内最大規模の地下調節池となる予定。**75mm/hの降雨による洪水を貯留可能**で、**白子川・石神井川・妙正寺川・善福寺川・神田川の5河川を連結**して流域間で貯留水を相互融通、**時間100mmの集中豪雨にも対応**〔[GOV-153](../gov/GOV-153.md)（地下河川構想）・[GOV-154](../gov/GOV-154.md)（豪雨対策基本方針）の「石神井川区間」の実事業段階の記述〕。
- **シールド機・工法の諸元〔確認: 本文〕**: **泥水式シールド工法**。シールド機は**直径13.45m・長さ12.91m・重量約2,500t**。**セグメント9枚で1リング**を構成。**土かぶり32〜40m**の深さで中野区野方五丁目から練馬区高松三丁目まで約5.4kmを掘削〔[GOV-156](../gov/GOV-156.md)（kanzyou7.com）の中間立坑「深さ52.4m」（底深度）と土かぶり32〜40m（トンネル覆工上端）は別の値〕。
- **工事時点の進捗〔確認: 本文〕**: **2020年2月にシールドマシン発進式典**（関係者の寄せ書きセグメントが組み込まれたまま現存）の記述。**2025年5月22日時点で掘削完了区間は1km超**、作業員がトンネル内を自転車で移動する様子、地下ストックヤードにセグメントを保管する工法の説明。トンネルは環状七号線に沿って一直線に続く。
- **repo上の意義〔観察〕**: ①**発進・到達たて坑の名称が「妙正寺川」「石神井川」であること**は、石神井川区間の両端が**神田川水系（妙正寺川は神田川支流＝水窪川・弦巻川の合流先の水系）と石神井川の取水・放流点である**ことを示す〔観察: 取水施設の併設記述に基づく。取水運用の実態は未確認〕。②**中間たて坑が練馬区豊玉中3丁目**と町名レベルで特定〔GOV-156（kanzyou7.com）は「練馬区豊玉」まで〕。③2022年4月からの定期取材シリーズは**建設過程の視覚記録の群**であり、完工後の記録として価値がある〔シリーズ全数の取得は未実施〕。
