# [BLOG-066] 上池袋～北大塚・巣鴨学園支流暗渠の観察

- **書誌**: 水徒然（onnbubatta）、2016年3月末（本文に3月末閉店の貼紙言及。投稿日未確認）。https://yatolove.exblog.jp/18908041/ 。2026-11-11全文取得確認。
- **〔観察〕** 北池袋駅西側から谷端川方面へ入る暗渠らしい細道を谷頭（山手線線路沿い）まで遡上した記録。筆者は事後調査で**Lotus（髙山）の「瓢箪池支流」に相当する流れか**としているが、未確認の同定〔[BLOG-061](BLOG-061.md)の瓢箪池支流（上池袋1-3）との照合課題。巣鴨学園の北側という位置から独自に「巣鴨学園支流」と呼称〕。
- **〔観察・付記〕** **小字「雲雀ヶ谷戸」と「下り谷（さがりだに）」の範囲を示した自作図**を掲載。コメント欄の照会に基づき、両字の接する場所は**池袋本町4-3と池袋本町1-38の地点（丁界・中小学校が向かい合う道の一本東）**〔雲雀ヶ谷戸（[BLOG-054](BLOG-054.md)初出）・下り谷（BLOG-059〜060の下り谷支流）の字界の具体化＝repo初出〕。
- **〔確認〕** 筆者の暗渠散策の座標源として**「明治44年逓信局の地図」に依存している**と明記〔repo未収録の読図用図。都立中央図書館目録に「東京市十五区番地界入地図（通称・郵便地図）」系の所蔵があり、正式書誌の同定が課題〕。
- **〔観察〕** その他: 北池袋の踏切名「雲雀が谷」・「ひばりがや地下道」の表記、お茶あがれ地蔵（二股）、石垣の曲線、補助82号線（旧ガン研通り）工事までの暫定公園、**「水窪川流域にも補助81号線計画が進捗」**の言及、栄橋（谷端川緑道の橋）の写真。
- **〔未解決〕** 巣鴨学園支流と瓢箪池支流の関係。明治44年逓信局図の該当図幅の特定。
