# [BLOG-204] 谷端川源泉部〜椎名町駅の流路読図（entry-236）

- **直接確認（2026-11-13、第64回・FC2直fetch）**。谷端川本流の最初の流路紹介回。
- **源泉部の読図〔観察：2018年〕**：弁天池から南へ300m余り、**岩手県学生会館の南角で分岐する流れ**があり、周り回って下流部の谷端川に至る〔分流の同定は本文で解決していない。境井田方面の分流候補として記録〕。千早フラワー公園（**大江戸線試作車両（鉄輪式リニアモーターカー）の静態保存**がある公園）を過ぎ、一ブロック先の右岸に**長崎公園（長崎3丁目）からの流れが合流**〔BLOG-157の長崎支流と同一〕。
- **椎名町駅前後〔観察〕**：椎名町サンロード商店街を流れ、**椎名町駅の東側にある踏切**を通過、そこで**南長崎三丁目からの流れが合流**、踏切後左に大きく曲がる。山手通り手前で緑色舗装、山手通りを越えると流路は道路の右側へ。**旧真和中学校の敷地手前で南からの流れが合流**し、流れは北向きに変わる。西武池袋線を再び越える〔南長崎支流・椎名町支流の合流位置の読図として [BLOG-157](BLOG-157.md)・[BLOG-064](BLOG-064.md) と照合可能。U字二度渡りは [BLOG-135](BLOG-135.md) と整合〕。
