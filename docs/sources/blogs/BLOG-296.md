# [BLOG-296] 五十嵐えりnote 2本（調節池B/Cの開示請求と石神井川上流の再提示）〔repo初出・[GOV-540](../gov/GOV-540.md)質疑の続報系譜〕

- **書誌〔確認: LDJSON・og:description〕**: 五十嵐えり（当時東京都議会議員・東京都議会の会派ポスターでは「弁護士」表記）のnote記事2本。①[「都が次々建設中の「調節池等」について費用便益分析の算出根拠資料を開示請求！新事実です。」](https://note.com/igarashi_eri/n/n81e05a256950)（**2024-05-15公開**・dateModified 2024-06-14）。②[「続報！都がやり直し「石神井川上流地下調節池の費用対効果」が再提示。事業費は予算案公表時の1.2倍の1,310億円に上昇し、B/Cは1.31から1.11へ。算出根拠は原則公表へと運用変更へ。」](https://note.com/igarashi_eri/n/na1ccf9e8011b)（**2024-07-24公開**・dateModified 2024-07-26）。
- **①の要点〔確認: og:description〕**: 都内で**10この調節池等が予定（うち8つ建設中）・完成済みは30こほど（確認中）**という現状把握を示した上で、**令和6年3月11日付で10調節池の費用便益分析の算出根拠資料を開示請求し、2か月延長の後、2024年5月14日に開示**（「東京都が国に補助採択のために申請した数点の書類を開示するのに、時間かかりすぎ」）＝**10調節池分の一括開示請求の当事者記録**。
- **②の要点〔確認: タイトル・og:description〕**: [GOV-540](../gov/GOV-540.md)の2024年3月予算特別委員会質疑（2ケース算定批判）を受けて都が費用対効果をやり直し、2024年7月下旬（本文では「昨日」＝公開前日の専門家委員会）に**石神井川上流地下調節池の費用対効果を再提示＝事業費は予算案公表時（1,073億円）の1.2倍の1,310億円に上昇し、B/Cは1.31から1.11へ低下**。都のやり直しの専門家委員会開催を都議会議員に事前通知しなかったことへの批判（「他の市民の方から教えて頂き、知りました」）を冒頭で表明。**B/C算出根拠資料は「原則公表」へ運用変更**［この運用変更文言はタイトルレベルでは「運用変更へ」であり、開示請求手続とは別の渠道のようだが、詳細は本文未確認につき文言の範囲で記録する］。
- **意義〔観察〕**: ①**石神井川上流地下調節池のB/Cが1.31→1.11に再計算され、事業費が1,073億→1,310億に上昇した一連の過程**（[GOV-540](../gov/GOV-540.md)の4変遷のさらにその後）を著者自身のnoteで追える。②**同じ視点が、その後の衆議院での質問主意書（[GOV-539](../gov/GOV-539.md)・善福寺川上流地下調節池B/C）に接続する**＝五十嵐えりのB/C監視系譜（都議会→開示請求note→衆議院質問）の断片として個々の資料に接続可能。③B/C計算の2ケース vs 6ケース問題が実際に再計算につながった（1.31→1.11）という**結果レベルの新事実**。
