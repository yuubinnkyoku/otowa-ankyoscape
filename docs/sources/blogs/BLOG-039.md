# [BLOG-039] 池袋・明治期の水路？川？（実測東京全図）

- **意義〔観察〕**：**明治11年実測東京全図が池袋周辺を描いているという地図の所在情報**と、丸池上流・弦巻川源流付近の**当時の水路・村境の候補読図**が新しい。弦巻川源流部（丸池周辺）の1878年時点の状況を、既収録の1911年・1925年町村図（[弦巻川.md](../../弦巻川.md)参照）より**30年以上遡る時点で検討できる**可能性がある。
