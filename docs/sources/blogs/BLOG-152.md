# [BLOG-152] 寅さん歩 その25 谷端川の流れを歩くー4（平野武宏）

- **直接確認（2026-11-13、Wayback id_付きURLでPDF本文全文取得）**：[Wayback保存版 2024-06-09](https://web.archive.org/web/20240609023623/http://shonan-fujisawa.jp/watanabe/wpage5145.pdf)。第42回まで「スニペット確認」としていた本文を、`https://web.archive.org/web/20240609023623id_/http://shonan-fujisawa.jp/watanabe/wpage5145.pdf` 形式（id_付き）で取得できることを確認した。湘南・藤沢地域情報サイト内の散歩連載「寅さん歩 その25」の第4回（明治通り〜不忍通り）。
- **暗渠化年次の文言〔確認：説明板の引用と判明〕**：第42回の未解決①（年次説明の出典不明）が解消。年次文言は**豊島区設置の「谷端川跡」説明板（豊島区西巣鴨1-17、植え込み内）の記載**を筆者が引用したもの。「昭和初年から谷端川の改修と暗渠化工事が始まりました。ＪＲ板橋駅より下流のこの地は、**昭和10年（1935年）前後に暗渠となり、上流域は昭和24年（1949年）から改修・暗渠工事行われ、昭和39年（1964年）に谷端川は全域が暗渠となりました**」。
- **説明板の内容〔確認〕**：粟島神社（**要町24**）境内の湧泉（弁天池）を水源とし、長崎村・池袋村・中丸村（板橋区）・滝野川村（北区）・巣鴨村を経て小石川村（文京区）から神田川に注ぐ**「全長約11km」**・区内最大の流域〔「全長約11km」はrepo初出の数値表記〕。豊島区・北区・板橋区内では「谷端川」、文京区内では「小石川(礫川)」、千川上水完成（1696年）後は「**千川分水**」とも呼ばれた〔呼称の併記は既存整理と整合〕。弁天池での雨乞い、野菜の洗い場・水車、夏の蛍、蜆・鮒・鯉・鰻・ドジョウ採り、この付近の**木綿の晒工場・染物屋**〔repo初出候補〕の記述。
- **宮仲公園の由来〔確認：筆者の叙述〕**：**宮仲公園の土地は渋沢栄一の三男・正雄の居住地で、昭和13年（1938年）に東京市へ寄付され児童公園となった**〔渋沢正雄・寄付年次ともにrepo初出（search_code確認済み）〕。BLOG-134/GOV-036の千川増強幹線人孔接続部として既出の公園の起源が具体化。
- **滝不動〔確認：説明板の記載〕**：北大塚1-14・都電荒川線の線路右手前に「滝不動」。説明板は「谷端川沿いの石造不動明王立像。川の流れが小さな滝のようになっていた場所に位置し『滝不動』と呼ばれた。**昭和10年（1935年）頃の暗渠化工事に伴い姿を消したが、平成11年（1999年）に元の位置に戻った**」〔BLOG-038（城所信英note）の瀧不動推定を、位置（北大塚1-14）・年次（昭和10年頃消滅・平成11年復帰）つきの説明板文言で裏付ける。大塚区間暗渠化「昭和10年頃」はBLOG-062「昭和8年または9年」と近似する第2データ〕。
- **大塚三業通り〔確認：筆者の叙述〕**：谷端川が山手線をくぐり大塚三業通りに入る区間、**両側が花街で芸者が約200名（最盛期約700名）**。入り口の先に「**姿見橋**」「**見返り橋**」という花街らしい橋名があった〔姿見橋はBLOG-088等で既出。「見返り橋」表記はBLOG-133「見返橋」・BLOG-081の表記差として記録し、別橋と断定しない〕。
- **その他〔観察〕**：南大塚1丁目児童遊園内に聾唖教育者・丸山ちよの記念碑（灘尾弘吉元文部大臣揮毫）〔人物・碑ともにrepo初出、川直接関係は薄く周辺記録〕。文京区千石3丁目との区境で豊島区が道の右側に入り込む複雑な区境形状。**氷川下児童公園内を川が突っ切って直進**し、不忍通りを横切る流路読図。江戸名所図会の谷端川図中の神社は**巣鴨総鎮守の神明社（現JR大塚駅南口の天祖神社）**との同定〔BLOG-093「明治6年まで神明社」と整合〕。**豊島区立郷土資料館友の会の資料の記録として明治通り〜不忍通りに14の橋**〔BOOK-062（友の会1999『旧谷端川の橋の跡を探る』）と整合する橋数言及〕。
- **制限〔未解決〕**：「昭和10年前後」の適用区間（説明板は板橋駅より下流の西巣鴨設置地点を指すが全区間の年次ではない）、寅さん歩その26（最終回・神田川合流まで）の所在、説明板の設置主体・設置年の直接確認。
