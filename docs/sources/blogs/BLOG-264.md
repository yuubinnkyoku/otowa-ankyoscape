# [BLOG-264] まろん通信「小金井の水路跡」シリーズ〔repo初出・小金井の用水路網跡を現場で定点観察する連載記事群〕

- **書誌〔確認: サイト内検索・No.2本文全文・2026-11-22取得〕**: まろん通信（koganei-kanko.jp/maron・小金井市観光まちおこし協会）のレポーター連載シリーズ「**小金井の水路跡**」＝**クマさん執筆**（まろんレポーター欄で確認・974投稿）。シリーズは**No.2（Vol.276・2016年5月24日）〜No.33（Vol.570）まで33回以上を確認**（Vol.291「遊歩道北2号」〔No.?＝検索スニペット〕・Vol.464 No.17「緑町四丁目から二丁目へ」・Vol.490 No.21「砂川用水 その4」・Vol.526 No.26「梶野分水 その1」・Vol.529 No.29「梶野分水 その4」・Vol.562 No.31「湧水の道 その1」・Vol.567 No.32「湧水の道 その2」・Vol.570 No.33「花と緑の小径 その1」等）＝**小金井分水・砂川用水・梶野分水・湧水の道・花と緑の小径という用水系統別の連載構成**。
- **No.2（Vol.276・2016-05-24）山王窪築樋〔確認: 本文全文〕**:
  - 「**小金井分水路跡の２回目、山王窪築樋です**」＝シリーズの第2回は[GOV-504](../gov/GOV-504.md)（山王窪の築樋で小金井分水の下を潜る立体交差）の実地記事。
  - 「**かっての水路は山王窪（現本町住宅）を回り込むように進んできて、仙川がトンネルとなって流れるその上に築かれた土手（築樋）の水路を南側へ流れました。築樋が築かれたのが1696年でそれ以降仙川以南の開墾地に生活用水、農業用水が供給されるようになります**」＝**築樋の築造年代＝1696年（元禄9年）・「それ以降仙川以南の開墾地に生活用水・農業用水が供給」という供給開始文言〔筆者記載で出典の明示は本文になし・一次史料の提示は今後の課題と明記する〕**。
  - 「**築樋は最も簡単な水道橋、付近にある関東ロームは元々は火山灰ですが粘土化していて水を透し難いのでそれを積み上げて土橋とし、その上に水路を通したものです**」＝**築樋の工法＝関東ロームの粘土質を活かした土橋構造**という技術的説明。
  - 「**築樋の北の入口、50mぐらい先から左に遊歩道北2号が分かれています**…**メインの水路跡は築樋を通って山王稲穂神社の鳥居の前から南に進んで北大通りと交差、更に南進します**」＝**分水（遊歩道北2号）の分岐位置・本流の経路（稲穂神社鳥居前→北大通り→南進）**＝Vol.291「遊歩道北2号」単独記事の存在も確認。
  - 「**仙川はトンネルで築樋の下を抜けます。余程の大雨でも降らない限り水が流れることはありません。三面がコンクリートで固められているので地下水が流れ込むこともありません。昔は違ったでしょうが**」＝**仙川の現況＝三面コンクリートのトンネル（常時無水）・地下水流入遮断という[GOV-510](../gov/GOV-510.md)の「近年は渇水期にたびたび涸渇」都文言の現場側観察**。
