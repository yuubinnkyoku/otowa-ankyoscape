## 内容メモ

- **〔観察〕** 千川上水は千川通りが中野通りにぶつかる地点で90度左折して北進するが、**葛が谷分水はこの曲がり角を曲がらず清戸道を直進**して始まる〔観察＝[GOV-005](../gov/GOV-005.md)の葛ケ谷村分水＝南長崎6丁目・千川北曲折点と位置対応〕。籾山牧場跡を突っ切り目白通りを越えて南側を並行。
- **〔二次転記: 『ふるさとは西落合 三』（西落合まちづくりの会・2003年3月）〕** 目白通りの左カーブ付近が**水車跡で「名倉水車」**という水車。冬は通水せず規模も小さく、大正時代は**絹糸を撚る**のに利用し、昭和に入る頃廃業〔repo grep新出の水車名＝水車群系譜（田中・矢島・斎藤・八成・平井・坂上等）への追加候補〕。
- **〔二次転記: 同書・加藤清氏（昭和5年生まれ）インタビュー〕** 弁天池（城田医院付近・北からの湧水合流点）: 「清水の池があってきれいな水がぼこぼとわいていた。三十センチぐらいの深さ…**底が全部見えて…白い砂のようなものが敷いてあった**」。
- **〔二次転記: 同書・岡本和代「セピア色した千川上水分水（昭和30年ごろ）」〕** 弁天池は**江戸以前から清水が湧き出て池となり、中州に弁財天の祠**が祀られ、**「雨乞いの儀式」には村中総出で池の底まで掃除して神事を行った**。〔雨乞い神事の具体叙述はrepo初出〕
- **〔観察〕** 付近一帯に湧水・沼が多くあったこと（加藤氏インタビュー）・ゴルフ練習場付近は「じくじくと水がわいていた」・新青梅街道越えには石橋があったらしい〔聞き取り〕が跡形なし・大正14年から昭和11年にかけての耕地整理表示板が数か所〔観察〕・目白大学の手前でくねり妙正寺川へ合流、**合流地点に四角い合流口が開いている**〔観察〕。
- **〔二次転記: 『長崎村物語』（1996年9月・豊島区郷土資料館）〕** 籾山牧場は長崎地域の3牧場（籾山・足立・安達）の一つで大正時代に役割を終え、昭和の初め「籾山分譲地」として売り出され、分譲パンフレット表紙に富士山の眺望をアピール〔[BLOG-145](BLOG-145.md)の籾山牧場記録と対応〕。
