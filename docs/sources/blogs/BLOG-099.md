## 内容メモ（『坂まち通信』第1号経由の記述）

- **〔二次転記: 記事本文〕** 地域雑誌**『坂まち通信』第1号（1992年発行）**が水窪川と「ふたご川」と呼ばれる弦巻川の特集号である。著者は図書館の書庫で発見。所収図書館・発行元・部数は本文に未記載。
- **〔二次転記〕** 源流部（美久仁小路付近）はもと「**蟹窪**」と呼ばれた湿地で、谷あいの池になっていた。巣鴨プリズン勤務の米兵のフットボール場を造成するため、隣の山（**根津山**）を切り崩して埋めた、とする。根津山の通称・位置はrepo既知（南池袋公園付近の通称）だが、**埋立ての目的・時期を結びつけた具体叙述**はこの記述が初出。
- **〔二次転記〕** サンシャイン近くの大マンションの地に望月家の屋敷があった。山梨（本文は「長野の飯田？」と併記）から来て紙漉きの技を伝え、**昭和30年代まで操業**。下流の音羽川・弦巻川は地形から和紙業に適した風が吹くため和紙業が盛んだった、とする。**望月家という紙漉き屋の家名はrepo初出**（音羽谷の紙漉きは[BOOK-001](BLOG-045.md)関連で既知）。
- **〔二次転記〕** 東池袋側の水窪川に面した穴（著者が「ルパン穴」と呼んだもの）は**巣鴨プリズンからの下水口**で、ここで水窪川に落とされていた。巣鴨刑務所排水口の観察は[LOST-003](../lost-web/LOST-003.md)（本田創2005）で既収録だが、坂まち通信が同じ伝承を遡って記載していたことの記録。
- **〔二次転記〕** 「君の湯」横の駐車場は木造ラムネ工場の跡で、**1990年すぎ頃に取り壊されて駐車場になった**。製造に使った水は川の水でなく地下水だった。旧ラムネ工場の存在は[LOST-003](../lost-web/LOST-003.md)既収録、**取り壊し時期の年代情報が本記事で初出**。
- **〔確認: コメント欄〕** 本田創コメント「水窪川、弦巻川については多分あれ（坂まち通信）が最も詳しい資料かと思います」。『坂まち通信』の史料価値の外部評価。
- **〔観察〕** 著者は水窪川の流路を見直し、下流（音羽川）は「新大塚の南の坂の下あたり」から辿ると予告（音羽川②＝[BLOG-100](BLOG-100.md)へ続く）。
