## 内容メモ

- **〔観察: 2019年〕** 千川駅前から川越街道まで。**千川上水の東側は谷端川の支流、西側は石神井川の支流が流れており、千川上水はその分水嶺を流れていく**という大局的な地形観察〔千川上水=分水嶺上の人工水路という位置づけの視覚的記録。中丸川・出端川等の谷端川支流群と千川上水の関係（[BLOG-059](BLOG-059.md)聴取・[BLOG-086](BLOG-086.md)中丸川）の地形文脈〕。
- **〔観察〕** 要町通りの北側は民家敷地。都道420号の変形した六叉路から板橋高校の脇へ。**歩道と街路樹のある植え込みがかつての上水路**（板橋高校裏の並木道）。
- **〔観察〕** その先で**中丸川の分水口**に出たと記す〔[BLOG-086](BLOG-086.md)（Natrium中丸川頁）・第14回の地籍図読図による中丸川の千川上水接続の、別頁での再観察記録。同一サイト内の整合する観察〕。都道420号との合流点手前に**「千」の字が書かれた境界標**。
- **〔観察〕** 都道420号鮫洲大山線に沿って下る区間。**水路敷の上に水神様が祀られている。「戦後の昭和20年代後半までは開渠で上水が流れていたという」**〔大山〜板橋区役所間の千川上水暗渠化の時期を「昭和20年代後半まで開渠」＝**1950年前後以降の暗渠化**と絞る聞き取り情報としてrepo初出。[GOV-056](../gov/GOV-056.md)（練馬区は昭和27年3月以降着手）・[GOV-072](../gov/GOV-072.md)（区内では昭和25年頃から暗きょ化工事）と矛盾せず、板橋区側の着手時期の手掛かりになる（出どおりは本文では示されず伝聞扱い）〕。
- **〔観察〕** 田崎病院の前の中丸通りと川越街道の間に**「千川管理地」と書かれた看板のある空間**が取り残されている〔管理地名の現存記録としてrepo初出〕。
- **〔観察〕** 板橋税務署の前には**石神井川に向かう氷川町の水路の分水口**がある〔千川上水から石神井川方向への分水口の観察。板橋区氷川町の水路の所在・名称は未整理〕。
- **〔観察〕** 板橋一中前で都道から右へ分かれ、税務署前を抜け山手通りを越え、板橋区役所の脇を下って中山道（板橋区役所駅前）に出る。以後は中山道の東側に膨らんだあと旧中山道に沿って南へ、豊島区立千川上水公園へ向かうと記す〔下流端の流路観察。[BLOG-089](BLOG-089.md)（簸川神社・千川改修記念碑）の位置文脈と接続〕。
