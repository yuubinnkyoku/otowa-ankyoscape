# [BLOG-260] Natrium.jp「桃園川の水路敷群」（桃園川の支流4頁: 日大二高の支流・谷戸川〔天神川〕・小淀川・阿佐ヶ谷川）〔repo初出・BLOG-254目録の「支流4頁」の全掃引〕

- **書誌〔確認: 本文全文4頁・2026-11-22取得〕**: ①「日大二高の支流」（2020/8/15・8/23・12/6ほか）・②「谷戸川」（2021/8/9・2022/7/14ほか）・③「小淀川」（2020/8/30・2025/4/12）・④「阿佐ヶ谷川」（2020/12/12・2025/3/26・2022/5/8）。撮影は2020〜2025年。
- **小淀川〔確認・repo初出の池系譜文言〕**: 「小淀川は神田川左岸側を並走している桃園川の支流で、**おそらくは神田川の豊水橋付近で旧神田上水を分水し、付近の農地に水を供給していたものと思われる**」〔神田上水分水説は推定文言〕。「**桃園川南側の一帯は中野町字小淀という地名であった（現在は中央一丁目）**」〔[対象repoの小淀橋行](../../地名・河川名対照表.md)（中野町誌1933）の流路側補助〕。**伏見宮別邸池**: 「**国立国会図書館デジタルコレクション所蔵の都市計画東京地方委員会常務委員会議事速記録 第5號**などに記載されている地図に『**伏見宮別邸**』なる記載がある。**同所蔵の中野町誌**によれば、**ここには江戸時代天保年間に麹町の豪商伊勢八こと加太八兵衛が成趣園を拓き、明治維新後に剣豪山岡鉄舟の道場となったが明治19年に伏見宮へ献上された**という」＋「**伏見宮別邸には大きな池があり、国土地理院Webサイトの昭和22年空中写真（米軍撮影）にも池が残っているのが写っている**」＋池跡の現況（東側の道路は池のヘリの形をそのまま残す・写真奥は崖・北東寄りに島があったように見える）〔**成趣園の来歴（天保年間開拓→鉄舟道場→明治19年伏見宮献上）の書誌つき文言**＝NDL史料2点（速記録第5號・中野町誌）へのリンク付き。池の戦後存続（昭和22年空中写真）と現在の痕跡観察〕。**東京府豐多摩郡中野町全圖 番地界入（小林又七、1929）**: 「**写真左のマンション奥あたりで小淀川が神田川から分水していたようだ**」〔小林又七1929図の読図文言＝神田川・桃園川レーンの地図史料に直結〕。付記事項: 1961〜62年東京都3千分の1地図の「木材市場」＝東南市場（昭和44年東京木材相互市場合併）〔中野区中央一丁目の土地利用史料〕。
- **阿佐ヶ谷川〔確認・六ヶ村分水の全系譜文言＝本項最重要〕**: 「**阿佐ヶ谷川は桃園川の支流で、青梅街道を流れていた六ヶ村分水（玉川上水の分水である千川上水のさらに分水）から桃園川に水を分けていた**」＋「**六ヶ村分水（半兵衛相澤堀）は関町で千川上水から分水し、この阿佐ヶ谷口まで導水していた。途中では井草川、妙正寺川、善福寺川、桃園川にも給水していたという**」〔**①玉川上水→千川上水→六ヶ村分水→給水先（阿佐ヶ谷川+井草川・妙正寺川・善福寺川・桃園川）という系譜の一覧文言**・②「半兵衛相澤堀」の別名併記（[GOV-490](../gov/GOV-490.md)の「半兵衛・相澤堀」と一致）・③分水点＝関町（[GOV-490](../gov/GOV-490.md)と一致する初の相互確認）。「途中で…給水していたという」は伝聞文言〕。流路は「**諸説あってはっきりしない。時代によって変遷があるのかもしれない**」（中央線ガード北・かわばた通り・いちょう小路・杉並第七小学校敷地内で東西二手に分流など複数候補の実走）。**寿々木園**＝大正13年（1924年）創業の現役釣り堀（金魚）。**2022/5/8追記**: 「**阿佐谷南三丁目バス停前にあった建物が解体されたため、その裏側にあった開渠が姿を現している**」「**開渠は北側のマンション入り口で行き止まりになっているが、かつてはここか、前の写真のあたりで青梅街道から分水していたものと思われる**」「その後、青梅街道側には店舗が建てられたがその裏には開渠が残されているのが隙間から垣間見える」〔**相澤堀（六ヶ村分水）の現役開渠が2022年時点で青梅街道裏に現存するという一次観察**＝repoの六ヶ村分水の「現存部」観察の最重要追記〕。**阿佐ヶ谷の地名**: 「駅名で、地名は『ヶ』のない阿佐谷北・阿佐谷南。**音の通り地形は桃園川と支流のいずれも浅い谷があることに由来すると思われる。中世には江戸氏の一族、阿佐ヶ谷氏が支配**していたという」〔「思われる」の推定文言〕。
- **谷戸川（天神川）〔確認〕**: 「**中野区史・下巻（1954年、中野区役所編）には谷戸川に架かる橋名に関する記事**があり、このページでは谷戸川として紹介していくが、**天神川とも呼ばれていたらしい**」〔桃園川支流の別名対照。中野区史・下巻の橋名記事へのリンク〕。小淀橋から中野駅北口商店街までの実走（北側水路・南側水路の分岐と再合流・真新しいブロック塀と苔むした擁壁の新旧・豊川稲荷神社）。**打越天神北野神社**: 「**天神川の名前の由来となったであろう打越天神北野神社**。**新編武蔵風土記稿に記述があることから江戸末期にはすでにあった**ことになる。**打越はこのあたりの小名**」〔天神川の名の由来と風土記稿記録の文言〕。**天神湯**＝昭和5年（1930年）創業の銭湯。**中野サンプラザ**: 1973年（昭和48年）全国勤労青少年会館として開館・2023年7月閉館・解体決定〔2026年時点の最新状況の記録〕。
- **日大二高の支流〔確認・観察〕**: 桃園川本流の北側に沿う支流（エトワール通りを遡る）。「**日大二高の北側を走る二高通りの向こうは妙正寺川水系の支流があり、分水嶺の南側に湧き水があったであろうことが推測される**」〔妙正寺川水系との分水嶺の明示と湧水推測〕。阿佐谷中央公園の東西両側に蓋暗渠が残る（公園は水路に挟まれた形）・銭湯裏の五叉路・コンビニ裏の蓋暗渠・上流端は中杉通り方面〔[BLOG-259](BLOG-259.md)（本流側から見た北支流）の支流側全走〕。

## 制限・未解決

- ①伏見宮別邸の位置同定（地図記載）はNDL史料の孫引きで、速記録第5號・中野町誌の該当頁の直接確認は未実施（NDLデジタルコレクションの閲覧課題）。②阿佐ヶ谷川の流路諸説のうち本文は特定せず（「時代によって変遷があるのかもしれない」）。③六ヶ村分水の給水先一覧は「という」伝聞文言で、『杉並の川と橋』（BOOK-229）本文確認待ち。④小淀川の旧神田上水分水説は「思われる」の推定。⑤谷戸川の天神川別名の使用時期・範囲は中野区史・下巻の確認待ち。
