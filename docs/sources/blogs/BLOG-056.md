# [BLOG-056] 谷端川沿い湧水ものがたり　長崎支流（仮）

- **直接確認（2026-11-11、open_url・本文全文）**：毎日暗活！暗渠ハンター（旧『東京Peeling！』、髙山英男）。2012年4月開始の「谷端川沿い湧水ものがたり」シリーズ第1回。全編が豊島区郷土資料館研究紀要第11号・横山恵美「＜調査ノート＞豊島区の湧き水をたずねて」の湧水リストに依拠した現地探索記録。
- **千川上水長崎分水の取水口〔観察〕**：千川上水緑道が一旦途切れる**要町三丁目交差点**にあたり、上水跡は金網に囲まれた空間になっている。分水はここからほぼ垂直に分かれ、粟島神社の手前を経て谷端川に落ちる。〔観察＋谷端川＝千川分水起点の既存理解と整合〕
- **長崎支流（仮）の流路〔観察〕**：**長崎2-28付近で西から谷端川に合流**。区画整理のため直角カーブを繰り返し、ブロック貫通型の細い暗渠路地が2か所現存。流路沿いの住民の聴取で「**30年ほど前（≒1980年頃）まで開渠の小川が流れていた**」「このへんは井戸が多く水も豊かだった」との証言を得ている。〔個人聴取のため年代は概数〕
- **長崎公園の湧水〔観察〕**：道路を挟んで上流・下流に分かれる長崎公園の上流側に小高い石積みの親水設備があり、**湧水地点**と推定される。公園を水源として長崎地区を流れ谷端川に合流したと整理する。
- **repoへの関連**：長崎公園は未反映分メモの谷端川支流候補の一つだった。谷端川起点＝千川上水長崎分水接続（[GOV-068](../gov/GOV-068.md)の分水設計思想）の観察側補強。研究紀要第11号そのものはrepoで書誌追跡中（2026-10-23・暗渠ブログ横断調査メモ）で、本シリーズは同紀要の支流別記述を間接的に伝える。
- **制限〔未解決〕**：1980年頃まで開渠という証言は個人聴取。長崎支流の合流点・「Uの字」上を横切る水路（本文で言及、未踏査）の所在は記事図なしでは特定できない。
