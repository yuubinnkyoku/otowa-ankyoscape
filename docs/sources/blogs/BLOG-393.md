# [BLOG-393] Natrium.jp「妙正寺川・井草川の水路敷群（江古田川周辺の水路敷）その2」

- **書誌〔確認：curl本文全文・2026-11-28取得〕**：Natrium.jp 江古田川シリーズその2（[BLOG-166](BLOG-166.md)（その1）の続き頁・repo初出URL）。写真は2020年2月撮影。
- **市杵島神社の湧水と字弁天〔伝聞・repo初出〕**：水路跡沿いの木立ちは**市杵島神社**の境内だった。**ここにはかつて湧水があったと言われ**、**この辺りの地名はかつて中新井村大字中新井字弁天だった**という。**ここに祀られている弁天様が字名や弁天分水の名前の由来になったのかもしれない**〔筆者の推定〕〔市杵島神社の湧水伝承・「字弁天」＝[BLOG-166](BLOG-166.md)（弁天分水＝桜台分水の別名）・[BLOG-320](BLOG-320.md)（市杵島神社の「弁天分水」別称）に対する**由来側の新観察**〕。
- **弁天分水の下流端と水路跡〔観察〕**：水路は中新井公園に向かって再びカーブし、**中新井公園の東側・豊玉二小との間がおそらくかつての分水**。その先は校舎になっていて水路は辿れない〔観察〕。**千川通り側から弁天分水を見ると、商店の間にある狭い隙間として水路敷が残されている**〔観察・repo初出の現況〕。
- **桜の碑〔確認・対校〕**：分水口近くに「桜の碑」。**「このあたりの千川通りは古くは清戸道といい、江戸川橋から清瀬までつながっている古道だった。清戸道沿いに作られた千川上水の桜並木から桜台の地名が起こり、それを記念した碑だという」**〔本文説明〕〔桜台地名＝千川上水桜並木由来は[BLOG-144](BLOG-144.md)（桜の碑・昭和63年練馬区教委）で既収録。清戸道の古道としての性格は[ORG-042](../org/ORG-042.md)・[BLOG-320](BLOG-320.md)と対校。本頁は観察側の補強〕。
- **下徳殿橋と「徳殿」小名〔確認・対校〕**：橋の欄干にある看板は**下徳「殿」橋**。**「ねりまの地名今むかし 現町名16＜豊玉 とよたま＞」によれば、年貢を免れて得した田んぼがあったので「得田」が「徳田」となって、中新井村の小名としては「徳殿」となっていたのだという**〔二次引用〕〔[BLOG-385](BLOG-385.md)（徳殿=中荒井村の小名・「得田」→「徳田」→「徳殿」由来説）と同じく『ねりまの地名今むかし16』に依拠する独立の観察で相互整合。「下徳殿橋」の橋名看板の実物観察はrepo初出〕。
