## 内容メモ

- **〔観察・repo初出〕田柄川下流端の石神井川合流3カ所説（その1）**: 「田柄川下流端での石神井川への合流ポイントは、実は向屋敷橋よりも上流に3カ所ある」＝中板橋・向屋敷橋から環七方面への水路敷出口3系統の実地観察。「現在、田柄川緑道は板橋区内では桜川緑道と名前を変え、桜橋で石神井川に注いでいるが、古地図では地図中央の東山町で合流していたり、中板橋付近まで流路が描かれているものもある」＝[BLOG-331](BLOG-331.md)（暗渠ハンター石神井川水系掃引の系統整理）・[BLOG-370](BLOG-370.md)（wanjin桜川緑道）に加わる**合流点複数説の独立観察**。中板橋から先は根付用水（稲付川）の領域という水系区分文言も記す。
- **〔観察・repo初出〕白箭稲荷大明神と太田道灌祈願伝承（その1）**: 下頭橋近くの白箭稲荷。「しらさき」ルビ vs 「白羽の矢」読みの議論＋**文明9年（1477年）江古田・沼袋原の戦いで太田道灌が戦勝を白箭稲荷に祈願したとされる伝承**＝[GAZ](../gazetteers/GAZ-083.md)系の江古田・沼袋戦（水窪川流域の戦場）に祈願側の石神井川沿い伝承として接続。
- **〔観察・repo初出〕下頭橋と下頭六蔵菩薩（その1）**: 江戸期川越街道の下頭橋。「橋のたもとに住んでいた六蔵が道ゆく人に頭を下げて喜捨をため込み、死後に石橋に架け替えた」由来と**六蔵を祀る下頭六蔵菩薩の現存**（repo grep 0件）＝橋名・石造物調査への追加。
- **〔観察・repo初出〕茶面不動尊・上之根橋・上板橋村役場跡門柱（その2）**: 三叉路の水路敷沿いの茶面不動尊（茶畑由来説）＝[GOV-083](../gov/GOV-083.md)（中板橋・向屋敷橋の行政記録）周辺の石造物。上の根橋（上板橋村字名・上之根由来）・**上板橋村役場跡の門柱（昭和2〜7年に所在）**・東新町氷川神社（明治35年改築の神楽殿）＝上板橋村の行政・神社資料（repo grep 0件）。
- **〔観察・repo初出〕安養院境内の水路痕跡とあいさつ通り（その2）**: 安養院（正嘉元年1257北条時頼創建伝承・豊島八十八ヵ所1番）の敷地内から水路敷が来ていた読図（垣根越しに窪んだ流路跡・空中写真で水路残存）＝[BLOG-370](BLOG-370.md)（wanjin桜川小・安養院敷地内通過）と**独立一致**。「あいさつ通り」も桜川合流水路として機能していた時期があるらしい説。桜川小前交差点で桜川緑道と分岐。2025/2/28追記でMapExpert地籍マップの水路敷（長狭物・城北公園内の石神井川分流と接続）記述。
- **〔観察・repo既出文言の独立観察〕板橋遊泉園（その1）**: 東武東上線橋梁近くの水神宮と**昭和2年（1927年）板橋遊泉園（プール）臨時駅=現在の中板橋駅由来説**＝[BLOG-331](BLOG-331.md)の遊泉園記録の橋梁・駅名側からの再観察。

## 四河川への使い方

- 田柄川（石神井川支流だが千川上水・田柄用水の隣接系統）の**最下流・合流点の具体的観察**がrepoで初めて揃った。合流3カ所説は[GOV-083](../gov/GOV-083.md)・[BLOG-331](BLOG-331.md)の合流点言説の対校材料。
