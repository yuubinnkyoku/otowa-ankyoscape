# [BLOG-014] 田村隆一と谷端川をめぐる初出調査（2020年）

- [「19番目の富士見坂（上）またの名を、あさみ坂（浅見坂）」](https://fujimizaka.wordpress.com/2020/08/27/asami-saka/)、2020年8月27日。
- 田村隆一の「谷端川」の呼び名について、原稿・再録・雑誌初出の区別と巻号・年月を詳細に記載。

- 田村の詩「川」は『海』171号（1983年6月）、『ワインレッドの夏至』（1985年）では一部改編という書誌が記載されている。
- 平山蘆江の「大塚節」歌詞と異文、発表日も記載される。
