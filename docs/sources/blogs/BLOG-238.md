# [BLOG-238] わんじん「東大下水：西片支流（仮）」（2014-03-04）

- **直接確認（2026-11-15、第99回。http://で-L追従させてFC2直取得・本文全文）**: wanjin東大下水カテゴリの西片支流記事。
- **西片支流の起点〔ページ記載〕**: 「**正確には本郷六丁目あたりの路地から流れは始まっているよう**ですが、周辺の排水や雨水を集めた流れなので、**ここが源流といえる個所を特定することが難しい**」〔wanjin観察。源流の特定不能性を明記〕。本郷六丁目あたりからの流れは**西片二丁目交差点**を抜け坂道を下る。
- **東京大学敷地内の分水嶺〔wanjin推定・repo初出の観察〕**: 「**おそらく、本郷通りを越えた東京大学の敷地内に分水嶺があり、西片側に流れる水と、根津方面に流れる水とがあったのだと思います**」〔推定と明記。東大本郷キャンパス敷地内が西片（千川＝東大下水系）と根津方面（藍染川系）の分水界となるという地形観察〕。
- **西片・本郷の戦災回避〔ページ記載〕**: 文京区の西片・本郷は関東大震災・第二次世界大戦の被害を免れたため「かなり直近まで明治時代の雰囲気」を残し、かつては本郷館などの木造歴史建築が多かったが、老朽化で建て替えが進んだ、とする〔地域の市街地変化の観察〕。
- **制限**: 個人散探索ブログで短い記事。分水嶺の位置は推定。流路の詳細（本郷六丁目〜西片交差点〜西片支流の合流まで）は wanjin 流路地図と次記事（[BLOG-239](BLOG-239.md)）参照。源流の特定はwanjin自身も不可能としている。
