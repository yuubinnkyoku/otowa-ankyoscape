# [BLOG-247] シジマ「渋谷区を流れていた河骨川跡の暗渠を歩いてきました」〔repo初出〕

- **書誌〔確認: 記事本文・2026-11-21取得〕**: note（投稿者: シジマ（静寂））「[渋谷区を流れていた河骨川跡の暗渠を歩いてきました](https://note.com/0129note/n/na3e224950113)」（**2026年10月27日21:00投稿**・写真紀行）。以前に**代々木八幡駅付近で遭遇した「謎の暗渠」が河骨川**で、これが暗渠化された**宇田川**に合流していたことを特定したという前提で、**合流地点から河骨川の暗渠を上流へ遡る**写真群。
- **観察〔確認: 記事本文＋添付の記述〕**: ①**宇田川跡（暗渠）は「レンガタイル敷きの道路」として路面に表示されており、正面の家と植え込みの間から流れてきた河骨川がこの地点で合流**する現況を撮影〔**2026年10月時点の河骨川×宇田川合流地点の路面景観の観察記録**としてrepo初出。宇田川が「奥から手前方向」に流れていたという流向の把握も記す〕。②河骨川暗渠を上流へ遡る途中で**線路（小田急線）沿いの区間が長く続く**こと・「いかにもな曲がり」（蛇行痕）の残存・木立の残存量の観察。③歩いた経路を**暗渠化される前の航空写真（昭和）で確認**し、A点（宇田川との合流地点）からB点まで遡った範囲を図示〔航空写真の出典・撮影年は本文に明記されず「まだ河骨川だった頃」としか記載なし＝年代は特定不能〕。
- **既知文言への態度**: 童謡『春の小川』のモデル川が河骨川であることは「ご存じのかたも多いと思いますが」として繰り返すのみ〔＝[GOV-136](../gov/GOV-136.md)（令和8年3月の都公式資料でも維持確認）・[BOOK-210](BOOK-210.md)（田原光泰2011）・[BOOK-212](BOOK-212.md)（渋谷区郷土博物館2008展示図録）に既収録の通説で新規性なし〕。暗渠化の工法（堰き止め→迂回→川底にコンクリ管設置→水を戻して蓋→埋め戻し）は一般解説の範囲〔新規性なし〕。
- **意義〔観察〕**: ①**宇田川暗渠跡の道路がレンガタイル敷きで表示されている**という路面表示の観察は、repoの宇田川観察系（README・[GAZ-181](../gazetteers/GAZ-181.md)の江戸期文言など歴史側中心）に対して**現在の道路景観として暗渠位置が可視化され続けている**ことの2026年定点〔宇田川跡の表示手法（渋谷区施行か）は本文未確認〕。②**河骨川×宇田川の合流地点の現在の様子を写真で特定した記事は、知る限りrepoでは初出**〔合流地点が宇田川暗渠路面上に接する様子・代々木八幡駅付近という所在地の証言。正確な座標・住居表示は本文になし〕。③写真の現物は当環境で確認しており、文言としての観察記録は上記に確定した〔画像の細部判読はhuman目視待ち〕。
