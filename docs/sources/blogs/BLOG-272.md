# [BLOG-272] 西東京水路跡散歩「おまけ 仙川上流と山王窪」〔repo初出・仙川上流部の別川説と1947〜50年代の新流路掘削説〕

## 内容〔確認: 本文全文・2026-11-22取得〕

- **書誌〔確認〕**: アメーバブログ「**西東京水路跡散歩**」（musasinowalker・2019/9/26開設・西東京市在住・「西東京市近隣を中心とした河川・用水・小水路の紹介をします」）。2020-04-23作成・2020-05-22最終編集。同ブログの水路図シリーズの「おまけ」記事で、シリーズ本編（西東京市周辺の全水路紹介）の後に仙川のみを扱った特別編。
- **仙川上流部＝別川・排水路説〔確認: 本文直接引用〕**:
  - 「**そもそも仙川自体も、現在の上流部と中流部以降は元々別な川だったようで、現在の上流部は排水路のような扱いであったという**」
  - 「**その排水路の流末は三鷹市の上連雀辺りではなかったかと推察される**」＝**現在の仙川上流部＝排水路で、流末は三鷹上連雀方面〔筆者の推察〕**。
  - 「**では、その頃の仙川の源流はというと三鷹市新川5丁目にあった丸池だったようだ**」＝**当時（江戸期）の仙川源流＝三鷹市新川5丁目の丸池**（[GOV-511](../gov/GOV-511.md)の「新川丸池公園の湧水池＝千釜」・[BOOK-138](../books/BOOK-138.md)系の丸池記録と同じ水系の源流観察）。
  - 「**上流部は江戸期より排水路であったが、当然人が増えれば排水が増え水路環境は悪化するため、小金井分水を繋げ水量を増やして是正を図ったりしたようだ**」＝**小金井分水接続＝排水路の水質是正目的という機能説明〔今回新たに注目する観察〕**。
- **1947〜50年代の新流路掘削説〔確認: 本文直接引用〕**:
  - 「**明治・大正・昭和と進み流域の人口は大幅に増え、排水路の環境はいよいよ劣悪となり排水を別な場所に捨てる必要が出てきたと思われる**」
  - 「**そこで１９４７年～１９４８年頃から１９５０年代にかけて、本来の仙川までの新流路が掘られて現在の流路が完成した、当時の新規掘削水路はそれほど広くはなく現在の砂川用水程度と思われる**」＝**1947〜48年頃〜1950年代に現在の仙川上流部〜本来の仙川（新川5丁目方面）までの新流路を掘削、こうして上流部も含め「仙川」となったとする流路形成史の仮説**。
  - 「**こうして１本の流れとなって、上流部も含め仙川となったようだ。仙川はその後、さらなる需要拡大に合わせ水路を拡幅して現在の形となった**」
- **山王窪の旧源流・現在の上流端の別流説〔確認: 本文直接引用・推定〕**:
  - 「**小金井本町住宅は山王窪内に１９６０年代前半に建てられましたが、造成前は現在の仙川とは別に北西方向へ1本水路があったようです。実はこちらが本来の源流のようで、現在の仙川上流端へ向かう水路は合流する支流の１つだったようだ**」＝**山王窪北西方向の水路＝本来の源流で、現在の上流端（新小金井街道側）の水路は合流支流にすぎないという観察〔「ようです」表現の推定〕**。
  - 「**明治期の地図では、仙川の水路は北西方向の水路しか存在せず、現在の上流端方面の水路は記載されていないものもある**」＝**明治期地図の読図根拠**＝Wikipedia「仙川」（明治から戦後の地形図で中央大学付属中学校付近に河川記号の上流端）の読図と整合する観察。
  - 「**山王窪自体傾斜地が多く、戦前までは耕作に適さない荒れ地として放置されていた**」＝**山王窪の戦前の土地利用＝荒れ地〔[BLOG-264](BLOG-264.md)No.1の「昭和17年陸軍技術研究所設置」と対照する開発史〕**。
  - 「**写真６　旧仙川源流部／山王窪北西側の旧仙川源流付近、遠目で見ると谷状の地形がよくわかる。左側は中央大学付属中・高校の敷地となっていて、谷の北側はすぐきつい上り坂**」＝**旧源流＝中央大学付属中・高校付近の谷状地形（現地観察）**。
  - 「**１９５５年頃の地図では川は記載されているものの、航空写真では既に川筋は判りづらい。この当時は現在の仙川が流れの主流になっていたようだ**」＝1955年頃地図と航空写真の対読。
- **上流端周辺の現況〔確認: 本文直接引用〕**:
  - 「**現在、仙川の上流端は新小金井街道に面した場所となっており…その延長線上に水路が続いていたと思わせる路地が続いています。古い航空写真でも、現在の上流端より続く水路が確認でき、その水路の筋を追っていくと現在のサレジオ学園の敷地内に行きつきます。ただ、水源があったのか窪地の水が集まり流れ出していたのかは不明**」＝**現上流端からサレジオ学園方面へ延びる旧水路（航空写真確認）**。
  - 「**新小金井街道の東側より水路が現れます、最初から大きい幅の水路で、新小金井街道側より僅かに水が流れ出していました。水路幅から見て、排水路として利用されていた感じはあります**」「**流水は３００ｍほど下流の小金井本町住宅周辺では確認できませんでした**」＝**上流端の僅かな流水（下水ではなく湧水か不明）**の観察。

## repoとの関連〔観察〕

- ①**仙川の流路形成史の新仮説**：現在の上流部＝江戸期の排水路で、1947〜50年代に本来の仙川（新川5丁目丸池起点）まで新流路を掘削して一本化、という流路史の統合仮説＝[GOV-504](../gov/GOV-504.md)（貫井村誌：仙川＝「悪水」「悪水堀」の呼称）と**「排水路＝悪水」の同義構造で強く整合する**。②山王窪北西＝本来の源流説は、①Wikipedia「仙川」の「明治から戦後の地形図では中央大学附属中学校付近に河川記号の上流端」という文言（対照表既記）と一致し、まろん通信No.6「1600年代中頃、仙川は恐らく水が流れていた」（[BLOG-264](BLOG-264.md)）の観察と対照可能な地形観察。③「小金井分水を繋げ水量を増やして是正」という文言は、Wikipedia「仙川」の「昭和初期、小金井用水から仙川へ一定量落水」文言（対照表第258回追記・三次文言）と同型の**水質是正目的の放水機能説**の観察側の補強。④当ブログは「西東京市近隣の河川・用水・小水路」を体系的に紹介するブログで、**仙川下流部・千川・新堀用水・保谷系水路などrepo関心水域の記事群が存在する可能性**＝次回以降の掃引対象。

## 意義〔観察〕

- 仙川の上流部を「本来の仙川とは別の排水路」として読み、新流路掘削（1947〜50年代）で現在の流路が完成したとする流路形成史の仮説を、明治期地図・1955年頃地図・航空写真・現地の谷状地形の4つの読図で提示した点が独自。repoの仙川流路史（[GOV-504](../gov/GOV-504.md)武蔵川／旧仙川・[GOV-510](../gov/GOV-510.md)水量変遷）に対して**流路の物理的な形成過程（いつ今の形になったか）という観察仮説**を新規に供給する。

## 制限・未解決

- ①「1947〜50年代掘削」の典拠（都水利資料・建設省絵図等の一次史料）は本文に明示なし＝**掘削年代の確定は一次史料確認まで「仮説」**として扱う。②「その頃の源流＝三鷹新川5丁目の丸池」も「〜だったようだ」と伝聞調で、丸池そのものの史料確認は別途必要。③「山王窪＝本来の源流」説は明治期地図の読図に基づく推定で、山王窪内水路とサレジオ方面水路の新旧関係は確定していない。④「小金井分水を繋げ水量を増やして是正」の時期（江戸期〜昭和初期のいつか）は未特定。
