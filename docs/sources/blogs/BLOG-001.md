# [BLOG-001] M — Natrium.jp「神田川周辺の水路敷群（水窪川）」

- https://natrium.jp/canal_lot/kanda/mizukubo/index.html
- 現地地形・水路敷・下水道台帳などを照合した現地調査記録。一次史料ではなく、現地観察・比較資料として使う。
- **本文の内容資料化〔確認：2026-11-11に本文全文を取得〕**（撮影2023-12-23〜2024-7-13）：
- **出口の特定〔確認：当頁の下水道台帳照合〕**：水窪川のもともとの川筋は現在の巻石通りとなっている**旧神田上水に注いでいたため、神田川に痕跡はなく**、下水道台帳では音羽通りの下で弦巻川の雨水管（雑司ヶ谷幹線）とクロスして江戸川橋西側に出る。**江戸川橋西側の坂下幹線排水口が水窪川の出口**と読む。
- **「鼠ヶ谷下水」呼称〔確認：当頁の古地図引用〕**：江戸時代の地図には水窪川の下流を**鼠ヶ谷（ねずみがやつ）下水**と書くものがあり、**弦巻川も合わせてそう呼ばれていた**という〔「下水」は用水路の意で汚水ではない〕。〔GOV-001・BOOK-057等の鼠ヶ谷関係記録を補強する。両川を包括する呼称という点はrepo初出の主張として記録〕
- **下流部の現地観察〔確認〕**：小日向台の崖下を流れる（久世山＝下総関宿藩主久世氏下屋敷）。今宮神社（護国寺境内から明治6年1873年に遷座）付近の崖下窪地、八幡坂（田中八幡宮に由来する坂名）。鳩山会館エントランス道路で川跡は一旦途切れるが**エントランス北側には空中写真で水路敷が残る**。附属横坂（筑波大附属横）との交差以降は細道化。
- **上流端の読図〔確認・推定が混在：当頁の主張〕**：最上流部はサンシャインシティ西側の**美久仁小路**にあったとする。**水久保停留場**：都電荒川線東池袋四丁目停留場は**昭和14年に日出町二丁目停留場と統合されるまでは水久保停留場として川筋のそばにあった**〔※頁には「昭和14年（1393年）」という誤記があり、1939年（昭和14年）の誤りと判断〕。**日出町公園の中央あたりを水路が流れていた**。美久仁小路・栄町通りはともに戦後混乱期に池袋駅東口の闇市店舗を移転した起源で、**谷頭は栄町通り付近にあったように見える**という観察。蟹ヶ窪は東口五差路〜池袋駅東口（ヤマダ電機付近）とされる〔いずれも地名・流路の具体化に有用な現地読図〕。
- **吹上稲荷神社〔確認：当頁の由緒記〕**：元和8年（1622）に徳川秀忠が江戸城内の吹上御殿に日光から勧請したことに始まり、遷座を繰り返し**現地に落ち着いたのは明治44年（1912）**〔GOV-029・ORG-006等の同神社記録と年代が一致〕。
