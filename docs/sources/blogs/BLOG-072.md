# [BLOG-072] 旧町名・杉並区八成町

- **直接確認（2026-11-11）**：元URLは2026-11-11時点で「Entry is not found」。[Wayback Machineの2022年12月4日スナップショット](https://web.archive.org/web/20221204011626/https://citywalk2020.hatenablog.com/entry/2021/12/19/120830)で本文全文を確認。発見場所は杉並区井草2丁目。
- **八成の読みと字名〔確認〕**：「八成」は「**はちなり**」と読む。『新編武蔵風土記稿』に「**東の方上鷺ノ宮の界を云**」と書かれた**下井草村の小名**。石造物に「**鉢成講中**」などの表記が残る〔「八成」の異表記「鉢成」はrepo初出。地名対照表候補〕
- **地名由来の伝承〔二次転記：『杉並風土記』（森泰樹、昭和52年）経由〕**：地名由来は**千川上水の八成橋とかかわる伝承**として、**観泉寺の住職が経典から八成（はっせい）橋と命名、住民は「はちなり」と読み、いつしか地名になった**という。〔**橋名が先で地名が後**という伝承で、八成橋が江戸期から千川上水の橋として実在したことを示唆する（伝承であり断定しない）。「八成橋」は現在もバス停・八成橋交差点などの名前として残る〕
- **行政史料の並記〔二次転記：杉並区教育委員会「杉並の地名」（文化財シリーズ19、昭和53年）経由〕**：同書は地名由来について「伝えられていない」とする。**千川用水を上井草村から分水して水田の灌漑に利用した**と記す〔上井草村分水の言及。関村分水（GOV-068）のような上流側分水の一事例として記録〕
- **町名変遷〔確認〕**：明治22年（1889）市制町村制で井荻村（のち井荻町）大字下井草の小字となる→昭和7年（1932）杉並区成立で八成町→**昭和38年（1963）住居表示で井草2丁目が成立し八成町は消滅**。杉並区立八成小学校（1955年開校、水路の先端にあたる農地を造成）・八成公園（昭和45年開園）に名残。中野区上鷺宮にも通称「八成山」由来の八成公園がある。
- **制限〔未解決〕**：『杉並風土記』『杉並の地名』とも原本未確認（ブログの引用書き下ろしに依存）。観泉寺（今川氏ゆかり、杉並区今川3丁目）と下井草村・八成の関係の詳細は未確認。
