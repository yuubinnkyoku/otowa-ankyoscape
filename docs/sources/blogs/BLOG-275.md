  - 写真13：「**もっと以前にはここで水路が分岐して、北側の亀久保橋を樋で渡り東大通り側へ抜ける水路もあったとの事**」＝**亀久保橋を樋で渡って東大通り側へ抜ける枝水路**〔「との事」の伝聞〕＝[BLOG-276](BLOG-276.md)（梶野新田用水（1）の「**亀久保橋を桶で渡した小金井分水も合流している**」）と同水路を指す**互いに独立していない同一ブログ内の対応文言で「樋」と「桶」の表記揺れがある（桶は樋の誤記候補だが両文言をそのまま記録する）。1960年代中頃の航空写真でこの一帯の水路に橋＝開渠水路の存在を確認。1970年代前半から仙川の拡幅工事。「**やはり昭和４０年代は、都市河川や水路が大きく様変わりした時代だったのだろう**」。

- ①**小金井市設置案内板の年次変遷文言（1）**: repoの小金井分水系の年次データは①まろん通信系の1696年説（4系統の一致・伝聞、[BLOG-264](BLOG-264.md)・[BLOG-266](BLOG-266.md)・[BLOG-269](BLOG-269.md)・[BLOG-270](BLOG-270.md)）②まろん通信No.16の「江戸時代中頃（1696年）」（[BLOG-273](BLOG-273.md)）のみで、**市の案内板という設置主体の違う情報源が初めて加わる**。「1688〜1704年順次許可」は1696年説を矛盾なく内包し、**順次設置（複数年次にわたる許可）**という新情報も含む。1870年（明治3年）の取水口統合は[GOV-510](../gov/GOV-510.md)の明治3〜5年（1870〜72）の通船・砂川用水系再編文言・[BLOG-266](BLOG-266.md)（小金井分水の明治の切替）・[BLOG-225](../blogs/BLOG-225.md)（新堀用水の明治3年統合）と同年次の再編群に整合する。②**山王橋（2）**: 「**昭和中期まで小金井分水は神社前の道の左側を流れており、神社前には山王橋という名前の橋が存在していた**」＝**小金井分水の開渠時代の橋名でrepo初出**（grep確認・0件）。山王稲穂神社前＝築樋の北側直上の流路位置の特定資料。③**梶家の水車口碑（3）**: 平代坂の水車の系譜に第3系統を加え、梶家文書絵図（[GOV-505](../gov/GOV-505.md)）の前原側水利施設群との対照候補となる。④**質屋の出水の現況（6）**: [GOV-506](../gov/GOV-506.md)の湧水点記録の2020年時点での物理的存続観察。⑤**野川の流路変更・天神橋合流点（3）（7）**: [GOV-508](../gov/GOV-508.md)（野川改修）の野川側の現地観察データ。⑥**仙川への加水用水路群（9）（11）**: 小金井市域の北側分水（遊歩道北2号・緑町系）が仙川への加水を目的としたという構造説は、山王窪築樋（仙川の立体交差）・[GOV-504](../gov/GOV-504.md)（悪水呼称）・[BLOG-272](BLOG-272.md)（上流部別川説・排水路扱い）という**仙川の流量史観察群に「給水側の動機」を新たに供給する**。

## 意義〔観察〕

- 小金井分水は[GOV-504](../gov/GOV-504.md)〜[GOV-506](../gov/GOV-506.md)（小金井市文化財センター通信）・まろん通信系列（[BLOG-264](BLOG-264.md)〜[BLOG-273](BLOG-273.md)）に続く**第3の観察系統**で、本ファイルは分岐・合流点・横断構造を含む**全流路の現地トレース**を初めて供給する。特に①**市設置案内板由来の1688〜1704年順次許可＋1870年統合という年次変遷**、②**山王橋・亀久保橋（樋渡し）という橋梁語彙の新規収集**、③**野川（昭和後期流路変更）・仙川（加水用水路群）の受給両河川側の近代改修観察**は、repoの玉川上水系南部水路網の年代・構造・河川相互接続の3層すべてに新規データを与える。

## 制限・未解決

- ①**市設置案内板の文言はブログ経由の二次記録**で、案内板の設置主体・年・原文は未確認（現地撮影も本取得には含まれない）。1688〜1704年・1870年の各年次の元史料（小金井市史等）は未特定。②**山王窪築樋の「1696年頃」・陸軍技研の水路移設・庚申塔1751年・亀久保橋の樋渡し・梶家の水車・小金井の井の現況**はいずれも「言われている」「と思われます」系の伝聞・推定文言。③野川の流路変更・仙川の拡幅の実施年は本文に年次特定なし（仙川拡幅は「1970年代前半から」で、[GOV-508](../gov/GOV-508.md)系の都改修文言と対照要）。④旧谷口家の屋敷林・質屋の出水・キンヒバリの里の湧水系の接続関係（トンネル直結説）は観察仮説で、[GOV-502](../gov/GOV-502.md)〜[GOV-503](../gov/GOV-503.md)の湧水点リストとの照合が次の課題。⑤奇妙な表記揺れ（「桶で渡した」〔BLOG-276〕 vs「樋で渡り」〔本ファイル〕）は同一ブログ内の対応文言として原義（樋）の推定を残しつつ確定しない。⑥当ブログの小金井市域の他シリーズ（白子川・中沢川・黒目川等）はrepo関心水域の外縁のため本回は未取得。
