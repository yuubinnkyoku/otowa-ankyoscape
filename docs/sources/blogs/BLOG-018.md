# [BLOG-018] 千川通り南端の路面隆起と下水道再構築に関する2025年の区議会議員の聞き取り記録

- **資料〔確認〕**：文京区議会議員・依田翼、本人サイト『[こんにゃくえんま前の道路隆起と千川通りの洪水対策の現状](https://yodatsubasa.tokyo/%E3%81%93%E3%82%93%E3%81%AB%E3%82%83%E3%81%8F%E3%81%88%E3%82%93%E3%81%BE%E5%89%8D%E3%81%AE%E9%81%93%E8%B7%AF%E9%9A%86%E8%B5%B7%E3%81%A8%E5%8D%83%E5%B7%9D%E9%80%9A%E3%82%8A%E3%81%AE%E6%B4%AA%E6%B0%B4%E5%AF%BE%E7%AD%96%E3%81%AE%E7%8F%BE%E7%8A%B6/)』（**2025年7月9日公開**）。東京都下水道局の工事担当者に聞いた内容を、議員本人が記した記事。**東京都下水道局の公式発表・設計図・回答書ではない**。
- **現地の状態〔観察：筆者の報告〕**：**こんにゃくえんま前の千川通り南端**で、車道中央が高く歩道との段差が生じていると記す。路面の横断測量値、沈下・隆起の開始時期、写真の撮影日は記事中では確定できない。
- **施設と工事段階〔確認：記事本文／二次伝聞：下水道局担当者の説明とされる内容〕**：既存の**千川幹線**の下方に**千川増強幹線**が掘られ、大雨時の雨水を貯留する。**第二千川幹線**を含む3幹線の水のやり取りに必要な施設は2025年7月時点で**一部未完成**で、記事では接続工事があと数年続く見込みと説明する。**完成時期・浸水防止効果は行政の公表工程・性能評価で未検証**。
- **道路平坦化の説明〔二次伝聞〕**：議員は、**比較的浅い既設千川幹線の上に道路が載ることが路面中央の盛り上がりに関係する**と担当者から聞いたと記す。雨水を別幹線に逃がせるようになれば既設管を**細い矩形のコンクリート管（記事中の表現はボックスカルバート）へ段階的に更新**し、道路を止めずに施工するため長期間を要するとの説明を紹介する。**2025年記事での「10年後くらい」は筆者の見通しであり、確定した竣工年ではない**。
- **出典と限界〔注意〕**：既収録の[BLOG-017](BLOG-017.md)（2020年の住民記事）は路面の相対的な凸状化を**地下水揚水による両側の地盤沈下**で説明したが、2025年の本記事は**浅い既設幹線の構造と更新計画**に着目する。**両説を区別する根拠が増えた**一方、後者も聞き取りの二次資料であり、**地盤沈下説を否定したり、道路の高さの主因を確定したりはできない**。工事名・区間・断面・工程は下水道局の施工図・竣工図・道路横断測量で要照合。
