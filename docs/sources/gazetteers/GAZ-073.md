# [GAZ-073] 市谷寺社書上・圓融寺自證院条（文政期）— 雑司ヶ谷村200石朱印の代地履歴全容＝護国寺門前町・御鷹部屋・犬小屋の土地収用の実務記録〔第149回〕

- **書誌〔確認〕**: 『寺社書上』（写・刊記なし。文政期の幕府による寺社御調書上の写本群の一冊）。NDL次世代デジタルライブラリー [book/2571395](https://lab.ndl.go.jp/dl/book/2571395)。**冊子冒頭文言「寺社書上 市谷寺社書上…二七六ノ第四十 市谷寺社書上上」「地誌御調書上 市谷本村」＝本冊は「市谷寺社書上」で、市ヶ谷の寺社群の御調書上を綴ったもの**。同シリーズの既登録冊: [GAZ-071](GAZ-071.md)（本所寺社書上六・2571450）。**書上はくずし字写本でOCRの崩れが非常に大きく、引用文言はすべて原画像照合を要する**。寺名・人名の OCR 崩れ（「自澄院」＝「自證院」の崩れ候補・「曹司を谷」＝「雑司ヶ谷」の崩れ候補など）が多い。
- **圓融寺自證院の沿革〔確認・文言候補〕**: 「**武州豊嶋郡市ヶ谷鎮護山圖融寺〔 圓融寺の崩れ〕天台宗自澄〔自證院の崩れ候補〕 一境内平領也此坪壱万六十余坪 右往古年代不知牛込榎町ニ有之候処寛永十七庚辰年八月廿八日市谷一於皆地拝領被仰付其節当所江引移り申候**」＝**牛込榎町の日蓮宗不受不施の寺（旧法常寺〔自証院記の引用部〕）が、寛永17年（1640）8月28日に尾州徳川義直室・千代姫の母堂於振之方の送葬を機に市ヶ谷16,000余坪の替地へ移転**、寛文中の不受不施禁断で天台宗に改宗、「**如今鎮慶山〔鎮護山の崩れ〕圓融寺自證院**」と改号した沿革。〔引用される「自証院記」（元禄4年・釋公慶謹記）によれば、於振之方は「**尾陽侯大夫人千代姫君ノ母堂**」で「**寛永庚辰歳八月二十八日…當寺ニ葬リ自證院大姉ト号ス**」、山号は「本理山〔 本照山の崩れ候補〕」、改号は東叡山第二世大僧正の命という。〕
- **雑司ヶ谷村200石の朱印〔確認・文言候補〕**: 「**御朱印高弐百石 右は正保四年正月十七日大院樣ゟ始る**」「**当寺領武蔵国豊嶋郡雑司谷村之内弐百〔石〕事 依為松寿院禅尼蓋提所〔 菩提所の崩れ候補〕…正保四年正月十七日 厳有院樣御朱印之写**」「**当寺領…雑司谷村之内弐百石事 任寛文六年三月廿日先利〔 判の崩れ〕之旨…寛文六年三月廿日御朱印 常憲院樣**」「**貞享二年六月十一日御朱印**」＝**豊島郡雑司ヶ谷村200石の朱印地が正保4年（1647）正月17日に発給開始され、寛文6年（1666）3月20日・貞享2年（1685）6月11日に再発出された朱印文言の写し**。〔「松寿院禅尼」はOCR崩れが大きく、於振之方の法号の崩れ候補として要照合（自証院記引用部では「自證院大姉」「高清」と記す）。〕
- **代地履歴①元禄10年・護国寺建立〔確認・文言候補・核心〕**: 「**右拝領分武蔵国豊嶋郡雑司ヶ谷村之内ニ而高弐百石之内御用ニ相成代地被下置候巨細左之通り**」——「**元禄十丑年五月 護国寺御建立之切〔 切付の切・建立の節の意〕御代官細井九左衛門殿御掛りニ而御用地ニ被上 巣鴨五軒町二而御代地被下置候 尤雑司ヶ谷村名主支配内御座候**（一高拾五石七斗八合）」「**同年十一月中 護国寺境内門前地に相成候ニ付御同人御掛にて御用地已上 雑司ヶ谷村之内御料之内拝代地被下置候**（一高壱斗弐升弐合）」「**元禄十二卯年六月中 護国寺境内為御添地御同人御掛に而御用地に罷上 雑司ヶ谷村之内御料所之内右御代地ニ被下置候**（一高壱石八斗七升弐合）」＝**元禄10年（1697）5月の護国寺御建立にともない雑司ヶ谷村の寺領200石のうち199石7斗7升5合余が御用地に収上げられ、代地として巣鴨五軒町（雑司ヶ谷村名主支配内の飛地）が下し置かれ、同年11月には一部が護国寺の門前地に組み込まれ、元禄12年（1699）6月には護国寺境内の御添地でも収上が行われた**＝**護国寺建立（延宝8年創建・元禄期本格化〔GAZ-072 追記参照〕）にともなう門前町造成の土地収用の実務記録（御代官細井九左衛門〔下高田村茶屋の除地化の奉行〔GAZ-048 系・風土記稿〕と同一人物候補・要照合〕の担当）**。

## 制限・未解決

- ①書上はくずし字写本でOCRの崩れが非常に大きい（「自澄院」「圖融寺」「曹司を谷」「松寿院禅尼」「蓋提所」「御大部屋」等はすべて崩れ候補）。引用文言は原画像照合を要する。特に高・石盛の数値・干支・人名の照合が必須。②「松寿院禅尼」の比定（於振之方の法号か、別の人物か）は本書からは確定できない（自証院記引用部の「高清」等の崩れも含め要照合）。③朱印発給開始（正保4年）と風土記稿の「寛永十八年自證院領」の前後関係の解釈（寛永17年の送葬時の寄進を正保4年に朱印化したのか）は断定しない。④元禄10年5月の収用と同「十一月中護国寺境内門前地」の文言の関係（同一地の二段階収用か別地か）は要照合。⑤本浄寺引移の「宝永4年」説と文政寺社書上の「寛永4年」説（〔GAZ-072〕）の対立の解決は原画像照合と本浄寺側資料の確認を要する（干支・根津権現造営年代との整合から宝永4年説が有力候補と観察されるが断定しない）。⑥同冊内の他寺条（市ヶ谷の諸寺）の精査は不十分で、雑司ヶ谷・音羽関連の他の文言の有無は再走査を要する（2026-11-17の全文検索で「雑司」は本条に集中）。⑦御代官の名（細井九左衛門・雨宮勘兵衛・会田伊右衛門・柴村藤右衛門）はOCR崩れを含み、『神田上水留』帳簿群〔GOV-334〜336〕等の人物との比定は今後課題。
