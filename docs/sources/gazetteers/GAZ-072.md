# [GAZ-072] 東京市史稿 市街篇第五（1928）— 市ヶ谷雑司谷町の同型町名起原伝承と本淨寺の文政寺社書上条〔第148回〕

- **書誌〔確認〕**: 東京市編『東京市史稿』**市街篇第五**（**東京市・1928年**・625頁。請求記号GC65-25・書誌ID000001226874。NDL次世代デジタルライブラリー [book/3450784](https://lab.ndl.go.jp/dl/book/3450784)）。市街起立轉移事蹟・寺社起立轉移事蹟・薬園開設事蹟等を項目別に編み、各条の典拠を「-文政町方書上」「-文政寺社書上」「-新編武藏風土記稿」「-芥川文書」等の引用元ラベル付きで採録する編纂体。**OCRの崩れが非常に大きく、引用文言はすべて原画像照合を要する**。同史稿の既登録冊: [GAZ-016](GAZ-016.md)（市街篇12・3450786）・[GAZ-055](GAZ-055.md)（市街篇第一）・[GAZ-056](GAZ-056.md)（遊園篇）・[BOOK-129](../books/BOOK-129.md)（橋梁篇第二）。
- **雑司谷町条＝市ヶ谷側の同名町の町名起原伝承〔確認・文言候補・混同注意〕**: 「市街起立轉移事蹟」の雑司谷町条——「**雜司谷町 一町名起り之儀、元來地名ニる雜司谷村と相唱い。右と往古禁中雜式相勤居い柳下若狹・戶張平司左衞門・長島內匠抔申者、南朝ニ相勤居い處流浪仕、當所ニ參り住居仕い由ニる、雜式谷に相唱い由。右之家筋、當時當村方百姓ニ殘り居い。然ル處其後文字之儀も區々ニゐ、藏主ケ谷、僧司谷、曾子ケ谷抔、向々相認い處、有德院樣御成之節、文字區々ニあ及混雜い間、右混雜之雜之字相用可申旨、上意有之い由申傳い得共、慥成義無御座い**」「且當町之義と、寬永十八巳年中大猷院樣御裏方尾州千代姫君樣御母堂自證院樣御靈屋領としる、市谷自證院領ニ相成申い」＝**①町名起原を南朝に仕えた禁中の雑式職の者たち（柳下若狹・戸張平司左衞門・長島內匠）の流浪住居に求める「雜式谷」説、②藏主ケ谷・僧司谷・曾子ケ谷の表記揺れ、③有徳院様御成の際に「雜」の字に統一する上意があったとする伝承（「慥成義無御座い」と出典自身が留保）、④寛永18年（1641）に尾州徳川家千代姫の御母堂の霊屋＝自証院領として起立した市谷の町**である旨を「文政町方書上」から引用する（同条に名主平次左衞門の先祖譚〔本苗田口→建武年中江州堅田浦の戦功で禁中から瓜の紋・錦の幌を拝領して苗字を幌と改め、後に戸張と書き改めた・寛永10年の御検地の御水帳に假名で苗字が記されている〕と文安元年5月2日の法名〔榮祥瑞禪定門・俗名幌平司左衞門藤原基賢〕の文言候補も続く）。〔**本条の雑司谷町は自証院領として起立した市ヶ谷の町（旧東京市牛込区市谷雑司谷町系）であって、武蔵国豊島郡雑司ヶ谷村（本調査の対象地域）ではない**。ただし**[BOOK-144](../books/BOOK-144.md)（遊歴雑記・文政7年草稿）が豊島郡雑司ヶ谷村の村名由来説として記す「雜式谷説・藏主ヶ谷説・有徳院御成の「雜の字」上意説」と構造・内容が同型**であり、文政町方書上（公式書上）レベルの同型文言としてrepo初出。両伝承の関係（共通の起原譚か、同名町による相互移入・混同か）は本書からは判定できず断定しない（対照表の雑司ヶ谷行で対校課題とする）。**豊島郡雑司ヶ谷村の村名由来説を引用する際に本条（市ヶ谷側）を混ぜないこと**。〕
- **文政寺社書上引用の雑司谷本淨寺条〔確認・文言候補・repo初出候補〕**: 寺社起立轉移の条——「**-文政寺社書上 雜司谷本淨寺 寛永中駒込ニ起立ス。…御護末、眞要山ト號ス。本尊三寳祖師、開山眞珠院日要、寛永年中駒込邊ニ起立シ、明暦三年三月十一日寂ス。其後根津權現御建立ノ時御用地トナリ、寛永四年此地郡雜司ケ谷村○武藏國豐島ニ引シト云。**（引用区切りのOCR崩れあり）」＋引き続く風土記稿引用の「雜司谷本淨寺門前」級の文言候補＝**①豊島郡雑司ヶ谷村の本淨寺（眞要山・日蓮宗）が寛永年中に駒込に起立し、根津権現建立の際に御用地となったため寛永4年（1627）に武蔵国豊島郡雑司ヶ谷村に引移された、②開山・眞珠院日要は明暦3年（1657）3月11日に寂した**という文政寺社書上レベルの沿革（市史稿経由の引用文・文言候補）。〔**[BOOK-144](../books/BOOK-144.md)の鬼子母神掘出地＝「本淨寺の南の林中・三角の井筒」の本淨寺の、文政期公式書上由来の沿革文言としてrepo初出候補**（本淨寺の雑司ヶ谷村引移が寛永4年であることは、掘出伝承の年代（永禄4年＝1561）と堂・寺の位置関係の整理に寄与する前提情報。ただし掘出地と本淨寺の位置関係の解釈は従来どおり断定しない）。**本淨寺（豊島郡雑司ヶ谷村・眞要山）と本仏寺（本所出村・安楽山・[GAZ-071](GAZ-071.md)）は別寺**（日蓮宗で寺名が類似するため書上の帰属確認を要することの実例＝第147回のGAZ-071誤帰属の教訓）。「御護末」等の語はOCR崩れで文脈復元不確実。〕
- **薬園開設事蹟＝芥川文書引用の牛込御薬園と護国寺〔確認・文言候補〕**: 「**寛永十五年十月品川及小石川之兩所へ藥園ヲ被設立。麻布南御藥園ハ壹萬六千坪餘、初池田道隆へ御預、後木下道圓…小石川北御藥園ハ壹萬八千坪餘、…宗琢へ御預**」と「**謂フ所ノ牛込藥園ハ今ノ音羽護國寺境內ニシテ、府內場末沿革圖書雜司ケ谷村小石川村大塚巢鴨ノ內、「延寶初之頃ハ…御藥園…延九年二月南手ニ有之御藥園護國寺境內」ト記ス者是也**」「**元祿年中護國寺を御建立の時、かの大塚の御藥園を此地に合せられ、芥川小野寺あづかれり。その後正德三年三月十一日此地は廢せられ、小石川白山御殿跡へうつされしゆへ、芥川氏もおのづから白山御殿跡へうつれり**」＝**①牛込御薬園が現在の音羽護国寺境内にあったとする芥川文書の文言、②元禄年中の護国寺建立の際に大塚の御薬園が護国寺地に併合され、正徳3年（1713）3月11日に廃止されて小石川白山御殿跡へ移されたとする沿革**（文言候補・崩れ多し）。〔護国寺境内の土地利用史（御薬園→護国寺建立→正徳3年移転）の一次系の編纂記録で、READMEの護国寺旧境内の埋没谷発掘・小石川御薬園跡発掘の記録群と対照できる。品川=南御薬園（麻布）・牛込=北御薬園の対応と「小石川」表記の混在はOCR崩れを含み要照合。〕

- ①本書のOCRは崩れが非常に大きく（引用元ラベルと本文の区切り・漢数字・固有名詞の判読）、引用文言はすべて原画像照合を要する。②**雑司谷町条（市ヶ谷）と豊島郡雑司ヶ谷村の区別**: 本条の自証院領・寛永18年起立の文言から市ヶ谷側の町と確認したが、市街篇第五の当該条の全体像（町域・前後の町条）の精査は未了で、原画像での確認を要する。③BOOK-144の豊島郡側の村名由来説と市ヶ谷側の同型伝承の関係（共通譚か移入か）は判定しない（風土記稿・御府内備考の両所の条の対照は今後課題）。④本淨寺条の「御護末」「眞要山」等の語の正確な文脈・根津権現建立の年次の対応は要照合。⑤薬園文言の「品川/麻布」「小石川/牛込」の対応の整理も要照合。⑥市街篇第五内の他の豊島郡関係条（音羽町・護国寺門前等の起立条）は「音羽」2件・「護國寺」11件が見えるのみで未精査（次回以降の走査対象）。
