# [GAZ-140] 町方書上[8] 牛込四 — 津久戸前町の石橋化年次・「小日向冷水番所通大下水」

- **書誌〔確認〕**: 『[8] 牛込町方書上　四』（写・NDL次世代デジタルライブラリー [book/2571489](https://lab.ndl.go.jp/dl/book/2571489)）。文政10亥年（1827）。表紙町列＝白銀町・西照院門前・無量寺門前・萬昌院門前・周(=洞?)寺内門前・五軒町・成願院門前・**津久戸前町・成就院門前・等覚寺門前・天徳院門前・宝蔵院門前**（p3）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571489_{NNNNNNN}.txt` コマ番号。**
- **津久戸前町条の大下水・板橋→石橋化の年次文言〔文言候補・repo初出候補〕（p27-29）**: ①「**町内大下水之義は 西之方白銀町ゟ流来り 往還を横切 東側町家表通を流申候 但幅三尺五六寸程**」＝**大下水（幅3尺5-6寸）は西の白銀町から流れ来て往還を横切り東側の町家表を流れる**。②「**右下水江掛渡シ候往還石橋壱ケ所有之候 近辺御武家方并町内其外最寄町々ニ而出銀修覆仕候 以前板橋ニ而有来掛渡シ有之候由申伝 起立之儀は不弁候得共 享保十己(=巳候補・OCR)年二月類焼致候砌 右板橋焼失致 其後健来(=古板候補・OCR?)え掛渡し候ニ付 古板等ニ而補理置候處 宝暦九年壬(=卯候補・OCR)七月 御道奉行所江願出 石橋ニ掛直し候砌 御見分相済 願之通被仰付候 但し石橋幅七尺長さ五尺**」（p27-28）＝**石橋化の時系列：元禄以前からの板橋（起立不弁）→享保10年（1725・干支はOCR「己」＝巳年候補）2月類焼で焼失→古板で仮補理→宝暦9年（1759・干支はOCR「壬」＝己卯年候補）7月に御道奉行所へ願出て石橋に掛け直し（幅7尺・長5尺）・御見分相済**＝**石橋化の年次・寸法・管轄（御道奉行所）・願出の実務文言repo初出候補**。③「**右同断下水掛渡し有之候 八幡明神前通石橋壱ケ所 右起立之儀は類焼後不弁に御座候 尤近辺御武家方町内其外最寄町々ニ而出銀修覆仕候 但し留(=長候補・OCR)弐間長さ五尺**」（p28）＝**八幡明神（津久八幡）前通の石橋1ヶ所（長2間・幅5尺・起立は類焼後不弁）**＝同一下水系の第2橋。〔**両橋とも大下水＝西から東（白銀町→江戸川方向）の流路を横切る。享保10年2月類焼＝江戸市中の類焼で板橋を焼失させた事件の記憶が橋の変遷の年代アンカーになっている点が橋名調査の年代層として利用可能。宝暦9年＝享保・宝暦期の石橋化（石垣化）潮流の具体的年次datapoint**。干支のOCR崩れ（宝暦九年「壬」＝己卯年・享保十「己」＝乙巳年）はいずれも原画像照合前提**〕。
- **成就院門前条の「小日向冷水番所通大下水」〔文言候補・repo初出の川名候補〕（p42）**: 「**一大下水之義 町内東堺に有之 巾三尺ゟ四尺迄有之 成就院構外ゟ町内江懸り 夫ゟ東え流レ 小日向冷水番所通大下水江流行 江戸川え落入申候 一右下水江飛渡シ有之 町内東角石橋之義ハ 長六尺巾九尺有之 近辺御武家方并町内出銀ニ而懸直シ修復共仕候**」＝**大下水（巾3尺〜4尺）が町内東境にあり、成就院構外から町内に懸かって東へ流れ、「小日向冷水番所通大下水」に合流して江戸川へ落入。町内東角の石橋（長6尺・巾9尺）が右下水に架かる**。〔**①「小日向冷水番所通大下水」＝小日向側の冷水番所を通る大下水の呼称文言repo初出候補**（「冷水番所」＝小日向の上水番所・冷水は玉川上水分水か神田上水かは本冊文言からは確定せず冷水の正体は別史料の照合課題）、②牛込五軒町前系の大下水（GAZ-108系の流路・天徳院門前条（p63）の五軒町大下水と接続候補）の下流側が「小日向冷水番所通大下水→江戸川」という流路文言、③石橋の寸法（長6尺巾9尺）と出銀修復の負担構造。④津久戸八幡・成就院の由緒（津久戸明神は元牛込御門内→元和年間御用地→替地・古門前地、p38-39）と里俗「津久戸片町」（p41）も条の内容**〕。
- **白銀町条の大下水〔文言候補〕（p10）**: 「**大下水町内裏通有之 幅三尺余**」＝**白銀町裏通の大下水（幅3尺余）**。〔津久戸前町条「西之方白銀町ゟ流来」と接続する白銀町側のwitness＝幅3尺余と津久戸前町側3尺5-6寸は近似（同一水路の上流側確認候補・同一視は水路図の照合前提）〕。
- **西照院門前・無量寺門前条の大下水〔文言候補〕（p20）**: 「**大下水之儀 町内家前に有之 内三尺五寸余**」＋「**里俗牛込津久戸仲町与相唱申候**」＝**津久戸仲町（西照院門前＝無量寺門前付近の里俗名）の大下水（巾3尺5寸余）**。
- **天徳院門前条の下水堀→五軒町大下水〔文言候補〕（p63）**: 「**下水堀之儀は 押(=東候補・OCR)之方同所清(=溝?)堤守前ゟ相流 巾弐尺程 家前に有之 夫lrt良之方(=西之方候補)中山備前守様御屋鋪境江埋柱有之 夫ゟ同所五軒町大下水江落候 流末は江戸川御渡申候**」＝**天徳院門前の下水堀（巾2尺）→中山備前守様屋敷境（埋柱）→五軒町大下水→江戸川の接続文言候補**。〔GAZ-108系（松源寺門前・通寺町条＝[6]牛込弐の「山伊名守様御屋敷裏外通ゟ牛込五軒町前大下水江落」文言候補との対校・五軒町大下水系の追加witness**。流末の「江戸川御渡申候」の「御渡」の原字は要照合**〕。
- **等覚寺門前条〔陰性確認・付随文言〕（p49-50）**: 等覚寺往古天神町→元和3年御用地→引移・赤城明神社地内寛永16年門前町屋起立の由緒文言はあるが**大下水・下水系文言は本条に不在（陰性）**。
