# [GAZ-135] 町方書上[144] 巣鴨 — 御駕籠町条の千川上水旧水路文言（安永之頃迄）

- **書誌〔確認〕**: 『町方書上[144] 巣鴨町方并寺院書上』（写・NDL次世代デジタルライブラリー [book/2571625](https://lab.ndl.go.jp/dl/book/2571625)）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571625_{NNNNNNN}.txt` コマ番号。**p29・p34・p43・p60等に見える「古上水跡」は御調書上の設問テンプレ（「古上水跡...所持之者は其訳可相調候事」の質問項目文字列）で実文言ではない（陰性判別済み）。
- **巣鴨御駕籠町条の千川上水旧水路文言〔文言候補・本冊の核心・repo初出の経文言〕（p50）**: 「**古上水跡 且 千川上水と唱 巣鴨町往還通りゟ 巣鴨御馬蔵町 生岡(=片岡・OCR候補・要照合)通り東之方 駒込富士前町通り江掛り候 右安永之頃迄有之候由**」＝**①旧上水の跡で「千川上水」と（今は地跡として）唱える、②巣鴨町往還通りから（始まり）巣鴨御馬蔵町・生岡（片岡候補）通りの東の方を経て駒込富士前町通りへ掛かっていた、③右は安永の頃まであった由**。〔**①千川上水の巣鴨区間の経路を町名・通り名で記す初の町方書上レベルの文言**＝[GAZ-049]（御府内備考・巣鴨仲町条「安永之頃迄有之候由」）と同じ「安永之頃迄」表現の**御府内備考元資料側・隣町（御駕籠町）側の第2 witness**、②「巣鴨御馬蔵町・生岡（片岡候補）通り経由」＝御府内備考の巣鴨仲町条にない経由地の追加（巣鴨区間の流路復元の通路インフラとしての通り名2件。「生岡」の原字は照合まで「片岡」候補のみ併記）、「古上水跡 且千川上水と唱」＝廃止後の呼称（跡地を千川上水と唱える）の用例として[GAZ-082]（古千川上水井戸）・[GOV-456](../gov/GOV-456.md)（旧千川上水）系の層に加わる1826年時点の文言**〕。
- **巣鴨御駕籠町の起立〔文言候補・町の成立の基準点〕（p49）**: 「**右町之儀は 元禄十一寅年四月 御駕籠之者五拾壱人分 拝(=評OCR候補)領町屋敷 且往古之御屋敷下屋敷と而已申伝 御家敷之名不相知候**」＝**元禄11寅年（1698）4月に御駕籠之者51人分の拝領町屋敷として起立、往古は御屋敷下屋敷で御家敷の名は知らない由**（御城ゟ子丑之方凡壱里拾八町）。〔千川上水旧水路文言と同町の成立史＝元禄11年の御駕籠之者拝領町屋敷起立の一次文言候補（要照合）〕。
- **巣鴨町条の下水堀2ヶ所と横切下水・石橋3ヶ所〔文言候補・副次〕（p8-9）**: ①「**下水堀弐ヶ所 幅弐尺程ゟ三尺位迄 右壱ヶ所も巣鴨町下組に有し 向側武家方御屋鋪前ゟ横切下水 巣鴨町家裏通り江相流 夫ゟ同町横町ゟ巣鴨原町江相流申候** 壱ヶ所は同町上中組町屋前(ゟ向側武家方...)」＝**下水堀2ヶ所（幅2尺〜3尺）のうち下組側は武家方御屋敷前から横切下水として巣鴨町家裏通り→同町横町→巣鴨原町へ流れる**、②「**石横切下水 一 石橋三ヶ所 壱ヶ所は下組に有之 長四尺(=四人・OCR候補)巾三間 壱ヶ所は上中組に有之 長四尺余巾四間余 壱ヶ所は横町に有之 長三尺巾六尺**」＝石橋3ヶ所の寸法・所在組。〔巣鴨町（増上寺安国殿料方丈領・延享2年町方御支配化の来历を同条が記す）の下水網・石橋の定点文言候補。巣鴨原町方面へ流れる横切下水の流路方向の記録として谷端川低地（巣鴨原町方面）の下水系の復元資料候補〕。

## 制限・未解決

- ①「生岡」の原字（「片岡」のOCR誤読か独立の通りの字形か）は要原文照合＝巣鴨御馬蔵町周辺に「片岡」と称すべき岡・通りの系譜が独立資料にあるかも併せて照合課題。②「巣鴨町往還」が千川上水（旧水路）の起点側の縁であることの解釈（往還に沿って流れるのか横切るのか）は「江掛り候」の文意から確定できない・流路図（御府内備考や絵図資料）との照合課題。③p8-9の下水堀・石橋の寸法群はOCR崩れ（「長四人」＝長四尺候補等）を含み採録文言は照合前提。④「安永之頃迄」の千川上水の実態（側流の残流か堀跡の残存か）は本文言からは判別できない（[GAZ-049]の文言と同様の解釈上の注意）。
