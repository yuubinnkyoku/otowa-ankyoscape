# [GAZ-150] 町方書上[17] 駒込参 — 富士前町系文言と「相掛らず」陰性3町

- **書誌〔確認〕**: 『[17] 駒込町方書上　参』（写・NDL次世代デジタルライブラリー [book/2571498](https://lab.ndl.go.jp/dl/book/2571498)）。文政10亥年（1827）の地誌御調書上。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571498_{NNNNNNN}.txt`）で示す。※第225回並走実行でdraft化され、第226回で採番・pushした（第225回並走インシデントの回収分）。
- **富士前町条のcross-ref文言〔文言候補〕（p9）**: 「一千川上水跡右委細之義は**駒足肴町**ゟ申上候」＝駒込肴町への委譲文言（「駒足」は「駒込」のOCR崩壊候補）。p9条には日光御成道の当町内分「百五拾円〔=間候補〕程」・道幅四間の文言＝[GAZ-149](GAZ-149.md)浅嘉町条の御定杭文言と同じ日光御成道測量の町別記録が並ぶ。
- **冨士前町条の詳細文言〔文言候補・判読異変あり〕（p18）**: 「一千川上水跡但明和六丑年二月中 浅草田原町小兵衛店忠兵衛 同町嘉右衛門店孫兵衛 高砂町三郎兵衛店幸島〔=幸右衛門候補〕右三人千川上水掛渡奉願 **安永一同十一年**〔=八年十一月廿八日候補〕十一月廿八日御検地御改有之 掛渡出来仕 **天明一寅年**〔=二寅候補〕八月中ゟ水銭小間壱間に付**銭廿八文宛**上納仕 其後同六午年五月中ゟ水銭半減に被仰付 同九月中ゟ**出浅相止**〔=出銀・出桟の判読候補〕 其後埋立被仰付候」＝[GOV-224](../gov/GOV-224.md)・[GAZ-149](GAZ-149.md)と同一の定型工程文の第3・4の書き分け。「安永一同十一年」「天明一寅年」「銭廿八文宛」「出浅相止」の判読の摇摆＝同一定型文の書写・OCRの両面で原字照合が必須な資料群であることを裏付ける。冨士前町条は定型文採用だが「相掛り」語がなく通過の明示は無い。
- **江岸寺門前条のcross-ref文言〔文言候補〕（p27）**: 「一千川上水跡但委細者**騒立肴町**ゟ申上候」（「騒立」も「駒込」のOCR崩壊候補）＝肴町への委譲（同条の坪数文言〔片側町二而南之方弐拾間・間口四拾四間・裏行北之方拾五間・747坪5合〕に続く位置）。
- **上冨士前町条の陰性回答〔文言候補〕（p36）**: 「**一千川上水跡当町えは相掛り不申候**」＝冨士前町（p18）と対になる表記の町名だが陰性回答（検地文言〔宝永御改・「寛永十酉年御改」等〕の直後に置かれる）。
- **七軒町条の陰性回答〔文言候補〕（p44）**: 「**千川上水跡当町江は相掛り不申候**」（え/江の表記差＝同一書記の用字揺れ候補）。
- **妙義坂下町条の陰性回答〔文言候補〕（p68）**: 「**千川上水跡当町えて相掛り不申候**」＝同じく陰性。
- **調査的意味〔観察・推定〕**: この3町（上冨士前町・七軒町・妙義坂下町）は「当町えは相掛り不申候」と明示して否認した町＝千川上水跡の駒込区間経路のマイナス側確定材料。上冨士前町の陰性と冨士前町の定型文採用の対、[GAZ-135](GAZ-135.md)御駕籠町条「駒込富士前町通り江掛り」文言との関係は3つ仮説しか置けない——①「富士前町通り」は町界外の往還を指し上冨士前町・冨士前町いずれにも掛からない、②流路は富士前町〜肴町・片町側にあった、③書上係が陰性町に誤って定型文を配った——いずれも原画像照合と地図対校まで決めない。
