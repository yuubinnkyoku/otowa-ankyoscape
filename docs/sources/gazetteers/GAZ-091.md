# [GAZ-091] 武蔵名勝図会 多摩郡之部巻第1 — 歸方領目録と井の頭・遲野井村の文言候補〔第167回〕

- **書誌〔確認〕**: 植田孟縉稿・小林幸次郎編『武蔵名勝図会』多摩郡之部巻第1（1926〔大正15〕・NDL次世代デジタルライブラリー [book/1172186](https://lab.ndl.go.jp/dl/book/1172186)）。文化期の植田孟縉の原稿を基にした名勝図会の刊本（『江戸名所図会』系の体裁）。**本書のOCRは崩壊が激しく、引用文言はすべて候補で原画像照合が必須。**
- **歸方領目錄の項目群〔確認・文言候補・所在記録〕**: 巻頭の「歸方領目錄」（歸方領＝野方領の異表記候補・原照合要）に**寶仙寺・善福寺川・大宮八幡・野天満宮・砂川道・高圓寺信成殿跡・佐々谷村・石神井道・天沼村妙正寺池・成宗村・江古田村丘墟・善福寺池・沼袋村路宮**等の項目が列挙される＝**野方領（中野・杉並周辺）の寺社・池・道の名勝図会項目の存在記録**〔**善福寺川・善福寺池・妙正寺池（天沼村）・大宮八幡等、repoの四河川周辺の水源地の項目が名勝図会の体系で採録されていることの所在記録（各条の本文の精読は次回以降の課題）**〕。
- **井の頭条の五倍子樹彫刻譚〔確認・文言候補・repo初出〕**: 「**…三代將軍家◯…五倍子樹同將軍家門成の…五倍子樹ヘ〓小柄を以て井ノ頭といふ文字津彫刻ありが基老木と成て有腐せしゆへ甚彫刻の品を代立…**」＝**三代将軍（家光）が五倍子樹（ふしの木）に小柄をもって「井ノ頭」という文字を彫刻させた譚の文言候補**〔**家光の井の頭命名・彫刻譚（repo初出の文言候補）＝井の頭池の名称由来の将軍伝承系（宝仙寺縁起の雄龍説・天海説〔[BOOK-194](../books/BOOK-194.md)〕とは別系統）に加わる候補。「津彫刻」は「彫刻せしめ」等の崩れで、文言の正確な形は原照合要。彫刻板が腐朽して代立（取替え）された旨も読める**〕。
- **遲野井村の村名由来〔確認・文言候補・repo初出〕**: 「**遲野井村古へは尾園と書や小園とも妻けり…古へよ尾固材あるを望地す怪池あしてお人の用あとするーを以て尾園井と唱人けるよし丼の字を加へ**」＝**遲野井村（井頭村）は古くは「尾園」とも「小園」とも書き、古へから尾固材（崩れ・原照合要）あるを望地とし、人の用に供するにより「尾園井」と唱え、井の字を加えた旨の村名由来**〔**①遅野井村の表記が尾園・小園・尾園井と変わる由来説（[BOOK-198](../books/BOOK-198.md)・[BOOK-199](../books/BOOK-199.md)の「小園井村」表記と対照）、②「井の字を加へ」＝井頭の「井」の付加由来譚（repo初出候補）。崩れが著しく文言候補として記録**〕。
- **善福寺川条〔確認・文言候補・第168回追記・本文初回精読〕**: 「**水予は上荻室村善福寺池よし湧出し下萩窪善福寺田 夢成宗を経て大宮八懐山際を流れ川巾一宮半程丼魚よう生るよある僅まあれる水中ましあ水落今す#野野上水ふとき流れとあって**」＝**善福寺川は上荻窪村の善福寺池より湧出し、下荻窪・成宗を経て大宮八幡山際を流れ、川巾一町半程（「一宮半」は「一町半」の崩れ候補）で、（魚が）生じる旨の流路記述**〔**善福寺川の水源（上荻窪村善福寺池湧出）・経由地（下荻窪・成宗・大宮八幡山際）・川巾の条が1822-24年（文化期原稿）の名勝図会で記述されていることの所在記録**。「水落」「野方上水」等の後半は崩壊が激しく、井頭上水（神田上水）への流入系の文言候補と読めるが確定読みは不可。OCR崩壊大・原画像照合必須〕。
- **妙正寺池条〔確認・文言候補・第168回追記〕**: 「**池妙正幸の地といふ廣サ三百坪余め正寺境内心にあり**」＋「**所〓障つけ流れ巾二弓半程ゆるの宮阿佐ヶ谷沿袋之吉田片山堺より豊富郡養合村妙正寺るて井頭上尔ヘ侵入**」＝**①妙正寺池は「妙正寺の地」といい、広さ三百坪余、妙正寺境内中にある旨、②流れの巾（「二弓半」は「二町半」の崩れ候補）と、阿佐ヶ谷方面の地名・「豊嶋郡養（川？）合村」等を挟んで「井頭上水へ侵入（流入）」と読める文言候補**〔**妙正寺池の規模（三百坪余）・境内中にある旨の記録＋流出が妙正寺川として（神田）井頭上水筋へ通じる流路記述の候補**。「養合村」は「石神井川筋の村名」等の崩れの余地が大きく、原照合まで特定しない〕。
- **池袋村条の沼の大蛇譚〔確認・文言候補・第168回追記・repo初出候補〕**: 「**池袋上高中戸のい名とあれり ちち度き沼すて大蛇すみけ〓村民〓ちまつが名祖あるもの苦州出けるはめるいしたしげん大蛇の頭をのて伐善し、蛇蛇死してよ水涸れて今は僅は四方五子ばかり今かせりの真中ハ深さ之七弄金もあといふ**」＝**池袋の地名に続けて、村内の沼に大蛇が住み、村民が退治して蛇が死ぬと水が涸れ、今は僅か四方五間（「五子」は「五間」の崩れ候補）ばかりで、真ん中は深さ七間もある旨の沼の記録**〔**池袋村の池・沼の大蛇譚と「水涸れによる池の縮小」（現況の沼＝四面五間・深さ七間の窪み）の記録候補**。[BOOK-100](../books/BOOK-100.md)（豊島風土記「池袋の池跡と地名のおこり」）や[対照表](../../地名・河川名対照表.md)丸池行（元池袋の池＝弦巻川源流）の池袋の池の系譜に加わる名勝図会側の datapoint（本沼が丸池（元池袋の池）と同一か別地点かは本文言では断定しない）。OCR崩壊大・要原画像照合〕。
