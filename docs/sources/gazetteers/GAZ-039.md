# [GAZ-039] 改正新編江戸志 — 掃部橋由来・麁栗橋の橋名由来文言群

- **書誌〔確認〕**: 『改正新編江戸志』[10]（天保3〔1832〕・東武懐山子輯著・写本。小石川周辺の橋の由来を記す地誌）。NDL次世代デジタルライブラリー [book/2545221](https://lab.ndl.go.jp/dl/book/2545221)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **掃部橋の由来文言〔確認・掃部橋由来系譜の独立テキスト（repo初出）〕**: 「**○掃部橋古川町ゟ水道町へ渡す昔此所に吉岡掃部といふ紺屋あるゆへ名とすと也**」〔**①掃部橋の接続（古川町〜水道町）が天保3年時点で明記されること、②「昔この所に吉岡掃部という紺屋があったため名とす」という人名由来説が地誌レベルで記録されること**＝**掃部橋の「吉岡掃部紺屋」由来説の独立テキスト（repo初出）。井伊掃部頭説（掃部ヶ橋の語源として広く流通する説）に対し、「紺屋の吉岡掃部」説という**異系統の由来説**が天保3年の時点（変災編の文政12年流失〔[BOOK-126](../books/BOOK-126.md)〕と嘉永の銘書〔[GOV-220](../gov/GOV-220.md)〕の間）の地誌に存在したことを確認**。由来説の系譜（どちらが先で、互いにどう影響したか）は本資料単独では確定できない（断定しない・要照合）〕。
- **古川橋＝俗「麁栗橋」〔確認・麁朶橋の別字形（repo初出のvariant）〕**: 「**○古川橋俗に麁栗橋といふそゞ町ゟ水道町へわたす也**」〔**①古川橋の俗名が「麁栗橋」と記されること（「そゞ町」は袖ヶ町・惣持町等の崩れか・要照合）、②**「麁**朶」橋（[BOOK-126](../books/BOOK-126.md)小石川区史等の表記）に対する**「麁栗」橋**という別字形が天保3年時点で存在したこと**＝**第108回課題②（麁朶橋の原字形問題）に新変種を追加する資料**。麁栗（あらぐり・そぐり）・麁朶（あらだ）の表記ゆれの実態（どちらが原形か・「そゞ〔そだ〕町」の表記との共鳴関係にあるか）は原文照合と諸本の対校が必要（[GAZ-040](GAZ-040.md)の江戸志〔[book/2563424](https://lab.ndl.go.jp/dl/book/2563424)〕では「麁朶橋」と読める文言があり対校可能）〕。
- **丸丁目橋・江戸川橋・大橋の文言〔確認・九丁目橋・名残橋の由来〕**: ①「**○丸丁目橋音羽町九丁目ゆく橋也**」（**丸丁目橋＝九丁目橋のOCR誤読（「音羽町九丁目〔へ〕ゆく橋」）である可能性が高く、九丁目橋の初出文言に対応する・要照合**）、②「**○江戸川橋俗に名残橋と云昔一休名残蕎麦といふ有故に俗名付**」（**江戸川橋＝俗名残橋・「一休名残蕎麦」という店（蕎麦屋）に由来する俗名説**＝名残橋由来の一次文言（repo初出））、③「**○大橋俗に石切橋といふ赤城下へ行通り也馬場片町ゟ水道町へわたす…むかし此所に石切あるよりの名也**」（**石切橋の由来（石切職人の居住）・馬場片町〜水道町の接続**＝[GOV-213](../gov/GOV-213.md)の古川橋・江戸川橋と併せ、小石川の神田上水筋の橋の由来文言が本書1冊で丸ごと揃う（repo初出の由来文言群）**〕。
- **位置づけ〔観察〕**: 小石川の神田上水（江戸川）沿いの橋（江戸川橋・掃部橋・古川橋・大橋〔石切橋〕・中の橋・九丁目橋）の由来が「人名（吉岡掃部・石切）・店名（名残蕎麦）・地形（九丁目）」の型で記される地誌記述として、橋名由来の系譜（享保期の江戸誌系〔[GAZ-040](GAZ-040.md)〕→天保3の本書→明治の東京市史稿橋梁篇〔[BOOK-126](../books/BOOK-126.md)〕）の中間点に位置する。**「吉岡掃部紺屋」説と「井伊掃部頭」説の二系統の由来説のうち、前者の最も古い（確認できる）テキストの一つになる可能性がある**（本書が享保の江戸志（[GAZ-040](GAZ-040.md)）の引き写しか独立の採訪かは、両者の文言の対校（次回課題）で判断する）。

## 第158回追記（2026-11-17・別写本候補[6]（book/2545217）の藤橋＝俗に乞食橋・諸橋の根子説・虎ヶ橋元禄初架文言）

- **藤橋＝一名崩橋＝俗に乞食橋〔確認・文言候補・repo初出の乞食橋名の江戸期文言候補〕**: 『改正新編江戸志』の**別写本候補[6]**（[book/2545217](https://lab.ndl.go.jp/dl/book/2545217)・10巻本・河合孫太郎写〔識語候補・要照合〕＝本登録冊[10]（[book/2545221](https://lab.ndl.go.jp/dl/book/2545221)）と同書名の写本）に「**藤橋 庚申塚の手ゆへ大塚の先巣鴨本村也 一名崩橋といふ 俗に乞食橋といへるは寔の名にあらす**」と読める文言候補＝**①藤橋の位置（庚申塚の手〔庚申塚より手前側〕・大塚の先・巣鴨本村）、②一名「崩橋」、③「俗に乞食橋といへるは実（寔）の名にあらず」という注記**。〔**①乞食橋名の江戸期の記録候補（repo初出）**＝[BOOK-186](../books/BOOK-186.md)（1935年書籍の「明治18年架橋の際は藤橋と書いてあった・大正11年改築の際富士橋と改めた」改称史）・[BOOK-109](../books/BOOK-109.md)（1922年改築）の**明治期の「藤橋」に先行する、江戸期の「藤橋」文言候補**、②「俗に乞食橋（＝実名でないとする注記）」＝谷端川の巣鴨側の乞食橋の俗呼の背景を江戸期に遡らせ得る記録候補。**ただし本条の藤橋は「小石川にかゝる」（次項の諸橋条の冒頭文言参照）と記される橋で、明治18年架橋とする谷端川の藤橋〔BOOK-186〕と同一橋か（同一なら呼称の連続が江戸期まで遡る）別橋か（別なら江戸期の藤橋名の明治期への再使用か）は本文言からは未決着で、断定しない**（石神井川下流〔小石川〕と谷端川の流路の関係＝巣鴨本村・大塚の先の位置は谷端川合流点附近とも読め得るが、位置の確定は原画像照合・地図対照を要する）。**④写本の系統**: 2545217（[6]）と2545221（[10]）は同書名の別写（または同書の異巻）候補で、両写の当該条の異同の対校は次回課題。〕
- **「諸橋」の根子説＝ねこまた橋の根子説の橋名分裂〔確認・文言候補〕**: 「**諸橋 小石川にかゝる藤橋の下の方なり 南向条話（南向茶話の崩れ候補）に云 此地の農民の説に 昔は今ゟ流細くして田畑の通ひ道にて 木の根子を以橋に渡すゆへの名也 土民は木の根本を根子と唱ふ也**」と読める文言候補＝**藤橋の下の方の小石川に架かる「諸橋」に、木の根子（木の根）で渡したことに由来する橋名説（南向茶話引用）が付く**。〔**[GAZ-083](GAZ-083.md)（小石川志料）が「ねこまた橋」に付したのと同一系統の「根子」語釈（南向茶話引用の文言）が、本写本では「諸橋」という別橋名に付く**＝**根子説の橋名の分裂**（ねこまた橋〔GAZ-083〕・根子股橋〔[GAZ-070](GAZ-070.md)〕・諸橋〔本条〕）＝南向茶話系の語釈の採録の過程で橋名が混在した可能性の候補（「諸橋」が「ねこまた橋」の別表記か誤記か、別橋かの判定は原画像照合・対校まで保留）。**〕
- **祇園橋・虎ヶ橋・八千橋・鍋割坂・藤橋稲荷社の文言候補〔確認・文言候補〕**: ①「**祇園橋 小石川に渡すねこまた橋の並ひ也 里談に云 此橋は木村氏と伝通院の知行交りしゆへ両方ゟかくるといふ 江戸砂子に氷川は奈盛烏尊（素盞鳴尊のOCR崩れ候補）ゆへに此はしを祇園橋と記す**」＝**[GAZ-083](GAZ-083.md)の祇園橋里談（木村氏と伝通院の知行交り）の対校文言（本写本では江戸砂子の素盞鳴尊〔氷川神〕に由来する祇園橋名の説と併記）**。②「**虎ヶ橋 大原町ゟ御駕籠町へ出る四辻の石橋をいふ 是は元禄寅年初てかけそめしゆへ橋の名とすと也**」＝**虎ヶ橋（大原町〜御駕籠町の四辻の石橋）の元禄寅年（1693）初架年代記録候補（repo初出候補）**＝虎ヶ橋（小石川の神田上水筋の橋〔[BOOK-126](../books/BOOK-126.md)橋梁篇系〕）の初架の年次 datapoint 候補（元禄寅年＝元禄6年1693・干支は整合するが実字照合を要する）。③「**八千橋**」（天神山の南・盆山のすり鉢説の文言候補）・「**鍋割坂**」（ねこまた橋から上る坂・鍋を落とし破った説の文言候補）・「**藤橋稲荷社**」（真性寺持・当所の鎮守の文言候補）＝小石川筋の橋・坂・社の由来記録の候補群（各文言の確定は原画像照合まで保留）。



- ①「麁栗橋」「そゞ町」「丸丁目橋」の正確な字形・読みは要原文照合。②[GAZ-040](GAZ-040.md)（江戸志・麁朶橋）との文言の対校（引用関係の有無）は未実施。③「一休名残蕎麦」の店の実在の傍証（他史料での言及）は未確認。
