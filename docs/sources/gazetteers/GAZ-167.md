# [GAZ-167] 町方書上[103] 本所町方書上 二 — 小泉町御用屋敷条の本所上水請負人・埋樋文言群

- **書誌〔確認〕**: 『[103] 本所町方書上 二』（写・NDL次世代デジタルライブラリー [book/2571584](https://lab.ndl.go.jp/dl/book/2571584)。NDL API volume欄直接確認）。本所小泉町御用屋敷条（koma 55-60他）・南町条（koma 68）。文政十一子年九月名主長兵衛署名（koma 60）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号。※本所上水（亀有上水・白堀上水）の末端実務の文言群として[GAZ-138](GAZ-138.md)に接続する資料。
- **本所上水白堀系の受負人群文言〔文言候補・本冊最重要〕（koma 55・58・60）**: ①「**右場所一圓…北側百五拾弐坪余之場所は元禄十一寅年三月 本所上水白堀浚受負人拝借地ニ相渡り…**」（koma 55・OCR・後半）＝ **元禄11年（1688）3月・本所上水の白堀浚受負人の拝借地**、②「**元禄十一寅年三月十四日…本所御奉行鈴木兵九郎様鳥井久五郎様ゟ本所上水白堀定渡受負人善六為 助成地拝借被仰付候処**」（koma 58・OCR）＝**白堀定渡受負人・善六為（人名）の助成拝借**、③「**…元禄十三辰年十一月…本所埋樋受負人物借地…**」（koma 55・OCR・後半）＝**元禄13年（1700）11月・埋樋受負人物借地**、④「**…本所埋垣受負人清六為 助成地拝領被仰付候処 享保四亥年四月三日本所御奉行相止 町御奉行大岡越前守様御勤役之節上り地に相成 町方御支配本所方御掛御用地に相渡り**」（koma 60・OCR）＝**埋垣受負人・清六為の助成拝領地が享保4年（1719）4月3日の本所奉行廃止で上り地化**の文言候補。〔**「本所上水白堀浚受負人」「白堀定渡受負人」「埋樋受負人」「埋垣受負人」という上水施設ごとの請負人職名の体系的列記（repo初出候補）**。しかもその受負人の拝借・拝領地の結末が享保4年奉行廃止（上り地化）まで記録される＝**万治2給水開始（[GOV-171](GOV-171.md)）→元禄11-13年の請負実務層→享保4年奉行廃止→享保7年9月差止（[GAZ-138](GAZ-138.md)）という本所上水の管理系譜の中間（元禄期の実務層）を埋める文言**。白堀（堀の型）・定渡・埋樋・埋垣の施設分類ベースの記録として、神田上水系の白堀・万年樋の呼称群（[GAZ-141](GAZ-141.md)）と対照可能。〕
- **本所中下水埋樋拾弐ヶ所の番人文言（koma 68）**: 「**…本所中下水埋樋拾弐ヶ所番人附置明立仕候に付右為助成 宝永四亥年四月十日本所御奉行三割（?）縫殿助様小笠原外記様ゟ本所…**」（koma 68・OCR）＝**宝永4年（1707）4月10日、「本所中下水」の埋樋12ヶ所に番人を附置した際の助成地文言**の候補。〔「中下水」の埋樋（伏越・暗渠樋）が12ヶ所という**埋樋数の一次数値と番人制度**（[GAZ-167]の小泉町側のみで全体の配置は未確定）。「三割（?）縫殿助様」は判読不能（三浦?・縫殿助）で要照合。〕
- **享保4年奉行廃止後の御用屋敷の転用文言（koma 68・前半）**: 「**享保四亥年四月三日…大岡越前守様御掛に而拝借地被召上 右場所一圓本所方御用屋敷ニ相成 本所道役両人御預りに被仰付候所 文化六巳年九月中小田切土佐守様御番所二而中之郷竹町船渡請負人次郎左衛門え為助成右御用屋敷受負…**」（koma 68・OCR）＝享保4年召上げ後の本所方御用屋敷が文化6年（1809）には中之郷竹町の船渡請負人の助成に転用された文言候補＝上り地→御用屋敷→用途転替の年代チェーンの末端。〔[GAZ-165](GAZ-165.md)の道役（清水八郎兵衛・家城善兵衛）の御預り文言と同名の「本所道役両人」で対応。〕

## 制限・未解決

- ①すべてOCR由来で要原文照合（「善六為」「清六為」「三割縫殿助」「物借地」「白堀定渡」等の判読候補。「為」は「為(ため)」=人名の一部かformat名かは未確定でそのまま表記）。②白堀浚・白堀定渡・埋樋・埋垣の4受負人の同一人物・別人物の別は本冊からは確定しない。③「本所中下水」の水路の比定と12ヶ所埋樋の配置は未確定。④koma 55の「東側弐万八拾壱坪五合」は坪数として過大でOCR崩壊（「弐千八拾壱坪」等の候補）＝照合前提。
