# [GAZ-154] 町方書上[4] 市谷参止（文政10亥年）— 桜川・楓川文言群の元資料側witnessと三軒屋敷条の石橋

- **書誌〔確認〕**: 『[4] 市谷町方書上　三止』（写・NDL次世代デジタルライブラリー [book/2571485](https://lab.ndl.go.jp/dl/book/2571485)）。文政10亥年（1827）五月付けの地誌御調書上で、市谷本村町・市谷三軒屋敷・市谷安養寺門前・市谷坂下茶王寺門前・市谷修行寺門前・市谷自詫院門前等を収録（修行寺門前条末尾に「文政十亥年五月 市谷修行寺門前名主次郎左衛門」の署名が見える）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571485_{NNNNNNN}.txt`）。同時採録の市谷系冊は[GAZ-153](GAZ-153.md)（[2]市谷壱）。
- **市谷修行寺門前条の饅頭谷・桜川・楓川文言＝元資料側witness〔文言候補・本冊最重要〕（p112-120）**: 「**（南之方武家方屋敷ヲ堰〔=擁のOCR崩れ候補〕 四ツ谷湯屋横丁往来下通リ 小川二流有之候中二而当時明地ヲ饅頭谷ト相唱申候 右由来ハ往古年代不知 素性庵与群候〔=与棲候補・OCR〕 庵室壱軒右地所ニ有之候由 依之其頃近辺里俗ニ〔饅頭谷ト〕唱候由 町内申伝ニ御座候**」（p118付近）＋「**巾五尺程 前書饅頭谷右東之方石橋左右ヲ桜川ト相唱 水上四ツ谷御上水之分水ニ而同所大木戸田安様御下屋敷内御泉水江落込 御同屋敷裏武家方構前通リ右饅頭谷江相流 夫ゟ御先手頭万年七郎左衛門様御組同心組屋敷裏通リ 市谷本村町後口楓川江落込申候 且桜川ト唱候由来ハ前書素性菴前通リ流候ニ付 三十六歌仙ニ有之素性法師詠哥之心ヲ以名付候由 右流末ヲ楓川ト唱候義 市谷田町通大下水ニ至リ柳川之唱候由二付 前後ニ榊桜之名目有之候間 錦ト申義理二而川之名目付候由 町内申伝ニ御座候**」（p118-119・OCR）＝**①饅頭谷＝四ツ谷湯屋横丁往来の下通りの小川が二流する中の明地。往古・年代不知に素性庵（庵室壱軒）があったことに由来する、②桜川＝饅頭谷東之方の石橋の左右の川の呼称。水源は四ツ谷御上水の分水で大木戸の田安様御下屋敷内の御泉水へ落込、御屋敷裏の武家方構前を通り饅頭谷へ相流れる、③桜川の名は素性庵の前を流れるにより三十六歌仙の素性法師詠歌の心で名付けた 由、④流末は市谷本村町後口で楓川と唱え、市谷田町通の大下水に至って柳川と唱う。前後に柳・桜の名目があるゆえの「錦」の義理で川の名目を付けた**という文言群候補。〔**この文言群は[GAZ-110](GAZ-110.md)（御府内備考市谷巻・修行寺門前条）が採録した文政書上そのものの側（元資料側）の文言確認で、対校すると御府内備考OCRの判読を複数の点で改良できる**＝①「御先手頭万年**七郎左衛門様**御組同心」（[GAZ-110]のOCR「万年**彦(?)清左衛門様**」→本冊では「七郎左衛門様」）、②「三十六歌仙ニ有之素性法師**詠哥之心**ヲ以名付」([GAZ-110]「詠歌**之名**ヲ以名付」→本冊「**之心**ヲ以名付」)、③「御泉水**江**落込」等の原文（御府内備考の当該頁の原画像照合で最終判定前提・孰れもOCR由来で断定しない）。名チェーン（桜→楓→柳川の錦の義理）・流路（四ツ谷御上水分水→田安様御泉水→饅頭谷→御先手組屋敷裏→本村町後口楓川→田町通大下水〔柳川〕）自体は[GAZ-110](GAZ-110.md)・対照表の桜川行の従来記録と整合する。〕
- **同条の石橋文言〔文言候補〕（p119）**: 「**一石橋壱ケ所 長五尺程 巾六尺程 右場所ハ饅頭谷東之方桜川ニ拙渡〔=掛渡のOCR崩れ候補〕有之 新規掛渡シ修復等年代不知 右近辺寺院持場二御座候**」＝**饅頭谷東之方の桜川に掛かる石橋（長5尺程・巾6尺程・掛渡、新規掛渡し・修復の年代は不知・近辺寺院持場）**という文言候補。〔桜川の掛渡（石橋1ヶ所）の構造・維持責任（寺院持場）の記録。[GAZ-110](GAZ-110.md)側の石橋記録の対校部材。橋名は無之。〕
- **市谷三軒屋敷条の源慶寺持添御年貢地内の下水→桜川落込文言と植木屋平蔵前の石橋〔文言候補・repo初出候補〕（p90-97）**: 「**…内池ゟ相流 前書源慶寺持添御年貢地内下水江流 自證院門前後え通リ 桜川江落込申候 尤下水之名無御座候 一石橋壱ケ所 右ハ植木屋平蔵前ニ有之 巾六尺 長三尺程 新規掛渡 年代相知不申候 尤持場之義ハ近辺武家寺院町方持ニ御座候 但石橋名無御坐候**」（p97・OCR）＝**市谷三軒屋敷条の内池から相流れる下水は源慶寺持添の御年貢地内の下水に流れ、自証院門前の裏を通って桜川へ落込む（下水の名は無之）。植木屋平蔵の前に石橋1ヶ所（巾6尺・長3尺程・新規掛渡・年代不知・近辺は武家・寺院・町方持・橋名無之）**という文言候補。〔**桜川の流路に三軒屋敷・源慶寺地内の無名下水が合流するという位置記録＝[GAZ-110](GAZ-110.md)修行寺門前条の流路チェーン（四ツ谷御上水分水→…→桜川→楓川→柳川）の上流側の給水構造を補う文言候補。三軒屋敷側から桜川へ寄せる水路の記録としてはrepo初出**（「桜川江落込」の解釈＝桜川への合流で、同条の内池・源慶寺地内下水の位置の特定は要原画像・地図照合）。〕
- **大木戸・田安様御下屋敷の御泉水（桜川の水源）の傍証構造〔文言候補・参考〕（p118）**: 上掲の通り水源を「**水上四ツ谷御上水之分水ニ而同所大木戸田安様御下屋敷内御泉水江落込**」と記す。〔**四ツ谷大木戸内の田安様（田安御三家）御下屋敷内の御泉水を経て市谷側へ流れるという、[GAZ-110](GAZ-110.md)・[GAZ-112](GAZ-112.md)（四谷伝馬町条の榎川・杉川＝内藤様御下屋敷内流出）と同型の「武家屋敷内の泉水経由」型の給水構造の文言**＝御屋敷内泉水の放水が周辺の川の名の水源とされる事例の追加。〕
- **市谷本村町・自詫院門前等のその他の文言〔文言候補・参考〕**: 市谷本村町条（冊頭・p1-）に「**巾四尺 町内裏通相流 市谷田町通 船行原橋流**」（p5-6付近・OCR・「船行原橋」は船河原橋のOCR崩れ候補）＝本村町の裏通りの小流（巾4尺）が田町通の船河原橋流へ相流れる途中の流路文言候補。自詫院門前条に「寛文元辛丑年 自詫院建立之節 当時門前百姓地ヲ尾州様ニ而御買上ニ相成 自澄院殿御墓所為御掃除役御寄附罷成候由 享保十九寅年 寺社御奉行井上河内守様ニ而町并家作御免被仰付候処…」の沿革（OCR）＝自詫院（自証院）門前の起立沿革の補助。〔水系の直接情報は薄いが、本村町後口の楓川・田町通大下水（柳川）の両側の町の実務側の記録として参考。〕
