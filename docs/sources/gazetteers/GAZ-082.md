# [GAZ-082] 大日本地誌大系 第1巻 所収「御府内備考」活字版 — 千川上水の市中実務の諸相（桝・樋・水銭・井戸・千川屋鋪）

- **書誌〔確認〕**: 『大日本地誌大系 第1巻』（雄山閣、1929）所収「御府内備考」巻之八〜十四の**活字版**（江戸の町・寺社の書上を集成した三浦淨心系の地誌）。NDL次世代デジタルライブラリー [book/1214847](https://lab.ndl.go.jp/dl/book/1214847)。写本系の [GAZ-024](GAZ-024.md)（1214857）・[GAZ-041](GAZ-041.md)〜[GAZ-045](GAZ-045.md)（2553666・2553672等）と対照する活字版側。**引用文言はすべてOCR由来で要原文照合**（写本系の文言との異同の確認に特に有用）。
- **神田旅籠町壹丁目の昌平橋通四ツ角の大桝〔確認・[GAZ-043](GAZ-043.md)の帰属未確定の解決〕**: 「**町內昌平橋通四ツ角に大桝壹ケ所、井同所續東の方横町角に同壹ヶ所、町內中通に小桝三ケ所…天明七未年四月十三日御差止めに相成其儘掘立**」＝昌平橋通四ツ角の大桝文言が活字版では**神田旅籠町壹丁目条**に置かれる＝[GAZ-043](GAZ-043.md)（丁亥書上・2553672）で帰属未確定だった同文言の町帰属が活字版で確認できる〔観察〕。なお活字版は「其儘**掘立**」、写本系[GAZ-043](GAZ-043.md)は「其侭**埋立**」で字が異なり、取潰し後の処理（掘り残しか埋め立か）の異同として要照合（断定しない）。
- **平永町の埋小樋〔確認・[GAZ-044](GAZ-044.md)制限③の部分解消〕**: 「**安永九子年十月二十七日…町內往還南北中通京間拾七間四尺八寸六分、北の方往還八十四間貳尺四寸貳分程往還中程に埋小樋掛ケ渡**」＝平永町の往還中程の「埋小樋」（暗樋）の文言が活字版で確認でき、[GAZ-044](GAZ-044.md)の制限③（文言の所在が写本で不明瞭）を部分解消。
- **佐久間町・久右衞門町の丁目内訳〔確認・[GAZ-042](GAZ-042.md)制限②の部分解消〕**: ①佐久間町3丁目「**町內河岸通東西七拾壹間程小樋往還中程に埋、和泉橋際に桝壹ケ所**」・4丁目の大樋＋西角大桝＋隣町境小桝、②久右衞門町1・2丁目の藏地新橋際の樋・桝＝丁目ごとの樋・桝の配置の内訳が活字版で確認できる。
- **下谷之部丙戌書上の千川上水文言群〔確認・[GAZ-041](GAZ-041.md)（2571554）系の文言と同型〕**: 下谷長者町續・正法院門前・仁王門前等に「**安永八亥年中千川上水相掛候得共無程相潰れ**」文言群（写本2553666〔[GAZ-044](GAZ-044.md)〕所収の[85]と同じ文言の活字版側）＝**下谷側は安永8年（1779）に千川上水が掛渡され、程なく潰れた**旨の町側記録。
- **上野山下の水銭記録〔確認・repo初出の市中側水銭 datapoint〕**: 上野山下条「**右は天明六午年正月町內道幅中程え千川上水の樋御座候。よりと相見へ、町入用押切帳面に正月分より水錢月々四百四文宛、同年十月迄差出し來り候得共**」＝**天明6年（1786）正月から10月まで、上野山下の町が千川上水の樋の分の水銭を月々404文ずつ町入用から差し出していた実務記録**（「よりと相見へ」の解釈は要照合）〔**千川上水の市中側の水銭額・納入期間の具体値。[GOV-224](../gov/GOV-224.md)（駒込側の水銭28文/月）と対になる下谷・上野側の水銭の記録で、月額・期間ともに初出**〕。※帰属町名（上野山下・くらやみ横町等の呼称関係）は要照合。
- **浅草之部乙酉書上の千川上水井戸〔確認・差止日の併記 datapoint〕**: ①上平右衞門町河岸1ヶ所・下平右衞門町河岸2ヶ所、②旅籠町1丁目代地2ヶ所・2丁目代地1ヶ所（「**天明七未年四月十二日御差留**」）、③天王町「**井戸壹ケ所も無御座候**」＝**文政8年（1825）乙酉書上の浅草側の千川上水井戸の残存記録**。※旅籠町の差止日が乙酉書上では**四月十二日**、[GAZ-043](GAZ-043.md)（丁亥書上）では**四月十三日**で1日差がある〔観察・調年の異なる書上の粒度差の候補。どちらが正かは本資料群では断定できない〕。
- **南茅場町の里俗呼名〔確認・千川屋敷（八丁堀）の書上レベル裏付け〕**: 巻之八「**南茅場町 里俗呼名千川屋鋪。裏茅場町。二ヶ所共裏通を云**」＝八丁堀の南・裏茅場町付近に「千川屋鋪」の里俗呼名があった町側書上の記録＝[対照表](../../地名・河川名対照表.md)（千川屋敷（八丁堀）行）への書上レベルの裏付け。
- **千川上水総説の活字版直接確認〔確認〕**: 総説（三浦淨心系）に「**元祿年中千川上水を作らしめられしが享保七年此四ケ所の上水は皆廢せられたり。その後安永九年再び千川上水を下谷·淺草邊まで掛渡されしに、幾ほどもなく天明六年廢せられたり**」＝元禄開削→享保7年（1722）四上水廃止→安永9年（1780）再開→天明6年（1786）廃止という通時的な千川上水史の記述の**活字版での直接確認**（既出の写本系・二次文献経由の内容の原典レベル確認）。
- **対照写本の所在〔確認〕**: 写本 [GAZ-044](GAZ-044.md)（2553666・巻8-10）・2553667（巻13-15）は活字版の対照系統として本条の検証に使用（独立ファイル化せず本ファイル内で言及）。

## 制限・未解決

- ①活字版の編集（1929）に際して写本間の異同が整理されている可能性があり、帰属町名・字句の最終確認は各写本・原町書上との照合が前提（「掘立/埋立」「四月十二日/十三日」の異同はその典型）。②上野山下の水銭文言の「よりと相見へ」の解釈、水銭404文の支払先（上水方か樋管理者か）は本条では確認できない。③浅草乙酉書上の井戸が千川上水の直接給水井戸か（伏流水・残余水か）は文言上「千川上水井戸」と記されるが、給水経路の実態は要考察。④「上野山下」の町域（くらやみ横町との関係）は要照合。
