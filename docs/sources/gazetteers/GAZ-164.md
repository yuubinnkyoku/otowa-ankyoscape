# [GAZ-164] 町方書上[9] 牛込町方書上 五（文政10亥年）— 牛込水道町条の江戸川名義と石切橋の文言

- **書誌〔確認〕**: 『[9] 牛込町方書上 五』（写・NDL次世代デジタルライブラリー [book/2571490](https://lab.ndl.go.jp/dl/book/2571490)。NDL目録volume表記「[9] 牛込町方書上 五」・直接確認）。牛込馬場先片町（p5-15）・牛込隠家片町（p16-27）・牛込水道町（p28-52）・牛込水道町久右衛門店本七（=本七家・OCR候補）明王院修験（p53-77）・牛込改代町東福院（p78-86）の各町条・条末署名は「文政十亥年」（p14・24・27・41・52・55・68・81等・OCR）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571490_{NNNNNNN}.txt`）。※江戸川（神田川の牛込区間の旧名）は当repo四河川のいずれでもないが、[GAZ-105](GAZ-105.md)/[GAZ-109](GAZ-109.md)御府内備考江戸川条・牛込水道町条の元資料側（文政地誌御調書上側）のwitnessとして採録する。
- **牛込水道町条の江戸川名義文言＝御府内備考の元資料側witness〔文言候補・本冊最重要〕（p35-36）**: 「**一江戸川ゟ唱候川有之 往古田畑之用水ニ而古川ゟ相当（=留・p35/p36でOCR表記が分かれる）申候処 万治年中より江戸川ゟ相唱候由申伝候 尤水上ハ武叶（=州・OCR候補）多摩郡吉祥寺村井ノ頭弁才天之池ゟ流出 関口二而神田御上水ヨリ分水仕 尤小日向水道町ゟ町内地所ニ移リ 土地之南方ゟ御極（=水・OCR候補）三間程相流レ 御武家方屋敷之方え流行申候 川巾凡拾間余不同有之候**」（p35・p36に同型文言が連続・OCR）＝**①「江戸川」の名義の文言＝往古は田畑の用水で「古川」と相当（=呼ばれた・OCR表記はp35「相当」/p36「相留」に分かれる）ところを万治年中（1658-1661）より「江戸川」と唱える由の申伝え、②水上は武州多摩郡吉祥寺村井ノ頭弁才天の池から流出し関口で神田御上水から分水し、小日向水道町の町内地所に移り南方へ流れ武家屋敷方を流行する、③川巾凡10間余（不同あり）**の文言候補。〔**[GAZ-105](GAZ-105.md)御府内備考江戸川条の「往古古川→万治年中江戸川改称」説と[GAZ-109](GAZ-109.md)御府内備考牛込水道町条（対岸側の対校とrepoで扱った文言）に対し、文政10亥年（1827）の牛込水道町の地誌御調書上がほぼ文言対応の記述をもつ＝御府内備考の江戸川名義文言の系譜（文政地誌御調書上を底本とする系）を裏付ける元資料側のwitness候補（repo初出）**。江戸川＝神田川の旧名論の一次側実例として採録。なお「御極三間」は「御水」のOCR候補（水路巾か水位か）で照合前提。〕
- **江戸川大橋＝里俗「石切橋」の明瞭文言〔文言候補・判読問題の解決方向〕（p37）**: 「**一橋之儀ハ 町内ゟ小日向水道町江渡ル候板橋ニ而 凡長八間程 巾凡弐間壱尺程有之 江戸川大橋ゟ相唱申候 又里俗ニ者石切橋共唱来リ候 訳相知不申候 尤御役所ヘ向えハ江戸川大橋ト相認メ申候 右ハ御武家様方御組会（=組合・OCR候補）普請ニテ 町内ゟモ出銀差出シ来リ申候**」（p37・OCR）＝**①江戸川大橋の構造（板橋・長約8間・巾2間1尺）と牛込水道町から小日向水道町へ渡る位置、②正式呼称「江戸川大橋」と里俗「石切橋」の並記、③里俗名義の理由は知れないこと、④御役所向けには江戸川大橋と認めること、⑤御武家様方の御組合普請で町内も出銀を出したこと**。〔**「石切橋」の語が本冊のOCRでは明瞭に読める＝[GAZ-109](GAZ-109.md)御府内備考牛込水道町条で「石切損」と読んだ箇所の判読問題（石切橋か）の解決方向を与える元資料側の文言候補**。石切橋（江戸川=神田川に架かり牛込水道町と小日向水道町を結ぶ橋の里俗名）の位置・構造記録。[GAZ-105](GAZ-105.md)関口の神田御上水の板橋＝里俗「上路橋」と並ぶ江戸川系の橋の里俗名の用例増補としても意味がある。〕
- **大橋掛直し普請の仮板橋文言〔文言候補・実務記録〕（p38）**: 「**右大橋掛直シ普請有之候節ハ 当町内小日向水道町両町ゟ町御奉行様江奉願上 右橋臺地際ゟ川下モ東ノ方え八間住鋪リ 巾三尺余 長八間程行様相付 仮板橋ニ而壱人立往来仕来リ申候 但入用之儀ハ両町ニテ差出来申候**」（p38・OCR）＋石橋4ヶ所（「町内中程西横町大下水」「南方四ツ辻小下水」等・巾・丈の文言）の文言＝大橋の掛直し普請の際の仮板橋（川下東方に8間を敷き巾3尺余・1人立往来・両町の入用）の実務文言候補。〔江戸川大橋の修繕手続き（町奉行への願上・両町負担）の実務記録。仮橋の構造（幅3尺余の1人立）は江戸の橋の修繕実務の参考記録。〕
- **牛込水道町の検地・出自文言〔文言候補・参考〕（p40）**: 「**一御検地之儀ハ 寛文十二子年九月廿八日 野村彦太夫様御手代平田作右衛門様梅村伝左衛門 次御名前之水帳壱冊御座候 表書ニ武州豊嶋郡牛込水道町屋敷改水帳案内庄兵衛八右衛門幷紙数八枚…**」（p40・OCR）＝寛文12子年（1672）9月28日の野村彦太夫（御手代 平田作右衛門・梅村伝左衛門）の検地水帳（表書「武州豊嶋郡牛込水道町屋敷改水帳」）の現存文言候補。〔**「牛込水道町」という町名自体が関口神田上水の分水（水道）に由来する（=水道町）文字通りの出自を示す町の、寛文12年の検地帳の表書文言**＝江戸川・神田御上水の水系史（水道町の構造）の一次側参考記録。〕
