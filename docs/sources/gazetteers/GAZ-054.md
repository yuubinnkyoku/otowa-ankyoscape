# [GAZ-054] 御府内場末往還其外沿革圖書 第20部貮拾利 分冊[26] — 音羽・桜木・関口村東南之方の嘉永7年地所書上の本文精読

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書』**第20部 貮拾利 分冊[26]**（嘉永7〔1854〕寅年十月調・幕府普請奉行編纂・全163コマ）。NDL次世代デジタルライブラリー [book/2587246](https://lab.ndl.go.jp/dl/book/2587246)（NDLデジタルコレクション [PID 2587246](https://dl.ndl.go.jp/pid/2587246)・DOI 10.11501/2587246・IIIFマニフェストで書名・書誌ID 000007328931を確認済み）。**史料群全体の同定・分冊対応・表紙文言（桜木町・音羽町・東西青柳町・大塚・小石川村・同字新田・巣鴨村・小日向村・関口村・雑司ヶ谷村・高田村・下高田村一円）は[GAZ-012](GAZ-012.md)に登録済み**。本エントリは分冊[26]の地所書上本文（OCR全文）の精読結果。引用文言はすべてOCR由来で要原文照合。
- **関口村東南之方の神田上水堀筋・目白坂通道〔確認・repo初出〕**: 「**関口村東南之方 神田上水堀筋 音羽町九丁目脇ゟ大泉寺前通八幡社地前迄目白坂 通道敷限西北之方…**」＋「**当時東手神田上水堀筋音羽町大通東頬…**」＝**①嘉永7年時点で音羽町九丁目脇から大泉寺前を通って八幡社地前に至る「目白坂」の通道が地所境界として現れること、②神田上水堀筋（旧上水の堀跡）が関口村東南・音羽町の大通の東頬に沿って地所境界を成していること**。〔[GAZ-012](GAZ-012.md)の同書第19部拾九利（嘉永5年）の「神田上水堀筋并同所大洗樋下川筋」に続く、音羽町側の嘉永7年の地所レベルの境界文言。目白坂の通道経路（音羽九丁目脇→大泉寺前→八幡社地前）の明示はrepo初出候補。〕
- **神田上水堀筋の「御普請中土取場」の変遷〔確認・repo初出〕**: 同地所（音羽町九丁目裏手付近と読める区域）の沿革に「**寛延二己年七月前に有之戸田肥前守寛延二巳年ハ豐前守清水権之助両人御預地 神田上水堀筋御普請中土取場二成 宝暦七丑年十一月右土取場願之通松平大学頭え御預成 天明三卯年五月…**（以降の文言候補は享和2年本庄近江守・文化4年大澤下総守下屋鋪への変遷と読めるがOCR列崩れ大・要照合）」＝**①寛延2年（1749）7月に戸田肥前守（豊前守）・清水権之助両人の御預地が「神田上水堀筋御普請中土取場」となったこと、②宝暦7年（1757）11月に土取場が松平大学頭の御預となったこと、③天明3年（1783）5月以降の変遷**。〔**旧神田上水の堀筋の土地が「御普請中土取場」として運用された年代つきの変遷記録**＝音羽谷・神田上水堀筋の土地履歴の年代層。OCRの列崩れが大きく寛延2の干支（己巳）・人名・以降の変遷は原文照合必須。〕
- **蓮光寺境内の「元目白坂下」から護国寺建立への召上げ〔確認・repo初出〕**: 「**蓮光寺境内元目白坂下に有之候処元禄十丑年中護国寺御建立之節御用に付被召上候事 同十一寅年中当所に而代地被下特添地者其頃ゟ有之**」＝**蓮光寺（音羽町の寺）の境内が元来目白坂下にあったが、元禄10年（1697）の護国寺建立の際に御用に付召し上げられ、元禄11年（1698）に代地が下げ渡された**という寺地の移転記録。〔移転後の蓮光寺の位置（現在の小日向側か）の比定は本書のみでは行わない。音羽谷の開発史（護国寺建立＝元禄10年を境界とする音羽町周辺の土地再編）を寺地レベルで示す書上記録。[GAZ-016](GAZ-016.md)（市街篇12・元禄10年8月町屋仰付け）・[GAZ-012](GAZ-012.md)（同書の関口村「元禄十丑年中東手關口村百姓地護国寺領ニ成」）と同じ元禄10年を境界とする再編の寺側の記録として対校可能。〕
- **巣鴨辻町後の「用水堀」〔確認・repo初出候補〕**: 巣鴨辻町・小石川村字新田・雑司ヶ谷村境の地所記述に「**同町後用水堀野道を隔小石川村之内百姓地**」＋「**此外野道用水堀等往古不明之箇所は古積図書入相除当時之絵図え出之**」＝**嘉永7年時点で巣鴨辻町の裏手に用水堀が地所境界として存在したこと・往古の野道・用水堀の不明箇所は古絵図に対比して記載した旨の凡例的文言**。〔[GAZ-012](GAZ-012.md)の第20部貮拾貞（分冊[28]・2587247）の「用水堀29箇所」（巣鴨村・池袋村・滝野川村・中丸村・長崎村側）に対する、雑司ヶ谷・大塚側（貮拾利）の用水堀記録として対になる。個々の用水の同定（谷端川上流か千川用水系か）は本文のみでは行わない。〕
- **御鷹部屋・御鷹方御役屋鋪の所在記録〔確認・対校資料〕**: 「**雑司ヶ谷村御鷹方御役屋鋪松浦金三郎屋鋪本立寺境内辺之部**」「**雑司ヶ谷村御鷹部屋本染寺境内…**」「**東之方御鷹方御役屋鋪脇手道敷より雑司ヶ谷村之内野道限…**」＝雑司ヶ谷村の御鷹部屋・御鷹方御役屋鋪（本染寺・本立寺境内と結びつく位置）の地所書上。〔[GAZ-048](GAZ-048.md)（風土記稿・御鷹部屋9,088坪余・御鷹方組屋敷14,530坪余）の嘉永7年時点の土地側の対校記録。〕
- **地割変遷の年代層〔確認・repo初出〕**: 本分冊の特徴である旧時点対比の記載に「**延宝初之形**」「**延宝六午年頃之形**」「**延宝九酉年之形**」「**元禄十丑年頃之形**」の図形対比のほか、本文中に「**往古は一円関口村小日向村入会之由申伝候趣…当所名主共申立候得共是又不詳候間前文之通惣体関口村に調之**」「**其後元禄十丑年中此辺一円護国寺領二成**」「**正徳三巳年中…町並地二成**」「**享保七寅年中町並地ニ成**」「**延享二丑年中東手巣鴨村増上寺領被仰付**」「**宝暦八寅年中より護持院え護国寺兼帯に成**」等の年代つき地割変遷文言が多数。〔**音羽町・桜木町・関口村周辺の地割が延宝→元禄10（護国寺領化）→正徳3（町並地化）→享保7（町並地化）→延享2（増上寺領）→宝暦8（護持院兼帯）→嘉永7の年代層で追えること**＝音羽谷の土地利用変遷の基礎年代データ。各文言はOCR崩れを含み個別の照合が必要。〕
