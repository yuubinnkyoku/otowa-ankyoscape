# [GAZ-192] 東京市史稿 市街篇 第二十 — 千川上水其他廢止の事蹟章〔第322回〕

- **書誌〔確認〕**: 東京市役所編『東京市史稿』**市街篇 第二十**（昭和9年〔1934〕刊・次世代デジタルライブラリー [book/3450797](https://lab.ndl.go.jp/dl/book/3450797)）。編年体の事蹟章を収め、享保7年（1722）の「隠シ遊女取締」に続き「**千川上水其他廢止**」の事蹟章（頁501〜504と読める・OCRによる）が置かれる。末尾に「**千川上水其他廢止 上水篇ニ詳記ス**」の案内文言（東京市史稿上水篇への相互参照）。本冊のOCRは表組崩壊が最大級で、以下の文言はすべて原画像照合を要する。
- **差止年月の多層構造〔文言候補〕**: 事蹟章の編年は（OCR列混在を成るべく時系列に並べ直すと）——
  1. **享保7年8月17日（庚午）**: 柳營日次記の条（「○享保七年八月十七日庚午」と読める行）と、撰要永久錄の同令の末尾記注（「右御觸八月十(七)日…喜多村ニ(而)寫物。町中連判…同十二日同所納」と読める＝触の写しの町中連判・納入の記録）。
  2. **「石川近江守茂總?被渡い御書付」**: 「**千川上水之義、中興〓懸り(事こい)故、自今相止い間、其段向々に可被申達い。來ル十月〓上水取可申筈ニい間、可被得其意い。以上。（八月）**」＝千川上水差止の石川近江守渡しの御書付。「來ル十月」＝**10月実施を予告する時限条**を含む。
  3. **青山三田両上水の停止**: 「靑山三田兩所上水之儀、中興〓懸い事こい故、自今相止い間…來ル十月〓上水取可申筈…」と読める同型の御書付（青山上水・三田上水の同時差止）。
  4. **九月の令の日次〔文言候補・repo初出の可能性〕**: 「(享保七年)九月三日乙酉…人更ニ同時ニ千川上水ヲ廢止セシム」「…本靑山三田兩上水ヲ廢スルノ令有リ。五日丁亥…(本所)上水ヲモ廢ス」＝**三正綜覽に拠る9月3日（乙酉）の千川・青山・三田上水廃止令、9月5日（丁亥）の本所上水廃止**の日次。既存のrepoの差止年代論（8月18日/19日の御書付系（[GOV-464](../gov/GOV-464.md)・[GAZ-083](GAZ-083.md)）と10月実施（触の「來ル十月」・町方側記憶の享保7年10月（[GAZ-130](GAZ-130.md)））の間に**9月の令の層**を加える候補。OCR崩壊のため日次・干支の確定は原画像照合必須。
- **「中奥／中興」判読対立の新たなテキスト〔文言候補・断定しない〕**: 上記の御書付の「中興〓懸り(事こい)」の部分は、[GOV-464](../gov/GOV-464.md)（憲教類典58・「**中奥ゟかヽり候事**」・石川近江守殿御渡）と『絲綸錄』系（「**中興よりかヽり候事**」・[GAZ-117](GAZ-117.md)の対立整理）の判読対立に対する**第3のテキスト＝東京市史稿事蹟編の採録は「中興」と読める**。OCRで中奥/中興の字体は酷似しており、本冊の読みだけで確定しない（原画像照合課題として両論の票数に加える）。石川近江守の諱として読める「茂總」の原字も要照合。
- **撰要永久錄の上水筋の触文言〔文言候補・repo初出〕**: 「**右と右上水筋に御觸。朱右（馬？）千川上水水筋と、武藏野保田新田〓板橋庚申塚 巢鴨 本〓(通) 谷中 上野下谷 淺草筋に相掛りい由。-撰要永久錄**」＝触書（朱印触？）として**千川上水の水筋＝武蔵野保田新田→板橋庚申塚→巣鴨→本(通)りの谷中→上野下谷→浅州筋に「相掛り」**（掛かり通る）趣旨の文言が撰要永久錄に引かれる。千川上水の水元（保田新田）と末端給水区域（谷中・上野下谷・浅草筋）を一つの触文言で結ぶ列挙として、開削時の分水先（[GAZ-049](GAZ-049.md)⑫1の「小石川御殿、湯島聖堂、東叡山、淺草御殿」）と並ぶ**末端側の範囲の一次的文言候補**。撰要永久錄は [GOV-378](../gov/GOV-378.md)（享保13年・寛延2年・明和6年等の触を登録）と**同一資料（町年寄触書集）**であり、本条でその享保7年8〜9月の触が市街篇側から引かれたことが確定。
- **有德院殿御實紀の実施文言〔文言候補・repo初出〕**: 「**この十月より千川の上水を引ことをとゞめらる**」「（この日）靑山三田にかゝる上水を停廢せらる」「**本所上水は、中古より取建られしかど、今は水もかゝらざるをもてとゞめらるゝとなり**」（有德院殿御實紀・殷昌期・p503〜504と読める）＝**御實紀による10月実施（「この十月より」）の文言**。8月の触（御書付）→9月の令（三正綜覽の日次）→**10月の実施（御實紀・町方側記憶の両側）**という三層構造のうち、御實紀側の本文がrepoで初めて採録された。本所上水の「水もかゝらざるをもてとゞめらるゝ」の文言は享保7年停止の本所上水側観察として同時に採録される。
- **國朝舊章錄の引用文言〔文言候補・引用元としてrepo初出〕**: 「**一、同年場合報番町小川町駿河臺等火消の組合被仰付〓千川上水靑山三田等の上水を被止。-國朝舊章錄**」＝**番町・小川町・駿河臺等の火消組合の仰付と、千川上水・青山・三田上水の停止とを一つの条文に併記**する國朝舊章錄の記載（享保7年の施策群を束ねる実務法令集側の記録）。**引用元『國朝舊章錄』がrepoの引用元リストに初出**（間接史料だが、差止施策の同時性・総合性を示す指標）。なお同所の石川藥園・施藥院創立の断片（「石川藥園…千坪ノ地ヲ町奉行ニ引渡…施藥院ヲ創立セシメ」）は次章の小石川養生所設立の章に続き、OCR崩壊が大きいため文言候補としてのみ記録する。
