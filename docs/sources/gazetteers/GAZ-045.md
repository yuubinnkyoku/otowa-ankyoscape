# [GAZ-045] 御府内備考 巻29-31 — 湯島区間の千川上水の町別書上の写本系統

- **書誌〔確認〕**: 『**府内備考**（御府内備考）巻29-31（写本）』。NDL次世代デジタルライブラリー [book/2553672](https://lab.ndl.go.jp/dl/book/2553672)。丁亥（文政10年）書上の文言を含む＝[GAZ-024](GAZ-024.md)（大日本地誌大系第2巻・雄山閣刊本の巻25-46）が採録するのと同じ湯島・本郷各町の「千川上水跡」条の**写本側の独立系統**。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **湯島横町・湯島六町目・切通町等の千川上水跡条〔確認・GAZ-024の数値の町名対応の追補〕**: ①湯島横町——「**一千川上水跡 右安永九子年 町内往還本郷壱丁目境ゟ湯島五町目境迄凡長六拾八間余 往還二埋申樋懸渡シ有之候処 天明七未年四月中以差止ミ相成候節取潰シ埋立申候**」＝**本郷1丁目境〜湯島5丁目境の凡68間余の埋樋**（[GAZ-024](GAZ-024.md)の「68間余（本郷一丁目境〜湯島五町目境）」と同一・写本側で確認）。②湯島六町目と見える町——「**千川上水跡 右安永九子年 町内往還長二拾三間程往来中程二埋中樋を渡有之 湯嶋同町目境四ツ角往来中程に中桝可所有之候処 天明七未年四月中御普止（＝差止のOCR崩れか）ニ相成候節取潰シ埋立申候**」＝**往還長23間の埋中樋＋湯島同町目境四ツ角の中桝**（「23間程」の町別延長は[GAZ-024](GAZ-024.md)の数値リストにない新セグメント候補）。③（切通町か・OCRの頁境界で帰属要照合）——**21間＋中桝＋小樋2ヶ所**の樋の記録〔**いずれも差止は「天明七未年**四月中**」の書式**＝[GAZ-041](GAZ-041.md)〜[GAZ-043](GAZ-043.md)（神田側の「**四月十三日**」）と対照すると、**湯島側の写本は日を特定せず「四月中」と書く**＝4月13日の通達が日単位で神田側の記憶に残り、湯島側は月中表記になった（あるいは通達・実施の段階差）という粒度の差の記録（断定しない）〕。
- **写本系統としての対照価値〔観察〕**: [GAZ-024](GAZ-024.md)は雄山閣刊本（1929）のOCR、本書はNDL次世代DLの写本OCR＝**千川上水跡条の文言・数値を独立した二系統（刊本・写本）で対照できる初の組み合わせ**〔湯島横町の「68間余・本郷1丁目境〜湯島5町目境」の完全一致は[GAZ-024](GAZ-024.md)の数値の信頼性を写本側から裏付ける。町名と延長の対応が[GAZ-024](GAZ-024.md)では不完全だった箇所（80間5尺3寸5分・22間・86間余・51間・18間3尺の各町）の帰属の一部（23間・六町目など）が本写本で進む〕。
