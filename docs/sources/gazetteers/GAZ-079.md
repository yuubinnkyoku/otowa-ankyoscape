# [GAZ-079] 東京府北豊嶋郡巣鴨町巣鴨村（1911）— 巣鴨側の字名一覧（北谷端・南谷端候補）

- **書誌〔確認〕**: 東京遞信管理局編『東京府北豊嶋郡巣鴨町巣鴨村』（遞信協會・明治44年〔1911〕。NDL次世代デジタルライブラリー [book/1089221](https://lab.ndl.go.jp/dl/book/1089221)・請求記号 YG21-Z-4666）。[GAZ-052](GAZ-052.md)（板橋町冊）・[GAZ-078](GAZ-078.md)（瀧野川村冊）と同じ**遞信協會郡部シリーズ**の巣鴨町・巣鴨村冊（谷端川の南・西側に当たる町村）。**本冊のOCRも表組みの列崩壊が激しく、字名の読みはすべて原画像との照合を要する。**
- **巣鴨町・巣鴨村の字名〔確認・OCR列崩壊・要照合〕**: OCRに「**字北谷…端谷南字**」の列崩れ文字列があり、**字北谷端・字南谷端（の配列）の候補**。その他の字名として「染井・駒込・庚申（塚）・池袋新田（池袋）・雑司ヶ谷（雑司谷）・石保・久水・浅井・戸谷池・並木・向・西原・王子・宮ノ下・谷頭（?）・高山・中原・丸山・前田（?）・上宿・下宿・中山寺（?）」等が読み取れる。＝**1911年時点の巣鴨町・巣鴨村（谷端川の南岸・西岸側）の字名の候補一覧**。
- **「北谷端・南谷端」の両岸構造〔観察・文言候補〕**: GAZ-078が滝野川村側（北岸）で字北谷端・字南谷端を確認したのに対し、本冊は川の反対側（巣鴨側）の冊である。OCR列崩れ「字北谷…端谷南字」が字北谷端・南谷端を指すなら、**「谷端」字名が谷端川の両岸で現れる**ことになり、谷端という地形語（谷の端）が川名の由来となりうる範囲の広さを示唆する。ただし①列崩れによる誤読の可能性（「北谷」＋別語の混在）・②巣鴨側に「谷端」を冠する字が実際にあるかの原画像確認、が前提で、**本冊だけでは断定しない**（文言候補に留める）。〔 BOOK-109（1922年・滝野川町字南北谷端と西巣鴨町字三家の対峙）との対校・BLOG-062の1921年地形図「王子」の谷端地名の前段としての意義。〕
- **水系文言の陰性〔確認〕**: 本冊のOCR全文で「弦巻」0件・「水窪」0件・「千川」0件・「谷端川」の川名表記は出ない（「谷端」は字名候補のみ）。「用水」0件。字名帳簿であり河川現勢の記録は含まれない。
- **その他の字名の位置づけ〔観察〕**: 字染井（染井災）・字庚申塚（金王坂上の巣鴨庚申塚・[BLOG-159](../blogs/BLOG-159.md)）・字池袋新田（池袋の新田起源〔[BOOK-110](../books/BOOK-110.md)の池袋新田開拓記録と対校〕）・字雑司ヶ谷・字久水・字浅井・字戸谷池等、**谷頭・湧水池・湿地を想起させる字名**が並び、豊島郡低地の微地形の字名記録として有用。ただし地番・面積の行割付はOCR崩壊で原画像照合が必要。

## 制限・未解決

- ①OCR列崩れ「字北谷…端谷南字」の正確な読み（北谷端・南谷端か、別の字の混在か）は原画像照合が前提で、現時点では候補に留める。②字名と谷端川との位置関係（どの字が川のどちら側か）は本冊の地図部分の読図を要し、OCRからは判読不能。③書誌の巣鴨町と巣鴨村の区分（町方・村方の別）とそれぞれの字名の帰属は要照合。
