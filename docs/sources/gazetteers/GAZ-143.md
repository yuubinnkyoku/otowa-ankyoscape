# [GAZ-143] 町方書上[60] 四谷壱 — 石切横町の起譚（万年石樋普請由来）と四谷伝馬町の小地名群

- **書誌〔確認〕**: 『[60] 四谷町方書上　壱』（写・NDL次世代デジタルライブラリー [book/2571541](https://lab.ndl.go.jp/dl/book/2571541)）。文政10亥年（1827）。四谷伝馬町新壱丁目条（p8-48・p48末「以上文政十亥年十月 四谷伝馬町新壱丁目名主」）、四谷伝馬町弐丁目条（p52-56ほか）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571541_{NNNNNNN}.txt` コマ番号。**
- **石切横町の起譚〔文言候補・repo初出候補〕（p55-56）**: 「**一町内南側中程横町ヲ里俗石切横町と旧(=申候補・OCR)日来候 右者 承応年中 玉川御上水万年石樋御起立之砌 御用石数多此辺ニ差置 日々石工相集り切立候事数月ニ及ひ候ニ付 自然ニ里俗石切横町江唱来候由 其節所々ゟ集り候石工とも 数月之御普請ニ付近辺ニ借家いたし御用相勤候処 御普請出来之後 元住所江引移候義有之 其侭此所ニ住居定候者も有之ニ付 今以此辺石屋共数多住居仕候由 里俗申伝候**」＝**伝馬町弐丁目南側中程の横町＝里俗「石切横町」の成立譚：承応年中（1652-54）の玉川上水万年石樋御起立の際、御用の石を数多くこの辺に置き、毎日石工が集まって切り立てたことが数ヶ月及んだため、自然に里俗に石切横町と唱えるようになった。諸所から集まった石工たちは近辺に借家して御用に勤め、普請完了後は元の住所へ引き移ったが、そのままこの所に住み着いた者もあり、それゆえ今もこの辺に石屋（石材業）が多く住居している**。〔**①石切横町の地名が万年石樋普請（承応年中）の石材置場・石工の集住から起きた旨の町方書上の一次文言＝repo全体で石切横町の文言は本登録が初出、②万年石樋普請（[GAZ-141](GAZ-141.md)塩町三丁目条の石樋区間〔大木戸〜伝馬町壱丁目〕・[GAZ-112](GAZ-112.md)の御府内備考側総説）の工程の性格＝御用石の町内置場・数ヶ月の石作業・石工の残余の住居定着を伝える工程側の記録、③文政10年時点で石屋が伝馬町に多いことの傍証文言。「旧日来候」「切立候」等の原字は要照合**〕。
- **御仮屋横町・御仮屋橋岸通〔文言候補・repo初出候補〕（p52-54）**: ①「**外御仮屋橋岸通 巾三間**」（p52）＝**町の外側の通り名「御仮屋橋岸通」（巾3間）**＝町内間数書上の外周通りとして記載される通り名で、**「御仮屋」＋「橋岸」の複合地名の文言候補（repo初出候補。「橋岸」の橋がどの水路の橋か（玉川上水（石樋）・四谷御門堀等）は本冊文言からは確定しない）**。②「**五一同所中程之横町を里俗御仮屋横町江唱来候 右は四谷町之起立之砌 寛永十一戌年中 弐(=武?)州豊嶋郡貝塚領上一ツ木村之内稲荷山福田寺宝蔵院(=室蔵院?候補)社内之稲荷幷神田明神社内ニ有之牛頭天王ヲ 右室蔵院と達し 両社共四谷鮫河橋之鎮守二勧請仕 同年六月十八日 右横町角自身番屋ヲ向横町江引初而役屋ヲ補理 両社神輿遷座旅所神事**（後略）**祭礼同廿一日帰座 右ヲ格例と定入干江無中極く毎年六月十八日ゟ同廿一日迄 石(=御仮屋候補・直前の崩壊部)横町え遷座旅所神古文(=神事候補)祭礼仕候ニ付 御仮屋横田(=町候補)唱留来候**」（p53-55）＝**里俗御仮屋横町の由来：寛永11戌年（1634）の四谷町起立の際、豊嶋郡上一ツ木村稲荷山福田寺宝蔵院社内の稲荷と神田明神社内の牛頭天王を四谷鮫河橋の鎮守に勧請し、毎年6月18日〜21日まで神輿がこの横町に遷座する旅所（御仮屋）となるため御仮屋横町と唱える**。〔**四谷鮫河橋の鎮守（牛頭天王・稲荷の両社勧請）の祭礼旅所としての御仮屋横町の由来文言候補＝四谷の祭礼地理の記録。祭礼文言は水系と直接しないが、町名の「御仮屋」と「御仮屋橋岸通」の呼称連鎖の側を記録**〕。
- **荒木横町の由来文言〔文言候補〕（p53）**: 「**一町内北側西境横町ヲ里俗荒木横町と唱来候 右は往古横町内に植木屋多く住居近在ゟ新木ヲ買入同所ニ而木根ヲ直し所々江売買致候由 右体新木数多引入候故 三軒木横町之名目有之候処 いづれ之頃ゟかゝ(=改ともOCR崩壊)新字ヲ荒宗(=荒木候補)ニ設り 荒木横町ゟ旧問(=申来候補)来候 併古之姿ヲ残し 今以植木屋四軒住居仕候**」＝**荒木横町＝往古は植木屋が多く「三軒木横町」の名があったのが、いつの頃か新字を「荒木」に改め荒木横町と申来た。古の姿を残して文政10年時点でも植木屋4軒が住居**。〔**植木屋由来の「三軒木」→「荒木」改字譚の一次文言候補（小地名史の記録）**〕。
- **天王横町・法蔵寺横町〔文言候補〕（p56）**: 「**一町内南側東境横町ヲ里俗天王横町と旧日来候 委細は同所伝馬町新壱丁目ゟ申上候通に御座候**」＋「**一町内南側西境横町ヲ里俗法蔵寺横町と四四日(=申来?OCR崩壊)来候 右は芝増上寺末浄土宗五劫上(=一寺?候補)法蔵寺一寺有之 依而法蔵寺横町ゟ旧旧来候**」＝**天王横町（委細は伝馬町新壱丁目条参照の相互文言）・法蔵寺横町（増上寺末法蔵寺の所在による町名）の文言候補**。〔横町群（石切・御仮屋・荒木・天王・法蔵寺）と町外通り（御仮屋橋岸通）の一覧構造が伝馬町弐丁目の町内間数書上（p52）に揃っており、**四谷伝馬町の小地名の一次リストとして記録価値**〕。
- **伝馬町新壱丁目条・弐丁目条の水系文言の不在〔陰性確認〕**: 弐丁目条の間数文言（p52）に「**大下水**」「**横切下水**」等の川系文言は本冊では不在（石樋はp55の石切横町文言にのみ現れる）。伝馬町新壱丁目条（p8-48）も川系Keyword掃引では陰性（名主孫右衛門家の由緒・御伝馬役等の文言が中心）。〔[GAZ-141](GAZ-141.md)塩町壱丁目条「大下水元之儀は四谷伝馬町壱丁目ゟ申上候」の委細先にあたる町の書上が川系文言の面では薄いことは対照表の大下水行（起点委譲文言）の側の制約事項として記録**〕。
