# [GAZ-153] 町方書上[2] 市谷壱（文政10亥年）— 市谷大下水の「柳川」元資料側witnessと八幡町・左内坂町の文言群

- **書誌〔確認〕**: 『[2] 市谷町方書上　壱』（写・NDL次世代デジタルライブラリー [book/2571483](https://lab.ndl.go.jp/dl/book/2571483)）。文政10亥年（1827）三月付けの地誌御調書上で、市谷田町壱〜四丁目・市谷八幡町・市谷左内坂町等を収録（末尾に「文政十亥年三月」の年記が見える）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571483_{NNNNNNN}.txt`）。同夜の町方書上シリーズはNDL labの満遍ない掃引対象（[GAZ-149](GAZ-149.md)〔駒込16〕・[GAZ-154](GAZ-154.md)〔市谷4〕・[GAZ-155](GAZ-155.md)〔四谷附録66〕・[GAZ-156](GAZ-156.md)〔西久保19〕・[GAZ-157](GAZ-157.md)〔芝伊皿子143〕と同時採録）。
- **市谷田町壱丁目条の大下水流路文言〔文言候補・本冊最重要〕（p16）**: 「**一大下水ハ寛永十八丑年中 堀千之助様御手伝にて出来仕候 但大下水ハ大久保辺落水并四ヶ谷辺迄水吐水二口二而 八幡町ゟ一口二相成 田町通 船河原町 御武家屋敷前通 牛込牡丹屋敷 揚場町 船河原橋際 江戸川江落込申候 右下水堀石垣出来以前ハ只今尾張様表御門ゟ下之方ヲ柳川ト相唱候由 右ハ川添之柳樹植有之候故之唱被申伝候**」＝**①大下水（八幡町から田町通への一口）は寛永18年（1641）堀千之助様の御手伝で出来た、②水源は大久保辺の落水と四ヶ谷辺までの吐水の二口、③流路は田町通→船河原町→御武家屋敷前→牛込牡丹屋敷→揚場町→船河原橋際→江戸川へ落込む、④下水堀の石垣が出来る以前は尾張様表御門の下の方を「柳川」と唱えた、その由来は川添いの柳の樹が植わっていたから**という文言候補。〔**③の流路文言は[GAZ-110](GAZ-110.md)（御府内備考巻市谷・田町条の採録）と同型で元資料側（文政書上そのもの）の確認になる。④の「柳川」文言は[GAZ-110](GAZ-110.md)の当該箇所がOCRで「**極川**ト相唱候由」となっている文字の元資料側witnessで、文政書上の原本系では「柳川」（柳樹由来）と読まれる方向が強い**（「極川」がOCR誤読か書き写しの際の替字かは原画像照合まで断定しないが、町方書上の側で「柳川」＋由来語が二箇所〔田町条・八幡町条〕で揃う）。対照表の極川/堰川行・柳川・桃川行の第229回追記参照。〕
- **市谷八幡町条の大下水＝「四ツ谷辺上水之吐水」・両側石垣石橋文言〔文言候補〕（p86-90）**: 八幡町条に「**大下水之儀ハ四ツ谷辺上水之吐水二而 両側石垣石橋共 明暦二甲年中 松平下総守様御手伝ニ而出来**」（p89付近・OCR）＝**①大下水は四ツ谷辺の上水の吐水、②両側に石垣・石橋、③明暦2年（1652）に松平下総守様の御手伝で石垣石橋が出来た**という文言候補。〔**四ツ谷側の上水（玉川上水系の四ツ谷給水）の吐水が市谷側の大下水の水源である旨の町方側の位置記録**＝[GAZ-110](GAZ-110.md)総説・[GAZ-154](GAZ-154.md)修行寺門前条の「水上四ツ谷御上水之分水」文言と同じ水源観の八幡町側での確認。〕
- **同条の「往古は相川幷柳川」併記文言と蓋坂・水茶屋願い〔文言候補〕（p90）**: 「**且大久保辺ゟ流来り候下水之義ハ田町壱丁目ニ而申上候通り往古ハ相川幷柳川ト唱候川筋ニ御座候 町内八幡表門前 前書大下水上江蓋坂仕 幅六尺ニ弐拾間之場所壱ヶ所 同拾八間堤所壱ケ所 筒葺張 水茶屋渡世之者差出申度段 寛政五巳年三月十一日 町御奉行池田筑后守様え奉願候処 願之通被仰付候 石橋弐ヶ所 何れも前書大下水上 各長壱間五尺五寸 町中之分ハ幅弐尺…**」（p90・OCR・「筑后守」等の表記要照合）＝**①大久保辺から流来する下水は「往古は相川幷（＝ならびに）柳川と唱えた川筋」である（委細は田町壱丁目が申上る＝上の柳川文言と同じ供述とみられる）、②八幡表門前の大下水の上に蓋坂（幅六尺・20間＋18間の堤所・筒葺張）を設け希望の水茶屋が寛政5年（1793）3月11日に町奉行池田筑后守様へ願い出て許可された、③大下水の上の石橋2ヶ所（各長1間5尺5寸）**という文言群候補。〔**①「相川幷柳川」の併記は従来の市谷大下水の別称系列（柳川・桃川・紅葉川等）に「相川」を加える文言でrepo初出候補**（「相川」の原字（相川・梁川等の判読候補）はOCR由来で原画像照合必須。対照表の第229回追記参照）。**②寛政5年の蓋坂文言は、大下水暗渠化（蓋を掛けて上を往還・店敷地として使う）の実務例の年次記録候補**＝市街化の進行に伴う大下水の空間利用の変化の定点資料。〕
- **市谷左内坂町条の無名石橋（文政8年大破・半分修復の体制文言）〔文言候補〕（p127-128）**: 「**一石橋壱ケ所 町内東之方御武家方境ヨリ縫坂江上リ口 前書大下水ニ掛ケ有之候 長九尺 巾弐間 石数八枚ニテ橋之宗名無御座候 右ハ御入用場所ニ御座候処 年月不知 武家方御組合ニ而半分 町方二而半方宛修復仕候様被仰渡 其後修復モ無御座候処 文政八酉年十月中及大破候ニ付 御組合年番佐原勘右衛門様 永田金平様ゟ御普請方御役所御願済之上 町内二而モ同御役所江奉願 橋半分修復仕候**」＝**左内坂町の東、縫坂（＝左内坂）上り口の大下水に掛かる石橋（長9尺・巾2間・石8枚・橋の名は無之）。御入用場所で、修復費は武家方御組合が半分・町方が半分という分担体制の文言が仰渡され、文政8年（1825）10月中に大破したため、御組合年番（佐原勘右衛門様・永田金平様）と町内の双方から御普請方御役所へ願い出て橋の半分を修復した**という文言候補。〔**左内坂町側から見た市谷大下水の石橋の構造と修復負担（武家方半分・町方半分・年番制）の実務記録**＝[GAZ-109](GAZ-109.md)（牛込各町の石橋群）・[GAZ-110](GAZ-110.md)の石橋リストに加える部材候補。橋名が無いことも「名目無之」型の記録として橋名対照に資する。人名・役職名はOCR要照合。〕
- **同条の堀兼之井戸の呼称混同文言〔文言候補・repo初出〕（p127-128）**: 「**一井戸之儀 町内北之方 塩谷大四郎様御屋敷附ニ往古ゟ有之候得共 町方持ニ而唱無之 他所二而ハ堀兼之井戸ト相唱候者モ有之由二候得共 右堀兼ト相唱候者 牛込富士見馬場 久保平左衛門様御屋鋪内之由 当所ニ而ハ無御座候**」＝**左内坂町の北、塩谷大四郎様御屋敷附に往古から井戸があるが、町方では名で唱えない。「堀兼之井戸」と唱える者が他所にもいる由だが、堀兼と唱える井戸の本体は牛込富士見馬場の久保平左衛門様御屋敷内にあり、当地には無い**という文言候補。〔**「堀兼之井戸」の本元を牛込富士見馬場の久保平左衛門屋敷内と明示しつつ、左内坂町側の同名呼称の混同を書上の場で訂正している実務文言＝井戸名の空間的伝播と訂正の記録としてrepo初出候補**（本元側の牛込富士見馬場の井戸の書上文言自体の所在は要追跡）。人名はOCR要照合。〕
- **八幡町条の町支配付の年次文言〔文言候補・参考〕（p86-87）**: 「**市谷八幡町一御城ゟ戌亥之方二当リ凡弐拾八丁程 町内地所之儀者八幡社地ニ而年代不知表通町家作有之候処 寛文三辰年十一月於御評定所 町御奉行神尾備前守様 村越次左衛門様御立合之上 町御支配ニ被仰付**」＝八幡町が寛文3年（1663）11月に評定所で町奉行（神尾備前守様〔神尾元珍候補〕・村越次左衛門様立合い）の下で町方支配になった文言候補（町名・役職名はOCR要照合）。〔水系の直接情報ではないが、文政書上レベルで八幡町の前史（八幡社地の表通町家作）が見える。〕
