# [GAZ-071] 寺社書上（文政11年・雑司ヶ谷鬼子母神の御調書上）— 天明4年類焼と寛政3年再建の年代定点・延宝5年小網町三又川出現説の略縁起〔第147回〕

- **書誌〔確認〕**: 『寺社書上』（**写・刊記なし**。文政9〜11年（1826〜1828）の幕府による寺社御調書上の写本群とみられる。NDL次世代デジタルライブラリー [book/2571450](https://lab.ndl.go.jp/dl/book/2571450)。冊子の末尾に「**文政十一戊子年十一月 本仏寺**」の年月・提出者文言あり）。雑司ヶ谷鬼子母神（別当・本仏寺〔大行院〕）の堂宇・神体・由緒を「御調」に応えて書き上げた条を含む。**同一タイトルの別冊** [book/2571466](https://lab.ndl.go.jp/dl/book/2571466)（谷中の寺社群の書上・鬼子母神は各寺の本尊像として言及されるのみで水系無関係）も確認した。**引用文言はOCR由来でくずし字原画像との照合を要する**。
- **鬼子母神堂の天明4年類焼・寛政3年再建立〔確認・文言候補・repo初出候補〕**: 「**鬼子母神堂…（本堂）最初起立之年月等 天明四甲辰年正月廿一日夜 類揆（類焼のOCR崩れ）ニ付 書物等塗失（焼失の崩れ）仕 惣而相分り不申候 棟札 最初之分燈（棟札の崩れ）失二付無御座候 寛政三辛亥年四月 再建立 上棟之砌認候分有之候**」＝**①鬼子母神堂の天明4年（1784）正月21日夜の類焼で由緒書類・棟札等が焼失したこと、②寛政3年（1791）4月に再建・上棟されたこと**の書上年月つきの記録。〔**鬼子母神堂の建物史の年代定点として天明4年焼失→寛政3年再建を明示する一次書上**。由緒書類が天明4年に失われた旨の申告は、後世の由緒文言（掘出・出現伝承）の系統が火災以前の記録に遡れないことを示す背景情報。repoでこの年代情報の初出（[GOV-258](../gov/GOV-258.md)府史・[BOOK-144](../books/BOOK-144.md)遊歴雑記等の由緒文言に堂宇の焼失・再建年代の記述は未収録）〕
- **延宝6年安置の神体と由来文言〔確認・文言候補〕**: 「**神躰 子孫鬼子母神立像壱体 像に而弐寸余 作人相分り不申候 延宝六戊午年四月安置 由来之儀は子供に縁なきもの心願を立 浅草川筋三ッ又川ニ而垢離を取るものへ 髻にかゝりて上り候を当寺へあ置仕候 後子授の利生有之に付 子授鬼子母神と称し申候**」＝**神体（鬼子母神立像）の安置年＝延宝6年（1678）4月と、その由来を「浅草川筋の三ッ又川で垢離を取る者の髻（もとどり）にかかって上がったものを当寺に安置した」とする申告**。〔神体の安置年（延宝6年）の申告は[BOOK-144](../books/BOOK-144.md)（寛文6年社建立）・風土記稿系（天正6年本地堂建立）と対照できる年代記録。髪に絡んで上がる「像出現」の型は次項の略縁起と同型〕
- **略縁起＝延宝5年小網町三又川出現説〔確認・文言候補・repo初出の系統〕**: 書上末尾に添付の「**開運子授鬼子母神略縁起 大仏寺（本仏寺のOCR崩れ候補） 子授鬼子母神略縁起 抑當寺ニ安置シ奉ル鬼子母尊神ハ延宝五年丁巳四月八日 小網町三又川ヨリ出現シ給フ處霊像ナリ 其来由ヲ尋ルニ江戸下谷池ノ端ニ横田七郎右衛門トイヘル深信ノ者アリ 木村伊左衛門トイフモノヽ娘ヲ娶テ男女五人ヲ生ズトイヘトモ長トナラズシテ失フ事ヲ歎キ 雑司谷鬼子母神へ日参シ…毎朝小網町三股川ニ浸リテ水垢離ヲトリ雑司ケ谷詣ズルコト七日ニヲヨベリ 然ル今朝一ッノ不思議アリ 水中ニテ垢離ヲトル時柄杓ニモノアリテ髻ニ力ヽル 是レヲ払ヒ捨レバ又髻ニカヽルコト三度ニ及フ…取テ見レハ則テ鬼子母神ノ像ナリ…横田氏ノ妻懐リテ男子ヲ生ズ 是レ則鬼子母神ノ授ケ給フ処也…延宝六戊午年當寺奉納セリ**」＝**①出現を延宝5年（1675）4月8日・日本橋小網町の三又川（堀川）での垢離中の霊像発見とする略縁起、②願主＝下谷池ノ端の横田七郎右衛門と木村伊左衛門の二家、③延宝6年当寺奉納・男子誕生の子授験談**という由緒の全体構造。〔**①の出現地＝小網町三又川（市中の堀川）説は、永禄4年雑司ヶ谷村内地中の掘出説（[BOOK-144](../books/BOOK-144.md)・風土記稿〔[GAZ-049](GAZ-049.md)系〕・[BOOK-159](../books/BOOK-159.md)清土説）と対立する別系統の出現伝承で、文政11年時点の寺院側公式書上の文言としてrepo初出候補**。「三又川」は小網町の堀川の分流点（神田川系の川の呼称か）の比定保留（浅草川筋とだけの文言で、日本橋小網町の堀川と読めるが要照合）。出現地の対立構造（村内地中掘出〔永禄4年説〕vs 小網町三又川〔延宝5年説〕）は両説の年代差（1561/1675）ともども**断定せず**、対照表の出現伝承行の対校課題とする〕
- **星跡の井・清土への言及なし〔確認・陰性〕**: 本書上の鬼子母神条には星跡の井・「清土」の地名・出現地の草叢の小祠等への言及がない（2026-11-17の全文検索で「星」は妙見星座像等の他語のみ・「清土」「掘出」は0件）。〔文政11年時点の寺院側公式書上に星跡の井系の文言が無いことは、星跡の井伝承（[BOOK-144](../books/BOOK-144.md)文政7年草稿・[GAZ-067](GAZ-067.md)江戸志・[GAZ-070](GAZ-070.md)安政5年の本文）が出版物・地誌側の記述であって寺院の由緒申告には採られなかった（あるいは天明4年の類焼で由緒が失われた）可能性を示す陰性観察。ただしOCR崩れで文言が読めていない箇所が多く、原画像照合までは断定しない〕

## 制限・未解決

- ①書上はくずし字写本でOCRの崩れが非常に大きく、引用文言はすべて原画像照合を要する（特に「類揆」「塗失」等の当て字部分と人名）。②「本仏寺」の寺号のOCRは「大仏寺」等に崩れる（雑司ヶ谷鬼子母神の別当寺の寺号の確定は要照合）。③略縁起の底本（いつ成立した縁起を文政11年に添付したか）は不明で、延宝5年出現説の初出年代は本書上より遡れない。④「小網町三又川」の比定（日本橋小網町の堀川筋）は「浅草川筋」の文言との整合を含め要照合。⑤寛政3年再建の再建主体・規模は本書上からは読めない。⑥同冊内の他寺条（谷中系等）は水系と無関係のため精査していない。⑦同じ『寺社書上』タイトルの複数冊（2571450/2571466のほかにも同系冊がNDLにある可能性）の全体像は未把握。
