# [GAZ-071] 本所寺社書上六・本仏寺条（文政11年）— 本所本仏寺境内鬼子母神堂の書上〔第147回登録・第148回全面改訂（帰属の誤りの訂正）〕

- **書誌〔確認〕**: 『寺社書上』（写・刊記なし。文政9〜11年（1826〜1828）の幕府による寺社御調書上の写本群とみられる。NDL次世代デジタルライブラリー [book/2571450](https://lab.ndl.go.jp/dl/book/2571450)）。**冊子の冒頭文言「寺社書上 本所寺社書上六 本仏寺去恩寺本法寺永隆寺霊山寺…止二七七ノ第三十調書 本所出村」＝本冊は「本所寺社書上六」で、本所出村の本仏寺・去恩寺・本法寺〔本文OCRでは「法恩寺」〕・永隆寺・霊山寺の各寺の御調書上を綴ったもの**。本仏寺条の末尾に「**以上 文政十一戊子年十一月 本仏寺**」の年月・提出者文言あり。**引用文言はOCR由来でくずし字原画像との照合を要する**。同一タイトルの別冊 [book/2571466](https://lab.ndl.go.jp/dl/book/2571466)（谷中の寺社群の書上・水系無関係）も確認済み。
- **〔第147回の誤帰属の訂正（第148回・2026-11-17）〕**: 第147回は本条を「雑司ヶ谷鬼子母神（別当・本仏寺〔大行院〕）の御調書上」として、①天明4年類焼→寛政3年再建立を「雑司ヶ谷鬼子母神堂の建物史の年代定点」、②略縁起の小網町三又川出現説を「雑司ヶ谷鬼子母神本体の出現伝承（永禄4年掘出説）と対立する別系統」と記録したが、**いずれも帰属を誤った**。本条の対象は雑司ヶ谷鬼子母神ではなく**本所出村の安楽山日蓮宗本仏寺（甲州手延山久遠寺末）と、その境内の鬼子母神堂（子授鬼子母神）**である。〔①**雑司ヶ谷鬼子母神堂の建物史は寛文4年（1664）本殿建立（自昌院寄進）・元禄13年（1700）相の間拝殿増築の現存建物で、天明4焼失・寛政3再建の過程はない**＝[ORG-035](../org/ORG-035.md)（豊島区公式HP）で確認。②略縁起は本仏寺の神体の由来譚で、武江年表巻之三延宝5年条（[BOOK-157](../books/BOOK-157.md)⑬「翌年此像を本所本佛寺に安置す」）と同一故事の寺院側文言。**出現伝承の「対立構造」は解消**し、対照表の清土行の第147回追記を修正した。〕
- **本仏寺の沿革〔確認・文言候補〕**: 「**寛永八辛未年谷中三崎起立 元禄二己巳年揆失ニ付元屋敷被召上 同三庚午年正月廿九日当所二おゐて代地拝領 南北四拾九間三尺五寸餘 東西弐拾五間壱尺弐寸餘 此坪数千弐百五拾坪**」「**一開山修行院日通 延宝八庚申年十二月廿八日近記（遷化の崩れ候補）仕候 書物等倹失ニ付事跡等相分り不申候**」＝**寛永8年（1631）に谷中三崎で起立→元禄2年（1689）の火災で元屋敷を召し上げられ→元禄3年（1690）正月29日に本所出村で代地1,250坪を拝領**した沿革と、開山・修行院日通の遷化年月（延宝8年12月28日）を書き上げた文言。末尾に「**元禄二年天明四年両度之証失ニ而書物等不残無之**」＝元禄2年・天明4年の両火災で書物を失った旨の申告。〔天明4年正月21日夜の類焼が本仏寺の本堂・境内鬼子母神堂と同冊の永隆寺（「天明四辰年正月廿一日本堂鎮守堂庫裏門前伝家共不残類焼」）に共通する文言で、本所出村側の火災である点も帰属特定の傍証（文言候補）。〕
- **本堂と境内鬼子母神堂〔確認・文言候補〕**: 本堂——「**本堂梁間三間内陣奥行九尺拝殿梁間七間奥行五間半 最初起立之年月等 天明四ツ辰年正月廿一日夜類揆ニ付書物等塗失仕惣而相分り不申候 棟札最初之分失二付無御座候 享和二壬戌年九月十八日再建立**」＝本堂は天明4年正月21日夜類焼→享和2年（1802）9月18日再建立。**境内鬼子母神堂**——「**免内一鬼子母神堂…梁間三間奥行四間 拝殿梁間四間奥行五間 最初起立之年月等 天明四甲辰年正月廿一日夜類湊ニ付書物等揆失仕惣而相分り不申候 棟札最初之分失二付無御座候 寛政三辛亥年四月再建立 上棟之砌認候分有之候**」＝**鬼子母神堂（梁間三間＋拝殿梁間四間）が天明4年正月21日夜類焼→寛政3年（1791）4月再建立、棟札等焼失と書き上げた**。〔この文言自体は第147回の引用どおりだが、帰属は本所本仏寺境内の鬼子母神堂（**雑司ヶ谷鬼子母神堂ではない**）。由緒書類が天明4年に失われた旨の申告は、本仏寺の神体の縁起の系譜が火災以前の記録に遡れないことを示す背景情報として残る。〕
- **神体と境内の造作〔確認・文言候補〕**: 「**神躰 子孫鬼子母神立像壱体 像に而弐寸余 作人相分り不申候 延宝六戊午年四月安置 由来之儀は子供に縁なきもの心願を立 浅草川筋三ッ又川ニ而垢離を取るものへ 髻にかゝりて上り候を当寺へあ置仕候 後子授の利生有之に付 子授鬼子母神と称し申候**」＝**神体＝子授鬼子母神立像（像高二寸余）・延宝6戊午年（1678）4月安置・三ッ又川の垢離で髻に掛かって上がった霊像を当寺に安置した由緒**。前立鬼子母神立像（高一尺）・脇立円満神立像・月大黒・**妙見星座像**・随身二神座像。扁額「安楽山」（竪二尺五寸横六尺四寸）。石鳥居＋銅額「子授鬼子母神」＝**文化7庚午年（1810）5月再建立**。銅燈籠二基＝文化9壬申年（1812）4月再建立。石燈籠二基（文政8乙酉年12月・津軽氏序文）。**石燈籠二基高五尺六寸＝享保9甲辰年（1724）9月造立**。末社＝七面大明神・稲荷大明神・六浦大明神の三社。〔造作の年月（文化7・文化9・文政8・享保9）は本仏寺境内の鬼子母神堂の造作暦としての記録（文言候補・要照合）。「子孫鬼子母神」の表記はOCR崩れ候補（「子授」か）。〕
- **略縁起＝延宝5年小網町三又川出現〔確認・文言候補・本仏寺の神体の由来譚〕**: 書上末尾の添付「**開運子授鬼子母神略縁起**」——「**抑當寺ニ安置シ奉ル鬼子母尊神ハ延宝五年丁巳四月八日 小網町三又川ヨリ出現シ給フ處霊像ナリ 其来由ヲ尋ルニ江戸下谷池ノ端ニ横田七郎右衛門トイヘル深信ノ者アリ 木村伊左衛門トイフモノヽ娘ヲ娶テ男女五人ヲ生ズトイヘトモ長トナラズシテ失フ事ヲ歎キ 雑司谷鬼子母神へ日参シ 長トナル子ヲ授ケ給ヘト祈誓スルコトナリ 百日参詣満ズル暁ノ夢ニ…此ノ四月八日ヨリ毎朝小網町三股川ニ浸リテ水垢離ヲトリ 雑司ケ谷詣ズルコト七日ニヲヨベリ 然ル今朝一ッノ不思議アリ 水中ニテ垢離ヲトル時柄杓ニモノアリテ髻ニ力ヽル 是レヲ払ヒ捨レバ又髻ニカヽルコト三度ニ及フ…取テ見レハ則テ鬼子母神ノ像ナリ…其ノ年横田氏ノ妻懐リテ男子ヲ生ズ…延宝六戊午年當寺奉納セリ**」＝**①出現＝延宝5年丁巳（=1677年。第147回の(1675)表記は誤り）4月8日・小網町三又川（「浅草川筋」）での水垢離中の霊像発見、②願主＝下谷池ノ端の横田七郎右衛門と木村伊左衛門の二家、③「雑司谷鬼子母神へ日参」＝延宝5年時点で雑司ヶ谷鬼子母神が子授祈願の参詣対象として実在した、④延宝6年（1678）当寺（本仏寺）奉納**という由緒の全体構造。〔**武江年表巻之三延宝5年条（[BOOK-157](../books/BOOK-157.md)⑬「翌年此像を本所本佛寺に安置す」）と同一故事の寺院側縁起文言**。**小網町三又川出現説は本所本仏寺の神体（像高二寸余の別像）の由来であって、雑司ヶ谷鬼子母神本体の起源譚（永禄4年清土掘出説・天正6年堂建立〔[ORG-035](../org/ORG-035.md)〕）とは別神像の譚であり対立しない**。縁起中の「雑司谷鬼子母神へ日参」はむしろ1677年時点の雑司ヶ谷鬼子母神の実在の傍証（寛文4年建立〔ORG-035〕と整合）。「三又川」の比定（日本橋小網町の堀川筋）は「浅草川筋」の文言と併せ要照合。縁起の底本の成立年代は本書上より遡れない。〕
- **星跡の井・清土への言及なし〔確認・陰性（帰属訂正後に位置づけ修正）〕**: 本条（本仏寺条）には星跡の井・「清土」の地名・出現地の草叢の小祠等への言及がない（2026-11-17の全文検索で「星」は妙見星座像のみ・「清土」「掘出」は0件）。〔第147回はこれを「文政11年時点の雑司ヶ谷鬼子母神側書上で星跡の井系文言が確認できない陰性」としたが、**本条は本所本仏寺の書上であるため、雑司ヶ谷鬼子母神の書上の陰性としては使用できない**（第148回取り下げ。星跡の井系文言の1828年時点の雑司ヶ谷側書上の陰性は、該当する書上の所在確認からやり直す）。本仏寺側の縁起に星跡系文言がないこと自体は当然の陰性（本仏寺は星跡の井の所在とは無関係）。OCR崩れで文言が読めていない箇所が多く、原画像照合までは断定しない。〕

## 制限・未解決

- ①書上はくずし字写本でOCRの崩れが非常に大きく、引用文言はすべて原画像照合を要する（特に「類揆」「塗失」「揆失」等の当て字・人名・「去恩寺」「本法寺/法恩寺」の判読）。②本仏寺の寺号・末寺（甲州手延山久遠寺）の判読と、本仏寺（本所・日蓮宗）と雑司ヶ谷鬼子母神の別当（法明寺塔頭・大行院）の関係は本書からは確認できない（両者が別寺院であることは冊子の帰属と建物史〔ORG-035〕から確認）。③略縁起の底本（いつ成立した縁起を文政11年に添付したか）は不明で、延宝5年出現説の初出年代は本書上より遡れない。④「小網町三又川」の比定（日本橋小網町の堀川筋）は「浅草川筋」の文言との整合を含め要照合。⑤寛政3年再建（境内鬼子母神堂）の再建主体・規模の背景（本仏寺の施主等）は本書上からは読めない。⑥同冊内の他寺条（去恩寺・本法寺〔法恩寺〕・永隆寺・霊山寺）は水系と無関係のため精査していない（永隆寺の天明4年正月21日類焼文言のみ本条の傍証として参照）。⑦同じ『寺社書上』タイトルの複数冊（2571450/2571466のほか同系冊）の全体像は未把握。⑧**くずし字原画像での本条の逐次照合（第147回・第148回の引用文言の確定）は人手待ちの継続課題**。
