# [GAZ-057] 新編武蔵風土記稿（多磨郡 巻之122〜128）— 仙川用水の多磨郡側の用例群

- **書誌〔確認〕**: 『**新編武蔵風土記稿**』巻之122〜128（多磨郡之34〜40・1884年〔明治17年〕刊の次世代DL版）。NDL次世代デジタルライブラリー [book/763995](https://lab.ndl.go.jp/dl/book/763995)。文化〜文政期の幕府編纂（[GAZ-046](GAZ-046.md)＝豊島郡巻11-17・[763977](https://lab.ndl.go.jp/dl/book/763977)と同一書の**別巻（多磨郡）**）。**引用はすべてOCR由来で、特に本巻は活字崩れ・列崩れが激しく、文言・村条の帰属は原文画像との照合を要する。**
- **「仙川用水」の用例6回〔確認・OCR崩れが激しく文言候補〕**: NDL横断検索（contentonly・「仙川用水」）で本冊がヒットし、fulltextで用例6回（2冊分の重複ページ分を除くと3箇所程度）を確認。いずれも多磨川沿い〜世田谷方面の村条の水利・用水の項。大系版（第10巻・風土記稿6＝[1214867](https://lab.ndl.go.jp/dl/book/1214867)・1933刊）にも同用例があり、**1884刊版と大系版の2系統で文言が確認できる**（大系版の本文確認は未実施・横断検索ハイライトのみ）。
  1. **下祖師ヶ谷村条（と見られる文言）の仙川用水の経路説明〔文言候補・repo初出級〕**: 「**水利 多磨川上水ノ分水ナリ 新座郡上保谷村ユリ入 同郡竹下新田ヲ經テ 此ホ（とり?）ニ至リテハ仙川用水ト云 豐島郡中荒井村ヨリ引入 石神井村三實寺ノ池水落合 上鷺ノ宮村ノ比ノ方ヨリナカレ來リ 村內ヘ入 處々ノ水田ニソヽキ 流末ハ豊嶋郡葛ケ谷村ヘイタル 村ニカヽルコト八町許**」〔**①「新座郡上保谷村より入り同郡竹下新田を経て」＝千川上水の上流部（保谷分水）と同じ経路文言、②「此のほとりに至りては仙川用水と云」＝呼称の起点の説明、③「豊島郡中荒井村より引入」＝中荒井村は千川上水跡の堀残存村として[GAZ-048](GAZ-048.md)⑩に既出の村、④「石神井村三實寺ノ池水落合」＝【專跡合考】の「石神井池を引しと云は誤」の考証（GAZ-048⑩）や[GAZ-002](GAZ-002.md)北豊島郡誌の「石神井池を引しと云は誤りにして実際は柳窪の湧水」説と対照できる文言候補、⑤流末は「豊嶋郡葛ヶ谷村」＝千川上水受益村リスト（[GOV-284](../gov/GOV-284.md)）の葛ヶ谷村と対応、⑥村内を貫く長さ八町許**〕〔**OCR崩れが激しく、村条の帰属（下祖師ヶ谷村条か）・語順・「比ノ方」の原字は要原文照合。本文言が千川上水の流路（豊島郡側）を多磨側から説明したものか、世田谷方面に流れる別の用水（境新田分水系）を指すかは、原画像照合まで断定しない**〕。
  2. **橫根村条（と見られる文言）の堀幅六尺・水車〔文言候補〕**: 「**水利 上祖師ケ谷村ヨリ入リ 村内二十町許ヲヘテ喜多見村ニ及ヘリ 堀幅（六尺?）仙川用水（?） 則村內田間ノ用水トナレリ この流の間に水車アリ 村民ノ持池小名池淵（の水?）テモ田間ノ用水トス あり廣サ一段許**」〔**堀幅六尺・上祖師ヶ谷→喜多見方面の流路・水車の存在・小名池淵の池（広さ一段許）**〕〔OCR崩れ・村帰属要照合。仙川用水の実態（灌漑用水路網）の規模の記録候補〕。
  3. **大藏村条・鎌田村条（と見られる文言）の用水網〔文言候補〕**: 大藏村条「**水利…大藏村ヨリ入（り）村內ヲフル（フル?）コト九町許 六〓（=六ヶ所?用水?）用水シテ荏原郡瀬田村ヘ（ワタ）ス 川幅凡二間…仙川用水（?）サ三町餘ヲスキテ六〓用水ニ合ス**」／鎌田村条「**水利 六〓用水（?）村內ニ掛カルコト二町許 大藏村ヨリ入 岡本村ヘ流ル 川幅二間 …當村ハ此用水ヲ專ラ引用ユ 或ハ所上 仙川用水（?）ヲリ掛極（=懸樋?）ヲシカケテ水田ニ沃ク**」〔**川幅2間・懸樋（掛樋）の候補文言**〕〔OCR崩れ著しく文言候補。大井町史・碑衾町誌の品川用水系（境新田分水の仙川用水→寛文9年品川用水）との対応の検討資料〕。
- **位置づけ〔観察・内容メモ〕**: ①江戸期官撰地誌で「仙川用水」の用例が**豊島郡側（池袋・中丸・下板橋宿＝[GAZ-046](GAZ-046.md)/[GAZ-048](GAZ-048.md)）と多磨郡側（本冊）の両側で確認できた**＝千川上水の名称由来（多磨郡仙川村の太兵衞徳兵衞・「仙の字を改め千川となし」〔[GAZ-048](GAZ-048.md)⑩・[GOV-212](../gov/GOV-212.md)〕）と「仙川用水」呼称の関係（千川上水の異記か・同名の別用水か）を検討する資料が揃った。②明治10年代の東京府統計表にも「仙川用水」の独立項目（[GOV-302](../gov/GOV-302.md)）があり、呼称の継続性の検討資料になる。③宝永4年20か村・慶応3年17ヶ村組合・文久元年20ヶ村組合（[GOV-284](../gov/GOV-284.md)）の受益村の系譜と本冊の受益村文言の照合は今後の課題。

## 大系版対校による条帰属の確定と世田ヶ谷領用水網の判読（2026-11-16第130回追記）

- **対校の方法〔確認〕**: 1884刊版（[763995](https://lab.ndl.go.jp/dl/book/763995)）のOCR崩壊箇所を、**大日本地誌大系版『新編武蔵風土記稿』第10巻**（[1214867](https://lab.ndl.go.jp/dl/book/1214867)・1933年刊・巻之百二十三〜百二十六等を収録）と**同第11巻**（[1214877](https://lab.ndl.go.jp/dl/book/1214877)・1933年刊・巻之百二十七等＝世田ヶ谷領を収録）の活字OCRで対校した。第129回の課題①（下祖師ヶ谷村条と見られた経路説明文言の条帰属）・課題②（大系版本文の確認未実施）を解消するもの。**条帰属は活字版ベースで確定できたが、いずれもOCR由来であり原画像（くずし字本文）との照合は残課題。**
- **条帰属の確定①＝江古田村条（巻之百二十四・野方領）〔確認・repo初出の条レベル確定〕**: 第129回に「下祖師ヶ谷村条（と見られる文言）」と記録した経路説明文言は、大系版では**○江古田村条の水利項**として現れる: 「**水利 仙川用水 多磨川上水の分水なり、入同郡竹下新田を經て、新座郡上保谷村より此ほとりに至りては仙川用水と云、豐島郡中荒井村より引入、石神井村三寶寺の池水落合 上鷺ノ宮村の北の方よりながれ來り村内へ入、處々の水田にそゝぎ、流末は豐嶋郡葛ケ谷村へいたる、村にかゝること八町許**」。①冒頭の「**水利仙川用水 多磨川上水の分水なり**」が連続する文言として確定（1884版OCRでは「水利」と「仙川用水」の列崩れで分離していた）、②「**三寶寺**」の字形確定（1884版OCR「三實寺」の対校解消）、③「**北の方**」確定（1884版OCR「比ノ方」）、④流末葛ヶ谷村・村内八町許は両版本で一致。**江古田村（現中野区江古田）から見た用水の説明として、保谷・竹下新田経由の多摩川（玉川）上水分水が石神井村三寶寺の池水に落合し上鷺ノ宮村の北方から村内に入り葛ヶ谷村に至る経路＝千川上水系の流路と読める記述**（[GOV-302](../gov/GOV-302.md)明治10年府統計の「竹下新田ヨリ分流シ」・[BOOK-145](../books/BOOK-145.md)大井町史の境新田分水と同じ上流側地名群）。
- **条帰属の確定②＝下祖師ヶ谷村条（巻之百二十六）〔確認〕**: 第129回に「橫根村条（と見られる文言）」と記録した堀幅六尺の用水文言は、大系版では**○下祖師ヶ谷村条の水利項**: 「**上祖師ヶ谷村より入り、村内二十町許をへて水利仙川用水喜多見村に及べり、堀幅六尺、則村内田間の用水となれり、この流の間に水車あり、村民の持、小名池淵（にあり、廣さ一段許、池この水をも田間の用水とす）**」。**上祖師ヶ谷→下祖師ヶ谷→喜多見（いずれも現世田谷区）を結ぶ堀幅6尺の灌漑用水**で、江古田村条の千川上水系とは別の水系方向（多摩川沿い〜世田谷方面）の用例であることが条レベルで分離した。村内の水車と小名池淵の池（一段許）も確定。
- **条帰属の確定③＝岡本村条（巻之百二十七・第11巻1214877）〔確認〕**: 第129回に「大藏村条（と見られる文言）」と記録した六〓用水と仙川用水の合流文言は、大系版第11巻では**○岡本村条の水利項**: 「**水利 六〓用水 大藏村より入、村内をふること九町許にして荏原郡瀨田村へ達す、川幅凡二間、（大藏村より入？）當村を流るゝこと長さ仙川用水三町餘をすぎて、六〓用水に合す、村內を流るゝこと長さ五町餘、橫根村より出る〓水一條（泉水?）用水となり、これも六〓用水に落合、字根河原に懸樋を設けて田間に沃げり、又惡水堀とてあり、鎌田·大藏の兩村さかひより、村内十一町をすぎて、鎌田村又荏原郡瀨田村の間にて多磨川へ落つ**」〔「大藏村より入」の重複はOCRの頁割れ・要照合〕。**岡本村（現世田谷区岡本）で仙川用水が六〓用水に合流し、横根村発の清水用水も落合、字根河原に懸樋**という世田ヶ谷領の用水網の結節記録。
- **第11巻で判読できた世田ヶ谷領の用水網＝六〓用水（古名次太夫堀）〔確認・repo初出〕**: 大系版第11巻（1214877）の巻之百二十七（世田ヶ谷領）の村条群で、1884版OCRで崩壊していた部分が大幅に読めるようになった:
  1. **和泉村条の村名義と湧水源〔確認〕**: 「村名義を尋るに、**村內泉龍寺境內の〓水（湧水?）を引て水田を作り初めしより、この近きあたりの村々も用水となせしゆへ、往昔は出水村と書せし**」＝**用水網の水源が和泉村（現世田谷区）泉龍寺境内の湧水**であることの村名由来説明。
  2. **次太夫堀の別名と受益範囲〔確認・repo初出〕**: 「**古名次太夫堀と云、村內を經ること十町許、この用水は多摩·荏原兩郡の內十三村、田間の用水となれり**」〔条帰属は入間村条付近と見られる・OCRの頁流れで要照合〕＋同巻の村条の「**御入國の後御代官小泉次太夫（が）六〓用水を引入れてより用水もたれり**」＝**六〓用水の古名が次太夫堀で、御代官小泉次太夫による引入れに由来し、多摩・荏原両郡13ヶ村の用水**であったことの文言群。喜多見村条の川に「**一名治太夫堀と云**」の別名表記もある〔OCR・要照合〕。
  3. **鎌田村条〔確認〕**: 「水利 **六〓用水** 村內ニ掛カルコト二町許 大藏村ヨリ入 岡本村ヘ流ル 川幅二間 …**當村ハ此用水ヲ專ラ引用ユ 或ハ所上（所々?）仙川用水（ヨリ?）掛極（懸樋?）ヲシカケテ水田ニ沃ク**」（1884版・大系版ともOCR崩れあり・要照合）＝**鎌田村（現世田谷区鎌田）が六〓用水を専ら引用し、仙川用水から懸樋で取水**する文言候補。
  4. **駒井村条〔確認〕**: 「水源は**和泉村泉龍寺境內より出**、猪ノ方村を（經て）…田間の用水となれり、堀幅四尺許」＝湧水源の再記載。
  5. **「六〓」の原字は未確定**（六郷用水・六ヶ村用水等の候補・要原画像照合）。
- **2水系構造の整理〔観察・第129回の対立の解決方向〕**: 風土記稿の「仙川用水」用例は、①**江古田村条**＝保谷・竹下新田経由で石神井三寶寺池水に落合する多摩川（玉川）上水の分水（**千川上水系の流路記述**・[GAZ-046](GAZ-046.md)/[GAZ-048](GAZ-048.md)の池袋・中丸村条〔豊島郡側〕の受益呼称と対応）と、②**下祖師ヶ谷・岡本・鎌田村条**＝上祖師ヶ谷→喜多見の堀幅六尺の灌漑用水と六〓用水（次太夫堀）網に組み込まれる用水（**多摩川水系・世田ヶ谷領の別系統**）の**2系統に条レベルで分離した**。「仙川用水」呼称が千川上水の異記か別用水かという対照表の対立は、**同名の用水が実際に複数の系統で使われていた**可能性を示すが、①の水路を千川上水（1696年開設）と同定するかは「仙川／千川」の原字・原画像照合まで断定しない（[BOOK-145](../books/BOOK-145.md)の寛文期境新田分水説との年代対照も残る）。
- **誤同定注意: 風土記稿多磨郡巻の別の「水窪」〔文言候補〕**: 同書多磨郡巻（大系版1214867・山口領の村条群）に小名「**水窪**」（「水窪 村の中央より東方なり」類の方位説明・山川用水堀（幅八九尺）・惡水堀二條を伴う・高木村条付近と見られる）と、多磨川上流の村条の山川説明に「**水源より水窪谷一里許を流れ來り、是も多磨川に沃けり**」（蛇澤谷・水根澤川と並ぶ）の文言がある〔いずれもOCRで条帰属・原字は要照合〕。**いずれも北多摩〜西多摩の「水窪」で、repoの水窪川（雑司が谷発祥・[BOOK-001](../books/BOOK-001.md)）とは無関係**。風土記稿を横断検索する際の誤同定防止の記録。

- ①すべてOCR由来で、本冊は特に活字崩れ・列崩れが激しい。「此ホニ至リテハ」の原字・「六〓」の原字・岡本村条の「大藏村より入」重複・鎌田村条の「所上仙川用水（ヨリ）掛極」の語順は原文画像との照合を要する。②「石神井村三寶寺ノ池水落合」の解釈（千川上水が三宝寺池水に合流したという意味か・別用水の説明か）は原画像照合まで断定しない（[GAZ-048](GAZ-048.md)⑩の【專跡合考】の石神井池引水説の否定文言・[GAZ-002](GAZ-002.md)北豊島郡誌の柳窪湧水説との対照課題）。③大系版の本文側の対校は第130回で実施済み（条帰属は活字版で確定）だが、**くずし字原画像（内務省刊本・[茨城大学図書館所蔵候補](https://digitalcollection.lib.ibaraki.ac.jp/kan-kokusho/001000102266/)等）との照合・「仙川／千川」の原字確認は残る**。④豊島郡側の「仙川用水」（池袋・中丸村条）と多磨郡側の江古田村条の「仙川用水」が同一水系（千川上水）かは、原字照合まで断定しない（下祖師ヶ谷・岡本・鎌田村条の世田ヶ谷領方面の用水は第130回の対校で別系統と整理）。⑤大系版第10・11巻（1214867/1214877）の該当頁の原画像照合・「六〓」の原字・次太夫堀文言の条帰属（入間村条付近か）の確定は次回課題。
