# [GAZ-115] 御府内備考 巻13-15（浅草之一〜三・写本OCR）— 浅草側の千川上水末端文言群と藍染川（浅草）の同名異川注意

- **書誌〔確認〕**: 『御府内備考』巻之十三〜十五（浅草之一〜三・浅草総説・川附・各町条）。NDL lab [book/2553667](https://lab.ndl.go.jp/dl/book/2553667)。書上末尾に「**乙酉書上**」（文政8年・1825）。**引用文言はすべてくずし字OCR由来で原画像照合を要する。**
- **本登録の性格**: [GAZ-082](GAZ-082.md)（大日本地誌大系活字版）が千川上水の末端の井戸・差止文言を「旅籠町1丁目2ヶ所・2丁目1ヶ所・天王町・上平右衛門町河岸・下平右衛門町河岸」等として収録しているのに対し、本写本（浅草巻）は**同じ末端文言群の原文（町方書上そのもの）を伝える**。①**旅籠町壱丁目代地条の「古千川上水井戸弐ヶ所」文言（条帰属は活字版と整合）**、②**尾町条の「始り年月有所共相知不申候」**＝千川上水の起りを町方が記憶しない文言（repo初出候補）、③**茅町壱丁目条の「埋垣枡」**（枡語彙の新変種）、④**総説・川附の藍染川条**＝**浅草側（雷門前〜花川戸）の藍染川は谷中の藍染川（谷戸川末流＝[GAZ-113](GAZ-113.md)）とも神田の藍染川（逢初川＝[GAZ-099](GAZ-099.md)）とも別の同名異川（第3例）であることの注意材料**、⑤**新堀への石神井用水の余水流入文言**が主な新規層。赤坂巻（[GAZ-116](GAZ-116.md)）とともに、四河川（水窪・弦巻・谷端・千川）の流域外だが千川上水末端史・石神井用水流末史・藍染川同名異川の対校に直結する資料。

## 第215回の読取（2026-11-20）

- **旅籠町壱丁目代地条の古千川上水井戸〔文言候補〕**: 「**一 古千川上水井戸弐ヶ所 右は天明七未年四月十二日御差留之事 但其節埋立被相成候 以上乙酉書上**」＝**古千川上水の井戸2ヶ所・天明7（1787）4月12日御差留・その際埋立になった旨**。〔**条帰属はOCR構造上「以上乙酉書上」の直前の条＝旅籠町壱丁目代地条**（往古豊島郡之内田領鳥越村・江戸浅草旅籠町弐丁目と唱・元禄元年火除地召上→代地）で、[GAZ-082](GAZ-082.md)活字版の「旅籠町1丁目2ヶ所」帰属と整合する。帳簿上「**古**千川上水」と呼ばれている点も注意（当時すでに旧式の水路という認識の表れ候補）。写本側で旅籠町2丁目代地条そのものの井戸文言は本OCRからは確認できない（活字版の「2丁目1ヶ所」の対応文言の所在は原画像照合課題）〕。
- **天王町代地条の「井戸壱ヶ所も無御座」〔文言候補・GAZ-082重複の写本側対応〕**: 「**一 先年千川上水相掛候得共 井戸壱ヶ所も無御座候 以上乙酉書上**」＝先年千川上水が（当地へ）相掛りしたが井戸は1ヶ所も無い旨＝[GAZ-082](GAZ-082.md)天王町文言の写本側対応（重複witness・新規採番の内容としては扱わない）。直前の「一 武蔵国豊嶋郡速田（＝鳥越候補・OCR）領鳥越村と申伝候」文言とともに、**千川上水末端の範囲が鳥越村起源の代地町（浅草蔵前側）にまで及んだ**地表の裏付け。
- **尾町条の「始り年月相知不申」＋札差伊勢屋四郎左衛門の草分書上〔文言候補・repo初出候補〕**: 「**一千川上水 天明七未年四月十二日御差止ニ付埋立申候由 但始り年月有所共相知不申候 一札差町人旧家伊勢屋四郎左衛門 右草分札差町人伊勢屋四郎左衛門事凡百八拾年程已前ゟ住居罷在候由申伝候 当四郎左衛門迄七代相続罷在申候**」＝**千川上水の当地への埋立の由緒を、草分から7代（凡180年）続く札差旧家・伊勢屋四郎左衛門の申し伝えとして記録し、千川上水の起り（始り）の年月は「相知不申」と明言する文言**。〔**①千川上水の末端側の町方がその起り年月を知らない＝開設（元禄9年説）から遡る由緒を末端では保有していないことの町方書上レベルの証言、②伊勢屋四郎左衛門という札差旧家の実名と「凡180年前」（≒1630年代）の草分年代の申伝という家史料側の情報**。尾町（往古鳥越村・瓦焼残の地名起源説・元和2年町屋化・貞享年中御用地→元禄元年浅草林町之内割込代地の条）＝条帰属はOCR構造上・要照合。〔repo初出候補〕〕。
- **茅町壱丁目条の「埋垣枡」〔文言候補・枡語彙の新変種〕**: 「**一千川上水 弥此上水先年町内江相懸り往還中程埋垣枡有之候処 天明七丁未年四月十二日御差止ニ相成候ニ付埋潰候由申伝候**」＝**千川上水が先年町内に相掛り、往還中程に「埋垣枡」があったところ、天明7年4月12日の差止により埋め潰した由の申伝**。同条には**藤之井戸**（往古松平安正〔＝安芸候補〕様御門前にあった井戸・藤の木の故事で「ふじの井戸」）・**大藤の木＝明和8辛卯年2月中村松町出火で焼失**・**雑人形市（2月25日頃〜3月3日）・菖蒲人形市（4月25日頃〜5月5日）**の文言。〔**「埋垣枡」は既収録の「大桝・中桝・小桝・石枡」（[GAZ-082](GAZ-082.md)など）に加わる枡語彙の変種（埋樋＋垣の構造か・原字・構造は要照合）。4月12日差止の再出現も末端の申伝の層として分布を広げる〕。条帰属はOCR構造上・茅町壱丁目条（原画像照合要）。**「弥此上水」の「弥」の判読も保留**。
- **上平右衛門町河岸・下平右衛門町河岸の井戸文言〔文言候補・GAZ-082重複の写本側対応〕**: 「**一先年有之候千川上水井戸 上平右衛門町河岸新焼町屋之方二壱ケ所 下平右衛門町河岸同方二弐ケ所有之候処 天明七未年四月中口差止二相成候節埋六（＝立候補・OCR）に相成申候**」＝上平右衛門町河岸に1ヶ所・下平右衛門町河岸に2ヶ所の井戸が天明7年4月中の口差止で埋立になった旨＝[GAZ-082](GAZ-082.md)の文言の写本側対応（重複witness）。**「四月十二日」と「四月中」の表記の揺れ**が同じ巻内で併存する点を対校記録する（差止日の一次書上の表記層）。
- **浅草総説・川附の藍染川条〔文言候補・同名異川の第3例〕**: 「**藍染川 江戸砂子に浅草観音雷神門の前より東の方なる小き溝をいふといへり 浅草志云 雷神門より東半町ほと花川戸町北側に唐獅子屋孫兵衛といふ紺屋の前にある小溝を今以藍染川と云 昔はその日音院（＝薬研堀・日輪院等の判読対立候補・OCR）の辺に池ありてその水浅草川へ入りしと**」＝**①江戸砂子：浅草観音雷門前より東の方の小溝、②浅草志：雷門より東半町ほど・花川戸町北側の紺屋（唐獅子屋孫兵衛）前の小溝を今も藍染川と云う・昔は日音院(?)の辺に池がありその水が浅草川へ入ったと**。〔**repoの「藍染川」の既収録は①谷中＝谷戸川の末流（[GAZ-113](GAZ-113.md)・[GAZ-032](GAZ-032.md)・[GAZ-033](GAZ-033.md)）②神田＝逢初川（[GAZ-099](GAZ-099.md)）の2系統で、本条は③浅草＝雷門前〜花川戸の紺屋前小溝という第3の同名異川の集成記録。**谷端川系の藍染川（谷中）と混同しないための対照表の注意行として登録価値がある**。「その日音院の辺に池ありてその水浅草川へ入りし」の池（浅草川へ流入）は[MAP](../maps/MAP-004.md)江戸府内実測図等の池の比定の対校課題〕。
- **新堀条・石神井用水条〔文言候補・石神井用水の流末側の集成文言〕**: 「（新堀）**今は石神井用水の余水をも中反国（＝団候補・OCR）の遠にて此堀落せり 此頃ハ大川より汐さし入て通船の便あり 又此堀出来し東京（＝江戸候補）後は堀の両岸をも新堀端と呼ひて小地名と成せり 此堀に数條の橋を架して往来に便す**」＋「**石神井用水 豊島郡石神井村より流出せる石神井川を引来れる用水なれはたゝちに名とせり 用水分水ハ同郡王子村金輪寺唯下にて石堰を設けて引分てり 二十三ヶ村の組合なり その用水永成し年月等の事は王子村にみへたり**」＝**①新堀（中反団海禅寺裏手〜東本願寺西〜南へ流れ三味線堀に合す・堀幅凡2間半余・江戸図説所引の明暦年後開削説・寛永4年東叡山御建立時の水堀割説の引用と「恐く誤り」の按語）に石神井用水の余水が落ちていた、②新堀端（両岸）の小地名、③石神井用水の定義（石神井村流出の石神井川を引く用水・分水は王子村金輪寺唯下の石堰・23ヶ村組合・用永成の年月は王子村に見ゆ）**。〔**石神井用水の流末側（浅草川・山谷堀・新堀）に余水が達していたことの市中集成本側の文言＝風土記稿の王子村石堰系統（[GAZ-032](GAZ-032.md)）の浅草巻側裏付け。対照表の石神井川（谷田川）行の追記材料。「東京後」は「江戸後」のOCR誤読候補〕。
- **川附のその他の水名〔文言候補〕**: 駒洗川（橋場下の宿を流るゝ小溝・江戸志所引・頼朝馬洗説は「覚束なき説」と按語）・思川（四国雑記所引の浅茅か原の思ひ川・「恐くは前の駒洗川のことくにもおもはるれ」の按語）・山谷堀（今戸橋の下より山谷町まで大川の入堀）・鏡ヶ池（万葉記所引・梅若丸の母妙亀の身を投げた池・総泉寺大門浅茅か原）・達磨ヶ池（浅草志所引・花川戸大長屋裏・真珠庵抱屋敷庭）・姫池附石枕（浅草寺東の方妙王院の庭・白川院御製）等、目録「川附」（か淵・鐘か渕・乙か渕・駒洗川・思川・藍染川・山谷堀・新堀・石神井用水・鏡か池・達磨か池・姫池附石枕）に対応する集成記事群（いずれもOCR・原画像照合課題）。
