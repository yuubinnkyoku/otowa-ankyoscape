# [GAZ-120] 町方書上[67] 湯嶋町方書上壱 — 湯島・神田明神下側3町の千川上水樋・古上水文言

- **書誌〔確認〕**: 『町方書上[67] 湯嶋町方書上　壱』（写・NDL次世代デジタルライブラリー [book/2571548](https://lab.ndl.go.jp/dl/book/2571548)・105コマ）。各条の署名は湯嶋町（文政10亥年・一冊中に「辰五月」の回月も見える）、湯嶋横町（文政十亥年二月）、神田明神下川辺町（亥二月）、神田明神下御手代屋敷（亥二月）等。**引用文言はすべてOCR由来で要原文照合。ページ番号はfulltextの `2571548_{NNNNNNN}.txt` コマ番号。**
- **湯嶋町条の樋文言〔文言候補・GAZ-024にない104間6尺条の原本側〕**: 「**千川上水之儀は安永九子年中町内往還に長折廻し百四間六尺程往来中程に埋中樋近渡し有之尤往来之内に中桝弐ケ所有之所天明七未年四月中御差止ニ相成候節取潰シ**」（p15）＝〔**区間長104間6尺・埋中樋・中桝2ヶ所・天明7未年4月中差止取潰。町帰属＝署名p21の湯嶋町条（p15の前段に同町の稲荷社の記載）**。[GAZ-024](GAZ-024.md)（雄山閣刊本・湯島之部の町別数値リスト）に104間6尺の条が見当たらないため、**刊本リストの未採録分を写本側から補う文言候補**〕〔「折廻し」の表現は [GAZ-044](GAZ-044.md)（御府内備考・相生町条の130間三方折廻し）等と同型語彙〕。
- **神田明神下川辺町条の古上水文言〔文言候補〕**: 「**古上水右は安永九子年中子川上水町内へ相懸り候得共無程御差冨に相成候様右之形に当時相見へ不申候**」（p36）＝〔**「子川上水」は「千川上水」のOCR崩れ候補、「御差冨」も同候補。安永9年再掛→無程差止（→形は当時見えず）の定型。条帰属＝署名p41の神田明神下川辺町条（同条に名主太郎右衛門（片山氏）の由緒で神田明神下同様町等の言及）**。**千川上水の末端部（神田明神下側）の町方書上レベルの給水記憶として [GAZ-124](GAZ-124.md)（外神田町方書上二の佐久間町・相生町側文言）と対校できる**〕。
- **神田明神下御手代屋敷条の「古上水沢」文言〔文言候補・語形要照合〕**: 「**古上水沢之儀は安永九子年中千川上水町内へ相懸り候得共無程御差留に相成候処右之形は当時相見合不申候 一幸龍寺跡万隆寺跡右弐ヶ寺往古当所之住居致罷有候由明暦三酉年中大火之節類焼仕候処右弐ヶ寺共浅草田甫へ引地に相成候様申伝へ候**」（p48）＝〔**①「古上水沢」の「沢」の字があるかはOCR判読課題（「古上水」+接続語の崩れ候補。原字は要照合）、②安永9再掛→無程差止→形なしの定型文言が神田明神下御手代屋敷条でも出る、③幸龍寺跡・万隆寺跡が明暦3年大火で類焼し浅草田甫へ移転（引地）した由緒の付記**。条帰属＝署名p61の神田明神下御手代屋敷条〕。
- **定型調査項目としての「古上水〔跡〕」〔陰性記録・書上形式の観察〕**: p60（湯嶋横町条内）「古上水郡〔跡〕…無御座候」、p69「古上水跡…無御座候」、p90「古上水江〔跡〕…無御座候」等、**各町の取調箇條書上の定型項目列（古塚・御殿跡・古上水跡・駒場跡等）に「古上水（跡）」が含まれ、多くの町が「無御座候」と回答している**＝町方書上という形式自体が千川上水跡への聞き取りを全町に一律に求めたものであることの写本レベルの観察材料〔[GAZ-118](GAZ-118.md)・[GAZ-119](GAZ-119.md)（本郷側）と同じ形式の湯島側陰性行。「無御座候」町名の特定は次回の原画像照合課題〕。

## 制限・未解決

- ①「百四間六尺」の数値・「子川上水」「御差冨」「古上水沢」の語形など本冊の文言はすべてOCR由来で原画像照合が前提。②湯嶋町条の署名回月「辰五月」（他条は文政10亥年）の年代（文政11辰年＝1828候補）は未確定。③p15条（104間6尺）と [GAZ-024](GAZ-024.md) の町別数値リストとの対応（刊本側の未採録か否か）は雄山閣刊本の該当頁照合まで保留。④神田明神下側2町の「古上水」が給水樋・井戸のどちらを指すかは本冊の文言では特定できない（浅草側の「井戸」文言〔[GAZ-127](GAZ-127.md)〕と違い、本冊では施設種別に触れない）。
