# [GAZ-046] 新編武蔵風土記稿（豊島郡 巻11-17）— 弦巻川の水元と松屋橋の文言

- **書誌〔確認〕**: 『**新編武蔵風土記稿**』巻之11〜17（豊島郡之3〜9・1884年〔明治17年〕刊の次世代DL版）。NDL次世代デジタルライブラリー [book/763977](https://lab.ndl.go.jp/dl/book/763977)。文化〜文政期の幕府編纂（幕府編纂原典の1884年刊）**引用はすべてOCR由来で、文言は原文画像との照合を要する。**〔本巻には幡ヶ谷村条の「用水ハ玉川上水ヲ分流シテ田間ニ沃ケリ」等も含まれるが、本項目は音羽町・西青柳町周辺の弦巻川文言に限る〕。
- **弦巻川の水元＝「水元巢鴨雜司ヶ谷接地ノ田間」堀＋松屋橋・申橋〔確認・repo初出の風土記稿の弦巻川文言〕**: 巻之15終わりの音羽町（西青柳町地内）の項目に——「**東ノ方耕地際ヲ流ル 水元巢鴨雜司ケ谷接地ノ田間（…）堀二ス 昔此邊耕地タリシ…（松屋橋の由緒書きか・OCR混入の広告文字を挟む）…松屋橋ト號ス長九尺 弦卷川下流ニ架ス 一○石橋二 申橋ト呼フ長一間 小流ニ架ス 共ニ西青柳町ノ西頃ヨリノ小名ナリアリ 護國寺（ハ音羽六町目東裏鼠坂下ニアリ…）**」〔**①（西青柳町の）東の方の耕地際を流れる（川の）**水元＝巣鴨・雑司ヶ谷接地处の田間の堀**であること、②**松屋橋＝長9尺・弦巻川の下流に架かる**、③石橋2ヶ所・申橋と呼ぶ（長1間・小流に架かる）・ともに西青柳町の西頃よりの小名であること**〕〔**①＝[GAZ-013](GAZ-013.md)（御府内備考・東青柳町「水上は巢鴨村雜司ケ谷村之內田場際より流出」）と同じ水元認識（巣鴨・雑司ヶ谷に接する田間）を、幕府の官撰地誌（風土記稿）が独立に記録＝弦巻川の水源論（丸池〔[GAZ-013](GAZ-013.md)西青柳町条・[GAZ-002](GAZ-002.md)北豊島郡誌〕と田場際論の両論の「田場際」側の公式文書側の文言。両者の関係＝丸池から出た水が田畑際を流れて青柳町に至る経路と整合するが、本文言は丸池に触れない）。②＝[GAZ-013](GAZ-013.md)の松屋橋（石橋長九尺幅壱間程）と橋長が一致（長9尺）＝風土記稿と御府内備考の松屋橋記録の一致。③申橋（長1間・小流）はrepo初出の橋名候補**〕〔OCRに巻末の広告・活字崩れ（「四川…お客様…」等）が混入しておおり、文言の連続性の復元は原文照合を要する〕。

- **池袋村条・中丸村条・下板橋宿条・上板橋村条の精読（巻之12・豊島郡之4・1884刊版OCR）〔確認・第129回・repo初出の村条群〕**:
  1. **池袋村条**: 「**池袋村ハ地高シテ東北ノ方ノミ水田アリ 其邊地窪ニシテ地形袋ノ如クナレハ村名起リシナラン…東ハ新田堀之內村 西ハ中丸村 南ハ雜司谷村（巽ハ巢鴨村少ク係リ）北ハ金井久保村ニ及フ 東西五丁南北十三丁 **用水ハ仙川用水ヲ引沃ク**…**」＝**①村の地形（地高・北東のみ水田・窪地が袋状）と地名説、②四至（東＝新田堀之内村・西＝中丸村・南＝雑司ヶ谷村・北＝金井久保村）、③「用水は仙川用水を引沃く」の官撰文言**＝[GAZ-015](GAZ-015.md)（池袋村条の二次転記・本条で本文側確認が完了）。
  2. **中丸村条**: 「**中丸村ハ元祿ノ改ニ枝村ト傍記ス 今ハ別村トナレリ…東ハ池袋村 西ハ下板橋宿 南ハ長崎村 北ハ金井久保村ナリ 東西四丁半南北十一町 **用水ハ仙川用水ヲ引用ユ**…村ノ飛地池袋村內ニ少クアリ**」＝**①元禄の検地帳で枝村傍記→別村化、②四至（東＝池袋・西＝下板橋宿・南＝長崎・北＝金井久保）、③「用水は仙川用水を引用ゆ」＝[GAZ-015](GAZ-015.md)の金井久保村条「用水等前村に同じ」の「前村」＝中丸村説（ブログの解説）の本文側裏付け、④飛地が池袋村内**。
  3. **下板橋宿条**: 「**…石神井川（ヲ流ル?） 幅七間 上宿中宿ノ間 ○仙川用水（場?滿?…崩壊文言） ○板橋（石神井川ニ架?） 長九間 幅三間 中山道ノ（石神井川ニ架?）… ○水車 村ノ東 名主市左衞門カ地內（往還?）…重吉ト云（ものノ持?） 石神井川ヲ引テ車ニ灌ク 車輪大サ徑一丈六尺（五寸?） 左右設クル所ノ杵五十三（本?） 挽臼ハ一組ナリ **水車ハ關東第一ニシテ（コレニ?）勝レルモノナシト云**…**」〔**①石神井川の幅7間（上宿・中宿の間）、②宿条内の「○仙川用水」の見出し文言（前後がOCR崩壊で文言候補・千川上水跡が下板橋宿を通る〔GAZ-048⑩〕ことと対応する可能性）、③板橋＝長9間・幅3間・中山道の石神井川架橋＝「板橋」の地名の直接の橋の官撰記録、④水車＝村の東・名主市左衞門が地内（往還）・重吉の持ち・石神井川引水・車輪径1丈6尺5寸・左右の杵53本・挽臼1組・「水車は関東第一にしてこれに勝れるものなしと云」＝下板橋宿の石神井川沿いの水車（製粉・精米用と見られるが用途は本文に未記載）の規模の記録〔repo初出〕**〕〔**本条のOCRは冒頭部が二重化・混在して崩壊しており、「石神井川を流る幅七間上宿中宿の間」の繰り返しと「○仙川用水（?）」の文言候補、板橋・水車の項目割注の帰属は原画像照合を要する**〕。
  4. **上板橋村条（参考・水系外）**: 「**上板橋村ハ…東ハ下板橋宿 西ハ下練馬村 南ハ長崎村 北ハ中臺村ナリ…**用水ハ石神井川ヨリ引沃ク**…石神井川…村ノ中央ニアリ幅三四間…石橋（ヲ?）…長六間半幅…**」＝**上板橋村の用水は石神井川**（仙川用水ではない）＝谷端川・千川水系からは外れるが、下板橋宿条の「仙川用水」候補との対照として記録〔OCR崩壊著しく文言候補〕。

## 制限・未解決

- ①「堀二ス」等のOCR崩れ（「堀卜号ス」「堀二號シ」等の候補がある）と「田間（…）堀」の間の欠落文字、②松屋橋条の前後の文脈（「昔此邊耕地タリシ」以下の橋の由緒）は広告文字混入で未復元、③申橋の正確な位置（西青柳町の西頃の小名・「共ニ」が松屋橋と申橋の両方を指すか）、④巻16（雑司ヶ谷村条）以降の弦巻川・千川関連文言の精読は本巻（1884刊・OCR劣化が激しい）では進めず、**2026-11-15（第111回）に大日本地誌大系版（[GAZ-048](GAZ-048.md)・lab 1214832・1929年刊・OCRが格段に清明）で同範囲を精読して本項目の欠落部分を復元した**——**「堀二」＝「堀二（つ）より流れ来り」（2本の堀＝東西二細流）、「申橋」の原字候補＝「庚申橋」（長一間・小流・西青柳町の西・護国寺持）、板橋2の一方＝「千貫橋」（音羽六丁目東裏鼠坂下・長七尺）、東流＝桜木町で神田上水の「石樋」を通して江戸川へ、西流＝「雑司ヶ谷村丸池の下流弦巻川」、二流の合流が「桜木町」「音羽町二町目の辺」、鼠ヶ谷下水の呼称区間が「九町目迄」＝いずれも[GAZ-048](GAZ-048.md)に詳録。本文言の原画像照合は今後も1884刊版・大日本地誌大系版の双方で要する。⑤〔第129回追記〕巻之12の池袋村条・中丸村条の「仙川用水」（本文側文言）は風土記稿の豊島郡側の用例で、多磨郡側の用例（下祖師ヶ谷・橫根・大藏・鎌田村条等）は[GAZ-057](GAZ-057.md)（巻122-128・763995）に詳録。下板橋宿条の「○仙川用水」の文言候補（OCR崩壊）と下板橋宿の水車・板橋の原画像照合は今後の課題。
