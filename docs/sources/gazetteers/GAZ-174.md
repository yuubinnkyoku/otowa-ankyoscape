# [GAZ-174] 町方書上[119] 中之郷 三止 — 瓦町条の源森川・源兵衛堀・源森橋・源安川文言群

- **書誌〔確認〕**: 『[119] 中之郷町方書上 三止』（写・NDL次世代デジタルライブラリー [book/2571600](https://lab.ndl.go.jp/dl/book/2571600)。NDL API volume欄直接確認）。中之郷瓦町条（koma 34-41）周辺を主に採録（koma 15-17等の隣接町条は対校に言及）。引用文言はすべてOCR由来で要原文照合。※[GAZ-138](GAZ-138.md)（小梅瓦町〔=南本所元瓦町〕条）と対になる**中之郷瓦町側の源森川文言**（両「瓦町」は別町）。
- **源森川＝源兵衛堀の複合文言〔文言候補・本冊最重要〕（koma 37-38）**: 「**一源森川幅拾四間長凡百七間 右は町内北之方に有之 字源森川と相唱候 万治年中堀割之由申伝 一名源兵衛堀吉留（?）申候 右は中々郷横川町に而申上候通 万治二亥年中大横門（?）御堀割に相成 其後右江価（?）候中之郷業早橋（=業平橋・OCR変種）辺 寛文三卯年中田堀官（?）に相成 右代地竪川通五之橋町之場所被下置候儀に付 追々御堀足しに相成候而 大川え流通仕候様ニ罷成 御檜蔵材木入宜敷様二相成候…**」（koma 37・OCR）＋「**…右得地者中之郷村に立帰新田に相成享保十七子年御高入に相成候 尤源兵衛堀と唱候里俗有之候に付別段御堀割に相成候義にも御座候哉相知不申候得共 往古ゟ諸向書上之扣等都而源直（?）と相認め有之 表立源兵衛堀と相唱候儀無御座候間 右両様之名目何之儀に寄唱始候哉由緒は相分り不申 古老之者にも申伝等無之由に付前々ゟ認来り候源森之名目を以申上候儀にて 源兵衛堀え相唱候儀は万里俗之申伝（?）に御座候**」（koma 38・OCR）＝**①源森川（巾14間・長約107間・町内北）は万治年の堀割と申伝え、一名「源兵衛堀」、②万治2年（1659）の大横門（OCR候補）堀割→中之郷業平橋辺が寛文3年（1663）に田になった（代地として竪川通五之橋町を下置）→堀足し→大川通航・御檜蔵の材木引入路に、③その得地が中之郷村に立ち戻り新田となり享保17年（1732）に高入、④名目論＝「源森」が書上の正系、「源兵衛堀」は里俗の申伝**という複合文言候補。〔**本所白堀上水堀跡（[GAZ-138]小梅側の業平橋南の上水堀埋立跡・寛文年中堀割・享保17高入文言）と、中之郷側の業平橋辺の堀群（万治2堀割→寛文3田畑化→新田→享保17高入）が同一の処分チェーンの両岸に見える対照候補**（両者が同一の堀かどうかは本2文言からは断定しないが、業平橋・寛文・享保17の同年次対応は丹念な対校課題）。源森川の巾14間・長107間は初の定量文言候補（repo初出）。「田堀官」は判読候補（田畑/田圃?・「官」は崩壊か）、「大横門」は「大横川門」候補。〕
- **源森橋＝源兵衛橋の文言＋寛文12年築留の100間余引込（koma 39-40）**: ①「**一源森橋長七間…（巾）弐升壱尺(?・OCR)…右は町内北之方字源森川に懸渡有之 寛文二寅年中伊奈半十郎様御掛りニ而始而御懸ケ被遊候 後地方御掛りニ而度々御懸直御修復共御座候 尤字源森橋え相唱 一名源兵衛橋共里俗相唱申候**」（koma 39・OCR）＝**源森橋（長7間）の寛文2年（1662）の伊奈半十郎初懸・諸修復・里俗「源兵衛橋」の並記**文言候補。②「**一築留堤 右は町内ゟ北之方に有之候 字源森川築留に御座候 往古浅草川西水之節源森橋押流候故 右橋北之為 寛文十二子年中伊奈半十郎様ゟ築留被仰付候由申伝候 尤其後元一禄六酉年北之方川岸付水戸様御屋敷に罷成 船御通路之為六品（=六間?・OCR候補）築留東之方え百間余引込候由 右跡江呼今之源森橋御掛け被成候共申伝候 但右築留堤ゟ東之方川筋をも以前は源安川と相唱候哉之儀相知不申候得とも 当時は大横川入江日里俗に申**」（koma 40・OCR）＝**③浅草川西水（西方からの洪水?）で源森橋が押し流されたため寛文12年（1672）伊奈半十郎が築留、④元禄6年（1693）に水戸様御屋敷の船通路のため築留を東へ100間余り引き込み、その跡に今の源森橋を掛け、⑤築留堤の東の川筋は以前「源安川」→当時は「大横川入」**という文言候補。〔**「源安川」という川名の用例（repo初出候補、文言は「哉」付きで不確定を留保）＋源安川→大横川入への呼称変遷の明記**＝[GAZ-138](GAZ-138.md)の「横川入堀」・[GAZ-172](GAZ-172.md)の「源森川/桑平川」と並ぶ本所堀群の呼称系譜の新枝。橋の掛替に伴う堀の付け替え（築留の100間余引込）という物理的変化の記録としても独特。〕
- **宝永2年の大川汲水用の川岸堤＋瓦師文言（koma 41）**: 「**一長百七拾三間壱尺九寸（巾?）申弐間 右は町内北之方源森門幷大横川入江川岸通に有之 大川汲水之節為水除 宝永二酉年中奉願 当町持にて築立申候…一当町瓦師当時之家数拾四軒竃数弐拾八御座候**」（koma 41・OCR）＝**大川の汲水（高潮?）の水除けとして宝永2年（1705）に当町持ちで築いた堤（長173間1尺9寸・巾2間）が源森門・大横川入江川岸通りにある**という文言候補＋瓦師14軒・竃28の記録。〔「大川汲水の節の水除」＝汐（満潮）が川を遡る際の堤。源森門の門名の用例も新出（地名対照候補）。〕
- **八軒町条・掻屋敷の里俗名文言（koma 15-17・対校）**: 中之郷八軒町条の「当町西之方横町通を里俗掻屋敷と相唱」（koma 16・OCR）等＝[GAZ-138](GAZ-138.md)（南本所元瓦町〔=かつて掻屋敷〕）の地名系譜と対照可能な**中之郷側の「掻屋敷」里俗名の空間的隣接用例**の記録候補（両者の関係は断定しない・文言候補のみ）。

## 制限・未解決

- ①すべてOCR由来で要原文照合（「田堀官」「大横門」「右江価」「吉留」「六品=六間」「弐升壱尺」「源直=源森」等の判読候補だらけで、本冊の文言は特に崩壊が多い）。②中之郷瓦町条と小梅瓦町条（[GAZ-138]）の「瓦町」の別町性・両文言の堀の同一物性は断定しない。③「業早橋」=業平橋のOCR変種候補は[GAZ-138]の位置文言（業平橋南8町4段20歩）との対応課題。④源森橋の「巾」の数値は判読不能（「弐升壱尺」）。⑤元禄6年の「六品築留」の原字は未決。
