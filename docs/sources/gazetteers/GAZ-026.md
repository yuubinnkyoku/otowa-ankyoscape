# [GAZ-026] 巣鴨町方書上 — 1826年の巣鴨町内下水の実態

- **書誌〔確認〕**: 「巣鴨町方并寺院書上」（文政9年・地誌御調書上）。NDL次世代デジタルライブラリー [book/2571625](https://lab.ndl.go.jp/dl/book/2571625)。OCRテキストで下水・橋の条を確認。**文言・寸法はOCR由来で要照合。**
- **下水堀2ヶ所の流れ先〔確認・repo初出〕**: 巣鴨町の下水堀2ヶ所（**幅2尺〜3尺**）の流れ先が「家裏通り→同町横町→**巣鴨原町江相流**」「上中組町屋前→**武家方屋敷町屋境江相流**」と申告される＝1826年の巣鴨町内の排水（下水）が**巣鴨原町方面・武家屋敷境へ流れる**実態記録。石橋3ヶ所の寸法も記録される〔寸法はOCR要照合〕。
- **位置づけ〔観察〕**: 巣鴨町は千川上水の江戸市中入口（巣鴨庚申塚通り）に位置し、町内下水は谷端川水系の源流側排水に接続すると推定されるが、**本書上の下水堀と谷端川・千川上水の接続は文言上直接確認できない**〔推定は留保〕。千川上水の境窪分水（谷端川）〜庚申塚間の水環境の1826年時点の町方側記録として、[GAZ-024](GAZ-024.md)・[GOV-176](../gov/GOV-176.md)と地域的に連続する資料。

## 制限・未解決

- ①下水堀と谷端川（境窪分水）の水理的接続は未確認。②「巣鴨町」が御府内扱いか村方かは本書上の帳簿体系の要確認。③石橋3ヶ所の位置は未特定。
