# [GAZ-087] 東京府北豊島郡高田村・豊多摩郡戸塚村（1911）— 高田村・戸塚村の字名一覧候補〔第160回〕

- **書誌〔確認〕**: 東京遞信管理局編『東京府北豊島郡髯田村・豊多摩郡戸塚村』（遞信協會・明治44年〔1911〕7月。NDL次世代デジタルライブラリー [book/1089212](https://lab.ndl.go.jp/dl/book/1089212)。書名の「髯田村」は**「高田村」のOCR/誤記候補**）。[GAZ-052](GAZ-052.md)（板橋町冊）・[GAZ-078](GAZ-078.md)（瀧野川村冊）・[GAZ-079](GAZ-079.md)（巣鴨町巣鴨村冊）と同じ**遞信協會郡部シリーズ**の高田村＋戸塚村合本冊（OCR末尾の奥付文言で発行所「東京市芝區…遞信協會」・印刷発行年月日の候補「明治四十(四)年…七月十八日…七月十五日印刷發行」・販賣所（大倉三省堂書店・丸善・東京堂の候補）が読める〔いずれもOCR崩れで要照合〕）。**本冊のOCRは表組みの列崩壊が高度（全1575字に満たない断片化）で、以下の字名はすべて原画像照合を要する候補**。
- **高田村の字名一覧候補〔確認・OCR列崩壊・要照合〕**: OCRに「**北豊島郡高田村字名一覽表**」の表題が立ち、字名候補として「**高田千登世町**」（複数回現れる）「**高田老桜町**」（老松町のOCR候補）「**字金久保**」「**雜司ヶ谷〔旭出〕町**（「雛司ケ谷旭出町」の列崩れ候補）」「**字東耕地**」等が読み取れる＝**1911年時点の北豊島郡高田村（弦巻川・水窪川の流域村）の公式字名一覧の候補**〔千登世町（ちとせちょう）は1912年の町制・1932年の区編入後も残る字名で、[BOOK-110](../books/BOOK-110.md)（1922年・滝野川）や東京区分町鑑（1939337）の町名リストと対照できる。金久保・雑司ヶ谷旭出町は[BOOK-116](../books/BOOK-116.md)（1922年・高田町の字水窪新田・雑司ヶ谷墓地周辺）と対照できる字名群〕。
- **戸塚村の字名一覧候補〔確認・OCR列崩壊・要照合〕**: OCRに「**豊多摩郡戸塚村字名一(覧)表**」の表題が立ち、字名候補として「**下戸塚**」「**諏訪**」「**源兵衛**（候補）」「**中通**（候補）」「**向**（候補）」等が読み取る（列崩れで確定できない）＝**1911年時点の豊多摩郡戸塚村（神田上水の南岸町）の字名一覧の候補**〔[BOOK-149](../books/BOOK-149.md)（1931・戸塚町誌）の小字名（馬場崎・馬尿川・川向・秣川・諏訪等）・[BOOK-190](../books/BOOK-190.md)（1922・戸塚町の字名「馬尿川」「中通」「源兵衛」「諏訪」）と対照できる1911年時点の字名層〕。
- **水系文言の陰性〔確認〕**: 本冊のOCR全文で「弦巻」0件・「水窪」0件・「千川」0件・「神田上水」の川名言及は出ない（地番・字名の帳簿であり河川現勢の記録は含まれない）。「千登世町」の「千登世」と千川の語源論（千川＝千登世説）を混同しない（千登世町の地名由来は別案として管理）。

## 制限・未解決

- ①本冊はOCR高度崩壊（列崩壊・文字化け）で、字名・表題・奥付の読みはすべて原画像照合が前提。「髯田村」＝高田村の比定もOCR/誤記候補として扱う。②字名と河川・地形との位置関係は本冊の地図部分の読図を要し、OCRからは判読不能。③戸塚村側の字名の網羅（馬尿川の字名が本冊に現れるか）は原画像確認が前提（1922年の[BOOK-190](../books/BOOK-190.md)で確認される字名「馬尿川」の1911年側の先行確認の可否は未確定）。④千登世町・老桜〔老松〕町の表記の原字確認。
