# [GAZ-002] 『北豊島郡誌』（1918年）

- 北豊島郡農会編『北豊島郡誌』大正7年（1918年）刊、614頁、336画像。
- 東京都立図書館デジタルアーカイブ: https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00005243
- 資料コード: 1124279807、パブリックドメイン。
- 地理篇・水利（印刷38〜42頁＝画像44〜46）に谷端川の独立記述（「長崎村より出る細流…池袋…板橋町の南辺…瀧野川町…西巣鴨町の北部…小石川区…神田川上流に合す」）、千川用水（元禄九年・太兵衛・徳兵衛・幕府の命）、千川上水跡（保谷村より巣鴨村まで行程六里余・享保七年廃止・庚申塚経由で本郷湯島浅草・別伝として石神井池起源説を柳窪湧水と訂正）、石神井用水（明治十九年水利組合・明治二十六年大沼田・田無用水残水）、田柄川・白子川の記述がある。
- 2026年10月25日に画像44〜46の高解像度判読を実施。

## 2026-11-15 追記（第106回）：次世代デジタルライブラリーOCR全文確認による追加文言

NDL次世代デジタルライブラリー [book/1879945](https://lab.ndl.go.jp/dl/book/1879945) のOCR全文を確認（**文言はOCR由来で原文画像との照合を要する**）。水利篇の既知記述（谷端川・千川用水・千川上水跡）以外に、以下の追加文言を確認した。

- **法明寺条の弦巻川〔確認・「古へは布引川」文言の本書内での位置〕**: 「北に進めば一條の渠流あり、**之を弦卷川といふ、古へは布引川とも稱せしよし、水源は池谷の邊に發し、下流は雑土[雑司ヶ谷]に出で、音羽町の西方を經て江戸川に會す**、石矼[桟]を渡れば仁王門あり」＝**①弦巻川＝法明寺北方の渠流、②古くは布引川とも称した由、③水源は池谷の邊（池谷戸）、④下流は雑司ヶ谷から音羽町の西方を経て江戸川に合流**〔対照表の「布引川（弦巻川上流の区間名）」の本書レベルの文言。**「水源は池谷の邊に發し」＝池谷戸（丸池所在の小字）を水源とする明言**〕。
- **【溜池】条＝丸池→弦巻川源流の1918年明言〔確認・重要〕**: 「**溜池 大字雜司ケ谷字池谷戶淺井原に在り、丸池と稱す、古は大池なりしよし、明治五年の調には『無名池 廣さ六百坪』と記さる、今は埋れて僅に十數坪許なるべし、此池より細流を出す、弦卷川これなり**」＝**①丸池＝雑司ヶ谷村大字池谷戸字浅井原に所在、②古くは大池、③明治5年の調（地租改正編纂資料か）に「無名池 広さ六百坪」と記録、④1918年時点では埋まって僅か十数坪、⑤この池から出る細流＝弦巻川と明言**〔**丸池→弦巻川源流の対応を1918年が「此池より細流を出す、弦卷川これなり」と明言した記録**。[BLOG-073](../blogs/BLOG-073.md)/[BLOG-074](../blogs/BLOG-074.md)（遊歴雑記・文化年間「三百餘坪」）と**明治5年の「六百坪」**の面積の対照（遊歴雑記の300余坪と明治5年調の600坪は50年余の差）も記録できる。「無名池」＝明治5年時点で丸池の名が公文書側になかった点も注記〕。
- **東京府誌引用の雑司ヶ谷町の弦巻川〔確認・要照合〕**: 「東京府誌に載せたる雜司ケ谷の變遷は左の如し。雜司ケ谷町もと自證院領上地…**里俗御嶽と唱ふる丘の下に幅九尺餘の小川あり、傳に舊義家奧州征伐の時此處にて弓弦を卷きしに因て弦卷川と號すと、此水西靑柳町より音羽の西を下りて關口に合す**」＝**①雑司ヶ谷町の御嶽（丘）の下に幅九尺余の小川、②義家弓弦説の伝承、③西青柳町から音羽の西を下り関口に合流**〔東京府誌（明治初年の府誌）経由の記述で、[GAZ-030](GAZ-030.md)（江戸名勝志）の絃巻川・[BOOK-124](../books/BOOK-124.md)（遊歴雑記引用）と同じ谷筋の記録。「幅九尺餘」＝流路規模の具体的数値〕。同章の巣鴨町条には遊歴雑記の丸池記事も引用（「池水旱魃にも枯ずして雜司谷妙法寺の門前を東流し、水下は御嶽を過…西靑柳町うら通音羽の瀧へかゝり、末は上水の埋石桝をくゞり江戶川へ落込なり…**水源は池袋より流出すこれなり**」）＝**丸池→妙法寺門前→御嶽→西青柳町裏通→音羽の瀧→上水の埋石桝→江戸川という流路の詳細経路**〔埋石桝＝神田上水の伏樋か。OCR要照合〕。
- **高田村の小字リスト〔確認〕**: 「大字高田 下田、四ツ家、宿、**堰下**、後田、階子田、八反日、金久保澤、稻荷原、龜原、中島前、**水久保新田、水久保**、中島御獄、**鶴卷**、金山、美名實、堂杉、**中谷戶、池谷戶、淺井原、西谷戶**、大門原、**星跡**」＝**堰下・水久保・鶴巻・池谷戸・浅井原・西谷戸・星跡など弦巻川・水窪川関連の小字が大字高田（雑司ヶ谷を含む）に集中**〔対照表の水久保・池谷戸・星跡の1918年公式リストレベルでの確認。「堰下」＝神田上水の堰（大洗堰か）に関係する小字名候補（対照表に追記）〕。
- **星跡の井・氷柱ヶ谷の古道〔確認・repo初出の古道〕**: 「**星跡の井 昔時慈覺大師遊錫の折、此地に星氣の降るを見て、井を穿ち、清水を得て病者を癒せしと傳ふ、その地大字雜司ケ谷に屬し、星跡の字殘れるも、井の所在は不明なり**」「**氷柱ヶ谷の古道 大字雜司ケ谷字威光に在り、古の鎌倉街道にあたる、現今法明寺の所有地に入れるも、尙ほ舊觀を存ずと聞く**」＝**①星跡の井（慈覚大師・井の所在は1918年時点で不明）、②氷柱ヶ谷の古道＝雑司ヶ谷字威光の古鎌倉街道（現・法明寺所有地）**〔**氷柱ヶ谷の古道はrepo初出の小地名・古道記録**（対照表に追記）。弦巻川谷筋（氷柱ヶ谷＝つらら谷）を通る旧道の記録として星跡・御嶽とともに谷地形の比定資料になる〕。目次に「氷柱ヶ谷の古道」が高田村の名勝旧蹟として立項されていることも確認。
- **矢端川の橋（巣鴨町条）〔確認・矢端川の1918年記録〕**: 「**藤橋、熊之窪橋、東福寺橋は共に、大字巢鴨に在りて矢端川に架し、大塚、小石川等に通ずる街路に當れり**」＝**大字巣鴨で矢端川に藤橋・熊之窪橋・東福寺橋の3橋が架かる**〔矢端川＝谷端川下流（池袋〜巣鴨）の別名候補の1918年記録。[BOOK-124](../books/BOOK-124.md)（1937・「池袋田甫は矢端川を挾んで板橋田團と相對した」）と合わせて対照表に「矢端川」として登録。矢端川の橋名3つは橋名調査の候補として記録に値するが、橋名調査への正式登録は谷端川への帰属確定後とする〕。同じ巣鴨町条に「**藍染川は源を大字巢鴨三丁目の溜池より發し、巢鴨、瀧野川の兩町を經て下谷區に入り、不忍池に注ぐ**」〔藍染川（谷田川系）の源＝巣鴨3丁目の溜池という独立記録もある。谷端川の谷頭との混同に注意〕。

**以上、本書は谷端川・千川用水の既知記述に加え、弦巻川源流（池谷の邊＝丸池）・小字群・古道を1918年レベルで固定する基本資料であることが改めて確認された。**
