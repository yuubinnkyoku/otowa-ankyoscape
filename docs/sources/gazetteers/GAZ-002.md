# [GAZ-002] 『北豊島郡誌』（1918年）

- 北豊島郡農会編『北豊島郡誌』大正7年（1918年）刊、614頁、336画像。
- 東京都立図書館デジタルアーカイブ: https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00005243
- 資料コード: 1124279807、パブリックドメイン。
- 地理篇・水利（印刷38〜42頁＝画像44〜46）に谷端川の独立記述（「長崎村より出る細流…池袋…板橋町の南辺…瀧野川町…西巣鴨町の北部…小石川区…神田川上流に合す」）、千川用水（元禄九年・太兵衛・徳兵衛・幕府の命）、千川上水跡（享保七年廃止・庚申塚経由で湯島浅草）、石神井用水（明治十九年水利組合・明治二十六年大沼田・田無用水残水）、田柄川・白子川の記述がある。
- 2026年10月25日に画像44〜46の高解像度判読を実施。
