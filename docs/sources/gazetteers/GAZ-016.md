# [GAZ-016] 『東京市史稿』市街篇 第12

## 書誌・目次（2026-10-30、東京都公文書館の公式目次ページの直接確認・ai）

- 『東京市史稿』市街篇は全87巻（大正3年から平成8年まで刊行）。第12の収録範囲は1694年（元禄7年）正月から1697年（元禄10年）で、東京都公文書館が各巻の目次（題目・篇巻頁・年月日・出典）を公開している。第12の目次：https://www.soumu.metro.tokyo.lg.jp/01soumu/archives/0601shigai12.htm （記事ID 003-001-20240718-007728）。
- 第12の刊行年と、国立国会図書館デジタルコレクションでの収録・公開区分は未確認。
- 本ファイルの段階では本文は未閲覧。以下は目次レベルの確認である。

## 内容メモ（目次から。本研究に関わる項目）

- 護国寺関係の項目（題目・篇巻頁・年月日・出典は目次の原文ママ）：
  - 護国寺領増附（市街12-0191、1694年10月18日、柳営日次記・常憲院殿御実紀・天享吾妻鑑・甘露叢）
  - 護国寺下屋敷（市街12-0593、1695年12月7日、屋敷渡預絵図証文・屋敷書抜）
  - 護国寺門前市井編入（市街12-0767、1696年11月5日、常憲院殿御実紀）— 1696〜1697年の門前再編を追う起点（[音羽谷西側の弦巻川下流の成立年代](../../open-questions/音羽谷西側の弦巻川下流の成立年代.md) の決着資料リスト第6項）
  - 護持院護国寺修造（市街12-1131、1697年正月12日、御当代記・柳営日次記・甘露叢・人見私記続編・常憲院殿御実紀ほか）
  - 附記 護国寺門前（市街12-1143、1697年8月27日、小石川原町名主安右衛門旧記・文政町方書上）
  - 参考 護国寺前新茶屋（市街12-1151、1697年7月、天享吾妻鑑）
- 千川上水関係：千川上水鑿通（市街12-1030、1696年、出典は御府内上水在絶略記・千川文書。目次に上水篇第1巻 p.275 への相互参照「水道1P275参照」がある）。
- 第12の目次に「音羽」「雑司ヶ谷」を題目に含む項目はない（目次全件の確認による）。
