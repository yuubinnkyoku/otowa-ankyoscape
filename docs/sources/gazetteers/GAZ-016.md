## 本文確認（2026-11-16・第117回・OCR全文・文言は要原文照合）

- **千川上水鑿通条〔確認〕**: 編年記事（元禄9年）に「**○柳營日次記○元祿九年(紀是年千川上水ヲ鑿通ス。上水元…二三年五六)…篇參照。千川上水鑿通上水篇ニ具錄ス**」＝**柳營日次記側の「紀是年千川上水ヲ鑿通ス」の文言（元禄9年＝1696年の鑿通の編年側傍証）＋上水篇第1への相互参照**。続けて**御府内上水在絕略記の引用**——「**千川上水元祿九子年初テ小石川御殿、湯島聖堂、東叡山、淺草御殿ヘノ上水ナリ、多摩郡保谷村ヨリ玉川上水ヲ引、巢鴨村迄五里五拾四町堀割、巢鴨庚申塚通リ、本〓湯島淺草へ懸ル。仙川村太兵衞、德兵衞開發被仰付、仙ノ字ヲ改メ千川トナシ、兩人ノ姓ニ給ハル〇下略**」＝**①在絕略記の本冊採録版では堀割を「五里五拾四町」とする**（[GOV-171](../gov/GOV-171.md)・[GOV-222](../gov/GOV-222.md)の「五里廿四町餘」系と対立する語群の**市街篇採録テキストとしての新例**・原字形照合前提で断定はしない）＝**同頁の幸治願書（下記）の「行程五里廿四町餘」と同一頁内で対立する**という重要な対校構造。〔[GAZ-049](GAZ-049.md)⑫1の【上水在絕記】同定問題（御府内上水在絕略記とほぼ逐語一致）の本文側の追加データポイント。〕
- **明和5年12月2日の千川幸治願書全文〔確認・repo初出の全文テキスト〕**（千川文書引用・市街篇「千川上水鑿通事蹟」の注「-千川文書一〇三一上水方御役所樣」）:
  1. **元禄9年の請負の経緯**: 「**元祿九子年聖堂、東叡山、小石川御殿、淺草寺御殿、右四ヶ所御成御殿は上水御用ニ付、道奉行毛利兵橋樣、佐橋内藏之助樣、伊勢平八郎樣、武島治郞左衞門樣、若年寄加藤越中守樣御懸ニ(る)、私共先祖兩人、右上水御普請御請負付、四ケ所之御成御殿に無障懸渡、奉差上い**」＝**道奉行4人（毛利兵橋?・佐橋内藏之助?・伊勢平八郎・武島治郞左衞門）＋若年寄加藤越中守の御懸り**〔人名はOCR崩れ大・[BOOK-138](../books/BOOK-138.md)の「毛利兵橘(?)・佐橋內藏之助(?)・伊勢平八郞、武島治郞左衞門」と対応・原字照合要〕。
  2. **私費投入**: 「**不足金私共自分入用を以普請成就仕、御上水本〓通下谷淺草邊迄、一同ニ相懸ケ申い**」。
  3. **宝永4年の20か村用水許可と道奉行4人**: 「**右堀通、元水(?)巢鴨村迄之間、行程五里廿四町餘之所、左右御領私領共ニ天水場之田地ニ御座い間、寶永四亥年廿ケ村程之百姓申合、私共方に相願いと、御上水堀通之內お、少々宛村々に用水ニ爲引吳い樣ニ申ひニ付、其節道奉行小宮山庄五郞樣、荒川八兵衞樣、松下權兵衞樣、高林又兵衞樣、御四人に奉願い得と、則被仰付い**」＝**①堀通の行程「五里廿四町餘」、②宝永4（1707）年に20か村程度の百姓が申し合わせて用水を願い出たこと、③その節の道奉行は小宮山庄五郎・荒川八兵衞・松下権兵衞・高林又兵衞の4人だったこと**〔**宝永4年の用水許可時の道奉行4人の氏名はrepo初出**。また「左右御領私領共ニ天水場之田地」＝堀割沿いが天水場（天水頼み）の田地だったという当時の土地利用記述も注記される。〕
  4. **維持負担と水料米**: 「**御高札十六ケ所御座い内八ケ所、私共入用ニ(る)新規修覆共ニ相勤可申間、爲水料米田壹反歩ニ付米三斗宛、右村々〓差出ひ樣奉願い處、双方御吟味之上、願之通被爲仰付い**」＝**①高札16ヶ所のうち8ヶ所の修覆を千川家が負担すること、②水料米は田1反歩につき米3斗宛**〔**「米三斗」は[GOV-098](../gov/GOV-098.md)（千川文書写・練馬区史）・[BOOK-138](../books/BOOK-138.md)（武蔵野歴史地理）の「米三升」と対立する**。同千川文書系内での対立のため原字形（三斗/三升）の照合が必須で、**断定せず併記**。幸治願書の文面は「三斗宛」と読める。〕
  5. **日付・署名**: 「**明和五子年十二月二日 千川幸治印（千川源藏煩ニ付名代忰千川善藏印）**」＝**明和5年（1768）12月2日付・千川幸治の願書（源藏の代理として子の善藏が連署）**〔[BOOK-138](../books/BOOK-138.md)の「明和五年 太兵衛の孫幸治郞が幕府に差出した由緒書」の**実文（市街篇採録版）の所在が確定**した点が今回の主要な発見の一つ。幸治＝太兵衛の孫という系譜位置の整合。〕
- **東青柳町・西青柳町・音羽町・櫻木町の町名起立と御城奥女中衆由来〔確認・repo初出候補〕**（文政町方書上引用）: 東靑柳町条「**町名起立之儀、元祿十丑年八月町屋ニを被仰付い得共、家作人無之故、御公儀樣家作御取建有之、於御城奧女中衆靑柳と申御方町家作御拜領有之いら、右御名ヲ町名ニ相唱い由申傳、後年ニ御讓り渡シ相成い由ニ御座い**」＝**元禄10年8月の町屋仰付けの際、家作人がいなかったため御公儀が家作を取り建て、御城奥女中衆「青柳」という御方の家作拝領で町名となった**という由緒。同型の文言が——
  - 音羽町: 「**其後於御城ニ奧女中衆音羽樣と申御方、町家作御拜領有之いら、右名を町名ニ相唱い由申傳**」
  - 櫻木町: 「**女中衆櫻木と申御方、町家作御拜領有之…右御名ヲ町名ニ相唱い由申傳**」
  ＝**護国寺領三ケ町（東西青柳町・音羽町）＋櫻木町の4町の町名が、御城奥女中衆「青柳」「音羽」「櫻木」の家作拝領に由来するとする文政町方書上レベルの同時並記**。〔音羽町の奥女中「音羽様」説は[BLOG-198](../blogs/BLOG-198.md)（新撰東京名所図会・音羽局説）・[GAZ-023](GAZ-023.md)（歴史地名大系）と対応するが、**文政期（1829）の町方書上側の文言としてはrepo初出**で、**青柳・櫻木の同型説が同じ書上で並ぶことは初出**。3町すべてが同型の「御公儀家作→奥女中拝領→町名」構造で、奥女中由来説の信頼性を相対的に高める（断定はしない）。また元禄10年8月の町屋仰付けの年月日も初出。〕
- **白山前町千川屋鋪条・千川金七由緒書〔確認・GAZ-049との対校〕**: 白山前町条「**當町往古さ小石川村百姓地ニ有之い處、年代不知余語古庵拜領町屋鋪ニ相成…元祿九子年中千川上水**（後略）」＋**千川金七由緒書**（「**四百八拾貳兩壹分差出、御普請成就仕…千川村と申所〓御上水開發仕い二付、千川と申名目被下置**」・「**御若年寄加藤越中守樣、道御奉行**」・正德四卯年の御不用・金七は「**本石町四丁目新道善藏店ニ罷在い**」）＋**享保〜明和の橋数の変遷**——「**御成橋一ケ所、橋幅減少被仰付(其代り谷中通りこる橋三ケ所相增、都合橋數六ケ所新規修復共相勤來い處、明和五年御普請方御役所御掛りニ(あ)、右橋六ケ所之內貳ケ所減少被仰付、其代り年々錢十七貫文ツヽ上いる、吹所人足爲賃錢上納仕來い。殘橋四ケ所**」＝[GAZ-049](GAZ-049.md)⑫3（御府内備考巻44・「四百八拾貳兩壹分」）と**同一由緒書の市街篇採録版**で、①**「3橋（初期）→享保の6橋化（御成橋幅減+谷中通り3橋増）→明和5年の2橋減=4橋+年17貫文」という橋数変遷の構造が2テキストで一致**、②本石町四丁目の善藏店（千川善藏=練馬村側と対応か）の所在記録が追加。〔対校の細部（482両1分の「壹分」・十七貫文の「錢」）は原字照合課題。〕
