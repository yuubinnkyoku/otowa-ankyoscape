# [GAZ-025] 本郷・湯島町方書上 — 千川上水の町別申告（御府内備考の元資料側）

- **書誌〔確認〕**: 町方書上（本郷・湯島一帯の地誌御調書上、文政期）・NDL次世代デジタルライブラリー [book/2571510](https://lab.ndl.go.jp/dl/book/2571510)。OCRテキストで本郷三・四・五丁目等の「千川上水」条を確認。**文言はOCR由来で要照合。**
- **本郷側の申告例〔確認〕**: 「千川上水之儀は**安永九子年 町内往還東之方え寄大樋掛り有之 町内北木戸際往還二小桝壱ケ所有之候処 天明七未年四月中 御差止に相成候節 堤立（埋立）申候**」「**安永九子年 町内往還東之方江寄大樋掛有之 同所三丁目境横町角二大枡壱ヶ所有之候処 天明七未年四月中御差止に相成候節埋立申候**」＝**本郷三丁目境横町角の大枡・北木戸際の小桝**など、上水の樋・桝の所在が町別に申告され、天明7年4月の御差止時に埋立されたと記録。本郷四丁目境（120間程・往来中程に小掘掛渡し）、本郷五町目境（160軒程・埋小樋）の長さ記録もあり〔文言・数字はOCR要照合〕。
- **元禄不詳の証言〔確認〕**: 「**元禄年中之儀は極諸（跡）等申伝へも無御座 書留無之 相分り不申候**」＝本郷側でも元禄開削の実態が町方に伝存しなかった。
- **位置づけ〔観察〕**: [GAZ-024](GAZ-024.md)（御府内備考湯島之部）と同系列の町方書上で、**御府内備考編纂の元資料側**に相当する可能性がある〔同一文言の重複から推定・成立関係は要照合〕。湯島側（GAZ-024）と本郷側（本件）を併せることで、千川上水市中樋管（本郷通り〜湯島）の町別申告が揃う。
