# [GAZ-085] 御府内備考・総目録・凡例（写本・文政12年完成）— 編纂年代の自記・切図分類・巻52雑司ヶ谷条とGAZ-072帰属問題・小石川・小日向・関口巻の目録〔第158回〕

- **書誌〔確認〕**: 『御府内備考』の**総目録・凡例の冊**（写本・冊子頭に「御府内備考 总目録 凡例」の書名文言。東京都立中央図書館蔵（平河）関連の識語群が見える）。NDL次世代デジタルライブラリー [book/2553660](https://lab.ndl.go.jp/dl/book/2553660)。**御府内備考は冊子ごとに独立した写本が流布しており（[GAZ-013](GAZ-013.md)・[GAZ-075](GAZ-075.md)等はその一部）、本冊は全58巻+の総目録・凡例にあたる**。OCR崩壊が大きく、目録の条名・巻次は原画像照合を要する。
- **①凡例の編纂年代の自記〔確認・文言候補・書誌情報〕**: 「**此書文政九年雨戌冬十月筆を起し 今茲己丑秋九月にして漸く全を得たり**」＝**文政9年（1826・丙戌）冬10月起筆→文政12年（1829・己丑）秋9月に漸く全を得た、と凡例が自記**。＋**毎巻末に浄書年の支干を記し、足書には支干を付すという編集方針の自記**＝[GAZ-013](GAZ-013.md)（巻52・丙戌書上）・[GAZ-075](GAZ-075.md)（高田雑司ヶ谷町方書上・文政9丙戌書上）等の**「丙戌書上」表記（1826年時点の町方書上の借用）の背景となる編纂体例の説明**。＋「**此書は御府内風土記の参考に備ふる編録なれば**」＝**幕府の地誌編纂（御府内風土記〔未成立〕）への備えとして編んだ旨の自記**。＋執筆者22名の列挙（**三島政行編次**・井上常明ら）＝**御府内備考の執筆体制の文言候補**。
- **②切図22分類〔確認・文言候補〕**: 総目録の切図の部に**22分類の地名配列**（其十小日向関口附護国寺領三ケ町・**其十一高田雑司ヶ谷**・其十二牛込・**其十三市ヶ谷**・**其十四四ッ谷**附麹町鮫ヶ橋狛木角筈等）＝**高田と雑司ヶ谷が同一の切図単位（其十一）に置かれ、市ヶ谷（其十三）・四ッ谷（其十四）が別単位とされる区分**＝[GAZ-075](GAZ-075.md)（高田雑司ヶ谷町方書上の冊子頭書名）と整合する御府内備考の内部的地理区分。
- **③巻52の雑司ヶ谷条とGAZ-072帰属問題〔確認・文言候補・本登録の主眼〕**: 総目録の巻之五十二の条立てに「**巻之五十二 … 雑司ヶ谷 雑司ヶ谷町 鬼子母神門前 本浄寺門前 本染寺門前**」（**「本染寺門前」は「本浄寺門前」の重出か別寺（本染寺）かOCR上判別不能・要照合**）＝**巻52（高田之部系）に雑司ヶ谷町・鬼子母神門前・本浄寺門前の条が置かれる目覧構成であるのに対し、市谷之部（巻之五十八〜六十: 市谷総説から大久保前町まで）の町名目録に「雑司谷町」の独立条は見えない**。〔**[GAZ-072](GAZ-072.md)（東京市史稿市街篇第五）の雑司谷町条（文政町方書上引用・市ヶ谷の文脈）と[GAZ-013](GAZ-013.md)第149回追記・[GAZ-075](GAZ-075.md)の御府内備考巻52豊島郡側雑司ヶ谷町条（丙戌書上）の文言がほぼ同一であるという帰属問題について、本総目録は①巻52が雑司ヶ谷町の書上を確かに含む巻であること②市谷之部の巻には雑司谷町の独立条が見えないこと（陰性・この1写本の目録レベル）を示す＝文政町方書上の帰属を豊島郡側雑司ヶ谷町条とする解決方向を支持する目録レベルの根拠**。ただし①本冊は1写本の目録であり、大系版（東京府〔市〕史料叢書版の底本〔1214872系〕）の目録との対校は未実施（次回課題）②市街篇第五の編纂過程で市ヶ谷の文脈に採録した経緯そのものは本目録からは確定できない、ため**帰属の断定は従来どおり保留する**。〕
- **④小石川・小日向・関口巻の目録〔確認・文言候補〕**: 巻之四十四（小石川之四）の目録に「**千川屋鋪**」「**大塚窪町**」「**護国寺領大塚上町**」＝**白山前町の千川屋鋪（[GAZ-034](GAZ-034.md)・[GAZ-037](GAZ-037.md)・[GOV-208](../gov/GOV-208.md)系）が巻44に置かれる目録レベルの所在裏付け**＋大塚窪町（[GAZ-083](GAZ-083.md)の鶏声窪＝東西大塚の間の窪地名系の対照）・護国寺領大塚上町。＋巻之四十五（小日向之一）の総説掲載項目の目録に橋梁群「**古川橋 琵琶橋 中ノ橋 石切橋 掃部橋 万年橋 立慶橋 船河原橋 獄門橋**」（江戸川附…屋鋪地名并里俗小名の記載枠）＝**巻45小日向総説に掃部橋・立慶橋・船河原橋等の橋梁文言がまとまって載る目録レベル確認**（[GOV-221](../gov/GOV-221.md)（掃部橋の惣水落ではない先例言及）・[GAZ-049](GAZ-049.md)（立慶橋）・[GAZ-083](GAZ-083.md)（立慶橋・船河原橋の由來）・[GAZ-086](GAZ-086.md)（船河原橋の俗「ドン」）の母体となる巻）。＋巻之四十八（関口之一）の目録「**上水 胸突坂 東京不動坂 駒止坂 関口橋 江戸川橋 疎儀荘蹟**」＝**関口巻に駒止坂・関口橋・江戸川橋（江戸川橋=掃部橋系の比定問題〔[BOOK-131](../books/BOOK-131.md)〕）・疎儀荘（江戸名所図会系の疏儀荘）の項立て**。＋巻之六（御曲輪内之四）の目録に「**玉川上水付助水 神田上水附助水**」＝**神田上水附助水（千川上水等の助水群）の項立てが巻6にある目録レベル確認**（[GAZ-054](GAZ-054.md)系）。
