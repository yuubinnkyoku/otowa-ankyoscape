# [GAZ-021] 『新編武蔵風土記稿』巻之十六（豊島郡之八）雑司ヶ谷村・巣鴨村条

## 書誌・所在（2026-10-30、リンク集「ネットで読める新編武蔵風土記稿」（古文書便覧）とNDLサーチ書誌の直接確認・ai）

- 『新編武蔵風土記稿』は昌平坂学問所地誌調所の編纂で文政13年（1830年）完成の官撰地誌。巻之九〜十九が豊島郡で、巻之十六（豊島郡之八）の収録は雑司ヶ谷村・関口町在方分・小日向町在方分・巣鴨村。
- 浄書本（将軍献上本と同一の完成本）は国立公文書館内閣文庫所蔵で、同館デジタルアーカイブで公開されている。巻之十六の浄書本へのリンクは古文書便覧のリンク集にあり、画像IDは 4045551。
- 明治17年（1884年）内務省地理局の活字翻刻本は国立国会図書館デジタルコレクションに収録（NDLサーチ書誌ID 000000425830、請求記号105-30、40冊合本）。同じく大日本地誌大系本（雄山閣、昭和9〜10年、全12巻）も同コレクションにあり、リンク集は巻之十六について pid 1051345 の該当コマ（コマ160）へのリンクを置く。本ファイルの段階ではNDL側の公開区分と大系本の巻次対応は未確認。
- リンク集：http://komonjo.rokumeibunko.com/binran/musashifudoki/m001.html （豊島郡の部）

## 内容メモ

- 二次資料の紹介では、雑司ヶ谷村条に丸池・弦巻川・農業用水に関する記述があるとされていた（[音羽谷西側の弦巻川下流の成立年代](../../open-questions/音羽谷西側の弦巻川下流の成立年代.md) の決着資料リスト第7項）。

## 浄書本の部分読取（2026-10-30、国立公文書館デジタルアーカイブの画像・ai。逐字の全転記は未了）

- デジタルアーカイブの資料同定：件名「新編武蔵風土記　巻１６　豊島郡」、請求番号173-0210、画像ID 4045551、ビューア https://www.digital.archives.go.jp/img/4045551 （全32コマ、1コマ左右2頁）。本文の並びは雑司ヶ谷村→巣鴨村→関口町在方分→小日向町在方分で、開始コマは雑司ヶ谷村が4コマ目左頁、関口町在方分が17コマ目左頁、小日向町在方分が21コマ目左頁。巣鴨村の開始コマと雑司ヶ谷村条の終了コマは未確定。巻末は30コマ目右頁。
- 雑司ヶ谷村条の水関係は6コマ目に集中する。「丸池」の字を6コマ目右頁に確認した。同コマ左頁には、方五間餘で村の西北にあるとする池の記述（名称と本文の結びつきは位置からの推定にとどまる）と、見出し「弦巻川」に続けて丸池の下流・幅七尺許・村の用水とする文の冒頭を確認したが、続きは未読で、読みに確信の持てない字もある。清水・星井への言及も同頁にある。「下水」の独立見出しは確認範囲では見当たらない。
- 関口町在方分では19コマ目に江戸川・神田上水・小石川の見出しがあり、神田上水と江戸川の分水口に大洗堰があるとする文の冒頭（「大洗堰」の読みは未確定）と、橋と水番人の小屋に関する記述を確認した。詳細は未読。
- 小日向町在方分では21〜22コマ目に上水・小石川への言及を確認したにとどまる。
- status は直接確認（浄書本画像での部分読取。全文の逐字転記は未了で、未読範囲は上の通り）。
- 隣接巻も本研究の対象域を含む：巻之十五（豊島郡之七）は小石川村・小石川大塚村・青柳町在方分・音羽町在方分・桜木町在方分、巻之十二（豊島郡之四）は池袋村・中丸村・下板橋宿、巻之十三（豊島郡之五）は長崎村・上石神井村・下石神井村・関村など千川上水分水の村々。いずれも同じリンク集から各本へ辿れる。
