# [GAZ-059] 『新撰名勝地誌』（1914）— 1914年時点の弦巻川現勢の文言

- **書誌〔確認〕**: 『**新撰名勝地誌**』（**博文館・1914年〔大正3〕**。出版年の末尾桁は奥付OCR由来で要照合）。NDL次世代デジタルライブラリー [book/762081](https://lab.ndl.go.jp/dl/book/762081)。明治末〜大正期の東京の名所・地誌案内記。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①小石川区条の弦巻川・小石川の現勢文言〔確認文言・repo初出の1914年時点記録〕**: 「**川は江戶川の他、小石川、弦卷川あり。小石川は巢鴨より來りて小日向臺、白山臺の間を流れて江戶川に入る。弦巻川は關口臺と小日向臺との間に流れたり。**」＝**①1914年時点の小石川区に江戸川のほかに小石川（＝谷端川の下流側呼称）と弦巻川の2河川が「あり」とする記述、②小石川は巣鴨から来り小日向台・白山台の間を流れて江戸川に入る流路、③弦巻川は関口台と小日向台の間に「流れたり」（現在形の記述）**。〔**[GAZ-029](GAZ-029.md)（東京府地誌1925「小石川ハ小日向臺、白山臺ノ間ヲ流レ江戸川ニ注ギ、弦卷川ハ關口臺ト小日向臺トノ間ヲ流ル」）の11年先行のほぼ同型文言**。1914年時点で弦巻川が開渠で存在したと読める現在形記述として、[GAZ-028](GAZ-028.md)（1907・開渠）と[GAZ-029](GAZ-029.md)（1925）の間の基準点。「流れたり」が実流か流路認識かは本書だけでは断定しない（暗渠化の時期の特定資料としては使わない）〕。
- **②小石川区の地形の総説〔確認・内容メモ〕**: 同条に「**江戶川一帶の地と本〓（本郷）に接するの地とを除くの他は、〓（総）じて、高阜にして、道華坂（＝百花坂か・OCR要照合）、金剛寺坂、安藤坂は南に面し、富坂は東に面せり。その他、鶯谷、名、荷谷（＝茗荷谷か）等の窪容（OCR崩れ）あり**」＝小石川区の台地・坂・谷の地形の記述。区の特色として砲兵工廠・植物園等を挙げる。〔弦巻川・小石川の谷地形の文脈の記録。「道華坂」はOCR崩れで百花坂の候補。原字形照合を要する〕。
