# [GAZ-131] 町方書上[80] 下谷壱 — 不忍池落水「忍川」の一次文言と寛橋の規模・修覆文言

- **書誌〔確認〕**: 『町方書上[80] 下谷町方書上　壱』（写・NDL次世代デジタルライブラリー [book/2571561](https://lab.ndl.go.jp/dl/book/2571561)・264コマ）。下谷屏風坂下町・車坂系町群・下谷町壱丁目（代地）等の町方取調箇條書（文政9戌年〔1826〕系の廻年月候補）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571561_{NNNNNNN}.txt` コマ番号。**
- **下谷町壱丁目条（里俗竹町）の忍川・寛橋文言〔文言候補・本冊の主要価値〕（p10）**: 「**不忍池落水 町内南之方上野町堺を流候川中九尺程有之 忍川と相唱申候 一右忍川江懸り候石橋 寛橋と唱 巾壱丈壱尺渡り壱丈弐尺有之 寛文二寅年中御入用に而相掛り候旨申伝候所 文化十酉年三月十五日出水ニ而橋損シ候ニ付 御普請方御役所え御訴申立候得共 以来市中持に被仰付候に付 橋ゟ北当町内 上野仁王門前町 同南 上野町弐丁目 下谷常楽院門前与(?)四郎 組合掛ヶ直シ修覆共仕候**」＝**①不忍池の落水（流出水）が下谷町壱丁目（里俗竹町）の南・上野町堺を流れる（川幅9尺）「忍川」という呼称、②そこに架かる石橋「寛橋」（巾1丈1尺・渡り1丈2尺・寛文2年〔1662〕に御入用で架けた旨の申伝、③文化10年〔1813〕3月15日の出水で橋が損じ、御普請方御役所へ訴えたが以後は市中持とされ、橋の北＝当町内＋上野仁王門前町・南＝上野町弐丁目＋下谷常楽院門前（与四郎?）の組合で掛け直し・修覆をしてきた**申伝。〔**①「忍川」呼称の江戸期町方書上レベルの一次文言＝[GAZ-055]（東京市史稿・不忍池を併せて「忍川ト為リ」「三味線堀(千川?)へ」）の後代編纂側規定の前側 witness。藍染川（谷戸川）系の不忍池からの流出部の名称用地として[GAZ-126]（下谷六・常楽院門前条「不忍池畔の流れの寛橋」）と同じ橋の対向側（北岸側）の条**＝同一橋の隣接2町条が独立に同じ橋名を載せる重複 witness、②寛文2年架設・文化10年3月15日出水という寛橋の年代・規模の初めての整った数値文言（出水の日付指定は[GOV-437]（天明6年出水の今戸橋・新鳥越橋と並ぶ出水日付の記録層）、③「御普請方への訴え→市中持」の転換＝寛橋がかつて公儀（御入用）の橋であった記憶と以後の維持主体の移行〔[GOV-210]系の千川家橋と同様の御普請役→町方の負担転換の事例で不忍池系]]。
- **下谷町壱丁目条の「千川迄」文言〔文言候補・文言変異の重要例〕（p10）**: 「**安永八亥年中 千川迄水相掛り候得共 無程相潰れ 当時右之形相見え不申候**」＝安永8年（1779）に千川まで水が掛ったがまもなく潰れ、現在その形は見えない旨。〔**[GAZ-126]（下谷六・4町条）の「千川上水相懸り」文言に対し、本冊の下谷町壱丁目条（里俗竹町）・屏風坂下町条は「千川まで（水が）相掛り」と読める「千川迄」文言**＝同じ下谷側の定型文で「千川上水／千川迄」の文言の揺れ（「千川」という単位での用例＝[対照表・千川（1,119）]行の「千川上水の略称のほか地名・谷端川下流の川名にも使われる」の指摘と整合する一次レベルの揺れの実例。断定はしない）〕。
- **下谷屏風坂下町条の同文言（p26）**: 同じ「安永八亥年中千川迄水相掛り候得共無程相潰れ当時右之形相見え不申候」文言が下谷屏風坂下町条（車坂地誌：田嶋主計＝慈明大師御家来に始まる家守権 etc の長い由緒の後）にもある＝**下谷側でこの文言が2条に載る**（[GAZ-126]の4町条と併せ、下谷・上野側の「安永8亥年」記憶の分布の広がり）。〔[GAZ-114]（御府内備考・巻21-23下谷長者町繋車坂町条の千川上水之樋・水銭204文）の当該町に相当する条では樋・水銭文言の出ないことに注意＝写本系の元書上の網羅性の差として陰性記録〕。
- **下谷町壱丁目条の草分文言〔付記〕**: 「往古御代官伊奈半左衛門様御支配所 豊嶋郡速田領(=鳥越候補)下谷村二有之 金子三郎兵衛 恩地惣兵衛と申者名主之由」＝下谷村の旧支配（伊奈半左衛門）・名主（金子三郎兵衛・恩地惣兵衛）の草分文言（[GAZ-115]の「速田(=鳥越)領鳥越村」と同じ表記対立）。

## 制限・未解決

- ①「忍川」の原字・「寛橋」の橋名原字はOCR由来で照合課題。②「下谷常楽院門前与(?)四郎」の「与四郎」の位置（人名か組合町の付帯文言か）は判読不明のまま保留、組合4ヶ所（当町内・上野仁王門前町・上野町弐丁目・下谷常楽院門前）の構成は[GAZ-126]の「4ヶ所の組合橋文言候補」と整合するが位置の対応（北2町＋南2町）は原画像照合まで断定しない。③寛文2寅年架設の「御入用」＝公儀負担の実態（幕府の御普請か寛文2年の何らかの普請に付随する架設か）は断定しない。④不忍池落水の流路（下谷壱丁目南の上野町堺の川＝池之端・上野公園側のいずれの水路か）と、忍川＝藍染川系の下流（[GAZ-055]）としての区間の対応は地形側の検討課題。⑤「千川迄」文言が千川上水の全体の廃止の意味か当町への給水の意味かは文言上の判別ができない。
