# [GAZ-044] 御府内備考 巻11-12（神田之四）— 神田相生町・通船屋敷の千川上水の樋

- **書誌〔確認〕**: 『**府内備考**（御府内備考）巻11-12（神田之四・写本）』。NDL次世代デジタルライブラリー [book/2553666](https://lab.ndl.go.jp/dl/book/2553666)。丁亥（文政10年）書上の文言を含む＝町方書上（[GAZ-041](GAZ-041.md)〜[GAZ-043](GAZ-043.md)）の編纂側の写本。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **神田相生町の千川上水条〔確認・神田区間の樋の区間ごとの延長〕**: 「**一千川上水（東京圖書繪・OCR乱れ）右は安永九子年十月廿七日牧野大隅守様御番所御掛に而上水掛渡之儀被仰付候儀二而町内往還大通者中樋二而上野町代地境ゟ神田佐久間町弐丁目持場境迄凡六拾八間余 片町は小ニ而神田相生町地境ゟ藤堂和泉守様住屋鋪脇迄凡八拾間余烈渡（＝埋渡か・要照合）有之候処天明七未年四月十三日御差止に相成候旨被仰渡候由に而其節取潰埋立申候但元禄之度千川上水御掛渡之義相分不申候以上丁亥書上**」〔**①相生町の往還の大通は中樋で、**上野町代地境〜神田佐久間町2丁目持場境まで凡68間余**、②**相生町地境〜藤堂和泉守様住屋敷脇まで凡80間余**の埋渡（OCR「烈渡」）、③天明7年4月13日差止→取潰埋立**＝**上野側（上野町代地境）から佐久間町境へ抜ける神田区間の境界つきの区間延長の一次記録**（神田相生町は[GOV-215](../gov/GOV-215.md)の差止直後の請負人町（神田相生町・平永町・佐久間町）の一つ＝掛渡と請負の町が一致）。
- **通船屋敷（筋違橋外）の千川上水跡〔確認・三方折廻しの130間〕**: 通船屋敷（享保11年水野隼人正屋敷跡の明地→町名化〔[GAZ-041](GAZ-041.md)の都稲荷の「水野隼人正様御上ケ屋敷跡」と同じ水野隼人正屋敷の後町〕）の書上に——「**一千川上水跡 右は元町内往還中通北角に枡壱ケ所同南角二同断壱ケ所小樋二而三方折廻し長延百三拾間程懸渡有之候処当時者御差止ニ相成申候 右委細之儀は同所仲町壱丁目二而申上候**」〔**①枡2ヶ所・小樋で三方に折り廻す凡130間の懸渡、②当時（書上時点）差止済み、③委細は（神田）仲町1丁目が申上げる＝代表申告町の指示**〕〔**筋違橋外の通船屋敷に千川上水の樋が三方に折り廻る構造で存在した記録＝[GOV-215](../gov/GOV-215.md)（筋違橋御門外の千川上水請負人助成地・揚場銭取立）の位置と重なる区域の構造データ**〕。
- **仲町・石置場等の同文言群〔確認・[GAZ-041](GAZ-041.md)（町方書上[73]の神田仲町条）と同一内容の編纂側採録〕**: 仲町条（枡2・中樋凡50間・小樋凡72間）等、町方書上と同一の文言・数値が御府内備考側（神田之四）にも採録される＝**[GAZ-024](GAZ-024.md)（湯島之部・雄山閣刊本）・[GAZ-045](GAZ-045.md)（湯島区間の写本）と併せ、御府内備考の千川上水条が湯島のみならず神田之部（巻11-12）にも及ぶことの確認**（神田側はこれまで未採録だった区間）。
