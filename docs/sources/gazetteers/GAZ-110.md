## 制限・未解決

- ①引用文言はすべてくずし字OCR由来で引用文言の表記対立（「堀千之助」（本条・巻53総説）vs「堀与之助」（揚場町条）、「極川」「堰川」「船何原町」「金曽木」等）は原画像照合まで並記する。②長延寺谷の古池と大下水の水源（大久保辺落水＋四谷辺水吐の二口）の水文学的な同一視は本文言各条が指す範囲の重なりの確認（地図作業）まで行わない。③北條分限帳・鶴岡寄進状・太田家文書はいずれも府内備考経由の二次引用で原文所在の同定は未了（「江戸市右三十二貫」等の判読は要照合）。④田町壱丁目条の条の区切り（巻59の頭）の原画像レベルの確認は未実施。
