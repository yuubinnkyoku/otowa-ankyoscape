## 内容メモ（目次から。千川上水に関わる項目）

- 千川上水創設（上水1-275、1696年（元禄9年）、出典は御府内上水在絶略記・文政町方書上・千川文書・参考落穂集・一話一言・三枝家記・武蔵通志・白山前町書上・参考録餘）。[市街篇第12](GAZ-016.md) の「千川上水鑿通」（市街12-1030）が相互参照する項目。
- 附記 元禄中ノ分水（上水1-296、1688〜1703年（元禄中）、出典は上水記）— 元禄期の分水の総括項目。千川上水から弦巻川・水窪川への分水の有無を本文で確認する対象（[未解決問題一覧](../../open-questions/README.md) の千川上水の項）。
- 参考 吉祥寺村・雑司ケ谷村・上井草村他（上水1-023、1624〜1654年、出典に新編武蔵風土記稿・関口町旧記書上・上水記・御府内上水在絶略記など）。
- 千川上水のその後を追う項目：千川青山三田本所各上水廃止（上水1-333、1722年）、千川上水再興（上水1-571、1779年）、千川上水堀割竣成（上水1-589、1783年）、千川上水廃止（上水1-598、1786年）。
