# [GAZ-052] 東京府北豐島郡板橋町（1911）— 板橋町の字名一覧表

- **書誌〔確認〕**: 東京遞信管理局編『東京府北豐島郡板橋町』（遞信協會・明治44年＝1911年11月18日発行。郵便局所在地・地番調査の郡部シリーズ）。NDL次世代デジタルライブラリー [book/1089208](https://lab.ndl.go.jp/dl/book/1089208)。**引用文言はOCR由来（表組みの崩れが特に激しい）で、字名・地番は原本画像との照合を要する。**
- **板橋町の字名一覧表〔確認・OCR崩れ大・要照合〕**: 「北豐島郡板橋町字名一覽表」として次の字名が読み取れる——**字堰・字沢金字・字谷津水・字宮ノ下・字鴻ノ巣・字北谷端・字家軒西（?）・字前池下・字宮・字戸谷ケ雀・字松高・字境・字池中・字金井窪・字境久保・字水道向・字平尾裏・字山之上・字稻荷臺・字袋前・字前田・字子場原**等（各字に地番の範囲・面積の数値が付されるが行割付はOCRで崩壊）。＝**1911年時点の板橋町の字名の公式一覧**。
- **谷端川・千川上水に関係する字名〔観察〕**: ①**「北谷端」**＝谷端川中流域の谷端（北谷端）の字として、1930年の計画道路地番（[GOV-255](../gov/GOV-255.md)・滝野川側の字北谷端）と表記を同じくする板橋町側の字名。②**「水道向」**＝「水道」（千川上水）に向かう土地と読める字名候補で、千川上水（旧水道）の板橋町内の通過位置を示唆する地名資料（由来の断定は不可）。③**「境久保」「境」**＝板橋町・滝野川町（あるいは金井窪・中丸）の境に関係する字名候補。④**「池下」「池中」**＝池（旧池）に関係する字名候補。⑤**「堰」**＝堰に関係する字名候補（どの堰かは本表では不明）。いずれも字名レベルの存在記録であり、個別の由来・位置の比定は地図・地番照合の課題。
- **位置づけ〔観察〕**: [GOV-253](../gov/GOV-253.md)（1931年・板橋町現状調査）・[GOV-255](../gov/GOV-255.md)（1930年・計画道路地番）と併せ、**明治末〜昭和初頭の板橋町（金井窪・下板橋・中丸・池袋の一部）の字名・地番の基礎資料**。地名対照表の地名セクションの字名行の根拠資料。
