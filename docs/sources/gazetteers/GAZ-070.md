# [GAZ-070] 江都近郊名勝一覧（安政5・1858）— 弦巻川＝布引川の仁王門前文言・鬼子母神出現地と三ヶ用井・星の影伝承・根子股橋由来・天保13年引移り記事〔第147回〕

- **書誌〔確認〕**: 著者不詳『江都近郊名勝一覧』（**安政5年〔1858〕・三河屋善兵衛刊**。NDL次世代デジタルライブラリー [book/2536711](https://lab.ndl.go.jp/dl/book/2536711)）。江戸近郊の名勝を寺社・地名ごとに列挙する安政期の地誌。**対校資料**: 『江戸年中行事』（春陽堂・1927・[book/1464045](https://lab.ndl.go.jp/dl/book/1464045)・請求記号565-52）が本書の本文を「江都近郊名勝一覽四〇五」「四九九」等の引用元頁表示つきで活字収録しており、**原本OCRの崩れを活字版で対校できる**（同一テキストの1927年活字版。本項の引用は原本と活字版の対校による。最終確定は原画像照合待ち）。
- **弦巻川条＝大行院仁王門前の川と布引川古名説〔確認・文言候補〕**: 「**弦卷川當寺の仁王門の前を流る川を云、古へは布引川とも唱へけるといふ**」（活字版校訂。原本OCRは「陸巻川当寺の仁王門の前を流る門を云□□□だいへは布引川とも唱へけるといふ」＝「弦卷」「川を云」「古へは」の各所がOCR崩れ）。直後に「**大行院鬼子母神の別當なり。天正年間加州侯の祖利家卿の開創也とぞ**」とあり、**「當寺」＝大行院（雑司ヶ谷鬼子母神の別当寺・天正年間加藤清正〔「加州侯の祖利家卿」〕開創説）と特定できる**。〔**①弦巻川の位置を「（鬼子母神の別当）大行院の仁王門の前を流る川」とする安政5年（1858）の本文文言**＝[BOOK-144](../books/BOOK-144.md)（文政7年草稿「法明寺の門前より御嶽の下を過て」）・[GAZ-067](GAZ-067.md)（江戸志「御鷹へや前絃巻川法妙寺前の細き流れ」）と対校できる位置記録。大行院・法明寺・法妙寺の関係（別当寺の呼称の相違）は断定せず原画像照合後に整理。**②「古へは布引川とも唱へける」＝布引川古名説の本文文言**＝[GAZ-047](GAZ-047.md)/[GAZ-058](GAZ-058.md)（江戸名所図会）と同文の「古へは」形式・[GAZ-066](GAZ-066.md)（名水品彙「一名布引川」・幕末候補）より確実に時期が早い（1858）**＝布引川異名系統の年代基準点として、名水品彙の幕末説（1836〜1867）を1836年以前に遡らせる年代的下枠を与える〕
- **鬼子母神堂条＝出現地・三ヶ用井・星の影伝承〔確認・文言候補・原字要照合〕**: 「**鬼子母神堂雜司ケ谷にあり、大行院護持す、此尊像出現の地、護國寺より坤の方にあたる、此の所を〓土といふ、その草叢の中に小さき祠あり、これ始め此(の)神を祀れる所也、傍に井あり、里俗三ヶ用井と云、始め此神出現のとき、この井に星の影を顯し給ふと云**」（活字版校訂。原本OCRは「護国寺より仲の方」「清正といふ」「里俗無用井と云」「星の影を願はし給ふ」＝「坤の方」「〓土（清土候補）」「三ヶ用井」「顕はし」の各所が原本OCRで崩れ）＝**①鬼子母神像の出現地を護国寺の坤の方（南西）の「〓土（清土候補）」の草叢中の小祠とする文言、②その傍らの井戸が「三ヶ用井」と呼ばれたとする里俗名の記録（原字は活字版の判読。語義は本項では不明）、③神出現のときこの井に星の影を顕したという伝承本文**。〔**③の星の影伝承の本文文言としては[BOOK-144](../books/BOOK-144.md)（文政7年草稿・三角の井筒＝星跡の〓水）より約34年後の1858年時点の本文で、「始め此神出現のときこの井に星の影を顕し給ふ」と出現と星の井を直接結ぶ形が明瞭**＝対照表「星の井／星の清水」行の系譜に1858年の定点を加える。**①の「護国寺より坤の方」＝南西の方角指定は[BOOK-159](../books/BOOK-159.md)（明治期「護国寺より神にあたり」＝OCR崩れ）の方角表記の原形候補**。「三ヶ用井」の井戸名と[BOOK-144](../books/BOOK-144.md)「三角の井筒」・[GAZ-066](GAZ-066.md)「三角井」の対応は呼称が異なり断定しない（原画像照合後に判断）。〕
- **根子股橋の由来説〔確認・文言候補〕**: 「**（巣鴨本村より南・伊勢祭九月十日）前当極楽水宗慶寺…小石川の流れに架す、むかし大木の根を以て橋にかえて渡したるより名とす、根子また橋也といふ**」＝巣鴨の極楽水・宗慶寺付近で小石川（江戸川上流の古称）に架かる根子股橋について「大木の根を橋に替えて渡した」由来説を記す本文文言。〔根子股橋（千川上水/小石川の橋）の江戸期の橋名由来説の本文記録＝[BLOG-079](../blogs/BLOG-079.md)（根子股橋の近代側記録）の前史。橋の位置・架設年代は本文言からは確定しない〕
- **天保13年8月の岡場所引移り記事〔確認・文言候補〕**: 「**天保十三寅八月江戸端々に住居せし料理茶屋水茶屋にて酌も女湯汲女など唱へ遊客をもてなす家業のともがら深川永代寺（門前仲町）をはじめ根津谷中音羽町にいたるまで皆引移り**（新吉原側の地へ来る）」＝天保13年（1842）8月の岡場所整理で、江戸端々の料理茶屋・水茶屋の遊女が深川永代寺門前仲町から根津・谷中・**音羽町**に至るまで引き移された（新吉原=猿若町側へ来た）実態記事。〔**音羽岡場所の天保13年廃止（[BOOK-009](../books/BOOK-009.md)系の「天保十三年廃止」文言）を、引き移された側の実態記述として裏付ける安政期の本文**＝音羽九丁目岡場所伝承（[BLOG-045](../blogs/BLOG-045.md)・[BOOK-141](../books/BOOK-141.md)の廓外艶郷図）の制度側背景の定点。〕
- **周辺条項〔確認・文言候補〕**: ①大塚の惣名と東西区分（「鶏声が窪の辺を東大塚といひ」系の文言候補）・②白山御殿の旧地・③護持院原（元一ツ橋御門外・護持院跡の広大さ）・④関口八幡宮等、音羽谷周辺の寺社・地名の記述。〔いずれも既存の対応項目（[GOV-258](../gov/GOV-258.md)府史・[GAZ-027](GAZ-027.md)等）に対校資料として使えるが、単独では登録に値しない周辺文言として記録する〕

## 制限・未解決

- ①原本（2536711）のOCRは崩れが多く、本項の引用は1927年活字版（1464045）との対校による。**「弦卷川」「三ヶ用井」「顕し」等の活字版の表記が安政5年原本の原字と一致するかは原画像照合待ち**（活字版が翻刻時に誤った可能性も残る）。②「當寺＝大行院」の特定は活字版の直後文によるが、原本で条の区切りが同じかは要照合（法明寺〔BOOK-144〕・法妙寺〔GAZ-067〕との寺名の相違は別記録の系統差か翻刻差か、原画像照合後に判断）。③「三ヶ用井」の語義・原字は不明（「無用井」等の他形も原本OCRにあり）。④「〓土」の原字（清土）は活字版でも不確定字のまま。⑤根子股橋の「小石川の流れ」が江戸川上流部か千川かを含む位置の確定は本書からはできない。⑥天保13年記事の「深川永代寺つぶ仲町」の「つぶ」は「門前」のOCR崩れ候補。⑦著者・編者不詳で、江戸名所図会等からの依拠関係（本文の系統）は未整理。
