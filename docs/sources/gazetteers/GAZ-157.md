# [GAZ-157] 町方書上[143] 芝伊皿子・芝二本榎（文政11子年）— 伊皿子台町条の三田上水の差止文言

- **書誌〔確認〕**: 『[143] 芝伊皿子・芝二本榎町方書上』（写・NDL次世代デジタルライブラリー [book/2571624](https://lab.ndl.go.jp/dl/book/2571624)）。文政11子年（1828）四月付けの地誌御調書上で、表紙見返しに「地誌御調書上帳 芝伊皿子台町」の書名が見え、目次（p3）に芝伊皿平町・伊皿子台町・伊皿子七軒町・伊皿子明下町・二本榎黄梅院門前・二本榎上行寺門前・二本榎明性寺門前・伊皿子寺町・二本榎広岳院門前・二本榎承教寺門前・二本榎覚真寺門前等が列挙される。各条末尾に「文政十一子年四月 右町名主無之 飯倉町組合名主〔兵庫〕」の署名が見える（伊皿子各町に名主が無く飯倉町の組合名主が立てた実務構造・OCR要照合）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571624_{NNNNNNN}.txt`）。※三田上水は当repo四河川（水窪川・弦巻川・谷端川・千川上水）のいずれの水系でもないが、**玉川上水系の江戸市中分水（千川上水の同世代の分水）の差止の町方側の一次記録として、上水史の系譜整理のために採録する**（[GAZ-156](GAZ-156.md)引請樋文言・[GOV-170](../gov/GOV-170.md)と並ぶ玉川上水系の周辺材料）。
- **伊皿子台町条の三田上水＝寛文4年分水・享保7年10月差止の文言〔文言候補・本冊最重要〕（p16-20）**: 「**一三田上水 寛文四辰年十一月中 武州多摩郡代田村ゟ玉川上水ヲ分水致 右上水当町え相懸り候処 享保七寅年十月中相止 当時上水無御座候**」（p20・OCR）＝**①三田上水は寛文4辰年（1664）11月中に武州多摩郡代田村で玉川上水を分水した、②その上水が当町（伊皿子台町）に相懸っていたが、享保7寅年（1722）10月中に相止められた、③現在（文政11年時点）上水は無い**という文言候補。〔**①「代田村分水」＝三田上水の分水地点（代田村＝現在の世田谷区代田）の町方側の一次記録で、分水起立の年次（寛文4年11月）の記録としてもrepo初出候補**（三田上水の起立を寛文年間に求める系統の実務側の記録・本冊は文政11年時点での回顧記録である点に注意）。**②享保7年10月の差止文言は[GOV-170](../gov/GOV-170.md)（享保撰要類集・享保7年8-9月の千川・青山・三田・本所上水の32ヶ所差停止の御書付・伺い）の行政側記録に対応する被差止側（給水区域の町側）の実例witness**＝行政側の伺い（8-9月）から実施（10月中相止）までの時間差を埋める実務記録候補（[BOOK-222](../books/BOOK-222.md)深川区史の享保7年千川・青山・三田同時廃止の並記、[BOOK-223](../books/BOOK-223.md)赤坂区史の室鳩巣献議説の系譜とも対校できる）。三田上水の流路が伊皿子台町に相懸っていたという位置情報（芝側の高台の町への給水）自体も三田上水の給水区域の復元の材料。〕
- **伊皿子台町条の町名起原と伊皿子坂文言〔文言候補・参考〕（p16・p12）**: 「**当町起立之儀ハ同所伊皿子町ニテ申上候通御座候 同町続高ミニ付 芝伊皿子台町え相唱申候**」（p16・OCR）＝伊皿子町の続きの高み（台地）に付くため伊皿子台町と唱える文言候補。伊皿子平町条に「**一坂之儀者 町内家前往還ニ而 芝田町九町目 同所車町横町ゟ 同所伊皿子台町江登リ 凡長壱町半程 幅三間 伊皿子坂ト相唱申候**」（p12・OCR）＝**芝田町九丁目・車町横町から伊皿子台町へ登る伊皿子坂（長約1町半・幅3間）**の文言候補。〔三田上水の給水があった高台（伊皿子台）への坂の構造記録として、上水の流路と町の高低差の文脈を補う参考記録。〕
- **伊皿子七軒町・伊皿子寺町・伊皿子明下町の起立文言〔文言候補・参考〕（p20-23など）**: 各条に「**当町起立之儀ハ上高輪村石高之内ニ而小町ニ付 芝伊皿子台町江附属致 町用相勤申候ニ付 芝伊皿子〔七軒町・寺町・明下町〕ト町銘相唱申候**」型の文言（寛文2寅年中の町奉行〔渡辺大隅守様御勤役〕の町方支配付の年次文言を含む・OCR）＝**上高輪村の石高の内の小町として伊皿子台町に附属し町用を勤めたことによる町銘と、寛文2年（1662）の町方支配化の年次**の文言群候補。〔伊皿子台町一帯（三田上水の給水が相懸った区域）の町割の前史の参考記録。伊皿子台町そのものの起立文言は「同所伊皿子町にて申上候通り」＝伊皿子町（平町）への委譲構造。〕
