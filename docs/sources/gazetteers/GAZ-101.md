# [GAZ-101] 江戸近郊道しるべ（村尾嘉陵・写26巻）— 江戸近郊紀行文集の面影橋・用水文言候補

- **書誌〔確認〕**: **村尾嘉陵（村尾正靖）『江戸近郊道しるべ』26巻**（写本。NDL次世代デジタルライブラリーで[2577942](https://lab.ndl.go.jp/dl/book/2577942)〜[2577967](https://lab.ndl.go.jp/dl/book/2577967)ほか全26巻中25点程度がデジタル化済み・書誌APIで責任表示「村尾, 嘉陵||村尾正靖」を確認）。各巻は江戸近郊の社寺・道筋の紀行原文で、[10]（[2577951](https://lab.ndl.go.jp/dl/book/2577951)）冒頭に「**江戸近郊の道しるべ十 文政二年八月…渋谷八幡十九伊勢野道の枝折**」、[21]（[2577962](https://lab.ndl.go.jp/dl/book/2577962)）冒頭に「**□江戸近郊道ト云ヘ二十一□ 廿一…文政十一年戊子十月**」の題・日付文言候補＝**収録紀行文の記述年代は文政期（1818〜1831）を含む**。「道しるべ」の成立・編年の全体像（嘉陵の撰年・各巻の対応関係）は本時点では書誌二次情報レベルで断定しない。**すべての文言はOCR由来で写本原画像照合前提（草本・くずし字の崩れが甚大）。**
- **面影の橋の四つ折・玉川せきわけ文言候補〔確認・文言候補・repo初出〕**: [21]（2577962・高田の馬場→諏訪明神→淀橋方面の紀行本文）に「**□□田村の□にいたる 一方水南より北に流る 面影の橋のよつ折にて 玉川をせきわけて井戸の頭の水に合す をもてこのあたりより小勢やゝ一川をみなきらす 橋より少し下りて杭あまた焼て水を瀬きりたるはこの頃秋田にせきかへき料なるへし**」＝**①「一方水南より北に流る」＝南から北へ流れる水路の記述、②面影の橋の四つ折（地点）で「玉川をせきわけて井戸の頭の水に合す」＝玉川上水の水を堰き分けて井の頭（＝神田上水筋の水）に合わせる機構の叙述候補、③杭を多く焼き打って瀬を切った「秋田にせきかへき料」〔飲み込みのOCR崩れ候補・「せきかへ（堰替え）」の読み保留〕**。②は**玉川上水から分水して神田上水筋に落とす水利機構（千川上水系の分流運用）への言及候補**として記録（分流の特定・「井戸の頭」の解釈〔井の頭池の水＝神田上水の水元の意か〕は原画像照合まで断定しない）。「面影の橋」は高田落合の面影橋系の橋。「□□田村」の村名（判読保留。面影橋の北側の村落名候補）も照合課題。
- **高田落合村七曲の用水道文言候補〔確認・文言候補〕**: [10]（2577951・椎名町→高田落合方面の紀行本文）に「**…高田落合村七曲して行…岐路あり 左を行れも両等田に出（?）…**衣服がり**用水道を損〔堰のOCR崩れ候補〕きりて東に流る こゝよりおよし平尾に出て末は瀧の川と成といへり**」＝**高田落合村七曲付近の用水路（「衣服がり」＝洗濯場・板敷きの判読候補・保留）を堰き切って東に流し、平尾を経て末は瀧の川（帰属保留候補）に至るという流路叙述候補**（高田・椎名町〜平尾方面の用水路の流路記録の候補。「瀧の川」の実体（千川系・妙正寺川系等の比定）は本条では判断できない）。「損きりて」＝「堰切りて」候補。OCR列崩壊大・要照合。

- **井草用水＝妙正寺池の流れの天保期観察〔第187回追記・確認（OCR）・文言候補・repo初出〕**: [22]（[2577965](https://lab.ndl.go.jp/dl/book/2577965)・井山村妙正寺并池略図を付す紀行）に「**井山村妙正寺并池略図 コノ池ノ流レヲ井艸（井草）用水ト云 下落合村へ流ル**」＋池畔の吉祥弁才天祠（南向き・小橋のかたわら）・祠のほどの外の小津（小溝?）のうちより水湧出する観察・「**この北東南流して下落合村に流るといへり**」（妙正寺庫裏の眺め・天保8年焼失の堂再建勧化の記事）＝**妙正寺池（中野区江古田・妙正寺）の流れを「井草用水」と呼び、下落合村（神田川/妙正寺川へ至る谷）へ流落とする天保期の実見文言候補**〔repoで「井草用水」の文字列は初出。妙正寺池の流れが下落合側（神田川水系）へ向かう観察は[BOOK-119](../books/BOOK-119.md)（落合町誌の千川用水西端と湧水群）・[GOV-068](../gov/GOV-068.md)（多摩郡六か村用水）とは別系統的一次観察レベル〕。対校注意: 池の湧水の方向・「下落合村へ流る」の流路（妙正寺川として現在の神田川支流）は地形と整合するが、呼称「井草用水」の並用範囲（井草村方面の千川上水分水群との異同）は本条からは断定しない。
- **嘉大年紀行の井の頭条の文言候補群〔第187回追記・確認（OCR）・文言候補〕**: [3]（[2577944](https://lab.ndl.go.jp/dl/book/2577944)。冒頭に「江戸近郊道しるべ三一一嘉大年紀行一前書二統尚ス村尾嘉陵」・文政26年の金子基三の賦）に①「**水のわき出るを七つかし依て七井の油（湧）ともいふ**」＝井の頭の名義を7つの湧き出口に求める**「七井」名義説の文化9年（1812）の紀行文言候補**（[GAZ-027](GAZ-027.md)井の頭池条「往古より水涌出る口七ヶ所あり よつて七井の池ともいひつたふ」〔1772〕の類縁本文・江戸砂子系統ではない紀行文側の用例）②「**大前院殿（大猷院殿候補）又こゝに成られしの水 江戸数万人の喰波をうるほす これ江戸井の頭也 と上意より**」＝家光上意文言の候補（井の頭池の水が江戸数万人の飲料を潤すという上意の伝承文言候補・[BOOK-151](../books/BOOK-151.md)吉祥寺村条の御茶井口建札系譜と対校）③流路観察「**中野淀橋の辺に至て玉水の助水と合し…下落合村に至て石神井川と合**」＝井の頭水が**淀橋の辺で玉川（上水）の助水と合流し、下落合で石神井川と合う**という流路の叙述候補〔**淀橋合流の流路第一観察の文化9年例**＝[GAZ-027](GAZ-027.md)玉川上水条「角はすより淀橋方の流をわかち…助水となりて」（1772）と[GOV-290](../gov/GOV-290.md)（1905）の間を埋める紀行文側の datapoint。「玉水の助水」の実体（千川上水〔淀橋分水〕か玉川上水助水堀か）は本条からは断定しない〕④「**おりたけ橋の辺にと行至ては其流消（張）一川を張らす**」＝合流後の川相の観察（橋名「おりたけ橋」の判読保留・[BOOK-152](../books/BOOK-152.md)おたき橋条・GAZ-097「おたき橋」見出しとの異同は照合課題）⑤高井戸〜久我山〜「**上に玉川上水のほりわりあり 石橋をわたす**」＋上水の制札（「この水にて魚とかへからす（獲てはならぬ）」の内容の候補）＝**玉川上水久我山〜井の頭区間の石橋と禁漁制札の文化9年観察**〔[GOV-307](../gov/GOV-307.md)系の玉川上水禁漁文言の先行観察例候補〕。
- **上高田の「井の頭上水」架橋文言候補〔第187回追記・確認（OCR）・文言候補・repo初出〕**: [4]（[2577961](https://lab.ndl.go.jp/dl/book/2577961)・表題文言候補「十上高田村氷川社路畧図 文化十三丙子年三月七日石坂直温同遊」）に「**この山麓を南へ…高田の場の北側の路を西ノ西て行 の高田は本名戸塚村と云といへともこの辺なくて高田と占へ来る**」＋「**門前ニ石碑あり戸塚村と彫付たり**」＝高田＝戸塚村の別称的扱い・戸塚村石碑の実見（文化13年）＋「**少し行へ左之方林持の間人どう（人どお）り行て橋あり 井の頭上水の流レにわたす**」＝**上高田付近で井の頭上水の流れに架かる橋（薬師堂前・大久保百人町へ抜ける道）の実見文言候補**〔「井の頭上水」という呼称の江戸期用例は[GOV-384](../gov/GOV-384.md)（静嘉堂井頭上水由緒の「井頭上水」）と系統的に連続する候補。位置は千川上水（淀橋〜高田間の分水）とも神田上水本流とも読めるが、本条からはどちらかを断定しない。※26巻全走査の結果、[21]面影の橋条の「玉川をせきわけて井戸の頭の水に合す」と本条の「井の頭上水の流レ」はともに神田上水筋を「井の頭」系の名で呼ぶ同時代の用法候補として対照表の千川上水行・神田上水行で対校〕＋「**橋より流レの…東を望めは下落合村桑土蛇の森見ゆ**」＝橋からの下落合方向の眺望（「桑土」「蛇の森」の判読保留）。ほか天保2年[20]（[2577963](https://lab.ndl.go.jp/dl/book/2577963)・高田村天満宮詣之記）に「**伊草ノ用水**」の通過文言候補（「伊草」＝井草の異表記候補）＝上高田〜高田天満宮周遊路上の用水路の天保2年例。
- **「淀橋の川」呼称の文政7年用例候補〔第187回追記・確認（OCR）・文言候補・repo初出〕**: [15]（[2577959](https://lab.ndl.go.jp/dl/book/2577959)・文政7年甲申9月12日藤稲荷詣の道草）に、井草〜上高田間の川の観察として「**らを行くは川あり三日はかりの橋を一ツ 川上中野の淀橋の川へ**」＝**この川の上流を「中野の淀橋の川」と認識する文政7年の観察文言候補**〔神田川上流を「淀橋」で認識する江戸後期の呼称の datapoint＝淀橋水車の通時系列（[GOV-390](../gov/GOV-390.md)等）・淀橋方の流（[GAZ-027](GAZ-027.md)・「千川上水＝淀橋分水」系譜）の呼称系の紀行文側用例〕。
