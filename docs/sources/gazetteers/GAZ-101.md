# [GAZ-101] 江戸近郊道しるべ（村尾嘉陵・写26巻）— 江戸近郊紀行文集の面影橋・用水文言候補

- **書誌〔確認〕**: **村尾嘉陵（村尾正靖）『江戸近郊道しるべ』26巻**（写本。NDL次世代デジタルライブラリーで[2577942](https://lab.ndl.go.jp/dl/book/2577942)〜[2577967](https://lab.ndl.go.jp/dl/book/2577967)ほか全26巻中25点程度がデジタル化済み・書誌APIで責任表示「村尾, 嘉陵||村尾正靖」を確認）。各巻は江戸近郊の社寺・道筋の紀行原文で、[10]（[2577951](https://lab.ndl.go.jp/dl/book/2577951)）冒頭に「**江戸近郊の道しるべ十 文政二年八月…渋谷八幡十九伊勢野道の枝折**」、[21]（[2577962](https://lab.ndl.go.jp/dl/book/2577962)）冒頭に「**□江戸近郊道ト云ヘ二十一□ 廿一…文政十一年戊子十月**」の題・日付文言候補＝**収録紀行文の記述年代は文政期（1818〜1831）を含む**。「道しるべ」の成立・編年の全体像（嘉陵の撰年・各巻の対応関係）は本時点では書誌二次情報レベルで断定しない。**すべての文言はOCR由来で写本原画像照合前提（草本・くずし字の崩れが甚大）。**
- **面影の橋の四つ折・玉川せきわけ文言候補〔確認・文言候補・repo初出〕**: [21]（2577962・高田の馬場→諏訪明神→淀橋方面の紀行本文）に「**□□田村の□にいたる 一方水南より北に流る 面影の橋のよつ折にて 玉川をせきわけて井戸の頭の水に合す をもてこのあたりより小勢やゝ一川をみなきらす 橋より少し下りて杭あまた焼て水を瀬きりたるはこの頃秋田にせきかへき料なるへし**」＝**①「一方水南より北に流る」＝南から北へ流れる水路の記述、②面影の橋の四つ折（地点）で「玉川をせきわけて井戸の頭の水に合す」＝玉川上水の水を堰き分けて井の頭（＝神田上水筋の水）に合わせる機構の叙述候補、③杭を多く焼き打って瀬を切った「秋田にせきかへき料」〔飲み込みのOCR崩れ候補・「せきかへ（堰替え）」の読み保留〕**。②は**玉川上水から分水して神田上水筋に落とす水利機構（千川上水系の分流運用）への言及候補**として記録（分流の特定・「井戸の頭」の解釈〔井の頭池の水＝神田上水の水元の意か〕は原画像照合まで断定しない）。「面影の橋」は高田落合の面影橋系の橋。「□□田村」の村名（判読保留。面影橋の北側の村落名候補）も照合課題。
- **高田落合村七曲の用水道文言候補〔確認・文言候補〕**: [10]（2577951・椎名町→高田落合方面の紀行本文）に「**…高田落合村七曲して行…岐路あり 左を行れも両等田に出（?）…**衣服がり**用水道を損〔堰のOCR崩れ候補〕きりて東に流る こゝよりおよし平尾に出て末は瀧の川と成といへり**」＝**高田落合村七曲付近の用水路（「衣服がり」＝洗濯場・板敷きの判読候補・保留）を堰き切って東に流し、平尾を経て末は瀧の川（帰属保留候補）に至るという流路叙述候補**（高田・椎名町〜平尾方面の用水路の流路記録の候補。「瀧の川」の実体（千川系・妙正寺川系等の比定）は本条では判断できない）。「損きりて」＝「堰切りて」候補。OCR列崩壊大・要照合。
