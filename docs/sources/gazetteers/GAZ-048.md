- **書誌〔確認・出版年は一部要照合〕**: 『**大日本地誌大系**』（**蘆田伊人**編・雄山閣）のうち『新編武蔵風土記稿』首巻〜巻之二十を収載した冊。NDL次世代デジタルライブラリー [book/1214832](https://lab.ndl.go.jp/dl/book/1214832)。巻末の奥付・例言OCRで「一本大系は、もと日本歴史地理學會の計畫に係り、その後大日本地誌大系刊行會之を繼承し…今回再び是を復興繼續するものなり」「一本卷には、新編武藏風土記稿二百六十五卷の中首卷より卷之第二十までを收載せり」「**昭和四年五月十五日發行**」＝**1929年（昭和4年）刊**と確認〔NDL書誌側の出版年表記は要照合〕。風土記稿本体は文化〜文政期の幕府編纂で、本冊の活字版は[GAZ-046](GAZ-046.md)（1884年〔明治17年〕刊・巻11-17）とは**別系統の刊本**で、**OCRが1884刊版より格段に読みやすい**。**引用はすべてOCR由来で、文言は原文画像（本冊活字または内閣文庫本）との照合を要する。**巻9（豊島郡之一・総説・川・用水）、巻15（豊島郡之七・小石川村・小石川新田・小石川大塚村・青柳町在方分＝音羽町・桜木町）、巻16（豊島郡之八・雑司ヶ谷村・巣鴨村・関口町）が今回の対象。

## 制限・未解決

- ①すべてOCR由来で、特に「堀二」「江戶水元…田間川に入」の語順・「水久保」の原字形（水窪の可能性）・小名リストの区切り（⑬①の「寂法〓・水・水久保」の両読み）・「是小谷端川石川の上流也」の原表記・「七九地」（丸池地か）・「絲馬」「本〓」の欠字・⑪④の割注崩れ（「一派は關口(堰を設て)」・「沃くしとなり」）・⑭⑤の小名「〓土」の原字形・⑪⑤の「古川町は小日向川跡を埋立し所」の解釈は原文照合を要する。②本冊（首巻〜巻20）の巻21以降（豊島郡の残巻・多摩郡等）の精読は未実施。③「小谷端川」と巻9「谷端川」・巣鴨村内呼称の関係（通称か別川か）は未解決。④巣鴨村条の橋4（藤橋・上橋・寂法橋・東福寺橋）と[GAZ-002](GAZ-002.md)北豊島郡誌の矢端川橋群（藤橋・熊之窪橋・東福寺橋）・[BLOG-133](../blogs/BLOG-133.md)巣鴨村絵図読図の同一性は未解決。⑤〔第112回で解消〕関口町条・小日向町在方分の精読は⑪⑫に実施済み。なお風土記稿の御府内の部（関口水道町・音羽町等の町条）は巻73以降にあり本冊（首巻〜巻20）は未収録のため未実施（大系版続巻の所在確認が課題）。⑥渋谷川村条の小名「水窪」は音羽・雑司ヶ谷側の水窪とは別地名（混同禁止）。⑦⑪④の摺鉢の瀧「古川町の方へ沃く」の比定（旧江戸川流路のどの部分か）・関口の瀧と摺鉢の瀧の位置確定は未解決（次回課題）。⑧〔第129回〕下板橋宿条の「○仙川用水」文言はOCR二重化崩壊で判読不能（「場滿の酒浦釀だ」）で文言候補のまま。池袋・中丸村条の「仙川用水」と千川上水（巻9千川上水跡条⑩・千川分水）の対応（異記か別用水か）は原画像照合・[GAZ-057](GAZ-057.md)（多磨郡側用例）との対照まで断定しない。⑨〔第149回〕⑰の村名由来説の文言（雜司料・雜士・小田原役帳の太田新六郞・十二貫五百文・中村二郞右衞門等）は大系版OCR由来で、小田原役帳自体が草体である旨の本文の注記どおり原典との照合を要する。風土記稿と御府内備考巻52（町方書上）の文言差（雜士／雜式・御放鷹／御成等）の孰れが古形かは断定しない。
