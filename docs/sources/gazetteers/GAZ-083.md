# [GAZ-083] 小石川志料（東京府文献叢書甲集巻之十七）— 蟹ヶ窪・鶏声窪・ねこまた橋・指江谷・千川屋鋪の江戸期文言

- **書誌〔確認・要補完〕**: 『小石川志料』（著者署名は本文の按語から「純庸」〔OCR〕。一箇所「紀庸曰」の表記もあり**著者名の実表記・人物比定は要原文照合**）。『東京府文献叢書』甲集巻之十七（NDL次世代デジタルライブラリー [book/2577108](https://lab.ndl.go.jp/dl/book/2577108)、labメタのvolumeは「[17]」・刊年欄は空欄）。同叢書は東京府記録掛編修部が明治11年（1878）から明治20年代に編纂した未公刊地誌集成（甲集全125巻・[東京都公文書館の叢書解説](https://www.soumu.metro.tokyo.lg.jp/01soumu/archives/0302shiryou_syokai.htm)）で、[GAZ-081](GAZ-081.md)駿河台志（甲集第五冊）と同系列。**巻之十七固有の刊年は未確認**（year欄の1878は叢書編纂開始年）。本デジタル化には**巻之一（総説・街・山川〔川条・橋梁条〕・馬場）と序**が含まれ、総目に掲げる巻之二〜六（神社寺院・寺院・売墓古蹟・人物）の本文は含まれない（未デジタル化か欠落かは未確認・断定しない）。
- **編纂背景〔確認・文言候補〕**: 序に「**文化八年の冬 風土記を作るへき仰こと承りしは**」＝文化8年（1811）の風土記編纂の仰（新編武蔵風土記稿の編纂開始期に対応）を受けた**私撰地誌**である旨と、「**予かふるくより家居する小石川のうちにつき地理の変遷古今の沿革を正し神社仏宇の社伝縁起を拾ひ集め江戸志の足らさるを補ひ**」＋「**故老に就て古今のかはりしさまを問ひ尋ねし**」＝**小石川在住の著者が江戸志（安永頃の地誌）を補う目的で故老聴取を交えて編んだ地誌**である旨の方法記述。〔文化8年を起点とする編纂年代の下限の文言。引用に江戸名所記・江戸名勝志・江戸雀（寛文〜天和頃）・江戸砂子（享保）・江戸志（安永）・江戸惣鹿子・紫の一本〔ママ・書名『紫の一筋』か要照合〕等を使い分ける史料批判の記述も含む〕。
- **蟹ヶ窪の由来2説〔確認・repo初出級・文言候補〕**: 蟹ヶ窪条「**蟹ヶ窪 此地名の所在定かにせす 可児某の居住ありし故名とせるなと故老の話あれと既に所在を失ふ故たしかなることをしらす**」＋江戸志引用「**愛谷〔ママ・OCR。茗谷・茗荷谷系の字の可能性があり要照合〕の上 伝通院前大通り組屋敷の前少き石橋の処 往古は流ありて蟹多く居し故にこの名あり 今は少き窪にて水も無し 次第にひきし地下りて鶯谷に至れり**」＝（ａ）**蟹ヶ窪の位置を「伝通院前大通りの小石橋の処」とする江戸期文言**（水窪川源流の旧地名〔[対照表](../../地名・河川名対照表.md)水久保行〕の位置特定の新資料）、（ｂ）**往古は流れがあり蟹が多く居た＝今は水の無い窪**という水窪川源流の乾枯叙述、（ｃ）**「次第に引き下りて鶯谷に至れり」＝蟹ヶ窪から鶯谷（谷頭）への地形接続の文言**、（ｄ）**可児某の居住に由来する別説（故老の話として所在既失と注記）**＝由来2説の併記。〔OCR由来のため字句はすべて要原文照合〕。
- **小石川川の流路詳述〔確認・文言候補・谷端川下流のアンカー文言〕**: 川条「**川名詳にせす 北方巣鴨里の方より小石川に〔同入〕南流すて水府中に入り水道橋の西合せり 川幅二三間或は五間に過す**」＋「**正保年中の絵図に此流を記したれは**」＋「**今目撃する処は先砂利取場の下より氷川明神前なる田向を流れ 井上某の後を経 松平播州〔ママ〕わき及宗慶寺北辺を過き 橋戸町を貫き 大雲寺の南脇より光圓寺の後に至り 慈昭院法傳寺〔ママ〕の後背を過き 夫より喜運寺念速寺の裏手を越 無量院門前を流 御先手組屋敷内を経 柳丁を貫き右に折下 冨坂町に至れり 此辺にては小石川大下水と云 源覚寺前…渡辺某中川某宅の後を経 小笠原信濃守脇より水府中に入 此に至るまて屈曲あれとも大概東南流なり**」＝（ａ）**北方の巣鴨里から南流し水道橋の西で江戸城堀（神田川）に合せる本流＝谷端川下流（小石川川）の流路を寺名・町名のアンカー付きで詳述した江戸期の目撃記録**、（ｂ）**冨坂町付近で「小石川大下水」と呼ぶ用例文言**（[対照表](../../地名・河川名対照表.md)小石川大下水行の1854年小石川絵図に先行する地誌用例・repo初出の本文文言候補）、（ｃ）**正保年中（1644-48）の絵図に本流が記されていた旨の言及**＝流路の遡及確認に使える図誌情報（正保図そのものの同定は未確認・断定しない）。
- **指ヶ谷丁支流と鶏声窪の水源池〔確認・文言候補・repo初出級〕**: 川条続「**又一流あり 指ヶ谷丁辺より是も南流して小石川馬場の脇を過き 宮城某川勝某渡辺中川等の前を經 松平丹後守宅地に入 後初に見えたる一流と合し南流して水府に入 水勢も緩く巾三四尺若クは五六尺に過す 水元は巣鴨〔ママ〕難声窪〔OCR・「鶏声窪」の誤読候補・要照合〕なる酒井雅楽頭下部中〔ママ・「下屋敷中」の候補〕の池なりと云**」＝（ａ）**指ヶ谷町辺から南流し本流（小石川大下水）に合する巾3-5尺の支流**、（ｂ）**その水源を「鶏声窪の酒井雅楽頭下屋敷中の池」とする伝え**。〔[GAZ-034](GAZ-034.md)（御府内備考巻44白山前町条）の「**一下水堀巾三尺 右北之方小石川村酒井雅楽頭様御下屋敷ゟ流出 指谷町通りヲ 武家屋敷境通り 小石川馬場之方二相流申候**」と**流路・水源の向き・幅が独立の資料系統で一致**＝指ヶ谷町の下水系統（[対照表](../../地名・河川名対照表.md)指ヶ谷町の下水堀行）の江戸期地誌側の裏付け。六義園の池の排水が鶏声ヶ窪の谷頭に繋がるという[BLOG-244](../blogs/BLOG-244.md)の現地仮説に先行する、**谷頭の窪地に屋敷池があった旨の江戸期文言**。「巣鴨」の冠はOCR崩壊の余地と著者の帰属認識の両方があり得るため保留〕。
- **鶏声窪の位置＝東西大塚の間〔確認・文言候補・repo初出級〕**: 大塚町条「**又鶏声窪 土井氏の下あたりをも大塚と云ひしことは**〔地黄方樽次の『水鳥記』引用・OCR崩壊〕」＋「**江戸小日向より巣鴨へ行所の大塚は小石川の面に…西東と二ツあり 東大塚は難声窪〔OCR・鶏声窪〕土井大炊頭屋敷内にあり 西大塚は小日向台森川小左衛門殿屋敷内にあり 右東西の塚の間の地名大塚と云**」＝（ａ）**鶏声窪の位置を東大塚（土井大炊頭屋敷内）と西大塚（小日向台の森川小左衛門屋敷内）の間の窪地として記す文言**＝BLOG-240/244の鶏声ヶ窪（傾城ヶ窪表記・六義園支流の谷頭）研究に対する**位置の江戸期文言**、（ｂ）**大塚の地名が東西2つの塚の間の地名である旨の独立テキスト**（第53回の大塚地名由来調査への江戸期地誌の追加）、（ｃ）守邦親王墓説（「紀庸曰 比仝郡大家村守邦親王墓あり…延慶元年将軍に任せり」）＝塚の比定の伝承の一つ。〔OCR崩壊が強い箇所であり、字句は要原文照合〕。
- **ねこまた橋の由来・位置と小石川の濫觴説〔確認・文言候補〕**: 総説の江戸砂子〔ママ〕引用「**小石川と云は小石の多き小川幾流もある故也と云 わけて伝通院のうしろの流 ぬこまた橋〔ママ・「祢こまた橋」の候補〕の川筋 小石川の濫觴と云**」＋橋梁条（OCR「子コマ夕橋／子コマタ橋」＝**ねこまた橋〔猫又橋・猫貍橋〕のOCR崩れと推定・実名は要原文照合**）「**氷川明神前なる流の上に架す 池田某表門前を西に向て下れは此に至る**」＋名義「**江戸志云〔南向茶話〕 此地の農民の説に 昔は今より流細くして田畑の通ひ道にて木の根を以て橋にわたす故の名なり 土民は木の根本を根子と唱ふる也**」＝（ａ）**「伝通院の裏の流・ねこまた橋の川筋」を小石川の名の濫觴とする江戸砂子説の文言**（[ma-maison](https://ma-maison.sakura.ne.jp/hill/hist_koishikawa2/hist_koishikawa2_2.html)が引用する『江戸砂子』「傳通院のうしろの流、祢（ね）こまた橋の川筋」と同文の独立テキスト）、（ｂ）**ねこまた橋が氷川明神前の本流（小石川川）に架かる旨の位置文言**（既収録の1918年親柱〔千石2・3丁目〕・不忍通り説明板との位置対校は要照合）、（ｃ）**木の根の渡しに由来し土民が「根子」と呼ぶ」という橋名由来説**＝[BLOG-156](../blogs/BLOG-156.md)の説明板狸伝承とは別系統の由来文言（猫又・猫股・根子股・根木股の異表記列挙の「根子」系を直接説明する江戸期文言候補）。
