# [GAZ-069] 東京誌略（大滝確荘編・1877）— 両上水の二源説と江戸川区間の明暦万治仙台侯疏浚説〔第145回〕

- **書誌〔確認〕**: 大滝確荘編『東京誌略』（1877〔明治10〕・請求記号特32-718・書誌ID000000425928・15頁）。NDL次世代デジタルライブラリー [book/764128](https://lab.ndl.go.jp/dl/book/764128)。**1頁ごとの短い概説書でOCRに乱れがあり、文言は要原文照合**（「御堀ニ覚ヲ架シテ」＝御堀ニ樋ヲ架シテ等）。
- **水道の二源説と井頭上水の経路〔確認・文言候補〕**: 「**水道ニ二源アリ、一ヲ多摩川ト云ヒ、一ヲ井頭池ト云フ。多摩川上水ハ承應二年ニ之ヲ疏シ、四谷ヨリ御堀ニ樋ヲ架シテ之ヲ引キ、四方ニ分レ伏流シテ市街ノ井泉トナリ。井頭ノ上水ハ目白小石川ヲ經テ神田以南ノ飮料ニ供シ、俗此レヲ神田上水ト稱セリ**」＝**①江戸/東京の水道に二源（多摩川＝玉川上水・井頭池＝神田上水）があるという二源説、②玉川上水は承応2年（1653）に疏いた、③井頭（井の頭）の上水は「目白・小石川」を経て神田以南の飲料に供し、俗にこれを神田上水と呼ぶ**という1877年の記述。〔**③の「目白小石川ヲ經テ」＝神田上水の流路を目白→小石川の順で記した明治10年の文言**＝関口大洗堰から白堀（目白台下）を経て小石川方面に至る区間の経路観察で、[GAZ-049](GAZ-049.md)（白堀上水・関口の方より流れ來り小石川にかゝる）・対照表の白堀行と対校できる。「俗此レヲ神田上水ト稱セリ」＝「神田上水」が俗呼であるという1877年の見方の記録。②の承応2年は玉川上水側の年代であり、神田上水への適用は本書では明記しない〕
- **神田川（江戸川）条＝明暦〜万治の仙台侯疏浚説〔確認・文言候補・repo初出候補〕**: 「**神田川ハ江戶川大洗堰ノ下流ニシテ、湯島師範學校ノ下ヲ斜ニ東流シ大川ニ入ル。明曆万治ノ間、仙臺矦ノ疏スル所ナリ**」＝**①神田川は江戸川の大洗堰の下流で、湯島の師範学校（湯島聖堂内・当時の東京師範学校）の下を斜めに東流して大川（隅田川）に入る、②その江戸川区間は明暦〜万治の間（1655〜1661）に仙台侯（伊達氏）が疏（疏浚・開掘）したものである**という1877年の記述。〔**②の江戸川区間（関口大洗堰〜神田）の開掘・疏浚年代を「明暦万治ノ間」・実行者を「仙臺矦」に帰する説はrepo初出候補の文言**。江戸川（神田上水の分派区間）の開削年代はrepoでは未解決事案で、本説は明治10年の概説書レベルの attribution として年代・実行者の両面で新しい datapoint。仙台侯の比定（明暦〜万治期の仙台藩主＝伊達綱宗か）・「疏」の解釈（新規開掘か疏浚か）は本書のみでは断定せず、原画像照合と他資料の対校を待つ。①の「大洗堰」の1877年用例は関口大洗堰の名称の通時系列の定点（[BOOK-147](../books/BOOK-147.md)系・[GAZ-065](GAZ-065.md)関口条と対校可）〕

## 制限・未解決

- ①本書は短頁数の概説書で、江戸川開削の典拠（明暦万治仙台侯説の出所）の記載はない。**実録・沿革物の通俗説の流用の可能性を排除できず、採用は対校資料の発見まで留保**。②「仙臺矦」の比定（明暦〜万治期＝伊達綱宗の襲封期〔万治元年・1661〕前後の動静）は本書のみではできない。③OCRの崩れ（「大洗堰」の読み・「江戶川大洗堰ノ下流ノ下流」の重複など）は要原文照合。④千川・仙川・谷端・水窪・弦巻の語は本書fulltext検索で陰性。
