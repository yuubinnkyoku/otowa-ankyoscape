# [GAZ-061] 東京市史稿 遊園篇 第3 — 「附記一 音羽玉水簾」（武江年表の転記）

- **書誌〔確認〕**: 『**東京市史稿 遊園篇 第3**』（東京市・1929年刊）。NDL次世代デジタルライブラリー [book/1915739](https://lab.ndl.go.jp/dl/book/1915739)。目次で「**附記一 音羽玉水簾**」の見出しが独立節として存在することを確認済み。〔遊園篇第3は[GAZ-056](../gazetteers/GAZ-056.md)（遊園篇第2・1926年・音羽の岡場所の同時代町方届を引く）の隣接巻〕
- **①「附記一 音羽玉水簾」〔確認文言・repo初出〕**: 官撰市史の遊園篇が音羽玉水簾（音羽の滝）を**独立した附記節**として立て、その全文が**武江年表**（[BOOK-154](../books/BOOK-154.md)・嘉永2年1849年刊）の文化9年（1812）の条の**転記**であることを確認（「音羽町二丁目三丁目あたりの西の裏手に…玉水簾と號す…天保の始より廃たり」の文言構造、および狂歌2首〔蜀山人「深山より…水無月の空」・縣麿「けふそ見る…」〕の併載まで含め武江年表の記事のほぼ全体を引用する構成）。
  - 〔市史稿の附記は武江年表の情報を官撰レベルで鵜呑みしただけではなく、一応の吟味の末に採用したものであり、**造営年代「文化9年秋」・「天保の始より廃」の系統が武江年表一系統のみならず市史稿にも及んでいる**という資料の広がりの意味がある。ただし本節自体は新事実の供給源ではなく武江年表の二謀系統（セカンダリー）である点に注意（断定しない）〕
- **②利用上の注意〔観察〕**: ①本節の記述は武江年表の転記であり、**文化13年5月説（[GAZ-035](../gazetteers/GAZ-035.md)・町方書上149）・文化初年説（[BOOK-151](../books/BOOK-151.md)）との年代対立の吟味は本節では行われていない**（年代対立の併記は[BOOK-154](../books/BOOK-154.md)参照）。②狂歌の署名「縣麿」の表記は原本OCR由来（「男山人縣麿」）で、転記の正確さは原文照合を要する。

## 制限・未解決

- ①附記一の文言は武江年表原本（1849年版）と江戸叢書活字版（1917年）のどちらを底本にしたかは本書では特定できない。②武江年表の記事以外に本節が独自に補う情報は今回のfulltext確認では見出せなかった（要再確認）。③遊園篇第3の付近に音羽の岡場所・音羽富士・潭弦亭の独立記述があるかは未走査（次回課題）。
