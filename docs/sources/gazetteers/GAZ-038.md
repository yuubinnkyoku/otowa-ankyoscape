# [GAZ-038] 町鑑 — 両「千川屋敷」の位置・番組の並記

- **書誌〔確認〕**: 『町鑑』[1]（江戸後期の町鑑（町方の名主・家主・番組を列挙する役所用/商用の名鑑）・写本）。NDL次世代デジタルライブラリー [book/2588035](https://lab.ndl.go.jp/dl/book/2588035)。**引用はすべてOCR由来（写本OCR）で、文言は原文画像との照合を要する。**
- **南茅場町の「裏通り千川屋敷」〔確認・茅場町千川屋敷の位置の確定文言（repo初出）〕**: 「**一南茅場町里俗裏通り千川屋敷裏茅場町と唱候北島町同小路之二而七軒町鍛冶町…**」〔**①南茅場町の「裏通り」に千川屋敷があり、里俗に「裏茅場町」と唱えられるという文言、②前後の列挙（北島町・七軒町・鍛冶町等）が八丁堀・茅場町側の小路群であること**＝**八丁堀系「千川屋敷」（[BOOK-131](../books/BOOK-131.md)・[BOOK-133](../books/BOOK-133.md)・[GOV-214](../gov/GOV-214.md)・[GOV-219](../gov/GOV-219.md)）の位置が「南茅場町の裏通り（＝裏茅場町と俗称される区域）」と町鑑レベルで確定できる文言（repo初出）。南茅場町の表通り（堀）に対する裏側＝現在の中央区茅場町裏側・八丁堀寄りの区域と推定できる（観察・番地レベルの特定は地籍図照合が今後必要）**〕。
- **白山前町の千川屋敷の13番組並記〔確認〕**: 「**…小石川白山前町同白山前町千川屋敷衣笠房次郎坪三之助小石川白山大道通り同白山社地内門前同妙清寺門前同常検寺門前同圓宗寺門前…**」〔**①小石川白山前町の千川屋敷が町鑑の13番組（の列挙と推定・OCRの番組対応は要照合）に現れること、②「衣笠房次郎・坪三之助」という隣接する人名（地親・名主層か）が並ぶこと**＝**白山前町千川屋敷が南茅場町千川屋敷と同じ町鑑の中で（別の番組として）並記されていること＝江戸に2系統の「千川屋敷」が町鑑レベルで並存していたことの確定資料**。「衣笠房次郎」は[GAZ-037](GAZ-037.md)大江戸志の「衣笠勘七」と同系（白山前町の町方の家）の可能性があるが対応は未確認（断定しない）〕〔ハンドオフ時に「13番組」と要約した番組は、OCRの番組標目と千川屋敷文言の行対応からは確定できず、原文照合まで保留〕。
- **位置づけ〔観察〕**: ①町鑑（実務の名鑑）に両「千川屋敷」が現れることで、「千川屋敷」の二系統（茅場町＝八丁堀の入堀埋立起-origin〔[BOOK-131](../books/BOOK-131.md)〕・白山前町＝千川家の拝領屋敷〔[GOV-210](../gov/GOV-210.md)〕）が江戸後期の町方行政で安定的に併存していたことが、①行政文書（[GOV-219](../gov/GOV-219.md)）・②地誌（[GAZ-037](GAZ-037.md)）・③町鑑（本書）という3種類の資料系統から裏付けられた（観察）。②「裏茅場町」の俗称は、[GAZ-038](GAZ-038.md)の位置特定を今後の地籍図・古地図照合（南茅場町裏の町割）に接続する手がかり。
