# [GAZ-024] 御府内備考 湯島之部 — 千川上水の市中埋樋の町別書上

- **書誌〔確認〕**: 『大日本地誌大系 第2巻』（御府内備考 巻25〜46＝湯島之部、1929年・雄山閣刊）。NDL次世代デジタルライブラリー [book/1214857](https://lab.ndl.go.jp/dl/book/1214857)。OCRテキストで湯島・本郷各町の「千川上水跡」条を確認。**文言・間数はOCR由来で要照合。**
- **天明7年4月の取潰・埋立〔確認・repo初出の月単位記録〕**: 湯島・本郷各町の地誌御調書上に「**千川上水跡**」条が繰り返し現れ、「**安永九子年中、町内往還に…往來中程に埋中樋懸渡し有之…天明七未年四月中、御差止に相成候節 取潰し埋立申候**」＝**天明7年（1787）4月に市中埋樋区間が物理的に取り壊し・埋め立てられた**旨が各町書上でほぼ同一書式で記録される。天明6年（1786）の上水差止に続き、**市中区間の実体的撤去が翌年4月に行われた**ことを町方文書レベルで示す。
- **町別の埋樋長・桝数〔確認・数値はOCR要照合〕**: 各町書上が自町内の埋樋の長さ・桝を申告する: 湯島横町境＝**長80間5尺3寸5分程・中桝1ヶ所**（湯島横町境三ツ角往来中程）、**22間程・中桝1**（湯島四丁目境四ツ角往来中程）、**68間余**（本郷一丁目境〜湯島五町目境）、**86間余・中桝3ヶ所**、**51間・中枡1・小枡1**、**18間3尺**（無程取潰）等。これらは[GOV-172](../gov/GOV-172.md)（東京府史引・陰樋延長凡1里15町47間）の市中樋管総延長を**町別・間数レベルで裏付ける**分解データ。
- **元禄起源の記憶喪失〔確認〕**: 複数町の書上が「元禄年中之儀は極跡等申伝へも無御座 書留無之 相分り不申」と記す＝**文政期の町方には元禄開削の実態記憶・記録が残っていなかった**ことの同時代証言。
- **位置づけ〔観察〕**: 千川上水の江戸市中区間（本郷・湯島経由）の**廃止過程（差止→取潰）と埋樋の実測申告**を、公式地誌（御府内備考）の基になった町方書上群ではじめて具体的に裏付ける。[GAZ-020](GAZ-020.md)（巻51-52 高田・雑司ヶ谷）と同じ御府内備考系列の湯島之部で、千川上水の市中側では初の本文確認。
