# [GAZ-129] 町方書上[72] 谷中町方書上 — 千川家の4人目の請負人名「金助」と根津・谷中境の川・橋の文言

- **書誌〔確認〕**: 『町方書上[72] 谷中町方書上　全』（写・NDL次世代デジタルライブラリー [book/2571553](https://lab.ndl.go.jp/dl/book/2571553)・276コマ）。谷中の九ヶ寺門前・善光寺前町・玉林寺門前町等の町方取調簡条書。9ヶ寺門前条の署名回月は「**文政九戌年十月**」（1826）・善光寺前町条は「**十一月**」署名（同年候補）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571553_{NNNNNNN}.txt` コマ番号。**
- **善光寺前町条の根津御組屋敷境の川・板橋〔文言候補・本冊の主要価値〕（p115）**: 「**但御検地帳谷中町之内に籠り有之候 町内ゟ西え根津御組屋鋪之方え渡り候 堂深川(=OCR崩れ候補)か唱来り 川幅九尺程 右江掛り候板橋名目不相知 幅弐間程渡り壱丈七尺程有之 千川請負人金助と申もの引受にて 町内に而は相拘り不申候 且同所北之方谷中片町之方え渡り候川幅九尺程 板橋北明門之橋と唱 幅七尺程渡り弐間程有之 三浦備後守様御屋敷御懸りニ而去川同之儀迚も船同に而も拘り不申候**」＝**①善光寺前町の西（根津御組屋敷との境）を流れる「堂深川(OCR候補)」と呼ぶ川（川幅9尺）、②そこに架かる名前のない板橋（幅2間・渡り丈7尺余）の請負人は「千川請負人金助」（町内では負担せず）、③同所の北・谷中片町へ渡る川幅9尺の川に架かる板橋「北明門之橋」（幅7尺・渡り2間・三浦備後守様御屋敷御懸り）**。〔**①千川家の橋請負人の実名として金助が新出（[GAZ-113]の茂是〔茂兵衛候補〕・茂兵衛・重助に続く4人目の名の文言候補・系譜の位置付けは [GOV-210]・[GOV-212] 系図との対照まで保留）、②「北明門之橋」は [GAZ-113]（御府内備考）の「不明門之橋」（三浦備後守様御屋敷御懸り・甲府屋敷不明門の遺名候補）と**懸り先が同一**で「北明門／不明門」の判読対立の新たな一組（原画像でどちらの字か確定するまで断定しない）、③川名「堂深川」はOCR崩れ大で谷戸川（藍染川）の区間呼称の変種候補（「堂久川」「堂ヶ崎川」等多義・原字は照合課題）＝[GAZ-113]藍染川総説（巣鴨駒込の谷戸川の末流が善光寺門前感応寺古門前等の辺で藍染川と称す）と同じ境川の谷中側一次文言としての対校値、④千川家が橋の建設・修復を請負い「町内では負担しない」＝千川上水の神田川湧水系の維持と橋負担の実態（[GAZ-113]千川家3橋・[GOV-210]四橋）が町方書上原本でも反復されること**〕。
- **GOV-210四橋リストとの対応候補**: [GOV-210]（遠山書付）の明和5年減免後の4橋「根津宮永町→同所惣門・宮永町西裏通→根津門前町（堀端）・同所→谷中通り・同所→善光寺前町」の第4橋（**善光寺前町へ渡る橋**）と本条の根津御組屋敷へ渡る板橋（千川金助引受）の対応可能性。〔比定は保留（本条の橋は名称なし・GOV-210の橋も橋名なしだが幅・村名の整合を原画像で確認するまで断定しない）〕。
- **寛延3午年5月の御検地文言〔文言候補・GAZ-113対校〕（p115）**: 「**反別六反五畝弐拾壱歩 一豊嶋郡岩渕領ニ而无之(=無之候補) 一寛延三午年五月 神殿(=神尾候補・OCR)若狭守様 曲淵豊後守様 御検地有之候**」＝善光寺前町の御検地（寛延3年〔1750〕5月・神尾若狭守・曲淵豊後守）＝[GAZ-113]（御府内備考・谷中総説の同検地文言）と同一年次・同一奉行の**一次書上側の反復witness**（岩淵領の領主名も併存）。
- **その他の条の陰性観察**: 9ヶ寺門前条（文政九戌年十月署名・名主無之の記述）・谷中玉林寺門前町条には千川家文言・水路文言の出ないことを確認（[GAZ-113]の玉林寺門前条「千川請負人重助」文言との搭載の差＝御府内備考の千川家文言は元書上の特定条のみの抽出と推定されるが断定しない）。谷中群全条で「内部」に湧水・池の文言はなし。
