- **書誌〔確認〕**: 『新編武蔵風土記稿』巻之十八 豊島郡之十（岩淵領: 王子村・滝野川村・田端村・西ヶ原村・新堀村ほか）（内務省地理局・1884〔明治17〕活字版・NDL次世代デジタルライブラリー [book/763978](https://lab.ndl.go.jp/dl/book/763978)・bibId 000000425830・callNo 105-30・114頁）。**原編は文化〜文政期（江戸後期）の官撰地誌で、1884年は活字刊年**（引用文言の年代の解釈に注意）。OCRは所々に別テキストの混入（「上海交通大学附属…」「臺灣日野党」等）があり要照合。引用文言はすべてOCR由来で文言候補。
- **滝野川村条〔確認・文言候補・repo初出文言群〕**: ①「**瀧野川村ハ古キ地名ナリ源平盛衰記賴朝隅田川ヲ渡テ府中ヘ趣シ條ニ武藏國豐島郡上瀧ノ川松橋ト云處ニ陣取由ヲ載セ**」＝**上瀧ノ川・松橋の中世陣所記録（grep 上瀧=0件・repo初出）**。②「及豐島系圖ニ**宮城八郞重中カ次男瀧野川太夫五郞信久**信久子…信川…久吉…久道…豐明トミユ**是等皆當所ニ住シテ在名ヲ氏ニ唱ヘシ**」＝豊島系図の瀧野川氏（中世の在名＝氏の関係）。③「**北條役帳ニ太田新六郞カ知行二十一貫五百文江戶瀧野川源三郞分二十一貫文江戸瀧之川梶原堀之内澁江分トモ載タリ**」＝北條役帳の江戸瀧野川・江戸瀧之川知行文言〔[GAZ-022](GAZ-022.md)長崎村条・GAZ-048大根原・雑司ヶ谷の役帳文言と同種・repo初出の文言候補・二次引用〕。④村名由来「**村ノ北王子村境ヲ流ルヽ石神井川急流ニシテ水聲四方ニ響ク事瀧ニヒトシトテ瀧ノ川ト唱ヘ始メシヨリ村名トモナセリト村內金剛寺松橋辨天ノ緣起ニイヘリ**」。⑤「**用水ハ仙川分水ノ下流ヲ引沃ク**」＝**滝野川村の用水＝仙川分水の下流とする官撰文言（grep 仙川分水=0件・repo初出）**〔1918年郡誌「長崎村・板橋町・瀧野川町を流れて王子村に至り石神井用水に合ふ」（千川用水下流の記述）の江戸後期編纂レベルの先行記録＝仙川用水受益村リストに滝野川村を加える対校点〕。⑥鎌倉古街道＋南向茶話引用「**高田馬塲ヨリ雜司ヶ谷法明寺脇通リ…谷村瀧ノ川村ヲ經テ豐島ヨリ千住ノ方ヘ**」＋「**谷村ハ村ノ小名谷津トイヘル所ナルヘシ**」〔[GAZ-092](GAZ-092.md)古道条・GAZ-048⑭と対照〕。⑦撿地寛永16年・小名 谷津・北山・押外戶・馬塲宮ノ下。⑧「**谷畑村ノ北境ヲ流ル幅五間程是ヲ瀧ノ川…逆川…石神井川トモ唱フル…王子川ニ入ル…村ノ南巢鴨村界ニ…幅一間ヨリ九尺ニ至ル○源五郞淵アル小流**」＝瀧ノ川（石神井川）・逆川・**源五郎淵**の水文文言〔源五郎淵=repo初出・王子川・逆川の対校点〕。
- **王子村条〔確認・文言候補〕**: ①村名「**往古岸村ト唱フ荒川ノ岸ニ臨ミシ地ナレハナルヘシ**」＝岸村旧名説。②「**飛鳥山（略）元ハ瀧野川村ニ屬セシ地ナリシ**」＝飛鳥山の旧滝野川村属地説（元文2年の桜植栽・采地召上げの記事と併せ文言候補）。③「**石神井用水ヲ引沃ク**」＝王子村も石神井用水受益村（田端村条と併せ受益村リストの対校点）。④金剛寺（松橋院）の項: 「**安置ス辨財天長一尺ノ石像ニテ松橋辨天ト號ス弘法大師ノ作當時此地ニ松橋ト云橋アリシ故地名ヲ…唱トイヘリ松橋ノ名ハ前ニ云ル如ク源平盛衰記ニ見エテ舊キ地名ナリ治承ノ頃賴朝此辨天ニ歸依ノ餘リ太刀ヲ寄附アリシ由**…**洞中ニ文保三年三月ト彫タル古牌一基**」＝**松橋＝橋の実在説＋源平盛衰記所出の旧地名＋治承頃の頼朝帰依譚＋文保3年（1319）古牌＝中世の橋名候補**（橋名調査の最重要追記点・緑起文言は二次引用）。
- **西ヶ原村条〔確認・文言候補〕**: 「**西ケ原村ハ昔平塚ニ屬セシト見ユ北條役帳ニ平塚藤右衞門二十貫文江戸平塚之內西原ト載タリ**…**用水等前村ニ同シ**（＝田端村と同じ石神井用水）」＋撿地延寶2年＋「**小名貝塚橋戶上ノ臺殿ノ上一本木御殿前原向ヒ原前谷津池ノ尻ソヤ形廣町原作茶ノ木田原久保穴回四谷戶一町目**」＝西ヶ原村の中世知行（平塚之内西原）・小名群〔**橋戶**＝小石川橋戸町との関係は断定しない（文言候補）〕。
