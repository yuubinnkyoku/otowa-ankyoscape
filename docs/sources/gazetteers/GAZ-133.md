# [GAZ-133] 町方書上[89] 浅草弐 — 鳥越町条の古上水（千川上水系）の差止・枡石垣文言と鳥越橋・八字天王橋

- **書誌〔確認〕**: 『町方書上[89] 浅草町方書上　弐』（写・NDL次世代デジタルライブラリー [book/2571570](https://lab.ndl.go.jp/dl/book/2571570)・292コマ）。大直寺門前・天王町・猿屋町・会所附地所・三好町・新旅籠町・元旅籠町一丁目・二丁目・森田町等の町列挙（表紙丁順）＝千川上水末端の浅草側代地町群と重なる町域の書上。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571570_{NNNNNNN}.txt` コマ番号。**
- **鳥越町条の古上水文言〔文言候補・本冊の主要価値〕（p15）**: 「**古上水 始り不相知仰(=申候補) 天明七未年四月□□十二日 御差止二相成 其砌井戸埋洩(=埋立候補・OCR)申候 当時会所付地所之内に差上ヶ所 右上水枡 古石垣潰申候**」＝**①古上水の始まりは（町方では）知らない、②天明7年（1787）4月□□十二日に御差止めとなり、その際井戸を埋めた、③その時会所付地所の内に（土地を）差し上げ、④上水の枡の古石垣を潰した**という一続きの文言。〔**①「古上水始り不相知」＝[GAZ-115]（御府内備考・尾町条「始り年月有所共相知不申候」）と同じ「始まりを知らない」文言の浅草町方書上側 witness**（同じ末端域でもう一つの町がはじまりの記憶を持たなかったことの反復＝千川上水の開設由緒が末端町方に全く残っていない観察の厚み）、②**「四月□□十二日」＝差止日として十二日を読める文言の新たな一例**（[GAZ-115]旅籠町壱丁目代地条・尾町条・茅町壱丁目条「四月十二日」系と整合、[GAZ-132]平右衛門町条「四月十三日」・[GAZ-041]/[GAZ-124]系「十三日」との対立群の一つ。□□はOCRの欠損で「十三日」の可能性も断定材料なしでは残るが十二日の字形が優位との判断すらしない）、③**「上水枡 古石垣潰」＝千川上水末端の枡（樋の高低差処理の石造枡か大桝系）の実体遺構が差止時に潰された文言**（[GAZ-115]茅町「埋垣枡」・[GAZ-043]昌平橋四ツ角大桝系と並ぶ枡の語彙の一次witness・石造の材質情報は新出候補）、④会所付地所内の差上げ＝上水施設地の土地の処分（井戸・枡のあった土地の返上）の実務記録**〕。
- **鳥越町条の鳥越橋・八字天王橋文言〔文言候補・橋名調査の対象〕（p15）**: 「**右橋弐ヶ所共 石三町(=石三?OCR崩れ候補)二而引請申候 板橋渡り五間巾三間に御座候由 右橋 鳥越橋と相唱候儀 何卒(=何年候補?)已前ゟ 橋台前後九尺ツヽ御座候 一右申伝候哉 年限相知シ不申 右二ケ所之橋 八字天王橋と相唱申候**」＝**2ヶ所の橋（石造成的な請負文言候補）と板橋（渡り5間・巾3間）があり「鳥越橋」と唱え、橋台は前後9尺ずつ、二ヶ所の橋を「八字天王橋」とも唱える**という橋名・規模の文言（何年以前からかは町方も知らない旨）。〔**浅草の鳥越（鳥越神社側低地）の橋名「鳥越橋」・「八字天王橋」の一次文言候補**＝[GOV-437]（天明6年出水被災3橋の「新鳥越橋」・渡り6間×巾2間）との対照候補・ただし**新鳥越橋（今戸側の御普請対象橋）と本条の鳥越橋（鳥越町側）の同一比定は断定しない**（渡り・巾の寸法が異なる〔5間×3間 vs 6間×2間〕ため別橋の可能性が強いが文言の出自が違う帳簿のため保留）。「八字天王橋」の語は鳥越神社の「酉の市」に関係する橋名の候補として記録（由来の断定はしない）〕。
- **天王町・旅籠町系の条の陰性観察**: 猿屋町・元旅籠町一丁目等の条に千川上水・上水文言の出ないことを確認（[GAZ-127]旅籠町2丁目代地井戸1ヶ所文言は浅草壱之下冊側。冊ごとの収録町の分担の観察）。古上水文言を載せるのは本冊では鳥越町条のみ。

## 制限・未解決

- ①「四月□□十二日」の欠損部の原字（十二日か十三日か）は原画像照合課題（十二日系の文言分布と断定材料の対応はしない）。②「古上水」の文言が千川上水を指すことは本冊の条では「千川」の文字列を伴わない（「古上水始り不相知」の文脈・井戸埋立・枡石垣の内容が[GAZ-115]・[GAZ-132]の千川上水末端文言群と同型であることによる同定の推定で、条自体の付記文言として断定していない）。③「石三町二而引請」の原字はOCR崩壊大（「石三丁」「石三町」等・請負側の文言候補としての解釈も保留）。④「埋洩」は「埋立」のOCR誤読候補。⑤鳥越橋と新鳥越橋（[GOV-437]）の関係・「八字天王橋」の由来は断定しない。
