# [GAZ-023] 『日本歴史地名大系』「音羽」項

- **直接確認（2026-11-13、第61回）**: コトバンクの「音羽」頁に転載される**平凡社『日本歴史地名大系』「音羽」項**（コトバンクは本文の一部を掲載。全項目はジャパンナレッジで閲覧可）。該当巻の刊年は今回確認していない。
- **音羽の地理と弦巻川〔確認: 地名大系本文の引用〕**: 「関口台と小日向台に挟まれた低地（**かつての弦巻川の流域**）および周辺の通称」〔**地名大系レベルで音羽低地=弦巻川流域と明記する文言はrepo初出**。BLOG-198の音羽谷=両川の谷戸という観察と整合〕。
- **護国寺領への寄進〔確認: 同引用〕**: 「一帯は**元禄10年（1697）に護国寺の観音堂建立に併せて同寺に寄進された**。護国寺領となった地は**『徳川実紀』には「寺前の市井百石の地」**とあり、**『風土記稿』によると雑司ヶ谷・小石川・小日向・関口・巣鴨の五ヵ村の耕地と備中松山藩主安藤氏（のち美濃加納藩主を経て陸奥磐城平藩主）の屋敷の一部など（合せて高一〇〇石）**であったという」〔『徳川実紀』「寺前の市井百石の地」・五ヵ村耕地100石はいずれもrepo初出文言候補。1681年護国寺創建整備伝承（BLOG-089等）と元禄10年観音堂建立の年次関係は本文では分離して語られる点を注意して保持〕。
- **門前町の町割〔確認: 同引用〕**: 「護国寺の表参道にあたる地で、門前町としての町屋の起立が許され、のち**東西の青柳町、音羽町一〜九丁目・桜木町の各町に割られ、正徳3年（1713）町奉行支配**となった」〔正徳3年町奉行支配=repo初出。青柳町（東青柳・西青柳）・桜木町の町名史の補強〕。
- **地名由来〔確認: コトバンク転載の事典3種〕**: デジタル大辞泉「**音羽局おとわのつぼねが徳川家からこの地を給されたのでこの名がある**とも、護国寺を京都清水寺に模して、**清水観音の音羽の滝にちなむ**ともいわれる」〔音羽局給地説・清水寺音羽滝説の双方を並記。奥女中音羽説の典拠文言はBLOG-198の新撰東京名所図会引用と別系統〕。精選版日本国語大辞典「江戸末期には**私娼の店が多かった**」〔音羽の私娼の記述はrepo初出候補。大塚花街史（BLOG-093等）と重なる時代の地域像〕。
- **限界〔未解決〕**: 地名大系該当巻の書誌（巻名・刊年）と全項目本文（ジャパンナレッジ）の確認。『徳川実紀』「寺前の市井百石の地」の原箇所。『風土記稿』音羽関係の巻・頁の特定。
