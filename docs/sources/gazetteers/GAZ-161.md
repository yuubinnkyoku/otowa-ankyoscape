# [GAZ-161] 町方書上[52] 芝町方書上 六（文政10-11年）— 三田上水の金杉側の実態文言と天和変種

- **書誌〔確認〕**: 『[52] 芝町方書上　六』（写・NDL次世代デジタルライブラリー [book/2571533](https://lab.ndl.go.jp/dl/book/2571533)。NDL目録volume表記「[52] 芝町方書上　六」・直接確認）。芝金杉通壱〜四町目（p5/52/67/76）・金杉同朋町（p88）・金杉社（p30）・金杉町漁船（p35）等の町条（条末「文政十亥年九月/十月」の署名が見える）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571533_{NNNNNNN}.txt`）。同帯の [53]（金杉裏壱〜五町目・p3の見出し文言「金杉裏壱町目」等）・[54]（金杉片町・浜町・西応寺町等）にも「三田上水跡之儀は金杉通壱町目ゟ申上候通」の委譲定型文言が連続する（対校のみ・本ファイルでは採録対象としない）。
- **金杉通壱町目条の三田上水の実態文言〔文言候補・本冊最重要〕（p26）**: 「**寛文四辰年ゟ玉川分水ニ而三田上水掛り候所 享保七寅年ゟ相止 当時上水無御座候 右水路之義者相分兼候 三田台町辺 聖坂通り通筋普請之節 出銀之請取書有之候迄に御座候**」（p26・OCR）＝**①三田上水の掛り（寛文4辰年）・相止（享保7寅年）の年次文言、②「水路の筋は分からない」が「三田台町辺・聖坂通りの通筋普請の際の出銀の請取書」が残っている、という水路の実態の限界と実務記録の所在を明記する文言**。〔**三田壱町目条〔[GAZ-158](GAZ-158.md)〕の全流路列記と対応する給水区側（金杉）の申出文言**＝壱町目側は村列・地形側（聖坂＝三田台の高低差）は金杉側が記録を分担したと読める材料。出銀之請取書の残存（文政11年時点）の指摘は通筋普請の実務（町方の負担出銀）の存在を裏付ける。なお「聖坂」文言は[GAZ-157](GAZ-157.md)伊皿子坂文言（長1町半・伊皿子台へ登る坂）と[GAZ-158]流路列記の「聖坂」と地点論で対校できる。支配は「町奉行御代官両御支配…中村八太夫様御代官所」（p26）＝三田側（GAZ-158 p22・p88）と同じ代官名。伊奈半左衛門（「伊奈半宿」OCR・要照合）の寛文11亥年8月の御検地文言（p26）も付随。〕
- **金杉同朋町条の「天和之度」起立変種文言〔文言候補・年次対立〕（p101）**: 「**当町天和之度ゟ三田上水相掛候所 享保七寅年ゟ相止申候 委細之儀者金杉通壱町目ゟ申上候通ニ御座候**」（p101・OCR）＝**三田上水の掛かりを「天和之度」（1681-1684）と記す文言**。〔寛文4辰年（1664）説（[GAZ-157]伊皿子台町条・[GAZ-158]三田各町・[GAZ-161]金杉通壱町目条・[152]系冊等の定型文言）に対する**異年次の変種文言候補（repo初出。天和期の何らかの再興・拡張事件を反映した可能性も含めて決定しない）**。町名主の起立文言（「当町并芝築地同朋町・芝六軒町名主之義…今井伊兵衛と申役…享保十七子年退役…町年寄樽屋藤左衛方」p101など）も金杉同朋町の行政史の参考記録。〕
- **金杉帯各町の委譲構造の文言群〔文言候補・組織実務の観察〕（p57・p72・他冊）**: 金杉通弐町目条「**三田上水跡之儀者 金杉通壱町目ゟ申上候通ニ御座候**」（p57）・同三町目条（p72）も同一文言（西応寺町続の横町の西応寺領由来文言を含む）。[53]冊（金杉裏壱〜五町目）・[54]冊（金杉片町・浜町・西応寺町・高輪上之町）・[55]冊（本芝壱〜四丁目）・[56]冊・[58]冊（芝築地同朋町・松本町・新細町代地・新網代地）にも同型の文言と変種（「**三田上水寛文之度始而出来**」〔p21の本芝壱町目条等＝寛文の年次省略型〕・「**三田上水跡 右は同所壱町目ゟ申上候通**」等）が連続する（上記は掃引時点のOCR言及・詳細は各冊の原画像照合後に扱う）。〔**三田上水の給水区側（芝金杉・本芝帯）の調書が金杉通壱町目の代表申出に委譲される実務構造**＝三田側（三田壱町目〔GAZ-158〕）と給水区域を挟む両側の代表町の存在（金杉通壱町目≠三田壱町目＝別の申出主体）が、その文言の情報の非対称（壱町目側は村列・金杉側は水路不明・出銀請取書）と一致して読める観察候補。この構造は千川上水跡の代表町の分業構造（肴町系列・浅嘉町系列〔GAZ-149等〕）と並ぶ委譲類型の追加例。〕
