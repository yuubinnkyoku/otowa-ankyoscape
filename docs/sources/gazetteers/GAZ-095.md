# [GAZ-095] 望海毎談（大橋方長・1800自序） — 不忍池・三崎・三河島蠣売山・日暮里一入堀〔第170回登録〕

- **書誌〔確認〕**: 大橋方長『望海毎談』（寛政庚申〔1800〕自序・[book/991270](https://lab.ndl.go.jp/dl/book/991270) 燕石十種第3〔国書刊行会・1908〕収録の活字版・当該部分 pages 93-136。**頁136末尾「寛政庚申年大橋方長尺寸堂におゐて記之」で自序の年次を確認**）。**江戸往古図説（[GAZ-090](GAZ-090.md)・[GAZ-092](GAZ-092.md)）と同じ大橋方長の別作品**で、望海毎談はrepoに全く未収録だった（grep確認）。江戸周辺の入海・地形変遷の考証・伝承集。引用文言は活字版OCRで要原文照合。
- **不忍池・三崎地名条〔確認・文言候補・repo初出〕**: 「忍の岡武藏の國にて今の上野を忍の岡と云湯島天神の臺を向ふの岡と云谷中の方を入砂の岡と云**昔は芝浦の海の潮此所迄入來る入江の續にて斯三ツの岡の打續を以て谷中の岡に三崎と云地名有其中間に有る池の大さ十二萬坪有と云傳ふ**此池東は忍の岡の岸西南の方は向ふの岡の岸北東は入砂の岡の岸迄にて其頃は今の池の岸べりの民家通りの道もなしとなり此池を不忍の池と名付け」＝①**忍の岡（上野）・向ふの岡（湯島天神の臺）・入砂の岡（谷中側）の三岡連続の地形認識と「谷中の岡に三崎と云地名」＝三崎地名由来説**〔谷中三崎の地名（蛍川条〔[BOOK-158](../books/BOOK-158.md)〕・[GAZ-092](GAZ-092.md)谷中村条「三崎につゞき」・地蔵坂の橋二〔GAZ-093〕の「谷中三崎ノ谷戸川方」）の起原説明として、入江論の文脈で記す1800年の記録＝repo初出級〕＋②**不忍池の大さ「十二萬坪」の伝承＋三岡の岸までの池の範囲＋「芝浦の海の潮此所迄入來る入江の續」＝不忍池周辺の古入江説**〔千川（池・谷頭系の水系）下流部・谷中〜上野の地形史の対照点。12万坪（約40ha）という数値は伝承レベルで、現状の不忍池（約11ha）との関係は断定しない。OCR要照合〕。
- **三河島の蠣売山（牡蠣山）条〔確認・文言候補〕**: 「三河島より少々北手に**牡蠣山**あり二ヶ所ともに長サ三町程有て土手の如く當時よりみれば海手へは餘程遠き所なるに此所にていつの時代に蠣等の貝をむきて斯迄殼をむき溜しそ**船繫ぎ松など呼たる古木等を以て考れば其昔橋塲邊の方より此邊大船の類迄通る程の川もなかりつべし**其川谷中の方へも續くを以て入砂の岡と呼て其所迄砂の押入しと云傳ふ**惣じて谷中より三河島の末までも土地甚低くややもすると河水の揚るをみれば古來は入江にて川もなかりつべし**」＝**三河島の北の牡蠣山（蠣売山）2ヶ所（長さ3町程・土手の如く）と貝殻のむき溜め・橋場側から大船が通じるほどの川はなかった（＝入江）とする古入江説**＋**「谷中より三河島の末までも土地甚低く河水の揚る」観察に基づく入海論**〔[GAZ-092](GAZ-092.md)三河島村条「此邊いにしへ入海になりしと云蠣売山と云ありすべて此邊より尾久のわたりへかけて今も土中を深く堀るに蠣売多く出る也」＝同一著者の江戸往古図説側の記録と対校（望海毎談＝論述展開の詳しい側・江戸往古図説＝村条採録の側）。README既出の網干坂・氷川田圃の入江伝承（1910・1923年時点）と貝殻層記録（関口新町・和佳場の小図絵1798）に先行する江戸期の入江説の本文として対照点。谷端川・谷戸川下流域（谷中〜三河島〜尾久）の低地地形の記録。OCR要照合〕。
- **日暮里一入堀・静勝寺条〔確認・文言候補・要照合〕**: 「萬里山萬里居士…**日暮里一入堀と云所今の谷中の北なる山を呼て**春は花見とて野がけの遊山に人々の志ざす所なり其山の東の麓の村を日暮里村といふ」＋静勝寺（豐島郡岩淵領稻付村）条「**當所の後右山の手より十條邊入堀まで山續**にて此邊不殘道灌領分なり」＝**日暮里＝「一入堀と云所」（今の谷中の北なる山の呼称に付く）と、稻付村の静勝寺の裏山手から「十條邊入堀」まで山が続くという2条の「入堀」文言候補**〔「一入堀」が独立した地名（入堀）か「一入」＋「堀」の区切りかはOCRの区切りに注意を要し原画像照合が前提（repo初出候補・断定は保留）。「十條邊入堀」は十条付近の入堀の文言候補で、この地域の入堀系の呼称（READMEの入堀系の注意書きと対照）に加わる対校点〕。同条の日暮里側の「**船繫松とて古き大木此山の崖に有**」＝日暮里・谷中側の崖の船繫松〔[GAZ-092](GAZ-092.md)小石川村条の船繫松とは別地点の船繫松譚の候補で、同一の伝承の分布かは断定しない。船繫松＝入江時代の係船に擬する伝承の系統（望海毎談自身が牡蠣山条で「船繫ぎ松など呼たる古木等を以て考れば」入江を推論している）として対照点〕。
- **その他の対校記録〔確認・参考〕**: 大塚村条（豐島左衞門の東泉寺・鈴木兵部の神職・大塚村名由来）・石濱条（千葉左京太夫常政・石濱城の跡の金龍山聖天の宮所・眞土山と淺草砂利・淺草川の古名の考察〔隅田川・今渡川・角田川〕）・品川觀音堂条（日蓮の船着・道灌の塚と最明寺時賴の墓説の批判）・稻付の砦と道灌山異名の条（「道灌時代に總の上下國より武州を侵さんと寄來るを稻付の砦又此山にも味万の人數を貯置し處なれば是を道灌山と異名す」）＝日暮里・稲付・道灌系の伝承の周辺記事（水系との直接の関連は限定的で参考記録として整理）。
