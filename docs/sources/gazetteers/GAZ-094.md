# [GAZ-094] 東京市史稿 宗教篇第二 — 金剛寺（松橋弁天）条・雑司ヶ谷鬼子母神条・三河島観音寺条〔第170回登録〕

- **書誌〔確認〕**: 『東京市史稿』宗教篇第二（東京市政調査会・1936〔昭和11〕・NDL次世代デジタルライブラリー [book/1915639](https://lab.ndl.go.jp/dl/book/1915639)・全文OCR取得済み）。東京市史稿の宗教編のうち豊島郡・葛飾郡側の寺社条を収録。**repoの東京市史稿系既登録（[GAZ-008](GAZ-008.md)・[GAZ-016](GAZ-016.md)・[GAZ-017](GAZ-017.md)・[GAZ-053](GAZ-053.md)・[GAZ-055](GAZ-055.md)・[GAZ-056](GAZ-056.md)・[GAZ-061](GAZ-061.md)・[GAZ-072](GAZ-072.md)・[GOV-396](../gov/GOV-396.md)）に宗教篇は含まれておらず本資料が宗教篇の初登録**。引用文言は活字刊本のOCRで、江戸志・源平盛衰記・江戸紀聞・再校江戸砂子・東京近郊名所図会・武蔵古蹟志等の**二次引用**であることに注意。
- **金剛寺（松橋弁天・滝野川）条〔確認・文言候補・repo初出文言群〕**: ①**江戸志を引く金剛寺略縁起本文**: 「抑此山い弘法大師此處に來て、樹下よ坐し、不動尊像を彫刻し給ふ。石上ま安置も。此石を不動尊影向石と名付、今まあり。里人來て、水を以てあらひ服をれば諸病平癒きと。又傍の岩窟に像なり。松橋辨才天と名付く。弘法大師の作也。**古へは橋なり。北國より鎌倉への大道なり。今n跡のみ存た**。治承の比、源賴朝公石橋山合戰の後此處は來て、ふかく辨才天よ歸依し、太刀を奉納し給ふ。今ま有。舊記曰、武藏國豐嶋上瀧の河松橋といふ所ま陣を取、神馬を引、上矢を奉り給ふ云云」＋「**又此地を瀧の河と名付る事を、瀧なくして河の音四方はひゝくゆへなりと云々**」＝**松橋の地点が「古へは橋」で北国から鎌倉への大道が通り「今跡のみ存た（存ツ）」とする橋跡存続文言（repo初出）**＋**「瀧の河（瀧ノ川）」の村名由来の縁起本文候補（[GAZ-093](GAZ-093.md)滝野川村条の「緣起ニイヘリ」系統の元文言候補）**。②**源平盛衰記本文の長文直接引用**: 「江戸葛西は石橋みて佐殿を射奉りしこと恐れおもひけるに、此仰をかうふりて、よろこひをなして、在家をこほちて浮橋をよの常に渡しけり、軍兵是よりうち渡して、**武藏の國豐嶋郡の上瀧野川まつ橋と云所ま陣を取**、その勢をでま十萬餘騎…まづ當國六所大明神に御參詣なりて、神馬を引、上矢を奉られたり。參これ治承四年…十月」＝**源平盛衰記の本文表記「上瀧野川まつ橋」＋江戸側浮橋からの渡河→松橋の陣→王子（六所大明神）への神馬・上矢奉納という一連の経路と治承四年十月の年次**〔表記対立群への追加: 上瀧ノ川松橋〔風土記稿・GAZ-093〕／上瀧の河松橋〔江戸志引く旧記〕／上瀧野河松橋〔江戸紀聞〕／**上瀧野川まつ橋〔盛衰記本文〕**。OCR・活字校訂を経ており各表記の原字確認が前提〕。③**江戸志の批判的按語**: 「今按に、此舊記といへるは、いあなる書にや。いまだ見侍らぞ。たゞし源平盛衰記を見るに云…**是よよれば、松橋は陣を取給ひしと云り、さもなるべしれど、上矢を奉を給ひしn六所の明神なり。この辨才天へたてまつりしと云n、いかなる舊記にや、おぼつかなし**」＝**松橋陣所説は肯定しつつ、上矢奉納先を六所明神（王子）として金剛寺弁天への奉納を疑う江戸志編者の批判的按語**（引用された「舊記」は未見書である旨の明記あり。金剛寺側の縁起譚と考証書側の批判の対立構造として記録）。④**江戸紀聞**: 「松橋辨財天社。**王子權現の西の方三四丁**せあり。本尊は弘法大師の作1して、卽大師の勸請なり。**此地い石神井河の流よ臨ミ**、自然の山水あり。兩岸高く櫻楓の二樹枝を交へ…源平盛衰記よ、治承四年…十月、賴朝卿隅田河をうち渡り、武藏國豐嶋の上瀧野河松橋といふ處る陣をとるとあるい、**此地の事なり。賴朝奉納の太刀一振當社**」＝**松橋弁天社の位置を王子権現の西三四丁・石神井川の流れに臨む地とし、盛衰記の「上瀧野河松橋」＝当地と比定し、頼朝奉納の太刀一振を当社宝物とする記録**〔石神井川（王子川）の流れを臨む地点としての松橋の位置づけ＝[GAZ-093](GAZ-093.md)の石神井川系の文脈と対校できる。OCRに崩れがあり原字照合要〕。⑤**東京近郊名所図会**: 「迂曲して下れば崖下に洞窟あり。辨財天を安置き。松橋辨天是なり。**今は過半埋りて入る能むぞ。此處往古い海なりしかば、貝殻の存きる者多し。因て好古者の來りて土を穿ち之を求る者頻繁なるより、かく埋めたるなりといふ**」＋「洞中に文保三年…元應元年、紀三月と彫たる古碑一基あり。按るに文保三年は卽元應元年己未にして、今を距ること五百九十二年なり。獨り編者の見たきは此碑なり。而して洞日埋りて見るを得ぞ。惜ろな。**のち武藏古蹟志を檢せしに、此碑の圖を載せて、文保三己未年三□日とありて、長二尺四五寸、幅一尺。岩屋前瀧野川端に臥て有りと見ゆ。編者到りし時は見當らざりし**」＝**松橋弁天洞窟の過半埋没・滝野川側の貝殻出土と「往古い海なりし」入海説＋好古者の発掘による埋土説**〔README既出の関口新町の貝殻層（和佳場の小図絵）・望海毎談（[GAZ-095](GAZ-095.md)）の三河島〜尾久の蠣売山と対照できる貝殻・入江系譚の滝野川側記録〕＋**武蔵古蹟志掲載の文保3年古牌の図（長2尺4-5寸・幅1尺・「岩屋前瀧野川端に臥て有り」）と、東京近郊名所図会編者の実見不能の記録**〔[GAZ-093](GAZ-093.md)風土記稿の文保3年古牌と対校。古牌の実在の前後（風土記稿「洞中ニ彫タル古牌」vs 近郊名所図会「洞日埋りて見るを得ず」vs 武蔵古蹟志「川端に臥す」）の記録のずれは原典照合が前提〕。⑥武蔵通志「天文年間、或ハ看瀧ノ川○瀧野川區ノ金剛寺ヲ復興ス。寺ハ岩屋辨天眞言僧宥印…」＝天文年間宥印による金剛寺復興説（北條氏康への訴えによる真言宗復帰の縁起本文〔上記略縁起〕と対校）。
- **雑司ヶ谷鬼子母神条〔確認・文言候補・repo初出文言〕**: ①**再校江戸砂子の引用**: 「星跡〓水。護國寺と雜司谷の田の中一の茂松あり。里諺よ曰、**鬼子母神出現の所えと。弦まき川の流のしもそへ。夜あとみ此所ま星くさりけるを里人あやし〓其所を求るに鬼子母神の像あり。後ま日照坊今の所へうつすといふ**」＝**鬼子母神出現地を「弦まき川の流の下（しも）」の星降り跡とする再校江戸砂子本文の文言（repo初出）**〔清土掘出地説（[BOOK-144](../books/BOOK-144.md)遊歴雑記）・三角の井＝出現の所説（[GAZ-090](GAZ-090.md)）・星の清水／星跡の清水系譜（[GAZ-066](GAZ-066.md)・[GAZ-067](GAZ-067.md)・[GAZ-070](GAZ-070.md)）に加わる、**出現地を弦巻川の流下側に求める系統**として新たな対校点。再校江戸砂子自体はrepo未収録で、本条経由の二次引用であることに注意〕。②**天正6戊寅年の棟札本文**: 「むかし永祿の頃、此弦まき川の邊よな〓〓ひかりありしをあやしみけるに、同じ四年…の五月十六日、**山本丹右衞門**といへる農夫の耕しける田の鍋にかゝるものあり。取上見れば鬼子母神の銅像なりければ、是を**東陽坊**かたへ持行、菴主にあたへたり。東陽坊といふは今の**大行院**の昔の名なり。…その堀いだせし處に杭をたてゝしるしを殘し置しか、**天正六戊寅年**…鬼子母の像を今の地に移して、いさゝか經營を加へ置しに、寛文六丙午年松平安藝守の室聞傳へ、祈願の事ありてより、新に本社を造立」＝**永禄4年（1561）掘出→天正6年（1578）移祀→寛文6年（1666）本社造立の通時系列と山本丹右衞門・東陽坊（大行院）の人名の本文**〔[ORG-035](../org/ORG-035.md)豊島区公式HPの天正6年堂建立・寛文4年本殿建立（[GAZ-013](GAZ-013.md)巻52系）と対校できる縁起本文。寛文6年vs寛文4年の年次の対立はOCR・版本系統の確認が前提で断定しない〕。③〓土（清土）鬼子母神出現所条: 「武州豐島郡〓土鬼子母神出現所は、**本淨寺の南一町、弦まき川の緣にありて、方凡貳拾餘間。眞中に三角の井ありて、萱屋根にて雨覆したり。昔此處より堀出しけるとなん**」＝**出現所を本浄寺の南一町・弦巻川の縁・方20余間・三角の井の地点とする本文**〔[GAZ-090](GAZ-090.md)江戸往古図説の「此地ニ今三角ノ井ト云アリ此地鬼子母神出現ノ所ト云」＝三角の井＝出現の所説の系統に属する本文候補で、位置の具体化（本浄寺の南一町・方20余間）を含む。引用元書名の帰属はOCR崩壊ゾーンで要照合〕。④雑司ケ谷法明寺条（東叡山元三大師・威光山法明寺・塔頭東陽坊大行院の持・「六老僧の寺。東陽坊。法明寺地中」）＝東陽坊＝大行院＝法明寺塔頭の別当構造の記録。
- **三河島観音寺条〔確認・文言候補・参考〕**: 「三河島○荒川區三河島町四丁日…觀音寺(眞言)草天文年中僧長偏、三河島…開創ス」＝**三河島観音寺（真言宗・天文年中僧長偏の開創・荒川区三河島町四丁目）の記録**〔谷端川下流部の三河島の寺の建立譚。天文年中＝16世紀中葉。東京近郊名所図会由来の記述〕。
- **制限・未解決**: ①江戸志・源平盛衰記・江戸紀聞・再校江戸砂子・東京近郊名所図会・武蔵古蹟志・武蔵通志の各文言は東京市史稿経由の**二次引用**で、各原典の本文確認が前提。②OCRに崩れ多数（「今n跡のみ存た」「四方はひゝく」「いあなる書」等の n・〓・判読不能字・明治期の正字体の揺れ）。③「再校江戸砂子」自体のデジタル化の所在は未確認（repo未収録・次回の探索候補）。**〔2026-11-18第171回追記・解決〕**: 再校江戸砂子＝『江戸砂子温故名蹟誌』（沾凉纂緝・恒足軒再校・明和9年・NDL次世代DLに2系統×7冊＝計14冊で公開）と書誌同定した。星跡清水条の引用文言（「鬼子母神出現の所えと。弦まき川の流のしもそへ」）が本書巻之四の本文（2563640・OCR「と弦まき川の流のしも也」）と語順・「弦まき川」表記まで一致＝引用元の確定（[GAZ-027](GAZ-027.md)第171回追記参照・原画像照合で確定）。④源平盛衰記の諸本の本文異同（「上瀧野川まつ橋」の表記の確認）は未了。⑤金剛寺略縁起の「北國より鎌倉への大道」（鎌倉街道と松橋の関係）の検討は今後の課題（松橋＝大道の橋としての位置づけは本条だけでは断定しない）。
