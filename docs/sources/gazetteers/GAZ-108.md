# [GAZ-108] 御府内備考 巻53-55（牛込之一〜三・写本OCR）— 大下水総説の文言確定と揚場町条の大下水・船河原橋

- **書誌〔確認〕**: 『御府内備考』巻之五十三（牛込之一・総説/御殿山〜陣橋の屋鋪地名並里俗小名含む）・五十四（牛込之二・揚場町/牡丹屋鋪/市ヶ谷田町四町目代地…袋町・光照寺門前）・五十五（牛込之三・越中石寺門前〜御箪笥町・佐細工町等）の合冊写本。NDL lab [book/2553677](https://lab.ndl.go.jp/dl/book/2553677)。**引用文言はすべてくずし字OCR由来で原文画像との照合を要する。**
- **本登録の性格**: 市谷牛込間の大下水（蟹川系の市中側幹線）の沿革の核心部。東京市史稿経由（[GAZ-016](GAZ-016.md)）等で部分的に既知であった大下水の流路・呼称・石垣年代・船河原橋の帰属を町方書上レベルの原文で初めて直接確認した。

## 第212回の読取（2026-11-20）

- **牛込総説の大下水条〔文言候補・repo初出の総説原文〕（改撰江戸志引用）**: 「**大下水ハ市ケ谷田町より牛込揚場町を歴て舩河原橋脇にて江戸川に合す此下水の成し年代等詳ならされと寛永十八年堀千之助御手伝にて石垣を築しよし伝ふれは古き下水なる事論なし此下水の上流尾州表門より下を柳川と唱へそれより上を桃川の唱ふるよしよりて下流まてを通して紅葉川なと書しものありその実は無名の大下水なり（改選江戸志）**」＝**①大下水は市ケ谷田町から牛込揚場町を経て船河原橋脇で江戸川に合流、②成立年代は詳でないが寛永18年（1641）堀千之助（OCR・〔与〕之助候補との表記対立あり〔GAZ-108/110の両条で千之助／与之助が分かれる〕）の御手伝で石垣を築いた由の伝え＝「古き下水なる事論なし」、③上流の尾州（尾張様）表門から下を「柳川」、それより上を「桃川」(OCR・判読注意)と唱える由、④下流まで通して「紅葉川」などと書くものもあるが、その実は無名の大下水である（いずれも改撰江戸志引用）**。〔**市谷牛込大下水の流路（市ケ谷田町→牛込揚場町→船河原橋脇の江戸川合流）・石垣の寛永18年説・通称群（柳川・桃川〔OCR注意〕・紅葉川）を一文にまとめた総説の原文がrepo初出**。[GAZ-110](GAZ-110.md)田町条・[GAZ-110](GAZ-110.md)総説の諸文言と対校すると、①流路が両書で完全一致、②呼称（極川／堰川／紅葉川〔田町条〕と柳川／桃川／紅葉川〔総説〕）が上下区間別の並列構造、③石垣年代の寛永18丑年（1641）の合致が確認される。「柳川」「桃川」は『新編江戸志』系の用例と形が近く判読対立の可能性が高く要原画像照合。〕
- **紅葉堀の名義（左内坂名主の古帳・四谷御門＝紅葉御門説）〔文言候補・repo初出〕**: 「**紅葉堀の名は市谷左内坂の名主蒙分(?)の名主といふの家に蔵するふるき帳にも見へしといふ…四谷御門をそのかみ紅葉御門といひし…それらの名より…かくいひしにや（OCR）**」＝**「紅葉堀」の名は市谷左内坂の名主の家に蔵する古い帳にも見え、かつて四谷御門を「紅葉御門」と呼んだ（坂光淳?＝人名OCR）説に由来する旨の総説**。〔紅葉堀の名義論の新系統（人名・「蒙分」等の判読は要照合）。四谷御門＝紅葉御門説と大下水の紅葉川通称（上の総説）・紅葉堀（江戸川橋付近の堀・[GAZ-049](GAZ-049.md)系の「紅葉堀」語群）の関係の整理は原文照合後に検討する。〕
- **陣橋（止めき）〔文言候補・repo初出の橋名・改撰江戸志引用〕**: 「**（車）陣橋/（車）押橋ハ榎木町と早稲田との境にあり土人とゝめきといふ延宝の江戸図にもとゝめきの名みへたりわつゆ(?)なる橋なり（改撰江戸志）**」＝**陣橋（車陣橋・車押橋の判読対立候補あり・いずれもOCR）は榎町と早稲田の境にあり、土地の人が「止めき」と呼ぶ。延宝の江戸図にも「止めき」の名が見える。わずかなる（小さな）橋である（改撰江戸志引用）**。〔**榎町/早稲田境の橋「止めき」はrepo初出候補。早稲田側・榎町境＝蟹川（戸山落）系または原町・川田久保系の下水流路域に位置する橋候補で、どの水路に架かるかは本文からは特定できない（蟹川系の大久保村→戸山→早稲田/下戸塚流路〔[GAZ-109](GAZ-109.md)馬場下町条〕・原町の下水（中里村田甫経由）〔同書〕の両候補を対照する。延宝図の該当箇所の読図・「とゝめき」の原字（留木?止木?）は今後課題）**。〕
- **揚場町条の大下水・石橋・船河原橋〔文言候補・大下水の町方書上〕**: ①「**石橋長九尺幅壱丈壱尺三寸右は町内南之方横町御武家方境より軽坂上り口大下水ニ指有之石数七枚ニ而橋之字無御坐（中略）其後御武家方町方半ニ之入用ヲ以修復仕候**」＝**軽坂上り口の大下水に架かる石橋（長9尺・巾1丈1尺3寸・石7枚・橋銘なし・もと御入用場所で後に御武家方町方の半々の出費で修復）**（「軽坂」＝軽子坂〔OCR・[対照表](../../地名・河川名対照表.md)の重複候補〕）。②「**一鶴(?)右は町内東北之方御武家方脇小石川(?)辺江て往来江戸川落口ノ橋有之船河原橋与相唱候…尤町川持ニ者無御座水戸様御一手持ニ御座候**」＝**町内東北の江戸川落口の橋＝船河原橋（俗称の異説あり・判読「異澤且里路ニ先之橋」は要照合）は町の川持ではなく水戸様（水戸徳川家）の御一手持**。③「**大下水巾壱間右は南之方より北之方へ流牛込牡丹屋敷より御武家前通流来末者江戸川江落入申候処両側石垣石橋とも寛永年中堀与之助様御手伝ニ而出来仕当村家町之方は町内に而修復仕道附之方者町御奉行所（被相？）**」＝**大下水は巾1間・牛込牡丹屋敷から御武家前を通じて流れ来たり末は江戸川に落入、両側石垣・石橋とも寛永年中堀与之助様の御手伝いで出来、家町側は町内で修復し、道附きの方は町奉行所（扱い）**。〔**①大下水の幅1間と牛込牡丹屋敷経由の流路の町方書上、②船河原橋の帰属＝水戸様一手持（repo初出候補）、③石垣年代＝寛永年中＋人名＝堀与之助様＝巻53総説の「寛永十八年堀千之助」との表記対立〔千之助／与之助〕は府内備考内部で並記される**。船河原橋の水戸様一手持文言は[GAZ-107](GAZ-107.md)の神田川名義（船河原橋以下を神田川と呼ぶ）と併せて、江戸川と大下水の合流点が江戸市中の行政的にも目印になっていた構造を示す候補。②の「鶴」の前後の判読は原画像必須（「一鶴」は「一括り」等の誤読候補）。〕
- **揚場町の町名起立〔文言候補〕**: 「**神田川附ニ而山之手諸色運送之揚場ニ相成候ニ付町名揚場町と相唱**（OCR）」＝**神田川附（沿い）に山の手の諸色（物資）運送の揚場となったため町名を揚場町と唱える**＝町名と船運揚場の関系。ほかに尾州様御物揚場（享保11年拝借・OCR）の文言候補も見える（江戸川の舟運終点の一つの機能記録。判読は要照合）。
- **軽子坂・神楽坂の名義（江戸砂子・改撰江戸志引用）〔対校差分〕**: 軽子坂「**揚場より船につミ来りしものをもこふ種子(?)此坂こに多くつとひ…（改撰江戸志）**」＝揚場から船に積み込みに来る荷物の扱いに係る坂の語源説候補、神楽坂（市ヶ谷八幡宮の祭礼に神輿が御門の橋の上に暫く留まり神楽を奏する由〔江戸砂子〕・津久戸社伝承と穴八幡旅所説の対立）等、既登録の坂名語源群に牛込側本文の対校点を加える（抄録）。
