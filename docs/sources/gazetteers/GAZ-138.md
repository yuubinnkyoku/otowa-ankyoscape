# [GAZ-138] 町方書上[152] 小梅 — 瓦町条の源森川・横川入堀と小梅古上水（白堀上水）の実務文言

- **書誌〔確認〕**: 『町方書上[152] 小梅町方書上』（写・NDL次世代デジタルライブラリー [book/2571633](https://lab.ndl.go.jp/dl/book/2571633)・53コマ）。**小梅瓦町条＝p5〜（条頭「地徳御調書上 小梅瓦町」p5）〜末尾（p53: 「以上 文政十一子年十一月 右町名主九兵衛」の起文＝文政11年〔1828〕11月提出）**。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571633_{NNNNNNN}.txt` コマ番号。**
- **源森川・東源森川・横川入堀の里俗名群〔文言候補・repo初出候補の川名群〕（p11-12）**: 「**右は源森川続ニ而 年暦不取知一切出来候 後 東之方は 東源森川 或ハ 横川入堀 共ニ申唱候処 近来入切(=埋切候補)ゟ 東北(?)□川ト唱申候 西之方は 源森川ト唱申候**」＝**①（当町の裏に当たる堀は）源森川の続きで、年暦は知り得ない、②後には東の方は「東源森川」または「横川入堀」と申し唱えたが、近来埋め切り、（今は）東北□川と唱え、西の方は「源森川」と唱える**。〔**①「源森川」「東源森川」「横川入堀」の3称呼の里俗名群＝[GAZ-093](GAZ-093.md)（風土記稿・横川への合流樋）・[BOOK-157](../books/BOOK-157.md)（武江年表の白堀上水・業平橋筋）系の横川水系の呼称群の町方レベルの初出候補、「埋切」の原字は要照合、②同町の火之見組仲間町リストに「**中之郷横川町**」が実在する（p23）＝横川系の川名に対応する町名（南本所横川町）の同一文書内の対応も記録**〕。
- **小梅古上水（=本所の白堀上水）の町方側witness〔文言候補・本冊の核心1〕（p12）**: 「**土(=小?)上水 川巾五間 右古上水ハ 万治寛文之頃 崎玉郡八條領 瓦曽根溜井 ヲ堀通シ(=分水ニ相成候補・要照合) 亀有村ゟ当領え入 上千葉 宝木塚 篠原 四ツ木 渋江 木之下 大畑 寺嶋 須崎 受地 右村々流通シ 小梅村ニ至リ 法恩寺橋辺迄 以前堀通シ有之由 享保七年九月 右上水相止候由 其後ハ村方用水ニ相用申候**」＝**①古上水の川巾5間、②万治寛文の頃・埼玉郡八條領瓦曽根溜井からの分水、③亀有村から当領に入り上千葉・宝木塚・篠原・四ツ木・渋江・木之下・大畑・寺嶋・須崎・受地の村々を流通し小梅村に至る、④法恩寺橋辺まで以前は堀が通っていた由、⑤享保7年（1722）9月に上水が相止めになった由、⑥その後は村方用水に相用いた**。〔**①「川巾五間」＝[GAZ-093](GAZ-093.md)（風土記稿・「堀幅二間許一名小梅古上水又白堀上水トモ云」）の堀幅二間許との巾の対立＝照合案件（両文言とも原画像照合まで数値の優劣は決めない）、②「享保七年九月」＝風土記稿「享保七年」に月を補う文言＝[GOV-170](../gov/GOV-170.md)（享保撰要類集・享保7年8-9月・青山三田本所上水と共なる差止御書付）の「九月」側と整合する町方側の月次witness、③受益村リストの「大畑」「須崎」＝風土記稿の列挙（上千葉・寶木塚・篠原・四ツ木・澁江・木ノ下・寺島・請地）にない村名の追加候補（照合前提）、④「瓦曽根溜井」＝風土記稿「瓦言根溜井」の判読対立の解消候補（「瓦曽根」優位）**〕。
- **享保17年9月の上水堀埋立跡の検地・高入転用〔文言候補・repo初出級の実務記録〕（p12）**: 「**但 小梅村入柱(=入村?柱?・判読候補・要照合) ヲ先(=西?東?・要照合) 業平橋南之方 小梅橋(=小梅の橋?字?・要照合) 反別八反四畝弐拾歩場所 上水堀埋立跡之由ニ而 享保十七子年九月 筧播磨守様 御検地 御高入ニ相成 小梅村百姓住居仕 百姓商売家作場所之積(=積リ)**」＝**小梅村内・業平橋の南の方の反別8町4段20歩の場所が「上水堀埋立跡」であり、享保17子年（1732）9月の筧播磨守様御検地で御高入となり、小梅村百姓の住居・商売家作の場所の積り（になった）**。〔**①享保7年9月の上水差止→享保17年9月の堀跡地検地・高入・宅地化の実務チェーンの一次記録＝白堀上水（小梅古上水）の廃止後の土地処分の具体例（repo初出級・「筧播磨守」の人物比定は保留・原字照合前提）、②「業平橋」＝[BOOK-157](../books/BOOK-157.md)（白堀上水の業平橋筋）・[GAZ-093](GAZ-093.md)（業平橋東以南の埋立・横川への樋設置）の位置アンカーと対応、③検地対象の範囲（「小梅村入柱ゟ先...」の読み＝境界標から数える表現候補）は原字照合まで解釈を確定しない**〕。
- **寛文年中の堀割と町の代地移転〔文言候補・repo初出級〕（p43）**: 「**当町古ハ 武州高師(=豊島?・OCR候補)郡 小梅村本高(=本郷?・要照合)内ニ而 町方起立相分リ...只今之源森川辺ニ而 百姓商売屋 取建罷在候処** 寛文年中所川(=小川/横川?・判読候補・要照合) 御堀割之砌リ 御用地ニ被召上 当時之場所ニ而 代地被下置候由申**」＝**当町（小梅瓦町）は古くは小梅村の中の町方起立・源森川辺に百姓商売屋を建てていたが、寛文年中の堀割（「所川御堀割」＝判読候補）の砌に御用地へ召し上げられ、当時の場所（現小梅瓦町）を代地として下げ置かれた由**。〔**①寛文年中の堀割（=小梅古上水〔万治寛文作立説・GAZ-093〕か横川堀割か）に伴う旧町地の収用・代地移転の実務記録＝万治寛文頃作立説（風土記稿の編者考証）と整合する町方側の年代文言、②「堀割」の対象水路の同定は本文言からは断定しない（源森川辺にある旧地が上水堀か横川系堀かの判別は位置照合が前提）**〕。
- **寛政2年正月22日の類焼と自身番屋の移転（p23）**: 「**寛政二戌年迄 町内中通り中程角ニ有之候処 同年正月廿二日類焼 富シ 其後右店借リ請申候**」＝寛政2年（1790）正月22日の類焼（焼失）までは自身番屋が町内中通中程の角にあった（その後移転）＝当町の被災史の一次文言（文政期の現況書上）。〔小梅瓦町=南本所元瓦町との合併町名経緯も同書上に見える（「南本所元瓦町最合」p11）。火災史は[BOOK系]対校課題。〕

## 制限・未解決

- ①「土(=小?)上水」の見出し原字（「一 小梅上水」等か・行頭崩れ）、「入柱ヲ先」「所川」「高師郡本高内」の判読候補はすべて原画像照合前提。②「川巾五間」vs「堀幅二間許」（[GAZ-093](GAZ-093.md)）の巾の対立の決着＝原画像照合（用語の違い〔幅・巾〕・測定箇所の違い〔全域最大幅か平均か〕の可能性も含め保留）。③「大畑」「須崎」村の位置（八條領側か足立郡側か）は独立資料での確認が必要。④「筧播磨守」の人物比定は行わない（原字照合前提・享保17年の関東検地の担当と結びつけるかは保留）。⑤「埋切」「東北□川」の原字は要照合（埋切後の呼称が何かは本冊の文言では欠損）。⑥寛文年中堀割の対象水路（小梅古上水か横川系か）の同定は未解決。
