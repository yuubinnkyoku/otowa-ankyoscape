# [GAZ-068] 東京府地誌略（東京府学務課・1881）— 承応年間設置説の府編纂版と神田上水の明治14年現勢記録〔第145回〕

- **書誌〔確認〕**: 東京府学務課編『東京府地誌略』（巻之上・下・1881〔明治14〕・請求記号291.36-To456t-(t2)・書誌ID000000892173）。NDL次世代デジタルライブラリー [book/991444](https://lab.ndl.go.jp/dl/book/991444)。**本書はOCRが高度に乱れており、引用文言はすべて原画像照合を要する**（例: 「玉川・神田」が「王川・神由」、「小石川」が「小右川」、「萬年樋」が「萬年第」、「城内」が「邨内」等）。
- **両上水の承応年間設置説〔確認・文言候補〕**: 総論部に「**往時府下ノ井水、大抵汚濁ヲ帶ビ飲ニ堪ヘズ、是ニ於テ承應年間始メテ玉川神田ノ両上水ヲ設ク**」（OCR崩れ補正前: 「王川神由ノ両上水ヲ設ク」）＝**①両上水の設置を「承応年間」（1652〜55）とする1881年の府編纂地誌の記述**。〔御府内備考の白堀「承應二年ノ頃堀割」説（[GAZ-049](GAZ-049.md)⑬）・武江年表系（[BOOK-157](../books/BOOK-157.md)）・明治10年府統計系の承応説に対し、**府（東京府学務課）自身が1881年に承応年間説を採用した公式版のdatapoint**。ただし本文は「玉川神田ノ両上水」を一括して承応年間とする表現で、**神田上水単独への適用かは原画像照合まで断定しない**（玉川上水の承応2年〔1653〕と一括した表現の可能性）〕
- **神田上水の1881年現勢流路＝十二所社下の支流合流・上落合村の井草川合流〔確認・文言候補・repo初出級〕**: 「**神田上水ハ、井頭池ヨリ發シ、北流シテ十二所社ノ下ニ至リ、玉川上水ノ支流ヲ合セ、上落合村ニ至リテ、又井草川ヲ合セ、小石川砲兵本廠ニ至リ、伏管之ヲ受ケテ、御茶ノ水ニ至リ、神田川ニ架スル萬年樋ヲ經テ城内ニ入リ、縦横散布シテ京橋以北戸々ノ飲用ニ供ス**」（「合七」＝合セ・「邨内」＝城内等のOCR崩れ補正済み）＝**①井頭池に発し北流、②十二所社の下で玉川上水の支流（＝千川用水/千川上水と読める水路）を合せ、③上落合村で井草川を合せ、④小石川の砲兵本廠で伏管を受け、⑤御茶ノ水から神田川に架す萬年樋を経て城内に入り、京橋以北の戸々の飲用に供する**という1881年時点の現勢記述。〔**②の「十二所社ノ下」＝千川用水の神田上水合流地点を社（十二所社）の下まで特定した文言候補はrepo初出級**。明治10年東京府統計の「仙川用水…上落合村ニテ神田上水ニ合ス」（[GOV-302](../gov/GOV-302.md)）と整合しつつ、合流位置を一段上流側に具体化する。同書の角筈村条に「**角筈村油(溜)ハ二アリ、一ヲ上ノ溜井ト曰ヒ、一ヲ下ノ溜井ト曰フ、世ニ十二所ノ池ト稱スル者是ナリ**」があり、「十二所社・十二所の池」＝幡ヶ谷・初台側（角筈村）の池・社と読める。④の給水現役記述は神田上水廃止（明治33/34年説）より前の定点〕
- **善福寺池の流＝井草川の文言〔確認・文言候補〕**: 「**善福寺池アリ、其流井草川トナリ、神田上水ニ合ス**」＝**善福寺池の流れが「井草川」となり神田上水に合することを、池→川→合流の連続記述で記す1881年文言**。〔**井草川＝善福寺池の流下の別称という系統の文言は[GAZ-051](GAZ-051.md)（豊多摩郡誌1916・「井草川」＝千川用水の井荻村区間の呼称）との対立候補**（同一の「井草川」を①善福寺池流下の自然水系の別称〔本書〕とするか、②千川用水の区間呼称〔郡誌〕とするか。上欄の現勢流路は井草川合流を上落合村で記すため、本書内では千川用水（支流）と井草川を別水路として併記している点に注意。断定しない）〕
- **小石川区条＝関口二派の現勢と旧水戸邸・後楽園〔確認・文言候補〕**: 「**神田上水ハ、西ヨリ来リ、関口ニ至リテ二派ト爲ル、一ハ小日向水道町ヲ過ギ、砲兵本廠内ヲ歴テ伏管ニ通シ、一ハ江戸川町ヲ過ギ神田川ニ入ル、卽チ江戸川是レナリ**」＝1881年時点の関口分派の現勢文言＋「**砲兵本廠ハ…此地舊時水戸藩邸ニテ、源光國（徳川光圀）創造スル所ノ後樂園今猶存セリ**」＝旧水戸邸（後の砲兵本廠）と後楽園の現存観察。〔関口二派の構造（伏管ルート＋江戸川ルート）の明治14年現勢＝[GAZ-065](GAZ-065.md)（1907・後樂園水道の旧に仍る）に先行する定点。千川上水の城内給水（水戸邸経由）の廃止後も白堀・伏管ルートが現役だった観察〕
- **本郷区条＝萬年樋と御茶ノ水の位置関係〔確認・文言候補〕**: 「**神田上水ハ、砲兵本廠内ノ伏管ヲ歴テ、此區ニ注キ、水道橋ノ下ニ於テ神田川ニ架セル萬年樋ヲ通シ、始メニ城内ニ入ル、其下流ノ東岸ヲ御茶ノ水ト曰フ**」＝**水道橋の下・神田川に架す萬年樋を通じて城内に入る流路と、その下流東岸＝御茶ノ水の位置関係を区誌レベルで明記した1881年文言**。〔「萬年樋」の固有名称の明治14年用例＝[GOV-231](../gov/GOV-231.md)（樋語彙）・町方書上の万年樋（[GAZ-035](GAZ-035.md)）・[GAZ-048](GAZ-048.md)（風土記稿の石樋）系の対校資料。御茶ノ水の呼称範囲（下流の東岸）の定義文言としても有用〕
- **江戸川・神田川条〔確認・文言候補〕**: 「**江戸川ハ、神田上水ノ支流ニシテ、関口町ニ於テ上水ト分レ、小日向ヲ経テ牛込小石川ノ間ニ東シ、船河原橋ノ南ニ至テ神田川ニ入ル**」＋「**神田川ハ、城北ノ外濠ニシテ、江戸川ノ末流ヲ合セ、外神田ヲ經テ(常磐?)橋ノ東ニ至リ、淺草川ニ入ル**」＝**江戸川＝神田上水の支流（関口町分派〜船河原橋南の神田川合流）という上下関係の1881年記述**と、神田川を「城北の外濠」とする表現。〔江戸川＝神田上水の支流という関係規定は明治10年府統計系と同型。神田川＝城北の外濠という表現はOCR乱れを含み要照合〕
- **鼠山＝1881年の土地利用観察〔確認・文言候補〕**: 「**鼠山ハ長崎村ナル小丘ニシテ、德川幕府ノ時練兵ノ地タリ、今變シテ田圃ト爲ル**」＝**鼠山（長崎村の小丘）が幕府時代は練兵の地で、1881年時点では田圃に変わったという観察**。〔[GAZ-022](GAZ-022.md)（風土記稿・長崎村の粟島神社・弁天池）・千川上水の鼠山収公説（享保12年の練兵地化）の後年側の土地利用の定点。鼠山の練兵地→田圃という変遷の1881年観察文言〕
- **溜池＝両上水の止水の設〔文言候補・OCR高度乱れ〕**: 「**溜池ハ赤阪門外ヨリ虎門ニ環ルル湟堂(堀?)ナリ、昔時ハ一大池ニシテ、末タ神田玉川止水ノ設アリ、其時、此水ヲ引キ飮料ニ供スト云フ**」＝溜池がかつて一大池で、神田・玉川の止水の設があり、その水を飲料に供したと伝える文言候補（「止水」の前後はOCRが激しく乱れており、「上水」「溜」等の補正可能性を残す）。〔溜池の水道史的側面（両上水系の溜め）を記す稀少な文言候補。断定せず要原文照合〕

## 制限・未解決

- ①**本書のOCRは高度に乱れており、すべての引用文言は原画像照合を要する**（本fileの引用は崩れ補正を施した上で「文言候補」として扱う）。特に溜池条の「止水ノ設」・神田川条の「城北ノ外濠」・十二所社の読みは補正の余地が大きい。②「承應年間」設置説は両上水一括の表現で、**神田上水単独の設置年代への適用は原画像照合まで断定しない**。③「十二所社」の比定（角筈村の十二所の池付近の社か・猿楽塚側か）は本書のみでは確定しない（「十二所社ノ下」という到達点の記録として扱う）。④井草川の帰属（善福寺池流下の自然川vs千川用水の区間呼称）は[GAZ-051](GAZ-051.md)との対立のまま確定しない。⑤千川・仙川・谷端・水窪・弦巻の語は本書fulltext検索で陰性（1881年府地誌の記載粒度の限界の記録）。
