# [GAZ-127] 町方書上[88] 浅草町方書上壱之下 — 浅草側の埋樋枡・井戸文言と鳥越村領名の異読群

- **書誌〔確認〕**: 『町方書上[88] 浅草町方書上　壱之下』（写・NDL次世代デジタルライブラリー [book/2571569](https://lab.ndl.go.jp/dl/book/2571569)・118コマ）。各条の廻年月は文政八酉年（1825）10月が中心。**引用文言はすべてOCR由来で要原文照合。ページ番号は `2571569_{NNNNNNN}.txt` コマ番号。**
- **浅草茅町弐丁目条＝埋樋枡〔文言候補・浅草側で井戸以外の桝文言〕**: 「**千川上相跡（＝千川上水跡の崩れ候補）此上水先年町内江相懸り往還中程埋樋枡有之候処天明七丁未年四月十二日御座止二相成候ニ付埋潰御生申傳候**」（p37）＝〔**条帰属＝署名p37の浅草茅町弐丁目条（名主利左衛門）。浅草側の町条でも井戸だけではなく「往還中程の埋樋枡」があった文言**＝浅草茅町2丁目の町方側レコード〔同条に宿之木の「ふしの井戸」伝承の付記（明和8辛卯年出火焼失の lore・千川上水との関係は本条では述べない）〕。「天明七丁未年」の「丁未」表記は干支崩れ候補（天明7＝未年）〕。
- **浅草旅籠町壱丁目代地条＝井戸2ヶ所＋別紙絵図面〔文言候補・GAZ-115の原本側〕**: 「**一古千川上水井戸弐ケ所有之候処天明七同年四月十二日御差留メ之事但其節埋立ニ相成申候右之外此度御調之ケ条無御座候間別紙絵図面を以奉申上候 以上文政八酉年十月浅草旅籠町壱丁目代地名主（名）古利左衛門**」（p64）＝〔**[GAZ-115](GAZ-115.md)（御府内備考浅草巻の旅籠町壱丁目井戸2ヶ所文言）の町方書上原本側の文言＋①差止日＝「四月十二日」＝4月12日系（[GAZ-125](GAZ-125.md) 久右衛門町条と同じ。神田仲町側の13日系〔[GAZ-041](GAZ-041.md)〕・湯島側の「四月中」との対立群への追加）、②「別紙絵図面ヲ以奉申上候」＝井戸2ヶ所の位置を絵図面で別途提出した旨の文言＝旅籠町壱丁目代地の井戸位置図（所在不明）の存在記録**〕。
- **浅草旅籠町弐丁目代地条＝井戸1ヶ所〔文言候補・GAZ-115未確認分の解消〕**: 「**一古千川上水井戸壱ヶ所有之候処天明七未年四月十二日御差留め之事**」（p69）＝〔**条帰属＝署名p70の浅草旅籠町弐丁目代地条（名主庄左衛門）。旅籠町弐丁目の井戸1ヶ所は [GAZ-115](GAZ-115.md) では御府内備考写本側で確認できなかった文言だが、原本側の町方書上で「井戸壱ヶ所」が確認できる**＝GAZ-115の未解決点の解消候補〕〔同条見出し部分に由緒「往古武州豊島郡之内**咬田領**鳥越村之由」（p67）＝後掲の領名異読群の一環〕。
- **帰属未確定条（旅籠町三丁目代地周辺）＝井戸なし＋鳥越村領名〔文言候補〕**: 「**先年千川上水相掛り候得共井戸壱ヶ所も無御座候 一武蔵国豊島郡挟目領鳥越村江申伝候**」（p75）＝〔**署名は「以上酉十月名主利左衛門」（町名の記載なし・条内の隣町列挙＝東＝旅籠町三丁目代地・南＝帯町壱丁目・西＝茅町弐丁目・北＝瓦町続（橋?）町より条帰属は要照合）。**上水は相掛ったが井戸は1ヶ所もない**＝上水が通行していても井戸給水がなかった町の陰性例**。「挟目領」も領名異読群の一環〕。
- **浅草瓦町条（GAZ-115尾町条との帰属対立）＝差止文言と伊勢屋由緒〔文言候補〕**: 「**千川上水天明七未年四月十二日御差止に付埋立申候由但始り年月有所共相知不申候**」（p88）＋同条の「**草分札差町人伊勢屋四郎左衛門事凡百八拾年程以前ゟ住居罷在…往古武州豊嶋郡建田領鳥越村之由申伝候**」（p86）・「**当町小相橋拝見罷出申候**」・「**町内西之方横町を小玉屋横町より申候**」等＋「**大下水差江…巾三尺**」（p88）＝〔**条帰属＝署名p89のOCR「浅草瓦町」条。ただし同条の伊勢屋四郎左衛門・小玉屋横町は [GAZ-115](GAZ-115.md)（御府内備考浅草巻）の「尾町条」の文言と近似するため、「瓦町／尾町」の署名の原字と条の実体帰属は原画像照合まで確定しない（OCR対立として記録）。千川上水文言は「差止に付埋立申候由**但始り年月有所共相知不申候**」＝差止の伝聞形式（「由」）で年次不詳の並記**。石川・小玉屋横町稲荷・巾3尺の大下水差も同条の位置アンカー〕。
- **鳥越村の領名の異読群〔観察・OCR対立の原字確定課題〕**: 本冊と [GAZ-115](GAZ-115.md) で**「◯◯領鳥越村」の領名が5種の読みで揺れる**: 「**速田領**」（[GAZ-115](GAZ-115.md)・御府内備考側）、「**坂田領**」（本冊p62・旅籠町壱丁目代地条見出し）、「**咬田領**」（本冊p67・旅籠町弐丁目代地条見出し）、「**挟目領**」（本冊p75）、「**建田領**」（本冊p86）。〔**官撰側も写本側も同じ語のOCR崩壊が疑わしく、原字（渋谷領候補の検討も含む）は原画像照合の共有課題。なお茅町壱丁目条は「武州豊嶋郡鳥越村桑原之里と唱候由」（p18）と領名なしで「桑原之里」の字名で伝える**＝鳥越村内部の字・里名の別記録（原字照合で対照する）**。浅草諸町の鳥越村起源説の広がりを町方書上の起立章で並べて読める**のが本冊の価値〕。

## 制限・未解決

- ①「御座止」「埋潰御生」等の崩れ字、「速田・坂田・咬田・挟目・建田領」の領名原字、「瓦町／尾町」の署名原字、条帰属未確定のp75条（署名の町名記載なし）はすべて原画像照合が前提。②「天明七丁未年」の「丁未」も干支崩れの候補。③旅籠町壱丁目代地の「別紙絵図面」の所在（都立中央図書館・内閣庫等の絵図面コレクション内検索）は未実施。④「井戸壱ヶ所も無御座候」条は上水経路と井戸給水の非同時性を示す文言候補だが、経路（樋か桝か）への言及なし、構造判断をしない。⑤浅草側の樋・桝文言（茅町2丁目の埋樋枡）と井戸文言（旅籠町側）の分布の非対称性の解釈は今後の対照課題。
