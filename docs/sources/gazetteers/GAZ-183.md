# [GAZ-183] 町方書上[21] 三田弐之口（文政11子）— 古川→新堀川呼称変遷の元資料側文言群・三田用水文政11年現役用例

- **書誌〔確認〕**: 『[21] 三田弐之口』（写・NDL次世代デジタルライブラリー [book/2571502](https://lab.ndl.go.jp/dl/book/2571502)。NDL目録volume表記「[21] 三田式之口〔弐〕」。収録は三田古川町（見出しp38・署名p47文政11子年4月・名主三太）・麻布古川町（p53-58）・久保三田町（p28-30）・三田老増町（p80-86）・豊岡町（p59-79）・三田北代地・南代地・麻布龍土町代地（p49・元禄12卯年4月伊奈半左衛門支配の龍土町御道広替地文言）・久保町。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571502_{NNNNNNN}.txt`）。〔第230回の見送り判定（水系文言薄と疑われた）は誤りであった。訂正記録。〕
- **三田古川町条の町名起原＝古川→新堀川呼称変遷文言〔文言候補・本冊最重要〕（p38-47）**: 「**延宝年中まで右場所に小さき川有之 川上と申も無之 渋谷ゟ麻布十番赤羽橋将監橋え相掛 水下は金杉川え相流…古き川を町銘に致三田古川町**」＋「**元禄十一寅年中白銀御殿御普請…将監橋ゟ渋谷迄右川筋通船ニ相成候様 川幅壱間余御堀広ヶ有之 其節ゟ右 新堀川ト相唱え申候**」＝**①江戸前期の「小さき川」＝古川の存在と金杉川への流下、②元禄11寅年（1698）の白銀御殿御普請を契機とする「通船相成」の川幅拡張、③拡張以後の「新堀川」呼称への転換、の3点を一つの町名由縁で語る一次文言候補（repo初出。古川→新堀川の呼称変遷を町方書上本文の側から直接に記す）**。〔[GAZ-103](GAZ-103.md)渋谷川総説・[GAZ-106](GAZ-106.md)麻布新堀総説（延宝3舟入・元禄11-12堀普請・飢民救済説）・[GOV-410](../gov/GOV-410.md)（元禄12卯年頃の堀広）・[GAZ-159](GAZ-159.md)（寛文8新規川普請→延宝3→元禄11の三段階説）の年代論に、**延宝「古川」実在・元禄11通船川幅広げの白銀御殿契機説**という新たな枝を加える対校材料。寛文8年新規普請説（GAZ-159）・白金御殿造営時改水流説（GAZ-106）との全面的な対立は本文言だけでは決着しない。〕
- **大雨湛水記録文言候補（p44-45）**: 「**大雨之節は一円水場に相成…川際迄凡間数拾間余も湛地ニ相成候 異変之節は町内に而取計来候**」＝**新堀川沿い低地町（三田古川町）の大雨湛水と町内取計の実務文言候補**。〔横川・十間川沿いの湛水文言（[GAZ-165]系）と同じ型の市街地水害記録で、古川低地の立地（旧河谷）を裏付ける材料。〕
- **肥後殿橋＝三之橋の橋名文言〔文言候補・repo初出〕（p44-45）**: 「一橋〔堰?長十二間・判読不良〕＝松平肥後守様屋敷脇＝里俗「**肥後殿橋**」＝「**三之橋**」ト唱・細川越中守様御一手持・新堀川江懸ケ渡」＝**同一橋の里俗名（肥後殿橋）と通称（三之橋）のpair文言**。〔[GAZ-180](GAZ-180.md)金杉川全流路の橋列（相模橋・肥後橋・一之橋・二之橋・中之橋…）の「肥後橋」「二之橋」との対応が橋名の形式（◯之橋の序列名）で読めるが、本条の「肥後殿橋」＝肥後橋と同一橋かは断定しない（[橋名調査](../../四河川の橋名・橋跡調査.md)第236回追補で対校表を掲げる）。〕
- **麻布古川町条の「細流ハ古来古川」＝元禄12御堀割文言〔文言候補〕（p53-58）**: 代地の由縁「**元禄十一寅年同所白銀御殿御用地二被召上 代地トシテ三田村之内 細流有之候近辺ニ而被下置**」＋「**細流ハ古来 古川ト相唱候哉 元禄十二卯年御堀割ニ相成候ツゝ 新堀ト相唱候得共 其以前之川名ヲ取元 麻布之引地二有之候二付 則 麻布古川町ト相唱**」＝**元禄11年（召上げ）→元禄12年（御堀割）の1年差で堀割を記す一次文言候補**＝三田古川町条（元禄11通船川幅広げ）との**記年対立（堀割の実施年を元禄11に置くか12に置くか）を文書レベルで両論併記できる材料**。〔寛文8申年（1668）新堀川普請＝[GAZ-159](GAZ-159.md)赤羽新堀川三段階説の第一段との対立関係も維持する（寛文8を当事者の記憶に遡る普請・元禄11/12を白銀御殿に伴う再普請と調停する仮説は可能だが断定しない）。古川＝新堀の新旧川名の付けかた「其以前之川名ヲ取元」は川名の継承の思考形式の記録としても価値（repo初出文言の系列）。〕
- **久保三田町条の新堀川流路規定と二之橋〔文言候補〕（p28-30）**: 「**新堀川…南渋谷辺ゟ北芝金杉辺迄相流 委細之儀は同所古川町ゟ申上候**」＝流路の全体規定（南は渋谷辺・北は芝金杉辺）＋**流路の詳述を三田古川町条に委譲する「代表町」構造**＋橋「**二之橋**」（幅弐間三尺・長拾弐間・松平千代丸様一手持・新堀川に架かる）＝**[GAZ-180]橋列の「二之橋」との地名対照の材料（同一橋か断定しない）**。
- **三田老増町条の「三田用水之末」→芝新堀文言〔文言候補・本冊最重要〕（p80-86）**: 「**大下水 右は 三田用水之末ニ而 同所続麻布谷町代地脇并町内裏通ゟ 芝新堀引え相流申候**」＋上水差止の定型文言（享保7年10月中相止型）＝**①三田用水の文政11年（1828）時点の現役用例（「用水之末」として生きている大下水の水源への言及）、②その流末＝芝新堀への流入文言**。〔[GAZ-157](GAZ-157.md)（寛文4年代田村分水・享保7差止）・[GAZ-158](GAZ-158.md)（元禄11白銀御殿枝線・全流路列記）・[GAZ-179](GAZ-179.md)（白金台町・猿町の三田用水埋樋2基・用水懸ヶ村々文言）との対校で、**享保7年の上水差止後も「三田用水」の呼称が文政期の下水・用水実務で使われ続けていたことの町方側witness（repo初出）**。差止＝用水の全廃ではなかったとする理解を強める材料だが、当条文言の「三田用水」が三田上水の枝線系（白金御殿系）の残存流用かは本文だけでは断定しない。〕
