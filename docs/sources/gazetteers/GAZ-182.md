# [GAZ-182] 町方書上[11] 牛込七之口（文政9戌）— 釣之橋文言の元資料側witness・浄泉寺谷・上稲橋/下稲橋

- **書誌〔確認〕**: 『[11] 牛込七之口』（写・NDL次世代デジタルライブラリー [book/2571492](https://lab.ndl.go.jp/dl/book/2571492)。NDL目録volume表記「[11] 牛込七之口」）。収録は牛込馬場下町（見出しp70・名主助之進・署名文政9戌年5月）・馬場下横町（p50-57・済松寺領）・早稲田町（p58-69・名主太郎兵衛）・若松町・弐拾人町・浄泉寺門前・供養塚町・来迎寺門前・西方寺門前・誓閑寺門前・正覚寺門前・放生寺門前。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571492_{NNNNNNN}.txt`）。〔第230回掃引では「boilerplateのみ」と記録したが、本回の通読でこの判定は誤りだったことが判明（判読の進んだp50-76の水系文言を拾い落としていた）。訂正記録としてここに残す。〕
- **穴八幡前石橋「釣之橋」文言〔文言候補・本冊最重要〕（p70-76 牛込馬場下町条）**: 「**穴八幡前石橋 釣之橋ト相唱**」（判読候補・「釣」の字は原画像照合前提）＋水路文言「**水り元大久保村下水 尾州様戸山御屋敷内 仙水〔泉水判読候補〕江流込 右御屋敷ゟ流出 末ハ早稲田村下 江戸塚村〔下戸塚村判読候補〕用水ニ可相成候哉 江戸川江流落**」＝**御府内備考写本（[GAZ-109](GAZ-109.md)）の穴八幡前「駒之橋」との判読対立の元資料側（町方書上原本側）witness**。〔①同じ場所の橋名について御府内備考本冊が「釣之橋」・写本が「駒之橋」と二つの読みが併存する＝**判読対立（同一橋の両読み候補か、別橋かも含めて断定しない・原画像照合で解決する課題）**、②大久保村下水→戸山御屋敷「仙水」流入→流出→早稲田村・下戸塚村用水→江戸川という蟹川系（[対照表](../../地名・河川名対照表.md)一本橋川・戸山落行参照）の流路文言が元資料側でも裏付けられた、の2点。書き上げ人の家臣リスト・「水銭204文」等と本橋名は無関係。〕
- **馬場下横町条の「浄泉寺谷」俗呼と往還下伏せ構造候補〔文言候補・repo初出候補〕（p50-57・文政9年5月・済松寺領）**: 小名「馬場下横町之内浅草○谷〔判読不良〕」・戌亥方馬場沿いの「見白水気下新〔判読不能〕」の谷＝俗に「**浄泉寺谷**」ト相唱候（判読候補）で巾弐尺・長往還三間余。石河太八郎様御屋敷の出水が「**往還通 土下〔=土の下〕流**」＝**往還の下を通る伏せ樋構造候補の文言**。〔浄泉寺門前条・浄泉寺谷の語形はrepo初出候補（grep済み）。「谷＝水路の地口」という谷戸語彙の牛込側用例として[対照表](../../地名・河川名対照表.md)鶯谷・指ヶ谷行の系列に追加する候補。〕
- **早稲田町条の下水堀と上稲橋・下稲橋pair〔文言候補・repo初出候補〕（p58-69・名主太郎兵衛）**: 下水堀（巾六尺）＝松平越後守様中御屋敷流入→町内通過→末は江戸川流入＋石橋「**下稲橋**」（長八尺二寸・巾壱丈・名義不知）＋「**上稲橋**」（御組屋敷に現存・御普請の由）＝**「稲」字橋名のpairでいずれもrepo初出候補（grep済み）**。〔早稲田村神明前通りの神明横丁・建勝寺横丁の方位文言も。名義「稲」の由来（早稲田村の稲か）は本文言からは断定しない。〕
- **陰性条件付きの確認〔観察〕**: 若松町・弐拾人町・浄泉寺門前・供養塚町・来迎寺門前・西方寺門前・誓閑寺門前・正覚寺門前・放生寺門前の各条は水系文言なし（家臣・寺社由緒のboilerplate中心）。
