# [GAZ-022] 『新編武蔵風土記稿』巻之十三（豊島郡之五）長崎村条

## 書誌・所在（2026-11-09、古文書便覧リンク集とNDL IIIF・ai）

- 『新編武蔵風土記稿』巻之十三（豊島郡之五）の収録は**長崎村・葛ヶ谷村・中荒井村・中村・谷原村・田中村・上石神井村・下石神井村・関村・竹下新田・土支田村・上練馬村・下練馬村**。リンク集：http://komonjo.rokumeibunko.com/binran/musashifudoki/m001.html
- 各本へのリンク（リンク集掲載）：浄書本 https://www.digital.archives.go.jp/img/4045548 ／明治写本 https://www.digital.archives.go.jp/img/4347330 ／明治活版本（公文書館） https://www.digital.archives.go.jp/img/4294884 ／明治活版本（NDL） https://dl.ndl.go.jp/pid/763977/1/37 ／**大日本地誌大系本（NDL） https://dl.ndl.go.jp/pid/1051345/1/138**。

## 内容メモ（大系本コマ138〜140の部分読取。逐字全転記は未了）

- **コマ138右（二六六）**：巻之十三（豊島郡之五野方領）の開始。**○長崎村**＝日本橋より二里余・民戸五十九、東は池袋村・西は葛ヶ谷村・南は下落合村・北は上板橋村、東西南北共に十町許、雑司ケ谷村より練馬村に通ずる往来あり（幅五間）、**用水は玉川分水を引沃く**。小名に椎名町・長崎（**新田御料の地**）・四向・塩久保・荒井・西原。
- **コマ138左（二六七）上**：長崎村の神社・寺院の末尾（十羅刹女社・羽黒社・八幡社・第六天社・太神宮二・稲荷社二・金剛院・地蔵堂）に続いて**○葛ヶ谷村**。同左下は**○中荒井村**（小名 本村・徳田・神明ケ谷戸・原・北荒井・中通、永川社・**○辨天社二**・稲荷社四・觀音堂）→○中村。
- **コマ139（二六八・二六九）**：谷原村（石神井内谷原在家、用水は石神井川、**千川上水堀**の記述、永川社・稲荷社三・金山社・長命寺）と**長命寺境内之図**・長命寺条。長崎村ではない。
- **コマ140（二七〇・二七一）**：○田中村・○上石神井村と、**三宝寺池之図**＋**○辨天社（三宝寺池の嶋にあり）**＋池（**三宝寺池＝石神井川の水源**）。上石神井村のもので長崎村ではない。

## 照合結果（弁天池・新田義貞）〔未解決〕

- **長崎村条（コマ138右〜左上部）に「弁天池」「弁天社」「新田義貞祈願所」の文は確認できない**。長崎村の神社列挙に弁天社は見当たらない。
- コマ138左下・コマ140左に見える**辨天社＋池は、それぞれ中荒井村・上石神井村（三宝寺池）のもので、粟島神社弁天池（長崎村・谷端川水源）とは別の池**である。両者を混同しない。
- したがって [BLOG-030](../blogs/BLOG-030.md) の「『新編武蔵風土記稿』によると弁天池のそばの祠は新田義貞の祈願所」という紹介は、**本照合（大系本コマ138〜140）では裏付けられない**（二次転記・未照合のまま）。浄書本（4045548）または長崎村条の未読部分での再確認を要する。
- status は直接確認（大系本画像での部分読取まで。弁天池・新田義貞文の所在は未発見）。
