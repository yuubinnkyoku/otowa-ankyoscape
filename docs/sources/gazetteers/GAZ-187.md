# [GAZ-187] 帝国地名辞典 下巻・千川上水条 — 沿革の年号つき要約と給水約2万人の辞典数値

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 太田為三郎編『帝国地名辞典』下巻（**三省堂・1912**・[book/762293](https://lab.ndl.go.jp/dl/book/762293)）。旧国・地域別の地名事典で、**巻末の武蔵国項に「センガワ-ジョウスイ（千川上水）」の見出し独立条**がある。同書内の東京市条（第6コマ以降・「上水にはもと玉川・神田・千川の三あり」の総説）にも並行文言がある。**引用はOCR由来で、字面（特に「本〓」の欠字部＝本所/本郷の別）は原本画像との照合を要する**。

## 文言〔確認・要照合〕

- **千川上水条**（見出し語「センガワ-ジョウスイ」）:
> 千川上水 【東京】東京市本〓·淺草邊の舊飮料水。**北足立郡**保谷村にて、玉川上水を分ち、北豐島郡巢鴨村**庚申塚**に至る水路**五里六町**。是より埋樋となり、本〓·湯島·淺草に給水せり。**元祿九年起工、享保七年廢し、附近諸村の用水とし、明和六年復舊、駒込·本〓·下谷·淺草邊まで掛りしが、便ならざるを以て天明六年廢す。明治十三年更に修理を加へ、專ら本〓區の上水に給せられ、給水を受くるもの約二萬人なりしといふ。東京市水道成るに及び廢す。**〔OCR「埋極」は「埋樋」の崩れ・「本〓」は欠字〕

- **同書・東京市条の並行文言**:
> 上水にはもと玉川·神田·千川の三あり。…**千川上水は元祿年中の創設、天明年中之を廢し、明治十三年復た工を起し、北多摩郡にて玉川上水と分れ、巢鴨に至りて伏樋に入り、本〓區に達せしが、近年市民の衞生と…**〔「近年」以下は淀橋浄水池に言及する東京市水道一般の文言で、千川の再興沿革とは切り離して読む必要がある〕

## 読み取り〔観察・対校課題は明記〕

- **①「明和六年復舊」の年号つき要約〔確認〕**: 再興期の文言として「**明和六年復舊**」と単年を挙げ、その後「駒込・本〓・下谷・淺草邊まで掛りしが、便ならざるを以て**天明六年廢す**」と終焉年を対にする。再興の過程（明和6年の願出〔[GAZ-034](GAZ-034.md)・御府内備考の白山前町条〕→安永8年見分→安永9年掛渡開始〔GAZ-034・上水在絶記〕）のうち**「明和6年」を採用する明治期辞典側の簡略化**で、御府内備考系の年号群と対校できる〔「復旧＝水の再開」か「願出・事業の再始動」かは本条の粒度では確定せず、既存の再興時期の解釈（願出：明和6／通水：安永9）に影響するものではない〕。
- **②保谷村の「北足立郡」表記＝誤記候補の内部対校**: 千川上水条は保谷村を「**北足立郡**」に置くが、**同書の東京市条は同じ千川上水について「**北多摩郡**にて玉川上水と分れ」と正しく記す**＝同一書内の矛盾で、「北足立郡」は**「北多摩郡」の誤変形候補**〔[GOV-228](../gov/GOV-228.md)（東京府史談）の「埼玉縣新座郡保谷村」と同型の地名誤栽の系譜に属する。保谷村の郡呼称の転訛パターンとしてrepo初出の変種〕。
- **③水路五里六町・巣鴨村庚申塚の並行文言〔確認〕**: 「保谷村にて玉川上水を分ち、北豐島郡巢鴨村**庚申塚**に至る水路**五里六町**。是より埋樋」＝**[GOV-228]の「保谷村より…巢鴨町溜池に至る水路長五里六町餘」・[GAZ-048](GAZ-048.md)の「新座郡保谷村より…巢鴨庚申塚邊より」**と並行する同一の数値・地名系統で、**「庚申塚＝開渠末端＝埋樋始点」の記述**は[GAZ-051](GAZ-051.md)等の取水口系文言群と整合する辞典側の確認。
- **④明治13年修理後の給水約2万人〔repo初出の独立数値候補〕**: 「明治十三年更に修理を加へ、專ら本〓區の上水に給せられ、**給水を受けるもの約二萬人なりし**」＝明治13年（1880）修理後の千川水道の給水人口**約2万人**と、その**給水区域「本〓區」**（欠字＝本所区または本郷区）を伝える。**[GOV-228]（東京府史談）の「本〓區、下谷區の一部人口凡そ一萬七千餘に給水せり」との対立候補**〔給水区域の「本郷 vs 本所」ⅱ)人口の「17,000余 vs 約20,000」の両面で対校を要する。明治13年の千川水道会社系の実務史料（[GOV-228]の注記参照）での確定が今後の課題。断定はしない〕。
- **⑤「東京市水道成るに及び廢す」〔観察・年代の枠〕**: 終焉を東京市水道の普及に帰する。東京市の砂濾過水道整備期（淀橋浄水池1892年着工・1898年通水等）を指すものと読めるが、本条単独では**千川上水（明治の）廃止の特定年は確定しない**〔文言どおり「東京市水道の完成に及んで廃した」旨の記述として記録〕。

## 第331回追記 — IIIF crop＋vision照合試行〔観察・候補語迎合のため判読は不採用・2026-11-26〕

- 千川上水条（762293・コマ6）をIIIF crop 6x相当の拡大画像＋vision判読（中立な文字書き取り→確認質問の2段方式）で照合したところ、「千川上水…東京市**本郷区**の飲料水。**北豊島郡**保谷村にて玉川上水を分ち」に相当する読みが得られた〔観察〕。
- ただし本判読は**採用しない**: 「北◯郡」の郡名は文脈を与えた読みでは「北豊島郡」と出る一方、同一字の単独拡大では「立」の読みが先立ち相互に矛盾する＝**vision判読が文脈から期待される語を出す「候補語迎合」の実例**と判断した〔観察〕。よって「北足立郡」（OCR）vs「北豊島郡」（vision文脈読み）の対立は**未解決のまま**。また「本郷区」の読みも同じ迎合リスクを含み、欠字「本〓」（本所/本郷・本所区/本郷区）問題を解消する根拠とはしない〔制限①②は有効のまま〕。
- OCR断片「武藤園」は【武藏】の誤読候補〔観察: 文脈〕。
- 文言の確定には原字のhuman照合が依然必要＝制限①②はそのまま回送。

## 制限・未解決

- ①「本〓」の欠字判読（本所／本郷／本所区／本郷区）が文言の要所に3箇所あり、原本照合が必須。②「北足立郡保谷村」の誤記説は同書内対校による**候補**であり、版本の実字確認まで断定しない。③「約二萬人」の測定時点（明治13年の修理直後か、廃止前の最盛期か）は本条では分からない。④同書はコンパクトな事典で、形式的には[GOV-228]・[GAZ-048]等の先行文献系統の要約と考えられ、**独立的な一次史料としてではなく対校資料として**扱う。⑤東京市条の「近年大に改良を加へ、淀橋に大淨水池を設け」以下は東京市水道一般の文言で千川の沿革に含めない。
