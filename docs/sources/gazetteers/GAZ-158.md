# [GAZ-158] 町方書上[20] 三田町方書上 壱（文政11子年）— 三田壱町目条の三田上水全流路文言

- **書誌〔確認〕**: 『[20] 三田町方書上　壱』（写・NDL次世代デジタルライブラリー [book/2571501](https://lab.ndl.go.jp/dl/book/2571501)。NDL目録volume表記「[20] 三田町方書上　壱」・直接確認）。文政11子年（1828）の地誌御調書上で、壱〜四町目・同朋町・台町（壱・弐町目）・台裏町・橋町（弐町目）等の町条を含む（コマ順に「地誌御調書上帳 三田壱町目」〔p5〕〜「三田台裏町」〔p109〕の見出し文言あり・目録面p3に「同二七四ノ第二十一」と読める通し番号らしき文言が見える〔OCR・対応関係は要照合〕）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571501_{NNNNNNN}.txt`）。※三田上水は当repo四河川のいずれの水系でもないが、[GAZ-157](GAZ-157.md)と同じく玉川上水系の市中分水の町方側一次記録として採録する。
- **三田壱町目条の三田上水の全流路列記文言〔文言候補・本冊最重要〕（p14）**: 「**一当町上水之儀は寛文四辰年十一月ゟ掛り候処 享保七寅年相止み 当時上水無御座候 右水路之儀は 武州多摩郡代田村ゟ玉川上水ヲ分水致 江原郡（=荏原郡・OCR候補）北沢村・瀬谷村・上目黒村・白銀村・大山寄村（OCR・原字要照合）・弐本榎通・芝伊四万千（=芝伊皿子等・OCR崩れ大・要照合）・台町・聖坂・三田町通・芝新馬場・同洞町（OCR）・西応寺町・金杉町・本芝町・田町・車町・高輪町・浮簀（OCR・原字不明）・八ツ山下迄 元禄十一寅年ゟ白銀御殿え掛ケ 本村町坂下町辺新堀端・屋（=？）松本町辺迄相掛り申候**」（p14・OCR）＝**①三田上水の分水起点（武州多摩郡代田村）から荏原郡の村列（北沢・瀬谷・上目黒・白銀・大山寄）を経て弐本榎通＝芝伊皿子以遠の市中の町列（台町・聖坂・三田・芝新馬場・西応寺町・金杉町・本芝町・田町・車町・高輪町・八ツ山下）に及ぶ全流路の列記文言（repo初出候補・終端の「八ツ山下」は飯倉六本木側の高輪末端と読める）、②元禄11寅年（1698）に「白銀御殿」への枝線（掛ケ）が新たに相懸ったこと、③本村町坂下町辺の新堀端・松本町辺までの区間が相懸ることの3点**。〔**[GAZ-157](GAZ-157.md)伊皿子台町条の「訳ケ委細は三田壱町目ゟ申上候」型の相互参照が指す本流側の実体がこの条の文言**＝[GAZ-157]制限②（三田上水の本流と各町への配水の系譜）への回答材料の第一候補。②の元禄11年白銀御殿枝線は[GAZ-162](GAZ-162.md)麻布本村町条の「玉川分水ニ而白金御殿江掛り候水筋」（白金/白銀はOCR判読対立）と時期・対象が呼応する候補（同一枝線かは地名判読と原画像照合まで断定しない）。〕
- **弐町目条の高札13ヶ町惣持＋上水文言〔文言候補〕（p22）**: 「**御高札之儀は 三田拾二ケ町幷芝伊皿子町都合拾三ケ町惣持ニ而 同所臺町本町日々建有之 委細之儀は同町に而申上候 一上水之儀は 武州多摩郡代田村より玉川上水分水致 寛文四辰年中当町も相掛り候所 享保七寅年十月中相止 当時上水無御座候 町奉行御代官両御支配に而当時中村八太夫様御代官所に御座候**」（p22・OCR）＝**①高札は三田12ヶ町＋芝伊皿子町の13ヶ町惣持で台町本町（＝台町一町目か）に日々建てる組織文言、②上水は寛文4辰年掛り・享保7寅年**十月中**相止の年月文言、③町奉行・御代官両支配で当時（文政11年時点）の中村八太夫代官所支配**。〔13ヶ町惣持の実務構造＝[GAZ-161](GAZ-161.md)金杉通壱町目条の「町奉行御代官両御支配…中村八太夫様御代官所」との役名一致で芝・三田両側の給水区域組織の対応関係を裏付ける。伊皿子町が三田12ヶ町の惣持に加わっている組織実態は[GAZ-157]の「飯倉町組合名主」署名構造と対校できる。〕
- **四国橋名義の文言〔文言候補・参考〕（p79・三田同朋町条）**: 「**松平讃岐守様上り屋敷之節 昔ゟ右場所に仕建有之 里俗四国町と唱候故 四国橋ト唱候由申伝ニ御座候**」（p79・OCR）＝四国橋の名義文言（松平讃岐守の上り屋敷の部位に昔から橋があり、里俗に四国町と唱えた場所なので四国橋と唱える由）。橋が何に架かっていたか（上水跡の通路か否か）は本文言からは判別できない（断定しない）。同条に「**三田上水之儀は寛文四辰年十一月中 武州多摩郡代田村ゟ玉川迄水も分水致 当時相止候訳ケ委細三田壱町目ゟ申上候通ニ御座候**」＝委細の壱町目への委譲文言の再出（p79）。
- **三文目条の石橋と上水の定型文言〔文言候補・参考〕（p30・p50・p88・p100）**: p30「**石橋壱ヶ所 町内往還中程ニ有之 長サ四間三尺 幅三尺 掛初修復年代等相分り不申候**」＋上水は寛文4辰年・享保7寅年十月中相止の定型文言。p50（四町目条・条帰属要確認）は流路列記の変種（「**代白村（=代田村・OCR変種）ゟ玉川上水を分水致 在原郡（=荏原郡）水沢村（=瀬谷村？）瀬谷村 上目黒村 白銀村 大崎村…**」〔p50・OCR・村名の重複・大崎村の追加は要照合〕）が見える。p88（台町壱町目条）・p100（橋町弐町目条）にも寛文4辰年〜享保7寅年十月中相止の定型文言と「惣反別之儀は三田壱町目に而申上候」の文言が続く＝壱町目＝全体の惣合計の代表申出町。
