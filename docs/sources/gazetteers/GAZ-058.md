# [GAZ-058] 『江戸名所図会』有朋堂版（1927）— 法明寺条の弦巻川文言の判読前進

- **書誌〔確認・巻冊の対応は要照合〕**: 『**江戸名所圖會**』（**有朋堂書店・1927年刊の冊**。天璣之部〔巻の3〕等を収める。江戸名所図会の近代活字版の一つ）。NDL次世代デジタルライブラリー [book/1174144](https://lab.ndl.go.jp/dl/book/1174144)。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①法明寺条の弦巻川文言＝[GAZ-047](GAZ-047.md)の対校で判読が前進〔確認文言〕**: 「**当寺仁王門の前を東流する細き溝川をなづく。古へは布引川とも唱ヘけるといひ傳ふれども、共に其由縁をし〔らず〕…弦卷川　水源は池谷〔イケヤド〕の邊に發し、下流は〓土の邊へ出て、音羽町の西の方を歷て、江戶川に會せり。**」＝**①法明寺（鬼子母神別当・雑司ヶ谷）仁王門前を東流する細き溝川が「弦巻川」と呼ばれること、②古くは「布引川」とも唱えたという伝承、③水源は「池谷〔イケヤド〕」の辺に発し、下流は「〓土（清土）」の辺に出て、音羽町の西の方を歴て江戸川に会す流路**。〔**[GAZ-047](GAZ-047.md)（1893年覆刻版・OCR著しく乱れ）の「源ハ弛谷ノ辺」「下流ハ清主ノ辺」の判読が、本活字版のOCRで「池谷〔イケヤド〕」「〓土（清土）」に前進した**。「弛谷」→「池谷」の修正は[BOOK-144](../books/BOOK-144.md)（遊歴雑記五編「池ヶ谷といえる處に丸池」）・[対照表139行](../../地名・河川名対照表.md)の池ヶ谷／池箇谷行と整合する。「イケヤド」のルビの原字（池谷戸〔イケヤド〕か池ヶ谷か）と「〓土」の原字は原文照合を要する。布引川の異名文言は[BOOK-001](../books/BOOK-001.md)・[GAZ-002](../gazetteers/GAZ-002.md)系の布引川言及の対校資料〕。
- **②天璣之部の「つるまきのがう（弦卷郷）」項目〔確認・同名異在地の記録〕**: 天璣之部の目録に「**つるまきのがう　實相院　當山開闢石塔　弦卷郷**」の項目群が見え、実相院条に「**長立山常光寺　弦卷村　世田ヶ谷上宿の南にあり**」＝**世田ヶ谷上宿の南の「弦卷村」の実相院・常光寺の条**。〔**世田谷の弦巻村（現・世田ヶ谷の弦巻）と雑司ヶ谷・音羽の弦巻川の「つるまき」の同名異在地**の記録。江戸名所図会が両者を別箇所に立項している点は[対照表](../../地名・河川名対照表.md)の弦巻川行・弦巻村行の対照に有用。本資料では世田谷側の条の詳細は採録しない〕。

## 制限・未解決

- ①「池谷〔イケヤド〕」のルビの原字・「〓土」の原字（清土）は原文画像（有朋堂版の該当頁または江戸名所図会の原版本）との照合を要する。②本冊の巻冊構成（天璣之部の巻数）と有朋堂版の書誌の詳細（復刻・新植字の別）は奥付照合を要する。③法明寺条の前後（鬼子母神・遊行寺等）の精読は今回は音羽の瀧関係以外未実施。④[GAZ-047](GAZ-047.md)の1893覆刻版の「源ハ弛谷ノ辺」の原字が「池谷」であるかは、1893版の原画像照合でも確定を要する（本対校は判読の前進であって原字の確定ではない）。
