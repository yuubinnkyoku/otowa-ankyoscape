# [GAZ-058] 『江戸名所図会』有朋堂版（1927）— 法明寺条の弦巻川文言の判読前進

- **書誌〔確認・巻冊の対応は要照合〕**: 『**江戸名所圖會**』（**有朋堂書店・1927年刊の冊**。天璣之部〔巻の3〕等を収める。江戸名所図会の近代活字版の一つ）。NDL次世代デジタルライブラリー [book/1174144](https://lab.ndl.go.jp/dl/book/1174144)。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①法明寺条の弦巻川文言＝[GAZ-047](GAZ-047.md)の対校で判読が前進〔確認文言〕**: 「**当寺仁王門の前を東流する細き溝川をなづく。古へは布引川とも唱ヘけるといひ傳ふれども、共に其由縁をし〔らず〕…弦卷川　水源は池谷〔イケヤド〕の邊に發し、下流は〓土の邊へ出て、音羽町の西の方を歷て、江戶川に會せり。**」＝**①法明寺（鬼子母神別当・雑司ヶ谷）仁王門前を東流する細き溝川が「弦巻川」と呼ばれること、②古くは「布引川」とも唱えたという伝承、③水源は「池谷〔イケヤド〕」の辺に発し、下流は「〓土（清土）」の辺に出て、音羽町の西の方を歴て江戸川に会す流路**。〔**[GAZ-047](GAZ-047.md)（1893年覆刻版・OCR著しく乱れ）の「源ハ弛谷ノ辺」「下流ハ清主ノ辺」の判読が、本活字版のOCRで「池谷〔イケヤド〕」「〓土（清土）」に前進した**。「弛谷」→「池谷」の修正は[BOOK-144](../books/BOOK-144.md)（遊歴雑記五編「池ヶ谷といえる處に丸池」）・[対照表139行](../../地名・河川名対照表.md)の池ヶ谷／池箇谷行と整合する。「イケヤド」のルビの原字（池谷戸〔イケヤド〕か池ヶ谷か）と「〓土」の原字は原文照合を要する。布引川の異名文言は[BOOK-001](../books/BOOK-001.md)・[GAZ-002](../gazetteers/GAZ-002.md)系の布引川言及の対校資料〕。
- **②天璣之部の「つるまきのがう（弦卷郷）」項目〔確認・同名異在地の記録〕**: 天璣之部の目録に「**つるまきのがう　實相院　當山開闢石塔　弦卷郷**」の項目群が見え、実相院条に「**長立山常光寺　弦卷村　世田ヶ谷上宿の南にあり**」＝**世田ヶ谷上宿の南の「弦卷村」の実相院・常光寺の条**。〔**世田谷の弦巻村（現・世田ヶ谷の弦巻）と雑司ヶ谷・音羽の弦巻川の「つるまき」の同名異在地**の記録。江戸名所図会が両者を別箇所に立項している点は[対照表](../../地名・河川名対照表.md)の弦巻川行・弦巻村行の対照に有用。本資料では世田谷側の条の詳細は採録しない〕。

## 2026-11-20追記（第211回）— 天權之部巻之四（高田・牛込地区）の蟹川・金川・山吹の井・蟹ヶ池・星谷の井の本文文言候補

同一デジタル化（[book/1174144](https://lab.ndl.go.jp/dl/book/1174144)）に天權之部巻之四が含まれることを確認し、金川条・山吹の里条・三島山条・護持院条・護國寺条のOCRテキストを精読した。**引用文言はすべてOCR由来で原画像照合を要する**（OCR崩壊・同一内容の二重採録箇所を含む）。対校資料として1922年版の同内容（[book/964492](https://lab.ndl.go.jp/dl/book/964492)・第2巻）も同じ文言を載せる。

- **③金川条〔文言候補・蟹川系の典源級〕**: 天權之部巻之四の目録に「**かながは　金川**」の独立見出し。本文「**（金川）穴八幡の前を、早稻田の方へ流る〓小川を云ふと（なり・唱へたり）。水源は戶山御庭（中より發する所なり）。文明年間、太田道灌遊獵のとき急雨に逢ひしは此地にして…（中略）幅も廣かりしとなり。其頃は加奈川、又加能川とも稱びけるとなり。**」（付近に「**或は蟹川**」の断片）＝**①1785年原典（天明5刊）の時点で「加奈川」「加能川」の古称と「幅も廣かりし」の由緒を明記**＝[GAZ-051](GAZ-051.md)（豊多摩郡誌・1916）戸塚町条「古は金川、加奈川、又は加能川など稱して川幅廣かりし由、源は戶山より發す」の**131年先行本文で、郡誌本文の典源（直引または共通原典）候補**（郡誌の「源は戶山より發す」に対し本条は「**水源は戶山御庭（中より發する所）**」とより具体的）＝[GAZ-046](GAZ-046.md)風土記稿の「尾彎（尾張）殿戸山屋敷」水源説・[BOOK-149](../books/BOOK-149.md)（戸塚町誌）「下戶塚舊尾州藩戶山の池より發し」の先行側の文言群にも対応。③道灌の急雨譚（山吹譚）の舞台を金川の地とする本文＝下の山吹の里条との相互参照。
- **④山吹の里条の按語〔文言候補・repo初出の「加牟川」〕**: 条末尾の編者按「**穴八幡の前を寶泉寺の方へ流る〓小溝を、今蟹川といふ。昔は加牟川と唱へけるとなり。是先にいふ所の（金）川ならん歟。其是非は詳にせずといへども、しばらくこ〓に云ひ傳ふるに任せて、是を擧ぐるのみ。**」＝**①「今蟹川」という1785年時点の用例、②「昔は加牟川と唱へける」という異称〔repo全域初出候補〕、③穴八幡前の小溝の流向を「寶泉寺の方へ」と記す文言（[GAZ-039](GAZ-039.md)〔南向茶話経由〕の「古へ蟹川と言ふ川有 当時穴八幡前ゟ半輪田裏通を流るゝ小川也と云 只今古川とよひけ川筋也」の**先行/共通原典候補**・後述の対立点参照）、④「是先にいふ所の金川ならん歟。其是非は詳にせず」＝**金川条と蟹川の同一性を編者自身が保留した天明期の按語**＝蟹川系の川名の異称・変遷を観察するうえで編纂態度の分かる文言候補**。〔宝泉寺方向の流向文言は、南向茶話系の「半輪田裏通」 ([GAZ-039](GAZ-039.md))・高田雲雀系の「目高橋より古川へ入」 ([GAZ-067](GAZ-067.md)) と流向・称呼の対校課題。OCR「こ〓に云ひ傳ふる」=「か〓に云ひ傳ふる」等の崩れ候補あり〕。条冒頭「**（太田持資〔OCR・道灌の別表記候補・人物名は要照合〕） …一日戶塚の金川邊に放鷹す、其時携ふる所の鷹、慕れて飛去りければ…時に急雨頻なれば…山吹の花を手折りて…**」＝**山吹譚の舞台を「戶塚の金川邊」とする本文**（和漢三才圖會・俗說辨・艷道通鑑の同譚所収と鎌倉・神奈川説の批判もこの条の按に含まれる）。
- **⑤山吹の井（三島山条内）〔文言候補・[GAZ-051](GAZ-051.md)第210回追記4の典拠本文〕**: 「**（三島山）…山岸に少し（ばか）りの甘泉あり。是を山吹の井と呼べり。土人或は三島明神の御手洗、又は賴朝卿の馬の冷し場なりともいひ傳へたり**」＝**郡誌（1916）が引いた「(江戶名所圖會)」本文の直接確認**＝山吹の里（民家後園）・三島明神（頼朝卿の勧請とする三島山条の縁起文言を含む）・山吹の井（甘泉・御手洗説・馬の冷し場説）の一体の記述＝[対照表](../../地名・河川名対照表.md)山吹の井行の典拠側対照が成立。
- **⑥護持院条の「蟹ヶ池」〔文言候補・repo初出〕**: 天權之部巻之四の目録（護持院条内）に「**蟹ガ池**」の見出し＋本文「**本尊藥師（佛は）、昔當寺草創の時、此地蟹ヶ池より出現ありし靈像（にして）…今の本尊藥師佛の胎中に收む**」＝**目白側（護持院・現在の豊島区目白付近の谷筋）に「蟹ヶ池」という池があった旨の1785年本文文言候補**＝水窪川源流の蟹ヶ窪（小石川・[GAZ-083](GAZ-083.md)）と「蟹」のつく窪・池名の別地点での並存例＝蟹川・蟹ヶ窪の命名環境（蟹の生息する水辺の窪地の分布）の観察材料。〔護持院＝元本傳寺（経読み祖師・波切不動尊）の条内で条の帰属の細部は原画像照合要〕。
- **⑦護國寺条の「星谷の井旧地」〔文言候補・弦巻川系の湧水アンカー〕**: 「**星谷の井舊地　護國寺の西の谷にあり。其地を星谷と號す。往古此地に星祭を修する行者ありしにや、本淨寺の裏に塚のごときものありて、星（塚?）と號け、其傍に一ツの井ありしとぞ。此井旱魃にも水絕えず涌出せしが、其後埋れて、今わづかに其跡を存す。符水、藥水に求むる人多し。此下流に（ある）橋を、星谷橋と號く。**」＝**①護国寺西谷（＝雑司ヶ谷側の谷筋・現在の椿山荘・目白側）の「星谷」の井＝旱魃にも絶えず涌出・その後埋没して跡のみ存す、②下流の「星谷橋」の橋名**＝**星谷の湧水（[対照表](../../地名・河川名対照表.md)星谷の井行・星谷行・[GAZ-066](GAZ-066.md)名水品彙の三角井泉・星清水・星之井の3条に先立つ1785年の本文側の記録候補**。〔星谷の井の位置を「護國寺の西の谷」の本淨寺裏の星塚の傍と特定する文言で、弦巻川（雑司ヶ谷〜音羽の谷筋）の湧水系（清水之流＝[GAZ-035](GAZ-035.md)西青柳町条・家元小流）との位置関係の対校が課題。GAZ-066の「星之井（護国寺西の山麓・今乞食の井水と成）」との異同（同一井か別井か）は断定しない〕。
- **⑧陰性〔確認〕**: 須原屋版系のデジタル化8点（[book/2559044](https://lab.ndl.go.jp/dl/book/2559044)ほか・巻五等）に天權之部巻之四を含む冊子なし＝原版撮影系では本地区（高田・牛込）の巻が未デジタル化。金川・蟹川・山吹の里の本文の原版側対照は本資料（有朋堂活字版）と[GAZ-047](GAZ-047.md)（覆刻版）・964492（1922年版）の活字系3点で進めるほか、原版本の所在確認（内閣文庫・国立国会図書館等）が今後課題。

## 制限・未解決

- ①「池谷〔イケヤド〕」のルビの原字・「〓土」の原字（清土）は原文画像（有朋堂版の該当頁または江戸名所図会の原版本）との照合を要する。②本冊の巻冊構成（天璣之部の巻数）と有朋堂版の書誌の詳細（復刻・新植字の別）は奥付照合を要する。③法明寺条の前後（鬼子母神・遊行寺等）の精読は今回は音羽の瀧関係以外未実施。④[GAZ-047](GAZ-047.md)の1893覆刻版の「源ハ弛谷ノ辺」の原字が「池谷」であるかは、1893版の原画像照合でも確定を要する（本対校は判読の前進であって原字の確定ではない）。⑤天權之部巻之四のOCR文言（第211回追記③〜⑦）は崩壊箇所（金川条冒頭・山吹の里条の人物名「持資」・星谷の井の「星（塚?）」等）を含み、すべて原画像照合が前提。「加牟川」の原字（加牟川・加務川等）と国字・ルビの有無も照合課題。⑥山吹譚の主人公の諱の表記（太田道灌・持資・資長）の原画像確認と、山吹の里条冒頭の OCR 文言のつながり（「一日戶塚の金川邊に放鷹す」の直前の人物名表記）は未確認。
