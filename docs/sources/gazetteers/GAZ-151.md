# [GAZ-151] 町方書上[35] 赤坂参 — 太刀洗川の元資料側・新規大下水の元資料側・駒止橋（赤坂）

- **書誌〔確認〕**: 『[35] 赤坂町方書上　参止』（写・NDL次世代デジタルライブラリー [book/2571515](https://lab.ndl.go.jp/dl/book/2571515)・表紙OCR「**二七四ノ第三十五**」・155コマ）。文政10亥年（1827）7〜11月の署名（新町壱丁目名主八郎左衛門・新町名主善三郎・赤坂氷川門前名主八郎左衛門〔OCR「水川」〕・飯倉新町名主市兵衛・溜池端青勝寺門前代地名主藤吉等）。収録は赤坂新町壱〜五丁目・氷川門前・氷川社僧屋敷・氷川植木溜・溜池端芝御霊屋／青龍寺門前／芝永井町各代地・飯倉新町・溜池榎坂床見世等。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571515_{NNNNNNN}.txt`）で示す。（[35]は第225回で「川系Keyword掃引で文言不在傾向＝次回全面掃引候補」とされた冊で、第226回の全面掃引で水系文言群を確認した。）
- **太刀洗川文言の元資料側対校〔文言候補・本冊最重要〕（p28-29・赤坂新町弐丁目条末尾・署名「文政十年亥ノ七月赤坂新町名主善三郎」）**: 「**二横切下水壱ケ所之儀ハ町内西之方一ツ木町浄土寺東ゟ東之方田町御堀端明地内大下水江流レ落申候巾三尺五寸水源之義ハ妻木彦右衛門様屋敷内より流出申候此義は年代不知梶原源太景季鎌倉ゟ奥州江通り候節景季右川を渡水中江帯候大刀落し候二付附居候者之内二而取上ヨゴレヲ洗ひ候由に御座候右に付其頃より太刀洗川と申伝候由然る處其後追々町屋出来候而当時は下水に相成申候得共今に右下水を梶原太刀洗川とり俗に申伝へ候**」＝**[GAZ-116](GAZ-116.md)（御府内備考巻67-69赤坂側）の「新町1丁目条」太刀洗川文言の元資料側witness**。①**条帰属対立**: 本冊では文言が（OCR上の条区切りでは）**弐丁目条**（見出し「地誌御調書上帳赤坂新町弐丁目」p14〜署名p29）に属し、[GAZ-116](GAZ-116.md)の「新町1丁目条」帰属と食い違う＝条区切りの誤読・集成時の再配列の両可能性があり原画像照合まで決めない。②流路の定量情報（**一ツ木町浄土寺東→東之方・田町御堀端明地内の大下水へ流落・巾三尺五寸・水源は妻木彦右衛門様屋敷内流出**）＝[GAZ-116](GAZ-116.md)の水源文言（対照表・太刀洗川行）の元資料側確認。③「大刀落し候二付附居候者之内二而取上ヨゴレヲ洗ひ候由」など御府内備考側抄録に残るか要確認の細部文言。④「今に…俗に申伝へ候」＝里俗名の文政期生存の元資料側でも裏付け。
- **赤坂新町弐丁目条の石橋2つと三条目の横切下水〔文言候補〕（p29）**: 「**六上石橋之儀は往来に而前書下水え掛渡し有之は幅弐間程渡り四尺程名目無御座候**」「**四横切下水壱ヶ所ハ町内と三丁目と之間里俗左り横町留候場所二而南之方ゟ北之方え流落末ハ御堀端明地内大下水江流落申候幅弐尺五寸程堀割年代相知レ不申候**」「**一下石橋之義ハ横町往来ニ而右下水江懸渡し有之幅九尺へ渡り三尺程に而名目無御座候**」＝①**上石橋**（往来の太刀洗川系下水掛け・幅弐間程・渡り四尺程・**名目無**）と**下石橋**（横町往来・幅九尺・渡り三尺程・**名目無有之**）の寸法と無名橋の明記、②弐丁目〜三丁目間の横切下水（南→北流・末は御堀端明地内大下水・巾弐尺五寸・堀割年代不知）。〔上石橋/下石橋という対の呼び分け候補はただし本文は「名目無御座候」と明記＝橋自体は無名で、上・下は書上側の整理語か判読要照合。**無名橋2つの寸法を対で記す一次文言**〕。
- **享保年中赤坂溜池端明地内新規大下水の元資料側〔文言候補〕（p43・赤坂新町三丁目条内）**: 「**享保年中道御奉行所御掛り二而赤坂溜池端明地内江新規大下水出来右下水大坂幷溜池日比谷門門外御堀常後炭町豊田屋源助和泉屋伝七御請負申上為助成右常後屋鋪拝領仕**」＝**[GAZ-116](GAZ-116.md)（御府内備考・新町三丁目条）の「享保年中の赤坂溜池端新規大下水」文言の元資料側確認**＋**①請負人の判読対立: 本冊OCR「**豊田屋**源助」vs [GAZ-116](GAZ-116.md) OCR「**白田屋**源助」（原字照合まで保留・「炭町」の所属と併せてどちらが正しいか決めない）、②「常渡屋敷」の表記（本冊は「常後屋敷」「常駿屋浦」等に崩壊）＝[GAZ-116](GAZ-116.md)の「常渡（幕府の定期渡し）」解釈の原字側確認課題。
- **赤坂新町五丁目条の駒止橋と青山御掃除町水源の横切下水〔文言候補〕（p107）**: 「**十二横切下水町内北之方武家地之方ゟ南之方江流落申候巾七尺程有之堀割年代相知不申候尤水源之義者青山御掃除町ゟ流出候而末水ハ赤坂田町五丁目大下水江落合申候二板橋壱ケ所右下水え掛渡し往来に有之巾壱丈壱尺渡り九尺程ニ而起立相知不申候駒止橋と相唱申候**右名目之儀は中古当橋際江何人之馬に候哉乗り来り候節一向ニ進ミ不申頻りニ聊候由右に付只今以唱来候儀に御座候」＝**①赤坂新町五丁目の横切下水（水源は青山御掃除町流出→末は赤坂田町五丁目大下水へ落合・巾七尺・堀割年代不知・北武家地方→南流）・②その板橋「駒止橋」（巾壱丈壱尺・渡り九尺程・起立不知・馬が一向に進まなかったとの名目伝承）**。〔**音羽の駒止橋**（[GAZ-013](GAZ-013.md)・御府内備考櫻木町節「駒止橋、古名鼠ケ谷橋」＝弦巻川系鼠ヶ谷下水に架かる）**と同名の別橋候補**＝「駒止」語の駒止め伝承が複数の橋に独立に付くのか、名称の系譜関係かは本資料からは断定しない（同名異橋の対照材料）。青山御掃除町を水源とする下水の流路文言は[GAZ-146](GAZ-146.md)赤羽川の水源認識文言（内藤新宿追分/四ッ谷大木戸系の玉川分れ）と青山側の下水水源観察として対照可能だが同一水路かは断定しない〕。
- **三丁目条の「東都宮橋」文言候補〔OCR崩壊大〕（p58）**: 「**十二東都宮橋右は同町弐丁と之間横切下水に掛渡し有之右は弐百目ゟ申上候市谷村壱ヶ所…**」＝「東都宮橋」「弐百目」の原字は未特定で、続きの小安稲荷（市谷村・昔之神妙繁束にて神宮無之・間口壱間）・神井木像（老翁・鎌・稲穂・白狐・正一位格賀稲荷）の下りとの関係も含め原画像照合まで候補扱い（橋名調査への採録可否は保留）。
- **四丁目条の無名下水と石橋〔文言候補〕（p81）**: 「**十下水町内向側ニ而武家方家前ニ有之巾五尺長百間程有之町内持ニ而堀割年代相知不申候但し下永際迄町内持ニ御座候石橋壱ヶ所右町内向側自身番屋脇ゟ南之方え這入候横町入口に巾六丈長六尺五寸程有之右紀立相知不申候尤修復等有之節は何方出銀致来候哉…松平安藝守様御屋鋪ニ而有之候節ゟ有来り候義と奉存候一井戸壱ヶ所**」＝巾五尺・長百間程・町内持の無名下水（「下永際迄町内持」＝下流端の表現候補・要照合）＋石橋1ヶ所（巾六丈〔=六尺候補〕長六尺五寸程・修復は武家方御組合持の出銀）＋井戸1ヶ所。
- **床見世起立願の「上水番」人名用例〔文言候補〕（p147・溜池榎坂床見世節）**: 「**板坂下通表間口拾弐間五尺奥行四郎右衛門本道世数三軒右地所之儀は松平肥前守様御預り地内二而水茶屋床見世起立之儀は安永三ヶ年御名不知御普請御奉行様江百三十五上水番落助と申者相願御上納地ニ御座候**（中略）**寛政六寅年退役被仰付行衛相知不申候**」＝水茶屋床見世の願立て人物として「**上水番・落助**」という人名・役職名の用例候補（どの上水の番方かは本文言からは確定不能。安永三年＝甲午1774候補の願立て・寛政6年退役の人物記録としてそのまま記録）。
- **陰性の確定〔観察〕**: 氷川門前条（p109-113）・氷川社僧屋敷条（p114-118）は「御箇條之廉…当町内にて無御〔座候〕」のboilerplate（川系文言なし）。溜池端芝御霊屋／青龍寺／芝永井町代地群（p124-144）は増上寺火除地事情の代地履歴中心（[GAZ-147](GAZ-147.md)・[GAZ-148](GAZ-148.md)の溜池端情報に重複層）で水系文言なし。千川上水・四河川の直接文言は本冊に none。

## 制限・未解決

- ①すべてOCR由来で特に固有名詞の判読対立が多い（水川/氷川・豊田屋/白田屋・東都宮橋・「下永際」等）。②太刀洗川の条帰属対立（本冊弐丁目条 vs [GAZ-116](GAZ-116.md)壱丁目条）は本冊側OCRの条区切りの誤り・集成時の再配列の両可能性があり原画像照合まで決めない。③上石橋・下石橋は本文が「名目無御座候」と明記する無名橋で、その呼び分けの性格（位置方言か書上側の整理か）は照合課題。④駒止橋（赤坂）と音羽の駒止橋の名称系譜関係は断定しない。⑤東都宮橋は橋名候補として橋名調査にまだ加算しない。
