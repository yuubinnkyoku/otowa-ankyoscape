# [GAZ-177] 町方書上[134] 深川 十五 — 両国橋御役船仲間の由緒書＝神田川系の洪水・流木記録群

- **書誌〔確認〕**: 『[134] 深川町方書上 十五』（写・NDL次世代デジタルライブラリー [book/2571615](https://lab.ndl.go.jp/dl/book/2571615)。NDL API volume欄直接確認）。両国橋御役船（茶船）仲間の由緒書（koma 57-58・64-65）。引用文言はすべてOCR由来で要原文照合。※第223回の本冊boilerplate陰性判定（四河川keyword）は以下の文言を捉えていなかった＝本回訂正。
- **万治2年両国橋架橋と伊奈半十郎文言〔文言候補〕（koma 57-58）**: 「**私共仲間六拾人之儀は先年ゟ茶舟所持仕諸荷物積送り之成渡世…一万治二亥年 初而西国御橋相懸り候節 伊奈半十郎様ゟ被仰付 其後本所御奉行様え相渡り 元禄六酉年十一月 本所御奉行藤堂店兵衛様（=庄兵衛・OCR候補）多賀又四郎様え書付差上 則舟仲間拾人ニ而数年御役相勤申候**」（koma 57-58・OCR）＝**①万治2年（1659）・両国橋（OCR「西国御橋」=両国御橋判読候補）が初めて架かった節に伊奈半十郎が御役船（茶船）を申し付け、②その後本所奉行へ相渡し、元禄6年（1693）11月に10人の舟仲間で御役を勤めた**という両国橋架橋と御役船の起立文言候補。〔**「万治二亥年初而…相懸り」=万治2年の両国橋架橋の一次文言候補（repo初出）＝[GAZ-165](GAZ-165.md)（万治2年本所御取立の新規御堀立）・[GOV-171](../gov/GOV-171.md)（万治2年本所上水開始）と万治2年の同時性（本所開発の起点年に両国橋が架かる）を指し揃える datapoint**（橋名は「西国」のまま読めるため「両国」への確定は原画像照合まで留保）。〕
- **寛文・天和の洪水記録と褒美文言（koma 58）**: 「**一寛文年中西国御橋壱之間類焼仕往来相留り申候節…無拠ニ而船渡仕一両日之間御用相勤…伊奈半十郎様ゟ右流掛り候材木共為御褒美被下置候 一天和年中溢水二而千住御橋材木其外売（=筏?・OCR）木等多く流懸り 西之方四拾間程流レ落候節…品川**」（koma 58・OCR）＝**寛文年間の両国橋類焼時の船渡・天和年間の溢水時の千住御橋建材・木筏の流懸り（西側40間程流れ落ちた）に対する船方の防方実働と褒美**の文言候補。〔**天和年中の神田川系（千住橋は石神井川/隅田川系かは注意・千宿御橋の位置は要確認）洪水記録の追加と、流木の経済（材木の褒美下げ渡し）**の一次記録候補。〕
- **寛延2年・明和3年の神田川洪水文言群〔文言候補・本冊最重要②〕（koma 64-65）**: ①「**寛延二巳年出水之節…其節 大高瀬舟 神田川ゟ流レ出シ御橋え流懸り候を右鯨舟幷右役舟之者共早速取除申候…町御奉行様ゟ御褒美頂戴仕候**」（koma 64・OCR）＝**寛延2年（1749）出水の节・神田川から流れ出た大高瀬舟が御橋（両国橋）に流れ懸かったのを役船が取除いた**、②「**明和三戌年六月ゟ八月迄度々出水仕候節 千住大橋流落申候…神田昌平橋え竹木流懸リ老く（=見え?・OCR）相見申候処…両国に残り候御役舟之者共昌平橋え参り流懸り候ものを取除相働申候**」（koma 64-65・OCR）＝**明和3年（1766）6〜8月の度々の出水で千住大橋が流落し、神田昌平橋に竹木が流れ懸かった際の差止実働**、③「**文化十一戌年以来 神田川本所竪川通其外加入仕候分弐拾四人 当時惣仲間七拾壱人**」（koma 64・OCR）＝**文化11年（1814）以来「神田川・本所竪川通」などから加入した24人を含む71人の仲間**という文言候補。〔**神田川の洪水史（寛延2・明和3）と、昌平橋（神田川の橋）への流木の一次記録（repo初出候補）＝神田川（江戸川）の治水・流木史の史料列の追加**。「神田川本所竪川通」の併記は神田川と竪川の船方実務上の繋がり（流下物の系統）を示す材料候補。〕

## 制限・未解決

- ①すべてOCR由来で要原文照合（「西国御橋」=両国御橋判読候補・「藤堂店兵衛」=藤堂庄兵衛・「売木」=筏木?・「老く」=見え? 等）。②「天和年中…千住御橋」の洪水は千住大橋（隅田川）か千住の他橋かの比定が未了（文言候補）。③明和3年6-8月の度々出水と千住大橋流落は既知の明和3年出水量?（外部対照は未了）＝repoの神田川洪水史 datapointとして追加するのみ。④「万治2年両国橋架橋」は広く知られる通説と整合するが、本冊は御役船側の由緒書で、架橋年次の確定史料としての優劣は対校表で管理する。
