# [GAZ-050] 御府内往還其外沿革図書 十二之二 — 白堀端を境目とする大縄地の目録

- **書誌〔確認〕**: 『御府内往還其外沿革図書』（江戸幕府普請奉行編纂の沿革図書・全22部のうち第15部までが『御府内往還其外沿革図書』・第16部以降が『御府内場末往還其外沿革図書』＝[GAZ-012](GAZ-012.md)）の**十二之二**＝「小日向台大塚小石川辺一円之絵図」[book/2571703](https://lab.ndl.go.jp/dl/book/2571703)。OCR全文精読。**引用文言はすべてOCR由来で要原文照合。**〔対象域は小日向台・大塚・小石川＝[GAZ-012](GAZ-012.md)（第20部・場末側）と対象を補い合う御府内側の沿革図書。本repoでは十二之二の直接精読は今回が初出〕
- **目録の「白堀端」を境目とする大縄地の列挙〔確認・repo初出〕**: 本冊の目録（絵図の丁目割の説明部）に**白堀端を境目とする大縄地（画地）の列挙**——「**神田川江戸川端〜内藤甚十郎屋敷脇**」「**水戸殿屋敷境〜白堀端**」「**牛天神脇〜白堀端通金剛寺坂**」「**金剛寺坂通斎藤伊豆守屋敷脇〜江戸川端**」「**白堀端字服部坂通東側茗荷谷**」「**白堀端通音羽町九町目橋**」「**白堀端通桜木町横町田中八幡前**」等＝**①「白堀端」（白堀の端・上水に沿う道の端部）が小日向〜小石川の大縄地の境目の基準線として使われていること、②境目の対応物が江戸川端・水戸殿屋敷境・牛天神・金剛寺坂・服部坂・茗荷谷・音羽町九町目橋・桜木町横町・田中八幡前であること**〔**白堀（神田上水の小日向〜小石川区間・[GAZ-049](GAZ-049.md)・[GOV-232](../gov/GOV-232.md)）の空間的な延長とその両側の土地利用を、幕府の地図帳の目録レベルで記録する**。「白堀端通音羽町九町目橋」＝[GOV-233](../gov/GOV-233.md)の「音羽町九丁目橋上之方ゟ…」・[GAZ-035](GAZ-035.md)の九丁目橋・[GOV-238](../gov/GOV-238.md)の定請負橋数書付の音羽町九丁目橋と整合する方向の文言。「白堀端通」の道路概念は[GAZ-049](GAZ-049.md)⑬の「白堀通」と接続〕。
- **小日向竹嶋町の道路の沿革〔確認・repo初出〕**: 小日向竹嶋町（現・文京区関口・小日向側か）の文言——「**延宝以前ゟ上水端道内え出張（出張り）→ 元禄十七年十月大塚法華寺出火類焼後 北之方切縮メ道内ニ成**」＝**延宝以前の家屋が上水の端の道内に張り出していたのが、元禄17年（1704）10月の大塚法華寺の出火類焼後に北側が縮められて道内に整理された**＝**白堀端（上水端）の道路の整備史の沿革図書本来の記録**〔大塚法華寺の出火（元禄17年・[BOOK-131](../books/BOOK-131.md)等の類焼記録との対校候補）が小日向側の道路区画の変更の画期であることの記録〕。
- **位置づけ〔観察〕**: [GAZ-049](GAZ-049.md)（御府内備考・町方書上系）と[GOV-232](../gov/GOV-232.md)〜[GOV-237](../gov/GOV-237.md)（幕府の普請・見守の行政記録）に対し、**幕府普請奉行の地図帳（沿革図書）の目録から白堀端の空間的な実在を記録面で確認できる**。白堀端が大縄地の境目の基準であることは、白堀（神田上水）の小日向〜小石川区間の土地利用・町割の制約線としての性格を示す。**絵図本体（各年代の地図）の読図は本精読では実施していない**（OCRの目録部のみ）ため、1772年図等との照合（[GAZ-012](GAZ-012.md)の課題）は次段階。
