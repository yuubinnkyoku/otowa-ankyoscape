# [GAZ-152] 東京市史稿 市街篇第六（1929）— 白山御殿跡条の千川上水御堀引用の対校テキストと「字小石川」

## 書誌

東京市役所編纂『東京市史稿 市街篇 第六』（秀英社印刷・**昭和4年〔1929〕1月12日発行**・東京市長代理舟田〔舟橋?〕奥付）。NDL次世代デジタルライブラリー [book/3450785](https://lab.ndl.go.jp/dl/book/3450785)。市街史第六（市街恢弘時代・代官條目・老中麻布邊巡察・細川氏賜邸等の収録冊）で、白山御殿跡・戸崎町の各条は**御府内備考（純庸案）系の書上・考証の再録**と文面から読める（同頁に「-府內備考」の採録表記あり。OCR崩れ大で引用文言はすべて原画像照合前提）。

## 内容

- **白山御殿跡条の御薬園南西の小溝＝古御堀の名残の観察文言〔文言候補・repo初出の観察文言〕**: 「**今御藥園ノ西南ハ地低ク、西ヨリ南へ小溝ノ貫ケルハ、古ヘ御堀ノ名殘ナルヘシ**」＝**現在（編纂時点＝大正〜昭和初期）の御薬園〔小石川御薬園＝現・小石川植物園〕の南西の低地を西から南へ貫く小溝が、白山御殿の古い御堀の名残であるという観察**＝GAZ-102（御府内備考写本・近藤氏随筆引用の「惣堀へハ多摩川の水をかけ召れ 堀幅ハ十間程四方」）・[GAZ-083](GAZ-083.md)⑪（小石川志料・「五十の瀧」）の堀の実在とそれを20世紀まで残す地形の観察記録候補。〔堀の水理復元（千川上水・神田上水・谷端川との接続）は本条のみでは確定できない**〕〔**「御殿坂ト呼」という坂名の文言も同頁にあり（「圖ノ左方南ヨリ東ヘハ坂ニテ上レリ。御殿坂ト呼」＝掲出の正保年間図面との対応）、[GAZ-102](GAZ-102.md)戸崎町条の御殿坂と同じ地形アンカー**〕
- **千川上水の御堀引用の「或ノ舊記」文言の市街篇テキスト〔文言候補・[GAZ-083]⑫とほぼ同文の対校テキスト〕**: 「**此頃ハ千川上水此邊ヲ通シ、コノ御堀ヘモ引用セラレタルヨシ。或ノ舊記ニ、御門下町家ヘ御歩行目付堺庄兵衞申渡いハ、此度御堀之端ニ高札建申い、此趣相守御堀ヘチリアクタ捨不申、水アビ申間敷い、殊ニ風雨之節ハ心付可申云々**」＝**①千川上水が白山御殿（→御薬園）付近を通り、御堀にも引かれていた旨、②御堀の端に高札が建てられ、塵芥（チリアクタ＝塵芥投棄）と「水アビ」が禁止された旨の、御歩行目付堺庄兵衞の申渡文言**。〔**①[GAZ-083](GAZ-083.md)⑫2（小石川志料・明治11年刊）はほぼ同文「千川上水此辺ヲ通シ　コノ御堀へモ引用トラレタルヨシ…御門下町家へ御触(?)出シ　目付堺庄兵衛申渡候ハ…水アヒ(汲合?)申間敷候」を採録済みで、本条はその市街篇（編纂・活字）側のテキスト。対校上の相違点は（ａ）市街篇では「**御歩行目付**」と役職名が4文字で明示（小石川志料OCRは「御触(?)出シ　目付…」）＝**「御歩行目付」（歩行目付＝幕府の巡見・私募取緬役）の役職表記の確定に寄与しうる1票**、（ｂ）市街篇OCRは「**水アビ申間敷**」＝[GAZ-083](GAZ-083.md)注記の「水アヒ(汲合?)」すなわち水の汲み合い禁止候補に対し、**「水アビ」＝水浴び（水遊び）禁止の判読候補を支持する1票**（⚠️両者ともOCR由来のため、判読の確定は原画像照合まで保留・「アビ」対「アヒ(汲合?)」の対立は断定しない）、③「殊ニ風雨之節ハ心付可申」＝風雨の折の高札文言は水堀の養生（堀の破損・濁り防止か）を気遣う趣旨か、所在は要照合**〕**②の構造（千川上水→白山御殿御堀の引用）は千川上水の江戸市内末端部（小石川・白山側）の用途・流路の記録候補で、元禄第1期（小石川御殿・湯島聖堂・東叡山・浅草御殿への給水＝[GAZ-049](GAZ-049.md)⑫1【上水在絕記】）と安永9年〜天明6年再興期（本郷・湯島・下谷・浅草）のどちらの時点のStoryであるかは本文から確定しない（享保7年差止後の正徳年間に御殿は御引払〔[GAZ-083](GAZ-083.md)⑪〕で、御殿堀への上水引用は元禄第1期の記憶である可能性が高いが断定しない）**。
- **同条の地形考証の文脈**: 「**右方モ西ヨリ北ヘ同シク上リノ坂ナレバ、水利不便ニテ、カヽル御堀ノアルハ如何ト覺束ナケレト…**」＝御薬園の北西側が坂で上がる（水利に不便な）地形なのに御堀があるのは首肯し難い、という著者の不思議がった観察＋その答えとしての千川上水の引用「ヨシ」＋高札文言＝**御薬園の西〜南の低地・御堀・小溝の地形セットの考証の全体構造**。
- **戸崎町条の「字小石川」の別テキスト〔文言候補・[GAZ-102]の「古名小石川」との対校〕**: 「**右町內西南地尻之方二相流申候。字小石川ト相唱申候。尤水元流末之儀ト、同所白山御殿有之候ニ付右之通唱來申候**」＋「**右町内北之方前通ツキ白山御殿跡ニ往來之坂ニ御座候。御殿坂ト相申候**」＝**①戸崎町の西南地尻を流れる川を「字小石川」と唱える、②「水元流末之儀」（水元から流末に至る川の儀）の語を伴う、③白山御殿との関係でそう唱え来た、という申立**。〔[GAZ-102](GAZ-102.md)（御府内備考巻41-43写本）の「**下水ノ名當時ハ唱無之候得共古名小石川之由申伝候**」と同一の川（谷端川下流＝小石川）の別テキスト。**「古名小石川」（呼称は絶えた）vs「字小石川」（現に字・小字として唱える）の表現差は、（あ）同一原文のOCR崩れ、（い）書上の段階差（御府内備考の文政書上と市街篇の再録の間の実態変化）、の両方があり得るため断定しない**。GAZ-102側の丙戌書上（文政9年・1826）以降・明治刊行前の「字小石川」の実在の用例として対照表の小石川行への追記材料**〕**「段尻之方」の西南に当たるのは、谷端川（小石川）の戸崎町区間（[GOV-208](../gov/GOV-208.md)の小石川流路・凡そ二里三十二町五十間の町列記録・[BOOK-111](../books/BOOK-111.md)の戸崎橋通）と整合的に低地が町の西南に当たる地形**〕
- **陰性〔確認〕**: 本冊のOCR全体で「谷端」「弦巻」「水窪」「鶴巻」の川名の出現なし。「千川」の出現は白山御殿跡条の2件（同一箇所のOCR重複）のみ＝**市街篇6の千川上水関係は白山御殿跡条に集約**。雑司ヶ谷関係の文言（9件）は[GOV-344](../gov/GOV-344.md)（諸宗作事図帳の雑司ヶ谷御薬園→護国寺）・[GAZ-072](GAZ-072.md)に既出の材料の同系再録が主。

## 対校・位置づけ

- 本冊の白山御殿跡条・戸崎町条は**御府内備考（及び小石川志料）系の材料の市街篇（東京市役所編纂・活字刊本）での再録**で、独立の採集ではなく同じ祖本（純庸の原案・「或ノ舊記」＝高札の一次文書）に遡る対校テキストとして位置づける。**白山御殿跡条の考証の主（「今御藥園ノ西南…」の観察）が純庸本人のものか市街篇編者のものかは、[GAZ-083](GAZ-083.md)（小石川志料・巻之五の同条）との本文照合まで確定できない**（小石川志料の白山御殿蹟条〔⑪⑫〕には南西小溝の文言がOCR上確認できないため、ここが市街篇固有の文言である可能性も残る）。
- 別冊の市街篇22（3450802）の白山前町千川屋鋪の陸尺衆拝領文言（谷口捨次郎・内藤十五郎・六拾三坪）は[GAZ-034](GAZ-034.md)（御府内備考巻44・第114回追記）と同一文言群の再録（再確認済み・新規採録せず）。市街篇2（3450781）の「千川屋敷」2件は町奉行所与力同心屋敷系の列挙の中の言及（OCR列崩れ・性質の確定まで留保し本ファイルには採らない）。
