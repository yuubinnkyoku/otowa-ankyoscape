# [GAZ-160] 町方書上[50] 芝町方書上 四（文政10-11年）— 芝新細町条の金杉川・将監橋・榎川・玉川御上水渡樋

- **書誌〔確認〕**: 『[50] 芝町方書上　四』（写・NDL次世代デジタルライブラリー [book/2571531](https://lab.ndl.go.jp/dl/book/2571531)。NDL目録volume表記「[50] 芝町方書上　四」・直接確認）。芝浜松町壱〜四丁目（p5/16/35/49）・芝土手跡町（p63）・芝新細町（p80以降の見出し文言あり）・芝湊町（p137）の町条。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571531_{NNNNNNN}.txt`）。※金杉川（古川＝渋谷川下流の水系）は当repo四河川の下流側隣接水系で、[GAZ-103](GAZ-103.md)渋谷川総説の金杉落差・[GAZ-106](GAZ-106.md)麻布新堀総説の対校本となる文言群として採録する。
- **芝新細町条の金杉川の名称文言と川幅変遷〔文言候補・本冊最重要〕（p74-75）**: 「**右は町内南境に有之 芝新堀之末に而御堀 又は里俗に金杉川と唱申候 堀割年代相知不申**（p74）…**将監橋ゟ金杉御橋之間 川巾七間余之処 堀廣拾八間ニ相成 川上麻布十番迄之所（p74末）…川中拾壱間二相成 近辺両川岸通土手御築立二相成候処（p75）**」（p74-75・OCR）＝**①「芝新堀之末の御堀」＝里俗「金杉川」の呼称文言と堀割年代不知文言、②将監橋〜金杉橋間で川巾7間余→18間の拡幅、その後11間への変遷**（文言の継承関係はOCRの切れ目の復元を要する）。〔「新堀川＝金杉川」の下流側（芝側）の呼称層の一次文言＝[GAZ-103]渋谷川総説「芝の邊にて新堀川と唱へ金杉にて海へおちいれり」の町方側の対応文言候補。〕
- **延宝3卯年の川御渡と元禄11寅年の船入文言〔文言候補・GAZ-106の元資料側対校〕（p75-76）**: 「**其後延宝三卯年中 御奉行石川蔵人様・岡田将監様御掛二而川御渡有之 猶又元禄十一寅年 麻布御殿御普請之砌 金杉川口ゟ渋谷迄川御渡有之 川上川巾壱間余之処 堀廣舩入二相成申候 此節御掛御奉行稲生七郎右衛門様・奥田八郎右エ門様 御手伝溝口信濃守様・伊達美作守様ニ御座候旨書留有之候**」（p75・OCR）＋「**川御渡有之候節初而相掛其節御奉行岡田将監様御掛ニ付将監橋と相唱候旨申伝候由 古絵図に記有之候得は延宝三卯年…比橋初而相掛候儀と奉存候**」（p76・OCR＝牧野〔OCR・原字要照合〕橋の条）＝**①延宝3卯年（1675）の川御渡（石川蔵人・岡田将監の御掛）、②元禄11寅年（1698）の金杉川口〜渋谷の川御渡（麻布御殿御普請の砌・船入への掘拡・川巾1間余の堀広）、③「将監橋」の名義文言（川御渡の節に初めて相掛・御奉行岡田将監の御掛に由来・延宝3年比の橋の初掛の自己推定付き）**。〔**[GAZ-106](GAZ-106.md)（御府内備考麻布巻）の元禄11年文言（「金杉川口より渋谷迄川御渡ニ而…船入ニ相成」＋稲生七郎右衛門・奥田八郎右衞門・溝口信濃守・伊達美作守）と文言・役名がほぼ一致する芝側（新細町）の独立witness**＝麻布新堀成立論（延宝3舟入・元禄11-12堀普請・飢民救済説）の芝側からの裏付け対校、ただし本冊は元禄11を「麻布御殿御普請の砌」と記す点が寛文8新規普請文言候補〔[GAZ-159](GAZ-159.md)〕・飢人御救文言候補〔GAZ-159・GAZ-106の江戸鹿子引用〕と並んで第4の由来説明となる（どの説明が正しいかは断定しない）。延宝3文言は[GAZ-159]の「延宝三卯年之頃…御浚…其節同時に赤羽橋新規御掛渡」文言と同年で互补（赤羽橋〔麻布側〕と将監橋〔芝側〕が同年の川普請に伴う架橋と読める＝同一事件性は年次・役名一致に基づく候補に留める）。〕
- **増上寺御構堀大下水＝里俗「榎川」と芝側流路文言〔文言候補・repo初出の榎川第2用例〕（p77-78）**: 「**一町内西境 増上寺御構堀大下水之儀は 巾弐間 上之方は愛宕下通大下水 里俗に榎川と唱候末ニ而 宇田川横町西境二而分水仕 芝神明社地後ゟ増上寺表御門前通…際え落入金杉川江相流申候**」（p77-78・OCR）＝**①巾2間の大下水、②上流は愛宕下通大下水で里俗に「榎川」と唱える、③宇田川横町西境で分水し、④芝神明社地の後ろ〜増上寺表御門前通を経て金杉川へ落入する、の流路構造**。〔「榎川」の用例は[GAZ-112](GAZ-112.md)四谷坂町の大下水の里俗名（第213回追記・OCR崩れ候補）に続く**第2の用例で、場所は別地（芝愛宕下）**＝「榎川」呼称が四谷と芝の2箇所に見られる別地用例となる（同一水路かは位置から断定しないが愛宕下と四谷坂町では離れており別水路の可能性が高い・いずれも原画像照合前提）。芝側の下水経路（愛宕下→宇田川横町境→神明社→増上寺前→金杉川）流路復元の一次文言候補。〕
- **玉川御上水渡樋の文言〔文言候補・repo初出候補〕（p78）**: 「**一玉川御上水渡樋 樋長拾三間 但壱尺六寸四方 高塀弐ヶ所 高サ壱丈宛 巾三尺四方 同駒寄矢来 高サ五尺 右渡樋将監橋西之方 橋並之間七尺隔弐渡?（OCR・原字要照合） 南北橋台際両芝間二高枡弐ヶ所有之 松平豊後守様御一手持二而 町内持には無御座候得共 当町地先之儀二付此段申上候**」（p78・OCR）＝**樋長13間・1尺6寸四方・高塀2ヶ所（高さ1丈・巾3尺四方）・駒寄矢来（高さ5尺）・将監橋の西で橋並の間7尺隔てた水路・南北橋台際に高枡2ヶ所を持つ「玉川御上水渡樋」の構造文言**（松平豊後守の御一手持で町内持ではない）。〔将監橋（汐留）西の金杉川畔の「玉川御上水」の渡樋＝江戸市中の玉川上水系水路の末端（汐留側）の構造物の町方側記録候補。渡樋の名称（樋）と樋筋の向き（金杉川を渡るか・沿うか）、「弐渡」の判読は原画像照合前提で構造の解釈は断定しない。上水差止（享保7）以後の文政期に「御一手持」として残存管理されていたか（文言は当時の所持帰属を記す）は今後の対校課題。〕
