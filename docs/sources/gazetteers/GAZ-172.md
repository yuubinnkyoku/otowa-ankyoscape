# [GAZ-172] 町方書上[116] 南本所 — 元町条の桑平川・源森川・横川文言

- **書誌〔確認〕**: 『[116] 南本所町方書上』（写・NDL次世代デジタルライブラリー [book/2571597](https://lab.ndl.go.jp/dl/book/2571597)。NDL API volume欄直接確認）。南本所元町条（koma 23-25・文政十一年十一月名主友太郎署名）と後段の町条（koma 48・町名条区切りは要照合）。引用文言はすべてOCR由来で要原文照合。
- **横川の里俗名「桑平川」・「源森川」の呼び分け文言〔文言候補・本冊最重要〕（koma 23）**: 「**一横川幅凡拾七間程 但川中央境にて町内持分 長凡三拾四間弐尺程 右は町内南之方を相流れ入切ゟ東之方迄 近来桑平川とも相唱 〆切より西之方を源森川と申候 万治二亥年中初而御堀割有之候**」（koma 23・OCR）＝**①横川の巾がおよそ17間（本町持分は川中央境で長さ34間2尺）、②近来「桑平川」とも唱えられる（OCR候補）、③〆切より西側を「源森川」と呼ぶ、④万治2年（1659）に初めて堀割**という文言候補。〔**横川の同一区間に対する呼称の空間的呼び分け（〆切を境に東=桑平川?西=源森川）を一次側で記す文言（repo初出候補）**。「桑平川」の字（OCR判読候補・候補字の余地あり）と、源森川の西側呼称は[GAZ-138](GAZ-138.md)（小梅瓦町条・「年暦不取知 後 東之方は東源森川 或ハ横川入堀…西之方は源森川ト唱」）の呼称群に接続する。**両文言で「源森川の使われる区間の具体（文政期時点では〆切の西）」が固まる材料**。巾17間は[GAZ-168](GAZ-168.md)（20間）・[GAZ-170](GAZ-170.md)（20間）と対立するため、原画像照合・測区間差の両方の可能性を残す。〕
- **享保16年伊奈半左衛門の土手敷築立文言（koma 23）**: 「**一土手敷弐月（=弐ヶ所?） 右は町内南側裏河岸通に有之 享保十六亥年中 御代官伊奈半左衛門様御掛りにて御築立有之候**」（koma 23・OCR）＝**享保16年（1741）・伊奈半左衛門（関東郡代伊奈家）の御掛で土手敷（裏河岸通）を築立**した文言候補。〔本所上水系の伊奈家の関与は[GAZ-165](GAZ-165.md)（元禄3年伊奈半十郎・松平美濃守・稲生下野守の御伺）等に続く系統の享保16年datapoint（奉行廃止〔享保4年〕後の代官所側の河岸整備）。「弐月」は「弐ヶ所」のOCR候補。〕
- **文政7年の新規御掛直文言（koma 48・後段の町条）**: 「**…御奉行徳山又兵衛様山崎四郎左衛門様御掛り二而初而御掛渡有之 其後度々新規御掛ケ直又者（?）御修復等有之 猶又五ヶ年以前 文政七申年十一月中新規御掛直有之候 町方定川方御掛に御座候**」（koma 48・OCR）＝**（何橋かの樋/橋の）初懸（徳山又兵衛〔=五兵衛OCR変種候補〕・山崎四郎左衛門）→文政7年（1824）11月の新規掛直（町方定・川方御掛）**という文言候補。〔同じ冊内で「万治2年堀割系の奉行名」が「徳山又兵衛様」と現れるOCR変種（五兵衛/又兵衛）の存在を記録（[GAZ-165]の佐山/徳山対立に追加）。koma 48の条帰属（元町条の続きか別町条か）は要照合。文政7申年=甲申で干支整合。〕
- **元禄10年検地・瓦竃文言（koma 24-25）**: 「**御検地之儀者 元禄十丑年十二月中 酒井河内守様御改御座候**」（koma 24・OCR）＋「**文化六丑年迄町内瓦師利左衛門方ニ而瓦竃焚申候処其後相止メ当時瓦職之者無御座候**」（koma 25・OCR）＝南本所元町の元禄10年（1697）検地（酒井河内守）と、文化6年（1803）まで町内で瓦竃が焚かれていた記録。〔中之郷・小梅側の瓦町（[GAZ-174](GAZ-174.md)・[GAZ-138](GAZ-138.md)）と並ぶ**本所側の瓦生産地の分散**の観察材料（瓦土・瓦師・瓦竃系の流通は未確定として記録のみ）。〕
