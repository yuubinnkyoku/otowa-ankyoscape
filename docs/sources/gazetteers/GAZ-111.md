# [GAZ-111] 御府内備考 巻64-66（四谷之四〜六・写本OCR）— 淀橋町条の「定橋」と神田御上水30間4間

- **書誌〔確認〕**: 『御府内備考』巻之六十四（四谷之四・伊賀町・忍町・内藤宿…）・六十五（四谷之五・附録鮫ヶ橋…）・六十六（四谷之六・付録麹町十一〜十三丁目・柏木・成子町・「濱橋町」〔＝澱橋町推定・後述〕・角筈・長楽寺門前・多聞院門前）の合冊写本。NDL lab [book/2553681](https://lab.ndl.go.jp/dl/book/2553681)。本文OCR頁番号2553681_0000142〜143に澱橋町条該当部、0000148に角筈条。**引用文言はすべてくずし字OCR由来で原画像照合を要する。**
- **本登録の性格**: 千川上水・神田上水の淀橋・角筈区間（十二社・代々木助水堀系）の江戸町方書上の初記録化。巻6上水章の助水条（[GAZ-107](GAZ-107.md)）と突き合わせると淀橋町を流れる「神田御上水」の水系比定の核心資料になる。

## 第212回の読取（2026-11-20）

- **町名の同定＝OCR「濱橋町」は澱橋町の判読対立候補〔要原画像照合〕**: 巻66目録の町列「麹町十一〜十三丁目・柏木・成子町・□濱橋町・角筈・長楽寺門前・多聞院門前」（OCR）と、柏木条・成子町条の本文中の「當町并浜(?)橋町境横町」「寺町濱橋町江附共方ヲ里俗上町…（OCR）」にある町は、①同巻の成子町条が「**下の淀橋も同し（柏木村の内在町であること）**」と隣接町を「淀橋」と言及する、②該当町条（後述）が神田御上水に架かる橋に由来する町名と自称する、ことから**OCRが「濱橋／浜橋」と読む町は「澱橋（淀橋）町」である可能性が最も高い**。くずし字の「澱」の OCR 誤読候補として扱い、原画像照合まで断定しない。
- **澱橋町条の「定橋」＝町名の由来橋〔文言候補・repo初出の橋名と神田御上水文言〕**: 「**尤町名之き(儀)は町内末西之方神田御上水江掛り候橋ヲ定橋と申御放(?)如斯唱申候町内北側町屋東西間四百三拾七万(?)…四隣東之方同所成子町西之方御代宝所中軽邨(=中野村候補)南之方御代官所角筈村北之方鱗磯院??栃木邨(?)（OCR）**」＋「**橘(?)右者当町西之方ニ有之浜(澱?)橋之唱申候享保之比上ハ姿不見之橋と申候由右以来に水車跡兵衛と申者神田御上水ヲ堰留水車渡無致候然候処享保年中有治院様中野筋御成之節山城国溢(?)水車ニ顕置（中略）有之由二而右橋ヲ定橋へ被申上意有之由申伝に御座候尤右橋之儀は御普請方御掛に而町内持には無御座候得共最寄に付此段申上候（OCR）**」＝**①町名は町内の末西の方の神田御上水に掛かる橋「定橋」に由来（里俗の唱え）、②当町の西にある（澱）橋と唱える由で、享保の比には姿を見せなかった（姿不見之）橋、③それ以来・水車跡兵衛（OCR・巻6助水条の「淀橋町久兵衛」と判読対立候補）という者が神田御上水を堰き留めて水車を仕た、④享保年中に有治院様（8代将軍吉宗候補・OCR・院号要照合）の中野筋御成の節に（取締り？顕置？＝判読保留）の御上意により右の橋を「定橋」と申上（命名）したと申伝、⑤橋は御普請方御掛で町持ちではなく、最寄りにつき町から申上げる**。〔**「定橋」の橋名＝repo初出候補。水車堰留と将軍御成を契機とする橋名改称の物語の町方伝承書上。**橋の「以前は姿見えず」の文言＝上水堀の暗渠化・地形改変の候補。人名「水車跡兵衛」は巻6「淀橋町久兵衛持水車」（GAZ-107）と対校すると「水車主久兵衛」の誤読の可能性が高い（要照合）。〕
- **神田御上水の規模と流路文言〔文言候補・repo初出の区間明細〕**: 「**神田御上水長三拾間巾四間右当町内ニ掛り町内と多摩郡境ヲ相流申候尤中野村江隣二本郷村角笹邨(?)ゟ小富町(?)地先二掛り末は板木(=幡木=幡ヶ谷村候補)村中野村江相流申候右御工水之儀は無礼村井之駅(?)池ゟ流古水に御座候（OCR）**」＝**①神田御上水は長30間・巾4間で当町内に掛かり、町内と多摩郡の境を相流し、②中野村に隣り・本郷村・角笹邨(OCR候補=角筈村)から小富町(OCR候補=小田町?笹塚?)の地先に掛かり、末は板木(幡木=幡ヶ谷村候補)村・中野村へ相流す、③この御用水の儀は「本家村井之駅池より流す（流し来り）水」候補文言（OCR崩壊部）**。〔**淀橋町内の神田御上水（長30間・巾4間）が町内と多摩郡との境を流れ、本郷村・幡ヶ谷方面へ相流す流路の町方書上はrepo初出**。③の文言はOCR高度崩壊で、原字候補は「本家村井之頭池ゟ流シヰ(?)来リ水」（神田上水本流系）のほか「玉川上水」説もあり、原画像照合まで決めない。**巻6上水章の「玉川上水代々木村より神田上水の助水口あり淀橋町久兵衛持水車へ掛り直に神田上水へ落合此堀筋土橋三ケ所御普請所にして都而久兵衛進退す」（〔GAZ-107〕）と対校すると、本条の「神田御上水」は代々木村方面からの助水堀（玉川上水系・十二社用水前史候補）である可能性が強まり、同時に町方側はこの堀を「神田御上水」と呼んでいた実態が読み取れる**（千川上水との関係〔第212回前半の仮説〕は本対校で一段弱まり、改めて千川上水本流側の記録〔GOV群〕と突き合わせて決める。水車堰の久兵衛の事業体は両文言で共通しており、個人の比定から寄り道はしない）。〕
- **角筈長楽寺門前条の帰属按語〔文言候補・repo初出〕**: 「**角筈長楽寺門前□此辺も四ツ谷内のことくおもへるハ誤なり全く角筈村に属す**」＋「**門前町家起立之儀は寛延年中焼先仕相故起立聢と相分不申候得共古門前町屋二而町御奉行御支配二御座候町内東西武拾八間南北八間…四隣東之方御代宝所角開邨西之方杏平窪太貞一?郎様御抱屋鋪南之方代々木邨北之方地主長原（楽）寺（OCR）**」＝**①この辺（角筈長楽寺門前）も四谷内のように思うのは誤りで、全く角筈村に属す、②門前町家の起立は寛延年中（の火事?焼失）に由来か詳細不知・古くは門前町屋で町奉行支配、四隣の村名（杏平窪〔OCR〕・代々木村など）**。〔**角筈=四谷境界の位置づけ論の按語（repo初出）＝千川上水・神田上水区間の「府内外」境界の証言**（角筈村＝千川上水経由地〔[GOV-220](../gov/GOV-220.md)系〕。「杏平窪」等の小名の判読は要照合）。〕
- **柏木・成子町条の石橋・小水〔文言候補・対校群〕**: 成子町条「**夫石橋巾三間四尺五寸（?）右当町東之方二水と掛渡シ有之候石橋巾壱間四尺右当町西之方可水江掛渡シ有之候小水長両側に而三百五拾間程巾弐尺…右当町并浜(澱)橋町境横町両町掛当町ゟ淀橋町江流申同下水長両側高(?)百五拾間程巾弐尺…花木(=幡木/幡ヶ谷村候補)村江流申候（OCR）**」＝**成子町の東西の小水（巾2尺・長350間と150間）に石橋2か所（巾3間4尺5寸・巾1間4尺）、一方は淀橋町へ流れ、他方は幡ヶ谷村（候補）方面へ流れる**。〔淀橋町・柏木・成子町・角筈の町村境の小水路群＝神田御上水の周辺排水の実態記録。判読対立多く要原画像。里俗名「雷久保」・「角谷横町」・「土内様坂」等の町内小名も同巻に見える（抄録）。〕

## 制限・未解決

- ①引用文言はくずし字OCR高度崩壊部を多く含む（「濱橋町＝澱橋町」推定を含め、特に「御放如斯」「水車跡兵衛」「山城国溢水車ニ顕置」「中軽邨」「角笹邨」「小富町」「板木村」「井之駅池」「無礼村」等の判読対立はすべて原画像照合前提）。②淀橋町条の「神田御上水」の水系比定（玉川上水系助水=十二社用水前史 vs 千川上水 vs 井之頭池系）は本書内部の対校 + 千川上水側記録の対校で決める（本条で決定しない）。③「定橋」改称の御上意説の史実性（吉宗中野筋御成の史実対応）は申伝留保のまま扱う。④巻61-63（四谷之一〜三・2553680）は「策の井」等の目録文言があったが、河川文言はほぼ無く本回は資料登録しなかった（角筈2・淀橋2は目録行のみ）。⑤柏木条・成子町条の条境の判別（OCRの町条の切れ目）は原画像照合で行う。
