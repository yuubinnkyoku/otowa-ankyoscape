# [GAZ-155] 町方書上[66] 四谷附録（文政10亥年）— 玉川上水万年石樋分水路の流路詳細と付帯文言群

- **書誌〔確認〕**: 『[66] 四谷町方書上　附録　全』（写・NDL次世代デジタルライブラリー [book/2571547](https://lab.ndl.go.jp/dl/book/2571547)）。文政10亥年（1827）10月付けの四谷伝馬町条の付帯文言群（附録）で、四谷御門外左右の高枡・万年石樋・井・坂・里俗地名等の「町内を持たない（or 委譲対象の）」名所・水路の記述を独立的に収める。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571547_{NNNNNNN}.txt`）。
- **四谷御門外左右の高枡＝万年石樋分水路の流路詳細文言〔文言候補・本冊最重要〕（p15-17）**: 「**一四谷御門外左右ニ高枡有之 右ハ御上水万年石樋西之方 四谷塩町三丁目ゟ相流 東之方 麹町拾三丁目里俗箱根屋横町ニ而北之方え分水 同町裏通リ里俗中箪笥町往還枡え掛リ 水路両口二相成 一口ハ右中箪笥町往還土中西ゟ東え相流 同町角里俗大横町出枡え懸リ 大横丁通南ゟ北え相流 麹町拾弐丁目往還南之方…出枡え掛リ 従夫同所拾壱丁目 四谷御門外南角高枡え至リ 同所御門内 麹町拾丁同南側樋え入 同所壱丁目 半蔵御門外南枡え流入 御本丸え掛リ候由 同一ト口ハ前書中御箪笥町往還枡ゟ北之方 里俗裏御箪笥町角往還出枡え掛リ 同町往還土中ヲ相流 麹町拾弐丁目北之方出桝え掛リ 従夫同所拾壱丁目 四谷御門外北角高枡え掛リ 同御門内 麹町拾丁同北側樋え入 同所壱丁目 半蔵御門外北之方桝え入 吹上御庭え相掛リ候由二御座候**」（p15-17・OCR・「…」部は麹町拾弐丁目往還南之方の直後の読み継ぎ）＝**①四谷御門外の左右の高枡は御上水万年石樋の西之方（四谷塩町三丁目）から相流れ、東之方（麹町13丁目）の里俗箱根屋横町で北之方へ分水する、②中箪笥町往還の枡に掛り、水路は両口に分かれる、③第一口＝中箪笥町往還土中を西→東に流れ、大横町の出枡→大横丁通を南→北へ、麹町12丁目→11丁目経由で四谷御門外南角の高枡→御門内麹町10丁目の南側の樋→半蔵御門外南枡→御本丸へ掛る、④第二口＝中箪笥町往還の枡→北之方の裏御箪笥町角の出枡→麹町12丁目北之方の出桝→四谷御門外北角の高枡→御門内麹町10丁目北側の樋→半蔵御門外北之方の桝→吹上御庭へ相掛る**という流路文言候補。〔**万年石樋（四谷＝玉川上水の市中埋設樋、[GAZ-112](GAZ-112.md)伝馬町条・[GAZ-143](GAZ-143.md)・[GAZ-141](GAZ-141.md)塩町条）の分水が、麹町13丁目の箱根屋横町で北へ分岐し、中箪笥町枡で両口に分かれて、南回りが御本丸へ・北回りが半蔵御門外北之方の桝から吹上御庭へ至るという末端の二口構造の詳細**＝[GAZ-128](GAZ-128.md)（麹町11丁目条の「御本丸掛・吹上掛樋2筋」）の文言の四谷側（附録）からの対応記録で、分水経路の地図レベルの特定に資する対校材料。吹上御庭＝江戸城吹上の御庭。抽象的な「~樋」「~枡」「~高枡」の所在の微地形の割出しは要原画像・古地図照合。〕
- **桜川・紅葉川・太田川の三川委譲文言＋筆之井・鏡之井〔文言候補・repo初出候補〕（p17）**: 「**一桜川 紅葉川 太田川 右三ケ所之儀ハ同所塩町三丁目ゟ委細申上候 一筆之井 右ハ武州多摩郡角谷村 松平中務大輔様御下屋鋪内ニ有之候由 一鏡之井 右同断 一久左衛門坂 右ハ大久保辺ニ有之候由 在所不詳候**」（p17・OCR）＝**①桜川・紅葉川・太田川の三川の委細は（附録ではなく）塩町三丁目が申上るという委譲文言、②「筆之井」は武州多摩郡角谷村の松平中務大輔様御下屋敷内にあるという由、③「鏡之井」も同断（角谷村御下屋敷内）という由、④「久左衛門坂」は大久保辺にあるが在所不詳という由**という文言群候補。〔**①の三川委譲文言は、桜川（[GAZ-154](GAZ-154.md)・[GAZ-110](GAZ-110.md)修行寺門前条）・紅葉川（[GAZ-108](GAZ-108.md)牛込総説の紅葉堀語群）・太田川（[GAZ-112](GAZ-112.md)太田橋語群）の詳細供述が塩町三丁目条に集中する実務構造の附録側の確認＝場所的な委譲指示の存在そのものが、これらの川名が四谷周辺で通用する名であった傍証候補。②筆之井・鏡之井はrepo初出の井名候補**（角谷村＝現在の赤坂・四谷周辺の多摩郡村の比定および井の位置の特定は要照合。「筆之井」の原字〔筆之井・筆井・不二井等〕もOCR照合前提。③久左衛門坂は大久保辺の坂名候補（所在不詳の記録自体が情報）。〕
- **御堀高札文言＝御堀の水利用の禁止〔文言候補〕（p21）**: 「**一四谷御門外御堀端ニ有之御高札御文言左之通 此御堀ニテ水ヲあひ 又ハ魚鳥ヲ取 ちり芥捨ル輩アラハ可為曲事ノ者也二月 右ハ麹町拾壱丁目持場ニ御座候間 同町ゟ委細可申上候**」（p21・OCR）＝**①四谷御門外の御堀端の御高札の文言：「此の御堀にて水をあい、又は魚鳥を取り、塵芥を捨てる輩あらば曲事たるべし」、②当該箇所は麹町11丁目の持場なので委細は同町が申上る**という文言候補。〔**「水あい（水アヒ）」＝御堀の水の汲み取り等の利用の禁止文言**＝[GAZ-152](GAZ-152.md)（東京市史稿市街篇六・御歩行目付堺庄兵衛の「水アビ申間敷」文言の「或ノ舊記」引用）の系譜に、四谷御門外御堀の高札実例の文言を加える対校材料（高札文言そのものの設置年次の明示は無く、書上時点で存在していた文言の記録）。〕
- **四谷御門・御堀・御多門の寛永13子年同時起立文言〔文言候補・年次情報〕（p14）**: 「**四谷御門御起立大略申伝 御入国之節ゟ元和之末迄ハ御櫓御多門モ無之 唯双枡形木戸斗ニ而 其頃わツ屋口ト而已唱来候処 寛永十三子年新規御堀出来 御多**（門御櫓等の起立・続く・OCR）」＋「御堀揚土之儀者 御土手ニ相成 又ハ武州豊嶋郡貝塚領上一ツ木村ノ内入江埋土ニ頂戴仕候由申伝候」＝**①四谷御門は御入国之節（徳川家康の江戸入城の由）から元和の末まで御櫓・御多門が無く、双枡形の木戸のみで「わつ屋口（＝四ツ谷口の崩し）」と唱えていた、②寛永13子年（1636）に新規の御堀が出来て御多門・御櫓が起立した、③御堀の揚土は御土手に相成り、あるいは豊嶋郡貝塚領上一ツ木村の内の入江の埋土に頂戴した**という申伝文言候補。〔**四谷御堀の寛永13年起立の年次は、御府内備考・[GOV-224](../gov/GOV-224.md)系統の四谷御門史料の対校情報**。「入江埋土に頂戴」の文言は、御堀掘削の土砂の処分先（上一ツ木村の入江＝低湿地の埋め立て）の記録で、江戸城周辺の地形改変の実務を思わせる文言候補（要照合）。〕
- **東福院坂・女夫坂・汐干の里等の附録の坂・地名群〔文言候補・参考〕（p20-21など）**: 「**一四谷伝馬町弐丁目南側東境 里俗天王横町ゟ鮫河橋谷町え往返之坂ヲ里俗東福院坂ト唱来候 右ハ此坂西側ニ護持院末真言宗 立勤山東福院ト唱候寺院有之ニ付 古来ゟ唱来候**」＋「**一女夫坂 右ハ同所伝馬町新壱丁目ゟ委細申上候**」＋「**一汐干之里一名潮踏野 右ハ四谷塩町三丁目ゟ委細申上候**」等（p20-21・OCR）＝**①東福院坂＝四谷伝馬町弐丁目の東境（里俗天王横町）から鮫河橋谷町へ往返する坂で、西側の護持院末・東福院にちなむ、②女夫坂（伝馬町新壱丁目へ委譲）、③汐干之里・一名潮踏野（塩町三丁目へ委譲）**という附録の坂・地名群の文言候補。〔**東福院坂が「鮫河橋谷町え往返之坂」とされる文言は、[GAZ-100](GAZ-100.md)（西影橋・東福院坂の従来記録）に、坂が結ぶ谷（鮫河橋谷町＝現在の新宿区若葉町周辺）の側への接続を示す付加文言候補。前回見送りの[GAZ-1506]系統（鮫河橋・権田原）も含めた坂谷系の整合の材料。〕

## 制限・未解決

- ①すべてOCR由来。「箱根屋横町」「大横町」「裏御箪笥町」等の里俗横丁名の表記、樋・枡・高枡の序列の読み取りは、p15-17の原画像（縦割レイアウト崩壊の可能性）の目視照合が前提。②「吹上御庭江相掛リ候由」の構造（吹上御庭への給水樋の末端）は、[GAZ-128](GAZ-128.md)麹町11丁目条の「御本丸掛・吹上掛樋2筋」との対校で、分水の二口の行き先（御本丸／吹上御庭）の対応関係を確定する必要がある（本冊だけでは「南回り=御本丸・北回り=吹上」と読めるが断定しない）。③筆之井・鏡之井の所在（角谷村の松平中務大輔様御下屋敷（松平前橋家系の角谷御屋敷の候補・比定は保留））の比定と、井の現地の特定は要照合。④「わつ屋口」の判読（四ツ谷口の崩し候補）は要原文照合。「貝塚領上一ツ木村」の「貝塚領」の判読も確定しない。
