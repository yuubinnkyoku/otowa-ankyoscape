# [GAZ-180] 町方書上[53] 芝町方書上　七（文政10亥）— 金杉川の全流路・橋列の裏町（金杉裏壱町目）側文言と寛文7年川幅拡張

- **書誌〔確認〕**: 『[53] 芝町方書上　七』（写・NDL次世代デジタルライブラリー [book/2571534](https://lab.ndl.go.jp/dl/book/2571534)。NDL目録volume表記「[53] 芝町方書上　七」・APIで直接確認。表紙通し番号「二七四ノ第五十四」）。収録は芝金杉裏壱町目〜五町目・附上高輪町之内寄洲築立地訳書等。条は文政10亥年（1827）8月提出（同帯の定型署名）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571534_{NNNNNNN}.txt`）。
- **金杉裏壱町目条の金杉川全流路・橋列文言〔文言候補・本冊最重要〕（p14）**: 「**一同目金杉川と相唱候 赤羽根橋上ニ而者新堀川与似回候 町内自身番屋裏手之方二而川中拾八間程 河岸通末ニ而弐拾間程 川中央を境ニ仕金杉惣町内持ニ御座候 右は町内北境二有之 水上武州原郡下渋谷村ゟ 麻布相模橋 肥後橋 三田久保町漬(?) 一之橋 麻布十番二之橋 中之橋 赤村佐橋 芝将監橋 金杉橋 川口ゟ 海上江流入申候 堀割年代相分不申候**」（p14・OCR）＝**①金杉裏壱町目の北境を流れる川＝「金杉川」（同一目〔＝金杉裏壱町目〕の川名）、②赤羽根橋上流側では新堀川と一緒に（「与似回候」＝並行・合流と読めるが判読要照合）回る、③川幅（川中18間余・河岸通末20間余・川中央を境に金杉惣町内持）、④水上＝武州荏原（原とあるがOCR崩れ候補）郡下渋谷村から、⑤橋列＝麻布相模橋・肥後橋・三田久保町through(?)・一之橋・麻布十番二之橋・中之橋・赤村佐橋・芝将監橋・金杉橋・川口、を経て海上に流入、⑥堀割年代は不知、の6点**。〔**金杉川（＝渋谷川下流の芝側区間の里俗名）の全流路を上流（下渋谷村）から河口（川口→海）まで橋名で列記する町方側文言**＝[GAZ-103](GAZ-103.md)渋谷川総説（元ハ西千駄ヶ谷…芝の邊にて新堀川と唱へ金杉にて海へおちいれり）・[GAZ-112](GAZ-112.md)吐水系統（相模殿橋・肥後殿橋→…→芝中ノ橋・赤羽根橋→増上寺脇将監橋・金杉橋→海・「古川之八ツ橋」）・[GAZ-160](GAZ-160.md)金杉川名称文言（芝新堀之末の御堀）に対する**裏町（金杉裏）側の第3の独立witness**。橋名の表記対立（「相模橋／相模殿橋」「赤村佐橋／赤羽根橋」〔OCR崩れ候補〕「三田久保町漬」〔判読不能〕）は原画像照合まで決めない。「赤羽根橋上ニ而者新堀川与似回候」＝金杉川と新堀川（赤羽新堀川）の下流部での合流・並行を示す候補文言で、[GAZ-159](GAZ-159.md)赤羽新堀川の三度の工事年代記の「金杉川口」との地点対校材料。〕
- **寛文7未年10月の川幅拡張と屋敷地収用文言〔文言候補〕（p14-15）**: 「**寛文七未年十月川幅御堀廣ケ有之候二付 町内家持三右衛門・又右衛門(?)・五郎兵衛・利兵衛・惣右衛門・源右衛門(?)・伊太郎・兵右衛門殿 佐野福河弥(?)殿 都合八人所持屋敷合三千弐百四拾坪五合御用地二被召上 三田有馬中務大輔様御上屋敷前ニ而当分拝借地被仰付候**」（p14-15・OCR）＝**寛文7年（1667）10月の川幅拡張に伴い8人の家持の屋敷地合計3,240坪5合が御用地に召し上げられ、三田有馬中務大輔様御上屋敷前の当分拝借地が代地として下された、という川普請に伴う用地収用・代地の実務文言**。〔**同帯の[49]芝神明門前端（[2571530](https://lab.ndl.go.jp/dl/book/2571530)）p63「寛文七未年八月中金杉橋際御多門相建候御沙汰ニ付右川幅堀底ニ相成候ニ付両町南之方地先…被召上 三田有馬中務大輔様御上屋敷前に而当分拝借地被仰付」とほぼ同一事件と読める事件の、金杉裏側の独立witness**＝寛文7年金杉橋際の川幅（堀底）化の御多門建設を含む下流部改修の月日対立（八月／十月）と被害・代地の集計例（対校と同定は原画像照合まで保留）。[GAZ-160]川巾3段変遷（7間余→18間→11間）の最初の変化（7間余→18間）に対応する改修事件の候補（対応の断定はしない）。〕
- **取払済みの旧橋の「絵図面二のみ」文言〔文言候補〕（p15）**: 「**一橋弥(?)右は町内北境河岸通当時自身番屋有之候裏手之方ゟ芝湊町江掛ケ渡候様子二相見へ候 古来掛始幷取払候年月其外橋幅等相知不申 橋之形斗絵図面二有之候**」（p15・OCR）＝**金杉裏壱町目北境河岸通の裏手から芝湊町へ掛け渡されたと見える旧橋で、掛始・取払の年月・橋幅ともに不知で「橋の形だけが絵図面にある」という消滅橋の文言**。〔町方書上段階で既に取払われた川橋の実務記録＝橋跡資料として「絵図面にのみ残る橋」の類例。比定は保留（芝湊町に渡る川川を跨ぐ橋なら金杉川下流部の海岸寄りか）。〕
- **台帳類の委譲定型文言〔確認・既知類型〕（p16ほか）**: 「**三田上水跡之儀は金杉通壱町目ゟ申上候通二御座候**」（p16）ほか金杉裏各町目・上高輪町之内寄洲条に連続＝[GAZ-161](GAZ-161.md)第230回採録の「金杉通壱町目への委譲定型文言群」と同型（対校のみ・本ファイルでは採録対象としない）。
