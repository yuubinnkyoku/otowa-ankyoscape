# [GAZ-175] 町方書上[122] 深川 三 — 桶師町条の黒口川・黒江川・「水道附キ」文言

- **書誌〔確認〕**: 『[122] 深川町方書上 三』（写・NDL次世代デジタルライブラリー [book/2571603](https://lab.ndl.go.jp/dl/book/2571603)。NDL API volume欄直接確認）。深川桶師町条（koma 64-66）。引用文言はすべてOCR由来で要原文照合。※第223回の本冊boilerplate陰性判定（四河川keyword）は以下の文言を捉えていなかった＝本回訂正。
- **黒口川＝黒江川＝「水道附キ」の川筋文言〔文言候補・本冊最重要〕（koma 64-65）**: 「**…尤当町黒口橋際ゟ八幡橋際迄之内一名二黒口川と唱候義は 桶師町起立以前小留所干潟ニ有之候砌 右川筋之処水道附キ有之 其比黒江川而唱候と申義ヲ以 寛永六己年当所築立之節右ヲ川筋附則黒江川ゟ留候旨申伝有之候 川巾之儀は八幡橋際八間半 久中橋西之方拾弐間 同東之方五間 黒江橋際七間 東の方蛤町佐賀町代地南本所代地向合之所川巾拾五間に御座候**」（koma 65・OCR）＝**①桶師町の黒口橋際〜八幡橋際の川を一名「黒口川」と唱え、②桶師町起立以前の小留所干潟の頃から右川筋には「水道附キ（水道接続）」があった、③その頃は「黒江川」と唱えた、④寛永6年（1629）の当所築立の際に川筋として黒江川に固定した**という文言候補＋川巾の変化（八幡橋際8間半→久中橋西12間/東5間→黒江橋際7間→蛤町境15間）。〔**「水道附キ」という川の属性文言（=水道が付いていた川筋）がrepo初出候補**。深川側の小河川（永代寺門前〜大川への流路）に上水・水道系の接続があったことを示す文言で、本所上水系の給水（[GOV-171](../gov/GOV-171.md)「南北本所一圓に懸渡す」）が深川側にまで及ぶかの対照課題の材料（直接の接続は断定しない）。「一名二黒口川」の句はOCR崩壊候補（「一名ヲ黒口川ト唱」等）。黒口川/黒江川という一対の川名の使い分けも地名対照の新規行候補。〕
- **元禄12年の堀割と橋3ヶ所の文言（koma 65-66）**: ①「**南之方川之儀は当町北之方河筋蛤町之方え流川巾八尺有之 堀割之義は元禄十弐卯年 筑愛（=築地・OCR候補）御普請御奉行深津八郎左衛門様御掛りニ而町内町人所持屋敷御用地ニ被召上 右川筋御堀割有之 尤里俗唱等無御座候**」（koma 65・OCR）＝**元禄12年（1699）の築地普請で深津八郎左衛門の御掛により新規堀割された川（巾8尺・里俗名なし）**、②「**一八幡橋巾弐間…元禄十六未年三月二日御入用を以御掛替有之 尤右名目付之義は八幡宮え御通行之橋に付八幡橋と相唱 当町并同所北川町中嶋町江見守被仰付**」（koma 66・OCR）＝八幡橋の元禄16年（1703）3月2日掛替（八幡宮への御通路橋・3町見守）、③「**久中橋長六間九尺…宝永弐酉年二月中御入用を以御掛替…黒江橋長六間…正徳四午年九月十八日中山出雲守様御番所え被召出**」（koma 66・OCR）＝久中橋宝永2年（1705）2月掛替・黒江橋の正徳4年（1714）9月18日中山出雲守信番所文言の文言候補。〔元禄12年堀割（深津八郎左衛門）は[GAZ-178](GAZ-178.md)（十間川側）と並ぶ深川側の堀割 datapoint。

## 制限・未解決

- ①すべてOCR由来で要原文照合（「一名二黒口川」「黒江川ゟ留」「筑愛御普請」「江見守（=三町見守?）」「巾弐升壱尺」等の判読候補・句切り）。②「水道附キ」の水道の実体（本所上水系か玉川系か井戸水道か）は本冊からは断定しない（「深川側の水道」の候補列記として対照表で管理）。③黒口川/黒江川の川名の正確な使い分け（同一川の新旧名か区間別名か）は「寛永6年築立の節に黒江川に留（=固定?）」の読みが立つまで決めない。④「川巾15間（蛤町境）」と別値の並存は測点違いと考えられるが断定しない。
