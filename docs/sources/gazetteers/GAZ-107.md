# [GAZ-107] 御府内備考 巻6-7（御曲輪内之四〜五・上水章・写本OCR）— 四上水総説・神田川名義・船入堀普請年代録・淀橋町助水の対校元テキスト

- **書誌〔確認〕**: 『御府内備考』巻之六（御曲輪内之四・目録「上水／玉川上水付助水／神田上水付助水／溜池／浅草川」）・巻之七（御曲輪内之五・両国橋〜鎧渡の屋鋪地名並里俗小名）の合冊写本。NDL lab [book/2553664](https://lab.ndl.go.jp/dl/book/2553664)。目録には「**神田川 紅葉川 神田堀 八町堀 薬研堀 土井堀 伊勢町堀**」の併記と橋名群（御谷吟橋・雉子橋・一ツ橋・神田橋・常盤橋…新慶橋）が見える。**引用文言はすべてくずし字OCR由来で原文画像との照合を要する。**
- **本登録の性格**: 巻6上水章は神田上水・神田川・千川上水の沿革を『江戸砂子』『見聞集』『武徳編年集成』『府内上水在絶略記』『万治年録』『寛文年録』『元文年録』などを引用して論じた総説部。神田川下流（浅草川合流まで）と上水系の既登録事項（[GAZ-049](GAZ-049.md)・[GAZ-085](GAZ-085.md)・[GOV-220](../gov/GOV-220.md)・[GOV-043](../gov/GOV-043.md)等）と重なる内容は対校差分・repo初出部分に絞って記録する。

## 第212回の読取（2026-11-20）

- **四上水の通時総説＝元禄年中千川上水開削文言〔文言候補・総説の年代枠の一次記録〕**: 「**又万治年中青山上水本所上水を作らしめられ寛文年中三田上水を作らしめられ元禄年中千川上水を作らしめられしか享保七年此四ヶ所の上水は皆廃せられたりその後安永九年再ひ千川上水を下谷浅草辺まて掛渡され(?)に幾何ともなく天明六年廃せられしなりその詳なる事は猶その地の条に記たれは合せ見るへし**」＝**①青山上水・本所上水＝万治年中、②三田上水＝寛文年中、③千川上水＝元禄年中開削、④享保7年（1722）にこの四ヶ所の上水は皆廃、⑤安永9年（1780）に千川上水を下谷浅草辺まで掛渡し、⑥幾何もなく天明6年（1786）廃**。〔「元禄年中千川上水開削→享保7年皆廃→安永9年再興→天明6年廃」の通時系列を一文で示す御府内備考レベルの総説文言。千川上水の開削年代論（[GOV-220](../gov/GOV-220.md)・[GAZ-049](GAZ-049.md)の系譜）に幕末地誌編纂側の年代整理として加わる。ただし本条自体が伝聞・引用の総説であること、年次表記はOCR由来であることを留保する。〕
- **井頭池引注ぎ説と神田上水水源文言〔文言候補・猪頭弁天地〕**: 「**其後大院殿の御代(?)井頭池より神田上水を引注かれつゐて万応年(?)ゆし(?)多磨川の水を引て玉川上水を掛られしより溜池と神田山下よりの用水は止められしといへり**」＋『江戸砂子』引用「**江戸砂子云神田上水は水源猪頭弁天地より流れ出ことに清潔にして…と涸ることなし**」＝**①「大院殿の御代に井頭池より神田上水を引注ぎ」たとする総説文言（大院殿＝徳川家宣法名常憲院?の比定は要照合。従来の神田上水開削論＝徳川家康命・大久保藤五郎忠行説〔武徳編年集成引用の「井頭地なるへしの水を小石川筋より通すへき」文言〕との関係は対校保留）、②江戸砂子の「水源猪頭弁天地」文言の直接引用（[GAZ-083](GAZ-083.md)系の江戸砂子経由情報の府内備考側の引用形）、③玉川上水掛渡し後に「溜池と神田山下よりの用水は止められし」＝赤坂溜池系の水停止説**。〔「大院殿の御代の引注ぎ」は他書に見えない系統の文言候補（要原画像照合）。赤坂溜池の水停止の文言は同章の溜池条（「**昔此地水を江戸中の水道に引注きし事は既に上水の条に弁せり**」）と呼応する。〕
- **神田川名義＝船河原橋以下の呼名〔文言候補・名義論の明文化〕**: 「**今神田川といふは船河原橋（俗にぞんと橋(?)）といふ迄より四条水(?)及柳原堤外を過て浅草川に落合へるまての呼名なり**」＝**「神田川」の呼称は船河原橋（俗呼・OCR判読注意）から四条水（ yük?・OCR）および柳原堤外を経て浅草川に落合うまでの区間名**とする総説。〔神田川＝江戸川区間の呼称の上下限を船河原橋で区切る文言は、[対照表](../../地名・河川名対照表.md)の江戸川／神田川区間呼称論の府内備考側の datapoint。巻6総説が船河原橋を神田川呼称の起点とすることは[GAZ-108](GAZ-108.md)の大下水＝船河原橋脇で江戸川合流文言（市谷牛込側の大下水の落口）と同じ地点を境目に扱う編纂方針の表れ。判読「ぞんと橋」〔善光寺橋?曽之处?〕は要照合。〕
- **天文19年北條氏康文書「神田川まけの郷」〔文言候補・神田川の最古層の文書言及〕**: 「**天文十九年(?)三月十九日北條氏康か用土新左衛門に與へし文書に武州高山知行之由神田川まけの郷進之居と見へたり此神田川と書しは何れの辺を捨ていへるにや詳にせす…文書に記せし神田川もとにかく此川を指ていへるなるへし**」＝**北條氏康が用土新左衛門に与えた文書（天文19年＝1550・年次はOCR要照合）に「武州高山知行之由 神田川まけの郷進之居」と見える由。編纂者は「この神田川がどの辺を指すか詳かでない」としつつ、見聞集の慶長の頃の神田明神山水張り（御茶水筋の川）を指す可能性を論じる**。〔「神田川まけの郷」はrepo初出候補の文書文言（「まけの郷」の判読・用土新左衛門の人物・北條氏康文書の所在は要照合。武州高山＝高山〔掃部?〕の地との関係も未確定）。神田川名称の最古層の候補として[対照表](../../地名・河川名対照表.md)江戸川区間開削年代行の系譜に登録する。〕
- **万治3年牛込〜和泉橋船入堀普請の年録引用〔文言候補・船入堀年代の一次記録〕**: 「**此川昔は水も深からすして舟運送の不便なりしを万治年中松平陸奥守綱宗に命して船入の川に堀割せ給ひし事は諸記に見へたり万治年録云三年庚子二月十日牛込より和泉橋迄船入堀普請松平陸奥守(?)迄仰付之依在国以奉書被伝之寛文年録云元年(?)万治四年三月廿九日松平亀(?)子代へ…御堀普請出来二付為上覧已上刻御成同四月十一日**」＝**①万治年中に松平陸奥守（伊達綱宗候補・要照合）に命じて船入の川に堀割かせた由の諸記引用、②万治年録・三年庚子二月十日「牛込より和泉橋迄船入堀普請」の奉行名、③寛文年録・万治4年3月29日の御堀普請出来・上覧御成（4月11日）**。〔「牛込より和泉橋迄」の船入堀普請＝江戸川（神田川）の牛込区間の堀割年代論（[対照表](../../地名・河川名対照表.md)の万治元年〔GAZ-102〕・万治2年〔GAZ-090〕各説に隣接する万治3年・4年の年録datapoint。堀割年代論に年録経由の新たな1633・1661?の二点を加えるが、年次・奉行名の判読は要照合であり従来の各説との優劣は決めない。〕
- **玉川上水代々木村よりの神田上水助水＝淀橋町久兵衛水車〔文言候補・GAZ-111との対校〕**: 巻6神田上水附助水条「**玉川上水代々木村より神田上水の助水口あり淀橋町久兵衛持水車へ掛り直に神田上水へ落合此堀筋土橋三ケ所御普請所にして都而久兵衛進退す**」＋府内上水在絶略記引用「**多摩郡吉祥寺村の北壱里に当て井草村善福寺池といふあり…一廉の水涌る和田村にて神田上水に落合右の弐流堀筋都而御手入なし**」＝**①玉川上水の代々木村からの分水が「神田上水の助水口」となり淀橋町の久兵衛持の水車に掛かって直に神田上水へ落合う、この堀筋の土橋3ヶ所は御普請所で久兵衛が進退する、②善福寺池の水が和田村で神田上水に落合う弐流堀筋（御手入なし）**。〔**①は[GAZ-111](GAZ-111.md)（巻66淀橋町条）の「神田御上水長三拾間巾四間…町内と多摩郡境ヲ相流…右御工水之儀ハ本家村井之駅(?)池ゟ流古水(?)」・「水車跡兵衛(?)」・定橋文言と対校する母体側の文言**。淀橋町を流れる「神田御上水」の水系比定（玉川上水系の助水堀＝十二社用水前史か、千川上水か、井之頭池からの神田上水本流か）は両文言の対照が不可欠で、本条の「代々木村よりの助水」が最も具体的。巻6編纂側は淀橋町の水を「助水」と呼び、淀橋町条は「神田御上水」と呼ぶ＝同水路の二重呼称の構造。詳細な流路比定は原画像照合と十二社溜井（[GAZ-111](GAZ-111.md)の関連行）の史料群との対校まで保留。〕
- **元文4年神田玉川両上水の町奉行支配化〔文言候補〕**: 「**元文年録云四年己未八月二日神田玉川上水向後町奉行支配に相成道奉行は道方計可相勤之旨於槙便之間本多伊預守殿被仰渡之**（OCR）」＝**元文4年（1739）8月2日、神田・玉川両上水が以後町奉行支配となり、道奉行は道方のみを勤める旨を本多伊預守（伊予守候補）が申し渡した**という年録引用。〔両上水の支配系統の変化の年次記録として[GOV-220](../gov/GOV-220.md)系の上水行政史の datapoint（年次・役職名の判読は要照合）。〕
