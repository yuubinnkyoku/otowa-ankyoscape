# [GAZ-029] 東京府地誌（1925年）— 弦巻川＝関口台と小日向台の間の1925年現勢

- **書誌〔確認〕**: 東京府編『**東京府地誌**』（1925年）。府内の区・郡・町村の地誌。NDL次世代デジタルライブラリー [book/925443](https://lab.ndl.go.jp/dl/book/925443)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **小石川区条の弦巻川・小石川〔確認・1925年現勢〕**: 「地勢ハ江戶川一帶ノ地ト本〓區界ノ地トヲ除ク外ハ〓シテ高阜ニシテ蓮華坂、金剛寺坂、安藤坂、富坂、鶯谷、茗荷谷等アリテ坂路多ク、**川ハ江戶川ノ外、小石川ハ小日向臺、白山臺ノ間ヲ流レ江戶川ニ注ギ、弦卷川ハ關口臺ト小日向臺トノ間ヲ流ル**、東西三十八町南北二十五町アリ」＝**1925年（大正14年）時点の府編纂地誌レベルの現勢で、①小石川（千川）は小日向台と白山台の間を流れて江戸川に注ぎ、②弦巻川は関口台と小日向台の間を流れる**と明記〔**弦巻川の下流区間（関口台〜小日向台間）が1925年時点でも川として現勢記録されていた**こと＝1932年弦巻通り開設・その後の暗渠化以前の、公的区勢資料レベルの現勢記録。音羽の瀧以東（江戸川合流点まで）の区間と推定されるが、区間の特定は本条ではできない〕。
- **位置づけ〔観察〕**: [BOOK-009](../books/BOOK-009.md)（1910・礫川要覧「關口臺ト小日向臺トノ間ニ弦卷川アリ」）→本書（1925・同一の地形学配置表現）→[GOV-208](../gov/GOV-208.md)（1938・音羽町各丁の西側現勢）という**弦巻川の下流の現勢記録の系譜を1910〜1938年で繋ぐ中間点**〔「関口台と小日向台の間」という表現は礫川要覧の転用系統の可能性もあるが、府の地誌が独立に採用した文言として記録する〕。小石川（千川）の「小日向台・白山台の間」も、谷端川下流（千川呼称）の台地間配置（小石川谷）の1925年記録として[BOOK-009](../books/BOOK-009.md)（1910・中央岡脈と東北岡脈の間）と[GOV-208](../gov/GOV-208.md)（1938・町列）の間を埋める。
