# [GAZ-179] 町方書上[1] 白金町方書上　完（文政11子）— 三田用水の白金台町・猿町通過の埋樋2基と流末文言

- **書誌〔確認〕**: 『[1] 白金町方書上　完』（写・NDL次世代デジタルライブラリー [book/2571482](https://lab.ndl.go.jp/dl/book/2571482)。NDL目録volume表記「[1] 白金町方書上　完」・APIで直接確認）。白金台町壱〜拾壱丁目（拾丁目条の見出しp95・署名「白金台町拾町目名主甚右衛門」p102）・白金瑞聖寺門前（p111-114）・白金猿町（見出しp115・署名「白金猿町名主甚右衛門」p126）・白金猿町妙玄院門前（p127）・白金報恩寺門前（p135-136）・白金神明社地門前（p140-141）・白金村・下豊沢村条（p145-149）。条末署名はいずれも「文政十一子年四月」＝文政11年（1828）4月提出。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571482_{NNNNNNN}.txt`・7桁）。
- **白金台町拾丁目条の三田用水埋樋文言〔文言候補・本冊最重要〕（p98）**: 「**一埋樋右は当町往還南側妙円寺前北角より南之方え凡長弐拾間 巾三尺程有之 三田用水埋樋有之候得共 右用水懸り村々ニ而取計 町内ニ而者相抱り不申候**」（p98・OCR）＝**①当町（白金台町拾丁目）往還南側・妙円寺（猿町梣p126の「妙玄院」との表記の揺れはOCR・原字照合前提）前北角から南へ約長20間・巾3尺の埋樋、②「三田用水埋樋」の存在文言、③経営主体が「用水懸りの村々」（＝上水・用水を掛けている村側）で町内（町方）は相抱らない、の3点**。〔文政11年時点で三田用水の埋樋が現存稼働している実務文言「有之候得共」＝[GAZ-162](GAZ-162.md)の「御殿引ケ候節 上水之儀は品川領へ用水に被下置候」（上水→品川領の農業用水への転用）の文政期の現況を町方側から裏付ける候補材料（転用後の通水継続を直接に記す文言ではないため断定しない）。支配文言「町奉行御代官所両御支配に而当時中村八太夫様御代官所に御座候」（p98末）＝[GAZ-158](GAZ-158.md)三田壱町目条・[GAZ-161](GAZ-161.md)金杉通壱町目条と同じ代官名。〕
- **白金猿町条の三田用水埋樋・横切下水・石橋・流末文言〔文言候補・本冊最重要〕（p120-121）**: 「**但白金猿町品川台町両町境に有之 巾弐尺余 横切下水壱ケ所 堀割年代等相知不申候 一石橋右下水に掛有之 巾四尺 長さ三間半 一埋樋右は当町有馬玄蕃頭様御中屋敷西角ゟ竹岡筋違横切埋樋壱ケ所 凡長三拾九間程 巾壱尺余程有之 三田用水と相唱申候 町内南割中程ゟ家前下水ヲ通り 町内境横町ゟ大塚村江落込申候 尤右は三田用水懸ヶ村々二而取計 町内に而は相抱不申候**」（p120-121・OCR）＝**①白金猿町と品川台町（＝白金台町の同冊内の別表記・同一町と読めるがOCR・原字照合前提）両町境の横切下水（巾2尺余・堀割年代不知）、②下水に架かる石橋（巾4尺・長3間半）、③有馬玄蕃頭様御中屋敷西角ゟ竹岡筋違（「竹岡」は字・地名の判読候補・要照合）を横切る長30間余・巾1尺余の埋樋＝「三田用水と相唱」申候＝里俗名としての三田用水、④流末＝町内南割中程の家前下水→町内境横町→「大塚村江落込」、⑤経営主体は台町条と同じく「三田用水懸ヶ村々」で町方は相抱らず、の5点**。〔猿町の大下水と「三田用水」（里俗呼称）の接続・併走は、台町条の埋樋（p98）とあわせ白金台町十丁目→猿町→大塚村へ南下する水筋の実務痕跡の候補（両文言が同一水路であるかは本文言だけでは断定しない）。「大塚村」の比定（荏原郡側の村か。猿町条p130の「毛利大和守様御下屋敷」南側等の方位材料との突合は今後の課題）。石橋の寸法（巾4尺・長3間半）は[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)の同型石橋群（[GAZ-154]三軒屋敷条の無名石橋巾6尺長3尺等）と並ぶ町方側小石橋の実寸の追加例。〕
- **猿町名義の「去り町→猿町」書替説〔文言候補・地名考〕（p116）**: 「**小留町之儀は白金台町石高之内に而起立之儀は委細白金台町壱丁目に申上候通 茶屋四ケ年起立仕候 猿町と相唱候名目相分兼申候 尤白金台町ヲ去り候町之由ニ而去り町より里俗相唱候所自然猿之文字ニ書替候由申伝候得共不詳候**」＝**猿町の名目は不明としつつ「白金台町を去った町」＝去り町を猿の字に書き替えた申伝**の文言（p116・OCR）。〔台町の起立（茶屋四ヶ年起立）とあわせ白金台町の縁辺の町起立の地名考資料。この「去り」町の話と味沢・「品川台町」表記は原画像照合前提。〕
- **品川台町＝白金台町の同冊内併記〔観察〕**: 台町各条の署名は「白金台町拾町目」等（p102）だが、猿町条（p120-121）では隣町を「品川台町」と記す＝[GAZ-162](GAZ-162.md)の品川領用水化文言の「品川領」との呼称の重なりを町名レベルでも観察できる材料（同一町の別表記か、町の一部の別呼称かは原文照合まで決めない）。

## 第236回の読取（2026-11-21）

- **白金台町壱・弐丁目条の「字玉名川」と「玉名之池」〔方言小字・川名文言候補・repo初出候補〕（p15-17）**: 白金台町壱丁目条の小字列に「**字玉名川**」＝**白金村・今里村入会場（検見場）と同年貢納の地域**、その水上は「**往古は玉名之壱池〔玉名之池・判読候補〕と唱し……文政十一年時点＝池は埋立済で「池跡地窪」**」＝**池の流出川としての「玉名川」呼称の継続文言候補**。水上が毛利出雲守様（判読候補）・山内遠江守様下屋敷境の除地に当たる旨も。repo全体をgrepし「玉名川」「玉名之池」の先行用例なし＝**両語ともrepo初出候補**。〔「玉名」の語形から地名・池名としての系譜（明治期の字名・現代の町名等への残存）は本冊OCRだけでは追えないので原画像照合後に調べる。川としては小規模な池流出川で、渋谷川（赤羽川）水系・三田用水（白金枝線）系統のどちらに属するか（あるいは独立の谷戸川か）は本文言からは断定しない。〕
- **蛍名所「名小先」と覚村寺「玉名橋」〔地誌文言候補〕（p16-17・p25-26）**: 白金台町壱丁目条に蛍の名所「**名小先**」（OCR崩れ候補・原字照合前提）・玉名川に架かる**石橋「玉名橋」＝巾六尺・長壱丈八尺**・覚村寺〔判読候補〕が「**玉名橋角**」に所在する旨の方位基準文言＝**玉名橋（玉名川の石橋）の氾用的位置情報として当寺を位置づける一次文言候補**（橋名・寸法ともにrepo初出候補）。〔四河川の橋名・橋跡調査に、白金台の小規模石橋の実寸（巾6尺・長1丈8尺）の追加例として登録〕。
- **「悪水祓」「悪水溜」の語彙観察〔観察〕（p25-26・p79）**: 白金台町・白金村条に「悪水祓」・「悪水溜」という悪水処理語彙（払・溜の字もOCR崩れ候補）が繰り返される＝隣接冊[GAZ-165]等の「悪水吐」とあわせ、谷戸地形の排水の字象（地口）レベルの用語対立系（祓／吐／溜）の材料。
