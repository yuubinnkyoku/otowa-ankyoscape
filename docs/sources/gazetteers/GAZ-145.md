# [GAZ-145] 町方書上[10] 牛込六 — 榎町の夷橋・川田ヶ久保町・原町の下水文言群

- **書誌〔確認〕**: 『[10] 牛込町方書上　六』（写・NDL次世代デジタルライブラリー [book/2571491](https://lab.ndl.go.jp/dl/book/2571491)）。文政10亥年（1827）。表紙町列＝天神町・中里村町・大願寺門前・多聞院門前・中里町・**榎町**・弁才天町・浄輪寺門前・千手院門前・**川田ヶ久保町**・鳳凰寺門前（鳳林寺）・**原町壱丁目**・永昌寺門前・原町弐丁目・同町三丁目・原町（p3）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571491_{NNNNNNN}.txt` コマ番号。**
- **榎町条の里俗「夷橋」〔文言候補・repo初出候補〕（p32）**: 「**町内東角往還ニ有之候 下水堀之儀者 巾弐人(=間候補)八寸 右下水二懸渡候名(=板?候補・OCR)橋 幅弐間壱人(=間候補)長四尺三寸 元地頭廉松寺咄し(=成り?候補)に御座候所 当時町内持に仕候 且又横町角下水堀之儀は巾三尺に而板橋長壱丈五尺 是は今以地頭廉松寺成り御座候 巾七尺 右下水江成渡候石橋 長七尺八寸巾弐間 里俗夷橋之唱候 尤召儀御普請所ニ而破損之節は町内yat(=ゟ候補)町奉行所え御訴申上候**」＝**①町内東角の往還の下水堀（巾2間8寸候補）に架かる橋（幅2間余・長4尺3寸・元は地頭廉松寺の持ち、当時は町内持）②横町角の下水堀（巾3尺）の石橋（長7尺8寸・巾2間）＝里俗「夷橋」、板橋（長1丈5尺・巾7尺）は今も地頭廉松寺持ち、破損の節は町奉行所に訴え出る**。〔**①「夷橋」（えびす橋）の里俗橋名文言repo初出候補**＝[GAZ-108](GAZ-108.md)の牛込系石橋群（揚場町・牡丹屋鋪）や[GAZ-140](GAZ-140.md)の津久戸前川・成就院系に続く牛込の堀・橋の管理構造（地頭・地頭→町内持の推移・破損時の奉行所訴え）の追加事例、②「廉松寺」の原字（蓮松寺候補）と「咄し」の原字は要原画像照合、③下水堀の系統（市谷大下水系か蟹川系か）は本冊文言単独では同定しない（榎町＝市谷柳町・原町方面の隣町構造から蟹川系江戸川合流域の下水群の候補）**〕。
- **天神町条の下水流出石橋〔文言候補〕（p8）**: 「**町内東角 御先手組屋敷lrt 町内続砲屋敷下水流出る 石橋長三尺五寸巾三間五寸御座候 石橋町内普請ニ御座候**」＝**天神町東角・御先手組屋敷から町内続きの砲屋敷(=雑業地域候補)下水が流れ出す地点の石橋（長3尺5寸・巾3間5寸・町内普請）**。〔巾に比べて長が短い（幅広の横断か読みの崩壊か）は原画像照合課題。天神町＝表紙町列の筆頭（牛込村の古町候補）で、[10]内で最も格式の高い石橋文言〕。
- **川田ヶ久保町条の前通り下水・横町通下水・石橋〔文言候補〕（p73-77）**: 「**一前通り下水巾壱尺壱寸五分 横町通リ下水巾凡四尺程 堀割年代相知不申候 一石橋壱ケ所 巾凡四尺程長弐間半 埋橋二仕有之候 尤御普請方御掛り二御座候**」＋「**二橋落大明神…**」（p76）＝**前通りの下水（巾1尺1寸5分）・横町通りの下水（巾4尺程・堀割年代不知）とその石橋（巾4尺程・長2間半・埋橋〔原字要照合〕仕立・御普請方御掛）**。〔川田ヶ久保町＝往古牛込村之内（p73）の町で、蟹川系下流域・[GAZ-109](GAZ-109.md)（御府内備考・原町・川田久保町・馬場下町条）の対岸側の元資料側witness候補。埋橋の構造の解釈は原画像照合前提〕。
- **原町壱丁目条の下水文言〔文言候補・[GAZ-109]の元資料側対校〕（p82）**: 「**一下水之儀 町内東境二有之 巾四尺五寸 尾張様西御門前lrt流出 御籏(=旗?)組屋敷より町内へ相流レ 末ハ根来御組屋敷lrt中里村田甫え落江戸川へ流入申候 石下水(*石橋?)江掛渡り候石橋壱ケ所 川田久保町往還に有之 巾四尺五寸長弐間 尤御普請方御掛りに御座候**」＝**下水（巾4尺5寸）は町内東境にあり、尾張様西御門前から流出し旗組屋敷を経て町内に流れ、末は根来御組屋敷から中里村の田甫（田んぼ）に落ちて江戸川へ流入。石橋1ヶ所（川田久保町往還・巾4尺5寸・長2間・御普請方御掛）**。〔**[GAZ-109](GAZ-109.md)原町壱丁目条（御府内備考）の下水文言（尾張様西御門前流出→根来御組家敷→中里村田甫→江戸川＝川田久保系とは別系統）の元資料側対校の成立**＝川の巾4尺5寸が一致・石橋の長が「長2間」（本冊）vs「長1間」（[GAZ-109]表記）の対立が判読・転記のどちら由来かは原画像照合まで保留**〕。
- **鳳林寺門前条の「牛込御門外船河原」建立と七軒寺町由来〔文言候補・地名由来〕（p66・p68）**: ①「**右鳳林寺 永禄元午年 牛込御門外船河原に記立(=建立候補)致候処 寛永玄軍(?=年中候補・OCR) 当所え代地拝領被仰付 右寺地之内寛文寅年門前町屋ニ起立仕候**」＝**鳳林寺は永禄元年（1558）牛込御門外の船河原に建立され、寛永年中に現在地の代地を拝領、寛文年門前町屋起立**。②「**里俗町内を七軒寺町ltr相唱候 右は牛込御門外御堀端近辺ニ有之候寺院 仏性寺宝龍寺鳳林寺久成寺千手院浄輪寺多関(=多聞・OCR)院 七ヶ寺御用地ニ被召上 一同寛永十二亥年当時之地所江引移り候二付近辺七軒与町ゟ相唱候**（後略・門前町屋は右之内鳳凰寺千手院浄輪寺多関院四ヶ寺に限る旨）」＝**「七軒寺町」の里俗名の由来：牛込御門外御堀端近辺の7ヶ寺（仏性寺・宝龍寺・鳳林寺・久成寺・千手院・浄輪寺・多聞院）が御用地に召し上げられ、寛永12亥年（1635）に当時の地所へ一緒に引っ移ったため七軒（寺）町と唱える**。〔**①「船河原」＝牛込御門外の地名（船着きの河原＝江戸川または外堀开水の河原候補）の用例文言＝[GAZ-139](GAZ-139.md)船河原橋・船河原町の地名群の背景、②七軒寺町の由来文言候補（repo初出。寛永12亥年=1635という年代付き）＝外堀普請（牛込御門外の寺社群の御用地化）に伴う寺移転の記録で、川系直接ではないが地名・寺社群移転の年代datapointとして記録**〕。
