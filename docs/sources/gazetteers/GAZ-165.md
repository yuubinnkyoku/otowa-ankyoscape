# [GAZ-165] 町方書上[101] 本所起立記 — 万治2年本所御取立の総説と橋梁起立書・享保4年奉行廃止

- **書誌〔確認〕**: 『[101] 本所起立記』（写・NDL次世代デジタルライブラリー [book/2571582](https://lab.ndl.go.jp/dl/book/2571582)。NDL API volume欄「[101] 本所起立記」・直接確認）。拝借地記立書（koma 6-8・文政十一子年九月名主新次郎署名）と「本所竪川通合せつ六間堀橋々起立書」（koma 14-17）で構成。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571582_{NNNNNNN}.txt`）。※本所の竪川・横川系は当repo四河川のいずれでもないが、万治2年本所御取立＝亀有上水（本所上水）の給水開始年（[GOV-171](GOV-171.md)「万治二亥年 本所へ上水をかけ渡す」）と同年で、[GAZ-138](GAZ-138.md)・[GOV-170](GOV-170.md)と並ぶ本所上水系の総説級資料として採録する。
- **万治2年の新規御堀立文言＝本所御取立の総説〔文言候補・本冊最重要〕（koma 6）**: 「**一弘化二亥年初ム本所御取立之節 徳山五兵衛様山崎四郎右衛門様御掛りに而 竪川横川拾間川六間堀五間堀新規御堀立 右上ケ土を以て川中地形誂等立御普請出来 其節右両人先祖之者御普請目論見等仕…**」（koma 6・OCR）＝**①本所御取立の節に竪川・横川・十間川・六間堀・五間堀の5水路を新規に堀割ったこと、②揚げ土で川中の地形を誂えた（=整地した）御普請だったこと、③その時の本所奉行が徳山五兵衛・山崎四郎右衛門（/左衛門・冊内で表記が分かれる）だったこと**の文言候補。〔**「弘化二亥年」は「万治二亥年」のOCR判読候補**とする。本所御取立は[GAZ-171](GAZ-171.md)（南本所元町条）「万治二亥年本所御取立有之」・[GAZ-169](GAZ-169.md)「南割下水…万治二亥年…堀割ニ相成」・[GAZ-170](GAZ-170.md)（竪川・横川「万治2年堀割」）・[GAZ-172](GAZ-172.md)（横川「万治二亥年中初而御堀割」）と万治2年（1659）で一致し、弘化2年（1845）は本冊の書上年（文政11=1828年署名）より後で御取立の「初」の記述と矛盾するため。原画像照合まで断定しない。**万治2= [GOV-171](GOV-171.md)亀有上水「万治二亥年本所へ上水をかけ渡す」の年次との整合が本文言の意義**（新規堀立5水路と上水開始の同時性）。〕
- **本所竪川通并六間堀の橋梁起立書〔文言候補・橋名群の一次記録〕（koma 15-17）**: ①竪川通「**一之橋二之橋三之橋新辻橋四之橋 元禄八亥年藤堂庄兵衛様多賀又四郎様懸り二而出来 右橋々万治二亥年 本所御奉行佐山五兵衛様山崎四郎左衛門様御懸り二而出来**」＋「**猿子橋 右は元禄七戌年藤堂庄兵衛様多賀又四郎様御懸り二而出来**」（koma 15-16・OCR）、②横川通「**法恩寺橋 万治二亥年徳山様山崎様…出来 長崎橋北辻橋 元禄十五年鈴木立九郎様鳥井久五郎様御懸りにて出来…南辻橋右同断 菊川橋猿江橋 元禄十五午年鈴木兵九郎様松平伝之湯様御懸り…**」（koma 15-16・OCR）、③十間川「**天神橋旅所橋清水様 右三ヶ所とも万治二亥年徳山五兵衛様山崎四郎左衛門様御懸り立出来**」、④六間堀通「**松井柳小之橋中之橋（=OCR「中之極」候補）…万治二亥年右同人御懸りにて出来**」（koma 16・OCR）、⑤五間堀通「**弥勤寺橋（=弥勒寺橋・OCR判読候補）伊豫橋 右弐ヶ所万治二亥年…山崎四郎左衛門様御懸り二而出来**」（koma 17・OCR）＝**竪川5橋＋猿子橋・横川6橋＋十間川3橋＋六間堀2橋＋五間堀2橋の18橋の起立書で、大半が万治2年・少数が元禄7・8・15年の再懸・追加**という構造の文言候補。〔**万治2年の堀割と同時の橋梁群の一次リスト（repo初出候補）**。元禄8亥年（藤堂庄兵衛・多賀又四郎）と万治2年（佐山/徳山五兵衛・山崎）のどちらが初懸かはOCR可読域では順序が確定できない（原文の照合課題）。「佐山五兵衛様」は「徳山五兵衛様」のOCR対立候補（冊内で両表記が混在）。〕
- **本所見廻り道役の系譜文言＝享保4年奉行廃止と大岡越前守への継承〔文言候補・管理系譜〕（koma 7-8・14）**: 「**…先祖両人之者 本所見廻り道役被仰付…天和三亥年迄罷在候所同年本所中大久保平日御様御代官所に相成…元禄六酉年又々本所御奉行藤堂庄兵衛様多賀又四郎様被仰付 善兵衛儀は伊奈半十郎様ゟ御引渡…**」（koma 7・前半）＋「**其後享保四亥年四月三日本所御奉行等止み以来 本山深川道橋共一島町奉行御遣に相成候趣被仰出 同年十月廿七日之間各々御儀大岡越前守様御内寄合江被召出 両人共是迄之通り道役相勤候様被仰付…**」（koma 8・OCR）＋「**享保四亥年四月三日本所御奉行相止み向後道橋川内一円町御奉行御懸り二相成候趣…**」（koma 14・OCR）＝**①万治2年御取立以来の見廻り道役（清水八郎兵衛・家城善兵衛〔OCR「宅成善兵衛」等〕の先祖）の推移（天和3年本所中が御代官所化→貞享3年→元禄6年本所奉行復活と支配の交代）、②享保4年（1719）4月3日の本所奉行廃止→以後「道橋川内一円」が町奉行持込となったこと、③同年10月27日大岡越前守御内寄合で両人が従来どおり道役を命じられたこと**の文言候補。〔**享保4年4月3日の本所奉行廃止日は[GAZ-167](GAZ-167.md)（小泉町条「享保四亥年四月三日本所御奉行相止」）・[GAZ-168](GAZ-168.md)（新坂町条「享保四亥年四月本所御奉行相止候節」）と同一日付で独立に3冊対応＝奉行廃止日の多冊witness。**[GOV-170](GOV-170.md)・[BOOK-222](../books/BOOK-222.md)の享保4年勘定奉行（町奉行）移管説の町方側実務系譜。〕〔天和3年=1683・伊奈半十郎様の登場は[GOV-171](GOV-171.md)の本所上水「（天和）三年やみ」年代との照合材料候補（道役系譜側から見た天和3年体制替え。断定はしない）。〕
