# [GAZ-139] 町方書上[5] 牛込壱 — 船河原橋の里俗「どん橋」・堀千之助文言・小栗横町

- **書誌〔確認〕**: 『[5] 牛込町方書上　一』（写・NDL次世代デジタルライブラリー [book/2571486](https://lab.ndl.go.jp/dl/book/2571486)）。文政10亥年（1827）の地誌御調書上帳。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571486_{NNNNNNN}.txt` コマ番号。** 本冊は牛込揚場町条（p12〜22）・牡丹屋鋪条（p30〜31）など、[GAZ-108](GAZ-108.md)（御府内備考巻53-55牛込）の揚場町条・牡丹屋鋪条と同じ町の町方書上元資料側にあたる。
- **揚場町条の船河原橋＝里俗「どん橋」〔文言候補・repo初出の里俗名候補〕（p14）**: 「**一船河原橋之義は町内東北之方御武家方脇小石川辺江之往来江戸川落口ニ掛有之 船河原橋と相唱候訳且(=得共候補・OCR崩壊)里俗どん橋与相唱候得共右唱之訳相知レ不申 尤町内持ニ者無御座候 水戸様御一手持ニ御座候得共町内最寄之儀ニ付申上候**」＝**船河原橋（町内東北・江戸川落口・小石川方面往来）は正式名で、里俗に「どん橋」とも唱えるが、その唱えの訳は知らない。橋は町方持ちではなく水戸様（水戸徳川家）の御一手持**。〔**①「どん橋」の里俗名文言はrepo初出候補**、②[GAZ-108](GAZ-108.md)揚場町条の判読対立部「**異澤且里路ニ先之橋**」と本冊「**得共里俗どん橋与相唱候得共右唱之訳相知レ不申**」は文字列・語順が酷似しており、御府内備考側の断片は本系統の町方書上文言（「得共里俗どん橋与相唱…」）の誤読の正体候補＝**御府内備考揚場町条と本冊揚場町条の資料的近接性（同系統元資料）の傍証候補**。ただしこの解決自体がOCRどうしの比較に基づく推定であり、両冊の原画像照合まで断定しない**、③水戸様一手持文言は[GAZ-108](GAZ-108.md)（「尤町川持ニ者無御座 水戸様御一手持ニ御座候」）と内容一致＝対校成立、④「どん橋」の原字（丼橋・土橋・鈍橋等の候補）は要原画像照合**〕。
- **揚場町条の大下水・石垣の堀千之助文言〔文言候補・千之助／与之助対立の新witness〕（p13-14）**: 「**大下水之儀は南之方ゟ北之方え流 巾壱間に而 牛込牡丹屋敷ゟ御武家方前通流来 末は江戸川江落入申候 両側石垣石橋共 寛永年中 堀千之助様御手伝に而出来仕**（後略）**一石橋壱ケ所 町内南之方横町御武家方境ゟ軽子坂上り口大下水に掛有之 長九尺巾壱丈壱尺三寸 石数七枚にて橋之字無御座**（後略）**御武家方町方半々之入用を以修復仕候**」＝**大下水は南から北へ・巾1間・牛込牡丹屋敷から武家方前を通り江戸川に落入。両側の石垣と石橋は寛永年中・堀千之助様の御手伝いで出来。軽子坂上り口の石橋は長9尺・巾1丈1尺3寸・石7枚・無銘・御武家方町方半々修復**。〔**①[GAZ-108](GAZ-108.md)揚場町条③の同型文言（御府内備考側は「堀与之助様」）に対し、本冊元資料側は「堀千之助様」＝千之助（[GAZ-108]牛込総説・改撰江戸志引用）／与之助（[GAZ-108]揚場町条・牡丹屋鋪条）の表記対立に、元資料側から「千之助」系の第3 witness**（正文どちらかの決着は原画像照合・対校資料の出現まで保留）、②大下水巾1間・石橋7枚の寸法文言も[GAZ-108]①と完全一致＝同系統資料の対校。③「軽子坂」表記は[GAZ-108]「軽坂」との表記対（いずれもOCR崩れ候補・原字要照合）**〕。
- **牡丹屋鋪条の小栗横町・材木置場文言〔文言候補・repo初出候補〕（p30-31）**: 「**町内西北之方 市ケ谷田町四丁目代地境横町ヲ里俗ニ小栗横町ト唱申候 右はわ前(=以前候補・OCR)小栗利右衛門様御屋敷 右横町地尻へ有之候故申習候**」（p30）＋「**大下水之義は 幅壱間 里俗に柳川と相唱 艮之方江戸川え落入申候**（中略）**大石橋之義は石数十五枚長九尺幅四間有之 新規修復共御普請方御掛り二御座候**（中略）**御堀端土手石垣ゟ往来之方 幅吉(=壱候補・OCR)間長八間之場所 材木置場ニ相願候得共 当時至場ニ不仕候 右願済年月相知不申候 右同処 幅壱間長十四間 もかり(=仮?候補・OCR)竹やらい**」（p31）＝**①市ケ谷田町四丁目代地境の横町の里俗名「小栗横町」（小栗利右衛門様屋敷の地尻に由来）＝repo初出候補、②大下水沿いの「材木置場」の願文言（幅1間・長8間の場所を願うも当時は実現していない＝願済年月も知らない）＝御堀端（外堀）土手沿いの土地利用の一次文言候補・repo初出候補、③同所の「幅1間長14間の仮り(?)竹やらい（矢来）」文言も付随、④柳川（巾1間）・大石橋15枚（長9尺幅4間）は[GAZ-108](GAZ-108.md)牡丹屋鋪条と同一内容＝元資料側対校の成立**。〔「わ前」「吉間」「もかり竹やらい」等の原字は要原画像照合。材木置場が大下水・外堀のどちらに面する場所かは本文言から確定しない（「御堀端土手石垣ゟ往来之方」＝外堀床石垣の往来側の読みが有力候補だが、絵図との照合前提）**〕。
- **揚場町の惣物場・船鴨・鯉取溜文言〔文言候補・江戸川（神田川）水運の実務〕（p15-16）**: 「**惣物場弐ヶ所 河岸南之方北之方 間四拾九間五尺 奥行様弐間**（中略）**享保十七子年五月中 町御奉行大岡越前守様江奉願候得者願之通被仰付**（中略）**神田川筋船鴨御用 幷江戸川鯉御取溜御用之節 御場掛様方 御鳥見方御出役之砌 御成之節 河岸通荷物取払候哉之旨 御尋ニ付**（後略）**文政七申年七月中 河岸地御調写 加金上納可仕旨被仰渡**」＝**揚場町の惣物場2ヶ所（享保17年〔1732〕5月町奉行大岡越前守への願出で成立）と、神田川筋の船鴨（水鳥）御用・江戸川の鯉御取溜御用の際の河岸使用の実務文言＋文政7年（1814）の河岸地御調写・加金上納**。〔江戸川（神田川）の揚場機能（[GAZ-108](GAZ-108.md)揚場起立文言）の運用面を補う町方側記録。船鴨御用・鯉取溜の解釈（御膳・鷹狩関連の供御候補）はrepoの範囲を超えるため採用しない**〕。
