# [GAZ-169] 町方書上[108] 本所町方書上 七 — 南割下水・沢樋群と白堀東添湿地の文言群

- **書誌〔確認〕**: 『[108] 本所町方書上 七』（写・NDL次世代デジタルライブラリー [book/2571589](https://lab.ndl.go.jp/dl/book/2571589)。NDL API volume欄直接確認）。長岡町弐丁目条（koma 62-67）・新坂町系（koma 29・73）・長崎橋周辺条（koma 8-12）等の複数町条。引用文言はすべてOCR由来で要原文照合。※第223回の本冊boilerplate陰性判定は四河川keyword掃引のみに基づくもので、本所上水・割下水系の文言が見逃されていた＝本回の訂正記録。
- **沢樋2ヶ所＝横川両縁の南割下水・東中割下水吐口の開閉文言〔文言候補・水利接続の実務記録〕（koma 12）**: 「**一沢樋弐箇所 巾四尺七寸 右は長崎橋際に而横川両縁に有之 西之方当町地先に有之候は南割下水吐口高（=方） 東之方ニ有之候は東中割下水吐口ニ御座候 横川水増減ニより右切樋開閉いたし候 尤両入樋共町方御勘定方御掛ニ而御修復有之 何とも町内ニ而見守仕候**」（koma 12・OCR）＝**①長崎橋際の横川両縁に巾4尺7寸の沢樋（切樋)2ヶ所、②西側が南割下水の吐口・東側が東中割下水の吐口、③横川の水位の増減に応じて切樋を開閉する、④修復は町方御勘定方御掛・見守は町内**という排水樋の操作実務の文言候補。〔**横川と南割下水・東中割下水の水利接続（排水樋による横川水位への連動）を一次側で記す実務記録（repo初出候補）**。「東中割下水」の呼称も新出（南割下水に対する東の中割下水か別水路かは本冊のみでは比定しない）。〕
- **南割下水の堀割年代と浚請負・大下水石橋群（koma 11・62-63・66-67）**: ①「**南割下水中弐間 右は町内中程東西え通り有之 万治二亥年 本所御奉行徳山五兵衛様山崎四郎左衛門様御懸ニ而堀割ニ相成申候 且右下水土砂浚之儀は天明二寅年中其節長兵衛と申者 永御請負人は（?）同所ニ而惣五郎と申者御請負仕罷在候**」（koma 62・OCR）＝**南割下水巾2間の万治2年（1659）堀割＋天明2年（1782）の土砂浚の請負人（長兵衛・惣五郎）**、②「**南割下水橋長壱間幅三間弐尺 右は万治年中…土橋ニ懸渡ニ相成候処崩落込等有之候に付 寛保年中以後右石橋に相成候旨申伝…**」＋「**大下水橋長六尺程巾六尺五寸 但石橋…元土橋ニ而有之候処 寛政三亥年中石橋ニ懸直御普請有之**」＋南割下水へ落口の石橋群（koma 63・66-67・OCR）＝**土橋→石橋への掛替群（寛保年中以後・寛政3年〔1791〕等）と南割下水への落口構造**の文言候補、③「**長崎橋之儀を里俗中之橋と相唱申候は北に法恩寺橋有之南ニ北辻御橋御座候間右之通相唱**」（koma 11・OCR）＝**長崎橋＝里俗「中之橋」の名義文言候補**（北の法恩寺橋・南の北辻橋の間だから中之橋。〔GAZ-165〕起立書の長崎橋・北辻橋と接続）。
- **樋枡文言の孫八伊兵衛重出（koma 29）**: 「**本所新坂町御用屋鋪…元禄年中 本所上水樋枡破損修復御請負役孫八伊兵衛与申者江被仰付…**」（koma 29・OCR）＝[GAZ-168](GAZ-168.md)（[105]桶掛・[110]樋掛）に続く**第3の書き分け「樋枡破損修復御請負役孫八伊兵衛」**＝桶掛・樋掛・樋枡の3語形と2冊での語順対立を含む上水修復請負文言の対校群が揃った。〔同じ新坂町御用屋敷文言の別冊重出（[108]側も新坂町御用屋鋪表記）で、文言の拡散・転写の実態の観察材料。どの書き上が正字かは原画像照合まで決めない。〕
- **上水白堀東添の湿地埋立・稽古場文言〔文言候補〕（koma 73）**: 「**…右上水白堀東添二而四百坪之地所割餘り湿地之所自分入用に而埋立て稽古場に致 矢場守源之丞源兵衛長右衛門三人之者共助成屋鋪に仕度段 元禄十三辰年本所御奉行鳥井久五郎様桜井庄之助様江相願拝借被仰付候処 右之者共不埒之義有之 宝永四亥年断絶仕 夫より享保四亥年御用地に相成 右両人御預りに罷成候**」（koma 73・OCR）＝**上水白堀の東添（東添い）の割り余り湿地を埋め立てて稽古場（矢場守3人の助成屋鋪）にした元禄13年（1700）拝借→宝永4年（1707）断絶→享保4年（1719）御用地化**の文言候補。〔「上水白堀東添い」という**白堀上水の空間的位置表現**（白堀に沿った東側の余地地）がrepo初出で、[GAZ-167](GAZ-167.md)の白堀浚・定渡受負人群と並ぶ白堀の物理的イメージ（巾・添地）を固める材料。条帰属は不明（新坂町系・koma 73は冊末の条）。〕
