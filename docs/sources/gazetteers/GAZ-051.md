# [GAZ-051] 東京府豊多摩郡誌（1916）— 千川用水の流路と「井草川」の別名

- **書誌〔確認〕**: 東京府豊多摩郡編『東京府豊多摩郡誌』（1916）。NDL次世代デジタルライブラリー [book/1874656](https://lab.ndl.go.jp/dl/book/1874656)。**引用文言はすべてOCR由来で、文言・地名は原文画像との照合を要する。**引用は「新編武蔵風土記稿」を多用する（「新風土記」と略記）。
- **千川用水の流路・沿革の総説〔確認・出棚橋の文言〕**: 郡の水利総説——「**千川用水 北豊島郡石神井村大字竹下地內出棚橋に於て玉川上水を分ち、靑梅街道に沿ふて東流し 井荻村及び野方村の北邊を通過し、北豊島郡瀧野川村に於て石神井川に合す、昔は巢鴨庚申塚邊より掘割ありて 本〓（＝本郷・OCR欠字）淺草邊へ引きたる上水なりしが 享保七年廃せられて以來 專ら附近一帶の用水に供せられ、沿岸澤（＝沾沢か）を蒙むるもの頗る大なり、本郡内に於て此の水を引くもの三ヶ所（竹下新田、江古田、葛ケ谷）に及ぶ**」＝**①千川用水の取水点を「石神井村大字竹下地内の出棚橋」とする記述、②青梅街道に沿って東流し井荻・野方両村の北辺を経て滝野川村で石神井川に合流する流路、③巣鴨庚申塚辺から本郷・浅草方面への上水だったが享保7年に廃止、④郡内で千川用水を引くのは3か所（竹下新田・江古田・葛ヶ谷）**という1916年の郡誌記述。
- **出棚橋・石神井村竹下の比定の注意〔観察・要検討〕**: 「北豊島郡石神井村大字竹下地內出棚橋」の位置文言は、**石神井村が玉川上水沿いにない点から地理的に難があり**、①保谷取水説（[GOV-077](../gov/GOV-077.md)・[GOV-250](../gov/GOV-250.md)・[MAP-175](../maps/MAP-175.md)）と食い違う。原文がOCR由来である点を踏まえ、誤記・誤植・別の橋（上流側の分水施設の通称か）の可能性を含めて**比定は保留**する。後段の「新風土記に曰く『新座野（＝新座郡?）郡保谷村より玉川上水を分ち…』」の引用文言と併せ、郡誌自体が保谷分岐説（風土記稿引用）と出棚橋説（本文）を併記している点も記録しておく。
- **井草川＝千川用水の井荻村側の別名〔確認・repo初出〕**: 井荻村の条——「**『井草川』（千川用水） 北豊島郡石神井村大字竹下地內出棚橋に於て玉川上水より分れ、靑梅街道に沿ひて大字上井草字新町に到り、玆より東北方に流れ、附近處々の田野に澆ぎて下井草に入り、妙正寺池の流を合して東に轉じ、落合村に於て神田上水と合す。村内の流程二十町餘**」＝**井荻村内での千川用水の呼び名が「井草川」であることの1916年記録**。〔地名対照表の河川名に登録（区間名・村別呼称のカテゴリ）。妙正寺池の流れを合流点とする流路記述（上井草字新町→下井草→東転→落合）も、中流域の比定資料。〕
- **妙正寺池流〔確認〕**: 「**妙正寺池流 井荻村大字下井草妙正寺池より發して、千川用水の分流を合し、東流して野方村を貫き、落合村大字葛ヶ谷を經上落合に於て神田上水に合す、水路凡三里、幅員二間乃至四間**」＝妙正寺川（池流）が千川用水の分流を合する流路（水路約3里・幅2〜4間）。善福寺池流（和田堀内村内で神田上水に合す・水路4里・幅3〜5間）も同頁にあり。
- **杉並村の水利〔確認〕**: 「**水利（善福寺池流 千川用水支流 沿 成宗、天沼）**」＝**杉並村の水利に「千川用水支流」があり、成宗・天沼（の灌漑）に充当される**という1916年の記録。〔千川用水の支流が杉並村内（成宗・天沼）に引かれていた実態の郡誌レベルの記録。落合村の水利欄にも千川用水が列挙される。〕

## 制限・未解決

- ①「出棚橋」「石神井村大字竹下」の原字形・行対応はOCR崩れの可能性が高く、原文照合が必須。②「本郡内に於て此の水を引くもの三ヶ所（竹下新田、江古田、葛ケ谷）」の「竹下新田」の表記（竹下新田の実在・比定）は要照合。③「沿岸澤を蒙むる」等の崩れ文言は要照合。④郡誌の他の村条（野方村・淀橋町等）の千川用水記述の追加精読は次回以降。
