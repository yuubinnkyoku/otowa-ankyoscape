# [GAZ-051] 東京府豊多摩郡誌（1916）— 千川用水の流路と「井草川」の別名

- **書誌〔確認〕**: 東京府豊多摩郡編『東京府豊多摩郡誌』（1916）。NDL次世代デジタルライブラリー [book/1874656](https://lab.ndl.go.jp/dl/book/1874656)。**引用文言はすべてOCR由来で、文言・地名は原文画像との照合を要する。**引用は「新編武蔵風土記稿」を多用する（「新風土記」と略記）。
- **千川用水の流路・沿革の総説〔確認・出棚橋の文言〕**: 郡の水利総説——「**千川用水 北豊島郡石神井村大字竹下地內出棚橋に於て玉川上水を分ち、靑梅街道に沿ふて東流し 井荻村及び野方村の北邊を通過し、北豊島郡瀧野川村に於て石神井川に合す、昔は巢鴨庚申塚邊より掘割ありて 本〓（＝本郷・OCR欠字）淺草邊へ引きたる上水なりしが 享保七年廃せられて以來 專ら附近一帶の用水に供せられ、沿岸澤（＝沾沢か）を蒙むるもの頗る大なり、本郡内に於て此の水を引くもの三ヶ所（竹下新田、江古田、葛ケ谷）に及ぶ**」＝**①千川用水の取水点を「石神井村大字竹下地内の出棚橋」とする記述、②青梅街道に沿って東流し井荻・野方両村の北辺を経て滝野川村で石神井川に合流する流路、③巣鴨庚申塚辺から本郷・浅草方面への上水だったが享保7年に廃止、④郡内で千川用水を引くのは3か所（竹下新田・江古田・葛ヶ谷）**という1916年の郡誌記述。
- **出棚橋・石神井村竹下の比定の注意〔観察・要検討〕**: 「北豊島郡石神井村大字竹下地內出棚橋」の位置文言は、**石神井村が玉川上水沿いにない点から地理的に難があり**、①保谷取水説（[GOV-077](../gov/GOV-077.md)・[GOV-250](../gov/GOV-250.md)・[MAP-175](../maps/MAP-175.md)）と食い違う。原文がOCR由来である点を踏まえ、誤記・誤植・別の橋（上流側の分水施設の通称か）の可能性を含めて**比定は保留**する。後段の「新風土記に曰く『新座野（＝新座郡?）郡保谷村より玉川上水を分ち…』」の引用文言と併せ、郡誌自体が保谷分岐説（風土記稿引用）と出棚橋説（本文）を併記している点も記録しておく。
- **井草川＝千川用水の井荻村側の別名〔確認・repo初出〕**: 井荻村の条——「**『井草川』（千川用水） 北豊島郡石神井村大字竹下地內出棚橋に於て玉川上水より分れ、靑梅街道に沿ひて大字上井草字新町に到り、玆より東北方に流れ、附近處々の田野に澆ぎて下井草に入り、妙正寺池の流を合して東に轉じ、落合村に於て神田上水と合す。村内の流程二十町餘**」＝**井荻村内での千川用水の呼び名が「井草川」であることの1916年記録**。〔地名対照表の河川名に登録（区間名・村別呼称のカテゴリ）。妙正寺池の流れを合流点とする流路記述（上井草字新町→下井草→東転→落合）も、中流域の比定資料。〕
- **妙正寺池流〔確認〕**: 「**妙正寺池流 井荻村大字下井草妙正寺池より發して、千川用水の分流を合し、東流して野方村を貫き、落合村大字葛ヶ谷を經上落合に於て神田上水に合す、水路凡三里、幅員二間乃至四間**」＝妙正寺川（池流）が千川用水の分流を合する流路（水路約3里・幅2〜4間）。善福寺池流（和田堀内村内で神田上水に合す・水路4里・幅3〜5間）も同頁にあり。
- **杉並村の水利〔確認〕**: 「**水利（善福寺池流 千川用水支流 沿 成宗、天沼）**」＝**杉並村の水利に「千川用水支流」があり、成宗・天沼（の灌漑）に充当される**という1916年の記録。〔千川用水の支流が杉並村内（成宗・天沼）に引かれていた実態の郡誌レベルの記録。落合村の水利欄にも千川用水が列挙される。〕

## 制限・未解決

- ①「出棚橋」「石神井村大字竹下」の原字形・行対応はOCR崩れの可能性が高く、原文照合が必須。②「本郡内に於て此の水を引くもの三ヶ所（竹下新田、江古田、葛ケ谷）」の「竹下新田」の表記（竹下新田の実在・比定）は要照合。③「沿岸澤を蒙むる」等の崩れ文言は要照合。④郡誌の他の村条（野方村・淀橋町等）の千川用水記述の追加精読は次回以降。

## 第210回追記（2026-11-20・戸塚町条の蟹川（東京府志料由来文言・幅一間）・山吹の井・鳥居ヶ淵・水利節の細流群文言）

本書の戸塚町条（水利節＝印刷頁635〜636・名勝及旧蹟部＝印刷頁687〜689）を精読し、蟹川系の流路文言・湧水・淵の記録群を確認した。**引用文言はすべてOCR由来で、文言・地名・数値の細部は原文画像との照合を要する**。

1. **水利節の蟹川文言〔確認・「加能川」異称候補はrepo初出〕**: 「**『蟹川』本町と牛込區との境界を流るゝ細流なり、古は金川、加奈川、又は加能川など稱して川幅廣かりし由、源は戶山より發す**」＝**①1916年時点の蟹川の位置＝戸塚町と牛込区の境界を流れる細流、②古称＝金川・加奈川・加能川、③古は川幅が広かったという由緒、④源は戸山**。〔**「加能川」はrepo初出の異称候補**（OCR取り違えの可能性も残し原照合まで保留。[BOOK-149](../books/BOOK-149.md)〔1931〕の「金川、加奈川、加二川とも書かれてゐる」の15年先行側の本文で、「加能川」と「加二川」の関係も対校課題）。**「古は川幅広かりし由」＝蟹川がかつて広い川だったとする由緒記録は、下戸塚谷頭の谷地形の水路の縮小史の傍証候補**（蟹川系村落部分の過去の水量の変遷を示す史料側文言。断定せず）〕。
2. **水利節の秣川・欠字水川の文言〔確認・1931年戸塚町誌本文の先行側対校〕**: 「**『秣川』（題字部にOCR欠字の可能性）大字諏訪地内辨天池より流るゝ細流にして、大字源兵衛地內に於て神田川に入る**」＋「**『（清?）〓水川』戶山より落ちて大字戶塚地內を南北に流れ、大字戶塜字〓水川山手線ガード下にて神田上水に入る、細流なり**」＝**①秣川＝大字諏訪地内の弁天池より発し大字源兵衛地内で神田川（上水）に入る細流、②戸山より落ちて大字戸塚地内を南北に流れ、大字戸塚字（欠字）水川の山手線ガード下で神田上水に入る細流**。〔対照表の「秣川」「清水川（戸塚）」行（いずれも[BOOK-149](../books/BOOK-149.md)戸塚町誌・1931由来）の**1916年先行側の本文対校点**。「〓水川」の原字が戸塚町誌の「清水川」に当たるか（OCR欠字）は原照合まで保留。小字「馬屎川」の由来説明「〓水の流れ出で（て）源兵衛に出る小流の名より起れり、此の流大字源兵衛に入りては秣川といふ」（同巻・戸塚町の小字部）も対校点〔BOOK-190系の馬尿川（馬屎川）飛地の沿革文言との対照〕〕。
3. **名勝及旧蹟・蟹川条＝東京府志料の引用文言と幅一間〔確認・repo既知書誌への内容側対校点〕**: 「**蟹川 古昔太田道灌の狩に出でし地として、人口に膾炙する金川にして、加奈川、加二川とも書す、東京府志料に記す所左の如し。加二川附中川 戶塚町舊名古屋藩戶山邸の池より發し、牛込馬場下町を過ぎ、再び牛込村早稻田村中里村を經て、牛込山吹町小日向松ヶ枝町を經て江戶川に入る、一名戶山落と云ふ幅一間、中川は早稻田村にて本流より分れ、西北に向ひ又東に折れて江戶川の上流と加二川との間を流れ、小日向松ヶ枝町にて本流に合す**」＝**①蟹川本文が「東京府志料」由来であることの明示、②流路＝戸塚町旧名古屋藩戸山邸の池より発し→牛込馬場下町→牛込村・早稲田村・中里村→牛込山吹町・小日向松ヶ枝町→江戸川、③一名戸山落・幅一間、④中川＝早稲田村で本流より分かれ西北へ向かい東へ折れて江戸川の上流と加二川の間を流れ小日向松ヶ枝町で本流に合す**。〔**①＝蟹川流路文言の典拠が東京府志料であることの本文側の明示で、repo既知の東京府志料系書誌（[GAZ-072](GAZ-072.md)・[GOV-098](../gov/GOV-098.md)・[GAZ-105](GAZ-105.md)）への内容側の対校接点**。**③の幅一間は風土記稿の幅六尺（[GAZ-046](GAZ-046.md)牛込・中里村条）と対立する（どちらが正しいかは本書のみでは決まらず断定せず並記）**。④は[GAZ-046](GAZ-046.md)第208回追記の早稲田村条「中川堀」・第210回追記の中里村条（大系版「關口村に達す」）を挟む区間の中川の分合流路の具体で、戸塚町誌・地名辞書（[GAZ-065](GAZ-065.md)第210回追記の山吹川条）と続く対校系列〕。
4. **山吹の井（三島山の甘泉）〔確認・repo初出〕**: 「**山岸に少し計りの甘泉あり、これを山吹の井と呼べり、土人或は三島明神の御手洗、又は賴朝卿の馬の冷し場なりともいひ傳へたり。(江戶名所圖會)**」（三島山・山吹里の項）＝**三島山（下戸塚の小字・高田馬場の北・旧三島神社地・今は大抵相馬邸構内）の山吹里（民家後園）の山岸にわずかな湧水（甘泉）があり「山吹の井」と呼ぶ＋三島明神の御手洗・頼朝卿の馬の冷し場の異説**。〔**山吹里周辺（現在の西早稲田〜高田馬場付近＝蟹川系谷頭の東縁附近）の湧水の1916年記録でrepo初出**（所引は江戸名所図会＝[GAZ-047](GAZ-047.md)と同書の本文側対照が今後課題）。湧水・井泉のdatapointとして対照表に新規採録〕。
5. **鳥居ヶ淵（戸塚字宮田の神田川の淵）〔確認・repo初出〕**: 「**鳥居が淵 大字戶塚字宮田地內の神田川に、鳥居ケ淵といへるあり、もと鳥居のありし趾地なりと（いふ）、蓋し宮田は村內諏訪神社の元地なれば同社のありし邊ならんか**」＝**大字戸塚字宮田地内の神田川（蟹川系の下流側呼称）に「鳥居ヶ淵」という淵があり、もと鳥居のある趾地で、宮田は村内諏訪神社の元地だから同社のあった辺りだろう、という1916年の記録**。〔**神田川（江戸川）水系の淵の小地名記録でrepo初出**。地名対照表に新規採録。蟹川系の神田川への接続部（宮田＝諏訪神社付近・[GAZ-051]第210回追記2の「〓水川」山手線ガード下合流点の下流側）の水際地形のdatapoint。当該「淵」の実体（江戸川開削後に残った旧流路・窪地か）は推測にとどめる〕。
6. **荒井山・戸山新道・紅皿塚・赤井屋敷の補足文言〔確認・荒井山の「往古海水浸せし土地」観察〕**: ①「**荒井山 戶山練兵場の北をいふ、江戶名所圖會には荒藺山とありて、同所と大窪諏訪の森の間をいふ、此の邊は雲雀の名所也とあり、大森にも荒藺が崎といへる場所あり、蓋し往古海水浸せし土地なること思ひ知らる**」＝荒井山の位置（戸山練兵場の北）・江戸名所図会の荒藺山表記・**「往古海水浸せし土地」＝海進期の浸水域の観察文言**。②「**戸山新道 荒井山の西、源兵衛諏訪に跨りて新設の道路あり、明治三十七八年戰役紀念戶山新道と題したる碑を建つ、東京府知事男爵千家尊福書と署せり**」＝戸山新道の新設と碑面情報。③紅皿の事＝「**右に云ふ農家の少女を世に傳ふる紅皿の事とし、大久保町東大久保西向天神社に存する、紅皿塚の由緒書にも、云々の記載あること大久保町の部に詳かなり**」＝道灌山吹伝承の少女＝「紅皿」の塚が**大久保町東大久保の西向天神社に存する**という記録（**紅皿塚はrepo初出候補**・山吹伝承の地名側の着地点）。④赤井屋敷＝大字戸塚の旧小名（観音寺附近・赤井某が禁令の鶴を射て関所され、墓は観音寺境内に明暦元年銘の五輪塔）〔下戸塚谷頭の土地利用の記録として参考〕。
