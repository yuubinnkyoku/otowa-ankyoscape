# [GAZ-032] 新編武蔵風土記稿（1884年刊・OCR版）の石神井用水条・谷戸川条

- **書誌〔確認〕**: 間宮士信ら編『新編武蔵風土記稿』（江戸後期編纂・**内務省地理局の1884年〔明治17年〕刊行版**・巻之6山川〜巻之10豊島郡之2を収める分冊）。NDL次世代デジタルライブラリー [book/763976](https://lab.ndl.go.jp/dl/book/763976) のOCRテキストで、山川部の「石神井用水」条と「谷戸川」条を今回確認した。**引用はすべてOCRテキスト由来であり、文言は原文画像との照合を要する。**〔1884年は刊行年で、記述の実質は江戸後期の編纂時点〕〔既存の[GAZ-015](GAZ-015.md)（池袋村条・二次転記）と同じ書の別巻（山川・豊島郡）のOCR版で、山川部の水路記述はrepo初出〕
- **石神井用水条〔確認・repo初出〕**: 「**石神井用水 三 一ハ下坂橋宿ノ內字根村ト云所ヨリ石神井川ヲ引分チ十條・神谷・稻附・岩淵・下村・下板橋六村ノ水田ニ注ク是ヲ根村用水ト稱ス 一ハ王子村石堰ヨリ十間許上流ニテ分泒シ飛鳥山下ヲ流レ西ケ原・梶原・堀之内・田端・新堀・三河島・金杉・龍泉寺・山谷・橋塲數村ヲ歷テ淺草川ニ達ス**」〔**①石神井用水が根村用水と王子村石堰の2系統であること、②王子村石堰から十間許上流で分派した流れが飛鳥山下を流れ、西ヶ原・梶原・堀之内・田端・新堀・三河島・金杉・龍泉寺・山谷・橋場の諸村を経て浅草川（隅田川）に達する流路**＝**王子の堰から西〜南へ流れる石神井川系統の用水の江戸期官撰地誌レベルの流路記録**〕〔千川上水の「王子分水」（[GOV-150](../gov/GOV-150.md)・[GOV-194](../gov/GOV-194.md)系・千川上水→王子→石神井川側）とは**向きの逆の水利**で、両者を同一視しない〕〔北豊島郡誌1918（[GAZ-002](GAZ-002.md)）の【石神井用水】条（明治19年水利組合・南千住・下谷浅草を含む組合）の江戸期の前身記述として対照できる〕。
- **谷戸川条〔確認・repo初出〕**: 「**谷戶川 巣鴨上駒込ノ接地ニ長池ト云アリ 此池ヨリ流レ出テ上駒込西ケ原村ヲ束ニ屈曲ン其間巢鴨駒込邊ヨリ出ル〓水及下水等モコノ流ニ沃キ 夫ヨリ中里・田端・谷中ニ添テ南ニ流レ 流末不忍池ニ落入レリ 根津谷中ノ邊ニテハ藍染川ト唱フ 川幅一間ヨリ二間許**」〔**①源を巣鴨・上駒込の接地の「長池」に置く、②上駒込・西ヶ原村を東へ屈曲し巣鴨駒込辺の湧水・下水も受ける、③中里・田端・谷中を経て南流し流末は不忍池、④根津・谷中の辺では「藍染川」と呼ぶ、⑤川幅1〜2間**〕〔**藍染川の呼称の江戸期の記録**＝[GOV-133](../gov/GOV-133.md)（2019年・区映像の古老証言「谷戸川→谷田川→藍染川」の区間別呼称）の江戸期対応文言。**長池**＝同証言の湧水池「長池」との対応も対照価値が高い〕〔風土記稿の谷戸川（長池起源）と石神井用水（王子石堰起源）は**別条**で、両者の水路的な関係（同一の堀網か別系統か）は本記述だけでは断定しない〕。
- **谷端川・小石川の記述〔確認・既出内容の原典側確認〕**: 同OCRの並びに「**小石川井〔ハ〕谷端川 長崎村ヨリ出ル細流 落合ヲ池袋村・瀧野川村・巢鳴村等ヲ〔経て…〕**」の文言＝長崎村源流説の原典側（OCR上）の確認〔長崎村源流はREADME既出（北豊島郡誌・区史系）で、風土記稿レベルでの文言確認として記録。文末の流路の切れ（OCR欠損）は要原文照合〕。
