# [GAZ-097] 江戸志 [2] — 橋場条の松橋採録と太平記批判の按語

- **書誌〔確認〕**: 『江戸志』[2]。近藤義休 撰・瀬名貞雄 補。NDL次世代デジタルライブラリーで写本10冊（[book/2563420](https://lab.ndl.go.jp/dl/book/2563420)〜[book/2563429](https://lab.ndl.go.jp/dl/book/2563429)）が公開されており、本資料はその[2]＝[book/2563421](https://lab.ndl.go.jp/dl/book/2563421)。NDL書誌の刊年欄は「写」のみで**成立年代の記載なし**（frontmatterのyear 1650は江戸前期地誌としての配列上の目安であり、書誌確定値ではない）。**repo既登録の『江戸砂子』（[GAZ-027](GAZ-027.md)＝江戸砂子温故名蹟誌）・『改正新編江戸志』（[GAZ-039](GAZ-039.md)・東武懐山子・天保3年）とは別書**で、近藤義休本『江戸志』の資料ファイルとしてはrepo初出（[GAZ-094](GAZ-094.md)が引く「江戸志掲載の金剛寺略縁起」・[GAZ-027](GAZ-027.md)の引用する江戸砂子とは書名が紛らわしいので注意）。**すべての引用は同館OCRテキスト由来で文言は原文画像との照合を要する。**
- **橋場条の松橋文言〔確認・repo初出の本文〕**: 「**橋場本名石浜。源平盛衰記を考るに頼朝隅田川に浮橋を掛しめ此川を渡り豊島の上瀧野川松橋に陣となれはその時の橋場なる故かくは名付るなるへし**」＝**①橋場の本名＝石浜、②盛衰記の「隅田川の浮橋→上瀧野川松橋の陣所」の記事を根拠に「その時の橋場なる故」＝隅田川渡河の橋場が橋場の地名の由来であるとする橋場由来説、③その際の盛衰記の採録表記が「上瀧野川松橋」**＝**松橋文言の江戸前期地誌（近藤義休本）による直接採録の本文で、表記は考証書系の「上瀧野川」（江戸初期版本系の「上瀧野河」との対照）**〔GAZ-096の表記対立群の整理に、版本系と江戸後期考証書の中間に位置する（と推定される）江戸前期の採録例として加わる。ただし本書の成立年代が書誌未確定のため年代基準点としては原画像・書誌確認が前提〕〔OCR・要照合〕。
- **江戸砂子の太平記解釈への批判的按語〔確認・repo初出の本文〕**: 引き続き「**江戸砂子云太平記に新田武蔵守むさし野の軍に少負石浜まて引たると有は今の橋場といへりと云う。按するに江戸砂子作者太平記をいかゝ見しや。新田方石濱まては勝軍也。太平記三十一巻に…義宗打勝て追来り玉ふ也。然るを江戸砂子に新田武蔵守石浜**（まで引きたる）**」**＝**①「橋場＝石浜」の同定は江戸砂子（の先行説）に由来すること、②江戸砂子が太平記の「新田武蔵守…石浜まで引きたる」を「少負（小負・敗走）」と読んだことに対し、太平記本文では石浜まで新田方が勝ち進むのであるから誤読であるとする批判的按語**＝橋場由来説の系譜（隅田川の橋場〔盛衰記〕vs 石浜の敗走〔太平記〕）が江戸前期の地誌で競合していた記録〔OCR・文言は要照合〕。
- **位置づけ〔観察〕**: ①松橋陣所文言を橋場（浅草側・隅田川下流）の地名由来に接続した最早的採録例の候補（盛衰記の「江戸葛西に仰て浮橋渡す」〔GAZ-096〕の江戸側の橋の場の解釈）。②GAZ-094（東京市史稿経由）の江戸志引く金剛寺略縁起「上瀧の河松橋」・江戸志按語（上矢批判）と本条の「上瀧野川松橋」は**同一書内で引用先によって表記・橋名の現れ方が異なる（候補）**＝引用元（盛衰記本文/略縁起）ごとの表記の貼り分けの資料。ただし**両者が同一の『江戸志』（近藤義休本）の何巻に当たるかは未確認**（本回は[2]のみ、金剛寺・王子条の所在冊の特定は未了）。
