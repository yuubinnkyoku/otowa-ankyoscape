# [GAZ-003] 茗荷谷・清水谷の地誌と町名

- 東京都公文書館『御府内備考』四十五・四十六（1829年、東京府本）、小日向之一の目録に「茗荷谷」「清水谷」が別項目で現れる。
- https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_01&pkey=000100952
- 地誌・古地図の解説：「坂と歴史の町・小日向の坂道」 https://ma-maison.sakura.ne.jp/hill/sakamichi/sakamichi3_kohinata.html
- **史料の書誌・目録を確認済み。谷名が指す正確な地理的範囲は一次史料本文・古地図との照合が必要。**
