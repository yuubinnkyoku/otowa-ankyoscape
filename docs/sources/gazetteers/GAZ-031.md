- **書誌〔確認〕**: 『**江戸名所和歌集**』（成立年代未詳・NDL書誌の出版年「[18--]」・写本）。江戸の名所を詠んだ和歌の集成。NDL次世代デジタルライブラリー [book/2563039](https://lab.ndl.go.jp/dl/book/2563039)。**すべての引用は同館OCRテキスト由来であり、和歌の本文・歌人の名はくずし字原本との照合を要する。**〔成立年代・撰者は目録レベルで未確認。年欄の「1800」は世紀目安であって特定年ではない〕。
- **弦巻川の独立項目〔確認・repo初出〕**: 「**山吹の里**〔の項の後〕**弦巻川** **あつさ弓つるまや川のつしきてみれはやよりも早く水のなかるゝ**（歌人名OCR不確定）」「**駅梓弓つるまゆき川の本すゑをさやにてらして飛またるかな**（歌人名OCR不確定）」〔続けて**鼠山**の項〕＝**①「弦巻川」が江戸名所の和歌集の独立項目として立項されている、②「つるまや川」「つるまゆき川」と詠まれた和歌が2首残る、③配列は山吹の里→弦巻川→鼠山**＝**江戸期の和歌集成レベルで弦巻川が名所として詠まれた記録**〔和歌本文の確定字（「あつさ弓」「駅梓弓」の初句表記・「つしきて」「本すゑ」等）はOCRの誤読を含む可能性が高く、全て原本照合まで和歌の確定本文とは扱わない。歌人名の帰属もOCRの行混在で不確定〕。
- **位置づけ〔観察〕**: 弦巻川を詠んだ和歌の存在は、①[BOOK-124](../books/BOOK-124.md)（1937・蜀山人の狂歌「つる巻川の瀧の白糸」）が江戸期狂歌として引く系統、②[GAZ-031]の和歌2首（和歌）の系統として、**弦巻川が江戸期に「名所」として文学に詠まれた痕跡**を初めて直接資料で確認した点で意義がある〔蜀山人狂歌の原典（狂詩文）との照合・本歌集の成立年代の特定が今後の課題。「梓弓」の語は義家弓弦説の周縁語彙（弓・弦）に通じるが、和歌の詠んでいるのは川の流れの速さであり、直接由来を詠んだものではない〕。
