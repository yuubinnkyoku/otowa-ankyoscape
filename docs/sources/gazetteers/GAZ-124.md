# [GAZ-124] 町方書上[74] 外神田町方書上二 — 68間余・80間余条の町方原本側と板野/牧野のOCR対立

- **書誌〔確認〕**: 『町方書上[74] 外神田町方書上　二』（写・NDL次世代デジタルライブラリー [book/2571555](https://lab.ndl.go.jp/dl/book/2571555)・103コマ）。署名は神田六軒町（三月）、柳原右衛門町（文政十亥年三月）、神田相生町（文政十亥年四月）、上野町代地（同三月）、神田松永町（同四月）、（六日）麹町等。**引用文言はすべてOCR由来で要原文照合。ページ番号は `2571555_{NNNNNNN}.txt` コマ番号。**
- **中樋68間余＋片町小樋80間余条〔文言候補・本冊の主要価値〕**: 「**千川上水之儀は安永九子年十月廿七日板野大隅守様御番所御掛りニ而上水掛渡之儀被仰付候儀二而町内往還大道は中樋二而上野町代地境ゟ神田佐久間町弐丁目持場境迄凡六拾ト八ツ間（宗）片町は小極二而神田相生町地境ゟ最堂和泉守様御屋敷脇迄凡八拾間余懸渡有之候処天明七未年四月十三日御差止二相成候旨被仰渡通達有之其節取潰埋立申候但元禄之度千川上水御掛渡之義相分不申候**」（p54）＝〔**①上水掛渡の仰付＝「安永九子年十月廿七日」＋「板野大隅守様御番所」＝外神田側の再興触文言で [GAZ-041](GAZ-041.md)（神田仲町条・牧野大隅守・発願人宇田川長十郎）・[GAZ-043](GAZ-043.md)（旅籠町弐丁目条）と日付が一致する**原本側の裏付け文言**。②**「板野大隅守」は [GAZ-041](GAZ-041.md)・[GAZ-125](GAZ-125.md) の「牧野大隅守」とのOCR対立（原字照合課題）**。③区間構成＝本町（表町）が中樋で上野町代地境〜神田佐久間町2丁目持場境まで凡68間余、片町（宗片町＝相生町側の片側町）は小樋（OCR「小極」候補）で神田相生町地境〜藤堂（OCR「最堂」対立）和泉守様御屋敷脇まで凡80間余＝[GAZ-044](GAZ-044.md)（御府内備考・相生町条系の「68間余＋80間余」文言）の町方原本側対校。④差止＝「天明七未年四月十三日」＋通達文言＝日付13日系（[GAZ-041](GAZ-041.md)・[GAZ-043](GAZ-043.md)・[GAZ-044](GAZ-044.md) と同型）**〔[GAZ-125](GAZ-125.md)（外神田町方書上四・久右衛門町条）の「四月十二日」・[GAZ-127](GAZ-127.md)（浅草側）の「四月十二日」との差止日粒度の対立群の一翼〕。⑤「**元禄之度千川上水御掛渡之義相分不申候**」＝元禄期の記憶喪失文言。⑥**条帰属＝署名p55「神田松永町名主」条（p42上野町代地署名〜p55の間）候補だが、文言内の樋区間（上野町代地境〜佐久間町2丁目境）と [GAZ-044](GAZ-044.md) の御府内備考側の採録町（相生町条系）との帰属の一致・不一致は条境界の原画像照合まで確定しない**〕。
- **同条内の周辺文言〔付記レコード〕**: p53＝同条前段に狩野伯国の元禄十三辰年拝領町屋敷・奥御坊主田村圓良の享保十一午年堀江六軒町への御形替上地の記載。p54＝文政六未年正月勧請の「栄福稲荷」の由緒。〔樋文言と同じ条に含まれる屋敷・社の記録。樋文言の位置割り出しのための隣接情報として照合時に使う〕。

## 制限・未解決

- ①「板野／牧野」「最堂／藤堂」「小極／小樋」「宗片町」等の語形はすべてOCR対立の原字照合課題。②本条の条帰属（神田松永町条候補）は署名位置からの推定で、[GAZ-044](GAZ-044.md)（御府内備考の採録側・相生町条系文言）との帰属のすり合わせ（同一条か別条か）は原画像照合まで判断しない。「凡六拾ト八ツ間」の数値も要照合。③「元禄之度…相分不申候」の文言は [GAZ-118](GAZ-118.md)（本郷竹町条・元禄初掛文言あり）と対照すると当町では元禄期給水の記憶が残らなかったことの外神田側例になるが、町ごとの記憶の濃淡として観察する以上の解釈はしない。④「栄福稲荷」「狩野伯国拝領屋敷」等の位置と樋文言の位置の関係は未検討。
