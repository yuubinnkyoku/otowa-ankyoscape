# [GAZ-020] 『御府内備考』巻之五十一「高田」・巻之五十二「雜司ケ谷町」（大日本地誌大系 第3巻）

- 書誌：大日本地誌大系 第3巻 御府内備考（雄山閣、昭和6年、NDLJP:1214872、インターネット公開）。巻之五十一「高田」はコマ25左頁下半分〜コマ26（印刷頁31〜33）。巻之五十二「雜司ケ谷町」はコマ27〜28（印刷頁34〜37）で、収録は雜司ケ谷町・鬼子母神門前・本淨寺門前・本染寺門前。巻之五十三「牛込之一」はコマ29右頁から始まる。
- 2026-10-30、NDL刊本画像の目視走査（ビューア全文検索は位置特定の補助）による読取（ai）。読みに確信の持てない字はその旨を記す。

## 内容メモ（水関係と周辺の土地利用のみ。解釈は書かない）

- 巻之五十二には、川・池・下水・用水・悪水・橋を題目とする独立した項目はない。水系の固有名として現れるのは弦卷川のみで、丸池は現れない。
- 川口飴商賣の項（印刷頁36）：鬼子母神境内で正徳年中から飴を売り始めた川口屋の名の由来として、この地に弦卷川があり、その流れが尽きないことにちなむと記される。川そのものの幅・流路・橋を記す項目ではない。「川口」は屋号であり河口ではない。紋所の「露の丸」の「露」の字はOCRが「霧」と読むため要再確認。
- 田畑関係：雜司ケ谷町の四隣は東が法明寺領雜司谷村畑地、西が下高田村、南が小石川四ツ家町、北が自證院領・傳通院領入會雜司谷村百姓家。本淨寺門前の町屋は四方とも雜司谷村畑である旨、本染寺門前の東も雜司ヶ谷村畑である旨が記される。鬼子母神門前の来歴には、往古は雜司ヶ谷村の内で、社地門前に百姓二三軒があったが田地はなかった旨がある。
- 「水窪」の語は、第3巻（巻之四十七〜七十四）の全文検索で該当がなく、巻之五十二の目視でも見当たらない。
- 巻之五十一「高田」にも、川・下水・橋を題目とする独立した項目はない。
