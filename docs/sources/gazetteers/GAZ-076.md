# [GAZ-076] 関口寺社書上（文政10年）— 関口水神社の起立書上〔第151回〕

- **書誌〔確認〕**: 『寺社書上 [61] 関口寺社書上 全』（文政10丁亥年〔1827〕の寺社御調書上の写・NDL次世代デジタルライブラリー [book/2571418](https://lab.ndl.go.jp/dl/book/2571418)）。巻頭に「**高源寺 一や永泉寺 吉（？）目白不動堂別当新長谷寺 一日正八幡社別当同寺 長光寺 同勘七丁まし（？）目白台町幸神社 神主村上近江 一口水神社 川当 同津大泉寺 …養国寺 …蓮光寺 二七六ノ第六十関口寺社書上**」の寺社列挙。**引用文言はすべてOCR由来で要原文照合**。
- **関口水神社の起立書上〔確認・repo初出の書上レベル文言〕**: 「**百五（？）関口水神社 起立 別当洞雲寺 七日（？）御除地九百坪 一水神社 一神躰別ニ無之 本地仏妙見木（塵？）像丈七寸八分 作相知不申候 一相殿群（弁？）財天木里（立？）像丈七寸五分 楯山八幡宮 馬上来帯（？）丈五寸 何レも作相知不申候 一鎮座勧請（勧諸）年代相知不申候 一祭礼五月十五日 水神八幡両祭礼 一氏子ハ目白坂正八幡同様別ニ無之 此辺ヲ楯山ト相伝候ハ 地名ニ而精山（楯山？）八幡ト世俗ニ相場（相唱）来り候**」＝**①関口水神社の起立（御調書上）＝別当は洞雲寺・御除地900坪・神体はなく本地仏妙見（木像丈7寸8分）＋相殿の弁財天（7寸5分）と八幡（5寸）・鎮座勧請年代は不明・祭礼は5月15日（水神・八幡の両祭礼）、という書上の文言候補**。〔**①[GAZ-048](GAZ-048.md)⑨の風土記稿の水神社文言「水神社八幡を合殿とせり 本地妙見を安す 辨天八幡關口洞雲寺持」との対校＝風土記稿（文政〜天保期編纂）とほぼ同時期の寺社奉行側の書上で、八幡合殿・本地妙見・洞雲寺持が一致し、御除地900坪・祭礼5月15日の量的情報が書上側の初出**。②[GOV-264](../gov/GOV-264.md)の明治2年「関口村大洗堰上水神前」の高札文言＝大洗堰近くの水神（水神社）への言及と接続する、江戸期の起立書上レベルの実体。神体を欠き本地仏で祀る構造は、水神＝上水の堰の守護神としての権現構造の観察資料（解釈は断定しない）。③「此辺を楯山と相伝」＝水神社周辺の小字・通称の記録候補。〕
- **正八幡社（上之宮）・水神社相殿八幡（下之宮）の伝承〔確認・文言候補〕**: 「**当社ヲ上之宮ト唱候ハ 当寺持水神社相殿八幡社ヲ下ト相催候ヨリ世俗ニ申伝候 相殿本地仏等無之候 一鎮座之年月相知不申候 縁起等無之 一神木銀杏 廻り一丈五寸 一氏子 関口水道町 同台町（目白台？） 大泉寺門前 新長谷寺門前 駒井町 其外目白台武家方不残**」＝**関口正八幡社が「上之宮」・水神社の相殿八幡が「下の宮」と世俗に唱えられる伝承＋正八幡社の氏子は関口水道町・台町（目白台）・大泉寺門前・新長谷寺門前・駒井町・目白台武家方**の文言候補。〔**関口の給水地（大洗堰・神田上水沿い）の氏子範囲＝関口水道町・目白台の武家方・門前町屋の列挙**＝[GAZ-048]の関口町在方分（貞享2年関口水道町の町並化・元文2年駒井町等の3町・享保5年台町）と対照できる、江戸期の関口の集落構造の書上レベルの記録（OCR崩れ多く要照合）。〕
- **目白不動（新長谷寺東豊山）・養国寺の書上〔確認・参考〕**: 「**目白不動起立書 境内御除地千七百九拾弐坪 新義真言宗 和州長谷小地坊（本？）末 目白不動別当東豊山本堂間数七間四面新長谷寺浄瀧院但通名寺号相用申候 本尊不動尊弘法大師御作秘仏開帳…元文年中石川播磨守殿造立不動堂相殿木立像丈壱丈余**」＋養国寺条の「**文政十丁亥年三月十五日**」の書上年次＋元和4年起立・大和国豊山長谷寺からの勧請・「**堂前に榎の老木今ニ存ス 俗ニ袈裟掛之木ト云フ**」・「**大勤院様御狩リノ時…城南ノ目黒ニ対シ 爰ヲ目白ト名クベシト仰事アリシヨリ目白不動ト世上ニ申広マレリ 此以前ハ関口不動ト云**」＝**目白不動（新長谷寺）の起立書上＝元和4年（1618）起立・元和4年赤井氏らの檀那・四世秀算僧正の中興・台徳院様（秀忠）依命の殿堂・大和長谷寺と同作の観音を移し東豊山・新長谷寺と号す・「此以前ハ関口不動ト云」**の文言候補。〔**目白不動の旧称が「関口不動」であった旨の書上レベルの文言候補**＝関口の給水地の宗教景観（水神社・正八幡・目白不動・洞雲寺）の変遷の記録（「袈裟掛の木」・「目白」の命名譚は縁起文言として要照合）。水系直接の文言ではないが、関口水道町・大洗堰の社会史の背景資料として記録する。〕

## 制限・未解決

- ①文言はOCR由来（書上写で崩れ大）で、御除地九百坪・千七百九拾弐坪・氏子町名（台町＝目白台の判別）・「楯山」等は原画像照合を要する。②水神社の位置（大洗堰の上流側・下流側、現・関口水神社〔関口一丁目か〕の比定）は本書上からは確定できない（「川当」の巻頭文言は位置の手掛かり候補に留める）。③「上之宮/下之宮」伝承の意味構造（祭神の上下・祭祀権の序列か）は断定しない。④目白不動条の元和4年・赤井氏・四世秀算等の縁起文言は伝承としての性格が強く、起立年代の一次確認（棟札・過去帳）は未実施。⑤永泉寺・大泉寺・目白不動条の精読は第152回追記（2026-11-17）で実施（未精読は解消）。ただし高源寺・長光寺・幸神社・蓮光寺条の水系文言は引き続き未精読（精査は次回課題）。
