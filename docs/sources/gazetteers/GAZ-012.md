# [GAZ-012] 『御府内場末往還其外沿革図書』

位置づけ（地図一覧の表記）: 地図を含む沿革図書の史料群。国立公文書館の解説あり。対象図そのものは未閲覧

## 貮拾利の同定（2026-10-30、NDLデジタルコレクションのIIIFマニフェストと詳細ページの直接確認・ai）

- 『御府内沿革図書』は江戸幕府普請奉行の編纂で、延宝年間から幕末までの土地利用の変遷を文章と各年代の地図で示す地図集（全22部。第15部までが『御府内往還其外沿革図書』、第16部以降が『御府内場末往還其外沿革図書』）。
- 本研究の対象域（小石川・巣鴨・音羽・関口村・雑司ヶ谷村・池袋・滝野川・板橋辺）は第20部に収まる。第20部は元・亨・利・貞に細分され、国立国会図書館デジタルコレクションの書誌レコード（書誌ID 000007328931、請求記号 802-38、全45分冊）では、元が分冊[21][22][23]、亨が[24][25]、利が[26][27]、貞が[28][29][30]に対応する。
- 研究メモに残っていた2つのPIDは、いずれも貮拾利の分冊と同定できた：
  - PID 2587246 = 分冊[26]貮拾利（利の第1分冊）。IIIFマニフェスト（https://dl.ndl.go.jp/api/iiif/2587246/manifest.json ）のメタデータで書名・請求記号・書誌ID・DOI 10.11501/2587246 を直接確認。アクセス制限は PDM（保護期間満了）。
  - PID 9370096 = 分冊[27]貮拾利（利の第2分冊）。詳細ページで公開範囲「インターネット公開（保護期間満了）」を確認。DOI 10.11501/9370096。
- 未確認のまま残る点：第20部の元・亨・利・貞がそれぞれ第20部内のどの小地域を担当するかの対応（特に「利」が雑司ヶ谷村・本立寺辺を含むか）は、冊自体の凡例・目次コマの判読が要る。1772年図との照合（[音羽谷西側の弦巻川下流の成立年代](../../open-questions/音羽谷西側の弦巻川下流の成立年代.md) の決着資料リスト第3項）はこの同定の次段である。

## 貮拾利の収録範囲（2026-10-30、PID 9370096 の表紙コマの読取・ai）

- 分冊[27]（PID 9370096）は全7コマで、第1コマは地図巻の表紙である。表紙には「嘉永七寅年十月調」「一圓之繪圖 貮拾利」とあり、収録地として桜木町・音羽町・東青柳町・大塚・小石川村・同字新田・巣鴨村・小日向村・雑司ヶ谷村・高田村・下高田村が挙がる（一部の字形は要再確認）。すなわち貮拾利は音羽町・雑司ヶ谷村を含む分冊であり、上で未確認とした「利」の担当域はこの表紙で確定した。
- 第2〜7コマが一圓之繪圖の図葉で、各18723×13249ピクセルの大判である。国立国会図書館のIIIF配信では全体縮小の取得がサーバ側で失敗するが、部分（リージョン）取得を組み合わせたモザイクで全体像は再構成できる（2026-10-30、全6葉のモザイクを作成して概観した）。6葉は管轄域を分担する図葉で、各葉に方位の一字（東・西・南）が記される。概観の対応は次の通り：第2コマ＝高田村の田畑、第3コマ＝町地と大縄地、第4コマ＝雑司ヶ谷村・法明寺・本立寺、第5コマ＝護持院（護国寺）と音羽町・小石川村の周囲、第6コマ＝雑司ヶ谷村・巣鴨村・御鷹方御役地・松浦金三郎屋鋪・本立寺（[成立年代ドキュメント](../../open-questions/音羽谷西側の弦巻川下流の成立年代.md) のいう「本立寺辺之部」に相当する図葉）、第7コマ＝護持院の北側と小石川村・巣鴨村。水路・池の細部の読図は未実施。

## 対象域の分冊の追加同定（2026-11-15・第107回追記・次世代DL全文横断）

  - **「神田上水堀筋并同所大洗樋下川筋」の境界文言**——下戸塚村の井伊掃部頭抱屋敷周辺の地所四隣に「**東北之方 神田上水堀筋并同所大洗樋（大洗堰）下川筋迄**」「**神田上水堀筋并上小咄（小日向）大洗堰下川筋等**」〔**神田上水の堀筋と大洗堰の下の川筋が嘉永5年（1854）の村方地所の境界として現れる一次文言**。大洗堰（関口の堰）の嘉永期の実在を書上レベルで示す〕。
  - **関口村の「水番屋構并水当人持地」**——同じ地所四隣に「同所之内**水番屋構并水当人持地**」〔神田上水の水番屋・水番人の持地の嘉永5年の存在を示す書上記録候補〕。
  - **掃部橋際の元禄8年（1695）頃の記述**——小日向西古川町の地所の沿革に「**元禄八亥年頃 北手掃部橋際 小日向西古川町百姓町屋**」〔**沿革図書特有の旧時点対比（延宝年中→当時）による、掃部橋際の元禄8年頃の存在を示す記述**＝掃部橋の最古の年代付き記録候補。享保13年（1728）『江戸洪水記』の流失記録（[BOOK-126](../books/BOOK-126.md)）を33年さかのぼる「橋際」の地名認識のデータポイント〕。
  - **関口村の町並発達の年代記述**——「貞享二丑年頃南手関口村百姓町屋弐ヶ所崩家町並地ニ成候由」「**元禄十丑年中**東手關口村百姓地護国寺領ニ成…**正徳三己年中**右關口村護国寺領百姓町屋町〔並〕…」〔貞享〜正徳（1685-1713）の関口村（江戸川合流点周辺＝弦巻川・水窪川の流末側）の町屋の発達年代を書上が記す〕。
