## 貮拾利の同定（2026-10-30、NDLデジタルコレクションのIIIFマニフェストと詳細ページの直接確認・ai）

- 『御府内沿革図書』は江戸幕府普請奉行の編纂で、延宝年間から幕末までの土地利用の変遷を文章と各年代の地図で示す地図集（全22部。第15部までが『御府内往還其外沿革図書』、第16部以降が『御府内場末往還其外沿革図書』）。
- 本研究の対象域（小石川・巣鴨・音羽・関口村・雑司ヶ谷村・池袋・滝野川・板橋辺）は第20部に収まる。第20部は元・亨・利・貞に細分され、国立国会図書館デジタルコレクションの書誌レコード（書誌ID 000007328931、請求記号 802-38、全45分冊）では、元が分冊[21][22][23]、亨が[24][25]、利が[26][27]、貞が[28][29][30]に対応する。
- 研究メモに残っていた2つのPIDは、いずれも貮拾利の分冊と同定できた：
  - PID 2587246 = 分冊[26]貮拾利（利の第1分冊）。IIIFマニフェスト（https://dl.ndl.go.jp/api/iiif/2587246/manifest.json ）のメタデータで書名・請求記号・書誌ID・DOI 10.11501/2587246 を直接確認。アクセス制限は PDM（保護期間満了）。
  - PID 9370096 = 分冊[27]貮拾利（利の第2分冊）。詳細ページで公開範囲「インターネット公開（保護期間満了）」を確認。DOI 10.11501/9370096。
- 未確認のまま残る点：第20部の元・亨・利・貞がそれぞれ第20部内のどの小地域を担当するかの対応（特に「利」が雑司ヶ谷村・本立寺辺を含むか）は、冊自体の凡例・目次コマの判読が要る。1772年図との照合（[音羽谷西側の弦巻川下流の成立年代](../../open-questions/音羽谷西側の弦巻川下流の成立年代.md) の決着資料リスト第3項）はこの同定の次段である。
