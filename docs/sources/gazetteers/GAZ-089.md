# [GAZ-089] 町方書上（大久保前町・柏木成子町）— 市ヶ谷村起源の町の書上と柏木村方の横切下水〔第165回〕

- **書誌〔確認〕**: 『町方書上』冊頭「**大角筈千駄谷町方喜上 二七五ノ第七十五**」（大久保前町・柏木成子町・千駄ヶ谷・淀橋町等の町方書上の集冊）。NDL次世代デジタルライブラリー [book/2571628](https://lab.ndl.go.jp/dl/book/2571628)。**文政十亥年5月**の地誌御調書上。**引用文言はすべてOCR由来で要原文照合。**
- **大久保前町の起源・町方化の年代層〔確認・核心〕**: 「**当町往古は武州豊嶋郡野方領市ヶ谷村之由其後年代并御役名不知小宮山伝三郎殿屋鋪ニ御座候處代地不知引地ニ相成候跡元禄十二卯年八月中野御囲下役相勤候安田忠左衛門同小坂八太夫同才戸孫次郎右三人拝領被致百姓町家作御免御座候由其後正徳三己年壬五月中町方御支配に相成**」＝**大久保前町が①往古は野方領市ヶ谷村、②小宮山伝三郎の屋敷地が引地に、③元禄12卯年8月（1709）に中野御囲下役の安田忠左衛門・小坂八太夫・才戸孫次郎の三人が拝領・百姓町家作御免、④正徳3己年5月（1713）に町方御支配化**という年代つきの変遷〔**野方領市ヶ谷村起源の町が元禄12年拝領・正徳3年町方化で成立した町方側の一次書上**〔repo初出の年代層。町銘の由来は「町西南の方一円に大久保村に有之候場所二而当所町方御支配に相成候に付大久保前町と町銘名付候哉之旨町内申伝」＝大久保村に面することからの付名の伝承（「哉」の付いた推量形のまま記録）。「壬五月」は干支と月の混線か・要照合〕。
- **柏木村方面への横切下水〔確認・文言候補・repo初出〕**: 「**右松平中務大輔様御下屋敷脇横町際より□六上柏木村江流申候横切下水石橋壱ケ所下水之幅弐尺橋之幅三間四尺五寸当町并淀橋町堺横町両町掛り下水長両側ニ而三百五拾間程巾弐尺**」＋「**当町ゟ淀橋町江流申候一右下水石橋壱ケ所下水之幅弐尺橋之幅壱間四尺**」＝**①松平中務大輔の御下屋敷脇の横町際から柏木村へ流れる横切下水（幅2尺・長300間余・石橋1か所＝橋幅3間4尺5寸）、②大久保前町から淀橋町へ流れる横切下水（幅2尺・石橋1か所＝橋幅1間4尺）**という、大久保前町周辺の東西方向の横切下水2系統の書上〔**柏木村（野方領）方面へ向かう横切下水の文言＝野方領側の水路（千川系・野方堀系の候補）との対校案件**〔repo初出〕。**流路の比定・千川上水との関係は本文言からは断定しない**（大久保前町は四谷区域の町で、柏木村はその北西の野方領村。幅2尺の小下水で上水ではなく悪水・下水の性格。「□六上」はOCR欠損〕。
- **町名起り・寺社・名物の周辺文言〔確認・参考〕**: ①当町中程の坂が「**享保年中地蔵相建候より坂以来地蔵坂と唱申候由当時は成子坂より唱申候**」＝享保年中の石地蔵起立による地蔵坂→成子坂の呼称の変遷、②石地蔵は「**享保十二未年勝厭と申道心者廻国終而当町え罹越右地蔵を相建候**」＝享保12年（1727）・勝厭道心の起立、③「**当所名産…元和年中之頃専作り上納致候由年々瓜畑を撰…元和六年申八月右瓜畑調役人坂本次郎右衛門根本与左衛門落合九左エ門**」＝元和6年（1620）の瓜畑上納と調役人3名、④柏木成子町側の町名起り「**往古は当町之末南側往還ゟ少々引込民家…萱筵を張…酒其外を出し置其側江鳴子ニ縄を附置…右縄を曳候得者住家より人出来り當内致候事…自然と往来人鳴子被申候より所之名之様ニ申触シ夫ゟ惣名に相成…以前は文字を鳴子と相認め候得共何之頃ゟ改メ候哉當時者成子と相認め申候**」＝**「鳴子」（よばわり用の鳴子）の仕掛けの店から「鳴子」→「成子」の町名への変遷**、⑤「**小田原北条時代迄は本住坊と申寺領二而天正十五丁亥年七月中北条家ゟ之触書等も有之今に右文書名主紋右衛門方に持伝罹在候**」＝**天正15年（1587）7月の北条家の触書が柏木成子町の名主紋右衛門方に現存**する書上〔成子坂・鳴子・天正15年触書の町名・文書レベルの記録（repo初出群。本住坊寺領の文言を含む）〕。
- **家数の内訳〔確認・参考〕**: 「**一町内惣家数三百三拾弐軒内五拾三軒明き店家持弐拾九軒地借五拾三軒店借百九拾七軒**」等の家数構成と自身番屋・火之見の文言〔文政期の町方書上の標準形式の用例〕。

## 制限・未解決

- ①横切下水の千川上水・野方堀系との対応は対校保留（幅2尺の下水で、上水路そのものと見る根拠はない。柏木村方の水路の既存記録〔千川上水の柏木村通過〕との位置対照が次回課題）。②「□六上」・「壬五月」・「勝厭」等のOCR崩れは原画像照合を要する。③大久保前町の書上の名主の系譜文言（天正15年北条家触書の川本杢右衛門〔大久保前町側か柏木成子町側か〕の帰属）は文脈の再確認を要する（触書の保有は柏木成子町名主紋右衛門と記される箇所と、大久保側の名主の由緒文言の混在の可能性）。④「富賀谷端円右衛門」型の文言はOCR崩れで谷端川とは無関係の人名の可能性が高い（採録せず・谷端川への関連付けはしない）。
