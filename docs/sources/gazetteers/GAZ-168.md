# [GAZ-168] 町方書上[105]+[110] — 新坂町・吉岡町条の本所上水修復請負人孫八伊兵衛文言の2冊対校

- **書誌〔確認〕**: ①『[105] 本所町方書上 四』（写・NDL次世代デジタルライブラリー [book/2571586](https://lab.ndl.go.jp/dl/book/2571586)。NDL API volume欄直接確認）＝本所新坂町御用屋敷条（koma 83-85）、②『[110] 本所町方書上 九』（写・[book/2571591](https://lab.ndl.go.jp/dl/book/2571591)）＝本所吉岡町壱丁目御用屋鋪条（koma 9）。ともに引用文言はすべてOCR由来で要原文照合。※同一の上水修復請負人文言が別冊の別町条で書き分けられている対校資料（同型2冊まとめ採録）。
- **桶掛と樋掛の修復請負人文言の対校〔文言候補・本冊最重要〕（[105] koma 83・[110] koma 9）**: ①[105]新坂町条「**本所御奉行藤堂庄兵衛様多賀又四郎様御勤役中 元禄年中 本所上水桶掛破損修復御請負役 孫八伊兵衛と申者え被仰付 其節ゟ右両人に而当屋敷地品拝借致右請負役相勤罷在候処 享保四亥年四月本所御奉行相止候節右拝借地被召上 同年十月廿七日本所御用屋敷に被仰付 道役清水八郎兵衛家城善兵衛え御預け被仰付候**」（koma 83-84・OCR）、②[110]吉岡町条「**本所御奉行藤堂庄兵衛様多賀又四郎様御勤役中 元禄年中 本所上水樋掛破損修復之御請負役 伊兵衛孫八与申者江被仰付 其節より右間数地所拝領致相勤候処**」（koma 9・OCR）＝**元禄年中、藤堂庄兵衛・多賀又四郎の本所御奉行勤役中に「本所上水の桶掛（→新坂町側文言）/樋掛（→吉岡町側文言）破損修復」の御請負役を孫八・伊兵衛（/伊兵衛・孫八・語順対立）が命じられ、拝借屋敷で請負役を勤めた**という同型文言の2冊対校。〔**①「桶掛」・「樋掛」という上水施設部位の別の修復請負文言のペア（repo初出候補）、②人名の表記対立「孫八伊兵衛」vs「伊兵衛孫八」＝2人連名（桶掛/樋掛の分業）か同一名の書き崩しかは原画像照合まで決めない、③享保4年（1719）4月奉行廃止で拝借地召上→同年10月27日本所御用屋敷→道役清水八郎兵衛・家城善兵衛御預けという[GAZ-165](GAZ-165.md)の道役文言（同日付の大岡越前守御内寄合）と完全に同期する処分チェーン**。〕
- **新坂町条の隣接・横川文言（koma 84-85）**: 「**隣町東之方横川向柳島出村町…**」（koma 84-85・OCR）＋「**横川内弐拾間 右は町内東之方に有之 万治年中本所御奉行徳山五兵衛様山崎四郎左衛門様…**」（koma 85・OCR）＝新坂町東方の横川（柳島出村町との間）の万治年中堀割文言候補＝[GAZ-170](GAZ-170.md)（神田徳右衛門町条の「横川巾弐拾間…万治2年堀割」）・[GAZ-172](GAZ-172.md)（元町条の「横川幅凡拾七間程…万治二亥年中初而御堀割」）・[GAZ-165](GAZ-165.md)（起立記の「横川…新規御堀立」）と横川巾・堀割年代が揃う対校群（巾は17間/20間で対立するため原画像照合まで優劣を決めない）。

## 制限・未解決

- ①すべてOCR由来で要原文照合。「桶掛」「樋掛」の施設部位の原字、「孫八伊兵衛」の姓名配列、万治年中/万治二亥年 の粒度差は照合前提。②koma 83-85の条区切り（新坂町条の途中で隣接情報が混在）はOCR境界で一部推定。③修復請負の「元禄年中」の具体年次は本2冊からは確定しない（藤堂庄兵衛・多賀又四郎の本所奉行在職期の同定は外部史料待ち）。④[110]吉岡町条のその後の文言（奉行廃止以降の処分）は本冊の後続komaに未確認＝対称を取るまで新坂町条のみの情報。
