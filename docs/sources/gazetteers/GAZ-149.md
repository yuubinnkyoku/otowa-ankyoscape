# [GAZ-149] 町方書上[16] 駒込弐 — 浅嘉町条の詳細文言と4条のcross-ref群

- **書誌〔確認〕**: 『[16] 駒込町方書上　弐』（写・NDL次世代デジタルライブラリー [book/2571497](https://lab.ndl.go.jp/dl/book/2571497)）。文政10亥年（1827）の地誌御調書上。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571497_{NNNNNNN}.txt`）で示す。※第225回並走実行でdraft化され、第226回で採番・pushした（第225回並走インシデントの回収分）。工程文言の本体は[GOV-224](../gov/GOV-224.md)（[15]駒込壱）に既登録のため、本ファイルは駒込弐冊側の文言変種とcross-ref群の記録が中心。
- **浅嘉町条の千川上水文言〔文言候補・本冊最重要〕（p9）**: 「**一千川上水跡町内往還中程相通り申候**　且明和六丑年二月中 浅草田原町小兵衛店忠兵衛 同町嘉右衛門店孫兵衛 高砂町三郎兵衛店幸右衛門 右三人千川上水掛渡奉願 安永八年十一月廿八日御検地御改有之 掛渡出来仕 天明二寅年八月中ゟ水銭小間壱間二付弐拾八文ツヽ上納仕 其後同六午年五月中ゟ水銭半減二〔=ニ候補〕被仰付 同九月中ゟ出桟相止 其後埋立被仰付候」＝①「千川上水跡が町内往還の中程を通る」という経路文言候補＝[GOV-224](../gov/GOV-224.md)追分町条「往還上通」（道路の上側）と対になる駒込区内の第2の位置語（浅嘉町と追分町の2点で「往還」に沿う言い回しが揃う＝[GAZ-135](GAZ-135.md)御駕籠町条「巣鴨町往還ゟ…駒込富士前町通り江掛り」に続く往還添い流路の材料。断定はしない）②工程文言（安永8.11.28御検地御改→掛渡→天明2.8水銭開始→天明6.5半減→9月出桟〔=出銀候補〕停止→埋立）は[GOV-224](../gov/GOV-224.md)追分町条・肴町条と同一の定型文の流用＝駒込各町の書上に同一テキストが配布・流用された実務構造の証拠候補（「御見分」〔GOV-224追分町条〕と「御検地御改」〔本条・肴町条〕は同一11月28日事件の表記差・対校材料）。「水銭小間壱間に付28文」の料率文言は[GOV-224](../gov/GOV-224.md)肴町条と同文。
- **浅嘉町の追加記録（p9続き・p43）**: p9条末に日光御成道の御定杭1ヶ所（当町内に百九間余・道幅四間弐尺・「是より内小荷駄馬駄賃馬口附之者乗へからさる」）。p43高林寺門前条内に「隣町名…駒込浅嘉町 高林寺境内ヲ南蓮光寺 戸田阿波守様御下屋敷 小円林寺境内」＝浅嘉町周辺の寺町構造。
- **高林寺門前条のcross-ref文言〔文言候補〕（p43）**: 「**一千川上水跡但委細之義は駒込浅嘉町ニ而申上候**」＝詳細提出を浅嘉町に委譲（条自体は自身番屋〔寛政3亥年8月23日願済〕の記録が主体）。
- **天栄寺門前条のcross-ref文言〔文言候補〕（p61）**: 「**一千川上水跡但委細之義は駒込浅嘉町二而申上候**」＋「大木之さいかち」（皂莢〔サイカチ・マメ科の高木候補〕の判読候補）の下で青物問屋の祖・斎藤安左衛門（授徳院誠覚・貞享三寅年8月18日病死）が渡世を始めたという天栄寺門前の町名由来文言。千川上水言及そのものは委譲文言のみ＝当町を千川上水跡が通ったか否かは当条からは確定不能。
- **吉祥寺門前条のcross-ref文言〔文言候補〕（p78）**: 「**一千川上水跡但委細之義は駒込浅嘉町ニ而申上候相除申合〔=申候候補〕**」＝同じ浅嘉町への委譲文言＋坪数帳の相除文言が連結した形（「相除」の原語は要照合。表記はOCR崩壊〔吉禅寺〕）。
- **片町条のcross-ref文言〔文言候補〕（p71）**: 「**一千川上水跡右委細者駆込〔=駒込候補〕肴町ゟ申上候**」＝[GOV-224](../gov/GOV-224.md)（[15]側）と同じ「駒込肴町へ委譲」文言＝委譲先が浅嘉町系列と肴町系列の2系列に分かれる分業構造が見える。
