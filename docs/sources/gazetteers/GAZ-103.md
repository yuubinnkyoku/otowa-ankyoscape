- **千駄ヶ谷由来譚＝紫の一本と江戸砂子の併記＋按語〔文言候補・由来3系統対校への府内備考層〕**: 「**…別テ(?)リ世の人青山の名をおは(呼)するは誤なり 紫一本に云 太田道灌入道此所を心見(?)とし時 此谷西の稲千駄もあるへしとて千駄ヶ谷と名付しと 又江戸砂子には 昔此辺萱野にて一日に千駄の萱…を出せしゆへの名なりと 未た正しき説を聞す**」＝**①太田道灌の稲千駄説を「紫一本」に求め、②江戸砂子の千駄の萱説を並記、③「未だ正しき説を聞かず」と留保する按語、④「世の人青山の名を呼するは誤なり」（千駄ヶ谷を青山の名で呼ぶことへの批判）**＝紫の一本本文（[BOOK-209](../books/BOOK-209.md)・巡見・稲千万）／江戸志[8]引用（[GAZ-097](GAZ-097.md)・道灌順見・稲千駄）／改正新編江戸志（[GAZ-039](GAZ-039.md)・巡検・橋千駄）の3系統対校に**御府内備考（町方書上編次）の採録層が加わる**（千駄ヶ谷の地名由来はrepo対照表の範囲外として紫の一本引用の対校軸で記録。「心見」「萱野」の判読対立は要照合）。
- **千駄ヶ谷町条＝玉川御上水餘水落川と石橋2・板橋1（掛替年次つき）〔文言候補・repo初出の水路文言群〕**: 千駄ヶ谷町（三ヶ寺領入合＝吉祥寺領・西福寺領・霊山寺領）の条: ①「**一石橋長弐間巾六尺 右玉川御上水除水流川ニ指渡有之 西福寺領吉祥寺領入合百姓地内ニ御座候 去ル文政四巳年五月中石橋ニ掛替 古来ゟ板橋ニ而有之候處 掛始年代相知不申候**」②「**一石橋長九尺巾壱丈壱尺 右玉川御上水餘水流川ニ掛渡有之 西福寺領吉祥寺領入分百姓地内ニ御座候 寛政十午年八月中石橋二掛替 古来板橋二而有之候 尤掛始年代相知不申候**」③「**一板橋長弐間巾六尺 右玉川御上水餘水流川ニ掛渡有之 吉祥寺領西福寺領入合百姓地之内ニ御座候 掛始末代不相知 尤村方持ニ而修覆等仕候**」④「**一玉川御上水餘水落川 巾凡弐間程 右堀割年代不相知 川中不同(ニ?)御座候 且又三ケ寺領入合地面之内江流水上之儀は 四ッ谷大木戸ゟ…分流水 南之方上渋谷邨江流入申候**」＝**①千駄ヶ谷界隈の「玉川御上水餘水落川」（除水流川・餘水流川の表記混在・巾凡2間・堀割年代不知）、②3橋の構造・規模（石橋長2間巾6尺・石橋長9尺巾1丈1尺・板橋長2間巾6尺）と板橋→石橋の掛替年次（文政4〔1821〕5月・寛政10〔1798〕8月・掛始年代不知）・修覆は村方持、③四ッ谷大木戸からの分流水が南へ上渋谷村へ流入、④三ヶ寺領入合地の境界としての川筋**＝**千川（玉川上水分水）系の千駄ヶ谷〜渋谷側への流下を記す文政期町方書上の一次文言群**（千川上水の広域流路論（上渋谷村への流入・渋谷川系へのrossover）の江戸期書上レベルの datapoint。「四ッ谷大木戸ゟ…」の直後の判読不能部（「十一月十日」等に読める箇所の原字）と、「除水流川／餘水流川／餘水落川」の使い分けは原画像照合が前提。分流の水利構造の比定は断定しない）。
- **青山上水の【上水在絕記】引用＝万治3年出来・享保7年差止・大久保市右衛門触〔文言候補・objectの同定と対校〕**: 「**青山上水 漬(?)上水在絶記ニ云 万治三千年(万治三年)青山上水初て出来たり 四谷大木戸より玉川上水伐(を?)引 裏大番町より森川出羽守 久能和泉守屋鋪通 紀伊殿青山西門前 青山通 赤坂火消屋鋪辺まて一筋 ハ足軽町龍土六本木 北之方は市兵衛町 榎坂まて 東は飯倉町四ッ辻 同雨(両?)町 秋田信濃守屋敷辺 又西は芝新堀端 左右へ懸る 享保七寅年十月止たり と按に享保七年九月三日大久保市右衛門より触出せし書取あり 考拠のゐに左に録す 青山三田両所上水之儀中(?)起より…**」＝**①青山上水の起立を万治3年（1660）とし、四谷大木戸からの玉川上水引水・青山・赤坂・龍土・芝新堀に及ぶ配水範囲、②享保7年（1722）10月差止（【上水在絕記】）と同年9月3日の大久保市右衛門触の書取（按語）、③「青山三田両所上水」の差止文脈**＝[GAZ-049](GAZ-049.md)制限⑪で同定済みの【上水在絕記】（[GOV-171](../gov/GOV-171.md)御府内上水在絶略記とほぼ逐語一致）の**青山上水条の本文候補＋三田上水を並記する享保7年差止層**＝repoで単発の言及にとどまってきた三田上水・青山上水の区域・年次を、丁亥書上の採録形で確認した対校資料（「万治三千」の判読・「伐引」の原字・範囲列挙の地名照合は要原画像。享保7年9月の触の「青山三田両所上水差止」の実務文言の一次確認は[GOV-171](../gov/GOV-171.md)との対校が課題）。
