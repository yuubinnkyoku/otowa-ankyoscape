# [GAZ-035] 町方書上 [149]（青柳町・音羽町・桜木町）— 万年樋・鼠ヶ谷稲荷・鼠坂・壱貫橋・地震橋・駒止橋・九丁目橋・目白坂

- **書誌〔確認〕**: 御府内備考編纂の基礎資料となった**町方書上**の一本（目録番号[149]・青柳町・音羽町・桜木町三ヶ町書上）。NDL次世代デジタルライブラリー [book/2571630](https://lab.ndl.go.jp/dl/book/2571630)。**[GAZ-013](GAZ-013.md)（御府内備考巻之五十「護國寺領三ケ町」＝大日本地誌大系刊本の一部採録）の元資料側に当たる写し**で、刊本採録部分に加えて桜木町・音羽町・東青柳町の橋・坂・稲荷・埋樋・上水の項目の原文テキストが確認できる。書上年の記載はOCRでは確認できていない（御府内備考の成立（文政期以降）と整合する時期の書上・要照合）。**すべての引用はOCR由来で、文言は原文画像との照合を要する。**
- **万年樋——桜木町の埋樋2ヶ所の固有名称〔確認・repo初出の名称〕**: 「**一 埋樋弐ヶ所 前書 東西鼠ヶ谷下水落口より 横壱間 建五尺程有之 石に而たゝみ 神田御上水下并道下共 凡七間程相通り 江戸川へ相流落申候 右出来之儀は 御上水御堀割之節 御公儀様に而御普請 被成候由に御座候 万年樋と相唱申候 町内懸りには無御座候**」〔**①桜木町の埋樋2ヶ所（東西鼠ヶ谷下水の落口・横1間・高さ(建)5尺・石造・神田御上水の下と道の下を凡7間通り江戸川へ流落）、②その名称が「万年樋」、③御上水御堀割の節に御公儀が普請した由、④桜木町の町内掛かりではない**＝**[GAZ-013](GAZ-013.md)の「埋樋二ヶ所（東西鼠谷下水落口）」に固有名称「万年樋」があったことの確認（repo初出）**。神田上水（江戸川）と鼠ヶ谷下水（弦巻川・水窪川系の流末）の交差構造（上水の下を下水が伏越で通る）の名称つきの一次記録。地名対照表に「万年樋」の行を追加〕。
- **桜木町条の神田御上水と「承応二年御堀割」の申伝〔確認・repo初出の年代文言〕**: 「**神田御上水之儀は 町内南之方を相流 西之方 関口目白下より相流 東之方え 小日向還国寺前通りえ相流申候 幅弐間程御座候 若応二年御堀割之由に御座候申伝 尤御普請方御掛りに而当町懸りに付無御座候**」〔**①神田上水が桜木町の南を流れ、西は関口目白下から、東は小日向還国寺前通りへ流れる（幅2間余）、②「承応二年（1653）御堀割の由」の申伝文言**＝**神田上水（江戸川〜関口〜小日向側の流路）の開削年代について「承応2年掘割」の伝承を町方書上が記録した文言（repo初出）**。「若応」は「承応」のOCR誤読の可能性が高いが要照合。桜木町側から見た神田上水の流向（西は関口方面・東は還国寺前方面）の記録も流路の比定資料〕。
- **目白坂——桜木町橋際から大泉寺門前へ登る坂〔確認・第107回課題（文政12年目白坂上崖崩落の位置〔[BOOK-130](../books/BOOK-130.md)〕）への前進〕**: 「**一 坂之儀は 西之方 当町ゟ大泉寺門前え登る坂二而 里俗目白坂相唱申候 坂幅三間程有之候 当町橋際ゟ凡三拾間程登り候 はしく 駒井町方ゟ目白台迄は百間も御座可有と存候 普請之節は当町組合に御座候**」〔**①桜木町の西から大泉寺門前へ登る坂の里俗名が「目白坂」、②坂幅3間、③桜木町の橋際（九丁目橋際〔川添屋敷町条〔[GAZ-034](GAZ-034.md)〕の「音羽町九丁目橋際」と対応か〕）から凡30間登る、④駒井町方から目白台までは凡100間と推量、⑤坂の普請は桜木町組合持ち**＝**目白坂の位置が桜木町橋際から大泉寺門前への登りと具体化する一次文言**。[BOOK-130](../books/BOOK-130.md)の文政12年8月2日「目白坂上家作二三軒崖崩落、神田上水に崩込」の「目白坂上」の位置を考える上での基準資料（当坂上部が神田上水に近い崖上である可能性を示唆するが、崖崩落地点の特定はこの文言だけでは断定しない）〕。
- **駒止橋・九丁目橋（桜木町条）〔確認・[GAZ-013](GAZ-013.md)の橋項目の数値・管理の詳細化〕**: ①「**石橋壱ケ所 音羽町九丁目・当町（桜木町）之間 横丁ゟ目白坂上り候橋に 駒止橋と相唱 往古ハ鼠ケ谷橋とも相唱候哉に御座候 幅六尺 長九尺 町内持に而 町方定川 両御掛り之御普請に御座候**」＝**駒止橋（音羽町9丁目〜桜木町間・目白坂上り口の横丁・往古は鼠ケ谷橋・幅6尺・長9尺・桜木町内持・町方と定川の両御掛かり）**。②「**橋壱ケ所 当町ゟ小日向水道町へ渡ル 板橋に而 神田御上水江相懸り 巾弐間 長三間程御座候 右橋名無御座 里俗九丁目橋共相唱申候 町内懸りに而者無御座 小日向水道町持に而 町方定川 両御掛りに而御普請に御座候**」＝**九丁目橋（桜木町〜小日向水道町・神田御上水に架かる板橋・幅2間・長3間・橋名なし・里俗九丁目橋・小日向水道町持ち・町方定川両御掛かり）**〔[BOOK-129](../books/BOOK-129.md)の宝暦10年「音羽町九丁目橋」修理の橋の管理実態（水道町持）と整合する記録。神田上水（千川上水ではない）に架かる点に注意〕。
- **壱貫橋・鼠ヶ谷稲荷・鼠坂〔確認・壱貫橋の規模・持分と稲荷の起原・鼠坂の位置の新記録〕**: ①「**橋壱ヶ所 鼠坂下に而…東之方 鼠ケ谷下水相懸候 板橋に御座候 里俗に壱貫橋と相唱候得共 右唱之訳相知レ不申候 長サ七尺 幅五尺余 尤も護国寺持に而 普請等之義は 町方懸りには無御座候**」＝**壱貫橋（鼠坂下・鼠ケ谷下水に架かる板橋・長7尺・幅5尺余・護国寺持ち・町方掛かり外）**〔[GAZ-013](GAZ-013.md)の壱貫橋条（護国寺持と読める旨のメモ）の原文側確認〕。②「**稲荷壱ヶ所 家持彦兵衛地之内に有之…右稲荷之儀は 寛政十年 元地主平次郎 右地面土中より堀出し…社建て 鼠ヶ谷稲荷と勧請し奉る 像之後口に 鼠ヶ谷稲荷と彫刻御座候**」＝**鼠ヶ谷稲荷（寛政10年〔1798〕に元地主平次郎が地面の土中から掘り出した像〔白狐に乗り鎌と稲穂を持つ・丈6寸5分〕を勧請・像の後口に「鼠ヶ谷稲荷」と彫刻・家持彦兵衛地内）**＝**「鼠ヶ谷」の語が18世紀末の像・社名に残っていた実物記録（repo初出）**。③「**坂之儀は 町内東之方裏通り 同所五丁目堺 横丁細道ゟ 鼠ヶ谷下水向 木村留三郎様・安藤對馬守様御屋敷 且 御賄方御組屋敷地境之名に有之 里俗に鼠坂と相唱申候 巾壱間程 長凡五拾間程 御賄方御組屋敷に而 里俗に新屋敷と相唱候方え登り仮に御座候 坂名之義は 昔音羽町之場所筋に谷と相唱候哉に付 其場所え下り候より之唱えと奉存候 町内組合之坂に而は無御座候**」＝**鼠坂（音羽町5丁目堺の横丁細道から鼠ヶ谷下水向かい・木村家・安藤家の屋敷と御賄方御組屋敷の地境・巾1間・長50間余・里俗「新屋敷」への登り・町方組合の坂ではない）**〔**鼠坂の位置・規模・性格の最詳の一次文言**。「昔音羽町の場所筋に谷と唱えた」ことに由来する旨の名義説も記録〕〔丁目帰属・人名はOCR照合要〕。
- **地震橋（東青柳町条）の寛政9年石橋化〔確認・repo初出の改築年代〕**: 「**石橋壱ケ所 前（に?）六之川往来江相懸り 地（震）橋と唱候哉 町方起立之節より町名同様ニ相唱候 長さ九尺程 巾弐間余御座候 町方御掛り之御普請に御座候 寛政九巳年十一月中 當時之石橋ニ相成 左右之約歩共 御普請御調合 其以前は土橋に而御座候 里俗には年洗橋とも（OCR判読不能・候補の読み・要照合）…本名 地震揺（＝地震橋か）に相唱申候由申伝候得共 右訳相知不申候**」〔**①地震橋（前六ツ川/六之川の往来に架かる・長9尺・巾2間余・町方御掛かり）、②寛政9巳年（1797）11月中に現在の石橋になり、それ以前は土橋だったこと、③里俗名（OCR判読不能）と「本名地震橋」の申伝**＝**地震橋の石橋化の年代（寛政9年）とそれ以前の土橋の実態はrepo初出**。[GAZ-013](GAZ-013.md)（御府内備考巻50の地震橋＝石橋・長9尺・幅貳間半）の改築前後の姿を埋める記録。里俗名の原字形は原文照合課題〕。
