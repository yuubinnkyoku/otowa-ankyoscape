# [GAZ-171] 町方書上[114] 南本所 — 元町条の万治2年本所御取立witness

- **書誌〔確認〕**: 『[114] 南本所町方書上』（写・NDL次世代デジタルライブラリー [book/2571595](https://lab.ndl.go.jp/dl/book/2571595)。NDL API volume欄直接確認）。南本所元町条（koma 6-）・名主友太郎署名の文言（koma 25周辺・[GAZ-172](GAZ-172.md)〔116〕と同名主。本冊・[116]冊の元町条文言の関係は要照合）。引用文言はすべてOCR由来で要原文照合。
- **万治2年本所御取立の元町条witness〔文言候補〕（koma 6）**: 「**当町之儀は南本前村之内所起立ゟ町屋に而家建込諸商売仕町並御年貢諸役等相勤来 最初之町屋ニ付元町と相唱申候然る所 万治二亥年本所御取立有之 寛文四辰年**（…後欠・koma 7続）」（koma 6・OCR）＝**①南本所元町の起立（南本前村之内の最初の町屋＝「元町」の名義）、②万治2年（1659）の本所御取立、③寛文4年（1664）への言及（後続komaで竪川通の江戸町屋化か・文言候補）**。〔**[GAZ-165](GAZ-165.md)（起立記の「万治二亥年（=OCR弘化二亥年判読候補）本所御取立之節…新規御堀立」）に対し、同年代の「本所御取立」語を独立の書上でもつ第2 witness（「万治二亥年」の明瞭な干支表記側）＝OCR判読対立（弘化/万治）の万治側の加味材料候補。町名「元町」の名義文言（最初の町屋）もrepo初出候補。〕
- **寛文4辰年の文言（koma 6後半〜7・要照合）**: koma 6末尾の「寛文四辰年」に続く文言はkoma 7（未取得）で、本回は「万治2年御取立→寛文4年の某処分」という読みの枠組みのみ記録した。**寛文4年が本所側の町屋化の画期（[GAZ-165]koma 7系の御代官所化＝天和3年前の体制）かは原画像照合まで概説しない。**

## 制限・未解決

- ①OCR由来で要原文照合（特に「南本前村」=南本所村か・「寛文四辰年」に続く文言）。②[114]と[116]（[GAZ-172](GAZ-172.md)）の名主友太郎は同一人か同一文言の別添かの判別が未了（両冊とも南本所元町条の文言を含む）。③本冊の他町条（新田町・若宮町等）の掃引は本回は文言目立たず表面化せず＝再掃引候補。
