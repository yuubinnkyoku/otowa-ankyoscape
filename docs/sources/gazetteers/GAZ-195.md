# [GAZ-195] 『日本地理志料』巻之十六 — 山岡浚明の小日向条と世田ヶ谷条の弦卷村文言（第328回）

- **書誌〔確認〕**: 邨岡良弼（むらおか・よしすけ／**村岡檪斎**と付記）著『**日本地理志料**』巻之十六（東陽堂・**明治36〔1903〕**。NDL次世代デジタルライブラリー [762751](https://lab.ndl.go.jp/dl/book/762751)＝**巻之14-17を1冊に収録**・bibId 000000424895）。『日本地理志料』の各条は国郡ごとに古代〜中世の地名古文書を博引する考証地誌で、文言の多くは引用元（東鑑・和名抄・分限帳・文書等）を明記する〔確認: 取得全文の構造〕。**全文言はOCR由来で〓・雜→雑等の崩壊が多く、以下の文言はすべて要原字照合（文言候補として記録）。**
- **経緯〔確認〕**: [GOV-603](../gov/GOV-603.md)の港区史第1巻ht001050が引用する日頭郷比定の文言の引用元として同書巻16を挙げていた（repo未収録書誌）が、本回でNDL labの全文ZIPを取得して該当条の存在を原文側で確認した＝**第327回課題④の解消**。

## 小日向条の文言〔確認・OCR候補〕

- 巻之十六（武蔵国豊島郡）の「按」部に、**山岡浚明（『殘篇風土記』）に帰属する比定文言**: 「**山岡浚明曰、日頭方ニ廢、今ノ小日向村、盖其遺名、因謂、殘篇風土記。載日頭〓〔原文文字不明〕、長祿ノ江戶圖、作小日向村、北條分限報、江戶小日向內、小日向彈正知行、按圖亘小日向、小石川、牛込、市谷、金杉、關口、音羽、高田、雜司カ谷、池袋ノ諸邑、盖其域也**」＝
  - ①**和名抄豊島郡の「日頭（にった）郷」の廃名が今の小日向村に遺名とする説が山岡浚明（殘篇風土記）に帰属して記される**＝[GOV-603](../gov/GOV-603.md)（港区史第1巻の引用文言）の**引用元側の文言の実在と帰属表記を確認**、
  - ②**長禄（1457-60）の江戸圖に「小日向村」・北條分限報に「小日向彈正知行」という古文書上の「小日向」の出現系譜を列挙した上で「按圖亘小日向、小石川、牛込、市谷、金杉、關口、音羽、高田、雜司カ谷、池袋ノ諸邑、盖其域也」**＝**日頭郷の比定域を小日向・小石川・牛込・市谷・金杉・関口・音羽・高田・雑司ヶ谷・池袋の10邑に亘るとする考証文言**。
  - **対照の意味〔確認〕**: 港区史第1巻（GOV-603）がこの10邑列挙を転記していたことは第327回で確認済みで、本件は**明治36年（1903）という時点印と、山岡浚明帰属・長禄江戸圖・北條分限報という出典構造が『日本地理志料』巻16の本文으로確認された**ことを意味する〔確認〕＝[GAZ-092](GAZ-092.md)（鳥越村条「或云小日向を日頭の地と云說あり」＝小日向単独比定系）との**比定範囲の対照資料**として[対照表](../../地名・河川名対照表.md)の日頭郷行を補強（音羽・高田・雑司ヶ谷を日頭郷域に含める系の文言本体の確認・比定の是非は断定しない）。「北條分限報」は北条氏分限帳系の想定名で同書の排列か（原字照合まで書名の確定は保留）。

## 世田ヶ谷条の弦卷村文言〔確認・世田谷側の同名異地記録〕

- 巻之十六（武蔵国荏原郡・世田ヶ谷条）: 「**鎌倉八幡宮永享元年ノ文書、世田谷〓〔内カ〕弦卷村**」＋「**按圖亘弦卷、用賀、經堂在家、深澤、野毛、等等力ノ諸邑、稱菅刈ノ莊**」＋「**吉良家譜、應永中、治家始ヲ城于此、子孫傳領、稱曰世田谷御所**」＝
  - ①**「弦卷村」を「鎌倉八幡宮の永享元年（1429）の文書」に出るとする記述＝世田谷側「弦巻」の文書初出候補として早い時点の語例**〔二次引用（同書が文書を引用検索した形）で文書本体は未確認〕、
  - ②吉良氏世田谷御所系の文脈で「菅刈ノ莊」の一部に「弦卷」以下6邑が亘るとする考証〔確認〕。
  - **意味〔確認〕**: 荏原郡世田ヶ谷＝**弦巻川（北豊島郡雑司ヶ谷）とは同名異地**（弦巻町・弦巻神社系＝[GAZ-058](GAZ-058.md)等で既知の世田谷側地名）で、本repoの四河川スコープ外だが、**「弦巻」地名の文書レベルの初出候補（1429）と莊（菅刈庄）への所属という系統の記述例**として同名異地整理の側から記録する（世田谷側の地理的比定の是非は本repoでは扱わない・文書の実在は未確認）。

## 雑司ヶ谷条・豊島郡の考証文言〔確認・OCR候補〕

- **雑司ヶ谷条**: 「按雜司〓〔ヶカ〕谷法明號〔雑司ヶ谷法明寺条〕**東鑑治承四年、有武藏ノ威光寺寺威光山、元暦二年ノ條、大即此、正嘉元年改日宗、用今ノ名**」＝**雑司ヶ谷法明寺が治承4年（1180）東鑑の「武蔵ノ威光寺」＝威光山と同一で、元暦2年の條に「大」〔地名か〕、正嘉元年（1257）に日宗〔にっしゅう〕と改め、今の名（法明寺）を用いる**とする系譜文言〔OCR崩壊大・候補〕＝**「威光」語（字威光・[GAZ-002](GAZ-002.md)氷柱ヶ谷条）の寺名由来系の文書候補として関心**（東鑑治承4年条・元暦2年条の該当文言の原典照合は未実施）。
- **豊島郡の考証**: 岩淵郷条の「**按圓〔圖カ〕亘豊島、王子、瀧野川、梶原、上坂橋、下板橋、十條、稻付、神谷、赤羽根、岩淵、袋、遵沼〔沼カ〕ノ諸邑、稱岩淵〓、是爲故區**」＝**岩淵郷の範囲を豊島・王子・瀧野川・梶原・上坂橋・下板橋・十条・稲付・神谷・赤羽根・岩淵・袋に亘るとして列挙**〔OCR候補〕＝谷端川下流域（王子・瀧野川側）を含む岩淵郷の比定域の記録例（四河川直接文言ではないが王子・滝野川の古代郡郷帰属の対照点に使える）〔確認: 地誌側の整理〕。

## 四河川文言の陰性〔確認・陰性〕

- 巻之14-17の収録冊（762751）の全取得テキストで「**千川**」「**谷端**」「**水窪**」「**水久保**」「**音羽川**」「**弦巻川**」の直接の川名文言は**0件**＝**本書（武蔵国の郡郷考証地誌）は四河川の川名レベルでは情報を持たない**〔陰性〕（「音羽」は小日向条の比定邑列挙のみ・世田谷の「弦卷」は邑名）。
