# [GAZ-064] 新編武蔵風土記稿 新座郡巻（巻之129〜134・1884刊）— 上保谷村条の千川上水村境文言と保谷氏開発説・小榑村・橋戸村条の四至〔repo初出・第141回〕

- **書誌〔確認〕**: 『新編武蔵風土記稿』巻之一百二十九〜百三十四（新座郡之一〜之六。幕末成立の官撰地誌の**明治17年（1884）4月16日出版の活字版**。奥付「**明治十七年四月十六日出版 版權届 內務省地理局出版 東京府平民近藤圭造 深川區富岡門前町七十番地 發兌**」）。NDL次世代デジタルライブラリー [book/763996](https://lab.ndl.go.jp/dl/book/763996) のOCR全文を確認＝[GAZ-046](GAZ-046.md)（巻11〜17・豊島郡）・[GAZ-057](GAZ-057.md)（巻之122〜128・多磨郡）と同じ1884刊版の系列で**多磨郡巻（763995）の次冊**。**OCRが全体的に高度に崩壊しており引用文言はすべて文言候補で原文（画像）照合を要する**（「小榑村」のOCR「小樽村」「下保谷村条の『小傳村』」等の誤読混入）。
- **上保谷村条＝保谷氏開発説と千川上水の村境文言〔確認・repo初出〕**: ①「**保谷氏ノ人主トシテ開墾セシ故ニコノ名アリ村內ニ下田岩崎桃井野口中村ヲ氏トセル民五軒アリ是開發ノ事ニ與リシ人々ノ子孫ナルヨシ又瀧島氏アリ是モ久シク此ニアリシト見ユ保谷氏以下六人コノ瀧島カ家ニ會シテ開發ノコトヲ謀リシト言傳フ人家三百軒餘**」＝**保谷氏を人主とする開墾が村名の由来とする風土記稿レベルの説明**＋**下田・岩崎・桃井・野口・中村の5氏と瀧島氏の計6家系が開発に関与したとする伝承の一次文言候補**（幕末編纂・1884刊）。②**瀧島氏の登載**＝[BLOG-096](../blogs/BLOG-096.md)（滝島俊「千川上水と上保谷新田の水車」）の研究者の姓と一致する家系が上保谷村の開発関与6家系に含まれることの一次側の記録候補（**家系の対応は確認できず断定しない**）。③開発年代「**北條分限帳ニモ地名ヲ載セサレハ永祿以後御打入ノ前後ナルヘシ**」＋村內東祥寺の開基「**保谷出雲守直政元和七年卒ストイヘハ恐クハコノ人領知セシ頃ノ開發ナルヘシ**」＝**北条分限帳不載（＝永禄以後の開発）・保谷出雲守直政（元和7年〔1621〕卒）の領知期開発説**＝千川上水の水元周辺の開発年代の絞り込み文言候補。④四至「**地ノ形ハ豐島多磨兩郡ノ間ニ出テ北ノ一方ハ郡内下保谷村ニ續ケリ西ヨリ東へカケテハ凡テ多磨郡ニ包マレ西南ハ同シ郡田無村ニ接シ東西ハ千川上水ノ流ヲ隔テヽ是モ同郡關前村ニ隣リ東ハ豐島郡關村ニ(接シ)**」＝**上保谷村の村境を千川上水の流れが区切る（「東西ハ千川上水ノ流ヲ隔テ」）という四至文言候補**＝**千川上水が村境（上保谷村と多磨郡關前村の間）をなしたことの官撰地誌の文言**＝[BOOK-137](../books/BOOK-137.md)（境橋＝「相岐るゝさかい所」）・[BOOK-153](../books/BOOK-153.md)（保谷村の西南隅境橋より玉川上水を分つ）の境橋の「境」考察（第140回課題②）への**幕末官撰地誌側の初の四至文言**。ただし「東西」の語がOCR崩れを含み、千川上水が上保谷村のどちらの辺をなすか（「東西ハ」か「西北ハ」か等）は**原文照合まで確定しない**。「關前村」（多磨郡）の帰属・比定もOCR要因で確定しない。
- **上保谷新田条＝千川上水の水涯と開発者〔確認・repo初出〕**: 「**本村ノ民伊右衛門ナルモノ開發セリ其年歴詳ナラス地形ハ東ノ方ヘ長ク千川上水ノ水涯ニ至リ凡十八町許西(ハ多磨郡田無村ニ隣レリ)…元文元年大岡越前守檢地セリ**」＝①**上保谷新田（水元周辺の新田）の開発者を本村民・伊右衛門とする文言候補**＝[GOV-251](../gov/GOV-251.md)（慶応4・「上保谷新田…伊左衛門 四分水壱分呑水料」）・[GOV-254](../gov/GOV-254.md)（安政3・「上保谷新田名主伊左衛門」）の幕末の名主伊左衛門と名が対応するが、**伊右衛門（開発者・元文期の人物候補）と伊左衛門（幕末の名主）が同一人物・同一家系かは本冊からは確認できない（OCRの表記差の可能性もあり断定しない）**。②**上保谷新田の地形が東方へ長く延び「千川上水ノ水涯ニ至リ凡十八町許」**＝**千川上水の水涯（水路の縁）までの方位と距離（東方18町）を記録した千川上水の上流端の地形記述**＝分水口（境橋）から千川上水が東方へ流れ出す構造の傍証文言候補。③**元文元年（1736）の大岡越前守（大岡忠相）検地**＝上保谷新田の検地年代の一次記録候補（開発は元文以前と説明）。下保谷新田条にも「**是モ上保谷新田ト同シ時大岡越前守檢地シ新田トナレリ**」＝**両新田の同時検地の記述**。
- **小榑村条（OCR「小樽村」）＝飛地状の村と1891年大泉村編入の地理的基礎〔確認・repo初出〕**: 「**郡ノ東南ノ隅ニアリテ…東ハ上白子村及白子川ヲ隔テ豐島郡土支田村ニ隣リ西ハ本郡下保谷村南ハ豐島郡關村及郡内上保谷村ニ堺ヒ北ハ中澤辻兩村ニ接シ**」＝**小榑村が東（白子川・土支田村）・南（関村・上保谷村）を豊島郡の村々に囲まれた新座郡の東南隅の飛地状の村**であることの四至＝**1891年（明治24年）の榑橋村（小榑村＋橋戸村）の東京府北豊島郡大泉村への編入（[GAZ-063](GAZ-063.md)・外側資料）の地理的基礎**。「**用水ノ便アシケレハ水田少ク畑多シ**」＝千川上水が同村の四至に現れない点と合わせ、**用水受益から外れた畑村としての小榑村の水利条件の記録**。北条分限帳「**小樽(榑)深屋九十八貫八百六十文太田大膳亮知行**」→御打入後**板倉四郞左衞門勝重の領地**（寛永3年頃まで）→正保頃**野村彥太夫**（前に伊奈半十郎）→寛文年中**稻葉美濃守正則の領知**（同三年検地）→貞享2年その子の所替→元禄16年**江川太郎左衞門支配の時 米津出羽守田盛へ**＝**小榑村の領主変遷の通時系列（文言候補）**。
- **橋戸村条＝上白子村への包摂と庄氏文書〔確認・repo初出〕**: 「**橋戸村ハ新倉〓廣澤庄ニ屬スコノ地ハ天正十九年伊賀組ヘ賜リシヨリ今モ伊賀組ノ給地ナリ…上白子村ノ內ニアリ人家三十軒其居住ノ地及神社佛寺等ノ散在スル處ノミ此村ニテ其餘ハ皆上白子村ノ地ナリ**」＝**橋戸村の村域の大半が上白子村地に包摂され、居住地と社寺のみが村地として残る天正19年（1591）以来の伊賀組給地**（庄忠右衞門家所蔵の天正19年・慶長元年・永禄年間の文書が引用される）＝**榑橋村のもう一半の実態の一次記述**。小榑村・橋戸村の双方に千川上水・千川用水の文言はなく、**千川上水の流路は上保谷村・上保谷新田の四至にのみ現れる**。
- **下保谷村条・郡総説〔確認〕**: 下保谷村条「**東ハ郡內小傳(榑?)村ニ隣リ南ハ豐島郡關村ニ接シ西ハ上保谷村ニ續キ北ハ野寺村ニ境フ民家三十軒**」＋「水田ハナク畑計リナリ」＝下保谷村の四至と畑村構造（OCR「小傳村」は小榑村の誤読候補）。領主は上保谷村・小榑村と同じ**稲葉美濃守正則（寛文）→貞享2年所替→御料所→川崎平右衞門代官所**の変遷＝**上保谷・下保谷・小榑の保谷周辺3村が寛文期に稲葉美濃守（小田原藩主稲葉正則）の一国的主人の領知ブロックをなした観察候補**（OCR要因で断定しない）。郡総説に「**抵白子川ヲ界トス南西ハ豐島多磨二郡ノ際ニ押入リ**」＝**新座郡の南西部が豊島・多磨両郡の間に食い込む郡域構造**＝保谷・榑橋の諸村が1891年・1907年に東京府へ移管された地理的背景の郡レベルの記述（郡名の新旧表記の事情（享保2年の郡名の唱の制定等）も総説に収録）。
- **用水・水車の文言の帰属〔確認・陰性〕**: 本冊の「用水」16hits・「水車」2hitsは黒目川の水車（中澤村方面）・白子川の分水（下白子村）・伊呂波樋（引又橋・野火止用水系）・広沢池の用水等の**新座郡内の他水系**に帰属し、**千川上水に係る文言は上保谷村条・上保谷新田条の2箇所のみ**＝新座郡巻は千川上水の水元・上流端の地形と村境の一次文言の供給源として価値がある。
