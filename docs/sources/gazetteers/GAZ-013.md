# [GAZ-013] 『御府内備考』巻之五十「護國寺領三ケ町」（大日本地誌大系 第3巻）

- 書誌：大日本地誌大系 第3巻 御府内備考（雄山閣、昭和6、NDLJP:1214872、DOI 10.11501/1214872、請求記号593-8、インターネット公開）。収録は巻之四十七〜七十四。巻之五十「護國寺領三ケ町」はコマ20〜25（冊子頁20〜巻之五十一開始の31の前まで）。第2巻（NDLJP:1214857、巻之二十五〜四十六）には巻之五十を含まない。
- NDLサーチ：https://ndlsearch.ndl.go.jp/books/R100000039-I1214872
- 成立は文政12年（1829）。刊本は昭和6年の雄山閣版。

## 内容メモ（NDL刊本画像の読取。解釈は書かない）

- 東青柳町（コマ20）、川項目：
  - 「一川幅九尺右は町內東寄に而北より南へ相流申候古來何川と唱候哉相知不申細流に而水上は巢鴨村雜司ケ谷村之內田場際より流出夫より當町え入音羽町裏通り江戶川え流出申候家無御座流末に而は鼠ケ谷下水と唱候よし御座候」
  - 続いて地震橋（石橋長九尺程幅貳間半、前出之川に懸有之）。
- 西青柳町（コマ21）、川項目：
  - 「一川幅九尺右は町內西寄に而北より南へ相流申候古來何川と唱候哉雜司ケ谷村之內に而里俗弦卷川と申來る細流にて水上は雜司ケ谷村之內丸池と申處より流出同村田畑際より當町え入音羽町裏通り江戶川え流出申候幅九尺程御座候流末にては鼠ケ谷下水と相唱候由に御座候」
  - 続いて松屋橋（石橋長九尺幅壹間程、前書之流に懸有之、里俗松屋橋）。
- 音羽町三丁目（コマ22）、下水項目：
  - 「一下水二ヶ所右は鼠ケ谷下水と相唱申候右唱之儀は音羽町之分不殘町屋に相成不申以前鼠ケ谷と申字に而御座候由申傳候」
- 榎木町節の続き（コマ25、同じコマに巻之五十終と巻之五十一「高田」の開始が並ぶ）、埋樋項目：
  - 「一埋樋貳ケ所右は東西鼠谷下水落口に而橫壹間建五尺程有之石に而たゝみ神田御上水下並道下共凡七間程相懸り江戶川へ相流落申候右儀御普請に而御座候」

## 音羽町各丁目の追加読取（2026-10-30、NDL刊本画像とビューア全文検索の照合・ai）

- 巻之五十の節構成は東青柳町・西青柳町・音羽町一丁目〜九丁目・櫻木町で、音羽町各丁目はコマ21〜24にある。各丁目とも小川・下水は「鼠ケ谷下水」と唱えると記される。一丁目には、音羽町が残らず町屋になる前は「鼠ケ谷」という字であったという唱の由来がある（この由来の文は三丁目の項にもある旨を上の既存メモに記録済み）。
- 二丁目の細目には川・下水二ヶ所・関口橋・江戸川橋とあり、本文に幅九尺の川の記述がある。四丁目は小川二ヶ所。五丁目は小川二ヶ所（幅壱間程）と橋の項があり、本文では里俗壱貫橋と唱える橋の普請は護国寺持ちと読める（細目では五丁目に丸太橋、六丁目に壱貫橋とあり、橋の丁目帰属は要再確認）。六丁目は小川二ヶ所（幅壱間位）。七丁目は小川二ヶ所（幅壱間位）。八丁目は小川二ヶ所（幅壹間位）と橋の項。九丁目は小川二ヶ所（幅八尺程）。
- 「池」を項目名とする記述は音羽町各丁目にはなく、「用水」の語も巻之五十には現れない（第3巻の対象範囲の全文検索でも「用水」は対象範囲外の4件のみ）。
- 櫻木町（コマ25、巻之五十最後の節）：石橋の項に、音羽町九丁目との間の橋が駒止橋と唱え、往古は鼠ケ谷橋とも唱えた旨がある。板橋の項は小日向水道町へ渡る橋（里俗九丁目橋）で神田御上水に懸かる旨。埋樋二ヶ所の項は東西鼠谷下水の落口に関するもので、下の確認注記の「榎木町節」との関係は再確認を要する（次項）。

## 確認注記

- 原文の字形は「鼠ケ谷下水」「弦卷川」である（現代字の「鼠ヶ谷下水」「弦巻川」ではない）。
- 「東西鼠谷下水」は東・西青柳町節ではなく、榎木町節の埋樋項目に「東西鼠谷下水落口」として現れる。
- 節名の再確認（2026-10-30）：同日の再読では、巻之五十の最後の節は「櫻木町」と読め、「榎木町」は第3巻全体の全文検索でも独立節としては現れず（言及2件のみ）、埋樋の項は櫻木町の節のうちに置かれる。上の既存メモの「榎木町節」は節名の読み違いの可能性が高く、また巻之五十終のコマも既存メモの25ではなく26左頁と読める。いずれも画像での最終確定を要するが、以後の参照では櫻木町節の埋樋項目として扱い、この注記を併記する。
- ビューアのコマ番号と目次の冊子頁番号は別系統。1コマに上下2段の頁が含まれるため、項目ごとの冊子頁番号は未確定。
