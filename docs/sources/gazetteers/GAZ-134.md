# [GAZ-134] 町方書上[95] 浅草 — 浅草猿屋町条の千川上水差止（四月中）とイナリ橋・加賀美稲荷・東叡山水吐し堀割

- **書誌〔確認〕**: 『町方書上[95] 浅草町方書上礼』（写・NDL次世代デジタルライブラリー [book/2571576](https://lab.ndl.go.jp/dl/book/2571576)）。表紙町列＝元鳥越明神門前書替所跡町屋・龍宝寺門前・**猿屋町**・元鳥越長楽寺門前・壽松院門前・浄念寺門前・東軒寺門前・善照寺門前（p1・p3）。**浅草猿屋町条＝p13〜25**（町名由来から代地・稲荷詞書上まで。p26に稲荷詞書上猿屋町次郎助）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571576_{NNNNNNN}.txt` コマ番号。**
- **千川上水の差止文言〔文言候補・本冊の核心〕（p22）**: 「**千川上水之儀 始め相知不申候 天明七...未年四月中 御差止メニ相成申候**」＝**①千川上水の始まりは（町方では）知らない、②天明7丁未年（1787）**四月中**に御差止めとなった**という文言（中間部「天明七リノ訳一八来夫ニアリアリ」はOCR崩壊・「天明七丁未年」の崩れ候補）。〔**①「始め相知不申」＝[GAZ-133]（[89]浅草弐・鳥越町条「古上水始り不相知仰」）・[GAZ-115]（御府内備考浅草巻・尾町条「始り年月相知不申候」）と同じ「始まりを知らない」文言の浅草側の別witness**、②**「四月中」（日付なし）＝差止日（日次）の記憶の粒度の対立群の中の「四月中」系の新たな一例**＝本郷・湯島区間の町条（[GAZ-049]第112回追記2）と同じ粒度で、[GAZ-041]（四月十三日）・[GAZ-133]（四月□□十二日）・[GAZ-132]（四月十三日）と並ぶ浅草末端での四月中文言。差止日の真の確定は本文言のみでは行わない（他の「四月中」文言と同群として併記にとどめる）**〕。
- **イナリ橋ノ下・古板出・橋詰の稲荷社〔文言候補・repo初出候補の橋名候補〕（p22）**: 「**イナリ橋ノ下 古板出 トヨシ(=討用?富用?・判読不能) 町内ゟ相渡り候 橋詰に稲荷社壱ケ所御座候 右稲荷之儀は 外地所御火除地に被召上候節ゟ右場所ニ有来リ申候**」＝**「イナリ橋（稲荷橋）」の下の古い板の出るところ（古板出・判読要照合）で町内から相渡り、その橋詰に稲荷社1ヶ所があり、右稲荷は（もとの土地が）御火除地に召し上げられた節から右場所にあった**という橋・稲荷の文言。〔**①「イナリ橋」の原字と架かる水路の堀の同定（千川上水末端堀か他の堀か）は本文言からは確定できない＝[GOV-358](../gov/GOV-358.md)の新堀川系の「里俗稲荷橋」（明和年中成立）との関係も断定材料がなく比定しない、②「古板出」の原字はOCR崩れ候補・要照合、③橋自体は「福富町並当町両町ニ而右橋懸ケ来リ申候」＝享保17年の福富町代地の際に両町が懸けた橋（下条）**〕。
- **享保17年類焼・川向福富町濱河岸の代地と両町の架橋〔文言候補〕（p19-22）**: 「**享保十七子年類焼之節 前書申上候通り 川向福富町濱河岸江代地被下置候節 福富町幷当町両町ニ而右橋懸ケ来リ申候**」＝**享保17子年（1732）の類焼の際、川向の福富町ハマ河岸に（当町の）代地が下げ置かれた節に、福富町と当町の両町で右の橋を懸けた**。〔当町（浅草猿屋町）自体が元名主吉右衛門旧地の御用地上げ→福富町続川岸の代地（141坪9合5勺5才）という来歴（p15-16）とあわせ、**浅草猿屋町＝旧地の御用地上げで川岸に移った町＝千川上水末端域の代地町群（会所附地所・新旅籠町系〔GAZ-133〕）と同型の来歴**であることの町方側記録。掛かる水路の同定（ハマ河岸=隅田川続の堀群か・千川上水末端堀か）は本文言からは断定しない〕。
- **加賀美大夫と町名由来・加賀美稲荷（猿屋町）〔文言候補〕（p13-14）**: ①「**古町之儀は往古武州豊嶋郡津田須島越村と申候由二而 寛永七庚午年中町屋に被仰付候処 如何之訳に而猿屋町と相唱候哉相知不申候**」＝古町は往古武州豊嶋郡津田須島越村、寛永7庚午（1630）に町屋化、猿屋町と唱えた訳は知らない。②「**土地ニ而申傳候に者 越後国猿屋村ゟ罷越候者ニ而猿屋 加賀美大夫と申大夫に而も御座候哉 右之者往古当所に住居罷在候由 其後町屋に被仰付候而も 里俗に猿屋町と相唱 自然町名と相成候由**」＝越後国猿屋村から来た猿屋加賀美大夫が往古当地に住居、その後町屋になり里俗に猿屋町と唱えた。③「**右大夫往古住居之場所を 加賀美稲荷え勧請致候而 右社当所町内持に御座候**」＝大夫の住居跡を加賀美稲荷に勧請、社は町内持。④「**然る処享保十七子年三月中類焼之後 同五月中 凡四拾弐三間程御減火除御用地に被召上**」＝享保17年3月類焼後・同年5月中に42-3間ほど減地の火除御用地に召し上げられた（代地は浅草諏訪町書通り立堀田相模守殿御上ヶ敷嶋字堀田原）。〔**猿屋町の町名由来の二重伝承（津田須島越村・寛永7町屋化＋越後国猿屋村由来の加賀美大夫譚）と加賀美稲荷の勧請・享保17年5月火除地召上の実務記録。地名由来説の真偽はrepoの範囲外・文言の保存記録として採録**〕。
- **寛永4年東叡山水吐しの堀割の申伝〔文言候補・repo初出候補〕（p13）**: 「**寛永四卯年中 東叡山御建立之節 御同所水吐之ため 当所江堀割被仰付候由申伝候**(中略)**同巾弐間半余 同所ゟ新旅籠町江懸渡候 寺院町方持合橋之義は 右堀割之時節**（後略）」＝**寛永4卯年（1627）の東叡山（寛永寺）御建立の節、同所の水吐しのために当地へ堀割が仰せ付けられた申伝＋巾2間半余・新旅籠町へ懸け渡す寺院町方持合の橋はその堀割の時節の由**。〔**堀の実体（浅草側の谷筋の堀＝山谷堀系か他か）の同定は本文言からは行わない**（「申伝」文言であり開削年代の史実採用も保留。ただし浅草側の寺社門前町群（元鳥越明神門前・龍宝寺門前・善照寺門前）と新旅籠町を結ぶ堀の建立譚が寛永4年「東叡山建立」に結び付けられている点は、浅草代地町群の立地史の背景文言候補として記録）。寛永4年説の singleton であることに注意して対校資料が出るまで年代採用はしない〕。
