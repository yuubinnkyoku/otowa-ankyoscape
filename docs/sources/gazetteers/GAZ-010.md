# [GAZ-010] 『史料纂集 護国寺日記』

## 書誌（2026-10-30、八木書店カタログとNDLサーチの直接確認・ai）

- 護国寺の役者が記した公用日記『護国寺日記』の翻刻。史料纂集 古記録編、坂本正仁校訂、八木書店古書出版部（発売・八木書店）、全5冊。
- 原本は護国寺所蔵で、元禄10年（1697年）から宝暦8年（1757年）まで、途中の欠落はあるものの253冊が現存する（八木書店カタログ第1冊の内容説明）。文京区指定文化財（古文書）で通常は非公開。文京区の文化財資料では令和6年（2024年）3月に2冊が追加指定され計255冊とされる（『文京区の文化財2020増補改訂版』正誤表・追録 https://www.city.bunkyo.lg.jp/documents/4232/seigohyo2026.pdf 。本ファイルの段階では当該PDFの直接確認は未了で、253冊は刊行時点の数）。
- 翻刻の範囲は徳川綱吉の代に限られ、元禄10年正月から宝永6年2月まで。
- 各冊（八木書店カタログ・NDLサーチで確認できた範囲）：
  - 第1冊（第170回配本）：2014年4月20日、288頁、ISBN 978-4-8406-5170-7。
  - 第2冊（第179回配本）：2015年、ISBN 978-4-8406-5179-0。
  - 第3冊（第184回配本）：収録は元禄16年（1703年）から宝永元年（1704年）。ISBNは未確認（八木書店カタログの書影ファイル名からは 978-4-8406-5184-4 と読めるが、書誌レコードでの確認は未了）。
  - 第4冊（第194回配本）：2018年、ISBN 978-4-8406-5194-3。
  - 第5冊（NDL書誌ID 029799418、請求記号 HM146-M6）：2019年7月、362頁、ISBN 978-4-8406-5202-5。収録は宝永4年正月から宝永6年2月。
