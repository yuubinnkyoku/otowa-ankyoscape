# [GAZ-043] 外神田町方書上 [78] — 昌平橋通四ツ角の樋と旅籠町の「樋跡土中残存」

- **書誌〔確認〕**: 町方書上の一本（[78] 外神田町方書上 五下・神田旅籠町弐丁目・金沢町等の書上。末尾に「**文政十亥年三月 神田旅籠町弐丁目名主善左衛門…同四月披露ニ写置**」の文言）。NDL次世代デジタルライブラリー [book/2571559](https://lab.ndl.go.jp/dl/book/2571559)。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **昌平橋通四ツ角の千川上水の枡〔確認・湯島〜神田の接続点の構造追補〕**: 湯島側の町の書上に——「**一千川上水之儀は安永九子年十月廿七日牧野大隅守様御番所御掛りに而上水掛渡之儀被仰渡町内昌平橋通四ツ角に大枡壱ケ処并同所続東之方横町角に同壱ヶ所町内中通二小枡三ケ所樋掛渡有之候処天明七未年四月十三日御差止メニ相成其侭埋立有之候但元禄之度千川上水御掛渡之儀相分不申候**」〔**①昌平橋通四ツ角に大枡1ヶ所・その続く東の方の横町角に同1ヶ所・町内中通に小枡3ヶ所の樋掛渡、②天明7未年4月13日御差止→**其侭埋立**（他町の「取潰し埋立」と表現が異なる＝取潰しを経ずにそのまま埋めた可能性の記録だが文言の解釈は断定しない）、③元禄の度の掛渡は相分からず**＝**昌平橋通四ツ角（千川上水の流路が昌平橋筋と交わる点・[GAZ-045](GAZ-045.md)の湯島区間の「四ツ角往来中程の中桝」と対応か）の樋・枡の構造の追補**。
- **神田旅籠町弐丁目の「古上水跡」＝樋跡が文政10年時点で土中に残存〔確認・repo初出の残存文言〕**: 神田旅籠町弐丁目の書上に——「**一古上水跡 右は安永年中本郷追分ゟ相流候千川上水ゟ相唱候場樋跡 今以町内南之方土中ニ相残有之候**」〔**①「古上水跡」＝安永年中に本郷追分から相流した（流れてきた）千川上水と唱えた場の樋跡、②**文政10年（1827）時点でも町内南の方の土中に樋跡が相残っていた**＝天明7年の埋立から40年後も樋の遺構が土中に残存していたことを町方書上が明記**〕〔**差止・埋立後も樋の実体が地中に残っていた町方側の証言＝[GAZ-024](GAZ-024.md)（湯島側の「取潰し埋立」）の「埋立」の実態（完全撤去か土中残存か）が町ごとに異なっていた可能性を示す。掘削・工事での発見情報と対照する価値のある文言（repo初出）**〕。
- **旅籠町の埋下水と神田川御堀〔参考・周辺の水路〕**: 同町の書上に「**一埋下水之儀は巾四尺に有之 神田旅籠町壱丁目自身番前ゟ南江里俗加賀原と唱候明地内高場際東之方ニ付神田川御堀江相続居同町并当町金沢町右三ヶ町持合二有之候**」〔巾4尺の埋下水が里俗加賀原の明地内から**神田川御堀**（神田上水の堀）に続くこと・旅籠町1・2丁目と金沢町の3ヶ町持合いであることの記録（千川上水とは別系統の水路だが、旅籠町・金沢町周辺の水路網の基礎資料）〕。

## 制限・未解決

- ①「被仰渡」vs「被仰付」の表記差・「其侭埋立」の語義は原文照合を要する。②昌平橋通四ツ角の町の帰属（旅籠町か湯島側の町か・OCRの頁境界で未確定）。③「本郷追分ゟ相流候」の「相流」の向き（本郷追分から流れてきた）の解釈は文脈からの推定。④古上水跡の位置（町内南の方位）は1912年地籍図との照合が未実施。
