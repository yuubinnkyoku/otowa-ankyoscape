# [GAZ-065] 大日本地名辞書 中巻 二版（吉田東伍・1907）— 白子川の源流=井頭池と下流呼称「矢川」・橋戸村の天正19年改名・神田上水廃止の明治33年説〔repo初出・第143回〕

- **書誌〔確認〕**: 吉田東伍著『大日本地名辞書 中巻 二版』（冨山房・1907年10月17日発行）。NDL次世代デジタルライブラリー [book/2937058](https://lab.ndl.go.jp/dl/book/2937058)（654頁・初版は1900〜1907刊）。**引用文言はすべてOCR由来で、崩れ・欠字を含むため原画像照合を要する。**

## 武蔵国・白子村条＝白子川の源流と「矢川」呼称

- **白子川条＝井頭池を源流とする記述〔確認・文言候補〕**: 白子村条の川の説明として「**郡土支田村との界、水路凡一里半餘、井頭池より出て、川幅二間より四五間に郡界を流れ…下流新倉村、成增村、赤塚村の邊にては矢川と呼ぶ、此川豐島郡赤塚村中の用水に引注く**」（OCR高度崩れあり・中略部を含む）＝**①白子川の水源を「井頭池」とし土支田村との郡界を流れる水路（約1里半余）とする記述、②下流の新倉村・成増村・赤塚村の辺では「矢川」と呼ぶこと、③赤塚村中の用水に引注くこと**。〔[GOV-331](../gov/GOV-331.md)（大泉村現状調査・1931）「白子川ハ其ノ源ヲ本村井頭溜池ニ(発)シ」・[GOV-331](../gov/GOV-331.md)／[GAZ-002](GAZ-002.md)（北豊島郡誌・1918）の井頭池＝大泉村名由来と合わせ、**白子川の源流=井頭池（井頭溜池）が1907年の地理辞書レベルでも独立に記録される**＝1918郡誌・1931現状調査に先行する傍証。**「矢川」＝白子川下流の呼称はrepo初出**（東京の白子川水系の呼称変遷の新datapoint）。赤塚村の用水という下流利用の記述も含む〕
- **白子村の四至と「一溝（矢川と名つく）」〔確認・文言候補〕**: 「今白子村と云ふ、新座郡の東界にあたり、**豐島郡白子赤塚村と一溝(矢川と名つく)を以て相隔つ**。板橋驛へ二里、川越へ六里」＝白子村（新座郡の東端）と豊島郡側を「矢川」という溝が隔てる四至記述＝矢川が郡界（埼玉・東京の前身の郡界）をなすことの辞典文言（[GAZ-064](GAZ-064.md)の上保谷村条の千川上水村境文言と同型の郡境をなす水路の記録）。
- **橋戸村条＝天正19年の榑橋村改名と伊賀組給地〔確認・文言候補・OCR高度乱れ〕**: 「**小樽記云、今橋戶に合し、橋戶村は天正十九年、榑橋村と改む、伊賀組へ賜りしより、白子の西隣也**」＋「**矢川(?)子村の一名を橋戶村とも心得たり、伊賀組の給地なり**」（周辺に「白子川とも呼ぶ」の語）＝**①橋戸村が天正19年（1591）に「榑橋村」と改めたこと、②伊賀組に賜われた所から（伊賀組の給地であること）の2点を小樽記（小榑村の村記か）引で記す文言候補**。〔[GOV-198](../gov/GOV-198.md)（北豊島郡総覧・1931）の明治22年「橋戶小樾兩村を合して榑橋村と稱し」との関係＝**榑橋の名が天正19年に遡る旧名（本文言）か、明治22年の新命名（1931文言）かの対立候補**。本条はOCR高度乱れ（「小樽記」の同定・「伊賀組へ賜りしより」の解釈）を含むため、原画像照合まで帰属・解釈は確定しない〕
- **廣澤庄条＝中世新座郡の広域荘園〔確認・文言候補〕**: 「**史學雜誌云、廣澤庄は東は白子、榑橋より、西は館村、南は片山に至り、北は柳瀨川に臨む、大約新座郡の八分を占め**」＋小田原役帳「江戶廣澤三箇村、百六十七貫文、太田新六郞」＝**中世の廣澤庄の四至が東端に白子・榑橋を含むこと**＝榑橋村位置の中世荘園四至レベルの記録候補（『史學雜誌』引用。廣澤野＝膝折村の北の廣澤池に由来との新記引文も同条に続く）。

## 豊多摩郡・井頭条ほか＝神田上水の明治33年廃止説と後楽園水道の現役

- **井頭条（豊多摩郡＝吉祥寺側の井の頭）＝神田上水の起源と廃止〔確認・文言候補〕**: 「**舊神田上水の溝渠なりき、然れども上水に供せられし以前より、水脉は自然に在りて、堀之內にて井草川と合し、淀橋川、江戶川と爲れるを想ふべし。寛永六年、井頭の源池を疏通し、江戶川の水を日白臺の下なる關口に分ち、之を神田上水と稱したり。明治三十三年に至り、其府內の給水を廢するも、小石川區…後樂園に至る迄の水道は舊に仍る**」＝**①井頭（＝井の頭。吉祥寺側で大泉村の井頭池とは別水域）が旧神田上水の溝渠であること、②上水供給以前から自然の水脉があったとする起源観（神田上水自然水脉起源説）、③寛永6年（1629）に源池を疏通し関口に分けて神田上水とした疏通説、④明治33年（1900）に府内の給水を廃したが後楽園までの水道は旧に依ること**。〔**神田上水廃止の「明治33年」説＝[GOV-307](../gov/GOV-307.md)（東京市水道史論・明治34年6月停止）との年次対立の新候補**。断定せず併記する。**④の後楽園（水戸邸＝後の造兵廠）水道の現役継続は1907年時点の観察**＝[GOV-290](../gov/GOV-290.md)（1905年・千川上水残存）と同年期の神田上水側の残存記録〕
- **江戸砂子・府内備考の引用〔確認・文言候補〕**: 同条に江戸砂子引「井頭池は神田上水の源にして、**池中七所より水涌出づ、因て七井の池とも云ひ**、池のめぐりに柳多く水色靑し、辨天社あり、慶長十一年、將軍家御成の節池水にて御茶召上り、寛永六年御成の節、江戶城下へ引かせらるべき旨仰付らる」＋府内備考引「神田上水は、大猷院殿の御代、堀割給ひし事は、諸記にも詳なり、然るを**武德記に、天正十八年よりの事といへるは誤れり**」＝**井頭池（井の頭池）の「七井の池」異称・辨天社・慶長11年・寛永6年の御成の江戸砂子記事と、武德記の天正18年説を誤りとする府内備考の考証の採録**。〔神田上水の掘割年代論（承応2年説〔GAZ-049〕・天正18年説の否定など）の1907年時点の辞書レベルの整理として対校資料〕
- **関口条＝堰説の1907年辞典版〔確認・文言候補〕**: 「**井頭川の末にして、落合村(豐多摩郡)に於て江戶川井草川を容れ、目白臺の下に至り、江戶川と云ふ、又上水道を分派する所あり、堰を設くるを以て、關口の稱あり**」＋「此上水は往時の神田上水なるを以て、**關口より以上の上游には、井頭川をも神田上水と呼ぶ**」＋「**關口以東、船河原橋に至るまでを、專江戶川と稱し、其間に一屈折あり、(牛込新小川町の北)大曲と稱す。船河原橋以下には、神田川と呼ひ**」＝**①関口の称が上水道の分派所の堰に由来する説の辞典版（[GAZ-048](GAZ-048.md)の風土記稿の堰由来考証と同系統）、②関口より上流の井頭川も神田上水と呼ぶ呼称区間、③大曲（牛込新小川町の北）の位置の明記**。〔関口の地名由来（奥州街道の関説〔GAZ-048で風土記稿が退ける〕vs 堰説）の1907年時点の採録＝堰説系の支持資料。江戸川・神田川の呼称区間の区分も対照表の江戸川行の資料〕
- **水道町条＝町名由来と明治33年停止の再掲〔確認・文言候補〕**: 「**今金剛寺以西には小日向水道町と云ひ、寺以東には小石川水道町(舊金杉水道町)と云ふ**」＋「**神田上水は、明治三十三年に至り、其給水を停止したり、然れども關口より水道町を經て、水戶邸(即造兵廠)後樂園に至る水道は、舊に仍りて保存せらる**」＝**①小日向水道町・小石川水道町（旧金杉水道町）の町名の水道（神田上水）由来、②明治33年停止の再掲、③水戸邸（＝造兵廠）後楽園水道の保存**。＋砂子補引「井頭上水は東照公御入國の砌、御菓子師**大久保主水**より、小石川へ上水の事を申上ると、彼家譜に在り」＋編者考証「（**井頭池を源とする上水は、寛永六年の修築とす、東照公の時にあらず**）」＝**大久保主水の上水言上説（砂子補）と、寛永6年修築説を確定する編者考証**。〔[GAZ-013](GAZ-013.md)系の神田上水起源論の対校資料〕
- **廃止年次の対校追記〔2026-11-17・第145回〕**: 上記の明治33年説に対し、**東京都水道局（水道歴史館）は2021年のプレスリリース・関連頁で一貫して明治34（1901）年説を採用**する（[ORG-034](../org/ORG-034.md)。「明治34（1901）年の神田・玉川上水廃止から120年」）。[GOV-307](../gov/GOV-307.md)（東京市水道史論・明治34年6月停止）と都水道局側が揃う一方、本書の明治33年説は孤立する形になったが、府内給水の廃止（明治33年）と市内給水の完全停止（明治34年6月）を別過程・別時点と読む余地は残し、採用の断定はしない。

## 制限・未解決

- ①本書は著名な OCR 崩れの激しい活版資料で、**白子川条・橋戸村条は特に高度に乱れている**。「井頭池より出て」前後の流れ（上流端の正確な文言）・「小樽記」の同定・「伊賀組へ賜りしより」の解釈・「廣澤庄」四至の細部は原画像照合を要する。②**豊多摩郡の「井頭」（井の頭池・吉祥寺）と大泉村の「井頭池」（井頭溜池＝白子川源流・[GOV-331](../gov/GOV-331.md)）は別水域**であり、本書の両条項を混同しない。③神田上水廃止の明治33年説と明治34年6月説（[GOV-307](../gov/GOV-307.md)）の対立は本書のみでは解決しない（「府内の給水」廃止と市内給水停止の別過程・別時点の可能性も残す。**都水道局側は明治34年説を公式に採用〔[ORG-034](../org/ORG-034.md)・第145回追記〕**）。④「矢川」呼称の初出史料（本書の典拠）は未特定。⑤二版（1907）と初版（1900〜）の文言差は未対校。
