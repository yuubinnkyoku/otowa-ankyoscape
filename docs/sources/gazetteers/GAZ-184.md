# [GAZ-184] 町方書上[153] 柳嶋（文政11子）— 北十間川・大横川の川名文言と万治堀割伝承の本所側witness

- **書誌〔確認〕**: 『[153] 柳嶋』（写・NDL次世代デジタルライブラリー [book/2571634](https://lab.ndl.go.jp/dl/book/2571634)。NDL目録volume表記「柳嶋」）。収録は柳嶋境町（見出しp23・名主五郎左衛門・文政11子年10月条）・柳増（嶋）土村町（p43-49）・柳嶋横川町（p36）・柳島町・柳島裏町。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571634_{NNNNNNN}.txt`）。〔第231回「陰性」冊リスト掲載の冊。水系文言を含むことが本回の通読で判明したため、登録する。〕
- **柳嶋境町条の「北十間川」川名文言〔文言候補・本冊最重要・repo初出候補〕（p23-30）**: 「**北十間川ト相唱申候 中川ゟ流レ来り 横十間川え相流**」＝**「北十間川」の川名文言（repo初出候補・grep済み）＝中川から横十間川への連絡水路（縦川的性格）としての命名の観察候補**＋「万治年中本所御取立 堀割之由申伝（度々出水ニ而書留亡失）」＝**堀割の万治年中起源 主張を申伝（伝聞）形式で記す**。〔〔観察〕横十間川系の万治年中本所御取立堀割文言（GAZ-165本所起立記・[GAZ-178](GAZ-178.md)・[GAZ-185](GAZ-185.md)亀戸町条の万治弐亥年文言）がまた一枚増えた。書留亡失（出水で文書を失った）という記録喪失の文言自体が、万治起源証拠の一次文献が存在し得ない理由の当事者側説明として興味深い。北十間川の位置（現行の十間川の北側平行水路か、横十間川の区間呼称か）は本文言だけでは断定しない。〕
- **柳嶋境町条の境橋文言〔文言候補〕（p23-30）**: 「**境橋**」＝字境橋に所在・長八間・巾弐間・北之方に架かる・「**地方御掛りニテ柳浜村 清地村 亀戸村持**」＝**三ヶ村持ちの境橋の寸法・維持主体文言**。〔[GAZ-185](GAZ-185.md)亀戸境町条の境橋（長拾間・板橋・亀戸村柳嶋村請地村三ヶ村入会之橋・梶橋?梁田治助・蔵田屋清左衛門請負）との**寸法・持ち村の対校wording（境＝両町の境、請地村の側の境町の度重なる境橋文言）**。同一橋かどうかは寸法差（8間 vs 10間）を含め断定しない。〕
- **柳増嶋土村町条の「大横川」・宗法恩寺橋文言〔文言候補・repo初出候補〕（p43-49）**: 「**一川…西之方ニ有之 大横川ト相唱申候 竪川続ニ而万治年申本所御取立之節 御堀割之由申伝**」＋「**宗法恩寺橋**」（法恩寺橋判読候補）＝橋長七間・町方御掛り・本所清水町・新坂町・南本所出村町?〔判読候補〕・中之郷代地の4ヶ町持ち＝**①「大横川」の川名文言（repo初出候補・grep済み）＝横十間川系の別称候補（竪川続の万治堀割という系列文言で「縦川系の大川」の意か、横十間川の区間名かは断定しない）、②宗法恩寺橋＝[GAZ-165](GAZ-165.md)本所起立記の「法恩寺橋」（万治2年起立）の文政期現況witness（4ヶ町持ち・長七間）。〔万治年「申」は万治2亥（1659）と整合する干支だが判読候補・原文照合前提。〕
- **柳嶋横川町条（p36）**: 万治年中本所御取立堀割の同型文言（横川町の町名と横十間川の関係を伝える材料）の候補。柳島町・柳島裏町条は水系文言薄。
