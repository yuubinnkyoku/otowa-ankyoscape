# [GAZ-119] 町方書上 本郷町方書上参 — 本郷春木町・真光寺門前・古庵屋敷の千川上水給水樋文言群と元禄期記憶の陰性

- **書誌〔確認〕**: 『町方書上 本郷町方書上参』（写・NDL次世代デジタルライブラリー [book/2571512](https://lab.ndl.go.jp/dl/book/2571512)）。冒頭「町方書上 本郷町方書上参／同二十四ノ九三十二 本郷宿木町壱丁目…真光寺門前…菊坂台町…古庵屋敷…本郷町方書上 亥止」という町列挙で始まり、春木町壱丁目・弐丁目・真光寺門前・古庵屋敷・菊坂台町等の「町内取調書上」を綴じる。各条の廻年月は**文政九戌年十月（1826）**（「以上 戌十月 春木町壱丁目名主太郎右衛門」「以上 文政九戌年十月 本郷古庵屋敷名主又右衛門」等）＝[GAZ-118](GAZ-118.md)（本郷町方書上弐・竹町条）と同一事業年度の隣接冊。**引用文言はすべてOCR由来で要原文照合**。
- **春木町壱丁目条〔文言候補・repo初出〕**: 「**千川上水之儀は安永九子年中 左に春来町弐丁目堀より田田往還江折廻 凡百壱間程往来中程ニ小樋掛渡有之 小桝弐ケ所有之候処 天明七未年四月中御差止に相成候節相埋申候**」＝**①安永9年再掛時の給水経路＝春木町弐丁目の堀から（壱丁目の）往還へ折り廻す、②引水区画は凡そ101間余で往復の往還中程に小樋を掛け渡す、③小桝2ヶ所、④天明7年4月中の御差止の節に埋めた、の構成**。〔**①「春来町弐丁目堀より…江折廻」「凡百壱間程」「小桝弐ケ所」はrepo初出（既存走査でhitなし）。②春木町弐丁目の堀を水源側と読める文言で、本郷台地上の給水経路の区間復元に足場を与える〔**「田田往還」はOCR判読の疑いがあり（「旧(?)往還」「湯島(?)往還」等の読み候補）、原文照合まで保留**〕。③小樋（樋）＋小桝（配水桝）の組で給水樋の設計単位が観察できるのは、[GAZ-118](GAZ-118.md)（大枡・小樋）・[GAZ-045](GAZ-045.md)（中桝）と同じ語彙体系＝本郷側の町方書上群の記述様式の共通性**〕。
- **春木町弐丁目条〔文言候補・repo初出〕**: 「**千川上水之儀は安永九年中 美濃守様地堤ゟ町内往還江七拾五間余 往来中程小樋ニ而掛渡り 小桝三ケ所有之候処 天明七未年四月中御差止に相成候節埋立申候**」＝**①安永9年に美濃守様（[GAZ-118](GAZ-118.md)同様・大名屋敷と読めるが本冊では人物の比定なし）の地の堤と読める場所から千川上水が引かれ、②町内往還へ75間余りで小樋で掛渡、③小桝3ヶ所、④天明7年4月差止時に埋立。〔**「美濃守様地堤ゟ」＝上水の水源側・掛り元として特定人物の屋敷地の堤をあげる文言で、本郷境内の給水網の掛り元が大名屋敷の屋敷地と読める点が新情報（美濃守=誰の比定は本冊では確定できない・原照合課題）。「七拾五間余」「小桝三ケ所」もrepo初出。壱丁目条（101間余・小桝2ヶ所）との間で、春木町壱・弐丁目の給水規模の町内対比が同じ書上内で読める**〕。
- **真光寺門前条〔文言候補・repo初出・元禄期の陰性文言〕**: 「**千川上水之儀 安永九子年 門前往還北之方江寄小樋壱筋掛り有之 天明七未年四月中御差止に相成候節埋立申候 但元禄年中之義は樋跡等申伝も無御座 書留無之相分り不申候**」＝**①安永9年の再掛時の配置（門前往還の北え寄せた小樋1筋）②天明7年4月の埋立、までは他条と同型だが、**③但書きとして「元禄年中の義は樋跡等申伝も無御座 書留無之相分り不申候」＝元禄期の給水について樋跡も言い伝えも書留も残っていない、と明言する文言**。〔**元禄初掛（[GAZ-118](GAZ-118.md)竹町条・[GAZ-034](GAZ-034.md)由緒書・白山前町条）から享保7年停止（[GOV-170](../gov/GOV-170.md)）を経て約130年後の書上で、元禄期の記憶が町ごとに残る所（竹町）と消えた所（真光寺門前）に分かれる＝**給水実態の地域差（元禄期には真光寺門前まで給水が達していなかった可能性）か記憶の喪失かの判別資料**。どちらに読むべきかは本冊では確定できない**〕。
- **古庵屋敷条〔文言候補・repo初出・同型の陰性文言〕**: 「**千川上水之儀は安永九子年 町内往還北之方町屋前通江寄小樋掛り有之 天明七未年四月中御先止〔ママ・「御差止」のOCR誤読候補〕二相成候節埋立申候 但元禄年中の儀は樋跡等申伝へも無御座 書留等無之相分り不申候**」＝真光寺門前条と同じ「但し元禄期は樋跡・申伝・書留なし」の但書きつきの書上で、末尾「**右之通取調申上候以上 文政九戌年十月 本郷古庵屋敷名主又右衛門**」。〔**真光寺門前・古庵屋敷の両条では元禄期の記憶が一様に喪失している＝町方側の「記憶の境界」が本郷台地上で竹町（記憶あり）とこの2町（記憶なし）の間に引ける観察**〕。
- **位置づけ〔観察〕**: ①4町すべて「安永9年再掛→天明7年4月差止→埋立」の共通骨格（[GAZ-034](GAZ-034.md)白山前町条の明和6願出→安永8御検地→再掛渡の時系列・[BOOK-217](../books/BOOK-217.md)市街篇30の天明6閏10/22廃止・閏10/27引渡と整合）。②「天明七未年四月中御差止」の文言は町方側の労働現場（埋めた側）の時刻表として、天明6閏10月の幕側の廃止公示から天明7年4月の市中埋樋取潰（[GAZ-024](GAZ-024.md)・[GOV-176](../gov/GOV-176.md)）への初動の実務リードタイムの裏付け。③本郷側の給水樋文言群の密度は、これまでの湯島側（[GAZ-045](GAZ-045.md)）・外神田側（[GAZ-041](GAZ-041.md)〜[GAZ-043](GAZ-043.md)）に比べて一段細かく、**本郷台地の千川上水末端部の給水網の輪郭（春木町弐丁目の堀・大枡→壱丁目・真光寺門前・古庵屋敷の小樋・小桝）が町方書上レベルで初めて並列で読める**。

## 制限・未解決

- ①「田田往還」・「美濃守様」の人物比定・「春来町弐丁目堀」の堀の実体（千川上水本流か分水か）は原文照合まで保留。②「凡百壱間程」「七拾五間余」の間数はOCR数値の誤読リスクがあり、数値の採用は原画像と対照するまで確定扱いしない。③元禄期の記憶喪失（真光寺門前・古庵屋敷）と記憶保持（竹町）の対立が給水実態の差か書上作成時の調査の差かは本冊では判定不能。④本冊に菊坂台町条の千川上水文言の有無は全ページ精査で確認中（triageでは菊坂関係の文言を未抽出・次回の原画像照合課題）。
