# [GAZ-047] 江戸名所図会 十二 — 弦巻川言及の存在（OCR乱れ・内容は留保）

- **書誌〔確認〕**: 『**江戸名所図会**』十二（1893年〔明治26年〕覆刻版・地図資料館版か）。NDL次世代デジタルライブラリー [book/994941](https://lab.ndl.go.jp/dl/book/994941)。天明5年（1785）の原本の1893年覆刻。**本巻のOCRは著しく乱れており、文言の正確な復元は原文画像照合を必須とする。**
- **実相寺条周辺の弦巻川言及〔確認・文言は留保〕**: 日蓮宗・実相寺（雑司ヶ谷・鬼子母神の別当法明寺〔伝通院…等のOCR断片〕の近隣）の条に相当すると見られる箇所に——「**…小山田の条下谷…まきの前を東流をる傾き満川と号く 古へハ…弦巻川 當寺二…川とも唱へるる…源ハ弛谷の辺ふ發し下流ハ清主の辺へゆく…鬼子母神の別當なり…**」〔**①「弦巻川」の語が江戸名所図会の本文に現れる言及の存在、②「源ハ弛谷ノ辺（＝雑司ヶ谷の辺か）ふ發し、下流ハ清主ノ辺（＝関口の辺か）へゆく」と読める流向文言の存在**＝**名所図会の弦巻川文言条の所在の記録**（[GAZ-046](GAZ-046.md)の風土記稿「水元巣鴨雑司ヶ谷接地ノ田間堀」と対応する方向（源＝雑司ヶ谷側・下流＝関口側）だが、OCR乱れのため「弛谷」「清主」の解読・条の帰属寺・「傾き満川」等の文意の確定は原文照合まで留保する）〕〔repoの[江戸名所図会・護国寺図の検討](../../docs/江戸名所図会・護国寺図の検討.md)は図版（護国寺図）の検討のみで本文言条の収録は未着手だった＝本文言側の調査の入口の記録〕。

## 第132回追記（2026-11-16・有朋堂版の対校による判読の前進・ai）

- **[GAZ-058](GAZ-058.md)（『江戸名所図会』有朋堂書店・1927年刊の冊・次世代DL OCR）の法明寺条が、本資料（1893覆刻版）のOCR崩れ文言の対校資料になる**: 有朋堂版の文言「**当寺仁王門の前を東流する細き溝川をなづく。古へは布引川とも唱ヘけるといひ傳ふれども…弦卷川　水源は池谷〔イケヤド〕の邊に發し、下流は〓土の邊へ出て、音羽町の西の方を歷て、江戶川に會せり**」＝**本資料の「源ハ弛谷ノ辺」「下流ハ清主ノ辺」が「水源は池谷〔イケヤド〕の邊」「下流は〓土（清土）の邊」と読める**ことが判明した。①「弛谷」→「池谷」は[BOOK-144](../books/BOOK-144.md)（遊歴雑記五編「池ヶ谷といえる處に丸池」）・[対照表](../../地名・河川名対照表.md)の池ヶ谷／池箇谷行と整合し、②「清主」→「清土」は[BOOK-151](../books/BOOK-151.md)（遊歴雑記初編・潭弦亭条の「此土地を清土といへば」）等の清土地名と整合する。**ただし本追記は活字版OCRによる判読の前進であって、天明5年原本・1893覆刻版の原字の確定ではない（原画像照合は今後も必要）**。③法明寺条の「古へは布引川とも唱ヘける」の異名文言も有朋堂版で確認された（[GAZ-058](GAZ-058.md)①）。
