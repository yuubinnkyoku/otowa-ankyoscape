# [GAZ-019] 『御府内備考』巻之四十八・四十九「関口之一・之二」（大日本地誌大系 第3巻）

- 書誌：大日本地誌大系 第3巻 御府内備考（雄山閣、昭和6年、NDLJP:1214872、インターネット公開）。巻之四十八「關口之一」はコマ16左頁（印刷頁13）から、巻之四十九「關口之二」はコマ17左頁（印刷頁15）からコマ20右頁上段まで。関口之二の収録は水道町（小日向水道町）・大泉寺門前・駒井町・新長谷寺門前。「関口町」という独立した町名節はない。
- 2026-10-30、NDL刊本画像とビューア全文検索の照合による読取（ai）。

## 内容メモ（水関係の項目のみ。解釈は書かない）

- 関口総説・上水（コマ16〜17）：江戸川の水源は武州多摩郡吉祥寺村の井之頭辨天池で、そこから神田御上水と分水し、町内地所へ移り、水末は神田川へ落ち入る旨がある（「辨天池」の表記は他箇所で「辨才天之池」とも読め、表記ゆれとして扱う）。
- 江戸川橋（コマ17）：板橋、長さ凡九間・幅二間、江戸川に掛かり小日向水道町方へ渡る橋で、江戸川橋と唱える旨がある。関口橋の項もある。
- 水道町（コマ17〜18）：町内北の方に神田御上水の南岸通りがあり「中堤」と唱える旨、御高札場は三拾町組合で小日向水道町にある旨がある。「用水」の語はなく「御上水」と記される。
- 駒井町（コマ19）：細目に神田御上水・下水・石橋とあるが、本文は水道町への参照が多い。
- 新長谷寺門前（コマ19）：神田御上水は南の方の崕下を流れ、委細は水道町にて申す旨、下水（幅二尺程）と石橋の項がある。
- 「池」を項目名とする記述は両巻にない。
