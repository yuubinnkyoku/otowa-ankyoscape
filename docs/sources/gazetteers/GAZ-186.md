# [GAZ-186] 東京府志料 第三 河渠志・水利志（都公文書館蔵本2種）

- **書誌〔確認: 詳細頁目録・2026-11-24〕**: ①「**東京府志料 第三 河渠志 水利志 (東京府写本)**」＝資料ID [000106393](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_01&pkey=000106393)・文書・資料群ID＝東京府・**請求番号ＤＣ－００３**（旧ＤＣ－００３・**大整理番号5664**）・1冊・紙・書誌事項＝竪帳（東京府写本）・配架230B015-060401・江戸明治期史料・シリーズ名1＝地誌・公開・複写可（原本電子コピー不可・撮影可）・16mmMF**江－地誌類０８３**（複製）・**コマ0702-0756**・電磁Ｄ０６－０００７－ＲＡＭ。②「**東京府志料 第三**」（府原本）＝資料ID [000106418](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_01&pkey=000106418)・**請求番号ＤＣ－０２８**（**大整理番号5689**）・1冊・書誌事項＝竪帳（府原本）・**文化財指定欄＝国重要文化財指定**・利用条件＝**原本**・複写可（原本電子コピー不可・撮影可）。
- **内容細目〔確認: 目録の「内容」欄文言〕**: 河渠志＝東京府志料**巻之五**の条目: 「内壕附道三堀・外壕・日本橋川筋附堀江町入堀・京橋川筋・八丁堀・新橋川筋・海運橋川筋附伊勢町堀・三十間堀・霊巌橋川筋附新川稲荷堀支堀二・越前堀（写本＝「越前堀附支堀」／原本＝「**越前堀 浜町堀附支堀**」）・神田堀・薬研堀附支渠・渋谷川・入間川・鮫河附桜川宇田川汐留町入堀・**弦巻川**・加二川附中川・親川・目黒川附北澤流島山流・蛇崩川・立會川・呑川附深澤流内川・海老取川」。水利志＝**巻之六**の条目: 「玉川上水・神田上水・神田上水助水堀・善福寺池流・石神井用水・**千川用水附支流**・六郷用水・品川用水・池上用水・井草川・三田用水・玉川分水新川・古上水川附中井堀東井堀西井堀篠原落・小合溜井・大井堀附小岩用水東井堀西井堀中井堀小松川境川」。
- **観察**: ①**弦巻川が東京府志料河渠志の独立条目**として実在し、配列上は「渋谷川→入間川→鮫河附桜川宇田川汐留町入堀→**弦巻川**→加二川附中川→親川」という**渋谷川系の系列内**に置かれる〔目録レベルとはいえ、**弦巻川条目の存在とその配列方向はrepo初出の書誌情報**。弦巻川が渋谷川系（渋谷川の枝川）の系列に分類された明治期の府志料編纂上の位置づけのdatapoint〕。②**千川用水は「附支流」付きの条目**として石神井用水と六郷用水の間に置かれる。③既収録の東京府志料引用群（[GAZ-051](GAZ-051.md)第210回追記の蟹川条「東京府志料に記す所左の如し」・[GAZ-072](GAZ-072.md)第149回の高田馬場条・茅場町条＝東京府志料引用・[GOV-098](../gov/GOV-098.md)の中荒井村水田）の**引用元の庁本（都公文書館蔵本）の書誌を固定した**点が本項目の主眼。④**府原本が国重要文化財指定**であること。⑤写本と原本の細目の差（「浜町堀附支堀」の有無）の観察（写本の省略か編纂上の差かは未確認）。
- **制限・未解決**: ①条目の**本文文言は未取得**＝弦巻川条・千川用水条の内容（流路・幅員・由緒等）は未確認。マイクロフィルム（江－地誌類083・**コマ0702-0756**・55コマ分）の閲覧・複写で本文取得の可能性がある〔repo初出の文言を含む可能性が高く**次回以降の最優先課題の一つ**〕。②府原本（ＤＣ－０２８）は国重文指定・閲覧＝原本。③千川用水条と[GAZ-051](GAZ-051.md)（豊多摩郡誌1916）の流路文言・[GOV-098](../gov/GOV-098.md)引用文言との対照は本文取得後に実施する。
