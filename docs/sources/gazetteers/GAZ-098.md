- **隅田川条の諸書列挙と長門本・盛衰記の引用〔確認・repo初出の本文〕**: 隅田川条が①東鑑（治承四年庚子十一月二日の武衛〔頼朝〕渡河の記事・豊嶋権守清光・葛西三郎清重の先発）→②「**十六夜に記し云**」（候補・OCR崩れ。書名特定は保留）→③**長門本平家物語**→④**源平盛衰記**→⑤北条氏康の武蔵野紀行→⑥川越記→⑦宗祇名所方角抄の順に諸書を列挙する構成で、③は「**長門本平家物語に云 叔兵衛佐むさしの国と下総とのさかひ隅田川のはたに陣をとる（中略）又うき橋をわたしてまいらせけり。此橋を渡て**武蔵国豊嶋の上瀧の川の板橋といふ所に陣をとる**」、④は「**源平盛衰記ニ云 兵衛佐頼朝ハ…隅田川原ニ陳ヲ取ル（中略）又留田川ノ浮橋ヲ渡シテ**武蔵国豊嶋ノ上瀧野川板橋ト云所ニ陣ヲ取ルト云**」＝**①長門本平家物語の本文を「上瀧の川の板橋」として直接引用する江戸期の用例（repo初出の文言系統）、②源平盛衰記を「上瀧野川板橋」として引用する江戸期の用例（江戸初期版本2本〔[GAZ-096](GAZ-096.md)〕の「上瀧野河松橋」と橋名部分が対立する引用形）**＝**1841年時点で、平家系（長門本）も盛衰記系も陣所を「板橋」として読む引本が存在した（またはそのように校して引用した）ことを示す考証記録**〔松橋/板橋対立（[GOV-198](../gov/GOV-198.md)第173回追記の「一説には盛衰記の松橋は誤りで長門本平家物語には板橋とある」の1931年言及）に先行する江戸期の本文・引用例として、GAZ-096の表記対立整理の橋渡し資料候補。**「板橋」が大橋方長の盛衰記の写しの本文由来か、彼自身の校訂（松橋→板橋の変更）かは本書からは判定できず断定しない**〕〔OCR・要照合〕。
- **長門本引用の区切り〔確認・文言候補〕**: 長門本引用は「**武蔵国豊嶋の上瀧の川の板橋**」＝「上瀧の川」（野なし）＋「の板橋」の形で、盛衰記引用の「**上瀧野川板橋**」（野あり）と並ぶ＝**「野」の有無・橋名の対立が、引用される本の系統ごとに貼り分けられている（候補）**＝GAZ-095（望海毎談）・GAZ-092（江戸往古図説）に見られる大橋方長の諸書対校の方法と整合する引用態度〔OCR・要照合〕。
- **「留田川」の判読〔文言候補・要照合〕**: 盛衰記引用の「**留田川ノ浮橋**」は文脈上「隅田川」を指すと見られるが、「留田川」の字形のままOCRに現れる＝**原文の判読（隅田川の崩れか、現にそう書いてあるか）は原画像照合が前提**でここでは判読保留とする。
- **陰性〔確認〕**: 本冊fulltextで「瀧野」は上記の2件（同一文の重複採録）のみ。「金剛寺」2件は川口の高畑村金剛寺条で**王子・滝野川の金剛寺（松橋院）とは無関係**、「岩屋」8件は比企郡吉見の岩屋（岩殿山・吉見の岩屋）等で**松橋弁天窟（いわや）とは無関係**、「飛鳥山」0件・「音無」0件＝**武蔵演路に王子滝野川金剛寺条・飛鳥山条・音無川条の存在は確認できず、対象4河川（水窪川・弦巻川・谷端川・千川上水）への直接の新文言も確認できない**（本資料の価値は隅田川条の軍記引用群に集約される）。「板橋」14件は中仙道板橋宿・下板橋宿の宿場・戸田川渡の記述で、松橋/板橋対立とは別文脈。
