# [GAZ-132] 町方書上[87] 浅草壱之上 — 平右衛門町条の千川上水の仰渡・水銭・差止の一次文言

- **書誌〔確認〕**: 『町方書上[87] 浅草町方書上　壱之上』（写・NDL次世代デジタルライブラリー [book/2571568](https://lab.ndl.go.jp/dl/book/2571568)・124コマ）。表紙丁順「二七五ノ第十五 平右衛門町」＝**本冊の主体は平右衛門町条**（地誌御調書上帳・浅草平右衛門町）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571568_{NNNNNNN}.txt` コマ番号。**
- **平右衛門町条の千川上水文言〔文言候補・本冊の主要価値〕（p38）**: 「**一千川上水 先年之通 遂渡之儀 願人有之 願之通被仰付 水筋町之井戸堀渡に付 水銭差遣可申旨 安永九子年十月廿七日 町御奉行 牧野大隅守殿 御番所に而被仰渡有之 右上水井戸 上平右衛門町河岸之方町屋前に壱ケ所 下平右衛門町同断町屋前に弐ヶ所 堀渡有之候 天明七未年四月十三日 御差止メニ相成候旨通達有之 其節堤立に相成申候**」＝**①千川上水を先年同様に遂渡（通水）させたい旨の願人があり願の通り仰付けられた、②その際給水ルート上の町（水筋町）の井戸・樋渡し（「堀渡」＝OCR・原字照合）について水銭を差し遣わすべき旨が、安永9年（1780）10月27日に町御奉行牧野大隅守殿の御番所で仰渡された、③上水の井戸は上平右衛門町河岸の方・町屋前に1ヶ所＋下平右衛門町同断・町屋前に2ヶ所、④天明7年（1787）4月13日の御差止めと通達があり、その節堤立（埋立候補）になった**という一続きの文言。〔**①「安永九子年十月廿七日」という日付文言の浅草側witness**＝[GAZ-124]・[GAZ-125]（外神田二・四・神田側同月同日の文言）と同じ日に**町御奉行牧野大隅守の番所での仰渡**として具体化する文言候補（末端給水の再開と水銭の連携の実務側）、②**水銭文言の浅草末端側の新出**＝[GAZ-114]（下谷長者町繋車坂町の水銭204文/月・天明6年）・[GAZ-082]（上野山下404文/月）に並ぶ**浅草末端の水銭実務の存在文言**（金額は本文言にはなし・「水筋町」という負担主体の語彙も新出候補）、③井戸数（上平右衛門町河岸1＋下平右衛門町河岸2）＝[GAZ-115]（御府内備考・写本側の「上平右衛門町河岸新焼町屋之方二壱ケ所 下平右衛門町河岸同方二弐ヶ所」）・[GAZ-082]（活字版）の**町方書上原本側の独立witness**、④**差止日「四月十三日」の浅草側の整った日付文言**＝[GAZ-115]の「四月中」・「四月十二日」・[GAZ-041]/[GAZ-124]系の「四月十三日」の対立群の中で、同じ末端域の町が十三日を明記する文言候補（12日/13日/中の文言分布がさらに複層に）、⑤「堤立」＝水路跡の更地化の語彙観察（[GAZ-115]の「埋立」との表記対立）**〕。
- **平右衛門町名の由来文言〔付記・地名由来の対校値〕（p38周辺）**: 「**平右衛門町名主平左衛門 元祖三枚平右衛門…往古遠州濱松住…天正十八庚寅年 権現様御入国之節御供仕 御当地江罷下り 当所に住居仕…元和二丙辰年 右三枚平右衛門并忰平八郎…当所町屋に取立 取締り可仕旨蒙上意 町名之儀は本家住居之地に付平右衛門町而附可申旨拝領被仰付…太宰大弐三枚守国末裔ニ而系図書付等御座候処…苗字立枝と相名乗候得共 右平長代子細有之村田而相改申候**」＝**町名「平右衛門町」が遠州浜松出身の三枚平右衛門（太宰大弐三枚守国末裔の申伝・元和2年の取立）に由来する旨の長い由緒文言**。〔第215回課題の済松寺（濱松寺/高松寺）・遠州系の関联回収の端緒になる可能性があるが水系文言ではないため付記に留める〕。

## 制限・未解決

- ①「遂渡」の語（水を通す意の「遂渡」原字か「遂渡り」の切れか）・「水筋町」・「堀渡」（樋渡のOCR候補）・「堤立」等の原字はOCR由来で原画像照合課題（いずれも断定せず）。②水銭の金額は本文言に現れない（他の町の帳簿〔[GAZ-114]押切帳面〕との対応でのみ金額層が出る・本文言単独では水銭の実額の記録ではない点に注意）。③「四月十三日」とGAZ-115の「四月十二日」・「四月中」の対立の解消（同一地域の年月日の記憶差・触の再達の日差等の可能性）は本冊の文言だけでは断定できない。④平右衛門町条が「浅草壱之上」冊のうちのどの位置の条か（表紙の「二七五ノ第十五」表記との対応）はOCRストリーム依存の候補。⑤安永9年10月27日の仰渡＝千川上水の天明期再興の実務上な開始点（[GOV-352]〔天明2年通水〕との年代順序＝安永9年掛渡→天明2年通水とする時系列の解釈の詳細は [GAZ-113]/[GAZ-124] 系の既存の年次論のままとし、本冊文言のみで年代を動かさない。
