# [GAZ-086] 改正東京名細記（児玉又七・大橋堂・明治14年初版系）— 掃部橋の音羽桜木町文言候補・船河原橋の三流合流・砲兵工廠内の神田上水〔第158回〕

- **書誌〔確認・書誌要再照合〕**: 児玉又七『**改正東京名細記 一名・独案内**』（**大橋堂**版。児玉又七は明治14年（1881）初版の独案内系地誌の刊行者で、本書はその**改正版**〔版冊の年次は未確定・目録上の15区制時代の記載から1880年代中半の候補・year近似〕）。NDL次世代デジタルライブラリー [book/764206](https://lab.ndl.go.jp/dl/book/764206)。**本書のOCRは片仮名・漢字の高度な崩壊があり、引用文言はすべて原画像照合を要する**（以下の文言も「候補」として扱う）。
- **掃部橋の文言候補〔OCR・要原文照合・音羽側比定の残存例〕**: 「**掃部橋 音羽サクラ木丁、ワ九流ニ架ル**」と読めるOCR断片＝「**掃部橋（は）音羽桜木町・（その）ワ（九）流ニ（＝間の流れに）架ル**」と解し得る文言候補。〔**[GAZ-030](GAZ-030.md)（江戸名勝志）が「音羽町九丁目の上水に懸ると云説は誤也」と退けた、掃部橋を音羽側に比定する系統の読みが、明治期の独案内（案内記）レベルで残存していた候補の記録**。ただし①「ワ九流」の原字（「ワタル流」「九ッツ(ノ)流」等の崩れ可能性）②対象橋の特定（関口側の掃部橋〔[GOV-221](../gov/GOV-221.md)・[GAZ-080](GAZ-080.md)〕か、音羽桜木町間の江戸川筋の橋〔音羽九丁目橋系・[GAZ-080](GAZ-080.md)の「音羽町九丁目橋」〕か）は本OCRからは確定できず、**原画像照合までは江戸名勝志への対校資料としてのみ位置づける**（断定しない）。〕
- **船河原橋・三流合流の文言候補〔OCR・要原文照合〕**: 「**舩河原橋 小石川砲兵本廠前ヨリ牛込ヘワタル 俗ニドン…**」＋「**牛込川ト江戸川ノ三流一ッセル**」と読める断片＝**①船河原橋が小石川砲兵本廠（旧砲兵工廠）前から牛込へ渡る橋として案内され、「ドン」（水勢トンの俗呼）の呼称を併記する候補**（[GAZ-049](GAZ-049.md)・[GAZ-083](GAZ-083.md)の「俗にどんと」の江戸期文言の明治側残存候補）＋**②「牛込川ト江戸川ノ三流一ッセル」＝牛込川（白山川系か）と江戸川の三流が一つになるという合流記述の候補**（明治期の神田川上流側の流系認識の datapoint 候補。どの3流かは本断片では不確定・要照合）。
- **神田上水の砲兵工廠内通過の文言候補〔OCR・要原文照合〕**: 「**水道…口ノ大洗垤(?)ヨリ分レテ水道丁…小石川砲兵本廠ノ内ヲ通シ神田上水ノ…**」と読める断片＝**神田上水（千川上水系）が小石川砲兵本廠（工廠）構内を通過すると案内した文言候補**（[GOV-350](../gov/GOV-350.md)系の幕末の鉄砲製造所帳簿・[GAZ-083](GAZ-083.md)の江戸期の神田上水文言と対照し、明治期の砲兵工廠と上水の空間的関係の案内記録レベルの候補。文脈の崩れが大きく内容の確定は要照合）。
- **駒止橋・大堰口・目白坂等の案内記述候補〔OCR・要原文照合〕**: 駒止橋（[GAZ-049](GAZ-049.md)・[GOV-226](../gov/GOV-226.md)系）・大堰口・目白坂・椿山（お茶の水附近の椿山か・要照合）・高田富士山・浅間社等の地名・坂橋の案内文言候補がOCR断片に見える＝**明治14年系独案内が雑司ヶ谷・音羽・高田・大塚側の名所・坂道を案内した記録の存在**（各文言の確定は原画像照合まで保留）。

## 制限・未解決

- ①本書のOCR崩壊はこの系統の資料の中でも特に大きく、本登録は断片レベルの所在記録である。引用文言はすべて原画像照合を要し、特に「ワ九流」「三流一ッセル」等の原字判定が必須。②版冊の刊年は未確定（明治14年初版系の「改正」版・15区制時代から1880年代中半の近似に留める）。「改正東京名細記」の改版系譜（明治14年〜20年代の各版の異同）の書誌確認は要する。③「掃部橋」文言の対象橋の特定（関口の掃部橋か音羽九丁目橋か）と、[GAZ-030](GAZ-030.md)江戸名勝志の誤説批判への対校の可否は原画像照合後の課題。④「牛込川」の実体（白山川・小石川下流の別名か）は本書からは確定できない。
