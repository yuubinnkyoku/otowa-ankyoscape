# [GAZ-030] 江戸名勝志 巻二（明治11年輯）— 絃巻川・掃部橋・安見橋＝面影橋の江戸期地名集成

- **書誌〔確認〕**: 藤原之廉輯『**江戸名勝志**』**二**（東京府文献叢書甲集第30冊・**明治11年〔1878〕輯**〔OCRで「輯」表記〕。江戸期の地誌の集成・再録で、江戸名所系の近世記述を明治期に編纂）。NDL次世代デジタルライブラリー [book/2577117](https://lab.ndl.go.jp/dl/book/2577117)。**すべての引用は同館OCRテキスト由来であり、くずし字原本・活字翻刻の双方との照合を要する。**〔原本の成立年代（江戸期原本の撰年）と明治11年輯の区別に注意。編者名の読み・輯年はOCR由来で要確認〕。
- **絃巻川・星跡清水〔確認・近世集成レベルの記述〕**: 「**絃巻川 右同所〔高田馬場項の次〕法明寺の前の細流也。皇[星]跡清水 絃巻川の下流也。雅[雑]司か谷と護国寺の間の田中**」＝**①絃巻川＝法明寺の前の細流、②星跡清水＝絃巻川の下流、③その位置＝雑司ヶ谷と護国寺の間の田中**〔[GAZ-027](GAZ-027.md)（明和9年・江戸砂子温故名蹟誌「法明寺前の細流をいふ」）の系統を受け、**星跡清水の弦巻川下流属性**を明確化した記述。「星跡」のOCR「皇跡」誤読があり要照合〕。
- **掃部橋〔確認・repo初出の橋名〕**: 「**掃部橋 江戸川に懸る橋は古川町・水屋町へ渡せり。音羽町九町目上水に懸ると云説は誤也。又古川町を吉川町と書も誤也**」＝**①掃部橋は江戸川（神田川）に架かり古川町・水屋町へ渡す橋、②「音羽町九丁目の上水に懸かる」という説を同書自身が「誤也」と否定、③古川町を吉川町と書くのも誤り**〔**掃部橋の橋名はrepo初出**。「音羽町九丁目上水に懸る」説＝千川上水（神田上水）の市中樋管経路（音羽町九丁目の地下）に関する伝承の橋をめぐる議論とつながる可能性があるが、同書は江戸川に架かる橋と結論しており、断定しない〔詳しくは下記制限〕。掃部（かもん）橋の比定地（江戸川橋〜西江戸川町付近と推定）は本文の「古川町・水屋町」からのみで特定は保留〕。
- **安見橋＝「面影橋とも云」〔確認・repo初出の面影橋の古名候補〕**: 「**安見橋 高田馬場二町余亥子方、上水川に懸る、長サ十二間四尺、面影橋とも云**」〔前後の項で「寛永十三年三月築かるゝと地人有」との文言が現れるが、OCRの項目境界で安見橋・穴八幡・高田馬場のいずれに属するかは要照合〕＝**①安見橋は高田馬場から二町余の亥子方、上水川（＝神田上水・千川上水系の川）に架かる、②長さ十二間四尺、③「面影橋とも云」＝面影橋の異名・古名候補**〔**面影橋の別名「安見橋」の記録はrepo初出**。高田馬場・面影橋＝弦巻川下流（旧神田上水沿い）の橋であり、橋名の変遷（安見橋→面影橋）の候補として記録。対応の方向（どちらが古い・新しいか）は本条では不明〕。
- **江戸川＝関口上水の余流・飯田町の下の川筋替え〔確認〕**: 「**江戸川 関口上水の余流也。小日向・筑地の間を流るゝ事十五町余にして神田川に落る也。昔は飯田町の下を流れしか、神田川出来て川筋替へると也**」＋「**仙台橋 牛込御門三町北方、江戸川の落口に懸る。和平陸奥守、神田川を掘れし時掛らると也。世俗どんど橋と云、又舟河原橋とも云**」＝**①江戸川（神田川下流区間名）は関口上水（神田上水）の余流、②小日向〜筑地間十五町余で神田川に注ぐ、③かつては飯田町の下を流れていたが神田川の出現で川筋を替えた、④仙台橋は江戸川の落口（神田川合流点）に架かり、神田川掘削（仙台藩・伊達家）の時に架けられた、別名どんど橋・舟河原橋**〔江戸川＝上水余流説・飯田町の旧流路説・仙台橋の由緒（神田川掘削時の架設・「仙台藩が架けた橋」[BLOG-154](../blogs/BLOG-154.md)の近世集成系の裏付け）を一つの資料で確認〕。
- **水門＝大洗堰・上水承応年中掘始め〔確認・repo初出文言候補〕**: 「**水門 関口村の西、白山の下に在。是を大洗堰と云と也。此川の源は…落合・高田の間を流れて爰に至り、比ゟ分れて一方は江府の上水とし一方に江戸川へ落る也。此上水承応年中に掘はじまる**」〔OCRの項目境界が乱れており、「此上水承応年中に掘はじまる」が水門条・椿山条のいずれに属するか要照合〕＝**①大洗堰は「水門」と説明され関口村の西・白山の下にある、②川（神田川上流）は落合・高田の間を流れて関口で二分し一方は江戸の上水に、一方は江戸川へ落ちる、③「此の上水は承応年中（1652〜55）に掘り始まる」**〔**「上水承応年中掘始め」の文言はrepo初出候補**＝神田上水の開削年代（承応3年〔1656〕家綱入府説系・寛文初年説系など）の系統に対応する近世集成レベルの記録として注記。千川上水（元禄9年）とは区別される〕。

## 制限・未解決

- ①本書は江戸期地誌の明治11年集成で、各条の原本（『江戸鹿子』『新編江戸志』系など）の特定と原本文言との異同確認が今後必要〔掃部橋・安見橋条の出典元の特定が最優先課題〕。②掃部橋の「音羽町九丁目上水に懸る説の否定」は、音羽町九丁目の上水（千川上水の市中樋管・[GAZ-013](GAZ-013.md)九丁目橋等の記述）に関連する伝承の存在と、その説を江戸川の橋として否定する近世側の判断を示すが、橋の実在位置・樋管経路の特定には使えない〔断定しない〕。③安見橋＝面影橋異名の向き（古名・異名の方向）と、寛永13年3月築橋文言の帰属は要照合。④「承応年中掘始め」が神田上水の開削年代説としてどの系統の記録か、水門条の文脈確定後に判断する。⑤OCRに多数の誤読（皇跡/星跡・雅司/雑司等）があり、全ての文言は原本・活字版との照合を要する。
