# [GAZ-053] 東京市史稿 市街篇 第十五（1932）— 宝永元年の白山下千川屋敷渡預絵図証文

- **書誌〔確認〕**: 東京市役所『東京市史稿』**市街篇 第十五**（1932年刊・次世代デジタルライブラリー [book/3450789](https://lab.ndl.go.jp/dl/book/3450789)）。市街篇第十二（[GAZ-016](GAZ-016.md)・[book/3450786](https://lab.ndl.go.jp/dl/book/3450786)）の収録範囲（1694〜97年）の続巻で、宝永元年（元祿十七年四月改元・1704）頃の市街異動を収める。引用文言はOCR由来で要原文照合。
- **屋鋪渡預繪圖證文（宝永元年8月23日）〔確認・repo初出〕**: 小石川白山下の余語古菴上ケ屋敷（坪数333坪・「東、鈴木兵右衞門。西、道南、伏屋賴母。北、道…」の四隣つき）について——
  1. **名主預（8月9日）**: 「**小石川余語古菴老上ケ屋敷、拙者に御預被成…名主寶永元甲申年八月九日六之丞印 水野權十郞內永田庄助。右立合相改、預之。名主六之丞印**」＝333坪が名主六之丞に預けられた（水野権十郎内永田庄助の立会い）。
  2. **上水請負人4人への渡（8月23日）**: 「**右御繪圖之面傍示杭之通相改、相違無御座請取申い。爲後日仍如件。寶永元甲申年八月廿三日 千川德兵衞印・同太兵衛印・同善九郎印・同善左衞門印 水野權十郞內中村傳右衞門。右立合相改、渡之。**」＋その前段「**巢鴨拜借屋敷指上い爲代地、小石川余語古菴樣御上ケ屋敷內こゐ私共四人に御渡被成**」＝**巣鴨の拝借屋敷を差し上げた代地として、余語古菴上ケ屋敷内の地（213坪）が上水請負人4人——千川德兵衞・太兵衛・善九郎・善左衞門——に渡された**旨の証文（坪数213坪・「東、表六尺。西、道。南、伏屋賴母。北、道」の四隣明記）。編者注「**元祿十七甲申年四月寶永ト改元**」。
  3. **陸尺衆拝領**: 同所に陸尺衆（川崎嘉兵衞らと読める文言）の拝領（63坪と読める文言）が並記（列崩れ・要照合）。
  ＝**千川上水請負の「千川」姓の人物が元禄〜宝永期に4人（徳兵衞・太兵衛・善九郎・善左衞門）並んで屋敷を受領した一次証文の全文**。〔徳兵衞・太兵衛の2人の請負は元禄9年の開削文言（[GAZ-016](GAZ-016.md)・[GAZ-048](GAZ-048.md)）で知られるが、**善九郎・善左衞門を含む4人への渡**・**「巢鴨拜借屋敷指上い爲代地」＝巣鴨側の拝借屋敷との交換という経緯**・白山下333坪/213坪の具体数値はいずれもrepo初出。千川家の巣鴨側屋敷（庚申塚付近の上水屋敷）から白山下への移転の実務記録として、白山前町千川屋鋪の元禄9年拝領（[GOV-210](../gov/GOV-210.md)〜[GOV-212](../gov/GOV-212.md)・[GAZ-049](GAZ-049.md)⑫巻44）の前段・並行の文書。〕
- **白山前町千川屋鋪条〔確認・3テキスト対校の確定〕**: 同冊に白山前町の千川屋鋪の書上があり「**當町往古さ小石川村百姓地ニ有之い處、年代不知余語古庵拜領町屋鋪ニ相成…元祿九子年中千川上水**（後略・[GAZ-016](GAZ-016.md)の同文とほぼ同一・文政町方書上引用）」＝**市街篇第十二（3450786）・市街篇第十五（3450789）・御府内備考巻44（[GAZ-049](GAZ-049.md)⑫）の3テキストが同文言を引用**し、白山前町千川屋鋪条の本文校勘の基礎が揃った（細字の異同は今後の照合課題）。
- **位置づけ〔観察〕**: 千川屋鋪（白山下）の成立を「余語古菴拝領地→名主預→上水請負人4人への代地渡→陸尺衆拝領の併行」という**土地譲受の実務過程（絵図証文レベル）**で示す史料が市街篇に採録されていたこと自体が収穫。千川家の屋敷が「白山前町（千川屋敷）」と「巣鴨（拝借屋敷→差上げ）」の2か所で運用されていた宝永期の実態の一次記録。
