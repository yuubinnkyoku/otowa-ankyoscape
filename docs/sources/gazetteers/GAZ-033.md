# [GAZ-033] 御府内備考（巻32〜40）の谷戸川条・合染橋・立合橋

- **書誌〔確認〕**: 『御府内備考』（江戸町方の書上を集成した地誌・**文政12年〔1829年〕の書上を基礎とする集成**〔調書の年は各条の書上年で、全巻の成立年は要照合〕）。NDL次世代デジタルライブラリー [book/2553673](https://lab.ndl.go.jp/dl/book/2553673)（**巻32-40**＝谷中・駒込・下駒込方面）のOCRテキストで谷戸川関係の文言を今回確認した。**引用はすべてOCRテキスト由来で、文言は原文画像との照合を要する。**〔既存の[GAZ-024](GAZ-024.md)（大日本地誌大系第2巻〔雄山閣・typeset版〕・巻25-46の千川上水跡条）と同じ書の**別版（原本系OCR版）・別巻域**で、本条はrepo初出〕
- **谷戸川条〔確認・repo初出〕**: 谷中の町（感応寺古門前町付近）の四隣書上——「東之方**谷戸川**を隔〔て〕谷中感応寺古門前町…北之方下駒込村 一**堀幅九尺程 右は字谷戸川と唱 渋江長伯様御預り 巣鴨御茶岡ゟ出〔て〕田端村・新堀村・下駒込村ゟ町内東之方…当町之間ヲ相流 谷中駒込之場ニ御座候**」〔**①「字谷戸川」の堀（幅9尺程・下駒込村北境）が巣鴨御茶ノ岡から出て田端村・新堀村・下駒込村を経て谷中方面へ流れる流路、②渋江長伯（熊）預り地の境界であること**＝**谷戸川の文政期の市中側の一次書上記録**〕〔幅9尺＝[GAZ-032](GAZ-032.md)の風土記稿谷戸川条（幅1〜2間）と概ね整合するが、区間・計測時点は異なるので単純比較しない〕。
- **石橋「合染橋」〔確認・repo初出・藍染橋の候補〕**: 「一**石橋 長サ弐間幅八尺 右は谷戸川ニ掛り候 而合染橋と唱候者も有之由 尤掛始年代相知不申候**」〔**谷戸川に架かる石橋（長2間・幅8尺）で「合染橋」と唱える者がいたこと、架け始めの年代は不明とする書上**〕〔**「合染橋」は風土記稿の「根津谷中ノ邊ニテハ藍染川ト唱フ」（[GAZ-032](GAZ-032.md)）・2019年の区映像証言の「藍染川」（[GOV-133](../gov/GOV-133.md)）と対応する「藍染橋」のOCR表記差（合⇔藍）の可能性が高いが、字形は原文画像で要照合**〕。
- **板橋「立合橋」〔確認・repo初出〕**: 別の町方書上（日光御成道の町）——「一堀巾一間 右字**谷戸川**と相唱申候 **板橋長二間幅同断 右谷戸川に相掛有之 立合橋に相唱申候**」〔**谷戸川（幅1間）に架かる板橋「立合橋」（長2間）の町方書上**〕〔同文言は幕末〜明治期の「町方書上」系資料（[次世代DL book/2571498](https://lab.ndl.go.jp/dl/book/2571498)・駒込町方書上〔17〕参）にも並行して現れる＝書上系テキストの流用関係を示す。個別の町名の同定（谷中感応寺古門前町のどの町か・日光御成道のどの町か）は原文照合まで保留〕。
- **位置づけ〔観察〕**: 谷戸川＝[GAZ-032](GAZ-032.md)（風土記稿・長池起源→中里・田端・谷中→不忍池・根津谷中では藍染川）・[GAZ-027](GAZ-027.md)（明和9年・王子村堰からの西流用水＝逆川の語）・[GOV-133](../gov/GOV-133.md)（2019年・谷戸川→谷田川→藍染川の区間別呼称）とつながる**谷田川系統の江戸期の市中側記録**で、①流路の区間（御茶ノ岡→田端→新堀→下駒込→谷中）、②堀幅、③橋（石橋「合染橋」・板橋「立合橋」）の3点が文政期の書上レベルで確認できた〔谷戸川は四河川（水窪川・弦巻川・谷端川・千川）のいずれでもない隣接水系（石神井川系）だが、谷端川北側の谷筋・下水の受け皿として流域環境の対照資料になる〕。
