# [GAZ-162] 町方書上[41] 麻布町方書上 七止（文政10-11年）— 白金御殿水筋の全域流路と品川領用水化の文言

- **書誌〔確認〕**: 『[41] 麻布町方書上 七止』（写・NDL次世代デジタルライブラリー [book/2571522](https://lab.ndl.go.jp/dl/book/2571522)。NDL目録volume表記「[41] 麻布町方書上 七止」・直接確認）。表紙に「地誌御調書上帳 麻布本村町」（p5）＝**麻布本村町単独冊**。条末署名は「文政十一子年」（p27・30・34・79・90・95・100等・OCR）で、1ヶ所に「文政十亥年」（p70）が混在。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571522_{NNNNNNN}.txt`）。※白金御殿水筋は当repo四河川（水窪川・弦巻川・谷端川・千川上水）のいずれでもないが、**玉川上水系の江戸市中分水（三田上水の御殿枝線候補）の廃止後の転用の一次文言として上水史の系譜整理のために採録する**。
- **本村町条の御上水跡＝白金御殿水筋の全域流路と品川領用水化の文言〔文言候補・本冊最重要〕（p17）**: 「**一御上水跡壱ヶ所 玉川分水ニ而白金御殿江掛り候水筋之儀は 萩園（OCR・判読不能）ゟ相分り 代々木村 上目黒村 下渋谷村 三田村 下豊田村ゟ河左布村（OCR・判読不能）江成り候処 其後御殿引ケ候節 上水之儀は品川領へ用水に被下置候 同所田地江相懸り候用水普請等不残右百姓ニ而改来り候**」（p17・OCR）＝**①麻布本村町に「御上水跡」1ヶ所があったこと、②その水筋は玉川分水で白金御殿に掛かり、代々木村・上目黒村・下渋谷村・三田村・下豊田村を経て「河左布村」（OCR・麻布村の判読不能候補）に至る流路として「相分り」（=分かっている・把握されている）と記すこと、③御殿が引かれた（廃止された）後、上水は品川領へ**用水として下し置かれ**、その田地に相懸かる用水普請をすべて百姓が管理（改来り）して来たこと**の文言候補。〔**①「御殿引ケ候節…品川領へ用水に被下置候」＝御殿（白金御殿）の廃止後に上水が打捨てられず近隣農村（品川領）の農業用水に転用されたことを記す行政史の文言候補（repo初出）**。上水→用水の転用の実態文言は江戸市中分水の廃止後史（千川上水跡の千川用水化〔千川上水/千川用水の系譜〕とも比較できる）の復元材料。**②流路の村列（代々木村・上目黒村・下渋谷村・三田村・下豊田村→「河左布村」）は[GAZ-158](GAZ-158.md)三田壱町目条の三田上水全流路列記（代田村分水→北沢村・瀬谷村・上目黒村・白銀村→…）と上目黒村で接しながら別構成をとる＝「三田上水本流」に対する「白金御殿枝線」の存在を仮定する系（[GAZ-158]の元禄11寅年白銀御殿枝線文言との対校）に立つ材料候補**。ただし③村名はすべてOCR由来（特に「萩園」「三田村」「下豊田村」「河左布村」の原字）で、流路の復元は原画像照合後に限る。白金御殿と白銀御殿の表記の揺れ（同殿説・別殿説）も断定しない。〕
- **白金御殿起立の元禄11寅年三月文言〔文言候補・起立年次の対校〕（p15-16）**: 「**一御殿之儀は本村町西之方ニ而 阿左布御厄畠（OCR・要照合）ト唱候内ニ有之 御花畠之儀ハ往古ゟ御座候由年代相知シ不申候 其後白金御殿起立之義ハ元禄年中被仰出 同十一寅年三月中御出来之旨ニ御座候 御掛り若年寄秋元但馬守様 米倉丹後守殿 御普請奉行酒井彦太夫様と相伝候 其後御不用ニ相成引候年来相知レ不申候 当時右弥（OCR）ハ御籏本方御拝領地ニ相成申候**」（p15-16・OCR）＝**①白金御殿（本村町西之方・「阿左布御○畠」内の御花畠）の起立が元禄年間に被仰出になり元禄11寅年（1698）3月中に御出来（完成）したこと、②御掛りは若年寄秋元但馬守・米倉丹後守、御普請奉行は酒井彦太夫と伝わること、③その後御不用となり引き（取壊し）の年代は知れないこと、④跡地は当時（文政期）御旗本方の御拝領地であること**の文言候補。〔**元禄11寅年3月の御殿完成文言＝[GAZ-158]三田壱町目条の元禄11寅年白銀御殿枝線文言の御殿側の同年代記録候補**（御殿造営と上水枝線の設置の同時性を支える材料。ただし白金/白銀表記と両文言の同一事件性は断定しない。御殿取潰年代不知文言は[GAZ-163](GAZ-163.md)龍土町条の享保7寅年十月取潰文言〔青山上水〕とは別水系の記録である点に注意）。「宝暦之比は御殿跡と有之候間」（p16・OCR）の回顧文言も付随。〕
- **本村町南之方の川の「渋谷川とも又は新堀川とも」二重呼称文言〔文言候補〕（p14）**: 「**一川之儀ハ本村町南之方ニテ 渋谷川トモ又ハ新堀川トモ申候 幷ニ橋壱ヶ所有之候**」（p14・OCR・「此儀は田嶌町ゟ書上申候」の委譲文言付き）＝本村町南辺の川が「渋谷川」「新堀川」の両名称で呼ばれ、橋1ヶ所があることの文言候補。〔渋谷川の下流部の呼称の並存（新堀川＝[GAZ-106](GAZ-106.md)麻布新堀総説・[GAZ-159](GAZ-159.md)赤羽新堀川年代記と対応）の町方側の使用例。麻布本村町の地形（南が渋谷川/新堀川）の位置関係も流路復元の参考。〕
- **御薬園＝里俗新堀端の所在文言と享保17年検地文言〔文言候補・参考〕（p17）**: 「**此水道式 本村之内ハ享保十七壬年笹増元（OCR・要照合）之様御検地之節 御高入ニ相成候而 同所光林寺仕徳地（OCR・要照合）二相成候 代官判是 百弐壱反壱畝六步見付村六畝九分 一御薬園之儀ハ当町西南之方ニ而里俗新堀端ニ有之候**」（p17・OCR）＝享保17壬子年（1732）の御検地で本村之内の「此水道敷」が御高入となり検地帳上の文言と、御薬園が当町西南の「里俗新堀端」にあったことの所在文言。〔**「新堀端」が麻布側（本村町西南）にも使われた用例**＝[GAZ-160](GAZ-160.md)本村町坂下町辺新堀端・宝永6年「新堀端芝御霊屋…代地」〔[GAZ-106](GAZ-106.md)〕と芝・麻布両岸での「新堀端」地名の分布の対校材料。享保17年（上水差止の15年後）に「水道敷」が御高入＝検地対象の耕作地になった文言候補は、上水廃止後の跡地の私有化（御高入）の一例としても注記に値する（文言の切れ目・「水道式」の原字は照合前提）。〕
