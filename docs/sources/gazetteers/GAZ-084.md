# [GAZ-084] 四神地名録（黄山人古松軒・寛政6年）— 雑司ヶ谷の「上世の巣鴨の在」伝承・鬼子母神掘出者の表記対立・大行院の院代物語〔第158回〕

- **書誌〔確認〕**: 黄山人古松軒『四神地名録』（寛政6年〔1794〕自序の江戸期私撰地誌。**本登録は東京府文献叢書甲集版〔1878年刊〕での採録**）。NDL次世代デジタルライブラリー [book/2577102](https://lab.ndl.go.jp/dl/book/2577102)（同叢書版・冊数はlabでは[11]冊。**叢書内の採録位置・巻次の特定は要照合**。同叢書の小石川志料＝[GAZ-083](GAZ-083.md)（2577108）と同じ叢書系）。**OCRは崩れが大きく、引用文言はすべて原画像照合を要する**。
- **雑司ヶ谷村条の「上世の巣鴨の在」伝承〔確認・文言候補・repo初出〕**: 「**此辺すべて上世の巣鴨の在といふなり しかし古書に見へず たゞ云ひ伝ふのみにて詳かならず**」＝**雑司ヶ谷一帯が「上世の巣鴨の在（在所）」であると云い伝えられるが、古書に見えず、ただの口伝ゆえ詳らかでない、と作者自身が限界を明記する伝承記録**。〔**水窪川・弦巻川源流域の広域地名史（巣鴨の在）の江戸期の文言候補で、repo内で「巣鴨の在」系の伝承は初出**。[BOOK-144](../books/BOOK-144.md)（遊歴雑記・豊島郡雑司ヶ谷村の村名由来説）・風土記稿（[GAZ-048](GAZ-048.md)）の「雑士」系・[GAZ-085](GAZ-085.md)の府内備考系の町名起原伝承（南朝流浪説）とは**別系統の、谷頭集落がかつて巣鴨側の在に属したとする広域名伝承**。上世の比定（前代のどの期か）は本文言からは全く特定できないため断定しない（口伝と明記された伝承として記録する）。〕
- **鬼子母神掘出者の表記対立の作者自記〔確認・文言候補〕**: ①「**相伝ふ 昔時此所に柳下何某といひし百性の耕作にしに地中よりうかちいたせし銅仏にて何仏とも称し難き古仏故に東陽房に送る 今の大行寺なり**」＝**柳下何某という百姓の耕作地中から銅仏を掘り出し、何仏とも称し難き古仏ゆえ東陽房に送った、今の大行寺なり、とする掘出伝承**。②これに対し「**此寺のゑんぎ（縁起）仁は鬼子母神を土中より堀出せしは山本氏の百性とあり 此所のものにきけば柳けば（柳下）氏のといふ者あり 堀出したるに違ひはなく 山本氏と縁起に記しあるは血統なりと**」＝**縁起が掘出者を「山本氏の百姓」と記すのに対し、当地（雑司ヶ谷）の聞き取りでは「柳下氏」と伝え、作者自身が両表記の対立を記録**（山本氏＝柳下氏の血統か血統の表記かは地元の釈義どおり記すのみ）。〔**鬼子母神掘出伝承（[ORG-035](../org/ORG-035.md)・[BOOK-159](../books/BOOK-159.md)（清土出現地説）・[GAZ-070](GAZ-070.md)（江都近郊名勝一覧）・[BOOK-144](../books/BOOK-144.md)（本淨寺の南の林中））の、掘出者の名字をめぐる表記対立（柳下／山本）を作者が聞き取りつつ両記する江戸期の一次的文言候補**。掘出地を清土側とする系統（BOOK-144等）と雑司ヶ谷側の掘出を暗黙に仮定する本書の記述位置（雑司ヶ谷村条）との関係は断定しない。東陽房・大行寺の比定も原画像照合を要する。〕
- **大行院＝自昌院建立の院代の物語＋小幡勘兵衛木像〔確認・文言候補〕**: 「**大行院の院代物語られしは 此寺は天正の頃 前田利常朝臣 加州の御先祖也の息女 芸州候へ入らせ給ひ 自昌院と申せし御方 御達立有りし寺也 との事なり**」＝**大行院（大行寺）の院代が語るとして、天正の頃に前田利常朝臣（加州の御先祖）の息女で芸州候へ入輿した自昌院と申す御方の建立である旨の伝承**＋同寺に**小幡勘兵衛の木像**を安置する旨。〔**前田利常息女の芸州（広島浅野家）入輿・自昌院建立説の大行院側の伝承記録候補**＝[ORG-035](../org/ORG-035.md)（雑司ヶ谷鬼子母神堂・大行寺の動座史）・[BOOK-144](../books/BOOK-144.md)・[GAZ-085](GAZ-085.md)（府内備考の本浄寺門前・大行寺周辺の町並）と接続する寺側の系譜情報。人名（前田利常・自昌院・小幡勘兵衛）の OCR 崩れ・干支年代（「天正の頃」）の整合は原画像照合を要する（天正〔1573-92〕期の建立とする点は他系統の年代記録と対校課題）。**なお「永禄四年」の年次文言は本OCRには存在しないため、当該年次を使った記述は本書からは作らない（原画像・大系版対校は次回以降の課題）。**〕

## 制限・未解決

- ①本書はくずし字版本で OCR の崩壊が大きい。引用文言（巣鴨の在・柳下何某／山本氏・大行院の院代物語）はすべて原画像照合を要する。②「巣鴨の在」伝承の「上世」の比定・巣鴨側史料（巣鴨村側の書上・地誌）での同伝承の有無は未確認（次回以降の対照課題）。③大行寺／大行院・東陽房の比定と[ORG-035](../org/ORG-035.md)の動座史（鬼子母神堂と大行寺の関係）との整合、自昌院の人物比定（前田利常息女の芸州候入輿者の実名）は要照合。④東京府文献叢書甲集版での採録巻次・底本の系統（寛政6年原本と叢書版の異同）は未確認。⑤雑司ヶ谷村条の全文の精読（水系文言・池・谷名の有無）は本回では「巣鴨の在」・掘出伝承・大行院の3点に絞って実施したため、残余条の再走査を要する。
