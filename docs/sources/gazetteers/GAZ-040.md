# [GAZ-040] 江戸志（近藤義休撰・瀬名貞雄補）— 麁朶橋・掃部橋由来の対校テキスト

- **書誌〔確認〕**: 『江戸志』[5]（近藤義休（狭亭）撰・瀬名貞雄補・写本〔江戸志系は享保〜寛延期の成立とされるが、この写本の年代は目録照合が必要〕）。NDL次世代デジタルライブラリー [book/2563424](https://lab.ndl.go.jp/dl/book/2563424)。**引用はすべてOCR由来（写本OCR）で、文言は原文画像との照合を要する。**
- **掃部橋・古川橋の文言〔確認・[GAZ-039](GAZ-039.md)改正新編江戸志との対校で確定度が上がる文言群〕**: ①「**○掃部橋古河町より水道町へわたすむかし此處に吉岡掃部と云紺屋ある故名とす**」、②「**○古川橋一俗麁朶橋と云そた町より水道町へわたす也**」、③「**○九丁目橋音羽九十目へゆくはし也**」、④「**○大橋俗石切橋と云赤城下へゆく通り高場片町ゟ水道町へわたすむかし此処に石切ある由の名也**」〔**①掃部橋の「吉岡掃部紺屋」由来説が本書にも（ほぼ同文言で）現れること、②古川橋の俗名の字形が本書では「**麁朶**橋」と読めること（OCR上「麁朶橋」と明瞭）＝[GAZ-039](GAZ-039.md)の「麁栗橋」と**字形が分岐する**こと、③「そた町」（惣田町・袖師町等か・要照合）、「音羽九十目」（音羽町九丁目の崩れ）の文言**＝**掃部橋由来・麁朶/麁栗橋の原字形問題（第108回課題②）の対校の中心資料**。江戸志系（享保〜寛延）と改正新編江戸志（天保3）の間で、①吉岡掃部説は共通・②字形は麁朶（本書）→麁栗（[GAZ-039](GAZ-039.md)）に書き分けられている（観察）。どちらの字形が「原形」かは写本の系統（両書の引用関係）と他の江戸志系諸本の照合まで保留（断定しない・要原文照合）**〕〔本書が[GAZ-039](GAZ-039.md)の直接の光源（引き写し元）である可能性があるが、文言の差（「あるゆへ名とすと也」vs「ある故名とす」等）から直接の引用か独立の採訪かは文言の全対照後に判断する〕。
- **位置づけ〔観察〕**: ①「九丁目橋音羽九十目へゆくはし」の文言は、音羽町九丁目への経路を示す橋の説明として[GAZ-039](GAZ-039.md)の「丸丁目橋」と対応し、九丁目橋（音羽九十目＝音羽町九丁目）の接続の確認資料になる。②「高場片町」（[GAZ-039](GAZ-039.md)の「馬場片町」）の字形差も対校対象（小石川の町名の原形の特定に寄与する可能性）。
