# [GAZ-056] 東京市史稿 遊園篇 — 正徳4年護国寺門前の娼婦の記録（音羽岡場所前史）

- **書誌〔確認〕**: 東京市編『東京市史稿』**遊園篇**（昭和4年・1929刊の巻冊。当該巻の篇・冊数〔第三ノ二等〕の特定は目録照合を要する）。NDL次世代デジタルライブラリー [book/1915704](https://lab.ndl.go.jp/dl/book/1915704)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**〔同シリーズの隣接巻 [book/1915739](https://lab.ndl.go.jp/dl/book/1915739) にも遊園篇の目次を確認。**2026-11-16・第133回追記**: 1915739は遊園篇第3（[GAZ-061](GAZ-061.md)）で、「**附記一 音羽玉水簾**」（武江年表の文化9年秋造営・天保の始より廃の転記）の独立節を含む〕
- **正徳4年の護国寺門前の娼婦〔確認・repo初出〕**: 江戸期の遊観所の沿革を記す部分に、**有章院殿御實紀**を引用して「**正德四年（九月）○中略。此日護國寺尊祐遠慮を命ぜらる。これは門前の茶肆ひそかに娼婦を置しによれり**」＝**正徳4年（1714年）、護国寺（音羽町の鎮守たる護国寺）の住持尊祐が、門前の茶屋が密かに娼婦を置いていたため遠慮（謹慎・退去）を命じられた**という公的日記（有章院殿御実紀）由来の記録。続けて「**根津の社門前の地、兼ての令にたがひ、遊女を置しに…祠官伊吹左京昌明に仰下さる**」＝同時期の根津社門前の遊女取締りの並記も。
- **内容メモ**: 本条は**音羽（護国寺門前）の岡場所・遊女の歴史の前史として、享保8年（1723）の遊女取締（旧記拾葉集〔[BOOK-009](../books/BOOK-009.md)・享保8年卯五月の護国寺門前の遊女差置間敷と門前町屋の取払い〕）の9年前、天保13年（1842）の廃止（[BOOK-009](../books/BOOK-009.md)文化天保の頃の遊女・同13年廃止）の128年前にあたる1714年時点で、護国寺門前の茶肆に娼婦が存在し幕府側に把握されていた**ことを示す記録。遊園篇自体は遊観所（寺社の門前・花見の名所）の沿革を扱う篇であり、護国寺は江戸の遊観所の一つとして同篇に収録される。
