# [GAZ-122] 町方書上[69] 湯島町方書上参 — 湯島三組町・棟梁屋鋪の古上水と86間余条の帰属前進

- **書誌〔確認〕**: 『町方書上[69] 湯島町方書上　参』（写・NDL次世代デジタルライブラリー [book/2571550](https://lab.ndl.go.jp/dl/book/2571550)・90コマ）。署名は妻恋町（亥二月）、酒嶋（湯嶋のOCR候補）三組町（亥二月）、湯嶋三組町続拝領屋鋪（玄久二月＝回月のOCR崩れ候補）、湯島棟梁屋鋪（委二月＝同じく崩れ候補）。**引用文言はすべてOCR由来で要原文照合。ページ番号は `2571550_{NNNNNNN}.txt` コマ番号。**
- **三組町条の古上水跡文言＋末広稲荷〔文言候補〕**: 「**古上水跡右は安永九子年中千川上水町目へ相懸り候得共無程御差留に相成候以右形干当時相見へ不申候**」（p46）＝〔**「町目」は「町内」のOCR崩れ候補。条帰属＝署名p56の湯島三組町条（p46直前条＝p14署名の妻恋町条以降）。安永9再掛→無程差止→形なしの定型**〕。直前項に「**正徳末広稲荷…文政五午年中取建町内諸領地主佐野内蔵之助地面内に有之**」＝**末広稲荷（文政5年勧請・地主佐野内蔵之助）の由緒文言**〔稲荷勧請の年代が千川上水差止（天明7）より後であることから、上水跡と社地の重複関係は本条からは読めない。付記レコード〕。
- **三組町続拝領屋鋪条の陰性回答〔陰性記録〕**: 「御殿跡…古上水防川跡馬場無御座候」（p70）＝條項列の中の「古上水跡…無御座候」定型回答〔[GAZ-120](GAZ-120.md)と同じ取調形式の陰性行。署名p71の湯島三組町続拝領屋鋪条。続拝領屋鋪側には上水記憶がないことの記録〕。
- **湯島棟梁屋鋪条＝86間余条の帰属前進〔文言候補・本冊の主要価値〕**: 「**下水石橋壱ケ所右は町内東之方湯島天神門前町に向合之方横町角に有之巾弐間余渡三尺有之… 一千川上水之義は安永九子年中町内往還長八拾六八間五尺往来中程に埋中樋懸け渡し有之中科無所有之候処天明七未年四月中御差上に相成候節取潰し仕無申候但委細之義并元禄之度之義は相分不申候**」（p82）＝〔**①86間余（OCR「壱八拾六八間五尺」＝「八拾六間余五尺」等の崩れ候補・要照合）・往来中程埋中樋・中桝（OCR「中科」崩れ候補）・天明7未年4月差止（「御差上」は「御差止」の崩れ候補）取潰し、②「**元禄之度之義は相分不申候**」の記憶喪失文言、③下水石橋1ヶ所（東之方・湯島天神門前町に向かい合う方の横町角・巾2間余・渡3尺）の寸法レコード。条帰属＝署名p85の湯島棟梁屋鋪条**〕〔**[GAZ-024](GAZ-024.md)（雄山閣刊本・86間余・中桝3ヶ所条）の町帰属がOCR頁境界で未解決だった問題に対し、本条が「86間余」の町条＝湯島棟梁屋鋪候補を写本側から指し示す主要な帰属前進**〔中桝のヶ数（写本側は「中科無所有之」で个数不明・刊本側は3ヶ所）の対校と「棟梁屋鋪」の原字照合は次回課題〕。「棟梁屋鋪」の表記・読み（とうりょうやしき・OCRの可能性含め）は原画像照合まで断定しない〕。
