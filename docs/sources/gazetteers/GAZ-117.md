# [GAZ-117] 古事類苑 政治部29（水利下）— 千川上水道8ヶ所禁制リストと享保7年差止触の絲綸錄引載

- **書誌〔確認〕**: 神宮司庁編『古事類苑』政治部二十九（水利下・NDL次世代デジタルライブラリー [book/897694](https://lab.ndl.go.jp/dl/book/897694)）。「政治部 九十六 下編 水利下」に相当する冊。享保集成絲綸錄・武江年表・新編武藏風土記稿・憲教類典（元文4年玉川上水請負の項）等の引載文言群を収める。**引用文言はすべてOCR由来で要原文照合**。
- **千川上水道8ヶ所の禁制リスト〔文言候補・repo初出・本登録の核心〕**: 「**一 此上水道に於て魚鳥をとり、水をあび、ちりあくたをすて、物をあらふべからざる事、一 上水道の兩ヶ輪三間通、有來下草苗木一切きりとるまじき事、一 兩ヶ輪三間通の內人馬通るまじき事、右條々於相背者、曲事たるべき者也、（月日朱書）一 千川上水道、小石川御殿懸り溜堀、巢鴨溜堀、同吐水門、同築土手、瀧川一里塚、金井久保橋際、板橋御林橋際、長崎築土手、以上八ケ所、同一 神田上水道、金杉橋際、金剛寺坂下、大六天前、小日向村、服部坂下、音羽町橋際、關口村大洗關、同所曾我周防守屋敷前高田橋際下、落合村、橋際戶塚村橋際、以上十ヶ所、定此上水道において、魚鳥をとり、水をあび、ちりあくたを捨る輩あらば、曲事たるべき者也〔享保集成絲綸錄〕**」＝**①上水道での魚鳥捕獲・水浴・塵芥捨て・洗浄の禁止、両ヶ輪三間通の下草苗木の刈取禁止・人馬通行禁止の3ヶ条の御触書、②その適用場所として千川上水道の8ヶ所（小石川御殿懸り溜堀・巣鴨溜堀・同吐水門・同築土手・瀧川一里塚・金井久保橋際・板橋御林橋際・長崎築土手）と神田上水道の10ヶ所（金杉橋際〜戸塚村橋際）が列挙されたリスト**。〔**①千川上水道の管理ポイント8ヶ所の一覧はrepo初出文言（「小石川御殿懸り溜堀」「金井久保橋際」等の地名・施設名文字列の組は既存走査で未出）。②千川上水道と神田上水道が同一の禁制触で並記された編成で、両上水管理体制の並行性を示す。③「月日朱書」＝原本の日付が朱書であったことの注記（絲綸錄の体裁）。④時期は享保集成絲綸錄=享保年間（享保7年廃止前の千川上水現役期の触と読めるが、廃止（享保7年8〜10月）前後のどちらかは日付が朱書不能のため本資料では確定しない）**〕。
- **享保7年8月の千川上水差止触〔文言候補・憲教類典対校〕**: 「**享保七寅年八月 千川上水之儀、中興よりかヽり候事に候故、自今相止候間、其段向々江可被申逹候、來ル十月より上水取不申筈に候間、可被得其意候、八月〔享保集成絲綸錄〕**」＝**享保7寅年8月の千川上水差止の触（中興よりかヽり候事＝再興されて運用されていた事由による、自今相止・來ル十月より上水取不申の文言）**。〔**[GOV-464](../../gov/GOV-464.md)（憲教類典58）の享保7年8月18日・19日触「**中奥ゟかゝり候事**」と同内容の触と読め、絲綸錄側の判読は「**中興**」＝**憲教類典の「中奥」判読より「中興（再興）」判読を強める対校証拠**（「来ル十月より上水取不申筈」の文言も一致）。原字は「中興」かどうかの確定は原画像照合まで保留するが、千川上水の享保7年差止の理由付け文言が絲綸錄のレベルでも確認された意義は大きい**〕。
- **青山・三田両上水・本所上水の同時停止文言群〔文言候補・同時性の裏付け〕**: 「**享保七寅年九月 靑山三田兩所上水之儀、中興かゝり候事に候故、自今相止候間、其段向々な可被申達候、來ル十月より上水取不申筈に候條、可被得其意候、以上、九月**」＋「**享保七寅年九月 本所上水之儀、中興よりかヽり候儀に候、殊水も不參候故、自今は彌相止候間、可被得其意候。以上、九月**」＝**享保7年9月の青山三田両上水・本所上水の同じく「中興（再興）」を事由とする相止・來ル十月より上水取不申の文言**。〔**千川（8月）→青山三田・本所（9月）→十月実施という享保7年上水一斉差止の月次の連鎖の絲綸錄レベル側裏付け（憲教類典58・武江年表・GOV-171・BOOK-121の各系統と一致）**〕。
- **武江年表享保7年条の引載〔確認・BOOK-157の本文側原典の所在〕**: 「**〔武江年表〕享保七年壬寅十月、千川上水靑山三田の上水を止らる、安永九年のころ、千川上水再度起りしが、水(掛)り宜しざりしかば、天明六年にいたり止む**」＝**①享保7年10月の千川・青山・三田の上水停止、②安永9年再興→水掛り宜しからざり→天明6年停止の年表本文。〔この文言自体は江戸叢書活字版（[BOOK-157](../books/BOOK-157.md)＝第134回登録済み）の本文と同一でrepo初出ではないが、①古事類苑が引載している＝編纂時に武江年表原本既読の二次的確認、②OCR判読の語順差（江戸叢書版「宜しからざりしかば、千川上水再度起りしが」vs本OCR「再度起りしが、水掛り宜しざりしかば」）＝原本の語順・「水掛り」の有無の原照合課題、として記録**〕。
- **周辺文言〔記録〕**: 同冊の水利下には新編武藏風土記稿の青山上水跡（萬治三年造立・享保七年停止）・三田上水跡（玉川ノ分水・白金御殿ヘ掛リ・品川領村々ノ用水ニ賜フ）・憲教類典の元文4年8月玉川上水請負人文言（玉川庄右衞門・〓右衞門の相滞りによる閉門・町奉行支配への変更）・寛延2年神田上水沿路費給割合（大洗堰〜三河町一丁目間）等、千川上水周辺の上水行政文言が集成されている（武蔵風土記稿の青山上水・三田上水は主題外のため要点のみの記録に留める）。

## 制限・未解決

- ①本書は事項編纂型の類書で、引載文言の元史料（享保集成絲綸錄の何巻何頁か）の特定は未了で、絲綸錄原本（東京大学史料編纂所データベース等）の直接確認が今後の課題。②8ヶ所リストの地名判読（「金井久保橋」＝金井窓/金井窪橋の判読候補・「瀧川一里塚」の比定・「板橋御林橋」の位置）は原照合を要し、千川上水の流路復元への本格的な反映はそこまで保留。③「月日朱書」の触の年代が享保7年以前か以後か（廃止後の残構造管理か現役期の規制か）は確定できない（廃止後も管理が続いた可能性を排除しない）。④OCRの「魚鳥」（魚鳩の誤判読候補・原文照合要）・「水(掛)り」の括弧内補いは筆者による判読補いであり原本表記ではない。
