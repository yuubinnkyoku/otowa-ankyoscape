# [GAZ-041] 外神田町方書上 [73] — 神田仲町の千川上水条と「発願人宇田川長十郎」の封子文言

- **書誌〔確認〕**: 御府内備考編纂の基礎資料である**町方書上**の一本（[73] 外神田町方書上 一・神田仲町三町目等の書上）。NDL次世代デジタルライブラリー [book/2571554](https://lab.ndl.go.jp/dl/book/2571554)。文政10年（1827）丁亥の地誌御調書上〔年判は要照合〕。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **神田区間の千川上水条＝差止の日付が日レベル〔確認・repo初出の文言〕**: 神田仲町の書上に——「**一千川上水之儀は安永九子年十月廿七日牧野大隅守様御番所御掛にて上水掛渡之儀被仰付候儀にて町内藁店通東之方に枡壱ケ所中通西之方二枡壱ヶ所有之凡五拾間程中樋南北通り中程ニ枡壱ケ所同所北之方ニ同断壱ケ所小樋ニ向凡七拾弐間程掛渡シ有之候処天明七未年四月十三日御差止ニ相成候旨被今度通達有之其節取潰し埋立申候但元禄之度千川上水掛渡之儀相分不申候**」〔**①安永9子年（1780）10月27日、牧野大隅守様御番所御掛かりで「上水掛渡」が仰付けられたこと（＝市中樋管の掛渡開始の年月日）、②神田仲町内の設備＝藁店通東に枡1・中通西に枡1・凡50間の中樋・南北通中程に枡1・北に枡1・小樋に向け凡72間の掛渡し、③**天明7未年（1787）4月13日御差止**の通達があったこと、④その節「取潰し埋立」をしたこと、⑤元禄の度の千川上水の掛渡は相分からないこと**〕〔**③の「四月十三日」は[GAZ-024](GAZ-024.md)（湯島側・「四月中」）・[GAZ-043](GAZ-043.md)（[78]・四月十三日）を併せ、**市中樋管の差止通達が天明7年4月13日**であることを日レベルで示す最初の群れ（湯島側の写本〔[GAZ-045](GAZ-045.md)〕は「四月中」のまま＝町方ごとに通達日とその記憶の粒度が異なる可能性を残す）。[GOV-215](../gov/GOV-215.md)〜[GOV-218](../gov/GOV-218.md)の上水本体の差止（天明6年8月出浅取立→閏10月差止）の翌年4月に市中樋管の物理的取潰しが行われた過程（9月出浅止→閏10月差止→翌4月13日市中差止通達→取潰埋立）を町方側の文言で裏付ける**。①の牧野大隅守（町奉行）は駒込側の御見分・水銭上納（[GOV-224](../gov/GOV-224.md)）と同じ奉行**＝千川上水再興の市中給水を一貫して牧野大隅守の番所が掌ったことを示す〕。
- **「千川上水発願人宇田川長十郎」の封子文言〔確認・repo初出の再興発願人の人名〕**: 同書上の稲荷の項に——「**一稲荷一社 同口壱間奥行同断 但土蔵地守又右衛門請負地之内…封子長八寸六分竪四寸九分巾三寸九分外黒塗内金箔置**後に朱千川上水発願人宇田川長十郎起原と記有之**勧請年月不相分 水野隼人正様御上ケ屋敷跡ニ有之候社ニ御座候 尤都稲荷と相当申候**」〔**①稲荷の封子（長8寸6分・竪4寸9分・巾3寸9分・外黒塗内金箔）の後（朱書か・要照合）に「**千川上水発願人 宇田川長十郎 起原**」と記があったこと、②勧請年月は不相分、③社は水野隼人正様御上げ屋敷跡にある「都稲荷」と呼ぶ社であること**＝**千川上水（安永9年再興）の発願人の名前＝宇田川長十郎を伝える唯一級の文言（repo初出の人物名）**。町方側の稲荷の封子という実物準拠の記録で、再興の請負人（明和6年願人3人〔[GOV-224](../gov/GOV-224.md)・[GOV-225](../gov/GOV-225.md)〕）と別に「発願人」の名を神田側が伝えていたことになる（発願・願出・請負の役割分担の解明は今後の課題。宇田川長十郎の素性は本文言からは不明）〕。
