# [GAZ-080] 御府内場末往還其外沿革圖書 拾九利（嘉永5年9月調）— 関口村の町並化年代層と大洗堰下川筋の水管理施設

- **書誌〔確認〕**: 『御府内場末往還其外沿革圖書 拾九利』（写・嘉永五子年九月調・NDL次世代デジタルライブラリー [book/2587242](https://lab.ndl.go.jp/dl/book/2587242)）。巻頭書名文言（OCR候補）「嘉永五子年九月調」「御府内場末往還沿革図書拾九利五八ノ十九」「早稲田村小日向村中里村高田村下戸塚村一円之絵図壱枚四枚之内利」「沿革図書拾九四冊之内利」＝**嘉永5年（1852）9月調・牛込御門外側（早稲田村・小日向村・中里村・高田村・下戸塚村・関口村一円）を収録する沿革図書の第19部（拾九）**。repo既登録の御府内往還其外沿革図書シリーズ（[GAZ-012](GAZ-012.md)の同定記録・[GAZ-054](GAZ-054.md)の貮拾利=嘉永7年調・[GOV-347](../gov/GOV-347.md)の十一・[GOV-351](../gov/GOV-351.md)の昭和15年活字版解題）の**未登録巻・今回の登録**。**引用文言はすべてOCR由来で要原文照合**。
- **関口村の町並化年代層〔確認・文言候補・repo初出の年代枠〕**: 関口村の百姓町屋→町並地（町名化）の沿革が複数の年代層で記される。①「**貞享二丑年頃北手関口村百姓町屋四ヶ所当時町名関口水道町町並地ニ成候由**」＋「**関口水道町年貢町屋弐ヶ所は関口村百姓町屋に候処貞享二丑年頃右百姓町屋弐ヶ所当時町名町並地二成候由**」＝**貞享2年（1685）頃に関口村百姓町屋（複数ヶ所）が「関口水道町」として町並地化**。②「**元禄十丑年中東手關口村百姓地護国寺領ニ成其頃ゟ百姓町屋ニ而地形如当時ニ有之由当所名主共申立**」＝**元禄10年（1697）東手関口村百姓地の護国寺領化**（名主の申立による由緒記録）。③「**其後正徳三己年中右關口村護国寺領百姓町屋町並地当所町名に成候由**」＝**正徳3年（1713）護国寺領百姓町屋の町名化**。④「**享保五子年頃北手関口村百姓町屋弐ヶ所**」（町並地化の文脈・直後文言はOCR列崩れ）＝享保5年（1720）頃層。⑤「**元文二己年頃北手関口村百姓町屋当時町名関口駒井町町並地ニ成候由**」＝**元文2年（1737）関口駒井町の町並地化**。〔**関口水道町（1685年層）→護国寺領化（1697）→町名化（1713）→享保5年層→関口駒井町（1737）という町並化の年代枠が、名主申立由来の由緒として一帳にまとめて現れる＝repo初出の年代層候補**。「由」「候」の伝聞形であり、各年代の実務文書による裏付けまでは本帳では確認できない。〕
- **大洗堰下川筋の水管理施設〔確認・文言候補・repo初出候補〕**: 井伊掃部頭（彦根藩井伊家）抱屋敷一円の四至記載に「**北手関口村百姓地同所之内水番屋構并水当人持地神田上水堀筋并上小咄大洗堰下川筋等右一円之地所**」＝**関口村百姓地の内に「水番屋構」および「水当人持地」が存在し、神田上水堀筋・大洗堰下川筋に沿う一円として図上に区分・記載**される。〔**大洗堰（関口大洗堰。神田上水の取入堰）下流の川筋沿いに水番屋（構）と水当人（水番人）の持地が嘉永5年調絵図に描かれた＝大洗堰下川筋（江戸川下流部）の水管理施設の持地記録としてrepo初出候補**。同帳内に関口水道町の「**年貢町屋弐ヶ所水番人持地**」の文言もあり（「当時東北之方谷帯刀守山は十郎抱屋敷関口水道町年貢町屋弐ヶ所水番人持地」）、水番人の持地が関口水道町側にも記録される。水番屋・水当人の具体的な配置（堰直下か・樋か）は本帳の縮尺・OCRでは確定できない（要原画像照合）。「上小咄」はOCR崩れ候補（上ヶ地等の要照合）。〕
- **蓮華寺境内幸神社地〔確認・文言候補〕**: 関口村之内東南之方（江戸川幷神田上水堀筋之内蓮華寺境内）の条に「**当時東手蓮華寺境内幸神社地**…」、その沿革冒頭に「**延宝年中は東手蓮華寺境内幸神社地関口村百姓也宝永四亥年中此百姓地秋元但馬守抱屋敷二成候由**」＝**蓮華寺境内の幸神社地が延宝年中（1673〜81）の図上にも描かれ、隣接百姓地が宝永4年（1707）秋元但馬守抱屋敷化**。図の年次対照列にも「幸神」の注記が延宝〜文政5年（1822）層にわたり反復して現れる。〔**[GAZ-076](GAZ-076.md)幸神宮（文政10年書上・現在の胸突坂上の幸神宮）の延宝期までさかのぼる図上連続記録**。宝永4年以降の「幸神」注記の連続から、社地は抱屋敷化した周辺地に囲まれて残存したと読めるが、本帳では社殿自体の動きは記されず、嘉永5年から文政10年書上までの間の変化は断定しない。〕
- **下戸塚村神明社の椿山引移伝承〔確認・文言候補・repo初出候補〕**: 下戸塚村の地所書上に「**同所之内に当時有之神明社地此社地往古当所に有之寛文年中戸塚村椿山江引移地所は其後天和年中又当所え立戻候由に候得共事実不詳候間治革信図除之**」（「治革信」は「沿革図」のOCR崩れ候補）＝**下戸塚村の神明社地について、往古は当所にあったが寛文年中（1661〜73）に戸塚村椿山へ引移、天和年中（1681〜84）に再び当所へ立ち戻った旨の伝承が記される**。〔**「戸塚村椿山」の地名と、社の引移・復帰の伝承記録＝repo初出候補**。①本帳自身が「事実不詳候間沿革図除之」と明記し、絵図からは除外した由緒として扱っている（伝承と図記録の区別の好例）。②[GAZ-048](GAZ-048.md)関口町椿山（現在の椿山・椿山荘庭院方面）との同定、および[GAZ-076](GAZ-076.md)貞享4年勧請の神明宮（関口台西坂上塚山）との関係は本文だけでは判別できず、一切断定しない。③社名の表記も「神明社」「神明社地」で、嘉永5年時点の下戸塚村の鎮守がこの神明社かは本帳では確定できない。〕
- **掃部橋際の拝領町屋の年代層〔確認・文言候補〕**: 「**元禄八亥年頃北手掃部橋際小日向西古川町百姓町屋之内奥女中駒井屋敷此屋敷拝領町屋ニ候哉不詳**」＋「**宝永四亥年十二月駒井上ケ地**」＋「**享保八卯年中北手掃部橋際小日向西古川町之内中程…拝領町屋二成候由**」＝**掃部橋（掃部殿橋。江戸川に架かる橋）際の小日向西古川町の百姓町屋が、元禄8年（1695）奥女中駒井屋敷を経て宝永4年（1707）上ケ地・享保8年（1723）拝領町屋化**する沿革。〔[docs/四河川の橋名・橋跡調査.md](../../四河川の橋名・橋跡調査.md)の掃部橋条の橋際町屋の年代層資料。〕
- **江戸川大橋・音羽九丁目橋・目白坂の通道敷文言〔確認・文言候補〕**: 関口村之内東北之方の四至に「**桜木町前ゟ関口台町迄目白坂通道敷**」、関口水道町側に「**関口水道町脇ゟ桜木町迄江戸川橋并音羽町九丁目橋通道敷**」、中里村側に「**牛込水道町前江戸川大橋通道敷**」「**北之方江戸川大橋ゟ掃部様迄右川筋限向寄道敷**」＝**嘉永5年調絵図に「江戸川大橋」（橋名）・「音羽町九丁目橋」（[GOV-349](../gov/GOV-349.md)音羽町九町目橋の別表記候補）・「目白坂」の通道敷が境界文言として現れる**。〔江戸川の橋の嘉永期の呼称記録。大橋と掃部橋の関係（同一橋の別称か別橋か）は本帳では確定できない。〕
- **そのほかの用水・社寺文言〔確認・文言候補〕**: ①「**中里村之内并長寿院後用水堀ゟ小日向西古川町後江戸川迄右用水堀**」＝中里村・長寿院後方から小日向西古川町後を経て江戸川に達する用水堀の記録。②「**井伊掃部頭抱屋敷前ゟ下戸塚村之内野道限東北之方神田上水堀筋并同所大洗樋下川筋迄**」（大洗樋の下川筋文言）。③「**下戸塚村水稲荷社地**」。④「**早稲田村之内元赤城明神社也**」（早稲田の赤城明神の移転前社地）。⑤「**済松寺領牛込原町**」「済松寺領町屋」（済松寺領の町屋化）。⑥関口村の水戸殿・細川越中守等の抱屋敷群、天保14卯年（1843）の関口村名主・百姓の文言断片。〔いずれもOCR列崩れがあり、細部は要原文照合。〕
- **陰性〔確認〕**: 本冊（第19部・拾九利）のOCR全文で「弦巻」0件・「水窪」0件・「雑司」0件・「白堀」0件・「千川」0件＝収録は牛込御門外南側（神田上水堀筋・江戸川の南岸側）で、雑司ヶ谷・音羽町側（第20部・貮拾利=[GAZ-054](GAZ-054.md)の対象）は含まれない。

## 制限・未解決

- ①写本でOCRの崩れが激しく（特に年次対照列・人名の列崩れ）、引用文言はすべて原画像照合を要する。「崩家」「上小咄」「治革信図」等はOCR崩れ候補。②町並化の各年代（貞享2・元禄10・正徳3・享保5・元文2）は名主申立由来の由緒記録であり、実務文書（町名免許・検地等）による裏付けは別途必要。③水番屋構・水当人持地の位置は絵図上の区分文言のみで、配置の具体化は原画像の読図待ち。④神明社の椿山引移伝承は本帳自身が「事実不詳」とする由緒であり、史実として採らない（伝承資料としてのみ扱う）。⑤第19部（本冊・嘉永5年9月調）と第20部（[GAZ-054](GAZ-054.md)貮拾利・嘉永7年10月調）は対象地（関口村・高田村）が一部重複し、調製年も2年差であることから対校が有効だが、本冊側の対応文言の同定は今後の原画像照合を待つ。
