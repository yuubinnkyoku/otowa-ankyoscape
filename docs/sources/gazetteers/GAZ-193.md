# [GAZ-193] 東京市史稿 市街篇 第二十一 — 神田旅籠町の堀井の安永9・天明3年の渡し文言〔第322回〕

- **書誌〔確認〕**: 東京市役所編『東京市史稿』**市街篇 第二十一**（昭和9年〔1934〕刊・次世代デジタルライブラリー [book/3450801](https://lab.ndl.go.jp/dl/book/3450801)）。享保9〜11年（1724〜26）の市街異動・屋鋪受授（昌平橋外堀井・筋違橋外・昌平橋外揚場・神田仲町等・頁744〜748と読める）を収める。引用文言はOCR由来（表組崩壊著しい）で要原文照合。
- **享保11丙午年2月18日の預かり証文の採録〔文言候補・対校本〕**: 「**昌平橋外明地内南之方ニ有之い堀井、拙者共町中爲用水御預り被遊被下い樣奉願い…則御繪圖を以願之通御預ヶ被下…右井鎰壹本御渡被成請取申い。以上。享保十一丙午年二月十八日 神田旅籠町壱丁目・貳丁目(町人月行事…)右立合相改預之。朽木丹後守內吉澤藤七郞・矢部伊右衞門・鈴木伊勢守(內)…**」＝[GAZ-130](GAZ-130.md)（御府内沿革図書・外神田五上側の願書文言＝享保11年正月23日願・2月18日預かり・井戸の鎰（鍵）受け取り）と同一事件の**証文言本文の体裁**での市街篇側採録。証文側の立会人名（吉澤藤七郎・矢部伊右衞門・鈴木伊勢守内役人外など）は [GAZ-130](GAZ-130.md) には採録されておらず、立合与力の編成の初出の指標（[GOV-352](../gov/GOV-352.md) の世界の牧野大隅守より前段の朽木丹後守＝御普請御奉行の与力側の実名）。
- **安永9年・天明3年の後日注記〔文言候補・repo初出の新文言・本冊の主要価値〕**: 同証文の末尾（または欄外）に後日の処理の注記が読める——「**…成い節障いハゝ、一切水汲申間鋪(敷?)旨被仰渡奉畏い。爲後日仍如件。…天明三卯年千川上水請負人に引渡こ相成い。右錠鍵加東屋甚五郞に相渡、先預り之者不殘消印濟。安永九庚子年五月九日…安永九子年五月九日 旅籠町之者共(よ)り請負人加東屋甚五郞に渡ス**」＝**①安永9庚子年（1780）5月9日に神田旅籠町の者共が堀井を請負人加東屋甚五郎に渡したこと（5月9日の日次・干支つき＝repo初出。[GOV-441](../gov/GOV-441.md)「安永九子年五月 深川永堀町 加藤屋甚五郎 冥加金上納 年季清負井戸に成」と月次で整合）、②天明3卯年（1783）に千川上水請負人に引渡となったこと（**[GOV-441](../gov/GOV-441.md)の「天明四辰年（1784）五月 千川上水請負人引請井戸に成候節 町方持」との年次対立＝天明3卯年／天明4辰年。いずれもOCR由来で原画像照合必須）、③引渡の際の錠鍵（享保11年の「井鎰」の系譜）が加東屋甚五郎に相渡され、先の預かり者の消印が済まされたことの運用細部**。〔年次対立の扱い: [GOV-441](../gov/GOV-441.md)（拝領者側の沿革図書）と本冊（証文の編纂採録）で天明3卯／天明4辰が食い違う。引渡処理の年度またぎ（請負願出・相願〔[GOV-352](../gov/GOV-352.md)の「同三(卯)午年相願」〕から実施・「引請」完了までの差）として両立し得るため、矛盾と断定せず対校表記にとどめる。〕
- **「一切水汲申間敷」の文言候補〔文言候補・要原画像照合〕**: 後日注記の一部として「**成い節障いハゝ、一切水汲申間鋪(敷?)旨被仰渡奉畏い**」の断片が読める。上水の再興・断水のどちらかの「節」に井戸の水汲の可否を条件として仰渡された趣旨か、文言の接続がOCR崩壊で切れているため、趣旨の確定は原画像照合まで保留する（享保11年預かり文言と安永9年渡しの間にどこかに属する文言候補）。
- **昌平橋外揚場の拝借文言〔文言候補・repo初出候補〕**: 「**土屋小左衞門拜借揚場。市人ニ貸附ス。昌平橋の北詰也。此所淺草門跡の舊地也。其後松平加賀守殿やしきと成**」「**昌平橋外御堀端 當分拜借揚場地所 享保十一丙午年二月四日…(於昌平橋外揚場奉願上い處、當分拜借被仰付…)御繪圖之面御定杭之通相違**」＝**昌平橋北詰（旧浅草門跡地）の揚場が享保11丙午年（1726）2月4日に当分拝借として下げ置かれた文言**（土屋小左衞門の拝借・市人への貸付運用・御定杭つき）。[GOV-352](../gov/GOV-352.md)（昌平橋外明地際の堀井・安永7年以降の水汲請負）と [GAZ-130](GAZ-130.md)（昌平橋外の芝地井戸＝享保7年断水後の旅籠町への御預かり）の「昌平橋外」の明地一帯の享保11年時点の土地利用（堀井の預かり2月18日・揚場の拝借2月4日が同じ月に並ぶ）を示す座標の補強。併せて神田仲町壱丁目の筋違橋外7,968坪の町割（享保9〜11年・水野隼人・本多唐之助上ケ屋敷→借地町屋）の文言は [GAZ-041](GAZ-041.md) 系と重複するため採録しない（第317回の判定を踏襲）。

## 制限・未解決

- ①後日注記の文言は証文の本文・欄外注記・（別文書の）覚のいずれの体裁かがOCR列崩壊で判別不能。「安永九庚子年五月九日(木)」の「(木)」は頁拾いの数字等の混入の可能性が高く原文照合で切り分ける。②「天明三卯年」対「天明四辰年五月」の年次対立は原画像照合で両確認テキストの確定後に扱いを確定する。③「先預り之者不殘消印濟」の「先預り之者」が旅籠町側（享保11年の御預かり以来の町方）か加東屋以前の請負者かの特定は本文のみからはできない。④享保11年の立合人名の列崩壊による脱落（⻑屋・列名の続き）は原画像照合必須。⑤昌平橋外揚場の土屋小左衞門の拝借文言の前後関係（浅草門跡旧地→松平加賀守屋敷→揚場の順序）はOCRの並び通りとは限らない。
