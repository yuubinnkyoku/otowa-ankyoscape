# [GAZ-144] 町方書上[62] 四谷参 — 坂町の桜川（榎川対立の元資料側）・御箪笥町石枡の対校

- **書誌〔確認〕**: 『[62] 四谷町方書上　参』（写・NDL次世代デジタルライブラリー [book/2571543](https://lab.ndl.go.jp/dl/book/2571543)）。文政10亥年（1827）。坂町条（p10-34）・四ッ谷御箪笥町条（p66-70）ほか。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571543_{NNNNNNN}.txt` コマ番号。** 本冊の坂町条・御箪笥町条は[GAZ-112](GAZ-112.md)（御府内備考巻61-63四谷・NDL 2553680）の同名の条にほぼ対応する文言を持ち、**御府内備考四谷巻の元資料側（町方書上）の直接確認として登録する**（新規採録の中心は①桜川直接呼称のwitness②石枡の修復年代の対立③深サ文言）。
- **坂町条の桜川横切大下水〔文言候補・川名対立の元資料側witness〕（p25）**: 「**一横切大下水 但町内坂下町家中程往還二有之 泊出(=深サ?候補・OCR崩壊)火五寸程 右ハ桜川lrt唱 南lrt北之方江相流申候 右水上 四谷大木戸 内藤大和守様御下屋敷内lrt流出候由 委細同所塩町三丁目lrt申上候**」＝**坂町の坂下・町家中程の往還にある横切の大下水（深さ5寸程候補）＝「桜川」と唱え、南から北へ流れる。水上（源）は四谷大木戸の内藤大和守様御下屋敷内から流れ出た由。委細は塩町三丁目（の書上）に申上候**。〔**①[GAZ-112](GAZ-112.md)坂町条の「下水巾五尺余…尤横切等(?)御水ニ而**榎川**と唱」に対し、元資料側（町方書上[62]）の同じ位置の水は明瞭に「**桜川**」と唱える＝**榎川（御府内備考・OCR要照合）vs 桜川（町方書上・OCR要照合）の川名対立が両書の間に成立**。両書が同系統の文章を共有すると推定される中で元資料側が「桜川」と読めることは、御府内備考側「榎川」が（a)OCR崩壊・(b)後代の別呼称・(c)原文ママの可能性のうち(a)の重みを上げる材料候補だが、**双方OCR崩壊を含むため原画像照合まで対立の決着はしない**（対照表の榎川行の評価材料として記録）**、②「委細同所塩町三丁目lrt申上候」＝[GAZ-141](GAZ-141.md)塩町三丁目条の桜川文言への相互参照文言（御府内備考側〔GAZ-112〕と同型の委譲構造の元資料側確認）＝桜川情報の「塩町三丁目条側に委ねる」書上の分業構造の実在を示す一次文言、③南→北の流向・内藤大和守様御下屋敷起源文言は[GAZ-112]と一致（ただし[GAZ-110](GAZ-110.md)修行寺門前条の「田安様」起源説との対立は残る）、④「泊出火五寸程」＝深サ5寸程候補の断面文言は対校可能な新出の観察文言候補**〕。
- **坂町の桜川石橋・稲垣対馬守様境大下水の元資料側対校〔文言候補〕（p25-26）**: ①「**一石橋壱ケ所 但長サ七尺 巾壱丈四尺五寸 右ハ坂下町屋中程 横切大下水二掛渡有之 掛始年代相分不申 尤町内持ニ無御座候 修復掛直等之節ハ 尾州様御持二而 都而間御屋形様二而 御修復等有之候**」＝**桜川の石橋（長7尺・巾1丈4尺5寸・掛始年代不知・町内持でなく尾州様〔尾張徳川家〕御持・修復掛替は御屋形様御修復）＝[GAZ-112](GAZ-112.md)坂町条①の石橋文言（長7尺巾壱丈4尺余・尾州様御持御修繕）と寸法・帰属が一致する元資料側対校**。②「**一町内北側 稲垣対馬守様御屋敷境ニ 幅三尺程之大下水有之 水上ハ市谷七軒町通横切下水lrt 右下水下水え流込 夫lrt裏通り地境を通 町内坂下桜川江流落申候**」＝**稲垣対馬守様屋敷境の大下水（幅3尺・水源＝市谷七軒町通横切下水）→裏通りの地境→坂下桜川に流落＝[GAZ-112](GAZ-112.md)③の下水文言（稲垣対馬守様屋敷境の下水巾3尺→町内坂下桜川江流落）の元資料側対校＋市谷七軒町系水源文言**。〔**本2条は[GAZ-112]で既登録の内容の元資料側確認が主であり、新情報は「掛始年代相分不申」「市谷七軒町通横切下水lrt水源」の細部**。稲垣対馬守様＝[GAZ-141](GAZ-141.md)塩町壱丁目条の稲垣対馬様頭取組合持石橋と同じ武家の水路・橋の関与例**〕。
- **坂町の自身番屋＝大下水石橋際の位置文言〔文言候補〕（p13-15）**: 「**一自身番屋之義ハ 町内坂下 大下水石橋際ニ…**」＝**自身番屋が町内坂下の大下水石橋際にある**＝番屋の書上で石橋際の位置がアンカーになる例。〔番屋の願済年代等の文言はOCR要照合〕。
- **御箪笥町条の石枡2ヶ所文言〔文言候補・修復年代の対立〕（p67）**: 「**一町内中程 横町通ニ 別紙絵図面之通 石枡弐ヶ所 いづれにも七尺四方程 地中ニ埋木蓋ニ而地面テ限りニ御座候 弐拾ケ年程以前 御修復有之 御普請方御掛二而 町内持ニハ無之候得共 御上水御堀割之義ハ 承応之度 御起立之由ニ御座候**」＝**町内中程の横町通りに石枡2ヶ所（いずれも7尺4方候補・地中に埋め・木蓋で地面を限る）。20年程以前に御修復があり、御普請方御掛かりで町内持ではない。御上水（玉川上水）御堀割は承応の度の御起立の由**。〔**①[GAZ-112](GAZ-112.md)御箪笥町条（南・北各1ヶ所・7尺四方程・地中埋・木蓋・「10ヶ年程前」の御修復・御普請方御持分・承応之度御起立）に対し、本冊（元資料側）は修復年代を「**弐拾ケ年程以前**」とする＝**修復の時点（「10ヶ年程前」vs「20年程前」）の対立**（御府内備考の書写時点とのずれ・判読のいずれかで、寛政〜文化期の御修復の実年代を絞る対校材料候補。原画像照合前提）**、②木蓋の石枡は塞がれた石枡の用途（分水・計量・掃除用昇降口候補）は本冊文言からは断定しない、③「御上水御堀割＝承応之度御起立」＝[GAZ-141](GAZ-141.md)塩町三丁目条「承応年中」「承応二癸巳年」・[GAZ-112]伝馬町壱丁目・湯屋横町・御箪笥町条と並ぶ**四谷側の上水起立年代文言の元資料側witness（[GAZ-112]既登録の文言の直接確認）**。④寛延期の江戸川・神田川49町川浚普請の対象町群（[GOV-373](../gov/GOV-373.md)）に御箪笥町が含まれることは、本町の水路の江戸川系統（=石樋分水系と横町通りの下水群）の江戸川系集水域としての位置づけの対校材料**〕。
