# [GAZ-005] 1895年の谷端川水車設立願

- 豊島区史年表（ADEAC）「谷端川」検索。
- https://adeac.jp/toshima-history/detailed-search?mode=timeline&word=%E8%B0%B7%E7%AB%AF%E5%B7%9D
- 1895年4月23日、小石川区掃除町23の宇野伊兵衛が巣鴨村大字巣鴨字新田928の谷端川に水車新設を願い出たが不許可となった記録。
