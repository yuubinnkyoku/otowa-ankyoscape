# [GAZ-055] 東京市史稿 市街篇第一（1914）— 小石川＝千川通称・上流谷端川呼称の市史稿河川総説

- **書誌〔確認〕**: 東京市編『東京市史稿』**市街篇第一**（大正3年・1914）。NDL次世代デジタルライブラリー [book/3450780](https://lab.ndl.go.jp/dl/book/3450780)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**〔市街篇シリーズは[GAZ-016](GAZ-016.md)（市街篇12・1931）・[GAZ-053](GAZ-053.md)（市街篇15・1932）が既登録。本冊はその第1巻〕
- **小石川＝今千川の通称・上流谷端川呼称〔確認・repo初出の文言〕**: 河川総説（北方岡脈と中央岡脈の分界川の項）に「**源 小石川ハ、今千川ヲ通稱トス。上流ヲ谷端川ト呼ビ、北豐島郡（長崎村）ヨリ出デ、（丸山町）小石川區ニ至リテ市內ニ入リ…小石川（柳町）ニ於テ神田川ニ會ス**」〔カッコ内はOCR列崩れ部分の推定復元〕＝**①「小石川」の現称が「千川」であること、②上流の呼称が「谷端川」であること、③源を北豊島郡（長崎村）に発すること、④小石川区柳町付近で神田川に会すること**を一枚の文言で示す東京市史稿レベルの公式記録。
- **藍染川の流路〔確認・repo初出の市史稿側文言〕**: 同総説に「**別ニ藍染川有リ。上流ヲ谷戶川ト云ヒ、又一ニ堺川トモ稱ス。武藏國北豐島郡巢鴨町上駒込ニ發シ、駒込動坂町ヨリ市內ニ入リ、南東ニ流レ…東折シテ不忍池一丁目（?）線ノ餘水ヲ併セ、忍川ト爲リ、三味線堀（千川?）…市內ニ合シ、曲折シテ隅田川ニ入ル**」＝**藍染川の上流呼称（谷戸川・堺川）・発源地（巣鴨町上駒込）・不忍池を併せて忍川となる流路**の市史稿記録〔OCR混線が著しく、固有名の復元（忍川・三味線堀等）は原画像照合まで保留〕。
- **内容メモ**: 本冊の四河川関係は河川総説の2条（小石川＝千川・藍染川）が主。市街篇第1巻は東京市の地誌総説にあたり、後の市街篇諸巻（千川上水鑿通条〔GAZ-016〕等）の体裁の源流。
