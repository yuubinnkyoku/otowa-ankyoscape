- **塩町弐丁目条の横切下水群〔文言候補〕（p37）**: 「**幅六尺二而西ゟ東江相流申候 委細同所塩町三十目(=壱丁目・OCR)ゟ申上候通二御座候 但右万年石樋ゟ分水井 町内二四ツ有之候**」＋「**一町北側里俗湯屋横町往還二古来ゟ有来候横切下水 中壱尺五寸左右は石垣二而石堂潰致し有之 西ゟ東江相流…一同側里俗浄運寺横町往還二古来ゟ有来候横切箱下水 巾壱尺木芭蕉(=箱蓋候補・OCR)ニ而西ゟ東え流落**」＝**塩町弐丁目側から見た大下水（幅6尺・相互参照）＋万年石樋からの分水井4ヶ所（町内）＋湯屋横町・浄運寺横町の往還横切下水（巾1尺5寸石垣・巾1尺箱下水）**。〔横切下水の由来（石樋分水の排水系か）は本冊文言からは確定しない〕。
- **塩町三丁目条の万年石樋の定量文言〔文言候補〕（p60）**: 「**一玉川御上水万年石樋 右は幅凡六尺程 地中九尺程二埋有之 大木戸南之方御上水番屋迄は流ありて 従夫東は石樋二相成 町内家持伊兵衛住居之所ゟ往還地中ヲ相流れ 同所伝馬町壱丁目迄一円二石樋二御座候 右石樋ゟ分水詰候井戸 町内往還二五ヶ所有之候 御起立之義は承応年中**」＝**万年石樋：幅約6尺・地中約9尺に埋設・大木戸南方の御上水番屋までは開渠、それから東は石樋となり町内家持の住居地中の往還地下を流れ伝馬町壱丁目まで一円石樋・石樋から分水詰めの井戸5ヶ所（町内往還上）・起立は承応年中**。〔**定量情報（幅6尺・地中9尺・大木戸〜伝馬町壱丁目の一円石樋区間）＝[GAZ-112](GAZ-112.md)の四谷万年石樋文言の元資料側・同じ数字構造の対校**〕。
- **塩町三丁目条の堀割時の井戸五ヶ所宛御免文言〔文言候補・repo初出候補〕（p61）**: 「**御上水御堀割之砌 数月之間 町人共商売不仕候ニ付 壱ケ町左右二井戸五ケ所宛 御免被仰付候由 今以右井戸五ヶ所町内二有之 尤修復仕候節は御願申上修覆仕候**」＝**玉川上水の堀割工事の際、数ヶ月間町人が商売できなかったため、1ヶ町あたり井戸5ヶ所宛を御免（許可・補償）された由。その井戸5ヶ所は文政10年時点でも町内に現存し、修復の節は御願の上で修復している**。〔**玉川上水開削（承応年間）が四谷の町人に与えた打撃と、井戸の付与という補償の構造を記す文言候補（repo未収録の情報）＝上水（開渠）→石樋（暗渠）化と分水井（p60）との系譜を読む鍵。同様の文言の他町での有無（伝馬町・麹町側）は今後の掃引課題。「壱ケ町左右」の意味（1ヶ町あたり・数町で分け合った等）は原画像照合まで保留**〕。
- **塩町三丁目条の玉川上水起立総説〔文言候補・[GAZ-112]の元資料側対校〕（p61）**: 「**玉川御上水御起立之儀は 承応二癸巳年中 武州多摩郡羽村ゟ川崎村福生村熊川村弥嶋村上川原村砂村小川村鈴木新田小金井三新田下小倉井村田無村保谷村梶之新田堺村西ヶ久保村上連雀村下連菅村吉祥寺村**（後略・村列続く）」＝**玉川上水起立＝承応2癸巳年（1653）・多摩郡羽村からの村列リスト（取水・経由村の列挙）**。〔[GAZ-112](GAZ-112.md)の玉川上水起立総説（筋の村数29ヶ所・道法13里）とほぼ同型＝**御府内備考四谷巻の総説が本冊（町方書上）系統の文章を引いている候補が強い対校**（文章の細部の異同は原画像照合の上で）。村名列は多摩郡全域にわたるため、repoでは四谷区間の視点からの位置付けのみ記録**〕。
- **塩町三丁目条の御水番屋・大流水善神・水門文言〔文言候補・[GAZ-112]対校〕（p65-68）**: ①「**先祖(=彦七)…御上水御起立以前ゟ奥所二住居罷在尤土地案内功者ニ付 御上水樋口幷水上数町之間水路番人役被仰付 御水番屋御構内惣坪数六百三拾坪余 此内御上水堀百七拾三坪…**」＋「**明和五子年十二月朔日 六代目彦七義も先御掛御奉行様ゟ御普請方御役所え御附渡りニ相成**」＋「**都而百七拾五年来 御水番屋地所御預り申上 番人御役相続相勤罷在候**」＝**御水番屋構内630坪余（うち上水堀173坪）・先祖が御上水起立以前から水路番人・明和5年（1764）に御普請方付替え・175年間の御預り**＝[GAZ-112](GAZ-112.md)の御水番屋文言（構内630坪）と数字一致の対校。②大流水善神・藤古木・夫婦紅葉（p66-67）＝**大流水善神文言の元資料側**（[GAZ-112]対校・対応行（対照表）参照）。③水門文言「**御構内南之方二吐候唱候水門有之 平日塵芥吐流且満水之節は洪水門ゟ除水いたし候義ニ而是亦御起立之節より御補理有之**」＋流下＝「**右御構南隣内藤大和守様御下屋鋪内を通り同所南之方里俗地尻と唱候辺ゟ千駄ヶ谷御焔蔵後チ流れ従夫青山渋谷二至り候而は渋谷川とも相唱…古川…芝金杉橋ニ至り末者海二落入…古川之八ツ橋**」（p67-69）＝**吐水門と玉川上水余水の流下系統（内藤下屋敷→千駄ヶ谷→渋谷川→古川→海）＝[GAZ-112](GAZ-112.md)の吐水系統文言と同一構造の対校・「古川之八ツ橋」も一致**。
- **塩町三丁目条の「里俗(?)桜川」文言＝杉川判読対立の元資料側〔文言候補・[GAZ-112]杉川条の対校・判読対立の新材料〕（p69-70）**: 「**一里谷(=里俗候補・OCR崩壊)桜川 右往古之水際は 関係(=内藤候補・OCR要照合)大和守様御下屋鋪内ltr流出 其辺ヲ過而市ヶ谷ltr牛込ヲ流レ江戸川江落合申候 尤今は幅凡弐尺程之大下水に而 流れ二ハ無御座候 其由緒相分り不申候 但当文場所大木戸ltr西之方凡弐拾間程先二有之 富町持場二は無御座候**」＝**「一 里俗(?)（桜川/杉川・判読要照合）」：往古の水端（水際）は（内藤?）大和守様御下屋敷内から流れ出て、その辺を過ぎ市ヶ谷・牛込を流れて江戸川に落合した。今は幅約2尺の大下水で流水は実質なく、由緒はわからない。ただし当文の（川の）場所は大木戸の西方およそ20間程先にあり、当町（塩町三丁目）の持場ではない**。〔**①本段は[GAZ-112](GAZ-112.md)杉川条（「**杉川古者里俗之唱?…往古之水源ハ内藤大和守様御下屋敷内より流出…巾凡弐尺程之大下水…但本文場所大木戸ノ西之方凡弐拾間程先ニ有之**」＝[対照表](../../地名・河川名対照表.md)の杉川行に第213回追記済み・repo初出の幻の川名）と内容・語順がほぼ一致する**元資料側（町方書上）の文言＝御府内備考四谷巻の杉川条が本冊系統の文章を引いている候補の強い対校**、②**本冊OCRが川名を「桜川」に読むのに対し御府内備考側は「杉川」＝「桜／杉」の字形近接による定型的崩壊を含む判読対立が両書間で成立**（本冊の真の原字が桜川・杉川のいずれかは原画像照合まで決めない。杉川読みの場合は[GAZ-112]杉川条の元資料側確定の重みが上がり、桜川読みの場合は[GAZ-110](GAZ-110.md)修行寺門前条・[GAZ-144](GAZ-144.md)坂町条の桜川文言群に新しいwitnessとなる）、③「往古の水際＝内藤(?)大和守様御下屋敷内」＝[GAZ-144](GAZ-144.md)坂町条「内藤大和守様御下屋敷内ltr流出」と整合（[GAZ-110]修行寺門前条の田安様文言との対立は併記のまま）、④「富町持場二は無御座候」＝塩町三丁目の場所外（大木戸西20間先）の川の紹介文言で、[GAZ-144](GAZ-144.md)坂町条「委細ハ塩町三丁目ltr申上候」の委譲構造の相手側の文章の候補（ただし杉川読みの場合は坂町の桜川（榎川対立中の水路）とは別水路の可能性があり、同一視は原画像照合までしない）**〕。
- **塩町三丁目条の紅葉川・西迎寺梵鐘銘文言〔文言候補・repo初出候補〕（p70-71）**: 「**一里俗紅葉川 右紅葉川之義は川玄(=候補・OCR?)申候由 前書細安(=桜?)川流下 当時田安様御下屋敷内ゟ市谷谷町辺御先手御組屋敷内ヲ流レ 同所木村町ニ落込申候 右場所三四町之間旧名紅葉川共唱候由 其由縁之義二候哉**」＋「**右御組屋敷南側裏続 四谷北寺町二浄土宗芝増上寺末西迎寺と申精舎有之 則山号ヲ今以紅葉山と申候…大田道灌手植之(=古木?)相と申伝し古木も有之候…其節寺称西迎乃三浦伊卜之法号峯基紅葉存延徳二祀山謂紅葉是江城西郭之舊名易地四谷存寛永某年伊ト太田道灌之臣造茲寺者也(下略) 貞享三丙寅冬十月如此**」＝**①紅葉川（田安様御下屋敷内→市谷谷町辺・御先手御組屋敷内→木村町に落込・三四町の間の旧名）の流路文言と、②西迎寺（紅葉山摂取院）の梵鐘銘の引用：西迎＝三浦伊卜(?)の法号峯基紅葉・延徳2年（1490）・「紅葉」は江城（江戸城）西郭の旧名・寛永某年に地を四谷に改め・太田道灌の臣がこの寺を造った（貞享3年銘）**。〔**紅葉川呼称の由来の側（西迎寺＝道灌臣造寺説・江城西郭旧名説）の梵鐘側一次引用文言repo初出候補**＝[GAZ-110](GAZ-110.md)・[GAZ-116](GAZ-116.md)の紅葉川行（対照表）に由来系譜の新材料。「川玄」「細安川」「伊ト」等の原字は要原画像照合。**紅葉川の流出点が田安様御下屋敷とされる点＝桜川文言の内藤様候補と両立するか（別池・別流か）は水路の位置関係の照合課題で本登録では決めない**〕。
- **塩町三丁目条の太田川・太田橋文言〔文言候補・[GAZ-112]対校〕（p72）**: 「**一里俗太田川 右は四谷大木戸ゟ西甲州街道 内藤新宿ゟ下高井戸え之間 萩久保と申処之少し先き 玉川御上水え掛渡候土橋ヲ太田橋被唱候 尤里人くだいだ橋と唱来 此辺御上水御堀割御起立以前ゟ少し義流ヲ太田川え呼来候由 其所御上水二相成候而も旧名ヲ呼伝へ 今二此辺二而は太田川と申候由**」＝**太田川＝萩久保の少し先（内藤新宿〜下高井戸間の甲州街道沿い）の玉川上水に架かる土橋＝太田橋（里人「くだいだ橋」）付近の旧川名。上水堀割起立以前の少しの流れを太田川と呼び、上水化後も旧名が残る**＝**[GAZ-112](GAZ-112.md)の杉川・太田橋文言と同型の元資料側対校**。「少し義流」等の崩れは要照合。
