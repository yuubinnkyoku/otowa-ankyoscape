# [GAZ-036] 江戸地名字集覧（1929）— 鼠ケ谷の地名字典における立項

- **書誌〔確認〕**: 三村清三郎編『**江戸地名字集覧**』（昭和4年・1929年）。江戸の小名・字名・横丁名を五十音順に集めた地名字典。NDL次世代デジタルライブラリー [book/1879949](https://lab.ndl.go.jp/dl/book/1879949)。**引用はすべて同館OCRテキスト由来で、項目名と場所の対応（行の対応）は原文照合を要する。**
- **「鼠ケ谷」の立項〔確認・repo初出の字典登録〕**: 「ね」の部の列挙——「**鼠阪（ねずみざか）…（場所列）…鼠山（ねずみやま）・鼠穴（ねずみあな）・鼠ケ谷（ねずみがや）・鼠橫町（ねずみよこちやう）…**」という鼠系地名の連続立項があり、その場所列に「**小日向臺町へ上る（鼠阪）・小石川音羽五丁目（鼠ケ谷）**」等の町名が付される〔**①「鼠ケ谷」が1929年時点の地名字典に独立項目（読みねずみがや）として立項されていたこと、②その場所が「小石川音羽五丁目」とされること（＝音羽町五丁目の鼠坂・鼠ヶ谷下水界隈〔[GAZ-035](GAZ-035.md)〕と整合する比定）、③「鼠阪」に「小日向臺町へ上る」場所が並記されること（＝音羽町側の鼠坂〔[GAZ-035](GAZ-035.md)の「新屋敷への登り」〕が小日向台町側への登りとしても認識されていたことを示す方向の記録）**＝1929年という明治以降・大正期以降の時点で鼠系地名の一群（鼠阪・鼠山・鼠穴・鼠ケ谷・鼠横町・鼠屋横町）が字典レベルで保存されていた記録〕〔OCRで項目と場所の行対応が崩れており、個々の対応の確定は原文照合まで保留。鼠横町・鼠屋横町の各場所もOCR上は判読困難〕。
- **位置づけ〔観察〕**: 「鼠ケ谷」が字名として字典に残っていたことは、①『御府内備考』巻50（[GAZ-013](GAZ-013.md)）の「音羽町の旧字鼠ヶ谷」申伝、②『御府内備考』巻44-46の手代不知堂町条の「鼠谷村」（[GAZ-034](GAZ-034.md)）、③町方書上の鼠ヶ谷稲荷・鼠ヶ谷下水（[GAZ-035](GAZ-035.md)）という江戸期の記録群の後に、明治・大正期の地名知識として定着していたことを示す。ただし字典の編纂資料（江戸期文献のどこに依拠したか）は未確認のため、独立の証拠（実地の字名の残存）か江戸期文献の引き写しかはこの資料からは判断できない（断定しない）。
