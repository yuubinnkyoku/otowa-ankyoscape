# [GAZ-036] 江戸地名字集覧（1929）— 鼠ケ谷の地名字典における立項

- **書誌〔確認〕**: 三村清三郎編『**江戸地名字集覧**』（昭和4年・1929年）。江戸の小名・字名・横丁名を五十音順に集めた地名字典。NDL次世代デジタルライブラリー [book/1879949](https://lab.ndl.go.jp/dl/book/1879949)。**引用はすべて同館OCRテキスト由来で、項目名と場所の対応（行の対応）は原文照合を要する。**
- **「鼠ケ谷」の立項〔確認・repo初出の字典登録〕**: 「ね」の部の列挙——「**鼠阪（ねずみざか）…（場所列）…鼠山（ねずみやま）・鼠穴（ねずみあな）・鼠ケ谷（ねずみがや）・鼠橫町（ねずみよこちやう）…**」という鼠系地名の連続立項があり、その場所列に「**小日向臺町へ上る（鼠阪）・小石川音羽五丁目（鼠ケ谷）**」等の町名が付される〔**①「鼠ケ谷」が1929年時点の地名字典に独立項目（読みねずみがや）として立項されていたこと、②その場所が「小石川音羽五丁目」とされること（＝音羽町五丁目の鼠坂・鼠ヶ谷下水界隈〔[GAZ-035](GAZ-035.md)〕と整合する比定）、③「鼠阪」に「小日向臺町へ上る」場所が並記されること（＝音羽町側の鼠坂〔[GAZ-035](GAZ-035.md)の「新屋敷への登り」〕が小日向台町側への登りとしても認識されていたことを示す方向の記録）**＝1929年という明治以降・大正期以降の時点で鼠系地名の一群（鼠阪・鼠山・鼠穴・鼠ケ谷・鼠横町・鼠屋横町）が字典レベルで保存されていた記録〕〔OCRで項目と場所の行対応が崩れており、個々の対応の確定は原文照合まで保留。鼠横町・鼠屋横町の各場所もOCR上は判読困難〕。
- **位置づけ〔観察〕**: 「鼠ケ谷」が字名として字典に残っていたことは、①『御府内備考』巻50（[GAZ-013](GAZ-013.md)）の「音羽町の旧字鼠ヶ谷」申伝、②『御府内備考』巻44-46の手代不知堂町条の「鼠谷村」（[GAZ-034](GAZ-034.md)）、③町方書上の鼠ヶ谷稲荷・鼠ヶ谷下水（[GAZ-035](GAZ-035.md)）という江戸期の記録群の後に、明治・大正期の地名知識として定着していたことを示す。ただし字典の編纂資料（江戸期文献のどこに依拠したか）は未確認のため、独立の証拠（実地の字名の残存）か江戸期文献の引き写しかはこの資料からは判断できない（断定しない）。

- **「千川屋敷」の立項とその場所列〔確認・文言候補・repo初出の千川屋敷の字典立項〕**: 本字典の項目列に「**千川屋敷**」の立項があり、その場所列（項目の後に並ぶ町名群）として「**四谷元鮫ケ橋南町**」「**小石川指ケ谷町**」が読める＝**千川屋敷の呼名が、八丁堀・南茅場町（[GOV-108](../gov/GOV-108.md)・[GAZ-082](GAZ-082.md)の裏茅場町＝千川屋敷）のほかに、四谷元鮫ヶ橋南町・小石川指ヶ谷町の側でも立項されていた記録候補**。〔**①対照版スキャン[book/1187170](https://lab.ndl.go.jp/dl/book/1187170)（本書1879949と同書の別スキャン）と登録スキャン[1879949]の両OCRで「四谷元鮫ケ橋南町」「小石川指ケ谷町」の語が「千川屋敷」とともに現れる（行の対応＝千川屋敷の場所列であることの確定は、OCRの行崩れがあるため原画像照合まで保留）。②日本橋・南茅場町・牛込辨天町・深川今川町の列は千川屋敷か仙臺堀（仙台堀）か帰属が未確定（ただし南茅場町＝八丁堀の千川屋敷〔GOV-108・GAZ-082〕と既知の文言と一致し得る）。**＝**千川上水沿いの複数の屋敷（または複数の呼名の分布）の候補を、1929年時点の地名字典レベルで指す datapoint**。〔四谷元鮫ヶ橋南町は四谷側の千川上水沿い（鮫ヶ橋は千川上水の四谷側の橋〔[BOOK-131](../books/BOOK-131.md)等〕）、小石川指ヶ谷町は指ヶ谷丁（谷端川下流の谷頭＝鶏声窪系〔[GAZ-083](GAZ-083.md)〕）で、**いずれも千川上水・谷端川系の水沿いの地名**であることが対照資料としての意味を持つ（立項の意味＝屋敷の所在か呼名かは本字典の凡例確認を要する）。〕
- **「乞食橋」の立項と乞食藪・乞食阪〔確認・文言候補〕**: 項目列に「**乞食橋**」の立項があり、その場所列として「**日本橋本銀町一丁目**」が読める候補＋「**乞食藪**」「**乞食阪**」（一曰「茶乞食阪」か・原字要照合）の立項が同じ附近に現れる＝**乞食橋の所在が日本橋本銀町（旧・神田新銀町）と読める立項候補**。〔**神田（新銀町）の乞食橋＝[GAZ-037](GAZ-037.md)第158回追記の『大江戸志』新革屋町条の乞食橋（神田祭礼第十三番花篭鉾と結びつく）と整合する方向の、字典レベルの立項候補**＝乞食橋名の江戸市中での同名異所（巣鴨の藤橋〔[GAZ-039](GAZ-039.md)第158回追記〕・赤坂〔[MAP-180](../maps/MAP-180.md)〕）の系譜の一部。行対応・丁目数は原画像照合まで保留。〕
- **「猫又橋」「猫又阪」の立項〔確認・文言候補〕**: 項目列に「**猫又橋**」（場所列はOCRでは不読）と「**猫又阪**」の立項が読め、猫又阪の場所列に「**上深川大和町**」「**小石川大門町**」「**淺草壽町**」の3町が併記される候補＝**猫又系の橋坂名が江戸市中の複数の地点（深川・小石川・浅草側）に立項されていた字典レベルの記録候補**。〔ねこまた橋（[GAZ-083](GAZ-083.md)・小石川の本流の橋）・根子股橋（[GAZ-070](GAZ-070.md)）の系譜と併せ、**猫又（根子）系の名が小石川の橋固有名から市中の複数地点に分布していた背景の資料**。猫又橋の立項と小石川大門町の関係（ねこまた橋〔千石側〕の登記か別橋か）は原画像照合まで断定しない。〕
