# [GAZ-121] 町方書上[68] 湯嶋町方書上弐 — 80間・18間・22間条と湯島側下水石橋の寸法文言

- **書誌〔確認〕**: 『町方書上[68] 湯嶋町方書上　弐』（写・NDL次世代デジタルライブラリー [book/2571549](https://lab.ndl.go.jp/dl/book/2571549)・115コマ）。署名は湯島町（亥二月）、「福島三町目」（亥正月・**「湯島三町目」のOCR崩れ候補**）、湯島五町目（亥二月）等。**引用文言はすべてOCR由来で要原文照合。ページ番号は `2571549_{NNNNNNN}.txt` コマ番号。**
- **80間5尺3寸5分条〔文言候補・GAZ-024該当条の原本側〕**: 「**千川上水之儀は安永九子年中町内往還に長八拾間五尺三寸五分位往来中程ニ埋山中樋近渡し有之湯嶋横町境三御角往来中程に中柳壱ヶ所有之候所天明七未年四月十御差止ニ相成候節取潰シ埋立申候但委敷義年元禄之度之義は相分不申候**」（p20）＝〔**①80間5尺3寸5分・埋中樋・湯嶋横町境（「三御角」の原字は照合課題）の往来中程に中柳（中桝のOCR候補）1ヶ所、②天明7未年4月（「十」以下OCR崩れ）差止取潰、③「元禄之度之義は相分不申候」＝元禄期の記憶喪失文言。条帰属＝署名p49の前段でOCR「福島三町目」（湯島三町目候補）条に帰属候補だが、署名p9（湯島町）〜p49の間の条境界は原画像照合まで確定しない**〕〔[GAZ-024](GAZ-024.md)（雄山閣刊本・80間5尺3寸5分（湯島横町境）条）の写本側文言。**「元禄之度之義は相分不申候」は刊本側に残っているか含め対校課題**〕。
- **18間条〔文言候補・GAZ-024該当条の原本側〕**: 「**千川上水之儀は安永九子年町内往還に長拾八間三人程往還中程に埋中樋掛渡し有之候但天明七未年四月中御座止に相成候節取潰し埋立申候其外委細儀は相分不申候**」（p43）＝〔**「拾八間三人程」は「拾八間三尺程」のOCR崩れ候補。18間3尺＝[GAZ-024](GAZ-024.md)の町別数値リストの18間3尺条と数値一致。条帰属は上記80間条と同じ条（湯島三町目候補）内で、**同一町内に2本の往還横断があったと読める候補**（80間条と18間条の主従関係は断定しない）**〕。
- **湯島五町目条＝22間条と下水石橋2ヶ所〔文言候補〕**: 「**町内往古ゟ日光御社参之節御成還御共御道筋ニ相成申候但当町ゟ川口宿渡船場迄道法弐里半余 一下水石橋弐ヶ所内壱ヶ所は往還木戸際にて幅四間四尺七寸渡リ六尺三寸有之壱ケ所は東方新道往還幅六尺七寸渡り四尺四寸有之尤何れも無程二御座候 一千川上水之儀は安永九子年町内往還長弐拾弐間程往来中程ニ埋中樋懸ケ渡有之湯嶋四丁目境四ツ角往来中程に中桝壱ヶ所有之候処天明七未年四月中御差止に相成候節取潰シ埋立申候**」（p89）＝〔**①22間・湯嶋四丁目境四ツ角の往来中程・中桝1ヶ所＝[GAZ-024](GAZ-024.md)の22間条の原本側文言で条帰属＝署名p93の湯島五町目条（[GAZ-045](GAZ-045.md)（御府内備考湯島区間）の22間条帰属問題への写本側の回答候補）、②下水石橋2ヶ所の寸法（往還木戸際＝幅4間4尺7寸・渡6尺3寸／東方新道往還＝幅6尺7寸・渡4尺4寸）＝湯島側の下水（排水溝）に架かる石橋の寸法レコード（千川上水の樋とは別の条項。位置アンカーとして[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)に追記）、③日光御社参の御道筋で当町から川口宿渡船場まで道法2里半余の由緒文言**〕。
- **p107の下水石橋2ヶ所〔文言候補・条帰属未確定〕**: 「**町内下水石橋弐ヶ所但東之方湯島五丁目境横丁入候は其所巾弐間渡り三尺程往還北側中程横丁右壱ヶ所損三間渡三尺程右は何れも無名にや座候**」（p107）＝〔**湯島五丁目境に接する別町条（署名p93の湯島五町目条以降の追記書上とみられるが、条帰属は原画像照合まで未確定）の下水石橋2ヶ所（巾2間渡3尺・巾3間渡3尺、「無名」）の文言**〕〔p89の丈面条と併せ、湯島側の下水石橋の分布が町方書上で2条4ヶ所読める**。何の「下水」か（千川埋樋跡の排水か、独立の悪水路か）は本冊では特定できない**〕。

## 制限・未解決

- ①署名の「福島三町目」は「湯島三町目」のOCR崩れの公算が大きいが、原字確定まで帰属表記はOCRのまま残す。②p20・p43の2条の町帰属（同一町か別町か）は条境界の原画像照合まで断定しない。③「湯嶋横町境三御角」「四月十御差止」「拾八間三人程」等の崩れ字の原字は照合課題。④p107条の帰属町名（p93署名以降の追加書上相当）は未確定。⑤下水石橋と千川上水の樋・桝との位置関係（同じ街路の上下か）は本冊の文言では比定できない。
