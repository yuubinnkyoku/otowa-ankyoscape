- **十番馬場町条＝元禄11年の「金杉川口より渋谷迄川御渡」・堀広げ船入化の行政側実務文言〔文言候補・奉行人名はrepo初出〕**: 「**一当所往古は麻布村之内原地有之十番と相唱候儀は元禄十一寅年麻布白銀御殿御普請之砌金杉川口より渋谷迄川御渡ニ而川上川巾壱間余之処堀広ケ船入ニ相成其節之御奉行稲生七郎右衛門様奥田八郎右衞門様御懸ニ而御手伝溝口信濃守様伊達美作守様え被仰付**」＝**①元禄11年（1698）寅年・麻布白銀御殿御普請の砌、金杉川口より渋谷まで川を御渡（流路付け替え）し、川上の川巾1間余の場所を堀広げて船入とした、②その節の御奉行＝稲生七郎右衛門・奥田八郎右衞門、御手伝＝溝口信濃守・伊達美作守**という町名（十番）由来の書上文言候補。〔**総説の元禄11年堀普請と同一事件の町方側実務文言であり、奉行人名（稲生七郎右衛門・奥田八郎右衞門）と「白銀御殿御普請との同時進行」はrepo初出の情報**。白銀御殿普請（御殿造営）と新堀成立の関係づけ（総説の「御殿造営時水流改め」との前後関係）は原画像照合まで断定しない。〕
