# [GAZ-109] 御府内備考 巻56-57（牛込之四〜五・写本OCR）— 河田窪地名論と蟹川（戸山経由下水）の町方書上

- **書誌〔確認〕**: 『御府内備考』巻之五十六（牛込之四・白銀町〜水道町改代町等）・五十七（牛込之五・天神町・中里村町・榎町〜川田ヶ谷久保町・原町壱〜三丁目・若松町・破損町・供養塚町・馬場下横町・早稲田町・馬場大下町候補・正覚寺門前・放生寺門前）の合冊写本。NDL lab [book/2553678](https://lab.ndl.go.jp/dl/book/2553678)。**引用文言はすべてくずし字OCR由来で原画像照合を要する。**目録「馬場六町」の原字（馬場大下町候補）等の判読対立がある。
- **本登録の性格**: 蟹川（戸山落）系の谷頭（河田窪）と早稲田・下戸塚方面の流路の町方書上レベルの初記録化。第211回課題⑥（河田窪系蟹川の市谷側該当巻のpid特定）の解決資料。第212回前半の大久保村=蟹川水源仮説（[GAZ-110](GAZ-110.md)総説との対校）の検討材料。

## 第212回の読取（2026-11-20）

- **川田久保町条〔文言候補・地名・地形・下水〕**: 「**川田久保町町内起立之儀は筆古き儀二而書留等無之相分不申候得共往古武州豊島郡野方領牛込村之内二有之候処其後町家ニ相成川田久保町と唱申候…東方山伏町之続西方原町壱丁目両方高ク町内地久保ニ付川田久保と唱来候由申聞候**」＋「**一下水右は町内西ゟ南へ折回有之西ニ而巾凡四尺程南ニ而巾壱尺壱寸五分程堀割年代相知不申候一石橋巾凡四尺程長弐間半(?)右は町内西南之角下水に懸有之埋橋二而尤御道具請方御掛ニ御座候（OCR）**」＝**①起立年代不詳（古く書留なし）・往古は武州豊島郡野方領牛込村の内、その後町家化、②東（山伏町続）西（原町1丁目）の両方が高く町内の地が窪（久保）なので川田久保と唱える由、③下水は町内の西で南へ折回（西側で巾凡4尺・南側で巾1尺1寸5分）、堀割年代不知、④石橋（巾凡4尺・長2間半候補）が町内西南角の下水に懸かり、埋橋で御道具請方御掛（OCR）**。〔**川田久保町の起立不詳・地形説明（両方高く地窪）・下水の折回構造の町方書上はrepo初出**。窪の成因（川田窪の谷頭地形）を地名側から裏付ける一次記録になり、[対照表](../../地名・河川名対照表.md)の河田窪系地名群（川田ヶ窪〔市谷柳町〕行）と併せて谷頭地形の記録層を厚くする。宮検・寛文12年9月28日野村彦太夫様手代等の文言（年次付き）も同条に見える（詳細は割愛・要照合）。〕
- **穢多ヶ窪→河田の字改め説と古訓カワタ説〔文言候補・repo初出の地名字源論〕**: 「**昔此地に穢多住居して革を製せしゆへ草多(?)がくほといひしを後河田の字に改めしなりと又改逼(?)江戸志に寛永の頃の書に穢多か窪と書へしものありと載たり今按に穢多を古訓かわたと唱へし由定家卿仮名造(?)等の書にもいへり然れは直に穢多か窪と云は古き唱へにして革を製せしよりの名にはあらす**」＝**①昔この地に穢多が住居して革を製したので「穢多ヶ窪」と言い、後に「河田」の字に改めた説、②改撰江戸志（OCR崩れ「改逼」）に寛永の頃の書に「穢多か窪」と書いたものがあると載る、③編纂者按＝穢多の古訓は「かわた」で（定家卿〔藤原定家〕の仮名造〔『仮名文字遣』候補OCR〕等の書にも言う）、従って「穢多か窪」は古い呼びであって革製造由来の名ではない**。〔**河田窪の地名論の核心：①「穢多ヶ窪→河田改字」説・②改撰江戸志の「寛永の頃の書」引証・③古訓カワタ説（語音由来説）の三層が一文に併存する府内備考の按語**（〔GAZ-065〕の地名辞書1907〔第210回登録〕の河田窪論の先行本文候補）。[対照表](../../地名・河川名対照表.md)川田ヶ窪行の第212回追記に反映。判読「草多」「仮名造」は要照合。〕
- **湯原氏日記の元禄4年川田窪原町出火と範囲拡大文言〔文言候補・repo初出〕**: 「**又湯原氏の日記に元禄四年二月十九日今夜酉の刻川田か窪原町より出火し加賀屋敷まて焼失大火におよふと書るに據ハ古人ハ原町遠越(?)もなへて川田窪と唱へしとみへたり今は市ヶ谷月桂寺辺をも川田窪と呼へり**」＝**①湯原氏日記（OCR・比定未了）の元禄4年（1691）2月19日酉の刻、川田窪原町からの出火で加賀屋敷まで焼失した記事、②それによれば古人は原町周辺（「遠越」は判読保留）も併せて川田窪と唱えた、③今（書上時点＝丁亥文政期）は市ヶ谷月桂寺辺をも川田窪と呼ぶ**。〔**河田窪（川田窪）の範囲が原町周辺から市ヶ谷月桂寺方面まで及ぶことの通時記録**。月桂寺＝市ヶ谷・現・国立がんセンター中央病院付近候補。河田窪＝蟹川水源窪地説（GAZ-065の「市谷河田窪の方より中里に至る者をも蟹川と云へば」文言）の範囲側の裏付け本文。元禄4年出火の信憑性（湯原氏日記の比定を含む）は原照合まで断定しない。〕
- **原町壱〜三丁目条の起立・石橋・下水〔文言候補〕**: 「**原町壱町目町内起立之儀は往古下戸塚村之内榊原と申伝候場所二有之（OCR）**」＝**起立は往古下戸塚村の内の榊原という場所の伝承**（人名・地名の両候補あり要照合）。同条の石橋・下水文言（「**石橋二ケ所右当町下水江掛渡埋橋ニ致者通之方巾壱尺（?）長二間横町之方巾壱尺五寸長弐間半下水巾壱尺右当町雨落御座候而堀割年代相知不申候**」OCR・条の帰属〔原町・破損町のいずれか〕は要照合）＝**下水巾1尺の雨落（堀割年代不知）に埋橋化した石橋2か所（巾1尺長2間・巾1尺5寸長2間半）**。〔原町の雨落下水と石橋の寸法群＝河田窪谷の市中側排水の実態記録（帰属特定は原画像で行う）。〕
- **馬場下町条・穴八幡前の下水掛渡＝駒之橋〔文言候補・repo初出の橋名〕**: 「**一石橋長壱間半余巾二間餘右町内境穴八幡前ニ有之下水掛渡駒之橋と唱申候尤前二ゟ御普請ニ御座候一下水右当町ニ有之候水元大久保村下水尾州様戸山御屋敷へ入夫ゟ流出末ハ早稲田村下戸塚村ゟ江戸川流落申候一下水巾壱尺五寸右町内銘々店前二有之尤雨落下水二御座候**」＝**①石橋（長1間半余・巾2間余）が町内境の穴八幡前にあり、下水の掛渡で「駒之橋」と唱える、以前に御普請があった、②下水は水元が大久保村の下水で、尾州様（尾張徳川家）戸山御屋敷に入ってから流出、末は早稲田村・下戸塚村を経て江戸川に流落、③下水巾1尺5寸は各家店前の雨落下水**。〔**①「駒之橋」の橋名はrepo初出候補（穴八幡前＝現・新宿区西早稲田の穴八幡宮前の石橋）＝大久保村→戸山屋敷→早稲田/下戸塚→江戸川という蟹川（戸山落）系流路の町方書上による裏付け文言、②巾1尺5寸の雨落下水の雨落ち構造の明記**。駒之橋の「以前御普請」の年代・馬場下町条の帰属（馬場下町/馬場六町〔OCR〕の整理）は原画像照合まで保留。馬場下町の町名語源（「**高田馬場東方ニ当り八幡坂ト申坂有之右坂下故二馬場御町ハ相唱申候**」）＝八幡坂下にあること由来説も同条。[GAZ-046](GAZ-046.md)・戸塚町誌（[BOOK-149](../books/BOOK-149.md)）の蟹川流路（大久保方面→戸山→早稲田→松ケ枝町江戸川）との対校時に「水元大久保村」文言の評価は重要（第211回ノートの大久保村＝蟹川水源仮説の検討材料・本条は町方書上側の一次記録）。〕
- **早稲田村・浜松寺領側の記録〔対校差分〕**: 馬場下町条周辺に「**正保三戊ノ年十二月三日同寺（浜松・OCR）領ニ相成**」・元禄15年11月今井九右衛門様ほかの御検地文言等（蟹川系流域の領有史・検地の年次datapoint、抄録。GAZ-105の満松寺＝浜松寺判読と対校）。
