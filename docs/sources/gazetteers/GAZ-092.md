# [GAZ-092] 燕石十種第3（江戸往古図説活字版） — 小石川村条・小日向村条・飯田川・古道条〔第169回登録〕

- **書誌〔確認〕**: 岩本佐七編『燕石十種』第3（国書刊行会・1908〔明治41〕・NDL次世代デジタルライブラリー [book/991270](https://lab.ndl.go.jp/dl/book/991270)・bibId 000000873174・257頁）。**第六輯に大橋方長『江戸往古図説』の全文（上・下巻）を活字収録**する〔写本〔[GAZ-090](GAZ-090.md)・NDL 2577095＝東京府文獻叢書甲集第四冊の写し〕と同一本文の活字版による別伝本系。成立は寛政庚申（1800）〜享和元年（1801）頃〔GAZ-090の自序・城郭条「享和元年当今」文言による〕。**活字版のため写本OCRより判読性は高いが、活字化時の校訂・底本写本自体の文字との全面的な異同照合は未実施**〕。引用文言はOCR由来で要原文照合。
- **小石川村条〔確認・文言候補・repo初出文言群〕**: 「**往古小石川といふ流れ有て大川のよしいへり既に此名北條分限帳にも出たり牛天神社傳にも見ゆ船繫松かきがら坂網干坂などの名此邊にあり光圓寺の寺傳にも小石川の入江といふ事ありかの小石川の流れは巢鴨西北よりねこまた橋の方を通り傳通院うしろの邊を流れし大川也といふ光圓寺は行基開基天平中草創といふ其頃は此わたりを中臺村といひしゆへ中臺山の號ありしと緣起に見へたり**」＝①**「巣鴨西北よりねこまた橋の方を通り傳通院うしろの邊を流れし大川」＝ねこまた橋川筋＝小石川流路説の1800-01年成立の考証書本体の文言**〔[GAZ-083](GAZ-083.md)（小石川志料・江戸砂子引用「伝通院のうしろの流 ねこまた橋の川筋 小石川の濫觴と云」）と同型の文言が江戸往古図説本体に存在＝独立の先行テキスト。[GAZ-049](GAZ-049.md)⑧（正保国図の御薬園西→伝通院後方の流れ）と整合〕。②**「北條分限帳にも出たり」「牛天神社傳にも見ゆ」＝中世の川名としての「小石川」の所出を北條分限帳・牛天神社伝に求める文言候補（repo初出・分限帳本体の文言確認が前提・二次引用であることに注意）**。③船繫松・**かきがら坂**〔repo初出候補〕・網干坂〔[GAZ-027](GAZ-027.md)の網干坂1772年記録の先行対校点〕・**光圓寺「小石川の入江」**〔GAZ-083系の「入江」伝承の別系統文言〕・**「此わたりを中臺村といひしゆへ中臺山の號ありしと緣起に見へたり」＝光圓寺（中臺山）の山号由来としての中臺村譚（repo初出候補・上板橋の北の中臺村（豊島郡）とは別の中臺村である可能性があり断定しない）**。④「又簸川原とあり是も小石川の事也と云猶考ふべし」＝江戸志の**簸川原**表記〔repo初出・「猶考ふべし」の留保つき・小石川の異表記候補〕。
- **巣鴨村条・鶏声ヶ窪「皂莢原」〔確認・文言候補・GAZ-090の対校〕**: 「○鷄聲ヶ窪今地名のやうになれり**元皂莢原と云**源賴朝公元曆元年建立江戶砂子に北條氏康勸請のよしいへり非也是は氏康再興の事にでもあるべし」＝**活字版は「皂莢原」**〔写本OCRは「皇角原」（[GAZ-090](GAZ-090.md)）＝皂／皇・莢／角の字形混淆による写本OCRの誤読である可能性が高いが、**写本原画像の照合までは読みの確定は保留**（活字版の校訂の可能性も残る）。江戸砂子「北條氏康勸請」に対する「非也」批判と「氏康再興」修正案も文言候補〕。巣鴨村条には中興治亂記応安元年（1368）「武州巢鴨に陣取」（上杉憲將・能憲・千葉助直胤二千餘騎）の引用文言もある（二次引用）。
- **小日向村条〔確認・文言候補〕**: 「**往古此地に白鳥池とて大池有よし今久永氏宅地にわづかに其名殘りの池ありといふ又此邊いにしへ沼池多しとぞ既に江戶川は關口の方より流れ小日向築地の間を通り飯田町の下へ流れしを後に神田川へ水筋替れりといふ**」＝①**白鳥池＝久永氏宅地の名残池の伝承**〔[GAZ-049](GAZ-049.md)⑬（御府内備考・幕末の同内容記録）の**1800-01年の先行記録**＝対校点〕＋②**江戸川の水筋替え説（關口→小日向築地の間→飯田町の下→後に神田川へ）**〔GAZ-049⑬の江戸川枝流考証と対照する旧流路譚の文言候補（repo初出）〕。同条には北條分限帳（南向茶話経由）の小日向知行文言（興津加賀守六十四貫貳百十六文「江戶廻り落合櫻田小日向」・小日向彌三郎知行所貳拾貳貫八百四拾文・小日向彈正屋敷）と風土記の白鳥神社＝妻戀神社説（湯島村条にも「往古白鳥神社といふは當社なるべし」・鳥越村条に「いにしへ江戶川の邊に白鳥池と云ありし由」）もある（いずれも二次引用・文言候補）。
- **飯田川・袖摺橋（上卷・千代田条）〔確認・文言候補・repo初出〕**: 「**飯田川飯田町下雉子橋の方より入堀むかし神田川堀割以前は江戶川こゝを流るとぞ小石川御門内高松侯南の方下水石橋を袖摺橋と云よし傳へいふ往古は市谷長圓寺池水牛込御門通りより飯田町堀止の水につヾき流れたり然るを後神田川堀割の時堀は埋て飯田町にて止め其時の堀筋に殘りし橋也とぞ**」＋「今の神田川の流れ古へ江戶川龍慶橋の筋川南方へ流れて平川といふに落合也…**神田川御茶の水堀割と云へるは後の事にて其以前より川筋は有しとぞ是万治二年也是を神田川と云**」＝**飯田川・袖摺橋・市谷長圓寺池水→飯田町堀止の流れ・万治二年（1659）神田川呼称の各文言候補**〔神田川（江戸川）堀割以前の旧流路譚の新文言群。grep 確認: 飯田川・袖摺橋＝repo初出〕。三崎村条（三崎稻荷・田安の項）にも「**いにしへ今の雉子橋外より北の方大沼あり是より西飯田町もちの木坂と云へる下迄入江にて在る由**」＝雉子橋外北方の大沼・飯田町下入江の文言候補（repo初出・小日向村条の白鳥池・沼池群と対照）。
- **平川条の表記対立〔確認・文言候補〕**: 上卷平川条「今の江戶川龍慶橋の筋より水道橋の上三崎稻荷社の邊より飯田町下**まな板橋**の所へわたり…今の常盤橋も其川筋にかゝりしを大橋と呼しなり（今の川筋とはたがへり）」＝**橋名表記の三系統対立: 活字版「まな板橋」vs 写本OCR「真那板橋」（GAZ-090）vs BOOK-157「魚板橋」**（いずれも原画像照合が必須・表記確定は保留）。
- **下卷末尾の古道条〔確認・文言候補・repo初出候補〕**: 「**澁谷靑山百人町西北原宿を經て千駄ヶ谷八幡門前四谷より高田雜司ケ谷法明寺寺脇通り護國寺うしろの方より板橋を橫に見て瀧野川豐島村（一に豐島より千住の方へ古道一筋ありと云）西ヶ原平塚より石濱へ出隅田川にかゝり往來すと云此外に道筋あり靑山百人町よりかゝり相州小田原へ往來せしを中道と呼んで東海道より二里近しと云源持資平安紀行は文明十二年也北條氏康武藏野道紀は天文十五年也**」＝**澁谷→原宿→千駄ヶ谷→雜司ヶ谷法明寺→護國寺うしろ→板橋を横に見て瀧野川・豐島→西ヶ原→平塚→石濱の山手古道筋と「中道」呼称**〔[GAZ-048](GAZ-048.md)⑭（雑司ヶ谷の「古の奧州道」）・GOV-349（雑司ヶ谷筋御成ルート）と対照できる古道記録の文言候補。「板橋を橫に見て」の板橋＝石神井川の板橋かは要照合。源持資（道灌）平安紀行＝文明12年・北條氏康武藏野道紀＝天文15年の年代言及も文言候補〕。
- **その他の対校記録〔確認〕**: 大塚（東西大塚・七ヶ所太田氏塚）・吹上「古へ奥州街道とて大木の榎有」・増司ヶ谷村条・池袋村条・石神井村条・誓閑寺条の各文言は[GAZ-090](GAZ-090.md)（写本）第168回追記分と同一内容で対校完了（細部の文言異同の全面照合は未実施・活字版では「浪切不動」の表記で写本OCR「波切不動」に対応）。谷中村条「北條分限帳に此名出いにしへは谷にて三崎につゞき」・新堀村条・三河島村条・鳥越村条は千川・谷端川流域の周辺村条としての要再読（次回以降の課題）。
- **制限・未解決**: ①活字版（本資料）と写本（GAZ-090・2577095）の全条項の異同照合は未実施（活字化の校訂の可能性は常に留保）。②北條分限帳・中興治亂記・江戸志・求凉雑記・南向茶話等の引用文言は江戸往古図説経由の**二次引用**であり、原本の文言確認が前提。③「巣鴨西北よりねこまた橋の方」の流路とねこまた橋の位置（GAZ-083の氷川明神前）との接続の具体比定は未実施。④「皂莢原」読みの確定には写本原画像照合が必要（OCR読みと活字版の対校のみ）。⑤燕石十種の他輯（江戸座等）は水系と無関係のため未精読。
