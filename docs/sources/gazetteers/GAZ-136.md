# [GAZ-136] 町方書上[148] 根津 — 宮永町・門前町・社地門前の千川茂兵衛請負橋群と下水網・名水の文言

- **書誌〔確認〕**: 『町方書上[148] 根津町方書上 全』（写・NDL次世代デジタルライブラリー [book/2571629](https://lab.ndl.go.jp/dl/book/2571629)）。**根津宮永町条＝p5〜22（文政九戌年十月 行事 根津宮永町の起文）・根津門前町条＝p23〜33（戌十月 名主長右衛門）・根津社地門前条＝p34〜40（七月 根津社地門前 名主長〔右衛門候補〕の起文）の3町構成**（まとまった根津の地誌御調書上。p17-18は拝領屋敷の年次リストで水系文言なし）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571629_{NNNNNNN}.txt` コマ番号。**
- **宮永町条の橋群——布成橋・水戸殿附の無名橋・伊合橋〔文言候補・本冊の核心・布成橋・伊合橋はrepo初出候補〕（p19-21）**: ①「**壱ケ所 南之方 松平備後守様附に有之候下水...幅三間余有之 右御屋敷御掛二而復修復等仕 町内持には無御座候**」＝松平備後守様附の下水（幅3間余）・御屋敷御懸かり、②「**布成橋と唱 一町内戌ノ亥之方 根津門前町江相渡候橋本儀は 御公儀御普請ニ而 幅弐間渡リ弐間余有之 千川茂兵衛受負修復附来リ申候**」＝**布成橋（宮永町の戌亥〔北西〕方・根津門前町へ渡る橋・御公儀御普請で幅2間・渡り2間余・千川茂兵衛が請け負い修復を附けきたった）**、③「**一同 西之方 水戸殿附二有之候橋之儀は 幅修復致来リ申候 尤右橋之名無御座候**」＝水戸殿附の無名橋（同様の修復）、④「**一同 子之方横町ゟ根津門前町え相渡候橋之儀は 伊合橋と唱 津町(?=判読要照合)御武家方私共町内并根津門前町一同組合橋二而 幅弐間程憚り(=渡り候補・要照合)弐間余有之 被聞合修復仕来リ申候**」＝**伊合橋（子〔北〕方の横町から根津門前町へ渡る・御武家方＋当町＋根津門前町の一同組合橋・幅2間程・渡り2間余・聞合せの上修復）**。〔**①「布成橋」「伊合橋」の橋名＝repo初出候補＝水戸殿附無名橋だけが既知だった[GAZ-113]（御府内備考写本・根津宮永町条「千川茂是(茂兵衛候補)漸請負」）の元資料側の条に橋名2件が付く、②布成橋の「御公儀御普請」の建設主体文言＝[GOV-465](../gov/GOV-465.md)（天保撰要類集・根津4橋の懸替修復請負）や[GOV-211](../gov/GOV-211.md)（嘉永3年4橋）の橋負担史の上流側の基準点、③伊合橋＝[GAZ-113]の「組合橋（幅2間・渡り2間余・根津門前町へ渡る・隣町武家方＋当町＋根津以前町一同組合）」と同一橋と読むのが自然だが（寸法・渡先・組合構造の一致）正式な同定は原画像照合まで断定しない、④「伊合橋」の原字（伊合＝伊合?五十合?）は要照合**〕。
- **門前町条の大下水と板橋3ヶ所——御成橋（中之橋）・南板橋〔文言候補・御成橋の構造の具体化〕（p26-27）**: 「**根津宮永町地境 幅九尺余 堀割大下水に掛渡有之候 板揚(=板橋・OCR)三ケ所之内 中之橋は御成橋へ指留(=指留相当の文言候補・要照合) 長弐間幅弐間有之 同所南之方え寄候板橋は長七尺巾六尺有之 右弐ケ所共 千川茂兵衛請負ニ而掛置シ修覆共仕候**」＋「**同所東之方え寄候板橋は長弐間幅九尺有之 武家方頭取町方組合ニ而掛直シ修覆方仕 里俗ニ組合橋ニ相唱申候**」＝**①根津宮永町地境の堀割大下水（幅9尺余）に板橋3ヶ所、②うち中之橋＝御成橋（長2間・幅2間）と南寄りの板橋（長7尺・巾6尺）の2ヶ所は千川茂兵衛の請負で掛け置き・修覆、③東寄りの板橋（長2間・幅9尺）は武家方頭取・町方の組合で掛け直し・里俗に組合橋と唱える**。〔**「御成橋」の位置（宮永町地境の大下水・中之橋）と千川茂兵衛請負の範囲（御成橋＋南板橋）の文言＝[GAZ-113]宮永町条の「同所御成橋同様 千川茂是漸請負」の元資料側の実体の具体化。別条の西裏下水（下記）を含めた下水網全体の幅の系列（3間余・9尺余・3尺・1間・4尺等）も記録**〕。
- **宮永町条・門前町条の御成橋の願出の経緯〔文言候補・repo初出候補〕（p8・p28）**: ①（宮永町条 p8）「**根津御前(=宮永)町江相渡候御成橋 右之方ニ建有之 右は去ル文政五午年五月中 榊原主計頭様御番所え奉願上 見分之上 於御奉行所ニ願之通被仰付候**」＝**御成橋（宮永町から渡る）は文政5午年（1822）5月中に榊原主計頭様御番所へ願上げ・見分の上、御奉行所で願の通り仰し付けられた**（木戸番屋・自身番屋の文言と続く）。②（門前町条 p28）「**右橋之内 御成橋組合橋之外 名目小名里俗等無御座候**」＝御成橋・組合橋の他に橋の名目・小名・里俗はない、と門前町側から補う。〔**御成橋の「建」が御番所への願出・見分を経たものとする文言＝御成橋の管理史に文政5年5月の行政イベントの一点を加える文言候補（新規の「建」と修覆の願かは「建有之」の文意と前後関係からは確定しない）**〕。
- **門前町条の石橋3ヶ所・西裏下水の橋4ヶ所〔文言候補〕（p27-28）**: ①「**根津え別当屋敷地境に幅三尺之下水有之 右往来に巾八尺之長三尺程も石橋掛渡有之**」＝別当屋敷地境の幅3尺下水の石橋（巾8尺・長3尺）、②「**石橋三ケ所...里俗上横町二唱候通りニ掛有之候石橋 幅弐尺五寸長三尺五寸程 里俗中坂横町は唱候通りに掛有良(=リ)石橋 幅五尺五寸長四尺五寸程 里俗鳥居横町ゟ唱候通り掛有之江(=石?)橋 幅弐尺五寸長三尺余**」＝**上横町・中坂横町・鳥居横町の各通りの石橋3ヶ所（幅2尺5寸×長3尺5寸程・幅5尺5寸×長4尺5寸程・幅2尺5寸×長3尺余）**、③「**右下水續キ異(=北?・OCR候補)之方 根津宮永町地境大下水江落口 谷中善光寺坂通り往来 武家方地境に有之候板橋 壱ケ所は幅壱丈長弐間有之 千川茂兵衛請負には掛直シ修覆共仕候**」＝**大下水の落口・谷中善光寺坂通り往来・武家方地境の板橋（幅1丈・長2間）の千川茂兵衛請負の掛直し・修覆**、④「**町内西側町屋裏通りニ有之候下水者 西江寄候方に而幅壱間中程巾弐尺南之方落口は幅四尺程...右下水に掛有之候石橋板橋等...長三尺幅弐尺之板橋壱ケ所長四尺巾四尺也板摺(=板橋?OCR)壱ヶ所長三尺幅三尺之板橋壱ケ所長壱尺巾四尺之石橋壱ヶ所**」＝**西裏下水（幅1間・中程巾2尺・南落口幅4尺）に板橋3＋石橋1の4ヶ所**。〔**上横町・中坂横町・清水横町・鳥居横町・惣門横町の里俗横町群の名の由来が「下水堀の通り名」である構造の実態（通りごとに石橋がかかる）＝根津谷底の横丁と下水網の一体構造の定量記録（寸法群はOCR照合前提）**〕。
- **法境星稲荷（前掛稲荷）と名水の井戸〔文言候補・repo初出候補の社名〕（p29）**: 「**名水之井戸 町内西側 里俗清水横町と唱候横町角ゟ 西江寄町屋裏通りに 間口壱間奥行九尺程之稲荷之社有之 前に鳥居壱ケ所有之 **法境星稲荷**と申 里俗に前掛稲荷共相唱候 尤別当神主無之**」＝**清水横町角・西寄り町屋裏通りの稲荷社（間口1間・奥行9尺・鳥居1・別当神主なし）＝法境星稲荷（里俗に前掛稲荷）・「名水之井戸」の見出し語**。〔**①「法境星稲荷」の社名はrepo初出候補（「前掛稲荷」の里俗名との二重呼称・別当を持たない町内持の小社の実態）、②「名水之井戸」の見出し語が、（イ）井戸の項として記されたものか（ロ）稲荷社の立地記述の一部かはOCRの文脈から確定できないが、根津の谷頭の名水・井戸系の叙述として記録**〕。
- **七月十二日の根津権現惣門前の精霊棚・草物市〔文言候補・流域の年中行事の一次文言〕（p29）**: 「**七月十二日 町内往還 御成橋際ゟ町内中程迄 精霊棚江相備候品之幷 草物市 朝之内計相立申候...其市相始りし年代相知不申候**」＝**毎年7月12日・町内往還の御成橋際から町内中程まで精霊棚に備える品と草物（草花・野菜か）の市が朝の内だけ立つ、市の始まりの年代は知らない**（惣門・銅鳥居の文言が続き根津権現門前の記述）。〔**根津権現惣門前（御成橋際）の盆市（精霊棚用の市）の文政期の一次文言＝御成橋の位置アンカー（根津権現惣門・銅鳥居側の橋際）としても利用可**〕。
