# [GAZ-074] 牛込寺社書上五・済松禅寺（芳心院）条（文政期）— 雑司ヶ谷村20石の追加朱印文言と芳心院の高田村足高〔第149回〕

- **書誌〔確認〕**: 『寺社書上』（写・刊記なし。文政期の幕府による寺社御調書上の写本群の一冊）。NDL次世代デジタルライブラリー [book/2571389](https://lab.ndl.go.jp/dl/book/2571389)。**冊子冒頭文言「寺社書上 牛込寺社書上五 宗哲寺南蔵院持稲荷社妙照寺済松寺附芳心院大法寺半込〔 牛込の崩れ〕寺社書上九 二七六ノ第三十四」＝本冊は「牛込寺社書上五」で、牛込榎町の蔭涼山済松禅寺とその塔頭（芳心院・真証院・慈光院・恵講院・実性院・定光院・養春院）ほか（宗柏寺・稲荷社・妙照寺・大法寺等）の御調書上を綴ったもの**。書上末尾に「**以上 文政十亥年五月**」の年月文言（芳心院条）。「済松寺」の寺名は本文OCRで「海松寺」「済松寺」「浄松寺」「深松寺」に揺れ（いずれも蔭涼山済松禅寺の崩れ候補）。**書上はくずし字写本でOCRの崩れが非常に大きく、引用文言はすべて原画像照合を要する**。
- **済松禅寺と祖心尼〔確認・文言候補〕**: 牛込村の蔭涼山済松禅寺（臨済宗妙心寺派・開山・水南和尚・開基・祖心禅尼）。「**正保三戌年十月十一日…牛込村大橋立慶屋鋪を大半地〔 寺地の崩れ候補〕に被仰付**」「**蔭涼山済松禅寺者…祖心禅尼創造 以水南宿禅師為開山祖**」＝正保3年（1646）の家光の命による建立（棟札・語録・鐘銘等の引用が長く続く）。祖心尼は「**勢州田丸之城主牧村兵部太夫利貞娘**」で、町野長門守への再縁中に生まれた二人の娘の一人に「**お帰りの方**」がおり、「**お帰りの方は尾州霊仙院樣御母儀に而市ヶ谷自澄院〔 自證院・圓融寺の崩れ候補〕開基之由に御座候**」＝**「お帰りの方」が尾州家（霊仙院様＝義直候補）ゆかりの「御母儀」で、市ヶ谷の自證院（圓融寺〔GAZ-073〕）の開基である旨の記述**。〔「御母儀」の帰属（義直の母か、義直の御簾中・千代姫の母＝於振か）はOCR崩れを含み断定できない。圓融寺側の書上（〔GAZ-073〕）は千代姫の御母堂・於振の送葬を開基の縁起として記す。祖心尼と於振の姉妹関係（この記述が正しければ成立する）も含め、OCR崩れが大きいため原画像照合と系譜資料の対校を要する。〕
- **朱印地＝牛込村345石3斗余〔確認・文言候補〕**: 「**御朱印拝領高幷御文言 高三百四拾五石三斗余 右は大献院樣〔 大猷院=家光の崩れ候補〕御代正保四亥年十月十二日初而拝領仕候**」「**海松寺領武蔵国豊嶋郡牛込村之内三百四拾五石三斗余事 新寄附…寛文五年七月十一日御朱印**」＝**牛込村345石3斗余の本領（正保4年〔1647〕10月12日初拝領・寛文5年〔1665〕7月11日）**。
- **雑司ヶ谷村20石の追加朱印〔確認・文言候補・核心〕**: 「**常憲院樣〔 綱吉〕御代元禄十四巳年六月十三日堤頭二方心院分御書加拝領仕候 御朱印御文言 海松寺領武蔵国豊嶋郡牛込村之内三百四拾五石三斗餘之事…此外同郡雑司ヶ谷村之内弐拾召〔 弐拾石の崩れ〕今度令新加之是ハ芳心院可収納之…元禄十四年六月十三日御朱印**」＝**元禄14年（1701）6月13日の朱印文言に「豊嶋郡雑司ヶ谷村之内弐拾石」が「今度新加」され「芳心院収納」と明記された追加朱印の文言**。続けて「**有徳院樣〔 吉宗〕御代享保三戌年七月十一日拝領仕候御朱印御文言 浄松寺領…此外雑用ケ谷村之内弐拾召〔 雑司ヶ谷村・弐拾石の崩れ〕是ハ寺中二方心院〔 芳心院の崩れ〕可収納…享保三年七月十一日御朱印**」＝**享保3年（1718）にも同文言（雑司ヶ谷村20石・芳心院収納）で再発出**。〔「弐拾召」「雑用ケ谷」はOCR崩れ候補。元禄14年巳年・享保3年戌年の干支は整合。以後の朱印（延享4年・宝暦12年・天明8年）も文言同様と記す。〕
- **芳心院条＝雑司ヶ谷村20石と高田村足高〔確認・文言候補〕**: 済松寺境内塔頭・芳心院（開基・芳心〔俗名かね・家光の御奉公人→桂昌院の厚意で尼寺を建立〕・開祖・単心）の由緒書上——「**元禄三午年十一月廿二日桂昌院樣江被召…**」「**大融院樣〔 大猷院=家光の崩れ候補〕御霊屋済松寺境内江御造営付…御霊屋別当壱ヶ院御取立被遊度旨被仰候**」＝桂昌院（徳川綱吉生母）の意向で芳心院が家光の御霊屋（済松寺境内）の別当に任じられた経緯。「**巳年五月五日きい〔 人名の崩れ候補〕相果申候…徳昌院樣ゟ役楽肥前守殿後室光曜院殿御使ニ而被仰下候趣ハ…徳昌院樣依御願御朱印ニ而弐拾石可被成下候趣被仰下 則元禄十四巳年御朱印弐拾石 当国豊嶋郡雑司ケ谷村ニ而拝領仕 則済松寺御朱印壱紙江新御書加江被下置候 同年十二月収納仕候**」＝**元禄14年（1701）に20石の御朱印が豊島郡雑司ヶ谷村で拝領され、済松寺の御朱印一枚に新たに書き加えられた旨**。「**先々ゟ拝領仕候御扶持方ト取箇不足ニ付其趣奉願候処 右同郡高田村におゐて込高九拾四石余被下置候 其節御月番永井伊賀守殿御列席にて被仰渡 都合高百拾四石余拝領仕候**」＝**元禄15年（1702）に扶持方の不足を補う足高（込高94石余）が高田村で下し置かれ（御月番・永井伊賀守が仰渡・都合高114石余）**。〔芳心院条の独立の書上末尾にも「**御朱印高弐拾石 右者元禄十四巳年常憲院樣御代当国豊嶋郡雑司ヶ谷村におゐて済松寺御朱印一紙に御書加被下置候**」とある。〕
- **対照（風土記稿の領属変遷との整合）〔観察〕**: 風土記稿の雑司ヶ谷村条（〔GAZ-048⑭〕）の領属変遷「**元祿十四年牛込芳心院領に附られ**」と、本書上の元禄14年6月13日の「雑司ヶ谷村之内弐拾石・今度令新加之是ハ芳心院可収納之」の追加朱印文言は**同年次の対応**として読める＝**雑司ヶ谷村の一部（20石）が元禄14年に牛込芳心院の朱印地に追加された実務記録（朱印発給文言）**。同様に〔GAZ-073〕の圓融寺200石（正保4年〜）は風土記稿の「寛永十八年市ヶ谷自證院領」の朱印側対応候補。〔ただし風土記稿の「領」の表現と朱印地の高の全体像（村高のうち朱印地が占める割合）の整理は今後課題。〕
- **寺領村町地誌書上〔確認・文言候補〕**: 「**済松寺領村町地誌書上**」として「**武州豊嶋郡牛込村之内** 本領…**手領地所 武蔵国豊嶋郡下戸塚村 早稲田村 高田村 中里村 同国同郡中里村町 高田四ツ家町 伊稲田町〔 稲田町の崩れ候補〕 馬場下町 馬場下横町 榎町 天神町 原町壱丁目 同弐丁目 同三丁目 築地片町**」＝**元禄15年9月の御扶持方（寺領）の村町名帳**（高田馬場・御給皇辻番所の享保6年廃止・高田四ツ家町の享保13年頃町屋化・中里村町の延享2年町奉行支配化などの沿革書上を含む）。〔高田村・下戸塚村・早稲田村は神田上水・千川上水流域の村で、水窪川・弦巻川周辺の村名（雑司ヶ谷・高田）の領有構造の背景資料。本書の水系直接文言（谷端川・弦巻川・千川・神田上水の流路記事）はない。〕

## 制限・未解決

- ①書上はくずし字写本でOCRの崩れが非常に大きい（寺名の「海松寺/済松寺/浄松寺/深松寺」揺れ、「弐拾召」「雑用ケ谷」「堤頭二方心院」「大献院樣/大融院樣」等はいずれも崩れ候補）。引用文言は原画像照合を要する。特に「弐拾召」が「弐拾石」であること・「雑用ケ谷」が「雑司ヶ谷」であることは文脈（芳心院収納・風土記稿の元禄14年芳心院領との整合）から強く支持されるが、OCRレベルでは断定しない。②祖心尼の系譜（牧村利貞娘・町野長門守への再縁・娘のお帰りの方＝市ヶ谷自證院開基の由の記述）はOCR崩れが激しく、「御母儀」の帰属（義直の母か千代姫の母＝於振か）・祖心尼と於振の姉妹関係を含め原画像照合と系譜資料の対校を要する。③桂昌院・徳昌院・光曜院殿等の院号のOCR判読（桂昌院=綱吉生母・徳昌院は桂昌院の別称候補）は要照合。④雑司ヶ谷村20石の位置（村内のどこか）は本書上からは特定できない。⑤高田村の込高94石余の位置も特定できない（水窪川源流域の高田村一字水窪との関係は今後の検討課題）。⑥同冊内の他寺条（宗柏寺・大法寺・稲荷社・妙照寺等）は水系と無関係のため精査していない。⑦元禄14年以前の雑司ヶ谷村の芳心院への「寄進」の経緯（桂昌院の御願の主体・「今度令新加之」の実務）の詳細は本書上の由緒譚（OCR崩れ大）に依存し、原画像照合を要する。
