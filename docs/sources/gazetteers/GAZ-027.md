# [GAZ-027] 江戸砂子温故名蹟誌（明和9年・1772）— 弦巻川の明和期の独立項目

- **書誌〔確認〕**: 『江戸砂子温故名蹟誌』6巻（**明和9年〔1772年〕**の序・江戸の名所・旧跡を項目立てで記す地誌）。NDL次世代デジタルライブラリーに同一書の抄本2点（[book/2565900](https://lab.ndl.go.jp/dl/book/2565900)・[book/2563640](https://lab.ndl.go.jp/dl/book/2563640)）が公開され、いずれも雑司ヶ谷関係条のOCRテキストで弦巻川を確認した。**すべての引用はくずし字OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **弦巻川の独立項目〔確認・repo初出の重要文言〕**: 雑司ヶ谷条に「**○弦巻川 法明寺前の細流をいふ そのゆへをしらす（そのゆえを知らず）**」＝**1772年刊の地誌に弦巻川の独立項目があり、①「法明寺前の細流」という位置記述、②当時すでに川名の由来が「知らず」と明記される**。〔文言はOCR要照合〕 **「法明寺前の細流」は新編武蔵風土記稿（文化〜文政期成立・[GAZ-015](GAZ-015.md)文脈）の弦巻川記述と同じ定型文言であり、この文言の系譜が明和9年にさかのぼることを示す**。また**「そのゆえを知らず」は、義家の弓の弦を巻いたことに由来する説（[BOOK-119](../books/BOOK-119.md)系統・後世の区史等に見える由来说）が1772年時点では地誌に載っていなかったことの傍証材料**となる〔由来説の否定・成立年代の特定としては扱わず、記録の差として保存〕。
- **星跡清水＝弦巻川の下流〔確認・repo初出の帰属文言〕**: 「**○星跡清水 護国寺と雑司谷の田の中一の茂松あり 里諺に曰鬼子母神出現の所也と証（つ）まき川の流のしも也**」＝鬼子母神出現伝承の星跡清水が**弦巻川の下流**にあると明記＝星跡清水の弦巻川水系帰属の明和期の記述。〔OCR要照合〕
- **雑司谷八境の弦巻川・蛍〔確認・repo初出〕**: 「**雑司谷八境**」の列挙（「星弥清水・御嶽・夜雪・姿見橋・医・**弦巻川・蛍**・威光山…三島・神籬山・木・玉池」）に**弦巻川と蛍**が含まれる＝**雑司ヶ谷の名所として弦巻川が数えられた1772年の記録**。〔OCR列崩れのため語列の正確な並び・八境の構成語は原文照合まで断定しない。「蛍」の列挙は[BOOK-113](../books/BOOK-113.md)（1890年・漢詩「弦巻川観螢」）に先行する螢関連の語列候補として記録〕
- **その他〔確認・要照合〕**: 「**鼠山 名（棒）林池 か（谷）谷ともに長崎村のうち也**」「○戸塚高田の事也…」など、長崎村・高田方面の地名記事も続き、弦巻川・谷端川両源流域の地名の江戸期記録として利用できる。
