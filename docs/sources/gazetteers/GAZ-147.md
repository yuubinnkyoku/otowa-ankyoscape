# [GAZ-147] 町方書上[33]（赤坂壱）— 玉川上水の高札文言写・伊賀屋210年見廻り・弁慶堀の寛永年中文言

- **書誌〔確認〕**: 御府内備考編纂の基礎資料となる**町方書上**の一本（表紙文言「二七四ノ第三十三」＝目録番号[33]候補・赤坂町方書上三口の壱冊目。本冊104頁に元赤坂町・表伝馬町壱〜弐丁目・裏伝馬町壱〜弐丁目の書上を収録）。NDL次世代デジタルライブラリー [book/2571513](https://lab.ndl.go.jp/dl/book/2571513)。各町の書上末尾に「**文政十亥年七月**」の起文が繰り返し現れ、書上の提出が文政10年（1827）7月であることがOCRで確認できた（要原文照合）。**[GAZ-116](GAZ-116.md)（御府内備考巻67-69赤坂・2553682）の元資料側**に当たる（内容が広く重複するため、本ファイルではGAZ-116既収録と対校しない既収録文言の再掲は避け、①GAZ-116に採録されていない文言、②元資料側としての対校価値が高い文言に限って記録する）。**すべての引用はOCR由来で、文言は原文画像との照合を要する**。
- **玉川上水端の高札の御文言の写〔文言候補・repo初出候補〕**: 元赤坂町条「**一 高札壱ヶ所 紀伊国坂下御上水端に建有之 御文言之写 定 此上水道にて魚を取 水をあひ 塵あくた捨る輩あらは 曲物(=事・OCR候補)たるへき者や **元文四己未年十二月 奉行** 但し竪壱尺五寸 横巾弐尺 駒寄三尺四方 右高札之儀は 御普請方御役所御掛り二而 建始り年代等相分り不申候 修覆建直之節者 除地預り人 伊賀屋半次郎ゟ申立候**」＋表伝馬町条「**一 高札壱ケ所 右は町内北之方御堀端土手に相建有之 但御文言左之通 □□ 此上水道に而魚を取 水をあひ 塵あくた捨る輩あらは 曲事たるへき者也 元文四己未年十二月奉行 但札竪壱尺五寸横幅弐尺駒寄三尺四方 右高札之儀は 御普請方御役所御懸りに而建始り年代等相分り不申 修復建直し之節は 土手預り人元赤坂町家主伊賀屋半次郎ゟ申立候**」＝**①玉川上水端（紀伊国坂下・御堀端土手）に建てられた高札の文言の写：「此上水道にて魚を取・水をあひ（水を浴びる候補・要照合）・塵あくた捨る輩あらは曲事たるへき者」＝**玉川上水での魚捕り・水浴・塵芥投棄の禁止という水質保護規制の文言全文**、②年記「元文四己未年（1739）十二月奉行」（元文4年=己未で干支整合）、③高札の寸法（竪1尺5寸・横巾2尺・駒寄3尺四方）、④建て始めは御普請方御役所掛かり（建始の年代は不知と言う）、⑤修覆・建直しの際は除地（土手）預り人の伊賀屋半次郎が申立てる**＝**玉川上水の水質管理高札の文言写・寸法・維持責任まで揃った一次記録の文言候補（[GAZ-116](GAZ-116.md)未採録・repo初出候補）**。〔上水の法的規制の実態資料。神田上水側の高札・掲示文言群との対校の着地点。「水をあひ」の原字形（あびる候補・「相扇」等の別字候補）は原画像照合前提〕。
- **伊賀屋半次郎家の玉川上水端見廻りの由緒——凡210年余の相預りと支配移管の3段階〔文言候補・repo初出の系譜文言〕**: 元赤坂町条「**御預り地伊賀屋半次郎 紀伊国坂下御堀端ゟ赤坂御門下玉川稲荷脇迄 御上水端土手通り凡長百八拾間余 右半次郎先祖茂右衛門と申者 先年水役玉川庄右衛門 同(=玉川?)清右衛衛門懇意に付 **寛永年中ゟ相預り 平生見廻り 御上水芥留(=芥溜?・OCR)致し 芥取揚 草刈掃除等仕来候處 元文年中町御奉行石河土佐守様 御上水御掛り相成候節 町年寄衆ゟ御尋に付 前書之趣申立 猶又引続右之場所御預ケ被仰付 然る処 明和年中御普請方御掛り二相成 其節も右之段申上奉願上候得は 御預ヶ被仰付 右場所見廻り芥取揚草苅掃除等仕来候 其餘御堀浮物為取上ケ舟差入之儀相願候処 願之通被仰付候** 尤書留等有之候得共 度々類焼二而焼失仕 **尤当半次郎迄凡弐百拾年余御預り申上** 芥取揚草苅掃除等仕来候**」＝**①伊賀屋半次郎の預り地＝紀伊国坂下御堀端から赤坂御門下玉川稲荷脇までの玉川上水端土手通り凡長180間余、②先祖茂右衛門が玉川上水の水役（玉川庄右衛門・清右衛門）と懇意であったことに由来する寛永年中からの相預り、③**元文中に町奉行石河土佐守が上水御掛りとなった際に町年寄衆の御尋で申立により引き続き預けられ、④明和中に御普請方御掛りとなった際にも願いにより引き続き預かる**という支配移管の3段階、⑤御堀の浮物取上のための舟差入願いの許可、⑥当半次郎まで凡210年余の相預り（寛永〔1644-48〕〜文政10〔1827〕≒183年前後で「210年余」は申伝の誇張か先祖系譜の遡及か・要照合）、⑦書留は度々の類焼で焼失**＝**伊賀屋家の玉川上水端の見廻り・芥取揚・草苅の管理業務（[GAZ-116](GAZ-116.md)の蓮の御用・弁慶堀の預かり文言に続く管理系譜の補完）と、上水の支配が寛永系（水役懇意）→元文中（町奉行石河土佐守）→明和中（御普請方）へ移ったという支配移ポート列の町方側申伝（repo初出候補）**。〔**元文中の石河土佐守の「上水御掛り化」は、[GOV-423](../gov/GOV-423.md)の元文4年10月3日・石河土佐守付の玉川上水改方見廻り役起立（下高井戸村名主源太左衛門・小川村名主弥次郎）と[GOV-170](../gov/GOV-170.md)の同年月日付の分水32ヶ所伺（石河土佐守御附紙）に対応する町方側の言及候補**＝元文4年10月3日の玉川上水管理体制の一斉整備を民間預り人側の申伝からも示唆する対校材料（同一事件かは文言の照合まで断定しない）。「玉川庄右衛門・清右衛門」は玉川上水開削の玉川庄右衛門家（藤右衛門系）の人名層と対応候補（比定は保留）〕。
- **弁慶堀の名義文言——「寛永年中堀割」文言と「一説も有之」の保留〔文言候補・年次対立の新witness〕**: ①元赤坂町条「**弁慶堀と唱候御堀之儀は 幅凡五拾間程に而喰違ひゟ赤坂御門際迄凡長三百間余 右唱候儀は 弁慶小右衛門と申者 **寛永年中**堀割御請負仕候由 右二付弁慶堀之唱来候由申伝に御座候**」、②裏伝馬町条「**但し弁慶堀と相唱候義は 赤坂御門外北之方御堀と 往古御堀割之節 奥名弁慶小右衛門と申者請負堀割候付 弁慶堀と相唱候由 **一説も有之候得共 聢(=確?)と相分り不申候***」＝**①弁慶堀（幅凡50間程・喰違から赤坂御門際まで凡長300間余）の名義＝弁慶小右衛門が堀割を御請負したことに由来、②**元赤坂町条は年次を「寛永年中」とする**のに対し[GAZ-116](GAZ-116.md)（御府内備考版）の同系文言は「**宝永年中**堀割御請負」と読める＝**寛永年中 vs 宝永年中の堀割請負年次の対立が新たに成立（元資料側〔町方書上〕と御府内備考側〔編纂本〕のあいだの対立で、どちらが編纂時に書き換えられたかは原画像照合まで決めない）**、③裏伝馬町条は人名由来説に「一説も有之候得共聢と相分り不申候」の保留文言を付す＝**弁慶堀名義説が町方側でも確定していないことの一次文言（名義聴取の実態がうかがえる）**。〔弁慶堀の名義（人名説）・幅尺は[GAZ-116](GAZ-116.md)既収録のため、本件は「寛永年中」文言と保留文言のwitness分として記録〕。
- **桜川・赤坂川の名義併存と湯光寺の「証ケ渕」〔文言候補・元資料側witness＋小池名repo初出候補〕**: 裏伝馬町壱丁目条（p72-73）「**一大下水 右は元鮫河橋ゟ紀州様御屋敷内え懸り 町内裏通りゟ表伝馬町壱丁目之方え相流し申候 大下水に而往古は川に而御座候哉 紀州様御屋敷内大下水辺りに桜之木有之 右桜花落散下水江相流レ候ニ付 先年ハ桜川とも相唱候由 又は地名に付往古は**赤坂川**と申候哉 聢と相分り不申候 幅六尺有之 堀割之年代相知レ不申候**」＋元赤坂町条（p19-20）「**横切大下水之儀は 西南之方紀州様御囲込地際ゟ幅平均六尺ニ而 紀州様御屋敷付石橋際ゟ赤坂裏伝馬町壱丁目竹矢来際迄 凡長百四拾間半余 水上鮫河橋 湯光寺内**証ケ渕**と申小さき地有之 右池ゟ紀州様御屋敷内え入 夫ゟ当町江出 同所裏伝馬町壱丁目江相掛 同所田町河岸通りゟ泊池端板坂江出夫ゟ桜川江落申候 右は往古此辺二而赤坂川と打唱候由申伝候**」＝**①裏伝馬町条の大下水（元鮫河橋→紀州様御屋敷内→裏通り→表伝馬町壱丁目方）の「桜川」呼称の由来文言（紀州様御屋敷内大下水辺りの桜の花が落散して下水に流れたため）と「往古は赤坂川と申候哉」（地名由来説）の併記＋「聢と相分り不申候」の保留**＝[GAZ-116](GAZ-116.md)の桜川名義文言の元資料側witness（四谷の桜川〔[GAZ-112](GAZ-112.md)系〕とは別の赤坂側の桜川であることに注意）、②元赤坂町条の横切大下水文言に見える**湯光寺内の「証ケ渕」と申小さき地（池）**＝水上は鮫河橋・湯光寺内の証ケ渕→紀州様御屋敷内→当町（元赤坂町）→裏伝馬町壱丁目→田町河岸通り→泊池端板坂→桜川へ落つる、という流路の一次文言候補（repo初出候補の小池名）**。〔「証ケ渕」「湯光寺」（桶煎寺等の別号候補）の原字形は要原文照合。横切大下水（凡長142間半余・巾平均6尺）もGAZ-116の大下水文言と対校候補〕。
- **その他の読取点〔文言候補・対校witness〕**: ①玉川御上水「町内北裏土手中通り**万年石垣樋**有之 幅六尺程而已 イ国坂通りゟ相流レ 表伝而町壱丁目ゟ埋樋二相成候」＝[GAZ-116](GAZ-116.md)・[GOV-280](../gov/GOV-280.md)等の万年石垣樋文言の元資料側witness、②天和年中の石橋御懸ケ替＋享保4亥年8月朽木丹後守の節からの町内負担化（「古来ゟ有来 長五尺巾弐間四尺余 御公儀橋にて先年は板橋に有之 天和年中石橋ニ御懸ケ替被下置候処 享保四亥年八月中御普請奉行朽木丹後守様御勘役之節ゟ自今修復之義は町内に而可仕旨被仰渡候」）＝[GAZ-116]既収録文言の元資料側witness、③弁慶堀の御堀端〜御上水間と御上水〜大下水間の土手2ヶ所（玉川稲荷際〜紀伊国坂下まで長180間・御普請方御持場だが御堀常渡請負人伊賀屋半次郎が先年から御預かり）＝伊賀屋預かり地两条（前記の由緒文言と対）、④きりしたん宗門禁制の高札文言の全写（享保6丑年8月大岡越前守の建替・「正徳元年五月奉行」の文言・伝馬町・田町拾ヶ町の御預かり）等も同冊に見える（[GAZ-146](GAZ-146.md)渋谷冊の高札文言と同種の文言写の例）。

## 制限・未解決

- ①すべてOCR由来で特に「曲物たるへき」「水をあひ」「芥留」「聢と」「証ケ渕」「湯光寺」等の原字形は原画像照合を要する。②元文4己未年の高札文言と元文年中の石河土佐守上水御掛り化（伊賀屋由緒文言）の対応（同一年の制度パッケージか）は対校候補の域を出ない。③「凡210年余」の相預り期間と寛永年間の起算は整合せず（寛永末1648→文政101827で凡179年）、書上の申伝の誇張・先祖追認の可能性が残る（断定しない）。④弁慶堀の堀割年次「寛永年中」〔本冊〕vs「宝永年中」〔GAZ-116御府内備考版〕の対立の決着は原画像の両照合まで保留。⑤高札の「建始り年代相分り不申」文言と元文4年12月の年記の関係（年記が建札年か文言の奉行年か）は不明。
