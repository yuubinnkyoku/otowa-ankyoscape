# [GAZ-018] 『御府内備考』巻之四十七「小日向之三」（大日本地誌大系 第3巻）

- 書誌：大日本地誌大系 第3巻 御府内備考（雄山閣、昭和6年、NDLJP:1214872、インターネット公開）。巻之四十七「小日向之三」はコマ10〜16（印刷頁1〜12）。収録は五軒町・若荷谷町・第六天前町・金剛寺門前・三軒町・林泉寺門前・清水谷町・清岸寺門前・正智院前町。
- 2026-10-30、NDL刊本画像とビューア全文検索の照合による読取（ai）。節の開始は見出しのあるコマで示す。読みに確信の持てない字はその旨を記す。

## 内容メモ（水関係の項目のみ。解釈は書かない）

- 若荷谷町（コマ11）：下水の項に、町内西南の境の下水堀が五軒町方から悪水として流れ、切支丹御組屋敷の後を通る御上水の上掛樋へ流れる旨がある（「掛樋」の字は画像とOCRで揺れがあり要再確認）。坂の項には、馬場六之助様御抱屋敷内に古池があるとの言及がある（池を項目名とする記述ではない）。
- 第六天前町（コマ12）：下水の項に、町内西南から流れて御組屋敷境の大下水へ落ち、御上水の上の箱樋へ流れる旨、箱樋は御普請方の持ちである旨がある。
- 清水谷町・正智院前町付近（コマ15）：下水の項に、軒下雨落下水が石畳の橋の下を徳雲寺地内の方へ通じ、水谷へ流入する大きな下水の記述がある。ただしこの項の町帰属（清水谷町か正智院前町か）は頁を跨ぐため未確定。
- 正智院前町飛地（コマ16）：下水が正智院境内裏の方から流れ、小石川御簞笥町を折れ曲がって南へ流れる旨がある。
- 「池」を項目名とする記述は巻之四十七にはない。「用水」の語も現れず、水道は「御上水」と記される。
- 小日向台町は独立節がなく、コマ13で住居者の住所として「小日向臺町」の言及が1件あるのみ。小日向松ヶ枝町は第3巻（巻之四十七〜七十四）の全文検索で該当がなく、小日向之一・之二（第2巻側）の可能性は未確認。
