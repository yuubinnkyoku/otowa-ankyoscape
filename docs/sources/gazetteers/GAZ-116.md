# [GAZ-116] 御府内備考 巻67-69（赤坂之一〜三・写本OCR）— 白堀通樋の請負人服部屋清右衛門と赤坂側の上水・大下水の記録群

- **書誌〔確認〕**: 『御府内備考』巻之六十七〜六十九（赤坂之一〔総説・一ツ木関係〕〜赤坂之三〔新町・溜池端芝代地群〕）。NDL lab [book/2553682](https://lab.ndl.go.jp/dl/book/2553682)。条末に「**丁亥書上**」「丙戌書上」等の混在（文政9-12年頃・書上次第は要照合）。**引用文言はすべてくずし字OCR由来で原画像照合を要する。**
- **本登録の性格**: 赤坂は四河川（水窪・弦巻・谷端・千川）の流域外だが、①**明暦2年（1656）の神田御上水「白堀」通樋の請負人・服部屋清右衛門の拝借地記録**＝白堀（神田上水の小石川区間の通称）の樋の請負史の実名一次記録（repo初出候補・対照表の白堀行に直結）、②**赤坂総説の玉川上水流路文言（文化8年改掘つき）**と元赤坂町条の**万年石埋樋（巾6尺）**＝四谷の万年石樋（[GAZ-112](GAZ-112.md)）と同系統・同寸法の玉川上水埋樋記事、③**伝馬町条の大下水＝往古「赤坂川」・桜川の名称系統**＝四谷桜川（[GAZ-110](GAZ-110.md)・[GAZ-112](GAZ-112.md)）と同名異流の赤坂桜川と「赤坂川」の旧称記録、の3層を、四河川研究の対校材料として登録する。併せて弁慶堀（[GAZ-111](GAZ-111.md)の里俗名文言の実態側）・享保年中の新規大下水の請負人池の石橋・土橋群（橋名調査の追補材料）を収める。

- **南伝馬町（田町五丁目条所収）の白堀通樋請負人・服部屋清右衛門の拝借地〔文言候補・本登録の核心・repo初出候補〕**: 「**明暦二申年中神田御上水白堀通樋請負人服部屋清右衛門拝借地ニ而同続 右地面裏明地巾弐間長三拾七間余是又同人拝借地ニ有之 其後服部屋大是漸(＝代?OCR)引続弐ヶ所共拝借罷在候処 明和七亥年四月中町御奉行牧野大隅守様曲淵甲斐守様御普請奉行夏日和泉守様御勤役中右地所弐ヶ所共上り地二相成御普請方御役所え御引渡相成候**」＝**①明暦2年（1656）に神田御上水の白堀の「通樋」の請負人であった服部屋清右衛門が（当地（田町五丁目）の）地面を拝借地として受けたこと、②裏明地（巾2間・長37間余）も同人の拝借地であったこと、③その後服部屋大是漸（대是漸＝名字・清右衛門の後継か・判読要照合）が引き続き2ヶ所を拝借していたが、明和7年（1771）4月に町奉行牧野大隅守・曲淵甲斐守・普請奉行夏日和泉守の勤役中に2ヶ所とも上り地（上地）となり御普請方役所へ引き渡されたこと**。〔**白堀（神田御上水）の通樋請負人の実名と、その請負人が拝借地として屋敷地を持っていたという樋請負と土地利用の実務記録。repoの白堀研究（対照表の白堀行・[GAZ-050](GAZ-050.md)等の神田上水留史料・明暦年間の神田上水整備史）に、請負人側の一次人名記録を加える。明暦2年＝神田上水の開削初期（寛文2年完成以前の整備期）にあたり、白堀区間の樋の維持管理を請負人制度で行っていた時期の記録として年代層が古い。田町五丁目＝元は海禅寺(?)周辺か・条帰属細部は要照合**〕。
- **赤坂総説の玉川上水流路文言（文化8年改掘）〔文言候補〕**: 「**玉川上水 喰違(＝喰違)外元赤坂町の辺より御堀端明地の内を堀通し 表伝馬町壱町目より埋樋となり それより又溜池明地内を流れて南の方葵坂上に達す 此上水元は大下水の西を流れしか水利不便なるにより文化八年今のことく堀改められしなり**」＝**玉川上水が元赤坂町の辺から御堀端明地の内を堀通し、表伝馬町1丁目から埋樋となり、溜池明地内を流れて葵坂上に達すること、および元は大下水の西を流れていたが水利不便のため文化8年（1811）に今のように堀改められた旨**。〔**玉川上水の赤坂区間（四谷からの延長：大木戸→四谷万年石樋〔[GAZ-112](GAZ-112.md)〕→赤坂喰違→元赤坂町→表伝馬町1丁目埋樋→溜池明地→葵坂上）の集成側流路記録＋文化8年改掘の年代定点**。同一テキストに大下水の記事（紀伊殿御屋敷→元赤坂町・表伝馬町1丁目→田町1丁目明地→葵坂辺→溜池合流）・江戸砂子所引「**赤坂川は鮫河橋の方より来りて流末桜川に落ると書しは此大下水の事なり**」の按語が続く＝**「赤坂川」の旧称と大下水の同一視の集成側系統文言**〕。
- **元赤坂町条の万年石埋樋〔文言候補・四谷の万年石樋と同寸法〕**: 「**玉川御上水巾六尺程右赤町内北裏土手中通万年石埋樋有之 紀伊国坂通ヨリ相流表伝馬町壱町目より埋樋ニ相成申候**」＝**元赤坂町内の北裏土手中通・巾6尺程の「万年石埋樋」があり、紀伊国坂通から相流し、表伝馬町1丁目より埋樋となる**。〔**「万年石樋」の語（[GAZ-112](GAZ-112.md)四谷伝馬町壱丁目条＝巾6尺・[GAZ-111](GAZ-111.md)）の赤坂側出現。巾6尺が四谷例と同一＝玉川上水の幹線埋樋の標準寸法の対校点**〕。
- **伝馬町条の大下水と桜川・赤坂川の名称系統〔文言候補・対照表の対校〕**: 表伝馬町壱丁目条「**大下水 右は元鮫河橋ゟ紀州様御屋鋪内江…表伝馬町壱丁目之方江相流申候 往古者河ニ而御座候**」＋元赤坂町条「**江戸中小池有之右池ゟ紀州様御屋敷内え入夫より当町江出同所裏伝馬町壱町目江相橋同所田町河岸通より溜池神榎坂え出夫より桜川江落申候 右は往古此辺に而赤坂川と相唱候由申伝候**」＋「**往古者河ニ而御座候 成紀州様御屋敷内大下水辺二桜之木有之右桜花落散下水江相流候付先年者桜川とも相唱候由 又者地名二付往古者赤坂川と申候哉聢と相分不申候**」＝**①紀州様御屋敷内の池（江戸中小池）から出水し当町へ出て裏伝馬町1丁目に橋を架け、田町河岸通から溜池・榎坂を経て桜川へ落る大下水が「往古は赤坂川と唱えた」という申伝、②屋敷内の大下水辺の桜の花が流れ散ったので先年は桜川とも唱えた由、③「赤坂川」の名称が地名由来かは「聢と相分不申」と留保する文言**。〔**①往古の赤坂側の大下水の旧称「赤坂川」（repo初出候補・対照表の新行候補）、②赤坂桜川の名称由来（桜の花）＝四谷の桜川（[GAZ-110](GAZ-110.md)・[GAZ-112](GAZ-112.md)）と同名異流の注意を要する川名で、由来伝承は四谷側（素性法師の錦・柳川系）と別系統**。大下水の全流路（鮫河橋→紀州屋敷内池→裏伝馬町→田町河岸通→溜池・榎坂→桜川）の定点記録としても、赤坂の水系復元の基礎史料〕。
