# [GAZ-156] 町方書上[19] 西久保全（文政10亥年）— 玉川上水引請樋の縮小運用と城山・熊谷橋文言群

- **書誌〔確認〕**: 『[19] 西久保町方書上　全』（写・NDL次世代デジタルライブラリー [book/2571500](https://lab.ndl.go.jp/dl/book/2571500)）。文政10亥年（1827）九月付けの地誌御調書上で、西久保新下谷町・車坂町・葺手町（見出しOCR「暮年町」）・神谷町・天徳寺門前町・大養寺門前・普門院門前・同朋町等を収録。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571500_{NNNNNNN}.txt`）。※西久保の下水群は芝側（古川・汐留系）の水系で当repo四河川の直接流域には含まれないが、①の玉川上水系文言（引請樋）と周辺系の記録整理のため採録する（[2571506]鮫河橋〔第229回ノート参照〕と同様の周辺系の扱い）。
- **新下谷町条の玉川上水引請樋の運用変遷文言〔文言候補・本冊最重要〕（p6-13）**: 「**一町内玉川上木〔=上水OCR〕 古来ゟ引請申候 最初上水請候年代相知不申候 尤藪小路通右上水御組合垣ゟ水口ヲ付 町内え森坂町請来候〔OCR・崩し要照合〕 引請樋間数弐百拾八間之場所 明和七寅年 右水口之内百三拾間不用仕 水口差止 残候八拾八間之場所ハ 同御組合別樋筋ニ而 町内家主弥右衛門表井戸江請来候処 右井戸え水口ヲ付 右八拾八間之場所え引請申度 水口付替之儀 同年六月廿一日 町内同断事久兵衛 平坂町同役事儀兵衛ゟ 御普請方御奉行久松筑前守様御役所え奉行 同閏六月十七日 同御役所ニ而〔願済〕…只今八拾八間之場所引請申候**」（p13・OCR・主な人名・町名は要照合）＝**①町内（西久保新下谷町）は古くから玉川上水を引請（受水）しており、最初の受水の年代は不知、②藪小路通の右上水の御組合垣から水口を付け、【森坂町】（OCR崩れ・要照合）経由で町内へ請来した引請樋は218間、③明和7寅年（1770）に水口のうち130間を不用として水口を差止め、④残る88間は御組合の別樋筋から町内家主弥右衛門の表井戸へ請来ていたが、右井戸に水口を付けた上で88間へ引請る旨の水口付替願いを同年6月21日（町内・久兵衛、平坂町・儀兵衛から御普請方御奉行久松筑前守様御役所へ）に奉り、閏6月17日に願済、⑤現在も88間で上水を引請している**という運用変遷の文言候補。〔**玉川上水の末端（市区への受水）が明和7年に218間→88間へ縮小された実務記録＝上水の供給縮小・樋の延長減少の町方側の一次記録候補**。明和7年は千川上水系の諸差止（天明年間）や三田上水の差止とも時期が近く（[GAZ-157](GAZ-157.md)伊皿子台町条の享保7年差止文言等と併せて）、玉川上水系の末端の再編の年次整理の材料。樋の「間数＝218間」は樋の長さ・延長の単位で、130間が「不用」となった理由（水量減・不採算等）は本文言には書かれず未解決。「藪小路通」「森坂町」の位置の比定（藪小路＝麹町側の通り候補・OCR照合前提）も要課題。〕
- **葺手町条の城山里俗文言＝熊谷次郎直実城跡伝承〔文言候補・repo初出候補〕（p37-40）**: 「**一里俗之唱 城山 右ハ当町後 御砂石場上山之所 熊谷次郎直実城許之由二而 葺手町西横町 江戸見坂上え之往還ヲ一圓ニ相唱申候**」（p40・OCR）＝**葺手町の里俗の唱「城山」＝当町の後方の御砂石場の上山の所で、熊谷次郎直実の城跡と申伝えることに由来し、葺手町西横町〜江戸見坂上えの往還を一圓に（その区域一帯を）城山と唱える**という文言候補。〔**葺手町・神谷町後方の砂利場・御用山の区域の里俗名「城山」と熊谷直実城跡伝承の記録**（熊谷直実の武蔵の居城伝承には複数の系統があり、比定はしない）。「江戸見坂」「葺手町」の坂・通り名の用例も記録される（江戸見坂は現在の慈恵医大周边の坂との重なり候補・要照合）。地名対照表の城山行（第229回新設）参照。〕
- **神谷町条の熊谷橋・石橋2ヶ所・鳫金之井・精霊棚の文言群〔文言候補・repo初出候補〕（p53-66）**: ①「**〔下水ハ〕東え掛 天徳寺裏門前町え相流申候 長壱丈 一熊谷橋 巾四間 但石橋 右ハ町内北之方ニ御座候 横切レ下水ニ掛有之候 尤葺手町境 西横町ヲ一圓ニ城山ト里俗ニ相唱 熊谷次郎直実火之城跡之由申伝候ニ付 熊谷橋ト相唱候由申伝候**」（p65・OCR）＝**神谷町の北之方の下水（天徳寺裏門前町へ相流）に掛かる石橋「熊谷橋」＝巾四間。葺手町境の西横町を一圓に城山と唱え、熊谷次郎直実の火之城跡の由申伝に付熊谷橋と唱える**。②「**石橋長サ壱間 横巾三間 右ハ町内東側中程 芝切通江之往還入口 横切レ下水ニ掛有之候 尤名目無御座候**」＝**町内東側中程・芝切通往還入口の下水（巾三尺）に掛かる無名の石橋（長1間・巾3間）**。③「**一鳫金之井**」（p65-66・文言の本体は要照合）＝井名候補。④「**毎年七月十二日朝 町内熊谷橋辺ゟ 葺手町え掛 南北え弐丁程之間 精霊棚江相備候 草物等商売仕候 建始年月相分不申候**」（p58・OCR）＝**毎年7月12日朝、熊谷橋辺から葺手町へ南北2丁程の間に精霊棚（盆の精霊棚の市）の草物商売が出る（建始の年月は不知）**。〔**①熊谷橋の名の由来語（城山・熊谷直実伝承とセット）と位置（神谷町北之方・巾4間の石橋）は、橋名対照に加わるrepo初出候補**（橋の名目的な特性＝伝承由来の里俗橋名）。②芝切通入口の無名石橋・下水の構造記録。③鳫金之井は井名候補（「鳫金」の原字は要照合）。④熊谷橋辺の精霊棚の市＝橋近辺の盆市の実務記録で、橋の位置（葺手町への2丁の沿道）の補助情報。〕
- **葺手町条の城山稲荷（元禄4年引移）〔文言候補・参考〕（p44-46）**: 「**尤城山稲荷ト相唱 右本社拝殿等之修復新規共 町内持ニ御座候**」＋「**右稲荷之儀ハ当時 松平右近将監様御囲外御預場之内 御沙山中段 当時之場所ニ御所々ゟ勤請仕有之候由ニ而 元禄四未年 町内当所江引移候砌ゟ為火除 例年二月初午ニ祭礼執行仕候**」（p46・OCR）＝**城山稲荷は松平右近将監様御囲外の御預場の御砂山中段から元禄4未年（1691）に町内の当所へ引移され、以後火除として例年2月初午に祭礼を執行する（修復・新規は町内持）**。〔城山の名の神社側の用例（稲荷の名に付く時期＝元禄4年引移以降）として、城山里俗名の歴史の補助的材料。加賀美次郎（加賀美氏・新羅三郎義光公五男）家の系譜文言（p47-49）が同じ条に続く（OCR崩れが大きく人名関係は要照合）。〕
- **同朋町条・天徳寺門前町条の大下水文言〔文言候補・周辺系〕（p28-35・p79-84）**: ①「**下水之儀ハ御公儀下水二而 町内持無御座候 古来ゟ有来候大下水二御座候所**」（天徳寺門前町条・p30付近・OCR）＝御公儀下水で町内持ではない古来の大下水の文言候補。②「**〔大〕下水之儀ハ町内家前ニ有之 巾三尺 長町並 東之方芝富山町ゟ 西之方神谷町江相流申候**」（同朋町条・p83）＝同朋町の家前の大下水（巾3尺・芝富山町(left)↔神谷町(right)へ相流）。〔**西久保・芝境の東西に走る大下水の位置の記録**（御公儀下水＝町方の管理外の下水）で、当repo四河川の流域外の周辺系文言として、芝切通・葺手町・神谷町・同朋町の間の下水網の復元の参考に採録。流末の帰属（古川か・汐留か）の特定は本文言からはできない。〕

## 制限・未解決

- ①すべてOCR由来。特に「森坂町請来候」の判読（崩し・替字の可能性大）、「久松筑前守様」等の役職・人名、「藪小路通」の比定は原画像照合必須。②引請樋218間→88間の「間」の単位の意味（樋の延長か・受水口の間口か）は未解決。130間不用の理由も本文言に情報なし。③城山・熊谷橋文言の「火之城跡」「城許之由」等の判読の乱れは要照合。熊谷直実の城跡伝承の諸説との整合（比定）は行わない。④大下水の流末の帰属（古川・汐留系）の確定は今後の課題。⑤新下谷町の玉川上水文言は、玉川上水全体の系譜（四谷・麹町方面の上水樋群）との位置関係の整理が必要。
