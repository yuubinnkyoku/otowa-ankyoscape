# [GAZ-096] 源平盛衰記 江戸初期版本2本（巻23-24） — 「上瀧野河松橋」の版本本文の直接確認

- **書誌〔確認〕**: 『源平盛衰記』巻23-24の江戸初期版本2冊がNDL次世代デジタルライブラリーに公開されている: [book/2544839](https://lab.ndl.go.jp/dl/book/2544839)（出版者不明・NDL書誌の刊年記述「[寛永年間]」・検索APIのpublishyear表記1600〔慶長5年〕）・[book/2544856](https://lab.ndl.go.jp/dl/book/2544856)（出版者不明・「[寛永年間]」）。巻23-24は「源氏隅田河原取陣事」（治承4年10月の頼朝の武蔵進撃・隅田川渡河）を収める。**いずれもくずし字OCR由来で文言は原文画像との照合を要する。刊年（慶長/寛永）の確定はNDL書誌の記述レベルで、版本系統の同定は版本誌学的検証が前提。**
- **「源氏隅田河原取陣事」の松橋文言〔確認・repo初出の版本本文〕**: 「**然レトテ江戸葛西ニ仰テ浮橋渡スヘシト下知せラル。江戸湾西〔寛永本OCR「江戸葛西」〕ハ石橋ニシテ。佐殿ヲ奉射シ事。恐思ケルニ此仰ヲ蒙テヲナシテ在家ヲコボナテ浮橋尋常ニ渡タリ軍兵是ヨリ打渡シテ武蔵国豊嶋ノ上瀧野河松橋ト云所ニ陣ヲ取テ其勢既十萬余騎懸リケレバ**」（2544839）／「**…江戸葛西ハ石橋ニシテ。佐殿ヲ奉謝シ事〔奉射のOCR崩れ候補〕…軍兵是ヨリ打渡ス武蔵国豊嶋ノ上瀧野河松橋ト云所ニ陣ヲ取其勢既ニ十萬余騎**」（2544856）＝**①江戸（太郎重長）・葛西（三郎）に命じて隅田川に浮橋を渡させた、②在家を壊して浮橋を尋常（通り通り）に渡した、③軍兵が渡って「武蔵国豊島の上瀧野河松橋という所」に陣を取り、勢い十万余騎に及んだ、という版本本文。松橋陣所文言の盛衰記諸本のうち最も遡る系統（江戸初期版本）の本文を2本で直接確認した**〔repo既出の松橋文言（[GAZ-093](GAZ-093.md)風土記稿・[GAZ-094](GAZ-094.md)東京市史稿の盛衰記長文引用・[GAZ-027](GAZ-027.md)江戸砂子橋場条・江戸紀聞〔GAZ-094経由〕）はすべて江戸後期〜近代の考証書・地誌経由の引用で、版本本文の直接確認は本資料が初めて〕〔OCR・要照合〕。
- **版本2本の本文異同〔確認〕**: ①松橋文言は**両本とも「武蔵国（国／國）豊嶋ノ上瀧野河松橋」で完全一致**（細部の仮名遣い・句読の差のみ: 2544839「陣ヲ取テ其勢既十萬余騎」／2544856「陣ヲ取其勢既ニ十萬余騎」）。②「江戸湾西ハ石橋ニシテ」（2544839）vs「江戸葛西ハ石橋ニシテ」（2544856）＝**「湾西」は「葛西」のOCR崩れ候補**（前文の「江戸葛西ニ仰テ」と同一人名〔江戸太郎重長・葛西三郎〕の反復と読むのが自然だが、原字照合まで断定しない）。③佐殿を「奉射シ」（2544839）vs「奉謝シ」（2544856）＝「奉射」が原義（石橋山合戦で佐殿を射た件の恐れ）で「奉謝」はOCR崩れ候補。
- **松橋の表記対立群の整理〔確認・GAZ-094制限④の解決〕**: 松橋の陣所文言の表記は次の通り対立する: **「上瀧野河松橋」（江戸初期版本2本・2544839/2544856＝本資料）／「上瀧野河松橋」（江戸名所図会の金剛寺条の盛衰記引用・下記）／「上瀧野河松橋」＝1903年農業志料の引用（[GOV-196](../gov/GOV-196.md)第172回追記）／「上瀧野河松橋」＝江戸紀聞（GAZ-094経由）／「上瀧野川まつ橋」＝東京市史稿の盛衰記長文引用（GAZ-094）／「豊嶋の上瀧野川松橋」＝江戸砂子巻之二の橋場条（GAZ-027第171回追記）／「上瀧ノ川松橋」＝風土記稿（GAZ-093）／「上瀧の河松橋」＝江戸志引く金剛寺略縁起の「舊記曰」文言（GAZ-094経由）**＝**江戸初期版本系は「上瀧野河」で一致し、江戸後期の考証書・地誌系（江戸砂子・東京市史稿引用）は「上瀧野川」、風土記稿は「上瀧ノ川」と「野河／野川／ノ川」の3形に分かれる**〔版本系「野河」が基準形で、考証書系で「野川」に転じた可能性を示すが、各資料の版本系統・引用経路の検証（原字照合）まで系統関係は断定しない〕〔OCR・要照合〕。
- **江戸名所図会の金剛寺条の盛衰記引用〔確認・[GAZ-047](GAZ-047.md)/[GAZ-058](GAZ-058.md)の別巻の文言〕**: 江戸名所図会7巻系版本2点（[book/2563394](https://lab.ndl.go.jp/dl/book/2563394)・[book/2559054](https://lab.ndl.go.jp/dl/book/2559054)）の金剛寺条に「**此地は石神井河の流に臨み…源平盛衰記に治承四年十月頼朝卿隅田河をうち渡り武蔵國豊島の上瀧野河松橋（といふ所に）陣（を取）**」＝**名所図会の金剛寺条も盛衰記を「上瀧野河松橋」の表記で引用**〔GAZ-047（1893覆刻版）・GAZ-058（1927有朋堂版）の既登録文言は法明寺条・実相寺条（雑司ヶ谷・弦巻川）で、金剛寺条（滝野川・松橋）は未登録だった＝本回の追記対象。名所図会の引用形「上瀧野河」は江戸初期版本系と一致〕〔OCR・要照合〕。
- **1885年活字版の対校〔確認・参考〕**: [book/877517](https://lab.ndl.go.jp/dl/book/877517)（『源平盛衰記』1・明治18年〔1885〕活字版）の同条は「**武藏國豐島ノ上瀧野河松備ト云所ニ。陣ヲ取**」＝活字版も「上瀧野河」の表記を保持（「松備」は「松橋」のOCR/植字崩れ候補）〔版本系の表記が近代活字版まで保持された対校点〕〔OCR・要照合〕。
- **武家名目抄稿の転写〔確認・参考・文言候補〕**: [book/11607787](https://lab.ndl.go.jp/dl/book/11607787)（『武家名目抄稿』）に「**源氏住田河原取陣候武蔵国豊島郡上滝野河招橋ト云所ニ陣ヲ取ル**」＝盛衰記本文の転写（「住田河原」は隅田河原・「招橋」は松橋のOCR崩れ候補・「上滝野河」は字体違い）〔武家故実書経由の別系統の転写例として記録。OCR崩れが大きく文言は候補扱い〕〔OCR・要照合〕。
