# [GAZ-118] 町方書上 本郷町方書上弐 — 本郷竹町の千川上水跡書上（元禄初掛→安永9再掛→天明7取潰しの三層文言）

- **書誌〔確認〕**: 『町方書上 本郷町方書上弐』（写・NDL次世代デジタルライブラリー [book/2571511](https://lab.ndl.go.jp/dl/book/2571511)）。冒頭「町方書上 本郷町方書上弐」＋本郷新町屋・松竹町・金助町・同朋町・元町等の町列挙（「御勘定奉行 本郷町方書上」の宛所）。各町の「町内取調箇條書上」を綴じた町方書上群で、諸町の書上の廻年月は**文政九丙戌十月（1826）**（本郷新町屋条末尾「以上 文政九丙戌十月 本郷新町屋地借家主平兵衛…」等）。**引用文言はすべてOCR由来で要原文照合**（写本でOCR崩れが多く、特に数字・地名の判読課題が残る）。
- **本郷竹町条の千川上水文言〔文言候補・repo初出の本郷側給水配置文言〕**: 「**町内千川上水跡之儀は最初元禄之度に相懸り候処相潰レ又々安永九子年中より相懸り 本郷壱町目往還大枡ゟ 竹町東通り徳温り壱歩 同町中程西江入横町際ニ而小壱ケ所 同所西へかり相懸り 其外小樋〔OCR「小柳」・判読要確認〕跡無御座候 去天明七未年四月斗〔頃?〕御差止メテ相成 取潰し埋立申候**」＝**①千川上水の町内給水が「最初元禄之度に相懸り→相潰レ→又々安永九子年中より相懸り」という元禄期初掛・廃絶・安永9年再掛の三層の年代構成、②安永9年再掛時の具体配置＝本郷壱町目往還の大枡ゟ〔「より」の意・本書OCRの頻出字〕竹町東通りへの樋・同町中程の西江入横町際の小樋1ヶ所・その西えの掛り、③その他の小樋跡なし（「其外小樋跡無御座候」）、④天明7未年4月の御差止による取潰し埋立の実施、の4点を1つの町条に収めた書上**。〔**①「本郷壱町目往還」「竹町東通り」「西江入横町」等の給水経路の具体地名はrepo初出（既存走査でhitなし）。②元禄初掛→安永9再掛の二層を同時に明言する町条は、元禄期給水の実在を町方側から伝える旁証（[GAZ-119](GAZ-119.md)の春木町・真光寺門前・古庵屋敷の各条では逆に元禄期の記憶が失われているため、町ごとの記憶の濃淡が並走して観察できる）。③天明7年4月の市中埋樋取潰（[GAZ-024](GAZ-024.md)・[GAZ-025](GAZ-025.md)・[BOOK-217](../books/BOOK-217.md)）の本郷側・町方申し出側の対応文書として対校できる**〕。
- **元禄初掛文言の位置づけ〔観察・repo内仮説との関係〕**: 本条の「最初元禄之度に相懸り候処相潰レ」＝**元禄期の千川上水給水が実在した後、いったん廃絶したことの町方側の年代つき言明**。亨保7年（1722）の幕府による差止（[GOV-170](../gov/GOV-170.md)・[GOV-464](../gov/GOV-464.md)）と元禄初掛の間の給水実態の問題（元禄〜亨保7年の間は給水があったのか、「相潰レ」はいつか）は本条では確定できないが、**「元禄之度に相懸り」＝享保差止の少なくとも半世紀前に遡る給水開始の町方記憶**として、千川上水の給水開始年代の下限を押し上げる根拠候補〔**ただし「元禄之度」の記憶が伝聞か文書に基づくかは本条では判定不能。元禄九子年初掛の文言（[GAZ-034](GAZ-034.md)の千川金七由緒書・白山前町条、[GOV-210](../gov/GOV-210.md)・[GOV-211](../gov/GOV-211.md)の宇兵衛側願書系）との年代対応の検討が今後の課題**〕。
- **周辺の町条〔記録〕**: 同冊の本郷新町屋・同朋町条は境界・拝領地・揚場等を記すのみで千川上水文言なし（同朋町条末尾に隣町として「北之方 本郷竹町」が現れる）。竹町条の前段には同町の享保13申年神田川御切広ケに伴う揚場召上・翌酉年9月の元之通拝借の文言があり、神田川側の水運・水利と千川上水の動向とを同じ町条の中で対比して読める書上である。

## 制限・未解決

- ①本条はOCR崩れが激しく「**竹町東通り徳温り壱歩**」（「樋渡り壱ヶ所」等の判読候補）・「**四月斗**」（頃/迄/際等の判読候補）・「**小樋跡**」の「小樋」（OCR「小柳」）等の語は**原文照合まで保留**とし、判読課題として明示する。②「元禄之度に相掛り候処相潰レ」の「相潰レ」（＝この元禄期給水の廃絶）の年代・理由は本条にない。③本郷壱町目往還の大枡の位置比定（本郷通りと千川上水樋の交点の具体座標）は次工程の課題（[GAZ-119](GAZ-119.md)・[GAZ-045](GAZ-045.md)（湯島区間）・[GAZ-041](GAZ-041.md)〜[GAZ-043](GAZ-043.md)（外神田町方書上）との対校で区間化する予定）。④書上の「写」の性格（原本の所在・提出先の御勘定奉行の年度）の確定は未了（文政9年の廻年月が全町共通のため、書上の一事業年度一括提出と読めるが確定はできない）。
