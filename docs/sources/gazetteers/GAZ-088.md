# [GAZ-088] 大江戸志 — 江戸川の御留川・鯉ヶ崎・蚊屋淵・とんど橋の原典側文言〔第163回〕

- **書誌〔確認・一部推定〕**: 『大江戸志』16巻のうち[3]（写本・NDL次世代デジタルライブラリー [book/2553930](https://lab.ndl.go.jp/dl/book/2553930)）。江戸志系の地誌（享保〜寛延期の候補・**著者・刊年は書誌不記載で要確認**）。[GAZ-049](GAZ-049.md)③の【江戶志】引用文言の**原典側**にあたる系統の本文と対校できる。**引用文言はすべてOCR由来で要原文照合。**
- **江戸川の御留川文言〔確認・repo初出〕**: 「**江戸川殺生禁断通船止御留川 此川に群鯉当有小石同ト小日向境川ヲ云**」＝**江戸川は殺生禁断・通船止めの御留川で、この川に群鯉がいる**という文言＋小石川・小日向の境川であることの定義〔**江戸川の御留川（幕府直轄の管理川）化と鯉の保護の文言**。[GAZ-049](GAZ-049.md)③の【江戶志】「此川に生ずる鯉は…みだりに取ことを禁ぜらる」の原典系対校資料。「御留川」の文言そのものはrepo初出候補〕。
- **鯉ヶ崎の位置〔確認・原典側対校〕**: 「**恋崎云鯉ヶ崎共 立慶橋中ノ橋ノ間南ノ出崎ヲ云**」＝**鯉ヶ崎（恋崎）＝立慶橋と中ノ橋の間の南の出崎**＝[GAZ-049](GAZ-049.md)③の鯉ヶ崎文言（江戸川の中の橋の辺）の位置を橋名で特定する原典側文言〔江戸川沿いの微地形（出崎）の位置記録〕。
- **蚊屋淵の蚊帳の怪談文言〔確認・repo初出〕**: 「**堀か渕 此両岸を云 此所にて女蚊帳を洗ふとて其蚊帳にまかれて死す其霊魂主となる**」＝**蚊屋淵（堀か渕）で女が蚊帳を洗い、その蚊帳に巻かれて死に、その霊が主（淵の主）となった**という伝承文言〔**蚊屋淵の地名由来に対応する怪談の本文**＝[GAZ-049](GAZ-049.md)③の蚊屋ヶ淵の位置文言（中の橋と立慶橋の間・大曲り）に由来譚のレイヤーを加える一次文言候補〕。
- **船河原橋＝とんど橋・水戸殿一手持〔確認・repo初出〕**: 「**船河原橋 とんど橋云 市谷船河原町へかゝる一人橋 水戸殿一手持為世**」＝**船河原橋は「とんど橋」とも呼ばれ、市谷船河原町へかかる一人橋（幅一人分の橋）で、水戸殿が一手に持（維持）している**＝**船河原橋の異名「とんど橋」＋幅員（一人橋）＋水戸家単独維持**の文言〔[BOOK-131](../books/BOOK-131.md)享保13年「水戶相懸り修復」・[GAZ-049](GAZ-049.md)②の「俗にどんと」等の船河原橋記録群と対校できる橋名・維持主体の原典側記録。とんど＝歳末の左義長（とんど焼き）との関係は原画像照合後に検討〕。
- **龍慶（厳来）橋下の通舟上限〔確認・文言候補〕**: 「**市兵衛厳来橋下 厳来云江戸川水下茲迄通舟有 洪水ノ節網曳ス**」＝**厳来橋（龍慶橋〔立慶橋〕のOCR変種候補）の下まで江戸川の水が通じ、ここまで通舟があり、洪水の節は網を曳く**〔**江戸川舟運の上限が龍慶橋下**であることの文言候補（[GOV-374](../gov/GOV-374.md)の通船差支の文言と対校）。「市兵衛」は市兵衛河岸（[BLOG-133](../blogs/BLOG-133.md)）の文脈か・原文照合を要する〕。
- **神田川上流の堀割の政宗説〔確認・repo初出の年代説候補〕**: 「**小石川神田川上御茶の水より水戸殿前の堀云是は二代将軍家の治世松平陸奥守正宗公堀割有**」＝**御茶ノ水から水戸殿前の堀（神田川上流・白堀系の堀）は二代将軍（秀忠）の治世に松平陸奥守（伊達）正宗（政宗）公が堀割した**という由緒文言＋小石川の地名由来（小石の多い川幾流もある故）〔**神田川上流（御茶ノ水〜水戸殿前）の堀割者＝伊達政宗・二代将軍治世説**＝[BOOK-147](../books/BOOK-147.md)の伊達綱宗寛文元年改修説（萬治3年起工）に対し**一世代前の政宗・二代将軍治世説**を提示する候補（[GOV-377](../gov/GOV-377.md)の内田六次郎説・[GAZ-049](GAZ-049.md)⑬の承応2年堀割説とあわせ開削者・年代論の対立候補を追加）。OCR「正宗」は「政宗」の候補・原画像照合前提〕。
- **その他の文言〔文言候補〕**: ①水道橋から小石川御門外・船河原橋・江戸川大曲り・牛天神下上水端・富坂・伝通院前・「極楽水辺」までの経路列挙、②「伝通院後流猫服橋ノ川通」＝ねこまた橋（猫服橋のOCR候補）と白山権現の遷座説、③広小路の水戸殿前通の団子茶屋の冥加金文言、④金杉上水端の武家屋敷の石高列挙（上水端南側・[GOV-369](../gov/GOV-369.md)の「上水端」立地語と対校）。
