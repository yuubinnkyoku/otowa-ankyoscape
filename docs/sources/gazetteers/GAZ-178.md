# [GAZ-178] 町方書上[141] 深川 二十二 — 十間川の汐合・伏越の文言と松代町起立説

- **書誌〔確認〕**: 『[141] 深川町方書上 二十二』（写・NDL次世代デジタルライブラリー [book/2571622](https://lab.ndl.go.jp/dl/book/2571622)。NDL API volume欄直接確認）。深川北松代町一〜四丁目条（koma 19-20・64-65・16・26等）。引用文言はすべてOCR由来で要原文照合。※第223回の本冊boilerplate陰性判定（四河川keyword）は以下の文言群を捉えていなかったわけではないが（十間川文言はkeyword外）＝本回の再掃引で採録。
- **十間川＝竪川→南小名木川への横川の「汐合」文言〔文言候補・本冊最重要〕（koma 19-20）**: 「**一竪川巾弐拾間余 右は町内北裏地先を相流 上は東之方逆井候分西え本所茅場町之方え流行申候 川名之記 御堀割年月等旧記無之相知不申候 一十間川巾拾間余 右は町内西之方地先 竪川ゟ南小名木川え之横川ニ有之 汐合之場所ニ而流相定り不申 里俗十間川と相唱 御堀割年同等旧記無之相知不申候**」（koma 19-20・OCR）＝**①町内北裏地先の竪川（巾20間余・上流は逆井方面→西の本所茅場町方へ流行）、②町内西地先の「十間川」（巾10間余=「十間」の名義と整合）は竪川から南小名木川へ通じる横川で、汐合（潮汐の影響する合流点）の場所で流れが定まらない、里俗「十間川」の呼称・堀割の年次は旧記なく知れない**という文言候補。〔**十間川の巾10間余と「竪川~小名木川を横断する川」+「汐合」という位置づけの一次文言（repo初出候補）**＝[GAZ-165](GAZ-165.md)（起立書の「竪川横川拾間川…万治2年新規御堀立」）・[GAZ-170](GAZ-170.md)（神田徳右衛門町条の竪川20間）と合わせて、十間川の機能（竪川と小名木川を結ぶ潮感区間）を一次側から記す材料。koma 64には「右は当町四丁目ゟ三丁目江相渡候橋ゟ横十間川に懸渡」という橋の文言（「横十間川」の表記もO候補）。〕
- **悪水の「伏越」文言＝小名木川悪水吐の逆水対策〔文言候補〕（koma 65）**: 「**右は当町地尻 亀戸清水町横町往来に幅四尺余之下水有之 右悪水 五ツ目渡場脇 亀戸村入極え之水吐に御座候処 逆水致候趣に而 北裏を小梅押上百姓方(?)両町地先往還江 伏越箱木付置 損古間川（=小名木川・OCR崩壊候補）悪水吐落申候 右状替等は百姓共ゟ仕来 町内二而は不相撲（=相撲?・OCR）…補理…**」（koma 65・OCR）＝**①亀戸清水町横町往来の幅4尺余の下水＝悪水、②本来は五ツ目渡場脇・亀戸村入極の水吐へ落ちるが、逆水（高潮・満水時の逆流）のため北裏の小梅押上百姓方が両町地先の往還に「伏越（箱木付置）」を付け、（小名木川?）の悪水吐に落とす、③その普請は百姓方の仕来で町内負担ではない**という文言候補。〔**「伏越」の語の用例（土管・箱樋による道路下の悪水の伏せ越し）が江戸期の一次文言で現れるのはrepo初出候補**（現代の清流「伏越」指摘との対照語彙・[LOST-005](../lost-web/LOST-005.md)等で使われる術語の江戸期実務用例）。OCRの崩壊が甚だしい箇所（「小梅押上百姓方(?)」「損古間川」等の判読不能部）で要原画像照合だが、文言構造（悪水の水吐の逆水対策としての伏越箱木）は読み取れる。亀戸村・小梅押上の双方の百姓が関与する悪水処理の境界実務の記録。〕
- **清水橋と本所清水町の再引地文言（koma 20）**: 「**一清水橋長八（間?）日幅壱丈 板橋ニ而御入用橋ニ御座候…古来当時本所清水町之儀は 元上野清水門外に有之 一旦当所之辺え地渡に越来 猶又当時之場所え再引地に相成候由ニ有之 其頃右橋掛渡候故清水橋**（と唱候）」（koma 20・OCR）＝**本所清水町（もと上野清水門外→地渡→再引地）の移転史と、その頃の掛渡に由来する清水橋（板橋・長8間?・巾1丈・御入用橋）の名義文言候補**。〔[GAZ-165](GAZ-165.md)起立書の「十間川…清水橋（万治2年御懸立）」の橋の系統と、清水町の移転史が橋名に残るという地名収束の好例（文言候補・「上野清水」は上野の清水町の可能性を併記）。〕
- **真田伊豆守の抱屋敷→松代町起立説（koma 16・26）**: 「**真田伊豆守様御抱屋敷ニ而 年月不相知百姓立帰り地ニ相成候趣申伝有之 伊豆守様者信州松代御在城に付 右之因に而町名に唱**（候）」（koma 16・OCR）＋「**真田伊豆守様御抱屋鋪ニ相成居候処 右御抱や敷年月不知村方江御戻しニ相成候間 百姓共住居仕商売屋取建候に付 御同人様御国許信州松代に…**」（koma 26・OCR）＝**北松代町一帯がかつて真田伊豆守（信州松代藩主）の抱屋敷で、後に村方へ戻されて百姓地→町屋化し、「松代」が町名に残ったとする起立説の文言候補**。〔※四河川の直接史料ではなく深川の町名起立説だが、十間川・竪川沿いの土地利用史（武家抱屋敷→町屋化）の文脈として記録。文言候補（伝承表現・断定しない）。〕

## 制限・未解決

- ①すべてOCR由来で要原画像照合。特にkoma 65の伏越文言（「(判読不能)」「損古間川」「不相撲」等）はOCR崩壊が甚だしく、文言構造の読み（伏越箱木・悪水吐・逆水）は全て判読候補扱い。②koma 19の竪川の「上は東之方逆井候分西え本所茅場町之方え流行」の句切り（逆井=地理名か）は未決。③「横十間川」（koma 64）の字面はOCR要再照合。④十間川の堀割年次は本冊自体「旧記無之相知不申」と明記＝万治2年堀立（[GAZ-165]起立書）との対応の確定は対校に委ねる。⑤清水町の再引地文言の年次は不記載。
