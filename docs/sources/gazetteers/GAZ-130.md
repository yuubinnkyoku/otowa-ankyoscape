# [GAZ-130] 町方書上[77] 外神田五上 — 神田旅籠町条の「中奥千川御上水」文言と昌平橋外芝地井戸の御預チェーン

- **書誌〔確認〕**: 『町方書上[77] 外神田町方書上　五上』（写・NDL次世代デジタルライブラリー [book/2571558](https://lab.ndl.go.jp/dl/book/2571558)・70コマ）。湯島三町目代地・湯島壱町目代地・和田明神門前町代地ほかの書上（町方書上群の文政9戌年〔1826〕系の廻年月候補）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571558_{NNNNNNN}.txt` コマ番号。**
- **神田旅籠町条の「中奥千川御上水」文言〔文言候補・本冊の主要価値〕（p22）**: 「**神田旅籠町之儀 古来神田上水請来候得とも 水不足二付 中奥千川御上水受来候処 享保七寅年十月 千川御上水相止候 以後水悪敷大勢難義仕候ニ付 右芝地井戸 旅籠町壱丁目弐丁目江 御預り被下置候様二 享保十一午年正月廿三日 御月番親類 大岡越前守様 牛番所え御願申上候得者 同晦日被召出 右願之義御普請御奉行 朽木丹後守様江可罷出旨被仰渡候ニ付 則同日愛宕下 朽木丹後守様江御願申上候へは 御用人村(=村大?OCR)衛門殿 絵図願書二三日中窺二可参旨被仰渡…二月十八日罷出候得者 願之通御預ケ被遊証文仕候 右井戸之鎰も御預ケ被遊…**」＝**①神田旅籠町は古来は神田上水を引いていたが水不足のため「中奥千川御上水（＝中奥からの千川上水）」を受け、享保7寅年（1722）10月に千川御上水が差し止められ、以後の水質悪化・難義のため昌平橋外の芝地井戸を旅籠町壱丁目・弐丁目が御預かりとして下げ置いてほしい旨を享保11午年（1726）正月23日に大岡越前守（＝大岡忠相）の牛番所へ願い出て、御普請御奉行朽木丹後守（＝朽木正煕候補）を経て2月18日に願の通り御預け・証文・井戸の鍵まで受け取った**という一連の絵図願書・日次付きの記録。〔**①「中奥」文言の第3の witness**：[GOV-464]（憲教類典58・享保7年8月の差止触「中奥ゟかヽり候事」石川近江守殿御渡）vs 絲綸錄（「中興よりかヽり候事」引载）の判読対立に対し、**町方（給水側）の書上が「中奥千川御上水」と書く**＝中奥（幕府奥向きの用達・万歳系の用法候補）を支持する消費者側の一次文言候補（[GAZ-117]古事類苑政治部29と並ぶ独立出所）、②**差止の年月「享保七寅年十月」**＝[GOV-464]の触「**来ル十月より上水取不申筆**」（8月触・10月実施）と整合する**実施月の町方側記憶文言**（触の月〔8月〕と実断水の月〔10月〕の対立ではなく時系列として揃う可能性が強まる。ただし町方の記憶であるため断定しない）、③旅籠町の神田上水→千川上水切替→断水→井戸御預の**因果の記憶**として [GOV-441]（沿革図書十四・享保8卯年9月拝借→享保11午年2月壱丁目・弐丁目御預）の**独立対校**（本冊は願出が正月23日・預かりが2月18日で [GOV-441]の「享保11午年2月御預」と月次整合）、④[GOV-352]（安永7戌年・昌平橋外堀井戸の伺書・加藤や甚五郎・深川永堀町）の井戸のルーツに当たる「昌平橋外芝地井戸」の享保期の柄が本条で裏側から描かれる**〕。
- **昌平橋外芝地井戸の大名屋敷サイクル〔文言候補〕（p22）**: 「**昌平橋外芝地井戸之儀 古来ゟ右芝地幷井戸共に本多唐之助様御預りニ而候処 享保七寅年十月朔日 廉々之助様御拾壱歳に而御死去被成 和州郡山十二万石御領地被召上 御舎弟喜十郎様江新地五万石乗置 筋違橋外御屋敷前々之通御相続被成候処 享保八卯年十一月廿六日 喜十郎様御死去被成 御改行絶仕 右御屋敷水野隼人正様江相渡 右段地 井戸共ニ御預りニ而候処 享保十巳七月廿八日糺出候成(=糺出来候補)候ニ付 信州松本七万石御領地被召上 御舎弟惣兵衛様江新地七千石被下 万(=浜?)町御屋敷被下置 筋違橋外御屋敷被召上 此度堂和泉守様江御預ヶ 同十二月掃地ニ罷成 芝地幷井戸之儀は和泉守様御預りニ而御座候**」＝**昌平橋外の芝地・井戸が本多家（本多廉々之助→喜十郎）から水野隼人正を経て堂和泉守（享保10年12月以降）へと大名の改易・相続ごとに御預け替わった記録**。〔昌平橋外の明地・井戸の空間が大名拝領地のたびに引き継がれたこと＝[GOV-441]神田旅籠町明地井戸・[GOV-352]昌平橋外堀井戸の前史の土地柄。享保7年10月朔日に当主死去（「享保七寅年十月」の重なり＝同年同月付の町方の記憶と屋敷側の事件が併走する点は偶然の可能性も保留）〕。
- **旅籠町側の髪結床文言〔付記〕（p22前後）**: 昌平橋外芝地井戸の髪結床の願出文言（享保11年3月10日大岡越前守様御番所え絵図願書…）が同条に連なる＝井戸の無番の明地の利用の実態。
