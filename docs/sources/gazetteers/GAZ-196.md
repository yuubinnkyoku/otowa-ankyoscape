# [GAZ-196] kotobank「弦巻村」項 — 永和2年（1376）吉良治家寄進状「武蔵国世田谷郷内上絃巻半分」と鶴岡八幡宮文書群（第330回）

- **書誌〔確認: kotobank当該頁の直接取得・2026-11-26〕**: kotobank「**弦巻村**」項（[https://kotobank.jp/word/弦巻村-3044766](https://kotobank.jp/word/%E5%BC%A6%E5%B7%BB%E6%9D%91-3044766)）＝**平凡社『日本歴史地名大系』（東京都の地名）の世田谷区項の部分転載**〔確認・ページ上の出典表記〕。事典項目のため原本文書は未見・文言の原字照合は未実施〔制限〕。
- **文言〔確認: 事典転載文言〕**: 項目本文は**永和2年（1376）の吉良治家寄進状〔鶴岡八幡宮文書〕で「武蔵国世田谷郷内上絃巻半分」を鶴岡八幡宮へ寄進した旨**と、**同日付の吉良治家書下写〔鶴岡神主家伝文書〕**を初出的な文書群として挙げる〔確認・転載文言ゆえ文書本体の表記・寸法等は未確認〕。

## 水系研究上の位置づけ〔確認・観察〕

- ①**世田谷側「弦巻」の文書初出系譜の前進**: [GAZ-195](GAZ-195.md)（『日本地理志料』巻之十六・1903）の世田ヶ谷条が「**鎌倉八幡宮永享元年ノ文書、世田谷内弦卷村**」と引いた文書の所在は未確認だったが、本項目により**鶴岡（鎌倉）八幡宮と鶴岡神主家が「弦巻（上絃巻）」を含む文書を実際に伝来すること**が独立の事典系で裏付けられた＝永享元年（1429）の52年前の永和2年（1376）の寄進状・書下写という**具体的な文書名・年次・文書群名つきの記録**〔観察・同一文書対応の断定はしない〕。
- ②**吉良治家との人物接続**: 寄進者とされる**吉良治家**は、[GAZ-195](GAZ-195.md)の「**吉良家譜、應永中、治家始ヲ城于此、子孫傳領、稱曰世田谷御所**」（世田谷御所の起業）と同一人物なので、**「弦巻」の文書初出が世田谷御所の吉良氏の領有・寄進行為と一体の記録**であるという系譜整理が可能〔観察・事典側の系譜記述の整合であって文書本体の確認ではない〕。「上絃巻半分」の「上」＝上絃巻の存在は弦巻の上下区分の地名史料候補〔推定〕。
- ③**鶴岡八幡宮文書群の実在の直接確認**: 文化庁「文化遺産データベース」の[鶴岡八幡宮文書（二百二十四通）詳細頁](https://online.bunka.go.jp/db/heritages/detail/186632)を本回で直接開き、**①名称「鶴岡八幡宮文書（二百二十四通）」②構成＝神社伝来の鶴岡八幡宮文書（**百三十一通**）＋八幡宮供僧坊相承院伝来の相承院文書（**九十三通**）③1315〜15巻・鎌倉〜江戸④永享六年（1434）三月十八日足利持氏血書願文等の願文類の収蔵⑤重要文化財指定年月日＝1983（昭和58）年6月6日・所有者＝鶴岡八幡宮**を確認〔確認: 詳細頁本文〕＝前回ノート予備調査（検索スニペットのみ）を格上げ。**ただし224通の内訳目録・永和2年吉良治家寄進状の存在そのものはデータベース詳細頁では確認できず**、文化庁DBの関連耐性や東大史料編纂所の古文書データベース等での目録確認が次回課題〔未解決〕。
