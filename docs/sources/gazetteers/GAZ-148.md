# [GAZ-148] 町方書上[34]（赤坂弐）— 服部屋文言の元資料側witnessと田町側の上水・大下水文言群

- **書誌〔確認〕**: 御府内備考編纂の基礎資料となる**町方書上**の一本。表紙文言「**二七四ノ第三十四**」＝目録番号[34]候補・赤坂町方書上三口の弐冊目。NDL次世代デジタルライブラリー [book/2571514](https://lab.ndl.go.jp/dl/book/2571514)。**田町壱〜五丁目・一ッ木町（続）・元赤坂町代地・願性院門前・浄土寺門前・専修寺門前・専福寺門前等の書上を1冊に収録**。各町条末尾に「文政十亥年七月」の起文が繰り返し現れ、提出が文政10年（1827）7月〔確認〕。**[GAZ-116](GAZ-116.md)（御府内備考巻67-69赤坂・2553682）・[GAZ-147](GAZ-147.md)（[33]赤坂壱・2571513）と同じ文言群の元資料側**に当たるため、本ファイルではGAZ-116既収録文言の再掲は避け、①GAZ-116の文言の判読対立を絞るwitness価値、②GAZ-116未収録の文言に限って記録する。**すべての引用はOCR由来で原画像との照合を要する**。
- **服部屋文言の元資料側witness——白堀の請負人服部屋清右衛門の拝借地から安永7年の拝領町屋敷化まで〔文言候補・判読対立の解消材料＋処分の結末はrepo初出候補〕**: 赤坂田町五丁目条（p64-66）「**右は町内向東之方明地際に而前書地面 **明暦二申年中神田御上水白堀通り極〔=樋候補・GAZ-116は「白堀通樋」〕請負人服部屋清右衛門拝借地ニ而**同続 右地面裏明地幅弐間長サ三拾七間余 是又同人拝借地に有之 其後**服部屋吉兵衛**〔GAZ-116は「大是漸(=代?)」で判読対立〕引続 弐ヶ所共拝借罷在候所 **明和七寅年四月中**〔GAZ-116は「明和七亥年」で判読対立・明和7年は寅年で本冊の干支が整合〕 町御奉行**牧野大隅守様 曲淵甲斐守様** 御普請**御奉行夏目和泉守様**〔GAZ-116は「夏日和泉守」〕御勤役中 石地所弐ヶ所も**上り地二相成 御普請方御役所え御引渡**に相成候 然所 **安永七戌年九月中** 町御奉行**曲渕甲斐守様御懸りに而** 御細工所支配**御経師田中勘兵衛** 同御支配**御小買物方今津茂兵衛** 右両人江**拝領町屋敷に被仰付** 引続当地主**田中源兵衛 今津仁兵衛**拝領仕 銘々御用達し相勤罷在候** 且右地所裏明地 御普請方御持場之内 幅弐間長三拾七間余之所も両人御願済にて其節ゟ拝借罷在候**」＋「**右は田町壱丁目ゟ五丁目迄之御改地御普請方御持場にて松平備前守様ゝ預り地に有之**」＝**①[GAZ-116](GAZ-116.md)本登録の核心文言（明暦2申年〔1656〕神田御上水白堀の通樋/通り極請負人・服部屋清右衛門の拝借地）の**元資料側（町方書上）witness**、②判読対立が複数絞られる：本冊「白堀通り極」vs GAZ-116「白堀通樋」／本冊「服部屋吉兵衛」vs GAZ-116「服部屋大是漸(=代?)」／本冊「明和七寅年」vs GAZ-116「明和七亥年」（明和7=寅年=1770で本冊が干支整合）／本冊「夏目和泉守」vs GAZ-116「夏日和泉守」、③**GAZ-116が明和7年4月の上り地化＋御普請方役所への引渡で切れていた後半**＝**安永7戌年9月（1778）町奉行曲淵甲斐守掛かりで、御細工所支配の御経師田中勘兵衛（直後文言では田中源兵衛）と御小買物方今津茂兵衛（同今津仁兵衛）の両人へ拝領町屋敷として下げ渡され、両人が御用達を勤めたこと、隣接の裏明地（幅2間・長37間余）も両人が拝借したこと、当一帯（田町1〜5丁目の御改地）が御普請方御持場で松平備前守の御預り地であること**＝服部屋拝借地の処分の結末まで追った文言（repo初出候補）**。〔白堀（神田上水の小石川区間）の樋請負人が得た拝借地が、明和7年に幕府へ収公され、安永7年には幕臣（御細工所支配の御経師・御小買物方）の拝領地に変わったという土地利用の変遷。GAZ-116の制限（拝借地は請負の見返りとは文言上読めない・両者の空間関係は確定しない）を継承する〕。
- **田町諸条の玉川御上水——万年石垣樋から埋樋へ〔文言候補・元資料側witness〕**: 田町壱丁目条（p13-14）「**一玉川御上水之儀は 町内向御堀端御明地内 但前書御上水難致〔判読要照合〕ゝ露田浦壱丁目後江通り 同様**万年石垣樋**…〔裏同様?〕**…里通二相成 表伝馬町壱丁目之方ゝ相流**…」・田町弐丁目条（p22）「**…**埋樋二相成 田町壱丁目方ゝ相流申候** 一大下水之儀 同断御明地内に有之 田町壱丁目之方ゝ相流申候 幅弐**〔間余〕…」＝**玉川御上水が元赤坂町・表伝馬町から田町諸条の御堀端御明地内を通り、万年石垣樋→埋樋を経て田町壱丁目方へ流れるという流路文言の田町側witness**＝[GAZ-116](GAZ-116.md)（赤坂総説の万年石埋樋文言）・[GAZ-147](GAZ-147.md)（裏伝馬町条の万年石垣樋→表伝馬町壱丁目埋樋文言）と連続する玉川上水の神田川湧水系末端〔いわゆる赤坂田町区域〕の並流記録（各文言とも細部の判読は要照合）。〔田町側からの「上水が田町壱丁目方へ流れる」文言は、元赤坂町の万年石垣樋→表伝馬町壱丁目埋樋というGAZ-147文言の下流側の帰属を田町壱丁目方に特定する対校材料〕。
- **大下水に掛かる古来の御公儀橋と享保4年の修復文言〔文言候補・対校witness〕**: 田町四丁目条（p51）「**雨落下水ゝ前書大下水え落込往還ニ有之 古来ゝ有来 長六尺幅三間有之 先年者板橋ニ而御公儀梢〔=橋〕ニ御座**…」＋同（p23）「**…替被下置 **享保四亥年九月** 御普請奉行**朽木丹後守様**御勤役之節ゝ 自今修復之儀は町内に而可致旨被仰渡**候**」＝**大下水（別途の雨落下水を落し込む）に掛かる古来の御公儀橋（長6尺・幅3間・先年板橋）と、享保4亥年（1719）9月朽木丹後守勘役の時期に石橋へ架け替え・修復の町内負担化が申し渡された文言**＝[GAZ-147](GAZ-147.md)裏伝馬町条の同型文言（享保四亥年**八月**・朽木丹後守）と月日が対立する同種の記録（町ごとの別桥か、月の判読問題かは断定しない・要照合）。〔田町側の大下水は幅2間余（p22・p68）で、[GAZ-147]元赤坂町条の横切大下水（巾平均6尺・凡長142間半余）とは別水路か同系かは本冊からは確定できない〕。
- **その他の読取点〔文言候補〕**: ①田町壱丁目条（p12）「十辰年 田町壱丁目ゝ四丁目迄長弐百五拾間 幅大下水ゝ御堀之方五間合千四百坪之処 伝馬町田町紺屋合〔羽屋?〕…」＝大下水ゝ御堀間の幅員文言（十辰年＝宝暦10庚辰1760候補・要照合）、②服部屋文言の直前（p64）に御研師竹屋伊右衛門の拝領町屋敷文言（「先規持主同様**南伝馬町え御伝馬助役相勤来り申候**」の文言を含む＝[GAZ-116](GAZ-116.md)が服部屋文言を「南伝馬町」に関連づけた背景に、田町五丁目条内の南伝馬町への言及が見える）、③一ッ木町条（p95-96）に一ツ木村の書改（延宝3卯年中ゝ一ツ木村と書改・往古氷川明神人継村の勧請）・寛文4辰年追々御用地化の文言＝赤坂一ツ木町の村起源申伝（本repoの水窪川流域の村落史とは直接接しないが豊嶋郡赤坂庄一ツ木村の記録として参考）。
