# [GAZ-185] 町方書上[154] 龜戸（文政11子）— 十間川万治2年堀割の奉行名文言・亀戸銭座舟入堀の埋立実務・天神橋の旧名

- **書誌〔確認〕**: 『[154] 龜戸』（写・NDL次世代デジタルライブラリー [book/2571635](https://lab.ndl.go.jp/dl/book/2571635)。NDL目録volume表記「龜戸」）。収録は亀戸町（見出しp12-14あい、文政11子年条）・亀戸境町（p57-58）・亀戸清水町（p49-52）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571635_{NNNNNNN}.txt`）。〔第231回「陰性」冊リスト掲載の冊。水系文言を含むことが本回の通読で判明したため、登録する。〕
- **亀戸町条の横十間川万治弐亥年堀割＝奉行名文言〔文言候補・本冊最重要〕（p12）**: 「**横十間川御堀割之義は 万治弐亥年 本所御奉行徳山五兵衛様 山崎四郎左衛門様 御懸りニテ堀割出来候趣申伝**」＝**[GAZ-165](GAZ-165.md)本所起立記の万治2年堀割文言と完全に一致する年代・奉行名を載せる十間川側の独立witness（奉行の実名を載せるのは本条が初出候補・repo初出級）**。〔[GAZ-184](GAZ-184.md)柳嶋境町条・柳増嶋土村町条の「万治年中本所御取立」申伝・[GAZ-185]亀戸清水町条（後述）の万治2年文言をあわせ、**万治2亥年（1659）・本所御取立の堀割の申伝が本所側の少なくとも4条で平行的に記される**ことになる。相川（氷川）堀立文?との対応も含め、本所堀割群の年代論の土台を固める材料。〕＋横壱間川?〔判読不良〕ヲ往還横切埋柱（石樋判読候補）文言。
- **亀戸銭座の舟入堀埋立・文化5年湛水の石蓋暗渠化実務文言〔文言候補・repo初出級〕（p13）**: 「**諸紙座〔=銭座OCR崩れ候補〕…舟入堀ニ有之同座ゟ入用相懸ケ小橋懸ケ…諸銭御差止ニ相成 右跡ニ而埋立 耕地悪水吐兼…伊奈半左衛門様江奉願…字銭座脇**」＝**①亀戸銭座の舟入堀（銭の運搬用堀）の実在・銭座廃止（御差止）後の埋立という実務履歴文言、②埋めた跡地の耕地悪水吐（排水確保）の願出（伊奈半左衛門＝関東郡代伊奈氏）という一連の水利実務文言（いずれもrepo初出級）**。＋「**大雨之節天神裏門辺地水相湛 往来同難儀候ニ付 文化五辰年中奉願…左右蓋共石ニ相間数之上**」＝**文化5年（1808）の湛水的具体故障と、それを受けた石蓋による道路下排水（石蓋暗渠化）の実務文言候補（repo初出級）**＝後の蓋掛け下水・道路下暗渠系の系譜に直接つながる江戸期の実例文言。〔現行の蓋暗渠（歩道下の排水蓋）の直接の制度的前身にどう接続するかは本文言だけでは断定しないが、石蓋文語の実施行例の系譜の最古級候補として付加価値が高い。悪水吐の向かい先「東之方笹戸村?〔判読候補〕地内」も記録。〕
- **天神橋旧名=亀戸橋・笹戸橋名目廃止文言〔文言候補・repo初出〕（p14）**: 「**右橋懸リノ初メゟ 亀戸橋ト相唱候由 其後天神社造営以後 天神橋ト申 間ハシ 笹戸橋之名目ハ止ミ候**」＋「**万治弐亥年二月 本所御奉行徳山五兵衛様 山崎四郎左衛門様御掛リニ而出来**」＝**①天神橋の旧名亀戸橋、②さらに旧名笹戸橋の名目廃止という二層の旧名の記録（repo初出候補・天神橋の架橋年代万治2年2月＝奉行名つき）**、③杉台石垣の万治亥年築立文言も。〔天神橋の旧名の2層構造（笹戸橋→亀戸橋→天神橋）と p13の「笹戸村?」判読候補との語形の重なりは観察材料（橋名＝地名由来の対応候補だが、いずれも原画像照合後に判断）。竪川・横十間川系の橋名変遷の一例として[橋名調査](../../四河川の橋名・橋跡調査.md)第236回追補に収める。〕
- **亀戸境町条の境橋・万治2年対校文言〔文言候補〕（p57-58）**: 北十間川（幅拾間・川向い＝小村井村候補?判読）＋万治2亥年堀割申伝＋境橋（長拾間・板橋＝**亀戸村・柳嶋村・請地村三ヶ村入会之橋**・梶橋?〔判読〕梁田治助・蔵田屋清左衛門の請負文言）・「起立ハ亀戸町ニ申上候 天神橋同様之年代（=万治2）」＋境橋通行の「本田筋/軒田筋」・「嵯峨寺?宿来候由申伝」。〔[GAZ-184](GAZ-184.md)柳嶋境町条の境橋（長8間・柳浜村・清地村・亀戸村持ち）との**寸法・持ち村の対校**が同型文言として成立する（同一橋か断定しない・請負人の実名記載は本条の特色）。「嵯峨寺宿」の読み＝斜門宿?（判読不良・照合前提、保留）。〕
