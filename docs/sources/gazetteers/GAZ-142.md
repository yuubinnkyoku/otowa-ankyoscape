# [GAZ-142] 町方書上[65] 四谷陸 — 天龍寺門前条の玉川上水区間長・添地・橋3ヶ所

- **書誌〔確認〕**: 『[65] 四谷町方書上　陸』（写・NDL次世代デジタルライブラリー [book/2571546](https://lab.ndl.go.jp/dl/book/2571546)）。文政10亥年（1827）。表紙町列・天龍寺門前（p67-74・p74末「以上文政十亥年五月 四谷天龍寺門前名主雄三郎」）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571546_{NNNNNNN}.txt` コマ番号。** 天龍寺門前＝代々木・千駄ヶ谷を望む玉川上水北岸の寺門前町（江戸四谷天龍寺＝関東天龍寺の前町〔現・渋谷区代々木〕周辺と比定されるが比定は[GAZ-142]の範囲外で本登録では文面のみ記録）。
- **玉川御上水の区間長の定量文言〔文言候補・repo初出候補〕（p71）**: 「**一玉川御上水堀 町内に懸り候 長凡弐百四拾五間 由凡九十人(=九十間候補・OCR崩壊)**」＝**玉川御上水堀が町内に懸かる長さは約245間（「由凡九十人」は「由凡九十間」等の崩れ候補で由〔両縁の幅?由来?〕の確定は要照合）**。〔**「上水堀が1町内に懸かる区間長」を明示する定量文言は玉川上水の町方側の通過実務のdatapoint候補（repo初出候補）。245間≒440m強は町の南境に沿った上水区間のスケールを示す。文面の原字確定まで数値は「凡」と付記された概数として扱う**〕。
- **天龍寺御預り添地の文言〔文言候補・repo初出候補〕（p71）**: 「**一天龍寺御預か地壱ヶ所 右は同寺表門前 東ゟ西え長百弐拾六間 巾弐間宛 玉川御上水両縁通 并西北角に而 東ゟ雨(=西候補・OCR崩壊)に長百三十九間 南北え巾五間半余 北條(=坪?OCR崩壊)千三百九坪 此反別四反三畝拾九歩 右は地主天龍寺御預り添地に而 芳野永御年貢年之御代官中村八太夫様御役所え差出申候 尤右御上水御縁通御預り添地内ニ異変有之候節は 町役人ゟ水面に拘り候義は御普請方御役所 町奉行所え御訴奉申上 御年貢地内之節は町奉行所 御代官中村八太夫様御役所え御訴申上候義に御座候**」＝**天龍寺御預かり添地：①表門前（東西長126間・巾2間宛）②玉川御上水の両縁通＋西北角（東西長139間・南北巾5間半余・坪千三百九坪・反別4反3畝19歩）、年貢は御代官中村八太夫様役所へ差し出す。上水の縁通（両岸の通路）の添地内に異変があれば、水面に関わる事は御普請方御役所と町奉行所へ訴え、年貢地内の事は町奉行所と御代官役所へ訴える**。〔**①玉川上水両縁通（両岸通路）の添地（預り地）構造と年貢帰属の実務文言repo初出候補、②水面/地内で訴え先が変わる管轄区分は上水管理の実務区分の一次記録、③「芳野永御年貢年」等の崩壊部と「東ratis」の混入はOCR崩壊・原画像必須**〕。
- **玉川上水橋3ヶ所の維持責任文言〔文言候補〕（p72）**: 「**一橋三ヶ所 但天龍寺一手持石橋壱ヶ所 但天龍寺裏門前ニ有之 長弐間半巾壱間半 同門前町内一手持板橋壱ヶ所 但町内北之方二有之 長弐間壱尺三寸巾七尺五寸 武家方町方組合持石橋壱ケ所 但町内西北角に有之 □□□巾壱間半 右何れも玉川御上水に懸渡有之候**」＝**玉川御上水に架かる橋3ヶ所の管理区分＝①天龍寺一手持の石橋（裏門前・長2間半巾1間半）②町内一手持の板橋（北之方・長2間1尺3寸巾7尺5寸）③武家方町方組合持の石橋（西北角・巾1間半）**。〔**同一上水区間内で寺持・町内持・組合持が橋単位で書き分けられている維持責任の一次文言群＝[GAZ-141](GAZ-141.md)の万年石樋区間（大木戸〜伝馬町壱丁目）より下流（西寄り・千駄ヶ谷側）の玉川上水の実態を補う資料。天龍寺門前＝上水堀の外（北）側の町と流末の「牛込川文」の位置から、本橋群の比定は原画像・絵図照合前提**〕。
- **上水の流れの方位文言〔文言候補〕（p72）**: 「**右西之方 武間(=豊嶋郡?OCR崩壊) 豊嶋郡代々木村新町(=新門候補?)ゟ当町内二懸り 夫lrt東之方 同間(=町?) 同郡内藤所宿(=新宿候補)南堂(?)lrt内藤大和守様御下屋敷内え流レ入申候**」＝**（上水/水路）西は豊嶋郡代々木村新町(?)から当町内に懸かり、東は内藤新宿(?)南…内藤大和守様御下屋敷内へ流入**。〔**方位の取り方（西→東）は「内藤様御下屋敷内え流レ入」＝吐水の流下（[GAZ-141]塩町三丁目条・[GAZ-112]の内藤下屋敷→千駄ヶ谷系統）と対応候補だが、「当町内二懸り」の主語（上水本川か吐水路か）は原画像照合まで確定しない**〕。
- **天龍寺門前の町割・由来文言〔文言候補〕（p67-69・73-74）**: ①「**四谷天龍寺門前町屋之義 権現様関東御入国之砌 遠州倉見領西郷村瀧谷法泉寺に西月友船公之御任解(=御縁起候補?OCR)有之候に付 右寺御当地へ御引移被仰付 其節於矢込(=牛込)御膳元(?)天龍寺寺地三万六千坪被下置 護本山(=勅本山?候補)天龍寺之改号被仰付候り 其後天和三亥年天龍寺類焼之節 於当所壱万弐千弐百九坪余 勢地(=余地候補)被下置 内五千坪余門前商百姓家 追々出来仕 其後只今之如く町方御支配に相成候由**」＝**天龍寺・門前町の由来：家康関東入国時、遠州倉見領西郷村瀧谷法泉寺が当地（牛込）へ引移・寺地3万6千坪下置・天龍寺改号→天和3亥年（1683）類焼の際、当所（四谷）に1万2,209坪余の余地を下置→内5千坪余に門前商百姓家が成立→町方支配**。②「**惣家数百九拾弐軒**」・字「**客町中道堀端**」の里俗唱（p69）・隣町（東天龍寺・西長延寺門前・南千駄谷町・**北玉川御上水**）の四至。③名主利兵衛の由緒「**明暦三年御城御普請有之候節 天龍寺義八王(=?)よ千人同心宿仕 御普請御出来後御城え天龍寺被為召 千人同心宿仕候段御喜悦に被為思召 依之白銀五百枚被下置**」（p72-73）。〔**「客町中道堀端」の字名＝中道の堀端（上水堀端）の 地名候補。由緒文言は寺・門前町の成立史の記録（類焼の天和3年下置と「牛込→四谷」の移転が玉川上水以北の門前町成立のタイミングになる点を記録）**〕。
