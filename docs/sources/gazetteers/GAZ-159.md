# [GAZ-159] 町方書上[23] 飯倉町方書上 全（文政10-11年）— 青山上水の大通樋筋と赤羽新堀川の年代記

- **書誌〔確認〕**: 『[23] 飯倉町方書上　全』（写・NDL次世代デジタルライブラリー [book/2571504](https://lab.ndl.go.jp/dl/book/2571504)。NDL目録volume表記「[23] 飯倉町方書上　全」・直接確認）。飯倉町壱〜六町目（p6/16/29/（四町目はコマ未同定）/52/82）・狸穴町（p90）・片町（p98）・永坂町（p107）の町条（条末は「文政十亥年九月 右町名主兵庫」〔p80〕等）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571504_{NNNNNNN}.txt`）。※青山上水・新堀川は当repo四河川のいずれでもないが、[GAZ-103](GAZ-103.md)青山上水条（未解決④＝流路復元）への回答材料として採録する。
- **飯倉町五町目条の青山上水の大通樋筋文言〔文言候補・本冊最重要〕（p78-79）**: 「**一青山上水之事 屋敷名前等 此上水現存之時之名前也 此外も可准知 青山上水新規掛渡 万治三庚子年初而出来 右之水口は四谷大木戸 水門垣根外石垣ゟ木柱に而水口を附 南之方江 裏大笹町通ゟ 東之方横町通り 夫ゟ表大並町 森川出羽守・久能和泉守前（p78） 青山六道辻え出 夫ゟ青山丹波守下屋敷前 紀伊藤中屋敷後通 青西門前 青山大通 紀伊殿辻番所前二而二筋二相成 一筋は東之方 赤坂大消（=火消・OCR候補）屋敷脇辺迄相懸り 一筋は紀伊殿辻茶所前横町 青山丹波守下屋敷内 足軽町通 龍土町 谷（=森・OCR候補）出羽守・鍋嶋摂津守屋敷前通 六本木町 有馬宮内屋敷藤（=垣・OCR候補）ニ而二筋ニ相成 北之方は市兵衛町通 石川主水・垣安芸守家敷前通 石尾七兵衛屋敷前 榎坂迄 一筋は六本木町ゟ飯倉片町 上杉弾正大粥（=大給・OCR候補）下屋敷前通にて二筋二相成 一筋は飯倉町通四ツ辻江出 一筋ハ同朋町 秋田信濃守屋敷脇通二而又候 二筋二相成 西之方は芝新堀同朋町 東之方は京極采女屋敷前迄相懸り 右は凡大通樋筋計如此 上水享保七寅年十月より相止**」（p78-79・OCR）＝**①青山上水の起立＝万治三庚子年（1660）・新規掛渡、②水口は四谷大木戸（水門・垣根外石垣・木柱で水口を附ける構造文言）、③大通樋（本管）の流路を4つの分岐ノード（紀伊殿辻番所前＝2筋／六本木町有馬宮内屋敷垣＝2筋／飯倉片町上杉屋敷前＝2筋／同朋町秋田屋敷脇＝2筋）で列記し、東筋は赤坂火消屋敷脇まで、西筋は芝新堀同朋町・東筋は京極采女屋敷前まで相懸る、④「右は凡大通樋筋計如此」＝大通樋（本管）だけを記し配水小管は略す旨の限定文言、⑤享保七寅年十月より相止、⑥屋敷名は上水現存時の名でその他は推定を許す旨の「此外も可准知」文言**。〔**[GAZ-103](GAZ-103.md)の【上水在絕記】引用（「四谷大木戸より…左右へ懸る」）の流路復元（未解決④）に対し、水口の構造・分岐ノード・末端指定・「大通樋筋だけ」の限定の4点を補う町方側（飯倉）の一次文言候補（repo初出。御府内備考の在絕記引用とほぼ対応する経路を独立の町の調書で確認＝対校）。[GAZ-163](GAZ-163.md)麻布五冊の青山上水文言群（龍土町への委譲文言・平岩右膳役所の書付指令）と給水区域を両側から挟む形になる。**〕
- **飯倉町五町目条の赤羽新堀川の三度の工事年代記〔文言候補・repo初出候補〕（p76-77）**: 「**一赤羽新堀川 古来者 高井戸代々木辺用水之餘 渋谷辺ゟ落水ニ而 右川筋共へ 金杉川口迄小堀有来候由 百六拾ヶ年以前 寛文八申年之頃 松平相模守様・松平新太郎様御手伝に而 金杉川口ゟ麻布十番迄新規川御普請有之 川幅広相成候由 其節道御奉行大久保甚右衛門様・安部四郎五郎様 町御奉行嶋田出雲守様・宮崎若狭守様（p76）御掛り之由申伝候 其後百五拾三ケ年以前 延宝三卯年之頃 米高直ニ付 飢人為御救 金杉川口ゟ麻布十番堀留辺御入用にて御浚有之 御手伝無御座 其節之川浚御掛り 岡田将監様・石川蔵人様 道御奉行大久保甚右衛門様・中坊長兵衛様之由 其節同時に赤羽橋新規御掛渡有之 同年十二月七日右御普請出来致 酒井雅楽頭様・稲葉美作守様 町奉行嶋田出雲守様・宮崎若狭守様 道御奉行安部四郎五郎様・大久保甚右衛門様御見分御座候由 百三拾ヶ年以前 元禄十一寅年之頃 右川筋 渋谷辺ゟ麻布十谷（=十番・OCR）迄伊達美作守様 十番堀留ゟ金杉川口迄溝口信濃守様御手伝にて川渡御座候由 稲生七郎右衛門様・奥田八郎右御（=エ・OCR）門様御懸り之由 其後新堀川浚無御座候**」（p76-77・OCR）＝**①「赤羽新堀川」の直呼文言、②古来は高井戸・代々木辺の用水の余水と渋谷辺からの落水が金杉川口までの小堀であったとする起源観察文言、③寛文8申年（1668・「160年前」＝文政11-160で整合）に金杉川口〜麻布十番の新規川普請・川幅拡張（松平相模守・松平新太郎の御手伝／道奉行・町奉行の役名列）、④延宝3卯年（1675・「153年前」で整合）に米価高による飢人救済の御浚＋赤羽橋の新規掛渡（同年12月7日出来・御見分列）、⑤元禄11寅年（1698・「130年前」で整合）に渋谷辺〜麻布十番＝伊達美作守・十番堀留〜金杉川口＝溝口信濃守の御手伝による川渡（稲生七郎右衛門・奥田八郎右エ門が御懸）、それ以降の浚は無し**＝寛文8開削 - 延宝3浚＋赤羽橋 - 元禄11川渡の3工程の各自内部的な年数整合（文政11年基準）を備えた年代記文言。〔**[GAZ-106](GAZ-106.md)麻布新堀総説（御府内備考）の「延宝三年二月金杉新堀舟入出来す」「元禄十一年寅八月…堀はしめ…米の価高く民大に飢たるを御救として」＋[GAZ-160](GAZ-160.md)芝新細町条の延宝3・元禄11年文言と役名が一致（岡田将監・石川蔵人／稲生七郎右衛門・奥田八郎右エ門／溝口信濃守・伊達美作守）する独立の町方側witness**で、麻布新堀成立論（白金御殿造営時改水流説〔GAZ-106〕に対する寛文8年新規普請文言候補）の対校材料。役名の判読はOCR照合前提。〕
- **新堀川＝里俗「赤羽川」と赤羽地名群〔文言候補・repo初出候補〕（p67・p68・p62-64・p78）**: 五町目条に「**一新堀川 但川幅七間程 右は町内南之方上納地先に有之 里俗赤羽川ゟ唱申候 尤河岸通り家前往還道敷并川際迄凡長弐拾間 幅拾壱四尺（OCR） 町内持場 寛政元卯年六月廿五日御目附方ゟ被仰付候**」（p67・OCR）＝新堀川の幅（7間余）と里俗「赤羽川」呼称・寛政元年6月25日の町内持場の御目附方申付文言。p68に高札文言「**飯倉町壱町目ゟ六町目迄 同片町 同六本木町 同永坂町 同程（=桜・OCR候補）宮町共拾ヶ町惣持ニ而 建初年代相知不申 元赤羽植木溜前に建置申候処 天明七未年正月中右植木溜地所飯倉町五町目外四ヶ所え代地に御割渡…**」＝高札10ヶ町惣持と「元赤羽植木溜」の地名文言（p68-69・御札取払→文化9申年8月に当町自身番屋脇へ建替）。p62-64に「**赤羽広小路往還道処持場**」「**赤羽円月院**」（御霊屋）の地名文言（p62-64）。p78に「**一赤羽橋 当時は武家方御組合持 有馬玄番頭様・松平土佐守様…織田愛之助様**（13家の組合持列挙）」の文言。〔麻布側の「赤羽」地名群（赤羽新堀川・赤羽川・赤羽橋・赤羽植木溜・赤羽広小路・赤羽円月院）の集中の記録＝[GAZ-106]の語源説（下流の芝赤羽根川説）の裏側の材料。渋谷川中流（広尾〜宮益）の「赤羽川」〔[GAZ-103]第189回追記〕とは別の川の同名呼称として両用例の対校に供する（同一視は断定しない）。高札の移転史（植木溜前→代地割渡→各町→文化9年建替）は高札行政の実務記録。〕
- **飯倉各町の青山上水の定型文言群〔文言候補・給水区域の確定材料〕（p13・p23・p24・p35・p44・p67-68・p87・p103-104）**: 壱・弐・三・四・五・六町目条に「**青山上水 万治三子年中初而出来 右上水当町え相懸り候処 享保七寅年十月中相止 当時上水無御座候**」（万治三「子」年／「三千」年＝庚子のOCR変種が併存）の定型文言が連続する（弥生句の前後に出火時打潰し6ヶ町組合等の定型文言を含む）。p23・p35に里俗の坂名文言（鴈木坂・かわらけ坂）、p87に抜坂（榎坂説文言：「**坂内何れ之場所に候以上大抜有之候に付里俗榎坂と唱来候由申伝候**」＝飯倉三・弐町目間の四ツ辻付近）が付随。〔青山上水の給水区域が飯倉6ヶ町＋片町等に及んだことの各町列挙文言＝給水区域復元の材料。与えられた文言が万治3庚子年（1660）で飯倉側から「初而出来」と記される点は[GAZ-103]在絕記の年次と一致。〕

## 制限・未解決

- ①すべてOCR由来で要原文照合。p78-79の大通樋筋の屋敷名・人名（「垣安芸守」「石尾七兵衛」「大粥」「藤ニ而」等）と p76-77の役名の原字、年数計算の「百六拾ヶ年以前」等の数字判読は照合前提。②青山上水・三田上水の給水の別（飯倉側への給水が青山上水の末端部か・飯倉側に三田上水の文言が見えないことの意味）は断定しない。③寛文8年新規普請文言候補と[GAZ-106]白金（白全）御殿造営時改水流説・延宝3舟入説（江戸鹿子引用）の関係、④元禄11文言と[GAZ-160]芝新細町条・[GOV-410](../gov/GOV-410.md)元禄12卯年堀広文言の同年性の解釈、⑤「高井戸代々木辺用水之餘・渋谷辺落水」の起源観察文言と渋谷川総説（GAZ-103「西千駄ヶ谷起源」）・赤羽川の水源認識（GAZ-146「内藤新宿追分ゟ玉川分水」）の関係はいずれも対校課題として残す。
