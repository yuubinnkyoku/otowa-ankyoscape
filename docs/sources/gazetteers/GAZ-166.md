# [GAZ-166] 町方書上[102] 本所町方書上 一 — 相生町三丁目条の神田川常浚請負人の助成地系譜

- **書誌〔確認〕**: 『[102] 本所町方書上 一』（写・NDL次世代デジタルライブラリー [book/2571583](https://lab.ndl.go.jp/dl/book/2571583)。NDL API volume欄直接確認）。本所相生町三丁目条（koma 81-82）ほか、三軒目条に神田川常浚上り地文言（koma 100）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号。※当repo四河川の神田川（江戸川下流）に直接関わる町方側実務文言として採録。
- **元禄6年の川筋常浚請負の助成地文言〔文言候補・本冊最重要〕（koma 81-82）**: 「**元禄六酉年五月廿八日 新之口御堀ゟ新堀大川口迄 飯田町堀留ゟ数寄屋橋迄 南紺屋町橋ゟ京橋迄 霊岸橋ゟ南川口迄之川筋常浚御請負仕候為助成…請負人嘉兵衛外六人え拝借地に被仰付**」（koma 81-82・OCR）＝**①元禄6年（1693）5月28日、新之口御堀〜新堀大川口・飯田町堀留〜数寄屋橋・南紺屋町橋〜京橋・霊岸橋〜南川口の4区間の川筋常浚を請負った嘉兵衛外6人の助成拝借地だったこと**の文言候補。〔**新之口御堀（神田上水系の新之口堀）から霊岸橋・南川口（江戸川下流域）までの神田川系の浚渫請負が本所側の拝借地で助成されていた実務記録（repo初出候補）**。町名「相生町三丁目」の起立もこの請負（「其砌ゟ本所相生町三町目と相唱申候」）に由来する文言＝**川の常浚請負が町の起立由来になるという珍しい起立譚**（文言候補）。〕
- **寛延3年の神田川常浚請負人文言〔文言候補・請負人名の系譜〕（koma 82）**: 「**其後寛延三午年六月中 神田川常浚請負人駿河屋新兵衛錠屋清五郎ト助成地二被下置候所 天明四辰年五月中被召放 同年十月中山崎屋七郎兵衛北門屋治郎右衛門両人え跡請負被仰付…寛政二戌年四月二日請負被召放右地所…上り地**」（koma 82・OCR・前後に享保5子年5月中の牛込御堀定浚助成地への相渡〔名主長兵衛御預り・朽木丹後守様丸毛美濃守様〕文言あり）＝**①寛延3年（1750）6月中に神田川常浚の請負人が駿河屋新兵衛・錠屋清五郎だったこと、②天明4年（1784）5月召放→同年10月に山崎屋七郎兵衛・北門屋治郎右衛門への跡請負、③寛政2年（1790）4月2日の請負召放（上り地化）**の文言候補。〔**「神田川常浚」の語の町方書上レベルの用例と、請負人名（駿河屋新兵衛・錠屋清五郎／山崎屋七郎兵衛・北門屋治郎右衛門）がrepo初出**（神田川維持の実務系譜の空白期を埋める候補。OCR変種「神田川常俊」「交負人」もあるため原画像照合前提）。〕
- **三軒目条の神田川常浚上り地文言（koma 100）**: 「**神田川常俊（=常浚・OCR）助成上り地…古来常浚上り地之内享保の度名主長兵衛御預る地に相成候所 寛延三午年六月中神田川常浚交負（=請負・OCR）人…**」（koma 100・OCR）＝三軒目側でも同一の神田川常浚助成地系譜を記す対校文言候補＝**相生町系の複数町で「神田川常浚」助成地の定型書き分けが存在**することの観察。

## 制限・未解決

- ①すべてOCR由来で要原文照合（「錠屋清五郎」「神田川常俊/常浚」「交負人/請負人」「寛延三午年」〔寛延3=1750年=庚午で干支整合〕等）。②「新之口御堀」の実体（神田上水の新之口〔飯田町側〕か）と4区間の神田川系水路の比定は本史料のみでは確定しない。③請負人嘉兵衛外6人・駿河屋新兵衛・錠屋清五郎と、[GAZ-165](GAZ-165.md)の清水八郎兵衛・家城善兵衛系の道役・[GAZ-167](GAZ-167.md)の白堀浚受負人群との人脈関係は未確定（同一の本所奉行系の実務層の可能性は断定しない）。④相生町の起立由来文言（常浚請負の助成地に町名由来がある）は本冊の述べ立てで、他冊の対応文言（壱丁目条への委譲文言）は未照合。
