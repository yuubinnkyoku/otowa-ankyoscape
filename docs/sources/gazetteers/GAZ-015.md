# [GAZ-015] 『新編武蔵風土記稿』池袋村条の水田・用水記述

- **原史料の所在〔確認：公的目録〕**：間宮士信ら編『新編武蔵風土記稿』**巻之12（豊島郡之4）**。国立公文書館デジタルアーカイブの簿冊目録は、**冊次0005**に巻之11・12・13を収録すると明記する（請求番号267-0079）。参照：[国立公文書館・簿冊目録](https://www.digital.archives.go.jp/file/1224755)。同館の目録から巻の所在は確認できるが、**池袋村条の原画像・頁・コマは未閲覧**。
- **刊行年代〔確認：書誌〕**：『新編武蔵風土記稿』は江戸後期に編纂された地誌で、上記公開版は**内務省地理局の1884年（明治17年）刊行版**。1884年を村の地形や水田・用水の成立年とみなさない。書誌：[国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/books/R100000002-I000000425830)。
- **池袋村条の引用〔二次転記／原本未照合〕**：地域史ブログ「[池袋村](https://ameblo.jp/kazuaruki/entry-12940941596.html)」（公開日未確認）は『新編武蔵風土記稿』から、村の**北東側だけに水田があり、周辺が窪んだ袋状の地形**とする説明、および「**用水は仙川用水を引沃く**」という記述を引用する。ブログによる転記・省略を含むため、原本と一致するかは未確認。
- **地名の二説との関係〔確認：ブログの主張／推定：地理的な照合価値〕**：筆者は池袋村北東の**谷端川流域**を地名の地形由来説の候補とし、別に丸池周辺説を挙げる。丸池は旧雑司ヶ谷村側に属したとする点を論点にする。これは既収録の豊島区「わが街ひすとりぃ」[GOV-034](../gov/GOV-034.md)が紹介する**二説の背景を補う二次解説**であり、語源の確定ではない。
- **用水系統の留保〔未解決〕**：転記の「仙川用水」を、既収録の**千川上水・長崎村外三村分水**と直ちに同じ施設・取水経路と断定しない。表記、原文の文脈、取水地点、村内の配水経路、谷端川本流への接続を、巻之12原本と近世池袋村絵図 [MAP-018](../maps/MAP-018.md)・1877年の四ケ村用水文書 [GOV-016](../gov/GOV-016.md)で照合する必要がある。
- **年代表記の留保〔未解決〕**：ブログは『遊歴雑記』の説明に**1814年**を添えるが、既収録の1997年『ぞうしがや』45号は**1829年**と記す。原典の成立年・巻次の不一致は未解決のまま扱う。
