# [GAZ-028] 東京案内（1907年）— 音羽町の町別解説に見る弦巻川

- **書誌〔確認〕**: 『東京案内』（**明治40年・1907年**刊の東京市の町名解説付き案内書）。NDL次世代デジタルライブラリーに本文2点（[book/764078](https://lab.ndl.go.jp/dl/book/764078)・別版 [book/900276](https://lab.ndl.go.jp/dl/book/900276)）が公開される。**すべての引用は同館OCRテキスト由来（カナ・ローマ字混りの誤読を含む）であり、文言は原文画像との照合を要する。**
- **音羽町の弦巻川〔確認・repo初出〕**: 町名解説で**音羽町二丁目「弦卷川西を流る（つるまきがは）」・三丁目「弦卷川西に在り 下流音羽瀧となる」・四丁目「弦卷川は本町の西をも流る」・五丁目「（弦卷）川西を流るゝこと亦同じ」・六丁目「川西に存り」・七丁目「西に弦卷川あり」・八丁目「西に弦卷川あり（八幡坂）」・九丁目「本町の西をも弦卷川流る」**＝**1907年時点で弦巻川が音羽町2〜9丁目の西側を開渠で流れていたことを町別に記す記録**。あわせて**櫻木町「町の西には弦卷川あり」**、神田上水の通過（「神田上水あり」）も併記される。〔文言・町丁対応はOCR要照合〕
- **意義〔観察〕**: ①弦巻川の開渠観察として、既収録の1910年『礫川要覧』・1919年『高田村誌』・1929年『高田の今昔』などに先行する**1907年の市販地誌レベルの町別位置記録**を加える。②「**下流音羽瀧となる**」の下流接続の定型文言の1907年用例。③既収録の1931年起工・1932年の道路化（弦巻川の暗渠化）以前の流路形状の記述資料として、音羽町西端の流路位置の補強。
- **制限〔注意〕**: 町名解説は当時の町界・通称に基づく記述であり、流路の微地形・幅員・水量は記さない。**1907年の開渠記述をもって1907年時点の水量・景観を確定しない。**

## 制限・未解決

- ①『東京案内』の編者・発行者の確定（東京市関与か民間刊行か）は書誌確認を要する。②「音羽瀧」の比定は既収録の音羽の滝関係記事に依る（本書では位置を明示しない）。③別版（900276）との本文異同は未照合。④音羽町一丁目に弦巻川の記述があるかどうかは今回の抽出では未確認。
