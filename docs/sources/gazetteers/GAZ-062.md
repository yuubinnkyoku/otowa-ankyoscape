# [GAZ-062] 日本地名大辞典 第5巻（1938）— 千川溪谷の断層谷説の地形学記述〔repo初出・第139回／谷端川工場分布文言の追記・第319回〕

- **書誌〔確認〕**: 『日本地名大辞典 第5巻』（昭和13年＝1938刊。地名辞典の東京府・東京市の巻で地形・地名の解説章を含む）。NDL次世代デジタルライブラリー [book/1116352](https://lab.ndl.go.jp/dl/book/1116352) のOCR全文を確認。**引用文言はOCR由来（「西市」「消ふ」等の崩れあり）で原画像照合を要する**。
- **千川溪谷の断層谷説〔確認・repo初出〕**: 東京市の地形章に「**（和田堀·落合間の神田川中流、）大和田·板橋間の千川溪谷（、四谷坂町·飯田橋間の溪谷、澁谷川上流の千駄ヶ谷溪谷等ハ東北·西市（西南のOCR誤候補）行ノ斷層ニ消フ（沿フのOCR誤候補）モノト考ヘラル**」＝**千川溪谷（大和田・板橋間＝現在の千川台地縁〜石神井川下流域の谷）を東北-西南行の断層に沿う断層谷とする1938年の地形学記述**＝千川溪谷を構造谷（断層谷）として説明する説を地名辞典レベルで採録した例。**観察**: 別箇所に「**根津藍染川ノ溪谷、板橋下流ノ千川溪谷、池尻下流ノ目黒川溪谷…等ハ西北·東南行ノ斷層ニ沿フ**」の文言もあり、**同一書内で千川溪谷が西北-東南系とも東北-西南系とも分類される**（OCR崩れの混在のため、原書が両系統を併記しているのか・章ごとに別の記述かは原画像照合まで確定しない＝谷の走向の実測との対照は地形学分野の今後課題として記録）。
- **山ノ手台地の地形区画〔確認・対校〕**: 「**斯クノ如キ地形ノ山ノ手臺地ハ地形上次ノ如ク分ツコトヲ得**」に続く地形区画の説明で、**千川上水と玉川上水が台地区画の境界をなす**という説明の構造（区画名の割付はOCR崩壊のため文言化は保留）＝千川上水が地形認識の区分線として使われてきた観察の旁証。
- **水窪川の陰性記録〔確認・false positive〕**: 本書の「水窪川」は「**中部久根銅山間ノ河谷ナリ…西渡ニテ東北青〓（安倍?）近傍ニ發源シ本流ト並行ノ縱谷ヲ流下スル水窪川ヲ入ル**」＝**静岡県の別川（安倍川水系・龍山村域の水窪川）**で、repo対象の水窪川（目黒川支流）とは無関係（検索のfalse positiveとして記録し、資料採用はしない）。

## 2026-11-25・第319回追記 — 金属工場分布章の谷端川文言〔repo初出〕

- **谷端川の工場分布文言〔確認: OCR全文・列崩壊の再構成〕**: 工業章の金属工業の分布記述に「**金屬製錬竝（並）に材料品工場は（山ノ手の）新市街地域に最も盛大なるも、板橋·品川·…の山手線沿線の石神井川·谷端川·（神田?）…の各區にも行はる**」という形式の文言がある（OCRの列崩壊が著しいため区名列挙の正確な並び・「行はる」の直前の主語範囲は再構成ベースで**断定しない**）。＝**1938年時点の工場分布記述に山手線沿線の浅蝕谷として石神井川と谷端川が並んで挙げられた記録**で、①山手線沿線の工場化の範囲に谷端川流域（新宿区下落合側・豊島区・北区側の谷）が含まれていたこと、②**谷端川が石神井川と同格の「沿線に小工場が分布する谷」として1938年に類型化されていたこと**の旁証候補〔観察: 工場化の実数・密度は本文表の原画像照合まで確認できない〕。同じ章に江東・東京灣面の大工場集中と対比する構造も見える（列崩壊のため概要のみ）。
- **対校情報〔確認・同一本文の別本〕**: NDL [book/1031309](https://lab.ndl.go.jp/dl/book/1031309)（『日本地名大辞典 第5巻』の別保有本・1939年刊行）にも**同一文言が存在**することを確認〔確認: 両OCR全文の突合〕。両本のOCRでは以下の対立が見られるため**原字は原画像照合まで留保**: 「淺蝕谷（1116352）／浸蝕谷（1031309）」・「計器額／計器類」・「銭金工場／鍍金工場」・「織工場／鐵工場」・「製練工場／製罐工場」等（1116352側にはハングル文字混入等のOCR壊れもある）。**「淺蝕谷／浸蝕谷」は同書の地形章の用語（GAZ-188『日本地理講義』の「淺蝕谷」との用語対照資料）ともなるため、原字確定は谷端川・千川の谷地形記述の用語史に資する**。
