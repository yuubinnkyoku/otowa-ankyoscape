# [GAZ-062] 日本地名大辞典 第5巻（1938）— 千川溪谷の断層谷説の地形学記述〔repo初出・第139回〕

- **書誌〔確認〕**: 『日本地名大辞典 第5巻』（昭和13年＝1938刊。地名辞典の東京府・東京市の巻で地形・地名の解説章を含む）。NDL次世代デジタルライブラリー [book/1116352](https://lab.ndl.go.jp/dl/book/1116352) のOCR全文を確認。**引用文言はOCR由来（「西市」「消ふ」等の崩れあり）で原画像照合を要する**。
- **千川溪谷の断層谷説〔確認・repo初出〕**: 東京市の地形章に「**（和田堀·落合間の神田川中流、）大和田·板橋間の千川溪谷（、四谷坂町·飯田橋間の溪谷、澁谷川上流の千駄ヶ谷溪谷等ハ東北·西市（西南のOCR誤候補）行ノ斷層ニ消フ（沿フのOCR誤候補）モノト考へラル**」＝**千川溪谷（大和田・板橋間＝現在の千川台地縁〜石神井川下流域の谷）を東北-西南行の断層に沿う断層谷とする1938年の地形学記述**＝千川溪谷を構造谷（断層谷）として説明する説を地名辞典レベルで採録した例。**観察**: 別箇所に「**根津藍染川ノ溪谷、板橋下流ノ千川溪谷、池尻下流ノ目黒川溪谷…等ハ西北·東南行ノ斷層ニ沿フ**」の文言もあり、**同一書内で千川溪谷が西北-東南系とも東北-西南系とも分類される**（OCR崩れの混在のため、原書が両系統を併記しているのか・章ごとに別の記述かは原画像照合まで確定しない＝谷の走向の実測との対照は地形学分野の今後課題として記録）。
- **山ノ手台地の地形区画〔確認・対校〕**: 「**斯クノ如キ地形ノ山ノ手臺地ハ地形上次ノ如ク分ツコトヲ得**」に続く地形区画の説明で、**千川上水と玉川上水が台地区画の境界をなす**という説明の構造（区画名の割付はOCR崩れのため文言化は保留）＝千川上水が地形認識の区分線として使われてきた観察の旁証。
- **水窪川の陰性記録〔確認・false positive〕**: 本書の「水窪川」は「**中部久根銅山間ノ河谷ナリ…西渡ニテ東北青〓（安倍?）近傍ニ發源シ本流ト並行ノ縱谷ヲ流下スル水窪川ヲ入ル**」＝**静岡県の別川（安倍川水系・龍山村域の水窪川）**で、repo対象の水窪川（目黒川支流）とは無関係（検索のfalse positiveとして記録し、資料採用はしない）。
