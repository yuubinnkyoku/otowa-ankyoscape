# [GAZ-128] 町方書上[71] 四谷御門外麹町書上 — 玉川上水の城内循環樋と分水井・外堀端の大下水の町方側一次記録

- **書誌〔確認〕**: 『町方書上[71] 四谷御門外麹町書上　全』（写・NDL次世代デジタルライブラリー [book/2571552](https://lab.ndl.go.jp/dl/book/2571552)・108コマ）。麹町拾壱町目〜拾三町目ほかの御調書上（13丁目条末尾に「以上文政十…」の署名年候補＝文政10〔1827〕候補）。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571552_{NNNNNNN}.txt` コマ番号。**
- **麹町拾壱町目条の玉川御上水伏樋＋分水井11ヶ所〔文言候補・本冊の主要価値〕（p11）**: 「**町内往還ニ埋有之 玉川御上水 御本丸掛 吹上掛 御樋式筋 西ゟ東え相流し 幷新道御組合樋 同様相流申候 右御組会(=合候補)樋ゟ 分水井拾壱ケ所 町内ニ有之候**」＝**麹町11丁目の往還に埋設された玉川上水の樋（御本丸懸けと吹上懸けの「御樋式筋」）が西→東に流れ、同じく新道の御組合樋も流れ、その樋から分水井11ヶ所が町内にある**。〔① 御本丸・吹上への二方向かけ（江戸城内循環）を町内書上のレベルで数える文言＝[GOV-354]（安永撰要類集の「四ッ谷御門外上水樋」人足文言）・[GAZ-112]（御府内備考・玉川上水の江戸市中側規定）の町方側の裏付け、② 単一町内の**分水井11ヶ所**という集中度は repo初出の数値候補（[GAZ-118]・[GAZ-119]の本郷側樋文言群や [GAZ-120]〜[GAZ-123]の湯島側の分水井列と並ぶ給水実態の datapoint）、③ 「御組合樋」＝麹町壱丁目外17ヶ町の出銀によると推定される組合運用の樋（下の石橋文言の「拾七ケ町」参照）〕。
- **麹町11丁目条の御堀端通の大下水〔文言候補・四谷御門外の東西大下水〕（p11）**: 「**御堀端通大下水 右は御堀端通町内町屋前二有之 巾五尺ニ而大通公儀下水 西之方ゟ東え相流 四谷塩町壱丁目之方え流落申候**」＝**外堀端通りの町家前にある巾5尺の「公儀下水」（大下水）が西→東に流れ、四谷塩町1丁目の方へ流れ落ちる**。〔**四谷御門外の外堀沿いの東西方向の大下水の一次文言候補**。この水路の実体（溜池系〔GAZ-116〕・藍染川系〔GAZ-099〕・澱橋側低地のいずれか・あるいは独立の公儀下水）は本文言からは断定しない。赤坂側の大下水文言群（[GAZ-116]の赤坂川・桜川・弁慶堀）と並ぶ「大下水」語彙の府内外堀端沿いの用法として対照表・対校の対象〕。
- **麹町11丁目条の石橋・板橋〔橋の文言候補〕（p11）**: ①「**石之橋 田内竹町入口に 幅三間長八尺 新規掛渡修覆之儀 先規ゟ当町ニ而頭取世話仕 出銀之儀は麹町壱丁目外拾七ケ町ゟ差出し申候**」＝石橋（幅3間・長8尺）の新規掛渡・修覆は先規から麹町側が頭取世話を務め、出銀は麹町1丁目のほか17ヶ町持ち（**計18ヶ町の組合構造**）。②「**板之橋 町内新道入口に 巾弐間長八尺 大下水上に掛け有之 新規修覆共四谷伝馬町壱町目組合ニ而仕来申候**」＝**大下水（上の文言の公儀下水）に架かる板橋**（巾2間・長8尺）は四谷伝馬町1丁目組合持ち。〔**上の「大下水」の空中を捉える橋の維持主体が隣町（四谷伝馬町1丁目）にあること**は、この大下水の経路・維持負担の境界を復元する材料。「田内竹町入口」の語はOCR崩れ候補（原画像照合課題）〕。
- **麹町拾三町目条の玉川御上水樋＋分水井3ヶ所〔文言候補〕（p27）**: 「**町内往還埋有之 玉川御上水 御本丸掛 御板弐筋 西ゟ東え相流 幷里俗吹上村大横町 御組合樋壱筋 同様相流 右御役合(=役合候補)樋ゟ 御分水請井三ケ所有之 右之通取調申上候**」＝**玉川上水の御本丸掛けの板樋2筋＋里俗「吹上村」大横町の御組合樋1筋が西→東に流れ、樋から御分水請井3ヶ所**。〔11丁目条と同型式の文言。「里俗吹上村」の呼称と「大横町」の樋は [GAZ-034]（御府内備考・四谷側）の吹上方面の地名対照の材料〕。
- **麹町拾弐町目条の高枡火消文言〔文言候補〕（p17）**: 「**四谷御門外玉川上水 御本丸掛 吹上掛 御組合 右高枡江最寄出火之節 町火消五番組之内や(?)組人足 同断六番組之内為(?)組の組人足 右三組に而四百三拾八人駆付可申旨 寛延三午年八月廿七日 馬場讃岐守様御内寄合ニ而被仰付**」＝**四谷御門外の玉川上水樋区間の「高枡」付近の火消人足438人（町火消2組＋1組の三組）の駆け付け体制が寛延3年（1750）8月27日の御内寄合（馬場讃岐守殿）で仰付けられた**。〔**「高枡」＝樋の高低差を処理する樋枡（大桝系）の実在と防火の対象化**＝樋・枡施設の維持管理の側面から見た玉川上水の四谷御門外区間の一次記録。[GAZ-117]（古事類苑・千川上水8ヶ所禁制リストの「四ッ谷」文言なし）との対照でも四谷御門外の樋群の堀割維持の実態を挟み撃ちにできる〕。
