# [GAZ-104] 寺社書上[26] 小日向寺社書上弐 — 善仁寺の承応2年神田上水御堀開き収用の代地履歴

- **書誌〔確認・一部要照合〕**: 冊子頭文言「**寺社書上 小日向寺社書上弐**」＋収録寺社の列挙（**専教院・十日向(?)長寿寺・深光寺・大円寺・大明照寺・徳雲寺・林泉寺・伝明寺・吉念寺・上小日向善仁寺・弥勒寺(?)等**）＋「**二七六ノ第廿八**」の類の調書番号表記（OCR崩れ込み）＝**文政期の幕府による寺院明細（御調書上）の小日向分の写**（[GAZ-076](GAZ-076.md)関口寺社書上〔文政10年調〕と同系列の綴）。NDL次世代デジタルライブラリー [book/2571383](https://lab.ndl.go.jp/dl/book/2571383)。**引用はすべてOCR由来で文言は原文画像との照合を要する。**
- **善仁寺条の「承応二己年神田上水御堀開キ」＝寺領収用の年代文言候補〔文言候補・repo初出の寺社側年次記録〕**: 「**…寺領田地壱反弐歩(?)石登(?)七斗代 右往古は境内続二而当寺門前二有之候 承応二己年神田上水御堀開キニ付 御用地ニ被(召上?) 江戸三代地(?) 明暦元未年於東青柳町裏送りニ被下之候 其節御懸曽根源蔵殿 大森半七殿ゟ被申渡候 其後元禄年中護国(寺?)奉寄(?)町屋二相成候 二付又…元禄十丑年九月於小日向村之内被下之候 御朱印ハ無之 御老中御澄文(?)御勘定判御預り二相成…**」＝**①善仁寺門前の寺領（田地1反余）が承応2年（1653・「己年」はOCR崩れ候補＝癸巳年の誤植か）の「神田上水御堀開き」の御用地として召し上げられ、②明暦元年（1655）に東青柳町裏へ代地として下され、③その後町屋化し、元禄10年（1697）に小日向村内に代地給付（護国寺への代知給付の記録も同条内）**＝**神田上水（白堀〜関口〜小日向区間）の開削を「承応2年の堀開き」とする年代文言の、地誌・申伝（[GAZ-035](GAZ-035.md)桜木町条の「承応二年御堀割之由に御座候申伝」・[GAZ-049](GAZ-049.md)⑬の白堀通文言）に対して、寺社側の寺領収用・代地履歴というファクトの年次として提示する点が新しい**（神田上水開削年代論の対立群（承応2年／寛永／万治等）の対校資料として加えるが、収用年次の記述自体が後代の書上への聞書再録である可能性は残り、採否は断定しない。干支（承応2＝癸巳・明暦1＝乙未）の「己年」「未年」の整合は原画像照合前提）。
- **善仁寺の代知と護国寺（元禄10年）〔文言候補〕**: 「**元禄十丑年…高八斗四升 右は善仁寺領 此度護国寺え被下為代知 細井九左衛門御代官所…小日向村之内可相渡旨之御勘定所御証文請取申候 近日地割可相渡候以上 元禄十年丑十一月九日…**」＝善仁寺領が元禄10年に護国寺の代知として下された御勘定所証文の写（小日向村内の代地給付の実務記録）。本文言は寺領移転史の補助記録として、[GAZ-073](GAZ-073.md)（雑司ヶ谷の代地履歴）等の収用・代地史の系列に対校可能。
- **陰性〔確認〕**: 本冊fulltextで「谷端」0件・「千川」0件・「水窪」0件・「弦巻」0件・「用水」0件・「池」0件・「沼」3件（「沼朝入継大統」等の崩れで地形沼ではない）＝**対象4河川の川名用例は本冊に見えない**。上記善仁寺条の神田上水文言が本冊の実質的な新情報（「上水」2件はいずれも善仁寺条内）。
