# [GAZ-188] 日本地理講義 下巻・小石川区条 — 東伍説（野水谷端川→千川剰水→神田川）の教科書への明示帰属と系譜の確定

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 阿部秀助著『日本地理講義』下巻（**金刺芳流堂・1910**・[book/762731](https://lab.ndl.go.jp/dl/book/762731)）。中等教育程度の地理講義書で、東京市各区の解説のうち**小石川区条の括弧内注記**に谷端川の沿革文言がある。**引用はOCR由来で、判読不能部・組版崩壊部（市内各区の見出しが本文行に混入）を含むため、文言の再構成箇所は〔〕で明示し原本照合を要する**。

## 文言〔確認・要照合・再構成部は明示〕

- **日本地理講義・小石川区条**（東京市各区の列挙中の注記括弧）:
> 小石川區（**吉田東伍氏の說に**元巢鴨村より出つる野水**谷端川の末〔OCR「未」＝末の崩れ候補〕なりしが**、今は千川上水の剰水を容れ、**小日向臺と白山臺との間を流れ、富坂下より砲兵工廠に入〔り〕**〔←OCR「入四谷區牛込區小石川區り」＝段落混入崩壊〕**…神田川へ注ぐ、昔は之も駿河臺の西にて小川と相會せしならん、此の邊を一般に小石川村と云ふと**）

- **対校（同一文言系・別書）**: 藤岡継平編『日本歴史地理辞典』（1907・[book/771424](https://lab.ndl.go.jp/dl/book/771424)）小石川条:
> 小石川 東京小石川區を流る、その源は**巢鴨村より出づる野水、谷端川なりしが、今は千川上水の剩水を容れ小日向台と白山台との間を流れ、富坂下より造兵所へ入り、神田川へ注ぐ、小石川の名これより起る**

## 読み取り〔観察・系譜の確定と帰属の相違〕

- **①東伍説の明示帰属〔確認・本登録の核心〕**: 本書は谷端川の沿革文言（元巣鴨村発の野水谷端川→千川剰水受容→小日向台と白山台の間→富坂下から砲兵工廠→神田川注込）を「**吉田東伍氏の說**」と**明示的に帰属して**引用する＝[GAZ-065](GAZ-065.md)（大日本地名辞書・東伍1907）にすでに見える東伍の小石川・谷端川記述の系統が、**1910年時点の地理教科書レベルで「東伍説」として流通していた**ことの証明〔文言の骨格（野水→剰水→神田川）は[GOV-164](../gov/GOV-164.md)（東京市下水道沿革誌1914）の「元巣鴨村ヨリ出ツル野水谷端川ノ末ナリシカ後千川上水ノ剰水ヲ容レ…現今ハ直チニ神田川ニ注ク」とも一致し、1907地名辞書→1907藤岡辞典→1910教科書→1914下水道沿革誌という**系譜の現れ方の違い（帰属の有無）の記録**〕。
- **②帰属の有無の対比〔観察〕**: 藤岡継平編『日本歴史地理辞典』（1907）はほぼ同一の文言を**帰属なく採録**する＝同一文言が帰属つき（本書）と無帰属（藤岡）で並走していた。藤岡版にのみ「**小石川の名これより起る**」の語源文言が付く〔東伍の原文言にこの語源文言があるか（大日本地名辞書小石川条の原形の確認）は今後の対校課題。いずれも原照合までは同一原典の変奏と断定しない〕。
- **③「駿河臺の西にて小川と相會せしならん」〔仮説文言の流通〕**: 本書だけに見える文言で、**谷端川/小石川の旧流路が駿河台の西で「小川」（神田川上流部の古称）に合流したであろうとする東伍の推定文言**が含まれる〔「昔は…ならん」と推量表現のまま＝旧河道復元の**仮説**として保存価値がある。OCRの文字面は要照合〕。「此の邊を一般に小石川村と云ふ」の地域呼称文言も本書のみ。
- **④富坂下→砲兵工廠（造兵所）の流入点〔確認・地形との整合〕**: 「富坂下より砲兵工廠に入り」＝谷端川（小石川）が**富坂の下で造兵所（後の小石川砲兵工廠・現・東京ドームシティ周辺）構内に入る**という流点位の記述は[GOV-164]の「直チニ神田川ニ注ク」（1914）より上流側の立ち位置が具体的〔藤岡版「富坂下より造兵所へ入り」との一致。富坂と白山台・小日向台の関係はREADME §谷端川の地形記述と対応〕。富坂下より構内に入る本研究の谷端川流路の途中点の再確認に使える。

## 制限・未解決

- ①本書の文言は組版崩壊（区名見出しの本文行混入）を含み、再構成〔〕部は原本照合まで確定しない。②「未なりしが」は「末なりしが」のOCR崩れと判断したが〔ママ〕で保存する（[GOV-164]の「末ナリシ」が傍証）。③東伍の原典（大日本地名辞書の小石川条本文）との直接対校は本回は未実施（GAZ-065は白子川条・井頭条中心で小石川条の文言採録を含まない）。④藤岡辞典の文言もOCR由来で要照合。⑤「小石川の名これより起る」の語源説（小石川村説）は藤岡版で初出という趣旨ではなく、帰属の問題としてのみ記録。
