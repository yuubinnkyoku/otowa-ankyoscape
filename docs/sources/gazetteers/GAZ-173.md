# [GAZ-173] 町方書上[117] 中之郷 壱 — 筧播磨守検地文言群と「岸堀」名義文言

- **書誌〔確認〕**: 『[117] 中之郷町方書上 壱』（写・NDL次世代デジタルライブラリー [book/2571598](https://lab.ndl.go.jp/dl/book/2571598)。NDL API volume欄直接確認）。又之橋町条・四之橋通条（koma 8・24-25他）を含む。文政十一子年十月四之橋通名主庄太郎署名（koma 25）。引用文言はすべてOCR由来で要原文照合。※第223回の本冊boilerplate陰性判定（四河川keyword）は以下の文言群を捉えていなかった＝本回訂正。
- **筧播磨守の享保17年検地文言群〔文言候補・本冊最重要〕（koma 32・38・45・73 vs koma 25）**: ①「**…享保十七子年 筧播磨守様 御縄入御水張相済申候**」（koma 32周辺・OCR）等、koma 32・38・45・73の4箇所で「筧播磨守様」の享保17年（1732）の検地系文言（御改・御検地・御縄入御水張）が繰り返される、②一方koma 25に「**御検地 享保十七子年 覚播磨守様御改に御座候**」（OCR）＝**「筧播磨守」4件vs「覚播磨守」1件のOCR判読対立**の文言候補。〔**[GAZ-138](GAZ-138.md)（小梅瓦町条）の「享保十七子年九月 筧播磨守様 御検地 御高入ニ相成」（上水堀埋立跡の高入文言）の「筧」字判読を、独立の冊の4:1の多数で裏付ける材料候補**（原画像照合まで決着しない）。本冊側の文言は上水堀埋立跡以外の中之郷全域の検地文言（御水張=水張検地の用語も）で、享保17年の中之郷検地の一環として小梅側の高入（[GAZ-138]）と同時期・同年次の行政作戦の一部であることを示唆する候補。〕
- **里俗「岸堀」→「堀留」の名義文言〔文言候補〕（koma 24）**: 「**一堀長拾八間程 町内地先に御座候 巾弐間三尺 右者町内南之方ニ有之 里俗岸堀え相唱候処 後来誤りきんし堀留留来申候 堀割年代等相分不申候得共 往古右堀通ニ御材木蔵有之 其岸通ニ付唱始候由ニ御座候**」（koma 24・OCR）＝**①堀長18間程・巾2間3尺の町内南の堀、②里俗は「岸堀」だったのが後に誤って「堀留」と唱えるようになった、③往古この堀通に御材木蔵があり、その岸通に付けて唱え始めた**という名義文言候補。〔**「岸堀→堀留」の誤称化（里俗の変遷）を当事者が明記する珍しい文言（repo初出候補）**。誤称化の方向「誤りきんし堀留留来申候」の句切り（「誤り禁し」?「誤り呼し」?）はOCR要照合。御材木蔵（中之郷側の材木蔵跡=当時亀戸村田畑）と堀の関係は[GAZ-174](GAZ-174.md)・[GAZ-178](GAZ-178.md)（十間川・材木蔵火除文言）との対照材料。〕
- **一ツ目〜五ツ目の竪川橋と又之橋町の町名文言（koma 8）**: 「**町方之義は竪川通本所一ツ目ゟ当町は五ツ目に御座候間 以前は橋も有之候処 貞享年中御取払者相成候得共 一ツ目ヲ一之橋と相唱候故 又之橋町と申来候由二御座候**」（koma 8・OCR）＝**①竪川通の本所一ツ目〜当町（五ツ目）間に以前は橋があったが貞享年中（1684-88）に御取払になったこと、②「一ツ目を一之橋と唱える故、又之橋町と申来」る町名の由来**文言候補。〔**竪川の橋（一ツ目〜五ツ目）の貞享年中取払の一次文言候補（repo初出候補）**＝[GAZ-165](GAZ-165.md)（起立書の一之橋〜四之橋・万治2・元禄8年 datapoint）と接続し、万治2（堀立と初懸）→貞享（一部取払）→文政（書上）の竪川橋の変遷材料。取払の範囲（全部か一部か）は「橋も有之候処」とあり曖昧＝断定しない。〕

## 制限・未解決

- ①すべてOCR由来で要原文照合（「筧/覚播磨守」・「誤りきんし堀留留来」・「御取払者相成」等の句切り）。②各筧播磨守文言の条帰属（又之橋町条・四之橋通条等の別）はkoma位置から精密化できていない（koma 32・38・45・73 の条区切りは原画像照合前提）。③「御水張」の語（水張検地=水田検地か水張工事か）の解釈は未確定。④岸堀の堀の実体（亀戸川?〔呼称のみで未比定〕・亀戸村側材木蔵への引入堀か）は比定できていない。
