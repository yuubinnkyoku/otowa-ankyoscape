# [GAZ-181] 町方書上[48] 芝町方書上　弐（文政10亥）— 増上寺周辺大下水の桜川／宇田川二重呼称と弁天ノ井

- **書誌〔確認〕**: 『[48] 芝町方書上　弐』（写・NDL次世代デジタルライブラリー [book/2571529](https://lab.ndl.go.jp/dl/book/2571529)。NDL目録volume表記「[48] 芝町方書上　弐」・APIで直接確認。表紙通し番号「二七四ノ第四十九」）。収録は源助町（見出しp5）・露月町（p22）・柴井町（p31）・芝新銭座町（p41）・宇田川町（見出しp53・署名「宇田川町 文政十亥年八月 名主弥兵衛」p67）・宇田川横町・中村町等。条はいずれも文政10亥年（1827）8月提出。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571529_{NNNNNNN}.txt`）。
- **宇田川町条の大下水＝里俗「桜川」／「宇田川」二重呼称文言〔文言候補・本冊最重要〕（p58）**: 「**一大下水壱ケ所 幅壱丈 長町内様之場五拾壱間壱尺 右は本堂宿下より増上寺裏門前通り 宇田川横町裏手之方江懸り 町内往還を横切無之 新銭座町海手江流落申候 里俗桜川又は宇田□□（川と判読候補・OCR切れ）共ニ相唱申候**」（p58・OCR）＝**①宇田川町の大下水（幅1丈・長51間1尺）、②起点＝本堂宿の下より増上寺裏門前通りを経て宇田川横町裏手に懸り（往還の横切なし）、③流末＝新銭座町の海手へ流落、④里俗に「桜川」または「宇田川」との二重呼称、の4点**。〔**増上寺周辺の大下水の里俗二重呼称の文言候補（repo初出。芝の大排水系の名前の一次記録）**＝[GAZ-160](GAZ-160.md)芝新細町条の増上寺構堀大下水＝里俗「榎川」（愛宕下通大下水の末・宇田川横町西境で分水→芝神明社地後→増上寺表御門前→金杉川落入）と対校すると、**本冊の文言は本堂宿下→増上寺裏門前を通る大下水の主水路側の記述と読める**（両文言の水路の同定・併走の別は断定しない）。「桜川」の用例は四谷の桜川（[GAZ-110](GAZ-110.md)/[GAZ-112](GAZ-112.md)）・赤坂の桜川（[GAZ-116](GAZ-116.md)）と同名異流の第3例候補（repo初出。川名の同定は原画像照合前提）。「宇田川」の川名としての使用例（町名宇田川町の由来方向・[GOV-452](../gov/GOV-452.md)澁谷町の地図ラベル「宇田川」との関係）も対校課題。〕
- **源助町条の弁天ノ井（油之井）文言〔文言候補・井戸・湧水〕（p15）**: 「**一町内伊助店文蔵借地内に有之候井戸之儀は往古水赤く有之日用に難用候故油之井と相唱候由 其後年月不知 右井ゟ弁財天之儀一体堀出し候ゟ跡清水二相成 夫ゟ弁天ノ井と申伝候 右弁天像之儀は町内持に而祭り有之候処 其後明和六己年正月中芝口三町目日比谷稲荷え相殿ニ相預ケ申候**」（p15・OCR）＝**①往古は水が赤く日用に耐えない「油之井」→年月不知に弁財天一体を掘り出した後に「清水」に成り「弁天ノ井」と申伝、②弁天像は町内持で祀られたが明和6年（1769）正月に芝口三町目日比谷稲荷へ相殿に預けた、の井戸の水質変化・社の遷座の文言**。〔**井戸の水質の変遷（赤水→清水）を伝える一次書上の文具候補**＝湧水・井戸系資料（[GAZ-113]清水横町の法境星稲荷「名水之井戸」等）の対校材料。水質変化の実態（掘削・湧水線の変化か伝承修辞か）は断定しない。〕
- **源助町条の下水・水落口・水吐口文言〔文言候補〕（p14-15）**: 「**源助大通りに相懸り候小橋を源助様と相唱申候由御答申上候儀御座候由承伝申候…右下水浚入用之儀は是口弐町目・同三町目・源助町・露月町・柴井町五ヶ所之水落口ニ御座候ニ付割合右町々江相掛申候 水吐口之儀は松平陸奥守様・松平肥後守様御屋敷境下水ゟ濱御殿脇堀江落申候…**（中略）…**一町内西之方新道武家方御屋敷境大下水之儀は長九拾壱間余幅六尺之場所…寛文四辰年七月中新道明候ゟ已後武家方ニ不拘町内壱手持ニ御座候 尤水仕口之儀は壱口弐町目・同三丁目・露月町・柴井町ゟ之藤合ニ而町内横切下水江水落し申候**」（p14-15・OCR）＝**①源助町大通りの小橋「源助」の人名由来説（年次不明）、②下水浚の入用を水落口5ヶ所（是口弐町目・同三町目・源助町・露月町・柴井町）の割合で担う実務文言、③水吐口＝武家屋敷境の下水から濱御殿（浜御殿）脇の堀へ落とす、④新道の大下水（長91間余・幅6尺）は寛文4年（1664）7月の新道開通以後は武家方に拘らず町方が一手持**、の4点。〔芝口から芝浦側への下水の流れと費用手続の実務記録。「濱御殿」＝芝浦の浜御殿（寛文2年頃設置の御鷹場・御殿）と読めるが比定は保留。長南ケ崎の地名文言（「上総国長南ト向ひ合居候処二而往古船着之由依之長南ケ崎ト相唱」p14）＝海岸地形の旧観察の名残として併記。〕
- **露月町条・柴井町条・新銭座町条〔確認・水系実質文言なし〕**: 露月町条の源助町西之方の御屋敷替文言（文化7年10月・p29）・柴井町条・新銭座町条（稲荷社勧請・p51）に水系の実質文言はなし＝陰性。
