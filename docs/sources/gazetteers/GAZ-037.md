# [GAZ-037] 大江戸志16巻 — 千川屋敷の火消組合（九番組）所属の記録

- **書誌〔確認〕**: 『大江戸志』16巻[5]（写本・小石川周辺の巻か。町方の組織（地親・名主・火消組合）の列挙を含む）。NDL次世代デジタルライブラリー [book/2553932](https://lab.ndl.go.jp/dl/book/2553932)。**引用はすべてOCR由来（写本のOCRは特に崩れが多い）で、文言は原文画像との照合を要する。**
- **千川屋敷＝九番組町火消組の一つ〔確認・千川屋敷の町方組織実態の初出〕**: 小石川白山周辺の町々の組織の列挙——「**…小石川白山前町同南片町同白山大通司安閑寺前町衣笠勘七重田弥二右エ門田中六右エ門同千川屋敷同智光寺前町同白山社地門前同善仁寺門前同妙清寺門前十八円乗寺門前同丸山田町…**」・「**…門前諸役組合へ入同所白山大道通白山坂上四辻両側片面地親付御手貢地十四番但名主朱引九番組町火消了組同所千川屋敷同所続片面片側拝領町屋敷諸役組合へ入**」〔**①「千川屋敷」が小石川白山前町・南片町・白山大通・各寺院門前町などと並ぶ町方の一単位として列挙されていること、②「九番組町火消〔タ〕組」（OCR「了」は崩れ）の所属町の一つに「同所千川屋敷」があること、③「片面片側拝領町屋敷・諸役組合へ入」（片面町・拝領町屋敷として諸役の組合に入る）という分類文言が付されていること、④「地親付御手貢地」・「名主朱引」等の組織文言が周辺に並ぶこと**＝**千川屋敷が地誌（町方組織の記述）のレベルで、九番組の町火消組合・諸役組合に編入された町方（片面の拝領町屋敷）として記録されていた実態の初出（repo初出）**。千川屋敷が単独の「町」単位（町名ではないが組合の構成単位）として扱われていたことが、行政文書（[GOV-219](../gov/GOV-219.md)拝領屋敷調査）とは独立の地誌系資料からも確認できた**〕〔九番組の所属町数（ハンドオフ時に「28町」と要約した数）はOCRの列挙の通し番号・改行の対応からは確定できず、原文照合まで保留（「十八円乗寺門前」の「十八」は崩れの可能性大）〕。
- **白山坂上四辻・円乗寺門前の文言〔観察〕**: 「白山坂上四辻両側片面地親付御手貢地」・「円乗寺門前」の文言は、千川屋敷の位置（白山前町＝白山坂上の四辻周辺）を地誌の町並み記述の文脈で囲み込むもの（[GAZ-038](GAZ-038.md)町鑑・[GOV-208](../gov/GOV-208.md)白山前町の比定と整合する方向）。文言の細かい対応（「御手貢地」＝御拝領地の崩れか）は要照合。
- **第118回追記・同16巻[2]（book/2553929）の「十四番組」町列挙にも千川屋敷〔確認・文言候補〕**: 『大江戸志』16巻**[2]**（写本・[book/2553929](https://lab.ndl.go.jp/dl/book/2553929)）の町方組織の列挙に「**十四番組一小石川白山前町白山坂同白山大道通附木店鶏声窪巣鴨横道四ッ辻同千川屋敷同丸山田町同妙清寺門前同後乗寺門前同常検寺門前同白山社地内門前同丸山浄心寺門前…**」（御成街道新屋敷・下谷筋と続く番組リストの中の小石川白山前町側の列挙と読める）＝**本巻[5]（九番組町火消）とは別の巻・別の番組（十四番組）の町列挙にも「同千川屋敷」が現れること**。〔**千川屋敷が複数の番組編成（火消組合・御成関連の区分と読めるが対応は未確定）の町列挙に繰り返し現れることの対校記録**。番組の性格（[5]の九番組＝町火消〔タ〕組との対応・十四番組の区分の意味）・列崩れの解消は原文照合必須。〕
