# [GAZ-063] 北足立郡誌（1924）— 保谷村・榑橋村の東京府移管の年表記録と郡会議員保谷半六〔repo初出・第141回〕

- **書誌〔確認〕**: 『北足立郡誌』（埼玉県北足立郡長**武田熊蔵**序・**北足立郡役所**・大正13年（1924）6月刊。郡制廃止（大正12年4月1日）を記念した郡誌で序に「**郡域の變更を始めとし**」とある）。NDL次世代デジタルライブラリー [book/978754](https://lab.ndl.go.jp/dl/book/978754) のOCR全文を確認（**表組みのOCRが高度に崩壊しており年次の割付は読み取れない箇所が多い**）。
- **沿革年表の保谷村・榑橋村の東京府移管の2件〔確認・repo初出＝第140回観察の修正・精密化〕**: 沿革年表（旧領地域調）に「**(四月保谷村を東京府に移す)**」「**(六月樽橋村を東京府に移す)**」の2条が並ぶ（**「樽橋」は「榑橋」のOCR誤読候補**＝本文に「榑橋」の表記は現れない）。**榑橋村（1889年町村制で小榑村＋橋戸村をもって成立・埼玉県新座郡）が東京府へ移管されていたことを郡誌の年表が記録する**＝第140回[GOV-330](../gov/GOV-330.md)「**埼玉県から東京府へ移ったのは保谷村のみ**」という観察の**修正点**：旧新座郡から東京府へ移った村は**保谷村（1907年4月1日・法律第8号）と榑橋村（外側資料で1891年6月15日・東京府北豊島郡大泉村の一部として）の2村**（榑橋村は単独移管でなく大泉村への合併編入）。**年表の各条の年次割付はOCRの表崩れで確定できない**（保谷村=明治40年はGOV-330で確定済み。榑橋村=明治24年6月15日は[Wikipedia「榑橋村」](https://ja.wikipedia.org/wiki/%E6%A6%91%E6%A9%8B%E6%9D%91)による三次資料で**法律・官報レベルの一次確認は未了・断定しない**。同記事は動機を小学校統合（榑橋小学校〔本照寺・現西大泉3丁目〕と豊西小学校〔妙延寺・現東大泉3丁目〕の統合）とする）。
- **新座郡章の2村のみの明記〔確認・対校〕**: 新座郡章に「**(今は樽橋、保谷の二村東京府に入れり)**」＝**旧新座郡から東京府に移された村は榑橋（樽橋）・保谷の2村のみ**と郡誌が明記＝年表の2条と整合する郡誌内部の一貫した説明。新座郡の和名（爾比久良）・享保2年の郡名の唱の制定等の記述は[GAZ-064](GAZ-064.md)（風土記稿新座郡巻）の郡総説と対校可能（文言はOCR崩れあり）。
- **保谷村の千川用水の水元を含む郡会選挙区の記録〔確認・repo初出〕**: 郡会議員補欠選挙・増員選挙の当選者名簿に「**保谷半六**」（住所欄=**保谷村**・明治31年5月31日または7月13日の選挙のいずれか＝表崩れで割付確定不可）が登載＝**1898年（明治31年）時点で保谷村が埼玉県北足立郡の郡会選挙区（植水村・扇村・馬宮村・膝折村・山村・保谷村・谷塚村等の選挙区）を構成していた行政記録**＝1907年4月1日の東京府移管（[GOV-330](../gov/GOV-330.md)）の9年前の所属の傍証。生年月日欄との割付はOCR表崩れで確定できない。
- **榑橋村先行移管による府県跨ぎ構造の精密化〔観察〕**: [GOV-330](../gov/GOV-330.md)の「千川用水の流路の府県跨ぎの時期構造」（〜1893年=3府県跨ぎ、1893〜1907年=2府県跨ぎ）について、**1891年6月15日の榑橋村の東京府移管（外側資料）を挟むと、旧新座郡側では榑橋村（小榑村・橋戸村）が1891年に先行して東京府へ移り、1891〜1907年の16年間は水元の保谷村（埼玉県）のみが埼玉県に残置**する構造が成り立つ（榑橋村・大泉村域が千川用水の流路に含まれるかどうかは本資料群からは確認できず、[GAZ-051](GAZ-051.md)（豊多摩郡誌・石神井村竹下出棚橋）・1918年北豊島郡誌（保谷村より石神井村へ来る）の流路記述との関係は今後の課題として断定しない）。
