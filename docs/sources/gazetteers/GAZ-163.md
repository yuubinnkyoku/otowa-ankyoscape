# [GAZ-163] 町方書上[39] 麻布町方書上 五（文政11子年）— 龍土町条の青山上水流路文言と平岩右膳役所の御書付指令

- **書誌〔確認〕**: 『[39] 麻布町方書上 五』（写・NDL次世代デジタルライブラリー [book/2571520](https://lab.ndl.go.jp/dl/book/2571520)。NDL目録volume表記「[39] 麻布町方書上 五」・直接確認）。表紙に「地誌御詞（=調・OCR）書上帳 麻布徳土六本木町」（p5）＝**麻布六本木町（p6-54）・麻布龍土町（p55-65）とその周辺門前町各条の合本**。条末署名は「文政十一子年」（p9・18・22・30・40・47・54・67・71・78・85等・OCR）。引用文言はすべてOCR由来で要原文照合。引用位置は頁＝コマ番号（`2571520_{NNNNNNN}.txt`）。※青山上水は当repo四河川のいずれでもないが、[GAZ-103](GAZ-103.md)青山上水条（未解決④）・[GAZ-159](GAZ-159.md)飯倉町条への給水区域側（麻布）の対として採録する。
- **龍土町条の青山上水大通樋筋文言＝文政9戌年5月の平岩右膳役所御書付の写し〔文言候補・本冊最重要〕（p59-61）**: 「**…七寅年中御取潰二相成 委細之訳相知不申候処 **去文政九戌年五月中御代官平岩右膳様ゟ御刀（=掟・OCR候補）持之節 上水通筋御書付出候間 右写左に申上候** 一青山上水新規掛渡 万治三庚子年初而出来 右水口者 四ツ谷大木戸外水門垣根外 右垣根ゟ木樋ニ而水口を附 南之方え裏大番町通ゟ東之方横町通 夫ゟ表大番町 森川出羽守 久能和泉守殿前 青山六道ノ辻え出 夫ゟ青山丹後守屋鋪前 紀伊殿中屋敷後 青西門前 青山大通紀伊尉辻番所前にて御筋に相成 壱筋は東之方にな坂火消屋敷脇辺迄相掛 一筋者紀伊殿辻番所前横町 青山丹後守下屋敷内足軽町まで 龍土町 谷（=森・OCR候補）出羽守 鍋嶋摂津守屋敷前通 六本木町甚大内屋敷前に而弐筋之相成 北之方は市兵衛町辺石川主水（p60） 稲垣安芸守屋敷前通り 石尾七兵衛屋鋪前 榎坂迄 壱筋は六本木町ゟ飯倉片町 上杉弾正天下屋敷前通りニ而弐筋ニ相成 壱以助者飯倉町通四ツ辻え出 壱筋は同朋町 秋田信濃守屋敷脇通りに而又けん筋に相成 西之方は芝新堀同伯町 東之方者京極采女屋敷前迄相懸り 右者凡大通樋筋はかり如此 この上水享保七寅年十月ゟ相止御書付記有之**」（p60-61・OCR）＝**①龍土町の青山上水の委細記述が「文政9戌年（1826）5月中に御代官平岩右膳様（御掟持之節）に出された上水通筋の御書付の写しである」と明記する文言、②万治3庚子年（1660）新規掛渡・四谷大木戸の水口から芝新堀同朋町・京極采女屋敷前までの大通樋筋の流路列記（分岐ノードは紀伊殿辻番所前・六本木町甚大内屋敷前・飯倉片町の3ヶ所＋同朋町で西=芝新堀同朋町／東=京極采女屋敷前へ）、「右者凡大通樋筋はかり如此」の限定文言、享保7寅年10月相止＋「御書付記有之」**。〔**①「文政9年5月の平岩右膳（代官）役所の上水通筋御書付」の写しである旨の文言＝[GAZ-159](GAZ-159.md)飯倉町五町目条の大通樋筋文言（p78-79）と本冊の龍土町条の文言がほぼ文言一致で対応することから、**両町の記述が同一の御書付（文政地誌御調の際に官辺から各村・町へ出された上水通筋の照会文書）を写したことが判然とする材料候補（repo初出）**。地誌御調書上（文政10-11年）の文言群の出所＝代官所の照会御書付という過程レベルの情報（fielddocumentの系譜）は、文言の価値づけ（一次の流路記録か・照会文書の写しか）に直結する鍵史料候補。**②御書付末尾の指令文言「万治三子年初而青山上水新規出来 享保七寅年十月相止候由 別紙廉々之内其村ニ而相心得居候儀者書付ニ致差出可申候 尤書冨（=付・OCR候補）等も無之不相訳候は以書付来ル十日迄に否可申出候 平岩右膳役所」**（p61・OCR）＝各村が心得ていることは10日限で書付にして差し出すよう命じた役所署名（平岩右膳役所）の文言候補。地誌御調の手続き（10日限の照会）が水系文言の成立過程に直接見える数少ない用例。**③龍土町＝青山上水の給水区域の麻布側の「委細申上候」の代表町**＝[GAZ-161](GAZ-161.md)金杉通壱町目（芝側）・[GAZ-158](GAZ-158.md)三田壱町目（三田側）と同じ「本筋の情報を代表町が申出る」委譲構造の本管側例。〕
- **六本木町・門前各町の青山上水定型文言群〔文言候補・給水区域の確定材料〕（p8・p29・p46・p53・p77）**: 六本木町条に「**一万治三子年 青山上水新規出来 町内往還二上水通り候処 享保七寅年十月中御取潰ニ相成申候 沢（=委細・OCR候補）は徳土町ニ而委細申上候**」（p8・OCR）、p29（門前町条）に「**一万治三子年 青山上水新規出来 町内往還二上水通り候処 享保七寅年十月中御取潰ニ相成 委細者然土町二而申上候**」（p29・OCR）、p46・p53（同門前条）に「**一上水跡 右は青山上水 万治三子年中初而出来 右上水当町往還二相懸り候処 享保七寅年十月中〔相止/五日（OCR）〕 当時上水無御座候 委細之儀は二棟布（=麻布・OCR候補）龍土町ゟ申上候**」（p46・p53・OCR）、p77に「**一上水跡 右青山上水之儀 万治三子年中初而出来 享保七寅年中御取潰二相成候由 委細之儀は然土町ニ而申上候**」等（p77・OCR）。〔**麻布六本木町とその周辺門前町の各条が万治3年（1660）新規出来・享保7年（1722）10月中取潰・委細の龍土町への委譲文言を定型として連続させる**＝青山上水の給水区域が六本木周辺（飯倉〔GAZ-159〕と連続する麻布側南縁）に及んだことの各町列挙文言で、龍土町＝代表町の委譲構造（[GAZ-158]三田壱町目＝惣合計代表・[GAZ-161]金杉通壱町目＝芝側代表と並ぶ第3例）。「徳土町」「然土町」は龍土町のOCR変種（原字照合前提）。〕
- **麻布うとん坂（うらん坂）の名義と日ヶ窪の下水文言〔文言候補・参考〕（p29・p8）**: 「**一坂之儀ハ…大久保加賀守様御屋敷前ゟ西之方え通り候道筋 四ツ角…ニ而巾五間程登凡拾五間位有之 うとん坂と唱候儀ハ年月不知 旧家にてうらん病（=餅・OCR候補）売致候**」（p29・OCR）＝麻布北日ヶ窪周辺の「うとん坂」の名義（旧家がうらん餅を売った由）の文言候補。p8に六本木町の下水文言（「町内西之方角ゟ麻布日ヶ窪町通り大久保加賀守様御屋敷前横切下水」）。〔うらん坂（現在の六本木7丁目付近の坂名）の町方側の名義文言候補。青山上水の末端部の地形記録の文脈で周辺記録として採録（水系の直接情報ではない）。〕
- **龍土町条の町内・支配構造の文言〔文言候補・参考〕（p56-58・p63）**: 龍土町の起立文言（「往古者芝愛宕下ゟ西久保辺ニ有之漁ヲ致候者住居仕候ニ付 猟人村ト相唱候由申伝候処…寛永十年之頃ゟ…御代官所ニ而後年百姓町家々相成就 土町ト相唱 正徳三己年閏五月中…町方御支配二相成候」p56-57・OCR）・反別文言（「平岩右膳様御代官所ニ而町方之分町御支配ニ御座候…一御検地之儀ハ元流（=元禄・OCR候補）十九年十二月織田越前守様御改ニ而御水張所持仕候」p63・OCR）等。〔文政11年時点の麻布一帯の町方支配が平岩右膳（代官）所（OCR・「平岩登」の可能性に注意）であることを示す文言＝p59-61の御書付の発出主体（平岩右膳役所）と支配の一致が見える参考記録。「猟人村（りょうにんむら）」の起立も麻布周辺の地名史の材料。〕

## 制限・未解決

- ①すべてOCR由来で要原文照合。特に「御刀持之節」（御掟持之節等の原字）、「甚大内屋敷」（有馬宮内屋敷垣の[GAZ-159]文言との照合）、「谷出羽守」（森出羽守候補）、「二棟布」「書冨」等の判読は照合前提。②「平岩右膳」の原字は御府内備考等の平岩登（代官）の可能性があるが本掃引では確定しない。③[GAZ-159]飯倉文言と本冊龍土町文言の文言一致（同一御書付由来説）は文言対校による推定で、原本照合後に確定する。④御書付の発出年（文政9戌年5月）と地誌御調書上の取調（文政10-11年）の間の約1年の時間差の実務的な意味（予備照会か）は断定しない。
