# [GAZ-060] 『東都新繁昌記』（1918）— 1918年時点の谷端川の流路現勢と羽田川の文言

- **書誌〔確認〕**: 『**東都新繁昌記**』（**京華堂書店ほか・1918年〔大正7〕**）。NDL次世代デジタルライブラリー [book/959204](https://lab.ndl.go.jp/dl/book/959204)。大正期の東京の繁昌記・地誌案内。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①小石川＝谷端川の流路現勢文言〔確認文言・1918年時点の通史記録〕**: 「**小石川は源を北豊島郡長崎村に發し、田柄川・羽田川の小溝を合せて巢鴨村に入りて谷端川と云ひ、（この區〔小石川区〕に入りて）…久堅町、戸崎町、掃除町、柳町、初音町、下富坂を經、砲兵工廠に入り、後樂園の池水と合し、水道橋の西に出で、神田川に注ぐ、長さ二里三十二丁で、昔は大川であつたが、今は川端狹くなつた。**」（「今は川端しかきこうぢやうあやBあたあたせまこすゐりうかせいめいも狹くなつた」の部分はOCRが著しく崩れており「今は川端狹くなつた」の候補。区名・町名の間にOCRのカナ注記が混入）＝**①小石川（谷端川）の源を北豊島郡長崎村とし、②田柄川・羽田川の小溝を合わせて巣鴨村に入ったところで「谷端川」と称し、③久堅町・戸崎町・掃除町・柳町・初音町・下富坂を経て砲兵工廠に入り、④後楽園の池水と合し、水道橋の西に出て神田川に注ぐ、⑤長さ二里三十二丁、という1918年時点の流路・延長の記録**。〔**谷端川（小石川）の明治末〜大正期の流路現勢の通時系列に1918年の基準点を追加する文言**。④の下流流路（砲兵工廠→後楽園池水→水道橋の西→神田川）は[GAZ-048](GAZ-048.md)⑧の幕府期流路（橋戶町、柳町より傳通院東の方を流れ）・[BOOK-117](../books/BOOK-117.md)系の近代流路記録と対校できる。「昔は大川であつた」の文言は河道規模の変遷の観察記録〕。
- **②羽田川の合流文言〔確認文言・支川名としてrepo初出〕**: 上記文言中の「**田柄川・羽田川の小溝を合せて**」＝**谷端川（小石川）に巣鴨村に入る前に合流する小溝として「田柄川」とともに「羽田川」を挙げる記録**。〔田柄川（[GAZ-002](GAZ-002.md)・[GOV-098](../gov/GOV-098.md)系の既出文言）と並ぶ支川名の「羽田川」は**資料ファイルでは本書が初出**（谷端川上流域〔長崎村〜巣鴨〕の小支川名。同名の「羽田」〔大田区〕とは無関係。どの流路を指すか（現在の谷端川支流のどれか）は本書だけでは特定できない）。「はつこみ」等の直前のOCR注記（板橋方面か）は原画像照合を要する〕。
- **③工場町化の観察〔確認・内容メモ〕**: 同条にこの水流を利用したものは砲兵工廠であったこと、器械を生命とする工場に力を与える旨の叙述（OCR崩れあり）＝小石川区の「工場町」化と水流利用の1918年時点の観察。
