# [GAZ-066] 名水品彙（乗化亭著・1枚・刊年未詳）— 張巻川＝布引川の源流二流説と護国寺星谷系3湧水・神田上水源泉の実測品評録〔第144回〕

- **書誌〔確認・刊年未詳〕**: 乗化亭著『名水品彙』（**1枚物**。請求記号特1-2994・書誌ID000007325204・DOI 10.11501/2536983・PDM）。NDL次世代デジタルライブラリー [book/2536983](https://lab.ndl.go.jp/dl/book/2536983)。IIIF manifest・NDL書誌のいずれにも**刊年の記載なし**（2026-11-17確認）。本文の「**濵田侯ハ本上州館林**」（館林→浜田の転封は明治元年〔1868〕以降の状況を反映か）・「**酸素**」「**元素**」等の理学語彙から**幕末〜明治初期の成立と推定（要書誌確認）**。武蔵野近郊の名水を**温度（分度）・秤量（比重か）の実測値**付きで列挙する品評録（宇治・宇治橋三ノ間から多摩川・千川・谷端系まで網羅する体裁）。引用文言はOCR由来で要原文照合。
- **張巻川（弦巻川）条＝布引川の別名と源流二流説〔確認・文言候補〕**: 「**一張巻川一名布引川 源は二流あり一流は雑司谷丸池の濫泉一流ハ護国寺西岸ノ沃泉也 二水落会テ一河ト成り音羽ヲ過テ下流ハ神田上水ニ入ナリ 分度四十度秤量四十三銭**」＝**①張巻川（弦巻川）の別名を「一名布引川」とする**、②**源流は二流で、一流は雑司ヶ谷丸池の湧泉、他の一流は護国寺西岸の湧泉、二水が落合して一河となる**、③**音羽を過ぎて下流は神田上水に入る**、④温度40度・秤量43の実測値。〔**①は[BOOK-001](../books/BOOK-001.md)（暗渠散歩）・[GAZ-002](GAZ-002.md)（北豊島郡誌）・[GAZ-047](GAZ-047.md)/[GAZ-058](GAZ-058.md)（江戸名所図会「古へは布引川とも唱ヘける」）系の布引川異名の、名水品評という独立系統での裏付け文言**（「一名」の形式で布引川を並記）。**②の源流二流説（丸池＋護国寺西岸）は、1772年絵図の「丸池系本流＋護国寺裏門付近の独立した水源・支流が本浄寺南側で接続する水系」仮説（[弦巻川](../../弦巻川.md)・1772年図の読図）を本文資料の側から支える候補**＝**護国寺西側を水源の一つとする弦巻川観の新datapoint**。③は[BOOK-152](../books/BOOK-152.md)（遊歴雑記四編・護国寺角西門前石橋下で合流）と対校できる合流文言。原字（「張」か「弦」か・「濫泉」「沃泉」）は要照合〕
- **三角井・星清水・星之井の3湧水条〔確認・文言候補〕**: ①「**三角井泉 一名星之清水 護国寺西雑司谷の東青折町に有 分度三十九度秤量四十二半**」＝**三角井の別名「星之清水」と護国寺西・雑司ヶ谷東の「青折町」所在**。②「**星清水 護国寺ノ西方三角井ノ西ノ野中ニアリ 今宮崎氏ノ部内ニ引水アリ佳泉也 分度三十九度秤量四十三**」＝**三角井の西の野中に星清水があり、当時（書き込み時点）宮崎氏の部内に引水されている**。③「**星之井 護国寺西ノ山麓ニアリ 今乞食ノ井水ト成故ニ常人不汲之**」＝**護国寺西の山麓の星之井が「乞食の井水」とされ常人が汲まなくなった**という観察。〔**星谷（ほしやと）水系の湧水3点を別条として位置関係（青折町→三角井の西→護国寺西山麓）付きで記す品評録**＝対照表の「星谷の井／星谷の清水・星跡の清水」行・「星の井／星の清水」行の新資料。「三角井」と[BOOK-144](../books/BOOK-144.md)（遊歴雑記五編・鬼子母神掘出地の「三角の井筒」）との同一性は断定しない。宮崎氏・青折町の比定は未了〕
- **神田上水条＝井頭池七井と長内田氏旧家地〔確認・文言候補・長内田氏はrepo初出候補〕**: 「**神田上水 多摩郡礼邑（OCR崩れ・要照合）ノ井頭池七井ノ監泉（湧泉）ヲ発ス 其源泉ハ農夫長内田氏ノ舊家地ヨリ流注ス 寛永大樹屢比地ニ遊歴シ賜ヒ此泉ノ甘美清潔ナルヲ以テ七井ノ地ニ注シ井頭ト称ス 又善福寺妙正寺ノ湖流ノ二水 源流ノ三水合テ高田ヲ径テ関口テテテ分流シ 一派ハ西水府ノ内ニ入 一派ハ小日向ヲ過テ神田川ニ入 分度四十度秤量四十三**」＝**①神田上水は井頭池（井の頭池）七井の湧泉に発すること、②その源泉は農夫・長内田氏の旧家地から流注すること、③寛永帝の遊歴と「井頭」の称の由来、④善福寺・妙正寺の二水と合流して三水となり高田を経て関口で分流（一派は西水府〔水戸邸〕の内へ・一派は小日向を過ぎて神田川へ）すること**。〔**②「長内田氏ノ舊家地ヨリ流注」＝井の頭池の水源の所在を具体的な土地（農家の旧家地）まで記す文言はrepo初出候補**（[GAZ-065](GAZ-065.md)引江戸砂子「池中七所より水涌出づ・七井の池」系統の湧水記述に、源泉の土地柄を加える記録）。③の寛永帝遊歴説も江戸砂子系統と同型。④の流路（三水合流→関口分流）は神田上水の標準流路記述の品評録版〕
- **波除湧泉条〔文言候補〕**: 「**波除沃泉 豊嶋郡筑地波除稲荷社ノ東橋ノ傍ニアル埋樋ヨリ流テ墜ル 小金井ノ下流ノ末ニシテ玉川上水ノ止メ水より分**」＝築地波除稲荷社東の埋樋から流れ落ちる湧泉を「玉川上水の止水から分かれる」と記す＝既存の波除・埋樋記録の対校資料（品評録側の観察）。
