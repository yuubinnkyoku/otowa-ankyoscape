# [GAZ-001] 雑司ヶ谷村条「西青柳町ニ通ス」

- 二次転記: https://ameblo.jp/kazuaruki/entry-12940940738.html
- 転記では、弦巻川について「丸池ヨリ出テ一条ノ流と為リ、本村ノ中央ヲ東流シ西青柳町ニ通ス」とする。
- 『皇国地誌稿本東京府誌』は東京都公文書館所蔵「東京府村誌」全15冊の影印を含む。CiNii Books: https://ci.nii.ac.jp/ncid/BB30888890
- **現時点では本リポジトリで原画像を直接固定できていないため、二次転記による確認として扱う。**
