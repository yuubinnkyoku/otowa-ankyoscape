# [GAZ-125] 町方書上[76] 外神田町方書上四 — 柳原新シ橋際の往置樋と4月12日差止バリアント

- **書誌〔確認〕**: 『町方書上[76] 外神田町方書上　四』（写・NDL次世代デジタルライブラリー [book/2571557](https://lab.ndl.go.jp/dl/book/2571557)・98コマ）。冒頭目次文言＝「**第四久永屋鋪冨松町元地柳原新シ橋飯島屋鋪久右衛門町壱丁目蔵地同町弐丁目藏地八名川町外神田町方書上**」（p3）＝本冊は柳原新シ橋周辺の外神田諸町（冨松町元地・久右衛門町壱丁目蔵地・弐丁目蔵地・八名川町等）の書上群。**引用文言はすべてOCR由来で要原文照合。ページ番号は `2571557_{NNNNNNN}.txt` コマ番号。**
- **神田富松町条の千川文言〔文言候補・前段のみ判読可〕**: 「**千川上水之儀安永九子年中牧野大隅守様御番所二而被仰渡有之新シ橋通往還中程二大垣…**（以下コマ末尾で切れ、後段は佐久右衛門町壱丁目蔵地・久右衛門町壱丁目蔵・同町弐丁目蔵地・神田川・「右絵図面二申上候」の文言候補としてOCR高度崩壊）」（p23）＝〔**条帰属＝署名p24の神田富松町条（元地名主源八郎。「新シ橋通往還中程」の文言で千川上水の神田側末端の樋が柳原新シ橋に近い往来中程にあったことを示す文言の前半**。隣町＝南が神田佐久間町四丁目裏町・北が御使番中根宇右衛門殿屋敷。「大垣」の原字（大枡・大樋等の崩れ候補）と後段の全文は要原画像照合〕。
- **新田久右衛門町壱丁目・弐丁目蔵地条＝往置樋2ヶ所〔文言候補・本冊の主要価値〕**: 「**千川上水之儀安永九子年十月二十七日牧野大隅守殿御番所御懸りニ而懸渡之儀被仰渡候儀ニ而久右衛門町壱丁目蔵地入西之方新し橋際往置樋壱ケ所 同町并同町弐丁目蔵地境目往長ニ樋躰壱ケ所埋伏せ有之候 右天明七未年四月十二日御差止メニ相成候旨再達有之 其節埋立ニ相成申候**」（p73）＝〔**①掛渡仰付＝安永九子10月27日・牧野大隅守（[GAZ-124](GAZ-124.md) の「板野」とのOCR対立）、②樋の配置＝久右衛門町壱丁目蔵地入西之方の「新し橋際」に往置樋1ヶ所＋同町并び弐丁目蔵地の境目・往還長手に「樋躰」1ヶ所（埋伏せ）＝**千川上水末端部（柳原新シ橋際）の樋2ヶ所の位置・形式の文言候補**（「往置樋」「樋躰」の原字・語義は照合課題）、③差止＝「**天明七未年四月十二日**」＋「**再達**」の文言＝⇒外神田・浅草側で12日系（[GAZ-127](GAZ-127.md)・[GAZ-043](GAZ-043.md) 活字版外の久右衛門町等）と、湯島・本郷側で「四月中」、神田仲町側で13日系（[GAZ-041](GAZ-041.md)・[GAZ-124](GAZ-124.md)）が併走する差止日粒度の対立群への追加材料、④条帰属＝p56の見出し「地諸御調書上帳新田久右衛門町壱丁目蔵地同所同町弐丁目蔵地名主平右衛門」＋署名p93（OCR「神田八名川町名主平右衛門」＝八名川町の原字（矢名川？）要照合・同一の名主平右衛門）。⑤同条に元禄二己年九月朔日の名主由緒文言（町草創人久左衛門・津町名主役の記述）**〕。
- **柳原新シ橋御尋の書上〔文言候補・橋管理体制史料〕**: p11「柳原新シ橋御尋之儀に付御調書上 神田紺屋町名主勘次郎 本銀町（?）神田佐柄木町惣蔵 木町（?）弥太郎」＋p13「**神田佐久間町四丁目ゟ柳原土手通江相渡候字柳原新シ橋之儀…此段前書三ケ町町人共所持之地面享保四亥年中本三ケ所町屋鋪元地御用地ニ相召上候訳新シ橋発端御掛渡年月新シ橋之唱候訳口三ケ條之義御尋に御座候得共書留幷申渡も無之一向二相分り不申候**」＋p15「**為冥加柳原新シ橋其節新規ニ右町人共入用を以掛直し以後新規修復共永々引請可仕旨同年閏九月中町御奉行所え奉願上同十五戌年中諏訪美濃守様御番所御内寄合え被召出大岡越前守様願之通被仰渡…橋見守之義は…与兵衛役三郎と申者相勤罷在候**」＝〔**①柳原新シ橋＝神田佐久間町四丁目と柳原土手通を結ぶ橋で、その発端・掛渡年月・唱の訳口の3点は文政時点の町方でも「書留も申渡も無之」と記憶が失われていた、②享保4亥年中に三ヶ所町（佐柄木町蔵地・本〔銀〕町会所屋鋪蔵地・佛屋町弐丁目横町蔵地候補）が屋敷元地を御用地に召し上げられた縁故があり、代地願の際に冥加として新シ橋を新規に掛け直し以後の修復を永代引受け（享保15戌年中諏訪美濃守番所・大岡越前守の内済候補）、③橋見守＝与兵衛・役三郎**＝柳原新シ橋の起立・管理体制の書上文言群**〔千川上水の樋文言（p23・p73）と同じ冊に含まれる、千川上水の末端部の地理アンカー（柳原新シ橋）の側面史料。**repo既出の柳原新シ橋文言（[GOV-420](../gov/GOV-420.md) 等の柳原側・[BOOK-129](../books/BOOK-129.md) 神田川新シ橋）への書上由来の新資料として対校**〕。
- **同条の番屋・物揚場文言〔付記レコード〕**: p70「久右衛門町壱丁目之内新之橋際ニ間口弐間奥行壱丈有之候髪結床番屋…享保四癸年十二月中久右衛門町蔵地に被仰付候節明地捨物等為無之為見守相願候…同断北之方西角に九尺四方之髪結床番屋…延宝四癸年中…新し橋際河岸に長弐間余巾九尺程之町内物揚場有之古来ゟ有来之由…」＝新し橋際の河岸の物揚場・番屋の記録〔千川樋文言の位置環境（新し橋際河岸＝神田川側）を示す付記〕。
