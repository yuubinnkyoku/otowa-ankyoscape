# [GAZ-191] 東京市史稿 市街篇 第十八 — 白山前町千川屋鋪の正徳4年2月27日・3月22日の両証文〔第322回〕

- **書誌〔確認〕**: 東京市役所編『東京市史稿』**市街篇 第十八**（昭和9年〔1934〕刊・次世代デジタルライブラリー [book/3450793](https://lab.ndl.go.jp/dl/book/3450793)）。正徳年間の市街異動・屋鋪受授（内藤宿・四谷角筈村・四谷伝馬町・神田仲町系の上ケ地の預かり等）とともに「屋鋪渡預繪圖證文・屋敷書拔」の採録があり、白山前町千川屋鋪の両証文が載る（頁500・544と読める・OCRによる頁番号は要照合）。引用文言はOCR由来で要原文照合。
- **正徳4年2月27日の名主預り証文〔文言候補・repo初出の文言本文〕**: 「**小石川指ケ谷町こゐ、小石川御殿地上水請負役屋鋪上ケ地、拙者に御預ヶ被成、四方間數坪數、右御繪圖之面、相違無御座御預り申い。爲後日仍如件。白山前町千川屋鋪 坪數貳百拾三坪。小石川指谷町名主六之丞（印） 正德四甲午年二月廿七日 嶋田佐渡守内小倉半内 右立合相改預之**」＋図面帳の四至・間数明細「**外ニ下水坪十七坪五合 東御六尺町(屋)。西道。南伏屋修理。北道 東十四間貳尺五寸。西十五間五尺(と読める)。南貳十間貳尺五寸。北壹間壹尺五寸**」＝**享保7年の上水差止後の小石川御殿地の上水請負役屋敷上ケ地（白山前町千川屋鋪213坪）が、正徳4甲午年（1714）2月27日に白山前町名主六之丞に御預地とされた際の名主側の預かり請取文言**。〔立会人が「**嶋田佐渡守内小倉半内**」であることが本証文で特定される（repo初出）。[GAZ-049](GAZ-049.md)⑫（御府内備考巻44・文政町方書上）は同一事実を書上体で「正德四甲午年二月廿七日…名主六之丞に御預地ニ罷成居」と記すが、証文言本文・立合人名は採録していなかった。〕
- **正徳4年3月22日の上水請負人渡し証文〔文言候補・repo初出の文言本文・日次初出〕**: 「**小石川根津惣門前橋三ケ所請負役屋鋪坪數貳百拾三坪。外ニ下水坪十七坪五合…小石川指ケ谷町こゐ、小石川御殿地上水請負役屋鋪上ケ地、今度根津惣門前橋三ケ所請負爲役屋鋪、御渡し被成、四方間數坪數、右御繪圖之面、御定杭之通、相違無御座請取申い。爲後日仍如件。上水請負人 正德四甲午年三月廿二日 千川德兵衛（印）…千川太兵衞（印）… 嶋田佐渡守内小倉半内 右立合相改渡之…小林久左衞門組鈴木（半左衞門と読める）…高林又兵衞組村井…**」＝**上記の213坪＋外に下水坪17坪5合の屋鋪が、根津惣門前橋3ヶ所の新規修復の負担（爲役）の見返りとして正徳4年3月22日に再び上水請負人千川德兵衞・千川太兵衞に渡された際の請取文言**。〔①**3月22日という日次はrepo初出**（[GAZ-049](GAZ-049.md)⑫の書上体は「正月から三月」を欠く年代表記、[GAZ-053](GAZ-053.md)は宝永元年の別証文）、②**「外ニ下水坪十七坪五合」＝上水請負役屋鋪に付帯する下水（排水）用地の坪数の初出**、③千川德兵衞・太兵衞の2人が連署する受領体、④高林又兵衞組（[GAZ-016](GAZ-016.md)の明和5年千川幸治願書の道奉行高林又兵衞と同組かは要照合）・小林久左衞門組の立合与力の編成。〕
- **「南伏屋修理」の判読対立〔観察〕**: 本冊の白山前町千川屋鋪の四至は「**南伏屋修理**」と読める。宝永元年8月の証文（[GAZ-053](GAZ-053.md)）の四至は「**南、伏屋賴母**」で、同じ南隣の人物（伏屋氏）について官名表記の対立「修理／頼母」が見える。同一人物の別官名、別人、OCRのいずれかは原画像照合まで断定しないが、**同一上ケ屋敷（余語古菴→千川屋鋪）四至の追跡資料として2証文の間で比較対照できる点**を記録する。
- **位置づけ〔観察〕**: 白山前町千川屋鋪の通時チェーン（余語古菴拝領→元禄9年太兵衞拝領〔[GAZ-049](GAZ-049.md)⑫2・[GAZ-053](GAZ-053.md)〕→享保差止で上り地→**正徳4年2月27日名主六之丞預り**→太兵衞の根津惣門前橋3ヶ所修復願い→**正徳4年3月22日再拝領**→享保以降の変遷→文政9年金七〔[GAZ-049](GAZ-049.md)〕→天保14年上納地化〔[GOV-210](../gov/GOV-210.md)〜[GOV-212](../gov/GOV-212.md)〕）のうち、**正徳4年の「預かり→再拝領」の実務過程の2つの証文言が初めて原文の体裁で採録された**。編年上の特記事項として、正徳4年（1714）は**甲午**であり、[GAZ-049](GAZ-049.md)⑫が注記した「正德四卯年」（干支対立）に対し本冊の両証文の日付部はいずれも「**正德四甲午年**」と読める＝四年干支（甲午）の確定に向けて証文側の2票が揃った（OCR由来のため原画像照合で確定させる）。
