# [GAZ-194] 東京市史稿 市街編39〜55 掃引 — 白山前町千川屋敷の頽勢時代〜明治初年実務文言群〔第324回〕

- **書誌〔確認〕**: 『東京市史稿』市街編39〜55（東京都編・1952〜1964年刊）。NDL次世代デジタルライブラリー [9640901](https://lab.ndl.go.jp/dl/book/9640901)〜9640918（14巻: 39=9640901/40=9640902/41=9640903/42=9640904/43=9640905/44=9640906/45=9640907/46=9640908/47=9640909/47附図=9640910/48=9640911/49=9640912/50=9640913/55=9640918）。市街編44（9640906）は[GOV-396](../gov/GOV-396.md)既収録。**市街編51〜54（9640914〜9640917）はlab本文未公開（403）で掃引不可**。39〜50・55の13巻の全文ZIPを取得し頁別テキスト展開で掃引。**全文言OCR由来・列崩壊多く原画像照合必須。**
- **掃引の結果〔確認・陰性を含む〕**: 水窪川・弦巻川・谷端川・音羽川の直接の文言は**14巻中0件**（9640908「戶川道」は青山千駄ヶ谷の小路名で誤検出）。**千川屋鋪（敷）の町方実務文言が市街編40・41・42・45・48・50に計10数件**。第二キーワード（藍染・鼠ヶ谷・水久保・濯川・用水・掛樋・上水樋・大洗堰・白山御殿）の走査では、白山御殿・御殿跡のヒットは既収録群（計199件・[GAZ-013](GAZ-013.md)等）と内容が重なる巻別文言で要点の新規性なし、掛樋・上水樋は「四谷御門外上水掛樋見守番屋」（玉川上水四谷樋番屋・市街編40・42）・「濱御庭中島御茶屋上水樋枡」（市街編42）・「關口大洗堰上え御移替」（神田川の鯉取扱い・市街編47）など**四河川と無関係の系統で陰性確定**。
- **市街編41（9640903）の天保14年8月23日の上地文言〔確認・repo初出の文言〕**: 町屋敷書抜の列「**小石川白山前町支配ニ屬ス。天保十四卯年卯八月廿三日。千川宇兵衞屋敷上地 小石川白山前 貳百三拾貳坪餘。右同斷教行。〇町-屋敷書抜**」＝**天保14年（1843）8月23日の千川宇兵衞屋敷の上地（=御取上）232坪余の町屋敷書抜**。①[GOV-175](../gov/GOV-175.md)の天保14年8月22・23日の拝領地引渡文書群〔147]（引渡受書・千川宇兵衛印・懸り名主3名）と**同日付の市街編側採録**＝同一事象の独立系統による裏付け、②屋敷の坪数が同時点側テキストで**232坪余**と出る＝「引渡側の屋敷232坪余」（第317回ノートのGOV-175対校メモ）と一致、③直前の同日付文言「四郞兵衛町屋敷上地小石川下富坂町六拾八坪餘」と料簡を同じくする書抜列（富坂下の町の同日付上地）。**「右同斷教行」は奉行銘か（要原文照合）。**
- **市街編42（9640904）の頽勢時代の上納金文言〔確認・repo初出の数値〕**: 上納金のリスト「**小石川白山前町 金六兩銀拾貳匁壹分七厘。よねた衣笠房次郎 同金貮分銀拾三匁四分五厘。同千川屋鋪 金三分銀拾匁九分九厘四毛**」＝①**千川屋鋪の上納額（金3分+銀10匁9分9厘4毛）**が独立計上される、②直前の「**衣笠房次郎**」の並記＝[GAZ-038](GAZ-038.md)町鑑の白山前町千川屋敷条の「衣笠房次郎・坪三之助の並記」（13番組か）と一致する町内秩序の反映候補（対校点）、③[GOV-210](../gov/GOV-210.md)（嘉永3年願書の地代11両）との対応は額が合わず**別個の賦課か別計算かは本件では確定しない**（いずれも原照合まで断定しない）。
- **市街編40（9640902）の町並測量表の独立計上〔確認・構造の新規確認〕**: 頽勢時代の小石川町々の表裏間數の表に「**小石川白山前町 小石川白山前町千川屋鋪 同拜領屋鋪分 小石川白山大道通**」の4単位が連続列挙され、対応と読める間数群（百四拾七間半裏行六間より廿間迄・九拾壹間半裏行十間より廿二間迄・廿九間三尺裏行六間・百三十一間裏行十八間・六拾八間裏行拾八間・百貳拾間裏行拾八間…）が続く＝**白山前町の町並測量に千川屋鋪と「拜領屋鋪分」が独立の計上単位として現れる**。**OCR列崩壊のためどの数値が千川屋鋪に対応するかは対応づけない。**「拜領屋鋪分」の表記は千川屋鋪の南接の拝領地帯か（未確定）。
- **市街編45（9640907）の請負地拂下測量請取の文言〔確認・核心・repo初出の実測値〕**: 「頽勢時代（七）」の「**請負地拂下事蹟**」章の測量請取の列「**小石川白山前町千川屋敷、表田舎間拾五間五尺、同斷南之方十九間壹尺。此坪貳百三拾貳坪五合四勺六才**」＋「**千川屋敷 表田舎間拾五間五尺、裏巾同拾四間貳尺、裏行北之方十壹間壹尺餘、但、右同斷**」＝①**千川屋敷の拂下時測量232坪5合4勺6才・表（間口）田舎間15間5尺・南之方19間1尺・裏巾14間2尺・裏行北之方11間1尺余**（不整形地の測量請取）、②前後の文言に「奉畏候。爲後日仍如件」の請取文言が続く＝**請負地拂下の実務文書（測量受領書類）の採録**、③目次でも「**千川屋敷**」が芝土手跡町・靈岸橋際埋立地・淺草山谷町などと並ぶ**町級の独立項目**として市街地異動事蹟の列に挙げられる（千川屋敷が町扱いの独立地籍単位で終幕を迎えた構造）、④巻の構成は「頽勢時代(七) 講武所附町屋鋪・請負地拂下・市街地異動」＝**測量の帰属する事件は明治初頭の町屋敷拂下と読めるが、当該測量の年次・拂下先（誰が請負ったか）は本文から取り出せていない**。
- **市街編48（9640911）の番組構成表〔確認・構造の新規確認〕**: 小石川区の番組構成の列挙に「**小石川白山前町 同千川屋鋪 同白山大道通 小石川白山社地門前 小石川妙〓寺門前**」（前後に 戶崎町・安閑寺門前・善仁寺門前・喜運寺門前・法傳寺門前・傳通院前各町・智香寺門前等）＝**千川屋鋪が白山前町と並ぶ番組の構成単位**。OCR列崩壊のため番組番号の対応は保留（周辺に「貳拾八番組」「三丁目拾四番組」等の表記）＝[GAZ-037](GAZ-037.md)大江戸志の9番組町火消・[GAZ-038](GAZ-038.md)町鑑の13番組かとの続柄は本件では確定しない。
