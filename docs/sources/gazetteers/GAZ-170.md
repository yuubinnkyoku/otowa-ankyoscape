# [GAZ-170] 町方書上[111] 本所町方書上 十 — 竪川規制確定文言と菊川御橋・北樋番屋

- **書誌〔確認〕**: 『[111] 本所町方書上 十』（写・NDL次世代デジタルライブラリー [book/2571592](https://lab.ndl.go.jp/dl/book/2571592)。NDL API volume欄直接確認）。神田徳右衛門町条（koma 39-41）・菊川町壱丁目〜四丁目条（koma 41-57）。引用文言はすべてOCR由来で要原文照合。※第223回の本冊boilerplate陰性判定（四河川keyword）は上記文言群を捉えていなかった＝本回訂正。
- **竪川川巾規制の確定文言＝享保15年大岡越前守内寄合〔文言候補・本冊最重要〕（koma 11）**: 「**一登川巾弐拾間 右は万治二亥年堀割 本所御奉行徳山吾衛様山崎四郎左衛門様御懸りニ而出来仕候一河岸地五百弐坪…右河岸地川巾之義は先年川巾廿一間川岸行七間半之所不同之場所有之候ニ付 享保十五戌年正月廿七日 大風越前守様御番所御内寄合ニ而竪川両側町々名主月行事被召出 以来川巾弐拾間川岸行八間道巾五間ニ仕 川岸は関板畑等仕堀上ヶ可申**」（koma 11・OCR）＝**①竪川（OCR「登川」）の巾20間は万治2年の堀割（徳山吾衛〔=五兵衛・OCR変種〕・山崎四郎左衛門）、②かつては川巾21間・川岸行7間半だったが不統一のため、享保15年（1730）正月27日、大岡越前守〔OCR「大風越前守」〕の御番所内寄合で竪川両側の町々の名主・月行事を召し出し、以後川巾20間・川岸行8間・道巾5間に定めた**という行政処分文言候補。〔**竪川の width管理の一次規制記録（repo初出候補）**。〔GAZ-165〕の竪川堀立総説と連続し、万治2（堀立）→享保4（奉行廃止）→享保15（川巾規制）→文政（書上）の竪川管理系譜の中核datapoint。大岡越前守の本所行政（「大岡支配」）の実務一例としても記録価値がある。〕
- **神田徳右衛門町の起立と竪川・横川文言（koma 39-41）**: ①「**当町之町名之儀は 神田柳原土手之内ゝ（?）居住之儀被召置候処 寛文元丑年 神田柳原火除地江相成候に付 三ツ目へ代地被下置…（天和）三年中 尻上有之 貞享元子年立退候…元禄六年御再下書…只今之神田龍閑（?）町代地**」（koma 41周辺・OCR要再照合・文言候補）＝**神田徳右衛門町が元は神田柳原の火除地化（寛文2年〔=寛文元丑年はOCR候補〕）で追われた町の人々の本所三ッ目代地**という起立譚候補（文言の細部は判読不能部分が多く要照合）、②「**一登川巾弐拾間…一横川巾弐拾間 右竪川横川共万治二年二堀割 本所御奉行徳山…**」（koma 41・OCR）＝**竪川・横川とも巾20間・万治2年堀割の並記文言**（「万治二年二」=「万治二亥年二」のOCR候補）。
- **菊川御橋の初懸と名義文言＋北樋番屋（koma 52-54）**: ①「**一菊川御橋 長拾間巾三間八寸五分 右は横川ニ掛渡有之 元禄十五午年 本所御奉行鈴木兵九郎様松平伝兵夫様御懸りニ而初而相掛り 間之猶子（?・判読不能）唱候処 享保之頃ゟ菊川橋と相唱申候 文政四巳年町方御勘定方御掛りニ而御修復有之**」（koma 53-54・OCR）＝**横川に架かる菊川御橋（長10間・巾3間8寸5分）が元禄15年（1702）に初めて架けられたことと、享保の頃から「菊川橋」の名に変わったこと**の文言候補。〔[GAZ-165](GAZ-165.md)起立書の「菊川橋猿江橋 元禄十五午年…御懸り」と全系共通の元禄15年datapointの独立witness＋**改称（かつての名→菊川橋）の示唆**（中抜けの名はOCR判読不能＝照合課題）。〕②「**一北樋番屋 間口四間裏行弐間半 右は菊川御橋際北樋 町内二見廻り罷在候處行届不申 以桶番人差置申度段 宝暦十辰年四月中 依田和泉守様御番（所）え奉願相建申候**」（koma 52・OCR）＝**菊川御橋際の北樋（下水樋）の番屋が宝暦10年（1760）4月の願で番人（桶番人）差的に建てられた**実務文言候補。③「**一入樋下水落口…菊川御橋脇ニ而…横川之方江流れ候下水吐口二有之 横川満水之節は〆切申候**」（koma 54-55・OCR）＝**横川満水時に〆切る下水吐口の入樋文言**（[GAZ-169](GAZ-169.md)の沢樋開閉文言と同型の横川水位連動構造の菊川側対校）。④「**一菊川巾壱間 右は西之方武家地境に有之**」（koma 53・57・OCR）＝**「菊川」という小水路（巾1間）の用例**（菊川町の西・武家地境。御橋の「菊川」との命名関係を示唆する材料候補だが断定しない）。
- **南辻御橋際の橋番屋（koma 41）**: 「**橋番屋弐箇所…右は南辻御橋際に有之 古来ゟ建来候趣申伝候**」（koma 41・OCR）＝南辻橋（[GAZ-165]起立書の横川通南辻橋と接続）の番屋文言の補助記録。

## 制限・未解決

- ①すべてOCR由来で要原文照合（「登川」=竪川・「大風越前守」=大岡越前守・「徳山吾衛」=徳山五兵衛・「万治二年二」=万治二亥年に・「寛文元丑年」の寛文元年=辛子〔丑年は寛文2〕の干支矛盾等はOCR由来候補として併記）。②神田徳右衛門町条の起立譚文言（koma 39-41周辺）は判読不能箇所が多く、引用構成と年次配列は原画像照合まで再構成しない（文言候補としてのみ記録）。③「間之猶子」の判読（旧橋名か）は未決。④菊川（巾1間の水路）と菊川御橋の名義関係は断定しない。
