# [GAZ-049] 『御府内備考貳』（大日本地誌大系版・巻25-46）— 千川上水の日光御成道・巣鴨区間の町方書上の活字版・小日向の坂と橋の由来文言

- **書誌〔確認・出版年は一部要照合〕**: 『**大日本地誌大系**』第2巻として『**御府内備考貳**』（巻之二十五〜巻之四十六）を収載した冊（**蘆田伊人**編・雄山閣・**1929年（昭和4年）12月15日発行**〔奥付OCR〕）。NDL次世代デジタルライブラリー [book/1214857](https://lab.ndl.go.jp/dl/book/1214857)。『御府内備考』は文化〜文政期に江戸町奉行が町々から徴集した町方書上を編んだもの（丁亥＝文政10年〔1827〕書上・丙戌＝文政9年〔1826〕書上の文言を多く含む）で、本冊はその**巻25（根津之一）〜巻46（小日向之二）**の活字版。巻39（巣鴨之一）・巻40（巣鴨之二）・巻45（小日向之一）・巻46（小日向之二）が今回の対象。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**なお巻50（西青柳町・音羽町等）は本冊の巻46までに未収録（[GAZ-013](GAZ-013.md)の雄山閣刊本・写本系が先行資料として有効）。
- **①日光御成道町（巻40・丙戌書上）の古上水跡条＝千川上水の日光御成道区間のmicro-history〔確認・repo初出の文言を多く含む〕**: 「**古上水跡(水上川千＝千川水上のOCR倒置か) 右は町內往還を通 千川上水と唱、武藏野原保田新田と申所水元にて、淺草田原町三丁目小兵衞店忠兵衞、同町壹丁目嘉右衞門店孫兵衞、高砂町三郞兵衞店幸左衞門、右三人の者共願人にて明和六丑年二月御普請方御役所え御訴訟申上、其後安永八亥年十一月廿八日、初て巢鴨庚申塚より駒込邊其外町々御見分有之候後樋掛渡出來、天明二寅年八月中より水錢小間に付貳拾八文宛差出、牧野大隅守樣御番所え上納致、其後天明六午年五月中より半減被仰付、同年八月中迄相納、九月中より御止**」＝**①「千川上水と唱」える古上水跡が日光御成道町内往還を通る、②**水元は「武藏野原保田新田」**＝[GOV-224](../gov/GOV-224.md)/[GOV-225](../gov/GOV-225.md)（駒込町方書上）の保田新田文言と一致、③**再興願人3人の店先つき氏名＝淺草田原町三丁目小兵衞店忠兵衞・同町壹丁目嘉右衞門店孫兵衞・高砂町三郞兵衞店幸左衞門**＝[GOV-218](../gov/GOV-218.md)（駒込肴町・富士前町条）の「忠兵衛・孫兵衛・**幸島**」との表記対立〔**幸左衞門／幸島**〕・[GOV-208](../gov/GOV-208.md)系（元禄9年太兵衞徳兵衞）とは別人の明和6年再興の願人、④明和6年2月御普請方御役所え御訴訟→**安永8年11月28日巣鴨庚申塚より駒込邊・其外町々の御見分→樋掛渡出来**→**天明2年8月中より水銭小間に付28文宛を牧野大隅守樣御番所え上納**→**天明6年5月中より半減・同年8月中迄相納・9月中より御止**＝差止の月次の粒度が「九月中より御止」とさらに細かく記録される、⑤「**日光御成道町內え壹町四拾九間壹尺相掛申候、但道幅四間**」＝千川上水の町内掛かり延長1町49間1尺、⑥「**當町內往還拾五間程、御成道に相成申候**」＝当町内往還15間ほどが御成道になった経緯**〔明和〜天明の再興〜差止の全過程の年月日・願人・水銭・延長が1つの町の書上で完結する記録として[GOV-215](../gov/GOV-215.md)〜[GOV-218](../gov/GOV-218.md)の町方書上群の対校資料〕。
- **②日光三ッ家町（巻40・丙戌書上）の千川上水跡条＝追分町への参照文言と幅2間半〔確認・repo初出〕**: 「**千川上水跡 右委細は追分町にて申上候、幅貳間半**」＝**①三ッ家町の書上が千川上水の詳細を**追分町（駒込追分町＝中流域の書上〔[GOV-224](../gov/GOV-224.md)/[GOV-225](../gov/GOV-225.md)〕）に参照させる＝町方書上の相互参照構造の記録、②**幅2間半**という規模記録**＝[GAZ-048](GAZ-048.md)⑩の「堀幅四五尺或は廣き所も九尺に過ず」（千川上水跡条）との対照では広い（2間半＝約4.5m）＝通水当時の樋掛渡区間と廃止後の堀跡とでは幅員が異なる可能性があり断定しない）。
- **③巣鴨仲町（巻40・丙戌書上）の古上水蹟条＝巣鴨区間の千川上水の位置の町方側文言〔確認・repo初出・第112回の主要成果の一つ〕**: 「**古上水蹟 右者千川上水と唱、巢鴨町往還通りより當町往還通東の方駒込富士前町通え掛、右安永の頃迄有之候由**」＝**①巣鴨仲町の古上水蹟は「千川上水と唱」えられ、巣鴨町往還（中山道）通りから当町往還通の東の方・駒込富士前町通へ掛かっていた、②「安永の頃迄有之候由」＝安永8年（1779）の掛渡開始で通水した際の流路（あるいは安永の頃まで存在した流路）として伝承**＝**庚申塚〜駒込富士前町間の千川上水の流路が「巣鴨町往還（中山道）を横切り、巣鴨仲町の東側を経て駒込富士前町へ向かう」という位置関係の町方側の一次記録**（[GOV-224](../gov/GOV-224.md)/[GOV-225](../gov/GOV-225.md)の巣鴨庚申塚からの中流流路の補完・巣鴨区間の具体的な通過地の初出）。
- **④巣鴨之一（巻39）の巣鴨村地理と御立場・御薬園＝[GAZ-048](GAZ-048.md)⑬との対校〔確認〕**: 「**板橋への往來にして、南は駒込鷄聲ケ窪續より、北は庚申塚に及び、其餘中町原町等は少しく往來の西にさし入、辻町と稱する僅の町(あり)、小石川大塚上町に隣れり**」＝巣鴨村の中山道（板橋への往来）が鶏声ヶ窪続から庚申塚まで、中町・原町が往来の西に入り込む地理描写（巣鴨の町割の空間構造）。**「御立場寛延三年伊奈半左衞門に仰せて新に築立らる、御藥園元藤堂和泉守の抱地なりしを寶曆四年御林と成り、寬政年中御藥園に改めらる」＝風土記稿（[GAZ-048](GAZ-048.md)⑬④⑤）と年代・人物がほぼ一致する対校**（風土記稿の「承りて」vs 御府内備考の「に仰せて」＝依頼主（幕府）と受注者（伊奈半左衞門）の関係の表現差。御薬園の12,610坪余・渋江長伯の文言は御府内備考側に見えない＝風土記稿固有の詳細）。
- **⑤小日向之一（巻45）の坂・橋群の改撰江戸志・江戸志引用文言の活字版〔確認・[BOOK-131](../books/BOOK-131.md)・[GAZ-039](GAZ-039.md)/[GAZ-040](../gazetteers/GAZ-040.md)の江戸志系テキストの対校〕**: 「**古川橋 江戶川に渡す、俗に麁朶はしといふ**」「**中ノ橋 中の橋は築戶下より江戶川はたへゆく通りにかゝる橋なり、立慶橋と石切橋の中なる橋なればかく名付たるべし**」「**石切橋 赤城下へ行とほりなり、馬場片町より水道町へわたす…むかしこの處に石切ありしよりの名なり、【江戶志】石切橋は大橋ともいへり、水道町より牛込の水道町へ往來の橋なり、長さ十間ほどなり、江戶川へかゝる橋にてはもつとも大なるはしなり、【改撰江戶志】**」「**掃部橋 むかしこの所に吉岡掃部といへる紺屋のありしゆへの名なりと、【江戶志】掃部橋は水道町より古川町へわたす(橋)なり、【改撰江戶志】**」「**萬年橋 萬年橋は水道端の方より中の橋へいつる處、齋藤氏の向ひをわつかに行て小橋あり、石をもて作ればかゝる名ありといふ**」「**立慶橋 立慶橋は中の橋の次なり、川のほとりにむかし大橋立慶の邸宅ありしゆへにかく橋の名となれりといふ**」＝**①石切橋＝「大橋ともいへり…長さ十間ほどなり、江戶川へかゝる橋にてはもつとも大なるはしなり」＝[GAZ-039](../gazetteers/GAZ-039.md)/[GAZ-040](../gazetteers/GAZ-040.md)の「むかし此所に石切あるよりの名」（大橋の俗名由来・石切の居住）と対校、②掃部橋の「吉岡掃部紺屋」由来の江戸志系文言のさらに先行（御府内備考が「【江戶志】【改撰江戶志】」と出典を明示する形）＝紺屋由来説の第4テキスト体制、③中ノ橋＝「立慶橋と石切橋の中なる橋」＝江戸川（神田川）筋の橋の並び（古川橋・中ノ橋・石切橋・掃部橋・萬年橋・立慶橋）の順序の基礎資料、④萬年橋＝「水道端の方より中の橋へいつる處…石をもて作ればかゝる名あり」＝石橋の萬年橋（[GAZ-034](GAZ-034.md)巻45日録の「万年橋」の比定資料・水道端の語の江戸川側〔小日向側〕用例としても注目）**。
- **⑥小日向之二（巻46・丁亥書上）の八幡坂→大日坂の改名文言・鼠ケ谷下水の小日向側呼称・白堀〔確認・repo初出・[GAZ-035](GAZ-035.md)音羽8丁目条との対校〕**: 「**枚登凡壹丁程、幅凡三間程、鼠ケ谷下水と里俗相唱(…)…右は門前前通より北の方有之、往古八幡坂と唱申候、尤其節右坂上左の通只今久世長門守樣小日向町畑地御抱屋敷場所の內、田中八幡宮有之候に付里俗八幡坂と唱候處、年代不知右御抱屋敷相成候後、社地は音羽町八丁目裏通り相移申候に付、坂下東の方妙足院境內に大日堂有之候間、其後里俗大日坂と相唱候、但坂道造の儀は右の方久世長門守樣、北の方は龍興寺、妙足院にて道造いたし候**」＝**①「**鼠ケ谷下水と里俗相唱**」＝坂（八幡坂＝現・大日坂）の幅凡三間の文言とともに**鼠ケ谷下水の呼称が小日向側（小日向坂下町）でも使われた記録**＝[GAZ-048](GAZ-048.md)①の「九町目迄を鼠ヶ谷下水と號す」（音羽2〜9丁目）と対照すると鼠ヶ谷下水呼称区間が小日向側まで及ぶ可能性の資料（区間の延長とまでは断定しない）、②**八幡坂→大日坂の改名過程**＝往古八幡坂→坂上の田中八幡宮（久世長門守抱屋敷化の後・年代不知）が**音羽町八丁目裏通りへ移転**→坂下の妙足院境内の大日堂により里俗「大日坂」へ＝**[GAZ-035](GAZ-035.md)音羽8丁目条の「古キ唱ニハ御座ナク田中八幡宮当所江引移リ候已後之唱」（音羽側の移転先記録）と対照して八幡坂側（旧地側）からの移転記録が確認できる＝田中八幡宮移転の両側（旧地・新地）の記録が揃った**、③「**神田御上水幅凡貳間半程、右は南の方相當、龍光院境內附を相流申候、右は白堀と唱、西の方は同所智願寺門前より流來、東の方同所水道町の方え流行申候**」＝**神田御上水（小日向区間）＝幅凡2間半・白堀と唱・龍光院境内附を流れ・西は智願寺門前から流れ来り・東は水道町の方へ流行＝小日向区間の神田上水（江戸川）の流路・通称（白堀）の町方側記録**〔「龍光院」はOCR・要照合〕、④「**板橋長凡四間、巾凡九尺、右は門前より東南の方前書御上水え相掛、北より南え渡候橋に有之候、御普請方御懸に御座候**」＝龍興寺門前の神田御上水に架かる板橋（長4間・幅9尺・御普請方御懸＝幕府管理）**。

## 制限・未解決

- ①すべてOCR由来で、「水上川千」の倒置・「枚登凡壹丁程」（坂の長さか）・「龍光院境內附」の社寺名・「橋休一名一橋口關」の割注・「一町四拾九間壹尺」の文脈接続などは原文照合を要する。②巣鴨仲町の「安永の頃迄有之候由」は「（安永の）頃まで（新たな流路として）存在した」とも「安永8年掛渡の際の流路が（書上時点までその跡を）残す」趣旨にも読め、原意の確定は原文照合後に判断する。③日光御成道町の願人3人の「幸左衞門」と[GOV-218](../gov/GOV-218.md)の「幸島」の表記対立（同一人物か）は未解決（店先形式〔高砂町三郞兵衞店〕と氏名形式の差を含め原字形照合が必要）。④巻50の西青柳町・音羽町条は本冊未収録（巻25-46まで）のため、[GAZ-013](GAZ-013.md)・[GAZ-035](../gazetteers/GAZ-035.md)の写本・刊本系が先行する（大系版続巻の有無は未確認）。⑤巣鴨区間の千川上水（③巣鴨仲町の流路）と巣鴨庚申塚の「御見分」（①の安永8年11月28日）の地点関係の詳細な復元は未実施。⑥小日向の白堀（神田御上水）と[GAZ-013](GAZ-013.md)巻50の櫻木町「埋樋二ヶ所」・万年樋の位置関係の整理は未実施。
