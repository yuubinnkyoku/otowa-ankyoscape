# [GAZ-049] 『御府内備考貳』（大日本地誌大系版・巻25-46）— 千川上水の日光御成道・巣鴨区間の町方書上の活字版・小日向の坂と橋の由来文言

- **書誌〔確認・出版年は一部要照合〕**: 『**大日本地誌大系**』第2巻として『**御府内備考貳**』（巻之二十五〜巻之四十六）を収載した冊（**蘆田伊人**編・雄山閣・**1929年（昭和4年）12月15日発行**〔奥付OCR〕）。NDL次世代デジタルライブラリー [book/1214857](https://lab.ndl.go.jp/dl/book/1214857)。『御府内備考』は文化〜文政期に江戸町奉行が町々から徴集した町方書上を編んだもの（丁亥＝文政10年〔1827〕書上・丙戌＝文政9年〔1826〕書上の文言を多く含む）で、本冊はその**巻25（根津之一）〜巻46（小日向之二）**の活字版。巻30-31（湯島之三・神田明神下）・巻33-35（本郷之二〜之四）・巻37-38（駒込之二・之三）・巻39-40（巣鴨之一・之二）・巻41（小石川之一）・巻44（小石川之四）・巻45-46（小日向之一・之二）が今回の対象。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**なお巻50（西青柳町・音羽町等）は本冊の巻46までに未収録（[GAZ-013](GAZ-013.md)の雄山閣刊本・写本系が先行資料として有効）。
- **①日光御成道町（巻40・丙戌書上）の古上水跡条＝千川上水の日光御成道区間のmicro-history〔確認・repo初出の文言を多く含む〕**: 「**古上水跡(水上川千＝千川水上のOCR倒置か) 右は町內往還を通 千川上水と唱、武藏野原保田新田と申所水元にて、淺草田原町三丁目小兵衞店忠兵衞、同町壹丁目嘉右衞門店孫兵衞、高砂町三郞兵衞店幸左衞門、右三人の者共願人にて明和六丑年二月御普請方御役所え御訴訟申上、其後安永八亥年十一月廿八日、初て巢鴨庚申塚より駒込邊其外町々御見分有之候後樋掛渡出來、天明二寅年八月中より水錢小間に付貳拾八文宛差出、牧野大隅守樣御番所え上納致、其後天明六午年五月中より半減被仰付、同年八月中迄相納、九月中より御止**」＝**①「千川上水と唱」える古上水跡が日光御成道町内往還を通る、②**水元は「武藏野原保田新田」**＝[GOV-224](../gov/GOV-224.md)/[GOV-225](../gov/GOV-225.md)（駒込町方書上）の保田新田文言と一致、③**再興願人3人の店先つき氏名＝淺草田原町三丁目小兵衞店忠兵衞・同町壹丁目嘉右衞門店孫兵衞・高砂町三郞兵衞店幸左衞門**＝[GOV-218](../gov/GOV-218.md)（駒込肴町・富士前町条）の「忠兵衛・孫兵衛・**幸島**」との表記対立〔**幸左衞門／幸島**〕・[GOV-208](../gov/GOV-208.md)系（元禄9年太兵衞徳兵衞）とは別人の明和6年再興の願人、④明和6年2月御普請方御役所え御訴訟→**安永8年11月28日巣鴨庚申塚より駒込邊・其外町々の御見分→樋掛渡出来**→**天明2年8月中より水銭小間に付28文宛を牧野大隅守樣御番所え上納**→**天明6年5月中より半減・同年8月中迄相納・9月中より御止**＝差止の月次の粒度が「九月中より御止」とさらに細かく記録される、⑤「**日光御成道町內え壹町四拾九間壹尺相掛申候、但道幅四間**」＝千川上水の町内掛かり延長1町49間1尺、⑥「**當町內往還拾五間程、御成道に相成申候**」＝当町内往還15間ほどが御成道になった経緯**〔明和〜天明の再興〜差止の全過程の年月日・願人・水銭・延長が1つの町の書上で完結する記録として[GOV-215](../gov/GOV-215.md)〜[GOV-218](../gov/GOV-218.md)の町方書上群の対校資料〕。
