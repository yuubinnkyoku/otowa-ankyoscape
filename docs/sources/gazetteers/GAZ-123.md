# [GAZ-123] 町方書上[70] 湯嶋町方書上肆止 — 湯島切通・天神門前・宝性院門前の樋条群と妻恋橋の石橋伝承

- **書誌〔確認〕**: 『町方書上[70] 湯嶋町方書上　肆止』（写・NDL次世代デジタルライブラリー [book/2571551](https://lab.ndl.go.jp/dl/book/2571551)・100コマ）。署名は名主「橋五郎」後見八郎右衛門（町名不特定）、「富島切通町」（湯島切通町のOCR崩れ候補・名主勝五郎）、「関島玄村屋敷」（原字要照合・同勝五郎）、「富島大神門前町」（湯島天神門前町候補・同勝五郎）、「富原天神社地門前」、湯嶋天神下宝性院門前（同勝五郎）。**引用文言はすべてOCR由来で要原文照合。ページ番号は `2571551_{NNNNNNN}.txt` コマ番号。**
- **51間条（名主橋五郎条・町名不特定）〔文言候補・GAZ-024該当条の原本側〕**: 「**千川上水之儀之（は）安永九子年中町内往還長五拾壱間往来往中樋通渡有之尤町内往来之内二中柳壱ケ所小柳壱ヶ所有之候所天明七未年四月中御差止二相成候節取潰シ埋立当時頭相見へ不申候但委細之儀并元禄之儀は相分り不申候**」（p16）＝〔**51間・中桝（OCR「中柳」崩れ候補）1ヶ所＋小枡（OCR「小柳」候補）1ヶ所＝[GAZ-024](GAZ-024.md)の「51間・中枡1・小枡1」条の原本側文言。条帰属は署名p19の「名主橋五郎」条のまま町名は特定できず（後続の切通町各条の名主勝五郎とは別名主）。「元禄之儀は相分り不申候」の記憶喪失文言を含む**〕。
- **湯島切通町条＝57間＋切通辺寺跡〔文言候補〕**: 「**右之内幡随院者当時板倉越中守様御屋敷之場所之由に申伝候尤湯島切通片町当時大縄拝領屋敷に相成候以前…宗源寺大宗寺万福寺幡随院右之寺々切通辺二往古有之候由…一千川上水之義は安永九子年中町内往還長五拾七間折曲り拾六間四人五寸往来埋中樋懸渡有之町内折曲り角中程ニ中枡壱ケ所有之候処天明七未年四月中御差止に相成候節取潰し埋立申候但委細之義并元禄之義は相分り不申候**」（p32）＝〔**①57間＋折曲り16間4尺5寸（OCR「四人五寸」＝「四尺五寸」崩れ候補）・町内折曲り角中程の中枡1ヶ所＝写本側の数値新種（[GAZ-024](GAZ-024.md)のリストに57間条なし・刊本側採録有無の照合課題）、②幡随院＝当時の板倉越中守屋敷の場所であった旨、宗源寺・大宗寺・万福寺の切通辺寺跡の列挙**。条帰属＝署名p35の湯島切通町条〕。
- **「関島玄村屋敷」条（原字要照合）＝11間条の池之端仲町折通り角〔文言候補〕**: 「**千川上水之義は安永九子年中町内往還之長拾壱間壱人往来埋中通懸渡有之池之端仲町江之折通り角中程ニ中棒壱ヶ所有之候処天明七未年四月中廿谷上（御差止に相成の崩れ候補）候節取潰埋立申候但委細之義爰元禄年中之義相分り不申候**」（p40）＝〔**11間1尺（OCR「壱人」＝「壱尺」崩れ候補）・「池之端仲町え之折通り角中程」の中枡（OCR「中棒」崩れ候補）1ヶ所。条帰属＝署名p44の「関島玄村屋敷」条（原字照合必須）。同条の隣町列挙＝東＝板倉越中守様御屋敷・榊原遠江守様御屋敷・（馬島＝湯島候補）切通町・須福成寺（原字候補）・北之方＝下谷池之端仲町・下谷茅町壱丁目（p39）＝**下谷池之端方面に接する町の上水文言**。自身番屋を「馬島切通町」え組合で建てた旨の文言も同条**〕。
- **湯島天神門前町条＝樋体系の集約条〔文言候補・本冊の主要価値〕**: 「**千川上水之義安永九子年町内坂下往還江長サ五拾九間往来埋中樋懸ケ渡有之切通し角々中桝壱ケ所并板倉越中守様御屋鋪廻り角に中桝壱ケ所坂上通り往還二長サ百拾四間小樋懸屋有之天神洞（道の崩れ候補）鳥居前二小仏（＝小枡の崩れ候補）壱ヶ所湯島三組町境二小耕（＝小樋の崩れ候補）壱ヶ処右坂上坂下去天明七未年四月中御差止候相成候節取潰し埋立当時形チ相見え不申候但委細之義并元禄年中之義相分り不申候**」（p53）＝〔**①坂下往還への59間・埋中樋・（切通の角々に中桝1ヶ所＋板倉越中守屋敷廻り角に中桝1ヶ所）、②坂上通り往還への114間・小樋懸屋、③天神道（候補）鳥居前の小枡1ヶ所＋湯島三組町境の小樋（OCR「小耕」候補）1ヶ所、④坂上・坂下とも天明7未年4月差止取潰、⑤元禄記憶喪失文言。**59間条・114間条は [GAZ-024](GAZ-024.md) の町別リストに見当たらない分解文言＝本条が湯島天神門前（現・湯島天満宮門前）の給水樋・桝・小樋の立体的配置を最も詳しく採録する写本側の条**候補。条帰属＝署名p60の湯島天神門前町条（同条p52に妻恋坂・男坂・女坂・中坂の坂名と天満宮地主戸隠の「御手洗跡」の出水伝承の記載もあるが、千川上水との関係は本条では述べない）〕。
- **宝性院門前条＝11間3尺条＋妻恋橋の石橋伝承〔文言候補・橋名史料〕**: 「**千川水水之（千川上水之儀はの崩れ候補）儀は安永九子年中町内往還長拾壱間三尺往来埋中樋懸渡シ有之石川主殿頭様表門通り曲り角に中枡壱ケ所有之候所天明七未年中御差止ニ相成候所取潰シ埋立申候但委細之儀并元禄之儀は相分り不申候…右…西之方…西丸御書院番大久保豊後守様御組松平裏右衛門様御屋敷内南之方に古来ゟ西に岸別当実盛之塚申伝候…一妻恋橋と申橋近辺ニ有之候様風聞も有之**」（p80）・「**当町ゟ…大関伊豫守様御屋敷間に有之候石橋を妻恋橋と相唱候儀も難計候得共申伝も更二無御座候外二最寄之橋等無御座候**」（p81）＝〔**①11間3尺・石川主殿頭（主殿頭＝とものものかみ・原字要照合）様表門通り曲り角の中枡1ヶ所。②「妻恋橋」という橋が「近辺ニ有之候様」風聞と、「大関伊豫守様御屋敷間」の**石橋を妻恋橋と相唱候儀（唱えの由来は「申伝も更二無御座候」＝由来自体は不詳）**の文言＝文政期の町方書上レベルでの妻恋橋の位置候補（大関伊予守屋敷脇の石橋）と由緒不明の記録**〔[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)の妻恋橋条に追記掲載。宝性院門前＝署名p83の条帰属。条内に西に岸別当実盛之塚（高4尺・大7尺程の塚）の伝承も併記〕。
