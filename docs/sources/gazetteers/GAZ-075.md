# [GAZ-075] 町方書上（写）・高田雑司ヶ谷町方書上（文政9年）— 雑司ヶ谷町六条の丙戌書上の写〔第150回登録〕

- **書誌〔確認〕**: 『町方書上』（写・刊記なし。冊子頭に「**町方書上全 高田雑司ヶ谷町方書上 同二七ノ第七十三 四月十三日**」の合綴題・目次文言。NDL次世代デジタルライブラリー [book/2571626](https://lab.ndl.go.jp/dl/book/2571626)）。目次文言により**本冊は高田・雑司ヶ谷一帯の町方書上（文政9年〔1826〕5月付けの地誌御調書上）の写**とみられ、収録は**高田四ツ家町（宗参寺領・蓮花寺領〔OCR〕）・高田四ツ家下も町（自証院領〔OCR「同意院領」〕）・高田四ツ家町（済松寺領〔OCR「堺松寺領」〕か）・雑司ヶ谷町・雑司谷鬼子母神門前・雑司谷本浄寺門前・雑司谷本染寺門前**の六町。各条の末尾に「文政九戌年五月」と名主名（高田四ツ家町=太郎兵衛、雑司谷町=平次左衛門〔OCR「名東次左衛門」〕、鬼子母神門前=太郎兵衛、本浄寺門前=平次八郎、本染寺門前=平次左衛門〔OCR崩れ〕）が見える。**写本でOCRの崩れが非常に大きく、引用文言はすべて原画像照合を要する**。
- **雑司谷町条＝御府内備考巻52の元資料レベルの文言確認〔確認・文言候補〕**: 雑司谷町条の四隣——「**一町内隣町之名 東 法師寺領〔法明寺領のOCR崩れ候補〕雑司谷村 弘化翌六御寄合近藤豊兵衛様御下屋敷其外御家人衆住居 南 小石川四ヶ家町津〔ママ〕高田四ツ家町 西 下高田村 乾 雑司谷鬼子勘左衛門前 小日記院領〔自証院領のOCR崩れ候補〕伝通院修会〔伝通院領のOCR崩れ候補〕雑司谷村百姓家 同五艮 右同断**」＝**東=法明寺領雑司谷村（+御寄合近藤豊兵衛御下屋敷・御家人衆住居）、南=小石川四ヶ家町・高田四ツ家町、西=下高田村、乾（北西）=鬼子母神門前・自証院領伝通院領雑司谷村百姓家**。この四隣は[GAZ-020](GAZ-020.md)・[GAZ-013](GAZ-013.md)（御府内備考巻52・豊島郡側雜司ケ谷町条）の四隣記録（東=法明寺領雜司谷村畑地・西=下高田村・南=小石川四ツ家町・北=自證院領・傳通院領入會雜司谷村百姓家）と一致するため、**本冊の雑司谷町条は豊島郡側雑司ヶ谷町の文政9年（丙戌）書上そのもの（御府内備考巻52の採録元）の写と比定される**（条の末尾の名主平次左衛門もGAZ-013の丙戌書上の名主と一致）。
- **寛永18年市谷自証院領文言＝市史稿市街篇五の帰属問題に資する写レベル文言〔確認・文言候補〕**: 同条に「**其後寛永十八己年〔巳年のOCR崩れ候補〕中 大和院様〔大赦院様とも・大猷院様（将軍家光の法名）のOCR崩れ候補〕御裏方 尾州千代姫君様御母堂 目信院様〔自強院様とも・自証院様のOCR崩れ候補〕御霊屋領として 市谷自検院領〔市谷自証院領のOCR崩れ候補〕に相成申候**」＋「**一当町之儀は前書上候通 自検院師〔自証院領のOCR崩れ候補〕雅司谷〔雑司谷〕村内に然り居候町方 御検地之義は寛永十酉年九月十九日御改有之候…其後寛永十八己年中 高二百石之処 市谷日詰院領〔市谷自証院領のOCR崩れ候補〕に相成**」＝**①雑司ヶ谷町が寛永18年（1641）に大猷院（家光）御裏方・尾州千代姫君の御母堂自証院様の御霊屋領（市谷自証院領）となった（高200石）、②当町は自証院領・雑司谷村内の町方で寛永10年（1633）9月19日の御検地があった**という文言。〔**この文言群（寛永18年市谷自証院領化・禁中雜式の町名起立伝承・名主幌→戸張先祖譚）は、[GAZ-072](GAZ-072.md)（東京市史稿市街篇第五）が「市ヶ谷雑司谷町条」として採録した文政町方書上引用文言と同型**であり、かつ**豊島郡側雑司ヶ谷町の文政9年書上の写（本冊）自体に実在する**。→[GAZ-072](GAZ-072.md)の対校課題（市ヶ谷側固有の文言か・豊島郡側文言の流用・誤採録か）について、**文言の帰属は豊島郡側町の書上に実在する方向が強く出た**（市ヶ谷側の同名町の書上の実物が確認できない限り最終断定はしない。対照表の雑司ヶ谷行の第150回追記参照）。〕
- **延享3年町奉行支配化と「雑式谷町」の表記〔確認・文言候補・年次情報〕**: 同条に「**其後延享三寅年中 本社御奉行〔寺社御奉行のOCR崩れ候補〕山名同徳寺様〔OCR崩れ候補〕 町御奉行能勢肥後守様 馬場浜波兵衛〔OCR崩れ候補〕御勤役中 右雑司谷村之内往還附百姓町屋之分 町方御支配被御付候 其砌ゟ雑式谷町と相認め申候**」＝**①延享3年（1746）に雑司谷村のうち往還添の百姓町屋分が町奉行支配となった、②その際の町の表記が「雑式谷町」であった**という文言候補。〔**雑司ヶ谷町の町奉行支配化の年次（延享3年）と「雑式谷」表記の1746年の実務用例**。鬼子母神門前条の延享2年閏12月町奉行化（下掲）と年次が異なる点は、町ごとの支配化の段階差として記録する（孰れの年をもって町の起立と呼ぶかは断定しない）。門前3町の延享2年（GAZ-013第149回追記・御府内備考巻52）と対校できる。〕また惣家数は「**百五拾弐軒（家持三拾六軒・家守九軒・地借五軒・店借六拾六軒・当時明店三拾六軒）**」・自身番屋1ヶ所（延享3年町方支配の節に相建）＝**文政9年時点の雑司ヶ谷町の家数構成の規模定点**。
- **町内の里俗の字＝御嶽・柳下・清土・大門〔確認・文言候補〕**: 同条に「**一町内里俗ニ相唱候字之儀者 御嶽 御機権現社有之候故相唱申候 但川岸の地来等之儀は村方に至り居故先達而御調之節書上申候**」＝**①「御嶽」の字は「御機権現社〔御嶽権現社のOCR崩れ候補〕」があって相唱える、②「川岸」の地は村方に至り居る（町方書上では先達の御調で書上済）**という文言候補。〔**「御嶽」の字の由来を権現社の存在に求める文政9年書上レベルの文言候補**＝[BOOK-144](../books/BOOK-144.md)（文政7年草稿）の里俗6称（御嶽・畢町・大門・柳下・仲町・〓土）や[BOOK-143](../books/BOOK-143.md)（1890「御嶽と唱ふる丘下に小流あり弦卷川と云ふ」）の「御嶽」の語源記録の系列に**公式書上レベルの先例候補**が加わる（OCR崩れが大きく原字照合までは断定しない）。**「川岸」の地が村方に属する旨の文言は、弦巻川の流位置（町方部分ではなく村方=御嶽・川岸側の谷）を示す位置情報候補**。〕同条の字列挙には**大門**（「**大門鎮守鬼子神鳥居先に付大門被相唱申候…往還町屋前にけや木並有之 是は天正之頃当村之住人長島内匠之申者最寄不苦候奉納ニ植付候由**」＝鬼子母神鳥居先の大門と天正之頃の長島内匠のけやき奉納植付〔[GAZ-013](GAZ-013.md)第149回追記の巻52文言と同型・写レベル確認〕）・**柳下**（「**ヤナキ柳下 往古柳下若狭被申上住居仕度相唱申候 此子孫当村へ入町屋敷に而村方住居仕…名主文左衛門被申者**」＝往古の柳下若狹（禁中雜式の者の一人）の住居地に由来する柳下の字）・**清土**（「**清土 御座最早成候〔OCR崩れ〕川除地に相成居候得共村内に至り居間御来等之義は先達而御調之上書上申候**」＝清土が「川除地」に相成居る旨の文言候補。〔**御府内備考巻52の同箇所（[GAZ-013](GAZ-013.md)第149回追記2・対照表の清土行）は「御除地に相成居候得共村內に籠居候間」**であり、**「川除地」〔本写〕/「御除地」〔御府内備考刊本〕の表記対立候補**。原字照合までは孰れとも断定しないが、「川除地」が原字であれば清土（鬼子母神掘出地）が川除地（川沿いの除地）であったという水系関連文言候補になる。〕）が含まれる。
- **川口屋飴の文言＝弦巻川「流尽せぬ」と川口屋の名乗り〔確認・文言候補・写レベル確認〕**: 同条に「**一川口屋臨売始候者 正徳年中頃ゟ手割いたし 老少成神〔鬼子母神のOCR崩れ候補〕境内に而買始候処 殊之外流行 追々川懸り申家足を名示類見せ出来いたし候 右川口屋之名乗候訳は 当所に往巻川〔弦巻川のOCR崩れ候補〕此川之名有之 注巻川之流尽せぬと申説して川口屋之付候由 右詰の子を変説しテ鶴の丸役所〔紋所のOCR崩れ候補〕へ付候由申伝候**」＝**①川口屋（川口飴）は正徳年中頃から鬼子母神境内で飴を売り始めた、②「川口屋」の名乗りは当所に弦巻川という川の名があり「弦巻川の流れが尽きない」（=名が尽きない）と説いたことに由来する、③鶴の丸紋所のいわれの伝承**という文言。〔[GAZ-020](GAZ-020.md)（御府内備考巻52・川口飴商賣の項）の**元資料（丙戌書上）レベルの文言確認**。加えて本写にのみ見える細部として、**実体者の列挙**——「**当時全川口口屋に相見乗候事は右正徳之頃ゟ売始候 川岸忠治子孫伝通院領百姓富士家忠治 外ニ御普請門前家之藤吉 自徒院領〔自証院領のOCR崩れ候補〕百姓兵右衛門 地借与兵衛 右三人之事共者全川口度々相見置候**」＝**飴売りの実体者として川岸忠治（伝通院領百姓・富士家）・御普請門前家の藤吉・自証院領百姓兵右衛門・地借与兵衛の名**、および**「御成其外御用之故ハ忠治ニ限リ右御買上け被仰付候」＝御成の際の御用（飴の御買上）は忠治に限り仰付られた旨**が記録される（文言候補・OCR崩れ大）。川口屋の家主名「**川岸**」忠治の名の用例も、弦巻川の川岸の地（上掲「川岸」の字）と対照できる。〕
