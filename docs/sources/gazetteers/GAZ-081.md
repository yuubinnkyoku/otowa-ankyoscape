# [GAZ-081] 駿河台志（明治11年刊）— 神田袋町の胸突坂と神田川の下水放流の変遷

- **書誌〔確認〕**: 無名氏『駿河台志』（東京府文献叢書甲集第五冊・明治11年〔1878〕刊・NDL次世代デジタルライブラリー [book/2577096](https://lab.ndl.go.jp/dl/book/2577096)）。活字版でOCRの信頼性は比較的高い。駿河台（神田駿河台・小川町・袋町一帯）の坂・屋敷・旧観を考証する地誌。**引用文言はOCR fulltextで検証済み（細部の字体は要原文照合）**。
- **神田袋町の胸突坂と寛政4年江戸図の「申賀坂」〔確認・repo初出の対校情報〕**: 「**十一 胸突坂 袋町中川飛騨守屋敷ノ坂ナリ…寛政四年ノ江戸図ニ此處ヲ申賀坂トシルシタリ**」＝**神田袋町（駿河台）に「胸突坂」という坂があり、寛政4年（1792）の江戸図に同所を「申賀坂」と記す**旨の考証（袋町中川飛騨守屋敷の坂・月夜の眺望の記事を伴う）。〔**駿河台側の胸突坂は[GAZ-076](GAZ-076.md)関口寺社書上の胸突坂（関口側・元禄10年新道・現在の学習院下の胸突坂）とは別地点の同名坂（同名異坂）**＝docs/地名・河川名対照表.mdの「胸突坂（関口側）」行の注意（第153回に設定）を補強する江戸期図名レベルの傍証。寛政4年江戸図の「申賀坂」表記は坂名の異名資料。両坂の混同は以後の資料で起こり得るため、対照表で明示を維持する。〕
- **雁木坂下の樋と神田川への下水放流の変遷〔確認・文言候補〕**: 「**今ハ此坂下ニ樋アリテ北側ノ下水ヲ皆是ニ流入落ス三十年程前ニハ坂中ニ樋ナシ北側ハ神田川へ落シ**」＋「**三十年程以前ハ袋町ノ下水南側ハ此淵（豕ヶ淵）ヘ落テ…北側ハ北ニ流レテ鈴木町滝川久助屋敷前ニ大溝有テ堤下ヨリ神田川へ落セシ**」＝**明治11年時点では雁木坂下に樋があって北側の下水を流入落とすが、30年程前（≒1840年代）までは坂中に樋がなく、北側の下水は直接神田川へ、南側は豕ヶ淵へ落としていた**旨の記録。〔**神田川（江戸川下流）への市中下水の直接放流と、その後の樋経由化の変遷時期の目安（1840年代〜明治初年の間の変化）**。駿河台南斜面の排水系統の記録としてrepo初出候補。「三十年程前」は明治11年基準の約数であり、樋新設の正確な年次は本誌では確認できない。〕
- **豕ヶ淵〔確認・文言候補〕**: 「**豕カ淵トイヒシ**」（雁木坂下・山下弥蔵屋敷の下の、今は下水となれる溝）＝**雁木坂下の「豕ヶ淵」という淵の旧観記録**。〔淵の成因（猪に由来する伝承か）は本誌に詳細がなく断定しない。神田川流域の小地形（淵）の記録資料。〕
- **神田淵の考証〔確認・文言候補〕**: 「**今ノ三河町辺ヲ神田村トスヘキカ**」等の神田淵（田淵）の位置考証＝神田川の淵としての「神田淵」の地誌的比定記事。〔神田川の上流部（関口・江戸川方面）ではなく神田側の考証であり、repoの水系文言の背景資料。〕
- **陰性〔確認〕**: 本誌は神田・駿河台の地誌で、「弦巻」0件・「水窪」0件・「谷端」0件・「関口」0件（OCR fulltext確認）＝対象4河川の関口・音羽・雑司ヶ谷側の記録は含まれない。

## 制限・未解決

- ①無名氏の地誌であり、記載は伝承・旧観の考証と明治期の実観の混在する（袋町の胸突坂の「寛政四年ノ江戸図」がどの図版を指すかの同定は未確認・断定しない）。②「三十年程前」の樋新設時期は約数であり、神田川放流の終了年次としては使用できない（「1840年代まで直接放流があった」ことの傍証としてのみ使用）。③雁木坂・豕ヶ淵は神田川本流の南側斜面の記録であり、repo対象の弦巻川・水窪川・谷端川の直接の流域ではない（神田川水系の下水史の周辺資料として扱う）。④関口側の胸突坂（GAZ-076）との同名異坂の指摘は本誌の直接的な主張ではなく、両資料の対照によるrepo側の判断（GAZ-076の胸突坂が関口・元禄10年新道、本誌の胸突坂が神田袋町と、地点・初出年代が明確に異なるため）。
