# [GAZ-126] 町方書上[85] 下谷町方書上六 — 上野・下谷4町の「安永八亥年中」文言＝年次対立の原本側裏付け

- **書誌〔確認〕**: 『町方書上[85] 下谷町方書上　六』（写・NDL次世代デジタルライブラリー [book/2571566](https://lab.ndl.go.jp/dl/book/2571566)・73コマ）。各条の署名回月は「戌九月」（文政9丙戌9月＝1826候補）。**引用文言はすべてOCR由来で要原文照合。ページ番号は `2571566_{NNNNNNN}.txt` コマ番号。**
- **4町条の「安永八亥年」文言〔文言候補・本冊の主要価値〕**: いずれも定型句で出る。
  - 上野新黒門町条（署名p11）: 「**安永八亥年中千川上水相掛り候得共無程相潰レ当時右之形相見え不申候**」（p8）
  - 上野小右衛門町条（署名p31）: 「**安永八亥年中千川上水相懸り候江（と）も無程相潰れ当時右之形相見へ不申候**」（p26）
  - 下谷常楽院門前条（署名p38）: 「**安永八癸年中千川上水相懸り候江とも無程相潰れ当時右之形相見へ不申候**」（p35）〔**「癸」は亥の干支OCR崩れ候補（安永8年＝亥年）。同条の後段に不忍池畔（流れの寛橋）周辺の文言**〕
  - 上野元黒門町条（署名p47）: 「安永八亥年中千川上水相掛り候得共無程相潰れ当時右之形相見え不申候」（p41）
  ＝〔**①「安永八亥年中相懸り→無程相潰レ（→当時形なし）」＝**下谷・上野側の4町が給水開始年を「安永8亥年」として揃って記憶している**文言群。湯島側（[GAZ-120](GAZ-120.md)〜[GAZ-123](GAZ-123.md)）・本郷側（[GAZ-118](GAZ-118.md)・[GAZ-119](GAZ-119.md)）・外神田側（[GAZ-124](GAZ-124.md)・[GAZ-125](GAZ-125.md)）が「安永九子年中」（中には10月27日の仰付年月日を明記）と記すのに対する**年次の体系的対立（安永8亥年(1779)vs安永9子年(1780)）の町方書上原本側の裏付け**、②下谷側の文言は差止を「御差止」でなく「**相潰レ**」と表現する点も神田・湯島側と語彙が違う（差止主体を幕府の達と読むか町方の観察と読むかは断定しない）、③[GAZ-113](GAZ-113.md)（御府内備考・上野仁王門前条の「安永八亥年」文言）の原本側対照となる**。
- **常楽院門前条の不忍池畔文言〔付記レコード〕**: p35後段に不忍池の流れの寛橋（4ヶ所の組合橋文言候補）等の記載。〔上野・下谷側の水文と千川上水文言が同じ条の書上に並ぶ。樋・桝などの施設文言は本冊の4町条には出ない（樋区間の記憶が残らなかったか、区間外であることの陰性観察）〕。

## 制限・未解決

- ①「安永八癸年」の「癸」など干支のOCR崩れは原画像照合課題（安永8＝亥年固定）。②「相潰レ」の主語（上水自体の廃絶か町内の給水樋の潰れか）は文言上曖昧なまま、構造判断をしない。③4町の「安永8亥年」対「安永9子年（十月廿七日）」の対立（区域差か記憶の丸めか、実際の通水が2年がかりか）は本冊の文言だけでは解決できない。④樋・桝・井戸の記載が下谷側4町条にない理由（未設置・記憶喪失・条の枠外）は未解決。⑤書上の回月「戌九月」の年（文政9＝1826候補）は原画像照合で確定する。
