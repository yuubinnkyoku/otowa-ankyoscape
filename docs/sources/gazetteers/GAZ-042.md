# [GAZ-042] 外神田町方書上 [75] — 佐久間町の千川上水樋と「残地」

- **書誌〔確認〕**: 町方書上の一本（[75] 外神田町方書上 三・佐久間町弐〜四丁目・鍛冶町等の書上）。NDL次世代デジタルライブラリー [book/2571556](https://lab.ndl.go.jp/dl/book/2571556)。文政10年丁亥〔年判は要照合〕。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **佐久間町の千川上水条＝「残地」としての樋跡〔確認・町別の樋の規模の追補〕**: 佐久間町（筋違橋内・河岸通を持つ町）の書上に——「**一千川上水之儀は安永九子年十月廿七日牧野大隅守様御番所御懸ニ而上水掛渡之儀被仰付候義ニ而町内河岸通往還ゟ長百三拾八間壱尺五寸程残地と唱候通り長百三拾八間壱尺五寸程往来中程二埋に樋掛渡両通とも西之方中程塀壱ケ所宛有之候所天明七未年四月十三日御差止二相成候旨被仰渡通達有之其節取潰し埋立申候但元禄之度千川上水御掛渡之義相分不申候**」〔**①同じく安永9子年10月27日牧野大隅守様御番所御掛かりの仰付、②佐久間町の河岸通から往還にかけ「**長138間1尺5寸程**」の区間（「**残地と唱候通り**」＝差止後に残地と呼ばれた通り・OCRの解釈注意）に**往来の中程に埋樋を掛渡し**（両通りとも西の方中程に塀1ヶ所ずつ）、③天明7未年4月13日御差止→取潰し埋立**＝**佐久間町区間138間1尺5寸という町別延長の追補データ**〔[GAZ-044](GAZ-044.md)（府内備考・相生町68間余＋80間余・通船屋敷130間等）と併せ、神田区間の町別の埋樋延長の分解が進む。「残地」の語が樋撤去後の跡地の呼称として使われている可能性に注意（文言のまま記録し解釈は断定しない）〕。同巻の他の町（鍛冶町等）の書上も同文言の書式を含む〔各町の樋の規模の全体像はOCRの行対応の再精読が残る〕。
