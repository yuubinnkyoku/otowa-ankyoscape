# [GAZ-176] 町方書上[130] 深川 十一 — 三角屋敷条の本所上水替負人・享保7年9月上り地文言

- **書誌〔確認〕**: 『[130] 深川町方書上 十一』（写・NDL次世代デジタルライブラリー [book/2571611](https://lab.ndl.go.jp/dl/book/2571611)。NDL API volume欄直接確認）。深川三角屋敷条（koma 75-76）。引用文言はすべてOCR由来で要原文照合。※第223回の本冊boilerplate陰性判定（四河川keyword）は以下の文言を捉えていなかった＝本回訂正。
- **本所上水「替負人」吉右衛門の拝借町屋敷文言〔文言候補・本冊最重要〕（koma 75）**: 「**右町内起立往古之儀は委細材木町ゟ申上候 当所之義 元禄十四巳年二月中 本所上水替負人二而吉右衛門と申者拝借町屋敷に御座候 御代官伊奈半左衛門様御支配に有之 町銘唱之起立聢と相分り不申候得共 右吉右衛門義拝借町屋敷ニ相成 家作相立候所 鱗形に而其頃ゟ三角屋敷と相唱候由申伝に御座候**」（koma 75・OCR）＝**①元禄14年（1701）2月中・本所上水の替負人（請負人）吉右衛門が代官伊奈半左衛門支配のもと拝借した町屋敷、②家作を鱗形（三角形）に建てたため「三角屋敷」と呼ばれた**という文言候補。〔**「本所上水替負人」という職名・人名（吉右衛門）がrepo初出**（[GAZ-167](GAZ-167.md)の白堀浚・定渡受負人や[GAZ-168](GAZ-168.md)の桶掛・樋掛修復請負人と並ぶ請負実務層の新例・「替負」の字はOCR候補で「請負」の可能性を併記）。深川側に本所上水系の請負人が拝借屋敷を持ったという支給の地理的広がりの datapoint。〕
- **支配移管から上り地・引渡までの処分チェーン文言（koma 76）**: 「**所 正徳三巳年閏五月中 松野壱岐守様丹羽遠江守様坪内能登守様 町御奉行之節ゟ町方御支配に相成 其砌ゟ公役銀上納仕 其後享保七寅年九月中 上り地に相成候跡引続上納地二相成 右上り高町年寄え差出候旨申伝二御座候所 寛政九巳年正月晦日 氷川明神別当大乗院江右町屋敷御引渡二相成 当時も氷門附（=門附・OCR候補）町屋鋪二御座候**」（koma 76・OCR）＝**①正徳3年（1713）閏5月の町奉行（松野壱岐守・丹羽遠江守・坪内能登守）の節の町方支配化（公役銀上納）、②享保7年（1722）寅年9月中に上り地化（上り高は町年寄へ）、③寛政9年（1797）正月晦日に氷川明神別当大乗院へ引渡**という文言候補。〔**「享保七寅年九月中上り地」という年月の一次文言＝[GAZ-138](GAZ-138.md)（小梅瓦町条「享保七年九月 右上水相止候由」）と月単位で一致する独立witness**。上水差止（享保7年8〜9月・[GOV-170](GOV-170.md)）に伴う上り地処分が同月に行われたと読める処分チェーン（万治2給水→元禄14請負人拝借→正徳3町方化→享保7年9月上り地→寛政9寺社引渡）として、**本所上水系の拝借地の終末処分のタイムラインを初めて通しで書けた資料**（「仏」字混同には注意: 享保7寅の干支は整合）。差止と上り地の先行後続の因果は断定しない。〕
