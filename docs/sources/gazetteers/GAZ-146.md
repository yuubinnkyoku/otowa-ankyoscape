# [GAZ-146] 町方書上[12]（渋谷町方書上全）— 樋籠（広尾町旧小名）・宮益町改称・赤羽川の水源認識・富士見坂=道玄坂他称

- **書誌〔確認〕**: 御府内備考編纂の基礎資料となる**町方書上**の集成冊（目録番号[12]・渋谷町方書上全＝渋谷長谷寺門前・広尾町・宮益町・御掃除町・東福寺門前・道玄坂町・金王門前・金王八幡社地等の渋谷界隈の書上を1冊に収録）。NDL次世代デジタルライブラリー [book/2571493](https://lab.ndl.go.jp/dl/book/2571493)。各町の書上末尾に「**文政十一子年三月**」の起文が繰り返し現れ、書上の提出が文政11年（1828）3月であることがOCRで確認できた（要原文照合）。[GAZ-103](GAZ-103.md)（御府内備考巻70-74・渋谷川系の赤羽川呼称と橋群）・[GAZ-106](GAZ-106.md)の**元資料側候補**に当たる。**すべての引用はOCR由来で、文言は原文画像との照合を要する**（本冊はOCR崩壊が大きく、町名・村名の判読対立が多い）。
- **渋谷広尾町の旧小名「樋籠」と享保年中の文字相改〔確認・repo初出候補〕**: 「**一 当町起立之儀は往古者渋谷村惣石高之内に而 寛文八申年町家作御免被仰付 其節新地御奉行遠藤主馬様 奥津内記様御座候処 元禄十二卯年伊奈半左衛門様御検地之節ゟ石高相分り 右町家作之場所 御領下銀谷村 同所野崎組 同上知組下豊沢村 三浦五郎左衛門様御知行所 合而五ヶ村分は道巾下水百姓地等相溜弐拾弐ヶ所に相離居候 町方に御座候 且**町名之儀は渋谷村地之節ゟ小名樋籠と相唱候場所ニ付 則町名ニ相唱候哉に御座候処 享保年中ゟ文字相改候由 此度書留等無之 委細之儀は相分り兼申候**」＝**①渋谷広尾町の起立は寛文8申年（1668）の町家作御免（新地御奉行・遠藤主馬・奥津内記）、②元禄12卯年（1699）伊奈半左衛門の御検地で石高分かり（御領は銀谷村〔=恵比寿付近の「蛭橋？」の村か・判読要照合〕・野崎組・下豊沢村三浦五郎左衛門知行所の5ヶ村分が22ヶ所に相離れる）、③**町名は渋谷村の時の小名「樋籠」に由来し、享保年中に文字を相改めた**（書留なし・委細不知）**＝**広尾町の旧小名「樋籠」（ひろう）の存在と享保年中の改称の申伝文言候補（repo初出候補）**。〔広尾＝恵比寿との改字説の江戸期の町方側申伝として、町名対照表の広尾町行に追加候補。原字（樋籠の表記・享保年中改称の実否）は原画像照合まで断定しない〕。
- **渋谷新町→宮益町の改称と御嶽権現〔確認・repo初出候補の改称年次文言〕**: 「**一 当町起立之儀は往古渋谷村惣石高之内之由 年代相知不申 百姓地町家作仕 当所石高相分 渋谷新町と相唱 承応元辰年迄伊奈半左衛門様御聞配に御座候処 同二巳年嶋田出雲守様御知行所ニ相成 其後御上ケ屋敷(=御上げ屋敷候補)ニ相成候哉**元禄十一寅年九月廿七日又候伊奈半左衛門様御支配ニ相成 同十三辰年六月十八日五益町(=宮益町・OCR)ゟ町銘之唱相改候由 右唱之儀は町内鎮守御嶽権現之宮有之候ニ付 宮益町而申候由申伝に御座候 尤書留等類焼仕 委細之儀は相知不申候**」＝**①宮益町の旧称「渋谷新町」、②承応元辰年（1652）まで伊奈半左衛門支配→承応2巳年（1653）嶋田出雲守知行所→御上げ屋敷化→元禄11寅年（1698）9月27日伊奈支配復帰、③**元禄13辰年（1700）6月18日に町銘を「宮益町」に改め、町内鎮守の御嶽権現の「宮」に由来する申伝**＝**宮益町改称の年月日レベルの文言候補（repo初出候補）**。〔書留類焼で「申伝に御座候」の伝聞表現。御嶽権現由来説の江戸期一次文言候補として地名対照表の宮益町行に追加〕。
- **赤羽川の水源認識文言——内藤新宿追分の「玉川分れ／玉川分水」〔文言候補・元資料側〕**: ①広尾町条「**一 川之儀者 町内西之方に而赤羽川と相唱 凡巾八丈(=間候補・OCR) 内藤新宿追分ゟ玉川分水ニ而 不駄ケ谷村(=千駄ヶ谷村・OCR) 隠田村(=原宿村候補?・OCR要照合) 上渋谷村 宮益町 中沼谷村(=中渋谷村・OCR)ゟ当所え相掛り 末者三田堺新堀川と相唱申候 此道堀割年代相知不申候**」、②宮益町条「**一 川之儀は町内未申之方二而字赤羽川と相唱 凡巾三間 内藤新宿追分ゟ玉川分れ二而 千駄ヶ谷村 原宿村 横田村 上渋谷村ゟ相掛り 未は麻布三田堺江流行 新堀川と相唱申候**」＝**①赤羽川（渋谷川の宮益町〜広尾区間の呼称〔[GAZ-103](GAZ-103.md)第189回の「赤羽川」7件の元資料側〕）の水上を「**内藤新宿追分の孫（ゟ）玉川分れ（分水）**」とする町方側の水源認識文言、②川巾の対立（「凡巾八丈/間」〔広尾町条〕vs「凡巾三間」〔宮益町条〕・[GAZ-103]巾3間文言と宮益町条が一致）、③流経村の対立（宮益町条：千駄ヶ谷→原宿→横田→上渋谷／広尾町条：千駄ヶ谷→隠田?→上渋谷→宮益町→中渋谷→当所）、④流末は麻布三田堺の「新堀川」（古川系下流の呼称）と堀割年代不知**。〔**[GAZ-103](GAZ-103.md)（御府内備考巻73）の千駄ヶ谷側文言「四ッ谷大木戸ゟ分流水 南之方上渋谷邨江流入」（＝玉川御上水餘水落川の四ツ谷大木戸起源文言）に対し、本冊の2町の書上は共に**内藤新宿追分**を起源位置とする点が対立する**＝渋谷川上流部への給水源（玉川上水系分水）の位置認識が「四ッ谷大木戸」系と「内藤新宿追分」系で分かれる観察（どちらが正確な流路かは本資料からは断定しない・千川上水／神田上水／玉川上水のどの分水を指すかの比定も保留。水窪川（渋谷川上流）の源流論の対校材料）**〕。
- **窪尾大反橋＝広尾大坂橋のOCR変種候補〔文言候補・橋名調査に掲載〕**: 広尾町条「**一 橋之儀は前書赤羽川に相掛有之 下沼谷村(=下渋谷村・OCR)ゟ渋谷宿尾町(=幡ヶ谷候補?・OCR要照合)江相渡候板橋ニ而長拾弐間 帳(=巾・OCR)弐間 窪尾大反橋と相唱 掛ケ始年代相知不申 去御公儀普請に御座候**」＝**下渋谷村〜渋谷(幡ヶ谷?)宿を結ぶ赤羽川の板橋・長12間・巾2間・御公儀普請**＝[GAZ-103](GAZ-103.md)の広尾大坂橋（橋長拾弐間巾弐(人)間・赤羽川に相掛・御公義御普請）と**橋長・川・御公儀普請で完全一致＝「窪尾大反橋」＝「広尾大坂橋」のOCR判読変種候補（元資料側の対校witness）**。〔「窪尾大反」の原字は原画像照合まで断定しない〕。
- **富士見坂＝道玄坂他称の相互参照文言と道玄物見松〔文言候補・repo初出の相互文言〕**: ①宮益町条「**一 坂之儀は町内中程二而富士見坂と相唱 道巾三間五尺五寸 とり凡四拾間程ニ而富士山相見へ候ニ付 里俗ニ申伝候 但他所二而は道玄坂とも相唱候者有之候由二御座候得共 町内二而は本文之外相唱不申候**」＝**宮益町中程の坂（道巾3間5尺5寸・長凡40間・富士山が見えるために里俗に唱える「富士見坂」）が他所では「道玄坂」とも唱えられるが町内では本名以外唱えない**。②道玄坂町条「**一 坂弐ケ所 壱ケ所之儀は宮益町に挟り候町門前通り有之 道幅三間五尺余 登り凡四拾間程 右は前文申上候道玄太郎此坂之辺二居住仕候由申伝へ候 但右坂之儀 宮益町ゟ書上候冨士見坂之磯(=際・OCR)は同町ニ而は道玄坂名目相唱不申候**（中略）**右坂ゟ四五町西之方 上目黒村宿山北之内に道玄物見松と唱候古木有之候哉 同所名主市之丞と申者明和九辰年御代官伊奈半左衛門様江相願切払候由 当時同村百姓清三郎庭内に跡有之候由承り伝へ申候**」＝**①宮益町と道玄坂町の書上が相互に相手側の坂名文言を参照する構造（宮益町では「道玄坂は他所の唱え」・道玄坂町では「冨士見坂の際は同町では道玄坂の名目を唱えない」）＝同一坂の坂名の縦割り認識の一次記録候補、②道玄坂町の大永年中の道玄太郎居住説、③上目黒村宿山北の「**道玄物見松**」の古木（明和9辰年〔1772〕に名主市之丞が御代官伊奈半左衛門に願い切り払い、現在百姓清三郎庭内に跡）の伝承文言候補（repo初出候補）**。〔道玄坂の坂名論・富士見坂（渋谷）の旧唱の対校材料。文言はOCRで原画像照合前提〕。
- **その他の読取点〔文言候補〕**: ①宮益町条の御高札（きりしたん宗門禁制の高札文言の全写・「定 一きりしたん宗門は累年御制禁たり 自然不害成者これあらは申出へし…銀五百枚銀三百枚同断銀百枚…正是よ元年五月日奉行」〔正徳元年五月〕・渋谷宮益町・道玄坂町・広尾町の三ヶ町持の御除地15坪〕、②道玄坂町条の塩谷＝潮入・埋木の海跡地形譚（[GAZ-103](GAZ-103.md)第189回追記の元資料側文言の確認）、③広尾町・宮益町の下水3ヶ所（笄橋辺から流来の巾6間の横切下水の赤羽川落入等・[GAZ-103]の広尾町下水3件と同内容の元資料側）、④金王八幡社地50049坪の門前町（延享3寅年町方御支配化）等。

- **宮益橋の寸法対立（長五間巾二間 vs 長拾間巾弐間）〔文言候補・第225回並走実行の追記・OCR要照合〕（p77-78）**: 宮益町条——「**此辺橋之儀は 右赤羽川え相掛 文壱町〔=宮益町判読〕ゟ 中渋谷村江相渡候 板橋二而 長五間 巾弐間有之 字宮益橋と唱 掛始年代相知不申 尤 御公儀普請に御座候**」＝**長五間・巾二間・宮益町⇄中渋谷村・掛始年代不知・御公儀普請**。丁亥書上（文政10・[GAZ-103](GAZ-103.md)第189回③）の同橋は「宮益町ゟ中渋谷邨江渡候橋 長拾間 巾弐間… 宮益橋… 御公儀普請」＝**長拾間**。渡る町・属性が同一で橋長だけが食い違う＝判読（拾/五の崩壊）・4年間（1827→1831提出）の掛替・別橋の3仮説を等しく保持し、原画像照合まではどれにも傾かない。寛延2年出水（1749）と天明6出水（1786）の被災歴（橋名調査第198/206回追補）と組み合わせると架替説の検証材料となる可能性がある。

## 制限・未解決

- ①すべてOCR由来で特に村名・小名の判読対立が激しい（銀谷村＝「氷谷」等の別村か・「隠田村」の原字・「渋谷宿尾町」＝幡ヶ谷宿か・「樋籠」の表記・「八丈/八間」の巾の対立・「承応元辰年」の干支整合〔承応元年=壬辰✓〕等、原画像照合が前提）。②宮益町改称の元禄13辰年6月18日と広尾町の享保年中改称の史実性は書留なき申伝文言であり断定しない。③「玉川分れ／玉川分水」の水利同定（千川上水・神田上水・玉川上水のどの分水か）と内藤新宿追分起源文言vs[GAZ-103]四ッ谷大木戸文言の対立の決着は保留。④「道玄物見松」の「明和九辰年」は明和9年=壬辰で干支整合するが、伊奈半左衛門の在職年代との整合は未確認。⑤本冊のOCR全文は13,692字程度と短く、収録町の網羅性（長谷寺門前・東福寺門前・車福寺門前・御掃除町の書上の細部）は今後の再走査課題。
