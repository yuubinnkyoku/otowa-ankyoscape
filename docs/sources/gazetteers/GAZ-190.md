# [GAZ-190] 東京市史稿 市街篇 第十四 — 霊岸島川口町「八町堀千川屋鋪」の請取文言と湯島埋樋の対校点〔第322回〕

- **書誌〔確認〕**: 東京市役所編『東京市史稿』**市街篇 第十四**（昭和9年〔1934〕刊・次世代デジタルライブラリー [book/3450788](https://lab.ndl.go.jp/dl/book/3450788)）。市街異動・屋鋪受授事蹟の編年系の冊で、元禄年間（坂本新道・坂本町の起立、霊岸島側の新地町屋など）の異動を『御府内沿革書』（図據）・『東京府誌』等の引用で採録する。引用文言はOCR由来で要原文照合。
- **霊岸島川口町「八町堀千川屋鋪」条〔文言候補・repo初出の一次文言・要原画像照合〕**: 「御府内沿革書図據ニ據レバ」の preamble の下に——「**靈岸島柳澤出羽守殿上ケ屋敷、今度町屋爲代地御渡被成、四方間數坪數右御繪圖之面、傍示杭之通、相違無御座請取申い。爲後日仍如件。（元祿十二己卯年）二月三日 松前伊豆守組與力 平塚伊右衞門（印）・保田越前守組與力（松前伊豆守組）… 松前伊豆守組同心 生田三郞左衞門（印）・鈴木孫左衞門（印）・保田越前守組同心… 町年寄 布施半右衞門（印）・奈良屋市右衞門（印）…**」＋図面帳の明細「**靈岸島川口町 坪數四千六百拾貳坪。西川。道。南南川。北道。東六間四尺、三十四間五尺、十四間、三十貳間壹尺…西九十五間三尺。南四十七間。北三十六間三尺…**」＝**霊岸島川口町の柳澤出羽守殿の上ケ屋敷（4,612坪）が、元禄12己卯年（1699）2月3日に町屋の代地として御渡しされた際の受領側の請取文言**。立会いは松前伊豆守組・保田越前守組の与力・同心（平塚伊右衞門・生田三郎左衞門・鈴木孫左衞門ら）と町年寄（布施半右衞門・奈良屋市右衞門）。前列の記事（元禄12年の山王旅所北通の入堀之内の埋立による新地町屋の成立・呉服師八人町屋敷・向井將監屋敷被召上・坂本新道の起立）と同じ元禄12年の市街異動の流れの中に置かれる。〔柳澤出羽守の人物比定（柳澤吉里候補等）は本資料のみでは行わない。四至「西川・南南川」は江戸川筋（霊岸島側の水際）に面する屋敷であることを示す。〕
- **「千川屋鋪」の語義〔仮説・断定しない〕**: 本条の節見出しとして「**八町堀千川屋鋪**」の語が（OCR列混在の中で2回）現れる。①本repoの主対象である千川上水（仙川用水）系の呼称か、②江戸湾・湊側の別系統の「千川〔仙川〕」系水路名か、③OCRの误読・判読揺れか、は本文・OCRの列崩れ（他言語文字コードの混入した判読不能部「玉鮮ハ賀新人地期限壓壓妊之川…」を含む）からは確定できない。霊岸島川口町の立地（江戸川の川口）は千川上水系の直接の施設座標ではなく、語義の確定は原画像照合まで保留する。
- **湯島切通町の神田上水埋樋86間5尺条の採録〔確認・既収録の対校点〕**: 同冊の湯島系の屋鋪受授の中に「**千川上水之義と、安永九子年中 町內往還長八拾六間五尺 往來中程ニ埋中樋懸ケ渡し 但、委細之義〓元錄之度之義と、相分不申い**」＝安永9年（1780）再興期の湯島区間の埋樋（町内往還86間5尺の中程に懸渡）の書上文言が採録されている。この文言は [GAZ-122](GAZ-122.md)（町方書上〔69〕の同内容）の東京市史稿市街篇側の採録として**対校本**に相当し、文言・数値は同一のため新規情報とはしない（GAZ-122 の対校欄に本冊を加える価値のみ）。
