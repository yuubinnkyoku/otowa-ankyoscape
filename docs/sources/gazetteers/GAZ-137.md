# [GAZ-137] 町方書上[147] — 柏木淀橋町条の淀橋（定橋）・姿不見之橋文言と弥兵衛水車の家史・千駄ヶ谷条（対校）

- **書誌〔確認〕**: 『町方書上[147]』（写・NDL次世代デジタルライブラリー [book/2571628](https://lab.ndl.go.jp/dl/book/2571628)）。収録＝大久保前町（文政十亥年五月・名主次郎左衛門）→柏木成子町（「地誌御調書上帳 柏木成子町」p15・p28）→**柏木淀橋町（「地誌御調書上帳 柏木淀橋町家持久兵衛」p39）**→同町円照院（p47）→千駄ヶ谷（p67-68）等。**引用文言はすべてOCR由来で要原文照合。頁番号は `2571628_{NNNNNNN}.txt` コマ番号。**
- **本登録の性格**: ①[GAZ-111](GAZ-111.md)（御府内備考巻66写本・澱橋町条）・[GAZ-039](GAZ-039.md)（改正新編江戸志・淀橋条）の**元資料側（町方の地誌御調書上そのもの）の文言の直接確認**＝「定橋／淀橋」の判読対立の一方の側の元文言がここで初めて直接読める、②姿不見之橋文言（[対照表](../../地名・河川名対照表.md)第52/53行の異名群）の町方書上側の整った文言、③家持久兵衛・先祖弥兵衛の水車家業の三代記録＝[GOV-390](../gov/GOV-390.md)（享保撰要類集・享保4年水車仕立の寛文年中説対校案件）・[GOV-395](../gov/GOV-395.md)（東京市史稿の文政町方書上引用）の**引用元の文言の原冊側確認**、④千駄ヶ谷条＝[GAZ-103](GAZ-103.md)（御府内備考巻70-74・丁亥書上）の元資料側（対校記録のみ・新たな文言層は作らない）。
- **町名の起り＝橋名との判読対立「淀橋／定橋」〔文言候補・本冊の核心1〕（p34）**: 「**町名之起りハ 町内未(=西・OCR候補)西之方 神田御上水江掛リ候橋ヲ**淀橋**ト申候故 如斯唱申候**」＝**町名の起りは町内の西の方の神田御上水に掛かる橋を「淀橋」と申すことによる**。〔**①[GAZ-111](GAZ-111.md)（御府内備考写本）の同一箇所はOCR「定橋ト申」と読んだ＝「淀橋」（本冊）vs「定橋」（御府内備考写本）の判読対立が成立**（後述の「山城国淀」の御上意文言が「淀」字を前提とするため本冊側の読みを支える要素があるが、両方ともOCRであり断定しない・原画像照合で決着する）、**②[GOV-395](../gov/GOV-395.md)（東京市史稿）の引用も橋名文言の系譜に既に載る**。「町内未」の「未」は行頭崩れで「西」などの方角の字候補（[GAZ-111](GAZ-111.md)の「末西之方」との対校で「西之方」が復元候補）**〕。
- **姿不見之橋から淀橋へ＝御上意譚の整った文言〔文言候補・本冊の核心2〕（p34・p36-37）**: 「**右橋之儀者 享保年中ノ頃迄ハ 姿不見之橋ト申候由**」＋「**右御上水ヲ 泥留(=堰留候補)水車渡世致候 然ル処 享保年中 有徳院様中野筋御成之節 山城国**淀**水車之形ヲ有之由ニ而 右橋ヲ淀橋ト申 御上意有之候由申伝(=OCR崩れの候補・原字要照合)に御座候 右橋之儀者 御普請方御掛リニ而 当町内持ニハ無御座候**」＝**①右の橋は享保年中の頃までは「姿不見之橋」と申した由、②それ以来は水車弥兵衛という者が神田御上水を堰き留めて水車渡世をした、③享保年中・有徳院様（吉宗）中野筋御成の節に「山城国淀の水車の形」があることから右の橋を「淀橋」と申す御上意があったと申伝、④橋は御普請方御掛かりで当町内持ではない**。〔**①「享保年中ノ頃迄ハ姿不見之橋」＝不姿見橋（[GOV-396](../gov/GOV-396.md)1854巷説）・姿見ず橋([BOOK-148](../books/BOOK-148.md))・[GAZ-039](GAZ-039.md)（江戸志改正「又姿不見橋トモ云」）・[GAZ-111](GAZ-111.md)（「享保之比上ハ姿不見之橋」）層の元資料側文言、②「山城国淀水車之形」＝淀の国名と水車の形を結ぶ命名譚の一次文言候補（[BOOK-152](../books/BOOK-152.md)四編の「暇乞橋・なみだ橋・姿見ず橋」・[GAZ-030](GAZ-030.md)（江戸名勝志・寛永御鷹野上意説）・[BOOK-209](../books/BOOK-209.md)（紫の一本・大猷院様御鷹野説）と別系の御上意譚として対照表の面影橋＝淀橋異名群の行に加える）、「泥留」は「堰留」のOCR候補**〕。
- **神田御上水の規模と流路文言〔文言候補・GAZ-111との文言対立〕（p36）**: 「**神田御上水 当町内ニ掛リ候 長三十間幅四間 但当町内ト多摩郡境ヲ相流申候 尤中野村江繰リ 本郷村 角谷村(=角筈村?・判読対立)ゟ当町地先ニ掛リ 末ハ柏木村江相流申候**」＋「**右御上水之儀ハ 無礼(=元?)村井之頭地ゟ流古水ニ御座候**」（「村井之頭」＝**井之頭**のOCR候補）。〔**①長30間・幅4間・町内と多摩郡境を相流＝[GAZ-111](GAZ-111.md)「長三拾間巾四間 右当町内ニ掛り 町内と多摩郡境ヲ相流」と寸法完全一致（元資料・編纂側の対校）、②流路は「中野村江繰リ 本郷村・角谷村ゟ当町地先ニ掛リ 末ハ柏木村」＝[GAZ-111](GAZ-111.md)の「本郷村 角笹邨(?)ゟ小富町(?)地先二掛リ 末ハ板木(幡ヶ谷?)村 中野村江相流」と並びが異なる＝「角谷村／角笹邨」「柏木村／板木(幡ヶ谷)村」の判読対立・流末の文言対立（比定は照合まで保留）、③「村井之頭地ゟ流古水」＝[GAZ-111](GAZ-111.md)「無礼村井之駅(?)池ゟ流古水」との判読対立＝「井之頭」 reading を本冊側が与える（井之頭池を水源とする神田上水本流系の文言候補・[GOV-390](../gov/GOV-390.md)の井之頭池水門管理と整合するが断定しない）**〕。
- **家持久兵衛・先祖弥兵衛の三代の水車家史〔文言候補・GOV-390/395の引用元の原冊側確認〕（p37・p40）**: ①「**右久兵衛先祖弥兵衛ト申者 年暦不知 旧来ゟ小宿所百姓ニ而罷在候処** 寛文年中 神田御上水助水堀分水仕 水車取立申度段相願 右願之通被仰付候由**」＝**先祖弥兵衛（旧来の小宿所百姓）が寛文年中に神田御上水の助水堀の分水をし水車を立ちたいと願い、願どおり仰せ付けられた由**（p40）、②「**神田御上水ヲ 泥留(=堰留)水車渡世致候 小麦粉幷米麦等 舂立渡世仕候**」＝小麦粉・米麦等の搗立の水車渡世（p34-36）、③「**三代目弥兵衛代 享保十七子年三月中 中野筋え有徳院様御成之節 右弥兵衛方え** 初而九五(=御成御?・OCR崩れ候補)御小休所ニ相成申候 其後象御預ケ等被仰付**」＝**三代目弥兵衛の代・享保17子年（1732）3月中の中野筋御成の節に弥兵衛方が初めて御小休所となり、その後象の御預け等を仰せ付けられた**（p37・p46の象の記事と対）。〔**①「寛文年中」の起立願文言＝[GOV-390](../gov/GOV-390.md)（享保撰要類集・享保4亥年の松平伊賀守相願）と対立する町方側回顧年代の原冊文言＝[GOV-395](../gov/GOV-395.md)（東京市史稿引用）が既に採録し「寛文年中説 vs 享保4年説」の対校案件とした文言の元本文の直接確認、②享保17年3月の中野筋御成＝上の姿不見之橋→淀橋の御上意譚（「享保年中」としか言わない）と同じ御成の可能性が強いが本冊自身は両文言を結合しないため結合は断定しない、③象の記事は寛文2年の象（江戸へ来た象）に関わるとみられるが象の比定は本冊の文言からは行わない**〕。
- **千駄ヶ谷条の玉川御上水餘水落川〔確認・[GAZ-103](GAZ-103.md)（御府内備考巻70-74・丁亥書上）の元資料側＝重複層につき対校記録のみ〕（p67-68）**: 「**玉川御上水餘水落川 但堀割之年代相知レ不申 川巾不同 凡弐間程 右ハ西福寺領吉祥寺領入合罡(=異?山?領)面之内え流 水上之儀ハ四ツ谷大木戸ゟ訳流入 南之方上渋谷村え流入申候**」＋「**西橋高瀬(=吉禅寺領?OCR候補) 吉祥寺領入合百姓地之内ニ御座候 長九尺巾壱丈壱尺 寛政十午年八月中 石橋ニ掛替 古来板場(=板橋?場)ニテ有之候 懸渡始年代相知不申 右橋名目無之候 七丁板橋壱ヶ所**」＝[GAZ-103](GAZ-103.md)が丁亥書上（文政10）として既採録の**玉川御上水餘水落川（巾凡2間・四ツ谷大木戸の分水・上渋谷村流入）・西橋高瀬の石橋掛替（寛政10年8月）・七丁板橋の文言と同一内容**＝本冊[147]は元資料側の一冊であることの対校確認のみ（新たな對校・新文言の採番は行わない）。石橋寸法の表記摇れ（「石橋長弐間巾六尺」等の有無）の照合は原画像課題。
