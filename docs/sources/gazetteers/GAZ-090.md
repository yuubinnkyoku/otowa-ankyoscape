# [GAZ-090] 大橋方長『江戸往古図説』（東京府文献叢書甲集第四冊） — 東西大塚・鶏声窪旧名説・増司ヶ谷村条等〔第167回登録・第168回書名同定・条項追記〕

- **書誌〔確認・第168回書名同定〕**: 大橋方長『江戸往古図説』（NDL次世代デジタルライブラリー [book/2577095](https://lab.ndl.go.jp/dl/book/2577095)・東京府文獻叢書甲集第四冊地理・明治11年1月輯の写し）。**fulltext冒頭で「東京府文獻叢書甲集第四冊地理 明治十一年一月輯 江戸往古図説 大橋方長」と自記し**、自序は「**寛政庚申年 大橋（方長）**」で締め、城郭条に「**此城築カレシヨリ当今享和元辛年ニ至リテ凡三百四十六年ニ及ヘリ**」＝**享和元年（1801）を「当今」とする言及がある**。＝**成立は寛政庚申（1800）〜享和元年（1801）頃の江戸往古地理の考証書**（古図を得て、古書と古老の言伝えに基づき地境を考証する体裁・上巻は城郭〜平川村〜雑司ヶ谷・石神井・練馬方面、下巻は神田村〜小石川・巣鴨・駒込〜滝野川・新堀村等の村条目次）。**第167回の「書名未同定」は本同定で解消。引用文言はすべてOCR由来で要原画像照合。**
- **東西大塚の範囲構造〔確認・文言候補・第167回登録〕**: 「**大塚是ハ太田塚ノ略称ナリトイヘル説アリ此辺七ケ處ニ太田氏塚ヲ築レシト云古ヘハ東西大塚ト呼ンデ至テ広キ地ナリ鶏声窪土井家ノ辺ハ東大塚ト云波切不動ノ所ナトヲ西大塚ト云シヤシ**」＝東西大塚の範囲構造の記述〔[GAZ-083](GAZ-083.md)（小石川志料）の土井家文言と同型・七ヶ所太田氏塚・波切不動＝西大塚は本書側の追加〕。
- **鶏声窪の旧名説〔確認・文言候補・repo初出・第168回年代基準点確定〕**: 「**鶏声窪今地名ノヤウニナレリ元皇角原ト云ヨシ此地土井家内ニ鶏声窪古跡アルヨシイエリ今ハ酒井家ノ内ニ入タリト云**」＝鶏声窪の旧名「皇角原」説＋土井家内の鶏声窪古跡・酒井家内への移行の言〔**第167回は本冊の成立年代を未確定としていたが、第168回の書名同定により、この旧名説の記録は1800-01年成立の考証書に遡ることが確定**。「皇角原」はOCR崩れの余地が大きく（「白山原」・「向岡原」等の類形の可能性も含め）、原画像照合まで読みは保留。[BOOK-197](../books/BOOK-197.md)（1779年由来譚）・[GOV-403](../gov/GOV-403.md)（1750年実務文書）と順に並ぶ年代系列の中の1800-01年の点として位置づけ〕。
- **増司ヶ谷村条〔確認・文言候補・第168回追記・repo初出〕**: 「**増司谷村北條分限帳ニ出今雜司谷ト書ス比ワタリ古ヘ巣鴨ノ庄ト云シ由法明寺ハ開基慈覚大師元天台ノ霊地也日源上人ノ頃日蓮宗ト改開基ヨリ凡九百八十有余年ニ及ヘリ鬼子母神ハ永禄ノ頃清土ト云地ヨリ堀出スト云清土又清戸トモ書民俗ハセイトウト云リ此地ニ今三角ノ井ト云アリ此地鬼子母神出現ノ所ト云**」＝**①雑司ヶ谷の旧字「増司谷」が北条分限帳に出る旨、②古くは「巣鴨の庄」と称した由、③鬼子母神は永禄の頃「清土」という地より掘り出した旨、④「清土」は「清戸」とも書き、民俗ではセイトウと読む旨、⑤此地に今「三角の井」があり、ここが鬼子母神出現の所とする旨**〔**①「増司谷」表記（[BOOK-144](../books/BOOK-144.md)の雜士谷・藏主ヶ谷等の表記群に加わる1800年の考証書側の別表記・北条分限帳所出とする系統はrepo初出候補）、②古巣鴨庄説（雑司ヶ谷の中世的所属の説・repo初出候補）、③清土＝清戸の別書と民俗音セイトウの記録、④三角の井の1800年の独立記録＝[GAZ-066](GAZ-066.md)（名水品彙の三角井泉）・[GAZ-070](GAZ-070.md)（1858「三ヶ用井」）に先立つ年代の対校点、⑤鬼子母神掘出地＝三角の井の地点の同定の系統を1800年に遡らせるdatapoint。OCR崩れあり要照合**〕。

## 制限・未解決

- ①「皇角原」の原字形は最重要照合案件（崩れ候補を複数保持）。ただし成立年代は1800-01年頃に確定した（旧名説の年代基準点として使用可能）。②「増司谷」の北条分限帳所出の真偽（分限帳の実物確認は別途）・「古巣鴨庄」説の出典は本文言では不明。③誓閑寺の小流の同定・誓閑寺の現所在地の確認は未了。④石神井村条・平川村条は四河川の範囲外の参考記録で、各川の流路史への組み込みはしない。
