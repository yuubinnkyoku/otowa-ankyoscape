# [GAZ-090] 東京府文献叢書[4] — 東西大塚の範囲構造と鶏声窪の旧名説（皇角原）〔第167回〕

- **書誌〔確認〕**: 『東京府文献叢書』[4]（写・NDL次世代デジタルライブラリー [book/2577095](https://lab.ndl.go.jp/dl/book/2577095)）。内容は氷川白山神社・光圓寺（行基開基説）・伝通院・浄心寺・祥雲寺・吹上等の小石川・大塚周辺の寺社・地名の地誌的記述。**書名は本冊内では同定できず未確認（[GAZ-083](GAZ-083.md)の甲集17『小石川志料』と同系統の地誌の写しの候補だが断定しない）。引用文言はすべてOCR由来で要原画像照合。**
- **東西大塚の範囲構造〔確認・文言候補〕**: 「**大塚是ハ太田塚ノ略称ナリトイヘル説アリ此辺七ケ處ニ太田氏塚ヲ築レシト云古ヘハ東西大塚ト呼ンデ至テ広キ地ナリ鶏声窪土井家ノ辺ハ東大塚ト云波切不動ノ所ナトヲ西大塚ト云シヨシ**」＝**①大塚＝太田塚の略称説・この辺り七ヶ所に太田氏の塚を築いた伝、②古くは東西大塚と呼んで広い地であった、③鶏声窪の土井家の辺が東大塚・波切不動の所などが西大塚**という東西大塚の範囲構造の記述〔**「鶏声窪土井家ノ辺ハ東大塚ト云」＝[GAZ-083](GAZ-083.md)（小石川志料）の「又鶏声窪 土井氏の下あたりをも大塚と云」＋「東大塚は〔鶏声〕窪土井大炊頭屋敷内にあり」と同型の文言で、鶏声窪の位置を東大塚（土井家辺）に置く系統の別冊側の裏付け（七ヶ所太田氏塚・波切不動＝西大塚の範囲情報は本冊側の追加）**〕。
- **鶏声窪の旧名説〔確認・文言候補・repo初出〕**: 「**鶏声窪今地名ノヤウニナレリ元皇角原ト云**」＝**鶏声窪は今は地名のようになれているが、元は「皇角原」といった旨**〔**鶏声窪の旧名「皇角原」説（repo初出の文言候補）**。「皇角原」はOCR崩れの余地が大きく（「白山原」・「向岡原」等の類形の可能性も含め）、原画像照合まで読みは保留。[BOOK-197](../books/BOOK-197.md)（1779年由来譚）・[GOV-403](../gov/GOV-403.md)（1750年実務文書）に先立つ時代の旧名と主張する記録だが、本冊の成立年代は未確定で、旧名説の史実性は断定しない〕。
- **同冊の他の記述〔参考〕**: 巣鴨村・氷川神社（江戸志の考証引用）・中興治乱記の応永元年巣鴨陣取等の小石川周辺の地名考証が同居（巣鴨・大塚の地名史の背景資料）。

## 制限・未解決

- ①書名の同定は未了（東京府文献叢書の甲集・乙集等の目録との照合が前提）。②「皇角原」の原字形は最重要照合案件（崩れ候補を複数保持）。③本冊の成立年代（写しの元の年代）は未確定で、旧名説の時代的前後関係（BOOK-197・GOV-403との順）は判定できない。④「七ケ處ニ太田氏塚」の各所の同定は本文言では不可能。
