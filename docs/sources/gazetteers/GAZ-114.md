# [GAZ-114] 御府内備考 巻21-23（下谷之一〜三・写本OCR）— 長者町繋車坂町の千川上水之樋と水銭204文/月

- **書誌〔確認〕**: 『御府内備考』巻之二十一〜二十三（下谷之一〜三）。NDL lab [book/2553670](https://lab.ndl.go.jp/dl/book/2553670)。書上文言の末尾に「**丙戌書上**」（文政9年・1826）＝[GAZ-113](GAZ-113.md)（巻24-28・2553671）と同時期の町方書上集成本。**引用文言はすべてくずし字OCR由来で原画像照合を要する。** 本資料は巻21-23分冊（下谷側）で、[GAZ-082](GAZ-082.md)（大日本地誌大系活字版・巻8-14/41-46等の編集を含む）の写本側対応巻の一つ。
- **本登録の性格**: ①**下谷長者町繋車坂町条に千川上水の樋と水銭の定量文言**（月々204文・天明6年正月〜10月）があり、[GAZ-082](GAZ-082.md)上野山下条の404文/月に並ぶ**水銭層の第2の数値**（repo初出）であること、②**下谷六軒町条の小名「埋堀」**が元溜池の埋立地の小名であること、③下谷側でも「**安永八亥年中千川上水相掛り候得共無程相潰れ**」文言が出ること（[GAZ-113](GAZ-113.md)上野仁王門前町条・活字版対応と同文の重複witness）が主な読取。

## 第215回の読取（2026-11-20）

- **長者町繋車坂町条の千川上水之樋と水銭〔文言候補・本登録の核心〕**: 「**一 町内道幅中程二千川上水之樋御座候 右は大明（＝天明候補・OCR）六年正月ゟと相見へ 町入用押切帳面二正月分ゟ水致月々弐百四文宛 同年十月迄差出し来り候得共 其次は無御座候**」＝**①町内の道幅中程に千川上水の樋があり、②（町の帳簿では）天明（OCR「大明」・判読要照合）六年正月からと見え、③町入用押切帳面に同年正月分から水銭月々204文宛を同年十月まで差し出した記録があり、同年十月以降（とそれ以前）の記録は無い旨**。
  - **条帰属〔OCR構造からの帰属・要照合〕**: この文言は「以上丙戌書上」直前、条末尾の支配変遷文言（往古は御代官伊奈半右衛門様支配→寛永九申年より東叡山御目代田村権右衛門支配→寺社奉行→延享二子年二月町方御支配）とともに、**下谷長者町繋車坂町条**（OCR「長者町統車坂町」・「統」は「繋／続」の判読対立候補）に属する。同条は寛永元年東叡山御建立の際の車坂下町屋起立→「下谷車坂町」改称→元禄11年上地で御徒町へ代地（当時地面数7ヶ所・御徒御組屋敷立跡）の由緒をもち、四隣＝東=長者町弐丁目・西=往来（福井上筑後守殿屋敷）・南=**上野南大門町**・北=土野御家来屋鋪＝**上野山の南西麓の代地町**。
  - **位置づけ**: [GAZ-082](GAZ-082.md)上野山下条「天明六午年正月 町內道幅中程え千川上水の樋御座候…水錢月々四百四文（404文）」と①「町内道幅中程に樋」という設置文言、②押切帳面による水銭記録、③天明6年正月起算、の3点が構造的に一致し、水銭額（204文/404文）と条帰属が異なる＝**千川上水の給水末端（上野・下谷側）で複数の町が月額を異にして水銭を差し出していたことを示す第2例**。天明6年（1786）正月〜10月の支払記録が翌天明7年4月の差止（[GAZ-041](GAZ-041.md)〜[GAZ-045](GAZ-045.md)・[GAZ-049](GAZ-049.md)・[GOV-216](../gov/GOV-216.md)〜[GOV-218](../gov/GOV-218.md)）の直前の運用実態の記録であり、**安永9年掛渡→天明6年水銭（404文＋204文）→天明7年4月差止→埋立**という千川上水末期の時系列に水銭層の数値を加える。
- **下谷六軒町条の小名「埋堀」〔文言候補・repo初出の小名〕**: 「**板倉内膳正様御下屋敷南側往来り隔一ヶ所小名ヲ埋堀と唱申候 元溜池を埋立候故右之濁（＝跡候補・OCR）に御座候**」＝**下谷六軒町内（板倉内膳正様御下屋敷の南側・往来を隔てた1ヶ所）の小名「埋堀」＝往古の溜池を埋め立てた跡地である旨**。〔**元溜池の埋立地名の小名としての生きた使用例。同条の小名群（薬養寺前・西町等）とともに、上野山南麓の湧水・溜池系の地形記憶の地名側資料。「埋堀」は既存の対照表に未収録の語で新行候補**〕。
- **下谷側の安永八文言〔文言候補・GAZ-113の重複確認〕**: 巻21冒頭の条（4ヶ町組合の橋＝上野仁王門前町・上野町弐丁目・下谷半楽（＝本性）院門前と組合掛ケ直しの文言をもつ町・**条帰属の町名はOCRから確定できず原画像照合要**）に「**安永八亥年中千川上水相掛り候得共無程相潰し当時右之形相見不申候**」＝[GAZ-113](GAZ-113.md)上野仁王門前町条（巻24-28）の安永8年文言（第214回追記）と同一内容の**下谷側（巻21-23）での重複出現**。新規採番の対象とはせず、安永8年相掛→挫折の文言の分布が上野側・下谷側両巻にあることを本ファイルに確認記録する。直後に正法院門前条（北隣=正法院門前・切し地・車坂の小名）が続き、**車坂・正法院門前周辺が安永8年千川上水の下谷側の相掛り範囲に含まれていた地表**を読み取れる。

## 陰性走査の記録（第215回）

- 本冊（巻21-23・下谷之一〜三）を対象河川名（水窪・弦巻・谷端・金森・白堀・弥生・藍染・千川）で走査し、上記3件のほかは陰性。**これにより巻21-23の走査は完了**。御府内備考所蔵冊の残冊（巻1-20・79-83等）の陰性走査と併せ、**所蔵全冊（2553660〜2553704相当）の走査が完了した**（対応表は[第215回ノート](../../2026-11-20（第215回）・御府内備考残冊走査の完結と千川水銭・浅草側千川末端・赤坂白堀樋の追加調査.md)参照）。
