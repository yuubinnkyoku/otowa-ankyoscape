# [GAZ-113] 御府内備考 巻24-28（下谷之四・根津・谷中・写本OCR）— 藍染川総説と千川家の根津・谷中側橋負担の実名群

- **書誌〔確認〕**: 『御府内備考』巻之二十四〜二十八（下谷之四〔上野仁王門前町〕・根津之一二〔根津総説・宮永町・門前町・社地門前〕・谷中之一二〔谷中総説・三崎坂ほか坂名群・各寺門前町・三崎町・玉林寺門前町〕）。NDL lab [book/2553671](https://lab.ndl.go.jp/dl/book/2553671)。書上文言の末尾に「**丙戌書上**」とあり（文政9年・1826。一部「丁亥」の混在可能性も含め要照合）＝**千川金七由緒書（[GAZ-034](GAZ-034.md)・2553675）と同時期の町方書上**。**引用文言はすべてくずし字OCR由来で原画像照合を要する。**
- **本登録の性格**: ①谷中総説に**藍染川を谷戸川の末流として規定する文言（repo初出の江戸期市中集成側の系統文言）**があること、②根津・谷中側の諸橋の修復負担人として**千川家の人名（茂是〔茂兵衛候補〕・茂兵衛・重助）が町方書上に実名で現れる**こと（[GOV-210](../gov/GOV-210.md)・[GOV-211](../gov/GOV-211.md)の嘉永3年遠山書付・由緒書群に先行する1826年時点の負担実名）、③根津社地門前の起立文言に「**千駄木元根津**」＝元根津の語が現れること、④玉林寺門前・三崎町の藍染川幅9尺・石橋「**不明門之橋**」「**北巴之橋**（OCR候補）」の定点観察群、が主な新規層。

- **「不明門之橋」のOCR対立「北明門之橋」〔文言候補・判読対立の新たな一組〕**: 同じ谷中町方書上善光寺前町条に「**板橋北明門之橋と唱…三浦備後守様御屋敷御懸り**」とある＝本資料の「不明門之橋」（三浦備後守様御屋敷御懸り）と**懸り先が同一で「不明門／北明門」の字形対立**。御府内備考（本資料）と町方書上元書（[GAZ-129]）のいずれの写もくずし字OCRに依存するため、どちらの原字かは原画像照合まで断定しない（甲府屋敷不明門の遺名説の当該判読は従来通り「有力候補」に留める）。

- ①すべてくずし字OCR由来で、固有名の判読対立（茂是/茂兵衛・北巴之橋/北北巴之橋・金助/重助・不明門/北明門・四禄・倉山・威応寺/感応寺等）は断定せず併記し原画像照合を要する。②「千川重助」の系譜上の位置づけ（金七・宇兵衛等の代・分家のいずれに当たるか）は`docs/千川上水請負人の変遷.md`・[GOV-210](../gov/GOV-210.md)・[GOV-212](../gov/GOV-212.md)と突き合わせても本資料からは確定できない。③「不明門之橋」＝甲府御屋敷不明門の遺名という比定は弦巻川薬師門・御殿坂系の地誌叙述（[GAZ-112](GAZ-112.md)甲府綱豊条等）からの類推を含み、本資料単独では名称の由来を書いていないため「有力候補」に留め断定しない。④根津総説・甲府御下屋敷所引文言（承應記・延宝貞享絵図・元禄8武鑑）はOCRの崩れが大きく、原画像での再読取が必須。⑤「野中の井・柏木の井」の文面は不完全で、法住寺の野中の井（既存）との異同は未確定。
