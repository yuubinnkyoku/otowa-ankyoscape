# [MAP-180] 東京方眼圖（春陽堂・1909）— 町名索引の「乞食橋」文言候補＝赤坂区側の所在候補〔第158回〕

- **書誌〔確認〕**: 『東京方眼圖』（**春陽堂**・1909年〔明治42〕）。NDL次世代デジタルライブラリー [book/764199](https://lab.ndl.go.jp/dl/book/764199)。方眼図（市街図）と町名索引からなる市販図集。**本登録は町名索引のOCR断片レベルの所在記録で、図面本体の読図は未実施**。
- **町名索引の「乞食橋」文言候補〔確認・OCR・要原画像照合〕**: 町名索引に「**赤坂と六コジキバシ乞食橋**」と読める断片＝**「赤坂区（赤坂）六丁目 乞食橋」（または「赤坂」と六…（丁目の数字）の間に「コジキバシ（乞食橋）」が割り込む形）と解し得る、乞食橋の所在を赤坂区側の町に立てた索引文言候補**。〔**①乞食橋名の明治末の第3の所在候補**＝谷端川（巣鴨・[BOOK-186](../books/BOOK-186.md)の藤橋→富士橋改称史・[BOOK-109](../books/BOOK-109.md)の1922年改築）・神田（[GAZ-037](../gazetteers/GAZ-037.md)第158回追記の新革屋町の乞食橋）と対照する、江戸〜明治期の市中の「乞食橋」の同名異所の分布を広げる datapoint 候補。②赤坂の乞食橋は江戸期の薩摩藩下屋敷の「乞食橋」（赤坂の台地の谷の橋・[GAZ-039](../gazetteers/GAZ-039.md)第158回追記の巣鴨藤橋の「俗に乞食橋」とは別系統）に連なる可能性があるが、**本索引の「赤坂と六」の部分の原字（丁目数・区名の実字）はOCRの崩れがあり、所在の確定は原画像照合まで保留する**。③江戸地名字集覧（[GAZ-036](../gazetteers/GAZ-036.md)第158回追記）が日本橋本銀町（神田側）に乞食橋を立項したのと同様、**明治末の索引図レベルでも乞食橋が町名・地名として生き残っていた記録候補**。〕

## 制限・未解決

- ①「赤坂と六コジキバシ乞食橋」のOCR断片の原字（「と」の部分・丁目数・立項の対象が町名か地形名か）は原画像照合が必須で、本登録は文言候補にとどめる。②赤坂区側の乞食橋の実体（江戸期の薩摩藩下屋敷内の橋の地名残存か、別の橋か）は本書からは確定できない。③図面本体（方眼図）の水系描写（谷端川・水窪川・弦巻川側の図郭は含まれるか）の確認・読図は未実施（次回課題）。
