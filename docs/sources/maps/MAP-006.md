## 所蔵本の区別（2026-10-27、ai による注記）

- 本ファイルの読図は東京都立図書館 TOKYOアーカイブ所蔵本（上記 URL）によるもの。カモ下の池の有無についての読図は本ファイルには含まれない。
- 同版の別所蔵本として国際日本文化研究センター（日文研）所蔵本があり、カモ下文書の1857年行はそちらの鮮明な拡大による読図（緑色の「ハタ」とその東隣の白い細長い区画の「カモ下」。池は図上確認できないが、不在とは断定不可）を記録している：[国際日本文化研究センター所蔵本](https://lapis.nichibun.ac.jp/chizu/map_detail.php?id=002150662)。
- したがって「1857年改訂版のカモ下読図」と「MAP-006 の TOKYOアーカイブ本の河川読図」は所蔵本が異なるものとして区別すること。夜間調査 LOG の cycle 5 要約にある「MAP-006 は未検証（画像解像度低で判読不可）」の記述は、TOKYOアーカイブ本の低解像度画像ではカモ下付近の池の有無までは判読していない、という意味に読み替えること（MAP-006 自体の河川読図は 2026-10-26 に利用者が直接確認済み）。
