# [MAP-156] 江戸上水配水図（享保2〜3年頃・千川家文書）

- **書誌**: 練馬区立石神井公園ふるさと文化館・分室 所蔵品アーカイブ（[neribun id=10016](https://www.neribun.or.jp/archive/detail.cgi?id=10016)）。所蔵番号 **2000-1-0002-279**、名称「**江戸上水配水図（えどじょうすいはいすいず）**」、備考**千川家文書絵図**。2026-11-11目録直接確認。
- **〔確認〕** 目録解説: **享保2年（1717）頃から享保3年（1718）の作成**。**玉川上水・青山上水・三田上水・千川上水・神田上水が描かれた、江戸市中への配水状況がわかる絵図**。
- **意義〔観察〕**: ①**千川上水の給水範囲を江戸市中との関係で示す享保期（1717–18）絵図**として、repoの千川上水給水論（白山御殿・湯島聖堂・上野・浅草系）に**元禄開削（1696）から約20年の状態を描く時点資料**を与える。②**千川家文書の絵図群の一篇**であり、既収録の [MAP-155](MAP-155.md)（板橋宿付近千川用水堀絵図・同2000-1-0002-284）と**同一文書群・連続所蔵番号**。千川家文書にはこの他にも所蔵番号が連続する絵図群が存在する可能性があり、アーカイブ全体の目録調査が次の一手〔推定〕。
- **〔未確認〕** 画像本文（配水域の描かれ方・千川上水の表記・縮尺）。目録の「享保2年頃から享保3年」が作成年か推定年かの区別。千川家文書群の全目録（2000-1-0002-系の通し調査）。
