# [MAP-197] 下練馬村絵図（寛政4年〈1792〉作成（写し））

- **書誌〔確認: 所蔵品アーカイブ詳細頁・2026-11-19〕**: 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（[detail.cgi?id=10010](https://www.neribun.or.jp/archive/detail.cgi?id=10010)）、地図カテゴリ（index.cgi?c=2）収録。**番号3000-1-0002**、名称「**下練馬村絵図（しもねりまむらえず）**」、備考「-」（家文書等の注記なし）、内容等「**下練馬村の道や川掘・田、村境、家屋舗などの情報や村の様子が詳細に描かれている寛政４年〈1792〉作成（写し）の絵図**」。画像は同頁から直接閲覧可能（[img/3000-1-0002_01.jpg](https://www.neribun.or.jp/archive/img/3000-1-0002_01.jpg)）。
- **千川上水研究との関係〔観察〕**: 下練馬村は千川上水本流が貫流する村の一つ（現在の練馬駅周辺〜桜台・向山方面）。**「川掘」「田」が寛政4年時点の村の姿として詳細に描かれる絵図**であることが目録で確認でき、千川上水開削（元禄9年・1696）から約100年後の下練馬村側の水路・耕地の状態を図面レベルで検証する材料の候補。川掘が千川上水（用水堀）か村側の小川かは画像判読まで特定しない。
- **経緯〔確認〕**: 第195回（2026-11-19）の所蔵品アーカイブ全面走査（c=2地図カテゴリ12件）で、repo未登録の地図6件（本絵図・上石神井村絵図4点・土支田村下組絵図）を含む公開状況とともに確認・登録〔第18回で残していた「アーカイブ全体の目録調査」の実施〕。
- **制限〔未解決〕**: 画像判読（千川上水の表記・流路・田の配置）は未実施。番号接頭辞3000-1-の収集系列（どの家文書に由来するか）は目録上の備考欄が空欄のため特定できていない。「写し」の元本との関係も未確認。
