# [MAP-111] GHQ/SCAP文書『Maps on Tokyo Sewerage System』

- **資料所在・書誌〔確認：所蔵元に由来する公開目録・複製ファイルの説明〕**：国立国会図書館デジタルコレクション [PID 11903521](https://dl.ndl.go.jp/pid/11903521)。原所蔵機関は米国国立公文書館（NARA、RG331）、文書群は **GHQ/SCAP Records, Civil Affairs Section / Kanto Civil Affairs Region / Miscellaneous File, 1945-51**、**Box 2662, Folder 11**。資料の表題は **“Maps on Tokyo Sewerage System”**、目録上の文書期間は **1945年10月～1949年2月**。
- **公開画像〔確認：公開複製の書誌と構成〕**：[Wikimedia Commons「NDL11903521 Maps on Tokyo Sewerage System part1.pdf」](https://commons.wikimedia.org/wiki/File:NDL11903521_Maps_on_Tokyo_Sewerage_System_part1.pdf) は、NDL所蔵マイクロ資料に由来する複製の**第1分冊・100頁**と表示する（Commonsへの掲載は**2023年11月23日**）。**個々の図面の作成年・縮尺・図郭・凡例は未判読**。
- **内容確認の範囲〔未解決〕**：現時点で確認したのは**「東京の下水道地図」という表題と文書群の所在**までであり、100頁の地図面は直接判読していない。**水窪川・弦巻川・谷端川の旧河道や雑司ヶ谷幹線・谷端川幹線が実際に載るかも未確認**。1945～1949年は**文書群の期間**であって、収録図すべての測量年・施工年ではない。
- **次の確認対象〔調査課題〕**：全頁の図名・図郭・縮尺・作成年を整理し、旧弦巻川沿いの雑司ヶ谷幹線、旧谷端川沿いの下水道、音羽・江戸川橋周辺の排水経路を描く図の有無を調べる。1947年刊『大東京区分図 豊島区詳細図』（[MAP-048](MAP-048.md)）や1930年代の暗渠工事資料との照合候補とするが、**地図面の未確認段階では流路・施設・年代の根拠に使用しない**。
