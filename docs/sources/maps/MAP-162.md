# [MAP-162] 「中野村高円寺村馬橋村三ヶ村用水路図」（大谷家文書・杉並区指定有形文化財）〔repo初出〕

- **書誌〔確認: ADEAC杉並区デジタルアーカイブ目録・2026-11-14〕**: 「**中野村高円寺村馬橋村三ヶ村用水路図**」（資料番号**mus-004203**）。**大谷家文書（大谷晴雄・大谷文子家文書）・分類番号I-3-1**、形態**絵図・紙本・270mm×467mm・1舗**、所蔵機関**杉並区立郷土博物館**（杉並区大宮1-20-8）、キーワード「**天保新堀用水／天保用水／善福寺川**」、**杉並区指定有形文化財（古文書）昭和57年度指定**、CC BY 4.0、IIIFマニフェスト欄あり〔[目録ページ](https://adeac.jp/suginami-city/catalog/mus-004203)で直接確認。同館のADEAC資料としては[GOV-105](../gov/GOV-105.md)（矢嶋又次記憶画ほか）に続く所蔵〕。
- **公開解説〔確認: ADEAC目録の公開解説欄〕**: 「**明治時代に描かれた絵図**で、**天保12年（1841）に作られた2度目の開削ルート**が描かれている。この開削は現在の**西田端橋から東へ須賀神社のある弁天池へ直線**で流路が掘られた。なお**1度目の開削ルートは、西田端橋から善福寺川沿いに南へ迂回**して須賀神社のある弁天池へ流れている。」〔**二段階開削の両ルートの形を解説する行政目録**。善福寺川系の天保新堀用水（中野村・高円寺村・馬橋村の灌漑用水・[GOV-146](../gov/GOV-146.md)参照）の一次絵図〕。
- **大谷家文書の性格〔確認: ADEAC目録の解説〕**: 大谷家は江戸時代初期より**馬橋村**に定住し**代々名主役を勤める世襲名主**の家柄で、慶安元年（1648）から昭和中期に至る約300年間の地方文書を保有〔**馬橋村名主の文書群に由来する絵図**という一次性格。[GOV-146](../gov/GOV-146.md)（すぎなみ学倶楽部）の説明する開削請負人＝**馬橋村名主大谷助次郎**との対応が文書群の出自として注目される〕。
- **repoでの位置づけ〔観察〕**: 天保新堀用水は**善福寺川系の用水で、水窪川・弦巻川・谷端川の直接の構成要素ではない**。ただし①**千川上水の分流（[GOV-105](../gov/GOV-105.md)の矢嶋又次記憶画「天沼弁天池」・[GOV-146](../gov/GOV-146.md)の「天沼弁天池の湧水と千川上水からの分水を合わせた桃園川の流水」）と並んで、桃園川流域（阿佐ヶ谷・中野方面）の灌漑水系を構成した隣接用水**であり、②同じ杉並区立郷土博物館の千川関係資料（GOV-105・GOV-109）と**同一機関・同一アーカイブの絵図類**として、千川上水の灌漑範囲・武蔵野台地尾根筋の水利の比較文脈に資する。**地元世襲名主が明治に模写した用水絵図が区指定文化財として公開されている**例として記録価値が高い。
- **ADEAC解説とすぎなみ学倶楽部の照合〔未整理〕**: 第一次ルートの形について、本目録解説は「善福寺川沿いに迂回」、[GOV-146](../gov/GOV-146.md)は「権現堰から掛樋で弁天池へ」と述べ、**両解説の枠組みが完全には揃わない**〔権現堰・広場堰・西田端橋の位置関係の照合とIIIF画像の判読が次回課題。ここでは併記に留める〕。
