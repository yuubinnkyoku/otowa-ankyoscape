# [MAP-123] 『火災保険特殊地図』小石川区・下（原図1936～1937年頃、1987年複製）

- **書誌・所蔵〔確認：都立図書館の公立図書館住宅地図総合目録〕**：『小石川区；下』、原図年代の目録表示 **1936～1937年**、都市整図社 **[1987年]複製**、『火災保険特殊地図旧35区』**No.17-2**。都立中央図書館資料ID **1123363719**。[所蔵目録](https://www.library.metro.tokyo.lg.jp/lib_info_tokyo/house_map_union_catalog/bunkyo/)（目録集計は**2024年7月末現在**）。文京区立真砂中央図書館にも所蔵。
- **資料の性格〔確認：NDL地図室解説〕**：[「火災保険図」](https://ndlsearch.ndl.go.jp/rnavi/maps/post_601014)（2026年8月24日更新）は、昭和前期の火災保険図を概ね**1:600～1:1,200**の大縮尺で、地番・建物などの調査に使う資料と説明する。ただし記載内容は図葉・系列ごとに異なる。
- **確認範囲〔所在のみ〕**：図書館の目録と系列解説を確認。**この巻の個別図葉・図郭・調査／修正年・河道・橋・暗渠・建物・塀の描線は未閲覧**。1936～1937年は原図年代の目録表示、1987年は複製年であり、河川改修・暗渠の工事年ではない。

年代（地図一覧の表記）: 1936～1937年頃（原図の目録表示、1987年複製）

読図メモ: 都立図書館の住宅地図総合目録で小石川区・下の1987年複製を確認（資料ID 1123363719）。原図の図葉・道路・河道・建物・塀は未閲覧。複製年は工事年ではない。
