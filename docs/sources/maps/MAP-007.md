# [MAP-007] 五千分一東京図測量原図と2026年10月8日の読図

- 参謀本部陸軍部測量局による五千分一東京図測量原図（1883–1884年）、地理院地図「文明開化期 東京主要部」表示、現在の色別標高図。
- [国土地理院・五千分一東京図測量原図索引](https://service.gsi.go.jp/kochizu/app/map/tokyo-sokuryozu) / [NDLサーチ：復刻版書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000008127561)
- 2026年10月8日、利用者が西側谷頭の上流端候補（**35.71478732582174, 139.7354095056653**）を地図上で記録し、筑波大学附属中・高南方の浅い枝谷候補を色別標高図で観察。**利用者による画像観察であり、原図の水路記号の直接確定や旧水源の位置確定ではない。** 詳細：[人参川](../../人参川.md)。

読図記録（2026-10-26、利用者が東京時層地図で確認した判定）: 水窪川・弦巻川・谷端川・人参川候補のいずれも描かれている。音羽谷下流・江戸川橋付近で、北からの水路と東西の水路が交わる箇所に破線区間があり、伏樋の表現とみられる（利用者の判定では確度はかなり高い）。下の読図メモにある二次読図由来の伏樋の留保は、この直接確認をもって解消する。

読図メモ: 音羽谷下流で水窪川・弦巻川が神田上水を伏樋で下越ししたとする二次読図あり。原図の凡例・線形を直接再確認するまでは△。**人参川候補**：2026年10月8日の地理院地図「文明開化期」表示で西側谷頭・線状表現を目視確認。上流端候補 35.71478732582174, 139.7354095056653。線種未判読のため△。[観察詳細](../../人参川.md)・[2026-10-09現地メモ](../../2026-10-09・茗荷谷・人参川現地観察.md) ／拓殖大東門付近に島状の部分がある池と南側の別池状表現。池は人参川本流の確定証拠とはしない。**音羽二丁目・水窪川西側（35.717529, 139.728814）にも池状の表現**があるとの利用者の読図を記録。詳細は[音羽二丁目遺跡と旧流路仮説](../../音羽二丁目遺跡と水窪川沿いの旧流路仮説.md)。池・水路・旧河道の判定は未確定。 図葉名の例：『五千分一東京図測量原図 : 東京府武蔵国小石川区小日向水道町近傍』。複製版『五千分一東京図測量原図 複製版（36面）』がある。図葉名の別例:「五千分一東京図測量原図 : 東京府武蔵国北豊嶋郡高田村近傍」。[日文研・小日向水道町近傍](https://lapis.nichibun.ac.jp/chizu/map_detail.php?id=002275675-0026)／[日文研・北豊嶋郡高田村近傍](https://lapis.nichibun.ac.jp/chizu/map_detail.php?id=002275675-0028)（内容年代明治16・1883。弦巻川流域。公開画像は低解像度約370pxで、中央左に蛇行水路が見えるが同定未確定）／[日文研・小石川区小石川表町近傍](https://lapis.nichibun.ac.jp/chizu/map_detail.php?id=002275675-0015)（同・1883。谷端川下流〜小石川）

## 2026年11月10日：高解像度アクセス経路の調査

- **GSI古地図「文明開化期 東京主要部」〔確認：ビューアJS/索引GeoJSON〕**：[tokyo-sokuryozu](https://service.gsi.go.jp/kochizu/app/map/tokyo-sokuryozu) は**37葉の索引GeoJSON**（`ids` 1431–1468／`name` 1001–1038）を淡色背景図に重ねる構成で、**索引は図郭ポリゴンとスタイルのみでRaster画像URLを含まない**。**茗荷谷谷頭（139.735, 35.715）を含む葉は id 1455／name 1025**（図郭 lon 139.73028–139.74413／lat 35.70646–35.71760）。高解像度Rasterの取得経路は本索引からは直ちに得られない。
- **日文研〔確認：既記録〕**：公開画像は低解像度（約370px）で、池・細水路の判読に限界。
- **彩色複製〔確認：NDLサーチ〕**：『明治前期測量中央官衙街2000分1彩色地図：五千分一東京図測量原図の拡大複製』は**中央官衙街のみ**を対象とし、茗荷谷・小日向を含まない。
- **結論〔留保〕**：茗荷谷の池（拓殖大東門・島状池＋南側別池）の**高解像度カラー原図判読はオンラインでは容易でない**。池の観察は利用者／二次（[BLOG-007](../blogs/BLOG-007.md)）のまま残し、**葉 id 1455／name 1025** を将来の高解像度・館内照合のポインタとする。〔未解決〕
