## repo内位置づけ〔観察・判読未実施・いずれも断定しない〕

1. **「川崎平右衛門伊奈半左衛門謝恩塔」＝repo初出の顕彰石塔文言〔repo grep確認: 「謝恩塔」0件〕**: 川崎平右衛門（定孝・1694〜1767）＝**千川上水開削請負人**（[GOV-341](../gov/GOV-341.md)元文2年桜植樹請負と同一人物としてrepoに記録済み・[BOOK-234](../books/BOOK-234.md)新田方川崎平右衛門）で、伊奈家＝**関東郡代**（repoの千川上水史料群の常連・印旛沼絵図〔MAP収録候補〕とも史料系統が重なる）。両者の顕彰石塔の所在を「北多摩郡小平村榎戸新田」と伝える〔確認: 「内容」欄の転記〕。
2. **石塔の同定対照資料〔確認: 公開Web資料・同一性は画像判読・現地確認まで断定しない〕**: 国分寺市の**妙法寺「川崎・伊奈両代官謝恩塔」＝宝篋印塔・国分寺市指定重要有形文化財**＝「幕府の新田農民援助策を立案した川崎平右衛門と、それを継続した伊奈半左衛門に感謝して、南北武蔵野新田80余の村々が、**寛政11年（1799）に建てた宝篋印塔**。建立の経緯は「武蔵野新田養料金一件始末書」に記載」（[国分寺市観光シティプロモーションサイト](https://kokubunji-citypro.jp/article/926/)）＝武蔵野新田の夫食貸付などの援助策への謝恩建立。同一石塔かどうかは絵葉書画像の判読と「小平村榎戸新田」という所在表記の帰属変遷（榎戸新田の菩提寺が妙法寺〔現在の国分寺市北町〕とする民間研究記録: [多摩めぐりブログ](https://tama-meguri.com/blog/2021/07/15/15/9125/)・関東大震災で倒壊し昭和26年再建の記載あり）の照合を要する〔要確認〕。川崎平右衛門にはこのほか国立市観音寺の供養塔（寛政7年〔1795〕・[国分寺市公式の解説](https://www.city.kokubunji.tokyo.jp/shisetsu/kouen/1005196/1004226.html)）もあり、絵葉書の石塔がいずれかの判別は画像判読待ち。いずれにせよ、**武蔵野新田開発×千川上水開削体制の中心人物2名の謝恩石造物の現存を伝える記録としてrepo初出の価値が高い**。
3. **「小泉次太夫四カ領用水掘割普請之図」＝四ヶ領用水の図面複製〔確認: 「内容」欄の転記・以下は公開Web資料による同定〕**: 「四ヶ領用水」＝**多摩川両岸の二ヶ領用水（稲毛領・川崎領）＋六郷用水の総称**で、用水奉行・小泉次大夫（吉次・天文8〔1539〕生〜代官・用水奉行）が**慶長16〔1611〕に完成**させた用水網（[Wikipedia「小泉次大夫」](https://ja.wikipedia.org/wiki/%E5%B0%8F%E6%B3%89%E6%AC%A1%E5%A4%A7%E5%A4%AB)・[Wikipedia「二ヶ領用水」](https://ja.wikipedia.org/wiki/%E4%BA%8C%E3%83%B6%E9%A0%98%E7%94%A8%E6%B0%B4)）＝**千川上水・四河川とは水系が別の多摩川水系用水**。川崎市側には「小泉次大夫の四ヶ領用水堀割巡検図（**明治17年〔1884〕作画**）」の現存系統が紹介されており（[新小杉開発株式会社のページ](https://www.shinkosugi.jp/kosugihistory/dataroom/data01_03_001.html)）、本絵葉書が複製する「掘割普請之図」の原図面・作成年の同定は画像判読待ち〔要確認〕。
4. **[GAZ-057](../gazetteers/GAZ-057.md)「次太夫堀」との呼称の並行〔観察・断定しない〕**: 風土記稿の「六〓用水＝古名次太夫堀・御代官小泉次太夫に由来・多摩・荏原両郡13村」文言と、多摩川水系の「四ヶ領用水＝次大夫堀」の呼称が**同名由来の呼称として並行**する。GAZ-057の「御入國ノ後」（家康関東入国後）の年代枠と初代小泉次大夫（吉次）の活躍期は重なるが、両用水（仙川用水系・多摩川両岸系）と両呼称の関係・人物の同一性は本文照合まで断定しない。本絵葉書収録により、この②系の「次大夫堀」図面の現存記録がrepoに入る。
5. **西多摩郡五日市町小和田広徳寺文書・平井郷伝馬定書**: 同袋の他の内容〔確認: 「内容」欄の転記〕。西多摩（あきるの市域）で四河川の水系からは外れる。記録のみとする。
