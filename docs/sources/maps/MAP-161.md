- **書誌〔確認: ADEAC目録〕**: **「千川上水探訪マップ　1996」、著編者: 豊島区教育委員会、発行年度: 平成08（1996）年、所蔵: 秋田県公文書館（行政資料、資料番号96-563）**。[ADEAC目録ページ（秋田県／図書館・公文書館・文学資料館デジタルアーカイブ・目録ID 20-ref-C-109229）](https://adeac.jp/akita/catalog/20-ref-C-109229)〔ADEAC横断検索「千川上水」で発見・2026-11-14直接確認〕。目録に数量・寸法・内容細目の記載はなく、画像公開はない〔確認: 目録の空欄〕。
- **位置づけ〔観察〕**: **1996年に豊島区教育委員会が作成した千川上水の「探訪マップ」の存在**を示す書誌。1993年の千川上水路図複製（[BOOK-014](../books/BOOK-014.md)・[MAP-060](MAP-060.md)）と1998年の「やばた川」発売（[GOV-127](../gov/GOV-127.md)）の間にあたる1990年代半ばの、区教委による千川上水の広報・啓発活動の産物とみられる〔推定。本文未見のため内容・形式（散策図・解説図か）は要確認〕。**所蔵が秋田県公文書館である点**は、都県外機関の収集経緯（寄贈・廃棄引き取り等）が不明で、本repoでの場所特定の手掛かりとして記録する〔[GOV-121](../gov/GOV-121.md)（農林水産系機関の千川用水六ヶ村文書）と同じく、千川関係資料の遠隔所蔵の一事例〕。
