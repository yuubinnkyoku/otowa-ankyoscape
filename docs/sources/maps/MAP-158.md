# [MAP-158] 浜田義一郎編『地図帳 江戸切絵図 2 近吾堂版』

- **書誌・所在〔確認：東京都立図書館の古地図目録PDF〕**：浜田義一郎編、**東京堂出版、1975年**。東京都立中央図書館蔵、請求記号 **DT0・290/12/12/2**。近江屋（近吾堂＝近江屋吾平）板の江戸切絵図を集成した復刻・コンピレーション。目録PDF（『古地図・絵図（明治期以前刊行図の複製）』2020年・2006年改訂版）で収録図一覧を直接確認。
  - 出典：[4kochizu.pdf](https://www.library.metro.tokyo.lg.jp/search/uploads/4kochizu.pdf) ／ [re_chizumokuroku202006_4_kochizu.pdf](https://www.library.metro.tokyo.lg.jp/search/uploads/re_chizumokuroku202006_4_kochizu.pdf)
- **収録図（本repo関系）**：内容細目に「**上水北小日向小石川辺絵図（嘉永5）**」「**小石川辺図（嘉永5）**」「谷中本郷駒込小石川辺絵図（嘉永3）」「**音羽目白雑司ヶ谷辺絵図（嘉永4）**」「**白山駒込辺之絵図（嘉永5）**」「**駒込巣鴨辺之絵図（嘉永5）**」「巣鴨染井王子辺図（嘉永5）」「大久保戸山高田辺之図（嘉永4）」等を確認。〔確認：目録PDFの内容細目記載〕
- **repo初出の図名**：**「白山駒込辺之絵図（嘉永5）」「駒込巣鴨辺之絵図（嘉永5）」「上水北小日向小石川辺絵図（嘉永5）」「小石川辺図（嘉永5）」「巣鴨染井王子辺図（嘉永5）」**。白山駒込・駒込巣鴨の2図は谷端川下流（小石川大下水・西大下水域）〜中流（巣鴨村地内）を描く切絵図として、既収録の尾張屋系小石川絵図（[MAP-022](MAP-022.md)）・近江屋単図（[MAP-019](MAP-019.md)・[MAP-005](MAP-005.md)）と別系統・別図の読図比較候補。上水北小日向小石川辺絵図はBLOG-133（夢七雑録part3）が挙げた図誌群のひとつで、所在が初めて具体化した。
- **別所蔵〔確認：各機関の目録・ページタイトル〕**：
  - **文京区立図書館デジタルアーカイブ**：[「上水北小日向小石川辺図 嘉永5年」](https://www.lib.city.bunkyo.tokyo.jp/dl/index_874.html)・[「小石川辺図 嘉永5年」](https://www.lib.city.bunkyo.tokyo.jp/dl/index_873.html)として公開頁を確認（2026-11-12時点。ページは検索結果のタイトルで所在確認、本文取得は遮断）。
  - **姫路文学館**：[館蔵目録PDF](https://www.himejibungakukan.jp/wordpress/wp-content/uploads/2016/02/kanaibunkomokuroku.pdf)に「上水北小日向小石川辺図 1舗 村上吾嶂誌、玉香園为人画 嘉永5年版 近吾堂」の蔵書誌を確認。版元・画者名の特定情報。
- **注意**：収録図はいずれも**図面本文・画像は未閲覧**。図名の同一性（表記ゆれ含む）は目録記載レベルの一致で、白山駒込・駒込巣鴨両図の谷端川描線の有無は未確認。近江屋板の版次（嘉永4〜7年の改版関係）は要照合。
- **次の一手**：本コンピレーションの実物（都立中央図書館）または文京区デジタルアーカイブの画像で「白山駒込辺之絵図」「駒込巣鴨辺之絵図」の水路描写を読図する。
