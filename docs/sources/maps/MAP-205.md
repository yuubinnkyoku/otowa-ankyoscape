# [MAP-205] 「神田上水絵図」（東京都立図書館・東京誌料）〔repo初出・第233回〕

- **書誌〔確認: TOKYOアーカイブ詳細頁・2026-11-21〕**: 「**神田上水絵図**」（名称表記のまま・年代欄なし）。**折本・15.4×290.6cm**（展開時の長尺折本）。**東京誌料**文庫・請求記号**760-21/東760-021**・資料コード**4300346361**。TOKYOアーカイブ [detail?tilcod=0000000015-00054522](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000015-00054522)。**画像の使用条件＝パブリックドメイン**。画像は**全10コマ**が同アーカイブでインターネット公開されている（画像リストAPIで確認・第233回）。フル解像度JPEGの取得可。
- **資料解説文言〔確認: アーカイブ詳細頁の「資料解説」欄〔出典表示: 文化財ウィーク2012（49）・大規模企画展2011(21)〕〕**: 「**水源地の井ノ頭池から多摩郡、豊島(としま)郡の武蔵野の村々を通って関口の大洗堰にいたるまで、途中の村々や橋、他の川からの取水口、分水口など、上水の経路が詳細に描かれています。井ノ頭池から関口を経由して御茶ノ水までは地表に開かれた水路（開渠）で、神田川を掛(かけ)樋(とい)で渡ってからは地中に埋設された水路（暗渠）で、江戸城内に流れていました。開削年代は、はっきりわかっていません。**」〔都立図書館展示解説（図録由来）の文言として記録。展示解説レベルであり一次文言ではない〕。
- **内容の位置づけ〔観察・読図未実施〕**: 「**井ノ頭池→武蔵野の村々→関口大洗堰までの上水経路に、村々や橋・他の川からの取水口・分水口を記入**」という40文字級の一方形状と、**「15.4×290.6cmの折本」**という体裁から、[MAP-192](MAP-192.md)（「神田上水大絵図 : 貞享ノ頃」・NDL 819-133・3舗・水上/水下分冊想定）や[MAP-193](MAP-193.md)（玉川上水大絵図）と同種の**神田上水全線・用地图（導水路図）**の可能性が高い〔折本の体裁・解説の詳細度からの推定で、図面確認までは断定しない〕。「**他の川からの取水口**」の記入が実在すれば、[GAZ-068](../gazetteers/GAZ-068.md)（1881・十二所社の下で玉川上水の支流を合せ）・[GOV-302](../gov/GOV-302.md)（明治10・仙川用水が上落合村で神田上水に合す）系の**支流合流・分水地点の図上確認資料**になりうる。
- **「開削年代は、はっきりわかっていません」の文言〔観察・展示解説レベル〕**: 都立図書館の展示解説が**神田上水の開削年代を「はっきりわかっていない」と明記**している。repoの神田川堀割年代論（承応2年〔GAZ-049〕・万治〔GAZ-083/GAZ-027〕・寛永13年文言候補〔GAZ-039〕・秀忠期開削説〔浮世絵解説群〕）に対して、**所蔵館側が2021年代(第1回江戸資料展・2011)以後も開削年代を確定しない立場であることの datapoint**〔外題・解説の文言候補であり年代論の材料にはできるが、それ以上の重み付けはしない〕。
- **導水形状文言（開渠→掛樋→暗渠）の系列〔観察〕**: 解説文言「**井ノ頭池から関口を経由して御茶ノ水までは開渠。神田川を掛樋で渡ってからは暗渠で江戸城内**」＝[GAZ-048](../gazetteers/GAZ-048.md)（風土記稿・水戸殿舘地→埋樋→御茶水の萬年樋）・[GAZ-068](../gazetteers/GAZ-068.md)（小石川砲兵本廠の伏管→水道橋の萬年樋）・[BOOK-147](../books/BOOK-147.md)（小日向小石川台下の白堀→明治10年巻石蓋→懸樋）と**同一の導水形状記述の図版側候補**。図面本体でこの形状（関口までの開渠・後楽園前後の伏せ・水道橋の掛樋）が確認できれば、江戸期の導水形態の図上定点になる〔読図未実施・断定しない〕。
