# [MAP-209] 樋線図第2種『水道橋から神田橋 絵図（神上）』（K0084）

## 書誌〔確認: ro-da API目録・2026-11-24〕

- **タイトル**: 「水道橋から神田橋 絵図（神上）」（樋線図第2種10点のうちの1点・第7図）
- **作成**: **東京府水道掛か**・**明治前期**〔目録説明: 大小区の表記があることから**明治4〜11年（1871〜78）の制作と考えられる**〕・7.5×54cm（表紙18×7.5）・和紙・墨書・朱書・手彩・**題箋欠損**
- **説明〔ro-da目録の内容説明〕**: 江戸切絵図の体裁にならって上水の通じている範囲を区域に分けて樋線（送水経路）を描く。**本図には神田上水の小石川から西神田・駿河台下地域、現在の文京区後楽、千代田区西神田・神田神保町・神田小川町周辺の樋線が描かれている**。
