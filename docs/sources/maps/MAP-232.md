## repo内位置づけ〔観察・読図・異同のいずれも未実施・断定しない〕

1. **谷端川中流の尾張屋板として[MAP-023](MAP-023.md)と対になる可能性〔仮説〕**: [MAP-023](MAP-023.md)『巣鴨邊絵図』（1854・二次転記・原図未確認）は「宮原橋付近の池を伴う屋敷地や、池田甲斐守屋敷地との対応が二次踏査・二次研究で言及される」図で、『巣鴨絵図』とも表記される。本図の**原題簽が「巢鴨繪圖　全」・刊年が嘉永7[1854]と一致する**ため、同一図（同一板木）の可能性がある候補。**表記の一致だけでは同一図と断定できず**、寸法（45.0×49.8cm／47.7×52.4cmの2群がある）、版元系統（尾張屋＝本図／MAP-023の版元は未記録）の照合が必要〔要確認〕。一致する場合は**MAP-023の原図アクセスが初めて可能になる**（原図の直接読図・宮原橋付近池描線の確認）。
2. **谷端川中流域の読図候補**: 図域は文京区本駒込〜豊島区巣鴨〜北区滝野川〜板橋区板橋〔確認: 資料解説の転記〕＝**谷端川中流（巣鴨村地内）と千川上水の末端方面（滝野川）を含む**。[MAP-030](MAP-030.md)（1911巣鴨町巣鴨村全圖）・[MAP-133](MAP-133.md)系の近代図と比べれば江戸末の谷筋・屋敷地の残存形が読める候補。水路描線の有無は未確認〔読図未実施〕。
3. **「此辺染井村植木屋多シ」＝染井の植木屋文言〔確認: 資料解説の転記〕**: 染井村の植木屋・ソメイヨシノの品種成立文言は、巣鴨・染井の花見文化の背景記録として、双六2点（巣鴨染井殿中江戸の花独案内・白山巣鴨造りきく独案内〔第340回ノート記録〕）とも位置づけが重なる。**図上の谷端川と植木屋地名帯の位置関係の確認が読図第一歩**〔未実施〕。
