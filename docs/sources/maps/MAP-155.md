# [MAP-155] 板橋宿付近千川用水堀絵図

- **所在のみ（2026-11-11、所蔵品アーカイブの目録ページを直接確認。絵図画像の判読は未実施）**：所蔵番号**2000-1-0002-284**、名称「**板橋宿付近千川用水堀絵図**（いたばししゅくふきんせんかわようすいぼりえず）」、備考「**千川家文書絵図**」、内容等「**中山道の板橋宿付近を流れる千川上水を描いた絵図。江戸時代の作成**」（公益財団法人練馬区文化振興協会・練馬区立石神井公園ふるさと文化館／分室の所蔵品アーカイブ）。
- **[GOV-038](../gov/GOV-038.md)・[GOV-068](../gov/GOV-068.md)の「千川家文書」「千川用水堀絵図」言及の具体化**：千川家文書（練馬区指定文化財）の絵図群の一案であること、**板橋宿付近＝千川上水の流末（板橋区側）を描く絵図**であることが目録で確認できた。〔千川上水の板橋宿周辺の流路・堀割の描出史料。板橋宿は千川上水の分水・流下先として豊島区板橋・下板橋周辺の川と用水の関係を補強する可能性〕
- **同アーカイブの関連目録〔確認〕**：「**千川分水口取調絵図**」（[id=10017](https://www.neribun.or.jp/archive/detail.cgi?id=10017)、所蔵番号2000-1-0002-133、備考「千川家文書絵図」、**元治元年（1864）作成・明治初期に修正・加筆**、上保谷新田（西東京市）〜巣鴨村（豊島区）の素掘区間を描く）の目録も確認。〔[MAP-119](MAP-119.md)（所在のみ）の所在先に一致。**MAP-119の格上げ・詳細化の候補**〕
- **制限〔未解決〕：**本絵図の作成年代の特定・画像判読・[GOV-068](../gov/GOV-068.md)の言及する「千川用水堀絵図」・[GOV-061](../gov/GOV-061.md)（都公文書館「千川元上水堀通見分絵図」）との異同は未確認。
