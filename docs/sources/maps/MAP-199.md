# [MAP-199] 上石神井村絵図（慶應4年〈1868〉・栗原家文書絵図）

- **書誌〔確認: 所蔵品アーカイブ詳細頁・2026-11-19〕**: 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（[detail.cgi?id=10012](https://www.neribun.or.jp/archive/detail.cgi?id=10012)）、地図カテゴリ収録。**番号2000-1-0001-6-2**、名称「**上石神井村絵図（かみしゃくじいむらえず）**」、備考「**栗原家文書絵図**」、内容等「**上石神井村の田、畑、道、川筋の様子が描かれている慶應４年(1868)作成の絵図**」。画像は同頁から直接閲覧可能（[img/2000-1-0001-6-2_01.jpg](https://www.neribun.or.jp/archive/img/2000-1-0001-6-2_01.jpg)）。
- **千川上水研究との関係〔観察〕**: [MAP-198](MAP-198.md)（文久元年・1861）と同じ村を**7年後の慶應4年（1868）に「田、畑、道、川筋」を描いた絵図**であることが目録で確認できた。明治維新の年にあたる時点の「川筋」の描かれ方（千川上水の流路・分水）が画像で確認できれば、千川上水の幕末〜明治初期の村側状態（[MAP-119](MAP-119.md)千川分水口取調絵図の元治元年1864・明治初期加筆と同時期）を複数資料で対照できる。
- **制限〔未解決〕**: 画像判読は未実施。「川筋」が千川上水かを含め、図の内容は目録文言依存。
