- **内容メモ（どこに何が写るか）〔観察：標準版画像の判読〕**：
  - **中央（南長崎の谷筋）**：**格子状の農地が卓越**し、住宅はまばら。目白通りが東西に横断し、西武池袋線が北東〜南西に斜走する。谷端川の谷筋にあたるが、**連続する河道の描線は確認できない**。
  - **上部（東長崎・千早町方面）**：農地と樹林状の暗調パッチ。東長崎駅の位置は現行の鉄道位置とおおむね整合する。
  - **中央〜右（椎名町西部）**：矩形の明るい屋根を持つ大規模建物が点在（施設名は未同定）。
  - **下部（下落合・中落合北部）**：蛇行する明るい帯（神田川の谷筋とみられる）と鉄道状の線形。
- **判読の限界〔留保〕**：谷端川の河道そのものは確認できない。1936年写真（[MAP-131](MAP-131.md)・[MAP-132](MAP-132.md)）と同様に農地の区画線と水路の区別がつかない。四隅座標からの幾何補正は大まかな対応（誤差約100〜300m）。
