# [MAP-005] 1851年『音羽目白雑司ケ谷辺絵図』

- 村上吾雄誌、近吾堂（近江屋吾平）板『音羽目白雑司ケ谷辺絵図』嘉永4年（1851）。
- 東京都立図書館 TOKYOアーカイブ: https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000013-00042337
- CiNii Books: https://ci.nii.ac.jp/ncid/BA59680420
- 護国寺南西端の青い水路が寺域外へ続くという記述は、**本調査による画像観察**。
- **別題・別蔵本（候補）〔確認: TOKYOアーカイブ詳細頁・2026-11-21第233回追記〕**: 同アーカイブに「**雜司ヶ谷音羽辺図**」（村上吾雄誌・近吾堂〔近江屋吾平〕・**嘉永4[1851]**・43.2×60.3cm・木版色刷・切絵図・**加賀文庫**・請求記号**加346/加00346**・資料コード**4300040880**・[detail?tilcod=0000000013-00042705](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000013-00042705)・画像の使用条件＝パブリックドメイン）のレコードがある。**編者・板元・刊年・寸法が本図（東京誌料本）と完全に一致し、題名の語順違い（音羽目白雑司ケ谷 ↔ 雑司ヶ谷音羽）のみの別題レコード**で、同一板木の別蔵本（別外題での目録化）と読める〔書誌一致のみによる同一図候補で、画像照合・版次照合は未実施のため断定しない〕。既知の別所在（台東区立図書館「音羽目白雑司ヶ谷辺絵図」嘉永4冬新刻・岡山大学附属図書館池田家文書「雑司ヶ谷音羽辺図」〔README第86回〕）と合わせ、**近吾堂板雑司ヶ谷音羽系切絵図の別所在が3か所＋都立2文庫（東京誌料・加賀）**となった。読図（水路描写の異同）は未実施。
