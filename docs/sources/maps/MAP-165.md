- **対象範囲〔観察: 題簽と既知の地理による〕**: 高田馬場から雑司ヶ谷まで＝**弦巻川（渋谷川上流）の主流域**。高田の谷（現目白通り〜弦巻通り方向の谷筋）と雑師ヶ谷村・雑司ヶ谷墓地周辺を含む。
- **意義〔観察〕**: ①**弦巻川の主流域（高田馬場〜雑司ヶ谷）を、正徳6（1716）『武蔵国豊島郡下高田村絵図』（[MAP-012](MAP-012.md)）と嘉永4『音羽目白雑司ケ谷辺絵図』（[MAP-005](MAP-005.md)）・嘉永新鐫尾張屋板（[MAP-164](MAP-164.md)・1851〜57年系）の中間の時期（目録の成立推定＝近世中期写）に描く絵図の所在を固定した**〔18世紀中頃の弦巻川流路・高田の溜池群・雑司ヶ谷の谷地形の図上確認の最有力候補〕。②岩瀬文庫は金子直徳『若葉の梢』粗稿『雑司谷辺里の諺』（[BOOK-094](../books/BOOK-094.md)）を所蔵する文庫で、雑司ヶ谷・高田関係史料がまとまって残る所蔵機関である〔同一文庫内の地図と文献の対照の可能性〕。
- **39舗のうち登録見送りの隣接舗〔確認: NDL横断検索・ADEAC目録〕**: 千駄ヶ谷・四谷系の「牛込神楽坂より市谷加賀屋鋪本村四谷北之方まて絵図」（R100000094-I218069）「内藤宿千駄ヶ谷辺迄絵図」（R100000094-I218088）「青山百人町より下渋谷辺千駄ヶ谷迄絵図」（R100000094-I218070）の3舗は、主対象3河川（水窪川・弦巻川・谷端川）の直接流域から外れるため今回の個別登録を見送った〔全39舗の書誌はNDL横断検索「江戸区分図」で取得できる〕。
