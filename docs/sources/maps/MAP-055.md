## 第157回追記（2026-11-17）: 寛文分間圖の分割刊記の文言候補

- 栗田元次『日本古版地圖集成』（1932・[MAP-178](MAP-178.md)）解説の寛文分間圖条＝「**北條安房守正房(初氏房)は明曆三年正月二十七日幕府の命を受け…福嶋傳兵衞國隆の助成もあつた。この製圖の板行となつたのが、この圖で、江戶の實測圖の權輆である。この圖は五枚から成つて居り、順次に刊行せられたもので、江戶城の外廓の分は、「江戶大繪圖本」(寛文十年十二月)、その他は江戶外繪圖で、その下に、「東は淺草」北は染井」西は小石川」(同十一年霜月)、「小日向」牛込」四谷」(同十二年閏六月)、「赤坂」麻布」芝筋」(同十三年二月)と記入されて居た**」〔OCR・文言候補・要原文照合〕＝**寛文分間圖（5枚）が明暦3年（1657）正月の幕府命を起点とし、寛文10年12月（江戸城外廓の江戸大繪圖本）→寛文11年霜月（東は淺草・北は染井・西は小石川）→寛文12年閏6月（小日向・牛込・四谷）→寛文13年2月（赤坂・麻布・芝筋）と順次刊行された**旨の分割刊記の文言候補。「江戸実測図の権輿」という評価。刊記「**間積り壹分にて五間のつもりに仕候但し六尺五寸之間也**」＝縮尺文言候補。
- 〔対校上の注意〕本書の目次には「**遠近道印 寛文十一年刊**」（図版43-44）の記載があり、**北條正房製図の5枚体系と目次の遠近道印図との対応（同一図か別図か）はOCRからは確定できない**。MAP-055の「遠近道印系」の系統仮定と北條正房説の両立・優先は原画像確認まで保留する。**「北は染井」「西は小石川」の外廓基準の文言は、[BOOK-002](../books/BOOK-002.md)の言及する「寛文十年の古圖」の候補資料の方位文言として対照価値がある**。
