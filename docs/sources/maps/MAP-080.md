# [MAP-080] 『一橋家小石川屋敷分水絵図』

年代・所在（地図一覧の表記）: 寛政元〜2年（1789〜1790年）の千川上水引水計画図。『千川上水関係史料集 1』所収図を参照した二次転記

状態・言及箇所: 滝野川村境付近の流末側に「巣鴨村田用水」と記され、既存用水落口への水門設置の注記が読まれるとされる。原図は未照合
