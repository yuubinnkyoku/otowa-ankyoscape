# [MAP-202] 土支田村下組絵図（天保4年〈1833〉・小島家文書絵図）

- **書誌〔確認: 所蔵品アーカイブ詳細頁・2026-11-19〕**: 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（[detail.cgi?id=10015](https://www.neribun.or.jp/archive/detail.cgi?id=10015)）、地図カテゴリ収録。**番号2000-1-0005-A1**、名称「**土支田村下組絵図（どしだむらしもぐみえず）**」、備考「**小島家文書絵図**」、内容等「**土支田村下組の荒地、取下ゲ地、木免地、用水、道の様子が描かれている天保４年(1833)作成の絵図**」。画像は同頁から直接閲覧可能（[img/2000-1-0005-A1_01.jpg](https://www.neribun.or.jp/archive/img/2000-1-0005-A1_01.jpg)）。
- **文書の由来〔確認〕**: 同アーカイブの文書カテゴリ総括レコード（[detail.cgi?id=10001](https://www.neribun.or.jp/archive/detail.cgi?id=10001)・小島家文書・約1,500点）によれば、小島家は「**江戸時代の土支田村下組名主**」を勤めた家〔本絵図はその絵図群の1点〕。
- **repo対象河川研究との関係〔観察〕**: 土支田村（現在の練馬区土支田・高松・東大泉周辺）は、千川上水流域の北側台地の村で、repoでは石神井川水系（田柄川上流側）・千川上水分水（土支田分水の可能性）の文脈で関連する区域。「**荒地、取下ゲ地、木免地**」という開拓余地の地割・免地の表現を含む天保4年の村絵図は、武蔵野新田開発と用水の関係（[GOV-005](../gov/GOV-005.md)長崎村外三村分水の受益村落側の状況）を村側から確認する対象の候補。「用水」の帰属（千川上水系か石神井川系か）は画像判読まで特定しない。
- **制限〔未解決〕**: 画像判読は未実施。小島家文書約1,500点の個別目録の水準での走査（用水・水車関係文書の探索）は未了。
