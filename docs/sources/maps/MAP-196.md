- **区域の意義〔観察〕**: ①区域は青山（権田原〜渋谷川上流方面）〜千駄ヶ谷〜上渋谷村〜上豊沢村＝**渋谷川・宇田川方面の谷頭部を含む場末端区域**で、弦巻川（澁谷川支流の久堅田用水方面）研究の外縁資料に当たる。②「千駄ヶ谷村田畑」「上渋谷村」などの**農村的土地利用の文言候補**は、[MAP-191](MAP-191.md)（下渋谷千駄ヶ谷内藤新宿牛込の後代控本・819-157）の区域と重なり、状況の変遷を突き合わせる価値がある。③天保13年は音羽岡御鷹匠組屋拝領（[MAP-177](MAP-177.md)）と同年で、天保の改革開始直後の江戸場末の取調系列的な文脈候補〔仮説・シリーズ背景の断定はしない〕。
