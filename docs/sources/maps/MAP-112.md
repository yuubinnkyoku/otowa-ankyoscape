# [MAP-112] 復興局『東京都市計画図（一万分之一）』（1924年）

- **書誌・年代〔確認：公的所蔵目録〕**：江戸東京博物館所蔵、資料番号 **08000183**。資料名は『東京都市計画図（一万分之一）』、作成者は**復興局**、年代は**大正13年（1924年）**、縮尺**1:10,000**、**1枚・112.5×109.0cm**。これは所蔵目録の記載であり、個々の測量・修正日や図中の水路表現を確定したものではない。
- **出典〔確認〕**：東京都歴史文化財団・江戸東京博物館「[東京都市計画図(一万分之一)（ToMuCo）](https://museumcollection.tokyo/works/7009408/)」および「[江戸東京博物館デジタルアーカイブズ・資料番号08000183](https://www.edohakuarchives.jp/detail-286583.html)」（原資料**1924年**、**2026年11月1日書誌確認**）。
- **研究上の意味〔推定〕**：関東大震災直後の東京市の都市計画図として、既収録の**1923年『東京市下水道計画平面図』**、**1927年『東京市下水道事業概要』付図**、**1929年の小石川区関係地図**との比較候補。小石川区を含む当時の東京市内で、旧谷端川（小石川）下流域の道路・市街地・都市計画線の変化を調べる手掛かりとなる可能性がある。
- **留保〔未解決〕**：**原図の高精細画像・図郭・凡例・小石川区該当部分は未判読**。水窪川・弦巻川・谷端川の流路、橋、下水道が実際に描かれていることは未確認。資料名が「都市計画図」であることだけから、河道・下水管の線や事業の実施状況を推定しない。江戸東京博物館の旧閲覧ページでは現時点で代替画像が表示され、図面そのものは検証できていない。

年代（地図一覧の表記）: 1924

読図メモ: 復興局作成、1924年の縮尺1:10,000都市計画図（江戸東京博物館08000183）。小石川区の図郭・凡例・旧谷端川描線は未読。
