## repo内位置づけ〔観察・読図未実施〕

1. **弦巻川の番地界図系列の空白帯（1911〜1929）を埋める中間図**〔観察〕: repoは[MAP-157](MAP-157.md)系の1911年「四十四年調査」図と、[弦巻川](../../弦巻川.md)文書§所蔵案内のNDL [8312068](https://dl.ndl.go.jp/pid/8312068)（1929〜31年・**川流堂（小林又七）刊「東京府郡部町村図 番地界入」系列高田町図**）を記録済みで、**本図は東京遞信局（編纂）→遞信協會＋川流堂（刊行）という同一刊行系列の1920年版に当たる**＝1911→**1920**→1929〜31の3点が揃い、弦巻川流域（高田町側）の地番界・道路・水路敷の変化を20年区切りで追える初の系列〔各図の並列比較は未実施〕。
2. **戸塚町を含む＝神田川上流域の両岸**〔観察〕: 図名どおり高田町（北豊島郡・弦巻川谷〜雑司ヶ谷台地）と戸塚町（豊多摩郡・神田川南岸＝現在の新宿区戸塚・高田馬場南側）を同一紙面に収める。**弦巻川が神田川へ合流する流域（西落合〜下落合方面の旧流路・[MAP-008](MAP-008.md)1912地籍図の上流域側）の番地界確認**候補＝水路描線の有無の確認を第一読図点とする〔未実施〕。「番地界入」の体裁上、水路は行政境界としてのみ描かれる可能性があり、**非記載をもって流路不在の証拠にはしない**〔注意〕。
3. **1:5000・色刷73×67cm**: 同巣鴨側（[MAP-031](MAP-031.md)の1911年郡部番地界入図）と同系統の縮尺・判型〔観察・両図の同定は未確認〕。
