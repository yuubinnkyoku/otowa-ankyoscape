# [MAP-178] 栗田元次『日本古版地圖集成』解説 — 江戸安見圖・寛文分間圖・嘉永板切圖・長祿古繪圖附記の書誌情報群

- **書誌〔確認・一部OCR崩れ〕**: 『**日本古版地圖集成**』（**栗田元次**〔広島文理科大学教授〕著・**博多成象堂藏版**〔大阪東京〕・NDL請求記号425-75）。NDL次世代デジタルライブラリー [book/1242479](https://lab.ndl.go.jp/dl/book/1242479)。判型の大きい図録（口絵・図版頁のOCRが漢字崩れ・勝手読みで著しく乱れている）で、**解説本文の旧字体活字OCRは比較的読める**。サマリ的書誌（栗田元次編）の「編」は本文表紙のOCRでは「**著**」（「大學〓授廣島文理科栗田元次著」）＝**編・著の別は要原画像照合**。刊年は書誌カード・解説内容（1932年時点の叙述）から**1932年**〔確認・NDL書誌〕。本登録は**repo未収録だった江戸図帖・切絵図・古絵図の書誌・刊年・評価を与える解説記事の文言記録**であり、掲載図版そのものの読図は未実施。

- **長祿年中御江戶古繪圖附記の「金會木は小石川の金杉也」〔確認・文言候補・repo初出候補〕**: 歴史圖章「**希言子の長祿年中御江戶古繪圖(文化十三年、梅年寫越前屋板)もあるが…今希言子の附記中本圖に見えぬ分を摘記する。「芝崎の道場(本〓)は時宗遊行派にて今の淺草日輪寺なり。會下寺とあるは總泉寺の事也。石濱は今の端芝也。金會木は小石川の金杉也。」又この圖に奧州道とあるは、鎌倉から奧州に通ずる街道の意で、十三年板には鎌倉道とある**」＝（ａ）**希言子『長祿年中御江戶古繪圖』＝文化13年（1816）・越前屋板**という書誌（「梅年寫」はOCR崩れの余地あり要照合）、（ｂ）**附記「金會木は小石川の金杉也」＝長禄年中（1457-60頃）の江戸を想定した歴史図の地名「金會木」を小石川の金杉（金杉水道町。[対照表](../../地名・河川名対照表.md)金會木行）と考証した**江戸期の地名同定文言、（ｃ）**「會下寺は總泉寺の事」「石濱は今の端芝」の同種の考証文言**、（ｄ）**「奧州道」が「十三年板には鎌倉道とある」＝複数板の本文異同の指摘**。〔金杉水道町の旧名「金曽大村」（[GAZ-083](../gazetteers/GAZ-083.md)）とは別系統の、**「金會木」という古表記から金杉への変更を示す考証文言候補**（金杉＝小石川の地名史の追証。長禄古絵図は室町期の江戸を後代に想像復元した「歴史圖」で史料価値は限定的という本文の評価「この圖の内容の誤の多いことは既に諸家の說があつて」にも留意。**「金會木」が長禄当時の実在表記ではなく後代の造形の可能性は本文の図評価から排除できない・断定しない**）。〕
- **江戸圖鑑綱目の書誌〔確認・文言候補〕**: 目次「**第四十三 江戶圖鑑綱目 石川流宣 元祿二年刊 四六··七二**」＋解説「**元祿時代に於ける繪圖製作の第一人者であつた**〔石川流宣〕…江戶圖の江戶圖鑑綱目(第四十三圖)**」＝**『江戸図鑑綱目』＝石川流宣・元禄2年（1689）刊**という書誌。〔江戸方角安見圖と「好一對」と評価される対の図帖＝延宝〜元禄期の分間図帖の双璧という位置づけ。repo未収録の図帖名の書誌記録として〔所在記録〕。板元須原屋茂兵衞が「寶永以來江戶圖の板元」という解説文言も切絵図版元史の参考。〕

## 制限・未解決

- ①本書は図録で、**口絵・図版のOCRが著しく崩壊**している（「狐阡瀨貞雄」等の固有名詞崩れ）。解説本文の活字OCRも引用の正確な字句は**すべて原画像照合を要する**。特に縮尺文言（一分三四間・間積り壹分にて五間・六尺五寸之間）の数値解釈は照合まで確定しない。②「日本古版地圖集成 栗田元次 著」の著・編の別、「博多成象堂藏版」の出版地（大阪東京の併記のOCR）は要照合。③寛文分間圖の北條正房5枚と、目次の「遠近道印 寛文十一年刊」図（版番43-44）の対応関係（同一図か別図か）はOCRからは確定できない。④嘉永板切圖29圖の個々の図（音羽繪圖・小石川繪圖等）と既収録の切絵図（MAP-006・MAP-021等）の同一板・別板判定、板元の比定は未実施。⑤長祿年中御江戶古繪圖の「梅年寫」の字句、金會木文言の原文表記は要照合。⑥本書の掲載図版そのもの（江戸方角安見圖・寛文分間圖・嘉永板切圖の図面）の読図（水路・川の描出確認）は未実施＝**谷端川・弦巻川・水窪川の流路確認のためには原画像（コマ画像）の読図が次の課題**（人手読図待ち）。
