# [MAP-163] 「千川上水使用権利詳細平面図」（明治38年・紙の博物館）〔repo初出〕

- **書誌〔確認: 紙の博物館「抄紙会社設立150年」特設ページ・2026-11-15〕**: 「**千川上水使用権利詳細平面図**」（**明治38年（1905）**・紙の博物館所蔵）。特設ページの「抄紙会社関係の資料をみる」コレクション紹介第08回（[特設ページ該当頁](https://papermuseum.jp/ja/shoshigaisya150-collection-08/)）で画像と解説が紹介されている〔収蔵品データベース（jmapps）の「千川上水」キーワードでは2026-11-15時点でヒットせず、DB上のレコード番号は未特定。特設ページの紹介レベルで所在を固定〕。
- **紹介文〔確認: 特設ページ解説〕**: 「**明治7年（1874）9月3日、抄紙会社と水利権利者らとの間で、千川用水を工場用水として利用するための約定が締結された。この平面図は、明治38年当時、用水使用権利者が所有した図面で、王子製紙(株)王子工場（抄紙会社）までの水の流れを分かりやすく表している。**」
- **意義〔観察〕**: ①**千川用水（王子分水）の取水から王子製紙王子工場までの水路を図示した明治38年時点の図面が現存する**〔千川上水の流末・工場導水路の明治後期の形を知る一次図面の存在確認。[BLOG-230](../blogs/BLOG-230.md)の掛桶渡し（石神井川上を渡す）の図示の有無が注目されるが図面未確認〕。②[GOV-150](../gov/GOV-150.md)の明治7年9月3日約定証書と**同じ約定に由来する図面**として、証書（文書）と図面（空間情報）の対応が想定される〔明治38年＝用水使用権利者側が所有した時点の再製・写しの可能性があるが、図面の作成経緯は紹介文に記載なし〕。③「用水**使用権利**者」という呼称から、明治38年時点で千川用水の使用権利関係者（村側・工場側）の枠組みが存続していたことが示唆される〔[GOV-151](../gov/GOV-151.md)（明治23年までの助合金請取）と合わせ、明治末まで権利関係が生きていた可能性。断定は図面確認まで行わない〕。
- **特設ページの性格〔確認〕**: 2023年の抄紙会社設立150年企画展（「抄紙会社150年―洋紙発祥の地・王子」・2023年9月16日〜12月17日）に先立つコレクション紹介（2023年3〜8月に順次追加）。同コレクション紹介9点のうち水路直接関連は本図面のみで、他は錦絵・古写真・銅版画・賞牌・平面図（明治17年警視庁提出）・ウォーターマーク型・レッテル。
