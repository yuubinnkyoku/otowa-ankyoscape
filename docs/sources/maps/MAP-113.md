# [MAP-113] 東京市土木局『重要道路橋梁及水防護岸府市分担並排水場分布図』

- **所在・書誌〔確認：公的所蔵目録〕**：江戸東京博物館所蔵、**資料番号97201096**。資料名は『**重要道路橋梁及水防護岸府市分担並排水場分布図**』、作成者は**東京市土木局**。**地図1枚、109.1×120.7cm**。所蔵目録の年代表示は**「[近代] 19～20世紀」**で、正確な作成・修正・刊行年は特定されていない。
- **出典〔確認〕**：[東京都立博物館・美術館収蔵品検索（ToMuCo、資料番号97201096）](https://museumcollection.tokyo/works/7050521/)／[江戸東京博物館デジタルアーカイブズ（同資料へのリンク）](https://www.edohakuarchives.jp/detail-312596.html)（原図年代未詳、**2026年11月1日書誌確認**）。後者の原図画像は今回直接判読できていない。
- **研究上の意味〔推定：照合資料候補〕**：資料名からは、**重要道路橋・水防護岸の府市間の管理分担・排水場**を図示した東京市土木行政の地図と考えられる。旧谷端川（小石川）下流と神田川との接続域、旧小石川区内の橋梁・水防施設の所在や管理区分を、既収録の都市計画図・下水道図と比較するための**新しい原図探索先**となり得る。
- **限界〔未解決〕**：**図郭・縮尺・凡例・個々の施設名と位置は未確認**。小石川区や水窪川・弦巻川・谷端川の施設が実際に掲載されていることも確認できていない。**資料名の「排水場」は谷端川幹線の排水ポンプや特定の旧河道施設を指すと断定しない**。目録の「19～20世紀」を特定の工事年に読み替えない。

年代（地図一覧の表記）: 年代未詳（所蔵目録は19～20世紀）
