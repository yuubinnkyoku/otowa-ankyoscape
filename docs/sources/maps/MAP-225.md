## 資料解説文言〔確認: アーカイブ詳細頁の「資料解説」欄〔出典表示: 大規模企画展2011-2『江戸の町づくり』リーフレットp.10〕〕

- 「**千代田区の内神田、司町、淡路町、小川町、駿河台、猿楽町、神保町、錦町あたりの切絵図**」「**図の中央下が水道橋駅、昌平橋のあたりが御茶ノ水駅です。神田川にかかる水道橋の隣は神田上水の掛樋で、ここから暗渠で江戸城内に入っていますが、風光明媚な場所として江戸の名所になっていま**す」〔都立図書館展示解説（図録由来）の文言として記録。展示解説レベルであり図面文言そのものではない〕。

## repo内位置づけ〔観察・読図未実施・いずれも断定しない〕

1. **千川筋市中末端域の尾張屋板切絵図としてrepo初出**: [BOOK-328](../books/BOOK-328.md)（明治千川水道の神田ルート）・[GAZ-193](../gazetteers/GAZ-193.md)（神田旅籠町文言群）等で問題になる「千川が神田川筋に落ちる市中末端域」の江戸期・市中側を対象にした切絵図。武家地・寺町ではなく町人地の細部図である点が当家屋敷絵図と異なる。
2. **小川町＝GAZ-188「小石川の名これより起る」の候補地の一つ**: [GAZ-188](../gazetteers/GAZ-188.md)（小石川名称起源の「小川」文言）の小川候補には神田小川町系が含まれ、本図の表題「小川町」はその地理の図上確認資料の候補。読図により小川町周辺の水路・堀描写を照合する価値がある〔仮説: 読図未実施〕。
3. **水道橋・神田上水掛樋・暗渠文言の図像側資料**: 解説文言の「**神田川にかかる水道橋の隣は神田上水の掛樋、以下暗渠で江戸城内**」は [GAZ-048](../gazetteers/GAZ-048.md)（萬年樋）・[GAZ-068](../gazetteers/GAZ-068.md)（小石川砲兵本廠の伏管→水道橋の萬年樋）・[MAP-205](MAP-205.md)（神田上水絵図の「掛樋で渡ってからは暗渠」解説）と同一の導水形状記述の系列。本図の「水道橋付近」の描き込みが掛樋等を図示しているか否かの読図課題〔読図未実施〕。
4. 神田上水と千川上水が江戸城内でどのように接続・併走するかは千川研究の長年の主題（「城内で神田上水に合流」系文言の吟味）。本図は城外側末端（水道橋〜神田川）を扱うため、千川側の読図には間接資料にとどまる〔本図のみでは千川の末端形状は何も確定しない〕。
