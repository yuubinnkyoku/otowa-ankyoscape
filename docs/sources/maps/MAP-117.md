# [MAP-117] 植野録夫『大東京区分図三十五区之内小石川区詳細図』（1935年所蔵例）

- **所蔵・年代〔確認：公的収蔵品目録〕**：江戸東京博物館所蔵、資料番号 **00002392**。資料名『**大東京区分図 三十五区之内 小石川区詳細図**』、著作者・発行兼印刷者 **植野録夫**、発行所 **東京地形社**、年代 **1935年（昭和10年）**、寸法 **54.7×79.0cm**。出典：[東京都歴史文化財団・ToMuCo所蔵目録](https://museumcollection.tokyo/works/7013871/)／[江戸東京博物館デジタルアーカイブズ](https://www.edohakuarchives.jp/detail-290973.html)。
- **公開図版の別所蔵例〔確認：公的目録〕**：特別区協議会の[資料目録](https://adeac.jp/tokyo-23city/catalog/ct00000171)と[IIIF図版](https://adeac.jp/tokyo-23city/viewer/ct00000171/dg00000171)に同名・同著作者・同発行所の地図がある。**縮尺1:6,500、寸法78.5×54.2cm、新旧町名一覧表あり、CC BY 4.0**。ただしこの所蔵目録の**製作年は空欄**であり、江戸東京博物館の1935年所蔵例と**同一刷・同一版であることは未確認**。寸法の差は測定対象・所蔵状態・版次のいずれによるか判断しない。
- **別版の区別〔確認：書誌〕**：CiNii Booksには**1941年6月、日本統制地圖刊、縮尺1:8,000**の同名『大東京區分圗三十五區之内小石川區詳細圗』が別書誌（NCID **BB2281021X**）として存在する。**1935年の東京地形社版と1941年の日本統制地圖版は、少なくとも書誌上、発行者・縮尺・年代が異なる**。出典：[CiNii Books](https://ci.nii.ac.jp/ncid/BB2281021X)／[MAP-118](MAP-118.md)。
- **研究上の位置づけ〔推定〕**：1934年に竣工したとする谷端川（小石川）下流の暗渠化工事記録と、戦前の道路・町名・橋の配置を比較する**1935年時点の地図候補**。既収録の1930年代の下水道計画図、1941年の同名別版、1947年の区分図と比較できる可能性がある。
- **限界〔未解決〕**：両所蔵例の**原図の小石川・谷端川該当部分、河道・橋・道路・管渠記号、図郭・修正履歴は未判読**。1935年という目録年代は地図の測量日や河道改修完了日ではない。図名だけで**1934年工事後の暗渠・道路が描かれること、旧谷端川の河道線形が示されることは確認できない**。

年代（地図一覧の表記）: 1935年（昭和10年、江戸東京博物館所蔵例）

読図メモ: 江戸東京博物館の1935年東京地形社版（00002392）と、特別区協議会の同名・同著者・1:6,500公開図（刊年未記載）を確認。同一刷か未確定。1941年日本統制地圖版（1:8,000）は別書誌。小石川下流の描線未読。
