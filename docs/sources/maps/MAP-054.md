## 同定とデジタル公開（2026-10-30、東京都立図書館TOKYOアーカイブの直接確認・ai）

- 本図は遠近道印作・経師屋加兵衛刊の「寛文五枚図」の第4図である。刊記は寛文12年（1672年）閏6月吉日で、1672年は刊記に基づく年（推定ではない）。収録範囲は小日向・牛込・市ヶ谷・四谷・高田・大久保・内藤宿。
- 東京都立図書館デジタルアーカイブ「TOKYOアーカイブ」に刊本と写図の2件がある。刊本（木版・手彩）：題名は「新板江戸絵図」とされ、別題に「新板江戸外絵図〔四〕 小日向、牛込、一谷、四谷、高田、大久保、内藤宿迄」。請求記号 A19-4／東A19-004、資料コード 4300037688、大きさ 136.5×133.7cm、画像の使用条件はパブリックドメイン。https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000013-00042427
- 写図（無彩）は請求記号 A19-8／東A19-008、資料コード 4300037731。
- 国立国会図書館デジタルコレクションにも収録があり、永続的識別子は pid 1286189（ジャパンサーチのレコード dignl-1286189 で利用条件「自由に利用可」と表示）。原図は明治大学図書館（蘆田文庫）にも1舗ある。
- 注意：音羽谷・護国寺予定地が本図（第4図）の図郭内にあるか、第3図（小石川・駒込方面、1671年）側にあるかは、目録情報だけでは確定できない。護国寺創建前（1681年以前）の読図対象としての位置づけ（[音羽谷の非対称な横断面の成因](../../open-questions/音羽谷の非対称な横断面の成因.md) の最短経路第1項）は画像の確認が前提になる。
- 画像確認の試行（2026-10-30）：TOKYOアーカイブのビューアで第4図・第3図の画像を開いたが、表示解像度では細かい地名注記まで判読できず、音羽・関口・大塚・護国寺の表記は確認できなかった。第4図の題名・解説の範囲は小日向・牛込・市ヶ谷までで、東端には太い線の東側が余白になる図郭が見えるが、音羽谷のどこで切れるかは断定できない。
- 高精細画像の経路（2026-10-30確認）：国立国会図書館デジタルコレクションの当該図はIIIFで配信されており（マニフェスト https://dl.ndl.go.jp/api/iiif/1286189/manifest.json 、画像は10400×12469ピクセル）、部分拡大をフル解像度で取得できる。スキャンの向きは上辺が東・左辺が北で、北を上にするには時計回り90度回転が要る。この経路で図郭東端の地名注記まで判読する読図は未実施。
