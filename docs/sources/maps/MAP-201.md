# [MAP-201] 上石神井村絵図（江戸時代・年次不詳・「ふじ大山道＝道者道」文言）

- **書誌〔確認: 所蔵品アーカイブ詳細頁・2026-11-19〕**: 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（[detail.cgi?id=10014](https://www.neribun.or.jp/archive/detail.cgi?id=10014)）、地図カテゴリ収録。**番号2000-1-0001-6-4**、名称「**上石神井村絵図（かみしゃくじいむらえず）**」、備考「**栗原家文書絵図**」、内容等「**上石神井村の田、畑、用水の様子が描かれている絵図（江戸時代　作成年次不詳）。ふじ大山道は、「道者道」と記載されている。**」画像は同頁から直接閲覧可能（[img/2000-1-0001-6-4_01.jpg](https://www.neribun.or.jp/archive/img/2000-1-0001-6-4_01.jpg)）。
- **「道者道」文言〔確認・repo初出の道路名候補〕**: 目録文言によれば、本絵図の「**ふじ大山道**」（富士・大山への道と読める名称。目録は判読を示しておらず解釈は保留）には「**道者道**」との記載があるという。大山道（大山阿夫利神社参詣道）はrepoの大山（板橋区）・出端川の系譜（[BLOG-080](../blogs/BLOG-080.md)）と関連する道路名称であるところ、**上石神井村側の江戸時代絵図で大山道系の道が「道者道」と呼称されていた（と目録解説される）記録**はrepo初出の用例候補。図上の道の経路（関町〜上石神井方面の大山道の位置）と「道者道」の表記の実在は画像判読まで確認できない。
- **千川上水研究との関係〔観察〕**: 上石神井村の田・畑・用水を描く絵図（判読は未実施）であることに加え、**千川上水と大山道（川越街道〜青梅街道間の移動経路）の交差関係を村絵図レベルで検証する対象**になり得る〔千川上水の青梅街道交差部を描く絵図＝[MAP-203](MAP-203.md・千川家文書絵図)と道路系の対照〕。
- **制限〔未解決〕**: 「ふじ大山道」「道者道」の文言は目録解説由来で、絵図本文の字面・経路は未確認（画像判読が前提）。作成年次も不詳。
