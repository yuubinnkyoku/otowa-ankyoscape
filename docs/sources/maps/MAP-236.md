## repo内位置づけ〔観察・読図は未実施・断定しない〕

1. **谷端川源流（長崎村）の1911年定点〔観察〕**: [GAZ-002](../gazetteers/GAZ-002.md)（北豊島郡誌）の「谷端川ハ長崎村より出ル細流」文言＝谷端川源流の村は長崎村。本図は**その源流域を1:5000で単独収録する明治44年の図**で、1912地籍図（[MAP-008](MAP-008.md)）や1911番地界入図（[MAP-031](MAP-031.md)・[MAP-157](MAP-157.md)）と同じ年の逓信局系統＝**谷端川源流描線（開渠時点）の対照候補**。長崎村側の谷頭部（千川駅北側〜T字谷）の水路・池の描かれ方が第一読図点〔未実施〕。
2. **千川上水中流域＋落合村〔観察〕**: 図域の豊多摩郡落合村側は千川上水の流末（中新井・下落合方面）と神田川沿いの低地＝**千川上水の1911年（再生用水期）の描線**が確認できる候補。千川上水関連の1911年前後定点（[GOV-569](../gov/GOV-569.md)群の管理文書と同年）として読図対象。
