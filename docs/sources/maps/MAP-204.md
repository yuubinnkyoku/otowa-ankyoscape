# [MAP-204] 羽村表水門之図（玉川上水羽村取水の水門・千川家文書絵図）

- **書誌〔確認: 所蔵品アーカイブ詳細頁・2026-11-19〕**: 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（[detail.cgi?id=10021](https://www.neribun.or.jp/archive/detail.cgi?id=10021)）、地図カテゴリ収録。**番号2000-1-0002-289**、名称「**羽村表水門之図（はむらおもてすいもんのず）**」、備考「**千川家文書絵図**」、内容等「**千川上水の本流の玉川上水が羽村（羽村市）で多摩川から取水している水門付近を描いた絵図。江戸期から明治初期の作成。**」画像は同頁から直接閲覧可能（[img/2000-1-0002-289_01.jpg](https://www.neribun.or.jp/archive/img/2000-1-0002-289_01.jpg)）。
- **[GOV-038](../gov/GOV-038.md)の「羽村表水門之図（所蔵資料リスト6番）」の個別対応〔確認〕**: 練馬区公式の千川家文書ページ・所蔵資料リストで名が挙がっていた「**羽村表水門之図**」の、所蔵品アーカイブ側の個別レコード（番号・画像）の特定に成功。
- **repoの水源論との関係〔観察〕**: repoの千川上水の系譜は「**玉川上水より分水**」（元禄9年・1696）に依拠するが、その分水の**元頼（玉川上水の多摩川羽村取水の水門）を千川家自身が絵図として保有していた**ことが目録文言で確認できた点は、千川家文書の範囲が羽村堰の取水構造の関心にまで及ぶという観察の datapoint〔千川上水の本源が玉川上水であるとする記載文言（「千川上水の本流の玉川上水」）としても、館側解説の表現として記録〕。
- **制限〔未解決〕**: 画像判読（水門の構造・幅・周年や樋管の有無）は未実施。作成年次は「江戸期から明治初期」まで。
