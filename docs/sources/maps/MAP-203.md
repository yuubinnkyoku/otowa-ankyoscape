# [MAP-203] 御林跡地竹下新田之内千川用水堀絵図面（青梅街道交差付近・千川家文書絵図）

- **書誌〔確認: 所蔵品アーカイブ詳細頁・2026-11-19〕**: 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（[detail.cgi?id=10019](https://www.neribun.or.jp/archive/detail.cgi?id=10019)）、地図カテゴリ収録。**番号2000-1-0002-281**、名称「**御林跡地竹下新田之内千川用水堀絵図面（おはやしあとちたけしたしんでんのうちせんかわようすいぼりえずめん）**」、備考「**千川家文書絵図**」、内容等「**千川上水が青梅街道と交差する付近を描いた絵図。江戸時代の作成。**」画像は同頁から直接閲覧可能（[img/2000-1-0002-281_01.jpg](https://www.neribun.or.jp/archive/img/2000-1-0002-281_01.jpg)）。
- **[GOV-038](../gov/GOV-038.md)の「竹下新田付近の絵図」の具体化〔確認〕**: 練馬区公式の千川家文書ページが代表資料として挙げる「**竹下新田付近の絵図**」、および同館所蔵資料リストの「**御林跡地竹下新田之内千川用水堀絵図面（12番）**」の、所蔵品アーカイブ側の対応個別レコード（番号・名称・内容）の特定に成功した。**千川上水と青梅街道の交差部**（練馬区関町南〜武蔵関周辺と推定される区間。位置は画像判読まで確定しない）を描く江戸時代絵図。
- **repoの青梅街道交差問題との関係〔観察〕**: repoは[BLOG-094](../blogs/BLOG-094.md)（sirakigiの千川上水と青梅街道の交差言及〔間接〕）などを通じて千川上水の青梅街道越え（伏樋・暗渠・開渠の別）を未解決課題として保持しているところ、**交差部そのものを主題とする千川家文書絵図の画像がアーカイブで公開されている**ことが確認できた。画像判読により交差構造の図上確認が進め得る〔千川家文書21点の絵図類のうち、アーカイブで画像公開が確認できた6点（[MAP-119](MAP-119.md)/[MAP-120](MAP-120.md)/[MAP-155](MAP-155.md)/[MAP-156](MAP-156.md)/本図/[MAP-204](MAP-204.md)）の一つ〕。
