# [MAP-118] 植野録夫『大東京區分圗三十五區之内小石川區詳細圗』（1941年6月版）

- **書誌・刊行〔確認：大学図書館共同目録〕**：CiNii Books（**NCID BB2281021X**）は、**植野録夫著、日本統制地圖、1941年6月刊**の地図1枚（**2図**）として登録する。**縮尺1:8,000、内匡48×69cm、全体52×73cm**。収録図として「**大東京市擴張區域一般圖**」を挙げ、国際日本文化研究センター図書館の所蔵を示す。出典：[CiNii Books・原書誌](https://ci.nii.ac.jp/ncid/BB2281021X)。
- **別の公的所蔵案内〔確認〕**：東京都立図書館の[所蔵地図目録（PDF）](https://www.library.metro.tokyo.lg.jp/search/uploads/2_ippanntizu.pdf)にも、**昭和16年・日本統制地図・1:8,000**の小石川区詳細図と、昭和礼文社による復刻版が掲げられる。これは上記の**1935年東京地形社版（MAP-117）と発行者・縮尺が異なる**。
- **研究上の位置づけ〔推定〕**：1935年の東京地形社版と1941年の日本統制地圖版を比較すれば、**谷端川（小石川）下流の暗渠化後における道路・橋・町割の地図上の表示変化**を調べる候補となる。
- **限界〔未解決〕**：**原図の該当部分は未閲覧**。1941年版の河道・暗渠・橋・道路がどのように描かれているか、1935年版からの実際の改訂内容、1934年工事との直接関係は未確認。**1941年6月を水路の施工・撤去・道路開通の年月としない**。地図2図のうち拡張区域一般図に対象地点が含まれることも未判読。

年代（地図一覧の表記）: 1941年6月（昭和16年）

読図メモ: CiNii Books BB2281021Xが1941年6月・日本統制地圖・1:8,000を明記。1935年東京地形社版とは書誌上別版。収録の「大東京市擴張區域一般圖」を含め図面未判読。
