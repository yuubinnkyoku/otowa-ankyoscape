# [MAP-164] 1853年『嘉永新鐫雑司ヶ谷・音羽絵図』〔repo初出・所在のみ〕

- **書誌〔確認: 雑司ヶ谷研究20の表1・2026-11-15〕**: 「**嘉永6(1853) 嘉永新鐫雑司ヶ谷・音羽絵図**」。杉浦美鈴・薬袋奈美子・大山祐加子・原わかな・古賀碧「雑司ヶ谷研究20 絵地図と国土地理院旧版地図より読み取る道路形成の歴史」（日本女子大学紀要家政学系72・2025年3月1日発行・pp.55-65・[DOI](https://doi.org/10.57483/0002000548)）の表1「雑司が谷の変遷調査に用いた地図」江戸期(4)として掲載。**表1に各図の所蔵先・出典の記載はなく**、原図の所蔵館・請求番号・デジタル公開の有無は未確認。
- **位置づけ〔推定: 図名・年代から〕**: 既収録の嘉永4年（1851）『音羽目白雑司ケ谷辺絵図』（[MAP-005](MAP-005.md)・村上吾雄誌・近吾堂（近江屋吾平）板）の**2年後**にあたる。「新鐫」（新たに彫り直すの意）の図名から、嘉永4年板の**改訂・改刻版の可能性**があるが、板元・図容の異同は原図確認まで断定しない。同時期の同地域の絵図が2種あることは、嘉永期の音羽・雑司ヶ谷周辺（弦巻川上流域）の地図流通の厚みを示す書誌的事実。
- **制限・未解決**: ①原図の所在・所蔵・デジタル公開の有無（東京都立図書館TOKYOアーカイブ・NDL等の目録検索が次回課題）。②嘉永4年図（MAP-005）との図容の異同——水路の描き方に差があれば、弦巻川・水窪川・護国寺周辺水路の1851→1853年の図上変化として読める可能性。③表1の(1)正徳6(1716)高田村絵図・(2)明和9(1772)雑司谷村絵図・(3)嘉永4(1851)音羽・目白・雑司ヶ谷絵図は、いずれもREADME既収録の各絵図（[MAP-012](MAP-012.md)・1772年雑司谷村絵図・MAP-005）と年代・図名が一致するが、所蔵本レベルの同一性は未照合。
