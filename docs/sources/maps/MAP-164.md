# [MAP-164] 『嘉永新鐫雑司ケ谷音羽絵図』（尾張屋板・都立図書館）〔repo初出〕

- **書誌〔確認: 東京都立図書館デジタルアーカイブTOKYOアーカイブ詳細頁・2026-11-15〕**: 「**嘉永新鐫雑司ケ谷音羽絵図**」（題簽「音羽繪圖 全」）。[TOKYOアーカイブ詳細](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000013-00042340)〔tilcod 0000000013-00042340・資料コード4300036439・請求記号0452-6イ/東0452-006イ・東京誌料文庫〕。**編者等: 戸松昌訓正訂・版元: 金鱗堂尾張屋清七・出版年: 安政4[1857]改**・46.2×50.0cm・木版色刷・シリーズ「**尾張屋板切絵図 17**」・江戸図種別=切絵図。**画像はパブリックドメインで公開**（viewサイズ1218×1024px・約1.4MBのzoom画像あり）。
- **紀要論文での掲載〔確認: 雑司ヶ谷研究20の表1・2026-11-15〕**: 杉浦美鈴・薬袋奈美子・大山祐加子・原わかな・古賀碧「雑司ヶ谷研究20 絵地図と国土地理院旧版地図より読み取る道路形成の歴史」（[PAP-082](../papers/PAP-082.md)・2025年）の表1は江戸期(4)として「**嘉永6(1853) 嘉永新鐫雑司ヶ谷・音羽絵図**」を掲げる。**都立図書館の書誌（安政4[1857]改）と論文の年代（嘉永6=1853）は食い違い、理由は本文に示されない**。「嘉永新鐫」の題名から論文が嘉永年間（嘉永6を採った可能性）として整理したと推測できるが断定しない。題名中の「嘉永」と改刻年（安政4改）の双方が図の成立に関わる年号として併存する。
- **嘉永4年板（MAP-005）との関係〔観察: 書誌比較〕**: 既収録の嘉永4年（1851）『音羽目白雑司ケ谷辺絵図』（[MAP-005](MAP-005.md)・村上吾雄誌・**近吾堂（近江屋吾平）板**）に対し、本図の版元は**金鱗堂尾張屋清七（尾張屋板切絵図シリーズ）**で**板元が異なる**。都立図書館の資料解説（2011年企画展リーフレット）は「**初版は嘉永4年の発行です**」と記す〔この「初版」が尾張屋板シリーズの嘉永4年初版か、本図自体の初版かは解説文から確定できない〕。「同一図の改訂版」というより**同一地域を扱う別系統（尾張屋板）の版本**である可能性が高く、嘉永4年板との図容（水路・道路の描き方）の異同は原図の読図による。
- **他所蔵〔確認: 検索結果の書誌・2026-11-15〕**: デジタルアーカイブ福井（[福井県立図書館](https://www.library-archives.pref.fukui.lg.jp/archive/da/detail?data_id=012-1003512-0)・data_id 012-1003512-0「［嘉永新鐫］雑司ヶ谷音羽絵図」）・国際日本文化研究センター[所蔵地図データベース](https://lapis.nichibun.ac.jp/chizu/map_detail.php?id=002150662)（id 002150662「嘉永新鐫雜司ケ谷音羽繪圖」）・Webcat Plus（NCID BB09641107）。各所蔵本の同一性・刊年記載の差異は未照合。
