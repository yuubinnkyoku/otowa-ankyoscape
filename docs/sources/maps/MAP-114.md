# [MAP-114] 『「東京」郡部下水道区域予定図』

- **書誌・所在〔確認：所蔵機関の公開目録〕**：後藤・安田記念東京都市研究所・市政専門図書館「東京関係地図」、**資料番号 OY 001-107**。標題は『**「東京」郡部下水道区域予定図**』、縮尺**1:100,000**、図面寸法**54.3×42.2cm**。編者・刊行年月は目録上空欄。**1920年代刊と断定しない**。
- **公開先〔確認：目録と図版へのリンク〕**：[市政専門図書館「東京関係地図」](https://www.timr.or.jp/library/degitalarchives_shinsai.html)／[図版PDF（資料番号 OY 001-107）](https://www.timr.or.jp/library/docs/mrl1003-01-16.pdf)。**目録に加え、公開PDFの1頁全体を2026年11月2日に直接閲覧した**。
- **図版の表題・凡例〔観察：公開PDFの原図画像、2026年11月2日閲覧〕**：図の上部に「**東京都市計畫區域圖**」、右側に縦書きで「**郡部下水道區域豫定圖**」、左下に「**東京市政調査會**」の文字が見える。下部の凡例には、**都市計画区域の境界、区境、東京市界**を別の色・線で示す項目がある。少なくとも個別管渠の管径・竣工年を記す工事竣工図ではなく、**広域の都市計画区域・行政境界を基図として示す図**である。下水道予定区域の着色・境界を凡例と厳密に対応させる作業は未了であり、各線の色と意味をこの記述だけで確定しない。出典：[原図PDF](https://www.timr.or.jp/library/docs/mrl1003-01-16.pdf)（1頁）。
- **記載範囲〔未解決〕**：高田町・長崎町・巣鴨町・池袋方面が実際に図郭に含まれるか、下水道区域が既設か予定か、各河川の排水区・管路と一致するかは未確認。「区域予定図」は**個々の管渠の竣工図ではない**。
