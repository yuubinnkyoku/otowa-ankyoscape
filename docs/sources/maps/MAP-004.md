# [MAP-004] 1817年頃『江戸府内実測図』／『江戸府内図（北半）』

- 伊能忠敬系の江戸府内実測図。文化14年（1817）頃の作製とされる測量図系統。
- 国立国会図書館デジタルコレクション（YR8-N95）: https://dl.ndl.go.jp/pid/1286225
- 国立国会図書館デジタルコレクション（YR8-N96）: https://dl.ndl.go.jp/pid/1286226
- 2026年9月29日の本調査では、オンライン画像の雑司ヶ谷付近に**弦巻川候補となる淡い細線**を確認した。一方、人文社の復刻版『伊能忠敬 江戸府内実測圖』を店頭で確認したところ、同じ細線はほとんど判読できなかった。
- この差は、写本差だけでなく、撮影・製版・印刷で淡色細線が弱くなった可能性もある。したがって、**復刻版で見えないことだけを根拠に「原図に河川がない」とはしない**。
- 現段階では淡線を弦巻川と確定せず、YR8-N95・N96間の描写差、周辺の既知の道路・村界・水路記号との比較を行うまで〔候補／判読保留〕とする。

## 東京市1927年版『江戸實測圖』の別複製（2026年11月1日追加）

- **書誌〔確認：国立国会図書館サーチ〕**：伊能忠敬測量・東京市編纂『[江戸實測圖](https://ndlsearch.ndl.go.jp/books/R100000002-I000010180928)』、**東京市、1927年2月刊、縮尺約1:6,000、色刷地図20枚（1図）、107×78cm、付属解説8頁**。請求記号**YG17-Z-342**、書誌ID**000010180928**。NDL公開の[20枚の索引図](https://ndlsearch.ndl.go.jp/file/rnavi/maps/post_601018/Z045.pdf)も確認できる。
- **複製経路〔確認：同書誌の一般注記〕**：『東京市史稿 市街篇』**附図第三**に当たり、**文化14年（1817年）に伊能忠敬が作成した図の副本を東京市が模写し、そこから複製した**と記される。**1817年は元となる図の内容年代、1927年はこの複製の刊行年**。筒の刊行表示は**1928年3月**であり、地図本体の書誌上の刊年と混同しない。
- **比較価値〔推定〕**：本調査がYR8-N95・YR8-N96の画像で観察した**雑司ヶ谷付近の淡い弦巻川候補線**について、別の複製工程を経た東京市版20枚と照合すれば、**描線の有無・濃淡が原図の差か、写し・製版・印刷によるものか**を検討できる。ただし**東京市版の該当図葉そのものは未閲覧**で、同版に弦巻川が描かれていること、既読画像と原図の系統が独立していることは確認していない。図葉番号・図郭も要確認。〔**未解決：該当図葉の閲覧と画像比較**〕
