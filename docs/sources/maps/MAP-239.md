# [MAP-239] 『東京府北豐島郡板橋町』（1922.9・逓信局系番地界図）〔repo初出・第341回〕

読図メモ: 谷端川下流域（板橋町＝現・板橋区中心部）を単独収録する大正11年番地界図。TOA「豊嶋」143件掃引（第341回）で検出。読図は未実施。

## repo内位置づけ〔観察・読図は未実施・断定しない〕

1. **「第2版」＝先行版（第1版）の存在〔観察〕**: 版表示「第2版」＝**明治44年〜大正初年の第1版が先行して存在する**ことが版表示から確認でき、谷端川下流の番地界図のもう1点（第1版の所在・刊年は未確認〔要探索〕）。
2. **谷端川下流・千川末端域の1922.8定点〔観察〕**: 板橋町は谷端川が流下する下流域（現・板橋区中心部）＝明治末〜大正期の谷頭部から下板橋方面へ向かう水路（谷端川・千川系の水路群〔関係水路の実態は読図まで断定しない〕）の1922年時点確認候補。板橋下水道（1906・repo既知）と1922（東京市雨水流下係数図 [MAP-115](MAP-115.md)と同年）の中間行政図。
3. **上板橋村図（[MAP-238](MAP-238.md)）との隣接対〔観察〕**: 同系列体裁（遞信協會・川流堂小林又七共同刊行・番地界入カバー題）で上板橋村1917.8と板橋町1922.9が揃い、**番地界図の体裁で谷端川中流から下流への接続判読が可能になった**（ただし刊年差＝5年の地番状況差に注意）。
