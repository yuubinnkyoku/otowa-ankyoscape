## repo内位置づけ〔観察・読図未実施〕

1. **弦巻川の1930.6定点＝暗渠化着工の直前図**〔観察〕: [弦巻川](../../弦巻川.md)文書の時系列仮説（1929年高田町下水道施設計画→1930年12月29日事業認可告示→1931年弦巻川暗渠化着工〔各出典は同文書〕）に対し、**本図は1930.6現在＝計画進行中・着工直前の高田町域**を伝える。**図上で弦巻川が開渠線として描かれるかどうかの確認が本図の第一読図点**＝開渠描線があれば「1930年時点で開渠」の図上基準資料となり、描かれなければ非記載の理由（青焼きの abbreviature・暗渠化済み範囲の有無）を凡例と併せて判断する。**描線の有無だけでは開渠・暗渠の実態を断定しない**〔未解決〕。
2. **丸池・旧神田上水路・高田町下水道設計図との対照**: [MAP-037](MAP-037.md)〜[MAP-040](MAP-040.md)（1926〜1927高田町・長崎町住宅明細図）、[GOV-167](../gov/GOV-167.md)（1930高田町政概要・音羽・鶴巻川・旧神田上水・谷端川の流域区分）、GOV-455〜系の高田町下水道設計図と同町域・同年の図面群として**丸池周辺の区画・旧神田上水路の線形・水久保・雑司が谷側の谷筋**を1:4000の青焼き図上で確認できる最初の候補〔要読図〕。
3. **水窪川・千川上水域**: 高田町域は水窪川・旧千川上水の南側台地～弦巻川谷線も含み、[MAP-157](MAP-157.md)（1911番地界入）・[MAP-234](MAP-234.md)（1920番地界入・本回採録）との3点比較で1911→1920→1930の地割変化を追える系列が初めて揃った〔観察〕。
4. **請求記号T/43・290/5006/1930＝TOAの町域図シリーズ**（[MAP-116](MAP-116.md)東京五拾区縮図が「60×85cm・ATD-1」＝同寸法系）＝**東京府郡部町村域の行政図面系列の高田町葉に当たる所在記録**〔観察・シリーズの全体像は未確認〕。
