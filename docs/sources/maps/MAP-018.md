読図メモ: 豊島区地域地図 第7集に複製と読みおこし参考図（原図の作成年不詳、東京都公文書館所蔵）。池袋村は谷端川・弦巻川の上流域を含むが、各河川の読図判定は未実施。別の言及では文政期（1818〜1830）に描かれた『池袋村図』ともされ、同一図かどうかは要照合。

## 原図の構成・閲覧条件と未描画水路をめぐる二次読図（2026年11月3日照合）

- **原図の公的目録〔確認：目録を直接確認／原図画像は未閲覧〕**：東京都公文書館「[池袋村図（帙書：江戸各郷村図　坤）](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_01&pkey=000100349)」（資料ID **000100349**、原図・彩色、**1枚・93×118cm**、年代記載なし）。「**編脩地志備用典籍**」印があり、**一部に別紙の図を貼付**したと目録が記す。利用区分は**条件付利用・複製物**、複写条件は**原本電子コピー不可、撮影可**。原図の貼付部分がどの地域・水路に対応するかは未確認。資料の作成年を「文政期」と確定しない。
- **複製図の所在〔確認：区公式刊行物案内〕**：豊島区『[豊島区史 地図編（上）](https://adeac.jp/toshima-history/top/topg/06kikankushi/index.html)』は**1974年1月刊**で、近世地図31図を収録。下記2025年記事は、同書**p.18の「池袋村図」**を読図対象と明記する。ただし本書p.18の図面は当方で直接判読していない。
- **描線と橋の食い違い〔観察：2025年の二次読図／原図未確認〕**：[sakura「池袋村図に描かれていない川の流れ」](https://note.com/toshima_lab/n/n2ee55a4da242)（**2025年6月26日**）は、**四面塔辻へつながる東西の道筋に「土橋」が2か所描かれる一方、対応する水流の線が描かれていない**と指摘する。記事の現代地図上の位置・西側を東京芸術劇場北側とする比定・東西の橋から弦巻川／水窪川への支流を引く線は**執筆者自身が推測・想像と明示**している。**橋の存在・位置・橋下の水路・流向は、原図または高精細複製の独立判読まで確定しない**。橋名「土橋」が2点あったとの記載も現時点では二次読図である。
