# [MAP-198] 上石神井村絵図（文久元年〈1861〉・栗原家文書絵図）

- **書誌〔確認: 所蔵品アーカイブ詳細頁・2026-11-19〕**: 練馬区立石神井公園ふるさと文化館・分室の所蔵品アーカイブ（[detail.cgi?id=10011](https://www.neribun.or.jp/archive/detail.cgi?id=10011)）、地図カテゴリ収録。**番号2000-1-0001-6-1**、名称「**上石神井村絵図（かみしゃくじいむらえず）**」、備考「**栗原家文書絵図**」、内容等「**上石神井村の道、用水、田の様子が描かれている文久元年(1861)作成の絵図**」。画像は同頁から直接閲覧可能（[img/2000-1-0001-6-1_01.jpg](https://www.neribun.or.jp/archive/img/2000-1-0001-6-1_01.jpg)）。
- **文書の由来〔確認〕**: 同アーカイブの文書カテゴリ総括レコード（[detail.cgi?id=10006](https://www.neribun.or.jp/archive/detail.cgi?id=10006)・栗原家文書・80点）によれば、栗原家は「**上石神井村の名主、石神井村の村長などを勤めた**」家で、天保2年（1831）〜昭和8年（1933）の上石神井地域の絵図や文書類を伝える〔本絵図はその絵図群の1点〕。
- **千川上水研究との関係〔観察〕**: 上石神井村は千川上水本流が貫流する村の一つ（現在の上石神井・関町南〜西武新宿線上石神井駅周辺）。**幕末文久元年の「道・用水・田」が村単位で描かれる絵図**の所在が目録で確認でき、千川上水の幕末期の流路・灌漑の村側絵図資料の候補。「用水」が千川上水を指すかは画像判読まで特定しない。
- **同村内絵図群〔確認〕**: 同アーカイブには上石神井村絵図が計4点（[MAP-198](MAP-198.md)文久元年・[MAP-199](MAP-199.md)慶應4年・[MAP-200](MAP-200.md)年次不詳・[MAP-201](MAP-201.md)年次不詳（道者道文言））が連続所蔵番号（2000-1-0001-6-1〜6-4）で公開されている〔文久元年→慶應4年の7年間の比較読図の可能性〕。
- **制限〔未解決〕**: 画像判読（用水の流路・千川上水の表記の有無）は未実施。栗原家文書80点のうち他の絵図・文書の目録水準の調査（c=1カテゴリ・id=10006の内容等の個別点検）は未了。
