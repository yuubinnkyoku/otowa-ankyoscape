# [MAP-115] 東京市下水課臨時調査掛『「東京」市内雨水流下係数図』

- **書誌・所在〔確認：所蔵機関の公開目録〕**：後藤・安田記念東京都市研究所・市政専門図書館「東京関係地図」、**資料番号 OY 001-108**。編者は**東京市下水課臨時調査掛**、刊行表示は**1922年6月**、縮尺**1:20,000**、図面寸法**78.6×54.1cm**。
- **公開先〔確認：目録と図版へのリンク〕**：[市政専門図書館「東京関係地図」](https://www.timr.or.jp/library/degitalarchives_shinsai.html)／[図版PDF（資料番号 OY 001-108）](https://www.timr.or.jp/library/docs/mrl1003-01-17.pdf)。**目録の標題・編者・年月・縮尺・寸法を確認したが、図面の係数値・区分・凡例は未判読**。
- **記載範囲〔未解決〕**：「市内」は1922年当時の東京市を指す標題で、**当時郡部だった高田町・長崎町などを図郭に含むとは限らない**。小石川区・音羽谷・旧谷端川下流に対応する区域の有無、係数の定義、数値、調査・算定の基準年は未確認。**1922年は地図の刊行年月で、河川暗渠化・下水道工事の年ではない**。

年代（地図一覧の表記）: 1922年6月

読図メモ: 東京市下水課臨時調査掛による1922年6月の雨水流下係数図、1:20,000（市政専門図書館 OY 001-108）。原図未判読。旧小石川区の図郭・係数値・凡例を要確認。
