# [MAP-109] 飯田錦之助『小石川区全図』（1904年10月5日）

- **書誌・年代**：飯田錦之助著、博益社、1904年10月5日刊。台東区立中央図書館所蔵のカラー地図1枚、37.1×53.0cm。NDLサーチ書誌 **R100000094-I1189**。
- **公開**：台東区立図書館の[画像閲覧画面](https://adeac.jp/taito-lib/viewer/mp071530-100070/2021_chi_011)／[IIIFマニフェスト](https://adeac.jp/viewitem/taito-lib/viewer/iiif/2021_chi_011/manifest.json)（**CC BY 4.0**）。原図の河川・橋の細部は未判読。
- **別所蔵**：東京都立中央図書館にも1904年10月刊の同題図（色刷1枚、40×55cm、請求記号 **32・290-5037-1904**）がある。寸法差だけで別版とは断定しない。
- **出典**：[国立国会図書館サーチ・公開画像版](https://ndlsearch.ndl.go.jp/books/R100000094-I1189)／[同・東京都立中央図書館所蔵](https://ndlsearch.ndl.go.jp/books/R100000001-I13111153209868)（2026年10月31日確認）。
- **内容メモ**：小石川区の町割・道路・橋の図上比較候補。1903年版（[MAP-108](MAP-108.md)）および1896年図（[MAP-027](MAP-027.md)）との相違は未判定。旧谷端川が描かれているかは未確認。

年代（地図一覧の表記）: 1904

読図メモ: 1904年10月5日刊、台東区立図書館がカラー原図を公開。旧谷端川・橋・道路の図上判読は未実施。
