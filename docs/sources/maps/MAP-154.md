# [MAP-154] 1948年米軍空中写真 USA-M737-72（茗荷谷〜小石川・後楽北＝人参川候補谷筋南・神田川合流部）

- **書誌〔確認：GSI詳細API〕**：整理番号 USA・コース M737・写真番号 72、specification_id 189222。撮影日 **1948/01/18（昭23）**。撮影縮尺 **約1/9,980**（カメラ K-17B・焦点距離 152.700m・撮影高度 1524m）。市区名（画像中心の所属）＝文京区。
- **範囲〔確認：API四隅〕**：左上 (139.721536997, 35.720330437)／右上 (139.746909852, 35.720597354)／左下 (139.721867419, 35.699639404)／右下 (139.747233721, 35.699906118)、中心約 (139.73439, 35.71012)。**人参川候補の谷頭（35.715）から谷筋南・神田川合流部（≈35.709）までを範囲内側に含む**。M372-52（[MAP-153](MAP-153.md)）下縁（35.7123）より南を覆う。

- **内容メモ〔確認：標準版・全体オーバービュー＋谷頭／谷筋／合流部中心クロップの判読〕**：全体は**密集市街地**。**神田川が東西方向の暗い開水面帯（橋を伴う）として明瞭**に写り（≈35.709）、右（東）縁に南北方向の水面帯（江戸川系）。谷頭東側は**明るい大型の施設建物（キャンパス候補）＋矩形区画（畑地／空地）＋暗い不整形パッチ（池・樹林・影の別は未確認）**。谷筋（35.7115 付近）は**曲走する明るい道路＋矩形区画格子＋散在建物**、右下に暗いパッチ（性格未確認）。合流部（35.7085 付近）は神田川南岸の**密集小住宅格子＋曲がる路地**で、不明瞭な暗い曲線（路地か水路か未確認）。**人参川候補そのものの連続する開渠・平滑な池水面は確認できない**（検出限界）。

年代（地図一覧の表記）: 1948

読図メモ: 1948年・人参川候補谷筋南（茗荷谷谷頭→小石川・後楽北→神田川合流）。約1/9,980・0.63m/px。受水側の神田川は開水面帯として明瞭だが、支流の人参川候補は連続開渠を検出できず（密集市街・検出限界）。谷頭の矩形区画・暗いパッチは池/樹林/影の別未確認。M372-52（1947）の南を補完し神田川合流までを覆う。〔人参川候補〕（[人参川](../../人参川.md)）
