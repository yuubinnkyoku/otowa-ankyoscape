## 2026年11月2日：地籍図と別冊台帳のデジタル化番号を区別

国立国会図書館サーチでは、**地籍図**を[PID 8311636](https://ndlsearch.ndl.go.jp/books/R100000039-I8311636)、**別冊「地籍台帳」**を[PID 1242316](https://ndlsearch.ndl.go.jp/books/R100000039-I1242316)として**別々のデジタル化資料**に登録している。両書誌の「他のアイテム」欄にも相互参照がある。いずれも**1931年（昭和6年）刊、内山模型製図社編・刊、請求記号426-87**で、地籍図は52枚・40cm、別冊台帳は1冊・27cm。〔**確認：国立国会図書館の巻別書誌・相互参照**〕

[国立国会図書館リサーチ・ナビ「日本の都市地図（市街図）」](https://ndlsearch.ndl.go.jp/rnavi/maps/post_546)（**2026年10月26日更新**）は、内山模型製図社刊「東京地籍図」（**1931～1935年**の系列）を**番地・地目・面積・地価・土地賃貸価格・所有者住所氏名**を調べられる地図群と説明する。〔**確認：図書館の系列案内**〕 ただし、この一般的な系列の項目が**1931年小石川区版の全筆に揃っているかは未確認**。地籍図・台帳とも**図書館・個人送信対象**であり、地番・地目・所有者・水路敷の個別記載はまだ閲覧していない。**1931年は刊行年で、各筆の測量・変更・水路埋立ての年ではない**。〔**推定：谷端川下流の旧河道・道路敷の筆界検証に有用／未解決：原本照合**〕
