- **題簽と年代〔確認・OCR〕**: 「**天保十三寅年六月之形牛込小日向音羽町辺場末（絵図）**」＝**天保13年（1842）6月時点の牛込・小日向・音羽町周辺の「場末」の絵図であることを題簽が明示する**。〔**1842年は音羽岡場所（遊里）が天保13年に廃止された年（README §音羽・第127回の音羽遊女天保13年廃止の記録）と同年**で、場所廃止直後の音羽町周辺の町割・地割の状態を伝える絵図候補として要注意資料。〕
- **凡例の「此色堀川」〔確認・OCR・水路描写の存在候補〕**: 「**此色屋敷 此色道敷 此色寺社 此色堀川 此色町屋 此色土手 此色田畑 此色明地**」＝**彩色凡例に「此色堀川」があり、図面に水路（堀川）が特定の色で描かれていることを示す**。〔音羽町周辺の堀川の描出候補＝弦巻川（江戸名所図会以降の西側の谷川）・水窪川系の1842年の定点図候補となりうる。ただし**「堀川」の対象（神田上水・白堀・堀割のどれか、町屋の前堀か、谷川か）はOCRからは判別できず、原画像の読図・彩色確認まで特定しない**。OCRテキスト層に「上水」「弦」「水窪」「音無」の語はいずれも0件〔確認〕。〕
