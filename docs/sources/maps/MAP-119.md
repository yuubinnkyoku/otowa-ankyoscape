# [MAP-119] 『千川分水口取調絵図』

## 書誌・所在（2026-10-30、石神井公園ふるさと文化館「所蔵資料リスト」の直接確認・ai）

- [千川家文書](../gov/GOV-038.md) の絵図類の1点（同館所蔵資料リスト、地図類8番。「千川家文書絵図」と注記）。
- 所蔵資料リストの内容説明（原文）：「取水口である上保谷新田（西東京市）から巣鴨村（豊島区）までの素掘りの部分の千川上水を描いた絵図。元治元年（1864）に作成されたが、明治初期に修正・加筆されている。」
- 所蔵資料リスト：https://www.city.nerima.tokyo.jp/kankomoyoshi/bunka/nerimi.files/hurubunrisuto.pdf

## 内容メモ

- 本ファイルの段階では図面そのものは未閲覧。分水口の位置・名称が図中にどう記されるかは未確認。
- 描かれる範囲は素掘り区間（上保谷新田〜巣鴨村）であり、千川上水から谷端川への長崎村外三村分水（[GOV-005](../gov/GOV-005.md)）の分水地点はこの区間の内にある。弦巻川・水窪川方面への分水の有無の判定材料になるかは、図面の実見による。
