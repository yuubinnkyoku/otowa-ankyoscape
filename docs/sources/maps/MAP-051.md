## 2026-10-31 追加照合：国立公文書館『正保年中江戸絵図』と猫又橋の橋記号候補

- 国立公文書館デジタルアーカイブ『正保年中江戸絵図』（内閣文庫、請求番号 **177-0665**、1鋪）：https://www.digital.archives.go.jp/file/1795289.html
- **所蔵目録の直接確認**：現存本は**嘉永6年（1853年）の写本**。記載屋敷名から、描かれた江戸の状況を**正保元〜2年（1644〜1645年）**頃と推定する。丘・林は緑、田はねずみ色、道は黄、**橋は赤**とする。原図の橋名や実測精度を保証する説明ではない。
- **二次読図（2021年以前の地域史記事）**：[「千石の坂道」猫又坂](https://ma-maison.sakura.ne.jp/hill/sakamichi/sakamichi5_sengoku.html) は、旧小石川（谷端川）を渡る猫又坂下付近の**赤い橋記号**を後世の猫又橋に比定する。
- **判定保留**：原図の該当箇所を本調査では高精細画像で独立判読していない。**1644〜45年に「猫又橋」の名が存在した、同一橋体が後世まで続いた、当時の河道中心線が現道と一致した**とは断定しない。橋記号・周囲の地物と現代位置の照合が必要。資料の状態は引き続き「所在のみ」。
