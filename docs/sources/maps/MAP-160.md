# [MAP-160] 『大東京最新明細地圖：隣接町村合併記念』（1932.12）

- **所在〔確認：目録頁を直接確認／図本体の読図は未実施〕**：[立教大学図書館 古地図デジタルライブラリ「地図にみる立教」](https://library.rikkyo.ac.jp/digitallibrary/kochizu/contents/con_04_daitokyo.html)。**1932.12、東亰日日新聞發行所**（[BLOG-136](../blogs/BLOG-136.md)経由で所在を確認し、目録頁を直接確認したもの）。
- **位置づけ〔推定〕**：東京市が周辺町村を合併した直後（1932年10月の区境確定直後）の明細図。**蟹ヶ窪・水久保などの旧字名の範囲特定**に使える。弦巻川（高田町による1932年暗渠化）・谷端川・水窪川の水路描写の有無は、1932年という暗渠化前後の境界年次だけに検証価値が高い。
- **注意**: 同ライブラリには『町名早見番地入東京市全圖』（1929）・『模範新大東京全圖』も公開されており、水路描写の年代断面として活用候補〔確認：ライブラリ目次〕。
