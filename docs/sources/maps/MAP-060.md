# [MAP-060] 『千川上水路図』

年代・所在（地図一覧の表記）: 明治17年頃の図への言及あり。複製は「豊島区地域地図第6集―近代（千川上水路図）編」

状態・言及箇所: 二次読図で、旧巣鴨村分水が明治17年頃の本図からは消えるとされる。原図は未照合
- **追記（2026-11-24）〔確認＝目録レベル〕**: 東京都公文書館（江戸明治期史料・資料ID [000100783](https://www.archives.metro.tokyo.lg.jp/detail?cls=collection_01&pkey=000100783)）に史料名「**千川上水路図**」の写図が1枚現存する＝請求番号**ＺＨ－４４５**（大整理番号6364）・配架220B100-020203・シリーズ名1＝**江戸図・江戸関係図（地図）**・シリーズ名2＝**陸地測量部地図類**・シリーズ名3＝水道河川橋梁・原本・複写可（電子コピー不可・撮影可）。〔**陸地測量部地図類系列であることと、本項目の「明治17年頃」推定（陸地測量部の前身は1884〔明治17〕年組織改編）が符号するが、同一の図かどうかは図面未見のため断定しない**。原図の所在の有力候補として記録するのみ〕。
