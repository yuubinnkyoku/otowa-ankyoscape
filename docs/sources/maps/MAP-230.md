## repo内位置づけ〔観察・読図未実施・いずれも断定しない〕

1. **[BOOK-234](../books/BOOK-234.md)（小平市史）の引用原典の所在特定〔repo初出の到達点〕**: 同市史が千川上水桜堤の原典引用として挙げる③仲田惟善『東都近郊図』（文政8・1825）「**上水の両岸五十余町ノ間、桜樹数百株アリ、是元文年中ヨリ延享ノ頃迄年々官ヨリ植シメラレル処ナリ**」（同・80頁）＝repoでは引用経由のみで現物の所在・画像公開は未特定だった〔repo grepで「050-2」「4300036994」0件を確認〕。本資料の特定により、①大田南畝『調布日記』（文化5・1808）②同『向岡閑話』（文化6・1809）③東都近郊図（文政8）の**桜堤原典3点のうち③の所在が画像公開付きで固定された**。ただし市史の引用文言が本図のどこに記載されているか（本文冊子が別か・図上Remarksか）は画像判読（human閲覧）まで確認できない〔制限②参照〕。
2. **範囲文言＝四河川全流域を含む近郊図〔確認: 注記文言の地名列挙〕**: 描画範囲が「東ハ小金舟橋・南ハ羽田神奈川・西ハ府中日野・北ハ大宮岩槻」＝**千川上水全域（府中・日野側の水元から小石川の流末まで）・弦巻川・水窪川上流域（高田・雑司ヶ谷）・谷端川流域（巣鴨・滝野川）をすべて含む江戸近郊広域図**〔観察: 地名列挙からの区域推定〕。
3. **用水略画の凡例文言**: 「**小社或ハ用水ノ如キニ至テハ畧セシモノアリ**」＝堂社の方位・川流の広狭は真景を得ず、**小社や用水に至っては省略した旨**を序文言で明記〔確認: 注記欄の転記文言〕。江戸期近郊図における用水の描写水準（省略あり）を示す図側文言で、千川上水・四ヶ領用水等が図上でどの精度で描かれるかの読図前の注意書として記録。千川上水が本図で「略」されている可能性もあるため、図上千川上水の非記載をもとに実在を疑う根拠にはならない〔観察〕。
4. **千川上水「口」周辺の読図候補**: BOOK-234引用文言の「小川村の地内より千川上水の口まで六十町の間」桜並木と、[GOV-341](../gov/GOV-341.md)（境水衞所〜小川水衞所間櫻並木）の対校資料として、図上の小金井桜堤・取水口（保谷樋口〔GOV-004〕より上流の千川上水の口）の記載の有無を確認するのが読図の第一目的〔次回以降・human閲覧〕。
