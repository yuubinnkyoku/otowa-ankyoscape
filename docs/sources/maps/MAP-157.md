# [MAP-157] 明治44年逓信局地図（郵便地図）の所在

- **郵政博物館の所蔵〔確認：所在〕**：[郵政博物館収蔵品](https://postalmuseum.jp/collection/genre/detail-362609.html)に「**四十四年調査東京十五區番地界入地圖 全拾五枚**」（東京逓信管理局・明治44年・絵図・地図）の所在〔[BLOG-066](../blogs/BLOG-066.md)が依存図と明記した「明治44年逓信局の地図」の**原典候補の所在特定**。十五区図そのものは豊島郡巣鴨村を含まない（15区の範囲は現在の千代田・中央・港等）が、同時期・同庁に近傍町村版が存在する〕。
- **近傍34町村版の書誌〔確認：書誌〕**：CiNii [BA38620103](https://ci.nii.ac.jp/ncid/BA38620103)「東京市十五区・近傍34町村」（人文社編集部編）の書誌に「**東京郵便局明治40年東京市15区・東京逓信管理局明治44年近傍34町村番地界入**」の記載〔明治44年「近傍34町村番地界入地圖」の存在を示す複製書誌。**豊島郡巣鴨村（谷端川流域・[BLOG-066](../blogs/BLOG-066.md)の雲雀ヶ谷戸・下り谷の読図・[BLOG-061](../blogs/BLOG-061.md)紀要引用の明治44年巣鴨村全図）は近傍34町村に含まれる**ため、水徒然の依存図の本命候補〕。
- **利用状況〔確認〕**：郵政博物館は**2026年4月1日から当面の間、照会回答・閲覧・貸出・画像データ提供・撮影の全サービスを一時停止中**〔現在の利用可否の記録。再開後の閲覧が次の一手〕。
- **制限〔未解決〕**：①図の実見・該当図幅（巣鴨村・池袋村）の確認は未実施。②明治44年「近傍34町村番地界入地圖」と、[BLOG-061](../blogs/BLOG-061.md)に横山恵美紀要から引用された「**明治44（1911）年の巣鴨村全図**」の異同（同一図か別図か）は未確認〔両者とも明治44年・巣鴨村を描くが、紀要引用の「巣鴨村全図」が逓信局図の一部か村製作の別図かは断定しない〕。

## 三河川への使い方

- 谷端川支流（下り谷・雲雀ヶ谷戸・瓢箪池）と谷頭湧水の読図座標源として明治44年地図を用いる流れ（[BLOG-065](../blogs/BLOG-065.md)・[BLOG-066](../blogs/BLOG-066.md)）に対し、原図の所在・正式書誌（東京逓信管理局編）を初めて特定した。谷端川の旧流路・小支流の描図確認の一次資料。
