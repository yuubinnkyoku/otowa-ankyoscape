# [MAP-116] 『東京五拾区縮図 小石川春日町 その他 27』

- **書誌・所蔵〔確認：所蔵機関の公開目録とNDLサーチ〕**：公益財団法人特別区協議会「特別区自治デジタルアーカイブ」、資料番号 **ATD-1**、資料コード **1939707**、書誌番号 **24520**。図名は『東京五拾区縮図 小石川春日町 その他 27』、製作年 **1869年（明治2年）**、寸法 **60×85cm**。原本所在は特別区自治情報・交流センター。公開条件は **CC BY 4.0**。出典：[所蔵機関の目録](https://adeac.jp/tokyo-23city/catalog/ct00000078)／[国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/books/R100000094-I1530771)。
- **成立背景〔確認：所蔵機関の解説〕**：特別区協議会は、**1869年3月に東京府が江戸期の982町を50区（番組）に再編**し、戸数・人口調査の報告資料として本図が作成されたとみられる、と説明する。小石川春日町は **第27番組の図名に明記**される。出典：[特別区協議会「東京五拾区縮図」解説](https://www.tokyo-23city.or.jp/chosa/tokei/kochizu/50kusyukuzu-index.html)。
- **公開原図〔確認：閲覧入口〕**：[IIIF図版ビューア](https://adeac.jp/tokyo-23city/viewer/ct00000078/dg00000078)／[IIIFマニフェスト](https://adeac.jp/viewitem/tokyo-23city/viewer/iiif/dg00000078/manifest.json)。**図面の細部は未判読**であり、町界・水路・橋の描線や図郭内の音羽谷・小石川（谷端川）との対応は未確認。
- **研究上の位置づけ〔推定〕**：1854・1857年の江戸切絵図と1873年の沽券地図・1883年測量の五千分一東京図の間を埋める、**1869年の旧小石川区周辺の町割・道路・水路の比較候補**。**小石川春日町という図名だけから旧谷端川（西大下水）・水窪川・弦巻川が描かれているとはいえず、特定の橋の存在や流路成立年代を立証するものではない**。同図が1869年当時の実測状態をどの程度反映するかも未検証。

年代（地図一覧の表記）: 1869年（明治2年）

読図メモ: 特別区協議会所蔵「東京五拾区縮図」第27番組の小石川春日町図（1869年、60×85cm、ATD-1）。図面の河道・町界は未判読。旧小石川下流の切絵図・1873年沽券地図・1883年図との比較候補。
