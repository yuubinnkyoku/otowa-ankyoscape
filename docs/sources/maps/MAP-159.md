# [MAP-159] 『大東京區分圖（豐島區詳細圖）』（1947.2）

- **所在〔確認：目録頁を直接確認／図本体の読図は未実施〕**：[立教大学図書館 古地図デジタルライブラリ「地図にみる立教」](https://library.rikkyo.ac.jp/digitallibrary/kochizu/contents/con_08_toshima.html)。タイトル読み「ダイトウキョウ クブンズ トシマク ショウサイズ」、**1947.2**、[東京]、立教大学図書館所属古地図（2018年度購入資料のデジタル化・公開）。
- **位置づけ〔推定〕**：1947年2月＝終戦直後・豊島区成立直後の区詳細図。この時点で谷端川（BLOG-135の1948年護岸着手前）・水窪川（BLOG-089の昭和8年頃暗渠化後）・弦巻川（1932年暗渠化後）がそれぞれ開渠として描かれるか、消えているかは**谷端川の残存開渠区間と水窪川暗渠化時期（昭和8年頃説）の両方の検証資料**になりうる。
- **課題**: 本図のオンライン画像で谷端川（特に千早〜長崎〜西池袋）・水窪川上流（蟹ヶ窪〜根津山周辺）・弦巻川（雑司が谷）の水路描写を読図し、[MAP-013](MAP-013.md)系の昭和初期地図群と突き合わせる。
