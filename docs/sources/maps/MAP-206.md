- **書誌〔確認: TOKYOアーカイブ詳細頁・2026-11-21〕**: 「**神田上水々元繪圖**」（名称表記のまま・年代欄なし）。**折本**（大きさ欄は空欄）。**東京誌料**文庫・請求記号**760-26/東760-026**・資料コード**4300346398**。TOKYOアーカイブ [detail?tilcod=0000000015-00215097](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000015-00215097)。**画像の使用条件＝パブリックドメイン**。画像は**全10コマ**が同アーカイブでインターネット公開されている（画像リストAPIで確認・第233回）。フル解像度JPEGの取得可。
- **資料解説文言〔確認: アーカイブ詳細頁の「資料解説」欄〔出典表示: 『第1回江戸資料展』図録解説p.19〕〕**: 「**井之頭の池から途中の橋等の名を記入し､関口大洗堰までを描き、最後に水道に関する高札をのせてある｡神田上水は関口から取水し、開渠で今の後楽園の所の水戸徳川邸に入りそれから地中を通し、水道橋の下流で神田川を掛け樋で渡して江戸の北半部に給水していた｡**」〔図録由来の解説文言として記録。展示解説レベルであり一次文言ではない〕。
- **内容の位置づけ〔観察・読図未実施〕**: 「**井之頭の池→（途中の橋等の名を記入）→関口大洗堰**」の区間図＋末尾に**「水道に関する高札」**を載せた体裁。**「水道高札」の図示**は repo既出の高札文言群（[BOOK-147](../books/BOOK-147.md)『上水記』系・[GAZ-035](../gazetteers/GAZ-035.md)桜木町の万年樋高札候補等）に対応する**図上の高札記録候補**〔高札文言の本文は未確認・読図待ち〕。「々元」の字面は「**水元（水源）**」の繰り返し符号表記と読める〔書名の読みは推定域〕。
- **導水形状文言（関口取水→水戸徳川邸→地中→水道橋下流の掛樋→江戸北半部給水）の系列〔観察〕**: [GAZ-048](../gazetteers/GAZ-048.md)（風土記稿・関口から水戸殿舘地に入り埋樋で御茶水の萬年樋）・[MAP-205](MAP-205.md)の資料解説（井ノ頭→関口→御茶ノ水まで開渠→掛樋→暗渠）と**同じ導水形状記述**を、後楽園（水戸徳川邸）への**開渠入地**と**水道橋の下流**で掛樋渡しという**給水経路単位**（江戸の北半部）まで含めて述べる点が詳細〔図録解説の観察として記録〕。水戸邸に入る区間を「開渠で入り**それから**地中を通す」と述べる点は、[MAP-205](MAP-205.md)の解説（御茶ノ水まで開渠）と比べて**後楽園区間の伏せの位置**が一段具体的〔解説間の対校案件・両図録文言の水路描写への反映は読図確認後に判断〕。
- **請求記号の系列〔観察〕**: 760-26/東760-026は[MAP-205](MAP-205.md)（760-21/東760-021・神田上水絵図）と**同じ東京誌料の760番台（水路・上水絵図帯）**で、隣番関係。同一文庫内に神田上水関連の絵図が複数所在することになる。
