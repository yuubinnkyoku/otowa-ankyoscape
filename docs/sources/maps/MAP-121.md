# [MAP-121] 西川光通編『小石川區』（大日本改正東京全圖・第10号）

- **原版の書誌〔確認：国立国会図書館サーチ〕**：西川光通編、西川光穂刊『**小石川區**』（シリーズ『大日本改正東京全圖 = The map of Tokio Japan』**第10号**）、**[1878年3月]**、**縮尺1:2,400**、地図1枚 **122×206cm**（折りたたみ26cm）、英語併記。国立国会図書館請求記号 **YG913-962**、書誌ID **000010125400**。目録では**紙資料**として所蔵され、当該図のオンライン原図閲覧は確認できていない。出典：[NDLサーチ・個別書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000010125400)。
- **系列の性格〔確認：NDL地図室の案内〕**：NDL「[日本の都市地図（市街図）](https://ndlsearch.ndl.go.jp/rnavi/maps/post_546)」は、1878～1879年の『大日本改正東亰全圖』系列を旧東京15区対象、**番地・間口・奥行・坪数を掲載**する地図として説明する。縮尺は系列全体で**1:2,400／1:7,400**。ただし、**各項目が小石川区図の全筆に揃うかは原図未確認**。同案内では**建物形状の掲載なし**と整理する。
- **復刻版の所在〔確認：出版社の刊行案内〕**：科学書院は**2002年5月**刊『**明治初期東京地籍圖集成**』（ISBN **4-7603-0287-5**）を、**西川光通・西川光穂編、1878～1879年刊の原図系列の復刻**と説明する。地番・面積・小道などを調べられるとし、**建物輪郭も掲載**と説明するが、この点はNDL系列案内の「建物の形状×」と**記述が食い違う**。**小石川区図の原画像を読んでいないため、建物輪郭の有無を確定しない**。出典：[科学書院・刊行案内](https://kagakushoin.com/products/detail.php?product_id=534)。
- **研究上の位置づけ〔推定〕**：1873年『第四大区沽券地図』と1883～1884年測量の五千分一東京図の**間を埋める、旧小石川区の大縮尺・地番入り地図**。**谷端川（小石川・西大下水）下流、音羽谷における水窪川・弦巻川の下流部**の地割・道路・水路敷を、1912年・1931年の地籍資料と対照する候補。ただし**原図の図郭・水路線・橋・筆界は未判読**で、各河川が描かれること、河道と筆界が一致すること、1878年当時の測量・施工実態を示すことは未確認。
- **未解決**：原版または2002年復刻版の小石川・音羽・小日向部分を閲覧し、河道・地番・間口寸法の描写を1873年沽券地図・1883年測量図と比較する。**[1878年3月]はNDLが付した刊年であり、個別の河道変更・暗渠化・水路敷成立年月ではない**。
