## repo内位置づけ〔観察・読図未実施・いずれも断定しない〕

1. **千川上水は玉川上水からの分水**: repo既収録の通り、千川上水の取水は玉川上水からの分水で、[GOV-004](../gov/GOV-004.md)保谷樋口（引水樋）や [BLOG-113](../blogs/BLOG-113.md)明治4年境橋上流への分水口変更（旧分水口の比定を含む）が分水点の核心資料。本図が玉川上水の**全線**（羽村〜四谷）を描く以上、千川分水口域（保谷〜練馬付近）が必ず紙面に入る〔確認: 全線を記したという解説文言に基づく図面外観の推定。当該コマの描写内容は未見〕。
2. **23コマ中の分水口域コマの特定が次の読図単位**: 保谷樋口（現在の保谷一丁目付近）〜境橋（武蔵境）〜練馬の区間が何コマ目に当たるかをまず特定し、zoom画像で樋・堰・分水記号の有無を確認する。工程表・村々の順序（羽村→四谷の並び）からコマ番号は推定可能〔仮説: 実装は次回実行で〕。
3. **[MAP-205](MAP-205.md)（神田上水絵図・760-21/東760-021・折本15.4×290.6cm・全10コマ）と同文庫の隣番帯**: 760-20（玉川上水絵図）と760-21（神田上水絵図）は東京誌料の上水絵図として同文庫で連番管理されている〔確認: 請求記号の並び〕。江戸二大上水の全線折本絵図ペアとして読図・対校の価値がある。
4. 千川上水自体の絵図（[BLOG-113](../blogs/BLOG-113.md)千川上水絵図・『東京市史稿』上水篇第1付録）とは別の、**分水源側の図上証拠**として位置づける。本図に千川分水の明示的記入（樋・口の文言）があれば、GOV-004（保谷樋口）の文言資料との図上照合が進む〔期待値の記述であり、記入の有無は読図まで確定しない〕。
