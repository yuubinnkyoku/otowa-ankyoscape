# [MAP-025] 第一軍管地方2万分1迅速測図原図

年代（地図一覧の表記）: 1880–1886

地図（表記ゆれを含む）: 第一軍管地方2万分1迅速測図原図（フランス式彩色図）

## 読図（地図一覧から移行）

- 水窪川: ○
- 弦巻川: ○
- 谷端川: ○
- 人参川候補: —

読図メモ: 3河川域を含む関東921面。水窪川上流（水久保新田周辺）が主に畑で字名なしとの既存観察あり（[2026-08-31追加史料](../../2026-08-31・水窪川・弦巻川の追加史料.md)）。**どの複製・画像で観察したか区別せずに読図判定しない**。彩色原図ビューア: [国土地理院地図・空中写真閲覧サービス](https://service.gsi.go.jp/kochizu/app/map/france_saisyokuzu)／[解説頁](https://service.gsi.go.jp/kochizu/app/about/france_saisyokuzu)。モノクロ復刻版の重ね合わせ: [農研機構 歴史的農業環境閲覧システム](https://habs.rad.naro.go.jp/)（東京リンクあり、CC BY 2.1 JP）

読図記録（2026-10-26、太郎が東京時層地図で彩色原図を確認した判定）:

- 水窪川・弦巻川・谷端川はいずれも描かれている。人参川は描かれていない。
- 水窪川と弦巻川は、接続せず分かれて描かれている。
- 丸池そのものの描出はなさそうだが、弦巻川の青線が途切れる位置は西池袋公園（丸池跡）のところにあたる。
- 弦巻川の下流の線は神田上水（神田川）まで届いていそう（断定まではしない観察）。
- 水窪川の青線が始まる位置は北緯35.726176・東経139.720294（東京時層地図上の読み取り。現在の地名では豊島区東池袋4丁目付近）。
