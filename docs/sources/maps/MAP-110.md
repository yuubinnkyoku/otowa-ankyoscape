# [MAP-110] 内山模型製図社『五千分之一東京市地図』小石川区関係図葉（1929年3月）

- **書誌・年代〔確認：公的所蔵目録〕**：内山模型製図社編・刊、**1929年（昭和4年）3月**、**縮尺1:5,000**。東京都立図書館の地形図目録（2023年版）では、第6・7・12・13図の内容細目にそれぞれ**「小石川区（一部）」**がある。図葉の書誌を確認したもので、測量日や水路表示を確定したものではない。
- **図葉・資料番号〔確認：所蔵目録〕**：第6図（本郷・下谷・小石川の各区の一部、資料コード **1128746294**）、第7図（下谷・本郷・小石川・浅草・神田・麹町・牛込の各区の一部、**1128746300**）、第12図（小石川区の一部、**1128746356**）、第13図（小石川・牛込の各区の一部、**1128746365**）。第6図の個別書誌は**55×79cm、請求記号 DT/0・290/3089/6**とする。
- **公開・出典〔確認〕**：東京都立図書館『[地形図目録（5千分1地形図）](https://www.library.metro.tokyo.lg.jp/search/uploads/chizumokuroku202306_5-1_chikeizu_zenhan.pdf)』（**2023年版**、内山模型製図社の第1～17図一覧）／同館TOKYOアーカイブ『[第6図・個別書誌と画像閲覧画面](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000008-00001469)』（原図刊行**1929年3月**、画像利用条件はパブリックドメイン）。
- **研究上の意味〔推定〕**：1903・1904年の小石川区全図（[MAP-108](MAP-108.md)・[MAP-109](MAP-109.md)）、1921・1929年図を引用する踏査記録（[MAP-043](MAP-043.md)）、1931年の小石川区地籍図（[MAP-045](MAP-045.md)）との**中間年代・別系統の縮尺1:5,000の比較候補**。とくに旧谷端川（小石川）の下流・支流、橋、道路・宅地の描写を調べる手掛かりとなりうる。
- **留保〔未解決〕**：**図葉の原画像から水路・橋の線を直接判読していない**。各図葉が旧谷端川のどの区間を実際に含むか、1903・1904年版との異同、1929年の刊行年と図面の測量・修正年の関係は未確認。「小石川区（一部）」の目録表示だけで河道が描かれるとは断定しない。第6図以外の個別画像公開URLも未特定。既収録の「図名未詳の1929年図」（MAP-043）と同一資料だとも断定しない。

年代（地図一覧の表記）: 1929

読図メモ: 1929年3月刊の1:5,000図。小石川区を含む第6・7・12・13図の書誌を確認。図郭の細部・旧谷端川の描線は未判読。
