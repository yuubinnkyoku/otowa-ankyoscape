# [BOOK-001] 『失われた川を歩く 東京「暗渠」散歩 改訂版』

- 本田創編著『失われた川を歩く 東京「暗渠」散歩 改訂版』実業之日本社、2021年。
- ISBN 978-4-408-33965-8
- 出版社書誌: https://www.j-n.co.jp/books/978-4-408-33965-8/
- 弦巻川・水窪川・谷端川の名称、流路、暗渠に関する二次資料として使用。
- 内容メモ（2026-10-26、利用者の読書メモより）：弦巻川の上流部は布引川とも呼ばれていた。雑司ヶ谷霊園の西側から弦巻川に注ぐ支流があった。
- 内容メモ（同）：水窪川は上流部が日の出川、下流部が音羽川と呼ばれ、江戸時代には東青柳下水とも呼ばれた。
- 内容メモ（同）：谷端川は文京区内では小石川、氷川とも呼ばれた。谷端川は千川上水から分水を受けていた。暗渠化は下流部が1934年、全体が1964年。
