# [BOOK-092] 『板橋区の歴史』（名著出版、1979年）

- **書誌〔確認: NDL書誌〕**: **萩原竜夫（1916-1985）・伊藤専成（1907-） 文、東京にふる里をつくる会 編『板橋区の歴史』、名著出版、1979年**（東京ふる里文庫）。NDL書誌ID [R100000002-I000001435004](https://ndlsearch.ndl.go.jp/books/R100000002-I000001435004)。巻末に板橋区略年表・歴史参考文献〔repo初出〕。
- **千川上水関連〔確認: NDLレコードの索引語〕**: NDLサーチの「千川上水」検索で本書のレコードが現れる（レコードの件名標目に千川上水を含む）〔板橋区は千川上水の下流域（旧千川上水が谷端川放水路・石神井川に接続する地域）を含むため、区史レベルの千川上水記述が予想される。本文は未確認のため千川・谷端川の記述内容は判断しない〕。
- **位置づけ〔観察〕**: 板橋区の通史として、[GOV-082](../gov/GOV-082.md)〜[GOV-084](../gov/GOV-084.md)系の千川幹線・谷端川放水路の下流側地域史の基礎資料候補。著者伊藤専成は板橋区史編さんに関わった民俗・地方史研究者（萩原竜夫は民俗学）。
