# [BOOK-183] 東京名物志（1901）— 雑司谷八境の全8項目の1901年継承〔第147回〕

- **書誌〔確認〕**: 『東京名物志』（**公益社・1901年**。請求記号116-144・書誌ID000000521685。NDL次世代デジタルライブラリー [book/900924](https://lab.ndl.go.jp/dl/book/900924)）。明治34年の東京の名物・名所を區・地名ごとに列挙する案内記。
- **雑司谷八境の全8項目〔確認・文言候補〕**: 威光山（法明寺）の条——「**雜司谷に八境を選べるものあり 曰く 星跡〓水、威光山花、御嶽夜雪、姿見橋鷺、絃卷川螢、三島神籬、鼠山木玉、池箇谷月、と此勝ありて此寺あり**」＝**雑司谷の八境として「星跡〓水（星跡の清水・OCR崩れ）・威光山花・御嶽夜雪・姿見橋鷺・絃卷川螢・三島神籬・鼠山木玉・池箇谷月」の8項目を1901年時点でまとめて引く記録**。〔**①[BOOK-144](../books/BOOK-144.md)（遊歴雑記五編・文政7年草稿）の「雑司谷八景」から明治34年（1901）まで八境選定が連続していたことの定点**＝八境系譜の明治期の継承記録。**②「星跡〓水」＝星跡の清水の井戸名が八境の第1項として1901年にも語られた用例**＝対照表「星谷の井／星跡の清水」行・「星の井」行の系譜への1901年の追加 datapoint。③「姿見橋鷺」＝[BOOK-159](../books/BOOK-159.md)の姿見橋（池の干潟）の景観と対照。④「絃卷川螢」＝弦巻川の蛍の八境文言が文政7年（BOOK-144の「絃卷川螢」）と一致。⑤「池箇谷月」「鼠山木玉」＝池ヶ谷（丸池の谷）・鼠山の地名の八境文言（[GOV-261](../gov/GOV-261.md)系の鼠山・[BOOK-144](../books/BOOK-144.md)の池ヶ谷と対照）。八境の選定者・底本（文政期の八景からの引用か）は本書では不明。〕

## 制限・未解決

- ①「星跡〓水」の原字（星跡の清水・星跡之水等）はOCR崩れで要照合。②八境の底本（文政7年草稿の遊歴雑記か、別の八景選定か）の特定は未了で、項目名の異同（八景/八境の呼称差）も原典对照待ち。③威光山＝法明寺の比定は現行の寺名（法明寺）による（文脈上「北に雜司谷の威光を擧ぐべし…日蓮宗中本山」とあるので威光山法明寺で整合する）。④八境各項目の比定（三島神籬の三島神社等）は本書では行わない。
