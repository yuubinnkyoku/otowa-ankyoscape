# [BOOK-167] 東京市史稿 変災編第1（震災編・大正3年頃）— 江戸川岸・白堀上水の地震被災記録群

- **書誌〔確認・刊年は候補〕**: 東京市役所編纂『**東京市史稿 変災編第1**』（震災編。NDL次世代デジタルライブラリー [book/1915621](https://lab.ndl.go.jp/dl/book/1915621)。大正3年7月23日寄贈本の蔵印から**大正3年（1914）刊候補**〔書誌の確定は要照合〕）。江戸期の地震・震災の一次史料（『なゐの後見草』・東京府震災被害表・関谷博士調査引用等）を編年集成。**OCR崩れが全編で激しく文言は要原文照合**。〔[BOOK-130](BOOK-130.md)（変災編第2・享保13年出水）・[BOOK-133](BOOK-133.md)（変災編第5・万延元年出火）の前巻に当たる〕
- **天明2年（1782）7月地震の「小日向の江戸川岸」の地割れ〔文言候補・repo初出・要原文照合〕**: 『なゐの後見草』経由——「**小日向の江戶川岸三尺ほども震ひらきけり**」〔**江戸川（神田川）の河岸（小日向側）で3尺ほどの地割れ（震ひらき）が生じたという天明2年地震の被災観察記録**＝江戸川岸の地盤（旧河道・埋立地帯）の地震被害の datapoint。repoで江戸川岸の地震被害の天明期の文言は初出〕。
- **安政2年（1855）大地震の江戸川・白堀関係の文言群〔文言候補・repo初出群〕**: ①逃走路の記述——「**牛込山伏町·通寺町…改代町·石切橋を過ぎ、白堀上水にそひて小日向切支丹組屋敷に入り**」〔**震災時の移動経路の描写に「白堀上水に沿って」という現地のランドマーク表現が使われている＝1855年時点で白堀上水（神田上水の小日向〜小石川区間の通称）が実在の水路として認識されていた観察文言（repo初出）**＝[地名対照表](../../地名・河川名対照表.md)の白堀行の通時系列に1855年の定点を追加〕。②「**江戶川通往還之路、河岸行き隨ひ中程割れる、又有切橋…河岸付之方半分程段違ひに成りて貳尺程下る**」〔**江戸川通りの道路の中程の割れと河岸側の約2尺の段違い＝江戸川沿いの地盤の地震変状の被害記録**〕。③隆慶橋手前の出火の記録（OCR崩れ著しく文言は要照合）。④関谷博士調査引用の震度分布——「**神田淵ノ跡（小石川大下水·江戶川尻ヨリ、舊小川町、駿河臺ト飯田町田安臺地ノ中間一面）**」＝**震度大区域が「神田淵の跡」（江戸川尻・小石川大下水から駿河台・飯田町の田安台地の中間の一面）に当たること**＋「**前記江戶川筋神田淵跡ノ九百人**」〔**安政地震の武家死者約900人が「江戸川筋（神田淵の跡）」に集中したという被害集計の文言**＝神田淵（江戸川下流の低湿地）の地震脆弱性の集計側記録〕。⑤震度中区域のリストに「**江戶川筋（小石川區牛込區）**」「**白山下**」〔江戸川筋が震度中区域にも挙げられること〕。
