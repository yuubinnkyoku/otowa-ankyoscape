# [BOOK-176] 英字新選東京方方（1872）— 関口水車のローマ字付き地図記載〔repo初出・第139回〕

- **書誌〔確認〕**: 『英字新選東京方方（英字新撰東京方角）』（松井某著・誠之堂梓・明治5年＝1872年9月刊。外国人向けの東京案内・地図帙）。NDL次世代デジタルライブラリー [book/764197](https://lab.ndl.go.jp/dl/book/764197) のOCR全文を確認。**OCRの崩壊が激しく（ローマ字と漢字の混植の判読不良）、文言の采用は地図画像の直接照合後のみとする**。
- **関口水車の地図ランドマーク記載〔確認・repo初出・時系列の補間〕**: OCRに「**関口水車（芭（?）飯田町九）シセキグチテマタ（?）**」の文字列が見える＝**関口水車が地図上のランドマークとして記載され、「シセキグチ」＝SEKIGUCHI（Sekiguchi）のローマ字（片仮名転写）が併記**されていると読める（OCR崩れのため文言は候補。地図画像で記載位置・綴りを直接確認する必要がある）。**関口水車の通時系列に1872年（明治5年）の存在記録を加える補間点**＝[GOV-250](../gov/GOV-250.md)系の安永5年（1776）の水車争論→[GOV-262](../gov/262.md)系の明治2年（1869）の水車行政→**明治5年（1872）の地図記載**→[MAP-1xx]系の1912年地籍図の水車記号という系列のうち**明治初頭の空白を埋める datapoint**。外国人向け案内のランドマークに採られたことは、**関口水車が江戸末期〜明治初頭の名所・目印としての認知度を持っていた**ことを示唆する（水車の稼働の実態は地図記載だけでは断定しない）。
- **陰性記録〔確認〕**: 千川上水・神田上水の流路自体の記載（水路の地図表現）はOCRでは読み取れなかった（地図画像の照合課題）。
