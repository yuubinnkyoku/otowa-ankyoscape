# [BOOK-190] 土地概評価 戸塚町（1922）— 字名「馬尿川」と窪地構造〔第160回〕

- **書誌〔確認〕**: 東京興信所『土地概評価』シリーズの戸塚町冊。NDL次世代デジタルライブラリー [book/921572](https://lab.ndl.go.jp/dl/book/921572)。奥付文言「**大正十一年三月十(一)日發行**」（列崩れを含む）＋「**發行所…東京市日本橋區三代町一番地 東京興信所**」＝**発行大正11年（1922）3月を奥付レベルで確認**できる数少ない同シリーズ冊。[BOOK-109](BOOK-109.md)〜[BOOK-116](BOOK-116.md)の未登録巻。**引用はOCR由来・要原文照合。**
- **字名「馬尿川」の文言〔確認・文言候補・repo初出の字名〕**: 「**字、馬尿川一〇七〇-一〇七六番地(大字源兵衛字向原と秣川との間に挾まれたる飛地 高田馬塲驛を距ること四丁許りの窪地なり)**」＝**①字「馬尿川」（番地1070〜1076）が戸塚町の字名として1922年に存在した、②その位置は大字源兵衛の字向原と「秣川」に挟まれた飛地で、高田馬場駅から約4丁の窪地**という字名・位置・地形の三点を備えた文言〔**「馬尿川」という字名はrepo全体で未収録**〔[地名対照表](../../地名・河川名対照表.md)に新設〕。1931年の[BOOK-149](BOOK-149.md)（戸塚町誌）が小字名リストに「**馬場崎自一〇四一番至一〇六九番 馬尿川自一〇七〇番至一〇七六番 川向自一〇七七番至一〇七八番**」と同番地で採録し、かつ「**馬尿川は飛地にして源兵衞字向原に入る、秣川と同じ流れに沿ひ、秣川の名に因ぬるものであらう**」と地名由来（秣川に因む）を記すのと**番地・位置で整合する先行（1922年）の字名記録**〕。
- **窪地による二分の文言〔確認・文言候補〕**: 「**中部即ち大字源兵衛及び諏訪は紀念碑附近より鐵道線路附近に至る間にして 馬尿川の窪地によりて更に東西に二分せられ**」＋「**大字、諏訪 馬尿川の窪地の東西に在る高臺**」＋「**字中通八九-一七八番地(馬尿川の窪地の東西に跨る地域にて東南部に諏訪神社あり…中央の窪地には中流以下の住宅あり又極稀に田地あり)**」＋「**川向一〇七七-一〇七八番地**」＝**馬尿川の窪地が大字源兵衛・諏訪を東西に二分し、字中通が窪地を東西に跨ぐ構造**という1922年の微地形観察〔馬尿川の窪地＝現在の新宿区西早稲田〜高田馬場間の窪地（神田川南岸の支流秣川の谷筋候補）。窪地の田地・中流以下の住宅という記録も土地利用史の定点〕。
- **位置づけ〔観察〕**: ①「馬尿川」は字名であり、独立の川の現勢とは限らない（[BOOK-149](BOOK-149.md)の「秣川と同じ流れに沿ひ、秣川の名に因ぬる」の解釈＝秣川（諏訪の森弁天池発源・源兵衛地内で神田上水に合流）の流れに沿う窪地の字名）。②ただし1922年の冊は「秣川」を地形名として（区切りなく）用いており、秣川の流路の実体の1922年の残存状況（開渠・埋立）は本冊からは判別できない。③番地1070〜1076の飛地が1931年まで同一番地で存続したことは、字名の安定性から位置比定（高田馬場駅の南約4丁＝現在の新宿区諏訪町〜西早稲田の谷筋）をかなり具体化できる〔原画像照合と地図照合が前提〕。

## 制限・未解決

- ①OCR由来の文言で、字名・番地・地価数値は原画像照合を要する（特に「挾まれたる」周辺の列崩れ）。②「馬尿川」の語源（馬尿＝馬の小便の窪地という里俗語か、秣川の変形か）は本冊からは確定できない（[BOOK-149](BOOK-149.md)の秣川由来説との対校は保留）。③馬尿川の窪地と秣川の流路の正確な対応（どの区間か）は1912年地籍図・1922年前後の地図との照合が前提。④神田上水岸の低地の文言（北端）も本冊にあるが、窪地文言の精査を優先した。
