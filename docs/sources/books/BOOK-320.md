# [BOOK-320] 大東京史蹟案内（1932）— 白山御殿の総堀引水・千川上水の沿革条・豊島ヶ岡の旧水路観察

## 書誌〔確認: NDL次世代デジタルライブラリー書誌API・2026-11-25〕

- 一高史談会 編『**大東京史蹟案内**』（育英書院・**1932年**・[book/1190953](https://lab.ndl.go.jp/dl/book/1190953)・NDC 291・bibId 000000761944・請求記号587-345・鳥羽(存)・増訂の記名「以上鳥羽、增訂者中村元」の表記あり）。引用文言はOCR由来で要原文照合〔白山御殿条・千川上水条・氷川神社（豊島ヶ岡）条の周辺を全文テキストで直接確認済み〕。

## 文言1: 白山御殿条〔確認・要照合〕

- 「白山御殿町の丘陵の殆ど全部その地で、承應元年(1652)上州館林城主松平德松(後の五代綱吉)の下屋敷となり、寛文二年(1662)及同九年に大に擴張、宏大なる御殿、御矢倉、大手御門を構へ、白壁を繞らし**周圍の總堀へは千川の水を引いて**立派な物であつた。この地は元白山神社の鎭座あつた地であるので白山御殿とも稱せられた(簸川神社の條參照)。將軍となつてから小石川御殿奉行を置いて守らせ、**正德三年(1713)この館を廢し、御藥園及旗下士の宅地とした**。御藥園は今、帝國大學附屬植物園となつた」。
- **読み取り〔観察〕**: ①白山御殿の**總堀への引水源を「千川の水」とする**叙述（[BOOK-319](BOOK-319.md)（1923・植物園案内）の「大瀑...千川上水ノ水ヲ引キテ...ト云フ」〔伝聞〕と組み合わさると、**白山御殿の外部堀給水＋園内滝落水を千川系統とする説明が昭和初期のガイド類に揃う**〔いずれも二次編纂・伝聞文言のため、幕府期文書での確証とは区別し断定しない〕）。②**正徳3年（1713）の御殿廃止→御薬園への転用**という廃クロニクルが史蹟案内形式で明記される。

## 文言2: 千川上水の独立条〔確認・要照合・年次ずれ注意〕

- 「千川上水とは玉川上水の一分流で保谷村上保谷新田から分れ、武藏野村·石神井村等を經て、巢鴨までの**五里五十五町餘**の堀割である。之は元祿九年(1696)に引いたもので、小石川御殿·湯島聖堂·**東叡山**·淺草御殿等への上水であつた。仙川村大兵衞·德兵衞と云ふものが之を仰せ付かつてやつたのである。後に仙川を千川と改稱して、二人に賞として千川の姓を賜ふた。**享保七年(1723)十月に一度この上水を中止し**單に田の用水に用ひたが、**安永九年(1780)に再興し、本〓湯島·下谷·淺草方面の上水となつてゐた。天明六年(1766)再び中止し**、以後は單に田の用水にのみ用ひられるに至つた。(玉川上水の條參照)」。
- **読み取り〔確認・原書表記のまま〕**: ①**元禄9年（1696）引水・仙川村大兵衞・德兵衞→「千川」賜姓説・享保期中止～安永9年再興～天明期再中止**という、いわゆる「仙川→千川」系の沿革記述を一つの独立項目にまとめた1932年時点の定型〔各エピソードはrepo既出系統の学説・伝承と同型だが、**「東叡山」（寛永寺）への給水先の追加表記と「五里五十五町餘」の距離表記を含む体裁**は本書固有の記録として対照値に使える〕。②**年次の不一致〔原書表記のまま記録・断定しない〕**: 「**享保七年(1723)**」＝享保7年は1722年（享保8年が1723年）、「**天明六年(1766)**」＝天明6年は1786年（明和6年が1766年）で、西暦併記が幕末以前の他史料（安永9年=1780は合っている）と比べても内部整合しない＝**編纂段階の誤記・混同の可能性**。特に「天明六年(1766)再び中止」と「安永九年(1780)再興」の前後関係は、[GOV-353](../gov/GOV-353.md)・[GAZ-041](../gazetteers/GAZ-041.md)〜[GAZ-045](../gazetteers/GAZ-045.md)（天明2〜3年頃の千川上水堀割御普請の実務文書・町方書上）と年次接続せず、**本書の天明期記述は転写段階の混同（実際は明和期中止・安永期再興・天明期普請は再興工事自体を指す等の可能性）を含む候補**として要照合とした。享保7年（1722）10月の中止そのものは、享保7年＝1722年説の系統（repo既知）と一致し得る。〔ここでは原書表記をそのまま残し、解釈の採否は原典・先行研究との対照後に判断〕。

## 文言3: 豊島ヶ岡・氷川神社条の旧水路観察〔確認・repo初出候補〕

- 石神井城址（志村・板橋側の条）の末尾: 「氷川神社前の道を南方へ進み、**西武電車を越えるとまもなく舊千川上水のほとりに出る**」。
- **読み取り〔観察〕**: この「氷川神社」が西武線の北側で線路を越えて南へ出る位置関係に合う社（豊島ヶ丘＝豊島園駅北側の氷川神社候補）であれば、**1932年時点で西武線南側の旧千川上水路が、散策ルートのランドマーク「舊千川上水のほとり」として地形的に認識・観察されていた**ことを伝える記録〔上水の給水機能終了後も水路形態が残っていた時期（通水終了1971年〔[GOV-058](../gov/GOV-058.md)〕の約40年前）の「見え方」の資料。同書冒頭の見どころ一覧に「豐島ヶ岡御陵」等の見どころが併記される〕〔該当社の同定・旧水路箇所の現在地的な位置確認は要照合・human観察〕。
