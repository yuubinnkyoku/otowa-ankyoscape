# [BOOK-253] 小金井市文化財ブックレット2『発掘された小金井』（2023）〔repo初出・第257回課題③(文化財ブックレット2の書誌)の解決。市内遺跡の発掘調査の最新動向の公式解説冊子〕

- **書誌〔確認: [GOV-509](../gov/GOV-509.md)市頒布書籍一覧頁・2026-11-22取得〕**: **小金井市文化財ブックレットシリーズ第2弾『発掘された小金井』**（令和5年〔2023〕発行・**小金井市教育委員会**・A5判72ページ（カラー版）・価格200円）。市公式頁の説明＝「**シリーズ第2弾は、遺跡（埋蔵文化財）をとりあげました。小金井市内では、日々、大小の発掘調査が行われ旧石器時代から現代に至るまで、さまざまな時代の遺跡が見つかっています。これまでの発掘調査の蓄積を踏まえて、本書では最近の調査状況も網羅しており、小金井市の遺跡の発掘調査の最前線をお届けしています**」＝**市内遺跡の通時的解説＋令和5年時点の最新調査状況を網羅する冊子**。

## repoとの関連〔観察〕

- ①**武蔵野公園低湿地遺跡〔[BOOK-254](../books/BOOK-254.md)報告書1984〕・野川中洲北遺跡〔[BOOK-255](../books/BOOK-255.md)報告書1989〕の最新の再解釈が掲載されている可能性**（収録範囲は未確認・断定しない）。②**貫井遺跡・本町六丁目遺跡（[BOOK-256](../books/BOOK-256.md)市史資料編考古・中世の二大遺跡）以降の市内発掘の蓄積**＝[GOV-506](../gov/GOV-506.md)（西之台遺跡＝武蔵野台地最古級）・[GOV-508](../gov/GOV-508.md)（調節池化に伴う野川周辺遺跡）の系譜を令和5年時点でアップデートする候補。③72頁カラー版・200円＝入手容易な現行資料で、野川・仙川流域の土地利用史（水田・用水路・悪水堀の遺構面）の最新定点。

## 意義〔観察〕

- 市内遺跡の発掘史を「旧石器〜現代」の通時でまとめ、**「最近の調査状況も網羅」**と明言する市公式の冊子で、1980年代の報告書群（BOOK-254・255）とBOOK-256（市史）の後を受ける**2023年時点の総合解説の所在**を記録した。低湿地遺跡の「船着き場説」等の解釈の現状を知る一次候補。
