- **書誌〔確認：東京都水道歴史館「開架図書一覧」2021-07-10〕**：**『千川上水展　うつりゆく流域のくらしと景観』、豊島区立郷土資料館編・発行、平成4年（1992）2月**。同館開架書架B・118-1番・貸出可〔[開架図書一覧PDF](https://www.suidorekishi.jp/images/information/library/book.pdf)〕。
