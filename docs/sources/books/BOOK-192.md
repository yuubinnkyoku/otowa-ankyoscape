# [BOOK-192] 土地概評価 中野町（1922）— 神田上水の支流の用水路と「上げ堀」〔第160回〕

- **書誌〔確認〕**: 東京興信所『土地概評価』シリーズの中野町冊（**発行大正11年〔1922〕3月ごろと推定**〔同時期刊行の921572奥付参照・本冊の年は部分的OCRで要照合〕）。NDL次世代デジタルライブラリー [book/921567](https://lab.ndl.go.jp/dl/book/921567)。**引用はOCR由来・要原文照合。**
- **中野町の三分構造と「神田上水の支流」の文言〔確認・文言候補・核心〕**: 「**地勢は〓ね高燥なれとも南に神田上水 北に其支流の流るありて自然南北及び中央の三部に區分せらる**」＋「**神田上水に合せる用水路流域の窪地以北…其中央には別に南北に鐵道線路を橫斷して流る〓用水路筋の窪地**」＝**①中野町が南の神田上水と北の「其支流」によって南北・中央の三部に区分される、②「神田上水に合せる用水路」の流域の窪地が町の北部を画し、鉄道線路を横断して流れる「用水路筋の窪地」がある**という1922年の地勢観察〔**北の支流たる「用水路」の川名は本冊に記されない**。桃園川（中野の北部を流れ東中野1丁目付近で神田川に合流〔[GOV-124](../gov/GOV-124.md)の「桃園川合流点」・[PAP-065](../papers/PAP-065.md)の桃園川廃止参照〕）の下流部が有力候補だが、**本冊文言だけでは比定しない**〕。
- **「上げ堀」の文言群〔確認・文言候補・repo初出級〕**: ①「**大凡神田上水の上げ堀以南の大部分にて字新橋以下十六字あり**」（大字雑色の区分）＝**「神田上水の上げ堀」の南側に大字雑色の大部分（16字）が広がる**。②「**字、五反田三〇七-三七五番地(內田邸前より內田製革工塲前に至る神田上水路と其の上げ堀との間に位する低地にて多くは水田)**」＝**神田上水路と「其の上げ堀」の間の低地が多く水田**。③「**多田神社の西北、神田上水と其の上げ堀との間にある水田**」＝**多田神社の西北でも上水と上げ堀の間に水田**。④「**川島橋附附近の上げ堀以南の畑**」。＝**「上げ堀」が神田上水の南側（雑色・五反田・多田神社方面）に並行して存在し、その間の帯状低地が水田である1922年の観察**〔**「上げ堀」＝上水から上げて流す堀（離れ堀・並行堀）の意と読むが、この上げ堀の比定（野方堀〔千川系の助水路〕か、上水の旧流路か、別の用水か）は本冊からは確定できない**〔千川上水（野方堀）が中野町の南部（上水と青梅街道の間）を流れたとする流路論と対照する主要候補の一つだが、**比定は今後の課題として保留**する〕。「桃園橋」通（桃園橋通り）・「農事試驗塲前」等の用語も雑色方面の方位語として現れる〕。
- **位置づけ〔観察〕**: ①本冊は、神田上水の中野区間（上水廃止後）について、①本水路（神田上水）・②北の支流の用水路（窪地）・③南の上げ堀、という**3本の水路的地形の並行構造を1922年の実業調査書が観察**した点で貴重（[GOV-366](../gov/GOV-366.md)の嘉永5年の中野村「神田上水堀筋」境界文言の北側に相当する区間）。②上げ堀と上水の間の水田の記録（五反田・多田神社）は、大正期の中野低地の水田残存の定点記録。③桃園橋通・川島橋の用語は、雑色〜中野駅南の橋の1922年の通称の候補（桃園川系の橋か上水の橋かは本冊からは特定できない）。
