# [BOOK-219] 東京府勢概要（1937/1939）— 谷端川改修（3,001m・668,530円）の府統計文言

- **書誌〔確認〕**: 東京府編『東京府勢概要』（1937・NDL次世代デジタルライブラリー [book/1263482](https://lab.ndl.go.jp/dl/book/1263482)）。「第十章 土木事業」p.448に中小河川改修の竣功・工事中リスト。改訂版『東京府勢概要』（1939・NDL [book/1710698](https://lab.ndl.go.jp/dl/book/1710698)）「第十五章 土木事業」p.682に同系統の記述あり。
- **谷端川改修の文言〔文言候補・repo初出の数値〕**: 1937年版「**旣に竣功したものは澁谷區內の澁谷川二千六百七十米の改修費百十四萬七千六百十六圓、大森區の立會川三千五百六十三米の改修費百二十七萬八千四百六十圓、豐島區板橋區に跨る谷端川三千一米（三千〇一米=3,001mの判読候補・OCR要照合）の改修費六十六萬八千五百三十圓等であつて**」＝**①豊島区・板橋区に跨る谷端川の改修（延長3,001m・改修費668,530円）が渋谷川・立会川と並ぶ「既に竣功した」中小河川改修として府政レベルで記録、②同時掲載の渋谷川2,670m・1,147,616円、立会川3,563m・1,278,460円との並記**。1939年版「**澁谷區内の澁谷川(二千六百米、百十四萬圓)、大森區の立會川(三千五百米、百二十七萬圓)、豐島區板橋區に跨る谷端川(三千米、六十六萬圓)等であつて**」＝**1939年版では延長・工費が百米・萬圓単位に丸められ、谷端川は「3,000m・66万圓」表記**。〔**谷端川改修事業（1931年着手・1937年度内務省告示系＝README既存の谷端川改修の枠）の工費・延長を府の統計書が具体的な数値で記した最初の一次確認（[GOV-159](../gov/GOV-159.md)/[GOV-172](../gov/GOV-172.md)系の改修費候補668,530円＝未収録数値のためrepo新情報。金種・桁・丸めは原画像照合前提）**〕。
- **工事中リストの「神田上水（1937年版）」の文言〔文言候補〕**: 1937年版の続き「**目下工事中のものは左表の通である（昭和十一年度現在）河川名…目黑川…神田上水 豐…**」（段組崩壊・OCR判読限界）＝**昭和11年度現在で神田上水（＝神田川）が目黒川と並ぶ「工事中」の対象（目黒川8,600m・989万円、神田上水7,400m・394万円は1939年版で判読可能）**。1939年版では「**目黑川(八千六百米、九百八十九萬圓)、神田上水(七千四百米、三百九十四萬圓)、吞川(五千米、二百十七萬圓)、宇田川(四百八十米、六十一萬圓)、谷田川(千八百米、百十萬圓)、蛇崩川(千五百米、六十一萬圓)、妙正寺川(千八百米、九十八萬圓)、澁谷川上流(二千五百米、五十九萬圓)**」＝**神田上水7,400m・394万円の1939年時点の改修予算文言（目黒川・神田上水改修は荒川放水路・環七調節池系の文脈でREADMEの既存記述と対校可能・本登録は数値の所在記録）**。

## 制限・未解決

- ①「三千壱米」のOCR判読は3,001mが正しいかの原画像確認が前提（1937年版の他河川が"三千五百六十三米"のように精確なため、谷端川も精確値の可能性が高い）。②668,530円の数字もOCR由来で原画像照合まで確定保留。③1939年版の谷端川3,000m／66万圓は1937年版の丸めか、改修区間の再測かは本資料群では判別不能。④谷端川改修の着手年度・竣功年度・区間（板橋側・豊島側の具体的な起終点）は本資料では示されず、府の河川改良計画・都市計画事業年報系の追調査が要る。
