- **位置づけ〔観察〕**: 本所区＝千川上水系の下流側の対照域。①**古上水**: 橋々銘書（[GOV-606](../gov/GOV-606.md)・明治4年）地方四番組の「**古上水土橋**」（pkey 618209・綾瀬板橋・業平橋・今戸橋・新鳥越橋と同組）＝古上水（千川上水の旧称候補文言＝[GAZ-043](../gazetteers/GAZ-043.md)「古上水跡…千川上水ゟ相唱候場樋跡」・[BOOK-302](BOOK-302.md)・[BOOK-222]の「古上水の享保7年9月差止」）の橋名。②**亀有上水（本所上水）**: [GOV-171](../gov/GOV-171.md)（御府内上水在絕略記・本所条＝万治2年本所給水開始→享保7年再廃止）・[BOOK-222](BOOK-222.md)（深川区史・亀有上水の通史と四上水差止の江東側の並記）・[GAZ-138](../gazetteers/GAZ-138.md)/[GAZ-093](../gazetteers/GAZ-093.md)（風土記稿・小梅瓦町書上の白堀＝本所上水の比定群）・GAZ-165〜178（本所深川帯書上群）。③**千川養水**: [GOV-608](../gov/GOV-608.md)「小石川掃除町…千川養水流末へ架渡」（1877・府文言）。本所区の区史本文にこれら古上水・本所上水（亀有上水）・千川養水流末の記述が含まれる可能性は十分にあるが、**文言は全て未確認**＝判読により「上水の末端は総て隅田川西岸に至って絶え」（[BOOK-222](BOOK-222.md)・1926）に対応する本所側（隅田川東岸）の叙述の有無・古上水の本所域での終末の記述の有無が第一確認点。
- **判読の一次確認点（human閲覧時）**: ①古上水・千川養水の文言の有無 ②白堀上水（本所上水＝亀有上水）の通史（BOOK-222上巻対応） ③業平橋・法恩寺橋・新鳥越橋等の橋梁章（東京市史稿橋梁篇の本所分との対照） ④江東の水船・改良水道の叙述（BOOK-222下巻対応部分があるか）。
