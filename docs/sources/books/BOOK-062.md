# [BOOK-062] 『暗渠となってその姿を消した、豊島区最長の川 旧谷端川の橋の跡を探る』

- **書誌〔確認〕**：豊島区立郷土資料館友の会編、1999年。**豊島区立上池袋図書館所蔵**（[BLOG-001](../blogs/BLOG-001.md)・[BLOG-002](../blogs/BLOG-002.md)（natrium.jp）の著者が橋名・橋跡探索の参考書として明記）。repoでは[GOV-007](../gov/GOV-007.md)や[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)で断片的に言及してきたが、書誌としての登録は本書が初めて。
- **内容〔二次情報〕**：谷端川（旧谷端川）の橋の跡を、旧橋名とともに記録した豊島区郷土資料館友の会の調査冊子。natrium.jpの谷端川緑道シリーズ（谷端川南緑道・北緑道・宮原橋〜板橋駅ほか）で、前田上橋・熊野橋・境井田橋・他領橋・丸山橋・宮下橋・豊橋・鎌倉橋等の橋名は本書に依拠している旨の記載がある。
- **次の一手〔未確認〕**：本文の橋名一覧・位置記述・掲載写真の直接確認（上池袋図書館・豊島区郷土資料室での現物閲覧）。[四河川の橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)の橋名リストと本書の突合。
