# [BOOK-153] 『遠足の栞』（1919）— 千川堤の桜（新小金井）と1919年時点の千川上水の現勢

- **書誌〔確認〕**: 東京女子高等師範学校附属高等女学校校友会編『**遠足の栞**』（**同校友会・1919年〔大正8頃〕**。出版年の末尾桁はOCR由来で要照合）。NDL次世代デジタルライブラリー [book/962027](https://lab.ndl.go.jp/dl/book/962027)。遠足（徒歩旅行）のコース沿いの地誌を記した学校刊行の案内書。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **①長崎村条の千川用水堤の桜＝「新小金井」〔確認文言・1919年の用例〕**: 「**千川用水(保谷村より分れ來れる玉川上水の一派)の兩岸二里餘に亙り櫻樹を多く栽植し、新小金井の稱あり**」＝**千川用水の両岸二里余にわたり桜樹を多く栽植し「新小金井」の称がある**という長崎村（北豊島郡）条の記録。〔千川堤の桜並木と「新小金井」の俗称は[GOV-056](../gov/GOV-056.md)・[BLOG-101](../blogs/BLOG-101.md)・[PAP-023](../papers/PAP-023.md)等の既出記録に対し、**1919年時点の現役の用例として対校する記録**。「新小金井」の称の地理的範囲（長崎村条に現れる点から西側にも及ぶか）は本書だけでは断定しない〕。
- **②保谷村条の境橋分岐と「仙川の人」起源説〔確認文言・起源説の用例〕**: 「**（保谷村）村の西南隅境橋の所より玉川上水を分ちて千川上水を引く。初めは享保七年の落成にして、仙川の人專ら其工に任じたるなり**」＝**①保谷村の西南隅の境橋の所で玉川上水を分けて千川上水を引くこと、②最初は享保7年の落成で「仙川の人」が専らその工に任じた由**。〔境橋＝千川上水の分岐点の地名（既出の[BOOK-126](BOOK-126.md)系等と対校）。「仙川の人」起源説＝[GOV-306](../gov/GOV-306.md)（仙石村）・[GOV-307](../gov/GOV-307.md)（仙川村ノ農民德兵衞太兵衞）の系統に加わる表現。「享保七年の落成」は千川上水の廃止（享保7年）ではなく開設（元禄期）を享保7年とする年代のずれを含む記述で、本書だけでは正誤を判断しない（大正期の学校刊行書の転述として記録する）〕。
- **③板橋周辺の1919年時点の現勢〔確認文言〕**: 「**（下板橋）北豊島郡板橋町の東南境に位し、谷端川畔にあり**」＋「**板橋町は巢鴨村の西北に接し、中仙道口の首驛なり…南には千川上水、北には石神井川、東北に並走し、東境に相會せり**」＝**①下板橋が谷端川畔にあること、②板橋町の南に千川上水・北に石神井川が「東北に並走」し東境で相会するという1919年時点の河川配置の記録**。〔**1919年時点で千川上水が板橋町の南を流れる現役水路として記録される用例**（[GOV-290](../gov/GOV-290.md)（1905現役）・[GOV-307](../gov/GOV-307.md)（明治40年6月廃止）との整合＝市内給水の廃止後も用水路として現役であったことの傍証の一つ。「相會せり」＝両川が東境で相会するという地形記述の解釈（実際の合流か接近か）は要照合）。板橋の千川上水・石神井川の並走は[MAP-175](../maps/MAP-175.md)等の地図記録と対校できる〕。
- **④西巣鴨町条の現況〔確認・内容メモ〕**: 「**西巢鴨町は巢鴨町の西に接し、人口三萬七千餘宅地千坪に付人口約八十に當り、郊外住宅地區として宅地大に增加せり**」＝1919年時点の西巣鴨町の郊外住宅地化の記録。〔千川上水・谷端川沿いの市街化の大正期の状況記録として[BOOK-145](BOOK-145.md)系の市街化記録と対校できる〕。
