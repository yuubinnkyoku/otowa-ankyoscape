## 意義〔観察〕

- **第295回課題④（都水道局局報の所在）への回答の一つ**: 都水道局の局報系広報誌「水道局報」が**1955年5月〜1959年6月の号について電子書籍として商業復刻**されている〔ro-da図書棚には未収録・CiNiiにも誌名書誌なし＝機関外での利用は本復刻か図書館等の紙所蔵〕。なお[GOV-574](../gov/GOV-574.md)④⑤の裏面注記「局報六十三号掲載／氷道昔と今」が指す局報は昭和30年代後半の号で、**本復刻期間（1955-59）より後の号**〔第63号の年代特定＝復刻範囲外であることに注意〕。
- **時期性状**: 1955-59年＝**千川上水暗渠化工事（昭和20年代後半〜30年代前半）の直後の都水道行政広報**で、この時期の水路現況・分水の再編・下水道計画の都側発信を集めた資料群〔掲載目次例に千川上水・千川用水は直接現れない。ただし「汚水を還元して工業用水に」「六郷原水補給」等、**廃止・転用後の水路の用途転換の行政側言説**を含む〕。
- 「神田上水路」＝神田上水の流路跡を利用した都水道の導水管路の近代的呼称で、repoの神田上水系（千川上水の神田側関連）の近代以降の実務呼称の用例候補。
