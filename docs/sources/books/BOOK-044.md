# [BOOK-044] 江副広忠『高田の今昔 : 一名雑司ケ谷盛衰史』（1929年）

- **書誌〔確認：国立国会図書館サーチ〕**：江副広忠著、三才社、**1929年（昭和4年）**、**301頁・25cm・和装・謄写版**。国立国会図書館請求記号**205-301**、書誌ID**000000761588**、PID **1175480**。デジタル資料は**館内閲覧・登録利用者の個人送信対象**で、一般公開の原画像は未確認。
- **内容・付図〔二次資料の観察記録／原本未照合〕**：2021年7月14日の地域史ブログ「『高田村誌』と『高田町政概要』の間に。」は、著者所持本に高田・雑司ヶ谷・落合・長崎周辺の折込図「**曹司谷 白眼 高田 落合 鼠山全図**」があり、金子直徳『和佳場の小図絵（若葉の梢）』の**1798年（寛政10年）頃の地域像を基にした図**と説明する。また本書に町の地勢・沿革・衛生・道路などの項目があると紹介する。図名・底本・図中の河川描写はブログ経由の情報であり、**1929年測量の河道図ではない**。
