# [BOOK-075] 『千川上水探訪マップ』（豊島区立郷土資料館、1996年・完売）


- **書誌〔確認：豊島区公式「図録（1996年度）」ページ〕**：**『千川上水探訪マップ』（完売）**。豊島区立郷土資料館、**千川上水開削300年記念企画展（1996年11月24日〜12月15日）**に合わせた冊子〔区公式頁は直接遮断のため2026-11-12、Wayback Machineで確認〕。
- **内容〔確認：同ページの序文紹介〕**：千川上水のガイドマップ的機能を重視した編集。**先行するガイドマップとして『かたりべ24・25合併号』と『豊島区地域地図第6集』解説書があった旨、詳細は1992年特別展図録[BOOK-071](BOOK-071.md)と調査報告書「千川上水関係文書I」〔[BOOK-070](BOOK-070.md)]を参照する旨を記す**〔かたりべ24・25合併号自体はrepo未収録〕。**1996年の記念事業が練馬区教育委員会・板橋区立郷土資料館と相互協力で組み立てられた旨**の序文もある〔[GOV-040](../gov/GOV-040.md)編集後記と整合〕。
- **制限〔未解決〕**：冊子本体・地図内容は未確認。
