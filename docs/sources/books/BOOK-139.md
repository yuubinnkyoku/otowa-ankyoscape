# [BOOK-139] 小石川區會史 上巻（1939）— 千川大下水の明治40〜41年出水と改修運動・分水口水門案（第118回追記: 蟹川文言候補・千川流域水害調査要領・明治43年聯合委員会）

- **書誌〔確認〕**: 小石川区（区長吉守市ほか）編『小石川區會史』**上巻**（1939年・次世代デジタルライブラリー [book/1277781](https://lab.ndl.go.jp/dl/book/1277781)）。**下巻（1939）は[BOOK-123](BOOK-123.md)として登録済み**（大正期の江戸川改修・千川浚渫陳情・音羽大下水）。本上巻は明治期の区会記録が中心。引用文言はOCR由来で要原文照合。
- **明治40年の千川大下水出水〔確認・repo初出の水害datapoint〕**: 区会の「**本月十八日及廿一日の千川大下水出水**」罹災者救助費の追加支出案（歲入は**水野忠義・水野升兩氏の寄附金**）＝**明治40年（1907）の千川大下水（旧千川上水の小石川側大下水）の出水（月内18日・21日の2回）と救助金支出の区会記録**。〔千川水害の年表（明治6年・13年・29年・30年・43年〔[BOOK-126](BOOK-126.md)〕）に明治40年を追加する新規datapoint。月名（本月）の特定は周辺記事の配列から原文照合要。〕
- **明治41年・水害排除及旧水道委員会〔確認・repo初出の文言群〕**: 千川大下水改修をめぐる区会の記録——
  1. 「**千川大下水改修の市への度重なる陳情**」・沿岸居住者の**浚渫・護岸の請願支援**（区会が請願を支援）。
  2. **砲兵工廠出張**: 「**工廠內千川大下水改修ニ關シ問合セノ爲メ砲兵工廠ニ出張、工廠當局ノ意見ヲ聞キ、審議ス**」＋**工廠内区間の先施要望**（工廠内の区間は来年度の工廠建築後は改修不可能ゆえ先に施工されたい旨と読める文言候補・原配列要照合）＝**千川大下水が東京砲兵工廠（現在の後楽園一帯）内を通過する区間の改修時期をめぐる、区会と工廠当局の交渉記録**。〔[BOOK-009](BOOK-009.md)（1910・工廠内通過）・[BOOK-123](BOOK-123.md)（大正期の工廠内水路視察・無名橋下掘下げ）・[BOOK-126](BOOK-126.md)（下水道設計の工廠内大溝渠）の系譜の明治41年時点の先駆記録。〕
  3. **「舊水道ニ關シ開申スヘキ意見書案」**の作成（市当局者の意見に基づく）。
- **排水方法答申（氷川下町・白山御殿町等）〔確認・repo初出級〕**: 「**千川上水分水口（北豊島郡長崎村字樋口）ニ水門ヲ設ケ開閉ヲ自由ナラシメ分水口及其附近ニ土堤ヲ築キ溢水ヲ防クコト**（三?）…**氷川下町字住吉ヨリ小石川町東京砲兵工廠ニ至ルノ間千川下流ノ幅員ヲ擴張シ川底凡ソ四尺(?)…浚渫**…初音町暗渠改修」＝**①千川上水の分水口（＝谷端川への分水点）の位置を「北豊島郡長崎村字樋口」と明示し、②そこに水門と土堤を設けて溢水を防ぐこと、③千川下流（氷川下町〜砲兵工廠間）の幅員拡張・浚渫、④初音町の暗渠改修**という技術的答申のリスト。〔**「長崎村字樋口」＝千川上水から谷端川（用水）への分水口の字レベルの位置特定の文言**として、[GOV-165](../gov/GOV-165.md)（長崎町・千川用水の通過）・[GOV-258](../gov/GOV-258.md)（「舊千川上水ヨリ分流シ」）・[BOOK-140](BOOK-140.md)（千川用水の台地脊梁）と並ぶ重要な位置記録。「字樋口」の比定（現在の豊島区西池袋〜長崎の千川児童公園・水源地付近か）は原文・地図照合の課題として断定しない。〕
- **昭和期の視察〔確認・repo初出〕**: 「**上流谷端川水源卽ち千川用水分水口に至る間等の實地視察を遂げたる上、市當局に對し本年度大削減を加へられた千川大下水改修費の明年度豫算に計上方を運動陳**（情）」＝**区会が「谷端川水源＝千川用水分水口」という認識で上流の実地視察を行い、千川大下水改修費の予算復活を陳情した**記録＋音羽大下水排水口調査の陳情。〔区会レベルで谷端川水源=千川用水分水口の等式が共有されていたことの明治〜昭和の通時的な証跡。〕

- **明治43年・旧神田上水二區一村聯合委員會〔確認・repo初出〕**: 「**舊神田上水ニ關スルモノ(聯合會) 本區牛込區高田村の二區一村にて聯合委員會を組織し、本區の大井玄洞會長となり本區三名(松井、杉山、西川)牛込區三名高田村二名の主査委員を選定、聯合開會竝出張六囘に及び**」（開會及出張「明治四十三年九月以降十一月間ニ十七囘・本年度累計三十囘」）＝小石川区・牛込区・高田村が**旧神田上水（江戸川）の水害対策のために合同委員会を組織**し、次を実行した——
  1. 「**先づ一關口ニ於ケル堰ヲ撤去セシムルコト 一前項不可能又ハ不利益ノ場合ハ水門ヲ擴大シはんどる式トナシ堰板ノ開閉ヲ自在ナラシムルコト**」＝**関口の堰（大洗堰）の撤去要求・不可能な場合はハンドル式水門への拡大改造案**。
  2. 「**堰ノ上流ヨリ鶴卷町大下水若クハ他方面へ分水ヲ施スコト**」＝**堰上流から鶴巻町大下水（弦巻川域の大下水）への分水案**〔弦巻川下流域の排水系統（鶴巻町大下水）が旧神田上水の水害対策の選択肢として挙がった文言候補・要照合〕。
  3. 「**豐橋附近河身ノ屈曲ヲ直スコト 一舊神田上水及江戶川ヲ浚渫シ堤防ヲ築キ護岸ノ改修工事ヲ施行セシムルコト**」＝豊橋付近の屈曲矯正・旧神田上水と江戸川の浚渫堤防護岸。
  4. 「**府市技師ノ臨檢ヲ請求シ一週間以內ニ主査委員同行實地踏查ヲナスコト**」→府・市の技師と同道実地調査・「**淀橋淨水場へも出張して水害排除の善後策に關する交渉**」→「**府と市の技師各意見を異にして本委員會の意見決定に資せざるを…**」→「**内務省技師の出張を乞ひ實地調査を遂げた**」＝**府市技師の意見不一致を内務省技師の出張調査で決着させようとした経過**。
  〔**旧神田上水（神田上水）の廃止後の水害対策を2区1村の合同で組織化し、関口の堰・水門を争点化した明治43年（1910）の一次記録**＝[BOOK-123](BOOK-123.md)（下巻・大正期の江戸川改修陳情）の先駆段階。同時期の出水（明治43年〔[BOOK-126](BOOK-126.md)〕）との前後関係は要照合。〕
- **明治22年市制施行時の「千川流域の田地」市内編入〔確認・沿革補助〕**: 「**市制施行に伴つて一部市區境域の變更が行はれた。本區に於ては、從來本區域內に在りながら、これ迄小石川村高田村雜司ケ谷村と稱して市部と別個の村地とし取扱はれてゐた千川流域の田地、原町以北及び大塚高田邊の畑地の多くが、市內に編入されて附近の町內に合併せしめられたり、又白山御殿町、氷川下町等の新町が設置されたりした。又巢鴨一丁目乃至四丁目は本區から分離し、府下の巢鴨町へ編入替**」＝**1889年（明治22）市制施行時、小石川村・高田村・雑司ヶ谷村の村地として扱われていた「千川流域の田地」・大塚高田辺の畑地が市内に編入され、白山御殿町・氷川下町等の新町が設置された沿革**〔千川流域（谷端川・千川上水沿い）の東京市編入と町設置の1889年という年代データポイント。〕

## 制限・未解決

- ①明治40年出水の「本月」の特定（区会の会期・配列からの推定は可能だが断定しない）・水野忠義・水野升の寄附金額は要照合。②「工廠建築後は改修不可能」の文言は列崩れを含み原配列の照合要。③排水方法答申の項番・区間名（氷川下町字住吉・初音町）・数値（川底四尺等）はOCR要照合。④「字樋口」の位置比定は保留（千川上水の分水口の字名として初出のため、地籍図・字名一覧との照合が次回課題）。⑤「蟹川」文言はOCR誤読可能性があり原字・当該小流の同定（1912年地籍図の蟹川観察区域との対応・弦巻川下流部との関係）は原文・地図照合まで文言候補として保留。⑥明治43年聯合委員会の「鶴卷町大下水」の流路同定（弦巻川下流の大下水か）・「豐橋」の比定は要照合。⑦「千川流域明治四十年九月十八日浸水家屋調査表」の表本体は本書では省略されており所在不明。
