# [BOOK-139] 小石川區會史 上巻（1939）— 千川大下水の明治40〜41年出水と改修運動・分水口水門案

- **書誌〔確認〕**: 小石川区（区長吉守市ほか）編『小石川區會史』**上巻**（1939年・次世代デジタルライブラリー [book/1277781](https://lab.ndl.go.jp/dl/book/1277781)）。**下巻（1939）は[BOOK-123](BOOK-123.md)として登録済み**（大正期の江戸川改修・千川浚渫陳情・音羽大下水）。本上巻は明治期の区会記録が中心。引用文言はOCR由来で要原文照合。
- **明治40年の千川大下水出水〔確認・repo初出の水害datapoint〕**: 区会の「**本月十八日及廿一日の千川大下水出水**」罹災者救助費の追加支出案（歲入は**水野忠義・水野升兩氏の寄附金**）＝**明治40年（1907）の千川大下水（旧千川上水の小石川側大下水）の出水（月内18日・21日の2回）と救助金支出の区会記録**。〔千川水害の年表（明治6年・13年・29年・30年・43年〔[BOOK-126](BOOK-126.md)〕）に明治40年を追加する新規datapoint。月名（本月）の特定は周辺記事の配列から原文照合要。〕
- **明治41年・水害排除及旧水道委員会〔確認・repo初出の文言群〕**: 千川大下水改修をめぐる区会の記録——
  1. 「**千川大下水改修の市への度重なる陳情**」・沿岸居住者の**浚渫・護岸の請願支援**（区会が請願を支援）。
  2. **砲兵工廠出張**: 「**工廠內千川大下水改修ニ關シ問合セノ爲メ砲兵工廠ニ出張、工廠當局ノ意見ヲ聞キ、審議ス**」＋**工廠内区間の先施要望**（工廠内の区間は来年度の工廠建築後は改修不可能ゆえ先に施工されたい旨と読める文言候補・原配列要照合）＝**千川大下水が東京砲兵工廠（現在の後楽園一帯）内を通過する区間の改修時期をめぐる、区会と工廠当局の交渉記録**。〔[BOOK-009](BOOK-009.md)（1910・工廠内通過）・[BOOK-123](BOOK-123.md)（大正期の工廠内水路視察・無名橋下掘下げ）・[BOOK-126](BOOK-126.md)（下水道設計の工廠内大溝渠）の系譜の明治41年時点の先駆記録。〕
  3. **「舊水道ニ關シ開申スヘキ意見書案」**の作成（市当局者の意見に基づく）。
- **排水方法答申（氷川下町・白山御殿町等）〔確認・repo初出級〕**: 「**千川上水分水口（北豊島郡長崎村字樋口）ニ水門ヲ設ケ開閉ヲ自由ナラシメ分水口及其附近ニ土堤ヲ築キ溢水ヲ防クコト**（三?）…**氷川下町字住吉ヨリ小石川町東京砲兵工廠ニ至ルノ間千川下流ノ幅員ヲ擴張シ川底凡ソ四尺(?)…浚渫**…初音町暗渠改修」＝**①千川上水の分水口（＝谷端川への分水点）の位置を「北豊島郡長崎村字樋口」と明示し、②そこに水門と土堤を設けて溢水を防ぐこと、③千川下流（氷川下町〜砲兵工廠間）の幅員拡張・浚渫、④初音町の暗渠改修**という技術的答申のリスト。〔**「長崎村字樋口」＝千川上水から谷端川（用水）への分水口の字レベルの位置特定の文言**として、[GOV-165](../gov/GOV-165.md)（長崎町・千川用水の通過）・[GOV-258](../gov/GOV-258.md)（「舊千川上水ヨリ分流シ」）・[BOOK-140](BOOK-140.md)（千川用水の台地脊梁）と並ぶ重要な位置記録。「字樋口」の比定（現在の豊島区西池袋〜長崎の千川児童公園・水源地付近か）は原文・地図照合の課題として断定しない。〕
- **昭和期の視察〔確認・repo初出〕**: 「**上流谷端川水源卽ち千川用水分水口に至る間等の實地視察を遂げたる上、市當局に對し本年度大削減を加へられた千川大下水改修費の明年度豫算に計上方を運動陳**（情）」＝**区会が「谷端川水源＝千川用水分水口」という認識で上流の実地視察を行い、千川大下水改修費の予算復活を陳情した**記録＋音羽大下水排水口調査の陳情。〔区会レベルで谷端川水源=千川用水分水口の等式が共有されていたことの明治〜昭和の通時的な証跡。〕
