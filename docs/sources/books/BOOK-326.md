# [BOOK-326] 杖の跡（大町桂月）— 千川堤の桜の文学証言（1916）と上水べり植栽の年次

## 書誌〔確認: NDL次世代デジタルライブラリー・2026-11-25〕

- 大町桂月 著『杖の跡』（**至誠堂書店・1916**・[book/948875](https://lab.ndl.go.jp/dl/book/948875)）。桂月の紀行・随筆集（大正4〜5年の執筆が中心）。**目次に「千川の櫻」「千川上水」の見出し**があり、武蔵野・千川上水沿いの散策紀行を含む。引用はOCR由来（OCRコマ115〜116枚目・同186枚目。印刷頁は「(69)」前後の数字 fragment が見えるが対応は未照合）。

## 文言〔確認・要照合〕

- **「千川の櫻」章（「（前略）…小金井の山櫻の區域盡きて」の部分・OCRコマ115）**:
> 千川の櫻（とき）… **小金井の山櫻の區域盡きて、境橋架れる處より、玉川上水分派し、練馬驛、東長崎驛を經て、板橋に入る。これを千川上水と稱す。大正四年、この上水べりに櫻と楓との若木を植る付けたりと聞く。さても花の名所の增加すること哉。**

- **同章の散策記（OCRコマ116）**:
> 停車場を出でゝ數十間行けば、一小溝路を橫切る。**これ千川上水也。** （上水の右岸に沿ひ…）**上水に沿うて行くこと數町、上水の兩側に若き櫻（あり）**（…楓もあり…）／ あくる日…目白驛を過ぎ、東長崎驛を右手に見るより間もなく…（五郞窪）橋に至り、**千川上水に沿うて、上へと行く。若木の櫻あり**…**上水は道路に接す。**

- **名所列挙の一文（OCRコマ186・沿線名所の列挙）**:
> **東長崎驛と練馬驛との間に、千川の櫻あり**、（…この沿線には白子不動の瀧…三寶寺池…）

- **目次（OCRコマ12）**:
> …新武藏野の櫻…**玉川上水 千川の櫻**…**千川上水**…板橋…小金井の櫻…

## 読み取り〔観察〕

- **①千川堤植栽の伝聞文言（1916・植栽の年次問題）〔既存仮説の対校材料〕**: 「大正四年、この上水べりに櫻と楓との若木を植る付けたりと**聞く**」＝植栽直後（1915-16年）の散策者の聞き取り証言。千川堤植桜楓碑（[BLOG-101](../blogs/BLOG-101.md)）の碑文は「大正3年（1914）に議を建て…数月で功成り（建碑は大正4年11月）」、[GOV-056](../gov/GOV-056.md)は「**大正4年・桜と楓1,600本**」と記す。桂月の「**大正四年…植る付けたり**」は**GOV-056の大正4年説と整合し、碑文の「大正3年議建て→数月で功成り」（1914年内完成）と微妙にずれる**〔伝聞（「と聞く」）であり、植栽運動の長期性（1914議→1915完成/補植）を考えれば食い違いとまでは言えないが、**年次の対校点として登録**〕。
- **②目次レベルの「千川の櫻」の独立見出し〔repo初出の見出し〕**: 1916年の紀行集の目次で「**千川の櫻**」が「玉川上水」に続く独立見出しを持ち、「千川上水」「板橋…小金井の櫻」と並ぶ＝**千川堤桜（新小金井）が武蔵野散策の目的地として1916年時点で名所化していた文学側の証拠**（[BOOK-180](BOOK-180.md)1918「兩岸二里餘」・[BOOK-153](BOOK-153.md)遠足の栞1919「新小金井」・[GOV-056](../gov/GOV-056.md)散策案内系より早い時点の用例列）。
- **③水路の実見〔観察〕**: 「停車場を出でゝ數十間行けば、一小溝路を橫切る。これ千川上水也」＝東長崎駅（武蔵野鉄道）下車直後の千川上水の見え方（小溝路）、「上水は道路に接す」「若木の櫻あり…楓もあり」＝**植栽直後の千川堤の景観（若木と道路に接する水路）の一次観察**〔執筆の年月の特定は要照合（大正4〜5年の散文随筆録と推定）。「五郞窪橋」「練馬」等の Bridge 名の正確な表記も原画像照合〕。
- **④経路認識〔観察〕**: 「小金井の山櫻の區域盡きて、**境橋架れる處より玉川上水分派し**、練馬驛・東長崎驛を經て板橋に入る。これを千川上水と稱す」＝境橋分派→練馬・東長崎→板橋の千川上水の流路認識が1916年の一般散策者に定着していた用例（[BOOK-137](BOOK-137.md)武蔵野1913の境橋文言と同系統）。
