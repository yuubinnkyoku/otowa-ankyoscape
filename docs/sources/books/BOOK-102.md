# [BOOK-102] 今尾恵介監修『東京凸凹地形案内』（2012）の004「雑司が谷、音羽」コース〔repo初出・第89回継続調査2〕

- **書誌〔確認: 平凡社公式書誌頁・2026-11-14〕**: 今尾恵介監修『**東京凸凹地形案内 5mメッシュ・デジタル標高地形図で歩く**』（平凡社・別冊太陽 太陽の地図帖・**2012年10月**・ISBN978-4-582-94548-5・B5・96p・品切中）。平凡社頁の内容紹介は「東京の地形を愉しむ12のモデルコースを紹介。標高差が一目でわかる細密なデジタル地図を持って、崖あり谷あり、スリバチありの東京地形散歩に出かけよう」。
- **12モデルコース中の004が雑司が谷・音羽〔確認: 平凡社公式頁の目次一覧〕**: 「**004_雑司が谷、音羽……浅い谷がいくつも入りこみ風情のある町並みを形成**」。**2012年時点で雑司が谷・音羽の谷地形（弦巻川・水窪川の谷に相当する地域）が5mメッシュ・デジタル標高地形図による一般向け地形散歩のモデルコース（全12コース中の1つ）として選ばれていた**〔確認〕。004以外に「005_渋谷……廃川跡歩きも楽しめる魅惑の凸凹エリア」「012_下北沢、明大前……川と上水が生み出す淀橋台の屋根と谷」など地形・水路系コースを含む〔確認: 同目次一覧〕。
- **意義〔観察〕**: ①[BOOK-101](BOOK-101.md)（『カラー版 東京凸凹地形散歩』平凡社新書842・2017）第1章「雑司が谷・音羽──音羽川と弦巻川を遡る」の**前身シリーズ**にあたる〔BOOK-101追記参照〕。カラー版が「雑司が谷・音羽」を23エリア中の第1エリアに据えた経緯の前提として、**少なくとも2012年の時点で同地域が地形散歩の定番コース化していた**ことがわかる〔観察: 目次構成から〕。②004コースの説明文「浅い谷がいくつも入りこみ」は、雑司が谷・音羽の谷地形の特徴を一般向けに要約した表現として、BLOG-001/002（Natrium地形読図）等の民間読図資料と対にできる〔観察〕。ただし**004コース内で「音羽川」「弦巻川」の語を用いるか・流路をどう記述するかは本文未確認のため断定しない**〔未解決〕。
- **制限・未解決**: ①本文は未確認（品切中・書誌と目次一覧のみ。図書館現物で004コース本文の確認が必要）。②004コースの記述に「音羽川」「弦巻川」「水窪川」の語があるか、流路・湧水への言及の有無は未確認。③シリーズ「東京凸凹地形案内2」「東京凸凹地形案内3 地形と鉄道」（いずれも別冊太陽 太陽の地図帖）の当該コース有無は未走査〔書誌のみ確認〕。
