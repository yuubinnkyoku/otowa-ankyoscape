# [BOOK-112] 滝野川町誌（1933年）

- **書誌〔確認〕**: 滝野川町史編纂室（板橋区教育会）による『滝野川町誌』（昭和8年・1933）・NDL次世代デジタルライブラリー [book/1050221](https://lab.ndl.go.jp/dl/book/1050221)。**引用はOCR由来・要原文照合。**
- **谷端川の流路記述〔確認・repo初出の文言〕**: 谷端川は字南谷端・北谷端を経過して西巣鴨町に出で、小石川区に入る。「**之れが小石川**」〔OCR・要照合〕という下流呼称への言及。**「数年前に水害で死者」**の出た旨の記述〔OCR・水害の年・規模の文言は要照合・死者数は判読できず〕。谷端川の水害が1920年代末〜1930年代初頭に人命を損なったことの町誌レベルの記録で、[GOV-159](../gov/GOV-159.md)（1930年）の現況説明（氾濫の頻発）に呼応する。
- **千川上水の全線暗渠と道路併用〔確認・repo初出の文言〕**: 千川上水について「**大山（ハーモニカ横丁方面か・要照合）から滝野川町堀割を経て醸造試験所に入る全部の延長を暗渠として道路に併用**」（する計画・またはした結果）との文言〔OCR・時制は要照合〕。**千川上水の滝野川町内区間の全線暗渠化・道路併用**を、町誌が記録したことになる〔堀割＝醸造試験所（現・滝野川公園内・大蔵省醸造試験所）付近の千川開渠部の文脈〕。READMEの千川上水の暗渠化・千川通り化の過程（既述）に滝野川町区間の1933年時点の記述を加える。
- **橋梁表〔所在のみ・次回課題〕**: 谷端川・谷田川等の橋梁一覧表が収録されている〔OCRでの表の読み取りは未了・橋名の抽出は次回以降〕。
- **滝野川町下水道計画〔確認・要照合〕**: 排水区劃＝**谷端川・石神井川・谷田川流域＋田端平坦地**、吐口は多数で**谷端川等へ放流**〔OCR〕。[GOV-166](../gov/GOV-166.md)（1937年・4排水区）の前身に相当する記述。
- **位置づけ〔観察〕**: 1933年＝谷端川改修工事の測中（[GOV-160](../gov/GOV-160.md)の1934年変更の前年）の滝野川町側の総合町誌。①水害死者の記録（改修事業の背景の実態）、②千川上水の全線暗渠・道路併用の文言（千川通りの形成過程）、③下水道計画の排水区（谷端川を軸に据える）の3点が記録価値。
