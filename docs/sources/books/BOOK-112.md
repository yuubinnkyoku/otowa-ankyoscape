# [BOOK-112] 滝野川町誌（1933年）

- **書誌〔確認〕**: 滝野川町史編纂室（板橋区教育会）による『滝野川町誌』（昭和8年・1933）・NDL次世代デジタルライブラリー [book/1050221](https://lab.ndl.go.jp/dl/book/1050221)。**引用はOCR由来・要原文照合。**
- **谷端川の流路記述〔確認・repo初出の文言〕**: 谷端川は字南谷端・北谷端を経過して西巣鴨町に出で、小石川区に入る。「**之れが小石川**」〔OCR・要照合〕という下流呼称への言及。**「数年前に水害で死者」**の出た旨の記述〔OCR・水害の年・規模の文言は要照合・死者数は判読できず〕。谷端川の水害が1920年代末〜1930年代初頭に人命を損なったことの町誌レベルの記録で、[GOV-159](../gov/GOV-159.md)（1930年）の現況説明（氾濫の頻発）に呼応する。
- **千川上水の全線暗渠と道路併用〔確認・repo初出の文言〕**: 千川上水について「**大山（ハーモニカ横丁方面か・要照合）から滝野川町堀割を経て醸造試験所に入る全部の延長を暗渠として道路に併用**」（する計画・またはした結果）との文言〔OCR・時制は要照合〕。**千川上水の滝野川町内区間の全線暗渠化・道路併用**を、町誌が記録したことになる〔堀割＝醸造試験所（現・滝野川公園内・大蔵省醸造試験所）付近の千川開渠部の文脈〕。READMEの千川上水の暗渠化・千川通り化の過程（既述）に滝野川町区間の1933年時点の記述を加える。
- **橋梁表〔所在のみ・次回課題〕**: 谷端川・谷田川等の橋梁一覧表が収録されている〔OCRでの表の読み取りは未了・橋名の抽出は次回以降〕。
- **滝野川町下水道計画〔確認・要照合〕**: 排水区劃＝**谷端川・石神井川・谷田川流域＋田端平坦地**、吐口は多数で**谷端川等へ放流**〔OCR〕。[GOV-166](../gov/GOV-166.md)（1937年・4排水区）の前身に相当する記述。
- **位置づけ〔観察〕**: 1933年＝谷端川改修工事の測中（[GOV-160](../gov/GOV-160.md)の1934年変更の前年）の滝野川町側の総合町誌。①水害死者の記録（改修事業の背景の実態）、②千川上水の全線暗渠・道路併用の文言（千川通りの形成過程）、③下水道計画の排水区（谷端川を軸に据える）の3点が記録価値。

## 第323回追記（2026-11-25・水利章「千川用水」条と名勝旧蹟「千川上水跡」条・地質注の追加精査）

- **水利章「千川用水」条の全区間ルート列挙と「大山」＝板橋町の確定〔確認・制限①の一部解消・repo初出文言を含む〕**: 「**水源は多摩川上水の分流で、北多摩郡保谷村より石神井村に流れ、中新井、練馬町、上板橋、長崎を經て板橋町に入り、同停車場前を流れて瀧野川町堀割に出で王子町音無橋の上流で石神井用水と合する**」＝**1933年時点の千川用水の全区間ルートの町誌レベルの列挙**（保谷→石神井→中新井→練馬町→上板橋→長崎→板橋町停車場前→滝野川町堀割→**王子町音無橋の上流で石神井用水と合流するという流末の記録**＝[GOV-587](../gov/GOV-587.md)・[GAZ-048]⑩の「流末は滝野川村にて石神井川に入り」との対校〔町誌が「音無橋の上流で石神井用水と合する」と合流点を具体化する点が文言候補として新しい・原画像照合前提〕）。**「今は板橋町の大山から、瀧野川町の堀割を經て釀造試驗所に入る全部の延長を暗渠として、道路に併用し非常に便利となつた」**＝既述「千川上水の全線暗渠と道路併用」文言の全文＝**「大山」が「板橋町の大山」であることが本文で確定**（制限①の「大山（ハーモニカ横丁方面か・要照合）」の比定問題を、**板橋町側（現・板橋区大山・ハーモニカ横丁方面）と町誌自身が明記**する形で解消。暗渠・道路併用区間＝大山～滝野川町堀割～醸造試験所）。
- **名勝及旧蹟「千川上水跡」条（pp.814-816付近）＝『事跡考』引用と「天明七年」変異〔確認・対校点〕**: 「千川上水とは元祿九年に多摩郡仙川村の百姓太兵衞、德兵衞の兩人が幕府の命に依て先づ新座郡保谷村から玉川上水を分つて、北豐島郡巢鴨村迄の六里餘の行程を堀割りし…最初は右兩人の村の名卽ち仙川を以て名としたのだが後ちに文字をば千川と改め、事を奉ぜし村民兩人に氏を賜り且つ江府に屋敷地を賜つた…享保七年廢せられて最寄村々の用水とされた。卽ち其遺跡であるが**『事跡考』**には左の如く記されてある。**千川上水は常憲院殿の御代、板橋の西練馬の南石神井池より、本〓及柳原筋に引かれし水流なりしが、文照院殿の御代停止せらると見えたり。（石神井池を引きしと云ふは誤りにて助水に用ひしものならん）然るに明和六年再び此事を起し、安永年中落成して、庚申塚より駒込本〓湯島下谷淺草邊まで掛りしが、便ならざるを以て、天明七年又廢せらる、今多摩郡關前新田の邊より、當郡關村、中村、中荒井村、下板橋宿、瀧野川村等に其堀殘れり、流末は瀧野川村にて石神井川に入り…堀幅四、五尺或は廣き所も九尺に過ず**」＝**①新編武蔵風土記稿 巣鴨村条（[GAZ-048]⑩・同文言の引用元【專跡合考】）とほぼ同文の叙事を、町誌は『事跡考』の書名で引用**＝**書名の変種（事跡考／專跡合考）の対校点**、②**「天明七年又廢せらる」と天明7年系の廃止年をとる**（風土記稿本文は「天明六年」・[GAZ-048]⑩・[BOOK-328]の天明6閏10月系の対立に7年系の1票＝年次対立表に追加）、③**堀跡残存範囲の列挙（関前新田→関村・中村・中荒井村→下板橋宿・滝野川村）**と「流末は瀧野川村にて石神井川に入り」＝中流廃堀の地理列挙の追認（OCRの「中荒井村」は「中新井村」の誤読候補・[GOV-456]中新井村の旧千川上水と対照・要照合）、「行程六里餘」＝堀割延長変種の追認（新規数値ではない）。
