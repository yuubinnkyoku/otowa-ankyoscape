- **確定できる項目〔確認〕**: **設立=明治13年8月**（[GOV-252](GOV-252.md)系の千川水道会社設立記録と一致）・**資本金40,000円・悉皆払込済**・**決算期=年2回（6月・12月）**・**株主配当=年一割**・**株主人員7名**・**役員・使用人6名**・**事務所=麹町区八重洲町一丁目一番地**。

## ②人物録の千川水道役員（三菱系）〔確認文言〕

- **莊田平五郎（取締役）**: 「**三菱合資會社造船所支配人 三菱合資會社管事 …莊田平五郎 千川水道株式會社取締役 東京倉庫株式會社取締役 日本郵船株式會社取締役 山陽鐵道株式會社取締役 日本海員抜濟會理事 農商工高等會議員**」（住所: 小石川区林町五十番地）＝三菱合資の管事（総番頭格）が千川水道の取締役を兼ねる。
- **豊川良平（監査役）**: 「**三菱合資會社銀行部支配人 東京銀行集會所副會長 東京興信所評議員 …豐川良平…千川水道株式會社監査役**」（住所: 小石川区水道町三十七番地）＝三菱合資銀行部支配人（岩崎家の銀行担当重役）が監査役。
- **瓜生震（監査役）**: 「**三菱合資會社支配人 …瓜生震…千川水道株式會社監査役**」（麹町区上二番町三十六番地・日本銀行理事の兼任も本文中に見える）＝同じく三菱側の監査役。
- **専務取締役〔文言候補〕**: 人物録に「**第三十國立銀行頭取 株式會社秦野銀行取締役 千川水道株式會社専務取締役 明治生命保險株式會社取締役 明治火災保險株式會社監査役**」（本所区緑町四丁目四番地候補）の役職群の行があり、**深津鋼作**（三十銀行頭取・明治生命・明治火災との兼任で知られる）が対応する候補。OCR列崩れで姓名の直接対応は原表照合まで確定しない。
- **意義**: **明治30年時点で千川水道の取締役・監査役の過半を三菱合資の支配人級が占め**、経営の実権が既に三菱側にあったことが観察できる。明治40年の岩崎所有化〔[BOOK-140](BOOK-140.md)〕に先行する、**明治20年代後半〜30年代の三菱との結合の同時点スナップショット**。[BOOK-165](BOOK-165.md)（第三版・明治32年1月調）と同じ顔ぶれ（莊田・豊川・瓜生）が一版でも確認でき、結合が一過性でないことも分かる。
