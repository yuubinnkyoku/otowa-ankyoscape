# [BOOK-184] 東京地方（1940）＋日本案内記 関東篇（1930）— 境水衞所＝小金井桜堤の東端の定点〔第151回〕

- **書誌〔確認〕**: ①日本旅行協会編『東京地方』（1940年・NDL次世代デジタルライブラリー [book/1091012](https://lab.ndl.go.jp/dl/book/1091012)）。②鉄道省（鉄道大臣官房国人課・参謀本部）編『日本案内記 関東篇』（1930年・[book/1176338](https://lab.ndl.go.jp/dl/book/1176338)）。**両書の小金井の桜の条の本文がほぼ同一文言（同一テキスト系統）のため、同一ファイルに併記して登録する**（個別採番はしない方針）。**引用文言はすべてOCR由来で要原文照合**。
- **境水衞所＝小金井桜堤の東端の観察文言〔確認・repo初出の位置情報候補〕**: 『東京地方』（1940）——「**北多摩郡小金井村にあり中央線武蔵小金井·武藏境驛から約一粁·玉川上水道の兩側、小川水衞所から境水衞所まで約六粁に亘つて多數に櫻樹が植ゑられてあり、東京近郊隨一の櫻の名所となつてゐる所である**」。『日本案内記 関東篇』（1930）——「**武藏小金井驛の北一粁、玉川上水道の兩側、小川水衞所から境水衞所まで約六粁に亘つて植ゑられて居る**」。〔**①小金井の桜堤の範囲が「小川水衞所（小平・小川側＝西端）から境水衞所（東端）まで約6km」と両端の水衞所で表現される1930・1940年の観察文言＝境水衞所が桜堤の東端＝武蔵境側（境橋・武蔵境駅の南）に位置することを示す、これまでの境水衞所位置比定（[GOV-338](../gov/GOV-338.md)の1898年制度文言・[GOV-340](../gov/GOV-340.md)の1936年建物台帳・BLOG-220の玉川系水衞所群説）に加わる初の「距離・両端」形式の位置記録候補**。②両書とも官公署・準官公署系の旅行案内（鉄道省1930→日本旅行協会1940）で、**同一文言の10年間の固定**は編纂系統の継承を示す（独立の現地観察2件とは評価しない・文言は候補として扱う）。〕
- **境橋附近の補植樹の観察〔確認・文言候補〕**: 「**境橋附近では後年の補植樹が多く、隨って幹の大なるものが少いが、關野橋·新小金井橋邊には大樹が多い**」（両書ほぼ同文）＋「日の出の櫻は大木で目通幹圍二米八に達し」（1930）＋「今尙原樹が多數に現存し、日ノ出櫻·入日ノ櫻·三吉野櫻等は樹形の壯大と花容の優れてゐるので知られてゐる名木」（1940）＋樹種「**殆んど皆白山櫻でその中大和の吉野から移殖したものが大半を占め、花の紅を帶びたものは常陸の櫻川から移したものであると云ふ**」（1940）。〔**境橋附近＝桜堤の東端（境水衞所側）が「後年の補植樹」中心であることの1930-40年の現地観察**＝[GAZ-070](../gazetteers/GAZ-070.md)系の小金井桜沿革（元文期植栽・嘉永4年補植説）と対照できる樹齢構造の観察記録。〕
- **元文の頃・川崎平右衞門の植栽説〔確認・文言候補〕**: 「**これは元文の頃(紀元二三九〇年代)武藏野新田の世話役川崎平右衞門が幕府の許可を得て植ゑたものであると云ふが**」（1940）＝元文期の川崎平右衞門の植栽説の旅行案内での採録＝[GOV-341](../gov/GOV-341.md)（東京府史・元文2年請負・翌3年6月竣工・川崎平右衞門定孝）の通俗流通版の文言候補。
