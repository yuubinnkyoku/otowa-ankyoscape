- **意義〔観察〕**: ①**1982年（昭和57年・区制50年）時点の区広報課が選んだ四河川の写真記録**で、《千川桜堤》は**千川上水堤の桜並木（現在の千川通り桜並木・[GOV-114](../gov/GOV-114.md)板橋高校前桜並木の前身景観）を1982年に区が公式写真記録した初出候補**〔写真の撮影地点は未確認のため断定しない〕。②《谷端川》《弦巻川》は**1982年時点の河川景観（開渠残存・緑道整備前か否かを含め）を区公式写真で照合できる座標資料**（谷端川緑道の開園は1991年〔[GOV-008](../gov/GOV-008.md)/[GOV-009](../gov/GOV-009.md)〕・弦巻川跡の整備はそれ以降と推測されるが断定しない）。③《神田川》p.102は区境河川の記録で、弦巻川が合流する神田川下流域の1982年景観の候補〔弦巻川合流点の写真かは未確認〕。
