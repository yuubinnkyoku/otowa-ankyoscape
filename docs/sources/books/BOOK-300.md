## repoとの関連〔観察〕

- **「（一）千川用水の水車」＝千川上水の板橋区内水車を专論する文章**。repo既収録の千川水車群（斉藤水車〔[GOV-246](../gov/GOV-246.md)系〕・八成水車・田中水車・下板橋の落差工等）の目録化・位置特定に直結する可能性があるが、掲載水車の同定を行えていないため対応関係は断定しない〔所在のみ〕。
- **著者・小坂克信**は武蔵野台地の水利用研究者で、repo既収録の[PAP-022](../papers/PAP-022.md)（2005・武蔵野台地南部の水利用の基礎研究）・[BOOK-296](BOOK-296.md)（羽村紀要36号「羽村取水堰と目黒海軍火薬製造所」）と同著者の系譜。**千川用水を含む武蔵野の水路・水車の研究を一貫して行う著者の2016年断面**〔観察〕。
- （四）「その他の河川の水車」の対象河川（谷端川・前谷津川等の區内小河川を含むか）は未確認〔次回課題〕。
