# [BOOK-149] 戸塚町誌（1931）— 神田上水章と蟹川・秣川・清水川の本文文言

- **書誌〔確認〕**: 高田町・戸塚町関係の町史編纂関連の『**戸塚町誌**』（1931年刊・豊多摩郡戸塚町〔現・新宿区西早稲田〜高田馬場付近一帯〕の町誌）。NDL次世代デジタルライブラリー [book/1176223](https://lab.ndl.go.jp/dl/book/1176223)。**引用はすべて同館OCRテキスト由来。引用は原文画像との照合を要する。**〔戸塚町は神田上水（神田川）中流の南岸に接する町〕
- **神田上水章の流路・実態文言〔文言候補・repo初出の通年記述〕**: 「**神田上水は天正十八年德川氏入府以來の計畫にて其の竣工は詳でないが、慶長頃までは江戶に上水の無かつた事は府內備考にも記されて居るから慶長以降には違ゐあるまい、上水が本村の灌漑に至大の關係を有し農民の生活根源であつたことは云ふまでもなく、水車は明治末期迄設けられてゐた。原を北多摩郡吉祥寺なる井の頭池に發して高井戶、中野、淀橋に至り玉川上水の分派を受けて落合に至り更に妙正寺川を併せて戶塚高田の堺緣を東流して小石川關口町に至る、水路五里二十六町餘 戶塚に接する延長七百六十五間約十三町、水質溷濁、流狀稍急にして、舊時は漁撈を禁ぜられてゐた。**」＝**①戸塚から見た神田上水の流路（井の頭池→高井戸・中野・淀橋で玉川上水の分派を受ける→落合で妙正寺川を併せる→戸塚高田の堺→小石川関口）、②水路全長「五里二十六町餘」＋戸塚に接する区間「765間（約13町）」、③水車の操業期限（明治末期まで）、④水質溷濁・流状稍急・旧時漁撈禁止**という神田上水の町誌レベルの通年記述〔水路延長「五里二十六町」は[BOOK-147](../books/BOOK-147.md)（五里二十六町十五間）と一致する第2の文言。「玉川上水の分派を受けて」＝千川系の合流を指すと見られる。戸塚区間765間はrepo初出の区間長〕。
- **堰張・分水・賦金の文言〔文言候補・repo初出の制度文言〕**: 「**此水舊時小石川關口より埋樋に通じて小石川神田日本橋京橋に給與された。水源及び樋桝修繕費は灌水田反別に依り課賦され、戶塚は久保田に堰張を設け分水は例年五月乃至九月に官許の上にて行ふた。慶應三年の賦金二圓九十錢二厘とある。**」＝**①江戸市内への給水（関口から埋樋で小石川・神田・日本橋・京橋へ）、②水源・樋桝修繕費の賦課基準（灌水田反別）、③戸塚の久保田の堰張（分水堰）と5〜9月の官許分水、④慶応3年（1867）の賦金2円90銭2厘**という上水運用の末端記録〔堰張の地名（久保田＝現・西早稲田の久保田地名か）・官許分水の期間（5〜9月）・賦金の実数値ともにrepo初出候補。反別賦課は[GOV-283](../gov/GOV-283.md)等の受益村負担の系譜の末端用例〕。
- **清水川の文言〔文言候補・repo初出の川名〕**: 「**清水川 細流素々として戶山より落ち、大字戶塚地內を南北に流れて山手線ガード下にて神田上水に入(る)**」＝**戸山（旧尾州藩戸山屋敷〜現・戸山町・戸山3丁目の低地）から落ちる細流が大字戸塚地内を南北に流れ、山手線ガード下で神田上水に合流する小川「清水川」**の記録〔[地名・河川名対照表](../../地名・河川名対照表.md)の「清水之流」（西青柳町・雑司ヶ谷側の湧水流）とは別の、戸山側の神田上水への合流小川。戸山の湧水・谷頭文脈の候補。OCR末尾が欠けるが文意は一応通る〕。
- **秣川の文言〔文言候補・repo初出の川名〕**: 「**秣川 其の昔諏訪の森辨天池より發して源兵衞地內にて神田上水に入る**」＋地名由来として「**秣川は此の邊り多く秣を苅とり置かれたるに起る**」＝**諏訪の森の弁天池（現・新宿区の諏訪町・西早稲田付近）を源とし源兵衛地内で神田上水に合流した「秣川」（地名は秣〔まぐさ〕の刈置きに由来）**の記録〔諏訪の森辨天池という湧水池の存在の文言候補。「秣川」という川名はrepo初出〕。
- **馬尿川の小字名と秣川由来説〔文言候補・2026-11-17第160回追記・repo初出の字名〕**: 本誌の下戸塚の旧小字名リストに「**馬場崎自一〇四一番至一〇六九番 馬尿川自一〇七〇番至一〇七六番 川向自一〇七七番至一〇七八番**」とあり、地名由来の項に「**馬尿川は飛地にして源兵衞字向原に入る、秣川と同じ流れに沿ひ、秣川の名に因ぬるものであらう**」＝**①小字名「馬尿川」（番地1070〜1076・馬場崎と川向に挟まれた飛地）の1931年の記録、②馬尿川の窪地は秣川と同じ流れに沿い、秣川の名に因むとする地名由来説**〔**「馬尿川」という字名はrepo初出**。[BOOK-190](BOOK-190.md)（土地概評価戸塚町・1922）の「字、馬尿川一〇七〇-一〇七六番地(大字源兵衛字向原と秣川との間に挾まれたる飛地高田馬塲驛を距ること四丁許りの窪地なり)」と**同一番地・同一位置で整合する1931年側の本文文言**＝字名・位置・由来説の3点が1922・1931の2時点で揃う（OCR・要原文照合）。「馬尿川」は独立の川ではなく秣川（諏訪の森弁天池〜源兵衛地内で神田上水に合流）の流れに沿う窪地の字名として理解されるが、川名・字名の別は原照合まで断定しない〕。
- **蟹川＝戶山落の本文文言〔文言候補・repo初出の本文側確定文言〕**: 「**蟹川 太田道灌の狩に出でし地として人口に膾炙す、金川、加奈川、加二川とも書かれてゐる、下戶塚舊尾州藩戶山の池より發し馬場下を過ぎ、早稻田村中里村を經て、牛込山吹町小日向松ケ枝町を經て江戶川に入る、一名戶山落とも云ふ**」＝**蟹川の流路＝下戸塚の旧尾州藩戸山の池（発源）→馬場下→早稲田村・中里村→牛込山吹町・小日向松ケ枝町→江戸川合流、異表記＝金川・加奈川・加二川、別名＝戸山落、由来伝承＝太田道灌の狩の地**という一連の本文文言〔[地名・河川名対照表](../../地名・河川名対照表.md)の蟹川行（[BOOK-139](../books/BOOK-139.md)小石川區會史上巻の明治40年頃の区会文書文言候補「蟹川ノ水流ヲ江戶川ニ落ス」）の**本文側・流路つきの裏付け**。異表記3種・戸山落の別名も本文側で初めてまとめて確認。蟹川＝戸山落の同定の対照表行を更新〕。
- **位置づけ〔観察・内容メモ〕**: ①戸塚町は神田上水の南岸町で、同町誌が神田上水の流路（千川系合流・妙正寺川合流の順）を「玉川上水の分派を受けて落合に至り更に妙正寺川を併せて」と整理している＝[BOOK-147](../books/BOOK-147.md)（三助水）・[BOOK-148](../books/BOOK-148.md)（村方書上）と対校できる流路認識。②蟹川・秣川・清水川の3支流の合流点（江戸川/神田上水への流入位置）がいずれも本文で示されるのは貴重（早稲田〜戸山間の神田川低地の水系の記録）。

- **〔2026-11-18・第167回追記〕面影橋条（本誌に面影橋の記録がなかったことの補充・OCR要原文照合）**: 「**面影橋 姿見の橋とも云ふ、舊時此の橋よりする流螢のながめは宇治の流螢に比されて名所地とされた江戶砂子に「淀橋を姿見ずの橋と稱せるに對して、之を姿見の橋といふ、古昔中野長者の娘、淀橋より入水したるを此の橋にて發見せるによれりと、又南向閑話には異說を記せり、明應年中の頃此の里に和田◯負佐守祐といふあり娘に於戶姫といふ…小川左衞門次郞義次に嫁した…村山三郞武範…於戶姫長刀を以て…此の川邊に至りて。變りぬる姿見よとや行水にうつすかゞみ…**」＝**①面影橋=姿見の橋説（『江戸砂子』引用・淀橋=姿見ずの橋に対して面影橋を姿見の橋とする対の命名構造）、②古昔中野長者の娘の入水を淀橋で行い面影橋で発見したとする由来、③『南向閑話』の明應年中の於戶姫（和田◯負佐守祐の娘）の異説、④流螢の名所（宇治の流螢に比された）の景観記録**（[BOOK-148](BOOK-148.md)の姿見ず橋条・小淀橋条・[BOOK-195](BOOK-195.md)・[BOOK-194](BOOK-194.md)の面影橋異名群と対照表で対校できる面影橋由来の3系統目）〔「和田◯負佐守」の諱の欠字・歌の切れは原画像照合必須〕。

## 制限・未解決

- ①蟹川の流路文言の「馬場下」〜「小日向松ケ枝町」の経路は本文の通りだが、実際の旧流路の比定は1912年地籍図等との照合要。②「諏訪の森辨天池」「久保田の堰張」「源兵衞地内」の位置は本誌の記述のみでは未特定。③清水川の文言は末尾がOCRで欠ける（「入(る)」の補いは文意推定）。④本誌のOCR全文に「千川」「仙川」「水窪」「弦巻」「谷端」の語は0件（陰性記録・第131回掃引）。神田上水章の「玉川上水の分派を受けて」（淀橋で合流）が千川系を指すと見られるが、千川の名では現れない。
