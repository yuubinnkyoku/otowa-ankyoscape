- **「千川屋敷」図版の収録〔確認・図版番号の記録〕**: 図版目録に「**山王旅所門前町屋（二七七）千川屋敷（二六）竹島町の起立（二二九）**」＝**参考画帖第1冊に「千川屋敷」の図版（図版番号26）が収録されていること**〔前後の項目（山王旅所門前町屋・竹島町の起立・坂本町の起立・龜島町・元禄年中〜天保三辰年之形等）から、この「千川屋敷」は**八丁堀・龜島川入堀埋立地側の千川屋敷**（[第108回](../../README.md)の「元禄12年龜島川入堀半埋立でできた千川屋敷（八丁堀側）」・万延元年2月4日出火〔BOOK系・東京市史稿変災編〕）の画帖と推定されるが、図版内容の未確認のため推定として留保する〕〔**八丁堀側の千川屋敷について、東京市史稿（文章）に次ぐ図版資料の所在の記録＝小石川の千川屋敷との関係（同一千川家か）の検討課題の資料源**〕。
