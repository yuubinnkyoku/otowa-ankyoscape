# [BOOK-196] 菊牕偶筆（1881）— 天下名水秤量表の井頭上水370兩〔第167回〕

- **書誌〔確認〕**: 木村芥舟毅『菊牕偶筆』（1881〔明治14〕・NDL次世代デジタルライブラリー [book/893531](https://lab.ndl.go.jp/dl/book/893531)）。漢詩文・随筆の私家版。**引用文言はOCR由来で要原文照合。**
- **天下名水秤量表〔確認・核心・repo初出〕**: 「**天下名水秤量表云加茂川三百廿兩池田川三百五十兩仙臺柳◯水日光麓水三百六十兩大山玉川上水井頭上水各三百七十兩東京三十間濠大森六合川金川臺刀根川井頭中央佐倉天龍河中河各三百八十兩。仙臺和歌山會津岐阜武州鮫洲奧州白河伊勢山田程谷金澤大堰河各四百兩品川鶴見各四百十兩鎌倉戶塚鬱宮各四百卄兩。東京新橋日本橋大傳馬町麴街増上寺門前房州中板川大磯各四百五十兩小田原上州桐生廣島上總久留利川各四百八十兩澱河四百九十兩東京兩國近傍新潟各五百兩信州千玉川東京本所各五百十兩東京下谷淺草近傍出羽山形各五百卄兩**」＝**天下規模の名水の秤量表で、大山・玉川上水・井頭上水が各370兩、三十間濠・大森等が380兩、兩國近傍・新潟が500兩等と評価する文言**〔**①井頭上水（神田上水の水源系）の秤量評価370兩の用例（repo初出）、②[GAZ-066](../gazetteers/GAZ-066.md)（名水品彙〔幕末〕・井頭上水の温度40度・秤量43）・[BOOK-182](BOOK-182.md)（七碗歌「玉川上水神田上水は四十三匁」1908）と並ぶ名水品評系の新datapoint（ただし本表の單位「兩」は「匁」の異表記・崩れの候補で、43匁系との数値の関係〔370=37匁×10等〕は原照合・単位確認まで断定しない）、③玉川上水と井頭上水が同評価で並置される構造**〕。
- **位置づけ〔観察〕**: 名水品評の口碑は弦巻川（音羽の名水系〔GAZ-070〕・名水品彙の弦卷川）を含む体系だが、本表は井頭上水・玉川上水を天下の名水群（加茂川・日光・澱河等）の中で評価した点で、江戸の上水2系統の名水評価の明治初期の定点となる。
