# [BOOK-155] 蜀山人全集 巻2 — 南畝自署の玉水簾狂歌（「千とせの門」中の2首）

- **書誌〔確認〕**: 『**蜀山人全集 巻2**』（大田南畝・吉川弘文館・明治41年〔1908年〕刊。NDLメタデータの出版者表記「かなゝ」はOCR由来と判断・通説により吉川弘文館とされる）。NDL次世代デジタルライブラリー [book/993337](https://lab.ndl.go.jp/dl/book/993337)。「**千とせの門**」（南畝の狂歌集）の中に玉水簾関係の作品を2件確認。
- **①狂歌「音羽町玉水簾に…」〔確認文言・repo初出〕**: 「**音羽町玉水簾に養老の瀧の白玉扇をひらきて玉たれの小がめの酒を汲みれば天か下なる養老の瀧**」＝**音羽町の玉水簾を養老の瀧（伝説の霊泉）に見立てた狂歌で、南畝が玉水簾を題材にした作品**。〔武江年表（[BOOK-154](../books/BOOK-154.md)）の文化9年秋の造営記事の直後に載る狂歌とは別の、玉水簾を詠んだ南畝の第二の作品として、音羽の滝（玉水簾）の知名度・狂歌文化の中での位置を示す資料〕
- **②詞書「神齡山の麓に音羽町瀧あり玉簾と名づく」＋狂歌「深山より…」〔確認文言・repo初出・最重要〕**: 「**神齡山の麓に音羽町瀧あり玉簾と名づく**」との**詞書（ことばがき）**を付け、その下に「**深山より落くる瀧の玉すだれかゝけてやみん水無月の雪**」の狂歌を載せる〔全集版の文言。武江年表（[BOOK-154](../books/BOOK-154.md)）の同歌は「かゝけてそ見る水無月の空」で、**第4句に異同がある（雪／空）**＝版本系統の異同として要照合〕。＝**南畝自身が「玉簾（玉水簾）」の名を詞書に書き、その滝に向けて狂歌を詠んだ一次テキスト**。
  - 〔**本詞書・自署作品の存在は、[BOOK-151](../books/BOOK-151.md)（遊歴雑記初編）の「南畝大人は玉水簾と筆を投せり」＝大田南畝が命名者とする伝承を、南畝の作品集という一次資料のレベルで裏付ける**。ただし詞書は「玉簾と名づく」と滝の名を記すのみで、**命名行為そのものを描写するものではない**ため、「南畝が命名した」ことの直接的証明ではなく、あくまで命名説を強める資料と位置づける（断定しない）。
  - 〔**「神齡山」は音羽町の裏手（西）の山の呼称の候補**として初出の文言。音羽谷の谷頭斜面（護国寺・弦巻川側）を指すと推定されるが、他史料での用例は今回確認できず、比定は今後課題〕
- **③[BLOG-185](../blogs/BLOG-185.md)（北大路魯山人の玉水簾命名句説）への影響〔観察〕**: 南畝（1749〜1823）の自署狂歌が作品集レベルで実在することが確認されたことで、**命名の狂歌を魯山人（1883〜1955・文化9年〔1812〕造営と時代が合わない）に帰する説はさらに成立しにくくなった**。魯山人説の弱化を記録。

## 制限・未解決

- ①全集（1908年刊）は南畝の作品を後代に編集・翻刻したものであり、**「千とせの門」の原本（南畝の自筠稿本・写本系統）との文言照合はできていない**（「雪／空」の第4句異同のどちらが原形かは未解決）。②「千とせの門」の当該2首の詠年代（文化9年〜文化13年のどの時点か）は全集の配列からは特定できなかった（玉水簾の造営年代対立の解決にはつながらない）。③「神齡山」の比定・他史料での用例の探索は今後課題。④出版者のメタデータ表記「かなゝ」の意味は未解決（OCR由来と推定）。
