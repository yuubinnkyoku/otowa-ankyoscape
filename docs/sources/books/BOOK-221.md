# [BOOK-221] 東京市衛生試験所報告 明治44年（1912）— 明治36/37年の千川上水水質試験

- **書誌〔確認〕**: 東京市衛生試験所編『東京市衛生試験所報告 明治四十四年』（1912・NDL次世代デジタルライブラリー [book/837096](https://lab.ndl.go.jp/dl/book/837096)）。業務概況（衛生試験所の試験体系=上水・堀井水・水源用水・河水・池水）と年度別統計表を収録。**引用文言はOCR由来で要原文照合**。
- **水源用水試験としての千川上水の文言〔文言候補・repo初出〕**: 「**(3)水源用水試驗 神田上水ノ水源タル府下北多摩郡三鷹村、井ノ頭池ノ池水ニ就キ水質ヲ試驗シ（三十五年乃至三十六年）本〓區内ニ散在セル千川上水ニ就キ水質試驗ヲ施行セリ（三十六年、三十七年）**」＝**①衛生試験所の「水源用水試験」部門において、神田上水の水源（井ノ頭池）と並んで「本市内に散在する千川上水」の水質試験が実施された、②実施年度は明治36年と明治37年**。〔**明治36〜37年時点で衛生試験所が「千川上水」を市内に散在する水源用水（飲料水等の供給源）として把握し、試験対象とした記録＝岩崎千川水道（民営・明治13年〜41年営業はGOV-172/BOOK-077系）が末期的に残っていた時期の市の衛生行政からの観測点。repoでは千川上水の水質試験の実施文言は本登録が初出**〕。
- **統計表の数値〔文言候補〕**: 明治36年の表「**丙、千川上水試驗 一（一）一種／（明治36年＝一種?）**」と読める行、明治37年の表「**丙、千川上水試驗 三〇種**」＝**明治37年度の千川上水試験は30種（明治36年度は1種との判読候補）**。〔**年度別の試験種数（甲上水/乙堀井水/丙千川上水/丁…の区分）として整理された統計表上の独立行であり、千川上水が上水・堀井水と独立の第三分類（丙）に置かれていたことが分かる**〕。
- **前段の体系文言〔文言候補・堀井水と千川上水の併置〕**: 「**(2)堀井水 市內ニ存スル飮用堀井ニ就テ施行スルモノニシテ、水質ノ良否ノミナラス併テ病原菌ノ存否ヲ檢査スル〓アリ**」＝**市内の飲用堀井（掘り井戸）の試験体系との併置で、千川上水が堀井水でも市水道栓でもない独自の供給源として扱われる視点の確認**。

## 制限・未解決

- ①「本〓區内」の「〓」（判読不能文字・「本市内」「本区内」等の候補）と36年「一種」/37年「三〇種」の判読は原画像照合前提（統計表の段組崩壊大）。②明治36/37年試験の採水地点（千川上水のどの地点・どの事業者の水か）は本報告では特定できず、採水記録の原本（試験台帳）の所在は未調査。③試験結果（成分・判定）の数値は本報告（明治44年報告=明治44年分の業務報告）の統計表では種数のみで、明治36/37年の個別結果は各年度の報告書（明治36/37年報告）の確認が要る（未入手）。
