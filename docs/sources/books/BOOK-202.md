# [BOOK-202] 十方庵遊歴雑記 二編（江戸叢書活字版）— 千川上水の廃絶年代文言と中野桃園の江戸期観察

- **書誌〔確認〕**: 『十方庵遊歴雑記||江戸惣鹿子名所大全 : 増補. 巻の4-6』（**二編 上・中・下**）。釈敬順（十方庵大浄）著（江戸惣鹿子名所大全側は藤田理兵衛 作・菱川師宣 画）。江戸叢書刊行会の活字版（大正5年〔1916〕・同叢書の[BOOK-151](BOOK-151.md)〔初編〕・[BOOK-152](BOOK-152.md)〔四編〕・[BOOK-144](BOOK-144.md)〔五編〕と同一シリーズ）。次世代デジタルライブラリー [book/952978](https://lab.ndl.go.jp/dl/book/952978)。本書の条内に「文化十一甲戌年」の言及があり**草稿は文化11年（1814）以降**〔二編単独の成立確定年は本書内では確認できず・要照合〕。**すべての引用は同館OCRテキスト由来で、文言は原文（活字版原本・写本）との照合を要する。**
- **千川上水の廃絶年代の一説〔確認・repo初出候補・最重要〕**: 葛飾郡亀有村の条（引舟の条）に「又**豐島郡上板橋の南うらてより巢鴨通駒込筋本〓〔湯島候補・OCR〕へ引て、湯島下谷邊へ分水せしを千川上水と稱せしが、自然と安永の末廃れて今只名のみをいひ傳ふ、今只一圓に珍重するは王川上水〔玉川上水OCR候補〕と猪のかしらの兩分水のみ也**」＝
  1. **千川上水の取水・流路の各要素の本文側文言**: ①起点＝**豊島郡上板橋の南うら手**、②経路＝**巣鴨通→駒込筋→本〓（湯島候補）**、③給水先＝**湯島・下谷方面への分水**＝千川上水の流路系譜（千川・巣鴨・駒込・湯島・下谷）を十方庵が一文に纏めた記録〔各要素の既出言及との対応・「本〓」の原字は要照合〕。
  2. **廃絶年代「安永の末」説〔repo初出候補〕**: 「自然と安永の末廃れて今只名のみをいひ傳ふ」＝**安永末（安永9〜天明元年頃・1780年前後）に自然に廃れ、文化〜文政期（本書成立時点）には「名のみ」になった**という観察。千川上水の廃止・衰亡年代の諸説（江戸期の断水以降も通水が部分的に続いた説・明治初年の千川水道解散〔第139回〕等）に対して**「安永の末に自然廃絶・文化期には名のみ」という江戸後期の一次観察の新系統**〔「自然と」廃れたという表現（段階的機能停止の観察）と諸説との整合・他の年代史料との対校は今後の課題〕。
  3. **「玉川上水と猪の頭の両分水」**: 文化〜文政期に江戸周辺で「一圓に珍重」される水源が玉川上水と**猪の頭（井の頭）**の両分水のみという水道事情の観察〔井の頭池の給水系の江戸後期の評価の用例〕。
- **中野通桃園（桃林）の吉宗御成記録〔確認・[BOOK-150](BOOK-150.md)・[GAZ-039](../gazetteers/GAZ-039.md)の桃林条の対校〕**: 「四ツ谷桃園煎茶の佳興」条（二編の中・第4条）に「**四つ家中野通桃園といふは、寳仙寺より西北の方拾貳三町鍋屋橫町の筋向より北へ入て凡四五町にあり、むかし有德尊君は度々成せ賜ひしとかや、則ち公の成せ賜ふ處は、小山のごとく五六尺も高く築たて聊庭樹を植たり、則ち此處に御床机をすゑさせ賜ふとなん**」＋「**浚明尊君は繁々成せ賜はざりし故にや、桃樹の御手入もなければ蟲生じ或は立枯等にて、近年は桃樹甚だ減少して名のみなれば、文化九申年新たに畑の畝々に桃樹の苗を植ならべ賜ふべきも、莫大の御入用に付…**〔OCR崩れ・植树沙汰の帰結は要照合〕」＝
  1. **位置**: 中野通桃園＝**宝仙寺の西北12〜13町・鍋屋横町の筋向から北へ4〜5町**＝中野桃林の位置の十方庵側の記録〔[GAZ-039](../gazetteers/GAZ-039.md)（改正新編江戸志・享保台命の桃植樹・御腰掛場・御馳走山）・[BOOK-195](BOOK-195.md)（中野町勢要覧の成趣園・小淀）との対校。桃園＝桃林の呼称の揺れは明記せず「中野通桃園」として記録〕。
  2. **吉宗（有徳尊君）の度々の御成・御床机・五六尺の小山**: 御成時に築いた小高みと御床机の設置の記録＝中野桃の名所の成立期（享保期）の実況観察の系統。
  3. **家治（浚明）期の衰退説と文化9年（1812）の植苗沙汰**: 将軍代替後の桃樹減少と文化9年の新規植栽計画〔莫大の御入用で頓挫したような文脈だがOCR崩れのため帰結は断定しない〕。
- **金剛寺条〔確認〕**: 小日向金剛寺の条（二編の中・第17条）に「金剛寺は東武小日向上水端…**なを門前には神田上水白堀の流れを望み**、後は山をかたどりて…」＋「**その頃臺所賄ふ禪門從者を置し處を、今雜司ヶ谷といひ又僧司ヶ谷とも書よし**」＋「往古はみな一圓金剛寺の屋敷と見えたり」＝**金剛寺門前の神田上水（白堀）の「流れを望む」という観察文言**〔金剛寺=松橋弁天（[GAZ-094](../gazetteers/GAZ-094.md)）の上水岸の位置記録・雑司ヶ谷の僧司ヶ谷説は[BOOK-144](BOOK-144.md)の蔵主ヶ谷・僧司谷説と対校〕。
- **雑司ヶ谷鬼子母神の古絵馬〔確認〕**: 雑司が谷鬼子母神の古絵馬条（二編の下・第4条）に「此鬼子母の社の右の方外擔〔外陣候補〕の根押の上に、古繪馬二枚かゝれり…**さくらの枝に鐘懸りて白拍子の立烏帽子をいたゞき、右に中啓を持て梢をながむる繪馬あり…發句は中村富十郞自筆…咲からは龍頭にとゝけ山さくら 慶子拜書**」＝**鬼子母神の古絵馬の図様・奉納人の一次観察記録**〔repoの鬼子母神資料（天正6年棟札〔GAZ-094〕・星跡の井系譜）へのappend。絵馬の年代は「月日等貞には見えがたき」として判読不能と明記〕。
- **池袋村天満宮〔確認・池袋村の江戸期記録〕**: 「池袋村天満宮のためし」条（二編の下・第5条）に「武州豐島郡**池袋村は、雜司ケ谷法妙寺〔法明寺OCR候補〕の地尻より西北の方凡二十餘町にあり、上下とふたつにわかれて、家數二百餘軒、一村の廣き事貳拾町四方**…當村に助右衛門といえる農夫の宅に、天滿宮を勸請して**池ぶくろの天神**とて、山の手一圓に評判し…」＝池袋村の規模（上下2分・家数200余・方20町）と池袋天神の流行流転の記録〔弦巻川源流域（池ヶ谷・丸池〔BOOK-144〕）の村側の江戸期記録〕。
- **署名の「武城白堀道人」〔確認・白堀呼称の用例〕**: 巻頭著者表示「**武城白堀道人前廓然盡 十方菴大淨老衲著述**」＝[BOOK-144](BOOK-144.md)（五編の「東武白堀鮮僧」）と同型の**白堀を含む自称・署名**の二編の用例〔「武城」=東武のOCR変種候補・原文照合必須〕。

## 制限・未解決

- ①すべての文言はOCR由来で「本〓（湯島候補）」「王川上水（玉川候補）」「法妙寺（法明寺候補）」「外擔（外陣候補）」等の原字形は要照合。②千川上水の「安永の末」廃絶説と、江戸後期〜明治の千川系史料（千川水道の存続記録等）との整合の検証は次回以降（廃絶の意味＝完全断水か・機能低下かも本書内では確定できない）。③二編単独の成立確定年は未確認（文化11年以降と推定する根拠は文中の年代言及のみ）。④四ツ谷桃園条の文化9年植苗沙汰の帰結箇所はOCR崩れで断定できない。⑤中野通桃園の「桃園」と[GAZ-039](../gazetteers/GAZ-039.md)・[BOOK-148](BOOK-148.md)の「桃林」の表記関係（同一地名の別表記か）は本資料内では断定しない。
