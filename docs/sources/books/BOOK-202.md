# [BOOK-202] 十方庵遊歴雑記 二編（江戸叢書活字版）— 千川上水の廃絶年代文言と染井柳沢家林泉の千川引水文言と中野桃園の江戸期観察

- **書誌〔確認〕**: 『十方庵遊歴雑記||江戸惣鹿子名所大全 : 増補. 巻の4-6』（**二編 上・中・下**）。釈敬順（十方庵大浄）著（江戸惣鹿子名所大全側は藤田理兵衛 作・菱川師宣 画）。江戸叢書刊行会の活字版（大正5年〔1916〕・同叢書の[BOOK-151](BOOK-151.md)〔初編〕・[BOOK-152](BOOK-152.md)〔四編〕・[BOOK-144](BOOK-144.md)〔五編〕と同一シリーズ）。次世代デジタルライブラリー [book/952978](https://lab.ndl.go.jp/dl/book/952978)（江戸叢書巻ノ四に同内容の並行冊 [book/1912998](https://lab.ndl.go.jp/dl/book/1912998)）。本書の条内に「文化十一甲戌年」の言及があり**草稿は文化11年（1814）以降**〔二編単独の成立確定年は本書内では確認できず・要照合〕。**すべての引用は同館OCRテキスト由来で、文言は原文（活字版原本・写本）との照合を要する。**
- **千川上水の廃絶年代の一説〔確認・repo初出候補・最重要(第178回登録分)〕**: 葛飾郡亀有村の条（引舟の条）に「又**豐島郡上板橋の南うらてより巢鴨通駒込筋本〓〔湯島候補・OCR〕へ引て、湯島下谷邊へ分水せしを千川上水と稱せしが、自然と安永の末廃れて今只名のみをいひ傳ふ、今只一圓に珍重するは王川上水〔玉川上水OCR候補〕と猪のかしらの兩分水のみ也**」＝
  1. **千川上水の取水・流路の各要素の本文側文言**: ①起点＝**豊島郡上板橋の南うら手**、②経路＝**巣鴨通→駒込筋→本〓（湯島候補）**、③給水先＝**湯島・下谷方面への分水**＝千川上水の流路系譜（千川・巣鴨・駒込・湯島・下谷）を十方庵が一文に纏めた記録〔各要素の既出言及との対応・「本〓」の原字は要照合〕。
  2. **廃絶年代「安永の末」説〔repo初出候補〕**: 「自然と安永の末廃れて今只名のみをいひ傳ふ」＝**安永末（安永9〜天明元年頃・1780年前後）に自然に廃れ、文化〜文政期（本書成立時点）には「名のみ」になった**という観察。千川上水の廃止・衰亡年代の諸説（江戸期の断水以降も通水が部分的に続いた説・明治初年の千川水道解散〔第139回〕等）に対して**「安永の末に自然廃絶・文化期には名のみ」という江戸後期の一次観察の新系統**〔「自然と」廃れたという表現（段階的機能停止の観察）と諸説との整合・他の年代史料との対校は今後の課題〕。
  3. **「玉川上水と猪の頭の両分水」**: 文化〜文政期に江戸周辺で「一圓に珍重」される水源が玉川上水と**猪の頭（井の頭）**の両分水のみという水道事情の観察〔井の頭池の給水系の江戸後期の評価の用例〕。
- **染井の柳澤家の林泉（六義園）の瀧の千川引水文言〔2026-11-25・第317回追記・repo初出・第178回掃引の見落とし回収〕**: 千代が堰条（952978 p186付近の条）に「…別して三の瀧の左右は得もいはれぬ怪岩のおもしろさ、天然のごとき奇木怪樹生茂り、取分瀧の落口又瀧壺の風情一々奇々妙々にして、只記憶にのみ殘りて、禿筆には書取がたし、**上にあらはす彼染井の里に名家たる、柳澤家の林泉は山幾重となく折重り、別して瀧はむかし千川上水を庭へ引て、風景を巧みにすといへど、瀧ツ〔シはOCR〕の丈漸く五尺餘に過べからず、殊更今千川の水行断〔刮はOCR・「断」判読候補〕れ飛泉かゝらねば風情もなし**、然るに此**千代が堰の飛泉は武州第一の名瀧**なれば、絕て公務の人に見物を許さぬも理りかや、此飛泉の眞向池を隔てゝ岡の上に亭あり、間口六間奧行三間半かとよ…件の飛泉を正面に見る…**彼千載集に、岩間より落來る瀧のしらいとは、むすはて見るも凉しかりけり**、とよみしは、かゝる風景に…」＝
  1. **「むかし千川上水を庭へ引て」＝染井の柳沢家林泉（六義園）の瀧への千川上水引水の二編側の文言**（repo初出。初編第69条〔[BOOK-151](BOOK-151.md)⑦染井松平甲斐守下屋敷林泉条の「板橋の驛の彼方より千川上水を爰に引て」伝承文言〕に対応する**二編側の並記で、「上にあらはす」は初編側の記述を指すと読める**〔同定は照合まで保留〕）。
  2. **「今千川の水行断れ飛泉枯れ」＝執筆時（文化〜文政期）に千川上水の水が止まって六義園の飛泉が枯れていた現勢観察**＝前項「安永の末廃れて今只名のみ」（二編内の別条）と同じ観察の六義園側の裏付けで、千川断水後・明治千川水道（[GOV-226](../gov/GOV-226.md)・1877接手）以前の六義園の滝の状態を伝える一次観察〔[BLOG-244](../blogs/BLOG-244.md)の六義園池水と鶏声ヶ窪谷頭の検討・[GOV-329](../gov/GOV-329.md)（1931年・大池の千川余水）への系譜上の前段として位置づけ。滝の丈「五尺余」の初編条の「九尺計り」との差は描写の焦点・判読の課題として並記〕。
  3. **千代ヶ堰の飛泉の記述群〔repo初出〕**: 「武州第一の名瀧」・見物は謹んで許されない・飛泉の正面の亭（間口6間・奥行3間半・三方欄干・瀧までの渡し24〜25間）・「千載集」の「岩間より落來る瀧のしらいとはむすはて見るも凉しかりけり」の歌＝**千代ヶ堰（江戸の名瀑・神田上水系の景観）の江戸期随筆レベルの記録**〔千代ヶ堰文言はrepo grep初出。神田上水（江戸川）系の景観史の資料として追加〕。
- **中野通桃園（桃林）の吉宗御成記録〔確認・[BOOK-150](BOOK-150.md)・[GAZ-039](../gazetteers/GAZ-039.md)の桃林条の対校〕**: 「四ツ谷桃園煎茶の佳興」条（二編の中・第4条）に「**四つ家中野通桃園といふは、寳仙寺より西北の方拾貳三町鍋屋橫町の筋向より北へ入て凡四五町にあり、むかし有德尊君は度々成せ賜ひしとかや、則ち公の成せ賜ふ處は、小山のごとく五六尺も高く築たて聊庭樹を植たり、則ち此處に御床机をすゑさせ賜ふとなん**」＋「**浚明尊君は繁々成せ賜はざりし故にや、桃樹の御手入もなければ蟲生じ或は立枯等にて、近年は桃樹甚だ減少して名のみなれば、文化九申年新たに畑の畝々に桃樹の苗を植ならべ賜ふべきも、莫大の御入用に付…**〔OCR崩れ・植树沙汰の帰結は要照合〕」＝
  1. **位置**: 中野通桃園＝**宝仙寺の西北12〜13町・鍋屋横町の筋向から北へ4〜5町**＝中野桃林の位置の十方庵側の記録〔[GAZ-039](../gazetteers/GAZ-039.md)（改正新編江戸志・享保台命の桃植樹・御腰掛場・御馳走山）・[BOOK-195](BOOK-195.md)（中野町勢要覧の成趣園・小淀）との対校。桃園＝桃林の呼称の揺れは明記せず「中野通桃園」として記録〕。
  2. **吉宗（有徳尊君）の度々の御成・御床机・五六尺の小山**: 御成時に築いた小高みと御床机の設置の記録＝中野桃の名所の成立期（享保期）の実況観察の系統。
  3. **家治（浚明）期の衰退説と文化9年（1812）の植苗沙汰**: 将軍代替後の桃樹減少と文化9年の新規植栽計画〔莫大の御入用で頓挫したような文脈だがOCR崩れのため帰結は断定しない〕。
- **金剛寺条〔確認〕**: 小日向金剛寺の条（二編の中・第17条）に「金剛寺は東武小日向上水端…**なを門前には神田上水白堀の流れを望み**、後は山をかたどりて…」＋「**その頃臺所賄ふ禪門從者を置し處を、今雜司ヶ谷といひ又僧司ヶ谷とも書よし**」＋「往古はみな一圓金剛寺の屋敷と見えたり」＝**金剛寺門前の神田上水（白堀）の「流れを望む」という観察文言**〔金剛寺=松橋弁天（[GAZ-094](../gazetteers/GAZ-094.md)）の上水岸の位置記録・雑司ヶ谷の僧司ヶ谷説は[BOOK-144](BOOK-144.md)の蔵主ヶ谷・僧司谷説と対校〕。
- **雑司ヶ谷鬼子母神の古絵馬〔確認〕**: 雑司が谷鬼子母神の古絵馬条（二編の下・第4条）に「此鬼子母の社の右の方外擔〔外陣候補〕の根押の上に、古繪馬二枚かゝれり…**さくらの枝に鐘懸りて白拍子の立烏帽子をいたゞき、右に中啓を持て梢をながむる繪馬あり…發句は中村富十郞自筆…咲からは龍頭にとゝけ山さくら 慶子拜書**」＝**鬼子母神の古絵馬の図様・奉納人の一次観察記録**〔repoの鬼子母神資料（天正6年棟札〔GAZ-094〕・星跡の井系譜）へのappend。絵馬の年代は「月日等貞には見えがたき」として判読不能と明記〕。

## 制限・未解決

- ①すべての文言はOCR由来で「本〓（湯島候補）」「王川上水（玉川候補）」「法妙寺（法明寺候補）」「外擔（外陣候補）」「瀧シ（瀧ツ候補）」「水行刮れ（断れ候補）」等の原字形は要照合。②千川上水の「安永の末」廃絶説と、江戸後期〜明治の千川系史料（千川水道の存続記録等）との整合の検証は次回以降（廃絶の意味＝完全断水か・機能低下かも本書内では確定できない）。③二編単独の成立確定年は未確認（文化11年以降と推定する根拠は文中の年代言及のみ）。④四ツ谷桃園条の文化9年植苗沙汰の帰結箇所はOCR崩れで断定できない。⑤中野通桃園の「桃園」と[GAZ-039](../gazetteers/GAZ-039.md)・[BOOK-148](BOOK-148.md)の「桃林」の表記関係（同一地名の別表記か）は本資料内では断定しない。⑥**第317回追記の染井林泉条は条の帰属正式名（見出し）・頁確定が今後の原照合課題**。「上にあらはす」の指示対象（初編条か二編内の前出か）も照合まで保留。
