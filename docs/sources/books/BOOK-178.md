- **目録の条目名〔確認・repo初出の系統〕**: 目録に「**千川上水堀割松平伊豆守殿名言の事**」の独立条目がある＝**千川上水の掘割停止の逸話が田沼意次関連の実録として採録される**。天明6年の油不足の条に続けて千川上水の条が置かれ、天明年中の再興試行と田沼時代の政治との関連で語られる構成（文脈の帰属は原画像照合待ち）。
- **千川上水の水源文言候補〔OCR候補〕**: 「**上水ハ二流にして其水源い玉川と同流なり**」（崩れを含む）＝千川上水の水源を玉川（上水）と同流とする記述。**「上水二流」の意味（千川上水が二つの流れを持つのか・千川と神田の二上水を指すのか）はOCR崩れのため本書からは確定しない。**

- **停止理由の文言候補〔OCR候補・repo初出の観点〕**: 「**其所謂ハ玉川神田の上水のためい出金…堀ハ土なり樋ハ木なり…**」（崩れ大）＝**千川上水の掘割停止の理由として「玉川（上水）・神田（上水）のための出金」**（既存二上水の費用・水利への配慮）**と「堀は土・樋は木」（土木の実費）**という論理が語られる候補＝**千川上水の停止史に「既存上水との費用競合」という観点を加える文言候補**。後続の「是を百姓に賣る時ハ火に…眼前なりとて千川上水…やめ」の部分は崩れが激しく、火患・売水の文脈は原画像照合まで解釈しない。
