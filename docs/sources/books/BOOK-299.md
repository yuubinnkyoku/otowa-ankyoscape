## repoとの関連〔観察〕

- **滝野川村＝千川上水終点部・王子分水経由地・谷端川水系の核心の旧村**: 千川上水の下流（西巣鴨〜滝野川〜王子分水・分配堰）と谷端川（旧滝野川川筋）の双方に接する村域。**芦川家文書が村方（名主級家）の文書群であれば、千川上水の分水・水車・王子分水の村側一次史料の可能性があるが、収録内容・頁数・文書数は未確認のため一切断定しない**〔所在のみ〕。
- **[BLOG-127](../blogs/BLOG-127.md)が「北区史」経由で引用した王子分水の工期・工区（慶応元年・高桝跡〜大砲製造所間の新規開削等）の該当頁・掲載古地図の書誌特定は未解決のまま残っていた**。本資料編（または同『北区史』の通史編・資料編他巻）が同ブログの引証元候補だが、BLOG-127の引用が本巻か他巻かは本文未確認のため確定しない〔次回以降の確認課題〕。
- **芦川家**: repo内の全掃引（grep）で「芦川」の初出＝**本書の目録備考が初記録**。滝野川村の旧家として他史料での登場は未確認（芦川家の家格・千川上水組合内での役割は本文確認後に判断）。
- **同名の芦川家文書の混同に注意〔観察・2026-11-24・第306回〕**: 稲城市大丸地区の芦川家文書（古文書152点・検地帳・村明細帳・村絵図・大丸用水関係文書・訴訟関係文書を含むとされる＝市公式ページ由来の検索情報で、ページ自体は403により直接確認未達・Waybackにも未捕獲）と、和歌山県立博物館の芦川家文書（紀伊藩上級家臣・紙本墨書53点・文化遺産オンライン登録〔https://online.bunka.go.jp/heritages/detail/86206 を2026-11-24に直接確認〕）が存在し、**いずれも滝野川村の芦川家とは別家**。芦川姓・「芦川家文書」での検索と引用の際は3家の区別が必要。
