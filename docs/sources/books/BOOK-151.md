# [BOOK-151] 十方庵遊歴雑記 初編（江戸叢書活字版）— 音羽の瀧の造営年代・伏越文言・玉水簾

- **書誌〔確認〕**: 『**十方庵遊歴雑記 初編‖江戸惣鹿子名所大全 : 増補. 巻の1-3**』（**江戸叢書刊行会・1916年**の江戸叢書冊。『十方庵遊歴雑記』初編と『江戸惣鹿子名所大全』増補巻1-3を収める活字版）。NDL次世代デジタルライブラリー [book/952977](https://lab.ndl.go.jp/dl/book/952977)。本条の音羽の瀧条は「遊歴雑記初編の中」の文言（ページ Headers「遊歴雜記初編の中・江戶叢書卷の三」）。**引用はすべて同館OCRテキスト由来であり、文言は原文（江戸叢書活字版さらにその底本）との照合を要する。**
- **①音羽の瀧の造営年代・規模・人工性〔確認文言・repo初出の造営年代の文言〕**: 「**文化初年の頃、音羽町壹丁目西橫丁崖下に、音羽の瀧と云ふものを作れり、瀧の幅六尺計り高さ五尺餘有、瀧の落口は岩を穿、西の崖通りを伐開き、下流を〓くし、もろ〓〓の樹木を植込み、石を並べ燈籠をすえ、橋を渡して風景巧みに作りて、音羽の瀧と號せり**」＝**①音羽の瀧が文化初年（1804年頃）に音羽町一丁目西横丁崖下に作られたこと、②幅六尺計り・高さ五尺余、③落口は岩を穿ち、崖通りを伐開き、樹木を植込み、石を並べ、燈籠を据え、橋を渡して風景を巧みに作った人工性**の記録。〔[GAZ-035](../gazetteers/GAZ-035.md)（町方書上149・音羽町の小川中程の高さ5尺の流落し＝文化13年5月・小滝・「玉簾」）と対校できる。町方書上の「文化13年5月」に対して本条は「文化初年の頃」で年代のずれがあり、同一の滝か複数の改修かは原典照合後に判断する（断定しない）〕。
- **②弦巻川の水源・流末と「目白下上水の埋み樋」の伏越文言〔確認文言・伏越文言の第4系統〕**: 「**一體此水池袋村より出で雜司ケ谷村みたけの下を過て弦卷川といひ、末は目白下上水の埋み樋を流れて江戶川に合流せり**」＝**①この水は池袋村より出で雑司ヶ谷村「みたけ」（＝御嶽）の下を過ぎて弦巻川と称し、②流末は目白下で上水（神田上水）の埋み樋を流れて江戸川に合流する**という弦巻川の流路認識の江戸期文言。〔**弦巻川が桜木町付近で神田上水の伏越（樋）を通って江戸川に合流する構造を伝える文言の系譜（[GAZ-048](../gazetteers/GAZ-048.md)の「石樋」・[GAZ-035](../gazetteers/GAZ-035.md)の「万年樋」・[GAZ-013](../gazetteers/GAZ-013.md)の「埋樋二ヶ所」）に「目白下上水の埋み樋」という表現で加わる第4系統**。「みたけ」は御嶽（御嶽社・現在の鬼子母神表通りの御嶽社周辺）の読み（要照合）〕。
- **③南畝「玉水簾」の命名〔確認文言・命名者の文言〕**: 「**此瀧の風情を賞して、南畝大人は玉水簾と筆を投せり、いか樣瀧の落る姿は、玉の簾ともいはんかし**」＝**音羽の瀧の風情を賞して大田南畝が「玉水簾」と名付けた由**。〔[GAZ-035](../gazetteers/GAZ-035.md)（町方書上の里俗「玉簾」）の命名者（南畝）を伝える文言。「玉水簾／玉簾」の表記差も対校材料〕。
- **④潭弦亭（長田右兵衛督抱屋敷）〔確認文言・位置の記録〕**: 「**長田右兵衛督抱屋敷は、音羽の瀧より北四丁〓土（清土）町の北側に有、則門を入て中に一室有、茶室待合ひらきの間、勝手等を皆一棟の藁屋にしつらひ、潭弦亭と號く、是は此亭より弦卷川の水源大瀧を居ながらに、眼下にみれば斯名付しと見ゆ**」＋「**曾て南畝大人のよみ歌を額に懸たり。流れ出るみなかみ〓き土なれや、つるまき川の瀧の白い（OCR崩れ・「白糸」等の候補）とよみしは、此土地を〓土といへば也**」＝**①音羽の瀧の北四丁、清土町の北側に長田右兵衛督の抱屋敷があり、一棟の藁屋の茶室等を「潭弦亭」と号したこと、②亭から弦巻川の水源の大瀧を眼下に見る場所で潭弦亭の名が付いたとみえる由、③南畝の詠歌「流れ出るみなかみ清き土なれや、つるまき川の瀧の白（糸）」を額に懸けていたこと、④歌の「清き土」は当地を「清土」と言うことに由来する由**。〔潭弦亭の位置（音羽の瀧の北四丁・清土町北側）と由来の文言。[BLOG-185](../blogs/BLOG-185.md)（wanjin・2014）が同型の歌を北大路魯山人の句として記録し潭弦亭を「旗本長田右兵衛督の抱え屋敷で文化人が集った」と紹介するのに対し、本条（江戸期の遊歴雑記）は南畝大人のよみ歌として額に懸けたと記す。**歌の作者の帰属（南畝／魯山人）の対立は本条と[BLOG-185](../blogs/BLOG-185.md)の対校課題**（原典照合まで断定しない）〕。

- **⑤南畝「玉水簾」命名説の一次資料対校〔2026-11-16・第133回追記〕**: 本条③の命名説について、**南畝自身の作品集レベルの裏付けが見つかった**。①[BOOK-155](../books/BOOK-155.md)（蜀山人全集巻2・1908）の「千とせの門」に詞書「**神齡山の麓に音羽町瀧あり玉簾と名づく**」付き狂歌「深山より…」と、玉水簾を養老の瀧に見立てた狂歌「音羽町玉水簾に…」の**自署作品2首**が確認できた（命名そのものの描写ではないが、南畝が「玉簾」の名を詞書に書いた一次テキスト）。②[BOOK-156](../books/BOOK-156.md)（寝ぬ夜のすさび下・天保2年写）に**命名の由来譚**（音羽3丁目の道具屋半兵衛が蜀山に頼んで命名・留山が矢立の墨で狂歌を木に書き・通称「音羽の瀬」）が記録された。③[BOOK-154](../books/BOOK-154.md)（武江年表）は造営を文化9年（1812）秋「**上水の餘りを引て**」と記し、本条「文化初年の頃」・[GAZ-035](../gazetteers/GAZ-035.md)「文化13年5月」との**年代対立はなお解消しない（併記・断定しない）**。④[BLOG-185](../blogs/BLOG-185.md)の北大路魯山人命名説は南畝自署作品の確認で**さらに成立しにくくなった**（魯山人1883年生まれ・造営と時代不合）。
