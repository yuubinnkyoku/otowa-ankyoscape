# [BOOK-210] 田原光泰『「春の小川」はなぜ消えたか』（2011）〔repo初出・第192回登録〕

- **書誌〔確認: NDL書誌・2026-11-19〕**: 田原光泰『**「春の小川」はなぜ消えたか―渋谷川にみる都市河川の歴史**』、**之潮、2011年**、**ISBN 978-4-902695-13-7**〔NDL書誌で出版社・ISBNを直接確認。請求記号・所蔵頁数等の転記は未了〕。
- **著者と弦巻川・渋谷川研究との接点〔確認・文脈〕**: 著者田原光泰は**渋谷川・「春の小川」系の都市河川史の実務家**で、[PAP-083](../papers/PAP-083.md)（亀岡岳志2017「東京の「里川」の変容」）の**註8で「この展示を企画したのが、後述する田原光泰である」**（石神井ふるさと文化館の展示〔註7の『絵図と写真にみる千川上水』関連か〕）・**註12・参考文献で引用**されている＝千川上水・中新井分水研究の文献学的支柱の一つ。童謡「春の小川」（大正元年・高野辰之作詞）のモデル川は**渋谷川の支流で現在暗渠の河骨川**とする説が通説（[GOV-136](gov/GOV-136.md)2026年3月時点の都公式資料でも維持確認済み）。本書はその「春の小川」の消えた過程＝渋谷川水系（弦巻川と同じ渋谷川支流圏）の河川変遷を一般書レベルで扱った単著。
- **位置づけ〔観察〕**: repoの弦巻川（渋谷川支流・[BOOK-106](BOOK-106.md)川跡探しの実例にも採用）研究にとり、**同じ渋谷川水系の支流消滅史を地域博物館実務家がまとめた先行書**として、弦巻川・久堅田用水・宇田川の記述の有無が本文取得時の対校課題。「清流復活」言説（[PAP-083]参考文献の田原の位置・白根記念渋谷区郷土博物館展示〔[BOOK-212](BOOK-212.md)〕との関係）の系譜上にある。
- **制限・未解決**: ①本文未取得（NDL所蔵・取り寄せ確認中）。弦巻川・久堅田用水への言及の有無は未確認。②著者の経歴（白根記念渋谷区郷土博物館学芸員・「渋谷川再生」関連の活動等）の詳細確認は未了。③本書と[PAP-083]註8の「展示」（企画者＝田原）の特定（『絵図と写真にみる千川上水』2013か否か）は本文と展示図録の突合せ待ち。
