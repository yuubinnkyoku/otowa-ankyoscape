# [BOOK-181] 東京の近郊 一日二日の旅（田山花袋・1920）— 千川用水の水源=三宝寺池の1920年観察と神田上水白堀区間の現勢

- **書誌〔確認〕**: 田山花袋著『東京の近郊 一日二日の旅』（磯部甲陽堂・大正9年＝1920。奥付「大正九年六月十六日發行」）。東京近郊の一日・二日コースの紀行文集。NDL次世代デジタルライブラリー [book/961001](https://lab.ndl.go.jp/dl/book/961001) のOCR全文を確認。**同書の該当紀行（武蔵野鉄道・西郊の章）は『花袋紀行集』（1923・[book/977044](https://lab.ndl.go.jp/dl/book/977044)）に同文で収録されている（同一テキスト＝977044は本項に併記し独立登録しない）**。**両版ともOCRの段組崩れ・介在語が多く、引用文言は原画像照合を要する**（下記の引用は961001・977044両版の対校で復元した文言候補）。
- **千川用水の水源＝三宝寺池の1920年観察〔確認・repo初出の観察文言〕**: 「**たゞ三寶寺池から出て東に流れてゐる千川と、その北に流れてゐる石神井川とがある位のものである**」（目白〜練馬向きの西郊の地勢描写中）＝**①千川用水の水源を三宝寺池とし、②その北を流れる石神井川（水源は同じく三宝寺池〔[GOV-257](../gov/GOV-257.md)〕）と並べて記した1920年の文学者による現地観察**。〔①[GAZ-057](../gazetteers/GAZ-057.md)（風土記稿・「石神井村三寶寺の池水落合」＝千川上水系への言及）・[GOV-257](../gov/GOV-257.md)（1931・石神井川水源三宝寺池＋千川水道の列挙）に対し、**千川用水の流下水源を「三寶寺池から出て」と現地の目で確認した1920年の定点観察**。②[GOV-070](../gov/GOV-070.md)（千川上水の記録フィルム・1952年＝境からの通水が絶えた後の三宝寺池の揚水利用）や練馬区側の「千川上水の水は境の分水から」という流路認識（README §千川上水）と対校すると、**1920年時点で現地観察者は千川用水の水源を三宝寺池と認識していた**という観察文言として扱う（千川用水の水源論＝境分水説と三宝寺池観察説の対立構造のdatapoint。観察文言であって水文学的な水源確定ではない＝断定しない）。〕
- **神田上水（下落合〜新井薬師間）の1920年現勢〔確認・文言候補〕**: 「**神田上水が南から北に流れてゐて、新井に行く路に橋が一つかゝつてゐる。そこには秋は柿など並べた休茶屋がある、橋の前後には芦荻が繁つてゐる**」＝**下落合側（現在の西武新宿線下付近〜新井薬師方面）の神田上水の白堀区間の1920年現地観察**で、①「南から北に流れてゐる」＝下落合付近で西から東へ（地図上の南側から北側へ）流れる神田上水の流下方向の観察、②新井薬師へ通じる道の神田上水橋が1本架かっていたこと、③橋畔の休茶屋（秋は柿を並べる）・橋前後の芦・荻の繁茂という水辺の現勢。〔神田上水の白堀区間（[GAZ-049](../gazetteers/GAZ-049.md)系の「白堀」記録・README §神田上水）の大正末期の景観観察。橋の位置の比定（下落合〜新井薬師間のどの橋か）は本文言からは特定できない。〕
- **「落合の水車」の1920年観察〔確認・文言候補・比定保留〕**: 「**早稲田の諏訪の森から戸塚を經て、落合の水車の傍を通つて、藥師へと出て行く路は、かなりに野趣に富んでゐて…秋などは好い**」＝**早稲田（諏訪の森）→戸塚→落合→新井薬師の経路の途上に「落合の水車」が存在した1920年の観察**。〔水車の所在（神田上水沿いか・千川側か・淀橋側の落合のどこか）は本文言からは特定できず**比定保留**（第12回調査の八成橋・八成水車〔豊島区上長崎側〕との直接の同一視はできない＝断定しない）。水車の文字記録の1920年定点として、千川・神田上水流域の水車史（README §水車）の周辺資料に位置づける。〕
- **井草の善福寺池の1920年観察〔確認・文言候補〕**: 「**私は曾て新井藥師から井草の善福寺池をたづねたことがある。…行つて見ると、善福寺は旣に亡びてなく、池もかすかにその面影をとゞめてゐるばかりであつた。それでも私は畑の中の路を通つて、寺のあつた跡に行つて、其處から下に池を見渡して見た**」＝井草の善福寺（廃寺）とその池の1920年現勢の観察（善福寺池は現在の杉並区の善福寺池とは別の、井草側の善福寺〔寺院〕の池である点に注意・比定は保留）。〔千川用水・仙川用水系の南方隣接域の観察記録として参考資料化。〕
- **千川用水沿いの街道の観察〔確認・文言候補〕**: 「**これから少し行くと靑梅街道に出る。…私は（荻窪）から千川の用水に添つた街道に出て、三寳寺池の方へと志した**」＝青梅街道から千川用水沿いの道（現在の千川通り系）に出て三宝寺池へ向かった1920年の経路観察。〔千川用水沿いの道路（現在の千川通り）の利用が1920年時点で観察されている用例。〕
