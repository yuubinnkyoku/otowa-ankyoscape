# [BOOK-213] 須藤亮作『中新井の今と昔』（1968）〔repo初出・第192回登録〕

- **書誌〔確認: 亀岡岳志2017〔[PAP-083](../papers/PAP-083.md)〕脚注・参考文献・2026-11-19〕**: **須藤亮作**『**中新井の今と昔**』、**練馬郷土史研究会、1968年**〔NDL書誌での検索では確認できず（2026-11-19・調査当環境）＝公共図書館レベルの所在未確認。亀岡論文の註19・註20がP13・P9を引用しており、実在して少なくとも十数頁以上の本文を持つことが文献内証明されている〕。
- **位置づけ〔観察〕**: 中新井（旧中新井村・現練馬区豊玉・中村一帯で[GOV-005](../gov/GOV-005.md)の分水・「中新井の池」＝学田公園〔豊玉南3丁目・[PAP-083]註6〕を含む地域）を主題にした**1968年時点の今昔記**＝区画整理・電気・道路等の生活史の聞き取り系史料（練馬郷土史研究会の「中新井シリーズ」〔奥山太郎氏は語る・きき手伊藤経一・[PAP-083]参考文献〕と同研究会の系統）。**[GOV-005](../gov/GOV-005.md)の須藤亮作氏提供写真**（昭和38年・中新井村分水と中村分水の合流点＝現学田公園西側の写真・クレジット確認済み）との関係＝同氏が「中新井の今と昔」の著者であることから、**同書の周辺で写真提供が行われた可能性があるが、両者の同一人物であることの明示的裏付けはGOV-005本文にないため断定しない**。
- **制限・未解決**: ①実物未取得（練馬区立図書館・郷土資料室の所蔵確認が次の課題）。②註19・20が引用する内容（P13・P9の文言）は亀岡本文（pp.5-24・未取得）にあるため、**何を引用したかは本文取得まで不明**。③須藤亮作の人物像（中新井の古老・区史編さん関係者等）は未確認。
