# [BOOK-106] 山岡光治『地形図を読む技術』（2013・2018新装版）〔repo初出〕

- **書誌〔確認: NDLサーチ・2026-11-15〕**: 山岡光治 著『**地形図を読む技術 : すべての国土を正確に描いた基本図を活用する極意**』。**初版＝ソフトバンククリエイティブ、2013年**（サイエンス・アイ新書 SIS-282・ISBN978-4-7973-6756-0・[ndlsearch R100000002-I024653490](https://ndlsearch.ndl.go.jp/books/R100000002-I024653490)）。**新装版＝SBクリエイティブ、2018年8月**（サイエンス・アイ新書 SIS-415・ISBN978-4-7973-9884-7・286p・[ndlsearch R100000002-I029128990](https://ndlsearch.ndl.go.jp/books/R100000002-I029128990)・EPUB版あり [R100000137-I9784797398847](https://ndlsearch.ndl.go.jp/books/R100000137-I9784797398847)）。著者は元国土地理院技官（1945年生まれ・2001年退職後「オフィス地図豆」店主）で、[BLOG-068](../blogs/BLOG-068.md)（地図豆9-1 目白の坂と泉・PDF）・[BLOG-049](../blogs/BLOG-049.md)（地図豆14-1「ぐるっと護国寺、弦巻川をたどる」）と**同一著者**〔そのほか「地図散歩2 東京・水窪川、鼠ケ谷を歩く」による護国寺付近の水窪川×弦巻川合流の復元は docs/江戸名所図会・護国寺図の検討.md §8 で引用済み〕。
- **目次〔確認: NDL目次レコード・2026-11-15・repo初出の重点〕**: 第3章「地形図をもち歩きながら読む技術」の**「3-1 川跡探しをする～弦巻川跡を探す」**を確認〔新装版の目次に「3-1 川跡探しをする～弦巻川跡を探す」「3-2 昔探しをする～人形町の昔を探す」「3-3 里山歩きをする～大山千枚田を歩く」「3-4 野山歩きをする～小田原の不動山に登る」、第2章2-6「異なる地図を並べ、重ねて変遷を読む」等〕。**全国の読者向けの地形図読図の入門書が「川跡探し」の実例として弦巻川（跡）を採用している**＝弦巻川が消滅河川の地図上の読み取り例として一般書レベルで流通している〔本自体は小説・紀行ではなく地形図解説書で、弦巻川跡を地形図で実際にたどる手順を示すとみられるが、**本文は未確認のため当該節の具体的なルート・言及内容は断定しない**〕。
- **repoでの位置づけ〔観察〕**: 弦巻川を題材にした既収録の文献列（[BOOK-100](BOOK-100.md)豊島風土記の「弦巻川」項目・[BOOK-101](BOOK-101.md)今尾恵介『東京凸凹地形散歩』の「音羽川と弦巻川を遡る」章・[BLOG-231](../blogs/BLOG-231.md)増田剛己2010の歩き記事）に加わり、**元国土地理院職員による地形図判読という技術的アプローチからの言及**という新しい系統。弦巻川跡の復元・特定の議論（README §弦巻川）に対して、専門家の地形図読図の実例として本文確認の価値がある〔未確認〕。
