# [BOOK-252] 小金井市文化財ブックレット1『小金井の石造物』（2021）〔repo初出・第257回課題③(文化財ブックレット1の書誌)の解決。路傍石造物系の市公式解説冊子〕

- **書誌〔確認: [GOV-509](../gov/GOV-509.md)市頒布書籍一覧頁・2026-11-22取得〕**: **小金井市文化財ブックレットシリーズ第1弾『小金井の石造物』**（令和3年〔2021〕発行・**小金井市教育委員会**・A5判64ページ（カラー版）・価格200円）。市公式頁の説明＝「**シリーズ第1弾は、石造物。石造物は、石仏とも言い小金井地域の歴史を語る上では欠かすことのできない、後世に継承すべき文化財です。本書は、小金井市内にある石造物のうち、お地蔵さまや、板碑、狛犬、道しるべ等、寺社や路傍でみられるものを中心にまとめたものです**」＝**石仏・板碑・狛犬・道しるべ等の路傍石造物を中心にした市域解説冊子**。
- **シリーズの位置〔確認〕**: 文化財ブックレットシリーズは令和3年から刊行開始（[GOV-509](../gov/GOV-509.md)）＝第1弾が本書で、第2弾『発掘された小金井』〔[BOOK-253](../books/BOOK-253.md)〕（令和5年）・第3弾『小金井桜拾遺』〔[BOOK-246](../books/BOOK-246.md)〕（令和7年）と続く。**編集母体＝小金井市石造物調査報告（編纂資料第60・61編）**の存在が同頁で確認できる。

## repoとの関連〔観察〕

- ①**道しるべ・石仏系＝橋名・里程標系の隣接ジャンル**で、[GOV-505](../gov/GOV-505.md)（くぢ宮・庚申塔系板碑）・[GOV-508](../gov/GOV-508.md)（梶家・貫井の地蔵堂系）で引用された石造物の市域分布の全容を掴む候補。②**板碑＝武蔵野公園低湿地遺跡の板碑片3片〔[GOV-508](../gov/GOV-508.md)〕・市史資料編考古・中世付録DVDの板碑写真群〔[BOOK-256](../books/BOOK-256.md)〕と同じ石造物系史料**で、市域板碑の所在分布を一覧できる可能性がある（収録範囲は未確認）。③64頁カラー版・200円という市公式入手可能性（現行頒布）＝現地実査への携行資料候補。

## 意義〔観察〕

- 市域の石造物を一冊にまとめた公式解説書で、市内の寺社・路傍の道しるべ（旧道復元の一次資料）・庚申塔・石仏の分布の参照点になり得る。『発掘された小金井』とともに、第257回課題③（文化財ブックレット1・2の書誌）を解決した。
