# [BOOK-140] 帝都と近郊（小田内通敏・1918）— 千川用水の地形学記述と谷端河域

- **書誌〔確認〕**: 小田内通敏『**帝都と近郊 : 都市及村落の研究**』（**大倉研究所・1918年**・次世代デジタルライブラリー [book/960716](https://lab.ndl.go.jp/dl/book/960716)・人文地理学者による東京と近郊の地理研究書・序に東京帝国農科大学の農業経済区研究への言及）。引用文言はOCR由来で要原文照合。
- **六派上水の列挙〔確認・対校用〕**: 「**玉川·神田·千川·三田·靑山·龜有の六派を見しが、今日は玉川·神田·千川の三派のみ現存し、神田上水は現水道の施設と（後略）**」＝**①幕末〜明治初期に上水が六派（玉川・神田・千川・三田・青山・亀有）あったこと、②1918年時点で現存が玉川・神田・千川の三派**という地理学書レベルの列挙〔**「亀有」はOCR含め原字照合要**（亀有上水の実在は本repoでは未確認の呼称）。「三派」の中に千川が含まれる＝千川上水が現役水路として扱われる1918年の認識＝[BOOK-137](BOOK-137.md)（1913・埋没樋口の観察）と同年代的。〕
- **千川上水の明治40年岩崎氏所有化〔確認〕**: 「**明治四十年岩崎氏の所有に歸し**、玉川上水のみは現水道の水路に利用せられ」＝**千川上水が明治40年（1907）に岩崎氏の所有となった旨の1918年テキスト**〔千川水道会社の岩崎家（[GOV-077](../gov/GOV-077.md)・明治13年設立）から岩崎氏私有への転換の年代を明治40年とする記録として、[BOOK-122](BOOK-122.md)（1913・岩崎氏巣鴨別邸）・[BOOK-138](BOOK-138.md)（1930・駒込岩崎邸の私有）・[GOV-077](../gov/GOV-077.md)と対校可能な独立の年代記述。〕
- **千川用水の地形学記述〔確認・repo初出の文言〕**: 「**玉川上水の分派たる千川用水は、大部此臺地の脊梁を通り、更に板橋·瀧野川二町に亙る臺地を過ぎて石神井川に入る通路なり**」＝**①千川用水＝玉川上水の分派、②武蔵野台地の脊梁（分水界稜線）の大部分を通り、③板橋・滝野川の台地を過ぎて石神井川に入る**という1918年の地形学的ルート記述。〔**千川用水が台地の脊梁（尾根筋）を通る水路であることを明示した人文地理学書レベルの記述**＝[GOV-257](../gov/GOV-257.md)（石神井川への注ぐ関係）を結ぶ中流域の地形記録として初出。「石神井川に入る」＝千川用水の放流先（現在の桜川〜旧千川上水放水路・板橋駅裏）の確認（[GOV-126](../gov/GOV-126.md)・板橋放水路問題）に対応する1918年時点の認識。〕
- **谷端川の地形記述〔確認・repo初出の文言〕**: 「**谷端川のあるが爲に、妙正寺流と谷端川との間には、長崎·落合·高田·巢鴨四村に亙る臺地の分支を見、谷端川と石神井川との間には、上板橋·長崎の二村、板橋·瀧野川·巢鴨の三町に亙る臺地の分布を見る**」＋「**長崎村より巢鴨町と巢鴨村、本〓區と小石川區との間を出入流下する谷端河域**」＝**①妙正寺川と谷端川の間の台地分支（長崎・落合・高田・巣鴨に亙る）、②谷端川と石神井川の間の台地（上板橋・長崎・板橋・滝野川・巣鴨）、③「本所区と小石川区の間を出入流下する」という谷端川の行政区割りを横断する流路**の記述〔**「谷端河域」という河域単位の用語**と、妙正寺流（妙正寺川）との対比で谷端川を記す構成はrepo初出。谷端川の本流が区境を「出入」する低地の連続性の地理学側からの裏付け。〕
- **水車の衰退の1918年観察〔確認・repo初出〕**: 「**水力を利用する水車の數亦多かりしも、今日に於ては、水量の利用昔日の如く自由ならず爲に其運轉を困難にし終に廢車の悲運に陷りしもの多く**」（前後割注）＝**1918年時点で武蔵野の水車が水量利用の制限により廃車に陥った**という同時代的観察〔[BLOG-071](../blogs/BLOG-071.md)（八成水車）・[GOV-254](../gov/GOV-254.md)（安政3年の水車規制）・[GOV-069](../gov/GOV-069.md)の文脈に、水車衰退の同時代証言を追加。〕
- **白子川上流・保谷側の記述〔確認〕**: 「**白子川の上流をなせる一支流の、保谷村大字下保谷より大泉村大字小搏(旭?)に至る低窪地を流るゝもの〓は、梅雨及秋霖の際には、水量豐かなるのみならず、沿岸の林地及畑地を浸し**」＝保谷村側（千川上水の水源側）の白子川上流支流の実況記録（千川取水点周辺の地形の理解の補助）。
