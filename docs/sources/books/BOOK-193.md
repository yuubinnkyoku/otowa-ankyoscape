# [BOOK-193] 蜻蛉集（泉鏡花・1921）— 関口の瀧の公園化の大正期の文学側観察〔第163回〕

- **書誌〔確認〕**: 泉鏡花著『蜻蛉集』（国文堂書店・1921〔大正10〕）。NDL次世代デジタルライブラリー [book/968241](https://lab.ndl.go.jp/dl/book/968241)。短編集（妖剣紀聞・紅玉・紅葛等を収録）。関口の瀧・大洗堰の文言は物語中の人物の語りとして現れる（**作品内の描写であり、純粋な観察記録とは区別して扱う**）。**引用文言はすべてOCR由来で要原文照合。**
- **関口の瀧の公園化〔観察候補・repo初出〕**: 「**は、お物語をいたします…なおほあらひせき場所は、現今の小石川關口の瀧-去年あたりから公園に成りました-以前は大洗堰こうづかじやうすゐめじろだいと言つた**」＝**現在（1921）の関口の瀧は「去年あたりから公園に成った」、以前は大洗堰・こうづかじやうすい・めじろだい（OCR・原字形要照合）と呼んだ**という語り〔**江戸川公園の開園大正8年（1919）3月15日（[GOV-305](GOV-305.md)）とほぼ整合する「去年あたりから公園」の文学側の観察候補**＝関口の瀧（大洗堰）の公園化の時期（大正8〜10年頃）の非行政系の裏付け。「こうづかじやうすゐ」は「江戸川上水」等の崩れの候補・要照合〕。
- **大洗堰の音景観と武蔵野の遞水〔観察候補〕**: 「**此やうきち口うごみせきぐちおほあらひの陽氣ゆゑに…あれが關口の大洗堰であります むさしの遞水と言ふ、昔の面影が偲ばれます**」＋「**大洗堰の瀧の音が谺をするかと…森を越えて目白臺まで屹と響いたに相違ない**」＝**大洗堰の瀧の音が森を越えて目白台まで響く**という音の描写＋「武蔵野の遞水（OCR・原字形要照合）」の呼び方〔大洗堰の滝音の通達距離（目白台まで）は物理的な観察として読める候補（文学描写であることを断りつつ音景観の資料とする）〕。
- **駒塚橋から目白臺への経路〔観察候補〕**: 「**あれから駒塚橋を渡つて、井の頭の、あの上水べりを、崖から目白臺へ拔ける**」＋「**音羽九町を見通しの辻の柳**」＝**駒塚橋を渡り、井の頭（神田）上水べりを崖から目白台へ抜ける経路と音羽九町の風景**〔[GAZ-048](../gazetteers/GAZ-048.md)⑧駒塚橋（神田上水堀に架かる・長9間）・上水べりの崖上の目白台という空間構造（大正10年の文学の中で維持されていた観察）〕。
