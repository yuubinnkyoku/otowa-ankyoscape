# [BOOK-045] 1910年8月の小石川指ケ谷町付近の出水写真を伝える絵葉書

- **書誌・年代〔確認：公的所蔵目録〕**：江戸東京博物館「喜多川周之コレクション」の絵葉書**資料番号88131292**は『**(明治四十三年八月都下大洪水)小石川指ケ谷町附近出水の実景**』と題され、**1910年（明治43年）**の1枚として登録される。別番号**88131404**も『**小石川指ケ谷町附近出水の実景**』という同年の絵葉書1枚である。〔確認：各所蔵目録の標題・資料番号・年代・形態〕
- **画像〔観察：公開された小画像〕**：両資料の公開画像では、**浸水した街路・建物・人の配置がほぼ一致**する。現時点では**同じ写真に異なる標題・版面を付けた印刷違いの可能性**が高く、**2地点・2回の出水を記録した独立写真2枚とは扱わない**。原版・撮影者・厳密な撮影日時は未確認。〔観察／推定〕
- **位置照合〔確認：地名データ、位置は未特定〕**：歴史地名データセット『日本歴史地名大系』の「小石川指ヶ谷町」（出典『東京都の地名』2002年）は、旧町域を**現在の文京区白山1・2・4・5丁目**に対応させる。ただし、この対応は**旧町域の範囲**であって写真の撮影位置・浸水範囲ではない。同データの代表座標も写真の撮影地点とはみなさない。
- **研究上の意味〔推定：周辺地域の比較資料〕**：**1930年代の小石川下流暗渠化より前の1910年**に、旧小石川区の近接谷地で街路浸水を写した資料の所在が判明した。旧谷端川（小石川）周辺の近代水害・地形・街路の比較写真として、1910年頃の地籍図・洪水記録との照合候補となる。
- **限界〔未解決〕**：旧指ヶ谷町は広く、**写真の浸水地点が谷端川本流・小石川大下水の流域に含まれるか未確認**。1910年の洪水と谷端川の氾濫・逆流・下水能力の因果関係を示すものではない。水深、浸水原因、撮影方向、道路名、橋の有無は未確定。『明治四十三年八月』は一方の絵葉書の標題に基づき、**撮影日を8月の特定日に固定できない**。
