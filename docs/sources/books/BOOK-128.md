# [BOOK-128] 帝国図書館和漢図書書名目録 第3編（1913年）— 明治19年橋梁明細調の原典の書誌記録

- **書誌〔確認〕**: 帝国図書館編『**帝国図書館和漢図書書名目録**』**第3編**（大正2年・1913年・708頁・書誌ID 000000882325・請求記号029.1-Te143t）。NDL次世代デジタルライブラリー [book/991348](https://lab.ndl.go.jp/dl/book/991348)。書名の五十音順による和漢図書の書名目録（本編第3巻＝「トウキ」（東京）等の書名の部）。**書誌項目は書名・編者・刊年・体裁（寫本等）の列で構成され、OCRの列崩れが多い。引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **「東京府橋梁明細調（明治十八年迄）」の書誌記録〔確認・repo初出〕**: 「トウキ」（東京府）の部（コマ数488付近）——「**東京府橋梁明細調(明治十八年迄)**」＋「**寫本**」〔書名列に「(明治十八年迄)」の注記が付き、隣接列に「寫本」の体裁表記。編者・刊年の列は空欄。OCR jsonlの文字座標で行構成（書名行と「寫本」表記の隣接）を確認〕。〔**小石川区史（[BOOK-126](BOOK-126.md)）が「東京府文献叢書乙集十八ニヨル」として引用する明治19年（1886）橋梁明細調の原典が、帝国図書館（現・国立国会図書館の前身機関）に写本として蔵書され、公的に目録化されていた記録**。「(明治十八年迄)」＝調査対象が明治18年までであることを示す書誌注記で、区史の「明治十九年の調査に係る」文言と整合する。1913年時点の所在記録であり、現・国立国会図書館での所蔵状況はこれでは確認できない〕。
- **「東京府文獻叢書」の書誌記録〔確認・repo初出〕**: 同頁——「**東京府文獻叢書**」＋「**小宮山綏介等編**」＋「**寫本**」＋「**缺乏 一九、二三、二八、三〇、四…**」〔OCR jsonlの文字座標で「缺乏」→「一九」→「、二三、二八、三〇、四」の縦連続（y=742→776→823）を確認。帝国図書館所蔵の同叢書の写本に**欠巻があり、その番号リストに「一九」（19）を含む**〕。同頁に「**東京府文獻叢書總目 東京府記錄課編 寫本**」の書誌も併記〔叢書の総目の写本の記録〕。〔**東京府文献叢書は甲集第30冊（[GAZ-030](../gazetteers/GAZ-030.md)『江戸名勝志』）等の集書で、区史の言う「乙集十八」の属する叢書**。帝国図書館所蔵分には欠巻19を含むことが1913年目録で確認できるが、**甲集・乙集の冊号と全体の通し冊番号の対応は未確認のため、「欠巻19＝乙集十八」であるとか、帝国図書館に乙集十八が欠けていたとまでは断定しない**。小宮山綏介＝同叢書編者としての書誌記録〔人物書誌情報レベル〕〕。
- **陰性〔確認〕**: 同目録第3編の「トウキ」部に「千川」「江戸川（江戶川）」「神田上水」「武蔵風土記」を含む書名の項目は確認できず（全文走査）。
- **位置づけ〔観察〕**: ①明治19年橋梁明細調（千川・江戸川筋の橋の1886年府調査＝[BOOK-126](BOOK-126.md)の橋梁章の原本）の所在が、1913年の公的書誌（帝国図書館目録）で「写本」として記録された〔**第107回第2次push時の課題「東京府文献叢書乙集十八の所在確認」の前進。現NDLでの所蔵・公開状況の確認が次の課題**〕。②「東京府文獻叢書」の帝国図書館所蔵の欠巻注記（19を含む）は、同叢書の伝来状況を示す傍証〔乙集十八との対応は未確認〕。③書名目録レベルの資料であり、橋梁明細調の内容（橋名・架換年次・工費）自体は含まない。
