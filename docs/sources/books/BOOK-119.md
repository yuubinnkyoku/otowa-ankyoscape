# [BOOK-119] 落合町誌（1932年）— 千川用水の終点と落合の湧水群

- **書誌〔確認〕**: 落合町町史編纂係『落合町誌』（昭和7年・1932・東京府豊多摩郡落合町）。NDL次世代デジタルライブラリー [book/1190694](https://lab.ndl.go.jp/dl/book/1190694)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **千川用水の終点記述〔確認〕**: 「千川用水ハ玉川上水ノ分派タル細流…**長崎町ヨリ葛ケ谷ノ北端ニ入リテ、長崎町トノ境堺ニ添ヒ、小字前耕地ヨリ下落合ニ入リ、妙正寺川ニ合シテ、千川用水ノ終リヲ〓グ**、此ノ間專ラ灌漑ニ供セラレタリ」＝**千川用水の西端流路（長崎町→葛ヶ谷北端→長崎町との境堺→小字前耕地→下落合→妙正寺川合流）**を落合側から記述。〔文言・OCR判読不能箇所（〓）は要照合〕。
- **落合の湧水群〔確認・repo初出の湧水一次記述〕**: ①**不動谷流**＝下落合字大原より湧出、田用水として妙正寺川へ。②**諏訪谷流**＝旧諏訪神社附属山林より湧出。③**西ヶ谷流**＝字本村西端の雑林中より湧出、諏訪谷流と相合。④**丸山流**＝字丸山北端より湧水、東耕地で神田川へ＝**1932年時点で記録された小湧水4流**（その後の消滅・残存は本文では確認できず）。〔文言・小字名はOCR要照合〕。
- **葛ヶ谷〔確認〕**: 妙正寺川・千川用水に恵まれ水田が多く、正保年中の水田43石8斗4升6合7勺・村高70石1斗7升5合＝**千川用水灌漑の村落側記録**。〔数値はOCR要照合〕。
