- **当該条: 第一章飮食物の部（八八）「御留川の紫鯉」〔fulltext本文・OCR・要原画像照合〕**: 「**江戶川筋隆慶橋邊より中の橋邊に至る間は御留川とて禁漁の場所であるが、尺以上のものありて紫黑色を帶び所謂紫鯉と稱し江戶名物の一として知られ**（たものである）」＋川柳句群（OCR区切り崩れあり・年号略字つき）: 「**鯉までも紫になる江戶の水**」「**江戶紫は助六と文四郞**」「**其間に棲む鯉は三將軍家の御料に供**」「**（車胤と王祥）江戶川の名所なり**」「**紫は人も奪はぬ御留川**」「**御留場の鯉はこつちでびく〓〓し**」「**おあがりの鯉紫の水にすみ**」「**紫を赤で煮るのは江戶の味噌**」等（句に付く略字は（保）（政）（化）（大）（一七）（明）等の年代記号）。
- **[BOOK-151](BOOK-151.md)（十方庵遊歴雑記初編・第拾四条候補）との対校〔観察〕**: 江戸期側は「誠の江戶川」＝**小日向の中の橋前後4〜5町**の御止川（釣禁・放生の紫鯉）と**橋名を起点に数えた範囲**で記すのに対し、本書（1926）は**隆慶橋〜中の橋の区間全体**を御留川と**橋から橋への区間**として解釈している＝**同一の御止禁止区域の読みが江戸期随筆と近代川柳研究書で異なる（または近代側が拡張して理解した）ことの対校案件**〔どちらが江戸期の実態に即するかは本書からは判定できず、両説併記して管理〕。
- **意義〔観察〕**: ①**「江戸川」呼称の範囲を橋で定義する文言群（BOOK-151・第180回④）に1926年の近代層を追加**＝隆慶橋（竜慶橋）〜中の橋区間が「江戸川筋」と呼ばれた認識が大正期の川柳研究書にまで継承された記録。②「紫鯉」が江戸名物として定型化（江戸紫=助六・文四郎の掛詞・将軍家御料・味噌の自慢句）し、江戸川中流の水質景観の記憶として流通した様子を句群で確認できる。③repoにない「江戸名物指南書」の系譜の新資料（川柳・狂句ベース）で、地名・橋名の柳俗的な層の資料になりうる。
