# [BOOK-051] 『文京区史』巻1・事項索引「音羽町抄紙場」

- **書誌〔確認：NDLサーチ・文京区公式案内〕**：東京都文京区編・刊『文京区史』**巻1**、**1967年刊、504頁・図版・地図、22cm**。国立国会図書館書誌ID **000001089561**、PID **3010394**。[NDL書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000001089561)／[文京区「過去の区史刊行物について」](https://www.city.bunkyo.lg.jp/b001/p005257.html)（全5巻は1967～1969年刊、地域資料デジタルアーカイブ等で閲覧可能と案内）。
- **地域索引の追加参照先〔確認：文京区立図書館「地域」索引、2026年11月2日閲覧〕**：[「文京区史（地域）」](https://www.lib.city.bunkyo.tokyo.jp/viewer/info.html?id=171)は、**「音羽谷」巻1・10／11／15／148頁、「谷端川」巻1・8／12／75／216頁、「音羽通り」巻1・59／71／86頁**を掲げる。既確認の事項索引「音羽町抄紙場」巻1・71頁とは**別の索引項目**である。〔推定〕谷地形・谷端川下流・音羽の土地利用を巻1の複数箇所で原文照合できる。〔未解決〕各頁の本文・図版は未閲覧で、索引から旧流路・合流・取水・橋の実在や位置、工事年を推定しない。1967年は区史の刊年。
- **掲載箇所〔確認：文京区立図書館の公式事項索引〕**：[「文京区史（事項）」](https://www.lib.city.bunkyo.tokyo.jp/viewer/info.html?id=172)に、**「音羽町抄紙場 | 1-71」**と掲載される。これは**巻1・71頁への索引参照**であり、同頁に当該事項への言及があることを示す。本文・図版の内容や原出典は**未閲覧**。
- **既存史料との照合〔推定・未解決〕**：2022年の[旅行記](https://4travel.jp/travelogue/11794487)は山本松谷作とする**「音羽町紙抄場」**の図を紹介する。索引の**「音羽町抄紙場」**とは字順が異なるが、**同一の図版・工房・地点を指すかは未確認**。1967年の区史の掲載箇所が原図の初出・作者・撮影／制作年を明らかにするかどうかも不明。**1967年は区史の刊年であって紙漉き場の操業年・図版制作年ではない**。
- **追加の突合候補（2026-11-10）**：文京区教育委員会『文京のあゆみ : その歴史と文化』**p.24**には利用者の現物確認によると「**音羽の紙すき場（明治39年頃）**」が掲載される。[BOOK-057](BOOK-057.md)。本書『文京区史』巻1・p.71の「音羽町抄紙場」と**同一地点・同一図版かは未確認**。1906年頃は先方資料にある年代表示であり、実際の撮影・制作時期かは未判定。
- **未解決**：巻1の印刷71頁を原画像で確認し、図か本文か、原典・図版の題名・掲載時期・工房所在地の記載を確かめる。音羽の紙漉きと水窪川の取水・排水関係は索引だけでは立証できない。
