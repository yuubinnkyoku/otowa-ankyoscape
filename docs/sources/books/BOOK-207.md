# [BOOK-207] 江戸時代落書類聚 巻之五（1915）— 「元文世撰／元文世説」の項目名運用と元文期世相の活字集成〔第183回登録〕

- **書誌〔確認〕**: 矢嶋松軒編『**江戸時代落書類聚**』**巻之五**（**大正4〔1915〕**・NDL次世代デジタルライブラリー [book/2562521](https://lab.ndl.go.jp/dl/book/2562521)。巻之四=[2562520](https://lab.ndl.go.jp/dl/book/2562520)・巻之六=[2562522](https://lab.ndl.go.jp/dl/book/2562522)が同時公開）。江戸時代の落書（風刺・世相の短文）を主題別の巻に集成した近代活字本。引用は活字版OCR由来で原本活字との照合を要する。
- **目次と構成〔確認〕**: 巻之五の目次は「米価一定・金銀改・績名実驕奢〔宗春隠居〕・辰巳晴嵐〔辰巳屋〕・兄弟仇討・注子就伝・**公御入水**・土岐出火・**元文落書**・政山今籠居・寄贈本」＝**巻之五の全体が元文年間（1736-41）を中心とする落書集成**。各項目の本文の後に矢嶋松軒の付説が付き、その見出し・本文中に「**元文世説**」「**元文世撰**」〔OCR。世選の候補もあり原字は要照合〕の呼称が節名として運用される。
- **「元文世説」の付説本文〔確認・repo初出の呼称運用例〕**: 米価・金銀改の部の付説冒頭に「**元文世説 元禄以降幕府の貴途年々増加し止む事を得ず金銀改鋳を為し文政天保安政万延と其の度毎に金質は悪しく貫目は減したり…元文小判は金位上のの中・重三匁五分…當時にありては此の改鋳に就き人民の不平を鳴したる有様は落書に依りて想像するに余るべし**」＝**矢嶋松軒が元文期の世相を語る節名として「元文世説（世撰）」を用いる実例**＝[GAZ-097](../gazetteers/GAZ-097.md)の音無川条が「**元文世説曰 元文四年七月朝鮮雉に白雉〔子〕瀧野川辺に放し給ふ由を記**」と引く「**元文世説**」〔repo内で書誌・所在とも未確認の引用書〕と同系の名称が、明治～大正期の元文落書の活字編纂でも節名として生きている観察〔**両者を即座に同一書とは同定しない**。江戸志の引く元文世説が随筆体の元文諸事輯なのか落書集なのかは本書からは確定できない。表記の揺れ（世説／世撰／世選）を含め、GAZ-097の引用書「元文世説」の実体確認（江戸期の元文諸事輯の探索）への方針情報として記録〕。
- **主な収録内容〔確認・文言候補〕**: ①**米価一定**＝「元文元年丙辰二月半価下落し前米役の旗本及御家人等困難により米価を定る事…上米金壱両壱石弐斗 下米金壹両壹石五斗 下々米金壱両壹石七斗五升…右明十二日より書面直段之通急度相守可致買売候」＋伏字連鎖の「米」歌（王様は即位米…芝居は見米…）＋「元文元年」の落首、②**金銀改**＝「元文元年丙辰五月十二日町奉行大岡越前守忠相〔OCR。大岡越前守忠宜候補〕御勘定奉行細田丹〔覚〕…慶長金新金八百兩三代り百兩…以改候金銀金座銀座ヨリ増歩差出可引替…」等の改鋳レート、③**績名実驕奢**＝元文4年未正月13日尾張宗春隠居の沙汰（御名正清／正水の沙汰・市ヶ谷屋敷など）と落書、④**辰巳晴嵐**＝元文5年3月の大坂辰巳屋・木津屋事件、⑤**兄弟仇討**＝元文5年3月6日築地での矢内兄弟の仇討（落書「元文曽我」等）と「元文世説」の付説、⑥**公御入水**＝「**元文五年庚申八月十五日岩清水八幡放生会に付参向の公家帰路…淀の城下間小橋の板橋損し清水谷左中将殿乗物入水 家来の内兩人溺死…九月十六日松平伊豆守於宅被仰渡…稲葉内〔匠〕頭…禁裏御用通路之義に付遠慮被仰付**」＝岩清水八幡放生会帰路の淀の小橋損壊による清水谷左中将の乗物落水事件と老中松平伊豆守による沙汰（**京都側の事件で、瀧野川の白雉放生〔江戸志の元文世説引用〕とは別の放生会記事**である点に注意）＋落書「しらぬかり橋をなんの罰ぞといは…」の「かり橋」の風刺、⑦**土岐出火**＝京都所司代土岐丹後守の自火落書等。いずれもOCR崩れがあり文言は要照合。
- **repo関連と陰性の確認〔確認・重要な重複回避〕**: [GAZ-097](../gazetteers/GAZ-097.md)の音無川条が「元文世説」から引く**元文4年（1739）7月の白雉（朝鮮雉）を瀧野川辺に放した記事**、および同書[3]の元文期の記事（元文4年の飛鳥山の花を冷泉家に奉る条〔求涼雑記引用〕等に対応する項目）は、**本巻之五（2562521）・巻之四（2562520）・巻之六（2562522）の本文検索（「白雉」「雉」「瀧野川」「放生」「飛鳥山」「冷泉」）では確認できなかった（陰性・2026-11-19）**＝**江戸時代落書類聚の活字収録は江戸志の引く「元文世説」と部分的な重なり（項目名・元文諸事）を持つが、該当条文の収録はない＝GAZ-097の引用書「元文世説」の所在解明は不成立・継続課題**。また本巻には水窪川・弦巻川・谷端川・千川上水の直接文言もない（陰性）＝本資料は水系の一次記録ではなく、**「元文世説」という書名・節名の運用の近代側実例として、GAZ-097の引用書研究の補助資料**に位置づける。
- **位置づけ〔観察〕**: 落書類聚の編者矢嶋松軒が元文期の落書の解説のために「元文世撰／元文世説」という名を節に付けたのは、江戸期から「元文世説」という呼び方で元文の世相を語る慣用（または書名）があったことへの依拠の候補を示す。江戸志[3]の音無川条が置かれた文脈（同巻の飛鳥山条が求涼雑記を引く）からも、近藤義休本→瀬名貞雄系の江戸志は元文代の世説記録（元文4年の白雉・飛鳥山等の年次を持つ）を多用しており、「元文世説」は江戸志系の地誌の参照書団の一つと考えるのが整合的である（文献の同定・原字の確定は今後課題・断定しない）。
