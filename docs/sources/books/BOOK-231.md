- **意義〔観察〕**: ①観泉寺（杉並区今川・今川氏の菩提寺）の寺誌・氏誌で、**江戸期に今川村（現杉並区）周辺を知行した旗本今川家ゆかりの史料集**とみられる〔収録文書の来歴（今川家伝来文書か否か）は本文未見のため断定しない〕。**千川用水の南六ヶ村側（杉並側）の樋口寸法・水積を記した「配当書」が同家・同寺関係の史料集に収録されている**というBOOK-032（文化財シリーズ29）解説部の引用経路の収録先が書誌レベルで裏付けられた＝**[GOV-110](../gov/GOV-110.md)№26「南六ヶ村引取分口」・[BOOK-032](BOOK-032.md)のM10年分水口6口水積文言の一次確認候補**。②杉並区立郷土博物館の[ADEACコレクション](https://adeac.jp/suginami-city/)（星野家文書・須田家文書系）とは独立した、**今川家系の千川用水文書の所在**を示す点で、千川用水の村方文書の所蔵系統のリストに新系統を加える。
- **関連史料の位置づけ〔観察・repo未登録の引用文言の位置〕**: BOOK-032が解説部で引く『千川用水南六ヶ村樋口寸法反別配当書』の本文（分水口6口の寸法＝新町口45坪5合1勺5才〔上井草・下井草〕ほか）は、現時点でrepo上はBOOK-032の孫引用のみ。**本書誌確定により、原本所在の探索（NDLオンライン請求・都立中央での現物確認・全832p内の当該頁同定）が可能になった**。
