- **元禄3年（1690）の田無村の検地帳＝田無用水の元禄9年（1696）嘆願・引受（[BLOG-284](../blogs/BLOG-284.md)の田無市史引用・[ORG-038](../org/ORG-038.md)「元禄年間（1688〜1704）用水引かれ」文言）のわずか6年前の村内の田畑・石高・地名の記録**＝**田無村が用水を必要とした土地条件（畑作中心・石高・地目の実態）を一次史料レベルで確認する入り口**〔15pの冊子で、翻刻・抜粋・解説かの区別は未確認〕。田無用水史の絞り込みに直結する所在として、西東京市中央図書館での実物確認が最優先に近い資料。
