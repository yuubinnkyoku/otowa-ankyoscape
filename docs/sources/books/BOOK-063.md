# [BOOK-063] 『みどりと水の練馬』第3章「練馬の水系」

- **書誌〔確認〕**：練馬区土木部公園緑地課発行、**平成元年（1989年）3月**。第3章「練馬の水系」は練馬区専門調査員・北沢邦彦による加筆。練馬わがまち資料館「ねりまの川」シリーズ（[GOV-005](../gov/GOV-005.md)・[GOV-056](../gov/GOV-056.md)・[GOV-067](../gov/GOV-067.md)・[GOV-068](../gov/GOV-068.md)）が「ねりま区報」連載とともに元にした資料と、各コラム末尾のシリーズ解説で明記。
- **意義〔確認〕**：千川上水・分水・湧水についての練馬区側の一次刊行物。「ねりまの川」連載は本書の内容をほぼ踏襲しているため、本書確認により各GOV記事の原典格上げ・図版（水系復元図など）の確認が可能になる可能性がある。
- **制限〔未確認〕**：本文・所蔵情報は未確認。練馬区立図書館等での現物確認が次の一手。
