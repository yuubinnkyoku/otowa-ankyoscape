# [BOOK-124] 豊島区大総覧（1937年）— 三川並記と谷端川暗渠化註・丸池と矢端川

- **書誌〔確認〕**: 『**豊島区大総覧**』（皇紀2597年版＝**1937年**、豊島区史編さんに関わる区勢総覧書。巻頭に「皇紀二五九七年」表記）。NDL次世代デジタルライブラリー [book/1222049](https://lab.ndl.go.jp/dl/book/1222049)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **三川並記と谷端川暗渠化の註〔確認・repo初出の1937年時点の明文〕**: 土地位置章「地形は東西が長く南北が短く**區の西南鶴卷川、西北に谷端川西に千川が流れて居る。註 谷端川は下水道工事によつて暗渠となつて居る**」＝**1937年時点で豊島区（旧谷端川流域町村）側が「谷端川は下水道工事によって暗渠となっている」と明記**〔谷端川の1934年下流部暗渠化（[GOV-201](../gov/GOV-201.md)・[GOV-205](../gov/GOV-205.md)）の後の時点の区勢書レベルの確認。**下水道工事に由来する暗渠化**という因果の表現はrepo初出候補〕。
- **三川の流路記述〔確認・1937年時点の地形説明〕**: 「窪地の田の間には小川が流れこの水が灌漑用の水となつた、**今の高田南町を流れるものや長崎南町から東町を通つて池袋と板橋金井窪の間を通つて巢鴨に入る谷端川、池袋の丸池に源を發して雜司ケ谷の窪地を濕し小石川音羽へと流れた細流**、これらが〓い水をたゝへて耕作の用を爲した」＝**①高田南町を流れる川（＝鶴巻川）、②長崎南町→東町→池袋と板橋金井窪の間→巣鴨（＝谷端川）、③池袋の丸池に源を発し雑司ヶ谷の窪地を湿し小石川音羽へ（＝弦巻川）の三川を灌漑水系として並記**〔1937年時点の過去形（「流れた」）での記述＝丸池〜音羽の流れがこの時点ですでに過去になった観察とも読める〕。
- **丸池の二つの記述〔確認〕**: ①池袋章「**豐島師範から一寸離れたところ（今の鐵道學校）の窪地に丸池と云ふ小沼があつた、この小沼は密林に覆はれて居てこゝには白蛇が小沼の主と云はれて居た**、この密林には狐も住み…**この小沼の水は雜司ケ谷に流れて居つて灌漑用水の源を爲して居た**」＝**丸池の位置（豊島師範から少し離れた窪地→今の鉄道学校）・白蛇が主の伝承・雑司ヶ谷へ流れて灌漑用水の源**〔「雜司ケ谷に流れて居つて」＝弦巻川源流としての観察。豊島師範・鉄道学校の前身関係はOCR要照合〕。②名所旧蹟章「**池袋の丸池 池袋二丁目鐵道〓[教]習所內**、池袋の地名もこの池に因むものと云はれて居る、これについては文化年間（今から百三四十年前）の**遊歷雜記**に「**當村を池袋と名づけしは往古夥しき池ありしによつてなり、中古より段々埋まりしかど今尙三百餘坪あらんや、此邊の西の果は池袋と雜司ケ谷との村境にありて常に迸水湧出し流る**」とあるが今は**鐵道〓[教]習所內に僅かにその名殘を止めて居るに過ぎぬ**、昔この丸池から出る〓[湧]水はこの附近一帶の田地を濕したもので**今の雜司ケ谷六丁目から三丁目を過ぎ音羽の方へ流れて居た**、**源義家がこの流れを狹んで合戰をなし戰終つて弓の弦を外し卷いて納めたから鶴卷川の名が起つた**のだと云はれて居るが今は昔の片鱗さへ止めて居らぬ」＝**遊歴雑記の丸池記事の引用（三百餘坪・村境に常に迸水湧出）＋1937年時点の実況（鉄道教習所内に名残のみ）＋雑司ヶ谷六丁目→三丁目→音羽の流路＋義家弓弦説**〔[BLOG-073](../blogs/BLOG-073.md)/[BLOG-074](../blogs/BLOG-074.md)（遊歴雑記の二次転記）の直接引用確認に相当する同書経由の記録。「今は鉄道教習所内に名残」＝1937年時点で水池の残存を示唆〕。
- **蜀山人の狂歌〔確認・repo初出〕**: 丸池条末尾に「**流れ出るみなかみ〓[清]き土なれやつる卷川の瀧の白糸 蜀山人**」＝**大田南畝（蜀山人）の鶴巻川の瀧を詠んだ狂歌**〔「つるまき川の瀧」＝弦巻川の滝（音羽の瀧系か）を詠んだ江戸期狂歌の存在記録。出典狂詩文書名・採録書は本書に記載なし・要確認。OCRの欠落字（〓）は原文照合で確認する〕。
- **矢端川〔確認・repo初出の川名記述〕**: 「**池袋田甫は矢端川を挾んで板橋田團と相對した**、この附近は夏になれば大きな螢が飛んで居た、**水田の多かつたのはこの川の附近でこゝからは農家の食料を充すに十分なだけの米がとれた**、この水田は大正時代に入つても可成殘つて居たが今は面影さへ見られなくなつた」＝**矢端川が池袋田圃（南側）と板橋田団（北側）の間を流れる灌漑川で、大正期まで水田が残ったことの記録**〔谷端川下流域（池袋〜板橋境）の「矢端川」呼称の1937年記録。矢端川＝谷端川の同区間の別名か、支流かは本書では明記されず断定しない（[BOOK-038](BOOK-038.md)「大塚節」の矢端との関係も未確認）〕。
- **庚申塚の巣鴨村役場〔確認〕**: 「明治二十二年**池袋村、堀之内村を合併して生れたもので當時の村役場を庚申塚六百三十番地中田方（現在の保養院前）に置き**初代の村長には田崎惣左衛門氏が就任した」＋大区小区制時代「**副戶長庚申塚に役場があつた**」＝**巣鴨村（明治22年町村制）の村役場が庚申塚630番地（保養院前）に置かれた記録**〔庚申塚＝谷端川中流の地名の行政拠点としての記録〕。
