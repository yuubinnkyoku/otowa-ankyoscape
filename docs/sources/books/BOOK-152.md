# [BOOK-152] 十方庵遊歴雑記 四編／江戸雀 後編（江戸叢書活字版）— 音羽の瀧の水源・観音由来の文言

- **書誌〔確認・条の帰属は要照合〕**: 『**十方庵遊歴雑記 四編‖江戸雀 : 後編. 7-12巻目**』（**江戸叢書刊行会・1916年**の江戸叢書冊。『十方庵遊歴雑記』四編と『江戸雀』後編巻7-12を収める活字版）。NDL次世代デジタルライブラリー [book/952980](https://lab.ndl.go.jp/dl/book/952980)。本条は十方庵の音羽の瀧に対する記述（江戸雀後編の項か遊歴雑記四編かの条帰属は原典の前後関係の照合を要する）。**引用はすべて同館OCRテキスト由来であり、文言は原文との照合を要する。**
- **①音羽の瀧の水源・合流点・人工性・観音由来の文言〔確認文言・repo初出の新地名と由来説の文言〕**: 「**上は池袋村の池上より湧出し、雜司谷村法妙寺まへより、御嶽通り〓土（清土）を過、又金が窪村より御鷹部屋の東を流るゝ小溝の水双方、護國寺角西門前石橋下にて合流し、弦卷川と成て諸方の小流助水となりて、西靑柳町を過、音羽町西側裏通りを流るゝを堰留て、塵芥を漉て、觀世音に因み町名を所緣に、音羽の瀧とは作りしもの也**」＝**①水源は池袋村の「池上」より湧出、②雑司ヶ谷村法妙寺前より御嶽通りの清土を過ぎ、③「金ヶ窪村」より「御鷹部屋」の東を流れる小溝の水が双方とも「護国寺角西門前石橋下」で合流して弦巻川となり、④西青柳町を過ぎ音羽町西側裏通りを流れるのを堰き止め、塵芥を漉いて、観音（護国寺観音）に因み町名を縁に「音羽の瀧」と作ったもの、という流路と由来の記録**。〔**①金ヶ窪村（現・目白〜雑司が谷側の窪地地名）と御鷹部屋（幕府の鷹部屋）の2地名、②護国寺の角の西門前石橋の下という合流点の位置、が資料ファイルとしてはrepo初出の記録**。③音羽の瀧の人工性（堰留・塵芥を漉く）と観音由来説の江戸期文言。[BOOK-151](BOOK-151.md)（初編・文化初年に作りし文言）・[BLOG-185](../blogs/BLOG-185.md)（wanjin・弦巻川＝天然物・護国寺観音由来説の二次記録）と対校できる。法妙寺（ほつみょうじ）は雑司ヶ谷の寺院（要照合）〕。
- **②同条の文脈〔確認・内容メモ〕**: 本条は伊皿子（品川）の「しら絲の瀧」（林泉の飛泉）の水質批判の中で、彼の飛泉が諸方の穢水（大どぶの落し水）であることの対比として音羽の瀧を挙げる文言である（「**彼音羽の瀧の玉水、簾の水上に似て不淨なるもの也、音羽の瀧も〓淨にはあらざれど…**」）。＝江戸の飛泉（人工の瀧）の水質の実態を衛生観に基づいて批判する江戸期の観察記録。〔音羽の瀧の水質（不浄）と水源（かくのごとし）の併記。[BOOK-151](BOOK-151.md)①の人工性の文言と補完関係〕。
