# [BOOK-046] 雑司が谷二丁目配水管新設工事地区の発掘調査報告書（2005年）

- **書誌〔確認：CiNii Booksの所蔵書誌〕**：雑司が谷遺跡（豊島区雑司が谷二丁目配水管新設工事地区）発掘調査団編『東京都豊島区・雑司が谷遺跡（豊島区雑司が谷二丁目配水管新設工事地区）の発掘調査』、**豊島区遺跡調査会、2005年3月刊**。**豊島区遺跡調査会調査報告8／「雑司が谷」2**、NCID **BA76878060**。
- **形態〔確認：同書誌〕**：**iii＋96頁、図版23頁、30cm**。**英文要旨あり**、引用・参考文献は**p.94**。CiNii Booksは学習院大学・立教大学など**10館**の所蔵を案内する。
- **資料の範囲〔確認：標題〕**：「雑司が谷二丁目配水管新設工事地区」という工事名が標題に明記されている。**2005年3月は報告書の刊行年月であり、配水管工事の着工・竣工年月ではない**。配水管を旧弦巻川の暗渠や下水道管と同一視しない。
- **未確認事項**：**報告書本文・図版・調査区の住所や座標は未閲覧**。旧河道・水田・井戸・湧水・溝・地層の検出有無は未確認。
- **出典**：[CiNii Books（NCID BA76878060）](https://ci.nii.ac.jp/ncid/BA76878060)（書誌・所蔵館）／[豊島区「遺跡別刊行済報告書一覧」](https://www.city.toshima.lg.jp/349/bunka/bunka/bunkazai/documents/isekibetsu-list170424.pdf)（「雑司が谷Ⅱ」・報告書8・2005年の対応）。
