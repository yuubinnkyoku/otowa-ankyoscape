# [BOOK-136] 東京府史 行政篇 第一巻 — 神田上水留史料群の書誌紹介

- **書誌〔確認〕**: 『東京府史 行政篇 第一巻』（東京府編・昭和期刊。NDL次世代デジタルライブラリー [book/1686820](https://lab.ndl.go.jp/dl/book/1686820)・発行所寄贈本）。総説の所蔵史料の解説の中に神田上水関係の記述あり。**引用文言はすべてOCR由来で要原文照合。**
- **神田上水留の書誌紹介文言〔確認・repo初出の性格づけ〕**: 総説（「東京府史行政篇總說」のページ割注と読める部分）: 「**神田上水留 二十八冊**…**神田玉川上水諸留**…**以上の三部は專ら兩上水修治の簿記であつて、その末篇には維新後のものが二三冊ある**」＝**『神田上水留』と『神田玉川上水留』（諸留）を「両上水（神田上水・玉川上水）の修治の簿記」として紹介し、末篇に維新後（明治期）の冊が含まれることを記す東京府史の記述**＝[GOV-232](../gov/GOV-232.md)〜[GOV-237](../gov/GOV-237.md)・[GOV-242](../gov/GOV-242.md)・[GOV-243](../gov/GOV-243.md)・[GOV-244](../gov/GOV-244.md)で利用している史料群の性格（修治の簿記＝普請・修復の帳簿）と構成（末篇の維新後の冊＝神田上水留[59][60][61]の明治2年分冊・神田玉川上水留の明治2年冊群）に対する府の修史事業側の二次的な裏付け。
- **冊数の対立〔観察・要照合〕**: 紹介文言の「**二十八冊**」（OCR・冊数の数字は乱れがある）に対し、NDL次世代DLの『神田上水留』は**61冊**（[1]〜[61]・2587456-2587516）＋「神田上水留」を本文に記す他のhit1冊（本書）＝**府史紹介時点の所蔵冊数とNDL版の61冊との冊数の対立**（合冊・分冊の数え方の差か、東京府の所蔵が後に分割・追加されたか）。原ページの数字の確認と、NDL版の各冊の「元の蔵印・伝来」の照合が課題。
