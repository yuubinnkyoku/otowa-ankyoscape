# [BOOK-142] 武蔵野及其周囲（鳥居竜蔵・1924）— 狹山池の跡と残堀川の1924年の学術観察

- **書誌〔確認〕**: 鳥居竜蔵『武藏野及其周圍』（磯部甲陽堂・大正13年7月23日＝1924）。NDL次世代デジタルライブラリー [book/983038](https://lab.ndl.go.jp/dl/book/983038)。人類学者・考古学者の鳥居竜蔵による武蔵野の考古学・地形の論集。「武藏狹山一帶に於ける先史時代及原史時代の遺蹟」等を収録し、大正7年（1918）3月以降の村山貯水池附近の遺蹟調査（「**大正七年三月三日である。それから三四囘此處に參つた**」）に基づく記述を含む。**引用文言はすべてOCR由来で要原文照合。**
- **狹山池の跡と残堀川の1924年の観察〔確認・repo初出級〕**: 「**一番西の端の狹山の丘陵の出鼻の下に箱根ケ崎といふ所があつて、其處に古池が殘つて居る。此の古池は昔の所謂狹山池の跡であらうと思ふ。今は纔に水溜りになつて居るが、昔は相當に大きな池であつたらう。此の池の水は殘堀川といふ流れになつて、今日繼かに溝の樣な狀態であるけれども、立川の普濟寺の西に至つて多摩川に注いで居る。さうすると此の殘堀川は多摩川の流域に屬することになる**」＝**①狹山丘陵の出鼻の下の箱根ヶ崎に古池が残る＝狹山池の跡の1924年の実見（「今は纔かに水溜り」＝当時すでに小規模化）②古池の水は「残堀川」という流れになり「溝の様な状態」で立川の普済寺の西で多摩川に注ぐ＝1924年時点で残堀川が玉川上水に合流せず多摩川に直接注ぐ**＝明治期の水質悪化による伏せ越し化（[GOV-283](../gov/GOV-283.md)のWikipedia脚注〔三次資料〕・[GOV-290](../gov/GOV-290.md)の1905年の汚染記録）**後の状態の学術観察**（伏せ越しの機構そのものへの言及はなく、観察結果としての多摩川への合流を記すのみ）。
- **標高の列〔確認・repo初出の定量〕**: 「**狹山の池が百四十四メートル、殘堀川の位置は…丁度狹山の池と立川との間の中央部あたりの沿岸で百〇八メートル、猶は殘堀川の普濟寺西より多摩川に注ぐ所は七十五メートル、それから府中の高さは五十メートル、川越と狹山の間の堀兼が五十七メートル**」＝**狹山の池144m→残堀川中央部（狹山の池と立川の間）108m→多摩川合流点（普済寺西）75m→府中50mという標高データつきの記述**＝残堀川の流路（狹山池→立川方面→多摩川）の比定の地形学的な補助資料。
- **残堀川・柳瀬川を伝った有史以前の交通路の議論〔確認・周辺〕**: 「**一方は多摩川に注ぐ所の殘堀川、一方は荒川に注ぐ所の柳瀨川、此の兩川を傳つて往古の民衆が南北から此處に入つて來ることも出來よう**」（鎌倉時代・有史以前の民衆の移動の議論）＝狹山丘陵（村山貯水池附近の遺蹟）へ有史以前の民衆が多摩川沿岸から残堀川を伝い・荒川方面から柳瀬川を伝って入ったという考古学的な交通路の議論＝**残堀川を古い時代の移動経路として位置づける観察**（本repoの四河川〔水窪川・弦巻川・谷端川・千川〕と同じ「谷筋＝古道」の視角の対比資料）。

## 制限・未解決

- ①OCR由来で「纔」「繼」等の字形は要原文照合。②狹山池の「跡」とする同定は鳥居の推定（「であらうと思ふ」）であり、池の規模・存廃の年代の断定はしない（遠山1905〔[GOV-290](../gov/GOV-290.md)〕の「約千坪餘ノ沼池」〔1905年時点で実在〕・武蔵野歴史地理1930〔[BOOK-138](BOOK-138.md)〕の「箱の池といふ小池」との規模記述の対校＝1924年前後の池の縮小過程の整理は要照合）。③残堀川と狹山池助水堀（江戸期）の同一水路であることの同定は本書単独では断定しない（[GOV-283](../gov/GOV-283.md)・[GOV-290](../gov/GOV-290.md)・[BOOK-138](BOOK-138.md)との対校による仮説）。④「立川の普済寺」の比定（立川市の普済寺か）と多摩川合流点の位置は地形資料との照合課題。
