# [BOOK-148] 中野町誌（1933）— あやめ橋・壽橋と神田川改修事業の町側記録

- **書誌〔確認〕**: 中野町編『**中野町誌**』（1933年刊・中野町（現・中野区）の行政誌）。NDL次世代デジタルライブラリー [book/1050477](https://lab.ndl.go.jp/dl/book/1050477)。**引用はすべて同館OCRテキスト由来。橋梁表・区間表は列崩れが著しく文言候補として扱う。**〔中野町（1932年まで）は神田川（神田上水）中流域の沿岸町で、旧市郡界の西側に当たる〕
- **橋梁表の「あやめ橋」〔文言候補・repo初出の橋梁表用例〕**: 第十三章「土木及交通」の橋梁表（橋名・場所・路線名列と見られる）に「**あやめ橋**」の橋名が読める（周辺に「千代田橋」等の橋名と中野·新井線・國分寺·四谷線・中野·板橋線・淀橋·白子線・世田ヶ谷·中野線等の路線名が並ぶ）＝**中野町域の橋として「あやめ橋」が1933年時点の町誌の橋梁表に載る用例**〔[GOV-184](../gov/GOV-184.md)の東京府告示768号（昭和11年・神田上水第一負担区「至同市同區同一丁目一番地先(あやめ橋)」＝中野区本町通1丁目先）と、橋名の綴り（あやめ橋）・町域（中野町域）が整合＝**告示の「あやめ橋」が中野区本町1丁目の神田川の橋であることの第130回課題③を大きく前進させる傍証**。列崩れで橋梁表内の所在地・路線対応は原画像照合まで保留。現在の菖蒲橋（中野区本町1丁目・神田川）の前身の橋と読めるが、同一性は断定しない〕。
- **神田川改修事業の町側記録〔文言候補・repo初出の実施側一次文言〕**: 町政史の記述に「**神田川改修事業多年本町及ビ落合、淀橋、戶塚、高田ノ五ヶ町關係者ニ於テ促進運動ニ努力シタル、神田川改修事業モ、本年度臨時府會ノ協賛ヲ經テ、失業救濟事業トシテ左記ノ方法ニ依リ實施ノコトニ決定セリ。改修區域 中野町藥師堂地内壽橋ヨリ早稻田地內郡界ニ至ル延長約二里 改修年度 昭和五年度ヨリ同八年度ニ至ル四ヶ年度 事業費 金貳百八拾五萬貳千六百圓 事業方法 失業救濟事業 工事着手 昭和五年十二月一日**」＝**①改修促進運動が中野・落合・淀橋・戸塚・高田の5ヶ町の関係者によること、②改修区域＝中野町薬師堂地内の壽橋から早稲田地内の郡界まで（約2里）、③昭和5年度〜8年度の4ヶ年・事業費285万2600円・失業救済事業・昭和5年12月1日着手という実施要項の町側記録**〔[GOV-296](../gov/GOV-296.md)（省令12号・受益者負担）・[GOV-303](../gov/GOV-303.md)（進捗表の神田上水改修＝和田本町〜壽橋）と対校すると、**「壽橋」が中野町薬師堂地内（現・中野区本町付近）の神田川の橋であることが町誌レベルで裏付けられた**＝[GOV-184](../gov/GOV-184.md)の告示768号の「壽橋」（中野区本町通3-16-2先）の位置特定の前進。〕
- **改修幅員の区間文言〔文言候補・repo初出の幅員区間表記〕**: 同記述に「**改修幅員 自毒橋至田替橋(六間中野地内) 自毒橋至妙正寺合流(六間五分中野落合調町地内) 自同右至高田馬場驛(七間戶塚町地內) 自同右至早稻田面影橋(七間五分早稻田地内) 自同右至郡市界駒振橋(八間早稻田地内)**」＝**改修幅員が6間→6間5分→7間→7間5分→8間と下流に向かって広がる区間表で、区間の基準点が毒橋・田替橋・妙正寺川合流点・高田馬場駅・面影橋・郡市界駒振橋という橋名・地点名**〔「毒橋」はOCR崩れの可能性が強い（同区間表の上流端で「壽橋」との重複が疑われる）が原画像照合までは「毒橋」と記録する。田替橋（田代橋か）・駒振橋（郡市界の橋）はrepo初出の橋名候補。幅員6〜8間＝[GOV-297](../gov/GOV-297.md)の神田上水改修の河幅（下流8間・上流壽橋4間→8/6間）とも対校可能〕。
- **村方書上系の神田御上水の文言〔文言候補〕**: 本誌所収の村方書上（村名帰属はOCR崩れで要確認・中野町域の村）に「**一當村田地用水は井之頭流れ神田御上水年々奉願用水相用申候尤水不足の節は御上水堰取拂申候間用水無御座候**」「**一神田御上水通用水堤橫四間長三百間土手堤先規より御入用御普請被成下候長拾間ならひ堰壹ケ所**」「**一神田御上水川通り沼川にて川幅四五間程御座候尤橋渡しに御座候**」「**神田御上水路當村東村境を流れ村下川幅四五間 水元は常郡吉祥寺村字井ノ頭の池より出…神田御上水に入る餘水は小日向江戶川筋船河原橋より神田川に落 同川淺草柳橋にて荒川に落**」＝**用水の願・用水堤（幅4間・長300間）・川幅4〜5間・橋渡し・水源（井ノ頭池）と餘水の経路（小日向江戸川筋の船河原橋より神田川）という村方書上レベルの神田御上水記述**〔「餘水は船河原橋より神田川に落」は、御上水系（千川系の流末か）の餘水が船河原橋で江戸川（神田川）に落ちたと読める文言候補（帰属の解釈は保留）。「魚獵留」（漁撈禁止）の文言も見える〕。
- **町會の「神田上水改修ニ關スル件」〔文言候補〕**: 昭和5年頃の町會決議事項表に「**神田上水改修ニ關スル件**」が見える＝改修決定時期（昭和5年度着手）に町會が神田上水改修を議案として扱った記録候補。
- **位置づけ〔観察・内容メモ〕**: ①壽橋＝中野町薬師堂地内（本町通3丁目先）・あやめ橋＝本町通1丁目先という[GOV-184](../gov/GOV-184.md)の負担区間の両端の橋が、中野町側の資料（橋梁表・改修記録）で確認された（橋名の綴りの一致はOCR上確実だが文言は要照合）。②改修幅員の区間文言は神田川の下流方向（妙正寺川合流→高田馬場→面影橋→郡市界）の橋名・地点の連続リストとして流路復元に使える。

## 制限・未解決

- ①橋梁表の列崩れで「あやめ橋」の所在地・架設路線の対応は読めない（原画像照合要）。②「毒橋」の原字形（壽橋の崩れか）は未確定。③村方書上の村名帰属（中野村か本町村か等）は未確認。④「餘水は船河原橋より神田川に落」の水路の帰属（千川系の流末か神田上水系か）は解釈保留。⑤本誌のOCR全文に「千川」「仙川」「水窪」「弦巻」「谷端」の語は0件（陰性記録・第131回掃引。江古田・妙正寺・善福寺・井の頭の語は多数）。「玉川上水の分派を受けて」等の千川系合流は千川の名では現れない。
