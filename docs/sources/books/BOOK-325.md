# [BOOK-325] 日本の発電所 東部日本篇 — 昭和12年時点の王子印刷局発電所に「千川上水を導入濾過」

- 社団法人日本動力協會 編『日本の発電所 東部日本篇』（**日本動力協會・1937**・[book/1257046](https://lab.ndl.go.jp/dl/book/1257046)）。官公庁・民間の発電所を敷地別に詳述した動力技術資料。**内閣印刷局王子分室（王子発電所）章**（OCRコマ124〜125枚目）を全文抽出して確認。引用はOCR由来。

## 文言〔確認・要照合〕

- **「罐水と冷却水」節（内閣印刷局王子分室・王子発電所章）**:
> 抄紙業には極めて多量の水を必要とする。**それ故當局では深さ300米及350米の2箇の鑿井を有し、更に千川上水を導入濾過して之に充てゝゐる。** それ故特に罐水及冷却水を得る爲めの設備はなく、唯井水は罐水に不適當…

- 同章の発電所の概要（所在の特定材料）:
> （內閣印刷局王子分室）…**王子發電所**…專ら河水を用ひてゐる（冷却水）…**ユングストローム·タービン**（三菱造船所見積・發電容量550kW・過負荷750kW）…バブコツク式・タクマ式汽罐…燃料受渡は荒川河岸 內閣印刷局敷地…

## 読み取り〔観察〕

- **①1937年時点で千川上水の導入が現役〔repo初出の文言〕**: 昭和12年（1937）刊行の技術資料が、内閣印刷局王子分室（王子抄紙工場。旧紙幣寮抄紙局→大蔵省印刷局→内閣印刷局）の用水を「**深さ300米及350米の2箇の鑿井を有し、更に千川上水を導入濾過して之に充てゝゐる**」と記す＝**印刷局抄紙部の千川水利（[BOOK-220](BOOK-220.md)明治7-8年の替水約定→[BLOG-095](../blogs/BLOG-095.md)系分配堰碑の「印刷局抄紙部八拾三坪四合」〔明治42年追刻〕→[ORG-050](../org/ORG-050.md)木樋断片の発掘写真）が昭和10年代に実際に稼働していた1937年定点の技術資料側記録**〔取水停止の昭和45/46年〔[GOV-056](../gov/GOV-056.md)系〕までの間を埋める昭和期の一次に近い記述〕。
- **②深井の併用という供給構成〔repo初出の数値群〕**: 用水を**地下水（300m・350mの深井）＋千川上水（導入濾過）＋河水（冷却）**の3層で構成していたことが読み取れる＝千川上水が単独水源でなく深井の補完水源として位置づけられていた。「濾過」処理が明記される点は水質側（千川の濁質）の情報として使える可能性がある〔用途の内訳（大量の抄紙用水への充当か・罐水補給か）は「之に充てゝゐる」の指示対象の原画像照合まで確定しない〕。
- **③「王子發電所」章の写実〔観察〕**: ユングストローム式/三菱造船所・不錆鋼翼車・550kW・石炭25トン/日等の機械詳細は、王子工場内発電（停電による抄紙損害の回避）の実像で、反射炉→抄紙→印刷局の王子臨川部一帯の動力史（[GOV-194](../gov/GOV-194.md)醸造試験所要覧1909・[BLOG-127](../blogs/BLOG-127.md)系大砲製造所）の昭和期の対比資料になる〔千川用水の流量・分水の工場内配置は本条の範囲外〕。
