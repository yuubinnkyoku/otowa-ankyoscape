# [BOOK-203] 十方庵遊歴雑記 三編（江戸叢書活字版）— 下高田村十二景とおたき橋・面影橋・千川上水・大洗堰の全文言群

- **書誌〔確認〕**: 『十方庵遊歴雑記||江戸雀 : 前編. 初巻-6巻目』（**三編 上・中・下**）。釈敬順（十方庵大浄）著（江戸雀側は菱川師宣 画）。江戸叢書刊行会の活字版（大正5年〔1916〕）。次世代デジタルライブラリー [book/952979](https://lab.ndl.go.jp/dl/book/952979)。文中に「文化十二乙亥年」の言及が繰り返し現れるため**草稿は文化12年（1815）以降**〔三編単独の成立確定年は本書内では確認できず・巻之中末尾の奥書「以上六拾六ヶ條著作畢 江城白堀眞人前廓然盡 十方庵大淨釋敬順宗知老衲」（OCR・判読保留）で草稿の完結を確認〕。**すべての引用は同館OCRテキスト由来で、文言は原文（活字版原本・写本）との照合を要する。**対象四河川（水窪川・弦巻川・谷端川・千川上水）流域に関する本文としては遊歴雑記初編〜五編で最も稠密な一冊。
- **下高田村十二景＋拾遺拾景の全文言群〔確認・repo初出候補が多数〕**: 「拾貳景」条（三編卷之中・第63条）＝**遠山瀾閣翁の「高田の拾貳景」発句集を閲して実見したという成立事情の明記**＋以下の各景の文言:
  1. **富士見坂の眺望**: 「彼富士見の垣生の小屋を何人が名付遣はしけん、**珍々亭**とかや呼で」＝富士見坂の茶屋「珍々亭」の名〔repo初出〕。
  2. **神穴の高樹**: 「ふじみ坂より東南の方凡貳拾七八町にあり、**むかし穴八幡出現の地たり**…今**ひかり松**と稱せり、又此社內に**觀世太夫が一世一代能舞臺の跡、或は放生池**等今に現在せり」＝穴八幡（神穴・水窪川源流域）の「光り松」・能舞台跡・放生池の現存記録〔穴八幡出現地の景観側の一次観察。GAZ系の穴八幡資料（音羽求涼亭・御薬園等）へのappend〕。
  3. **守宮の小池**: 「穴八幡の東へ隣りて**水稻荷**の地にあり、又俵藤太秀郷が守本尊とかやいえる毘沙門天は、山上の堂中に安置せり、**此地往古は舟わたしの川端にてやありけん、船つなぎ松と稱する古松あり**、或は旗たての古櫻といふあり、是は後醍醐帝第一の皇子**宗良親王**と申上又征西將軍の宮とも稱じけるが、此親王の**御陣處の跡也**といふ、又此山を**音信山**ともいふとなん、**櫻雲記に見へて**宗良親王のよみ賜へり…」＝**①水稲荷付近が「往古は舟わたしの川端」で「船繫ぎ松」の古松が残るという舟運記憶、②宗良親王（征西将軍宮）の陣所跡と旗立の古桜、③音信山の別称、④出典『櫻雲記』**〔治安・保元〜南北朝期の高田低地の水運・陣城記憶の江戸期の地名側記録。舟渡しの位置は断定しない。守宮（やもり）の小池の比定も未確定〕。
  4. **戸山の長松**: 「高田の西南三町にあり、此地往昔は**和田戶山と號して、源賴朝公は奧州より御歸陣の砌、御旅館なりし**といひ傳ふ、中古より**尾陽公の御やしき**となり廣く東海道五十三驛の雅景を摸せらるゝいにしへの鎌倉街道は**此御構の中にあり**、近くは諏訪の社の前より望み」＝和田戸山の頼朝御旅館伝承→尾張大納言家下屋敷化・古鎌倉街道の屋敷内取り込み〔戸山（和戸山）の地名・伝承の江戸期記録〕。
  5. **玄國の老杉**: 「高田馬塲より西の方凡五六町にして、諏訪村諏訪明神の社内にあり、是むかし**有原の業平朝臣の思ひの杉、又思ひ返しの大杉**といえるありて今に存す」＝諏訪明神の業平「思ひの杉・思ひ返しの杉」〔高田馬場西方5〜6町の諏訪社の杉の伝承、目白台・諏訪町系の伝承群へのappend〕。
  6. **面影橋の流螢〔最重要・橋名研究の中核文言〕**: 「**面影橋の流螢といふは、富士見坂より東南の方拾二三町にあり、此橋中古承應年間に掛初らる、是は猪のかしら及び明福寺の池水玉川の〓流等を江戸に引て、幾千萬家の渴を扶けしめんが爲に段々に堀來り、雜色村にいたりてもろ〓〓の〓流を落合しめ、川筋を大洗堰まで堀わりし砌、掛渡せし橋也**、此處ほたる名處にて實に流螢のながめは、川に田に畑に路傍にみち〓〓て、**宇治の滿螢と稱するも爭がこれに勝らん**、東西の川筋四五町の間斯の如し、依て都鄙の男女籠を携へ來り團扇にて追ふあり走るあり…**此面影橋の北に掛し小橋をこそ、すがた見の橋といえり、是はむかし業平卿の面痩し形容を、水面に移し見賜ひしとて姿見の橋とは號たり、此橋の名に因て面影橋とは名付しならん、是比丘尼橋但馬橋等の川下にして高田馬塲より雜司谷村四家町への往還たり、後人面影ばしを取違て姿見の橋と混同すべからず**」＝
     - **面影橋の架橋年代・由来自体の文言候補**: 中古**承応年間架初説**と、**上水（猪の頭池水・明福寺池水・玉川〓流等を江戸に引く）開削の砌に掛け渡した橋とする由来説明**〔開削の際の橋という由来記録はrepoの面影橋系の由来論に新系統。「明福寺の池水」の原字・比定は要照合〕。
     - **「面影橋の北の小橋＝すがた見の橋」＝面影橋と姿見橋の2橋の区別の明言**: 「後人面影ばしを取違て姿見の橋と混同すべからず」＝**姿見橋は面影橋の北の別橋で、面影橋の名が姿見橋に因むとする名称論**＝[GAZ-039](../gazetteers/GAZ-039.md)（改正新編江戸志・「面影橋 上水にわたす橋をいふ ○姿見の橋 面影橋の先の小橋をいふ」〔第176回登録〕）の**新旧系統の対応本文が十方庵側に先行して存在**したことの確認＝2橋構造説の独立裏付け。
     - **但馬橋・比丘尼橋の川下にあること・高田馬場から雑司ヶ谷村四家町への往還であること**＝両方向の道筋の記録〔但馬橋はrepo初出候補・比丘尼橋は泰雲寺条（下記）と対校〕。
     - **流螢の名所**: 「宇治の満螢と称するも争がこれに勝らん」＝面影橋の螢の盛況の一次観察〔第171回の「落合三昧」の蛍（1772）と対校可能な蛍名所系列の1815年以降の観察〕。
  7. **山吹の冷泉**: 「高田馬塲の北裏三島明神の社内にあり…むかし右大將賴朝公奧州より御凱陣の砌、和田戶山に御在陣ありて**此山吹の流れに御馬を冷させ賜へり**しとなん、又**山吹の里**といえるも、その後**太田入道々灌**かに川〔?OCR〕の邊に放鷹して此あたりへ來りし頃急雨…心きゝたる少女の山吹の花を折てまいらせしは、**兼明親王の御詠の古事にて、歌は後拾遺に見へたり**」＝三島神社の山吹の流れ・山吹の里・道灌山吹譚（兼明親王の歌）の高田側の記録〔高田馬場北方・三島明神〕。
  8. **大鏡山の古梅**: 「富士見坂の正東八九町にあり、藥師堂**南藏院と號し、又八門の寺ともいえり**…大猷君〔家光〕御手植御愛樹の梅は今も榮えて…**此地古驛の名所にして、麥から橋奥州橋等あり**」＝南蔵院の家光御手植梅＋**「麦から橋・奥州橋」の橋名2件**〔repo初出候補。八門寺＝大猷院（家光）御成の門8つの由来〕。
  9. **田島橋の行人**: 「珍々亭より南眼下に見へて行程凡拾町ばかり、**是上は犀が淵鳥井の淵等の下流たり**、むかし**但馬守何某**といえりし人、此邊野屋敷に鶴あまた飼れし砌の**道路の橋**とかや、**是は一枚岩上田大まがり等いえるの川上なり**」＝田島橋の位置（犀淵・鳥井淵の下流・一枚岩の川上・上田大曲りの下流）と但馬守の鶴飼育の野屋敷に因む橋の由来譚〔**犀が淵・鳥井淵・上田大曲り・一枚岩**の高田馬場〜田島橋間の淵などの地名群はrepo初出候補。河川地形（淵・早瀬・大岩の配列）の江戸期側の記録として貴重〕。
  10. **七曲の紅葉**: 「富士見坂の西五町にあり、むかし賴朝公和田戶山に御在陣の砌敵の軍勢を見賜はんとて開かせ賜ひしとかや…**上は鼠山に三四町下は落合村に五六町**」＝七曲坂の頼朝開坂説・鼠山〜落合村間。
  11. **一枚岩の鮎**: 「**田島橋の川下面かげ橋の上**に、大岩河中にありて長さ數十間幅凡三間餘、その岩中高に**龜の甲に似たる逆流左右へわかれて**…水增時は石面纔に出、**水涸る時は大石みなあらはれて龜の甲を干たるが如し**…數千の鮎の魚の下流より登る…水上より盃を流し河下に有て取上て樂しめるもあり」＝**面影橋直下の神田川の一枚岩（亀甲状の中洲岩）と鮎遡上・流し盃の記録**〔「面かげ橋」表記＝面影橋の書き分け候補・河床の大岩の形状の一次記録〕。
  12. **芙蓉嶺の雪**: 富士見坂のetchup眺望・桃青翁（芭蕉）の碑「目にかゝる時や殊更五月富士」〔富士見坂の碑〕。
  **拾遺拾景**＝「本山の薇蕨」（藤稲荷後山）・「犀が淵の月光」（**文化11年甲戌の夏の楽山翁の怪獣目撃譚**〔古猫に似た白毛の怪獣・川童獺功曾久の類の巷談〕・悪魚栖り）・「鼠山の春秋」（ふじみ坂より北拾餘町・**寢ず見山**の別名・板橋の驛裏手続・**駒塲の御ならし**）・「神靈山の額字」（宿坂の下の金乘院・**水戶黄門光圀卿の「花咲耶姫」染筆**の神額）・「宿坂の古關」（**むかし文明の頃までは、此處に東山北陸の關をすえて守らしめ賜ふ**とぞ・関守の突棒もぢりさくたまの伝来）・「大野山の眺望」（難波浪士・**元和二年丙辰の春**大野一族の籠居・後裔の家例＝門に枝松・芦の年棚）・「**溜池の懷舊**」（「**むかし高田の用水なり、廣き方數拾間ふじみ坂四家町出るの閑道にあり、見下すばかりに低し**、四邊今雜樹繁茂し…むかし何某の卿の影を寫し見賜ひしとて、**面影の池とも又形見の池ともいふ**となん、彼業平卿のすがたの池の枯芦の歌に似寄て、此溜池の枯芦を賞する雅人もあるよし」＝**高田の用水の溜池・面影の池／形見の池の別名の記録**〔高田用水の溜池の位置（富士見坂〜四家町の閑道）の江戸期記録・repo初出候補〕）・「下道の紅葉」（胸突坂より水神の社の邊・**むかしは奧州街道なりし時の並樹松**）・「**龍隱菴の眺望**」（下記・千川上水の文言を含む）・「**夜さむの里の遠砧**」（下記・大洗堰の紙漉家の文言を含む）。
- **おたき橋畷道条〔確認・第177回の「おたき橋」見出しの独立本文裏付け〕**: 三編卷之下・第2条「**上落合村おたき橋畷道の風景**」に「**武州豐島郡上高田の西おたき橋に、落合村へ取付繩手の風景は古雅にして詠深く、南は大久保より四ツ谷中野邊を一圓に眺望し、北は富士見の臺に續きて、椎名町の裏手の山々、西は落合村の立塲より…高田より諏訪村へ續きて、明神の森の木立の夕陽にうつろふ風情**、また**おたき橋の川筋は、渚の綺麗に長流のいざよきは目覺るこゝちせられ、此川筋に鮎釣らんと汀に敷物して水中を見入たる人の風俗も又一品あり**…只うらむらくは**おたき橋より落合村の人家迄繩手の間わずか壹町餘なり**」＝
  1. **「おたき橋」が条の見出し語として独立に存在する江戸期の実例**: [GAZ-097](../gazetteers/GAZ-097.md)（江戸志[8]・落合の橋条の見出し「おたき橋」〔第177回・headwordの実体が独立橋名かどうか保留だった〕）に対して、**十方庵は「上高田の西おたき橋」と橋名として使用**＝「おたき橋」の橋名の実在性を支える独立本文〔おたき橋と淀橋・面影橋の関係（同一橋の別名か・近接の別橋か）は本書内では断定できない・「たき」の原字も要照合〕。
  2. **おたき橋の位置・景観**: 上高田の西・落合村へ取付く繩手（畷道）・南北の眺望（大久保〜四ツ谷中野辺／富士見台〜椎名町裏山）・川筋の鮎釣・繩手は1町余＝面影橋・淀橋の位置記録群と対照可能な上落合〜下落合の橋の観察。
- **泰雲寺条の落合合流構造と比丘尼橋〔確認・repo初出文言〕**: 三編卷之中・泰雲寺条に「**泰雲寺門前通北の方三町にして比丘尼橋にいたる、此土橋は寳永年間了然尼發願して掛初しによつて比丘尼橋と號す、これより下落合村と稱す…此土橋へ流來れるは井草村の妙正寺日蓮の池水也**…**此比丘尼橋の川下一町にして南の方より猪の頭の池水と中野善福寺の池水と一〓〔一圓候補〕に會流して、下は但馬橋姿見橋を過て大洗堰にいたる、諸方の水爰に落合が故に村の名とす**、その川丈の樣子圖のごとし」＝
