# [BOOK-141] 岡場所考（石塚豊芥子編）— 廓外艶郷図目録に現れる音羽の大見世

- **書誌〔確認〕**: 石塚豊芥子編『**岡場所考**』[1]（写本・出版年不記載。安政4丁巳〔1857〕の記事を含み、幕末（安政〜元治頃）の成立と読める〔石塚豊芥子の没年・写本の書写年代は目録照合要〕）。NDL次世代デジタルライブラリー [book/2554872](https://lab.ndl.go.jp/dl/book/2554872)。江戸の岡場所（不特定遊女・廓外の遊興地）を考証した写本。引用文言はすべてOCR由来（写本OCRは崩れが多い）で要原文照合。
- **廓外艶郷の図目録の「音羽大見世長屋」「音羽谷中大見世総圖」〔確認・repo初出の江戸期文言候補〕**: 本書に収録・引用される「**東都廓外艶郷分野之図并妓時勢粧摸写**」（豊亨芥子戯記内の艶郷図の目録と読める）の掲載図リスト——「**深川大新地…本所辨天松井町大見世并五ヶ処局見勢 芝三田新三角大見世并局長屋…音羽大見老（世の崩れか）長屋 根津大見世局長屋 音羽谷中大見世総圖 赤坂田町大見せ…麻布藪下…品川駅…内藤新宿…千住小塚原両駅畧図 板橋**」——に「**音羽大見世長屋**」「**音羽谷中大見世総圖**」が現れる〔**①江戸後期〜幕末の岡場所の図（艶郷図）の目録に、根津・芝三田・赤坂田町・品川・内藤新宿・千住・板橋等の著名岡場所と並んで「音羽」の大見世（遊女屋）を描いた図2種が存在したと記録されること、②「音羽谷中大見世総圖」という図題から、音羽谷の谷中（谷底低地）に大見世があったことを示す図が幕末期に存在したこと**＝**音羽（小石川音羽町）が岡場所（私娼窟）として江戸期の資料レベルで記録される文言候補**。〔[BLOG-045](../blogs/BLOG-045.md) の「音羽九丁目辺りは幕府非公認の私娼窟（岡場所）」伝承（原典不明・事実とは掴らない扱い）に対し、**幕末の岡場所考証書の図目録という文献側の先例**を加える記録。ただし①OCR崩れ（「大見老」等）・②「音羽」の比定（小石川音羽町でほぼ間違いないと読めるが、京都等の別地ではないことの再確認）・③大見世の位置（九丁目か谷中か・水窪川・弦巻川沿いのどこか）は本目録では特定できず、**あくまで文言候補・伝承の強化資料として記録し、存在を確定したとは断定しない**。〕
- **位置づけ〔観察〕**: 音羽谷の水田（[BOOK-002](BOOK-002.md)の「溪谷の水田」）が明治以降に宅地化・都市化する過程で、江戸後期に谷底低地に遊興地（岡場所）が形成されていた可能性を示す系統の史料候補。水窪川下流域の土地利用史（水田→岡場所候補→宅地）の補助線。水窪川・弦巻川沿いの遊興地の立地と流路の関係は、大見世の位置特定（図自体の探索・[地図一覧](../../地図一覧.md) 側の調査）が前提であり、現段階では推定しない。

## 制限・未解決

- ①「音羽大見世長屋」「音羽谷中大見世総圖」は図の目録文言であり、図そのものの所在は未確認（浮世絵・風俗図の目録情報の探索が次回課題）。②「音羽谷中」の読み（音羽谷の谷中・音羽+谷中の両地名の列記等の両義）は原文照合要。③本書の成立年・石塚豊芥子の没年との関係・写本の系統は目録照合要。④岡場所としての音羽の規模・時期の特定は本資料では不可能。
