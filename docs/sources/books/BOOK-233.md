- **千川用水系の資料と配信頁〔確認: 上記目次頁・第三編近代第二章経済(二)農業・(三)交通〕**:
  1. **資料23「予川用水源費」**（明治12年7月〜明治13年6月）＝**配信頁118**〔**目次表記は「予川用水源費」のまま**。「千川用水源費」の誤記と推定されるが、画像判読まで確定しない〕。
  2. **資料28「千川用水取調表」**（明治17年11月）＝**配信頁131**〔[BOOK-032](BOOK-032.md)解説部の「**明治13年資料＝合計117町9反1畝**」や「明治10年代の五ヶ村の千川用水掛田反別」の引用元の候補資料（対応は本文判読まで断定しない）〕。
  3. **資料37「千川水路水車取調書」**（明治38年4月）＝**配信頁190**。
  4. **資料38「千川上水古記録上申」**（明治42年10月）＝**配信頁191**〔＝**[BOOK-032](BOOK-032.md)が「明治42年「千川上水古記録上申」（『豊島区史 資料編』4引用）」として引く高札16ヶ所・橋梁7ヶ所・水番3か所（長崎村・竹下新田・保谷新田元樋口取締）文言の出典資料の所在＝第248回課題②の後半の解決**〕。
  5. **資料41「高田村内鉄道工事による用水路付替に伴う敷地買上願書の下戻願」**（明治18年6月）＝**配信頁195**〔高田村地内の用水路付替＝千川上水系・谷端川系のどちらの水路かは本文判読まで確定しない〕。
  6. （関連）**資料22「池袋村ほか田方干ばつ被害届」**（明治10年）＝配信頁113〔池袋村の千川用水受益の傍証資料候補〕。
- **谷端川・下水道系の資料と配信頁〔確認: 同目次頁〕**: ①**資料121「谷端川改修計画」**（**昭和5年〔1930〕8月**）＝**配信頁849**〔[GOV-301](../gov/GOV-301.md)（日本都市年鑑・都市計画河川「谷端川改修3線」事業決定文言・昭和7.3.31変更）・[GOV-159](../gov/GOV-159.md)（改修費）・[GOV-135](../gov/GOV-135.md)（国立公文書館の1930年代谷端川改修附図群）より前年の**1930年8月時点の「谷端川改修計画」文書が豊島区側に現存**することを巻目次レベルで確認＝谷端川改修の計画書原本の所在候補〕。②**資料119「巣鴨町下水道計画概要と説明書」**（**昭和2年〔1927〕11月**）＝**配信頁840**〔[GOV-135](../gov/GOV-135.md)の「巣鴨町下水道決定（1919-1922）」群の後続・町政期の下水道計画書で、谷端川流域の下水の初期的計画資料候補（巣鴨町＝谷端川中流域）〕。
- **雑司が谷柳下家の帳簿群と配信頁〔確認: 同目次頁〕**: ①**資料35「雑司が谷柳下家日記」**（**明治29年〔1896〕（推定）〜明治32年〔1899〕**）＝**配信頁146**（次資料36が頁189＝約43頁分の大半を占める）・②**資料62「雑司が谷柳下家大福帳(抄)」**（明治7・8年）＝配信頁242・③**資料63〜66「雑司が谷・柳下家領収(抄)」**（明治32・33年）＝**配信頁253ほか4点**〔[GAZ-048](../gazetteers/GAZ-048.md)・[GAZ-072](../gazetteers/GAZ-072.md)の雑司ヶ谷村名由来説に現れる中世雑士**「柳下若狹」の柳下家**と家名を同じくする雑司ヶ谷の家の明治期帳簿群。「柳下若狹」の子孫系か否かの家系の同一性は本文未見で断定しないが、**弦巻川上流域（雑司ヶ谷＝谷頭側）の村方・町方の帳簿・日記類が豊島区に現存**することは、水路・湧水・土地利用（[PAP-097](../papers/PAP-097.md)雑司ヶ谷町の窮民層研究と同じ谷頭集落の明治期）の一次材料の所在として重要〕。
- **水車関係の資料群〔確認: 同目次頁・(二)農業〕**: 資料30「巣鴨村水車営業継年期并器械変換願」（明治20年1月＝頁134）・資料31「長崎村水車営業継年期并増杵願」（明治20年8月＝頁135）・資料32「高田村水車挽臼新設願」（明治20年10月＝頁136）・資料33「巣鴨村水車設立願」（明治28年4月＝頁137）・資料36「巣鴨村水車売買認可願」（明治29年10月＝頁189）＝**[BOOK-098](BOOK-098.md)（通史編2「千川上水と水車業」節）の資料編側の元資料群**〔千川用水水車＝巣鴨・長崎・高田の各村の水車文言の一次確認候補〕。
- **意義〔観察〕**: ①第89〜248回を通じてBOOK-032が引いてきた『豊島区史 資料編』4の引用文言（千川上水古記録上申・千川用水掛田反別など）が**どの資料番号・頁に載るかが初めて特定**され、ADEAC刊行画像で本文確認可能性が開けた。②**資料121「谷端川改修計画」(1930.8)**はrepo初出の計画書の所在で、谷端川改修史（GOV-159/GOV-301）の計画段階の文書を直接確認する道ができた。③柳下家帳簿群は弦巻川上流域の村方史料として、PAP-097・[BOOK-144](BOOK-144.md)（遊歴雑記）・[GAZ-048](../gazetteers/GAZ-048.md)（風土記稿）の系統に接続する。
