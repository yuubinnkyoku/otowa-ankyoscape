# [BOOK-166] 銀行会社要録 第四版・第十三版 — 千川水道会社の明治33年の続投と明治42年の記載消滅

- **書誌〔確認〕**: 『**銀行会社要録 : 附・役員録**』**第四版**（**明治三十三年五月刊行**・東京興信所。NDL次世代デジタルライブラリー [book/803641](https://lab.ndl.go.jp/dl/book/803641)）と**第十三版**（**明治四十二年**〔「明治四十二年一月」「明治四十二年五月」の版記をOCRで確認。1912のNDL書誌publishyearは誤りの可能性〕。[book/803649](https://lab.ndl.go.jp/dl/book/803649)）。[BOOK-164](BOOK-164.md)（第一版・明治30年9月）・[BOOK-165](BOOK-165.md)（第三版・明治32年1月調）の続版調査。**引用文言はOCR由来で原画像照合を要する**。

## ①第四版（明治33年5月刊）の役員録〔確認文言〕

- 「**東京倉庫株式會社取締役會長 千川水道株式會社監査役 東京興信所評議員 豐川良平 三菱合資會社銀行部長 東京銀行集會所副會長**」＋「**三菱合資會社造船所支配人…千川水道株式會社取締役 東京倉庫株式會社取締役…莊田平五郞 三菱合資會社管事**」
- **意味〔確認・対校〕**: 第一版（明治30）・第三版（明治32）に続き、**第四版（明治33）でも莊田平五郎（取締役）・豊川良平（監査役）の三菱系役員が続投**＝明治30年代を通じた千川水道会社の経営実権の三菱側継続（明治40年の岩崎所有化〔BOOK-140〕の前段）の第3の定点。瓜生震・深津鋼作の本版での在任は今回の抽出範囲では確認できず未確認とする。

## ②第十三版（明治42年）で千川水道の記載なし〔確認・陰性記録〕

- 第十三版（明治42年）のfulltext全体に「千川水道」「千川」の記述を確認した結果、**会社統計・役員録ともに千川水道株式會社の記載が存在しない**（grep陰性）。
- **意味〔確認・要因は断定しない〕**: 千川上水の廃止は明治40年6月〔[GOV-307](GOV-307.md)〕。**その2年後の明治42年版に記載が消えている＝廃止後の会社の消滅（解散・岩崎側への吸収・事業転換のいずれかは本書からは判定不能）と整合する**。ただし要録への記載欠如自体は薄い証拠（調査対象からの除外・漏載の可能性）であり、**解散登記・買収契約等の一次資料での確定は今後課題**。中間の第五版〜第十二版（803642等）でいつ記載が消えたかの特定も未了（次回課題）。
