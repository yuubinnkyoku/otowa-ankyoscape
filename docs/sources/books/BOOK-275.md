# [BOOK-275] 滑川邦夫『明治初期田無村及び下田半兵衛家の土地所有と土地利用』（2019）〔明治初頭の田無村の地目構成の研究〕

## 書誌〔所在のみ: NDL SRU・2026-11-22〕

- **滑川邦夫 著**「**明治初期田無村及び下田半兵衛家の土地所有と土地利用 : 『田畑其他取調野帳』の分析を通して**」（**2019**）・**83 p ; 30 cm**＝NDL所蔵（NDL書誌 R100000002-I033672920・JPNO 24045972）。

## 意義〔観察〕

- 明治政府の地租改正（明治6年〜）に伴う**『田畑其他取調野帳』を用いた田無村の地目（田・畑・宅地等）の分析**＝**明治初頭の田無村の水田の有無・分布の一次データ分析候補**。田無村の地形（崖線・谷戸）と田無用水の灌漑対象（畑作中心か水田か）を地目レベルで確認できる可能性がある資料〔地目データの実際の数値・水田の含否は本文未見のため断定しない〕。下田半兵衛家（名主）の所有地の内訳も扱う。
