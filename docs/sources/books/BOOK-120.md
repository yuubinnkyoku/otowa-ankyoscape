# [BOOK-120] 絵入暴風見聞誌（1880年）— 明治13年10月4日暴風雨の千川用水氾濫・千川橋流失

- **書誌〔確認〕**: 大島真治郎編輯兼出版『絵入暴風見聞誌』（**明治13年（1880年）10月出版**・東京塵積堂・定価金四銭・出版人は東京下谷區彌左衛門町十二番地の平民大島眞治郞）。NDL次世代デジタルライブラリー [book/901800](https://lab.ndl.go.jp/dl/book/901800)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **暴風雨の概要〔確認・要照合〕**: 「**明治十三年十月四日午前一時よりの暴風雨の實**…有餘年來の天變…の實況を記す」。10月1日曇天→3日まで雨・弱い北西風→**4日午前1時に北西の風が「烈しく雨亦暴し」**、「人家を倒し獨木を折堤…」と実況を記す。奥付の屆出は明治13年10月8日＝**災害の4日後に出版された実況記録**。
- **千川用水の氾濫・千川橋流失〔確認・repo初出の重要文言〕**: 小石川区の倒壊戸数リスト（水道町・大和町・同心町・諏訪町・春日町・小日向武島町・大塚窪町・林町・雑司ヶ谷町・掃除町・久堅町・餌差町・白山前町・初音町・音羽町・大塚仲町・上富坂町）の末尾に「**久堅町柳町音羽町邊 千川用水溢れ入家床上を浸し〔OCR判読不能部分あり〕千川橋流失す**」＝**1880年10月4日の千川用水（谷端川下流小石川区間）の氾濫・床上浸水・千川橋流失の一次記録**。〔判読不能部分（「そこと二はしりうしつ尺餘」等）は引用から除外・要原文照合〕
- **意義〔観察〕**: ①**千川橋の年代付き橋名記録として、従来の最古（明治16年・1883年東京図測量原図＝[BLOG-133](../blogs/BLOG-133.md)）を3年前倒し**する。**氾濫地点（久堅町・柳町・音羽町辺）はBLOG-133の千川橋の位置（柳町→掃除町）と整合**し、同橋の橋名史を補強する。②1880年時点で同区間の流れが「**千川用水**」と呼ばれた印刷記録＝**谷端川下流の千川呼称（BLOG-133「千川分水」説・[PAP-027](../papers/PAP-027.md)・[GOV-164](../gov/GOV-164.md)「千川上水ノ剰水ヲ容レ」）への加証**。③1880年は**千川水道株式会社の開業年（明治13年）と同年**の、営運中水路の災害記録。④**氾濫した流れが千川上水本流（千川堀）か谷端川下流（千川呼称の流れ）かは本文から確定できないため、断定せず両可能性を並記する**。⑤明治17年（1884）の千川水路変更（[BOOK-077](BOOK-077.md)④・汚水浸入防止）に先行する、下流小石川区間の氾濫・流失記録。
- **根津藍染町の浸水〔確認・repo初出〕**: 本郷区の被害リストに「**根津藍染町一圓 田水一時道路切る**」＝1880年暴風雨時に**根津藍染町（藍染川＝谷田川〔千川〕下流の流路にあたる町名）一帯で水が道路を切った**記録。〔「田水」の判読は要照合〕水源（藍染川か周囲の田面の水か）は本文では特定できない。
