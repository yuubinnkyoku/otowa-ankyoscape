# [BOOK-117] 実地調査 北豊島郡の園芸（1929）

- **書誌〔確認〕**: 北豊島郡農会『実地調査 北豊島郡の園芸』（1929年）。NDL次世代デジタルライブラリー [book/1123065](https://lab.ndl.go.jp/dl/book/1123065)。OCRテキストで確認。**文言はOCR由来で要照合。**
- **境窪の千川用水樋口のランドマーク性〔確認・repo初出〕**: 篤農家一覽表で篤農家の所在地が「**字境窪 千川用水樋口より約一丁**」「約三丁」と案内に使われる＝**1929年時点で境窪の千川用水樋口（谷端川分水口）が地域のランドマークとして機能**していた記録。
- **村別作物図〔確認〕**: 滝野川・西巣鴨・高田・長崎等の北豊島郡村別作物図（付録）を収録。
- **位置づけ〔観察〕**: [GOV-129](../gov/GOV-129.md)（境窪証言）・[GOV-159](../gov/GOV-159.md)（境窪分水）の境窪＝谷端川分水点の認識が、1929年の農会刊行物でも案内基準として定着していた傍証。谷端川流域（長崎町・滝野川等）の近郊園芸の作物構成の一次資料。
