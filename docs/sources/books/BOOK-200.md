# [BOOK-200] 源平軍物語（1919活字・国史研究会）— 「豐島の上、瀧野川松橋」の陣所文言

- **書誌〔確認〕**: 黒川真道編・国史研究会『源平軍物語』（大正8年〕〔1919〕活字版）。NDL次世代デジタルライブラリー [book/948815](https://lab.ndl.go.jp/dl/book/948815)。**同書の序文が便宜上「源平軍物語」と自称する軍記物語**（源平盛衰記と別系統の軍記として、講談社『源平盛衰記』等の諸本と区別される系統の可能性を記載上は保持する）。**本資料の記述は活字版由来で、底本（写本・版本）の系統と本文批判の検証は未了。**
- **松橋文言〔確認・repo初出の本文〕**: 頼朝の武蔵進撃（隅田川渡河）の条＝「**江戶、高西と仰せしと下知せらる。江戶·葛西は石橋の合戰に、兵衞佐殿を討ち奉りし事恐れ思ひけるに、此仰を蒙りて悅びをなし、在家を毀ちて浮橋尋常に渡したり。軍兵是より打渡して、武藏の國豐島の上、瀧野川松橋といふ所に陣を取る。其勢既に十萬餘騎**」＝**①江戸太郎・葛西三郎（「高西」は「葛西」の誤植候補）に命じて在家を壊して浮橋を渡させた前後関係（盛衰記版本〔GAZ-096〕と同型）、②陣所の表記が「**武藏の國豐島の上、瀧野川松橋**」＝「地名（武蔵国豊島の〔かみ〕）」＋「瀧野川松橋」に区切って読める本文（候補）＝**GAZ-096の表記対立群に「瀧野川松橋〔盛衰記と别系統の軍記として直接引用〕」を追加する新文言系統**（「上瀧野河松橋」の「上瀧野河」を「豊島の上」＋「瀧野」の区切りで読む可能性を示す本文例として、盛衰記の「上瀧野河」の句切り（「上＋瀧野河」／「上瀧野＋河」等）の解釈に直接の対照材料）**〔活字植字の際の区切りの可能性を含み、底本本文の原形は未確認・断定しない〕。
- **六所大明神参詣の文言〔確認・対校〕**: 引き続き「**兵衞佐殿はいとヾ力付き給ひて、先づ當國六所大明神に御參詣ありて神馬を引き、上矢を奉られたり**」＝**松橋陣→王子（六所大明神）の神馬・上矢の奉納の文言**＝GAZ-094（東京市史稿の盛衰記長文引用）・GAZ-094経由の江戸志按語（上矢は六所であって弁天ではないとする批判）の本文側の対応条文を持つ、盛衰記と别系統の軍記の本文〔対校用〕。
- **位置づけ〔観察〕**: ①1919年活字版は盛衰記の本文系統の検証材料としては一歩離れた後代の再生産であるため、GAZ-096の対校群の「参考」欄に置く。②「上」区切り読みは1884年刊の風土記稿滝野川村条の「上瀧ノ川」（GAZ-093）・版本系「上瀧野河」（GAZ-096）の解釈問題（「上」が「上瀧」「上瀧野」の一部か、「（豊島の）上」の方位・位置語か）に1919年時点で生きた区切りの例を与える（候補）。**どの区切りが原形に近いかの判定は本資料からは行わない。**
