# [BOOK-194] 井の頭（土岐頼旨・天保7年）— 井の頭池紀行の面影橋異名群と淀橋水車の助水〔第165回〕

- **書誌〔確認〕**: 『井の頭』（**土岐頼旨**撰の紀行文。末尾「**于時天保七申年六月廿二日 大保守源頼旨録 土岐頼旨撰**」＝天保7申年（1836）6月22日付）。NDL次世代デジタルライブラリー [book/2542001](https://lab.ndl.go.jp/dl/book/2542001)。井の頭池への道中（四谷大木戸→甲州街道→中野→和田堀の内→井の頭池→淀橋）を記す私撰紀行。**引用文言はすべてOCR由来で要原文照合。**
- **出立の動機＝梅雨出水期の上水源の懸念〔観察・文言候補〕**: 「**天保七年ひのえさるの卯月の初九日より雨降梅両初めて日々をやみなく降続きつゆになりて…溝川水増し道路ぬけり…土用東つちいみに入りても冷なる風吹て晴るゝひまなく…玉川の水かさ増りも破て引入るゝ水常ならす…いふはかりなし…堀筋をも見はや又**神田上水の源井の頭池の柵なとの破れもいかならんにして思ひ侍れは**水無月の廿日余り二日に先つ井々頭池におもむかんてつとめて出立**」＝**卯月9日からの長雨で溝川・道路が増水し、玉川の水も増えた折、「神田上水の源井の頭池の柵などの破れ」を案じて水無月20日過ぎに井の頭池へ出立した**〔**上水利用者側（殿様・幕臣クラスの知識人）が梅雨出水期に井の頭池の柵・堰の破損を心配し現地確認に出た観察**＝天保7年の出水期の水元管理の意識の紀行レベル記録。「はや」の文は破れの度合いの心配文言（OCR崩れの可能性も残す）〕。
- **面影橋の異名群と淀橋改称伝承〔伝承・repo初出級〕**: 「**此橋もと面影の橋又姿見数の橋姿か橋ともいふ寛永の度御鷹狩の砌淀橋と改むへしと御供の榊原河某に清ことありしとなん**」＝**淀橋（多摩川）の橋の元の名が「面影の橋」で、別に「姿見数の橋（すがたみ…の橋）」「姿か橋」とも言い、寛永の御鷹狩の折に「淀橋」と改称すべき旨を御供の榊原河内守に清言（口添え）があった**という伝承〔**面影橋の異名「姿見数の橋」「姿か橋」の文言群と淀橋改称の由来伝承＝repo初出級**〔[GAZ-030](../gazetteers/GAZ-030.md)（安見橋＝面影橋異名）・[GOV-349](../gov/GOV-349.md)（面影橋御渡）に加わる3点目の系統。**改称年代を寛永期とする伝承は本紀行が初出の系統候補**。あくまで「となん（〜ということだ）」の伝承形式で、史実の改称年代とは断定しない。榊原河内守の比定（榊原氏の河内守）は要照合〕。
- **姿見数の橋の由来譚〔伝承・参考〕**: 「**むかし多摩郡定野の内正報寺の薬師堂の陣れに朝日長者昌蓮か書たるには漆千盃朱千盃黄金千両銭十六万貫朝日さす夕日からやく藤の木の下にありといふこれをいむらき下男に負せて此橋をわたりけるか下男か後にぬすむこともやあらんとそこにて殺しけるとなりその下男のわたりたるは人見たれとも帰る所を見さるゆゑ姿見数の橋といふと里人の物語なり**」＝**朝日長者昌蓮の宝物を負わされた下男が渡った橋で殺され、姿を見たが帰る所は見なかったので「姿見（数）の橋」という**里人の物語〔多摩郡定野〔OCR候補〕の正報寺薬師堂の額文言（朝日長者昌蓮）を引き合いに出した下男殺し譚＝姿見橋の名の俗語源伝承。作者自身「笑ふに堪たりかゝる野夫村老の物語を書付おかんもつたなけれと（野夫村老の物語を書き留めるのも良くない事だが）」と留保を付す＝**作者に伝承としての距離感がある**（repo初出の橋名由来譚。朝日長者・正報寺の比定は未了〕。

- **善福寺池水車の神田上水助水〔観察・文言候補〕**: 「**坂を下り田面にいたる小川に板橋を渡せり善福寺の池より涌出る水にて神田上水の助水となる水車あり**」（妙法寺・和田堀の内の道中）＝**善福寺池の湧水を使い神田上水の助水となる水車**の道中観察〔**善福寺池水系の神田上水助水の天保7年の観察文言候補**（repo初出候補。神田上水の善福寺川筋の水車に関する記録の補充。「なる水車あり」の解釈（水車が助水の役を担うか・その水で水車が回るか）は原文照合まで候補扱い〕。
