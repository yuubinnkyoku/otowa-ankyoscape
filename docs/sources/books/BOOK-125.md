# [BOOK-125] 九中を中心としたる史蹟名勝（1932年）— 千川上水の流末（王子で荒川に放流）と千川堤桜

- **書誌〔確認〕**: 東京府立九中三十五会編『**九中を中心としたる史蹟名勝』**（昭和7年・1932年10月・府立九中〔現・北園高校〕の史蹟名勝の生徒編纂書。巻頭に昭和7年10月の序）。板橋区・王子周辺の史蹟名勝を収録。NDL次世代デジタルライブラリー [book/1209254](https://lab.ndl.go.jp/dl/book/1209254)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **「千川用水と櫻の新名所」〔確認・repo初出の1932年時点の流末記録〕**: 「**千川用水と櫻の新名所〔所在〕板橋區中村町より江古田町迄**（本校より西南江古田町迄約廿丁）…**板橋區を通る千川上水も、元祿九年に保谷の邊から、石神井、妙正寺兩川の中間臺地を、一直線に引かれたもので**、嘗つては小石川御殿湯島聖堂、東叡山、淺草御殿に用ゐられた上水も、**今では板橋、瀧野川に於ては埋められて地下水道となり、王子に到つて荒川にその汚水を放流する程に變つてゐる**」＝**①千川上水の線形認識（石神井川と妙正寺川の中間台地を一直線＝分水嶺上の直線引水という地形説明）、②供給先（小石川御殿・湯島聖堂・東叡山・浅草御殿）、③1932年時点の実況（板橋・滝野川では埋められて地下水道〔暗渠下水〕化、王子で荒川に汚水放流）**〔流末の「王子で荒川放流」＝[BOOK-122](BOOK-122.md)（1930・瀧野川經由王子落とし）・系統の1932年確認。江戸三上水系の列挙「神田上水、玉川上水、三田上水、龜有上水、千川上水」も〕。
- **千川堤桜＝「大正年間に植え」説〔確認・第3の変遷記述〕**: 「**大正年間に、江古田町から練馬を通つて中村町迄蜿蜒一里十餘町に亘つて、其の兩岸に櫻を植え、現在櫻花の新名所となつた。八重櫻、吉野櫻を主として、春風花に醉ふる頃は、行樂の好適地として、小金井、荒川堤に優るとも劣らない**」＝**植樹時期「大正年間」・範囲（江古田町→練馬→中村町・一里十餘町）・品種（八重桜・吉野桜が主体）**〔千川堤の桜の時期について、[BLOG-101](../blogs/BLOG-101.md)の「大正4年11月」（植櫻楓碑・1915）・[BOOK-122](BOOK-122.md)の「大正の初年」（1930）に続く**第3の変遷記述**（1932・「大正年間」）。碑文の大正4年11月植樹と「大正年間」は矛盾しないが、品種（八重・吉野）がBOOK-122と完全一致する点は同一植樹説を補強する。断定は原文照合まで保留〕。
- **板橋火薬製造所の水車（石神井川分疏）〔確認・明治の水利の実録〕**: 陸軍省撰文の記念碑記事として「**明治五年二月太郞左衞門出仕兵部省兼勤造兵司分課創工場於板橋分疏石神井川籍水車便輪轉。九年八月始業迄三十九年十一月癈**」＝**澤太郎左衞門が明治5年2月に板橋工場（後の陸軍火薬製造所）を創設、石神井川から水を分疏して水車を廻し、明治9年8月に操業開始、同39年11月に廃止**〔板橋火薬製造所の水車用水が石神井川の分疏であったこと・明治39年11月廃止の年月が一次（碑文引用）レベルで確認できる。千川上水ではない点に注意〕。

## 制限・未解決

- ①「一直線に引かれた」「中間臺地」は生徒編纂書の説明文で、千川上水の線形の地理学的説明として正確だが、測量に基づく記述ではない。②「小石川御殿・湯島聖堂・東叡山・浅草御殿に用ゐられた」供給先の列挙の典拠は不明（風土記稿系か）。③「王子に到って荒川にその汚水を放流」の具体的位置（音無川経由か石神井川放水路か）は本書では特定できない。④千川堤桜の植樹年（「大正年間」）と[BOOK-122](BOOK-122.md)「大正の初年」・[BLOG-101](../blogs/BLOG-101.md)大正4年11月の関係の確定は、碑文・新聞等の同時代資料で行う。⑤板橋火薬製造所の石神井川分疏の取水位置は本書では特定できない。
