# [BOOK-223] 赤坂区史（1942）— 千川上水通史と明治13年再興の給水区文言・室鳩巣献議説

## 書誌

東京市赤坂区（編）『赤坂区史』（**昭和17年〔1942〕**刊・第十章「衞生」の上水関係の記載が主体）。NDL次世代デジタルライブラリー [book/1042120](https://lab.ndl.go.jp/dl/book/1042120)。区史（行政刊行の二次編纂）で、千川上水・青山上水・麻布水道（旧青山水路の明治13年再興）の各条は『東京通志』・文政町方書上・開鑿上請書等の二次利用とみられる。引用文言の典拠の多くは本文中に挙示されるが原画像照合前提。

## 内容（千川上水関係）

- **江戸の諸上水の整理と千川上水の給区域文言〔確認・対校〕**: 「**元祿九年には千川上水を開いて、先の神田玉川兩上水の給水地外の場末市街に供水した。…千川上水は北多摩郡保谷村に於て玉川上水を分水して、本〓、下谷、淺草邊に給水したものである**」＝**①千川上水を元禄9年（1696）に開き、神田・玉川両上水の給水地外の「場末市街」への給水と性格づける文言、②保谷村分水・本郷・下谷・浅草辺への給水の整理**＝[GOV-226](../gov/GOV-226.md)〜[GOV-228](../gov/GOV-228.md)（1893-94年東京府の水道刊行物の「元祿九年中其工竣ル」「本〓下谷ノ一部ニ給水」）・[GAZ-049](../gazetteers/GAZ-049.md)⑫1（【上水在絕記】「淺草御殿」「淺草の邊一圓」）・[BOOK-174](../books/BOOK-174.md)（「場末市街」に給水する諸上水）と同系の概説で、**新事実ではないが「給水地外の場末市街」への供給という千川の建前の整理文言として区史レベルの対校資料**。〔「場末市街」供水の語で千川の性格づけ（市街地給水）を行う視点は、宝永4年（1707）の農村側の「最寄二十箇村」用水利用の許可（〔[GOV-098](../gov/GOV-098.md)〕の千川文書系）と対比できる〕
- **享保7年の四上水廃止と室鳩巣献議の文言〔確認・対校〕**: 「**享保七年十月に至り、室鳩巢獻議する所あつて、神田玉川兩上水を除き、他の四上水を悉く廢止した。千川上水は上水として一時再興されたが永續せす**」＝神田・玉川を除く四上水（青山・亀有・三田・千川）の享保7年10月の一斉廃止と千川の再興の不永続の整理文言＝[GOV-170](../gov/GOV-170.md)（享保撰要類集・「十月より上水取不申」）・[GAZ-049](../gazetteers/GAZ-049.md)⑫1（「享保七寅年十月止之」）・[GOV-390](../gov/GOV-390.md)等と整合。続けて「**靑山上水は享保七年に龜有、三田、千川の諸上水と共に廢された**」（青山水系節）も同一内容。
- **室鳩巣献議の趣旨の詳細文言〔文言候補・既出説の1942年行政刊行での文言〕**: 「**その鳩巢の獻言の趣旨は今日から見れば誠に不思議なものである。卽ち、水道が發達したことが火事の原因を爲すといふのであつて、地下に水道管が縱橫に通じて地脈を絕つ故に、大地の噫氣である風を拘束する力を失ひ、狂忽な浮ついた風に火が誘はれて大火となり易いといふのである。斯くして水質の惡い下町方面の上水として缺き難い神田、玉川兩上水を殘して、他の上水は廢されてしまつたのである**」＋「**享保七年に靑山、龜有、三田、千川の四上水を一時に廢したことは、文化の進歩に逆行する出來事である**」＝**①水道の発達が火事の原因になる、②地下の水道管が地脈を絶つため大地の噫気である風を拘束する力を失い、狂忽な浮ついた風に火が誘われて大火になりやすい、という室鳩巣の趣旨の説明文言、③区史編者の「文化の進歩に逆行する出来事」という評価**＝[BOOK-161](BOOK-161.md)（1941・武蔵高等学校報国団冊子「地脈が絕たれ…火災の因」）・[PAP-023](../papers/PAP-023.md)（大橋欣治・室鳩巣献策説）・[PAP-027](../papers/PAP-027.md)（地脈分断建議）・[BLOG-113](../blogs/BLOG-113.md)と**同系説の1942年区史（行政刊行物）レベルの文言**で、地脈→風→火災の因果の説明が最も具体的な部類。〔献議の一次史料（鳩巣の建議書）の同定は引続き別課題〕
- **明治13年の千川上水再興の給水区文言〔文言候補・「小石川・神田」の追加が対校上の新規性〕**: 「**明治十三年には、舊靑山上水の水路を利用した麻布水道が開設され、同年また千川上水を再興して本〓、下谷、小石川、神田諸區に給水した**」＝**明治13年（1880）の千川上水の再興（千川水道株式会社の開業＝[BOOK-169](BOOK-169.md)〜[BOOK-171](BOOK-171.md)・明治13年8月）の給水区として本郷・下谷・小石川・神田の諸区を挙げる文言候補**。〔**①[BOOK-174](BOOK-174.md)（1910年代の水道書）の「本〓湯島、下谷、淺草等ニ給水セシモ」・[GOV-226](../gov/GOV-226.md)系の「本〓下谷ノ一部」との対校で、本書は「小石川」「神田」を含む点が特徴的、②小石川＝千川の流路（旧上水路の小石川区間＝戸崎町〜白山側）への給水と読める文言候補で、千川水道株式会社の市内配水の実態（小石川側の配水区域）を示唆する数少ない記録（水道樋の実測＝[GOV-471](../gov/GOV-471.md)の千川線設計・音羽町柳町富坂谷中初音町の実測図リストと対校課題）、③「神田」＝玉川上水（淀橋系）の給水区域（麹町区ほか）と重なる区で、千川水道の神田区側への給水の実態の確認は本書のみではできない（断定しない）、④江戸期の給区（本郷・下谷・浅草）と明治13年の給区（本郷・下谷・小石川・神田）の「浅草→小石川・神田」の入れ替わりの表象が実態（給水先の変更）か区史の認識の混同かは本書からは確定しない**〕
- **麻布水道（青山水路の明治13年再興）の開鑿上請書の文言〔確認・参考〕**: 「**明治十三年には舊靑山上水の水路を利用した麻布水道が開設され…四谷、赤坂、麻布、芝諸區に給水した**」＋開鑿上請書（聖上東台ヘ御臨幸ノ節ノ恩賜金七萬圓云々）の引用＝**同じ明治13年の民間水道の再興の例（麻布水道＝旧行政区単位の給水）として千川水道株式会社と対照する整理に有用**（青山水路＝四谷大木戸分水系、千川＝保谷分水系という2つの玉川系分水の明治13年同時再興の構図）。

## 制限・注意

1. 本書は区史（二次編纂）で、上水通史の叙述は『東京通志』・文政町方書上等の二次利用。文言は原典・原画像照合前提。
2. 明治13年再興の給水区の「本〓、下谷、小石川、神田諸區」文言の典拠（区の調査・水道会社の届出か）は本書では示されず、千川水道株式会社の給水区域の確定は登記・行政文書（[GOV-077](../gov/GOV-077.md)系）の確認課題として残る。断定はしない。
3. 室鳩巣献議説は江戸期の一次史料（建議書）が未同定で、本書の記述も伝聞系（[BOOK-121](BOOK-121.md)の「室新助」との人物同定も含め併記で保留）。
4. 「元禄9年開鑿」説は、repoで既出の対立群（明暦「中興」説＝[BOOK-121](BOOK-121.md)・承応〜寛文系譚など）と並べ、優劣はつけない。
