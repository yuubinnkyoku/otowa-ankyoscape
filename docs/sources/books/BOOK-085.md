# [BOOK-085] 吉野俊『江戸上水史（千川上水の灌漑利用）』（昭和30年）

- **書誌〔確認: 練馬区史歴史編第七部歴史資料編の「練馬区立郷土資料室蔵書目録」〕**: 「江戸上水史（千川上水の灌漑利用） 吉野俊 昭30 吉野俊」の行で掲載〔[GOV-098](../gov/GOV-098.md)〕。**自費刊行とみられる単行書誌でrepo未収録**。

- **所在調査〔未解決〕**: NDL・練馬区立図書館・水道歴史館の所蔵検索は今回未実施（次回課題）。所蔵確認・目次・灌漑利用の定量記述（元治元年村別面積 [GOV-067](../gov/GOV-067.md)・寛政2年100町歩 [GOV-098](../gov/GOV-098.md) との比較）を要する。
