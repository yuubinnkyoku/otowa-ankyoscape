# [BOOK-127] 明治工業史・火兵・鉄鋼篇（1929年）— 滝野川反射炉の着工年代と未完成評価

- **書誌〔確認〕**: 『明治工業史』（**火兵・鉄鋼篇**・**1929年**刊）。NDL次世代デジタルライブラリー [book/1226043](https://lab.ndl.go.jp/dl/book/1226043)（同書の別刷・[book/1835146](https://lab.ndl.go.jp/dl/book/1835146)〔第4〕に同一文言）。第一編第一章「幕末幕府の火兵事業」所収の幕府反射炉記事を今回OCR全文確認した。**引用はすべて同館OCRテキスト由来であり、文言は原文画像との照合を要する。**〔編纂者の正式名称・ publisher の書誌確認は今後課題〕
- **元治元年（1864）滝野川村の反射炉・錐臺建設着工〔確認・repo初出〕**: 「幕府は伊豆江川家の反射爐及び大砲製造所、竝に**關口大砲製造所を合して一大鑄鐵所と大砲製造所を設立せんとし、元治元年（西曆一八六四年）府下瀧野川村地内に反射爐と錐臺との建設工事に著手す**」〔**①韮山（伊豆江川家）系統と関口大砲製造所を統合する一大鋳鉄所計画、②元治元年の滝野川村での反射炉・錐臺建設着工年代**を1929年の工業史集成が記す〕〔[GOV-144](../gov/GOV-144.md)の一次記録列（元治元年12月上知達→慶応元年7月伺→慶応2年10月書付→明治3年管轄移管）の**着工側の年代を集成書レベルで埋める文言**。上知達（1864年12月）と同年内の着工という年代整合をとるかは原本照合まで断定しない〕。
- **天城山産白土の煉瓦と未完成評価〔確認・repo初出〕**: 「該工事は地域の決定を了へ、**反射爐用煉瓦の一部を豆州天城山產白土を以て製造せしも、外圍の出來るのみにして完成を見る能はざりき**」〔**①反射炉用煉瓦の原料が豆州天城山産白土だったこと、②外郭（外圍）のみが出来て完成に至らなかったとする1929年側の評価**〕〔**「慶応2年10月頃完成」説（[BOOK-104](../books/BOOK-104.md)・北区飛鳥山博物館展図録2016・[PAP-079](../papers/PAP-079.md)の論点）に対して、1929年の工業史が「未完成」と評価した側の記録として対照資料になる**。完成説・未完成説の優劣はこの一文では決めない〕。
- **位置づけ〔観察〕**: ①1929年刊行の工業史集成が、関口大砲製造所（[BLOG-227](../blogs/BLOG-227.md)・[BOOK-103](../books/BOOK-103.md)）と韮山反射炉の統合計画として滝野川反射炉を位置づける。②元治元年着工・天城山白土・外郭のみ未完成という着工年代と工程の記述は、[GOV-144](../gov/GOV-144.md)（NDA一次記録列）・[BLOG-226](../blogs/BLOG-226.md)（1864年上申→工事進行の二次整理）と対照できる。③本書は全国的な幕末各藩反射炉の年次対照（佐賀・薩摩・水戸など）も載せており、滝野川反射炉の相対的位置づけ資料になる〔各藩記事の詳細確認は今回未実施〕。
