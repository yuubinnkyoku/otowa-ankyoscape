## repoとの関連〔観察〕

- **志村＝千川上水の下流末端部に接する旧村**: 現在の板橋区志村（板橋台地上）。千川上水の暗渠は板橋区役所〜JR板橋方面（[BLOG-312](../blogs/BLOG-312.md)の渇水区間文言）から石神井川放流（[BLOG-059](../blogs/BLOG-059.md)）へ向かい、志村地区は当該下流部・石神井川（立會川〔[GOV-102](../gov/GOV-102.md)〕）・谷端川系の隣接地帯。村誌に千川上水・依樋・灌漑の記述が含まれる可能性はあるが**本文未閲覧のため一切断定しない**〔所在のみ〕。
- **1916年＝郡制期の村誌**: 『北豊島郡誌』（GAZ-002・1918）に先行する2年。水窪川・弦巻川・谷端川の四河川目録（GAZ-002系）の一次側の対校資料候補〔観察〕。
- **同系統の村誌**: [BOOK-297](BOOK-297.md)（市郡合併紀念中新井村誌・1933＝千川上水組合村の村誌）と並ぶ北豊島郡村内の村誌で、千川上水沿いの村落の自己記録という類型〔観察〕。志村は千川上水の取水組合・分水村とされたかは本文確認後に判断。
