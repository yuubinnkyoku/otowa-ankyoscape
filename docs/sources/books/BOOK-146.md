# [BOOK-146] 東京豊島史（1915）— 池袋・中丸・金井久保村条の仙川用水文言の郡史レベルの継承

- **書誌〔確認〕**: 『**東京豊島史**』（1915年刊・豊島郡の郡史）。NDL次世代デジタルライブラリー [book/1921063](https://lab.ndl.go.jp/dl/book/1921063)。**引用はすべて同館OCRテキスト由来。本書の該当部は活字崩れ・ルビ・振り仮名の混入でOCRが劣化しており、文言は候補として原文画像との照合を要する。**〔[GOV-293](../gov/GOV-293.md)（1938東京市町名沿革史続巻）の池袋村「用水は仙川用水を引注ぐ」に先行する1915年の継承例〕
- **池袋村・中丸村・金井久保村条の引用継承〔文言候補・repo初出の継承記録〕**: 本書の村誌の部（風土記稿の引用と見られる体裁）に——①「**池袋村は、地高くして、（東）北の方のみ水田あり、邊（邊地窪に）して地（形袋の如くなれば村名起りしならん…用水は仙川用水を引沃ぐ**」（池袋村条）、②「**中丸村は、元祿の（改）に枝（村）と傍記す。今は別村となれり…用水は仙川用水を引用ゆ**」（中丸村条）、③「**金井久保村は、日本橋よりの里數、用水等前村に同じ**」（金井久保村条）＝**風土記稿の池袋・中丸・金井久保村条の「仙川用水」文言を1915年の郡史が（引用元明示つきで）そのまま継承・再録した記録**〔**本文書が風土記稿の文言の流通史（幕府編纂→1884活字版→1915郡史→1938町名沿革史〔GOV-293〕）の中間リンクになる**〕〔OCR崩れのため括弧内は推定補充・原画像照合要〕。
- **下板橋宿条の「板橋の名ここに發す」〔文言候補〕**: 同部に「**この驛合の中有を流きゝ石神井川に（家?）ずる小（橋?）極あり、板極（＝板橋?）の名ここに發す。按ずるに此いたばし（の名?）と（は）…義經記に見えたり**」という崩れた文言＝**下板橋宿の項で板橋の地名の発祥を石神井川に架かる橋に求め、【義經記】（治承4年頼頼朝が板橋に着した由）を引く記述**の候補〔OCR崩れ著しく文言候補・原画像照合要。[GAZ-046](../gazetteers/GAZ-046.md)の上板橋村条（【源平盛衰記】【義經記】の板橋文言）と対応する郡史側の記録〕。
- **位置づけ〔観察・内容メモ〕**: ①[GAZ-015](../gazetteers/GAZ-015.md)（池袋村条の二次転記）・[GAZ-046](../gazetteers/GAZ-046.md)/[GAZ-048](../gazetteers/GAZ-048.md)（両版本の本文側確認）・本書（1915郡史の継承）・[GOV-293](../gov/GOV-293.md)（1938町名沿革史）で「仙川用水」文言の転記の系譜が4系統揃った。②本書は豊島郡史系（[GAZ-002](../gazetteers/GAZ-002.md)北豊島郡誌1918の前身的研究に当たる）で、他の豊島郡史料との対照資料。
