# [BOOK-121] 徳川禁令考 巻16（1890年）— 正徳3年神田上水高札の橋地名群と千川用水按語

- **書誌〔確認〕**: 司法省編『徳川禁令考』（**明治23年（1890年）刊行、巻16**＝神田・玉川上水関係の達書・高札を収録する巻）。NDL次世代デジタルライブラリー [book/786982](https://lab.ndl.go.jp/dl/book/786982)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **正徳3年8月の神田上水高札・達書の橋地名群〔確認・repo初出〕**: 「**正德三癸巳年八月 上水道高札**」として、玉川上水側（代々木村〜高井戸間6ヶ所定）に続き、神田上水側の**魚洗い・塵芥投棄禁止の場所**として「**金杉橋際・金剛寺坂下・大六天前・小日向村・服部坂下・音羽町橋際・關口村大洗堰（神田上水道上水道大洗堰）・曾我周防守屋敷前・髙田橋際・下落合村橋際・戸塚村橋際**」を列挙＝**1713年時点の神田上水沿線の橋・堰の地名群**。うち**小日向村・服部坂下・音羽町橋際・関口村大洗堰**は**小日向・音羽・関口（弦巻川下流域と神田上水の並走区間）**にあたり、**弦巻川下流の神田上水沿線の橋・堰の江戸期法令集レベルの一次記録**として、弦巻川下流と神田上水の並走関係の傍証となる。**髙田橋際・下落合村橋際・戸塚村橋際**は神田上水上流沿線（高田・下落合・戸塚）の橋地名記録。
- **按語①「上野堀」呼称〔確認・repo初出〕**: 「**其水源井ノ頭ノ隣地ニ故ノ千川用水ノ廢溝アリ〓上野堀ト云**」＝神田上水の水源（井ノ頭）の隣地の「故の千川用水の廃溝」を「**上野堀**」と呼ぶとする按語＝**「上野堀」の呼称はrepo初出**。〔OCR由来・要原文照合。井ノ頭近隣の廃溝を千川用水とするこの按語は、保谷村分岐・元禄9年開削の系統（[GAZ-002](../gazetteers/GAZ-002.md)『北豊島郡誌』等）とは整合しない**伝承系統の差異**として記録し、いずれの優劣も断定しない。井の頭公園の上野堀（じょうのぼり）との比定は候補として要検討〕
- **按語②享保7年廃止達書の引用〔確認〕**: 「享保七年八月之ヲ廢止スル達書ニ曰 **千川用水之儀中興より掛り候事ニ候故自今相止候間向々江可被相達候**…」と**教令類纂**から引用＝[GOV-170](../gov/GOV-170.md)（享保撰要類集）の御書付と**同文の文言の教令類纂系統による独立確認**。〔文言はOCR要照合〕
- **按語③「中興」＝明暦年間説〔確認・repo初出の学説記録〕**: 享保7年4月の儒官・**室新助**の上申と廃止の経緯を述べ、「**中興トハ明暦年間ヲ謂フ**」＝**千川用水の「中興」を明暦年間（1655-58）とする江戸期の解釈**。〔「室新助」の人物比定（室鳩巣〔[PAP-023](../papers/PAP-023.md)の献策説〕か）は本文表記のみでは確定しない。**元禄9年（1696）開削説（[GAZ-002](../gazetteers/GAZ-002.md)・仙川村太兵衛・徳兵衛）と食い違う年代観として、断定せず差異の記録として扱う**〕
- **按語④神田上水との同時引水説〔確認〕**: 「**此ニ由レハ神田上水モ同時ニ水道ヲ通シ江戸ヘ引クモノトス**」＝千川用水と神田上水の起源を結びつける江戸期の見解。〔OCR要照合〕
- **その他〔確認〕**: 寛延2年（1749）の神田上水沿線修復の割合方（大洗堰より三河町一丁目河岸石垣・木樋等は従来公儀入用→玉川之通御組合普請となる）など、神田上水の修復制度の達書も続く。〔文言はOCR要照合〕
