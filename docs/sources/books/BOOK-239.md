# [BOOK-239] 豊島区「としまひすとりぃ: 平成ひすとりぃ」第2項「少子化対策① 学校教育」〔repo初出・千川上水の桜堤に由来する「さくら小学校」校名の公式選定理由の文言〕

- **書誌〔確認: ADEACとしまひすとりぃ目録詳細頁・2026-11-22取得〕**: 「**としまひすとりぃ: 平成ひすとりぃ**」（**目録ID mp101000**・作成者＝豊島区・公開年令和5年〔2023〕・資料種別＝ウェブコンテンツ・豊島区の区史通史編として章立てで順次公開〔第2節第2項＝「少子化対策① 学校教育」〕・**全文テキストCC BY**）。[目録](https://adeac.jp/toshima-history/catalog/mp101000)・[第2項本文](https://adeac.jp/toshima-history/texthtml/d100010/mp101000/ht0102020)〔確認: texthtml本文取得・2026-11-22〕
- **さくら小学校の校名選定理由＝千川上水の桜堤〔直接確認・repo初出・本資料の目玉〕**: 千川・大成小学校の統合の項で「**新校名の決定にあたっても円滑に協議が進められ、同年10月の第3回協議会で「さくら小学校」に決定された。その選定理由は、両校の所在がかつての千川上水の桜堤の地域にあり、その当時の桜並木のイメージが地域住民に根付いていること、両校とも校庭には桜の樹が多くあり、児童、地域住民に親しまれていること、そして、子どもたちにもわかりやすく、かつ親しみやすくするため、ひらがな名が採用されたものである。**」＋「**こうして平成14（2002）年4月、全校児童361名により、新たに「さくら小学校」としての開校の日を迎えたのである（※24）。**」＝**①千川小学校・大成小学校（豊島区千川・西池袋周辺）の統合新校「さくら小学校」の校名が、両校の所在地域＝かつての千川上水の桜堤であることに由来すると公式に記録されている、②「桜並木のイメージが地域住民に根付いている」という記載、③統合推進協議会（2000年6月設置）の同年10月第3回協議会で決定、④開校＝平成14年（2002）年4月（児童361名）**〔A. **千川上水の桜堤（桜並木）の記憶が、2000年代の校名選定という公式の地域的決定に採用された**＝桜堤の存在が単なる往時の景観記録でなく、現代の地域アイデンティティとして機能した証拠。B. 第251回で保留だった「桜堤に由来する校名（千川・大成統合校）」が「さくら小学校」に特定解決した〔[BLOG-131](../blogs/BLOG-131.md)の千川上水まち歩き記事の「現さくら小学校」記述と対応〕。C. ※24として「千川小学校・大成小学校統合関連資料（H130705文教委員会資料）」＝2001年7月5日文教委員会資料が出典側資料として挙げられており、区議会文教委員会資料レベルの典拠が区史編さんで採用されている〕
- **千川・大成統合までの経緯〔直接確認〕**: 統合計画5番目の実施校・千川小学校児童数の減少（1997年度137名→2000年度77名→2001年度57名、6学年中5学年で10人を割る状態）・大成小学校も2001年度317名に減少・統合校舎は大成小学校の既存校舎改修という経緯の記述。＝**千川上水旧沿いの小学校（千川小）の児童数が1997年度137名から2001年度57名へと激減し、2001〜2002年に統合へ至った過程の記録**〔「千川」の校名が2002年に消滅し「さくら」へ置換された事実＝千川上水由来の地名系校名の近代史上の転換点〕
- **意義〔観察〕**: ①**千川上水の桜堤・桜並木の「記憶の現代的効用」を、区の公式史（区史通史編）が明記した**＝[GOV-341](../gov/GOV-341.md)（東京府史 行政篇第5巻〔1937〕・境水衛所〜小川水衛所間の櫻並木）等の桜堤景観記録や千川上水桜並木の回想記事群に対して、2000年代の校名選定理由という「事実」と呼応する。②「さくら小学校」という現行校名自体が千川上水の桜堤の記念碑として機能している＝まち歩き資材・案内板等の設計にも使える事実。③第2項全体は豊島区の平成期学校統合史（千登世橋中・要小・南池袋小・巣鴨北中・さくら小・朋有小・池袋小・西池袋中・明豊中）の通史記述で、千川・谷端川流域の平成の学校地図の変化を一括して扱える。

## 制限・未解決

- ①校名選定理由の文言そのものは区史編さんの記述であり、**原典（2000年10月第3回統合推進協議会議録・H130705文教委員会資料）は未確認**（区議会資料の本文検索・開示請求で照合可能な表記）。②「桜堤の地域」の地理的範囲（両校のどこからどこまでを指すか）は本文に定義がなく、千川上水の桜堤一般として受け取るのみで特定しない。③平成ひすとりぃは全5章の順次公開のため、今回確認したのは第2節第2項のみで、他章（千川上水関連の記述の有無）の走査は次回課題。
