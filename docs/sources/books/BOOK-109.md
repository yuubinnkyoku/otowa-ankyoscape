# [BOOK-109] 土地概評価 北豊島郡西巣鴨町（1922年・東京興信所）

- **書誌〔確認〕**: 東京興信所『土地概評価 北豊島郡西巣鴨町』（大正11年・1922）・NDL次世代デジタルライブラリー [book/921576](https://lab.ndl.go.jp/dl/book/921576)。字別の地価・土地利用の調査書。**引用はOCR由来・地価数値・字名・橋名は要原文照合。**
- **「乞食橋」〔確認・repo初出〕**: 谷端川の橋名として**乞食橋**が現れる。「大塚終点（停留場）より北へ約一丁・廃兵院の西」に位置する旨の記述〔OCR・位置文言は要照合〕。乞食橋〜鎌倉橋間の谷端川両岸は**工場地・住宅地で空地なし**、鎌倉橋以西（上流側）は**田畑**が残る、という谷端川沿いの土地利用の東西差が1922年時点で記録される。READMEの谷端川橋梁リストに新規の橋名候補（要現在地特定）。
- **谷端川沿いの字〔確認・要照合〕**: ①**境井田**＝耕地整理が行われ中丸との間に新道数条、②**宮の下**＝**西前橋・田楽橋・中丸橋**の橋名〔OCR判読・要照合〕、③**字三家**＝滝野川町字南谷端・北谷端と対峙（町境）〔＝谷端川が両町の境を流れることの字名レベルの傍証〕、④**千川上水＝庚申塚の北で町境**を流れる、⑤高田町水久保に隣接する窪地〔谷端川上流の谷頭に連なる低地の記述候補〕。西前橋は[GOV-159](../gov/GOV-159.md)（1930年・改修区間上流端「西巣鴨町大字池袋の西前橋下流約百米」）・[BLOG-233](../blogs/BLOG-233.md)に接続する橋名の1922年時点の登場。
- **巣鴨町・板橋町の同シリーズ巻〔所在のみ〕**: 同シリーズに**巣鴨町（[book/921577](https://lab.ndl.go.jp/dl/book/921577)）・板橋町（[book/921578](https://lab.ndl.go.jp/dl/book/921578)）**の各巻が次世代デジタルライブラリーに所在〔未精読・次回課題〕。
- **位置づけ〔観察〕**: 1922年＝谷端川改修（1930年決定）の8年前の両岸土地利用・地価の民間調査断面。①乞食橋の発見（橋梁リストの充実）、②「乞食橋〜鎌倉橋間は市街化・以西は田畑」という**改修区間と市街化の範囲がほぼ一致**することの1922年側の傍証、③耕地整理による新道（境井田）の記録、の3点が記録価値。地価の絶対値はOCR判読の信頼性が低いため本項では引用しない。
