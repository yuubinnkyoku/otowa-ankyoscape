# [BOOK-198] 愚得襍載巻2 — 善福の池の井頭上水助水と青石の釘譚（1）〔第167回〕

- **書誌〔確認〕**: 喜多村節信『愚得襍載』巻2（写・NDL次世代デジタルライブラリー [book/2533343](https://lab.ndl.go.jp/dl/book/2533343)）。江戸後期の考証随筆（喜多村節信は『筠庭雑録』の喜多村信節〔筠庭〕の別称・同一人物の別署かは書誌確認要）。**引用文言はOCR崩れが大きく原画像照合必須。**
- **善福の池の井頭上水助水文言〔確認・文言候補・repo初出〕**: 「**井頭上水ノ助江戸井上ノ井キノ方小園井辺善福ノ池ト云アリ外罰之筋水トナルト云此ニ青石ニ釘アルアリ**」＝**井頭上水の助けとして江戸の井上（井の頭）の井の方の小園井（遅野井／井頭村）辺りに善福の池があり、「外罰之筋水」（悪水の筋水〔崩れ候補〕）となるとの趣旨＋その地に青石に釘のあるものがある**〔**①善福寺池が井頭（神田）上水の助水の筋となる旨の江戸期随筆記録（[BOOK-199](BOOK-199.md)（筠庭雑録）に同型文言の明瞭版があり2系統で裏付け）、②[GOV-377](../gov/GOV-377.md)（1877年東京水道改設之概略・井の頭池＋善福寺池＋妙正寺池の多水源合流説）に先行する江戸期の善福寺池＝助水認識の随筆側層、③善福寺の青石の釘譚（吉野吉水院の釘石・古野山蔵王権現の片身鯉等の諸国の奇勝の対比列の中に置かれる）は善福寺の石の伝承の江戸期記録候補**（「外罰之筋水」の読み〔「悪水之筋水」等の崩れ〕は原照合要）〕。
- **同巻の対比記事〔参考〕**: 古野山蔵王権現の片身鯉（半面魚）・吉野吉水院の青黒き石に大釘を打てる釘石（旅人皆これを磨る）等の考証が同居＝善福寺の釘石が天下の奇勝の考証列に並べられている。
