# [BOOK-030] 永井荷風『葛飾土産』（1947年）

- 永井荷風『葛飾土産』（昭和22年、岩波文庫『荷風随筆集（上）』所収）。青空文庫本文で直接確認。
- [葛飾土産（青空文庫）](https://www.aozora.gr.jp/cards/001341/files/49636_39417.html)
- 内容メモ（小石川区内の溝川リストの一節。原文の仮名遣いは青空文庫表示による）：「小石川区内では○植物園門前の小石川○柳町指ヶ谷町辺の溝○竹島町(たけしまちょう)の人参川○音羽久世山崖下の細流○音羽町西側雑司ヶ谷より関口台町下を流れし弦巻川」。
- **本書の「竹島町の人参川」と『日和下駄』の「金剛寺坂下の人参川」が同じ水路の区間か、別の場所かは本書だけでは決まらない。** また、同じリスト内で弦巻川が別項目として挙げられており、荷風は人参川と弦巻川を区別している。
- 竹島町（たけしまちょう）の所在地・旧町名としての実在は未確認。青空文庫本文には「竹島町(たけしまちょう)」と振り仮名があるため、武島町への読み替えは行わない。
