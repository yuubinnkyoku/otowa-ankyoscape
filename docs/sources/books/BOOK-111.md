# [BOOK-111] 土地概評価 小石川区（1922年・東京興信所）

- **書誌〔確認〕**: 東京興信所『土地概評価 小石川区』（大正11年・1922）・NDL次世代デジタルライブラリー [book/908566](https://lab.ndl.go.jp/dl/book/908566)。**引用はOCR由来・要原文照合。**
- **丸山町「千川（谷端川）岸」〔確認・repo初出の文言〕**: 小石川区丸山町（現・文京区千石〜白山方面）の土地記述に**「千川（谷端川）岸」**の文言〔OCR・要照合〕。谷端川の下流部（小石川区内）が**千川**の名で呼ばれていたことの、1922年の民間土地調査書レベルの傍証。
- **位置づけ〔観察〕**: [GOV-023](../gov/GOV-023.md)（千川の下流呼称）・[GOV-163](../gov/GOV-163.md)（1924年・「谷端川ノ下流ハ千川ニシテ」）・[GOV-164](../gov/GOV-164.md)（1914年・小石川＝谷端川の末）と併せ、**「谷端川→千川」の呼称の切り替わりが小石川区（巣鴨町との境＝山手線付近）から下流で行われていた**というREADMEの仮説を、公文書（1914・1924）と民間調査書（1922）の両側から補強する。谷端川名義区間の末端（大塚駅〜山手線下）と千川名義区間の起点の位置特定に使える比較資料。
