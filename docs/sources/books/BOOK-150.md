# [BOOK-150] 閑日月（1908）— 落合の舊神田上水沿いの水田景観の観察

- **書誌〔確認〕: 『**閑日月**』（1908年刊の随筆・紀行文集）。NDL次世代デジタルライブラリー [book/888987](https://lab.ndl.go.jp/dl/book/888987)。引用はすべて同館OCRテキスト由来。文言は原文画像との照合を要する。
- **舊神田上水の水田景観の観察文言〔観察・repo初出の風景記録〕**: 「**舊神田上水をわたりて、田間を步す。一面の凹地。稻生ひ出でゝ、湖の如し。曇りたる空、ばつ〓〓雨をもらして、天も泣くに似たり。**」＝**1908年時点で落合付近の舊神田上水（神田川）を渡って一面の凹地に水田が広がる光景**（稲が湖のように見える）という観察記録〔舊神田上水という呼称の1908年の随筆用例＋**神田川低地（落合〜下落合の凹地）の水田の実況観察**。土地利用史（水田→宅地化）の1900年代の定点観察として使える文言〕。
- **泰雲寺（了然尼遺跡）の記述〔観察〕**: 同文に「**つい近頃までも廢れながらに、寺門はあり、否、新に出來て、本堂はなきも、庫裡は存したりし泰雲寺、札をはりて、本堂建築の寄附金を募り居りしに、思ふやうに集まらざりけむ、今は、全く跡方もなくなりたる也。當年絕世の美人、了然尼が、自から面皮を燎いて道を修めし遺跡、惜しや荒蕪に歸して、落合村の名物は失せぬ。**」＝**落合村の泰雲寺（了然尼の遺跡）が1908年時点で全く跡形もなくなっていた**という観察〔落合の寺院（泰雲寺）の消長の観察記録。現・中井町側（泰雲寺は現在も中野区本町側に同名寺がある）との対応は本随筆のみでは確定しない〕。
- **位置づけ〔観察・内容メモ〕**: ①「舊神田上水」という呼称の随筆用例（1908年＝上水廃止（明治30年代）後まもない時期の呼称の実態）。②水田景観の観察は、[GOV-304](../gov/GOV-304.md)（1936年・不良住宅地区の谷田川水害文言）や明治末〜大正の宅地化の進行と対校できる**宅地化前夜の神田川低地の土地利用の定点観察**。③本書は随筆で、特定の橋・水路施設の記述は今回確認できず、風景観察の資料として登録する。

## 制限・未解決
