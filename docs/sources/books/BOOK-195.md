# [BOOK-195] 中野町勢要覧（1926）— 淀橋由来・小淀山成趣園・姿不見橋転訛説・四所橋・餘戶橋・位置地勢〔第167回〕

- **書誌〔確認〕**: 中野町編『中野町勢要覧』（中野町・1926〔大正15〕・NDL次世代デジタルライブラリー [book/917648](https://lab.ndl.go.jp/dl/book/917648)）。中野町の行政・史跡・名勝の要覧。**本書のOCRは二段組の走査線崩れが激しく、引用文言は順序混在・文字欠落のある候補であり、原画像照合が必須。**
- **淀橋由来と中野長者〔確認・文言候補・repo初出の由来文言群〕**: ①「**八代將軍吉宗公此地ニ放鷹ノ際其景致山城ノ淀ニ似タルヲ以テ殊ニ淀橋ト唱フベシト台命**」＝**八代将軍吉宗の放鷹の際に地形が山城（淀）の淀に似ているとして「淀橋」と唱えるべしとの台命**という淀橋由来説〔[BOOK-148](BOOK-148.md)（中野町誌・1933）の『江戸砂子』系「寛永の頃御鷹野の節」説・春日局柏木村邸説、[BOOK-194](BOOK-194.md)の寛永期榊原河内守伝承に加わる吉宗放鷹説（江戸砂子系の御鷹野説とは将軍・年代が異なる系統候補）〕。②「**應永年間中野長者ノ娘事情アリテ川ノ上流ニ投身セリ家人之レヲ捜索シテ此橋ニ至ル**」＝応永年間の中野長者の娘の投身・捜索がこの橋（淀橋）に至る旨〔姿見ず橋・面影橋の由来譚の娘投身系と橋の帰属が食い違う構造は原画像で精査要〕。③「**中野長者俗稱鈴木九郞法號ヲ正蓮ト稱ス應永年間紀州ヨリ來リ住ム**」＝中野長者＝俗称鈴木九郎・法号正蓮・応永年間に紀州から来住（[BOOK-194](BOOK-194.md)の朝日長者昌蓮系との人名対校案件）。
- **小淀山・成趣園〔確認・文言候補・第166回課題の補強〕**: 「**密ニ古ヨリ小淀山又ハ天狗山ノ名アリ明治十九年伏見宮家御所有トナレリ**」＋「**一萬一千七百五十坪ノ地積ニシテ維新ノ際山岡鐵舟ノ有ニ歸シ爾來成趣園ト號ス高臺ニシテ樹林…**」＝**成趣園の小淀山＝天狗山の古名・明治19年の伏見宮家所有・11,750坪・山岡鉄舟から成趣園**〔[BOOK-148](BOOK-148.md)の成趣園条（字小淀・中野坂下北側・11,757坪余・伏見宮別邸）と1926年時点で同一内容（坪数は本書では「一萬一千七百五十坪」・数字は原照合要）。[GOV-398](../gov/GOV-398.md)・[GOV-401](../gov/GOV-401.md)の「中野村小淀山御立場」との中野村内小字としての小淀山の系列〕。
- **姿不見橋の三重塔転訛説と洲潟水〔確認・文言候補・repo初出〕**: 「**三重塔ハ寛◯ノ頃ニカ轉訛シテ姿不見ト稱スルニ至レリトモ言フ**」＋「**（娘カ）…其姿ヲ見ズ依テ自ラ橋ノ名ヲナセリトモ言傳フ**」＋「**又此邊洲潟ヲ生ズルニヨリ洲潟水ト稱セル**」＝**①三重塔（付近の寺〔宝仙寺候補・原文の帰属はOCR上不明〕の三重塔）が寛○の頃に転訛して「姿不見」の称となった説、②娘の姿を見ずの橋名由来説、③この辺りに洲潟を生じたことから「洲潟水」と称したとの口碑**〔[BOOK-148](BOOK-148.md)の姿見ず橋条（洲潟→洲湯水→姿見ず転訛口碑）の1926年側の先行的文言候補。「洲潟水」の表記と三重塔転訛説は本書で初出の系統候補〕。
- **四所橋・餘戶橋〔確認・文言候補・橋名ともrepo初出〕**: 「**此地柏木中野角筈本◯ノ四村ノ境地ナルヲ以テ斯ク名付ケタリ**」＝**柏木・中野・角筈・本◯（本郷・本村等の崩れ要照合）の四村の境地であることから四所橋と名付けた説**。＋「**橋ヲ餘戶橋ト言ヘリ**」＋「**古此橋豐島多摩兩郡ノ境堺ヲ劃シ附近ニ兩郡ノ餘戶ヲ移セシメシニヨリ此村落ヲ餘戶ト…**」＝**豊島・多摩両郡の境堺を画し、両郡の余戸を移したことによる餘戶橋・餘戸村の名の由来説**〔四所橋・餘戶橋ともrepoに未収録の橋名（[BOOK-148](BOOK-148.md)・[BOOK-191](BOOK-191.md)等の橋梁群にない）。位置は神田上水・神田川筋の四村境地・豊島多摩郡境から推定できるが原画像での配置確認要〕。
- **位置地勢〔確認・文言候補〕**: 「**本町ハ宮城ノ西ニ位シ豐多摩郡ノ中央部ヲ占メ東ハ神田上水ヲ隔テヽ淀橋町ト相對シ…靑梅街道ヲ挾ンデ神田上水南部ノ北端ヲ善福寺支流北部ノ南端ヲ各東西ニ貫流ス**」＝**青梅街道を挟んで神田上水（南側）の北端と善福寺支流（北部）の南端を東西に貫流する**という1926年の中野町の位置記述〔神田上水と善福寺川（善福寺支流）の並行構造の行政資料側の表現〕。
