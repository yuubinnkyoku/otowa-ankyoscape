- **目次〔確認: NDLデジタルコレクション提供の目次データ（NDL書誌ページ経由で全文取得・2026-11-14）〕**: 第四編「明治前期の豊島」第四章「園芸農業の展開」（pp.83-）は第一節 染井・巣鴨の植木（p.83）・第二節 農業生産（p.105）・**第三節 千川上水と水車業（p.128）**・第四節 竹本焼（p.134）の構成。ほかに第一節 土地の利用と所有（p.56）・第二節 都市化の開始（p.231）等。
- **意義〔観察〕**: ①**「千川上水と水車業」を章節単位で立てた区史**で、[BLOG-094](../blogs/BLOG-094.md)（板橋区史通史編上経由の水車史・明治17年路図の8水車）・[GOV-076](../gov/GOV-076.md)（武蔵学園アルバム）・[BOOK-092](BOOK-092.md)（板橋区の歴史）と並ぶ、**水車業史の公的区史レベルの記述の所在を固定**した〔本文未見のため記述内容は断定しない〕。②明治前期の豊島（巣鴨・池袋・雑司が谷・高田等の前身町村）を扱う通史編で、**染井・巣鴨の植木（谷端川流域の園芸農業）と千川上水の水利を併せ論じる構成**は、谷端川上流域の土地利用と千川上水の関係を区史の文脈で確認する一次の二次資料になる〔観察: 目次構成から〕。③1983年という時点で千川上水の灌漑利用史が区史でどう総括されたかの研究史座標になる（[PAP-049](../papers/PAP-049.md) 1955年西郊文化・BOOK-060 2006大石学監修の中間に位置する）。
