  1. **「小石川の水道修成傭夫」系**: ①『近世風俗見聞集』（国書刊行会・大正元〜2年刊の複製・[book/1749410](https://lab.ndl.go.jp/dl/book/1749410)）: 「芭蕉翁俗名を松尾忠左衞門と云、伊賀上野藤堂家之近臣なり…寬文末つかた東武に下り、**小石川の水道修成傭夫**となつて、功を終るの頃薙髮して風羅坊と云、深川に庵を結ぶ」。②『元祿寶永珍話』の芭蕉傳（『問題の点を主としたる芭蕉の伝記の研究』〔[book/1258151](https://lab.ndl.go.jp/dl/book/1258151)・1938〕の引用で知る）: 「寛文末つかた東武に下り、**小石川の水道修成傭夫**となつて、功を終るの頃薙髮して風羅坊と云」。
  2. **「礫川/碑川」系**: ①『古画備考』50巻の[14]（写本・[book/2591600](https://lab.ndl.go.jp/dl/book/2591600)）の芭蕉条: 「松尾桃青…寛文未年来于江都**為礫川上水道修成傭夫**終功薙髪号風羅次郎庵于深川板…」（坦筆記引用とされる・OCR崩壊甚大）。②『達人志操 : 一名・皇朝新語』（小川尚栄堂・[book/757693](https://lab.ndl.go.jp/dl/book/757693)）: 「松尾芭蕉、寛文の頃、東武にあり、**礫川の水道修成の事に預り**、其功なりて後、薙髮して風羅坊といふ、深川に庵を結び…」。③『鶯宿雑記』（写・[book/10301270](https://lab.ndl.go.jp/dl/book/10301270)〔巻113-114冊〕）: 「冷叟に遊学する事七年寛文の末つかた東武に下り**碑川の水道修成傭夫**」（「碑川」＝礫川のOCR変種候補）。
  3. **「小石川水樋」系**: 『芭蕉翁略伝と芭蕉連句評釈』（[book/1018324](https://lab.ndl.go.jp/dl/book/1018324)）: 「九月始て東武に下ル。**小石川水樋に功を殘す**」。
- **repo内の既存系統との対校〔観察〕**: ①[BOOK-157](BOOK-157.md)（大東京小盛り年表・神田上水再修奉行説〔松尾忠左衛門〕＋「俳家奇人談には、芭蕉翁此地を愛して…旧趾をとゞむる…**龍隱庵此事世上に傳ふる**」）・第134回の[BOOK](../books/BOOK-147.md)系武江年表も**俳家奇人談を引用する形**で芭蕉＝神田上水再修奉行説を記していたが、**俳家奇人談そのものの本文・変種群の所在はrepo未収録だった**（本登録が初出）。②[BOOK-203](BOOK-203.md)（十方庵遊歴雑記三編）の龍隠菴文言（**松尾甚七郎＝芭蕉・藤堂家の上水御手伝御用の司役・千川上水寛文末開削・さみだれ塚**）と対校すると、**芭蕉＝水道工事関与伝承が江戸後期に少なくとも2系統（音羽龍隠菴系＝千川上水〔堀割〕と、俳家奇人談系＝礫川/小石川の水道〔修成〕）で流通しており、時期規定はいずれも「寛文の末」で一致する**。③工事の名指しの対立軸「**礫川・小石川（神田上水系の谷地形の水道）**」vs「**千川上水の堀割・神田上水の白堀（十方庵・BOOK-157系）**」と、役割の対立軸「**傭夫（日雇人夫）**」vs「**普請方・奉行・司役（松村市兵衛・松尾甚七郎・忠左衛門）**」は、この伝説の後裔の近代研究（[BOOK-205](BOOK-205.md)）でも整理された構図〔repoでは伝承記録として保持し、史実性の判断はしない〕。
