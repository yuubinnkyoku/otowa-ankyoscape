# [BOOK-039] 田村隆一『ぼくのピクニック 1981・7‐1988・3』（1988年）

- 田村隆一『ぼくのピクニック 1981・7‐1988・3』、朝日新聞社、1988年。
- [初出を比較した文献調査](https://fujimizaka.wordpress.com/2020/08/27/asami-saka/)は、所収の「夜の帽子」「武州大塚のエピソード」などに「谷端川」が登場すると指摘する。
- 初出は「夜の帽子」『年金と住宅』21号（1981年12月25日）、「武州大塚のエピソード」同23号（1982年5月31日）でルビなし。同25号（1982年9月20日）「田園交響楽」では「たにはがわ」、1988年『青春と読書』「あとはなんにもない」では「たにばがわ」等、初出を照合した先行調査により異同が報告されている。
- 1987年に巣鴨小学校で本来の読み「やばたがわ」を教えられたとの記述もある。
- **本書本体、雑誌初出の原本は今回未閲覧**。読みの異同と初出書誌は二次研究に基づく。資料批判の詳細は [BLOG-014](../blogs/BLOG-014.md)。
