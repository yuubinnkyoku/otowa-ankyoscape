# [BOOK-050] 『明治東京名所図会 : 幻の画人山本松谷』

- **書誌〔確認：NDLサーチ〕**：山本駿次朗著、**三樹書房、1979年5月刊**、298頁、16×23cm、請求記号 **KC229-126**、書誌ID **000001416213**、NDLJP **14313033**。[書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000001416213)／[デジタル版](https://dl.ndl.go.jp/pid/14313033)（館内限定）。
- **照合候補〔二次紹介・未確認〕**：2022年11月27日の[旅行記](https://4travel.jp/travelogue/11794487)は、山本松谷の「**音羽町紙抄場**」という図を『明治東京名所図会』由来と説明する。ただし、**この1979年刊画集にその図が収録されるかは未確認**。明治期の『新撰東京名所図会』（[BOOK-024](BOOK-024.md)）と同一書誌として扱わない。
- **未確認**：図の初出、制作年、原掲載号・頁、工房の所在地、絵の細部。1979年は画集の刊年であって絵の制作年ではない。
- **追加照合候補（2026-11-10）**：文京区教育委員会『文京のあゆみ : その歴史と文化』p.24に「音羽の紙すき場（明治39年頃）」の**絵**が掲載されていると利用者が現物確認。[BOOK-057](BOOK-057.md)。本書で言及される山本松谷「音羽町紙抄場」と同じ図かは**未確認**（作者・題名・図版の比較が必要）。
