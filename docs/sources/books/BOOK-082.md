# [BOOK-082] 『練馬の水系』（祖先の足跡4）

- **書誌〔確認: 東京都水道歴史館デジタルアーカイブ ro-da 書誌頁（2026-11-13 直接取得）〕**: **『練馬の水系』（祖先の足跡 4）**、石神井図書館郷土資料室 編、練馬区教育委員会、**昭和51年（1976）3月**、145p・22cm。水道歴史館の所蔵は**開架書架B・館外貸出不可**。
- **repoへの意義**: 練馬区の水系（千川上水・石神井川・分水）を扱った**昭和51年刊行の基礎文献**であり、repoの練馬区側資料群（『みどりと水の練馬』BOOK-063・『練馬区史』BOOK-065・練馬区教委諸資料）の系譜で**1970年代の中間点を埋す書誌**。千川上水の暗渠化が進行した時期（区内昭和25年頃着手説 GOV-072・昭和27年3月着手 BLOG-113・1952年頃撮影で旭丘「暗渠化直後」GOV-092）の直後に区がまとめた水系記録という時間的位置づけをもつ〔内容の断定は本文確認後にする〕。
- **関連**: キーワード付与は「水道／水道史／江戸上水／玉川上水／分水／千川上水／練馬区／川」〔ro-da書誌〕。祖先の足跡シリーズの他巻の所在も要確認。
