# [BOOK-138] 武蔵野歴史地理 第3冊（1930）— 千川用水の沿革概説と千川家系譜の1930年記録

- **書誌〔確認〕**: 高橋源一郎編『武蔵野歴史地理』**第3冊**（昭和5年・1930年・武蔵野歴史地理学会）。NDL次世代デジタルライブラリー [book/1178661](https://lab.ndl.go.jp/dl/book/1178661)。**第1冊は[BOOK-122](BOOK-122.md)として登録済み・第2冊（[book/1178647](https://lab.ndl.go.jp/dl/book/1178647)）は千川・谷端・弦巻・水窪の直接記述なし（見送り）**。引用文言はすべてOCR由来で要原文照合。
- **千川用水の沿革概説〔確認・年代の確認と対校〕**: 千川用水の項（p.343付近）——「**千川用水は保谷村にて玉川上水と分かれ 北豊島郡石神井、中新井、長崎、板橋等を貫き、巢鴨庚申塚より本郷、下谷、淺草邊まで掛つたものである。これは元祿九年 湯島聖堂、東叡山、小石川御殿、淺草寺御殿に水を引く目的で、道奉行毛利兵橘（?）佐橋內藏之助（?）・伊勢平八郞、武島治郞左衞門等の掛りで 德兵衞、太兵衞二人に工を請負はせた**」＝**①保谷村での分水、②貫く村々（石神井・中新井・長崎・板橋）、③巣鴨庚申塚から本郷・下谷・浅草方面、④元禄9年起立・道奉行（伊勢平八郎ら）掛かり・徳兵衛・太兵衛請負**の1930年概説。〔道奉行の人名列（毛利・佐橋内蔵之助等）はOCR崩れが大きく要照合。〕
- **千川氏の賜姓と邸宅〔確認〕**: 「**竣成の後 兩人に千川の氏を賜ひ、又小石川白山前町に於て邸宅を賜つた。以來此子孫のものが、上水役を勤め見廻り修理等をして居つた**」＝**千川の姓の下賜と小石川白山前町の邸宅下賜・子孫の上水役**の概説＝[GOV-210](../gov/GOV-210.md)〜[GOV-212](../gov/GOV-212.md)（千川屋敷の請負系譜）・[GAZ-048](../gazetteers/GAZ-048.md)（風土記稿）の並行記録としての対校資料。
- **宝永4年20か村・米3升／反と廃置の年代列〔確認・対校用〕**: 「**この用水掘鑿後十年を經て 寶永四年に至り、最寄二十箇村の百姓より此水道の水を田畑の用水に少しづゝ引かせて貰ひたいと願ひ出て、道奉行の許可を得、其代償として千川兩氏に田一反に付米三升づゝを納めた。享保七年に至り、江戶市內の引水は中止したが、明和六年再興を願出づるものあり、安永八年に至り漸く許可せられ、樋の掛渡も出來た。しかし天明六年に再び廃止、明治十三年三たび興復した。續いて駒込岩崎邸の私有となり、今は全く市中には引用しない**」＝**①宝永4年（1707）に最寄20か村の用水許可・代償は田1反につき米3升、②享保7年（1722）市中引水中止、③明和6年（1769）再興願→安永8年（1779）許可・樋の掛渡、④天明6年（1786）再廃止、⑤明治13年（1880）三たび興復→駒込岩崎邸の私有→市中には引用しない**という年代列の1930年まとめ。〔①宝永4年20か村・米3升＝[GOV-098](../gov/GOV-098.md)（千川文書写・練馬区史）と整合。③「安永八年許可」は[GOV-169](../gov/GOV-169.md)系の「安永9年（1780）10月27日掛渡開始」・[GOV-215](../gov/GOV-215.md)〜[GOV-218](../gov/GOV-218.md)（安永9年開始の町方書上群）と1年の対立（許可年と着手年か。断定せず併記）。⑤明治13年＝千川水道会社設立（[GOV-077](../gov/GOV-077.md)・岩崎弥太郎）と整合する年。⑥岩崎邸私有・市中引用なし＝[BOOK-122](BOOK-122.md)（第1冊の岩崎氏巣鴨別邸・王子落とし）と対校。〕
- **千川家系譜の1930年記録〔確認・repo初出の系譜細部〕**: 「**通俗には兩人は多摩郡仙川村の百姓であつたといへど、それは間違であらう。德兵衞の家の系圖には 初代玄海は播州姬路產で、二代久右衞門は江戶本〓（欠字）追分に住居、三代德兵衛は其未亡人に入夫したとある。太兵衞の家の系圖も甚だ不明である。明和五年 太兵衛の孫幸治郞が幕府に差出した由緒書にも 多摩郡仙川の百姓であつたといふことは少しも書いてない。蓋し兩人は江戶の商人であらう**」＝**①千川家系図の内容（初代玄海＝播州姫路産・二代久右衛門＝江戸本○追分に住居・三代徳兵衛＝未亡人への入夫）、②明和5年（1768）に太兵衛の孫・幸治郎が幕府に差し出した由緒書に仙川百姓説が書かれていないこと、③「両人は江戸の商人であらう」という推定**＝千川家出自の仙川村説（[GAZ-048](../gazetteers/GAZ-048.md)・[GAZ-049](../gazetteers/GAZ-049.md)・[BOOK-065](BOOK-065.md)）への1930年時点の批評的検討。〔播州姫路産の玄海＝[GOV-090](../gov/GOV-090.md)（渡邉学芸員の「播磨屋は姫路出身と名乗っていた」）・「入夫」＝[GOV-077](../gov/GOV-077.md)（一説に常陸出身・千川家に入夫）と部分的に対応しつつ、系図の代構造（玄海→久右衛門→徳兵衛）の細部はrepo初出。「本〓追分」の欠字（本所追分か）は要照合。「明和5年幸治郎由緒書」の実物は未確認。〕
- **谷端（三鷹・新川）の記述〔観察・本対象外の確認〕**: 同冊の「谷端」の語は三鷹村（仙川）の小字谷端（新川丸池＝千釜池周辺）の記述のみで、北豊島の谷端川とは無関係（本対象外として見送り・誤同定に注意）。

- **残堀川（蛇堀川）の条〔確認・repo初出・2026-11-16第125回追記〕**: 第六篇村山地方（p.647付近）に残堀川の詳述がある——「**殘堀川三ツ木の南野中を流れる野水に殘堀川又は蛇堀川といふがある。是は狹山の西麓にある箱の池といふ小池より流れ出るもので、今の砂川村東方より國分寺村中藤新田、平兵衛新田を經、國分寺西方の崖下を通つて居つた。平素は水は少しも無い位であれど、夏秋の候には洪[水]…**」「**承應年中玉川上水を開通した際箱の池を浚へ、此水を助水として玉川上水に引入れて居つたが、今は全く此水をば用ひないことになり砂川村一番の裏手にて暗渠を以て上水の下を通じ、立川村方面に導いて居る**」＝**①残堀川＝蛇堀川の別称②源流＝「狹山の西麓にある箱の池」（＝狹山池の別称候補・repo初出）③経路＝砂川村東方→国分寺村中藤新田・平兵衛新田→国分寺西方崖下④承応年中（玉川上水開通時）に箱の池を浚渫して助水化⑤1930年時点では砂川村一番の裏手で暗渠（伏せ越し）で上水の下を通り立川村方面へ導く**＝[GOV-283](../gov/GOV-283.md)（狹山池助水堀通見廻役）・[GOV-290](../gov/GOV-290.md)（1905年の狹山助水の記述）と対校できる残堀川の1930年の詳述。
  - 同条には**元和3年（1617）秋の洪水伝説**（「**元和三年秋洪水して府中まで押行き、高安寺境內の觀音堂を流亡したといふ、大げさな言傳へすら殘つて居る程である**」＝残堀川の大雨時の涨溢が府中まで及んだという伝承）・**小字残堀の部落**（「**小字殘堀といふ部落は此川の岸に倚り靑梅街道に沿うて居る**」）・**「蛇堀」の語源説**（「**發といふは土地の崩壊せるところを稱する語である。この蛇堀川にもかかる地形があるから、この名を得たのであらう。東京近郊目黑附近の蛇崩川といふも同語である**」＝目黒の蛇崩川と同語源とする説）・**「惡水堀」「砂川」の別称**（「**狹山の西邊より流れ出づる惡水堀に、砂川、一名殘堀川といふがあり…小字田堀辯天より南國分寺村に及んで居る**」＝残堀川を「惡水堀」「砂川」とも呼ぶ記録。「砂川」が村名（砂川村）由来か流路を下る川名かは本条では整理されず断定しない）も含まれる＝**残堀川の別称群（蛇堀川・惡水堀・砂川）・語源説・洪水伝説・小字の集成的な記録（いずれもOCR由来で要原文照合）**。 → [地名・河川名対照表](../../地名・河川名対照表.md)の狹山池・残堀川関連の行の根拠に反映。
