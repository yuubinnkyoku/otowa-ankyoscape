# [BOOK-182] 小品十種（1908・幸田露伴著）— 七碗歌（露伴の小品・咄）の名水列挙に「音羽の弦卷川」＝弦巻川の名水の1908年文芸用例〔第147回・第148回解釈訂正〕

- **書誌〔確認〕**: 『小品十種』（**成功雑誌社・1908年**。表紙OCR「**小品十種 幸田露伴著**」で作者を確認。請求記号26-460・書誌ID000000513532。NDL次世代デジタルライブラリー [book/889104](https://lab.ndl.go.jp/dl/book/889104)）。幸田露伴の小品（短篇随筆・咄）を10篇＋附錄（「七碗歌」「笑話」「賭け碁」等）で収めた叢書で、附錄に茶道に凝る老翁の咄「七碗歌」を収録する。**同一内容の別刊**: [book/886753](https://lab.ndl.go.jp/dl/book/886753)（別刊・同内容として併記し独立登録しない）。
- **「音羽の弦卷川」＝名水列挙の文言〔確認・文言候補・repo初出候補・第148回解釈訂正〕**: 附錄「七碗歌」——「**小日向の黄金水を汲んで來い…澁谷の八幡の井の水を取つて來い…馬喰町の三日月井、（吹）出町の雁金の井、**音羽の弦卷川**、隅田に流れ込む**綾瀨川**なんどの水を汲めのと云はれました 其の初は異なことゝ思ひました**」（OCR崩れあり・要照合）＝**老茶人が名水の汲み取りを命じる場面の水名群に「音羽の弦卷川」が含まれる1908年活字収録例**。〔**第147回はこれを「江戸の名水を列挙する茶道口伝歌の水名群」と解したが、第148回に本篇の全体構造を確認した結果、**露伴の小品（咄）内の趣向であり、独立の「口伝歌」の実在を裏付ける文言ではない**（下の第148回追記参照）。「弦巻川を名水として列挙する用例＝弦巻川の名水評価の文芸側の記録」としてのrepo初出候補の価値は残る**（名水品評録〔[GAZ-066](../gazetteers/GAZ-066.md)名水品彙の張巻川条・分度40度秤量43〕の系統と対校できる）。列挙水の比定（小日向の黄金水・澁谷の八幡の井・馬喰町の三日月井・雁金の井）は既存の名水記録と対照する。〕
- **〔2026-11-17・第148回追記〕「七碗歌」の実体＝露伴の小品（咄）であって「口伝歌」ではない〔確認・第147回解釈の訂正〕**: 表紙OCR「小品十種 幸田露伴著」で作者確認。附錄「七碗歌」は、**茶道に凝る老翁を、その妾と密夫が語り合う咄（滑稽小品）**で、**盧仝「七碗茶歌」の句（「一碗喉吻潤フ」「二碗孤悶ヲ破ル」「三碗枯膓ヲ捜ル 惟有文字五千卷」「四碗輕汗ヲ發ス」「五碗肌膚〓ス」「六碗仙靈ニ通ズ」「七碗喫シ得ズ 唯兩腋習習トシテ清風ヲ生ズ」）を各段の見出しに用いた構成**であることをfulltextで確認した。名水列挙（黄金水・八幡の井・三日月井・雁金の井・音羽の弦卷川・綾瀨川）は**老翁が妾・密夫に「水を汲んで來い」と命じる場面の文言**（密夫の語り「何處の國に自己が妾に煽動てられて水を汲みに行く大〓があるだらう」）であり、水の秤量比較（四十二匁等）も同じ咄内の老翁の水の講釈の文言。〔**第147回の「江戸の名水を列挙する茶道口伝歌」「江戸期の口伝歌が明治41年時点で活字収録されていた用例」とする解釈は取り下げ、本篇は明治期の文芸作品内の名水列挙（当時流布の名水知識を反映した文学的趣向）と位置づける**。目次で附錄各篇に干支の執筆年月表示（「巳の一月」等＝明治38年〔1905〕候補）が付くが、七碗歌への対応はOCRで確定できず、江戸期の素材（実在の口伝）を下敷きにした可能性は排除しない（断定しない）。〕
- **水の秤量（重量）比較の口伝〔確認・文言候補〕**: 同箇所——「**隅田川の水は四十二匁、玉川上水神田上水は四十三匁、眞間の手古奈の水は四十八匁…有馬の鷹塚の〓水は甘いけれども…同あま匁に就いて六分輕い…合の杓に就て一匁六分重いとかふふやうな事も分つて居る**」＝名水の優劣を**水の重量（匁目）で比較する口伝**の記録（咄内の老翁の水の講釈の文言であって実測記録ではない=第148回追記参照）。〔[GAZ-066](../gazetteers/GAZ-066.md)（名水品彙・張巻川条「分度四十度秤量四十三銭」）の「秤量」評価と同じ発想（水の比重・重量による品評）の文芸側用例で、**弦巻川の名水評価の系譜（品評録の実測値×文芸作品内の列挙）が両面から確認できる**。数値の意味（一升当たりの重量か）は本書からは不明。〕
