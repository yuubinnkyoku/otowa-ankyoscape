- **書誌〔確認〕**: 『小品十種』（**成功雑誌社・1908年**。請求記号26-460・書誌ID000000513532。NDL次世代デジタルライブラリー [book/889104](https://lab.ndl.go.jp/dl/book/889104)）。江戸後期の随筆・小品を集めた叢書で、附錄に茶道の口伝歌「七碗歌」（盧仝の「七碗茶歌」に擬えた江戸の水取舍の口伝）を収録する。**同一内容の別刊**: [book/886753](https://lab.ndl.go.jp/dl/book/886753)（別刊・同内容として併記し独立登録しない）。
- **「音羽の弦卷川」＝名水列挙の口伝歌〔確認・文言候補・repo初出候補〕**: 附錄「七碗歌」——「**小日向の黄金水を汲んで來い…澁谷の八幡の井の水を取つて來い…馬喰町の三日月井、（吹）出町の雁金の井、**音羽の弦卷川**、隅田に流れ込む**綾瀨川**なんどの水を汲めのと云はれました 其の初は異なことゝ思ひました**」（OCR崩れあり・要照合）＝**江戸の名水を列挙する茶道口伝歌の水名群に「音羽の弦卷川」が含まれる1908年活字収録例**。〔**弦巻川を名水として列挙した江戸期の口伝歌が明治41年時点で活字収録されていた用例＝弦巻川の名水評価の文芸・実用側の記録としてrepo初出候補**（名水品評録〔[GAZ-066](../gazetteers/GAZ-066.md)名水品彙の張巻川条・分度40度秤量43〕の系統と対校できる。歌の成立年代（江戸期か明治か）は本書からは確定しない）。列挙水の比定（小日向の黄金水・澁谷の八幡の井・馬喰町の三日月井・雁金の井）は既存の名水記録と対照する。〕
- **水の秤量（重量）比較の口伝〔確認・文言候補〕**: 同箇所——「**隅田川の水は四十二匁、玉川上水神田上水は四十三匁、眞間の手古奈の水は四十八匁…有馬の鷹塚の〓水は甘いけれども…同あま匁に就いて六分輕い…合の杓に就て一匁六分重いとかふふやうな事も分つて居る**」＝名水の優劣を**水の重量（匁目）で比較する口伝**の記録。〔[GAZ-066](../gazetteers/GAZ-066.md)（名水品彙・張巻川条「分度四十度秤量四十三銭」）の「秤量」評価と同じ発想（水の比重・重量による品評）の文芸側用例で、**弦巻川の名水評価の系譜（品評録の実測値×口伝歌の列挙）が両面から確認できる**。数値の意味（一升当たりの重量か）は本書からは不明。〕
