# [BOOK-133] 東京市史稿 変災編第5（1917）— 八丁堀の千川屋敷出火と1898年の本郷警察署前の千川上水

- **書誌〔確認〕**: 東京市役所編纂『**東京市史稿 変災編第5**』（大正6年・1917年・東京市役所刊）。江戸末期〜明治期の火災・震災の編年体集成（『續武江年表』『齋藤月岑日記』『山口直毅日簿』『見聞雜錄』『風俗畫』『官報』等の抄出）。NDL次世代デジタルライブラリー [book/1915694](https://lab.ndl.go.jp/dl/book/1915694)。**引用はすべて同館OCRテキスト由来で、文言は原文画像との照合を要する。**「本郷」が一貫して「本〓」等に崩れて読めるなどOCR崩れがある。
- **万延元年（1860）2月4日の「八丁堀千川屋敷」出火〔確認・repo初出〕**: 「**〔附記〕二月四日（万延元年）曉、八丁堀千川屋敷より出火、龜島町迄燒る。（齋藤月岑日記ニハ「四日曉七時過、未申大風、八丁堀藥師樣〔より〕出火、龜島町邊やける」と記ス。山口直毅日簿ニモ「今曉六時頃北島町通出火ニ付、場所見屆、夫より登城致ス」と有リ。）**（續武江年表）」〔**①万延元年2月4日晓に「八丁堀千川屋敷」から出火して龜島町まで焼けたという続武江年表の記録、②斎藤月岑日記は「八丁堀薬師様より出火」、③山口直毅日簿は「北島町通出火」と、出火地点の表記が日記間で異なる**＝**八丁堀側に「千川屋敷」と呼ばれる屋敷が存在した幕末の記録（repo初出）**。[BOOK-131](BOOK-131.md)（橋梁篇第一）の「元祿十二年コノ堀幅半埋メラレテ千川屋敷トナリ」（龜島川から茅場町の方へ入る入堀の半埋立＝千川屋敷の起原）と対になる火災記録。**この八丁堀・茅場町側の千川屋敷と、小石川白山前町の千川屋敷（千川上水請負人の拝領屋敷〔[GOV-208](../gov/GOV-208.md)・[GOV-210](../gov/GOV-210.md)・[GAZ-034](../gazetteers/GAZ-034.md)〕）が同一の千川家か別家かはこれらの記録からは確定できない（両者の関係は照合課題とし断定しない）**〕。
- **明治31年（1898）3月23日の本郷・湯島大火と「本郷警察署前千川上水」〔確認・repo初出・千川上水の明治末期の現存記録〕**: 風俗番（『江戸の花報所收』を引用）の大火の記述——「**卅一年三月廿三日午前二時廿五分 本（郷）區春木町二丁目五十五番地なる同町一丁目卅二番地漬物商橫枕昇太郞所有の物置より出火…火は西北に燃え廣がり…西は本（郷）一丁目・元町二丁目まで延燒し…燒失せし戶數は實に八千四百七十八戶なり**（中略）**此火災に際し、第一著に馳付けしは、消防第四分署萬世橋派出所の蒸氣喞筒にて、三時十分下谷區上野櫻木町の火災場より引上げ、上野に來リし際、春木町に火の手上りしを見、直に方向を轉じて現場に馳せ付け、喞筒を本（郷）警察署前千川上水に据付けしも、水利不便の爲め、本（郷）二丁目に轉じたり**」〔**①明治31年3月23日の本郷・湯島大火（焼失8,478戸・放火）の記録、②消防の蒸気唧筒を「本郷警察署前の千川上水」に据け付けたが水利不便で転じたという行動記録**＝**1898年時点で本郷警察署前に「千川上水」と呼ばれる水路が存在し、消防水利として使える状態（実際は水利不便）だったことを示す記録（repo初出）**。千川上水の下流域（本郷・湯島方面）の明治末の残存状況を示すデータポイントとして、①「本郷湯島下谷浅草の辺一図に懸渡り…天明六午年十一月また止ミ」（上水在絶記・[GAZ-034](../gazetteers/GAZ-034.md)・[GOV-171](../gov/GOV-171.md)系）の江戸期の給水範囲文言、②神田上水の廃止（享保7年）後も1829年に給水実態があったという記録（[BOOK-130](BOOK-130.md)内神田の水切）、と並べて検討する資料。ただしこの「千川上水」が旧上水の開渠残流か、上水跡を転用した下水・溝かはこの文言からは特定できない（断定しない）**〕〔「本郷」のOCR表記は「本〓」に崩れており、町名の全数は原文照合を要する〕。
- **陰性〔確認〕**: 「水窪」「谷端」「弦卷」「鶴卷」は全文走査で四河川に繋がる文言は0件（変災編第5は火災・震災中心の構成）。付記の震災関係（江戸期地震）にも四河川関連文言は確認できず。
