# [BOOK-222] 深川区史上巻（1926）— 上水の末端は隅田川西岸に絶ゆの文言と本所上水廃止「此頃水も參らず」

## 書誌

深川区史編纂会編『深川区史』上巻（深川区史編纂会・**大正15年〔1926〕**刊・下巻はNDL [1020221](https://lab.ndl.go.jp/dl/book/1020221)）。NDL次世代デジタルライブラリー [book/1020207](https://lab.ndl.go.jp/dl/book/1020207)。上巻の第三章（江戸時代人文史）第五節「上水道路及橋梁」・第八章（市制施行後の深川）第二節「衞生上水道」ほかに江戸〜明治期の上水の通史と江東側（本所・深川）の飲料水問題の記述がある。

## 内容（千川上水・本所上水関係）

- **上水の末端は総て隅田川西岸に絶ゆの文言〔文言候補・repo初出の地理的整理文言〕**: 「**江戸の上水に神田上水·玉川上水·千川上水のあつたことは人のよく知る所である。玉川上水は、赤坂·麴町·芝以南の地に引水し、神田上水は、その以北江戶川以南の地に引用したもので、それらの水道の末端は總て隅田川西岸に至つて絕え、地方に及ぶものはなかつたのである**」（第三章第五節。OCRの字句は要照合）＝**江戸の上水（神田・玉川・千川）の給水区域がすべて隅田川（大川）の西岸で終わり、江東地方（本所・深川側）に及ばなかったという1926年区史レベルの地理的整理**＝**江戸（大川）を越えて江東に給水した上水は亀有上水（本所上水）のみで一時的だったという本節の叙述構造の前提文言**。〔**千川上水の給水末端が「隅田川西岸」に至るという表現は、千川上水の給区域の下限（浅草方面＝[GAZ-049](../gazetteers/GAZ-049.md)⑫1【上水在絕記】の「淺草御殿」「淺草の邊一圓」）を東限として江戸川・大川手前で捉えた整理**。千川上水の末端の具体的区間（浅草のどこまで到達したか）は本書では特定できない〕
- **亀有上水（本所上水）の通史と白堀上水説〔確認・既出材料の区史レベルの対校〕**: 「**水源地は今の南埼玉郡八條村にあつたものらしく、八條領瓦會根溜井から分水したものと考へられる。それから引いた水路は足立郡を經て葛飾郡龜有村に入り、それより上千葉·寶木塚·篠原·四ツ木·澁江·木下·寺島·請地の諸部落を通過して小梅村に至り法恩寺橋の東迄來てゐた**」＝瓦曽根溜井→亀有村→上千葉〜請地→小梅村・法恩寺橋の経路＝[GAZ-138](../gazetteers/GAZ-138.md)（小梅瓦町書上・受益村リスト「大畑」「須崎」の追加）・[GAZ-093](../gazetteers/GAZ-093.md)（風土記稿の村列挙）と対校（大畑・須崎は区史の列挙になく風土記稿系に従う。村列挙の差は対立として記録）。「**一說には本所の北の方、綾瀨川の本流を業平橋筋に引き、本所中に配水せしものこれを白堀上水と云ひ…しかしこれについては『新編武藏風土記稿』『葛西誌』共に否定してゐる**」＝白堀上水＝業平橋筋配水説を両書が否定する旨＝[GAZ-093](../gazetteers/GAZ-093.md)・[GAZ-138](../gazetteers/GAZ-138.md)の白堀＝本所上水の比定問題の1926年時点の認識の記録。
- **『御府内上水在絕略記』の本所上水条の引用文言〔文言候補・[GOV-171]の在絕略記の別条の運用例〕**: 「**『御府内上水在絕略記』には天和三年やみ元祿年中又開發と記してゐる**」＝**御府内上水在絕略記（[GOV-171](../gov/GOV-171.md)・NDL 2541386＝千川上水条の引用元としてrepo既登録）が本所（亀有）上水について天和3年（1683）に止み元禄年中に再び開発したと記す旨の引用**＝**在絕略記が千川上水条（元禄9子年・享保7寅年10月・安永9子年・天明6午年11月）のほかに本所上水の興廃の年次も載せる帳簿であることの1926年区史レベルの witness**。〔在絕略記の原冊の本所上水条の文言の直確認は未実施（[GOV-171](../gov/GOV-171.md)のOCR走査は千川上水条中心のために未採録か）・次回課題〕〔**天和3年やみ＝本所開拓の天和3年一時中絶（本書の前段の「天和三年になつて一時中絕の姿となつた」）と対応し、元禄年中の再開発＝元禄10年の本所再開発（旗本の士二百餘人の移転）・元禄12年4月11日・5月27日の上水修理の町觸（本書記載）に接続する年代構造**〕
- **享保4年の上水掛の勘定奉行への移管と享保7年の廃止文言〔文言候補・享保7年四上水差止の江東側の文言〕**: 「**これより先同四年に上水掛は在來の本所奉行の所管を移して勘定奉行に引渡されたが、七年には八九月の交『此頃水も參らず』との理由で廢止になつた。この時には、他にも同樣な運命に會つたものに千川·靑山·三田の各上水が有た**」＝**①享保4年（1719）に本所奉行から勘定奉行への所管移替、②享保7年（1722）八九月の交に「此頃水も參らず」の理由で廃止、③千川・青山・三田の各上水が同時に同じ運命（廃止）にあった、の3点**。〔**①の享保4年の勘定奉行移管＝江戸上水の奉行系統の変化の文言候補（千川上水の享保7年差止〔[GOV-170](../gov/GOV-170.md)・[GAZ-049](../gazetteers/GAZ-049.md)⑫1〕の制度面の文脈資料・repoでこの移管文言の別出は未確認）**、**②の廃止の理由文言「此頃水も參らず」＝亀有上水の通水低下の一次文言候補を区史が採録**、**③の四上水差止の並記は[GOV-170](../gov/GOV-170.md)（享保撰要類集「青山三田千川本所上水と共なる差止御書付」）・[GAZ-138](../gazetteers/GAZ-138.md)（小梅瓦町書上・享保7年9月）と整合**〕「**葛西誌にも『本所を開かれし時…新に上水をかけられしが、その後戶ごとに井をうがちて、無用の上水となりし故やめられし』と記してゐる**」＝廃止の解釈（掘井戸の普及説）の葛西誌引用。
- **享保7年の引水成績調査の文言〔文言候補・上水廃止時の実態調査の記録〕**: 「**上記の調査は、享保七年のものである**」＋南本所小名木川より北本所龜澤町通迄（平均竪十九町・横十一町）は普通には船水を用ひ上水にはよらなかった／南本所富川町辺・北本所亀沢町通〜北割下水松倉町辺・西材木藏〜東天神橋（竪十三町・横十町）は所により上水を用ひ水勢薄く潮気を含む場には掘井・池水を用いた／中の鄕町大川通・業平橋邊・瓦町〜松倉町・両国橋際〜御材木藏・川端通り四ツ目〜猿江〜柳島辺は**上水全く懸らず、專ら堀井・池水によつた**＝**享保7年時点の本所側の引水実態の区域別調査の様子**（潮差・水勢・距水による通水不全の実録）。〔**千川上水の享保7年差止と同時期の江戸市中の上水の実態調査の存在を示す文脈資料**（本調査は本所上水の廃止の「やむを得ない事情」の裏付けとして区史が記す）〕
- **水船・改良水道までの江東の飲料水〔確認〕**: 「**本所、深川方面は終始水道の利便に浴することが出來ず…水船によつて飮料水の賣買が行はれ、この狀態はつひに改良上水道の竣工せし明治三十二年（原文の数字表記は要照合）迄繼續した**」＝江東の水船による飲料水供給と淀橋浄水場系改良水道の竣工までの継続の文言＝千川水道株式会社（[PAP-023](../papers/PAP-023.md)・明治13年〜）が江東に給水しなかったこと（給水区が本郷・下谷・小石川・神田諸区＝[BOOK-223](BOOK-223.md)等）と整合する江東側の記録。

## 制限・注意

1. 本書は区史（二次編纂）で、白堀・亀有上水の叙述は『新編武蔵風土記稿』『葛西誌』『御府内上水在絕略記』その他の二次利用とみられる。引用文言の典拠の多くは本文中に挙示されるが、文言は原文（原典・原画像）との照合を要する。
2. 「八九月の交」「此頃水も參らず」の文言の原典（本所奉行・勘定奉行の伺書・町触か）は本書では示されず、特定は次回課題。
3. 「改良水道の竣工せし明治三十二年」の年次（32=1899）は淀橋浄水場の通水開始（明治31年〜区域拡大）と厳密にはずれる可能性があり、原文照合まで断定しない。
4. 千川上水関係の直接文言は「上水の末端は総て隅田川西岸に至つて絕え」句と享保7年の四上水並記（千川・青山・三田）で、千川の流路・給水区の新事実は本書からは出ない（文脈資料としての採録）。
