# [BOOK-132] 東京市史稿 変災編第3（1916）— 明治期の千川・弦巻川の水害の市史稿側集成

- **書誌〔確認〕**: 東京市役所編纂『**東京市史稿 変災編第3**』（大正5年・1916年・東京市役所刊）。明治期の風水災・震災の編年体集成（『警視廳公文類纂』『諸災調上申』『佐野弘毅日誌』『小笠原某務日記（OCRで人名部分崩れ・原字形要照合）』『明治颱風誌』等の抄出）。NDL次世代デジタルライブラリー [book/1915649](https://lab.ndl.go.jp/dl/book/1915649)。**OCRの列崩れが多く（表組みの崩れ）、文言・数値・行対応は原文照合まで保留。引用はすべて同館OCRテキスト由来。**
- **明治6年（1873）9月23日の千川・江戸川出水の明細〔確認・[BOOK-126](BOOK-126.md)（小石川区史）の明治6年項を変災編側から補完〕**: 「**小石川 千川筋 水嵩平水ヨリ八尺程。右出水ニ付 流失 小石川 裏柳橋。小石川 鶯橋、浮上リ**。同斷（小日向）**江戶川筋 水嵩、平水ヨリ八尺弱。右洪水ニ付、押流シ 一、小日向 中ノ橋**。床上ヘ溢候戶數：**小石川 戶崎町内 十戶。掃除町内 四十五戶程。柳町内 六十戶。初音町内 貳十五戶。餌差町内 三十五戶。下富坂町内 百戶程**」〔**①千川筋の増水8尺・裏柳橋流失・鶯橋浮上り、②小日向江戸川筋8尺弱・中ノ橋押流し、③町別床上浸水戸数（戸崎町10・掃除町45・柳町60・初音町25・餌差町35・下富坂町100）の変災編側の集計**＝区史（[BOOK-126](BOOK-126.md)）の「千川流域床上浸水約三百戶」の元になる町別内訳に相当する記録（変災編の表組みで初めて町別・戸数つきで確認）〕。
- **明治8年（1875）8月10日夜の出水と三橋流失〔確認・repo初出の水害〕**: 「**明治八年八月十一日 第四大區十一小區 町用掛リ 高橋伊三郞 出水御屆**——（柳町・初音町・餌差町・下富坂町・春日町・掃除町・石切橋邊〜江戶川端通リ等の町内の浸水深の列挙）——**一、裏柳橋、鶯橋、丸太橋 右三橋、古角材ニ而假ニ掛ケ渡有之候處、何レモ流失仕候**」〔**明治8年8月10日夜の出水で、裏柳橋・鶯橋・丸太橋の三橋が流失した際、それらが「古角材にて仮に掛け渡し」されていた仮橋だったことを記す町用掛の御届**＝①明治8年の出水（区史・repo未収録の水害）、②明治8年時点で裏柳橋・鶯橋・丸太橋が仮橋（古角材の仮掛）だった実態、の2点が新規確認できる記録。明治6年流失（上項）からの応急復旧状況を示唆するが断定はしない〕。
- **明治10年（1877）9月14日夜の掃除橋流失と弦卷川筋の増水・床上浸水〔確認・弦巻川（鶴巻川）の明治期氾濫の新明細＝repo初出〕**: 「**明治十年九月十四日（佐野弘毅日誌：十四日寅、曇、夕雨、夜ニ入極大雨、雷）（小笠原某務日記：十四日寅、天氣、三時頃雨少々、五時頃大雨、夜大雷）—— 市内小石川 千川筋 洪水之節 流失 小石川 掃除橋**＋**音羽町（石川區）内（小西裏）弦卷川筋 洪水平水ヨリ水嵩六尺餘。右洪水床上ヘ溢候戶數、音羽町八丁目 拾貳戶。音羽町九丁目 四十五戶。櫻木町（石川區） 五戶**（警視廳公文類纂・諸災調上申）」〔**①明治10年9月14日夜の大雨で小石川掃除橋が流失、②音羽町内の弦卷川筋（小西裏・OCR）が平水より6尺余増水、③床上浸水は音羽町8丁目12戸・9丁目45戸・櫻木町5戸**＝**弦巻川（鶴巻川）の明治10年氾濫の被災町丁目・戸数つきの明細はrepo初出**。[BOOK-126](BOOK-126.md)の明治13年（1880）10月4日の鶴巻川増水6尺・床上浸水64戸と並ぶ弦巻川氾濫のデータポイントで、1880年の3年前に同規模（6尺余）の増水があったことを示す。掃除橋の流失は明治6年（裏柳橋などと同年の区史記録）・明治13年（[BOOK-126](BOOK-126.md)）に加えて明治10年にもあった記録〕〔「音羽町内小西裏」の「小西裏」はOCR崩れ・原字形要照合〕。
- **明治18年（1885）の千川・藍染川筋の浸水〔確認・藍染川の並記〕**: 「**明治十八年（十月十六日暴風雨）…小石川 千川筋、（及）北豐島郡千束村・本（所）割下水・藍染川筋（淺草區）等浸水ス**」＋「藍染川沿淵ノ人家ハ、床上二三寸ヲ浸サレシモノ凡四十戶」〔明治18年10月16日暴風雨で千川筋と並んで藍染川（浅野川系）の浸水が記録される。千川の出水河川としての位置づけ資料〕。
- **明治43年（1910）8月の千川氾濫と明治44年（1911）8月の大下水氾濫〔確認・[BOOK-126](BOOK-126.md)の明治43年項の市史稿側の補完〕**: ①明治43年8月の暴風雨——「**千川氾濫 富坂警察署管内 床上（浸水）百戶 床下（浸水）百五十六戶**」＋「初音町十一番地六歳児童 大下水に落入 行方不明」〔千川氾濫の富坂警察署管内の床上100戸・床下156戸の集計と、初音町11番地の6歳児童が大下水に落ちた記録〕。②明治44年8月——「**音羽（町）七丁目 大下水 氾濫 約八尺増**」＋「大塚警察署管内 床上二百八十戶」＋「（八月十日）**藍染川 干駄木町 約千戶浸水**」〔音羽町7丁目の大下水が約8尺増水した明治44年の記録。大下水＝小石川下流部の呼称（[GOV-208](../gov/GOV-208.md)「小石川に至て大下水と稱し」）と整合する音羽側の氾濫記録〕〔数値の行対応はOCR表組み崩れのため要照合〕。
- **出水河川リストの「千川上水」〔確認〕**: 変災編第3の出水河川の列挙に「**神田川・荒川・江戸川・中川・神田上水・千川上水**…藍染川」が含まれる〔明治期の水害統計の対象河川として「千川上水」が独立に計上されている文言（OCR列挙・行対応要照合）〕。
