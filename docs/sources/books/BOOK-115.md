# [BOOK-115] 土地概評価 板橋町（1922）

- **書誌〔確認〕**: 『土地概評価 北豊島郡板橋町』（東京府・1922年）。NDL次世代デジタルライブラリー [book/921578](https://lab.ndl.go.jp/dl/book/921578)。OCRテキストで千川上水・谷端川関係を確認。**文言はOCR由来で要照合。**
- **千川上水以北の地形・谷端川岸工場〔確認・repo初出〕**: 「**千川上水以北は概ね北に傾斜**…畑多く」＝**1922年時点で「千川上水」が地形区分の基準線**として使われている。工業地として「石神井及び**谷端川岸の低地**を有し…**板橋驛の西北 谷端川岸のプライウード（プライウッド）工塲**」＝**谷端川岸の合板（plywood）工場の所在**を1922年の公文書が記録。「境久保」の表記も現れる〔＝境窪〕。
- **大字中丸の谷端川と「其支流」の並行谷〔確認・第107回追記・repo初出〕**: ①大字中丸の記述——「**南は谷端川を距て、西巢鴨町大字池袋の高臺と相對し北は其支流々域の低地を挾んで大字金井窪の高臺と相對する**高臺及び其附近の低地とにて字川原以下五字あり」＝**中丸高台の南＝谷端川本流（対岸は西巣鴨町大字池袋の高台＝[GOV-159](../gov/GOV-159.md)の「板橋町及西巣鴨町ノ境界ヲ流レ」と整合）、北＝「其支流」流域の低地（対岸は金井窪の高台）**という1922年時点の水系構造の記述〔**谷端川の支流（中丸〜金井窪間の谷筋）の存在を明示する府の査定文書レベルの文言。README既出の滝野川側支流「逆川」（[BLOG-087](../blogs/BLOG-087.md)）や「悪水路」とは別系統の支流の候補。OCR・要照合〕。②字川原の記述——「**東上鐵道板橋驛の西南、大字中丸の高臺の東端及び其下谷端川と其支流との間に在る窪地**、高臺には畑及び農家、窪地には田あり**東には中丸橋通其他新道二三ありて池袋に通じ**北は金井窪を經て川越街道に出づる道路あり」＝**板橋駅西南の谷端川と支流の間の窪地（田）＋中丸橋通りの道路名**〔**中丸橋＝谷端川（または支流）に架かる橋の候補で、板橋駅〜池袋間の東西道路**。現在の橋名との照合・橋の正確な位置は未確認〕。③「**谷端川岸の田地には旣に一部工事を完りたる處あり**引き續き各方面に之れを行ふ筈」「低地は目下**耕地整理中**なり」＝**谷端川岸低地の耕地整理事業が1922年時点で一部完工・進行中**だった記録〔板橋放水路の着工時期（READMEの1924/25年次問題）と同時期の谷端川岸低地の土地改変の状況データ。事業名・区画の特定は要原典照合〕。
- **位置づけ〔観察〕**: 谷端川岸低地の工業立地（合板工場）の1922年時点の公認記録で、[BOOK-114](BOOK-114.md)（巣鴨町の谷端川岸小工場）と対になる板橋町側の記録。千川上水以北の傾斜文言は台地地形（千川上水沿いの尾根）の当時の認識を示す。**中丸高台を挟む南（本流）・北（支流）の対称的な谷構造は、谷端川旧流路研究（本流の湾曲と支流谷の並行）に1922年の地形断面を与える**。
