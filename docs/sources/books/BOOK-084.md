- **書誌〔確認: 練馬区史歴史編本文の参考文献列挙〕**: 都立板橋高等学校編・**『千川上水沿線集落』（昭和31年）**が、千川上水の基本文献として東京市『東京市史稿上水編』・『練馬の水系』（昭和51年）・武蔵高等学校『千川上水』（昭和16年）と並んで挙げられている〔[GOV-098](../gov/GOV-098.md)〕。
