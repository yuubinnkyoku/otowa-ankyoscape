# [BOOK-154] 武江年表 巻之七 — 文化9年秋の玉水簾造営記事（上水の余り引水・天保の始より廃）

- **書誌〔確認〕**: 『**武江年表 8巻**』のうち**巻之七**（嘉永2年〔1849〕刊・須原屋伊八ほか版。NDLメタデータの責任表示は空欄で、編者は通説により斎藤月岑とされる・メタデータでの確認は不可）。NDL次世代デジタルライブラリー [book/2563436](https://lab.ndl.go.jp/dl/book/2563436)。原本OCRは崩れが大きいため、**江戸叢書刊行会の活字版『江戸叢書 巻の十二』（1917・[book/1913086](https://lab.ndl.go.jp/dl/book/1913086)・同書に武江年表を収録）の同一文言で対校して引用を整形した**。**すべての引用はOCRテキスト由来であり、文言は原文画像との照合を要する。**〔なお1850年刊の別版（[book/2605169](https://lab.ndl.go.jp/dl/book/2605169)）のfulltextは取得不能（0バイト）だったが、1849年刊版で足りる〕
- **①文化9年秋の玉水簾の造営記事〔確認文言（活字版対校済み）・repo初出の造営年代の独立系統〕**: 文化9年（1812）の年中記事の末尾（直前は同年11月吉原火事・翌年8月仮宅移転の記事、直後に文化10年癸酉の紀事が始まる。項目の先頭に「**此秋**」）に、活字版で「**此秋、音羽町二丁目三丁目あたりの西の裏手に、上水の餘りを引て瀧を拵へ、玉水簾と號す、高一丈五六尺幅一間餘り、道左右山を作り、四時の花木を裁へて、側に茶店を出し、往來の人の休み所となす、天保の始より廢たり**」〔原本1849年版OCRでは「瀧をこゝきよくすゐれんらへ玉水簾と号す」「四時の花木を載て例に茶店を出し」等の崩れ〕＝**①文化9年秋に音羽町2〜3丁目あたりの西の裏手に、上水（神田上水）の余水を引いて滝が造られ「玉水簾」と号されたこと、②高一丈五六尺（約5.5〜6m）・幅一間余（約1.8m超）の規模、③道の左右に築山を作り四時の花木を植え、側に茶店を出して往来人の休み所としたこと、④天保の始め（1830年前後）に廃れたこと**の年表記事。
  - 〔**「上水の餘りを引て」の文言は水文的に重要**＝玉水簾（音羽の滝）が神田上水（白堀）の余水の引水による**人工滝**であることを造営当時の年代記レベルで記す。音羽谷を通る神田上水（白堀・[GOV-232](../gov/GOV-232.md)・[GOV-233](../gov/GOV-233.md)・[GAZ-048](../gazetteers/GAZ-048.md)）から音羽谷斜面への分水の実在を示唆する文言として、弦巻川・水窪川の水源論（[BOOK-152](../books/BOOK-152.md)の金ヶ窪村〜御鷹部屋東の小溝等）と神田上水の関係の新しい視点。ただし引水の経路・樋の所在は本条では特定できない（断定しない）〕
- **②狂歌2首の併載〔確認文言・repo初出〕**: 続けて狂歌2首を載せる。「**深山より落くる瀧の玉すたれかゝけてそ見る水無月の空**（原本OCR。蜀山人の歌）」「**けふそ見るこゝも音羽の音高くきゝわたりぬる滝の岩浪** 男山人縣麿」〔原本OCRの「男山人縣麿」の表記は活字版・[GAZ-061](../gazetteers/GAZ-061.md)（遊園篇の引用では「縣麿」）との照合を要する。第2首の帰属（縣麿）はOCR文末表記による〕。〔第1首「深山より落くる瀧の玉すだれ…」は南畝（蜀山人）の狂歌として[BOOK-155](../books/BOOK-155.md)（蜀山人全集・詞書「神齡山の麓に音羽町瀧あり玉簾と名づく」付き）に自署の一次テキストがあり、[BOOK-151](../books/BOOK-151.md)の「南畝大人は玉水簾と筆を投せり」の命名説を強化する〕
- **③造営年代の系譜での位置づけ〔観察・年代の対立は併記して断定しない〕**: 音羽の滝（玉水簾）の造営年代は、[BOOK-151](../books/BOOK-151.md)（遊歴雑記初編）「**文化初年の頃**」／[GAZ-035](../gazetteers/GAZ-035.md)（町方書上149・音羽町の小川中程の高さ5尺の流落し）「**文化13年5月**」／本条（武江年表）「**文化九年秋（此秋）**」／[BOOK-156](../books/BOOK-156.md)（寝ぬ夜のすさび・天保2年の記事で「二十年にも余り」忘れられた）＝**1812年説が最有力の候補になるが、町方書上の文化13年5月との対立（造営と町方への届出・改修の時差か）は解消できず、併記して断定しない**。
  - 〔**「天保の始より廃たり」もrepo初出の廃滅時期文言**。天保13年（1842）の護国寺門前の遊女取締り・岡場所廃止（[BOOK-009](../books/BOOK-009.md)）と天保の改革の狭間の時期であり、茶店・遊観地としての玉水簾の衰退と政策の前後関係は本条だけでは特定できない。廃滅の「天保の始」＝1830年代前半と解せる文言（要原文照合）〕
- **④玉水簾の位置の文言〔観察・位置の対立は併記〕**: 「**音羽町二丁目三丁目あたりの西の裏手**」（本条）／「音羽町壹丁目西橫丁崖下」（[BOOK-151](../books/BOOK-151.md)）／「**音羽三丁目の道具屋半兵衛かうらの山の下の流**」（[BOOK-156](../books/BOOK-156.md)）／「音羽町の小川中程」（[GAZ-035](../gazetteers/GAZ-035.md)）＝**いずれも音羽町の西側（弦巻川側・護国寺寄り）の谷斜面を指す系統の文言で、丁目の表記に幅がある**。西の裏手＝弦巻川（西流）側の谷頭と整合する候補だが、[BLOG-109](../blogs/BLOG-109.md)・[BLOG-110](../blogs/BLOG-110.md)・[BOOK-151](../books/BOOK-151.md)の音羽富士前・潭弦亭（音羽の瀧の北四丁・清土町北側）位置説との対応は本条だけでは確定できない。

## 制限・未解決

- ①原本1849年版のOCR崩れ（「瀧をこゝきよくすゐれんらへ」＝「瀧を拵へ玉水簾と号す」の崩れ等）は江戸叢書活字版で対校したが、**活字版の底本と原本の異同・句読点・表記（「載て例に」vs「裁へて、側に」等）は原文画像照合まで確定しない**。②「此秋」の紀年帰属（文化9年秋）は前後の記事の並び（文化9年11月吉原火事の後・文化10年の前）による文脈確定で、原本の項目区切り（○）の位置は要照合。③狂歌の署名表記（「男山人縣麿」・蜀山人歌の帰属）は原本・活字版の両方で要照合。④「天保の始より廃たり」の「廃」の解釈（滝・茶店のどちらが廃れたか）は本条では特定できない。⑤引水の経路（樋・枡の所在）は今後課題。⑥1850年刊版（2605169）のfulltextは取得不能だった（再取得不要と判断）。
