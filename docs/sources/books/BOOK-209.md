# [BOOK-209] 紫の一本（写2冊・柳亭種彦手沢本）— 江戸志系地誌が引く「むらさきの一本」の本文側〔第185回登録〕

- **書誌〔確認・要再確認〕**: NDL次世代デジタルライブラリーの写本2冊: [2575104](https://lab.ndl.go.jp/dl/book/2575104)（川・井・谷・堀・嶋等の部）＋[2575105](https://lab.ndl.go.jp/dl/book/2575105)（橋の部）。奥書に**書写正徳4（1714）と読める年紀候補**（前回実行の確認に基づく・本登録時点で要再確認）。表紙書込: 「**柳亭種彦手澤本 むらさきの一もと十一 天保乙未夏 表紙あらたむ**」＋「**むらさきの一もと序遺失して怨さるは浅草の隠士か気味也**」＝**天保乙未（1835）夏に柳亭種彦が表紙を改めた手沢本**で、序が遺失している旨の識語。冊頭に山・坂・谷・窪・川・嶋・堀・井等の全体目録（「…渋谷僧司谷下谷比谷千駄ヶ谷世多谷…浅草川江戸川玉川宮戸海…堀新堀八町堀井極楽井鯰の升堀かねの井柳井糀町の井 亀の井亀井戸油の井笛の井…」と読める列）。
- **書誌対校〔観察〕**: [GAZ-099](../gazetteers/GAZ-099.md)（新編江戸志活字版・1917）の引用之書目は「**紫一本〔天和の頃・儉逸〕**」＝**成立天和の頃・儉逸（撰者名候補）という書誌情報**＝[BOOK-148](BOOK-148.md)（中野町誌・1933）の『紫の一本』**天和2年（1682）刊**説と整合（frontmatterのyear 1682はこの二次書誌に基づく目安）。一方、[改正新編江戸志[1]](https://lab.ndl.go.jp/dl/book/2545212)（2545212）の書目OCRに「**紫一本戸田茂理名所談元禄七年**」と読める列＝**茂睡（戸田茂睡）の『名所談』（元禄7年・1694）の書誌が「紫一本」に隣接して現れる**（名所談の前置きか誤判読かは原画像照合待ち。**茂睡＝紫の一本の撰者であるとは機械的に断定しない**）。写本の奥書（正徳4=1714候補）は刊本（天和2年説）を書写した年代の下限として管理する。
- **淀橋条（2575105）＝[GAZ-097](../gazetteers/GAZ-097.md)淀橋条・おたき橋条の引く「むらさきの一本」の本文側〔確認・文言候補・今次登録の核心〕**: 「**今はなる子(?)淀捻かる こ宿と中野の間にあり 元はすがたみすの橋と云 いひよきようすかたか橋と云 昔武州多堂郡中野の内正観寺の薬師の棟札に朝日長者昌連か書たるは漆千盃朱銅金千両銭十六万貫朔日さす夕日からやく藤の木の下ニ有と云云 是を埋る時下人に負せて此橋を渡りて増たるが下人埋たる所を知りてなりとも有とてそこにてころす 彼下人の渡りたるをは皆人みたれ共帰りに渡姿をみざる故に姿不見の橋と名付たるよし 所の者 宮大瀧院様御鷹野へ出御の時此橋を淀橋と申へきよし上意より定橋と云 水車を仕掛しに能水浸なりとて御付被遊由なり**」＝**①旧名「すがたみすの橋（姿見ずの橋）」、②中野の内・正観寺薬師棟札を引き、朝日長者昌連が書いたとする埋蔵譚（漆千盃・朱銅金千両・銭十六万貫・朔日に刺す夕日に枯れゆく藤の木の下）、③埋蔵を下人に担がせて橋を渡らせた後、下人が埋蔵地を知ったため殺害→下人の渡るのを皆見たが帰りに渡る姿を見ない→「姿不見の橋」の名義譚、④「宮大瀧院様」御鷹野の出御時に淀橋と申すべき旨の上意→定橋（改称譚）、⑤水車の言及（「水車を仕掛しに能水浸なりとて御付被遊由なり」・判読は原画像照合必須）**。〔**対校**: 引用側（江戸志[8]おたき橋条・[GAZ-097](../gazetteers/GAZ-097.md)第177回追記）の「**寛永此御鷹野の時…約〔勅〕命**」には年次「寛永」があり、本文側には代わりに「宮大瀧院様」の号が現れる（年次付与と号付与のどちらが原形かは照合まで断定しない。「宮大瀧院」の比定もOCR崩れを含み行わない）。共通要素＝朝日長者昌連・下男殺し→姿不見の橋・御鷹野命名・水車（引用側おたき橋条「**水車有**」）＝**面影橋＝淀橋異名群の系譜（[GAZ-030](../gazetteers/GAZ-030.md)第183回・[BOOK-152](BOOK-152.md)十二双条・[GAZ-039](../gazetteers/GAZ-039.md)淀橋条〔一名西新橋・又姿不見橋〕・[GOV-396](../gov/GOV-396.md)不姿見橋巷説）に紫の一本本文層が加わった**。対照表の不姿見橋行参照。〕
- **江戸川条（2575104）〔確認・文言候補〕**: 「**江戸川 江戸より西にいをかしらといふ所みなみ也 善論寺の池の水も落入 是を関口村不動の下よりせきあけて江戸水道に用る也**」＝**①水源を「いをかしら」（井頭〔いのがしら〕のOCR崩れ候補）の南とする文言、②「善論寺の池（善福寺池のOCR誤読候補・要照合）の水も落ち入る」、③関口村不動の下より堰き開けて江戸水道に用いる**＝**神田上水の水源を井頭＋善福寺池側に記す本文候補**＝[BOOK-148](BOOK-148.md)村方書上の三水源説（井ノ頭池・遅野井村善福寺の池・雑色村和田村境）・[GOV-377](../gov/GOV-377.md)（1877年・多水源合流説）に先行する江戸前期地誌側の複数水源記述候補（書写正徳4=1714候補のため記述年代の下限は書写年代以下として管理・他の水源説〔関口の瀧系〕との優劣は本条では判断しない）。
- **千駄ヶ谷条（2575104）〔確認・文言候補〕**: 「**此辺巡見のとき此田面の稲千万もあるべしとて千駄谷と口了村とも申たる成へし**」＝**3系統対校（[GAZ-097](../gazetteers/GAZ-097.md)第185回追記）**: 本文側「巡見…稲千万」／江戸志[8]引用「**道灌順見の時…稲千駄**」／改正新編江戸志「**巡検…橋千駄**」＝主語（道灌名の有無）・「巡見／順見／巡検」・「千万／千駄／橋千駄」の対立群（OCR崩れの可能性が強く原画像照合前提）。千駄ヶ谷の地名由来はrepo対照表の範囲外だが紫の一本引用の精度の対校軸として記録。
- **僧司谷条（2575104）〔確認・文言候補・雑司ヶ谷旧表記のdatapoint〕**: 「**僧司谷 目白不動の先鐘の銘に俗司各（＝僧司谷／俗司谷のOCR崩れ候補）と有 本の寺法明寺と云 六老僧の御影ある寺は東陽坊と云 本堂ゟ手前南に鬼子母神の社あり そのあたり茶や在 七月十六日の夜本堂の前にて毎年相撲アリ 近郷の百姓大勢めつよりてとる也**」＝**①雑司ヶ谷の古表記「僧司谷」の実例として「目白不動の先の鐘の銘」を挙げる本文（鐘の銘の現物・年代は未確認）、②本護持寺＝法明寺、六老僧の御影のある寺＝東陽坊、③鬼子母神社前の茶屋・七月十六日の夜の本堂前の毎年の相撲（近郷の百姓が集う）＝雑司ヶ谷の年中行事の記録候補**〔対照表の雑司ヶ谷行（「曹司谷、僧司ヶ谷、雑士ヶ谷、蔵司谷」）への追記候補。「俗司各」「めつよりてとる」等の判読は原画像照合必須〕。
- **井系条群（2575104）〔確認・文言候補〕**: ①**極楽の井**: 「**小石川松平播磨守屋敷のうしとら そうけん寺（松源寺候補・要照合）と云寺の前に在 伝通院の開山了誉上人…龍女四脈を損給ひし其報恩に此水出し奉るといへり**」＝[GAZ-039](../gazetteers/GAZ-039.md)第176回の改正新編江戸志巻之五極楽水条（了誉上人行業記・応永22年・吉水）との対校点＝**龍女報恩譚の層**（対照表極楽水行）。②**蜘の井**: 「**四谷自性院の寺内ニ在…渡辺舎人西綱三田の屋敷…土蜘蛛退治譚**」＝[GAZ-097](../gazetteers/GAZ-097.md)第177回の市ヶ谷圓融寺条の紫一本引用「**紫一本二山際にあり**」との**帰属対立**（四谷自性院寺内vs市ヶ谷圓融寺山際。自性院は圓融寺とは別寺＝同譚の分布・帰属の対校案件として管理。OCR崩れ込み）。③**三崎条**: 「**新丁流布の木ニナシ 野中の清れ谷中三崎ト有…後鳥羽院の官女右衛門の佐…御制 衣むさしのゝ野中の清水 尋れは笹分る 袖に露取らゝ 此御製より三崎にある井を野中清れといふ…私云…野中の清水は播磨国印南野に有**」＝**野中の清水の後鳥羽院御製由来説とその批判（「野中の清水は播磨国印南野に有」）の私云按語**＝repoの三崎系対校群（[GAZ-039](../gazetteers/GAZ-039.md)・[GAZ-030](../gazetteers/GAZ-030.md)・GAZ-083系）に加わる本文。
