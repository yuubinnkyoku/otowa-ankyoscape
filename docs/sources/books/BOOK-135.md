# [BOOK-135] 棚橋源太郎『尋常小学に於ける実科教授法』— 藍染川を河系教材とした1903年の実科教授記録

- **書誌〔確認〕**: 棚橋源太郎（東京高等師範学校附属小学校訓導）著『**尋常小学に於ける実科教授法**』、金港堂、**1903年（明治36年）**。NDL次世代デジタルライブラリー [book/810543](https://lab.ndl.go.jp/dl/book/810543)。明治33年小学校令改正に伴い文部省が東京高等師範学校附属小学校（第一部）に実科を独立教科として加えることを許した際の、著者自身の実践に基づく教授法書。**引用はすべてOCR由来で、文言は原文画像との照合を要する。**
- **藍染川＝「一の河系」の直観教材〔確認・1903年時点の藍染川の現勢観察の集成〕**: 上野の丘〜本郷台（聖堂の森方面）の間の谷＝「**藍染川の谷**」を児童の逍遥区域の自然地理教材とし、次の観察項目を記す——①「**根津の平野を流れて、曾て涸るゝことなき藍染川の水源が、如何にして涵養されつゝあるか、土地の傾斜と排水との間に、果して如何なる關係の存するか等の事實を、實際的に學ばしむる**」（両高台の森林に覆われた丘陵側面の諸処から泉水の湧出）＝**恒常的な湧水水源の涵養構造**、②「**其の左右より藍染川に合する所の數條の支流は、更に之れに合する數多の細流を有することを直觀せしめ、以て藍染川が一の河系を成せることを理會せしめ**」＝**支流群を含む河系としての把握**、③「**大雨に際して藍染川の（氾）濫して、上野の丘本〓（本郷?）臺の麓を浸蝕する有樣**」「**降雨の後、兒童を此の土地に引率せば、濁流の藍染川の兩岸を壓して漲り、下流及び不忍の池に向ひて、盛に土砂を運搬せる狀况を見せしむることを得べし**」＝**大雨後の氾濫・土砂運搬・不忍池への堆積の実況**（「數百千年の長に涉り…下流に至るに從ひて次第に幅廣く且低平に」＝谷の発達の説明）、④「**其の流れの左右に沿うて、諸處に水田の存在せること**」「**藍染川の谷が、米作に適する所以は其の土地の低平にして灌漑に利用すべき流の存する**」＝**水田と灌漑利用**、⑤教授要項として「**藍染川の流域・水源・河口・河系・利用（排水灌漑（洗滌））、流水の作用、大雨後の狀況、不忍の池の土砂堆積、縱谷、橫谷、谷の住民、住民の職業（農業染工）**」＝**1903年時点で藍染川が排水・灌漑・洗濯に利用され、谷の住民の職業が農業と染工であったことの記録**、⑥「根津の平地は即ち濃尾の平野に相當して、藍染川の水源を涵養せる左右の高臺は即ち美濃飛驒高原及び木曾山脈に匹敵」＝木曾川流域との縮小模型比較（京都・白河の谷との比較も）。
- **意義〔確認〕**: ①1903年時点の藍染川＝根津谷中〜不忍池系（[GAZ-032](../gazetteers/GAZ-032.md)風土記稿「根津谷中の邊にて藍染川と唱ふ」・[BLOG-079](../blogs/BLOG-079.md)根津の猫股橋周辺）について、**「涸れない水源」「支流群」「氾濫」「水田」「染工」という川としての実態を、教育実践者の現地観察として記録した1903年の一時点資料**。②住民の職業「染工」の併記は、藍染川の川名（藍染め）と染物業者の関係（[BLOG-079](../blogs/BLOG-079.md)根津の藍染問屋等）を1903年時点の観察として傍証する（川名の直接の起源説明ではないので断定しない）。③水田・灌漑の記録は、染井〜谷中〜根津の田（[GAZ-013](../gazetteers/GAZ-013.md)系・千川筋の水田）の1903年時点の存続状況の比較資料。④なお本書は教材として藍染川を扱った記録であり、流量・流路の測量ではなく、学校の位置（附属小学校＝上野・根津方面から半時間）や観察範囲の同定も文言からの推定にとどまる。

- **対校: 1902年『尋常小学に於ける実科教授法講義要領』（育成会・[810544](https://lab.ndl.go.jp/dl/book/810544)）〔確認・第112回・本書の1年前の講義要領版〕**: 棚橋源太郎・育成会・**1902年（明治35年）**刊の講義要領（本書〔1903・金港堂〕とは**別冊**）に、第二学期（凡十三週・毎週三時）の教材配列として「**第三、四週 藍染川-位置水源河口支流利用(排水灌漑)流水の作用大雨後の狀况 根津の平地-境界流域谷住民 地圖及ひ模型の製作-平面縮圖(上野の丘本〓臺根津の平地不忍の池の等を含む) 同上砂及ひ粘土模型の製作 同上斷面圖の制作**」＝**①藍染川が第二学期第3-4週の教材として「位置・水源・河口・支流・利用（排水灌漑）・流水の作用・大雨後の狀况」の項目で配列され、②根津の平地（境界・流域・谷・住民）と上野の丘・本郷台・不忍池を含む平面縮図・砂粘土模型・断面図の製作が続く**、さらに隅田川教材（第5週以降）の中に「**神田川及ひ藍染川との比較**」＝**藍染川が神田川と比較される都市内小河川の教材としても位置づけられる**。1903年版の教授要項「藍染川の流域・水源・河口・河系・利用（排水灌漑洗滌）…」とほぼ同じ項目構成が1902年の講義要領で既に現れている＝**藍染川の教材化（河系としての取り上げ）が1902年に遡って確認でき、1903年版がその実践記録の完成形であることが確定**〔OCR・「本〓臺」＝本郷台の原字形は要照合〕。
