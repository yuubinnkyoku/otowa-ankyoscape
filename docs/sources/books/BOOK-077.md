- **全文テキストの公開〔確認・repo初出〕**：NDL次世代デジタルライブラリーに所収（[book/1043756](https://lab.ndl.go.jp/dl/book/1043756)・40コマ・巻頭図版＋4章構成「一、千川の沿革／二、本流／三、分水／四、余説」＋附図）。**全文OCRテキストが取得可能になった**（2026-11-15・次世代デジタルライブラリーの全文検索API経由）。**以下の引用はすべてOCRテキスト由来であり、数値・文言は原文画像との照合を要する。**
- **谷端川＝長崎村分水〔確認・repo初出〕**：谷端川は**「千川の分水の中最大のもの」「所謂長崎村分水」**。分水口は**庚申橋の下流・釣堀の裏**（現・豊島区要町三丁目付近と読める〔図版第24参照文言・位置の特定は要照合〕）で、**石積水門**の形式（略図第24）。千川文書の水口は「**七寸四方**」であるのに対し、現在（1941）は水量が僅かとなり「**四寸四方**」の穴を穿つ、と本文にある一方、分水の章では「**三寸四方**程に縮小」との文言もあり**寸法表記に揺れがある**〔OCR判読も含め要照合〕。
- **1941年時点の谷端川流路の観察記録〔確認・repo初出〕**：要町四丁目から南流→椎名町駅横で武蔵野線を横切り東流→約500mで北流して再び線路を越え→約2.5km北上→**東上線金井窪駅附近で東流**→省線板橋駅前→東南流→小石川植物園・後楽園の横を経て**神田川に合流**、**全長11km**。かつては開渠だったが「**現在は板橋駅前から暗渠に入り、開渠部分も二三年前改修**」〔1941年時点で板橋駅から下流は暗渠・開渠残存部（金井窪〜板橋駅間）は1938〜39年頃に改修、との観察記録。[GOV-159](../gov/GOV-159.md)（1930年・改修区間は西前橋下流から）・[GOV-135](../gov/GOV-135.md)（1940年・「谷端川ハ既ニ完成」）と整合する目撃記録〕。
- **明治17年（1884年）の千川水路変更〔確認・repo初出の文言〕**：**下板橋宿・金井窪村・滝野川村**において、流通不良・家屋下水の接近による**汚水浸入の防止**のため**千川の水路を変更**した旨。石神井公園文化館所蔵の**1884年（明治17）千川用水絵図**（[MAP-120](../maps/MAP-120.md)・README既述）と同じ年の変更事件を本文が記述しており、**絵図が変更後の新水路を描くというREADME仮説を本文レベルで補強する**〔絵図と変更の同一性は要画像・本文照合〕。
- **昭和初年・庚申塚の開渠埋立と陰樋出土〔確認・repo初出〕**：**巣鴨庚申塚の開渠部の埋立**（住民の記憶にない時期に行われた旨）、暗渠工事で**木製の陰樋が多数出土**。**明治15年（1882）7月建立の千川上水分配石標が現存**（1941時点）。庚申塚＝千川上水と谷端川の分岐域（[GOV-165](../gov/GOV-165.md)「千川用水＝庚申塚の北で町境」）で、分配石標の実物の存在と建立年の記録。
- **落合分水〔確認・repo初出の分水〕**：椎名町八丁目の屈曲点から分かれ、**西落合1・2丁目**を経て西武線を越え、**西落合5丁目で妙正寺川に合流**、**全長2.3km**。二三年前まで流水があり、**新十三間道路（明治通り）の工事で閉鎖**・一部埋立して街路樹を植えた旨、沿いに**猫地蔵**がある旨〔OCR・要照合〕。千川上水系の分水が妙正寺川（神田川水系）に跨っていた記録。
- **櫻台分水〔確認・repo初出の分水〕**：武蔵野線桜台駅前で分かれて南流、市寮養所の前で**中荒井分水に合流**、**全長約1km**、現在は下水に等しい旨〔OCR・要照合〕。
- **千川の沿革の要点〔確認・年号はOCR（括弧内は皇紀表記の読み替え）〕**：**宝永4（1707）年**灌漑利用許可→**享保7（1722）年**上水廃止→**安永8（1779）年**再興→**天明3（1783）年**堀割竣成→**天明6（1786）年**再廃止→**慶応年間**滝野川の反射炉で水力利用→**明治3（1870）年**砂川村分水→**明治13（1880）年**千川水道会社創立→**明治17（1884）年**水路変更→**明治40（1907）年**会社閉鎖。**六義園への暗渠送水**・**上野公園への送水**も記録。〔宝永4年＝宝永期の灌漑許可の年が具体的に判明することはREADMEの沿革記述を精緻化する〕
- **千川本流の暗渠化〔確認〕**：大正以降の人家増加による水質汚濁で**板橋四丁目以下が暗渠化**、**昭和15年度計画**で板橋町四丁目入口の橋まで暗渠化予定、**皇紀2600年（昭和15）7月までに約550m埋没**との記述〔OCR・数値は要照合〕。
