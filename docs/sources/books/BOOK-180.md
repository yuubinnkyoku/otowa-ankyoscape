# [BOOK-180] 三府及近郊名所名物案内（1918）— 千川堤桜（新小金井）の1918年の現地観察

- **書誌〔確認〕**: 『三府及近郊名所名物案内』（日本名所案内社・大正7年＝1918。本電子複製は「特再版」の版）。東京府・神奈川県・埼玉県（三府）とその近郊の名所・名物を鉄道沿線別に紹介するガイドブック。NDL次世代デジタルライブラリー [book/906086](https://lab.ndl.go.jp/dl/book/906086) のOCR全文を確認。**引用文言はOCR由来で原文画像との照合を要する**。
- **千川堤桜（新小金井）の1918年観察〔確認・repo初出〕**: 武蔵野鉄道（現・西武池袋線）沿線の東長崎駅項——「**新小金井は、下練馬、長崎兩村を流るゝ千川用水の兩岸二里餘に亘つて、櫻樹が植ゑられて居る、花時の美觀は幾紙に蓋し難く**」（OCR「兩岩」＝兩岸・「別植」＝植ゑられ（並植・遍植）の誤読候補・「下練馬、長崎兩谷村」＝下練馬・長崎兩村の誤読候補・**文言は原画像照合を要する**）＝**千川用水の下練馬〜長崎間の堤への桜の植栽（新小金井）を「兩岸二里餘」にわたって現認した1918年のガイドブック側の現地観察**。〔①植樹時期についてrepo既出の記録群——[BOOK-122](BOOK-122.md)（1930・大正初年に中新井側で植桜）・[BOOK-125](BOOK-125.md)（1932・第3の植樹時期記述）・[BLOG-101](../blogs/BLOG-101.md)（大正年間に江古田〜練馬〜中村町）——に対し、**1918年時点ですでに「兩岸二里餘」の桜が存在した観察記録**を加える定点。②[BOOK-153](BOOK-153.md)（1919・遠足の栞「千川用水…の兩岸二里餘に亙り櫻樹を多く栽植し、新小金井の稱あり」）の**1年前の、ほぼ同一表現の観察**で、千川堤桜の「新小金井」呼称と桜並木の成立が1918年（遅くとも）まで遡ることを裏付ける。③[GOV-294](../gov/GOV-294.md)（1936・千川堤の櫻花）までの戦間期の連続記録の起点側を1年前倒しするdatapoint。ガイドブックの宣伝文であることを踏まえ、植樹主体・年次の特定には使わない（断定しない）。〕
- **同書の千川系のその他の記述〔確認・参考〕**: 同書の武蔵野鉄道沿線項には保谷駅・石神井駅（「石神井城址西南三寳寺の池」）・所沢駅等の記述があり、**石神井駅項の「三寳寺の池」の言及**は[GAZ-057](../gazetteers/GAZ-057.md)（風土記稿の「石神井村三寶寺の池水落合」）・[GOV-257](../gov/GOV-257.md)（1931石神井村現状調査・石神井川水源三宝寺池）と併せ、三宝寺池の水源認識の通時系列の参考資料（千川用水の水源観察〔[BOOK-181](BOOK-181.md)の1920年文言〕の周辺情報として位置づける）。
