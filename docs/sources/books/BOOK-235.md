# [BOOK-235] 小平市史編さん委員会編集『小平市史 地理・考古・民俗編』（2013）〔境水衛所の水死の聞き取り文言確定・大堀旧呼称・小平水衛所の衛視と浚渫の町予算〕

- **書誌〔確認: ADEAC目録詳細頁・2026-11-22取得〕**: 『**小平市史 地理・考古・民俗編**』（**小平市史編さん委員会/編集・小平市/発行・出版年＝平成25年3月29日〔2013-03-29〕・数量881p・付図2枚**）。こだいらデジタルアーカイブ目録ID **mp000010-100010**・**CC BY（表示）4.0**・**テキスト一覧の公開あり**。[目録](https://adeac.jp/kodaira-lib/catalog/mp000010-100010)。〔通史3編（近世編 mp000010-100020＝[BOOK-234](BOOK-234.md)・近現代編 mp000010-100030）と同じアーカイブ〕
- **「地元の方を訪ねて（その十三）岡田久義氏大いに語る」〔直接確認: texthtml ht004930（pp.848-852・民俗編巻末資料）・第254回取得・平成2年7月15日号の全文〕**: 
  - **境水衛所の水死体文言（前後文脈まで確定）**: 「**時々、酔っ払いが大堀に落ちて一命を失うことも珍らしいことではない、上水の水流は下から盛り上がり湧水の様な状態でゆっくりと淀みながら流れ、水路壁の両側が削り取られ湾曲になっており、一たん潜ってしまうと水圧も手伝って再び浮上しない構造になっている為ではないでしょうか。水死体は、千川用水が分岐する境水衛所で引き揚げられ、夢の跡の静けさだけが残り、時は過ぎてゆくということでしょうかね。（文責・庄司）**」＝**①水死の主体＝花見時の「酔っ払い」（前文＝小金井桜の「ドンチャン騒ぎ」の描写に続く）、②玉川上水（大堀）の水流＝「下から盛り上がり湧水の様な状態」「水路壁の両側が削り取られ湾曲」（断面形の目撃証言）、③「一たん潜ってしまうと水圧も手伝って再び浮上しない構造」＝溺水の機構についての観察、④水死体引き揚げ場所＝「千川用水が分岐する境水衛所」（＝玉川上水の境分水点・水衛所〔番所〕）**〔当初スニペットでは「夢の跡」の意味が不明だったが、全文では桜の群衆と酔っ払いの水死の前後文脈に確定。落命の年代・特定事例の断定は不可（聞き取り者の回想で年代不記載）〕
  - **「大堀」＝玉川上水の小平市域旧呼称（〔対照表〕新 row の根拠文言）**: 「**此の辺では分水を堀と言い、上水は大堀と呼んでおり、玉川上水と呼ぶようになったのは戦後のことですよ。ですから鈴木堀とか大沼田は大岱田堀と呼び、田無堀というように、「堀」という名称を使っておったんです**」＝**玉川上水＝「大堀」、その分水＝「堀」（鈴木堀・大岱田堀〔大沼田〕・田無堀）という呼称体系。専門家の記述ではなく古老の聞き取りによる地元の言語使用の記録であり、千川上水（＝玉川上水からの分水系）の呼称史の記録として扱う。**〔「玉川上水と呼ぶようになったのは戦後のこと」という意識は、当repoの千川上水→千川用水呼称遷移（名称の変遷）系の記録（[BOOK-234](BOOK-234.md)の水衛所文言・〔対照表〕の名称行）と対応する。聞き取り対象は鈴木新田の古老＝千川上水沿いの集落〕
  - **田圃の消滅と水利権の東京府委譲・不正事件**: 「**田圃は明治三十六年頃まであったんですが、東京の人口が増加したことにより、田圃の水を売ってくれとの要請があり東京府に水利権を委譲して以来、姿を消したんです。譲渡をめぐって不正事件が発覚した**」＝**鈴木新田の田圃＝明治36年（1903）頃まで、水利権の東京府への委譲を境に消滅したという記憶。玉川上水の水利用の明治期転換の聞き取り記録（千川上水系でない点に注意）。「不正事件」の詳細・内容は風聞の域を出ないため、事実として断定せず「不正事件が発覚した」という文言の存在のみ記録する**〔当時を知る人は「数年前に故人になられました」と続き、検証の余地が失われた旨の本文〕
  - **沼ざらい（堀の清掃）の回数とホタル**: 「**昔は桜橋の所まで春、秋の二回沼ざらいをしたものです。四、五年前までは前庭にある堀には六月頃、随分とホタルが飛び交ったものですよ。しかし、以前から源氏ボタルはおりませんから、平家ボタルですね。水流さえ戻れば復元できます**」＝**大岱田堀（大沼田用水）の沼ざらい（春・秋の年2回）＋平家ボタルの記憶（源氏ボタルはいなかったという区別まで語られている）**〔当repoの谷端川・神田川系のホタル・水質証言と同型の、昭和後期までの清流が語られた証言〕
  - **鈴木新田の沿革**: 開拓は小金井貫井村名主鈴木利左衛門、上鈴木（現上水本町）・下鈴木（野中新田善兵衛門組＝現天神町・花小金井南町）・堀端鈴木（現御幸町）から成る、稲荷神社の遷祀（享保9年〔1724〕9月）・宝寿院の観請（享保16年〔1726〕）＝**千川上水取水樋に隣接する鈴木新田の開発主体と村構成の本文文言（[BOOK-234](BOOK-234.md)の開発史項と時期対応）**
- **「地元の方を訪ねて（その十四）島村繁治氏大いに語る」〔直接確認: texthtml ht004940（pp.852-855・民俗編巻末資料）・第254回取得・平成5年7月18日号の全文〕**:
  - **小平水衛所・境水衛所の「衛視による厳重な監視」と「触らぬ神」意識**: 「**玉川上水に対するイメージは上水沿線居住者に限らず我々同様、お上の水ですからチリ、芥類を流さないことと撤去作業も頻繁にしており、小平水衛所、境水衛所等で衛視によって厳重に監視、監督され管理しておったものですから親しみどころか触らぬ神意識が一般的にそう感じていたと思いますがね。**」＝**「小平水衛所」という施設名の本文確定（第251回はスニペット文言・今回全文で確定）＋「衛視」という監視人員の文言＋庶民側の「触らぬ神」意識＝水衛所の管理・監視の実像と、庶民側の心理の両面の文言**〔[BLOG-220](../blogs/BLOG-220.md)（境水衛所）・[BOOK-234](BOOK-234.md)（水衛所項）に、被管理者側の視点からの心性面の補強。水衛所＝後の水道局系列の施設という公記録の系譜はそのまま、聞き取りの記憶面の出典として併記できる**〕
  - **鈴木用水を飲料水にしていた濾過の実務**: 「**鈴木用水は開渠で上流から耕地を経て来るのでどんなものが流れてくるものやら、それを飲料水として利用していたもので大変だったんです。…先祖は酒造元から四斗樽を求め多摩川へ行って砂と砂利を買ってきて四層、五層にも砂と砂利とを積み重ね分水が使用されない早朝の綺麗な水を樽に汲み取り濾過して杉の葉を差し挟んだ底下穴からのものを飲料水としていた**」＝**千川上水系の開渠用水（鈴木用水＝大岱田堀系の分水か、その枝のいずれかにあたるかの特定は断定しない）を飲料水として使う家庭レベルの砂礫濾過（四斗樽に多摩川の砂と砂利を四〜五層に積む）の実務記憶（早朝汲み＝「分水が使用されない早朝の綺麗な水」）**〔当repoの千川上水の上水→用水転換の各種文言と対応する、末端利用の実態記録。井戸掘削の困難（ガス充満）という地域水文の文言も含む〕
  - **年一回の浚渫を町予算で・全長60キロ**: 「**生産組合員が年一回水路に詰った泥やゴミ、芥類を取り除く浚渫作業をするわけですが、それには小平町予算として計上され全域区内全長六〇キロの用水路を復元し排除物は外へ運んで捨てるという徹底した管理を施しておったんです。**」＝**聞き取り時点（平成5年＝1993より遡る昭和戦後期の回想）で、小平町（1943市制以前またはその後の市）の予算計上による年一回の全域浚渫＝用水路網が行政の維持管理対象だった実態**〔「小平町」という表現が市制（昭和18年・1943）以前の記憶を指すか、市制後も続いた慣称かの特定はせず、聞き取り原文のまま引用する〕
  - **「大部分が暗渠」**: 「**現在は、処所に用水路が見え隠れしているが原形を留めているのは極めて限られ、深さも浅く幅も狭くなっており大部分が暗渠になっている所が多くなってますね。**」＝**平成5年（1993）時点の小平市域の用水路暗渠化の進行度に関する当事者の観察**〔当repoの千川上水暗渠化史（各年代の暗渠化時期の根拠群）に、1993年時点の総括的観察として加える。全体の数値化を含まない観察値のため、他の定量資料と併記して用いる〕
- **意義〔観察〕**: [BOOK-234](BOOK-234.md)（近世編）と合わせ、**千川上水の上流側（取水樋・分水口・水衛所）域の自治体史3編がCC BY・テキスト公開でADEACに全文閲覧可能**なことが確定した。境水衛所の水死の聞き取りは水衛所という管理拠点の記憶として、また「大堀」呼称は土着の言語使用の記録として残る〔水防・水利行政とは別の位相での川の記憶〕。
