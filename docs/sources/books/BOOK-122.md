# [BOOK-122] 武蔵野歴史地理 第1冊（1930年）— 千川堤桜の植樹主体・品種の記録

- **書誌〔確認〕**: 高橋源一郎編『武蔵野歴史地理』**第1冊**（昭和5年・1930年・武蔵野歴史地理学会）。北豊島郡地方（東京北郊）の村別地誌。NDL次世代デジタルライブラリー [book/1178635](https://lab.ndl.go.jp/dl/book/1178635)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **中新井村「千川用水と新櫻名所」〔確認・repo初出の植樹主体・品種〕**: ①「**此千川用水べり、練馬停車場の近くに一里半ばかりも連なつて稚櫻が植ゑてある。是は大正の初年、中新井軍人會や靑年會で植ゑたもので、花の種類は八重と吉野とある**」＝**千川堤の桜の植樹主体（中新井軍人会・青年会）・品種（八重・吉野）・範囲（練馬停車場近くに一里半）の1930年時点の記録**。〔[BLOG-101](../blogs/BLOG-101.md)（千川堤植櫻楓碑・**大正4年11月**・中新井・下練馬・長崎・上板橋4村の大礼記念植樹）と同一事件か別の植樹かは本文のみでは確定できない。「大正の初年」の年幅・碑の4村合同植樹との関係は原文照合・碑文照合課題〕②千川用水の沿革として「元祿九年江戶の商人德兵衞、太兵衞二人の請負ひて堀鑿したるもの…此用水興廢屢あり、**近くは岩崎氏巢鴨別邸の專用水となつたが、今は瀧野川を經て王子町に落して居る**」＝**岩崎家巣鴨別邸の専用水化→瀧野川経由の王子落としという流末処理の1930年の確認**〔既収録系統（[GAZ-002](../gazetteers/GAZ-002.md)千川用水の王子合流等）の同時点観察として裏付け〕。
- **長崎町〔確認〕**: 「町の殆ど中央に**谷端川の小低地**があるけれども大體は陸田の地」＝[GOV-165](../gov/GOV-165.md)（1931・「谷端川ハ町ノ中央ヲ貫通シ」）に先行する1930年の同系統の地形観察。〔OCR要照合〕
- **慶応期反射炉の水利〔確認・既知系統の確認〕**: 瀧野川（今の醸造試験所内）の反射炉について「**千川上水を引入れて水車運轉の用に供しよう**と云ふ計畫」「作事奉行の方では千川上水は江戸御用屋敷及び江戸城西丸御用のもので其の障になる」と陸军方（小栗上野介等）と作事奉行の交渉を記す＝**慶応期反射炉の千川上水利用計画と上水保護の対立の本文記述**〔[GOV-144](../gov/GOV-144.md)・[BOOK-077](BOOK-077.md)（慶応期反射炉水力）文脈の独立確認〕。
