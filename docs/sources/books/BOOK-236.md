- **「すいどっぱた（千川上水）」〔直接確認: texthtml本文取得・repo初出〕**: 「馬と追はぎ」の章（15～16ページ）で「**帰り道、冷酒を一ぱいひっかけて、目白の坂を通り江古田近くまで戻る頃は、日もとっぷりと暮れてしまいます。一つの集落を過ぎると、次の部落までは一軒の家も無く、鼻を摘まれてもわからぬ位真暗です。すいどっぱた（千川上水）なども恐ろしく淋しい道でした。**」＝**①千川上水（中村区間）が「すいどっぱた」と呼ばれていた回想文言の直接確認、②江戸〜東京へ野菜せり売りに出た荷馬車が目白の坂・江古田近く経由で中村へ戻る流通経路の記録、③「恐ろしく淋しい道」＝千川上水沿道が夜間無人の恐怖の道だったという記憶**〔「水道端」の音写表現とみられる（[対照表](../../地名・河川名対照表.md)の水道端行へ追加：滝野川区間・板橋区大谷口・関口（GAZ-076）の用例に、**千川上水沿い（練馬区中村側）の音写用例**を加える。漢字表記の原典表記は照合まで断定しない）〕

- **追い剥ぎ被害譚〔直接確認: texthtml本文取得・repo初出候補〕**: 同章の続きで「**ポックリポックリひずめの音を聞きながら、荷台でうとうとしていた父親は、馬の異常に気がつき、所辺をすかして見ますと黒い人影が近づいて来ます。…追はぎは「金を出せ！」とばかりに刃物をちらつかせてすごんでいます。**」→父親は「**三十六計逃げるにしかず……**」と有り金全部を投げ出し「**傍にいる馬の長い顔にしがみついたまゝ、一生懸命逃げました。「ナンマンダブ……」とお題目を唱えながら、やっとの事で家にたどり着いたと言うことです。**」＝**明治後期（章冒頭「明治後期のころ」）に千川上水・江古田方面の帰路で当家の父親が追い剥ぎに襲われたという被害の一次伝承**〔千川上水沿道（中村〜江古田間）の夜間の治安・荷馬車の小銭を狙う追い剥ぎの実在を示す生活史側の証言として、[BOOK-179](BOOK-179.md)（1922年千川用水通水観察）等の水系記録に治安・流通史の面を加える。伝承の細部は事実確定をしない〕
- **千川上水から引いた小川の生態〔本文検索スニペット確認〕**: 「螢とり」の章で「**千川上水からひいた小川が、どじょう、だぼ、小えび、川にな、しじみ、げんごろう等泳がせながら、竹藪の西側…**」＝**千川上水から引いた小川（＝中村への分水・引水路）の水生生物の回想**〔A. 千川上水の引水路が実際に通水し生物相を維持していたという昭和初期の観察文言候補。B. 「川にな」の原字は照合待ち（川蜷候補）〕
- **川浚いと川刈り〔第251回・第252回は本文検索スニペット確認 → 第254回にtexthtml ht000240（p.21）で本文全文直接確認・章題「川浚いと川刈り」＝目次階層は「新屋敷の子供歳時記」配下〕**: 「**千川用水は、元祿九年（一六九五年）に玉川上水から分水され、享保七年（一七二二年）には、灌漑用に使川することが許されたそうです。中村にも、千川からひいた小川が幾筋か流れていました。稲作もする農家にとって、用水は大切な流れです。冬の間中、何処かで眠っていたお寺の堀の亀たちが、元気に動き始める頃、村中力を合せて川浚いを行います。霜解けの岸辺から崩れ落ちた土や、枯草を取り除いて、やがて来る「代かき」「田植え」に備えて手入れをはじめるのです。又、秋の彼岸の頃には「川刈り」と云って、春と同様に灌漑用水の手人れをしたものでした。**」＝**①元禄9年（1695）分水・享保7年（1722）「灌漑用に…することが許された」の年代枠が回想記の本文として確定（テキスト化本文の「使川」「手人れ」は「使用」「手入れ」のOCR誤読とみられるため、引用は原文表記のまま明記）、②春の「川浚い」（霜解け後・代かき・田植え前）＋秋彼岸の「川刈り」＝灌漑用水の手入れが年2回のサイクルで行われていた記憶、③「村中力を合せて」＝村規模の共同的作業、④「お寺の堀の亀」＝堀の生態の小景**〔千川上水系末端（中村）の年2回維持サイクル。上流の小平では[BOOK-235](BOOK-235.md)島村章の「年一回…浚渫作業」（生産組合員・町予算・全長六〇キロ）＝行政・組織側の浚渫、本書は農村の村規模の季節行事側の川浚い・川刈りで、系統の異なる維持実務の対比になる。元禄9年・享保7年の年代枠は既収録（[GAZ-048](../gazetteers/GAZ-048.md)・[BOOK-234](BOOK-234.md)）と一致〕
- **意義〔観察〕**: ①**千川上水の取水樋から中流域にあたる中村（旧中新井村大字中・現在の中村北・中村南地域）の水環境について、大正12年生まれの著者の回想が丸ごと一冊として保存・公開されている**（千川上水沿川の年代・位置確定の回想記として [GOV-418](../gov/GOV-418.md)（千川上水記録フィルム・昭和27年・中村北・豊玉北のコマ）と並ぶ文字側の資料）。②「馬と追はぎ」の追い剥ぎ譚は、千川上水沿道が**荷馬車の流通路（小石川・牛込への野菜せり売り往復）であり同時に夜間の追い剥ぎの危険地だった**ことを示す数少ない生活史証言。③「すいどっぱた」「千川からひいた小川」は、[GAZ-064](../gazetteers/GAZ-064.md)（風土記稿の千川上水村境文言）・[PAP-038](../papers/PAP-038.md)・[PAP-039](../papers/PAP-039.md)（中村土地区画整理）などの地誌・研究系に、**生活史側の用水呼称と実感の系統**を接続する。
