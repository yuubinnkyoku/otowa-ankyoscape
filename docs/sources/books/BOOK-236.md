- **千川上水から引いた小川の生態〔本文検索スニペット確認〕**: 「螢とり」の章で「**千川上水からひいた小川が、どじょう、だぼ、小えび、川にな、しじみ、げんごろう等泳がせながら、竹藪の西側…**」＝**千川上水から引いた小川（＝中村への分水・引水路）の水生生物の回想**〔A. 千川上水の引水路が実際に通水し生物相を維持していたという昭和初期の観察文言候補。B. 「川にな」の原字は照合待ち（川蜷候補）〕
- **川浚いと川刈り〔本文検索スニペット確認〕**: 「**千川用水は、元祿九年（一六九五年）に玉川上水から分水され、享保七年（一七二二年）には…**」＋「**中村にも、千川からひいた小川が幾筋か流れていました。稲作もする農家にとって、用水は大切な流れです。**」＝**①千川用水元禄9年分水・享保7年停止の通説年代の郷土回想での再記、②中村への引水小川の複数筋の存在と農家的用水観の回想**〔元禄9年・享保7年の年代枠は既収録（[GAZ-048](../gazetteers/GAZ-048.md)・[BOOK-234](BOOK-234.md)）と一致〕
- **意義〔観察〕**: ①**千川上水の取水樋から中流域にあたる中村（旧中新井村大字中・現在の中村北・中村南地域）の水環境について、大正12年生まれの著者の回想が丸ごと一冊として保存・公開されている**（千川上水沿川の年代・位置確定の回想記として [GOV-418](../gov/GOV-418.md)（千川上水記録フィルム・昭和27年・中村北・豊玉北のコマ）と並ぶ文字側の資料）。②「すいどっぱた」「千川からひいた小川」は、[GAZ-064](../gazetteers/GAZ-064.md)（風土記稿の千川上水村境文言）・[PAP-038](../papers/PAP-038.md)・[PAP-039](../papers/PAP-039.md)（中村土地区画整理）などの地誌・研究系に、**生活史側の用水呼称と実感の系統**を接続する。
