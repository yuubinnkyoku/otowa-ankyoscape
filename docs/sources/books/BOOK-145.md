# [BOOK-145] 大井町史（1932）— 寛文期の「境新田より分水する仙川用水」の記録

- **書誌〔確認〕**: 『**大井町史**』（大井町役場編・1932年刊）。NDL次世代デジタルライブラリー [book/1209587](https://lab.ndl.go.jp/dl/book/1209587)。**引用はすべて同館OCRテキスト由来で、文言は原文画像との照合を要する。**
- **品川用水の起源＝寛文2〜4年の細川家屋敷引水〔確認・repo初出の年代つき「仙川用水」文言〕**: 「**これより以前寬文二年に、品川領戶越、蛇窪兩村入會にて細川越中守が抱屋敷(現在の戶越農園の處と云ふ)四萬五千坪を拜領し、同三年より四年に亙り、玉川上水を境新田より分水する仙川用水を、野川村にて分水することゝし、水路を掘り、庭內に引入れた。其後寛文六年に及び、細川家にて水不用となりたる爲め、この水を用水に使用したき旨を出願し、同七年に至り品川傳馬宿並に宿附定助〓の村々救濟として許可されたのである。然るにこの小堀は殆ど水無く、同九年六月に至り官費を以て此の小堀を擴張することになり、江戶西紺屋町尾張屋金兵衞外四人にて請負ひ之を開鑿した**」〔**①寛文2年（1662）: 戸越・蛇窪両村入会で細川越中守が抱屋敷45,000坪を拝領（現在の戸越農園）、②寛文3〜4年（1663-64）: 「玉川上水を境新田より分水する仙川用水」を野川村で分水して屋敷内に引水、③寛文6年: 細川家の水不要化→用水使用の出願、④寛文7年: 品川伝馬宿ほか宿附定助の村々救済として許可、⑤寛文9年6月: 官費で小堀拡張（江戸西紺屋町尾張屋金兵衞外4人の請負）＝品川用水の開鑿**〕＝**「仙川用水」の名称が寛文2〜4年（1662-65）の玉川上水分水（境新田分水）に遡るとする町史の記述**。
- **品川用水の流路記事〔確認〕**: 同条に「**品川用水は多摩郡境村地內に取入口を設け、玉川上水より分水し、同郡數村を過ぎ、船橋より荏原郡世田ケ谷町に入り、弦卷、世田ヶ谷新町、上下馬引澤、碑文谷を經、戶越地藏の辻に至つて二派に分れ、一は桐ケ谷、大崎を經、品川に至り、他は荏原町字中延、下蛇窪境にて內堀用水となり、上蛇窪を經て本町に入り、更に分派して灌漑に用ひられたものであつて、其の延長七里餘**」＝境村取入口→世田ヶ谷町の「弦卷」→馬引澤・碑文谷→戸越地蔵の辻で二派→品川／中延・蛇窪方面という流路。〔**「弦卷」＝世田ヶ谷町の町名（弦巻）で本repo対象の弦巻川とは別地名（同名の町名の用例として対照表参照）。「境新田」「境村」＝玉川上水沿いの境新田・境村（仙川村の近傍）**〕
- **碑衾町誌の同記事〔確認・対照〕**: 『**碑衾町誌**』（市郡合併記念・1932年刊・[book/1879888](https://lab.ndl.go.jp/dl/book/1879888)・未登録）にもほぼ同文の記事があり、末尾に「**(以上、品川町史)**」と明記＝碑衾町誌の記事は**品川町史を経由した二次記録**と分かる〔品川町史そのもののデジタル化・所在は未確認〕。「これより先寬文二寅年、品川領戶越、蛇窪兩村入會にて、細川越中守へ抱屋敷四萬五千坪を下されたが(今の三井別邸)、庭池に水緣がないので、同二年より四年に亙り、玉川上水を境新田より分水する仙川用水を野川村より分水する事にして、井筋を掘つて庭內に水を引入れたが最初である」＝細川屋敷の比定が碑衾町誌では「今の三井別邸」・大井町史では「現在の戶越農園の處」と食い違う記録**も含まれる。
- **位置づけ〔観察・内容メモ〕**: ①千川上水の元禄9年（1696）起立説（[GAZ-048](../gazetteers/GAZ-048.md)⑩・[GOV-212](../gov/GOV-212.md)）より30年以上先行する寛文期の「仙川用水」の用例として、**「仙川」を冠する玉川上水分水の系統が千川上水の前に存在した（可能性がある）**ことを示す町史記録。ただし本書の記述の典拠（細川家文書・品川町史の原拠）は未確認で、寛文期の「仙川用水」と千川上水・風土記稿の「仙川用水」（豊島郡側・多磨郡側）の関係（同一水系の前史か・同名の別用水か）は断定できない。②[GAZ-057](../gazetteers/GAZ-057.md)（風土記稿・多磨郡側の仙川用水）の受益村文言・[GOV-302](../gov/GOV-302.md)（明治10年府統計の仙川用水）と併せ、「仙川用水」呼称の通時的・地理的広がりの検討資料。③品川用水の前史として、戸越・蛇窪方面の宅地池への引水→救済用水化という水利用の展開過程の記録。
