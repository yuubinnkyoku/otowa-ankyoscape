# [BOOK-158] 江戸名所花暦（江戸遊覧花暦）— 音羽九丁目橋の丁目体系の由来・護国寺の山号神齢山・蛍の条

## ①護国寺の条〔確認文言・BOOK-155神齡山比定の第2系統〕

- 「頼曰、ここくしい、したんさゆう、**おとはまち、しんれいさん護国寺、石階の左右、音羽町のさき、山号は神齢山、ほんそんめなうせきによい、本尊は馬悩石如意輪観音、唐仏、元禄年中に本堂こんりふ、御建立あり**」＝**山号を「神齢山」と明記する護国寺の縁起記事**＝①[BOOK-155](BOOK-155.md)（蜀山人全集・詞書の神齡山）・[GAZ-027](../gazetteers/GAZ-027.md)（江戸砂子温故名蹟誌「神齢山護国寺領千二百石音羽町」）と3系統一致し、**詞書の山名＝音羽町西隣の護国寺の山号である比定が確定**（第133回課題②の解決）。②本尊＝馬脳石（めのうせき）如意輪観音・唐仏。③「**此地は御薬園なりしを御建主のとき御薬ゑんはくさん、ほんたう園は白山にうつさる**」＝**護国寺の地が元御薬園で、建立時に本薬園を白山に移したという縁起文言**（[GAZ-027](../gazetteers/GAZ-027.md)の元御薬園記録の別系統裏付け・音羽地域の土地利用史の基礎資料）。④「本堂西の方の柱に木目猿の面に似たるあり、俗に是を**猿はしら**と号く」＝猿柱の縁起。

## ②音羽町九丁目の丁目体系の由来〔確認文言・repo初出〕

- 「**都て大江戸の丁数一丁目二丁目は御大城の方を一丁目とさたむるにはまちことゝしもんせん、音羽町は護固寺門前の方を一丁目と定む故に順を追ひて目白のした神田上水へ懸りたるはしは九丁目の橋といふ**」＝①江戸の丁目数えの原則（「御大城の方を一丁目と定める」のが一般）に対し、**音羽町は護国寺門前を一丁目として順に数えるため、目白下の神田上水に掛かる橋が「九丁目の橋」になる**という丁目体系の由来説明＝**音羽九丁目橋（[橋名調査](../../四河川の橋名・橋跡調査.md)の対象橋）の名称の成り立ちの明文（repo初出）**。②「護固寺門前」の表記はOCR由来とみられ原字形の照合を要する。③音羽町の丁目が門前から数えて神田上水に達するまで続く＝**音羽町の町並みが神田上水（白堀）沿いに九丁目まで連続する観察**としても読める（町域の末端の具体化に有用）。

## ③蛍の条〔確認文言・弦巻川流域の蛍の地名の体系〕

- 「**蛍 澤さは 蛍川とも云、なかさん、さきそうりんし、谷中三崎宗林寺の地なり、他のとくらふはなはたれは光り甚しく形も大ひなり**」＝蛍の名所として沢（蛍川ともいう）を谷中三崎の宗林寺の地とする記事＝**「蛍川」の地名の用例（谷中側）**。
- 「**すかたみおもけけはし〔ママ〕、頃め見の橋、伝の橋とも云、落合すかたみ橋より三丁はかり、かはかみしやうすいかは、川上の上水川と雑司谷の細流との間なり**」＝①**姿見橋（すかたみはし・頃見の橋・伝の橋ともいう）が落合にあり、そこから三丁ほどの所に蛍の名所**があるという記事。②「**川上の上水川と雑司谷の細流との間**」＝**神田上水（上水川）と「雑司谷の細流」（＝弦巻川と解せる）との間の土地に蛍が生息するという観察文言**＝弦巻川と神田上水の並行区間の土地利用（蛍の生息地）の記録（[BOOK-144](BOOK-144.md)雑司ヶ谷八景の「絃卷川螢」の系統を、地形的に具体化する文言）。③「**この川の上のいちまいす、ゆちゆうおほいは、ところに一枚岩と唱て水中に大麦あり**」＝川の中の一枚岩の伝承（「大麦あり」の判読は崩れ要照合）＝弦巻川（かは雑司谷の細流）の河床の一枚岩の口碑。
- 「**りうけいはし、かは小日向龍慶橋の川**」＝蛍の条の関連記事として小日向の**龍慶橋の川**（立慶橋・[BOOK-157](BOOK-157.md)安政2年「隆慶橋手前」・[BOOK-156](BOOK-156.md)対校の橋）を掲げる＝**江戸川（神田川）の蛍の名所としての龍慶橋周辺の記録**（橋名表記の「龍慶」の用例。立慶橋との表記の揺れの対校資料）。
