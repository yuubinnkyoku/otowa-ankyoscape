# [BOOK-211] 鳥越皓之編『里川の可能性』（2006）〔repo初出・「里川」概念の源典の書誌登録〕

- **書誌〔確認: NDL書誌・2026-11-19〕**: 鳥越皓之**編者代表**『**里川の可能性―利水・治水・守水を共有する**』、**新曜社、2006年**、**ISBN 4-7885-1024-3**〔NDL書誌で直接確認〕。同編者の『水と人の環境史―琵琶湖報告書』（鳥越皓之・嘉田由紀子編・お茶の水書房）は[PAP-083](../papers/PAP-083.md)参考文献に併記されている。
- **位置づけ〔観察〕**: [PAP-083](../papers/PAP-083.md)（亀岡岳志2017「東京の「里川」の変容」）は**論文題名の用語「里川」を用い、註13で本書を引用**＝都市河川・用排水路研究における「里川」概念（人と関わりながら利用されてきた川の概念・亀岡註14が「里山」「里海」との類推でイメージしやすい旨を注記）の**源典**。千川上水中新井分水＝「里川」の変容としての分析枠組みは本書の概念系から来ており、repoの千川用水系の位置づけ（農村水利から都市溝渠への転換）の理論的文脈を与える。亀岡論文の「利水・治水」に併置される「守水」（水を守る概念）も本書のタイトル由来。
- **制限・未解決**: ①本文未取得＝「里川」の定義文の文言・千川上水への言及の有無は未確認。②本書と千川用水関連（千川上水は本書の事例か）の関係は本文取得待ち。③本書の細目（各章の執筆者・対象流域）は未確認。
