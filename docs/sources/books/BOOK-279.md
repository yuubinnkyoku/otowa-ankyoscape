# [BOOK-279] 滑川邦夫『保谷市史料所在目録・蓮見家所蔵文書目録・人別関係文書抄』（2012）〔保谷側の村文書の所在目録〕

## 書誌〔所在のみ: NDL SRU・2026-11-22〕

- **滑川邦夫 著**「**保谷市史料所在目録・蓮見家所蔵文書目録・人別関係文書抄**」（**2012**）・**37 p ; 30 cm**＝NDL所蔵（NDL書誌 R100000002-I033695743・JPNO 24048283）。

## 意義〔観察〕

- 滑川邦夫氏の**田無村（[PAP-103](../papers/PAP-103.md)・下田家文書〔[BOOK-270](BOOK-270.md)〕）に対する旧保谷市側（千川上水圏の村＝[GOV-501](../gov/GOV-501.md)の関野分水圏）の史料所在目録**＝**田無村と保谷が水系・祭祀（[ORG-038](../org/ORG-038.md)の保谷の御嶽山代参講）・人別で接続する際の保谷側の文書の所在**を示す。蓮見家＝保谷の旧家と推定されるが家の同定は本文未見のため断定しない。
