# [BOOK-201] 觀瀾集 [3]（三宅緝明〔観瀾〕著・写本）— 秋遊記の所在特定と1706年の瀧野川遊覧記録

- **書誌〔確認〕**: NDL次世代デジタルライブラリー [book/2590573](https://lab.ndl.go.jp/dl/book/2590573)。目録書誌＝**title「觀瀾集」・volume「[3]」・responsibility「三宅緝明 [著]」・publisher「写」・published「[1--」**（刊年不記載の写本）。**「三宅緝明」は三宅観瀾（観瀬）の諱**であり、目録責任表示自体が著者＝三宅観瀬説（[BOOK-112](BOOK-112.md)・[BOOK-122](BOOK-122.md)の「儒者三宅觀瀾」記事との一致）を支持する〔成立年代・巻冊構成の書誌確定は未了〕。
- **「十四 秋遊記」の所在と本文〔確認・OCR崩れ甚大〕**: [3]所収の紀行文。くずし字OCRテキストで「**丙戌之秋。與二三寮老。游于郊北。臨所謂瀧野川道灌山者。川乃源頼朝。稱兵進以置陣之所。而山亦太田道灌之星夫〔OCR崩れ・原字要照合〕…**」以下、「**両崖□絶並峙…如奔電鳴如夏雷**」（OCR崩れ・[GOV-198](../gov/GOV-198.md)第173回追記の1931年引く「兩岸峭絕並峙…」の原形候補）、「**府中人士自春亙秋。来遊于此**」等が読める。**〔確認〕丙戌＝宝永3年（1706）**＝[BOOK-122](BOOK-122.md)（武蔵野歴史地理・1930）「今より約二百二三十年前の寶永三年儒者三宅觀瀾は此處に遊んで秋遊記といふ文を作つた」・[BOOK-112](BOOK-112.md)（滝野川町誌・1933）の宝永3年記事に一致**＝第173回ノート課題④（観瀬『秋遊記』の所在・実冊確認）の解決**（第174回ノートの「lab検索でデジタル化なし」という探索結果の訂正になる：keyword=「秋遊記」検索の2番目に本書が現れる）。
- **datapoint①＝頼朝陣所を「川」として記し橋名を記さない〔確認・陰性＝中立witness〕**: 秋遊記本文中に**松橋・板橋の橋名の言及はない**（fulltext検索で陰性）。頼朝について「**川乃源頼朝。稱兵進以置陣之所**」＝**陣所を川（瀧野川＝石神井川）として記録**＝[対照表](../../地名・河川名対照表.md)松橋行の「松橋/板橋」対立（第2軸〔GAZ-096～GAZ-098ほか〕）について、**盛衰記系（松橋）・長門本系（板橋）のいずれの橋名も採らない1706年時点の中立witness**〔斜に位置する観察記録であり、両橋名説の優劣を判定する材料ではない〕。
- **datapoint②＝「瀧野川道灌山」の1706年固定〔確認〕**: 「臨所謂瀧野川道灌山」という一語で**1706年時点での「道灌山」の称呼の使用例**＝[GAZ-094](../gazetteers/GAZ-094.md)（江戸往古図説・1800-01系想定）・[GOV-198](../gov/GOV-198.md)第173回追記（1931「觀瀾著の秋遊記には此邊を瀧野川道灌山と稱し」）の間を埋める本文側の定点〔OCR・原字照合必須〕。
- **datapoint③＝楓・紅葉への言及なし〔確認・陰性〕**: 秋遊記本文中に**楓・紅葉の語は確認できない**（fulltext検索で陰性）＝[BOOK-122](BOOK-122.md)「觀瀾の秋遊記中には楓樹に關して一言もいふところがない。是は寛永七年金剛寺の住僧阿闍梨看印なるものが植ゑ始めたと傳へるけれども、如何なものか」・[GOV-198](../gov/GOV-198.md)（看印寛永7年植樹説）という1930年代書物の本文側観察の補強＝**1706年時点で紅葉が目立たなかった（あるいは記録に値しなかった）可能性を支持する陰性材料**（書き手の関心の問題でもあり、植樹説の年次そのものの証否には使わない）。
- **datapoint④＝遊覧地としての瀧野川〔確認〕**: 「**府中人士自春亙秋。来遊于此**」＝府中（江戸）の人士が春から秋まで来遊した旨＝[BOOK-122](BOOK-122.md)「江戶府中の人士春より秋に亙つて此處に來遊するものが多いと記してある。是にて飛鳥山が遊覽地となる以前、早く此處は都人士遊觀逍遙の地となつて居つた」の元記事＝**飛鳥山（享保期遊覧地化）以前の瀧野川谷の遊覧地としての1706年観察**。
