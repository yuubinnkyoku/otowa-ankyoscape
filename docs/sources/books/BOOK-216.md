# [BOOK-216] 家ふれ窓の記（破窓記）（城東山人・写本・安政2年序）— 安政地震の江戸川沿いの地割れ実見と天明2年地震記録の本文側確認〔repo初出・第211回〕

- **書誌〔確認・同一作品の異名書誌の並存〕**: NDL次世代デジタルライブラリー [book/2533598](https://lab.ndl.go.jp/dl/book/2533598)＝メタ「**家ふれ窓の記**／城東山人／写本」（45丁分のOCR・末尾覚書を含む）。本文冒頭の題号OCRは「実東原家ふれ窓の記」〔崩れ候補〕、序の題は「**破窓記序**」、序末に「**安政二年十一月十日**」の日付と作者号（「不立亭のあるじ」〔OCR候補〕）・「元どの（水戸殿）のおほきのもとにすめるふるふみや」の住所自認がある。NDLサーチには本作品の書誌が**異名で複数並存**する: ①「**破窓記**」責任表示「**日一亭**」・水上德正写・安政2〔1855〕（[R100000143-I1000101768](https://ndlsearch.ndl.go.jp/books/R100000143-I1000101768)）、②「**屋ふれ窓の記**」城東山人〔著〕・水上徳正〔写〕・安政2〔1855〕（[R100000136-I1970867909819536392](https://ndlsearch.ndl.go.jp/books/R100000136-I1970867909819536392)）、③「**やふれ窓の記**」水上徳正〔写〕・安政2〔1855〕（[R100000136-I1971712334774012213](https://ndlsearch.ndl.go.jp/books/R100000136-I1971712334774012213)）、④「**やふれ窓の記**」城東山人〔著〕（[R000000050-I000068870](https://ndlsearch.ndl.go.jp/books/R000000050-I000068870)）。〔**大日本地名辞書（[GAZ-065](../gazetteers/GAZ-065.md)）が〔破窓記〕として引用する天明2年地震文言が本書の覚書に実在することで、辞書引用の「破窓記」＝本書（家ふれ窓の記・屋ふれ窓の記系）と同定する根拠が成立**。「日一亭」（破窓記書誌）と「城東山人」（屋ふれ窓の記書誌）は同一人物の異号の可能性があるが、**責任表示の異同・本文の題号の揺れを含め確定はしない**（要原画像・書誌原本照合）〕
- **巻構造〔確認・OCR候補〕**: 序＋標目（「地震起りし次第」以下の目録）＋安政2年（1855）10月2日の大地震当日からの日記（江戸市中の変死・出火・火元・御救小屋等の集成）＋地震・天変の引用層（元禄16年＝折〔焚〕柴の記〔新井白石〕の言及・後見草〔鶏斎（OCR候補）〕の言及）＋末尾の**天明2年（1782）7月14日の地震覚書**（「亀岡石見〔OCR候補〕が眼前に記したる覚書に合冊して…名つけし写本也」）＝**安政地震の一次記録に天明2年地震の覚書を合冊した写本構造**。
- **安政2年10月11日の見廻りルート＝江戸川（小日向区間）沿いの地割れの実見文言〔文言候補・repo初出〕**: 「**百間長屋の前を過つゝ江戸川の北へら（北べり候補・OCR）を行に龍慶橋の上（かみ候補）、中の橋より石切橋のあはひ、あるは一条あるハ二条にいたく地の裂したる跡長しと見ゆ**」＝**江戸川の北岸（小日向側）の龍慶橋の上流側・中の橋〜石切橋の区間に、1〜2条の甚だしい長い地割れの跡が残っていたという地震後9日目（10月2日地震→10月11日見廻り）の実見記録**。前後の行程＝「**行々水道橋をわたりつゝ水府公のみあたりを窺ふに御館を初めて御築地に至るまでつよく**」（水道橋を渡り水戸上屋敷＝後楽園の御館〜御築地の被災を観察）→百間長屋の前→江戸川北岸→「**小日向の荒木坂**」（作者の親族の酒商・松本屋忠左衛門を訪ねる文言）→「**小石川伝通院前通り**より**冨坂**を越えて本郷」＝**水道橋〜江戸川沿い〜荒木坂〜伝通院前〜冨坂〜本郷の歩行ルートで、江戸川（白堀区間の下流側）の北岸を下流から上流へ実際に遡った観察**。〔①「中の橋より石切橋のあはひ」＝中の橋〜石切橋区間が位置アンカーとして実測される江戸期の一次用例で、**立慶橋（龍慶橋）との中の橋の並び（[GAZ-049](../gazetteers/GAZ-049.md)「立慶橋と石切橋の中なる橋」）・紫鯉の増水時移動（[BOOK-151](BOOK-151.md)「川下竜慶橋邊へさがる…水上石切橋邊へ登る」）と石切橋＝水上・竜慶橋＝川下の前後関係が一致**＝本書の見廻りルート（下流から上流へ遡行）と整合する位置解釈。②江戸川通りの道路割れ・河岸の2尺段違い（[BOOK-167](BOOK-167.md)・なゐの後見草経由）の**同一地震の別観察記事として対校**が成立。③百間長屋は「小日向牛天神下百間長屋際、隆慶橋之東堀端まで燒る」〔[BOOK-168](BOOK-168.md)正徳3年〕・「小石川上富坂…水戶中納言樣、但し百間長屋少々殘る」〔[BOOK-214](BOOK-214.md)享保2年〕の既登録の百間長屋の位置をめぐる係争に、**百間長屋の前を通って江戸川の北岸に出た**という本書の行程文言が参考対校点を追加（百間長屋の位置は従来通り確定保留）〕
- **水府公（水戸上屋敷＝後楽園）の被災観察〔文言候補〕**: 「行々水道橋をわたりつゝ水府公のみあたりを窺ふに**御館を初めて御築地に至るまでつよく**」＋藤田誠之進（誠之進＝虎之輔改名・若年寄海防掛〔OCR候補〕）・戸田忠太夫両士の震死の言及（「誠の忠の両士」）＝**安政地震での小石川後楽園側（神田上水の流入する屋敷）の被災と水戸家重臣の死を記す周辺記録**（水戸家系の記述は水系史料ではなく水府公屋敷＝神田上水取水屋敷の被災の観察文言として参考登録。人名の詳細はOCR崩れ大・原画像照合前提で採用確定しない）。
