# [BOOK-065] 『練馬区史』第五編補説「千川上水の歴史」

- **書誌〔確認〕**：練馬区史編さん委員会『練馬区史』。編さんは昭和29年12月3日の練馬区史編さん委員会条例（委員長・区長須田操）に始まり、**区独立十周年の昭和32年完成を目標**とした（あとがき頁。専門家として早稲田大学滝口宏教授に依頼）。練馬区歴史資料デジタルアーカイブ（i-repository、www2.i-repository.net/contents/myc/）で本文テキストが公開され、第五編補説「千川上水の歴史」はjunenshi_honcho5.xhtml。2026-11-11時点でopen_urlによる直接取得は遮断されており、**検索スニペットで確認できた文言**を記録する〔[BLOG-094](../blogs/BLOG-094.md)がsirakigi経由で引用した「練馬区史（昭和32年版）10.53km・橋41」の元本がこの書と同一〕。
- **仙川村説への検討〔確認：スニペット文言〕**：「（御府内上水在絶略記・武蔵通志・新編武蔵風土記稿）これは、仙川村と千川上水を結びつけた説と思われるが、**真偽のほどは明らかでない**。**千川家では、たびたび先祖についての由緒書を提出しているが、この中でも仙川村百姓云々ということにはまつたくふれていない**」〔①[GAZ-016](../gazetteers/GAZ-016.md)・[GAZ-017](../gazetteers/GAZ-017.md)（御府内上水在絶略記等）の仙川村説に対する**区史レベルの批評的検討**の存在（repo初出）。②千川家の由緒書という一次資料群の存在と、その内容が仙川村説を支持しないという指摘。③[BLOG-031](../blogs/BLOG-031.md)（由緒書既出）との照合課題〕。
- **千川名字拝領の文書〔確認：スニペット文言〕**：「徳兵衛（え）千川名字拝領被（二）仰付（一）、此訳、仙川村之名ニ寄り是を御取用イ之由、然**仙の字不宜と千の字ニ御直し**被（二）下置（一）、同役太兵衛（え）も此段奉（レ）願候処、同太兵衛ゟ可（レ）申由、御下知ニ而御座候。此儀ニ依て自ラ上水ノ名目千川上水と唱来、其上**御免駕籠**（…）」〔江戸時代の名字拝領関係文書の引用。「仙の字不宜」による改字の理由付けと御免駕籠までの文言はrepo初出の可能性。外字・返り点を含む引用のため正確な翻刻は原文画像確認要〕。
- **千川家の後裔〔確認：スニペット文言〕**：「千川上水開発の功によつて、徳兵衛、太兵衛の子孫は、代々**上水見廻役**を勤めてきたが、**五代源蔵のときに上水管理の都合という理由で、練馬区北町（…**」〔千川家五代目が練馬区北町に移ったという系譜。スニペット途切れのため以後の全文は未確認。千川家文書（[GOV-038](../gov/GOV-038.md)）との照合が次の課題〕。
- **江戸三上水〔確認：スニペット文言〕**：神田上水・玉川上水に並べて千川上水を「**俗に江戸の三上水と呼ばれて**」いたとする叙述〔「江戸六上水」に対する「三上水」呼称の用例としてrepo初出〕。開削は元禄9年（1696）、玉川上水を上保谷新田から分水。
