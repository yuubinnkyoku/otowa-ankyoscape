# [BOOK-174] 市町村の水道（龜井重麿・1926）— 千川水道會社の営業終期の文言候補〔repo初出・第139回〕

- **書誌〔確認〕**: 龜井重麿（工學博士・八幡製鐵所技師）著『市町村の水道』（早稻田大學出版部・大正15年＝1926年2月刊。奥付文言はOCR列の逆順で要照合）。NDL次世代デジタルライブラリー [book/1019979](https://lab.ndl.go.jp/dl/book/1019979) のOCR全文を確認。**引用文言はOCR由来で要原文照合**。
- **沿革説の採録と保谷村の郡変換の注記〔確認・repo初出の注記〕**: 「**千川上水ハ武藏國新座郡保谷村（明治年間該村ハ北多摩郡ニ變換セラル）地先ニ於テ玉川上水ヲ分岐シ之ヲ巢鴨溜池ニ致ス。沿渠各村落ニ供給シテ市內ニ入リ、本〓、下谷ノ一部ニ給水セシモノナリ**」＝**①武蔵国新座郡保谷村が「明治年間に北多摩郡へ変換された」という郡変換の明示的注記つきの水源記述、②「本〓（本郷候補）、下谷の一部」給水の沿革説**＝保谷村の所属郡の変換（新座郡→北多摩郡）を沿革説の中に明示した稀な例で、[GOV-100](../gov/GOV-100.md)（小平・小川家文書）・[BOOK-173](BOOK-173.md)（「埼玉縣新座郡保谷村」＝1907年時点の旧郡表記）の中間の**郡変換の認識の文献記録**（変換の年次〔明治几年か〕は本書では「明治年間」とのみ。行政記録での確定は次の課題）。
- **廃止→再興→営業終期の文言〔確認・repo初出の営業終期文言〕**: 「**享保七年上水トシテノ供給ヲ廢シ、單ニ田用水トナセシガ、後安永九年再ビ之ヲ興シ、本〓湯島、下谷、淺草等ニ給水セシモ、爾後興廢一ナラズ。明治十三年岩崎彌太郞等千川水道會社ヲ起シ、舊渠ヲ修理開通シ、改良水道給水開始ノ頃迄營業ヲ繼續セリ**」＝**千川水道會社が「改良水道（東京市の改良水道＝淀橋浄水場系）の給水開始の頃まで営業を継続した」**という営業終期の文言＝**廃止・解散の時期を東京市改良水道の給水開始時期（淀橋浄水場の通水は明治31年〜区域拡大の進行期）と関連づけた記述**で、[BOOK-166](BOOK-166.md)（第13版欠載・明治42年）・[BOOK-170](BOOK-170.md)（解散記念品・明治42年12月24日）より**営業終期の説明原理（改良水道への需要の移行）を与える記述**（「改良水道給水開始ノ頃」の具体的内容〔千川の給水区域への改良水道の到達時期〕は本書では特定できない）。
- **露渠樋管の定量〔確認・対校〕**: 「**保谷新田分水口ヨリ巢鴨沈澄池ニ至ル其間水路延長五里餘、其他露渠樋管ノ長サハ三千九百餘間ニ達セリ**」＝**露渠・樋管合わせ3,900余間**という定量（[BOOK-173](BOOK-173.md)の露渠170間＋樋管3,700余間＝3,870間余と整合する測定系統）。
- **観察〔観察〕**: 本書は1926年（=千川上水廃止〔明治40年〕の19年後）の水道論の一般書で、千川を過去の上水として整理する立場から書かれる。**廃止後の千川を「營業を繼續」の過去形で総括した叙述の採録例**として、沿革説の定型（[BOOK-173](BOOK-173.md)系）が一般書に定着したことを示す。
