# [BOOK-162] 三田村鳶魚『江戸の生活』（1941）「江戶の瀧」— 音羽の玉水簾の位置説と弦巻川流路の引用文言

- **書誌〔確認〕**: **三田村鳶魚著**『**江戸の生活**』（大東出版社・**1941**。NDL次世代デジタルライブラリー [book/1460041](https://lab.ndl.go.jp/dl/book/1460041)。170頁）。「江戶の瀧」章（p.253〜）に「音羽の玉水簾」節・「音羽の瀧」節・「關口の瀧」節がある。**引用文言はOCR由来で原画像照合を要する。引用されている「その頃の人の書いたもの」の元文献の同定は未了（後述）**。

## ①音羽の玉水簾の位置説と構造〔確認文言・位置対校の第4説〕

- 「**文化九年の秋に、音羽町一丁目の崖下へ拵へたのが、音羽の瀧といつて、當時評判なものになり、太田南畝は玉水簾といふ名を付け**」＝①造営年代＝文化9年（1812）秋＝[BOOK-154](BOOK-154.md)（武江年表「文化九年秋」）と一致。②**位置＝「音羽町一丁目の崖下」**＝[BOOK-151](BOOK-151.md)（遊歴雑記初編・文化初年・「音羽の瀧造営」）・[GAZ-035](../gazetteers/GAZ-035.md)（町方書上・文化13年5月）・[BOOK-156](BOOK-156.md)（寝ぬ夜のすさび・音羽3丁目の道具屋半兵衛裏）の位置対校に**「1丁目」説を追加する第4の位置記録**（各書の丁目記録〔1丁目西横丁崖下候補・2-3丁目西裏手・3丁目半兵衛裏〕と併記し、断定は原画像照合まで保留）。③**太田南畝が「玉水簾」の名を付けた**＝[BOOK-155](BOOK-155.md)（蜀山人全集・南畝自署狂歌）・[BOOK-156](BOOK-156.md)（寝ぬ夜のすさび・「蜀山に頼んで玉水簾と命名」）の系統の再確認（魯山人句説〔[BLOG-185](../blogs/BLOG-185.md)〕の弱化をさらに裏付ける）。
- 「その頃の人の書いたものにも、**瀧の幅六尺許り、高さ五尺餘有、瀧の落口は岩を穿ち、西の崖通りを伐開き、下流を〓くしもろ〓〓の樹木を植込み、石を並べ燈籠をすゑ、橋を渡して風景巧みに作りて音羽の瀧と號せり**」＝当時の記録（引用元文献は本頁では明示されず・同定課題）による**滝の構造寸法（幅6尺・高さ5尺余）と造園手法（岩穿孔・崖通りの伐開・樹木植込・石・灯籠・橋）の文言**＝武江年表「高一丈五六尺・幅一間余」（[BOOK-154](BOOK-154.md)）との寸法対立（幅一間余≈6尺で一致方向・高さは1丈5-6尺と5尺余で対立）＝**要照合・併記**（引用元の特定により対立の解決が可能になる）。

## ②弦巻川流路の引用文言〔確認文言・伏越交差の第4テキスト体制の補強〕

- 「**一體此水、池袋村より出で雜司ケ谷村みたけの下を過て弦卷川といひ、末は目白下上水の埋み樋を流れて、江戶川に合流せり**」＝①**弦巻川の水源を「池袋村」に置く流路記述**（丸池＝雑司ヶ谷池ヶ谷〔[BOOK-144](BOOK-144.md)〕と池袋の関係の対校材料）②雑司ヶ谷村御嶽（みたけ）の下を通る＝[BOOK-143](BOOK-143.md)（東京地理沿革誌・御嶽と唱ふる丘下の小流）と同型③「弦卷川」の呼称④**「末は目白下上水の埋み樋を流れて、江戸川に合流」**＝[BOOK-152](BOOK-152.md)（江戸雀・「目白下上水の埋み樋」）・[BOOK-144](BOOK-144.md)（遊歴雑記・「目白坂より上水の下を潜りて江戶川に合流す」）と並ぶ**弦巻川×神田上水（白堀）の伏越交差構造の流路文言の第3の本文テキスト**（書誌系列では第4系統）。③この文言も「その頃の人の書いたもの」の引用と思われ、引用元の同定は課題（江戸雀か静のとぎは系か・特定できず）。

## ③根津音羽の岡場所記述〔確認文言〕

- 「明治の初めに老輩が…誇りかに話したのは音羽の瀧でありました。といふのは、**根津音羽といつて、江戶に多かつた岡場所といふやつで、吉原よりも繁昌した所です。こゝの賣笑女でも、オイランのやうに部屋持があつて威張つたもの**」＝根津音羽岡場所の随筆記録（[BLOG-045](../blogs/BLOG-045.md)音羽九丁目岡場所伝承・[BOOK-009](BOOK-009.md)天保13年廃止・[GAZ-056](../gazetteers/GAZ-056.md)正徳4年茶肆の娼婦・[BOOK-157](BOOK-157.md)享保8年売女発生の系統の江戸史家による通時の再整理）。
