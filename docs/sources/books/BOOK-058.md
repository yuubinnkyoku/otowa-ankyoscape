# [BOOK-058] 千川上水 昭和27年の写真を中心に

- **書誌〔確認：東京都水道歴史館デジタルアーカイブの書誌ページを直接確認（2026-11-11）〕**：資料ID B078-2（開架書架B・図書）、『千川上水 昭和27年の写真を中心に』、**練馬区教育委員会 編・発行、平成12年（2000）3月、45p・25cm**、貸出不可、主題: 水道／歴史／東京／江戸上水／玉川上水／分水／千川上水。
- **意義〔推定〕**：**昭和27年（1952）= [GOV-056](../gov/GOV-056.md) の「練馬区内の暗きょ化は昭和27年3月以降」という年と一致する時点の千川上水写真**を中心に編まれた区編纂の写真史料集。暗渠化着手直前・着手時の開渠部・分水施設の状況写真が含まれる可能性があるが、**デジタル画像は公開されておらず内容は未確認**（館内閲覧・他機関所蔵の確認が必要）。
- **三河川への使い方〔推定〕**：谷端川への長崎村分水の廃止・千川上水の通水終了（1971年）前史の実景写真の一次史料候補。**本書の存在をもって分水の廃止年代や施設位置を主張しない**。
- **制限〔未解決〕**：本文・収録写真の内容、昭和27年の写真の撮影者・撮影区間は未確認。都立中央図書館・練馬区立図書館等での現物確認を次回以降の課題とする。
