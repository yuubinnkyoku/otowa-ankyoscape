- **雑司ヶ谷町の弦巻川〔確認・repo初出の1890年文言〕**: 雑司ヶ谷町の条に「**此地御嶽と唱ふる丘下に小流あり弦卷川と云ふ**」＝**雑司ヶ谷の「御嶽」（御嶽＝鬼子母神の丘）の下に小流があり「弦巻川」という**という1890年（明治23年頃）の町名沿革記述。〔「御嶽」は雑司ヶ谷の御嶽（鬼子母神・御嶽社の丘）を指すと解され、OCR・文脈由来の推定を含む〕
- **内容メモ**: 本書は東京市内の町名・地誌を沿革つきで引く字典形式の書。弦巻川関係では、雑司ヶ谷町条の本条が主。1890年時点で弦巻川の名称が地誌レベルで定着していたこと、その位置認識が「御嶽の丘下」という地形表現で記されたことが確認できる。同書の鬼子母神表記（「貴子母神」等の異表記の用例）もOCR上に見える〔字形は要照合〕。
