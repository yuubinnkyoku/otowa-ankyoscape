# [BOOK-143] 東京地理沿革誌（1890）— 弦巻川の1890年記述

- **書誌〔確認〕**: 『東京地理沿革誌 : 一名・東京字典』（稲垣常三郎・稲垣氏藏版）。NDL次世代デジタルライブラリー [book/764148](https://lab.ndl.go.jp/dl/book/764148)。自序に明治21年の紀年が見える（**刊年の確定（明治23年・1890年頃とする目録情報の照合）は原奥付で要確認**）。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **雑司ヶ谷町の弦巻川〔確認・repo初出の1890年文言〕**: 雑司ヶ谷町の条に「**此地御嶽と唱ふる丘下に小流あり弦卷川と云ふ**」＝**雑司ヶ谷の「御嶽」（御嶽＝鬼子母神の丘）の下に小流があり「弦巻川」という**という1890年（明治23年頃）の町名沿革記述。〔「御嶽」は雑司ヶ谷の御嶽（鬼子母神・御嶽社の丘）を指すと解され、OCR・文脈由来の推定を含む〕
- **内容メモ**: 本書は東京市内の町名・地誌を沿革つきで引く字典形式の書。弦巻川関係では、雑司ヶ谷町条の本条が主。1890年時点で弦巻川の名称が地誌レベルで定着していたこと、その位置認識が「御嶽の丘下」という地形表現で記されたことが確認できる。同書の鬼子母神表記（「貴子母神」等の異表記の用例）もOCR上に見える〔字形は要照合〕。
- **位置づけ〔観察〕**: [GAZ-046](../gazetteers/GAZ-046.md)（1884刊・風土記稿の音羽町条）→[BOOK-143](BOOK-143.md)（1890・本条）→[GAZ-028](../gazetteers/GAZ-028.md)（1907・東京案内）→[BOOK-009](../books/BOOK-009.md)（1910・礫川要覧）という**弦巻川の名称・位置の明治期の通時記録の列の1890年の断面**として位置づけられる。

- **裏靑柳橋の1890年記述〔確認・repo初出の1890年文言〕**: 東西靑柳町の条に「**町名の起因ハ元祿年中舊幕府の役女靑柳ある者此地にて居宅を有し其後追々町家を開きしもへ遂に町名となる此所い音羽町一町目を隔てヽ両町東西ふ相分る故に名つけて東靑柳町、西靑柳町と云ふ東靑柳町に裏靑柳橋あり**」＝**東青柳町に「裏靑柳橋」がある**という1890年の記述。〔[橋名・橋跡調査](../../四河川の橋名・橋跡調査.md)で裏青柳橋は出典が[GAZ-035](../gazetteers/GAZ-035.md)系（文政町方書上・明治期地図）に依拠しており未裏付け課題としていたが、**1890年刊の地誌による独立した文献裏付けが確保された**。音羽谷（弦巻川下流部）の「裏」側（谷の背面側）の橋の1890年時点の実在文言として記録する。〕
- **雜司ケ谷町の社寺列挙と「貴子母神」表記〔確認・文言候補〕**: 雜司ケ谷町の条に「**雜司ケ谷町ハもと自證院領上地、並に本染寺門前、鬼子母神門前、舊幕諸士地、拂下地なとを悉く合併し明治初年より新に町名を加ふ此地御嶽と唱ふる丘下に小流あり弦卷川と云ふ社寺あり豐川神社、本淨寺、本納寺、本染寺あり又貴子母神ハ古より其名廣く知られもとハ鬼子母神としたり**」＝**①雑司ヶ谷町（明治の新町名）が自証院領上地・本染寺門前・鬼子母神門前・旧幕諸士地・払下地の合併によること、②町内社寺として豐川神社・本淨寺・本納寺・本染寺の列挙、③「貴子母神」表記（「もとハ鬼子母神としたり」）**。〔**1890年時点の雑司ヶ谷の社寺構成の定点**として[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考巻52）・[GAZ-075](../gazetteers/GAZ-075.md)（文政9年町方書上写）の六町構成（雑司谷町・鬼子母神門前・本浄寺門前・本染寺門前・高田四ツ家町×2）と対校できる。本浄寺の1890年存続、本納寺の追加（[GAZ-035](../gazetteers/GAZ-035.md)系には見えない社寺名・OCR候補）。「貴子母神」の異表記の1890年の用例も追加確認された（字形は要照合）。〕
- **音羽・靑柳・櫻木三町の役女3人由来説と享保8年廃町〔確認・文言候補〕**: 音羽町の条に「**（もと小石川、小日向、關口、雜司ケ谷等の地）音羽の總稱なりしを元祿十年護國寺の領となり町家を起立せしに享保八年之を廢し又德川氏より町家を再建し其家作を役女音羽、靑柳、櫻木の三人に與へしより町名となれりと云ふ**」＝**①元禄10年（1697）護国寺領となり町家を起立、②享保8年（1723）廃町、③再建の際に徳川氏が家作を役女音羽・靑柳・櫻木の3人に与え、町名となった**という1890年の町名沿革記述。〔[GAZ-016](../gazetteers/GAZ-016.md)（市史稿市街篇12・文政町方書上所引の御城奥女中衆由来説）・[GAZ-035](../gazetteers/GAZ-035.md)（文政町方書写149・青柳町音羽町桜木町）の**役女3人由来説の1890年刊書レベルでの継承（内容の流布を示す流行度の指標）**。**享保8年廃町と再建の年次も1890年の記述として記録する**（文政書上側の「元禄10年8月町屋仰付け」〔GAZ-016所引〕と対校して、起立→廃町→再建の流れの1890年時点の通時理解を示す。文言はOCR・要照合）。〕
- **櫻木町=關口小日向兩村入會地説〔確認・文言候補・repo初出候補〕**: 同条に「**櫻木町いもと關口小日向兩村の入會地〓らんと云ふもとハ護國寺領なりしに明治初年上地して町地となれり**」＝**櫻木町はもと関口・小日向両村の入会地とも云われ、もとは護国寺領、明治初年に上地して町地となった**。〔**櫻木町の起立前の土地の帰属についての1890年の説**。「音羽の總稱」（音羽町条冒頭）との関係ではやや異なる帰属説を併記する形で、1890年時点で既に複数説が並存していたことを示す記録としてrepo初出候補。〕
- **高田老松町=舊「高田下四ツ谷町」・髙田豊川町=舊「小石川四ツ谷町」〔確認・文言候補〕**: 高田の条に「**高田老松町いむかし高田下四ツ谷町と唱ヘ髙田村の小名にて宗參寺領、芳心院領、舊大野、安志二藩の邸地其他幕府諸士の宅地おりしを明治初年今の町名に改めたり髙田豊川町いもと小石川四ツ谷町と唱へ傳通院領、舊鳥羽藩邸、幕府諸士の宅地おりしを明治初年上地とるり更に今の名に改む**」＝**①高田老松町はむかし「高田下四ツ谷町」と唱えた高田村の小名で、宗参寺領・芳心院領・旧大野（藩・OCR候補）・安志（藩・OCR候補）二藩の邸地等があった、②髙田豊川町はもと「小石川四ツ谷町」と唱え、伝通院領・旧鳥羽藩邸・幕府諸士の宅地であった**。〔**「四ツ谷町」の旧町名・小名の高田村側（高田下四ツ谷町）と小石川側（小石川四ツ谷町）の対になる1890年記述**。[GAZ-075](../gazetteers/GAZ-075.md)（文政9年町方書上写）の高田四ツ家町・高田四ツ家下も町条の「高田四ヶ家町」系の表記（「小石川四ヶ家町」の隣町文言もあり）と**「四ツ家/四ツ谷」の表記対立候補**として対照表に追記する価値がある（孰れの表記が原字かは要照合）。宗参寺領（高田四ツ家町）・芳心院領（高田四ツ家下も町）・伝通院領（雑司谷村）の領有関係がGAZ-075の各条と一致する点は整合する。藩名（大野・安志・鳥羽）はOCR崩れ大・要照合。〕
