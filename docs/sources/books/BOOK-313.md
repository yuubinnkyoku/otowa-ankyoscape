## repoとの関連〔観察〕

- **弦巻川・谷端川（ともに豊島区・文京区起点の川）を所管する区の郷土資料館の1984年段階の常設展示図録**。同館は[BOOK-300](../books/BOOK-300.md)・[BOOK-310](../books/BOOK-310.md)ほか豊島区・隣接区の水系資料の刊行元・収集元としてrepoで追跡中の機関で、常設展が**地形・河川・開削（谷頭の湧水・谷戸・旧河道）をどの単元として展示していたか**は四河川の地域史仮説の背景資料になり得る〔展示内容・四河川関係資料の収録有無は本文未見のため断定しない〕。
- 同館刊行の研究紀要『生活と文化』（PAP-054・112・118〜121等を収録）に対して、常設展図録は**同じ館の展示系の初期（1984）構成記録**として比較対象になる〔関連付けの可否は本文確認後に判断〕。
