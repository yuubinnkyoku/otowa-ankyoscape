# [BOOK-170] 莊田平五郎傳（1932）— 千川水道會社解散記念品の贈与（明治42年12月24日）〔repo初出・第139回〕

- **書誌〔確認〕**: 対胸舎著『莊田平五郎傳』（昭和7年＝1932刊。荘田平五郎〔1856-1938・三菱の重鎮〕の伝記）。NDL次世代デジタルライブラリー [book/1030687](https://lab.ndl.go.jp/dl/book/1030687) のOCR全文を確認。**引用文言はOCR由来で要原文照合**。
- **千川水道會社解散記念品の贈与〔確認・repo初出・第138回課題②の決め手〕**: 年譜の明治42年（己酉）の条に「**（十二月）同二十四日、千川水道會社解散記念靑銅花盛器贈與セラル**」＝**明治42年（1909）12月24日に荘田平五郎が千川水道會社の解散の記念として靑銅の花盛器を贈られた**という記録＝**「解散記念」の品の贈与が明治42年12月24日に行われた**ことを伝記年譜が記す。年譜の直前の行が「**十二月□日、賞與金一萬五千圓**」で日付がOCRで欠落しているため「同二十四日」の帰属（12月24日）は文脈読みで、**原画像照合を要する**。本 datapoint は**千川水道會社の解散の時期が明治42年12月前後であることを示す最も直接的な文献記録**（[BOOK-166](BOOK-166.md)の第13版〔明治42年〕欠載・[BOOK-169](BOOK-169.md)の第12版〔明治41年〕最終掲載と整合）で、**解散の正確な登記年月日とは別に、「解散」の事実が明治42年内に認識されていた**ことを示す。**解散日そのもの（登記・官報等の一次記録）は本伝記では確認できないため断定しない**。
- **明治19年3月29日の三菱社の届書と千川水道會社〔確認・repo初出の文脈〕**: 明治19年の条に、日本郵船への海運事業の引譲に伴い社名を「三菱社」と改めた**岩崎彌之助の東京府への届書**（「**明治十九年三月廿九日…三菱社長岩崎彌之助**」）を引用した上で、**「（其ノ統轄スル所モ…）高島炭坑、吉岡鑛山、長崎造船所、第百十九國立銀行、千川水道會社ト云フヤウナモノ**」＝**明治19年（1886）時点で千川水道會社が三菱社の統轄する事業の一つに列する**という記述（届書そのものの文言は高島炭坑・長崎造船所等を挙げ、千川の名は届書後の叙述部分にあるため、**届書本文に千川が現れるかは原画像照合待ち**として叙述レベルの datapoint とする）。
- **『三菱創世物語』の同届書記述の対校〔確認・repo初出〕**: 『三菱創世物語』（昭和10年＝1935刊・[book/1280570](https://lab.ndl.go.jp/dl/book/1280570)）にも同一の届書（明治19年3月29日・東京府差出）の引用があり、「**彌之助ハ右ノ如キ屆書ヲ東京府ニ差出ト共ニ、其ノ統轄スル高島炭坑、吉岡鑛山、長崎造船所第百十九國立銀行、千川水道會社等ノ殘壘ヲ死守シテ更生ノスタートヲキツタ**」＝**両書が同じ屆書を引用し、いずれも千川水道會社を三菱社統轄事業に含める**。千川水道會社の三菱傘下の位置づけ（[BOOK-172](BOOK-172.md)〔財閥研究の傍系事業記載〕・[BOOK-171](BOOK-171.md)〔役員の三菱重鎮〕）に**1886年という時点を付けた伝記資料側の記述**（両書とも三菱側の社史的叙述のため、届書の原文にさかのぼる一次確認が将来課題）。
- **年譜の千川水道會社関連の空白〔観察〕**: 年譜の明治13年（1880）の条に千川水道會社の再興（起業）の記述は本書OCRでは確認できなかった（荘田が三菱に入社したのは明治15年で、千川水道會社の起業（明治13年8月）は荘田の三菱入社前のため、伝記が扱わないのは自然という観察）。

## 制限・未解決
