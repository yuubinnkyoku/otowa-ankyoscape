# [BOOK-116] 土地概評価 高田町（1922）

- **書誌〔確認〕**: 『土地概評価 北豊島郡高田町』（東京府・1922年）。NDL次世代デジタルライブラリー [book/921575](https://lab.ndl.go.jp/dl/book/921575)。OCRテキストで確認。**文言はOCR由来で要照合。OCRで「水久保」と表記される語は字名「水窪」の判読誤りと推定し、下記の解釈はこの推定に依存する。**
- **字水窪の地価区分〔確認・repo初出候補〕**: 「最低の八反步、**水久保（＝水窪と推定）等にても尙二十五圓乃至三十圓**」「字 水久保新田 一一二〜一八八番地（**小石川區大塚下町の西に接續…南に雜司ケ谷墓地及び護國寺あり 北には巢鴨監獄を見る 南部は高燥…北部は低濕にして中流以下の住宅地若くは工塲地**）評價最高四〇圓 最低二五圓」「字 水久保一八九〜二六〇番地（字水窪新田の西に連り…）」＝1922年時点の**水窪（雑司ヶ谷〜大塚下町の間）の地価水準（25〜40円）と土地利用（南部住宅・北部低湿の住宅・工塲地）**の府評価記録。
- **雑司ヶ谷・神田上水沿岸の工業化文言〔確認〕**: 「**工業地としては水利の關係上 從來より晒業者多かりし神田上水沿岸の低地に各種の工塲が近年著しく增加したる**と**東北部水久保（＝水窪）附近に二、三の工塲を見るに至りたる**」＝**神田上水（＝江戸川・弦巻川下流の神田川）沿岸の晒業→工場化と、水窪方面の工場進出**を1922年時点で記録。
- **位置づけ〔観察〕**: 弦巻川・水窪川の流れる高田・雑司ヶ谷の低湿地（水窪・雑司ヶ谷墓地周辺・巣鴨監獄＝現・豊島区東池袋周辺）の**1922年時点の土地利用・地価・工場立地を府の調査書で固定**する。弦巻川・水窪川の直接の川名言及はない（OCR上確認不能）ことに注意。
