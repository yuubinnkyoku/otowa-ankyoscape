# [BOOK-199] 筠庭雑録 — 善福寺地＝井頭上水の助水の文言（明瞭版）〔第167回〕

- **書誌〔確認〕**: 喜多村信節（筠庭）『筠庭雑録』上中巻（写・NDL次世代デジタルライブラリー [book/2533617](https://lab.ndl.go.jp/dl/book/2533617)）。江戸後期（文政12〔1829〕序の知られる考証随筆）の写本。**引用文言はOCR由来で要原画像照合。**
- **善福寺地＝井頭上水の助水〔確認・核心・repo初出〕**: 「**江戸の井頭のわたりに小園井村善福寺地といふは井頭上水の助水となるの処にも青石の碑にかふ釘を打たるあり**」＝**江戸の井頭の辺りの小園井村（遅野井村＝井頭村）の善福寺地は、井頭上水の助水となる処であり、その地に青石の碑に鋼（かふ＝釘）を打ちたてたものがある**という記述〔**①善福寺地（善福寺池）が井頭（神田）上水の助水である旨の江戸期随筆の明瞭な文言、②[BOOK-198](BOOK-198.md)（愚得襍載・喜多村節信）の同型文言（崩れ版）と対校することで善福寺池＝井頭上水助水の認識が随筆2系統（同一人物の別署の可能性を含む）で裏付けられる、③[GOV-377](../gov/GOV-377.md)（1877年東京水道改設之概略）の多水源合流説（井の頭池＋善福寺池＋妙正寺池）に先行する江戸期の助水認識の層、④青石の碑の釘譚（吉野吉水院の釘石と対比）の明瞭版**〕。
- **同書の対比記事〔参考〕**: 吉野山吉水院の青黒き石に大釘を打てる弁慶の釘石（遊観の人みなこれを摩る）等の考証が同居（[BOOK-198](BOOK-198.md)と共通の故事列）。

## 制限・未解決

- ①「かふ釘」（鋼の釘か別語か）の原字形は要照合。②喜多村信節（筠庭）と喜多村節信（愚得襍載）の別署・同一人物の関係の書誌確認は未了（同一なら随筆内の反復記述としての意味づけが変わる）。③青石の碑の現在地名（善福寺境内の石）との同定は不可（境内の石の実物確認は今後の課題）。
