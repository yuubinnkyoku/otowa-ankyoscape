# [BOOK-043] 鈴木理生『江戸の川・東京の川』第IX章・図38（1989年再刊）

- 鈴木理生『江戸の川・東京の川』井上書院、1989年8月（日本放送出版協会1978年刊の再刊）。国立国会図書館書誌ID **000002063051**、永続的識別子 **13134421**。書誌：[国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/books/R100000002-I000002063051)、[CiNii Research](https://cir.nii.ac.jp/crid/1971149384787321128)、[出版社](https://www.inoueshoin.co.jp/books/ISBN978-4-7530-2304-2.html)。
- 第IX章「川の変貌と死」第2節「独立当時の東京の川」・**図38「自然の川と上水・用水」**の公開転記：[書籍の公開転記](https://ktymtskz.my.coocan.jp/B/river9.htm)。同図は東京都建設局発行「東京の河川図」からの転載とされ、同局が東昌文化研究所へ委託した河川図・河川表に由来すると説明される。転記本文は、谷端川・谷田川・宇田川などが図中に破線で示されていると述べる。
- **年代表記の注意：** 公開転記には「昭和二八年（一九五二）六月一〇日」という矛盾した表記がある。昭和28年は**1953年**であり、本文の「1952年」と一致しない。図の説明にも「昭和28年の河川図」とあるが、原図の作成日・調査基準日を直接確認するまで1953年6月10日を確定日としない。
- **確認状況：二次転記。** 書籍の書誌は確認したが、1989年刊本の原ページ・図38の高精細画像・1950年代の東京都建設局原図および凡例は未閲覧。破線の意味（暗渠・河川跡・下水道化など）は公開転記の著者解説に依拠しており、図面の個別区間や流路の位置を直接判読したものではない。
