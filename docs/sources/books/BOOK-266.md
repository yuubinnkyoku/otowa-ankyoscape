## 意義〔観察〕

- [ORG-038](../org/ORG-038.md)の「焼きこがしの口述（浜野）」（祈雨祭系の焼きこがし＝悪天候を防ぐ民俗呪術）の**原本候補**。昭和50年代初頭の田無市による聞き取り・座談会方式の郷土資料シリーズで、[BOOK-259](BOOK-259.md)『田無の昔話 その3』（1979・田無中央図書館）と繫がるシリーズ群。
- 中山行事（年中行事）の口述記録＝雨乞い・水まつり等の水系習俗の聞き取り層の候補。
