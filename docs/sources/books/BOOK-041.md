# [BOOK-041] 夏目漱石『それから』（1909年）

- 夏目漱石『それから』、1909年。青空文庫[公開本文](https://www.aozora.gr.jp/cards/000148/files/1746_18325.html)を確認。
- 代助が神田川（当時の区間名は江戸川）の川辺を散歩する場面と「すぐ橋を渡って、金剛寺坂を上った」という場面がある。
- 文中で対象の橋は江戸川にかかるもの。「金剛寺坂下の人参川」という荷風の語と地点が近いが**人参川の橋が描かれたという意味ではない**。
- 対象四河川の名は確認できない。小石川・人参川下流域に隣接する坂の文学資料として採録。
