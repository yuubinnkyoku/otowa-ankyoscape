## repoとの関連〔観察〕

- **中新井村は千川上水の組合・分水村**: 千川上水は中新井村へ宝永4年（1707）からの分水が知られ、明治10年7月の千川用水組合村樋口伏替願に「字上新街」「字下新街」「字北新井」の3樋口が記録される〔[GOV-005](../gov/GOV-005.md)・[GOV-100](../gov/GOV-100.md)の周辺文脈で知られる内容・練馬わがまち資料館の様な既出二次資料と一致〕。1864年頃の本幹線利用組合12村にも中新井が列なる〔既出の二次叙述〕。**1932年の東京市郡合併（村の消滅）直後に村政側が編んだ公式村誌**であり、用水・樋口・村政財政に関する一次記録を含む可能性がある資料だが、**本文未閲覧のため内容の評価は未確定**〔所在のみ〕。
- **地域の帰属**: 中新井村は1932年から板橋区中新井町、1947年の練馬区分区を経て**現在の練馬区豊玉・中村地区**に相当〔[PAP-083](../papers/PAP-083.md)註1と一致する既知の帰属〕。千川上水練馬区間（豊玉周辺の分水・学田公園一帯〔[GOV-005](../gov/GOV-005.md)〕）の文献掘り下げの一次候補。
