# [BOOK-241] 『近世交通史料集 3 御伝馬方旧記』（1969）〔所在のみ・千川上水の伝馬方関連一次史料の所在記録〕

- **書誌〔確認: CiNii Books OpenSearch・NDLサーチ OpenSearch・2026-11-22取得〕**: 『**御伝馬方旧記**』（**児玉幸多 校訂・吉川弘文館・1969年（昭和44年）・近世交通史料集 3**・[NCID BN03142200](https://ci.nii.ac.jp/ncid/BN03142200)（CiNii Books・132館所蔵由来のカウント表示）・NDLサーチの書誌レコードあり）。ADEAC横断検索の本文検索（第252回実行）で**岡山機関のデジタル化資料（ADEAC機関資料ID: M2008011918585063583 と記録されていた目録）の目次「拾八」の一に「千川上水御用」という項目が立つ**ことが前回実行の目次観察として記録されている〔確認: 第252回ノート・知識継承。本実行ではADEAC側の当該目録の再取得・本文頁の確認には至っていない（前回記録の資料IDからADEAC目録頁のURL形式を確定できなかったため）〕。
- **内容メモ〔所在のみ〕**: 「御伝馬方」は江戸の伝馬役・諸国助郷等を所管した幕府機関で、『近世交通史料集』3はその旧記の活字化。**目次上に「千川上水御用」の項目名が立つ**＝**御伝馬方の業務文書の中に千川上水の御用（実際の文言は未確認）の項目がある**ことの所在記録〔A. 伝馬方経由の人馬が千川上水の普請・維持に動員された可能性を示す所在指標、本文の文言（対象年次・内容）未確認のため一切断定しない。B. 元文2年請負（川崎定孝）の桜堤普請群・堀割御普請（[GOV-353](../gov/GOV-353.md)）等、千川上水の普請史料の対校資料候補〕
- **意義〔観察〕**: 千川上水の一次史料の探索レーンとして、**江戸の交通・労務系機関文書の活字化という系統（近世交通史料集）に目を開く**もの。既収録の[GOV-353](../gov/GOV-353.md)（堀割御普請・天明2年12月記写）・[GOV-354](../gov/GOV-354.md)（千川上水小屋場の人足差止・天明6年）等の千川上水再興期の普請・人足の文言群に対し、伝馬方側の窓口記録の存在可能性を指す。
