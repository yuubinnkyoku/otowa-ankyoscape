# [BOOK-241] 『近世交通史料集 3 御伝馬方旧記』（1969）〔千川上水の伝馬方関連一次史料の所在記録・第254回で目次文言を直接確認〕

- **書誌〔確認: CiNii Books OpenSearch・NDLサーチ OpenSearch・ADEAC岡山機関目録・2026-11-22取得〕**: 『**御伝馬方旧記**』（**児玉幸多 校訂・吉川弘文館・1969年（昭和44年）・近世交通史料集 3**・[NCID BN03142200](https://ci.nii.ac.jp/ncid/BN03142200)（CiNii Books・132館所蔵由来のカウント表示）・NDLサーチの書誌レコードあり）。ADEAC横断検索の本文検索（第252回実行）で**岡山機関（岡山県立図書館・デジタル岡山大百科・ADEAC機関ID `okayama-pref-digioka`）のデジタルアーカイブ目録ID M2008011918585063583** が特定され、第254回で[目録頁](https://adeac.jp/okayama-pref-digioka/catalog/M2008011918585063583)と[目次テキスト頁（ht000010・全巻目次）](https://adeac.jp/okayama-pref-digioka/texthtml/M2008011918585063583/M2008011918585063583/ht000010)の取得に成功した〔確認: 目次テキスト頁の全目次文言。**史料本体の翻刻本文（各項目の中身）はADEACでは未公開＝本文文言は未確認**〕。
- **「千川上水御用」項目の目次文言〔直接確認: 目次テキスト頁ht000010・第254回・repo初出の全文言〕**: 巻「**御伝馬方旧記 十九**」（p.783以下）の末尾項＝「**拾八 一 千川上水御用ニ付，両御番所与力衆賃伝馬１件 …p.813**」＝**①項目名は「千川上水御用」ではなく「千川上水御用ニ付，両御番所与力衆賃伝馬」、②御伝馬方の業務文書として「両御番所の与力衆が賃伝馬（有償の人馬提供）を差し出した」1件が千川上水御用に関連して記録されていた、③頁は p.813（前回〔第253回〕記録の「p.811付近」は誤り＝p.811は隣接項「拾七 御番所江差上候書付之事」の頁であり、p.813に訂正する）**〔賃伝馬＝伝馬方の定型業務（『御伝馬方旧記』各巻に「賃伝馬」の項目が散在する）であることから、**千川上水の御用（大規模な御用奉行の出張・普請関係とみられるが対象年次・内容は本文未確認で断定しない）に際して与力衆が乗馬賃負担の人馬を出した**という業務記録の項目名レベルの確定〕。
- **隣接項目〔直接確認: 同目次テキスト頁〕**: 同巻「十九・四」＝「**板橋宿為助成，音羽町江馬市場相建申度願人有之候ニ付，御伝馬之儀，町御奉行御拘り者無之哉之旨，御尋之事 …p.788**」＝**板橋宿助成のため「音羽町江」馬市場を建てたいという願に対する御伝馬方の御尋**の項目〔音羽町（江戸の音羽町＝小石川音羽町か・千川上水沿いの音羽。これらは別系統）の比定は本文未確認のため断定しない。千川上水沿いの音羽（水窪川・護国寺周辺）との直接の関連も本文確認まで主張しない〕。
- **意義〔観察〕**: ①**江戸の伝馬方（機関文書）に「千川上水御用」の文言が実在することが項目名レベルで一次確定**＝千川上水の普請・維持に江戸市中の交通・労務系機関の人馬が絡んだ可能性の所在指標から、文言の存在確定へ格上げ。②対象年次・内容が本文未確認のため、[GOV-353](../gov/GOV-353.md)（堀割御普請・天明2年12月記写）・[GOV-354](../gov/GOV-354.md)（千川上水小屋場の人足差止・天明6年）等の千川上水再興期の普請・人足文言群との対応付け（いつの御用か）は翻刻本文の確認（ADEACでは公開されていないため岡山県立図書館の当該頁・活字書の閲覧待ち）まで判断しない。③「両御番所」が伝馬方のどの番所か（江戸の両伝馬町の番所とみられる）も本文確認課題。
