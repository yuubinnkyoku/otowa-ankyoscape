- **成立〔確認: 目録の成立欄〕**: 書中に「酒井大内記様」（酒井忠求は天明7年12月に大内記となる）、「黒田鶴松様」（天明6年9月に3歳で襲封した黒田直温）とあり、**概ね天明末〜寛政初年頃の成立**と目録が推定する。凡例に「一江戸砂子にのせたる説は除きてあやまりたるは又改て爰にしるす」「一霊地其外由来等の板に出たるは除之」「一説々多き中に正しく糺しき説は出ぬ」。
- **内容〔確認: 目録の内容欄の引用〕**: 江戸近郊・雑師ヶ谷村周辺の歴史や土地の伝説口碑・巷説を集めた地誌（漢字かな交じり・箇条書）。**同人による雑司ヶ谷辺の詳細な地誌『若葉の梢』の粗稿の一つ**と目録は位置づける。巻頭条「雑司谷の近辺／一鼠山はねつみにはあらて不寝に伏兵を護し故也と里人の口伝」。記事例として目録が引用するのは「一北村季吟屋敷は松平大炊頭様御内西北の隅の処千五百坪斗也…」「一穴八幡は委細に砂子に出たり社の前西かはに柱石の居たる処は観世大夫一世一代の能此処にていたしたる跡也…」。
- **意義〔観察〕**: ①[README](../../../README.md)既出の『若葉の梢』（寛政10年自序・江戸西北郊の基本史料）に対し、**その粗稿段階の写本が愛知県西尾市の岩瀬文庫に残る**ことを固定した。②巣鴨の**鼠山の口碑**（ねづみ山・源頼朝鵠沼説話系〔README §谷端川（巣鴨）既出の諸説と同じ山〕）を「里人の口伝」として採録した**近世の口碑記録そのもの**であり、現代の網越しの解説（BLOG系）と異なり**天明〜寛政期（1780〜90年代）の時点で鼠山伝説が流通していた**ことを示す年代基準になりうる〔口碑の内容（不寝番・伏兵）の史実性は別問題で、採録年代の確定のみ使う〕。③北村季吟屋敷（千五百坪）・穴八幡の観世一世一代の能跡は、雑師ヶ谷・目白周辺の土地利用・寺社縁起の座標資料として『若葉の梢』本文と対照する価値がある。
