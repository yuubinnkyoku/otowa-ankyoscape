# [BOOK-240] 葛城明彦『郷土史研究ノート・"幻"の「貫井池」と「富士見台ファミリーランド」』（2025）〔repo初出・貫井池・貫井川（石神井川水系・千川上水中流域南側の隣接湧水域）の総合資料集・千川上水との接点を含む〕

- **書誌〔確認: ADEAC目録詳細頁・2026-11-22取得〕**: 『**郷土史研究ノート・"幻"の「貫井池」と「富士見台ファミリーランド」**』（**作成者＝葛城明彦（郷土史家）・令和7年〔2025〕4月1日制作〔奥付 ht000220〕・数量1冊・資料種別＝図書**）。練馬区立貫井図書館デジタルアーカイブ（ADEAC機関ID `nerima-nukui-lib`）目録ID **mp000030-100020**・**権利関係・利用条件「教育目的の利用可」**（注記＝研究等）・**テキスト一覧の公開あり**（本文20頁全取得・[目次](https://adeac.jp/nerima-nukui-lib/table-of-contents/mp000030-100020/d210010)）。[目録](https://adeac.jp/nerima-nukui-lib/catalog/mp000030-100020)。ADEAC目録解説＝「先土器時代から存在していたと考えられ、江戸期～昭和初期には灌漑用水としても使われていた湧水池「貫井池」（1958［昭和33］年頃に消滅）と、その水によって生活していた人々の村の跡である「貫井二丁目遺跡」、さらには1969（昭和44）年～1971（昭和46）年の間、貫井池跡に設けられていたレジャーランド「富士見台ファミリーランド」等についての資料集」〔確認: ADEAC解説文／池の消滅年代＝資料集自体の記述と合わせて採録。**本repoは水系資料としての部分を収録（レジャーランドの遊園地史は従属的にのみ）**〕
- **貫井池の水源「出頭（でがしら）」〔直接確認: ht000060・ht000070・ht000080〕**: ①ht000060＝「**標高約35ｍ付近からの自然湧水＝「出頭」（でがしら）**」＋小俣隣平氏説（貫井池は「山抜け」による湧水池）と平田英二氏の否定説（「湧水が逆に崖を掘り込むもので、逆の例はない」）の対立を掲げ、筆者葛城は「西武有楽町線工事の際、台地切断面から突然湧水（水源不明）が噴出した例もあるため、「がけ崩れ等による湧水池の発生」も十分有り得る」。②ht000070＝**『東京府北豊島郡誌』（1918年＝大正7年刊）の貫井池条の引用文言「上練馬字向貫井にあり、面積七町歩（＝約６万９千平方メートル）、但現今は、全部開墾して、池の中心出頭と称する個所を存するのみなり。出頭は、昔村民の旱魃に泣けるを見て、弘法大師の持てる杖に手穿(てうが)ちたる泉なりと伝ふ。貫井の地名もまた此より起こるよし里人は語れり。此辺古跡あるにや土器石器の発掘さるもの多し」**＝**1918年時点で「池の中心出頭と称する個所」が残り、出頭＝弘法大師の杖による泉の伝説と「貫井」地名由来が郡誌レベルで記録されていた一次文言**〔repo初出・[対照表](../../地名・河川名対照表.md)の地名行（出頭・貫井）への追記対象〕。③ht000080＝関口信保氏談話（練馬区地名研究会会報第10号・小俣隣平氏稿）＝「**貫井池は現在の貫井１丁目22番地付近にあって、約１反歩（992平方メートル）の広さ。以前、区で水源調査を行った際、その南の約百坪の出頭（でがしら＝水源）にしめ縄を張ったこともあった。**」＋昭和10年頃の葦山（池に生える葦の腐食の小山・ヨシキリ・鯉鮒のすみか）・「水の抜ける穴に草を詰め込むのが仕事」＝**1935年頃の池の位置（貫井1-22付近）・規模・出頭と水源調査の一次回想**。
- **地名由来「貫井」の諸説と「溜井」〔直接確認: ht000050〕**: ①（岩盤などを）貫いて水（井）が湧き出ていたため、②「山抜け（＝ヌケ）」による湧水、③「温井（ぬくい）」説（※冬場は出頭付近で「湯気が立っていた」との証言あり・ht000190の鷲頭証言と対応）。**「貫井池」の名は江戸期絵図にはなく、呼称は「溜井」。明治～大正期からの呼び名と思われる（「貫井の池」から次第に「貫井池」に変わったか？）**＝**江戸期「溜井」呼称説（筆者の観察として記録・典拠絵図の特定は本文になし）**。
- **湧水地点群の所在〔直接確認: ht000100・repo初出の地点リスト〕**: ①石神井消防署（下石神井5-16-8）西側がかつて池であり貫井川の水源（窪地＝上久保の始まり・現「洋服の青山」付近）②石神井南幼稚園（下石神井4-21-23）南側付近の小湧水 ③下石神井2-10付近の小湧水 ④南田中4-7付近（**ここより上流は涸川**）⑤富士見台2-13の都営アパート付近に存在した池からの流れ⇒「すずしろ園」（貫井1-16-12）付近で合流⇒流れは約200メートル東で貫井池に注ぐ＝**貫井池への給水系統を5系統の現在地番つきで記した資料集の水源リスト**〔各々を所在確認と呼ぶには至らない（資料集の記述として記録）。⑤の「すずしろ園合流」は貫井池への給水経路の具体的な比定文言候補〕。
- **貫井川区間の呼称群〔直接確認: ht000100・repo初出・注記: 前回（第252回並走側）ノートの音写は「しまっぱり」だったが原典は「しまっぽり」〕**: 「◇「貫井川」の呼称・別称…「貫井川」と呼ばれていた区間＝石神井付近～貫井池の間のみ ◇下石神井上久保～下久保…「**しまっぽり**」（「しまちびっこ遊園地」＝下石神井２の35にその名が残る）◇富士見台付近支流の支流…「**ほりっこ**」◇貫井池～石神井川間…「**貫東川**」「**かんぴょう川**」「**かんちょう川**」（「かんちょう」の名については、「子供たちが「貫東」をふざけて呼んだ」とも、円光院の「灌頂(かんじょう)」（＝香水を頭に注ぐ儀式、または墓石に水をかけること）に関連して付けられた、ともされる）」＝**貫井川の区間別呼称の音写群（4区間・7呼称）を1頁に集録した改善呼称リスト（練馬区側郷土資料）**〔①「貫井川」が区間限定の呼称であること、②「しまちびっこ遊園地」（下石神井2-35）が「しまっぽり」の名残り候補として現存すること、③円光院の「灌頂」関連説と「貫東」のふざけ呼び説の2説が並記されることは呼称論の資料（いずれも断定せず）〕。
- **鷲頭文男氏聞き取り（2016（平成28）年5月25日・1932年＝昭和7年7月11日生まれ・当時84歳）〔直接確認: ht000190・本資料の核心部〕**: ●貫井池・貫井川について＝「**水が湧いていたのは（最大の水源は）、貫井1-30の真ん中あたり。そこからはゴボゴボ水が湧いて、よく湯気が立っていた。まるで温泉のようだった**」「**高台の千川上水からの流れも少しあった。それは土管で流されていた。**」「**貫井２－13のあたりで湧き水は下水管に流されていた**」「**このあたりは、５ｍくらい掘らないと砂利の層に当たらない。砂利は茶色っぽかった。その層の部分に土管が通された**」＝**①貫井1-30のゴボゴボ湧水＝最大水源の地番特定の一次証言、②千川上水（高台側）から貫井池方面への流れが「土管で流されていた」＝千川上水の漏水・導水が土管と目されていた証言〔千川上水と貫井池の間の水位差・導水経路を考える上での生活史側の一次証言。ht000090の「西武線のあるあたりからは、昭和30年代まで北に向けて小さな川も流れていた（筆者注：千川上水からの漏水か？）。最後の頃は完全にドブ川で、その後はコンクリートのフタもされた」とも対応。確定的な土管の敷設主・経路の第一次史料は本資料になく、断定はしない〕、③湧水の下水管への転送（貫井2-13）。**
- **貫井川・千川上水の氾濫記憶〔直接確認: ht000190・repo初出〕**: 同聞き取りで「**雨が降ると、貫井川や千川上水はすぐに氾濫していた。貫井川脇の家ではボートで２階から脱出していたこともあった。**」＋「**大雨で水が溢れ、富士見台～中村橋間では西武線が不通になったこともあった。**」＋「**昭和40年の初め頃までは、大雨が降ると『出頭』の付近は水浸しになっていた。豪雨の時にかなりの水が出て、西武線・富士見台～中村橋間の線路が宙吊り状態になったこともあった**」＋「旧・飯田百貨店東側の坂の上は、地元で「山の内」と呼ばれていた。大水が出た時は皆、そこを通って帰っていた」＝**①貫井川・千川上水が豪雨で頻繁に氾濫したという昭和30年代までの一次記憶、②富士見台～中村橋間の西武線不通・「線路が宙吊り状態」＝千川上水沿い低地（練馬区側）の冠水が西武池袋線の運行に及んだという生活史記録、③避難経路としての「山の内」の坂**〔A. 千川上水の中流域（貫井・富士見台・中村橋側）の氾濫頻度の一次証言として、[BOOK-179](BOOK-179.md)（1922年千川用水通水観察）や千川上水の開渠記憶（[GOV-418](../gov/GOV-418.md)記録フィルム等）に対して氾濫側の面を補うrepo初出の系統。B. 「線路が宙吊り状態」の物理的解釈（路盤洗掘等）は断定しない。C. ht000090の小林實氏談話（貫井中学校校庭南側の川=雨が降るとすぐにあふれて腰のあたりまで）も同系の低湿地氾濫記憶〕
- **重殿山・秋葉神社・水天宮ほかの記録〔直接確認: ht000090〕**: ①「**貫井池の東側の坂上は「重殿山」（じゅうどのやま）と呼ばれていた（※水に関係ある場所に付く地名とされる）**」＝**重殿山の音写・位置（池の東側坂上）・「水に関係ある場所に付く地名」説の一次記録（対照表地名行に追加）**。②「池跡に建っている神社は…『秋葉神社』なので間違い。以前ここにあった飯田百貨店の経営者が「火伏せの神」として1969（昭和44）年に祀ったもの」＝池跡の神社の正体（秋葉神社・飯田百貨店・1969年）の訂正記録。③「池付近にあった水天宮（＝水神社）は明治期に円光院脇に移された」（文政九年銘碑あり）＝池に関わる水神社の移転史。④「旧・飯田百貨店側からの流れは1968（昭和43）年頃に暗渠になった。細長いコンクリートのフタが敷き詰められており、上を歩くとバタバタ音がした」＝貫井池跡側の小流の暗渠化年代（1968年頃）の一次記録〔池本体の消滅＝1958年頃（目録解説・本文）との新旧関係の整理に注意〕。
- **円光院の大根洗い桟橋〔直接確認: ht000190〕**: 「**昭和20年代、円光院のそばには大根を洗うための桟橋が設けられてあった。**」＝**戦後の円光院（貫井寺・南池山）そばの水路（貫井池系の残水）に大根洗い桟橋があったという一次記録＝貫井池消滅後も残水が生活用水として使われた記憶**〔位置は円光院そば・千川上水（千川通り）沿いではなく池跡系の水路と解されるが、本文には水路名の特定なし・断定しない〕。
- **意義〔観察〕**: ①**貫井池は千川上水の中流域（練馬区貫井・富士見台側）に隣接する湧水池として、千川上水研究の水文学的な対照資料（千川台地の湧水リーズ）になる**（[BOOK-236](BOOK-236.md)・[BOOK-237](BOOK-237.md)の中村側回想と並ぶ貫井側の郷土資料で、千川上水からの土管導水・氾濫の連鎖の一次証言を含む）。②1918年北豊島郡誌の「出頭」文言は、**呼称・地名由来・伝説の3点を1918年時点で固定する一次文言**として江戸期「溜井」説と接続できる。③「しまっぽり」「ほりっこ」「貫東川」等の呼称群は[対照表](../../地名・河川名対照表.md)の音写呼称の系に加わる（第252回ノートの「しまっぱり」から「しまっぽり」への訂正も含む）。④レジャーランド（1969-1971）・準工業地帯（昭和30-50年代）・酒悦工場（1958-1974）等の池跡の土地利用史は、**湧水池消滅後の土地の転用史の典型例**として河川隣接史の背景資料になる。
