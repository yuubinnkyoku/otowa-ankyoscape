## repoとの関連〔観察〕

- **四谷大木戸＝玉川上水の江戸側終端の管理拠点**（[GAZ-141](../gazetteers/GAZ-141.md)/[GAZ-112](../gazetteers/GAZ-112.md)が既収録の玉川上水起立総説も大木戸で締められる）。**大木戸の水番屋を主題とする角田清美の論考**で、番屋側の実務（樋の管理・配水の監視）の記述が千川上水の石樋取水（[GOV-576](../gov/GOV-576.md)『上水記』の分水調等の前提）の背景情報に接する可能性があるが、本文未見のため千川上水言及の有無は断定しない〔所在のみ〕。
- [BOOK-291](BOOK-291.md)（同著者・紀要37号「千川上水の歴史と水利用」2023）の翌年の成果で、**千川上水論文と大木戸水番屋論文が同著者・同誌で連続している**＝羽村市郷土博物館紀要が千川上水系研究の継続的な掲載場になっている〔観察〕。
