# [BOOK-271] 滑川邦夫『江戸時代末期における田無村と近村との関係』（2013）〔田無村の近村ネットワーク研究〕

## 書誌〔所在のみ: NDL SRU・2026-11-22〕

- **滑川邦夫 著**「**江戸時代末期における田無村と近村との関係 : 田無市史編纂資料「人別関係文書」の分析を通して**」（**2013**）・**58p ; 30cm**＝NDL所蔵（NDL書誌 R100000002-I033696569・JPNO 24048289・冊子）。同著者の同年刊行に[BOOK-272](BOOK-272.md)『田無村人別関係文書抄』（42p）があり、研究編・史料編の対をなすと推定される〔断定はしない〕。

## 意義〔観察〕

- **幕末期の田無村と近村（保谷・上保谷・関前・芝久保等の千川上水・田無用水圏の村々）の関係構造**を人別（人口）文書から分析する研究冊子＝田無用水・千川上水系水論・水利組織の村際関係（[GOV-501](../gov/GOV-501.md)の水争い・[ORG-038](../org/ORG-038.md)の喧嘩神輿の石神井川はさみ）の**社会経済的な側面の裏付け資料候補**。滑川邦夫氏は下田家文書の研究家で田無村の村政・土地問題を一貫して研究（[BOOK-273](BOOK-273.md)〜[BOOK-278](BOOK-278.md)）。
