# [BOOK-171] 日本会社銀行録（1900）— 千川水道株式會社の設立登記（明治26年10月）と樋線資金の定量〔repo初出・第139回〕

- **書誌〔確認〕**: 東京興信所編『日本会社銀行録』（明治33年＝1900刊）。NDL次世代デジタルライブラリー [book/803740](https://lab.ndl.go.jp/dl/book/803740) のOCR全文を確認（水道関連の株式組織の部に千川水道株式會社の統計行）。**引用文言はOCR由来（割付の列崩れあり）で原表照合を要する**。
- **千川水道株式會社の統計行〔確認・repo初出の詳細〕**: 「**會社ハ玉川上水ノ供給ヲ以テ目的トシ（明治）十三年八月開業ス、後二十六年十月商法ノ規定ニ遵ヒ設立登記ヲ了セリ、資本金四萬圓、總株數四百、悉皆拂込濟**」＝**①明治13年（1880）8月開業、②明治26年（1893）10月に旧商法の規定による設立登記を了した**という沿革の明記＝**千川水道會社が明治26年10月に（合名会社的な実態から）商法上の設立登記を経て株式會社の形式を整えた**という法形式上の転換の datapoint（[BOOK-169](BOOK-169.md)の版次系列の「設立明治十三年八月」表記の裏側の、登記面での二段構えの記録。**登記の実体（設立登記により商号・株主構成が変わったか）は登記簿の確認課題**）。
- **資産・積立の定量〔確認・repo初出の数値〕**: 「**積立金二萬五千八百八十七圓、水賦金四千百七十三圓、未拂工事費七千八百七十八圓、水道樋線起業資金四萬六千九百七十五圓、未納金千三百一圓**」＝**積立金25,887圓・水道樋線起業資金46,975圓**等という1900年時点の会社の資産・積立の内訳＝**樋線（樋管の敷設）の起業資金が資本金（4萬圓）を上回る**点で、千川水道の樋管網の整備が資本金規模を超える投資を要した事業だったことを示す帳簿側の観察（数値の割付は原表照合を要する。「水賦金」の意味〔水道使用料の賦課金か〕も原表の項目名確認待ち）。
- **役員・配当〔確認・repo初出の1900年断面〕**: 統計行に「**利益金分配…配當率年一割**」・役員欄に「**取締役 莊田平五郞…同 橋元長…監査役 豐川良平…同 瓜生震**」（割付の列崩れあり・帰属は要照合）＝**①配当率年一割、②役員は取締役2名（莊田平五郎・橋元長）・監査役2名（豐川良平・瓜生震）**という1900年の体制（[BOOK-169](BOOK-169.md)の第2版〔明治31年〕〜第12版〔明治41年〕の役員系列の1900年の中間断面に対応。莊田・豐川・瓜生は三菱の重鎮で[BOOK-170](BOOK-170.md)の三菱社統轄事業記述と整合）。
- **事務所〔確認・対校〕**: 統計行に「**麴町區八重洲町一ノ一**」＝**事務所が麹町区八重洲町一ノ一（三菱會社内・現中央区日本橋付近）**＝[BOOK-169](BOOK-169.md)の「麹町區八重洲町一ノ一 三菱會社内」の表記の1900年側の先行確認（八重洲町の町名は明治44年の区画で日本橋に編入）。
