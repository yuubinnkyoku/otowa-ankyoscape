# [BOOK-086] 東京都『千川上水の沿草』（昭和27年）

- **書誌〔確認: 練馬区史歴史編第七部歴史資料編の「練馬区立郷土資料室蔵書目録」〕**: 「千川上水の沿草 東京都 昭27」の行で掲載〔[GOV-098](../gov/GOV-098.md)〕。**repo未収録の公文書系沿革書誌**。
- **性格〔推定〕**: 発行主体が「東京都」とされる沿革史料で、千川上水が上水から用水へ転換した時期（明治〜昭和戦前）の行政側記述を含む可能性がある。昭和27年は千川上水暗渠化着手期（昭和25年頃〜27年3月着手の諸説・[GOV-072](../gov/GOV-072.md)・[BLOG-113](../blogs/BLOG-113.md)）と重なる時期で、**暗渠化決定前後の行政記述の一次資料候補**。ただし**本文は未見で、千川上水路図（明治17年）等の既知資料との関係も不明**。目録の行送りで隣接行（創立二十五周年記念誌・共栄信用金庫）との混同の可能性もあり、正確な編者・発行元は原本確認待ち。
- **所在調査〔未解決〕**: NDL・都公文書館・練馬区立図書館の所蔵検索は今回未実施（次回課題）。
