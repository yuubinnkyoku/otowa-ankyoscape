# [BOOK-160] 正調新案和歌作法指南（明治25年）附錄・武藏名所 — 弦巻川を詠んだ和歌2首

- **書誌〔確認〕**: 笹村良昌著『**正調新案和歌作法指南**』（頴才新誌社・**明治25年〔1892〕**。本文中「明治二十五年」の記載を確認）。NDL次世代デジタルライブラリー [book/874715](https://lab.ndl.go.jp/dl/book/874715)。和歌の作法・作例を載せる実用書で、**附錄「詠歌の名に付て武藏名所」**に東京近郊の名所を歌題とした歌を掲げる（「東京に接近せる名所を武藏名所」として揭ぐる趣旨の序文言あり）。**引用文言はOCR活字版由来で、原字形との照合を要する。**

## ①弦巻川を詠んだ和歌2首〔確認文言・明治期の歌題としての弦巻川〕

- 「**梓弓つるまき川の本末をさやにてらして飛ほたるかな**」＝①「つるまき川」の表記（弦巻川）を含む和歌。②**「飛ほたる」＝蛍の飛ぶ川として弦巻川を詠む**＝[BOOK-144](BOOK-144.md)（遊歴雑記・雑司ヶ谷八景「絃卷川螢」）・[BOOK-158](BOOK-158.md)（江戸名所花暦・蛍の条「上水川と雑司谷の細流との間」）の系統に連なる**明治期の歌題としての弦巻川＝蛍の記憶の残存例**（実景としての蛍の存続ではなく歌題・歌枕としての残存である点に注意。実態は断定しない）。③「本末をさやにてらして」＝本末をさやかに照らす（梓弓の縁語）。
- 「**もの〓ふの腰に付ゑる弦卷い里の名にのみ殘りける哉**」＝①「弦卷い里」の表記（〓はOCR崩れ・「ものもふの」〔武士の意〕の崩れとみられる）。②**「腰に付けぬる弦巻」＝弦巻の実物（弓の弦を巻いた輪）を詠み込み、「里の名にのみ残る」とする歌**＝**弦巻川・弦巻（地名）の語源（弦を巻いたもの）を前提とし、実物が失せて地名のみが残るという明治期の認識の文言**（地名の由来語の意識が明治期にまで残る例・語源そのものの検証ではない点に注意）。③歌の帰属（作者名）は本頁のOCRでは確認できず要照合。
