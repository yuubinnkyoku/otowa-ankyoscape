# [BOOK-038] 平山蘆江「大塚節」（1929年発表）

- 平山蘆江作詞の新作小唄「大塚節」。1929年10月10日発表と、資料を比較した[地域史・文学調査記事](https://fujimizaka.wordpress.com/2020/08/27/asami-saka/)が記す。
- 二次転記された歌詞に「戀の大塚姿見橋で」「矢端」「末は互ひにこいし川」等がある。
- 1934年『市町村別 日本國勢總攬』に基づく再建歌詞と1932年『三都花街めぐり』の異文が示される。両原典の該当頁・原画像は未照合。
- 川名の明示と断定しない。姿見橋・矢端・小石川は地名や掛詞との重複がある。
