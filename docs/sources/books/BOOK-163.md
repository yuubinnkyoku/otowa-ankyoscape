# [BOOK-163] 墓碑史蹟研究 第6巻（1935）— 神齡山護国寺の梵鐘銘・観音堂銅燈籠銘

- **書誌〔確認〕**: **磯ケ谷紫江著**『**墓碑史蹟研究**』**第6巻**（後苑荘・**1935**。NDL次世代デジタルライブラリー [book/1242818](https://lab.ndl.go.jp/dl/book/1242818)）。東京周辺の金石文（鐘銘・燈籠銘・墓碑銘）の調査・釈文集。**引用文言はOCR由来で、銘文の釈文は原石・原画像との照合を要する**。

## ①神齡山護国寺の梵鐘銘（天和2年・1682）〔確認文言・repo初出の実物銘文レベル用例〕

- 「**神齡山護國寺境內右-奉寄進梵鐘一口 神齡山大聖護國寺鐘樓前 天和二壬戌年九月吉祥日 從四位下備後守源姓牧野氏成貞朝臣**」＝①**「神齡山」の用例のうち最古級の年代つき実物銘文**（天和2年=1682＝[GAZ-027](../gazetteers/GAZ-027.md)江戸砂子〔明和9年〕の93年前・護国寺創建〔延宝9年=1681通説〕の翌年）＝**第134回で確定した「神齡山＝神齢山＝護国寺の山号」比定（GAZ-027・BOOK-158・BOOK-159・BOOK-155の4系統一致）に、梵鐘という実物資料の銘文レベルの用例を加える**。②寄進者＝牧野成貞（従四位下備後守・常陸古河藩主・綱吉側近）＝**音羽谷の寺領化の最初期（天和〜元禄）の寄進者層の記録**。「夫物之發興者必有由氣時矣人深信則佛閣起佛閣成則不無梵鐘矣」の序文言つき。

## ②観音堂前の銅燈籠銘（元禄10年・1697）〔確認文言・観音堂造営の年代の銘文レベル確定〕

- 「**元祿十年丁丑之秋 神齡山護國寺之觀音堂造畢** 越八月廿七日…台駕適下賀落成臣等奉扈從于尊母公幸拜賀時臣辱蒙高命不料奉寄進銅燈籠一基於圓通大士之寶前」＝①**護国寺観音堂が元禄10年（1697）秋に「造畢」したことの銘文レベルの確定記録**（[2577110](https://lab.ndl.go.jp/dl/book/2577110)東京府文獻叢書〔江戸惣鹿子引用〕の「元禄年中本堂御建立」の「元禄年中」を元禄10年と特定する方向の銘文＝要照合）。②**将軍綱吉が落成の賀に「尊母公」（桂昌院）を伴い下向した**（「台駕適下賀落成…尊母公幸拜賀」）という光景の記録。③銘の謹記者＝「**元祿十年丁丑十一月十八日 從五位下安藝守藤原姓本庄氏宗俊朝臣謹記 治工椎名伊豫作**」＝**本庄宗俊**（桂昌院の実家本庄家＝[GAZ-053](../gazetteers/GAZ-053.md)宝永元年屋鋪渡預証文の余語古庵→上水請負人の系譜の本庄氏）が銅燈籠を寄進。④銘文「玉堂功就妖魔潛跡 德輝萬世神齡山永法燈影明」に「神齡山」を織り込む。

## 制限・未解決

- ①釈文はOCR由来で原石・原画像との照合を要する（天和2年銘の「吉祥日」の日付等の細部）。②梵鐘の現存確認（護国寺の鐘は戦災等で失われた可能性があり、銘が本書でしか確認できない場合は「釈文のみ現存」の処理が必要）。③観音堂造営の元禄10年説と「延宝9年桂昌院殿の御建立」（醇堂漫筆〔[2568106](https://lab.ndl.go.jp/dl/book/2568106)〕・護国寺創建通説）との関係（創建=延宝9年・観音堂造営=元禄10年の二段構えか）は、寺側の年表・『新編武蔵風土記稿』等との対校で整理する（本書のみでは断定しない）。④本庄宗俊の寄進の背景（桂昌院家の護国寺への関与）と千川屋敷（白山前町）の本庄家との関係の照合は別課題。
