# [BOOK-147] 玉川上水の建設者安松金右衞門（1942）— 白堀の定義・明治10年卷石蓋・寛文改修説

- **書誌〔確認〕**: 三田村鳶魚著『**玉川上水の建設者安松金右衞門**』（電通出版部・1942年刊〔別版1058272＝1943年刊・OCR上は同内容〕）。NDL次世代デジタルライブラリー [book/1876899](https://lab.ndl.go.jp/dl/book/1876899)（別版: [book/1058272](https://lab.ndl.go.jp/dl/book/1058272)・未登録冊）。江戸上水史の講述体の伝記書。**引用はすべて同館OCRテキスト由来。講述調のため著者の再述と一次史料の転用が混在する（流路記述の直後に「(上水記、上水在絕略記)」という出典挙示がある）。文言は原文画像との照合を要する。**
- **白堀の定義文言〔文言候補・repo初出の定義文言〕**: 樋の種類の語彙解説部に「**又は河、又は堀の水底を潜る所もあり、是を潜樋といふ、橋の下にそひて向ふ岸にわたる所も有、渡樋といふ、亦た懸樋といふ、石にて流を通す所、萬年樋といふ、樋なくてながるゝ所を白堀といふ、地方にて素樋といふ**」＝**潜樋・渡樋・懸樋・萬年樋・白堀（素樋）という樋種語彙の系列の中で、白堀＝「樋（導水構造）なしで流れる所」＝素樋（すとい）と定義する文言**〔白堀の定義の1942年の文献側用例。潜樋（伏越）・萬年樋（[GAZ-048](../gazetteers/GAZ-048.md)/[GAZ-035](../gazetteers/GAZ-035.md)の石樋・万年樋）・掛樋（[GOV-269](../gov/GOV-269.md)の水戸屋敷の掛樋）というrepo既出の樋種語彙と同じ体系に白堀を位置づける語彙解説。「地方にて素樋」という別称はrepo初出候補〕。
- **明治10年卷石蓋の文言〔文言候補・repo初出級の年代文言〕**: 流路記述（『上水記』系の転用と見られる）に「**是より小日向小石川の臺下を經て(舊時花水橋より工廠構外までは白堀なりしを、明治十年に卷石蓋を設けらる、凡八百五十九間三尺なり)砲兵工廠の內を通じ、初て、伏管に入り、水道橋の東に於て懸樋を以て神田川を横過し**」＝**舊時は花水橋から砲兵工廠（東京砲兵工廠）構外までが白堀だった区間が、明治10年（1877）に巻石蓋（石造の蓋）で覆われ、その長さが凡859間3尺（≒1.56km）だった**とする注記文言候補＝**白堀（小日向〜小石川区間）の暗渠蓋化の年代と区間長の候補**〔括弧内の注記で、『上水記』（1791・[対照表 巻石白堀行]）より後の明治期の施策を述べる箇所。「卷石蓋」という構造呼称もrepo初出候補。江戸川（開渠）としての機能はこの後も存続した時期の、上水導管部分の衛生蓋か。原典（どの明治期記録に基づくか）は未確認で、文言候補として扱う〕。
- **流路・區間の文言〔文言候補〕**: 「**高田を經て關口(こゝまでは舊來の川筋にて白堀より以下は新に開鑿したるものなり)に至り、分れて兩派となり、一は大洗堰を下りて江戶川となり、一は水門より目白臺下なる白堀に入つて乃ち上水となる、水源より此(花水橋以上)に至て、凡五里二十六町十五間とす**」＝①**関口までは旧来の川筋・白堀より以下は新開鑿**という区間性格の叙述、②**大洗堰を下りて江戸川／水門より白堀に入って上水**という両派の分岐構造、③**水源〜花水橋＝五里二十六町十五間**という延長文言〔[BOOK-149](../books/BOOK-149.md)（戸塚町誌）の「水路五里二十六町餘」と一致する延長の独立叙述。花水橋という橋名の用例〕。末尾に「**樋管の長延は凡三萬六千四百五十二間(呼樋は此外なり)井桁數は凡そ三千六百六十三**」＝樋管延長・井桁数の数値文言候補。
- **寛文元年神田上水改修説〔文言候補・年代説としてrepo初出〕**: 「**綱宗が、幕命を受けて、萬治三年二月から寛文元年四月まで、十四ケ月掛りで竣功いたしたから、神田上水改修は寬文元年の事です**」（伊達陸奥守綱宗による改修）＝**神田上水の改修を寛文元年（1661）竣功（萬治3年2月起工・14ヶ月）とする年代説**〔[GAZ-049](../gazetteers/GAZ-049.md)⑬の御府内備考「承應二年の頃堀割に相成候由」と対校できる年代説のひとつで、repoでは初出。神田上水の開削年代論（慶長期説・承応・寛文）に新しい系統を加える候補。講述体の伝承・記録のどちらに基づくかは原典確認まで保留〕。
- **綾瀨川系の「白堀上水」の別系統用例〔文言候補・注意書き要〕**: 「**綾瀨川の水を取入れた白堀上水、玉川の分水と石神井の三寶寺池の水とを合せた千川上水、まだもう二つほど上水があつたのでありますが、これは享保年間に、幕府が費用を出すのに困つて廢してしまつた**」＋「**千川上水の方は、明治になつて再興したこともありましたけれども、それも遂に廢れたやうであります**」＝**「白堀上水」＝綾瀨川取水の別上水、「千川上水」＝玉川分水＋三寶寺池の合流水、双方とも享保年間に廃止（千川は明治に再興も遂に廃れた）**という1942年の叙述〔小日向区間の白堀（神田上水の通称）とは別に「綾瀨川系の白堀上水」という呼称があったとする用例で、「白堀」が神田上水固有の呼称ではないことの注意書き（[GOV-263](../gov/GOV-263.md)赤坂の白堀・[GOV-245](../gov/GOV-245.md)/[GOV-246](../gov/GOV-246.md)赤坂弁慶堀端白堀通と並ぶ別系統用例）を補強する。享保廃止説（千川上水）は他の廃止年代説と対校要〕。
- **千川上水の水源叙述〔文言候補〕**: 「**神田上水は府下三上水(玉川、神田、千川)の第二なり**」という前提の下、「**水源は多摩郡吉祥寺村なる井の頭の池…又同郡上井草善福寺の池より流出るもの一條あり、和田村にて本流と合し、下井草村妙正寺の池より流出る井草川あり、落合村に至りて本流へ合するもの及び玉川上水を代々木村より分流するもの、角筈村淀橋の下にて本流に入る、以上三派は共に其の助水なり**」＝井の頭池本流＋善福寺池・井草川（妙正寺池）・玉川上水の代々木分流（角筈村淀橋下で合流）の三助水という神田上水の水源構成の叙述〔「府下三上水（玉川・神田・千川）」という上水体系の呼称例。代々木分流＝千川（神田上水への助水）の位置づけの1942年の理解〕。
