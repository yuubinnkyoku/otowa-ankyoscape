# [BOOK-144] 遊歴雑記 五編（江戸叢書第7巻活字版）— 弦巻川の流路と雑司ヶ谷の字名の本文

- **書誌〔確認〕**: 『遊歴雜記』五編（菊岡沾凉・江戸叢書第7巻収録の活字版）。次世代デジタルライブラリー [book/952981](https://lab.ndl.go.jp/dl/book/952981)。**五編卷の上の末尾に「右五十八話綴之 文政七甲申年八月壹日草稿畢」＝五編（上）の草稿年が文政7年（1824）8月1日**と明記〔巻之中の成立年の上限の datapoint。区資料等の1814年説・1829年説との対校に使用〕。**すべての引用は同館OCRテキスト由来で、活字版であること自体が字形の一次確認ではないため、文言は要原文（活字版原本・写本）照合。**
- **弦巻川の流路〔確認・repo初の本文側確認〕**: 五編卷の中・雑司ヶ谷村条（鬼子母神掘出地の記述の続き）に「**水源ハ西北ノ方池袋村ノ境ニテ、池ヶ谷トイエル處ニ丸池トイフアリ、方凡五六間、此小地より〓出〔湧出〕シ法明寺ノ門前より御嶽ノ下ヲ過テ、爰ニ流ル、中程ニ至リテ里俗弦卷川ト稱シ、末ハ西靑柳町より音羽町西裏通りヲ過、目白坂より上水ノ下ヲ潜リテ江戶川ニ合流ス**」＝
  1. **弦巻川×神田上水（白堀）の伏越交差の直接文言〔repo初出〕**: 「**目白坂より上水の下を潜りて江戸川に合流す**」＝**弦巻川（＝鼠ヶ谷下水・東青柳下水系）が音羽町西裏通りを過ぎ、目白坂のところで神田上水（白堀）の下を潜って江戸川に落ちる**という文政7年（1824）以降の流末の文言。既存の[GAZ-048](../gazetteers/GAZ-048.md)（風土記稿・櫻木町の「石樋」）・[GAZ-035](../gazetteers/GAZ-035.md)（町方書上・万年樋）・[GOV-232](../gov/GOV-232.md)/[GOV-233](../gov/GOV-233.md)（桜木町鼠ヶ谷渡石樋）と**同じ交差構造を指す第4系統・本文側の文言**。「目白坂」を交差位置の目安として挙げた点が既出3系統にない情報〔比定（目白坂＝現在のどの坂か・桜木町大下の渡石樋との位置関係）は断定しない〕。
  2. **丸池の形状**: 「丸池といふあり、**方凡五六間**」＝池ヶ谷（池袋村の境）の丸池は**一辺約5〜6間**＝風土記稿の「長五間餘」（[GAZ-048](../gazetteers/GAZ-048.md)）と整合、現代の「三百坪」説との対照は要検討（[地名・河川名対照表](../../地名・河川名対照表.md)の池ヶ谷・丸池の行を参照）。OCRの「湧出」は「〓出」で湧出の補訂の可能性〔要照合〕。
  3. **流路の別名の層構造**: 「中程にいたりて里俗弦卷川と稱し」＝上流部（池ヶ谷〜法明寺門前〜御嶽下）は「弦巻川」を名乗らず、**中程から里俗で弦巻川**。法明寺門前→御嶽下→音羽方面という流路記述は[BOOK-143](BOOK-143.md)（1890「御嶽と唱ふる丘下に小流あり弦卷川と云ふ」）等の明治期記録の前史として位置づけられる。
- **雑司ヶ谷村の19小名〔確認・原字形対校資料〕**: 「此一村方量廣ければいろ〓〓の字ありて地名とす、所謂**南、北、西小北原、水久保、中島、西原、向原、車門、大門原、檢校島、淺井原、龜田、窪、弦卷、星谷、龜甲島、向山、地谷**ト以上**拾九**ノ字アリ」＝**19小名の列挙（水久保・弦卷・星谷を含む）**＋「又町方の內には里俗の唱へ來りし字は**御嶽、畑町、大門、柳下、仲町、〓土**などの六稱あり」＝**町方の里俗6称に「〓土」（清土候補）**。〔[GAZ-048](../gazetteers/GAZ-048.md)の小名対校・[GOV-298](../gov/GOV-298.md)の大正15年大火の字（向原・水久保・水原）の対照に使用〕
- **村高・家数・四至・支配〔確認〕**: 「雜司谷村ノ起元 鎭主ノ濫觴」条に「武州豐島郡**巢鴨の庄雜司谷村**ハ、**高貳百八拾八石貳斗八升七合九勺**アリトカヤ」＝**雑司谷村＝巣鴨の庄所属・村高288石2斗8升7合9勺**＋「東ハ小石川村護國寺マデ、南ハ日向臺組屋敷ヨリ高田四家下高田村ヲカギリ、西ハ巢鴨村代地ヨリ**池袋村ヲ境**トシ、北ハ巢鴨村マデヲ限トシテ南北ノ長サ凡拾町ホド、東西ノ廣サ西靑柳町ヨリ池袋村マデ凡拾四五町」＝**四至（東＝小石川村護国寺・南＝下高田村・西＝池袋村・北＝巣鴨村）**＋「惣家數**百六拾壹軒**」＋「御入國以前ノ領主ハ…**永祿二己未ノ年ノ筆記**ニテ太田…道灌翁ヨリ四代…五代…マデ界隈一圓ノ領地」＋「中古より一村高ノ內御代官領、市ヶ谷自證院、傳通院、芳心院、〓明寺ト五處相給二入交レリ」＝戦国期の太田氏領→江戸期の5か所給入（**法明寺＝「〓明寺」OCR**）。
- **村名の由来説〔確認〕**: ①**雜式谷説**: 「往古大內裏の雜式を勤務せし柳下若狹之助、長島內匠亮、戶張平司左衛門など…南朝北朝と御双方立たれ賜ひ…官を辭し浪人して亂を避け、一同當村に落付き住居を〓たるより以來、誰いふとなく雜式谷と唱えたるよし」＋②藏主ヶ谷説（小日向上水ばた悪日山金剛禪寺の藏主の領分・「むかしは藏主が谷」）・僧司谷説・曹司ケ谷説＋③**「雜の字」上意説**: 「中古有德庸〔有徳院〕御成の節、一村の內より書上たる文字區々にて混雜せし儘、以來は混雜の雜の字を用ゆべき旨上意ありけるより以來、雜司谷村と認る事となん」＝**雑司ヶ谷の表記統一が有徳院（徳川吉宗）御成の際の上意によるとする説**。
- **鬼子母神掘出の伝承〔確認・時期の整合〕**: 「**永祿四辛ノ酉年四月山本丹右衛門トイフ者ノ所持ノ深田ヨリ鬼子母ノ像ヲ掘出シケル**砌、此釜にて洗ひ淨めしより」＋星跡の〓水条「**時是永祿四辛ノ酉年五月十六日**なりけり」＝**掘出し＝永禄4年（1561）4月（村明細）／5月16日（星跡条）と同書内で月日が揺れる**。掘出地は「本淨寺の南凡半町〓士の林中…**土地〓土と號けしも爰に起る**」＝**「〓土」（清土）の地名が鬼子母神掘出地に由来するとする説**＋「傍に**三角に作る井筒**ある處こそ、鬼子母神の像を掘出せし土地にして、彼江戶砂子の三に星跡の〓水といえるは是也」＝**三角の井（星跡の井）の形状（井筒が三角）と掘出地の同一視**＋草薙の神事（天正六戊寅年四月に稲荷の社地へ仮安置・寛文六丙午年に浅野家の内室〔自昌院英心日妙〕が社建立・寛文八戊申年境内2,100坪・表間口30間・奥行70間の除地）＝[README]既出の武江図説・江戸紀聞系統の伝承の**本文側・年代つきの原記録**。
- **雑司谷八景〔確認・repo初出〕**: 「此雜司谷に中古誰いひ置けん、八境の風景ありて…**星跡〓水・御嶽夜雪・姿見橋鷺・絃卷川螢・威光山花・三島神離・鼠山秋草・池箇谷月**右八景」＝**雑司谷八景の全8景**。**「絃卷川螢」＝文政期に弦巻川で蛍が見られた**ことの傍証、「姿見橋」（=姿見の橋か）「鼠山」（鼠ヶ谷の丘）「池箇谷」（丸池の谷）の地名の用例。
- **署名の「白堀」〔確認・白堀呼称の用例〕**: 五編卷の上の末尾署名「**赤北鮮僧前廓然盡十方庵宗知老衲戯書**」／五編卷之中の著者表示「**東武白堀鮮僧前廓然盡十方菴大淨宗知老衲著**」＝**「東武白堀」の語を含む自称が活字版で確認できる**。白堀（神田上水の別称）が著者の居住地・所在を示す語として江戸後期の自称に使われた可能性の用例〔**「鮮僧」の語義・「東武白堀」の比定は断定しない。OCR由来のため原字形照合必須**〕。

## 制限・未解決

- ①すべての文言は活字版のOCR由来で、写本との異同・原字形（特に「〓土」「湧出」「東武白堀」）は要照合。②五編卷の上の草稿年（文政7年8月1日）と巻之中の成立年の関係（直後か・数年後か）は本書内では確定できず、区資料の1814年説・1829年説との調整は今後の課題（[GAZ-034](../gazetteers/GAZ-034.md)の対立の文脈）。③「目白坂より上水の下を潜りて」の比定（桜木町大下の渡石樋〔[GOV-233](../gov/GOV-233.md)〕と同一地点か・下流の別交差点か）は断定しない。④丸池「方凡五六間」と現代「三百坪」説との面積対照は未計算・要検討。⑤19小名のほかに1字がOCR欠落の疑い（「拾九」と数える一方で列挙名の確認）は要照合。
