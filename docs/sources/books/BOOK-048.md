# [BOOK-048] 東京府『東京府土木概要』（1926年11月）と隣接町下水改良系統図

- **原刊行物の書誌〔確認：東京都立図書館デジタルアーカイブの目録〕**：東京府編・刊『東京府土木概要』、**1926年11月刊、65頁、22cm、附図7枚**。本文側の公開資料コード**5004265531**、請求記号**T/510.9/5038/1926**。[本文側目録・画像入口](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00006285)。
- **別組付録の所在〔確認：同館目録〕**：別組付録として別の公開資料コード**5010270107**、請求記号**T/510.9/5038/1926-2**が公開されている。[別組付録の目録・画像入口](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00006316)。両方とも画像の使用条件はパブリックドメインと記載。
- **図名〔確認：国立国会図書館サーチが収録する書誌の一般注記〕**：附図に「**東京市隣接町下水改良系統図**」が含まれる。このほか管内図、国道改修計画図、都市計画事業に属する道路図などが挙げられる。[国立国会図書館サーチの書誌](https://ndlsearch.ndl.go.jp/books/R100000136-I1971430859753652924)（NCID **BN09265098**）。
- **研究上の価値〔推定〕**：1929年の高田町下水道施設計画立案や1930年の都市計画認可、1931年の弦巻川暗渠化着工より**前の1926年時点**に、東京府が隣接町の下水改良をどのような系統として構想していたかを比較する候補史料。もし高田町・長崎町・巣鴨町等が図示されていれば、弦巻川・谷端川流域の**計画上の排水方向・接続予定**を年代付きで検証できる。
- **未確認事項〔重要〕**：**附図原画像の図郭・凡例・文字・管路は未判読**。特定の町が図示されているか、既設・計画の区別、弦巻川・谷端川やその後の下水幹線との対応は確認できない。**1926年は書誌上の刊行年であって、工事の着工・竣工年ではない**。附図名の「下水改良」を実施済み工事と読まない。
