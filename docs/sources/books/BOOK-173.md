# [BOOK-173] 東京勧業博覧会衛生調査報告（1907）— 千川上水の沿革総説と樋管の定量〔repo初出・第139回〕

- **千川上水の沿革総説〔確認・repo初出の系統〕**: 「**千川上水ハ埼玉縣新座郡保谷村ニ於テ玉川上水ヲ分派シ之ヲ巢鴨溜池ニ致シ沿渠各村ニ供給シテ市內ニ入リ本〓下谷ノ一部ニ給水ス。其開鑿ノ起リハ元祿年間ニシテ彼ノ河村瑞賢ノ計〓（計画）ニ係リ多摩郡仙川村ノ農民德兵衞、太兵衞ノ兩人此工事ニ從ヒ元祿九年中其工竣ル**」＝**①水源＝埼玉県新座郡保谷村での玉川上水分派、②終端＝巣鴨溜池→市内→「本〓（本郷候補）」・下谷の一部への給水、③起請＝河村瑞賢の計画、④施工＝多摩郡仙川村の農民德兵衞・太兵衞、⑤竣成＝元禄9年（1696）**という沿革総説の1907年の採録＝**「本〓下谷の一部に給水」系の沿革説**（[BOOK-174](BOOK-174.md)〔1926〕・[GOV-327](../gov/GOV-327.md)〔1926〕・[GOV-290](../gov/GOV-290.md)〔1905〕と同系統）がさらに1907年に遡って確認できた点で、**この沿革説の定型化の時期を1900年代にまで引き上げる datapoint**（文言は要原文照合。「本〓」の原字も同様）。
- **露渠・樋管の定量〔確認・repo初出の数値〕**: 「**千川上水ハ明治十三年岩崎彌太郞等千川水道會社ヲ起シ舊渠ヲ修理開通セシモノナリ。保谷新田分水口ヨリ巢鴨沈澄池ニ至ル其間水路五里餘、露渠長百七十（間・OCR「問」）樋管長三千七百餘間ニ達セリ**」＝**①水路5里余、②露渠長170間、③樋管長3,700余間**という露渠と樋管の内訳の定量（「露渠長百七十問」の「問」は「間」のOCR誤候補）＝[GOV-172](../gov/GOV-172.md)（上水道章程の「瀧野川堰口ヨリ巢鴨村ニ至ル二町五十二間、陰樋延長凡壹里拾五町四十七間」）・[BOOK-174](BOOK-174.md)（「露渠樋管ノ長さ三千九百餘間」）と**単位の異なる同種の定量の対校資料**（170間＋3,700間＝3,870間で3,900余間〔BOOK-174〕とほぼ整合するが、両書の測定区間の同異は要精読）。
- **観察〔観察〕**: 勧業博覧会の衛生調査という需要側（博覧会の飲食水の安全性の調査）の報告書に六派上水の沿革説が収録されている＝**明治40年（1907）＝千川上水の廃止の年（[GOV-327](../gov/GOV-327.md)の明治40年6月）の刊行年を付す沿革説**で、廃止の年の水道調査が千川を「本〓下谷の一部に給水す」と現在形で記すか過去形かは原画像照合の際の確認点（OCRでは「給水ス」の形だが助動詞の切れ目は要照合）。
