# [BOOK-137] 並木仙太郎編『武蔵野』（1913）— 千川上水の分岐点・樋口の1913年観察

- **書誌〔確認〕**: 並木仙太郎編『武蔵野』（民友社・大正2年＝1913）。NDL次世代デジタルライブラリー [book/980800](https://lab.ndl.go.jp/dl/book/980800)。武蔵野の桜・名所の紀行・案内のアンソロジー。**引用文言はすべてOCR由来で要原文照合。**旧字表記（「歴史」等のOCR戻し）にも注意。
- **境橋＝玉川上水と千川上水の分岐点の橋という観察〔確認・repo初出の観察記録〕**: 小金井の桜の描写——「**これなん名にしおふ玉川上水と千川上水と相岐るゝさかい（ばし所・OCR崩れ）所 茲に境橋を架けたり**」＝**玉川上水と千川上水が分かれる境界の場所に「境橋」が架かっているという1913年の観察**。〔①千川上水の分水点（保谷・武蔵野両市境＝現在の境橋付近〔[GOV-077](../gov/GOV-077.md)〕）に橋があり、分岐点の目印であったことの同時点の観察記録。②「境橋」の橋名の用例として、弦巻川の境橋（1853年書上）・谷端川緑道の境橋（21番）とは別の同名異橋。③前後の文脈（小金井堤から北に進み桜が尽きた所）から、境橋は玉川上水沿い（小金井〜保谷間）に位置すると読めるが、OCR崩れがあるため正確な位置文言は原文照合後に確定する。〕
- **西久保関前の「六百年割」の樋口の埋没観察〔確認・表記は要照合〕**: 吉祥寺方面の道筋の記述——「**七丁程入、西久保關前、是に千川上水堀六百年割の樋の口あり、今は絕て埋れたり、此邊都て尾州侯の御鷹塲なり**」＝**①吉祥寺・西久保の関前（御鷹場）付近に「千川上水堀」の「六百年割」の樋の口があったこと、②1913年時点ですでに埋没していたことの観察**。〔**「六百年割」は「六百間割」等のOCR・誤植の可能性が高く、原字形照合が必須**。何の樋口か（千川上水本流の樋か・玉川上水から千川側への分水の樋口か・別の割の樋か）は本文言のみでは特定できない。「御鷹場」（尾州侯＝徳川家の御鷹場）の言及は位置の手がかり。〕
- **康樂園（保谷新田の私園）〔確認・周辺情報〕**: 「**康樂園 園軍山 只是れ一小私園…園は保谷村保谷新田に在り、境停車塲（＝境停車場・武蔵境駅）より北十五六町、境橋よりすれば東十二三町にして達することを得べし…園成りて猶十有餘年**」＝**保谷村保谷新田にあった私園・康楽園（成立10年余＝1900年代の開園）の位置記録（武蔵境駅の北15-16町・境橋から東12-13町）**。〔境橋・境停車場（武蔵境）・保谷新田の位置関係を具体的に伝える資料として、千川上水の分岐点周辺の地形理解に利用できる（康楽園自体は四河川と直接関係しない周辺情報として記録）。〕
- **看櫻の順路の引用群〔観察〕**: 『江戸名所花曆』を引用した看櫻順路（「道筋四谷、中野、光圓寺村、左關口、柳窪、正庵（＝正庵か）、吉祥寺、關前村、保谷新田邊より南岸に花有…」）等、幕末〜明治の玉川上水沿いの道筋・村名の二次引用を含む。
