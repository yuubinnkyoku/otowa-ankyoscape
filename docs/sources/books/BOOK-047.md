# [BOOK-047] 『雑司が谷8』地域別発掘調査報告（2013年）

- **書誌〔確認：CiNii Booksの所蔵書誌〕**：としま遺跡調査会編『豊島区地域別調査報告・雑司が谷遺跡における発掘調査』、**豊島区教育委員会、2013年3月刊**。**豊島区埋蔵文化財調査報告40／「雑司が谷」8**、NCID **BB13118751**。
- **形態〔確認：同書誌〕**：**ii＋157頁、30cm**、引用・参考文献**p.155**。CiNii Booksは学習院大学・国立歴史民俗博物館など**9館**の所蔵を案内する。
- **資料の区別〔確認：公的刊行物一覧〕**：豊島区の遺跡別刊行済報告書一覧では、**2005年の配水管新設工事地区（雑司が谷Ⅱ）**や**2010年の副都心線関連報告（雑司が谷Ⅲ・Ⅳ）**と別の**「雑司が谷Ⅷ」**として記載されている。
- **未確認事項**：**本文・調査地点図は未閲覧**。どの街区・時期の調査を収録し、旧弦巻川の谷筋・水田・水路・井戸・地層に触れるかは未確認。地域別調査という標題だけで、特定の旧河道を掘削したとは断定できない。
- **出典**：[CiNii Books（NCID BB13118751）](https://ci.nii.ac.jp/ncid/BB13118751)（書誌・所蔵館）／[豊島区「遺跡別刊行済報告書一覧」](https://www.city.toshima.lg.jp/349/bunka/bunka/bunkazai/documents/isekibetsu-list170424.pdf)（「雑司が谷Ⅷ」・報告書40・2013年の対応）。
