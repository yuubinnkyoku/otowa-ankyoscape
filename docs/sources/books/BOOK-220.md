# [BOOK-220] 日本紙業綜覽（1937）— 王子製紙の千川用水替水約定の全文

- **書誌〔確認〕**: 王子製紙株式会社編『日本紙業綜覽』（1937・NDL次世代デジタルライブラリー [book/1222443](https://lab.ndl.go.jp/dl/book/1222443)）。「第四編 歴史」p.544-548に工場用水の來歴として創業期（明治7〜8年）の約定書数点の全文を収録。**引用文言はすべてOCR由来で要原文照合**。
- **替水の仕組みの本文〔文言候補・本登録の核心〕**: 「**會社創立ノ明治初年頃ハ王子村ヲ始メ北豐島郡方面ハ水田多ク、同郡ヲ貫流スル石神井川ハ其等水田ノ用水組合ニ屬シ、みだりニ流用ヲ許サナカツタ。…地元王子村ノ有志ノ熱心ナル盡力ニヨリ、當時同用水組合ノ村々ノ加用水卽補助水ナリシ多摩川上水ノ支流字千川用水ノ流末水積六十六坪八合ヲ會社用水トシテ提供シ、王子村ノ田用水ト替水シテ工場ニ引入ルゝ事トシタ**」＝**①石神井川流域の王子村・十条村・豊島村等（用水組合）は千川用水の流末水（水積66坪8合）を加用水＝補助水として用いていた、②明治7年の抄紙會社（後の王子製紙）創業に際し、この流末水を會社用水として替水（交換）に供した**。〔**千川用水の流末が滝野川村の鹿島萬平絲器械所（紡績工場）の水車に掛かり石神井川に落ち、王子村外23ヶ村の田用水の補助だった実態＝千川用水末端の明治期の用途と水量（水積）の企業史料レベルの記録。水積66坪8合は[BLOG-095]（飛鳥山側の碑文系116.8坪）との対校点（66坪8合×2＝133.6坪と碑文116.8坪の対立は既存の検討課題・本資料では半量33.4坪供出後も約定は「是迄ノ通リ」なのが重要）**〕。
- **明治7年9月3日の約定書（王子村外二十三ヶ村宛）全文〔文言候補・repo初出文言の塊〕**: 「**武州豐島郡王子村地内へ抄紙會社工場取建候ニ付、同所用水ノ儀ハ石神井川用水組合廿四ヶ村ノ内、地元王子村並十條村豐島村三ヶ村用水路へ添樋イタシ、字千川ノ水ヲ引入、王子村用水ト替水イタシ、抄紙會社工場ヘ相用候示談行屆、然ル上ハ王子村小前一同ハ勿論二ヶ村ニ於テモ聊カ故障無之候、萬一他人ヨリ故障申出候共、抄紙會社工場差支無之樣可取計事／一、王子村外二ヶ村用水引入口大破ノ節修復ノ儀ハ一切抄紙會社ニ於テ差構無之候得共、右三ヶ村用水不用ノ節ニ至リ破損致候ハヽ抄紙會社ニ於テ臨時修復可致事／一、金貳拾五圓也是ヲ王子村用水ト替水致シ、同村地内流水致候ニ付、用水路浚方助合金トシテ抄紙會社ヨリ年々七月一日同村へ差出可申事／一、村ニ用水肝要ノ節ハ抄紙會社工場用水ノ外各村々用水聊モ工場ニ於テ相用申間敷、尤不用ノ節ハ此限ニ非ズ事／（右ノ通儀定取結ビタル證…明治七年九月三日 抄紙會社株主惣代 小野善右衞門 永田甚七…）**」＝**①添樋による字千川の水の王子村用水路への引入、②修復責任の分界（引入口大破は會社持ち）、③助合金25円の年々7月1日差出、④用水肝要の節は會社側が各村々用水を利用しない、という4条の替水約定（明治7年9月3日・王子村外23ヶ村宛の2種の約定書を収録）**。
- **明治8年3月10日の鹿島萬平（絲器械所）との約定〔文言候補・流末の実形態〕**: 「**字千川用水ノ儀、是迄絲器械所水車ヘ相掛リ候流末ハ音無川(石神井川)ヘ流棄イタシ、王子村外二十三ヶ村ノ組合加用水ニ相成居候處、今般…右加用水ヲ抄紙會社用水ノ替水トシテ王子村へ流用イタシ候儀ヲ絲器械所ニ於テ聊故障無之事。右用水絲器械所水末音無川南際ヨリ王子村ヘ箱樋掛ヶ渡シ王子村用水路へ流水致シ可申**」＋**保谷新田〜滝野川絲器械所間の箱樋の修繕は絲器械所持ち・半高分は會社の助金・絲器械所の上納水税の半額を會社が代納等の条項**＝**①千川用水の流末が（保谷新田→）滝野川村の絲器械所（水車）を経て音無川＝石神井川に流棄されていたこと、②その替水化に際し絲器械所の水末音無川南際から王子村へ箱樋掛渡ししたこと、③水税半額の會社による代納**。〔**千川用水末端（滝野川側）の掛樋・水車・水税の実務の詳細＝repo初出の流末側施設文言群**〕。
- **明治8年9月の東京府の「半量差出」命令〔文言候補・千川水道史の接点〕**: 「**會社唯一ノ賴ミトセル千川上水流末水ノ半量ヲ東京府へ差出セトノ命令**」…「**今般東京御府ヨリ御沙汰ノ趣有之、右千川流末水ノ半量ヲ同御府へ差出候ニ付テハ、王子村へ可引取千川ノ水減少致候ヘドモ、抄紙會社工場へ可引入水ハ是迄ノ通リ…**」（明治8年9月21日約定）＝**①明治8年9月に東京府が千川流末水の半量を府へ差し出させる命令（＝明治期の千川上水の府側用途〔給水/千川水道系〕の具体例候補）、②半量（水積33.4坪相当候補）供出後も工場用水は「是迄ノ通リ」とする王子村外23ヶ村との再約定**。〔**半量33.4坪の供出先（東京都水道の千川系統）＝[GOV-325](../gov/GOV-325.md)/[GOV-324](../gov/GOV-324.md)（境〜千川間の府県屬上水/水道の枠)との対校案件。また当該命令が明治8年9月＝明治6年の千川上水取上（府屬化）直後の施策タイミングであることも注記点（断定は保留）**〕。

## 制限・未解決

- ①約定書・約定の原文は本書（1937企業史）の翻字引用であって一次原本の写真・実物確認は未了（OCR崩壊箇所「早船彌左衞門」等の署名部は要照合）。②「流末水積六十六坪八合」の「坪」（面積か水量単位か）と水積の定義は本書では説明不足で、碑文116.8坪系（[BLOG-095]）との整合の解釈確定には、明治6/8年の東京府の水道政策一次文書の確認が要る。③「多摩川上水ノ支流字千川用水」という位置づけの表現も藩閥期の企業史料特有の言い方で、境分水（保谷）が「支流」表記になる点の精度は原照合外では評価不能。
