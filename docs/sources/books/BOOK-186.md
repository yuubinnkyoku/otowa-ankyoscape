# [BOOK-186] 国語学習指導の研究（1935）— 谷端川のコンクリート暗渠化と乞食橋（藤橋→富士橋）の橋名史

- **書誌〔確認〕**: 佐久間政一『国語学習指導の研究』（目黒書店、1935）。NDL次世代デジタルライブラリー [book/1454009](https://lab.ndl.go.jp/dl/book/1454009)。国語教育の研究書で、板橋（旧東京府豊多摩郡…要照合：板橋区）周辺の語り物教材として谷端川・乞食橋の記事を含む。**引用文言はすべてOCR由来で要原文照合**。
- **谷端川のコンクリート暗渠化〔確認・repo初出の改修年代の書籍記録〕**: 「**昭和八年東京市に編入される直前、谷端川が改修され、コンクリートの暗渠となつた**」＝**谷端川が東京市へ編入（昭和8年〔1932〕10月の区制施行・周辺郡部の東京市編入）される直前に改修され、コンクリート暗渠となった**旨の1935年時点の記録〔観察：編入直前＝昭和6〜8年（1931-32）頃の改修を示唆するが、「直前」の幅は本書では確定できない。谷端川の暗渠化の時期を当時資料で直接記述した datapoint として [BOOK-109](BOOK-109.md)系の乞食橋記録と対になる〕。
- **乞食橋の橋名史〔確認・[BOOK-109](BOOK-109.md)（乞食橋1922年改築）・[BLOG-133](../blogs/BLOG-133.md)（読図）との対照〕**: 「**明治十八年架橋の際は藤橋と書いてあつたが、大正十一年改築の際富士橋と改めた**」＋「**昔附近に番太小屋があり…乞食橋と俗稱**」＝**乞食橋の正式橋名が明治18年（1885）架橋時の「藤橋」から、大正11年（1922）改築時に「富士橋」へ改められたこと、番太小屋（幕府の見張番所）の伝承が俗稱「乞食橋」の由来として語られていること**＝橋名改称の年次・方向（藤→富士）の当時資料レベルの記録〔観察：大正11年改築の年次は [BOOK-109](BOOK-109.md)と整合。「藤橋→富士橋」の改称方向が初出〕。
- **谷端川の水質の変遷〔確認・文言候補〕**: 「**明治年間には…川の水も澄んでゐたが、大正に入つてから人家が激增し、川も近年は全く溝川となつてゐた**」＋「**現在は橋はなく、空地となつてゐる。將來は暗渠の上が道路になるといふ**」＝明治期の清流→大正期の人家激増による溝川化→暗渠化後の空地化・将来の道路化予測という谷端川の近現代史の実観記録〔文言候補〕。
