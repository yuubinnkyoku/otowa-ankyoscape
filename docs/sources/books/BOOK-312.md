## repoとの関連〔観察〕

- **目次題から、小石川・神田上水系から玉川上水系への切り替えを主題とする論考と読めるが、本文未見のため論旨・対象区間の言及は確定しない**〔所在のみ〕。小石川・本郷台（水窪川・弦巻川・谷端川起点域）への上水給水系の変遷は、repoの神田上水樋線図群（[MAP-066](../maps/MAP-066.md)〜[MAP-069](../maps/MAP-069.md)・[MAP-209](../maps/MAP-209.md)〜[MAP-221](../maps/MAP-221.md)）と直接対応する主題。
- 「**小石川上水**」の呼称は[BOOK-205](BOOK-205.md)（『芭蕉の全貌』）の水道工事諸説（「藤堂家小石川上水掘割の役」）ですでにrepoに用語史料として登場しており、明治期上水史研究で同呼称をどう扱うかの照合対象〔観察〕。
