- **repoとの関連〔観察〕**: ①**堀越正雄「江戸の上水―六水道の興廃経過―」＝千川上水を含む江戸六上水（神田・玉川・千川・三田・青山・亀有）の興廃史を論じた記事の書誌**（堀越氏は第34号〔[PAP-068](../papers/PAP-068.md)〕でも「玉川上水系配管の仕組み」を執筆＝**同誌で六水道史と配管構造を分担した水道史研究者**としての書誌初出）。②**矢嶋仁吉「玉川上水とその分水」＝千川上水を玉川上水の分水として扱う1976年時点の先行研究の書誌**（大石学編『千川上水・用水と江戸・武蔵野名著出版2006〔[BOOK-060](BOOK-060.md)〕に先行する分水史系の一般誌レベルの記事として、千川上水研究史の系譜に加える）。③**皆木繁宏「江戸名所「小金井桜」」＝千川上水口を東端とする小金井桜堤の1976年研究史の書誌**（[BOOK-234](BOOK-234.md)近世編桜章〔2026-11-22取得〕が引用する江戸期紀行文名と、[GOV-341](../gov/GOV-341.md)・[BOOK-180](BOOK-180.md)系の桜堤記録の間の研究史の座標）。④蓑田倜「碑と遺蹟」→第34号「玉川上水「橋物語」」＝**同著者の上水沿いの石碑・遺構・橋の連続的関心**（水路沿いの遺構記録系の書誌）。
- **意義〔観察〕**: repoの千川上水レーンが中心として利用してきた『多摩のあゆみ』側の資料は第34号の肥留間博記事（[PAP-068](../papers/PAP-068.md)）のみだったが、**その12年前の第4号に既に六水道史（堀越）・分水史（矢嶋）・小金井桜（皆木）の3系統が揃っていた**ことが目次レベルで確定＝**千川上水研究史の1976〜1984年の層をたましん系の一般誌内で追える**という研究史の広がりの記録。本文確認後は千川上水の取り上げ方（上水として扱うか用水として扱うか）の1970〜80年代観察の定点になる。
