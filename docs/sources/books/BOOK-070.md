# [BOOK-070] 『千川上水関係史料集Ⅰ』（豊島区立郷土歴史館編・豊島区教育委員会、1995年3月）


- **書誌〔確認：東京都水道歴史館「開架図書一覧」2021-07-10〕**：**『千川上水関係史料集　Ⅰ』、豊島区立郷土歴史館編、豊島区教育委員会発行、平成7年（1995）3月**。同館開架書架B・79番・貸出可〔[開架図書一覧PDF](https://www.suidorekishi.jp/images/information/library/book.pdf)〕。
- **対応〔観察〕**：豊島区公式「図録（1996年度）」ページの[BOOK-075](BOOK-075.md)解説にある「**豊島区立郷土資料館調査報告書『千川上水関係文書I』**」と同一史料群と推定されるが、表記の揺れ（史料集/文書、郷土歴史館/郷土資料館）があり断定しない。**「Ⅰ」の刊行から「Ⅱ」以降の存否・所在は未確認**。
- **意義〔観察〕**：豊島区が千川上水関係の一次文書を刊行した公的調査報告書の存在を、所蔵館目録レベルで確認。
