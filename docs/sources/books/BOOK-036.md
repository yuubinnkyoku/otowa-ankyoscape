# [BOOK-036] 夏目漱石『こころ』（1914年）

- 夏目漱石『こころ』、1914年。青空文庫[公開本文](https://www.aozora.gr.jp/cards/000148/files/773_14560)に小石川方面の叙述がある。
- 「下 先生と遺書」の回想に、砲兵工廠の裏手から坂を下り、小石川柳町へ至る谷で道の排水が悪く、泥だらけになり、「細い石橋を渡って柳町の通りへ出る」との記述がある（[該当部分の現代表記を確認できるページ](https://kakuyomu.jp/works/16817330651222768332/episodes/16817330651226097411)）。
- 別の場面では「本郷台を西へ下りて小石川の坂を真直に伝通院の方へ上がりました」と記す。
- 「谷端川」の固有名は確認できない。小石川柳町周辺の谷底と橋の文芸資料として採録。
