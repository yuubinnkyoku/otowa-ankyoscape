# [BOOK-185] 東京遊行記（1906）— 関口堰の実地観察（神田上水廃止後も水は流る）

- **書誌〔確認〕**: 『東京遊行記』（大倉書店・明治39年〔1906〕9月。NDL次世代デジタルライブラリー [book/764247](https://lab.ndl.go.jp/dl/book/764247)）。書誌APIで著者名の記載なし（author None）。田山花袋の遊記として言及されることがあるが、本書誌では確認できず**著者不詳と置く（断定しない）**。第十七章「雑司ケ谷」等、東京近郊の遊行記。
- **関口堰の実地観察文言〔確認・文言候補・要原文照合〕**: 第十七雑司ケ谷の鬼子母神章の帰路として「**歸路に就きて、目白臺下の關口堰に來る。神田上水の水を堰き落して、水深し。これより以下を江戶川と稱す**」、および「**神田上水は、廃れたれども、水なほ舊によりて流る**」（OCR）。＝**神田上水の廃止（明治36年〔1903〕・[GOV-307](../gov/GOV-307.md)）から3年後の明治39年（1906）に、関口堰で堰き止められた水がなお流れていたことの実地観察記録**。少年期に神田上水（江戸川）で泳いだ記憶への言及も読める〔文言候補〕。
- **位置づけ〔観察〕**: 神田上水廃止後も水が流れ続けた記録としては、[GOV-327](../gov/GOV-327.md)（昭和期まで水が供給され続けた行政記録・2026年当時の観察との対校）が知られるが、本書は**その20年前・廃止直後の1906年の民間側実地観察**であり、廃止（1903）から供給停止までの間の水流の実態をfolk-levelで裏付ける〔観察。「水深し」と堰の機能が残っていたかの解釈は原画像照合と前後文の精読を要する〕。
- **千川上水の1906年通俗説明〔確認・文言候補〕**: 「**小金井にて支流を生じて千川上水の名あり、板橋を經て本〓方面に向へり**」（OCR・「本〓」は判読不能字）＝千川上水が小金井（小平・小金井の善川分水〔[GOV-334](../gov/GOV-334.md)・千川上水の分岐の通説〕）で分かれ板橋へ向かうという説明の1906年の通俗地理書用例〔文言候補〕。
- **その他の観察〔確認・文言候補〕**: ①雑司ヶ谷鬼子母神の縁日起源説話・門前の様子の記述。②目白不動（新長谷寺）への言及〔文言候補〕。③早稲田の田甫（早稲田の田圃・水田）の市街化の観察（鶴と亀の松〔鶴松亀松〕の名物の言及を含む）＝早稲田の水田が開発途上にあった1906年時点の記録〔文言候補・要照合〕。

## 制限・未解決

- ①著者不詳（書誌APIでauthor None）。田山花袋候補は確証がないため断定しない。②OCR文言は旧字体・崩れがあり、すべて原画像照合が前提。特に「堰き落して、水深し」の解釈（堰で水をせき止め水深があった）と「水なほ舊によりて流る」の解釈（水が旧来の通りに流れ続けた）の前後関係（廃止後も水路として機能したか）は、原画像の前後文精読で確定する。③千川上水の「小金井」が現在の小平市小金井（善川分水）を指すかの同定は本書の記述単独では確定できず（当時の通俗説明の踏襲の可能性）、千川上水の分岐点の記録としてはGOV-334等の行政記録を主とし本書は補助資料とする。
