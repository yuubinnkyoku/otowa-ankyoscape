# [BOOK-123] 小石川區會史 下巻（1939年）— 大正期の千川・江戸川治水行動の区会記録

- **書誌〔確認〕**: 『**小石川區會史**』**下巻**（1939年）。大正期の小石川区会・聯合会（小石川・牛込両区・高田村）の議事経過の記録。NDL次世代デジタルライブラリー [book/1277818](https://lab.ndl.go.jp/dl/book/1277818)。**すべての引用は同館OCRテキスト由来であり、文言は原文画像との照合を要する。**
- **江戸川改修寄附金と市への正式申込（大正3年2月10日）〔確認〕**: 「江戶川改修工事寄附金の募集に盡瘁し…**本區牛込兩區を合しての豫定額たる金參萬五千圓を稍超過するの好成績**に到達したので、牛込區と協議の上**三年二月十日市へ正式に寄附金の申込書を提出**した」＝**小石川・牛込両区で3万5千円超を募り、1914年2月10日に市へ正式申し込みした記録**〔江戸川改修（神田川治水）に地元財政が参加した規模の一次記録。区会史由来で金額の最終確認は市側資料で要照合〕。同章に「市に於ては**先に十二萬餘圓を以て一部改修の考へなりしを、更に廿二萬圓を以て全部に亙る改修施行に決意**したるを以て、聯合會に於ても**高田村は川敷を提供し、牛込小石川兩區は應分の寄附金を提供**すべきこと」＝**市の改修予算が12万円余（一部）→22万円（全部）へ拡大した経緯＋高田村の川敷提供**〔旧神田上水流域3自治体の負担区分〕。
- **大正3年9月21日委員会の諸決定〔確認・repo初出の文言群〕**: 「一千川ヲ浚渫シ且屈曲ヲ直ス樣市ヘ陳情スルコト、二**江戶川小櫻橋附近幅員目下十一間幅ナルカ改修後ハ八間幅ニナストノ事ニ付將來ノ意見如何ヲ市ヘ照會スルコト**、三同上改修工事ハ本月十四日出水ニ鑑ミ上流ヨリ着手スルコト、四**音羽町兩側大下水中改修ヲ要スル個所アルニ依リ改修工事ニ着手セラル樣市ヘ陳情スルコト**、五以上二三四號ハ聯合會ノ問題トスベク聯合會ヲ開クコト、六**千川ヘ塵芥投入ヲ爲ササル樣嚴重ニ取締ラレタキ決議書ヲ作製シ區長ヨリ警察署長ヘ交涉セラレタキコト**」＝**①千川浚渫＋屈曲直しの陳情（千川＝小石川下流の蛇行改善要求）、②小櫻橋の川幅が目下11間→改修後8間に狭まる件の照会、③9月14日出水を踏まえた上流着手要求、④音羽町両側の大下水改修陳情、⑤千川への塵芥投入取締（警察署長宛）**〔大正3年の千川（小石川下流）の実態：蛇行・塵芥投入・出水。小櫻橋は江戸川（神田川）の橋〕。
- **「牛込區鶴卷町ヨリ本區關口町ヘ貫通ノ大下水」設計変更（大正3年10月22日→12月決定）〔確認・repo初出の重要文言〕**: 「次で**十月二十二日の聯合會に於て左記を決議し、同月廿六日本區牛込兩區主査委員が市工務課へ出張陳情をなした。目下計劃中ノ牛込區鶴卷町ヨリ本區關口町ヘ貫通ノ大下水設計變更方陳情。右の結果十二月に至り陳情通り現設計より下流へ下水新設に設計變更方決定せられ**」＝**1914年時点で牛込区鶴巻町から小石川区関口町へ貫通する大下水（＝現在の神田川上流部・旧神田上水路の下水化）が計画中であり、区側の陳情で排水口位置が現設計より下流へ移す下水新設に設計変更された**〔大正期の神田川（江戸川）改修と並行して、上流側（鶴巻町〜関口町）の大下水（旧神田上水の流路）にも下水新設の設計変更があったことの区会記録。鶴巻町起点の大下水＝弦巻川下流・旧神田上水筋の近代下水への設計変更史の一次資料〕。
- **音羽大下水・旧水道（千川上水残流路）への対応（千川大下水聯合委員会・明治末〜大正初年）〔確認・repo初出〕**: 「**音羽町大下水竝舊水道に關し該地附近住民より市參事會へ改修要望陳情書を提出に付き、審議の結果、一音羽大下水の江戶川排水口を擴大すること、一舊水道を鐵管にすること、一其他浚渫護岸改修等治水上必要なる事項に關し市へ陳情すること等を決定し、全委員市へ出張陳情を了した。（以上八月乃至十月）**」＝**①音羽大下水の江戸川排水口拡大、②旧水道（旧神田上水＝千川上水の残流路）の鉄管化、③浚渫・護岸改修の陳情**〔音羽大下水＝弦巻川下流の大下水。「舊水道を鐵管にすること」＝**音羽町の旧神田上水残流路（千川上水の市内残流）の鉄管化要求**＝千川上水の残流処理（現在の水道管・暗渠化）への言及として注記〕。同じ千川大下水委員会の記録として「**砲兵工廠內水路及下富坂町より餌差町に至る新工事の視察檢分**」「**工廠前無名橋下を掘り下ぐること**」も〔千川（小石川）が砲兵工廠内を通過する水路の実地視察・無名橋下の掘下げ要求＝[BOOK-009](BOOK-009.md)（1910・砲兵工廠内通過記録）と[GOV-208](../gov/GOV-208.md)（1938・仙台橋経由）の間の時期の工廠内流路記録〕。
- **旧神田上水治水の府知事宛意見書〔確認・repo初出〕**: 大意見書として「客年八月大洪水以來**牛込區小石川區高田村ハ舊神田上水治水ノ目的ヲ以テ聯合會ヲ組織シ**…一、**小石川區關口町ニ於ケル堰ノ排水口ヲ擴大スルコト**、二、**堰ノ排水口ノ開閉ヲ自在ナラシムルコト**、三、**堰以西上流ノ堤防ヲ完全ナラシムルコト**、四、**江戶川橋附近河幅狭隘ナル箇所ヲ前後ノ幅員ニ做ヒテ取擴ケ横架セル水道鐵管ヲ橋梁ノ行桁下端以上ニ引上クルコト**、五、堰以東下流ハ適度ノ浚渫ヲ施シ流水ヲ充分ナラシメ出水時氾濫ナカラシムルコト」＝**旧神田上水（江戸川）治水のための①関口町の堰（＝大洗堰比定）の排水口拡大・②開閉自在化・③上流堤防の完全化・④江戸川橋付近の河幅拡げと水道鉄管の引き上げ・⑤下流浚渫**を列挙した意見書〔大洗堰（関口の堰）の排水口改良要求の一次記録。「横架セル水道鐵管」＝江戸川橋に架かる水道鉄管〕。
- **大正2〜5年のその他〔確認〕**: ①大正2年2月23日「**千川上水ニ關スルモノ**」区会（水道町小石川区役所内議事堂・内容省略の記載）〔千川上水を議題とした区会の開会記録。議題内容は本書に省略されている〕。②大正3年9月23日聯合会「**江戶川橋下流（小日向水道町裏）ヲ現設計幅員以上ニ取擴ケルコト及…改修工事ハ上流ヨリ着手セラルヽ樣陳情**」。③**小日向水道町裏側買上**について市の予算12万円の増額決定。④大正5年6月「**江戶川上流豐橋面影橋間の實地視察の上市役所へ出張、兩橋間の堤防應急手當方に付き陳情**」〔豊橋〜面影橋間の堤防応急手当＝江戸川上流区間の治水記録〕。⑤大正期の区要望（大正6年）に「**千川工事ノ促進竝江戶川改修工事ハ繼續年限短縮ヲ望ム**」「**早稻田鶴卷町ヨリ江戶川公園ニ達スル適當ノ個所ニ橋梁ナク關口町方面ヨリノ通學兒童ノ不便多ク…急速ニ架橋セラレンコトヲ望ム**」〔早稲田鶴巻町〜江戸川公園間の架橋要求＝現在の面影橋周辺の交通史資料候補〕。

## 制限・未解決

- ①区会史の記録であり、市の工事記録・設計図面とは別の側の一次資料。設計変更（下流への下水新設）の具体的位置・対象区間は本書では特定できない。②「舊水道を鐵管にすること」の旧水道が千川上水の市内残流路（音羽町の旧神田上水）か小石川水道町の旧水道かは、文脈（音羽町大下水と並記）から旧神田上水残流路と推定するが断定は要照合。③関口町の堰＝大洗堰の比定は位置記述（関口町・排水口）からの推定。④各陳情の結果（実施・不実施）は市側資料で確認する必要がある。⑤大正2年2月23日の千川上水区会は「内容省略」で議題不明。
