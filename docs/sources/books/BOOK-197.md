# [BOOK-197] 名取菊黄白長者（1779）— 鶏声窪の地名由来譚（宝掘り・けいせい窪）〔第167回〕

- **書誌〔確認〕**: 山東京伝画『名取菊黄白長者』（鶴屋喜右衛門板・安永8〔1779〕・NDL次世代デジタルライブラリー [book/9892446](https://lab.ndl.go.jp/dl/book/9892446)）。ひらがな主体の読み物（黄表紙系）で、OCRの崩れが大きい。**引用文言はすべて候補であり原画像照合必須。譚は伝承として扱い史実とは断定しない。**
- **鶏声窪の地名由来譚〔確認・文言候補・repo初出〕**: 「**…こがねのにはとりおんな板…とつこの瀧蔵いつほん松太夫はこゆこみにてよな金色の光りさしにはとりのこへするよしきゝおよびてこれまさにふんじつのたからなりと此所へきたりひかりをめあてにほりうがちたからをゑる是より此所をけいせいかくぼ鶏声窪といへり□世に傾城と心へるはひなりがたや**」＝**金色の光がさし鳥の声がするのを手がかりに（松太夫・とつこの瀧蔵が）宝のありかと心得てこの所へ来たり、光をめあてに掘り穿って宝を得、「これより此所をけいせい窪＝鶏声窪といへり」、世に「傾城」と心得るのは字違いである旨**という鶏声窪の地名由来譚〔**①鶏声窪の地名由来を「鳥の声（鶏声）＋窪」の地形的説明ではなく「金色の光をめあてに宝を掘り得た」譚とし、「けいせい窪（鶏声窪）」の命名・「傾城ヶ窪」は字違いという趣旨の1779年の読み物側記録（repo初出）、②[BLOG-240](../blogs/BLOG-240.md)の江戸期地図の「傾城ヶ窪」表記と対照される字音の揺れ（鶏声／傾城）の18世紀の側の用例、③登場人物（松太夫・とつこの瀧蔵・金王丸・世田ヶ人口勘八等）は読み物の仮構で、谷頭地名の由来譚の系譜（[GAZ-090](../gazetteers/GAZ-090.md)の皇角原旧名説・[GOV-403](../gov/GOV-403.md)の実務文書用例）に加える伝承側のdatapoint**〕。
- **位置づけ〔観察〕**: 鶏声窪の由来としては、字音による複数の説明（鶏声＝鳥の声・傾城＝字違い説）が安永期の読み物で既に語られていた＝地名の通俗語源の成立が18世紀末に遡る資料。史実の由来ではなく譚の存在記録として位置づける。
