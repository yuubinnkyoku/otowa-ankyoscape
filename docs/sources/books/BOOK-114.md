# [BOOK-114] 土地概評価 巣鴨町（1922）

- **書誌〔確認〕**: 『土地概評価 北豊島郡巣鴨町』（東京府・1922年・地価評価区分の調査書）。NDL次世代デジタルライブラリー [book/921577](https://lab.ndl.go.jp/dl/book/921577)。OCRテキストで谷端川・藍染川関係を確認。**文言はOCR由来で要照合。**
- **谷端川岸の地価・小工場〔確認・repo初出〕**: 字平松・字宮下の評価区分に「**ガード以北の谷端川岸 六〇圓内外**」「**谷端川岸の低地には若干の小工塲あり**」＝1922年時点の谷端川岸（山手線ガード以北）の地価水準と臨川小工場の存在を公文書レベルで記録。
- **染井墓地附近＝「藍染川の上流」注記〔確認・repo初出〕**: 染井墓地附近の評価記述に「**藍染川の上流**」との注記＝**1922年の東京府の土地評価文書で藍染川の上流が染井墓地附近と比定されている**。
- **位置づけ〔観察〕**: [BOOK-109](BOOK-109.md)（西巣鴨町）・[BOOK-110](BOOK-110.md)（滝野川町）・[BOOK-111](BOOK-111.md)（小石川区）の土地概評価シリーズの巣鴨町分で、谷端川岸の土地利用（低地小工場）と藍染川の位置把握（染井墓地＝染井墓地周辺の谷頭低地）を1922年時点の府の評価資料で裏付ける。

## 制限・未解決

- ①「ガード」がどのガード（山手線か豊島線か）かは本文では特定できない。②藍染川の流路を本書のみでは確定できない（染井墓地附近が上流とする1922年の府の認識の記録）。
