# [BOOK-118] 評伝河村瑞賢（1912年）— 千川上水開削の河村瑞賢関与説の伝記書記述

- **書誌〔確認〕**: 『評伝河村瑞賢』（明治45年・1912）。NDL次世代デジタルライブラリー [book/946233](https://lab.ndl.go.jp/dl/book/946233)。**すべての引用は同館OCRテキスト由来であり、文言・人名・数値は原文画像との照合を要する。**
- **河村瑞賢関与説〔確認・repo初出〕**: 「**元祿九年、瑞賢千川太郞兵衞・千川德兵衞ノ兩人ニ命ジテ、千川上水ヲ始メサセタ**、多摩郡保谷村デ多摩川ヲ引入レ、**巢鴨村マデ六里十八町ヲ掘割ツテ**水ヲ通ジ、**巢鴨ノ庚申塚通リカラ本郷湯島淺草ヘ水ヲ供給スル**」＝**河村瑞賢が千川太郎兵衛・徳兵衛の両人に命じて千川上水を開かせた**とする1912年伝記書の記述。〔新編武蔵風土記稿の「幕府ノ命＝太兵衞・德兵衞」に対し、**瑞賢の指揮（「命ジテ」）を付加した伝記書レベルの伝承**。瑞賢関与の史拠（一次史料）は本文では示されない。人名が「太郞兵衞」（風土記稿は「太兵衞」）と食い違う点・開削長が「六里十八町」（風土記稿系は「六里余」）である点も含め、要照合・断定しない〕〔文言はOCR要照合〕。
- **廃止・再興の通史〔確認〕**: 「**享保七年十月廢止サレタル**」＝差止理由の伝承として「**水道ヲ拵ヘルト火災ガ多クナル**」と云う当時の学説のため、→「**安永九年再ビ之レヲ開キ**」→「**天明六年マタ廢シ**」→「**明治ニ至リ三タビ之レヲ開イテ、岩崎男爵個人ノ所有ニ歸シ、株式會社ノ名**…」＝**火災誘引説を差止理由とする廃止伝承と、明治の再興→岩崎所有→会社化（千川水道）までの通史**。〔文言・年次はOCR要照合〕。
- **位置づけ〔観察〕**: 河村瑞賢説の書誌列（GOV-171『御府内上水在絶略記』には瑞賢記載なし）に、20世紀初頭の伝記書として瑞賢関与説を明記した点が新しい。千川上水開削（元禄9年）の実態が幕府の命（風土記稿）か瑞賢の指揮かは一次史料では未確定であり、本書は伝承の一つとして整理する（断定しない）。
