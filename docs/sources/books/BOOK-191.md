# [BOOK-191] 土地概評価 淀橋町（1922）— 舊神田上水流域の土地利用〔第160回〕

- **書誌〔確認〕**: 東京興信所『土地概評価』シリーズの淀橋町冊（**発行大正11年〔1922〕3月ごろと推定**〔同時期刊行の921572奥付参照・本冊の年は部分的OCRで要照合〕）。NDL次世代デジタルライブラリー [book/921568](https://lab.ndl.go.jp/dl/book/921568)。**引用はOCR由来・要原文照合。**
- **「舊神田上水流域」の文言群〔確認・文言候補〕**: ①「**地勢は〓ね高燥なるも西部は西端中野町との境界をなせる舊神田上水流域に向つて傾斜し**」＝**淀橋町の西部が「舊（旧）神田上水流域」に向かって傾斜する地勢**。②「**中央線以北には神田上水を挾んで中野町字小瀧の高臺と相對する戶山原の陸軍用地の西に連る高臺と其の西、神田上水流域の低地**」＝**中央線以北で神田上水を挟んで中野町字小瀧（小滝）の高台と戸山原の陸軍用地が相対する構造**〔**「舊神田上水」＝上水廃止（1899年淀橋浄水場転用後の逓水停止）後の旧水路の流域としての1922年の呼称**。「神田上水」の区間名と「舊」の限定の使い分けが同冊内で観察できる〕。
- **字別の上水岸文言〔確認・文言候補〕**: ①**字長町**＝「**淨水所の西方に當る舊神田上水沿岸の低地にて近年著しく宅地を增加し北端の東京電燈變電所其他二、三の工塲あり、淀橋々畔より十二社に至る通筋…然れども上水岸の一部には尙若干の田地あり**」＝**浄水所（淀橋浄水場）の西の旧神田上水沿岸の低地の宅地化・変電所・田地の残存**。②**字本村**＝「**(神田上水支流々域)にて國活撮影塲及び日本綱球、和光堂等の工塲**」＝**字本村を「神田上水支流の流域」とする表現**〔**支流の比定（千川系の分水か妙正寺川系か）は本冊からはしない**〕。③**字新堀**＝「**字蜀江山の西に位する神田上水岸の低地にて中流以下の住宅地若しくは工塲地たらんとし現時尙若干の田畑あり**」＝**字新堀（淀橋町の字）の神田上水岸の低地**〔「新堀」の字名が淀橋町（神田上水の中流域）にも現れる点は、新堀の地名分布（谷端川上流の新堀村・淀橋の字新堀）の資料〕。④**字小瀧橋**＝「**神田上水添の低地に至る、北端に小瀧橋あり、其の南に三友社あり**」＝**字小瀧橋の小滝橋・神田上水添（ぞい）の低地**〔小滝橋の橋名とその南の三友社（工塲）の1922年立地〕。
- **位置づけ〔観察〕**: ①本冊は[GOV-366](../gov/GOV-366.md)（嘉永5年・柏木・中野・上戸塚の「神田上水堀筋」境界）と[BOOK-192](BOOK-192.md)（中野町・上水と上げ堀）の間の区間（淀橋〜戸塚）の1922年の土地利用・地勢記録で、**嘉永期の「堀筋」境界帯が大正期に「舊神田上水流域」の傾斜地・低地として観察される**対応を見られる。②字小瀧橋・中野町字小瀧の対岸構造は、小滝橋（上水の淀橋付近の橋）の位置の比定（[GOV-366](../gov/GOV-366.md)の「小瀧橋ゟ中野村」の方位起点）に1922年側の材料を加える。③十二社（角筈の窪地）・淀橋畔の商業地の記録も周辺の窪地観察の補助資料。
