# [BOOK-087] 『近世練馬史料目録 付 千川家・金沢家文書目録』（1957年）〔repo初出〕

- **書誌〔確認: NDLサーチ書誌〕**: 東京都練馬区史編纂委員会編『**近世練馬史料目録 付 千川家・金沢家文書目録**』（**1957年**）〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000146-I10001_1150369)〕。別レコードに同書の**表記ゆれ「近世練馬資料目録 : 付千川家金沢家文書目録」**〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000136-I1971430859794080410)〕、および「千川家・金沢家」を付録に付けない版の書誌が複数存在する〔[NDLサーチ](https://ndlsearch.ndl.go.jp/books/R100000002-I000000965611)〕。
- **内容〔確認: NDL書誌のタイトル・責任表示のみ／本文未見〕**: 1957年の練馬区史編纂事業（『練馬区史』昭和32年刊行〔[BOOK-065](BOOK-065.md)〕の前身事業）で、**千川家文書と金沢家文書が独立の目録として刊行物に付された**。**1957年時点で千川家文書が既に調査・目録化されていたことの公刊記録**で、千川家文書の所在・規模を知る最初期の公的書誌。
- **位置づけ〔観察〕**: 現行の千川家文書アーカイブ（[GOV-089](../gov/GOV-089.md)・練馬区立石神井公園ふるさと文化館・297点・元禄9年〜明治17年）や、練馬区登録文化財としての千川家文書・千川家の墓（[GOV-004](../gov/GOV-004.md)・[GOV-078](../gov/GOV-078.md)）より約30〜40年さかのぼる時点での文書群の存在確認の入口。**金沢家文書**はrepo未収録の新出の文書家名（[近世練馬諸家文書抄](https://ndlsearch.ndl.go.jp/books/R100000002-I000001025218)（1961年）との関係も未確認）。
- **制限・未解決**: 本文未見。1957年目録時点の点数・資料名と現行297点（[GOV-089](../gov/GOV-089.md)）との対応、千川家文書がこの時点でどこに保管されていたか、金沢家文書の現況は不明。所蔵調査（NDL・練馬区立図書館・石神井公園ふるさと文化館）が次の一手。
