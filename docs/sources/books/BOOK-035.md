# [BOOK-035] 森鴎外『鼠坂』（1912年）

- 森鴎外『鼠坂』。青空文庫の[公開本文](https://www.aozora.gr.jp/cards/000129/files/45618_25532.html)を確認。
- 冒頭「小日向から音羽へ降りる鼠坂と云う坂がある」。急で細く、曲がった坂、空地と松、邸宅の建築などを描く。
- 水窪川・弦巻川という川名やその河道の直接描写は、確認した本文にはない。流域周辺の文学作品として採録。
- 作中の人物・屋敷と特定史実との対応は出典自体からは確定できない。
