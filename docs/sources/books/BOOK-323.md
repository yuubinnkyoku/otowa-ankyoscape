# [BOOK-323] 江戸名所花暦 春之部・桜の条（有朋堂文庫〔第95〕活字版）— 千川上水堀割の樋の口の文言確定と武蔵野1913引用の原典

## 書誌〔確認: NDL次世代デジタルライブラリー・IIIF manifest・2026-11-25〕

- 塚本哲三 等編『有朋堂文庫.〔第95〕』（有朋堂書店・**大正4=1915**・[book/1913680](https://lab.ndl.go.jp/dl/book/1913680)・288頁）。本冊は**江戸名所圖會（搖光之部ほか）＋『江戸名所花暦』＋同『江戸名所圖會内容細目』**を活字化した分冊で、**江戸名所花暦は原本頁381以降に収録**（頁頭「江戶名所花曆」・内容細目「江戶名所花曆 春夏秋冬ノ四部ニ分チ述ス」）。千川上水の文言は**春之部・桜の条の金井橋章**（OCRコマ0217付近）にある。**対校テキスト**: 岡山鳥（島岡権六・号琴驢）編・長谷川雪旦画『江戸名所花暦』の吉川弘文館活字版（**明治44=1911**・[book/763659](https://lab.ndl.go.jp/dl/book/763659)・115頁・同書p.50-51に同文言・**ルビ「ほりわり」付き**）。解題によれば著者岡山鳥＝**島岡権六（長盈・字哲甫・号琴驢・丹前舍）**、曲亭馬琴に私淑した読本作者で**文化末年に「岡山鳥」を号した**＝本書の成立は文化末〜文政期以降、[BOOK-158](BOOK-158.md)の書誌（**文政10年〔1827〕頃刊**・別称・江戸遊覧花暦）と整合する年代枠。**引用文言は2活字版ともOCR由来で、版本・原本画像との照合を要する。**

## 文言〔確認・要照合・本登録の核心〕

春之部・桜の条で、四谷から青梅街道を遡って小金井の桜に至る看櫻順路の記述（吉川弘文館版は「ほりわり」のルビ付き）:

> 中高井戶、正庵村…吉祥寺村、左側觀音堂、淡島大明神の祠あり…別當月秀山井頭院、右側に八幡宮あり、當村鎭守なり、別當安養寺（OCR「安艱寺」）、左 **井頭辨財天への道あり。七丁ほど入り、西久保關前、是に千川上水堀割（ほりわり）の樋の口あり。今は絕て埋れり。此邊總て尾州侯の御鷹場なり。** 關前新田、保谷新田…

## 読み取り〔観察・断定していない部分は明記〕

- **①樋口文言の原典側の表記は「堀割」**: [BOOK-137](BOOK-137.md)（並木仙太郎編『武蔵野』1913）が引く「**是に千川上水堀六百年割の樋の口あり**」の「**六百年割**」について、原典の活字版2系統（有朋堂1915・吉川弘文館1911）はいずれも「**堀割**」で一致（吉川版は「ほりわり」のルビ付き）＝**「六百間割」等と読む可能性は大きく後退し、『武蔵野』側の誤植かOCR崩れが有力**〔『武蔵野』の活字自体が「六百年割」となっている可能性とOCRの崩れの二通りがあり、『武蔵野』原本（[book/980800](https://lab.ndl.go.jp/dl/book/980800)）の紙面照合まで確定しない〕。
- **②観察時期の前倒し（1913→江戸後期）**: 『武蔵野』の当該箇所は**「と『江戶名所花曆』又『東都より行程七里半ほどあり…』」と明示的に江戸名所花暦を引用する引用ブロックの中にあり**、西久保関前の文言は同書の編者・並木仙太郎の1913年現勢観察ではなく**花暦成立期（文政10年頃の原板か天保期内の再板・[BOOK-158]の書誌参照）の観察文言の引載**と確定する〔[BOOK-137]の「1913年時点ですでに埋没していたことの観察」という位置づけの訂正。享保7年（1722）廃止から約100年後の樋口の埋没観察として、廃止後の上流部の施設の残存状態を伝える江戸後期の同時点文言候補〕。
- **③樋口位置の幾何関係の基準点**: 順路上、**吉祥寺村の別當井頭院付近から「左 井頭辨財天への道」が分岐し、そこから「七丁ほど入り」た所が西久保関前で、そこに千川上水堀割の樋の口があった**＝①井頭（いのがしら）への道との分岐、②七丁という距離、という2つの基準で樋口の位置を示す最良級の江戸期文言〔現在の西東京市保谷側（旧西久保村・関前新田）の流路復元の対照資料。「何の樋か」（本流の伏樋・玉川上水からの分水樋）は本条単独では特定できない（[BOOK-137]の留保を維持）〕。
- **④尾州侯御鷹場と関前新田・保谷新田**: 「此邊總て尾州侯の御鷹場なり」＋「關前新田、保谷新田」＝**保谷周辺が尾州徳川家の御鷹場であったことの花暦の地的確認**〔関前新田・保谷新田の並記は[BOOK-137]の康樂園（保谷新田の私園）・[GOV-251](../gov/GOV-251.md)等の関前新田系の諸資料と対照可能。看櫻の途上の蕎麦・酒を鬻ぐ店の文言はOCR崩壊箇所があり引らない〕。
- **⑤看櫻順路の全体**: 四谷・内藤新宿→成子→淀橋→中野（左に鍋屋横町・堀之内）→…→高圓寺村→…→關口→田畑村→白幡→小崎→…→高井戶→正庵村→吉祥寺村→西久保関前→保谷新田→新橋・梶野橋・關野橋→小金井橋→貫橋・留橋・車田新田→玉川の堰入（五六里）＝**文政期の四谷から小金井に至る桜見物の顺路の一次叙述**（玉川上水沿い・青梅街道筋の村名の配列）〔[BOOK-137]の引用群（「道筋四谷、中野、光圓寺村…關前村、保谷新田邊より南岸に花有」）の原典本文側の全形〕。

## 制限・未解決

- ①引用文言は活字版（1915・1911）のOCR由来で、**花暦の版本・原本地紙の原字（「堀割」の字面・「埋れり」の表記・「尾州矦/侯」等）との照合は未実施**。②本冊が文政10年原板か天保6年/8年再板かの特定はできていない（[BOOK-158]と同じ留保。いずれにせよ江戸後期の観察）。③「何の樋の口か」（千川上水本流の伏樋・玉川上水からの分水樋・西久保関前の地域分水の樋）は特定できない。④吉川弘文館版の「保谷新田」以降の文言（蕎麦・酒・麦酒(?)を鬻ぐ店）はOCR崩壊が著しく判読しない。⑤有朋堂文庫〔第95〕の内容細目（江戸名所図会五十音索引）に「弦卷川(二)」の行があるのは同索引が江戸名所図会巻之二を参照する証であるが、弦巻川本文は本冊の分担外で新規文言はない。
