# [BOOK-064] 豊島区の湧水の調査ノート（研究紀要第11号）

- **書誌**: 横山恵美「**＜調査ノート＞豊島区の湧き水をたずねて**」、『豊島区立郷土資料館研究紀要』**第11号**収録。正式誌名・刊行年ともに確定済み（第75回・2026-11-14）: **『生活と文化』紀要第11号・2001年12月25日発行・800円**（[豊島区立郷土資料館刊行物ページ](https://www.city.toshima.lg.jp/129/bunka/bunka/shiryokan/kankobutu/005957.html)の目次で確認。同号の「調査ノート」欄に収録）。
- **〔二次言由〕** 暗渠ハンター（髙山英男）の湧水シリーズ（[BLOG-056](../blogs/BLOG-056.md)ほか）が**「豊島区の湧水が充実した冊子」**として当該論攷を紹介済み。[2026-10-23・暗渠ブログ横断調査](../../2026-10-23・暗渠ブログ横断調査.md)の「原典追跡」最優先課題だったため、**書誌の資料ファイル化を行い追跡状況を記録**する。
- **意義〔推定〕**: 弦巻川・水窪川・谷端川の各谷頭・崖線の湧水について**区立郷土資料館による（準）一次的な地点記録**が含まれる可能性。谷頭湧水の減衰時期論（[PAP-018](../papers/PAP-018.md)・[BLOG-067](../blogs/BLOG-067.md)）の照合候補。
- **〔未確認〕** 本文・掲載頁・湧水地点一覧の有無・図版。所在は豊島区立郷土資料館（有償刊行物リスト経由で購入・閲覧可の可能性）。
