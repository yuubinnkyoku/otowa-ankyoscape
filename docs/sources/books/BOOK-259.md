# [BOOK-259] 田無中央図書館編『田無の昔話 その3』（1979）〔西武新宿線開通前の「青梅街道沿いの町並み図」掲載の地域史料〕

## 書誌〔所在のみ・二次転記〕

- 田無中央図書館編「**田無の昔話 その3**」（**昭和54年〔1979〕**）＝[BLOG-283](../blogs/BLOG-283.md)（大貫伸樹・2015-03-08「田無用水のはけ口は今どこに？」）内の言及「**「青梅街道沿いの町並み図」部分（田無中央図書館編『田無の昔話その3』昭和54年より。この地図には、まだ西武新宿線やその奥にある民家はない。**」〔確認: 引用文言〕。
- **内容の要点〔観察・二次転記〕**: 同書掲載の「**青梅街道沿いの町並み図**」は、**西武新宿線（田無駅開業1927年〔村山線として1927年4月開通〕）や沿線民家を描かない田無の町並み地図**＝**開通前（1927年以前）の状況を写した地図として田無市街地の読図候補**。大貫伸樹がはけ口・田無神社〜石神井川間の流路復元に本図（部分）を利用したという使用実績の記録も付随する。

## 意義〔観察〕

- 西武新宿線開通以前の田無の町並み・水路を読める**市史・地図ではない地域史料（図書館編集の昔話集）の掲載図**という独特の系統。昔話集の挿図は刊行の趣旨から「古老の記憶に基づく復元図」の可能性もあり、田無用水・はけ口の流路の対照資料（[BLOG-283](../blogs/BLOG-283.md)）として、また**「古老に聞いた田無用水」〔BLOG-280の探索課題〕と同種の聞き取り系資料の系譜**として、所在・実物の確認価値が高い。
- 現地確認ルート: 西東京市中央図書館（旧田無市域の田無中央図書館の後身）の郷土資料架・書誌検索。NDLサーチ（2026-11-22・title=田無市史等の検索）では本書の書誌レコードは未検出で、市立図書館ローカル蔵書の可能性。

## 制限・未解決

- ①実物は未確認（本文中の部分引用図もブログ掲載画像止まり）。②「その3」とある以上シリーズ物（その1・その2等）で、水路記述が他号にあるかは未調査。③町並み図の原図・典拠（実測図か古老の記憶による復元図か）は未確認。④大貫は本図の年代を「西武新宿線やその奥にある民家はない」から開通前と読むが、描画対象が青梅街道沿いに限られる可能性もあり、範囲・年代の断定はしない。
