# [BOOK-188] 江戸年中行事（鶴屋喜右衛門版・江戸後期）— 雑司ヶ谷鬼子母神参りと法妙寺の角力の年中行事記録〔第158回〕

- **書誌〔確認・書誌要再照合〕**: 著者不詳『江戸年中行事』（**鶴屋喜右衛門**版・江戸後期の版本。刊年は未確定でyearは18世紀後半の概算〔1800近似〕。**菊岡沾涼著『江戸年中行事』（享保期の改版本群）が知られるが、本版の作者記載はOCRでは確認できなかったため、沾涼著への比定は本登録では行わない**）。NDL次世代デジタルライブラリー [book/2533820](https://lab.ndl.go.jp/dl/book/2533820)。
- **正月8日の雑司ヶ谷鬼子母神参り〔確認・文言候補・repo初出の礼俗記録〕**: 正月8日の部に「**雑司ヶ谷鬼子母神参り 坂本入谷にもあり**」＝**正月8日の年中行事として雑司ヶ谷鬼子母神への参詣が記され、「坂本入谷にもあり」（鬼子母神の礼拝所が坂本・入谷にもある、または同参りが坂本・入谷でも行われる、のいずれか・原画像照合待ち）と併記する江戸期の記録**。〔**鬼子母神の8日縁日・正月8日参詣の礼俗の江戸期の記録候補**＝[ORG-035](../org/ORG-035.md)（雑司ヶ谷鬼子母神堂）・[GAZ-070](../gazetteers/GAZ-070.md)（江都近郊名勝一覧・安政5年の雑司ヶ谷参詣記述）に先行する年中行事レベルの datapoint。坂本（目白・雑司ヶ谷側の坂本〔豊島区目白・雑司ヶ谷の町名〕）・入谷（下谷の入谷鬼子母神か・要照合）との併記の文脈は原画像照合後に解釈する。〕
- **5月16日の雑司ヶ谷法妙寺の角力〔確認・文言候補〕**: 「**十六日 ◯雑司ヶ谷法妙寺角力あり**」＝**5月16日に雑司ヶ谷の法妙寺で角力（相撲興行）があるという年中行事記録**。〔**「法妙寺」は雑司ヶ谷の本妙寺（法華経寺の流れを汲む日蓮宗の寺・[GAZ-085](../gazetteers/GAZ-085.md)の本浄寺門前等の雑司ヶ谷寺社群の文脈）のOCR崩れ候補**として要照合（本妙寺の堂宮・本行寺等の比定も含めて原画像の実字確認後に断定する）。雑司ヶ谷の寺社の礼俗（参詣・興行）が年中行事書に採られたこと自体が、**雑司ヶ谷が江戸市中の行楽・礼俗圏に組み込まれていた記録**（[GAZ-070](../gazetteers/GAZ-070.md)の江都近郊名勝一覧の対照資料）。〕
