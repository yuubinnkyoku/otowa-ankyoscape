# [BOOK-049] 関義城『江戸東京紙漉史考』

- **書誌〔確認：NDLサーチ〕**：関義城著、**富山房、1943年刊**、372頁、図版45枚、地図2枚、26cm。図版10枚に手漉見本添付。請求記号 **585.6-Se139e**、書誌ID **000000909559**、NDLJP **1874690**。[書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000000909559)／[デジタル版](https://dl.ndl.go.jp/pid/1874690)（図書館・個人送信対象、一般の無認証閲覧不可）。
- **内容〔二次転記・原本未閲覧〕**：落合道人の[2026年10月6日記事](https://tsune-atelier.seesaa.net/article/521591207.html)が本書所収の東京府産紙同業組合沿革を紹介。**1920年12月27日設置認可、対象地域は北豊島・豊多摩・荏原・南足立の4郡と東京市小石川区、当時の組合員115名**と転記する。同記事は組合全体の推移として**1922年116工房、昭和期48工房、1929年解散**とも記す。小石川区や音羽だけの業者数ではない。原本の該当頁・統計表は未照合。
