# [BOOK-242] 豊島区「平成ひすとりぃ」第4章第2節（池袋西口公園整備の項）〔repo初出・弦巻川の水源丸池が2017年の公園デザインの公式モチーフに採用された区史本文の文言〕

- **書誌〔確認: ADEACとしまひすとりぃ・2026-11-22取得〕**: 「**としまひすとりぃ: 平成ひすとりぃ**」（目録ID mp101000・豊島区・公開年令和5年〔2023〕・ウェブコンテンツ・[全5章で確認済みのは ht0101040〜ht0402030 等の本文頁群](https://adeac.jp/toshima-history/catalog/mp101000)）。**本頁＝第4章「消滅可能性都市から持続発展都市へ」第2節「としま新時代へ 変貌を遂げる池袋副都心」の国際アート・カルチャー都市構想・池袋西口公園整備の項（ht0402030・texthtml取得・CC BY）**〔[BOOK-239](BOOK-239.md)（第2章第2節・さくら小学校）と同じ mp101000 の別頁〕
- **GLOBAL RING＝丸池モチーフ文言〔直接確認・repo初出・本資料の目玉〕**: 池袋西口公園の整備経緯の項で「**平成29（2017）年5月、区は地元町会・商店会・再開発準備組合・東京芸術劇場等各代表で構成される「池袋西口公園整備検討会」を立ち上げた。そして同月29日から整備基本計画の策定業務を委託する事業者をプロポーザル方式で公募、8者からの応募を受け、書類審査、プレゼンテーション審査を経て、7月に三菱地所設計と南池袋公園を設計したランドスケープ・プラスの共同企業体を受託事業者として選定した。**」「**池袋の地名の由来とも言われるこの地にかつてあった弦巻川の水源「丸池」をモチーフにしたリング状の屋根（GLOBAL RING）のデザインの斬新さや、イベント開催時はもとより、日常時から災害時まで様々なシーンに対応できる機能を備えた提案内容が高く評価された**」「**以後、この提案をもとにさらに検討を重ね、同年12月、「池袋西口公園等整備基本計画」を策定した。**」＝**①2017年5-7月の公園整備事業者選定（プロポーザル・8者応募・JV）の経緯、②デザインの中心的モチーフが「かつてあった弦巻川の水源「丸池」」であり、しかも「**池袋の地名の由来とも言われるこの地**」と池袋の地名由来に接続する区史本文文言、③同年12月の「池袋西口公園等整備基本計画」策定、④審査に池袋西口公園整備検討会が加わった**〔A. **弦巻川の水源丸池（西池袋側の失われた池）が2017年に公式な都市公園のデザインモチーフとして採用され、2019年公開に至る改修へ結実した**＝丸池の現代的顕彰の行政側決定の本文。B. 「池袋の地名の由来とも言われる」という限定表現は地名由来説の断定ではなく、区の採用時の認識を伝える。C. 検討会の構成（地元町会・商店会・再開発準備組合・東京芸術劇場等）も記録される。D. 対となる区議会側の文言が[GOV-496](../gov/GOV-496.md)第253回追記（平成29年第3回あいさつ・2017年9月）＝2系統の行政文書での丸池モチーフ文言の二重記録〕
- **意義〔観察〕**: ①**丸池（弦巻川水源）の顕彰史の下限が2017年に具体化する**＝[BLOG-231](../blogs/BLOG-231.md)（増田剛己の弦巻川痕跡まち歩き・元池袋の丸池）等の池袋村図・丸池研究や、丸池をめぐる灌漑管理の古地誌二次引用（1997年広報等）に対し、**池の消失後に公共空間のデザインの主題として公式再採用された事実**が記録された。②弦巻川は區内でも景観・デザイン資源として2000年代以降に再解釈されている例で、[GOV-496](../gov/GOV-496.md)（1990年代の谷端川緑道文言）と並ぶ「河川の記憶の都市計画への転用」の系列。③国際アート・カルチャー都市構想（2015年3月策定）・4つの公園構想（池袋西口公園・造幣局跡地・ハレザ周辺・南池袋公園）等の文脈も同頁に含まれ、池袋副都心近代史の背景資料になる。
