# [BOOK-243] 豊島区「平成ひすとりぃ」残章掃引群〔宿題であったmp101000未収録頁の全走査・千川小跡地・千川中学校・谷端川プロムナードの項〕

- **書誌〔確認: ADEACとしまひすとりぃ・2026-11-22〜本実行でmp101000本文頁30 ht全取得・全走査〕**: 「としまひすとりぃ: 平成ひすとりぃ」（豊島区・[mp101000](https://adeac.jp/toshima-history/catalog/mp101000)・公開年令和5年〔2023〕・CC BY・texthtml本文取得）。**第252回で第2章第2節（[BOOK-239](BOOK-239.md)）のみを収録していた時の「残章走査」課題の消化で、本ファイルは千川・谷端川関連の文言を含む6頁（ht0101040・ht0301020・ht0302020・ht0303030・ht0402010・ht0402020）を1ファイルに掃引採録する**〔1資料1ファイル原則に対し同一mp101000内の掃引群として1ファイル管理（[GOV-496](../gov/GOV-496.md)の議事録群と同じ扱い）〕。
- **①中央環状新宿線高架計画と千川中学校〔直接確認: ht0101040・repo初出・本群の目玉〕**: 第1章第1節「都市高速道路中央環状新宿線建設事業」の項で、昭和57（1982）年策定の中央環状新宿線整備計画が豊島区では**西側区間にあたる要町・千川・高松地区側を対象に高架構造での整備が計画されていた**ことに対する住民運動の記述＝「**高架化が予定されている区間の沿道住民からは、計画の再検討とともに地元千川中学校での説明会の早期開催や、周辺住民の十分な理解と同意がないかぎり具体化を進めないことなどを求める陳情2件が区議会に提出され、昭和63（1988）年区議会第1回定例会でいずれも採択された。**」＋「**千川中学校での説明会でさらに不安を募らせた沿道住民らは、新たに4件の請願を区議会に提出した。請願者には沿道住民・町会に加え、高架への出入路に面する聖パトリック幼稚園の関係者も含まれていたが、その趣旨は建設計画そのものに反対するもの（1件）と高架式での建設に反対し地下化の再検討を求めるもの（3件）の二つに分かれていた。**」＋「**結果は全線地下化とはならなかったが、区内路線の大部分が地下となる変更案は区にとって大きな成果と言えた。しかし、千川中学校はこの新たに示された案でも依然として高架となる区間に面し、また換気塔が設置される要町交差点の近くには要町小学校（現・要小学校）があった。このため、高架反対運動は児童生徒たちへの健康被害に強い不安を感じる保護者らが中心となっての公害対策運動へと形を変え、新局面を迎えることとなった。**」＝**①中央環状新宿線の高架計画が千川中学校・要町小学校・聖パトリック幼稚園を含む千川・要町地区の学校環境問題として住民運動・区議会陳情請願（計6件・陳情2件はS63-1で採択）に至った経緯、②換気塔の設置場所＝要町交差点の言及、③計画変更（大部分の地下化）と運動の続行**〔A. **千川上水・千川地名の核心地域（千川・要町）が1980〜90年代に大規模高架計画に直面した史実と住民側の運動の記録はrepo初出**＝千川地区の土地利用史・環境史の基本資料。B. 都と首都高速道路公団の昭和63年5月27日説明会・7月15日委員会質疑等の経緯も記述される（この部分はrepo直接採録対象としない）。C. 千川中学校が「依然として高架となる区間に面し」＝最終的な学校周辺の構造形式（地下・地上・変更後の位置関係）は本項記述のみでは確定できない〕
- **②谷端川プロムナード構想1988〔直接確認: ht0302020・README既出文言の資料ファイル化（SSOT補完）〕**: 第3章第2節「防災まちづくりの推進」の項で「（立教大学地区不燃化まちづくり協議会も）63（1988）年に**谷端川プロムナード構想**、平成2（1990）年にはブロック塀の生垣化や建物の後退、地域緑化等の地域独自の「まちづくり協定」を提案、**谷端川緑道の整備**や池袋第三小学校の緑化活動（池三小緑の会）など、地域のシンボルである立教大学の景観と調和する緑豊かなまちづくりが進められた。**」＝**1988年谷端川プロムナード構想→1990年まちづくり協定→谷端川緑道整備という架構の一次文言**〔この文言自体は[README](../../../README.md)第169回（行1739系の項）で出典URLつき既出（[URL](https://adeac.jp/toshima-history/texthtml/d100010/mp101000/ht0302020)）だが、**資料ファイルが未登録だったため本ファイルでSSOT化する**。README本文の解釈（対象区間・幅員は本文では確定できない等）はそのまま〕
- **③旧千川小学校の文化活用〔直接確認: ht0301020・ht0303030・repo初出〕**: 第3章の項で「**芸術家と子どもたちは、同じく学校統合により14（2002）年3月に閉校となった旧千川小学校で稽古場運営や子ども向けのワークショップを試行的に実施していた。**」（ht0301020）＋2003年夏「アート夏まつり＠旧千川小学校」等の展開（ht0303030）＝**旧千川小学校（千川上水旧沿いの小学校・[BOOK-239](BOOK-239.md)の2002年閉校・2002〜03年に芸術NPOの稽古場・ワークショップ拠点として文化活用された記録**〔千川小の閉校後利用史の一次文言。ANJ（劇団）・芸術家とこどもたち等の活動主体名も本文に記される。「旧千川小学校は利用団体が多く、施設開放事業という枠の中で事業を展開していくことには限界があった」という制約文言も含む〕
- **④「せんかわみんなの家」と特養「千川の杜」〔直接確認: ht0402010・ht0402020・repo初出（第253回追記の[GOV-496](../gov/GOV-496.md)区議会文言と対応）〕**: 第4章第2節の少子化・高齢化対策の項で「**高松第一保育園を民営化し、旧千川小学校跡地に新たに私立認可保育所「せんかわみんなの家」（要町3－54－8、定員105名）を開設**」（ht0402010）＋「**図書館跡地の2か所にそれぞれ社会福祉法人を誘致し、平成27（2015）年4月に「千川の杜」（要町3－54－16）、同年11月に「東池袋桑の実園」（東池袋5－39－18）の2施設を開設した。これにより定員216名分（うちショートステイ22名）の増床が図られ、**」（ht0402020）＋千川小跡地（高松第一保育園の移転改築を含む飛び地活用から特養整備候補への転換）と旧中央図書館跡地の2か所で整備に至った経緯の記述＝**①旧千川小学校跡地（要町3-54-8＝保育園「せんかわみんなの家」・要町3-54-16＝特養「千川の杜」）の転用施設名・所在地番・定員・開設年（いずれも現在地名・公益施設の所在の一次文言）、②千川小跡地と旧中央図書館跡地の2か所で事業者選定・整備が進めた経緯、③区議会側の文言群（[GOV-496](../gov/GOV-496.md)・平成22年第1回の特養候補浮上・平成24年第2回の49事業者公募説明会・平成26年第4回の「千川の杜」開設経緯）との対応**〔「千川の杜」「せんかわみんなの家」の施設名・所在はrepo全域初出。千川小学校の跡地が「千川」の名を冠した社会福祉施設（千川の杜）と「せんかわ」の名を冠した保育園に転用された事情は、千川地名の現代的継承の一事例として記録に値する（解釈は広げない）〕
