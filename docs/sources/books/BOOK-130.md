# [BOOK-130] 東京市史稿 変災編第2（1915年）— 文政12年水害の神田上水崩込と掃部橋流失の因果記録

- **書誌〔確認〕**: 東京市役所編纂『**東京市史稿 変災編第2**』（大正4年・1915年・東京市役所刊）。NDL次世代デジタルライブラリー [book/1915633](https://lab.ndl.go.jp/dl/book/1915633)。江戸〜明治期の風水災の編年体集成（『江戸洪水記』『柳營日次記』『寳曆現來集』『金地院記錄』『續日本王代一覽』『出水一件』等の一次史料からの抄出）。**OCRの列崩れが激しく、文言・数値の対応は原文照合まで保留。引用はすべて同館OCRテキスト由来。**
- **文政12年（1829）8月2日大風雨の「神田上水に崩込」と掃部橋・麁朶橋流失〔確認・repo初出〕**: 「文政十二丑年八月二日、大風雨にて、**夜八ツ時前より、目白坂上家作二三軒崖崩落、神田上水に崩込、江戶川口水あふれ、小日向內〇七邊關口改代町、市一圓出水、掃部橋·麁朶橋中の橋流失、江戶川端水道橋邊小日向水道町邊內に俄に押水致し、何も床上三四尺水上り、夜中俄の事故、誠に寢耳に水とは此時の事なり。其節流家又は卽死怪我人等有之、上水流崩込にて留たる故、一時に出水しけり**」〔**①目白坂上の家作2〜3軒の崖崩落が神田上水（の流路）に崩れ込み、上流を堰き止めた後に一時に出水したという因果関係つきの水害記録、②掃部橋・麁朶橋（麁朶橋の語はrepo初出候補＝麦香橋系の表記か）・中之橋の流失、③江戸川端の水道橋辺・小日向水道町辺の床上3〜4尺、④流家・即死怪我人の存在**＝[BOOK-126](BOOK-126.md)の変災章（享保13年〜明治43年の水害年表）にない**文政12年8月2日の出水の記録としてrepo初出**。「上水流崩込にて留たる故、一時に出水」の説明は、出水源が目白坂上の谷筋（弦巻川上流域か）であったことを示唆するが、崩込先の「神田上水」が旧上水の残流路か本流かはこの文言からは確定できず断定しない〕。
- **文政12年8月2日の内神田の水道「水切」〔確認・repo初出・要原文照合〕**: 「然る處**內神田內〇七井下町邊は、夜中より俄に水切と成、春中の出火後、堀井未だ修復も無之、水道計を一圓に用ひし處、俄の水切ゆゑ狼狽せり**」〔**崖崩落で神田上水の水が止まったため、内神田の井戸（堀井）の修理が未了で水道の水を一円に使っていた町々で夜中に急に水が切れ、狼狽したという記録**＝**文政12年（1829）時点で内神田側まで神田上水の給水が機能していたことの傍証文言（repo初出）**。「春中の出火後、堀井未だ修復」＝同年春の出火で井戸が壊れ水道依存になっていた事情。神田上水の廃止期（享保7年〔1722〕廃止説＝[GOV-170](../gov/GOV-170.md)等）と1829年の給水実態の関係は、この文言だけで確定できない（残流路・部分給水の可能性）が、**廃止後も水道用水として使われていたと読める記録として残す**〕。
