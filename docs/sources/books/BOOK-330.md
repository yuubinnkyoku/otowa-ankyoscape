## 文言〔確認・OCR由来で判読の対立箇所は留保〕

- **護国寺前から一丁余の音羽川と溪谷景観**: 「（前略）條**護國寺前を左へ曲つて一丁餘行くと音羽川といふ、狹い流れながら割りに溪の深い川がある**。……**向う岸の崖の上を椎の老木**（中略）**其處には丸木を並べた橋が架つてゐて橋下には浮々たる水聲が聞え**（中略）**夏なは寒いといふほどではないが一寸都離れのした幽**（OCR「幽菱」・寂/邃等の判読対立候補）**な場所があ**（る）」（OCR頁135〜137付近・印刷頁135「バラ雨…」〜137近傍の対応付けは断片数字ベース）。続けて「**川についた道を右手の山の方へと登つて行つた**。（中略）**此の邊の山は（三）面に雜木林**」「市之丞は其の橋を渡らずに（中略）**雨の音がはげしく聞えて來た**」。
- **追跡される側から見た同じ川**: 「（捕手は容易に近付かず）**一方は幾丈もある崖で、近付かない。只三方から取り卷いてゐるだけだ。其の下を音羽川が流れてゐる**」——逃走者が**崖の縁へ追ひ詰められ、その下を音羽川が流れる**という地形構造の記述。
- **場面前段の道と街並み**: 「**音羽の通には一寸した呑み屋な**（ど）**が處どころにあつて、油障子に映る灯かげが黄色くポンヤリ往來を照らしてゐたりする**。**江戶川邊から**見え隱れに彼の後を尾けて來る人間があつた」——江戸川（神田川）べりから「音羽の通」を通って護国寺前へ至る経路としての場面設定〔確認・「音羽の通」が現代のどの道路に対応するかは特定しない〕。
- **地名用例群（第一話「ろくろ首」〜後続の場面）**: ①料理屋「雪乃家」＝「小石川の江戶川べり」の「江戶向きの凝つた造り」の屋敷料理屋（「直ぐ下をば麥が植ゑてある早稻田田圃が廣々と續いて見え、築土の森を目掛けて幕れ行く空を鳥が群飛んでゐる」）②同店の裏口から「川べりの道」に出て「川の音が急に激しくなる」③大奥から逃亡した娘お秀の住処＝「御家人……山崎傳十郞……**音羽に住んで居ります**」「**音羽なら遠くはないが**」④お秀を送り届ける人物が「お宅は音羽のどのへん」「**妾は雜司ケ谷迄參ります道順**（ゆえ）（中略）お宅迄お送り申しませう」と述べる＝**小石川の江戸川〜音羽〜雑司ヶ谷という現在の音羽・目白・雑司が谷地域の江戸期地名の配置を物語の交通の前提として使う構成**⑤後続場面の「**音羽の屋敷町の宵闇**」＝音羽を（武家）屋敷町とする表記〔いずれも確認・OCR由来〕。なお「音羽屋」の複数箇所は歌舞伎役者の屋号言及で河川・地名とは無関係＝誤検出として除外〔確認・陰性〕。
