# [BOOK-091] 伊藤好一『江戸上水道の歴史』（吉川弘文館、1996年・2010年復刊）

- **書誌〔確認: NDL書誌〕**: **伊藤好一（1916-1998）著『江戸上水道の歴史』、吉川弘文館、1996年12月（四六版・208頁）。2010年復刊（ISBN 978-4-642-06367-8）**。NDL書誌ID [R000011013763](https://ndlsearch.ndl.go.jp/books/R100000002-I000011013763)（1996年原刊は [R000002568269](https://ndlsearch.ndl.go.jp/books/R100000002-I000002568269)）〔repo初出〕。
- **位置づけ〔観察〕**: 著者は江戸上水道研究の第一人者で、同じ吉川弘文館から『[江戸の上水道](https://ndlsearch.ndl.go.jp/)』等も出している。NDLサーチの「千川上水」索引語で本書が検索に現れる（レコードの件名・内容に千川上水を含む）ため、**江戸六上水の一つとしての千川上水を扱う基本書**の候補として所在を記録する〔千川上水個別の記述の方向・頁は本文未確認〕。同一著者の論考「青梅街道に於ける農間駄賃稼と宿駅の抗争」（『西郊文化』通号6・pp.30-33）もNDLで確認したが、水路そのものの論考ではないため本レコードには含めない。
- **関連書誌〔確認〕**: 森田貴子による書評（『史学雑誌』106編7号、1997年、p.1373-1374）の存在もNDLで確認〔内容は未取得〕。
