# [BOOK-129] 東京市史稿 橋梁篇第二（1936年）— 江戸川筋の橋・堰・浚渫の18世紀記録

- **書誌〔確認〕**: 東京市役所編纂『**東京市史稿 橋梁篇第二**』（昭和11年・1936年・東京市役所刊。CiNiiの書誌では昭和11〜14年刊の橋梁篇の第2冊）。NDL次世代デジタルライブラリー [book/1915642](https://lab.ndl.go.jp/dl/book/1915642)。江戸〜明治期の橋梁の編年体集成（『享保撰要類集』『柳營日次記』『惇信院殿御實紀』『武江年表』等の一次史料からの抄出）。**OCRの列崩れが全編で激しく、数値・文言の対応は原文照合まで保留。引用はすべて同館OCRテキスト由来。**
- **寛延2年（1749）8月13日洪水の「神田上水掛樋流れ」〔確認・repo初出・要原文照合〕**: 「惇信院殿御實紀 橋梁流失傳フ」の抄出——「寛延二年己巳…八月十三日の曉より北風大嵐となりて、**牛込·小日向出水、下谷淺草邊迄溢き出、高田關口邊家を流し人を溺〔を〕。江戶川通り橋々押流し、小石川通大水、神田上水掛樋流れ**。昌平橋・筋違橋…其外神田川橋も流る」＋「武江年表 寛延二年己巳八月十三日…西風强…別る大雨北風强…小日向·牛込…」〔**神田上水の掛樋（水路橋・樋）が寛延2年8月13日の出水で流失した記録**＝[BOOK-126](BOOK-126.md)（小石川区史）が『江戸洪水記』から抄出した同日の「江戶川橋落る、水高さ床上五尺…柳町水七尺計」と同じ出水の御実紀・武江年表系統の文言。**神田上水の樋管（水道橋系）の流失史の一次文言としてrepo初出**〕。
- **寛延2年の江戸川（神田川）浚49町〔確認・repo初出・OCR列崩れ大〕**: 寛延2年出水後の浚渫の願・達の抄出——「**神田川出水ニ付、江戶川神田川筋土砂押出シ埋いこ付、柳橋入口〓牛込御門下迄三拾四町、舟河原橋〓關口大洗堰迄拾五町、都合四拾九町之場所川浚之儀**」＋「江戶川通**船川原橋**よ（り）を**目白下大洗堰**迄**長サ拾五町程**浚之儀…**水下五尺浚立**」＋「**船河原橋下洗堰**右之分取拂い儀吟味仕候處…**江戶川通目白下大洗堰〓船河原橋迄水盛りこ付、有來候樣**」＋「寛延二巳年十月此度被仰渡い**神田川通浚之儀**…大橋掛名主共に江戶川浚可申付旨被仰渡」＋「新大橋之儀も町橋こ被下置い以後、年數も無之助成〓薄ク御座い間」〔**①寛延2年出水後の江戸川（神田川）の浚渫範囲が柳橋入口→牛込御門下34町＋舟河原橋→関口大洗堰15町＝計49町と数値化される記録、②「船河原橋下洗堰」の取払い吟味、③目白下大洗堰→船河原橋の水盛りの記録、④新大橋の町橋化（橋銭との引換）と浚渫引受の関係＝大洗堰・船河原橋・江戸川の18世紀中葉の維持管理の一次文言群**。いずれもOCR列崩れが激しく文言の行対応は要照合〕。
- **延享4年（1747）水道橋修理の工費明細〔確認・repo初出・要原文照合〕**: 『享保撰要類集』の抄出——「**水道橋修理ス。延享四卯年**（水道橋區・小石川區・市內神田）」＋「水道橋計之仕樣御入用高書拔記之。**水道橋御入用金六拾九兩／渡り拾四間半／御橋幅四間／袖之間七尺八寸／平均板より平高欄〓り取拂、新鋪仕直し、鐵物不足仕足し**」〔**神田上水の水道橋（小石川・神田区境）の延享4年修理の工費69両・長14間半・幅4間・袖7尺8寸の明細＝水道橋の18世紀の構造・規模の数値記録としてrepo初出**（[GOV-167](../gov/GOV-167.md)の水道端・[BOOK-126](BOOK-126.md)の大正期「旧水道鉄管化」に先行する江戸期の水道橋修理記録）。OCR列崩れのため数値の行対応は要照合〕。
- **「神田上水白堀に相懸かりい金剛寺橋」〔確認・repo初出候補・要原文照合〕**: 『享保撰要類集』の抄出——「**金剛寺橋修理ス。延享四卯年**四月廿日…**神田上水白堀こ相懸りい金剛寺橋**右橋破損仕いニ付、修復申付い。四月…白米廿日依之明廿一日より**往來人留**仕い」〔**金剛寺橋（江戸川＝神田川の橋）が「神田上水白堀（素掘り水路）に相懸かる」と表現された享保撰要類集の文言＋延享4年破損・往来制限・修復の記録**。「白堀」の語はOCR崩れの可能性もあり要照合〕。
- **宝暦10年（1760）「音羽町九丁目橋」の修理〔確認・repo初出・要原文照合〕**: 『柳營日次記』の抄出——「**音羽町九町目橋修理アリ。廿三日○寶曆十年十一月**」「音羽町九町目橋（小）石川區…**朽損いこ付**、○寶曆十年十（二）月…**往來人留之旨**…相模守正亮…堀田申渡之」「音羽町九丁目橋**御修覆出來、明後廿五日往來有之旨**…○寶曆十（一）年十一月・十二月」＋宝暦10年ノ橋梁普請のリスト（「六間ニ貳間半○市内…十間二三間音羽町九丁目橋石（小）川區」等、列崩れ）〔**「音羽町九丁目橋」という橋名の宝暦10年（1760）の修理・朽損・往来制限・修覆完了の記録＝18世紀中葉の橋名の一次記録**。[GAZ-030](../gazetteers/GAZ-030.md)（江戸名勝志）が掃部橋について「音羽町九丁目上水に懸る説は誤也」と記す文脈で、**「音羽町九丁目橋」という別橋名の実在の可能性を示す記録**。ただしこの橋が千川上水樋管上の橋か江戸川の橋か（掃部橋の異名か）はこの文言からは特定できず、断定しない〕。
- **天明6年（1786）洪水の水道橋被害〔確認・要原文照合〕**: 「…目白不動之山崩落…水戸御屋敷…門破、龍慶橋筋…辻番所三ケ所崩流ル。**小石川御茶水川水增、水道橋水道掛…破レ**、昌平橋・筋違橋…其外神田川橋も流る」〔天明6年7月出水（[BOOK-126](BOOK-126.md)の『江戸洪水記』抄出の「柳町床上二尺三寸餘上る」と同出水）の水道橋周辺の被害記録。OCR崩れが激しく文言の対応は要照合〕。
- **位置づけ〔観察〕**: ①江戸川（神田川）・大洗堰・船河原橋・水道橋・金剛寺橋の18世紀（寛保〜天明）の修理・水害・浚渫の一次文言の集成で、[BOOK-126](BOOK-126.md)（小石川区史・変災章）の水害年表の橋梁篇側の補完。②「神田上水掛樋流れ」（寛延2年）・「水道橋修理69兩・長14間半・幅4間」（延享4年）＝神田上水の樋管・水道橋の18世紀の実態記録としてrepo初出。③寛延2年浚49町（柳橋→牛込御門下・舟河原橋→大洗堰）＝江戸川（神田川）の18世紀の川浚体制の数値記録。④宝暦10年「音羽町九丁目橋」＝掃部橋位置論（GAZ-030）に関連する橋名の実在記録。
