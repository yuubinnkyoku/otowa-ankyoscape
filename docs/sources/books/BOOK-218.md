- **千川上水の市中経路と廃止〔文言候補〕**: 「**千川上水は巣鴨込千駄木根津本郷湯嶋外神田下谷浅草蔵前まて掛りしか 中陣(?)水不足に而市中の分を廃す**」＝**千川上水は巣鴨→駒込→千駄木→根津→本郷→湯島→外神田→下谷→浅草蔵前まで掛っており、水不足のため市中の分を廃した**。〔**市中経路の町名連鎖の明治期回想記録。既知の給水範囲（巣鴨→神田・下谷・浅草方面）と整合し、「浅草蔵前」までの下流端の表現は浅草御殿・蔵前系への給水（1225116東京近郊史蹟案内の記述系）と親和的。判読「中陣」の原字は要照合**〕。
