# [BOOK-168] 東京市史稿 変災編第4（覇都時代ノ火災編）— 関口水車・水道町・江戸川堀端の火災記録群

- **書誌〔確認・刊年未確認〕**: 東京市役所編纂『**東京市史稿 変災編第4**』（**覇都時代ノ火災編**。NDL次世代デジタルライブラリー [book/1915668](https://lab.ndl.go.jp/dl/book/1915668)。刊年未確認〔変災編第3（1916）と第5（1917）の間の刊行候補・要書誌照合〕）。江戸期の火災の一次史料（享保撰要類集・月堂見聞集等）を編年集成。**OCR崩れが激しく文言は要原文照合**。本ファイルでは水系関連（水車・堀端・水道町の町名リスト）の文言に絞って採録。
- **安永5年（1776）12月25日除夜の出火＝「關口水道町水車」の存在記録〔文言候補・repo初出候補・要原文照合〕**: 「**關口水道町水車之三四軒東隣より出火、此所餘ほど燒失…牛込中里町へ飛火**」〔**①関口水道町に「水車」があって、その三四軒東隣から出火したという1776年の記録＝関口水車の江戸期の存在を示す独立の文字史料**（[BOOK-139](BOOK-139.md)の1912年地籍図「關口水車西隣地」〔関口町104番地〜関口水道町39番地間〕と対になる裏付け。水車の位置の東西対応は原照合まで保留）、②牛込中里町への飛火〕。
- **正徳3年（1713）12月21日夜の出火＝水道町・音羽町側の火災と隆慶橋東堀端までの延焼〔文言候補・repo初出候補〕**: 「**水道町〓出火**」＋「**改代町〓出火、小日向牛天神下百間長屋際、隆慶橋之東堀端まで燒る。又曰、此出火、音羽町八丁目火元の由**」＋月堂見聞集経由「**護國寺音羽町九丁目より出火にて、幅一町程、長さ水戶殿百間長屋まで十町餘燒**」〔**①「水道町」を火元候補とする出火記録、②延焼端が隆慶橋の東堀端（＝江戸川の堀端）であった文言、③音羽町八丁目／九丁目火元説の対記録**＝江戸川上流側（水道町〜音羽町）の市街火災の延焼が江戸川堀で止まった（または堀端まで達した）ことの記録。repoで正徳3年の水道町出火は未登録（初出候補）〕。
- **享保2年（1717）正月23日牛込赤城下大火の水道町一帯の延焼明細〔文言候補〕**: 「**改代町·水道町·音羽九丁目〓目白臺に燒行**」＋「**關口水道町。新町兩側。音羽町六丁目ぎり…大泉寺…久世大和守下屋敷半分…大名五十八軒・御旗本三百七十五軒**」〔**関口水道町・新町・音羽町六丁目までの延焼と焼失対象（大名58軒・御旗本375軒）の集計**＝江戸川上流側の市街の18世紀初頭の延焼範囲の datapoint〕。
- **享保16年（1731）4月15日目白臺夏目五郞屋敷出火の関口・目白下側の大火〔文言候補〕**: 「**江戶關口秋元但馬守殿御下屋敷向之方より出火。夫より目白臺·宗泉寺…蓮華寺…關口町家不殘、目白下新町·松枝町…**」〔**関口の秋元但馬守下屋敷の向かいから出火し、関口町家不残・目白下新町・松枝町まで延焼した記録**＝関口〜目白下（江戸川・神田上水沿いの市街）の火災史の datapoint〕。
- **宝暦13年（1763）2月5日四谷大火の関口新町・音羽町までの延焼〔文言候補〕**: 「**小日向關口新町·目白臺·小日向臺鼠坂上·同所新屋敷·音羽町·靑柳町·大塚臺町迄**」〔四谷大火の延焼記録に小日向関口新町・音羽町が含まれる文言＝関口新町（江戸川・神田上水沿いの町）の被災史の datapoint〕。
- **元文2年（1737）火災後の瓦葺拜借金の対象町＝江戸川上流の「水道町」系6町のリスト〔文言候補〕**: 享保撰要類集経由——「**牛込水道町·同改代町·關口水道町·小日向水道町·東西古川町·松枝町**」〔**元文2年の火災後の瓦葺拝借金（再建融資）の対象町に、江戸川（神田上水）沿いの水道町系6町（牛込水道町・改代町・関口水道町・小日向水道町・東西古川町・松枝町）が列挙される文言**＝「水道町」の町名群と江戸川の水系の対応を示す行政側の町名リスト（瓦葺令の文脈はOCR崩れがあって要照合）〕。
- **陰性記録〔確認〕**: 本書のfulltextで「水窪」0件・「谷端」0件・「弦卷」0件。
