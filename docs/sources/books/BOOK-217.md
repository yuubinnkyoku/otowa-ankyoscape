# [BOOK-217] 東京市史稿 市街篇30 — 千川上水廃止事蹟の本文側初入手

- **書誌〔確認〕**: 東京市役所編『東京市史稿 市街篇第三十』（殷昌期・1938・NDL次世代デジタルライブラリー [book/3450817](https://lab.ndl.go.jp/dl/book/3450817)）。**引用文言はすべてOCR由来で要原文照合**。目次によれば市街篇30は幕末維新期の市街史稿で、**「千川上水廢止」の独立立項**（天明六丙午年閏十月廿二日）と「屋鋪相對替」（織田信節・三雲定察・佐藤豊昌・玉田盛章ほか）を含む。
- **千川上水廃止事蹟の本文〔文言候補・本登録の核心〕**: 「**天明六午年閏十月廿二日壬戌 千川上水ヲ廢ス 上水篇ニ記ス…天明撰要集 天明六年閏十月廿二日書上寫ニ 千川上水請負人 神田相生町喜兵衞地借長十郎 同所（平）永町家持長右衞門 佐久間町貳丁目喜兵衞店幸右衞門 同所三町目勘左衞門店吉兵衞 武州多摩郡小川村名主孫次郎申上ゆ 昨廿二(廿一?)日信濃守殿良旺(?)…私共被召出 千川上水之儀 御差止こ相成ゆ段 被仰渡い**」＝**①天明6閏10月22日の千川上水廃止（「千川上水ヲ廢ス」）の事蹟立項、②請負人（神田相生町喜兵衞地借長十郎・平永町家持長右衞門・佐久間町の幸右衞門・吉兵衞・武州多摩郡小川村名主孫次郎）が閏10月21日/22日に召し出され、御差止の段を仰渡された天明撰要集所収の書上写**。〔**東京都公文書館公開の『東京市史稿 上水篇第1』目次（千川上水廃止・1786-11-22・上水1-598・天明撰要集・文政町方書上＝README既出）の該当章の本文側を、市街篇30の同主題の集成で初めて直接確認したもの**。差止の公示日の日付が同一（閏10月22日）で一致**〕。
- **屋鋪渡預繪圖證文の筋違橋御門外明地の引渡文言〔文言候補・repo初出の帯有日文言〕**: 「**筋違橋御門外明地 筋違橋御門外明地東西南三方士手際九尺通商床地所 井井戶壹ケ所 水番屋共 千川上水請負人引受場こい處 今度千川上水御差止ニ相成い間 右助成地井井戶水番屋共 御普請奉行方に御引渡被成 右御繪圖之通 相違無御座請取申い 爲後日仍如件 天明六丙午年閏十月廿七日 御普請方改役 御普請方改役 村田新次郎印 倉加(?)澤源郞殿 加藤勘助殿 承テ取**」＝**①筋違橋御門外明地の三方商床地所（土手際9尺通）・井戸1ヶ所・水番屋の千川上水請負人引受場が、②千川上水御差止に伴い閏10月27日（差止公示の5日後）御普請奉行方へ御引渡しされた、③御普請方改役 村田新次郎・倉沢源郎（OCR候補）・加藤勘助の受取りによる屋鋪渡預繪圖證文**。〔**筋違橋御門外の請負人助成地（商床・井戸・水番屋＝[GOV-215](../gov/GOV-215.md)・[GOV-109](../gov/GOV-109.md)系の安永撰要類集・天明撰要類集の助成地文言群）の返納が差止から5日後の閏10月27日だったことを示す日付つき一次文言（要照合）**〕。
- **文政町方書上（府内備考）系の引用の集成確認〔文言候補〕**: 「**一、千川上水 右ハ安永九子年十月廿七日牧野大隅守様御番所御懸まて 上水掛渡之儀被仰付い義そ…天明七未年四月十三日御差止こ相なりゆ旨 被仰渡い由まて 其節取潰し埋立申い 但、元祿之度 千川上水御掛渡之義 相止不申ゆ（府内備考 淺草天王町略）**」＋浅草田原町3人（忠兵衞・嘉右衞門店孫兵衞・三郎兵衞店幸左衞門）の明和6年2月の願出→安永8亥年11月28日の巣鴨庚申塚〜駒込方面の御見分→樋掛渡→天明2寅年8月中〓水錢小間ニ付貳拾八文宛差出・牧野大隅守様御番所に上納→天明6午年5月半減→9月出浅→埋立仰付（＝「尤千川上水と相唱い義、相分兼申い」で終わる書上文言）＝**GAZ-041〜045・GOV-224・GOV-215・BOOK-217保田新田系「武藏野原保田新田と申所水元」の各既知文言の市街篇側集成**。〔**個々の文言はrepo既出だが、東京市史稿が廃止事蹟に「元祿之度…相止不申」の書上の一文と、保田新田水元・28文・半減・埋立の系列を同一の事蹟の枠で統合している確認**〕。
- **本郷・浅草の書上引用の確認〔文言候補・限界値〕**: 目次頁付近の引用列に本郷の「**元祿之度ニ相懸リ候処相潰レ**」・浅草旅籠町の井戸天明7/4/12差留文言が見えるが、ここは目次側であって本文引用の文字が崩壊している。本郷・浅草側の各文言の対校は写本側（GAZ-113・GAZ-082）を主とし本登録は所在記録に留める。

## 制限・未解決
