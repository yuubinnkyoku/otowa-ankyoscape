# [BOOK-177] 南梁遺稿（1911）— 明治13年8月の千川水道再興の年代記〔repo初出・第139回〕

- **書誌〔確認〕**: 『南梁遺稿』（明治44年＝1911刊。遺稿集で年代記〔明治期の記事の編年〕を含む）。NDL次世代デジタルライブラリー [book/2560486](https://lab.ndl.go.jp/dl/book/2560486) のOCR全文を確認。**引用文言はOCR由来で要原文照合**（著者の南梁の比定は本書の書誌確認待ちとする）。
- **年代記の千川水道再興の文言〔確認・repo初出の独立裏付け〕**: 年代記の明治13年の条に「**十三年八月千川水道を用興す 九月麻布水道を開鑿す**」＝**①明治13年（1880）8月に千川水道を再興（「用興」は「再興」のOCR誤候補・原字照合待ち）、②同年9月に麻布水道を開鑿**という記事＝**千川水道の再興（明治13年8月）を、区史・沿革説（[GOV-172](../gov/GOV-172.md)の「明治十三年八月岩崎彌太郞等の請を許し」・[BOOK-173](BOOK-173.md)系・[GOV-329](../gov/GOV-329.md)の「再興ハ明治十三年八月」）とは独立の資料種（遺稿の年代記）で裏付ける** datapoint＝**明治13年8月起業の月レベルの一致の更なる強化**。麻布水道の開鑿（同年9月）との並記も、明治13年の水道再編期（千川・麻布の連続着工）の全体像の手がかり（麻布水道の比定・実態は本書では追えない）。
- **観察〔観察〕**: 年代記という形式が「事件を年月で記録する」体のため、**「八月」という月の情報が沿革説（起業・再興の総説）より具体的**で、[BOOK-171](BOOK-171.md)（明治13年8月開業）・[BOOK-172](BOOK-172.md)（明治13年8月創立）と月の一致が揃う。
