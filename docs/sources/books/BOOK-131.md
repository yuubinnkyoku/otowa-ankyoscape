# [BOOK-131] 東京市史稿 橋梁篇第一（1936）— 掃部橋・四郎橋（江戸川橋）・麁朶橋の由緒と享保13年洪水の橋被害

- **書誌〔確認〕**: 東京市役所編纂『**東京市史稿 橋梁篇第一**』（昭和11年・1936年・江戸府誌社刊〔要照合〕）。東京市史稿の橋梁史第一巻（入國以前〜享保年頃までの橋梁の事蹟集成）。NDL次世代デジタルライブラリー [book/1915626](https://lab.ndl.go.jp/dl/book/1915626)。**すべての引用は同館OCRテキスト由来で、列崩れ・誤認識が多く文言は原文画像との照合を要する。**〔[BOOK-129](BOOK-129.md)（橋梁篇第二・寛延〜宝暦期）の前巻に当たる〕
- **掃部橋の由緒と規模〔確認・[GAZ-030](../gazetteers/GAZ-030.md)（江戸名勝志）の掃部橋条の内容を橋梁篇側でも確認〕**: ①新編江戸志の引用——「**掃部橋、古川町より水道町へ渡す橋（OCR崩れ）…吉岡掃部と云紺屋ありし故に名付け（OCR崩れ）**」＝**掃部橋の名は「吉岡掃部」という紺屋（染物屋）がこの所に住んでいたことに由来**する旨の新編江戸志文言。②府内備考の引用——「**小日向水道町より小日向西古川町に渡る橋有之。里俗掃部橋と唱申候。昔此所に掃部と申紺屋住居致しに付き、右様に唱来たる由申伝候。右も両町にて補理申候（OCR崩れ）橋普請之節は御番所に御願申上候**」＝**小日向水道町〜西古川町間・里俗掃部橋・両町で補理・橋普請の節は御番所へ御願**という管理体制つきの記録。③「**一、橋長凡七間程、幅凡壱間壱尺程**」＝**掃部橋の橋長7間・幅1間1尺**〔[BOOK-129](BOOK-129.md)の水道橋（延享4年修理・長14間半・幅4間）と対比できる江戸川下流域の橋の数値。流失記録（享保13年・天明6年・文政12年〔[BOOK-130](BOOK-130.md)〕）を持つ橋の規模のデータポイント〕。④「**位置ハ後ノ掃部橋ノ稍上流ニ当ル**」と preceded する文言——正保御国図に橋記号（OCRで「永ミ權七クミ」と読める図記・要照合）があって後の掃部橋の稍上流に当たる橋の存在を示す〔正保図（17世紀中葉）の時点でこの位置に橋が図示されていた可能性を示す記述だが、図記の判読は要照合〕。
- **古川橋＝里俗麁朶橋の由来〔確認・[BOOK-130](BOOK-130.md)の麁朶橋／粗朶橋の比定問題への前進〕**: 「**古川橋（市内小石川區）…新編江戸志ニ「古川橋、俗麁朶橋と云…」…府內備考（引用）——「小日向水道町ゟ小日向東古川町へ渡る橋御座候。古川橋相唱申候。又**里俗麁朶橋と相唱申候。往古此所に麁朶（あらた＝柴・薪の類か）を持出し商売致し候由に有之、右之字有之由申傳候**。右之町方懸り定川懸りに有之候。御入用橋に御座候。且御役所向に認むる節は古川橋と認申候**」〔**①「麁朶橋」＝古川橋（小日向水道町〜東古川町間）の里俗名であること、②その名が往古この所で麁朶（柴・薪類）の持ち出し商売をしたことに由来するという伝承文言、③町方懸り・定川懸りで御入用橋、④公用文書では古川橋と認める運用**＝変災編の「掃部橋・麁朶橋流失」（享保13年・天明6年・文政12年〔[BOOK-130](BOOK-130.md)〕）の「麁朶橋」が古川橋の里俗名と特定できる方向の記録。麦香橋系表記説の検討資料。断定は比定の慣行に従い「方向の記録」として記す〕。
- **四郎橋＝後の江戸川橋位置・江戸川橋は俗に名残橋〔確認・repo初出の橋名と異名の系譜〕**: 「**四郎橋 同川筋（江戸川）ニ架ス。後ノ江戸川橋（市内小石川區）ニ位置略当ル。江戸川橋俗ニ名残橋と云。昔一休名残蕎麦といふありし故は、俗に名付。新町より音羽町へ渡す橋（新編江戸志）。橋長凡拾壱間程、幅凡三間程**」＋「**関口水道町に相渡る橋…江戸川橋と相唱申候。町内懸り定川懸りに有之候。御入用橋に御座候（府内備考）以上五橋共正保圖ニ見エザリシモノナリ**」〔**①「四郎橋」という橋名（repo初出候補）が江戸川筋にあり後の江戸川橋の位置に略当たること、②「江戸川橋」＝俗に「名残橋」で、一休の名残蕎麦に由来する異名（OCR文言の正確な帰属・「一休」の原字形は要照合）、③橋長11間・幅3間、④新町〜音羽町を渡す、⑤正保図に見えない5橋の一つ**＝江戸川橋の位置と異名の系譜（名残橋・四郎橋）の初出記録群〕。
- **享保13年（1728）9月洪水の橋被害（享保撰要類集経由）〔確認・[BOOK-126](BOOK-126.md)・[BOOK-130](BOOK-130.md)の『江戸洪水記』系文言の橋梁篇側からの補完〕**: 「**享保十三年九月三日…覺 江戶川橋（市内小石川區）・小日向水道町ゟ關口水道町へ渡る橋・小日向水道町ゟ同所東古川町へ渡橋・東古川町之橋・小日向松ヶ枝町ノ橋 右之橋流落い旨、右町ゟ訴出申い。此外橋々落い所々も御座い哉未相知レ不申い（享保撰要類集）**」＋「九月五日…（中略）**未刻大風雨…（後略・OCR崩れ）**」〔**享保13年9月の洪水で江戸川橋・水道町〜関口水道町橋・東古川町橋・松ヶ枝町橋等の流失訴出の一次書付（享保撰要類集）を橋梁篇が抄出**＝「関口橋落」（江戸洪水記・[BOOK-130](BOOK-130.md)）に対応する水道町〜関口間の橋群の被害の別史料系。流失橋の町別列挙の対応（關口橋・掃部橋・中ノ橋・隆慶橋・センヂ橋等〔[BOOK-130](BOOK-130.md)〕）は原文照合課題〕。
- **関口水道町・江戸川橋の修覆入札の町触〔確認・repo初出の江戸川橋修理の実務記録〕**: 「**關口水道町 江戶川橋 御修覆入札之儀、先達る相觸い處に、望之者を無之に付、又々相觸い間、望之者は今日ゟ來る廿三日迄之內…仕樣帳寫取、入札相認、同廿六日朝五ツ時…御番所に入札持參い樣、町中不殘可被相觸い（十月五年〔＝OCRの年次表記・宝暦5年か・要照合〕）**」＋「江戶川橋 御修覆入札高直に付…（十一月五年）」＋「享保十二年二月廿三日ゟ御取掛り、江戶川橋修理アリ」〔**江戸川橋（関口水道町側の橋）の修覆が入札（競争入札）で行われた町触・享保12年修理の記録**＝江戸川橋の修繕が町触・仕様帳・入札のプロセスで運営されたことの初出記録〕。
- **元禄12年（1699）龜島川入堀の半埋立でできた「千川屋敷」（八丁堀側）〔確認・repo初出・第108回の最重要の新事実の一つ〕**: 「**橋名（欠落か） 龜島川ヨリ西ニ茅場町ノ方ニ入レル入堀ニ架ス。府内往還其外沿革圖書ニヨレバ、元祿十二年コノ堀幅半埋メラレテ千川屋敷トナリ、從ツテ橋長短クナレリ**」〔**①龜島川から西へ茅場町の方へ入る入堀に架かる橋の記録、②元禄12年にこの堀の幅が半分埋め立てられて「千川屋敷」となり、橋長が短くなったという沿革（出典＝『府内往還其外沿革圖書』）**＝**「千川屋敷」という地名・屋敷名が小石川白山前町（千川上水請負人の拝領屋敷〔[GOV-208](../gov/GOV-208.md)・[GOV-210](../gov/GOV-210.md)〕）とは別に八丁堀・茅場町側（龜島川入堀跡）にも存在したことを示す橋梁篇の記録（repo初出）**。**両千川屋敷の関係（同一の千川家か別家か）はこの史料からは確定できない**——小網町1丁目家主の千川家（宇兵衛）の屋敷という地域的近接性から同一家の可能性は棄てられないが、[GOV-208](../gov/GOV-208.md)の「仙川村の民太兵衞・徳兵衞」2名の拝領文言や『類集撰要』の「茅場町千川屋敷地主」「千川屋敷藤兵衛」の表記との対応は今後の照合課題とする（断定しない）。[BOOK-133](BOOK-133.md)（変災編第5）の万延元年2月4日「八丁堀千川屋敷より出火」と対になる屋敷起原の記録〕。
- **駒留橋・駒塚橋（神田上水系の橋の伝承集成）〔確認・音羽の駒止橋（[GAZ-013](../gazetteers/GAZ-013.md)・[GAZ-035](../gazetteers/GAZ-035.md)）とは別橋の記録〕**: ①「**駒留橋○（新編江戸志の引用）神田上水に懸かる橋…古來丸木橋にて渡ししに、後御成の御道となりしより板橋（丸太橋）と成る。丸太橋の頃、此上四ツ屋の南土手下に馬多く宿し、駒込の馬市より出しける。白き馬多く出でし由、目白は馬白のよし…（中略）自然と止るゆえ、その名なりとも（OCR崩れ）**」〔**神田上水に架かる「駒留橋」の名の由来（駒込の馬市の馬がここで留まった）の伝承**＝音羽町9丁目〜桜木町間の「駒止橋」（往古鼠ケ谷橋・[GAZ-035](../gazetteers/GAZ-035.md)）とは**別の橋の伝承**として記録（両者の混同に注意）〕。②「**神田上水堀ニ架セリ、長九間 駒塚橋ト號ス。相傳フ、古へ橋北ニ老松一株アリ。行客常ニ駒ヲ繋シユヘ駒繫橋ト稱セシカ、後松モ枯シユリ駒塚橋ト呼誤レリト云。又駒塚ノ名義ニ付テ異說アレト、虛誕ノ傳ニシテ取カタシ（新編武藏風土記稿）**」＋風土記稿の古詠「駒とめて猶水かがむ山吹の花の露そふ井出の玉川」〔**神田上水堀に架かる長さ9間の「駒塚橋」（駒繫橋の誤伝説・山吹の里の古詠）**＝神田上水沿いの橋名の伝承集成。「龍隱庵の前、上水の流れに架かる」（風土記稿）〕〔OCR崩れ著しく文言は要照合〕。
- **「仙臺橋」（水戸邸前・小石川の流れ）の文言〔確認・要照合〕**: 「**小石川『水戶宰相殿』邸前 小石川ノ流ニ架ス。所謂仙臺橋（OCR崩れ）**」＋「**關口ヨリ水戶邸ニ至ル間ノ上水道ニ架ス（橋）…とんどむし（＝どんど橋か）江戶川ニ架ス。船河原橋…正保ノ圖ニ橋名ナカリシモノナリ**」〔**仙臺橋を「水戸宰相殿邸前・小石川の流れに架かる橋」として記す文言が橋梁篇第一にある（OCR崩れが激しく、仙臺橋の位置記述（水戸邸前）と従来の指ヶ谷側の比定〔[BLOG-133](../blogs/BLOG-133.md)・[GOV-208](../gov/GOV-208.md)〕との関係は原文照合まで保留）**。関口〜水戸邸間の上水道（神田上水〜小石川流路の関係）の架橋群（どんど橋・転軫橋か・船河原橋）の列挙もある〕。
