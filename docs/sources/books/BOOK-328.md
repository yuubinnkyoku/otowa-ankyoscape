- **①六派上水の列挙と千川上水の由来条〔確認・repo文言変種を含む〕**: 「江戶市中には所謂六派の上水があつた。卽ち神田上水、玉川上水、靑山上水、龜有上水、三田上水、**千川上水**これである」＝**千川上水を六派の一つに数える1935年時点の区史記述**。「**千川上水は元祿九年小石川御殿、湯島聖堂、東叡山、淺草寺の御成御殿上水用として開通したもの**」＝給水先4施設の列挙（**「淺草寺の御成御殿」という給水先表記の変種**〔[GAZ-049]⑫「淺草御殿」等との対校・OCR要照合〕）。流路記述「**新座郡上保谷新田より玉川上水を分派し、東流して豐島郡石神井、多摩郡上鷺宮、豐島郡中新井を經、下練馬村より南折し、上板橋村の南部を過ぎ、長崎村に至り東北に流れ、下板橋宿金井窪を經、巢鴨村より本〓（本郷）、湯島、淺草へかゝつた**」＝**「上保谷新田」表記の追加**（保谷村〔GAZ-049〕・保田新田〔GOV-224/225〕・上保谷新田〔本条〕の第3表記・OCRゆえ要照合）。「仙川村の太兵衞、德兵衞に、仙の字を改めて千とし、千川の姓を與へて水元を命じ、白山前町に屋敷を給した」＝姓授与・白山前町屋敷の通説記述（[GAZ-049]⑫・[GOV-212]と整合）。**「然し享保七年十月、この上水も廢止となり、たゞ田地灌漑用として野方用水のみを存した」＝「野方用水」という存続用水名の文言候補（repo grep新出）**〔享保7年廃止後に千川筋が灌漑用水として残った際の呼称「野方用水」（野方方面への通水に由来する呼称候補・[BOOK-112]水利章の「千川用水」との関係は原画像照合後に判断・断定しない）〕。

- **②明和6年願人の離反と千川善藏・阿部川町三郎兵衞の加入〔確認・repo初出・本掃引の最重要文言の一つ〕**: 「**然るに明和六年二月、淺草田原町の忠兵衞、孫兵衞、高砂町の幸左衞門の三人が町奉行所に出願し、（後、願人孫兵衞、幸左衞門は離反し、千川善藏と淺草阿部川町の三郎兵衞が加はり）しくい調査の結果、安永八年十一月許可せられ、再興するに至つた**」＝**①明和6年2月出願の願人3人（忠兵衞・孫兵衞・幸左衞門＝[GAZ-049]①・[GOV-215]-[GOV-218]の町方書上群の3人と対応）のうち**後、孫兵衞・幸左衞門が離反し、千川善藏と浅草阿部川町三郎兵衞が加入した**という願人交代の過程の区史レベル記録**、②**千川善藏が明和6年（1783～）の再興願の段階で願人側に加わっていた可能性を示す文言**（[GAZ-049]⑫千川金七由緒書の千川家系譜〔太兵衞→善蔵→金七〕と、[GOV-210]〔嘉永3〕の元祖太兵衞由緒申告との中間の空白期〔明和~天明〕を埋める候補）、③**「淺草阿部川町」の地名帰属の三郎兵衞**＝[GAZ-049]①の「高砂町三郞兵衞店幸左衞門」との関係（店先つき書き分けなら幸左衞門の店元か、別人か）は判別できない。**離反・加入の是非・人物の異同はOCRの丸括弧部分の原画像照合まで断定しないが、**願人名簿問題（[GAZ-049]制限③の幸左衞門／幸右衞門／幸兵衞門／幸島4変種）に「離反」という変動要因の説明候補を追加する**。
