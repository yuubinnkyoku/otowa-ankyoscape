## 意義〔観察〕

- **元禄5年（1692）〜明治14年（1881）の下田家の土地・質地（担保土地）経営の証文群の抄録**＝田無用水の元禄年間引受（ORG-038: 元禄年間（1688〜1704）=元禄9年1696嘆願書〔BLOG-284〕）**と同時代から始まる下田家の土地集積の実態**が文書レベルで追える目録。田無村の土地利用・灌漑地の所有構造（[BOOK-275](BOOK-275.md)『田畑其他取調野帳』研究）の前史にあたる。
