- **書誌〔確認〕**: 東京興信所『**銀行会社要録**』の版次横断調査。NDL次世代デジタルライブラリーで**第2版**（[book/803639](https://lab.ndl.go.jp/dl/book/803639)・**明治31年5月6日発行**〔奥付・文言候補〕）〜**第12版**（[book/803648](https://lab.ndl.go.jp/dl/book/803648)・明治41年刊）のfulltextを確認（第3版〔[BOOK-165](BOOK-165.md)〕・第4版・第13版〔[BOOK-166](BOOK-166.md)〕は既登録のため再掲省略。**第5版（明治34年4月30日発行候補）はNDLにデジタル化なし**＝陰性記録。第6版〔[book/803642](https://lab.ndl.go.jp/dl/book/803642)〕〜第11版〔[book/803647](https://lab.ndl.go.jp/dl/book/803647)〕は第7〜11版に対応）。**引用文言はOCR由来（統計行の割付は列崩れが激しい）で原表照合を要する**。
- **版次発行日の確定〔文言候補・奥付〕**: 第1版明治30.9.24印刷（[BOOK-164](BOOK-164.md)）→**第2版明治31.5.6**→**第3版明治32.5.15**→**第4版明治33.5.11**→第5版明治34.4.30（デジタル化なし・書誌情報のみ）→**第6版明治35.5.8印刷/5.11発行**〔**BOOK-164〜166の間の版次の空白（第137回課題④）の埋め**〕。
- **千川水道株式會社の全版掲載確認と最終掲載版＝第12版〔確認〕**: 第2版から第12版までの**全ての版の統計行に千川水道株式會社の記載をgrep確認**＝**千川水道の最終掲載版は第12版（明治41年刊。統計基準「明治四十一年三月調」が6回出現〔grep確認〕）で、第13版（明治42年）で消滅**〔[BOOK-166](BOOK-166.md)の第13版欠載と接続する版次系列の完成。**上水廃止（明治40年6月）の翌年の版まで掲載が続いた**ことになる〕。
- **第12版の統計行＝上水廃止後も決算継続の観察〔文言候補・割付要照合〕**: 「**役員並社員氏名及出資額 麹町區八重洲町一ノ一三菱會社内…設立明治十三年八月…總株數400…决算期六月十二月…決算（日）明治四十年十二月三十一日…（資本金）40,000**」〔**①事務所が引き続き麹町区八重洲町一ノ一（三菱會社内）、②決算期6月・12月、③決算日が明治40年12月31日＝上水廃止（明治40年6月）の後の決算期（12月）を迎えても会社として決算を継続した観察、④総株数400・資本金40,000は第1版（[BOOK-164](BOOK-164.md)）から不変**。上水廃止と会社の解散の時間差（少なくとも半年以上）を示す datapoint（解散・清算の実態は登記等の一次資料での確認課題）〕。
