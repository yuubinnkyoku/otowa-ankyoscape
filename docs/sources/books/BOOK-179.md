# [BOOK-179] 撮影探勝武蔵野めぐり（横山信・1922）— 大正末期の千川用水開渠現況の観察記録〔第144回〕

- **書誌〔確認〕**: 横山信著『撮影探勝武蔵野めぐり』（合資会社アルス・大正11年〔1922〕6月発行・奥付より。自序は大正11年5月渋谷）。趣味の写真家向けの武蔵野散策案内記（挿入写真は著者自撮影と自記）。NDL次世代デジタルライブラリー [book/965105](https://lab.ndl.go.jp/dl/book/965105) のOCR全文を確認。**引用文言はOCR由来で要原文照合**。
- **千川用水の1922年現況観察〔確認・文言候補〕**: ①「**上石神井字出店といふ所は、小金井の境橋から玉川上水を分流して來た彼の千川用水が、丁度靑梅街道をクロツスする位置にあるので、ゴー〓〓と音を立てゝ流れる野水の上に、楢や櫟の林が蔽ひかゝつてゐて、風情に富んだ所である**」＝**1922年時点で千川用水が上石神井字出店付近（青梅街道交差点）で開渠のまま流れ、音を立てるほどの水量があった**という現地観察。②「**中央線境驛から田無町に通ふ街道が此の用水路を越える所に柳橋といふ小橋がかゝつてゐる。橋畔には水車があつたり、大きな樫の木の森があつたりして、一種の趣が…**」＝**境駅〜田無街道と千川用水の交差部の「柳橋」と、その橋畔の水車の1922年の観察**。〔**大正末期の千川用水の通水実態・水量・水車を、散策者の目で記した観察記録**＝[GOV-290](../gov/GOV-290.md)（1905年・千川上水残存給水観察）より後の時点の現況datapointで、**千川用水の消滅前の実態を位置（出店・青梅街道交差点・柳橋）付きで具体化する**。「柳橋」の橋名（千川用水の他の柳橋記録との異同）・出店の比定は地図照合待ち〕
- **千川用水の流路記述〔確認・文言候補〕**: 「**次に千川上水は北多摩郡武藏野村の境橋附近で玉川上水を分流し、石神井村、練馬村中新井村、長崎村などといふ武藏野の面影の多く殘つた村々を通つて、板橋町に出で、巣鴨から瀧野川の方へと流れ、飛鳥山の西で石神井川に合流してゐる**」＋「**境橋から板橋ま(で)ざつと五六里もあらうか**」＝**1922年時点の千川用水の通流路（境橋→石神井村→練馬村→中新井村→長崎村→板橋町→巣鴨→滝野川→飛鳥山西で石神井川に合流）の観察ベースの記述**＝既存の流路復元（地図・統計書系）に対し、散策記レベルでの1922年の現況確認を与える。
- **千川上水沿革の再述〔文言候補〕**: 「**常憲公の時代に出來たもので、享保七年に一度中止し安永九年に再起したが水掛りがよくないため天明六年にまた中止した。その頃は駒込、本〓、湯島に至り、上野谷中、下谷邊、柳原、淺草邊まで給水してゐたといふことである。しかしそれが上水廢止とともに田畑の灌漑用水として殘つたのである**」＝**①開設を常憲公（綱吉）の代とする、②享保7年中止・安永9年再起・天明6年再中止の沿革、③かつての給水範囲（駒込・本郷・湯島→上野谷中・下谷・柳原・浅草辺）、④上水廃止後は田畑の灌漑用水として残った、という1922年時点の沿革再述**。〔②③は既知の沿革（[BOOK-094](BOOK-094.md)系・[GAZ-024](../gazetteers/GAZ-024.md)）の散策記での再述＝**通説が大正末期の一般書で定着していたことの傍証**。④の「灌漑用水として残った」観察は現況（前条の開渠・水流）と一体の記述〕
- **神田上水の流路と1922年観察〔文言候補〕**: 「**神田上水は井の頭池の水を引き、彼の善福寺川の流れと妙正寺川との二水をも併せ堀之内、柏木、落合、高田を過ぎ、小石川關口を經て、江戶城內へ來て御茶の水となつた。それは丁度寛永六年將軍家綱の時分に工事を竣へたもので**」＋「**今では無論上水の實はなく、附近の田圃の灌漑に使はれてゐるのであるが、それでも水は美しく澄んで流れてゐる**」＝**①神田上水の流路（井の頭池＋善福寺川・妙正寺川の三水→堀之内→柏木→落合→高田→関口→江戸城内→御茶の水）、②「寛永6年工事」の年代記述**（「將軍家綱の時分」との併記は著者側の年代混同候補。寛永6年〔1629〕は家光期で、[GAZ-065](../gazetteers/GAZ-065.md)引江戸砂子・府内備考系の寛永6年疏通説と同じ年代を取る）、**③1922年時点で上水としての実はなく田圃の灌漑に使われているが澄んで流れているという観察**。〔**神田上水廃止（明治33/34年説対立の既存整理を参照）後の大正末期の水路の現況観察**として、神田上水跡の灌漑転用の実態を記す。芭蕉が普請奉行を務めたという伝承の言及もある（典拠は本書では示されない）〕
- **意義〔観察〕**: 本書は**千川用水・神田上水が「通水する開渠」として観察できる最終期に近い時点（1922）の散策記**で、①出店の青梅街道交差点・柳橋の水車という位置・施設の具体化、②「ゴー〓〓と音を立てゝ流れる」という水量の観察、③沿革通説の大正期一般書への定着、の3点が新しい。

## 制限・未解決

- ①文言はOCR由来で要原文照合（「ゴー〓〓」等の擬音・「本〓」の欠字＝本郷か）。②「柳橋」「出店」の比定（地図・地籍との照合）は未実施。千川用水の水車（橋畔）が営業中の物置・精米水車かは本書からは不明。③「常憲公の時代」は年代を記さず、開設年（元禄9年/11年等の通説）との直接の対応は本書から確定しない。④神田上水の「寛永6年＋家綱」の記述の混同は著者の誤り候補として本文のみ記録し、神田上水起源論の資料としては寛永6年説の側の系統とだけ位置づける。⑤水窪川・弦巻川・谷端川の直接の記述は2026-11-17の全文検索では確認できていない（陰性。渋谷川・神田川合流部周辺の言及はあるが流路史料としては未精査）。
