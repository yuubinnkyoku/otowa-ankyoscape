# [ORG-043] 「としまの記憶」動画アーカイブの谷端川・橋の記憶口述証言群

- **プラットホーム〔確認〕**：[ORG-042](ORG-042.md)と同じNPO法人「としまの記憶」をつなぐ会の口述歴史動画アーカイブのうち**谷端川・橋を主題とする証言5本**をまとめて資料化（ページ文言の直接確認。**動画本体はすべて未判読**。撮影・編集は大正大学放送・映像表現コース）。
- **川のない霜田橋〔確認：公開ページ文言／動画未判読〕**：[「川のない霜田橋」](https://movie.toshima-kioku.jp/archives/2012077/)（語り手=岩崎康弘・77歳・西池袋・時代=昭和20年〔戦後混乱期〕・**2012年撮影**）。説明文言＝「**現在は暗渠となっているが、椎名町には谷端川が流れ、それに架かる霜田橋があった**」＝**椎名町の谷端川・霜田橋の実在の口述witness**。霜田橋の位置（西池袋4-18と4-19の間・立教通り交差）と「霜田＝下田（検地用語）由来」文言は[BLOG-153](../blogs/BLOG-153.md)既収録で、本証言はその**住民記憶側の独立witness**（橋の記憶の時代=昭和20年）。
- **谷端川の水の流れ〔確認：公開ページ文言／動画未判読〕**：[「谷端川の水の流れ」](https://movie.toshima-kioku.jp/archives/2017024/)（語り手=中村勝則・70歳・**北池袋**・時代=**昭和30〜35年〔戦後復興期〕**・**2017年撮影**）。説明文言＝「今は暗渠となった谷端川。**その昔の水の流れを滔々と語る**」＝北池袋区間で**昭和30〜35年頃に谷端川に水が流れていた記憶の口述**（谷端川全体の暗渠化1964年説〔[BOOK-001](../books/BOOK-001.md)〕と矛盾しない水流記憶の下限定点。同時期の都下水道への切替・覆蓋着工の実感の有無は動画判読待ち）。
- **北池袋の北映座からどんどん橋を渡った〔確認：公開ページ文言／動画未判読〕**：[「北池袋の北映座からどんどん橋を渡った」](https://movie.toshima-kioku.jp/archives/2015028/)（語り手=後藤昭司・66歳・**池袋本町**・時代=昭和30年代〔高度成長期〕・**2015年撮影**）。説明文言＝「**歩くとどんどん鳴る橋（どんどん橋）**についての話と北映座（映画館）についての話」＝**北池袋〜池袋本町界隈の「どんどん橋」の橋名の口述**（[地名・河川名対照表](../../地名・河川名対照表.md)第287回新設行。谷端川（区界沿いの流路）に架かる橋である可能性が高いが、**ページ文言には川名がなく同定は動画判読まで保留**。田無の枝用水の通称「ドンドン川」〔BLOG-284〕とは別系統の語）。
- **池袋にあった成蹊学園＝丸木橋の記憶〔確認：公開ページ文言／動画未判読〕**：[「池袋にあった成蹊学園」](https://movie.toshima-kioku.jp/archives/2012058/)（語り手=長島花樹・97歳・西池袋・時代=**大正12年〜〔大正・戦前〕**・**2012年撮影・立教大学放送研究会**）。説明文言＝「まだ自然いっぱいだった**池袋西口**にあった成蹊小学校。**丸木橋を渡る時に川に落ちた**など数々のエピソード」＝大正期の成蹊小学校（池袋西口）の通学路に**丸木橋を架けた川**があった口述。成蹊学園側でこの川を「**十町川**」と呼んだ記録が[BOOK-029](../books/BOOK-029.md)（『成蹊小学校之一年間』1917・所在のみ）と[MAP-033](../maps/MAP-033.md)（『成蹊学園六十年史』所収図）にあり、**同一の川（谷端川水系）の記憶への接続候補**だが、口述側の川名は動画判読まで特定しない。
- **池袋と粟島神社〔確認：ページ存在のみ／説明文言なし〕**：[「池袋と粟島神社」](https://movie.toshima-kioku.jp/archives/2013058/)（語り手=星川葭夫・68歳・**2013年撮影**）。ページに説明文言がなく、サイト内検索「谷端川」でヒットする（本文外フィールドの可能性）。**粟島神社（谷端川の水源・弁天池）に由来する証言動画の存在のみ記録**（内容は動画判読まで採用しない）。
- **未解決**：①全動画の本体判読（霜田橋の構造・谷端川の水量・どんどん橋の架かる川・成蹊の川の名称発話）＝human視聴待ち。②2013058の「谷端川」検索ヒットの理由（タグ・transcript等の仕組み）。
