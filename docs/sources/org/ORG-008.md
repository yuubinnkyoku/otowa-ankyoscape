# [ORG-008] 千早一丁目の舗石建立塔と谷端川上流の湿地帯

- **資料〔確認〕**：豊島区商店街連合会「[としま名所旧跡と商店街の散歩：千川・要町・高松コース](https://www.toshima-kushoren.gr.jp/course/course09.html)」。ページに刊行・更新年月日の表示は見当たらない（**2026年11月3日閲覧**）。**1801年は本文が伝える石塔の建立年**であり、このウェブ記事の刊行年ではない。
- **地蔵堂と石塔〔確認：団体の公開説明／二次伝承・原碑未判読〕**：**千早1丁目23-3**の「地蔵堂」の説明に、**1714年（正徳4年）の地蔵**と子育て地蔵が祀られ、**道標を兼ねた「舗石建立塔」が谷端川の湿地帯の舗道整備を記念して1801年（寛政13年）に建立された**とある。1924年（大正13年）の馬頭観世音・水洗い観音にも言及する。**1801年の建立・工事の年代は団体の二次説明**であり、碑面銘文・建立願文・工事範囲・旧位置は未確認。
- **史料価値〔推定〕**：現在の**千早1丁目23-3付近**を、近世末期以前の谷端川上流で**湿地と通行路の整備が交差した地点を調べる基準候補**にできる。舗石建立塔が道標を兼ねたとの説明は、旧道の方向・渡河位置を古地図・地籍図・現存石碑で照合する動機になる。ただし、**現所在地が1801年当時の建立地点とは限らず、石塔の説明だけで川筋・橋・湿地の広がり・舗装工区を確定しない**。
- **粟島神社〔確認：団体の表現／未解決〕**：同ページは所在地を**要町2-14-4**とし、弁財池を谷端川のかつての源泉と説明する。「**谷端川の中州（湧水点）**」という表現もあるが、**近世の川が神社敷地を両側から囲んでいたことを実測で立証した記述とは扱わない**。既登録資料の「要町2-41」との食い違いは[GOV-047](../gov/GOV-047.md)とともに住所・地籍で再検証する。

- **独立した公的館報による補強〔確認〕**：豊島区立郷土資料館『かたりべ』43号（**1996年10月20日、印刷p.7**）には石塔の写真・寸法、**1801年2月吉日**とする碑文転記、谷端川湿地の敷石**約100mという伝聞**がある。詳しくは[GOV-049](../gov/GOV-049.md)。**碑の現物を直接再判読したものではなく、約100mは原工事図面による測量値ではない**。
