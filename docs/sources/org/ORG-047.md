# [ORG-047] 齋藤知明レポート（2022-11-01）— 種子地蔵の建立年次と植木鉢文言・第1回縁日

## 要点〔確認: レポート本文〕

- 著者＝大正大学心理社会学部専任講師・齋藤知明。本文「**大学は今年度、観光庁が実施する「地域独自の観光資源を活用した地域の稼げる看板商品の創出事業」に採択され、この通りを「種子屋街道」として打ち出すことにしました**」〔確認: 本文＝[ORG-046](ORG-046.md)の観光庁実証事業名とは事業名が異なる。**両事業の採択年度の対応は本文上では特定できず、そのまま文言として記録**〕。
- **種子地蔵＝大正大学が「今年5月」（記事の2022-11-01から**2022年5月**）に南門に建立**〔確認: 本文「大学は今年5月に「種子地蔵」を建立しました。まさに、仏教系大学独自の取り組みです」〕。**「参拝のしおり」の文言**: 「（種子地蔵が持つ）**植木鉢はこの種子屋通りの歴史を顕彰するとともに、地域の安泰と発展そして豊作を祈願する地蔵尊のお心を表しています。また「種」は一粒まけばその一万倍もの粒となることから、一粒万倍（いちりゅうまんばい）といわれ、新事業に挑むには良い縁があるとされます**」〔確認: 本文引用〕。
- **第1回種子地蔵縁日＝2022年11月4日**（初開催）。内容＝伝統野菜を通した「農と食と歴史」のマーケット「**種子屋街道さんぽ市**」・ワークショップ・キャンパス内農園とさざえ堂のツアー。すがもプロジェクトの学生を中心に地域創生学部・追手門学院大学の学生も参画〔確認: 本文〕。
- **2022年10月22日＝稲荷湯（同年6月に長屋がリノベーションされてカフェ化）でのプレイベント**（バスボムづくりワークショップ・3時間で50人超）〔確認: 本文。稲荷湯＝創業から100年の銭湯としての地域伝統資源の文言〕。背景＝巣鴨は真性寺（江戸六地蔵尊）・高岩寺（とげ抜き地蔵）の「祈り」のまち、という説明。

## リード意義

- **種子地蔵は2022年5月建立の21世紀の新造構築物**であり、種子屋街道再興の事業群（[ORG-046](ORG-046.md)の看板→本件の種子地蔵・縁日→[ORG-048](ORG-048.md)の第2回縁日→[GOV-583](../gov/GOV-583.md)のシンポ3回）の中核的モニュメント。READMEの構築物・石碑群（千川上水分配堰の碑・種苗屋街道の碑等＝[BLOG-313](../blogs/BLOG-313.md)）に**現代の顕彰構築物の系譜を加える**。植木鉢文言は「種子屋通りの歴史を顕彰」を目的文言として公言するもので、[PAP-027](../papers/PAP-027.md)（構築物調査系）との接続候補。
- 「種子屋街道さんぽ市」の名称が第1回縁日のマーケット名として使われている点に注意（[ORG-048](ORG-048.md)では2021年12月のプレイベント名として出る。**同一名称の再利用であり、さんぽ市の初回＝2021.12説との混同に注意**）〔観察〕。

## 制限・注意

- **本文に千川上水・谷端川等の水系文言はない**（旧中山道の説明のみ）。種子地蔵の造形（材質・寸法・制作者）は本文にない。
- 縁日の参加者数・看板の現況等は未確認。建立の入仏・開眼供養の有無も本文に記載なし。
