# [ORG-019] 武蔵学園百年史「語り継ごう濯川」

- **書誌〔確認：2026-11-12更新〕**：『武蔵学園百年史』主題編「創立50周年・60周年のころ」所収「語り継ごう濯川」（阿妻耕次郎）。2026-11-12に百年史公開ページ（[CentennialHistory版](https://100nenshi.musashi.jp/CentennialHistory/Index/94f55392-04f1-4dac-b6d8-68dd848f52eb)）で**本文全文を取得・直接確認**（第21回時点のスニペット確認から格上げ。旧未解決「本文の全取得」を解消）。
- **濯川小史の全文年表〔確認：本文〕**：
  - 1922年4月旧制武蔵高等学校創立。校地中央部を千川分水が流れていたが、田川のままの細流であった。
  - 1925年 運動場整備完成に合わせ分水を拡げ「濯川」と命名。1928年 川畔に北極標設置。
  - **1932年 濯川七橋に命名（上流から佐の橋・十年橋・出橋・入橋・一の橋・欅橋・玉の橋）**。1936年 喜寿島・喜寿橋・泉橋〔七橋・二橋の橋名は第21回スニペットと同一〕。
  - **1941年 民族文化部門（文化学部）編「千川上水」刊行**〔[BLOG-113](../blogs/BLOG-113.md)・[GOV-076](../gov/GOV-076.md)の武蔵学園記念室資料（昭和16年刊）と刊年一致の裏付け〕。
  - **1959〜60年 学校付近の千川上水が暗渠となる。濯川への分水は、千川の増水時のみに限られるようになった**〔①濯川周辺の千川暗渠化の年次が1959-60年と具体化。②[BLOG-113](../blogs/BLOG-113.md)（武蔵学園記念室1996年写真展略年表）の「昭和28年（1953）武蔵学園前暗渠」とは**年次が食い違う**（1953 vs 1959-60）。両資料とも学園由来だが、どの区間を指すか（学園前の道路部か学園付近一帯か）で差がある可能性があり、**断定せず並記**。③趣意書（1983）は「昭和30年代に千川上水は暗渠となり」と概括〕。
  - **1969年 大学体育館・高校中学校舎の建設に伴い「佐の橋」より上流部、「玉の橋」より下流部が暗渠となる**〔学園内濯川の暗渠区間の具体化＝repo初出〕。
  - 1979年「欅橋」架け替え。**1980年「一の橋」「欅橋」の間で川底からの汚水が甚だしく、川は涸堀となる**。
  - **1981年7月22日 観測史上最大の集中豪雨で濯川氾濫、下流近隣も冠水。10月22日 台風24号の豪雨により同様の氾濫・冠水**〔濯川（千川分水系）の昭和56年の2度の氾濫記録＝repo初出〕。
  - 1982年 太田学園長のもと「濯川蘇生構想計画委員会」設置。**1985年4月20日 第1期工事完了・通水式、1986年4月26日 第2期工事完了・竣工式**〔[ORG-018](ORG-018.md)「1983年ポンプ式蘇生事業」より詳細な年次に更新。趣意書は1983年4月〕。
- **命名の経緯〔確認：本文〕**：命名者は初代教頭**山本良吉**。屈原「漁父辞」の「滄浪の水」から採った。経緯は**1928年発行の『校友会誌』第8号**に掲載（1984年『武蔵高等学校同窓会会報』第26号に再録）。山本良吉「すすぎ川の記」全文・1期生大塚弘・伊藤高の説の全文を本文が再録〔「武蔵のケム川」という仮称段階があったこと＝repo初出〕。
- **水源の湧水〔確認：本文・観察年代の特定〕**：「源はその一部を千川水に得て居るが、大部分は塀の下より滾々と湧き出づる清水である。その水は清冽である。」という文言は**伊藤高（文科三年生・1期）の「すすぎ川の説」＝1928年時点の同時代観察**と特定〔旧未解決「湧水観察の年代」を解消。濯川の水源が千川分水＋校内湧水だったことの、年代つきの同時代証言〕。
- **蘇生事業の設計〔確認：本文〕**：計画の設計に携わったのは**内田祥哉（高校17期・東京大学名誉教授）**〔repo初出〕。蘇生事業は創立60周年記念事業として同窓生の寄付で実施、ポンプによる還流で流れを復活〔[ORG-018](ORG-018.md)（八角井戸・還流水）と対応〕。
- **三河川への使い方〔推定〕**：1959-60年「学校付近の千川上水が暗渠」・「分水は増水時のみ」という学園側の年次は、千川上水暗渠化の練馬区側時期（昭和25年頃着手説[GOV-072](../gov/GOV-072.md)・27年3月着手説[GOV-056](../gov/GOV-056.md)・28年武蔵学園前暗渠説[BLOG-113](../blogs/BLOG-113.md)）より遅い。**着手（27-28年）から学園付近の完了（1959-60年）までの数年差として整合的に読めるが、区間同定ができないため断定しない**。

## 制限・未解決

- 1953年（BLOG-113）と1959-60年（本文）の年次差の解消（区間の同定）。
- 濯川七橋・喜寿島の現況、1974年遮断の行政文書（周辺下水道整備事業の年次）の照合。
- 1981年7月22日・10月22日の濯川氾濫の周辺被害記録（地域紙・気象記録）の探索。
