# [ORG-019] 武蔵学園百年史「語り継ごう濯川」

- **書誌〔確認〕**：学校法人根津育英会武蔵学園『武蔵学園百年史』主題編「創立50周年・60周年のころ」所収の「語り継ごう濯川」（阿妻耕次郎）。学園公式サイトの百年史公開ページ（100nenshi.musashi.jp）。2026-11-11にopen_urlで頁を直接確認した（本文個別頁の抽出には至らず、年次等は同ドメインの検索結果スニペットで確認）。成書は学園創立100周年（2022年）に向けた刊行。
- **濯川の沿革〔確認：スニペット文言〕**：
  - 「1922年4月旧制武蔵高等学校創立。校地中央部を千川分水が流れていたが、田川のままの細流であった」。
  - 「江古田校地を二分して流れる細流は**千川上水の分水**で、**18世紀初め宝永年間に作られたもの**」〔濯川の起源を宝永年間の分水とする年代表記は[ORG-018](ORG-018.md)の「千川上水支流」を具体化する〕。
  - 1925年、運動場整備に合わせて分水を拡げ「**濯川（すすぎがわ）**」と命名。1928年、川畔に北極標設置。**1932年、濯川七橋に命名（上流から佐の橋・十年橋・出橋・入橋・一の橋・欅橋・玉の橋）**。1936年、根津理事長の喜寿を記念して中之島部分を拡げ「**喜寿島**」を作り、「喜寿橋」「泉橋」を架橋〔七橋・二橋の橋名一覧はrepo初出〕。
  - 「**しかし、1950年代末までに千川がすべて暗渠となり、以來、その暗渠から僅かな分水を得ていた濯川も、1974（昭和49）年、周辺下水道の整備とともに千川との連絡を断たれて**雨水の溜まり場となって孤立した」〔①「1950年代末までに千川すべて暗渠」は[GOV-069](../gov/GOV-069.md)（南田中・昭和30年頃には暗渠化済みの証言）・[BLOG-113](../blogs/BLOG-113.md)（昭和28年武蔵学園前暗渠）と整合する練馬区側の概括。板橋区側（[BLOG-103](../blogs/BLOG-103.md)「昭和20年代後半まで開渠」）との地区差は並記して断定しない。②**1974年（昭和49）の下水道整備による連絡遮断**という年次は、[ORG-018](ORG-018.md)（1983年ポンプ式蘇生事業）の前提となる濯川枯渇の時期を具体化する新根拠〕。
- **水源の湧水〔確認：旧制時代の記述引用〕**：旧制時代の記述として「**源はその一部を千川水に得て居るが、大部分は塀の下より滾々と湧き出づる清水である。その水は清冽である。**」との引用文言〔濯川の水源が千川分水＋**校内の湧水**だったことの同時代観察。千川の完全暗渠化後も濯川が細流として存続した理由の説明として、湧水系の存在を示す〔湧水の継続時期はこの文言からは推定できない〕〕。
- **命名の人物〔確認〕**：濯川の命名について[ORG-018](ORG-018.md)（校長散歩200）は初代教頭山本良吉の命名とする。本頁の年次（1925年命名）と合わせ、命名の年代が具体化した〔命名者記述の整合は本文全取得後に確認〕。
- **注意〔制限〕**：本文ページ単位の直接抽出に至っていないため、上記は頁目次確認＋スニペット引用による。引用文言の前後・湧水観察の年代（旧制のいつの記述か）は未確認。
