# [ORG-005] 東京大学小石川植物園「小石川養生所の井戸」

- 東京大学大学院理学系研究科附属植物園（小石川植物園）公式の[園内案内「小石川養生所の井戸」](https://koishikawa-bg.jp/ennai/ido/)を**2026年10月31日**に直接確認。ページの初出・更新年月は明記されていない。
- 同園は、享保7年（1722年）に設立された**小石川養生所で使用された井戸**を園内の見学対象として紹介する。
- 同園の解説は、**1923年（大正12年）の関東大震災時に飲料水として役立った**と記す。これは現在の施設管理者による歴史的説明であり、震災当時の取水量・利用者数・水質分析の原記録は未確認。
- 公式案内は園内マップへの導線を持つが、**井戸の座標、掘削年代、深さ、取水層、現在の使用可否、地下水の流向は本文に記載されない**。1722年の養生所設置年を井戸の掘削年と同一視しない。
