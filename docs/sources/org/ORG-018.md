# [ORG-018] 武蔵高等学校中学校 校長散歩200「濯川の水源」

## 書誌・確認範囲

- 武蔵高等学校中学校公式サイトの「校長散歩」第200回（2020年9月28日公開）。2026-11-11に open_url で本文全文を取得確認。
- https://www.musashi.ed.jp/blog/20200928-200.html

## 内容メモ

- **〔確認: 本文〕** 武蔵学園（武蔵高等学校中学校・武蔵大学）に流れる**濯川（すすぎがわ）は元々千川上水とつながっていたが、千川上水の暗渠化に伴い切り離された**。**1983年から学園60周年記念事業として蘇生事業が行われ、上流の水源からポンプ式で水が流れるようになった**。
- **〔確認: 本文〕** 最上流の水源（地下水）には**八角井戸**が埋められており、そこには初代教頭**山本良吉**（のち第3代校長）が「濯川」と命名した由来となった**楚の屈原の詩（「滄浪之水清兮 可以濯吾纓 滄浪之水濁兮 可以濯吾足」、楚辞「漁父」）**が記されている。
- 〔確認: 本文言及〕「清濁を呑み今日も流れる濯川物語」（武蔵学園百年史HP）を参照。

## 三河川への使い方

- 濯川（武蔵学園の水路）が**千川上水の支流（分水）として設けられた水路**であることを学校側が公式に説明する資料として、[BLOG-094](../blogs/BLOG-094.md)（sirakigi「濯川−歴史と景観−」頁）に**1983年蘇生事業の年次と八角井戸の存在・命名由来**を補強する〔sirakigi頁では1983年・八角井戸の記述は未確認だった情報〕。
- 濯川の千川上水からの分水位置・時期（江戸期か近代か）は本頁では示されず〔未解決〕。学園の所在地（中新井村／練馬区豊玉北付近）は千川上水沿い〔[BLOG-094](../blogs/BLOG-094.md)の桂橋・上石神井車両基地付近の築樋の文脈〕。
