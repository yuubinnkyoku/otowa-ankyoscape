# [ORG-011] 芝浦工業大学附属中学・高等学校公式「本校の沿革・校歌」（東京鉄道中学→池袋鉄道教習所内）

- **書誌〔確認：公式沿革表を直接判読〕**：芝浦工業大学附属中学・高等学校公式「本校の沿革・校歌」。東京鉄道中学（1922開校）を前身とする学校法人の公式沿革。
- **所在〔確認〕**：https://www.fzk.shibaura-it.ac.jp/guide/history/
- **内容メモ〔確認：沿革表の該当条目〕**：
  - **東京鐵道中学開校（麹町区永楽町1-3、鉄道教習所内）**＝1922年。
  - 関東大震災で校舎焼失後、**東京府荏原郡南品川の東京鉄道教習所内に校舎移転**。
  - **東京府北豊島郡西巣鴨字池袋の東京教習所内に校舎を移転**（大正期・1925年4月1日項）。
  - 戦時空襲で校舎焼失後、昭和鉄道学校の校舎で授業再開（1946年）、**池袋の鉄道教習所内に校舎を再建し移転**（1946年12月26日項）。
  - 1953年（昭和28）芝浦工業大学が経営引継ぎ・芝浦工業大学高等学校、**芝浦高等学校普通科・交通科（田町）が池袋に移転**。
  - 本文：開校の地は麹町の鉄道教習所内、国鉄職員・子弟のみ入学→外部開放で東京育英中学→学制改革で東京育英高等学校となり**池袋へ移転**。
- **留保**：日付は沿革表の隣接セル対応（表組による）。池袋の教習所＝[BLOG-029](../blogs/BLOG-029.md)の東京鉄道教習所（西池袋1-11-1・1924〜1954）と同一候補。丸池の区画位置は本沿革にない。関連：[GOV-055](../gov/GOV-055.md)。
