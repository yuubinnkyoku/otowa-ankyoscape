# [ORG-031] 武蔵学園百年史「オンライン博物館」濯川と自然観察の頁（看板№9）

- **直接確認（2026-11-13、open_url・本文全文・URLのGUID特定）**：武蔵学園百年史サイトのオンライン博物館・看板設置マップ№9「濯川と自然観察」の解説頁（[ORG-026](ORG-026.md)の「濯川」頁〔事項〕とは別頁。第55回ノートでは本文未取得のままだった頁を取得）。濯川を「**武蔵学園を東西に流れる濯川は千川上水の分水であり、当時は農業用水として利用されていた無名の小川であったが、山本良吉初代教頭により「濯川」と命名された**」と定義〔ORG-018〜020・026と同系統の看板文言のSSOT〕。
- **Florula/Faunaの看板文言〔確認〕**：博物を担当した**和田八重造講師**が濯川周辺を中心とした自然観察を企図し生徒と現地調査。**半径4km内の植物を調査した目録が「Florula Musashinoensis」として1926年に出版**、**同じく半径2.5哩内の動物を調査した写真つき目録が「Fauna Musashinensis」として1929年に出版**〔PAP-033/035/040の研究史と整合する看板レベルの要約。「半径2.5哩」=約4kmでFlorulaの「半径4km」と一致〕。
- **出版費用の援助〔確認〕**：**上記二つとも出版費用を根津嘉一郎理事長が援助している**〔第55回ノートで「根津嘉一郎の出版費援助」と記録していた内容の、看板文言レベルの本文確認〕。
- **調査写真の人物同定〔確認〕**：調査を担当した教員と生徒の写真に**中央前列＝和田八重造講師、その背後＝山川黙教授、右の和服姿＝柳田友輔講師**、写る生徒に**高宮篤（1期・前列右から二人目）・桑原萬寿太郎（2期）**らがいる〔**柳田友輔講師はrepo初出の人名**（和田八重造・山川黙・高宮篤・桑原萬寿太郎は第55回ノート既記録）。Florula/Fauna調査の担当教員・参加生徒の構成を写実的に裏付ける〕。
- **注意**：当頁は構内看板の解説文とみられ、ORG-018〜020・026と同系統。千川上水暗渠化の年次文言（ORG-026「1960年代」）は当頁にはない。Fauna Musashinensisの鳥類編は未刊中断（PAP-035）。
