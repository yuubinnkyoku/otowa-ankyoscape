# [ORG-030] 武蔵学園百年史・正史II第4章の千川上水調査記述とアルバム写真キャプション

- **資料〔確認〕**：武蔵学園百年史サイト（[ORG-025](ORG-025.md)と同一サイト）の正史「武蔵学園百年史」オンライン版・通史編II（旧制武蔵高等学校の歴史）第4章「生徒の課外活動」ページ。2026年11月13日閲覧。頁自体に掲載年月の記載なし（『武蔵九十年のあゆみ』系の既刊正史を掲載中とサイトトップに記される）〔未解決〕。
- **千川上水調査〔確認〕**：「**1938（昭和13）年から、石山乾二教授の指導の下で千川上水の現状調査に力を注ぎ、1941年にはその報告書『千川上水』を刊行した**。これは半世紀以上を経て、『Florula Musashinoensis』、『Fauna Musashinensis』と並ぶ武蔵野文献として注目されており、**2006年には『千川上水』の調査アルバム4冊が練馬区登録有形文化財に登録された**」。
  - 開始年1938・指導者「石山乾二教授」は[GOV-076](../gov/GOV-076.md)（昭和13〜16年調査・編者石山乾二）と整合。『Florula』『Fauna』と並ぶ武蔵野文献という評価は、千川上水調査を和田八重造のファウナ・フローラ調査の系譜に位置づける[PAP-033](../paps/PAP-033.md)の解釈の学園正史レベルでの独立裏付け。
  - 登録年「**2006年**」はGOV-076の「**平成17年度区登録**」（=2005年度）との表記差。年度呼称と暦年のずれの可能性もあるが断定せず並記。
- **調査アルバム写真キャプション〔確認・repo初出〕**：本文末尾にアルバム写真2枚の説明として「**武蔵学園記念室所蔵の『千川上水』調査アルバム中に存在する、1940年7月撮影の江古田二又の下流部分の写真。「将来かゝる風景は消えん」と説明がある。**」「**同上『千川上水』調査アルバム中に存在する写真。武蔵学園前の千川通りにあった橋で武蔵高等学校の生徒が実測中である。**」
  - 「江古田二又」の下流部分を1940年7月時点で「将来消える」風景として意識して撮影・説明していたことが、アルバムの説明文レベルで確認できる〔観察〕。調査時点（1938〜41）で開渠風景の消失（暗渠化・埋立て）が予見されていた可能性を示唆するが、説明の執筆時期（撮影時か昭和16年刊行時か）は本頁からは確定しない〔仮説として記録〕。江古田二又は[BLOG-167](../blogs/BLOG-167.md)（エンガ堀江古田駅方面支流の二又）と同地点かは断定しない。
  - 武蔵学園前の橋（[BLOG-113](../blogs/BLOG-113.md)・[ORG-022](ORG-022.md)の学園前区間）で生徒が実測中の写真が現存することの初出。
- **中新井観測所〔確認・repo初出〕**：同章に気象観測所の記述があり、1940年から中央管区気象台観測所として認められ、**1942年から「中新井観測所」の名称**となったとある。濯川=中新井村分水（[GOV-005](../gov/GOV-005.md)）・中新井の池と同じ「中新井」の字名を冠する観測所で、地域字名の旁証資料。水路そのものの記録ではない〔注意〕。
- **文化学部の起源〔確認〕**：校友会発足以前から「学校周辺で土器や矢尻の破片を採集して歩いた同好のグループ」が発展して文化学部（後の民族文化部）が作られ、原田亨一教授を中心とした、とある。千川上水調査（1938〜41）を実施した民族文化部門の前身活動の記述として記録。
