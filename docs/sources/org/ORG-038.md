# [ORG-038] 田無神社「祭典をより詳しく」〔公式による田無用水の流末・暗渠化年代・祈雨祭の全系列の記述。田無宿風土記と田無市史民俗編の引用を含む〕

- **書誌〔確認: ページ本文・2026-11-22取得〕**: 田無神社公式ページ「祭典と行事 > [祭典をより詳しく](https://www.tanashijinja.or.jp/event/details/)」〔ページmeta上の更新日2025-06-26〕。祈雨祭・雹祭・節分追儺祭・初午祭・紀元祭・祈年祭・天長祭・夏越の大祓・七夕てるてるトンネル・津嶋祭・お人形感謝祭・酉の市を網羅する解説頁。
- **田無用水の流末文言〔確認: 本文・repo初出の公式側文言〕**: 「**田無に用水が引かれたのは、元禄年間（1688～1704年）のことでありました。田無用水は、玉川上水から分水し、芝久保を経由して橋場にて二手に分かれ、それぞれ田柄川および石神井川へと注ぎます**」＝**橋場の二手分岐の先を「田柄川および石神井川」と明記する神社側の公式文言**〔[BLOG-281](../blogs/BLOG-281.md)〜[BLOG-287](../blogs/BLOG-287.md)の観察群・[GOV-513](../gov/GOV-513.md)の「ふれあいのこみち・やすらぎのこみち」文言と同じ構造を流末まで書いた点が決定的に違う〕。
- **暗渠化年代の文言〔確認: 本文〕**: 「**昭和期に入り水道施設の整備が進むと、生活用水としての田無用水の役割は終焉を迎え、昭和40年（1965年）頃にはコンクリート製の蓋で覆われ、現在の遊歩道となりました**」＝**昭和40年（1965年）頃のコンクリート蓋による暗渠化・遊歩道化**〔[BLOG-285](../blogs/BLOG-285.md)（note・1964年東京オリンピック巷間説）と1年差で近接＝『田無市史』側文言の確認が引き続き課題〕＋「**江戸時代から約300年にわたり続いた水路の流れる風景は失われてしまいました**」。
- **神橋＝遺構文言〔確認: 本文〕**: 「**田無神社の参道に架かる神橋は、田無用水がかつて河川であったことを示す、貴重な遺構であります**」＝[BLOG-281](../blogs/BLOG-281.md)・[BLOG-282](../blogs/BLOG-282.md)・[BLOG-283](../blogs/BLOG-283.md)の石橋観察（田無神社境内の石橋・立て札・水神宮）に対応する**同社公式の「神橋」呼称と遺構認定文言**〔名称の「石橋」/「神橋」表記差はそのまま記す〕。
- **田無小学校記念誌の引用〔確認: 本文・引用文言〕**: **田無市立田無小学校（1974）『東京都田無市立田無小学校創立百周年記念誌』教育出版 p.39**「**この校舎は、田無用水の上に建てられた。当時から、この用水は生徒の手洗い、飲料水、清掃などの重要な水資源であった。用水にはフナ、ドジョウ、ゲバチ、ハヤなど泳いでいたので、子ども達のよい遊び相手であった**」＝**校舎が田無用水の上に建設・生徒の飲料水・魚相（フナ、ドジョウ、ゲバチ、ハヤ）の一次文言**〔出典はページの脚注(1)による。記念誌はrepo未登録書誌〕。
- **祈雨祭の全系列〔確認: 本文＋下田富宅『田無宿風土記（二）』引用文言〕**:
  - 祭祀構造: {日照り継続→氏子代表が武蔵御嶽神社（青梅・御岳山）へお水頂戴の代参**〔孟宗竹の一節で七重の滝の水を頂き、杉の枝に結んで持ち帰る〕**→帰路は**小平の小川橋あたり**で迎えの者に引き継ぎ→**田無着後まず橋場でお祓いし、お水の一部を田無用水へ流す**→**樹齢300年の御神木（現在本殿右手の切り株）と「境内を流れていた用水」に注水**→**田無用水をせき止めて水をかぶる「みそぎ」**→**獅子頭二基を神輿に載せ町内を隈なく巡幸（竜神を招き慈雨を乞う）→未降雨なら再代参、降雨なら御礼参り**}＝**用水と祭祀が一つの水循環として記述される全文言**〔「橋場」が田無用水分岐点の祭祀上の結節点であることを示す〕。
  - 年代層: 鉄道以前は往復徒歩（朝暗いうち出発→夕方御岳山登り口）、御岳駅開業は**昭和4年（1929年）**・それまでは青梅で汽車降車、**大正10年頃から自転車利用（明治のころ田無に4台）**、掲載の祈雨祭祝詞の写真は**大正2年（1913年）斎行**〔祈雨祭の実態が大正期まで遡る座標〕。
  - 終焉: 「**祈雨祭は、戦後に「天気祭」へと名称を改めて存続しましたが、次第に行われなくなりました**」＝戦後改名と廃絶〔[BLOG-282](../blogs/BLOG-282.md)（3）に対応〕。
  - 保谷側の講〔確認: 本文・repo初出〕: 「**上保谷・下保谷においても雨乞い祈願のため、御嶽山から水を持ち帰る代参の講が組織されておりました。持ち帰った水を用いて、下保谷では天神社で雨乞い神事が、上保谷では尉殿神社で神輿の渡御が行われました**」＝**保谷（千川上水の水利に関わる村）の御嶽山代参雨乞い講と、その祭祀の担い手（下保谷＝天神社・上保谷＝尉殿神社）**〔[BLOG-111](../blogs/BLOG-111.md)（向原・榛名講）・[PAP-027](../papers/PAP-027.md)（中村垢離取不動尊・大山系）と並ぶ雨乞い霊場のネットワーク記事の西側データ〕。
- **雹祭〔確認: 本文＋『田無神社（１）』・『田無宿風土記（三）』引用文言〕**: 正式名称「五穀豊穣春祭・雹祭」・祭日は総代会で決定。起源は**明治41年（1908年）と昭和10年（1935年）の大規模雹害のどちらを契機とするか二説**〔本文〕。『田無宿風土記（三）』（1982・千曲秀版社 p.211）引用: 「**現在は群馬県の榛名神社に雹除けの神として毎年講中の方々が代参に4月８日前後に今でも行きますが、明治43年6月10日の玉子大の雹が降ったのを思いだして代参の当日は、玉子は食べない事にしてお参りに行くそうです。又5月22日は農家の仕事が忙しいので、田無神社では、1月早く4月22日に田無農協主催で雹祭を行っています**」＝**榛名神社代参講（4月8日前後）・4月22日田無農協主催雹祭という現行祭祀**（同書引用の「明治43年6月10日の玉子大雹」にはページ側が「実際には、明治41年（1908年）に発生」と注記＝**雹害年代二説（明治41年直説・明治43年6月10日記憶説）の対立を神社側ページ自体が明示**）。田無役場から農家への押し麦一斗見舞いの文言も。

## repoとの関連〔観察〕

- **流末構造の第3系統**: 橋場の南北分岐の流末を「田柄川および石神井川」と書く公式文言が、[BLOG-281](../blogs/BLOG-281.md)「北水路＝柳沢遊水地から石神井川→田柄用水完成で接続切替」（観察）・[BLOG-287](../blogs/BLOG-287.md)（2）「明治初期図では北水路は石神井川と非接続」（田無市史1872年図の読図）に対して、**神社側の現行公式解釈**として加わる。暗渠化以後の遊歩道（やすらぎのこみち・ふれあいのこみち〔[GOV-513](../gov/GOV-513.md)〕）の説明系としても田無神社自身が用水史を所管している。
- **暗渠化年代の補強**: 昭和40年（1965年）頃コンクリート蓋文言は、[BLOG-285](../blogs/BLOG-285.md)の1964年（東京オリンピック）巷間説に**公共側ではないが由緒ある主体（氏神）による「昭和40年頃」の別系統**を与える〔1年差は年代特定の絞り込みに資する〕。
- **祈雨祭＝水利と祭祀の接合**: 「お水の一部を田無用水へ流し」「境内を流れていた用水に流し」「田無用水をせき止めてみそぎ」という文言は、[BLOG-281](../blogs/BLOG-281.md)（4）の田無神社境内の北水路文言と直結し、**田無用水の祭祀上の位置（橋場＝分岐点の同時にお祓いの場）** を示す。保谷の御嶽山代参講は千川上水系（保谷）と田無用水系（田無）が**同じ雨乞いネットワーク（武蔵御嶽）**でつながっていた観察材料。
- **喧嘩神輿の石神井川はさみ文言**: 石神井川が田無の町区（1区・2区・5区）の境界であったことの民俗面の文言として、石神井川の社会的機能の記録層。

## 意義〔観察〕

- 田無用水の水系構造（分水・流末・暗渠化・遺構）を、個人の散歩ブログ（musasinowalker・miwa3k・大貫伸樹）と行政（[GOV-513](../gov/GOV-513.md)）に次ぐ**第3の主体（地域の氏神）の公式ページとして**記録した点で、出典体系の多様性が一段上がる。
- 祈雨祭の全行程（御嶽山取水→小川橋引継ぎ→橋場お祓い→用水注水→みそぎ→巡幸）は、田無用水が生活用水であると同時に**祭祀用水**でもあったことを示す一次記述で、他の資料にはない層。
- 下田富宅『田無宿風土記（二）（三）』・『田無神社（１）（２）』・『たなしのむかし話 その1』・『田無市史第四巻 民俗編』・田無小学校百周年記念誌という**未登録書誌・内容の所在が田無用水関係文言つきで所在特定できた**＝今後の個別BOOK化候補リスト。
