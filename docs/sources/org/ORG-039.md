# [ORG-039] 学習院大学広報マガジン G.LiFE Web「目白の地理さんぽ」〔学習院公式広報の目白崖線巡検記録・霜柱学説の教育現場での応用〕

- **書誌〔確認: ページ本文・2026-11-23取得〕**: 学習院大学の広報マガジン **G.LiFE Web** の「さんぽ」記事「**目白の地理さんぽ**」 https://glifeweb.jp/articles/sanpo/240 （2025年2月公開・高等科の地理の授業で実施した目白キャンパスと周辺の巡検を同法人の公式広報としてまとめた記事。写真9点＋巡検ルートマップ＋地名由来イラスト付き）。学習院の法人本部・大学・高等科・中等科・幼稚園が所在する豊島区目白の地誌を、**高等科教員の巡検実習（PHOTO1〜9）**として所在・標高・坂道・説明板ごとに記録したもの。
- **地形記録〔確認〕**: 「**標高32mの洪積台地は「豊島台地」または「目白台地」と称され、学習院の目白キャンパスはこの台地の南端に位置する**」＋キャンパス内の高低差＝「10mの高低差を緩やかに下り西坂門から入り、テニスコート脇の10m弱の急な坂を上って、またすぐ血洗いの池に向かって10mほど下る」〔学生実習レベルとはいえ学習院公式広報による台地基面高・標高値の明記〕＋「**西門を左折し「椿坂」とも称される西坂を下る。椿は江戸時代の台地上の雑木林に自生しており、目白一体の冬の枯れ野に紅をさすことで愛でられた**」〔**西坂＝椿坂の別称の明記＋椿の自生という植生側の由来叙述**＝[BLOG-198](../blogs/BLOG-198.md)の椿坂（椿山の旧跡に因む・里俗又新坂）の音羽側からの記録に対する学習院側の補強〕。
- **説明板の文言〔確認〕**: ①**血洗いの池の説明板**＝「**湧水でできた池。かつては灌漑に用いられた**」〔池の起原・用途の簡潔規定文言。[BLOG-295](../blogs/BLOG-295.md)（2015年のブログが引用した学習院構内案内の全文言）と整合〕。②**富士見茶屋跡の説明板**＝「**江戸時代、神田川の崖線の高台から富士山が一望でき、目白不動参りや鬼子母神詣での遊山に訪れた江戸っ子が一服する茶屋があった**」〔江戸期の目白崖線上の行楽（目白不動参道・鬼子母神詣）の説明板文言＝[BOOK-100](../books/BOOK-100.md)（豊島風土記・富士見茶屋p.208）と対照できる現地設置の記録層〕。③おとめ山公園＝「**落合崖線にある斜面緑地**」＋巡検で「**おとめ山公園内にある崖線の湧水点を確認**」〔崖線湧水点の実地確認の記録〕。
- **神田川の崖線の全体規定〔確認〕**: 「**西武新宿線中井駅付近から東京メトロ有楽町線江戸川橋駅付近までの5kmほど続く神田川左岸の斜面**。学習院目白キャンパス南側、関口芭蕉庵、新江戸川公園、椿山荘の庭、おとめ山公園、東長谷寺（薬王寺）の庭はいずれも、崖線の雑木林の原風景・原地形が残されている貴重な場所。それらの多くにはそれぞれ「湧水点」がある」＋「**崖線の北側の高台は江戸時代、「富士見台」ともよばれ、富士山が望める江戸っ子の遊山の行楽地として賑わった**」〔**中井〜江戸川橋間・約5km・神田川左岸という崖線の範囲規定＋湧水点付きの緑地リスト（学習院・芭蕉庵・新江戸川公園・椿山荘・おとめ山公園・東長谷寺）＝[BLOG-068](../blogs/BLOG-068.md)の湧水観察リストと対応する公式広報側の一次的記録〕
- **地名由来〔確認・諸説はページ自身が断定を避ける〕**: 落合＝「**神田川と妙正寺川の合流地点（落ち合う場所）に由来する説が有力。（所説あり）**」／関口＝「**神田川（旧名「江戸川」）から上水を引いたときの取水口（堰）があったことから「関口」。松尾芭蕉が水門管理の役人を務めた時の住まいが「芭蕉庵」として残されている**」〔関口の上水取水堰命名説＝[GAZ-013](../gazetteers/GAZ-013.md)（御府内備考・関口之一の地名由来「堰を仮借して関と書く」）の続行文言候補。ただし本記事は巡検教材レベルの出典表示で、『江戸砂子』等の一次考証の提示はない〕／目白＝「五色不動と呼ばれる不動尊群の1つ「目白不動」が**当初、文京区関口1丁目付近に建立されたが、戦災で現在の金乗院境内に移された**」／御留山＝「江戸時代の将軍家の狩場だったことから一般人立ち入り禁止として「御留(止)山」と呼ばれ、名称の由来になっている」／椿山荘＝「山縣有朋が自らの別荘に名付けた名称」。
- **日立目白クラブ〔確認・repo初出〕**: 「**1928年に旧制高等科学生の寄宿舎として建築された。新制大学発足後も引き続き使用されたが、1952年に中央商事に売却され、現在は日立製作所の社員クラブになっている**」＋「権藤要吉設計のアール・デコ様式」の階段の写真〔**学習院旧制高等科寄宿舎（1928）→1952年中央商事への売却→日立製作所社員クラブという建物来歴と権藤要吉設計のアール・デコ様式の文言はいずれもrepo初出**。学習院構内（椿山荘北方の目白崖線上縁）の近代建築史の記録層〕。
- **霜柱学説〔確認〕**: 結びの「目白の地形」＝「**神田川の浸食で形成された南向きの左岸斜面は急崖に対し、北向きの右岸斜面は緩斜面で、両岸の傾斜が異なる「非対称谷」が形成されている。その主な要因は「日当たりの良し悪しによって霜柱ができやすいか否かが異なり、その結果、斜面の土壌の凍結・融解の程度が異なることによって形成される」。（『霜柱学説』（貝塚爽平「東京の自然史」2011年, 講談社学術文庫））すなわち、日当たりの良い学習院目白キャンパスのある北側斜面は霜柱が立ちにくく、日陰になる南側斜面は頻繁に立つ霜柱が日中に融解して微小の地滑りを繰り返すことで緩斜面が形成され、川を挟んで急斜面と緩斜面の非対称谷が形成される**」〔貝塚爽平『東京の自然史』（講談社学術文庫・2011）の霜柱学説を、**神田川を目白キャンパス前で横断する巡検の結論として教育現場が採用している**記録。同書66-74頁の地下水と集落の紹介文言は[PAP-020](../papers/PAP-020.md)の文献案内で既出だが、非対称谷への適用例は初出]。

## repoとの関連〔観察〕

- **血洗いの池・目白崖線の現行の一次的記録の追加**: 「湧水でできた池・灌漑に用いられた」の説明板文言（[BLOG-295](../blogs/BLOG-295.md)の2015年構内案内の全文言と照合）・おとめ山公園の湧水点確認・中井〜江戸川橋の5km崖線規定が、学習院自身の公式広報として記録された点で、[BLOG-068](../blogs/BLOG-068.md)（個人ブログの湧水リスト）と[BOOK-100](../books/BOOK-100.md)（豊島風土記）に加わる第3主体（大学）の出典。
- **音羽谷の非対称谷の成因論への関連**: 貝塚爽平の霜柱学説（日当たり差→霜柱の凍結融解差→斜面後退差）は、[未解決問題「音羽谷の非対称な横断面の成因」](../../open-questions/音羽谷の非対称な横断面の成因.md)の説明候補4と同型の機構。ただし本記事の適用対象は**学習院前の東西流区間（北向き右岸＝緩・南向き左岸＝急）**であって、概ね南北方向の音羽谷区間にそのまま日向・日陰の説明を写すことは従来どおりできない〔同ページの注意（玉川上水の東西走向例との対比）を維持したまま、神田川自体のE-W区間で学説が生きていることの現行例として参照される〕。
- **椿坂＝西坂の別称**: 弦巻川の水源地帯（椿山荘・学習院西側の谷頭）の地形記録の補強。椿の自生という由来叙述は[BLOG-198](../blogs/BLOG-198.md)の椿山旧跡説の植生側の裏付け候補にすぎず、独立断定はしない。

## 意義〔観察〕

- 高等科の地理巡検という**教育現場の実習が公式広報化された**もので、目白崖線の地形・湧水・説明板・地名由来の現行状態を2025年時点の学習院側の記録として一冊分一覧できる。広報記事ゆえ一次史料ではないが、**設置主体（大学）自身が血洗いの池＝湧水を由来と認識し教材化している**ことが池の水文化史の現在進行形の記録になる。
- 貝塚爽平『東京の自然史』の霜柱学説が**2025年の時点の高校地理教育で神田川に適用され続けている**ことの現生証拠＝非対称谷の成因論が生きた知識として継承されている地域の記録。

## 制限・未解決

- ①巡検記事のため、現地説明板の文言は写し取りで、設置年度・設置主体（学習院・区等）の明記はない。②血洗いの池の「案内」としては[BLOG-295](../blogs/BLOG-295.md)が引用した2015年時点の構内案内の方が詳細で、本記事の簡単文言との間の案内板の入れ替え等の変遷は確認できていない。③霜柱学説の適用の学術的な妥当性（音羽谷N-S区間への適用可否）は本記事では検討されておらず、repoの未解決問題の解決材料ではない。④地名由来の各説（落合・関口・目白・御留山）は教材レベルの記述で、出典の書誌表示がない（一部所説扱い）。
