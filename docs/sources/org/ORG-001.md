# [ORG-001] 共同印刷の1898年小石川移転

- 共同印刷『CORPORATE PROFILE 2024』。
- https://www.kyodoprinting.co.jp/company-profile/pdf/profile2024.pdf
- 1897年に京橋区竹川町で博文館印刷工場を創業し、1898年に小石川区久堅町（現本社所在地）へ移転して合資会社博進社工場と改称したことを確認する公式沿革。
- **年代差に注意**：文京区公式「氷川下町会」に掲載された地域史は、博進社印刷工場の「播麿たんぼ」進出を1896年とする。会社公式沿革の1898年小石川移転とは2年の差があるため、1896年を移転確定年としては採用せず、両資料を併記して原資料確認の対象とする。文京区公式：https://www.city.bunkyo.lg.jp/b011/p001251.html
