# [ORG-027] 武蔵写真館045「千川通りの桜」1957年・暗渠化済み川床未舗装の写真キャプション

- **直接確認（2026-11-12、open_url・本文全文）**: 武蔵学園百年史サイト「武蔵写真館」ギャラリー045「武蔵周辺の江古田風景」の個別写真頁。**写真番号MS027-001m「千川通りの桜」・1957年4月12日撮影**。「講堂北側付近から東方向を望んだもの。**千川沿いの桜並木はそのままに、暗渠化された千川の川床部分は未だ舗装されていない**」〔**1957年時点で武蔵学園前の千川が暗渠化済みで、川床が舗装前だったことを写す公式キャプション＝repo初出**〕。
- **〔確認〕 暗渠化年次問題への位置づけ**: [BLOG-113](../blogs/BLOG-113.md)（1953年・武蔵学園前暗渠）→**1957年（本写真: 暗渠化済み・未舗装）**→[ORG-022](ORG-022.md)（1959年2月写真: 埋立て跡の半分が歩道化済み）→[ORG-026](ORG-026.md)（1960年代表記）・[ORG-019](ORG-019.md)（1959〜60年）の並びのうち、**1957年の実写真が1953年説を支持する方向の第4の傍証**（撮影・キャプションは学園側資料であり、行政の工事記録ではないため断定はしない）。
- **〔確認〕 ギャラリー045の千川関係写真群の所在**: 一覧に「1929年の江古田駅」「**正門前の千川**」「**千川通りでの植樹**」3枚「**1959年の千川通り**」「1960年頃の江古田の町」等の個別頁の存在を確認〔**千川通りでの植樹（千川堤植樹〔[BLOG-101](../blogs/BLOG-101.md)参照〕の学園周辺での実施か）の写真が3枚ある点は読図・判読の候補**。個別頁URLの取得とキャプション採録は次回課題〕。
- **意義**: [GOV-092](../gov/GOV-092.md)（1952年・旭丘「暗渠化された直後」）から[ORG-022](ORG-022.md)（1959年）の間を埋める**1957年の一次的影像史料の所在特定**で、武蔵学園前区間の暗渠化→整備の時系列を写真3点（1952・1957・1959）で追えるようになった。
