# [ORG-027] 武蔵写真館045「千川通りの桜」1957年・暗渠化済み川床未舗装の写真キャプション

- **直接確認（2026-11-12、open_url・本文全文）**: 武蔵学園百年史サイト「武蔵写真館」ギャラリー045「武蔵周辺の江古田風景」の個別写真頁。**写真番号MS027-001m「千川通りの桜」・1957年4月12日撮影**。「講堂北側付近から東方向を望んだもの。**千川沿いの桜並木はそのままに、暗渠化された千川の川床部分は未だ舗装されていない**」〔**1957年時点で武蔵学園前の千川が暗渠化済みで、川床が舗装前だったことを写す公式キャプション＝repo初出**〕。
- **〔2026-11-12 第41回追記・確認〕 1956年4月12日の第2の未舗装写真**: 同ギャラリーの個別写真頁「**千川通りを隔てての三号館**」（[MS028-005m](https://100nenshi.musashi.jp/Gallery/Photo/0974cc8b-efee-4176-8aa2-da311e3bb0a6)）のキャプションを直接確認。「**1956年4月12日撮影、千川通りの北側より正門、三号館を撮影したもの。千川通りの手前側は舗装されておらず、写真左側の自動車はオート三輪である**」〔**1957年写真に先行する1956年時点でも千川通りの暗渠川床が未舗装だったことを示す第2の公式キャプション**。1956→1957→1959（[ORG-022]）と未舗装→整備の経過が3時点で追えることになった〕。
- **〔2026-11-13 第45回追記・確認〕 1960年頃グリーンベルト造成中のキャプション**: 個別写真頁「**1960年頃の旧一号館**」（[12f648c6](https://100nenshi.musashi.jp/Gallery/Photo/12f648c6-6395-4acf-93ca-4ea54ea74b09)）のキャプション「**撮影時期不詳（1960年ごろ）、千川通り北側より三号館、正門を撮影したもの。当時千川通りのグリーンベルトを造成中であった**」〔**千川通りのグリーンベルト（歩道帯）造成が1960年頃進行中だったことを示す公式キャプション＝repo初出**。1959年2月（ORG-022・埋立跡半分が歩道化済み）→1960年頃（グリーンベルト造成中）→昭和40年代後半（下記・車道拡幅）と整備の経過が追える〕。
- **〔2026-11-13 第45回追記・確認〕 1970年代の千川通り**: 個別写真頁「**1970年代の千川通り**」（[a66329d6](https://100nenshi.musashi.jp/Gallery/Photo/a66329d6-0f31-4ceb-8e18-c53180287115)）のキャプション「**昭和40年代後半の撮影、大学3号館から見下ろした正門と千川通り。以前と比べ、千川通りの車道がだいぶ広くなっているように見える**」〔**車道拡幅が昭和40年代後半までに進んだことを示す観察記録キャプション＝repo初出**。[BLOG-145](../blogs/BLOG-145.md)コメント欄の1970年代後半の道幅拡幅記憶証言と整合〕。
- **〔2026-11-13 第45回追記・確認〕 「正門前の人々」PS050-004m**: 個別写真頁「**正門前の人々**」（[19ac9422](https://100nenshi.musashi.jp/Gallery/Photo/19ac9422-5734-4b83-a575-02043bc69c0b)・写真番号PS050-004m）のキャプション「**撮影時期不明、千川通り。写真右端がちょうど正門であり、写真中央の人々はバスを待つ人々と思われる。左には碁会所の看板がみえる**」〔**千川通り沿いの碁会所（当時の通り沿い商業设施）の存在＝repo初出の小観察**〕。なお「**正門前の千川**」「**正門前の千川通り**」「**1950年代の千川通り**（1959年2月・1号館から見下ろした正門と千川通り、埋立跡の向こう側半分は広い歩道）」「**千川通りでの植樹**」3枚の個別頁も一覧で存在確認〔「1950年代の千川通り」のキャプションは[ORG-022](ORG-022.md)と同内容。「正門前の千川」自体のキャプション本文は依然未取得〕。
- **〔確認〕 暗渠化年次問題への位置づけ**: [BLOG-113](../blogs/BLOG-113.md)（1953年・武蔵学園前暗渠）→**1956年（川床未舗装）→1957年（「千川通りの桜」: 暗渠化済み・未舗装）**→[ORG-022](ORG-022.md)（1959年2月: 埋立て跡の半分が歩道化済み）→**1960年頃（グリーンベルト造成中）**→**昭和40年代後半（車道拡幅観察）**→[ORG-026](ORG-026.md)（1960年代表記）・[ORG-019](ORG-019.md)（1959〜60年）の並びのうち、**1956・1957年の実写真2枚が1953年説を支持する方向の傍証**（撮影・キャプションは学園側資料であり、行政の工事記録ではないため断定はしない）。
- **意義**: [GOV-092](../gov/GOV-092.md)（1952年・旭丘「暗渠化された直後」）以降の武蔵学園前区間を写真6時点（1952・1956・1957・1959・1960頃・1970年代）で追える一次的影像史料群となった。
