# [ORG-023] 城北中央公園調節池一期工事の視察報告（2024年4月16日見学）

- **資料〔確認：公開PDF本文〕**：土木技術系の現場視察報告「城北中央公園調節池（一期）工事」（発注者：東京都建設局・施設所在地：板橋区・練馬区、**調査見学時期 2024年4月16日**）（[enaa.or.jp/?fname=2024_chosetsuchi.pdf](https://www.enaa.or.jp/?fname=2024_chosetsuchi.pdf)）。〔確認：技術系視察報告の本文〕
- **工種の詳細〔確認〕**：一期は**ニューマチックケーソン工（延長80.3m×幅33.4m×深さ35.3m）2函**、ケーソン間接続工、調節池内部構築工、取水施設築造工からなる。**2函同時沈設は日本最大級**で、視察時点でケーソン沈設・内部構築・ケーソン間接続がほぼ終了し調整池底部まで見学できた。**ケーソン間接続は将来の維持管理効率化と地上有効利用のため上下2か所で行われ、確実な止水のため凍結工法が使用された**。
- **二期計画〔確認〕**：今後**二期工事が予定され、一期の約9万m³と合わせ全体では約25万m³の貯留量**となる。石神井川では1時間当たり75mmの降雨に対応できる河川整備を進めている。
- **意義〔解釈〕**：[GOV-083]（2022・電子展示室）と[GOV-087]（2025・報道）の間の2024年時点の施工状況と工法（凍結工法）を補う技術資料。
