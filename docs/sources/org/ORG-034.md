# [ORG-034] 東京都水道局（2021）— 神田・玉川上水廃止の明治34年説の公式文言

- **文言〔確認〕**: 東京都水道局のプレスリリース「2021年度東京都水道歴史館『秋の特別企画展』のお知らせ」（2021年10月29日）は「**本年は明治34（1901）年の神田・玉川上水廃止から120年になることを記念して、明治時代にも引き続き東京市民の生活を支えた江戸時代以来の上水について紹介します**」と記す＝**東京都水道局（東京都水道歴史館）は神田・玉川両上水の廃止を明治34年（1901）とする公式見解**。同時開催の上水記展（東京都指定有形文化財『上水記』の年1回の一般公開・2021-10-30〜11-07）・水道歴史展「明治時代の神田・玉川上水」とセットの告知。([水道局プレスリリース](https://www.waterworks.metro.tokyo.lg.jp/information/topics/r3/10/2021102902))
- **廃止年次の対立における位置づけ〔確認〕**: [GAZ-065](../gazetteers/GAZ-065.md)（大日本地名辞書・1907）は神田上水の府内給水廃止を「明治三十三年」と記し、[GOV-307](../gov/GOV-307.md)（東京市水道史論）は明治34年6月の給水停止と記す。**都水道局側は2021年時点でも明治34年説を採用**しており、GAZ-065の明治33年説との対立において現代の事業主体（水道行政の継承者）側のdatapointとなる。同一時点の複数過程（府内給水廃止と市内給水停止の別時点）の可能性はGAZ-065の制限③のとおり残す。
- **都水道局側の同説の他頁〔確認・2026-11-17確認〕**: ①都水道局「玉川上水の歴史」頁「**玉川上水は明治34年（1901年）に市内への給水を停止し**、淀橋浄水場に原水を運ぶための施設へと役割を変えました」([水道局・玉川上水の歴史](https://www.waterworks.metro.tokyo.lg.jp/kouhou/pr/tamagawa/rekishishiritai/rekishishiritai/rekishi))。②東京都水道歴史館サイトの同展示案内「江戸・東京の人々の生活を支え続けた神田上水・玉川上水が廃止されたのは明治34年（1901）」([水道歴史館](https://www.suidorekishi.jp/event/2021josuiki/))。③水道局「STEP21 第2章 東京水道100年のあゆみ」も「神田・玉川上水は明治34年に廃止となった」([STEP21](https://www.waterworks.metro.tokyo.lg.jp/suidojigyo/torikumi/seisaku/pastplans/step21/02))＝都水道局系のページで明治34年説が一貫している。

## 制限・未解決

- ①プレスリリース本文の直接取得は2026-11-17時点で検索サービス経由のスニペット・キャッシュで文言を確認した（ページ自体は存続）。②明治34年説と明治33年説（[GAZ-065](../gazetteers/GAZ-065.md)）の優劣は本資料群では解決しない（廃止過程の複数時点の可能性を残す）。③神田上水単独の給水停止月（GOV-307の明治34年6月説）の月レベルの確認資料は本頁群にはない。
