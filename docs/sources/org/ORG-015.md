# [ORG-015] 椿山荘庭園の水景構成と古香井の伝承（公式）

- **資料〔確認〕**: ホテル椿山荘東京「[『令和十二景』](https://hotel-chinzanso-tokyo.jp/page/12views-of-the-reiwa-era/)」公式ページ。2026-11-11全文取得確認。令和5年（2023）の開業70周年に策定。
- **〔確認・伝承〕** **「古香井（ここうせい）」は秩父山系からの地下水が湧き出る井戸**と説明し、**大正12年（1923）の東京大震災の折に水を求める被災者に開放され、人びとの渇きを潤したと言われる**〔確認：公式ページの伝承文言／未確認：震災時の一次記録〕。藤田平太郎男爵の妻富子が好んだ場所。**古香井の震災開放伝承はrepo初出候補**（[BLOG-068](../blogs/BLOG-068.md)は古香井を湧水地点として扱うが伝承文言なし）。
- **〔確認〕** **「ほたる沢」は元々「竹裏渓」と呼ばれ、山縣有朋が選定した「椿山荘十勝」の流れがあった場所で、現在もせせらぎを保つ**。**聴秋瀑**（幽翠池から流れる水が岩間から落ちる小滝）・**幽翠池・雲錦池**（造営当初からの水景）・**五丈滝（昭和40年〔1965〕竣工・伊藤邦衛設計）**・**望郷橋（令和5年に命名、水流の交わり＝各水系の合流点が山縣公の庭園観の象徴と説明）**。
- **〔確認・二次〕** 椿山荘は明治11年（1878）に山縣有朋が入手・築園（「南北朝時代から椿の景勝地『つばきやま』」）、大正7年（1918）に藤田平太郎が譲り受けた沿革。
- **〔repoへの関連〕** 音羽谷・目白台の湧水系（椿山荘は旧「水窪」の谷頭に隣接する台地の庭園）の**近代の水源利用と震災時の応急給水の記録候補**。庭園の採水構造（谷戸の水源と隣接する芭蕉庵〔東京の名湧水57選〕の湧水）については他資料と合わせて検討する〔観察〕。
- **〔未解決〕** 古香井の現況と水量、震災開放伝承の出典（藤田家の記録等）、竹裏渓の流路と弦巻川・水窪川水系への接続関係。
