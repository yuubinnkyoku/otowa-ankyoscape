# [ORG-032] 武蔵学園百年史サイト「Florula Musashinoensis, Fauna Musashinensis」頁

- **直接確認（2026-11-13 第66回、curlによる本文取得）**: 資料館「所蔵資料一覧」Index頁（GUID 019eaa28-fb7a-71de-be84-a3364ff3c36b）経由で個別頁を特定・本文確認。第55回・第58回・第59回で「GUID形式URLが特定不能」だったFauna個別頁の解消。**2026-10-01公開**。
- **Fauna Musashinensis No.1: April, 2589(1929)**〔サイト表記。「2589」は「1929」の誤植と解されるが表記のまま記録〕＝1929年刊行。**Fauna No.2: April, 2598(1936)**＝**1936年刊行〔repo初出の書誌情報〕**。[PAP-035](../papers/PAP-035.md)（高田・白井2016）の「鳥類のFauna Musashinensisが未刊中断」との関係（シリーズとしてはNo.2まで刊行で、鳥類編が中断だった可能性）は**要原文確認で断定しない**。Florula Musashinoensis 1926〔既知〕。
- **本文PDFの公開URL〔repo初出〕**: Fauna No.1のPDFが `https://100nenshi.musashi.jp/Historical_Materials/_PDF/019ef7dc-8e94-711e-ae52-b123fae7c5cf` で公開（Google Docs Viewer経由・直接取得可・約8.8MB・**スキャン画像のみでテキスト層なし**＝OCR環境なしでは機械的な種名抽出不可）。**[PAP-033](../papers/PAP-033.md)課題「Fauna No.1で千川上水産2種の種名特定」の原典アクセスが開通**（判読は人手・OCR環境待ち）。
- **調査の概要説明〔確認〕**: 和田八重造講師を中心に専門家・生徒が「半径数キロ」で動植物相調査（1920年代後半〜1930年代刊行）。**出版に際し根津嘉一郎氏が個人として援助**（[ORG-031](ORG-031.md)看板文言と整合）。著作者表記: 和田八重造・**久内清孝**（著作者表記の初確認）・根津嘉一郎。
- **制限〔未解決〕**: Fauna No.1本文PDFの判読（千川上水産2種の種名）。Fauna No.2のPDF頁（01a06492→個別頁GUID 01a0ea6f-e1ba-7eb3-951d-4232d846cdc1は確認済みでPDF URL未取得）。「2589/2598」表記の初出（原本の表記かサイトの誤植か）。
