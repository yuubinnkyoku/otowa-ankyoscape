# [ORG-025] 武蔵学園百年史サイト 資料館の千川上水調査アルバム公開

- **直接確認（2026-11-12、open_url・サイト更新情報）**: 根津育英会武蔵学園百年史サイト（[100nenshi.musashi.jp](https://100nenshi.musashi.jp/)）の更新情報欄に「**2026.08.01　資料館に「千川上水調査アルバム」を追加しました**」の記載を確認〔[GOV-076](../gov/GOV-076.md)（練馬区b1706・平成17年度区登録文化財・武蔵学園記念室所蔵・石山乾二編・昭和13〜16年調査・4冊200カット超）の当該アルバムが、2026年8月1日付で学園百年史サイトの「資料館」にデジタル公開されたことを示す更新記録〕。第21回ノートの課題「アルバム本文確認手段」がネット上で開けたことになる。
- **アクセス〔確認〕**: 資料館トップ頁（[Historical_Materials](https://100nenshi.musashi.jp/Historical_Materials)）から「所蔵資料一覧」経由でアクセスする構成。**アルバム個別頁の直接URLは今回特定できず**（2026-11-12時点で検索エンジンに未収録）。「所蔵資料」カテゴリのリンクを辿る形での閲覧が次の一手。
- **同一資料館の他の2026年追加〔確認〕**: 本間文書第3〜5集（2026-08-15〜10-15）・Fauna Musashinoensis No.1/2（2026-09-03/10-01）・写真館「110 武蔵学園の樹木・歴史版」（2026-11-01）など、千川・濯川に直接関係しない資料館・写真館の追加が継続していることは、同サイトの更新頻度の記録として付記。
- **注意**: アルバム本文・収録写真の内容は今回未確認。b1706頁・GOV-076の書誌情報（昭和13〜16年・石山乾二編・4冊）とデジタル版の収録範囲（全4冊か否か・キャプションの有無）の一致は確認後に更新する。
