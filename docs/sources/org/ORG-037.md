# [ORG-037] 日本地下水学会「善福寺川の湧水」（地下水余話）〔repo初出・2018年時点の原寺分橋湧水観察〕

- **書誌〔確認: ページ本文・2026-11-21取得〕**: 公益社団法人日本地下水学会サイト「アーカイブ＞地下水余話」コラム「善福寺川の湧水」。**情報掲載日2018/05/30・執筆担当「しん」・撮影日2018年4月30日**。
- **地点文言〔確認: 本文・repo初出の住所文言〕**: 「杉並区の善福寺公園から歩いて約15分位の場所、**原寺分橋の地点（杉並区西荻北４丁目40番地～５丁目18番地の間）**」＝原寺分橋湧水の番地レベルの文言。[BLOG-248](../blogs/BLOG-248.md)（西荻北4-40岸壁）・[GOV-489](../gov/GOV-489.md)区カメラ1（西荻北5丁目）と同一界隈。
- **観察文言〔確認: 本文〕**: ①「湧水量は少ないものの、水中の枯れ葉が湧水の揺らぎで動く様子を見ることができました」②「雨が降り川が増水で水位が上昇すると**湧水口は水没してしまいそうな位置**にありました」＝2018年時点で湧水量「少ない」・増水時水没が想定される位置関係の一次観察。③善福寺川遊歩道内に「**湧水のしくみ**」の看板設置（撮影写真の説明）＝後の[BLOG-248](../blogs/BLOG-248.md)（2026年4月時点で痛んで判読不能・平成15年度設置のパネルと同一の管理系列）。
- **意義〔観察〕**: ①2018年4月時点の原寺分橋湧水の状態を学会コラムが記録＝[GOV-486](../gov/GOV-486.md)P.24「地下水位は地面から3.5m（R4年より観測）」の観測開始の前段階にあたる民間観察の基準点、②「増水で水没」と「枯れ葉が揺らぐ」の対比＝湧水量が小さいが常時湧出している状態の記述、③[BLOG-248](../blogs/BLOG-248.md)の「2018年動画に比べると水量が減っているように思います」（2026年）と直結する**比較基準年**としての採録。
- **制限・未解決**: ①動画の中身（jagh.jp上の映像）は未確認。②湧水量の数値は本文にない。③「しん」の氏名・所属は不明。
