# [ORG-010] 東邦音楽大学・三室戸学園の大塚校地の沿革

- **書誌・所在〔確認〕**：東邦音楽大学公式サイトの「沿革」ページ。2026年11月8日に本文を文字抽出で確認。ページの公開・更新日は明記なし。
- **大塚校地の取得・移転〔確認：公式沿革の叙述〕**：**1934年（昭和9年）**、三室戸敬光がJR大塚駅前（豊島区西巣鴨2丁目2071番地）に「東京高等音楽学院大塚分教場」を開設。**1938年**に三室戸為光が継承し「東邦音楽学校」に改称。**1939年**、**小石川区（文京区大塚上町25番地）に校舎落成**し、東邦音楽学校を大塚駅前より**大塚の現在地に移転**。**1954年**、大塚キャンパスが文京区大塚上町より現在の**文京区大塚4丁目46番9号**に町名変更。
- **校舎の残存・移転〔確認：公式沿革の叙述〕**：**1939年（昭和14年）から使用の校舎一部360平方メートル**を川越に移転し、記念校舎（現・東邦音楽学校三室戸記念館）として復元したと記す。
- **法人の変遷〔確認〕**：1946年 財団法人三室戸学園設立、1951年 学校法人三室戸学園に組織変更。
- **資料の限界〔未解決〕**：**池・湧水・旧河道・水辺への言及はない**。校地の敷地範囲・樹林地の有無・1939年以前の土地利用は、この沿革では分からない。敷地の現況・区による取得は [GOV-054](../gov/GOV-054.md) を参照。
