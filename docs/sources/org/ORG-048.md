# [ORG-048] 齋藤知明レポート（2024-04-01）— 第2回縁日の記録とさんぽ市（2021-12）の年次

## 要点〔確認: レポート本文〕

- **2023年11月11日＝第2回種子地蔵縁日**（大正大学南門広場）。**「2021年12月に開催されたプレイベントとしての「種子屋街道さんぽ市」、2022年11月の第1回種子地蔵縁日に続いて実施された第2回」**〔確認: 本文〕＝**種子屋街道イベント群の初回＝2021年12月（さんぽ市）の年次文言**（[ORG-047](ORG-047.md)の2022年縁日マーケット名との同名再利用の整理を確定させる文言）。
- 観光庁「**インバウンドの地方誘客や消費拡大に向けた観光コンテンツ造成支援事業**」の採択事業として、主に外国人観光客をターゲットに実施〔確認: 本文＝[ORG-046](ORG-046.md)（2022年度実証事業）・[ORG-047](ORG-047.md)（看板商品創出事業）に続く3つ目の観光庁系事業名の記録〕。
- コンテンツ（第2回縁日）: ①種子地蔵クイズ②御朱印③さざえ堂参拝ツアー④キャンパス農園ツアー＆芋堀り⑤足湯⑥銭湯スタンプラリー⑦すがもプロジェクトパネル展示⑧写経体験⑨飲食販売（江戸東京野菜・滝野川焼きそば等）⑩**江戸東京野菜の種の配布（株式会社日本農林社協賛）**⑪**種子地蔵「一粒万倍シール」の配布**⑫観光用スマホガイド「くノ一（くのいち）戦隊〜巣鴨の街を取り戻せ〜」⑬第11回鴨台祭・第13回鴨台盆踊り合同報告会〔確認: 本文〕。
- **Locatone（位置情報連動のサウンドAR）**による観光用スマホガイド（日本語版＋英語版）。「巣鴨地蔵通り商店街から庚申塚商栄会にいたる**旧中山道**の歴史を観光用スマホガイドで理解しながら」という**モニターツアーの区間記録**〔確認: 本文。神田外語大学留学生・追手門学院大学生の参加〕。「**巣鴨は大学のキャンパス、大学は巣鴨の観光地**」文言〔確認: 本文〕。大正大学2026年創立100周年の言及。

## リード意義

- 種子屋街道再興のイベント系譜（2021.12さんぽ市→2022.3看板→2022.5種子地蔵→2022.11第1回縁日→2023.11第2回縁日→R6〜R8シンポ3回）の**年次を示す公式側の記録**。旧中山道の区間（地蔵通り〜庚申塚）に観光コンテンツが実装された事実は、街道の空間範囲の現代的再定義の観察資料。
- **本文に千川上水等の水系文言はない**。地名・交通史・まちおこし系のリードとして収録。
