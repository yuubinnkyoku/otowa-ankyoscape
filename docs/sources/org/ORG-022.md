# [ORG-022] 武蔵学園百年史 写真館「102 | 武蔵の門」の千川上水関連写真

- **書誌〔確認〕**：学校法人根津育英会武蔵学園公式サイト内「武蔵学園百年史」の写真館。ギャラリー「102 | 武蔵の門」に「1950年代の千川通り」「千川上水の看板」「1970年代の千川通り」の3点が収録されていることをギャラリー一覧で直接確認（2026-11-12）。個別写真頁のキャプション本文は本環境では抽出できず、検索スニペットで確認した内容を以下に記録する。
- **「千川上水の看板」（スニペット確認）**：「1969年撮影、練馬区教育委員会が正門前に設置した看板、千川上水の由来が記されている。現在ではこの場所から**200メートルほど池袋寄りに移設**されている」〔**区教委設置の千川上水由来看板の1969年設置と、現在地への移設距離・方向を示す記録としてrepo初出**。武蔵学園前の千川上水（昭和28年暗渠化・[BLOG-113](../blogs/BLOG-113.md)）に付随する案内設備の変遷資料〕。
- **「1950年代の千川通り」（スニペット確認）**：「1959年2月撮影、1号館から見下ろした正門と千川通り。現在と比べて車道の道幅はかなり狭く、**千川上水を埋め立てた向こう側半分は広い歩道になっている**」〔**昭和34年時点で千川上水の埋立て跡の歩道化が完了していたことを示す写真記録としてrepo初出**。同区間の暗渠化（昭和28年=1953年・[BLOG-113](../blogs/BLOG-113.md)）と武蔵学園百年史「1950年代末までに千川すべて暗渠」（[ORG-019](ORG-019.md)）の年次を絞る資料〕。
- **意義〔解釈・仮説〕**：武蔵学園前区間について①1953年（昭和28年）暗渠化、②1959年2月時点で埋立て跡が歩道として整備済み、③看板は1969年区教委設置→現在地へ移設、という**設置・整備の順序が百年史写真で初めて並んだ**。1953年vs1959〜60年暗渠化年次差（第22回ノートの課題）について、1959年写真が「埋め立てた」の過去形表現をとる点は1953年説を支持する方向の傍証になるが、キャプション文の解釈の幅を残し断定しない。

## 制限・未解決

- 個別写真の画像・キャプション全文の直接確認（写真頁はギャラリー一覧のみ抽出可）。「1970年代の千川通り」のキャプション内容。
