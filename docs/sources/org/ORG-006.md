# [ORG-006] 2024年10月6日の水窪川上流踏査・吹上稲荷神社前の写真

- お茶の水女子大学同窓会・桜蔭会千葉支部の[「2024年度 秋の文化活動報告」](https://www.ouinkai.org/wp-content/uploads/2025/03/2024%E7%A7%8B%E3%81%AE%E6%B4%BB%E5%8B%95%E3%81%A82025%E7%B7%8F%E4%BC%9A.pdf)（**行事開催2024年10月6日**、PDF公開先の年月表示は**2025年3月**、**PDF 1頁**）を本文・掲載写真で確認した。PDF内に刊行日そのものの明記は確認できない。
- 同報告は、午前に大学構内の**高所・北側崖下（体育館、テニスコート、グラウンド）**を歩き、午後に**水窪川の上流から暗渠となった川跡をたどった**と記す。〔確認：参加団体による2024年の踏査記録〕
- 掲載写真の右側は**「水窪川上流の吹上稲荷神社前で音羽の歴史について解説」**との説明が付く。写真には神社の鳥居付近に集まる参加者が写る。〔確認：掲載写真・説明文／観察：2024年10月6日の現地景観の記録〕
- **川の水面・旧河床・管渠断面・湧水が写っているわけではない**。「水窪川上流」は報告作成者の踏査経路上の呼称であり、写真の立ち位置が旧河道中心線上であることを証明しない。〔注意／未解決：古地図・地籍図との正確な位置合わせ〕
- 写真の転載は行わず、原PDFへリンクする。現在地の神社が**1912年に移転してきた**という区の説明は[GOV-029](../gov/GOV-029.md)に別記する。
