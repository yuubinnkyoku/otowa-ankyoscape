# [ORG-007] 2024年の谷端川3回踏査と映像記録の所在

- **主催者の活動記録〔確認〕**：NPO法人「としまの記憶」をつなぐ会「[団体について・あゆみ](https://toshima-kioku.jp/about/)」は、**2024年5～6月**に「暗渠編 谷端川3回シリーズ」を実施したと記す。事業の実施年月であって谷端川の改修・暗渠化年代ではない。
- **動画アーカイブの案内〔確認：公開ページ本文・書誌的表示／映像の各場面は未判読〕**：「[記憶の遺産ツアー：消えたとしまの川を訪ねる：谷端川編：上映会のお知らせ！](https://movie.toshima-kioku.jp/archives/yabatagawa-pr/)」は、**伊藤一雄氏の案内で全行程を3回に分けて踏査**したと説明し、**2024年撮影、長島光男氏が撮影・編集**と表示する。**11月10日の上映会**を告知するが、告知本文は年を省略しているため、同ページ単独では開催年・上映結果を確定しない。
- **説明内容〔二次概説〕**：同ページは、粟島神社弁天池を水源、東京ドーム周辺を経て神田川へ至る**延長約11km**の川とし、U字状の蛇行を特徴と説明する。延長値は主催者による概説で、独立測量の値ではない。既収録の[GOV-007](../gov/GOV-007.md)にも約11km・弁天池の記述があるため**新しい独立の河川計測値として扱わない**。
- **史料価値〔推定〕**：2024年の地上景観・旧橋跡・緑道の状態や案内者の説明を動画から時点付きで検証できる可能性がある。ただし**動画全編の内容・各回の経路・旧橋の位置は未確認**。公開ページの存在のみをもって新たな河道・橋の実在を立証しない。
