# [ORG-013] 新宿歴史博物館「江戸の水道 玉川上水」展と小川家文書千川上水絵図

- **二次転記（2026-11-11）**：新宿歴史博物館の令和6年度特別展「江戸の水道 玉川上水」（2024年10月5日～12月1日）の出品資料リストPDF（図録関連資料一覧）が検索結果の抄録で確認できる。同リストの資料20として **「(千川上水絵図) 前欠・小川家文書・年未詳・小平市立中央図書館」**、資料21として「乍恐書付を以御訴訟申上ヶ候御事(玉川上水より神田上水へ分け堀御用に立不申候に付)(後欠)」（玉川上水・神田上水関係）が挙がる。PDF自体は本実行環境からは開けなかった（自動アクセス遮断、Waybackにも未収録）。
- **別途確認（プレスリリース）**：同展では**江戸上水配水図（千川家文書・練馬区指定文化財、享保2～3年〔1717～1718〕頃、練馬区立石神井公園ふるさと文化館蔵）**も展示されたことが新宿未来創造財団の[プレスリリース](https://prtimes.jp/main/html/rd/p/000000006.000146578.html)の抄録で確認できる（千川家文書の配水図自体は既収録の[GOV-038](../gov/GOV-038.md)系と同一文書群と思われるが、**本展での展示という所在情報は新規**）。
- **意義〔観察〕**：**小平市立中央図書館蔵・小川家文書「(千川上水絵図) 前欠」という一次史料候補の実在が2024年の博物館展示の資料リストで確認できた**。「前欠」＝巻頭を欠く状態とみられる。千川上水を描く絵図の新規な所在情報として、[MAP-119](../maps/MAP-119.md)（千川分水口取調絵図）等の既収録絵図群に加えられる可能性がある。
- **制限〔未解決〕**：絵図の年代（年未詳）・内容・描かれた区間は一切未確認。**本資料で千川上水や谷端川分水の流路・年代を主張しない**。図録（1,000円・同館販売）の入手、小平市立中央図書館での原本確認を次回以降の実見候補とする。
