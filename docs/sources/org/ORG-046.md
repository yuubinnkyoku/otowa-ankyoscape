# [ORG-046] 大正大学プレスリリース（2022-03-31）— 種子屋街道紹介看板5枚設置の大学側原本

## 要点〔確認: プレス本文〕

- 大正大学は「本学の位置する巣鴨の地がかつて種子屋街道として繁栄した歴史や文化を蘇らせる取り組みの一環として、**本学南門広場を中心に種子屋街道の歴史を紹介する看板（監修：本学准教授 松本洋幸）を5枚設置**」（リリース日＝2022-03-31）。＝[BLOG-315](../blogs/BLOG-315.md)の参加記の「種子屋街道説明案内板の設置2022年3月」文言の**大学側原本**〔大竹記事の「松本洋幸教授」との称号の表記差は転記の揺れとして記録〕。
- 歴史説明文言: 「江戸時代から戦前までの間、**旧中山道を巣鴨から北上した所から滝野川三軒家（現：北区滝野川六丁目）の間が「種子屋通り」と呼ばれるほどたくさんの種苗問屋や販売店が立ち並ぶ街**だった歴史」＋「滝野川ゴボウ」「滝野川ニンジン」など地域の名を冠した伝統野菜の品種〔確認: リリース文言＝[GOV-583](../gov/GOV-583.md)・[BLOG-313](../blogs/BLOG-313.md)の街道範囲文言と整合〕。
- **活用事業名（いずれもrepo初出）**: ①観光庁「**地域の観光資源の磨き上げを通じた域内連携促進に向けた実証事業**」②（公社）農林水産・食品産業技術振興協会「**種苗資源の保護に係る取組み支援事業**」。学内の基盤＝社会・地域貢献科目「**サービスラーニングⅡ-D**」の活動〔確認: リリース文言〕。目標＝「種子屋街道としての巣鴨」の歴史・文化の認知復活、伝統野菜を通した交流・教育・観光資源化。
