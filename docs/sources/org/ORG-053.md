# [ORG-053] 東洋文庫ワークショップ「見て！歩いて！古地図を楽しもう～再興された千川上水～」（2025-11-29）

## 書誌・確認範囲〔確認〕

- 公益財団法人東洋文庫のミュージアムワークショップのイベントページ。2025年11月29日（土）10:00〜16:00開催・参加費2900円（昼食込み）・定員20人（中学生以上）・入金締切11月26日。2026-11-28（第390回）に取得。直アクセスは本環境から不通のため**Waybackスナップショット**（2026-04-17取得分）で本文全文を確認。repo grepで当該イベント・中村佳史・HUMIは0件＝repo初出。
- https://toyo-bunko.or.jp/event/2351/

## 内容〔確認〕

- **講師・企画構成〔確認・repo初出〕**: 講師は**中村佳史氏（株式会社HUMIコンサルティング）**。第一部（座学・東洋文庫内）で古地図の読み方・楽しみ方と**岩崎久彌や岩崎家4代**について学び、第二部で**古地図を片手に東洋文庫から台東区池之端まで約5km縦断、最後に旧岩崎邸を見学**（解散は旧岩崎邸庭園）。
- **「再興された千川上水」の題号〔確認・repo初出文言〕**: イベントの公式題号が「見て！歩いて！古地図を楽しもう**～再興された千川上水～**」＝千川上水を「再興された」水路と銘打った公的財団のイベント名。
- **ルートと千川上水跡の重複説〔確認・本文文言〕**: 「このワークショップでは、東洋文庫所蔵の古地図を片手に、東洋文庫ミュージアムから久彌の本邸である「旧岩崎邸庭園」までを歩きます。**このルートは、久彌の父・岩崎彌太郎が会社をつくって再興した「千川上水」の跡とも重なります**」〔千川上水の流路（文京区小石川方面）と神田川沿いの池之端までの縦断ルートが千川上水跡に重なるという企画側の流路観。原文ママ。千川上水の江戸市中末端部と神田川合流以遠の取り扱いは本文では区切られないため断定せず〕。
- 東洋文庫は1924年（大正13年）に**三菱3代目社長の岩崎久彌**が創設した研究図書館であることの明記〔千川水道会社（明治13年設立）を起こした岩崎彌太郎と、千川上水跡地に近い岩崎久彌施設（東洋文庫・旧岩崎邸庭園）の家系接続が、千川上水の評価史レーンの2025年の定点資料になる〕。

## 四河川への使い方

- **千川上水の岩崎再興説（千川水道会社・明治13年〔[GOV-077](../gov/GOV-077.md)・[PAP-023](../papers/PAP-023.md)〕）が2025年時点で「再興された千川上水」として一般向け文化イベントの題号に使われている受容の定点**。歴史解説イベントの企画文言ではあるが、公的財団の公式ページである。
- 東洋文庫（岩崎久彌創設）〜旧岩崎邸庭園（台東区池之端）〜千川上水跡を1つの文化ルートとして提示した初出例。千川上水跡の散策受容（[GOV-075](../gov/GOV-075.md)清流の復活・[BLOG-121](../blogs/BLOG-121.md)など）の系列に、古地図歩きの企画側事例を追加。

## 制限・未解決

- ルートの具体的な経路（千川上水跡のどの区間を辿るか）の記載はなく、5km前後の概略のみ。
- ワークショップで使用された東洋文庫所蔵の古地図の特定資料名は未記載。
- 旧番号対応表の該当なし（新規採番）。
