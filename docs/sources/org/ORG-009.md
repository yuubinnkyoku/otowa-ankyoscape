# [ORG-009] 巣鴨遺跡の石器・陥し穴と埋没枝谷の分布

- **資料〔確認〕**：NPO法人としま遺跡調査会「[豊島区No.6遺跡『巣鴨遺跡』～石器と獲物と巣鴨の谷 原始・古代編～](https://wp.toshima-iseki.org/wp/iseki-list06/)」。公開ページに記事の発行・更新日を確認できないため**掲載年不詳、2026年11月3日閲覧**とする。記事の「縄文時代草創期～早期（1万2千～6千年前）」は**遺構の時代区分**であって記事の刊行年ではない。
- **出土資料〔確認：調査団体による発掘成果の紹介／原報告書未照合〕**：巣鴨四丁目の関東ローム層から**黒曜石製ナイフ形石器**が出土したと記す。都立大塚ろう学校の建替えに伴う発掘では、**縄文時代草創期～早期の陥し穴**、縄文時代後期の土器、黒曜石製の矢じり等が確認されたと説明する。本文には黒曜石製ナイフ形石器と陥し穴の写真もある。
- **谷地形との関係〔観察：調査団体による出土地点の分布整理〕**：出土地点を地図上に示すと**現在は埋もれた谷の周囲に集中**し、巣鴨は**谷田川と谷端川に挟まれ、枝状の谷が複数延びていた**と説明する。「狩り場」だったという解釈は記事執筆者の考察であり、発掘遺構だけから一意に決まる用途ではない。
- **調査上の価値〔推定〕**：谷端川の中・下流域の支谷・埋没谷を、遺構分布・色別標高図・旧地形図で比較するための考古学的な手掛かりになる。水路の直接証拠というより、**河川沿いの谷地形と人間活動の位置関係**を調べる資料として扱う。
- **制約〔未解決〕**：公開記事には遺物・陥し穴の**地点別座標、遺構平面図、谷底の堆積層序、埋没時期、谷の縦断勾配**が示されていない。石器・陥し穴の分布は**旧河床の位置・水流方向・谷田川との水路接続を直接証明しない**。現在の谷端川暗渠の線形や、更新世の旧河道流向に遡及しない。原発掘報告書の調査区図と地形断面の照合が必要。
