# [ORG-024] 武蔵学園百年史写真館の濯川ギャラリー（062・104）

- **資料〔確認：公開頁本文〕**：根津育英会武蔵学園「武蔵学園百年史」写真館。**ギャラリー062「武蔵学園の象徴・濯川」**（写真17枚：1920年代の濯川・生徒による濯川の工事・濯川と集会所・1968年の濯川・1979年の濯川・濯川のみなもと・濯川の中流部など）と**ギャラリー104「濯川蘇生工事」**（[テーマ頁](https://100nenshi.musashi.jp/Gallery/Theme/2afa8310-037c-4bd5-ad85-54eed5191509)・写真約30枚）。〔確認：頁本文・キャプション〕
- **1920年代の濯川〔確認：キャプション〕**：PK024-014m「欅橋より上流側の濯川。現在の総合図書館南側付近…写真奥に位置するはずの集会所・体育館が見えないことから**1925年ごろの撮影と推測**される（サイト側推定）。川岸は未整備だが**写真右手前に板材を積んであることから工事を始める直前**と思われる」。＝1925年の山本良吉命名（[ORG-019]）と整合する年代の写真が存在指定されている。
- **蘇生工事の工程写真〔確認：キャプション群〕**：ギャラリー104は1957年の濯川（NS015-006）・1970年代の環境悪化（PS071-003）・空堀（PS075-010）・改修工事のテスト（NS037-003）・改修工事の開始（PS075-033/034）・玉の橋付近の河床工事（PS076-010）・河床の防水・護岸の石積み・遊歩道の整備・飛び石・**ワンドの造成**（PS077-013）・通水式（PS077-001/005）・八角井戸（PS078-024）・アヒルの新しい庭・野生のカモの飛来と続き、**1974年の千川遮断から1985-86年の通水・竣工（[ORG-019]）に至る工事の全工程を写真で追える構成**。
- **新規性〔解釈〕**：[ORG-019]（「語り継ごう濯川」本文）に記載のなかった**年次を打たれた写真（1957・1968・1979）の存在と、空堀・ワンド造成・玉の橋の写真記録**を確認。「**ワンド**」の造成はrepo初出文言。写真番号の接頭辞（PK/NS/PS＋年度）は撮影年推定の手がかりになる（PS075=昭和50年代前半の通水式関係と整合する配置）。
- **〔2026-11-12 第41回追記・確認〕「濯川のみなもと」個別頁キャプション全文**: 個別写真頁（[DS20200928-014m](https://100nenshi.musashi.jp/Gallery/Photo/ff8a9f34-6785-4980-90c2-2586eccf8526)・2020年代撮影）のキャプションを直接確認。「**かつて千川上水の分水であった濯川は現在、切り離されて独立した水系となっており、下流の校地東端に達した水を濯過してポンプで上流に循環させている。湧出場所は講堂南側・大学十号館西側であり、正田建次郎学長の石碑が傍にある**」〔**湧出（放水）場所の所在地レベルの特定＝repo初出**。濯川の復元水路における水の出所が講堂南側・大学十号館西側であることと、正田建次郎（数学者・武蔵大学学長）の石碑が傍にあることを記す〕。同ギャラリーの「欅橋からみた濯川と校舎」〔[34efb177](https://100nenshi.musashi.jp/Gallery/Photo/34efb177-aa0f-411f-8081-fabd13414b83)〕のキャプション「濯川に架かる**欅橋（現在の総合図書館南側）**から撮影…手前から平屋の金工木工室・二階建ての化学教室・三階建ての校舎本館（現在の大学三号館）」も検索スニペットで確認〔欅橋の位置の別表現。PK024-014mの「総合図書館南側付近」と整合〕。
- **未確認〔注意〕**：各写真の撮影年はキャプション明示分のみ。「濯川の中流部」「正田建次郎学長の石碑」等の残る個別頁キャプションは未取得。
