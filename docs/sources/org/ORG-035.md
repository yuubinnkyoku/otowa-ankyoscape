# [ORG-035] 豊島区「雑司ヶ谷鬼子母神堂」頁 — 雑司ヶ谷鬼子母神堂の建物史の公式文言〔第148回〕

- **文言〔確認・2026-11-17取得〕**: 豊島区公式HP「雑司ヶ谷鬼子母神堂」（ページID34371・更新日2024年3月11日）——「**『新編武蔵風土記稿』（文化・文政期〈1804～1829〉に編纂された武蔵国の地誌）などによれば、雑司ヶ谷鬼子母神堂に祀られている鬼子母神尊像は永禄4年（1561年）に清土（現・清土鬼子母神堂）で掘り出され、はじめは法明寺の塔頭東陽坊（後に大行院）に納められていましたが、天正6年（1578）に雑司ヶ谷村の人びとによりお堂が建てられると、こちらに安置されました。現在の雑司ヶ谷鬼子母神堂は寛文4年（1664）に第二代広島藩主浅野光晟の正室・自昌院の寄進によって本殿が建立され、元禄13年（1700）に相の間と拝殿が増築されたものです**」「**雑司ヶ谷鬼子母神堂は、平成28年（2016）7月25日、国の重要文化財（有形文化財（建造物））に指定されました**」＝**①尊像の系譜（永禄4年清土掘出→法明寺塔頭東陽坊〔後の大行院〕→天正6年雑司ヶ谷村の堂）、②現本殿＝寛文4年建立（浅野光晟正室・自昌院寄進）・元禄13年相の間拝殿増築の現存建物、③2016年7月25日の国指定**を豊島区の公式見解として記す。([豊島区・雑司ヶ谷鬼子母神堂](https://www.city.toshima.lg.jp/132/miryoku/shiru/jinja/kishimojin.html))
- **GAZ-071（本所寺社書上六・本仏寺条）の帰属訂正の裏付け〔確認・第148回〕**: [GAZ-071](../gazetteers/GAZ-071.md)（文政11年の寺社御調書上・NDL lab 2571450）の「天明四甲辰年正月廿一日夜類焼→寛政三辛亥年四月再建立」の鬼子母神堂文言は、冊子の帰属（本所寺社書上六＝本所出村の本仏寺・去恩寺・本法寺〔法恩寺〕・永隆寺・霊山寺の御調書上）から**本所本仏寺境内の鬼子母神堂（子授鬼子母神・像高二寸余）の記録**と特定した。本頁の建物史（寛文4年建立・元禄13年増築の現存建物＝天明4年・寛政3年の焼失再建の過程なし）は**この帰属特定と整合し、天明4焼失・寛政3再建を雑司ヶ谷鬼子母神堂の建物史に当てはめた第147回の記録が誤りであったことを裏付ける**。〔第147回がGAZ-071について「鬼子母神堂（雑司ヶ谷）の建物史の年代定点 repo初出」とした記録は取り下げる。天明4年正月21日夜の類焼は本所本仏寺（本堂・境内鬼子母神堂）と同冊内の永隆寺（「天明四辰年正月廿一日本堂鎮守堂庫裏門前伝家共不残類焼」）にも見え、本所側の火災（本所出村一帯の類焼か）の記録である。〕
- **延宝5年（1677）時点の実在との整合〔確認・観察〕**: [GAZ-071](../gazetteers/GAZ-071.md)の略縁起中の「**雑司谷鬼子母神へ日参**」（延宝5年4月8日起算の水垢離と参詣の対象）は、寛文4年建立の本殿が1677年に実在し子授祈願の参詣対象だったことと整合する。〔GAZ-071の縁起（小網町三又川出現の神体を本所本仏寺に安置）と雑司ヶ谷鬼子母神本体の起源譚（永禄4年清土掘出）は別神像の由来譚であり、対立しない=対照表の清土行の第147回追記の「対立構造」は解消済み。〕

## 制限・未解決

- ①区HPは解説ページであって一次史料ではなく、各年代（永禄4・天正6・寛文4・元禄13）の根拠原文（風土記稿・文化財指定書・『雑司ヶ谷鬼子母神』等）の直接確認は別途必要（本頁を根拠に「断定」としては扱わない）。②「東陽坊（後に大行院）」の別当の変遷の時期（何年に大行院になったか）は本頁からは特定できない。③自昌院寄進の初出史料（風土記稿か寺伝か）は本頁では示されない。④本頁の尊像系譜は風土記稿系の通説（[BOOK-144](../books/BOOK-144.md)・[GAZ-049](../gazetteers/GAZ-049.md)系）の区版採用であり、掘出地・年代の異説（[BOOK-159](../books/BOOK-159.md)清土条の文言等）の整理は従来の対校課題のまま。
