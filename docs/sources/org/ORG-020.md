# [ORG-020] 武蔵高等学校中学校 校長散歩058「武蔵を流れる濯川（すすぎがわ）」

- **書誌〔確認〕**：武蔵高等学校中学校公式サイト「校長散歩」第58回（2019年9月22日公開）。2026-11-12にopen_urlで本文全文を取得〔[ORG-018](ORG-018.md)（校長散歩200）の未解決「校長散歩58も未確認」を解消〕。
- **中新井分水〔確認：本文〕**：濯川は「**もともとは江戸時代に作られた千川上水中新井分水の流れ**」と説明〔①濯川の水源流路を**中新井分水**という分水名で特定する学校側の文言＝**repo初出の分水名**。武蔵学園の所在地は旧豊島郡中新井村（現練馬区豊玉北・中新井）で、[ORG-018](ORG-018.md)・[ORG-019](ORG-019.md)の「千川分水」がどの分水かを名前レベルで具体化する。②ただし本頁では中新井分水の分水口の位置・開設年は示されず、「中新井」の字名由来の用水名として記録し、[GOV-068](../gov/GOV-068.md)（関村分水・中村分水等）・[BLOG-094](../blogs/BLOG-094.md)（井草村分水6か村組合）など千川上水の分水系譜との対応は未確認〔断定しない〕〕。
- **既知事実の再確認〔確認：本文〕**：濯川の名称は1925年に山本良吉教頭（のち校長）が命名〔[ORG-019](ORG-019.md)と一致〕。千川上水は農業用水としての役割を終え下水道として暗渠化、濯川は千川とのつながりを失い一時流れが途絶えたが、**1983年から学園60周年記念事業として蘇生作業**が行われ現在は校内で循環〔[ORG-018](ORG-018.md)・[ORG-019](ORG-019.md)と一致。加算しない〕。
- **制限〔未解決〕**：中新井分水の分水口の位置・分水開始年（江戸期か近代か）。[ORG-019](ORG-019.md)の1959〜60年暗渠化・1974年遮断との前後関係。

## 三河川への使い方

- 千川上水の分水網（谷端川〔[GOV-068](../gov/GOV-068.md)で分水接続の設計思想を指摘〕・中丸川〔[BLOG-081](../blogs/BLOG-081.md)・[BLOG-105](../blogs/BLOG-105.md)〕・濯川）に「中新井分水」の名を加える候補。濯川が千川上水の支流系水路であることの学校側公式説明の第2確認源。
