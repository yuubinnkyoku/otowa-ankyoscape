# [ORG-021] 雑司が谷公園「丘の上テラス」と弦巻川の河岸段丘

- **書誌〔確認〕**：雑司が谷公園（豊島区雑司が谷、旧高田小学校跡地の公園）の施設紹介ページ（zoshigaya.org）。**サイトの運営主体（指定管理者等）はページ上で特定できず未確認**〔2026-11-12、本文直接取得〕。
- **弦巻川と段丘地形〔確認：本文〕**：「**高田小学校の敷地は近くを流れていた弦巻川の河岸段丘の上にあり、敷地の北側は2mほどの擁壁となっていました。この段差を利用し、さらに盛り土によって高さを確保して、丘の上テラスは建てられています。**（地下1階・地上1階だが北側からは2階建てに見える）」〔観察：**弦巻川の谷地形（約2mの段丘崖）が2020年代の施設建築設計に反映されている現況記録**。弦巻川旧流路北縁＝崖線位置の間接的な裏付け候補。段丘面の帰属（弦巻川形成か、より高位の面の流用か）は断定しない〕。
- **整備工事の地形改変〔確認：本文〕**：公園整備で発生したコンクリートガラの3分の1を再生砕石化して路盤・盛り土に利用し、**敷地（ボールひろば中心）を約90cm盛り上げた**旨も記す〔観察：旧谷地形の現況が改変を受けている記録〕。
- **注意**：施設由来の解説ページであり、地形面の学術的記載ではない。弦巻川の河道位置と擁壁の正確な対応は地形図・空中写真（[MAP-126](../maps/MAP-126.md)等）との照合が次の一手。
- **未解決**：運営主体の特定、丘の上テラス建設年。
