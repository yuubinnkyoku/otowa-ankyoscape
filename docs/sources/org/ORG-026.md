# [ORG-026] 武蔵学園百年史「オンライン博物館」濯川の頁

- **直接確認（2026-11-12、open_url・本文全文）**: 武蔵学園百年史サイトのオンライン博物館「濯川」頁（構内看板の解説頁）。濯川を「江古田校地をほぼ二分して東西に流れる小川」「千川上水の分水で、学校創立以前から敷地内を流れ、農業用水として利用されていた」と定義。
- **命名〔確認: 既知内容の裏付け〕**: 1925年・校地南側運動場整備完了時に山本良吉教頭が命名、由来は屈原「漁父辞」（滄浪の水…纓・足を濯ぐ）＝[ORG-018](ORG-018.md)・[ORG-019](ORG-019.md)と一致。
- **蘇生計画の具体的内容〔確認: repo初出の細部〕**: 1980年代・学園創立60周年記念事業として**太田博太郎学園長・大坪秀二校長**による濯川蘇生計画が企図され、後援会・同窓会からの寄附で**河床・護岸の改良、井戸および還流水を供給するポンプを設置**して清流が蘇った、と記載〔蘇生=ポンプ式である点はORG-018と一致。**井戸＋還流水の併用、実施主体の学園長・校長名、60周年記念事業である点はrepo初出の細部**〕。
- **千川上水暗渠化の年次文言〔確認〕**: 「**1960年代に千川上水が暗渠となると**濯川へ分かれる水量も減少し、濯川周辺の環境は悪化した」〔ORG-019の「1950年代末までに千川すべて暗渠」・BLOG-113の1953年着手説・武蔵学園前1953年暗渠（BLOG-113）に対し、本頁は1960年代表記。既存の年次対立に第三の表記が加わった。断定せず並記〕。
- **欅橋〔確認〕**: オンライン博物館の看板設置マップに「**欅橋と北極標**」（№11）、「濯川と自然観察」（№9）の項目があり、欅橋が濯川の橋として現地看板レベルで案内されている〔欅橋の橋名自体はORG-019/024既出。橋跡・現況の観察記録は次回以降〕。
- **注意**: 当頁は構内看板の解説文とみられ、ORG-018〜020・百年史「語り継ごう濯川」と内容的に同一系統のSSOT。年代・水量の文言は看板表記であり、行政史料との照合は従来どおり未解決。
