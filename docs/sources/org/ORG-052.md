## 内容メモ

- **〔確認・repo初出〕シールドマシン発進式の実施と施工者**: 大豊建設東京土木支店が、東京都下水道局発注の雨水幹線「千川増強幹線工事」の**安全祈願祭とシールドマシン発進式を現地で開催（関係者約30人・下水道局から7人参加）**。**発進スイッチは東京都下水道局第一基幹施設再構築事務所工事第二課の毛利光夫課長と竹内清常務執行役員支店長が押下**〔発進式の実施・式次第・氏名・役職名ともrepo grep新出〕。作業所長＝生形浩之（大豊建設）。
- **〔確認〕幹線規格・工事期間・場所（GOV-082と整合）**: **仕上がり内径3750mm・延長2525m**・**工期は2021年3月まで**・**工事場所は豊島区上池袋1・文京区千石2ほか**。**既存の下水道管と今回構築する新設幹線で1時間当たり75mmの大雨に対応**＝[GOV-082](../gov/GOV-082.md)（75ミリ対策地区・内径3.75mシールド・上池袋東公園→窪町東公園2.5km）と規格・目的が完全に整合し、2019年時点の施工開始段階の記録として裏付けを追加。
- **〔確認・repo初出〕発注者側の浸水文脈の説明**: 毛利課長の挨拶として「**（既設の）千川幹線沿いは、起伏がなく地盤が低い地域のため、浸水被害が起きやすい。13年には大塚付近で浸水被害が多発した**」＝千川幹線沿いの地形（起伏なく地盤が低い）と2013年（平成25年）大塚浸水を幹線事業の動機として発注者が公の場で説明した発言記録〔2013年南大塚床上浸水131件（BLOG-134）の当局側言及として対応〕。
- **〔確認・repo初出〕施工実務の特色**: ①シールドトンネル内に**5%の急勾配区間**ができるため、資機材運搬車両に通常の鉄製車輪ではなく**高摩擦車輪**を使用、坂の上と下に緊急制御装置を導入（生形所長の話）。②水道管が近接するなど慎重な施工が必要（竹内支店長）。③ダンプカー等にGPSを搭載し中央監視室モニターと連携した運行管理で近隣影響を低減。④現場見学会の開催意向。
- **〔言及〕支店の現場位置づけ**: 竹内支店長が「支店としてこの現場を最重要現場と捉えている」と強調。

## 四河川への使い方

- **千川幹線（旧千川上水筋の下水道幹線）の再構築事業の施工側一次記録**として、GOV-082（着工・規格・事業費）・BLOG-134/289（枝線接続・2024年接続完了・令和9年まで枝線継続）に「**2019年の発進式・施工者・発注者説明**」の年次と主体を加え、**H29着工→2019発進式→2021工期→2024.8.21接続完了→R9枝線完了の工程列がrepo内で揃った**。
- 千川幹線沿いの地形説明（起伏なく地盤が低い）は、谷端川・千川流域の浸水危険性の地形的原因（[BLOG-115](../blogs/BLOG-115.md)の50mm/h設計基準・[BLOG-107](BLOG-107.md)谷積み石垣等の地形状況記録）の行政側文言として追加。
