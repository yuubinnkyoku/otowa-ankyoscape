# [ORG-049] JA東京中央会「東京農業歴史めぐり」— タネ屋街道の由来語りと店舗数の数値文言

## 要点〔確認: 本文〕

- ＪＡ東京中央会の「東京農業歴史めぐり」シリーズの一頁。**旅行者が街道沿いの農家で見慣れない野菜の種子を買っていった→農家の副業として種子販売→種子専門店化、という街道成立の由来語り**。
- **「明治の中期には巣鴨のとげぬき地蔵から板橋区清水町にいたる約6キロの間にタネ屋問屋が9戸、小売店が20戸も立ち並ぶ、タネ屋街道になっていました」**〔確認: 本文〕＝**明治中期の種苗店家数（問屋9・小売20）・区間（約6km）の数値文言**（[BLOG-317](../blogs/BLOG-317.md)のいけぶくろねっと告知も同文言を引用）。
- **「寛永20年（1643）の代官所に申告した書き付けに、長野県諏訪の種の行商人が榎本種苗店（豊島区西巣鴨）に仕入れにきた模様が記されています。馬12〜3頭を曳いて種子を仕入れ、帰り道「萬種物」の旗を立て街道筋の種子問屋に卸していったり、農家に販売して歩くなど、さながら富山の薬売りと同じように種子も行商により商われていました」**〔確認: 本文・文言どおり〕＝**寛永20年（1643）の代官所申告書き付けを由来とする由緒文言**〔観察: **「1643年」と「榎本種苗店（西巣鴨）」の店名の併記は時代考証的に疑わしい**。東京種苗の創業は弘化元年（1844・[BLOG-313](../blogs/BLOG-313.md)⑯）とされ、1643年当時の西巣鴨に同店名が存在したとは考えにくい。原文（代官所書き付け）の実物は未確認であり、**本文の文言どおり観察記録として保存し、史実としては採用しない**。江戸期の種子行商（諏訪産種子・行商旗）の存在自体は別史料での対校候補〕。
- 付記＝真性寺（豊島区巣鴨3-21-21・JR巣鴨駅とげぬき地蔵通り／江戸六地蔵尊）〔確認: 本文＝種苗屋街道の碑の所在地（[BLOG-313](../blogs/BLOG-313.md)）と同寺〕。

## 制限・注意
