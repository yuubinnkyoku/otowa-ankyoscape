# [ORG-029] 氷川神社裏貝塚（池袋本町三丁目）と谷端川上流域の縄文環境

- **資料〔確認〕**：NPO法人としま遺跡調査会（ORG-009と同一団体）の遺跡紹介頁。公開頁に発行・更新日を確認できないため**掲載年不詳、2026年11月12日閲覧**とする。
- **内容〔確認〕**：氷川神社裏貝塚（池袋本町三丁目）は大正年間に地元稲垣喜平・義松親子が縄文土器を採集した遺跡で、**シジミが特に多く、主淡貝塚＝川や沼に棲む貝が中心**と説明（依拠表示：豊島区1981『豊島区史』通史編1）。ハマグリ・アサリなど河口付近の貝もみられ、縄文人の行動範囲の広さが指摘される。明治期に**白井光太郎が土偶を発見**（1886「貝塚より出でし土偶の考」『人類学会報告』2）し、かつては「**池袋村貝塚**」と呼ばれた東京の著名遺跡。貝層の正確な位置は現在不明だが、近年の発掘でも**縄文時代中期〜晩期（約4000〜3000年前）**の土器・石器が発見され続ける。
- **repoへの関連〔推定〕**：池袋村（谷端川上流・雲雀ヶ谷戸周辺の村域）に淡水貝主体の縄文貝塚が存在した事実は、**谷端川谷頭付近の湧水・低湿地環境が縄文期にまで遡る傍証**として扱える（BLOG-125「山手線完成前は谷は山手線内側から続いた」聴取・PAP-018の谷頭湧水と並ぶ古環境資料）。ただし本頁は水路そのものを記録しない。
- **制限〔未解決〕**：貝層の位置・範囲は不明と明記される。湧水・低地との位置関係の記述はなく、谷端川との距離は本頁からは確定しない。『豊島区史』通史編1の該当頁原本確認と、池袋東貝塚（同3丁目・2017年調査）との位置関係整理が今後課題。
