# [ORG-014] 千川上水まち歩き北区編（JIA関東城北地域会）

- **資料〔確認〕**：日本建築家協会関東甲信越支部（JIA関東）城北地域会の見学会報告PDF（2017年6月10日実施、1頁）。板橋駅東口から王子駅東口まで、旧千川上水（用水）の経路に沿って歩いた行程メモ。
- **行程と観察〔観察：参加者のメモ〕**：埼京線線路際（板橋区境）から千川上水の経路に沿って出発→**右手に谷端小学校を眺めながら旧谷端川の谷筋も感じながら歩く**→**道中、上水を暗渠にした時のマンホールがいくつか残存（「80年もの」）**→明治通りに近づくと千川上水蓋（各種）→**千川上水分配堰の石碑（「このあたりが堀割という地名」）**→明治通りを渡ると豊島区千川上水公園・溜池、**これより江戸へ木樋等で上水を供給**→直角に曲がり王子分水（**幕末期反射炉を計画、大砲芯を削る水車・水力用水**）→大正大学（元宗教学校）→白山通り・明治通り・天理教教会前→**桜丘学園前から大規模な歩道橋を渡り、レンガ造の醸造試験所へ（ここが幕府の反射炉計画地、この大砲製造のために開削した用水路）**→石神井川・逆川・千川上水の水道橋の遺構→正受院（不動の瀧）→音無親水公園。
- **repoへの関連〔確認・推定〕**：①分配堰石碑と堀割の地名の関係は[BLOG-053](../blogs/BLOG-053.md)（1865年反射炉王子分水が「堀割」の由来）と整合する。②**板橋駅東口から王子まで千川用水の通し経路（谷端小学校・旧谷端川谷筋との並走区間を含む）を歩行確認した記録**は、[BLOG-043](../blogs/BLOG-043.md)・[BLOG-070](../blogs/BLOG-070.md)等の断片的な記録をつなぐ補助資料になる。③**木樋による江戸への供給**という叙述、④暗渠化当時のマンホールの残存観察、⑤醸造試験所＝反射炉計画地の比定は、repo初出レベルの細部〔見学会メモ由来のため、典拠の記載はなく要裏付け〕。
- **制限〔未解決〕**：見学会メモという性格上、各記述の史料的裏付けが薄い。分配堰石碑の設置年・碑名の特定、木樋供給の典拠、水道橋の遺構の位置は未確認。
