# [ORG-036] 「善福寺川流域の自然と暮らしを守る会」〔repo初出〕

- **書誌〔確認: サイト本文・2026-11-21取得〕**: [zenpukujigawa.com](https://zenpukujigawa.com/)（「緊急のお知らせ」を掲げる活動サイト・最終更新は2026年8月11日と観測〔サイト上部に「私たちの川、私たちの未来を守るために」のコピー〕）。善福寺川上流地下調節池計画への反対・見直しを求める**流域住民団体の一次サイト**〔JBpressまさのあつこ記事（[GOV-149](../gov/GOV-149.md)第240回追記）で言及される住民メーリングリスト・森川明夫技術士の主張と接続する住民側の組織的表明資料。団体の法的形態・設立年は本文未記載〕。
- **計画の住民側記載〔確認: サイト文言〕**: 東京都の計画は「**善福寺川緑地（ロケット公園～センター広場）、関根文化公園、原寺分橋付近住宅地の3か所に立坑を掘り、地下トンネルとしてつなげて調節池とする、費用1,557億円の巨大工事**」・「**公式発表の工期は17年だが、実際は完成まで20～30年かかることが見込まれ**」・「**自然と生活環境を破壊する工事内容から見直しを訴える署名が18,000筆超**集まっている」〔立坑3か所の位置のうち**第3立坑を「原寺分橋付近住宅地」と書くのは本サイトの特徴的な文言**＝都のFAQ（[GOV-485](../gov/GOV-485.md)「原寺分橋下流右岸部」）と位置が対応。ロケット公園通称は都側資料とも一致〕。**直径約9m・全長約5.8kmのシールド工法による巨大地下トンネル**。
- **経緯の住民側記載〔確認〕**: 「**杉並区の地下に…巨大地下トンネルの建設が2023年8月に突然発表され**た」「周辺住民への丁寧な説明もないまま密かに進められていた計画は、住民の意見を半ば無視するようなかたちで強引に進められ、**2025年1月22日には都市計画事業認可が告示され**た」〔2023年8月発表・2025年1月22日認可告示という日程の住民側表明。都側資料（GOV-485）では令和5年8月下旬素案説明会・令和7年1月認可取得〕。
- **問題提起の骨子〔確認: サイト文言・いずれも住民側の主張として〕**: ①**50軒以上の住宅立退きや区分地上権設定**が必要で、用地取得には10～20年が予想され、工期17年と合わせると**30年は水害対策機能を発揮できない**。②善福寺川の水害は**短時間の豪雨が下水に流入しマンホールから汚水があふれる内水氾濫がほとんど**で、あふれ出た水量を地域ごとに調査することが最も早く有効なのに、**都は水害ポイントの調査を一切していない**。浸透舗装道路・浸透ますの大規模整備など**代替策はあるが複数案の検討をしていない**。③**氾濫の大きな要因は武蔵野市からの汚水流入**だが都は武蔵野市の対策を何も考えていない。④**シールドマシンは全ての用地取得が終わらなければ1ミリも動けない**ので、取得完了前に立坑を掘ると**公園が工事現場のまま数十年放置される**恐れがあり、「**用地取得が完了するまで工事を開始しないこと**」を要望。
- **川の自然の記載〔確認: サイト文言〕**: 善福寺川緑地では**カルガモ・ヒヨドリ・カワセミ・オオタカ**などの野鳥観察ができ、川には**モツゴ・タモロコ・ニゴイ・ドジョウやナマズなど在来の魚類が多数生息**〔2026年時点の住民側の生態観察文言。水質・生息の学術的裏付けは本文に示されず住民の概括観察として記録〕。
- **意義〔観察〕**: ①善福寺川上流地下調節池をめぐる住民側の一次表明資料として、[GOV-485](../gov/GOV-485.md)（都側）と**同一の立坑3か所・1557億円を対極から共有している**ことを確認できる＝両者の事実認識の大部分は一致し、争点は工期・用地取得・評価方法に集中している構図の記録。②「原寺分橋付近住宅地」という第3立坑文言は、[GOV-149](../gov/GOV-149.md)第240回追記の武蔵野市下水道吐口（原寺分橋袂）・原寺分橋湧水（GOV-485の観測井戸方針）と場所を共有する**「原寺分橋」という地点の多層的な意味論**（吐口×湧水×立坑×住民の立退き）を記録に値する。③森川明夫技術士の費用対効果批判（GOV-149追記）と署名18,000筆超という**数値で示される住民側の規模感**を接続する資料。repoの対照系（善福寺川）としてはじめての住民団体の組織的資料というだけでなく、千川上水・谷端川周辺でも先例のない**「上水・用水の考古層」に現代の用地取得・地上権の問題として直接触れる点**で四河川研究の現代史側の補助線〔推定〕。
- **制限・未解決**: ①団体の設立年・構成・正会員数は本文未記載。②署名18,000筆の提出先・時期の詳細は未確認。③「2023年8月に突然発表」の発表媒体・都側資料との整合（令和5年8月下旬の素案説明会4回〔GOV-485〕との前後関係）は断定できないまま記録〔住民側の「突然」文言と都側の「手続き」文言の温度差自体が資料的価値。両文言の併置で判断は読者に委ねる〕。④2026年5月の住民抗議・作業中止（東京新聞〔GOV-485関連報道欄〕）と本サイトの関係（声明主体）は未確認。
