# [ORG-028] JIA城北地域会 まち歩き「谷端川をたどる。（第二弾）」

- **資料〔確認〕**：JIA城北地域会のまち歩き案内頁（2019.09.17投稿、実施日2019年9月21日）。2012年の豊島区まち歩き（第一弾）の中流域方面の再訪と説明される。**ORG-014（2017年・板橋駅東口→王子の千川用水コース）とは別イベント**で、谷端川中流域を対象にしたプログラム。
- **経路〔確認〕**：北池袋駅→池袋中学校・池袋本町小学校→氷川神社→**神社下遺跡**→谷端川緑道→板橋駅ガード→市場通り商店街→**旧鎌倉橋（鎌倉街道）**→明治通り→**上池袋東公園（千川幹線工事・第三の谷端川）**→巣鴨新田→大塚駅→天祖神社→旧大塚三業地。
- **用語〔確認〕**：千川増強幹線（上池袋東公園地下・GOV-082/BLOG-134）を「**第三の谷端川**」と呼ぶ表現がイベント案内に現れる。都下水道局のインフラ整備を谷端川の後継水路として位置づける呼称で、（確認限り）repo初出の用例。ハザードマップで大豪雨時に1〜2m浸水危険地帯と告知される谷端川流域の認識も記す。
- **地域史の補助情報〔確認〕**：経路上の神社下遺跡を「四千年前の縄文遺跡が明治期に豊島区内で発掘され100年後に再確認された場所」と紹介。氷川神社（池袋本町）・旧大塚三業地（BLOG-093・第35回の大塚花街と同系統）を経路に含む。
- **repoへの関連〔整理〕**：旧鎌倉橋＝谷端川と鎌倉街道の交点（BLOG-133の鎌倉橋と同一。BLOG-122の耕地整理橋観察とも接続）。上池袋東公園＝千川増強幹線中間立坑部（BLOG-134の宮仲公園・北大塚2-23と並ぶ接続部）。「第三の谷端川」用例は千川増強幹線の説明資料として加算できる。
- **制限〔未解決〕**：イベント案内のみで、実施報告・配布資料の内容は未確認。神社下遺跡の正式遺跡名（氷川神社裏貝塚〔ORG-029〕と同一か否か）は本文では特定できない。
