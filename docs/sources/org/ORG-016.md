# [ORG-016] としまの記憶 水窪川コース（2023年5月13日）の開催記録

- **資料〔確認〕**: NPO法人「としまの記憶」をつなぐ会「[消えた〝としまの川〟を訪ねる1 水窪川コース（5/13）](https://toshima-kioku.jp/toshimanokawa1/)」（申込フォームページ・実施日時2023/5/13〔土〕13:00〜15:00・集合ニッセイ池袋ビル前）。2026-11-11全文取得確認。**同会の「消えたとしまの川」シリーズの第1回として水窪川を最初に扱ったことの記録**（[ORG-007](ORG-007.md)の谷端川3回踏査〔2024〕に先行する開催）。
- **〔確認・二次〕** 案内文：水窪川は**東池袋に源を発し、現在は美久仁小路となっている**場所に水源があった。**暗渠化され、その上を道路が整備されている。下流部は弦巻川と併流し、神田川に合流する**。**上流部の地名を由来とし、都電荒川線の東池袋四丁目停留場はかつて水久保停留所であった**。**巣鴨プリズンから水窪川への排水口の石組みは、東池袋4丁目のとしまみどりの防災公園（IKE・SUNPARK）に遺構として保存されている**〔確認：主催者案内文言／水久保・IKE・SUNPARK石組みは既収録（[GOV-001](../gov/GOV-001.md)・[BLOG-025](../blogs/BLOG-025.md)）の再叙述。「**下流部は弦巻川と併流し**」という明示的な表現は弦巻川・水窪川の下流接続をめぐる未解決問題への独立傍証候補〕。
- **〔未解決〕** ツアー当日の記録（動画アーカイブに水窪川編があるかは本確認では未確認）、「谷戸川」表記（谷端川編ページの周辺文言に見える）と谷端川の関係、案内者の解説内容。
