# [ORG-040] 武蔵野大学校友サイト「仏教ゆるさんぽ」後編〔散華乙女の記念樹碑の建立年・由来・現行追悼体制の学園側記録〕

## 書誌〔確認: ページ本文・2026-11-23取得〕

- 学校法人武蔵野大学 校友サポートサイト「**仏教ゆるさんぽ ～武蔵野キャンパス編 後編～**」 https://www.mu-alumni.jp/alumni/18412/ （**2025.12.01**・カテゴリ「校友トピックス」・**監修：仏教教育事務課**・著者表記なし）。武蔵野キャンパスの中のモニュメントを「これ、なんだろ？」とひも解くシリーズの後編で、案内役は仏教教育事務課のアオヤマ課長。

## 散華乙女の記念樹碑（記事冒頭の連載リストで「侘助と散華乙女の記念樹碑（わびすけとさんげおとめのきねんじゅひ）」として項目7）〔確認〕

- **位置**: 「**雪頂講堂と大学図書館のちょうど間**に建てられた石碑」。かたわらに侘助（椿の一品種）が植えられ、冬に白い花を咲かせる〔位置の明文は[GOV-558](../gov/GOV-558.md)（西東京市新町）と整合〕。
- **1944年12月3日の事件の叙述**: 「時は1944年（昭和19年）。…武蔵野女子学院高等女学校の生徒たちは、学徒勤労動員として**中島飛行機武蔵製作所**で航空機増産のため連日けんめいに働いていました。**武蔵野の地が初めて空爆の恐怖にさらされた日から9日後の12月3日、4人の生徒が空襲に遭い尊い命を落としました。校庭に落ちた6発の爆弾のうち1発が、避難していた掩蓋壕（えんがいごう）に命中してしまったのです**。この4人はその後「散華乙女」と呼ばれるようになりました」〔初空襲11月24日から9日後＝12月3日、校庭6発・1発が掩蓋壕命中・死者4名、の文言群は[ORG-041](../org/ORG-041.md)（証言集引用）と一致。本文中に氏名の記載なし（氏名はORG-041）〕。
- **鷹谷俊之校長の植樹**: 「当時の武蔵野女子学院高等女学校の**鷹谷俊之校長**はその**爆弾跡に土壇をつくり、侘助を植えて哀悼の記念樹**としました」〔鷹谷俊之の名と「爆弾跡に土壇」の細部はrepo初出〕。
- **碑の建立**: 「しかしながら侘助が成長するにつれ記念樹の由来を知る人も少なくなっていきました。そこで記念樹の由来を記した碑を建てる計画が立てられたのです。その話を聞きつけた**石材商「石正園」のご主人が台石を寄贈**してくださり、その台石に**黒御影石の碑文**を刻み、**1978年（昭和53年）12月「散華乙女の記念樹碑」が建てられました**」〔**建立年月・石材の細部（石正園台石寄贈・黒御影石）はrepo初出**〕。
- **現行の追悼体制**: 本法人では**毎年12月3日**、犠牲となった4人の乙女を追悼する「**散華乙女の追悼会**」の法要が記念樹碑前で執り行われる（12月3日が土日祝日の場合は前後に実施）。同時期に**雪頂講堂1階ロビーで「散華乙女追悼写真展」**も開催され、**中島飛行機武蔵製作所シリンダー内壁を検査する学徒勤労動員の写真**や**1トン爆弾の模型**が展示される。
- **体験談へのリンク**: 「平和の尊さを強く感じる 島津好江さん」「今日もまた手を合わせて願う 土手内幸枝さん」（卒業生の戦争体験談として記事末尾で紹介・本文未確認）。

## 同時収録の雪頂講堂・高楠順次郎像の沿革〔確認・背景〕

- **雪頂講堂**: 学院創立60周年記念事業として、かつて「第一講堂」があった場所に**1986年（昭和61年）2月**に再建。「雪頂」は学祖・高楠順次郎の雅号（ヒマラヤ）で、公募で決定。1929年（昭和4年）中央区築地から武蔵野に校舎移転〔12月3日の爆弾で「二人は第一講堂の屋根に落下」（[ORG-041](../org/ORG-041.md)）という第一講堂の、後年の再建関係〕。
- **高楠順次郎像**: 1970年（昭和45年）5月21日完成、島根県出身の塑像家・池田佳穂作。当初は紅雲台の玄関に置かれ、雪頂講堂完成後1階ロビーへ。
