# 2026-11-08・1936年空中写真の初回判読（B7-C3-70）

[空中写真目録](空中写真目録.md)は2026年10月25日時点で「写真本体はまだ1コマも視認していない」状態だった。本メモは**その最初の実画像判読**として、1936年6月11日撮影の陸軍写真 **B7-C3-70**（[MAP-126](sources/maps/MAP-126.md)、ビューアID 695350）を扱い、画像取得方法・観察・限界を記録する。

## 画像取得方法（再現用）

〔確認：2026年11月8日に実際に取得・視認〕

1. 検索API `https://service.gsi.go.jp/map-photos/app/api/photo?id={ID}` でメタデータ（撮影日・縮尺・四隅座標）を得る。
2. 詳細API `https://service.gsi.go.jp/map-photos/app/api/photo/{ID}`（**パスパラメータ**。`?id=` ではない）が画像パス `url_image_simple`（100dpi）・`url_image_standard`（400dpi）を返す。
3. 画像本体は `https://service.gsi.go.jp/map-photos/contents/screen/mapphoto/img/{画像パス}` で取得できる。**簡易版・標準版はいずれもユーザー登録なしでダウンロードできた**。B7-C3-70の標準版は3130×2200ピクセル・約2.6MB。
4. アクセスにはブラウザ相当のUser-Agent文字列が必要。curlの既定UAでは403 Forbiddenになる。
5. 最大画質（`is_image_high`）はオンライン閲覧機能に登録が要るため未確認。

目録の「簡易閲覧は無償・登録不要、高画質・最大画質は登録が必要」という記述のうち、**400dpi標準版までは登録不要で公開されている**ことを実測で確認した。最大画質の要否は引き続き未確認。

## 観察（標準版画像の判読）

〔観察：画像に見えること〕北が上、撮影範囲は西池袋・雑司が谷・護国寺・目白台・音羽・東池袋南半。

- **護国寺境内**：中央左に大規模な樹林（暗調）と明るい屋根の本堂・講堂類。東側を不忍通りが斜断する。樹林の広がりは現地図の護国寺境内と整合する。
- **雑司が谷の谷筋**：中央部に**格子状に区画された農地**（畑・水田候補）が広く残る。区画境界の明線は道路・畦であり、連続する河道の描線は確認できない。
- **北端（東池袋・上池袋方面）**：平行する切妻棟を6〜7棟並べた塀囲いの大規模施設と、東側の大きな楕円トラック状空地。
- **右下部（音羽・小日向方面）**：楕円トラックを持つ学校と複数の大型校舎。
- 谷筋の低地には農地・樹林が残り、1936年時点で**谷が完全に市街化・暗渠化してはいない**ことが読み取れる。

## 候補となる説明（未確定）

〔推定〕

- 雑司が谷の格子状区画は、谷筋の低地を利用した農地（水田または畑）の可能性が高い。水窪川の旧流路沿いの土地利用を示す間接証拠になり得る。
- 北端の平行棟施設は、配置・規模から軍事施設・大規模福祉施設（養育院系）・工場のいずれかが候補。**現時点で特定しない**。
- 右下の楕円トラック校は、お茶の水女子大学・筑波大学附属系学校の候補。位置照合が未検証。

## 反証・留保

〔留保：この写真だけでは言えないこと〕

- **水窪川・弦巻川の河道そのものは確認できない**。農地区画・樹林・道路は判読できるが、水面・河道の連続はこの1コマでは確定できない。したがって[水窪川と弦巻川の合流・接続問題](open-questions/水窪川と弦巻川の合流・接続問題.md)・[弦巻川下流の成立年代](open-questions/音羽谷西側の弦巻川下流の成立年代.md)をこの写真で解くことはできない。
- 四隅座標からの幾何補正は大まかな対応で、建物単位の正確な位置同定には検証が要る。施設名・学校名の推定はいずれも未確定。
- 写真の色調・コントラストで水面判定は誤り得る（目録の判読上の注意と同じ）。
