## 1. TOKYOアーカイブ自動アクセスの技術メモ（第232回の遮断解除）

- **到達法〔確認・実測〕**: `http://archive.library.metro.tokyo.jp/` へのアクセスはリダイレクトで **`https://archive.library.metro.tokyo.lg.jp/da/top`（`.lg.jp` ドメイン）** に着地する。`.jp` 側の HTML 遮断はリダイレクト先を直接叩くことで回避できる。cookie jar（例: `/tmp/ta.jar`・`curl -c`）でトップ頁の cookie を保持すると以後の頁が安定して開く。
- **頁構造〔確認〕**:
  1. 検索: `POST/GET {base}/da/result_s?q={URLエンコード}` → 抜粋 `moveDetail('{tilcod}', n)` から **tilcod**（例 `0000000015-00215097`）を抽出。
  2. 詳細: `{base}/da/detail?tilcod={id}&start=0` → `<th>/<td>` 表から書誌（題名・文庫名・請求記号・資料コード・「画像の使用条件」等）を抽出。
  3. 画像リスト: `{base}/da/ajax/image` に `page=0&start=0&tilcod={id}` を POST → JSON の `imagePath`（URLエンコード済ファイルパス）・`total`（全コマ数）。
  4. 画像DL: `{base}/da/download/?id={tilcod}&size=zoom&type=image&file={encoded path}` → **フル解像度JPEG**が直接取得できる（例: 神田上水組合限絵図金森 = 6000×4500px・約761KB）。
- **制約**: 当実行環境では取得画像の文言OCR・判読が不可能（read_file のバイナリ画像読み込み不可・画像ライブラリの導入禁止）。したがって**書誌・コマ数・画像取得可の確認までは機械ででき、文言確定は human 閲覧（または閲覧環境での目視）待ち**という役割分担になる。画像DLは 40 秒前後の間隔を置かないと 503/空応答を返す時がある（ajax/image で数件連続すると失敗しやすい）。

3. **[MAP-207](sources/maps/MAP-207.md) 神田上水図「神田上水組合限絵図金森（袋共）」**（1枚39.5×54＋24×33.5cm・**木子文庫**〔甲良家関係〕・木11-5-5-1/木011-5-05・資料コード4300071161・[detail?tilcod=0000000016-00042992](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000016-00042992)・全2コマ・zoomフル解像度JPE**G取得実績済み**）。題名の「金森」は[GAZ-114](sources/gazetteers/GAZ-114.md)の走査河川名リストの「金森」に接する語だが、**金森の比定（地名か・人名か・組合名か）も「組合限」の意味（[GOV-463](sources/gov/GOV-463.md)「組合限取集」・[GOV-387](sources/gov/GOV-387.md)「御組合限月行事」の用水組合境界か）も全くの文言未確認**。作事大工甲良家文庫の収蔵点という文化財的所在の珍度だけが確定している。
