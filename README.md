# otowa-ankyoscape

水窪川・弦巻川・谷端川と、その周辺の旧河道・暗渠・湧水・用水・土地利用について調べた記録です。

中心となる範囲は、池袋・雑司が谷・護国寺・音羽・小日向・小石川です。

**追加調査対象：人参川（古茗荷谷川との関係は未確定）** — 2026年10月8日、茗荷谷の西側谷頭について明治初期の地図表示と色別標高図を照合。筑波大学附属中・高の南方にある浅い枝谷が合流する可能性も含め、[人参川の調査ノート](docs/人参川.md)に記録した。**10月8〜9日の現地歩行・二源頭・古地図上の池・筑附南方の分水界候補・還国寺の湧水・水窪川の橋名**は[専用の観察記録](docs/2026-10-09・茗荷谷・人参川現地観察.md)に整理した。名称の史料上の確実性と、水路・谷地形の推定は区別している。

> [!IMPORTANT]
> このリポジトリでは、既知の河川史をまとめるだけでなく、**まだ決着していない流路・接続・成立年代を史料から検証すること**を重視します。
> とくに「水窪川と弦巻川はどこかで合流していたのか」「音羽通り西側の弦巻川下流はいつ成立したのか」「弦巻川・水窪川側と谷端川側の更新世旧河道はどちら向きに流れていたのか」は中心的な未解決問題です。

## 水系の全体像

```mermaid
flowchart TD
    A[西池袋・丸池方面] --> B[弦巻川]
    B --> C[雑司が谷]
    C --> D[護国寺・音羽谷 西側]
    D --> K[神田川]

    E[東池袋・蟹ヶ窪方面] --> F[水窪川]
    F --> G[大塚]
    G --> H[護国寺・音羽谷 東側]
    H --> K

    S[千川上水] --> T[谷端川]
    T --> U[小石川]
    U --> K
```

これは近代以降に把握しやすい大まかな配置であり、全時代にそのまま当てはまるとは限りません。近世の造成・灌漑、近代の河川改修、暗渠化、下水道再編によって接続関係や流路が変化した可能性があります。

- **1993年の豊島区立郷土資料館だよりは、三河川の暗渠化後の認識と神田川の旧流路を同時に伝える。** 『**かたりべ』30号（1993年4月30日）**の印刷**p.6**「郷土資料館なんでもQ&A」（回答者「伊藤」）は、当時区内で地表を流れる川を**新宿区境の神田川**とし、**谷端川・弦巻川・水窪川・谷戸川を「自然の川」、千川上水を「人工の川」**として列挙する。谷端川の**農業用水としての利用から生活排水の流入への変化**、川跡が道路・公園として残ること、**千川上水は上流で通水が復活したが豊島区内は暗渠のまま**だったことも記す。〔**確認：1993年の公的館報の本文を原PDF画像から直接判読／観察：当時の河川認識と土地利用の概説**〕 同号**p.1**「区境が見えた！」は、**3月7・14・21・28日**の高田・雑司が谷等の境界踏査を報じ、**目白3-4／下落合3-1の旧高田町・落合村境**を写真で示し、踏査を通じて**護岸工事以前の神田川の流路**を意識したと記す。〔**確認：館報の踏査記録／推定：旧区村境と改修前河道を地図照合する手掛かり**〕 **「自然の川」は資料館による総称で、弦巻川下流の成立過程や水窪川との接続を確定しない**。境界写真の細道を旧神田川河床と同一視せず、**1993年の現況・記憶を現在の状態や改修工事年と混同しない**。〔**未解決：旧神田川の河道中心線、護岸工事の区間・年代、個別水路の人工改変**〕 出典：[GOV-039](docs/sources/gov/GOV-039.md)／[豊島区公式PDF](https://www.city.toshima.lg.jp/documents/2549/kataribe30.pdf)。
